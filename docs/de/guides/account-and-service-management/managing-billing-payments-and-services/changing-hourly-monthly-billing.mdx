## Ziel

Wenn Sie eine Public Cloud Instanz erstellen, können Sie wählen, ob die Abrechnung stündlich oder monatlich erfolgen soll (Ausgenommen sind Public Cloud-Instanzen der dritten Generation, die standardmäßig stundenweise abgerechnet werden und bei deren Erstellung keine monatliche Option angeboten wird). Instanzen mit Stundensatz werden nach dem Verfahren *Pay as you go* abgerechnet, d.h. am Monatsende werden den Nutzern die spezifischen Ressourcen in Rechnung gestellt, die sie verwendet haben.

Instanzen mit monatlicher Fälligkeit können im Voraus bezahlt werden und werden zu einem niedrigeren Preis berechnet (bis zu 50% weniger als bei der verbrauchsspezifischen Abrechnung). Wenn Sie ursprünglich die stündliche Abrechnung ausgewählt haben, können Sie jederzeit zur monatlichen Abrechnung wechseln.

**In dieser Anleitung wird erläutert, wie Sie von der stündlichen zur monatlichen Abrechnung wechseln.**

:::warning
Sie können nicht von der monatlichen zur stündlichen Abrechnung wechseln. Um Ihre Instanz im Stundensatz abrechnen zu lassen, müssen Sie die monatlich abgerechnete Instanz löschen, eine neue erstellen und die stündliche Abrechnung auswählen. In diesem Fall empfehlen wir Ihnen das folgende Verfahren:

- Erstellen Sie einen Snapshot Ihrer aktuellen Instanz.

- Erstellen Sie eine neue Instanz basierend auf diesem Snapshot.

- Löschen Sie die alte Instanz.

:::

## Voraussetzungen

- Sie verfügen über eine [Public Cloud Instanz](https://www.ovhcloud.com/de/public-cloud/).

## In der praktischen Anwendung

### Über die OVHcloud Konsole

:::warning
Das folgende Verfahren funktioniert nicht bei Instanzen der dritten Generation (Beispiel: B3-32). Um die monatliche Abrechnung für diese Art von Instanz zu erhalten, müssen Sie einen [Savings Plan](/guides/public-cloud/cross-functional/savings-plans) für diese Instanz erstellen.

:::

Klicken Sie im linken Menü Ihres Public Cloud Projekts unter **Compute** auf <code className="action">Instances</code>. Wählen Sie die Instanz aus, für die Sie die Abrechnungsart ändern möchten, und öffnen Sie ihr Optionsmenü, indem Sie rechts neben der Instanz auf den Button <code className="action">...</code> klicken. Sie sehen dann den Button <code className="action">Auf monatliche Abrechnung umstellen</code>. Sie können auch in der Karte **Allgemeine Informationen** des Tabs <code className="action">Übersicht</code> der Instanz auf <code className="action">Auf monatlich umstellen</code> klicken.

Sie müssen dann bestätigen, dass Sie die Abrechnungsart ändern möchten: Klicken Sie im Fenster **Auf monatliche Abrechnung umstellen** auf <code className="action">Bestätigen</code>.

Sobald Sie Ihre Wahl bestätigt haben, erhalten Sie umgehend eine anteilige Monatsrechnung. Die nächste Rechnung enthält den Stundensatzanteil des Monats (1. des Monats bis zur Änderung) und die neue monatliche Gebühr.

### Über die OpenStack API

Bei der Erstellung einer Instanz mithilfe der OpenStack API wird die Instanz automatisch mit Stundensatz erstellt, wenn nicht anders im Erstellungsskript angegeben. Um auf die monatliche Abrechnung umzustellen, führen Sie folgenden Befehl aus:

```bash
openstack server set --property ovh-monthly-instance=1 "InstanceID"
```

Ersetzen Sie "InstanceID" mit der ID der entsprechenden Instanz. Diese Kennung kann über die OVHcloud Konsole oder die OVHcloud API abgerufen werden.

### Über die OVHcloud API

Öffnen Sie das <ApiLink>OVHcloud API Interface</ApiLink> gemäß der [entsprechenden Anleitung](/guides/manage-and-operate/api/first-steps) und folgen Sie den nachstehenden Schritten.

Verwenden Sie folgenden Aufruf:

<Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\{serviceName\}/instance/\{instanceId\}/activeMonthlyBilling"} />

### Mit einem Terraform-Skript

Dies ist möglich dank des `metadata` [Attributs](https://registry.terraform.io/providers/terraform-provider-openstack/openstack/latest/docs/resources/compute_instance_v2#metadata) aus der Ressource [*openstack_compute_instance_v2*](https://registry.terraform.io/providers/terraform-provider-openstack/openstack/latest/docs/resources/compute_instance_v2):

```terraform
metadata = {
    "ovh-monthly-instance" = 1
}
```
