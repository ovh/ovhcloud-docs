## Ziel

Im Rahmen Ihrer beruflichen Tätigkeit oder aus Interesse an dem Thema müssen Sie möglicherweise den CO2-Fußabdruck Ihrer Dienstleistungen berechnen.

**Diese Anleitung erklärt, wie Sie monatlich die CO2-Bilanz Ihrer OVHcloud Dienste ermitteln.**

## Voraussetzungen

- Ihr Kunden-Account ist der "Rechnungskontakt" für die Dienstleistungen, für die Sie den CO2-Fußabdruck erhalten möchten. Weitere Informationen finden Sie in [unserer Anleitung zur Kontaktverwaltung](/guides/account-and-service-management/account-information/managing-contacts).

[[cpnav:account-dashboard]]

**Die Berechnung des CO2-Fußabdrucks ist für folgende Dienste verfügbar:**

- [Dedicated Server](https://www.ovhcloud.com/de/bare-metal/) (Advance, Game, Scale, High Grade, Storage)
- [Eco Dedicated Server](https://eco.ovhcloud.com/de/) (Rise, Kimsufi, So you Start)
- [VMware on OVHcloud](https://www.ovhcloud.com/de/hosted-private-cloud/vmware/)
- [Public Cloud](https://www.ovhcloud.com/de/public-cloud/)

## In der praktischen Anwendung

:::info
Daten zum Kohlendioxidausstoß für 3AZ-Architekturen und Local Zones sind noch nicht verfügbar.

:::

Dabei sind mehrere Punkte zu beachten:

- Für den laufenden Monat kann keine Bilanz erstellt werden.
- Unabhängig davon, ob Sie über die OVHcloud API ein Datum am Anfang, in der Mitte oder am Ende eines Monats eingeben, berücksichtigt die Bilanz stets vollständige Monate.
- Nach Ablauf der letzten 24 Monate kann keine Bilanz erstellt werden.
- Für jeden OVHcloud Dienst kann vor der Bereitstellung der Funktion keine Bilanz erstellt werden (siehe nachstehende Tabelle).

### Abrufen der monatlichen Bilanz des Vormonats über das OVHcloud Kundencenter

1. Auf dem <ManagerLink to="/#/account/useraccount/dashboard">Mein Account</ManagerLink> gehen Sie in der linken Spalte nach unten zu **Nützliche Links**, und klicken Sie dann auf den Tab <code className="action">Meine CO2-Bilanz</code>.
1. Klicken Sie auf der neu geöffneten Seite auf <code className="action">Meinen CO2-Fußabdruck von [Monat] [Jahr] herunterladen</code>.

<img className="thumbnail" alt="Carbon footprint" src="/images/assets/screens/control-panel/product-selection/right-column/carbon-footprint/my-carbon-footprint.png" loading="lazy" />

Sie können jeden Monat die CO2-Bilanz des Vormonats für Ihre wählbaren Dienste abrufen.

Wenn Sie den CO2-Fußabdruck für einen Monat vor dem Vormonat oder eine Bilanz über mehrere Monate benötigen, müssen Sie diese über unsere API abrufen.

### Eine Bilanz vor dem Vormonat über unsere API abrufen

Standardmäßig wird die OVHcloud API zur Verfügung gestellt, damit Entwickler oder Integratoren Funktionen, die im OVHcloud Kundencenter vorhanden sind oder darüber hinaus direkt in ihren Anwendungen oder Lösungen kombinieren können.

#### Schritt 1 - Verbindung zur OVHcloud API

- Besuchen Sie unsere Website <ApiLink>OVHcloud API</ApiLink> (überprüfen Sie, ob Sie sich auf `https://api.eu.ovhcloud.com` befinden, wenn Ihre Dienste in Europa gehostet werden, und auf `https://api.ca.ovhcloud.com`, wenn sie außerhalb Europas gehostet werden).
- Klicken Sie auf der angezeigten Seite auf <code className="action">Explore the OVHcloud API</code>.
- Gehen Sie auf der neu angezeigten Seite und links auf der Seite auf das Formular rechts neben dem Feld <code className="action">v1</code> und wählen Sie die Option `/me` aus.
- Suchen Sie in der unten angezeigten Liste der API-Aufrufe nach dem Aufruf, der dem gewünschten Format entspricht, und klicken Sie auf diesen: **POST /me/carbonCalculator/pdf** für eine Bilanz im PDF-Format oder **POST /me/carbonCalculator/csv** für eine Bilanz im CSV-Format. Sie können auch direkt auf einen der unten stehenden API-Aufrufe klicken, um darauf zuzugreifen:

<Api version="v1" section="/me" method="POST" route={"/me/carbonCalculator/pdf"} />

<Api version="v1" section="/me" method="POST" route={"/me/carbonCalculator/csv"} />

- Auf der rechten Seite wird dann der Aufruf mit den zu vervollständigenden Daten angezeigt.
- Klicken Sie oben rechts auf <code className="action">Authenticate</code> und dann auf <code className="action">Login with OVHcloud SSO</code>.
- Das Login-Interface für Ihr <ManagerLink to="/#/account/useraccount/dashboard">OVHcloud Kundencenter</ManagerLink> wird geöffnet.
- Loggen Sie sich mit Ihrer Kundenkennung ein und klicken Sie auf <code className="action">Authorize</code>, um die OVHcloud API mit Ihren Diensten zu verwenden.
- Sie werden dann automatisch auf die vorherige Seite des gewählten API-Aufrufs weitergeleitet.

#### Schritt 2 - Bilanzgenerierung anfordern und die ID des angeforderten Tasks abrufen

Je nach gewünschtem Format stehen zwei API-Aufrufe zur Verfügung. Die in diesem Schritt erhaltene `taskID` liefert eine PDF- oder eine CSV-Datei, je nach dem in Schritt 1 gewählten Aufruf. Wählen Sie den entsprechenden Tab aus.

<Tabs>
  <Tab label="PDF-Format">
    Der API-Aufruf **POST /me/carbonCalculator/pdf** generiert eine Bilanz für einen einzelnen Monat.

    Ersetzen Sie das aktuelle Datum in der Konsole durch ein Datum des Monats, für den Sie die Bilanz erhalten möchten. Beachten Sie das folgende Datumsformat:

    ```bash
    {
      "month": "YYYY-MM-DD"
    }
    ```

    Der eingegebene Tag ist unerheblich: Unabhängig davon berücksichtigt die Bilanz den gesamten Monat. Der angeforderte Monat darf weder der laufende Monat sein noch mehr als 24 Monate zurückliegen.

    <img className="thumbnail" alt="API" src="/images/assets/screens/api/post-me-carboncalculator-pdf.png" loading="lazy" />

    Wenn Sie das Datum richtig eingegeben haben, klicken Sie unten rechts im zuvor ausgefüllten Abschnitt auf die blaue Schaltfläche <code className="action">EXECUTE</code>.
  </Tab>
  <Tab label="CSV-Format">
    Der API-Aufruf **POST /me/carbonCalculator/csv** generiert eine Bilanz für einen Zeitraum von mehreren Monaten.

    Ersetzen Sie die beiden Daten in der Konsole durch den Monat, in dem die Berechnung beginnt, und den Monat, in dem sie endet. Beachten Sie das folgende Datumsformat:

    ```bash
    {
      "endMonth": "YYYY-MM-DD",
      "startMonth": "YYYY-MM-DD"
    }
    ```

    Der eingegebene Tag ist unerheblich: Unabhängig davon berücksichtigt die Bilanz vollständige Monate, mindestens jedoch einen Monat. Das Enddatum (`endMonth`) muss nach dem Startdatum (`startMonth`) liegen, und das Startdatum darf nicht mehr als 24 Monate zurückliegen.

    <img className="thumbnail" alt="API" src="/images/assets/screens/api/post-me-carboncalculator-csv.png" loading="lazy" />

    Wenn Sie beide Daten richtig eingegeben haben, klicken Sie unten rechts im zuvor ausgefüllten Abschnitt auf die blaue Schaltfläche <code className="action">EXECUTE</code>.
  </Tab>
</Tabs>

Unabhängig vom verwendeten Aufruf erscheint, wenn alles korrekt ausgeführt wurde, im Fenster <code className="action">RESPONSE</code> unten auf der Seite unter der Schaltfläche <code className="action">EXECUTE</code> eine `taskID`.

Wenn Ihre OVHcloud Kundenkennung beispielsweise `aa00000-ovh` lautet und Sie eine Bilanz im PDF-Format für den Monat Januar 2025 angefordert haben, erhalten Sie folgendes Ergebnis:

```bash
{
  "taskID": "aa00000-ovh_202501"
}
```

Kopieren Sie nur den Wert der dem Wert unseres Beispiels `aa00000-ovh_202501` entspricht (ohne die beiden (`"`) an den Enden zu kopieren).

#### Schritt 3 - Datei mit der Kohlenstoffbilanz Ihrer Dienstleistungen im PDF- oder CSV-Format abrufen

Dank des zuvor abgerufenen Wertes der `taskID` (aus dem PDF-Aufruf oder aus dem CSV-Aufruf) können Sie die CO2-Bilanz Ihrer Dienstleistungen abrufen.

In unserer API-Konsole <ApiLink>OVHcloud API</ApiLink> führen Sie folgende Aktionen aus:

- Gehen Sie auf der linken Seite auf das Formular rechts neben dem Formular <code className="action">v1</code> und wählen Sie/geben Sie die Option <code className="action">/me</code> ein.
- Suchen Sie in der unten angezeigten Liste der API-Aufrufe nach dem folgenden API-Aufruf, und klicken Sie auf diesen: **GET /me/carbonCalculator/task/&#123;taskID&#125;**. Sie können auch direkt auf den unten stehenden API-Aufruf klicken, um darauf zuzugreifen:

<Api version="v1" section="/me" method="GET" route={"/me/carbonCalculator/task/\{taskID\}"} />

- Auf der rechten Seite wird dann der API-Aufruf mit einem auszufüllenden Formular angezeigt.

Füllen Sie das Formular im Teil `PATH PARAMETERS` aus:

- `taskID`: Kopieren Sie den in Schritt 2 abgerufenen Wert der `taskID` hier, unabhängig vom angeforderten Format.

<img className="thumbnail" alt="API" src="/images/assets/screens/api/get-me-carboncalculator-task-taskid.png" loading="lazy" />

Wenn Sie den Wert Ihrer `taskID` korrekt eingegeben haben, klicken Sie auf den blauen Button <code className="action">EXECUTE</code>.

Das folgende Ergebnis wird im Fenster <code className="action">RESPONSE</code> angezeigt, wenn Sie nach unten auf die Seite unterhalb der Schaltfläche <code className="action">EXECUTE</code> gehen:

```bash
{
  "link": "Find here the complete URL to download the carbon footprint",
  "status": "SUCCESS",
  "taskID": "aa00000-ovh_202501"
}
```

Kopieren Sie in diesem Ergebnis die gesamte URL inklusive HTTPS rechts neben dem Vermerk `"link":` und fügen Sie sie in die Adressleiste Ihres Browsers ein, um das Herunterladen der CO2-Bilanz im angeforderten Format zu starten.

Die Datei wird in Ihrem Browser automatisch heruntergeladen und kann bei einer Bilanz im PDF-Format direkt angezeigt werden.

:::info
Je nach Konfiguration Ihres Browsers kann es sein, dass der Download oder die Anzeige der Datei blockiert werden. Ist das der Fall, überprüfen Sie die Konfiguration Ihres Browsers und laden Sie die Seite neu.

:::

Nach dem Öffnen der Datei enthält sie u.a. folgende Elemente.

**In der Bilanz im PDF-Format:**

- Eine Tabelle mit einer Übersicht über die CO2-Emissionen nach Kategorien für den beantragten Monat
- Eine Übersicht über die CO2-Emissionen nach Kategorien vom Beginn des Kalenderjahres bis zum beantragten Monat
- Eine Tabelle, in der die Werte nach der Art des abonnierten Produkts aufgeführt sind
- Eine Grafik mit den CO2-Emissionen nach Kategorie

**In der Bilanz im CSV-Format:**

- Eine Übersicht über die CO2-Emissionen pro physischem Server bzw. pro Serverreihe (PCI) für den bzw. die beantragten Monate

:::warning
Der generierte Link ist nur 24 Stunden gültig. Achten Sie also darauf, die CO2-Bilanz mit Ihrem Browser herunterzuladen, nachdem der Link geöffnet wurde.

:::
