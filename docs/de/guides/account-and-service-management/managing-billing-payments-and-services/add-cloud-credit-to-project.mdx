## Ziel

Mit der Option "Cloud Guthaben" können Sie in Ihrem Public Cloud Projekt einen bestimmten Betrag hinterlegen, der als Standardzahlungsmittel für die [Abrechnung des Projekts](/guides/public-cloud/cross-functional/analyze-billing) zugewiesen wird.<br/>
Das bedeutet, dass dieses Guthabenkonto zuerst belastet wird und dann noch verbleibende Beträge mit anderen verfügbaren Zahlungsmitteln beglichen werden. Weitere Informationen finden Sie in der [Public Cloud Dokumentation zur Abrechnung](/guides/account-and-service-management/managing-billing-payments-and-services/best-practices).

**Diese Anleitung erklärt, wie Sie Guthaben für Ihr Public Cloud-Projekt aufladen können, mit einem Gutschein oder über eine Bestellung.**

## Voraussetzungen

- Sie verfügen über ein [Public Cloud Projekt](/links/public-cloud/public-cloud) in Ihrem OVHcloud Kunden-Account.

[[cpnav:publiccloud-credits-vouchers-console]]

## In der praktischen Anwendung

Klicken Sie im linken Menü Ihres Public Cloud Projekts auf <code className="action">Kostenstelle</code> und dann auf den Tab <code className="action">Guthaben & Gutscheine</code>. Die Buttons dieses Tabs sind für ein Projekt im Discovery-Modus nicht verfügbar.

:::warning
Bitte beachten Sie, dass die in diesem Abschnitt hinzugefügten Mittel nicht übertragen oder erstattet werden können. Sie haben keinen Geldwert, und nicht genutztes Guthaben verfällt 13 Monate nach dem Kauf.

:::

### Guthaben aufladen

Klicken Sie auf den Button <code className="action">Cloud-Guthaben aufladen</code>.

Geben Sie im Fenster **Cloud-Guthaben aufladen** im Feld **Betrag der Aufladung** den Betrag (ohne MwSt.) ein, den Sie in Ihrer Währung hinzufügen möchten. Klicken Sie auf <code className="action">Bestellschein erstellen</code>, um zu bestätigen.

Ein Bestellschein wird dann erstellt. Klicken Sie auf den Link in der grünen Benachrichtigung, um ihn in einem neuen Tab anzuzeigen und die Zahlung zu veranlassen.

Sobald die Zahlung eingegangen ist, erscheint Ihr Guthaben im Tab <code className="action">Guthaben & Gutscheine</code>.

### Einen Gutschein verwenden

Klicken Sie auf den Button <code className="action">Gutschein aktivieren</code>.

Geben Sie im Fenster **Gutschein aktivieren** Ihren Gutscheincode im Feld **Ihr Gutschein** ein und klicken Sie auf <code className="action">Aktivieren</code>.

Der Gutschein-Saldo erscheint im Tab <code className="action">Guthaben & Gutscheine</code>.

:::info
Gutscheine sind in der Regel einen Monat gültig. Verwenden Sie den Gutschein so schnell wie möglich. Der Gutschein-Saldo wird vor dem Public Cloud Guthaben verwendet.

:::
