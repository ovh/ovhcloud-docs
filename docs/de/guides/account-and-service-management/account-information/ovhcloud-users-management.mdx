## Ziel

Bei OVHcloud haben Sie die Möglichkeit, lokale Benutzer zu erstellen und diesen Lese- oder Schreibrechte für Ihren Kunden-Account zu erteilen. So können Sie Mitgliedern Ihres Unternehmens Zugriff auf Ihre OVHcloud Dienste gewähren, ohne einen riskanten Umweg zu nehmen, indem Sie etwa Ihr Passwort oder Login-Codes weitergeben.

:::info
Die Benutzerverwaltung unterscheidet sich von der Kontaktverwaltung. Ein Benutzer erhält abhängig von der zugewiesenen Berechtigungsstufe Zugriff auf alle Bereiche der OVHcloud Konsole.

Bei der Kontaktverwaltung hingegen geht es darum, die vollständige Verwaltung der administrativen, technischen oder rechnungsrelevanten Aspekte eines oder mehrerer Dienste Ihres OVHcloud Accounts auf eine andere Person zu delegieren. Für weitere Informationen zur Verwaltung der Kontakte lesen Sie [unsere Anleitung](/guides/account-and-service-management/account-information/managing-contacts).

:::


**Diese Anleitung erklärt, über welche Rechte ein lokaler Benutzer verfügen kann und wie Sie Benutzer hinzufügen und verwalten.**

## Voraussetzungen

- Sie verfügen über einen aktiven OVHcloud Kunden-Account.

## In der praktischen Anwendung

### Grundlegendes zu Identitäten

Lokale Benutzer sind einer der Identitätstypen, die in Ihrem OVHcloud Kunden-Account eingerichtet werden können. Diese Typen werden in der [zugehörigen Dokumentation](/guides/manage-and-operate/iam/identities-management) beschrieben.

### Benutzerverwaltung

#### Benutzer hinzufügen

Klicken Sie im Tab **Lokale Benutzer** der Seite <ManagerLink console to="/#/iam/identities/users">Identitäten</ManagerLink> auf <code className="action">Lokalen Benutzer erstellen</code>.

Füllen Sie im Fenster **Lokalen Benutzer erstellen** alle erforderlichen Felder aus. Klicken Sie auf <code className="action">Erstellen</code>, um den Benutzer zu erstellen.

<img className="thumbnail" alt="Fenster Lokalen Benutzer erstellen mit Benutzername, E-Mail, Passwort, Hauptgruppe, Zusätzliche Gruppen und Beschreibung" src="/images/account-and-service-management/account-information/ovhcloud-users-management/console/usersmanagement2.png" loading="lazy" />
 
| Feld | Beschreibung |
|--|--|
| Benutzername | Geben Sie zum Beispiel den Namen des Benutzers oder dessen Funktion ein. |
| E-Mail | Geben Sie die E-Mail-Adresse des Benutzers ein. |
| Passwort | Legen Sie das Passwort des Benutzers fest. Er kann dieses ändern, nachdem der Zugang erstellt wurde. <br/>Wir empfehlen Ihnen, hierzu [die Anleitung zur Passwortverwaltung](/guides/account-and-service-management/account-information/manage-ovh-password) zu lesen. |
| Hauptgruppe | Wählen Sie eine der verfügbaren Gruppen aus (siehe unten stehende Tabelle). |
| Zusätzliche Gruppen | Sie können den Benutzer auch zu weiteren Gruppen hinzufügen. |
| Beschreibung | Sie können eine Benutzerbeschreibung hinzufügen, beispielsweise die Rolle in Ihrem Unternehmen. |

**Standardgruppendetails:**

| Gruppe (Rolle) | Details |
|--|--|
| UNPRIVILEGED (Nur Lesen) | Lesezugriff auf die OVHcloud Konsole und alle ihre Bereiche. |
| DEFAULT (Standard) | Schreibzugriff auf die OVHcloud Konsole und alle ihre Bereiche, **mit Ausnahme der** Benutzerverwaltung. |
| ADMIN (Admin) | Schreibzugriff auf die OVHcloud Konsole und alle ihre Bereiche, **einschließlich** der Benutzerverwaltung. |

Der Benutzer erhält im Anschluss eine eigene Kennung, die aus Ihrer Kundenkennung (NIC-Handle) und seinem Benutzernamen besteht, getrennt durch ein "/". Das Formular zeigt diese Kennung unter dem Feld **Benutzername** an.

Beispiel: **aa00000-ovh/johnsmith**.

<img className="thumbnail" alt="Hinweis zur Anmeldung und Vorschau der Kennung unter Benutzername im Fenster Lokalen Benutzer erstellen" src="/images/account-and-service-management/account-information/ovhcloud-users-management/console/usersmanagement3.png" loading="lazy" />

Der Benutzer kann sich von nun an mit dieser Kennung in der <ManagerLink console to="/#/">OVHcloud Konsole</ManagerLink> einloggen.

Darüber hinaus kann er sein Passwort ändern und seinen eigenen Zugang zu Ihrem Account mithilfe einer Zwei-Faktor-Authentifizierung zusätzlich schützen (diese betrifft nur den Zugriff als Benutzer). Um mehr über die Einrichtung der Zwei-Faktor-Authentifizierung zu erfahren, lesen Sie [diese Anleitung](/guides/account-and-service-management/account-information/secure-ovhcloud-account-with-2fa).

#### Benutzer verwalten

Sie können einen Benutzer bearbeiten, deaktivieren oder löschen, indem Sie in der Spalte **Aktionen** der Zeile des Benutzers auf den Button <code className="action">⋮</code> und dann auf <code className="action">Benutzer bearbeiten</code>, <code className="action">Benutzer deaktivieren</code> oder <code className="action">Benutzer löschen</code> klicken. Ein deaktivierter Benutzer kann über dasselbe Menü wieder aktiviert werden.

<img className="thumbnail" alt="Geöffnetes Menü einer Benutzerzeile mit Benutzer bearbeiten, Benutzer deaktivieren, Tokens verwalten und Benutzer löschen" src="/images/account-and-service-management/account-information/ovhcloud-users-management/console/usersmanagement4.png" loading="lazy" />

Durch Bearbeiten des Benutzers können Sie dessen E-Mail-Adresse, Rechte und die Beschreibung aktualisieren.

<img className="thumbnail" alt="Fenster Benutzer bearbeiten mit den Feldern Benutzername, E-Mail, Hauptgruppe, Zusätzliche Gruppen und Beschreibung" src="/images/account-and-service-management/account-information/ovhcloud-users-management/console/usersmanagement6.png" loading="lazy" />

### Verwaltung der Gruppen

#### Gruppe hinzufügen

Um eine Gruppe hinzuzufügen, gehen Sie zum Tab <code className="action">Benutzergruppen</code> und klicken Sie auf die Schaltfläche <code className="action">Gruppe erstellen</code>.

<img className="thumbnail" alt="Tab Benutzergruppen der Seite Identitäten mit dem Button Gruppe erstellen" src="/images/account-and-service-management/account-information/ovhcloud-users-management/console/usersmanagement7.png" loading="lazy" />

Füllen Sie im Fenster **Gruppe erstellen** die erforderlichen Felder aus. Klicken Sie auf <code className="action">Erstellen</code>, um die Gruppe zu erstellen.

<img className="thumbnail" alt="Fenster Gruppe erstellen mit den Feldern Name, Rolle und Beschreibung" src="/images/account-and-service-management/account-information/ovhcloud-users-management/console/usersmanagement8.png" loading="lazy" />

Gruppen weisen den darin enthaltenen Benutzern je nach ausgewählter Rolle eine Standardberechtigungsstufe zu:

| Rolle | Details |
|--|--|
| Keine | Gewährt keinen Zugriff auf die OVHcloud Konsole, solange keine IAM-Richtlinie existiert. |
| Nur Lesen | Lesezugriff auf die OVHcloud Konsole und alle ihre Bereiche. |
| Standard | Schreibzugriff auf die OVHcloud Konsole und alle ihre Bereiche, **mit Ausnahme der** Benutzerverwaltung. |
| Admin | Schreibzugriff auf die OVHcloud Konsole und alle ihre Bereiche, **einschließlich** der Benutzerverwaltung. |

#### Gruppen verwalten

Sie können eine Gruppe aktualisieren oder löschen, indem Sie in der Spalte **Aktionen** der Zeile der Gruppe auf den Button <code className="action">⋮</code> und dann auf <code className="action">Gruppe bearbeiten</code> oder <code className="action">Gruppe löschen</code> klicken. Diese Aktionen sind für die Standardgruppen UNPRIVILEGED, DEFAULT und ADMIN nicht verfügbar.

<img className="thumbnail" alt="Menü einer Gruppenzeile mit Gruppe bearbeiten und Gruppe löschen, über den Button ⋮ geöffnet" src="/images/account-and-service-management/account-information/ovhcloud-users-management/console/usersmanagement9.png" loading="lazy" />

Wenn Sie eine Gruppe bearbeiten, können Sie ihre Beschreibung und Rolle ändern.

<img className="thumbnail" alt="Fenster Gruppe bearbeiten mit den Feldern Name, Rolle und Beschreibung" src="/images/account-and-service-management/account-information/ovhcloud-users-management/console/usersmanagement10.png" loading="lazy" />

### Rechteverwaltung

Zusätzlich zur Rolle für Benutzergruppen können Sie die Zugriffsrechte mithilfe der OVHcloud IAM-Verwaltung präzisieren.

Beachten Sie dazu unsere Anleitung zur [Verwaltung der IAM-Richtlinien](/guides/account-and-service-management/account-information/iam-policy-ui).
