## Ziel

Als Mitglied des OVHcloud Startup Program können Sie sich mit den unterschiedlichsten Fragen und Anliegen an unsere Startup Program Manager wenden. Ob Sie die Vorteile des Programms besser verstehen, eine technische Beratung für Ihre Server-Infrastruktur anfordern, unsere Produkte entdecken, Möglichkeiten für Partnerschaften ausloten oder erfahren möchten, wo Sie uns auf Events treffen können: Unsere Teams stehen Ihnen zur Seite.

Sie können sie auch um Rat zur Nutzung Ihres kostenlosen Guthabens bitten.

Alle diese Punkte werden in Ihrer Onboarding-Session zu Beginn des Programms ausführlich behandelt, aber unsere Startup Program Manager stehen Ihnen auch danach für eine fortlaufende Unterstützung zur Verfügung.

## Die wichtigsten Punkte

- **Allgemeine Fragen zum Startup Program**: Unsere Startup Program Manager beantworten gerne alle Fragen zum OVHcloud Startup Program und seinen Angeboten zur Unterstützung.
- **Technische Unterstützung**: Als Mitglied des OVHcloud Startup Program erhalten Sie Stunden technischer Unterstützung für Ihre Server-Infrastruktur. Diese Sessions helfen Ihnen zu beurteilen, ob Ihre Infrastruktur Ihren Anforderungen entspricht, und sie andernfalls mit Unterstützung unserer technischen Experten weiterzuentwickeln.
- **Technische Störung**: Bei Fragen zu einer Bestellung oder zu einer laufenden Störung, die einen Ihrer Dienste betrifft, empfehlen wir Ihnen, sich [direkt an unser Vertriebsteam und unseren technischen Support zu wenden](https://help.ovhcloud.com/csm?id=csm_get_help), bevor Sie unser Startup Program Team kontaktieren.

## In der praktischen Anwendung

### Kontakt per E-Mail

Sie können unsere Startup Program Manager bei allen Fragen oder für Unterstützung rund um das Startup Program, einschließlich technischer Beratungen, per E-Mail kontaktieren. Die Kontakt-E-Mail-Adresse für Ihre Region finden Sie in der Onboarding-E-Mail, die Sie bei Ihrem Beitritt zum Startup Program erhalten haben. Verwenden Sie diese Adresse, um mit dem Team für Ihre Region in Kontakt zu treten.

### Einen Startup Program Manager direkt kontaktieren

Wenn Sie bereits mit einem unserer Startup Program Manager in Kontakt stehen oder ihn getroffen haben, können Sie ihn direkt über LinkedIn erreichen. Die vollständige Liste unserer Startup Program Manager finden Sie auf [unserer Website](/links/transversal/startup-program-faq-managers).

### Unsere Teams auf Events treffen

Wir organisieren zahlreiche Events oder nehmen daran teil. Dort beantworten unsere Startup Program Manager Ihre Fragen und stellen Ihnen das OVHcloud Startup Program vor. Die vollständige Liste unserer Events finden Sie auf [unserer Website](/links/transversal/events-startup).

## Fazit

Das OVHcloud Startup Program bietet Ihnen eine persönliche Begleitung während Ihres gesamten Wegs. Ob Sie Rat zur Nutzung Ihres Guthabens, Möglichkeiten zur Zusammenarbeit oder technische Beratungen benötigen: Unsere Startup Program Manager sind für Sie da. Kontaktieren Sie sie per E-Mail, treffen Sie sie persönlich auf Events oder schreiben Sie ihnen über LinkedIn. Bei dringenden technischen Problemen stehen Ihnen auch unsere Support- und Vertriebsteams zur Verfügung. Wir freuen uns darauf, das Wachstum Ihres Startups zu unterstützen und Ihnen zum Erfolg zu verhelfen.
