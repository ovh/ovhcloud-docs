## Ziel

Diese Anleitung erklärt die Schritte, um bei der Nutzung unserer Dienste eine Quota-Erhöhung für Ihren Cloud-Account anzufordern. Wenn Sie am Startup Program teilnehmen, sollten Sie bestimmte Einschränkungen beachten, insbesondere bezüglich der Nutzung des vom Programm bereitgestellten Guthabens bei der Erhöhung Ihrer Quota.

## Die wichtigsten Punkte

- **Nutzung des Startup-Guthabens**: Es ist nicht möglich, eine Quota-Erhöhung mit dem Guthaben aus dem Startup Program anzufordern. Wenn Sie die Quota dennoch erhöhen möchten, befolgen Sie die unten beschriebenen Schritte.
- **Zahlung mit eigenen Mitteln**: Wenn Sie Mitglied des Startup Program sind und sich entscheiden, die Erhöhung Ihrer Quota mit eigenen Mitteln zu bezahlen, kann der gezahlte Betrag (auf Anfrage) Ihrem Kunden-Account als Cloud Guthaben gutgeschrieben werden. Dieses Guthaben wird bei künftigen Zahlungen vor Ihrem Guthaben aus dem Startup Program verwendet.
- **Vorbereitung**: Bevor Sie eine Quota-Erhöhung anfordern, müssen Sie Ihrem Kunden-Account ein gültiges Zahlungsmittel hinzufügen und sicherstellen, dass Ihr Account als Unternehmen registriert ist.

## Voraussetzungen

- Sie sind Mitglied des [Startup Program](/links/transversal/startup-program).
- Sie haben in Ihrem OVHcloud Kunden-Account ein gültiges Zahlungsmittel hinterlegt. Lesen Sie [diese Anleitung](/guides/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods), um ein gültiges Zahlungsmittel hinzuzufügen.
- Sie haben Ihren Account mit dem Status `Unternehmen` registriert. Lesen Sie [diese Anleitung](/guides/account-and-service-management/account-information/all-about-username), um Ihre Angaben zu aktualisieren.

## In der praktischen Anwendung

Mit diesem Verfahren können Sie manuell eine Quota-Erhöhung anfordern und diese durch eine erste Zahlung (Public Cloud Guthaben) bestätigen.

### Schritt 1 - Ein Support-Ticket zur Anforderung einer Quota-Erhöhung erstellen

Wenn Sie die oben genannten Voraussetzungen erfüllt haben, erstellen Sie ein Support-Ticket, indem Sie die folgenden Schritte ausführen:

Wählen Sie in der <ManagerLink console to="/#/public-cloud/project">OVHcloud Konsole</ManagerLink> Ihr Public Cloud Projekt in der Projektauswahl oben im linken Menü aus. Klicken Sie im linken Menü auf <code className="action">Projektverwaltung</code>, dann auf den Tab <code className="action">Quotas</code> und anschließend auf <code className="action">Support kontaktieren</code>.

<img className="thumbnail" alt="Tab Quotas der Seite Projektverwaltung mit dem Link Support kontaktieren" src="/images/account-and-service-management/startup-program/07-increase-quota/console/quotas-tab.png" loading="lazy" style={{ maxWidth: '800px' }} />

Das Fenster **Kontingenterhöhung beim Support anfragen** wird geöffnet. Ihre Anfrage kann nur bewilligt werden, wenn Sie alle vier Fragen beantworten:

- der Zweck Ihres Projekts;
- das Volumen, das Sie für die kommenden Monate benötigen (Anzahl der Prozessoren, RAM, Instanzen usw.);
- ob Sie bereits versucht haben, die Quota über die OVHcloud Konsole zu erhöhen;
- die Website Ihres Unternehmens oder eine öffentliche URL, unter der Informationen über Sie oder Ihr Unternehmen zu finden sind.

Begründen Sie in Ihrer Antwort zum Zweck Ihres Projekts Ihre Anfrage zur Quota-Erhöhung: Geben Sie an, dass Sie am OVHcloud Startup Program teilnehmen, und nennen Sie den Namen des Startup Program Managers, der Ihre Teilnahme betreut (siehe [Liste der Startup Program Manager](/links/transversal/startup-program-faq-managers)). Beschreiben Sie in Ihrer Antwort zum benötigten Volumen Ihren technischen Bedarf im Detail.

<img className="thumbnail" alt="Fenster Kontingenterhöhung beim Support anfragen mit den vier Fragen und dem Button Absenden" src="/images/account-and-service-management/startup-program/07-increase-quota/console/quota-support-dialog.png" loading="lazy" style={{ maxWidth: '800px' }} />

Klicken Sie auf <code className="action">Absenden</code>, um Ihre Anfrage zu übermitteln. Sie wird als Support-Ticket registriert: Erstellen Sie nur ein Ticket pro Anfrage.

### Schritt 2 - Ihren Startup Program Manager kontaktieren

Nachdem Sie Ihre Anfrage zur Quota-Erhöhung übermittelt haben, empfehlen wir Ihnen, sich an den Startup Program Manager Ihrer Region zu wenden, damit Ihr Ticket nachverfolgt wird und Sie schnell Unterstützung erhalten.

Die Liste der Startup Program Manager finden Sie [hier](/links/transversal/startup-program-faq-managers).

## Fazit

Eine Quota-Erhöhung kann notwendig sein, um Ihre Cloud-Ressourcen an Ihren wachsenden Bedarf anzupassen. Es ist jedoch wichtig, die Zahlungsbedingungen und die Reihenfolge zu verstehen, in der das Guthaben verwendet wird, um unerwartete Belastungen Ihrer eigenen Mittel zu vermeiden. Im Zweifelsfall wenden Sie sich an Ihren Startup Program Manager, der Sie durch jeden Schritt des Vorgangs begleitet.
