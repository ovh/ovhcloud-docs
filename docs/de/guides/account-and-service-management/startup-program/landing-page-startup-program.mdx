## OVHcloud Startup Program

Das [OVHcloud Startup Program](/links/transversal/startup-program) unterstützt Startups beim Aufbau und bei der Skalierung ihrer Server-Infrastruktur bei OVHcloud. Sobald Ihre Bewerbung angenommen und Ihr Vertrag unterzeichnet ist, erhalten Sie kostenlose Credits mit einer Gültigkeit von 12 Monaten, und unsere Startup Program Manager begleiten Sie während des gesamten Programms.

Als Mitglied des Startup Program können Sie:

- Berechtigte Produkte wie Public Cloud und Hosted Private Cloud mit Ihren Credits bezahlen
- Technische Beratungen anfordern, um Ihre Infrastruktur zu prüfen und weiterzuentwickeln
- Jederzeit einen Startup Program Manager um Rat fragen
- Unsere Teams auf Startup-Events treffen
