## Ziel

Sie können Ihre **Managed Hosting for WordPress** Lösung in natürlicher Sprache über einen KI-Agenten (Claude Code, Codex usw.) verwalten, und zwar über das Protokoll **MCP** (*Model Context Protocol*). Sie verbinden selbst nur einen einzigen Server, den **OVHcloud MCP**. Ihr KI-Agent nutzt ihn anschließend, um die beiden anderen einzurichten: **MCP for WordPress** für die Inhalte einer Website und **MainWP**, um mehrere Websites gleichzeitig zu verwalten.

**Erfahren Sie, wie Sie Ihren KI-Agenten mit dem OVHcloud MCP verbinden und ihn anschließend MCP for WordPress und MainWP einrichten lassen.**

## Voraussetzungen

- Sie verfügen über eine aktive [Managed Hosting for WordPress](/guides/web-cloud/managed-hosting/wordpress) Lösung mit mindestens einer WordPress-Website.
- Sie verfügen über einen OVHcloud Account mit Zugriff auf diese Lösung.
- Sie verwenden einen MCP-kompatiblen KI-Agenten, der **auf Ihrem Computer installiert** ist und Befehle ausführen kann, zum Beispiel [Claude Code](https://code.claude.com/docs/de/overview) oder [Codex](https://learn.chatgpt.com/docs/codex/cli).
- Für MainWP: Sie haben [Node.js](https://nodejs.org/en) (LTS-Version) auf Ihrem Computer installiert.

:::info
Ein KI-Assistent, den Sie in einem Webbrowser verwenden, kann sich mit dem OVHcloud MCP verbinden, aber nicht mit MCP for WordPress oder MainWP: Diese beiden Verbindungen werden in der Konfiguration des Agenten auf Ihrem Computer gespeichert.
:::

## Einführung

Drei MCP-Server decken jeweils einen Teil Ihrer Lösung ab:

| MCP-Server | Was Ihr KI-Agent verwalten kann | Wie Sie ihn verbinden |
|---|---|---|
| **OVHcloud MCP** | Das Hosting: Lösungen, Websites, Domains, PHP-Versionen, CDN-Cache, Logs, Backups, SFTP-Passwörter, phpMyAdmin und Datenbank | Sie fügen ihn einmal hinzu und melden sich dann mit Ihrem OVHcloud Account an |
| **MCP for WordPress** | Eine WordPress-Website: Beiträge, Seiten, Medien, Kommentare, Menüs, Einstellungen, Plugins, Themes und Benutzer | Ihr KI-Agent richtet ihn ein, eine Verbindung pro Website |
| **MainWP** | Mehrere Websites gleichzeitig über das in Ihrer Lösung enthaltene MainWP-Dashboard: Updates, Aktivierung und Deaktivierung von Plugins, Themes und Übersetzungen | Ihr KI-Agent richtet ihn ein, eine Verbindung für die gesamte Lösung |

**MCP for WordPress** ist ein OVHcloud Plugin, das auf den Websites Ihrer Lösung vorinstalliert ist. Es stellt Ihrem KI-Agenten eine geschlossene Liste von Aktionen zur Verwaltung Ihrer WordPress-Website bereit.

## In der praktischen Anwendung

:::warning
Ihr KI-Agent handelt mit den Rechten, die Sie ihm gewähren: Ihr OVHcloud Account für den OVHcloud MCP, ein Administrator-Account für MCP for WordPress. Prüfen Sie jede vorgeschlagene Aktion, bevor Sie sie bestätigen, insbesondere Löschungen, Updates und Veröffentlichungen.
:::

### Schritt 1: Den OVHcloud MCP verbinden

Der OVHcloud MCP ist ein Remote-Server, der von OVHcloud gehostet wird. Sie übermitteln ihm kein Passwort: Ihr KI-Agent öffnet die OVHcloud Login-Seite in Ihrem Webbrowser, und Sie melden sich wie in Ihrem Kundencenter an.

Wählen Sie Ihren KI-Agenten in den folgenden Tabs aus.

<Tabs>
  <Tab label="Claude Code">
    Führen Sie in einem Terminal folgenden Befehl aus:

    ```bash
    claude mcp add --transport http --scope user ovhcloud https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    ```

    Starten Sie Claude Code, geben Sie `/mcp` ein, wählen Sie den Server **ovhcloud** und dann **Authenticate** aus. Melden Sie sich auf der sich öffnenden Seite mit Ihrem OVHcloud Account an.

    :::warning
    Fügen Sie diesem Befehl keine Option `--header` hinzu. Ein fester `Authorization`-Header verhindert die OVHcloud Anmeldung: Der Server wird als verbunden angezeigt, aber jede Anfrage schlägt anschließend mit einem 401-Fehler fehl.
    :::
  </Tab>
  <Tab label="Codex">
    Führen Sie in einem Terminal folgende Befehle aus:

    ```bash
    codex mcp add ovhcloud --url https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    codex mcp login ovhcloud
    ```

    Melden Sie sich auf der sich öffnenden Seite mit Ihrem OVHcloud Account an und starten Sie Codex dann neu.
  </Tab>
  <Tab label="Anderer KI-Agent">
    Fügen Sie in der Konfiguration Ihres KI-Agenten einen Remote-MCP-Server (Transport *streamable HTTP*) hinzu:

    - **URL**: `https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS`
    - **Authentifizierung**: OAuth, ohne Header oder Token.

    Starten Sie die Authentifizierung über Ihren KI-Agenten und melden Sie sich mit Ihrem OVHcloud Account an.
  </Tab>
</Tabs>

Um die Verbindung zu überprüfen, fragen Sie Ihren KI-Agenten:

> Liste meine Managed Hosting for WordPress Lösungen und ihre Websites auf.

Er antwortet mit Ihren Lösungen und den Adressen Ihrer Websites.

### Schritt 2: MCP for WordPress für eine Website einrichten lassen

Bitten Sie Ihren KI-Agenten unter Angabe der Adresse Ihrer Website:

> Richte MCP for WordPress für meine Website www.example.com ein

Wenn Sie keine Website angeben, schlägt er Ihnen die Liste der Websites Ihrer Lösung vor.

Die Einrichtung läuft dann wie folgt ab:

1. **Ihr KI-Agent bittet Sie um die Erlaubnis**, ein Anwendungspasswort auf der Website zu erstellen. Mit diesem Passwort kann er auf der Website als Administrator handeln, im Rahmen der Aktionen von MCP for WordPress. Um zuzustimmen, antworten Sie ausdrücklich:

    > Ja, erstelle das Anwendungspasswort

    Die Wiederholung Ihrer ursprünglichen Anfrage gilt nicht als Zustimmung: Ihr KI-Agent wartet auf diese Antwort, bevor er fortfährt.

2. **Ihr KI-Agent prüft, ob das Plugin MCP for WordPress auf der Website aktiv ist.** Ist es das nicht, teilt er Ihnen dies mit: Aktivieren Sie **MCP for WordPress** über das Menü <code className="action">Plugins</code> der WordPress-Administration Ihrer Website und wiederholen Sie dann Ihre Anfrage.
3. **Ihr KI-Agent erstellt das Anwendungspasswort** über den OVHcloud MCP und fügt die Verbindung der Website seiner Konfiguration hinzu. Bestätigen Sie den Befehl, den er ausführt.
4. **Laden Sie die MCP-Server neu**: Geben Sie in Claude Code `/mcp` ein und verbinden Sie sich erneut, oder starten Sie Claude Code neu; starten Sie Codex neu. Die Tools der Website erscheinen erst nach diesem Neuladen.

Um die Verbindung zu überprüfen, fragen Sie:

> Liste die 5 letzten Beiträge von www.example.com auf

Wiederholen Sie diesen Schritt für jede Website, die Sie verwalten möchten: Jede Website hat ihre eigene Verbindung.

### Schritt 3: MainWP einrichten lassen

Das in Ihrer Lösung enthaltene MainWP-Dashboard verwaltet alle Ihre Websites. Bitten Sie Ihren KI-Agenten:

> Richte den MainWP MCP ein

Die Einrichtung folgt demselben Ablauf wie in Schritt 2:

1. **Ihr KI-Agent bittet Sie um die Erlaubnis**, ein Anwendungspasswort auf dem MainWP-Dashboard zu erstellen. Um zuzustimmen, antworten Sie:

    > Ja, erstelle das Anwendungspasswort

2. **Ihr KI-Agent prüft, ob Node.js** auf Ihrem Computer installiert ist. Falls nicht, installieren Sie die LTS-Version von [nodejs.org](https://nodejs.org/en) und wiederholen Sie dann Ihre Anfrage.
3. **Ihr KI-Agent erstellt das Anwendungspasswort** über den OVHcloud MCP und fügt den MainWP-Server seiner Konfiguration hinzu. Bestätigen Sie den Befehl, den er ausführt.
4. **Laden Sie die MCP-Server neu**, wie in Schritt 2.

Um die Verbindung zu überprüfen, fragen Sie:

> Liste die Websites in meinem MainWP-Dashboard und die Plugins auf, die aktualisiert werden müssen.

:::info
Der MainWP-Server ist so konfiguriert, dass er Sie vor jeder Aktion, die Ihre Websites ändert, um Bestätigung bittet.
:::

### Beispielanfragen

Sobald die drei Server verbunden sind, formulieren Sie Ihre Anfragen wie gegenüber einem Kollegen. Ihr KI-Agent wählt den passenden Server.

| Sie möchten… | Beispielanfrage |
|---|---|
| Inhalte verfassen | "Schreibe einen Beitragsentwurf über unsere Sommeröffnungszeiten für www.example.com." |
| Kommentare moderieren | "Zeige die Kommentare an, die auf www.example.com auf Moderation warten." |
| Mehrere Websites aktualisieren | "Welche Plugins müssen auf allen meinen Websites aktualisiert werden?" |
| Einen Fehler analysieren | "Meine Website www.example.com gibt 500-Fehler zurück: Prüfe die Logs und sage mir, warum." |
| Den Cache leeren | "Leere den CDN-Cache von www.example.com." |
| Eine Website sichern | "Exportiere ein vollständiges Backup von www.example.com." |

Bevor Ihr KI-Agent einen Beitrag veröffentlicht, fragt er Sie, welcher WordPress-Account als Autor eingetragen werden soll.

### Zugriff widerrufen

Sie können den Ihrem KI-Agenten gewährten Zugriff jederzeit entziehen:

- **MCP for WordPress**: Öffnen Sie in der WordPress-Administration der Website <code className="action">Benutzer</code> > <code className="action">Profil</code> und löschen Sie das Anwendungspasswort im Bereich **Anwendungspasswörter**.
- **MainWP**: Gehen Sie in der WordPress-Administration des MainWP-Dashboards genauso vor.
- **OVHcloud MCP**: Entfernen Sie den Server aus der Konfiguration Ihres KI-Agenten, zum Beispiel mit `claude mcp remove ovhcloud` in Claude Code.

### Fehlerbehebung

- **Ihr KI-Agent meldet, dass er keine Verbindung zur Website oder zu MainWP herstellen kann**: Prüfen Sie, dass er auf Ihrem Computer und nicht in einem Webbrowser ausgeführt wird.
- **Die neuen Tools werden nicht angezeigt**: Laden Sie die MCP-Server neu (`/mcp` in Claude Code) oder starten Sie Ihren KI-Agenten neu.
- **Ihr KI-Agent bricht ab und meldet eine abgelehnte Aktion**: Er hat die Erstellung des Passworts oder die Ausführung des Befehls blockiert. Erlauben Sie diese Aktion in seinen Berechtigungseinstellungen oder nennen Sie sie ausdrücklich in Ihrer Anfrage, zum Beispiel "Erstelle ein Anwendungspasswort auf der Website www.example.com".
- **Anfragen an den OVHcloud MCP schlagen mit einem 401-Fehler fehl**: Entfernen Sie den Server, fügen Sie ihn ohne Header erneut hinzu und starten Sie die Authentifizierung neu.
