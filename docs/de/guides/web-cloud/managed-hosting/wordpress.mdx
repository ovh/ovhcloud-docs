## Ziel

**Managed Hosting for WordPress** ist ein neues OVHcloud-Angebot, mit dem Sie Ihre WordPress-Websites einfach hosten und verwalten können. Dieser Service richtet sich an Fachleute, Agenturen und Selbstständige und befreit Sie von den technischen Aufgaben der Infrastrukturverwaltung und der Aktualisierungen, sodass Sie sich auf Ihre Inhalte und Ihre Geschäftstätigkeit konzentrieren können. Diese Anleitung stellt das Produktkonzept, die wichtigsten Vorteile und die verfügbaren Funktionen vor.

## Voraussetzungen

- Sie verfügen über ein aktives [Managed Hosting for WordPress](/links/web/managed-hosting-wordpress)-Angebot.

## In der praktischen Anwendung

### Produktübersicht

#### 100% WordPress-Verwaltung durch OVHcloud

Mit Managed Hosting for WordPress **kümmert sich OVHcloud um alles**:

- Hosting, Infrastruktur, Cache und Sicherheit.
- Installation und Wartung von WordPress.
- Automatische Backups und Aktualisierungen.
- Überwachung von Performance und Verfügbarkeit.
- Vereinfachte Verwaltung von Domains, Plugins und Staging-Umgebungen.

Es sind keine Serverkenntnisse erforderlich: Alles ist **über die OVHcloud Konsole zugänglich**. So können Sie **Ihre WordPress-Websites in wenigen Klicks erstellen, importieren und verwalten**, ohne jemals FTP, eine Datenbank oder die Befehlszeile verwenden zu müssen.

#### Eine schlüsselfertige Lösung

Jede Website profitiert von einer optimierten, einsatzbereiten Umgebung:

- **Automatische WordPress-Installation** sofort nach der Bestellung.
- **Verwaltete Infrastruktur**: Wartung, Patches, Software-Updates und Sicherheit werden von OVHcloud übernommen.
- **Garantierte Performance**: integrierter WordPress-Cache, Hosting auf optimierter Infrastruktur und kontinuierliches Monitoring.
- **Integrierte Skalierbarkeit**: Überwachen Sie die Nutzung in Echtzeit anhand wichtiger Kennzahlen (Speicher, Traffic, Anzahl Websites) und passen Sie sich mühelos an Ihre wachsenden Anforderungen an.
- **Volle Kompatibilität**: Zugang über die OVHcloud Konsole, was die Integration in Ihre bestehenden Workflows ermöglicht.

### Funktionen

#### Eine Website erstellen

Um eine Website zu erstellen, klicken Sie auf den Button <code className="action">Website erstellen</code> oberhalb der Tabelle im Tab <code className="action">Meine Sites</code>. Rechts auf dem Bildschirm öffnet sich der Bereich **Website erstellen**:

<img className="thumbnail" alt="Bereich Website erstellen rechts neben dem Tab Meine Sites geöffnet" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/console/managed_wordpress_create_site.png" loading="lazy" />

Füllen Sie die Formularfelder aus, um die Anmeldedaten für Ihre WordPress-Website festzulegen:

- **E-Mail-Adresse**: Geben Sie die E-Mail-Adresse des Administrators der WordPress-Website ein. Dieses Feld ist mit der E-Mail-Adresse Ihres OVHcloud Kunden-Accounts vorausgefüllt.
- **Passwort**: Legen Sie das Passwort für dieses Administratorkonto fest. Es muss mindestens 8 Zeichen enthalten, darunter Großbuchstaben, Ziffern und Sonderzeichen.
- **Passwort bestätigen**: Geben Sie dieses Passwort erneut ein.
- **PHP-Version**: Wählen Sie die gewünschte PHP-Version für Ihre WordPress-Umgebung aus. Die verfügbaren PHP-Versionen finden Sie auf [dieser Seite](/guides/web-cloud/web-hosting/web-hosting-main-info).
- **Sprache**: Wählen Sie die Standardsprache der Administrationsoberfläche aus.

Die Felder **E-Mail-Adresse**, **Passwort** und **Passwort bestätigen** sind Pflichtfelder: Der Button <code className="action">Website erstellen</code> bleibt inaktiv, solange sie nicht korrekt ausgefüllt sind. Klicken Sie anschließend auf <code className="action">Website erstellen</code>, um die Angaben zu bestätigen.

Sie bleiben im Tab <code className="action">Meine Sites</code> und eine Meldung bestätigt die Erstellung Ihrer Website.

In der Tabelle erscheint eine neue Zeile für Ihre neue Website:

- Spalte **Website-Name**: zeigt den Hauptdomainnamen Ihrer Website an oder, solange ihr kein Domainname zugeordnet ist, ihre technische URL. Diese technische URL dient als Staging-URL (Vorproduktion): Sie können damit auf Ihre Website zugreifen, bevor Sie sie mit Ihrem eigenen Domainnamen verknüpfen.
- Spalte **Status**: gibt den Fortschritt der Website-Erstellung an. Der Status wird zunächst als **Erstellung...** angezeigt, während die Infrastruktur bereitgestellt und WordPress installiert wird. Sobald Ihre Website betriebsbereit ist, wechselt der Status zu **Aktiv**. Ihr WordPress ist dann über seine technische URL online verfügbar.

<img className="thumbnail" alt="Tab Meine Sites mit der Tabelle der WordPress-Websites und ihrem Status" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/managed-hosting-for-wordpress-my-sites-tab.png" loading="lazy" />

Sie können den Fortschritt der Website-Erstellung auch verfolgen, indem Sie auf den Tab <code className="action">Vorgänge</code> klicken. Die Tabelle in diesem Tab zeigt den Status und den Fortschritt jedes laufenden oder abgeschlossenen Vorgangs an.

<img className="thumbnail" alt="Tab Vorgänge mit der Tabelle der Vorgänge einer Managed WordPress Ressource" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/console/managed_wordpress_task_new_line.png" loading="lazy" />

#### Eine Website importieren

Sie können eine bestehende WordPress-Website in Managed Hosting for WordPress importieren. Der Import kann automatisch Folgendes übertragen:

- WordPress-Inhalte (Plugins, Themes, Medien, Artikel, Seiten, Benutzer).
- Dateien.
- Datenbank.

Um eine WordPress-Website zu importieren, klicken Sie auf den Button <code className="action">Website importieren</code> oberhalb der Tabelle im Tab <code className="action">Meine Sites</code>.

Zunächst wird ein Fenster mit dem Titel **Deaktivieren Sie Ihren Bot-Schutz** angezeigt. Um Verbindungsfehler zu vermeiden, werden Sie aufgefordert, die Bot-Schutzmaßnahmen Ihrer Quell-Website vorübergehend zu deaktivieren: Sicherheits-Plugins, Captchas, Netzwerk-Firewalls oder Sperren wie Cloudflare. Sie können sie nach Abschluss des Imports wieder aktivieren. Klicken Sie nach dem Deaktivieren dieser Schutzmaßnahmen auf <code className="action">Bestätigen</code>. Rechts auf dem Bildschirm öffnet sich der Bereich **Website importieren**:

<img className="thumbnail" alt="Bereich Website importieren rechts neben dem Tab Meine Sites geöffnet" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/console/managed_wordpress_import_site.png" loading="lazy" />

:::info
Eine Informationsmeldung oben im Bereich weist Sie darauf hin, dass der Vorgang je nach Komplexität Ihrer Website bis zu 48 Stunden dauern kann. Bei Bedarf greifen unsere technischen Teams ein, um den Import abzuschließen.

:::

Füllen Sie die Formularfelder aus, die alle Pflichtfelder sind:

- **Admin-URL**: Geben Sie die Adresse ein, über die Sie sich bei der Administrationsoberfläche Ihrer aktuellen WordPress-Website anmelden, zum Beispiel `https://www.domain.tld/wp-admin`.
- **Administrator-Benutzername**: Geben Sie den Benutzernamen oder die E-Mail-Adresse eines WordPress-Administratorkontos Ihrer aktuellen Website ein.
- **Administrator-Passwort**: Geben Sie das Passwort dieses WordPress-Administratorkontos ein.

Mit diesen Angaben kann das System auf Ihre bestehende Website zugreifen, um die Dateien, die Datenbank und die erforderliche Konfiguration automatisch zu extrahieren.

Der Button <code className="action">Fortfahren</code> bleibt inaktiv, solange die Pflichtfelder nicht ausgefüllt sind. Sobald sie ausgefüllt sind, klicken Sie auf <code className="action">Fortfahren</code>, um den Importvorgang zu starten.

Anschließend können Sie die zu importierenden Elemente auswählen, einschließlich Plugins, Themes, Medien und Datenbanken.

:::warning
Um eine perfekte Datenkonsistenz zu gewährleisten, nehmen Sie bitte keine Änderungen an Ihrer Website vor, bis der Import abgeschlossen ist.

Bitte ergreifen Sie die erforderlichen Maßnahmen, um Datenabweichungen während des Imports zu vermeiden.

:::

Sobald alle Elemente ausgewählt sind, klicken Sie auf <code className="action">Import starten</code>.

#### Eine Website löschen

:::danger
Das Löschen einer Website ist endgültig und führt zum Löschen aller Inhalte der Website.
Bitte sichern Sie Ihre Daten, bevor Sie etwas löschen.

:::

##### Eine einzelne Website löschen

Um eine Website zu löschen, navigieren Sie zum Tab <code className="action">Meine Sites</code> und identifizieren Sie die Zeile in der Tabelle, die Ihrer Website entspricht. Klicken Sie in der Spalte **Aktionen** rechts neben dieser Website auf den Button <code className="action">⋮</code> und dann auf <code className="action">Website löschen</code>.

<img className="thumbnail" alt="Menü des Buttons ⋮ einer Website mit dem Eintrag Website löschen an letzter Stelle" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/adding-domain.png" loading="lazy" />

Ein Fenster mit dem Titel **Website löschen** wird angezeigt. Es weist Sie darauf hin, dass diese Aktion unwiderruflich ist: Alle Daten der Website werden dauerhaft gelöscht. Klicken Sie auf <code className="action">Löschen</code>, um das Löschen Ihrer Website zu bestätigen.

Sie bleiben im Tab <code className="action">Meine Sites</code> und eine Meldung bestätigt das Löschen Ihrer Website.

Sobald Ihre Website endgültig gelöscht ist, verschwindet die zugehörige Zeile in der Tabelle.

##### Mehrere Websites gleichzeitig löschen

Um mehrere Websites gleichzeitig zu löschen, navigieren Sie zum Tab <code className="action">Meine Sites</code>. Identifizieren Sie die Zeilen in der Tabelle, die den zu löschenden Websites entsprechen, und aktivieren Sie die Kontrollkästchen auf der linken Seite. Der Button <code className="action">Aktionen</code> oberhalb der Tabelle zeigt dann die Anzahl der ausgewählten Websites an. Klicken Sie auf diesen Button und dann auf <code className="action">Löschen</code>.

<img className="thumbnail" alt="Tab Meine Sites mit zwei ausgewählten Websites und dem geöffneten Menü Aktionen beim Eintrag Löschen" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/console/managed_wordpress_delete_several_sites.png" loading="lazy" />

Ein Fenster mit dem Titel **X Websites löschen** wird angezeigt, wobei X der Anzahl der ausgewählten Websites entspricht. Es weist Sie darauf hin, dass diese Aktion unwiderruflich ist und diese Websites dauerhaft gelöscht werden. Klicken Sie auf <code className="action">X Websites löschen</code>, um das Löschen Ihrer Websites zu bestätigen.

Sie bleiben im Tab <code className="action">Meine Sites</code> und eine Meldung bestätigt das Löschen Ihrer Websites. Schlägt das Löschen einer oder mehrerer Websites fehl, gibt diese Meldung die Anzahl der gelöschten Websites und die Anzahl der Fehler an.

Sobald Ihre Websites endgültig gelöscht sind, verschwinden die zugehörigen Zeilen in der Tabelle.

#### Ihre Websites verwalten

Um alle Ihre Websites zu verwalten, navigieren Sie zum Tab <code className="action">Meine Sites</code>, klicken Sie oberhalb der Tabelle auf den Button <code className="action">Verwalten</code> und dann auf <code className="action">Meine Websites verwalten</code>. Dieser Eintrag öffnet in einem neuen Tab Ihres Browsers den in Managed Hosting for WordPress integrierten Flottenmanager. In diesem Bereich können Sie mehrere WordPress-Websites gleichzeitig über eine einheitliche Oberfläche verwalten.

Der Eintrag <code className="action">Meine Websites verwalten</code> erscheint auch ganz oben im Menü des Buttons <code className="action">Aktionen</code>.

##### Dashboard

Der Flottenmanager ist ein zentralisiertes Überwachungs- und Verwaltungstool, das automatisch mit Ihrem Angebot bereitgestellt wird. Es ermöglicht Ihnen, Ihre verwalteten WordPress-Websites zu administrieren, ohne sich bei jeder Website einzeln anmelden zu müssen.

Über dieses Dashboard können Sie insbesondere:

- den Gesamtstatus all Ihrer Websites einsehen: verfügbare Aktualisierungen, Warnungen, Performance, Sicherheit.
- WordPress-Aktualisierungen (Plugins, Themes usw.) zentral verwalten.
- schnell auf jede Website zugreifen, um deren Status zu prüfen oder einzugreifen.
- die letzten Aktivitäten überwachen (Änderungen, Aktualisierungen, Synchronisationen).
- die integrierten Funktionen für Sicherheit, Monitoring, Backups und Analyse nutzen (in zukünftigen Phasen).

#### Intelligente automatische Aktualisierungen

Automatische Aktualisierungen können Kompatibilitätsprobleme verursachen, die sich auf die Stabilität, die Performance und das Nutzererlebnis der Website auswirken. Bei der Verwaltung mehrerer WordPress-Websites erhöht die manuelle Verwaltung der Aktualisierungen den operativen Aufwand und das Risiko einer Dienstunterbrechung für die Endbenutzer.

Managed Hosting for WordPress mindert diese Risiken durch einen kontrollierten Aktualisierungsprozess:

- **Tests vor der Bereitstellung**
    Alle Aktualisierungen – einschließlich des WordPress-Kerns, der Plugins und der Themes – werden zunächst auf eine geklonte Umgebung Ihrer Website angewendet.
- **Validierungsprüfungen**
    Die geklonte Website wird hinsichtlich Performance, Funktionalität und Nutzererlebnis bewertet, um Regressionen oder Fehler vor der Bereitstellung zu erkennen.
- **Automatisierter Entscheidungsprozess**
    - Wenn keine Probleme erkannt werden, wird die Aktualisierung automatisch auf der Live-Website bereitgestellt.
    - Wenn Probleme erkannt werden, bleibt die Live-Website unverändert. Sie werden über das Dashboard benachrichtigt und erhalten eine E-Mail, die die erkannten Probleme sowie die empfohlenen Korrekturmaßnahmen beschreibt.

Dieser Ansatz stellt sicher, dass Aktualisierungen sicher angewendet werden, während die Zuverlässigkeit der Website erhalten bleibt und die Auswirkungen auf die Endbenutzer minimiert werden.
