## Ziel

**Managed Hosting for WordPress** ist ein neues OVHcloud-Angebot, mit dem Sie Ihre WordPress-Websites einfach hosten und verwalten können. Dieser Service richtet sich an Fachleute, Agenturen und Selbstständige und befreit Sie von den technischen Aufgaben der Infrastrukturverwaltung und der Aktualisierungen, sodass Sie sich auf Ihre Inhalte und Ihre Geschäftstätigkeit konzentrieren können. Diese Anleitung stellt das Produktkonzept, die wichtigsten Vorteile und die verfügbaren Funktionen vor.

## Voraussetzungen

- Sie haben Zugang zum Programm [OVHcloud Labs](https://labs.ovhcloud.com/en/managed-wp/).
- Sie haben Zugriff auf das <ManagerLink to="/">OVHcloud Kundencenter</ManagerLink>.

## In der praktischen Anwendung

### Produktübersicht

#### 100% WordPress-Verwaltung durch OVHcloud

Mit Managed Hosting for WordPress **kümmert sich OVHcloud um alles**:

- Hosting, Infrastruktur, Cache und Sicherheit.
- Installation und Wartung von WordPress.
- Automatische Backups und Aktualisierungen.
- Überwachung von Performance und Verfügbarkeit.
- Vereinfachte Verwaltung von Domains, Plugins und Staging-Umgebungen.

Es sind keine Serverkenntnisse erforderlich: Alles ist **über das OVHcloud Kundencenter zugänglich**. So können Sie **Ihre WordPress-Websites in wenigen Klicks erstellen, importieren und verwalten**, ohne jemals FTP, eine Datenbank oder die Befehlszeile verwenden zu müssen.

#### Eine schlüsselfertige Lösung

Jede Website profitiert von einer optimierten, einsatzbereiten Umgebung:

- **Automatische WordPress-Installation** sofort nach der Bestellung.
- **Verwaltete Infrastruktur**: Wartung, Patches, Software-Updates und Sicherheit werden von OVHcloud übernommen.
- **Garantierte Performance**: integrierter WordPress-Cache, Hosting auf optimierter Infrastruktur und kontinuierliches Monitoring.
- **Integrierte Skalierbarkeit**: Überwachen Sie die Nutzung in Echtzeit anhand wichtiger Kennzahlen (Speicher, Traffic, Anzahl Websites) und passen Sie sich mühelos an Ihre wachsenden Anforderungen an.
- **Volle Kompatibilität**: Zugang über das OVHcloud Kundencenter, was die Integration in Ihre bestehenden Workflows ermöglicht.

### Funktionen

Melden Sie sich im <ManagerLink to="/">OVHcloud Kundencenter</ManagerLink> an, navigieren Sie zum Bereich <code className="action">Web Cloud</code> und klicken Sie auf <code className="action">Managed Hosting for WordPress</code>.

#### Eine Website erstellen

Um eine Website zu erstellen, klicken Sie auf die Schaltfläche <code className="action">Website erstellen</code>. Die folgende Seite wird angezeigt:

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_create_site.png" loading="lazy" />

Füllen Sie die Formularfelder aus, um die Anmeldedaten für Ihre WordPress-Website festzulegen:

- <code className="action">WordPress-Administrationssprache</code>: Wählen Sie die Standardsprache der Administrationsoberfläche aus.
- <code className="action">PHP-Version</code>: Wählen Sie die gewünschte PHP-Version für Ihre WordPress-Umgebung. Verfügbare PHP-Versionen finden Sie auf [dieser Seite](/guides/web-cloud/web-hosting/web-hosting-main-info).
- <code className="action">Admin-E-Mail</code>: Geben Sie die E-Mail-Adresse des Administrators der WordPress-Website ein.
- <code className="action">Admin-Passwort</code>: Legen Sie das mit diesem Administratorkonto verknüpfte Passwort fest.

Klicken Sie auf <code className="action">Weiter</code>, um die Informationen zu bestätigen.

Sie werden zum Tab <code className="action">Meine Sites</code> weitergeleitet. Oben am Bildschirm wird eine Bestätigungsmeldung angezeigt, die darauf hinweist, dass Ihre Anfrage zur Website-Erstellung verarbeitet wurde.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_banner_creation_site.png" loading="lazy" />

In der Tabelle erscheint eine neue Zeile für Ihre neue Website:

- Spalte <code className="action">Domain-Name</code>: entspricht dem technischen Domain-Namen Ihrer Website. Er dient als Staging-URL (Vorproduktion) und ermöglicht den Zugriff auf Ihre Website, bevor Sie sie mit Ihrem eigenen Domain-Namen verknüpfen.
- Spalte <code className="action">Status</code>: gibt den Fortschritt der Website-Erstellung an. Der Status erscheint zunächst als <code className="action">In Bearbeitung</code>, während die Infrastruktur bereitgestellt und WordPress installiert wird. Sobald Ihre Website betriebsbereit ist, wechselt der Status zu <code className="action">Aktiviert</code>, was bedeutet, dass Ihre WordPress-Website jetzt über ihren technischen Domain-Namen online verfügbar ist.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_tab_new_line.png" loading="lazy" />

Sie können den Fortschritt der Website-Erstellung auch verfolgen, indem Sie auf den Tab <code className="action">Aufgaben</code> klicken.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_task_new_line.png" loading="lazy" />

#### Eine Website importieren

Sie können eine bestehende WordPress-Website in Managed Hosting for WordPress importieren. Der Import kann automatisch Folgendes übertragen:

- WordPress-Inhalte (Plugins, Themes, Medien, Artikel, Seiten, Benutzer).
- Dateien.
- Datenbank.

Um eine WordPress-Website zu importieren, klicken Sie auf die Schaltfläche <code className="action">Website importieren</code>. Der folgende Bildschirm wird angezeigt:

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_import_site.png" loading="lazy" />

:::info
Eine Informationsmeldung weist Sie darauf hin, dass Ihre Website in einer Umgebung mit einer stabilen PHP-Version (PHP 8.4 in unserem Beispiel) und der neuesten Version von WordPress installiert wird.

:::


Füllen Sie die Formularfelder aus:

- <code className="action">URL der Website-Administration</code>: Geben Sie die Adresse ein, die für den Zugriff auf die Administrationsoberfläche Ihrer aktuellen WordPress-Website verwendet wird, zum Beispiel `https://www.meinewebsite.de/wp-admin`.
- <code className="action">Admin-Konto</code>: Geben Sie den WordPress-Administrator-Benutzernamen ein.
- <code className="action">Admin-Passwort</code>: Geben Sie das Passwort des WordPress-Administrator-Benutzers ein.

Mit diesen Angaben kann das System auf Ihre bestehende Website zugreifen, um die Dateien, die Datenbank und die erforderliche Konfiguration automatisch zu extrahieren.

Sobald die Pflichtfelder ausgefüllt sind, klicken Sie auf <code className="action">Weiter</code>, um den Import-Prozess zu starten.

Anschließend können Sie die zu importierenden Elemente auswählen, einschließlich Plugins, Themes, Medien und Datenbanken.

:::warning
Um eine perfekte Datenkonsistenz zu gewährleisten, nehmen Sie bitte keine Änderungen an Ihrer Website vor, bis der Import abgeschlossen ist.

Wir empfehlen, den Wartungsmodus auf der zu importierenden Website zu aktivieren oder die erforderlichen Maßnahmen zu ergreifen, um während des Imports Datenabweichungen zu vermeiden.

:::


Sobald alle Elemente ausgewählt sind, klicken Sie auf <code className="action">Import starten</code>.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_import_site_selection.png" loading="lazy" />

:::danger
Das Löschen einer Website ist endgültig und führt zum Löschen aller Inhalte der Website.

Eine Bestätigungsmeldung wird angezeigt. Klicken Sie auf <code className="action">Löschen</code>, um das Löschen Ihrer Website zu bestätigen.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_delete_site_confirmation.png" loading="lazy" />

Sie werden zum Tab <code className="action">Meine Sites</code> weitergeleitet. Oben am Bildschirm wird eine Bestätigungsmeldung angezeigt, die darauf hinweist, dass der Löschvorgang Ihrer Website läuft.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_delete_site_banner_validation.png" loading="lazy" />

#### Ihre Websites verwalten

Um alle Ihre Websites zu verwalten, navigieren Sie zum Tab <code className="action">Meine Sites</code> und klicken Sie auf <code className="action">Websites verwalten</code>. Diese Schaltfläche öffnet automatisch den Flottenmanager, der in Managed Hosting for WordPress integriert ist. Dieser Bereich ermöglicht es Ihnen, mehrere WordPress-Websites gleichzeitig über eine einheitliche Oberfläche zu verwalten.

##### Dashboard

Der Flottenmanager ist ein zentralisiertes Überwachungs- und Verwaltungstool, das automatisch mit Ihrem Angebot bereitgestellt wird. Es ermöglicht Ihnen, Ihre verwalteten WordPress-Websites zu administrieren, ohne sich bei jeder Website einzeln anmelden zu müssen.

Über dieses Dashboard können Sie insbesondere:

- den Gesamtstatus all Ihrer Websites einsehen: verfügbare Aktualisierungen, Warnungen, Performance, Sicherheit.
- WordPress-Aktualisierungen (Plugins, Themes usw.) zentral verwalten.
- schnell auf jede Website zugreifen, um deren Status zu prüfen oder einzugreifen.
- die letzten Aktivitäten überwachen (Änderungen, Aktualisierungen, Synchronisationen).
- die integrierten Funktionen für Sicherheit, Monitoring, Backups und Analyse nutzen (in zukünftigen Phasen).

#### Intelligente automatische Aktualisierungen

Automatische Aktualisierungen können Kompatibilitätsprobleme verursachen, die sich auf die Stabilität, die Performance und das Nutzererlebnis der Website auswirken. Bei der Verwaltung mehrerer WordPress-Websites erhöht die manuelle Verwaltung der Aktualisierungen den operativen Aufwand und das Risiko einer Dienstunterbrechung für die Endbenutzer.

Managed Hosting for WordPress mindert diese Risiken durch einen kontrollierten Aktualisierungsprozess:

- **Tests vor der Bereitstellung**
    Alle Aktualisierungen – einschließlich des WordPress-Kerns, der Plugins und der Themes – werden zunächst auf eine geklonte Umgebung Ihrer Website angewendet.
- **Validierungsprüfungen**
    Die geklonte Website wird hinsichtlich Performance, Funktionalität und Nutzererlebnis bewertet, um Regressionen oder Fehler vor der Bereitstellung zu erkennen.
- **Automatisierter Entscheidungsprozess**
    - Wenn keine Probleme erkannt werden, wird die Aktualisierung automatisch auf der Live-Website bereitgestellt.
    - Wenn Probleme erkannt werden, bleibt die Live-Website unverändert. Sie werden über das Dashboard benachrichtigt und erhalten eine E-Mail, die die erkannten Probleme sowie die empfohlenen Korrekturmaßnahmen beschreibt.

Dieser Ansatz stellt sicher, dass Aktualisierungen sicher angewendet werden, während die Zuverlässigkeit der Website erhalten bleibt und die Auswirkungen auf die Endbenutzer minimiert werden.
