## Ziel

**Managed Hosting for WordPress** ist die Managed-WordPress-Hosting-Lösung von OVHcloud: Die technische Wartung (Updates, Sicherheit, Backups) wird automatisch übernommen. Das Angebot ermöglicht es, Domainnamen über die OVHcloud-Oberfläche zu verwalten, ohne manuellen Eingriff. Sie können jedem Ihrer WordPress-Websites einen Domainnamen oder eine Subdomain zuordnen, unabhängig von deren Ursprung.

Je nach Situation stehen zwei Vorgehensweisen zur Verfügung:

- **Interner Domainname**: Der Domainname befindet sich bereits in Ihrem OVHcloud-Konto.
- **Externer Domainname**: Der Domainname wird bei einem anderen Registrar verwaltet.

**Erfahren Sie, wie Sie die Domainnamen Ihres Managed Hosting for WordPress über die OVHcloud Konsole hinzufügen, ändern oder entfernen.**

## Voraussetzungen

- Sie verfügen über ein aktives **Managed Hosting for WordPress**-Angebot mit mindestens einer angelegten WordPress-Website.
- Für einen externen Domainnamen: Sie haben Zugriff auf die aktive DNS-Zone (Domain Name System) bei Ihrem aktuellen Anbieter.

## In der praktischen Anwendung

### 1 - Zur Verwaltung der Domainnamen wechseln

Das Hinzufügen eines Domainnamens erfolgt über den Tab <code className="action">Meine Sites</code> Ihrer Managed Hosting for WordPress-Ressource. Klicken Sie auf die untenstehenden Tabs, um nacheinander jeden der **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Rufen Sie die Seite <ManagerLink to="/beta/#/web-cloud/wordpress">Managed WordPress</ManagerLink> in der OVHcloud Konsole auf. Ihre Ressourcen werden dort als Rahmen angezeigt.

    <img className="thumbnail" alt="Seite Managed WordPress der OVHcloud Konsole mit den als Rahmen angezeigten Ressourcen" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/managed-hosting-for-wordpress.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie im Rahmen der betreffenden Ressource rechts neben **Weitere Aktionen** auf den Button <code className="action">⋮</code> und dann auf <code className="action">Verwalten</code>. Hat die Ressource den Status **Zu verlängern** oder **Gekündigt**, klicken Sie direkt auf den Link <code className="action">Verwalten</code> unten in ihrem Rahmen.

    <img className="thumbnail" alt="Rahmen einer Managed WordPress Ressource mit dem geöffneten Menü des Buttons ⋮ und dem Eintrag Verwalten" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/manage-ressource-button.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie auf den Tab <code className="action">Meine Sites</code>. Die Tabelle listet Ihre WordPress-Websites auf: Die Spalte **Website-Name** zeigt den primären Domainnamen jeder Website an (oder ihre technische URL, wenn ihr kein Domainname zugeordnet ist), die Spalte **Verknüpfte Domains** gibt die Anzahl der der Website zugeordneten Domainnamen an und die Spalte **Aktionen** bietet Zugriff auf die verfügbaren Aktionen.

    <img className="thumbnail" alt="Tab Meine Sites mit der Tabelle der WordPress-Websites" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/managed-hosting-for-wordpress-my-sites-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Klicken Sie in der Spalte **Aktionen** rechts neben der betreffenden WordPress-Website auf den Button <code className="action">⋮</code> und dann auf <code className="action">Domainnamen hinzufügen</code>. Rechts öffnet sich ein Bereich mit dem Titel **Domainnamen hinzufügen**.

    <img className="thumbnail" alt="Menü des Buttons ⋮ einer WordPress-Website im Tab Meine Sites mit dem Eintrag Domainnamen hinzufügen" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/adding-domain.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
Der **erste hinzugefügte Domainname** einer WordPress-Website wird automatisch zum **primären Domainnamen**. Sie können später weitere hinzufügen (Multi-Domain) und den primären Domainnamen über den Eintrag <code className="action">Meine Domains verwalten</code> desselben Menüs ändern.
:::

### 2 - Einen Domainnamen hinzufügen

**Klicken Sie auf eine der untenstehenden Situationen, um den Inhalt anzuzeigen.**

<details>

<summary>Einen internen Domainnamen hinzufügen</summary>

Ein **interner** Domainname ist ein Domainname, der sich bereits in Ihrem OVHcloud-Konto befindet (registriert oder übertragen).

Sobald der Bereich **Domainnamen hinzufügen** geöffnet ist, wählen Sie die interne Zuordnung, um einen bereits in Ihrem OVHcloud Kunden-Account vorhandenen Domainnamen zu verwenden. Alle Schritte erfolgen in diesem Bereich, ohne Zwischenzusammenfassung. Klicken Sie auf die untenstehenden Tabs, um nacheinander jeden der **3** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Wählen Sie im Abschnitt **Domainkonfiguration** des Bereichs <code className="action">Bestehende OVHcloud-Domain zuordnen</code> aus (standardmäßig vorgeschlagene Option).

    <img className="thumbnail" alt="Bereich Domainnamen hinzufügen mit ausgewählter Option Bestehende OVHcloud-Domain zuordnen" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/attach-ovhcloud-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Wählen Sie im Dropdown-Menü **Domainname** den gewünschten Domainnamen unter den in Ihrem OVHcloud Kunden-Account verfügbaren Domainnamen aus.

    Um eine Subdomain zuzuordnen, aktivieren Sie anschließend das Kontrollkästchen <code className="action">Subdomain erstellen</code> und geben Sie das Präfix der Subdomain (zum Beispiel: `blog` für `blog.domain.tld`) in das angezeigte Feld ein.

    <img className="thumbnail" alt="Dropdown-Menü Domainname geöffnet mit den im Account verfügbaren OVHcloud Domainnamen" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/select-ovh-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie unten im Bereich auf den Button <code className="action">Domainnamen hinzufügen</code>. Dieser Button bleibt inaktiv, solange der ausgewählte Domainname der Website bereits zugeordnet ist. Eine Meldung bestätigt anschließend, dass Ihre Anfrage berücksichtigt wurde. Die DNS-Konfiguration wird automatisch durchgeführt.
  </Tab>
</Tabs>

:::info
Bei einem internen Domainnamen erfolgt die DNS-Propagation automatisch. Ihre Website ist innerhalb weniger Minuten bis weniger Stunden über diesen Domainnamen erreichbar.
:::

</details>

<details>

<summary>Einen externen Domainnamen hinzufügen</summary>

Ein **externer** Domainname wird bei einem anderen Registrar verwaltet (Gandi, Namecheap, Google Domains usw.). Sie müssen Ihre DNS-Zone manuell ändern.

Sobald der Bereich **Domainnamen hinzufügen** geöffnet ist, wählen Sie die externe Zuordnung, um einen bei einem anderen Registrar verwalteten Domainnamen zu verwenden. Die Eingabe des Domainnamens und seine Bestätigung erfolgen in diesem Bereich; die Anleitung zur DNS-Konfiguration wird Ihnen anschließend per E-Mail zugesandt. Klicken Sie auf die untenstehenden Tabs, um nacheinander jeden der **3** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Wählen Sie im Abschnitt **Domainkonfiguration** des Bereichs <code className="action">Externe Domain zuordnen</code> aus. Das Dropdown-Menü **Domainname** wird dann durch ein Eingabefeld ersetzt.

    <img className="thumbnail" alt="Bereich Domainnamen hinzufügen mit ausgewählter Option Externe Domain zuordnen" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/attach-external-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Geben Sie Ihren Domainnamen (zum Beispiel: `domain.tld`) in das Feld **Domainname** ein und klicken Sie dann unten im Bereich auf den Button <code className="action">Domainnamen hinzufügen</code>.

    <img className="thumbnail" alt="Feld Domainname mit einem externen Beispiel-Domainnamen ausgefüllt und aktiver Button Domainnamen hinzufügen" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/associate-external-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Eine Meldung bestätigt, dass Ihre Anfrage berücksichtigt wurde, und informiert Sie, dass Ihnen eine E-Mail mit der Anleitung zugesandt wurde. Die OVHcloud Konsole zeigt die zu erstellenden DNS-Einträge nicht an und bietet keinen Bestätigungsschritt: Alles Weitere erfolgt über diese E-Mail.

    Folgen Sie der erhaltenen Anleitung, um über die DNS-Oberfläche Ihres aktuellen Anbieters die erforderlichen DNS-Einträge zu konfigurieren (in der Regel einen DNS-Eintrag vom Typ **A** oder **CNAME**: **C**anonical **NAME**).
  </Tab>
</Tabs>

:::warning
Die DNS-Propagation eines externen Domainnamens kann je nach Anbieter bis zu **24 bis 48 Stunden** dauern. Ihre WordPress-Website ist während dieses Zeitraums nicht über diesen Domainnamen erreichbar.
:::

:::info
Das SSL-Zertifikat (Secure Sockets Layer) wird nach der Validierung der DNS-Propagation automatisch generiert. Auf Ihrer Seite ist kein manueller Eingriff erforderlich.
:::

</details>

**Auswirkungen des Löschens:**

- **Ihre WordPress-Website bleibt unversehrt**: Nur die Verbindung mit dem Domainnamen wird getrennt, die Site funktioniert weiter.
- **Die permanente technische URL bleibt erreichbar**: Ihre WordPress-Website ist weiterhin über diese URL erreichbar, auch ohne Domainnamen.
- **Das SSL-Zertifikat wird widerrufen**: Es deckt den gelöschten Domainnamen nicht mehr ab.
- **Das SEO-Ranking kann beeinträchtigt werden**: Wenn der Domainname von Suchmaschinen indexiert wurde, wirkt sich seine Entfernung auf das Ranking aus.
- **Denken Sie daran, Ihre E-Mail-Dienste zu überprüfen**: Die mit diesem Domainnamen verknüpften Adressen können vom Löschen betroffen sein.

:::info
**Sonderfall — einziger primärer Domainname:** Wenn Sie den einzigen primären Domainnamen einer WordPress-Website löschen, wechselt Ihre WordPress-Website automatisch auf ihre **permanente technische URL**. Diese URL ist immer erreichbar und wird nie gelöscht, auch wenn kein Domainname zugeordnet ist.
:::

### Die permanente technische URL

Jede Managed Hosting for WordPress-Website verfügt über eine **permanente technische URL**, unabhängig von jeglichem Domainnamen. Diese URL wird beim Anlegen der WordPress-Website automatisch generiert und kann nicht gelöscht werden.

<img className="thumbnail" alt="Bereich Meine Domains verwalten mit dem primären Domainnamen und der technischen URL einer WordPress-Website" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/show-domain-linked-to-a-site.png" loading="lazy" />

Sie ermöglicht es Ihnen:

- Unter **allen Umständen** auf Ihre WordPress-Website zuzugreifen, auch ohne zugeordneten Domainnamen.
- Ihre WordPress-Website zu testen, bevor Sie einen Domainnamen darauf zeigen lassen.
- Einen Notzugriff im Falle eines DNS-Problems aufrechtzuerhalten.

:::info
Die technische URL hat die Form `*.mcms.ovh.net` oder ähnlich. Sie finden sie im Tab <code className="action">Meine Sites</code>: Klicken Sie in der Spalte **Aktionen** rechts neben der betreffenden WordPress-Website auf den Button <code className="action">⋮</code> und dann auf <code className="action">Meine Domains verwalten</code>. Der sich öffnende Bereich zeigt sie neben den Domainnamen der Website an. Eine Website, der kein Domainname zugeordnet ist, wird in der Spalte **Website-Name** direkt mit ihrer technischen URL angezeigt.
:::
