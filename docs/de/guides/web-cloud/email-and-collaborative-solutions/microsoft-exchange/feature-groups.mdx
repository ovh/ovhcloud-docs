## Ziel

Mit Exchange Gruppen können mehrere Benutzer durch Senden von E-Mails an eine Gruppenadresse untereinander kommunizieren. Mit dieser kollaborativen Funktion können Sie Mailinglisten erstellen und verwalten, die sowohl Exchange Benutzer als auch externe Kontakte enthalten können.

**In dieser Anleitung wird erläutert, wie Sie Exchange Gruppen über die OVHcloud Konsole und die Outlook Web App (OWA) verwenden.**

## Voraussetzungen

- Sie haben eine [OVHcloud Exchange Lösung](/links/web/emails-exchange) abonniert.

## In der praktischen Anwendung

### Eine neue Gruppe erstellen

Klicken Sie auf den Tab <code className="action">Verwaltung der Accounts</code> und dann auf den Unter-Tab <code className="action">Gruppen</code>.

<img className="thumbnail" alt="Unter-Tab Gruppen eines Exchange Dienstes mit dem Button Kontaktgruppe erstellen oberhalb der Tabelle" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/console/exchange-groups-create01.png" loading="lazy" />

Klicken Sie oberhalb der Tabelle auf den Button <code className="action">Kontaktgruppe erstellen</code>, um das Panel **Kontaktgruppe erstellen** zu öffnen und die Einstellungen der Gruppe festzulegen:

<img className="thumbnail" alt="Panel Kontaktgruppe erstellen, rechts neben dem Unter-Tab Gruppen geöffnet" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/console/exchange-groups-create02.png" loading="lazy" />

- **E-Mail-Adresse der Gruppe**: Legen Sie eine neue Adresse fest, über die Nachrichten an die Mailingliste gesendet werden. Geben Sie den Teil vor dem `@` ein und wählen Sie dann die Domain in der darauffolgenden Drop-down-Menü aus. Achten Sie darauf, keine bereits bestehende Adresse zu verwenden.
- **Anzeigename**: Geben Sie den Namen der Gruppe an, der in der <ManagerLink to="/">OVHcloud Konsole</ManagerLink> und in Ihrem [OVHcloud Webmail](/links/web/email) (OWA) erscheint.
- **Unternehmen**: Dieses Feld ist optional.
- **Maximale Empfangsgröße (MB)** und **Maximale Sendegröße (MB)**: Geben Sie die maximale Größe eingehender und ausgehender E-Mails an. Das Kontrollkästchen **Maximalwert (100)**, das unter jedem Feld standardmäßig aktiviert ist, wendet die maximal zulässige Größe (100 MB) an: Deaktivieren Sie es, um einen niedrigeren Wert einzugeben.
- **Verwaltung der Anmeldung** und **Verwaltung der Abmeldung**: Diese beiden obligatorischen Einstellungen legen fest, ob Benutzer der Gruppe selbstständig beitreten bzw. sie verlassen können (**Offen**, die Standardeinstellung) oder nicht (**Abgeschlossen**). Die Liste **Verwaltung der Anmeldung** bietet zusätzlich **Moderiert**: Jede Anmeldeanfrage muss dann genehmigt werden.
- **Adresse im Verzeichnis ausblenden**: Wenn dieses Kontrollkästchen aktiviert ist, erscheint die Adresse der Gruppe nicht im Verzeichnis des Exchange Dienstes.
- **Authentifizierung des Absenders erforderlich**: Wenn dieses Kontrollkästchen aktiviert ist, können nur Benutzer derselben Plattform Nachrichten an die Adresse der Gruppe senden.

Klicken Sie unten im Panel auf den Button <code className="action">Erstellen</code>, um die Gruppe zu erstellen.

Die Kontakte und Administratoren der Gruppe werden nach der Erstellung der Gruppe festgelegt: Klicken Sie dazu in der Tabelle rechts neben der Gruppe auf den Button <code className="action">⋮</code> und dann auf die Option <code className="action">Benutzer konfigurieren</code> (siehe Abschnitt "[Benutzer in einer Gruppe verwalten](#benutzer-in-einer-gruppe-verwalten)"). Zur Auswahl stehen nur E-Mail-Adressen und externe Kontakte, die bereits im Dienst vorhanden sind.

- **Administrator**: E-Mail-Account, der berechtigt ist, eine E-Mail an alle Kontakte der Gruppe zu senden.
- **Kontakt**: E-Mail-Account oder externer Kontakt, der die von den Administratoren an die Gruppe gesendeten E-Mails erhält.

:::info
Bitte beachten Sie, dass Administratoren als **Kontakt** konfiguriert sein müssen, um die E-Mails der Gruppe zu erhalten.

:::

### Gruppen verwalten

Um die Einstellungen einer Gruppe nach ihrer Erstellung zu ändern, klicken Sie in der Tabelle rechts neben der Gruppe auf den Button <code className="action">⋮</code> und dann auf <code className="action">Gruppe konfigurieren</code>. Das Panel **Gruppe konfigurieren** öffnet sich, mit den aktuellen Werten vorausgefüllt. Klicken Sie nach Ihren Änderungen auf <code className="action">Konfigurieren</code>.

<img className="thumbnail" alt="Menü ⋮ einer Gruppe im Unter-Tab Gruppen, erster Eintrag Gruppe konfigurieren" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/console/exchange-groups-options01.png" loading="lazy" />

#### Benutzer in einer Gruppe verwalten

Um Kontakte zu Ihrer Gruppe hinzuzufügen oder ihre Administratoren festzulegen, klicken Sie in der Tabelle rechts neben der Gruppe auf den Button <code className="action">⋮</code> und dann auf <code className="action">Benutzer konfigurieren</code>.

Die Seite **Nutzer der Gruppe …** listet zunächst die Accounts der ersten Domain Ihres Dienstes auf. Um eine andere Domain oder alle anzuzeigen, wählen Sie in der Drop-down-Menü **Nach Domain filtern** die gewünschte Domain oder **Alle Domains** aus. Aktivieren Sie für jede Adresse in der Spalte **E-Mail-Adresse** das Kontrollkästchen **Administrator**, das Kontrollkästchen **Kontakt** oder beide, je nach der Rolle, die dem Account zugewiesen werden soll. Externe Kontakte können nicht Administratoren der Gruppe sein.

Klicken Sie nach Ihrer Auswahl auf den Button <code className="action">Speichern</code>.

:::info
Eine Gruppe kann bis zu 10.000 Kontakte enthalten.

:::


<img className="thumbnail" alt="Seite Nutzer der Gruppe mit den Spalten Administrator und Kontakt zum Aktivieren" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/console/exchange-group-options-users01.png" loading="lazy" />

#### Delegierungen einer Gruppe verwalten

Um Berechtigungen für die Gruppe auf andere Accounts zu übertragen, klicken Sie in der Tabelle rechts neben der Gruppe auf den Button <code className="action">⋮</code> und dann auf <code className="action">Berechtigungen konfigurieren</code>. Die Seite **Delegierung der Gruppe …** funktioniert wie die eines Exchange Accounts, mit zwei Berechtigungen: **Senden als** und **Senden im Auftrag von**. Weitere Informationen finden Sie in der Anleitung "[Berechtigungen für einen E-Mail Account übertragen](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/permissions-delegation)".

<img className="thumbnail" alt="Seite Delegierung der Gruppe mit den Kontrollkästchen Senden als und Senden im Auftrag von" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/console/exchange-groups-options-delegation01.png" loading="lazy" />

:::info
Bitte beachten Sie, dass jede an diesem Dienst vorgenommene Änderung einige Minuten dauern kann, bis sie angewendet wird. Den Status der meisten Vorgänge können Sie im Tab <code className="action">Vorgänge</code> Ihres Dienstes überprüfen.

:::


### Nachricht an eine Gruppe mit OWA senden

Sie können jetzt Ihre Mailingliste über [OVHcloud Webmail](/links/web/email) (OWA) testen: Senden Sie einfach eine E-Mail an die Gruppenadresse.
