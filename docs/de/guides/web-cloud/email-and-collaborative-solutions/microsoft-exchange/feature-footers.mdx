## Ziel

In der OVHcloud Konsole können Sie universelle Signaturen (Footer) für E-Mail-Adressen erstellen, die dieselbe Domain verwenden (Unternehmenssignatur). Diese werden automatisch zu allen über einen Benutzer-Account versendeten E-Mails hinzugefügt.

**Diese Anleitung erläutert, wie Sie eine automatische Signatur über die OVHcloud Konsole erstellen.**

## In der praktischen Anwendung

Klicken Sie auf den Tab <code className="action">Einstellungen</code> Ihres Dienstes und öffnen Sie dann den Bereich **Fußzeilen**.

<img className="thumbnail" alt="Tab Einstellungen eines Exchange Dienstes, geöffneter Bereich Fußzeilen mit seiner Tabelle" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-footers/console/exchange-footer-step1.png" loading="lazy" />

Die Tabelle listet Ihre zugehörigen Domains auf: Für jede können Sie eine eigene Fußzeilenvorlage erstellen. Klicken Sie rechts neben der betreffenden Domain auf den Button <code className="action">⋮</code> und dann auf <code className="action">Hinzufügen</code>, um den Editor auf der Seite **Signatur hinzufügen** zu öffnen.

<img className="thumbnail" alt="Menü ⋮ einer Domain im Bereich Fußzeilen mit der Aktion Hinzufügen" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-footers/console/exchange-footer-step2.png" loading="lazy" />

Der Editor bietet Variablen an, die den Daten des Benutzer-Accounts entsprechen. Sie können zum Beispiel eine generische Abschlussnachricht erstellen und darunter mithilfe der Variablen eine passende Unterschrift oder Kontaktinformationen hinzufügen. Wählen Sie in der Liste **Variable einfügen** eine Variable aus und klicken Sie dann auf den Button <code className="action">Variable einfügen</code>, um sie im Editierfenster hinzuzufügen.

Die Fußzeile wird in HTML erstellt, was einige Formatierungsoptionen bietet. Verwenden Sie die Toolbar über dem Editierfenster, um Ihre Signatur anzupassen (fett, kursiv, unterstrichen, Listen, Größe, Farbe, Ausrichtung) und einen Link oder ein Bild hinzuzufügen. Ein Bild muss unter einer öffentlichen Adresse gehostet sein: Geben Sie diese Adresse im Feld **Bildadresse** des Fensters **Bild einfügen** ein, das sich über den Bild-Button der Toolbar öffnet, und klicken Sie dann auf <code className="action">Einfügen</code>.

{/* v8-gap: CG-030 (oversight) — v6 « Source »: showed the footer's HTML code in the editor so it could be checked */}

<img className="thumbnail" alt="Seite Signatur hinzufügen mit der Variablenliste und der Toolbar" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-footers/console/exchange-footer-step4.png" loading="lazy" />

Setzen Sie einen Haken bei **Signatur nur für externe Sendungen aktivieren**, um zu verhindern, dass die Fußzeile zu E-Mails zwischen Benutzern derselben Domain hinzugefügt wird. Wenn die Signatur fertig ist, klicken Sie unten auf der Seite auf <code className="action">Speichern</code>. Sie wird dann zu E-Mails hinzugefügt, die von den Accounts dieser Domain versendet werden.

Um eine Signatur zu bearbeiten oder zu löschen, klicken Sie im Bereich **Fußzeilen** rechts neben der Domain auf den Button <code className="action">⋮</code> und dann auf <code className="action">Ändern</code> oder <code className="action">Löschen</code>.

Bitte beachten Sie die folgenden Hinweise, bevor Sie Signaturen für Benutzer einrichten:

- Mit Ausnahme von "Vorname", "Nachname" und "Anzeigename" können Account-Informationen nicht über die OVHcloud Konsole bearbeitet werden, sondern müssen im OWA ("Optionen", "Allgemein", "Mein Konto") des Benutzers festgelegt werden.

<img className="thumbnail" alt="Exchange Signaturen" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-footers/exchange-footer-step5.png" loading="lazy" />

- Die Signatur wird ohne Abstand zum E-Mail-Körper hinzugefügt. Daher empfiehlt es sich, die Signatur mit mindestens einer leeren Zeile zu beginnen.
- Im OWA wird nicht angezeigt, ob ein Footer für eine Domain aktiviert wurde, und es gibt **keine Synchronisation**. Wenn Benutzer ihre [eigenen Signaturen](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/email-owa#eine-signatur-hinzufügen) hinzufügen, werden E-Mails sowohl den eigenen als auch den für die gesamte Domain erstellten Footer enthalten.
- Der Editor unterstützt HTML-Formatierung, Hyperlinks, Bilder etc. Allerdings sollten sich Signaturen nicht zu sehr auf diese Optionen stützen. Empfänger verwenden möglicherweise E-Mail-Clients, die HTML und eingebundene Bilder nicht erlauben, oder die Signaturen werden anders angezeigt, als geplant. Beachten Sie, dass HTML-Tags vollständig entfernt werden, wenn eine E-Mail über OWA als "Plain Text" versendet wird.
- "Initialen" sind für den Dienst nicht aktiv. Wenn Sie diese Variable hinzufügen, hat dies keinerlei Auswirkungen.
