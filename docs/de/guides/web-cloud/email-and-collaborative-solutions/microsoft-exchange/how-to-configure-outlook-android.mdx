## Ziel

Sie können die E-Mail-Adressen Ihrer Exchange Lösung in der Outlook-App für Android konfigurieren, die kostenlos im Google Play Store verfügbar ist. Wenn Sie sie als **Exchange** Account konfigurieren, wird Ihre Adresse über das ActiveSync-Protokoll synchronisiert. Ihre E-Mails, Ihr Kalender und Ihre Kontakte stehen so auf Ihrem Gerät zur Verfügung.

**Diese Anleitung erklärt, wie Sie einen Exchange Account über ActiveSync in der Outlook-App für Android einrichten.**

[[fragment:support-scope]]

:::warning
Wir empfehlen Ihnen, sich bei Schwierigkeiten an einen [spezialisierten Dienstleister](/links/transversal/marketplace-support-collaboration) und/oder den Softwarehersteller zu wenden.
:::

## Voraussetzungen

- Sie verfügen über eine [Exchange](/links/web/emails-exchange) Lösung.
- Sie haben die [Outlook-App](https://play.google.com/store/apps/details?id=com.microsoft.office.outlook&hl=de) auf Ihrem Android-Gerät installiert.
- Sie verfügen über die Zugangsdaten der E-Mail-Adresse, die Sie konfigurieren möchten.

:::info
Diese Anleitung wurde mit einem Gerät unter Android 17 und der Version 5.2645.1 der Outlook-App erstellt.
:::

## In der praktischen Anwendung

### Konto hinzufügen <a name="add-account"></a>

Das Hinzufügen eines Kontos läuft unterschiedlich ab, je nachdem, ob in der Outlook-App **noch kein Konto eingerichtet ist** oder **bereits ein Konto eingerichtet ist**. Wählen Sie den Tab, der Ihrer Situation entspricht:

    </div>

  </Tab>
  <Tab label="Bestehende Einrichtung">

    1. Tippen Sie oben links auf dem Bildschirm auf Ihr Konto-Symbol.
    2. Tippen Sie im geöffneten Bereich auf den Button <code className="action">+</code>.
    3. Tippen Sie auf <code className="action">Konto hinzufügen</code>.

    </div>

    </div>

  <Tab label="Schritt 3">
    <CardGrid columns={2}>
    <div>

    Aktivieren Sie im Fenster "**Mit Exchange verbinden**" die Option <code className="action">Erweiterte Einstellungen</code>, falls die erweiterten Felder nicht angezeigt werden, und geben Sie dann die folgenden Informationen ein:

    - **E-Mail-Adresse**: Ihre vollständige E-Mail-Adresse, bereits ausgefüllt.
    - **Kennwort**: das Passwort Ihrer E-Mail-Adresse.
    - **Beschreibung**: ein Name, mit dem Sie dieses Konto unter Ihren anderen Konten in Outlook erkennen (optional).
    - **Server**: der Name Ihres Exchange Servers, falls er nicht bereits ausgefüllt ist. Wie Sie ihn ermitteln, erfahren Sie im Abschnitt "[Servernamen ermitteln](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/landing-page-microsoft-exchange#servernamen-ermitteln)" der Seite "Microsoft Exchange - OVHcloud E-Mail-Hub".
    - **Domäne**: Lassen Sie dieses Feld leer.
    - **Benutzername**: Ihre vollständige E-Mail-Adresse. Dieses Feld ist erforderlich: Die Verbindung kann nicht starten, solange es leer ist.

    Tippen Sie oben rechts auf dem Bildschirm auf <code className="action">✓</code>, um sich anzumelden.

    Nach der Anmeldung fragt Outlook, ob Sie ein weiteres Konto hinzufügen möchten. Tippen Sie auf <code className="action">Vielleicht später</code> und entscheiden Sie dann, ob Sie Benachrichtigungen aktivieren möchten.

    Ihr Posteingang wird angezeigt.
  </Tab>

:::warning
Konfigurieren Sie Ihre Exchange Adresse nicht als **IMAP** oder **POP3**: Nur der Kontotyp **Exchange** synchronisiert Ihren Kalender und Ihre Kontakte.
:::

:::tip
Wenn nach Schritt 3 die Meldung "**Anmeldung nicht möglich**" erscheint, überprüfen Sie Ihr Passwort. Nach einem fehlgeschlagenen Versuch leert Outlook die Felder **Server** und **Benutzername**: Füllen Sie sie vor einem neuen Versuch erneut aus.
:::

:::info
Bei einem Exchange Account verbindet sich die Outlook-App für Android nicht direkt mit Ihrem Server: Ein Microsoft-Cloud-Dienst synchronisiert Ihre E-Mails, Ihren Kalender und Ihre Kontakte zwischen dem Exchange Server und der App. Weitere Informationen finden Sie in der [Microsoft-Dokumentation](https://learn.microsoft.com/de-de/exchange/clients/outlook-for-ios-and-android/use-basic-auth).
:::

### E-Mail-Adresse verwenden

Sobald Ihre E-Mail-Adresse konfiguriert ist, können Sie in der Outlook-App Nachrichten senden und empfangen sowie Ihren Kalender und Ihre Kontakte ansehen.

:::tip
OVHcloud bietet eine Webanwendung an, mit der Sie über einen Webbrowser auf Ihre E-Mail-Adresse zugreifen können: das [Webmail](/links/web/email). Sie können sich mit den Zugangsdaten Ihrer E-Mail-Adresse anmelden.
:::

### Kontoeinstellungen ändern <a name="modify-settings"></a>

Sie können die Servereinstellungen eines bereits in der Outlook-App konfigurierten Kontos nicht ändern. Um sie zu ändern, entfernen Sie das Konto aus der App und fügen Sie es anschließend erneut hinzu:

<CardGrid columns={2}>
<div>

1. Tippen Sie oben links auf dem Bildschirm auf Ihr Konto-Symbol.
2. Tippen Sie unten im geöffneten Bereich auf das Einstellungssymbol (<code className="action">⛭</code>).
3. Tippen Sie im Abschnitt "**Allgemein**" auf <code className="action">Konten</code> und dann auf das betreffende Konto.
4. Tippen Sie auf <code className="action">Konto entfernen</code> und bestätigen Sie dann das Entfernen.

Durch das Entfernen wird das Konto aus der App gelöscht, ebenso die auf Ihrem Gerät gespeicherten Daten. Ihre E-Mails bleiben auf dem Exchange Server erhalten.

Bei Synchronisierungsproblemen tippen Sie zuerst auf derselben Seite auf <code className="action">Konto zurücksetzen</code>.

</div>
<div>

<img className="thumbnail" alt="Outlook für Android, Einstellungen des Exchange-Kontos mit Konto entfernen" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/how-to-configure-outlook-android/outlook-android-09-delete-account.png" loading="lazy" />

</div>
</CardGrid>

:::tip
Sobald Ihr Konto entfernt ist, folgen Sie den Schritten im Abschnitt "[Konto hinzufügen](#add-account)" dieser Anleitung.
:::
