## Ziel

Wenn Sie die Sicherheit Ihres Accounts erhöhen möchten, können Sie die Zwei-Faktor-Authentifizierung (2FA) aktivieren. Auf diese Weise können Sie zusätzlich zu Ihrem Passwort einen individuellen Code generieren, der bei jeder Anmeldung am Webmail OWA (Outlook Web App) eingegeben werden muss. Dieser Code wird über eine OTP-App (*one-time password*) erzeugt, die auf Ihrem Smartphone oder Tablet installiert werden muss.

:::warning
Die Zwei-Faktor-Authentifizierung schützt ausschließlich den Zugang zum Webmail OWA. Sie gilt nicht für E-Mail-Clients (Outlook, Mail, Thunderbird usw.) und nicht für Mobilgeräte: Diese Verbindungen (ActiveSync, EWS, IMAP, POP usw.) sind weiterhin nur durch das Passwort des Accounts geschützt. Wählen Sie daher ein sicheres Passwort.

:::

**Diese Anleitung erläutert die Einrichtung der Sicherheitsfunktion "Zwei-Faktor-Authentifizierung" für Ihren Exchange Account.**

## Voraussetzungen

- Sie haben bereits einen [OVHcloud Exchange](/links/web/emails-exchange) Dienst eingerichtet.
- Sie haben eine OTP-Applikation auf einem Smartphone oder Tablet mit Android oder iOS installiert.

## In der praktischen Anwendung

### Erste Konfiguration

#### Schritt 1: Die Zwei-Faktor-Authentifizierung auf der Plattform aktivieren

Bei der ersten Einrichtung muss die Zwei-Faktor-Authentifizierung zunächst auf der Plattform aktiviert werden, bevor sie für einen Account aktiviert werden kann.

Wählen Sie den Tab <code className="action">Einstellungen</code> Ihrer Plattform aus.

1. Klicken Sie im Bereich **Kontosicherheit** auf den Link <code className="action">Kontosperrung bearbeiten</code>.
1. Aktivieren Sie im daraufhin geöffneten Fenster **Kontosperrung** den Schalter **Zwei-Faktor-Authentifizierung**.
1. Klicken Sie zum Abschluss unten im Fenster auf <code className="action">Speichern</code>.

<img className="thumbnail" alt="Fenster Kontosperrung, geöffnet über den Tab Einstellungen, mit dem Schalter Zwei-Faktor-Authentifizierung" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-2fa-exchange/console/2fa-exchange-00.png" loading="lazy" />

#### Schritt 2: Die Zwei-Faktor-Authentifizierung auf einem Account aktivieren

Nachdem Sie die Zwei-Faktor-Authentifizierung auf Ihrer Plattform aktiviert haben, können Sie sie für einen Ihrer Accounts aktivieren.

Klicken Sie in Ihrer Exchange Plattform auf den Tab <code className="action">Verwaltung der Accounts</code> (Unter-Tab **E-Mail-Account**, standardmäßig geöffnet). Klicken Sie rechts neben dem betreffenden Account auf den Button <code className="action">⋮</code> und dann auf <code className="action">Zwei-Faktor-Authentifizierung aktivieren</code>. Klicken Sie im daraufhin geöffneten Fenster auf <code className="action">Bestätigen</code>.

Beim nächsten Login in Webmail muss der Nutzer des Accounts seine OTP-App einrichten.

<img className="thumbnail" alt="Menü ⋮ eines Accounts im Tab Verwaltung der Accounts, Eintrag Zwei-Faktor-Authentifizierung aktivieren" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-2fa-exchange/console/2fa-exchange-01.png" loading="lazy" />

Um Ihr Konto mit Ihrer OTP-App zu verknüpfen, loggen Sie sich in den betreffenden Account über [Webmail](https://www.ovhcloud.com/de/mail/) ein.

Während dieses ersten Logins wird ein QR-Code angezeigt. Verwenden Sie Ihre OTP-App, um ihn zu scannen, und geben Sie dann den von der App generierten Zahlencode ein, um die Verbindung herzustellen.

<img className="thumbnail" alt="2fa-exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-2fa-exchange/2fa-exchange-02.png" loading="lazy" />

Bei Ihren nachfolgenden Verbindungen werden Sie nur noch nach dem von Ihrer OTP-App generierten Code gefragt.

### Die Zwei-Faktor-Authentifizierung deaktivieren

Die Zwei-Faktor-Authentifizierung Ihres Accounts kann auf drei Arten deaktiviert werden.

Klicken Sie im Tab <code className="action">Verwaltung der Accounts</code> Ihrer Exchange Plattform (Unter-Tab **E-Mail-Account**, standardmäßig geöffnet) rechts neben dem Account, für den die Zwei-Faktor-Authentifizierung aktiv ist, auf den Button <code className="action">⋮</code>.

<img className="thumbnail" alt="Menü ⋮ eines Accounts mit aktiver Zwei-Faktor-Authentifizierung, Einträge Deaktivieren, Zurücksetzen und Entfernen" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-2fa-exchange/console/2fa-exchange-04.png" loading="lazy" />

Wählen Sie die Option, die Ihren Anforderungen entspricht, gemäß der folgenden Tabelle aus:

| Funktion | Beschreibung |
|------------------|------------------|
| <code className="action">Zwei-Faktor-Authentifizierung deaktivieren</code> | Setzt die Zwei-Faktor-Authentifizierung für 1 bis 8760 Stunden aus. Die Dauer geben Sie im Feld **Dauer der Deaktivierung** des Bestätigungsfensters ein. Nach Ablauf dieser Dauer wird die Zwei-Faktor-Authentifizierung automatisch reaktiviert. <br/> *Beispiel: Ein Benutzer hat sein Smartphone vergessen und kann sich nicht über die OTP-App authentifizieren.* |
| <code className="action">Zwei-Faktor-Authentifizierung zurücksetzen</code> | Setzt den QR-Code zurück, der beim ersten Login in Webmail angefordert wird.<br/> *Beispiel: Ein Benutzer hat sein Smartphone gewechselt und muss seine OTP-App neu konfigurieren.* |
| <code className="action">Zwei-Faktor-Authentifizierung entfernen</code> | Entfernt die Zwei-Faktor-Authentifizierung vollständig vom Account. |

Klicken Sie im daraufhin geöffneten Fenster auf <code className="action">Bestätigen</code>.
