### Ihren Zimbra Dienst konfigurieren <a name="zimbra-conf"></a>

Bevor Sie mit der Konfiguration Ihrer Zimbra E-Mail-Accounts beginnen, beachten Sie die drei Elemente, die Ihre Zimbra Dienstleistung hierarchisch strukturieren:

- [**Organisation**](#organizations): Gruppierung von Domainnamen zur Verwendung mit E-Mails.
- [**Domainname**](#domains): Notwendig zur Erstellung eines E-Mail-Accounts; Sie müssen mindestens einen Domainnamen zu Ihrem Zimbra Dienst hinzufügen.
- [**E-Mail-Accounts**](#emails): Mit den zu Ihrem Zimbra Dienst hinzugefügten Domainnamen können Sie E-Mail-Adressen erstellen.

:::info
Die *Organisation* dient zur Abbildung einer Entität (Unternehmen, Verein, persönliches Projekt, etc.). Sie erlaubt die Trennung von E-Mail-Accounts, die Anwendung spezifischer Sicherheitsrichtlinien (zukünftige Funktion) und die Übertragung von Rechten an eine Organisation (zukünftige Funktion). Die Verwendung von Organisationen vereinfacht die Navigation und Verwaltung Ihres Zimbra Dienstes.

:::


Die folgende Abbildung zeigt die hierarchische Beziehung zwischen den oben genannten Elementen.

### Organisationen <a name="organizations"></a>

Wenn Sie Ihrem Zimbra Dienst eine große Anzahl von Domainnamen hinzufügen, kann es sinnvoll sein, diese zu gruppieren, indem Sie sie einer "Organisation" zuordnen. Die Seite **Zimbra** der OVHcloud Konsole listet Ihre Organisationen auf: Für jede Organisation zeigt die Tabelle ihre Domainnamen und die Anzahl ihrer E-Mail-Accounts an.

<img className="thumbnail" alt="Seite Zimbra der OVHcloud Konsole, Tabelle der Organisationen" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_organization_tab.png" loading="lazy" />

#### Organisation erstellen <a name="organizations-create"></a>

Um eine Organisation zu erstellen, klicken Sie über der Tabelle der Organisationen auf <code className="action">Eine neue Organisation erstellen</code>. Geben Sie im Fenster **Organisation hinzufügen** den **Namen** der Organisation und ihre **Bezeichnung** (2 bis 12 Zeichen) ein. Dabei handelt es sich um eine Kurzbeschreibung, anhand derer Sie die Organisation wiedererkennen, wenn Sie die Anzeige der Domainnamen und E-Mail-Accounts Ihres Zimbra Dienstes filtern. Klicken Sie anschließend auf <code className="action">Hinzufügen</code>.

#### Nach Organisation filtern <a name="organizations-filters"></a>

Um nur die Elemente anzuzeigen, die mit einer Organisation verknüpft sind, klicken Sie in der Tabelle auf der Seite **Zimbra** auf deren Bezeichnung. Ihr Zimbra Dienst wird dann nach dieser Organisation gefiltert geöffnet: Die Tabs <code className="action">E-Mail-Account</code> und <code className="action">Zugehörige Domains</code> zeigen nur die E-Mail-Accounts und Domainnamen dieser Organisation an.

<img className="thumbnail" alt="Tabelle der Organisationen auf der Seite Zimbra, Bezeichnung einer Organisation hervorgehoben" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_organization_filter.png" loading="lazy" />

Der Filter bleibt beim Wechsel zwischen den Tabs aktiv. Um den Filter zu entfernen, klicken Sie oben auf der Seite im Navigationspfad auf den Namen Ihres Zimbra Dienstes.

### Domains <a name="domains"></a>

:::warning
Für einen optimalen Betrieb, wenn Sie denselben Domainnamen für die OVHcloud Lösungen [Exchange](/links/web/emails-hosted-exchange), [Email Pro](/links/web/email-pro) und Zimbra verwenden, muss der Domainname im Modus **Nicht-autoritativ** konfiguriert werden. Wie Sie einen Domainnamen im nicht-autoritativen Modus auf einer Exchange oder Email Pro Plattform konfigurieren, erfahren Sie in unserer Anleitung "[Domainnamen zu Ihrem Exchange Dienst hinzufügen](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain)".

:::


Der Tab <code className="action">Zugehörige Domains</code> listet die zu Ihrem Zimbra Dienst hinzugefügten Domainnamen auf.

Die Tabelle enthält unter anderem folgende Informationen:

- **Organisation**: Die Bezeichnung der Organisation, die beim Hinzufügen des Domainnamens ausgewählt wurde.
- **Anzahl der Accounts**: Die Anzahl der E-Mail-Accounts, die unter diesem Domainnamen erstellt wurden.

<img className="thumbnail" alt="Tab Zugehörige Domains eines Zimbra Dienstes, Tabelle der Domainnamen" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_domain_tab.png" loading="lazy" />

#### Einen Domainnamen hinzufügen <a name="domains-add"></a>

:::warning
Sie müssen [eine Organisation erstellen](#organizations), um Ihrem Zimbra Dienst einen Domainnamen hinzufügen zu können.

:::


Um Ihrem Zimbra Dienst einen Domainnamen hinzuzufügen, klicken Sie auf den Tab <code className="action">Zugehörige Domains</code> und dann auf <code className="action">Domain hinzufügen</code>.

Wählen Sie im Panel **Domain hinzufügen** im Drop-down-Menü **Organisation** eine Organisation aus und wählen Sie dann eine der beiden folgenden Optionen:

- **Domain in der Liste auswählen** (interne Domain): Die Liste enthält die Domainnamen, die Sie in der OVHcloud Konsole verwalten.
- **Eine Domain angeben, die nicht in Ihrem OVHcloud Account verwaltet wird** (externe Domain): Geben Sie einen Domainnamen ein, der nicht in der OVHcloud Konsole verwaltet wird oder bei einem anderen Registrar registriert ist und von Ihnen verwaltet wird.

Wählen Sie den Tab, der Ihrer Wahl entspricht:

       - *SRV-Eintrag automatisch konfigurieren (Autodiscover)*: Damit werden die Parameter eines E-Mail-Accounts automatisch konfiguriert, wenn Sie ihn in einer E-Mail-Software (Outlook, Mail für Mac, Thunderbird usw.) hinzufügen.

Klicken Sie auf die Markierung <code className="action">CNAME</code>, um die Seite **Überprüfen** zu öffnen, die den Eintrag im Detail beschreibt.

#### Domainnamen bearbeiten <a name="domains-modify"></a>

Sie können Ihren Domainnamen ändern, um seine Organisation zu wechseln oder die zugehörigen DNS-Einträge zu überprüfen.

Klicken Sie im Tab <code className="action">Zugehörige Domains</code> Ihres Zimbra Dienstes rechts neben dem betreffenden Domainnamen auf den Button <code className="action">⋮</code>, um die Optionen anzuzeigen.

<img className="thumbnail" alt="Tab Zugehörige Domains eines Zimbra Dienstes, Menü eines Domainnamens geöffnet" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_domain_modify01.png" loading="lazy" />

- Klicken Sie auf <code className="action">Ändern</code>, um die mit Ihrem Domainnamen verknüpfte Organisation zu wechseln: Wählen Sie im Fenster **Domain ändern** in der Liste **Organisation** die Organisation aus und klicken Sie dann auf <code className="action">Ändern</code>.
- Klicken Sie auf <code className="action">Diagnose</code>, um die Diagnoseseite für die DNS-Einträge des Domainnamens anzuzeigen. Prüfen Sie, dass in keinem der Tabs **MX**, **SRV**, **SPF** und **DKIM** eine Warnung angezeigt wird, und folgen Sie den Anweisungen in jedem Tab mit einer Warnung, um den betreffenden DNS-Eintrag zu konfigurieren:
    - **MX**: Unerlässlich für den Empfang Ihrer E-Mails.
    - **SPF**: Sicherheitseintrag, der von den meisten empfangenden E-Mail-Servern verlangt wird, um die E-Mail-Ausgangsserver von OVHcloud mit Ihrem Domainnamen zu legitimieren.
    - **DKIM**: Ermöglicht ein Signatursystem für jede von Ihrem Zimbra Dienst gesendete E-Mail. Die Signatur wird vom Empfänger anhand des öffentlichen Schlüssels überprüft, der in Ihrer DNS-Zone sichtbar ist.
    - **SRV**: Erleichtert die Konfiguration Ihres Zimbra Accounts, wenn Sie ihn in einer E-Mail-Software (Outlook, Mail für Mac, Thunderbird usw.) hinzufügen.

<img className="thumbnail" alt="Seite Diagnose eines Domainnamens, Tab SRV mit Warnung" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_domain_modify02.png" loading="lazy" />

### E-Mail-Accounts <a name="emails"></a>

Sie verwalten die E-Mail-Adressen Ihres Zimbra Dienstes im Tab <code className="action">E-Mail-Account</code>. Die Tabelle listet die E-Mail-Accounts Ihres Dienstes auf und enthält für jeden unter anderem folgende Informationen:

- **Organisation**: Wenn der Domainname Ihres E-Mail-Accounts mit einer Organisation verknüpft ist, finden Sie in dieser Spalte automatisch deren Bezeichnung.
- **Angebot**: Da Ihr Zimbra Dienst mehrere Zimbra Lösungen enthalten kann, finden Sie in dieser Spalte das Angebot, das Ihrem E-Mail-Account zugeordnet ist.
- **Genutztes Kontingent**: Diese Spalte zeigt die Gesamtkapazität Ihres E-Mail-Accounts und den belegten Speicherplatz an.

Oben auf dieser Seite finden Sie im Bereich **Anmeldung beim Webmail** außerdem einen Link zum [Webmail](/links/web/email), über den Sie sich direkt in Ihrem Webbrowser mit dem Inhalt Ihres E-Mail-Accounts verbinden können.

<img className="thumbnail" alt="Tab E-Mail-Account eines Zimbra Dienstes, Tabelle der E-Mail-Accounts" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_emailaccounts_tab.png" loading="lazy" />

#### Einen E-Mail-Account erstellen <a name="emails-create"></a>

Um einen E-Mail-Account für Ihren Zimbra Dienst zu erstellen, klicken Sie auf den Tab <code className="action">E-Mail-Account</code>, dann auf <code className="action">Neues Konto</code> und schließlich auf <code className="action">Konto konfigurieren</code>.

Füllen Sie auf der Seite **E-Mail-Account konfigurieren** die folgenden Felder aus:

- **E-Mail-Adresse**: Geben Sie den *Account-Namen* ein, den Ihre E-Mail-Adresse tragen soll (zum Beispiel Ihr Vorname.Nachname), und *wählen Sie einen Domainnamen* im Drop-down-Menü aus.

:::warning
Der Name Ihrer E-Mail-Adresse muss die folgenden Bedingungen erfüllen:

- Mindestens 2 Zeichen.
- Höchstens 32 Zeichen.
- Keine Akzente.
- Keine Sonderzeichen, mit Ausnahme der folgenden Zeichen: `.`, `+`, `-` und `_`. Zwei dieser Zeichen dürfen nicht aufeinanderfolgen.
- Der Teil vor dem "@" muss mit einem Buchstaben oder einer Ziffer enden.

:::


- **Name**: Geben Sie einen Namen ein.
- **Vorname**: Geben Sie einen Vornamen ein.
- **Anzeigename**: Geben Sie den Namen ein, der als Absender angezeigt wird, wenn E-Mails von dieser Adresse gesendet werden.
- **Passwort**: Legen Sie ein sicheres Passwort mit mindestens 10 Zeichen fest, das einen Großbuchstaben, eine Ziffer und ein Sonderzeichen enthält, oder generieren Sie eines mit dem Schlüsselsymbol rechts neben dem Feld. Verwenden Sie aus Sicherheitsgründen nicht zweimal dasselbe Passwort, wählen Sie eines, das in keinem Zusammenhang mit Ihren persönlichen Daten steht (zum Beispiel Nachname, Vorname und Geburtsdatum), und ändern Sie es regelmäßig. Die standardmäßig aktivierte Option **Änderung beim nächsten Anmelden erzwingen** fordert den Nutzer des Accounts auf, dieses Passwort bei der nächsten Anmeldung zu ändern.

:::warning
Das Passwort muss die folgenden Anforderungen erfüllen:

- Mindestens 10 Zeichen.
- Höchstens 64 Zeichen.
- Mindestens 1 Großbuchstabe.
- Mindestens 1 Ziffer.
- Mindestens 1 Sonderzeichen.
- Keine Akzente.

:::


- **Angebot**: Wählen Sie im Drop-down-Menü das Angebot des Accounts aus (Zimbra Starter oder Zimbra Pro) oder **Inklusive mit einem Domainnamen**, um einen Dienst zu verwenden, der mit einem Ihrer Domainnamen inklusive ist (siehe [Den Dienst eines neuen Accounts auswählen](#services-choice)). Für jede Auswahl wird die Anzahl der noch verfügbaren Accounts angezeigt.

Klicken Sie auf <code className="action">Erstellen</code>, um die Erstellung des Accounts zu starten.

<img className="thumbnail" alt="Seite E-Mail-Account konfigurieren eines Zimbra Dienstes" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_emailaccounts_add.png" loading="lazy" />

#### Angebot wechseln <a name="emails-offer"></a>

Sie können das Angebot jedes Zimbra Accounts auf ein höheres oder niedrigeres Angebot ändern.

1. Klicken Sie auf den Tab <code className="action">E-Mail-Account</code>.
1. Klicken Sie rechts neben dem betreffenden E-Mail-Account auf <code className="action">⋮</code>.
1. Klicken Sie auf <code className="action">Angebot wechseln</code>.

    <img className="thumbnail" alt="Tab E-Mail-Account eines Zimbra Dienstes, Menü eines E-Mail-Accounts geöffnet" src="/images/assets/screens/email-clients/zimbra/console/zimbra-change-offer.png" loading="lazy" />

1. Wählen Sie auf der Seite **Neues Angebot auswählen** das gewünschte Angebot aus und klicken Sie dann auf <code className="action">Mit meiner Bestellung fortfahren</code>.

:::warning
Bevor Sie auf ein niedrigeres Angebot wechseln, stellen Sie sicher, dass folgende Punkte erfüllt sind:

- Keine Dateien sind auf Ihrem Speichervolumen "Aktentasche" gespeichert, wenn Sie auf das Angebot Starter wechseln.
- Der Inhalt Ihres E-Mail-Accounts muss weniger als 15 GB sein, wenn Sie auf das Angebot Starter wechseln.

:::


### Dienste <a name="services"></a>

Jeder E-Mail-Account belegt einen Dienst, also einen Platz des Angebots Starter oder Pro, das Sie bestellt haben. Um Ihre Dienste anzuzeigen, klicken Sie im Bereich **Abonnement** des Tabs <code className="action">Übersicht</code> Ihres Zimbra Dienstes auf <code className="action">Meine Dienste verwalten</code>. Die Seite **Dienste** zeigt die Anzahl der konfigurierten Accounts für jedes Angebot (zum Beispiel **Starter** "3 / 3 Konten konfiguriert") und die Liste Ihrer Dienste mit jeweils den folgenden Angaben:

- **E-Mail-Account**: der Account, der diesen Dienst belegt;
- **Kosten/E-Mail-Postfach**: "Kostenlos" für einen Dienst, der mit einem Domainnamen verknüpft ist;
- **Verknüpfter Dienst**: der Domainname, dem der Dienst zugeordnet ist.

Die Tabelle zeigt außerdem die Referenz, das Angebot, die Verlängerung und das Verlängerungsdatum jedes Dienstes an. Die Suche auf dieser Seite bezieht sich auf die Adresse der E-Mail-Accounts, die Referenz der Dienste und die verknüpften Domainnamen.

#### Den Dienst eines neuen Accounts auswählen <a name="services-choice"></a>

Im Formular zur Erstellung eines E-Mail-Accounts bestimmt das Drop-down-Menü **Angebot** den Dienst, dem der Account zugeordnet wird:

- **Zimbra Starter** oder **Zimbra Pro**: Der Account wird dem ersten freien Dienst dieses Angebots zugeordnet, der mit keinem Domainnamen verknüpft ist;
- **Inklusive mit einem Domainnamen**: Wählen Sie anschließend den Dienst im Drop-down-Menü **Zugehöriger Domainname** aus, in dem jeder Dienst mit seinem Domainnamen und seinem Angebot angezeigt wird.

<img className="thumbnail" alt="Formular E-Mail-Account konfigurieren, Drop-down-Menü Angebot geöffnet mit den Optionen Zimbra Starter, Zimbra Pro und Inklusive mit einem Domainnamen" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra-account-service-plan-list.png" loading="lazy" />

Wenn der Domainname der Adresse über einen inklusiven Dienst verfügt, der noch frei ist, wählt die OVHcloud Konsole diesen automatisch aus.

Sie können auch von der Seite [Dienste](#services) ausgehen: Klicken Sie auf den Button <code className="action">⋮</code> eines freien Dienstes und dann auf <code className="action">Account konfigurieren</code>. Das Erstellungsformular wird für diesen Dienst geöffnet.

Sie können den Account auch über die OVHcloud API einem bestimmten Dienst zuordnen.

Rufen Sie zunächst die ID des Dienstes (`id`) und den damit verknüpften Domainnamen (`currentState.domainPromotionLink`) mit folgendem API-Aufruf ab:

<Api version="v2" section="/zimbra" method="GET" route={"/zimbra/platform/\{platformId\}/slot"} />

Erstellen Sie anschließend den Account und geben Sie diese ID im Feld `targetSpec.slotId` an:

<Api version="v2" section="/zimbra" method="POST" route={"/zimbra/platform/\{platformId\}/account"} />

:::info
Der Dienst eines Accounts kann nach dessen Erstellung nicht mehr geändert werden.
:::

### Weiterleitungen <a name="redirections"></a>

Um eine Weiterleitung auf eine Zimbra E-Mail-Adresse zu erstellen, loggen Sie sich im [Webmail](/links/web/email) ein.
Die Erstellung einer Weiterleitung erfolgt über Posteingangsregeln, im Webmail als "Filter" bezeichnet. Diese Regeln, die beim Empfang einer E-Mail angewendet werden, erlauben es, eine E-Mail weiterzuleiten oder umzuleiten.

Um die E-Mails Ihres Zimbra-Accounts an eine andere E-Mail-Adresse weiterzuleiten, wenden wir eine Transferregel an. Folgen Sie den unten stehenden Tabs, um Ihre Weiterleitung einzurichten.

:::info
Im Beispiel unten sollen alle eingehenden E-Mails an eine andere E-Mail-Adresse weitergeleitet werden. Als Beispiel-Account wird **zimbra@mydomain.ovh** verwendet und alle eingehenden E-Mails an diese E-Mail-Adresse werden an die Adresse **address@example.com** geleitet.

:::

### Alias <a name="alias"></a>

Klicken Sie auf die folgenden Tabs, um einen Alias zu erstellen:

    - Klicken Sie auf <code className="action">Alias</code>.
    
    <img className="thumbnail" alt="Tab E-Mail-Account eines Zimbra Dienstes, Menü eines E-Mail-Accounts geöffnet" src="/images/assets/screens/email-clients/zimbra/console/zimbra-change-offer.png" loading="lazy" />

### Automatische Antworten <a name="autoreply"></a>

Wenn Sie abwesend sind und Ihre E-Mails nicht bearbeiten können, können Sie eine Abwesenheitsnachricht einrichten. Führen Sie die folgenden Schritte aus:

- Klicken Sie auf den Button &#9881; oben rechts in Ihrem Webmail-Fenster und dann auf <code className="action">Einstellungen</code>.

<img className="thumbnail" alt="zimbra" src="/images/assets/screens/email-clients/zimbra/zimbra_settings01.png" loading="lazy" />

- Klicken Sie auf den Abschnitt `Abwesend im Büro` hinter dem Fenster der Parameter.
- Aktivieren Sie das Kontrollkästchen "Automatische Antwort für diese Datumsangaben (inklusive) aktivieren".
- Geben Sie das Startdatum der Abwesenheit vor dem Vermerk "Von" ein.
- Deaktivieren Sie die Option "Kein Enddatum", wenn Sie ein Enddatum für die Abwesenheit festlegen möchten.
- Geben Sie in das Feld Ihre Abwesenheitsmeldung ein.
- Klicken Sie auf <code className="action">Speichern</code>, um die Abwesenheitsnotiz abzuschließen.

<img className="thumbnail" alt="zimbra" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/zimbra_autoreply01.png" loading="lazy" />

:::warning
E-Mails, die ein Filter nur mit der Aktion <code className="action">Weiterleiten an</code> weiterleitet, bleiben nicht in Ihrem Posteingang, und ihre Absender erhalten Ihre automatische Antwort nicht. Fügen Sie diesem Filter die Aktion <code className="action">Im Posteingang aufbewahren</code> hinzu (siehe Abschnitt "[Weiterleitungen](#redirections)").
:::
