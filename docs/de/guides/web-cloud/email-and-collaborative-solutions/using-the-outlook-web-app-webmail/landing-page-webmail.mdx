## Was ist ein Webmail?

Ein **Webmail** ist eine Benutzeroberfläche, mit der Sie Ihre E-Mails direkt über einen Webbrowser abrufen, versenden und organisieren können, ohne ein E-Mail-Programm installieren oder konfigurieren zu müssen. Ihre Nachrichten bleiben auf den OVHcloud Servern gespeichert: Sie greifen von jedem mit dem Internet verbundenen Computer darauf zu, indem Sie sich einfach authentifizieren.

Der einfachste Zugang ist die OVHcloud **Webmail-Anmeldeseite**: Geben Sie dort Ihre vollständige E-Mail-Adresse und Ihr Passwort ein, um Ihr Postfach zu öffnen.

> Greifen Sie auf Ihr Postfach unter [www.ovhcloud.com/de/mail/](https://www.ovhcloud.com/de/mail/) zu.
