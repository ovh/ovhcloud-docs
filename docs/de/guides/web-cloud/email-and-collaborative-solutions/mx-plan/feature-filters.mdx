## Ziel

Mit einem Filter können Bedingungen für die von Ihnen erhaltenen E-Mails sowie die sich daraus ergebenden Aktionen konfiguriert werden.

Zum Beispiel: Sie können jede E-Mail, die von unserem Spamschutz als Spam markiert wurde, automatisch löschen lassen.

- Bedingung: der Betreff der E-Mail enthält *[SPAM]*
- Aktion: E-Mail löschen

**Diese Anleitung erklärt, wie Sie Filter für Ihre E-Mail-Adressen erstellen und konfigurieren.**

## In der praktischen Anwendung <a name="oldmxplan"></a>

Im Tab <code className="action">E-Mail-Account</code> Ihres MX Plan Dienstes werden Ihre E-Mail-Adressen aufgelistet. Klicken Sie rechts neben dem betreffenden Account auf den Button <code className="action">⋮</code> und dann auf <code className="action">Filter verwalten</code>.

<img className="thumbnail" alt="⋮-Menü eines Accounts im Tab E-Mail-Account mit der Option Filter verwalten" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-filters/console/mxplan-filters-01.png" loading="lazy" />

Die Seite **Filter von …** listet die für diese E-Mail-Adresse konfigurierten Filter auf.

<img className="thumbnail" alt="Filterseite einer E-Mail-Adresse mit dem Button Filter erstellen" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-filters/console/mxplan-filters-02.png" loading="lazy" />

Um Ihrer E-Mail-Adresse einen Filter hinzuzufügen, klicken Sie auf den Button <code className="action">Filter erstellen</code>. Legen Sie im Bereich **Informationen** des sich öffnenden Panels Folgendes fest:

- **Filtername:** Wählen Sie einen Namen für Ihren Filter.

- **Priorität:** Legt die Reihenfolge fest, in der Ihre Filter auf eine eingehende Nachricht angewendet werden, von 1 bis 99. Ein Filter der Priorität 1 wird vor einem Filter der Priorität 2 ausgeführt.

- **Filter aktivieren:** Deaktivieren Sie diese Option, wenn Sie den Filter erst später anwenden möchten.

### Die Filter-Einstellungen verstehen

Das Panel **Filter erstellen**, das beim Hinzufügen eines Filters angezeigt wird, besteht aus 3 Bereichen: **Informationen**, **Regeln** und **Aktion**.

<img className="thumbnail" alt="Panel Filter erstellen mit den Bereichen Informationen, Regeln und Aktion" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-filters/console/mxplan-filters-03.png" loading="lazy" />

#### Regeln

Im Bereich **Regeln** legen Sie fest, auf welche Nachrichten der Filter angewendet wird.

Erste Auswahl (Header):

- **Absender (From):** Entspricht der E-Mail-Adresse des Absenders, zum Beispiel: "Wenn der Absender ...".
- **Empfänger (To):** Entspricht der E-Mail-Adresse des Empfängers, zum Beispiel: "Wenn der Empfänger ...".
- **Betreff (Subject):** Entspricht dem Betreff der Nachricht, zum Beispiel: "Wenn der Betreff der Nachricht ...".
- **Andere:** Die OVHcloud Konsole bietet kein Feld, in dem Sie das zu berücksichtigende Element des E-Mail-Headers angeben können.

Zweite Auswahl (Regel):

- **Enthält:** Beispiel: "... enthält ...".
- **Enthält nicht:** Beispiel: "... enthält nicht ...".
- **SPF-Prüfung:** Geben Sie einen zu berücksichtigenden Wert des [SPF-Eintrags](/guides/web-cloud/domains/dns-zone-spf) an, zum Beispiel: "... hat keinen SPF-Eintrag ...".

:::info
Mit SPF (Sender Policy Framework) kann der Server, der eine E-Mail empfängt, überprüfen, ob diese von einem vertrauenswürdigen Server stammt.
Dies verhindert Identitätsbetrug über E-Mail-Adressen mit Ihrem Domainnamen (Spoofing). Weitere Informationen zu SPF finden Sie in der Anleitung "[E-Mail-Sicherheit durch SPF-Eintrag verbessern](/guides/web-cloud/domains/dns-zone-spf)".

:::


Dritte Auswahl (Wert):

- Beispiel: [SPAM]

Vierte Auswahl (<code className="action">Neue Regel</code>):

- Mit diesem Button können Sie eine oder mehrere weitere Bedingungen für dieselbe Aktion hinzufügen.

#### Aktion

Im Bereich **Aktion** legen Sie die anzuwendende Aktion fest.

Im Dropdown-Menü **Aktion** haben Sie die Wahl zwischen:

- **Akzeptieren:** E-Mails, die die Bedingungen erfüllen, werden normal empfangen.
- **Löschen:** E-Mails, die die Bedingungen erfüllen, werden gelöscht.
- **Weiterleiten an:** Leitet E-Mails, die die Bedingungen erfüllen, an die E-Mail-Adresse Ihrer Wahl weiter, die Sie im Feld **Parameter (E-Mail)** eingeben.
- **Übertragen an:** Überträgt E-Mails, die die Bedingungen erfüllen, an eine der E-Mail-Adressen Ihrer Domain, die Sie im Feld **Parameter (E-Mail)** eingeben.

Klicken Sie anschließend auf <code className="action">Erstellen</code>, um den Filter zu speichern.

### Beispiele

#### Spam löschen

:::warning
Das Beispiel bezieht sich auf den Vermerk [SPAM] im Betreff einer E-Mail. Er wird hinzugefügt, wenn vom Antispam-Programm des Empfangsservers als unerwünscht eingestufte E-Mails im Posteingang abgelegt werden. Dies gilt für MX Plan Dienste, die das Roundcube Webmail verwenden.

:::


||Header|Regel|Wert|Aktion|
|---|---|---|---|---|
|Filtereinstellungen|Betreff (Subject)|Enthält|[SPAM]|Löschen|
|Was der Filter bewirkt|Wenn der Betreff der Nachricht|enthält|[SPAM]|dann die Nachricht löschen.|

#### E-Mails eines bestimmten Senders weiterleiten

||Header|Regel|Wert|Aktion|
|---|---|---|---|---|
|Filtereinstellungen|Absender (From)|Enthält|contact@example.com|Weiterleiten an: user@example.net|
|Was der Filter bewirkt|Wenn der Absender|ist|contact@example.com|dann die E-Mail an user@example.net weiterleiten|

#### An eine Mailingliste adressierte E-Mail weiterleiten

||Header|Regel|Wert|Aktion|
|---|---|---|---|---|
|Filtereinstellungen|Empfänger (To)|Enthält|ml@example.com|Übertragen an: user@example.org|
|Was der Filter bewirkt|Wenn die Nachricht an die Mailingliste versandt wurde|namens|ml@example.com|dann die Nachricht an meine andere Adresse weiterleiten: user@example.org|

#### E-Mails mit unerwünschten Phrasen löschen, unter Ausnahme einer Absenderadresse

Sie müssen nur einen Filter mit zwei Regeln hinzufügen. Klicken Sie nach dem Ausfüllen der ersten Regel auf <code className="action">Neue Regel</code>, um die zweite hinzuzufügen:

||Header|Regel|Wert|
|---|---|---|---|
|Einstellungen der Regel 1|Betreff (Subject)|Enthält|money|
|Einstellungen der Regel 2|Absender (From)|Enthält nicht|contact@example.net|

Aktion des Filters: **Löschen**.

Wenn der Betreff der Nachricht das Wort "money" enthält **und** der Absender der Nachricht nicht "contact@example.net" ist, wird die Nachricht gelöscht.
