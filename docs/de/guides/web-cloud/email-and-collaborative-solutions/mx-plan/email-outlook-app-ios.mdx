## Ziel

MX Plan Accounts können auf verschiedenen kompatiblen E-Mail-Clients eingerichtet werden. So können Sie Ihr bevorzugtes Gerät für Ihre E-Mail-Adressen verwenden. Die Microsoft Outlook App für iOS ist kostenlos im Apple App Store verfügbar.

**Erfahren Sie, wie Sie Ihre MX Plan E-Mail-Adresse auf der mobilen Outlook App für iOS konfigurieren**

[[fragment:support-scope]]

## Voraussetzungen

- Sie haben einen MX Plan E-Mail-Account (als MX Plan Dienst oder in einem [OVHcloud Webhosting](https://www.ovhcloud.com/de/web-hosting/) enthalten).
- Microsoft Outlook ist auf Ihrem [iOS Gerät](https://apps.apple.com/app/microsoft-outlook/id951937596) installiert.
- Sie verfügen über die Login-Daten für den E-Mail-Account, den Sie konfigurieren möchten.

## In der praktischen Anwendung

### Account hinzufügen <a name="add-account"></a>

- **Wenn Sie die Anwendung zum ersten Mal starten**: Ein Konfigurationsassistent wird angezeigt. Tippen Sie auf <code className="action">Account hinzufügen</code>.

<img className="thumbnail" alt="Outlook iOS" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-outlook-app-ios/outlook-app-ios-add01.png" loading="lazy" />

- **Wenn bereits ein Account eingerichtet wurde**:
    1. Tippen Sie auf den Kreis mit den Initialen des E-Mail-Accounts oder das Home Icon "&#8962;" oben links auf dem Bildschirm.
    2. Tippen Sie das Zahnrad "&#9881;" unten links auf dem Bildschirm.
    3. Tippen Sie im Menü **Einstellungen** auf <code className="action">Konten</code>.
    4. Tippen Sie auf <code className="action">Konto hinzufügen</code>.
    5. Tippen Sie <code className="action">E-Mail-Konto</code>.

<img className="thumbnail" alt="Outlook iOS" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-outlook-app-ios/outlook-app-ios-add02.png" loading="lazy" />

Folgen Sie den Installationsschritten, indem Sie auf die Tabs klicken:

<Tabs>
  <Tab label="Schritt 1">
    Geben Sie Ihre E-Mail-Adresse ein und tippen Sie auf <code className="action">Account hinzufügen</code>.
    
    <img className="thumbnail" alt="Outlook iOS" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-outlook-app-ios/outlook-app-ios-add-step01.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Sie haben zwei Möglichkeiten:
    
    - Wenn am oberen Seitenrand " **IMAP** " steht, fahren Sie mit Schritt 3 fort.
    - Wenn im Fenster für die Kontoeinstellungen oben "**Exchange**" angezeigt wird, Tippen Sie die Schaltfläche `?` in der rechten oberen Ecke des Bildschirms **(1)** und wählen Sie <code className="action">Kontoanbieter wechseln</code> **(2)**. Wählen Sie nun `IMAP`**(3)** aus und fahren Sie mit Schritt 3 fort.
    
    <img className="thumbnail" alt="Outlook iOS" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-outlook-app-ios/outlook-app-ios-add-step02.png" loading="lazy" />

  <Tab label="Schritt 3">
    Aktivieren Sie im folgenden Fenster <code className="action">Erweiterte Einstellungen</code> und geben Sie die folgenden Informationen ein:
    
    - **E-Mail-Adresse**
    - **Anzeigename**: Vollständige E-Mail-Adresse
    - **Beschreibung**
    - **IMAP-Posteingangsserver**:
    
    <Region zones={['eu']}>
    - **IMAP-Hostname**: `imap.mail.ovh.net` oder `ssl0.ovh.net`
    - **IMAP-Port**: 993
    - **IMAP-Benutzername**: Vollständige E-Mail-Adresse.
    - **IMAP-Passwort**: Passwort Ihres E-Mail-Accounts.
    - **Portsicherheit**: SSL
    </Region>
    
    <Region zones={['ca', 'apac']}>
    - **IMAP-Hostname**: `imap.mail.ovh.ca`
    - **IMAP-Port**: 993
    - **IMAP-Benutzername**: Vollständige E-Mail-Adresse.
    - **IMAP-Passwort**: Passwort Ihres E-Mail-Accounts.
    - **Portsicherheit**: SSL
    </Region>
    
    - **SMTP-Posteingangsserver**:
    
    <Region zones={['eu']}>
    - **SMTP-Hostname**: `smtp.mail.ovh.net` oder `ssl0.ovh.net`
    - **SMTP-Port**: 465
    - **SMTP-Benutzername**: Vollständige E-Mail-Adresse.
    - **SMTP-Passwort**: Passwort Ihres E-Mail-Accounts.
    - **Portsicherheit**: SSL
    </Region>
    
    <Region zones={['ca', 'apac']}>
    - **SMTP-Hostname**: `smtp.mail.ovh.ca`
    - **SMTP-Port**: 465
    - **SMTP-Benutzername**: Vollständige E-Mail-Adresse.
    - **SMTP-Passwort**: Passwort Ihres E-Mail-Accounts.

### Bestehende Einstellungen ändern <a name="modify-settings"></a>

1. Tippen Sie auf den Kreis mit den Initialen des E-Mail-Accounts oder das Home Icon "&#8962;" oben links auf dem Bildschirm.
2. Tippen Sie das Zahnrad "&#9881;" unten links auf dem Bildschirm.
3. Tippen Sie im Menü **Einstellungen** auf <code className="action">Konten</code>.
4. Wählen Sie das entsprechende Konto aus.
5. Tippen Sie auf <code className="action">Anmeldeinformationen bearbeiten</code>.

<img className="thumbnail" alt="Outlook iOS" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-outlook-app-ios/outlook-app-ios-modify-account-01.png" loading="lazy" />

Die Einstellungen finden Sie in **Schritt 3** unter [Account hinzufügen](#add-account).

### E-Mail-Account löschen <a name="delete"></a>

1. Tippen Sie auf den Kreis mit den Initialen des E-Mail-Accounts oder das Home Icon "&#8962;" oben links auf dem Bildschirm.
2. Tippen Sie das Zahnrad "&#9881;" unten links auf dem Bildschirm.
3. Tippen Sie im Menü **Einstellungen** auf <code className="action">Konten</code>.
4. Wählen Sie das entsprechende Konto aus.
5. Tippen Sie <code className="action">Account löschen</code>.

<img className="thumbnail" alt="Outlook iOS" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-outlook-app-ios/outlook-app-ios-modify-delete-01.png" loading="lazy" />

### POP-, IMAP- und SMTP-Einstellungen <a name="popimap-settings"></a>

#### IMAP und POP - Empfang

Für eingehende E-Mails empfehlen wir bei der Auswahl des Kontotyps die Verwendung von **IMAP**. Sie können aber auch **POP** auswählen.

Folgen Sie den Installationsschritten, indem Sie auf die Tabs klicken:

<Tabs>
  <Tab label="IMAP-Konfiguration">
    <Region zones={['eu']}>
    - **Server eingehend**: imap.mail.ovh.net **oder** ssl0.ovh.net
    - **Benutzername**: Geben Sie die **vollständige** E-Mail-Adresse ein.
    - **Passwort**: Geben Sie das Passwort des E-Mail-Accounts ein.
    - **Port**: 993
    - **Sicherheitstyp**: SSL/TLS
    </Region>

    <Region zones={['ca', 'apac']}>
    - **Server eingehend**: imap.mail.ovh.ca
    - **Benutzername**: Geben Sie die **vollständige** E-Mail-Adresse ein.
    - **Passwort**: Geben Sie das Passwort des E-Mail-Accounts ein.
    - **Port**: 993
    - **Sicherheitstyp**: SSL/TLS
    </Region>
  </Tab>
  <Tab label="POP-Konfiguration">
    <Region zones={['eu']}>
    - **Server eingehend**: pop.mail.ovh.net **oder** ssl0.ovh.net
    - **Benutzername**: Geben Sie die **vollständige** E-Mail-Adresse ein.
    - **Passwort**: Geben Sie das Passwort des E-Mail-Accounts ein.
    - **Port**: 995
    - **Sicherheitstyp**: SSL/TLS
    </Region>

    <Region zones={['ca', 'apac']}>
    - **Server eingehend**: pop.mail.ovh.ca
    - **Benutzername**: Geben Sie die **vollständige** E-Mail-Adresse ein.
    - **Passwort**: Geben Sie das Passwort des E-Mail-Accounts ein.
    - **Port**: 995
    - **Sicherheitstyp**: SSL/TLS
    </Region>
  </Tab>
</Tabs>


#### SMTP - Senden

Wenn Sie zum Senden von E-Mails die **SMTP**-Parameter in den Kontoeinstellungen manuell eingeben müssen, verwenden Sie die folgenden Werte:

**SMTP-Konfiguration**

<Region zones={['eu']}>
- **Server ausgehend**: smtp.mail.ovh.net **oder** ssl0.ovh.net
- **Benutzername**: Geben Sie die **vollständige** E-Mail-Adresse ein.
- **Passwort**: Geben Sie das Passwort des E-Mail-Accounts ein.
- **Port**: 465
- **Sicherheitstyp**: SSL/TLS
</Region>

<Region zones={['ca', 'apac']}>
- **Server ausgehend**: smtp.mail.ovh.ca
- **Benutzername**: Geben Sie die **vollständige** E-Mail-Adresse ein.
- **Passwort**: Geben Sie das Passwort des E-Mail-Accounts ein.
- **Port**: 465
- **Sicherheitstyp**: SSL/TLS
</Region>

:::info
**Konfiguration ändern**

Wenn Ihr E-Mail-Account mit **IMAP** konfiguriert ist und Sie diese Konfiguration in **POP** ändern möchten, müssen der Account gelöscht und als **POP** neu erstellt werden. Lesen Sie den Abschnitt "[Vorhandene Einstellungen ändern](#modify-settings)" in dieser Anleitung.
:::
