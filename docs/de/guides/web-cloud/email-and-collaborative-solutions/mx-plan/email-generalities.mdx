## Ziel

Mit der MX Plan Lösung verfügen Sie über E-Mail-Adressen, mit denen Sie Nachrichten von einem Gerät Ihrer Wahl aus versenden und empfangen können.

**Diese Anleitung erklärt, wie Sie Ihr MX Plan Angebot verwenden.**

<Region zones={['eu']}>

:::warning
Bei MX Plan ist es nicht möglich, von einer E-Mail-Technologie zu einer anderen zu wechseln (zum Beispiel zwischen Roundcube, OWA und Zimbra). Die Ihrem Service zugewiesene E-Mail-Technologie ist festgelegt und kann nicht geändert werden.
:::

</Region>

### Eine E-Mail-Adresse erstellen <a name="create-email"></a>

Um zu erfahren, wie Sie eine E-Mail-Adresse erstellen, klicken Sie auf den Tab für die von Ihrem MX Plan Dienst verwendete E-Mail-Technologie:

<ZoneTabs>
  <Tab label="Roundcube" availableIn={['eu']}>
    Gehen Sie zum Erstellen einer E-Mail-Adresse auf den Tab <code className="action">E-Mails</code>. Das angezeigte Fenster listet die bereits erstellten Konten auf. Um einen neuen E-Mail-Account hinzuzufügen, klicken Sie auf <code className="action">Einen Account hinzufügen</code>.
    
    <img className="thumbnail" alt="email" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-generalities/mxplan-starter-new-step2.png" loading="lazy" />

Geben Sie im angezeigten Fenster die angeforderten Informationen ein:
    
    - **Kontoname**: Geben Sie Ihre neue E-Mail-Adresse ein (z.B. Vorname.Name). Der Domainname der E-Mail-Adresse ist bereits in der Liste vorausgewählt.
    - **Account-Beschreibung**: Informationen zur E-Mail-Adresse, die nur in der Tabelle im Tab <code className="action">E-Mails</code> Ihres E-Mail-Dienstes angezeigt werden.
    - **Account-Größe**: Legen Sie die Größe fest, die Sie dem E-Mail-Account zuweisen möchten.
    - **Passwort**: [Passwort festlegen](/guides/account-and-service-management/account-information/manage-ovh-password) und bestätigen Sie dieses. Aus Sicherheitsgründen empfehlen wir Ihnen, nicht zweimal das gleiche Passwort zu verwenden, sondern ein Passwort auszuwählen, das keinen Bezug zu Ihren persönlichen Daten hat (vermeiden Sie zum Beispiel Ihren Namen, Vornamen und Ihr Geburtsdatum) und dieses regelmäßig zu erneuern.
    
    Nachdem Sie die Felder ausgefüllt haben, klicken Sie auf <code className="action">Weiter</code> und überprüfen Sie die Informationen in der Übersicht. Sind diese korrekt, klicken Sie auf <code className="action">Bestätigen</code>. Führen Sie diesen Schritt so oft wie nötig aus, abhängig von der Anzahl der verfügbaren Accounts.
    
    <img className="thumbnail" alt="email" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-generalities/mxplan-creation-new-step3-roundcube.png" loading="lazy" />
  </Tab>
  <Tab label="Zimbra und OWA" availableIn={['eu']}>
    Gehen Sie zum Erstellen einer E-Mail-Adresse auf den Tab <code className="action">E-Mail-Accounts</code>. Das angezeigte Fenster listet die bereits verfügbaren Accounts sowie die Accounts auf, die Sie noch erstellen können. Um einen neuen E-Mail-Account hinzuzufügen, klicken Sie auf <code className="action">Einen Account hinzufügen</code>.
    
    <img className="thumbnail" alt="email" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-generalities/mxplan-starter-new-step2.png" loading="lazy" />

Geben Sie im angezeigten Fenster die angeforderten Informationen ein:
    
    - **E-Mail-Account**: Ein temporärer Name ist bereits im Textfeld eingegeben: Löschen Sie ihn und geben Sie Ihre neue E-Mail-Adresse an (z.B. Vorname.Name). Der Domainname der E-Mail-Adresse ist bereits in der Liste vorausgewählt.
    - **Vorname**: Geben Sie einen Vornamen ein.
    - **Name**: Geben Sie einen Namen ein.
    - **Anzeigename**: Geben Sie den Namen an, der als Absender angezeigt werden soll, wenn E-Mails mit dieser Adresse gesendet werden.
    - **Passwort**: [Passwort festlegen](/guides/account-and-service-management/account-information/manage-ovh-password) und bestätigen Sie dieses. Aus Sicherheitsgründen empfehlen wir Ihnen, nicht zweimal das gleiche Passwort zu verwenden, sondern ein Passwort auszuwählen, das keinen Bezug zu Ihren persönlichen Daten hat (vermeiden Sie zum Beispiel Ihren Namen, Vornamen und Ihr Geburtsdatum) und dieses regelmäßig zu erneuern.
    - **Quota**: Legen Sie die Größe fest, die Sie dem E-Mail-Account zuweisen möchten.
    
    Nachdem Sie die Felder ausgefüllt haben, klicken Sie auf <code className="action">Weiter</code> und überprüfen Sie die Informationen in der Übersicht. Sind diese korrekt, klicken Sie auf <code className="action">Bestätigen</code>. Führen Sie diesen Schritt so oft wie nötig aus, abhängig von der Anzahl der verfügbaren Accounts.
    
    <img className="thumbnail" alt="email" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-generalities/mxplan-starter-new-step3.png" loading="lazy" />
  </Tab>
</ZoneTabs>


### E-Mail-Adressen verwenden <a name="consult-emails"></a>

Sobald Ihre E-Mail-Adressen angelegt sind, können Sie mit deren Verwendung beginnen. Hierzu haben Sie zwei Möglichkeiten: Webmail über einen Webbrowser oder einen E-Mail-Client verwenden.

#### Webmail verwenden <a name="consult-emails-webmail"></a>

Gehen Sie auf die Seite "[Webmail Login](https://www.ovhcloud.com/de/mail/)" und geben Sie die betreffende E-Mail-Adresse sowie das zugehörige Passwort ein. Klicken Sie dann auf den Button <code className="action">Verbinden</code>.

Wählen Sie den Tab für die E-Mail-Technologie Ihres MX Plan Angebots aus:

<ZoneTabs>
  <Tab label="Roundcube" availableIn={['eu']}>
    Sie sollten ein Interface erhalten, das dem folgenden Bild ähnelt, mit dem Vermerk "Roundcube" oben links.  
    Weitere Informationen zum Roundcube Interface und dessen Verwendung finden Sie in unserer Anleitung "[Roundcube Webmail-Adresse verwenden](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-roundcube)".
    
    <img className="thumbnail" alt="email" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-generalities/mxplan-webmail-roundcube01.png" loading="lazy" />
  </Tab>
  <Tab label="Zimbra" availableIn={['eu']}>
    Wie in der Abbildung unten wird ein Fenster mit dem Zusatz "Zimbra" oben links angezeigt.  
    Weitere Informationen zur Verwendung Ihrer E-Mail-Adresse mit Zimbra finden Sie in unserer Anleitung "[Zimbra Webmail verwenden](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-zimbra)".
    
    <img className="thumbnail" alt="email" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-generalities/mxplan-webmail-zimbra01.png" loading="lazy" />

    Weitere Informationen zur Verwendung Ihrer E-Mail-Adresse mit OWA finden Sie in unserer Anleitung "[E-Mail-Adresse über Outlook Web App (OWA) verwenden](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/email-owa)".

### Weiterleitungen und Alias <a name="redirection-alias"></a>

Sie möchten Ihre E-Mails an einen anderen Empfänger weiterleiten, einen Alias erstellen oder systematisch eine andere E-Mail-Adresse kopieren?

Klicken Sie hierzu auf den Tab für Ihre E-Mail-Technologie:

<ZoneTabs>
  <Tab label="Roundcube" availableIn={['eu']}>
    Um eine Weiterleitung oder einen Alias hinzuzufügen, klicken Sie auf den Tab <code className="action">E-Mails</code> Ihres MX Plan Dienstes und dann rechts auf <code className="action">Weiterleitungsverwaltung</code>.  
    Die Tabelle der bereits aktiven Weiterleitungen wird angezeigt. Rechts klicken Sie auf den Button <code className="action">Weiterleitung hinzufügen</code>, um mit der Erstellung Ihrer Weiterleitung oder Ihres Alias zu beginnen.
    
    - `Von Adresse`: Geben Sie hier die E-Mail-Adresse ein, die Sie weiterleiten möchten.<br/>
    - `Zur Adresse`: Geben Sie hier die Zieladresse Ihrer Weiterleitung ein. Dies kann eine Ihrer OVHcloud E-Mail-Adressen oder eine externe E-Mail-Adresse sein.<br/>
    - `Wählen Sie einen Kopiermodus`: Legen Sie fest, ob Sie eine Kopie der empfangenen E-Mail an der Ziel-E-Mail-Adresse (`Von Adresse`) aufbewahren oder direkt an die Weiterleitungsadresse (`An Adresse`) ohne Kopie weiterleiten möchten.
    
    Die Verwendung der Weiterleitungen und Alias für Ihren MX Plan Dienst können Sie unserer vollständigen Anleitung entnehmen: "[E-Mail-Weiterleitungen verwenden](/guides/web-cloud/email-and-collaborative-solutions/common-email-features/feature-redirections)".
  </Tab>
  <Tab label="OWA und Zimbra" availableIn={['eu']}>
    Wenn Sie sich auf einer **OWA** oder **Zimbra** Technologie befinden, gibt es zwei Möglichkeiten:
    
    1. **Weiterleitung über Webmail erstellen**: Über Posteingangsregeln oder Filter. Diese Regeln, die beim Empfang einer E-Mail angewendet werden, erlauben es, eine E-Mail weiterzuleiten oder weiterzuleiten. Folgen Sie hierzu unserer Anleitung "[Posteingangsregeln über das OWA-Interface](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/creating-inbox-rules-in-owa-mx-plan)" oder unter "Filter" unserer Anleitung "[Zimbra Webmail verwenden](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-zimbra)".
    
    2. **Weiterleitung und Alias über Ihr OVHcloud Kundencenter erstellen**: Um eine Weiterleitung oder einen Alias hinzuzufügen, klicken Sie auf den Tab <code className="action">Weiterleitungen</code>. Die Tabelle der bereits aktiven Weiterleitungen wird angezeigt. Rechts klicken Sie auf den Button <code className="action">Weiterleitung hinzufügen</code>.
    
    - `Von Adresse`: Geben Sie hier die E-Mail-Adresse ein, die Sie weiterleiten möchten.<br/>
    - `Zur Adresse`: Geben Sie hier die Zieladresse Ihrer Weiterleitung ein. Dies kann eine Ihrer OVHcloud E-Mail-Adressen oder eine externe E-Mail-Adresse sein.<br/>
    - `Wählen Sie einen Kopiermodus`: Legen Sie fest, ob Sie eine Kopie der empfangenen E-Mail an der Ziel-E-Mail-Adresse (`Von Adresse`) aufbewahren oder direkt an die Weiterleitungsadresse (`An Adresse`) ohne Kopie weiterleiten möchten.
    
    Weitere Informationen zur Verwendung von Weiterleitungen und Alias für Ihren MX Plan Dienst finden Sie in unserer Anleitung: "[E-Mail-Weiterleitungen verwenden](/guides/web-cloud/email-and-collaborative-solutions/common-email-features/feature-redirections)".
  </Tab>
</ZoneTabs>


### Automatische Antwort <a name="autoreply"></a>

Sie können für Abwesenheiten eine automatische Antwort einrichten, um anzuzeigen, dass Sie Ihre E-Mails nicht einsehen oder verarbeiten können.

Wählen Sie den Tab für die E-Mail-Technologie Ihres MX Plan Angebots aus:

<ZoneTabs>
  <Tab label="Roundcube" availableIn={['eu']}>
    Um eine automatische Antwort auf eine Ihrer E-Mail-Adressen hinzuzufügen, klicken Sie in Ihrem MX Plan Dienst auf <code className="action">E-Mails</code> und dann rechts auf <code className="action">Verwaltung der automatischen Antworten</code>.  
    Die Tabelle der bereits aktiven Auto-Antworten wird angezeigt. Rechts klicken Sie auf den Button <code className="action">Eine Auto-Antwort hinzufügen</code>, um Ihre Weiterleitung oder Ihren Alias zu erstellen.
    
    Weitere Informationen zur Einrichtung einer automatischen Antwort von Ihrem MX Plan Dienst aus in Ihrem OVHcloud Kundencenter finden Sie in unserer Anleitung "[MX Plan - Eine automatische Antwort auf eine E-Mail-Adresse erstellen](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/feature-auto-responses)".
  </Tab>
  <Tab label="Zimbra" availableIn={['eu']}>
    Die Einrichtung einer automatischen Antwort erfolgt direkt über die Verbindung mit der E-Mail-Adresse über das Webmail. Weitere Informationen finden Sie in unserer Anleitung "[Zimbra Webmail verwenden](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-zimbra)" unter "Automatische Antworten".
  </Tab>
  <Tab label="OWA">
    Die Einrichtung einer automatischen Antwort erfolgt direkt über die Verbindung mit der E-Mail-Adresse über das Webmail. Weitere Informationen finden Sie in unserer Anleitung "[E-Mail-Adresse über Outlook Web App (OWA) verwenden](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/email-owa)" unter "Automatische Antwort hinzufügen".
  </Tab>
</ZoneTabs>
