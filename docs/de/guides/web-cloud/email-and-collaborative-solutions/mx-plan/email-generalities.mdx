## Ziel

Mit der MX Plan Lösung verfügen Sie über E-Mail-Adressen, mit denen Sie Nachrichten von einem Gerät Ihrer Wahl aus versenden und empfangen können.

**Diese Anleitung erklärt, wie Sie Ihr MX Plan Angebot verwenden.**

<Region zones={['eu']}>

:::warning
Bei MX Plan ist es nicht möglich, von einer E-Mail-Technologie zu einer anderen zu wechseln (zum Beispiel zwischen Roundcube, OWA und Zimbra). Die Ihrem Service zugewiesene E-Mail-Technologie ist festgelegt und kann nicht geändert werden.
:::

</Region>

### Eine E-Mail-Adresse erstellen <a name="create-email"></a>

Um zu erfahren, wie Sie eine E-Mail-Adresse erstellen, klicken Sie auf den Tab für die von Ihrem MX Plan Dienst verwendete E-Mail-Technologie:

<ZoneTabs>
  <Tab label="Roundcube" availableIn={['eu']}>
    Um eine E-Mail-Adresse zu erstellen, klicken Sie auf den Tab <code className="action">E-Mail-Account</code>. Die Tabelle listet die bereits erstellten Accounts auf. Um einen neuen E-Mail-Account hinzuzufügen, klicken Sie oberhalb der Tabelle auf den Button <code className="action">Den Account hinzufügen</code>.
    
    <img className="thumbnail" alt="Tab E-Mail-Account eines MX Plan Dienstes mit dem Button Den Account hinzufügen oberhalb der Tabelle" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-creation/console/mxplan-creation-legacy-step2.png" loading="lazy" />

Geben Sie im angezeigten Panel **Den Account hinzufügen** die angeforderten Informationen ein:
    
    - **Kontoname**: Geben Sie den Teil der Adresse vor dem "@" ein (z.B. Vorname.Name); der Domainname wird bereits hinter dem Feld angezeigt. Der Name muss zwischen 2 und 32 Zeichen lang sein, ohne Leerzeichen und Akzente; nur die Zeichen ".", "-" und "_" sind erlaubt.
    - **Beschreibung**: Optionale Information zur E-Mail-Adresse, die nur in der Spalte **Beschreibung** der Tabelle im Tab <code className="action">E-Mail-Account</code> angezeigt wird.
    - **Kontogröße**: Wählen Sie die Größe aus, die Sie dem E-Mail-Account zuweisen möchten.
    - **Passwort**: [Legen Sie ein Passwort fest](/guides/account-and-service-management/account-information/manage-ovh-password) oder generieren Sie eines mit dem Schlüssel-Symbol rechts neben dem Feld. Das Passwort muss zwischen 9 und 30 Zeichen lang sein und darf keine Akzentzeichen enthalten. Aus Sicherheitsgründen empfehlen wir Ihnen, nicht zweimal das gleiche Passwort zu verwenden, sondern ein Passwort auszuwählen, das keinen Bezug zu Ihren persönlichen Daten hat (vermeiden Sie zum Beispiel Ihren Namen, Vornamen und Ihr Geburtsdatum) und dieses regelmäßig zu erneuern.
    
    Nachdem Sie die Felder ausgefüllt haben, klicken Sie auf <code className="action">Hinzufügen</code>. Führen Sie diesen Schritt so oft wie nötig aus, abhängig von der Anzahl der verfügbaren Accounts.
    
    <img className="thumbnail" alt="Panel Den Account hinzufügen, geöffnet im Tab E-Mail-Account eines MX Plan Dienstes" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-creation/console/mxplan-creation-legacy-step3.png" loading="lazy" />
  </Tab>
  <Tab label="Zimbra und OWA" availableIn={['eu']}>
    Um eine E-Mail-Adresse zu erstellen, klicken Sie auf den Tab <code className="action">E-Mail-Account</code>. Die Tabelle listet die bereits erstellten Accounts auf. Um einen neuen E-Mail-Account hinzuzufügen, klicken Sie auf den Button <code className="action">Den Account hinzufügen</code>.
    
Geben Sie im angezeigten Panel **Den Account hinzufügen** die angeforderten Informationen ein:
    
    - **E-Mail-Adresse**: Geben Sie Ihre neue E-Mail-Adresse an (z.B. Vorname.Name). Der Domainname wird bereits hinter dem Feld angezeigt.
    - **Vorname**: Geben Sie einen Vornamen ein.
    - **Name**: Geben Sie einen Namen ein.
    - **Anzeigename**: Geben Sie den Namen an, der als Absender angezeigt werden soll, wenn E-Mails mit dieser Adresse gesendet werden.
    - **Account-Größe**: Wählen Sie die Größe aus, die Sie dem E-Mail-Account zuweisen möchten.
    - **Passwort**: [Legen Sie ein Passwort fest](/guides/account-and-service-management/account-information/manage-ovh-password). Das Passwort muss mindestens 10 Zeichen lang sein und 1 Ziffer, 1 Sonderzeichen (`$`, `!`, `&`, …) sowie 1 Großbuchstaben enthalten. Aus Sicherheitsgründen empfehlen wir Ihnen, nicht zweimal das gleiche Passwort zu verwenden, sondern ein Passwort auszuwählen, das keinen Bezug zu Ihren persönlichen Daten hat (vermeiden Sie zum Beispiel Ihren Namen, Vornamen und Ihr Geburtsdatum) und dieses regelmäßig zu erneuern.
    
    Nachdem Sie die Felder ausgefüllt haben, klicken Sie auf <code className="action">Hinzufügen</code>. Führen Sie diesen Schritt so oft wie nötig aus, abhängig von der Anzahl der verfügbaren Accounts.
  </Tab>
</ZoneTabs>


### E-Mail-Adressen verwenden <a name="consult-emails"></a>

Sobald Ihre E-Mail-Adressen angelegt sind, können Sie mit deren Verwendung beginnen. Hierzu haben Sie zwei Möglichkeiten: Webmail über einen Webbrowser oder einen E-Mail-Client verwenden.

### Weiterleitungen und Alias <a name="redirection-alias"></a>

Sie möchten Ihre E-Mails an einen anderen Empfänger weiterleiten, einen Alias erstellen oder systematisch eine andere E-Mail-Adresse kopieren?

Klicken Sie hierzu auf den Tab für Ihre E-Mail-Technologie:

<ZoneTabs>
  <Tab label="Roundcube" availableIn={['eu']}>
    Um eine Weiterleitung oder einen Alias hinzuzufügen, klicken Sie auf den Tab <code className="action">Weiterleitungen</code> Ihres MX Plan Dienstes.
    Die Tabelle der bereits aktiven Weiterleitungen wird angezeigt. Klicken Sie oberhalb der Tabelle auf den Button <code className="action">Weiterleitung erstellen</code>.
    
    - **Von der Adresse**: Geben Sie die E-Mail-Adresse an, die Sie weiterleiten möchten.
    - **An die Adresse**: Geben Sie die Zieladresse Ihrer Weiterleitung an. Dies kann eine Ihrer OVHcloud E-Mail-Adressen oder eine externe E-Mail-Adresse sein.
    - **Lokale Kopie behalten**: Setzen Sie diesen Haken, wenn Sie eine Kopie der empfangenen E-Mail an der ursprünglichen Adresse (**Von der Adresse**) behalten möchten. Andernfalls wird die E-Mail nur an die Zieladresse (**An die Adresse**) weitergeleitet.
    
    Nachdem Sie die Felder ausgefüllt haben, klicken Sie auf <code className="action">Erstellen</code>.
    
    Um zu verstehen, wie Sie Weiterleitungen und Aliasse in Ihrem MX Plan Dienst verwenden, lesen Sie unsere ausführliche Anleitung: "[E-Mail Alias und Weiterleitung verwenden](/guides/web-cloud/email-and-collaborative-solutions/common-email-features/feature-redirections)".
  </Tab>
  <Tab label="OWA und Zimbra" availableIn={['eu']}>
    Wenn Sie die Technologie **OWA** oder **Zimbra** verwenden, haben Sie zwei Möglichkeiten:
    
    1. **Weiterleitung über Webmail erstellen**: Verwenden Sie die Posteingangsregeln oder Filter des Webmails, die eine E-Mail bei Eingang weiterleiten oder umleiten. Folgen Sie unserer Anleitung "[Posteingangsregeln in OWA erstellen](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/creating-inbox-rules-in-owa-mx-plan)" oder lesen Sie den Abschnitt "[Filter](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-zimbra#filters)" unserer Anleitung "[Zimbra Webmail verwenden](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-zimbra)".
    
    2. **Weiterleitung oder Alias über die OVHcloud Konsole erstellen**: Um eine Weiterleitung oder einen Alias hinzuzufügen, klicken Sie auf den Tab <code className="action">Weiterleitungen</code>. Die Tabelle der bereits aktiven Weiterleitungen wird angezeigt. Klicken Sie oberhalb der Tabelle auf den Button <code className="action">Weiterleitung erstellen</code>.
    
        - **Von der Adresse**: Geben Sie die E-Mail-Adresse an, die Sie weiterleiten möchten.
        - **An die Adresse**: Geben Sie die Zieladresse Ihrer Weiterleitung an. Dies kann eine Ihrer OVHcloud E-Mail-Adressen oder eine externe E-Mail-Adresse sein.
        - **Lokale Kopie behalten**: Setzen Sie diesen Haken, wenn Sie eine Kopie der empfangenen E-Mail an der ursprünglichen Adresse (**Von der Adresse**) behalten möchten. Andernfalls wird die E-Mail nur an die Zieladresse (**An die Adresse**) weitergeleitet.
    
        Nachdem Sie die Felder ausgefüllt haben, klicken Sie auf <code className="action">Erstellen</code>.
    
    Um zu verstehen, wie Sie Weiterleitungen und Aliasse in Ihrem MX Plan Dienst verwenden, lesen Sie unsere ausführliche Anleitung: "[E-Mail Alias und Weiterleitung verwenden](/guides/web-cloud/email-and-collaborative-solutions/common-email-features/feature-redirections)".
  </Tab>
</ZoneTabs>


### Automatische Antwort <a name="autoreply"></a>

Sie können für Abwesenheiten eine automatische Antwort einrichten, um anzuzeigen, dass Sie Ihre E-Mails nicht einsehen oder verarbeiten können.

Wählen Sie den Tab für die E-Mail-Technologie Ihres MX Plan Angebots aus:

<ZoneTabs>
  <Tab label="Roundcube" availableIn={['eu']}>
    Um eine automatische Antwort für eine Ihrer E-Mail-Adressen hinzuzufügen, klicken Sie auf den Tab <code className="action">Automatische Antworten</code> Ihres MX Plan Dienstes.
    Die Tabelle der bereits erstellten automatischen Antworten wird angezeigt. Klicken Sie oberhalb der Tabelle auf den Button <code className="action">Autoresponder hinzufügen</code>.
    
    Weitere Informationen zum Einrichten einer automatischen Antwort in der OVHcloud Konsole finden Sie in unserer Anleitung "[MX Plan - Einrichten von Auto-Antworten für E-Mails](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/feature-auto-responses)".
  </Tab>
  <Tab label="Zimbra" availableIn={['eu']}>
    Richten Sie die automatische Antwort direkt im Webmail ein, indem Sie sich bei der E-Mail-Adresse anmelden. Weitere Informationen finden Sie im Abschnitt "[Automatische Antworten](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-zimbra#auto-reply)" unserer Anleitung "[Zimbra Webmail verwenden](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-zimbra)".
  </Tab>
  <Tab label="OWA">
    Richten Sie die automatische Antwort direkt im Webmail ein, indem Sie sich bei der E-Mail-Adresse anmelden. Weitere Informationen finden Sie im Abschnitt "[Eine automatische Antwort hinzufügen](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/email-owa#eine-automatische-antwort-hinzufügen)" unserer Anleitung "[E-Mail-Adresse über das Webmail Outlook Web App (OWA) verwenden](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/email-owa)".
  </Tab>
</ZoneTabs>
