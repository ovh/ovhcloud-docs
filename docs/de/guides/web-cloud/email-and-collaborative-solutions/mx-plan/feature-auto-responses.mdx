## Ziel

Mit diesem OVHcloud Feature können Sie einen Autoresponder einrichten, der automatisch Nachrichten an alle sendet, die in Ihrer Abwesenheit versuchen, Sie per E-Mail zu kontaktieren.

**Diese Anleitung erklärt, wie Sie Autoresponder für Ihre Adressen einrichten.**

## Voraussetzungen

<Region zones={['eu']}>

- Sie verfügen über einen MX Plan, als E-Mail-Dienst enthalten in einem [OVHcloud Webhosting-Angebot](/links/web/hosting) oder [Kostenloses Hosting](/links/web/domains-free-hosting), oder als eigenständige Lösung bestellbar.

</Region>

- Sie verfügen über einen MX Plan, als E-Mail-Dienst enthalten in einem [OVHcloud Webhosting-Angebot](/links/web/hosting) oder als eigenständige Lösung bestellbar.

</Region>

### Automatische Antwort erstellen

Klicken Sie auf den Tab <code className="action">Automatische Antworten</code> Ihres MX Plan Dienstes. Die Tabelle listet die eingerichteten automatischen Antworten auf.

Klicken Sie oberhalb der Tabelle auf den Button <code className="action">Autoresponder hinzufügen</code>.

<img className="thumbnail" alt="Tab Automatische Antworten eines MX Plan Dienstes mit dem Button Autoresponder hinzufügen oberhalb der Tabelle" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-auto-responses/console/email_responder01.png" loading="lazy" />

Füllen Sie im Panel **Autoresponder hinzufügen** die folgenden Felder aus:

- **E-Mail-Konto**: Die E-Mail-Adresse oder der Alias, auf die bzw. den sich die automatische Antwort bezieht. Wählen Sie eine bestehende E-Mail-Adresse Ihres E-Mail-Dienstes aus oder geben Sie im Fall eines Alias einen freien Namen ein: Der Autoresponder ist dann nicht mit einer bestehenden Adresse verknüpft. Der Domainname wird rechts neben dem Feld angezeigt.
- **Dauer des Autoresponders**:
    - **Temporär**: Legen Sie ein Start- (**Ab dem**) und Enddatum (**Bis zum**) mit Uhrzeit fest, in dem die automatische Antwort aktiv sein soll (z.B. nützlich, wenn Sie in den Urlaub fahren).
    - **Permanent**: Die automatische Antwort bleibt aktiv, bis Sie sie löschen oder auf **Temporär** umstellen.
- **Eine Kopie senden** (freier Name) oder **Nachrichten auf dem Server behalten** (bestehende E-Mail-Adresse): Mit diesem Kontrollkästchen wählen Sie, ob während Ihrer Abwesenheit empfangene Nachrichten an eine Adresse Ihrer Wahl weitergeleitet oder auf der E-Mail-Adresse aufbewahrt werden.

:::warning
Wenn Sie dieses Kontrollkästchen deaktivieren, werden während Ihrer Abwesenheit empfangene Nachrichten automatisch gelöscht.

:::


- **Kopie-Adresse** (nur bei einem freien Namen, wenn das Kontrollkästchen **Eine Kopie senden** aktiviert ist): Wählen Sie in der Liste die E-Mail-Adresse Ihres Angebots aus, die die an den Alias gesendeten E-Mails erhält.
- **Nachricht**: Dies ist die Nachricht, die Ihre Korrespondenten erhalten, wenn sie Ihnen eine E-Mail senden. Verfassen Sie sie nur mit lateinischen Zeichen: Andere Zeichen funktionieren im Autoresponder nicht.

Klicken Sie anschließend auf <code className="action">Hinzufügen</code>. Ihr Autoresponder ist innerhalb von 5 bis 10 Minuten verfügbar.

:::tip
Wenn Sie die Verwaltung einer automatischen Antwort für einen E-Mail-Account delegieren möchten, lesen Sie unsere Anleitung "[MX Plan - Die Verwaltung Ihrer E-Mail-Accounts einer anderen Person übertragen](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/feature-delegation)".

:::


### Automatische Antwort bearbeiten oder löschen

Nachdem Ihre automatische Antwort erstellt wurde, wird sie in der Tabelle des Tabs <code className="action">Automatische Antworten</code> Ihres MX Plan Dienstes angezeigt. Um sie zu ändern oder zu löschen, klicken Sie rechts davon auf den Button <code className="action">⋮</code> und dann auf <code className="action">Bearbeiten</code> oder <code className="action">Löschen</code>.

<img className="thumbnail" alt="⋮-Menü eines Autoresponders im Tab Automatische Antworten mit den Einträgen Bearbeiten und Löschen" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-auto-responses/console/email_responder02.png" loading="lazy" />

Im Panel **Autoresponder bearbeiten** können Sie die Dauer, die Daten und die Nachricht der automatischen Antwort ändern, nicht jedoch das zugehörige E-Mail-Konto. Klicken Sie auf <code className="action">Bearbeiten</code>, um Ihre Änderungen zu speichern.

Um sie zu löschen, klicken Sie im Fenster **Automatische Antwort löschen** auf <code className="action">Löschen</code>: Diese Aktion kann nicht rückgängig gemacht werden.
