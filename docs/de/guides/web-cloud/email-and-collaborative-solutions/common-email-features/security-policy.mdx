## Ziel

Mit den E-Mail-Diensten von OVHcloud können Sie professionelle E-Mail-Adressen erstellen. Um diese Umgebung zu sichern, können Sie die globalen Sicherheitseinstellungen für Ihre E-Mails-Accounts verwalten.

**Diese Anleitung erläutert die Sicherheitseinstellungen Ihres E-Mail-Dienstes.**

## Voraussetzungen

- Sie verfügen über einen [OVHcloud E-Mail-Dienst](/links/web/emails).

[[cpnav:web-email-pro+web-mx-plan+web-exchange]]

## In der praktischen Anwendung

Über die Sicherheitseinstellungen Ihres E-Mail-Dienstes können Sie die folgenden vier Aktionen ausführen:

- Sicherheit der E-Mail-Accounts bei Login-Versuchen der Benutzer erhöhen
- Komplexität der Account-Passwörter Ihres E-Mail-Dienstes erhöhen
- Überprüfung von auf unseren Servern eingehenden Nachrichten zu Ihren E-Mail-Adressen verschärfen (nur für [Exchange](/links/web/emails-hosted-exchange) Accounts)
- festlegen, wie "unerwünschte" Nachrichten (Spam-Mails) in Ihren Posteingängen angezeigt werden (nur für [Exchange](/links/web/emails-hosted-exchange) Accounts)

Um auf die Sicherheitseinstellungen Ihres E-Mail-Dienstes zuzugreifen, folgen Sie den nachstehenden Anweisungen.

### Sicherheit beim Login erhöhen <a name="enhanced-security"></a>

Hier können Sie festlegen, ob E-Mail-Accounts nach einer bestimmten Anzahl fehlgeschlagener Login-Versuche gesperrt werden sollen.

Klicken Sie im Bereich **Kontosicherheit** auf <code className="action">Kontosperrung bearbeiten</code>. Füllen Sie im Panel **Kontosperrung** die folgenden Felder aus:

- **Sperrschwelle**: Aktivieren Sie den Schalter und legen Sie dann die Anzahl der fehlgeschlagenen Login-Versuche fest, nach denen der Account gesperrt wird. Deaktivieren Sie ihn, wenn keine Sperrschwelle gelten soll.
- **Zurücksetzungsfrist**: Wenn eine Sperrschwelle festgelegt ist, geben Sie den Zeitraum in Minuten an, nach dem der Zähler für fehlgeschlagene Login-Versuche auf null zurückgesetzt wird.
- **Sperrdauer**: Wenn eine Sperrschwelle festgelegt ist, geben Sie den Zeitraum in Minuten an, für den der Account nach Erreichen der Schwelle gesperrt bleibt.

Klicken Sie nach Eingabe dieser Informationen auf <code className="action">Speichern</code>.

### Komplexität der Passwörter erhöhen <a name="password-complexity"></a>

Hier legen Sie Komplexitätsanforderungen und Regeln für die Passwortänderung fest.

Klicken Sie im Bereich **Kontosicherheit** auf <code className="action">Passwortrichtlinie bearbeiten</code>. Aktivieren Sie im Panel **Passwortrichtlinie** den Schalter jeder Einstellung, die angewendet werden soll, und füllen Sie die folgenden Felder aus:

- **Anforderungen an die Komplexität**: Hiermit legen Sie Regeln für die Komplexität der Passwörter fest:
    - Das Passwort darf den Namen des Benutzeraccounts weder ganz noch teilweise enthalten.
    - Es muss mindestens 6 Zeichen lang sein.
    - Es muss Zeichen aus mindestens 3 der folgenden 4 Kategorien enthalten: Großbuchstaben, Kleinbuchstaben, Ziffern und Sonderzeichen (zum Beispiel `!` oder `$`).
- **Änderung verhindern**: Hiermit legen Sie eine Mindestgültigkeit für die Passwörter Ihrer E-Mail-Accounts fest. Die Benutzer müssen eine bestimmte Anzahl von Tagen warten, bevor sie ihr Passwort ändern können.
- **Maximale Gültigkeitsdauer**: Hiermit legen Sie eine maximale Gültigkeitsdauer für die Passwörter Ihrer E-Mail-Accounts fest. Die Benutzer müssen ihr Passwort ändern, sobald diese Frist erreicht ist.
- **Verlauf beibehalten** (nur Exchange): Wenn eine maximale Gültigkeitsdauer festgelegt ist, geben Sie die Anzahl der vorherigen Passwörter an, die nicht erneut verwendet werden dürfen.
- **Mindestlänge**: Hiermit legen Sie eine Mindestlänge für Passwörter fest, die gilt, wenn ein Benutzer sein Passwort ändert.

Bei MX Plan heißen diese Einstellungen **Komplexität erforderlich**, **Mindestalter begrenzen**, **Maximales Alter begrenzen** und **Mindestlänge erforderlich**.

Klicken Sie nach Eingabe dieser Informationen auf <code className="action">Speichern</code>.

### Überprüfung von eingehenden Nachrichten verschärfen (nur Exchange) <a name="incoming-messages-verification"></a>

Sie können festlegen, ob auf Ihren E-Mail-Accounts eingehende Nachrichten auf einen legitimen Absender überprüft werden sollen (Überprüfung der DKIM- und/oder SPF-Signatur).

Klicken Sie im Tab <code className="action">Einstellungen</code> Ihres Exchange Dienstes auf den Bereich <code className="action">Nachrichtensicherheit</code>, um ihn zu erweitern, und dann auf <code className="action">Eingehende Nachrichten ändern</code>. Aktivieren Sie im Panel **Eingehende Nachrichten** die gewünschten Kontrollkästchen:

- **Überprüfung der DKIM-Signatur aktivieren**: Legen Sie fest, ob unsere Server die DKIM-Signatur der Nachrichten prüfen sollen, die Sie auf Ihren Exchange Accounts erhalten. Diese Aktion garantiert die Authentizität der Absenderdomain und die Integrität der Nachricht und kann dabei helfen, nicht legitime Sendungen zu erkennen, die dann als Spam markiert werden.
- **Überprüfung des SPF-Schutzes aktivieren**: Legen Sie fest, ob unsere Server prüfen sollen, dass die Quelle der Nachrichten, die Sie erhalten, im SPF-Eintrag der Absenderdomain enthalten ist. Diese Überprüfung kann dabei helfen, nicht legitime Sendungen zu erkennen, die dann als Spam markiert werden.

Klicken Sie nach Ihrer Auswahl auf <code className="action">Speichern</code>.

### Anzeige von Spam-Mails festlegen (nur Exchange) <a name="unwanted-messages-management"></a>	

Sie können festlegen, ob auf Ihren E-Mail-Accounts eingehende Spam-Mails einen Tag erhalten sollen, über den sie als solche identifiziert werden können, oder ob sie direkt in den Spam-Ordner verschoben werden.

Erweitern Sie bei Bedarf den Bereich <code className="action">Nachrichtensicherheit</code> und klicken Sie dann auf <code className="action">Spam-Nachrichten ändern</code>. Aktivieren Sie im Panel **Spam-Nachrichten** die gewünschten Kontrollkästchen:

- **Spam-Nachrichten kennzeichnen.**: Legen Sie fest, ob unsere Server ein Tag hinzufügen sollen, mit dem als "unerwünscht" eingestufte Nachrichten als Spam gekennzeichnet werden.
- **Spam-Nachrichten in den Papierkorb verschieben.**: Legen Sie fest, ob unsere Server als "unerwünscht" eingestufte Nachrichten automatisch in den Papierkorb verschieben sollen.

Klicken Sie nach Ihrer Auswahl auf <code className="action">Speichern</code>.
