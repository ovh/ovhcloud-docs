## Ziel

Die OVHcloud Angebote für **Microsoft 365 Apps for Business** und **Microsoft 365 Apps for Enterprise** bieten mehrere Vorteile. Die Abrechnung erfolgt monatlich und Sie können eine Lizenz für 5 PCs/Macs, 5 Tablets und 5 Smartphones verwenden.

Ihre Microsoft 365 Lizenzen werden zu einer Gruppe zusammengefasst, auch "Service" genannt. Eine *Apps for Business* Lizenzgruppe kann maximal 300 Lizenzen enthalten, eine Lizenzgruppe *Apps for Enterprise* ist unbegrenzt.

Die Lizenzen gelten für folgende Software:

- Apps for Business: Excel, Word, PowerPoint, Outlook, OneNote, Publisher.
- Apps for Enterprise: Excel, Word, PowerPoint, Outlook, OneNote, Publisher, Access.

**Diese Anleitung erklärt, wie Sie eine Microsoft 365 Lizenz bestellen und in der OVHcloud Konsole verwalten.**

## In der praktischen Anwendung

### Lizenz bestellen

1. Rufen Sie die [Microsoft 365 Verkaufsseite](/links/web/ms365) auf. Sie können sie auch über den Bereich Microsoft 365 der OVHcloud Konsole öffnen: Klicken Sie auf <code className="action">Bestellen</code> (<code className="action">Einen Microsoft 365-Dienst bestellen</code>, wenn Sie noch keinen Microsoft 365-Dienst besitzen) und anschließend auf <code className="action">Bestellen</code> im Bereich **Microsoft 365** der Seite **Einen Microsoft 365-Dienst bestellen**. Die Seite wird in einem neuen Tab geöffnet.
1. Wählen Sie aus unseren verfügbaren Angeboten "Apps for Business" und "Apps for Enterprise".
1. Legen Sie das Erneuerungsintervall für Ihre Lizenzgruppe fest.
1. Legen Sie die Anzahl der gewünschten Lizenzen fest und schließen Sie Ihre Bestellung ab.

### Lizenz aktivieren

So aktivieren Sie die bestellte Lizenz:

1. Wählen Sie den betreffenden Microsoft 365-Dienst aus.
1. Klicken Sie auf den Tab <code className="action">Lizenzen</code>.
1. Klicken Sie auf den Button <code className="action">⋮</code> rechts neben der zu aktivierenden Lizenz und anschließend auf <code className="action">Bearbeiten</code>.

    <img className="thumbnail" alt="Geöffnetes Menü ⋮ einer nicht konfigurierten Lizenz, Option Bearbeiten" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-office/office-csp1/console/Outlook-cps1-01.png" loading="lazy" />

1. Geben Sie die Daten des Lizenznutzers ein (**Vorname**, **Nachname** und **Anmeldename**) und klicken Sie auf <code className="action">Speichern</code>.

    <img className="thumbnail" alt="Fenster Benutzer bearbeiten mit den Feldern Vorname, Nachname und Anmeldename" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-office/office-csp1/console/Outlook-cps1-02.png" loading="lazy" />

### Installieren von Microsoft 365 Suite <a name="install365"></a>

Sobald die Lizenz aktiviert ist, erhalten Sie eine E-Mail an die Kontakt-E-Mail-Adresse Ihres OVHcloud Kunden-Accounts. Sie finden diese E-Mail auch in der <ManagerLink to="/">OVHcloud Konsole</ManagerLink>: Klicken Sie oben rechts auf den Button mit Ihren Initialen und dann auf <code className="action">Meine Kommunikation</code>. Suchen Sie im standardmäßig angezeigten Tab **Nachrichten** nach der E-Mail, deren Betreff "Ein neuer Microsoft Office Benutzer wurde erstellt" enthält.

Diese E-Mail enthält die zum Herunterladen und Installieren Ihrer Microsoft 365 Suite erforderlichen Informationen, nämlich **die E-Mail-Adresse für die Aktivierung** und das **Kennwort**.

Gehen Sie auf [https://portal.office.com/](https://portal.office.com/) und melden Sie sich mit der zuvor erhaltenen **E-Mail-Adresse** und dem **Passwort** an. Sie werden zu einem Fenster weitergeleitet, in dem Sie die Microsoft 365 Suite auf Ihren Computer herunterladen können, mit Installationsanweisungen.

<img className="thumbnail" alt="Office-Portal, geöffnetes Menü Office installieren, Option Premium Office apps" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-office/office-csp1/Outlook-cps1-04.png" loading="lazy" />

#### Installation von Microsoft 365 Suite auf mehreren Geräten

Mit einer Lizenz kann der Benutzer die Microsoft 365 Suite auf **5x Windows oder macOS**, **5 Tablets** und **5 Smartphones** installieren. Das sind insgesamt **15 Geräte** für eine Lizenz. Alle diese Geräte müssen Eigentum des Lizenznehmers sein.

Um Ihre Lizenz auf mehreren Geräten zu installieren, wiederholen Sie [den vorherigen Schritt](#install365) **auf jedem Gerät**. Jedes Gerät muss **vom selben Benutzer** verwaltet werden.

### Passwort einer Lizenz ändern

Wenn Sie das Passwort Ihrer Lizenz selbst festlegen möchten:

1. Wählen Sie den betreffenden Microsoft 365-Dienst aus.
1. Klicken Sie auf den Tab <code className="action">Lizenzen</code>.
1. Klicken Sie auf den Button <code className="action">⋮</code> rechts neben der betreffenden Lizenz und anschließend auf <code className="action">Passwort ändern</code>.

    <img className="thumbnail" alt="Geöffnetes Menü ⋮ einer Lizenz mit dem Status Aktiv, Option Passwort ändern" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-office/office-csp1/console/Outlook-cps1-03.png" loading="lazy" />

1. Wählen Sie auf der Seite **Passwort ändern** entweder **Passwort automatisch generieren** und geben Sie die **Benachrichtigungs-E-Mail** an, oder **Passwort manuell festlegen** und geben Sie das **Passwort** ein. Klicken Sie anschließend auf <code className="action">Speichern</code>.

### Lizenz zu einer bestehenden Gruppe hinzufügen

So fügen Sie einer bestehenden Gruppe Lizenzen hinzu:

1. Wählen Sie den betreffenden Microsoft 365-Dienst aus und klicken Sie auf den Tab <code className="action">Lizenzen</code>.
1. Klicken Sie oberhalb der Tabelle auf den Button <code className="action">Lizenzen bestellen</code>.
1. Wählen Sie im Fenster **Lizenzen bestellen** den **Produkttyp** aus, geben Sie die **Menge** der Lizenzen an und klicken Sie auf <code className="action">Bestellen</code>. Sie werden zum Bestellschein weitergeleitet: Sobald die Zahlung erfolgt ist, kehren Sie in den Tab <code className="action">Lizenzen</code> zurück, um Ihre neuen Benutzer zu konfigurieren.

    <img className="thumbnail" alt="Fenster Lizenzen bestellen mit den Feldern Produkttyp und Menge" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-office/office-csp1/console/Outlook-cps1-05.png" loading="lazy" />

Bei einer Lizenzgruppe vom Typ **Pay as you go** wird der Button <code className="action">Lizenzen bestellen</code> durch <code className="action">Benutzer bestellen</code> ersetzt. Er öffnet eine Seite mit demselben Namen: Geben Sie **Vorname**, **Nachname**, **Anmeldename** und **Lizenztyp** an und klicken Sie auf <code className="action">Speichern</code>.

### Abonnements verwalten <a name="managesubscriptions"></a>

#### Lizenz aus einer Lizenzgruppe entfernen

Klicken Sie im Tab <code className="action">Lizenzen</code> Ihrer Lizenzgruppe auf den Button <code className="action">⋮</code> rechts neben der Lizenz, die Sie löschen möchten, und anschließend auf <code className="action">Löschen</code>. Klicken Sie im Fenster **Benutzer löschen** erneut auf <code className="action">Löschen</code>, um zu bestätigen.

<img className="thumbnail" alt="Geöffnetes Menü ⋮ einer Lizenz mit dem Status Aktiv, Option Löschen" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-office/office-csp1/console/Outlook-cps1-06.png" loading="lazy" />

:::warning
Der Benutzer wird unmittelbar nach Ihrer Bestätigung gelöscht.

:::

:::info
Der Verbrauch des laufenden Monats wird am Ende des laufenden Monats abgerechnet.

:::


### Lizenzgruppe kündigen

So kündigen Sie Ihre Microsoft 365 Lizenzgruppe (CSP1):

1. Klicken Sie oben rechts in der OVHcloud Konsole auf den Button mit Ihren Initialen.
1. Klicken Sie auf <code className="action">Meine Angebote und Dienste</code>.
1. Identifizieren Sie Ihre Lizenzgruppe in der Tabelle, zum Beispiel indem Sie ihren Namen in das Feld **Suchen** eingeben.
1. Klicken Sie in der Spalte **Aktionen** in der Zeile der Lizenzgruppe, die Sie kündigen möchten, auf den Button <code className="action">⋮</code> und anschließend auf <code className="action">Meinen Dienst kündigen</code>.
1. Geben Sie im Fenster **Dienst kündigen** den Grund für die Kündigung an und klicken Sie auf <code className="action">Kündigen</code>.

:::warning
Sie verlieren alle mit diesem Dienst verbundenen Daten.

:::

:::info
Der Verbrauch des laufenden Monats wird am Ende des laufenden Monats abgerechnet.

:::
