## Ziel

Office 365 Reseller (CSP2) ist ein Dienst, mit dem Sie verschiedene Arten von Microsoft 365 Lizenzen zu Sonderpreisen erwerben können, um diese Ihren Kunden anzubieten.

**Diese Anleitung erklärt, wie Sie einen Office 365 Reseller Dienst (CSP2) über die OVHcloud Konsole abonnieren und verwalten.**

## Voraussetzungen

- Sie verfügen über eine [MPN ID](https://learn.microsoft.com/de-de/partner-center/mpn-create-a-partner-center-account) (Microsoft Partner Network IDentifier). 
- Sie sind im Microsoft CSP (Cloud Solutions Provider) Programm als "indirekter Reseller" in der Region angemeldet, in der Sie aktiv sind (zum Beispiel: "EU" für Europa).

:::warning
Seit dem 01.07.2022 werden alle Office 365 Reseller Dienstleistungen (CSP2), die nicht über eine im Programm "CSP indirect reseller" eingetragene MPN ID verfügen, von Microsoft deaktiviert.

Eine MPN ID ist für jede Neubestellung notwendig.

:::


Wenn Sie noch nicht über eine MPN ID verfügen, können Sie eine erstellen (sofern Sie die Bedingungen von Microsoft erfüllen), indem Sie diese offizielle Dokumentation von Microsoft befolgen: "[Was ist das Microsoft Cloud Partner Program?](https://learn.microsoft.com/de-de/partner-center/mpn-create-a-partner-center-account)".

Um sich dann als indirekter Reseller anzumelden, lesen Sie die Microsoft Dokumentation "[Sich als indirekter Vertriebspartner registrieren](https://learn.microsoft.com/de-de/partner-center/enrolling-in-the-csp-program#enroll-as-an-indirect-reseller)".

:::tip
Mit der MPN ID können Sie *Cashback*-Erstattungen zu den Abonnements erhalten, die Sie über die OVHcloud Konsole bestellen. Dieses Erstattungsverfahren unterliegt den von Microsoft festgelegten Regeln, abhängig von der Anzahl der von Ihnen erstellten Abonnements.

:::


## In der praktischen Anwendung

### Office 365 Reseller bestellen

Klicken Sie im Bereich Microsoft 365 der OVHcloud Konsole auf <code className="action">Bestellen</code> (<code className="action">Einen Microsoft 365-Dienst bestellen</code>, wenn Sie noch keinen Microsoft 365-Dienst besitzen) und anschließend auf der Seite **Einen Microsoft 365-Dienst bestellen** im Abschnitt **Microsoft 365 Reseller** auf <code className="action">Bestellen</code>. Die Bestellung erfolgt in 3 Schritten:

1. Geben Sie im Abschnitt **Reseller information** Ihre zuvor bei Microsoft erstellte MPN ID im Feld **Microsoft partner ID** ein und klicken Sie dann auf <code className="action">Next</code>.

    <img className="thumbnail" alt="Bestellseite Microsoft 365 Reseller, Feld Microsoft partner ID" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-office/office-csp2/console/csp2-01.png" loading="lazy" />

1. Wählen Sie im Abschnitt **Platform configuration and end customer information** die Option **New platform** oder, wenn Ihre Plattform bereits bei Microsoft existiert, **Delegation of a platform previously created at Microsoft**. Bei einer Delegation nehmen Sie zunächst die Partnerschaftsanfrage über den Link <code className="action">Consent form</code> an und füllen dann das Feld **Existing Office 365 tenant (Delegation only)** aus. Vervollständigen Sie in beiden Fällen die Kontaktinformationen des Endkunden (Land, Postleitzahl, Vorname, Nachname und E-Mail-Adresse): Diese werden angefordert, um die Verwaltung der Lizenzgruppe (*Tenant*) zu definieren.

    - *Optional*: Für eine neue Plattform können Sie eine personalisierte **Subdomain** definieren (unter Vorbehalt der verfügbaren Namen). Aktivieren Sie die Option **I want a custom subdomain** und geben Sie die Subdomain dann im Feld **Enter your subdomain** ein. Andernfalls wird eine generische Subdomain in der Form `bizofficeXXX.onmicrosoft.com` erstellt.

    Klicken Sie anschließend auf <code className="action">Next</code>.

1. Wählen Sie im Abschnitt **Select your licenses** die Lizenzen aus, die Sie in Ihre Gruppe integrieren möchten, geben Sie deren Anzahl an und klicken Sie dann auf <code className="action">Continue my order</code>: Die Bestellung wird in einem neuen Tab abgeschlossen.

:::warning
Bitte überprüfen Sie die Gültigkeit der bei der Erstellung Ihrer Lizenzgruppe angegebenen E-Mail-Adresse, da diese für den Empfang der Login-Daten für die Microsoft Plattform verwendet wird.

:::

:::info
Rufen Sie nach der Bestellung das Microsoft 365 Verwaltungsportal auf, um den Vertrag mit Microsoft (Microsoft Customer Agreement, MCA) zu bestätigen. Ihre Lizenzen werden nach dieser Bestätigung bereitgestellt.

:::

:::warning
Bei lizenzierten Produkten ist es nicht möglich, einen Office 365 Reseller *Tenant* zwischen OVHcloud Kunden zu übertragen. Es ist notwendig, das Abonnement für den ursprünglichen OVHcloud Kunden-Account zu beenden und die gleiche Lizenz dann für den neuen OVHcloud Kunden-Account zu bestellen.

:::


### Office 365 Reseller Dienste verwalten

Sobald der Dienst verfügbar ist, wählen Sie ihn im Bereich Microsoft 365 der OVHcloud Konsole aus (Typ **Reseller**).

Der Tab **Übersicht**, der beim Öffnen des Dienstes angezeigt wird, enthält folgende Angaben:

- **Anzeigename des Dienstes**: Er dient als Titel der Seite. Um ihn zu personalisieren, klicken Sie auf das Stiftsymbol rechts neben dem Titel, geben Sie den neuen Namen ein und bestätigen Sie.
- **Referenz des Dienstes** (Abschnitt **Allgemeine Informationen**): Interner Name Ihres Dienstes, nur in der OVHcloud Konsole sichtbar. Er entspricht auch dem *Tenant* bei Microsoft.
- **MPN ID** (Abschnitt **Allgemeine Informationen**): Ihre Microsoft Partner-Kennung. Um sie zu ändern, klicken Sie auf das Stiftsymbol rechts daneben, geben Sie die neue Kennung ein (6 oder 7 Ziffern) und bestätigen Sie.
- **Erstellungsdatum** (Abschnitt **Mein Angebot**): Erstellungsdatum des Dienstes.

Der Tab <code className="action">Lizenzen</code> zeigt außerdem:

- **Microsoft administration portal**: Link zur Office Verwaltungsoberfläche, über die Sie Ihre Abonnements verwalten können.
- Die Verwaltung des Administratorpassworts Ihres Microsoft *Tenant* erfolgt direkt über das Microsoft Verwaltungsinterface. Lesen Sie hierzu auch [die Microsoft Dokumentation](https://support.microsoft.com/de-de/account-billing/zur%C3%BCcksetzen-eines-vergessenen-kennworts-f%C3%BCr-ihr-microsoft-konto-eff4f067-5042-c1a3-fe72-b04d60556c37).
- Die Verwaltung zusätzlicher Domainnamen erfolgt auch über das Verwaltungsinterface von Microsoft. Erfahren Sie mehr in der [offiziellen Microsoft Dokumentation](https://support.microsoft.com/de-de/office/hinzuf%C3%BCgen-ihrer-dom%C3%A4ne-zu-office-365-cd74b4fa-6d34-4669-9937-ed178ac84515).

Der Tab <code className="action">Aufgaben</code> listet die Vorgänge Ihres Dienstes und deren Status auf.

:::info
Wenn Sie das Microsoft Customer Agreement (MCA) noch nicht akzeptiert haben, akzeptieren Sie es im Microsoft 365 Verwaltungsportal und klicken Sie dann im Tab **Übersicht** auf <code className="action">I have approved the MCA</code>.

:::

### Ihre Abos verwalten

Sie können die Anzahl der Lizenzen Ihrer Abonnements ändern oder diese kündigen. Der Tab <code className="action">Lizenzen</code> Ihres Dienstes zeigt sie in einer Tabelle:

- **ID**: Jeder Typ einer bestellten Lizenz verfügt über eine eindeutige Kennung (ID).
- **Status**: Zeigt den Status Ihrer Lizenz.
- **License name**: Gibt die Art der abonnierten Lizenz an.
- **Number of licenses**: Gibt die Anzahl der verfügbaren Lizenzen an.
- **Creation date**: Gibt das Erstellungsdatum des Abonnements für den ausgewählten Lizenztyp an.
- **Last update**: Gibt das Datum an, an dem das Abonnement zuletzt aktualisiert wurde (z. B. durch Hinzufügen einer Lizenz).

Um die Gesamtzahl der Lizenzen eines Abonnements zu ändern, klicken Sie rechts neben dem Abonnement auf den Button <code className="action">⋮</code> und dann auf <code className="action">Change quantity</code>. Geben Sie im Fenster **Edit subscription** die **New number of licenses** an und klicken Sie dann auf <code className="action">Speichern</code>. Zusätzliche Lizenzen werden Ihnen ab dem Speichern in Rechnung gestellt.

Um das Abonnement und alle zugehörigen Lizenzen zu kündigen, klicken Sie rechts neben dem Abonnement auf den Button <code className="action">⋮</code> und dann auf <code className="action">Delete subscription</code>. Klicken Sie im Fenster **Delete subscription — …** erneut auf <code className="action">Delete subscription</code>, um zu bestätigen.

Um einen Lizenztyp zu abonnieren, den Sie noch nicht besitzen, klicken Sie oberhalb der Tabelle auf <code className="action">New subscription</code>. Wählen Sie im Fenster **Add a new subscription** den **License type** aus, geben Sie die **Number of licenses** an und klicken Sie dann auf <code className="action">Speichern</code>.

:::info
Für Office 365 Education sind besondere Lizenzbedingungen von Microsoft einzuhalten. Die entsprechenden offiziellen Dokumente stehen Ihnen je nach Region und Sprache in der [Microsoft Lizenzdokumentation](https://www.microsoft.com/licensing/docs) zur Verfügung.

:::

### Benutzer verwalten

Sobald Sie über eine ausreichende Anzahl an Lizenzen verfügen, müssen Sie die Benutzer verwalten, die diese verwenden. Dieser Schritt erfolgt direkt über das [Verwaltungsportal von Microsoft](https://portal.office.com/Admin/Default.aspx).

Um sich dort einzuloggen, geben Sie Ihre Kundenkennung und das Passwort ein, das Sie in der Bestätigungsmail von OVHcloud zur Installation Ihrer Lizenzgruppe erhalten haben. Diese Informationen werden an die bei der Erstellung der Lizenzgruppe angegebene Adresse versandt.
