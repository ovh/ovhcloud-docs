## Ziel

Die auf dieser Seite gelisteten Details beziehen sich auf die Versionen von **PHP**, **Python**, **Perl** und **Apache**, die mit [Web Hosting](/links/web/hosting) Diensten verwendet werden.

**Diese Anleitung enthält Informationen zu PHP-, Python-, Perl- und Apache-Versionen.**

## Voraussetzungen

- Sie verfügen über ein [OVHcloud Webhosting](/links/web/hosting).

## In der praktischen Anwendung

Die folgenden Tabellen zeigen die Versionen der Programmiersprachen, die in den OVHcloud Webhosting-Lösungen verfügbar sind, und ihren Status. Jede Version verweist auf ihre Informationsseite, die die vollständige Versionsnummer und die Konfiguration angibt.

### Status der Versionen

<span style={{backgroundColor:"#198754", color:"white", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Unterstützt</span>: Version, die in den Webhosting-Lösungen gepflegt wird.

<span style={{backgroundColor:"#ffc107", color:"#212529", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>End-of-Life</span>: Migrieren Sie vor dem End-of-Life bei OVHcloud auf eine unterstützte Version.

<span style={{backgroundColor:"#dc3545", color:"white", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Veraltet</span>: Version, die nicht mehr gepflegt wird; migrieren Sie auf eine unterstützte Version.
