## Ihr Webhosting absichern

Schützen Sie Ihre Website und ihre Besucher: Aktivieren Sie die HTTPS-Verschlüsselung mit einem SSL-Zertifikat, richten Sie eine Web Application Firewall ein und wenden Sie bewährte Sicherheitspraktiken auf Ihrem OVHcloud Webhosting an. Diese Seite vereint alle Anleitungen, um Ihre Website abzusichern.

Um die passende Anleitung für Ihren Bedarf zu finden:

- **Sicherheit der Website** (Best Practices, Web Application Firewall): Beginnen Sie mit dem Abschnitt *Website absichern*.
- **SSL-Zertifikat und HTTPS** (ein Zertifikat verwalten, auf HTTPS umstellen): Siehe Abschnitt *SSL-Zertifikat und HTTPS*.
- **Ein SSL-Zertifikat auswählen** (kostenloses Let's Encrypt, Sectigo DV/EV, eigenes Zertifikat): Siehe Abschnitt *SSL-Zertifikat aktivieren*.

## SSL-Zertifikat aktivieren

Wählen Sie den für Ihre Website passenden Zertifikatstyp und folgen Sie der entsprechenden Anleitung.

<Tabs>
  <Tab label="Let's Encrypt (kostenlos)">

Kostenloses SSL-Zertifikat, das mit Ihrem Webhosting verfügbar ist.

[Kostenloses Let's Encrypt SSL-Zertifikat aktivieren](/guides/web-cloud/web-hosting/ssl-letsencrypt)

  </Tab>
  <Tab label="Sectigo DV">

Sectigo-Zertifikat mit Domain-Validierung (Domain Validation), gültig für einen Domainnamen und seine "www"-Subdomain.

[Sectigo DV SSL-Zertifikat aktivieren](/guides/web-cloud/web-hosting/ssl-dv)

  </Tab>
  <Tab label="Sectigo EV">

Sectigo-Zertifikat mit erweiterter Validierung (Extended Validation), gültig für einen Domainnamen und seine "www"-Subdomain.

[Sectigo EV SSL-Zertifikat aktivieren](/guides/web-cloud/web-hosting/ssl-ev)

  </Tab>
  <Tab label="Eigenes Zertifikat">

Um Ihr eigenes SSL-Zertifikat zu importieren, wenn keine der OVHcloud-Lösungen Ihren Anforderungen entspricht.

[Eigenes SSL-Zertifikat installieren](/guides/web-cloud/web-hosting/ssl-custom)

  </Tab>
</Tabs>
