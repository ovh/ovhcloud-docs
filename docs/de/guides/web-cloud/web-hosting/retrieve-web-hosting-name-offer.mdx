## Ziel

Sie können sich nicht mehr an den Namen Ihres [Webhostings](/links/web/hosting) erinnern?
Möchten Sie dessen Details prüfen oder mit einem anderen Angebot vergleichen?

Während der Nutzung Ihres Services könnten Sie den Namen Ihres Webhosting Angebots benötigen.

**Erfahren Sie, wie Sie den Typ des Webhostings identifizieren können, den Sie über die OVHcloud Konsole nutzen.**

## Voraussetzungen

- Sie haben ein [OVHcloud Webhosting](/links/web/hosting).

[[cpnav:web-hosting]]

## In der praktischen Anwendung

Klicken Sie auf die Tabs, um die **2** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Suchen Sie im Tab <code className="action">Übersicht</code> den Abschnitt **Abonnement**. Der Name Ihres Webhosting-Angebots wird dort unter **Angebot** angezeigt (zum Beispiel: Perso, Pro, Performance).

    <img className="thumbnail" alt="Abschnitt Abonnement und Name des Angebots unter Angebot" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/subscription-card.png" loading="lazy" />
  </Tab>
</Tabs>
