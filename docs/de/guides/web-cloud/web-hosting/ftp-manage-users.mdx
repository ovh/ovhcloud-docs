## Ziel

Die OVHcloud Webhostings bieten Zugriff auf einen FTP-Speicherplatz. Mit diesem FTP-Bereich können Sie zum Beispiel die Dateien Ihrer Websites oder Anwendungen online stellen. Auf diesen können Sie über einen FTP- oder SSH-Benutzer und das zugehörige Passwort zugreifen. Beispielsweise können Sie mehrere FTP-Zugänge für Ihre Mitarbeiter erstellen.

**Diese Anleitung erklärt, wie Sie FTP-Benutzer auf Ihrem OVHcloud Webhosting erstellen, ändern und löschen.**

:::info
Diese Anleitung gilt nur für Webhostings der Reihen **Pro**, **Performance**, **Agency**, **Agency Plus** und **Agency Max**. Nur bei diesen Angeboten können mehrere FTP-Benutzer aktiviert werden.

:::

## Voraussetzungen

- Sie verfügen über ein kompatibles [OVHcloud Webhosting](/links/web/hosting).

## In der praktischen Anwendung

### Einen neuen FTP-Benutzer auf Ihrem Webhosting erstellen <a name="create-ftp-user"></a>

Um einen neuen FTP-Benutzer auf Ihrem Webhosting über die OVHcloud Konsole zu erstellen, klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Tab FTP-SSH eines Webhostings" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie im Abschnitt **FTP- und SSH-Benutzer** auf <code className="action">Benutzer erstellen</code>.

    <img className="thumbnail" alt="Bereich zur Erstellung eines FTP-Benutzers in der Konsole" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/create-user.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Der Bereich **Benutzer erstellen** öffnet sich und fasst alle Einstellungen auf einer einzigen Seite zusammen:

    - **Benutzer**: der Name, mit dem sich Ihr Mitarbeiter einloggt. Ihm wird **immer der FTP-Hauptlogin Ihres Webhostings, gefolgt von einem Bindestrich, vorangestellt**: Wenn dieser Login `ftplogin` lautet und Sie `user1` eingeben, lautet die vollständige Kennung `ftplogin-user1`. Der von Ihnen hinzugefügte Name umfasst 1 bis 12 alphanumerische Zeichen;
    - **Stammverzeichnis**: das Verzeichnis, in dem dieser Benutzer arbeiten kann. **Lassen Sie dieses Feld leer, um Zugriff auf den gesamten Speicherplatz zu gewähren**; andernfalls geben Sie ein Verzeichnis oder Unterverzeichnis an, zum Beispiel `www`, `blog`, `website1` oder `www/development`;
    - **Verbindungsprotokolle**: das oder die für diesen Benutzer zugelassenen Protokolle. Wenn Sie **FTP, SFTP und SSH** auswählen, kann Ihr Mitarbeiter sowohl die Dateien verwalten als auch sich über die Kommandozeile verbinden;
    - **Passwort** und **Passwort bestätigen**: Beachten Sie die unter den Feldern angezeigte Richtlinie.

    Klicken Sie abschließend auf <code className="action">Erstellen</code>.
  </Tab>
</Tabs>

:::info
Nach der Validierung der Erstellungsanfrage kann es bis zu 15 Minuten dauern, bis der neue Nutzer auf Ihrem Webhosting registriert ist.

:::

Testen Sie bei Bedarf diesen neuen FTP-Benutzer mithilfe unserer Anleitung "[Mit dem FTP-Speicherplatz eines Webhostings verbinden](/guides/web-cloud/web-hosting/ftp-connection)".

### FTP-Benutzer bearbeiten

Klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Tab FTP-SSH eines Webhostings" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Der Abschnitt **FTP- und SSH-Benutzer** listet die auf Ihrem Webhosting erstellten Benutzer auf. Klicken Sie in der Spalte **Aktionen** rechts neben dem betreffenden Benutzer auf den Button <code className="action">⋮</code> und dann auf <code className="action">Bearbeiten</code>.

    <img className="thumbnail" alt="Menü Aktionen eines FTP-Benutzers in der Konsole" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Der Bereich **Benutzer bearbeiten** öffnet sich. Drei Einstellungen sind verfügbar:

    - **Stammverzeichnis**: das Verzeichnis, in dem dieser Benutzer arbeiten kann. Lassen Sie dieses Feld leer, um ihm Zugriff auf den gesamten Speicherplatz zu gewähren;
    - **Benutzer deaktivieren**: Aktivieren Sie dieses Kästchen, um einem Mitarbeiter den Zugriff auf Ihren FTP-Speicherplatz zu verwehren, **ohne die mit ihm verbundenen FTP- und SSH-Logs zu löschen**. Mithilfe dieser Logs können Sie feststellen, welche Operationen er durchgeführt hat, wenn Sie unerwünschte Eingriffe auf Ihrem Webhosting feststellen;
    - **Verbindungsprotokolle**: das oder die für diesen Benutzer zugelassenen Protokolle. Details zu den Protokollen finden Sie im Abschnitt "[Einen neuen FTP-Benutzer auf Ihrem Webhosting erstellen](#create-ftp-user)" weiter oben in dieser Anleitung.

    :::info
    Das **Stammverzeichnis** des **Hauptkontos** kann nicht geändert werden: Das Feld bleibt ausgegraut und die Konsole zeigt die Meldung "Das Stammverzeichnis des Hauptkontos kann nicht geändert werden." an. Nur die von Ihnen erstellten Benutzer können es ändern.
    :::

    Der Benutzername und das Passwort können hier nicht geändert werden. Um das Passwort zu ändern, verwenden Sie den Eintrag <code className="action">Passwort ändern</code> im selben Menü, der in unserer Anleitung "[Passwort eines FTP-Benutzers ändern](/guides/web-cloud/web-hosting/ftp-change-password)" beschrieben ist.

    <img className="thumbnail" alt="Bereich zur Bearbeitung eines FTP-Benutzers" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user.png" loading="lazy" />

    Klicken Sie abschließend auf <code className="action">Bestätigen</code>.
  </Tab>
</Tabs>

:::info
Wenn Sie nur das Passwort des FTP-Benutzers ändern möchten, lesen Sie unsere Anleitung "[Passwort eines FTP-Benutzers ändern](/guides/web-cloud/web-hosting/ftp-change-password)".

Wenn Sie den FTP-Benutzernamen ändern möchten, ist es erforderlich, [einen neuen FTP-Benutzer mit dem gewünschten Benutzernamen zu erstellen](#create-ftp-user). Anschließend können Sie bei Bedarf [den alten FTP-Benutzer löschen](#delete-ftp-user).

:::

### FTP-Benutzer löschen <a name="delete-ftp-user"></a>

Klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Tab FTP-SSH eines Webhostings" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie in der Spalte **Aktionen** des Abschnitts **FTP- und SSH-Benutzer** rechts neben dem betreffenden Benutzer auf den Button <code className="action">⋮</code> und dann auf <code className="action">Löschen</code>.
    <img className="thumbnail" alt="Menü Aktionen eines FTP-Benutzers in der Konsole" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Ein Fenster fordert Sie unter Angabe der betreffenden Kennung zur Bestätigung auf. Klicken Sie auf <code className="action">Löschen</code>, um diesen Benutzer endgültig von Ihrem Webhosting zu entfernen.

    <img className="thumbnail" alt="Bestätigungsfenster zum Löschen eines FTP-Benutzers" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/delete-user-confirmation.png" loading="lazy" />
  </Tab>
</Tabs>
