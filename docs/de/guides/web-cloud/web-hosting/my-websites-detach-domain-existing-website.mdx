## Ziel

Sie können mehrere Websites auf derselben Webhosting Angebot nutzen, selbst wenn die Domainnamen nicht bei OVHcloud registriert sind. Zudem können Sie einen oder mehrere Domainnamen oder Subdomains derselben Website zuordnen.

Möchten Sie einen Domainnamen oder eine Subdomain nicht länger für Ihre Website verwenden?  
Möchten Sie Ihren Domainnamen oder Ihre Subdomain einer anderen Website auf einem Ihrer Webhostings zuordnen?  

**Diese Anleitung erklärt, wie Sie einen Domainnamen oder eine Subdomain von einer bereits existierenden Website auf Ihrem Webhosting trennen können.**

## Voraussetzungen

- Sie haben ein kompatibles [OVHcloud Webhosting](https://www.ovhcloud.com/de/web-hosting/uc-multisite/).
- Sie verfügen über einen oder mehrere [Domainnamen](https://www.ovhcloud.com/de/domains/).
- Sie haben die erforderlichen Berechtigungen zur Verwaltung der [DNS-Zonen Ihrer Domainnamen](/guides/web-cloud/domains/dns-zone-edit).

[[cpnav:web-hosting]]

## In der praktischen Anwendung

:::warning
Das Trennen eines Domainnamens oder einer Subdomain von einer Website auf Ihrem Webhosting ist eine sensible Aktion. Nach dieser Operation wird Ihre Website nicht mehr über das Internet mit Ihrem Domainnamen und/oder Subdomain zugänglich sein.

:::

Klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Meine Websites</code>. Klicken Sie in der Tabelle in der Spalte **Aktionen** rechts neben der betreffenden Website auf den Button <code className="action">⋮</code> und dann in der Gruppe **Domainnamen** auf <code className="action">Meine Domains verwalten</code>.

    <img className="thumbnail" alt="Aktionsmenü einer Website" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Der Bereich **Meine Domains verwalten** öffnet sich rechts und listet die mit dieser Website verknüpften Domainnamen und Subdomains auf. Klicken Sie bei derjenigen, die Sie trennen möchten, rechts neben ihrem Namen auf den Button <code className="action">⋮</code> und dann auf <code className="action">Trennen</code>.

    <img className="thumbnail" alt="Bereich Meine Domains verwalten und Aktionsmenü einer Domain" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/manage-domains-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Das Fenster **Eine Domain trennen** wird angezeigt und fordert Sie auf, Ihre Wahl zu bestätigen. Es enthält zwei Einstellungen:

    <img className="thumbnail" alt="Fenster Eine Domain trennen" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/detach-domain-dialog.png" loading="lazy" />

    - **Die Subdomain ebenfalls trennen**, gefolgt von der betreffenden Subdomain `www`: Dieses standardmäßig deaktivierte Kästchen trennt sie gleichzeitig mit dem Domainnamen, sofern sie ebenfalls auf dieser Website deklariert ist. Die DNS-Zone dieser Subdomain und alle ihre Optionen werden dann gelöscht.
    - <code className="action">Die Verweis-Einträge (A und AAAA) in der DNS-Zone des Domainnamens löschen.</code>: Dieses standardmäßig aktivierte Kästchen entfernt die Einträge, die auf Ihr Webhosting verweisen, aus der DNS-Zone. Deaktivieren Sie es, wenn Sie diese Einträge behalten möchten.

    Klicken Sie abschließend auf <code className="action">Bestätigen</code>.

    :::warning
    **Sonderfall: Ihre Website ist mit einem Git-Repository verknüpft**

    Das Fenster zeigt dann eine Warnung und ein zusätzliches Kästchen an, <code className="action">Ja, meine Git-Konfiguration löschen</code>. Der Button <code className="action">Bestätigen</code> bleibt inaktiv, bis Sie es aktiviert haben: Das Trennen des Domainnamens löscht gleichzeitig die [Git-Verknüpfung](/guides/web-cloud/web-hosting/git-integration-webhosting) der Website.

    <img className="thumbnail" alt="Fenster Eine Domain trennen bei einer mit Git verknüpften Website" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/detach-domain-git.png" loading="lazy" />

    :::
  </Tab>
</Tabs>

### Besonderer Fall: Trennen eines Domainnamens oder einer Subdomain, um sie mit einer anderen Website zu verwenden

- Falls Sie Ihren Domainnamen oder Ihre Subdomain einer anderen bestehenden Website auf einem Webhosting hinzufügen möchten, konsultieren Sie [diese Anleitung](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).
- Falls Sie eine neue Website auf einem Webhosting mit Ihrem kürzlich getrennten Domainnamen oder Subdomain erstellen möchten, konsultieren Sie [diese Anleitung](/guides/web-cloud/web-hosting/multisites-configure-multisite).
