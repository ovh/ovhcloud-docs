## Ziel  

Secure Socket Layer (SSL) Zertifikate erlauben es, Verbindungen von oder zu Ihrer Website zu verschlüsseln. So wird verhindert, dass unbefugte Personen oder Bots auf ausgehende und eingehende Anfragen von Ihrer Website zugreifen können.

OVHcloud bietet verschiedene Arten von SSL-Zertifikaten für die [Webhostings](/links/web/hosting) an, wie in unserer Anleitung "[SSL-Zertifikat auf einem Webhosting verwalten](/guides/web-cloud/web-hosting/ssl-on-webhosting)" beschrieben. SSL-Zertifikate sind für die Sicherheit Ihrer Website unentbehrlich.

Es gibt drei Arten von SSL-Zertifikaten:

- Domain Validation (DV)
- Organisation Validation (OV)
- Extended Validation (EV)

Die SSL-Verschlüsselungsstufen sind bei diesen drei Zertifikatstypen identisch.

Der Hauptunterschied besteht in den Überprüfungen, mit denen die ausstellende Zertifikatsstelle (CA) die Legitimität verifiziert.

Let's Encrypt ist eine kostenlose, automatisierte, offene und gemeinnützige Zertifizierungsstelle. Weitere Informationen finden Sie unter [https://letsencrypt.org/de/about/](https://letsencrypt.org/de/about/).

**Diese Anleitung erklärt, wie Sie ein kostenloses SSL-Zertifikat von Let's Encrypt auf Ihrem OVHcloud Webhosting aktivieren.**

## Voraussetzungen

- Sie verfügen über ein [OVHcloud Webhosting](/links/web/hosting).
- Sie verfügen über einen [Domainnamen](/links/web/domains) und dessen exklusive Nutzungsrechte oder beabsichtigen, einen zu registrieren. Der Domainname darf nicht bereits mit einem SSL-Zertifikat verbunden sein.

:::info
Seit dem **06.08.2025** ist das Let's Encrypt SSL-Zertifikat automatisch aktiviert für:

- Alle neuen Domainnamen/Subdomains, die mit einem Webhosting verbunden sind.
- Alle neuen Abonnements eines Domainnamens mit einem neuen Webhosting.

Das Ziel ist, Ihnen bei der Konfiguration Ihrer Dienste Zeit zu sparen. Sie können das Let's Encrypt SSL-Zertifikat jederzeit über die <ManagerLink to="/beta/#/">OVHcloud Konsole</ManagerLink> deaktivieren, wenn Sie ein anderes SSL-Zertifikat installieren möchten (Sectigo DV, Sectigo EV oder ein personalisiertes SSL-Zertifikat).
Weitere Informationen finden Sie in unserer Anleitung "[SSL-Zertifikat einrichten](/guides/web-cloud/web-hosting/ssl-on-webhosting)", Teil **SSL-Zertifikat auf einem Webhosting deaktivieren**.

:::

## In der praktischen Anwendung

:::warning
**Bevor Sie fortfahren**, überprüfen Sie, dass **jeder Domainname und/oder jede Subdomain**, die von einem zukünftigen Let's Encrypt SSL-Zertifikat betroffen sind:

- Auf die IP-Adresse Ihres Webhostings verweisen.
- Auf einem der Webseiten Ihres Webhostings deklariert sind.
- Nicht bereits über ein aktives SSL-Zertifikat verfügen.

Um dies zu überprüfen, lesen Sie bei Bedarf unsere Anleitungen:

- [Mehrere Websites auf einem Webhosting einrichten](/guides/web-cloud/web-hosting/multisites-configure-multisite)
- [Webhosting - Liste der IP-Adressen pro Cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
- [Bearbeiten der OVHcloud DNS-Zone](/guides/web-cloud/domains/dns-zone-edit)
- [Webhosting - SSL-Zertifikat einrichten](/guides/web-cloud/web-hosting/ssl-on-webhosting), Teil **SSL-Zertifikat auf einem Webhosting deaktivieren**

:::

### Let's Encrypt SSL-Zertifikat aktivieren

Klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">SSL</code>.

    <img className="thumbnail" alt="Tab SSL eines Webhostings" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie oberhalb der Zertifikatstabelle auf <code className="action">Zertifikat hinzufügen</code>.
  </Tab>
  <Tab label="Schritt 4">
    Rechts öffnet sich ein Fenster. Unter **Zertifikatstyp** ist **Let's Encrypt** bereits ausgewählt: Dies ist die kostenlose, automatisch verlängerte Option mit Domainvalidierung (DV). Wählen Sie unter **Zu sichernde Domains** den oder die betreffenden Domainnamen und Subdomains aus und klicken Sie dann auf <code className="action">Aktivieren</code>.

    <img className="thumbnail" alt="Fenster Zertifikat hinzufügen mit ausgewähltem Let's Encrypt" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/enable-ssl-lets-encrypt.png" loading="lazy" />
  </Tab>
</Tabs>

Es kann mehrere Stunden dauern, bis das SSL-Zertifikat von Let's Encrypt eingerichtet ist.

### Die Aktivierung des kostenlosen SSL-Zertifikats Let's Encrypt (DV) überprüfen

Um zu überprüfen, dass die Installation abgeschlossen ist, klicken Sie auf die Tabs, um die **3** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">SSL</code>.

    <img className="thumbnail" alt="Tab SSL eines Webhostings" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Suchen Sie jeden betreffenden Domainnamen und jede Subdomain in der Spalte **Hauptdomain** und lesen Sie die zugehörige Spalte **Status**. Die Installation ist abgeschlossen, wenn dort **Aktiv** angezeigt wird; solange sie läuft, wird **Wird erstellt** angezeigt.

    <img className="thumbnail" alt="Tabelle der SSL-Zertifikate und ihre Spalte Status" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/tab.png" loading="lazy" />

Die Tabelle zeigt den Zertifikatstyp nicht an. Um ihn zu ermitteln, klicken Sie auf <code className="action">Als CSV exportieren</code>: Die erhaltene Datei enthält eine Spalte **Zertifikatstyp**.

    <img className="thumbnail" alt="Button Als CSV exportieren oberhalb der Tabelle" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/export-csv.png" loading="lazy" />
  </Tab>
</Tabs>

Ihr Let's Encrypt SSL-Zertifikat ist nun installiert und aktiv. Sie können es ab sofort mit Ihrer Website verwenden, indem Sie zum Beispiel [HTTPS für Ihre Website aktivieren](/guides/web-cloud/web-hosting/ssl-activate-https-website).
