## Ziel 

*ModSecurity* ist ein zusätzliches Apache-Modul, das alle auf Ihrem Webserver eingehenden Anfragen filtert. Es erhöht die Sicherheit gegen bekannte Schwachstellen, indem es Anfragen abfängt und filtert, bevor sie von Skripten verarbeitet werden.

Das vorkonfigurierte "Core Rule Set" (CRS) unserer *ModSecurity*, schützt Ihre Webseiten vor den häufigsten Angriffen, zum Beispiel:

- Trojaner
- E-Mail Injection
- Sicherheitslücken in PDF Dateien
- File Injections auf Ihrem Hosting
- SQL oder XSS Injection
- usw.

**Diese Anleitung erklärt, wie Sie die Application Firewall über die OVHcloud Konsole aktivieren können, um eine verbesserte Schutzfunktion zu erhalten.**

:::info
Da sich Ihr Webhosting auf einer Shared Hosting Infrastruktur befindet, ist die Änderung der Firewall-Konfigurationseinstellungen nicht verfügbar.

:::

## Voraussetzungen

- Sie haben ein [Webhosting](/links/web/hosting) in Ihrem OVHcloud Account.
- Sie verfügen über mindestens einen mit dem Hosting verbundenen [Domainnamen](/links/web/domains).

[[cpnav:web-hosting-console]]

## In der praktischen Anwendung

**Klicken Sie auf die Titel, um die Erklärungen anzuzeigen.**

<details>
<summary>Application Firewall für die gesamte Webhosting-Konfiguration in PHP aktivieren</summary>

Klicken Sie auf die Tabs, um die **3** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Das Hosting öffnet sich im Tab <code className="action">Übersicht</code>. Suchen Sie den Bereich **PHP** mit dem Eintrag **Globale PHP-Version** und klicken Sie dann auf <code className="action">PHP-Version ändern</code>.

    <img className="thumbnail" alt="Bereich PHP im Tab Übersicht" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/php-section.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Das Konfigurationsfenster öffnet sich rechts. Öffnen Sie im Bereich **Erweiterte Optionen** das Dropdown-Menü **Anwendungs-Firewall** und wählen Sie den Wert <code className="action">Sicherheit</code> aus: Er aktiviert `mod_security`, das Ihr Hosting vor gängigen Angriffen schützt. Mit dem Wert <code className="action">deaktiviert</code> bleibt die Firewall inaktiv.

    <img className="thumbnail" alt="Erweiterte Optionen der PHP-Konfiguration und Menü Anwendungs-Firewall" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/php-config-firewall.png" loading="lazy" />

    Klicken Sie abschließend auf <code className="action">Bestätigen</code>.

    :::warning
    Eine Änderung der Konfiguration kann sich auf Ihre Websites auswirken: Testen Sie diese nach jeder Änderung.
    :::
  </Tab>
</Tabs>

</details>

<details>
<summary>Application Firewall nur für einen bestimmten Domainnamen oder Subdomain aktivieren</summary>

Klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Meine Websites</code>. Klicken Sie in der Tabelle in der Spalte **Aktionen** rechts neben der betreffenden Website auf den Button <code className="action">⋮</code> und dann in der Gruppe **Domainnamen** auf <code className="action">Meine Domains verwalten</code>.

    <img className="thumbnail" alt="Menü Aktionen einer Website" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Der Bereich **Meine Domains verwalten** öffnet sich rechts und listet die mit dieser Website verbundenen Domainnamen und Subdomains auf. Klicken Sie bei der betreffenden Domain auf den Button <code className="action">⋮</code> rechts neben ihrem Namen und dann auf <code className="action">Meine Optionen verwalten</code>.

    <img className="thumbnail" alt="Bereich Meine Domains verwalten und Menü Aktionen einer Domain" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/manage-domains-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Aktivieren Sie im Fenster **Optionen verwalten** in der Gruppe **Sicherheit** das Kontrollkästchen <code className="action">Firewall aktivieren</code> und klicken Sie dann auf <code className="action">Bestätigen</code>.

    <img className="thumbnail" alt="Fenster Optionen verwalten eines Domainnamens" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/country-ip-selection.png" loading="lazy" />

    :::info
    Die Einstellung gilt nur für den ausgewählten Domainnamen bzw. die ausgewählte Subdomain. Um auch die Subdomain `www` zu schützen, wiederholen Sie den Vorgang in ihrer Zeile im Bereich **Meine Domains verwalten**, sofern sie dort deklariert ist.
    :::

    Sobald die Firewall aktiviert ist, zeigt die Spalte **Firewall** der Website-Tabelle die Anzahl der geschützten Domainnamen im Verhältnis zur Gesamtzahl der mit der Website verbundenen Domainnamen an, zum Beispiel `1/4`. Wenn sich dieser Zähler nach einigen Minuten nicht ändert, laden Sie die Seite neu.
  </Tab>
</Tabs>

</details>
