## Ziel 

*ModSecurity* ist ein zusätzliches Apache-Modul, das alle auf Ihrem Webserver eingehenden Anfragen filtert. Es erhöht die Sicherheit gegen bekannte Schwachstellen, indem es Anfragen abfängt und filtert, bevor sie von Skripten verarbeitet werden.

Das vorkonfigurierte "Core Rule Set" (CRS) unserer *ModSecurity*, schützt Ihre Webseiten vor den häufigsten Angriffen, zum Beispiel:

- Trojaner
- E-Mail Injection
- Sicherheitslücken in PDF Dateien
- File Injections auf Ihrem Hosting
- SQL oder XSS Injection

**Diese Anleitung erklärt, wie Sie die Application Firewall in Ihrem OVHcloud Kundencenter aktivieren können, um eine verbesserte Schutzfunktion zu erhalten.**

:::info
Da sich Ihr Webhosting auf einer Shared Hosting Infrastruktur befindet, ist die Änderung der Firewall-Konfigurationseinstellungen nicht verfügbar.

:::

:::info
Einige Verfahren in dieser Anleitung gelten für die <ManagerLink to="/beta/#/">neue Version des OVHcloud Kundencenters</ManagerLink>.
Eine Erinnerung wird zu Beginn jedes betreffenden Abschnitts angezeigt.

:::

## Voraussetzungen

- Sie haben ein [Webhosting](/links/web/hosting) in Ihrem OVHcloud Account.
- Sie verfügen über mindestens einen mit dem Hosting verbundenen [Domainnamen](/links/web/domains).

## In der praktischen Anwendung

**Klicken Sie auf die Titel, um die Erklärungen anzuzeigen.**

<details>
<summary>Application Firewall für die gesamte Webhosting-Konfiguration in PHP aktivieren</summary>

Klicken Sie auf die Tabs, um die **3** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/#/web/hosting">Hosting-Pakete</ManagerLink>, und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Im Feld **Konfiguration** finden Sie die Bezeichnung **Globale PHP-Version**.

    <img className="thumbnail" alt="Global PHP version" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/modify-hosting-configuration.png" loading="lazy" />

    Klicken Sie auf den Button <code className="action">...</code> rechts neben **Globale PHP-Version** und anschließend auf <code className="action">Konfiguration ändern</code>.
  </Tab>
  <Tab label="Schritt 3">
    In dem sich öffnenden Fenster wählen Sie den Eintrag <code className="action">Aktuelle Konfiguration ändern</code> aus und klicken Sie auf den Button <code className="action">Weiter</code>.

    <img className="thumbnail" alt="managephpconfig" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/application-firewall-step-2.png" loading="lazy" />

    Im neuen Fenster stellen Sie sicher, dass die Option **Application Firewall** auf <code className="action">aktiviert</code> gesetzt ist. Klicken Sie anschließend auf den Button <code className="action">Bestätigen</code>.
  </Tab>
</Tabs>

</details>

<details>
<summary>Application Firewall nur für einen bestimmten Domainnamen oder Subdomain aktivieren</summary>

Klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

:::info
Dieser Abschnitt gilt für die <ManagerLink to="/beta/#/">neue Version des OVHcloud Kundencenters</ManagerLink>.

:::

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hosting-Pakete</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Hosting-Pakete" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf der angezeigten Seite auf den Tab <code className="action">Meine Seiten</code>.

    <img className="thumbnail" alt="Meine Seiten" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Im angezeigten Tabelle klicken Sie auf den Button <code className="action">></code> links neben dem Namen der Website, um die zugehörigen Domainnamen oder Subdomains anzuzeigen.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />

    Klicken Sie anschließend auf den Button <code className="action">⁝</code> rechts neben dem gewünschten Domainnamen oder Subdomain und dann auf <code className="action">Domain bearbeiten</code>.

    <img className="thumbnail" alt="Associated domains options" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/associated-domains-options.png" loading="lazy" />

  <Tab label="Schritt 4">
    Im Konfigurationsfenster aktivieren Sie das Feld <code className="action">Firewall aktivieren</code>. Sie können auch die Subdomain `www` in diese Konfiguration einbeziehen, indem Sie das entsprechende Feld oben ankreuzen (sofern diese ebenfalls auf der gleichen Website deklariert ist).

    <img className="thumbnail" alt="Modify a domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/modify-a-domain-enable-firewall-step-1.png" loading="lazy" />

    Sobald die Firewall für Ihren Domainnamen oder Subdomain aktiviert ist, wird die Bezeichnung **Aktiviert** in der Spalte **Firewall** angezeigt.

    Falls die Bezeichnung **Aktiviert** nach einigen Minuten nicht in der entsprechenden Zeile des Domainnamens oder Subdomain angezeigt wird, laden Sie die Seite erneut.
  </Tab>
</Tabs>

</details>
