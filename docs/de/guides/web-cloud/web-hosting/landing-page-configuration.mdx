## Ihr Webhosting konfigurieren

Konfigurieren Sie alle Aspekte Ihres OVHcloud Webhostings: hosten Sie mehrere Websites, verwalten Sie die Umgebung und die PHP-Version, aktivieren Sie die inbegriffenen E-Mail-Adressen, optimieren Sie die Performance und das CDN, überwachen Sie die Logs, führen Sie das Deployment durch (Git, CRON, API) und passen Sie Ihren Tarif an. Datenbanken, FTP/SSH-Zugang, CMS und Sicherheit verfügen außerdem über eine eigene Seite.

Um die passende Anleitung für Ihren Bedarf zu finden:

- **Möchten Sie Ihre Websites konfigurieren, Ihre Domainnamen zuordnen oder die Umgebung einrichten (PHP, IPv6)?** Siehe Abschnitt *Websites, Domainname und Umgebung*.
- **Möchten Sie die Performance Ihrer Dienste verbessern oder Logs überwachen (CDN, Statistiken)?** Siehe Abschnitt *Performance, CDN und Logs*.
- **Möchten Sie das Deployment durchführen, automatisieren (Git, CRON, API) oder Ihren Tarif anpassen?** Siehe Abschnitt *Deployment, Automatisierung und Tarif*.
