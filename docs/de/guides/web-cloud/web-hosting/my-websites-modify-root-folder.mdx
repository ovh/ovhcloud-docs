## Ziel

Sie können mehrere Websites auf demselben Webhosting-Angebot hosten, auch wenn die Domainnamen nicht bei OVHcloud registriert sind. Darüber hinaus können Sie einen oder mehrere Domainnamen oder Subdomains mit derselben Website verknüpfen.

Bei der Nutzung Ihrer Dienste können Sie Folgendes benötigen:

- Den gesamten Inhalt einer bestehenden Website ersetzen, ohne sie von Ihrem Webhosting zu entfernen. Dies ohne Unterbrechung des Zugangs und in voller Transparenz für die Besucher Ihrer Website.
- Ein [1-Klick-Modul](/guides/web-cloud/web-hosting/cms-install-1-click-modules) oder ein [anderes CMS](/guides/web-cloud/web-hosting/cms-manual-installation) installieren, um den Inhalt einer bestehenden Website zu ersetzen, ohne den alten Inhalt von Ihrem Webhosting zu löschen. In diesem Fall müssen Sie anschließend die verschiedenen Seiten Ihrer neuen Website über Ihren Webbrowser erstellen.
- Die Namen der Wurzelverzeichnisse Ihrer Websites im Speicherplatz Ihres Webhostings neu organisieren, ohne den Zugang zu Ihren verschiedenen Websites zu unterbrechen.

**Erfahren Sie, wie Sie das für eine bestehende Website auf Ihrem Webhosting deklarierte Wurzelverzeichnis über Ihre OVHcloud Konsole ändern.**

:::info
Wenn Sie die betreffende Website noch nicht auf Ihrem Webhosting erstellt haben, lesen Sie **direkt** [diese Anleitung](/guides/web-cloud/web-hosting/multisites-configure-multisite).

Über die Konsole können Sie das Stammverzeichnis einer Website ändern, auch wenn sie mit einem Git-Repository verknüpft ist (lesen Sie in diesem Fall unsere Anleitung "[Konfiguration und Nutzung von Git mit OVHcloud Webhosting](/guides/web-cloud/web-hosting/git-integration-webhosting)"). Nur die Website, die die Hauptdomain Ihres Webhostings trägt, kann es nicht ändern: Das Feld ist dann ausgegraut.

:::

## Voraussetzungen

- Sie verfügen über ein kompatibles [OVHcloud Webhosting](https://www.ovhcloud.com/de/web-hosting/uc-multisite/).
- Sie verfügen über einen oder mehrere [Domainnamen](https://www.ovhcloud.com/de/domains/).

## In der praktischen Anwendung

:::warning
Diese Anleitung beschreibt ausschließlich die Aktionen, die über die <ManagerLink to="/beta/#/">OVHcloud Konsole</ManagerLink> durchzuführen sind.

Außer in dem Fall, dass Sie ein 1-Klick-Modul installieren möchten, um die Website schrittweise aufzubauen, müssen Sie vorab:

- Das neue Wurzelverzeichnis im [Speicherplatz](/guides/web-cloud/web-hosting/ftp-connection) Ihres Webhostings erstellen.
- Den gesamten neuen Inhalt Ihrer Website in dieses neue Verzeichnis einfügen.
- Wenn der neue Inhalt Ihrer Website eine Datenbank verwendet, müssen Sie auch eine [Datenbank erstellen](/guides/web-cloud/web-hosting/sql-create-database) und den [Datenbankinhalt importieren](/guides/web-cloud/web-hosting/sql-importing-mysql-database).
- Die Zugangsdaten für die Datenbank in die Datei mit den Verbindungsinformationen zur Datenbank einfügen. Diese Datei muss bereits im neuen Wurzelverzeichnis vorhanden sein.

**Ohne diese Aktionen wird die Anzeige Ihrer Website unterbrochen**.

Diese Anleitung beschreibt ausschließlich das Verfahren zur Änderung des ursprünglich für Ihre Website definierten Wurzelverzeichnisses über Ihre OVHcloud Konsole. Diese Aktion ist erforderlich, damit die Website den Inhalt des neuen Verzeichnisses anstelle des alten anzeigt.

:::

Klicken Sie auf die unten stehenden Tabs, um die **3** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Meine Websites</code>. Klicken Sie in der Tabelle in der Spalte **Aktionen** rechts neben der betreffenden Website auf den Button <code className="action">⋮</code> und dann in der Gruppe **Website** auf <code className="action">Website konfigurieren</code>.

    <img className="thumbnail" alt="Aktionsmenü einer Website" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Der Bereich **Website konfigurieren** öffnet sich rechts. Ersetzen Sie im Feld **Stammverzeichnis** das alte Stammverzeichnis durch das neue.

    <img className="thumbnail" alt="Bereich Website konfigurieren, Felder Website-Name und Stammverzeichnis" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/configure-site.png" loading="lazy" />

    :::info
    Im Bereich können Sie Ihre Website auch im Feld **Website-Name** umbenennen. Dieser Name dient nur dazu, die Website in der OVHcloud Konsole zu identifizieren, und hat keine Auswirkung auf ihre Adresse oder ihren Inhalt. Lassen Sie ihn unverändert, wenn Sie nur das Stammverzeichnis ändern möchten.
    :::

    Klicken Sie abschließend unten im Bereich auf <code className="action">Bestätigen</code>. Wenn Sie das Verzeichnis geändert haben, fasst das Fenster **Stammverzeichnis ändern** das aktuelle Verzeichnis, das neue Verzeichnis und die zugehörigen Domains zusammen: Klicken Sie erneut auf <code className="action">Bestätigen</code>.
  </Tab>
</Tabs>
