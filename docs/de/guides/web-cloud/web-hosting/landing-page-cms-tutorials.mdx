## Ein CMS auf Ihrem Webhosting installieren

Ein CMS (Content Management System) ist eine Software, mit der Sie eine Website ohne Programmierkenntnisse über eine Verwaltungsoberfläche erstellen und verwalten können.

Installieren Sie das CMS Ihrer Wahl auf Ihrem OVHcloud Webhosting. Diese Seite vereint die Anleitungen zur manuellen Installation der wichtigsten CMS (WordPress, Joomla, PrestaShop, Drupal u. a.) oder die Installation eines 1-Klick-Moduls direkt über Ihr OVHcloud Kundencenter.

Um die passende Anleitung für Ihren Bedarf zu finden:

- **Sie möchten ein CMS für Ihre Website installieren?** Siehe Abschnitt *Ein CMS installieren*.
- **Sie möchten eines der gängigsten CMS installieren (WordPress, Joomla, PrestaShop, Drupal)?** Siehe Abschnitt *Die gängigsten CMS*.
- **Sie suchen ein anderes CMS (Grav, Pico, Typo3, SPIP)?** Siehe Abschnitt *Weitere CMS*.
