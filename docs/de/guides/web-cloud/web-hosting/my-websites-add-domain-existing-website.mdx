## Ziel

Sie können mehrere Websites auf einem Webhosting-Plan hosten, selbst wenn die Domainnamen nicht bei OVHcloud registriert sind. Zudem können Sie einen oder mehrere Domainnamen oder Unterdomänen mit derselben Website verknüpfen.

:::info
Falls Sie die betreffende Website noch nicht auf Ihrem Webhosting erstellt haben, konsultieren Sie **direkt** [dieses Handbuch](/guides/web-cloud/web-hosting/multisites-configure-multisite).

:::

**Erfahren Sie, wie Sie einen Domainnamen oder eine Unterdomain mit einer bereits bestehenden Website auf Ihrem Webhosting verknüpfen können.**

## Voraussetzungen

- Ein kompatibler [OVHcloud Webhosting-Plan](https://www.ovhcloud.com/de/web-hosting/uc-multisite/) besitzen.
- Einen oder mehrere [Domainnamen](https://www.ovhcloud.com/de/domains/) besitzen.
- Die Konfiguration Ihrer Domainnamen über deren [DNS-Zonen](/guides/web-cloud/domains/dns-zone-edit) anpassen können.

## In der praktischen Anwendung

### Einen Domainnamen oder eine Unterdomain zu einer bestehenden Website hinzufügen

**Klicken Sie auf einen der untenstehenden Titel, um die Erklärungen anzuzeigen.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Einen in Ihrem OVHcloud Account verwalteten Domainnamen hinzufügen</summary>

Dieser Teil gilt nur, wenn sich Ihr Domainname und/oder seine aktive DNS-Zone **in Ihrem OVHcloud Account** befinden.

Das Formular passt auf eine einzige Seite: Füllen Sie es von oben nach unten aus und bestätigen Sie dann. Klicken Sie auf die unten stehenden Tabs, um die **4** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Meine Websites</code>. Klicken Sie in der Tabelle in der Spalte **Aktionen** rechts neben der betreffenden Website auf den Button <code className="action">⋮</code> und dann in der Gruppe **Domainnamen** auf <code className="action">Domainnamen hinzufügen</code>.

    <img className="thumbnail" alt="Aktionsmenü einer Website, Eintrag Domainnamen hinzufügen" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Die Seite **Eine Domain hinzufügen** wird geöffnet. Sie übernimmt das Formular zum Hinzufügen einer Website, in dem das **Stammverzeichnis** und der **Website-Name** bereits aus der bestehenden Website übernommen sind: Lassen Sie diese unverändert.

    <img className="thumbnail" alt="Seite Eine Domain hinzufügen und Auswahl des Domainnamen-Typs" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    Wählen Sie im Abschnitt **Zuordnung des Domainnamens** die Option **Bestehender OVHcloud-Domainname** aus.
  </Tab>
  <Tab label="Schritt 4">
    Der Abschnitt **Ihre Domain konfigurieren** wird angezeigt. Wählen Sie im Dropdown-Menü **Domainname** den zu verknüpfenden Domainnamen aus.

    <img className="thumbnail" alt="Domainkonfiguration, Optionen und DNS-Konfiguration" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-configure-domain.png" loading="lazy" />

    :::info
    Um eine Subdomain hinzuzufügen, wählen Sie zuerst den Domainnamen in der Liste aus (zum Beispiel: domain.tld). Aktivieren Sie dann das Kästchen **Eine Subdomain erstellen**. Ein Eingabefeld erscheint, in das Sie die Subdomain eingeben (zum Beispiel: **sub**.domain.tld).

    **Sonderfall**: Die Subdomain `www` (zum Beispiel: **www**.domain.tld) wird nicht automatisch mit dem Domainnamen hinzugefügt. Damit auch sie Ihre Website anzeigt, fügen Sie sie separat hinzu, indem Sie dieses Verfahren mit `www.domain.tld` wiederholen.
    :::

    Der Abschnitt **Optionen** fasst drei Funktionen zusammen, die standardmäßig deaktiviert sind. Je nach Ihrem [Webhosting-Angebot](/links/web/hosting) können einige davon nicht auswählbar sein.

    |Option|Beschreibung|
    |---|---|
    |Länder-IP|Ermöglicht Ihnen, eine geolokalisierte IP-Adresse (aus einer Liste von Ländern) für den ausgewählten Domainnamen zu nutzen.<br/> Erfahren Sie mehr auf [dieser Seite](/links/web/hosting-options).|
    |Firewall|Ermöglicht Ihnen, eine Firewall (Filterung und Analyse von Anfragen) für den ausgewählten Domainnamen zu aktivieren.<br/> Erfahren Sie mehr auf [dieser Seite](/links/web/hosting-options).|
    |CDN|Ermöglicht Ihnen, das CDN (Caching von statischen Elementen Ihrer Website, wie z. B. Bilder) für den ausgewählten Domainnamen zu aktivieren.<br/> Erfahren Sie mehr auf [unserer CDN-Seite](/links/web/hosting-options-cdn).<br/> Durch Aktivierung von SSL und CDN können Sie zudem auch vom Protokoll **HTTP/2** profitieren (dieses Protokoll ist standardmäßig in unserem Gravelines-Datencenter aktiviert).|

    :::info
    Diese Optionen können später aktiviert werden. Lesen Sie dazu [diese Anleitung](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::

    Der Abschnitt **DNS-Konfiguration** bietet schließlich zwei Modi:

    - **Für eine automatische Konfiguration** lassen Sie die Option **Automatische Konfiguration** ausgewählt: Die A- und AAAA-Einträge werden in der DNS-Zone der Domain erstellt.
    - **Für eine manuelle Konfiguration** wählen Sie die Option **Manuelle Konfiguration** und lesen Sie dann die folgenden Anleitungen:
        - [Webhosting - Liste der IP-Adressen pro Cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Bearbeiten der OVHcloud DNS-Zone](/guides/web-cloud/domains/dns-zone-edit)

    Klicken Sie abschließend auf <code className="action">Validate</code>. Das Hinzufügen kann bis zu einer Stunde dauern.

    :::info
    Die Änderung der DNS-Konfiguration Ihres Domainnamens erfordert eine Propagationszeit von bis zu 48 Stunden, bis sie vollständig wirksam ist.
    :::
  </Tab>
</Tabs>

<details>
<summary>Einen externen Domainnamen hinzufügen</summary>

Dieser Abschnitt gilt nur, wenn Ihr Domainname nicht in Ihrem OVHcloud-Konto vorhanden ist.

Das Formular passt auf eine einzige Seite: Füllen Sie es von oben nach unten aus und bestätigen Sie dann. Klicken Sie auf die unten stehenden Tabs, um die **4** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Meine Websites</code>. Klicken Sie in der Tabelle in der Spalte **Aktionen** rechts neben der betreffenden Website auf den Button <code className="action">⋮</code> und dann in der Gruppe **Domainnamen** auf <code className="action">Domainnamen hinzufügen</code>.

    <img className="thumbnail" alt="Aktionsmenü einer Website, Eintrag Domainnamen hinzufügen" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Die Seite **Eine Domain hinzufügen** wird geöffnet. Sie übernimmt das Formular zum Hinzufügen einer Website, in dem das **Stammverzeichnis** und der **Website-Name** bereits aus der bestehenden Website übernommen sind: Lassen Sie diese unverändert.

    <img className="thumbnail" alt="Seite Eine Domain hinzufügen und Auswahl des Domainnamen-Typs" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    Wählen Sie im Abschnitt **Zuordnung des Domainnamens** die Option **Externer Domainname** aus.
  </Tab>
  <Tab label="Schritt 4">
    Geben Sie im Abschnitt **Ihre Domain konfigurieren** im Feld **Domainname** den Domainnamen (zum Beispiel: domain.tld) oder die Subdomain (zum Beispiel: **sub**.domain.tld) ein.

    :::tip
    **Sonderfall**: Die Subdomain `www` (zum Beispiel: **www**.domain.tld) wird nicht automatisch mit dem Domainnamen hinzugefügt. Damit auch sie Ihre Website anzeigt, fügen Sie sie separat hinzu, indem Sie dieses Verfahren mit `www.domain.tld` wiederholen.
    :::

    Der Abschnitt **Domainverwaltung** zeigt dann die zu erstellenden Einträge in zwei Schritten an. Diese Überprüfung ist obligatorisch: Sie ermöglicht es uns sicherzustellen, dass das Hinzufügen des externen Domainnamens rechtmäßig ist.

    <img className="thumbnail" alt="Domainverwaltung: zu erstellende DNS-Einträge und BIND-Eintrag" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-external-dns.png" loading="lazy" />

    1. **Domain-Eigentum überprüfen**: Fügen Sie den angegebenen **TXT**-Eintrag in der DNS-Zone Ihres Anbieters hinzu.
    2. **Leiten Sie die Domain auf Ihr Hosting weiter**: Fügen Sie die angegebenen **A**- und **AAAA**-Einträge hinzu.

    Jeder Wert verfügt über einen Kopier-Button, und der Block **BIND-Eintrag** enthält die drei Zeilen in dem Format, das die meisten DNS-Zonen-Anbieter erwarten.

    Klicken Sie abschließend auf <code className="action">Validate</code>. Der Domainname wird vorübergehend hinzugefügt, während Sie seine DNS-Konfiguration ändern.

    :::warning
    Sie müssen diese Änderungen **schnell** vornehmen, damit Ihr Domainname korrekt mit Ihrer Website verknüpft wird.

    Die DNS-Einträge vom Typ **A** und **TXT** müssen zwingend in der aktiven DNS-Zone Ihres Domainnamens eingetragen werden. Nur die DNS-Einträge vom Typ **AAAA** sind optional.

    Beachten Sie: Wenn Sie `sub.domain.tld` verknüpfen möchten, müssen Sie den TXT-Eintrag `ovhcontrol.domain.tld` erstellen und nicht den Eintrag `ovhcontrol.sub.domain.tld`.

    Um die aktive DNS-Zone Ihres Domainnamens zu finden, ermitteln Sie die [DNS-Server](/guides/web-cloud/domains/dns-server-edit), mit denen er verbunden ist.
    :::

    :::info
    Die Änderung der DNS-Konfiguration Ihres Domainnamens erfordert eine Propagationszeit von bis zu 48 Stunden, bis sie vollständig wirksam ist.
    :::
  </Tab>
</Tabs>

</details>

### E-Mail-Angebot, das mit Ihrem Webhosting einhergeht

Die meisten Angebote für [OVHcloud Webhosting](https://www.ovhcloud.com/de/web-hosting/) enthalten eine Option zur Erstellung von benutzerdefinierten E-Mail-Adressen mit Ihrem Domainnamen.

Diese E-Mail-Option kann für **einen einzigen** Domainnamen aktiviert werden. Das bedeutet, dass Sie diese Option nur für einen Ihrer Domainnamen aktivieren können, wenn Sie mehrere Webseiten mit verschiedenen Domainnamen auf Ihrem Webhosting einrichten.

Weitere Informationen zur Aktivierung dieser Option finden Sie in [unserem speziellen Leitfaden](/guides/web-cloud/web-hosting/activate-email-hosting).
