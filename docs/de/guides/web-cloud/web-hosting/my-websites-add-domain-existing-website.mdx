## Ziel

Sie können mehrere Websites auf einem Webhosting-Plan hosten, selbst wenn die Domainnamen nicht bei OVHcloud registriert sind. Zudem können Sie einen oder mehrere Domainnamen oder Unterdomänen mit derselben Website verknüpfen.

:::info
Falls Sie die betreffende Website noch nicht auf Ihrem Webhosting erstellt haben, konsultieren Sie **direkt** [dieses Handbuch](/guides/web-cloud/web-hosting/multisites-configure-multisite).

:::

**Erfahren Sie, wie Sie einen Domainnamen oder eine Unterdomain mit einer bereits bestehenden Website auf Ihrem Webhosting verknüpfen können.**

:::info
Dieses Verfahren gilt für die <ManagerLink to="/beta/#/">neue Version des OVHcloud Kundencenters</ManagerLink>, die derzeit als Beta verfügbar ist. Um es durchzuführen, wechseln Sie aus Ihrem gewohnten Kundencenter zu dieser Oberfläche.

:::

## Voraussetzungen

- Ein kompatibler [OVHcloud Webhosting-Plan](https://www.ovhcloud.com/de/web-hosting/uc-multisite/) besitzen.
- Einen oder mehrere [Domainnamen](https://www.ovhcloud.com/de/domains/) besitzen.
- Die Konfiguration Ihrer Domainnamen über deren [DNS-Zonen](/guides/web-cloud/domains/dns-zone-edit) anpassen können.

## In der praktischen Anwendung

### Einen Domainnamen oder eine Unterdomain zu einer bestehenden Website hinzufügen

**Klicken Sie auf einen der untenstehenden Titel, um die Erklärungen anzuzeigen.**

    Dieser Vorgang kann bis zu eine Stunde dauern.

    Die DNS-Konfiguration wird automatisch durchgeführt, sofern die aktive DNS-Zone Ihres Domainnamens in Ihrem OVHcloud Kundencenter verwaltet wird.

    - [Bearbeiten der OVHcloud DNS-Zone](/guides/web-cloud/domains/dns-zone-edit)

    :::info
    Die Änderung der DNS-Konfiguration Ihres Domainnamens benötigt eine Ausbreitungszeit, die bis zu 24 Stunden dauern kann, bis sie vollständig wirksam ist.

<summary>Einen externen Domainnamen hinzufügen</summary>

Dieser Abschnitt gilt nur, wenn Ihr Domainname nicht in Ihrem OVHcloud-Konto vorhanden ist.

Klicken Sie auf die Tabs, um die **6** Schritte anzuzeigen.

<Tabs>

  </Tab>
  <Tab label="Schritt 2">

    <img className="thumbnail" alt="Meine Seiten" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Im angezeigten Tabelle klicken Sie auf den Button <code className="action">⁝</code> rechts neben der betreffenden Website und anschließend auf <code className="action">Eine Domain hinzufügen</code>.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/website-options.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Aktivieren Sie die Option <code className="action">Einen externen Domain zuordnen</code> und klicken Sie auf <code className="action">Weiter</code>.

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-1.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 5">
    Geben Sie den Domainnamen (z. B. domain.tld) oder die Unterdomain (z. B. **sub**.domain.tld) in das Feld **Domainname - erforderlich** ein, das darunter angezeigt wird.

    :::tip
    **Besonderheit**: Unterdomänen mit `www` (z. B. **www**.domain.tld) werden automatisch ergänzt. Daher ist es nicht notwendig, diese spezielle Unterdomain im Eingabefeld anzugeben.

    :::

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-2.png" loading="lazy" />

    Nachdem Sie die Informationen eingegeben haben, klicken Sie auf den Button <code className="action">Weiter</code>.

    :::info
    Im Gegensatz zu Domainnamen, die direkt über Ihr OVHcloud Kundencenter verwaltet werden, sind die **erweiterten Optionen** nicht direkt verfügbar, wenn Sie einen externen Domainnamen oder eine externe Unterdomain zu Ihrer Website hinzufügen.

    Allerdings können **alle diese Funktionen später aktiviert werden, nachdem der externe Domainname oder die externe Unterdomain zu Ihrer Website hinzugefügt wurde.** Dazu konsultieren Sie direkt [dieses Handbuch](/guides/web-cloud/web-hosting/multisites-modify-domain).

    :::

  </Tab>
  <Tab label="Schritt 6">
    Jede externe Domain, die bei OVHcloud hinzugefügt wird, erfordert eine obligatorische zusätzliche Validierung. Dies ermöglicht uns, sicherzustellen, dass die Hinzufügung des externen Domainnamens legitim ist. Sie erhalten daher eine Nachricht, in der Sie aufgefordert werden, die DNS-Konfiguration des Domainnamens zu ändern.

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-3.png" loading="lazy" />

    Notieren Sie sich die angezeigten Elemente und klicken Sie auf den Button <code className="action">Weiter</code>. Danach wird der Domainname vorübergehend hinzugefügt, bis Sie seine DNS-Konfiguration ändern können.

    :::warning
    Sie müssen diese Änderungen **schnell vornehmen**, damit Ihr Domainname korrekt hinzugefügt wird. Andernfalls wird die Hinzufügung Ihres Domainnamens storniert.

    Die DNS-Einträge des Typs **A** und **TXT** müssen obligatorisch in der aktiven DNS-Zone Ihres Domainnamens platziert werden, damit er zu Ihrer Website hinzugefügt wird. Nur die DNS-Einträge des Typs **AAAA** sind optional.

    Beachten Sie, dass wenn Sie `sub.domain.tld` hinzufügen möchten, Sie den TXT-Eintrag `ovhcontrol.domain.tld` erstellen müssen und nicht den Eintrag `ovhcontrol.sub.domain.tld`.

    Um die aktive DNS-Zone Ihres Domainnamens zu finden, konsultieren Sie die [DNS-Server](/guides/web-cloud/domains/dns-server-edit), an die dieser Domainname angeschlossen ist. Sie müssen nur den Domainnamen mit dem Feld **TXT** validieren, nicht alle seine Unterdomänen.|

    :::

  </Tab>
</Tabs>

### E-Mail-Angebot, das mit Ihrem Webhosting einhergeht

Die meisten Angebote für [OVHcloud Webhosting](https://www.ovhcloud.com/de/web-hosting/) enthalten eine Option zur Erstellung von benutzerdefinierten E-Mail-Adressen mit Ihrem Domainnamen.

Diese E-Mail-Option kann für **einen einzigen** Domainnamen aktiviert werden. Das bedeutet, dass Sie diese Option nur für einen Ihrer Domainnamen aktivieren können, wenn Sie mehrere Webseiten mit verschiedenen Domainnamen auf Ihrem Webhosting einrichten.

Weitere Informationen zur Aktivierung dieser Option finden Sie in [unserem speziellen Leitfaden](/guides/web-cloud/web-hosting/activate-email-hosting).
