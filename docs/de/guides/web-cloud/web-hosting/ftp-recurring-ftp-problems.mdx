## Ziel 

Die Verwendung von FTP-Software beim Login auf Ihr [Hosting-Pakete](/links/web/hosting) kann zu verschiedenen Anomalien führen. In dieser Anleitung können Sie die gängigsten Lösungen auswählen.

**Diese Anleitung erklärt, wie Sie gängige Fehler im Zusammenhang mit FTP-Programmen beheben.**

[[fragment:support-scope]]

## Voraussetzungen

- Sie verfügen über ein [OVHcloud Webhosting](/links/web/hosting).

[[cpnav:web-hosting-console]]

## In der praktischen Anwendung

### "Dieser Server unterstützt FTP auf TLS nicht" (FileZilla)

<img className="thumbnail" alt="doesnt-support-ftp-on-tls" src="/images/assets/screens/other/web-tools/filezilla/doesnt-support-ftp-on-tls.png" loading="lazy" />

Diese Nachricht im [FileZilla-Programm](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide) zeigt an, dass Sie die SFTP- oder SSH-Option in der <ManagerLink to="/beta/#/">OVHcloud Konsole</ManagerLink> nicht aktiviert haben. Daher werden die zwischen Ihrem OVHcloud Hosting-Server und Ihrem Computer ausgetauschten Informationen nicht verschlüsselt.

Wenn die Daten, die Sie über diese Verbindung austauschen möchten, nicht vertraulich sind, klicken Sie auf <code className="action">OK</code>.

Ist das nicht der Fall, gehen Sie in der OVHcloud Konsole auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Hosting aus. Bearbeiten Sie im Tab <code className="action">FTP-SSH</code>, Bereich **FTP- und SSH-Benutzer**, den betreffenden FTP-Benutzer, um das SFTP-Protokoll für ihn zu aktivieren.

Die ausführliche Vorgehensweise, die für alle Hosting-Angebote gleich ist, finden Sie in unserer Anleitung "[Webhosting – Aktivieren des Zugriffs über SFTP](/guides/web-cloud/web-hosting/enable-sftp)". Warten Sie anschließend einige Minuten.

:::info
Für sonstige Fehlermeldungen beachten Sie den Bereich `Diagnose` unserer [Webhosting-Anleitungen](/guides/web-cloud/web-hosting/landing-page-web-hosting).

:::

### Ich habe meine Dateien mit einem FTP-Programm übertragen, aber meine Seite wird nicht angezeigt

Überprüfen Sie zunächst, dass die Dateien und Ordner Ihrer Website im [Wurzelverzeichnis](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online#3-dateien-auf-ihren-speicherplatz-hochladen) Ihres Hostings enthalten sind.

Wenn Sie vor weniger als 48 Stunden eine Änderung an Ihren [DNS-Servern](/guides/web-cloud/domains/dns-server-edit) oder Ihrer [DNS-Zone](/guides/web-cloud/domains/dns-zone-edit) vorgenommen haben, warten Sie ab und starten Sie Ihre Geräte regelmäßig neu, um ihren Cache zu leeren.

### Meine FTP-Zugangsdaten funktionieren nicht.

Wenn Sie sich nicht authentifizieren können, ändern Sie Ihr FTP-Passwort entsprechend den Anweisungen in [dieser Anleitung](/guides/web-cloud/web-hosting/ftp-change-password).

### Auf meiner Website sind zufällige Fehler aufgetreten

Wenn Sie den Speicherplatz Ihres Webhostings überschreiten, kann es zu Fehlfunktionen auf Ihrer Seite kommen.

Um den verbleibenden Speicherplatz auf Ihrem Webhosting zu überprüfen, klicken Sie auf die Tabs, um die **2** Schritte anzuzeigen.

### Ich kann meine Dateien nicht auf den FTP-Server übertragen

Überprüfen Sie, dass Ihr FTP-Programm im "Passivmodus" (Konfigurationsmodus eines FTP-Servers, in dem der Server den Verbindungsport bestimmt) verbunden ist.

Klicken Sie zum Beispiel für [Filezilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide) auf <code className="action">Bearbeiten</code>, dann auf <code className="action">Einstellungen</code>. Öffnen Sie <code className="action">Verbindung</code>, dann klicken Sie auf <code className="action">FTP</code> und wählen Sie dann <code className="action">Passiv (empfohlen)</code> aus.

Begrenzen Sie auch die Größe Ihrer Datentransfers (Sie können nicht mehr als **5000 Dateien und Ordner** auf den Shared Hosting Servern von OVHcloud in einem einzigen Transfer versenden). Führen Sie mehrere Importe durch, wenn nötig unter Verwendung komprimierter Ordner.

Wenn Sie über eine **Pro**, **Performance**, **Agency**, **Agency Plus** oder **Agency Max** Lösung verfügen, verwenden Sie vorzugsweise das [SSH-Protokoll](/guides/web-cloud/web-hosting/ssh-on-webhosting), um Ihre Dateien dem Speicherplatz Ihres Hostings hinzuzufügen.

### Der symbolische Link "index.html" kann nicht in meinem FTP-Bereich gelöscht werden

Dieser Link ist standardmäßig auf den Shared Hosting Paketen von OVHcloud installiert. Er zeigt die unten abgebildete Seite an:

<img className="thumbnail" alt="site-under-construction" src="/images/assets/screens/other/browsers/errors/site-under-construction.png" loading="lazy" />

Wenn Sie die Funktion "[1-Klick-Modul](/guides/web-cloud/web-hosting/cms-install-1-click-modules)" nicht für Ihre Website verwendet haben, müssen Sie sich [mit dem FTP-Speicherplatz verbinden](/guides/web-cloud/web-hosting/ftp-connection) Ihres Webhostings einloggen, um die Seite "Site under construction" manuell zu löschen.
