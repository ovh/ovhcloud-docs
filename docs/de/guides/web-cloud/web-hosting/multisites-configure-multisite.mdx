## Ziel

Sie können mehrere Webseiten auf einem Hosting-Paket hosten, selbst wenn die Domainnamen nicht bei OVHcloud registriert sind.

Möchten Sie eine neue Website auf Ihrem Hosting-Paket hinzufügen?

**Diese Anleitung erklärt, wie Sie mehrere Webseiten auf Ihrem Hosting-Paket hosten können.**

:::info
Wenn Sie bereits eine Website auf Ihrem Hosting-Paket erstellt haben und diese mit einem neuen Domainnamen oder Subdomain verknüpfen möchten, besuchen Sie direkt [diese Anleitung](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).

:::

## Voraussetzungen

- Sie haben ein kompatibles [OVHcloud Webhosting](/links/web/hosting-multisite).
- Sie verfügen über einen oder mehrere [Domainnamen](/links/web/domains).
- Sie haben die erforderlichen Berechtigungen zur Verwaltung der [DNS-Zonen Ihrer Domainnamen](/guides/web-cloud/domains/dns-zone-edit).

[[cpnav:web-hosting-console]]

## In der praktischen Anwendung

### 1 - Fügen Sie eine Website zu Ihrem Hosting-Paket hinzu

**Klicken Sie auf einen der untenstehenden Titel, um die Erklärungen anzuzeigen.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Eine Website mit einem in Ihrem OVHcloud Account verwalteten Domainnamen hinzufügen</summary>

Dieser Teil gilt nur, wenn sich der Domainname (und/oder seine aktive DNS-Zone), mit dem Sie Ihre Website erstellen möchten, **in Ihrem OVHcloud Account** befindet.

Das Formular zum Hinzufügen passt auf eine einzige Seite: Füllen Sie es von oben nach unten aus und bestätigen Sie dann. Klicken Sie auf die unten stehenden Tabs, um die **5** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Meine Websites</code> und dann über der Tabelle auf den Button <code className="action">Website hinzufügen</code>.

    <img className="thumbnail" alt="Tab Meine Websites und Button Website hinzufügen" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-button.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Geben Sie im Abschnitt **Stammverzeichnis** den Namen des Ordners ein, der die Dateien Ihrer Website enthalten soll. Lassen Sie das Feld leer, damit die Konsole ihn automatisch erstellt.

    Wählen Sie im Abschnitt **Zuordnung des Domainnamens** die Option **Bestehender OVHcloud-Domainname** aus.

    <img className="thumbnail" alt="Stammverzeichnis und Auswahl des Domainnamen-Typs" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    :::warning
    Das **Stammverzeichnis** wird auch im Speicherplatz Ihres Webhostings erstellt, auf den Sie je nach Angebot per FTP, SFTP oder SSH zugreifen. Wenn sich der Inhalt Ihrer Website bereits in einem bestimmten Ordner dieses Speicherplatzes befindet, geben Sie hier dessen Namen an.
    :::
  </Tab>
  <Tab label="Schritt 4">
    Der Abschnitt **Ihre Domain konfigurieren** wird angezeigt. Geben Sie im Feld **Website-Name** einen Namen Ihrer Wahl ein: Er dient nur dazu, Ihre Website in der OVHcloud Konsole zu identifizieren. Wählen Sie dann im Dropdown-Menü **Domainname** den zu verknüpfenden Domainnamen aus.

    <img className="thumbnail" alt="Domainkonfiguration, Optionen und DNS-Konfiguration" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-configure-domain.png" loading="lazy" />

    :::info
    Um eine Subdomain hinzuzufügen, wählen Sie zuerst den Domainnamen aus (zum Beispiel: domain.tld) und aktivieren Sie dann **Eine Subdomain erstellen**. Ein Feld erscheint, in das Sie sie eingeben (zum Beispiel: **sub**.domain.tld).

    **Sonderfall**: Die Subdomain `www` (zum Beispiel: **www**.domain.tld) wird nicht automatisch mit dem Domainnamen hinzugefügt. Damit auch sie Ihre Website anzeigt, fügen Sie sie separat hinzu, indem Sie dieses Verfahren mit `www.domain.tld` wiederholen.
    :::

    Der Abschnitt **Optionen** fasst drei Funktionen zusammen, die standardmäßig deaktiviert sind. Je nach Ihrem [Webhosting-Angebot](/links/web/hosting) können einige davon nicht auswählbar sein.

    |Option|Beschreibung|
    |---|---|
    |Länder-IP|Ermöglicht das Nutzen einer geolokalisierten IP-Adresse (aus einer Liste von Ländern) für den ausgewählten Domainnamen.<br/> Weitere Informationen finden Sie auf [dieser Seite](/links/web/hosting-options).|
    |Firewall|Ermöglicht die Aktivierung eines Firewalls (Filterung und Analyse von Anfragen) für den ausgewählten Domainnamen.<br/>Weitere Informationen finden Sie auf [dieser Seite](/links/web/hosting-options).|
    |CDN|Ermöglicht die Aktivierung des CDNs (Caching von statischen Elementen Ihrer Website, wie z. B. Bilder) für den ausgewählten Domainnamen.<br/>Weitere Informationen finden Sie auf [dieser Seite](/links/web/hosting-options-cdn).<br/>Durch die Aktivierung von SSL und CDN können Sie außerdem vom Protokoll **HTTP/2** profitieren (dieses Protokoll ist standardmäßig in unserem Rechenzentrum in Gravelines aktiviert).|

    :::info
    Diese Optionen können später aktiviert werden, sobald die Website erstellt ist. Lesen Sie dazu [diese Anleitung](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::

    Der Abschnitt **DNS-Konfiguration** bietet schließlich zwei Modi:

    - **Für eine automatische Konfiguration** lassen Sie die Option **Automatische Konfiguration** ausgewählt: Die A- und AAAA-Einträge werden in der DNS-Zone der Domain erstellt. Ein Hinweis gibt an, dass die Konsole versucht, Konflikte durch das Löschen inkompatibler Einträge zu lösen.
    - **Für eine manuelle Konfiguration** wählen Sie die Option **Manuelle Konfiguration** und lesen Sie dann die folgenden Anleitungen:
        - [Webhosting - Liste der IP-Adressen nach Cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [DNS-Zone von OVHcloud bearbeiten](/guides/web-cloud/domains/dns-zone-edit)
  </Tab>
  <Tab label="Schritt 5">
    Der Abschnitt **Ein 1-Klick-Modul zur Installation wählen** schließt das Formular ab. OVHcloud stellt die Module WordPress, Joomla!, PrestaShop und Drupal bereit, die automatisch im oben konfigurierten Stammverzeichnis installiert werden. Weitere Informationen finden Sie in unserer Anleitung "[Installation Ihrer Website mit 1-Klick-Modulen (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules)".

    <img className="thumbnail" alt="Auswahl des zu installierenden 1-Klick-Moduls" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-1-click-module.png" loading="lazy" />

    Lassen Sie **Kein vorinstalliertes Modul** ausgewählt, wenn Sie die Dateien Ihrer Website lieber selbst hochladen möchten. Weitere Informationen finden Sie in unserer Anleitung "[Eine Website auf Ihrem Webhosting online stellen](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online)".

    Überprüfen Sie abschließend die eingegebenen Informationen und klicken Sie dann auf <code className="action">Validate</code>. Das Hinzufügen kann bis zu einer Stunde dauern.

    :::info
    Die Änderung der DNS-Konfiguration Ihres Domainnamens erfordert eine Propagationszeit von bis zu 48 Stunden, bis sie vollständig wirksam ist.
    :::
  </Tab>
</Tabs>

</details>

<details>
<summary>Eine Website mit einem nicht in Ihrem OVHcloud Account verwalteten Domainnamen hinzufügen</summary>

Dieser Abschnitt gilt nur, wenn Sie eine Website mit einem Domainnamen hinzufügen möchten, der nicht in Ihrem OVHcloud Kunden-Account vorhanden ist. Dies kann ein Domainname sein, der in einem anderen OVHcloud Kunden-Account vorhanden ist oder bei einem anderen Anbieter registriert ist.

Das Formular zum Hinzufügen passt auf eine einzige Seite: Füllen Sie es von oben nach unten aus und bestätigen Sie dann. Klicken Sie auf die unten stehenden Tabs, um die **5** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Meine Websites</code> und dann über der Tabelle auf den Button <code className="action">Website hinzufügen</code>.

    <img className="thumbnail" alt="Tab Meine Websites und Button Website hinzufügen" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-button.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Geben Sie im Abschnitt **Stammverzeichnis** den Namen des Ordners ein, der die Dateien Ihrer Website enthalten soll. Lassen Sie das Feld leer, damit die Konsole ihn automatisch erstellt.

    Wählen Sie im Abschnitt **Zuordnung des Domainnamens** die Option **Externer Domainname** aus.

    <img className="thumbnail" alt="Stammverzeichnis und Auswahl des Domainnamen-Typs" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    :::warning
    Das **Stammverzeichnis** wird auch im Speicherplatz Ihres Webhostings erstellt, auf den Sie je nach Angebot per FTP, SFTP oder SSH zugreifen. Wenn sich der Inhalt Ihrer Website bereits in einem bestimmten Ordner dieses Speicherplatzes befindet, geben Sie hier dessen Namen an.
    :::
  </Tab>
  <Tab label="Schritt 4">
    Geben Sie im Abschnitt **Ihre Domain konfigurieren** den **Website-Name** Ihrer Wahl ein: Er dient nur dazu, Ihre Website in der OVHcloud Konsole zu identifizieren. Geben Sie dann im Feld **Domainname** den Domainnamen (zum Beispiel: domain.tld) oder die Subdomain (zum Beispiel: **sub**.domain.tld) ein.

    :::tip
    **Sonderfall**: Die Subdomain `www` (zum Beispiel: **www**.domain.tld) wird nicht automatisch mit dem Domainnamen hinzugefügt. Damit auch sie Ihre Website anzeigt, fügen Sie sie separat hinzu, indem Sie dieses Verfahren mit `www.domain.tld` wiederholen.
    :::

    Der Abschnitt **Domainverwaltung** zeigt dann die zu erstellenden Einträge in zwei Schritten an. Diese Überprüfung ist obligatorisch: Sie ermöglicht es uns sicherzustellen, dass das Hinzufügen des externen Domainnamens rechtmäßig ist.

    <img className="thumbnail" alt="Domainverwaltung: zu erstellende DNS-Einträge und BIND-Eintrag" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-external-dns.png" loading="lazy" />

    1. **Domain-Eigentum überprüfen**: Fügen Sie den angegebenen **TXT**-Eintrag in der DNS-Zone Ihres Anbieters hinzu.
    2. **Leiten Sie die Domain auf Ihr Hosting weiter**: Fügen Sie die angegebenen **A**- und **AAAA**-Einträge hinzu.

    Jeder Wert verfügt über einen Kopier-Button, und der Block **BIND-Eintrag** enthält die drei Zeilen in dem Format, das die meisten DNS-Zonen-Anbieter erwarten.

    :::warning
    Nehmen Sie diese Änderungen **schnell** vor. Andernfalls wird das Hinzufügen Ihres Domainnamens abgebrochen und Ihre neu erstellte Website ist nicht erreichbar.

    Die DNS-Einträge vom Typ **A** und **TXT** müssen zwingend in der aktiven DNS-Zone Ihres Domainnamens eingetragen werden. Nur die Einträge vom Typ **AAAA** sind optional.

    Achten Sie darauf, dass Sie, wenn Sie `sub.domain.tld` verknüpfen möchten, den TXT-Eintrag `ovhcontrol.domain.tld` und nicht den Eintrag `ovhcontrol.sub.domain.tld` erstellen.

    Um die aktive DNS-Zone Ihres Domainnamens zu finden, identifizieren Sie die [DNS-Server](/guides/web-cloud/domains/dns-server-edit), an die diese Domain angeschlossen ist. Sie müssen nur den Domainnamen mithilfe des Feldes **TXT** bestätigen, nicht jedoch alle Subdomains.
    :::

    :::info
    Im Gegensatz zu Domainnamen, die in Ihrem OVHcloud Account verwaltet werden, werden die Abschnitte **Optionen** und **DNS-Konfiguration** für einen externen Domainnamen nicht angeboten.

    Diese Funktionen können nach dem Erstellen der Website weiterhin aktiviert werden. Lesen Sie dazu [diese Anleitung](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::
  </Tab>
  <Tab label="Schritt 5">
    Der Abschnitt **Ein 1-Klick-Modul zur Installation wählen** schließt das Formular ab. OVHcloud stellt die Module WordPress, Joomla!, PrestaShop und Drupal bereit, die automatisch im oben konfigurierten Stammverzeichnis installiert werden. Weitere Informationen finden Sie in unserer Anleitung "[Installation Ihrer Website mit 1-Klick-Modulen (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules)".

    <img className="thumbnail" alt="Auswahl des zu installierenden 1-Klick-Moduls" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-1-click-module.png" loading="lazy" />

    Lassen Sie **Kein vorinstalliertes Modul** ausgewählt, wenn Sie die Dateien Ihrer Website lieber selbst hochladen möchten. Weitere Informationen finden Sie in unserer Anleitung "[Eine Website auf Ihrem Webhosting online stellen](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online)".

    Klicken Sie abschließend auf <code className="action">Validate</code>. Der Domainname wird vorübergehend hinzugefügt, während Sie seine DNS-Konfiguration ändern.

    :::info
    Die Änderung der DNS-Konfiguration Ihres Domainnamens erfordert eine Propagationszeit von bis zu 48 Stunden, bis sie vollständig wirksam ist.
    :::
  </Tab>
</Tabs>

Klicken Sie auf die unten stehenden Tabs, um die **3** Schritte nacheinander anzuzeigen.

  </Tab>
  <Tab label="Schritt 2">

  <Tab label="Schritt 3">
    Wählen Sie im Abschnitt **Zuordnung des Domainnamens** die Option **Neuen Domainnamen bestellen** aus.

    <img className="thumbnail" alt="Stammverzeichnis und Auswahl des Domainnamen-Typs" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    Das Formular verlangt nichts weiter: Der Button unten auf der Seite trägt dann die Bezeichnung <code className="action">Neuen Domainnamen bestellen</code>. Klicken Sie darauf.

    Sie werden dann auf unsere Bestellseite für Domainnamen weitergeleitet. Wählen Sie Ihren neuen Domainnamen je nach Verfügbarkeit aus und folgen Sie dann den Anweisungen des Bestellprozesses bis zur Bestätigung des Bestellscheins, ohne zusätzlich ein neues Webhosting zu bestellen.

    Nachdem Ihre Bestellung bezahlt und validiert wurde, warten Sie einige Minuten, bis diese verarbeitet wird.

    :::info
    Sobald Ihr Domainname in Ihrem OVHcloud Account angezeigt wird, folgen Sie dem Teil "[Einen in Ihrem OVHcloud Account verwalteten Domainnamen hinzufügen](#add-domain-ovhcloud)" dieser Anleitung, um Ihre Website zu Ihrem Webhosting hinzuzufügen.

### 2 - Ihre Website online stellen <a name="site-online"></a>

Sobald die Website mit Ihrem Domainnamen auf Ihrem Webhosting deklariert ist, können Sie den Inhalt Ihrer Website online stellen. Zur Erinnerung: Sie müssen dies im **Stammverzeichnis** vornehmen, das Sie beim Hinzufügen der Website in der OVHcloud Konsole festgelegt haben.

:::info
Wenn Sie mehrere Websites hinzufügen möchten, wiederholen Sie die in dieser Anleitung beschriebenen Aktionen.

Wir empfehlen Ihnen, aufmerksam zu sein, wie viele Websites auf Ihrem Webhosting vorhanden sind. Je mehr Websites vorhanden sind, desto mehr Ressourcen Ihres Webhostings werden beansprucht. [Die Seite mit unseren Webhosting-Angeboten](/links/web/hosting) enthält eine Einschätzung, wie viele Websites Sie auf Ihrem Webhosting hosten können.

:::
