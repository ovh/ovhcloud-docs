## Ziel

Auf Ihrem OVHcloud Webhosting können Sie Skripte verwenden, um bestimmte Operationen zu automatisieren. Ein geplanter Task ("CRON Job") ermöglicht es, dass Ihre Skripte zu bestimmten Zeiten ausgeführt werden, ohne dass weitere Aktionen Ihrerseits erforderlich sind.

**Hier erfahren Sie, wie Sie CRON-Tasks erstellen, um Ihre geplanten Tasks auf einem Webhosting zu automatisieren.**

[[fragment:support-scope]]

## Voraussetzungen

- Sie haben ein [OVHcloud Webhosting](/links/web/hosting) in Ihrem Kunden-Account.

[[cpnav:web-hosting-console]]

## In der praktischen Anwendung

### Erstellung eines automatisierten Tasks

Klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Cron</code>.

    <img className="thumbnail" alt="Tab Cron eines Webhostings" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Sie erhalten einen Überblick über Ihre geplanten Tasks und deren Einstellungen: Jeder Task wird als Kasten mit seinem Befehl, seinem **Status**, seiner **Häufigkeit**, seiner **Sprache** und der Berichts-**E-Mail** angezeigt.

    Um einen CRON-Task zu erstellen, klicken Sie auf den Button <code className="action">Aufgabe erstellen</code>.

    <img className="thumbnail" alt="Kästen der geplanten Tasks und Button Aufgabe erstellen" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/tasks.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Passen Sie die Task-Einstellungen im angezeigten Bereich **Cron-Aufgabe erstellen** an.

    <img className="thumbnail" alt="Bereich Cron-Aufgabe erstellen im Modus Einfach" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/create-task.png" loading="lazy" />

    |Option|Beschreibung|
    |---|---|
    |Befehl|Legen Sie den Zugriffspfad zur Datei mit Ihrem Skript relativ zum Wurzelverzeichnis Ihres Hostings fest. Beispiel: *www/jobs/cron.php*|
    |Häufigkeit|Legen Sie fest, wie oft der Task ausgeführt wird (siehe unten).|
    |Sprache|Wählen Sie die vom Skript verwendete PHP-Version aus.|
    |Beschreibung|Geben Sie eine Beschreibung ein, um Ihre Tasks zu dokumentieren.|
    |Berichts-E-Mail|Geben Sie bei Bedarf die E-Mail-Adresse an, an die bei einem Ausführungsfehler ein Bericht gesendet wird.|

    Der Task wird sofort bei seiner Erstellung aktiviert. Wenn er nicht sofort ausgeführt werden soll, deaktivieren Sie ihn anschließend (siehe Abschnitt [Task bearbeiten oder löschen](#task-bearbeiten-oder-löschen)).

    Für die **Häufigkeit** bietet das Interface zwei Modi an:

    - **Einfach**: Wählen Sie eine vordefinierte Häufigkeit in der Liste aus (stündlich, täglich um Mitternacht oder Mittag, jeden Montag um Mitternacht, am 1. jedes Monats um Mitternacht).
    - **Erweitert**: Geben Sie einen Ausdruck wie in einer *crontab* ein, dessen Positionen in dieser Reihenfolge **Min**, **Std**, **Tag**, **Monat** und **Wochentag** entsprechen. Das Interface übersetzt den Ausdruck über dem Feld in Klartext und erinnert an die Bedeutung der Zeichen `*` (beliebiger Wert), `,` (Listentrennzeichen), `-` (Wertebereich) und `/` (Schrittweite). Beispielsweise führt `0 * * * *` den Task **einmal pro Stunde jeden Tag** zur Minute 0 aus.

    <img className="thumbnail" alt="Häufigkeit im Modus Erweitert mit dem Cron-Ausdruck und seiner Übersetzung" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/create-task-advanced.png" loading="lazy" />

    :::info
    Mit der Position **Tag** können Sie die Ausführungsfrequenz für einen monatlichen Zyklus festlegen.

    Mit der Position **Wochentag** können Sie zusätzliche Ausführungszeitpunkte festlegen, jedoch in einem wöchentlichen Zyklus.
    :::

    Sie können während der Konfiguration zwischen den beiden Ansichten wechseln. Beachten Sie auch die [Einschränkungen bei der Task-Planung auf einem Webhosting](#einschränkungen-bei-geplanten-tasks-auf-ihrem-webhosting).

    Wenn alles korrekt ist, klicken Sie auf <code className="action">Erstellen</code>.

    Der Task wird in einigen Minuten bereit sein. Sie können dann alle Einstellungen ändern oder den Task über den Button <code className="action">⋮</code> oben rechts in seinem Kasten löschen.
  </Tab>
</Tabs>

### Einschränkungen bei geplanten Tasks auf Ihrem Webhosting

|Funktion|Beschreibung|
|---|---|
|Zeitplanung|Die Minuten werden vom Hosting ignoriert: Ein Task kann nur einmal pro Stunde ausgeführt werden, dies ist die höchste Wiederholungsfrequenz, die angegeben werden kann. Geben Sie im Modus **Erweitert** eine feste Minute an (zum Beispiel `0`): Das Interface weist Sie darauf hin, wenn dies nicht der Fall ist.|
|Laufzeit|Die Ausführungsdauer eines Tasks beträgt 60 Minuten. Wenn ein Skript diese Ausführungsdauer überschreitet, wird es automatisch vom System angehalten.|
|Variable|Sie können Variablen nur in einem Skript definieren. Sie zur URL hinzuzufügen, die das Skript anruft, funktioniert nicht (Beispiel: *www/jobs/cron.php?variable=value*).|
|Datenlimit|Ein Task kann nur 5 MB an Daten generieren (*stdin/stderr*). Wenn beispielsweise ein Skript Daten in eine .txt-Datei schreibt, endet die Ausführung automatisch, sobald die Datei 5 MB erreicht.|
|Fehlergenerierende Skripte|Wenn ein Skript fehlerhaft ist, wird es nach 10 fehlgeschlagenen Ausführungsversuchen automatisch deaktiviert. Der Fehlerbericht wird erst gesendet, wenn alle 10 Versuche fehlgeschlagen sind.<br/>Korrigieren Sie Ihr Skript auf der Grundlage des erhaltenen Fehlerberichts und reaktivieren Sie dann den Task über den Tab <code className="action">Cron</code> (klicken Sie im Kasten des Tasks auf <code className="action">⋮</code> und dann auf <code className="action">Aktivieren</code>).|
|Ausführungsberichte|Die Berichte werden nur einmal täglich (während der Nachtstunden) an die ausgewählte E-Mail-Adresse versandt.|

### Fehlerdiagnose

#### Test Ihres Skripts mit einem Webbrowser

Ein einfacher Test, um zu sehen, ob Ihr Skript einen Fehler verursacht, ist, es in einem Webbrowser auszuführen. Wenn zum Beispiel der Zugriffspfad auf Ihr Skript "www/cron.php" ist und Ihre Domain "mypersonaldomain.ovh" ist, verwenden Sie die URL "http://<i></i>mypersonaldomain.ovh/cron.php". Wenn kein Fehler auftritt, das Skript aber nicht wie geplant funktioniert, folgen Sie den nachstehenden Empfehlungen.

#### Überprüfung der Nutzung absoluter Pfade

Achten Sie immer darauf, absolute Zugriffspfade zu den Dateien Ihrer Skripte zu verwenden. Die Konstante "DIR" kann beispielsweise dazu dienen, den aktuellen Pfad in PHP-Skripten zu erhalten ([PHP-Dokumentation](https://www.php.net/manual/de/language.constants.predefined.php)).

#### Überprüfung der Ausführungsprotokolle

In den Logs Ihres Webhostings, einsehbar in der <ManagerLink to="/beta/#/">OVHcloud Konsole</ManagerLink>, finden Sie die Log-Kategorie "cron".

Weitere Informationen finden Sie in unserer Anleitung zu [Statistiken und Logs](/guides/web-cloud/web-hosting/logs-and-statistics).
