## Ziel

Ein Log ist ein Ereignis, das auf einem Computersystem (Server, Computer, Anwendung, Website, Datenbank, Computernetzwerk usw.) aufgetreten ist.
Ein Log kann beispielsweise eines oder mehrere der folgenden Elemente aufzeichnen und enthalten:

- Den Zeitstempel (Datum, Stunde, Minute, Sekunde usw.) des Ereignisses.
- Die Art des Ereignisses (Verbindung, Trennung, Fehler, Download, Upload, Warnung usw.).
- Zusätzliche Informationen zum Ereignis (aufgerufene Seite oder Datei, gestartete Anwendung, aufgerufener Remote-Server, Name einer hoch- oder heruntergeladenen Datei usw.).
- Den Ursprung des Ereignisses (Benutzerkennung, Quell-IP-Adresse, Quellprogramm usw.).
- Den Zustand des Systems, in dem das Ereignis stattfindet (verfügbare Ressourcen, verbleibender Speicher, CPU-Auslastung usw.).

In den meisten Fällen werden die Logs direkt von den Computersystemen generiert, in denen die Ereignisse auftreten.
Sie werden in Textdateien gespeichert und archiviert, die auch als Logdateien bezeichnet werden.

Logdateien ermöglichen es Ihnen daher:

- Das Verhalten des Computersystems zu analysieren, das die Logs generiert.
- Auf dem Computersystem aufgetretene Fehler zu identifizieren.
- Auf dem Computersystem aufgetretene Fehler zu beheben.
- Die Leistung des Computersystems zu optimieren.

Ihr [Webhosting](/links/web/hosting)-Paket generiert daher seine eigenen Logs.

In manchen Situationen müssen Sie die Logs gegebenenfalls einsehen oder abrufen:

- für Ihr Webhosting-Paket;
- für eine der Websites oder Anwendungen auf Ihrem Webhosting.

**Erfahren Sie, wie Sie die Logs der Websites oder Anwendungen auf Ihrem Webhosting aktivieren, anzeigen und verwalten.**

:::warning
Wir stellen Ihnen diese Anleitung zur Verfügung, um Sie bei gängigen Aufgaben bestmöglich zu unterstützen. Wir empfehlen Ihnen jedoch, sich an einen [spezialisierten Dienstleister](/links/partner) zu wenden, falls Sie auf Schwierigkeiten stoßen. Wir können Ihnen nämlich keine Unterstützung bei der Interpretation der mit Ihrem Webhosting verfügbaren Logs bieten. Weitere Informationen finden Sie im Abschnitt ["Weiterführende Informationen"](#go-further) dieser Anleitung.
:::

### Die Logs Ihres Webhosting-Pakets für Logs Data Platform abonnieren <a name="webhosting-ldp"></a>

[Logs Data Platform](/links/manage-operate/ldp) ist eine Plattform zur Verwaltung Ihrer Logs. Sie kann nützlich sein, wenn Sie über eine sehr große Infrastruktur verfügen oder wenn Ihre Dienste sehr viele Logs generieren. Diese Plattform ist nämlich darauf ausgelegt, die Aggregation und Verwaltung von Logs zu vereinfachen.

Sie funktioniert, indem sie die von Ihrer Infrastruktur, Ihren Websites oder Ihren Anwendungen generierten Logs abruft, um diese beispielsweise:

- zu speichern;
- in Echtzeit-Dashboards anzuzeigen;
- den Benutzern zu ermöglichen, komplexe Abfragen durchzuführen;
- nach Datum, Anwendung, Typ oder Inhalt zu filtern;

Weitere Details zu Logs Data Platform finden Sie in unserer Anleitung [Einführung in Logs Data Platform](/guides/manage-and-operate/observability/logs-data-platform/introduction) (EN).

Da [Webhosting](/links/web/hosting)-Pakete mit zahlreichen Diensten (Datenbanken usw.) verwendet werden können, können Sie diese zusätzlich zu den bereits verfügbaren Echtzeit-Logs per Datenstream für Logs Data Platform abonnieren.

Mit einem Logs Data Platform Account verfügen Sie kostenlos über **1 GB** Log-Aufbewahrung. Um davon zu profitieren, müssen Sie [Ihren Logs Data Platform Account kostenlos aktivieren](/guides/manage-and-operate/observability/logs-data-platform/getting-started-quick-start) und Ihr Webhosting für einen Datenstream abonnieren.

:::danger
Abhängig von:

- Den von Ihrem Webhosting generierten Logs
- Der Anzahl der für Ihren Logs Data Platform Account abonnierten Webhosting-Pakete

kann das **1 GB** an Daten mehr oder weniger schnell verbraucht werden.

Je nach Nutzung kann dieser Datenverbrauch nämlich ein Logvolumen darstellen, das von einigen Tagen bis zu einigen Monaten oder sogar Jahren reichen kann.

Wenn Sie ein Volumen von mehr als **1 GB** für die Aufbewahrung Ihrer Logs wünschen, können Sie ein zusätzliches kostenpflichtiges Angebot abonnieren.
:::
