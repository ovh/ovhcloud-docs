## Ziel 

In dieser Anleitung werden die Schritte zum Exportieren aller Elemente einer Webseite im Standardformat von einem unserer Webhosting-Dienste beschrieben.

**Erfahren Sie hier, wie Sie Ihre OVHcloud Webseite exportieren können.**

:::info
Einige Verfahren in dieser Anleitung gelten für die <ManagerLink to="/beta/#/">neue Version des OVHcloud Kundencenters</ManagerLink>.
Eine Erinnerung wird zu Beginn jedes betreffenden Abschnitts angezeigt.

:::

## Voraussetzungen

- Sie haben ein [OVHcloud Webhosting](/links/web/hosting).

### Zugriff auf das OVHcloud Kundencenter

- **Direkter Link:** <ManagerLink to="/#/web/hosting">Hosting-Pakete</ManagerLink>
- **Navigationspfad:** <code className="action">Web Cloud</code> > <code className="action">Hosting-Pakete</code> > Wählen Sie Ihr Webhosting aus

## In der praktischen Anwendung

### 1 - Dateien von Ihrem FTP-Speicherplatz abrufen

#### 1.1 In den Speicherplatz einloggen

Um sich in Ihren Speicherplatz einzuloggen, benötigen Sie:

- Einen aktiven FTP- oder SSH-Benutzer.
- Das Passwort für diesen Benutzer-Account.
- Die Server-Adresse.
- Den Verbindungsport des Servers.

Diese Informationen wurden Ihnen per E-Mail bei der Installation Ihres Webhostings mitgeteilt.

Wenn Sie nicht mehr im Besitz dieser Daten sind, klicken Sie auf die Tabs, um die **3** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/#/web/hosting">Hosting-Pakete</ManagerLink>, und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">FTP - SSH</code>.

    <img className="thumbnail" alt="FTP - SSH" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Es werden nun die Informationen Ihres Speicherplatzes angezeigt. Sie sollten hier alle Elemente zum Einloggen in Ihren FTP-Speicherplatz finden.

    <img className="thumbnail" alt="FTP - SSH tab" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/ftp-ssh/tab-pro.png" loading="lazy" />

Falls nötig, konsultieren Sie unsere Anleitung: [Mit dem Speicherplatz eines Webhostings verbinden](/guides/web-cloud/web-hosting/ftp-connection).

    Wenn Sie das Passwort nicht kennen, nutzen Sie die Anleitung [Passwort eines FTP-Benutzers ändern](/guides/web-cloud/web-hosting/ftp-change-password).
  </Tab>
</Tabs>

Wenn Sie alle nötigen Informationen bereit haben, können Sie Ihre Dateien auf dem Speicherplatz abrufen. Hierfür haben Sie zwei Möglichkeiten:

- **FTP- oder SFTP-kompatibles Programm verwenden**: Installieren Sie einen FTP-Client auf Ihrem Computer, wie [FileZilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide). Kontaktieren Sie den Herausgeber der eingesetzten Anwendung, falls Sie für deren Verwendung Hilfe benötigen, da OVHcloud keine Unterstützung zu externer Software anbieten kann.

- **SSH-Zugang verwenden**: Um auf Ihren Speicherplatz zuzugreifen, müssen die entsprechenden Befehle in einem Terminal ausgeführt werden. Für diesen Zugriffstyp sind fortgeschrittene Kenntnisse sowie ein kompatibles [OVHcloud Webhosting](/links/web/hosting) erforderlich. Weitere Informationen hierzu finden Sie in unserer [Anleitung](/guides/web-cloud/web-hosting/ssh-on-webhosting). 

#### 1.2 Dateien von Ihrem Speicherplatz herunterladen

Sobald Sie sich bei Ihrem Speicherbereich angemeldet haben und je nach Anzahl der darauf gehosteten Webseiten, können mehrere Ordner angezeigt werden.

Falls erforderlich, identifizieren Sie vorab im Webhosting den Namen des Stammordners, in dem Ihre Webseite gespeichert ist. Klicken Sie auf die Tabs, um die **3** Schritte anzuzeigen.

:::info
Dieser Abschnitt gilt für die <ManagerLink to="/beta/#/">neue Version des OVHcloud Kundencenters</ManagerLink>.

:::

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hosting-Pakete</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Hosting-Pakete" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf der angezeigten Seite auf den Tab <code className="action">Meine Seiten</code>.

    <img className="thumbnail" alt="Meine Seiten" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    In der angezeigten Tabelle für die gewünschte Webseite, beachten Sie das <code className="action">Wurzelverzeichnis</code>, das angezeigt wird.

    <img className="thumbnail" alt="export-website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/root-folders.png" loading="lazy" />
  </Tab>
</Tabs>

Solange Sie weiterhin bei Ihrem Speicherbereich angemeldet sind, müssen Sie lediglich die Dateien Ihrer Webseite herunterladen, indem Sie auf den zuvor identifizierten Stammordner zugreifen.

### 2 - Backup Ihrer Datenbank abrufen (optional)

:::info
Dieser Schritt ist optional, wenn Ihre Webseite keine Datenbank verwendet.

:::

Informationen zum Abrufen eines Backups Ihrer Datenbank finden Sie in unserer Anleitung:
[Backup einer Webhosting-Datenbank exportieren](/guides/web-cloud/web-hosting/sql-database-export).

Wenn Sie eine Datenbank **Web Cloud Databases** für Ihre Website verwenden, lesen Sie den Abschnitt "Backup" in unserer Anleitung:
[Eine Datenbank Ihres Datenbankservers sichern und exportieren](/guides/web-cloud/databases/db-backup-export-database-server).

### 3 - Logs Ihres OVHcloud Webhostings abrufen

Lesen Sie unsere dedizierte Anleitung: [Webhosting - Die Statistiken und Logs einer Website einsehen](/guides/web-cloud/web-hosting/logs-and-statistics).
