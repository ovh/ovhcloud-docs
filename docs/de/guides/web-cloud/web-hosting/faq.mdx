<summary>Wie kann ich meine Website online stellen?</summary>

Um Ihre Website online zu stellen, benötigen Sie zunächst Folgendes:

- Eine [Domainname](/links/web/domains), die der Webadresse entspricht, von der aus über einen Webbrowser auf Ihre Website zugegriffen werden kann (Beispiel: *domain.tld*). Dieser Domainname muss auch mit Ihrem Webhosting verbunden sein, um die Website anzeigen zu können.
- Ein [Webhosting](/links/web/hosting), auf dem Sie Ihre Website installieren können.

Im Folgenden sind die wichtigsten Schritte aufgeführt:

1. Definieren Sie Ihr Projekt (fertige Website (CMS), die manuell oder mithilfe der 1-Klick-Module von OVHcloud oder von Ihnen oder einem Dienstleister erstellte Website etc. installiert wird).
2. Stellen Sie die Dateien der Website auf dem FTP-Speicherplatz Ihres Webhostings online.
3. Verknüpfen Sie die Website mit einer Datenbank (falls die Website eine Datenbank verwendet).
4. Wechseln Sie zu Ihrer Website.

:::tip
Weitere Informationen zum Onlinestellen einer Website auf einem Webhosting finden Sie in unserer detaillierten Anleitung "[Webhosting - Website online stellen](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online)".

Wenn Sie sich dafür entscheiden, ein CMS (WordPress, Joomla!, PrestaShop, Drupal) mit unserer Lösung "1-Klick-Module" zu installieren, lesen Sie unsere detaillierte Anleitung "[Installation Ihrer Website mit 1-Klick-Modulen](/guides/web-cloud/web-hosting/cms-install-1-click-modules)".

Wenn Ihre Website bereits bei einem anderen Anbieter vorhanden ist und Sie sie zu OVHcloud migrieren möchten, lesen Sie unsere detaillierte Anleitung "[Website und zugehörige Dienste zu OVHcloud migrieren](/guides/web-cloud/web-hosting/hosting-migrating-to-ovh)".

Um Ihnen bei der Konfiguration Ihres Webhostings zu helfen, können Sie [hier alle Anleitungen zu unseren Webhosting-Lösungen finden](/guides/web-cloud/web-hosting/landing-page-web-hosting).

:::

<summary>Wie zeige ich meine Website mit einer URL in HTTPS an?</summary>

Damit Ihre Website über eine HTTPS-URL erreichbar ist (Beispiel: `https://domain.tld`), sind zwei Voraussetzungen erforderlich:

- Sie benötigen ein aktives SSL-Zertifikat für Ihre Domain (oder auf Ihrem Webhosting installiert)
- Im Quellcode Ihrer Website muss diese das Umschreiben der URLs in HTTPS erzwingen.

OVHcloud bietet [mehrere SSL-Zertifikate](/links/web/hosting-options) für Webhostings an.

Um ein SSL-Zertifikat auf Ihrem Webhosting für Ihre Website zu aktivieren, klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting und Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf der angezeigten Seite auf den Tab <code className="action">SSL</code>.

    <img className="thumbnail" alt="Tab SSL eines Webhostings" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie über der Zertifikatstabelle auf <code className="action">Zertifikat hinzufügen</code>. Wählen Sie im sich öffnenden Bereich unter **Zertifikattyp** das gewünschte Zertifikat aus den [verfügbaren Zertifikaten](/guides/web-cloud/web-hosting/ssl-on-webhosting) aus.

    <img className="thumbnail" alt="Bereich Zertifikat hinzufügen und Auswahl des Zertifikattyps" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/enable-ssl-lets-encrypt.png" loading="lazy" />

  <Tab label="Schritt 4">
    Fahren Sie fort, bis die Installation des SSL-Zertifikats abgeschlossen ist (nach vorheriger Validierung des Bestellscheins, wenn Sie eines der Sectigo SSL-Zertifikate auswählen).
  </Tab>
</Tabs>

:::tip
Weitere Informationen finden Sie in den folgenden Anleitungen:

- [Webhosting - SSL-Zertifikat verwalten](/guides/web-cloud/web-hosting/ssl-on-webhosting).
- [Webhosting - Ein kostenloses SSL-Zertifikat von Let's Encrypt aktivieren](/guides/web-cloud/web-hosting/ssl-letsencrypt).
- [Webhosting - SSL-Zertifikat für Sectigo DV aktivieren](/guides/web-cloud/web-hosting/ssl-dv).
- [Webhosting - SSL-Zertifikat für Sectigo EV aktivieren](/guides/web-cloud/web-hosting/ssl-ev).

:::

Sobald das SSL-Zertifikat Ihrer Wahl installiert und bei OVHcloud eingerichtet ist, überprüfen Sie, dass der Quellcode Ihrer Website die Zugriff-URLs Ihrer Website in HTTPS umschreibt. Sollten Sie diesbezüglich Schwierigkeiten haben, wenden Sie sich an Ihren Webmaster oder einen unserer [Partner](/links/partner).

<summary>Warum ist der Verlängerungspreis meines Webhostings gestiegen?</summary>

Unsere Webhosting-Angebote haben sich 2026 weiterentwickelt: Die Angebote und ihre Preise wurden geändert. Seit dem 1. Juni 2026 werden Verlängerungen von Webhostings zu den neuen Preisen abgerechnet. Sie wurden per E-Mail über diese Änderungen informiert.

Die neuen Angebote bieten Ihrem Dienst mehr Kapazität, zum Beispiel mehr Datenbanken mit mehr Speicherplatz, sowie neue Funktionen auf Basis künstlicher Intelligenz.

Weitere Informationen finden Sie in unserem Blogartikel "[Entwicklung unserer Webhosting-Angebote: Was ändert sich und warum](https://blog.ovhcloud.com/de/posts/evolution-webhosting-2026/)".

<summary>Wie kann ich bei einer Kündigung eines Webhostings das dazugehörige kostenlose Angebot "Web Cloud Databases" beibehalten?</summary>

Wenn Sie Ihr Webhosting kündigen oder löschen, wird auch das eventuell damit verbundene Angebot Web Cloud Databases gekündigt. Um Ihre Web Cloud Databases Lösung zu behalten, müssen Sie diese **vor** Kündigung des Hostings abtrennen.

Klicken Sie auf die Tabs, um die **3** Schritte anzuzeigen.

<Tabs>

    <img className="thumbnail" alt="Abschnitt Datenbanken und Menü der Zeile Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png" loading="lazy" />

<summary>Was tun, wenn die Seite "Seite im Aufbau" von OVHcloud nach dem Onlinestellen meiner Website weiterhin angezeigt wird?</summary>

<img className="thumbnail" alt="construction" src="/images/assets/screens/other/browsers/errors/site-en-construction.png" loading="lazy" />

Bei der Installation Ihres Webhostings legt OVHcloud diese Seite in Form einer **index.html** Datei im Ordner `www` auf dem FTP-Speicherplatz Ihres Webhostings ab.

Es gibt zwei mögliche Szenarien:

- Wenn Sie ein [1-Klick-Modul](/guides/web-cloud/web-hosting/cms-install-1-click-modules) installieren: Diese Datei wird automatisch von unseren Installationsrobotern gelöscht.
- Wenn Sie Ihre Website manuell installieren, führen Sie die folgenden Schritte aus:
    - [Verbinden Sie sich mit dem FTP-Speicherplatz Ihres Webhostings](/guides/web-cloud/web-hosting/ftp-connection).
    - Gehen Sie nach dem Login im FTP-Speicherplatz in das Verzeichnis `www`.
    - Benennen Sie die Datei **index.html** in **index.html.old** um. Dadurch wird die Seite nach einigen Minuten deaktiviert.

:::tip

- [Anleitung - FileZilla mit Ihrem Webhosting verwenden](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide)
- [Anleitung - Cyberduck mit Ihrem Webhosting verwenden](/guides/web-cloud/web-hosting/ftp-cyberduck-user-guide-on-mac)

<summary>Meine Website leitet Sie zum Login-Interface für Webmail von OVHcloud weiter. Was soll ich tun?</summary>

<img className="thumbnail" alt="webmail-login-interface" src="/images/assets/screens/website/webmail/webmail-login-interface.png" loading="lazy" />

Diese Situation weist auf eine fehlerhafte Konfiguration der Ihrem Domainnamen zugeordneten [DNS-Server](/guides/web-cloud/domains/dns-server-edit) oder [DNS-Zone](/guides/web-cloud/domains/dns-zone-edit) hin.

Der häufigste Fall ist folgender: Sie haben Ihren Domainnamen und Ihr Webhosting getrennt bestellt, sodass diese nicht automatisch über die DNS-Zone Ihrer Domain miteinander verbunden werden.

Um dies zu korrigieren, klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> und wählen Sie den betreffenden Domainnamen aus.

    <img className="thumbnail" alt="Seite Domains & DNS und Liste der Domainnamen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Der Domainname öffnet sich im Tab <code className="action">Übersicht</code>. Notieren Sie im Abschnitt **DNS-Konfiguration** die in der Liste **DNS-Server, die die Zone hosten** angegebenen Server.

    <img className="thumbnail" alt="Abschnitt DNS-Konfiguration mit der Konfiguration und der Liste der DNS-Server, die die Zone hosten" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/dns-servers-ovhcloud.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Gehen Sie anschließend in den Tab <code className="action">DNS-Zone</code>.
  </Tab>
  <Tab label="Schritt 4">
    Vergleichen Sie in der angezeigten Tabelle (die die DNS-Zone des Domainnamens darstellt) die `Ziele` der Einträge vom Typ `NS` in der DNS-Zone mit den Namen der zuvor notierten DNS-Server. Um nur diese Einträge anzuzeigen, klicken Sie auf <code className="action">Filter</code> und wählen Sie dann in der Liste **Eintragstyp** <code className="action">NS</code> aus.

    <img className="thumbnail" alt="Auf NS-Einträge gefilterte DNS-Zone eines Domainnamens" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-ns.png" loading="lazy" />
  </Tab>
</Tabs>

<Tabs>
  <Tab label="Fall 1">
    Die `Ziele` (DNS-Server) der in der DNS-Zone des Domainnamens deklarierten Einträge vom Typ `NS` **sind identisch** mit denen, die im Abschnitt **DNS-Konfiguration** notiert wurden.

    In diesem Fall bedeutet dies, dass Ihr Domainname (oder seine Subdomain mit der Endung *www*) auf die IP-Adresse unseres Weiterleitungsservers (213.186.33.5) verweist.

    1. Loggen Sie sich in die <ManagerLink to="/">OVHcloud Konsole</ManagerLink> ein und gehen Sie dann in das Universum <code className="action">Web Cloud</code>.
    2. Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> und wählen Sie den betreffenden Domainnamen aus.
    3. Klicken Sie auf der angezeigten Seite auf den Tab <code className="action">DNS-Zone</code>.
    4. Geben Sie in der angezeigten Tabelle (die die DNS-Zone Ihrer Domain darstellt) den Eintrag vom Typ `A` an, dessen `Ziel` auf die IP-Adresse `213.186.33.5` festgelegt ist.
    5. Öffnen Sie in der betreffenden Zeile das Aktionsmenü <code className="action">⋮</code> und klicken Sie auf <code className="action">Ändern</code>.
    6. Ersetzen Sie im Bearbeitungsformular die IP-Adresse `213.186.33.5` im Feld `Ziel` durch die IP-Adresse des Webhostings, auf dem sich Ihre Website befindet, bestätigen Sie dann Ihre Änderungen.

    :::tip
    Lesen Sie bei Bedarf auch die folgenden detaillierten Anleitungen:

    - [OVHcloud DNS-Zone bearbeiten](/guides/web-cloud/domains/dns-zone-edit).
    - [Webhosting - Liste der IP-Adressen pro Cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip).

    :::

  </Tab>
  <Tab label="Fall 2">
    Die `Ziele` (DNS-Server) der in der DNS-Zone des Domainnamens deklarierten Einträge vom Typ `NS` **sind nicht identisch** mit denen, die im Abschnitt **DNS-Konfiguration** notiert wurden. Die `Ziele` (DNS-Server) haben jedoch eine der folgenden Formen:

    - `nsXX.ovh.net` und `dnsXX.ovh.net` **oder** `nsXXX.ovh.net` und `dnsXXX.ovh.net` (wobei jedes `X` eine Ziffer zwischen **0** und **9** bezeichnet);
    - `nsXX.ovh.ca` und `dnsXX.ovh.ca` **oder** `nsXXX.ovh.ca` und `dnsXXX.ovh.ca` (wobei jedes `X` eine Ziffer zwischen **0** und **9** bezeichnet);
    - `ns200.anycast.me` und `dns200.anycast.me` (wenn Sie die Option [DNS anycast](/links/web/domains-options) abonniert haben).

    :::info
    Wenn einer Ihrer im Abschnitt **DNS-Konfiguration** angegebenen DNS-Server die Form `sdnsX.ovh.net`, `sdnsX.ovh.ca`, `vpsXXXXXX.ovh.net` oder `vpsXXXXXX.ovh.ca` hat (wobei jedes `X` eine Ziffer zwischen **0** und **9** ist), lesen Sie direkt **Fall 3**.
    Es handelt sich um Namen von DNS-Servern, die von OVHcloud bereitgestellt werden und es unseren Kunden ausschließlich ermöglichen, ihre DNS-Konfiguration direkt auf ihren eigenen Servern (Dedicated Server, VPS usw.) zu hosten.

    :::

    In diesem Fall bedeutet dies, dass Ihre Domain nicht die richtigen OVHcloud DNS-Server verwendet, um die im Tab <code className="action">DNS-Zone</code> aufgeführte Konfiguration der DNS-Zone anzuwenden.

    Gehen Sie wie folgt vor, um dies zu korrigieren:

    1. Loggen Sie sich in die <ManagerLink to="/">OVHcloud Konsole</ManagerLink> ein und gehen Sie dann in das Universum <code className="action">Web Cloud</code>.
    2. Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> und wählen Sie den betreffenden Domainnamen aus.
    3. Der Domainname öffnet sich im Tab <code className="action">Übersicht</code>. Klicken Sie im Abschnitt **DNS-Konfiguration** auf <code className="action">DNS-Server bearbeiten</code>.
    4. Wählen Sie im Bereich **DNS-Server ändern** die Option <code className="action">OVHcloud Standard-DNS verwenden</code> aus und klicken Sie dann auf den Button <code className="action">Konfiguration anwenden</code>.

    <img className="thumbnail" alt="Bereich DNS-Server ändern eines Domainnamens" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/modify-dns-servers.png" loading="lazy" />

    Die Propagation der Aktualisierung der DNS-Server einer Domain kann bis zu **48** Stunden dauern.

    :::tip
    Alle Details finden Sie in unserer Anleitung "[DNS-Server eines OVHcloud Domainnamens ändern](/guides/web-cloud/domains/dns-server-edit)".

    :::

  </Tab>
  <Tab label="Fall 3">
    Die `Ziele` (DNS-Server) der in der DNS-Zone des Domainnamens deklarierten Einträge vom Typ `NS` **sind nicht identisch** mit denen, die im Abschnitt **DNS-Konfiguration** notiert wurden. Außerdem haben die Namen der im Abschnitt **DNS-Konfiguration** notierten DNS-Server keine der in **Fall 2** beschriebenen Formen, mit Ausnahme der folgenden: `sdnsX.ovh.net`, `sdnsX.ovh.ca`, `vpsXXXXXX.ovh.net` oder `vpsXXXXXX.ovh.ca` (wobei jedes `X` eine Ziffer zwischen **0** und **9** ist).

    In diesem Fall wird die auf Ihre Domain angewendete aktive DNS-Zone nicht direkt von OVHcloud verwaltet. Wenden Sie sich an Ihren Webmaster, Ihren Domain-Anbieter, Ihren DNS-Anbieter oder an einen unserer [OVHcloud Partner](/links/partner).
  </Tab>
</Tabs>

<summary>Was kann ich tun, wenn auf meiner Website die Fehlermeldung "Your request has been blocked" angezeigt wird?</summary>

<img className="thumbnail" alt="your-request-has-been-blocked" src="/images/assets/screens/other/browsers/errors/your-request-has-been-blocked.png" loading="lazy" />

Die Seite "Your request has been blocked" kann aus verschiedenen Gründen angezeigt werden (nicht abschließende Liste):

- Die Anfrage wird über einen nicht aktualisierten Browser (Firefox, Chrome, Safari, Edge etc.) durchgeführt.
- Eine sehr große Zahl von Anfragen wird innerhalb einer äußerst kurzen Frist ausgeführt.
- Die Anfrage versucht, nicht autorisierte Aktionen auf der Hosting-Infrastruktur durchzuführen, auf der sich Ihr Webhosting befindet.

In diesem Fall sind mehrere Aktionen erforderlich:

- Stellen Sie sicher, dass Ihr Browser auf dem neuesten Stand ist.
- Notieren Sie die aufgerufene URL (zum Beispiel: `https://www.domain.tld`) sowie alle Informationen auf der Seite "Your request has been blocked" (`IP address`, `Date` und `Request ID`).
- Übermitteln Sie diese Informationen an den Support, indem Sie ein [Support-Ticket](/links/support-contact) erstellen.

Wenn Sie sich nicht sicher sind, welche Schritte Sie ausführen sollen, wenden Sie sich an Ihren Webmaster oder einen unserer [Partner](/links/partner).

:::tip
Lesen Sie auch unsere detaillierte Anleitung: [Was tun, wenn die Meldung "Your request has been blocked" angezeigt wird?](/guides/web-cloud/web-hosting/request-has-been-blocked-diagnosis).

:::

<summary>Ich habe einen Domainnamen mit Akzenten bestellt, der in der OVHcloud Konsole seltsam angezeigt wird. Was muss ich tun?</summary>

In diesem Fall müssen Sie nichts unternehmen. Auch wenn Ihre Domain in der OVHcloud Konsole in [internationalisierter Schreibweise (IDN)](https://de.wikipedia.org/wiki/Internationalisierter_Domainname) angezeigt wird, funktioniert sie und wird an anderer Stelle ganz normal angezeigt. Die Webadresse Ihrer Website wird so angezeigt, wie Sie sie angefordert haben. Auch Ihre E-Mail-Adressen werden Ihren Korrespondenten so angezeigt, wie Sie es wünschen.

:::danger
Es wird nicht empfohlen, eine E-Mail-Adresse mit einem IDN-Domainnamen (Internationalized Domain Name) von einem E-Mail-Client (Outlook, macOS Mail etc.) aus zu verwenden. Dies liegt daran, dass einige E-Mail-Clients Domainnamen nicht mit Akzentzeichen interpretieren, was die Übertragung von E-Mails verhindert. Ein Absender, der Ihnen eine E-Mail sendet, erhält dann eine automatische Nachricht, dass Ihre E-Mail-Adresse nicht existiert.

**Es wird empfohlen, zusätzlich zu Ihrem Domainnamen mit Akzent den gleichen Domainnamen ohne Akzente zu reservieren, um Inkompatibilitäten beim E-Mail-Verkehr zu vermeiden.**

:::

</details>
