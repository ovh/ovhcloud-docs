## Ziel

Mit einem CNAME-Eintrag können Sie eine Subdomain einem Domainnamen oder einer Subdomain zuordnen, ohne eine IP-Adresse angeben zu müssen. Das bedeutet, dass die Subdomain auf die IP-Adresse der Ziel-Domain bzw. Subdomain weitergeleitet wird, ohne dass eine zusätzliche Konfiguration erforderlich ist.

Wenn Sie beispielsweise einen CNAME-Eintrag für *www.domain.tld* erstellen, der auf *domain.tld* verweist, verwendet *www.domain.tld* dieselbe IP-Adresse wie *domain.tld*.

CNAME-Einträge sind nützlich, um zu vermeiden, dass die IP-Adressen für Ihre Subdomains geändert werden müssen. Sie können auch verwendet werden, um Dienste wie E-Mail-Server zu konfigurieren.

**Diese Anleitung erklärt, wie Sie einen CNAME-Eintrag in Ihre OVHcloud DNS-Zone eintragen.**

> **Sie haben bereits einen CNAME-Eintrag in Ihrer DNS-Zone?** Folgen Sie unserer Anleitung "[Bearbeiten der OVHcloud DNS-Zone](/guides/web-cloud/domains/dns-zone-edit)".

## Voraussetzungen

- Sie haben einen [Domainnamen](/links/web/domains).
- Sie nutzen eine diesem Domainnamen zugeordnete DNS-Zone bei OVHcloud.

## In der praktischen Anwendung

### Einen CNAME DNS-Eintrag für die Subdomain eines Domainnamens hinzufügen

Klicken Sie auf die unten stehenden Tabs, um die **5** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> und wählen Sie den betreffenden Domainnamen aus.

    <img className="thumbnail" alt="Seite Domains & DNS und Liste der Domainnamen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">DNS-Zone</code> und dann über der Tabelle auf <code className="action">Eintrag erstellen</code>.

    <img className="thumbnail" alt="Tab DNS-Zone eines Domainnamens und Button Eintrag erstellen" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Wählen Sie im Formular, das sich über der Tabelle öffnet, in der Liste **Typ** `CNAME — Alias auf eine andere Domain` aus.

    <img className="thumbnail" alt="Liste Typ des Formulars zum Erstellen eines Eintrags, Typ CNAME ausgewählt" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-cname.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Geben Sie im Feld **Subdomain** die betreffende Subdomain ein (zum Beispiel: `www` für `www.domain.tld`). Geben Sie im Feld **Ziel (Hostname)** den Domainnamen oder die Subdomain ein, auf die verwiesen werden soll (zum Beispiel: `domain.tld`): Die Konsole fügt den abschließenden Punkt selbst hinzu.

    <img className="thumbnail" alt="Formular zum Erstellen eines Eintrags in der DNS-Zone, CNAME-Eintrag von der Subdomain www auf domain.tld" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-cname-record.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 5">
    Überprüfen Sie die **Datensatzvorschau** und klicken Sie dann auf <code className="action">Hinzufügen</code>.
  </Tab>
</Tabs>

Es dauert bis zu **24** Stunden, bis die Änderung im DNS-Netzwerk voll wirksam ist.

### Sonderfälle

Klicken Sie auf die folgenden Links, um weitere Informationen zu erhalten:

<details>

<summary>CNAME- und TXT-Einträge für eine Subdomain</summary>

Konfigurieren Sie nicht gleichzeitig einen CNAME- und einen TXT-Eintrag für dieselbe Subdomain. Dies kann zu unvorhersehbaren Ergebnissen bei der DNS-Auflösung führen, da nur eine Antwort pro DNS-Abfrage zurückgegeben werden kann.

Beispiel: Für *www.domain.tld* stehen folgende Einträge zur Verfügung:

- Ein CNAME-Eintrag, der auf *domain.tld* verweist
- Ein TXT-Eintrag mit einem bestimmten Wert

Eine DNS-Abfrage für *www.domain.tld* gibt entweder das Ziel des CNAME-Eintrags oder den Wert des TXT-Eintrags zufällig zurück.

</details>

<details>

<summary>CNAME auf einem Domainnamen in seiner eigenen DNS-Zone</summary>

Gemäß der Konvention **können CNAME-Einträge nicht für einen Domainnamen in seiner eigenen DNS-Zone verwendet werden**. Der Domainname muss nämlich direkt auf eine IP-Adresse mit einem Eintrag vom Typ [A](/guides/web-cloud/domains/dns-zone-a-record-creation) für eine IPv4 oder [AAAA](/guides/web-cloud/domains/dns-zone-aaaa-record-creation) für eine IPv6 verweisen.

Wie bereits erwähnt, können Sie in der DNS-Zone, die Sie für den Domainnamen *domain.tld* erstellt haben, keinen CNAME-Eintrag für diesen Domainnamen erstellen.  
Sie können jedoch CNAME-Einträge für alle Subdomains (zum Beispiel: *subdomain.domain.tld* oder *www.domain.tld*) des Domainnamens *domain.tld* in der für *domain.tld* erstellten DNS-Zone erstellen.

Wenn Sie in der OVHcloud Konsole im Feld **Subdomain** eines CNAME-Eintrags `@` eingeben, bleibt der Button <code className="action">Hinzufügen</code> deaktiviert und das Formular zeigt die Meldung "Ein CNAME-Eintrag kann nicht an der Domain-Root (@) erstellt werden. Sie können stattdessen SVCB-Verweis verwenden." an.

</details>
