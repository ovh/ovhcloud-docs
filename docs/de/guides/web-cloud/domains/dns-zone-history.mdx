## Ziel

Die **D**omain **N**ame **S**ystem (**DNS**)-Zone eines Domainnamens ist dessen Konfigurationsdatei. Sie besteht aus technischen Informationen, den sogenannten *DNS-Einträgen*. Die DNS-Zone funktioniert gewissermaßen wie eine Vermittlungszentrale.

Weitere Informationen finden Sie in den folgenden Anleitungen:

- [Alle Informationen zu DNS-Servern](/guides/web-cloud/domains/dns-server-general-information)
- [Alle Informationen zu DNS-Zonen](/guides/web-cloud/domains/dns-zone-general-information)
- [Alle Informationen zu DNS-Einträgen](/guides/web-cloud/domains/dns-zone-records)

Es kann aus verschiedenen Gründen erforderlich sein, eine ältere DNS-Konfiguration auf Ihren Domainnamen anzuwenden.

Die DNS-Verwaltung wird durch den Versionsverlauf Ihrer DNS-Zonen vereinfacht.

**Erfahren Sie, wie Sie Backups Ihrer DNS-Zone einsehen, vergleichen, herunterladen und wiederherstellen.**

## Voraussetzungen

- Sie verfügen über Zugriff auf die Verwaltung des betreffenden Domainnamens.

## In der praktischen Anwendung

:::info
Die Backups Ihrer DNS-Zone unterliegen folgenden Einschränkungen:

- Es werden maximal 200 Backups für eine DNS-Zone aufbewahrt.
- Sobald ein Backup älter als 31 Tage ist, wird es automatisch gelöscht, mit Ausnahme der **5 jüngsten Backups**.

:::

### Versionsverlauf Ihrer DNS-Zone öffnen

Öffnen Sie oberhalb der Tabelle das Menü <code className="action">Aktionen zu meiner Zone</code> und klicken Sie auf <code className="action">Historie meiner DNS-Zone anzeigen</code>.

Auf einer neuen Seite wird der Versionsverlauf Ihrer DNS-Zone-Backups aufgelistet, von der jüngsten bis zur ältesten Version. Die aktuelle Version Ihrer DNS-Zone befindet sich am Anfang der Tabelle und ist mit **Aktuell** gekennzeichnet. Jede Zeile bietet die Aktionen <code className="action">Visualisieren</code>, <code className="action">Jetzt herunterladen</code> und <code className="action">Wiederherstellen</code>, und über den Button <code className="action">Versionen vergleichen</code> können Sie zwei Versionen miteinander vergleichen.

<img className="thumbnail" alt="Seite mit dem Versionsverlauf der DNS-Zone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-history.png" loading="lazy" />

**Klicken Sie auf die gewünschte Aktion, um die Details anzuzeigen.**

<details>

<summary>Eine DNS-Zone anzeigen</summary>

Um den Inhalt einer Version anzuzeigen, identifizieren Sie die entsprechende Zeile in der Tabelle und klicken Sie in der Spalte **Visualisieren** auf <code className="action">Visualisieren</code>. Die Einträge dieser DNS-Zone-Version werden angezeigt. Klicken Sie auf <code className="action">Schliessen</code>, um zur Seite mit dem Versionsverlauf der DNS-Zone zurückzukehren.

<img className="thumbnail" alt="Inhalt einer Version der DNS-Zone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-history-view.png" loading="lazy" />

</details>

<details>

<summary>Eine DNS-Zone herunterladen</summary>

Um eine Version herunterzuladen, identifizieren Sie die entsprechende Zeile in der Tabelle und klicken Sie in der Spalte **Jetzt herunterladen** auf <code className="action">Jetzt herunterladen</code>. Die DNS-Zone wird im Format `.txt` heruntergeladen.

</details>

<details>

<summary>Eine DNS-Zone wiederherstellen</summary>

Um Ihre aktuelle DNS-Zone durch eine ältere zu ersetzen, identifizieren Sie die Zeile für die Version, die Sie wiederherstellen möchten (überprüfen Sie das Datum links neben der Zeile), und klicken Sie in der Spalte **Wiederherstellen** auf <code className="action">Wiederherstellen</code>.

Überprüfen Sie im daraufhin angezeigten Bestätigungsfenster, ob das angezeigte Datum der Version entspricht, die Sie wiederherstellen möchten. Wie der Warnhinweis anzeigt, wird die aktuelle DNS-Zone (ganz oben in der Verlaufsliste) gelöscht und durch die wiederhergestellte Version ersetzt. Klicken Sie zur Bestätigung auf <code className="action">Wiederherstellen</code> oder auf <code className="action">Abbrechen</code>.

<img className="thumbnail" alt="Bestätigungsfenster für die Wiederherstellung der DNS-Zone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-history-restore.png" loading="lazy" />

:::info
Das Ändern oder Wiederherstellen einer DNS-Zone führt zu einer Propagationsverzögerung von **4** bis **24** Stunden, bis die Änderung im DNS-Netzwerk vollständig berücksichtigt wird.

:::

</details>

<details>

<summary>Zwei DNS-Zonen vergleichen</summary>

Um zwei Versionen zu vergleichen, klicken Sie oberhalb der Tabelle auf <code className="action">Versionen vergleichen</code>. Wählen Sie auf der Seite, die sich öffnet, die zu vergleichenden Versionen in den Dropdown-Listen <code className="action">Basisversion</code> und <code className="action">Modifizierte Version</code> aus: Standardmäßig ist die Basisversion die neueste und die modifizierte Version die unmittelbar davor.

Die beiden Versionen werden Zeile für Zeile nebeneinander angezeigt, und ein Farbcode hebt die Unterschiede hervor:

- Im Bereich <code className="action">Basisversion</code> links sind die abweichenden Zeilen **rot** hervorgehoben.
- Im Bereich <code className="action">Modifizierte Version</code> rechts sind die entsprechenden Zeilen **grün** hervorgehoben.

<img className="thumbnail" alt="Vergleich zweier Versionen einer DNS-Zone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-history-compare.png" loading="lazy" />

</details>
