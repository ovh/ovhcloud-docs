## Ziel

Die **D**omain **N**ame **S**ystem (**DNS**)-Zone eines Domainnamens ist dessen Konfigurationsdatei. Sie besteht aus technischen Informationen, den sogenannten *DNS-Einträgen*. Die DNS-Zone funktioniert gewissermaßen wie eine Vermittlungszentrale.

Weitere Informationen finden Sie in den folgenden Anleitungen:

- [Alle Informationen zu DNS-Servern](/guides/web-cloud/domains/dns-server-general-information)
- [Alle Informationen zu DNS-Zonen](/guides/web-cloud/domains/dns-zone-general-information)
- [Alle Informationen zu DNS-Einträgen](/guides/web-cloud/domains/dns-zone-records)

Es kann aus verschiedenen Gründen erforderlich sein, eine ältere DNS-Konfiguration auf Ihren Domainnamen anzuwenden.

Die DNS-Verwaltung wird durch den Versionsverlauf Ihrer DNS-Zonen vereinfacht.

**Erfahren Sie, wie Sie Backups Ihrer DNS-Zone einsehen, vergleichen, herunterladen und wiederherstellen.**

## Voraussetzungen

- Sie verfügen über Zugriff auf die Verwaltung des betreffenden Domainnamens.

## In der praktischen Anwendung

:::info
**Einschränkungen der Backups**

Die Backups Ihrer DNS-Zone unterliegen folgenden Einschränkungen:

- Es werden maximal 200 Backups für eine DNS-Zone aufbewahrt.
- Sobald ein Backup älter als 31 Tage ist, wird es automatisch gelöscht, mit Ausnahme der **5 jüngsten Backups**.

**Wenn Ihre DNS-Zone gelöscht wurde**

Wenn eine DNS-Zone aus Ihrem OVHcloud Account gelöscht wird (manuelle Löschung, Ablauf des Dienstes oder ein anderer Grund), wird zum Zeitpunkt der Löschung eine E-Mail an den **Administrator-Kontakt** des Dienstes gesendet. Ihr Betreff hat die Form `[aa00000-ovh] [OVH-DNS] Löschung Ihrer DNS-Zone domain.tld` und sie enthält einen Link, mit dem Sie den Inhalt Ihrer alten DNS-Zone abrufen können.

Dieser Link ist nur **30 Tage** ab dem Versand der E-Mail gültig. Nach Ablauf dieser Frist ist die Konfiguration der gelöschten DNS-Zone unwiederbringlich verloren.

Wenn Sie diese E-Mail nicht in Ihrem Postfach finden, können Sie sie auf der Seite <ManagerLink to="/beta/#/customer/communications">Meine Kommunikation</ManagerLink> einsehen, auf der alle an Ihre Kontakt-E-Mail-Adresse gesendeten Nachrichten zusammengefasst sind. In der OVHcloud Konsole gelangen Sie dorthin, indem Sie oben rechts auf den Button mit Ihren Initialen und dann auf <code className="action">Meine Kommunikation</code> klicken. Weitere Informationen finden Sie in unserer Anleitung "[Verwalten von Benachrichtigungen in Ihrem OVHcloud Kundencenter](/guides/account-and-service-management/account-information/manage-messages)".

Um den Administratorkontakt eines Dienstes zu überprüfen oder zu ändern, lesen Sie unsere Anleitung "[Die Kontakte Ihrer Dienste verwalten](/guides/account-and-service-management/account-information/managing-contacts)".

:::

### Versionsverlauf Ihrer DNS-Zone öffnen

Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink>, wählen Sie den betreffenden Domainnamen aus und klicken Sie dann auf den Tab <code className="action">DNS-Zone</code>. Der Verlauf Ihrer DNS-Zone wird in der Karte **Verlauf meiner DNS-Zone** unten im Tab angezeigt.

Links in dieser Karte reicht die Liste der Backups Ihrer DNS-Zone von der neuesten bis zur ältesten, jeweils durch ihr Datum gekennzeichnet: Die aktuelle Version steht oben und ist mit **Aktuelle Version** gekennzeichnet. Rechts wird der Inhalt der ausgewählten Version angezeigt. Mit dem Button <code className="action">Vergleichen</code> im Kopfbereich dieses Inhalts können Sie zwei Versionen vergleichen.

<img className="thumbnail" alt="Karte Verlauf meiner DNS-Zone, Liste der Versionen und Inhalt der aktuellen Version" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/history.png" loading="lazy" />

**Klicken Sie auf die gewünschte Aktion, um die Details anzuzeigen.**

<details>

<summary>Eine DNS-Zone anzeigen</summary>

Um den Inhalt einer Version anzuzeigen, klicken Sie in der Liste links auf ihr Datum. Die Einträge dieser Version der DNS-Zone werden rechts im Textformat angezeigt. Mit dem Kopier-Button oben rechts über diesem Inhalt können Sie ihn kopieren.

<img className="thumbnail" alt="Im Verlauf ausgewählte frühere Version der DNS-Zone und ihr Inhalt" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/history-view.png" loading="lazy" />

</details>

<details>

<summary>Eine DNS-Zone herunterladen</summary>

Um eine Version herunterzuladen, klicken Sie in der Liste links auf ihr Datum und dann auf den Download-Button oben rechts über ihrem Inhalt. Die DNS-Zone wird im Format `.txt` heruntergeladen.

</details>

<details>

<summary>Eine DNS-Zone wiederherstellen</summary>

Um Ihre aktuelle DNS-Zone durch eine ältere zu ersetzen, klicken Sie in der Liste links auf die Version, die Sie wiederherstellen möchten (überprüfen Sie das Datum genau), und dann oben rechts über ihrem Inhalt auf <code className="action">Wiederherstellen</code>. Dieser Button wird für die aktuelle Version nicht angezeigt.

Überprüfen Sie im angezeigten Fenster **DNS-Zone wiederherstellen**, ob das angegebene Datum der Version entspricht, die Sie wiederherstellen möchten. Wie das Fenster angibt, wird die aktuelle Konfiguration Ihrer DNS-Zone (oben in der Verlaufsliste) durch die wiederhergestellte Version ersetzt. Klicken Sie zur Bestätigung auf <code className="action">Wiederherstellen</code> oder auf <code className="action">Abbrechen</code>.

<img className="thumbnail" alt="Fenster DNS-Zone wiederherstellen und Datum der wiederherzustellenden Version" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/history-restore.png" loading="lazy" />

:::info
Das Ändern oder Wiederherstellen einer DNS-Zone führt zu einer Propagationsverzögerung von **4** bis **24** Stunden, bis die Änderung im DNS-Netzwerk vollständig berücksichtigt wird.

:::

</details>

<details>

<summary>Zwei DNS-Zonen vergleichen</summary>

Um zwei Versionen zu vergleichen, klicken Sie in der Liste auf die erste zu vergleichende Version und dann im Kopfbereich ihres Inhalts auf <code className="action">Vergleichen</code> (dieser Button erscheint, sobald der Verlauf mindestens zwei Versionen enthält). Die Liste der Versionen bleibt angezeigt. Die ausgewählte Version wird links angezeigt; wählen Sie rechts in der Dropdown-Liste über der Spalte die Version aus, mit der sie verglichen werden soll. Standardmäßig ist dies die Version vor der ausgewählten.

Die beiden Versionen werden Zeile für Zeile nebeneinander angezeigt, und ein Farbcode hebt die Unterschiede hervor:

- Links sind die abweichenden Zeilen **rot** hervorgehoben.
- Rechts sind die entsprechenden Zeilen **grün** hervorgehoben.

Standardmäßig werden nur die abweichenden Zeilen angezeigt: Die Option **Nur Unterschiede** über dem Vergleich blendet identische Zeilen aus. Deaktivieren Sie sie, um alle Zeilen anzuzeigen. Klicken Sie auf <code className="action">Vergleich beenden</code>, um zum Inhalt der ausgewählten Version zurückzukehren.

<img className="thumbnail" alt="Vergleich zweier Versionen einer DNS-Zone, Unterschiede hervorgehoben" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/history-compare.png" loading="lazy" />

</details>
