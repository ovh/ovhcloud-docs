## Ziel

Der Eintrag vom Typ MX legt den für die E-Mail-Adressen eines Domainnamens zuständigen E-Mail-Server fest. Damit wird Servern, die E-Mails an Ihre Adressen versenden, mitgeteilt, wohin diese versendet werden sollen.

**Diese Anleitung erklärt, wie Sie bei OVHcloud MX-Einträge zur Konfiguration Ihres Domainnamens hinzufügen.**

## Voraussetzungen

- Der Domainname verwendet die OVHcloud Konfiguration (die OVHcloud DNS-Server).

<Region zones={['eu']}>

- Sie verfügen über einen MX Plan (enthalten in einem [Webhosting](/links/web/hosting) oder [Kostenloses Hosting](/links/web/domains-free-hosting) oder separat bestellt), einen unserer [OVHcloud E-Mail-Dienste](/links/web/emails) oder einen externen E-Mail-Dienst.

</Region>

<Region zones={['ca', 'apac']}>

- Sie verfügen über einen MX Plan (enthalten in einem [Webhosting](/links/web/hosting) oder separat bestellt), einen unserer [OVHcloud E-Mail-Dienste](/links/web/emails) oder einen externen E-Mail-Dienst.

</Region>

[[cpnav:web-domain-dns-zone]]

:::info
- Wenn Ihr Domainname **nicht** die DNS-Server von OVHcloud verwendet, muss die Änderung der MX-Einträge über das Interface des Anbieters vorgenommen werden, der die Konfiguration Ihres Domainnamens verwaltet.

- Wenn Ihr Domainname bei OVHcloud registriert ist, können Sie überprüfen, ob er unsere Konfiguration verwendet. Lesen Sie dazu bei Bedarf unsere Anleitung "[DNS-Server eines OVHcloud Domainnamens ändern](/guides/web-cloud/domains/dns-server-edit)".

:::

## In der praktischen Anwendung

### Grundlegendes zur Rolle von MX-Einträgen

Der MX-Eintrag (**M**ail e**X**change) ist ein DNS-Eintrag, der festlegt, welche empfangenden E-Mail-Server mit Ihrem Domainnamen verknüpft sind.

Um die Funktionsweise zu verstehen, verwenden wir ein Beispiel:

- Die Adresse **sender@otherdomain.tld** sendet eine E-Mail an **contact@domain.tld**.
- Der sendende E-Mail-Server (**Outgoing mail server**) fragt die DNS-Zone des Domainnamens **domain.tld** ab und liest die **MX**-Einträge.
- Die E-Mail wird an die URL des gelesenen **MX**-Eintrags weitergeleitet.

<Region zones={['eu']}>

- Die E-Mail wird an das Ziel **mx0.mail.ovh.net** gesendet, dem der Wert **0** vorangestellt ist. Dieser Wert entspricht der Priorität: Der niedrigste Wert wird zuerst abgefragt, der höchste zuletzt. Das bedeutet, dass mehrere MX-Einträge eine fehlende Antwort des Servers ausgleichen, der durch den Eintrag mit der niedrigsten Priorität festgelegt wurde, indem nacheinander die folgenden Server in der Prioritätsreihenfolge abgefragt werden.

</Region>

<Region zones={['ca', 'apac']}>

- Die E-Mail wird an das Ziel **mx0.mail.ovh.ca** gesendet, dem der Wert **0** vorangestellt ist. Dieser Wert entspricht der Priorität: Der niedrigste Wert wird zuerst abgefragt, der höchste zuletzt. Das bedeutet, dass mehrere MX-Einträge eine fehlende Antwort des Servers ausgleichen, der durch den Eintrag mit der niedrigsten Priorität festgelegt wurde, indem nacheinander die folgenden Server in der Prioritätsreihenfolge abgefragt werden.

</Region>

<img className="thumbnail" alt="E-Mail" src="/images/assets/schemas/emails/mx-dns-resolution.png" loading="lazy" />

Sie können mehrere MX-Einträge für denselben Domainnamen einrichten. In diesem Fall ist es notwendig, eine Prioritätsnummer für jeden dieser Einträge zu definieren. MX-Einträge werden in aufsteigender Reihenfolge von der niedrigsten zur höchsten Nummer abgefragt, bis eine Antwort vom empfangenden Server erfolgt.

:::warning
Generell ist bei der **Änderung der MX-Einträge in der DNS-Zone Ihres Domainnamens Vorsicht geboten**: Bei einer fehlerhaften Änderung können E-Mails an Ihre Adressen nicht mehr empfangen werden.
Im Zweifelsfall empfehlen wir Ihnen, einen [spezialisierten Dienstleister](/links/partner) zu kontaktieren.

:::

### MX-Eintrag in einer OVHcloud DNS-Zone konfigurieren

Klicken Sie auf die unten stehenden Tabs, um die **5** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> und wählen Sie den betreffenden Domainnamen aus.

    <img className="thumbnail" alt="Seite Domains & DNS und Liste der Domainnamen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">DNS-Zone</code>. Ihre Einträge werden in einer Tabelle aufgelistet, mit einer Zeile pro Eintrag.

    <img className="thumbnail" alt="Tab DNS-Zone eines Domainnamens und Tabelle der Einträge" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Prüfen Sie zunächst, ob bereits MX-Einträge vorhanden sind: Klicken Sie über der Tabelle auf <code className="action">Filter</code> und wählen Sie dann in der Liste **Eintragstyp** <code className="action">MX</code> aus, oder verwenden Sie das Feld **Suchen**.

    <img className="thumbnail" alt="Auf MX-Einträge gefilterte DNS-Zone" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-mx.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    - **Um einen bestehenden MX-Eintrag zu ändern**, klicken Sie in seiner Zeile auf den Button <code className="action">⋮</code> in der Spalte **Aktionen** und dann auf <code className="action">Ändern</code>. Die Zeile wird zu einem Bearbeitungsformular erweitert.

      <img className="thumbnail" alt="Aktionsmenü eines MX-Eintrags der DNS-Zone" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/mx-row-actions.png" loading="lazy" />

    - **Um einen neuen MX-Eintrag hinzuzufügen**, klicken Sie über der Tabelle auf <code className="action">Eintrag hinzufügen</code>. Wählen Sie im sich öffnenden Formular in der Liste **Typ** `MX — Mailserver` aus.

      <img className="thumbnail" alt="Liste Typ des Formulars Eintrag hinzufügen, Typ MX" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-mx.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 5">
    Füllen Sie die Felder entsprechend der von Ihnen verwendeten E-Mail-Lösung aus:

    - **Wenn Sie über eine E-Mail-Lösung von OVHcloud verfügen**, verwenden Sie die Werte aus dem obigen Abschnitt "[Werte der OVHcloud MX-Konfiguration](#mxovhcloud)": `@` im Feld **Subdomain**, dann die **Priorität** und das **Ziel (Mailserver)** jedes Eintrags.
    - **Wenn Sie eine andere E-Mail-Lösung nutzen**, beachten Sie die Angaben Ihres E-Mail-Dienstanbieters.

    Geben Sie die **TTL** an (belassen Sie sie auf `Standard` oder wählen Sie `Benutzerdefiniert`) und klicken Sie dann auf <code className="action">Hinzufügen</code> (bzw. auf <code className="action">Ändern</code> bei einem bestehenden Eintrag). Das Formular weist darauf hin, dass die manuelle Bearbeitung der MX-Felder zum Verlust von E-Mails führen kann: Überprüfen Sie Ihre Werte vor der Bestätigung.

    <img className="thumbnail" alt="Formular Eintrag hinzufügen der DNS-Zone, MX-Eintrag auf mx0.mail.ovh.net" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-mx-record.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
Jede Änderung erfordert eine Propagationszeit zwischen 4 und 24 Stunden, bis sie voll wirksam ist.

:::
