## Ziel

Die Option [DNS Anycast](/links/web/domains-options-anycast) beschleunigt die DNS-Auflösung Ihres Domainnamens weltweit. Sie benötigen diese Beschleunigung nicht mehr oder möchten sie zum Ablaufdatum nicht mehr verlängern?

**Erfahren Sie, wie Sie die DNS Anycast Option Ihres Domainnamens über Ihr OVHcloud Kundencenter kündigen.**

## Voraussetzungen

- Sie verfügen über einen [Domainnamen](/links/web/domains) bei OVHcloud.
- Die Option DNS Anycast ist für den betreffenden Domainnamen aktiviert. Um dies zu prüfen, lesen Sie unsere Anleitung "[DNS Anycast für Ihren Domainnamen aktivieren](/guides/web-cloud/domains/dns-anycast-enable)".
- Sie sind in Ihrem OVHcloud Kundencenter angemeldet.

- **Direkter Link:** <ManagerLink to="/#/web-domains/domain">Domainnamen</ManagerLink>

## In der praktischen Anwendung

:::info
Die Kündigung wird nicht sofort wirksam: Die Option DNS Anycast bleibt bis zu ihrem Ablaufdatum aktiv und funktionsfähig. Sie wird nicht verlängert und zu diesem Datum gelöscht.
:::

Klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie zur Seite <ManagerLink to="/#/web-domains/domain">Domainnamen</ManagerLink> und wählen Sie dann den betreffenden Domainnamen aus.

    <img className="thumbnail" alt="Liste der Domainnamen im OVHcloud Kundencenter" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-names.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Wählen Sie beim betreffenden Domainnamen den Tab <code className="action">DNS-Server</code> aus.

    <img className="thumbnail" alt="Tab DNS-Server eines Domainnamens" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie in der rechten Spalte der angezeigten Seite auf den Button <code className="action">DNS Anycast kündigen</code>.

    <img className="thumbnail" alt="Button DNS Anycast kündigen im Tab DNS-Server" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Die angezeigte Seite erläutert den Zweck der Option sowie das Datum, zu dem sie automatisch verlängert wird. Klicken Sie auf den Button <code className="action">DNS Anycast kündigen</code>.

    <img className="thumbnail" alt="Seite zur Kündigung der Option DNS Anycast" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns-page.png" loading="lazy" />

    Klicken Sie im angezeigten Bestätigungsfenster auf <code className="action">Bestätigen</code>, um die Kündigung des Dienstes DNS Anycast zu bestätigen.

    <img className="thumbnail" alt="Bestätigungsfenster für die Kündigung des Dienstes DNS Anycast" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns-confirm.png" loading="lazy" />
  </Tab>
</Tabs>

Sobald die Kündigung erfasst ist, prüfen Sie diese im Tab <code className="action">Allgemeine Informationen</code> Ihres Domainnamens: Der Abschnitt **Konfiguration** zeigt den Status der Option DNS Anycast sowie das Datum an, zu dem sie wirksam wird.

:::info
Nach dem Wirksamwerden der Kündigung verwendet Ihr Domainname die DNS Anycast Server nicht mehr. Berücksichtigen Sie die natürliche Propagationszeit des DNS-Dienstes, die bis zu 48 Stunden dauern kann.
:::
