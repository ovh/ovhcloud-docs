## Ziel

Sie möchten Ihre Website über einen bestimmten Domainnamen erreichbar machen? Hierzu muss Ihr Domainname auf die IP-Adresse des Dienstes verweisen, auf dem sich Ihre Website befindet (Webhosting, Dedicated Server, VPS, etc.). Konfigurieren Sie hierzu die aktive DNS-Zone Ihrer Domain mit einem DNS-Eintrag vom Typ AAAA.

**Diese Anleitung erklärt, wie Sie einen DNS-Eintrag vom Typ AAAA zu einer von OVHcloud verwalteten DNS-Zone für Ihre Domain hinzufügen.**

:::info
Befolgen Sie [diese Anleitung](/guides/web-cloud/domains/dns-zone-edit), um einen DNS-Eintrag vom Typ AAAA einer OVHcloud DNS-Zone zu ändern oder zu löschen.

:::

## Voraussetzungen

- Sie haben einen [Domainnamen](/links/web/domains).
- Sie nutzen eine diesem Domainnamen zugeordnete DNS-Zone bei OVHcloud.

[[cpnav:web-domain-dns-zone]]

## In der praktischen Anwendung

:::warning
Das Hinzufügen, Ändern oder Löschen von DNS-Einträgen in einer aktiven DNS-Zone kann zu Dienstunterbrechungen führen. Im Zweifelsfall wenden Sie sich an einen [spezialisierten Dienstleister](/links/partner).

:::

### Einen DNS-Eintrag vom Typ AAAA für eine Domain hinzufügen

Klicken Sie auf die unten stehenden Tabs, um die **5** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> und wählen Sie den betreffenden Domainnamen aus.

    <img className="thumbnail" alt="Seite Domains & DNS und Liste der Domainnamen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">DNS-Zone</code> und dann über der Tabelle auf <code className="action">Eintrag erstellen</code>.

    <img className="thumbnail" alt="Tab DNS-Zone eines Domainnamens und Button Eintrag erstellen" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Wählen Sie im Formular, das sich über der Tabelle öffnet, in der Liste **Typ** `AAAA — Auf eine IPv6 verweisen` aus.

    <img className="thumbnail" alt="Liste Typ des Formulars zum Erstellen eines Eintrags und angebotene Eintragstypen" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Geben Sie im Feld **Subdomain** `@` ein: Dieses Symbol steht für den Domainnamen selbst. Geben Sie im Feld **Ziel (IPv6)** die IPv6-Adresse (zum Beispiel: `2001:db8:1:1b00:203:0:113:0`) des Dienstes, auf dem sich Ihre Website befindet (Webhosting, Dedicated Server, VPS usw.) ein.

    <img className="thumbnail" alt="Formular zum Erstellen eines Eintrags in der DNS-Zone, AAAA-Eintrag für den Domainnamen" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-aaaa-record.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 5">
    Überprüfen Sie die **Datensatzvorschau** und klicken Sie dann auf <code className="action">Hinzufügen</code>.
  </Tab>
</Tabs>

Es dauert bis zu **24** Stunden, bis die Änderung im DNS-Netzwerk voll wirksam ist.

### Einen DNS-Eintrag vom Typ AAAA für die Subdomain einer Domain hinzufügen

Klicken Sie auf die unten stehenden Tabs, um die **5** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> und wählen Sie den betreffenden Domainnamen aus.

    <img className="thumbnail" alt="Seite Domains & DNS und Liste der Domainnamen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">DNS-Zone</code> und dann über der Tabelle auf <code className="action">Eintrag erstellen</code>.

    <img className="thumbnail" alt="Tab DNS-Zone eines Domainnamens und Button Eintrag erstellen" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Wählen Sie im Formular, das sich über der Tabelle öffnet, in der Liste **Typ** `AAAA — Auf eine IPv6 verweisen` aus.

    <img className="thumbnail" alt="Liste Typ des Formulars zum Erstellen eines Eintrags und angebotene Eintragstypen" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Geben Sie im Feld **Subdomain** die betreffende Subdomain ein (zum Beispiel: `www` für `www.domain.tld`). Geben Sie im Feld **Ziel (IPv6)** die IPv6-Adresse (zum Beispiel: `2001:db8:1:1b00:203:0:113:0`) des Dienstes, auf dem sich Ihre Website befindet (Webhosting, Dedicated Server, VPS usw.) ein.

    <img className="thumbnail" alt="Formular zum Erstellen eines Eintrags in der DNS-Zone, AAAA-Eintrag für die Subdomain www" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-aaaa-record-www.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 5">
    Überprüfen Sie die **Datensatzvorschau** und klicken Sie dann auf <code className="action">Hinzufügen</code>. Es kann bis zu **24** Stunden dauern, bis die Änderung im DNS-Netzwerk vollständig propagiert ist.
  </Tab>
</Tabs>
