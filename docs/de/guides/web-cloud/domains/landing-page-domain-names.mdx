## Was ist ein Domainname?

Ein **Domainname** ist die eindeutige und lesbare Adresse Ihrer Online-Präsenz: zum Beispiel `mydomain.ovh`. Er ersetzt die technische IP-Adresse Ihrer Server durch einen Namen, der leicht zu merken und zu teilen ist – sowohl für eine Website als auch für Ihre E-Mail-Adressen.

Ein Domainname besteht aus zwei Teilen, die von rechts nach links gelesen werden:

- der **Endung** (oder TLD, *Top-Level Domain*), dem Suffix, das auf den letzten Punkt folgt: `.ovh`, `.com`, `.fr`…;
- der **Domain** (dem *Label*), dem Namen, den Sie wählen und reservieren: `mydomain`.

Anschließend können Sie **Subdomains** vor Ihrer Domain hinzufügen (`www.mydomain.ovh`, `blog.mydomain.ovh`), um Ihre verschiedenen Dienste zu unterscheiden.

Der Domainname ist somit das **Eingangstor** zu Ihrer Online-Präsenz: Ohne ihn müssten Ihre Besucher die technische IP-Adresse Ihres Servers kennen, um auf Ihre Website zuzugreifen.

## Der Lebenszyklus eines Domainnamens

Von der Registrierung bis zur Verlängerung durchläuft ein Domainname drei Hauptphasen. Jederzeit können Sie ihn zudem transferieren. Wählen Sie eine Phase aus, um zur entsprechenden Einstiegsanleitung zu gelangen.

<DomainLifecycle />

### Registrieren

Einen Domainnamen erhalten Sie bei einem Registrar wie OVHcloud für einen verlängerbaren Zeitraum. Sie können eine neue Domain reservieren oder eine bereits anderswo registrierte Domain [zu OVHcloud transferieren](/guides/web-cloud/domains/transfer-incoming-generic-domain). Die [FAQ zu Domainnamen & DNS](/guides/web-cloud/domains/faq-domain-dns) beantwortet die häufigsten Fragen.

### Konfigurieren

Sobald die Domain registriert ist, entscheiden Sie, worauf sie verweist: eine Website, eine E-Mail-Adresse oder eine [Weiterleitung](/guides/web-cloud/domains/redirect-domain-name). All dies beruht auf ihrer [DNS-Konfiguration](/guides/web-cloud/domains/dns/landing-page-dns). Sie können auch [Subdomains erstellen](/guides/web-cloud/domains/domain-create-subdomains) (wie `blog.mydomain.ovh`), um Ihre verschiedenen Dienste zu organisieren.

### Verlängern

Ein Domainname wird für einen festgelegten Zeitraum reserviert: ohne Verlängerung läuft er ab und wird wieder für andere Personen verfügbar. Aktivieren Sie die [automatische Verlängerung](/guides/web-cloud/domains/autorenew-domain-name), um Ihre Adresse nie durch bloßes Vergessen zu verlieren.

### Transferieren

Sie bleiben jederzeit frei in Ihrer Entscheidung: [transferieren Sie Ihre Domain zu OVHcloud](/guides/web-cloud/domains/transfer-incoming-generic-domain) von einem anderen Registrar, oder [transferieren Sie sie umgekehrt zu einem anderen Registrar](/guides/web-cloud/domains/transfer-outgoing-domain).
