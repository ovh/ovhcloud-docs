**D**omain **N**ame **S**ystem bezeichnet einen Satz von Elementen (DNS-Server, DNS-Zonen, etc.), mit denen ein Domainname IP-Adressen zugeordnet werden kann.

Weitere Informationen finden Sie in unseren Anleitungen "[Alle Informationen zu DNS-Servern](/guides/web-cloud/domains/dns-server-general-information)" und "[Alle Informationen zu DNS-Zonen](/guides/web-cloud/domains/dns-zone-general-information)"

**Erfahren Sie hier, wie Sie Ihre OVHcloud DNS-Zone über die OVHcloud Konsole bearbeiten.**

## Voraussetzungen

- OVHcloud DNS-Server sind in Verwendung für die betreffende Domain.

[[cpnav:web-domain-dns-zone-console]]

:::warning
- Wenn Ihre Domain nicht die DNS-Server von OVHcloud verwendet, muss die Änderung über das Interface des Anbieters vorgenommen werden, der die DNS-Konfiguration Ihrer Domain verwaltet.

- Wenn Ihre Domain bei OVHcloud registriert ist, können Sie überprüfen, ob sie unsere Konfiguration verwendet. Lesen Sie bei Bedarf unsere Anleitung "[DNS-Server einer OVHcloud Domain bearbeiten](/guides/web-cloud/domains/dns-server-edit)".

Seien Sie in jedem Fall vorsichtig, wenn Sie Ihre DNS-Server ändern. Die alte Konfiguration wird deaktiviert, wenn Sie die neue DNS-Zone bei OVHcloud aktivieren und nicht zuvor neu konfiguriert und bearbeitet haben.

Sie können nur eine aktive DNS-Zone pro Domainname nutzen.

:::

## In der praktischen Anwendung

### Zugang zur Verwaltung einer OVHcloud DNS-Zone

:::info
Im Gegensatz zum Domainnamen gibt es für eine DNS-Zone keinen Inhaber, lediglich die Kontaktverwaltung bei OVHcloud. Wenn Sie die Verwaltung Ihrer DNS-Zone auf einen anderen OVHcloud Kunden-Account übertragen möchten, folgen Sie unserer Anleitung [Die Kontakte Ihrer Dienste verwalten](/guides/account-and-service-management/account-information/managing-contacts).

:::

Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink>, wählen Sie den betreffenden Domainnamen aus und klicken Sie dann auf den Tab <code className="action">DNS-Zone</code>. Er listet Ihre Einträge in einer Tabelle auf, eine Zeile pro Eintrag, mit der **Subdomain**, dem **Typ** des Eintrags, seinem **Ziel** und seiner **TTL**. Sie können die Tabelle mit dem Feld **Suchen** durchsuchen oder sie mit dem Button <code className="action">Filter</code> nach Eintragstyp filtern.

<img className="thumbnail" alt="Tab DNS-Zone eines Domainnamens und Tabelle der Einträge" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />

### Bearbeiten der OVHcloud DNS-Zone Ihrer Domain

**Die Bearbeitung einer DNS-Zone ist kritisch**: Bei fehlerhaften Änderungen kann es sein, dass Ihre Website nicht mehr erreichbar ist oder Ihre E-Mail-Adressen keine Nachrichten mehr empfangen können.

:::tip
Lesen Sie unsere Anleitung zu [DNS-Einträgen](/guides/web-cloud/domains/dns-zone-records), um sich ein besseres Bild von Ihren DNS-Einstellungen zu machen.

Weitere Informationen finden Sie in unserer Anleitung zu [Subdomains](/guides/web-cloud/domains/domain-create-subdomains).

:::

Im Tab <code className="action">DNS-Zone</code> können Sie einen Eintrag direkt in der Tabelle der Karte **DNS-Einträge** hinzufügen, ändern oder löschen. Mit der Karte **DNS-Zone** oben im Tab können Sie außerdem die Standard-TTL ändern und über ihr Menü <code className="action">Weitere Aktionen</code> die Zone im Textmodus bearbeiten, eine Zonendatei importieren, die Zone exportieren oder sie zurücksetzen. Der Verlauf der Zone wird in der Karte **Verlauf meiner DNS-Zone** unten im Tab angezeigt. **Klicken Sie auf die Überschriften unten, um die Details anzuzeigen.**

<img className="thumbnail" alt="Menü Weitere Aktionen der Karte DNS-Zone" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-actions-menu.png" loading="lazy" />

<details>

<summary>Neuen DNS-Eintrag hinzufügen</summary>

Klicken Sie im Tab <code className="action">DNS-Zone</code> über der Tabelle auf <code className="action">Eintrag erstellen</code>. Zwischen der Werkzeugleiste und der Tabelle öffnet sich ein Formular:

1. Wählen Sie in der Liste **Typ** den Typ des DNS-Eintrags aus, den Sie erstellen möchten (A, AAAA, CNAME, MX, TXT, SPF, DKIM, DMARC, CAA, SRV, TLSA, HTTPS usw.). Jeder Typ zeigt eine kurze Beschreibung seines Zwecks an, und ein Hinweisfeld erläutert den gewählten Eintrag. Der Button <code className="action">Hilfe</code> beschreibt die im Formular erwarteten Werte im Detail.
2. Füllen Sie die Felder für diesen Eintragstyp aus (**Subdomain**, **Ziel** und alle typspezifischen Felder). Die **Datensatzvorschau** zeigt die Zeile an, die Ihrer Zone hinzugefügt wird.
3. Legen Sie die **TTL** fest: Behalten Sie den Wert `Standard` bei oder wählen Sie `Benutzerdefiniert`, um einen Wert einzugeben.
4. Klicken Sie auf <code className="action">Hinzufügen</code>.

Wenn Sie mit der Syntax von DNS-Zonen vertraut sind, können Sie im Tab <code className="action">Erweiterter Modus</code> des Formulars einen Eintrag direkt im DNS-Format eingeben (zum Beispiel: `www 3600 IN A 203.0.113.1`).

Wir empfehlen Ihnen, vorab zu überprüfen, ob dieser Eintrag nicht bereits existiert und nicht auf ein anderes Ziel verweist. Verwenden Sie dazu das Feld **Suchen** oder filtern Sie die Tabelle mit dem Button <code className="action">Filter</code> nach Eintragstyp. Wenn der Eintrag bereits existiert, ändern Sie ihn stattdessen (siehe unten).

> Wenn das Ziel Ihres Eintrags ein Domainname oder eine Subdomain ist (Typen `CNAME`, `MX`, `NS`, `SRV` oder `DNAME`), fügt das Formular automatisch den abschließenden Punkt zum Ziel hinzu: Die **Datensatzvorschau** zeigt ihn an (zum Beispiel: `domain.tld.`).
> Im Textmodus hingegen müssen Sie das Ziel selbst mit einem Punkt abschließen. Andernfalls wird Ihr Domainname automatisch an das Ende Ihres Ziels angehängt.
> **Beispiel**: Für einen CNAME-Eintrag von `test.domain.tld` auf `domain.tld` muss das Ziel `domain.tld.` lauten und nicht `domain.tld` ohne den **.** am Ende.

<img className="thumbnail" alt="Formular zum Erstellen eines Eintrags in der DNS-Zone, Typ A ausgewählt" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry.png" loading="lazy" />

</details>

<details>

<summary>Existierenden DNS-Eintrag bearbeiten</summary>

Klicken Sie in der Tabelle des Tabs <code className="action">DNS-Zone</code> in der Zeile des betreffenden Eintrags in der Spalte **Aktionen** auf den Button <code className="action">⋮</code> und dann auf <code className="action">Ändern</code>.

<img className="thumbnail" alt="Aktionsmenü einer Zeile der DNS-Zone" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/row-actions.png" loading="lazy" />

Die Zeile wird zu einem Bearbeitungsformular erweitert: Ändern Sie die Werte und klicken Sie dann zur Bestätigung auf <code className="action">Ändern</code>.

<img className="thumbnail" alt="Unter der Zeile eines A-Eintrags erweitertes Bearbeitungsformular" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/edit-entry.png" loading="lazy" />

</details>

<details>

<summary>DNS-Eintrag löschen</summary>

Klicken Sie in der Tabelle des Tabs <code className="action">DNS-Zone</code> in der Zeile des betreffenden Eintrags in der Spalte **Aktionen** auf den Button <code className="action">⋮</code> und dann auf <code className="action">Löschen</code>. Bestätigen Sie im Fenster **DNS-Eintrag löschen**, das sich öffnet, mit einem Klick auf <code className="action">Löschen</code>.

Um mehrere Einträge gleichzeitig zu löschen, haken Sie deren Kästchen links in der Tabelle an, klicken Sie auf den Button <code className="action">X Eintrag/Einträge löschen</code>, der über der Tabelle erscheint (X ist die Anzahl der angehakten Einträge), und bestätigen Sie.

<img className="thumbnail" alt="Löschen eines DNS-Eintrags über das Aktionsmenü" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/row-actions.png" loading="lazy" />

</details>

<details>

<summary>Die Zone im Textmodus bearbeiten oder eine Zonendatei importieren</summary>

:::warning
Nur für erfahrene Benutzer. Achten Sie auch sehr auf die Syntax, wenn Sie Änderungen vornehmen.

:::

Öffnen Sie im Tab <code className="action">DNS-Zone</code> das Menü <code className="action">Weitere Aktionen</code> der Karte **DNS-Zone** und klicken Sie auf <code className="action">Im Textmodus bearbeiten</code>. Die Karte **DNS-Einträge** wechselt in die <code className="action">Textansicht</code>: Der aktuelle Inhalt Ihrer Zone wird angezeigt und bleibt bearbeitbar; bearbeiten Sie ihn direkt. Der Button <code className="action">Diff-Modus verwenden</code> zeigt die Unterschiede zwischen der aktuellen Version und Ihren Änderungen an. Klicken Sie anschließend auf <code className="action">Speichern</code> oder auf <code className="action">Änderungen verwerfen</code>, um zum gespeicherten Inhalt zurückzukehren.

:::warning
Ändern Sie die DNS-Einträge Ihrer DNS-Zone im Textmodus nicht zu Gunsten von DNS-Servern außerhalb von OVHcloud. Diese DNS-Zone funktioniert **nur** mit OVHcloud DNS-Servern.

:::

<img className="thumbnail" alt="Karte DNS-Einträge in der Textansicht" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/text-mode.png" loading="lazy" />

Um den Inhalt Ihrer Zone durch den einer Zonendatei zu ersetzen, öffnen Sie das Menü <code className="action">Weitere Aktionen</code> der Karte **DNS-Zone**, klicken Sie auf <code className="action">Datei importieren</code> und wählen Sie Ihre Datei aus (akzeptierte Dateien: `.txt`, `.zone`). Ihr Inhalt öffnet sich in der Karte **DNS-Einträge** in der <code className="action">Textansicht</code>, und der Diff-Modus zeigt an, was sich gegenüber Ihrer aktuellen Zone ändert. Es wird nichts geändert, solange Sie nicht auf <code className="action">Speichern</code> geklickt haben: Das Speichern ersetzt dann die bestehenden Einträge Ihrer Zone.

</details>

<details>

<summary>DNS-Zone zurücksetzen</summary>

Durch das Zurücksetzen Ihrer DNS-Zone können Sie zu einer minimalen Konfiguration zurückkehren. Dabei werden die Standardeinträge von OVHcloud oder Ihrer Dienste verwendet. Sie können Ihren Domainnamen auch eigenen Webhosting- und E-Mail-Diensten zuordnen.

:::danger
Bevor Sie Ihre DNS-Zone zurücksetzen, vergewissern Sie sich, dass Ihr Domainname nicht mit anderen Diensten wie Websites oder E-Mail-Adressen verbunden ist.

:::

Öffnen Sie im Tab <code className="action">DNS-Zone</code> das Menü <code className="action">Weitere Aktionen</code> der Karte **DNS-Zone** und klicken Sie auf <code className="action">Zone zurücksetzen</code>.

<img className="thumbnail" alt="Menü Weitere Aktionen der Karte DNS-Zone" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-actions-menu.png" loading="lazy" />

Im sich öffnenden Bereich **DNS-Zone zurücksetzen**:

- Wählen Sie, wie Ihre Zone zurückgesetzt werden soll: mit den `Standardwerte` von OVHcloud oder mit `Benutzerdefinierte Werte`, um selbst festzulegen, wohin Ihr Domainname verweist und an welchen Server Ihre E-Mails weitergeleitet werden.
- Wählen Sie aus, ob nur die **Mindesteinträge** (`NS` und `SOA`) neu erstellt werden sollen. Mindesteinträge in einer DNS-Zone verhindern, dass eine Anfrage an den Domainnamen zu einem Fehler führt.
- Legen Sie mit benutzerdefinierten Werten das Ziel der IP-Adresse des **Webhostings** fest (`A`-Eintrag): die OVHcloud `Weiterleitung`, `OVHcloud Webhosting` (wählen Sie dann das betreffende Hosting aus) oder eine `Benutzerdefiniert`-IPv4-Adresse.
- Legen Sie mit benutzerdefinierten Werten das Ziel des **E-Mail-Servers** fest (`MX`-Eintrag): die OVHcloud `Weiterleitung`, den `OVHcloud E-Mail-Server` oder einen `Benutzerdefiniert`-Server mit Priorität.

Klicken Sie anschließend auf <code className="action">Zone zurücksetzen</code>.

<img className="thumbnail" alt="Bereich zum Zurücksetzen der DNS-Zone" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/reset-zone.png" loading="lazy" />

</details>

<details>

<summary>Historie Ihrer DNS-Zone anzeigen</summary>

Der Verlauf Ihrer Zone wird in der Karte **Verlauf meiner DNS-Zone** unten im Tab <code className="action">DNS-Zone</code> angezeigt. Dort können Sie eine frühere Version Ihrer Zone anzeigen, herunterladen, vergleichen und wiederherstellen. Weitere Informationen finden Sie in unserer Anleitung "[Versionsverlauf einer DNS-Zone verwalten](/guides/web-cloud/domains/dns-zone-history)".

</details>

### Propagationszeit

Nach der Änderung der DNS-Zone Ihrer Domain ist eine Propagationszeit von maximal 24 Stunden erforderlich, bis die Änderungen vollständig übernommen und wirksam sind.

Wenn Sie diese Verzögerung für künftige Bearbeitungen Ihrer OVHcloud DNS-Zone verkürzen möchten, können Sie die TTL (*Time To Live*) anpassen, die für alle Einträge der DNS-Zone gilt. Suchen Sie dazu im Tab <code className="action">DNS-Zone</code> die Zeile **Standard-TTL** der Karte **DNS-Zone** (dort wird der aktuelle Wert angezeigt) und klicken Sie direkt darunter auf <code className="action">Standard-TTL bearbeiten</code>. Wählen Sie im sich öffnenden Fenster eine der **Voreinstellungen** aus oder geben Sie einen Wert `Benutzerdefiniert` in Sekunden ein, und klicken Sie dann auf <code className="action">Speichern</code>.

Sie können die TTL auch für einen einzelnen Eintrag beim Hinzufügen oder Bearbeiten ändern.
