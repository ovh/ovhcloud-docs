**D**omain **N**ame **S**ystem bezeichnet einen Satz von Elementen (DNS-Server, DNS-Zonen, etc.), mit denen ein Domainname IP-Adressen zugeordnet werden kann.

Weitere Informationen finden Sie in unseren Anleitungen „[Alle Informationen zu DNS-Servern](/guides/web-cloud/domains/dns-server-general-information)“ und „[Alle Informationen zu DNS-Zonen](/guides/web-cloud/domains/dns-zone-general-information)“

**Diese Anleitung erklärt, wie Sie Ihre OVHcloud DNS-Zone über Ihr Kundencenter bearbeiten.**

## Voraussetzungen

- OVHcloud DNS-Server sind in Verwendung für die betreffende Domain.

:::warning
- Wenn Ihre Domain nicht die DNS-Server von OVHcloud verwendet, muss die Änderung über das Interface des Anbieters vorgenommen werden, der die DNS-Konfiguration Ihrer Domain verwaltet.

- Wenn Ihre Domain bei OVHcloud registriert ist, können Sie überprüfen, ob sie unsere Konfiguration verwendet. Lesen Sie bei Bedarf unsere Anleitung „[DNS-Server einer OVHcloud Domain bearbeiten](/guides/web-cloud/domains/dns-server-edit)“.

Seien Sie in jedem Fall vorsichtig, wenn Sie Ihre DNS-Server ändern. Die alte Konfiguration wird deaktiviert, wenn Sie die neue DNS-Zone bei OVHcloud aktivieren und nicht zuvor neu konfiguriert und bearbeitet haben.
Sie können nur eine aktive DNS-Zone pro Domainname nutzen.

:::

## In der praktischen Anwendung

### Zugang zur Verwaltung einer OVHcloud DNS-Zone

:::info
Im Gegensatz zum Domainnamen gibt es für eine DNS-Zone keinen Inhaber, lediglich die Kontaktverwaltung bei OVHcloud. Wenn Sie die Verwaltung Ihrer DNS-Zone auf einen anderen OVHcloud Kunden-Account übertragen möchten, folgen Sie unserer Anleitung [Die Kontakte Ihrer Dienste verwalten](/guides/account-and-service-management/account-information/managing-contacts).

:::

Der Tab **DNS-Zone** listet Ihre Einträge in einer Tabelle auf, mit einer Zeile pro Eintrag, in der die **Subdomain**, der **Typ** des Eintrags, sein **Ziel** und seine **TTL** angezeigt werden. Sie können die Tabelle durchsuchen oder nach Eintragstyp filtern.

<img className="thumbnail" alt="Tab DNS-Zone im OVHcloud Kundencenter" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-zone-overview.png" loading="lazy" />

### Bearbeiten der OVHcloud DNS-Zone Ihrer Domain

**Die Bearbeitung einer DNS-Zone ist kritisch**: Bei fehlerhaften Änderungen kann es sein, dass Ihre Website nicht mehr erreichbar ist oder Ihre E-Mail-Adressen keine Nachrichten mehr empfangen können.

:::tip
Lesen Sie unsere Anleitung zu [DNS-Einträgen](/guides/web-cloud/domains/dns-zone-records), um sich ein besseres Bild von Ihren DNS-Einstellungen zu machen.

Weitere Informationen finden Sie in unserer Anleitung zu [Subdomains](/guides/web-cloud/domains/domain-create-subdomains).

:::

Über den Tab **DNS-Zone** können Sie einen Eintrag direkt in der Tabelle hinzufügen, bearbeiten oder löschen, die gesamte Zone im Textmodus bearbeiten, die Zone zurücksetzen oder ihre Historie anzeigen. **Klicken Sie auf die nachstehenden Überschriften, um die Details anzuzeigen.**

<img className="thumbnail" alt="Menü Aktionen zu meiner Zone der DNS-Zone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-actions-menu.png" loading="lazy" />

<details>

<summary>Neuen DNS-Eintrag hinzufügen</summary>

Klicken Sie oberhalb der Tabelle auf <code className="action">Eintrag hinzufügen</code>. Zwischen der Symbolleiste und der Tabelle öffnet sich ein Formular:

1. Wählen Sie den **Typ des DNS-Eintrags** aus, den Sie erstellen möchten (A, AAAA, CNAME, MX, TXT, SPF, DKIM, DMARC, CAA, SRV, TLSA, HTTPS usw.). Zu jedem Typ wird eine kurze Beschreibung seines Zwecks angezeigt.
2. Füllen Sie die Felder für diesen Eintragstyp aus (Subdomain, Ziel und alle typspezifischen Felder).
3. Legen Sie die **TTL** fest — belassen Sie sie auf `Standard` oder wählen Sie `Benutzerdefiniert`, um einen Wert einzugeben.
4. Klicken Sie auf <code className="action">Hinzufügen</code>.

Wir empfehlen Ihnen, zunächst zu überprüfen, ob dieser Eintrag bereits vorhanden ist und auf ein anderes Ziel verweist. Verwenden Sie hierzu das Suchfeld oder filtern Sie die Tabelle nach Eintragstyp. Wenn der Eintrag bereits existiert, bearbeiten Sie ihn stattdessen (siehe unten).

> Wenn das Ziel Ihres Eintrags eine URL ist, denken Sie daran, diese zu punktieren. Wenn Sie dies nicht tun, wird Ihr Domainname automatisch am Ende Ihres Ziels hinzugefügt.
> **Beispiel**: Sie möchten einen CNAME-Eintrag von `test.mydomain.ovh` auf `mydomain.ovh` erstellen.
> Sie müssen dann als Ziel `mydomain.ovh.` haben, anstatt `mydomain.ovh` ohne **.** am Ende.

<img className="thumbnail" alt="Eintrag über die DNS-Zone hinzufügen" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-add-entry.png" loading="lazy" />

</details>

<details>

<summary>Existierenden DNS-Eintrag bearbeiten</summary>

Öffnen Sie in der Tabelle in der Zeile des betreffenden Eintrags das Aktionsmenü <code className="action">⋮</code> und klicken Sie auf <code className="action">Eintrag bearbeiten</code>. Die Zeile wird zu einem Bearbeitungsformular erweitert: Ändern Sie die Werte und bestätigen Sie anschließend.

<img className="thumbnail" alt="Aktionsmenü einer Zeile der DNS-Zone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-row-menu.png" loading="lazy" />

</details>

<details>

<summary>DNS-Eintrag löschen</summary>

Öffnen Sie in der Tabelle in der Zeile des betreffenden Eintrags das Aktionsmenü <code className="action">⋮</code>, klicken Sie auf <code className="action">Eintrag löschen</code> und bestätigen Sie anschließend.

Um mehrere Einträge auf einmal zu löschen, setzen Sie links in der Tabelle die entsprechenden Häkchen und klicken Sie dann auf den Button <code className="action">Löschen</code>, der oberhalb der Tabelle erscheint.

<img className="thumbnail" alt="Löschen eines DNS-Eintrags über das Aktionsmenü" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-row-menu.png" loading="lazy" />

</details>

<details>

<summary>Zone im Textmodus bearbeiten</summary>

:::warning
Nur für erfahrene Benutzer. Achten Sie auch sehr auf die Syntax, wenn Sie Änderungen vornehmen.

:::

Öffnen Sie oberhalb der Tabelle das Menü <code className="action">Aktionen zu meiner Zone</code> und klicken Sie auf <code className="action">Im Textmodus bearbeiten</code>. Auf der Seite, die sich öffnet, wird der aktuelle Inhalt Ihrer Zone angezeigt und kann bearbeitet werden: Ändern Sie ihn direkt oder importieren Sie eine Zonendatei, indem Sie sie in den vorgesehenen Bereich ziehen oder auf <code className="action">Dateien durchsuchen</code> klicken (akzeptierte Dateien: `.txt`, `.zone`). Klicken Sie anschließend auf <code className="action">Importieren</code>.

:::warning
Ändern Sie die DNS-Einträge Ihrer DNS-Zone im Textmodus nicht zu Gunsten von DNS-Servern außerhalb von OVHcloud. Diese DNS-Zone funktioniert **nur** mit OVHcloud DNS-Servern.

:::

<img className="thumbnail" alt="Bearbeiten der DNS-Zone im Textmodus" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-text-mode.png" loading="lazy" />

</details>

<details>

<summary>DNS-Zone zurücksetzen</summary>

Durch das Zurücksetzen Ihrer DNS-Zone können Sie zu einer minimalen Konfiguration zurückkehren. Dabei werden die Standardeinträge von OVHcloud oder Ihrer Dienste verwendet. Sie können Ihren Domainnamen auch eigenen Webhosting- und E-Mail-Diensten zuordnen.

:::danger
Bevor Sie Ihre DNS-Zone zurücksetzen, vergewissern Sie sich, dass Ihr Domainname nicht mit anderen Diensten wie Websites oder E-Mail-Adressen verbunden ist.

:::

Öffnen Sie oberhalb der Tabelle das Menü <code className="action">Aktionen zu meiner Zone</code> und klicken Sie auf <code className="action">Meine DNS-Zone zurücksetzen</code>. Folgen Sie anschließend den Schritten im geöffneten Bereich:

- Wählen Sie aus, ob mit den **minimalen Einträgen** zurückgesetzt werden soll. Die Festlegung von Minimaleinträgen in einer DNS-Zone verhindert Fehlerantworten bei der Abfrage des Domainnamens.
- Legen Sie das Ziel für die IP-Adresse des **Webhostings** (`A`-Eintrag) fest: `Weiterleitung`, `OVHcloud Webhosting` oder `Benutzerdefiniert` für eine eigene IPv4-Adresse.
- Legen Sie das Ziel für den **Mailserver** (`MX`-Eintrag) fest: `Weiterleitung`, `OVHcloud E-Mail-Server` oder `Benutzerdefiniert` für einen eigenen Server samt Priorität.

<img className="thumbnail" alt="Panel zum Zurücksetzen der DNS-Zone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-reset-zone.png" loading="lazy" />

</details>

<details>

<summary>Historie Ihrer DNS-Zone anzeigen</summary>

Öffnen Sie oberhalb der Tabelle das Menü <code className="action">Aktionen zu meiner Zone</code> und klicken Sie auf <code className="action">Historie meiner DNS-Zone anzeigen</code>. Von dort aus können Sie eine frühere Version Ihrer Zone anzeigen, herunterladen und wiederherstellen. Weitere Details finden Sie in unserer Anleitung [Die Historie einer DNS-Zone verwalten](/guides/web-cloud/domains/dns-zone-history).

</details>

### Propagationszeit

Nach der Änderung der DNS-Zone Ihrer Domain ist eine Propagationszeit von maximal 24 Stunden erforderlich, bis die Änderungen vollständig übernommen und wirksam sind.

Wenn Sie diese Verzögerung für die nächsten Bearbeitungen Ihrer OVHcloud DNS-Zone verkürzen möchten, können Sie die TTL (*Time To Live*) anpassen, die für alle Einträge in der DNS-Zone gilt. Öffnen Sie dazu oberhalb der Tabelle das Menü <code className="action">Aktionen zu meiner Zone</code> und klicken Sie auf <code className="action">Standard-TTL bearbeiten</code>.

Sie können die TTL auch für einen einzelnen Eintrag beim Hinzufügen oder Bearbeiten ändern.
