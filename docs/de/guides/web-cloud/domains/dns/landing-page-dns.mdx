## Was ist DNS?

**DNS** (*Domain Name System*) ist das Telefonbuch des Internets: Es übersetzt für Menschen lesbare Domainnamen (wie `mydomain.ovh`) in IP-Adressen, die Maschinen verstehen. Ohne DNS müssten Sie sich eine Zahlenfolge merken, um jede Website oder jeden Onlinedienst zu erreichen.

Bei OVHcloud beruht die DNS-Konfiguration eines Domainnamens auf drei Bausteinen:

- die **DNS-Server**, die die Informationen Ihrer Domain hosten und verbreiten;
- die **DNS-Zone**, die Datei, die alle Ihre Einträge zusammenfasst;
- die **DNS-Einträge**, wobei jede Zeile einen Namen mit einem Wert verknüpft (IP-Adresse, Mailserver, Text usw.).

## Wie funktioniert DNS?

Von Ihrem Domainnamen bis zu jedem Eintrag folgt die DNS-Auflösung einer Kette aus vier Gliedern.

<DnsChain />

### Der DNS-Server

DNS-Server hosten und verbreiten die Informationen Ihrer Domain im Internet. Wenn ein Nutzer Ihre Website aufruft, antworten sie, indem sie angeben, wo sie zu finden ist. Standardmäßig verwendet Ihre Domain die DNS-Server von OVHcloud. [Alle Informationen zu DNS-Servern](/guides/web-cloud/domains/dns-server-general-information).

<DnsServerIllustration />

### Die DNS-Zone

Die DNS-Zone ist die Konfigurationsdatei, die mit Ihren DNS-Servern verknüpft ist. Sie fasst alle Einträge Ihrer Domain zusammen: Hier fügen Sie Ihre Einträge hinzu, bearbeiten oder löschen sie. [Alle Informationen zu DNS-Zonen](/guides/web-cloud/domains/dns-zone-general-information).

<DnsZoneIllustration />

### Die DNS-Einträge

Jeder Eintrag ist eine Zeile der Zone, die einen Namen mit einem Wert verknüpft: eine IP-Adresse, einen Mailserver, Text usw. Sein Typ bestimmt seine Funktion, die unten durch die Farbe gekennzeichnet ist. Wählen Sie den Eintrag aus, den Sie konfigurieren möchten, um die passende Anleitung zu öffnen.
