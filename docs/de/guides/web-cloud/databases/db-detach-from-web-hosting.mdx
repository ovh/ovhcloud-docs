## Ziel

Die Lösung [Web Cloud Databases](/links/web/databases) ist in unseren [Webhostings](/links/web/hosting) Performance, Agency, Agency Plus und Agency Max inklusive und kann ohne Zusatzkosten aktiviert werden. In diesem Fall wird sie dem Webhosting zugewiesen, von dem aus sie aktiviert wurde. Wenn sich im Laufe der Nutzung Ihrer Dienste etwas verändert, müssen Sie möglicherweise Ihre Web Cloud Databases von dem Webhosting, an das sie gebunden ist, abtrennen.

**Diese Anleitung erklärt, wie Sie Ihre Web Cloud Databases von einem Webhosting abtrennen.**

## Voraussetzungen

- Sie verfügen über eine [Web Cloud Databases Instanz](/links/web/databases), die mit einem [Webhosting](/links/web/hosting) Performance, Agency, Agency Plus oder Agency Max verbunden ist.
- Sie sind der [Administrator-Kontakt](/guides/account-and-service-management/account-information/managing-contacts) der betroffenen Dienste.

[[cpnav:web-hosting]]

## In der praktischen Anwendung

Klicken Sie auf die unten stehenden Tabs, um die **3** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting mit der Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Im Bereich **Datenbanken** finden Sie den Eintrag **Web Cloud DB**. Klicken Sie auf den Button <code className="action">⋮</code> rechts daneben und dann auf <code className="action">Meine PrivateSQL-Datenbank trennen</code>.

    <img className="thumbnail" alt="Bereich Datenbanken mit dem Menü der Zeile Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Wählen Sie auf der neu geöffneten Seite die gewünschte **Vertragslaufzeit** für Ihre Web Cloud Databases Lösung aus. Die **Zusammenfassung** weist darauf hin, dass Ihre Datenbank künftig zum Standardpreis abgerechnet wird und dass diese Aktion unwiderruflich ist. Klicken Sie auf <code className="action">Weiter</code> und folgen Sie dann den angezeigten Schritten bis zur Zahlung.

    <img className="thumbnail" alt="Seite Meine PrivateSQL-Datenbank trennen mit Angebot, Vertragslaufzeit und Zusammenfassung" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/detach-web-cloud-db.png" loading="lazy" />
  </Tab>
</Tabs>

Sobald Sie diese 3 Schritte abgeschlossen und den Bestellschein bezahlt haben, wird Ihre Web Cloud Databases Lösung innerhalb von höchstens einigen Stunden abgetrennt.
