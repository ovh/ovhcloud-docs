## Ziel

Die Lösung [Web Cloud Databases](/links/web/databases) kann mehrere Datenbanken enthalten. Damit können Sie einen oder mehrere Benutzer für die Verwaltung und Nutzung Ihrer Datenbanken definieren. Diese Benutzer können je nach ihren Rollen in den Datenbanken über mehr oder weniger erweiterte Rechte verfügen.
Bei der Verwendung des Produkts kann es erforderlich sein, die Rechte eines Benutzers auf Ihrer [Web Cloud Databases](/links/web/databases) Lösung zu ändern.

**Diese Anleitung erklärt, wie Sie die Benutzerrechte für Ihre Web Cloud Databases Lösung ändern.**

## Voraussetzungen

- Sie verfügen über eine [Web Cloud Databases](/links/web/databases) Lösung und einen oder mehrere Benutzer.

[[cpnav:web-cloud-databases]]

## In der praktischen Anwendung

:::info
Um einen neuen Benutzer für Ihre Web Cloud Databases Lösung zu erstellen, lesen Sie den Abschnitt **Benutzer erstellen** unserer Anleitung "[Datenbanken und Benutzer auf Ihrem Datenbankserver erstellen](/guides/web-cloud/databases/db-create-databases-users)".

:::

Klicken Sie auf die unten stehenden Tabs, um die **4** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf der angezeigten Seite auf den Tab <code className="action">Benutzer & Rechte</code>.

    <img className="thumbnail" alt="Tab Benutzer & Rechte einer Web Cloud DB Instanz" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Jeder Benutzer wird in einer Karte mit seinem Namen angezeigt. Klicken Sie in der Karte des betreffenden Benutzers auf den Button <code className="action">⋮</code> rechts neben der Angabe **Weitere Aktionen** und dann auf <code className="action">Rechte verwalten</code>.

    <img className="thumbnail" alt="Menü Weitere Aktionen eines Benutzers mit dem Eintrag Rechte verwalten" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Das Panel **Rechte von**, gefolgt vom Namen des Benutzers, öffnet sich auf der rechten Seite. Es listet alle Datenbanken Ihrer Web Cloud Databases Lösung auf und zeigt für jede von ihnen in einem Dropdown-Menü rechts daneben die Rechtestufe an, über die Ihr Benutzer verfügt.

    <img className="thumbnail" alt="Rechte-Panel eines Benutzers mit einer Stufe pro Datenbank" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />

    Hier können Sie die Rechte Ihres Benutzers für jede Ihrer Datenbanken ändern. Wählen Sie hierzu für jede betroffene Datenbank im Dropdown-Menü der Datenbank die Rechtestufe aus, die Sie Ihrem Benutzer zuweisen möchten. Die Änderung wird sofort wirksam: Die Meldung **Recht geändert** wird angezeigt.
  </Tab>
</Tabs>
