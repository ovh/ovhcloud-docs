## Ziel

Die Lösung Web Cloud Databases bietet eine Datenbankinstanz mit dedizierten und garantierten Ressourcen und sorgt so für Leistung und Flexibilität.
Standardmäßig ist Ihre Web Cloud Databases Lösung mit dem OVHcloud Webhosting-Netzwerk verbunden. Sie können sie auch über eine Liste autorisierter IP-Adressen mit jedem anderen Netzwerk verbinden.

**Erfahren Sie, wie Sie mit der Lösung Web Cloud Databases starten.**

## Voraussetzungen

- Sie verfügen über eine [Web Cloud Databases Instanz](/links/web/databases) (in einem [Webhosting](/links/web/hosting) Performance, Agency, Agency Plus oder Agency Max enthalten).

[[cpnav:web-cloud-databases]]

## In der praktischen Anwendung

### Aktivierung Ihres im Webhosting enthaltenen Web Cloud Databases Servers

Wenn Ihr Hosting die Option Web Cloud Databases beinhaltet, klicken Sie auf die unten stehenden Tabs, um die **3** Schritte nacheinander anzuzeigen.

:::warning
Für die Aktivierung dieser Option müssen Sie mindestens Administrator-Kontakt des Webhostings sein, das den Dienst Web Cloud Databases beinhaltet. Weitere Informationen zur Verwaltung der Kontakte finden Sie in unserer Anleitung "[Die Kontakte Ihrer Dienste verwalten](/guides/account-and-service-management/account-information/managing-contacts)".

:::

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/hosting">Webhosting</ManagerLink> und wählen Sie das betreffende Webhosting aus.

    <img className="thumbnail" alt="Seite Webhosting mit der Liste der Hostings des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Suchen Sie im Tab <code className="action">Übersicht</code> den Bereich **Datenbanken**. Die Zeile **Web Cloud DB** zeigt an, dass Ihre Instanz noch nicht aktiviert ist. Klicken Sie unter dieser Zeile auf <code className="action">Aktivieren</code>.

    <img className="thumbnail" alt="Bereich Datenbanken des Hostings mit dem Link Aktivieren in der Zeile Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Wählen Sie auf der angezeigten Seite **Web Cloud DB aktivieren** die Kapazität Ihrer Instanz (die Kapazität von 512 MB ist in Ihrem Webhosting enthalten, höhere Kapazitäten sind kostenpflichtig), dann ihre Engine (PostgreSQL, MariaDB, MySQL oder Valkey) und ihre **Version**. Klicken Sie anschließend auf <code className="action">Aktivieren</code> (enthaltene Kapazität) oder auf <code className="action">Bestellen</code> (kostenpflichtige Kapazität) und bestätigen Sie den Bestellschein, der sich in einem neuen Tab öffnet.

    <img className="thumbnail" alt="Seite Web Cloud DB aktivieren mit der Auswahl von Kapazität, Engine und Version" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate-page.png" loading="lazy" />

    Ihre Instanz ist anschließend über die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> zugänglich.
  </Tab>
</Tabs>

### Allgemeine Informationen der Instanz anzeigen

Klicken Sie auf die unten stehenden Tabs, um die **2** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />

    :::info
    Der Name des Web Cloud DB Dienstes in der OVHcloud Konsole enthält einen Teil Ihrer Kundenkennung und endet mit drei Ziffern (001 für den ersten installierten Web Cloud Databases Dienst, 002 für den zweiten, etc.).

    :::

  </Tab>
  <Tab label="Schritt 2">
    Vergewissern Sie sich, dass Sie sich im Tab <code className="action">Übersicht</code> befinden.

    Überprüfen Sie, ob die in den Bereichen **Allgemeine Informationen** und **Ressourcennutzung** angezeigten Daten korrekt sind oder den nachfolgenden Angaben entsprechen.

    |Information|Details|
    |---|---|
    |Status|Zeigt unter anderem an, ob die Instanz gestartet, gerade neu gestartet oder ausgesetzt ist. Ihre Instanz muss gestartet sein, um Aktionen ausführen zu können.|
    |Datenbank-Engine|Zeigt das vom Server verwendete Datenbanksystem und dessen Version an. Achten Sie auf die Kompatibilität Ihrer Website mit der gewählten Version.|
    |Region|Zeigt die Region des Rechenzentrums an, in dem die Instanz erstellt wurde.|
    |Host|Zeigt den OVHcloud Server an, auf dem Ihre Instanz erstellt wurde. Hierbei handelt es sich um eine der OVHcloud Infrastruktur inhärente Information, die in Mitteilungen zu [OVHcloud Störungen](https://www.status-ovhcloud.com/) verwendet werden kann.|
    |CPU-Auslastung|Gibt an, wie oft Ihre Instanz durch die ihr zugewiesene CPU begrenzt wird. Ist dieser Wert hoch, sollten Sie in Erwägung ziehen, mehr RAM zu bestellen.|
    |RAM|Zeigt den für Ihre Instanz verfügbaren Arbeitsspeicher sowie eventuelle Speicherüberschreitungen an. Ihre Web Cloud Databases Instanz verfügt über dedizierte und garantierte Ressourcen: den RAM. Bei Bedarf können Sie diesen über den Link **Mehr RAM bestellen** upgraden.|
    |Speicherkontingent|Zeigt den von Ihren Daten belegten Speicherplatz im Verhältnis zu dem in Ihrem Angebot enthaltenen Speicherplatz an. Sobald dieses Kontingent erreicht ist, schlagen Schreibvorgänge fehl: Sie müssen dann Daten löschen oder zu einem höheren Angebot wechseln.|

    <img className="thumbnail" alt="Bereiche Allgemeine Informationen und Ressourcennutzung der Übersicht" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/overview.png" loading="lazy" />
  </Tab>
</Tabs>

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />

  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Datenbanken</code>.

    <img className="thumbnail" alt="Tab Datenbanken einer Web Cloud DB Instanz" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie oberhalb der Datenbanktabelle auf <code className="action">Datenbank hinzufügen</code>.

    <img className="thumbnail" alt="Button Datenbank hinzufügen oberhalb der Datenbanktabelle" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    Die Erstellung von PostgreSQL-Schemata ist derzeit auf Web Cloud Databases Servern nicht verfügbar.

    :::

  </Tab>
  <Tab label="Schritt 4">
    Das Panel **Datenbank hinzufügen** öffnet sich auf der rechten Seite. Füllen Sie die Felder gemäß den unter jedem Feld angegebenen Kriterien aus:

    - **Datenbankname** (Pflichtfeld): Dies ist der Name Ihrer zukünftigen Datenbank.
    - **Zugriff auf diese Datenbank**: Wählen Sie aus, wer sich mit der Datenbank verbinden und Anfragen ausführen kann.
        - **Vorläufig kein Zugriff** (Standardauswahl): Die Datenbank wird ohne Benutzer erstellt. Sie können einem Benutzer nachträglich Rechte zuweisen.
        - **Ein bestehender Benutzer**: Wählen Sie den **Benutzer** und anschließend seine **Rechte** für die Datenbank aus.
        - **Ein neuer Benutzer**: Füllen Sie die nachfolgenden Felder aus, um den Benutzer gleichzeitig mit der Datenbank zu erstellen.
    - **Benutzername** (nur mit **Ein neuer Benutzer**): Der Benutzer, der sich mit Ihrer Datenbank verbinden und Anfragen ausführen kann.
    - **Rechte** (mit **Ein bestehender Benutzer** oder **Ein neuer Benutzer**): Die dem Benutzer für die Datenbank zugewiesenen Rechte. Wählen Sie für eine Standardnutzung `Admin`. Die Rechte können nachträglich geändert werden.
    - **Passwort**/**Passwort bestätigen** (nur mit **Ein neuer Benutzer**): Geben Sie ein Passwort ein und bestätigen Sie es.

    Klicken Sie auf <code className="action">Hinzufügen</code>.

    <img className="thumbnail" alt="Panel Datenbank hinzufügen mit einem neuen Benutzer" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
Dieser Schritt gilt nicht für das Datenbanksystem Valkey.

:::

Wenn Ihr Projekt keinen zusätzlichen Benutzer erfordert, können Sie zum nächsten Schritt übergehen. Andernfalls klicken Sie auf die unten stehenden Tabs, um die **4** Schritte nacheinander anzuzeigen.

### IP-Adresse autorisieren

Damit Ihre Web Cloud Databases Instanz funktioniert, müssen Sie die IPs oder IP-Bereiche angeben, die sich mit Ihren Datenbanken verbinden dürfen.

Klicken Sie dazu auf die unten stehenden Tabs, um die **4** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf der angezeigten Seite auf den Tab <code className="action">Autorisierte IPs</code>.

    <img className="thumbnail" alt="Tab Autorisierte IPs einer Web Cloud DB Instanz" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie auf der angezeigten Seite auf den Button <code className="action">IP hinzufügen</code> oberhalb der Tabelle.

    <img className="thumbnail" alt="Button IP hinzufügen oberhalb der Tabelle der autorisierten IPs" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Wenn Sie eine bereits autorisierte IP-Adresse oder einen IP-Bereich ändern möchten, klicken Sie in der Spalte **Aktionen** auf den Button <code className="action">⋮</code> rechts neben der Zeile der zu ändernden IP-Adresse oder des zu ändernden IP-Bereichs und dann auf <code className="action">Bearbeiten</code>. Sie können den Namen und die Berechtigungen ändern; die IP-Adresse selbst kann nicht geändert werden.

    <img className="thumbnail" alt="Menü einer Zeile in der Tabelle der autorisierten IPs" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Schritt 4">
    Im sich öffnenden Fenster **Autorisierte IP hinzufügen** müssen mehrere Felder ausgefüllt werden:

    <img className="thumbnail" alt="Fenster Autorisierte IP hinzufügen mit seinen Feldern" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (Pflichtfeld): Geben Sie die IP-Adresse (z. B. `203.0.113.44`) oder den IP-Bereich (z. B. `203.0.113.0/24`, der alle IP-Adressen von `203.0.113.0` bis `203.0.113.255` umfasst) ein, die Sie für Ihre Web Cloud Databases Lösung autorisieren möchten.
    - **Name** (Pflichtfeld): Sie können hier zum Beispiel die Rolle der betreffenden IP-Adresse oder des IP-Bereichs angeben.
    - **Dienstzugang erlauben** (standardmäßig aktiviert): Aktivieren Sie dieses Kontrollkästchen, damit die IP-Adresse oder der IP-Bereich auf die Datenbanken Ihrer Web Cloud Databases Lösung zugreifen kann.
    - **SFTP-Zugang erlauben**: Aktivieren Sie dieses Kontrollkästchen, damit die IP-Adresse oder der IP-Bereich auf die Logs Ihrer Web Cloud Databases Lösung zugreifen kann.

    :::warning
    Es wird dringend davon abgeraten, das Kontrollkästchen **Dienstzugang erlauben** zu aktivieren, um den IP-Bereich `0.0.0.0/0` für den Zugriff auf Ihre Datenbanken zu autorisieren.

    Dies würde den Zugriff auf Ihre Datenbanken für alle existierenden IPv4-Adressen ermöglichen.

    :::

    Klicken Sie nach Eingabe der Informationen auf den Button <code className="action">Hinzufügen</code>.
  </Tab>
</Tabs>

### Verbindungen von einem OVHcloud Webhosting erlauben <a name="trustip"></a>

Standardmäßig ist Ihre Web Cloud Databases Lösung automatisch mit OVHcloud Webhostings verknüpft. Wenn Sie möchten, können Sie den Zugriff von OVHcloud Webhostings auf Ihre Web Cloud Databases deaktivieren.

Lesen Sie dazu die Sonderfälle in unserer Anleitung "[Web Cloud Databases - Wie kann eine IP-Adresse autorisiert werden?](/guides/web-cloud/databases/db-authorise-ip-mask)", um den Zugriff von OVHcloud Webhostings auf Ihre Web Cloud Databases zu aktivieren oder zu deaktivieren.

### Ihre Website mit der Datenbank verbinden

Nachdem Ihre Datenbank erstellt wurde, ein oder mehrere Benutzer Rechte dafür haben und mindestens eine IP-Adresse oder OVHcloud Webhostings auf Ihrer Web Cloud Databases Instanz autorisiert wurden, muss nur noch Ihre Website mit Ihrer Datenbank verbunden werden. Dieser Schritt kann auf verschiedene Weisen erfolgen, je nach Website oder CMS (WordPress, Joomla!, etc.) und je nachdem, in welchem Stadium Sie sich bei der Installation einer Website befinden.

Dafür benötigen Sie die folgenden 5 Informationen:

|Information|Beschreibung|
|---|---|
|Datenbankname|Der Name, den Sie bei der Erstellung der Datenbank festgelegt haben.|
|Benutzername|Der Benutzername, den Sie bei der Erstellung der Datenbank festgelegt haben, oder ein zusätzlicher Benutzer, den Sie hinzugefügt haben.|
|Benutzerpasswort|Das mit dem Benutzer verknüpfte Passwort, das Sie in den vorherigen Schritten festgelegt haben.|
|Server-Hostname|Der Server, der angegeben werden muss, damit Ihre Website sich mit Ihrer Datenbank verbinden kann.|
|Server-Port|Der Verbindungsport zu Ihrer Web Cloud Databases Instanz, damit Ihre Website sich mit Ihrer Datenbank verbinden kann.|

Um diese Informationen abzurufen, klicken Sie auf die unten stehenden Tabs, um die **2** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Rufen Sie die folgenden Verbindungsinformationen ab:

    - **Server (Hostname) und Port:** sichtbar im Tab <code className="action">Übersicht</code>, Bereich **SQL**, Angaben **Hostname** und **Port**.
    - **Benutzer:** sichtbar im Tab <code className="action">Benutzer & Rechte</code>.
    - **Passwort:** das mit dem Benutzer verknüpfte Passwort. Wenn Sie es vergessen haben, gehen Sie zum Tab <code className="action">Benutzer & Rechte</code>, klicken Sie auf den Button <code className="action">⋮</code> des betreffenden Benutzers und dann auf <code className="action">Passwort ändern</code>.

    <img className="thumbnail" alt="Bereich SQL der Übersicht mit Hostname und Port" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />

    :::warning
    Wenn Sie das Passwort eines Datenbankbenutzers ändern, müssen alle Anwendungen/Websites, die auf diese Datenbank zugreifen, entsprechend aktualisiert werden.

    :::

  </Tab>
</Tabs>

:::warning
Das Feld <code className="action">Port</code> ist möglicherweise in der Konfiguration Ihrer Website nicht vorhanden. Sie müssen dieses Feld nach dem Hostnamen Ihres Servers hinzufügen, getrennt durch ein *:*.

Zum Beispiel müssten Sie für den Hostnamen `aaXXXXX-XXX.eu.clouddb.ovh.net` mit dem SQL-Port `12345` im Bereich "Host" / "Hostname" `aaXXXXX-XXX.eu.clouddb.ovh.net:12345` eingeben.

:::

:::info
OVHcloud bietet keinen TLS-verschlüsselten Port für Valkey-Datenbankserver an. Die Kommunikation darf ausschließlich über den standardmäßigen, unverschlüsselten Port erfolgen.

:::
