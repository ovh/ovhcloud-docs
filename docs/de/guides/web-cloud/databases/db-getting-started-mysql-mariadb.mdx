## Ziel

Sie möchten MySQL oder MariaDB für Ihre Datenbanken verwenden?

### Was ist eine MySQL-Datenbank?

MySQL ist ein Verwaltungssystem für relationale Datenbanken und im Gegensatz zu anderen Systemen speziell für eine höhere Performance beim Lesen der Daten entwickelt.

Das System ist eine Open-Source-Software von Oracle.

### Was ist eine MariaDB-Datenbank?

MariaDB ist durch eine Abspaltung (Fork) von dem Datenbankverwaltungssystem MySQL entstanden.

Das System ist 100% kompatibel und gilt insgesamt als "freier" als das originäre MySQL. Im Gegensatz zu dem Verwaltungssystem von Oracle sind alle Bug Fixes und Roadmaps frei erhältlich.

**Diese Anleitung erklärt, wie Sie Ihre MySQL oder MariaDB Datenbanken erstellen und verwalten.**

## In der praktischen Anwendung

### Verbindung mit der Datenbank

:::info
Dieses Angebot ermöglicht keinen Zugriff auf den Host, sondern auf die darauf gehosteten Datenbanken. Allgemeine SQL-Befehle funktionieren problemlos, und Software wie HeidiSQL oder SQuirreL SQL ist voll kompatibel.

:::

:::info
Da MariaDB ein Derivat von MySQL ist, sind die Befehle für diese 2 Datenbanktypen genau dieselben.

:::

Um sich mit Ihrer Datenbank zu verbinden, stellen Sie sicher, dass Sie über Folgendes verfügen:

- die Adresse Ihrer Web Cloud Databases Instanz
- den Port Ihrer Web Cloud Databases Instanz
- den Benutzernamen Ihrer Web Cloud Databases Instanz
- das Passwort des Benutzers
- den Namen Ihrer Datenbank

Alle diese Informationen finden Sie in der OVHcloud Konsole auf der Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.

Eine Anleitung ist ebenfalls verfügbar: [Erste Schritte mit Web Cloud Databases](/guides/web-cloud/databases/db-getting-started).

#### Verbindung über die Kommandozeile

```bash
mysql --host=server --user=user --port=port --password=password database_name
```

#### Verbindung über ein PHP-Skript

```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

#### Verbindung über eine Software (SQuirreL SQL)

- Starten Sie SQuirreL SQL und klicken Sie auf <code className="action">Aliases</code> und dann auf <code className="action">+</code>.

<img className="thumbnail" alt="SQuirreL SQL starten" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Füllen Sie die folgenden Felder aus und bestätigen Sie dann mit dem Button <code className="action">OK</code>:
    - **Name**: Wählen Sie einen Namen
    - **Driver**: Wählen Sie `MySQL Driver`
    - **URL**: Geben Sie die Serveradresse und den Port im Format `jdbc:mysql://server:port` ein
    - **User Name**: Geben Sie den Benutzernamen ein
    - **Password**: Geben Sie das Passwort ein

<img className="thumbnail" alt="Verbindung konfigurieren" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Bestätigen Sie erneut mit dem Button <code className="action">Connect</code>.

<img className="thumbnail" alt="Verbindung bestätigen" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

Sie sind jetzt mit Ihrer Datenbank verbunden:

<img className="thumbnail" alt="Verbindung konfigurieren" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

#### Verbindung über phpMyAdmin

Sie können phpMyAdmin verwenden, um den Inhalt Ihrer Datenbank zu durchsuchen. Installieren Sie dazu phpMyAdmin auf Ihrem eigenen Server oder Webhosting. Achten Sie bei der Installation darauf, die Angaben zu Ihrem Web Cloud Databases Server und zur gewünschten Datenbank korrekt zu konfigurieren, damit phpMyAdmin sich damit verbinden kann.

### Eine MySQL- oder MariaDB-Datenbank exportieren und importieren

- **Meine Datenbank über die Kommandozeile exportieren**

```bash
mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql
```

- **Meine Datenbank über die Kommandozeile importieren**

```bash
cat database_name.sql | mysql --host=server --user=user --port=port --password=password database_name
```

:::info
In manchen Fällen reicht der in Ihrer Web Cloud Databases Instanz verfügbare RAM möglicherweise nicht aus, um den gewünschten Export oder Import durchzuführen. In diesem Fall empfehlen wir Ihnen, das von OVHcloud bereitgestellte Import-Tool zu verwenden. Lesen Sie bei Bedarf die Dokumentation "[Erste Schritte mit Web Cloud Databases](/guides/web-cloud/databases/db-getting-started#datenbank-importieren)".

:::
