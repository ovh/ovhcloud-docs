## Web Cloud Databases

[OVHcloud Web Cloud Databases](/links/web/databases) ist ein verwalteter Datenbankdienst (MySQL, PostgreSQL und MariaDB) für Ihre Websites und Anwendungen, nutzbar mit einem Webhosting, einem VPS oder anderen OVHcloud Produkten. Diese Seite vereint die gesamte Dokumentation, nach Thema geordnet: von den ersten Schritten über die Konfiguration bis zur Migration.
