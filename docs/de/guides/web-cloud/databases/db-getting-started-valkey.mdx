## Ziel

**Valkey** ist ein quelloffener **In-Memory**-Datenspeicher, der mit den Clients und Protokollen des Redis Ökosystems (RESP, REdis Serialization Protocol) kompatibel ist. Er eignet sich für **Caches**, **Sessions**, **leichtgewichtige Warteschlangen** und **Zähler** mit hoher Performance.

**Erfahren Sie, wie Sie sich mit Ihrer Valkey-Instanz auf Web Cloud Databases verbinden: Autorisierung der IP-Adressen, Abruf der Verbindungsparameter und Test über einen Befehlszeilen-Client.**

:::warning
Sichern Sie den Zugriff auf Ihre Instanz ab (autorisierte IPs, sichere Passwörter) und testen Sie diesen in der Vorproduktion, bevor Sie live gehen.

:::

## In der praktischen Anwendung

### Teil 1 — Die Zugriffs-IP-Adresse autorisieren

Standardmäßig verweigert Ihre Valkey-Instanz öffentliche Verbindungen. Um die IP-Adresse zu autorisieren (auf die Whitelist zu setzen), von der aus Sie sich verbinden, lesen Sie unsere Anleitung "[Web Cloud Databases - Wie autorisiere ich eine IP-Adresse?](/guides/web-cloud/databases/db-authorise-ip-mask)"

Wiederholen Sie den Vorgang für jeden Rechner, der auf Ihre Valkey-Instanz zugreifen soll.

### Teil 2 — Die Verbindungsparameter vorbereiten <a id="get-credentials"></a>

#### Das Passwort des Benutzers `default` festlegen

Ihre Valkey-Instanz wird mit einem Benutzer `default` geliefert, dem einzigen verfügbaren Konto: Verwenden Sie es, um sich zu verbinden.

:::warning
Sein Passwort wird in der OVHcloud Konsole niemals angezeigt. Sie müssen es mindestens einmal ändern, um es zu erfahren.

:::

#### Ihre Angaben notieren

Bewahren Sie die folgenden Angaben auf:

- Hostname
- Port
- Passwort des Benutzers `default`

Diese Angaben sind erforderlich, um die Verbindung zu Ihrer Instanz über einen Valkey-Client oder Ihre Anwendung zu testen.

### Teil 3 — Die Verbindung mit einem Befehlszeilen-Client testen

Um zu überprüfen, ob Ihre Valkey-Instanz funktionsfähig ist, verbinden Sie sich ein erstes Mal mit ihr:

#### Den Verbindungs-Client installieren

In diesem Beispiel verwenden wir den Client `redis-cli`, der mit Valkey kompatibel und einfach zu installieren ist. Sie können den Client Ihrer Wahl verwenden. Öffnen Sie ein Terminal und führen Sie je nach Betriebssystem den folgenden Befehl aus.

<Tabs>
  <Tab label="Debian/Ubuntu">
    ```bash
    sudo apt update && sudo apt -y install redis-tools
    ```
  </Tab>
  <Tab label="AlmaLinux/Rocky">
    ```bash
    sudo dnf -y install redis
    ```
  </Tab>
  <Tab label="macOS">
    Installieren Sie [Homebrew](https://brew.sh/de/), indem Sie den Anweisungen auf der zugehörigen Website folgen, und installieren Sie anschließend `redis-cli`:

    ```bash
    brew install redis
    ```
  </Tab>
  <Tab label="Windows">
    Geben Sie im Startmenü `PowerShell` ein, klicken Sie mit der rechten Maustaste auf das Ergebnis und anschließend auf <code className="action">Als Administrator ausführen</code>.

    Installieren Sie [Chocolatey](https://chocolatey.org/install), indem Sie den folgenden Befehl ausführen:

    ```powershell
    Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
    ```

    Installieren Sie `redis-cli`:

    ```powershell
    choco install redis-64 -y
    ```
  </Tab>
</Tabs>

Überprüfen Sie nach der Installation des Clients dessen Funktionsfähigkeit, indem Sie den folgenden Befehl ausführen:

```bash
redis-cli --version
```

#### Sich mit der Instanz verbinden

Führen Sie in Ihrem Terminal den folgenden Befehl aus:

```bash
redis-cli -h <hostname> -p <port>
```

Ersetzen Sie `<hostname>` durch Ihren Hostnamen und `<port>` durch den Port Ihrer Instanz. Um diese Werte abzurufen, lesen Sie den Abschnitt "[Teil 2 — Die Verbindungsparameter vorbereiten](#get-credentials)".

#### Überprüfen, ob alles funktioniert

Wenn die Verbindung erfolgreich ist, wird die Eingabeaufforderung Ihrer Instanz angezeigt. Authentifizieren Sie sich mit dem Befehl `AUTH` und ersetzen Sie dabei `<password>` durch das Passwort des Benutzers `default`:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:12345> AUTH <password>
OK
```

Überprüfen Sie anschließend, ob der Server antwortet:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:12345> PING
```

Die Datenbank muss antworten:

```console
PONG
```

Versuchen Sie auch Folgendes:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:12345> SET ovh-test-connexion "hello"
aaXXXXX-XXX.eu.clouddb.ovh.net:12345> GET ovh-test-connexion
```

Sie müssen Folgendes sehen:

```console
"hello"
```

Löschen Sie den Testschlüssel:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:12345> DEL ovh-test-connexion
```

Geben Sie zum Beenden Folgendes ein:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:12345> QUIT
```

Wenn die vorherigen Tests funktionieren, ist Ihre Valkey-Instanz betriebsbereit.
