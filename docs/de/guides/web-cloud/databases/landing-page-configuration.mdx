## Ihren Web Cloud Databases Dienst konfigurieren

Konfigurieren und verwalten Sie Ihren OVHcloud Web Cloud Databases Dienst: Zugriff, Datenbanken, Benutzer und Rechte, Verbindung, PostgreSQL-Erweiterungen und Logs.

So finden Sie sich je nach Bedarf zurecht:

- **Möchten Sie den Zugriff öffnen und sich mit Ihren Datenbanken verbinden?** Sehen Sie sich den Abschnitt *Zugriff und Verbindung* an.
- **Verwalten Sie Ihre Datenbanken, Benutzer und deren Rechte?** Sehen Sie sich den Abschnitt *Datenbanken und Benutzer* an.
- **Verwalten Sie den Server (Konfiguration, Logs)?** Sehen Sie sich den Abschnitt *Server und Betrieb* an.
