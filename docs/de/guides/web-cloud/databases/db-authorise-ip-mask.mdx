## Ziel

Die [Web Cloud Databases](/links/web/databases) können mit anderen OVHcloud Diensten oder externen Diensten verwendet werden.

Standardmäßig und aus Sicherheitsgründen für diese Lösungen:

- Nur die IP-Adressen, die mit unserer Hosting-Infrastruktur verbunden sind, sind zum Zugriff auf den Inhalt der Datenbanken berechtigt.
- Der Zugriff auf die Logs der Lösung ist nicht auf IP-Basis eingeschränkt. So kann zum Beispiel über beliebige Endgeräte darauf zugegriffen werden.

Möchten Sie diese Berechtigungen/Einschränkungen ändern?

**Diese Anleitung erklärt, wie Sie einer oder mehreren IP-Adressen Zugriff auf Ihre Web Cloud Databases Lösung gewähren.**

## Voraussetzungen

- Sie verfügen über die OVHcloud Lösung [Web Cloud Databases](/links/web/databases).
- Sie haben die IP-Adresse (oder den IP-Adressbereich), die Datenbank-Zugriff erhalten soll.

[[cpnav:web-cloud-databases]]

## In der praktischen Anwendung

### Eine IP-Adresse oder einen IP-Adressbereich autorisieren

:::info
Zur Erinnerung: Wenn Sie Ihre [Web Cloud Databases](/links/web/databases) Lösung gerade aktiviert haben und diese mit einem [OVHcloud Webhosting](/links/web/hosting) verwenden möchten, sind die IP-Adressen dieser Angebote bereits standardmäßig autorisiert.

:::

Klicken Sie auf die folgenden Tabs, um die **4** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf der angezeigten Seite auf den Tab <code className="action">Autorisierte IPs</code>.

    <img className="thumbnail" alt="Tab Autorisierte IPs einer Web Cloud DB Instanz" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie auf der angezeigten Seite auf den Button <code className="action">IP hinzufügen</code> oberhalb der Tabelle.

    <img className="thumbnail" alt="Button IP hinzufügen oberhalb der Tabelle der autorisierten IPs" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Wenn Sie eine bereits autorisierte IP-Adresse oder einen bereits autorisierten IP-Adressbereich ändern möchten, klicken Sie in der Tabelle auf den Button <code className="action">⋮</code> in der Spalte **Aktionen**, rechts in der Zeile der zu ändernden IP-Adresse oder des zu ändernden IP-Adressbereichs, und dann auf <code className="action">Bearbeiten</code>. Sie können den Namen und die Berechtigungen ändern; die IP-Adresse selbst kann nicht geändert werden.

    <img className="thumbnail" alt="Menü einer Zeile in der Tabelle der autorisierten IPs" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Schritt 4">
    Füllen Sie im angezeigten Fenster **Autorisierte IP hinzufügen** die folgenden Felder aus:

    <img className="thumbnail" alt="Fenster Autorisierte IP hinzufügen mit seinen Feldern" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (erforderlich): Geben Sie die IP-Adresse (zum Beispiel: `203.0.113.44`) oder den IP-Adressbereich (zum Beispiel: `203.0.113.0/24`, der alle IP-Adressen von `203.0.113.0` bis `203.0.113.255` umfasst) ein, die bzw. den Sie für Ihre Web Cloud Databases Lösung autorisieren möchten.
    - **Name** (erforderlich): Sie können hier zum Beispiel die Rolle der betreffenden IP-Adresse oder des betreffenden IP-Adressbereichs angeben.
    - **Dienstzugang erlauben** (standardmäßig aktiviert): Setzen Sie hier einen Haken, um der IP-Adresse oder dem IP-Adressbereich den Zugriff auf die Datenbanken Ihrer Web Cloud Databases Lösung zu erlauben.
    - **SFTP-Zugang erlauben**: Setzen Sie hier einen Haken, um der IP-Adresse oder dem IP-Adressbereich den Zugriff auf die Logs Ihrer Web Cloud Databases Lösung zu erlauben.

    :::warning
    Wir raten dringend davon ab, die Option **Dienstzugang erlauben** zu aktivieren, um dem IP-Adressbereich `0.0.0.0/0` den Zugriff auf Ihre Datenbanken zu erlauben.

    Dadurch würden alle existierenden IPv4-Adressen Zugriff auf Ihre Datenbanken erhalten.

    :::

    Nachdem Sie die Informationen eingegeben haben, klicken Sie auf den Button <code className="action">Hinzufügen</code>.
  </Tab>
</Tabs>

## Sonderfälle

**Klicken Sie auf die unten stehenden Fälle, um die zugehörigen Informationen anzuzeigen.**

<details>

<summary>Der IP-Adressbereich 0.0.0.0/0</summary>

Bei der Aktivierung Ihrer Web Cloud Databases Lösung ist standardmäßig bereits eine Zeile für den IP-Adressbereich `0.0.0.0/0` vorhanden, um den Zugriff per **SFTP** auf die Lösung zu erlauben.

Diese Berechtigung wird absichtlich eingerichtet, damit Sie auf die Logdateien Ihrer Web Cloud Databases Lösung zugreifen können, ohne die IP-Adresse Ihres Internetzugangs angeben zu müssen.

Diese IP-Adresse kann sich nämlich je nach Internetanbieter regelmäßig ändern.

Außerdem empfehlen wir Ihnen, diese Berechtigung **nicht** zu ändern und den Zugriff auf die Datenbanken Ihrer Web Cloud Databases Lösung nicht zu erlauben.

Dadurch würden alle existierenden IPv4-Adressen Zugriff auf Ihre Datenbanken erhalten, was ein Risiko für die Sicherheit Ihrer Daten darstellt.

</details>

<details>

<summary>Zugriffsberechtigung für OVHcloud Webhostings</summary>

Bei der Aktivierung Ihrer Web Cloud Databases Lösung ist die Zugriffsberechtigung für OVHcloud Webhostings standardmäßig aktiviert.

Wenn Sie diese Berechtigung deaktivieren möchten, weil Sie kein Webhosting mit Ihrer Web Cloud Databases Lösung verwenden, klicken Sie auf die folgenden Tabs, um die **3** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf der angezeigten Seite auf den Tab <code className="action">Autorisierte IPs</code>.

    <img className="thumbnail" alt="Tab Autorisierte IPs einer Web Cloud DB Instanz" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Deaktivieren Sie oben auf der Seite im Bereich **Zugriff auf OVHcloud-Webhosting** den Schalter **OVHcloud-Webhosting den Zugriff auf die Datenbank erlauben**.

    <img className="thumbnail" alt="Bereich Zugriff auf OVHcloud-Webhosting mit seinem Schalter" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/web-hosting-access.png" loading="lazy" />

    :::info
    Wenn Sie diesen Zugriff deaktivieren, blockieren Sie für Ihre gesamte Web Cloud Databases Lösung auch den Zugriff auf **phpMyAdmin** über den in der OVHcloud Konsole verfügbaren Link.
    :::

  </Tab>
</Tabs>
