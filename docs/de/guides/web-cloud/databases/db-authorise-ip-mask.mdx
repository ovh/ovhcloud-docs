## Ziel

Die [Web Cloud Databases](/links/web/databases) können mit anderen OVHcloud Diensten oder externen Diensten verwendet werden.

Standardmäßig und aus Sicherheitsgründen für diese Lösungen:

- Nur die IP-Adressen, die mit unserer Hosting-Infrastruktur verbunden sind, sind zum Zugriff auf den Inhalt der Datenbanken berechtigt.
- Der Zugriff auf die Logs der Lösung ist nicht auf IP-Basis eingeschränkt. So kann zum Beispiel über beliebige Endgeräte darauf zugegriffen werden.

Möchten Sie diese Berechtigungen/Einschränkungen ändern?

**Diese Anleitung erklärt, wie Sie einer oder mehreren IP-Adressen Zugriff auf Ihre Web Cloud Databases Lösung gewähren.**

## Voraussetzungen

- Sie verfügen über die OVHcloud Lösung [Web Cloud Databases](/links/web/databases).
- Sie haben die IP-Adresse (oder den IP-Adressbereich), die Datenbank-Zugriff erhalten soll.

[[cpnav:web-cloud-databases]]

## In der praktischen Anwendung

### Eine IP-Adresse oder einen IP-Adressbereich autorisieren

:::info
Zur Erinnerung: Wenn Sie Ihre [Web Cloud Databases](/links/web/databases) Lösung gerade aktiviert haben und diese nur mit einem [OVHcloud Webhosting](/links/web/hosting) verwenden möchten, müssen die IP-Adressen Ihres Webhosting nicht manuell autorisiert werden.

:::

Klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/#/web/private_database">Web Cloud Databases</ManagerLink>, und wählen Sie die betreffende Lösung aus.

    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf der angezeigten Seite auf den Tab <code className="action">Autorisierte IPs</code>.

    <img className="thumbnail" alt="Authorised IPs" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/authorised-ips.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie auf der angezeigten Seite auf den Button <code className="action">IP-Adresse / Maske hinzufügen</code> über der Tabelle.

    <img className="thumbnail" alt="Authorised IPs interface" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/authorized-ips/tab-0000-sftp-hosting-enabled.png" loading="lazy" />

    :::tip
    Wenn Sie eine bereits zugelassene IP-Adresse (oder IP-Adressbereich) ändern möchten, klicken Sie in der Tabelle auf den Button <code className="action">...</code> in der Zeile der zu ändernden IP-Adresse (oder IP-Adressbereich), und dann auf <code className="action">Whitelist bearbeiten</code>.

    :::

  </Tab>
  <Tab label="Schritt 4">
    Im angezeigten Fenster müssen mehrere Felder ausgefüllt werden:

    <img className="thumbnail" alt="Add an IP address or mask" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/authorized-ips/add-an-ip-address-mask-confirmation.png" loading="lazy" />

    - <code className="action">IP / Maske *</code>: Geben Sie hier die IP-Adresse (zum Beispiel: `203.0.113.44`) ein, die Sie für Ihre Web Cloud Databases Lösung autorisieren möchten bzw. den IP-Adressbereich (zum Beispiel: `203.0.113.0/24`, der alle IP-Adressen von `203.0.113.0` bis `203.0.113.255` darstellt).
    - <code className="action">Beschreibung</code> (optional): Sie können etwa Informationen zur Rolle der betreffenden IP-Adresse (oder IP-Adressbereich) hinzufügen.
    - <code className="action">Datenbanken</code>: Aktivieren Sie diese Option, damit die IP-Adresse (oder IP-Adressbereich) auf die Datenbanken auf Ihrer Web Cloud Databases Lösung zugreifen kann.
    - <code className="action">SFTP</code>: Setzen Sie hier einen Haken, damit die IP-Adresse oder der IP-Adressbereich auf die Logs Ihrer Web Cloud Databases Lösung zugreifen können.

    :::warning
    Um die Sicherheit Ihres Dienstes zu erhöhen, ist der Adressbereich `0.0.0.0/0` standardmäßig nicht mehr autorisiert. Bitte legen Sie die Liste der autorisierten IP-Adressen direkt in Ihrem OVHcloud Kundencenter fest.

    :::

    Nachdem Sie die Informationen eingegeben haben, klicken Sie auf <code className="action">Bestätigen</code>.
  </Tab>
</Tabs>

## Sonderfall

**Klicken Sie auf die unten stehenden Fälle, um die zugehörigen Informationen anzuzeigen.**

<details>

<summary>Autorisierung des Datenbank-Zugriffs für OVHcloud Webhostings</summary>

Bei der Aktivierung Ihrer Web Cloud Databases Lösung ist die Autorisierung für den Zugriff auf die OVHcloud Webhostings standardmäßig aktiviert.

Wenn Sie diese Berechtigung deaktivieren möchten, da Sie kein Webhosting mit Ihrer Web Cloud Databases Lösung verwenden, klicken Sie auf die Tabs, um die **3** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/#/web/private_database">Web Cloud Databases</ManagerLink>, und wählen Sie die betreffende Lösung aus.

    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Autorisierte IPs</code>.

    <img className="thumbnail" alt="Authorised IPs" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/authorised-ips.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Deaktivieren Sie die Option <code className="action">Den OVHcloud Webhostings den Zugriff auf die Datenbank erlauben</code>.

    <img className="thumbnail" alt="Authorised IPs interface" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/authorized-ips/tab-0000-sftp-hosting-enabled.png" loading="lazy" />

    :::info
    Wenn Sie diese Option deaktivieren, blockieren Sie für Ihre gesamte Web Cloud Databases Lösung auch den Zugriff auf **phpMyAdmin** über den in Ihrem OVHcloud Kundencenter verfügbaren Link.
    :::

  </Tab>
</Tabs>

</details>
