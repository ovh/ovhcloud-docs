## Ziel

Sie können den Inhalt Ihrer Datenbank über ein Interface einsehen. Es gibt verschiedene Möglichkeiten, sich damit zu verbinden.

**Diese Anleitung erklärt, wie Sie sich mit Ihrer Datenbank auf Ihrem Datenbankserver verbinden.**

## Voraussetzungen

- Sie verfügen über eine [Web Cloud Databases Instanz](/links/web/databases) (in einem [Webhosting](/links/web/hosting) Performance, Agency, Agency Plus oder Agency Max Angebot enthalten).

[[cpnav:web-cloud-databases]]

## In der praktischen Anwendung

:::info
[Web Cloud Databases](/links/web/databases) Dienste gewähren keinen Zugriff auf den Datenbankserver selbst, sondern auf die darauf gehosteten Datenbanken.

- Es gibt keinen Super-User-Zugang "root".
- Generische SQL-Befehle funktionieren normal, und Programme wie HeidiSQL, SQuirreL SQL oder Adminer sind vollständig kompatibel.

:::

### Mit einer MySQL- oder MariaDB-Datenbank verbinden

:::info
Da MariaDB ein Derivat von MySQL ist, sind die Befehle für diese beiden Datenbanktypen exakt gleich.

:::

#### Verbindung über OVHcloud phpMyAdmin

Klicken Sie auf die unten stehenden Tabs, um die **4** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Rufen Sie die folgenden Verbindungsinformationen ab:

    - **Server (Hostname) und Port:** sichtbar im Tab <code className="action">Übersicht</code>, Bereich **SQL**, Angaben **Hostname** und **Port**.
    - **Benutzer:** sichtbar im Tab <code className="action">Benutzer & Rechte</code>.
    - **Passwort:** das mit dem Benutzer verknüpfte Passwort. Wenn Sie es vergessen haben, gehen Sie zum Tab <code className="action">Benutzer & Rechte</code>, klicken Sie auf den Button <code className="action">⋮</code> des betreffenden Benutzers und dann auf <code className="action">Passwort ändern</code>.

    <img className="thumbnail" alt="Bereich SQL der Übersicht mit Hostname und Port" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />

    :::warning
    Wenn Sie das Passwort eines Datenbankbenutzers ändern, müssen alle Anwendungen/Websites, die auf diese Datenbank zugreifen, entsprechend aktualisiert werden.

    :::

  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie im Tab <code className="action">Übersicht</code>, Bereich **SQL**, auf den Button <code className="action">⋮</code> rechts neben **Weitere Aktionen** und dann auf <code className="action">Administrationsoberfläche</code>. phpMyAdmin wird in einem neuen Tab Ihres Browsers geöffnet.

    <img className="thumbnail" alt="Menü Weitere Aktionen des Bereichs SQL mit dem Eintrag Administrationsoberfläche" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-additional-actions.png" loading="lazy" />

    :::info
    Wenn der Eintrag **Administrationsoberfläche** nicht im Menü angezeigt wird, ist OVHcloud phpMyAdmin für Ihre Instanz nicht verfügbar. Verwenden Sie in diesem Fall eine der Methoden im Abschnitt "[Verbindung zur Datenbank außerhalb der OVHcloud Konsole](#connexion-à-la-base-de-données-hors-espace-client)".

    :::

  </Tab>
  <Tab label="Schritt 4">
    Geben Sie auf der phpMyAdmin-Loginseite die in Schritt 2 abgerufenen Informationen ein:

    <img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-login-web-cloud-db.png" loading="lazy" />

    - **Server:** Geben Sie den *Hostnamen* gefolgt von der *Port-Nummer* ein, getrennt durch "**:**" oder ein "**Leerzeichen**". Beispiel: **aaXXXXX-XXX.eu.clouddb.ovh.net:12345**.
    - **Benutzername:** Geben Sie den *Benutzernamen* ein.
    - **Passwort:** Geben Sie das *Passwort* ein.
  </Tab>
</Tabs>

Wenn die Verbindung erfolgreich ist, wird die folgende Seite angezeigt.

<img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-main-page-web-cloud-db.png" loading="lazy" />

:::warning
**Im Fehlerfall:**

- Fehler #1045 bedeutet, dass die Zugangsdaten falsch sind. Überprüfen Sie Ihren Benutzernamen und/oder Ihr Passwort.
- Fehler #2005 bedeutet, dass der Servername überprüft werden sollte und ob dieser korrekt funktioniert.

:::

#### Verbindung zur Datenbank außerhalb der OVHcloud Konsole <a name="connexion-à-la-base-de-données-hors-espace-client"></a>

:::warning
Wenn Sie eine "Web Cloud Databases"/"Private SQL"-Lösung verwenden, denken Sie daran, Ihre IP-Adresse mithilfe der Anleitung zur [Konfiguration Ihres Datenbankservers](/guides/web-cloud/databases/db-configure-optimise-database-server#zugriff-verwalten) zu autorisieren.

:::

Klicken Sie auf die unten stehenden Tabs, um die **2** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Rufen Sie die folgenden Verbindungsinformationen ab:

    - **Server (Hostname):** sichtbar im Tab <code className="action">Übersicht</code>, Bereich **SQL**, Angabe **Hostname**.
    - **Port:** sichtbar am gleichen Ort, Angabe **Port**.
    - **Benutzer:** sichtbar im Tab <code className="action">Benutzer & Rechte</code>.
    - **Passwort:** das dem betreffenden Benutzer zugehörige Passwort.
    - **Datenbankname:** sichtbar im Tab <code className="action">Datenbanken</code>.

    <img className="thumbnail" alt="Bereich SQL der Übersicht mit Hostname und Port" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />
  </Tab>
</Tabs>

**Klicken Sie auf die Verbindungsmethode Ihrer Wahl, um den Inhalt anzuzeigen.**

<details>

<summary>Verbindung über die Kommandozeile</summary>

```bash
mysql --host=server --user=user --port=port --password=password database_name
```

</details>

<details>

<summary>Verbindung per PHP-Skript</summary>

```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

</details>

<details>

<summary>Software-Verbindung (SQuirreL SQL)</summary>

:::info
In unserem Beispiel verwenden wir die Open-Source-Software SQuirreL, aber andere Interfaces wie HeidiSQL oder Adminer sind vollständig kompatibel.

:::

- Starten Sie SQuirreL SQL und klicken Sie auf <code className="action">Aliases</code> und dann auf <code className="action">+</code>

<img className="thumbnail" alt="SQuirreL SQL starten" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Füllen Sie die folgenden Felder aus und bestätigen Sie dann mit dem Button <code className="action">OK</code>:
    - **Name**: Wählen Sie einen Namen
    - **Driver**: Wählen Sie "MySQL Driver"
    - **URL**: Geben Sie die Serveradresse und den Port im Format `jdbc:mysql://server:port` ein
    - **User Name**: Geben Sie den Benutzernamen ein
    - **Password**: Geben Sie das Passwort ein

<img className="thumbnail" alt="Verbindung konfigurieren" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Bestätigen Sie erneut mit dem Button <code className="action">Connect</code>

<img className="thumbnail" alt="Verbindung bestätigen" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

Sie sind jetzt mit Ihrer Datenbank verbunden:

<img className="thumbnail" alt="Verbindung konfigurieren" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

</details>

<details>

<summary>Verbindung über phpMyAdmin</summary>

Sie können Ihr eigenes phpMyAdmin-Interface verwenden, um den Inhalt Ihrer Datenbank zu durchsuchen. Installieren Sie dazu phpMyAdmin auf Ihrem eigenen Server oder Webhosting. Achten Sie bei der Installation darauf, die Verbindungsinformationen Ihres Datenbankservers und der gewünschten Datenbank korrekt zu konfigurieren, damit phpMyAdmin sich damit verbinden kann.

</details>
