## Ziel

In einer Datenbank (DB) können sogenannte dynamische Elemente, wie zum Beispiel Kommentare oder Artikel, gespeichert werden. Diese Datenbanken werden heute von praktisch allen Content Management Systemen (CMS) wie WordPress oder Joomla! verwendet.

**Diese Anleitung erklärt, wie Sie eine Datenbank auf Ihrem Datenbankserver erstellen und Benutzern Zugriff gewähren.**

## Voraussetzungen

- Sie verfügen über eine [Web Cloud Databases Instanz](/links/web/databases) (auch in einem [Webhosting](/links/web/hosting) Performance, Agency, Agency Plus oder Agency Max Angebot enthalten).

[[cpnav:web-cloud-databases]]

## In der praktischen Anwendung

### Datenbank erstellen

Klicken Sie auf die unten stehenden Tabs, um die **4** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Datenbanken</code>.

    <img className="thumbnail" alt="Tab Datenbanken einer Web Cloud DB Instanz" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie oberhalb der Datenbanktabelle auf <code className="action">Datenbank hinzufügen</code>.

    <img className="thumbnail" alt="Button Datenbank hinzufügen oberhalb der Datenbanktabelle" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    Die Erstellung von PostgreSQL-Schemata ist derzeit auf Web Cloud Databases Servern nicht verfügbar.

    :::

  </Tab>
  <Tab label="Schritt 4">
    Das Panel **Datenbank hinzufügen** öffnet sich auf der rechten Seite. Füllen Sie die Felder gemäß den unter jedem Feld angegebenen Kriterien aus:

    - **Datenbankname** (Pflichtfeld): Dies ist der Name Ihrer zukünftigen Datenbank.
    - **Zugriff auf diese Datenbank**: Wählen Sie aus, wer sich mit der Datenbank verbinden und Anfragen ausführen kann.
        - **Vorläufig kein Zugriff** (Standardauswahl): Die Datenbank wird ohne Benutzer erstellt. Sie können einem Benutzer nachträglich Rechte zuweisen.
        - **Ein bestehender Benutzer**: Wählen Sie den **Benutzer** und anschließend seine **Rechte** für die Datenbank aus.
        - **Ein neuer Benutzer**: Füllen Sie die nachfolgenden Felder aus, um den Benutzer gleichzeitig mit der Datenbank zu erstellen.
    - **Benutzername** (nur mit **Ein neuer Benutzer**): Der Benutzer, der sich mit Ihrer Datenbank verbinden und Anfragen ausführen kann.
    - **Rechte** (mit **Ein bestehender Benutzer** oder **Ein neuer Benutzer**): Die dem Benutzer für die Datenbank zugewiesenen Rechte. Wählen Sie für eine Standardnutzung `Admin`. Die Rechte können nachträglich geändert werden.
    - **Passwort**/**Passwort bestätigen** (nur mit **Ein neuer Benutzer**): Geben Sie ein Passwort ein und bestätigen Sie es.

    Klicken Sie auf <code className="action">Hinzufügen</code>.

    <img className="thumbnail" alt="Panel Datenbank hinzufügen mit einem neuen Benutzer" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

Klicken Sie auf die unten stehenden Tabs, um die **4** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Benutzer & Rechte</code>.

    <img className="thumbnail" alt="Tab Benutzer & Rechte einer Web Cloud DB Instanz" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie auf <code className="action">Benutzer hinzufügen</code>.

  <Tab label="Schritt 4">

### Verwaltung der Benutzerrechte

Um einem Benutzer die Durchführung von Aktionen auf einer Datenbank zu ermöglichen, müssen ihm Rechte zugewiesen werden.

Klicken Sie auf die unten stehenden Tabs, um die **4** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Benutzer & Rechte</code>.

    <img className="thumbnail" alt="Tab Benutzer & Rechte einer Web Cloud DB Instanz" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Jeder Benutzer wird in einer Karte mit seinem Namen angezeigt. Klicken Sie in der Karte des betreffenden Benutzers auf den Button <code className="action">⋮</code> rechts neben der Angabe **Weitere Aktionen** und dann auf <code className="action">Rechte verwalten</code>.

    <img className="thumbnail" alt="Menü Weitere Aktionen eines Benutzers mit dem Eintrag Rechte verwalten" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Das Panel **Rechte von**, gefolgt vom Namen des Benutzers, öffnet sich auf der rechten Seite. Es listet die Datenbanken auf Ihrem Server auf, jeweils mit einem Dropdown-Menü rechts daneben, das die Rechtestufe des Benutzers für diese Datenbank anzeigt. Wählen Sie für jede Datenbank die gewünschte Stufe aus. Die Änderung wird sofort wirksam: Die Meldung **Recht geändert** wird angezeigt.

    4 Rechtestufen stehen zur Verfügung:

    - `Admin`: Freigabe von Anfragen des Typs **Select / Insert / Update / Delete / Create / Alter / Drop**.
    - `Lesen / Schreiben`: Freigabe von Anfragen des Typs **Select / Insert / Update / Delete**.
    - `Nur Lesen`: Freigabe von Anfragen des Typs **Select**.
    - `Keine`: Keine Rechte auf der Datenbank.

    :::info
    Die oben genannte Aufteilung der Rechte ist spezifisch für OVHcloud. So kann ein Benutzer mit der `Admin`-Berechtigung **DDL** (Data Definition Language) und **DML** (Data Manipulation Language) verwenden, während ein Benutzer mit der Berechtigung `Lesen / Schreiben` nur **DML** (Data Manipulation Language) nutzen kann.

    :::

    <img className="thumbnail" alt="Rechte-Panel eines Benutzers mit einer Stufe pro Datenbank" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />
  </Tab>
</Tabs>

### Datenbank löschen

:::warning
Beim Löschen einer Datenbank auf einem Datenbankserver findet keine Überprüfung
des Datenbankinhalts statt. Die Datenbank wird auch dann gelöscht, wenn
noch Daten darin gespeichert sind. Es wird daher empfohlen, vor jeder
Löschung ein Backup zu erstellen und lokal herunterzuladen.

:::

Klicken Sie auf die unten stehenden Tabs, um die **3** Schritte nacheinander anzuzeigen.
