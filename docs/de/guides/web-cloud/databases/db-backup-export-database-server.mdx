## Ziel

Ihre Datenbank kann eine Vielzahl von Informationen enthalten, die für Ihre Website unverzichtbar sind. Es ist daher wichtig, sie sichern oder exportieren zu können.

**Diese Anleitung erklärt, wie Sie Ihre Datenbank auf Ihrem Datenbankserver sichern und exportieren.**

## Voraussetzungen

- Sie verfügen über eine [Web Cloud Databases Instanz](/links/web/databases) (in einem [Webhosting](/links/web/hosting) Performance, Agency, Agency Plus oder Agency Max Angebot enthalten).

[[cpnav:web-cloud-databases]]

## In der praktischen Anwendung

:::info
Die [Web Cloud Databases](/links/web/databases) Dienste gewähren keinen Zugriff auf das Datenbankmanagementsystem, sondern auf die darauf gehosteten Datenbanken.

- Es gibt keinen Superuser-Zugang ("root").
- Generische SQL-Befehle funktionieren normal und Software wie HeidiSQL, SQuirreL SQL oder Adminer ist vollständig kompatibel.

:::

### Datenbank über die OVHcloud Konsole sichern und exportieren <a name="sauvegarder-et-exporter-une-base-de-données-depuis-lespace-client"></a>

:::info
- Sicherungen werden automatisch einmal täglich für alle Ihre Datenbanken durchgeführt.
- Automatische und manuelle Sicherungen werden 30 Tage lang aufbewahrt. Nach Ablauf dieser Frist werden sie automatisch gelöscht. Das Löschdatum jeder Sicherung wird in der Liste der Sicherungen der Datenbank angezeigt.

:::

#### Manuelle Sicherung erstellen

Klicken Sie auf die unten stehenden Tabs, um die **3** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> und wählen Sie die betreffende Instanz aus.

    <img className="thumbnail" alt="Seite Web Cloud DB mit der Liste der Instanzen des Accounts" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Datenbanken</code>.

    In der Spalte **Sicherungen** gibt die Zahl an, wie viele Sicherungen für jede Datenbank verfügbar sind.

    <img className="thumbnail" alt="Tab Datenbanken einer Web Cloud DB Instanz" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie in der Tabelle auf den Button <code className="action">⋮</code> in der Spalte **Aktionen** rechts neben der betreffenden Datenbank und dann auf <code className="action">Jetzt sichern</code>.

    <img className="thumbnail" alt="Menü einer Zeile in der Tabelle der Web Cloud DB Datenbanken" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    Die Sicherung startet sofort und ohne Bestätigung. Die Meldung **Sicherung gestartet** wird angezeigt.
  </Tab>
</Tabs>

### Datenbank außerhalb der OVHcloud Konsole sichern und exportieren <a name="sauvegarder-et-exporter-une-base-de-données-hors-espace-client"></a>

Wenn der verfügbare RAM auf Ihrem Server den gewünschten Export nicht ermöglicht, verwenden Sie das OVHcloud-Tool in der OVHcloud Konsole, das Ressourcen außerhalb Ihres Angebots nutzt. Weitere Informationen finden Sie im Abschnitt "[Datenbank über die OVHcloud Konsole sichern und exportieren](#datenbank-über-die-ovhcloud-konsole-sichern-und-exportieren)" dieser Anleitung.

**Klicken Sie auf die Exportmethode Ihrer Wahl, um den Inhalt anzuzeigen.**

<details>

<summary>MySQL- oder MariaDB-Datenbank über OVHcloud phpMyAdmin exportieren</summary>

Um Ihre Datenbank direkt über phpMyAdmin zu exportieren, müssen Sie sich zuerst einloggen. Folgen Sie dazu der Anleitung "[Verbindung mit einer Datenbank herstellen](/guides/web-cloud/databases/db-connecting-database-server)".

Wenn Sie in phpMyAdmin eingeloggt sind, klicken Sie auf den Namen der Datenbank, die Sie exportieren möchten, und anschließend oben auf den Tab <code className="action">Exportieren</code>.

Es gibt zwei Exportmodi. Wenn Sie keine besonderen Anforderungen haben, empfehlen wir den Modus **Schnell** im Format **SQL**.

<img className="thumbnail" alt="Tab Exportieren in phpMyAdmin mit der Methode Schnell und dem Format SQL" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-export-backup-web-cloud-db.png" loading="lazy" />

</details>

<details>

<summary>MySQL- oder MariaDB-Datenbank über die Kommandozeile exportieren</summary>

```bash
mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql
```

</details>

<details>

<summary>MySQL- oder MariaDB-Datenbank über ein PHP-Skript exportieren</summary>

```php
1. <?php echo "Your database is being backed up.......";
2. system("mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql");
3. echo "Backup complete. You can retrieve the database via FTP";
4. ?>
```

:::warning
- Um zu verhindern, dass Dritte auf diese Datei mit sensiblen Daten zugreifen, sichern Sie den Zugang mithilfe der Anleitung: [Ordner und Verwaltungsinterface Ihrer Website mit den Dateien .htaccess und .htpasswd schützen](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password).
- Diese Aktion ist nur über ein OVHcloud Webhosting möglich.

:::

</details>

<details>

<summary>PostgreSQL-Datenbank über die Kommandozeile exportieren</summary>

```bash
pg_dump --host=server --port=port --username=user --password database_name > database_name.sql
```

</details>

<details>

<summary>PostgreSQL-Datenbank über ein PHP-Skript exportieren</summary>

```php
1. <?php echo "Your database is being backed up.......";
2. system("PGPASSWORD=password pg_dump --host=server --port=port --username=user database_name > database_name.sql");
3. echo "Backup complete. You can retrieve the database via FTP";
4. ?>
```

:::warning
- Um zu verhindern, dass Dritte auf diese Datei mit sensiblen Daten zugreifen, sichern Sie den Zugang mithilfe der Anleitung: [Ordner und Verwaltungsinterface Ihrer Website mit den Dateien .htaccess und .htpasswd schützen](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password).
- Diese Aktion ist nur über ein OVHcloud Webhosting möglich.

:::

</details>
