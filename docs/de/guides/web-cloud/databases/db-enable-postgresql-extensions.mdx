## Ziel

PostgreSQL-Erweiterungen sind Module, die Ihre Datenbank um zusätzliche Funktionen erweitern: neue Datentypen, Funktionen, Operatoren oder prozedurale Sprachen. Bei einer Web Cloud Databases-Lösung können Sie die kompatiblen Erweiterungen direkt über das OVHcloud Kundencenter aktivieren, ohne Eingriff über die Befehlszeile.

**In dieser Anleitung erfahren Sie, wie Sie die verfügbaren Erweiterungen für eine PostgreSQL-Datenbank auf einer Web Cloud Databases-Lösung aktivieren.**

## Voraussetzungen

- Sie verfügen über eine [Web Cloud Databases-Instanz](/links/web/databases), die **PostgreSQL** verwendet.
- Sie haben die Anleitung [Erste Schritte mit PostgreSQL](/guides/web-cloud/databases/db-getting-started-postgresql) gelesen.

## In der praktischen Anwendung

### Eine Erweiterung aktivieren

Klicken Sie auf die unten stehenden Tabs, um die **3** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite <ManagerLink to="/#/web/web/private_database">Web Cloud Databases</ManagerLink>, und wählen Sie den betreffenden Dienst aus.

    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf den Tab <code className="action">Datenbanken</code>. Klicken Sie in der Spalte **"Erweiterungen"** auf das Tabellensymbol der betreffenden Datenbank.

    <img className="thumbnail" alt="Zugriff auf die Erweiterungen einer Datenbank" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/databases/extensions.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Suchen Sie im angezeigten Fenster die gewünschte Erweiterung in der Liste der verfügbaren Erweiterungen. Aktivieren Sie sie anschließend, indem Sie in der Spalte **"Aktiv"** auf das entsprechende Symbol klicken.

    <img className="thumbnail" alt="Liste der PostgreSQL-Erweiterungen" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/databases/extensions-list.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
Die Aktivierung einer Erweiterung gilt für die ausgewählte Datenbank. Um sie für eine andere Datenbank desselben Servers zu aktivieren, wiederholen Sie den Vorgang und wählen Sie die betreffende Datenbank aus.

:::

### Verfügbare Erweiterungen

Die Liste der angebotenen Erweiterungen hängt von der PostgreSQL-Version ab, die Ihr Server verwendet. Die für Ihre Version verfügbaren Erweiterungen werden im Aktivierungsfenster angezeigt.

Nachfolgend finden Sie die Liste der verfügbaren Erweiterungen:

| Erweiterung | Beschreibung |
|---|---|
| `address_standardizer` | Analysiert eine Adresse und zerlegt sie in ihre Bestandteile. Wird in der Regel zur Unterstützung der Adressnormalisierung beim Geocoding verwendet. |
| `autoinc` | Funktionen zur automatischen Inkrementierung von Feldern. |
| `bloom` | Bloom-Zugriffsmethode – Index auf Basis einer Signaturdatei. |
| `btree_gin` | Unterstützung für die Indizierung gängiger Datentypen in GIN. |
| `btree_gist` | Unterstützung für die Indizierung gängiger Datentypen in GiST. |
| `citext` | Datentyp für Zeichenketten ohne Berücksichtigung der Groß-/Kleinschreibung. |
| `cube` | Datentyp für mehrdimensionale Würfel. |
| `earthdistance` | Berechnung von Großkreisdistanzen auf der Erdoberfläche. |
| `fuzzystrmatch` | Ermittelt Ähnlichkeiten und den Abstand zwischen Zeichenketten. |
| `hstore` | Datentyp zum Speichern von Mengen aus (Schlüssel, Wert)-Paaren. |
| `intarray` | Funktionen, Operatoren und Indexunterstützung für eindimensionale Integer-Arrays. |
| `isn` | Datentypen für internationale Produktnummerierungsstandards. |
| `ltree` | Datentyp für hierarchische, baumartige Strukturen. |
| `moddatetime` | Funktionen zur Nachverfolgung des Zeitpunkts der letzten Änderung. |
| `pg_trgm` | Messung der Textähnlichkeit und Indexsuche auf Basis von Trigrammen. |
| `pgcrypto` | Kryptografische Funktionen. |
| `postgis` | Räumliche Datentypen und Funktionen von PostGIS (Geometrie, Geografie und Raster). |
| `postgis_raster` | Raster-Datentypen und -Funktionen von PostGIS. |
| `postgis_tiger_geocoder` | Tiger-Geocoder und Reverse-Geocoder von PostGIS. |
| `postgis_topology` | Räumliche Topologie-Datentypen und -Funktionen von PostGIS. |
| `seg` | Datentyp zur Darstellung von Liniensegmenten oder Gleitkomma-Intervallen. |
| `unaccent` | Wörterbuch für die Textsuche, das Akzente entfernt. |
| `uuid-ossp` | Generiert universell eindeutige Bezeichner (UUIDs). |
| `xml2` | XPath-Abfragen und XSLT. |
