## Ziel

[SSL Gateway](/links/web/ssl-gateway) sichert die Verbindungen zu Ihrer Website: Es schaltet Ihren eigenen Servern (VPS, Dedicated Server etc.) ein verwaltetes HTTPS-Frontend mit einem SSL-Zertifikat vor.

:::warning
SSL Gateway ist nicht mit den [OVHcloud Webhosting-Angeboten](/links/web/hosting) kompatibel. Um ein SSL-Zertifikat mit einem Webhosting zu nutzen, lesen Sie unsere Anleitung "[Webhosting - SSL-Zertifikat einrichten](/guides/web-cloud/web-hosting/ssl-on-webhosting)".

:::

**Diese Anleitung erklärt, wie Sie ein SSL Gateway bestellen.**

## Voraussetzungen

- Sie verfügen über einen [Domainnamen](/links/web/domains) oder eine Subdomain, die bereits auf den Server Ihrer Website verweist.
- Sie haben Zugriff auf die DNS-Zone des Domainnamens.

[[cpnav:network-ssl-gateway-console]]

## In der praktischen Anwendung

### Bestellung

Klicken Sie auf der Seite **SSL Gateway** auf <code className="action">SSL Gateway bestellen</code>. Das Bestellformular umfasst 4 Schritte.

**1. Angebot**: Wählen Sie <code className="action">Free</code> oder <code className="action">Advanced</code>.

- **Free**: 1 Domain, ihre `www`-Variante und 1 Subdomain, Domains mit bis zu 3 Ebenen, eine geteilte IP-Adresse, 1 Backend-Server und ein automatisch erneuertes Let's Encrypt-Zertifikat, ohne monatliche Gebühren.
- **Advanced**: bis zu 1.000 Domains und Subdomains, Domains mit 4 und mehr Ebenen, eine dedizierte IP-Adresse und Loadbalancing über bis zu 3 Backend-Server.

Beide Angebote werden monatlich abgerechnet, ohne Einrichtungsgebühr und ohne Mindestvertragslaufzeit.

<img className="thumbnail" alt="Seite SSL Gateway bestellen mit den Angeboten Free und Advanced, dem Schritt Domain und der Bestellübersicht" src="/images/network/ssl-gateway/order-ssl-gateway/console/order-offer.png" loading="lazy" />

**2. Domain**: Geben Sie im Feld **Domain** die Domain oder Subdomain ein, die Ihr SSL Gateway über HTTPS bereitstellt, und klicken Sie dann auf <code className="action">Prüfen</code>. Die Domain muss bereits auf Ihre Website verweisen: Unter **Backend-IP** zeigt das Formular die IPv4-Adresse an, auf die sie verweist und an die Ihr SSL Gateway den Traffic weiterleitet. Gibt es mehrere, wählen Sie eine davon aus.

:::warning
- Mit dem Angebot Free kann die Domain bis zu 3 Ebenen haben, zum Beispiel `www.domain.tld`. Wählen Sie für eine tiefere Subdomain, zum Beispiel `blog.www.domain.tld`, das Angebot Advanced.
- Das Formular lehnt eine Domain ab, die auf eine Adresse verweist, die bereits von einem anderen OVHcloud Dienst (Load Balancer, CDN, Webhosting oder SSL Gateway) verwendet wird. Lassen Sie die Domain auf die Adresse Ihres eigenen Servers verweisen und prüfen Sie sie dann erneut.
- Mit dem Angebot Advanced können Sie nach der Bereitstellung im Bereich **Backend** Ihres SSL Gateways bis zu 2 weitere Backend-Server hinzufügen. Lesen Sie dazu unsere Anleitung "[SSL Gateway konfigurieren und verwalten](/guides/network/ssl-gateway/use)".

:::

**3. Standort**: Wählen Sie <code className="action">Roubaix (eu-west-rbx-a)</code> oder <code className="action">Beauharnois (ca-east-bhs-a)</code>.

**4. DNS**: Wenn Sie die DNS-Zone der Domain bei OVHcloud verwalten, können Sie <code className="action">Ich verwalte die DNS-Zone dieser Domain und erlaube es OVHcloud, den erforderlichen DNS-Eintrag automatisch zu aktualisieren.</code> aktivieren. Der Eintrag wird dann für Sie aktualisiert, und die Bestellübersicht zeigt **DNS-Update**: Automatisch an. Andernfalls lassen Sie die Domain nach der Bestellung selbst auf Ihr SSL Gateway verweisen (siehe unten).

<img className="thumbnail" alt="Schritte Domain, Standort und DNS des Bestellformulars für SSL Gateway nach der Prüfung einer Domain, mit der Backend-IP, der Frist von 3 Tagen und dem Hinweis zu HTTPS" src="/images/network/ssl-gateway/order-ssl-gateway/console/order-domain-location-dns.png" loading="lazy" />

Überprüfen Sie Ihre Auswahl in der Bestellübersicht und klicken Sie dann auf <code className="action">Bestellung fortsetzen</code>. Die Seite zur Überprüfung der Bestellung öffnet sich in einem neuen Tab: Folgen Sie den Schritten bis zur Bezahlung Ihrer Bestellung. Ihr SSL Gateway erscheint nach der Bereitstellung auf der Seite **SSL Gateway**.

### Ihren Domainnamen auf das SSL Gateway verweisen lassen

Wenn Sie die DNS-Option nicht aktiviert haben, lassen Sie Ihren Domainnamen oder Ihre Subdomain innerhalb von 3 Tagen nach der Bestellung auf die IP-Adresse Ihres SSL Gateways verweisen: Die Adresse finden Sie in unserer E-Mail. Ohne diese Änderung wird die Bestellung storniert.

:::info
**Fall 1: Ihre DNS-Zone wird von den gemeinsam genutzten DNS-Servern von OVHcloud verwaltet**

- Wenn Ihre Kundenkennung ein *administrativer* oder *technischer* Kontakt dieser DNS-Zone ist, ändern Sie die Zone in der <ManagerLink console to="/#/web-cloud/domains/listing">OVHcloud Konsole</ManagerLink>.
- Andernfalls bitten Sie die für diese DNS-Zone zuständige Person, die Zone zu ändern.

Lesen Sie bei Bedarf unsere Anleitung "[DNS-A-Eintrag für einen Domainnamen hinzufügen](/guides/web-cloud/domains/dns-zone-a-record-creation)".

:::

:::info
**Fall 2: Ihre DNS-Zone wird nicht von den gemeinsam genutzten DNS-Servern von OVHcloud verwaltet**

Ändern Sie die IP-Adresse in Ihrer DNS-Zone über die Benutzeroberfläche Ihres DNS-Anbieters oder auf Ihrem eigenen DNS-Server.

:::

Ab der Bereitstellung fließt normales HTTP bereits durch Ihr SSL Gateway. HTTPS startet, sobald Ihre Domain auf das SSL Gateway verweist und das Zertifikat ausgestellt ist, normalerweise innerhalb von 15 Minuten.

:::warning
Es kann bis zu 24 Stunden dauern, bis eine Änderung an Ihrer DNS-Zone wirksam wird, da Internetanbieter DNS-Einträge in ihren Caches speichern.

:::
