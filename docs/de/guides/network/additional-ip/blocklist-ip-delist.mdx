## Ziel

Das Blocklisting (auch als Blacklisting bekannt oder als Eintrag auf einer Realtime Blackhole List (RBL)) ist eine Anti-Spam-Maßnahme, die auf IP-Adressen oder IP-Adressbereiche angewendet wird, um E-Mails zu blockieren, die als Spam eingestuft werden oder Schadsoftware enthalten könnten. Wenn ein E-Mail-Domainname oder eine IP-Adresse auf einer Blockliste steht, erreichen die davon versendeten Nachrichten ihre Empfänger möglicherweise nicht, was sich auf die Zustellbarkeit und den Absenderruf auswirkt. Zugestellte Nachrichten können im Spam-Ordner des Empfängers statt im Posteingang landen.

Blocklisten können Domainnamen und IP-Adressen enthalten, die keine tatsächliche Bedrohung darstellen. Einige Spam-Filterdienste wie SpamRATS berücksichtigen bei der Auswertung von IP-Adressen auch das Reverse DNS.

:::info
Best Practices für den Betrieb eines E-Mail-Servers finden Sie in unserer Anleitung [So verhindern Sie, dass Ihre E-Mails als Spam markiert werden](/guides/bare-metal-cloud/dedicated-servers/mail-sending-optimization).

:::


**Diese Anleitung erklärt, welche Maßnahmen Sie ergreifen können, um OVHcloud IP-Adressen zu entfernen, die auf einer Blockliste erscheinen.**

:::warning
Die Informationen in dieser Anleitung können sich ändern und gelten für neu erworbene IP-Adressen. OVHcloud übernimmt keine Verantwortung für die Handlungen von Drittanbietern.

Wir empfehlen Ihnen, sich an einen [spezialisierten Dienstanbieter](/links/partner) oder an [unsere Community](/links/community) zu wenden, wenn Sie Schwierigkeiten oder Zweifel hinsichtlich der Verwaltung, Nutzung oder Implementierung der Dienste auf einem Server haben.

:::


## Voraussetzungen

- Sie haben aktuell keine offenen Abuse-Verfahren für Ihre Dienste.

## In der praktischen Anwendung

### Unterstützte Anbieter

- [Spamhaus](https://check.spamhaus.org/)

    - [Spamhaus Block List (SBL)](https://www.spamhaus.org/blocklists/spamhaus-blocklist/)  
    Wenn [die IP auf der Spamhaus Blocklist (SBL) aufgeführt ist](https://check.spamhaus.org/sbl/listings/ovh.net/), wurden Sie bereits per E-Mail von unserem Abuse Team kontaktiert.

      Die von unserem Team versandte E-Mail stammt von einer Adresse in der Form: `ticket+ABCDEFGHIJ.ID@abuse.ovh.net` (die Ticketnummer ist immer in Großbuchstaben geschrieben, die folgende ID besteht aus 4 alphanumerischen Zeichen).

      Folgen Sie den Anweisungen in dieser E-Mail, um die Situation zu beheben. Sobald Sie Abhilfemaßnahmen ergriffen haben, leiten wir diese an Spamhaus weiter, mit der Aufforderung, Ihre IP-Adresse von der Liste zu entfernen. Spamhaus entscheidet allein über unsere Anfrage.
    - [Exploits Block List (XBL)](https://www.spamhaus.org/blocklists/exploits-blocklist/) oder [Combined Spam Sources (CSS)](https://www.spamhaus.org/blocklists/combined-spam-sources/)  
    Wenn Ihre IP-Adresse in der Exploits Block List und/oder in Combined Spam Sources aufgeführt ist, liegt dies in der Regel an Konfigurationsproblemen. Befolgen Sie die auf der Spamhaus-Website beschriebenen Schritte, um die IP-Adresse aus der Liste zu entfernen (siehe Beispiel unten). Sobald Sie diese ausgeführt haben, können Sie die IP-Adresse selbst aus der Liste entfernen.

- [SpamCop](https://www.spamcop.net/bl.shtml)  
    Auf dieser Seite können Sie den aktuellen Status einer IP-Adresse überprüfen. Die SpamCop Blocking List (SCBL) ist zeitbasiert: Eine IP-Adresse wird automatisch aus der Liste entfernt, sobald keine Spam-Meldungen mehr eingehen, sodass in der Regel keine manuelle Entfernungsanfrage erforderlich ist.

- [Barracuda](https://www.barracudacentral.org/lookups)  
    Um die Entfernung aus der Barracuda Reputation Block List (BRBL) anzufordern, füllen Sie das [Barracuda-Entfernungsformular](https://www.barracudacentral.org/rbl/removal-request) aus. Die Einträge werden manuell geprüft, sodass die Entfernung nicht sofort erfolgt.

- [SpamRATS](https://spamrats.com/lookup.php)  
    Wenn Sie Ihren eigenen E-Mail-Server verwenden, müssen Sie den Domainnamen im PTR-Eintrag konfigurieren, in dem die Kontaktdaten des Verantwortlichen zu finden sind. Nur korrekt konfigurierte E-Mail-Server werden aus dieser Liste entfernt.  
    Sie müssen außerdem die [Reverse DNS-Auflösung konfigurieren](/guides/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns).
    
    :::info
    **Best Practices:**
    
    Die für den Versand von E-Mails verwendeten IP-Adressen sollten auf den Domainnamen des Verantwortlichen aufgelöst werden. Sie können auch Subdomains für die Reverse DNS-Auflösung verwenden, wie `mail.domain_name.com` oder `gateway.domain_name.com`.

    :::



### Nicht unterstützte Anbieter

#### s5h.net

<details>

<summary>Weitere Informationen</summary>


Um die Entfernung anzufordern, öffnen Sie von der blockierten IP-Adresse aus die [usenix RBL-Entfernungsseite](https://www.usenix.org.uk/content/rblremove). Die IP sollte sofort aus der Liste entfernt werden.

Dies ist auch mit den Tools *telnet*, *curl* oder *wget* möglich.

Um Ihre IPv4-Adresse über *curl* aus der Liste zu entfernen, loggen Sie sich beim aufgeführten Mailserver ein und führen Sie folgenden Befehl aus:

```bash
curl -4 http://www.usenix.org.uk/content/rblremove
```

Wenn Sie denselben Vorgang mit *telnet* auf einem Windows- oder Linux-Host ausführen möchten, geben Sie die Zeilen *GET* und *Host* nach dem Befehl *telnet* wie unten dargestellt ein.

```bash
telnet www.usenix.org.uk 80
```

```bash
GET /content/rblremove HTTP/1.1
```

```bash
Host: www.usenix.org.uk
```

Eine ausführliche Erläuterung finden Sie in der [usenix RBL-Dokumentation](https://www.usenix.org.uk/content/rbl.html).

</details>


#### UCEprotect


<details>

<summary>Weitere Informationen</summary>


UCEprotect setzt regelmäßig eine große Anzahl von ASNs auf seine Level-3-Blockliste, und die OVHcloud ASN (AS16276) kann davon betroffen sein. Die Liste der betroffenen ASNs und die Anzahl der neu hinzugefügten ASNs finden Sie unter folgenden Links:

- [UCEPROTECT Level 3 charts](https://www.uceprotect.net/en/l3charts.php)
- [UCEPROTECT statistics center](https://stats.uceprotect.net/?page=su)

Unser Abuse Team kontaktiert UCEprotect, um die Entfernung unserer ASN aus der Blockliste anzufordern. UCEprotect verlangt von den Netzbetreibern der gesperrten ASNs eine Bezahlung für die sofortige Entfernung aus der Liste. Wie alle großen Anbieter zahlt OVHcloud nicht für die Entfernung aus Blocklisten, da es sich um einen Dienst außerhalb unserer Kontrolle handelt. Die Bezahlung für die Entfernung erhöht das Blocklisting insgesamt nur und schadet letztlich der Branche.

UCEprotect gibt an, dass ASNs nach einer Woche automatisch aus der Liste entfernt werden. Da dies außerhalb unserer Kontrolle liegt, können wir diesbezüglich keine Garantie geben.

Wenn Sie derzeit davon betroffen sind, empfehlen wir Ihnen Folgendes:

1. Verwenden Sie IPv6-Adressen zum Versenden von E-Mails. UCEprotect blockiert keine über IPv6 versendeten E-Mails. Alle OVHcloud Dienste umfassen mindestens eine IPv6-Adresse, die Sie konfigurieren können, und alle großen E-Mail-Anbieter unterstützen mittlerweile IPv6.
2. Bitten Sie den Empfänger, sich mit seinem E-Mail-Anbieter in Verbindung zu setzen und ihn aufzufordern, die Verwendung der UCEprotect-Blockliste einzustellen.


</details>


#### Fabel Spamsources

<details>

<summary>Weitere Informationen</summary>


Um eine IP-Adresse aus Fabel Spamsources zu entfernen, öffnen Sie deren [Entfernungsseite](https://www.spamsources.fabel.dk/delist).

Klicken Sie auf <code className="action">Please login to continue</code>, geben Sie Ihre E-Mail-Adresse ein und überprüfen Sie Ihren Posteingang. Verwenden Sie den Prüfcode, um die Anmeldung abzuschließen.

Geben Sie Ihre IP-Adresse ein, geben Sie einen Grund für die Entfernungsanfrage an und klicken Sie auf <code className="action">Submit Query</code>.

<img className="thumbnail" alt="Fabel Spamsources-Entfernungsformular mit Feldern für IP-Adresse und Grund" src="/images/network/additional-ip/blocklist-ip-delist/blocklist3.png" loading="lazy" />

Die Entfernung aus der Liste sollte zwischen 20 und 30 Minuten dauern.

</details>



#### MIPSpace

<details>

<summary>Weitere Informationen</summary>


Um [eine IP aus MIPSpace zu entfernen](https://www.mipspace.com/removal.php), loggen Sie sich zunächst im <ManagerLink to="/">OVHcloud Kundencenter</ManagerLink> ein und stellen Sie sicher, dass die folgenden Informationen aktuell sind:

- [Die Reverse DNS-Auflösung](/guides/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns) (PTR-Eintrag).
- Die Details Ihrer Organisation (*RWhois*). Navigieren Sie zu <code className="action">Network</code> > <code className="action">Öffentliches Netzwerk</code> > <code className="action">Öffentliche IP-Adressen</code> und öffnen Sie dann die Registerkarte <code className="action">Meine Organisationen verwalten</code>.

</details>
