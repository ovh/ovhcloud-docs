## Einleitung

Sie können Ihrem Content Delivery Network (CDN) ein [SSL-Zertifikat](https://www.ovhcloud.com/de/web-hosting/options/ssl/) hinzufügen, damit Ihre Nutzer auch über das CDN eine gesicherte Verbindung herstellen können.

**In dieser Anleitung erfahren Sie, wie Sie dies mit einem von OVHcloud bereitgestellten Let's Encrypt-Zertifikat oder mit Ihrem eigenen Zertifikat umsetzen.**

## Voraussetzungen

- Sie verfügen über ein [CDN von OVHcloud](https://www.ovhcloud.com/de/network/cdn/).
- Sie haben Zugriff auf die Verwaltung der DNS-Zone Ihrer Domain.

## Beschreibung

### Wie bekomme ich ein von OVHcloud bereitgestelltes SSL-Zertifikat von Let's Encrypt für meine CDN-Subdomains?

- Wenn Ihr CDN noch kein Zertifikat hat, können Sie beim Hinzufügen einer Domain ein kostenloses Let's Encrypt-Zertifikat erstellen lassen: Wählen Sie im Assistenten **Geführte Domaineinrichtung** im Schritt **SSL-Zertifikat** die Option **Let's Encrypt**. Sie können es auch jederzeit im Tab <code className="action">SSL</code> erstellen: Klicken Sie auf <code className="action">Zertifikat hinzufügen</code>, wählen Sie **Let's Encrypt (kostenlos)** aus, geben Sie einen Namen für das Zertifikat ein und klicken Sie auf <code className="action">Zertifikat hinzufügen</code>.
- Hat Ihr CDN beim Hinzufügen einer weiteren Subdomain bereits ein Zertifikat, überspringt die geführte Einrichtung den SSL-Schritt.

Damit die Zertifikatserstellung erfolgreich ist, muss die hinzugefügte Subdomain korrekt auf das CDN zeigen, und Port 80 muss für die Let's Encrypt-Validierung auf dem CDN erreichbar sein. Um zu überprüfen, ob Ihre Subdomain auf das CDN zeigt, folgen Sie der Anleitung zum Thema "[Erste Konfiguration einer Domain](/guides/network/cdn/cdn-infrastructure-first-domain-configuration)".

Die Erneuerung des Zertifikats erfolgt automatisch innerhalb von 20 Tagen vor dessen Ablauf.

:::warning
Das von OVHcloud bereitgestellte SSL-Zertifikat von Let's Encrypt gilt für die ersten 100 auf dem CDN konfigurierten Domains oder Subdomains. Sollten Sie mehr als 100 Domains einrichten wollen, konfigurieren Sie bitte Ihr eigenes Wildcard-/Multi-Domain-Zertifikat.
:::

### Wie lange dauert die Erstellung meines Zertifikats?

Sobald Ihre Domain korrekt auf das CDN zeigt, dauern die Erstellung (oder Erneuerung) eines Let's Encrypt-Zertifikats und dessen Deployment etwa 2 Minuten.

Solange ein SSL-Vorgang läuft, wird dies im Tab <code className="action">SSL</code> angezeigt, und der Tab wird automatisch aktualisiert.

Wenn die Erstellung länger als erwartet dauert, zeigt der Tab <code className="action">SSL</code> eine Meldung sowie den Link <code className="action">SSL-Vorgänge anzeigen</code> an, der die SSL-Vorgänge Ihres CDN im Tab **Vorgänge** auflistet. Überprüfen Sie in diesem Fall, ob die auf Ihrem CDN konfigurierte Domain auf das CDN zeigt und ob Port 80 erreichbar ist. Ist dies nicht der Fall, kann unser System das Zertifikat nicht korrekt generieren.

Es gibt keine Zeitüberschreitung: Solange Ihre DNS-Änderungen nicht propagiert sind, bleibt die Erstellung ausstehend und wird abgeschlossen, sobald die Domain auf das CDN zeigt. Sie müssen kein neues Zertifikat anfordern.

Sobald das Zertifikat aktiviert ist, zeigt der Tab <code className="action">SSL</code> es unter **Zertifikatsinformationen** an: Name, Anbieter (**Let's Encrypt** oder **Eigenes Zertifikat**), Status, Common Name (CN) und Gültigkeitszeitraum.

### Wie kann ich ein eigenes Zertifikat hinzufügen?

Wenn Ihr CDN noch kein Zertifikat hat, können Sie Ihr eigenes Zertifikat im Tab <code className="action">SSL</code> importieren, auch bevor Ihre DNS-Änderungen propagiert sind. Klicken Sie auf <code className="action">Zertifikat hinzufügen</code>, wählen Sie **Eigenes Zertifikat importieren** aus und geben Sie dann einen Namen (optional), Ihr Zertifikat und dessen privaten Schlüssel im PEM-Format sowie, falls Ihre Zertifizierungsstelle dies verlangt, die Zertifikatskette ein. Klicken Sie zur Bestätigung auf <code className="action">Zertifikat hinzufügen</code>.

<img className="thumbnail" alt="Tab SSL eines CDN ohne Zertifikat" src="/images/network/content-delivery-network-infrastructure/ssl-certificate/ssl-tab.png" loading="lazy" />

<img className="thumbnail" alt="Panel Zertifikat hinzufügen" src="/images/network/content-delivery-network-infrastructure/ssl-certificate/ssl-add-certificate.png" loading="lazy" />

Wenn Ihr CDN bereits ein eigenes Zertifikat hat, klicken Sie im Tab <code className="action">SSL</code> auf <code className="action">Zertifikat aktualisieren</code>. Geben Sie Ihr neues Zertifikat, dessen privaten Schlüssel und optional dessen Kette ein und klicken Sie dann auf <code className="action">Zertifikat aktualisieren</code>.

Ein Let's Encrypt-Zertifikat kann auf diese Weise nicht aktualisiert werden: Um es durch Ihr eigenes Zertifikat zu ersetzen, klicken Sie im Tab <code className="action">SSL</code> auf <code className="action">Löschen</code> und bestätigen Sie im Fenster **Zertifikat löschen** mit <code className="action">Löschen</code>. Fügen Sie anschließend Ihr Zertifikat wie oben beschrieben hinzu.
