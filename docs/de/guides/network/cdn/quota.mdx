## Einleitung

Mithilfe des Content Delivery Network (CDN) können Sie die Antwortzeiten von Websites für Ihre Benutzer optimieren. Jede Verbindung mit Ihrer Website erzeugt dabei einen Datenstrom, der Quota (das Gesamtdatenlimit des Traffics zu und von Ihrem CDN) verbraucht.

**In dieser Anleitung erhalten Sie alle Informationen zur Verwaltung des Quotas in Ihrem CDN.**

## Voraussetzungen

- Sie verfügen über eine Lösung [OVHcloud Content Delivery Network (CDN)](https://www.ovhcloud.com/de/network/cdn/).

[[cpnav:network-cdn-console]]

## Beschreibung

### Quota bestellen

Bei der Bestellung erhalten Sie **1 TB** Traffic-Quota. Bitte beachten Sie, dass dieses nicht jeden Monat automatisch erneuert wird. Ist das Quota aufgebraucht (egal über welchen Zeitraum), muss neues Quota bestellt werden.

Das verbleibende Datenvolumen wird im Tab **Übersicht** Ihres CDN im Bereich **Nutzung** unter **Datenvolumen** angezeigt. Wenn Sie zusätzliches Quota benötigen, klicken Sie in diesem Bereich auf <code className="action">Add-on hinzufügen</code>. Wählen Sie im Panel **Add-on hinzufügen** in der Liste **Add-on** den Eintrag **Datenvolumen** und in der Liste **Option** die gewünschte Bandbreite aus, setzen Sie einen Haken bei **Ich habe die allgemeinen Verkaufsbedingungen gelesen und akzeptiere sie** und klicken Sie dann auf <code className="action">Hinzufügen</code>. Die Zahlungsseite wird geöffnet, damit Sie Ihre Bestellung abschließen können.

<img className="thumbnail" alt="Panel Add-on hinzufügen mit der Option Datenvolumen" src="/images/network/content-delivery-network-infrastructure/quota/add-addon.png" loading="lazy" />

Die Preise für das Quota finden Sie auf der zugehörigen [Webseite](https://www.ovhcloud.com/de/network/cdn/).

Sie erhalten eine E-Mail, sobald nur noch **100 GB** Quota übrig sind, damit Sie rechtzeitig weitere Bandbreite bestellen können. Wenn Ihr Quota aufgebraucht ist, wird automatisch die `bypass`-Funktion aktiviert, bis Sie weiteres Quota bestellt haben.

### Traffic-Abrechnung für das CDN-Angebot

:::info
Ihnen wird der gesamte ausgehende Traffic des CDN berechnet.  

:::

Der Traffic Ihres CDN setzt sich aus zwei Arten von Anfragen zusammen, die Sie im Tab <code className="action">Statistiken</code> verfolgen können (**Bandbreite** und **Cache-Leistung**):

- **Bereits im Cache gespeicherte Dateien**: Das CDN beantwortet Anfragen zu diesen Dateien direkt.

- **Vom *Backend* des CDN abgerufene Dateien**: Die auf Ihre Domain angewendeten Cache-Regeln, die Sie im Tab <code className="action">Cache-Regeln</code> verwalten, legen fest, welche Dateien vom *Backend* abgerufen und welche im Cache gespeichert werden.

Unabhängig davon, ob die Dateien in den Cache gelegt oder vom *Backend* aus über Ihr CDN geladen werden, **beide Arten von Traffic werden von Ihrem Quota abgezogen**. Aus diesem Grund empfehlen wir Ihnen, eine spezielle Subdomain für Dateien anzulegen, die in den Cache geladen werden, und für die übrigen Dateien Domains zu verwenden, die auf das *Backend* weisen.
