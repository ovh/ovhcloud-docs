## Ziel

Ziel dieser Anleitung ist es, die Verwendung des Secret Manager über die OVHcloud Konsole vorzustellen.

## Voraussetzungen

- Sie verfügen über einen [OVHcloud Kunden-Account](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- Um über die REST-API oder die mit HashiCorp Vault KV2 kompatible API auf Secrets zuzugreifen, konfigurieren Sie eine [Authentifizierungsmethode](/guides/manage-and-operate/kms/okms-authentication-methods) für Ihre OKMS-Domain (Personal Access Token, Service-Account oder Zugriffszertifikat).

[[cpnav:security-secret-manager]]

## In der praktischen Anwendung

### Beschreibung

Der Secret Manager ist ein Produkt, mit dem Sie Zugangsdaten, API-Schlüssel, SSH-Schlüssel oder jede andere Art von Secret, die für den Betrieb Ihrer Anwendungen erforderlich ist, sicher speichern können.

Ein Secret ist eine Sammlung aus einem oder mehreren Schlüssel-Wert-Paaren, die innerhalb einer Version zusammengefasst sind.
Jede Änderung eines Secrets erzeugt eine neue Version dieses Secrets, sodass Sie in der Änderungshistorie des Secrets zurückgehen können.

### Ein Secret erstellen

In der OVHcloud Konsole werden Secrets im Key & Secret Manager verwaltet. Öffnen Sie im linken Menü <code className="action">Sicherheit</code> und klicken Sie auf <code className="action">Key & Secret Manager</code>. Jede OKMS-Domain verfügt über einen Tab <code className="action">Secrets</code>, der die in dieser Domain gespeicherten Secrets auflistet.

<img className="thumbnail" alt="Tab Secrets einer OKMS-Domain mit der Schaltfläche Ein Secret erstellen" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secrets-tab.png" loading="lazy" />

Um ein Secret zu erstellen, klicken Sie auf <code className="action">Ein Secret erstellen</code>.

Im Erstellungsformular ist keine Region auszuwählen: Das Secret wird in der OKMS-Domain erstellt, die in der Liste **OKMS-Domain** ausgewählt ist, und damit in der Region dieser Domain. Wählen Sie die richtige Domain aus, bevor Sie auf <code className="action">Ein Secret erstellen</code> klicken.

:::info
Wenn Sie in der Region, in der Sie das Secret erstellen möchten, noch keine OKMS-Domain haben, erstellen Sie zuerst eine: Öffnen Sie die Liste **OKMS-Domain**, klicken Sie auf <code className="action">Domain erstellen</code> und wählen Sie die Region aus.
Die Erstellung der Domain kann einige Minuten dauern.
:::


Geben Sie den **Path** des Secrets an, zum Beispiel **prod/database/MySQL**. Dieser Path dient dazu, die Secrets hierarchisch zu organisieren.

Geben Sie dann im Bereich **Konfiguration der Werte** den Inhalt des Secrets an. Das Secret enthält eine Liste von Schlüssel-Wert-Paaren. Standardmäßig werden diese in der Ansicht **Schlüssel-Wert** einzeln eingegeben (<code className="action">Schlüssel/Wert hinzufügen</code> fügt eine Zeile hinzu). In der Ansicht **JSON** können Sie sie im JSON-Format eingeben:

```json
{
    "login": "admin",
    "password": "my_secret_password"
}
```

<img className="thumbnail" alt="Seite Ein Secret erstellen mit den Bereichen Path und Konfiguration der Werte" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/create-secret-form.png" loading="lazy" />

:::info
Es gibt keine Begrenzung für die Anzahl der Schlüssel-Wert-Paare in einem Secret, die Gesamtgröße der Daten darf jedoch 64 KB nicht überschreiten.
:::


Sobald das Secret erstellt ist, erscheint es in der Liste der Secrets im Tab **Secrets** der OKMS-Domain.

### Secrets verwalten

Sobald ein Secret erstellt wurde, wird die Liste der Secrets im Tab **Secrets** der OKMS-Domain in der OVHcloud Konsole angezeigt.
Um die Secrets einer anderen OKMS-Domain anzuzeigen, wählen Sie diese in der Liste **OKMS-Domain** oberhalb der Tabs aus, in der Ihre Domains nach Region gruppiert sind.

Sie können auf die Konfiguration des Secrets zugreifen, indem Sie in der Liste der Secrets auf seinen Path klicken, um seinen Inhalt anzuzeigen, eine neue Version zu erstellen oder es zu löschen.

Das Dashboard des Secrets zeigt mehrere Informationen an, wie allgemeine Informationen sowie die für das Secret geltenden Parameter:

- **Maximale Anzahl von Versionen**: Über den angegebenen Wert hinaus wird die älteste Version gelöscht.
- **Ablaufzeit einer Version**: Nach Ablauf der angegebenen Dauer wird die Version deaktiviert.
- **CAS (Check-And-Set Version Control)**: Wenn diese Option aktiviert ist, müssen Sie bei Änderungen immer die aktuelle Versionsnummer angeben.

<img className="thumbnail" alt="Dashboard eines Secrets mit den Bereichen Werte, Allgemeine Informationen und Konfiguration" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secret-dashboard.png" loading="lazy" />

#### Auf den Inhalt eines Secrets zugreifen

Ein Benutzer mit den erforderlichen IAM-Rechten kann auf den Inhalt eines Secrets zugreifen. Konfigurieren Sie die Authentifizierung und die IAM-Richtlinien wie unter [OKMS-Authentifizierungsmethoden](/guides/manage-and-operate/kms/okms-authentication-methods) beschrieben.

:::info
Die Rechte zum Auflisten einer Version (**okms:apiovh:secret/get**) unterscheiden sich vom Recht, den Inhalt dieser Version abzurufen (**okms:apiovh:secret/version/getData**).
:::


Klicken Sie dazu im Bereich **Werte** des Secret-Dashboards auf <code className="action">Wert einblenden</code>.

Der Bereich **Werte** wird erweitert und zeigt den Inhalt der neuesten Version des Secrets an – als Schlüssel-Wert-Paare oder im JSON-Format. Jeder Wert kann kopiert werden.

<img className="thumbnail" alt="Bereich Werte mit den Schlüssel-Wert-Paaren der aktuellen Version" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secret-values-revealed.png" loading="lazy" />

Ein Selektor ermöglicht es, zwischen den verschiedenen Versionen des Secrets zu navigieren und den Status der ausgewählten Version einzusehen.
Wenn die Version deaktiviert oder gelöscht ist, wird kein Wert angezeigt.

#### Versionen verwalten

Um auf die Versionen eines Secrets zuzugreifen, klicken Sie auf den Tab <code className="action">Versionen</code>. Er listet alle Versionen des Secrets auf, jeweils mit Nummer, Erstellungsdatum, Ablaufdatum und Status.
Jede Änderung eines Secrets erzeugt eine neue Version.

<img className="thumbnail" alt="Tab Versionen mit den Versionen eines Secrets und ihrem Status" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secret-versions.png" loading="lazy" />

Eine Version kann entweder sein:

- Aktiv: Der Wert dieser Version ist zugänglich.
- Deaktiviert: Der Wert dieser Version ist noch im System vorhanden, aber nicht mehr zugänglich, bis die Version reaktiviert wird.
- Gelöscht: Der Wert dieser Version ist nicht mehr im System vorhanden und kann nicht wiederhergestellt werden.

Klicken Sie bei jeder Version auf <code className="action">Version einblenden</code>, um ihren Wert anzuzeigen. Über die Schaltfläche `⋮` öffnen Sie ein Menü, um die Version zu deaktivieren (<code className="action">Deaktivieren</code>) oder zu reaktivieren (<code className="action">Reaktivieren</code>) oder um sie zu löschen (<code className="action">Löschen</code>).

Eine durch den Parameter **Maximale Anzahl von Versionen** gelöschte Version erscheint nicht mehr in der Liste der Versionen.

### Die OKMS-Domain verwalten

Die OKMS-Domain des Secret Manager wird mit der OKMS-Domain des Key Management Service geteilt.
Das Erstellen oder Löschen einer OKMS-Domain hat daher Auswirkungen auf beide Produkte.

Sie können die Secrets-Konfiguration der OKMS-Domain in deren Tab **Übersicht** im Bereich **Konfiguration der Secrets** ändern (<code className="action">Ändern</code>).

#### Fall mehrerer OKMS-Domains

In derselben Region können mehrere OKMS-Domains vorhanden sein. Die OKMS-Domain wird vorab in der Liste **OKMS-Domain** oberhalb der Tabs ausgewählt, in der Ihre Domains nach Region gruppiert sind. Die Secrets, die Sie anzeigen oder erstellen, gehören zu der in dieser Liste ausgewählten Domain: Beim Erstellen eines Secrets gibt es keinen zusätzlichen Auswahlschritt.

<img className="thumbnail" alt="Liste OKMS-Domain mit den nach Region gruppierten Domains und dem Eintrag Domain erstellen" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/okms-domain-switcher.png" loading="lazy" />

Um eine OKMS-Domain in einer Region hinzuzufügen, klicken Sie oben in dieser Liste auf <code className="action">Domain erstellen</code> und wählen Sie anschließend die Region aus.

### Den Secret Manager über die API nutzen

Der Secret Manager ist über zwei verschiedene API-Sets zugänglich. Beide bearbeiten dieselben Objekte — ein mit der einen Methode erstelltes Secret ist über die andere zugänglich.

Bevor Sie eine der beiden APIs aufrufen, konfigurieren Sie eine [Authentifizierungsmethode](/guides/manage-and-operate/kms/okms-authentication-methods) und die erforderliche [IAM-Richtlinie](/guides/manage-and-operate/kms/okms-authentication-methods#iam-rights-for-okms) für Ihre OKMS-Domain. Für die Nutzung der REST-API wird ein Personal Access Token oder ein Service-Account empfohlen.

- Eine [REST-API](/guides/manage-and-operate/secret-manager/rest-api), die den Standard-APIs von OVHcloud ähnelt.
- Eine [mit HashiCorp Vault KV2 kompatible API](/guides/manage-and-operate/secret-manager/kv2-api), die Kompatibilität mit Anwendungen bietet, die bereits mit HashiCorp Vault KV2 kompatibel sind.
