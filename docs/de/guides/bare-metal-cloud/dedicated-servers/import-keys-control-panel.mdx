## Ziel

Schlüsselpaare werden zur Authentifizierung von SSH-Verbindungen zwischen Hosts verwendet, z.B. zwischen einem Desktop-Client und einem Remote-Server. Bei der Reinstallation eines Dedicated Servers oder VPS über die OVHcloud Konsole haben Sie die Möglichkeit, einen öffentlichen Schlüssel zum Betriebssystem hinzuzufügen. Die Speicherung öffentlicher Schlüssel in der OVHcloud Konsole vereinfacht diesen Vorgang.

**Diese Anleitung erklärt, wie Sie Ihre öffentlichen Authentifizierungsschlüssel in der OVHcloud Konsole speichern.**

## Voraussetzungen

- Sie haben einen [Dedicated Server](/links/bare-metal/bare-metal) oder einen [VPS](/links/bare-metal/vps) in Ihrem Kunden-Account.

## In der praktischen Anwendung

Wenn Sie noch kein SSH-Schlüsselpaar erstellt haben, lesen Sie zuerst unsere Anleitungen:

- [Erstellen und Verwenden von Schlüsseln für die SSH-Authentifizierung](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutorial - PuTTY für SSH-Verbindungen und Authentifizierung verwenden](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

Auf der Seite **SSH-Schlüssel** werden die in Ihrem Account gespeicherten Schlüssel aufgelistet.

Klicken Sie auf <code className="action">SSH-Schlüssel hinzufügen</code> und wählen Sie <code className="action">Dedicated</code> aus dem Menü.

Kopieren Sie im Fenster **SSH-Schlüssel hinzufügen** die gesamte Zeichenfolge des öffentlichen Schlüssels und fügen Sie sie in das Feld **Öffentlicher Schlüssel** ein. Geben Sie dann im Feld **Name** eine Bezeichnung für den Schlüssel ein.

Klicken Sie auf <code className="action">Hinzufügen</code>.

Der Schlüssel ist ab sofort bei der Reinstallation eines Dedicated Servers oder VPS in der OVHcloud Konsole verfügbar.

Sie können einen Schlüssel auch über die Seite eines Dedicated Servers hinzufügen: Klicken Sie im Tab <code className="action">Server</code> im Block **SSH keys** des Bereichs **Server connection** auf <code className="action">Add SSH key</code>. Geben Sie im Fenster **Add SSH key** einen **Key name** ein, fügen Sie den Schlüssel in das Feld **Public key** ein und klicken Sie auf <code className="action">SSH-Schlüssel hinzufügen</code>. Der Schlüssel wird in Ihrem Account gespeichert, wie ein über die Seite **SSH-Schlüssel** hinzugefügter Schlüssel.
