## Ziel

Schlüsselpaare werden zur Authentifizierung von SSH-Verbindungen zwischen Hosts verwendet, z.B. zwischen einem Desktop-Client und einem Remote-Server. Bei der Reinstallation eines Dedicated Servers oder VPS über die OVHcloud Konsole haben Sie die Möglichkeit, einen öffentlichen Schlüssel zum Betriebssystem hinzuzufügen. Die Speicherung öffentlicher SSH-Schlüssel in der Konsole vereinfacht diesen Vorgang.

**Diese Anleitung erklärt, wie Sie Ihre öffentlichen SSH-Schlüssel in der OVHcloud Konsole speichern.**

## Voraussetzungen

- Sie haben einen [Dedicated Server](/links/bare-metal/bare-metal) oder einen [VPS](/links/bare-metal/vps) in Ihrem Kunden-Account.

## In der praktischen Anwendung

Wenn Sie noch kein SSH-Schlüsselpaar erstellt haben, lesen Sie zuerst unsere Anleitungen:

- [Erstellen und Verwenden von Schlüsseln für die SSH-Authentifizierung](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutorial - PuTTY für SSH-Verbindungen und Authentifizierung verwenden](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

<img className="thumbnail" alt="Identity and Access Management group of the Console left menu, with the SSH keys entry" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/sidebar-iam-ssh-keys.png" loading="lazy" />

Öffnen Sie im linken Menü der OVHcloud Konsole **Identitäts- und Zugriffsverwaltung** und klicken Sie auf <code className="action">SSH-Schlüssel</code>.

<img className="thumbnail" alt="SSH keys page with the Add an SSH key button above the list of keys" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-button.png" loading="lazy" />

Öffnen Sie das Menü <code className="action">SSH-Schlüssel hinzufügen</code> oberhalb der Liste und wählen Sie <code className="action">Dedicated</code> aus.

<img className="thumbnail" alt="Add an SSH key menu open, showing the Dedicated and Public Cloud options" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-menu.png" loading="lazy" />

Kopieren Sie im Fenster **SSH-Schlüssel hinzufügen** die gesamte Zeichenfolge des öffentlichen Schlüssels und fügen Sie sie in das erste Feld, **Öffentlicher Schlüssel**, ein. Fügen Sie nur den öffentlichen Schlüssel ein (den Inhalt Ihrer `.pub`-Datei), niemals den privaten Schlüssel.  
Geben Sie im zweiten Feld, **Name**, eine Bezeichnung für den Schlüssel ein, damit Sie ihn wiedererkennen (zum Beispiel den Namen Ihres Computers).

<img className="thumbnail" alt="Add an SSH key window with the Public key and Name fields and the Add button" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-dedicated-window.png" loading="lazy" />

Klicken Sie auf <code className="action">Hinzufügen</code>.

Der Schlüssel ist ab sofort bei der Reinstallation eines Dedicated Servers oder VPS in der OVHcloud Konsole verfügbar.
