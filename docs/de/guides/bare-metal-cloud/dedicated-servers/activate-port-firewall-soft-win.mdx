## Ziel

Um Ihr System bestmöglich zu schützen, verfügt Ihr Dedicated Server mit Windows Server über eine integrierte Firewall. Durch deren Konfiguration können Sie das Sicherheitsniveau erhöhen und so die Verfügbarkeit und Integrität aller auf dem Server gehosteten Elemente wie Rollen, Dienste und freigegebener Ordner gewährleisten.

**Diese Anleitung erklärt, wie Sie Firewall-Regeln unter Windows anwenden.**

:::warning
OVHcloud stellt Ihnen Dienstleistungen zur Verfügung, für deren Konfiguration und Verwaltung Sie die alleinige Verantwortung tragen. Es liegt somit bei Ihnen, sicherzustellen, dass diese ordnungsgemäß funktionieren.

Diese Anleitung soll Sie bei allgemeinen Aufgaben bestmöglich unterstützen. Dennoch empfehlen wir Ihnen, einen [spezialisierten Dienstleister](/links/partner) zu kontaktieren und/oder sich mit [unserer Community](/links/community) auszutauschen, wenn Sie Schwierigkeiten oder Zweifel hinsichtlich der Verwaltung, Nutzung oder Sicherheit eines Servers haben.

:::

## Voraussetzungen

- Sie verfügen über einen [Dedicated Server](/links/bare-metal/bare-metal) mit Windows in Ihrem OVHcloud Account.
- Sie haben über Remotedesktop administrativen Zugriff auf Ihren Server.

## In der praktischen Anwendung

### Schritt 1: Auf die Windows-Firewall zugreifen

Um auf die Windows-Firewall zuzugreifen, gehen Sie wie folgt vor:

- Klicken Sie auf <code className="action">Start</code>.
- Klicken Sie auf <code className="action">Suchen</code>.
- Suchen Sie in der Suchleiste nach "Windows Defender Firewall".
- Klicken Sie auf <code className="action">Windows Defender Firewall</code>.

Klicken Sie anschließend auf <code className="action">Erweiterte Einstellungen</code>.

<img className="thumbnail" alt="Fenster der Windows Defender Firewall mit dem Link Erweiterte Einstellungen" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step1.PNG" loading="lazy" />

### Schritt 2: Eine eingehende Regel aktivieren

In dem Fenster, das sich öffnet, sehen Sie Einstellungen wie:

- Eingehende und ausgehende Regeln
- Verbindungssicherheitsregeln
- Überwachungsoptionen der Server-Firewall

Wenn Sie <code className="action">Eingehende Regeln</code> auswählen, werden alle vorkonfigurierten Windows-Server-Regeln angezeigt, die mit Netzwerkverbindungen und eingehenden Paketen verknüpft sind. Einige dieser Regeln sind standardmäßig nicht aktiviert. Um sie zu aktivieren, klicken Sie mit der rechten Maustaste auf die Regel und wählen Sie die Option <code className="action">Regel aktivieren</code> aus.

<img className="thumbnail" alt="Liste der eingehenden Regeln mit der Option zum Aktivieren einer Regel" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step2.PNG" loading="lazy" />

### Schritt 3: Eine neue Regel erstellen

Um eine neue Regel zu erstellen, öffnen Sie das Menü <code className="action">Aktion</code> und wählen Sie <code className="action">Neue Regel</code> aus, oder klicken Sie im rechten Bereich auf <code className="action">Neue Regel</code>.

<img className="thumbnail" alt="Menü Aktion in der Konsole der Windows Defender Firewall mit hervorgehobenem Eintrag Neue Regel" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step3.PNG" loading="lazy" />

### Schritt 4: Den Typ der zu aktivierenden Regel festlegen

Der Assistent für neue Regeln bietet Optionen, um den Typ der zu erstellenden Regel festzulegen. Wählen Sie die Option <code className="action">Port</code> aus.

<img className="thumbnail" alt="Seite Regeltyp des Assistenten für neue eingehende Regel mit ausgewählter Option Port" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step4.PNG" loading="lazy" />

### Schritt 5: Den Typ des zu aktivierenden Ports festlegen

Legen Sie im nächsten Schritt den Typ des zu aktivierenden Ports fest:

<img className="thumbnail" alt="Seite Protokoll und Ports, auf der TCP und ein bestimmter lokaler Port ausgewählt sind" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step5.PNG" loading="lazy" />

:::info
- TCP (Transmission Control Protocol)

  Es handelt sich um ein verbindungsorientiertes Protokoll, d. h., mit TCP können Verbindungen zwischen Hosts aufgebaut werden, um Datenströme zu senden. Dieses Protokoll stellt sicher, dass die Daten in derselben Reihenfolge und fehlerfrei beim Empfänger ankommen.

- UDP (User Datagram Protocol)

  Es handelt sich um ein verbindungsloses Protokoll. Es wurde auf Basis des Austauschs von Datagrammen entwickelt und erleichtert deren Versand über das Netzwerk. Es muss zuvor keine Verbindung zum Ziel hergestellt werden.

Sie können auch die Option <code className="action">Alle lokalen Ports</code> auswählen, um alle TCP- bzw. UDP-Ports auf einem nicht gesicherten Server freizugeben. Alternativ können Sie die Option <code className="action">Bestimmte lokale Ports</code> auswählen, um festzulegen, welcher Port zugelassen werden soll.

:::

### Schritt 6: Die Verbindung zulassen oder blockieren

Für die Aktion, die diese Regel auslösen soll, stehen folgende Optionen zur Verfügung. Wählen Sie die für Sie passende Option aus.

- **Verbindung zulassen**. Diese Option erlaubt die vollständige Kommunikation über diesen Port.
- **Verbindung zulassen, wenn sie sicher ist**. Diese Option erlaubt die Übertragung von Daten nur, wenn die Verbindung über IPsec authentifiziert ist.
- **Verbindung blockieren**. Diese Option verhindert, dass Daten über diesen Port geleitet werden.

Wählen Sie die Option <code className="action">Verbindung zulassen</code> aus und klicken Sie auf <code className="action">Weiter</code>.

<img className="thumbnail" alt="Seite Aktion des Assistenten mit ausgewählter Option Verbindung zulassen" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step6.PNG" loading="lazy" />

### Schritt 7: Das Profil und den Namen der Regel festlegen

Abschließend müssen Sie auswählen, für welche Profile die Regel gelten soll: Öffentlich, Domäne oder Privat.
Sie können bei Bedarf alle Profile aktivieren.

<img className="thumbnail" alt="Seite Profil des Assistenten mit aktivierten Profilen Domäne, Privat und Öffentlich" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7.PNG" loading="lazy" />

Geben Sie der neuen Regel einen Namen und (optional) eine Beschreibung, um ihre Verwendung zu erleichtern:

<img className="thumbnail" alt="Seite Name des Assistenten mit eingegebenem Namen der Regel" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7-01.PNG" loading="lazy" />

Klicken Sie auf die Schaltfläche <code className="action">Fertig stellen</code>, um den Vorgang abzuschließen und die neue Regel zu erstellen.

<img className="thumbnail" alt="Liste Eingehende Regeln mit der neuen, aktivierten Regel" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7_02.PNG" loading="lazy" />

Anschließend können Sie die Einstellungen der neu erstellten Regel ändern.
