## Ziel

Die OVHcloud Link Aggregation (OLA) wurde von unseren Teams entwickelt, um die Verfügbarkeit Ihres Servers zu erhöhen und die Effizienz Ihrer Netzwerkverbindungen zu steigern. Mit nur wenigen Klicks können Sie Ihre Netzwerkkarten aggregieren und Ihre Netzwerkverbindungen redundant machen. Wenn also eine Verbindung ausfällt, wird der Datenverkehr automatisch auf eine andere verfügbare Verbindung umgeleitet. Die verfügbare Bandbreite wird durch Aggregation ebenfalls verdoppelt.
Die Aggregation verwendet das Link Aggregation Control Protocol (LACP), das im Standard IEEE 802.3ad definiert ist.

**Diese Anleitung erklärt, wie Sie NIC Teaming für OLA in Windows Server 2019 konfigurieren.**

## In der praktischen Anwendung

Da Ihre NICs in OLA privat-privat konfiguriert sind, können Sie keine SSH-Verbindung zum Server herstellen. Sie müssen daher die IPMI/KVM-Konsole verwenden, um auf den Server zuzugreifen.

Öffnen Sie in der OVHcloud Console den Tab <code className="action">Server</code> Ihres Servers. Klicken Sie im Block **KVM over IP** des Bereichs **Server connection** auf <code className="action">Mit einem Java-Applet (KVM)</code>. Diese Option wird nur bei Servern angezeigt, deren IPMI kein KVM im Browser (HTML5) bietet. Klicken Sie bei anderen Servern im selben Block auf <code className="action">Access console (KVM)</code>. Klicken Sie im Fenster **Access KVM console** auf <code className="action">Request access</code> und dann auf <code className="action">Open console</code>, um die Konsole in Ihrem Browser zu öffnen. Wenn der Block **Not supported** anzeigt, ist KVM auf diesem Server nicht verfügbar.

Wenn Sie das Java-Applet verwenden, klicken Sie im Fenster **Mit einem Java-Applet (KVM)** auf <code className="action">Java-Applet vorbereiten</code>.

Beim Java-Applet wird automatisch eine JNLP-Datei heruntergeladen: Öffnen Sie diese, um auf IPMI zuzugreifen. Melden Sie sich in beiden Fällen mit gültigen Anmeldeinformationen für den Server an.

Sobald Sie auf dem Server sind, öffnen Sie den Server-Manager. Wenn er nicht bereits standardmäßig geöffnet wird, wird er an das Start-Menü angeheftet.

<img className="thumbnail" alt="server manager" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/local_server.png" loading="lazy" />

Klicken Sie nach dem Öffnen des Server-Managers in der linken Seitenleiste auf **Lokaler Server**. Klicken Sie anschließend neben "NIC Teaming" auf die Schaltfläche **Deaktiviert**.

<img className="thumbnail" alt="Lokaler Server" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/server_manager.png" loading="lazy" />

Klicken Sie im NIC-Teaming-Popup im Dropdown-Menü **AUFGABEN** im Abschnitt "TEAMS" auf die Schaltfläche **Neues Team**.

<img className="thumbnail" alt="NIC-Teaming" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/nic_teaming.png" loading="lazy" />

Geben Sie Ihrem Team einen Namen und wählen Sie die NICs aus, die Sie mit OLA verwenden möchten. Klicken Sie auf den Dropdown-Pfeil neben "Weitere Eigenschaften" und ändern Sie den "Teaming-Modus" zu LACP. Klicken Sie auf **OK**, sobald Sie die Richtigkeit der Informationen bestätigt haben.

<img className="thumbnail" alt="Neues Team" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/new_team.png" loading="lazy" />

Es kann einige Minuten dauern, bis das NIC-Team online ist. Sobald es bereit ist, klicken Sie auf das Netzwerkverbindungssymbol in der rechten unteren Ecke.  Klicken Sie anschließend auf die Schaltfläche **Netzwerk- und Interneteinstellungen**. Dann klicken Sie auf **Ethernet** in der linken Seitenleiste des folgenden Popups.

<img className="thumbnail" alt="Netzwerkschaltfläche" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/network_button.png" loading="lazy" />

Klicken Sie auf die Schaltfläche **Adaptereigenschaften ändern**.

<img className="thumbnail" alt="Ethernet" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/ethernet.png" loading="lazy" />

Klicken Sie anschließend mit der rechten Maustaste auf Ihr NIC-Team und wählen Sie im Dropdown-Menü **Eigenschaften** aus.

<img className="thumbnail" alt="Eigenschaften" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/properties.png" loading="lazy" />

Doppelklicken Sie im folgenden Popup-Fenster auf die Schaltfläche **Internetprotokoll Version 4 (TCP/IPv4)**.

<img className="thumbnail" alt="ipv4" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/ipv4.png" loading="lazy" />

Klicken Sie auf "Diese IP-Adresse verwenden" und fügen Sie Ihre gewählte private IP und das Subnetz hinzu. Klicken Sie auf die Schaltfläche **OK**, sobald Sie die Richtigkeit Ihrer Einstellungen bestätigt haben.

<img className="thumbnail" alt="ipv42" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/ipv42.png" loading="lazy" />

Um zu testen, ob das NIC-Team funktioniert, senden Sie einen Ping an einen anderen Server im selben vRack. Wenn es funktioniert, sind Sie fertig. Wenn nicht, überprüfen Sie Ihre Konfigurationen oder versuchen Sie, den Server neu zu starten.
