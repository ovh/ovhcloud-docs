## Ziel

Wenn Sie Windows auf einem Server mit Hardware-RAID-Konfiguration installieren, muss die RAID-Partition manuell erstellt werden.

**Diese Anleitung erklärt die erforderlichen Schritte, um eine Windows-Partition auf einem Server mit Hardware-RAID zu erstellen.**

## Voraussetzungen

- Sie verfügen über einen [Dedicated Server](/links/bare-metal/bare-metal) mit installiertem Windows und einer Hardware-RAID-Karte (LSI MegaRaid).
- Ihr Server verfügt über mindestens zwei identische Festplatten.

## In der praktischen Anwendung

:::warning
Wenn Sie die Schritte dieser Anleitung befolgen, müssen Sie das bestehende RAID-Volume löschen und neu erstellen. Dadurch gehen alle vorhandenen Daten verloren. Erstellen Sie unbedingt vorher ein Backup Ihrer Daten. Diese Anleitung richtet sich an erfahrene Benutzer.
:::


### Bestehende RAID-Volumes auflisten
Zunächst müssen die bestehenden RAID-Volumes aufgelistet werden, damit sie anschließend gelöscht werden können. Verwenden Sie dazu folgenden Befehl: <code className="action">MegaCli -LDInfo -Lall -aAll</code>.

```sh
# root@rescue:~# MegaCli -LDInfo -Lall -aAll
 
Adapter 0 -- Virtual Drive Information:
Virtual Drive: 0 (Target Id: 0)

Name                 :
RAID Level           : Primary-5, Secondary-0, RAID Level Qualifier-3
Size                 : 3.637 TB
Sector Size          : 512
Is VD emulated       : No
Parity Size          : 1.818 TB
State                : Optimal
Strip Size           : 256 KB
Number Of Drives     : 3
Span Depth           : 1
Default Cache Policy : WriteBack, ReadAhead, Direct, No Write Cache if Bad BBU
Current Cache Policy : WriteBack, ReadAhead, Direct, No Write Cache if Bad BBU
Default Access Policy: Read/Write
Current Access Policy: Read/Write
Disk Cache Policy    : Disk's Default
Encryption Type      : None
Bad Blocks Exist     : No
PI type              : No PI
 
Is VD Cached: No
 
Exit Code: 0x00
```

Im obigen Ergebnis sehen Sie, dass sich derzeit nur ein RAID-Volume auf dem Server befindet und dass der Server das **Virtual Drive** `0` hat.

### RAID löschen
Nun können Sie das bestehende RAID auflösen und anschließend das neue RAID erstellen.

Verwenden Sie dazu den folgenden Befehl. Sie benötigen die im vorherigen Schritt ermittelte Nummer des **Virtual Drive**.

<code className="action">MegaCli -CfgLDDel -Lx -a0</code>

`x` ist die Nummer des **Virtual Drive**.

Beispiel:

```sh
# root@rescue:~# MegaCli -CfgLDDel -L0 -a0
 
Adapter 0: Deleted Virtual Drive-0(target id-0)
 
Exit Code: 0x00
```

:::info
Wenn Ihr Server bereits mehr als ein RAID hat, wiederholen Sie den Vorgang für jede Nummer eines **Virtual Drive**.
:::


### Festplatten-IDs ermitteln
Ermitteln Sie nun die **Enclosure ID** und die **SlotID** der Festplatten des Servers, um das neue RAID zu erstellen.

Verwenden Sie dazu folgenden Befehl: <code className="action">MegaCli -PdList -aALL | egrep -i "Adapter|Slot|Enclosure Device"</code>.

Beispiel:

```sh
# root@rescue:~# MegaCli -PdList -aALL | egrep -i "Adapter|Slot|Enclosure Device"
Adapter #0
Enclosure Device ID: 252
Slot Number: 0
Enclosure Device ID: 252
Slot Number: 1
Enclosure Device ID: 252
Slot Number: 2
```

Es sind drei Festplatten vorhanden. Die **Enclosure ID** und die **SlotIDs** lauten 252:0, 252:1 und 252:2.

### Neues RAID erstellen
Erstellen Sie zunächst das erste RAID, das für das Betriebssystem verwendet wird.

Verwenden Sie folgenden Befehl: <code className="action">MegaCli -CfgLdAdd -rX[EncID:SlotID,EncID:SlotID,...] -szYYYYY -a0</code>.

`X` ist das gewünschte RAID-Level (0, 1, 5 oder 6).

`EncID` ist die im vorherigen Schritt ermittelte Enclosure ID der Festplatte.

`SlotID` ist die im vorherigen Schritt ermittelte SlotID der Festplatte.

`YYYYY` ist die Größe der ersten virtuellen Festplatte in MB.

In diesem Beispiel wird ein RAID-5-Volume auf den drei Festplatten mit 200 GB für das Betriebssystem erstellt.

:::info
Es wird empfohlen, ein Volume mit etwas mehr Speicherplatz als der erforderlichen Mindestgröße zu erstellen. So steht dem System ausreichend Platz für Updates und Installationen zur Verfügung.
:::


```sh
# root@rescue:~# MegaCli -CfgLdAdd -r5[252:0,252:1,252:2] -sz204800 -a0
 
Adapter 0: Created VD 0
 
Adapter 0: Configured the Adapter!!
 
Exit Code: 0x00 
```

Das erste RAID ist nun erstellt. Jetzt muss nur noch der restliche verfügbare Speicherplatz zugewiesen werden.

Erstellen Sie dazu mit folgendem Befehl ein zweites RAID: <code className="action">MegaCli -CfgLdAdd -rX[EncID:SlotID,EncID:SlotID,...] -a0</code>.

`X` ist das gewünschte RAID-Level (0, 1, 5 oder 6).

`EncID` ist die im vorherigen Schritt ermittelte Enclosure ID der Festplatte.

`SlotID` ist die im vorherigen Schritt ermittelte SlotID der Festplatte.

Beispiel:

```sh
# root@rescue:~# MegaCli -CfgLdAdd -r5[252:0,252:1,252:2] -a0
 
Adapter 0: Created VD 1
 
Adapter 0: Configured the Adapter!!
 
Exit Code: 0x00 
```

Fertig. Jetzt muss das RAID nur noch überprüft werden.

### Windows über die OVHcloud Console installieren
Installieren Sie abschließend Windows auf Ihrem Server.

Aktivieren Sie dabei das Kontrollkästchen <code className="action">Partitionskonfiguration anpassen</code> und ändern Sie das aktuelle Partitionsschema so, dass nur die Festplatte **C** mit einer maximalen Größe von 200 GB angegeben ist.

Sobald das System installiert ist, loggen Sie sich in Ihr Windows-System ein, öffnen Sie das Tool <code className="action">Datenträgerverwaltung</code> und partitionieren Sie die zweite virtuelle Festplatte (entspricht dem zweiten RAID, das als "Nicht zugeordnet" angezeigt wird) im GPT-Format.
