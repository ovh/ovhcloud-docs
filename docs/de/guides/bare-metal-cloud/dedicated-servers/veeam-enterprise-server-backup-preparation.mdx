## Ziel

Für das Backup eines Bare Metal Servers mit Veeam Enterprise müssen mehrere Anwendungen und Dienste zusammenarbeiten. Der Ablauf kann außerdem je nach Ihrer Konfiguration und Ihren Präferenzen variieren.

**Diese Anleitung erklärt, wie Sie das Backup Ihres Bare Metal Servers mit Veeam Backup and Replication (Enterprise) vorbereiten.**

## Voraussetzungen

- Sie verfügen über einen [OVHcloud Bare Metal Server](/links/bare-metal/bare-metal).
- Sie verfügen über eine [Veeam Enterprise Backup-Lösung](/links/hosted-private-cloud/veeam-enterprise).
- Sie verfügen über [OVHcloud Object Storage](/links/public-cloud/object-storage) (optional).

[[cpnav:publiccloud-object-storage-console]]

## In der praktischen Anwendung

### Ihren Dedicated Server einrichten

Ihr OVHcloud Bare Metal Server muss installiert und konfiguriert sein.

Lesen Sie dazu unsere [Anleitungen zum Einstieg](/guides/bare-metal-cloud/dedicated-servers/getting-started-with-dedicated-server) für Dedicated Server.

Sie können Ihren Dedicated Server außerdem für die Verwendung des privaten Netzwerks konfigurieren, indem Sie den Schritten in [dieser Anleitung](/guides/bare-metal-cloud/dedicated-servers/vrack-configuring-on-dedicated-server) folgen.

### Ihren Veeam Enterprise Backup-Server einrichten

Laden Sie Ihren Veeam Enterprise Backup-Server herunter, installieren und lizenzieren Sie ihn mithilfe unserer Anleitung [Veeam Backup & Replication einrichten](/guides/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication).

Anschließend können Sie weiterlesen, um zu erfahren, wie Sie Object Storage als Repository einrichten, oder direkt zum Abschnitt [Weiterführende Informationen](#gofurther) wechseln.

### Ihren Object Storage einrichten

Sie können Object Storage im Bereich <code className="action">Public Cloud</code> der OVHcloud Console erstellen und konfigurieren, im Abschnitt <code className="action">Object Storage</code> Ihres Public Cloud Projekts.

Wenn Sie in Ihrem OVHcloud Account noch kein Public Cloud Projekt haben, lesen Sie unsere Anleitung [Erstellen Ihres ersten Public Cloud Projekts](/guides/public-cloud/cross-functional/create-a-public-cloud-project).

[Erstellen Sie einen Object Storage Container](/guides/storage-and-backup/object-storage/s3-getting-started-with-object-storage) mit einer der **Object Storage Lösungen von OVHcloud (Standard oder High Performance)**. Standard wird empfohlen, da für dieses Backup in der Regel kein High Performance Speicher erforderlich ist.

:::info
Wenn Sie einen Object Storage Container bei OVHcloud bestellen, wählen Sie ausschließlich **Standard Object Storage** oder **High Performance Object Storage**. Diese Container unterstützen das Amazon S3<sup>1</sup> Protokoll vollständig und sind für die Verwendung als Backup-Repositories ausgelegt.

:::


Erteilen Sie dem Object Storage Benutzer Rechte für den Container, indem Sie den folgenden Text in eine JSON-Datei kopieren.

```json
{
  "Statement":[
    {
      "Action":
         [
             "s3:GetObject",
             "s3:PutObject",
             "s3:DeleteObject",
             "s3:ListBucket",
             "s3:ListMultipartUploadParts",
             "s3:ListBucketMultipartUploads",
             "s3:AbortMultipartUpload",
             "s3:GetBucketLocation"
          ],
      "Effect":"Allow",
      "Resource":
          [
              "arn:aws:s3:::<container name>",
              "arn:aws:s3:::<container name>/*"
          ],
      "Sid":"RWContainer"
     }
  ]
}
```

Ersetzen Sie `container name` durch den tatsächlichen Namen Ihres Object Storage Containers.

Klicken Sie im Tab <code className="action">User</code> der Seite **Object Storage** in der Spalte **Aktionen** des Object Storage Benutzers auf den Button <code className="action">⋮</code> und wählen Sie <code className="action">Eine Policy importieren</code>.

Wählen Sie im Fenster **Eine Policy importieren** die soeben bearbeitete JSON-Datei aus und klicken Sie auf <code className="action">Importieren</code>. Die importierte Policy ersetzt die aktuelle Policy des Benutzers: Wenn dieser Benutzer bereits eine Policy hat, laden Sie diese zuerst über <code className="action">Die Policy herunterladen</code> (im selben Menü) herunter und fügen Sie dieses Statement zu ihrer `Statement`-Liste hinzu, bevor Sie sie importieren.

### Das Object Storage Repository in Veeam Enterprise konfigurieren

Wählen Sie in der Veeam-Anwendung <code className="action">Backup Infrastructure</code>, <code className="action">Backup Repositories</code> und <code className="action">Add Repository</code>.

<img className="thumbnail" alt="Veeam - Repository hinzufügen" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-02.png" loading="lazy" />

Wählen Sie <code className="action">Object storage</code> als Repository-Typ aus.

<img className="thumbnail" alt="Veeam - Object Storage" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-03.png" loading="lazy" />

Wählen Sie <code className="action">S3 Compatible</code> aus.

<img className="thumbnail" alt="Veeam - S3-kompatibel" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-04.png" loading="lazy" />

Geben Sie dem neuen Repository einen **Name** und klicken Sie auf <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - Name des Repositorys" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-05.png" loading="lazy" />

Geben Sie die Informationen **Service point** (Endpoint) und **Region** Ihres Object Storage Dienstes ein.

> Sie finden diese Informationen im Bereich <code className="action">Public Cloud</code> der OVHcloud Console.
> Klicken Sie auf <code className="action">Object Storage</code>, klicken Sie dann im Tab <code className="action">Container</code> auf den Namen Ihres Containers und öffnen Sie anschließend dessen Tab <code className="action">Übersicht</code>. Die **Region** wird im Abschnitt **Allgemeine Informationen** angezeigt (sowie in der Spalte **Region** der Containerliste), der **Endpoint** im Abschnitt **Verbindungsdetails**.

<img className="thumbnail" alt="Veeam - Service-Endpoint und Region" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-08.png" loading="lazy" />

Klicken Sie auf <code className="action">Add</code>, um Ihre Zugangsdaten einzugeben. Geben Sie Ihren **Access key** und Ihren **Secret key** ein und klicken Sie dann auf <code className="action">OK</code>.

> Diese Informationen finden Sie in der OVHcloud Console im Tab <code className="action">User</code> der Seite **Object Storage**. Der **Zugriffsschlüssel** (Access key) wird in der Spalte **Zugriffsschlüssel** der Benutzerliste angezeigt.
> Den **Geheimen Schlüssel** (Secret key) erhalten Sie, indem Sie in der Spalte **Aktionen** des Benutzers auf den Button <code className="action">⋮</code> klicken und <code className="action">Geheimen Schlüssel anzeigen</code> auswählen. Er wird im Fenster **S3-Zugangsdaten** angezeigt.

<img className="thumbnail" alt="Veeam - Schlüssel" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-10.png" loading="lazy" />

Klicken Sie auf <code className="action">Browse...</code>, um den **Bucket** auszuwählen.

<img className="thumbnail" alt="Veeam - Bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-11.png" loading="lazy" />

Wählen Sie den Bucket aus und klicken Sie auf <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - Bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-12.png" loading="lazy" />

Klicken Sie auf <code className="action">Browse...</code>, um den **Folder** (Ordner) auszuwählen.

<img className="thumbnail" alt="Veeam - Ordner" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-13.png" loading="lazy" />

Klicken Sie auf <code className="action">New Folder</code>, geben Sie einen Namen für den Ordner ein, wählen Sie ihn aus und klicken Sie dann auf <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - Ordner" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-14.png" loading="lazy" />

Klicken Sie im Schritt "Mount Server" auf <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - Mount Server" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-15.png" loading="lazy" />

Klicken Sie im Schritt "Review" auf <code className="action">Apply</code>.

<img className="thumbnail" alt="Veeam - Überprüfung" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-16.png" loading="lazy" />

Klicken Sie nach erfolgreichem Abschluss der Prozesse auf <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - Abschluss der Prozesse" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-17.png" loading="lazy" />

Überprüfen Sie die Seite "Summary" und klicken Sie auf <code className="action">Finish</code>.

<img className="thumbnail" alt="Veeam - Zusammenfassung" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-18.png" loading="lazy" />

Die Backup Repositories sollten nun in etwa so aussehen:

<img className="thumbnail" alt="Veeam - Repositories" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-19.png" loading="lazy" />

Sie können nun ein Backup mit Veeam Enterprise durchführen.
