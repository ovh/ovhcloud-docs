## Ziel

Wenn Sie Ihren dedizierten Server als DNS-Server konfigurieren, können Sie den sekundären OVHcloud DNS verwenden, um eine sekundäre Zone zu hosten. So bleibt das DNS Ihres Domainnamens auch dann verfügbar, wenn der primäre DNS-Server nicht mehr antwortet.

**Diese Anleitung erklärt, wie Sie Ihren Domainnamen in der OVHcloud Konsole hinzufügen, um einen sekundären DNS-Server von OVHcloud zu verwenden.**

## Voraussetzungen

- Sie verfügen über einen [Dedicated Server](/links/bare-metal/bare-metal) in Ihrem Kunden-Account.
- Sie haben adminstrativen Zugriff auf einen [Domainnamen](/links/web/domains).

:::warning
OVHcloud stellt Ihnen Dienstleistungen zur Verfügung, für deren Konfiguration und Verwaltung Sie die alleinige Verantwortung tragen. Es liegt somit bei Ihnen, sicherzustellen, dass diese ordnungsgemäß funktionieren.

Wir stellen Ihnen diese Anleitung zur Verfügung, um Ihnen bei der Bewältigung alltäglicher Verwaltungsaufgaben zu helfen. Dennoch empfehlen wir Ihnen, einen [spezialisierten Dienstleister](/links/partner) zu kontaktieren, wenn Sie Schwierigkeiten oder Zweifel hinsichtlich der Verwaltung, Nutzung oder Implementierung der Dienste auf einem Server haben.

:::

## In der praktischen Anwendung

### Einen Domainnamen hinzufügen <a name="addingdomain"></a>

Fügen Sie vor Beginn den TXT-Eintrag ownercheck zur DNS-Zone des Domainnamens hinzu, wie im Abschnitt [Bestätigung der Domainauthorisierung](#verifyingdomain) beschrieben. Schlägt das Hinzufügen fehl, zeigt das Fenster lediglich die Meldung **Failed to add secondary DNS domain. Please try again.** an.

Klicken Sie auf der Seite Ihres Dedicated Servers auf den Tab <code className="action">Connectivity</code>. Klicken Sie im Bereich **DNS** unter **Secondary DNS** auf <code className="action">Add a domain</code>.

Folgen Sie im Fenster **Add secondary DNS** den drei Schritten:

1. Geben Sie den hinzuzufügenden Domainnamen in das Feld **Domain name** ein und klicken Sie dann auf <code className="action">Weiter</code>.
2. Wählen Sie optional in der Dropdown-Liste **Master IP (optional)** die IP-Adresse des Servers aus, die als Master fungieren soll. Klicken Sie auf <code className="action">Weiter</code>.
3. Überprüfen Sie Ihre Konfiguration und klicken Sie dann auf <code className="action">Add</code>. Um vor der Bestätigung einen Wert zu ändern, klicken Sie auf <code className="action">Zurück</code>.

Nachdem Sie auf <code className="action">Add</code> geklickt haben, wird der Domainname zum sekundären DNS-Server von OVHcloud hinzugefügt.

Die hinzugefügten Domainnamen werden unter **Secondary DNS** aufgeführt. Die Spalte **DNS-Server** zeigt neben jedem Domainnamen den Namen des sekundären DNS-Servers an. Um einen Domainnamen zu löschen, klicken Sie auf das Papierkorbsymbol am Ende der entsprechenden Zeile.

:::info
Weitere für die Konfiguration Ihres eigenen DNS für Ihren Domainnamen erforderliche Aktionen sind üblicherweise:

- Konfiguration eines DNS-Dienstes (z.B. *BIND*)
- Konfiguration von GLUE-Einträgen
- Genehmigung von Zonentransfers

Konsultieren Sie die entsprechenden Anleitungen und sonstige externe Wissensressourcen, wenn Sie zusätzliche Informationen zu diesen administrativen Aufgaben benötigen.

:::


### Bestätigung der Domainauthorisierung <a name="verifyingdomain"></a>

Es ist erforderlich, Ihre Berechtigung zum Verwalten des Domainnamens zu bestätigen, bevor er zum sekundären DNS von OVHcloud hinzugefügt werden kann. Dies erfolgt über eine automatisierte DNS-Abfrage auf die Subdomain *ownercheck.ihrdomainname*. Hierzu wird eine individuelle Zeichenkette generiert.

Das Fenster **Add secondary DNS** in der OVHcloud Konsole zeigt diesen Wert nicht an. Um ihn abzurufen, verwenden Sie den folgenden API-Aufruf und geben Sie dabei den internen Namen des Servers (Beispiel: `ns3956771.ip-169-254-10.eu`) sowie im Parameter `domain` den Domainnamen an:

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/secondaryDnsNameDomainToken"} />

Die Antwort enthält den Eintragstyp (`TXT`), die Subdomain (`ownercheck`) und den zu verwendenden Wert.

- Wenn der Domainname von einem externen Registrar verwaltet wird oder externe DNS-Server verwendet, loggen Sie sich in die Verwaltungsoberfläche Ihres DNS-Anbieters ein und fügen Sie einen TXT-Eintrag mit der Subdomain "ownercheck" und diesem Wert hinzu.

- Wenn der Domainname von OVHcloud als Registrar verwaltet wird und OVHcloud DNS-Server verwendet, folgen Sie den Anweisungen in [dieser Anleitung](/guides/web-cloud/domains/dns-zone-edit), um den TXT-Eintrag in der OVHcloud Konsole hinzuzufügen.

Nachdem Sie den TXT-Eintrag erfolgreich zur DNS-Zone des Domainnamens hinzugefügt haben, wiederholen Sie die [oben erklärten Schritte](#addingdomain) und schließen Sie den Vorgang ab.
