## Ziel

Bei OVHcloud können Sie eine virtuelle MAC-Adresse mit einer IP-Adresse verbinden, um virtuelle Maschinen mit Bridge-Konfiguration auf Ihrem Server einzurichten.

**Diese Anleitung erklärt, wie Sie eine virtuelle MAC-Adresse erstellen und mit einer Additional IP verbinden.**

## Voraussetzungen

- Sie haben einen [Dedicated Server](/links/bare-metal/bare-metal) in Ihrem Kunden-Account. Ihr Server muss virtuelle MAC-Adressen unterstützen. Überprüfen Sie dies mithilfe [unserer Anleitung](/guides/bare-metal-cloud/dedicated-servers/network-support-virtual-mac).
- Sie verfügen über eine [Additional IP](/links/network/additional-ip).

:::warning
- Diese Funktion kann nur eingeschränkt oder nicht verfügbar sein, falls ein Dedicated Server der [**Eco** Produktlinie](/links/bare-metal/eco-about) eingesetzt wird. Weitere Informationen finden Sie auf der [Vergleichsseite](/links/bare-metal/eco-compare).

- Advance Server der dritten Generation (mit EPYC 4004 Series Prozessoren) unterstützen 32 verschiedene vMACs.

- Seit Mai 2025 ist diese Funktion für die Reihen Scale und High Grade verfügbar.

:::


:::info
Wenn Sie mit der Verwendung der OVHcloud API nicht vertraut sind, lesen Sie unsere Einführung zur [Verwendung der OVHcloud API](/guides/manage-and-operate/api/first-steps).

:::

## In der praktischen Anwendung

### MAC-Adresse zuweisen

:::warning
Wenn ein IP-Block im vRack umgezogen wurde, dann ist es nicht mehr möglich, einer IP eine virtuelle MAC-Adresse zuzuweisen.

:::


#### Über die OVHcloud Konsole

Klicken Sie über der Liste auf den Filter <code className="action">Zusätzliche IP</code>, um nur Ihre Additional IPs anzuzeigen.

Suchen Sie Ihre Additional IP (oder Ihren Block) in der Liste und klicken Sie darauf, um die zugehörige Seite zu öffnen. Klicken Sie dann auf den Tab <code className="action">Virtuelle MAC</code>. Bei einem Block wählen Sie in der Drop-down-Liste **Virtuelle MACs anzeigen für** die IP aus, deren virtuelle MACs angezeigt werden. Klicken Sie auf <code className="action">Virtuelle MAC hinzufügen</code>.

Wenn das Fenster **Virtuelle MAC hinzufügen** erscheint, wählen Sie die IP-Adresse in der Liste **IP-Adresse** aus (nur bei einem Block), wählen Sie einen Typ in der Drop-down-Liste **Typ** aus, geben Sie einen Namen in das Feld **Virtuelle Maschine** ein und klicken Sie anschließend auf <code className="action">Hinzufügen</code>.

:::info
**Typ**: Hierbei handelt es sich um den Typ der virtuellen MAC-Adresse (<code className="action">vmware</code> für eine MAC-Adresse für das System VMware ESXi und <code className="action">ovh</code> für alle anderen Virtualisierungssysteme).

**Virtuelle Maschine**: Das ist der gewünschte Name für die virtuelle MAC-Adresse, damit das IP/MAC-Paar später einfacher gefunden werden kann.

Wenn Ihr Server bereits über virtuelle MAC-Adressen verfügt, können Sie im Fenster zwischen <code className="action">Neue virtuelle MAC-Adresse erstellen</code> und <code className="action">Bestehende virtuelle MAC-Adresse verwenden</code> wählen. Bei der zweiten Option wählen Sie anstelle eines Typs die wiederzuverwendende MAC-Adresse aus.

:::

:::info
Denken Sie daran, die bei der Konfiguration Ihrer virtuellen Maschine erstellte MAC-Adresse zuzuweisen.

:::


#### Über die OVHcloud API

Verwenden Sie folgenden API Aufruf:

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/virtualMac"} />


### MAC-Adresse löschen

:::warning
Der Löschvorgang einer MAC-Adresse ist unwiderruflich. Die Adresse kann danach nicht wiederhergestellt werden.

:::


#### Über die OVHcloud Konsole

Verwenden Sie auf der Seite **IP-Adressen** die Drop-down-Liste **Nach Dienst filtern...** oder die Suchleiste, um die Additional IP (oder den IP-Block) zu finden. Klicken Sie darauf, um die zugehörige Seite zu öffnen, und klicken Sie auf den Tab <code className="action">Virtuelle MAC</code>. Bei einem Block wählen Sie die IP in der Drop-down-Liste **Virtuelle MACs anzeigen für** aus.

Jede virtuelle MAC wird unter ihrer MAC-Adresse aufgeführt. Klicken Sie unter der virtuellen MAC auf <code className="action">Löschen</code> und anschließend im Fenster **Virtuelle MAC-Adresse löschen** auf <code className="action">Löschen</code>, um den Vorgang zu bestätigen.

#### Über die OVHcloud API

Verwenden Sie folgenden API Aufruf:

<Api version="v1" section="/dedicated/server" method="DELETE" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


## FAQ

- **Was geschieht, wenn ich einen Block mit vMACs auf einen Advance Server der dritten Generation (mit EPYC 4004 Series) verlagere, der bereits über 32 vMACs verfügt?**

Der Block wird nicht verschoben.

Beispiel: Wenn Sie versuchen, einen Block mit 4 IPs zu verschieben, wobei verschiedene vMACs an einen Server mit bereits 30 vMACs angehängt sind, wird der Block nicht verschoben, da die Gesamtanzahl der vMACs die erlaubten 32 vMACs übersteigen würde.
