## Ziel

Tags sind kennzeichnende Meta-Informationen, die Ihren Ressourcen zugeordnet werden können, um sie effizienter zu organisieren und zu verwalten.

Jeder Tag besteht aus zwei Elementen:

- **Schlüssel**: Ein Attribut oder eine Kategorie.
- **Wert**: Die Informationen, die mit diesem Schlüssel verknüpft sind.

Beispielsweise können Sie Ihre Ressourcen nach Standort, Dienst oder nach Sicherheitsstufe kategorisieren. Die Verwendung von Tags erleichtert die Suche, das Organisieren von Ressourcen, das Verwalten zugehöriger Kosten und das Anwenden von Richtlinien mit der gewünschten Granularität.

**Diese Anleitung erklärt, wie Sie über die OVHcloud Konsole Tags für jeden Dedicated Server erstellen, zuweisen und löschen.**

## Voraussetzungen

- Ein [Dedicated Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account.

## In der praktischen Anwendung

### Tags einem Dedicated Server über die OVHcloud Konsole zuweisen

Wählen Sie Ihren Server aus der Liste aus. Im Tab **Übersicht** listet der Bereich **Tags** die bereits zugewiesenen Tags auf. Klicken Sie auf <code className="action">Meine Tags verwalten</code>.

Sie gelangen zum Bereich **Tags** des Tabs <code className="action">Server</code>. Sie können auch direkt den Tab <code className="action">Server</code> öffnen und zu dessen Bereich **Tags** wechseln.

Klicken Sie auf den Button <code className="action">Tag zuweisen</code>.

Klicken Sie im daraufhin geöffneten Panel **Tag zuweisen** auf das Feld **Schlüssel auswählen oder eingeben**, um die Dropdown-Liste zu öffnen, und wählen Sie dann den gewünschten Schlüssel aus.

Klicken Sie anschließend auf das Feld **Wert auswählen oder eingeben** und wählen Sie den entsprechenden Wert aus der Dropdown-Liste aus.

:::warning
**Wenn Sie einen Schlüssel oder Wert verwenden möchten, der noch nicht existiert**, können Sie ihn erstellen, indem Sie ihn in das Feld eingeben und dann auf <code className="action">Ihr-Wert hinzufügen</code> klicken, wobei "Ihr-Wert" dem von Ihnen eingegebenen Text entspricht.

:::

Um mehrere Tags gleichzeitig zuzuweisen, klicken Sie auf <code className="action">Weiteres Schlüssel/Wert-Paar hinzufügen</code> und füllen Sie das neue Paar aus.

Klicken Sie abschließend unten im Panel auf den Button <code className="action">Zuweisen</code>.

Es wird eine Bestätigungsmeldung angezeigt, und der Bereich **Tags** listet die auf den Server angewendeten Tags auf.

### Löschen eines Tags eines Dedicated Servers

So finden Sie die Liste der Ihrem Server zugewiesenen Tags:

1. Wählen Sie Ihren Server aus der Liste aus.
2. Gehen Sie zum Tab <code className="action">Server</code> und dann zu dessen Bereich **Tags**.

Setzen Sie einen Haken im Kontrollkästchen des Tags, den Sie von Ihrem Server entfernen möchten. Nur Tags, deren **Tag-Typ** **Benutzerdefinierter Tag** ist, können ausgewählt werden.
Klicken Sie dann oberhalb der Tabelle auf den Button <code className="action">Aktionen</code> und wählen Sie <code className="action">Zuweisung aufheben</code>.

Das Fenster **Tags-Zuweisung aufheben** wird angezeigt. Klicken Sie auf den Button <code className="action">Zuweisung aufheben</code>, um die Zuweisung des Tags aufzuheben.
