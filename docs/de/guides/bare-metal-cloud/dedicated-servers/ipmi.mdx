## Ziel

Die IPMI-Konsole (Intelligent Platform Management Interface) ermöglicht eine direkte Verbindung zu Ihrem Dedicated Server, ohne dass der Konnektivitätsstatus des Betriebssystems eine Rolle spielt. In dieser Anleitung erfahren Sie, wie Sie diese Konsole starten.

## Voraussetzungen

:::warning
Diese Funktion kann nur eingeschränkt oder nicht verfügbar sein, falls ein Dedicated Server der [**Eco** Produktlinie](/links/bare-metal/eco-about) eingesetzt wird.

Weitere Informationen finden Sie auf der [Vergleichsseite](/links/bare-metal/eco-compare).

:::

## In der praktischen Anwendung

Die Verbindung mit IPMI kann auf verschiedene Arten hergestellt werden¹. Auf dem Server konfigurierte SSH-Schlüssel werden nicht für diese Verbindungen verwendet. Zusammenfassung:

|Methode|Alternativer Name|Beschreibung|Kopieren-Einfügen|Virtuelles ISO-Laufwerk²|Anwendungsfälle|
|---|---|---|---|---|---|
|**KVM**³ über **Webbrowser**|**KVM HTML**|Emulation des Bildschirms mit **HTML Canvas**, so als würden Sie eine USB-Tastatur/Maus und einen VGA-Bildschirm physisch an Ihren Dedicated Server anschließen.|❌|⚠️⁴|- Diagnostizieren eines Problems mit dem Server-Boot.|
|**KVM**³ über **Java-Applet**|**KVM Java**|Wie KVM HTML, mit der Ausnahme, dass die Emulation über ein **Java-Applet** anstelle von HTML Canvas durchgeführt wird.|❌|✅|- Diagnose eines Bootproblems des Dedicated Servers. <br />- Manuelles Installieren eines bestimmten Betriebssystems (außerhalb des [Katalogs](/links/bare-metal/os))⁵.|
|**SoL**⁶ über **Webbrowser**|**SoL JavaScript**|Serielle Verbindung über Webbrowser emuliert, als ob Sie eine serielle Konsole physisch in RS-232 an Ihren Dedicated Server anschließen würden.|✅|❌|- Netzwerkproblem diagnostizieren: Logs abrufen und Konfigurationsdateien bearbeiten.|
|**SoL**⁶ über **SSH**|**SoL SSH**|Wie SoL JavaScript, mit der Ausnahme, dass die Emulation über ein SSH-Gateway erfolgt. Sie verbinden sich über Ihren bevorzugten SSH-Client mit einem Server, der die Befehle dann seriell an den Dedicated Server weiterleitet.|✅|❌|- Wie bei SoL JavaScript, allerdings ohne grafische Oberfläche.|

¹ Abhängig von der Hardware-Kompatibilität Ihres Dedicated Servers (einige Methoden werden nicht in der OVHcloud Konsole angezeigt).<br />
² Funktion zum Mounten eines lokal auf Ihrem Rechner gespeicherten ISO-Images auf einem dedizierten Server, um ein Betriebssystem über IPMI installieren zu können.<br />
³ KVM = Keyboard Video and Mouse<br />
⁴ Abhängig von der Hardware-Kompatibilität Ihres Dedicated Servers. Die OVHcloud Konsole bietet KVM Java nur bei Servern ohne KVM-Zugriff über den Browser an.<br />
⁵ Wenn das Betriebssystem, das Sie installieren möchten, nicht im [Katalog der für OVHcloud Dedicated Server verfügbaren Betriebssysteme](/links/bare-metal/os) ist, können Sie auch ein personalisiertes Image verwenden: siehe [Vergleich von Bring Your Own Image (BYOI) und Bring Your Own Linux (BYOLinux)](/guides/bare-metal-cloud/dedicated-servers/bring-your-own-image-versus-bring-your-own-linux) für weitere Details.<br />
⁶ SoL = Serial over LAN

Um eine dieser Methoden zu aktivieren, klicken Sie auf den Tab <code className="action">Server</code> Ihres Servers. Die Methoden sind im Bereich **Server connection** zusammengefasst.

### KVM über Java-Applet öffnen <a name="applet-java"></a>

:::info
Wir empfehlen die Installation der neuesten Java-Version.

:::


Damit das Java Applet funktionieren kann, muss Java auf Ihrem Computer installiert sein. Ist das nicht der Fall, gehen Sie auf die [offizielle Seite](https://www.java.com/en/download/).

Klicken Sie im Block **KVM over IP** des Bereichs **Server connection** der OVHcloud Konsole auf <code className="action">Mit einem Java-Applet (KVM)</code>. Diese Option wird nur bei Servern angezeigt, deren IPMI keinen KVM-Zugriff über den Browser (HTML5) bietet.

Klicken Sie im Fenster **Mit einem Java-Applet (KVM)** auf <code className="action">Java-Applet vorbereiten</code>.

Die Applet-Datei (`.jnlp`) wird automatisch heruntergeladen, sobald sie bereit ist. Führen Sie sie aus:

<img className="thumbnail" alt="Java KVM starten" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-02.png" loading="lazy" />

Sie gelangen dann zur Login-Seite. Geben Sie Ihre `Root`-Login-Daten ein, wie bei einer Verbindung über ein Terminal oder einen GUI-Client.

<img className="thumbnail" alt="Java KVM-Vorschau" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-03.png" loading="lazy" />

Sie können nun Ihren Server verwalten.

### KVM über Webbrowser öffnen <a name="kvm-browser"></a>

Klicken Sie im Block **KVM over IP** des Bereichs **Server connection** der OVHcloud Konsole auf <code className="action">Access console (KVM)</code>.

Klicken Sie im Fenster **Access KVM console** auf <code className="action">Request access</code>. Die Aktivierung dauert einige Sekunden.

Klicken Sie auf <code className="action">Open console</code>, um die Konsole in einem neuen Tab Ihres Browsers zu öffnen.

### SoL via SSH öffnen <a name="sol-ssh"></a>

Weitere Informationen zum Erstellen von SSH-Schlüsselpaaren finden Sie auf [dieser Seite](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys).

Klicken Sie im Block **Serial over LAN** des Bereichs **Server connection** der OVHcloud Konsole auf <code className="action">Connect via SSH key (SoL)</code>.

Wählen Sie im Fenster **Serial over LAN — SSH key session** entweder einen der in Ihrem Account registrierten Schlüssel aus der Drop-down-Liste **Select an existing SSH key** aus, oder fügen Sie den öffentlichen SSH-Schlüssel, mit dem Sie sich verbinden möchten, in das Feld **Public key** ein. Klicken Sie anschließend auf <code className="action">Start session</code>.

Um vorab einen Schlüssel in Ihrem Account zu registrieren, verwenden Sie <code className="action">Add SSH key</code> im Block **SSH keys** desselben Bereichs.

Wenn die Sitzung bereit ist, kopieren Sie den angezeigten SSH-Befehl in die Zwischenablage: Damit verbinden Sie sich über SSH per Serial over LAN mit Ihrem Dedicated Server.

Weitere Informationen zur Verwendung eines SSH-Schlüssels für die SSH-Verbindung finden Sie auf [dieser Seite](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys).

### SoL über Webbrowser öffnen <a name="sol-browser"></a>

Klicken Sie im Block **Serial over LAN** des Bereichs **Server connection** der OVHcloud Konsole auf <code className="action">Connect via browser (SoL)</code>.

Klicken Sie im Fenster **Access Serial over LAN console** auf <code className="action">Request access</code>. Die Aktivierung dauert einige Sekunden.

:::info
Die Konsole öffnet sich nicht automatisch: Sobald der Zugang bereit ist, klicken Sie auf <code className="action">Open console</code>, um sie in einem neuen Tab Ihres Browsers zu öffnen.

:::

### IPMI testen und neu starten <a name="ipmi-test-reboot"></a>

Es kann vorkommen, dass IPMI nicht mehr reagiert. Wenn Sie nicht darauf zugreifen können, können Sie es zunächst testen: Klicken Sie im Block **IPMI** des Bereichs **Server connection** der OVHcloud Konsole auf <code className="action">Test IPMI</code> und anschließend im Fenster **Test IPMI** auf <code className="action">Run test</code>. Die HTTP-, Passwort- und Ping-Tests werden dann nacheinander ausgeführt.

Wenn alle Tests erfolgreich sind, liegt wahrscheinlich ein lokales technisches Problem vor (Internetverbindung, lokaler Rechner). Wenn IPMI tatsächlich Störungen aufweist, können Sie es neu starten: Klicken Sie auf <code className="action">Restart IPMI</code> und bestätigen Sie anschließend mit <code className="action">Restart IPMI</code> im Fenster **Restart IPMI interface**.

Der Neustart von IPMI dauert einige Minuten.

:::info
Dieser Vorgang beeinträchtigt nicht den Betrieb des Servers.

:::


### Installation eines Betriebssystems mit IPMIv1

:::warning
OVHcloud garantiert nicht die Funktionalität von über IPMI installierten Betriebssystemen. Diese Methode sollte nur von einem erfahrenen Server-Administrator erwogen werden.

64-Bit-Versionen von Java können das Öffnen der Menüs `Redirect ISO`/`Redirect CDROM` verhindern und JViewer zum Absturz bringen.

:::


Um zu beginnen, öffnen Sie [IPMI über Java-Applet](#applet-java) in der OVHcloud Konsole (diese Option wird nur bei Servern angeboten, deren IPMI keinen KVM-Zugriff über den Browser bietet). Klicken Sie anschließend im Menü auf <code className="action">Device</code> und wählen Sie im Drop-down-Menü <code className="action">Redirect ISO</code> aus.

<img className="thumbnail" alt="Redirect_ISO" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/RedirectISO.jpg" loading="lazy" />

Wählen Sie dann die ISO im Dateisystem Ihres lokalen Computers aus. Wenn Sie die ISO-Datei ausgewählt haben, klicken Sie auf <code className="action">Ctrl Alt Del</code> in der oberen rechten Ecke des Bildschirms, um den Server neu zu starten. Tippen Sie auf die Taste `F`, um auf die Startoptionen zuzugreifen.

:::info
Vielleicht müssen Sie die Software-Tastatur verwenden, um die Einträge in IPMI zu speichern. Um darauf zuzugreifen, klicken Sie oben im Fenster auf die <code className="action">Keyboard</code>-Option. Wählen Sie anschließend im Drop-down-Menü `Soft Keyboard` aus und klicken Sie auf <code className="action">Show</code>.

:::


Wählen Sie `UEFI Virtual CDROM 1.00` im Startmenü (Boot) aus, um den Server von der zuvor verbundenen ISO zu starten.

<img className="thumbnail" alt="UEFI_Virt" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/UEFIVirt.jpg" loading="lazy" />

Folgen Sie den notwendigen Schritten für die Installation des Betriebssystems. Vergessen Sie nicht, die ISO aus der Option "Redirect ISO" zu löschen.

### Installation eines Betriebssystems mit IPMIv2

:::warning
OVHcloud garantiert nicht die Funktionalität von über IPMI installierten Betriebssystemen. Diese Methode sollte nur von einem erfahrenen Server-Administrator erwogen werden.

:::


Um zu beginnen, öffnen Sie [IPMI mit einem Java-Applet](#applet-java) in der OVHcloud Konsole (diese Option wird nur bei Servern angeboten, deren IPMI keinen KVM-Zugriff über den Browser bietet). Klicken Sie dann auf <code className="action">Virtual Media</code> und auf <code className="action">Virtual Storage</code>.

<img className="thumbnail" alt="Virtual Storage" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/virtual_storage.png" loading="lazy" />

Wählen Sie im angezeigten Fenster `ISO File` aus der Drop-down-Liste "Logical Drive Type". Klicken Sie anschließend auf <code className="action">Open Image</code> und navigieren Sie zu Ihrer ISO-Datei. Klicken Sie abschließend auf <code className="action">Plug-in</code> und <code className="action">OK</code>.

<img className="thumbnail" alt="ISO_file" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/iso_file.png" loading="lazy" />

Um von Ihrer ISO-Datei aus zu starten müssen Sie auf das BIOS zugreifen und die Startoptionen ändern. Klicken Sie hierzu auf <code className="action">Power Control</code> und dann auf <code className="action">Set Power Reset</code>.

<img className="thumbnail" alt="Power_Reserver" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/power_reset.png" loading="lazy" />

:::info
Möglicherweise müssen Sie die Software-Tastatur verwenden, um die Einträge in IPMI zu speichern. Um darauf zuzugreifen, klicken Sie oben im Fenster auf die Option <code className="action">Virtual Media</code>. Wählen Sie dann <code className="action">Virtual Keyboard</code> im Drop-down-Menü aus.

:::


Klicken Sie auf die `ENTF` Taste während des Startvorgangs, um zum BIOS-Interface zu gelangen. Sie können auch die Taste `F11` drücken und auf das BIOS zugreifen, indem Sie die Option <code className="action">Enter Setup</code> auswählen.

<img className="thumbnail" alt="Startmenü" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/boot_menu.png" loading="lazy" />

Gehen Sie im BIOS zum Tab <code className="action">Boot</code> und ändern Sie die `UEFI Boot Order #1` zu `UEFI USB CD/DVD:UEFI: CDROM virtual ATEN YSOJ`.

<img className="thumbnail" alt="Bios" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/bios.png" loading="lazy" />

Klicken Sie auf die Taste `F4`, um die Änderungen zu speichern und den Server neu zu starten.

:::warning
OVHcloud garantiert nicht die Funktionalität von über IPMI installierten Betriebssystemen. Diese Methode sollte nur von einem erfahrenen Server-Administrator erwogen werden.

Öffnen Sie in der OVHcloud Konsole die [KVM-Konsole über den Webbrowser](#kvm-browser).

Hier haben Sie Zugriff auf die gleichen Informationen und Funktionen wie in den auf Java basierenden IPMI-Modulen.

:::info
Stellen Sie sicher, dass Sie die nächsten Schritte zügig ausführen. Der Vorgang könnte abgebrochen werden, wenn zwischen den Aktionen längere Pausen bestehen.

Klicken Sie auf den Button <code className="action">Browse File</code> und wählen Sie Ihre Image-Datei aus.

<img className="thumbnail" alt="KVM installieren" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install01.png" loading="lazy" />

Klicken Sie auf <code className="action">Start Media</code>. Dadurch wird die ISO-Datei für den Installationsprozess vorbereitet.

<img className="thumbnail" alt="KVM installieren" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install02.png" loading="lazy" />

Die nun angezeigte Dateigröße ist nicht die echte Größe. Das ist normal, denn die Datei wird in diesem Schritt nicht vollständig übertragen.

<img className="thumbnail" alt="KVM installieren" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install03.png" loading="lazy" />

Warten Sie, bis die Anzeige zur Start-Auswahl erscheint, und drücken Sie die entsprechende Taste, um in das Boot-Menü zu gelangen (`F11` in diesem Beispiel).

Wählen Sie im Boot-Menü das optische Laufwerk (`UEFI: AMI Virtual CDROM0` in diesem Beispiel) und drücken Sie `Enter`.

### Neustarten eines Servers ins BIOS-Menü

Möglicherweise möchten Sie beim Konfigurieren oder Troubleshooting Ihres Servers auf das BIOS zugreifen. Dies lässt sich am einfachsten mit dem Tool `ipmiutil` erreichen. (Weiterführende Informationen finden Sie auf der [Projektseite](https://ipmiutil.sourceforge.net/).)

Wenn sich der Server im [Rescue-Modus](/guides/bare-metal-cloud/dedicated-servers/rescue-mode) befindet und Sie eingeloggt sind, installieren Sie es mit den folgenden Befehlen:

```bash
apt install ipmiutil
```

Starten Sie dann den Server mit diesem Befehl neu:

```bash
ipmiutil reset -b
```

Anschließend rufen Sie die [IPMI-Konsole](#procedure) in der OVHcloud Konsole auf. Es sollte dort das BIOS-Menü des Servers angezeigt werden.

<img className="thumbnail" alt="KVM BIOS" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_bios.png" loading="lazy" />
