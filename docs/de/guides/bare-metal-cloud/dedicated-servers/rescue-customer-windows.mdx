## Ziel

Der Rescue-Modus ist ein von OVHcloud zur Verfügung gestelltes Tool für Ihren dedizierten Server, das dazu dient, den Server mithilfe eines temporären Betriebssystems zu booten. Damit haben Sie Zugriff auf den Server und können Probleme diagnostizieren und beheben.  

Die allgemeine Funktionsweise des Rescue-Modus wird in unserer Anleitung beschrieben:

[Rescue-Modus aktivieren und verwenden](/guides/bare-metal-cloud/dedicated-servers/rescue-mode)

Das **Windows Customer Rescue System** ist nur für Dedicated Server mit installiertem **Windows Server** Betriebssystem verfügbar. Es gelten folgende Bedingungen:

- Das Rescue-System für Windows (`rescue-customer-windows`) läuft in einer virtuellen Maschine (VM), die vom Customer Rescue System gestartet wurde (`rescue-customer`, basierend auf Debian GNU/Linux).
- Die Disks des Servers sind mit der VM per *Passthrough* verbunden, sodass Sie darauf zugreifen können.
- Auf andere Serverkomponenten (CPU, RAM, Netzwerkkarte, RAID-Karte) kann nicht zugegriffen werden.
- Das Netzwerk ist mit *Passthrough* angebunden, ohne direkten Zugriff auf den Netzwerkadapter. Die VM trägt die IP-Adresse und die MAC-Adresse des  *Bare Metal* Servers.

:::warning
Falls Sie nicht schon über aktuelle Backups verfügen, sollte der erste Schritt im Troubleshooting, auch im Rescue-Modus, immer darin bestehen, ein Backup Ihrer Daten zu erstellen.

Wenn Sie Dienste auf Ihrem Dedicated Server im laufenden Betrieb haben, wird der Rescue-Modus diese Dienste unterbrechen, da er in das Hilfsbetriebssystem neu gestartet wird.

:::


**Diese Anleitung erklärt, wie Sie einen Server in das Rescue-System für Windows starten.**

## Voraussetzungen

- Sie haben einen [Dedicated Server](/links/bare-metal/bare-metal) mit Windows Server installiert.
- Der Server verfügt über mindestens 16 GB RAM.

## In der praktischen Anwendung

### Aktivierung des Rescue-Modus für Windows

Klicken Sie auf den Namen Ihres Servers, um dessen Seite zu öffnen. Die Seite öffnet sich im Tab **Übersicht**, der den Abschnitt **Allgemeine Informationen** enthält.

<a name="netboot"></a>

Klicken Sie im Abschnitt **Allgemeine Informationen** in der Zeile **Boot Mode** auf den Link <code className="action">Rescue-Modus</code>. Der Tab **Server** öffnet sich bei der Einstellung **Boot mode** im Abschnitt **System**. Sie können auch auf den Tab <code className="action">Server</code> klicken und direkt zur Einstellung **Boot mode** gehen.

Wählen Sie die Option <code className="action">Rescue mode</code> aus.

Wählen Sie in der Dropdown-Liste **Rescue kernel** den Eintrag <code className="action">Windows customer rescue system v12 (Windows2022-based)</code> aus.

Die Benachrichtigung zur Aktivierung des Rescue-Modus und die zugehörigen Login-Daten werden an die Kontakt-E-Mail-Adresse Ihres OVHcloud Kunden-Accounts gesendet. Um eine abweichende E-Mail-Adresse zu verwenden, geben Sie diese in das Feld **Rescue email** ein. Wenn im Feld **Rescue email** bereits eine Adresse angezeigt wird, wird die E-Mail an diese Adresse gesendet.

Klicken Sie auf <code className="action">Apply</code>. Überprüfen Sie im Fenster **Apply boot mode change** den aktuellen und den neuen Startmodus und klicken Sie dann auf <code className="action">Apply</code>. Der neue Startmodus wird beim nächsten Neustart wirksam.

Im letzten Schritt muss der Server neu gestartet werden. Klicken Sie im Fenster **Reboot to apply** auf <code className="action">Reboot now</code>. Wenn Sie den Server später neu starten, klicken Sie in der Zeile **Boot Mode** des Abschnitts **Allgemeine Informationen** (Tab **Übersicht**) auf den Link <code className="action">Neu starten</code> und anschließend im Bestätigungsfenster auf <code className="action">Reboot</code>.

Der *hard reboot* benötigt einige Minuten zur Durchführung. Sie können den aktuellen Status im Tab <code className="action">Aktivitäten</code> überprüfen.

:::info
Achten Sie darauf, nach Abschluss Ihrer Aktionen im Rescue-Modus die Einstellung **Boot mode** auf <code className="action">Boot from hard disk</code> zurückzusetzen, bevor Sie den Server neu starten.

:::


### Zugriff auf Ihren Server im Rescue-Modus

Sobald Sie die E-Mail zur Aktivierung des Rescue-Modus erhalten haben, können Sie sich über das Windows Rescue-System einloggen und auf Ihren Server zugreifen.  
Diese E-Mail ist auch in der OVHcloud Konsole verfügbar, sobald sie verschickt wurde. Öffnen Sie oben rechts das Account-Menü und klicken Sie unter **Schnellzugriff** auf <code className="action">Meine Kommunikation</code>. Die E-Mail wird im Tab **Nachrichten** der Seite **Communications** aufgeführt.

Zum Aufbau einer Remote-Verbindung mit dem Windows Rescue-System benötigen Sie die folgenden Anmeldedaten:

- IP-Adresse des Servers
- Benutzername für den temporären Administrator-Account (`Administrator`)
- Passwort für den temporären Administrator-Account

Sie haben die folgenden Verbindungsmethoden zur Auswahl, um über das Windows Rescue-System auf Ihren Server zuzugreifen:

- Remote Desktop Protocol (RDP)
- KVM over IP (wenn Ihr Server dies erlaubt)
- OpenSSH (offizielle Komponente von Windows Server)

#### SSH

<details>

<summary>Diesen Abschnitt erweitern</summary>


Öffnen Sie die Befehlszeilenanwendung auf dem lokalen Gerät, und geben Sie den folgenden Befehl ein:

```bash
ssh Administrator@SERVER_IP
```

Beispiel:

```bash
ssh Administrator@203.0.113.100
```

Geben Sie das temporäre Passwort für den Rescue-Modus ein, wenn Sie dazu aufgefordert werden. Beispiel:

```console
Administrator@ns9356771.ip-203-0-113.eu's password:
administrator@WINRESCUEOVH C:\Users\Administrator>
```

Weitere Informationen zu SSH-Verbindungen finden Sie in unserer [SSH-Einführung](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction).  
Sie können auch ein beliebiges Tool für SSH-Verbindungen verwenden, z.B. [PuTTY](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows).

</details>

### Rescue-Modus verlassen

Gehen Sie in der OVHcloud Konsole zur Einstellung [Boot mode](#netboot) im Tab **Server** Ihres Servers, wählen Sie <code className="action">Boot from hard disk</code> aus und klicken Sie auf <code className="action">Apply</code>. Klicken Sie im Fenster **Apply boot mode change** erneut auf <code className="action">Apply</code>.

Starten Sie den Server anschließend neu: Klicken Sie im Fenster **Reboot to apply** auf <code className="action">Reboot now</code> oder verwenden Sie den Link <code className="action">Neu starten</code> in der Zeile **Boot Mode** des Abschnitts **Allgemeine Informationen**.
