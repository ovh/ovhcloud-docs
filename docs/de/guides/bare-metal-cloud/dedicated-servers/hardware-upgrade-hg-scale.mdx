## Ziel

Dedicated Server der Reihen High Grade und SCALE bieten Ihnen eine Skalierungsoption, mit der Sie Speicherplatz und RAM erhöhen können.

**Diese Anleitung erklärt die Vorgehensweise zum Hardware-Upgrade für OVHcloud Dedicated Server der Reihen High Grade und SCALE.**

:::info
Die in dieser Anleitung beschriebenen Schritte gelten nur für unsere aktuellen Produktreihen Advance, High Grade und SCALE. Bei älteren Diensten ist die Anfrage über ein Ticket an den Kundensupport zu richten.

:::


## Voraussetzungen

- Sie haben einen [Advance Dedicated Server](/links/bare-metal/advance) (mit Ausnahme der vor Mai 2025 ausgelieferten Modelle), [High Grade Dedicated Server](/links/bare-metal/hg) oder [SCALE Dedicated Server](/links/bare-metal/scale).

## In der praktischen Anwendung

### RAM hinzufügen

Klicken Sie auf der Seite Ihres Servers auf den Tab <code className="action">Server</code>. Klicken Sie im Bereich **Hardware** in der Zeile **Arbeitsspeicher** auf <code className="action">RAM hinzufügen</code>.

Wählen Sie im Fenster **RAM skalieren** unter **Bitte wählen Sie eine RAM-Option** die gewünschte RAM-Option aus und klicken Sie auf <code className="action">Bestellen</code>. Die Bestellung wird in einem neuen Browser-Tab geöffnet, in dem Sie die Zahlung abschließen können.

Sobald die Bestellung bezahlt wurde, erhalten Sie eine E-Mail mit einem Link, um den Eingriff für das RAM-Upgrade zu planen.

Folgen Sie dem Link in der E-Mail oder kehren Sie zum Tab <code className="action">Server</code> Ihres Servers zurück. Klicken Sie im Bereich **Hardware** auf <code className="action">Den Vorgang planen</code>.

Wählen Sie im Fenster **Der Vorgang im Detail** Datum und Uhrzeit aus den verfügbaren Zeitfenstern aus. Setzen Sie unter **Haben Sie bereits ein Backup Ihrer Daten durchgeführt?** einen Haken bei <code className="action">Ja. Ich bestätige, dass ich ein vollständiges Backup meiner Daten durchgeführt habe. Andernfalls bin ich mir sicher, dass ich meine Daten nicht speichern möchte.</code> Bitte beachten Sie, dass ein Eingriff durch die Techniker in unseren Rechenzentren eine gewisse Vorbereitungszeit erfordert. Das erste Verfügbarkeitsdatum wird daher nach einem Zeitraum von mindestens 10 Tagen festgelegt.

Klicken Sie dann auf <code className="action">Bestätigen</code>.

Sie erhalten dann eine E-Mail, in der Datum und Uhrzeit des Eingriffs bestätigt werden.

### Storage erhöhen

Klicken Sie auf der Seite Ihres Servers auf den Tab <code className="action">Server</code>. Klicken Sie im Bereich **Hardware** unter der letzten Festplattenzeile (in der Regel **Datenfestplatten**) auf <code className="action">Storage erhöhen</code>.

Wählen Sie im Fenster **Storage skalieren** unter **Bitte wählen Sie eine Storage-Option** die gewünschte Storage-Option aus und klicken Sie auf <code className="action">Bestellen</code>. Die Bestellung wird in einem neuen Browser-Tab geöffnet, in dem Sie die Zahlung abschließen können.

Sobald die Bestellung bezahlt wurde, erhalten Sie eine E-Mail mit einem Link, um den Eingriff für das Hardware-Upgrade zu planen.

Folgen Sie dem Link in der E-Mail oder kehren Sie zum Tab <code className="action">Server</code> Ihres Servers zurück. Klicken Sie im Bereich **Hardware** auf <code className="action">Den Vorgang planen</code>.

Wählen Sie im Fenster **Der Vorgang im Detail** Datum und Uhrzeit aus den verfügbaren Zeitfenstern aus. Setzen Sie unter **Haben Sie bereits ein Backup Ihrer Daten durchgeführt?** einen Haken bei <code className="action">Ja. Ich bestätige, dass ich ein vollständiges Backup meiner Daten durchgeführt habe. Andernfalls bin ich mir sicher, dass ich meine Daten nicht speichern möchte.</code> Bitte beachten Sie, dass ein Eingriff durch die Techniker in unseren Rechenzentren eine gewisse Vorbereitungszeit erfordert. Das erste Verfügbarkeitsdatum wird daher nach einem Zeitraum von mindestens 10 Tagen festgelegt.

Klicken Sie dann auf <code className="action">Bestätigen</code>.

Sie erhalten dann eine E-Mail, in der Datum und Uhrzeit des Eingriffs bestätigt werden.

Möchten Sie gleichzeitig Storage und RAM erweitern? Dann bestellen und bezahlen Sie einfach die beiden Upgrades innerhalb eines Zeitraums von einer Stunde.
