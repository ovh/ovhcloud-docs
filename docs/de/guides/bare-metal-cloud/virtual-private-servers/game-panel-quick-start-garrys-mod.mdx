## Ziel

Mit dem Game Panel können Sie einen Garry's Mod-Server mit automatisierter Installation und Portkonfiguration bereitstellen.

**In dieser Anleitung erfahren Sie, wie Sie über das Game Panel einen Garry's Mod-Server bereitstellen und sich mit ihm verbinden.**

## Voraussetzungen

- Sie verfügen über einen [VPS](https://www.ovhcloud.com/de/vps/) in Ihrem OVHcloud Konto, für den die Game-Panel-Funktion aktiviert ist.
- Sie haben Zugriff auf das Game Panel. Weitere Informationen finden Sie unter [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Melden Sie sich bei Ihrem Game Panel an. Gehen Sie im Menü auf der linken Seite zum Bereich <code className="action">Game Servers</code>.

<img className="thumbnail" alt="Bereich Game Servers mit der Schaltfläche Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/game-servers-list.png" loading="lazy" />

### Schritt 2 – Einen Garry's Mod-Server erstellen

Klicken Sie auf <code className="action">Add Game Server</code> und wählen Sie **Garrys Mod** aus der Liste aus.

<img className="thumbnail" alt="Auswahl von Garry's Mod aus der Liste der Spiele" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/select-garrys-mod.png" loading="lazy" />

Konfigurieren Sie die Installation:

- <code className="action">Server Name</code>: Geben Sie Ihrem Server einen Namen (z. B. `Garrys Mod Server`).
- <code className="action">Network Ports</code>: Behalten Sie die Standardports bei oder fügen Sie bei Bedarf weitere im erweiterten Bereich hinzu. Garry's Mod verwendet üblicherweise Ports um `27015`.

### Schritt 3 – Die Installation starten

Klicken Sie auf <code className="action">Select</code>. Die Bereitstellung startet automatisch. Warten Sie einige Minuten, während das Image heruntergeladen und der Server installiert wird.

Klicken Sie anschließend auf <code className="action">Launch</code>, um den Server zu starten.

### Schritt 4 – Überprüfen, ob der Server läuft

Prüfen Sie, ob der Serverstatus **Running** anzeigt und die CPU-/RAM-Aktivität sichtbar ist.

<img className="thumbnail" alt="Garry's Mod-Server mit dem Status Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-running.png" loading="lazy" />

Verfügbare Aktionen:

- <code className="action">Log/Console</code>: Öffnen Sie die Konsole, um den Start zu überwachen und bei Problemen die Protokolle zu prüfen.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: Greifen Sie auf die Spieleinstellungen zu (Startkarte, Tickrate, Spielmodus, Spielerlimit, RCON-Passwort, Workshop-Sammlung, GSLT).

<img className="thumbnail" alt="Garry's Mod-Einstellungen unter Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-game-config.png" loading="lazy" />

### Schritt 5 – Mit dem Server verbinden

In der Spalte <code className="action">Connection</code> finden Sie die IP-Adresse und den Port (z. B. `xxx.xxx.xxx.xxx:27015`).

In Garry's Mod:

1. Öffnen Sie die Konsole (`~`).
2. Geben Sie Folgendes ein:

    ```console
    connect IP:PORT
    ```

:::info
Für weitere Schritte können Sie Mods oder Workshop-Sammlungen hinzufügen, die Tickrate und Leistungseinstellungen anpassen oder den Zugriff mit einem Passwort oder einer Whitelist beschränken.
:::
