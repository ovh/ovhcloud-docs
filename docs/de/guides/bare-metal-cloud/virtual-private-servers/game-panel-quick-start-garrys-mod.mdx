## Ziel

Mit dem Game Panel können Sie einen Garry's Mod-Server mit automatisierter Installation und Portkonfiguration bereitstellen.

**In dieser Anleitung erfahren Sie, wie Sie über das Game Panel einen Garry's Mod-Server bereitstellen und sich mit ihm verbinden.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben Zugriff auf das Game Panel. Weitere Informationen finden Sie unter [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Melden Sie sich bei Ihrem Game Panel an. Gehen Sie im Menü auf der linken Seite zum Bereich `Game Servers` und klicken Sie auf <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Bereich Game Servers mit der Schaltfläche Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/game-servers-list.png" loading="lazy" />

### Schritt 2 – Einen Garry's Mod-Server erstellen

Wählen Sie **Garry's Mod** aus der Spieleliste aus. Ein Konfigurationsfenster wird geöffnet.

<img className="thumbnail" alt="Auswahl von Garry's Mod aus der Liste der Spiele" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/select-garrys-mod.png" loading="lazy" />

### Schritt 3 – Den Garry's Mod-Server konfigurieren

Geben Sie einen **Server Name** ein (z. B. `Garry's Mod Server`). Die erforderlichen Netzwerkports werden während der Installation automatisch konfiguriert.

Sie können <code className="action">Advanced settings</code> aufklappen, um Optionen wie die Portzuordnung (Ports Binding) und Ressourcenlimits anzupassen. Die Standardwerte sind für die meisten Game-Server geeignet.

### Schritt 4 – Die Installation starten

Klicken Sie auf <code className="action">Install</code>. Die Bereitstellung startet automatisch. Warten Sie einige Minuten, während das Image heruntergeladen und der Server installiert wird.

### Schritt 5 – Die Installation verfolgen

Klicken Sie auf <code className="action">Log/Console</code>, um den Fortschritt in Echtzeit zu verfolgen. Der Status zeigt **Installing** an.

### Schritt 6 – Den Abschluss der Installation bestätigen

Sobald die Installation abgeschlossen ist und der Server gestartet wurde, ändert sich der Status zu **Running**.

### Schritt 7 – Überprüfen, ob der Server läuft

Prüfen Sie, ob die CPU- und RAM-Aktivität sichtbar ist. Sie können die Schaltflächen <code className="action">Log/Console</code> und <code className="action">Settings</code> verwenden, um den Server zu verwalten.

<img className="thumbnail" alt="Garry's Mod-Server mit dem Status Running und sichtbarer CPU- und RAM-Aktivität" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-running.png" loading="lazy" />

### Schritt 8 – Verbindungsinformationen abrufen

Kopieren Sie die IP-Adresse und den Port aus der Spalte **Connection** der Game-Servers-Liste.

### Schritt 9 – Ihrem Server in Garry's Mod beitreten

Fügen Sie Ihren Server zunächst zu Ihren Steam-Favoriten hinzu:

1. Gehen Sie in **Steam** auf **View** > **Game Servers**.
2. Öffnen Sie den Tab **Favorites** und klicken Sie auf **Add a server**.
3. Fügen Sie die IP-Adresse und den Port aus der Spalte **Connection** ein und klicken Sie anschließend auf **OK**.

Treten Sie dem Server anschließend über das Spiel bei:

1. Starten Sie **Garry's Mod** und klicken Sie auf **Find Multiplayer Game**.
2. Öffnen Sie den Tab **Favorites**.
3. Wählen Sie Ihren Server aus und verbinden Sie sich per Doppelklick.

### Spieleinstellungen konfigurieren

Gehen Sie zu <code className="action">Settings</code> > <code className="action">Game Config</code>, um die wichtigsten Einstellungen Ihres Servers anzupassen, ohne eine einzige Konfigurationsdatei zu bearbeiten.

<img className="thumbnail" alt="Die Game-Config-Einstellungen eines Garry's Mod-Servers" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-game-config.png" loading="lazy" />

| Einstellung | Beschreibung |
|-------------|--------------|
| `Server name` | Der Name, der im Serverbrowser des Spiels angezeigt wird. |
| `Map` | Die Karte, die beim Serverstart geladen wird. |
| `Game mode` | Der Spielmodus, den der Server ausführt. |
| `Workshop collection` | Die ID einer Steam-Workshop-Sammlung, die bei jedem Start heruntergeladen und eingebunden wird. Die Sammlung muss öffentlich oder nicht gelistet sein. |
| `Counter-Strike: Source content` | Lädt die Inhalte von Counter-Strike: Source herunter, die viele Addons verwenden. Die Spieler müssen das Spiel ebenfalls besitzen. Beim nächsten Start kommt ein Download von mehreren Gigabyte hinzu. |
| `Maximum players` | Die maximale Anzahl gleichzeitiger Spieler. |
| `Server password` | Das Passwort, das Spieler zum Beitreten eingeben müssen. Lassen Sie das Feld für einen öffentlichen Server leer. |
| `Admin password (RCON)` | Das Passwort, mit dem Sie den Server über die Konsole fernsteuern. |
| `Steam GSL token` | Das Token, mit dem Ihr Server im offiziellen Serverbrowser erscheint. Sie erhalten es auf [steamcommunity.com](https://steamcommunity.com/dev/managegameservers). |
| `Update workshop addons` | Aktualisiert die Addons der Sammlung bei jedem Start. |
| `Update on start` | Sucht bei jedem Start nach Spielupdates und installiert sie. |

Änderungen werden beim Neustart des Servers wirksam.

### Spielmodus ändern

Die Felder `Game mode` und `Map` sind Freitextfelder: Das Dropdown-Menü schlägt nur die mit dem Spiel ausgelieferten Werte vor, Sie können aber jeden beliebigen Namen eingeben.

**Trouble in Terrorist Town** ist in Garry's Mod enthalten. Wählen Sie es unter `Game mode` aus und starten Sie Ihren Server neu. Prüfen Sie die Karte: `Construct` und `Flatgrass` sind Sandbox-Karten, ein TTT-Server benötigt dagegen `ttt_`-Karten aus dem Workshop.

**DarkRP** ist nicht im Spiel enthalten und stammt aus dem Workshop:

1. Erstellen Sie eine öffentliche oder nicht gelistete Steam-Workshop-Sammlung mit DarkRP, seinen Abhängigkeiten und einer `rp_`-Karte.
2. Geben Sie ihre ID unter `Workshop collection` ein.
3. Geben Sie `darkrp` unter `Game mode` und den Namen Ihrer Karte unter `Map` ein.
4. Aktivieren Sie `Counter-Strike: Source content`, dessen Texturen viele DarkRP-Addons verwenden.
5. Starten Sie Ihren Server neu.

<img className="thumbnail" alt="Die Einstellungen Game mode, Workshop collection und Counter-Strike: Source content" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/gameplay-settings.png" loading="lazy" />

:::warning
Das Feld `Map` gibt die zu ladende Karte an, lädt sie aber nicht herunter. Eine Karte, die nicht in Ihrer Workshop-Sammlung enthalten ist, wird beim Start nicht gefunden, und der Server lässt sich nicht starten.
:::
