## Ziel

Mit dem Game Panel können Sie Ihren Rust-Server anpassen, indem Sie eine benutzerdefinierte Map installieren. Die Map-Datei wird extern gehostet und in Ihrer Server-Konfiguration referenziert.

**Diese Anleitung erklärt, wie Sie eine benutzerdefinierte Map auf einem im Game Panel gehosteten Rust-Server installieren.**

## Voraussetzungen

- Sie verfügen über einen [VPS](https://www.ovhcloud.com/de/vps/) in Ihrem OVHcloud Konto, für den die Game-Panel-Funktion aktiviert ist.
- Sie haben einen Rust-Server im Game Panel bereitgestellt.
- Sie verfügen über eine benutzerdefinierte Map-Datei im Format `.map`.

## In der praktischen Anwendung

### Schritt 1 – Ihre benutzerdefinierte Map vorbereiten

1. Stoppen Sie Ihren Rust-Server über das Game Panel.
2. Stellen Sie sicher, dass Ihre benutzerdefinierte Map im Format `.map` vorliegt.
3. Laden Sie die Map auf einen Filesharing-Dienst hoch.
4. Kopieren Sie den daraus entstehenden Download-Link und speichern Sie ihn – Sie benötigen ihn später.

:::warning
Dropbox eignet sich für diesen Zweck nicht. Verwenden Sie einen anderen Filesharing-Dienst.
:::


### Schritt 2 – Den File Manager öffnen

Klicken Sie auf Ihrem Rust-Server auf <code className="action">Settings</code> und öffnen Sie anschließend den Tab <code className="action">File Manager</code>.

:::warning
Stellen Sie sicher, dass Ihr Rust-Server **gestoppt** ist, bevor Sie eine der folgenden Aktionen durchführen.
:::


### Schritt 3 – Die Server-Konfiguration bearbeiten

1. Wechseln Sie im File Manager in folgendes Verzeichnis:

    ```
    /serverfiles/server/rustserver/cfg
    ```

2. Suchen Sie die Datei `server.cfg` und öffnen Sie sie zur Bearbeitung.
3. Suchen Sie die Zeile, die mit `levelURL=` beginnt, und fügen Sie den zuvor gespeicherten Download-Link hinter dem Zeichen `=` ein.
4. Stellen Sie sicher, dass der Link mit `dl=1` (nicht `dl=0`) endet. Passen Sie ihn bei Bedarf an.
5. Suchen Sie die Zeile, die mit `serverLevel=` beginnt, und geben Sie denselben Map-Typ ein, der zur Erstellung der benutzerdefinierten Map verwendet wurde:

    - `Procedural Map`
    - `Barren`
    - `Craggy Island`
    - `Savas Island`

6. Speichern Sie Ihre Änderungen.

### Schritt 4 – Den Server neu starten

Sobald Ihre Änderungen gespeichert sind, starten Sie Ihren Rust-Server über das Game Panel erneut.
