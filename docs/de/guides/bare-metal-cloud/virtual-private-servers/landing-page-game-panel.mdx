Willkommen bei der Dokumentation, die dem [OVHcloud Game Panel](/links/bare-metal/game-hub) gewidmet ist. Mit dem Game Panel können Sie direkt von Ihrem OVHcloud VPS oder dedizierten Server aus Game-Server für eine breite Auswahl beliebter Titel bereitstellen und verwalten. Hier finden Sie alle verfügbaren Anleitungen, um Ihre Game-Server zu installieren, zu konfigurieren und zu administrieren.

## Was ist das Game Panel?

Das OVHcloud Game Panel ist eine optimierte Oberfläche zum Bereitstellen und Verwalten von Game-Servern auf Ihrem VPS oder dedizierten Server. Dank der automatisierten Bereitstellung und der integrierten Tools können Sie Instanzen starten, Konfigurationen anpassen und die Leistung überwachen – ohne die zugrunde liegende Infrastruktur manuell verwalten zu müssen.

Mit dem Game Panel können Sie:

- Game-Server für mehr als 140 Titel bereitstellen (Minecraft, ARK, Counter-Strike 2, Rust und weitere)
- mehrere Game-Server auf einem einzigen VPS oder dedizierten Server betreiben
- Serverdateien, Backups und geplante Aufgaben verwalten
- den Zugriff mit Berechtigungen pro Benutzer und pro Server steuern
- die Auslastung von CPU, RAM, Festplatte und Netzwerk in Echtzeit überwachen
