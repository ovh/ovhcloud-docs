## Ziel

Mit dem OVHcloud Game Panel können Sie einen Valheim-Server mit automatisierter Installation und Portkonfiguration bereitstellen.

**In dieser Anleitung erfahren Sie, wie Sie über das OVHcloud Game Panel einen Valheim-Server bereitstellen und sich mit ihm verbinden.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben Zugriff auf das Game Panel. Weitere Informationen finden Sie unter [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Melden Sie sich bei Ihrem OVHcloud Game Panel an.

### Schritt 2 – Eine neue Serverinstanz erstellen

Klicken Sie auf <code className="action">Add Game Server</code> und wählen Sie **Valheim** aus.

<img className="thumbnail" alt="Auswahl von Valheim aus der Liste der Spiele" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/select-valheim.png" loading="lazy" />

:::info
Wenn dies Ihr erster Valheim-Server im Game Panel ist und der Standard-Spielport verfügbar ist, werden alle erforderlichen Ports automatisch konfiguriert. Es ist keine manuelle Einrichtung erforderlich.
:::


### Schritt 3 – Den Installationsfortschritt überwachen

Sobald die Installation startet, wird ein Bestätigungsbildschirm angezeigt. Klicken Sie auf <code className="action">Log/Console</code>, um den Installationsfortschritt in Echtzeit zu verfolgen.

<img className="thumbnail" alt="Überwachung der Installation des Valheim-Servers" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/installation-logs.png" loading="lazy" />

### Schritt 4 – Den Abschluss der Installation bestätigen

Sobald die Installation abgeschlossen ist, wird eine Benachrichtigung angezeigt: **Server status is now: Running**.

<img className="thumbnail" alt="Valheim-Server mit dem Status Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/server-running.png" loading="lazy" />

### Schritt 5 – Verbindungsinformationen abrufen

Sobald der Status Ihres Servers **Running** lautet, kopieren Sie die IP-Adresse und den Port aus der Spalte **Connection** der Game-Servers-Liste. Valheim verwendet zwei UDP-Ports: `2456` (Spiel) und `2457` (Query).

:::info
Während der Installation wird automatisch ein Serverpasswort generiert. Öffnen Sie den [File Manager](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/) über die <code className="action">Settings</code> Ihres Servers und suchen Sie unter `config-lgsm` > `vhserver` > `secrets-common.cfg`, um es abzurufen.
:::


### Schritt 6 – In Valheim Ihrem Server beitreten

1. Öffnen Sie **Valheim**.
2. Klicken Sie auf **Start** und anschließend auf **Join Server**.
3. Klicken Sie auf **Join IP** und fügen Sie die IP-Adresse und den Port aus der Spalte **Connection** ein.
4. Geben Sie das Passwort ein und klicken Sie auf **Connect**.
