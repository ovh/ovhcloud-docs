## Objective

The OVHcloud Game Panel lets you deploy a Valheim server with automated installation and port configuration.

**This guide explains how to deploy and connect to a Valheim server on the OVHcloud Game Panel.**

## Requirements

- A [VPS](https://www.ovhcloud.com/en-gb/vps/) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your OVHcloud Game Panel.

### Step 2 — Create a new server instance

Click <code className="action">Add Game Server</code> and select **Valheim**.

<img className="thumbnail" alt="Selecting Valheim from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/select-valheim.png" loading="lazy" />

:::info
If this is your first Valheim server on the Game Panel and the default Game Port is available, all required ports are configured automatically. No manual setup is needed.
:::


### Step 3 — Monitor installation progress

Once the installation starts, you will see a confirmation screen. Click <code className="action">Open Logs</code> to follow the installation progress in real time.

<img className="thumbnail" alt="Monitoring Valheim server installation" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/installation-logs.png" loading="lazy" />

### Step 4 — Confirm installation is complete

Once the installation is finished, a notification will appear: **Server status is now: Running**.

<img className="thumbnail" alt="Valheim server with Running status" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/server-running.png" loading="lazy" />

### Step 5 — Retrieve connection information

Once your server status is **Running**, copy the connection information from the Game Panel. Valheim uses two UDP ports: `2456` (Game) and `2457` (Query).

:::info
A server password is generated automatically during installation. Open the <code className="action">File Manager</code> from your server <code className="action">Settings</code> and look in `config-lgsm` > `vhserver` > `secrets-common.cfg` to retrieve it.
:::


### Step 6 — Join your server in Valheim

1. Open **Valheim**.
2. Click <code className="action">Start</code>, then <code className="action">Join game</code>.
3. Click <code className="action">Add server</code>.
4. Enter your VPS IP along with the port (e.g., `serv8.gamepanel.ovh:2456`).
5. Enter the password and click <code className="action">Connect</code>.
