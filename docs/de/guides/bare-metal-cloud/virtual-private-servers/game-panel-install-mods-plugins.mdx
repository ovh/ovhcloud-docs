## Ziel

Das OVHcloud Game Panel enthält einen Katalog für Mods und Plugins, der von [Modrinth](https://modrinth.com/) bereitgestellt wird. Suchen Sie nach Inhalten, prüfen Sie deren Abhängigkeiten und installieren Sie sie mit einem Klick – ohne das Panel zu verlassen und ohne eine einzige Datei zu bearbeiten.

**Diese Anleitung erklärt, wie Sie Mods und Plugins auf Ihrem im OVHcloud Game Panel gehosteten Minecraft-Server installieren.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben einen Minecraft-Server mit **PaperMC**, **Fabric**, **NeoForge** oder **Forge** im Game Panel bereitgestellt. Lesen Sie hierzu [Minecraft-Server über das Game Panel bereitstellen](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).
- Sie haben Zugang zum Game Panel. Lesen Sie hierzu [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## In der praktischen Anwendung

### Mod oder Plugin?

Beide erweitern Ihren Server, richten sich jedoch an unterschiedliche Serversoftware.

- Ein **Plugin** wird auf einem **PaperMC**-Server installiert. Es läuft ausschließlich serverseitig: Ihre Spieler müssen nichts installieren, um Ihnen beizutreten. Dies ist die richtige Wahl für Wirtschaftssysteme, Berechtigungen, Gebietsschutz oder Mini-Spiele.
- Eine **Mod** wird auf einem **Fabric**-, **NeoForge**- oder **Forge**-Server installiert. Sie verändert das Spiel selbst – neue Blöcke, Kreaturen, Dimensionen, Mechaniken – und je nach Mod müssen die Spieler dieselbe Mod manchmal in ihrem Client installieren.

Sie müssen sich diese Unterscheidung nicht merken: Das Game Panel wendet sie für Sie an und schlägt Ihnen nur Inhalte vor, die mit Ihrem Server kompatibel sind.

:::info
Da die Vorgehensweise in beiden Fällen identisch ist, verwendet diese Anleitung durchgehend den Begriff **Mod**. Wenn Ihr Server PaperMC verwendet, lesen Sie stattdessen **Plugin** und `Plugins` überall dort, wo die Benutzeroberfläche mit `Mods` zitiert wird.
:::

### Schritt 1 – Den Katalog öffnen

Suchen Sie Ihren Minecraft-Server und gehen Sie dann zu <code className="action">Settings</code> > <code className="action">Game Config</code> > <code className="action">Mods</code>.

Die Seite vereint drei Bereiche:

1. **Installed Mods**: alles, was bereits auf Ihrem Server vorhanden ist.
2. **Browse Mods on Modrinth**: der Katalog.
3. Ein Drag-and-Drop-Bereich am Ende der Seite, um Ihre eigenen Dateien hochzuladen.

<img className="thumbnail" alt="Der Tab Mods eines Minecraft-Servers im Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-plugins/mods-tab-overview.png" loading="lazy" />

### Schritt 2 – Eine Mod finden

Standardmäßig zeigt der Katalog nur Mods an, die sowohl mit dem **Mod-Loader** als auch mit der **Minecraft-Version** Ihres Servers kompatibel sind. Sie können die Ergebnisse daher durchsuchen, ohne Gefahr, die falsche Datei auszuwählen: Auf einem NeoForge-Server werden Ihnen niemals eine Fabric-Mod oder ein Paper-Plugin vorgeschlagen.

Die Kopfzeile des Katalogs bietet Ihnen:

- eine **Suchleiste**;
- ein **Sortiermenü**: `Relevance`, `Downloads`, `Follows`, `Newest` oder `Updated`;
- ein **Kategorienmenü**: `Adventure`, `Optimization`, `Equipment`, `Magic`, `Technology` und viele weitere;
- einen Schalter **All Minecraft versions**.

Aktivieren Sie **All Minecraft versions**, um die Suche auf alle Minecraft-Versionen auszuweiten und dabei beim Mod-Loader Ihres Servers zu bleiben. Ergebnisse, die nicht zur Version Ihres Servers passen, tragen dann das Badge **Incompatible**.

<img className="thumbnail" alt="Die Kopfzeile des Katalogs und der Schalter All Minecraft versions" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-plugins/catalog-filters.png" loading="lazy" />

### Schritt 3 – Die Detailseite vor der Installation prüfen

Klicken Sie auf den Titel einer Mod, um ihre Detailseite zu öffnen. Prüfen Sie diese stets: Hier finden Sie das, was einen Fehlschlag beim Start verhindert.

Sie finden dort:

- die Anzahl der Downloads und Follower, die Lizenz und die Kategorien;
- eine Bildergalerie und die vollständige Beschreibung des Autors;
- ein Menü **Version**, um die genaue zu installierende Version auszuwählen, wobei die neueste mit **Latest release** gekennzeichnet ist;
- Links zum Quellcode, zum Bugtracker, zum Wiki oder zum Discord des Projekts;
- und vor allem den Bereich **Dependencies declared by the author**.

Manche Mods benötigen andere Mods, um zu funktionieren: Dies sind die **Abhängigkeiten**. Jede ist als `required` oder `optional` gekennzeichnet und verfügt über eigene Schaltflächen <code className="action">Details</code> und <code className="action">Install</code>.

:::warning
Installieren Sie immer die als `required` gekennzeichneten Abhängigkeiten. Ohne sie startet Ihr Server möglicherweise überhaupt nicht. Am einfachsten ist es, sie direkt über die Detailseite zu installieren, bevor Sie zum Katalog zurückkehren.
:::

<img className="thumbnail" alt="Die Detailseite einer Mod und ihre vom Autor deklarierten Abhängigkeiten" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-plugins/mod-details-dependencies.png" loading="lazy" />

### Schritt 4 – Installieren

Klicken Sie auf <code className="action">Install</code>, entweder direkt auf der Katalogkarte oder über die Detailseite, wenn Sie eine bestimmte Version auswählen möchten. Die Schaltfläche wechselt zu **Installed** und die Mod erscheint sofort in der Liste am Anfang der Seite.

Sie müssen Ihren Server nicht stoppen, um eine Mod zu installieren. Die Änderungen werden jedoch erst beim nächsten Start wirksam: Wenn Ihr Server läuft, zeigt das Panel den Hinweis **Restart the server to apply your changes.** an.

<img className="thumbnail" alt="Die Schaltfläche Install auf einer Katalogkarte" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-plugins/catalog-install-button.png" loading="lazy" />

### Schritt 5 – Neu starten und prüfen

Starten Sie Ihren Server neu und öffnen Sie dann <code className="action">Log/Console</code>, um den Start zu verfolgen.

Behalten Sie die Logs im Auge: Sie bestätigen, dass der Server korrekt startet und dass Ihre Mods richtig geladen werden. Ein Fehler beim Start weist meist auf eine fehlende Abhängigkeit oder eine inkompatible Version hin.

### Ihre installierten Mods verwalten

Die Liste **Installed Mods** fasst alles zusammen, was auf Ihrem Server vorhanden ist, unabhängig davon, ob Sie es über den Katalog installiert oder manuell hochgeladen haben. In jeder Zeile können Sie:

- auf den Namen klicken, um die Detailseite erneut zu öffnen;
- auf <code className="action">Update</code> klicken, wenn eine neue Version verfügbar ist;
- den Schalter verwenden, um die Mod zu **aktivieren oder zu deaktivieren**, ohne sie zu löschen – nützlich, um die Ursache eines Absturzes zu ermitteln;
- das Papierkorb-Symbol verwenden, um die Mod zu löschen, oder mehrere Zeilen markieren, um sie gesammelt zu löschen.

Die Badges **Disabled** und **Incompatible** weisen Sie auf einen Blick auf die Zeilen hin, die Sie im Auge behalten sollten.

<img className="thumbnail" alt="Die Liste der installierten Mods und ihre Verwaltungsaktionen" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-plugins/installed-mods-manage.png" loading="lazy" />

### Ihre eigene Mod hochladen

Sie können auch eine Mod installieren, die Sie bereits vorliegen haben: eine Datei von [CurseForge](https://www.curseforge.com/minecraft) oder SpigotMC, eine selbst kompilierte Version oder eine private Mod.

1. Laden Sie die `.jar`-Datei herunter und achten Sie dabei darauf, den richtigen **Mod-Loader** (Paper, Fabric, NeoForge oder Forge) und die richtige **Minecraft-Version** auszuwählen.
2. Scrollen Sie im Tab <code className="action">Mods</code> bis zum Drag-and-Drop-Bereich am Ende der Seite.
3. Legen Sie Ihre Datei dort ab oder klicken Sie auf den Bereich, um sie auf Ihrem Computer auszuwählen.
4. Starten Sie Ihren Server neu, um die Änderungen zu übernehmen.

Die hochgeladene Datei erscheint in der Liste Ihrer installierten Mods. Wenn Modrinth sie erkennt, ergänzt das Panel sie automatisch – Name, Symbol, Version – und schlägt Ihnen ihre Updates wie bei einer Installation über den Katalog vor.

:::info
Es werden ausschließlich `.jar`-Dateien akzeptiert. Denken Sie daran, die Abhängigkeiten ebenfalls selbst zu prüfen: Im Gegensatz zum Katalog werden sie beim manuellen Hochladen nicht angezeigt.
:::
