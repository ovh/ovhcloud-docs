## Ziel

Mit dem OVHcloud Game Panel können Sie Ihren Minecraft-Server durch die Installation von Mods und Plugins anpassen, je nach der von Ihnen verwendeten Serversoftware.

**Diese Anleitung erklärt, wie Sie Mods und Plugins auf Ihrem im OVHcloud Game Panel gehosteten Minecraft-Server installieren.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben einen Minecraft-Server, der eine der folgenden Softwarevarianten verwendet: **PaperMC**, **Fabric** oder **NeoForge**.
- Sie haben Zugang zum Game Panel. Lesen Sie hierzu [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## In der praktischen Anwendung

### Den Unterschied zwischen PaperMC, Fabric und NeoForge verstehen

Auch wenn alle drei Plattformen es Ihnen ermöglichen, Ihren Minecraft-Server anzupassen, funktionieren sie unterschiedlich.

- **PaperMC** ist eine leistungsstarke Minecraft-Serversoftware, die **Plugins** unterstützt. Plugins sind leichtgewichtige Ergänzungen, die neue Befehle, Gameplay-Mechaniken, Berechtigungssysteme, Wirtschaftssysteme und vieles mehr hinzufügen können, ohne dass die Spieler etwas auf ihrem Spiel-Client installieren müssen.
- **Fabric** ist ein leichtgewichtiger und moderner **Mod-Loader**. Er unterstützt eine breite Palette von Mods und ist für seine schnellen Updates und seine ausgezeichnete Leistung bekannt. Sowohl der Server als auch, in den meisten Fällen, die verbundenen Spieler müssen die erforderlichen Mods installiert haben.
- **NeoForge** ist ein leistungsstarker und moderner **Mod-Loader**, der für größere und fortgeschrittenere Modpacks konzipiert ist. Er bietet umfangreiche Modding-Möglichkeiten und wird häufig für stark modifizierte Minecraft-Erlebnisse mit komplexen Gameplay-Ergänzungen verwendet.

Kurz gesagt:

- PaperMC → Plugins
- Fabric → Mods
- NeoForge → Mods

### Schritt 1 – Ihre Plugins oder Mods herunterladen

Zunächst müssen Sie das Plugin oder die Mod herunterladen, die Sie installieren möchten. Viele Websites bieten Minecraft-Plugins und -Mods an, eine der beliebtesten ist [CurseForge](https://www.curseforge.com/minecraft).

1. Suchen Sie nach dem gewünschten Plugin oder der gewünschten Mod.
2. Öffnen Sie deren Seite.
3. Klicken Sie auf <code className="action">Download</code>.
4. Achten Sie darauf, die korrekte **Minecraft-Version** und den korrekten **Plugin/Mod Loader** (Paper, Fabric oder NeoForge) auszuwählen.

So stellen Sie sicher, dass das Plugin oder die Mod mit Ihrem Server kompatibel ist.

<img className="thumbnail" alt="Ein Plugin oder eine Mod herunterladen" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-plugins/download-plugin-mod.png" loading="lazy" />

### Schritt 2 – Den Server stoppen

Bevor Sie ein Plugin oder eine Mod installieren, stoppen Sie Ihren Minecraft-Server.

1. Öffnen Sie Ihren Server im Game Panel.
2. Klicken Sie auf <code className="action">Stop</code>.

:::warning
Das Installieren von Dateien während der Server läuft, kann zu Problemen führen oder verhindern, dass sie korrekt geladen werden.
:::

### Schritt 3 – Das Plugin oder die Mod hochladen

1. Öffnen Sie Ihren Server im Game Panel.
2. Navigieren Sie zu <code className="action">Settings</code>.
3. Öffnen Sie den Tab <code className="action">Game Config</code>.
4. Wählen Sie je nach Ihrer Serversoftware entweder den Tab <code className="action">Plugins</code> oder <code className="action">Mods</code> aus.

<img className="thumbnail" alt="Der Tab Plugins oder Mods in Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-plugins/plugins-mods-tab.png" loading="lazy" />

Laden Sie anschließend die Datei hoch:

1. Suchen Sie die Plugin- oder Mod-Datei, die Sie auf Ihren Computer heruntergeladen haben.
2. Ziehen Sie die Datei per Drag-and-drop in den Upload-Bereich.

<img className="thumbnail" alt="Eine Plugin- oder Mod-Datei hochladen" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-plugins/upload-area.png" loading="lazy" />

Sobald der Upload abgeschlossen ist, erscheint das Plugin oder die Mod in der Liste.

### Schritt 4 – Den Server starten

Nach dem Hochladen Ihres Plugins oder Ihrer Mod:

1. Starten Sie Ihren Minecraft-Server.
2. Öffnen Sie die Server-Logs.

Es wird dringend empfohlen, die Logs während des Starts zu überwachen, um sicherzustellen, dass der Server erfolgreich startet, keine Fehler gemeldet werden und die installierten Plugins oder Mods korrekt geladen werden.

Wenn alles ohne Fehler geladen wird, ist Ihre Installation abgeschlossen. Sie können diesen Vorgang jederzeit wiederholen, wenn Sie weitere Inhalte zu Ihrem Server hinzufügen möchten.
