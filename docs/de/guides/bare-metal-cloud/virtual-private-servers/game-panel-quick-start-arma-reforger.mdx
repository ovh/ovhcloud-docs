## Ziel

Mit dem Game Panel können Sie einen Arma Reforger Server in wenigen Schritten bereitstellen. Das Panel übernimmt die Installation automatisch, einschließlich der Portkonfiguration.

**Diese Anleitung erläutert, wie Sie einen Arma Reforger Server im Game Panel bereitstellen und sich mit ihm verbinden.**

## Voraussetzungen

- Sie verfügen über einen [VPS](https://www.ovhcloud.com/de/vps/) in Ihrem OVHcloud Account mit aktivierter Game-Panel-Funktion.
- Sie haben Zugriff auf das Game Panel. Lesen Sie hierzu [Sich am Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Melden Sie sich an Ihrem Game Panel an.

### Schritt 2 – Eine neue Serverinstanz erstellen

Klicken Sie auf <code className="action">Add Game Server</code> und wählen Sie **Arma Reforger** aus.

<img className="thumbnail" alt="Auswahl von Arma Reforger aus der Spieleliste" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/select-arma-reforger.png" loading="lazy" />

:::info
Wenn dies Ihr erster Arma Reforger Server im Game Panel ist und der standardmäßige Game Port verfügbar ist, werden alle erforderlichen Ports während der Installation automatisch konfiguriert. In diesem Fall ist keine manuelle Einrichtung erforderlich.
:::


### Schritt 3 – Den Installationsfortschritt überwachen

Sobald die Installation startet, erscheint ein Bestätigungsbildschirm. Klicken Sie auf <code className="action">Log/Console</code>, um den Installationsfortschritt in Echtzeit zu verfolgen.

<img className="thumbnail" alt="Bildschirm zum Installationsstart von Arma Reforger mit der Schaltfläche Open Logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-started.png" loading="lazy" />

Während der Server installiert wird, zeigt der Status **Installing** an. Verfolgen Sie den detaillierten Fortschritt direkt im Logs-Bereich.

<img className="thumbnail" alt="Arma Reforger Server mit dem Status Running und Installationslogs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-logs.png" loading="lazy" />

### Schritt 4 – Den Abschluss der Installation bestätigen

Sobald die Installation abgeschlossen ist, ändert sich der Serverstatus zu **Running**.

### Schritt 5 – Die Verbindungsinformationen abrufen

Sobald Ihr Serverstatus **Running** lautet, kopieren Sie die Verbindungsinformationen aus dem Game Panel.

<img className="thumbnail" alt="Verbindungsdetails für den Arma Reforger Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-connection-details.png" loading="lazy" />

### Schritt 6 – Ihrem Server in Arma Reforger beitreten

1. Öffnen Sie **Arma Reforger** und rufen Sie das Hauptmenü auf.
2. Klicken Sie auf <code className="action">Multiplayer</code>.
3. Wählen Sie <code className="action">Direct Join</code> aus oder drücken Sie `v`.
4. Geben Sie die IP-Adresse und den Port ein und klicken Sie anschließend auf <code className="action">Join</code>.
