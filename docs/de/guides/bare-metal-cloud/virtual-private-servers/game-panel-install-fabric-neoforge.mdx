## Ziel

Fabric und NeoForge sind Mod-Loader für Minecraft-Server. Wenn Sie einen davon auf einem im Game Panel gehosteten Minecraft-Server installieren, können Sie modifiziertes Gameplay mit erweiterten Funktionen ausführen.

**Diese Anleitung erklärt, wie Sie Fabric oder NeoForge auf einem Minecraft-Server im Game Panel installieren und Mods hinzufügen.**

## Voraussetzungen

- Sie verfügen über einen [VPS](https://www.ovhcloud.com/de/vps/) in Ihrem OVHcloud Konto, für den die Game-Panel-Funktion aktiviert ist.
- Sie haben einen Minecraft-Server im Game Panel bereitgestellt. Lesen Sie hierzu [Einen Minecraft-Server im Game Panel bereitstellen](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

## In der praktischen Anwendung

### Schritt 1 – Automatische Updates deaktivieren

Um Konflikte mit Mod-Loadern zu vermeiden, deaktivieren Sie die automatischen Updates, bevor Sie Änderungen vornehmen:

1. Rufen Sie die <code className="action">Settings</code> Ihres Servers auf.
2. Öffnen Sie den Tab <code className="action">Game Config</code>.
3. Deaktivieren Sie die automatischen Updates.

### Schritt 2 – Den Server stoppen

Stoppen Sie Ihren Minecraft-Server über das Game Panel, bevor Sie weitere Änderungen vornehmen.

### Schritt 3 – Den Installer herunterladen und hochladen

Laden Sie den Installer für den von Ihnen gewählten Mod-Loader herunter:

- **Fabric**: [https://fabricmc.net/use/server/](https://fabricmc.net/use/server/)
- **NeoForge**: [https://neoforged.net/](https://neoforged.net/)

Öffnen Sie nach dem Herunterladen die <code className="action">Settings</code> Ihres Servers, wechseln Sie zum Tab <code className="action">File Manager</code> und laden Sie die Datei `.jar` über <code className="action">Upload files</code> oder per Drag-and-drop in das Verzeichnis `serverfiles` hoch.

### Schritt 4 – Den Installer ausführen

Öffnen Sie den Tab <code className="action">Terminal</code> in den <code className="action">Settings</code> Ihres Servers und führen Sie den passenden Befehl für Ihren Mod-Loader aus.

Für **Fabric**:

```bash
java -jar fabric-installer-X.X.X.jar server --downloadMinecraft
```

Dadurch werden die Minecraft-Server-Dateien heruntergeladen, der Fabric-Loader installiert und die Fabric-Server-Startdatei erzeugt.

Für **NeoForge**:

```bash
java -jar neoforge-X.X.X-installer.jar --installServer
```

Dadurch wird NeoForge installiert, die Minecraft-Server-Dateien werden heruntergeladen und die Server-Startdateien werden erzeugt.

### Schritt 5 – LinuxGSM konfigurieren

Teilen Sie LinuxGSM mit, welche ausführbare Datei je nach Mod-Loader verwendet werden soll.

Für **Fabric**:

```bash
printf '\nexecutable="./fabric-server-launch.jar"\n' >> /data/config-lgsm/mcserver/common.cfg
```

Für **NeoForge**:

```bash
printf '\npreexecutable=""\nexecutable="./run.sh"\nstartparameters="nogui"\n' >> /data/config-lgsm/mcserver/common.cfg
```

:::warning
Wenn Sie NeoForge mit `run.sh` verwenden, wird die Einstellung **Max RAM** in der Game Config nicht mehr angewendet. Bearbeiten Sie stattdessen `/data/serverfiles/user_jvm_args.txt`. Beispiel:

```
-Xms2G
-Xmx4G
```
:::


### Schritt 6 – Den Server starten

Setzen Sie die korrekten Berechtigungen, bevor Sie den Server starten:

```bash
sudo chown -R linuxgsm:linuxgsm /data/serverfiles
```

Starten Sie anschließend den Server über das Game Panel und prüfen Sie die Server-Logs, um einen erfolgreichen Start zu bestätigen.

### Schritt 7 – Mods hinzufügen

Um Mods auf Ihrem modifizierten Server zu installieren:

1. Laden Sie mit Fabric oder NeoForge kompatible Mods herunter.
2. Öffnen Sie den Tab <code className="action">File Manager</code> in den <code className="action">Settings</code> Ihres Servers.
3. Laden Sie die Mod-Dateien `.jar` in das Verzeichnis `serverfiles/mods` hoch.
4. Setzen Sie die Berechtigungen zurück:

    ```bash
    sudo chown -R linuxgsm:linuxgsm /data/serverfiles
    ```

5. Starten Sie den Server neu. Prüfen Sie die Logs, um zu bestätigen, dass die Mods geladen sind.
