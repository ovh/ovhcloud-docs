## Ziel

Mit dem OVHcloud Game Panel können Sie einen Hytale Server mit automatisierter Installation und Portkonfiguration bereitstellen.

**Diese Anleitung erläutert, wie Sie einen Hytale Server im OVHcloud Game Panel bereitstellen und sich mit ihm verbinden.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben Zugriff auf das Game Panel. Lesen Sie hierzu [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Sie verfügen über einen Hytale Account, der für die Authentifizierung während der Installation erforderlich ist.

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Melden Sie sich an Ihrem OVHcloud Game Panel an. Gehen Sie zum Bereich **Game Servers** im Menü auf der linken Seite und klicken Sie auf <code className="action">Add Game Server</code>.

### Schritt 2 – Einen Hytale Server erstellen

Wählen Sie **Hytale** aus der Spieleliste aus. Ein Konfigurationsfenster wird geöffnet.

<img className="thumbnail" alt="Auswahl von Hytale aus der Spieleliste" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-hytale/select-hytale.png" loading="lazy" />

### Schritt 3 – Den Hytale Server konfigurieren

Geben Sie einen **Server Name** ein (z. B. `Hytale Server`). Die erforderlichen Netzwerkports werden während der Installation automatisch konfiguriert.

Sie können <code className="action">Advanced settings</code> aufklappen, um Optionen wie die Portzuordnung (Ports Binding) und Ressourcenlimits anzupassen. Die Standardwerte sind für die meisten Game-Server geeignet.

### Schritt 4 – Die Installation starten

Klicken Sie auf <code className="action">Install</code>. Die Bereitstellung startet automatisch. Warten Sie einige Minuten, während das Image heruntergeladen und der Server installiert wird.

Während der Installation fordert das Game Panel Sie auf, sich über eine Schaltfläche, die Sie per OAuth auf die offizielle Hytale Website weiterleitet, mit Ihrem Hytale Account zu authentifizieren. Sie werden zweimal zur Authentifizierung aufgefordert:

- Die erste Authentifizierung ermöglicht es dem Game Panel, die Serverdateien herunterzuladen.
- Die zweite Authentifizierung erfolgt beim ersten Start des Servers und ist erforderlich, um eine Spielsitzung von Hypixel zu erhalten.

Sobald die jeweilige Authentifizierung abgeschlossen ist, wird der Installations- und Startvorgang automatisch fortgesetzt.

### Schritt 5 – Die Installation verfolgen

Klicken Sie auf <code className="action">Log/Console</code>, um den Fortschritt in Echtzeit zu verfolgen. Der Status zeigt **Installing** an.

### Schritt 6 – Überprüfen, ob der Server läuft

Überprüfen Sie, ob der Serverstatus **Running** anzeigt und ob CPU-/RAM-Aktivität sichtbar ist.

Verfügbare Aktionen:

- <code className="action">Log/Console</code>: Öffnen Sie die Konsole, um den Start zu überwachen und bei Problemen die Logs zu prüfen.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: Greifen Sie auf die Spieleinstellungen zu.

<img className="thumbnail" alt="Hytale Server mit dem Status Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-hytale/hytale-running.png" loading="lazy" />

### Schritt 7 – Den Abschluss der Installation bestätigen

Sobald die Installation abgeschlossen ist, ändert sich der Status zu **Running** und der Server ist einsatzbereit.

### Schritt 8 – Verbindungsinformationen abrufen

Kopieren Sie aus der Spalte **Connection** der Game-Servers-Liste die IP-Adresse und den Port Ihres Servers.

### Schritt 9 – Ihrem Server in Hytale beitreten

In Hytale:

1. Starten Sie das Spiel und öffnen Sie das Menü **Servers**.
2. Klicken Sie auf **Direct Connect** und geben Sie die IP-Adresse und den Port aus der Spalte **Connection** ein.
3. Klicken Sie auf **Connect**, um Ihrem Server beizutreten.

### Bewährte Vorgehensweisen

- Konfigurieren Sie die Berechtigungen über <code className="action">User Administration</code>.
- Führen Sie regelmäßig Backups durch.
- Passen Sie Ihre Spieleinstellungen an.

:::info
Um weiterzugehen, passen Sie die Einstellungen Ihres Servers an, beschränken Sie den Zugriff mit einem Passwort oder einer Whitelist oder optimieren Sie die Leistungsoptionen.
:::
