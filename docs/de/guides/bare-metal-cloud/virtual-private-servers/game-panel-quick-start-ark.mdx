## Ziel

Mit dem OVHcloud Game Panel können Sie einen ARK: Survival Evolved Server in wenigen Schritten bereitstellen. Das Panel übernimmt die Installation automatisch, einschließlich der Portkonfiguration.

**Diese Anleitung erläutert, wie Sie einen ARK: Survival Evolved Server im OVHcloud Game Panel bereitstellen und sich mit ihm verbinden.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben Zugriff auf das Game Panel. Lesen Sie hierzu [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Melden Sie sich an Ihrem OVHcloud Game Panel an.

### Schritt 2 – Eine neue Serverinstanz erstellen

Klicken Sie auf <code className="action">Add Game Server</code> und wählen Sie **ARK: Survival Evolved** aus.

<img className="thumbnail" alt="Auswahl von ARK: Survival Evolved aus der Spieleliste" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/select-ark.png" loading="lazy" />

:::info
Wenn dies Ihr erster ARK-Server im Game Panel ist und der standardmäßige Game Port verfügbar ist, werden alle erforderlichen Ports während der Installation automatisch konfiguriert. In diesem Fall ist keine manuelle Einrichtung erforderlich.
:::


### Schritt 3 – Den Installationsfortschritt überwachen

Sobald die Installation startet, erscheint ein Bestätigungsbildschirm. Klicken Sie auf <code className="action">Log/Console</code>, um den Installationsfortschritt in Echtzeit zu verfolgen.

Während der Server installiert wird, zeigt der Status **Installing** an. Verfolgen Sie den detaillierten Fortschritt direkt im Logs-Bereich.

<img className="thumbnail" alt="Überwachung der ARK-Serverinstallation im Logs-Bereich" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/installation-logs.png" loading="lazy" />

### Schritt 4 – Den Abschluss der Installation bestätigen

Sobald die Installation abgeschlossen ist, ändert sich der Serverstatus zu **Running**.

<img className="thumbnail" alt="ARK-Server mit dem Status Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/server-running.png" loading="lazy" />

### Schritt 5 – Die Verbindungsinformationen abrufen

Sobald Ihr Serverstatus **Running** lautet, kopieren Sie die Verbindungsinformationen aus dem Game Panel.

<img className="thumbnail" alt="Verbindungsdetails für den ARK-Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/connection-details.png" loading="lazy" />

### Schritt 6 – Ihrem Server in ARK beitreten

Fügen Sie zunächst Ihren Server zu Ihren **Steam**-Favoriten hinzu:

1. Gehen Sie in **Steam** zu **View** > **Game Servers**.
2. Öffnen Sie die Registerkarte **Favorites** und klicken Sie auf **Add a server**.
3. Fügen Sie die IP-Adresse und den Port aus der Spalte **Connection** ein und klicken Sie anschließend auf **OK**.

Treten Sie dem Server dann über das Spiel bei:

1. Starten Sie **ARK: Survival Evolved** und klicken Sie auf **Join ARK**.
2. Stellen Sie den **Session Filter** auf **Favorites** ein.
3. Wählen Sie Ihren Server aus und klicken Sie auf **Join**.
