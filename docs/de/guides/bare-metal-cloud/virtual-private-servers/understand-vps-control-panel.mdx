## Ziel

- Das VPS-Dashboard verstehen.
- Wesentliche Informationen identifizieren.
- Erfahren, wie Sie die wichtigsten Aktionen ausführen können.

## Voraussetzungen

- Sie verfügen über einen aktiven [VPS](/links/bare-metal/vps) in Ihrem OVHcloud Kunden-Account.

:::warning
Einige VPS-Funktionen, die auf dieser Seite erwähnt werden, sind in den OVHcloud Local Zones nicht verfügbar.

Weitere Informationen finden Sie auf unserer [Local Zones Seite](/links/bare-metal/vps-lz).

:::

### Dashboard <a name="controlpanel"></a>

Der Tab <code className="action">Übersicht</code> ist das **Haupt-Dashboard** Ihres VPS.

Er bündelt **wichtige Informationen zum Dienst** und bietet Zugang zu **wesentlichen Verwaltungsfunktionen**.

<img className="thumbnail" alt="Tab Übersicht eines VPS in der OVHcloud Konsole" src="/images/bare-metal-cloud/virtual-private-servers/understand-vps-control-panel/console/vpshome.png" loading="lazy" />

#### Allgemeine Informationen <a name="myvps"></a>

Der Abschnitt **Allgemeine Informationen** zeigt die grundlegenden Informationen zu Ihrem VPS an. Der Dienst-Status wird oben auf der Seite neben dem Namen Ihres VPS angezeigt. Klicken Sie auf die untenstehenden Tabs, um die Details anzuzeigen.

<Tabs>
  <Tab label="Name">
    Um den Namen Ihres VPS anzupassen, klicken Sie oben auf der Seite auf das Stiftsymbol neben dem Namen, geben Sie den neuen Namen ein und klicken Sie dann auf das Häkchensymbol, um ihn zu speichern. Diese Funktion ist nützlich, um bei der Verwaltung mehrerer VPS-Dienste in der OVHcloud Konsole einfacher navigieren zu können. Der interne Dienstname bleibt jedoch im Format *VPS-XXXXXXX.VPS.ovh.net*.
  </Tab>
  <Tab label="Boot">
    Der angezeigte Startmodus ist:
    
    - **Normaler Modus** (*LOCAL*), bei dem der Server das installierte Betriebssystem lädt.
    - **Rescue-Modus**, der von OVHcloud bereitgestellt wird, um Probleme zu beheben.
    
    Klicken Sie in der Zeile **Weitere Aktionen** des Abschnitts auf den Button <code className="action">⋮</code> und wählen Sie dann <code className="action">VPS neu starten</code>, um den [VPS neu zu starten](#rebootvps), oder <code className="action">Neustart im Rescue-Modus</code>, um ihn bei Bedarf im Rescue-Modus zu starten.
    
    Falls erforderlich, finden Sie weitere Informationen in unserer Anleitung zu [Rescue-Modus](/guides/bare-metal-cloud/virtual-private-servers/rescue).
  </Tab>
  <Tab label="Distribution">
    Dies ist das aktuell installierte Betriebssystem. Klicken Sie auf den Link <code className="action">VPS reinstallieren</code> darunter, um [das gleiche Betriebssystem neu zu installieren oder eine andere Option aus den verfügbaren Möglichkeiten auszuwählen](#reinstallvps).
    
    :::warning
    Eine Neuinstallation löscht alle Daten, die aktuell auf dem VPS gespeichert sind (mit Ausnahme zusätzlicher Disks).

    :::

    
    :::info
    Wenn Sie einen **Windows**-VPS bestellt haben, können Sie bei der Neuinstallation nur ein Windows-Betriebssystem auswählen. Ebenso können Sie Windows nicht nachträglich installieren, wenn es bei der Bestellung nicht ausgewählt wurde.

    :::

    
    Nach der Installation des Systems sind Sie verantwortlich für die Anwendung der Sicherheitsupdates für das Betriebssystem. Weitere Informationen finden Sie im Abschnitt "[Neuinstallation Ihres VPS](#reinstallvps)" sowie in unserer Anleitung "[Sicherung eines VPS](/guides/bare-metal-cloud/virtual-private-servers/secure-your-vps)".
  </Tab>
  <Tab label="Region">
    Das Feld **Region** liefert Informationen zum Standort Ihres VPS. Dies kann hilfreich sein, um potenzielle Auswirkungen auf Ihren Dienst zu identifizieren und einzuschätzen, wie z. B. in [Vorfällen oder Wartungsberichten](https://bare-metal-servers.status-ovhcloud.com/).
  </Tab>
</Tabs>

Klicken Sie auf die untenstehenden Tabs, um die Details dieses Abschnitts anzuzeigen.

<Tabs>
  <Tab label="Modell">
    Dieser Punkt gibt die kommerzielle Referenz an, die das VPS-Modell identifiziert, das dem [VPS-Angebot auf unserer Website](/links/bare-metal/vps) entspricht.
  </Tab>
  <Tab label="Prozessor/Arbeitsspeicher/Primäre Festplatte">

    Dieser Punkt gibt an, ob zusätzliche Disks auf Ihrem VPS aktiviert sind. Zusätzliche Disks erhöhen die Speicherkapazität des Servers über die im ursprünglichen Setup enthaltene hinaus. Sie können z. B. Backup-Daten darauf speichern. Verwalten Sie sie über den Tab <code className="action">Zusätzliche Festplatte</code>.
  </Tab>
</Tabs>


#### Verbindungsdetails <a name="ip"></a>

Klicken Sie auf die untenstehenden Tabs, um die Details dieses Abschnitts anzuzeigen.

<Tabs>
  <Tab label="IPv4">
    Die Haupt-IPv4-Adresse des VPS wird automatisch bei der Installation konfiguriert. Weitere Informationen zur IP-Verwaltung finden Sie in unserer Anleitung "[Konfigurieren einer Alias-IP-Adresse](/guides/bare-metal-cloud/virtual-private-servers/configuring-ip-aliasing)".
  </Tab>
  <Tab label="IPv6/Gateway">
    Hier finden Sie die öffentliche IPv6-Adresse und die zugehörige Gateway-Adresse (**IPv6-Gateway**). Diese werden automatisch beim Installieren des VPS angehängt. Weitere Informationen finden Sie in unserer Anleitung "[Konfigurieren von IPv6 auf einem VPS-Server](/guides/bare-metal-cloud/virtual-private-servers/configure-ipv6)".
  </Tab>
  <Tab label="Sekundärer DNS">
    Dieser Punkt gibt an, ob Domains auf dem sekundären OVHcloud DNS Ihres VPS konfiguriert sind. Diese Funktion ist nützlich, um DNS-Dienste zu hosten. Das Hinzufügen oder Löschen einer Domain auf dem sekundären DNS ist in der OVHcloud Konsole nicht verfügbar. Weitere Informationen zu diesem Thema finden Sie in unserer Anleitung "[Konfigurieren eines sekundären OVHcloud DNS auf einem VPS](/guides/bare-metal-cloud/virtual-private-servers/adding-secondary-dns-on-vps)".
  </Tab>
</Tabs>


#### Backup <a name="save"></a>

Diese Optionen beziehen sich auf zusätzliche VPS-Dienste für das Backup und die Wiederherstellung Ihres Systems.

<Tabs>
  <Tab label="Snapshot">
    Ein Snapshot auf einem VPS ist ein Momentaufnahme-Backup des Serverzustands, das es Ihnen ermöglicht, das System bei Problemen schnell wiederherzustellen. Die Option `Snapshot` ermöglicht es Ihnen, einen manuellen Snapshot als einzelnen Wiederherstellungspunkt zu erstellen. Wenn die Option auf Ihrem VPS nicht aktiv ist, bestellen Sie sie über den Link <code className="action">Snapshot bestellen</code>.
  </Tab>
  <Tab label="Automatisches Backup">
    Ein tägliches Systembackup (mit Ausnahme zusätzlicher Disks) wird automatisch durchgeführt und 24 Stunden lang gespeichert (gilt nur für Dienste, die ab dem 7. August 2025 bestellt wurden). Wenn Sie die Option **Automatisches Backup** auf **Premium** umstellen, haben Sie die letzten 7 täglichen Backups Ihres VPS, die Sie für das Einhängen und Wiederherstellen nutzen können.  
    Im Vergleich zu manuellen Snapshots erhöht diese Funktion die Datensicherheit, indem mehrere Wiederherstellungspunkte zu regelmäßigen Zeitintervallen erstellt werden.
  </Tab>
</Tabs>


Finden Sie alle Informationen zu den Backup-Lösungen, die für Ihren Dienst verfügbar sind, auf der [VPS-Produktseite](/links/bare-metal/vps-options) und in unseren Anleitungen "[Snapshots auf einem VPS verwenden](/guides/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps)" und "[Automatische Backups auf einem VPS verwenden](/guides/bare-metal-cloud/virtual-private-servers/using-automated-backups-on-a-vps)".

#### Neustart Ihres VPS <a name="rebootvps"></a>

Ein Neustart kann erforderlich sein, um Konfigurationsaktualisierungen anzuwenden oder ein Problem zu beheben. Falls möglich, führen Sie einen "Software-Neustart" über die grafische Benutzeroberfläche des Servers (Windows, Plesk etc.) oder über den folgenden Befehl durch:

```bash
sudo reboot
```

Sie können jedoch jederzeit einen erzwungenen Neustart in der <ManagerLink to="/">OVHcloud Konsole</ManagerLink> durchführen. Klicken Sie im Tab <code className="action">Übersicht</code> in der Zeile **Weitere Aktionen** des Abschnitts **Allgemeine Informationen** auf den Button <code className="action">⋮</code>. Wählen Sie <code className="action">VPS neu starten</code> und klicken Sie im erscheinenden Fenster auf <code className="action">Bestätigen</code>.

<img className="thumbnail" alt="Menü Weitere Aktionen eines VPS in der OVHcloud Konsole mit VPS neu starten" src="/images/assets/screens/console/product-selection/bare-metal-cloud/vps/cp-reboot.png" loading="lazy" />

#### Neuinstallation Ihres VPS <a name="reinstallvps"></a>

Die Neuinstallation Ihres VPS kann über die OVHcloud Konsole erfolgen. Dieser Vorgang wird in der Regel bei Systemproblemen, bei Änderungen der Umgebung oder für einen Neubeginn mit einer sauberen Installation durchgeführt.

Klicken Sie im Abschnitt **Allgemeine Informationen** des Tabs <code className="action">Übersicht</code> unter **Distribution** auf den Link <code className="action">VPS reinstallieren</code>.

<img className="thumbnail" alt="Link VPS reinstallieren unter Distribution in der OVHcloud Konsole" src="/images/assets/screens/console/product-selection/bare-metal-cloud/vps/cp-reinst.png" loading="lazy" />

Wählen Sie im erscheinenden Fenster **VPS reinstallieren** ein Betriebssystem aus der Dropdown-Liste **Betriebssystem** aus. Die angebotenen Optionen sind [Images, die mit einem OVHcloud VPS kompatibel sind](/guides/public-cloud/compute/image-life-cycle) und funktionieren nach der Installation sofort.

Wenn Sie ein kompatibles Betriebssystem ausgewählt haben, können Sie einen **öffentlichen Schlüssel** angeben, der automatisch installiert wird. Zwei Optionen stehen zur Verfügung:

- Kopieren Sie den Schlüsseltext manuell und fügen Sie ihn in das Feld `Ihr öffentlicher SSH-Schlüssel` ein.
- Wenn Sie zuvor in der <ManagerLink to="/">OVHcloud Konsole</ManagerLink> [einen öffentlichen Schlüssel gespeichert haben](/guides/bare-metal-cloud/dedicated-servers/import-keys-control-panel), wählen Sie den gewünschten Schlüssel aus dem Dropdown-Menü `SSH-Schlüssel für die Vorinstallation` aus.

<img className="thumbnail" alt="Fenster VPS reinstallieren in der OVHcloud Konsole" src="/images/bare-metal-cloud/virtual-private-servers/understand-vps-control-panel/console/reinstall.png" loading="lazy" />

Weitere Informationen zu diesem Thema finden Sie in unseren Anleitungen:

- [Erstellen und Verwenden von Authentifizierungsschlüsseln für SSH-Verbindungen zu OVHcloud Servern](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutorial - Wie Sie PuTTY für SSH-Verbindungen und -Authentifizierung verwenden](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

Wenn Sie im Dropdown-Menü `SSH-Schlüssel für die Vorinstallation` einen gespeicherten Schlüssel ausgewählt haben und kein Passwort zum Verbinden benötigen, aktivieren Sie das Kontrollkästchen `Ich möchte die Zugangsdaten zu meinem VPS nicht per E-Mail erhalten.` in diesem Fenster.

:::warning
Die Neuinstallation formatiert alle Disks des Servers. Es wird dringend empfohlen, vor dem Fortfahren einen Snapshot Ihres VPS zu erstellen, damit Sie im Falle eines Problems zum vorherigen Zustand zurückkehren können.

:::


:::info
**Lizenzen**

Einige Betriebssysteme oder proprietäre Plattformen, wie z. B. Plesk oder cPanel, benötigen Lizenzen, die zusätzliche Kosten verursachen. Lizenzen können über die OVHcloud Konsole verwaltet werden: Klicken Sie in der oberen Navigationsleiste auf <code className="action">Bare Metal Cloud</code> und dann im linken Menü auf <code className="action">Lizenzen</code>.

Um ein **Windows**-Betriebssystem auf einem VPS zu betreiben, müssen Sie es bereits **im Bestellprozess** ausgewählt haben. Ein VPS mit einem anderen Betriebssystem kann nicht über die oben beschriebene Methode mit Windows neu installiert werden.

:::


Der Neuinstallationsvorgang kann einige Minuten dauern.
