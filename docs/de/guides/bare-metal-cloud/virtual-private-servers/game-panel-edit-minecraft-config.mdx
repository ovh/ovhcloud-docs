## Ziel

Das Game Panel stellt die Konfiguration des Minecraft-Servers direkt in der Oberfläche bereit. Grundlegende Optionen wie Spielmodus und Schwierigkeitsgrad sind über ein grafisches Formular verfügbar, und über die erweiterten Einstellungen können Sie die Datei `server.properties` für die volle Kontrolle direkt bearbeiten.

**Diese Anleitung erläutert, wie Sie die Konfiguration eines Minecraft-Servers im Game Panel bearbeiten.**

## Voraussetzungen

- Sie verfügen über einen [VPS](https://www.ovhcloud.com/en-gb/vps/) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben einen Minecraft-Server im Game Panel bereitgestellt. Weitere Informationen finden Sie unter [Einen Minecraft-Server über das Game Panel bereitstellen](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

## In der praktischen Anwendung

### Schritt 1 – Die Servereinstellungen öffnen

Suchen Sie auf der Hauptseite des Game Panels den Minecraft-Server, den Sie konfigurieren möchten. Klicken Sie in der Spalte <code className="action">Management</code> auf <code className="action">Settings</code>.

<img className="thumbnail" alt="Minecraft-Server mit hervorgehobenem Settings-Button" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-server-settings.png" loading="lazy" />

### Schritt 2 – Den Tab Game Config öffnen

Wählen Sie im Bereich **Server Settings** in der linken Seitenleiste <code className="action">Game Config</code> aus.

<img className="thumbnail" alt="Tab Game Config im Bereich Server Settings" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-game-config.png" loading="lazy" />

### Schritt 3 – Ihr Spiel konfigurieren

Im Bereich **Game Configuration** können Sie:

- **automatische Updates** aktivieren oder deaktivieren.
- den **Spielmodus**, den **Schwierigkeitsgrad** und weitere Gameplay-Optionen anpassen.

### Schritt 4 – Erweiterte Einstellungen bearbeiten

Der Bereich **Advanced Configuration** bietet Ihnen direkten Zugriff auf die Datei `server.properties` und damit mehr Kontrolle als die grundlegenden Optionen der Oberfläche.

<img className="thumbnail" alt="Bereich Advanced Configuration mit dem server.properties-Editor" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-advanced-config.png" loading="lazy" />

:::info
Die vollständige Liste der `server.properties`-Schlüssel mit Beschreibungen, Standardwerten und zulässigen Bereichen finden Sie auf der [offiziellen Minecraft-Wiki-Seite zu server.properties](https://minecraft.wiki/w/Server.properties).
:::


Häufige Schlüssel, die Sie möglicherweise anpassen möchten:

| Schlüssel | Beschreibung | Standardwert |
|-----|-------------|---------|
| `gamemode` | Standardspielmodus (`survival`, `creative`, `adventure`, `spectator`) | `survival` |
| `difficulty` | Schwierigkeitsgrad des Servers (`peaceful`, `easy`, `normal`, `hard`) | `easy` |
| `max-players` | Maximale Anzahl gleichzeitiger Spieler | `20` |
| `motd` | In der Serverliste angezeigte Nachricht | `A Minecraft Server` |
| `online-mode` | Beschränkt den Beitritt auf authentifizierte Minecraft-Accounts | `true` |
| `view-distance` | Serverseitige Renderdistanz in Chunks (3–32) | `10` |
| `simulation-distance` | Distanz für Entity-Updates in Chunks (3–32) | `10` |
| `white-list` | Beschränkt Verbindungen auf Spieler der Whitelist | `false` |
| `hardcore` | Aktiviert den Hardcore-Modus | `false` |
| `pvp` | Aktiviert Spieler-gegen-Spieler-Schaden | `true` |

:::warning
Einige Schlüssel (wie `level-seed`, `level-type`, `generator-settings`) werden nur bei der Generierung der Welt wirksam. Eine Änderung in einer bestehenden Welt hat keine Auswirkung.
:::


### Schritt 5 – Speichern und neu starten

Starten Sie nach dem Speichern Ihrer Änderungen den Minecraft-Server über das Game Panel neu, damit die neue Konfiguration wirksam wird.
