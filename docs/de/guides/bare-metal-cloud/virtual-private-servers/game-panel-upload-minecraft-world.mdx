## Ziel

Mit dem OVHcloud Game Panel können Sie eine benutzerdefinierte Minecraft-Welt hochladen, indem Sie Dateien mit dem File Manager übertragen und die Konfiguration des Weltordners anpassen.

**Diese Anleitung erläutert, wie Sie eine benutzerdefinierte Welt auf Ihren Minecraft-Server im OVHcloud Game Panel hochladen.**

## Voraussetzungen

- Sie verfügen über einen [VPS](https://www.ovhcloud.com/de/vps/) in Ihrem OVHcloud Account mit aktivierter Game-Panel-Funktion.
- Sie haben einen Minecraft-Server im Game Panel bereitgestellt. Lesen Sie hierzu [Einen Minecraft-Server im Game Panel bereitstellen](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

:::warning
Stellen Sie sicher, dass Ihr Minecraft-Server **gestoppt** ist, bevor Sie eine der folgenden Aktionen durchführen.
:::


## In der praktischen Anwendung

### Schritt 1 – Den File Manager öffnen

Klicken Sie bei Ihrem Minecraft-Server auf <code className="action">Settings</code> und öffnen Sie dann den Tab <code className="action">File Manager</code>.

### Schritt 2 – Den Weltordner finden

Navigieren Sie im File Manager zu:

```
data > serverfiles
```

In diesem Verzeichnis sehen Sie einen Ordner mit dem Namen `world`. Dieser Ordner enthält Ihre aktuelle Minecraft-Karte und wird standardmäßig erstellt.

<img className="thumbnail" alt="Der standardmäßige Weltordner in der Dateistruktur des Servers" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder.png" loading="lazy" />

### Schritt 3 – Den Server für Ihre neue Karte vorbereiten

Bevor Sie Ihre eigene Karte hochladen, müssen Sie den Ordnernamen `world` freigeben. Sie haben drei Möglichkeiten:

- **Löschen Sie ihn** mit der Aktion <code className="action">Delete</code>, wenn Sie ihn nicht mehr benötigen.
- **Benennen Sie ihn um** mit der Aktion <code className="action">Rename</code>, um ihn als Backup aufzubewahren.
- **Laden Sie ihn lokal herunter** mit der Aktion <code className="action">Download</code>.

### Schritt 4 – Ihre benutzerdefinierte Karte hochladen

Klicken Sie im File Manager, während Sie sich in `data > serverfiles` befinden, auf <code className="action">Upload files</code> oder ziehen Sie Ihren Kartenordner per Drag-and-drop in die Dateiliste.

### Schritt 5 – Den Namen der Welt konfigurieren (falls erforderlich)

Wenn Ihr Kartenordner nicht den Namen `world` trägt, müssen Sie die Serverkonfiguration aktualisieren:

1. Kehren Sie zum Game Panel zurück.
2. Öffnen Sie die <code className="action">Settings</code> Ihres Servers.
3. Navigieren Sie zum Tab <code className="action">Game Config</code>.
4. Suchen Sie die Option **World folder name**.
5. Geben Sie den exakten Namen Ihres Kartenordners ein.

<img className="thumbnail" alt="Konfiguration des Namens des Weltordners in Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder-name-config.png" loading="lazy" />

:::info
**Mehrere Karten verwenden**: Sie können mehrere Karten auf Ihrem Server speichern und einfach zwischen ihnen wechseln. Ändern Sie den **World folder name** im Bereich Game Config, um eine andere Karte zu laden. Vergessen Sie nicht, den Server nach dem Ändern der Einstellung neu zu starten.
:::


### Schritt 6 – Den Server starten

Starten Sie Ihren Server über das Game Panel neu. Ihre benutzerdefinierte Minecraft-Karte ist nun einsatzbereit.
