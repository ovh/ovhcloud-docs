## Ziel

PaperMC ist eine leistungsstarke Minecraft-Server-Implementierung, die Plugins zur Erweiterung des Gameplays unterstützt. Mit dem Game Panel können Sie einen PaperMC-Server in wenigen Klicks bereitstellen und durch das Hochladen von Plugins anpassen.

**Diese Anleitung erklärt, wie Sie einen PaperMC-Server im Game Panel installieren und Plugins hinzufügen.**

## Voraussetzungen

- Sie verfügen über einen [VPS](https://www.ovhcloud.com/de/vps/) in Ihrem OVHcloud Konto, für den die Game-Panel-Funktion aktiviert ist.
- Sie haben Zugriff auf das Game Panel. Lesen Sie hierzu [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## In der praktischen Anwendung

### Schritt 1 – Einen PaperMC-Server installieren

Klicken Sie auf der Hauptseite des Game Panels auf <code className="action">Add Game Server</code>, suchen Sie **PaperMC** und klicken Sie auf <code className="action">Select</code>.

Weitere Informationen zur Server-Installation finden Sie unter [Erste Schritte mit dem Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

### Schritt 2 – Plugins herunterladen

Laden Sie Plugins von einer vertrauenswürdigen Quelle herunter, beispielsweise aus dem Repository [PaperMC Hangar](https://hangar.papermc.io/).

### Schritt 3 – Plugins mit dem File Manager hochladen

Klicken Sie auf Ihrem PaperMC-Server auf <code className="action">Settings</code> und öffnen Sie anschließend den Tab <code className="action">File Manager</code>. Wechseln Sie in den Ordner `serverfiles`, öffnen Sie das Verzeichnis `plugins` und laden Sie Ihre Plugin-Dateien über <code className="action">Upload files</code> oder per Drag-and-drop hoch.

### Schritt 4 – Den Server neu starten

Starten Sie Ihren Server über die entsprechende Schaltfläche auf der Hauptseite des Game Panels neu.

:::info
Beobachten Sie die Server-Logs, um zu bestätigen, dass der Server korrekt startet und dass die Plugins geladen werden.
:::
