## Ziel

Mit dem Game Panel können Sie einen 7 Days to Die Server mit automatisierter Installation und Portkonfiguration bereitstellen.

**Diese Anleitung erläutert, wie Sie einen 7 Days to Die Server im Game Panel bereitstellen und sich mit ihm verbinden.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben Zugriff auf das Game Panel. Lesen Sie hierzu [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Melden Sie sich an Ihrem Game Panel an. Gehen Sie zum Bereich **Game Servers** im Menü auf der linken Seite und klicken Sie auf <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Bereich Game Servers mit der Schaltfläche Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/game-servers-list.png" loading="lazy" />

### Schritt 2 – Einen 7 Days to Die Server erstellen

Wählen Sie **7 Days to Die** aus der Spieleliste aus. Ein Konfigurationsfenster wird geöffnet.

<img className="thumbnail" alt="Auswahl von 7 Days to Die aus der Spieleliste" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/select-7-days-to-die.png" loading="lazy" />

### Schritt 3 – Den 7 Days to Die Server konfigurieren

Geben Sie einen **Server Name** ein (zum Beispiel `7 Days to Die Server`). Die erforderlichen Netzwerkports werden während der Installation automatisch konfiguriert.

<img className="thumbnail" alt="Installationsformular für 7 Days to Die" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/7-days-to-die-install-form.png" loading="lazy" />

Sie können <code className="action">Advanced settings</code> aufklappen, um Optionen wie die Portzuordnung (Ports Binding) und Ressourcenlimits anzupassen. Die Standardwerte sind für die meisten Game-Server geeignet.

### Schritt 4 – Die Installation starten

Klicken Sie auf <code className="action">Install</code>. Die Bereitstellung startet automatisch. Warten Sie einige Minuten, während das Image heruntergeladen und der Server installiert wird.

### Schritt 5 – Die Installation verfolgen

Klicken Sie auf <code className="action">Log/Console</code>, um den Installationsfortschritt in Echtzeit zu verfolgen. Der Status zeigt **Installing** an.

### Schritt 6 – Überprüfen, ob der Server läuft

Überprüfen Sie, ob der Serverstatus **Running** anzeigt und ob CPU-/RAM-Aktivität sichtbar ist.

<img className="thumbnail" alt="7 Days to Die Server mit dem Status Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/7-days-to-die-running.png" loading="lazy" />

Verfügbare Aktionen:

- <code className="action">Log/Console</code>: Öffnen Sie die Konsole, um den Start zu überwachen und bei Problemen die Logs zu prüfen.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: Greifen Sie auf die Spieleinstellungen zu.

<img className="thumbnail" alt="Game-Config-Einstellungen für 7 Days to Die" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/7-days-to-die-game-config.png" loading="lazy" />

### Schritt 7 – Den Abschluss der Installation bestätigen

Sobald die Installation abgeschlossen ist, ändert sich der Status zu **Running**.

### Schritt 8 – Verbindungsinformationen abrufen

Kopieren Sie in der Spalte **Connection** der Game-Servers-Liste die IP-Adresse und den Port Ihres Servers.

### Schritt 9 – Ihrem Server in 7 Days to Die beitreten

So treten Sie aus dem Spiel bei:

1. Starten Sie **7 Days to Die** und klicken Sie auf **Join a Game**.
2. Fügen Sie die IP-Adresse und den Port aus der Spalte **Connection** ein.
3. Klicken Sie auf **Connect**.

### Bewährte Praktiken

- Konfigurieren Sie die Berechtigungen über <code className="action">User Administration</code>.
- Führen Sie regelmäßig Backups durch.
- Passen Sie Ihre Spieleinstellungen an.

:::info
Um weiterzugehen, fügen Sie Mods oder kompetitive Konfigurationen hinzu, passen Sie Tickrate- und Leistungseinstellungen an oder beschränken Sie den Zugriff mit einem Passwort oder einer Whitelist.
:::
