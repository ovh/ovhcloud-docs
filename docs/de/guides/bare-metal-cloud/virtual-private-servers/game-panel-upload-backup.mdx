## Ziel

Mit dem OVHcloud Game Panel können Sie ein Backup wiederherstellen, indem Sie ein Archiv herunterladen, es extrahieren und die Dateien mit dem File Manager hochladen.

**Diese Anleitung erläutert, wie Sie ein Backup auf Ihrem OVHcloud Game Panel Server wiederherstellen.**

## Voraussetzungen

- Sie verfügen über einen [VPS](https://www.ovhcloud.com/de/vps/) in Ihrem OVHcloud Account mit aktivierter Game-Panel-Funktion.
- Sie haben eine Game-Server-Instanz im Game Panel bereitgestellt.
- Sie verfügen über ein vorhandenes Backup. Lesen Sie hierzu [Ein Backup im Game Panel erstellen](/guides/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/).

## In der praktischen Anwendung

### Schritt 1 – Sich am Game Panel anmelden

Melden Sie sich an Ihrem Game Panel an. Wenn Sie Hilfe benötigen, lesen Sie [Sich am Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Schritt 2 – Auf die Backup-Einstellungen zugreifen

Sobald Sie angemeldet sind:

1. Wählen Sie Ihren Game Server aus.
2. Klicken Sie auf <code className="action">Settings</code>.
3. Gehen Sie zum Tab <code className="action">Backups</code>.

### Schritt 3 – Ein Backup herunterladen

Am unteren Rand der Seite finden Sie die Liste der verfügbaren Backups. Klicken Sie neben dem Backup, das Sie wiederherstellen möchten, auf <code className="action">Download</code>.

Wenn kein Backup verfügbar ist, müssen Sie zunächst eines erstellen. Lesen Sie hierzu [Ein Backup im Game Panel erstellen](/guides/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/).

<img className="thumbnail" alt="Herunterladen eines Backups aus der Liste" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-backup/download-backup.png" loading="lazy" />

### Schritt 4 – Das Backup extrahieren

Sobald das Backup heruntergeladen ist, extrahieren Sie das Archiv auf Ihrem Computer. Der extrahierte Inhalt enthält das Verzeichnis `serverfiles`.

### Schritt 5 – Den Server stoppen

Bevor Sie fortfahren, stellen Sie sicher, dass Ihr Game Server über das Game Panel vollständig gestoppt ist. Dies verhindert eine Beschädigung der Dateien oder Konflikte während der Wiederherstellung.

### Schritt 6 – Den File Manager öffnen

Klicken Sie bei Ihrem Server auf <code className="action">Settings</code>, öffnen Sie dann den Tab <code className="action">File Manager</code> und suchen Sie den Ordner `serverfiles`.

<img className="thumbnail" alt="Das Verzeichnis serverfiles auf dem Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-backup/serverfiles.png" loading="lazy" />

Bevor Sie das Backup hochladen, sollten Sie eine der folgenden Aktionen durchführen:

- **Löschen Sie ihn** mit der Aktion <code className="action">Delete</code>, wenn Sie ihn nicht mehr benötigen.
- **Benennen Sie ihn um** mit der Aktion <code className="action">Rename</code>, um ihn als Backup aufzubewahren.
- **Laden Sie ihn lokal herunter** mit der Aktion <code className="action">Download</code>.

### Schritt 7 – Die Backup-Dateien hochladen

Klicken Sie im File Manager auf <code className="action">Upload files</code> oder ziehen Sie den lokalen Ordner `serverfiles` aus dem extrahierten Backup per Drag-and-drop in die Dateiliste.

Für die meisten Spiele genügt es, den Ordner `serverfiles` wiederherzustellen. Einige Spiele speichern Konfigurationsdateien jedoch möglicherweise an anderen Orten. Wenn die Spielkonfiguration geändert wurde, wird empfohlen, auch den Ordner `config-lgsm` wiederherzustellen, sofern verfügbar.

### Schritt 8 – Den Server starten

Sobald der Upload abgeschlossen ist, starten Sie Ihren Server über das Game Panel neu. Ihr Server sollte nun mit der wiederhergestellten Backup-Umgebung laufen.
