## Ziel

Mit dem Game Panel können Sie in wenigen Schritten einen DayZ-Server bereitstellen. Das Panel übernimmt die Installation automatisch, einschließlich der Steam-Authentifizierung und der Konfiguration der Netzwerkports.

**In dieser Anleitung erfahren Sie, wie Sie über das Game Panel einen DayZ-Server bereitstellen und sich mit ihm verbinden.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben Zugriff auf das Game Panel. Weitere Informationen finden Sie unter [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Sie verfügen über einen Steam Account, um die Installation des DayZ-Servers zu authentifizieren.

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Melden Sie sich bei Ihrem Game Panel an.

Gehen Sie im Menü auf der linken Seite zum Bereich <code className="action">Game Servers</code> und klicken Sie auf <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Bereich Game Servers mit der Schaltfläche Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/add-game-server.png" loading="lazy" />

### Schritt 2 – Einen DayZ-Server erstellen

Wählen Sie **DayZ** aus der Liste der Spiele aus. Ein Konfigurationsfenster wird geöffnet.

### Schritt 3 – Den DayZ-Server konfigurieren

Im Konfigurationsfenster:

- Geben Sie einen **Server Name** ein.
- Geben Sie Ihren **Steam Username** und Ihr **Steam Password** ein.

:::warning
Es wird dringend empfohlen, hierfür ein dediziertes Steam-Konto zu verwenden und nicht Ihr persönliches Konto. Verwenden Sie ein komplexes Passwort und deaktivieren Sie auf diesem Konto die E-Mail-basierte Zwei-Faktor-Authentifizierung (Steam Guard), bevor Sie fortfahren.
:::

<img className="thumbnail" alt="DayZ-Installationsformular mit den Feldern für Servernamen und Steam-Anmeldedaten" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/install-dayz-form.png" loading="lazy" />

:::info
Die erforderlichen Netzwerkports werden während der Installation automatisch konfiguriert. Wenn dies Ihr erster DayZ-Server im Game Panel ist und die Standardports verfügbar sind, sind keine manuellen Änderungen erforderlich.
:::

Sie können <code className="action">Advanced settings</code> aufklappen, um Optionen wie die Portzuordnung (Ports Binding) und Ressourcenlimits anzupassen. Die Standardwerte sind für die meisten Game-Server geeignet.

### Schritt 4 – Die Installation starten

Klicken Sie auf <code className="action">Install</code>. Die Bereitstellung startet automatisch. Das Panel führt folgende Schritte aus:

1. Es lädt das DayZ-Server-Image herunter.
2. Es installiert die Serverdateien.

### Schritt 5 – Die Installation verfolgen

Klicken Sie auf <code className="action">Log/Console</code>, um den Installationsfortschritt in Echtzeit zu verfolgen. Während die Dateien bereitgestellt werden, zeigt der Serverstatus **Installing** an.

### Schritt 6 – Überprüfen, ob der Server läuft

Bestätigen Sie nach dem Start, dass der Serverstatus **Running** lautet. Die CPU- und RAM-Aktivität sollte im Panel sichtbar sein.

Die folgenden Steuerelemente stehen zur Verfügung:

- <code className="action">Log/Console</code> – Überwachen Sie den Serverstart und die Aktivität in Echtzeit und prüfen Sie bei Problemen die Protokolle.
- <code className="action">Settings</code> – Greifen Sie auf die Optionen zur Spielkonfiguration zu.

<img className="thumbnail" alt="DayZ-Server mit dem Status Running und den Verwaltungssteuerelementen" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/server-running.png" loading="lazy" />

Klicken Sie bei Ihrem Server auf <code className="action">Settings</code> und öffnen Sie anschließend <code className="action">Game Config</code>, um Optionen im Panel anzupassen, etwa die automatischen Updates. Für die erweiterte Konfiguration verwenden Sie den [File Manager](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/), um die Konfigurationsdatei des DayZ-Servers direkt zu bearbeiten.

<img className="thumbnail" alt="Bereich Server Settings mit den Optionen Game Config und File Manager" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/game-config.png" loading="lazy" />

### Schritt 7 – Den Abschluss der Installation bestätigen

Sobald die Installation abgeschlossen ist, ändert sich der Status zu **Running**. Ihr DayZ-Server ist nun bereit, Verbindungen anzunehmen.

### Schritt 8 – Verbindungsinformationen abrufen

Kopieren Sie in der Spalte **Connection** der Liste der Game Servers die IP-Adresse und den Port Ihres Servers.

<img className="thumbnail" alt="Liste der Game Servers mit hervorgehobener Verbindungs-IP und Port" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/connection-details.png" loading="lazy" />

### Schritt 9 – Ihrem Server in DayZ beitreten

So treten Sie über den DayZ-Client bei:

1. Starten Sie **DayZ**.
2. Gehen Sie zu **Server** und klicken Sie auf **Direct connect**.
3. Fügen Sie die IP-Adresse und den Port aus der Spalte **Connection** ein.
4. Klicken Sie auf **Connect**.
