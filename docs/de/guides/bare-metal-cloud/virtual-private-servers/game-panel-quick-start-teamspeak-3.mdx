## Ziel

Mit dem Game Panel können Sie in wenigen Minuten einen TeamSpeak 3-Voiceserver bereitstellen und konfigurieren – ohne Kommandozeile oder Systemkenntnisse.

**In dieser Anleitung erfahren Sie, wie Sie über das Game Panel einen TeamSpeak 3-Server bereitstellen und sich mit ihm verbinden.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben Zugriff auf das Game Panel. Weitere Informationen finden Sie unter [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Sie haben einen TeamSpeak 3-Client auf Ihrem Rechner installiert, um die Verbindung zu testen.

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Klicken Sie in Ihrem Game-Panel-Dashboard auf <code className="action">Add Game Server</code>.

### Schritt 2 – Einen TeamSpeak 3-Server erstellen

Suchen Sie in der Liste der verfügbaren Spiele nach **TeamSpeak 3** und wählen Sie es aus. Ein Konfigurationsfenster wird geöffnet.

<img className="thumbnail" alt="Auswahl von TeamSpeak 3 aus der Liste der Spiele" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/select-teamspeak-3.png" loading="lazy" />

### Schritt 3 – Den TeamSpeak 3-Server konfigurieren

Eine Konfigurationsseite wird geöffnet. Die Standardwerte sind für einen sofortigen Start einsatzbereit, Sie können sie jedoch an Ihre Anforderungen anpassen.

Zu den verfügbaren Einstellungen, die Sie ändern können, gehören:

- <code className="action">Server Name</code>: Geben Sie Ihrer Instanz einen Namen (z. B. `My TS3 server`).
- <code className="action">Network Ports</code>: Automatisch vorkonfiguriert:
    - `9987` (UDP) – Sprache
    - `10011` (TCP) – ServerQuery
    - `30033` (TCP) – Dateiübertragung

<img className="thumbnail" alt="Konfiguration der Netzwerkports für TeamSpeak 3" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-network-ports.png" loading="lazy" />

:::info
Sie können diese Einstellungen ändern, sie sind jedoch nicht erforderlich, um den Server zu starten.
:::

Sie können <code className="action">Advanced settings</code> aufklappen, um Optionen wie die Portzuordnung (Ports Binding) und Ressourcenlimits anzupassen. Die Standardwerte sind für die meisten Game-Server geeignet.

### Schritt 4 – Die Installation starten

Sobald Sie die Konfiguration überprüft haben, klicken Sie auf <code className="action">Install</code>, um die Bereitstellung zu starten.

<img className="thumbnail" alt="Installationskonfigurationsformular für TeamSpeak 3 mit der Schaltfläche Select" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-install-form.png" loading="lazy" />

### Schritt 5 – Die Installation verfolgen

Die Bereitstellung startet automatisch. Lassen Sie die Installation laufen, ohne die Seite zu schließen.

Verfolgen Sie den Vorgang in Echtzeit, indem Sie auf <code className="action">Log/Console</code> klicken, um die Installationsmeldungen anzuzeigen.

<img className="thumbnail" alt="Protokollbereich der TeamSpeak 3-Installation" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-installation-logs.png" loading="lazy" />

### Schritt 6 – Überprüfen, ob der Server läuft

Bestätigen Sie, dass Ihr Server den Status **Running** anzeigt.

<img className="thumbnail" alt="TeamSpeak 3-Server mit dem Status Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-running.png" loading="lazy" />

### Schritt 7 – Den Abschluss der Installation bestätigen

Sobald die Installation abgeschlossen ist, ändert sich der Status zu **Running**. Ihr Server ist online.

### Schritt 8 – Verbindungsinformationen abrufen

Rufen Sie die IP-Adresse und den Port aus der Spalte <code className="action">Connection</code> der Game-Servers-Liste ab, um sich über den TeamSpeak 3-Client zu verbinden.

### Schritt 9 – Ihrem Server in TeamSpeak 3 beitreten

Im TeamSpeak 3-Client:

1. Klicken Sie auf <code className="action">Connections</code> > <code className="action">Connect</code>.
2. Geben Sie die in der Spalte **Connection** der Game-Servers-Liste angezeigte Adresse ein.
