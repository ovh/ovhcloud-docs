## Ziel

Mit dem OVHcloud Game Panel können Sie Backups Ihrer Game-Server-Instanzen erstellen, sodass Sie Ihren Server bei Bedarf in einen früheren Zustand zurückversetzen können.

**Diese Anleitung erläutert, wie Sie im OVHcloud Game Panel ein Backup Ihres Game-Servers erstellen.**

## Voraussetzungen

- Sie verfügen über einen [VPS](https://www.ovhcloud.com/de/vps/) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben eine Game-Server-Instanz im Game Panel bereitgestellt. Weitere Informationen finden Sie unter [Erste Schritte mit dem Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

## In der praktischen Anwendung

### Schritt 1 – Sich beim Game Panel anmelden

Melden Sie sich bei Ihrem Game Panel an. Wenn Sie Hilfe benötigen, lesen Sie [Sich beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Schritt 2 – Auf die Backup-Einstellungen zugreifen

Sobald Sie angemeldet sind:

1. Wählen Sie Ihren Game-Server aus.
2. Klicken Sie auf <code className="action">Settings</code>.
3. Wechseln Sie zum Tab <code className="action">Backups</code>.

<img className="thumbnail" alt="Der Tab mit den Backup-Einstellungen" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/backup-tab.png" loading="lazy" />

### Schritt 3 – Ein Backup erstellen

Klicken Sie auf <code className="action">Create backup now</code>.

<img className="thumbnail" alt="Erstellen eines Backups mit der Option zum Stoppen des Servers" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/create-backup.png" loading="lazy" />

Sobald das Backup abgeschlossen ist, steht die Datei in der Liste **Available Backups** weiter unten auf demselben Tab zum Download bereit.

### Schritt 4 – Eine Aufbewahrungsrichtlinie festlegen

Unter **Retention Policy** können Sie steuern, wie viele Backups aufbewahrt werden und wie lange:

- **Keep the last backups**: die maximale Anzahl der aufzubewahrenden Backups (geben Sie `0` ein, um alle aufzubewahren).
- **Keep backups for days**: wie lange Backups aufbewahrt werden (geben Sie `0` ein, um sie unbegrenzt aufzubewahren).
- **Stop server before backup**: stoppt den Server während der Erstellung des Backups, um konsistente Sicherungen zu gewährleisten.

:::info
Wir empfehlen, die Option **Stop server before backup** aktiviert zu lassen, um konsistente Sicherungen zu gewährleisten.
:::

Klicken Sie auf <code className="action">Save retention settings</code>, um Ihre Änderungen zu übernehmen.
