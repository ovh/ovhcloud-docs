## Ziel

Mit dem Game Panel können Sie in wenigen Schritten einen Team Fortress 2-Server bereitstellen. Das Panel übernimmt die Installation automatisch, einschließlich der Portkonfiguration.

**In dieser Anleitung erfahren Sie, wie Sie über das Game Panel einen Team Fortress 2-Server bereitstellen und sich mit ihm verbinden.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben Zugriff auf das Game Panel. Weitere Informationen finden Sie unter [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Melden Sie sich bei Ihrem Game Panel an.

### Schritt 2 – Eine neue Serverinstanz erstellen

Klicken Sie auf <code className="action">Add Game Server</code> und wählen Sie **Team Fortress 2** aus.

<img className="thumbnail" alt="Auswahl von Team Fortress 2 aus der Liste der Spiele" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/select-tf2.png" loading="lazy" />

:::info
Wenn dies Ihr erster Team Fortress 2-Server im Game Panel ist und der Standard-Spielport verfügbar ist, werden alle erforderlichen Ports automatisch konfiguriert. Es ist keine manuelle Einrichtung erforderlich.
:::


### Schritt 3 – Den Installationsfortschritt überwachen

Sobald die Installation startet, wird ein Bestätigungsbildschirm angezeigt. Klicken Sie auf <code className="action">Log/Console</code>, um den Installationsfortschritt in Echtzeit zu verfolgen.

Während der Server installiert wird, zeigt der Status **Installing** an. Verfolgen Sie den detaillierten Fortschritt direkt im Protokollbereich.

<img className="thumbnail" alt="Überwachung der Team Fortress 2-Serverinstallation im Protokollbereich" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-installation-logs.png" loading="lazy" />

### Schritt 4 – Den Abschluss der Installation bestätigen

Sobald die Installation abgeschlossen ist, wechselt der Serverstatus zu **Running**.

<img className="thumbnail" alt="Team Fortress 2-Server mit dem Status Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-running.png" loading="lazy" />

### Schritt 5 – Verbindungsinformationen abrufen

Sobald der Status Ihres Servers **Running** lautet, kopieren Sie die Verbindungsinformationen aus dem Game Panel.

### Schritt 6 – In Team Fortress 2 Ihrem Server beitreten

Fügen Sie Ihren Server zunächst zu Ihren Steam-Favoriten hinzu:

1. Gehen Sie in **Steam** zu **View** > **Game Servers**.
2. Öffnen Sie den Tab **Favorites** und klicken Sie auf **Add a server**.
3. Fügen Sie die IP-Adresse und den Port aus der Spalte **Connection** ein und klicken Sie anschließend auf **OK**.

Starten Sie dann **Team Fortress 2** und klicken Sie bei Ihrem favorisierten Server auf **Connect**.
