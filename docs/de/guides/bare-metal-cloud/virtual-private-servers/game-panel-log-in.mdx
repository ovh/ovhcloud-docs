## Ziel

Das OVHcloud Game Panel bietet eine eigene Oberfläche zur Verwaltung Ihrer Game-Server. Um es zu nutzen, müssen Sie sich mit Ihren Zugangsdaten anmelden.

**Diese Anleitung erklärt, wie Sie sich beim OVHcloud Game Panel anmelden und wie Sie ein verlorenes Passwort wiederherstellen.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie verfügen über den Zugangslink zum Game Panel, der Ihnen bei der Installation bereitgestellt wurde.

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Rufen Sie Ihr Game Panel auf. Der Zugangslink hängt von der Domain ab, die Sie bei der Installation ausgewählt haben.

<img className="thumbnail" alt="Die Anmeldeseite des Game Panels" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login.png" loading="lazy" />

### Schritt 2 – Anmelden

Geben Sie Ihren Benutzernamen und das zugehörige Passwort ein und klicken Sie anschließend auf <code className="action">Sign In</code>, um sich beim Game Panel anzumelden.

<img className="thumbnail" alt="Eingabe der Zugangsdaten auf der Anmeldeseite" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login-form.png" loading="lazy" />

### Ein verlorenes Passwort wiederherstellen

#### Konten ohne Administratorrechte

Wenn ein Passwort verloren gegangen ist, bitten Sie einen Administrator, es zurückzusetzen. Weitere Informationen finden Sie unter [Benutzer im Game Panel verwalten](/guides/bare-metal-cloud/virtual-private-servers/game-panel-manage-users/).

#### Super-Admin-Konto

Wenn das Passwort des Super-Admin-Kontos verloren gegangen ist, können Sie es zurücksetzen, indem Sie sich per SSH mit dem Host-Rechner verbinden, in den Deploy-Ordner der Installation wechseln und den folgenden Befehl ausführen. Wenn Sie mit SSH-Verbindungen nicht vertraut sind, lesen Sie [SSH-Verbindungen verwenden](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction/).

```bash
sudo bash tools/reset-admin-password.sh
```

Erwartete Ausgabe:

```console
New admin password: XXXXXXXXXX
Confirm new admin password: XXXXXXXXXX
[INFO] Updating the root user password in the database...
[INFO] Rotating JWT secret...
[INFO] Recreating the backend to invalidate existing sessions...
[INFO] Admin password reset complete for user: admin
```

Verbinden Sie sich mit dem neuen Admin-Passwort erneut mit der Anwendung.

:::warning
Bei diesem Vorgang werden alle derzeit verbundenen Benutzer getrennt.
:::
