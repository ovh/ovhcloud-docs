## Ziel

Mit dem OVHcloud Game Panel können Sie Game-Server für eine Vielzahl beliebter Titel bereitstellen und verwalten. Dank der übersichtlichen Oberfläche und der automatisierten Tools können Sie Instanzen starten, Konfigurationen anpassen und die Leistung überwachen.

Gründe für das OVHcloud Game Panel:

- **Einfache Bedienung**: Konzipiert sowohl für Einsteiger als auch für erfahrene Anwender.
- **Automatisierte Bereitstellung**: Richten Sie Server schnell ein und warten Sie diese.
- **Multi-Game-Unterstützung**: Betreiben Sie mehrere Game-Server auf einem einzigen VPS.
- **Ressourcen-Transparenz**: Behalten Sie die volle Kontrolle über die Systemleistung.

Mit der OVHcloud Infrastruktur wird das Hosten von Game-Servern unkompliziert und zuverlässig. Egal, ob Sie Sessions auf Rust, ARK, Minecraft, Counter-Strike oder anderen Titeln betreiben: Dieser Leitfaden bietet Ihnen die Grundlage, um Ihre Server effizient zu starten und zu verwalten.

**Diese Anleitung führt Sie durch die ersten Schritte mit dem OVHcloud Game Panel.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Lokalisieren Sie auf Ihrer [VPS-Verwaltungsseite](https://manager.eu.ovhcloud.com/#/dedicated/vps) die mit Ihrem Server verknüpfte Game-Management-Funktion und klicken Sie auf <code className="action">Open Panel</code>, um auf die Oberfläche des Game Panels zuzugreifen.

<img className="thumbnail" alt="Das Haupt-Dashboard des Game Panels" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/game-panel-dashboard.png" loading="lazy" />

### Schritt 2 – Ihren ersten Game-Server bereitstellen

Wählen Sie im Dashboard der Game-Server die Option zum Hinzufügen einer neuen Instanz aus.

<img className="thumbnail" alt="Auswahl eines Spiels aus der verfügbaren Liste" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/game-selection-list.png" loading="lazy" />

Wählen Sie das Spiel, das Sie hosten möchten, aus der verfügbaren Liste (mehr als 140 Spiele) aus und klicken Sie auf <code className="action">Select</code>. Die Konfiguration kann je nach Spiel variieren.

- Vergeben Sie einen Namen für Ihren Server.
- Richten Sie bei Bedarf Ports ein.
- Starten Sie den Bereitstellungsvorgang.

Das Panel lädt alle erforderlichen Dateien automatisch herunter und konfiguriert sie. Sie können den Installationsfortschritt direkt im Log-Tab verfolgen.

<img className="thumbnail" alt="Installationsfortschritt im Log-Tab" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/deployment-progress.png" loading="lazy" />

### Schritt 3 – Ihren Server verwalten

Nach der Bereitstellung bietet Ihnen das Panel die folgenden Steuerungsmöglichkeiten für Ihren Game-Server:

- **Start/Stop/Restart**: Server starten, stoppen oder neu starten.
- **Edit**: Den Servernamen bearbeiten.
- **Copy the IP**: Die IP-Adresse kopieren.
- **View resource consumption**: Den Ressourcenverbrauch anzeigen (CPU, RAM, Festplatte und Netzwerk).
- **Access logs and console**: Auf Logs und Konsole zugreifen.
- **Delete**: Den Server löschen.

<img className="thumbnail" alt="Oberfläche zur Serververwaltung mit Statussteuerung" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/server-management.png" loading="lazy" />

### Schritt 4 – Spieleinstellungen konfigurieren

Je nach Spiel können Sie Optionen konfigurieren, indem Sie auf die Schaltfläche <code className="action">Settings</code> klicken. Die folgenden Tabs stehen zur Verfügung:

- **Game Config**: Passen Sie spielspezifische Parameter an, die sich auf das Gameplay auswirken.
- **File Manager**: Durchsuchen und bearbeiten Sie Serverdateien.
- **Backups**: Richten Sie Backups und deren Aufbewahrung für Ihren Game-Server ein.
- **Scheduled Tasks**: Automatisieren Sie wiederkehrende Aktionen auf Ihrem Server.
- **Terminal**: Greifen Sie auf eine vollständige Shell innerhalb des Server-Containers zu.
- **Container Config**: Verwalten Sie das Container-Image, die Ports, Umgebungsvariablen, Volumes und Ressourcenlimits.

:::warning
Das Terminal gewährt vollständigen Shell-Zugriff innerhalb des Server-Containers. Eine unsachgemäße Nutzung kann den Game-Server beschädigen, Dateien löschen oder sensible Daten offenlegen. Verwenden Sie es mit Vorsicht.
:::


<img className="thumbnail" alt="Spielspezifisches Konfigurationspanel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/game-settings.png" loading="lazy" />

### Schritt 5 – Leistung überwachen

Der Monitoring-Bereich zeigt den Zustand Ihres Game-Servers an:

- Überwachen Sie die Auslastung von **CPU, RAM, Festplatte und Netzwerk**.
- Prüfen Sie den **allgemeinen Serverzustand**.

<img className="thumbnail" alt="Dashboard zur Leistungsüberwachung" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/monitoring-dashboard.png" loading="lazy" />

### Schritt 6 – Benutzer verwalten

Die Benutzerverwaltung steuert und individualisiert den Zugriff auf Ihre Game-Server. Ausführliche Informationen finden Sie unter [Benutzer im Game Panel verwalten](/guides/bare-metal-cloud/virtual-private-servers/game-panel-manage-users/).

Über diese Oberfläche können Sie Benutzerkonten erstellen und verwalten, den Zugriff aktivieren oder deaktivieren und Zugangsdaten zuweisen. Jedem Benutzer können anschließend spezifische Berechtigungen erteilt werden, sowohl auf globaler Ebene als auch pro Server.

**Berechtigungen auf globaler Ebene:**

- Verwaltung anderer Benutzer.
- Installation von Servern.

**Berechtigungen auf Serverebene:**

Vordefinierte Rollen (Viewer, Operator oder Vollzugriff) oder benutzerdefinierte Berechtigungen, darunter:

- Zugriff auf die Serverkonsole.
- Starten, Stoppen oder Neustarten des Servers.
- Verwaltung von Spiel-Updates.
- Lesen und Bearbeiten von Dateien.
- Verwaltung von Backups (erstellen, wiederherstellen, herunterladen, löschen).
- Zugriff auf Logs.
- Zugriff auf das Container-Terminal.

So greift jeder Administrator nur auf die Funktionen zu, die er benötigt, was die Sicherheit und die betriebliche Effizienz verbessert. Dies ist besonders nützlich für Teams, die mehrere Server verwalten oder gemeinsam an Game-Hosting-Projekten arbeiten.
