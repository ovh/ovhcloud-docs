## Ziel

Mit dem OVHcloud Game Panel können Sie einen Palworld-Server mit automatisierter Installation und Portkonfiguration bereitstellen.

**Diese Anleitung erklärt Ihnen, wie Sie einen Palworld-Server über das OVHcloud Game Panel bereitstellen und sich mit ihm verbinden.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben Zugriff auf das Game Panel. Weitere Informationen finden Sie unter [Beim Game Panel anmelden](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## In der praktischen Anwendung

### Schritt 1 – Auf das Game Panel zugreifen

Melden Sie sich bei Ihrem OVHcloud Game Panel an. Gehen Sie im linken Menü zum Abschnitt `Game Servers` und klicken Sie auf <code className="action">Add Game Server</code>.

### Schritt 2 – Einen Palworld-Server erstellen

Wählen Sie **Palworld** aus der Spieleliste aus. Ein Konfigurationsfenster öffnet sich.

<img className="thumbnail" alt="Auswahl von Palworld aus der Spieleliste im Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/select-palworld.png" loading="lazy" />

### Schritt 3 – Den Palworld-Server konfigurieren

In diesem Abschnitt können Sie einen Namen für Ihren Server festlegen. Außerdem wird automatisch ein Administrator-Passwort generiert. Es kann direkt im Spiel verwendet werden, um Administratorrechte zu erhalten und die zugehörigen Befehle auszuführen.

:::warning
Achten Sie darauf, dieses Administrator-Passwort an einem sicheren Ort aufzubewahren.
:::

Sie können <code className="action">Advanced settings</code> aufklappen, um Optionen wie das Port-Mapping (ports binding) und die Ressourcenlimits anzupassen. Die Standardwerte eignen sich für die meisten Spieleserver.

<img className="thumbnail" alt="Konfigurationsformular des Palworld-Servers mit dem Servernamen und dem Administrator-Passwort" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/configure-server.png" loading="lazy" />

### Schritt 4 – Die Installation starten

Klicken Sie auf <code className="action">Install</code>, um die Installation zu starten. Die Bereitstellung beginnt.

### Schritt 5 – Die Installation verfolgen

Klicken Sie auf <code className="action">Log/Console</code>, um den Installationsfortschritt in Echtzeit zu verfolgen.

Während der Installation des Servers zeigt der Status **Installing** an. Verfolgen Sie den detaillierten Fortschritt im Protokollbereich.

<img className="thumbnail" alt="Verfolgung der Palworld-Server-Installation im Protokollbereich" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/installation-logs.png" loading="lazy" />

### Schritt 6 – Überprüfen, ob der Server läuft

Überprüfen Sie, ob der Serverstatus **Running** lautet und ob CPU- und RAM-Aktivität sichtbar ist. Sie können die Steuerelemente <code className="action">Log/Console</code> und <code className="action">Settings</code> verwenden, um den Server zu verwalten.

<img className="thumbnail" alt="Palworld-Server mit dem Status Running und CPU- und RAM-Aktivität" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/server-running.png" loading="lazy" />

### Schritt 7 – Den Abschluss der Installation bestätigen

Sobald die Installation abgeschlossen ist, wechselt der Serverstatus zu **Running**.

### Schritt 8 – Verbindungsinformationen abrufen

Sobald Ihr Server den Status **Running** hat, kopieren Sie die IP-Adresse und den Port aus der Spalte **Connection** der Game-Servers-Liste.

### Schritt 9 – Ihrem Server in Palworld beitreten

So treten Sie Ihrem Server über den Palworld-Client bei:

1. Öffnen Sie **Palworld** und klicken Sie auf **Join Multiplayer Game**.
2. Fügen Sie im Eingabefeld unten in der Mitte die IP-Adresse und den Port aus der Spalte **Connection** ein.
3. Klicken Sie auf **Connect**.

### Verfügbare Befehle bei Palworld

Bei einem Palworld-Server können Sie verschiedene Befehle direkt über das Eingabefeld unten im Protokoll ausführen. Hier sind einige der verfügbaren Befehle:

| Befehl | Argumente | Beschreibung |
|--------|-----------|--------------|
| `announce` | `<message>` | Sendet eine Ankündigung, die für alle verbundenen Spieler sichtbar ist. |
| `players` | - | Zeigt die Liste der aktuell mit dem Server verbundenen Spieler an. |
| `info` | - | Gibt allgemeine Informationen über den Server zurück. |
| `settings` | - | Gibt die aktuelle Serverkonfiguration zurück. |
| `metrics` | - | Zeigt verschiedene Metriken und Statistiken des Servers an. |
| `kick` | `<PlayerId or SteamId>` | Wirft einen Spieler vom Server. |
| `ban` | `<PlayerId or SteamId>` | Sperrt einen Spieler auf dem Server. |
| `unban` | `<PlayerId or SteamId>` | Hebt die Sperre eines Spielers auf. |

:::info
Haben Sie das Administrator-Passwort für das Spiel vergessen? Klicken Sie auf <code className="action">Settings</code>, öffnen Sie den Abschnitt <code className="action">Game Config</code> und ändern Sie das Passwort am Ende der Seite.
:::

### Den Server auf eine neue Spielversion aktualisieren

Standardmäßig aktualisiert sich der Server nicht automatisch, wenn eine neue Version verfügbar ist, um mögliche Kompatibilitätsprobleme oder die Unterbrechung laufender Partien zu vermeiden.

Um automatische Updates zu aktivieren, klicken Sie auf <code className="action">Settings</code>, öffnen Sie den Abschnitt <code className="action">Game Config</code> und aktivieren Sie am Ende der Seite die Option **Update on start** (standardmäßig deaktiviert). Speichern Sie und starten Sie den Server anschließend neu, damit die Änderungen wirksam werden. Der Server wendet dann automatisch jedes neue verfügbare Update an.
