## Ziel

Mithilfe eines Snapshots haben Sie die Möglichkeit, schnell und einfach ein laufendes System zu sichern, etwa bevor Änderungen vorgenommen werden, die unerwünschte oder unvorhergesehene Folgen haben können (z.B. Testen einer neuen Konfiguration oder Software). Es handelt sich jedoch nicht um eine vollständige Backup-Strategie.

**Diese Anleitung erläutert die Verwendung von Snapshots für Ihren OVHcloud VPS.**

:::info
Bevor Sie Backup-Optionen anwenden, empfehlen wir, die [Produktseiten und FAQ](/links/bare-metal/vps-options) zu Preisvergleichen und weiteren Details zu konsultieren.
:::

## Voraussetzungen

- Sie haben einen [VPS](/links/bare-metal/vps) in Ihrem Kunden-Account.

:::warning
Diese Funktion ist derzeit nicht verfügbar für VPS in [Local Zones](/links/bare-metal/vps-lz).

:::

## In der praktischen Anwendung

### Schritt 1: Snapshot-Option aktivieren

Scrollen Sie im Tab <code className="action">Übersicht</code> nach unten zum Bereich **Backup**.  
Wenn in der Zeile **Snapshot** "Aktiviert" angezeigt wird, fahren Sie direkt mit Schritt 2 fort. Wenn dort "Deaktiviert" angezeigt wird, klicken Sie unter der Zeile **Snapshot** auf den Link <code className="action">Snapshot bestellen</code>.

<img className="thumbnail" alt="Bereich Backup eines VPS in der OVHcloud Konsole mit dem Link Snapshot bestellen" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_step1b.png" loading="lazy" />

Beachten Sie im sich öffnenden Fenster die Kosteninformation und klicken Sie dann auf <code className="action">Bestellen</code>. Sie werden durch den Bestellvorgang geführt und erhalten eine Bestätigungsmail.

Um die Dienstoption zu kündigen, klicken Sie unter der Zeile **Snapshot** auf den Link <code className="action">Kündigen</code> und anschließend im Fenster **Snapshot-Option kündigen** auf <code className="action">Bestätigen</code>.

:::warning
Die Kündigung wird zum Verlängerungsdatum der Option wirksam und kann nicht rückgängig gemacht werden.
:::

<img className="thumbnail" alt="Zeile Snapshot eines VPS in der OVHcloud Konsole mit dem Link Kündigen" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_cancel.png" loading="lazy" />

### Schritt 2: Einen Snapshot erstellen

Sobald die Option aktiviert ist, klicken Sie unter der Zeile **Snapshot** auf den Link <code className="action">Snapshot erstellen</code>. Im Fenster **Snapshot erstellen** können Sie eine Beschreibung eingeben, die an Ihren Snapshot angehängt wird. Klicken Sie anschließend auf <code className="action">Bestätigen</code>.

:::warning
Während der Erstellung des Snapshots ist Ihr VPS nicht erreichbar, und ein eventuell vorhandener früherer Snapshot geht verloren.
:::

Die Dauer der Erstellung des Snapshots hängt vom verwendeten Speicherplatz ab. Aktualisieren Sie danach die Seite, um das Erstellungsdatum in der Zeile **Snapshot** des Bereichs **Backup** zu sehen.

### Schritt 3: Einen Snapshot löschen/wiederherstellen

Da immer nur ein Snapshot aktiviert sein kann, muss der vorhandene Snapshot gelöscht werden, bevor ein neuer erstellt wird. Klicken Sie dazu einfach unter der Zeile **Snapshot** auf den Link <code className="action">Snapshot löschen</code> und bestätigen Sie anschließend im angezeigten Fenster mit einem Klick auf <code className="action">Snapshot löschen</code>.

<img className="thumbnail" alt="Zeile Snapshot eines VPS in der OVHcloud Konsole mit den Snapshot-Links" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_step2.png" loading="lazy" />

Wenn Sie sicher sind, dass Sie Ihren VPS auf den Stand des Snapshots zurücksetzen möchten, klicken Sie auf <code className="action">Snapshot wiederherstellen</code> und bestätigen Sie die Aktion im Popup-Fenster. 

:::warning
Bei der Wiederherstellung des Snapshots wird die aktuelle Version Ihres VPS gelöscht und der im Snapshot festgehaltene Zustand wiederhergestellt. Dieser Vorgang kann nicht rückgängig gemacht werden.
:::

:::danger
Dabei ist zu beachten, dass der Snapshot im Zuge der Wiederherstellung gelöscht wird. Wenn Sie einen identischen Snapshot behalten möchten, ist es notwendig, einen neuen Snapshot zu erzeugen, bevor Sie Änderungen am wiederhergestellten System vornehmen.

Wenn die Snapshot-Funktion für Ihr Projekt zu eingeschränkt ist, gibt es die Option [Automatische Backups](/guides/bare-metal-cloud/virtual-private-servers/using-automated-backups-on-a-vps) als Alternative.

:::


### Snapshot herunterladen

Der aktuelle Snapshot kann über einen Download-Link abgerufen werden. Klicken Sie unter der Zeile **Snapshot** auf den Link <code className="action">Snapshot herunterladen</code>.

<img className="thumbnail" alt="Bereich Backup eines VPS in der OVHcloud Konsole mit dem Link Snapshot herunterladen" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps03.png" loading="lazy" />

:::info
Wenn Ihr VPS aus einer älteren Produktreihe stammt, erhalten Sie möglicherweise eine Fehlermeldung, da die Option für einen Legacy VPS nicht verfügbar ist. Diese älteren Dienste erkennen Sie am folgenden Namensschema: *vpsXXXX.ovh.net* (wobei *X* für eine Zahl steht). Sie können diese Server-Referenz in der Überschrift der Seite Ihres VPS in der <ManagerLink to="/">OVHcloud Konsole</ManagerLink> überprüfen.

:::

Klicken Sie im Fenster **Snapshot herunterladen** auf <code className="action">Download-Link erstellen</code>.

<img className="thumbnail" alt="Fenster Snapshot herunterladen in der OVHcloud Konsole mit dem Button Download-Link erstellen" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps04.png" loading="lazy" />

Nach einigen Sekunden wird eine Erfolgsmeldung angezeigt. Darunter können Sie den vollständigen Download-Befehl mit einem Klick kopieren und anschließend in Ihrem Terminal ausführen.

<img className="thumbnail" alt="Fenster Snapshot herunterladen in der OVHcloud Konsole mit dem erstellten Download-Befehl" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps05.png" loading="lazy" />

Die Größe des Snapshots wird ebenfalls im Bereich **Informationen** angezeigt.

Beachten Sie, dass der Download-Link nach **24 Stunden** abläuft.

Der Download-Befehl verwendet `curl` in folgendem Format:

```bash
curl "https://storage.sbg.cloud.ovh.net/v1/AUTH_f5fgh4674dd706f15f6ffgf4z667d3f4g5f05/glance/5ceg3f93-8b49-436b-aefe-4185f9fc3f78?
temp_url_sig=f508cacda60256d5f211dddf3f81130e935f0e4&temp_url_expres=1678247579" --output vps-x11x11xyy.vps.ovh.net --fail
```

Er sollte von jedem Befehlszeilen-Terminal aus funktionieren.

Wenn Sie jedoch Windows *PowerShell* verwenden, muss der Befehl wie folgt angepasst werden:

```powershell
curl -uri "https://storage.sbg.cloud.ovh.net/v1/AUTH_f5fgh4674dd706f15f6ffgf4z667d3f4g5f05/glance/5ceg3f93-8b49-436b-aefe-4185f9fc3f78?
temp_url_sig=f508cacda60256d5f211dddf3f81130e935f0e4&temp_url_expres=1678247579" -OutFile vps-x11x11xyy.vps.ovh.net
```

<img className="thumbnail" alt="snapshotvps" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/snapshot_vps06.png" loading="lazy" />

:::info
Wir empfehlen, Snapshots nicht direkt auf den VPS herunterzuladen, um die Auslastung des Speicherplatzes zu vermeiden.

Die heruntergeladene Datei kann über [OpenStack](/guides/public-cloud/compute/overview) als Image (QCOW2) in ein Public Cloud Projekt importiert werden. (Nutzungsbeispiele finden Sie z.B. in [dieser Anleitung](/guides/public-cloud/compute/upload-own-image).)

:::

 
### Optimale Vorgehensweise zur Snapshot-Erstellung

#### Konfiguration des QEMU-Agents auf einem VPS

Snapshots sind Momentaufnahmen Ihres Systems bei der Ausführung (“live snapshot”). Um die Verfügbarkeit Ihres Systems während der Erstellung des Snapshots zu gewährleisten, wird der QEMU-Agent verwendet, um das Dateisystem für diesen Vorgang vorzubereiten.

Der hierzu benötigte *qemu-guest-agent* ist bei den meisten Distributionen nicht standardmäßig installiert. Auch können lizenzbedingte Einschränkungen OVHcloud daran hindern, diese Bedingung in die Images der verfügbaren Betriebssysteme einzubeziehen. Es wird daher geraten, dies zu überprüfen, und den Agent zu installieren, falls er nicht auf Ihrem VPS aktiviert ist. Verbinden Sie sich per SSH mit Ihrem VPS und folgen Sie je nach Betriebssystem den unten stehenden Anleitungen. 

##### **Debian Distributionen (Debian, Ubuntu)**

Überprüfen Sie mit folgendem Befehl, ob das System richtig für Snapshots konfiguriert ist.

```bash
file /dev/virtio-ports/org.qemu.guest_agent.0
/dev/virtio-ports/org.qemu.guest_agent.0: symbolic link to ../vport2p1
```

Erscheint ein anderes Ergebnis (“No such file or directory”), dann installieren Sie das aktuelle Paket:

```bash
sudo apt-get update
sudo apt-get install qemu-guest-agent
```

Starten Sie den VPS neu:

```bash
sudo reboot
```

Überprüfen Sie, ob der Dienst ausgeführt wird:

```bash
sudo service qemu-guest-agent status
```

##### **Redhat Distributionen (CentOS, Fedora)**

Überprüfen Sie mit folgendem Befehl, ob das System richtig für Snapshots konfiguriert ist.

```bash
file /dev/virtio-ports/org.qemu.guest_agent.0
/dev/virtio-ports/org.qemu.guest_agent.0: symbolic link to ../vport2p1
```

Erscheint ein anderes Ergebnis (“No such file or directory”), dann installieren und aktivieren Sie den Agent:

```bash
sudo yum install qemu-guest-agent
sudo chkconfig qemu-guest-agent on
```

Starten Sie den VPS neu:

```bash
sudo reboot
```

Überprüfen Sie, ob der Dienst ausgeführt wird:

```bash
sudo service qemu-guest-agent status
```

##### **Windows**

Sie können den QEMU Guest Agent über eine MSI-Datei installieren. Diese ist auf der Webseite des *Fedora project* verfügbar: [https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/latest-qemu-ga/](https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/latest-qemu-ga/).

Überprüfen Sie, ob der Dienst ausgeführt wird. Verwenden Sie dazu folgenden *PowerShell*-Befehl:

```powershell
PS C:\Users\Administrator> Get-Service QEMU-GA

Status   Name               DisplayName
------   ----               -----------
Running  QEMU-GA            QEMU Guest Agent
```
