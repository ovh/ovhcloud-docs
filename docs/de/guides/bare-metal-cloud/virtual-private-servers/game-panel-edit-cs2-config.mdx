## Ziel

Das Game Panel stellt die Konfiguration des Counter-Strike 2 Servers direkt in der Oberfläche bereit. Grundlegende Optionen wie Servername, Karte und Spielmodus sind über ein grafisches Formular verfügbar, und Sie können zudem Server-Frameworks wie MetaMod und CounterStrikeSharp installieren.

**Diese Anleitung erläutert, wie Sie die Konfiguration eines Counter-Strike 2 Servers im Game Panel bearbeiten.**

## Voraussetzungen

- Sie verfügen über einen [VPS](/links/bare-metal/vps) oder einen [dedizierten Server](/links/bare-metal/bare-metal) in Ihrem OVHcloud Account, bei dem die Game-Panel-Funktion aktiviert ist.
- Sie haben einen Counter-Strike 2 Server im Game Panel bereitgestellt. Lesen Sie hierzu [Einen Counter-Strike 2 Server im Game Panel bereitstellen](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/).

## In der praktischen Anwendung

### Schritt 1 – Die Servereinstellungen öffnen

Suchen Sie auf der Hauptseite des Game Panels den Counter-Strike 2 Server, den Sie konfigurieren möchten. Klicken Sie in der Spalte <code className="action">Management</code> auf <code className="action">Settings</code>.

<img className="thumbnail" alt="Counter-Strike 2 Server mit hervorgehobenem Settings-Button" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-server-settings.png" loading="lazy" />

### Schritt 2 – Den Tab Game Config öffnen

Wählen Sie im Bereich **Server Settings** in der linken Seitenleiste <code className="action">Game Config</code> aus.

Im Bereich **Game Config** können Sie die wichtigsten Einstellungen Ihres Counter-Strike 2 Servers über zwei Tabs verwalten:

- **Settings**: Konfigurieren Sie die Einstellungen des Spielservers.
- **Frameworks**: Installieren und verwalten Sie unterstützte Server-Frameworks.

### Schritt 3 – Den Tab Settings konfigurieren

Im Tab <code className="action">Settings</code> können Sie die wichtigsten Parameter des Counter-Strike 2 Servers anpassen:

| Einstellung | Beschreibung |
|---------|-------------|
| Server Name | Der Name, der im Counter-Strike 2 Serverbrowser angezeigt wird. |
| Max Players | Die maximale Anzahl an Spielern, die sich gleichzeitig verbinden können. |
| Map | Die Karte, die beim Start des Servers geladen wird. Sie können auch manuell einen Kartennamen eingeben, der nicht in der Liste enthalten ist. |
| Game Type | Legt die Hauptkategorie des Spiels fest. |
| Game Mode | Legt den Spielmodus innerhalb des ausgewählten Spieltyps fest. Weitere Informationen zu den verfügbaren Modi finden Sie im [Leitfaden der Valve Developer Community](https://developer.valvesoftware.com/wiki/Counter-Strike:_Global_Offensive/Game_Modes). |
| Server Password | Verlangt von den Spielern die Eingabe eines Passworts, bevor sie dem Server beitreten können. |
| Admin Password (RCON) | Aktiviert den Zugriff über die Remote Console (RCON) und legt das Passwort fest, das für die Fernverwaltung des Servers verwendet wird. |
| Steam GSL Token | Ein Game Server Login Token (GSLT), mit dem Ihr dedizierter Server gegenüber den Steam-Diensten authentifiziert wird. Informationen zum Generieren eines Tokens finden Sie auf der [Seite zur Verwaltung von Steam Game Server Accounts](https://steamcommunity.com/dev/managegameservers). |
| VAC Anti-Cheat | Aktiviert oder deaktiviert den Valve-Anti-Cheat-Schutz (VAC) auf dem Server. |

<img className="thumbnail" alt="Der Tab Settings der Counter-Strike 2 Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-settings.png" loading="lazy" />

:::info
Speichern Sie nach dem Ändern einer dieser Einstellungen Ihre Änderungen und starten Sie den Server neu, damit sie wirksam werden.
:::


### Schritt 4 – Frameworks installieren

Im Tab <code className="action">Frameworks</code> können Sie zusätzliche Komponenten installieren, um den Funktionsumfang Ihres Counter-Strike 2 Servers zu erweitern.

- **MetaMod**: ein Server-Plugin-Framework, das als Zwischenschicht zwischen dem Spielserver und den Plugins fungiert. Es bildet die Grundlage, die von vielen erweiterten Server-Erweiterungen und Administrationswerkzeugen benötigt wird.
- **CounterStrikeSharp**: ein modernes Plugin-Framework für Counter-Strike 2, mit dem Serveradministratoren und Entwickler eigene Plugins in C# erstellen und ausführen können. Es kann Gameplay-Funktionen, Werkzeuge zur Serververwaltung und von der Community entwickelte Erweiterungen hinzufügen.

Sie können beide Frameworks direkt über das Game Panel installieren und sie später erneut installieren, um auf eine neuere Version zu aktualisieren, sobald diese verfügbar ist.

<img className="thumbnail" alt="Der Tab Frameworks mit MetaMod und CounterStrikeSharp" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-frameworks.png" loading="lazy" />

:::info
Der Server muss gestoppt sein, bevor ein Framework installiert werden kann.
:::


### Schritt 5 – Speichern und neu starten

Starten Sie nach dem Speichern Ihrer Änderungen den Counter-Strike 2 Server über das Game Panel neu, damit die neue Konfiguration wirksam wird.
