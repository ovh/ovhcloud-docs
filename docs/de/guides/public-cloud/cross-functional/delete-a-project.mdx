## Ziel

Wenn Sie Ihr Public Cloud Projekt nicht mehr benötigen, können Sie es direkt in der <ManagerLink to="/">OVHcloud Konsole</ManagerLink> löschen.

Wenn Sie Ihr Public Cloud Projekt löschen, wird eine Abschlussrechnung für den offenen Restbetrag erstellt.

:::warning
Beachten Sie, dass das Löschen eines Projekts nicht dem Deaktivieren Ihrer Public Cloud Instanzen gleichkommt. Wenn Sie ein Projekt löschen, werden die darin enthaltenen Ressourcen permanent verloren gehen. Diese Aktion kann nicht rückgängig gemacht werden.
:::

**Diese Anleitung erklärt, wie Sie ein Public Cloud Projekt löschen.**

## Voraussetzungen

- Sie haben ein [Public Cloud Projekt](/links/public-cloud/public-cloud) in Ihrem Kunden-Account.

[[cpnav:publiccloud-project-settings-console]]

## In der praktischen Anwendung

1. Klicken Sie im linken Menü Ihres Public Cloud Projekts auf <code className="action">Projektverwaltung</code>.
2. Klicken Sie auf den Tab <code className="action">Einstellungen</code>.
3. Klicken Sie im Bereich **Projekt löschen** auf <code className="action">Projekt löschen</code>.
4. Das Fenster **Projekt kündigen** informiert Sie darüber, dass alle Ihre Dienste, Ressourcen, Einstellungen und Daten gelöscht werden, mit Ausnahme der Failover-IPs, die geparkt werden. Klicken Sie auf <code className="action">Ja, kündigen</code>, um fortzufahren.

:::info
Ein Projekt mit einem Savings Plan kann nicht gelöscht werden: Der Bereich **Projekt löschen** zeigt eine Warnung an, und das Fenster bietet stattdessen <code className="action">Den Kundendienst kontaktieren</code> an. Kontaktieren Sie unser Support-Team, um dieses Projekt zu löschen.
:::

Anschließend wird eine E-Mail an Ihre Kontakt-E-Mail-Adresse gesendet, in der Sie aufgefordert werden, das Löschen des Projekts entweder zu bestätigen oder abzubrechen. Der Bestätigungslink leitet Sie zu einer Webseite weiter, auf der Sie das Passwort Ihres Accounts eingeben müssen.

Sobald Sie Ihr Passwort eingegeben und bestätigt haben, tritt Ihr Projekt in die Löschphase ein.

:::warning
Beachten Sie, dass ein Projekt, das in die Löschphase eintritt, 7 Tage lang im Aussetzungsstatus verbleibt. Das Projekt wird daher nicht sofort gelöscht. Falls die Löschung beschleunigt stattfinden muss, zum Beispiel wenn Ihre Projektquota begrenzt ist, kontaktieren Sie bitte unsere Support-Teams.

:::
