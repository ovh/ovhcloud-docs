## Ziel

Der Zugriff auf Horizon und die OpenStack API erfolgt über Benutzername/Passwort-Kombinationen, die als "OpenStack User" bezeichnet werden. Sie können so viele OpenStack User wie nötig erstellen und ihnen verschiedene Zugriffsrechte zuweisen.

Mithilfe des Horizon-Interface kann jedem Benutzer ein Passwort zugewiesen werden. Beachten Sie, dass mit dem Ändern eines Benutzer-Passworts die bisherigen Login-Daten unmittelbar deaktiviert werden.

**Diese Anleitung erklärt, wie OpenStack-Benutzer über die OVHcloud Konsole und das Horizon-Interface verwaltet werden.**

## In der praktischen Anwendung

### Erstellung eines OpenStack Benutzers

Klicken Sie im linken Menü Ihres Public Cloud Projekts auf <code className="action">Projektverwaltung</code> und dann auf den Tab <code className="action">Benutzer</code>.

Klicken Sie auf <code className="action">Benutzer erstellen</code>. Das Fenster **Benutzer erstellen** wird geöffnet.

Geben Sie im Feld **Benutzerbeschreibung** eine Beschreibung ein. Die Benutzerbeschreibung ist nicht der Benutzername des OpenStack-Benutzers, sondern eine erläuternde Bezeichnung, die Ihnen hilft, die Benutzer und deren Berechtigungen zu organisieren.

Wählen Sie im Bereich **Rollen** die Rollen aus, welche die Berechtigungen repräsentieren, die der Benutzer erhalten soll. Für jedes angehakte Kästchen erhält der Benutzer die entsprechenden Zugriffsrechte. Um die Berechtigungen der einzelnen Rollen einzusehen, klicken Sie im Tab **Benutzer** auf <code className="action">Rollenmatrix anzeigen</code>.

Klicken Sie auf <code className="action">Erstellen</code>, um den OpenStack-Benutzer zu erstellen. Das Passwort wird automatisch generiert und im Fenster **Zugangsdaten erstellt** angezeigt. Der Benutzername wird automatisch generiert und in der Benutzertabelle angezeigt.

Achten Sie darauf, das Passwort zu diesem Zeitpunkt in einem Passwortmanager zu speichern: Es wird nur einmal angezeigt und kann später nicht mehr abgerufen werden. Kopieren Sie es mit dem Button <code className="action">Kopieren</code> und klicken Sie dann auf <code className="action">Schließen</code>. Sie können jedoch jederzeit ein neues Passwort erstellen, indem Sie in der Zeile des Benutzers auf <code className="action">...</code> klicken, <code className="action">Passwort generieren</code> auswählen und dann im Fenster **Passwort generieren** auf <code className="action">Generieren</code> klicken.

Sobald der OpenStack-Benutzer erstellt ist, können Sie seine Zugangsdaten für den Login im [Horizon-Interface](/guides/public-cloud/cross-functional/introducing-horizon) verwenden, indem Sie in der Zeile des Benutzers auf <code className="action">...</code> und dann auf <code className="action">OpenStack Horizon starten</code> klicken.

### Passwörter von OpenStack-Benutzern verwalten

Nachdem Sie sich bei [OpenStack Horizon](https://horizon.cloud.ovh.net) eingeloggt haben, können Sie ein OpenStack-Passwort erstellen:

<img className="thumbnail" alt="Login Horizon" src="/images/public-cloud/cross-functional/create-and-delete-a-user/1_H_login_window.png" loading="lazy" />

Die Benutzerkennung für Horizon sehen Sie oben rechts im Horizon-Interface. Klicken Sie auf die Kennung, um im Menü alle Optionen zu sehen.  
Wählen Sie <code className="action">Settings</code> und dann links <code className="action">Change password</code>.

<img className="thumbnail" alt="Passwort ändern" src="/images/public-cloud/cross-functional/create-and-delete-a-user/2_H_pass_change_option.png" loading="lazy" />

Tragen Sie im ersten Feld Ihr aktuelles Passwort und in den beiden folgenden Feldern Ihr neues Passwort ein.

:::info
Beachten Sie beim Ändern des Passworts folgende Richtlinie:

- Das Passwort muss mindestens 8 Zeichen umfassen.
- Es darf maximal 30 Zeichen umfassen.
- Es muss mindestens einen Großbuchstaben enthalten.
- Es muss mindestens einen Kleinbuchstaben enthalten.
- Es muss mindestens eine Zahl enthalten.
- Es darf nur aus Zahlen und Buchstaben bestehen.

:::


Bestätigen Sie anschließend das neue Passwort, indem Sie auf <code className="action">Change</code> klicken.

<img className="thumbnail" alt="Neues Passwort erstellen" src="/images/public-cloud/cross-functional/create-and-delete-a-user/3_H_set_new_passord.png" loading="lazy" />

Beachten Sie, dass beim Ändern des Benutzerkonto-Passworts die bisherigen Login-Daten sofort gelöscht werden.

### Löschung eines OpenStack Benutzers

Klicken Sie im linken Menü Ihres Public Cloud Projekts auf <code className="action">Projektverwaltung</code> und dann auf den Tab <code className="action">Benutzer</code>.

Klicken Sie in der Zeile des Benutzers auf <code className="action">...</code>, wählen Sie <code className="action">Löschen</code> aus und klicken Sie dann im Fenster **Benutzer löschen** auf <code className="action">Bestätigen</code>.

:::warning
Die Löschung eines Benutzers ist endgültig und führt zur Ungültigkeit aller zugehörigen Token, auch derjenigen, deren Ablaufdatum noch nicht überschritten ist.

:::
