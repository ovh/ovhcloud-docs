**Diese Anleitung erklärt die Schritte zur Erstellung Ihres ersten Public Cloud Projekts.**

## In der praktischen Anwendung

### Erstellung des Projekts

Die ersten Schritte hängen davon ab, ob Sie bereits ein Public Cloud Projekt haben:

- **Es ist Ihr erstes Public Cloud Projekt:** Die OVHcloud Konsole öffnet die Seite **Willkommen im Public-Cloud-Ökosystem**. Nachdem Sie die Vertragsbedingungen gelesen haben, bestätigen Sie diese, indem Sie das entsprechende Kästchen im Bereich **Verträge** ankreuzen, und klicken Sie dann auf <code className="action">Das Public-Cloud-Universum entdecken</code>. Ihr Projekt wird im [Discovery-Modus](#discovery) erstellt.
- **Sie haben bereits ein Public Cloud Projekt:** Klicken Sie auf der Seite **Projekte** auf <code className="action">Neues Projekt erstellen</code>. Sie können auch oben im linken Menü auf die Auswahl <code className="action">Projekt</code> und dann auf <code className="action">Projekt erstellen</code> klicken. Auf der Seite **Public Cloud-Projekt erstellen**:
    1. Geben Sie im Feld **Projektname** einen Namen für Ihr Projekt ein.
    2. Nachdem Sie die Vertragsbedingungen gelesen haben, bestätigen Sie diese, indem Sie das entsprechende Kästchen im Bereich **Verträge** ankreuzen.
    3. Wählen Sie im Bereich **Bestätigen Sie Ihre Identität mit einem Zahlungsmittel** Ihr Zahlungsmittel aus. Wenn Sie einen Gutschein haben, geben Sie ihn im Bereich **Haben Sie einen Promo-Code?** ein und klicken Sie auf <code className="action">Hinzufügen</code>.
    4. Klicken Sie auf <code className="action">Mein Projekt erstellen</code>.

Einigen Accounts wird der Discovery-Modus nicht angeboten: Deren erstes Projekt wird ebenfalls über die Seite **Public Cloud-Projekt erstellen** erstellt.

Sobald der Erstellungsprozess abgeschlossen ist, wird Ihr neues Public Cloud Projekt in der Auswahl **Projekt** oben im linken Menü des Public Cloud Bereichs angezeigt.

Sie haben ab sofort Zugriff auf das gesamte OVHcloud Public Cloud Ökosystem. Um dieses Interface kennenzulernen, lesen Sie unsere Anleitung "[Einführung in das Public Cloud Interface](/guides/public-cloud/cross-functional/public-cloud-interface-walk-me)".

<a name="discovery"></a>

:::info
**Discovery-Modus**

Ihr erstes Public Cloud Projekt wird im `Discovery-Modus` erstellt. Das bedeutet, dass Sie die Public Cloud Produkte durchsuchen und entdecken, aber noch keine Ressourcen wie etwa Instanzen erstellen können. Solange sich dieses Projekt im Discovery-Modus befindet, können Sie auch kein weiteres Projekt erstellen: Die OVHcloud Konsole fordert Sie auf, es zuerst zu aktivieren.

Um das volle Potenzial der Public Cloud auszuschöpfen und Ihre ersten Ressourcen zu starten, aktivieren Sie Ihr Projekt:

1. Auf der Startseite Ihres Projekts erinnert Sie das Banner **Starten Sie das Deployment Ihrer Cloud-Ressourcen.** daran, dass Sie sich im Discovery-Modus befinden. Klicken Sie in diesem Banner auf <code className="action">Aktivieren</code>.
2. Klicken Sie im daraufhin geöffneten Fenster auf <code className="action">Projekt aktivieren</code>.
3. Bestätigen Sie auf der Seite **Projekt aktivieren** ein Zahlungsmittel und klicken Sie dann auf <code className="action">Projekt aktivieren</code>.

:::

### Projektaktivierung und Gratis-Testphase

Wenn Sie ein Projekt aus dem `Discovery-Modus` heraus aktivieren und ein Zahlungsmittel hinterlegen, wird Ihnen ein **Gratis-Testguthaben von 200 €** gutgeschrieben, sofern Sie dafür berechtigt sind. In diesem Fall zeigen das Banner auf der Startseite Ihres Projekts und die Seite **Projekt aktivieren** den Betrag des Angebots an.

:::info
**Bedingungen für das Gratis-Testguthaben**

- Das Guthaben wird zum Zeitpunkt der Projektaktivierung freigeschaltet und ist **einen Monat** lang gültig.
- **Berechtigt:** Alle OVHcloud Kunden, die ihr erstes Public Cloud Projekt erstellen, auch wenn sie bereits einen OVHcloud Account besitzen.
- **Nicht berechtigt:** Kunden mit einem aktuellen oder früheren Public Cloud Projekt sowie Kunden, die bereits ein Gratis-Testguthaben in Anspruch genommen haben.

Weitere Informationen finden Sie auf der Seite [OVHcloud Public Cloud Gratis-Testphase](/links/public-cloud/free-trial).
:::

:::info
**Zusätzliche Projekte über Terraform erstellen**

Sobald Sie Ihr erstes Public Cloud Projekt erstellt und ein Zahlungsmittel hinterlegt haben, können Sie weitere Projekte programmatisch mit der Terraform-Ressource `ovh_cloud_project` erstellen. Weitere Informationen finden Sie in der Anleitung [Terraform verwenden (EN)](/guides/public-cloud/cross-functional/how-to-use-terraform#creating-a-public-cloud-project).

Derzeit gibt es keinen dedizierten OVHcloud API-Endpunkt und keinen CLI-Befehl für die Projekterstellung.
:::
