## In der praktischen Anwendung

### Erstellung des Projekts

Nachdem Sie die Vertragsbedingungen gelesen haben, bestätigen Sie diese, indem Sie das entsprechende Kästchen ankreuzen und auf <code className="action">Das Public-Cloud-Universum entdecken</code> klicken.

<img className="thumbnail" alt="Projekt erstellen" src="/images/public-cloud/cross-functional/create-a-public-cloud-project/firstproject2024.png" loading="lazy" style={{ maxWidth: '400px' }} />

- Wenn Sie noch kein gültiges Zahlungsmittel in Ihrem OVHcloud Account haben, beginnt direkt der Erstellungsprozess des Public Cloud Projekts. Ihr Projekt wird dann zunächst im [Discovery-Modus](#discovery) erstellt.
- Wenn Sie bereits eine Zahlungsart in Ihrem OVHcloud Account hinterlegt haben, können Sie Ihr Public Cloud Projekt benennen und dann Ihre Zahlungsart auswählen.

<img className="thumbnail" alt="Projekt erstellen" src="/images/public-cloud/cross-functional/create-a-public-cloud-project/project-creation.png" loading="lazy" style={{ maxWidth: '400px' }} />

Sobald der Erstellungsprozess abgeschlossen ist, wird Ihr neues Public Cloud Projekt oben links im Bereich <code className="action">Public Cloud</code> Ihres OVHcloud Kundencenters angezeigt:

<img className="thumbnail" alt="Neues Projekt erstellt" src="/images/public-cloud/cross-functional/create-a-public-cloud-project/pci-interface-2025.png" loading="lazy" style={{ maxWidth: '400px' }} />

Sie haben ab sofort Zugriff auf das gesamte OVHcloud Public Cloud Ökosystem. Entdecken Sie mehr über dieses Interface in Ihrem Kundencenter in unserer Anleitung "[Einführung in das Public Cloud Interface](/guides/public-cloud/cross-functional/public-cloud-interface-walk-me)".

<a name="discovery"></a>

:::info
**Discovery-Modus**

Wenn es sich um Ihr erstes Public Cloud Projekt handelt und Sie keine Zahlungsart in Ihrem Account angegeben haben, ist Ihr Public Cloud Projekt auf den Discovery-Modus des OVHcloud Kundencenters beschränkt. Das bedeutet, dass Sie Zugang zur Public Cloud Oberfläche haben und die verfügbaren Dienste sehen können, aber noch keine Ressourcen wie etwa Instanzen erstellen können.

Um das volle Potenzial der Public Cloud auszuschöpfen und Ihre ersten Ressourcen zu verwenden, klicken Sie auf der Startseite Ihres Projekts auf <code className="action">Projekt aktivieren</code>.

<img className="thumbnail" alt="Projekt aktivieren" src="/images/public-cloud/cross-functional/create-a-public-cloud-project/activate-project.png" loading="lazy" style={{ maxWidth: '400px' }} />
:::

### Projektaktivierung und Gratis-Testphase

Wenn Sie im `Discovery-Modus` auf <code className="action">Projekt aktivieren</code> klicken und ein Zahlungsmittel hinterlegen, wird Ihnen ein **Gratis-Testguthaben von 200 €** gutgeschrieben, sofern Sie dafür berechtigt sind.

:::info
**Bedingungen für das Gratis-Testguthaben**

- Das Guthaben wird zum Zeitpunkt der Projektaktivierung freigeschaltet und ist **einen Monat** lang gültig.
- **Berechtigt:** Alle OVHcloud Kunden, die ihr erstes Public Cloud Projekt erstellen, auch wenn sie bereits einen OVHcloud Account besitzen.
- **Nicht berechtigt:** Kunden mit einem aktuellen oder früheren Public Cloud Projekt sowie Kunden, die bereits ein Gratis-Testguthaben in Anspruch genommen haben.

Weitere Informationen finden Sie auf der Seite [OVHcloud Public Cloud Gratis-Testphase](/links/public-cloud/free-trial).
:::

:::info
**Zusätzliche Projekte über Terraform erstellen**

Sobald Sie Ihr erstes Public Cloud Projekt erstellt und ein Zahlungsmittel hinterlegt haben, können Sie weitere Projekte programmatisch mit der Terraform-Ressource `ovh_cloud_project` erstellen. Weitere Informationen finden Sie in der Anleitung [Terraform verwenden (EN)](/guides/public-cloud/cross-functional/how-to-use-terraform#creating-a-public-cloud-project).

Derzeit gibt es keinen dedizierten OVHcloud API-Endpunkt und keinen CLI-Befehl für die Projekterstellung.
:::
