:::


## Ziel

Es gibt verschiedene Gründe, auf Ihrer Instanz eine Additional IP-Adresse zu konfigurieren:

- Sie verwalten mehrere Webseiten auf Ihrer Instanz.
- Sie hosten internationale Projekte.
- Sie möchten von einem Dedicated Server zu einer Public Cloud Instanz migrieren.

In der OVHcloud Konsole können Sie eine Additional IP-Adresse, die mit einem anderen OVHcloud Dienst verknüpft ist, einfach Ihrem Projekt zuordnen.

**In dieser Anleitung wird erläutert, wie Sie eine Additional IP in Ihr OVHcloud Public Cloud Projekt importieren.**

## Voraussetzungen

- Sie haben ein [Public Cloud Projekt](/links/public-cloud/public-cloud) in Ihrem Kunden-Account.
- Sie verfügen über eine [Additional IP-Adresse](/links/bare-metal/ip).

[[cpnav:publiccloud-public-ips-console]]

:::warning
Diese Funktion ist derzeit für Metal Instanzen nicht verfügbar.

:::


## In der praktischen Anwendung

Öffnen Sie im linken Menü <code className="action">Public IP</code> unter **Netzwerk**.

Öffnen Sie den Tab <code className="action">Additional IP</code> und klicken Sie auf <code className="action">Eine Additional IP importieren</code>, um alle IP-Adressen anzuzeigen, die in Ihr Public Cloud Projekt importiert werden können.

Klicken Sie in der Zeile der IP-Adresse, die Sie importieren möchten, auf das Symbol <code className="action">Diese Additional IP importieren</code> und bestätigen Sie dann mit einem Klick auf <code className="action">Importieren</code>.

Nach einigen Minuten ist der Import abgeschlossen. Öffnen Sie den Tab <code className="action">Additional IP</code>, um die importierte Additional IP-Adresse zu sehen. Aktualisieren Sie die Seite falls nötig.

Klicken Sie in der Zeile der IP-Adresse auf <code className="action">...</code> und wählen Sie <code className="action">Verbundene Instanz bearbeiten</code>. Wählen Sie im angezeigten Fenster unter **Instanz auswählen** die Instanz aus, der Ihre IP-Adresse zugewiesen werden soll.

Klicken Sie auf <code className="action">Anfügen</code>, um zu bestätigen.

:::warning
Eine Additional IP kann nicht von einer Länderzone zur anderen umgezogen werden. So kann beispielsweise eine IP-Adresse von SBG nach GRA oder RBX umgezogen werden, aber nicht nach BHS. 

:::


Ihre Additional IP-Adresse wird nun mit Ihrer Instanz verbunden.

Im nächsten Schritt muss die IP-Adresse in Ihrem Betriebssystem konfiguriert werden. Lesen Sie dazu unsere [Anleitung zur IP-Konfiguration](/guides/public-cloud/network-services/configure-additional-ip).
