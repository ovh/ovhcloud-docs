## Ziel

Aus verschiedenen Gründen kann es sein, dass Sie eine Additional IP-Adresse auf Ihren Instanzen konfigurieren müssen:

- Sie haben auf Ihrer Instanz mehrere Websites.
- Sie hosten internationale Projekte.

Um diesen Anforderungen zu entsprechen, können Sie eine Additional IP-Adresse für Ihre Public Cloud Instanzen erwerben.

Diese Additional IPs können nur für Instanzen desselben Projekts migriert werden.

**Diese Anleitung erklärt, wie Sie eine Additional IP-Adresse für Ihr OVHcloud Public Cloud Projekt erwerben können.**

## Voraussetzungen

- Sie haben mindestens eine [Public Cloud Instanz](/guides/public-cloud/compute/getting-started) in Ihrem Kunden-Account.

:::warning
Diese Funktion ist derzeit für Metal Instanzen nicht verfügbar.

:::

## In der praktischen Anwendung

Öffnen Sie im linken Menü <code className="action">Public IP</code> unter **Netzwerk**.

Öffnen Sie den Tab <code className="action">Additional IP</code> und klicken Sie auf <code className="action">Eine Additional IP bestellen</code>.

Wählen Sie im Bereich **Wählen Sie ein Land für Ihre neue Additional IP von OVHcloud aus** ein Land für die neue IP-Adresse aus.

Folgende Länder sind für die Geolokalisierung von IPs verfügbar:

|          |          |          |           |                |
|:--------:|:--------:|:--------:|:---------:|:--------------:|
| Belgien  | Finnland  | Frankreich   | Deutschland   | Tschechische Republik |
| Irland  |  Italien   | Litauen | Niederlande | Vereinigtes Königreich    |
| Portugal |  Spanien   |  Polen |  Schweiz |                 |

:::info
**Verfügbarkeit**

Es ist möglich, dass einige dieser Länder nicht aufgelistet werden, abhängig von der aktuellen Verfügbarkeit der IPv4-Adressen.
:::

:::info
**Lokalisierung**

Die Geolokalisierung referenziert ausschließlich die jeweils authoritative Organisation.

Zum Beispiel bedient [RIPE NCC](https://www.ripe.net/) Europa als die *Regional Internet Registry*.

Wenn Sie die Geolokalisierung anderweitig überprüfen möchten, wenden Sie sich direkt an die betreffenden Organisationen. OVHcloud kann Ihnen diesbezüglich keine Unterstützung gewähren.
:::

Wählen Sie anschließend im Bereich **Weisen Sie einer Instanz oder einem Netzwerk eine IP zu** Ihre Instanz unter **Zu verbindende Instanz** aus. Die IP-Adresse wird direkt mit der Instanz verbunden (Legacy-Modus, ohne Gateway). Überprüfen Sie die Zusammenfassung und klicken Sie dann auf <code className="action">Eine Additional IP bestellen</code>.

Der Bestellschein wird automatisch geöffnet, damit Sie Ihre Bestellung abschließen können.

Weitere Informationen finden Sie in unserer [Anleitung zur Verwaltung von Bestellungen](/guides/account-and-service-management/managing-billing-payments-and-services/ovh-orders).

Sie finden den Bestellschein auch im Bereich **Meine Bestellungen** Ihres Kunden-Accounts in der OVHcloud Konsole.

Im nächsten Schritt muss die IP-Adresse in Ihrem Betriebssystem konfiguriert werden. Lesen Sie dazu unsere [Anleitung zur IP-Konfiguration](/guides/public-cloud/network-services/configure-additional-ip).
