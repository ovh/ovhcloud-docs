## Ziel

Sie können Ihre Public Cloud Instanzen in der <ManagerLink to="/">OVHcloud Konsole</ManagerLink> verwalten.

**Diese Anleitung beschreibt die in der OVHcloud Konsole verfügbaren Aktionen für eine Public Cloud Instanz.**

## Voraussetzungen

- Sie verfügen über ein [Public Cloud Projekt](/links/public-cloud/public-cloud) in Ihrem OVHcloud Kunden-Account.
- Sie haben eine [Public Cloud Instanz](/guides/public-cloud/compute/getting-started) in Ihrem Projekt erstellt.

[[cpnav:publiccloud-instances-console]]

## In der praktischen Anwendung

### Das Verwaltungsinterface für Instanzen verwenden

Klicken Sie im linken Menü Ihres Public Cloud Projekts unter **Compute** auf <code className="action">Instances</code>.

Diese Seite zeigt alle Ihre Public Cloud Instanzen und einige ihrer Eigenschaften an:

- Der Name und die ID der Instanz (erforderlich für bestimmte API-Aufrufe)
- Der Standort des Rechenzentrums, d.h. die Region der Instanz
- Das Modell der Instanz
- Das Image, d.h. das auf der Instanz installierte Betriebssystem
- Die öffentlichen IP-Adressen der Instanz
- Die privaten IP-Adressen, die derzeit an die Instanz angehängt sind
- Zusätzliche Volumes (Disks), die derzeit mit der Instanz verbunden sind
- Der Status der Instanz, der anzeigt, ob sich die Instanz im Zustand `Aktiv` befindet

### Verwaltungsoptionen im Instanz-Dashboard

Klicken Sie in der Liste der Instanzen auf den Namen der betreffenden Instanz.

Sie gelangen auf den Tab <code className="action">Übersicht</code> der Instanz. Die Karte **Allgemeine Informationen** fasst die wichtigsten Details Ihrer Instanz zusammen (Modell, Region, Image, Ressourcen und Preise), neben den Karten **Verbindungsdetails**, **Öffentliches Netzwerk**, **Privates Netzwerk**, **Snapshot-Verwaltung** und **Speicherverwaltung**. Die Seite bietet außerdem die Tabs <code className="action">VNC-Konsole</code>, <code className="action">Observability</code> und <code className="action">Snapshots</code>.

Die meisten dieser Aktionen sind auch in der Liste der Instanzen über den Button <code className="action">...</code> in der Tabelle verfügbar.

#### Konfiguration einer Instanz bearbeiten

Jedes Element der Instanzkonfiguration wird im Tab <code className="action">Übersicht</code> bearbeitet:

- **Instanz umbenennen**: Bearbeiten Sie den Namen der Instanz im Seitenkopf. Sie können der Instanz einen Namen geben, um die Identifikation zu vereinfachen.
- **Image ändern**: Klicken Sie in der Karte **Allgemeine Informationen** in der Zeile **Image** auf <code className="action">Image bearbeiten</code>. Sie können ein anderes Betriebssystem für die Instanz auswählen. (Beachten Sie, dass bei der Reinstallation einer Instanz alle darauf gespeicherten Daten gelöscht werden.)
- **Modell ändern**: Klicken Sie in der Karte **Allgemeine Informationen** in der Zeile **Modell** auf <code className="action">Modell ändern</code> und wählen Sie dann auf der Seite **Modell ändern** das neue Modell aus. Weitere Informationen zu den Optionen finden Sie in [dieser Anleitung](/guides/public-cloud/compute/getting-started#schritt-4-instanz-erstellen).
- **Abrechnungszeitraum ändern**: Klicken Sie in der Karte **Allgemeine Informationen** auf <code className="action">Auf monatlich umstellen</code>, um den Abrechnungszeitraum der Instanz von stündlicher auf monatliche Abrechnung umzustellen. Weitere Informationen finden Sie in [dieser Anleitung](/guides/account-and-service-management/managing-billing-payments-and-services/changing-hourly-monthly-billing).

#### Snapshot einer Instanz erstellen

Klicken Sie in der Liste der Instanzen in der Zeile der Instanz auf <code className="action">...</code> und wählen Sie dann <code className="action">Snapshot erstellen</code>.

Weitere Informationen finden Sie in unserer Anleitung "[Snapshot einer Instanz erstellen](/guides/public-cloud/compute/save-an-instance)".

#### Instanz löschen

Klicken Sie in der Liste der Instanzen in der Zeile der Instanz auf <code className="action">...</code> und wählen Sie dann <code className="action">Löschen</code>. Sie können auch unten in der Karte **Allgemeine Informationen** des Tabs <code className="action">Übersicht</code> auf <code className="action">Löschen</code> klicken.

Diese Aktion löscht die Instanz und alle zugehörigen Daten endgültig.

Bestätigen Sie die Anfrage, indem Sie im Fenster **Instanz löschen** auf <code className="action">Instanz löschen</code> klicken.

:::warning
Das Löschen einer Instanz löscht nicht automatisch alle damit verbundenen Optionen (Storage, Snapshot, Backup, etc...). Stellen Sie sicher, dass alle anderen mit der Instanz verbundenen Optionen ebenfalls gelöscht werden, um deren Abrechnung zu stoppen.

:::


#### Volume anhängen

Klicken Sie in der Karte **Speicherverwaltung** des Tabs <code className="action">Übersicht</code> auf <code className="action">Volume anhängen</code>.

Wählen Sie dann das Volume aus, das Sie der Instanz zuordnen möchten, und klicken Sie auf <code className="action">Anhängen</code>. Nach dem Anhängen ist das Volume sofort verfügbar und kann über das Betriebssystem der Instanz eingebunden werden.

#### DNS Reverse ändern

Der Reverse DNS der öffentlichen IP-Adresse der Instanz wird zusammen mit all Ihren IP-Adressen verwaltet: Klicken Sie in der oberen Leiste der OVHcloud Konsole auf <code className="action">Bare Metal Cloud</code>, dann im linken Menü unter **Netzwerk** auf <code className="action">IP-Adressen</code>, und öffnen Sie den Tab <code className="action">Reverse DNS</code>.

Weitere Informationen finden Sie in der Anleitung "[Reverse DNS einer Instanz konfigurieren](/guides/public-cloud/compute/setup-instance-reverse)".

#### Firewall konfigurieren

Die Edge Network Firewall der öffentlichen IP-Adresse der Instanz wird zusammen mit all Ihren IP-Adressen verwaltet: Klicken Sie in der oberen Leiste der OVHcloud Konsole auf <code className="action">Bare Metal Cloud</code>, dann im linken Menü unter **Netzwerk** auf <code className="action">IP-Adressen</code>, und öffnen Sie den Tab <code className="action">Edge Firewall</code>.

Weitere Informationen finden Sie in der Anleitung "[Edge Network Firewall aktivieren und konfigurieren](/guides/bare-metal-cloud/dedicated-servers/firewall-network)".

#### Private Netzwerke verwalten

Klicken Sie in der Karte **Privates Netzwerk** des Tabs <code className="action">Übersicht</code> auf <code className="action">Mein privates Netzwerk verwalten</code>.

Weitere Informationen finden Sie in der Anleitung "[Ein privates Netzwerk mit Gateway erstellen](/guides/public-cloud/network-services/create-private-network-gateway)".

#### Netzwerk anhängen

Klicken Sie in der Karte **Privates Netzwerk** des Tabs <code className="action">Übersicht</code> auf <code className="action">Netzwerk anhängen</code>.

Wählen Sie das gewünschte Netzwerk aus der Dropdown-Liste aus und klicken Sie auf <code className="action">Bestätigen</code>.

#### Weitere Aktionen

Klicken Sie in der Karte **Allgemeine Informationen** des Tabs <code className="action">Übersicht</code> auf <code className="action">Weitere Aktionen</code>. Dieselben Aktionen sind auch in der Liste der Instanzen über den Button <code className="action">...</code> in der Zeile der Instanz verfügbar.

##### Automatischen Snapshot einer Instanz erstellen

Klicken Sie in der Liste der Instanzen in der Zeile der Instanz auf <code className="action">...</code> und wählen Sie dann <code className="action">Automatischen Snapshot erstellen</code>.

Weitere Informationen finden Sie in unserer Anleitung "[Snapshot einer Instanz erstellen](/guides/public-cloud/compute/save-an-instance#automatischen-snapshot-einer-instanz-erstellen)".

##### Instanz anhalten

Klicken Sie auf <code className="action">Hard stop</code> und dann im Fenster **Hard stop der Instanz** auf <code className="action">Bestätigen</code>.

Dadurch wird die Instanz in den Zustand **Hard stop (Shutoff)** versetzt: Die Daten auf der Disk bleiben erhalten, der Zustand des Arbeitsspeichers geht jedoch verloren, und Ihnen wird weiterhin der gleiche Preis für die Instanz berechnet. Weitere Informationen finden Sie in unserer Anleitung "[Instanzstatus verwalten (Stopp, Shelve, Pause)](/guides/public-cloud/compute/suspend-or-pause-an-instance#hard-stop-instance)".

Klicken Sie auf <code className="action">Starten</code>, um die Instanz wieder zu starten.

##### Rescue-Modus verwenden

Klicken Sie auf <code className="action">Neustart im Rescue-Modus</code> und dann im angezeigten Fenster auf <code className="action">Bestätigen</code>.

Dies aktiviert den Rescue-Modus der Instanz. Weitere Informationen finden Sie in unserer Anleitung "[Rescue-Modus auf einer Public Cloud Instanz aktivieren](/guides/public-cloud/compute/put-an-instance-in-rescue-mode)".

##### Instanz neu starten

:::warning
Die Hot-Reboot-Option ist derzeit für Metal Instanzen nicht verfügbar.

:::


- Klicken Sie auf <code className="action">Soft Reboot durchführen</code>, um einen Neustart auf Software-Ebene durchzuführen.
- Klicken Sie auf <code className="action">Hard Reboot durchführen</code>, um einen Neustart auf Hardware-Ebene durchzuführen.

Bestätigen Sie die Neustart-Anfrage, indem Sie im angezeigten Fenster auf <code className="action">Bestätigen</code> klicken.

##### Instanz in Shelve versetzen

Klicken Sie auf <code className="action">Shelve</code> und dann im Fenster **Instanz in Shelve versetzen** auf <code className="action">Bestätigen</code>.

Dadurch wird die Instanz in den Zustand **Shelve** versetzt. Weitere Informationen zu den verschiedenen Zuständen einer Instanz finden Sie in unserer Anleitung "[Instanzstatus verwalten (Stopp, Shelve, Pause)](/guides/public-cloud/compute/suspend-or-pause-an-instance#shelve-instance)".

Klicken Sie auf <code className="action">Unshelve</code>, um den Zustand **Aktiv** der Instanz wiederherzustellen.

##### Instanz neu installieren

Klicken Sie auf <code className="action">Neu installieren</code> und dann im Fenster **Instanz neu installieren** auf <code className="action">Bestätigen</code>.

Diese Aktion installiert die Instanz mit demselben Betriebssystem neu, sofern das Image weiterhin unterstützt wird.

Beachten Sie, dass bei einer Reinstallation **alle Daten**, die derzeit auf Ihrer Instanz gespeichert sind, gelöscht werden.

### Auf die VNC-Konsole zugreifen <a name="accessvnc"></a>

Klicken Sie im linken Menü Ihres Public Cloud Projekts unter **Compute** auf <code className="action">Instances</code> und dann in der Tabelle auf den Namen der Instanz.

Öffnen Sie den Tab <code className="action">VNC-Konsole</code>.

Die VNC-Konsole bietet direkten Zugriff auf Ihre Instanz. Damit dieser Zugang funktioniert, müssen Sie zuerst einen Benutzernamen und ein Passwort auf der Instanz konfigurieren.

Weitere Informationen zu den notwendigen Schritten finden Sie in unserer Anleitung "[Eine Public Cloud Instanz erstellen und darauf zugreifen](/guides/public-cloud/compute/getting-started#54-vnc-konsolenzugriff)".
