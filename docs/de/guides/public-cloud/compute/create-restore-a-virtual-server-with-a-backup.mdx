## Ziel

Die OVHcloud Konsole erlaubt es Ihnen, mit wenigen Klicks [Snapshots Ihrer Instanzen zu erstellen](/guides/public-cloud/compute/save-an-instance) und diesen Prozess auch zu automatisieren.  
Sie können diese Instanz-Snapshots für zwei grundlegende Zwecke verwenden:

- Eine neue Instanz mit dem Snapshot als Vorlage erstellen, um die originale Instanz zu duplizieren; zum Beispiel, wenn Sie eine Infrastruktur zur Lastverteilung (Loadbalancing) konfigurieren.
- Instanzen mithilfe eines Snapshots wiederherstellen; zum Beispiel, wenn aufgrund kürzlicher Änderungen kritische Konfigurationen der Instanz beschädigt wurden.

**Diese Anleitung erklärt, wie Sie Snapshots verwenden, um Ihre Instanzen zu duplizieren oder wiederherzustellen.**

## Voraussetzungen

- Sie verfügen über einen Snapshot einer [Public Cloud Instanz](/links/public-cloud/instance-backup).

[[cpnav:publiccloud-instance-backup-console]]

## In der praktischen Anwendung

:::info
Es stehen Ihnen zwei Arten von Snapshots zur Verfügung:

- Lokal: In derselben Region wie Ihre Instanz gespeichert.
- Remote: Automatisch in eine andere, von Ihnen gewählte Region repliziert.

Das **Erstellen** und **Wiederherstellen** einer Instanz aus einem Remote-Snapshot wird vollständig über die OVHcloud API unterstützt, was eine größere Flexibilität und eine mühelose Integration in Ihre Automatisierungsprozesse bietet.

**Hinweis:** In der OVHcloud Konsole können Sie eine Instanz aus jedem Snapshot erstellen, der auf der Seite **Instanz-Snapshots** aufgeführt ist. Eine bestehende Instanz können Sie jedoch nur aus einem Snapshot wiederherstellen, der in ihrer eigenen Region gespeichert ist.

:::


### Eine Instanz aus einem Snapshot erstellen

<Tabs>
  <Tab label="OVHcloud Konsole">
    Klicken Sie im linken Menü Ihres Public Cloud Projekts unter **Compute** auf <code className="action">Instance Snapshot</code>. Die Seite **Instanz-Snapshots** listet Ihre Snapshots auf.

    Klicken Sie in der Zeile des betreffenden Snapshots auf den Button <code className="action">...</code> und wählen Sie dann <code className="action">Instanz erstellen</code>.

    Die Seite **Instanz erstellen** öffnet sich, wobei einige Elemente vordefiniert sind:

    - **Region**: Ihre Instanz wird in derselben Region wie Ihr Snapshot erstellt. Die Region wird durch den Snapshot bestimmt und kann nicht geändert werden.
    - **Image**: Der Snapshot ist im Tab <code className="action">Snapshots</code> des Bereichs **Wählen Sie ein Image** vorausgewählt.
    - **Modell**: Abhängig von Ihrer Quota sind nur diejenigen Modelle verfügbar, die mit Ihrem Image kompatibel sind.

    Geben Sie den Namen der neuen Instanz, den SSH-Schlüssel sowie die Netzwerk- und Abrechnungseinstellungen an und klicken Sie dann auf den Button <code className="action">Meine Instanz erstellen</code>.

    Weitere Informationen zur Erstellung einer Instanz finden Sie in [dieser Anleitung](/guides/public-cloud/compute/getting-started).

    :::info
    Um die Instanz in einem anderen Rechenzentrum zu erstellen, müssen Sie den Snapshot zuerst in die entsprechende Region übertragen. Beachten Sie hierzu die [Anleitung zur Sicherung einer Instanz zwischen Rechenzentren](/guides/public-cloud/compute/transfer-instance-backup-from-one-datacentre-to-another).

    :::

  </Tab>
  <Tab label="OVHcloud API">
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/instance"} />

Tragen Sie die Werte für folgende Parameter ein:
    
    - **serviceName**: Die ID des OVHcloud Projekts.
    - **regionName**: Der Name der Region, in der die Instanz erstellt wird.
    
    Beispiel für eine Anfrage:
    
    ```json
    {
      "billingPeriod": "hourly",
      "bootFrom": {
        "imageId": "5cb8ea68-****-****-****-820be8346***"
      },
      "flavor": {
        "id": "e81b46f8-****-****-****-cad655e65***"
      },
      "name": "newInstance",
      "network": {
        "public": true
      },
      "sshKey": {
        "name": "MySSHKey"
      }
    }
    ```
  </Tab>
  <Tab label="OpenStack CLI">
    Um eine Instanz aus Ihrem Snapshot zu erstellen, verwenden Sie die Snapshot-ID als Image mit diesem Befehl:
    
    ```bash
    $ openstack server create --key-name SSHKEY --flavor 98c1e679-5f2c-4069-b4da-4a4f7179b758 --image 0a3f5901-2314-438a-a7af-ae984dcbce5c Server1_from_snap
    ```
  </Tab>
  <Tab label="Horizon">
    In der Horizon-Oberfläche klicken Sie auf <code className="action">Compute</code> im linken Menü und dann auf <code className="action">Images</code>. Suchen Sie das gewünschte Image und klicken Sie auf den Button <code className="action">Launch</code> rechts neben der Zeile Ihres Image.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon1.png" loading="lazy" />

Geben Sie den Namen Ihrer Instanz im entsprechenden Feld an und bestimmen Sie die Anzahl der zu erstellenden Instanzen. Klicken Sie anschließend auf <code className="action">Flavor</code>.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-2" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon2.png" loading="lazy" />

Wählen Sie das gewünschte Instanzmodell aus und klicken Sie auf den Tab <code className="action">Networks</code>.
    
    :::warning
    Wenn Ihre Instanz ein Windows-Server ist, müssen Sie einen Flavor des Typs win-xx-xx (z. B. win-b2-15) auswählen und über eine öffentliche Schnittstelle im Netzwerk Ext-Net verfügen. Ohne diese Voraussetzungen ist eine Authentifizierung beim OVHcloud KMS nicht möglich, und Ihr Server bleibt mit einer [nicht aktivierten Lizenz](/guides/public-cloud/compute/activate-windows-license-private-mode) bestehen. Dies könnte zu Einschränkungen führen, insbesondere zu fehlenden Updates. Zu beachten ist, dass eine Linux-Instanz (z. B. b2-15) nicht in eine Windows-Instanz (z. B. win-b2-15) skaliert werden kann. Um dies zu erreichen, ist es notwendig, eine neue Instanz zu erstellen.

    :::

    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-3" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon3.png" loading="lazy" />

Wählen Sie das Netzwerk aus, das Sie zuweisen möchten, und klicken Sie auf den Button <code className="action">Launch Instance</code>.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-4" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon4.png" loading="lazy" />

Den Status Ihrer neuen Instanz können Sie unter <code className="action">Compute</code> im linken Menü und dann auf <code className="action">Instances</code> einsehen.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-5" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon5.png" loading="lazy" />
  </Tab>
</Tabs>


### Eine Instanz mithilfe eines Snapshots wiederherstellen

<Tabs>
  <Tab label="OVHcloud Konsole">
    Klicken Sie im linken Menü Ihres Public Cloud Projekts unter **Compute** auf <code className="action">Instances</code> und dann auf den Namen der betreffenden Instanz.

    Klicken Sie in der Karte **Allgemeine Informationen** des Tabs <code className="action">Übersicht</code> in der Zeile **Image** auf <code className="action">Image bearbeiten</code>. Das Fenster **Image bearbeiten** öffnet sich.

    Wählen Sie im Bereich **Distribution auswählen** die Snapshots aus und wählen Sie dann im Bereich **Image auswählen** den wiederherzustellenden Snapshot aus. Es werden nur die Snapshots angeboten, die in der Region der Instanz gespeichert sind. Klicken Sie auf <code className="action">Image bearbeiten</code>, wenn Sie sicher sind, dass Sie das aktuelle Image durch den Snapshot ersetzen möchten.

    Die Instanz wird neu installiert und neu gestartet, bis der Vorgang abgeschlossen ist.

    :::warning
    Wie in der Warnmeldung angegeben, werden alle Daten der Instanz gelöscht: Daten, die nach der Erstellung des Snapshots hinzugefügt wurden, gehen verloren.

    :::

  </Tab>
  <Tab label="OVHcloud API">
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/instance/\\{instanceId\\}/reinstall"} />

Tragen Sie die Werte für folgende Parameter ein:
    
    - **serviceName**: Die ID des OVHcloud Projekts.
    - **regionName**: Der Name der Region, in der sich die Quellinstanz befindet.
    - **instanceId**: Die ID der Instanz.
    
    Beispiel für den Anfragetext:
    
    ```json
    {
      "imageId": "5cb8ea68-****-****-****-820be8346***",
      "imageRegionName": "GRA11"
    }
    ```
  </Tab>
</Tabs>
