## Ziel

Wenn Ihre Instanz aufgrund erhöhter Aktivität oder neuer Anforderungen nicht mehr über ausreichende Ressourcen verfügt, können Sie diese mit wenigen Klicks über die Public Cloud erhöhen.

**Diese Anleitung erklärt, wie Sie die Größe Ihrer Instanz über die OVHcloud Konsole ändern.**

:::warning
Bei klassischen Modellen ist nur die Umstellung auf ein größeres Modell möglich.
Beachten Sie, dass die Instanz während der Operation unterbrochen wird.

:::


:::tip
*Flex*-Instanzen erlauben die Anpassung auf höhere oder niedrigere Modelle aufgrund einer festen Einzeldiskgröße.

:::


## Voraussetzungen

- Sie verfügen über eine [Public Cloud Instanz](/links/public-cloud/public-cloud) in Ihrem OVHcloud Account.

[[cpnav:publiccloud-instances-console]]

## In der praktischen Anwendung

Klicken Sie im linken Menü Ihres Public Cloud Projekts unter **Compute** auf <code className="action">Instances</code> und dann auf den Namen der Instanz.

Klicken Sie in der Karte **Allgemeine Informationen** des Tabs <code className="action">Übersicht</code> in der Zeile **Modell** auf <code className="action">Modell ändern</code>. Die Seite **Modell ändern** wird geöffnet.

Wählen Sie das gewünschte Modell in der Liste **Instanzmodell** und in der Tabelle der Modelle aus. Aktivieren Sie **Nicht verfügbare einschließen**, um auch die Modelle anzuzeigen, die nicht ausgewählt werden können (nicht vorrätig, Quota erreicht oder Festplatte zu klein).

:::info
Bei klassischen Modellen können Sie auf jedes Modell mit gleicher oder größerer Disk umstellen. Sie können nicht auf ein Modell mit kleinerer Disk wechseln: Diese Modelle sind mit **Festplatte zu klein** gekennzeichnet.

Nur **flexible Instanzen** können auf ein höheres oder niedrigeres Modell umgestellt werden, wobei eine feste Diskgröße von 50 GB beibehalten wird.

:::


Der Wechsel zu einem flexiblen Modell ist in der OVHcloud Konsole nicht verfügbar. Verwenden Sie dafür die [OpenStack CLI](/guides/public-cloud/compute/resize-instance-openstack).

:::warning
Wenn Sie eine Instanz vom Typ *Flex* bearbeiten, ist es nicht möglich, über die OVHcloud Konsole auf eine klassische Instanz zurückzuwechseln. Weitere Informationen finden Sie in unserer Anleitung [Eine Flex-Instanz auf eine klassische Instanz zurücksetzen](/guides/public-cloud/compute/revert-a-flex-instance).

:::


Klicken Sie nach der Auswahl auf <code className="action">Bestätigen</code>, um Ihre Wahl zu bestätigen. Die Änderung des Modells kann zu einer Unterbrechung führen: Wir empfehlen Ihnen, vorher einen Snapshot Ihrer Instanz zu erstellen.

### Änderung der Diskgröße unter Windows

Bei einer Größenanpassung einer Windows-Instanz wird die Partitionsgröße nicht automatisch aktualisiert. Sie müssen diese über die **Datenträgerverwaltung** erweitern:

- Klicken Sie mit der rechten Maustaste auf das Menü <code className="action">Start</code> und öffnen Sie die Datenträgerverwaltung, indem Sie auf <code className="action">Disk Management</code> klicken:

<img className="thumbnail" alt="Kontextmenü des Startmenüs mit der Option Datenträgerverwaltung" src="/images/public-cloud/compute/resize-instance-manager/2980.png" loading="lazy" />

- Klicken Sie mit der rechten Maustaste auf die Hauptpartition und dann auf <code className="action">Extend Volume</code>.

<img className="thumbnail" alt="Rechtsklick auf die Hauptpartition zum Erweitern des Volumes" src="/images/public-cloud/compute/resize-instance-manager/2981a.png" loading="lazy" />

- Klicken Sie im `Extend Volume Wizard` auf <code className="action">Next</code>. Wählen Sie die Ressourcen der zu erweiternden Disk aus und klicken Sie auf <code className="action">Next</code>.

<img className="thumbnail" alt="Extend Volume Wizard mit Auswahl der Diskressourcen" src="/images/public-cloud/compute/resize-instance-manager/2978a.png" loading="lazy" />

Klicken Sie abschließend auf <code className="action">Finish</code>, um die Änderung zu bestätigen.

<img className="thumbnail" alt="Abschlussschritt des Extend Volume Wizard" src="/images/public-cloud/compute/resize-instance-manager/wizard2021.png" loading="lazy" />

- Die neue Diskgröße wird in der Datenträgerverwaltung angezeigt.

<img className="thumbnail" alt="Datenträgerverwaltung mit der neuen Diskgröße" src="/images/public-cloud/compute/resize-instance-manager/2979.png" loading="lazy" />
