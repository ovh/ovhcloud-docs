## Ziel

Sie können die Administrator- und Rechnungskontakte eines Public Cloud Projekts in der OVHcloud Konsole ändern.

Die Änderung dieser Kontakte erlaubt es, die technische Verwaltung der Dienste innerhalb eines Projekts von der Abrechnung des Projekts zu trennen.

**Diese Anleitung erklärt, wie Sie die Kontakte eines Public Cloud Projekts in der OVHcloud Konsole ändern.**

## Voraussetzungen

- Sie haben ein [Public Cloud](/links/public-cloud/public-cloud) Projekt in Ihrem OVHcloud Kunden-Account.
- Administrator- und Rechnungskontakt gehören zu derselben OVHcloud Filiale.

[[cpnav:publiccloud-contacts-rights-console]]

## In der praktischen Anwendung

### Die Kontakte ändern

Klicken Sie im linken Menü Ihres Public Cloud Projekts auf <code className="action">Projektverwaltung</code> und dann auf den Tab <code className="action">Kontakte & Rechte</code>.

Auf dieser Seite können Sie die Administrator- und Rechnungskontakte Ihres Projekts einsehen.

Klicken Sie auf einen der Links <code className="action">Bearbeiten</code>, um die aktuellen Kontakte zu ändern. Dadurch wird die Seite **Verwaltung der Kontakte** der OVHcloud Konsole in einem neuen Tab geöffnet. Die Links <code className="action">Bearbeiten</code> sind nur für Kunden-Accounts der EU-Zone verfügbar und nicht für ein Projekt im Discovery-Modus.

Die Kontakte Ihres Public Cloud Projekts werden im Tab <code className="action">Meine Dienste</code> angezeigt. Klicken Sie auf den Button <code className="action">...</code> und dann auf <code className="action">Kontakte ändern</code>.

Geben Sie im Fenster **Kontakte ändern** die gewünschte Kundenkennung für jeden Kontakt ein, den Sie ändern möchten (**Administrator-Kontakt**, **Technischer Kontakt**, **Rechnungskontakt**). Beachten Sie, dass die OVHcloud Kunden-Accounts für `Administrator-Kontakt` und `Rechnungskontakt` in derselben OVHcloud Filiale registriert sein müssen.

Nachdem Sie auf <code className="action">Bestätigen</code> geklickt haben, erhalten die beiden von der Änderung betroffenen OVHcloud Kunden-Accounts eine Bestätigungsmail. Diese E-Mail enthält einen Code (Token), mit dem die Kontaktänderung im Tab <code className="action">Meine Anfragen</code> der Seite **Verwaltung der Kontakte** bestätigt werden kann: Klicken Sie in der Zeile der Anfrage auf <code className="action">...</code> und dann auf <code className="action">Die Anfrage akzeptieren</code> und geben Sie den Code in das Feld **Validierungscode** ein.

Genauere Informationen zur Vorgehensweise finden Sie in unserer Anleitung "[Die Kontakte Ihrer Dienste verwalten](/guides/account-and-service-management/account-information/managing-contacts)".
