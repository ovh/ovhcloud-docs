## Ziel

Sie können basierend auf zuvor erstellten Volume Snapshots weitere Festplatten für Ihre Public Cloud Instanzen erstellen.

Dies kann in folgenden Fällen nützlich sein:

- Wenn Sie die zusätzlichen Festplattendaten wiederherstellen möchten.
- Wenn Sie einen hochverfügbaren und leistungsfähigen Speicherplatz für Ihre Daten benötigen.
- Wenn Sie Ihre Daten auf eine andere Instanz übertragen möchten.

**Diese Anleitung erklärt, wie Sie aus einem Volume Snapshot eine zusätzliche Festplatte auf einer Ihrer Instanzen erstellen und konfigurieren.**

## Voraussetzungen

- Sie verfügen über eine [Public Cloud Instanz](/links/public-cloud/public-cloud).
- Sie verfügen über einen Volume Snapshot in der gleichen OpenStack-Region.
- Sie haben administrativen Zugriff (sudo) über SSH oder RDP auf Ihre Instanzen.

## In der praktischen Anwendung

### Festplatte aus einem Volume Snapshot erstellen

Klicken Sie im linken Menü Ihres Public Cloud Projekts unter **Speicher** auf <code className="action">Volume Snapshot</code>.

Klicken Sie in der Zeile des Snapshots, aus dem Sie ein Volume erstellen möchten, auf den Button <code className="action">...</code> und dann auf <code className="action">Volume erstellen</code>.

Geben Sie im Fenster **Volume aus einem Snapshot erstellen** in den Feldern **Volume-Name** und **Volume-Kapazität** den Namen und die Kapazität der neuen Festplatte ein, überprüfen Sie den geschätzten Betrag und klicken Sie dann auf <code className="action">Volume erstellen</code>.

Um stattdessen ein Volume aus einem Volume Backup zu erstellen, klicken Sie unter **Speicher** auf <code className="action">Volume Backup</code> und folgen Sie dann denselben Schritten über den Button <code className="action">...</code> des Backups.

Die Erstellung der Festplatte kann abhängig von deren Größe einige Minuten in Anspruch nehmen.

### Festplatte mit einer Instanz verbinden

Sobald die Festplatte erstellt ist, können Sie sie mit einer Instanz verbinden. Klicken Sie hierzu im linken Menü unter **Speicher** auf <code className="action">Block Storage</code>.

Klicken Sie in der Zeile des Volumes Ihrer Wahl auf den Button <code className="action">...</code> und dann auf <code className="action">An Instanz anhängen</code>.

Wählen Sie im Bereich **Volume mit einer Instanz verbinden** unter **Instance** die Instanz aus und klicken Sie auf <code className="action">Bestätigen</code>, um die Festplatte anzuhängen.

Der Vorgang zur Anbindung der Festplatte an Ihre Instanz beginnt und kann einige Minuten dauern.

Sobald der Vorgang abgeschlossen ist, können Sie für die nächsten Schritte unsere Konfigurationsanleitung verwenden, für [Linux](/guides/public-cloud/compute/create-and-configure-an-additional-disk-on-an-instance#unter-linux)- oder [Windows](/guides/public-cloud/compute/create-and-configure-an-additional-disk-on-an-instance#unter-windows)-Instanzen.
