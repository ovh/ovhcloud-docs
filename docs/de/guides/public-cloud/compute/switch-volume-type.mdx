## Ziel

In dieser Anleitung wird erläutert, wie Sie einen Block Storage Volume vom Typ *Classic* oder *High speed* auf *High speed gen2* ändern können.

## Voraussetzungen

- Zugriff auf das [Horizon Interface](/guides/public-cloud/cross-functional/introducing-horizon).
- Sie haben ein [Block Storage Volume](/guides/public-cloud/compute/create-and-configure-an-additional-disk-on-an-instance) in Ihrem [Public Cloud Projekt](/links/public-cloud/public-cloud) erstellt.

[[cpnav:publiccloud-block-storage-console]]

## In der praktischen Anwendung

Wenn Sie einen Block Storage Volume Typ auf *High speed gen2* ändern, muss die Migrationsrichtlinie von `Never` auf `On Demand` gewechselt werden.

Als Standard ist die Migrationsrichtlinie auf `Never` eingestellt, da das Volume auf demselben CEPH Cluster verbleibt. Für *High speed gen2* muss das Volume jedoch auf ein neues Cluster migriert werden.

Diese Änderung kann über Horizon oder OpenStack CLI vorgenommen werden.

:::warning
Wenn das Block Storage Volume mit einer Instanz verbunden ist, müssen Sie es zuerst trennen, bevor Sie fortfahren. Weitere Informationen finden Sie im Abschnitt **Volume abtrennen** in "[Zusätzliches Volume auf einer Instanz erstellen und konfigurieren](/guides/public-cloud/compute/create-and-configure-an-additional-disk-on-an-instance#volume-abtrennen)".

Das Ändern des Volume-Typs (Retyping) über die OVHcloud Konsole oder die OVHcloud API ist nur für nicht verschlüsselte Volumes verfügbar. Verschlüsselte Volumes vom Typ **-LUKS** können nicht retypisiert werden. In der OVHcloud Konsole ist das Retyping auch für **Classic Multi-Attach** Volumes nicht verfügbar.

Konvertierungen von **-LUKS** zu **nicht -LUKS** (oder umgekehrt) werden nicht unterstützt, auch nicht über OpenStack / Horizon.

:::


<Tabs>
  <Tab label="OVHcloud Konsole">
    Klicken Sie im linken Menü Ihres Public Cloud Projekts unter **Speicher** auf <code className="action">Block Storage</code>.

    Klicken Sie in der Zeile des betreffenden Volumes auf den Button <code className="action">...</code> und wählen Sie dann <code className="action">Volume-Typ ändern</code>.

    Im Fenster **Ändern Sie Ihren Angebotstyp**:

    - Wenn das Volume mit einer Instanz verbunden ist, geben Sie `DETACH` ein, um die Trennung zu bestätigen, und klicken Sie dann auf <code className="action">Bestätigen und fortfahren</code>.
    - Wenn das Volume Snapshots hat, geben Sie `DELETE` ein, um deren Löschung zu bestätigen, und klicken Sie dann auf <code className="action">Bestätigen und fortfahren</code>.
    - Wählen Sie den gewünschten Typ aus (der aktuelle Typ wird unter **Aktueller Typ** angezeigt) und klicken Sie dann auf <code className="action">Bestätigen</code>.

    :::info
    Das Ändern des Volume-Typs (Retyping) kann einige Minuten dauern.
    
    :::
  </Tab>
  <Tab label="OpenStack CLI">
    Stellen Sie sicher, dass Sie den folgenden Leitfaden vorab konsultieren:
    
    - [Preparing an environment for using the OpenStack API](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment).
    
    Zunächst listen Sie die in Ihrer Region verfügbaren Volumetypen mit dem folgenden Befehl auf:
    
    ```bash
    #~$ openstack volume type list
    +--------------------------------------+----------------------------------------------------+-----------+
    | ID                                   | Name                                               | Is Public |
    +--------------------------------------+----------------------------------------------------+-----------+
    | 27844ef7-1a9a-4944-be59-6e4eb19a71f6 | high-speed-gen2                                    | True      |
    | 23f75fef-d4f6-416a-a884-95aa3fd45695 | classic                                            | True      |
    | 2f78e8af-93c9-4e5c-b177-83c4a7ec456a | high-speed                                         | True      |
    | 9c5b1e42-3d8f-4a67-a9d2-84f3b2e7c1aa | high-speed-gen2-luks                               | True      |
    | f41d7c8e-6a2b-4b91-9e73-2d6c0a58e94f | classic-luks                                       | True      |
    | c8e92a5d-0f6e-4e3b-b1a4-7a9d6f3c2e8b | high-speed-luks                                    | True      |
    ---------------------------------------------------------------------------------------------------------
    ```
    
    :::warning
    Bitte beachten Sie, dass, wenn die Typen "high-speed-gen2" oder **-LUKS** nicht in der Liste erscheinen, dies bedeutet, dass sie in dieser Region nicht verfügbar sind.
    
    Typen von **-LUKS** Volumen werden nur angezeigt, wenn sie in der Region unterstützt werden und mit dem Verschlüsselungstyp des Volumens kompatibel sind.

    :::

    
    Als nächstes wechseln Sie den Volumetyp mit dem folgenden Befehl:
    
    ```bash
    $ openstack volume set --type <VOLUME_TYPE> --retype-policy on-demand <VOLUME_NAME_OR_ID>
    ```
  </Tab>
  <Tab label="Horizon">
    Melden Sie sich bei der [Horizon-Schnittstelle](https://horizon.cloud.ovh.net/auth/login/) an und stellen Sie sicher, dass Sie sich in der richtigen Region befinden. Dies können Sie in der linken oberen Ecke überprüfen. 
    
    <img className="thumbnail" alt="Region selection" src="/images/public-cloud/compute/switch-volume-type/region2021.png" loading="lazy" />

Klicken Sie auf das Menü <code className="action">Volumes</code> auf der linken Seite und wählen Sie <code className="action">Volumes</code> aus.
    Klicken Sie auf das Dropdown-Menü neben <code className="action">Edit Volume</code> und wählen Sie <code className="action">Change Volume Type</code>.
    
    <img className="thumbnail" alt="Option selection" src="/images/public-cloud/compute/switch-volume-type/selectoption.png" loading="lazy" />

Im Pop-up-Fenster klicken Sie auf das Dropdown-Menü unter `Type` und wählen Sie <code className="action">high-speed-gen-2</code> aus. Klicken Sie auf das Dropdown-Menü unter `Migration Policy` und wählen Sie <code className="action">On Demand</code>.
    
    Sobald Sie fertig sind, klicken Sie auf <code className="action">Change Volume Type</code>, um die Änderung zu bestätigen.
    
    <img className="thumbnail" alt="Option selection" src="/images/public-cloud/compute/switch-volume-type/changevolume.png" loading="lazy" />
  </Tab>
</Tabs>
