## Ziel

Sie können einen einzelnen Snapshot einer Instanz erstellen oder einen Zeitplan konfigurieren, um die Snapshots Ihrer Instanzen zu automatisieren. Snapshots können verwendet werden, um Ihre Instanz auf einen früheren Zustand wiederherzustellen oder um eine neue, identische Instanz zu erstellen.

**Diese Anleitung erklärt, wie Sie manuelle und automatische Snapshots einer Public Cloud Instanz erstellen.**

## Voraussetzungen

- Sie haben eine [Public Cloud Instanz](/links/public-cloud/public-cloud) in Ihrem OVHcloud Kunden-Account.
- Sie haben [OpenStack CLI auf Ihrem System installiert und konfiguriert](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment).

[[cpnav:publiccloud-instances-console]]

## In der praktischen Anwendung

### Snapshot einer Instanz erstellen

:::warning
Diese Option ist für Metal Instanzen nur über einen **Cold Snapshot** verfügbar. Die Metal-Instanz wird in den Rescue-Modus versetzt, und sobald der Snapshot abgeschlossen ist, wird die Instanz im normalen Modus neu gestartet.

:::


:::info
Zwei Arten von Snapshots sind verfügbar:

- Lokal: Ein lokaler Snapshot wird in derselben Region wie Ihre Instanz gespeichert.
- Remote: Ein Remote-Snapshot erstellt automatisch eine Kopie des lokalen Snapshots in einer anderen, von Ihnen ausgewählten Region.

Jeder Snapshot wird gesondert berechnet. Der Remote-Snapshot wird gemäß den Speicherkosten der ausgewählten Remote-Region berechnet.

**Hinweis:** Local Zones sind für Remote-Snapshots nicht verfügbar.

:::

    </details>

  <Tab label="OVHcloud API">
    Sie können anschließend alle verfügbaren Regionen mit folgendem API-Aufruf anzeigen:
    
    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/region"} />

Verwenden Sie anschließend folgenden API-Aufruf:
    
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/instance/\\{instanceId\\}/snapshot"} />

Füllen Sie die Felder für die Parameter aus:
    
    - **instanceId**: Eindeutige ID der betreffenden Instanz.
    - **regionName**: Name der Region, in der sich die Quell-Instanz befindet.
    - **serviceName**: ID des OVHcloud Projekts.
    - **distantRegionName (optional)**: Name der Remote-Region, in der der Remote-Snapshot gespeichert wird.
    - **distantSnapshotName (optional)**: Name des Remote-Snapshots, der in der Remote-Region erstellt werden soll.
    - **snapshotName**: Name des lokalen Snapshots, der erstellt werden soll.
    
    :::info
    Ein Remote-Snapshot wird nur erstellt, wenn die Parameter der Remote-Region (**distantRegionName** und **distantSnapshotName**) angegeben sind.

    :::

### Automatischen Snapshot einer Instanz erstellen

:::info
Wenn Sie diese Funktion direkt über OpenStack automatisieren möchten, können Sie einen Mistral-Workflow mit einem Cron-Trigger erstellen.

:::


Klicken Sie im linken Menü Ihres Public Cloud Projekts unter **Compute** auf <code className="action">Instances</code>. Klicken Sie auf den Button <code className="action">...</code> rechts neben der Instanz und wählen Sie <code className="action">Automatischen Snapshot erstellen</code>.

Die Seite **Schedule erstellen** öffnet sich. Sie können dann folgende Einstellungen konfigurieren:

#### **Workflow** 

Der Schedule erstellt einen automatischen Snapshot der Instanz und ihres primären Volumes. Es muss kein Workflow-Typ ausgewählt werden.

#### **Ressource** 

Im Bereich **Wählen Sie eine zugeteilte Ressource aus** können Sie die Instanz auswählen, von der ein Snapshot erstellt werden soll.

#### **Name**

Geben Sie im Bereich **Geben Sie einen Namen für Ihren Schedule ein** einen Namen für den Zeitplan des automatischen Snapshots ein. Nehmen Sie die Preisinformationen in der Zusammenfassung rechts zur Kenntnis und erstellen Sie den Schedule dann mit <code className="action">Erstellen</code>.

#### **Scheduling** 

Im Bereich **Scheduling festlegen** können Sie einen personalisierten Zeitplan festlegen (**Personalisiert**, im UNIX-Cron-Format, in UTC) oder eine der Standardfrequenzen auswählen:

- **Rotation 7**: täglicher Snapshot mit Aufbewahrung der letzten 7 Snapshots
- **Rotation 14**: täglicher Snapshot mit Aufbewahrung der letzten 14 Snapshots

<details>

<summary>**Hinzufügen eines Remote-Snapshots**</summary>


Aktivieren Sie <code className="action">Einen Remote-Snapshot hinzufügen</code>, wählen Sie einen Standort aus, überprüfen Sie die Preisinformationen und klicken Sie auf den Button <code className="action">Erstellen</code>.

</details>


### Verwaltung der Snapshots und Zeitpläne

Zeitpläne werden auf der Seite **Workflow Management** angezeigt und gelöscht: Klicken Sie im linken Menü unter **Compute** auf <code className="action">Workflow</code>.

Die Snapshots Ihrer Instanzen werden auf der Seite **Instanz-Snapshots** verwaltet: Klicken Sie im linken Menü unter **Compute** auf <code className="action">Instance Snapshot</code>.

:::warning
Die Snapshot-Option der Instanz muss separat gelöscht werden, damit sie nicht mehr in Rechnung gestellt wird. Das Löschen einer Instanz entfernt nicht automatisch die mit ihr verbundenen Optionen.

:::



:::warning
**Beachten Sie, dass Sie einen Instanz-Snapshot nicht löschen können, wenn eine Instanz, die aus diesem Snapshot erzeugt wurde, zum Zeitpunkt des Löschvorgangs ausgeführt wird.**

:::
