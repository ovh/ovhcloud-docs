## Ziel

Public Cloud Archive ist eine Cold Storage Lösung für das Hosting großer Datenmengen ohne Größenbeschränkung und zu sehr attraktiven Preisen.

Da Cold Storage Daten nur selten Zugriff benötigen, ist eine Freigabeanforderung (*Unfreeze*) notwendig, was eine Verzögerung des Datenabrufs nach sich zieht. Dieser Zeitraum variiert je nach Datenalter und Häufigkeit des Datenzugriffs.

## In der praktischen Anwendung

### Objekte in der OVHcloud Konsole freigeben

Klicken Sie im linken Menü Ihres Public Cloud Projekts unter **Speicher** auf <code className="action">Cloud Archive</code>. Klicken Sie in der Zeile Ihres Containers auf den Button <code className="action">...</code> und dann auf <code className="action">Archiv anzeigen</code>.

Im Tab <code className="action">Objekte</code> zeigt die Spalte **Verfügbarkeit** den Status jedes Objekts an:

- **Gesperrt**: Das Objekt ist archiviert und muss freigegeben werden, bevor es heruntergeladen werden kann.
- **Verfügbar ab** *Datum*: Das Objekt wird gerade freigegeben und kann ab dem angezeigten Datum heruntergeladen werden.
- **Ja**: Das Objekt ist verfügbar.

Um ein Objekt freizugeben, klicken Sie in seiner Zeile auf den Button <code className="action">...</code> und dann auf <code className="action">Freigeben</code>. Die Spalte **Verfügbarkeit** zeigt dann das Datum an, ab dem das Objekt abgerufen werden kann.

Sobald das Objekt verfügbar ist, klicken Sie in seiner Zeile auf den Button <code className="action">...</code> und dann auf <code className="action">Herunterladen</code>. Sie können es auch über einen [Swift/SFTP/SCP Client](/guides/storage-and-backup/object-storage/pca-sftp) herunterladen.

#### Objekt-Download automatisieren

:::info
Diese Funktion erfordert das Paket `at`.

:::


```bash
swift download <pca_container> <object>
```
```
Error downloading object '<pca_container>/<object>': Object GET failed: https://storage.gra.cloud.ovh.net/v1/AUTH_702xxxxxxxxxxxxxxxxxxxxxxxxxxdaf/<pca_container>/<object> 429 Too Many Requests
```

```bash
X_OVH_RETRIEVAL_DELAY=$(swift download <pca_container> <object> | awk -F ": " '/X-Ovh-Retrieval-Delay/ {print $2}'
RETRIEVAL_DELAY=$((${X_OVH_RETRIEVAL_DELAY} / 60 + 2))
swift download <pca_container> <object> | at now + ${RETRIEVAL_DELAY} minutes
```
