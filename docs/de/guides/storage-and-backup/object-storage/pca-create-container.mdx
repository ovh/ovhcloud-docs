## Ziel

Public Cloud Archive ist eine unbegrenzte Speicherlösung mit einfacher Abrechnung und auf Ihren Bedarf angepasst. Es gibt mehrere Arten von Objekt-Containern:

- für statisches Hosting (statische Website)
- für privates Hosting (Beispiel: Speicherung personenbezogener Daten)
- für öffentliches Hosting (zur Speicherung von allen öffentlich zugänglichen Daten)
- für Cold Storage (Archivierung)

Der erste Schritt ist die Erstellung eines Containers, der Ihre Dateien zusammenfasst.

**Diese Anleitung erklärt, wie Sie in der OVHcloud Konsole einen Container erstellen.**

## In der praktischen Anwendung

### Erstellung eines Public Cloud Archive Containers in der OVHcloud Konsole

Klicken Sie im linken Menü Ihres Public Cloud Projekts unter **Speicher** auf <code className="action">Cloud Archive</code> und dann auf <code className="action">Archiv-Container erstellen</code>.

Im Bereich **Container-Name** wird ein Name vorgeschlagen: Behalten Sie ihn bei oder geben Sie einen eigenen ein (3 bis 63 Zeichen in Kleinbuchstaben, `.` und `-` sind erlaubt).

Wählen Sie im Bereich **Region** die Region Ihres Containers aus.

:::warning
Wenn Sie Ihren Container mit einem Domainnamen verbinden möchten, darf der Name Ihres Containers folgende Zeichen nicht enthalten:

- [ . ]
- [ _ ]
- Es dürfen weiterhin keine Großbuchstaben enthalten sein.

Weitere Informationen finden Sie in unserer Anleitung zum [Verbinden eines Containers mit einer Domain](/guides/storage-and-backup/object-storage/pcs-link-domain).

:::

Überprüfen Sie die Zusammenfassung und klicken Sie dann auf <code className="action">Erstellen</code>. Ihr Container wird in der Liste **Cloud Archive** angezeigt.
