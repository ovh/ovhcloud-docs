## Ziel

Ein NAS (Network Attached Storage) ist ein Dateiserver, der mit einem Netzwerk verbunden ist und dessen Hauptfunktion darin besteht, Daten auf einem zentralisierten Volume für heterogene Netzwerk-Clients zu speichern.

## Voraussetzungen

- Sie verfügen über eine IP-Adresse, die an einen OVHcloud Dienst angebunden ist (Hosted Private Cloud, Dedicated Server, VPS, Public Cloud Instanz, etc.).
- Sie haben ein [OVHcloud HA-NAS](https://www.ovhcloud.com/de/storage-solutions/nas-ha/) in Ihrem Kunden-Account.

## In der praktischen Anwendung

Klicken Sie in der Liste auf den Namen Ihres Dienstes. Der Tab <code className="action">Übersicht</code> zeigt Folgendes zu Ihrem Dienst an: **Allgemeine Informationen** (darunter **Kennung** und **IP-Adresse**), **Dienstkonfiguration** und **Abonnement**.

:::info
In der OVHcloud Konsole werden die Partitionen eines HA-NAS als **Volumes** bezeichnet.
:::

Um eine Aktion für ein bestehendes Volume auszuführen, öffnen Sie den Tab <code className="action">Volumes</code>, aktivieren Sie das Kontrollkästchen des betreffenden Volumes und öffnen Sie dann das Menü <code className="action">Aktionen</code>.

### Eine Partition erstellen <a name="partition"></a>

Um eine neue Partition hinzuzufügen, öffnen Sie den Tab <code className="action">Volumes</code> und klicken Sie auf <code className="action">Volume erstellen</code>.

Geben Sie **Volume-Name**, **Größe (GB)** und optional eine **Beschreibung** ein, wählen Sie das autorisierte **Protokoll** aus (<code className="action">NFS</code>, <code className="action">CIFS (SMB)</code> oder <code className="action">NFS + CIFS</code>) und klicken Sie dann auf <code className="action">Volume erstellen</code>.

### Größe einer Partition ändern

Um die Größe einer Partition zu ändern, aktivieren Sie das Kontrollkästchen des betreffenden Volumes und klicken Sie dann auf <code className="action">Aktionen</code> und <code className="action">Die Größe ändern</code>.

Geben Sie die **Neue Größe** ein und klicken Sie dann auf <code className="action">Anwenden</code>.

### Die Frequenz der Snapshots ändern

Standardmäßig wird stündlich ein Snapshot des Inhalts Ihres NAS erstellt und auf Ihrem NAS gespeichert.

Sie können jedoch auf Wunsch zusätzliche Snapshots mit unterschiedlichen Frequenzen aktivieren, die ebenfalls auf Ihrem NAS gespeichert werden.

Aktivieren Sie hierzu das Kontrollkästchen des betreffenden Volumes und klicken Sie dann auf <code className="action">Aktionen</code> und <code className="action">Die Snapshots verwalten</code>. Klicken Sie im Tab <code className="action">Snapshot-Richtlinien</code> des Volumes im Bereich **Automatische Snapshots** auf <code className="action">Snapshot-Häufigkeiten verwalten</code>.

Aktivieren Sie die gewünschten Frequenzen und klicken Sie dann auf <code className="action">Änderungen speichern</code>.

### Snapshot erstellen

Zusätzlich zu den automatisch erstellten Snapshots können Sie jederzeit einen sofortigen Snapshot einer Partition erstellen. Klicken Sie im Tab <code className="action">Snapshot-Richtlinien</code> des Volumes im Bereich **Manuelle Snapshots** auf <code className="action">Snapshot erstellen</code>.

Geben Sie ein **Snapshot-Suffix** ein (Ihr Snapshot erhält den Namen `snap-<Volume-Name>-<Ihr Suffix>`) und klicken Sie auf <code className="action">Snapshot erstellen</code>.

Um manuelle Snapshots zu löschen, aktivieren Sie deren Kontrollkästchen in der Liste **Manuelle Snapshots**, klicken Sie auf <code className="action">Löschen</code> und bestätigen Sie.

### Zugang hinzufügen <a name="addaccess"></a>

Um auf die zuvor von Ihnen erstellte Partition zuzugreifen, müssen Sie einen Zugang konfigurieren.

:::info
Nur IP-Adressen von OVHcloud Diensten können auf Ihr NAS zugreifen (z. B. ein Dedicated Server, ein VPS, eine Public Cloud Instanz usw.).

:::


Um einer IP den Zugriff auf das NAS zu erlauben, aktivieren Sie das Kontrollkästchen des betreffenden Volumes und klicken Sie dann auf <code className="action">Aktionen</code> und <code className="action">Zugriff verwalten</code>. Der Tab <code className="action">Zugriffskontrolle (ACL)</code> des Volumes wird geöffnet.

Klicken Sie dann auf <code className="action">Zugriff hinzufügen</code> und wählen Sie im Feld **IP** die IP-Adresse oder den IP-Block Ihres OVHcloud Produkts aus.

Sie müssen außerdem unter **Typ** festlegen, ob der für diese IP-Adresse erlaubte Zugriff <code className="action">Nur Lesen</code> oder <code className="action">Lesen/Schreiben</code> ist. Klicken Sie anschließend auf <code className="action">Zugriff hinzufügen</code>.

#### Zugang löschen

Um einen Zugang zu einer Partition zu entfernen, aktivieren Sie im Tab <code className="action">Zugriffskontrolle (ACL)</code> des Volumes das Kontrollkästchen der betreffenden IP-Adresse, klicken Sie auf <code className="action">Löschen</code> und dann auf <code className="action">Zugriff löschen</code>.

### ZFS-Einstellungen

:::warning
Die Standard-ZFS-Einstellungen eignen sich für die meisten Anwendungsfälle. Ändern Sie diese nur, wenn Sie wissen, welche Daten auf der Partition gespeichert sind.

:::


Um die ZFS-Einstellungen einer Partition zu ändern, aktivieren Sie das Kontrollkästchen des betreffenden Volumes und klicken Sie dann auf <code className="action">Aktionen</code> und <code className="action">Nutzung parametrieren (ZFS)</code>.

Wenden Sie unter **Template auswählen** ein für Ihre Daten geeignetes Nutzungs-Template an (<code className="action">Standard</code>, <code className="action">Virtuelle Maschinen</code>, <code className="action">Datenbanken</code> oder <code className="action">Dateisysteme (große Dateien)</code>), oder wählen Sie <code className="action">Benutzerdefiniert</code>, um die Werte für *atime*, *recordsize* und *sync* selbst festzulegen. Klicken Sie anschließend auf <code className="action">Einstellungen ändern</code>.

Ausführliche Informationen zu den einzelnen Einstellungen und zu den von den einzelnen Nutzungs-Templates angewendeten Werten finden Sie in unserer Anleitung "[ZFS-Einstellungen einer Partition konfigurieren](/guides/storage-and-backup/file-storage/ha-nas/nas-zfs-settings)".

### Eine Partition löschen

:::danger
Beim Löschen einer Partition werden alle darin enthaltenen Daten vollständig und endgültig gelöscht.

:::


Um eine Partition zu löschen, aktivieren Sie das Kontrollkästchen des betreffenden Volumes und klicken Sie dann auf <code className="action">Aktionen</code> und <code className="action">Löschen</code>. Geben Sie zur Bestätigung `DELETE` ein und klicken Sie dann auf <code className="action">Löschen</code>.
