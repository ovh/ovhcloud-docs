## Ziel

OVHcloud HA-NAS Dienste ermöglichen Ihnen die Verwaltung zentral gespeicherter Dateien, die über ein Netzwerk zugänglich sind.

**Diese Anleitung erklärt, wie Sie die Partitionen Ihres HA-NAS über die OVHcloud API verwalten.**

## Voraussetzungen

- Sie haben ein [OVHcloud HA-NAS](https://www.ovhcloud.com/de/storage-solutions/nas-ha/) in Ihrem Kunden-Account.
- Sie haben sich anhand der [Anleitung zu den ersten Schritten mit der OVHcloud API](/guides/manage-and-operate/api/first-steps) mit der Verwendung der OVHcloud APIv6 vertraut gemacht.

## In der praktischen Anwendung

Alle API-Routen in dieser Anleitung sind im <ApiLink section="/dedicated/nasha">Bereich */dedicated/nasha*</ApiLink> der API-Konsole verfügbar.

:::info
Bei der Verwendung der API sind alle mit einem Stern (\*) gekennzeichneten Felder Pflichtfelder.
:::


### Informationen zu Ihrer Dienstleistung abrufen

Alle Ihre aktiven Dienste können über folgende Route abgerufen werden:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha"} />


### Liste aller Partitionen

Verwenden Sie die folgende Route, um die Partitionen eines Dienstes abzurufen:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Der interne Name Ihres HA-NAS |

### Die Eigenschaften einer Partition abrufen

Um die Details einer Partition anzuzeigen, verwenden Sie die folgende Route:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Der interne Name Ihres HA-NAS |
| `partitionName` | Yes | Partitionsname |

### Abruf der Statistiken einer Partition

Verwenden Sie die folgende Route, um die Nutzungsinformationen einer Partition abzurufen:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/use"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Der interne Name Ihres HA-NAS |
| `partitionName` | Yes | Partitionsname |
| `type` | Yes | Der Typ der zu übernehmenden Statistiken: *size*, *used* oder *usedbysnapshots* |

### Erstellung einer Partition

Verwenden Sie die folgende Route, um eine neue Partition zu erstellen:

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Der interne Name Ihres HA-NAS |
| `partitionDescription` |  | Optionale Beschreibung |
| `partitionName` | Yes | Ein Name für die Partition |
| `protocol` | Yes | *NFS*, *CIFS* oder *NFS_CIFS* für beide |
| `size` | Yes | Größe der Partition |

Wählen Sie beispielsweise `NFS` als Protokoll mit einer Größe von `10` Gigabyte aus.

### Die Eigenschaften einer Partition ändern

Verwenden Sie die folgende Route zur Änderung einer Partition:

<Api version="v1" section="/dedicated/nasha" method="PUT" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Der interne Name Ihres HA-NAS |
| `partitionName` | Yes | Partitionsname |
| `partitionDescription` |  | Die neue Beschreibung |
| `size` |  | Die neue Größe der Partition |

### ZFS-Einstellungen einer Partition abrufen

Verwenden Sie die folgende Route, um die ZFS-Einstellungen abzurufen:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Der interne Name Ihres HA-NAS |
| `partitionName` | Yes | Partitionsname |

### Änderung der ZFS-Einstellungen einer Partition

:::warning
Die Standard-ZFS-Einstellungen eignen sich für die meisten Anwendungsfälle. Ändern Sie diese nur, wenn Sie wissen, welche Daten auf der Partition gespeichert sind. Ausführliche Informationen zu den einzelnen Einstellungen und zu den von den einzelnen Nutzungs-Templates angewendeten Werten finden Sie in unserer Anleitung "[ZFS-Einstellungen einer Partition konfigurieren](/guides/storage-and-backup/file-storage/ha-nas/nas-zfs-settings)".
:::


Verwenden Sie die folgende Route zur Änderung der ZFS-Einstellungen:

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Der interne Name Ihres HA-NAS |
| `partitionName` | Yes | Partitionsname |
| `templateName` |  | Anzuwendendes Nutzungs-Template: *Default*, *Virtual machines*, *Databases* oder *File Systems (big files)*. Senden Sie diesen Parameter allein, ohne `atime`, `recordsize` oder `sync` |
| `atime` |  | Parameter für die Aktualisierung der Zugriffszeit: *off* (Standardwert) oder *on* |
| `recordsize` |  | Maximale Blockgröße in Bytes: *4096*, *8192*, *16384*, *32768*, *65536*, *131072* (Standardwert) oder *1048576* |
| `sync` |  | Datei-Synchronisierungsparameter: *always*, *disabled* oder *standard* (Standardwert) |

### Löschung einer Partition

Verwenden Sie die folgende Route, um eine Partition zu löschen:

| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Der interne Name Ihres HA-NAS |
| `partitionName` | Yes | Partitionsname |
