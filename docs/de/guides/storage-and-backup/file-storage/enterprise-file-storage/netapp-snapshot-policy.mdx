## Ziel

In dieser Anleitung geben wir Ihnen einen Überblick über die Verwaltung Ihrer Snapshot-Policys für OVHcloud Enterprise File Storage Volumes.

**Diese Anleitung erklärt, wie Sie in der OVHcloud Konsole eine Snapshot-Policy erstellen, auf Ihr Volume anwenden und löschen.**

## Voraussetzungen

- Sie verfügen über einen OVHcloud Enterprise File Storage mit verfügbarem Volume.

## Grundlagen

Ein Volume Snapshot ist eine schreibgeschützte Point-in-Time-Kopie eines Volumes.<br/>
Snapshots werden aus einem bestehenden, betriebsbereiten Volume erstellt. Sie können nicht separat davon existieren.

Eine Snapshot-Policy erlaubt es, die Erstellung von Snapshots anhand verschiedener Einstellungen zu automatisieren. Diese Regel kann gelöscht werden, wenn Sie sie nicht mehr benötigen.

## In der praktischen Anwendung

Wählen Sie Ihre Dienstleistung in der Liste aus.

### Snapshot-Policy erstellen

Mit einer Snapshot-Policy können Sie Snapshots automatisieren, indem Sie das Erstellungsintervall in Minuten, Stunden, Tagen, Wochen oder Monaten festlegen.
Außerdem müssen Sie die Anzahl der Kopien angeben, die Sie aufbewahren möchten.

1\. Öffnen Sie den Tab <code className="action">Richtlinien</code> Ihres Dienstes und klicken Sie auf <code className="action">Richtlinie erstellen</code>.

2\. Füllen Sie auf der Seite **Snapshot-Richtlinie erstellen** die Felder **Name der Richtlinie** und **Beschreibung der Richtlinie** aus. Klicken Sie anschließend auf <code className="action">Regel hinzufügen</code>, um der Policy eine oder mehrere Regeln hinzuzufügen.

3\. Füllen Sie die Felder der Regel aus: das für die Benennung der Snapshots erforderliche **Präfix**, die Felder **Minute(n)**, **Stunde(n)**, **Tag(e) des Monats**, **Monat(e)** und **Wochentag(e)** für die Erstellung des Snapshots sowie im Feld **Aufzubewahrende Kopien** die Anzahl der Kopien.

Über das Hilfesymbol jedes Feldes erhalten Sie weitere Informationen zu dessen Werten. Wenn Sie den Bereich **Beispiel** erweitern, werden zwei Sätze von Policy-Regeln mit einer Erläuterung ihrer Ergebnisse angezeigt.

Klicken Sie auf das Bestätigungssymbol der Zeile, um die Regel zu bestätigen. Wenn Sie alle Regeln hinzugefügt haben, klicken Sie auf <code className="action">Richtlinie erstellen</code>.

:::info
Sie müssen ein Präfix und einen Wert für die Minuten angeben. Optional können Sie Stunden, Tage und Monate der Ausführung auswählen, um den Zeitplan zu präzisieren. Die Regeln verwenden die Zeitzone UTC.

:::


Sie können eine Snapshot-Policy nach der Erstellung nicht mehr ändern. Wenn Sie neue Einstellungen für das Intervall anwenden müssen, löschen Sie die aktuelle Snapshot-Policy und erstellen Sie eine neue.

### Snapshot-Policy anwenden

Nachdem Sie die Snapshot-Policy erstellt haben, können Sie sie auf ein Volume anwenden.

1\. Öffnen Sie den Tab <code className="action">Volumes</code> Ihres Dienstes und klicken Sie auf den Namen des Volumes, auf das die Snapshot-Policy angewendet werden soll.

2\. Öffnen Sie den Tab <code className="action">Snapshots</code> des Volumes. Klicken Sie im Bereich **Snapshot-Richtlinie** auf <code className="action">Snapshot-Richtlinie verwalten</code>.

3\. Wählen Sie in dem sich öffnenden Fenster unter **Verfügbare Richtlinien** die anzuwendende Policy aus und klicken Sie dann auf <code className="action">Richtlinie anwenden</code>.

### Snapshot-Policy löschen

:::warning
Eine an ein Volume gebundene Snapshot-Policy kann nicht gelöscht werden. Wenn Sie eine Snapshot-Policy löschen möchten, die mit einem oder mehreren Volumes verknüpft ist, müssen Sie zuerst die Zuordnung dieser Policy aufheben, indem Sie diesen Volumes eine andere Snapshot-Policy zuordnen. Die Standard-Policy kann nicht gelöscht werden.

:::


So löschen Sie eine Snapshot-Policy:

1\. Öffnen Sie den Tab <code className="action">Richtlinien</code> Ihres Dienstes.

2\. Klicken Sie in der Zeile der zu löschenden Policy auf den Button <code className="action">...</code> und dann auf <code className="action">Löschen</code>.

3\. Bestätigen Sie mit einem Klick auf <code className="action">Richtlinie löschen</code>.
