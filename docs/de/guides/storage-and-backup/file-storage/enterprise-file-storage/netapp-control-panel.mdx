## Ziel

Enterprise File Storage Dienste können über die [OVHcloud API](/guides/storage-and-backup/file-storage/enterprise-file-storage/netapp-quick-start) oder in der <ManagerLink to="/">OVHcloud Konsole</ManagerLink> verwaltet werden.

**Diese Anleitung erklärt, wie Sie Enterprise File Storage Volumes und Snapshots in der OVHcloud Konsole verwalten.**

## Voraussetzungen

- Sie haben einen Enterprise File Storage Dienst in Ihrem OVHcloud Kunden-Account. Der Dienst kann über die [Produktseite](/links/storage/enterprise-file-storage) oder in der <ManagerLink to="/">OVHcloud Konsole</ManagerLink> bestellt werden.

[[cpnav:storage-enterprise-file-storage-console]]

## In der praktischen Anwendung <a name="instructions"></a>

Wählen Sie Ihren Dienst in der Liste aus.

Im Tab <code className="action">Übersicht</code> werden die Bereiche **Allgemeine Informationen** und **Dienstkonfiguration** Ihres Dienstes (mit einem Shortcut zur [Erstellung eines Volumes](#create_volume)) sowie die Bereiche **Netzwerkkonfiguration**, **Abonnement** und **Tags** angezeigt.

:::info
Detaillierte Informationen zu den technischen Eigenschaften der Enterprise File Storage Lösung finden Sie auf der Seite [Enterprise File Storage - Konzepte](/guides/storage-and-backup/file-storage/enterprise-file-storage/netapp-concepts).

:::

### Verwaltung der Volumes <a name="manage_volume"></a>

Wechseln Sie zum Tab <code className="action">Volumes</code>. Die Tabelle listet alle Volumes auf, die Sie für den ausgewählten Dienst erstellt haben. Klicken Sie auf den Namen eines Volumes, um dessen [Verwaltungsseite](#modify_volume) zu öffnen.

Um eine Aktion für ein Volume auszuführen, setzen Sie den Haken in der entsprechenden Zeile und öffnen Sie dann das Menü <code className="action">Aktionen (1)</code> über der Tabelle:

- **Volume bearbeiten**: Öffnet den [Tab "Information"](#modify_volume) des Volumes.
- **Volume anpassen**: Öffnet ein Fenster, in dem Sie im Feld **Neue Größe** die neue Größe des Volumes eingeben und dann auf <code className="action">Anpassen</code> klicken.
- **Snapshots verwalten**: Öffnet den [Tab "Snapshots"](#snapshots) des Volumes.
- **IP-Zugriff verwalten (ACL)**: Öffnet den [Tab "ACL"](#access_control) des Volumes.
- **Volumes replizieren**: Repliziert die ausgewählten Volumes auf einen anderen Enterprise File Storage Dienst.
- **Volume löschen**: Löscht dieses Volume, nachdem Sie die Aktion im daraufhin geöffneten Fenster bestätigt haben.

#### Erstellung eines Volumes <a name="create_volume"></a>

Klicken Sie auf den Button <code className="action">Volume erstellen</code>. Im daraufhin geöffneten Fenster können Sie die Felder **Name** und **Beschreibung** (optional) ausfüllen, das **Protokoll** auswählen, optional unter **Aus einem Snapshot erstellen** einen Snapshot auswählen, die **Größe** festlegen und optional den **Mount-Pfad** angeben. Klicken Sie zur Bestätigung auf <code className="action">Volume erstellen</code>.

#### Bearbeitung eines Volumes <a name="modify_volume"></a>

Klicken Sie in der Tabelle auf den Namen eines Volumes, um die Verwaltungsseite dieses Volumes zu öffnen.

Im Tab <code className="action">Information</code> werden die Details Ihres Volumes (Bereiche **Volume**, **Speicher** und **Nutzungsübersicht**) sowie der Bereich **Volume-Verbindung** mit dem Mount-Pfad und den Schritten zur Verbindung mit dem Volume angezeigt.

In diesem Tab können Sie außerdem den Namen (<code className="action">Namen ändern</code>) und die Beschreibung (<code className="action">Beschreibung ändern</code>) des Volumes ändern, seine Größe anpassen (<code className="action">Volume anpassen</code>) und seine Snapshot-Reserve ändern (<code className="action">Snapshot-Reserve ändern</code>).

Im Tab <code className="action">NFS-Verbindungen</code> werden die NFS-Verbindungen zum Volume aufgelistet, und im Tab <code className="action">Leistung</code> werden seine Leistungsmetriken angezeigt.

#### Löschen eines Volumes <a name="delete_volume"></a>

Sie können ein Volume löschen, indem Sie in seinem Tab <code className="action">Information</code> auf <code className="action">Volume löschen</code> klicken oder indem Sie im Tab <code className="action">Volumes</code> den Haken bei dem Volume setzen und im Menü <code className="action">Aktionen (1)</code> die Option <code className="action">Volume löschen</code> auswählen.

Bestätigen Sie den Löschvorgang, indem Sie `DELETE` in das Bestätigungsfeld eingeben, und klicken Sie dann auf den Button <code className="action">Volume löschen</code>.

### Verwaltung der Volume-Snapshots <a name="snapshots"></a>

:::info
Snapshots nutzen die Speicherkapazität Ihres Enterprise File Storage Angebots. Standardmäßig sind 5 % der Speicherkapazität eines Volumes für Snapshots reserviert.
:::

Im Tab <code className="action">Snapshots</code> eines Volumes werden alle für dieses Volume erstellten Snapshots aufgelistet. Sie können sie nach **Typ** filtern.

:::info
Sie können auch über Ihren Mount-Punkt auf Snapshots zugreifen, indem Sie die in der [NetApp-Dokumentation](https://library.netapp.com/ecmdocs/ECMP1196991/html/GUID-36DC110C-C0FE-4313-BF53-1C12838F7BBD.html) angegebenen Befehle verwenden.
:::

Im Bereich **Snapshot-Richtlinie** dieses Tabs können Sie die auf das Volume angewendete [Snapshot-Richtlinie](#snapshot_policy) und deren Regeln (<code className="action">Regeln anzeigen</code>) einsehen.

Um eine andere Richtlinie anzuwenden, klicken Sie auf <code className="action">Snapshot-Richtlinie verwalten</code>, wählen Sie unter **Verfügbare Richtlinien** eine Richtlinie aus und klicken Sie dann auf <code className="action">Richtlinie anwenden</code>. Die Richtlinie `default` kann nicht manuell ausgewählt werden.

Um Ihre [Snapshot-Richtlinien](#snapshot_policy) zu konfigurieren, kehren Sie zu Ihrem Dienst zurück und öffnen Sie den Tab <code className="action">Richtlinien</code>.

#### Erstellung eines Snapshots <a name="create_snapshot"></a>

Um einen neuen Snapshot vom Typ `manual` mit dem aktuellen Zustand des Volumes zu erstellen, klicken Sie im Tab <code className="action">Snapshots</code> (oder im Tab <code className="action">Information</code>) auf <code className="action">Snapshot erstellen</code>.

Im daraufhin geöffneten Fenster können Sie die Felder **Name** und **Beschreibung** des Snapshots ausfüllen (optional). Klicken Sie auf <code className="action">Snapshot erstellen</code>, um die Erstellung des Snapshots zu starten.

#### Bearbeitung eines Snapshots <a name="modify_snapshot"></a>

Um den Namen oder die Beschreibung eines Snapshots vom Typ `manual` zu ändern, klicken Sie in der entsprechenden Zeile auf den Button <code className="action">...</code> und dann auf <code className="action">Bearbeiten</code>. Geben Sie im daraufhin geöffneten Fenster einen neuen Namen und/oder eine neue Beschreibung ein und klicken Sie dann auf <code className="action">Bestätigen</code>.

#### Löschen eines Snapshots <a name="delete_snapshot"></a>

:::warning
Snapshots vom Typ `system` können nicht gelöscht werden.
Diese sind für das reibungslose Funktionieren Ihres Enterprise File Storage Dienstes notwendig.
:::

Sie können einen Snapshot löschen, indem Sie im Tab <code className="action">Snapshots</code> in seiner Zeile auf den Button <code className="action">...</code> klicken und dann <code className="action">Löschen</code> auswählen. Klicken Sie im daraufhin geöffneten Fenster auf <code className="action">Snapshot löschen</code>.

#### Wiederherstellung eines Volumes mit einem seiner Snapshots <a name="restore_volume"></a>

:::warning
Beachten Sie, dass alle später erstellten Dateien oder Snapshots verloren gehen, sobald ein Volume mit einem Snapshot wiederhergestellt wurde.
Wenn ein Volume wiederhergestellt wird, werden alle darin enthaltenen Daten durch die Snapshot-Daten ersetzt. Diese Aktion kann nicht rückgängig gemacht werden.
:::

Sie können ein Volume mit seinem neuesten Snapshot wiederherstellen, indem Sie im Tab <code className="action">Snapshots</code> auf <code className="action">Letzten Snapshot wiederherstellen</code> klicken. Geben Sie im daraufhin geöffneten Fenster zur Bestätigung den Namen des Volumes ein und klicken Sie dann auf <code className="action">Letzten Snapshot wiederherstellen</code>. Wenn der neueste Snapshot vom Typ `automatic` ist, wird er vor der Wiederherstellung des Volumes zunächst als Snapshot vom Typ `manual` gespeichert.

:::info
Um ein Volume mit einem Snapshot wiederherzustellen, der älter als der letzte Snapshot ist, müssen Sie Snapshots löschen, bis der gewünschte Snapshot der neueste ist.
:::

#### Aufbewahren automatischer Snapshots <a name="hold_snapshot"></a>

Ein von einer [Snapshot-Richtlinie](#snapshot_policy) erstellter Snapshot vom Typ `automatic` kann aufbewahrt werden, indem Sie im Tab <code className="action">Snapshots</code> in seiner Zeile auf den Button <code className="action">...</code> klicken und dann <code className="action">Speichern</code> auswählen.

Nach Abschluss dieses Vorgangs ändert sich der Typ des Snapshots in `manual`, und der Snapshot wird nicht mehr durch eine Snapshot-Richtlinie rotiert.

Sie können auch ein neues Volume aus einem Snapshot vom Typ `manual` erstellen: Klicken Sie in seiner Zeile auf den Button <code className="action">...</code> und dann auf <code className="action">Volume erstellen</code>.

#### Verwaltung der Volume-ACLs <a name="access_control"></a>

Die Zugriffskontrolle auf Volumes funktioniert über IP-Adressbeschränkungen. Da standardmäßig keine konfiguriert sind, besteht der erste Schritt bei neuen Volumes darin, die IP-Adressen oder -Bereiche festzulegen, von denen aus der Zugriff erlaubt wird.

Öffnen Sie den Tab <code className="action">ACL</code> des Volumes und klicken Sie auf <code className="action">Regel hinzufügen</code>. Geben Sie im Bereich **ACL-Regel hinzufügen** eine **IP-Adresse** oder einen Adressblock (CIDR) ein, wählen Sie die **Zugriffsebene** (`Nur Lesen` oder `Lesen/Schreiben`) aus und klicken Sie dann auf <code className="action">Hinzufügen</code>.

Um einen Volume-Zugriff zu entfernen, klicken Sie in der entsprechenden Zeile auf den Button <code className="action">...</code> und dann auf <code className="action">Regel löschen</code>.

### Verwaltung der Snapshot-Richtlinien <a name="snapshot_policy"></a>

:::info
Standardmäßig ist jedes Volume durch die Snapshot-Richtlinie `default` geschützt, die in regelmäßigen Abständen Snapshots des Volumes erstellt.
:::

Durch das Hinzufügen von Richtlinien können Sie die Erstellung von Snapshots für alle Ihre Volumes planen.

Wechseln Sie zum Tab <code className="action">Richtlinien</code> Ihres Dienstes. Die Tabelle listet alle für den ausgewählten Dienst erstellten Richtlinien auf.

Eine Standardrichtlinie ist bereits vorhanden und kann nicht geändert werden. Um eine eigene Richtlinie hinzuzufügen, klicken Sie auf den Button <code className="action">Richtlinie erstellen</code>.

Füllen Sie auf der Seite **Snapshot-Richtlinie erstellen** die Felder **Name der Richtlinie** und **Beschreibung der Richtlinie** aus. Klicken Sie dann auf <code className="action">Regel hinzufügen</code>, um der Richtlinie eine oder mehrere Regeln hinzuzufügen.

Legen Sie in den Feldern **Minute(n)**, **Stunde(n)**, **Tag(e) des Monats**, **Monat(e)** und **Wochentag(e)** den Zeitpunkt der Snapshot-Erstellung fest, geben Sie im Feld **Präfix** das für die Benennung der Snapshots benötigte Präfix und im Feld **Aufzubewahrende Kopien** die Anzahl der aufzubewahrenden Kopien ein. Wenn Sie den Bereich **Beispiel** erweitern, werden zwei Regelsätze mit einer Erläuterung ihres Ergebnisses angezeigt.

Klicken Sie auf das Bestätigungssymbol der Zeile, um die neue Regel hinzuzufügen. Wenn Sie alle Regeln hinzugefügt haben, klicken Sie auf <code className="action">Richtlinie erstellen</code>.

[Wählen Sie ein Volume aus](#manage_volume) und gehen Sie zu dessen Tab <code className="action">Snapshots</code>, um [Ihre Richtlinien anzuwenden](#snapshots).

Um eine Richtlinie zu löschen, klicken Sie in der entsprechenden Zeile auf den Button <code className="action">...</code> und dann auf <code className="action">Löschen</code>.
