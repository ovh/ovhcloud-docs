## Ziel

**Diese Anleitung beschreibt die bekannten Einschränkungen und Beschränkungen des Produkts Backup Licenses, die Sie kennen sollten, bevor Sie Ihre Lizenz bestellen.**

## Bekannte Einschränkungen

### Version von Veeam Backup & Replication

- Unsere Infrastruktur unterstützt ausschließlich Veeam Backup & Replication Server, die mit **Version 12 oder höher** betrieben werden. Ein VBR-Server mit einer älteren Version kann nicht mit der OVHcloud Veeam Service Provider Console (VSPC) verbunden werden und kann daher keiner Lizenz zugewiesen werden.

### Betriebssystem und verfügbare Editionen

- VBR-Server, die unter **Linux** (Veeam Software Appliance) betrieben werden, unterstützen ausschließlich **Veeam Data Platform (VDP)** Lizenzen: Foundation, Advanced oder Premium.
- Die Edition **Veeam Enterprise Plus** ist ausschließlich für VBR-Server verfügbar, die unter **Windows** betrieben werden.

Die folgende Tabelle fasst die möglichen Kombinationen zusammen:

| VBR-Betriebssystem | Veeam Enterprise Plus | Veeam Data Platform (Foundation / Advanced / Premium) |
|---|:---:|:---:|
| **Windows** | Ja | Ja |
| **Linux** (Veeam Software Appliance) | Nein | Ja |

:::info
Details zu jeder Edition und ihren Funktionen finden Sie in der Anleitung "[Bestellung und Konfiguration Ihrer ersten Lizenz](/guides/storage-and-backup/backup-licenses/first-configuration)".

:::

### Über Veeam Enterprise lizenzierte VBR-Server

- Ein VBR-Server, dessen Lizenz noch über das frühere OVHcloud Angebot **Veeam Enterprise** verwaltet wird, kann keine Lizenz von Backup Licenses erhalten: Seine Lizenz wird von einem Veeam Backup Enterprise Manager Server gesteuert, der verhindert, dass die VSPC eine neue Lizenz zuweist.
- Sie müssen daher **Ihren früheren Dienst Veeam Enterprise (`backupserverenterprise`) kündigen und 24 Stunden warten, bevor Sie Ihren VBR-Server mit der VSPC verbinden**. Die vollständige Vorgehensweise wird in der Anleitung "[Von Veeam Enterprise zu Backup Licenses migrieren](/guides/storage-and-backup/backup-licenses/migration-veeam-enterprise)" beschrieben.
