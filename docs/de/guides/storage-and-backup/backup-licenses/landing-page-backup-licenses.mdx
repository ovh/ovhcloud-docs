## Backup Licenses Anleitungen

Mit dem Produkt **Backup Licenses** können Sie Veeam-Lizenzen bei OVHcloud für Ihren eigenen **Veeam Backup & Replication** (VBR) Server mieten, unabhängig davon, ob dieser bei OVHcloud oder in Ihrer eigenen Infrastruktur gehostet wird. Wählen Sie Ihr Lizenzniveau, skalieren Sie ohne langfristige Vertragsbindung nach oben oder unten und überlassen Sie OVHcloud die Verwaltung der Lizenz und des Speichers, während Sie die volle Kontrolle über Ihren Veeam Server behalten. Die Lizenz wird automatisch angewendet und verlängert, sobald Ihr VBR Server mit der OVHcloud **Veeam Service Provider Console** (VSPC) verbunden ist, und jede Lizenz enthält einen verwalteten Vault — 500 GB Object Storage — zum Speichern Ihrer Backup-Daten. Backup Licenses ersetzt das Angebot Veeam Enterprise.

Ob Sie Ihre erste Lizenz bestellen, von Veeam Enterprise migrieren, Ihren Backup-Speicher verwalten oder eine Verbindung beheben möchten: Die folgenden Anleitungen decken das gesamte Produkt ab.
