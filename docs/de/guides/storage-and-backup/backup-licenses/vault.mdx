## Ziel

Ein **Vault** ist ein von OVHcloud bereitgestellter Speicherplatz, an den Sie Ihre Backup-Daten senden können. Bei Backup Licenses wird mit Ihrer ersten Lizenz automatisch ein erster Vault geliefert.

**Diese Anleitung erläutert, wie die Vaults von Backup Licenses funktionieren, wie sie abgerechnet werden und wie Sie zusätzliche Vaults bestellen.**

## Voraussetzungen

- Sie haben eine Backup Licenses-Lizenz bestellt. Weitere Informationen finden Sie in unserer Anleitung "[Ihre erste Lizenz bestellen und konfigurieren](/guides/storage-and-backup/backup-licenses/first-configuration)".

## In der praktischen Anwendung

### Der "Bundle"-Vault

Ein **"Bundle"**-Vault wird standardmäßig mit Ihrer ersten Backup Licenses-Lizenz geliefert.

- Dieser Vault ist **an das Produktabonnement gebunden**: Er wird **gelöscht, wenn das Produkt Backup Licenses gekündigt wird**.
- Er ist **einzigartig**: Sie verfügen nur über einen "Bundle"-Vault, unabhängig davon, wie viele Lizenzen Sie besitzen.
- Er ist **bis 500 GB kostenlos**. Dieser Speicherplatz kann sowohl für Ihre VBR-Server als auch für andere Speicheranforderungen genutzt werden.

:::danger
Die Kündigung des Produkts Backup Licenses führt zur **Löschung des "Bundle"-Vaults und der darin enthaltenen Daten**. Stellen Sie sicher, dass Sie Ihre Daten abgerufen haben, bevor Sie kündigen.

:::

### Die Verbindungsdaten des Vault abrufen

Der "Bundle"-Vault wird als **S3<sup>1</sup>-Bucket** bereitgestellt. Um die Verbindungsdaten (Endpoint, Zugangsdaten) abzurufen, klicken Sie auf der Vault-Seite im OVHcloud Kundencenter auf <code className="action">Zugangsdaten anzeigen</code>.

Mit diesen Daten können Sie den Vault als Object Repository in Ihrem Server Veeam Backup & Replication konfigurieren oder mit einem beliebigen S3-kompatiblen Client darauf zugreifen.

### Abrechnung des "Bundle"-Vaults

- Die **ersten 500 GB sind** in Ihrem Backup Licenses-Abonnement **enthalten**, ohne zusätzliche Kosten.
- **Ab 500 GB** wird jedes zusätzlich verbrauchte GB **monatlich** zum **öffentlichen OVHcloud Object Storage-Tarif** abgerechnet.

:::info
Die aktuellen Preise finden Sie auf der [Object Storage Preisseite](/links/public-cloud/prices-object-storage).

:::

### Zusätzliche Vaults bestellen

Sie können **zusätzliche Vaults** über das OVHcloud Kundencenter bestellen.

Sie funktionieren genauso wie der "Bundle"-Vault (S3-Bucket, gleiche Verwendungszwecke, gleiche Zugriffsmethoden), mit einem Unterschied: Sie werden **ab dem ersten verbrauchten GB** zum öffentlichen OVHcloud Object Storage-Tarif abgerechnet. Es ist kein kostenloses Kontingent enthalten.

Die folgende Tabelle fasst die Unterschiede zusammen:

| | "Bundle"-Vault | Zusätzlicher Vault |
|---|---|---|
| **Bereitstellung** | Wird automatisch mit der ersten Lizenz geliefert | Wird bei Bedarf über das Kundencenter bestellt |
| **Anzahl** | Einer pro Abonnement | So viele wie benötigt |
| **Enthaltenes Volumen** | 500 GB kostenlos | Keines |
| **Abrechnung** | Ab dem 501. GB, zum öffentlichen Object Storage-Tarif | Ab dem ersten GB, zum öffentlichen Object Storage-Tarif |
| **Lebenszyklus** | Wird gelöscht, wenn das Produkt Backup Licenses gekündigt wird | Kann unabhängig gekündigt werden |
