## Ziel

**Erfahren Sie, wie Sie Ihre gesicherten Daten mit Backup Agent wiederherstellen.**

Ihnen stehen zwei Wiederherstellungsmethoden zur Verfügung, die Sie je nach Bedarf wählen:

- **Dateiwiederherstellung (FLR-Assistent)**: Dies ist die wichtigste und gängigste Methode. Sie ermöglicht es, eine oder mehrere Dateien oder Ordner aus einem Backup wiederherzustellen, ohne den Server neu zu starten.
- **Vollständige Serverwiederherstellung (Bare Metal Recovery)**: Sie ermöglicht es, das gesamte System aus einem Wiederherstellungs-ISO wiederherzustellen. Sie ist für Szenarien zur Notfallwiederherstellung gedacht, wenn der Server nicht mehr startet.

:::info
Weitere Informationen zum Produkt Backup Agent finden Sie auf [dieser Seite](/guides/storage-and-backup/backup-agent/product-presentation).

:::


## Voraussetzungen

- Sie haben einen Bare Metal Server mit installiertem und konfiguriertem Backup Agent. Lesen Sie unsere Anleitung "[So konfigurieren Sie Ihr erstes Backup](/guides/storage-and-backup/backup-agent/first-configuration)", um weitere Informationen zu erhalten.
- Mindestens ein durchgeführtes Backup. Lesen Sie unsere Anleitung "[Ihre Backups verwalten](/guides/storage-and-backup/backup-agent/backup-restore)" für weitere Informationen.

## In der praktischen Anwendung

### Dateiwiederherstellung (FLR-Assistent)

Dies ist die wichtigste Methode, um eine oder mehrere Dateien oder Ordner aus einem Backup wiederherzustellen.

Um Dateien und Ordner wiederherzustellen, klicken Sie auf die Registerkarte, die Ihrem Betriebssystem entspricht:

<Tabs>
  <Tab label="Windows">
    Öffnen Sie die Anwendung "Veeam Agent" auf Ihrem Bare Metal Server:
    
    <img className="thumbnail" alt="Suche nach der Veeam Agent-Anwendung" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-bkpagent-search.png" loading="lazy" />

Gehen Sie zum Menü und wählen Sie <code className="action">Restore File</code>:
    
    <img className="thumbnail" alt="Wiederherstellungsmenü von Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-menu.png" loading="lazy" />

Wählen Sie im Assistenten den gewünschten Wiederherstellungspunkt aus:
    
    <img className="thumbnail" alt="Wiederherstellungspunkte von Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-restore-points.png" loading="lazy" />

Bestätigen Sie anschließend:
    
    <img className="thumbnail" alt="Zusammenfassung des Wiederherstellungspunkts von Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-restore-point-summary.png" loading="lazy" />

Suchen Sie schließlich nach Ihrer Datei und wählen Sie eine Option:
    
    <img className="thumbnail" alt="Wiederherstellungsassistent von Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-wizard.png" loading="lazy" />
    
    - Restore - Overwrite: Ermöglicht Ihnen, die Datei wiederherzustellen und die aktuelle Datei auf dem Server zu überschreiben.
    - Restore - Keep: Ermöglicht Ihnen, die Datei wiederherzustellen, ohne die aktuelle Datei auf dem Server zu überschreiben.
    - Copy To: Ermöglicht Ihnen, die Datei an einen Speicherort auf Ihrem Server zu kopieren.
    - Explore: Ermöglicht Ihnen, das Backup zu durchsuchen.
    - Properties: Ermöglicht Ihnen, die Dateieigenschaften anzuzeigen.
    
    Das Starten einer Wiederherstellung zeigt Ihnen abschließend ein Fenster an, das den Transfer anzeigt:
    
    <img className="thumbnail" alt="Übertragung der Wiederherstellung von Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-transfer.png" loading="lazy" />
  </Tab>
  <Tab label="Linux">
    Um Dateien und Ordner unter Linux wiederherzustellen, stehen Ihnen zwei Optionen zur Verfügung: über die grafische Benutzeroberfläche oder über die Befehlszeile.
    
    #### Über die grafische Benutzeroberfläche
    
    1\. Melden Sie sich per SSH an Ihrem Bare Metal Server an.
    2\. Starten Sie die Veeam-Oberfläche, indem Sie den folgenden Befehl eingeben:
    
    ```bash
    sudo veeam
    ```
    
    3\. Wählen Sie in der Oberfläche die Option zur Dateiwiederherstellung aus.
    4\. Wählen Sie das Backup und den gewünschten Wiederherstellungspunkt.
    5\. Navigieren Sie durch das Backup, um die wiederherzustellenden Dateien oder Ordner zu finden.
    6\. Wählen Sie die Dateien aus und wählen Sie die Wiederherstellungsoption:
       - Zur ursprünglichen Position wiederherstellen
       - An einen neuen Speicherort kopieren
       - Backup durchsuchen
    
    #### Über die Befehlszeile
    
    Um Dateien über die Befehlszeile wiederherzustellen, müssen Sie das Backup zunächst einhängen:
    
    1\. Listen Sie Ihre verfügbaren Backups auf (verwenden Sie `--all`, um alle importierten Backups anzuzeigen):
    
    ```bash
    sudo veeamconfig backup list --all
    ```
    
    2\. Listen Sie die Wiederherstellungspunkte eines Backups auf:
    
    ```bash
    sudo veeamconfig backup info --id <sicherungs_id>
    ```
    
    3\. Einhängen eines Wiederherstellungspunkts:
    
    ```bash
    sudo veeamconfig point mount --id <punkt_id>
    ```

    Dies gibt eine Bestätigung des Einhängens aus und gibt die Sitzungs-ID an.
    
    ```bash
    Wiederherstellungspunkt ist eingehängt.
    Sitzungs-ID: [{<sitzungs_id>}].
    Protokolle gespeichert in: [/var/log/veeam/Mount/Session_########_######_{<sitzungs_id>}].
    ```

    4\. Sobald eingehängt, können Sie über den Einhängepunkt auf die Dateien zugreifen (in der Regel in `/mnt/backup/`).
    
    5\. Kopieren Sie die gewünschten Dateien vom Einhängepunkt an ihr Ziel.
    
    6\. Nach Abschluss der Wiederherstellung verwenden Sie die Sitzungs-ID, um das Backup auszuhängen:
    
    ```bash
    sudo veeamconfig session stop --id <sitzungs_id>
    ```
    
    Weitere Informationen finden Sie in der [Veeam-Dokumentation](https://helpcenter.veeam.com/docs/agentforlinux/userguide/files_restore_gui.html?ver=13) und in der [Dokumentation zur Wiederherstellung über die Befehlszeile](https://helpcenter.veeam.com/docs/agentforlinux/userguide/files_restore_cmd.html?ver=13).
  </Tab>
</Tabs>

### Vollständige Serverwiederherstellung (Bare Metal Recovery)

Bare Metal Recovery ist eine Funktion von Veeam, bei der im Voraus ein benutzerdefiniertes ISO-Image erstellt wird, das anschließend verwendet werden kann, um ein System zu starten und es von einem Backup wiederherzustellen, das auf einem anderen Server gespeichert ist. Diese Methode ist für Szenarien zur Notfallwiederherstellung gedacht, wenn Ihr Server nicht mehr startet.

Sie ermöglicht Folgendes:

- Ein **Wiederherstellungs-ISO-Image erstellen**: Mit dieser Datei können Sie Ihre Maschine starten, wenn das System nicht mehr bootet.
- Ihr ISO-Image verwenden, um auf Ihr letztes Backup zuzugreifen und es aus der OVHcloud-Infrastruktur wiederherzustellen.

:::warning
Diese Anleitung basiert auf dem Veeam Agent für Windows. Wenn Sie den Veeam Agent für Linux verwenden, ist das Vorgehen ähnlich, auch wenn die Oberfläche textbasiert ist.
:::


Um von der Wiederherstellungs-ISO zu starten, verwenden Sie das IPMI Ihres Bare Metal Servers, um die ISO zu laden.

#### Schritt 1: Wiederherstellungs-ISO erstellen

Wenn Ihr Computer nicht mehr startet, benötigen Sie ein Wiederherstellungs-ISO-Image, um ihn erneut zu starten.

:::warning
Dieses Image muss vor jedem Zwischenfall erstellt werden. Wenn Ihr Server nicht mehr verfügbar ist, können Sie es nicht mehr erstellen.
:::


So erstellen Sie es:

1\. Öffnen Sie auf Ihrer Maschine das Tool **Create Recovery Media**, das im Veeam Agent enthalten ist.

<img className="thumbnail" alt="Das Tool Create Recovery Media starten" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_01.png" loading="lazy" />

2\. Veeam fragt Sie, ob Sie zusätzliche Treiber einbinden möchten.

:::info
Wenn Sie spezielle Hardware verwenden (z. B. einen RAID-Controller), wählen Sie die erforderlichen Treiber aus. Andernfalls sind die Standardoptionen in der Regel ausreichend.
:::


<img className="thumbnail" alt="Treiber für das Boot-Image auswählen" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_02.png" loading="lazy" />

3\. Wählen Sie den Speicherort für die ISO aus und geben Sie ihr einen Namen.

<img className="thumbnail" alt="Speicherort und Namen der ISO festlegen" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_03.png" loading="lazy" />

4\. Warten Sie, bis der Vorgang abgeschlossen ist. Die ISO-Datei wird generiert.

<img className="thumbnail" alt="Wiederherstellungs-ISO erstellt" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_04.png" loading="lazy" />

<img className="thumbnail" alt="Wiederherstellungs-ISO" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_05.png" loading="lazy" />

Sie können diese ISO nun verwenden, um mit einem Tool wie Rufus einen bootfähigen USB-Stick zu erstellen.

#### Schritt 2: Die Maschine von der Wiederherstellungs-ISO starten

Wenn Ihr System nicht mehr startet und Sie es wiederherstellen müssen:

1\. Binden Sie die ISO in der Konsole Ihres Servers ein und starten Sie die Maschine anschließend davon.

:::tip
**Sie wissen nicht, wie Sie von einer ISO starten?**

Starten Sie Ihre physische Maschine neu und drücken Sie die angezeigte Taste (in der Regel F2, F12, ESC oder DEL), um auf das Boot-Menü zuzugreifen.
:::


2\. Sobald das System gestartet ist, öffnet sich der Veeam-Wiederherstellungsassistent. Klicken Sie auf <code className="action">Bare Metal Recovery</code>.

<img className="thumbnail" alt="Bare Metal Recovery starten" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_01.png" loading="lazy" />

3\. Wählen Sie <code className="action">Network Storage</code> aus, um auf Ihre Online-Backups zuzugreifen.

:::warning
Wenn das Netzwerk nicht erkannt wird, müssen Sie es möglicherweise manuell konfigurieren. Klicken Sie auf <code className="action">Configure network settings</code> und laden Sie die fehlenden Treiber.
:::


<img className="thumbnail" alt="Network Storage auswählen" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_02.png" loading="lazy" />

4\. Wählen Sie <code className="action">Veeam Cloud Connect repository</code> aus.

<img className="thumbnail" alt="Veeam Cloud Connect repository auswählen" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_03.png" loading="lazy" />

5\. Geben Sie die folgende Adresse ein, wenn Sie zur Angabe des Dienstanbieters aufgefordert werden:

<img className="thumbnail" alt="DNS eingeben" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_04.png" loading="lazy" />

:::warning
Um zu erfahren, welche DNS und welche Zugangsdaten Sie verwenden müssen, wenden Sie sich bitte an [unser Support-Team](/links/support-contact), um diese zu erhalten.
:::


6\. Geben Sie Ihren Benutzernamen und Ihr Passwort ein, um sich anzumelden.

<img className="thumbnail" alt="Zugangsdaten eingeben" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_05.png" loading="lazy" />

7\. Wählen Sie den Server aus, den Sie wiederherstellen möchten.

<img className="thumbnail" alt="Server auswählen" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_06.png" loading="lazy" />

8\. Wählen Sie den Wiederherstellungspunkt (Datum/Uhrzeit) aus, zu dem Sie zurückkehren möchten.

Wir empfehlen, das letzte erfolgreiche Backup zu verwenden, sofern Sie keinen bestimmten Grund haben, zu einer früheren Version zurückzukehren.

<img className="thumbnail" alt="Einen Wiederherstellungspunkt auswählen" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_07.png" loading="lazy" />

9\. Wählen Sie den Wiederherstellungsmodus aus, der zu Ihrer Situation passt (wählen Sie **Entire computer** für eine vollständige Wiederherstellung).

<img className="thumbnail" alt="Wiederherstellungsmodus" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_08.png" loading="lazy" />

10\. Überprüfen Sie die Zusammenfassung und starten Sie anschließend die Wiederherstellung.

<img className="thumbnail" alt="Wiederherstellung starten – Bestätigung" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_09.png" loading="lazy" />

<img className="thumbnail" alt="Wiederherstellung starten – Fortschritt" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_10.png" loading="lazy" />

:::warning
Die Dauer des Wiederherstellungsvorgangs hängt von der Größe Ihres Backups und der Geschwindigkeit Ihrer Internetverbindung ab. Nach Abschluss startet Ihr System mit dem Zustand neu, der dem ausgewählten Wiederherstellungspunkt entspricht.
:::
