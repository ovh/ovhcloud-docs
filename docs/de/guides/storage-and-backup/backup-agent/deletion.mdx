## Ziel

**Diese Anleitung erklärt, wie Sie verschiedene Elemente Ihres Backup Agent-Dienstes löschen können: Agenten, Vault und Tenant.**

## Voraussetzungen

- Ein aktiver Backup Agent-Dienst.

[[cpnav:baremetal-backup-agent-console]]

## In der praktischen Anwendung

### Einen Agenten löschen

:::info
**Verhalten je nach Nutzung des Agenten:**

- **Wenn der Agent nicht zum Übertragen von Daten verwendet wurde**: Er kann sofort gelöscht werden. Zunächst wird er deaktiviert, danach gelöscht.
- **Wenn Daten übertragen wurden**: Wir setzen den Agenten für 14 Tage in den Status "Deaktiviert", um Zeit für die Löschung von unveränderlichen Daten zu lassen.

:::


:::warning
Sobald Ihr Agent deaktiviert ist, können Sie keinen neuen Agenten auf demselben Server erstellen. Sie müssen warten, bis der erste Agent gelöscht ist.

:::


Klicken Sie im Tab <code className="action">Server</code> in der Zeile des Servers auf die Schaltfläche <code className="action">...</code> und dann auf <code className="action">Löschen</code>.

Klicken Sie im Fenster **Diesen Backup-Agent löschen** auf <code className="action">Bestätigen</code>.

### Einen Vault löschen

:::warning
Ein Vault kann nicht gelöscht werden, wenn er Daten enthält. Wenn Sie einen Vault löschen möchten, müssen Sie [Kundendienst kontaktieren](https://help.ovhcloud.com/csm?id=csm_get_help), der vor der Löschung mit Ihnen Prüfungen durchführt.

:::


Klicken Sie im Tab <code className="action">Vaults</code> auf den Namen des Vaults und dann auf <code className="action">Dienstleistung kündigen</code>. Ein mit VSPC-Tenants verknüpfter Vault kann nicht gelöscht werden.

Klicken Sie im Fenster **Vault löschen** auf <code className="action">Bestätigen</code>. Ein Bestätigungslink wird an die Kontakt-E-Mail-Adresse Ihres Kunden-Accounts gesendet: Der Vault wird erst gelöscht, wenn Sie die Löschung über diesen Link bestätigt haben.

### Einen Tenant löschen

:::warning
Derzeit kann ein Tenant nicht eigenständig gelöscht werden. Wenn Sie einen Tenant löschen möchten, müssen Sie [Kundendienst kontaktieren](https://help.ovhcloud.com/csm?id=csm_get_help). Wir werden Ihre Anfrage bearbeiten.

:::
