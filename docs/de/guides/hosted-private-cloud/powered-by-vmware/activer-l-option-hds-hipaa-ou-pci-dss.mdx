## Ziel

Sie haben die Möglichkeit, für Ihre Private Cloud die PCI-DSS-Zertifizierung zu aktivieren, was zum Beispiel beim Hosten von [Kreditkartendaten](https://www.ovh.de/private-cloud/payment-infrastructure/pci-dss.xml) unerlässlich sein kann.

**In dieser Anleitung erfahren Sie, wie Sie die PCI-DSS-Zertifizierung für Ihre Private Cloud aktivieren.**

## Voraussetzungen

- Sie verfügen über eine Private Cloud Infrastruktur mit Version 6.0 oder höher.

[[cpnav:privatecloud-vmware-vsphere-console]]

## In der praktischen Anwendung

### Überprüfen, dass die Sicherheitsoption aktiviert ist

Um Ihre Private Cloud an diese Zertifizierung anzupassen, muss eine der entsprechenden Sicherheitsoptionen aktiviert sein. Um dies zu überprüfen, gehen Sie in der OVHcloud Konsole zu **Private Cloud** › **Managed VMware vSphere** und wählen Sie den betreffenden Dienst in der Liste aus.

Der Dienst öffnet sich im Tab <code className="action">Dashboard</code>. Überprüfen Sie den Aktivierungsstatus der Sicherheitsoptionen im Bereich **Compliance** in der Zeile **Branchenspezifische Compliance**. **Bitte beachten Sie, dass es aktuell nicht möglich ist, mehrere Sicherheitsoptionen für dieselbe Private Cloud zu aktivieren.**

Wenn die gewünschte Sicherheitsoption nicht aktiviert ist, klicken Sie in dieser Zeile auf <code className="action">Branchenspezifische Compliance aktivieren</code>, um den Aktivierungsassistenten zu öffnen. Hierzu sind einige Voraussetzungen erforderlich:

- **Die Optionen [NSX](/links/hosted-private-cloud/vmware-nsx) und [vROps](/links/hosted-private-cloud/vmware-vrops) müssen installiert sein**: Im Tab <code className="action">Dashboard</code> können Sie im Bereich **Optionen** den Aktivierungsstatus dieser Optionen in den Zeilen **Netzwerk- und Sicherheitsvirtualisierung (NSX-T)** und **vRealize Operations (vROps)** überprüfen. Ist vROps nicht aktiviert, klicken Sie in der entsprechenden Zeile auf <code className="action">Optionen hinzufügen</code>.

- **Die Zugangseinstellungen für vCenter müssen eingeschränkt sein**: Im Tab <code className="action">Zugriffskontrolle</code> können Sie den Status der Zugriffsrichtlinie im Bereich **Sitzungseinstellungen** in der Zeile **vCenter-Zugriffsrichtlinie** überprüfen. Die Richtlinie wird dort angezeigt, kann aber nicht über die OVHcloud Konsole geändert werden: Wenn sie nicht eingeschränkt ist, kontaktieren Sie unsere Support-Teams, um sie ändern zu lassen. Wenn Sie hierbei Hilfe benötigen, lesen Sie die Anleitung "[Ihre Hosted Private Cloud in der OVHcloud Konsole verwalten](/guides/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud)".

- **Sie benötigen mindestens eine IP-Adresse mit der Berechtigung, sich mit vCenter zu verbinden**: Überprüfen Sie im Tab <code className="action">Zugriffskontrolle</code>, dass die Liste der IP-Adressen und Blöcke, die sich verbinden dürfen, mindestens eine autorisierte IP-Adresse enthält. Falls nötig, verwenden Sie den Button <code className="action">IP-Block zuordnen</code>. Wenn Sie hierbei Hilfe benötigen, lesen Sie die Anleitung "[Ihre Hosted Private Cloud in der OVHcloud Konsole verwalten](/guides/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud)".

Um sicherzustellen, dass Sie sich immer einloggen können, empfehlen wir, mindestens zwei autorisierte IP-Adressen einzurichten. Diese sollten natürlich fix und nicht dynamisch sein, um die Verfügbarkeit zu gewährleisten.

- **Die Informationen des Admin-Benutzers müssen vollständig sein und er verfügt über die erforderliche Berechtigung**: Überprüfen Sie im Tab <code className="action">Benutzer</code>, dass Telefonnummer und E-Mail-Adresse des Admin-Benutzers gespeichert sind und dass dieser die "**token validator**"-Berechtigung hat (Spalte **Token validator**). Falls nötig, öffnen Sie das Menü ⋮ (Spalte **Aktionen**) des Benutzers und klicken Sie dann auf <code className="action">Bearbeiten</code>, um den Benutzer zu bearbeiten: Das Fenster **Bearbeiten** zeigt die Felder **Mail** und **Telefonnummer** sowie die Berechtigung **Token Validator** an. Wenn Sie hierbei Hilfe benötigen, lesen Sie die Anleitung "[Ihre Hosted Private Cloud in der OVHcloud Konsole verwalten](/guides/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud)".

Um sicherzustellen, dass Sie sich im vCenter einloggen können, empfehlen wir Ihnen, mindestens zwei Benutzer mit den notwendigen Informationen und Berechtigungen (mit verschiedenen E-Mail-Adressen und Telefonnummern).

Der Aktivierungsassistent umfasst vier Schritte:

1. Im ersten Schritt wählen Sie die Zertifizierung aus, die für Ihren Dienst aktiviert werden soll (zum Beispiel **HDS (Healthcare Data) Certification** oder **Payment Card Industry Data Security Standard (PCI DSS) Certification**). Wählen Sie sie aus und klicken Sie dann auf <code className="action">Weiter</code>.
2. Im zweiten Schritt wird sichergestellt, dass die Zugriffsrichtlinie für vCenter eingeschränkt ist und dass Sie über mindestens eine IP-Adresse verfügen, die sich mit vCenter verbinden kann. Angezeigt werden die Zugriffsrichtlinie und die Anzahl der autorisierten IP-Adressen und Blöcke.
3. Im nächsten Schritt wird sichergestellt, dass die erforderlichen Informationen (mindestens) des Admin-Benutzers ausgefüllt sind: Mindestens einer Ihrer Admin-Benutzer muss eine Mobilnummer und eine E-Mail-Adresse haben und als "token validator" eingetragen sein. Falls nötig, verweist dieser Schritt auf den Tab <code className="action">Benutzer</code>, damit Sie Ihre Benutzer konfigurieren können.
4. Der letzte Schritt fasst Ihre Bestellung zusammen. Klicken Sie auf <code className="action">Place order</code>, um sie zu bestätigen.

Wenn Sie die Aktivierungsschritte durchgeführt haben, müssen Sie nur noch:

- den Erhalt des Tokens bestätigen, der per SMS an die Benutzer mit **token validator**-Berechtigung versendet wurde. So wird sichergestellt, dass Sie diese für die Bestätigung sensibler Operationen notwendigen Token empfangen können.
- die Dokumente vervollständigen, die Sie per E-Mail erhalten werden, um den vertraglichen Teil abzuschließen. 

Während Sie warten, empfehlen wir Ihnen, diese Anleitung weiter zu lesen und sich so bereits mit dem sicheren Interface vertraut zu machen. 

:::info
Bitte beachten Sie, dass das vSphere-Interface während der Aktivierung der Sicherheitsoption nicht verfügbar ist.

:::


### Mit der Verwendung des sicheren Interface beginnen

Nach der Aktivierung der Sicherheitsoption erhalten Sie per E-Mail eine Beschreibung der Funktionsweise des Token-Validierungsprozesses. Diese erklärt unter anderem, wie Token funktionieren und wie Sie diese verwenden können. 

Aus Sicherheitsgründen gilt Folgendes nach der Aktivierung der Sicherheitsoption:

- Alle für Ihre Private Cloud eingerichteten Benutzer sind deaktiviert.
- Ändern Sie die Passwörter Ihrer Benutzer, um dieser wieder zu aktivieren.
- Die Passwörter Ihrer Benutzer können von nun an nur noch über das sichere Interface geändert werden. Sie können diese Aktion nicht länger über die OVHcloud Konsole vornehmen. 

Zur Erinnerung: Es ist nicht möglich auf das sichere Interface zuzugreifen, bevor die Aktivierung der Sicherheitsoption abgeschlossen ist.

Nach fertiger Aktivierung können Sie sich über den Link, den Sie per E-Mail erhalten haben, auf dem sicheren Interface einloggen. Dieser Link entspricht in etwa der Form `https://pcc-xxx-xxx-xxx-xxx.ovh.com/secure/password-lost`. Sobald Sie eingeloggt sind, können Sie das Passwort des Admin-Benutzers und anschließend die Passwörter der anderen Benutzer ändern. Weitere Informationen hierzu finden Sie in unserer Anleitung [Das sichere Interface verwenden](/guides/hosted-private-cloud/powered-by-vmware/interface-secure).
