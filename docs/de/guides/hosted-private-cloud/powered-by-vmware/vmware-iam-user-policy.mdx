## Ziel

**Diese Anleitung erläutert, wie Sie eine OVHcloud Identität (einen Benutzer) mit einer globalen IAM-Richtlinie verknüpfen**.

## Voraussetzungen

- Sie verfügen über einen [OVHcloud Kunden-Account](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- Sie haben ein oder mehrere Hosted Private Cloud Produkte - VMware on OVHcloud, die mit diesem Account verbunden sind (Hosted Private Cloud powered by VMware, VMware Service Pack).
- Sie haben IAM für Ihren Hosted Private Cloud Dienst - VMware on OVHcloud aktiviert. Folgen Sie hierzu den Schritten der Anleitung [IAM für VMware on OVHcloud - IAM aktivieren](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-activation).

[[cpnav:iam-policies-console]]

## In der praktischen Anwendung

### Wie verknüpfe ich einen Benutzer mit einer globalen IAM-Richtlinie?

<img className="thumbnail" alt="Seite Meine Richtlinien mit der Liste der Richtlinien und der Spalte Aktionen" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-user-policy/console/iam_policies_resize.png" loading="lazy" />

Hier finden Sie die Richtlinien, die Sie bereits erstellt haben.

Klicken Sie in der Spalte **Aktionen** rechts neben Ihrer Richtlinie auf den Button <code className="action">⋮</code> und dann auf <code className="action">Richtlinie bearbeiten</code>.

<img className="thumbnail" alt="Seite Richtlinie bearbeiten mit dem Abschnitt Identitäten und dem Abschnitt Übersicht rechts" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-user-policy/console/iam_policies_modify.png" loading="lazy" />

Wählen Sie anschließend die gewünschten Identitäten im Abschnitt **Identitäten** aus, in dem jeder Identitätstyp einen eigenen Tab hat: **Benutzer**, **Gruppen**, **Servicekonten** und **Andere OVHcloud Kunden**. Ihre lokalen Benutzer werden im Tab **Benutzer** aufgelistet; für Benutzergruppen klicken Sie auf den Tab <code className="action">Gruppen</code>. Setzen Sie bei jeder Identität, die Sie der Richtlinie hinzufügen möchten, einen Haken im Kontrollkästchen.

<img className="thumbnail" alt="Abschnitt Identitäten mit den Tabs der Identitätstypen und der Benutzerliste mit Kontrollkästchen" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-user-policy/console/iam_add_user.png" loading="lazy" />

Im Tab **Gruppen** werden nur IAM-Gruppen (keine vSphere-IAM-Gruppen) aufgelistet. Achten Sie darauf, die richtige Gruppe aus der Liste auszuwählen: Um die Liste einzugrenzen, verwenden Sie das darüber befindliche Feld **Suchen**.

Um Ihre Richtlinie abzuschließen, klicken Sie dann unten im Formular auf <code className="action">Speichern</code> oder im Abschnitt **Übersicht** auf der rechten Seite auf <code className="action">Richtlinie bearbeiten</code>.

:::info
Wenn Ihre Identität nicht vorhanden ist, müssen Sie sie zuerst in der OVHcloud Konsole auf der Seite <ManagerLink to="/beta/#/iam/identities/users">Identitäten</ManagerLink> hinzufügen.

:::
