## Ziel

vRack bietet die Möglichkeit, verschiedene Cloud-Dienste von OVHcloud untereinander innerhalb eines oder mehrerer gesicherter privater Netzwerke (VLANs) zu verbinden.

**Diese Anleitung erklärt, wie Sie vRack für Ihre Hosted Private Cloud einrichten.**

## Voraussetzungen

- Sie haben eine [vRack](/links/network/vrack) Dienstleistung in Ihrem Account.
- Sie sind Administrator-Kontakt für die [Hosted Private Cloud](/links/hosted-private-cloud/enterprise) Infrastruktur, um Login-Daten zu erhalten.
- Sie haben eine aktive Benutzerkennung (erstellt in der <ManagerLink console to="/">OVHcloud Konsole</ManagerLink>).

[[cpnav:network-vrack-console]]

## In der praktischen Anwendung

### OVHcloud Konsole

Sobald Ihre [Hosted Private Cloud](/links/hosted-private-cloud/enterprise) Infrastruktur bereitgestellt ist, ist ihr "Rechenzentrum" in ein vRack eingebunden. Um es in der OVHcloud Konsole anzuzeigen, gehen Sie zu **Netzwerk** › <code className="action">vRack</code>, wählen Sie Ihr vRack aus der Liste aus und öffnen Sie dann den Tab <code className="action">Zugeordnete Dienste</code>.

Sie können das "Rechenzentrum" Ihrer Private Cloud in ein anderes vRack verschieben: Klicken Sie in der Zeile **Private Cloud** auf <code className="action">Verschieben</code>. Wählen Sie im Fenster **Verschieben eines Private Cloud Rechenzentrums** das **Ziel-vRack** aus und klicken Sie dann auf <code className="action">Verschieben</code>. Dieser Vorgang führt zu einer Ausfallzeit von etwa 5 Minuten.

### vSphere Client

Im vSphere Client finden Sie die vRack-kompatiblen VLANs im Bereich `Networks`, der sich im Ordner *vRack* befindet.

:::tip
Standardmäßig liefert Ihnen OVHcloud eine Infrastruktur mit 11 VLANs (VLAN10 bis VLAN20).

:::


<img className="thumbnail" alt="VLAN" src="/images/hosted-private-cloud/powered-by-vmware/using-private-cloud-in-vrack/vRackVsphere.png" loading="lazy" />

Sie können deren Einstellungen ändern oder sie neu einrichten; verwenden Sie dazu [diese Anleitung](/guides/hosted-private-cloud/powered-by-vmware/create-vlan).

Anschließend können Sie die *Distributed Port Groups* den Netzwerkinterfaces Ihrer virtuellen Maschinen zuweisen.
