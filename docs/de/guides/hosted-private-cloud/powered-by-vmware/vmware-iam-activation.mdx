## Ziel

**Diese Anleitung erklärt, wie Sie IAM mit Hosted Private Cloud - VMware on OVHcloud über die OVHcloud Konsole oder mit der OVHcloud API aktivieren**.

## Voraussetzungen

- Sie verfügen über einen [OVHcloud Kunden-Account](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- Sie haben ein oder mehrere Hosted Private Cloud - VMware on OVHcloud Produkte, die mit diesem Kunden-Account verbunden sind (Hosted Private Cloud powered by VMware, VMware Service Pack).

[[cpnav:privatecloud-vmware-vsphere-console]]

## In der praktischen Anwendung

### IAM aktivieren

:::info
Dieser Vorgang kann bis zu 30 Minuten dauern.

:::


### Über die OVHcloud Konsole

Wählen Sie Ihre Infrastruktur aus und öffnen Sie dann den Tab <code className="action">Benutzer</code>.

Klicken Sie im Bereich **OVHcloud IAM** unten im Tab auf <code className="action">OVHcloud IAM aktivieren</code>.

<img className="thumbnail" alt="Bereich OVHcloud IAM mit dem Status Deaktiviert und dem Link OVHcloud IAM aktivieren" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_2.png" loading="lazy" />

:::warning
Nur das Produkt vSphere ist in OVHcloud IAM integriert. Eine Infrastruktur mit erweiterten Sicherheitsoptionen oder einem zertifizierten Dienst (HDS, PCI-DSS oder SNC) kann OVHcloud IAM derzeit nicht nutzen. Wenn Sie eine dieser zertifizierten Optionen oder einen dieser Dienste später aktivieren, müssen Sie OVHcloud IAM deaktivieren.
:::

Klicken Sie in dem sich öffnenden Fenster **OVHcloud IAM aktivieren** auf <code className="action">Bestätigen</code>.

:::tip
Sobald IAM aktiviert ist, lautet der Status `Aktiviert` und wird grün angezeigt.

:::

<img className="thumbnail" alt="Tab Benutzer mit dem Bereich OVHcloud IAM im Status Aktiviert" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_3.png" loading="lazy" />

### Über die OVHcloud API

:::tip
Lesen Sie die Anleitung [Erste Schritte mit der OVHcloud API](/guides/manage-and-operate/api/first-steps), um sich mit der Verwendung der OVHcloud APIv6 vertraut zu machen.

:::


:::warning
Ersetzen Sie `serviceName` durch die Referenz Ihres Hosted Private Cloud Dienstes im Format `pcc-XXX-XXX-XXX-XXX`.

:::


Um die IAM-Option zu aktivieren, führen Sie folgenden API-Aufruf aus:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/enable"} />


#### Überprüfen, ob IAM aktiviert ist

Um die Aktivierung von IAM zu überprüfen, führen Sie folgenden API-Aufruf aus:

<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\{serviceName\}/iam"} />

Antwort der API:

```shell
{
  "state": "enabled",
  "identityProviderId": 275
}
```

### IAM deaktivieren

Sie können OVHcloud IAM auf Ihrer Hosted Private Cloud deaktivieren.

#### Über die OVHcloud Konsole

Wählen Sie Ihre Infrastruktur aus und öffnen Sie dann den Tab <code className="action">Benutzer</code>.

Klicken Sie im Bereich **OVHcloud IAM** unten im Tab auf <code className="action">OVHcloud IAM deaktivieren</code>. Klicken Sie in dem sich öffnenden Fenster **OVHcloud IAM deaktivieren** auf <code className="action">Bestätigen</code>.

#### Über die OVHcloud API

Um die IAM-Option zu deaktivieren, führen Sie folgenden API-Aufruf aus:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/disable"} />
