## Ziel

Die Berechtigungen und Passwörter von Nutzern des vSphere Clients werden in der OVHcloud Konsole verwaltet.

**Diese Anleitung erklärt, wie Sie Ihr Nutzerpasswort ändern können.**

## Voraussetzungen

- Sie haben Zugriff auf die <ManagerLink console to="/">OVHcloud Konsole</ManagerLink>.
- In der OVHcloud Konsole wurde ein Nutzeraccount für Sie angelegt. Weitere Informationen finden Sie in unserer Anleitung "[Ihre Hosted Private Cloud in der OVHcloud Konsole verwalten](/guides/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud#benutzer)".

[[cpnav:privatecloud-vmware-vsphere-console]]

## In der praktischen Anwendung

### Passwort ändern

Gehen Sie in der OVHcloud Konsole zu **Private Cloud** › **Managed VMware vSphere** und wählen Sie Ihren Dienst aus der Liste aus. Klicken Sie dann auf den Tab <code className="action">Benutzer</code>.

Öffnen Sie das Menü ⋮ (Spalte **Aktionen**) des betreffenden Nutzers und klicken Sie auf <code className="action">Passwort ändern</code>.

Geben Sie im Fenster **Passwort ändern** ein neues Passwort in das Feld **Neues Passwort** ein, bestätigen Sie es im Feld **Bestätigung des Passworts** und klicken Sie dann auf <code className="action">Bestätigen</code>.

:::info
Wenn Sie kein neues Passwort eingeben, wird ein zufällig generiertes Passwort per E-Mail an die Adresse gesendet, die mit dem Nutzer verbunden ist.

:::

Bei einem Dienst mit einer zertifizierten Compliance-Option (PCI DSS, HDS…) zeigt das Fenster kein Formular an: Es gibt die Adresse der zertifizierten Oberfläche an (`https://<ihr-dienst>/secure`), über die Sie das Passwort ändern.

:::warning
Um die Sicherheit Ihrer Infrastruktur nicht zu gefährden empfehlen wir Ihnen, diese bewährte Verfahren zu befolgen. Ihr Passwort muss:

- Aus mindestens 8 Zeichen bestehen.
- Mindestens 3 verschiedene Zeichentypen enthalten.
- Es darf kein Wort aus dem Wörterbuch sein.
- Es darf keine privaten Informationen enthalten.
- Es darf nicht für mehrere Zugänge verwendet werden.
- In einem Passwort-Manager gespeichert sein.
- Alle drei Monate geändert werden.
- Sich von den vorherigen Passwörtern unterscheiden.

:::
