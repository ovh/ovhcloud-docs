## Ziel

Die globalen vSphere-Berechtigungen ermöglichen es, die Rechte eines Benutzers für Ihren Hosted Private Cloud-Dienst zu definieren. Über das OVHcloud Kundencenter können Sie diese Optionen für jeden Benutzer über Kontrollkästchen aktivieren oder deaktivieren.

In dieser Anleitung erfahren Sie, wie Sie diese globalen Berechtigungen über das OVHcloud Kundencenter verwalten.

## Voraussetzungen

- Ein aktiver [Hosted Private Cloud-Dienst](/links/hosted-private-cloud/vmware)
- Ein bereits auf Ihrem Dienst erstellter [vSphere-Benutzer](/guides/hosted-private-cloud/powered-by-vmware/vsphere-interface-connexion)
- Zugriff auf das <ManagerLink to="/">OVHcloud Kundencenter</ManagerLink> mit ausreichenden Rechten zur Benutzerverwaltung

## In der praktischen Anwendung

### Auf die Benutzerechtsverwaltung zugreifen

1. Öffnen Sie das <ManagerLink to="/">OVHcloud Kundencenter</ManagerLink>. Klicken Sie in der oberen Leiste auf <code className="action">Hosted Private Cloud</code>, dann im linken Menü auf <code className="action">Managed VMware vSphere</code>, und wählen Sie Ihren PCC-Dienst aus.

2. Gehen Sie zum Tab <code className="action">Nutzer</code>.

    <img className="thumbnail" alt="Tab Benutzer" src="/images/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud/en05users.png" loading="lazy" />

3. Öffnen Sie in der Zeile des betreffenden Benutzers das Menü <code className="action">...</code> und klicken Sie auf <code className="action">Bearbeiten</code>.

### Globale Berechtigungen konfigurieren

1. Im Bearbeitungsfenster des Benutzers entsprechen mehrere Kontrollkästchen den globalen Berechtigungen.

2. Aktivieren oder deaktivieren Sie die Optionen je nach den Rechten, die Sie dem Benutzer gewähren möchten.

    <img className="thumbnail" alt="Fenster zur Bearbeitung der Benutzerrechte" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/user-global-rights.png" loading="lazy" />

3. Bestätigen Sie die Änderung.

### Verfügbare Berechtigungen

Die globalen Berechtigungen werden durch die folgenden Kontrollkästchen im Bearbeitungsfenster des Benutzers dargestellt:

| Berechtigung | Beschreibung |
|---|---|
| Token Validator | Ermöglicht dem Benutzer, Vorgänge zu validieren, die ein Validierungs-Token erfordern. Diese Berechtigung ist in der Regel nützlich, wenn die Zwei-Faktor-Authentifizierung (2FA) für den Dienst aktiviert ist, beispielsweise im Rahmen bestimmter Zertifizierungen wie Hosting von Gesundheitsdaten (HDS). |
| IP | Ermöglicht dem Benutzer, die mit dem Dienst verbundenen IP-Adressen zu verwalten. |
| Failover-IP | Ermöglicht dem Benutzer, die mit dem Dienst verbundenen IP-Failover-Adressen zu verwalten. |
| NSX-Interface | Gewährt Zugriff auf die NSX-Netzwerkverwaltungsoberfläche. |
| Verschlüsselungsverwaltung | Ermöglicht dem Benutzer, die Verschlüsselung der virtuellen Maschinen (KMS) zu verwalten. |

### Rechte pro Datacenter verwalten

Zusätzlich zu den globalen Berechtigungen auf Dienstebene können Sie Rechte auf Ebene jedes virtuellen Datacenters in Ihrer Hosted Private Cloud definieren.

1. Im Tab <code className="action">Nutzer</code>, in der Zeile des betreffenden Benutzers, öffnen Sie das Menü <code className="action">...</code> und klicken Sie auf <code className="action">Die Rechte für jedes Datacenter anzeigen / ändern</code>.

    <img className="thumbnail" alt="Tab Benutzer und Aktionsmenü" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/users-actions-menu.png" loading="lazy" />

2. Auf der Seite **Verwaltung der Rechte des Nutzers nach Rechenzentrum** suchen Sie die Zeile des entsprechenden Datacenters. Klicken Sie auf das Menü <code className="action">...</code> (oder auf <code className="action">Rechte ändern</code>), um die Rechte zu bearbeiten.

    <img className="thumbnail" alt="Rechte pro Datacenter verwalten" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/rights-by-datacentre.png" loading="lazy" />

3. Im Fenster **Rechte bearbeiten** konfigurieren Sie die gewünschten Rechte und bestätigen Sie.

    <img className="thumbnail" alt="Fenster zur Rechtebearbeitung" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/edit-rights-modal.png" loading="lazy" />

#### Rechte-Referenz

**vSphere Zugang** — globale Benutzerrechte auf vSphere.

| Recht        | Beschreibung                    |
|--------------|---------------------------------|
| Operator     | Nur für OVHcloud-Administratoren |
| Kein         | Kein Zugriff                    |
| Schreibgeschützt | Schreibgeschützter Zugriff  |
| Lesen/Schreiben | Lese- und Schreibzugriff     |

**Zugang zum vmNetwork** — Verwaltungsrechte für den öffentlichen Netzwerkabschnitt ("VM Network" in vSphere).

| Recht        | Beschreibung                                                   |
|--------------|---------------------------------------------------------------|
| Operator     | Ermöglicht die Konfiguration von VMs in einem öffentlichen Netzwerk |
| Kein         | Kein Zugriff                                                  |
| Schreibgeschützt | Nur Lesezugriff                                           |

**Zugang zu V(x)LAN / GENEVE** — Verwaltungsrechte für den privaten Netzwerkabschnitt (VXLAN/GENEVE für Hosted Private Cloud, VLAN für SDDC).

| Recht          | Beschreibung                                                                                          |
|----------------|-------------------------------------------------------------------------------------------------------|
| Operator        | Ermöglicht die Konfiguration von VMs in einem privaten Netzwerk                                       |
| Administrator   | Ermöglicht die Verwaltung von Portgruppen auf dem virtuellen Switch (erstellen, ändern, löschen). Nur SDDC und Premier |
| Kein           | Kein Zugriff                                                                                         |
| Schreibgeschützt | Nur Lesezugriff                                                                                      |

**Verwaltung der Hosts und Speicher** — wenn aktiviert, kann der Benutzer Hosts und Speicher über das OVHcloud-Plugin im vSphere-Client hinzufügen oder löschen.

### Weiterführende Informationen zu granularen Rechten

Die oben beschriebenen Berechtigungen gelten auf der Dienstebene (vSphere-Cluster) oder auf der Ebene jedes virtuellen Datacenters. Wenn Sie einem Benutzer nur den Zugriff auf bestimmte Objekte des vSphere-Inventars gewähren möchten, beispielsweise eine virtuelle Maschine, einen Datastore oder einen Ordner, müssen Sie die [granularen Rechte auf vSphere-Objekte](/guides/hosted-private-cloud/powered-by-vmware/vsphere-granular-rights) verwenden.
