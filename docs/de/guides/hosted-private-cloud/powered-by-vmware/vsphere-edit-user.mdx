## Ziel

Ein Name, Vorname, eine Telefonnummer und E-Mail-Adresse können mit dem vSphere-Nutzer Ihrer Private Cloud verbunden werden. Die E-Mail-Adresse ermöglicht insbesondere die Bestätigung per Token.

**Diese Anleitung erklärt, wie Sie eine E-Mail-Adresse mit Ihrem Nutzerprofil bei vSphere verbinden können.**

## Voraussetzungen

- Sie verfügen über eine [Hosted Private Cloud](https://www.ovhcloud.com/de/enterprise/products/hosted-private-cloud/) Infrastruktur.

[[cpnav:privatecloud-vmware-vsphere-console]]

## In der praktischen Anwendung

Wählen Sie die betreffende Infrastruktur aus.

Gehen Sie auf den Reiter <code className="action">Benutzer</code>, öffnen Sie das Menü ⋮ (Spalte **Aktionen**) des betreffenden Nutzers und klicken Sie dann auf <code className="action">Bearbeiten</code>.

Das Fenster **Bearbeiten** wird geöffnet. Sie können Ihren Namen, Vornamen, Ihre Telefonnummer und E-Mail-Adresse festlegen.

In diesem Fenster können Sie außerdem die Berechtigungen **Token Validator**, **IP**, **Failover-IP** und **Verschlüsselungsverwaltung** erteilen. Die Berechtigung **Token Validator** wird verwendet, um bestimmte kritische Aktionen in Infrastrukturen mit aktivierter Option **Advanced Security** zu genehmigen.

Klicken Sie auf <code className="action">Speichern</code>, um Ihre Änderungen zu speichern.
