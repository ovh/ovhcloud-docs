## Ziel

Ein Name, Vorname, eine Telefonnummer und E-Mail-Adresse können mit dem vSphere-Nutzer Ihrer Private Cloud verbunden werden. Die E-Mail-Adresse ermöglicht insbesondere die Bestätigung per Token.

**Diese Anleitung erklärt, wie Sie eine E-Mail-Adresse mit Ihrem Nutzerprofil bei vSphere verbinden können.**

---

- **Direktlink:** [VMware vSphere](/links/control-panel/privatecloud-vmware-vsphere)
- **Navigationspfad:** <code className="action">Hosted Private Cloud</code> > <code className="action">Managed VMware vSphere</code> > Wählen Sie Ihren vSphere Dienst aus

## Voraussetzungen

- Sie verfügen über eine [Hosted Private Cloud](https://www.ovhcloud.com/de/enterprise/products/hosted-private-cloud/) Infrastruktur.
- Sie haben Zugriff auf Ihr <ManagerLink to="/">OVHcloud Kundencenter</ManagerLink>.

## In der praktischen Anwendung

Loggen Sie sich in Ihrem <ManagerLink to="/">OVHcloud Kundencenter</ManagerLink> ein und wählen Sie dann den Bereich `Hosted Private Cloud`. Klicken Sie im linken Menü auf `Private Cloud` und wählen Sie die betreffende Infrastruktur aus.

<img className="thumbnail" alt="vSphere-Nutzer" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-edit-user/addMailOnUser01.png" loading="lazy" />

Gehen Sie auf den Reiter <code className="action">Benutzer</code>, klicken Sie rechts vom jeweiligen Nutzer auf `...` und dann auf <code className="action">Bearbeiten</code>.

<img className="thumbnail" alt="vSphere-Nutzer" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-edit-user/addMailOnUser02.png" loading="lazy" />

Das folgende Fenster wird angezeigt:

<img className="thumbnail" alt="vSphere-Nutzer" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-edit-user/addMailOnUser03.png" loading="lazy" />

Sie können Ihren Namen, Vornamen, Ihre Telefonnummer und E-Mail-Adresse festlegen.

In diesem Fenster können Sie ebenfalls Bearbeitungsrechte hinzufügen: Für **IP** Adressen, **Additional IP** und das **NSX Interface**, sowie das Recht **Token Validator**. Es wird verwendet, um bestimmte kritische Aktionen in Infrastrukturen mit aktivierter Option zu **erweiterter Sicherheit** zu genehmigen.

Klicken Sie auf den Button <code className="action">Bestätigen</code>, um Ihre Änderungen zu bestätigen.
