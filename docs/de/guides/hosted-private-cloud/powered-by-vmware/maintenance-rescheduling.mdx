## Ziel

Wenn Wartungsarbeiten geplant sind, die Ihre Hosted Private Cloud Infrastruktur betreffen, erhalten Sie eine Benachrichtigung per E-Mail, um Sie über das Datum dieser Wartungsarbeiten zu informieren. Wenn Ihnen das Datum nicht zusagt, etwa wegen Produktionserfordernissen, können Sie diese Wartungsarbeiten in der OVHcloud Konsole oder über die OVHcloud API auf ein Datum Ihrer Wahl verschieben.

:::info
Wir versuchen, uns so weit wie möglich Ihrer Infrastrukturnutzung und Ihren Anforderungen anzupassen. Unter Umständen müssen wir jedoch Wartungsarbeiten vornehmen, bei denen es nicht möglich ist, Datum und/oder Uhrzeit zu ändern (beisielsweise Wartungsarbeiten an Infrastrukturen mit mehreren Kunden, dringende Eingriffe zur Vermeidung von Störungen, etc.).

Zur Information: Wenn ein Wartungsdatum von Ihnen selbst geändert werden kann, sind die vorgeschlagenen neuen Termine innerhalb kürzerer Zeitperioden.

:::

**Diese Anleitung erklärt, wie Sie das Datum für eine geplante Wartung an Ihrer VMware on OVHcloud über die OVHcloud Konsole oder die OVHcloud API verschieben.**

## Voraussetzungen

- Sie haben eine E-Mail mit der Benachrichtigung über die Wartungsarbeiten erhalten, in der ausdrücklich darauf hingewiesen wird, dass Sie **das Datum der Wartungsarbeiten** ändern können. Andernfalls können die Arbeiten nicht verschoben werden.
- Sie sind als administrativer oder technischer Kontakt für die [VMware on OVHcloud](https://www.ovhcloud.com/de/enterprise/products/hosted-private-cloud/) Infrastruktur eingetragen.
- Sie haben Zugriff auf die  <ApiLink>OVHcloud API </ApiLink>.

## In der praktischen Anwendung

:::tip
Benachrichtigungen von OVHcloud sind auch im Verlauf der Service-E-Mails verfügbar, die an Ihr OVHcloud Konto gesendet wurden.

:::

### In der OVHcloud Konsole

Gehen Sie mit einem Administrator-Account in der OVHcloud Konsole zu **Private Cloud** › **Managed VMware vSphere**, wählen Sie Ihren Dienst in der Liste aus und klicken Sie auf den Tab <code className="action">Vorgänge</code>. Überprüfen Sie in der Drop-down-Liste rechts über der Tabelle der Vorgänge, dass <code className="action">In Bearbeitung</code> (Standardwert) ausgewählt ist, um die noch nicht abgeschlossenen Vorgänge anzuzeigen.

Öffnen Sie anschließend das Menü ⋮ (Spalte **Aktionen**) des Wartungsvorgangs und klicken Sie auf <code className="action">Bearbeitungsdatum ändern</code>.

:::info
Wenn die Option <code className="action">Bearbeitungsdatum ändern</code> nicht verfügbar ist, kann diese Wartung nicht verschoben werden.

:::

Wählen Sie im Fenster **Bearbeitungsdatum ändern** ein Datum im Kalender **Bearbeitungsdatum** aus. Es können nur verfügbare Daten ausgewählt werden: Daten außerhalb des zulässigen Wartungszeitfensters sind nicht auswählbar.

Geben Sie dann im Feld **Uhrzeit** eine neue Uhrzeit für diese Wartung ein oder lassen Sie die ursprünglich geplante Uhrzeit unverändert.

Klicken Sie abschließend auf den Button <code className="action">Ändern</code>, um Ihre Änderungen zu bestätigen.

### Mit der OVHcloud API

Öffnen Sie die <ApiLink>OVHcloud API-Konsole</ApiLink>. Folgen Sie falls nötig unserer Anleitung "[Erste Schritte mit der OVHcloud API](/guides/manage-and-operate/api/first-steps)".

Führen Sie folgenden Aufruf aus:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/task/\{taskId\}/changeMaintenanceExecutionDate"} />

Geben Sie die Werte ein:

- **serviceName** Die ID Ihrer Hosted Private Cloud Infrastruktur in der Form `pcc-XX-XX-XX-XX`.
- **taskId**: Hierbei handelt es sich um die Referenz der Wartung, die Ihnen in der Benachrichtigung per E-Mail mitgeteilt wurde.
- **executionDate**: Geben Sie das neue Wartungsdatum ein, im Format `YYYY-MM-DDTHH:MM+01:SS` (Beispiel: 2023-01-02T08:00:00+01:00 für die Wartung zum Zeitpunkt 02/01/2023, 08.00 (UTC+1)).
