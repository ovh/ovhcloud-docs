## Ziel

IP-Blöcke können verwendet werden, um Ihre Dienste über das Internet zugänglich zu machen. 

**Diese Anleitung erklärt, wie Sie einen IP-Block für Ihre Hosted Private Cloud bestellen, hinzufügen und migrieren.**

## Voraussetzungen

- Sie sind Administrator-Kontakt für die Infrastruktur [Hosted Private Cloud](https://www.ovhcloud.com/de/enterprise/products/hosted-private-cloud/), um Login-Daten zu erhalten.
- Sie haben eine aktive Benutzerkennung (erstellt in der <ManagerLink console to="/">OVHcloud Konsole</ManagerLink>).

[[cpnav:network-public-ip-console]]

## In der praktischen Anwendung

### IP-Block bestellen

Um einen zusätzlichen IP-Block für Ihre **Hosted Private Cloud** zu bestellen, öffnen Sie Ihren Dienst in der OVHcloud Konsole (**Private Cloud** › **Managed VMware vSphere**, dann Ihr Dienst). Öffnen Sie im Tab **Dashboard** im Bereich **Optionen** das Menü ⋮ der Zeile **Anzahl der IP-Blöcke** und klicken Sie auf <code className="action">IP-Blöcke bestellen</code>. Dieselbe Bestellseite ist auch über **Netzwerk** › **IP-Adressen** erreichbar: Klicken Sie auf <code className="action">IP bestellen</code> und dann auf <code className="action">Additional IP bestellen</code>.

Füllen Sie auf der Seite **IP bestellen** die folgenden Abschnitte aus, um Ihren IP-Block zu erstellen:

- **IP-Adresstyp auswählen**: Wählen Sie **IPv4** aus.
- **Dienst auswählen, dem die Additional IP zugewiesen werden soll**: Wählen Sie Ihren **Hosted Private Cloud** Dienst aus. Die Region wird anschließend automatisch anhand des ausgewählten Dienstes bestimmt.
- **Angebot auswählen**: Wählen Sie die Größe des IP-Blocks aus (/28 bis /24).

:::info
Zur Erinnerung haben wir in der nachstehenden Tabelle die Anzahl der in einem Block enthaltenen IPs sowie die Anzahl der verwendbaren IPs aufgeführt.

:::


|Block-Größe|IPs im Block|Bei OVHcloud verwendbare IPs|
|:---:|:---:|:---:|
|28|16|11|
|27|32|27|
|26|64|59|
|25|128|123|
|24|256|251|

:::info
Welche IPs Ihres Blocks reserviert sind und wofür sie verwendet werden, können Sie in unserer Anleitung zum [OVHcloud Network Plugin](/guides/hosted-private-cloud/powered-by-vmware/plugin-ovh-network) nachlesen.

:::

- **Geolokalisierung auswählen**: Wählen Sie das Land des IP-Blocks aus. Das Land, in dem ein IP-Block gehostet wird, kann für das SEO-Ranking Ihrer Dienste von Bedeutung sein (zum Beispiel ist die Referenzierung einer deutschen Website in Deutschland besser, wenn auch ihre IP deutsch ist).

Netzwerkname und Netzwerkbeschreibung, die im Whois des IP-Blocks sichtbar sind, werden bei der Bestellung nicht abgefragt: Sie können den Netzwerknamen nach der Lieferung des Blocks über die Seite **IP-Adressen** ändern.

:::tip
Sie müssen die Aktivierungsgebühr für Ihren IP-Block vor der Lieferung bezahlen.

:::

Überprüfen Sie die **Zusammenfassung** und klicken Sie dann auf <code className="action">Bestellen</code>. Der Bestellschein für Ihren IP-Block wird in einem neuen Tab geöffnet. Wenn dieser Ihren Wünschen entspricht, begleichen Sie den Betrag einfach mit einem der angebotenen Zahlungsmittel, damit Ihr Block geliefert wird.

### IP-Block zwischen zwei Hosted Private Clouds migrieren

<iframe className="video" width="560" height="315" src="https://www.youtube-nocookie.com/embed/Gemao3Fd7rI" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen={true}></iframe>

Für die Migration eines IP-Blocks müssen die Blöcke manuell über die OVHcloud APIv6 verschoben werden.

Verwenden Sie hierzu folgenden Befehl:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/move"} />

Die Felder müssen wie folgt ausgefüllt werden:

- ip: IP-Block mit /mask
- nexthop „newPrimaryIp“ (case-sensitive)
- to: Ziel-Private-Cloud in der Form pcc-XXX-XXX-XXX-XXX

Das Ergebnis wird wie folgt angezeigt:

```json
{
  "function": "genericMoveFloatingIp",
  "status": "todo",
  "taskId": 178970672
}
```

Wenn Sie anschließend den IP-Block abtrennen müssen, können Sie diesen API-Aufruf verwenden, um die IP in den IP-Parkplatz zu verschieben:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/park"} />


:::warning
Dieser Aufruf trennt das Netzwerk auf den VMs, die die betreffenden IPs verwenden.

:::


Sie können den Block auch über die OVHcloud Konsole verschieben: Öffnen Sie im Tab **Dashboard** Ihres Dienstes im Bereich **Optionen** das Menü ⋮ der Zeile **Anzahl der IP-Blöcke** und klicken Sie auf <code className="action">IP-Blöcke mit einem anderen Service verknüpfen</code>.

Sie können die Migration Ihres IP-Blocks im Bereich **Managed VMware vSphere** nachverfolgen. Klicken Sie auf Ihren Hosted Private Cloud Dienst und dann auf den Tab <code className="action">Vorgänge</code>.

Die Referenz des Vorgangs lautet `removeIpRipeBlock`.

Die IP wird dann in der Liste **IP-Adressen** (**Netzwerk** › **IP-Adressen**) mit dem Typ **IP Parking** angezeigt.
