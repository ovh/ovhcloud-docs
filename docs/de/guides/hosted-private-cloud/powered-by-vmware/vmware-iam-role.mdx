## Ziel

**In dieser Anleitung erklären wir, wie Sie eine IAM-Rolle in Hosted Private Cloud - VMware on OVHcloud erstellen**.

## Voraussetzungen

- Sie verfügen über einen [OVHcloud Kunden-Account](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- Sie haben ein oder mehrere Hosted Private Cloud - VMware on OVHcloud Produkte, die mit diesem Kunden-Account verbunden sind (Hosted Private Cloud powered by VMware, VMware Service Pack).
- Sie haben IAM für Ihren Hosted Private Cloud - VMware on OVHcloud Dienst aktiviert. Folgen Sie dazu den Schritten der Anleitung [IAM für VMware on OVHcloud - IAM aktivieren](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-activation).

[[cpnav:privatecloud-vmware-vsphere-console]]

## In der praktischen Anwendung

Standardmäßig verfügen Sie über 2 vSphere IAM-Rollen. Das Erstellen einer zusätzlichen Rolle ist daher optional.

Im Folgenden erklären wir, wie Sie eine zusätzliche Rolle erstellen.

### IAM-Rolle über die OVHcloud Konsole erstellen

Wählen Sie Ihre Infrastruktur aus und öffnen Sie dann den Tab <code className="action">Benutzer</code>.

Klicken Sie auf <code className="action">IAM-Rolle erstellen</code>.

<img className="thumbnail" alt="Tab Benutzer eines Managed VMware vSphere Dienstes mit dem Button IAM-Rolle erstellen" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role/console/iam_role_8.png" loading="lazy" />

Geben Sie in dem sich öffnenden Fenster **Neue OVHcloud IAM-Rolle erstellen** den Namen Ihrer Rolle in das Feld **Rollenname** ein und klicken Sie dann auf <code className="action">Bestätigen</code>.

:::info
IAM-Rollen erhalten automatisch das Präfix `iam-`.

:::

<img className="thumbnail" alt="Fenster Neue OVHcloud IAM-Rolle erstellen, Präfix iam- im Feld Rollenname" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role/console/iam_role_9.png" loading="lazy" />

Sie können die Rechte der Gruppe anschließend wie bei einem lokalen vSphere-Benutzer bearbeiten: Klicken Sie in der Spalte **Aktionen** der Zeile Ihrer Rolle auf den Button <code className="action">⋮</code> und wählen Sie dann <code className="action">Rechte pro DC anzeigen/bearbeiten</code>.

#### IAM-Rolle über die OVHcloud API erstellen

:::tip
Lesen Sie die Anleitung [Erste Schritte mit der OVHcloud API](/guides/manage-and-operate/api/first-steps), um sich mit der Verwendung der OVHcloud APIv6 vertraut zu machen.

:::



Führen Sie folgenden API-Aufruf aus:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/addRole"} />


:::warning
Ersetzen Sie `serviceName` durch die Referenz Ihres Hosted Private Cloud Dienstes im Format `pcc-XXX-XXX-XXX-XXX`.

:::
