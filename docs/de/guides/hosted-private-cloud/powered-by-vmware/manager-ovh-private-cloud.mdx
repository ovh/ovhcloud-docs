## Ziel

Mit der OVHcloud Konsole können Sie Ihre Hosted Private Cloud Infrastruktur einfach verwalten.

**Diese Anleitung beschreibt die verschiedenen Konfigurationsmöglichkeiten.**

## Voraussetzungen

- Sie verfügen über ein [Hosted Private Cloud](https://www.ovhcloud.com/de/enterprise/products/hosted-private-cloud/) Produkt.

[[cpnav:privatecloud-vmware-vsphere-console]]

## In der praktischen Anwendung

### Hosted Private Cloud Ansicht

Gehen Sie mit einem Administrator-Account in der OVHcloud Konsole zu **Private Cloud** › **Managed VMware vSphere** und wählen Sie Ihren Dienst in der Liste aus, indem Sie auf seinen Namen klicken. Die Seite des Dienstes öffnet sich im Tab **Dashboard**; die weiteren Tabs sind **Rechenzentrum**, **Benutzer**, **Zugriffskontrolle**, **Verschlüsselung**, **Vorgänge** und **Logs**.

Der Seitentitel zeigt die Beschreibung Ihrer Infrastruktur an. Um sie zu ändern, klicken Sie auf das Stift-Symbol neben dem Titel, geben Sie die neue Beschreibung ein und bestätigen Sie mit dem Symbol ✓. Der Name des Dienstes selbst kann nicht geändert werden.

#### Dashboard

Der Tab **Dashboard** bietet Ihnen eine Übersicht über Ihren Dienst, aufgeteilt in vier Abschnitte.

Der Abschnitt **Allgemeine Informationen** zeigt:

- die **Beschreibung**, die über das Stift-Symbol daneben bearbeitet werden kann
- die **Softwarelösung**, die die installierte vCSA-Version anzeigt
- die **Private-Cloud-Zone** und die **Region**: den Standort Ihrer Hosted Private Cloud
- die **Anzahl der Rechenzentren** in Ihrer Infrastruktur
- Links zu Ihren Verwaltungsinterfaces: <code className="action">vScope öffnen</code> und <code className="action">Weboberfläche öffnen</code> (der vSphere Client)

Der Abschnitt **Optionen** zeigt Ihre aktivierten und deaktivierten Optionen (Zerto, vRealize Operations (vROps), NSX-T, Logs, Windows-Lizenz (SPLA)), jeweils mit einer Aktion in ihrer Zeile, um sie zu ändern (zum Beispiel <code className="action">Aktivieren</code>, <code className="action">Optionen bearbeiten</code> oder <code className="action">Deaktivieren</code>). Er zeigt außerdem die **Anzahl der IP-Blöcke**, über die Sie verfügen: Um weitere zu bestellen, öffnen Sie das Menü ⋮ daneben und klicken Sie auf <code className="action">IP-Blöcke bestellen</code>.

Der Abschnitt **Compliance** zeigt die branchenspezifische Compliance Ihres Dienstes. Klicken Sie auf <code className="action">Branchenspezifische Compliance aktivieren</code>, um eine Zertifizierung (HDS oder PCI DSS) zu aktivieren.

Im Abschnitt **Abonnement** können Sie sich für die OVHcloud Hosted Private Cloud Mailingliste anmelden (**Mailingliste**, <code className="action">In die Mailingliste eintragen</code>). Er zeigt das Erstellungsdatum und das Verlängerungsdatum (**Automatische Verlängerung**) Ihres Dienstes an und ermöglicht die Kündigung des Dienstes über den Link <code className="action">Service kündigen</code>.

Weitere Informationen zur Kündigung eines Hosted Private Cloud Dienstes finden Sie in unserer Anleitung [Hosted Private Cloud kündigen](/guides/account-and-service-management/managing-billing-payments-and-services/cancel-private-cloud).

Die Zugriffsrichtlinie Ihrer Infrastruktur (`Offen` oder `Eingeschränkt`) wird im Tab **Zugriffskontrolle** unter **vCenter-Zugriffsrichtlinie** angezeigt (siehe unten).

#### Datacenter

Der Tab **Rechenzentrum** zeigt Ihre aktuellen virtuellen Datacenter mit ihrer Reihe, ihren Ressourcen und ihrer Anzahl virtueller Maschinen an. Über den Button <code className="action">Ein Datacenter bestellen</code> können Sie bei Bedarf weitere hinzufügen. Über das Menü ⋮ (Spalte **Aktionen**) eines Datacenters können Sie außerdem einen Host oder einen Datastore dafür bestellen.

Klicken Sie auf den Namen eines Datacenters, um die vollständige Datacenter-Ansicht zu öffnen (siehe unten), die Ihnen weitere Details und Optionen bietet.

#### Benutzer

Der Tab **Benutzer** listet alle Accounts auf, die sich bei vSphere einloggen können, und ermöglicht über den Button <code className="action">Benutzer erstellen</code> die Erstellung neuer Accounts.

Wenn Sie das Menü ⋮ (Spalte **Aktionen**) eines Benutzers öffnen, stehen Ihnen mehrere Optionen zur Verfügung:

- <code className="action">Bearbeiten</code>: die in der Übersichtstabelle angezeigten Angaben und Berechtigungen des Benutzers bearbeiten
- <code className="action">Rechte pro DC anzeigen/bearbeiten</code>: die Rechte des Benutzers für jedes Datacenter anzeigen/ändern
- <code className="action">Passwort ändern</code>: das Passwort des Benutzers ändern
- <code className="action">Diesen Benutzer löschen</code>: den Benutzer löschen

Wenn Sie auf <code className="action">Rechte pro DC anzeigen/bearbeiten</code> klicken, gelangen Sie zur Seite der Rechteverwaltung, mit einer Zeile pro Datacenter.

Öffnen Sie das Menü ⋮ (Spalte **Aktionen**) eines Datacenters und klicken Sie auf <code className="action">Rechte bearbeiten</code>, um die Rechte im Fenster **Rechte bearbeiten** zu ändern.

- **vSphere-Zugriff**: Hierbei handelt es sich um die globalen Rechte des Benutzers für vSphere:

|Berechtigung|Beschreibung|
|---|---|
|Kein|kein Zugriff|
|Nur Lesen|nur lesender Zugriff|
|Lesen/Schreiben|lesender und schreibender Zugriff|
|Operator|den OVHcloud Administratoren vorbehaltener Zugriff|

- **Zugriff auf das VM Network**: Hierbei handelt es sich um die Rechteverwaltung für den öffentlichen Netzwerkbereich (im vSphere Interface als `VM Network` bezeichnet):

|Berechtigung|Beschreibung|
|---|---|
|Kein|kein Zugriff|
|Nur Lesen|nur lesender Zugriff|
|Operator|erlaubt die Konfiguration virtueller Maschinen (VMs) im öffentlichen Netzwerk|

- **Zugriff auf V(x)Lans / GENEVE**: Hierbei handelt es sich um die Rechteverwaltung für den privaten Netzwerkbereich (VXLAN für die Dedicated Cloud Reihe, VLAN für die SDDC Reihe und die Hosted Private Cloud Premier Packs):

|Berechtigung|Beschreibung|
|---|---|
|Kein|kein Zugriff|
|Nur Lesen|nur lesender Zugriff|
|Operator|erlaubt die Konfiguration virtueller Maschinen (VMs) im privaten Netzwerk|
|Administrator|erlaubt die Verwaltung von Port-Gruppen des virtuellen Switch (erstellen, bearbeiten, löschen, ...), nur für SDDC und die Hosted Private Cloud Premier Packs|

- **Verwaltung der Hosts und Speicher**: Diese Berechtigung erlaubt es, Hosts und Speicher über das OVHcloud Plugin im vSphere Client hinzuzufügen oder zu löschen.

#### Zugriffskontrolle und Verschlüsselung

Die vCenter-Zugriffsrichtlinie und die weiteren Sicherheitseinstellungen sind auf zwei Tabs verteilt: **Zugriffskontrolle** und **Verschlüsselung**.

Der Tab **Zugriffskontrolle** zeigt in seinem Abschnitt **Sitzungseinstellungen** die **vCenter-Zugriffsrichtlinie** Ihrer Infrastruktur an (`Offen` oder `Eingeschränkt`). Die Richtlinie wird nur zur Information angezeigt: Um sie zu ändern, kontaktieren Sie den OVHcloud Support. Die weiteren Sitzungseinstellungen (**Zeitlimit der Sitzung**, **Anzahl gleichzeitiger Verbindungen** und **Abmelderichtlinie**) können Sie über den Button <code className="action">Bearbeiten</code> in der jeweiligen Zeile konfigurieren. Darunter können Sie in der Liste der IPs und Blöcke, die sich verbinden dürfen, über den Button <code className="action">IP-Block zuordnen</code> einen Eintrag hinzufügen.

:::warning
Wenn die Zugriffsrichtlinie auf "Eingeschränkt" gesetzt und keine IP-Adresse autorisiert ist, kann sich kein Benutzer im vSphere Client einloggen. Die virtuellen Maschinen bleiben jedoch weiterhin verfügbar.

:::

Im Tab **Verschlüsselung** können Sie außerdem Ihre Key Management Server hinzufügen (<code className="action">KMS-Server zuordnen</code>) oder einsehen.

Weitere Informationen finden Sie in [dieser Anleitung](/guides/hosted-private-cloud/powered-by-vmware/vm-encrypt) (Englisch).

#### Operationen

Der Tab **Vorgänge** führt ein Protokoll aller auf Ihrer Infrastruktur ausgeführten Aufgaben.

Standardmäßig zeigt die Liste die laufenden Aufgaben an: Sie können sie nach Status filtern (alle Status, in Bearbeitung, abgeschlossen oder abgebrochen) und über den Button <code className="action">Spalten</code> weitere Spalten anzeigen. Wenn das Bearbeitungsdatum einer Aufgabe geändert werden kann, bietet ihr Menü ⋮ (Spalte **Aktionen**) die Option <code className="action">Bearbeitungsdatum ändern</code>.

:::info
Wenn Sie nicht auf den vSphere Client zugreifen können, wird vielleicht gerade eine Wartungsarbeit durchgeführt. Überprüfen Sie zuerst diesen Tab, bevor Sie weitere Maßnahmen ergreifen.

:::

#### Windows-Lizenz

Der Status Ihrer Windows-SPLA-Lizenz wird in der Zeile **Windows-Lizenz (SPLA)** des Abschnitts **Optionen** im Tab **Dashboard** angezeigt. Wenn die Option deaktiviert ist, können Sie sie über den Button <code className="action">SPLA aktivieren</code> bestellen. Die Lizenzen werden anschließend pro virtueller Maschine aktiviert, im Tab **Virtuelle Maschinen** eines Datacenters (Menü ⋮ der VM, <code className="action">Lizenz aktivieren</code>). Der Tab **Rechenzentrum** zeigt für jedes Datacenter die Anzahl der Windows-VMs und der lizenzierten Windows-VMs an.

Die Preisübersicht hierzu finden Sie [hier](https://www.ovhcloud.com/de/enterprise/products/hosted-private-cloud/images-licenses/).

### Datacenter-Ansicht

Eine Hosted Private Cloud kann mehrere virtuelle Datacenter enthalten.

Diese werden im Tab **Rechenzentrum** Ihres Dienstes aufgelistet. Klicken Sie auf den Namen eines Datacenters, um dessen Verwaltungsseite zu öffnen.

Der Name des Datacenters kann angepasst werden, indem Sie oben auf der Seite auf das Stift-Symbol daneben klicken. Seine Beschreibung können Sie im Abschnitt **Allgemeine Informationen** seines Tabs **Dashboard** bearbeiten (siehe unten).

#### Datacenter-Dashboard

Der Tab **Dashboard** des Datacenters bietet Ihnen eine Übersicht darüber. Sein Abschnitt **Allgemeine Informationen** zeigt:

- den **Namen** und die **Beschreibung**, jeweils über das Stift-Symbol daneben bearbeitbar
- die **Kommerzielle Reihe**, die die abonnierten VMware-Dienste anzeigt
- die Felder **Hosts** und **Datastores**, die Ihnen die jeweilige Anzahl im Datacenter angeben, mit den Buttons <code className="action">Host bestellen</code> und <code className="action">Datastore bestellen</code>
- Links zu Ihren Verwaltungsinterfaces: <code className="action">Zu vScope gehen</code> und <code className="action">Weboberfläche</code>

Der Abschnitt **Merkmale** beschreibt die Ressourcen des Datacenters (CPU, RAM, Speicherplatz) und seine Anzahl virtueller Maschinen.

Der Backup-Status Ihrer virtuellen Maschinen wird in der Spalte **Backup** des Tabs **Virtuelle Maschinen** angezeigt, der Status Ihrer Disaster-Recovery-Lösung in der Zeile **Zerto** des Abschnitts **Optionen**.

#### Hosts

Der Tab **Hosts** bietet eine Übersicht über die Hosts im ausgewählten Datacenter.

*Wenn ein Host stündlich abgerechnet wird, können Sie ihn auf monatliche Abrechnung umstellen: Öffnen Sie sein Menü ⋮ (Spalte **Aktionen**) und klicken Sie auf <code className="action">Auf monatliche Abrechnung umstellen</code>.*

Über den Button <code className="action">Host bestellen</code> können Sie außerdem einen Host bestellen.

#### Datastores

Der Tab **Datastores** bietet eine Übersicht über die Datastores im ausgewählten Datacenter; die Spalte **Geltungsbereich** zeigt an, ob es sich jeweils um einen globalen Datastore handelt.

*Ein Datastore kann über sein Menü ⋮ (Spalte **Aktionen**) › <code className="action">Datastore in globalen Datastore umwandeln</code> in einen globalen Datastore umgewandelt werden. Dasselbe Menü bietet die Option <code className="action">Auf monatliche Abrechnung umstellen</code>.*

Über den Button <code className="action">Datastore bestellen</code> können Sie außerdem einen Datastore bestellen.

#### Backup

Der Tab **Backup** bietet Zugriff auf die Backup-Lösung des Datacenters. Bei aktuellen Diensten stellt er Managed Backup for VMware vor, eine auf Veeam basierende und von OVHcloud betriebene Backup-Lösung, mit Links zum Schutz Ihrer Infrastruktur und zu den zugehörigen Tutorials (einschließlich der Migration von Veeam Managed Backup zu Managed Backup for VMware).

Bei einem Dienst, der noch Veeam Managed Backup verwendet, können Sie in diesem Tab stattdessen diese Lösung aktivieren und verwalten. Weitere Informationen finden Sie in [dieser Anleitung](/guides/hosted-private-cloud/powered-by-vmware/veeam-backup-as-a-service) (Englisch).

#### Disaster Recovery Plan (DRP)

Im Tab **DRP** können Sie mit Zerto einen DRP einrichten: Wählen Sie die Art des Plans, **Zwischen zwei OVH Private Clouds** oder **Zwischen Ihrer Infrastruktur und einer OVH Private Cloud**, und klicken Sie dann auf <code className="action">Zerto DRP aktivieren</code>.

Weitere Informationen finden Sie in [dieser Anleitung](/guides/hosted-private-cloud/powered-by-vmware/zerto-virtual-replication-vmware-vsphere-drp) (Englisch).

:::warning
Sie benötigen eine zweite Hosted Private Cloud Lösung, um die Zerto Option **Zwischen zwei OVH Private Clouds** zu aktivieren.

:::
