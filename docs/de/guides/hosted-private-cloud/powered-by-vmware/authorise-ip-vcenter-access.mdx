## Ziel

Der Zugang zu Ihrem vCenter ist auf autorisierte IP-Adressen beschränkt.

**Erfahren Sie, wie Sie IP-Adressen für die Verbindung mit vCenter zulassen können.**

## Voraussetzungen

- Sie verfügen über eine [Hosted Private Cloud](https://www.ovhcloud.com/de/enterprise/products/hosted-private-cloud/) Infrastruktur.
- Sie haben Zugriff auf Ihr <ManagerLink to="/">OVHcloud Kundencenter</ManagerLink>.

## In der praktischen Anwendung

Der Zugang zu vCenter ist nur eingeschränkt möglich. Fügen Sie daher die IP-Adressen hinzu, die zur Verbindung mit dem Dienst berechtigt sind.

Dies erfolgt im <ManagerLink to="/">OVHcloud Kundencenter</ManagerLink>. Klicken Sie im Bereich `Hosted Private Cloud` auf die Rubrik <code className="action">VMware</code>. Wählen Sie die Infrastruktur aus. Klicken Sie dann auf den Tab <code className="action">Sicherheit</code> und danach auf <code className="action">Neuen IP-Bereich hinzufügen</code>.

<img className="thumbnail" alt="vCenter" src="/images/hosted-private-cloud/powered-by-vmware/authorise-ip-vcenter-access/restrictIP.JPG" loading="lazy" />

Fügen Sie hier die IP-Adresse hinzu. Sie können auch eine Beschreibung anfügen, um sie später einfacher in der Liste wiederzufinden.

Nun müssen Sie nur noch bestätigen: Klicken Sie auf <code className="action">Weiter</code>, und sobald die IP-Adresse als **„Autorisiert und eingerichtet“** gekennzeichnet ist, ist die Verbindung mit vSphere über diese IP möglich.

<img className="thumbnail" alt="vCenter" src="/images/hosted-private-cloud/powered-by-vmware/authorise-ip-vcenter-access/restrictIP2.JPG" loading="lazy" />

:::info
Beachten Sie, dass Sie aus Sicherheitsgründen maximal 2048 IP-Adressen zur Verbindung mit vCenter erlauben können.

:::
