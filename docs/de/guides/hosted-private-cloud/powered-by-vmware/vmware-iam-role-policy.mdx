## Ziel

**Diese Anleitung erläutert, wie Sie eine globale IAM-Richtlinie erstellen oder bearbeiten und ihr eine vSphere-Rolle hinzufügen**.

## Voraussetzungen

- Sie verfügen über einen [OVHcloud Kunden-Account](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- Sie haben ein oder mehrere Hosted Private Cloud Produkte - VMware on OVHcloud, die mit diesem Account verbunden sind (Hosted Private Cloud powered by VMware, VMware Service Pack).
- Sie haben IAM für Ihren Hosted Private Cloud Dienst - VMware on OVHcloud aktiviert. Folgen Sie hierzu den Schritten der Anleitung [IAM für VMware on OVHcloud - IAM aktivieren](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-activation).

## In der praktischen Anwendung

### Richtlinie erstellen oder bearbeiten

<img className="thumbnail" alt="Seite Meine Richtlinien der OVHcloud Konsole mit dem Button Richtlinie erstellen" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role-policy/console/iam_role_policy_9.png" loading="lazy" />

Klicken Sie auf <code className="action">Richtlinie erstellen</code>.

Um eine Richtlinie zu bearbeiten, klicken Sie in der Spalte **Aktionen** rechts neben der betreffenden Richtlinie auf den Button <code className="action">⋮</code> und dann auf <code className="action">Richtlinie bearbeiten</code>.

<img className="thumbnail" alt="Abschnitt Produkttypen mit ausgewähltem VMware on OVHcloud und einem vSphere-Dienst" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role-policy/console/iam_role_policy_10.png" loading="lazy" />

Das Formular der Richtlinie besteht aus fünf Abschnitten: **Informationen zur Richtlinie**, **Identitäten**, **Produkttypen**, **Bedingungen** und **Aktionen** sowie dem Abschnitt **Übersicht** auf der rechten Seite. Geben Sie die angeforderten Einstellungen ein:

- **Name** im Abschnitt **Informationen zur Richtlinie**: Wählen Sie einen Namen. Er darf nur Buchstaben, Ziffern und die Zeichen `-`, `/`, `_` und `+` enthalten.
- **Beschreibung** im selben Abschnitt: Geben Sie eine Beschreibung für Ihre Richtlinie ein.
- **Identitäten** (erforderlich): Wählen Sie die von Ihrer Richtlinie betroffenen Identitäten in den Tabs **Benutzer**, **Gruppen**, **Servicekonten** und **Andere OVHcloud Kunden** aus.
- **Produkttypen**: Wählen Sie <code className="action">VMware on OVHcloud</code> / <code className="action">VMware-Servicepaket</code> aus.
- **Ressourcen** im Abschnitt **Produkttypen**: Fügen Sie die von Ihrer Richtlinie betroffenen Ressourcen hinzu (**pcc-XX-XX-XX-XX/servicepack**, **pcc-XX-XX-XX-XX.ovh.com (pccVMware)** usw.).
- **Aktionen**: Hier fügen Sie Ihre Rolle hinzu (siehe unten).

#### IAM-Rolle zu einer globalen Richtlinie hinzufügen

Bei der Aktivierung von IAM in vSphere werden standardmäßig zwei Rollen hinzugefügt (`iam-admin`, `iam-auditor`).

Kopieren Sie die Rollen aus dem untenstehenden Codeabschnitt, fügen Sie sie in das Feld **Aktionen manuell hinzufügen** im Abschnitt **Aktionen** ein und klicken Sie dann auf den Button <code className="action">Hinzufügen</code>.

```bash
pccVMware:vSphere:assumeRole?iam-admin
pccVMware:vSphere:assumeRole?iam-auditor
```

Wenn Sie eine zusätzliche IAM-Rolle erstellt haben (nachdem Sie die Schritte der Anleitung "[IAM für VMware on OVHcloud - IAM-vSphere-Rolle erstellen](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-role)" befolgt haben), können Sie diese ebenfalls hinzufügen, indem Sie den untenstehenden Code kopieren und an Ihre Rolle anpassen:

```bash
pccVMware:vSphere:assumeRole?{role_name}
```

<img className="thumbnail" alt="Abschnitt Aktionen mit einer im Feld Aktionen manuell hinzufügen eingegebenen assumeRole-Aktion" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role-policy/console/iam_role_policy_11.png" loading="lazy" />

Achten Sie darauf, auf den Button <code className="action">Hinzufügen</code> zu klicken, um die Aktion hinzuzufügen.

Klicken Sie abschließend unten im Formular auf <code className="action">Erstellen</code> oder im Abschnitt **Übersicht** auf der rechten Seite auf <code className="action">Richtlinie erstellen</code>. Wenn Sie eine Richtlinie bearbeiten, klicken Sie auf <code className="action">Speichern</code> oder im Abschnitt **Übersicht** auf <code className="action">Richtlinie bearbeiten</code>.
