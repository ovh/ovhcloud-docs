## Objectif

Le RACI ci-dessous détaille le partage des responsabilités entre OVHcloud et le client pour le service Cloud HSM.

Cloud HSM est un service managé de conservation de clés. Vos clés sont stockées dans des partitions qui vous sont dédiées, sur du matériel HSM partagé entre plusieurs clients. Chaque cluster Cloud HSM est composé d'exactement trois partitions, situées sur trois HSM physiques différents selon une répartition prédéfinie par OVHcloud pour la région que vous choisissez. Vous accédez au service via des endpoints publics, avec une authentification TLS mutuelle (mTLS) et une autorisation OVHcloud IAM, à l'aide du driver PKCS#11 OVHcloud.

OVHcloud exploite le matériel HSM, assure la maintenance du service et réplique vos clés entre les partitions de votre cluster. Vous gérez vos clés, les droits d'accès à vos clusters et l'intégration de vos applications, y compris le basculement vers un autre endpoint si l'un d'eux devient indisponible.

:::info
Les clés créées dans Cloud HSM ne quittent jamais le HSM en clair. L'encapsulation (wrap) et l'export de clés ne sont pas disponibles  vous ne pouvez pas sauvegarder, exporter ni récupérer vos clés en dehors du service. Vous pouvez en revanche importer des clés existantes par import de clés encapsulées (wrapped key import).
:::
