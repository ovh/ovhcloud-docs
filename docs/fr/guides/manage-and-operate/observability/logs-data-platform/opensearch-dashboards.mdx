## En pratique

### Créer l'alias de votre flux

Pour accéder à vos logs depuis OpenSearch Dashboards, vous devrez configurer un alias OpenSearch et le lier à vos flux Graylog. Voici comment procéder :

1. Dans l'onglet <code className="action">Alias</code>, cliquez sur le bouton <code className="action">Ajouter un alias</code>
2. Choisissez un nom et définissez une description pour votre alias
3. Enregistrez la saisie en cliquant sur le bouton <code className="action">Sauvegarder</code>
4. Une fois l'alias créé, utilisez le menu **...** situé à droite et sélectionnez l'option <code className="action">Attacher du contenu à l'alias</code>.
5. Définissez à cet endroit les flux Graylog que vous souhaitez associer à votre alias
6. C'est terminé.

<img className="thumbnail" alt="Création d'un alias" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/alias.png" loading="lazy" />

Logs Data Platform sait désormais quel flux vous souhaitez consulter. Configurons maintenant OpenSearch Dashboards et voyons si cela fonctionne !

### Accéder à votre instance OpenSearch Dashboards

Pour créer votre instance OpenSearch Dashboards, cliquez sur l'onglet OpenSearch Dashboards, cliquez sur <code className="action">Add a instance</code>, indiquez une description et cliquez sur **Order** pour lancer la création de votre instance. Votre instance sera créée et livrée en 20 minutes environ.

<img className="thumbnail" alt="création de l'instance osd" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/osd_created.png" loading="lazy" />

Utilisez le menu **...** situé à droite et sélectionnez l'option <code className="action">Access to your OpenSearch Dashboards instance</code> pour être redirigé.

<img className="thumbnail" alt="accès à osd" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/url.png" loading="lazy" />

Une fois sur place, utilisez le fournisseur d'identité approprié pour vous connecter et effectuez la configuration sur la première page. Cliquez sur le bouton <code className="action">Add data</code> pour ajouter des données d'exemple avec lesquelles vous pourrez expérimenter. En revanche, si vous souhaitez utiliser vos propres données, vous devez configurer les **Index Patterns** dans la page stack management. Cette page est accessible en cliquant sur le bouton <code className="action">Manage</code> situé à côté du bouton « Add data ». Vous pouvez également utiliser l'option « Stack Management » dans le menu latéral gauche, que vous pouvez afficher à l'aide du bouton sandwich en haut à gauche.

Dans cette page de configuration, vous pouvez indiquer comme nom d'index le nom complet de votre alias **ldp-XXXXX-a-XXXXX**, mais vous pouvez également utiliser des caractères génériques. Choisissez **timestamp** comme nom du champ temporel, puis cliquez sur l'onglet Discover pour lire vos entrées de logs.

<img className="thumbnail" alt="configuration d'osd" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/osd_setup.png" loading="lazy" />

Vous pouvez également explorer n'importe quel [index OpenSearch](/guides/manage-and-operate/observability/logs-data-platform/index-as-a-service) que vous avez créé sur la plateforme. Une seule instance OpenSearch Dashboards vous permet d'explorer toutes les données que vous avez transmises à Logs Data Platform.

Pour savoir ce que vous pouvez faire avec OpenSearch Dashboards, consultez la [documentation OpenSearch Dashboards](https://opensearch.org/docs/latest/dashboards/index/)
