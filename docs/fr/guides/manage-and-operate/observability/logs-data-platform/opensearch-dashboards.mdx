## Objectif

Ce guide vous aidera à exploiter toute la puissance d'[OpenSearch Dashboards](https://opensearch.org/docs/latest/dashboards/index/) et à créer des tableaux de bord à partir de vos logs.

## Prérequis

Voici ce que vous devez savoir pour démarrer :

- Vous envoyez déjà des logs sur un flux dont vous êtes propriétaire : [consultez le tutoriel de démarrage rapide](/guides/manage-and-operate/observability/logs-data-platform/getting-started-quick-start)
- Rien d'autre

Après un peu de pratique, vous serez en mesure de réaliser ce type de tableau de bord :

## En pratique

### Créer l'alias de votre flux

Pour accéder à vos logs depuis OpenSearch Dashboards, vous devrez configurer un alias OpenSearch et le lier à vos flux Graylog. Voici comment procéder :

1. Dans la console OVHcloud, ouvrez la section **Observabilité**, rendez-vous sur la page **Gestion des logs**, choisissez votre service Logs Data Platform dans la liste **Service**, puis cliquez sur l'onglet <code className="action">Alias OpenSearch</code> et sur le bouton <code className="action">Ajouter un alias</code>
2. Saisissez un suffixe pour votre alias (la plateforme y ajoute un préfixe) et définissez une description
3. Enregistrez la saisie en cliquant sur le bouton <code className="action">Ajouter</code>
4. Une fois l'alias créé, utilisez le bouton `⋮` à droite de l'alias et sélectionnez l'option <code className="action">Associer du contenu</code>.
5. Dans l'onglet **flux de données**, cliquez sur chaque flux Graylog que vous souhaitez associer à votre alias, puis cliquez sur <code className="action">Confirmer</code>. Un alias regroupe soit des flux de données, soit des index OpenSearch, jamais les deux.
6. C'est terminé.

<img className="thumbnail" alt="Attach content window with the data streams and OpenSearch indexes tabs and the Available and Attached lists" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/console/os-attach-content.png" loading="lazy" />

Logs Data Platform sait désormais quel flux vous souhaitez consulter. Configurons maintenant OpenSearch Dashboards et voyons si cela fonctionne !

### Accéder à votre instance OpenSearch Dashboards

Pour créer votre instance OpenSearch Dashboards, ouvrez la page **Tableaux de bord** de la section **Observabilité**, cliquez sur l'onglet <code className="action">Instances OpenSearch Dashboards</code>, puis sur <code className="action">Ajouter un OpenSearch Dashboard</code>. Indiquez une description et cliquez sur <code className="action">Commander</code> pour lancer la création de votre instance. Le panneau affiche le prix mensuel d'une instance. Votre instance sera créée et livrée en 20 minutes environ.

<img className="thumbnail" alt="Add an OpenSearch Dashboard panel with the Description field, the monthly price and the Order button" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/console/osd-add-instance.png" loading="lazy" />

Utilisez le bouton `⋮` situé à droite de votre instance et sélectionnez l'option <code className="action">Accéder à votre instance OpenSearch Dashboards</code> pour être redirigé.

<img className="thumbnail" alt="OpenSearch Dashboards instances tab with the actions menu of an instance" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/console/osd-instances-menu.png" loading="lazy" />

Une fois sur place, utilisez le fournisseur d'identité approprié pour vous connecter et effectuez la configuration sur la première page. Cliquez sur le bouton <code className="action">Add data</code> pour ajouter des données d'exemple avec lesquelles vous pourrez expérimenter. En revanche, si vous souhaitez utiliser vos propres données, vous devez configurer les **Index Patterns** dans la page stack management. Cette page est accessible en cliquant sur le bouton <code className="action">Manage</code> situé à côté du bouton « Add data ». Vous pouvez également utiliser l'option « Stack Management » dans le menu latéral gauche, que vous pouvez afficher à l'aide du bouton sandwich en haut à gauche.

Dans cette page de configuration, vous pouvez indiquer comme nom d'index le nom complet de votre alias **ldp-XXXXX-a-XXXXX**, mais vous pouvez également utiliser des caractères génériques. Choisissez **timestamp** comme nom du champ temporel, puis cliquez sur l'onglet Discover pour lire vos entrées de logs.

<img className="thumbnail" alt="configuration d'osd" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/osd_setup.png" loading="lazy" />

Vous pouvez également explorer n'importe quel [index OpenSearch](/guides/manage-and-operate/observability/logs-data-platform/index-as-a-service) que vous avez créé sur la plateforme. Une seule instance OpenSearch Dashboards vous permet d'explorer toutes les données que vous avez transmises à Logs Data Platform.

Pour savoir ce que vous pouvez faire avec OpenSearch Dashboards, consultez la [documentation OpenSearch Dashboards](https://opensearch.org/docs/latest/dashboards/index/)
