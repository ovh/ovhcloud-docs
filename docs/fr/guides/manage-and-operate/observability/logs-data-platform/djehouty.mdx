## Objectif

Ce guide vous montre comment envoyer vos logs vers Logs Data Platform en utilisant Python 2.x.

[Djehouty](https://github.com/ovh/djehouty) est conçu comme un ensemble de formatters et de handlers de journalisation permettant d'envoyer facilement des entrées de log vers Logs Data Platform.

Ce package inclut :

- pour [GELF](https://go2docs.graylog.org/4-x/getting_in_log_data/gelf.html?tocpath=Getting%20in%20Log%20Data%7CLog%20Sources%7CGELF%7C_____0#GELFPayloadSpecification) :
    - un handler TCP/TLS pour envoyer des entrées de log via TCP avec prise en charge de TLS.
    - un formatter pour convertir un enregistrement de log au format GELF(1.1).
- pour [LTSV](http://ltsv.org/) :
    - un handler TCP/TLS pour envoyer des entrées de log via TCP avec prise en charge de TLS.
    - un formatter pour convertir un enregistrement de log au format LTSV.

## Prérequis

Pour suivre ce guide, vous aurez besoin de :

- Python 2 ; nous recommandons d'installer [pip](https://pip.pypa.io/en/stable/installing/).
- [Avoir activé votre compte Logs Data Platform.](https://www.ovh.com/fr/order/express/#/new/express/resume?products=~%28~%28planCode~%27logs-account~productId~%27logs%29)
- [Créer au moins un flux et récupérer son jeton.](/guides/manage-and-operate/observability/logs-data-platform/getting-started-quick-start)

### Comment envoyer des logs

Les exemples suivants supposent que vous disposez déjà d'un flux fonctionnel. Vous devrez par ailleurs modifier l'adresse et les ports de l'endpoint pour ceux qui vous ont été attribués. Pour récupérer l'adresse et les ports de votre endpoint, rendez-vous sur la page **About** du Manager. Pour envoyer des messages de log, utilisez simplement le handler du format souhaité avec les paramètres suivants (« * » signifie obligatoire) :

|Paramètre|Gelf|LTSV|
|---|---|---|
|host *|votre endpoint attribué. Ex : `gra1.logs.ovh.com`||
|port *|Reportez-vous à la liste des ports PaaS Logs||
|level|logging.DEBUG ou supérieur||
|use_tls|True ou False (selon le port choisi)||
|static_fields *|`{"X-OVH-TOKEN": "XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX"}`||
|null_character|True|Non pris en charge|

La liste complète des paramètres pris en charge par Djehouty est disponible sur [GitHub](https://github.com/ovh/djehouty).

#### Exemple : cas d'usage avec GELF sur TCP/TLS

```python
import logging
from djehouty.libgelf.handlers import GELFTCPSocketHandler

gelf_logger = logging.getLogger('djehouty-gelf')
gelf_logger.setLevel(logging.DEBUG)
gelf_logger.addHandler(GELFTCPSocketHandler(
    host            = "gra1.logs.ovh.com",
    port            = 12202,
    static_fields   = {"X-OVH-TOKEN": "XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX"},
    use_tls         = True,
    level           = logging.DEBUG,
    null_character  = True,
))

gelf_logger.info('test')
```

#### Exemple : cas d'usage avec LTSV sur TCP/TLS

```python
import logging
from djehouty.libltsv.handlers import LTSVTCPSocketHandler

ltsv_logger = logging.getLogger('djehouty-ltsv')
ltsv_logger.setLevel(logging.DEBUG)
ltsv_logger.addHandler(LTSVTCPSocketHandler(
    host            = "gra1.logs.ovh.com",
    port            = 12201,
    static_fields   = {"X-OVH-TOKEN": "XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX"},
    use_tls         = True,
    level           = logging.DEBUG
))

ltsv_logger.info('test')
```

### Envoyer des métadonnées supplémentaires

Si vous avez plusieurs handlers, vous pouvez utiliser la classe [logging.LoggerAdapter](https://docs.python.org/2/library/logging.html#loggeradapter-objects) pour ajouter des données supplémentaires.

L'exemple suivant utilise le logger LTSV défini ci-dessus :

```python
mylogger = logging.LoggerAdapter(
    ltsv_logger,
    extra = {"myvar": 5}
)
mylogger.info('test')
```

Vous pouvez ajouter des métadonnées de log spécifiques à chaque entrée à l'aide du paramètre extra ; l'exemple suivant utilise le logger LTSV défini ci-dessus :

```python
ltsv_logger.info("Hello '%s'", 'John', extra={"lang": 'en'})
ltsv_logger.info("Bonjour '%s'", 'John', extra={"lang": 'fr'})
```
