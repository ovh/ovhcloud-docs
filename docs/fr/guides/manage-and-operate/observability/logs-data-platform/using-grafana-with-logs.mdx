## Objectif

[Grafana](http://grafana.org/) offre un moyen puissant et élégant de créer, d'explorer et de partager des tableaux de bord et des données avec votre équipe et avec le monde entier. Depuis la version 7, Grafana est capable de communiquer avec OpenSearch, ce qui vous permet de mélanger les données de Logs Data Platform avec d'autres sources de données comme l'IoT au même endroit. Ce guide vous montre comment procéder.

## Prérequis

Voici ce que vous devez savoir pour commencer :

- vous envoyez déjà des logs sur un flux qui vous appartient [voir le tutoriel de démarrage rapide](/guides/manage-and-operate/observability/logs-data-platform/getting-started-quick-start)
- vous avez accès au port 9200 de votre cluster (rendez-vous sur la page **Home** du manager pour connaître l'adresse de votre cluster)

Après un peu d'entraînement, vous serez en mesure de créer ce type de tableau de bord :

## En pratique

### Sélectionner votre alias de flux

Pour accéder à vos logs depuis Grafana, vous devez configurer un alias OpenSearch et le lier à vos flux Graylog, alors c'est reparti :

1. Dans l'onglet <code className="action">Alias</code>, cliquez sur le bouton <code className="action">Ajouter un alias</code>
2. Choisissez un nom et définissez une description pour votre alias
3. Enregistrez l'entrée en cliquant sur le bouton <code className="action">Sauvegarder</code>
4. Une fois l'alias créé, utilisez le menu **...** à droite et sélectionnez l'option <code className="action">Attacher du contenu à l'alias</code>.
5. Définissez-y les flux Graylog que vous souhaitez associer à votre alias
6. C'est terminé.

<img className="thumbnail" alt="Création d'un alias" src="/images/manage-and-operate/observability/logs-data-platform/visualization-grafana/alias.png" loading="lazy" />

Logs Data Platform sait désormais quel flux vous souhaitez explorer. Configurons maintenant Grafana et vérifions le fonctionnement de l'ensemble.

### Configurer votre propre grafana

Récupérez la dernière version de Grafana ici : [http://grafana.org/download/](http://grafana.org/download/) (v9.0.0 au moment de la rédaction).
Suivez ensuite le guide d'installation de Grafana selon votre plateforme : [http://docs.grafana.org/installation/](http://docs.grafana.org/installation/)

### Lancez-le !

Si tout est correctement configuré, lancez votre navigateur préféré et rendez-vous sur `http://localhost:3000`. Une fois connecté avec vos identifiants grafana, accédez au panneau des sources de données pour configurer votre source de données Logs Data Platform :

<img className="thumbnail" alt="Data source_1" src="/images/manage-and-operate/observability/logs-data-platform/visualization-grafana/datasource_1.png" loading="lazy" />

:::warning
Pour que la configuration fonctionne, veillez à :

- Définir `https://<your_cluster>.logs.ovh.com:9200` comme valeur d'**URL**
- Définir vos [identifiants Logs Data Platform](/guides/manage-and-operate/observability/logs-data-platform/tokens) pour les valeurs de **Basic auth**
- Définir le **nom d'index** comme l'alias Logs Data Platform lié à Grafana
- Remplacer le nom du **champ Time** par défaut par timestamp
- Définir la **Version** en cliquant sur <code className="action">Obtenir la version et sauvegarder</code>.
- Enregistrer votre source de données et la tester.

:::


Si votre configuration est correcte, il devrait afficher : « _Index Ok. Timefield Ok._ »

<img className="thumbnail" alt="Data source 2" src="/images/manage-and-operate/observability/logs-data-platform/visualization-grafana/datasource_2.png" loading="lazy" />

Pour aller plus loin, vous pouvez créer un nouveau tableau de bord et ajouter différents styles de visualisations.
Si vous souhaitez savoir ce que vous pouvez faire avec Grafana et OpenSearch, consultez la [documentation officielle](https://grafana.com/grafana/plugins/grafana-opensearch-datasource/).
