## Objectif

Ce guide vous montre comment créer un nouvel utilisateur Cloud Disk Array, en utilisant la console OVHcloud ou l'API OVHcloud.

## Prérequis

- Une solution [Cloud Disk Array](https://www.ovhcloud.com/fr/storage-solutions/cloud-disk-array/)

[[cpnav:storage-cloud-disk-array]]

## En pratique

### Depuis la console OVHcloud

:::info
L'utilisation de la console OVHcloud est le moyen le plus simple de créer un utilisateur.

:::


Sur la page de votre service Cloud Disk Array, ouvrez l'onglet <code className="action">Utilisateurs</code> et cliquez sur <code className="action">Ajouter un utilisateur</code>.

Dans le panneau **Ajouter un utilisateur**, saisissez un **Nom de l'utilisateur** (lettres, chiffres et underscore uniquement).

:::warning
Votre nom d'utilisateur doit contenir au moins trois caractères.
:::

Cliquez sur <code className="action">Ajouter l'utilisateur</code>. Une clé d'accès est générée automatiquement. Vous pourrez configurer les permissions de l'utilisateur une fois celui-ci créé : consultez le guide [Modifier les droits des utilisateurs](/guides/storage-and-backup/block-storage/cloud-disk-array/ceph-change-user-rights).

### Depuis l'API OVHcloud

:::tip
Si vous n'êtes pas familier avec l'utilisation de l'API OVHcloud, consultez notre guide « [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps) ».

:::


Vous pouvez créer un utilisateur en utilisant cette route API :

<Api version="v1" section="/dedicated/ceph" method="POST" route={"/dedicated/ceph/\{serviceName\}/user"} />


`serviceName` est le fsid de votre cluster.

Vous pouvez également vérifier la création des utilisateurs en dressant une liste des utilisateurs :

<Api version="v1" section="/dedicated/ceph" method="GET" route={"/dedicated/ceph/\{serviceName\}/user"} />

```bash
GET /dedicated/ceph/98d166d8-7c88-47b7-9cb6-63acd5a59c15/user
[
  {
    mdsCaps: ""
    monCaps: "allow r"
    serviceName: "98d166d8-7c88-47b7-9cb6-63acd5a59c15"
    name: "myuser"
    osdCaps: "allow class-read object_prefix rbd_children"
    key: "AQA9KpdXoBrDNhAAFCM7m/XOtmWh3LMSNlHVqw=="
  }
]
```
