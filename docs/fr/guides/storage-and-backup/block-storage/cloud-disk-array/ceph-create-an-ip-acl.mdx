## Objectif

Ce guide vous montre comment créer une ACL IP pour autoriser l'accès à votre cluster Ceph, en utilisant la console OVHcloud ou l'API OVHcloud.

## Prérequis

- Une solution [Cloud Disk Array](https://www.ovhcloud.com/fr/storage-solutions/cloud-disk-array/)

[[cpnav:storage-cloud-disk-array]]

## En pratique

:::info
L'utilisation de la console OVHcloud est le moyen le plus simple de créer une ACL IP.

:::


### Depuis la console OVHcloud

Sur la page de votre service Cloud Disk Array, ouvrez l'onglet <code className="action">Contrôle d'accès IP</code>. Par défaut, il n'y a pas d'ACL.

Obtenez votre adresse IP :

```bash
admin@server:~$ ip -4 a
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc pfifo_fast state UP group default qlen 1000
    inet 123.123.123.123/32 brd 234.234.234.234 scope global eth0
      valid_lft forever preferred_lft forever
```

Cliquez sur <code className="action">Ajouter un contrôle d'accès IP</code>. Dans le panneau qui s'ouvre, saisissez votre adresse IP dans **IP avec masque de sous-réseau** (par exemple `123.123.123.123/32`), puis cliquez sur <code className="action">Ajouter le contrôle d'accès</code>.

La demande est alors prise en compte. Vous pouvez suivre l'opération en cours dans l'onglet <code className="action">Activités</code>.

### Depuis l'API OVHcloud

:::tip
Si vous n'êtes pas familier avec l'utilisation de l'API OVHcloud, consultez notre guide « [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps) ».

:::


Utilisez l'appel API suivant :

<Api version="v1" section="/dedicated/ceph" method="POST" route={"/dedicated/ceph/\{serviceName\}/acl"} />


`serviceName` est le fsid de votre cluster.

Vous pouvez vérifier la création d'une ACL en consultant la liste des ACL.

<Api version="v1" section="/dedicated/ceph" method="GET" route={"/dedicated/ceph/\{serviceName\}/acl"} />

Example:

```bash
GET /dedicated/ceph/98d166d8-7c88-47b7-9cb6-63acd5a59c15/acl
[
  {
    network: "123.123.123.123"
    id: 57054
    netmask: "255.255.255.255"
    family: "IPV4"
  }
]
```
