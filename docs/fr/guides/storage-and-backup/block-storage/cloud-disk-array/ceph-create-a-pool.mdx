## Objectif

Ce guide vous montre comment créer un pool pour votre cluster Ceph, en utilisant la console OVHcloud ou l'API OVHcloud.

## Prérequis

- Une solution [Cloud Disk Array](https://www.ovhcloud.com/fr/storage-solutions/cloud-disk-array/)

[[cpnav:storage-cloud-disk-array]]

## En pratique

:::info
L'utilisation de la console OVHcloud est la méthode la plus simple pour créer un pool.

:::


### Depuis la console OVHcloud

Sur la page de votre service Cloud Disk Array, ouvrez l'onglet <code className="action">Pools</code>, qui liste les pools existants, et cliquez sur <code className="action">Ajouter un pool</code>.

Dans le panneau **Ajouter un pool**, saisissez un **Nom du pool** (lettres, chiffres et underscore uniquement). Celui-ci doit comporter au moins trois caractères. Cliquez ensuite sur <code className="action">Ajouter le pool</code>.

La demande de création du pool est alors prise en compte. Vous pouvez suivre l'opération en cours dans l'onglet <code className="action">Activités</code>.

## Depuis l'API OVHcloud

:::tip
Si vous n'êtes pas familier avec l'utilisation de l'API OVHcloud, consultez notre guide « [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps) ».

:::


Utilisez l'appel API ci-dessous pour créer votre pool :

<Api version="v1" section="/dedicated/ceph" method="POST" route={"/dedicated/ceph/\{serviceName\}/pool"} />


`serviceName` est le fsid de votre cluster.

Vous pouvez vérifier la création d'un pool en consultant la liste des pools, via l'appel API suivant :

<Api version="v1" section="/dedicated/ceph" method="GET" route={"/dedicated/ceph/\{serviceName\}/pool"} />

Par example:

```bash
GET /dedicated/ceph/98d166d8-7c88-47b7-9cb6-63acd5a59c15/pool
[
{
  replicaCount: 3
  serviceName: "98d166d8-7c88-47b7-9cb6-63acd5a59c15"
  name: "rbd"
  minActiveReplicas: 2
  poolType: "REPLICATED"
  backup: false
},
{
  replicaCount: 3
  serviceName: "98d166d8-7c88-47b7-9cb6-63acd5a59c15"
  name: "testpool"
  minActiveReplicas: 2
  poolType: "REPLICATED"
  backup: true
  }
]
```
