## Utilisation de la console OVHcloud
L'utilisation de la console OVHcloud est le moyen le plus simple de modifier les droits des utilisateurs.

Sur la page de votre service Cloud Disk Array, ouvrez l'onglet <code className="action">Utilisateurs</code>. Cliquez sur le bouton <code className="action">...</code> de la ligne de l'utilisateur, puis sur <code className="action">Modifier les permissions</code>.

Le panneau liste les pools du cluster avec les droits actuels de l'utilisateur (par défaut, il n'y a pas de droits). Pour chaque pool, cochez les droits à accorder : **Lecture**, **Écriture**, **Exécution**, **Classread** ou **Classwrite**.

:::warning
L'enregistrement remplace intégralement les permissions actuelles de l'utilisateur : un pool dont toutes les cases sont décochées perd tous ses droits.
:::

Cliquez sur <code className="action">Enregistrer</code>. Vous pouvez suivre l'opération en cours dans l'onglet <code className="action">Activités</code>.

## Utiliser l'API

<Api version="v1" section="/dedicated/ceph" method="PUT" route={"/dedicated/ceph/\{serviceName\}/user/\{userName\}/pool"} />


<Api version="v1" section="/dedicated/ceph" method="GET" route={"/dedicated/ceph/\{serviceName\}/user"} />

Exemple de résultat:

```bash
GET /dedicated/ceph/98d166d8-7c88-47b7-9cb6-63acd5a59c15/user
[
  {
    mdsCaps: "",
    monCaps: "allow r",
    serviceName: "98d166d8-7c88-47b7-9cb6-63acd5a59c15",
    name: "myuser"
    osdCaps: "allow class-read object_prefix rbd_children, allow rwx pool=mypool",
    key: "AQA9KpdXoBrDNhAAFCM7m/XOtmWh3LMSNlHVqw==",
  }
]
```
