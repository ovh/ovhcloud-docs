## Objectif

Les services Enterprise File Storage peuvent être gérés [via les API OVHcloud](/guides/storage-and-backup/file-storage/enterprise-file-storage/netapp-quick-start) ou depuis la <ManagerLink to="/">console OVHcloud</ManagerLink>.

**Découvrez comment gérer les volumes et les snapshots de votre offre Enterprise File Storage depuis la console OVHcloud.**

## Prérequis

- Avoir un service Enterprise File Storage dans votre compte OVHcloud. Le service peut être commandé depuis la [page produit](https://www.ovhcloud.com/fr/storage-solutions/enterprise-file-storage/) ou depuis la <ManagerLink to="/">console OVHcloud</ManagerLink>.

[[cpnav:storage-enterprise-file-storage]]

## En pratique <a name="instructions"></a>

Dans la console OVHcloud, ouvrez **Bare Metal Cloud**, cliquez sur <code className="action">Enterprise File Storage</code> sous **Stockage** dans le menu de gauche, puis sélectionnez votre service dans la liste.

L'onglet <code className="action">Vue d'ensemble</code> affiche les **Informations générales** et la **Configuration du service** (avec un raccourci pour [créer un volume](#create_volume)), la **Configuration du réseau**, les informations d'**Abonnement** et les **Tags** de votre service.

:::info
Consultez la page [Concepts](/guides/storage-and-backup/file-storage/enterprise-file-storage/netapp-concepts) pour obtenir des informations détaillées sur les propriétés techniques de la solution Enterprise File Storage.

:::


### Gestion des volumes <a name="manage_volume"></a>

Rendez-vous dans l'onglet <code className="action">Volumes</code>. Le tableau liste tous les volumes que vous avez créés pour le service sélectionné. Cliquez sur le nom d'un volume pour ouvrir sa [page de gestion](#modify_volume).

Pour effectuer une action sur un volume, cochez la case de sa ligne, puis ouvrez le menu <code className="action">Actions (1)</code> au-dessus du tableau :

- **Modifier le volume** : ouvre l'[onglet « Information »](#modify_volume) du volume.
- **Redimensionner le volume** : ouvre une fenêtre dans laquelle vous indiquez la **Nouvelle taille** du volume, puis cliquez sur <code className="action">Redimensionner</code>.
- **Gérer les snapshots** : ouvre l'[onglet « Snapshots »](#snapshots) du volume.
- **Gérer IP Access (ACL)** : ouvre l'[onglet « ACL »](#access_control) du volume.
- **Répliquer les volumes** : réplique les volumes sélectionnés vers un autre service Enterprise File Storage.
- **Supprimer le volume** : supprime ce volume après confirmation de l'action dans la fenêtre qui s'ouvre.

#### Création d'un volume <a name="create_volume"></a>

Cliquez sur le bouton <code className="action">Créer un volume</code>. Dans la fenêtre qui s'ouvre, vous pouvez saisir un **Nom** et une **Description** (facultatifs), choisir le **Protocole**, sélectionner éventuellement un snapshot dans **Créer à partir d'un snapshot**, définir la **Taille** et, si besoin, le **Chemin de montage**. Cliquez sur <code className="action">Créer le volume</code> pour confirmer.

#### Modification d'un volume <a name="modify_volume"></a>

Cliquez sur le nom d'un volume dans le tableau pour ouvrir sa page de gestion.

L'onglet <code className="action">Information</code> affiche les détails de votre volume (sections **Volume**, **Stockage** et **Aperçu de l'utilisation**) ainsi que la section **Connexion des volumes**, avec le chemin de montage et les étapes pour vous connecter au volume.

Depuis cet onglet, vous pouvez également modifier le nom (<code className="action">Modifier le nom</code>) et la description (<code className="action">Modifier la description</code>) du volume, le redimensionner (<code className="action">Redimensionner le volume</code>) et modifier sa réserve de snapshots (<code className="action">Modifier la réserve de snapshots</code>).

L'onglet <code className="action">Connexions NFS</code> liste les connexions NFS au volume, et l'onglet <code className="action">Performance</code> affiche ses métriques de performance.

#### Suppression d'un volume <a name="delete_volume"></a>

Vous pouvez supprimer un volume en cliquant sur <code className="action">Supprimer le volume</code> dans son onglet <code className="action">Information</code>, ou en cochant sa case dans l'onglet <code className="action">Volumes</code> puis en sélectionnant <code className="action">Supprimer le volume</code> dans le menu <code className="action">Actions (1)</code>.

Confirmez la suppression en saisissant `DELETE` dans le champ de confirmation, puis cliquez sur le bouton <code className="action">Supprimer le volume</code>.

### Gestion des snapshots d'un volume <a name="snapshots"></a>

:::info
Les snapshots utilisent la capacité de stockage de votre solution Enterprise File Storage. Par défaut, 5 % de la taille d'un volume sont toujours réservés aux snapshots.

:::

L'onglet <code className="action">Snapshots</code> d'un volume liste tous les snapshots créés pour celui-ci. Vous pouvez les filtrer par **Type**.

Dans la section **Politique de snapshot** de cet onglet, vous pouvez consulter la [Snapshot Policy](#snapshot_policy) appliquée au volume et ses règles (<code className="action">Voir les règles</code>).

Pour appliquer une autre politique, cliquez sur <code className="action">Gérer la politique de snapshot</code>, sélectionnez une politique dans **Politiques disponibles**, puis cliquez sur <code className="action">Appliquer la politique</code>. La politique `default` ne peut pas être sélectionnée manuellement.

Pour configurer vos [Snapshot Policies](#snapshot_policy), revenez sur votre service et ouvrez l'onglet <code className="action">Politiques</code>.

#### Création d'un snapshot <a name="create_snapshot"></a>

Pour créer un nouveau snapshot `manuel` de l'état actuel du volume, cliquez sur <code className="action">Prendre un snapshot</code> dans l'onglet <code className="action">Snapshots</code> (ou dans l'onglet <code className="action">Information</code>).

Dans la fenêtre qui s'ouvre, vous pouvez saisir un **Nom** et une **Description** pour le snapshot (facultatifs). Cliquez sur <code className="action">Prendre un snapshot</code> pour lancer la création du snapshot.

#### Modification d'un snapshot <a name="modify_snapshot"></a>

Pour modifier le nom ou la description d'un snapshot `manuel`, cliquez sur le bouton <code className="action">...</code> de sa ligne, puis sur <code className="action">Modifier</code>. Dans la fenêtre qui s'ouvre, choisissez un nouveau nom et/ou une nouvelle description, puis cliquez sur <code className="action">Confirmer</code>.

#### Suppression d'un snapshot <a name="delete_snapshot"></a>

:::warning
Il n'est pas possible de supprimer un snapshot de type `système`.
Ceux-ci sont indispensables au bon fonctionnement de votre offre Enterprise File Storage.

:::

Un snapshot peut être supprimé en cliquant sur le bouton <code className="action">...</code> de sa ligne dans l'onglet <code className="action">Snapshots</code>, puis en sélectionnant <code className="action">Supprimer</code>. Dans la fenêtre qui s'ouvre, cliquez sur <code className="action">Supprimer le snapshot</code>.

#### Restauration du volume en utilisant un snapshot <a name="restore_volume"></a>

:::warning
Veuillez noter qu'une fois qu'un volume est restauré à l'aide d'un snapshot, tous les fichiers ou snapshots créés ultérieurement seront perdus.
Lorsqu'un volume est restauré, toutes les données qu'il contient sont remplacées par les données du snapshot. Cette action est irréversible.

:::

Vous pouvez restaurer un volume à partir de son snapshot le plus récent en cliquant sur <code className="action">Restaurer le dernier snapshot</code> dans l'onglet <code className="action">Snapshots</code>. Dans la fenêtre qui s'ouvre, saisissez le nom du volume pour confirmer, puis cliquez sur <code className="action">Restaurer le dernier snapshot</code>. Si le snapshot le plus récent est de type `automatique`, il est d'abord sauvegardé en snapshot `manuel` avant la restauration du volume.

:::info
Afin de restaurer le volume en utilisant un snapshot antérieur au dernier snapshot, il est nécessaire de supprimer les snapshots jusqu'à ce que le snapshot à utiliser pour la restauration soit le plus récent.

:::

#### Sauvegarde d'un snapshot automatique <a name="hold_snapshot"></a>

Un snapshot `automatique`, créé par une [Snapshot Policy](#snapshot_policy), peut être sauvegardé en cliquant sur le bouton <code className="action">...</code> de sa ligne dans l'onglet <code className="action">Snapshots</code>, puis en sélectionnant <code className="action">Sauvegarder</code>.

En sauvegardant un snapshot `automatique`, celui-ci deviendra `manuel`, ce qui empêchera sa rotation par la politique de snapshots et donc sa suppression automatique.

Vous pouvez également créer un nouveau volume à partir d'un snapshot `manuel` : cliquez sur le bouton <code className="action">...</code> de sa ligne, puis sur <code className="action">Créer un volume</code>.

### Gestion des ACL de volumes <a name="access_control"></a>

Le contrôle d'accès aux volumes fonctionne via des restrictions d'adresses IP. Comme aucune restriction n'est configurée par défaut, la première étape lors de la création de volumes consiste à définir des adresses IP ou des plages à partir desquelles l'accès sera autorisé.

Ouvrez l'onglet <code className="action">ACL</code> du volume et cliquez sur <code className="action">Ajouter une règle</code>. Dans le panneau **Ajouter une règle ACL**, saisissez une **Adresse IP** ou un bloc d'adresses (CIDR), sélectionnez le **Niveau d'accès** (`Lecture seule` ou `Lecture/Écriture`), puis cliquez sur <code className="action">Ajouter</code>.

Pour supprimer un accès au volume, cliquez sur le bouton <code className="action">...</code> de sa ligne, puis sur <code className="action">Supprimer la règle</code>.

### Gestion des politiques de snapshots <a name="snapshot_policy"></a>

:::info
Par défaut, chaque volume est protégé par une Snapshot Policy nommée `default` qui crée des snapshots du volume à intervalles réguliers.

:::

L'ajout de politiques vous permet de planifier la création de snapshots pour tous vos volumes.

Rendez-vous dans l'onglet <code className="action">Politiques</code> de votre service. Le tableau liste toutes les politiques créées pour le service sélectionné.

Une politique par défaut est déjà en place et ne peut pas être modifiée. Pour ajouter la vôtre, cliquez sur le bouton <code className="action">Créer une politique</code>.

Sur la page **Créer une politique de snapshot**, saisissez un **Nom de la politique** et une **Description de la politique**. Cliquez ensuite sur <code className="action">Ajouter une règle</code> pour ajouter une ou plusieurs règles à la politique.

Renseignez les champs pour indiquer les **Minute(s)**, **Heure(s)**, **Jour(s) du mois**, **Mois** et **Jour(s) de la semaine** de création des snapshots, le **Préfixe** nécessaire à leur nommage et le nombre de **Copies à garder**. En dépliant la section **Exemple**, vous pouvez consulter deux ensembles de règles accompagnés d'une explication de leur résultat.

Cliquez sur l'icône de validation de la ligne pour ajouter la nouvelle règle. Une fois toutes les règles ajoutées, cliquez sur <code className="action">Créer la politique</code>.

[Sélectionnez un volume](#manage_volume) et rendez-vous dans son onglet <code className="action">Snapshots</code> afin d'[appliquer vos politiques](#snapshots).

Pour supprimer une politique, cliquez sur le bouton <code className="action">...</code> de sa ligne, puis sur <code className="action">Supprimer</code>.
