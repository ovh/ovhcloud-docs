## Objectif

Le NAS (Network Attached Storage) est un serveur de fichiers relié à un réseau dont la principale fonction est le stockage de données en un volume centralisé pour des clients réseau hétérogènes.

## Prérequis

- Disposer d'une adresse IP attachée à un service OVHcloud (Hosted Private Cloud, Serveur Dédié, VPS, Instance Public Cloud, Offre Internet, etc...)
- Disposer d'un [NAS-HA](https://www.ovhcloud.com/fr/storage-solutions/nas-ha/)

[[cpnav:storage-nas-ha]]

## En pratique

Cliquez sur le nom de votre service dans la liste. L'onglet <code className="action">Vue d'ensemble</code> affiche les **Informations générales** de votre service (dont son **Identifiant** et son **Adresse IP**), sa **Configuration du service** et son **Abonnement**.

:::info
Dans la console OVHcloud, les partitions d'un NAS-HA sont appelées **volumes**.
:::

Pour agir sur un volume existant, ouvrez l'onglet <code className="action">Volumes</code>, cochez la case du volume concerné, puis ouvrez le menu <code className="action">Actions</code>.

### Créer une partition <a name="partition"></a>

Pour ajouter une nouvelle partition, ouvrez l'onglet <code className="action">Volumes</code> et cliquez sur <code className="action">Créer un volume</code>.

Renseignez le **Nom du volume**, la **Taille (GB)**, une **Description** facultative ainsi que le **Protocole** autorisé (**NFS**, **CIFS (SMB)** ou **NFS + CIFS**), puis cliquez sur <code className="action">Créer le volume</code>.

### Modifier la taille d'une partition

Pour modifier la taille d'une partition, cochez la case du volume concerné, puis cliquez sur <code className="action">Actions</code> et sur <code className="action">Modifier la taille</code>.

Indiquez la **Nouvelle taille**, puis cliquez sur <code className="action">Appliquer</code>.

### Modifier la fréquence des snapshots

Par défaut, un snapshot du contenu de votre NAS a lieu toutes les heures, et s'enregistre sur votre NAS.

Il vous est néanmoins possible d'activer des snapshots supplémentaires à des fréquences différentes si vous le souhaitez, qui seront également enregistrés sur votre NAS.

Pour cela, cochez la case du volume concerné, puis cliquez sur <code className="action">Actions</code> et sur <code className="action">Gérer les snapshots</code>. Dans l'onglet <code className="action">Politiques de snapshot</code> du volume, cliquez sur <code className="action">Gérer les fréquences de snapshot</code> dans la section **Snapshots automatiques**.

Cochez les fréquences à activer, puis cliquez sur <code className="action">Enregistrer les modifications</code>.

### Créer un snapshot instantané

En dehors des snapshots réalisés automatiquement, vous pouvez à tout moment créer un snapshot instantané d'une partition. Dans l'onglet <code className="action">Politiques de snapshot</code> du volume, cliquez sur <code className="action">Prendre un snapshot</code> dans la section **Snapshots manuels**.

Renseignez un **Suffixe du snapshot** (votre snapshot sera nommé `snap-<nom du volume>-<votre suffixe>`) et cliquez sur <code className="action">Prendre un snapshot</code>.

Pour supprimer des snapshots manuels, cochez-les dans la liste **Snapshots manuels**, cliquez sur <code className="action">Supprimer</code>, puis confirmez.

### Ajouter un accès <a name="addaccess"></a>

Afin de pouvoir accéder à la partition que vous avez créée précédemment, vous devez configurer un accès.

:::info
Seules les adresses IP de services OVHcloud peuvent accéder à votre NAS (ex : un serveur dédié, un accès Internet fourni par OVHcloud, un VPS, une instance Public Cloud, etc...)

:::


Pour autoriser une IP à accéder au NAS, cochez la case du volume concerné, puis cliquez sur <code className="action">Actions</code> et sur <code className="action">Gérer les accès</code>. L'onglet <code className="action">Contrôle d'accès (ACL)</code> du volume s'ouvre.

Cliquez alors sur <code className="action">Ajouter un accès</code> puis sélectionnez l'adresse IP ou le bloc IP de votre produit OVHcloud dans le champ **IP**.
<br/>Vous devez également définir dans **Type** si l'accès autorisé pour cette adresse IP est en **Lecture seule** ou en **Lecture/Écriture**. Cliquez ensuite sur <code className="action">Ajouter un accès</code>.

#### Supprimer un accès

Pour supprimer un accès à une partition, cochez l'adresse IP concernée dans l'onglet <code className="action">Contrôle d'accès (ACL)</code> du volume, cliquez sur <code className="action">Supprimer</code>, puis sur <code className="action">Supprimer l'accès</code>.

### Paramètres Z File System (ZFS)

:::warning
Tous les paramètres ZFS par défaut sont optimisés. Bien que nous déconseillons la modification de ces paramètres, ce menu permet d'ajuster le ZFS utilisé par le NAS-HA.

:::


Pour modifier les paramètres ZFS d'une partition, cochez la case du volume concerné, puis cliquez sur <code className="action">Actions</code> et sur <code className="action">Paramétrer l'usage (ZFS)</code>. Choisissez un modèle dans **Sélectionner le template** (choisissez **Personnalisé** pour définir chaque paramètre vous-même), puis cliquez sur <code className="action">Modifier les paramètres</code>.

- **Désactiver la mise à jour des temps d'accès (*atime*)** : La désactivation du *atime* signifie que le noyau ne mettra plus à jour l'horodatage du système de fichiers à chaque accès à un fichier. Cela peut être utile pour accélérer les opérations de lecture fréquentes, par exemple sur des pages web statiques. Cependant, cette désactivation n'est pas conseillée pour les applications critiques en terme de cohérence, telles que les bases de données.
- **ZFS recordsize** : Cette propriété modifie la taille de bloc maximale sur le système de fichiers ZFS. Notez que ZFS utilisera toujours une taille de bloc inférieure si le fichier est inférieur à la taille maximale. Par exemple, un fichier de 16 KB utilisera un bloc de 16 KB (plus les métadonnées) pour ne pas gaspiller d'espace de stockage. De manière générale, nous vous déconseillons donc de modifier le ZFS *recordsize*.
- **Sync** : Ce paramètre modifie le comportement des transactions du système de fichiers ZFS en ce qui concerne la mise en mémoire tampon des données RAM et l’écriture des données sur le disque. Sauf raison spécifique, nous vous déconseillons de modifier cette propriété.

### Supprimer une partition

:::danger
La suppression d'une partition entraîne la suppression totale et définitive de toutes les données qu'elle contient.

:::


Pour supprimer une partition, cochez la case du volume concerné, puis cliquez sur <code className="action">Actions</code> et sur <code className="action">Supprimer</code>. Saisissez `DELETE` pour confirmer, puis cliquez sur <code className="action">Supprimer</code>.
