## Objectif

Le service NAS-HA OVHcloud vous permet de gérer un stockage de fichiers accessible depuis un réseau.

**Ce guide vous explique comment gérer les partitions de votre service NAS-HA via l'API OVHcloud.**

## Prérequis

- Un service [NAS-HA OVHcloud](https://www.ovhcloud.com/fr/storage-solutions/nas-ha/)
- Consultez notre guide des [premiers pas avec l'API OVHcloud](/guides/manage-and-operate/api/first-steps) afin de vous familiariser avec l'APIv6 OVHcloud

## En pratique

Toutes les routes API de ce guide sont disponibles dans la <ApiLink section="/dedicated/nasha">section */dedicated/nasha*</ApiLink> de la console API.

:::info
Lors de l'utilisation de l'API, tous les champs marqués d'un astérisque (\*) sont obligatoires.
:::


### Récupérer des informations sur votre service

Tous vos services actifs peuvent être récupérés en utilisant la route suivante :

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha"} />


### Liste de toutes les partitions

Utilisez la route suivante pour récupérer les partitions d'un service :

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service NAS |

### Récupérer les propriétés d'une partition

Pour visualiser les détails d'une partition, utilisez la route suivante :

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service NAS-HA |
| `partitionName` | Yes | Nom de la partition |

### Récupération des statistiques d'une partition

Utilisez la route suivante pour récupérer les informations d'utilisation d'une partition :

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/use"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service NAS-HA |
| `partitionName` | Yes | Nom de la partition |
| `type` | Yes | Le type de statistique à récupérer : *size*, *used* or *usedbysnapshots* |

### Création d'une partition

Utilisez la route suivante pour créer une nouvelle partition :

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service NAS |
| `partitionDescription` |  | Description facultative |
| `partitionName` | Yes | Un nom pour la partition |
| `protocol` | Yes | *NFS*, *CIFS* ou *NFS_CIFS* pour les deux |
| `size` | Yes | La taille de la partition |

Choisissez `NFS` comme protocole et une taille de `10` Gigaoctets par exemple.

### Modifier les propriétés d'une partition

Utilisez la route suivante pour modifier une partition :

<Api version="v1" section="/dedicated/nasha" method="PUT" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service NAS |
| `partitionName` | Yes | Nom de la partition |
| `partitionDescription` |  | La nouvelle description |
| `size` |  | La nouvelle taille de la partition |

### Récupérer les paramètres ZFS d’une partition

Utilisez la route suivante pour récupérer les paramètres ZFS :

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service NAS |
| `partitionName` | Yes | Nom de la partition |

### Modification des paramètres ZFS d’une partition

:::warning
Les paramètres ZFS par défaut conviennent à la plupart des usages. Ne les modifiez que si vous connaissez les données hébergées sur la partition. Pour le détail de chaque paramètre et des valeurs appliquées par chaque template d'usage, consultez notre guide « [Configurer les paramètres ZFS d'une partition](/guides/storage-and-backup/file-storage/ha-nas/nas-zfs-settings) ».
:::


Utilisez la route suivante pour modifier les paramètres ZFS :

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service NAS |
| `partitionName` | Yes | Nom de la partition |
| `templateName` |  | Template d'usage à appliquer : *Default*, *Virtual machines*, *Databases* ou *File Systems (big files)*. À envoyer seul, sans `atime`, `recordsize` ni `sync` |
| `atime` |  | Paramètre de mise à jour du temps d'accès : *off* (par défaut) ou *on* |
| `recordsize` |  | Taille de bloc maximale, en octets : *4096*, *8192*, *16384*, *32768*, *65536*, *131072* (par défaut) ou *1048576* |
| `sync` |  | Paramètre de synchronisation de fichier : *always*, *disabled* ou *standard* (valeur par défaut) |

### Suppression d'une partition

Utilisez la route suivante pour supprimer une partition :

<Api version="v1" section="/dedicated/nasha" method="DELETE" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service NAS-HA |
| `partitionName` | Yes | Nom de la partition |
