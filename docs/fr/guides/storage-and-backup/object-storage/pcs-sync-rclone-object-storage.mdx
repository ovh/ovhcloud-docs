## Objectif

L'Object Storage d'OVHcloud peut être synchronisé via rClone.

**Ce guide a pour objectif de vous rappeler les étapes pour effectuer cette synchronisation avec rClone et la console OVHcloud.**

rClone étant un logiciel de synchronisation externe, les détails d'utilisation de celui-ci sont à découvrir directement sur sa [documentation officielle](https://Rclone.org/).

## Prérequis

- Avoir créé son container *Object Storage* (depuis la console OVHcloud ou depuis [Horizon](/guides/storage-and-backup/object-storage/pcs-create-container)).
- Avoir créé un [utilisateur OpenStack](/guides/public-cloud/cross-functional/create-and-delete-a-user).

[[cpnav:publiccloud-object-storage]]

## En pratique

Une fois votre container et votre utilisateur OpenStack créés, il vous reste deux choses à faire :

- Récupérer le fichier de configuration pour rClone :

Une fois votre [utilisateur OpenStack](/guides/public-cloud/cross-functional/create-and-delete-a-user) créé, vous pouvez récupérer le fichier de configuration nécessaire pour rClone depuis la console OVHcloud.

Pour cela, dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">Object Storage</code> sous **Stockage**, puis ouvrez l'onglet <code className="action">Utilisateurs</code>. Cliquez sur le bouton <code className="action">...</code> de la ligne de l'utilisateur, puis sur <code className="action">Télécharger une configuration rclone</code>. Sélectionnez **Swift** comme **Type**, choisissez la **Région** de votre conteneur, puis cliquez sur <code className="action">Télécharger</code>.

- Configurer rClone :

Une fois le fichier téléchargé, vous pouvez lancer la commande suivante afin d’ajouter votre nouvel espace de stockage :

```sh
rclone config
```

Vous serez invité à insérer les données de configuration présentes dans votre fichier.

:::info
Vous pouvez également copier-coller le contenu de votre fichier dans l'espace dédié aux configurations de Rclone (*.config/Rclone/Rclone.conf*).
:::


Une fois votre configuration effectuée, vous pouvez la tester en listant par exemple vos containers :

```sh
rclone lsd BackupStorage
```

*BackupStorage* correspond au nom donné à votre espace de stockage.

Vous trouverez sur le site officiel de rClone une documentation précise des actions à effectuer pour synchroniser votre Object Storage et rClone : [Documentation officielle rClone](https://Rclone.org/swift/).
