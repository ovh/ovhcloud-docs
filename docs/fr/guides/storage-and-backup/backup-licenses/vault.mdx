## Objectif

Un **Vault** est un espace de stockage fourni par OVHcloud vers lequel vous pouvez envoyer les données de vos sauvegardes. Avec Backup Licenses, un premier Vault est livré automatiquement avec votre première licence.

**Ce guide explique comment fonctionnent les Vaults du produit Backup Licenses, comment ils sont facturés et comment en commander des supplémentaires.**

## Prérequis

- Avoir commandé une licence Backup Licenses. Consultez notre guide « [Commander et configurer votre première licence](/guides/storage-and-backup/backup-licenses/first-configuration) » pour plus d'informations.

## En pratique

### Le Vault « bundle »

Un Vault dit **« bundle »** est livré par défaut avec votre première licence Backup Licenses.

- Ce Vault est **lié à la souscription du produit** : il est **supprimé si le produit Backup Licenses est résilié**.
- Il est **unique** : vous ne disposez que d'un seul Vault « bundle », quel que soit le nombre de licences.
- Il est **gratuit jusqu'à 500 Go**. Cet espace peut être utilisé pour vos serveurs VBR comme pour d'autres besoins de stockage.

:::danger
La résiliation du produit Backup Licenses entraîne la **suppression du Vault « bundle » et des données qu'il contient**. Assurez-vous d'avoir récupéré vos données avant toute résiliation.

:::

### Récupérer les informations de connexion du Vault

Le Vault « bundle » est mis à disposition sous la forme d'un **bucket S3<sup>1</sup>**. Pour récupérer les informations de connexion (endpoint, identifiants d'accès), cliquez sur <code className="action">Montrer les identifiants</code> depuis la fiche du Vault dans votre espace client OVHcloud.

Ces informations vous permettent de configurer le Vault comme dépôt objet dans votre serveur Veeam Backup & Replication, ou d'y accéder avec n'importe quel client compatible S3.

### Facturation du Vault « bundle »

- Les **500 premiers Go sont inclus** dans votre souscription Backup Licenses, sans surcoût.
- **Au-delà de 500 Go**, chaque Go supplémentaire consommé est facturé **mensuellement**, au **tarif public de l'OVHcloud Object Storage**.

:::info
Les tarifs à jour sont disponibles sur la page [tarifs Object Storage](/links/public-cloud/prices-object-storage).

:::

### Commander des Vaults supplémentaires

Vous pouvez commander des **Vaults supplémentaires** depuis votre espace client OVHcloud.

Ils fonctionnent exactement de la même manière que le Vault « bundle » (bucket S3, mêmes usages, mêmes modalités d'accès), à une différence près : ils sont **facturés dès le premier Go consommé**, au tarif public de l'OVHcloud Object Storage. Aucun volume gratuit n'y est associé.

Le tableau ci-dessous résume les différences :

| | Vault « bundle » | Vault supplémentaire |
|---|---|---|
| **Livraison** | Livré automatiquement avec la première licence | Commandé à la demande depuis l'espace client |
| **Nombre** | Un seul par souscription | Autant que nécessaire |
| **Volume inclus** | 500 Go gratuits | Aucun |
| **Facturation** | À partir du 501e Go, au tarif public Object Storage | Dès le premier Go, au tarif public Object Storage |
| **Cycle de vie** | Supprimé à la résiliation du produit Backup Licenses | Résiliable indépendamment |
