## Objectif

Une fois votre service livré, Prism Central est accessible sur l'Internet public. Vous pouvez en restreindre l'accès à une ou plusieurs adresses IP via le [Load Balancer OVHcloud](https://www.ovhcloud.com/fr/network/load-balancer/).

**Ce guide vous explique comment sécuriser l'accès à l'interface Prism Central.**

:::warning
OVHcloud vous met à disposition des services dont la configuration, la gestion et la responsabilité vous incombent. Il vous appartient donc de ce fait d’en assurer le bon fonctionnement.

Ce guide a pour but de vous accompagner au mieux sur des tâches courantes. Néanmoins, nous vous recommandons de faire appel à l'équipe [Professional Services OVHcloud](https://www.ovhcloud.com/fr/professional-services/) ou à un [prestataire spécialisé](https://partner.ovhcloud.com/fr/directory/) si vous éprouvez des difficultés ou des doutes concernant l’administration, l’utilisation ou la mise en place d’un service sur un serveur.

:::

## Prérequis

- Disposer d'un cluster Nutanix dans votre compte OVHcloud

## En pratique

### Étape 1 : trouver le Load Balancer concerné

{/* CP-STEPS-START:trouver-le-load-balancer */}

Sélectionnez votre cluster. Dans son onglet <code className="action">Vue d'ensemble</code>, la section **Réseau** indique le Load Balancer de votre cluster à la ligne **Répartiteur de charge**.

{/* CP-STEPS-END:trouver-le-load-balancer */}

### Étape 2 : accéder aux frontends de votre Load Balancer

{/* CP-STEPS-START:acceder-aux-frontends */}

Cliquez sur le nom du Load Balancer à la ligne **Répartiteur de charge** pour ouvrir sa page.

Ouvrez l'onglet <code className="action">Frontends</code>.

{/* CP-STEPS-END:acceder-aux-frontends */}

### Étape 3 : modifier le front-end Prism Central

{/* CP-STEPS-START:modifier-le-front-end-prism-central */}

Dans le tableau, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions** du frontend Prism Central, puis sur <code className="action">Modifier</code>. La page **Modifier le frontend** s'ouvre.

{/* CP-STEPS-END:modifier-le-front-end-prism-central */}

### Étape 4 : ajouter les IPs autorisées

{/* CP-STEPS-START:ajouter-les-ips-autorisees */}

Cliquez sur <code className="action">Paramètres avancés</code> pour déplier cette section. Dans le champ **IPs autorisées**, saisissez l'adresse IP de votre fournisseur d'accès à Internet public ou toute adresse IP que vous souhaitez autoriser à accéder à l'interface web Prism Central, en notation CIDR, puis cliquez sur <code className="action">Ajouter</code> pour chacune d'elles. Si la liste est vide, l'accès est autorisé depuis toutes les adresses.

Cliquez sur <code className="action">Enregistrer les modifications</code>. Ensuite, pour appliquer la configuration, rendez-vous dans l'onglet <code className="action">Vue d'ensemble</code> puis, dans la section **Informations générales**, sous **Déploiement**, cliquez sur <code className="action">Appliquer N changements</code>, N étant le nombre de modifications en attente. Un seul clic applique la configuration à toutes les zones de votre Load Balancer.

{/* CP-STEPS-END:ajouter-les-ips-autorisees */}
