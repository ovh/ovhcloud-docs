## Objectif

Les clusters Nutanix sur OVHcloud sont évolutifs. Vous pouvez désormais **ajouter (scale out)** ou **retirer (scale in)** des nœuds directement depuis la console ou l'API OVHcloud.

:::warning
OVHcloud vous met à disposition des services dont la configuration, la gestion et la responsabilité vous incombent. Il vous appartient donc de ce fait d’en assurer le bon fonctionnement.

Ce guide a pour but de vous accompagner au mieux sur des tâches courantes. Néanmoins, nous vous recommandons de faire appel à l'équipe [Professional Services OVHcloud](https://www.ovhcloud.com/fr/professional-services/) ou à un [prestataire spécialisé](https://partner.ovhcloud.com/fr/directory/) si vous éprouvez des difficultés ou des doutes concernant l’administration, l’utilisation ou la mise en place d’un service sur un serveur.

:::

## Prérequis

- Un cluster Nutanix hébergé dans votre compte OVHcloud
- Être connecté à l’<ApiLink>API OVHcloud</ApiLink>
- Être connecté à l’interface Prism Central

## Informations techniques

- Votre cluster doit comporter entre **3 et 32 nœuds**
- Tous les nouveaux nœuds doivent utiliser la **même version d’AOS** que le cluster existant

## En pratique

### Scale Out (ajouter un nœud)

#### Ajouter un nœud

{/* CP-STEPS-START:ajouter-un-noeud */}

1. Sélectionnez votre cluster Nutanix. Sa page s'ouvre sur l'onglet **Vue d'ensemble**.

2. Dans la section **Informations générales**, la ligne **Nombre de nœuds** indique le nombre de nœuds de votre abonnement. Cliquez sur <code className="action">Ajouter un nœud</code> sur cette ligne. Le même bouton est également disponible dans l'onglet **Nœuds**.

3. La page **Ajouter un nœud** s'ouvre. Vérifiez la configuration du nœud (génération, modèle, stockage et RAM) et le tarif mensuel indiqué dans le panneau **Récapitulatif de la commande**. Vous pouvez ajouter un nœud par commande.

4. Cliquez sur <code className="action">Commander</code> pour lancer l'ajout. La commande express s'ouvre dans un nouvel onglet de votre navigateur, où vous finalisez votre commande.

Une fois le nœud livré, il apparaît dans l'onglet **Nœuds** avec le badge **Non installé** dans la colonne **OS installé** : il s'agit d'un nouveau nœud prêt à être installé.

{/* CP-STEPS-END:ajouter-un-noeud */}

#### Installer un système d’exploitation (OS)

<Tabs>
  <Tab label="Console OVHcloud">
    {/* CP-STEPS-START:installer-un-os */}

    Cliquez sur l'onglet <code className="action">Nœuds</code> pour afficher la liste de vos nœuds. Pour tout nœud portant le badge **Non installé** dans la colonne **OS installé**, cliquez sur le bouton `⋮` de la colonne **Actions** et sélectionnez <code className="action">Installer</code>.

    La fenêtre **Installer le nœud** s'ouvre. Saisissez les paramètres de configuration du nœud : ses adresses **IP AHV** et **IP CVM**, ainsi que la version d'AOS dans le champ **Version**. Veillez à installer la même version d'AOS que votre cluster.

    Cliquez sur <code className="action">Confirmer</code>.

    {/* CP-STEPS-END:installer-un-os */}
  </Tab>
  <Tab label="API OVHcloud">
    Pour installer le nœud via l’<ApiLink>API OVHcloud</ApiLink>, utilisez l’appel suivant :
    
    <Api version="v1" section="/nutanix" method="PUT" route={"/nutanix/\{serviceName\}/nodes/\{server\}/deploy"} />
  </Tab>
</Tabs>


Une fois le nœud installé, vous pouvez vous connecter à Prism Central ou Prism Element pour l’intégrer au cluster.

Consultez la documentation suivante :

- [Étendre un cluster via Prism Central](https://portal.nutanix.com/page/documents/details?targetId=Prism-Central-Guide-vpc_2024_3_1:mul-node-add-pc-t.html)
- [Étendre un cluster](https://portal.nutanix.com/page/documents/details?targetId=Web-Console-Guide-Prism-v7_0:wc-cluster-expand-wc-t.html)

### Scale In (retirer un nœud)

#### Éteindre (power down) un nœud

{/* CP-STEPS-START:eteindre-un-noeud-1 */}

1. Accédez à votre cluster Nutanix via le menu <code className="action">Nutanix</code>.

2. Dans l'onglet **Vue d'ensemble**, la ligne **Nombre de nœuds** de la section **Informations générales** indique le nombre de nœuds de votre abonnement. Cliquez sur l'onglet <code className="action">Nœuds</code> pour afficher la liste de vos nœuds.

3. Deux options s'offrent à vous :

{/* CP-STEPS-END:eteindre-un-noeud-1 */}

<Tabs>
  <Tab label="Console OVHcloud">
    {/* CP-STEPS-START:eteindre-un-noeud-2 */}

    Pour le nœud à retirer, cliquez sur le bouton `⋮` de la colonne **Actions** puis sélectionnez <code className="action">Éteindre</code>.

    La fenêtre **Éteindre le nœud** s'ouvre et vous demande de confirmer. Cliquez sur <code className="action">Éteindre</code>.

    :::info
    L'arrêt d'un nœud Nutanix peut avoir un impact sur votre cluster. Consultez les [prérequis sur le portail Nutanix](https://portal.nutanix.com/page/documents/list?type=software) avant de poursuivre.

    :::

    {/* CP-STEPS-END:eteindre-un-noeud-2 */}
  </Tab>
  <Tab label="API OVHcloud">
    Vous pouvez également arrêter un nœud via l’<ApiLink>API OVHcloud</ApiLink>.
    
    - Récupérez le Boot ID (saisissez *power* comme valeur pour **bootType**) :
    
    <Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/boot"} />
    
    - Définissez le Boot ID :
    
    <Api version="v1" section="/dedicated/server" method="PUT" route={"/dedicated/server/\{serviceName\}"} />
    
    - Éteignez le nœud :
    
    <Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/reboot"} />
  </Tab>
</Tabs>


#### Désinstaller le nœud

<Tabs>
  <Tab label="Console OVHcloud">
    {/* CP-STEPS-START:desinstaller-le-noeud */}

    Une fois le nœud éteint, cliquez sur le bouton `⋮` de la colonne **Actions** puis sélectionnez <code className="action">Désinstaller</code>.

    La fenêtre **Désinstaller le nœud** s'ouvre. Saisissez `UNINSTALL` dans le champ pour confirmer, puis cliquez sur <code className="action">Désinstaller</code>.

    :::info
    La désinstallation d'un nœud Nutanix peut avoir un impact sur votre cluster. Consultez les [prérequis sur le portail Nutanix](https://portal.nutanix.com/page/documents/list?type=software) avant de poursuivre.

    :::

    {/* CP-STEPS-END:desinstaller-le-noeud */}
  </Tab>
  <Tab label="API OVHcloud">
    Pour désinstaller un nœud via l’<ApiLink>API OVHcloud</ApiLink>, utilisez l’appel suivant :
    
    <Api version="v1" section="/nutanix" method="POST" route={"/nutanix/\{serviceName\}/nodes/\{server\}/terminate"} />
  </Tab>
</Tabs>


#### Supprimer le nœud

{/* CP-STEPS-START:supprimer-le-noeud */}

Une fois le nœud désinstallé, cliquez sur le bouton `⋮` de la colonne **Actions** puis sélectionnez <code className="action">Résilier</code>.

La fenêtre **Résilier le nœud** s'ouvre. Cliquez sur <code className="action">Confirmer</code> pour résilier le nœud.

:::info
Le service suspendu restera visible dans la liste des nœuds pendant environ une semaine avant suppression définitive. Vous pouvez ainsi réactiver le service si vous souhaitez annuler la suppression.

:::

{/* CP-STEPS-END:supprimer-le-noeud */}
