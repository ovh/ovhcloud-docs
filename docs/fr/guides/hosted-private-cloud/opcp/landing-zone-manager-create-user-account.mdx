## Objectif

L'OPCP Cloud Console est le portail du Cloud Store qui permet à chaque équipe, département ou client de déployer et piloter ses workloads en toute autonomie, dans un espace dédié et cloisonné. Les Organization Admins y provisionnent les utilisateurs et leur donnent accès à la plateforme. Chaque organisation s'appuie sur un realm dédié dans l'instance Keycloak sous-jacente, garantissant l'isolation multitenant des accès.

**Ce guide explique comment créer un nouveau compte utilisateur dans l'OPCP Cloud Console et comment s'y connecter pour la première fois.**

## Prérequis

- Disposer d'un accès à l'OPCP Cloud Console avec les privilèges d'Organization Admin, qui permettent la gestion des comptes utilisateurs
- Connaître le mot de passe par défaut de première connexion défini lors du déploiement de votre OPCP Cloud Console
- Disposer de l'URL de l'OPCP Cloud Console (communiquée au préalable par votre administrateur)
- Disposer des informations utilisateur à provisionner (nom complet et adresse e-mail)

## En pratique

### Étape 1 : Accéder à la section de gestion des comptes utilisateurs

Connectez-vous à l'OPCP Cloud Console en tant qu'Organization Admin. Depuis la navigation principale, ouvrez la section <code className="action">Account management</code>.

<img className="thumbnail" alt="Page d'accueil de l'OPCP Cloud Console" src="/images/hosted-private-cloud/opcp/landing-zone-manager-create-user-account/landingzone_homepage.png" loading="lazy" />

### Étape 2 : Créer un nouveau compte utilisateur

Cliquez sur le bouton <code className="action">+ Create new account</code> pour ouvrir le formulaire de création de compte utilisateur.

Renseignez les champs obligatoires suivants :

| Champ      | Description                                                                                               |
| ------------| -----------------------------------------------------------------------------------------------------------|
| Name       | Le nom d'affichage du compte utilisateur                                                                  |
| Email      | L'adresse e-mail de l'utilisateur. Cette valeur sera également utilisée comme identifiant de **connexion** |
| First name | Le prénom de l'utilisateur                                                                                |
| Last name  | Le nom de famille de l'utilisateur                                                                        |

Une fois tous les champs remplis, confirmez la création du compte utilisateur.

<img className="thumbnail" alt="Formulaire de création d'utilisateur" src="/images/hosted-private-cloud/opcp/landing-zone-manager-create-user-account/landingzone_create_user.png" loading="lazy" />

:::info
L'adresse e-mail fournie est utilisée comme identifiant de connexion du nouveau compte utilisateur. Assurez-vous qu'elle est correcte avant de valider, car les utilisateurs s'authentifieront avec cette valeur.
:::

### Étape 3 : Communiquer les identifiants de première connexion

Une fois le compte utilisateur créé avec succès, communiquez l'URL de l'OPCP Cloud Console à l'utilisateur ainsi que ses identifiants de première connexion :

- **Login** : l'adresse e-mail saisie lors de la création
- **Mot de passe** : le mot de passe par défaut de première connexion défini lors du déploiement d'OPCP et du Cloud Store

:::warning
Le mot de passe par défaut est partagé entre toutes les premières connexions et est défini au moment du déploiement. Pour des raisons de sécurité, il sera demandé aux utilisateurs de le changer immédiatement après leur première connexion.
:::

### Étape 4 : Première connexion à l'OPCP Cloud Console

Une fois le compte utilisateur provisionné, l'utilisateur peut se connecter à l'OPCP Cloud Console en utilisant l'URL communiquée précédemment.

<img className="thumbnail" alt="Formulaire de connexion à l'OPCP Cloud Console" src="/images/hosted-private-cloud/opcp/landing-zone-manager-create-user-account/landingzone_loginpage.png" loading="lazy" />

Depuis la page de connexion :

1. Saisissez l'adresse e-mail utilisée lors de la création du compte comme identifiant.
2. Saisissez le mot de passe par défaut de première connexion.
3. Validez pour accéder à l'OPCP Cloud Console.

Lors de cette première connexion, l'utilisateur doit définir un nouveau mot de passe et compléter les étapes d'authentification supplémentaires requises par la plateforme avant d'accéder à l'OPCP Cloud Console.

## Correspondance des organisations dans Keycloak

:::info
L'OPCP Cloud Console repose sur sa **propre stack Keycloak dédiée**, indépendante du Keycloak OPCP Core et du Keycloak de l'OPCP Admin Console. Elle n'est pas fédérée avec ces instances : les identités, realms et identifiants gérés dans l'OPCP Cloud Console sont totalement isolés des autres couches d'identité OPCP dédiées aux administrateurs.
:::

Chaque organisation dispose automatiquement d'un **realm dédié dans Keycloak**, dans lequel l'Organization Admin crée en toute autonomie les comptes utilisateurs de l'organisation. Cette conception garantit :

- une configuration indépendante des flux d'authentification par organisation
- des bases d'utilisateurs et des mappings de rôles séparés par realm

:::info
Comme chaque organisation correspond à un realm Keycloak distinct, toute opération liée à l'identité (ajout d'utilisateurs, configuration de la fédération, définition de rôles) doit être effectuée au sein du realm associé à l'organisation cible.
:::
