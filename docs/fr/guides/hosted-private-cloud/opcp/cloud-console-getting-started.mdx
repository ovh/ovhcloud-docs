## Objectif

**Ce guide présente aux Organization Admins et aux Organization Users comment se connecter à l'OPCP Cloud Console, utiliser les services activés pour leur organisation et créer les comptes utilisateurs de l'organisation.**

L'**OPCP Cloud Console** est l'interface Cloud Store destinée aux organisations. Pour une présentation de Cloud Store et de ses concepts, consultez notre guide « [Premiers pas avec Cloud Store](/guides/hosted-private-cloud/opcp/cloudstore-getting-started) ».

## Prérequis

- Une organisation créée par votre IT Admin, avec au moins un service activé.
- L'**URL** de l'OPCP Cloud Console, votre identifiant (votre adresse e-mail) et le mot de passe par défaut de première connexion, fournis par votre IT Admin ou votre Organization Admin.

## En pratique

### Connexion à l'OPCP Cloud Console

1. Accédez à l'**URL** de l'OPCP Cloud Console. Si l'URL n'inclut pas déjà votre organisation, saisissez le **nom de l'organisation** (`Organization name`) et cliquez sur <code className="action">Submit</code>.

    <img className="thumbnail" alt="Choix de l'organisation" src="/images/hosted-private-cloud/opcp/cloud-console-getting-started/cloud_console_organization.png" loading="lazy" />

2. Vérifiez l'organisation sélectionnée et cliquez sur <code className="action">Log in</code>. Cliquez sur <code className="action">Change organization</code> s'il ne s'agit pas de la bonne.

    <img className="thumbnail" alt="Page de connexion de l'OPCP Cloud Console" src="/images/hosted-private-cloud/opcp/cloud-console-getting-started/cloud_console_login.png" loading="lazy" />

3. Vous êtes redirigé vers le realm Keycloak de votre organisation. Saisissez votre adresse e-mail et votre mot de passe, puis cliquez sur <code className="action">Sign In</code>.

    <img className="thumbnail" alt="Formulaire de connexion du realm de l'organisation" src="/images/hosted-private-cloud/opcp/cloud-console-getting-started/organization_realm_login.png" loading="lazy" />

4. Lors de votre première connexion, définissez un nouveau mot de passe.

:::warning
Le mot de passe par défaut de première connexion est commun et défini au moment du déploiement. Modifiez-le dès votre première connexion.
:::

### Utiliser les services activés

La barre latérale liste les services activés de votre organisation, c'est-à-dire les services que votre IT Admin a activés pour elle.

<img className="thumbnail" alt="Page d'accueil de l'OPCP Cloud Console" src="/images/hosted-private-cloud/opcp/cloud-console-getting-started/cloud_console_home.png" loading="lazy" />

Ouvrez un service pour afficher sa version et ses onglets :

- **Overview** affiche les **Outputs** du service : les informations nécessaires pour vous y connecter avec vos propres outils, par exemple un fichier `openrc.sh` pour la CLI OpenStack et le nom de la région.
- **Onglets du service** : chaque service peut ajouter ses propres onglets pour gérer ses ressources cloud, par exemple `Compute` pour les machines virtuelles ou `Buckets` pour Object Storage.

<img className="thumbnail" alt="Outputs d'un service Compute and Block Storage" src="/images/hosted-private-cloud/opcp/cloud-console-getting-started/cloud_console_compute_overview.png" loading="lazy" />

<img className="thumbnail" alt="Buckets d'un service Object Storage" src="/images/hosted-private-cloud/opcp/cloud-console-getting-started/cloud_console_object_storage.png" loading="lazy" />

### Créer un compte utilisateur

L'Organization Admin crée les comptes utilisateurs de l'organisation dans le **realm Keycloak** de l'organisation. Chaque organisation dispose de son propre realm, isolé des autres organisations : toute opération liée à l'identité (ajout d'utilisateurs, configuration de la fédération, définition de rôles) s'effectue dans le realm de l'organisation cible.

<img className="thumbnail" alt="Utilisateurs du realm d'une organisation" src="/images/hosted-private-cloud/opcp/cloud-console-getting-started/organization_realm_users.png" loading="lazy" />

1. Ouvrez la console d'administration Keycloak de votre organisation et connectez-vous en tant qu'Organization Admin. Votre IT Admin peut vous en communiquer l'URL.
2. Accédez à <code className="action">Users</code> et cliquez sur <code className="action">Add user</code>.
3. Renseignez le nom d'utilisateur, l'e-mail, le prénom et le nom. L'e-mail est l'**identifiant de connexion** de l'utilisateur. Ajoutez l'action requise `Update Password`.
4. Cliquez sur <code className="action">Create</code>.
5. Transmettez à l'utilisateur l'URL de l'OPCP Cloud Console, son e-mail et le mot de passe par défaut de première connexion.

Pour retirer l'accès d'un utilisateur, désactivez son interrupteur `Enabled`.

Depuis ce même realm, l'Organization Admin peut également configurer des groupes d'utilisateurs (<code className="action">Groups</code>), connecter le fournisseur d'identité de l'entreprise (<code className="action">Identity providers</code>) ou un annuaire LDAP / Active Directory (<code className="action">User federation</code>).

:::info
Les services déclarent leurs propres rôles et groupes, que la plateforme crée dans le realm lorsqu'ils sont activés pour l'organisation. Compute and Block Storage et Object Storage ne créent ni groupes ni droits par utilisateur : tous les utilisateurs de l'organisation peuvent les utiliser.
:::

### Correspondance des organisations dans Keycloak

:::info
L'OPCP Cloud Console repose sur sa **propre stack Keycloak dédiée**, indépendante du Keycloak OPCP Core et du Keycloak de l'OPCP Admin Console. Elle n'est pas fédérée avec ces instances : les identités, realms et identifiants gérés pour l'OPCP Cloud Console sont totalement isolés des administrateurs des autres couches d'identité OPCP.
:::

Chaque organisation dispose automatiquement d'un realm dédié, nommé `account-{name}`. Cette conception garantit :

- une configuration indépendante des flux d'authentification par organisation ;
- des bases d'utilisateurs et des mappings de rôles séparés par realm.
