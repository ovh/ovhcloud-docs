## Objectif

Ce guide présente les trois interfaces graphiques que vous utilisez pour gérer un projet **SNC Cloud Platform** :

- le **Global Panel** (`SNC Admin Console`), la console d'administration de l'organisation ;
- le **Regional Panel** (`SNC Cloud Console`), la console opérationnelle d'une région et d'un projet ;
- **Horizon**, le tableau de bord OpenStack natif, pour la gestion détaillée des ressources.

## Prérequis

Pour suivre ce guide, vous avez besoin des éléments suivants :

- l'**ID d'organisation** et les identifiants fournis lors de la livraison du service (nom d'utilisateur ou adresse e-mail, et mot de passe) ;
- un dispositif d'**authentification multifacteur** configuré pour les codes à usage unique ;
- les **URL de gestion** fournies à la livraison.

Si vous avez uniquement besoin d'un accès programmatique, vous pouvez aussi piloter la plateforme avec le **CLI et les API OpenStack** à l'aide d'identifiants d'application (voir la section « [API Access d'Horizon](#api-access) »).

## En pratique

### Les trois interfaces en un coup d'œil

| Interface | Rôle | Usage courant |
|---|---|---|
| **Global Panel** | Console d'administration de l'organisation | Sélectionner l'organisation, gérer les **projets** et les **utilisateurs**, ouvrir le Regional Panel d'un projet |
| **Regional Panel** | Console opérationnelle d'une région et d'un projet | Consulter les services du projet (instances, volumes, réseaux, Object Storage…), ouvrir Horizon, obtenir des identifiants d'application |
| **Horizon** | Tableau de bord OpenStack natif | Gérer en détail les instances, volumes, images, réseaux et l'identité OpenStack, avec la vue complète des quotas |

### Se connecter au Global Panel

#### Sélection de l'organisation

Ouvrez l'URL du Global Panel. À la première connexion, vous êtes invité à identifier votre organisation.

<img className="thumbnail" alt="Sélection de l'organisation dans le Global Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_organisation.png" loading="lazy" />

Saisissez votre **ID d'organisation** et cliquez sur <code className="action">Go to login</code>.

#### Authentification

L'écran suivant est la page d'authentification de la plateforme. Saisissez votre **nom d'utilisateur ou adresse e-mail** et votre **mot de passe**.

<img className="thumbnail" alt="Authentification dans le Global Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_login.png" loading="lazy" />

#### Authentification multifacteur

L'authentification multifacteur est obligatoire : sélectionnez la méthode d'authentification que vous souhaitez utiliser et saisissez le **code à usage unique**.

<img className="thumbnail" alt="Authentification multifacteur dans le Global Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_mfa.png" loading="lazy" />

:::info
Si plusieurs dispositifs d'authentification sont configurés sur votre compte, vérifiez que vous sélectionnez celui qui correspond à votre appareil avant de saisir le code.
:::

Une fois authentifié, vous arrivez sur le tableau de bord du Global Panel.

:::info
Comportement de la session : selon la manière dont la session a été établie, le Global Panel peut revenir à l'écran de sélection de l'organisation après une période d'inactivité. Dans ce cas, sélectionnez de nouveau votre organisation. Le SSO de la plateforme peut alors vous permettre de continuer sans ressaisir vos identifiants.
:::

### Découvrir le Global Panel

Le tableau de bord donne une vue d'ensemble de l'organisation : **projets** et **utilisateurs**.

<img className="thumbnail" alt="Tableau de bord du Global Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_dashboard.png" loading="lazy" />

Depuis le menu de gauche, vous pouvez ouvrir **Project management** et **User management**.

#### Projets

Le menu **Project management** liste les projets de l'organisation. Chaque projet est un environnement isolé, avec ses propres permissions et ses propres quotas.

<img className="thumbnail" alt="Liste des projets du Global Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_projects.png" loading="lazy" />

Ouvrez un projet pour accéder à sa page de détail. Cette page affiche l'**ID du projet** et donne accès à la **console régionale** du projet via le bouton <code className="action">Login</code>.

<img className="thumbnail" alt="Détail d'un projet du Global Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_project_detail.png" loading="lazy" />

#### Utilisateurs

Le menu **User management** liste les utilisateurs de l'organisation. Utilisez le bouton <code className="action">New user</code> pour ouvrir le formulaire de création d'un utilisateur.

<img className="thumbnail" alt="Formulaire de création d'un utilisateur du Global Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_user_create.png" loading="lazy" />

### Découvrir le Regional Panel

Le Regional Panel est la console opérationnelle du projet sélectionné dans une région. Ouvrez-le depuis le bouton <code className="action">Login</code> d'un projet dans le Global Panel, ou directement depuis l'URL régionale.

Le tableau de bord liste les principaux services du projet, ainsi que la section dédiée à l'accès aux API et à la documentation.

<img className="thumbnail" alt="Tableau de bord du Regional Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_dashboard.png" loading="lazy" />

#### Instances

La page **Instances** liste les instances du projet avec leur statut, leur flavor, leurs adresses IP, leurs volumes attachés et leurs réseaux.

<img className="thumbnail" alt="Liste des instances du Regional Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_instances.png" loading="lazy" />

Utilisez <code className="action">Create instance</code> pour créer une instance, ou <code className="action">Open horizon</code> pour les actions avancées.

#### Block Storage

La page **Block Storage** liste les volumes du projet avec leur taille, leur type, l'indicateur bootable, leurs snapshots et l'instance à laquelle ils sont attachés.

<img className="thumbnail" alt="Liste des volumes Block Storage du Regional Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_block_storage.png" loading="lazy" />

#### Private Networks

La page **Private Networks** liste les réseaux du projet, leur plage d'adresses, leur passerelle, l'état du DHCP et les instances attachées.

<img className="thumbnail" alt="Liste des réseaux privés du Regional Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_private_networks.png" loading="lazy" />

:::info
Sur cette plateforme, la connectivité publique est assurée par des **ports directs sur le réseau externe partagé**. Les IP flottantes et les routeurs Neutron ne sont pas disponibles sur un projet standard (les quotas correspondants sont à 0 et Horizon les affiche comme épuisés).
:::

#### Security groups

La page **Security groups** liste les groupes de sécurité du projet et montre comment ils sont reliés aux instances.

<img className="thumbnail" alt="Liste des groupes de sécurité du Regional Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_security_groups.png" loading="lazy" />

#### IP management

La page **IP management** affiche l'état des IP flottantes du projet. Lorsqu'aucune IP flottante n'est allouée, la page affiche l'état *stealth mode*.

<img className="thumbnail" alt="Page IP management du Regional Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_ip_management.png" loading="lazy" />

:::info
Les IP flottantes n'étant pas disponibles sur cette plateforme, l'action <code className="action">Allocate floating IP</code> n'est pas utilisable sur un projet standard. Pour publier un service sur Internet, attachez plutôt un port public à l'instance (voir le [guide de gestion des IP publiques](/guides/hosted-private-cloud/cloud-platform/snc-cloud-platform-public-ip-management)).
:::

#### Object Storage

La page **Object Storage** donne les informations de connexion S3<sup>1</sup> et les clés d'accès du projet.

<img className="thumbnail" alt="Informations de connexion Object Storage du Regional Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_object_storage_connect.png" loading="lazy" />

L'onglet **Access Keys** liste les clés d'accès du projet et permet d'en demander une nouvelle.

<img className="thumbnail" alt="Clés d'accès Object Storage du Regional Panel" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_object_storage_access_keys.png" loading="lazy" />

:::info
Les buckets se gèrent via l'**API/CLI S3**, avec une clé d'accès et son secret. Le Regional Panel ne propose pas, pour le moment, de page dédiée aux buckets.
:::

### Découvrir Horizon

Horizon est le tableau de bord OpenStack natif. Ouvrez-le avec le bouton <code className="action">Open horizon</code> disponible sur les pages du Regional Panel, ou directement depuis l'URL Horizon de votre région.

Le menu latéral de gauche s'organise en deux entrées parentes :

- **Project**, qui rassemble les ressources du projet (*API Access*, *Compute* avec ses pages *Overview*, *Instances*, *Images* et *Key Pairs*, *Volumes*, *Network*) ;
- **Identity**, qui rassemble les ressources d'identité OpenStack (*Projects*, *Users*, *Application Credentials*).

#### API Access

La page **API Access** liste les points d'accès (endpoints) des services OpenStack de la plateforme.

<img className="thumbnail" alt="Accès API d'Horizon" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_api_access.png" loading="lazy" />

Utilisez <code className="action">View Credentials</code> pour afficher le détail de votre session : utilisateur, projet et URL d'authentification.

#### Compute

La section **Compute** rassemble la vue d'ensemble du projet et les ressources servant à exécuter des instances.

##### Overview

La page **Overview** affiche les quotas alloués au projet et leur consommation actuelle.

<img className="thumbnail" alt="Vue d'ensemble d'Horizon" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_overview.png" loading="lazy" />

Elle se compose de deux parties :

- **Limit Summary** : le quota alloué pour chaque type de ressource (Compute, Volume, Network) ;
- **Usage Summary** : l'historique de consommation des ressources sur une période donnée.

##### Instances

La page **Instances** liste les instances avec leur image, leur adresse IP, leur flavor, leur paire de clés, leur statut et les actions disponibles.

<img className="thumbnail" alt="Liste des instances d'Horizon" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_instances.png" loading="lazy" />

Utilisez <code className="action">Launch Instance</code> pour créer une instance, ou les actions de la ligne (par exemple <code className="action">Create Snapshot</code>) pour agir sur une instance existante.

##### Images

La page **Images** liste les images disponibles pour créer des instances. Vous pouvez aussi créer une nouvelle image avec <code className="action">Create Image</code>.

<img className="thumbnail" alt="Liste des images d'Horizon" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_images.png" loading="lazy" />

##### Key Pairs

La page **Key Pairs** permet de gérer les paires de clés SSH utilisées pour se connecter à vos instances.

<img className="thumbnail" alt="Liste des paires de clés d'Horizon" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_key_pairs.png" loading="lazy" />

Utilisez <code className="action">Create Key Pair</code> ou <code className="action">Import Public Key</code> pour enregistrer une clé.

#### Volumes

La section **Volumes** permet de gérer les volumes de stockage bloc du projet.

<img className="thumbnail" alt="Liste des volumes d'Horizon" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_volumes.png" loading="lazy" />

Utilisez <code className="action">Create Volume</code> pour ajouter un volume, ou les actions de la ligne (par exemple <code className="action">Edit Volume</code>) pour agir sur un volume existant.

#### Network

La section **Network** permet de gérer les réseaux du projet.

##### Network Topology

La page **Network Topology** représente les réseaux du projet et les instances qui y sont attachées.

<img className="thumbnail" alt="Topologie réseau d'Horizon" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_network_topology_graph.png" loading="lazy" />

Utilisez les onglets <code className="action">Topology</code> et <code className="action">Graph</code> pour passer de la vue avec libellés à la vue en graphe.

##### Networks

La page **Networks** liste les réseaux du projet, leurs sous-réseaux associés et leur état.

<img className="thumbnail" alt="Liste des réseaux d'Horizon" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_networks.png" loading="lazy" />

:::info
Le réseau externe du projet est partagé et provient de la commande de connectivité publique. Il ne se crée pas depuis Horizon.
:::

#### Identity

La section **Identity** permet de gérer les ressources d'identité OpenStack du projet.

##### Application Credentials

La page **Application Credentials** permet de gérer les identifiants utilisés par le **CLI et les API OpenStack**.

<img className="thumbnail" alt="Identifiants d'application d'Horizon" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_application_credentials.png" loading="lazy" />

Utilisez <code className="action">Create Application Credential</code> pour en créer un, puis téléchargez son fichier `clouds.yaml` depuis la fenêtre de confirmation : le secret n'est affiché qu'une seule fois.
