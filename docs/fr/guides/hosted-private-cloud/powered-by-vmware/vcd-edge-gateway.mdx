## Objectif

Une Edge Gateway est le composant réseau qui connecte votre organisation Public VCF as-a-Service au réseau public. Elle est indispensable pour que vos machines virtuelles puissent accéder à Internet.

**Ce guide vous explique comment configurer votre première Edge Gateway à la livraison de Public VCF as-a-Service, et comment en créer, modifier et supprimer depuis la console OVHcloud.**

:::warning
La gestion des Edge Gateways s'effectue uniquement depuis la console OVHcloud. Cette fonctionnalité n'est pas disponible dans l'interface VMware Cloud Director.
:::

## Prérequis

{/* CP-STEPS-START:prerequis-bloc-ip */}

- Disposer d'une offre **Public VCF as-a-Service Advanced** (la fonctionnalité Edge Gateway n'est pas disponible avec l'offre Standard)
- Disposer d'un bloc IP (IP Space) lié à votre organisation Advanced. Vous pouvez le commander depuis l'onglet <code className="action">Informations générales</code> de votre organisation dans la console OVHcloud : sur la ligne **Nombre d'IP Space**, cliquez sur <code className="action">Commander des IP Space</code>. Un bloc IP ne peut être lié qu'à une seule organisation Advanced (cette fonctionnalité n'est pas disponible pour les organisations Standard)

{/* CP-STEPS-END:prerequis-bloc-ip */}

## En pratique

{/* CP-STEPS-START:acceder-edge-gateway */}

Sélectionnez votre organisation, ouvrez l'onglet <code className="action">Virtual Datacenters</code>, sélectionnez votre **Virtual Datacenter** et cliquez sur l'onglet <code className="action">Edge Gateway</code>. Cet onglet n'est affiché que pour les Virtual Datacenters d'une organisation Advanced (gamme commerciale **NSX**).

{/* CP-STEPS-END:acceder-edge-gateway */}

### Configurer votre première Edge Gateway à la livraison

{/* CP-STEPS-START:configurer-premiere-edge-gateway */}

À la livraison de votre organisation Public VCF as-a-Service, une Edge Gateway est automatiquement créée et associée à votre bloc IP. Elle apparaît dans l'onglet <code className="action">Edge Gateway</code> de votre Virtual Datacenter dans la console OVHcloud.

{/* CP-STEPS-END:configurer-premiere-edge-gateway */}

Cette Edge Gateway est prête, mais pour que vos machines virtuelles puissent accéder au réseau public, vous devez créer une **règle NAT** sur cette Edge Gateway depuis l'interface VMware Cloud Director.

### Configurer une règle NAT sur votre Edge Gateway

Connectez-vous à votre interface **VMware Cloud Director**, puis rendez-vous dans <code className="action">Networking</code> > <code className="action">Edge Gateways</code>. Cliquez sur votre Edge Gateway, puis sur l'onglet <code className="action">NAT</code> et cliquez sur <code className="action">New</code>.

Les deux types de règles les plus courants sont :

<Tabs noSync>
  <Tab label="SNAT — accès Internet sortant">
    Une règle **SNAT (Source NAT)** permet à vos machines virtuelles d'accéder à Internet. Le trafic sortant est traduit de l'adresse IP privée de la VM vers une adresse IP publique de votre bloc IP.

    **Quand l'utiliser ?** Pour permettre à vos VMs d'initier des connexions vers Internet (mises à jour, téléchargements, appels API, etc.).

    Renseignez les champs suivants :

    | Champ | Valeur |
    |---|---|
    | **Name** | Nom de la règle (ex: `snat-vers-internet`) |
    | **Action** | `SNAT` |
    | **Source IP** | Adresse IP ou plage du réseau privé de vos VMs (ex: `192.168.1.0/24`) |
    | **Translated IP** | Adresse IP publique de votre bloc IP |
    | **Port** *(optionnel)* | Port source à traduire (ex: `443`). Si non renseigné, s'applique à tout le trafic |

  </Tab>
  <Tab label="DNAT — accès entrant vers une VM">
    Une règle **DNAT (Destination NAT)** permet à des utilisateurs externes d'accéder à un service hébergé sur l'une de vos machines virtuelles. Le trafic entrant est redirigé depuis une adresse IP publique vers l'adresse IP privée de la VM.

    **Quand l'utiliser ?** Pour exposer un service sur Internet (site web, serveur SSH, application, etc.).

    Renseignez les champs suivants :

    | Champ | Valeur |
    |---|---|
    | **Name** | Nom de la règle (ex: `dnat-serveur-web`) |
    | **Action** | `DNAT` |
    | **Destination IP** | Adresse IP publique de votre bloc IP |
    | **Translated IP** | Adresse IP privée de la VM cible (ex: `192.168.1.10`) |
    | **Port** *(optionnel)* | Port de destination à rediriger vers la VM (ex: `80` pour HTTP, `443` pour HTTPS) |

  </Tab>
</Tabs>

Cliquez sur <code className="action">Save</code> pour appliquer la règle. Elle est active immédiatement.

:::info
Vous pouvez créer plusieurs règles NAT sur une même Edge Gateway et les activer ou désactiver individuellement selon vos besoins.
:::

### Configurer les règles de pare-feu

Par défaut, une règle de pare-feu bloque tout le trafic sur votre Edge Gateway. Vous devez créer des règles d'autorisation pour que le trafic puisse transiter.

Depuis l'interface **VMware Cloud Director**, rendez-vous dans <code className="action">Networking</code> > <code className="action">Edge Gateways</code>. Cliquez sur votre Edge Gateway, puis sur l'onglet <code className="action">Firewall</code> et cliquez sur <code className="action">New</code>.

Renseignez les champs suivants :

| Champ | Description |
|---|---|
| **Name** | Nom de la règle (ex: `allow-outbound`) |
| **Direction** | `IN-OUT` pour autoriser le trafic sortant, `IN` pour entrant uniquement |
| **Source** | IP source ou `Any` pour toutes les origines |
| **Destination** | IP de destination ou `Any` pour toutes les destinations |
| **Service** | Port et protocole concernés (ex: `TCP:443`) ou `Any` pour tout le trafic |
| **Action** | `Allow` pour autoriser, `Drop` pour bloquer |

:::warning
Les règles sont évaluées de haut en bas. Placez vos règles d'autorisation **avant** la règle de blocage par défaut, sinon le trafic sera bloqué avant d'atteindre vos règles.
:::

Cliquez sur <code className="action">Save</code> pour appliquer.

### Créer une nouvelle Edge Gateway

{/* CP-STEPS-START:creer-edge-gateway */}

Vous pouvez créer jusqu'à **5 Edge Gateways** par Virtual Datacenter. Chaque Edge Gateway nécessite un IP Space qui n'est pas encore assigné à une autre Edge Gateway.

Depuis l'onglet <code className="action">Edge Gateway</code>, cliquez sur <code className="action">Ajouter une Edge Gateway</code>.

Dans le panneau **Nouvelle Edge Gateway**, renseignez les informations demandées :

| Champ | Description |
|---|---|
| **Nom de la Edge Gateway** | Nom de votre Edge Gateway (modifiable ultérieurement) |
| **IP Space** | Bloc IP à assigner à cette Edge Gateway (bloc livré avec l'organisation ou commandé en supplément) |

Cliquez sur <code className="action">Créer la Edge Gateway</code> pour valider.

:::info
Dans votre interface VMware Cloud Director, le bloc IP assigné à votre Edge Gateway est visible en tant qu'objet **IP Space**. Un bloc IP ne peut être assigné qu'à une seule Edge Gateway à la fois. La suppression d'un IP Space dans l'interface VCD ne détache pas le bloc IP de votre organisation dans la console OVHcloud. Pour associer les IP Space de votre organisation à un autre service, contactez le support OVHcloud : cette action n'est pas encore disponible dans la console OVHcloud.
:::

{/* CP-STEPS-END:creer-edge-gateway */}

### Modifier une Edge Gateway

{/* CP-STEPS-START:modifier-edge-gateway */}

Vous pouvez modifier le nom et le bloc IP (IP Space) assigné à une Edge Gateway existante.

Depuis l'onglet <code className="action">Edge Gateway</code>, ouvrez le menu ⋮ (colonne **Actions**) de l'Edge Gateway concernée, puis :

- pour modifier son nom, cliquez sur <code className="action">Modifier le nom</code>, saisissez le nouveau **Nom de la Edge Gateway** et cliquez sur <code className="action">Modifier</code> pour confirmer ;
- pour modifier son bloc IP, cliquez sur <code className="action">Modifier l'IP Space</code>, sélectionnez le nouvel **IP Space** et cliquez sur <code className="action">Modifier</code> pour confirmer.

:::warning
Changer le bloc IP assigné à une Edge Gateway peut interrompre temporairement la connectivité réseau des machines virtuelles qui l'utilisent.
:::

{/* CP-STEPS-END:modifier-edge-gateway */}

### Supprimer une Edge Gateway

{/* CP-STEPS-START:supprimer-edge-gateway */}

Depuis l'onglet <code className="action">Edge Gateway</code>, ouvrez le menu ⋮ (colonne **Actions**) de l'Edge Gateway à supprimer, puis cliquez sur <code className="action">Supprimer</code>. Dans la fenêtre **Supprimer la Edge Gateway**, confirmez avec <code className="action">Supprimer</code>.

:::warning
La suppression d'une Edge Gateway est irréversible : tous ses services réseau et ses configurations sont définitivement supprimés. Toutes les machines virtuelles connectées via cette Edge Gateway perdront immédiatement leur accès au réseau public.
:::

{/* CP-STEPS-END:supprimer-edge-gateway */}
