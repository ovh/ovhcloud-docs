## Objectif

Le vRack, c’est la possibilité de connecter différents services cloud de OVHcloud entre eux, au sein d’un ou plusieurs réseaux privés sécurisés (VLAN).

**Ce guide explique comment mettre en place cette solution**

## Prérequis

- Avoir un service [vRack](/links/network/vrack) dans votre compte ou en commander un si besoin
- Être contact administrateur de l'[infrastructure Hosted Private Cloud](/links/hosted-private-cloud/enterprise), pour recevoir des identifiants de connexion
- Avoir un identifiant utilisateur actif (créé dans la <ManagerLink console to="/">console OVHcloud</ManagerLink>)

[[cpnav:network-vrack-console]]

## En pratique

### Console OVHcloud

{/* CP-STEPS-START:espace-client */}

Lors de la livraison de votre service [Hosted Private Cloud](/links/hosted-private-cloud/enterprise), la partie *datacenter* est déjà à l'intérieur d'un vRack. Pour visualiser le contenu dans la console OVHcloud, rendez-vous dans **Réseau** › <code className="action">vRack</code>, sélectionnez votre vRack dans la liste, puis ouvrez l'onglet <code className="action">Services rattachés</code>.

Il est possible de déplacer le *datacenter* de votre Hosted Private Cloud dans un autre vRack : sur sa ligne **Private Cloud Datacenter**, cliquez sur <code className="action">Déplacer</code>. Dans la fenêtre **Déplacement d'un datacentre Private Cloud**, sélectionnez le **vRack de destination**, puis cliquez sur <code className="action">Déplacer</code>. Cette opération entraîne une interruption de service d'environ 5 minutes.

{/* CP-STEPS-END:espace-client */}

### Client vSphere

Dans le client vSphere, vous pouvez retrouver les *VLANs* compatibles vRack dans le switch virtuel distribué (vds), lui-même situé dans le dossier **vrack**.

:::tip
Par défaut, OVHcloud vous livre une infrastructure avec 11 VLANs (VLAN10 à VLAN20).

:::


<img className="thumbnail" alt="vlan" src="/images/hosted-private-cloud/powered-by-vmware/using-private-cloud-in-vrack/vRackVsphere.png" loading="lazy" />

Il est possible de modifier leurs paramètres, ou d'en créer de nouveau en suivant le guide de [création de VLAN](/guides/hosted-private-cloud/powered-by-vmware/create-vlan).

Vous pourrez ensuite assigner ces *portgroup* sur les interfaces réseaux de vos machines virtuelles.
