## Objectif

L'accès à votre vCenter est restreint uniquement aux adresses IP autorisées.

**Découvrez comment autoriser des adresses IP à se connecter au vCenter.**

## Prérequis

- Être connecté à la <ManagerLink console to="/">console OVHcloud</ManagerLink>.
- Posséder une [infrastructure Private Cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/) sur votre compte OVHcloud.

[[cpnav:privatecloud-vmware-vsphere-console]]

## En pratique

Par défaut, l'accès à votre vCenter est restreint. Il est donc nécessaire d'ajouter les IPs qui seront autorisées à se connecter au service.

{/* CP-STEPS-START:autoriser-ip */}

Sélectionnez votre service dans la liste en cliquant sur son nom, puis cliquez sur l'onglet <code className="action">Contrôle d'accès</code>.

Dans la partie qui liste les IP et blocs autorisés à se connecter, cliquez sur <code className="action">Associer un bloc IP</code>.

Dans la fenêtre **Ajouter une règle de sécurité**, ajoutez l'IP concernée, ou cliquez sur <code className="action">Utiliser mon adresse IP actuelle</code> pour renseigner l'adresse depuis laquelle vous êtes connecté. Ajoutez éventuellement une description pour la retrouver plus facilement dans la liste ultérieurement.

Cliquez sur <code className="action">Suivant</code>, puis validez cet ajout en cliquant sur <code className="action">Confirmer</code>. Une fois que l'IP est bien marquée comme « **Autorisé et configuré** » dans la colonne **Droit**, la connexion au vSphere sera possible depuis l'adresse IP en question.

{/* CP-STEPS-END:autoriser-ip */}

:::info
Veuillez noter que, pour des raisons de sécurité, vous ne pourrez autoriser qu'un maximum de 2048 adresses IP à se connecter à votre vCenter.

:::
