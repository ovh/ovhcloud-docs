## Objectif

**Ce guide vous détaille comment activer IAM avec Hosted Private Cloud - VMware on OVHcloud via la console OVHcloud ou par le biais de l'API OVHcloud**.

## Prérequis

- Disposer d'un [compte OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation)
- Avoir un ou plusieurs produits Hosted Private Cloud - VMware on OVHcloud liés à ce compte (Hosted Private Cloud powered by VMware, Service Pack VMware).

[[cpnav:privatecloud-vmware-vsphere-console]]

## En pratique

### Activer IAM

:::info
Cette opération peut prendre jusqu’à 30 minutes.

:::


### Via la console OVHcloud

Sélectionnez votre infrastructure puis rendez-vous dans l'onglet <code className="action">Utilisateurs</code>.

Dans la section **OVHcloud IAM** en bas de l'onglet, cliquez sur <code className="action">Activer OVHcloud IAM</code>.

<img className="thumbnail" alt="Section OVHcloud IAM avec le statut Désactivé et le lien Activer OVHcloud IAM" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_2.png" loading="lazy" />

:::warning
Seul le produit vSphere est intégré à OVHcloud IAM. Une infrastructure disposant d'options de sécurité renforcée ou d'un service certifié (HDS, PCI-DSS ou SNC) ne peut actuellement pas utiliser OVHcloud IAM. Si vous activez ultérieurement l'une de ces options ou l'un de ces services certifiés, vous devrez désactiver OVHcloud IAM.
:::

Dans la fenêtre **Activer l'IAM OVHcloud** qui s'ouvre, cliquez sur <code className="action">Confirmer</code>.

:::tip
Une fois IAM activé, son statut sera `Activé` et affiché en vert.

:::

<img className="thumbnail" alt="Onglet Utilisateurs avec la section OVHcloud IAM affichant le statut Activé" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_3.png" loading="lazy" />

### Via l'API OVHcloud

:::tip
Consultez le guide [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps) pour vous familiariser avec l'utilisation des APIv6 OVHcloud.

:::


:::warning
Veillez à remplacer le `serviceName` par la référence de votre service PCC, sous la forme `pcc-XXX-XXX-XXX-XXX`.

:::


Pour activer l'option IAM, exécutez l'appel API suivant :

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/enable"} />


#### Pour vérifier si IAM est activé

Pour contrôler l'activation d'IAM, exécutez l'appel API suivant :

<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\{serviceName\}/iam"} />

Retour de l'API :

```shell
{
  "state": "enabled",
  "identityProviderId": 275
}
```

### Désactiver IAM

Vous pouvez désactiver OVHcloud IAM sur votre Hosted Private Cloud.

#### Via la console OVHcloud

Sélectionnez votre infrastructure puis rendez-vous dans l'onglet <code className="action">Utilisateurs</code>.

Dans la section **OVHcloud IAM** en bas de l'onglet, cliquez sur <code className="action">Désactiver OVHcloud IAM</code>. Dans la fenêtre **Désactiver l'IAM OVHcloud** qui s'ouvre, cliquez sur <code className="action">Confirmer</code>.

#### Via l'API OVHcloud

Pour désactiver l'option IAM, exécutez l'appel API suivant :

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/disable"} />
