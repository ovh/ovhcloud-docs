## Objectif

Ce guide explique comment configurer des tâches de sauvegarde chiffrées en utilisant la solution de sauvegarde Veeam et le service KMS d’OVHcloud (OKMS).

## Prérequis

- Être connecté à la <ManagerLink console to="/">console OVHcloud</ManagerLink>.
- Disposer d'une offre [VMware on OVHcloud](/links/hosted-private-cloud/vmware).
- Avoir lu les guides : 
    - [Intégration d'un KMS pour VMware on OVHcloud](/guides/hosted-private-cloud/powered-by-vmware/vmware-overall-vm-encrypt).
    - [Premiers pas avec OKMS](/guides/manage-and-operate/kms/quick-start).

[[cpnav:security-kms-console]]

## En pratique

### Étape 1 : Créer un certificat dans OKMS

Vous pouvez créer votre certificat d’accès dans OKMS en utilisant soit l’<ApiLink>API OVHcloud</ApiLink>, soit la <ManagerLink console to="/">console OVHcloud</ManagerLink>.

#### Option 1 : Utiliser l’API

1. Générez la clé privée avec l’API (sans CSR) :

    <Api version="v2" section="/okms" method="POST" route={"/okms/resource/\\{okmsId\\}/credential"} />

2. Récupérez le certificat avec une requête GET :

    <Api version="v2" section="/okms" method="GET" route={"/okms/resource/\\{okmsId\\}/credential"} />

    {/* CP-STEPS-START:equivalence-espace-client */}

    :::info
    Cette méthode est équivalente au choix de l'option **Je n'ai pas de clé privée** dans la console OVHcloud.
    Vous pouvez également soumettre un CSR si vous avez déjà votre propre clé privée.

    :::

    {/* CP-STEPS-END:equivalence-espace-client */}

3. Téléchargez la clé privée.

4. Téléchargez le certificat.

    :::info
    La clé privée téléchargée est utilisée pour générer le fichier `.pfx` à l’étape suivante.
    Vous n’avez pas besoin de l’importer manuellement dans Veeam, mais elle est requise pour convertir le certificat dans un format compatible.
    Veillez à la conserver en lieu sûr.

    :::

#### Option 2 : Utiliser la <ManagerLink console to="/">console OVHcloud</ManagerLink>

{/* CP-STEPS-START:utiliser-espace-client */}

1. Dans la console OVHcloud, rendez-vous dans **Sécurité** › **Key & Secret Manager**. La page s'ouvre sur votre dernier domaine OKMS.

2. Sélectionnez votre KMS : si nécessaire, choisissez-le dans le sélecteur **Domaine OKMS** en haut de la page.

3. Ouvrez l'onglet <code className="action">Certificats d'accès</code>.

4. Cliquez sur <code className="action">Créer un certificat d'accès</code>.

5. Renseignez les champs de la section **Informations générales** (**Nom d'affichage**, **Description**) et la **Validité** du certificat (1 mois par défaut), puis, sous **Méthode de création**, sélectionnez **Je n'ai pas de clé privée**.

    :::info
    Cela revient à générer un certificat sans CSR, comme avec l'API.
    Vous pouvez également choisir **J'ai déjà une clé privée** pour générer un certificat à partir de votre propre CSR.

    :::

6. Ajoutez des identités au certificat, dans la section **Ajouter des identités** de la même page :
    - Sélectionnez **Choisir des identités**
    - Cochez les utilisateurs autorisés dans les onglets **Utilisateurs**, **Groupes d'utilisateurs** ou **Comptes de service**
    - Cliquez sur <code className="action">Créer</code> pour créer le certificat avec ces identités

    :::info
    Cette étape est indispensable pour que le certificat fonctionne avec Veeam.

    :::

7. Téléchargez la clé privée et le certificat : sur la page affichée après la création, cliquez sur <code className="action">Télécharger la clé privée</code>, cochez **Je confirme avoir téléchargé la clé privée**, puis cliquez sur <code className="action">Terminer</code>.

    Le certificat peut être téléchargé à tout moment depuis sa ligne dans l'onglet **Certificats d'accès**, avec l'action **Télécharger le certificat**.

{/* CP-STEPS-END:utiliser-espace-client */}

### Étape 2 : Conversion du certificat PEM au format PFX

Pour importer le certificat dans Veeam, vous devez le convertir au format `.pfx` en utilisant la commande suivante :

```bash
openssl pkcs12 -export -out cert.pfx -inkey privatekey.pem -in certificate.pem
```

### Étape 3 : Importation du certificat dans le Windows Certificate Store de Veeam

- Ouvrez le Windows Certificate Store sur votre serveur Veeam.
- Importez le fichier `.pfx` généré à l’étape précédente.
- Cochez l’option permettant de rendre le certificat exportable.

<img className="thumbnail" alt="Import Certificate - Exportable" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_4.png" loading="lazy" />

### Étape 4 : Enregistrement du KMS dans Veeam

- Ouvrez Veeam Backup & Replication et allez dans <code className="action">Credentials & Passwords</code>, puis cliquez sur <code className="action">Key Management Servers</code>.

<img className="thumbnail" alt="Veeam Key Management Servers" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_5.png" loading="lazy" />

- Cliquez sur <code className="action">Add</code> pour ajouter un nouveau serveur KMS.

<img className="thumbnail" alt="Add KMS Server" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_6.png" loading="lazy" />

- Saisissez les informations suivantes :
    - Adresse du serveur : `eu-west-rbx.okms.ovh.net`
    - Port : `5696`
    - Certificat serveur : `*.okms.ovh.net`
    - Certificat client : le fichier `.pfx` que vous venez d'importer

<img className="thumbnail" alt="Add KMS Server Details" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_7.png" loading="lazy" />

### Étape 5 : Récupération du certificat serveur

Pour récupérer le certificat depuis le serveur OKMS, utilisez la commande suivante :

```bash
openssl s_client -connect eu-west-rbx.okms.ovh.net:443 2>/dev/null </dev/null |  sed -ne '/-BEGIN CERTIFICATE-/,/-END CERTIFICATE-/p'
```

### Étape 6 : Configuration du chiffrement des tâches de sauvegarde

- Enregistrez le serveur KMS dans votre console Veeam Backup & Replication.
- Sélectionnez la tâche de sauvegarde souhaitée, puis configurez le chiffrement avec le KMS enregistré.

<img className="thumbnail" alt="Configure Backup Encryption" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_8.png" loading="lazy" />

- Une fois la sauvegarde exécutée, une icône de cadenas s'affiche à côté de son nom.

<img className="thumbnail" alt="Encrypted Backup" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_9.png" loading="lazy" />

- En cas d’erreur `Unsupported attribute: OPERATION_POLICY_NAME`, consultez la documentation ou contactez le support.

<img className="thumbnail" alt="Operation Policy Name Error" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_10.png" loading="lazy" />
