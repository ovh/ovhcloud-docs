## Objectif

OVHcloud propose une option de migration reposant sur **VMware Cloud Director Availability (VCDA)** pour déplacer vos machines virtuelles vers une organisation Public VCF as-a-Service.

**Ce guide vous explique comment activer cette option depuis la console OVHcloud, puis où gérer les adresses IP autorisées après activation.**

## Prérequis

- Disposer d'une organisation [Public VCF as-a-Service](/links/hosted-private-cloud/vmware-vcd) active.
- Disposer de l'adresse IP publique (CIDR `/32`) du serveur qui héberge votre appliance VCDA on-premises.

:::info
L'IP saisie à l'activation sert à autoriser votre environnement source à communiquer avec le service VCDA OVHcloud.
:::

[[cpnav:privatecloud-vmware-vcf-console]]

## En pratique

### Étape 1 : Ouvrir le service Public VCF as-a-Service

{/* CP-STEPS-START:ouvrir-service-public-vcf */}

La page Public VCF as-a-Service liste vos organisations. Sélectionnez l'organisation sur laquelle vous souhaitez activer la migration.

{/* CP-STEPS-END:ouvrir-service-public-vcf */}

### Étape 2 : Démarrer l'activation

{/* CP-STEPS-START:demarrer-activation */}

Une fois dans l'organisation, l'onglet **Informations générales** s'affiche. Dans sa section **Migration VCDA**, cliquez sur <code className="action">Commander</code>.

{/* CP-STEPS-END:demarrer-activation */}

### Étape 3 : Renseigner le formulaire de première activation

{/* CP-STEPS-START:formulaire-premiere-activation */}

Sur la page **VCDA managé pour Public VCF**, dans la section **Saisissez les informations de votre infrastructure**, saisissez l'adresse IP publique de votre serveur source au format CIDR `/32` dans le champ **Votre IP publique**, puis cliquez sur <code className="action">Commander</code> dans le **Récapitulatif**.

À l'étape **Confirmez votre commande**, acceptez les contrats, puis cliquez sur <code className="action">Confirmer et payer</code>. Cette opération active l'option de migration VCDA pour l'organisation et ajoute cette IP à la liste autorisée.

:::warning
Assurez-vous d'indiquer l'IP publique sortante réellement utilisée par votre appliance VCDA on-premises. Une IP incorrecte empêchera l'appairage avec le service cloud.
:::

Après validation, un e-mail de confirmation vous est envoyé, avec toutes les informations nécessaires pour appairer votre VCDA avec le service VCDA d'OVHcloud.

{/* CP-STEPS-END:formulaire-premiere-activation */}

### Étape 4 : Utiliser l'onglet Migration après activation

{/* CP-STEPS-START:onglet-migration */}

Une fois l'option activée, un onglet <code className="action">Migration</code> apparaît dans l'interface de l'organisation.

Dans cet onglet, la section **IP VCDA pour Public VCFaaS** affiche l'IP du service VCDA déployé sur votre organisation (utile pour ouvrir les flux côté source si nécessaire).

{/* CP-STEPS-END:onglet-migration */}
