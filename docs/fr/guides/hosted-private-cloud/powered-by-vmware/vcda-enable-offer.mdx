## Objectif

OVHcloud propose une option de migration reposant sur **VMware Cloud Director Availability (VCDA)** pour déplacer vos machines virtuelles vers une organisation Public VCF as-a-Service.

**Ce guide vous explique comment activer cette option depuis votre espace client OVHcloud, puis où gérer les adresses IP autorisées après activation.**

## Prérequis

- Disposer d'une organisation [Public VCF as-a-Service](/links/hosted-private-cloud/vmware-vcd) active.
- Avoir accès à <ManagerLink to="/">l'espace client OVHcloud</ManagerLink> avec des droits administrateur sur l'organisation.
- Disposer de l'adresse IP publique (CIDR `/32`) du serveur qui héberge votre appliance VCDA on-premises.

:::info
L'IP saisie à l'activation sert à autoriser votre environnement source à communiquer avec le service VCDA OVHcloud.
:::

{/* CP-NAV-START:privatecloud-vmware-vcf */}
---

### Accès à l'espace client OVHcloud

- **Lien direct :** <ManagerLink to="/#/vmware/public-vcf-aas">VMware Cloud Foundation</ManagerLink>
- **Pour accéder à vos services :** <code className="action">Hosted Private Cloud</code> > <code className="action">Public VCF as-a-Service</code> > Sélectionnez votre service VCF

## En pratique

### Étape 1 : Ouvrir le service Public VCF as-a-Service

La page d'accueil affiche la liste de vos organisations. Sélectionnez l'organisation sur laquelle vous souhaitez activer la migration.

<img className="thumbnail" alt="Page Public VCF as-a-Service avec la liste des organisations" src="/images/hosted-private-cloud/powered-by-vmware/vcda-enable-offer/01-landing-public-vcf.png" loading="lazy" />

### Étape 2 : Démarrer l'activation

Une fois dans l'organisation, ouvrez le tableau de bord et cliquez sur le bouton <code className="action">Commander</code> dans le bloc **Migration**.

<img className="thumbnail" alt="Bloc Migration avant activation avec le bouton Commander" src="/images/hosted-private-cloud/powered-by-vmware/vcda-enable-offer/02-enable-vcda-button.png" loading="lazy" />

### Étape 3 : Renseigner le formulaire de première activation

Dans le formulaire d'activation, saisissez l'adresse IP publique de votre serveur source au format CIDR `/32`, puis cliquez sur <code className="action">Commander</code>.

Cette opération active l'option de migration VCDA pour l'organisation et ajoute cette IP à la liste autorisée.

<img className="thumbnail" alt="Formulaire d'activation VCDA avec champ IP publique" src="/images/hosted-private-cloud/powered-by-vmware/vcda-enable-offer/03-first-activation-form.png" loading="lazy" />

:::warning
Assurez-vous d'indiquer l'IP publique sortante réellement utilisée par votre appliance VCDA on-premises. Une IP incorrecte empêchera l'appairage avec le service cloud.
:::

Après validation, un e-mail de confirmation vous est envoyé.

### Étape 4 : Utiliser l'onglet Migration après activation

Une fois l'option activée, un onglet <code className="action">Migration</code> apparaît dans l'interface de l'organisation.

Dans cet onglet, vous pouvez :

- ajouter d'autres IP de service à autoriser pour l'accès à l'infrastructure OVHcloud ;
- consulter l'IP du service VCDA déployé sur votre organisation (utile pour ouvrir les flux côté source si nécessaire).

<img className="thumbnail" alt="Nouvel onglet Migration après activation de VCDA" src="/images/hosted-private-cloud/powered-by-vmware/vcda-enable-offer/04-migration-tab.png" loading="lazy" />
