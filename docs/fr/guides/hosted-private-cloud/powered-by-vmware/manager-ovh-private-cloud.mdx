## Objectif

La console OVHcloud vous propose de nombreuses options de paramétrage de votre infrastructure Hosted Private Cloud.

**Ce guide vous explique les multiples options possibles.**

## Prérequis

- Une [Infrastrucure Hosted Private Cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/)

[[cpnav:privatecloud-vmware-vsphere-console]]

## En pratique

### Vue Hosted Private Cloud

{/* CP-STEPS-START:vue-hosted-private-cloud */}

Avec un compte administrateur, rendez-vous dans **Private Cloud** › **Managed VMware vSphere** dans la console OVHcloud et sélectionnez votre service dans la liste en cliquant sur son nom. La page du service s'ouvre sur l'onglet **Tableau de bord** ; les autres onglets sont **Datacenter**, **Utilisateurs**, **Contrôle d'accès**, **Chiffrement**, **Opérations** et **Logs**.

Le titre de la page affiche la description de votre infrastructure. Vous pouvez la modifier en cliquant sur l'icône en forme de crayon à côté du titre, en saisissant la nouvelle description puis en validant avec l'icône ✓. Le nom du service, lui, n'est pas modifiable.

{/* CP-STEPS-END:vue-hosted-private-cloud */}

#### Tableau de bord

{/* CP-STEPS-START:informations-generales */}

L'onglet **Tableau de bord** donne le résumé de votre service Hosted Private Cloud, réparti en quatre sections.

La section **Informations générales** présente :

- La **Description**, modifiable via l'icône en forme de crayon située à côté
- La **Solution logicielle**, qui vous donne la version vCSA installée
- La **Zone Private Cloud** et la **Région**, qui indiquent la localisation de votre Hosted Private Cloud
- Le **Nombre de datacenters** de votre infrastructure
- Des liens vers les interfaces de gestion : <code className="action">Ouvrir vScope</code> et <code className="action">Ouvrir l'interface web</code> (client vSphere)

La section **Options** liste les options activées et désactivées (Zerto, vRealize Operations (vROps), NSX-T, Logs, Licence Windows (SPLA)). L'action située sur la ligne de chaque option vous permet de la modifier (par exemple <code className="action">Activer</code>, <code className="action">Modifier les options</code> ou <code className="action">Désactiver</code>). La section affiche également le **Nombre de blocs IP** qui vous sont assignés : pour en ajouter, ouvrez le menu ⋮ situé à côté puis cliquez sur <code className="action">Commander des blocs IP</code>.

La section **Conformité** indique la conformité sectorielle de votre service. Cliquez sur <code className="action">Activer la conformité sectorielle</code> pour activer une certification (HDS ou PCI DSS).

La section **Abonnement** vous permet de vous abonner à la liste de diffusion e-mail Hosted Private Cloud OVHcloud (**Mailing list**, <code className="action">S'inscrire à la mailing list</code>). Elle affiche la date de création et la date de **Renouvellement automatique** de votre service, et permet de résilier le service via le lien <code className="action">Résilier le service</code>.

La politique d'accès de votre infrastructure (`Ouvert` ou `Restreint`) est affichée dans l'onglet **Contrôle d'accès**, sous **Politique d'accès vCenter** (voir plus bas).

{/* CP-STEPS-END:informations-generales */}

#### Datacentres

{/* CP-STEPS-START:datacentres */}

L'onglet **Datacenter** montre vos datacentres virtuels existants, avec leur gamme, leurs ressources et leur nombre de machines virtuelles, et permet d'en ajouter via le bouton <code className="action">Commander un datacentre</code>. Le menu ⋮ (colonne **Actions**) d'un datacentre permet aussi de lui commander un hôte ou un datastore.

Cliquez sur le nom d'un datacentre pour ouvrir la vue Datacentre (voir plus bas), qui donne tous les détails et options.

{/* CP-STEPS-END:datacentres */}

#### Utilisateurs

{/* CP-STEPS-START:utilisateurs */}

L'onglet **Utilisateurs** liste tous les comptes qui peuvent se connecter à vSphere et permet la création de nouveaux comptes via le bouton <code className="action">Créer un utilisateur</code>.

Le menu ⋮ (colonne **Actions**) d'un utilisateur propose les actions suivantes :

- <code className="action">Éditer</code> : modifier les champs du résumé (informations et permissions de l'utilisateur)
- <code className="action">Voir/Modifier les droits par DC</code> : voir / modifier les droits utilisateur par datacentre
- <code className="action">Changer le mot de passe</code> : changer le mot de passe utilisateur
- <code className="action">Supprimer cet utilisateur</code> : supprimer l'utilisateur

Cliquez sur <code className="action">Voir/Modifier les droits par DC</code> pour ouvrir la page de gestion des droits, qui comporte une ligne par datacentre.

Ouvrez le menu ⋮ (colonne **Actions**) d'un datacentre puis cliquez sur <code className="action">Modifier les droits</code> pour les modifier dans la fenêtre **Edition des droits**.

- **Accès vSphere** : il s'agit des droits globaux de l'utilisateur sur le vSphere :

|Droits|Description|
|---|---|
|Aucun|aucun accès|
|Lecture seule|accès en lecture seule|
|Lecture/Écriture|accès en lecture et écriture|
|Opérateur|accès réservé aux administrateurs OVHcloud|

- **Accès au VM Network** : il s'agit de la gestion des droits sur la partie réseau public (appelée `VM Network` dans l'interface vSphere) :

|Droits|Description|
|---|---|
|Aucun|aucun accès|
|Lecture seule|accès en lecture seule|
|Opérateur|permet de configurer des machines virtuelles (VM) sur le réseau public|

- **Accès aux V(x)Lans / GENEVE** : il s'agit de la gestion des droits sur la partie réseau privé (les VXLAN pour la gamme Dedicated Cloud, les VLAN pour la gamme SDDC et les packs Hosted Private Cloud Premier) :

|Droits|Description|
|---|---|
|Aucun|aucun accès|
|Lecture seule|accès en lecture seule|
|Opérateur|permet de configurer des machines virtuelles (VM) sur le réseau privé|
|Administrateur|permet de gérer les port groups du switch virtuel (en créer, modifier, supprimer...), pour les SDDC et les packs Hosted Private Cloud Premier uniquement|

- **Gestion des hôtes et des stockages** : cette case permet d'accorder ou non le droit d'ajouter ou de supprimer des hôtes et du stockage via le plugin OVHcloud dans le client vSphere.

{/* CP-STEPS-END:utilisateurs */}

#### Contrôle d'accès et chiffrement

{/* CP-STEPS-START:securite */}

La politique d'accès à votre vCenter et les autres paramètres de sécurité sont répartis entre deux onglets, **Contrôle d'accès** et **Chiffrement**.

L'onglet **Contrôle d'accès** affiche, dans sa section **Paramètres de session**, la « Politique d'accès vCenter » de votre infrastructure (`Ouvert` ou `Restreint`). Cette politique est affichée à titre d'information : pour la modifier, contactez le support OVHcloud. Vous pouvez paramétrer les autres options de session (« Délai d'expiration de session », « Nombre de connexions simultanées » et « Politique de déconnexion ») à l'aide du bouton <code className="action">Modifier</code> situé sur leur ligne. En dessous, la liste des IP et blocs autorisés à se connecter vous permet d'en ajouter via le bouton <code className="action">Associer un bloc IP</code>.

:::warning
Si la politique d'accès est en mode restreint et qu'aucune IP n'est autorisée, aucun utilisateur ne pourra se connecter au client vSphere. Les machines virtuelles resteront toutefois accessibles.

:::

Dans l'onglet **Chiffrement**, vous pouvez aussi ajouter un Key Management Server (<code className="action">Associer un serveur KMS</code>) ou consulter les serveurs existants.

Consultez le guide « [Activation du chiffrement des machines virtuelles](/guides/hosted-private-cloud/powered-by-vmware/vm-encrypt) » pour plus de détails.

{/* CP-STEPS-END:securite */}

#### Opérations

{/* CP-STEPS-START:operations */}

L'onglet **Opérations** montre le journal de toutes les tâches exécutées sur votre infrastructure.

Par défaut, la liste affiche les tâches en cours : vous pouvez la filtrer par état (tous les états, en cours, terminées ou annulées) et afficher d'autres colonnes via le bouton <code className="action">Colonnes</code>. Si la date de traitement d'une tâche est modifiable, son menu ⋮ (colonne **Actions**) propose <code className="action">Modifier la date de traitement</code>.

:::info
Si votre accès au client vSphere n'est pas possible, une maintenance peut être en cours. Cet onglet vous permet de le vérifier.

:::

{/* CP-STEPS-END:operations */}

#### Licence Windows

{/* CP-STEPS-START:licence-windows */}

Le statut de votre licence Windows SPLA est affiché sur la ligne « Licence Windows (SPLA) » de la section **Options**, dans l'onglet **Tableau de bord**. Si l'option est désactivée, vous pouvez la commander via le bouton <code className="action">Activer le SPLA</code>. Les licences s'activent ensuite machine virtuelle par machine virtuelle, depuis l'onglet **Machines virtuelles** d'un datacentre (menu ⋮ de la VM, <code className="action">Activer la licence</code>). L'onglet **Datacenter** indique, pour chaque datacentre, le nombre de VM Windows et de VM Windows sous licence.

Consultez la page des [tarifs](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/images-licenses/).

{/* CP-STEPS-END:licence-windows */}

### Vue Datacentre

{/* CP-STEPS-START:vue-datacentre */}

Un Hosted Private Cloud peut inclure plusieurs datacentres virtuels.

L'onglet **Datacenter** de votre service les liste tous. Cliquez sur le nom de l'un d'entre eux pour ouvrir son interface de gestion.

Le nom du datacentre est modifiable en cliquant sur l'icône en forme de crayon située à côté, en haut de la page ; sa description se modifie depuis la section **Informations générales** de son onglet **Tableau de bord** (voir ci-dessous).

{/* CP-STEPS-END:vue-datacentre */}

#### Tableau de bord du datacentre

{/* CP-STEPS-START:datacentre-informations-generales */}

L'onglet **Tableau de bord** du datacentre donne un aperçu du datacentre. Sa section **Informations générales** présente :

- Les champs « Nom » et « Description », modifiables via l'icône en forme de crayon située à côté de chacun
- La « Gamme commerciale », qui montre les services VMware souscrits
- Les champs « Hôtes » et « Datastores », qui vous donnent les quantités d'hôtes et de datastores du datacentre, avec les boutons <code className="action">Commander un host</code> et <code className="action">Commander un datastore</code>
- Des liens qui vous redirigent vers les interfaces de gestion : <code className="action">Aller sur vScope</code> et <code className="action">Interface web</code>

La section **Caractéristiques** détaille les ressources du datacentre (CPU, RAM, espace disque) et son nombre de machines virtuelles.

Le statut de sauvegarde de vos machines virtuelles figure dans la colonne **Sauvegarde** de l'onglet **Machines virtuelles**, et le statut de votre solution de PRA sur la ligne **Zerto** de la section **Options**.

{/* CP-STEPS-END:datacentre-informations-generales */}

#### Hôtes

{/* CP-STEPS-START:hosts */}

L'onglet **Hôtes** vous montre un résumé de vos hôtes présents sur le datacentre sélectionné.

*Si votre hôte est en facturation à l'heure, vous pouvez le passer en facturation mensuelle : ouvrez son menu ⋮ (colonne **Actions**) puis cliquez sur <code className="action">Changer en facturation mensuelle</code>.*

Vous pouvez également ajouter un nouvel hôte via le bouton <code className="action">Commander un hôte</code>.

{/* CP-STEPS-END:hosts */}

#### Datastores

{/* CP-STEPS-START:datastores */}

L'onglet **Datastores** vous montre un résumé des datastores présents sur le datacentre sélectionné ; la colonne **Portée** indique si chacun est global.

*Vous pouvez convertir un datastore en global via son menu ⋮ (colonne **Actions**) › <code className="action">Convertir le datastore en global</code>. Le même menu propose <code className="action">Changer en facturation mensuelle</code>.*

Vous pouvez également ajouter un nouveau datastore via le bouton <code className="action">Commander un datastore</code>.

{/* CP-STEPS-END:datastores */}

#### Backup

{/* CP-STEPS-START:backup */}

L'onglet **Backup** donne accès à la solution de sauvegarde du datacentre. Sur les services actuels, il présente Managed Backup for VMware, une solution de sauvegarde basée sur Veeam et opérée par OVHcloud, avec des liens pour protéger votre infrastructure et vers les tutoriels associés (dont la migration de Veeam Managed Backup vers Managed Backup for VMware).

Sur un service qui utilise encore Veeam Managed Backup, l'onglet vous permet d'activer et de gérer cette solution. Consultez le guide « [Activer et utiliser Veeam Managed Backup](/guides/hosted-private-cloud/powered-by-vmware/veeam-backup-as-a-service) » pour plus de détails.

{/* CP-STEPS-END:backup */}

#### Plan de reprise d’activité (PRA)

{/* CP-STEPS-START:plan-de-reprise-d-activite */}

L'onglet **PRA** vous permet de construire une solution de PRA avec Zerto : choisissez le type de PRA, **Entre deux Private Cloud OVH** ou **Entre votre infrastructure et un Private Cloud OVH**, puis cliquez sur <code className="action">Activer Zerto PRA</code>.

Consultez le guide « [Mise en oeuvre de Zerto Virtual Replication pour votre PRA](/guides/hosted-private-cloud/powered-by-vmware/zerto-virtual-replication-vmware-vsphere-drp) » pour plus de détails.

:::warning
Vous devez posséder une seconde solution Hosted Private Cloud pour activer l'option Zerto **Entre deux Private Cloud OVH**.

:::

{/* CP-STEPS-END:plan-de-reprise-d-activite */}
