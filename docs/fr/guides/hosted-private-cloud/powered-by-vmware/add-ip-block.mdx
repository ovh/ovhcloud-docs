## Objectif

Un bloc IP peut vous servir à rendre vos services accessibles sur Internet. 

**Ce guide explique comment commander, ajouter et migrer un bloc IP associé à votre Hosted Private Cloud.**

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), pour recevoir des identifiants de connexion.
- Avoir un identifiant utilisateur actif (créé dans la <ManagerLink console to="/">console OVHcloud</ManagerLink>)

[[cpnav:network-public-ip-console]]

## En pratique

### Commander un bloc IP

{/* CP-STEPS-START:commander-bloc-ip */}

Pour commander un bloc IP supplémentaire pour votre **Hosted Private Cloud**, ouvrez votre service dans la console OVHcloud (**Private Cloud** › **Managed VMware vSphere**, puis votre service). Dans l'onglet **Tableau de bord**, section **Options**, ouvrez le menu ⋮ de la ligne **Nombre de blocs IP** et cliquez sur <code className="action">Commander des blocs IP</code>. La même page de commande est également accessible depuis **Réseau** › **Adresses IP** : cliquez sur <code className="action">Commander une IP</code>, puis sur <code className="action">Commander une IP additionnelle</code>.

Sur la page **Commander une IP**, renseignez les sections suivantes pour la création de votre bloc IP :

- **Sélectionner la version de l'adresse IP** : choisissez **IPv4**.
- **Sélectionnez un service** : sélectionnez votre service **Hosted Private Cloud**. La région est ensuite déterminée automatiquement à partir du service sélectionné.
- **Sélectionnez une offre** : choisissez la taille du bloc IP (de /28 à /24).

:::info
Pour rappel, voici un tableau récapitulant le nombre d'IP présentes dans un bloc et le nombre d'IP utilisables.

:::


|Taille du bloc|IP dans le bloc|IP utilisables chez OVHcloud|
|:---:|:---:|:---:|
|28|16|11|
|27|32|27|
|26|64|59|
|25|128|123|
|24|256|251|

:::info
N'hésitez pas à consulter notre guide sur le [plugin OVHcloud Network](/guides/hosted-private-cloud/powered-by-vmware/plugin-ovh-network) afin de savoir quelles sont les IPs réservées de votre bloc ainsi que leur utilisation.

:::

- **Sélectionnez une géolocalisation** : choisissez le pays du bloc IP, important dans certains cas pour le référencement de vos services (un site à affluence française aura un meilleur référencement en France si l'IP est française également).

Le nom et la description du réseau visibles dans le whois du bloc IP ne sont pas demandés à la commande : vous pouvez modifier le nom du réseau depuis la page **Adresses IP** une fois le bloc livré.

:::tip
Vous devrez vous acquitter des frais d'activation de votre bloc IP avant livraison.

:::

Vérifiez le **Récapitulatif**, puis cliquez sur <code className="action">Commander</code>. Le bon de commande de votre bloc IP s'ouvre dans un nouvel onglet. Si celui-ci est conforme à votre souhait, il vous suffit de le payer avec les moyens de paiement proposés afin que votre bloc soit livré.

{/* CP-STEPS-END:commander-bloc-ip */}

### Migrer un bloc IP entre deux Hosted Private Cloud

<iframe className="video" width="560" height="315" src="https://www.youtube-nocookie.com/embed/Gemao3Fd7rI" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen={true}></iframe>

La migration d'un bloc d'IP nécessite de déplacer manuellement les blocs via l'APIv6 OVHcloud.

Utilisez l'appel API suivant :

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/move"} />

Les champs doivent être complétés ainsi :

- ip : bloc IP avec le /mask
- nexthop « newPrimaryIp » (sensible a la casse)
- to : Hosted Private Cloud de destination sous la forme pcc-XXX-XXX-XXX-XXX

Le résultat sera sous cette forme :

```json
{
  "function": "genericMoveFloatingIp",
  "status": "todo",
  "taskId": 178970672
}
```

Si, par la suite, vous devez détacher le bloc IP, vous pouvez utiliser cet appel API pour déplacer l'IP dans le parking des IPS :

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/park"} />


:::warning
Cet appel coupe le réseau sur les VMs qui utilisent les IPs en question.

:::

{/* CP-STEPS-START:migrer-bloc-ip */}

Vous pouvez également déplacer le bloc depuis la console OVHcloud : dans l'onglet **Tableau de bord** de votre service, section **Options**, ouvrez le menu ⋮ de la ligne **Nombre de blocs IP** et cliquez sur <code className="action">Associer des blocs IP à un autre service</code>.

Vous pourrez suivre le déplacement du bloc IP dans la partie **Managed VMware vSphere**. Cliquez sur votre service Hosted Private Cloud puis sur l'onglet <code className="action">Opérations</code>.

La référence de l'opération est `removeIpRipeBlock`.

L'IP apparaîtra ensuite dans la liste **Adresses IP** (**Réseau** › **Adresses IP**) avec le type **IP Parking**.

{/* CP-STEPS-END:migrer-bloc-ip */}
