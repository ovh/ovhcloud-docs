## Objectif

La gestion des autorisations et mots de passe des utilisateurs du client vSphere s'effectue depuis la console OVHcloud.

**Découvrez comment modifier votre mot de passe utilisateur**

## Prérequis

- Être connecté à la <ManagerLink console to="/">console OVHcloud</ManagerLink>
- Disposer d'un compte utilisateur créé depuis la console OVHcloud. Pour plus d'informations, consultez [ce guide](/guides/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud#utilisateurs).

[[cpnav:privatecloud-vmware-vsphere-console]]

## En pratique

### Modifier le mot de passe

{/* CP-STEPS-START:modifier-mot-de-passe */}

Dans la console OVHcloud, rendez-vous dans **Private Cloud** › **Managed VMware vSphere** et sélectionnez votre service dans la liste. Cliquez alors sur l'onglet <code className="action">Utilisateurs</code>.

Ouvrez le menu ⋮ (colonne **Actions**) de l'utilisateur concerné puis cliquez sur <code className="action">Changer le mot de passe</code>.

Dans la fenêtre **Changer le mot de passe**, renseignez un nouveau mot de passe dans le champ **Nouveau mot de passe**, confirmez-le dans le champ **Confirmation du mot de passe**, puis cliquez sur <code className="action">Confirmer</code>.

:::info
Si vous ne renseignez pas de mot de passe, un mot de passe généré de façon aléatoire sera envoyé par e-mail à l'adresse associée à l'utilisateur.

:::

Sur un service disposant d'une option de conformité certifiée (PCI DSS, HDS…), la fenêtre n'affiche pas de formulaire : elle indique l'adresse de l'interface certifiée (`https://<votre-service>/secure`), depuis laquelle vous modifiez le mot de passe.

{/* CP-STEPS-END:modifier-mot-de-passe */}

:::warning
Afin de ne pas compromettre la sécurité de votre infrastructure, nous vous recommandons de suivre ces quelques bonnes pratiques. Votre mot de passe doit :

- Comporter au minimum 8 caractères.
- Comporter au minimum 3 types de caractères.
- Ne pas être tiré du dictionnaire.
- Ne pas comporter d'information personnelle.
- Ne pas être utilisé pour plusieurs accès.
- Etre stocké dans un coffre-fort de mots de passe.
- Etre changé tous les 3 mois.
- Etre différent des mots de passe précédents.

:::
