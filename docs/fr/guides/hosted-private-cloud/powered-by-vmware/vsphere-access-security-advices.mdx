## Objectif

Pour assurer l'intégrité de votre infrastructure, il convient d'en restreindre l'accès. Pour cela, nous vous proposons différentes méthodes.

**Apprenez à sécuriser rapidement et facilement l'accès à votre client vSphere Web grâce à quelques conseils.**

## Prérequis

- Posséder un produit [Hosted Private Cloud](/links/hosted-private-cloud/vmware).

[[cpnav:privatecloud-vmware-vsphere-console]]

## En pratique

### Contrôler les accès par IP

Le premier conseil est lié à la restriction de l'accès par IP. Nous vous conseillons de toujours fonctionner avec un système d'inscription sur une liste blanche. Cette technique fonctionne sur l'interdiction de principe de toutes les adresses IP et d'ajout des adresses pouvant avoir accès à votre infrastructure.

{/* CP-STEPS-START:controler-acces-ip */}

Sélectionnez votre service, puis allez dans l'onglet <code className="action">Contrôle d'accès</code>. Un tableau affiche les adresses et blocs IP autorisés. Pour en ajouter de nouveaux, cliquez sur <code className="action">Associer un bloc IP</code>. Dans la fenêtre **Ajouter une règle de sécurité**, renseignez l'adresse IP ou cliquez sur <code className="action">Utiliser mon adresse IP actuelle</code>, ajoutez une description, puis cliquez sur <code className="action">Suivant</code> et sur <code className="action">Confirmer</code>.

{/* CP-STEPS-END:controler-acces-ip */}

### Créer des utilisateurs spécifiques

{/* CP-STEPS-START:creer-utilisateurs */}

Nous vous conseillons fortement de créer un accès personnel pour chaque personne devant avoir accès à votre infrastructure. Cette opération s'effectue également depuis votre service, mais cette fois dans l'onglet <code className="action">Utilisateurs</code>. Pour en ajouter de nouveaux, cliquez sur <code className="action">Créer un utilisateur</code>.

Lors de la création d'un utilisateur, nous vous recommandons de définir un mot de passe.

:::info
Pour sécuriser parfaitement vos données, votre mot de passe doit suivre ces quelques recommandations :

- comporter au minimum huit caractères ;
- comporter au minimum trois types de caractères ;
- ne pas être tiré du dictionnaire ;
- ne pas comporter d'informations personnelles (votre prénom, nom ou date de naissance) ;
- ne pas être utilisé pour plusieurs accès utilisateur ;
- être stocké dans un coffre-fort de mots de passe ;
- être changé tous les trois mois ;
- être différent des mots de passe précédents.

:::

Vous pourrez ensuite gérer les droits de chaque utilisateur depuis le menu ⋮ (colonne **Actions**) de l'utilisateur, en sélectionnant <code className="action">Voir/Modifier les droits par DC</code>.

{/* CP-STEPS-END:creer-utilisateurs */}

### Limiter les temps de session

En fin d'utilisation, il est conseillé de fermer la session de votre utilisateur. Pour limiter le temps de connexion, il est possible d'ajouter une durée d'expiration de session.

{/* CP-STEPS-START:limiter-temps-session */}

Celle-ci est paramétrable dans la section <code className="action">Managed VMware vSphere</code>. Sélectionnez votre service, puis choisissez l'onglet <code className="action">Contrôle d'accès</code>. Dans la section **Paramètres de session**, cliquez sur <code className="action">Modifier</code> sur la ligne **Délai d'expiration de session**.

Dans la fenêtre **Modifier le délai d'expiration de session**, renseignez ensuite le nombre de minutes avant qu'une session expire, ou cochez **Pas d'expiration de session** pour désactiver l'expiration. Cliquez sur <code className="action">Suivant</code>, puis sur <code className="action">Confirmer</code>.

{/* CP-STEPS-END:limiter-temps-session */}
