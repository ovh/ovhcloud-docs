## Objectif

La fonctionnalité **LTR (Long Term Retention)** permet à Zerto de conserver vos sauvegardes sur le long terme, dans un bucket OVHcloud Object Storage.

**Ce guide explique comment ajouter, consulter, modifier et supprimer ce bucket de rétention long terme.**

:::warning
**Le bucket LTR se déclare dans la console OVHcloud, et non dans l'interface Zerto.**

L'ajout du bucket (stockage objet S3<sup>1</sup>) se fait uniquement depuis l'onglet **DRP** de votre datacentre, dans la console OVHcloud. Il n'existe aucune étape équivalente à réaliser dans l'interface Zerto pour relier ce bucket à votre service.
:::

## Ce qui se fait dans la console et dans Zerto

| | Console OVHcloud | Interface Zerto |
|:--|:--|:--|
| Déclarer le bucket de rétention long terme (ajout, modification, suppression) | Oui, c'est ici | Non |
| Renseigner le bucket, l'endpoint et les clés S3 | Oui | Non |
| Activer l'immutabilité des données | Oui | Non |
| Piloter la durée de conservation des points de restauration de vos VPG | Non | Oui, avec la politique de rétention Zerto |

## Prérequis

- Disposer d'un service Managed VMware vSphere avec Zerto activé sur le datacentre concerné.
- Disposer d'un bucket OVHcloud Object Storage, de classe **High Performance** ou **Standard** (les deux sont pris en charge). Seuls les buckets OVHcloud Object Storage sont acceptés.
- Avoir activé l'**Object Lock** sur ce bucket (voir l'étape 2).
- Disposer des identifiants S3<sup>1</sup> associés à ce bucket (access key et secret key).

## En pratique

### Étape 1 : Accéder à l'onglet LTR dans la console

1. Connectez-vous à la console OVHcloud.
2. Ouvrez <code className="action">Hosted Private Cloud</code> > <code className="action">Managed VMware vSphere</code>, puis sélectionnez votre service.
3. Sélectionnez le datacentre concerné.
4. Ouvrez l'onglet <code className="action">DRP</code> (Disaster recovery plan).
5. Dans le groupe de boutons, cliquez sur <code className="action">LTR</code>.

<img className="thumbnail" alt="Onglet DRP du datacentre, avec le bouton LTR sélectionné" src="/images/hosted-private-cloud/powered-by-vmware/zerto-ltr/ltr-tab.png" loading="lazy" />

### Étape 2 : Préparer votre bucket Object Storage

Si aucun bucket n'est configuré, la page LTR affiche le message « No LTR repository configured » et deux boutons :

<img className="thumbnail" alt="Page LTR sans bucket configuré" src="/images/hosted-private-cloud/powered-by-vmware/zerto-ltr/ltr-no-bucket.png" loading="lazy" />

- <code className="action">Create an OVHcloud bucket</code> : ouvre la commande d'un bucket Object Storage. Si vous disposez d'un projet Public Cloud, vous arrivez dans la section Object Storage de la console ; sinon, sur la page Object Storage du site OVHcloud.
- <code className="action">Add an existing bucket</code> : ouvre le formulaire d'ajout (étape 3).

Lors de la création du bucket :

- Choisissez sa classe : **High Performance** ou **Standard**. Les deux sont pris en charge.
- Activez l'**Object Lock**, sans quoi la rétention long terme ne peut pas fonctionner correctement.
- Créez un utilisateur S3 et conservez son access key et sa secret key.

:::warning
Si l'Object Lock n'est pas activé sur le bucket, la configuration LTR peut échouer ou ne pas garantir l'immutabilité attendue.
:::

### Étape 3 : Ajouter le bucket

Cliquez sur <code className="action">Add an existing bucket</code> (ou <code className="action">Add a bucket</code> si un bucket est déjà configuré). La fenêtre **Add an LTR bucket** s'ouvre :

<img className="thumbnail" alt="Fenêtre d'ajout d'un bucket LTR" src="/images/hosted-private-cloud/powered-by-vmware/zerto-ltr/ltr-add-bucket.png" loading="lazy" />

Renseignez les champs obligatoires :

| Champ | Détails |
|:--|:--|
| Bucket name | Nom du bucket OVHcloud Object Storage. |
| Endpoint URL | Endpoint S3 de la région du bucket, par exemple `https://s3.gra.io.cloud.ovh.net`. |
| Access key | Clé d'accès S3 du bucket. |
| Secret key | Clé secrète S3 du bucket. |

Vérifiez que l'endpoint correspond bien à la région OVHcloud de votre bucket.

Vous n'avez pas à indiquer la classe du bucket (High Performance ou Standard) : la console la détecte automatiquement.

Si besoin, activez **Enable immutability** (voir l'étape 4), puis cliquez sur <code className="action">Add</code>.

:::warning
La configuration du bucket peut prendre jusqu'à 15 minutes. Pendant ce temps, vous ne pouvez pas ajouter un autre bucket.
:::

Si la configuration échoue, un message d'erreur s'affiche et le formulaire d'ajout reste disponible : corrigez les informations (en premier lieu l'endpoint, les clés S3 et l'Object Lock) et recommencez.

### Étape 4 : Activer l'immutabilité (optionnel)

L'option **Enable immutability** protège les données contre la suppression ou la modification pendant la période définie. Une fois l'option activée, choisissez un type d'immutabilité (**Immutability type**) :

<img className="thumbnail" alt="Options d'immutabilité d'un bucket LTR" src="/images/hosted-private-cloud/powered-by-vmware/zerto-ltr/ltr-immutability.png" loading="lazy" />

- **Period** : vous définissez explicitement une durée dans le champ **Number of days**, avec une valeur comprise entre **30 et 90 jours**.
- **Per VPG Retention Policy** : la durée est pilotée par la politique de rétention définie dans Zerto pour chaque VPG.

### Étape 5 : Consulter, modifier et supprimer un bucket

Une fois le bucket configuré, le tableau de la page LTR indique son nom (**Bucket name**), la durée en jours (**Number of days**) et son **Endpoint**.

<img className="thumbnail" alt="Tableau des buckets LTR configurés" src="/images/hosted-private-cloud/powered-by-vmware/zerto-ltr/ltr-bucket-list.png" loading="lazy" />

Pour agir sur un bucket, cliquez sur le menu en fin de ligne (colonne **Actions**) :

<img className="thumbnail" alt="Menu Actions d'un bucket LTR : Edit et Delete" src="/images/hosted-private-cloud/powered-by-vmware/zerto-ltr/ltr-actions-menu.png" loading="lazy" />

- <code className="action">Edit</code> : modifier la configuration du bucket.
- <code className="action">Delete</code> : supprimer le bucket. Confirmez avec <code className="action">Confirm</code>.

<img className="thumbnail" alt="Confirmation de suppression d'un bucket LTR" src="/images/hosted-private-cloud/powered-by-vmware/zerto-ltr/ltr-delete-bucket.png" loading="lazy" />
