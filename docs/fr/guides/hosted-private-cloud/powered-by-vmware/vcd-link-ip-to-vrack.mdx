## Objectif

Lors de la commande d'une nouvelle organisation Public VCF as-a-Service, un vRack ainsi qu'un bloc d'adresses IP publiques vous sont livrés.

Ce bloc IP n'est pas directement lié à votre vRack, vous devez effectuer cette liaison manuellement.

**Découvrez comment lier le bloc d'adresses IP publiques livré avec votre organisation Public VCF as-a-Service et son vRack.**

## Prérequis

- Posséder une offre [Public VCF as-a-Service](https://www.ovhcloud.com/fr/lp/vmware-vcd-evolution/).
- Être administrateur technique de votre solution [VMware vSphere on OVHcloud](https://www.ovhcloud.com/fr/hosted-private-cloud/vmware/).

[[cpnav:privatecloud-vmware-vcf-console+network-vrack-console]]

## En pratique

{/* CP-STEPS-START:lier-bloc-ip-vrack */}

1. Sélectionnez votre organisation, puis ouvrez l'onglet <code className="action">Virtual Datacenters</code>.

2. La colonne **vRack** affiche le vRack attaché à chaque Virtual Datacenter de votre organisation, avec un ID sous la forme `pn-xxxxxxx`. Il apparaît également dans l'onglet <code className="action">Informations générales</code> du Virtual Datacenter.

3. Dépliez le menu <code className="action">Réseau</code> dans la colonne de gauche, sélectionnez <code className="action">vRack</code> puis votre vRack `pn-xxxxxxx`.

4. Ouvrez l'onglet <code className="action">Services rattachés</code> et cliquez sur <code className="action">Attacher un service</code>. Sur la page **Services éligibles**, réglez le filtre **Type de service** sur **Blocs IPv4 additionnels**, puis cliquez sur <code className="action">Rattacher</code> sur la ligne du bloc IP à lier à votre vRack/organisation.

5. Le bloc d'adresses IP publiques est désormais lié à votre vRack.

    Pour rendre ces adresses utilisables dans votre environnement Public VCF as-a-Service, vous devez également déclarer la passerelle IP publique dans VMware Cloud Director (VCD).

    Suivez le guide [Public VCF as-a-Service - Déclarer la passerelle IP publique dans VCD](/guides/hosted-private-cloud/powered-by-vmware/vcd-declare-public-gateway) pour finaliser cette étape.
