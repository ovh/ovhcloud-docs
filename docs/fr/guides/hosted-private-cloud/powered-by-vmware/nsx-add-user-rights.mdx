## Objectif

Ce guide vous détaille comment ajouter les droits de lecture à un utilisateur pour accéder à la console Web NSX-T de votre Hosted Private Cloud - VMware on OVHcloud.

Ces droits sont accordés depuis la <ManagerLink console to="/">console OVHcloud</ManagerLink>.

## Prérequis

- Avoir souscrit une offre [Hosted Private Cloud](/links/hosted-private-cloud/vmware) avec les options **"Network Security Virtualization"** ou **"Software-Defined Datacenter"** 
- Être contact administrateur de l'infrastructure VMware sur OVHcloud, celui-ci recevant les identifiants de connexion.
- Avoir suivi les étapes de cette documentation : [Premiers pas avec NSX](/guides/hosted-private-cloud/powered-by-vmware/nsx-first-steps)

[[cpnav:privatecloud-vmware-vsphere-console]]

## Instructions

### Etape 1 - Activer NSX-T

{/* CP-STEPS-START:activer-nsx-t */}

<details>

<summary>Comment activer l'interface NSX-T pour votre utilisateur ?</summary>

Il n'existe pas, dans la console OVHcloud, de permission NSX distincte à activer sur l'utilisateur. L'accès à l'interface Web NSX-T est accordé par datacentre, avec le droit **Accès à V(x)Lans / GENEVE** de l'utilisateur avec lequel vous souhaitez y accéder (voir l'étape 3).

</details>

{/* CP-STEPS-END:activer-nsx-t */}
### Etape 2 - Ajouter les droits NSX-T

{/* CP-STEPS-START:ajouter-droits-nsx-t */}

<details>

<summary>Comment ajouter les droits pour votre utilisateur ?</summary>

Dans la console OVHcloud, accédez à **Private Cloud** › **Managed VMware vSphere** et sélectionnez votre service (`pcc-XXX-XXX-XXX-XXX`) dans la liste. Accédez à l'onglet <code className="action">Utilisateurs</code> et repérez l'utilisateur avec lequel vous souhaitez accéder à l'interface Web NSX-T.

La fenêtre **Modifier** de l'utilisateur (menu ⋮ de la colonne **Actions**, puis <code className="action">Éditer</code>) ne contient aucun droit NSX-T : les droits qui donnent accès à NSX-T se définissent par datacentre, comme décrit à l'étape 3.

</details>

{/* CP-STEPS-END:ajouter-droits-nsx-t */}

### Etape 3 - Ajouter les droits NSX-T aux Datacentres

{/* CP-STEPS-START:ajouter-droits-datacentres */}

<details>

<summary>Comment ajouter les droits aux datacentres ?</summary>

Il ne vous reste plus qu'à modifier les droits de chaque datacentre souhaité. Dans la console OVHcloud, accédez à **Private Cloud** › **Managed VMware vSphere**, sélectionnez votre service (`pcc-XXX-XXX-XXX-XXX`) puis accédez à l'onglet <code className="action">Utilisateurs</code>. Ouvrez le menu ⋮ (colonne **Actions**) de l'utilisateur et cliquez sur <code className="action">Voir/Modifier les droits par DC</code>. Sur la ligne du datacentre, ouvrez le menu ⋮ (colonne **Actions**) et cliquez sur <code className="action">Modifier les droits</code>.

La fenêtre **Edition des droits** s'ouvre alors. Choisissez les droits nécessaires dans les 3 listes principales : **Accès vSphere** / **Accès au vmNetwork** / **Accès à V(x)Lans / GENEVE**. La fenêtre contient également la case **Gestion des hôtes et des stockages**.

<br/><br/>
Les droits suivants sont disponibles : <strong>Opérateur</strong> / <strong>Aucun</strong> / <strong>Lecture seule</strong> dans les trois listes, <strong>Lecture/Écriture</strong> dans **Accès vSphere** uniquement et <strong>Administrateur</strong> dans **Accès à V(x)Lans / GENEVE** uniquement.
<br/><br/>
Seul l'accès <strong>Lecture seule</strong> dans **Accès à V(x)Lans / GENEVE** est nécessaire pour accéder à l'interface Web NSX-T.
<br/><br/>
Dans **Accès à V(x)Lans / GENEVE**, sélectionnez <strong>Lecture seule</strong>, puis cliquez sur <code className="action">Enregistrer</code>.
<br/><br/>
Si vous voulez faire des modifications dans l'interface Web NSX-T, des droits supplémentaires seront alors nécessaires, tels que <strong>Opérateur</strong> ou <strong>Administrateur</strong>.

</details>

{/* CP-STEPS-END:ajouter-droits-datacentres */}
### Etape 4 - Accéder à l'interface NSX-T

{/* CP-STEPS-START:acceder-interface-nsx-t */}

<details>

<summary>Comment accéder à l'interface Web NSX-T ?</summary>

La console OVHcloud ne propose pas de lien vers l'interface Web NSX-T. Dans la console, accédez à **Private Cloud** › **Managed VMware vSphere** et sélectionnez votre service (`pcc-XXX-XXX-XXX-XXX`) : dans son onglet <code className="action">Tableau de bord</code>, la section **Options** indique si l'option **Virtualisation du réseau et de la sécurité (NSX-T)** est activée et sur quel datacenter elle est hébergée. L'adresse de l'interface Web NSX-T est fournie par l'API OVHcloud, comme décrit à l'étape 5. Une fois cette adresse obtenue, connectez-vous à l'interface Web NSX-T avec votre utilisateur :

### Etape 5 - Informations utiles

Vous pouvez vérifier si NSX-T est activé sur votre Datacenter. Vous pouvez également retrouver votre URL NSX-T et sa version :

#### Via l'API OVHcloud

<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\{serviceName\}/nsxt"} />


> **Paramètres:**
>
> serviceName: La référence de votre PCC sous la forme `pcc-XX-XX-XX-XX`.
>

Exemple de retour :

```shell
{
  "version": "4.1.1.0.0-22224312",
  "state": "enabled",
  "url": "https://nsxt.pcc-XX-X-X-X.ovh.X",
  "datacentersState": [
    {
      "id": 1542,
      "state": "disabled"
    },
    {
      "state": "enabled",
      "id": 1345
    }
  ]
}
```
