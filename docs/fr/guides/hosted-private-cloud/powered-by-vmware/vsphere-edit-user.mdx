## Objectif

Il est possible d'associer un nom, prénom, numéro de téléphone et adresse e-mail à l'utilisateur vSphere de votre Private cloud. L'adresse e-mail permet notamment la validation par token.

**Découvrez comment associer une adresse e-mail à votre utilisateur vSphere**

## Prérequis

- Disposer d'une offre [Hosted Private cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/).

[[cpnav:privatecloud-vmware-vsphere-console]]

## En pratique

{/* CP-STEPS-START:associer-email-utilisateur */}

Sélectionnez l'infrastructure concernée.

Accédez à l'onglet <code className="action">Utilisateurs</code>, ouvrez le menu ⋮ (colonne **Actions**) de l'utilisateur concerné puis cliquez sur <code className="action">Éditer</code>.

La fenêtre **Modifier** s'affiche. Vous pouvez y définir vos nom, prénom, numéro de téléphone et adresse e-mail.

Cette fenêtre permet également d'attribuer les droits **Token validator**, **Ip**, **Ip FailOver** et **Gestion du chiffrement**. Le droit **Token validator** est utilisé pour approuver certaines actions sensibles sur des infrastructures ayant l'option **Sécurité avancée** activée.

Cliquez sur le bouton <code className="action">Enregistrer</code> pour confirmer vos modifications.

{/* CP-STEPS-END:associer-email-utilisateur */}
