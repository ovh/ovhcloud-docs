## Objectif

**Ce guide vous détaille comment créer ou modifier une politique IAM globale et lui ajouter un rôle Vsphere**.

## Prérequis

- Disposer d'un [compte OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation)
- Avoir un ou plusieurs produits Hosted Private Cloud - VMware on OVHcloud liés à ce compte (Hosted Private Cloud powered by VMware, Service Pack VMware)
- Avoir activé IAM pour votre service Hosted Private Cloud - VMware on OVHcloud. Suivez les étapes du guide « [IAM pour VMware on OVHcloud - Comment activer IAM](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-activation) »

## En pratique

### Créer ou modifier une politique

<img className="thumbnail" alt="Page Mes politiques de la console OVHcloud, avec le bouton Créer une politique" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role-policy/console/iam_role_policy_9.png" loading="lazy" />

Cliquez sur <code className="action">Créer une politique</code>.

Pour modifier une politique, cliquez sur le bouton <code className="action">⋮</code> dans la colonne **Actions**, à droite de la politique concernée, puis sur <code className="action">Modifier la politique</code>.

<img className="thumbnail" alt="Section Types de produit avec VMware on OVHcloud et un service vSphere sélectionnés" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role-policy/console/iam_role_policy_10.png" loading="lazy" />

Le formulaire de la politique comporte cinq sections : **Informations de la politique**, **Identités**, **Types de produit**, **Conditions** et **Actions**, ainsi qu'une section **Récapitulatif** sur la droite. Renseignez les paramètres demandés :

- **Nom**, dans la section **Informations de la politique** : choisissez un nom. Il ne peut contenir que des lettres, des chiffres et les caractères `-`, `/`, `_` et `+`.
- **Description**, dans la même section : renseignez une description pour votre politique.
- **Identités** (obligatoire) : sélectionnez les identités concernées par votre politique, dans les onglets **Utilisateurs**, **Groupes**, **Comptes de service** et **Autres comptes OVHcloud**.
- **Types de produit** : sélectionnez <code className="action">VMware on OVHcloud</code> / <code className="action">Service Pack Vmware</code>.
- **Ressources**, dans la section **Types de produit** : ajoutez les ressources concernées par votre politique (**pcc-XX-XX-XX-XX/servicepack**, **pcc-XX-XX-XX-XX.ovh.com (pccVMware)**, etc.).
- **Actions** : c'est ici que vous ajoutez votre rôle (voir ci-dessous).

#### Ajouter un rôle IAM à une politique globale

Lors de l'activation d'IAM dans vSphere, deux rôles sont ajoutés par défaut (`iam-admin`, `iam-auditor`).

Copiez les rôles depuis la section de code ci-dessous, collez-les dans le champ **Ajouter des actions manuellement** de la section **Actions**, puis cliquez sur le bouton <code className="action">Ajouter</code>.

```bash
pccVMware:vSphere:assumeRole?iam-admin
pccVMware:vSphere:assumeRole?iam-auditor
```

Si vous avez créé un rôle IAM supplémentaire (après avoir suivi les étapes du guide « [IAM pour VMware on OVHcloud - Comment créer un rôle vSphere IAM](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-role) »), vous pouvez également l'ajouter en copiant le code ci-dessous et en l'adaptant à votre rôle :

```bash
pccVMware:vSphere:assumeRole?{nom_du_rôle}
```

<img className="thumbnail" alt="Section Actions avec une action assumeRole saisie dans le champ Ajouter des actions manuellement" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role-policy/console/iam_role_policy_11.png" loading="lazy" />

Veillez à bien cliquer sur le bouton <code className="action">Ajouter</code> pour ajouter l'action.

Pour finir, cliquez sur <code className="action">Créer</code> en bas du formulaire, ou sur <code className="action">Créer une politique</code> dans la section **Récapitulatif** sur la droite. Si vous modifiez une politique, cliquez sur <code className="action">Enregistrer</code>, ou sur <code className="action">Modifier la politique</code> dans la section **Récapitulatif**.
