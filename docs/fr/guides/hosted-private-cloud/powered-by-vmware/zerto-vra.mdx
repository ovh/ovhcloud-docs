## Objectif

Ce guide décrit le fonctionnement de la vue **VRA** de l'onglet **PRA** pour Zerto sur Managed VMware vSphere.

Cette vue permet de :

- Afficher toutes les Virtual Replication Appliances (VRA) présentes sur l'installation.
- Sélectionner une ou plusieurs VRA à l'aide de cases à cocher.
- Appliquer une configuration cible de ressources via la liste **Ressources cibles**.

## Prérequis

- Disposer d'un service Managed VMware vSphere avec Zerto activé.
- Avoir accès à l'onglet **PRA** de votre datacenter.
- Disposer des droits nécessaires pour lancer une opération de redimensionnement.
- Vérifier que votre PCC dispose de ressources suffisantes (CPU, RAM, stockage) pour appliquer les changements de configuration.

{/* CP-STEPS-START:cp-access */}

:::info
La vue VRA est accessible depuis l'onglet **PRA** du datacentre en cliquant sur <code className="action">VRA</code>.
:::

:::info
Les profils proposés dans la liste **Ressources cibles** forment une liste fixe : ils ne dépendent pas des VRA sélectionnées.
:::

[[cpnav:privatecloud-vmware-vsphere-console]]

{/* CP-STEPS-END:cp-access */}

## En pratique

### Étape 1 : Consulter la liste des VRA

{/* CP-STEPS-START:consulter-liste-vra */}

La vue VRA affiche un tableau contenant les VRA présentes sur votre installation, avec les colonnes suivantes :

- **Nom** : le nom de la VRA.
- **VMId** : l'identifiant VM.
- **Ressources** : les ressources associées (par exemple, 2 vCPU · 6 GiB RAM).

Chaque ligne dispose d'une case à cocher pour la sélection.

{/* CP-STEPS-END:consulter-liste-vra */}

### Étape 2 : Sélectionner les VRA à redimensionner

{/* CP-STEPS-START:selectionner-vra */}

Vous pouvez sélectionner une ou plusieurs VRA en même temps.

Tant qu'aucune VRA n'est sélectionnée :

- La liste **Ressources cibles** est désactivée.
- Le bouton <code className="action">Démarrer le redimensionnement</code> est désactivé.

Quand au moins une VRA est sélectionnée :

- La liste **Ressources cibles** devient disponible.

Le bouton <code className="action">Démarrer le redimensionnement</code> devient actif uniquement après :

- La sélection d'au moins une VRA.
- Le choix d'un profil dans **Ressources cibles**.

{/* CP-STEPS-END:selectionner-vra */}

### Étape 3 : Choisir la configuration Ressources cibles

{/* CP-STEPS-START:choisir-ressources-cibles */}

Dans la liste **Ressources cibles**, choisissez le profil de destination souhaité : XS (1 vCPU, 2 GiB de RAM), S (2 vCPU, 6 GiB de RAM), L (4 vCPU, 12 GiB de RAM) ou XL (4 vCPU, 16 GiB de RAM).

{/* CP-STEPS-END:choisir-ressources-cibles */}

### Étape 4 : Confirmer l'opération de resize

{/* CP-STEPS-START:confirmer-redimensionnement */}

Cliquez sur <code className="action">Démarrer le redimensionnement</code> après sélection des VRA et du profil cible.

Une fenêtre de confirmation s'ouvre avec le titre **Confirmer la reconfiguration VRA**. Cette fenêtre affiche :

- Le profil cible choisi.
- La liste des VRA qui seront reconfigurées.
- Un message d'avertissement indiquant que le redimensionnement impactera pendant quelques minutes les réplications configurées dans vos VPG.

Actions disponibles :

- <code className="action">Confirmer</code> : lance la reconfiguration des VRA sélectionnées.
- <code className="action">Annuler</code> : ferme la fenêtre sans appliquer de changement.

:::warning
Avant de confirmer, vérifiez que votre PCC dispose de ressources suffisantes (CPU, RAM et stockage) pour appliquer la nouvelle configuration.
:::

{/* CP-STEPS-END:confirmer-redimensionnement */}
