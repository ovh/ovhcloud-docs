## Objectif

Ce guide décrit le fonctionnement de l'onglet **VRA** dans Zerto sur Managed VMware vSphere.

Cette vue permet de :

- Afficher toutes les Virtual Replication Appliances (VRA) présentes sur l'installation.
- Sélectionner une ou plusieurs VRA à l'aide de cases à cocher.
- Appliquer une configuration cible de ressources via la liste **Target resources**.

## Prérequis

- Disposer d'un service Managed VMware vSphere avec Zerto activé.
- Avoir accès à la section Zerto de votre datacenter.
- Disposer des droits nécessaires pour lancer une opération de redimensionnement.
- Vérifier que votre PCC dispose de ressources suffisantes (CPU, RAM, stockage) pour appliquer les changements de configuration.

:::info
L'onglet VRA est accessible depuis le groupe d'onglets Zerto en cliquant sur **VRA**.
:::

:::info
Les options proposées dans la liste **Target resources** sont récupérées automatiquement et correspondent aux configurations applicables.
:::

## En pratique

### Étape 1 : Consulter la liste des VRA

La vue VRA affiche un tableau contenant les VRA présentes sur votre installation, avec notamment :

- Le nom de la VRA.
- L'identifiant VM (VMid).
- Les ressources associées.

Chaque ligne dispose d'une case à cocher pour la sélection.

### Étape 2 : Sélectionner les VRA à redimensionner

Vous pouvez sélectionner une ou plusieurs VRA en même temps.

Tant qu'aucune VRA n'est sélectionnée :

- Le champ **Target resources** est désactivé.
- Le bouton **Start resize** est désactivé.

Quand au moins une VRA est sélectionnée :

- Le champ **Target resources** devient disponible.

Le bouton **Start resize** devient actif uniquement après :

- La sélection d'au moins une VRA.
- Le choix d'une valeur dans **Target resources**.

### Étape 3 : Choisir la configuration Target resources

Dans la liste **Target resources**, choisissez la configuration de destination souhaitée (par exemple 1 vCPU - 2 GiB, 2 vCPU - 6 GiB, etc. selon les options affichées).

La liste affiche uniquement les configurations applicables aux VRA sélectionnées.

### Étape 4 : Confirmer l'opération de resize

Cliquez sur **Start resize** après sélection des VRA et de la configuration cible.

Une fenêtre de confirmation s'ouvre avec le titre **Confirm VRA reconfiguration**. Cette fenêtre affiche :

- Le profil cible choisi.
- La liste des VRA qui seront reconfigurées.
- Un message d'avertissement indiquant que l'opération peut impacter temporairement les réplications configurées dans vos VPG.

Actions disponibles :

- **Confirm** : lance la reconfiguration des VRA sélectionnées.
- **Cancel** : ferme la fenêtre sans appliquer de changement.

:::warning
Avant de confirmer, vérifiez que votre PCC dispose de ressources suffisantes (CPU, RAM et stockage) pour appliquer la nouvelle configuration.
:::
