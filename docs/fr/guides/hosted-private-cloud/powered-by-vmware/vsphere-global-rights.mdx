## Objectif

Les permissions globales vSphere permettent de définir les droits d'un utilisateur sur votre service Hosted Private Cloud. Depuis l'Espace Client OVHcloud, vous pouvez activer ou désactiver ces options pour chaque utilisateur au moyen de cases à cocher.

Ce guide explique comment gérer ces permissions globales depuis le Manager OVHcloud.

## Prérequis

- Un [service Hosted Private Cloud](https://www.ovhcloud.com/fr/hosted-private-cloud/vmware/) actif
- Un [utilisateur vSphere](/guides/hosted-private-cloud/powered-by-vmware/vsphere-interface-connexion) déjà créé sur votre service
- Un accès à l'<ManagerLink to="/">Espace Client OVHcloud</ManagerLink> avec les droits suffisants pour administrer les utilisateurs

## En pratique

### Accéder à la gestion des droits utilisateur

1. Ouvrez l'<ManagerLink to="/">Espace Client OVHcloud</ManagerLink>. Cliquez sur <code className="action">Hosted Private Cloud</code> dans la barre supérieure, puis sur <code className="action">Managed VMware vSphere</code> dans le menu de gauche, et sélectionnez votre service PCC.

2. Accédez à l'onglet <code className="action">Utilisateurs</code>.

	<img className="thumbnail" alt="Onglet utilisateurs" src="/images/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud/en05users.png" loading="lazy" />

3. Sur la ligne de l'utilisateur concerné, ouvrez le menu <code className="action">…</code> puis cliquez sur <code className="action">Modifier</code>.

### Configurer les permissions globales

1. Dans la fenêtre de modification de l'utilisateur, plusieurs cases à cocher correspondent aux permissions globales.

2. Cochez ou décochez les options selon les droits que vous souhaitez accorder à l'utilisateur.

	<img className="thumbnail" alt="Fenêtre de modification des droits utilisateur" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/user-global-rights.png" loading="lazy" />

3. Validez la modification.

### Permissions disponibles

Les permissions globales sont représentées par les cases à cocher suivantes dans la fenêtre de modification de l'utilisateur :

| Permission | Description |
|---|---|
| Token validator | Permet à l'utilisateur de valider les opérations nécessitant un jeton de validation. Cette permission est généralement utile lorsque l'authentification à deux facteurs (2FA) est activée sur le service, par exemple dans le cadre de certaines certifications telles que l'Hébergement de Données de Santé (HDS). |
| Ip | Permet à l'utilisateur de gérer les IP associées au service. |
| Ip Failover | Permet à l'utilisateur de gérer les IP Failover associées au service. |
| Interface NSX | Donne accès à l'interface de gestion réseau NSX. |
| Gestion du chiffrement | Permet à l'utilisateur de gérer le chiffrement des machines virtuelles (KMS). |

### Aller plus loin avec les droits granulaires

Les permissions globales décrites ci-dessus s'appliquent au niveau de l'inventaire vSphere Hosted Private CLoud, autrement au niveau du cluster VMWare considéré.

Si vous avez besoin d'autoriser un utilisateur uniquement sur certains objets de l'inventaire vSphere, par exemple une machine virtuelle, un datastore ou un dossier, vous devez utiliser les [droits granulaires sur les objets vSphere](/guides/hosted-private-cloud/powered-by-vmware/vsphere-granular-rights).
