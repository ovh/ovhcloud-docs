## Objectif

**Ce guide vous détaille comment associer une identité (un utilisateur) OVHcloud à une politique IAM globale**.

## Prérequis

- Disposer d'un [compte OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation)
- Avoir un ou plusieurs produits Hosted Private Cloud - VMware on OVHcloud liés à ce compte (Hosted Private Cloud powered by VMware, Service Pack VMware)
- Avoir activé IAM pour votre service Hosted Private Cloud - VMware on OVHcloud. Suivez les étapes du guide « [IAM pour VMware on OVHcloud - Comment activer IAM](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-activation) »

[[cpnav:iam-policies-console]]

## En pratique

### Comment associer un utilisateur à une politique IAM globale ?

<img className="thumbnail" alt="Page Mes politiques avec la liste des politiques et la colonne Actions" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-user-policy/console/iam_policies_resize.png" loading="lazy" />

Vous retrouvez ici les politiques que vous avez déjà créées.

Cliquez sur le bouton <code className="action">⋮</code> dans la colonne **Actions**, à droite de votre politique, puis sur <code className="action">Modifier la politique</code>.

<img className="thumbnail" alt="Page Modifier la politique avec la section Identités et la section Récapitulatif à droite" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-user-policy/console/iam_policies_modify.png" loading="lazy" />

Sélectionnez ensuite les identités souhaitées dans la section **Identités**, où chaque type d'identité dispose de son propre onglet : **Utilisateurs**, **Groupes**, **Comptes de service** et **Autres comptes OVHcloud**. Vos utilisateurs locaux sont listés dans l'onglet **Utilisateurs** ; pour les groupes d'utilisateurs, cliquez sur l'onglet <code className="action">Groupes</code>. Cochez la case de chaque identité que vous souhaitez ajouter à la politique.

<img className="thumbnail" alt="Section Identités avec les onglets des types d'identité et la liste des utilisateurs avec leurs cases à cocher" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-user-policy/console/iam_add_user.png" loading="lazy" />

Seuls les Groupes IAM (et non les groupes IAM vSphere) sont listés dans l'onglet **Groupes**. Veillez à choisir le bon groupe dans la liste : pour la filtrer, utilisez le champ **Rechercher** situé au-dessus.

Puis, pour terminer votre politique, cliquez sur <code className="action">Enregistrer</code> en bas du formulaire, ou sur <code className="action">Modifier la politique</code> dans la section **Récapitulatif** à droite.

:::info
Si votre identité n'est pas présente, vous devez l'ajouter auparavant dans la console OVHcloud, sur la page <ManagerLink to="/beta/#/iam/identities/users">Identités</ManagerLink>.

:::
