## Objectif

Lorsqu'une maintenance est programmée sur votre Hosted Private Cloud, un e-mail de notification vous est envoyé pour vous prévenir de la date de cette maintenance. Si cette date ne vous convient pas, par exemple pour des impératifs de production, vous pouvez reporter cette maintenance à une date de votre choix, via la console OVHcloud ou l'API OVHcloud.

:::info
Nous essayons de nous adapter au maximum à votre utilisation de l'infrastructure et à vos contraintes. Cependant, nous devons parfois planifier des maintenances pour lesquelles il ne sera pas possible de modifier la date et/ou l'heure (maintenances d'infrastructure impliquant plusieurs clients, interventions urgentes pour éviter un incident, etc).

Pour information, lorsqu'une date de maintenance peut être modifiée par vos soins, les nouvelles dates proposées sont comprises dans un intervalle de temps réduit.

:::

**Découvrez comment reporter la date d'une maintenance programmée sur votre VMware on OVHcloud, depuis la console OVHcloud ou l'API OVHcloud.**

## Prérequis

- Avoir reçu un e-mail de notification de maintenance indiquant spécifiquement que vous pouvez « **modifier la date d'exécution de la maintenance** ». Dans le cas contraire, la date de la maintenance ne peut pas être modifiée.
- Être contact administrateur ou technique de l'infrastructure [VMware on OVHcloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/).
- Avoir accès à l'<ApiLink>interface d'administration de vos services par API</ApiLink>.

### Depuis la console OVHcloud

{/* CP-STEPS-START:depuis-espace-client */}

Avec un compte administrateur, rendez-vous dans **Private Cloud** › **Managed VMware vSphere** dans la console OVHcloud, sélectionnez votre service dans la liste et cliquez sur l'onglet <code className="action">Opérations</code>. Dans le menu déroulant situé au-dessus du tableau des opérations, à droite, vérifiez que <code className="action">En cours</code> (valeur par défaut) est sélectionné pour afficher les opérations qui ne sont pas encore terminées.

Ouvrez ensuite le menu ⋮ (colonne **Actions**) de l'opération de maintenance puis cliquez sur <code className="action">Modifier la date de traitement</code>.

:::info
Si l'option <code className="action">Modifier la date de traitement</code> n'est pas disponible, cette maintenance ne peut pas être reportée.

:::

Dans la fenêtre **Modifier la date de traitement**, sélectionnez une date dans le calendrier **Date de traitement**. Seules les dates disponibles sont sélectionnables : les dates situées en dehors de la fenêtre de maintenance autorisée ne peuvent pas être choisies.

Renseignez ensuite une nouvelle heure pour cette maintenance dans le champ **Heure** ou laissez inchangé l'horaire initialement prévu.

Enfin, cliquez sur le bouton <code className="action">Modifier</code> pour valider vos modifications.

{/* CP-STEPS-END:depuis-espace-client */}

### Depuis l'API OVHcloud

Rendez-vous sur l'<ApiLink>interface d'administration de vos services par API</ApiLink>. Vous pouvez vous aider de notre guide « [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps) ».

Exécutez l'appel API suivant :

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/task/\{taskId\}/changeMaintenanceExecutionDate"} />

Renseignez les variables :

- serviceName : la référence de votre PCC sous la forme `pcc-XX-XX-XX-XX` ;
- taskId : il s'agit de la « référence de l'opération » de maintenance renseignée dans l'e-mail de notification qui vous a été envoyé ;
- executionDate: renseignez la nouvelle date de maintenance au format `YYYY-MM-DDTHH:MM+01:SS` (par exemple, 2023-01-02T08:00:00+01:00 pour une maintenance programmée le 02/01/2023 à 08h00 (UTC+1)).
