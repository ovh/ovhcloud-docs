## Objectif

OVHcloud propose un ensemble d’outils IA managés conçus pour la création de vos projets de machine learning.

Ce guide explique comment vous repérer parmi les outils IA d’OVHcloud dans la console OVHcloud, et où se trouvent désormais les éléments de l’ancien AI Dashboard.

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

[[cpnav:publiccloud-projects]]

## En pratique

Dans la console OVHcloud, les outils IA sont regroupés sous **AI** dans le menu de gauche de votre projet : <code className="action">AI Notebooks</code>, <code className="action">AI Training</code>, <code className="action">AI Deploy</code>, <code className="action">AI Endpoints</code> et <code className="action">AI Agents</code>.

:::info
L'ancienne page **AI Dashboard** n'existe pas dans la console OVHcloud. Ses éléments transversaux (utilisateurs, tokens, registres et data stores) sont désormais regroupés sur la page **Configuration**, commune à AI Notebooks, AI Training et AI Deploy : les mêmes paramètres, valables pour tout le projet, s'affichent quel que soit le produit depuis lequel vous l'ouvrez.
:::

### Pages de liste des produits

Chaque page produit liste vos notebooks, jobs ou apps avec leur statut (par exemple **En cours** ou **Arrêté**), et donne accès à leur création (<code className="action">Créer un notebook</code>, <code className="action">Créer un job</code>, <code className="action">Créer une app</code>). Depuis ces pages, vous accédez facilement à [AI Notebooks](/guides/public-cloud/ai-machine-learning/ai-notebooks-definition), [AI Training](/guides/public-cloud/ai-machine-learning/ai-training-submit-job) et [AI Deploy](/guides/public-cloud/ai-machine-learning/ai-deploy-getting-started).

Vous pouvez trouver plus de détails sur les tarifs des outils IA [ici](/links/public-cloud/prices-ai).

### Page Configuration

Cliquez sur <code className="action">Configuration</code> sur la page de liste d'AI Notebooks, d'AI Training ou d'AI Deploy. La page contient les onglets suivants :

- <code className="action">Utilisateurs</code> : créez un utilisateur doté d'un rôle IA dédié, ou ouvrez la page des utilisateurs de votre projet avec <code className="action">Gérer les utilisateurs</code>. Pour savoir comment gérer vos utilisateurs, consultez le guide suivant : [Gérer les utilisateurs et rôles IA](/guides/public-cloud/ai-machine-learning/ai-users).
- <code className="action">Token</code> : créez, régénérez et supprimez les tokens d'application que vous pourrez ensuite utiliser avec vos notebooks, jobs ou apps.
- <code className="action">Registres Docker</code> : reliez vos registres Docker privés, et retrouvez les commandes pour pousser des images vers le registre partagé du projet (consultez le guide [Gérer les registres](/guides/public-cloud/ai-machine-learning/ai-manage-registries)).
- <code className="action">Dépôts Git privés</code> et <code className="action">Volumes S3</code> : reliez les dépôts Git privés et les volumes compatibles S3 que vos charges de travail IA peuvent utiliser.

### Interface en ligne de commande (CLI)

Les pages de création et les pages de détail des notebooks, jobs et apps affichent l'**Équivalent CLI** de votre configuration, sous forme de commandes `ovhai`. Pour installer et authentifier la CLI, consultez le [guide d'installation de la CLI](/guides/public-cloud/ai-machine-learning/ai-cli-install-client).
