## Objectif

OVHcloud propose un ensemble d’outils IA managés conçus pour la création de vos projets de machine learning.

Ce guide explique comment démarrer avec l’AI Dashboard d’OVHcloud, une vue consolidée de votre utilisation des outils IA d’OVHcloud.

## Prérequis

- Accès à l’<ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

## En pratique

L’AI Dashboard est accessible via le menu principal `AI & Machine Learning` dans la section `Public Cloud` de votre espace client OVHcloud.

:::info
**AI Dashboard** n’est pas un produit mais un aperçu des outils IA que vous utilisez, ainsi qu’une interface où vous retrouverez tous les éléments transversaux tels que les accès de sécurité, les informations relatives à la CLI et à la facturation, ou encore des guides (comme celui-ci).

:::


<img className="thumbnail" alt="Menu Dashboard" src="/images/public-cloud/ai-machine-learning/gi-06-dashboard-getting-started/dashboard-01.jpg" loading="lazy" />

Les chapitres suivants vous aideront à découvrir chaque section de l’`AI Dashboard`.

### Onglet Dashboard

<img className="thumbnail" alt="Onglet Dashboard" src="/images/public-cloud/ai-machine-learning/gi-06-dashboard-getting-started/dashboard-02.png" loading="lazy" />

Dans cette section, vous trouverez des informations relatives à votre utilisation des outils IA, avec un accès facile à [AI Notebooks](/guides/public-cloud/ai-machine-learning/ai-notebooks-definition), [AI Training](/guides/public-cloud/ai-machine-learning/ai-training-submit-job) et [AI Deploy](/guides/public-cloud/ai-machine-learning/ai-deploy-getting-started).  
Les instances listées sont celles dont le statut est `RUNNING` ou `STOPPED`.

Vous pouvez également accéder facilement à votre Object Storage.

Vous pouvez trouver plus de détails sur les tarifs des outils IA [ici](/links/public-cloud/prices-ai).

Vous pouvez aussi consulter les informations de sécurité avec le nombre d’utilisateurs et de tokens créés pour utiliser vos outils IA.

### Utilisateurs et tokens

<img className="thumbnail" alt="Onglet Utilisateurs et tokens" src="/images/public-cloud/ai-machine-learning/gi-06-dashboard-getting-started/dashboard-03.png" loading="lazy" />

Dans cette section, vous trouverez toutes les informations concernant vos utilisateurs et tokens IA.

Vous pouvez facilement créer de nouveaux utilisateurs Public Cloud avec des rôles dédiés aux outils IA (`AI Platform - Operator` ou `AI Platform - Read-Only`) et accéder à tous vos utilisateurs Public Cloud.

Vous pouvez également gérer les tokens (créer, modifier et supprimer) que vous pourrez ensuite utiliser avec vos notebooks, jobs ou apps.

Pour savoir comment gérer vos utilisateurs et tokens, veuillez consulter le guide suivant : [Gérer les utilisateurs et rôles IA](/guides/public-cloud/ai-machine-learning/ai-users).
