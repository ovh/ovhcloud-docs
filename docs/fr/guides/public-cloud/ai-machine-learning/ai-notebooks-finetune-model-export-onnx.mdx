## Objectif

L'objectif de ce tutoriel est de vous montrer comment **fine-tuner** un modèle PyTorch et l'exporter au format **ONNX** ([Open Neural Network Exchange](https://onnx.ai/)).

Pour cela, nous utilisons un modèle de **classification d'images** : [DenseNet](https://pytorch.org/hub/pytorch_vision_densenet/).

:::info
Les modèles DenseNet sont pré-entraînés sur le dataset [ImageNet](https://www.image-net.org/).

:::


L'objectif est de fine-tuner un modèle **DenseNet121** pour classifier des images de la vie quotidienne avec le dataset **CIFAR-10**. Il est composé de 10 classes :

- avion
- automobile
- oiseau
- chat
- cerf
- chien
- grenouille
- cheval
- bateau
- camion

*Trouvez plus d'informations sur le dataset CIFAR-10 via le [lien suivant](https://www.cs.toronto.edu/~kriz/cifar.html).*

À la fin de l'entraînement, le modèle DenseNet est sauvegardé au format PyTorch (`.pth`). Il sera ensuite transformé en ONNX.

Exporter votre modèle au format ONNX vous permet d'**optimiser l'inférence** d'un modèle de Machine Learning.

## En pratique

Vous pouvez lancer le notebook depuis l'<ManagerLink to="/">espace client OVHcloud</ManagerLink> ou via la [CLI](/guides/public-cloud/ai-machine-learning/ai-cli-run-notebook) ovhai.

### Lancer un notebook Jupyter avec « Conda » via l'interface (espace client)

Pour lancer votre notebook depuis l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>, suivez les étapes ci-dessous.

#### Éditeur de code

Choisissez l'éditeur de code `Jupyterlab`.

#### Framework

Dans ce tutoriel, le framework `conda` est utilisé.

#### Ressources

L'utilisation de GPU est recommandée pour entraîner le modèle de classification d'images : **densenet121**.

:::info
Ici, l'utilisation d'`1 GPU` est suffisante.

:::


### Lancer un notebook Jupyter avec « conda » via la CLI

*Si vous n'utilisez pas encore notre CLI, suivez [ce guide](/guides/public-cloud/ai-machine-learning/ai-cli-install-client) pour l'installer.*

Si vous souhaitez lancer votre notebook avec l'OVHcloud AI CLI, choisissez l'éditeur `jupyterlab` et le framework `conda`.

Pour accéder aux différentes versions de `conda` disponibles, exécutez la commande suivante :

```console
ovhai capabilities framework get conda -o yaml
```

Vous devrez également choisir le nombre de GPU à utiliser dans votre notebook, à l'aide de `<nb-gpus>`.

Pour lancer votre notebook, exécutez la commande suivante :

```console
ovhai notebook run conda jupyterlab \
		--name <notebook-name> \
		--framework-version conda-py310-cuda11.8-v22-4 \
		--gpu <nb-gpus>

```

Vous pourrez ensuite accéder à l'URL de votre notebook une fois celui-ci en cours d'exécution.

### Accéder aux notebooks

Une fois notre [dépôt d'exemples AI](https://github.com/ovh/ai-training-examples/) cloné dans votre environnement, retrouvez le tutoriel de fine-tuning en suivant ce chemin : `ai-training-examples` > `notebooks` > `go-further` > `onnx` > `notebook_finetune_densenet_export_onnx.ipynb`.

Un aperçu de ce notebook est disponible sur GitHub [ici](https://github.com/ovh/ai-training-examples/blob/main/notebooks/go-further/onnx/notebook_finetune_densenet_export_onnx.ipynb).
