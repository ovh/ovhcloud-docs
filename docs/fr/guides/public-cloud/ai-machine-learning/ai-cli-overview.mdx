## Objectif

Ce guide couvre l'utilisation de la CLI **ovhai**.

## Prérequis

-   une CLI `ovhai` fonctionnelle [comment installer la CLI ovhai](/guides/public-cloud/ai-machine-learning/ai-cli-install-client)

## En pratique

### Lancer un job

Pour soumettre un job, vous avez besoin d'une **image docker** et éventuellement de **données**.

Commençons par soumettre un job simple, une image ubuntu publique qui exécute une commande `echo` :

```console
ovhai job run ubuntu --gpu 1 -- echo "Hello from my first job"
```

:::info
* Ajoutez le flag `--help` pour obtenir plus d'informations sur une commande.
* Vous pouvez augmenter le nombre de GPUs avec le flag `--gpu <x>` ou choisir d'utiliser des CPUs avec le flag `--cpu <x>`.

:::


Vous pouvez ensuite lister vos jobs actuels et anciens avec :

```console
ovhai job list
```

:::info
* Ajoutez le flag `--watch` pour suivre les changements en direct.
* La plupart des commandes gèrent le flag `--output <format>` si vous souhaitez un format de sortie différent (JSON ou YAML)

:::


Vous devriez voir le job que vous venez d'exécuter, vous avez besoin de son `ID` pour obtenir plus d'informations à son sujet.

Pour voir les informations d'un job, utilisez la commande suivante :

```console
ovhai job get <job-id>
```

Pour voir ses logs en direct, utilisez la commande suivante :

```console
ovhai job logs <job-id> --follow
```

Vous devriez voir la sortie de la commande `echo` :
> Hello from my first job

### Utiliser des données dans votre job

Vous pouvez envoyer des données vers l'Object Storage et monter ces données lors de l'exécution d'un job. Si vous montez ces données en lecture/écriture, elles seront sauvegardées sur l'Object Storage à la fin du job.

Envoyons quelques données et utilisons-les dans un job qui produira davantage de données.

```console
ovhai bucket object upload `<container>`@`<region>` some-file.txt
```

:::info
* Si vous avez déjà utilisé la CLI Swift, les commandes sont similaires.

:::


Maintenant que vous avez des données dans un conteneur, vous pouvez les monter lors de l'exécution d'un job avec le flag `--volume`.

```console
ovhai job run <image> --volume <container>@<region>:/data:rw
```

:::info
* Vous pouvez utiliser le flag `--volume` plusieurs fois si vous souhaitez monter plusieurs conteneurs.
* Les conteneurs montés avec accès en écriture ne sont synchronisés qu'à la fin du job.

:::


Vous pouvez lister et télécharger les données que vous avez envoyées ou générées par un job avec :

```console
ovhai bucket object list `<container>`@`<region>`
ovhai bucket object download `<container>`@`<region>` --prefix /some-data
```

### Synchroniser des données pendant l'exécution d'un job

Vous pouvez synchroniser des données vers l'Object Storage pendant l'exécution d'un job avec :

```console
ovhai job push-data `<job-id>`
```

Vous pouvez suivre la progression avec :

```console
ovhai job get `<job-id>`
```

### Exécuter des commandes à l'intérieur d'un job en cours d'exécution

Vous pouvez exécuter des commandes (comme `bash`) pendant qu'un job est en cours d'exécution.

```console
ovhai job exec -it <id> -- bash
```

Cela vous permet d'interagir avec un job en cours d'exécution.

### Lancer un job avec un accès ssh

```console
ovhai job run -s ~/.ssh/id_ed25519.pub ovhcom/ai-training-fastai
```

### Gérer les registres

Vous pouvez lister les registres disponibles avec :

```console
ovhai registry list
```

Par défaut, vous avez accès à des registres publics, ainsi qu'à un registre partagé rattaché à votre projet.

:::warning
Ce registre partagé peut vous aider à réaliser vos tests, mais ne doit pas être utilisé en production, car nous nous réservons le droit de supprimer son contenu si cela s'avère nécessaire. Les images envoyées vers ce registre sont destinées uniquement aux charges de travail AI Tools, et ne seront pas accessibles pour des usages externes.
:::


C'est pourquoi il peut être intéressant d'ajouter et de gérer d'autres registres. Pour ajouter un registre privé, utilisez :

```console
ovhai registry add `<url>`
```

Il vous sera demandé de saisir vos identifiants.

Vous trouverez plus d'informations sur l'ajout et la gestion des registres publics et privés [ici](/guides/public-cloud/ai-machine-learning/ai-manage-registries).

### Changer de région dans la CLI

Les régions disponibles pour installer et utiliser la CLI `ovhai` sont `GRA` et `BHS`. Si vous souhaitez changer de région dans la CLI, vous pouvez utiliser les commandes suivantes.

Vous pouvez lister les **noms** et **URLs** des régions disponibles avec :

```console
ovhai config list
```

:::info
La région en **vert** est celle dans laquelle vous vous trouvez actuellement.
:::


Pour changer de région, utilisez :

```console
ovhai config set <region>
```

:::info
`<region>` est le nom de la nouvelle région (`GRA` ou `BHS`), dans laquelle vous souhaitez être placé.
:::
