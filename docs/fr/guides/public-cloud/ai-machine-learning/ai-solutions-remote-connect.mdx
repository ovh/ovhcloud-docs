## Objectif

Ce tutoriel couvre le processus de démarrage d'un job à l'aide d'une connexion Visual Studio Code Remote via SSH.

## Prérequis

- Un AI Notebook ou un AI Training Project créé dans un [Public Cloud project](/links/public-cloud/public-cloud) de votre compte OVHcloud
- Un [utilisateur AI](/guides/public-cloud/ai-machine-learning/ai-users)
- [La CLI OVHcloud AI](/guides/public-cloud/ai-machine-learning/ai-cli-install-client) installée sur votre ordinateur

[[cpnav:publiccloud-ai-notebooks]]

## En pratique

### Installation

1. Installez un [client SSH compatible OpenSSH](https://code.visualstudio.com/docs/remote/troubleshooting#_installing-a-supported-ssh-client) si vous n'en avez pas déjà un.
2. Installez [Visual Studio Code](https://code.visualstudio.com/).
3. Installez le [pack d'extensions Remote Development](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.vscode-remote-extensionpack).

### Générer une paire de clés SSH

Si vous n'avez pas encore de clé SSH, vous devrez en créer une. Pour cela, ouvrez un terminal / PowerShell, et exécutez la commande de génération de clé :

```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```

:::info
- `-t ed25519` crée une clé moderne et sécurisée (recommandé).
- `-C` vous permet d'ajouter un label (généralement votre email) pour identifier la clé.

:::


Cela créera une clé privée (par exemple, `id_ed25519`, à ne pas partager) et une clé publique (par exemple, `id_ed25519.pub`) dans votre répertoire `~/.ssh/`.

### Spécifier la clé SSH lors de la création d'un AI Notebook ou d'un job AI Training

Voici comment ajouter votre clé SSH à votre solution AI si vous utilisez la <ManagerLink to="/">console OVHcloud</ManagerLink> ou la CLI `ovhai` :

<Tabs>
  <Tab label="Console OVHcloud">
    Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">AI Notebooks</code> ou <code className="action">AI Training</code> sous **AI**.

    Cliquez ensuite sur <code className="action">Créer un notebook</code> ou <code className="action">Créer un job</code> pour configurer et créer votre solution AI.

    Renseignez les différentes informations demandées jusqu'à atteindre la section **Configuration avancée**. Activez l'interrupteur **Clé SSH**, puis cliquez sur <code className="action">Ajouter une clé SSH</code>.

    Dans la fenêtre qui s'ouvre, sélectionnez **Clé existante** pour choisir l'une des clés de votre projet, ou **Nouvelle clé** pour en enregistrer une nouvelle : saisissez un **Nom** et collez le contenu de votre fichier de clé publique (par exemple `id_ed25519.pub`) dans le champ **Clé publique**. Cliquez ensuite sur <code className="action">Ajouter</code>.

    Le nombre de clés configurées s'affiche sous la liste (par exemple `1 / 10 clés`).
  </Tab>
  <Tab label="CLI ovhai">
    Pour suivre cette partie, assurez-vous d'avoir installé la [CLI ovhai](/guides/public-cloud/ai-machine-learning/ai-cli-install-client) sur votre ordinateur ou sur une instance.
    
    Lors de la création de votre ressource AI avec la CLI `ovhai`, spécifiez la clé publique SSH à l'aide de l'option `--ssh-public-keys`, ou de son raccourci `-s` :
    
    ```bash
    ovhai job run <job_image> \
      --gpu <nb-gpus> \
      --ssh-public-keys ~/.ssh/id_ed25519.pub
    ```
    
    Une fois le job à l'état `Running`, vous pouvez voir la `sshUrl` en récupérant les informations de votre job :
    
    ```bash
    ovhai job get <job-id>
    ```
  </Tab>
</Tabs>


Une fois votre job créé, quelle que soit la méthode choisie, vous pourrez copier l'id de votre job (par exemple, `bfa1d77a-9746-4128-9974-f94139937927`), qui sera nécessaire dans les étapes suivantes.

:::warning
Pour fonctionner, l'image déployée doit contenir le binaire `bash` et une distribution Linux basée sur glibc (Ubuntu / Debian).

:::


### Vérifier que vous pouvez vous connecter à l'hôte SSH

Avant de continuer, vous pouvez vérifier que vous pouvez accéder à votre job en exécutant la commande suivante depuis une fenêtre terminal / PowerShell, en remplaçant `<job-id>` par l'ID de votre job et `<region>` par l'emplacement de votre ressource (par exemple, `gra`, `bhs`) :

```bash
ssh <job-id>@<region>.ai.cloud.ovh.net
```

Si la clé SSH est bien configurée, vous devriez voir ceci :

```
Welcome to OVHcloud!
ovh@job-36ed1f18-626b-42f7-b15f-0ed844e65d20:~$
```

### Configurer la connexion distante VSCode

Dans Visual Studio Code, cliquez sur l'icône <code className="action">Remote Explorer</code>.

<img className="thumbnail" alt="Barre d'activité de VS Code avec l'icône Remote Explorer sélectionnée" src="/images/public-cloud/ai-machine-learning/gi-03-remote-connection/vscode-1.png" loading="lazy" />

À partir de là, cliquez sur l'icône en forme d'engrenage de la fonctionnalité SSH pour accéder au fichier de configuration SSH de VSCode, généralement situé à `~/.ssh/config`, et ouvrez-le.

<img className="thumbnail" alt="Remote Explorer de VS Code ouvrant la sélection du fichier de configuration SSH" src="/images/public-cloud/ai-machine-learning/gi-03-remote-connection/vscode-2.png" loading="lazy" />

Ajoutez la section suivante pour votre nouvel hôte :

```
Host my_ai_training_job
HostName <region>.ai.cloud.ovh.net # Adapt to your resource location (gra, bhs)
User bfa1d77a-9746-4128-9974-f94139937927 # ID of your AI Training Job or AI Notebook
IdentityFile C:\Path\To\id_ed25519 # Path to your private key file (not .pub)
```

Enregistrez le fichier `config`. Puis actualisez les ressources distantes en cliquant sur cette icône :

<img className="thumbnail" alt="Bouton Refresh de la liste des hôtes SSH de VS Code" src="/images/public-cloud/ai-machine-learning/gi-03-remote-connection/vscode-3.png" loading="lazy" />

Votre ressource devrait maintenant apparaître dans le menu SSH à gauche. Connectez-vous à celle-ci en cliquant sur la flèche à côté de votre ressource. VSCode redémarrera pour se connecter à votre ressource distante :

<img className="thumbnail" alt="Liste des hôtes SSH affichant my_ai_training_job avec l'action Connect in New Window" src="/images/public-cloud/ai-machine-learning/gi-03-remote-connection/vscode-4.png" loading="lazy" />

Si la connexion est bien établie, vous devriez voir ce message dans le coin inférieur gauche de VSCode :

<img className="thumbnail" alt="Barre d'état de VS Code confirmant la connexion SSH à my_ai_training_job" src="/images/public-cloud/ai-machine-learning/gi-03-remote-connection/vscode-5.png" loading="lazy" />

### Développer et exécuter votre code

Une fois connecté, vous pouvez commencer à développer et exécuter votre code dans le dossier par défaut `/workspace`, en cliquant sur le bouton bleu <code className="action">Open folder</code>, et en sélectionnant `/workspace`.

<img className="thumbnail" alt="Invite Open Folder listant le contenu du répertoire workspace distant" src="/images/public-cloud/ai-machine-learning/gi-03-remote-connection/vscode-6.png" loading="lazy" />

Vous pouvez également ouvrir un terminal et y exécuter des commandes. Profitez-en !

<img className="thumbnail" alt="Terminal VS Code exécutant nvidia-smi sur le job distant et affichant un GPU NVIDIA H100 PCIe" src="/images/public-cloud/ai-machine-learning/gi-03-remote-connection/vscode-7.png" loading="lazy" />
