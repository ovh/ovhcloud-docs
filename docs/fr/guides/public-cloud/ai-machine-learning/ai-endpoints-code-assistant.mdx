## Introduction

### Qu’est-ce que Continue ?

**[Continue](https://www.continue.dev/)** est un assistant IA agnostique vis-à-vis de l’IDE qui intègre directement le chat, la génération de code et l’autocomplétion dans votre éditeur. Compatible avec VS Code et les IDE JetBrains (IntelliJ, PyCharm, etc.), Continue vous permet de brancher n’importe quel LLM compatible hébergé sur **[AI Endpoints](/links/public-cloud/ai-endpoints)**.

Continue vous permet de configurer et d’utiliser vos propres LLM, vous donnant un contrôle total sur les modèles que vous utilisez et sur la façon dont ils interagissent avec votre code.

Ce tutoriel décrit comment configurer Continue pour se connecter aux LLM d’AI Endpoints, permettant à ces modèles de s’intégrer à votre éditeur afin d’améliorer l’efficacité, la précision et la productivité de vos développements.

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un token d’accès pour **OVHcloud AI Endpoints**. Pour créer un token API, suivez les instructions du guide [AI Endpoints - Premiers pas](/guides/public-cloud/ai-machine-learning/ai-endpoints-getting-started).

## En pratique

### Installer Continue

Suivez les [instructions officielles d’installation de Continue](https://docs.continue.dev/docs/getting-started/install) pour votre IDE.

Une fois installé, Continue partagera la même configuration entre vos IDE.

### Configurer Continue avec AI Endpoints

Continue utilise un fichier de configuration au format YAML pour gérer :

- Les modèles utilisés par l’outil de chat
- Les modèles utilisés pour l’autocomplétion (Tab)

Vous pouvez personnaliser ce fichier de configuration pour connecter le plugin à AI Endpoints :

## Configuration de Continue pour OVHcloud AI Endpoints

```yaml
name: ide-configuration
version: 0.0.1
schema: v1
models:
  - name: Meta-Llama-3_3-70B-Instruct
    provider: openai
    model: Meta-Llama-3_3-70B-Instruct
    apiBase: https://oai.endpoints.kepler.ai.cloud.ovh.net/v1
    apiKey: <you AI Endpoint API key> # replace with your API key
    roles: [chat, edit, apply, summarize]
  - name: Qwen3-Coder-30B-A3B-Instruct
    provider: openai
    model: Qwen3-Coder-30B-A3B-Instruct
    apiBase: https://oai.endpoints.kepler.ai.cloud.ovh.net/v1
    apiKey: <you AI Endpoint API key> # replace with your API key
    roles: [chat, edit, apply, summarize, autocomplete]
```

:::info
Une fois votre fichier de configuration modifié, veillez à le recharger avant d’essayer d’interagir avec vos modèles configurés !
:::


Essayez différents LLM de [notre catalogue](/links/public-cloud/ai-endpoints-catalog) et choisissez celui qui correspond le mieux à votre cas d’usage. Vous pouvez facilement passer de l’un à l’autre depuis l’interface de l’IDE.

### Testez la configuration

Une fois Continue configuré avec vos AI Endpoints, vous êtes prêt à tester les deux fonctionnalités :

**Outil de chat**

Utilisez la barre latérale du chatbot pour demander de l’aide, générer du code ou refactoriser de la logique avec l’un de vos modèles configurés.

### Dépannage

- **Le modèle ne se charge pas** : vérifiez l’URL `apiBase` et assurez-vous que la variable `apiKey` est correctement définie.
- **L’autocomplétion ne fonctionne pas** : assurez-vous que le rôle du modèle inclut `autocomplete` et que le modèle sélectionné prend en charge cette fonctionnalité.
- **Erreurs de connexion** : vérifiez la connectivité réseau et confirmez que votre `apiKey` est valide.
