## Introduction

Un **notebook** est un document qui intègre du code, des éléments de texte enrichi et du multimédia, ce qui en fait un outil pratique pour l'analyse de données, la visualisation et les tâches de Machine Learning.

**OVHcloud AI Notebooks** est notre solution managée pour les notebooks Jupyter et VSCode. Vous pouvez facilement lancer des notebooks avec les ressources CPU et GPU nécessaires tout en bénéficiant d'avantages tels que des dépendances et frameworks AI préinstallés (par exemple TensorFlow, PyTorch, Hugging Face, Scikit-learn, ...), un accès utilisateur sécurisé et une gestion simplifiée des données.

L'avantage par rapport à une configuration réalisée par vous-même est que tout est déjà installé, et que vous ne payez que pour vos AI Notebooks pendant qu'ils fonctionnent.

## Objectif

Ce guide montre comment créer, configurer, accéder, arrêter, redémarrer et supprimer des AI Notebooks depuis plusieurs interfaces :

- L'**espace client OVHcloud (UI)** est convivial et idéal pour les débutants.
- L'interface en ligne de commande (CLI) **ovhai**
- L'**API AI**
- Le SDK Python **ovhai**

Chaque méthode offre ses propres avantages, selon votre niveau d'expertise et le workflow que vous préférez.

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un utilisateur Public Cloud avec les rôles **Administrator** ou **AI Training Operator & Objectstore Operator**, voir [ici](/guides/public-cloud/ai-machine-learning/ai-users) pour plus d'informations

### Lancer votre premier AI Notebook

Pour créer un AI Notebook, suivez ces étapes :

**3\. Ressources de calcul**
    
    Spécifiez et ajustez le type et la quantité de ressources de calcul (CPU / GPU) pour votre AI Notebook. Utilisez les boutons <code className="action">+</code> et <code className="action">-</code> pour augmenter ou diminuer le nombre de CPU et de GPU, selon vos besoins.

    Ensuite, choisissez le framework AI que vous souhaitez utiliser, qui sera préinstallé et prêt à l'emploi au lancement de votre AI Notebook. Un large éventail de frameworks de Machine Learning est disponible, dans différentes versions. Sélectionnez la version qui correspond à vos besoins. Ce guide utilisera _PyTorch_ comme exemple.

**5\. Éditeur de code en direct**
    
    Choisissez l'éditeur de code que vous souhaitez.
    
    Dans cet exemple, nous utilisons *JupyterLab*, mais vous avez également la possibilité de choisir *Visual Studio Code*. Les deux ont leurs propres avantages et inconvénients. Jupyter Notebook est généralement considéré comme plus facile à utiliser pour les débutants.
    
    <img className="thumbnail" alt="Créer un notebook depuis l\'espace client 06" src="/images/public-cloud/ai-machine-learning/notebook-guide-introduction-definition/creating-a-notebook-using-UI-06.png" loading="lazy" />

**6\. Paramètres de confidentialité**
    
    Ensuite, sélectionnez vos paramètres de confidentialité.
    
    :::warning
    L'*accès public* exposera vos données et votre code à toute personne obtenant le lien de l'AI Notebook. Soyez prudent(e) et ne l'utilisez pas avec des données sensibles. À l'inverse, l'*accès restreint* demandera une combinaison utilisateur/mot de passe ou un token AI pour accéder au contenu du notebook, garantissant ainsi un environnement sécurisé.

    :::

    
    <img className="thumbnail" alt="Créer un notebook depuis l\'espace client 07" src="/images/public-cloud/ai-machine-learning/notebook-guide-introduction-definition/creating-a-notebook-using-UI-07.png" loading="lazy" />

**7\. Cycle de vie du notebook**
    
    :::warning
    Notre principale motivation est de maintenir la plateforme à jour en termes de correctifs de sécurité et d'alignement avec les nouvelles fonctionnalités. Pour y parvenir, nous devons de temps à autre mettre à jour et redémarrer les hôtes, ce qui nécessite qu'ils soient libres de toute charge de travail client.

    :::

    
    Par défaut, votre AI Notebook s'arrêtera automatiquement après 7 jours consécutifs passés à l'état RUNNING. Rassurez-vous, tous vos paramètres et données seront conservés. Vous avez la possibilité d'activer le redémarrage automatique, qui redémarrera automatiquement votre notebook tous les 7 jours, garantissant une perturbation minimale de votre travail. Vous pouvez également contacter [notre support](https://help.ovhcloud.com/csm?id=csm_get_help) pour prolonger cette période de redémarrage automatique de 7 à 28 jours.
    
    <img className="thumbnail" alt="Créer un notebook depuis l\'espace client 08" src="/images/public-cloud/ai-machine-learning/notebook-guide-introduction-definition/creating-a-notebook-using-UI-08.png" loading="lazy" />

**8\. Configuration avancée**
    
    *Cette étape est optionnelle.*
    
    Par défaut, votre AI Notebook est fourni avec un **stockage éphémère** (stockage local). Mais à cette étape, vous pouvez également lier des conteneurs Object Storage et des dépôts Git à votre AI Notebook, pour accéder facilement à vos données distantes.
    
    Si vous souhaitez en savoir plus sur la configuration des conteneurs et des dépôts Git dans le notebook, vous pouvez vous référer à cette [documentation](/guides/public-cloud/ai-machine-learning/ai-notebooks-manage-data-ui). Pour l'instant, nous allons lancer un notebook classique sans volume externe ajouté.
    
    Ensuite, vous avez la possibilité de définir des labels. Cela permet de spécifier l'un de vos tokens AI et de l'appliquer à ce nouvel AI Notebook. Ce token AI peut ensuite être partagé avec toute personne devant avoir accès au notebook, lui permettant d'y accéder sans avoir besoin de vos propres identifiants de projet Public Cloud. Ceci est utile si vous souhaitez fournir un accès à l'AI Notebook en dehors de votre projet Public Cloud. Plus d'informations [ici](/guides/public-cloud/ai-machine-learning/ai-cli-app-token).
    
    Enfin, les **clés publiques SSH** vous permettent d'accéder à votre notebook à distance.

  <Tab label="Via le SDK Python">
    La bibliothèque *ovhai* est un client Python qui permet aux développeurs d'utiliser facilement l'API AI OVHcloud. Avec ce SDK, vous pouvez exécuter, gérer et automatiser vos AI Notebooks.
    
    :::warning
    **Avertissement Alpha** : ce package est actuellement en **phase alpha** de développement. Les API et fonctionnalités du package peuvent ne pas être entièrement testées.

    :::

    
    Pour lancer un AI Notebook en utilisant le [SDK Python ovhai](https://pypi.org/project/ovhai/), vous devez d'abord installer la bibliothèque *ovhai*. Vous pouvez le faire à l'aide de `pip`. Ouvrez votre terminal et exécutez la commande suivante :
    
    ```bash
    pip install ovhai
    ```
    
    Une fois installée, nous vous invitons à suivre les instructions fournies sur la page [ovhai PyPI](https://pypi.org/project/ovhai/) pour apprendre à créer un token d'authentification, comprendre le fonctionnement du SDK et lancer un AI Notebook en utilisant le SDK Python *ovhai*.
    
    Voici un exemple simple pour vous aider à démarrer facilement :
    
    ```python
    from ovhai import AuthenticatedClient
    from ovhai.api.notebook import notebook_new
    from ovhai.models import NotebookSpec, Notebook
    from ovhai.ovhai_types import Response
    
    client = AuthenticatedClient(
        base_url="https://gra.training.ai.cloud.ovh.net",
        token="YOUR_AI_TOKEN",
    )
    
    # Define notebook parameters
    editor_id = "jupyterlab"
    framework_id = "conda"
    framework_version = "conda-py311-cudaDevel11.8"
    nb_cpu = 2
    
    # Create the notebook creation request
    notebook_specs = {
        "env": {"editorId": editor_id, "frameworkId": framework_id, "frameworkVersion": framework_version},
        "resources": {"cpu": nb_cpu},
    }
    
    with client as client:
        response: Response[Notebook] = notebook_new.sync_detailed(
            client=client, body=NotebookSpec.from_dict(notebook_specs)
        )
        
        import json
        response_content = response.content.decode('utf-8')  # Decode bytes to a string
        response_dict = json.loads(response_content)
    
        status_code = response.status_code
        id_ = response_dict['id']
        spec = response_dict['spec']
        status = response_dict['status']
        state = status['state']
        info = status['info']
        url = response_dict['status']['url']
    
        print(f"Status code: {status_code}")
        print(f"ID: {id_}")
        print(f"Spec: {spec}")
        print(f"State: {state}")
        print(f"Info: {info}")
        print(f"URL: {url}")
    ```
    
    Assurez-vous de remplacer `YOUR_AI_TOKEN` par un bearer token. Les bearer tokens peuvent être créés via l'[AI Dashboard](/guides/public-cloud/ai-machine-learning/ai-dashboard-getting-started) ou en utilisant la CLI *ovhai*. Pour des instructions plus détaillées sur la création d'un token, veuillez consulter la documentation [Gérer les tokens d'accès](/guides/public-cloud/ai-machine-learning/ai-cli-app-token).
    
    L'exécution de ce code lancera un nouvel AI Notebook basé sur les spécifications que vous avez fournies. N'hésitez pas à ajuster les spécifications selon le notebook que vous souhaitez créer.

  <Tab label="Via le SDK Python">
    Si vous n'avez plus l'`UUID` et l'`URL` du notebook affichés dans votre IDE Python, vous pouvez facilement lister tous vos AI Notebooks en exécutant :
    
    ```python
    from ovhai.api.notebook import notebook_get_all
    from ovhai.models import NotebookList
    from ovhai.ovhai_types import Response
    
    from ovhai import AuthenticatedClient
    
    client = AuthenticatedClient(
        base_url="https://gra.training.ai.cloud.ovh.net",
        token="YOUR_AI_TOKEN",
    )
    
    with client as client:
        response: Response[NotebookList] = notebook_get_all.sync_detailed(client=client)
        import json
        response = json.loads(response.content.decode())
        for notebook_info in response["items"]:
            print(f"ID: {notebook_info['id']}")
            print(f"Name: {notebook_info['spec']['name']}")
            print(f"Status: {notebook_info['status']['state']}")
            print(f"Framework: {notebook_info['spec']['env']['frameworkId']}")
            print(f"Framework version: {notebook_info['spec']['env']['frameworkVersion']}")
            print(f"Editor: {notebook_info['spec']['env']['editorId']}")
            print(f"Access link: {notebook_info['status']['url']}")
            print("---------------")
    ```
    
    Cela vous permettra de récupérer l'`URL` du notebook auquel vous souhaitez accéder. Assurez-vous simplement d'utiliser la bonne URL d'API, et remplacez `YOUR_AI_TOKEN` par votre token AI réel.
    
    Vous pouvez également obtenir toutes les informations relatives à un notebook (spécifications, Access Url, Monitoring URL, ...) en exécutant le code suivant :
    
    ```python
    from ovhai.api.notebook import notebook_get
    from ovhai import AuthenticatedClient
    import json
    
    client = AuthenticatedClient(
        base_url="https://gra.training.ai.cloud.ovh.net",
        token="YOUR_AI_TOKEN",
    )
    id = "YOUR_NOTEBOOK_UUID"
    
    with client as client:
        response = notebook_get.sync_detailed(
            id=id, client=client
        )
    
    print(json.loads(response.content.decode()))
    ```

### Se connecter à votre AI Notebook

Une fois que vous avez cliqué sur l'`URL` du notebook, vous serez redirigé(e) vers la page du notebook correspondant. Pour les notebooks en *accès restreint*, vous devrez vous authentifier pour vérifier que vous disposez des droits requis pour y accéder.

Pour les notebooks en *accès public*, aucune authentification ne sera nécessaire, vous arriverez donc directement sur le notebook avec vos données et votre code exposés.

Il existe deux méthodes d'authentification pour un notebook restreint : utiliser une combinaison **nom d'utilisateur et mot de passe** ou utiliser un **token d'accès**.

### Arrêter un AI Notebook

Vous pouvez arrêter votre AI Notebook à tout moment. Cela libérera ses ressources de calcul mais conservera les données de votre notebook et les bibliothèques installées. Par conséquent, vous ne serez plus facturé(e) pour le calcul à moins de redémarrer le notebook. Cependant, le stockage attaché sera facturé au tarif d'OVHcloud Object Storage. Consultez la [documentation sur la facturation d'AI Notebooks](/guides/public-cloud/ai-machine-learning/ai-notebooks-billing) pour plus d'informations.

En effet, lorsque vous arrêtez un notebook, il sera indisponible pendant une certaine période le temps que vos données soient synchronisées vers l'Object Storage, afin que vous puissiez récupérer votre travail plus tard. Une fois la synchronisation terminée, le notebook atteindra l'état `STOPPED`, à partir duquel vous pourrez soit le redémarrer, soit le supprimer.

    Ensuite, sélectionnez le notebook que vous souhaitez arrêter en cliquant sur son `Name`.
    
    À partir de là, vous pourrez cliquer sur le bouton d'arrêt <code className="action">🔴</code> :
    
    <img className="thumbnail" alt="Arrêter un notebook depuis l'espace client" src="/images/public-cloud/ai-machine-learning/notebook-guide-introduction-definition/stopping-a-notebook-using-UI.png" loading="lazy" />

    Assurez-vous de remplacer `<NOTEBOOK_UUID>` par l'UUID du notebook que vous souhaitez arrêter.

### Redémarrer un notebook

Lorsque votre notebook est à l'état `RUNNING`, vous pourriez vouloir le redémarrer pour actualiser l'environnement ou appliquer des mises à jour tout en conservant toutes vos données et paramètres.

L'opération de redémarrage **ne déclenchera pas de processus de synchronisation des données**, ce qui signifie que les données et paramètres de votre notebook seront conservés sans nécessiter le processus chronophage de copie des données.

Si vous avez activé la fonctionnalité de redémarrage automatique, votre notebook redémarrera automatiquement tous les 7 jours sans nécessiter d'intervention manuelle. Vous avez également la possibilité d'étendre cette période à 28 jours en contactant notre [support](https://help.ovhcloud.com/csm?id=csm_get_help).

### Supprimer un notebook

Si vous n'avez plus besoin de votre notebook, vous pouvez le supprimer.

Supprimer un notebook signifie également que vous supprimerez le stockage local du notebook. Ces données ne pourront pas être récupérées une fois le notebook supprimé. Cependant, tout Object Storage distant monté sur l'AI Notebook lors de sa création ne sera pas supprimé.

<Tabs>
  <Tab label="Depuis l'espace client (UI)">
    Si vous souhaitez **supprimer** complètement votre AI Notebook, cliquez simplement sur le bouton <code className="action">...</code>, puis sélectionnez l'action <code className="action">Supprimer</code>.
    
    <img className="thumbnail" alt="Supprimer un notebook depuis l'espace client" src="/images/public-cloud/ai-machine-learning/notebook-guide-introduction-definition/deleting-a-notebook-using-UI.png" loading="lazy" />
  </Tab>
  <Tab label="Depuis la CLI ovhai">
    Si vous souhaitez **supprimer** complètement votre AI Notebook, exécutez simplement la commande suivante :
    
    ```bash
    ovhai notebook delete `<NOTEBOOK_UUID>`
    ```
    
    Si le notebook est toujours à l'état `RUNNING`, un message de confirmation apparaîtra, vous demandant de confirmer l'action. Ne confirmez que si vous êtes sûr(e) de vouloir supprimer le notebook.
  </Tab>
  <Tab label="Via l'API AI">
    Sélectionnez l'endpoint <code className="action">Delete permanently a notebook</code>, qui est une méthode DELETE. Fournissez l'UUID du notebook que vous souhaitez supprimer. Utilisez le paramètre `force` si votre notebook n'est pas `STOPPED` et est toujours `RUNNING`. Ensuite, cliquez sur le bouton <code className="action">Send API request</code> pour envoyer la requête.
    
    Si la requête réussit, le notebook sera supprimé et un message 'No content' s'affichera dans le panneau 'Response'. Si la requête échoue, un message d'erreur s'y affichera.
    
    <img className="thumbnail" alt="Delete a Notebook API" src="/images/public-cloud/ai-machine-learning/notebook-guide-introduction-definition/deleting-a-notebook-using-API.png" loading="lazy" />
  </Tab>
  <Tab label="Via le SDK Python">
    Voici un exemple montrant comment supprimer un notebook en utilisant le SDK Python :
    
    ```python
    from ovhai.api.notebook import notebook_delete
    from ovhai import AuthenticatedClient
    
    client = AuthenticatedClient(
        base_url="https://gra.training.ai.cloud.ovh.net",
        token="YOUR_AI_TOKEN",
    )
    id = "YOUR_NOTEBOOK_UUID"
    
    with client as client:
        response = notebook_delete.sync_detailed(
            id=id, client=client, force=False
        )
    
        print(response.content.decode())
    ```
    
    Remplacez `YOUR_AI_TOKEN` par votre token AI réel et `YOUR_NOTEBOOK_UUID` par l'`UUID` du notebook que vous souhaitez supprimer. Si le notebook est toujours à l'état `RUNNING`, vous devrez définir le paramètre `force` sur `True` pour supprimer le notebook.
  </Tab>
</Tabs>


Une fois l'AI Notebook supprimé, vous ne devriez plus le voir lors du listage de vos AI Notebooks existants.
