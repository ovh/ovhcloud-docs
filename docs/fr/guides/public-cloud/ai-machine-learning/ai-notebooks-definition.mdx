## Introduction

Un **notebook** est un document qui intègre du code, des éléments de texte enrichi et du multimédia, ce qui en fait un outil pratique pour l'analyse de données, la visualisation et les tâches de Machine Learning.

**OVHcloud AI Notebooks** est notre solution managée pour les notebooks Jupyter et VSCode. Vous pouvez facilement lancer des notebooks avec les ressources CPU et GPU nécessaires tout en bénéficiant d'avantages tels que des dépendances et frameworks AI préinstallés (par exemple TensorFlow, PyTorch, Hugging Face, Scikit-learn, ...), un accès utilisateur sécurisé et une gestion simplifiée des données.

L'avantage par rapport à une configuration réalisée par vous-même est que tout est déjà installé, et que vous ne payez que pour vos AI Notebooks pendant qu'ils fonctionnent.

## Objectif

Ce guide montre comment créer, configurer, accéder, arrêter, redémarrer et supprimer des AI Notebooks depuis plusieurs interfaces :

- La **console OVHcloud (UI)** est conviviale et idéale pour les débutants.
- L'**API AI**
- L'interface en ligne de commande (CLI) **ovhai**
- Le SDK Python **ovhai**

Chaque méthode offre ses propres avantages, selon votre niveau d'expertise et le workflow que vous préférez.

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un utilisateur Public Cloud avec les rôles **Administrator** ou **AI Operator & ObjectStore operator**, voir [ici](/guides/public-cloud/ai-machine-learning/ai-users) pour plus d'informations

### Lancer votre premier AI Notebook

Pour créer un AI Notebook, suivez ces étapes :

<Tabs>
  <Tab label="Console OVHcloud">
    La console OVHcloud est le moyen le plus intuitif de lancer un AI Notebook. Pour commencer, suivez ces étapes :

    Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">AI Notebooks</code> sous **AI**.

    Une fois sur cette page, vous pouvez créer votre premier notebook en cliquant sur le bouton <code className="action">Créer un notebook</code>.

    La page **Créer un notebook** s'ouvre : renseignez les informations qui définissent la configuration de votre AI Notebook (éditeur de code, framework préinstallé, ressources de calcul, etc.). Un récapitulatif de votre configuration et son prix estimé par heure s'affichent sur la droite.

    **1\. Nom**

    Donnez un nom à votre AI Notebook. Cela facilitera sa gestion lorsque vous aurez créé plusieurs AI Notebooks.

    **2\. Région**

    Sélectionnez ensuite la région dans laquelle s'exécute votre notebook.

    **3\. Flavor**

    Sélectionnez le matériel sur lequel tourne votre notebook (flavor CPU ou GPU) dans le tableau **Flavor**, puis ajustez la **Quantité** de ressources selon vos besoins.

    **4\. Framework**

    Choisissez ensuite le framework AI que vous souhaitez utiliser, qui sera préinstallé et prêt à l'emploi au lancement de votre AI Notebook. Un large choix de frameworks de Machine Learning est disponible, en différentes versions. Sélectionnez la **Version** adaptée à vos besoins. Ce guide utilise _PyTorch_ comme exemple.

    **5\. Éditeur**

    Choisissez l'éditeur de code que vous souhaitez.

    Dans cet exemple, nous utilisons *JupyterLab*, mais vous pouvez également choisir *Visual Studio Code*. Chacun a ses avantages et ses inconvénients. Jupyter Notebook est généralement considéré comme plus simple à prendre en main pour les débutants.

    **6\. Confidentialité**

    Sélectionnez ensuite vos paramètres de confidentialité : **Privé** (l'accès requiert un jeton) ou **Public** (accès sans jeton).

    :::warning
    L'*accès public* exposera vos données et votre code à toute personne disposant du lien de l'AI Notebook. Soyez prudent et ne l'utilisez pas avec des données sensibles. À l'inverse, l'*accès privé* demandera une combinaison utilisateur/mot de passe ou un token AI pour accéder au contenu du notebook, garantissant un environnement sécurisé.

    :::

    **7\. Expiration**

    :::warning
    Notre principale motivation est de maintenir la plateforme à jour en termes de correctifs de sécurité et d'alignement des nouvelles fonctionnalités. Pour cela, nous devons mettre à jour et redémarrer les hôtes de temps en temps, ce qui nécessite qu'ils soient libérés de toute charge de travail client.

    :::

    Par défaut, votre AI Notebook s'arrêtera automatiquement après 7 jours consécutifs à l'état RUNNING. Soyez assuré que tous vos paramètres et vos données seront conservés. Vous pouvez activer **Redémarrer automatiquement après expiration**, qui redémarrera automatiquement votre notebook tous les 7 jours, limitant ainsi l'impact sur votre travail. Vous pouvez également contacter [notre support](/links/support-contact) pour étendre cette période à 28 jours.

    **8\. Configuration avancée**

    *Cette étape est facultative.*

    Par défaut, votre AI Notebook dispose d'un **stockage éphémère** (stockage local). Mais dans cette étape, vous pouvez également associer des conteneurs Object Storage (**Volumes**) et des dépôts Git (**Git Public**) à votre AI Notebook, afin d'accéder facilement à vos données distantes.

    Pour en savoir plus sur la configuration des conteneurs et des dépôts Git dans le notebook, consultez cette [documentation](/guides/public-cloud/ai-machine-learning/ai-notebooks-manage-data-ui). Pour le moment, nous allons lancer un notebook classique sans y ajouter de volume externe.

    Vous avez ensuite la possibilité de définir des **Labels**. Cela permet de spécifier l'un de vos tokens AI et de l'appliquer à ce nouvel AI Notebook. Ce token AI peut ensuite être partagé avec toute personne devant accéder au notebook, sans qu'elle ait besoin des identifiants de votre projet Public Cloud. C'est utile si vous souhaitez donner accès à l'AI Notebook en dehors de votre projet Public Cloud. Plus d'informations sur les tokens sont disponibles dans la documentation [Gérer les tokens d'accès](/guides/public-cloud/ai-machine-learning/ai-cli-app-token).

    Enfin, la **Clé SSH** vous permet d'accéder à votre notebook à distance.

    **9\. Lancer l'AI Notebook**

    À la fin du processus, vérifiez le récapitulatif de vos paramètres et cliquez sur le bouton <code className="action">Créer le notebook</code> pour confirmer et lancer la création de votre notebook.

    :::info
    Cliquez sur <code className="action">Équivalent CLI</code> pour afficher la commande CLI *ovhai* équivalente. Cette commande vous permet de lancer exactement le même notebook avec la CLI.

    :::

    Une fois créé, votre notebook apparaît dans la liste de vos AI Notebooks.
  </Tab>

  <Tab label="SDK Python">
    La bibliothèque *ovhai* est un client Python qui permet aux développeurs d'utiliser facilement l'API AI OVHcloud. Avec ce SDK, vous pouvez exécuter, gérer et automatiser vos AI Notebooks.
    
    :::warning
    **Avertissement Alpha** : ce package est actuellement en **phase alpha** de développement. Les API et fonctionnalités du package peuvent ne pas être entièrement testées.

    :::

    
    Pour lancer un AI Notebook en utilisant le [SDK Python ovhai](https://pypi.org/project/ovhai/), vous devez d'abord installer la bibliothèque *ovhai*. Vous pouvez le faire à l'aide de `pip`. Ouvrez votre terminal et exécutez la commande suivante :
    
    ```bash
    pip install ovhai
    ```
    
    Une fois installée, nous vous invitons à suivre les instructions fournies sur la page [ovhai PyPI](https://pypi.org/project/ovhai/) pour apprendre à créer un token d'authentification, comprendre le fonctionnement du SDK et lancer un AI Notebook en utilisant le SDK Python *ovhai*.
    
    Voici un exemple simple pour vous aider à démarrer facilement :
    
    ```python
    from ovhai import AuthenticatedClient
    from ovhai.api.notebook import notebook_new
    from ovhai.models import NotebookSpec, Notebook
    from ovhai.ovhai_types import Response
    
    client = AuthenticatedClient(
        base_url="https://gra.training.ai.cloud.ovh.net",
        token="YOUR_AI_TOKEN",
    )
    
    # Define notebook parameters
    editor_id = "jupyterlab"
    framework_id = "conda"
    framework_version = "conda-py311-cudaDevel11.8"
    nb_cpu = 2
    
    # Create the notebook creation request
    notebook_specs = {
        "env": {"editorId": editor_id, "frameworkId": framework_id, "frameworkVersion": framework_version},
        "resources": {"cpu": nb_cpu},
    }
    
    with client as client:
        response: Response[Notebook] = notebook_new.sync_detailed(
            client=client, body=NotebookSpec.from_dict(notebook_specs)
        )
        
        import json
        response_content = response.content.decode('utf-8')  # Decode bytes to a string
        response_dict = json.loads(response_content)
    
        status_code = response.status_code
        id_ = response_dict['id']
        spec = response_dict['spec']
        status = response_dict['status']
        state = status['state']
        info = status['info']
        url = response_dict['status']['url']
    
        print(f"Status code: {status_code}")
        print(f"ID: {id_}")
        print(f"Spec: {spec}")
        print(f"State: {state}")
        print(f"Info: {info}")
        print(f"URL: {url}")
    ```
    
    Assurez-vous de remplacer `YOUR_AI_TOKEN` par un bearer token. Les bearer tokens peuvent être créés via l'onglet <code className="action">Token</code> de la page **Configuration** d'AI Notebooks, d'AI Training ou d'AI Deploy ou en utilisant la CLI *ovhai*. Pour des instructions plus détaillées sur la création d'un token, veuillez consulter la documentation [Gérer les tokens d'accès](/guides/public-cloud/ai-machine-learning/ai-cli-app-token).
    
    L'exécution de ce code lancera un nouvel AI Notebook basé sur les spécifications que vous avez fournies. N'hésitez pas à ajuster les spécifications selon le notebook que vous souhaitez créer.

### Accéder à votre AI Notebook

À ce stade, votre AI Notebook est créé. Vous devrez patienter quelques secondes pour que le notebook démarre et atteigne le statut `RUNNING`. Une fois cela fait, l'URL du notebook sera accessible.

<Tabs>
  <Tab label="Console OVHcloud">
    Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">AI Notebooks</code> sous **AI**. Cliquez ensuite sur le nom du notebook pour ouvrir son onglet <code className="action">Vue d’ensemble</code>.

    Dans la carte **Détails de connexion**, cliquez sur le bouton <code className="action">Ouvrir JupyterLab</code> (le bouton porte le nom de l'éditeur sélectionné). Le champ **URL de l'éditeur** donne le même lien.

    Sur la page de votre notebook, vous trouverez de nombreuses informations sur votre notebook (spécifications, cycle de vie, données attachées dans l'onglet <code className="action">Conteneurs</code>, etc.). Le lien <code className="action">Monitoring Grafana</code> de la carte **Détails de connexion** vous permet de consulter en temps réel les métriques de votre notebook, comme l'utilisation moyenne du GPU par exemple.
  </Tab>
  <Tab label="API AI">
    À l'étape précédente, vous avez commandé la création de votre notebook. Cela devrait avoir affiché l'`URL` de votre notebook dans le panneau 'Response', vous permettant d'y accéder :
    
    <img className="thumbnail" alt="Access a Notebook API" src="/images/public-cloud/ai-machine-learning/notebook-guide-introduction-definition/accessing-a-notebook-using-API.png" loading="lazy" />

Si vous n'avez plus l'`UUID` et l'`URL` du notebook affichés sur la page de l'API, vous pouvez lister tous vos AI Notebooks en utilisant la méthode GET <code className="action">Paginated list of notebooks</code>, dans la catégorie <code className="action">Notebook</code>.
    
    Cela vous permettra de récupérer l'`URL` du notebook auquel vous souhaitez accéder.
    
    Vous pouvez également obtenir toutes les informations relatives à un notebook (spécifications, Access Url, Monitoring URL, ...) en utilisant la méthode GET <code className="action">Get notebook information</code>. Il vous suffira de fournir l'`UUID` du notebook dont vous souhaitez obtenir les informations.
  </Tab>
  <Tab label="CLI ovhai">
    À l'étape précédente, vous avez commandé la création de votre notebook. Cela devrait avoir affiché l'`URL` de votre notebook dans votre terminal, vous permettant d'y accéder :
    
    <img className="thumbnail" alt="Access a Notebook ovhai CLI" src="/images/public-cloud/ai-machine-learning/notebook-guide-introduction-definition/accessing-a-notebook-using-ovhai-CLI.png" loading="lazy" />

Si vous n'avez plus l'`UUID` et l'`URL` du notebook affichés dans votre terminal, vous pouvez facilement lister tous vos AI Notebooks existants en exécutant :
    
    ```bash
    ovhai notebook list
    ```
    
    Cela vous permettra de récupérer l'`URL` du notebook auquel vous souhaitez accéder.
    
    Vous pouvez également obtenir toutes les informations relatives à un notebook (spécifications, Access Url, Monitoring URL, ...) en exécutant :
    
    ```bash

    ```
    
    Assurez-vous simplement de remplacer `<NOTEBOOK_UUID>` par l'`UUID` réel du notebook dont vous souhaitez récupérer les informations.
  </Tab>
  <Tab label="SDK Python">
    Si vous n'avez plus l'`UUID` et l'`URL` du notebook affichés dans votre IDE Python, vous pouvez facilement lister tous vos AI Notebooks en exécutant :
    
    ```python
    from ovhai.api.notebook import notebook_get_all
    from ovhai.models import NotebookList
    from ovhai.ovhai_types import Response
    
    from ovhai import AuthenticatedClient
    
    client = AuthenticatedClient(
        base_url="https://gra.training.ai.cloud.ovh.net",
        token="YOUR_AI_TOKEN",
    )
    
    with client as client:
        response: Response[NotebookList] = notebook_get_all.sync_detailed(client=client)
        import json
        response = json.loads(response.content.decode())
        for notebook_info in response["items"]:
            print(f"ID: {notebook_info['id']}")
            print(f"Name: {notebook_info['spec']['name']}")
            print(f"Status: {notebook_info['status']['state']}")
            print(f"Framework: {notebook_info['spec']['env']['frameworkId']}")
            print(f"Framework version: {notebook_info['spec']['env']['frameworkVersion']}")
            print(f"Editor: {notebook_info['spec']['env']['editorId']}")
            print(f"Access link: {notebook_info['status']['url']}")
            print("---------------")
    ```
    
    Cela vous permettra de récupérer l'`URL` du notebook auquel vous souhaitez accéder. Assurez-vous simplement d'utiliser la bonne URL d'API, et remplacez `YOUR_AI_TOKEN` par votre token AI réel.
    
    Vous pouvez également obtenir toutes les informations relatives à un notebook (spécifications, Access Url, Monitoring URL, ...) en exécutant le code suivant :
    
    ```python
    from ovhai.api.notebook import notebook_get
    from ovhai import AuthenticatedClient
    import json
    
    client = AuthenticatedClient(
        base_url="https://gra.training.ai.cloud.ovh.net",
        token="YOUR_AI_TOKEN",
    )
    id = "YOUR_NOTEBOOK_UUID"
    
    with client as client:
        response = notebook_get.sync_detailed(
            id=id, client=client
        )
    
    print(json.loads(response.content.decode()))
    ```

### Se connecter à votre AI Notebook

Une fois que vous avez cliqué sur l'`URL` du notebook, vous serez redirigé(e) vers la page du notebook correspondant. Pour les notebooks en *accès restreint*, vous devrez vous authentifier pour vérifier que vous disposez des droits requis pour y accéder.

Pour les notebooks en *accès public*, aucune authentification ne sera nécessaire, vous arriverez donc directement sur le notebook avec vos données et votre code exposés.

Il existe deux méthodes d'authentification pour un notebook restreint : utiliser une combinaison **nom d'utilisateur et mot de passe** ou utiliser un **token d'accès**.

<Tabs>
  <Tab label="Avec un nom d'utilisateur et un mot de passe">
    Pour vous authentifier avec un nom d'utilisateur et un mot de passe, veuillez suivre ces étapes :
    
    Saisissez le nom d'utilisateur et le mot de passe de l'un des utilisateurs de votre projet Public Cloud dans les champs respectifs, comme indiqué dans la capture d'écran ci-dessous. L'utilisateur doit appartenir au même projet Public Cloud que celui utilisé pour créer le notebook et doit disposer de permissions suffisantes.
    
    Si vous n'avez pas encore créé d'utilisateur Public Cloud pour votre projet, ou si vous avez besoin de plus d'informations sur la marche à suivre, veuillez vous référer au [guide](/guides/public-cloud/ai-machine-learning/ai-users) suivant.
    
    Une fois votre nom d'utilisateur et votre mot de passe saisis, cliquez sur le bouton <code className="action">Connect</code> pour vous connecter à votre AI Notebook.
    
    <img className="thumbnail" alt="Notebook Authentication Credentials" src="/images/public-cloud/ai-machine-learning/notebook-guide-introduction-definition/notebook-authentication-creds.png" loading="lazy" />
  </Tab>
  <Tab label="Avec un token d'accès">
    Utiliser un token est un moyen efficace de partager l'AI Notebook avec n'importe qui, sans avoir besoin de lui fournir les identifiants de l'un des utilisateurs de votre projet Public Cloud. Ceci est utile lorsque vous souhaitez fournir un accès au notebook en dehors de votre projet Public Cloud.
    
    Pour vous authentifier avec un token d'accès, veuillez suivre ces étapes :
    
    Cliquez sur le bouton <code className="action">Login with token</code>, situé sous les champs utilisateur et mot de passe. Cela basculera le mode d'accès vers une méthode d'authentification basée sur un token.
    
    Assurez-vous d'utiliser un token que vous avez créé depuis l'onglet <code className="action">Token</code> de la page **Configuration** d'AI Notebooks, d'AI Training ou d'AI Deploy ou depuis la CLI, l'API ou le SDK ovhai. Vous pouvez utiliser des tokens créés sans sélecteur de label. Si vous avez spécifié un sélecteur de label lors de la création du notebook, vous pouvez également utiliser le token correspondant au sélecteur de label spécifié. Pour plus d'informations sur la création d'un token d'accès, veuillez vous référer à cette [documentation](/guides/public-cloud/ai-machine-learning/ai-cli-app-token).
    
    Saisissez le token d'accès dans le champ 'Access Token', comme indiqué dans la capture d'écran ci-dessous.
    
    Cliquez sur le bouton <code className="action">Connect</code> pour vous connecter à votre AI Notebook.

### Arrêter un AI Notebook

Vous pouvez arrêter votre AI Notebook à tout moment. Cela libérera ses ressources de calcul mais conservera les données de votre notebook et les bibliothèques installées. Par conséquent, vous ne serez plus facturé(e) pour le calcul à moins de redémarrer le notebook. Cependant, le stockage attaché sera facturé au tarif d'OVHcloud Object Storage. Consultez la [documentation sur la facturation d'AI Notebooks](/guides/public-cloud/ai-machine-learning/ai-notebooks-billing) pour plus d'informations.

En effet, lorsque vous arrêtez un notebook, il sera indisponible pendant une certaine période le temps que vos données soient synchronisées vers l'Object Storage, afin que vous puissiez récupérer votre travail plus tard. Une fois la synchronisation terminée, le notebook atteindra l'état `STOPPED`, à partir duquel vous pourrez soit le redémarrer, soit le supprimer.

<Tabs>
  <Tab label="Console OVHcloud">
    Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">AI Notebooks</code> sous **AI**. Cliquez ensuite sur le nom du notebook pour ouvrir son onglet <code className="action">Vue d’ensemble</code>.

    Dans la carte **Informations générales**, cliquez sur <code className="action">Arrêter</code>, puis confirmez avec <code className="action">Arrêter</code>. Vous pouvez aussi utiliser le bouton <code className="action">...</code> de la ligne du notebook dans la liste des AI Notebooks.
  </Tab>
  <Tab label="API AI">
    Sélectionnez l'endpoint <code className="action">Stop a running notebook</code>, qui est une méthode PUT. Fournissez l'UUID du notebook que vous souhaitez arrêter comme paramètre d'entrée. Ensuite, cliquez sur le bouton <code className="action">Send API request</code> pour envoyer la requête.
    
    Si la requête réussit, le notebook sera arrêté et un message 'No content' s'affichera dans le panneau 'Response'. Si la requête échoue, un message d'erreur s'y affichera.
    
    <img className="thumbnail" alt="Stop a Notebook API" src="/images/public-cloud/ai-machine-learning/notebook-guide-introduction-definition/stopping-a-notebook-using-API.png" loading="lazy" />
  </Tab>
  <Tab label="CLI ovhai">
    Vous pouvez facilement arrêter votre notebook en utilisant la commande suivante :
    
    ```bash
    ovhai notebook stop `<NOTEBOOK_UUID>`
    ```
    
    Assurez-vous de remplacer `<NOTEBOOK_UUID>` par l'UUID du notebook que vous souhaitez arrêter.
    
    Si vous ne connaissez pas son UUID, rappelez-vous que vous pouvez facilement lister tous vos AI Notebooks existants en exécutant :
    
    ```bash
    ovhai notebook list
    ```
  </Tab>
  <Tab label="SDK Python">
    Voici un exemple montrant comment arrêter un notebook en cours d'exécution en utilisant le SDK Python :

    ```python
    )

    with client as client:
        response = notebook_stop.sync_detailed(client=client, id=id)
    ```
    
    Remplacez `YOUR_AI_TOKEN` par votre token AI réel et `YOUR_NOTEBOOK_UUID` par l'`UUID` du notebook que vous souhaitez arrêter.
  </Tab>
</Tabs>

### Redémarrer un notebook

Lorsque votre notebook est à l'état `RUNNING`, vous pourriez vouloir le redémarrer pour actualiser l'environnement ou appliquer des mises à jour tout en conservant toutes vos données et paramètres.

L'opération de redémarrage **ne déclenchera pas de processus de synchronisation des données**, ce qui signifie que les données et paramètres de votre notebook seront conservés sans nécessiter le processus chronophage de copie des données.

Si vous avez activé la fonctionnalité de redémarrage automatique, votre notebook redémarrera automatiquement tous les 7 jours sans nécessiter d'intervention manuelle. Vous avez également la possibilité d'étendre cette période à 28 jours en contactant notre [support](/links/support-contact).

### Supprimer un notebook

Si vous n'avez plus besoin de votre notebook, vous pouvez le supprimer.

Supprimer un notebook signifie également que vous supprimerez le stockage local du notebook. Ces données ne pourront pas être récupérées une fois le notebook supprimé. Cependant, tout Object Storage distant monté sur l'AI Notebook lors de sa création ne sera pas supprimé.

<Tabs>
  <Tab label="Console OVHcloud">
    Si vous souhaitez **supprimer** complètement votre AI Notebook, cliquez sur le bouton <code className="action">...</code> de la ligne du notebook dans la liste des AI Notebooks, puis sélectionnez <code className="action">Supprimer</code>. Vous pouvez aussi cliquer sur <code className="action">Supprimer le notebook</code> dans la carte **Informations générales** du notebook. Confirmez avec <code className="action">Supprimer</code>.
  </Tab>
  <Tab label="API AI">
    Sélectionnez l'endpoint <code className="action">Delete permanently a notebook</code>, qui est une méthode DELETE. Fournissez l'UUID du notebook que vous souhaitez supprimer. Utilisez le paramètre `force` si votre notebook n'est pas `STOPPED` et est toujours `RUNNING`. Ensuite, cliquez sur le bouton <code className="action">Send API request</code> pour envoyer la requête.
    
    Si la requête réussit, le notebook sera supprimé et un message 'No content' s'affichera dans le panneau 'Response'. Si la requête échoue, un message d'erreur s'y affichera.
    
    <img className="thumbnail" alt="Delete a Notebook API" src="/images/public-cloud/ai-machine-learning/notebook-guide-introduction-definition/deleting-a-notebook-using-API.png" loading="lazy" />
  </Tab>
  <Tab label="CLI ovhai">
    Si vous souhaitez **supprimer** complètement votre AI Notebook, exécutez simplement la commande suivante :
    
    ```bash
    ovhai notebook delete `<NOTEBOOK_UUID>`
    ```
    
    Si le notebook est toujours à l'état `RUNNING`, un message de confirmation apparaîtra, vous demandant de confirmer l'action. Ne confirmez que si vous êtes sûr(e) de vouloir supprimer le notebook.
  </Tab>
  <Tab label="SDK Python">
    Voici un exemple montrant comment supprimer un notebook en utilisant le SDK Python :
    
    ```python
    from ovhai.api.notebook import notebook_delete
    from ovhai import AuthenticatedClient
    
    client = AuthenticatedClient(
        base_url="https://gra.training.ai.cloud.ovh.net",
        token="YOUR_AI_TOKEN",
    )
    id = "YOUR_NOTEBOOK_UUID"
    
    with client as client:
        response = notebook_delete.sync_detailed(
            id=id, client=client, force=False
        )
    
        print(response.content.decode())
    ```
    
    Remplacez `YOUR_AI_TOKEN` par votre token AI réel et `YOUR_NOTEBOOK_UUID` par l'`UUID` du notebook que vous souhaitez supprimer. Si le notebook est toujours à l'état `RUNNING`, vous devrez définir le paramètre `force` sur `True` pour supprimer le notebook.
  </Tab>
</Tabs>


Une fois l'AI Notebook supprimé, vous ne devriez plus le voir lors du listage de vos AI Notebooks existants.
