## Objectif

Ce guide montre comment partager des [**notebooks**](/guides/public-cloud/ai-machine-learning/ai-notebooks-definition) avec d'autres personnes via la CLI **ovhai**.

## Prérequis

-   une CLI `ovhai` fonctionnelle ([comment installer la CLI ovhai](/guides/public-cloud/ai-machine-learning/ai-cli-install-client))

## Partager un notebook avec des personnes de votre projet Public Cloud

Lorsque vous y accédez depuis votre navigateur, vous devrez vous connecter avec vos identifiants.
Toute personne se trouvant dans le même projet Public Cloud que vous aura également accès à ce notebook avec ses propres
identifiants. La seule chose à faire est de lui transmettre l'URL renvoyée par la commande `ovhai notebook get <notebook-id>`.

Tout d'abord, créons un notebook :

```console
$ ovhai notebook run --gpu 1 pytorch vscode

createdAt: "2021-05-27T14:01:09.867501592Z"
updatedAt: "2021-05-27T14:01:09.867501592Z"
user: user-uY7UNgjpKBPY
spec:
  name: ""
  labels: {}
  resources:
    gpu: 1
    gpuModel: Tesla-V100S
    cpu: 13
  volumes: []
  unsecureHttp: false
  env:
    frameworkId: pytorch
    frameworkVersion: 1.8.1
    editorId: vscode
status:
  lastTransitionDate: ~
  infos: ~
  state: STARTING
  duration: 0
  url: ~
  monitoringUrl: ~
  lastStartedAt: ~
  lastStoppedAt: ~
  dataSync: []
```

Attendez quelques secondes que le notebook atteigne l'état `RUNNING`.

```console

  Monitoring Url:  https://monitoring.gra.ai.cloud.ovh.net/d/gpu?var-notebook=d8d809f2-717b-4b60-9881-07e6987a144d&from=1622124009877

```

Ici, l'URL est `https://d8d809f2-717b-4b60-9881-07e6987a144d.notebook.gra.ai.cloud.ovh.net`.
Elle sera différente pour chaque notebook que vous créerez. Toute personne de votre projet Public Cloud peut désormais accéder à cette URL
depuis son navigateur avec ses propres identifiants.

## Partager un notebook avec des personnes en dehors de votre projet Public Cloud

Pour permettre à des personnes en dehors de votre projet Public Cloud d'accéder à votre notebook, nous devons générer pour elles des
identifiants qui ne leur donneront accès qu'aux notebooks que nous souhaitons. Ces identifiants sont appelés des App tokens et sont représentés
par une longue chaîne de caractères.

La première étape consiste à générer un token qui donnera accès aux notebooks portant un label spécifié :

```console
$ ovhai token create my-token --role read --label-selector subject=image-recognition                                                                                                                                                                                  14:16:28
Info:     
  ID:             0aa3c557-10c9-4331-b168-cd4e45abebdc
  Name:           my-token
  Label selector: subject=image-recognition
  Version:        1
  Created at:     2021-05-27 14:03:06.178808548 UTC
  Updated at:     2021-05-27 14:03:06.178808548 UTC

Token:    eyJhbGciOiJFZERTQSJ9.eyJwcm9qZWN0IjoiZDBhMzRkZDQtNzZmOC00MzhkLWJlMjQtOWJlZDg4MmIyY2RlIiwianRpIjoiMGFhM2M1NTctMTBjOS00MzMxLWIxNjgtY2Q0ZTQ1YWJlYmRjLTEiLCJpc3MiOiJ0cmFpbmluZy5haS5jbG91ZC5vdmgubmV0Iiwic3ViIjoiYmJmZTU4ZjMtODNhNS00NzBiLWFiZDUtMGY3ZTg4ZjAxYjc2In0.HuQfPBfpSOvxABtXAsSc-1RPCEZjQQFSpKZftjRy2lOcayd1xjfmR6LaRklt-68ffkQbHPcPxLQQI8WIlgyADg
```

Nous venons de créer un token nommé `my-token`, qui permettra d'accéder à tout notebook portant le label `subject=image-recognition`.
L'option `--role read` signifie que les personnes utilisant ce token pourront uniquement accéder à l'adresse depuis leur navigateur, mais ne pourront pas arrêter ou supprimer le notebook.
Si vous souhaitez permettre à d'autres personnes de le faire, utilisez plutôt `--role operator`.

Dans cet exemple, le token est :

    eyJhbGciOiJFZERTQSJ9.eyJwcm9qZWN0IjoiZDBhMzRkZDQtNzZmOC00MzhkLWJlMjQtOWJlZDg4MmIyY2RlIiwianRpIjoiMGFhM2M1NTctMTBjOS00MzMxLWIxNjgtY2Q0ZTQ1YWJlYmRjLTEiLCJpc3MiOiJ0cmFpbmluZy5haS5jbG91ZC5vdmgubmV0Iiwic3ViIjoiYmJmZTU4ZjMtODNhNS00NzBiLWFiZDUtMGY3ZTg4ZjAxYjc2In0.HuQfPBfpSOvxABtXAsSc-1RPCEZjQQFSpKZftjRy2lOcayd1xjfmR6LaRklt-68ffkQbHPcPxLQQI8WIlgyADg

Ce token est unique et sera différent pour vous.
Vous devriez le sauvegarder de votre côté, car il n'existe aucun moyen de le récupérer par la suite.

Si vous êtes déjà connecté avec votre navigateur, il affichera alors le notebook. Sinon, vous obtiendrez une page comme celle-ci :

Collez le token que nous avons créé précédemment dans le champ de texte et cliquez sur `Connect`. Vous devriez maintenant voir votre notebook.

Vous pouvez désormais donner ce token à toute personne avec qui vous souhaitez partager le notebook.

## Partager votre notebook publiquement

Partager votre notebook publiquement signifie que n'importe qui pourra accéder au notebook s'il dispose de l'URL.
Ces personnes ne pourront pas arrêter ou supprimer le notebook, mais pourront le modifier, exécuter du code et accéder à vos volumes montés.

Vous aurez besoin de l'option `--unsecure-http` lors de la création de votre notebook pour le rendre accessible publiquement :

```console
$ ovhai notebook run --gpu 1 --unsecure-http pytorch vscode                                                                                                                                                                                                           14:47:49
---
id: 8e3ac445-0b47-4eea-9269-19a36b7213c7
createdAt: "2021-05-27T14:06:47.356124682Z"
updatedAt: "2021-05-27T14:06:47.356124682Z"
user: user-uY7UNgjpKBPY
spec:
  name: ""
  labels: {}
  resources:
    gpu: 1
    gpuModel: Tesla-V100S
    cpu: 13
  volumes: []
  unsecureHttp: true
  env:
    frameworkId: pytorch
    frameworkVersion: 1.8.1
    editorId: vscode
status:
  lastTransitionDate: ~
  infos: ~
  state: STARTING
  duration: 0
  url: ~
  monitoringUrl: ~
  lastStartedAt: ~
  lastStoppedAt: ~
  dataSync: []
```

Attendez quelques secondes que le notebook atteigne l'état `RUNNING`.
