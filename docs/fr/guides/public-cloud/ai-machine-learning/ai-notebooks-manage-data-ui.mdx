## Objectif

Ce guide montre comment accéder aux données de l'Object Storage depuis vos [**notebooks**](/guides/public-cloud/ai-machine-learning/ai-notebooks-definition) via la console OVHcloud.

## Prérequis

- un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- un accès à la <ManagerLink to="/">console OVHcloud</ManagerLink>
- un utilisateur Public Cloud avec le rôle `Administrator` ou `AI Operator`, voir [ici](/guides/public-cloud/ai-machine-learning/ai-users) pour plus d'informations

## Envoyer des données vers votre Object Storage

Vous devez d'abord envoyer des données vers l'`Object Storage` avant d'y accéder depuis le notebook.

Cliquez sur <code className="action">Object Storage</code> sous **Stockage** dans le menu de gauche de votre projet Public Cloud. Vos conteneurs sont listés dans l'onglet <code className="action">Conteneurs</code>.

:::info
Vous pouvez envoyer différents types de données : jeux de données, code, notebooks, poids de connexion, fichiers texte ou csv, etc.

:::

Supposons qu'un fichier nommé `my-dataset.zip` existe localement sur votre ordinateur et contienne votre jeu de données. Vous pourrez l'envoyer dans un conteneur d'objets de votre Object Storage en suivant ces étapes.

### 1- Créez votre conteneur

Dans l'onglet <code className="action">Conteneurs</code>, cliquez sur <code className="action">Créer un conteneur d'objets</code>. Sélectionnez le **Type de conteneur** (Swift ou **API compatible S3**), nommez votre conteneur `my-dataset`, sélectionnez le mode de déploiement et la région, puis cliquez sur <code className="action">Créer</code>.

:::info
Pour optimiser les temps de téléchargement et d'envoi, nous vous conseillons de stocker vos données au même endroit que votre notebook (`GRA` ou `BHS`).

:::

:::warning
Pour attacher un bucket compatible S3<sup>1</sup> à votre notebook, vous devez d'abord le déclarer comme datastore dans l'onglet <code className="action">Volumes S3</code> de la page **Configuration** d'AI Notebooks. Pour en savoir plus, consultez le [guide sur l'Object Storage compatible S3](/guides/public-cloud/ai-machine-learning/ai-s3-compliance).

:::

Si vous souhaitez en savoir plus sur les différentes solutions de stockage, consultez cette page.

Vous avez créé votre conteneur pour héberger votre jeu de données. Vous êtes maintenant prêt à charger vos données !

### 2- Ajoutez des objets à votre conteneur

Dans l'onglet <code className="action">Conteneurs</code>, cliquez sur le nom de votre conteneur `my-dataset` : son onglet <code className="action">Objets</code> s'ouvre. Cliquez sur <code className="action">Ajouter un objet</code>, puis sur <code className="action">Parcourir les fichiers</code>, sélectionnez votre fichier local `my-dataset.zip` et cliquez sur <code className="action">Téléverser</code>.

Votre fichier `my-dataset.zip` s'affiche maintenant dans votre conteneur d'objets.

:::info
Vous pouvez également créer un nouveau conteneur vide `my-weights` dans lequel vous pourrez enregistrer vos **poids de connexion** (ou votre **modèle validé**) à la fin de votre entraînement.

:::

Nous supposons que nous disposons maintenant de deux conteneurs d'objets :

- `my-dataset`, contenant le fichier `my-dataset.zip`
- `my-weights`, vide

Vous êtes maintenant prêt à lancer un notebook avec vos données !

## Lancer un notebook avec des données attachées

Pour lancer un AI notebook, cliquez sur <code className="action">AI Notebooks</code> sous **AI** dans le menu de gauche de votre projet Public Cloud, puis sur <code className="action">Créer un notebook</code>.

Pour le nom, la flavor, le framework et l'éditeur de votre notebook, consultez ce [tutoriel](/guides/public-cloud/ai-machine-learning/ai-notebooks-definition).

### Choisissez la région du notebook

Dans la section **Région**, vous pouvez choisir entre *2 datacenters* pour le stockage de votre notebook : `GRA` ou `BHS`.

### Attachez un conteneur ou un dépôt Git

Vous pouvez attacher vos différents types de données à votre notebook dans la section **Configuration avancée** de la page de création.

Pour attacher un conteneur, activez l'interrupteur **Volumes** et cliquez sur <code className="action">Ajouter un volume</code>. Dans la fenêtre **Ajouter un volume datastore**, sélectionnez le **Datastore** qui contient votre conteneur, puis le **Conteneur** (vous pouvez aussi en créer un nouveau à la volée en saisissant son nom), renseignez le **Chemin de montage** et choisissez la **Permission**. Cliquez ensuite sur <code className="action">Ajouter</code>.

#### Accès avec des permissions en lecture seule

Vous pouvez charger le conteneur `my-dataset` dans le répertoire `/workspace/dataset`, avec la permission **Lecture seule**.

Vous ne pourrez pas modifier le jeu de données depuis ce notebook, car vous l'avez chargé avec la permission **Lecture seule**.

Les permissions **Lecture seule** garantissent que vous ne modifiez pas vos données par erreur. Si vous souhaitez modifier des données depuis vos
notebooks, pour enregistrer un réseau de neurones entraîné par exemple, vous pouvez utiliser la permission **Lecture / écriture** à la place.

#### Accès avec des permissions en lecture / écriture

De la même manière qu'en mode **Lecture seule**, vous pouvez charger des données avec la permission **Lecture / écriture** : par exemple, chargez le conteneur `my-weights` dans le répertoire `/workspace/weights`.

Lorsque vous avez des données à enregistrer depuis le notebook vers l'Object Storage (les poids de connexion dans cet exemple), il vous suffit de les écrire dans le dossier `/workspace/weights`.

Ce dossier sera envoyé vers votre Object Storage lorsque vous arrêterez votre notebook.

Tant que votre notebook est à l'état **Arrêt**, l'envoi est toujours en cours. Une fois que l'état passe à **Arrêté**, toutes les données ont été envoyées vers votre Object Storage.

#### Attacher un dépôt Git public

Si du code Python, des notebooks ou d'autres fichiers sont disponibles sur un dépôt GitHub public, vous pouvez les attacher à votre notebook.
Pour pouvoir les éditer et les modifier facilement, utilisez la permission **Lecture / écriture**.

Activez l'interrupteur **Git Public** et cliquez sur <code className="action">Ajouter un dépôt</code>. Saisissez l'URL dans le champ **Dépôt git public**, puis le **Chemin de montage** (par exemple `/workspace/git-hub-repository`) et la **Permission**, et cliquez sur <code className="action">Ajouter</code>.

:::warning
Pour que l'URL de votre dépôt soit valide, n'oubliez pas d'ajouter `.git` à la fin de l'URL du dépôt GitHub.

:::

#### Utiliser des volumes en cache

Le chargement de fichiers volumineux depuis l'`Object Storage` peut prendre du temps. Dans ce cas, vous pouvez mettre les volumes en cache afin qu'ils n'aient pas besoin d'être téléchargés à nouveau lorsque vous démarrez de nouveaux notebooks utilisant les mêmes données.

Pour cela, cochez **Mettre le volume en cache près de l'instance** dans la fenêtre **Ajouter un volume datastore**.

Les volumes en cache seront supprimés au moins 72 heures après l'arrêt du dernier notebook qui les utilise.
Notez que le cache est partagé avec tous les utilisateurs de votre projet. La principale conséquence à laquelle vous devez faire attention
est que si quelqu'un d'autre modifie les données de votre volume en cache, vous verrez également ces modifications de votre côté.

### Lancer et accéder au notebook

Votre notebook est maintenant prêt à être lancé avec vos données ! Les volumes attachés sont listés dans le récapitulatif de la page de création. Cliquez sur <code className="action">Créer le notebook</code>.

Une fois le notebook créé, ses volumes attachés sont listés dans son onglet <code className="action">Conteneurs</code>. Vous pouvez ajouter ou détacher des volumes depuis cet onglet lorsque le notebook est arrêté.

Consultez la page [Premiers pas](/guides/public-cloud/ai-machine-learning/ai-notebooks-definition) pour savoir comment trouver cette URL.

Dès que vous accédez à votre notebook, vous voyez vos différents dossiers contenant vos données.
