## Objectif

Ce tutoriel montre comment utiliser **AI Endpoints** dans AI Notebooks pour obtenir un assistant de code.

[AI Endpoints](/links/public-cloud/ai-endpoints) est une plateforme serverless qui offre un accès simplifié à des modèles d'IA pré-entraînés de renommée mondiale. Elle est simple, sécurisée et intuitive, avec la confidentialité des données comme priorité absolue. Nous ne stockons pas les données des utilisateurs, ce qui en fait un choix idéal pour les développeurs qui souhaitent ajouter des capacités d'IA tout en préservant la confidentialité des données.

Aucune expertise approfondie en IA n'est requise, ce qui fait d'AI Endpoints un choix pratique et sécurisé pour intégrer l'IA dans vos applications.

Par défaut, vous pouvez utiliser notre solution [AI Endpoints](/links/public-cloud/ai-endpoints) dans tous les notebooks sans token personnel, mais vous serez soumis à une limitation de débit.

## Prérequis

- Un projet AI Notebooks créé au sein d'un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un utilisateur AI Notebooks

## En pratique

Vous pouvez lancer un notebook depuis l'<ManagerLink to="/">espace client OVHcloud</ManagerLink> ou via la [CLI ovhai](/guides/public-cloud/ai-machine-learning/ai-cli-run-notebook).

:::warning
Si ce plugin n'apparaît pas comme activé dans votre notebook actuel, c'est parce que vous n'utilisez pas la dernière version de framework disponible dans notre catalogue d'images. Démarrez un nouveau notebook pour accéder à cette nouvelle fonctionnalité.

:::


### Lancer un notebook via l'interface (espace client)

Pour lancer votre notebook depuis l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>, suivez les étapes ci-dessous. L'assistant de code diffère selon que vous utilisez des notebooks Jupyter ou VS Code.

    **1 - Posez votre question**
    
    Vous êtes prêt à démarrer avec les paramètres par défaut ; posez votre première question sur votre code !
