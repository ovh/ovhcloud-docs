## Objectif

Les moteurs Analytics sont des services managés, ce qui signifie qu'ils ne sont pas entièrement configurables. Par exemple, il n'est pas possible de modifier *pg_hba.conf*.

:::info
La configuration avancée est disponible pour les moteurs Analytics suivants :

- Managed Dashboards (Grafana)
- Kafka
- Kafka Connect
- OpenSearch

:::



## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un service Analytics en cours d'exécution sur votre OVHcloud Analytics (ce [guide](/guides/public-cloud/data-analytics/analytics/getting-started) peut vous aider à remplir ce prérequis)
- Accès à votre <ManagerLink to="/">espace client OVHcloud</ManagerLink> ou à l'<ApiLink>API OVHcloud</ApiLink>

## En pratique

:::warning
Notez que les modifications apportées aux paramètres avancés s'appliquent au niveau du cluster et donc à tous les services Analytics du cluster.

:::


:::info
Selon le moteur, certains paramètres peuvent déjà être définis.

:::


:::info
Une fois la configuration avancée soumise, il n'est pas possible de la réinitialiser à ses valeurs initiales. Il est uniquement possible de mettre à jour les valeurs ; nous vous recommandons donc de noter les valeurs initiales avant de les modifier.

Pour vérifier les valeurs soumises, consultez la section [Obtenir la configuration avancée existante](#obtenir-la-configuration-avancée-existante) ci-dessous.

:::


### Depuis l'espace client OVHcloud

{/* CP-STEPS-START:using-the-ovhcloud-control-panel */}
Pour modifier la configuration avancée, connectez-vous d'abord à votre <ManagerLink to="/">espace client OVHcloud</ManagerLink> et ouvrez votre projet <code className="action">Public Cloud</code>. Cliquez sur <code className="action">Data Streaming</code> ou <code className="action">Data Analysis</code> dans la barre de navigation de gauche, sélectionnez votre instance de moteur, puis l'onglet <code className="action">Configuration avancée</code>.

Sélectionnez la clé du paramètre avancé que vous souhaitez définir, puis renseignez sa valeur.

Une fois prêt, cliquez sur <code className="action">Configuration avancée</code>.

:::info
En haut à droite de l'onglet de configuration avancée, vous pouvez consulter les paramètres déjà définis.

:::
{/* CP-STEPS-END:using-the-ovhcloud-control-panel */}


### Depuis l'API

:::info
Si vous n'êtes pas familier avec l'utilisation de l'API OVHcloud, consultez notre guide [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps).

:::


#### Obtenir vos ID de service et de cluster

Vous devez d'abord identifier le service et le cluster auxquels vous souhaitez appliquer les modifications.

##### Obtenir l'ID du service souhaité

Exécutez l'appel API suivant :

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project"} />


<img className="thumbnail" alt="serviceName" src="/images/public-cloud/data-analytics/analytics/analytics-advanced-parameters/api_ui_00.png" loading="lazy" />

Dans la liste obtenue, sélectionnez et copiez l'identifiant du service souhaité, également appelé serviceName.

##### Obtenir l'ID du cluster souhaité

Ouvrez l'appel API suivant, collez votre ID de service dans le champ `serviceName` et cliquez sur <code className="action">Execute</code> :

<Tabs>
  <Tab label="Kafka">
    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/database/kafka"} />
  </Tab>
  <Tab label="Kafka Connect">
    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/database/kafkaConnect"} />
  </Tab>
  <Tab label="OpenSearch">
    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/database/opensearch"} />
  </Tab>
  <Tab label="Dashboards">
    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/database/grafana"} />
  </Tab>
</Tabs>


<img className="thumbnail" alt="ID du cluster" src="/images/public-cloud/data-analytics/analytics/analytics-advanced-parameters/api_ui_01.png" loading="lazy" />

Dans la liste obtenue, sélectionnez et copiez l'ID du cluster, également appelé clusterId.

Ouvrez l'appel API suivant et renseignez les paramètres correspondants (serviceName, clusterId)

  <Tab label="Kafka">

  </Tab>
  <Tab label="Kafka Connect">
    <Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\\{serviceName\\}/database/kafkaConnect/\\{clusterId\\}/advancedConfiguration"} />
  </Tab>
  <Tab label="OpenSearch">
    <Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\\{serviceName\\}/database/opensearch/\\{clusterId\\}/advancedConfiguration"} />

<img className="thumbnail" alt="Put OpensSearch Advanced Parameters" src="/images/public-cloud/data-analytics/analytics/analytics-advanced-parameters/api_ui_04.png" loading="lazy" />
