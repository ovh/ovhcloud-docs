## Objectif

Apache Kafka est une plateforme open source distribuée de streaming d'événements, conçue pour le traitement de données en temps réel et à grande échelle, avec une scalabilité et une durabilité élevées ainsi qu'une faible latence.

Ce guide explique comment activer le schema registry pour votre cluster Kafka via l'espace client OVHcloud.

## Prérequis

- Accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un [cluster Kafka en cours d'exécution](/guides/public-cloud/databases/kafka-getting-started) sur OVHcloud Public Cloud

## En pratique

### Activer le schema registry

{/* CP-STEPS-START:enable-schema-registry */}
Pour activer le schema registry, accédez à l'onglet `Configuration` de votre cluster Kafka. Faites ensuite défiler jusqu'à la section spécifique à Kafka et cliquez sur le bouton bascule du schema registry pour l'activer.

![Activer le schema registry](/images/guides/public-cloud/data-analytics/analytics/kafka-enable-schema-registry/kafka_enable_schema_registry.png)

Le schema registry peut être désactivé avec le même bouton bascule.
{/* CP-STEPS-END:enable-schema-registry */}
