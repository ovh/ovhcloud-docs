## Objectif

Découvrez comment ajuster l'espace de stockage de votre cluster selon vos besoins.

:::info
Cette fonctionnalité est disponible uniquement pour les moteurs utilisant de l'espace de stockage.

:::


## Comment augmenter ou diminuer le stockage

Vous pouvez augmenter ou diminuer le stockage de votre service à tout moment, via l'<ApiLink>API</ApiLink> OVHcloud ou l'<ManagerLink to="/">espace client</ManagerLink>.

:::info
Lors de la modification de l'espace de stockage de votre service, le système vérifie qu'au moins 20 % de votre espace de stockage total restera disponible après l'opération de redimensionnement. Par conséquent, il se peut que vous ne puissiez pas effectuer de diminution de l'espace de stockage si la nouvelle taille demandée est trop proche de votre utilisation actuelle de l'espace disque.

:::


### Comment ajuster l'espace de stockage depuis l'espace client

#### Prérequis

- Accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

#### En pratique

{/* CP-STEPS-START:adjust-storage-cp */}

Pour ajuster l'espace de stockage de votre cluster, connectez-vous à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink> et ouvrez votre projet Public Cloud. Cliquez sur <code className="action">Data Analysis</code> ou <code className="action">Data Streaming</code> dans la barre de navigation de gauche, puis sélectionnez votre instance de moteur.

<img className="thumbnail" alt="Vue d'ensemble du cluster" src="/images/public-cloud/data-analytics/analytics/analytics-resize-cluster-storage/cluster-overview.png" loading="lazy" />

Cliquez sur <code className="action">Modifier le stockage additionnel</code> et ajustez l'espace de stockage de votre cluster. Utilisez le curseur pour augmenter ou diminuer l'espace de stockage.

<img className="thumbnail" alt="Modifier le stockage additionnel" src="/images/public-cloud/data-analytics/analytics/analytics-resize-cluster-storage/edit-additional-storage.png" loading="lazy" />

{/* CP-STEPS-END:adjust-storage-cp */}

### Comment ajuster l'espace de stockage via l'API

#### Prérequis

- Accès à l'<ApiLink>API</ApiLink> OVHcloud (créez vos identifiants en consultant [ce guide](/guides/manage-and-operate/api/first-steps))
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

#### En pratique

Par exemple, pour les services OpenSearch, vous pouvez effectuer une augmentation ou une diminution de l'espace de stockage à l'aide de cet endpoint :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/opensearch/\{clusterId\}"} />

Les autres moteurs utilisant un espace de stockage proposent des endpoints similaires, par exemple :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/kafka/\{clusterId\}"} />
