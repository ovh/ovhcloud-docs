## Objectif

Les services Analytics vous permettent d'envoyer les logs de votre service vers votre propre flux de données Logs Data Platform (LDP).

**Ce guide explique comment transférer les logs de votre service vers votre propre flux LDP avec l'API OVHcloud.**

## Prérequis

- Accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [service Analytics](/links/public-cloud/analytics) en cours d'exécution
- Un accès à l'<ApiLink>API OVHcloud</ApiLink>
- Un compte Logs Data Platform au sein de ce compte OVHcloud, avec au moins un flux de destination configuré
    - Si vous n'êtes pas familier avec toutes les possibilités de configuration des *Streams* LDP, créez-en simplement un nouveau avec les options par défaut (indexation et websocket activés, stockage longue durée désactivé) pour les besoins de ce guide.
- Un service Analytics en cours d'exécution

## En pratique

### Étape 1 - Récupérer les informations nécessaires

#### Récupérer votre `streamId` de destination LDP :

{/* CP-STEPS-START:retrieve-ldp-stream-id */}
- Dans l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>, accédez à la page LDP.
- Accédez à l'onglet <code className="action">Flux de données</code>.
- Choisissez votre flux cible et cliquez sur <code className="action">Copier l'identifiant du flux</code>.
{/* CP-STEPS-END:retrieve-ldp-stream-id */}

#### Récupérer votre `serviceName` de destination LDP :

- Il s'agit de l'ID de votre projet Public Cloud.

#### Récupérer votre `clusterId` :

{/* CP-STEPS-START:retrieve-cluster-id */}
- Dans l'espace client OVHcloud, accédez à votre service Analytics.
- Récupérez votre `Cluster ID` depuis le champ correspondant.
{/* CP-STEPS-END:retrieve-cluster-id */}

### Étape 2 - Créez votre abonnement

Utilisez l'appel API suivant :

<Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\{serviceName\}/database/kafka/\{clusterId\}/log/subscription"} />

Remplacez `kafka` dans la route par le moteur de votre service (par exemple `opensearch` ou `grafana`).

```console
body : {
    streamId: <LDP destination stream ID>
}
```
Les logs commenceront alors à être transférés vers votre flux LDP.

### Retrouver les logs dans Graylog

Pour retrouver les logs de votre service dans votre flux Graylog, vous pouvez utiliser les requêtes Graylog suivantes :

Requête : `clusterID: "<Engine>-<HostID>"`

{/* CP-STEPS-START:find-host-id-in-cp */}
Vous pouvez retrouver ce `HostID` dans votre espace client OVHcloud :

- Retrouvez le Cluster ID au format UUID (AAAAAAAA-BBBB-CCCC-DDDDDDDDDDDD)
- Le `HostID` correspond à la première partie de l'UUID (AAAAAAAA)
{/* CP-STEPS-END:find-host-id-in-cp */}

### Supprimer un abonnement

Il existe 2 méthodes pour supprimer un abonnement :

- Vous pouvez supprimer les abonnements concernés à l'aide du `subscriptionId` et de cet appel API :

<Api version="v1" section="/cloud" method="DELETE" route={"/cloud/project/\{serviceName\}/database/kafka/\{clusterId\}/log/subscription/\{subscriptionId\}"} />


- Si vous supprimez votre service Analytics, tous les abonnements de ce service sont automatiquement supprimés.
