## Objectif

Les services Analytics vous permettent d'exporter les métriques de service à l'aide de Prometheus.

**Ce guide explique comment configurer un exporteur Prometheus pour votre service Analytics afin qu'un serveur Prometheus puisse collecter les métriques.**

## Prérequis

- Un [service Analytics](/links/public-cloud/analytics) opérationnel,
- Accès à l'<ApiLink>API OVHcloud</ApiLink>,
- Un serveur [Prometheus](https://prometheus.io) pour collecter les métriques.

## En pratique

### Activer l'exporteur Prometheus pour votre service

Vous pouvez activer un exporteur Prometheus pour votre service à l'aide de cet endpoint API :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/kafka/\{clusterId\}"} />

Remplacez `kafka` dans la route par le moteur de votre service (par exemple `opensearch` ou `grafana`).


La propriété booléenne `enablePrometheus` doit être définie sur `true` pour activer l'exporteur Prometheus de votre service.

### Récupérer les informations d'accès de l'exporteur Prometheus

Utilisez l'endpoint API suivant pour obtenir les données nécessaires à l'accès à l'exporteur Prometheus :

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/kafka/\{clusterId\}/prometheus"} />


Vous devrez également réinitialiser les identifiants afin d'obtenir le mot de passe requis pour y accéder :

<Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\{serviceName\}/database/kafka/\{clusterId\}/prometheus/credentials/reset"} />


### Configurer votre serveur Prometheus et démarrer la collecte des métriques

Utilisez les données de l'étape précédente pour configurer votre serveur Prometheus et démarrer la collecte des métriques de votre service. Voici un exemple de configuration Prometheus pour un service OpenSearch :

```yaml
scrape_configs:
- job_name: opensearch-metrics
  scrape_interval: 10s
  metrics_path: /metrics
  scheme : https
  basic_auth:
    username: prometheus
    password: "xxx"
  tls_config:
      insecure_skip_verify: true
  static_configs:
    - targets: 
        - opensearch-02d6a757-ovh-dev.database.cloud.ovh.net:9273
```

## Limitations

Analytics propose des métriques de service via Prometheus pour les moteurs suivants :

- Kafka
- Kafka Connect
- Kafka MirrorMaker
- OpenSearch

Les endpoints Prometheus sont soumis aux mêmes limitations réseau que le service associé. Ainsi, les restrictions d'IP s'appliquent, et pour les services utilisant un réseau privé, l'endpoint de l'exporteur Prometheus n'est accessible que depuis le réseau privé auquel votre service est rattaché.
