## Objectif

ClickHouse est un système de base de données analytique en colonnes et open source, conçu pour le traitement en temps réel de volumes de données massifs, offrant des performances élevées, une grande scalabilité et une faible latence.

**Ce guide explique comment créer un cluster ClickHouse via la console OVHcloud.**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud.

[[cpnav:publiccloud-analytics]]

## En pratique

### Souscrire au service

{/* CP-STEPS-START:subscribing-to-the-service */}
Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">ClickHouse</code> sous **Analytics**, puis sur <code className="action">Créer un service</code>. La page **Créer une base de données infogérée** s'ouvre.

#### Sélectionner votre service Analytics

Sous **Moteur de base de données**, sélectionnez ClickHouse et sa **Version**.

Un nom aléatoire est généré pour votre service dans le champ **Nom**. Vous pouvez le modifier à cette étape ou ultérieurement.

#### Sélectionner une région

Sous **Sélectionner une région**, choisissez la région géographique du datacentre qui hébergera votre service, ainsi que le mode de déploiement (1-AZ ou 3-AZ).

#### Sélectionner une offre

:::info
Actuellement, seule l'offre **Production** est disponible. L'offre **Discovery** sera bientôt proposée.
:::

Sous **Offre**, choisissez une offre de service adaptée. Si nécessaire, vous pourrez changer d'offre après la création, à la hausse comme à la baisse.

Consultez la page des capacités du service Analytics sélectionné pour obtenir des informations détaillées sur les propriétés de chaque offre.

#### Sélectionner le type de nœud

Sous **Type de nœud**, choisissez le type d'instance pour les nœuds de votre service. Vous pourrez le modifier par la suite. Le nombre de nœuds (**Nœuds**) dépend de l'offre choisie précédemment.

#### Sélectionner le stockage

Sous **Stockage**, sélectionnez le stockage additionnel. Le stockage peut être augmenté jusqu'à 3 fois le stockage de base.

#### Configurer le réseau et les restrictions IP

Sous **Réseau**, choisissez **Réseau public** ou **Réseau privé (vRack)**. Sous **Restrictions IP**, ajoutez les adresses IP qui accèderont à votre service (<code className="action">Ajouter une IP</code>, <code className="action">Ajouter mon IP actuelle</code>).

#### Vérifier et confirmer

Le **Récapitulatif** vous aide à vérifier la configuration de votre service. Les composants du prix sont également récapitulés, avec une estimation mensuelle.

Cliquez sur le bouton <code className="action">Équivalent API et Terraform</code> pour afficher l'appel API et la configuration Terraform équivalents. Utilisez ces informations pour automatiser la création du service avec l'[API OVHcloud](/guides/manage-and-operate/api/first-steps) ou le provider Terraform OVHcloud.

Lorsque vous êtes prêt, cliquez sur le bouton <code className="action">Créer la base de données</code> pour créer votre service.

En quelques minutes, votre nouveau service ClickHouse sera déployé. Son statut passe à **Actif** lorsqu'il est prêt à l'emploi.
