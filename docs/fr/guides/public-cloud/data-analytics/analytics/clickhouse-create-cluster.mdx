## Objectif

ClickHouse est un système de base de données analytique en colonnes et open source, conçu pour le traitement en temps réel de volumes de données massifs, offrant des performances élevées, une grande scalabilité et une faible latence.

**Ce guide explique comment créer un cluster ClickHouse via l'espace client OVHcloud.**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud.

## En pratique

### Souscrire au service

{/* CP-STEPS-START:subscribing-to-the-service */}
Cliquez sur <code className="action">Data Streaming</code> dans la barre de navigation de gauche, sous **Databases & Analytics**.

Cliquez sur le bouton <code className="action">Créer un service</code>.

#### Sélectionner votre service Analytics

Cliquez sur le type de service Analytics que vous souhaitez utiliser, ainsi que sur sa version.

Un nom aléatoire est généré pour votre service. Vous pouvez le modifier à cette étape ou ultérieurement.

#### Sélectionner un datacentre

Choisissez la région géographique du datacentre qui hébergera votre service, ainsi que le mode de déploiement (1-AZ ou 3-AZ).

#### Sélectionner une offre

:::info
Actuellement, seule l'offre **Production** est disponible. L'offre **Discovery** sera bientôt proposée.
:::


Lors de cette étape, choisissez une offre de service adaptée. Si nécessaire, vous pourrez changer d'offre après la création, à la hausse comme à la baisse.

Consultez la page des capacités du service Analytics sélectionné pour obtenir des informations détaillées sur les propriétés de chaque offre.

#### Sélectionner l'instance

Choisissez le type d'instance pour les nœuds de votre service. Vous pourrez le modifier par la suite. Le nombre de nœuds dépend de l'offre choisie précédemment.

#### Sélectionner le stockage

Le stockage peut être augmenté jusqu'à 3 fois le stockage de base.

#### Configurer vos options

Choisissez les options réseau et ajoutez à la liste d'autorisation les adresses IP qui accèderont à votre service.

#### Vérifier et confirmer

Un récapitulatif de votre commande s'affiche afin de vous aider à vérifier la configuration de votre service.

Les composants du prix sont également récapitulés, avec une estimation mensuelle.

Cliquez sur le bouton <code className="action">Équivalent API et Terraform</code> pour ouvrir la fenêtre suivante :

Utilisez ces informations pour automatiser la création du service avec l'[API OVHcloud](/guides/manage-and-operate/api/first-steps) ou le provider Terraform OVHcloud.

Lorsque vous êtes prêt, cliquez sur le bouton <code className="action">Commander</code> pour créer votre service.

En quelques minutes, votre nouveau service ClickHouse sera déployé.

Des messages dans l'espace client OVHcloud vous informeront lorsque le cluster ClickHouse sera prêt à l'emploi.
