## Objectif

Les moteurs Analytics vous permettent de vous concentrer sur la création et l'analyse de données, pendant qu'OVHcloud prend en charge l'infrastructure de base de données.

**Ce guide explique comment vous connecter à une instance Analytics for ClickHouse à l'aide de Tabix, un client SQL léger et convivial pour ClickHouse.**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud.
- Un service ClickHouse en cours d'exécution sur votre OVHcloud Analytics ([ce guide](/guides/public-cloud/data-analytics/analytics/getting-started) peut vous aider à répondre à ce prérequis).
- Une instance ClickHouse configurée pour accepter les connexions entrantes.
- Une version stable de Tabix installée et une connectivité réseau publique (Internet). Ce guide a été créé avec Tabix version 22.05.25.

## Concept

Un service ClickHouse peut être géré de plusieurs manières.

L'une des approches les plus simples, mais aussi les plus puissantes, consiste à utiliser l'interface en ligne de commande (CLI), comme illustré dans le guide : Connect to ClickHouse with CLI, ou à utiliser des langages de programmation et des drivers.

Une autre option consiste à interagir directement à l'aide d'un outil de gestion graphique conçu pour ClickHouse : **Tabix**.

Pour cela, vous allez installer Tabix, configurer votre service Analytics for ClickHouse pour qu'il accepte les connexions entrantes, puis vous y connecter à l'aide de Tabix.

## En pratique

### Installer Tabix

Suivez la [documentation officielle de Tabix](https://tabix.io/doc/Install/) pour installer Tabix.

Vous êtes maintenant prêt à vous connecter à votre instance ClickHouse.

### Se connecter avec Tabix

Dans Tabix, créez une nouvelle connexion et renseignez les champs requis (nom, port, identifiant, mot de passe et certificat SSL le cas échéant).

Vous êtes maintenant prêt à interagir avec votre service Analytics for ClickHouse.

### Insérer et interroger des données

Utilisez l'éditeur SQL de Tabix pour créer votre première base de données et table et y insérer des exemples de données. Voici un exemple qui crée la base **company** et la table **customer**, puis insère une ligne d'exemple.

#### Charger des données dans ClickHouse

Pour charger 100 lignes aléatoires dans une table nommée `customer`, vous pouvez utiliser l'éditeur SQL de Tabix avec le script suivant :

```sql
CREATE DATABASE IF NOT EXISTS company;

CREATE TABLE IF NOT EXISTS company.customer
(
    id UInt32,
    firstName String,
    lastName String,
    email String,
    age UInt8,
    createdAt DateTime
) ENGINE = MergeTree()
ORDER BY id;

INSERT INTO company.customer
SELECT
    number + 1 AS id,
    arrayElement(['John','Jane','Mary','Michael','Sarah','Robert','Linda','James','Patricia','David'], rand() % 10 + 1) AS firstName,
    arrayElement(['Smith','Johnson','Williams','Jones','Brown','Davis','Miller','Wilson','Moore','Taylor'], rand() % 10 + 1) AS lastName,
    concat(lower(arrayElement(['John','Jane','Mary','Michael','Sarah','Robert','Linda','James','Patricia','David'], rand() % 10 + 1)),
           '.',
           lower(arrayElement(['Smith','Johnson','Williams','Jones','Brown','Davis','Miller','Wilson','Moore','Taylor'], rand() % 10 + 1)),
           '@',
           arrayElement(['example.com','email.com','mail.com','test.com','demo.com'], rand() % 5 + 1)
    ) AS email,
    18 + rand() % 60 AS age,
    now() AS createdAt
FROM numbers(100);

SELECT '100 random rows inserted into the customer table.' AS message;
```

#### Interroger des données avec le framework d'agrégation

Vous pouvez utiliser des requêtes SQL `GROUP BY` dans ClickHouse pour agréger vos données. Par exemple, pour compter le nombre de clients par âge :

```sql
SELECT
    age,
    COUNT(*) AS count
FROM company.customer
GROUP BY age
ORDER BY age ASC;
```

Cette requête synthétise les clients par âge.
