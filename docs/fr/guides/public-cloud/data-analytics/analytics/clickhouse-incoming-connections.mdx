## Objectif

ClickHouse est un système de base de données analytique en colonnes et open source, conçu pour le traitement en temps réel de volumes de données massifs, offrant des performances élevées, une grande scalabilité et une faible latence.

**Ce guide explique comment configurer votre cluster ClickHouse pour qu'il accepte les connexions entrantes depuis l'espace client OVHcloud.**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud.
- Un cluster ClickHouse en cours d'exécution sur OVHcloud Public Cloud.

## En pratique

### Configurer le service ClickHouse

{/* CP-STEPS-START:configure-clickhouse-service */}
Une fois votre service ClickHouse opérationnel, vous devez définir au moins un utilisateur et une IP autorisée (si cela n'a pas déjà été fait lors de la commande) pour pouvoir vous connecter pleinement au service (en tant que producteur ou consommateur).

L'onglet <code className="action">Dashboard</code> se met à jour automatiquement lorsque votre service est prêt.

#### Configurer un utilisateur

Basculez sur l'onglet <code className="action">Utilisateurs</code>. Un utilisateur admin nommé `avnadmin` est préconfiguré lors de l'installation du service.

Vous pouvez ajouter d'autres utilisateurs en cliquant sur le bouton <code className="action">Ajouter un utilisateur</code>.

Saisissez un nom d'utilisateur, puis cliquez sur <code className="action">Créer un utilisateur</code>.

Les mots de passe doivent être réinitialisés depuis le tableau de l'onglet <code className="action">Utilisateurs</code>.

#### Configurer les IP autorisées

:::warning
Pour des raisons de sécurité, la configuration réseau par défaut n'autorise aucune connexion entrante. Vous devez donc autoriser les adresses IP appropriées pour accéder à votre cluster ClickHouse.
:::


Si vous n'avez pas défini les IP autorisées lors de la commande, vous pouvez le faire dans l'onglet <code className="action">Configuration</code>. Au moins une adresse IP doit être autorisée ici avant de pouvoir vous connecter à votre base de données.

Ajoutez l'adresse IP de votre ordinateur à l'aide du bouton <code className="action">IP actuelle</code>.

Vous pouvez ensuite supprimer des IP du tableau.

Votre service ClickHouse est désormais pleinement accessible !

Vous pouvez également configurer des listes de contrôle d'accès (ACL) pour des permissions granulaires et créer des topics.
{/* CP-STEPS-END:configure-clickhouse-service */}
