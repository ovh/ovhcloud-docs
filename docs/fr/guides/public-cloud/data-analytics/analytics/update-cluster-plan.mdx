## Objectif

Découvrez comment mettre à niveau l'offre de service de votre cluster selon vos besoins.

:::warning
Une fois que vous avez mis à niveau votre offre, vous ne pourrez plus revenir à une offre inférieure.

:::


## Prérequis

- Accès à l'<ApiLink>API OVHcloud</ApiLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

[[cpnav:publiccloud-analytics]]

## En pratique

### Depuis la console OVHcloud

{/* CP-STEPS-START:update-cluster-plan-cp */}
Dans le menu de gauche de votre projet Public Cloud, cliquez sur votre produit sous **Analytics**, puis sur le nom de votre service.

Dans la carte **Informations générales** de l'onglet <code className="action">Vue d'ensemble</code>, cliquez sur <code className="action">Mettre à niveau</code>. Dans le panneau qui s'ouvre, sélectionnez la nouvelle **Offre** de votre cluster, puis cliquez sur <code className="action">Enregistrer</code>.
{/* CP-STEPS-END:update-cluster-plan-cp */}

### Depuis l'API

:::tip
Si vous n'êtes pas familier avec l'utilisation de l'API OVHcloud, consultez notre guide [Premiers pas avec l'API OVHcloud](/guides/manage-and-operate/api/first-steps).

:::


Pour mettre à niveau ou revenir à une offre inférieure pour le service de votre cluster, utilisez l'appel API suivant :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/kafka/\{clusterId\}"} />

Remplacez `kafka` dans la route par le moteur de votre service (par exemple `opensearch` ou `grafana`).

```console
body : {
    plan: <essential|business|enterprise>
}
```

Si vous revenez à une offre Essential, votre flavor actuel et/ou votre nombre de nœuds seront automatiquement réduits s'ils dépassent les limites de l'offre Essential.
