## Objectif

ClickHouse est un système de base de données analytique en colonnes et open source, conçu pour le traitement en temps réel de volumes de données massifs, offrant des performances élevées, une grande scalabilité et une faible latence.

**Ce guide explique comment se connecter à un cluster ClickHouse à l'aide de la CLI native, HTTPS et des protocoles MySQL.**

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud.
- Un cluster ClickHouse en cours d'exécution sur OVHcloud Public Cloud et acceptant les connexions entrantes.

### Méthodes de connexion

Vous pouvez vous connecter à un cluster ClickHouse en utilisant différents protocoles et ports :

| Protocole | Port | Outil |
|---|---|---|
| ClickHouse Native | 20184 | `clickhouse-client` |
| ClickHouse HTTPS | 20185 | `curl` ou tout client HTTP |
| ClickHouse MySQL | 20186 | `mysql` |

{/* CP-STEPS-START:find-cluster-credentials */}
:::info
Le nom d'hôte, les ports et les identifiants de votre cluster sont disponibles dans l'onglet <code className="action">Dashboard</code> de l'espace client OVHcloud.
:::
{/* CP-STEPS-END:find-cluster-credentials */}


### Se connecter avec le protocole natif ClickHouse (port 20184)

Connectez-vous à l'aide de la CLI officielle `clickhouse-client`. Pour les détails d'installation, consultez la [documentation officielle du client ClickHouse](https://clickhouse.com/docs/interfaces/cli).

```bash
clickhouse-client --user avnadmin \
                  --password <password> \
                  --host clickhouse-01234567-89abcdef.database.cloud.ovh.net \
                  --port 20184 \
                  --secure
```

Remplacez `<password>` par votre mot de passe réel et le nom d'hôte par celui de votre tableau de bord de cluster.

#### Fichier de configuration du client ClickHouse

Vous pouvez configurer le client ClickHouse à l'aide d'un fichier XML ou YAML pour simplifier la connexion. Le client recherche les fichiers de configuration dans l'ordre suivant :

1. Un fichier spécifié avec `-c` / `--config` / `--config-file`.
2. `./clickhouse-client.[xml|yaml|yml]`.
3. `$XDG_CONFIG_HOME/clickhouse/config.[xml|yaml|yml]` (ou `~/.config/clickhouse/config.[xml|yaml|yml]` si XDG_CONFIG_HOME n'est pas défini).
4. `~/.clickhouse-client/config.[xml|yaml|yml]`.
5. `/etc/clickhouse-client/config.[xml|yaml|yml]`.

<details>
<summary>**Exemple de configuration XML**</summary>


Créez un fichier nommé `clickhouse-client.xml` avec le contenu suivant :

```xml
`<config>`
    `<user>avnadmin</user>`
    `<password>your_password</password>`
    `<secure>true</secure>`

    `<openSSL>`
        `<client>`
            `<caConfig>/home/user/clickhouse/ca.pem</caConfig>`
        </client>
    </openSSL>

    `<connections_credentials>`
        `<connection>`
            `<name>default</name>`
            `<hostname>clickhouse-01234567-89abcdef.database.cloud.ovh.net</hostname>`
            `<port>20184</port>`
        </connection>
    </connections_credentials>
</config>
```

Pour plus d'informations, consultez le [fichier de configuration officiel d'exemple](https://github.com/ClickHouse/ClickHouse/blob/master/programs/client/clickhouse-client.xml).

</details>


<details>
<summary>**Exemple de configuration YAML**</summary>


Créez un fichier nommé `clickhouse-client.yml` avec le contenu minimal suivant :

```yaml
user: avnadmin
password: 'your_password'
secure: true
openSSL:
  client:
    caConfig: '/home/user/clickhouse/ca.pem'
```

</details>


Modifiez ces valeurs selon la configuration de votre propre cluster.

#### Insérer des données dans ClickHouse avec la CLI native ClickHouse

Pour ce premier exemple, insérons une ligne de test dans la table `my_table` de la base `test_db`.

```bash
clickhouse-client --query "INSERT INTO test_db.my_table (id, message) VALUES (1, 'test-message-content')"
```

#### Interroger des données depuis ClickHouse avec la CLI native ClickHouse

Récupérez toutes les données de la table `my_table` dans la base `test_db` :

```bash
clickhouse-client --query "SELECT * FROM test_db.my_table"
```

### Se connecter avec HTTPS (port 20185)

Connectez-vous à l'aide de `curl` ou de tout client HTTP via HTTPS :

```bash
curl https://clickhouse-01234567-89abcdef.database.cloud.ovh.net:20185 \
  --user avnadmin:`<password>` \
  -d "SELECT 1"
```

Remplacez `<password>` par votre mot de passe réel et le nom d'hôte par celui de votre tableau de bord de cluster.

### Se connecter avec le protocole MySQL (port 20186)

Connectez-vous à l'aide du client standard `mysql` via l'interface compatible MySQL :

```bash
mysql --host=clickhouse-01234567-89abcdef.database.cloud.ovh.net \
      --port=20186 \
      --user=avnadmin \
      --password=<password> \
      --ssl-mode=REQUIRED
```

Remplacez `<password>` par votre mot de passe réel et le nom d'hôte par celui de votre tableau de bord de cluster.
