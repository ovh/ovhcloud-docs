## Objectif

Apache Kafka est une plateforme open source distribuée de streaming d'événements, conçue pour le traitement de données en temps réel et à grande échelle, avec une scalabilité et une durabilité élevées ainsi qu'une faible latence.

Ce guide explique comment créer des topics Kafka via l'espace client OVHcloud.

## Prérequis

- Accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un [cluster Kafka en cours d'exécution](/guides/public-cloud/databases/kafka-getting-started) sur OVHcloud Public Cloud [acceptant les connexions entrantes](/guides/public-cloud/databases/kafka-capabilities)

## En pratique

### Créer des topics Kafka

{/* CP-STEPS-START:kafka-create-topics */}
Les topics peuvent être considérés comme des catégories, vous permettant d'organiser vos enregistrements Kafka. Les producteurs écrivent dans les topics et les consommateurs lisent depuis les topics.

Pour créer des topics Kafka, accédez d'abord à l'onglet `Topics` puis cliquez sur le bouton `Ajouter un topic` :

![Ajouter un topic](/images/guides/public-cloud/data-analytics/analytics/kafka-create-topics/kafka_topics.v2.png)

Dans la configuration avancée, vous pouvez modifier la valeur par défaut des paramètres suivants :

- Minimum in-sync replica (2 par défaut)
- Partitions (1 partition par défaut)
- Replication (3 brokers par défaut)
- Retention size in bytes (-1 : aucune limitation par défaut)
- Retention time in hours (-1 : aucune limitation par défaut)
- Deletion policy

![Créer un topic](/images/guides/public-cloud/data-analytics/analytics/kafka-create-topics/kafka_create_topic.v2.png)
