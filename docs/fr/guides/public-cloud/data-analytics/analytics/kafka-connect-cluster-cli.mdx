## Objectif

Apache Kafka est une plateforme open source distribuée de streaming d'événements, conçue pour le traitement de données en temps réel et à grande échelle, avec une scalabilité et une durabilité élevées ainsi qu'une faible latence.

Ce guide explique comment vous connecter à un cluster Kafka via la CLI.

## Prérequis

- Accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un [cluster Kafka en cours d'exécution](/guides/public-cloud/databases/kafka-getting-started) sur OVHcloud Public Cloud [acceptant les connexions entrantes](/guides/public-cloud/databases/kafka-capabilities)

## En pratique

### Première connexion en CLI

:::warning
Vérifiez que l'adresse IP visible depuis votre navigateur fait partie des « Authorised IPs » définies pour ce service Kafka.

Vérifiez également que l'utilisateur dispose des ACL nécessaires pour les topics ciblés.
:::

#### Installer une CLI Apache Kafka

Dans le cadre de l'installation officielle d'Apache Kafka, vous obtiendrez différents scripts qui vous permettront également de vous connecter à Kafka dans un environnement Java 8+ : [Apache Kafka Official Quickstart](https://kafka.apache.org/quickstart).

Nous vous proposons plutôt d'utiliser un client producteur et consommateur générique et plus léger (ne nécessitant pas de JVM) : `Kcat` (anciennement `kafkacat`).

##### **Installer Kcat**

Pour l'installation de ce client, veuillez suivre les instructions disponibles sur : [Kafkacat Official Github](https://github.com/edenhill/kcat).

##### **Fichier de configuration Kcat**

Créons un fichier de configuration pour simplifier les commandes CLI agissant comme producteur et consommateur Kafka :

kafkacat.conf :

```text
bootstrap.servers=kafka-f411d2ae-f411d2ae.database.cloud.ovh.net:20186
enable.ssl.certificate.verification=false
ssl.ca.location=/home/user/kafkacat/ca.pem
security.protocol=ssl
ssl.key.location=/home/user/kafkacat/service.key
ssl.certificate.location=/home/user/kafkacat/service.cert
```

Dans notre exemple, l'adresse et le port du cluster sont **kafka-f411d2ae-f411d2ae.database.cloud.ovh.net:20186** et les certificats CA téléchargés précédemment se trouvent dans le dossier **/home/user/kafkacat/**.

Modifiez ces valeurs selon votre propre configuration.

##### **Producteur Kafka**

Pour ce premier exemple, envoyons la clé "test-message-key" et son contenu "test-message-content" vers le topic "my-topic".

```sh
echo test-message-content | kcat -F kafkacat.conf -P -t my-topic -k test-message-key
```

*Remarque* : selon le binaire installé, la commande CLI peut être **kcat** ou **kafkacat**.

##### **Consommateur Kafka**

Les données peuvent être récupérées depuis "my-topic".

```sh
kcat -F kafkacat.conf -C -t my-topic -o -1 -e
```

*Remarque* : selon le binaire installé, la commande CLI peut être **kcat** ou **kafkacat**.
