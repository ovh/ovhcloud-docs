## Objectif

Apache Kafka est une plateforme open source distribuée de streaming d'événements, conçue pour le traitement de données en temps réel et à grande échelle, avec une scalabilité et une durabilité élevées ainsi qu'une faible latence.

Ce guide explique comment configurer votre cluster Kafka pour accepter les connexions entrantes via la console OVHcloud.

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un [cluster Kafka en cours d'exécution](/guides/public-cloud/databases/kafka-getting-started) sur OVHcloud Public Cloud

## En pratique

### Configurer le service Apache Kafka

{/* CP-STEPS-START:configure-kafka-service */}
Une fois votre service Kafka opérationnel, vous devez définir au moins un utilisateur et une IP autorisée (si cela n'a pas déjà été fait lors de la commande) pour pouvoir vous connecter pleinement au service (en tant que producteur ou consommateur).

Le statut de votre service passe à **Actif** lorsqu'il est prêt.

#### Configurer un utilisateur

Basculez sur l'onglet <code className="action">Utilisateurs</code>. Un utilisateur admin nommé `avnadmin` est préconfiguré lors de l'installation du service.

Vous pouvez ajouter d'autres utilisateurs en cliquant sur le bouton <code className="action">Ajouter un utilisateur</code>.

Saisissez un **Nom d'utilisateur**, puis cliquez sur <code className="action">Créer</code>. Le mot de passe n'est affiché qu'une seule fois : notez-le.

Les mots de passe peuvent être réinitialisés depuis le bouton <code className="action">...</code> de la ligne de l'utilisateur dans l'onglet <code className="action">Utilisateurs</code> (<code className="action">Réinitialiser le mot de passe</code>).

Un nouvel utilisateur n'a aucun accès à vos topics tant que vous ne lui accordez pas cet accès avec une liste de contrôle d'accès (ACL). Nous vous recommandons de créer un utilisateur par application, avec uniquement les permissions dont elle a besoin. Consultez le [guide sur les ACL](/guides/public-cloud/data-analytics/analytics/kafka-configure-acl).

#### Configurer les IP autorisées

:::warning
Pour des raisons de sécurité, la configuration réseau par défaut n'autorise aucune connexion entrante. Il est donc essentiel d'autoriser les adresses IP appropriées pour accéder à votre cluster Kafka.
:::

Si vous n'avez pas défini les restrictions IP lors de la commande, vous pouvez le faire dans la section **Restrictions d’IP** de l'onglet <code className="action">Configuration</code>. Au moins une adresse IP doit être autorisée ici avant de pouvoir vous connecter à votre service.

Cliquez sur <code className="action">Ajouter</code> et saisissez une adresse IP ou un bloc CIDR dans le champ **Bloc d’IP (CIDR)**, ou ajoutez l'adresse IP de votre ordinateur à l'aide du bouton <code className="action">Ajouter mon IP actuelle</code>, puis cliquez sur <code className="action">Enregistrer</code>.

Vous pouvez ensuite supprimer des IP de la liste.

Votre service Apache Kafka est désormais pleinement accessible !
Vous pouvez également configurer des listes de contrôle d'accès (ACL) pour des permissions granulaires et créer des topics.
