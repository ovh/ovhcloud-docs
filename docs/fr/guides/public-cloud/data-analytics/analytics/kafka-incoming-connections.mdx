## Objectif

Apache Kafka est une plateforme open source distribuée de streaming d'événements, conçue pour le traitement de données en temps réel et à grande échelle, avec une scalabilité et une durabilité élevées ainsi qu'une faible latence.

Ce guide explique comment configurer votre cluster Kafka pour accepter les connexions entrantes via l'espace client OVHcloud.

## Prérequis

- Accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un [cluster Kafka en cours d'exécution](/guides/public-cloud/databases/kafka-getting-started) sur OVHcloud Public Cloud

## En pratique

### Configurer le service Apache Kafka

{/* CP-STEPS-START:configure-kafka-service */}
Une fois votre service Kafka opérationnel, vous devrez définir au moins un utilisateur et une IP autorisée (si ce n'est pas déjà fait lors de la commande) afin de vous connecter pleinement au service (en tant que producteur ou consommateur).

L'onglet `Dashboard` se met à jour automatiquement lorsque votre service est prêt.

![Informations générales Kafka](/images/guides/public-cloud/data-analytics/analytics/kafka-incoming-connections/kafka_cluster_ready_to_configure.v2.png)

#### Configurer un utilisateur

Basculez vers l'onglet `Utilisateurs`. Un utilisateur admin nommé `avnadmin` est préconfiguré lors de l'installation du service.

![Utilisateurs](/images/guides/public-cloud/data-analytics/analytics/kafka-incoming-connections/kafka_users.v2.png)

Vous pouvez ajouter d'autres utilisateurs en cliquant sur le bouton `Ajouter un utilisateur`.

![Ajouter un utilisateur](/images/guides/public-cloud/data-analytics/analytics/kafka-incoming-connections/kafka_add_user.v2.png)

Saisissez un nom d'utilisateur, puis cliquez sur `Créer un utilisateur`.

Les mots de passe doivent être réinitialisés depuis le tableau `Users`.

![Réinitialisation du mot de passe](/images/guides/public-cloud/data-analytics/analytics/kafka-incoming-connections/kafka_user_password_reset1.v2.png)

#### Configurer les IP autorisées

:::warning
Pour des raisons de sécurité, la configuration réseau par défaut n'autorise aucune connexion entrante. Il est donc essentiel d'autoriser les adresses IP appropriées afin d'accéder correctement à votre cluster Kafka.
:::

Si vous n'avez pas défini les IP autorisées lors de la commande, vous pouvez le faire dans l'onglet `Configuration`. Au moins une adresse IP doit y être autorisée avant de pouvoir vous connecter à votre base de données.

![IP autorisée](/images/guides/public-cloud/data-analytics/analytics/kafka-incoming-connections/kafka_authorized_ip.v2.png)

Ajoutez l'adresse IP de votre ordinateur à l'aide du bouton `IP actuelle`.
Vous pourrez ensuite supprimer des IP du tableau.

![Ajouter une IP](/images/guides/public-cloud/data-analytics/analytics/kafka-incoming-connections/kafka_add_ip.v2.png)

Votre service Apache Kafka est désormais pleinement accessible !
