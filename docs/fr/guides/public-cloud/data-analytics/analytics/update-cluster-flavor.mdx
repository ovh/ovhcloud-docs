## Objectif

Découvrez comment ajuster le flavor de votre cluster selon vos besoins.

## Prérequis

- Accès à l'<ApiLink>API</ApiLink> OVHcloud (créez vos identifiants en consultant [ce guide](/guides/manage-and-operate/api/first-steps))
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

[[cpnav:publiccloud-analytics]]

## En pratique

### Augmenter votre flavor

Cette option est disponible via l'<ApiLink>API</ApiLink> OVHcloud et la <ManagerLink to="/">console OVHcloud</ManagerLink>.

{/* CP-STEPS-START:instructions-upgrade */}
Dans le menu de gauche de votre projet Public Cloud, cliquez sur votre produit sous **Analytics**, puis sur le nom de votre service.

Dans la carte **Informations générales** de l'onglet <code className="action">Vue d'ensemble</code>, cliquez sur <code className="action">Mettre à niveau</code>. Dans le panneau qui s'ouvre, sélectionnez la nouvelle **Flavor des nœuds** de votre cluster, puis cliquez sur <code className="action">Enregistrer</code>.
{/* CP-STEPS-END:instructions-upgrade */}

### Diminuer votre flavor

Cette option est actuellement disponible via l'<ApiLink>API</ApiLink> OVHcloud.

Pour pouvoir diminuer votre flavor, vous devez disposer d'un seuil de 20 % entre l'espace disque actuellement utilisé (stockage de base + stockage additionnel) et l'espace de stockage maximum autorisé pour le flavor.

Par exemple, si vous disposez d'un cluster OpenSearch avec db1-15 comme flavor et moins de 384 Go (80 % de 480 Go) d'espace disque utilisé, vous pouvez diminuer le flavor à db1-7 sur cet endpoint :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/opensearch/\{clusterId\}"} />
