## Objectif

Découvrez comment ajuster le flavor de votre cluster selon vos besoins.

## Comment augmenter votre flavor

Cette option est disponible via l'<ApiLink>API</ApiLink> OVHcloud et l'<ManagerLink to="/">espace client</ManagerLink>.

### Prérequis

- Accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink> ou à l'<ApiLink>API</ApiLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

### En pratique

{/* CP-STEPS-START:instructions-upgrade */}
Pour ajuster le flavor de votre cluster, connectez-vous à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink> et ouvrez votre projet Public Cloud. Cliquez sur <code className="action">Data Analysis</code> ou <code className="action">Data Streaming</code> dans la barre de navigation de gauche, puis sélectionnez votre instance de moteur.

<img className="thumbnail" alt="Vue d'ensemble du cluster" src="/images/public-cloud/data-analytics/analytics/analytics-update-cluster-flavor/cluster_overview.png" loading="lazy" />

Cliquez sur <code className="action">Modifier le modèle de nœud</code> et ajustez le flavor de votre cluster.

<img className="thumbnail" alt="Modifier le modèle de nœud" src="/images/public-cloud/data-analytics/analytics/analytics-update-cluster-flavor/flavor_change.png" loading="lazy" />
{/* CP-STEPS-END:instructions-upgrade */}

## Comment diminuer votre flavor

Cette option est actuellement disponible via l'<ApiLink>API</ApiLink> OVHcloud.

### Prérequis

- Accès à l'<ApiLink>API</ApiLink> OVHcloud (créez vos identifiants en consultant [ce guide](/guides/manage-and-operate/api/first-steps))
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

### En pratique

Pour pouvoir diminuer votre flavor, vous devez disposer d'un seuil de 20 % entre l'espace disque actuellement utilisé (stockage de base + stockage additionnel) et l'espace de stockage maximum autorisé pour le flavor.

<img className="thumbnail" alt="Modifier le modèle de nœud" src="/images/public-cloud/data-analytics/analytics/analytics-update-cluster-flavor/flavor_change.png" loading="lazy" />

Par exemple, si vous disposez d'un cluster OpenSearch avec db1-15 comme flavor et moins de 384 Go (80 % de 480 Go) d'espace disque utilisé, vous pouvez diminuer le flavor à db1-7 sur cet endpoint :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/opensearch/\{clusterId\}"} />
