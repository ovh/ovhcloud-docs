Public Cloud Analytics vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

Le tableau RACI ci-dessous détaille les responsabilités partagées entre OVHcloud et le client pour les services Public Cloud Analytics.
Ce modèle partagé peut aider à alléger la charge opérationnelle du client.

## Définition RACI

| Rôles |
| --- |
| R : est en charge de la réalisation du processus |
| A : garantit la bonne exécution du processus |
| C : est consulté durant le processus |
| I : est informé des résultats du processus |

Pour information, un **Service** désigne un service Public Cloud Analytics tel qu'un cluster Kafka ou OpenSearch.

### 1. Avant la souscription

#### 1.1. Spécifier le service selon les besoins

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
| Se renseigner sur les capacités et limites des Services détaillées dans la documentation OVHcloud | RA | I |
| Choisir la localisation du service | RA | I |
| Dimensionner les services selon les besoins | RA | I |
| Choisir les options selon les besoins | RA | I |

| Acheter et détenir les licences et droits d'utilisation des solutions de sauvegarde fournies par OVHcloud |  | RA |
