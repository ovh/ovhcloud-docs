## Objectif

Apache Kafka est une plateforme open source distribuée de streaming d'événements, conçue pour le traitement de données en temps réel et à grande échelle, avec une scalabilité et une durabilité élevées ainsi qu'une faible latence.

Ce guide explique comment créer un cluster Kafka via l'espace client OVHcloud.

## Prérequis

- Accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

## En pratique

### Souscrire au service

{/* CP-STEPS-START:kafka-create-cluster-subscribe */}

Connectez-vous à votre <ManagerLink to="/">espace client OVHcloud</ManagerLink> et basculez sur `Public Cloud` dans la barre de navigation supérieure. Après avoir sélectionné votre projet Public Cloud, cliquez sur `Data Streaming` dans la barre de navigation de gauche, sous **Databases & Analytics**.

Cliquez sur le bouton `Créer un service`.

#### Sélectionner votre service Analytics

Cliquez sur le type de service Analytics que vous souhaitez utiliser, ainsi que sur sa version.
Un nom aléatoire est généré pour votre service. Vous pouvez le modifier à cette étape ou ultérieurement.

![Choisir le service Data Streaming](/images/guides/public-cloud/data-analytics/analytics/kafka-create-cluster/kafka_db_type.v2.png)

#### Sélectionner un datacentre

Choisissez la région géographique du datacentre qui hébergera votre service, ainsi que le mode de déploiement (1-AZ ou 3-AZ).

![Choisir un datacentre](/images/guides/public-cloud/data-analytics/analytics/kafka-create-cluster/kafka_region.v2.png)

#### Sélectionner une offre

Lors de cette étape, choisissez une offre de service adaptée. Si nécessaire, vous pourrez changer d'offre après la création, à la hausse comme à la baisse.

![Choisir une offre](/images/guides/public-cloud/data-analytics/analytics/kafka-create-cluster/kafka_solution_business.v2.png)

Consultez la [page des capacités](/guides/public-cloud/data-analytics/analytics/getting-started) du service Analytics sélectionné pour obtenir des informations détaillées sur les propriétés de chaque offre.

#### Sélectionner l'instance

Choisissez le type d'instance pour les nœuds de votre service, vous pourrez le modifier par la suite. Le nombre de nœuds dépend de l'offre choisie précédemment.

![Choisir l'instance](/images/guides/public-cloud/data-analytics/analytics/kafka-create-cluster/kafka_features.v2.png)

#### Sélectionner le stockage

Le stockage peut être augmenté jusqu'à 3 fois le stockage de base.

![Choisir le stockage](/images/guides/public-cloud/data-analytics/analytics/kafka-create-cluster/kafka_storage.v2.png)

#### Configurer vos options

Choisissez les options réseau et ajoutez à la liste d'autorisation les adresses IP qui accèderont au service.

![Configurer les options](/images/guides/public-cloud/data-analytics/analytics/kafka-create-cluster/kafka_options.v2.png)

#### Vérifier et confirmer

Un récapitulatif de votre commande s'affiche afin de vous aider à vérifier la configuration de votre service.

![Vérifier la commande](/images/guides/public-cloud/data-analytics/analytics/kafka-create-cluster/kafka_configuration.1.v2.png)

Les composants du prix sont également récapitulés, avec une estimation mensuelle.

![Vérifier le prix](/images/guides/public-cloud/data-analytics/analytics/kafka-create-cluster/kafka_configuration.2.v2.png)

Cliquez sur le bouton `Équivalent API et Terraform` pour ouvrir la fenêtre suivante :

![Équivalent API et Terraform](/images/guides/public-cloud/data-analytics/analytics/kafka-create-cluster/kafka_configuration.3.v2.png)

Les informations affichées dans cette fenêtre peuvent vous aider à automatiser la création du service avec l'[API OVHcloud](/guides/manage-and-operate/api/first-steps) ou le provider Terraform OVHcloud.

Lorsque vous êtes prêt, cliquez sur le bouton `Commander` pour créer votre service.
En quelques minutes, votre nouveau service Apache Kafka sera déployé.
Des messages dans l'espace client OVHcloud vous informeront lorsque l'outil de streaming sera prêt à l'emploi.
