:::warning
Lakehouse est en alpha. Il n'est accessible qu'aux comptes invités au programme alpha, et ses fonctionnalités, son interface et son API peuvent évoluer.
:::

## Objectif

Par défaut, toute adresse peut joindre les points d'accès d'un Lakehouse, à condition de disposer d'un identifiant valide. Le filtrage IP limite l'accès aux adresses que vous listez.

**Ce guide explique comment activer le filtrage IP sur un Lakehouse.**

## Prérequis

- Un Lakehouse dans votre projet Public Cloud. Consultez le guide [Lakehouse - Premiers pas](/guides/public-cloud/data-analytics/lakehouse/lakehouse-getting-started).
- Les adresses IP publiques des machines et réseaux qui doivent joindre le Lakehouse.

## En pratique

Dans l'espace client OVHcloud, ouvrez votre projet Public Cloud, rendez-vous dans **Analytics** > **Lakehouse**, cliquez sur le nom de votre Lakehouse et ouvrez l'onglet **Accès réseau**.

![Onglet Accès réseau avec deux adresses IP listées et le filtrage désactivé](/images/guides/public-cloud/data-analytics/lakehouse/network-access/network-ip-filtering.png)

### Lister les adresses autorisées

Cliquez sur **Ajouter** et saisissez une adresse IPv4 ou IPv6 publique, ou un bloc en notation CIDR (par exemple `203.0.113.0/24` pour un réseau entier), avec une description facultative. Répétez l'opération pour chaque adresse, puis cliquez sur **Enregistrer**.

- Les plages privées et réservées sont refusées : seules des adresses publiques peuvent être listées.
- La liste doit contenir au moins une entrée IPv4 ; une liste d'entrées IPv6 seules bloquerait tous les clients IPv4.

:::warning
Ajoutez l'adresse depuis laquelle vous travaillez avant d'activer le filtrage. Sinon, vos outils perdent l'accès au point d'accès SQL et au catalogue Iceberg REST depuis cette adresse. L'option **Ajouter mon IP actuelle** renseigne l'adresse depuis laquelle vous êtes connecté.
:::

### Activer le filtrage

Tant que le filtrage est désactivé, les adresses listées sont enregistrées mais pas appliquées : toute adresse peut joindre le Lakehouse. Cliquez sur **Appliquer le filtrage** pour appliquer la liste.

Le filtrage s'applique au point d'accès SQL, au catalogue Iceberg REST et aux clés S3 du Lakehouse. Il prend effet en une minute environ. Une requête provenant d'une adresse non listée est refusée avec l'erreur `403` et le message `Source address not allowed`.

Pour modifier la liste ensuite, éditez-la et enregistrez de nouveau : la nouvelle liste prend elle aussi effet en une minute environ.
