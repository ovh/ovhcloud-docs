## Objectif

Vous pouvez gérer vos instances Public Cloud dans la <ManagerLink to="/">console OVHcloud</ManagerLink>.

**Ce guide détaille les actions disponibles dans la console OVHcloud pour une instance Public Cloud.**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Une [instance Public Cloud](/guides/public-cloud/compute/getting-started) dans votre projet

[[cpnav:publiccloud-instances]]

## En pratique

### Utiliser l'interface de gestion des instances

{/* CP-STEPS-START:instances-list */}
Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">Instances</code> sous **Compute**.

Cette page liste l'ensemble de vos instances Public Cloud et certaines de leurs propriétés :

- le nom et l'ID de l'instance, nécessaire pour certains appels API ;
- la localisation du datacentre, c'est-à-dire la région de l'instance ;
- le modèle de l'instance ;
- l'image, c'est-à-dire l'OS installé sur l'instance ;
- les adresses IP publiques de l'instance ;
- les adresses IP privées actuellement attachées à l'instance ;
- les volumes (disques) additionnels actuellement attachés à l'instance ;
- le statut de l'instance, indiquant si elle est à l'état `Active`.

{/* CP-STEPS-END:instances-list */}
### Options de gestion sur le tableau de bord de l'instance

{/* CP-STEPS-START:instance-dashboard */}
Depuis la liste des instances, cliquez sur le nom de l'instance concernée.

Vous accédez alors à l'onglet <code className="action">Vue d'ensemble</code> de l'instance. Son encadré **Informations générales** centralise les principaux détails de votre instance (modèle, région, image, ressources et prix), à côté des encadrés **Détails de connexion**, **Réseau public**, **Réseau privé**, **Gestion des snapshots** et **Gestion du stockage**. La page propose aussi les onglets <code className="action">Console VNC</code>, <code className="action">Observabilité</code> et <code className="action">Snapshots</code>.

La plupart de ces opérations sont aussi accessibles depuis la liste des instances, via le bouton <code className="action">...</code> du tableau.
{/* CP-STEPS-END:instance-dashboard */}

#### Éditer la configuration d'une instance

{/* CP-STEPS-START:edit-instance-configuration */}
Chaque élément de la configuration de l'instance se modifie depuis l'onglet <code className="action">Vue d'ensemble</code> :

- **Modifier le nom** : modifiez le nom de l'instance dans l'en-tête de la page. Vous pouvez donner un nom à l'instance pour plus de facilité d'identification.
- **Modifier l'image** : dans l'encadré **Informations générales**, cliquez sur <code className="action">Modifier l'image</code> sur la ligne **Image**. Vous pouvez choisir un autre système d'exploitation pour l'instance (notez que la réinstallation d'une instance supprimera toutes les données qu'elle contient).
- **Modifier le modèle** : dans l'encadré **Informations générales**, cliquez sur <code className="action">Modifier le modèle</code> sur la ligne **Modèle**, puis choisissez le nouveau modèle sur la page **Changer de modèle**. Consultez [ce guide](/guides/public-cloud/compute/getting-started#model) pour plus d'informations sur les options.
- **Modifier la période de facturation** : dans l'encadré **Informations générales**, cliquez sur <code className="action">Passer en mensuel</code> pour passer d'une facturation horaire à mensuelle. Consultez [ce guide](/guides/account-and-service-management/managing-billing-payments-and-services/changing-hourly-monthly-billing) pour plus d'informations.

{/* CP-STEPS-END:edit-instance-configuration */}

#### Créer un snapshot d'une instance

{/* CP-STEPS-START:create-backup */}
Dans la liste des instances, cliquez sur <code className="action">...</code> sur la ligne de l'instance dans la liste, puis sélectionnez <code className="action">Créer un snapshot</code>.
{/* CP-STEPS-END:create-backup */}

Reportez-vous au guide « [Créer un snapshot d'une instance](/guides/public-cloud/compute/save-an-instance) » pour plus d'informations.

#### Supprimer une instance

{/* CP-STEPS-START:delete-instance */}
Dans la liste des instances, cliquez sur <code className="action">...</code> sur la ligne de l'instance dans la liste, puis sélectionnez <code className="action">Supprimer</code>. Vous pouvez aussi cliquer sur <code className="action">Supprimer</code> en bas de l'encadré **Informations générales** de l'onglet <code className="action">Vue d'ensemble</code>.

Cette action supprimera définitivement l'instance et toutes ses données.

Confirmez la demande en cliquant sur <code className="action">Supprimer l'instance</code> dans la fenêtre **Supprimer l'instance**.
{/* CP-STEPS-END:delete-instance */}

:::warning
La suppression d'une instance ne supprime pas automatiquement toutes les options qui lui sont associées (storage, snapshot, backup, etc...), assurez-vous que toutes les autres options associées à l'instance sont également supprimées pour arrêter d'être facturé.

:::


#### Attacher un volume

{/* CP-STEPS-START:attach-volume */}
Dans l'encadré **Gestion du stockage** de l'onglet <code className="action">Vue d'ensemble</code>, cliquez sur <code className="action">Attacher un volume</code>.

Sélectionnez ensuite le volume à associer à l'instance, puis cliquez sur <code className="action">Attacher</code>. Une fois attaché, le volume est immédiatement disponible et peut être monté depuis le système d'exploitation de l'instance.
{/* CP-STEPS-END:attach-volume */}

#### Changer le reverse DNS

{/* CP-STEPS-START:change-reverse-dns */}
Le reverse DNS de l'adresse IP publique de l'instance se gère avec l'ensemble de vos adresses IP : dans la barre supérieure de la console OVHcloud, cliquez sur <code className="action">Bare Metal Cloud</code>, puis sur <code className="action">Adresses IP</code> sous **Réseau** dans le menu de gauche, et ouvrez l'onglet <code className="action">Reverse DNS</code>.
{/* CP-STEPS-END:change-reverse-dns */}

Reportez-vous au guide « [Configurer le reverse DNS d'une instance Public Cloud](/guides/public-cloud/compute/setup-instance-reverse) » pour plus d'informations.

#### Configurer le pare-feu

{/* CP-STEPS-START:configure-firewall */}
L'Edge Network Firewall de l'adresse IP publique de l'instance se gère avec l'ensemble de vos adresses IP : dans la barre supérieure de la console OVHcloud, cliquez sur <code className="action">Bare Metal Cloud</code>, puis sur <code className="action">Adresses IP</code> sous **Réseau** dans le menu de gauche, et ouvrez l'onglet <code className="action">Edge Firewall</code>.
{/* CP-STEPS-END:configure-firewall */}

Reportez-vous au guide « [Activer et configurer le Edge Network Firewall](/guides/bare-metal-cloud/dedicated-servers/firewall-network) » pour plus d'informations.

#### Gérer les réseaux privés

{/* CP-STEPS-START:manage-private-networks */}
Dans l'encadré **Réseau privé** de l'onglet <code className="action">Vue d'ensemble</code>, cliquez sur <code className="action">Gérer mon réseau privé</code>.
{/* CP-STEPS-END:manage-private-networks */}

Reportez-vous au guide « [Créer un réseau privé avec une Gateway](/guides/public-cloud/network-services/create-private-network-gateway) » pour plus d'informations.

#### Attacher un réseau

{/* CP-STEPS-START:attach-network */}
Dans l'encadré **Réseau privé** de l'onglet <code className="action">Vue d'ensemble</code>, cliquez sur <code className="action">Attacher un réseau</code>.

Sélectionnez le réseau souhaité dans la liste déroulante, puis cliquez sur <code className="action">Confirmer</code>.
{/* CP-STEPS-END:attach-network */}

#### Actions supplémentaires

{/* CP-STEPS-START:additional-actions */}
Dans l'encadré **Informations générales** de l'onglet <code className="action">Vue d'ensemble</code>, cliquez sur <code className="action">Actions supplémentaires</code>. Les mêmes actions sont disponibles dans la liste des instances, via le bouton <code className="action">...</code> de la ligne de l'instance.
{/* CP-STEPS-END:additional-actions */}

##### Créer un snapshot automatique d'une instance

{/* CP-STEPS-START:create-automatic-backup */}
Dans la liste des instances, cliquez sur <code className="action">...</code> sur la ligne de l'instance dans la liste, puis sélectionnez <code className="action">Créer un snapshot automatique</code>.
{/* CP-STEPS-END:create-automatic-backup */}

Reportez-vous au guide « [Créer un snapshot d'une instance](/guides/public-cloud/compute/save-an-instance#créer-un-snapshot-automatique-dune-instance) » pour plus d'informations.

##### Arrêter une instance

{/* CP-STEPS-START:stop-instance */}
Cliquez sur <code className="action">Éteindre</code>, puis sur <code className="action">Confirmer</code> dans la fenêtre **Éteindre votre instance**.

Ceci mettra l'instance dans l'état `Arrêtée`, mais vous serez toujours facturé au même prix pour votre instance. Référez-vous à notre guide « [Suspendre ou mettre en pause une instance](/guides/public-cloud/compute/suspend-or-pause-an-instance#arreter-suspend-une-instance) » pour plus d'informations.

Cliquez sur <code className="action">Démarrer</code> pour redémarrer l'instance.
{/* CP-STEPS-END:stop-instance */}

##### Utiliser le mode rescue

{/* CP-STEPS-START:rescue-mode */}
Cliquez sur <code className="action">Redémarrer en mode rescue</code>, puis sur <code className="action">Confirmer</code> dans la fenêtre qui s'ouvre.
{/* CP-STEPS-END:rescue-mode */}

Cela activera le mode rescue de l'instance. Consultez notre guide [Comment activer le mode rescue sur une instance Public Cloud](/guides/public-cloud/compute/put-an-instance-in-rescue-mode) pour obtenir des informations détaillées.

##### Redémarrer une instance

{/* CP-STEPS-START:restart-instance */}
:::warning
L'option de redémarrage à chaud (soft) est actuellement indisponible pour les instances Metal.

:::


- Cliquez sur <code className="action">Redémarrer à chaud (soft)</code> pour effectuer un redémarrage au niveau logiciel.
- Cliquez sur <code className="action">Redémarrer à froid (hard)</code> pour lancer un reboot au niveau matériel.

Confirmez la demande de redémarrage en cliquant sur <code className="action">Confirmer</code> dans la fenêtre qui s'ouvre.
{/* CP-STEPS-END:restart-instance */}

##### Suspendre (*shelve*) une instance

{/* CP-STEPS-START:shelve-instance */}
Cliquez sur <code className="action">Suspendre</code>, puis sur <code className="action">Confirmer</code> dans la fenêtre **Suspension de votre instance**.

Ceci placera l'instance dans l'état « *shelved* », affiché comme `Suspendue`. Consultez notre guide « [Suspendre ou mettre en pause une instance](/guides/public-cloud/compute/suspend-or-pause-an-instance#suspendre-shelve-une-instance) » pour plus d'informations sur les différents états de suspension d'une instance.

Cliquez sur <code className="action">Réactiver</code> pour restaurer l'état `Active` de l'instance.
{/* CP-STEPS-END:shelve-instance */}

##### Réinstaller une instance

{/* CP-STEPS-START:reinstall-instance */}
Cliquez sur <code className="action">Réinstaller</code>, puis sur <code className="action">Confirmer</code> dans la fenêtre **Réinstaller une instance**.

Cette action réinstallera l'instance avec le même système d'exploitation, à condition que l'image soit toujours prise en charge.

Notez que la réinstallation **supprime toutes les données** actuellement stockées sur votre instance.
{/* CP-STEPS-END:reinstall-instance */}

### Accéder à la console VNC <a name="accessvnc"></a>

{/* CP-STEPS-START:access-vnc-console */}
Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">Instances</code> sous **Compute**, puis cliquez sur le nom de l'instance dans le tableau.

Ouvrez l'onglet <code className="action">Console VNC</code>.
{/* CP-STEPS-END:access-vnc-console */}

La console VNC fournit un accès direct à votre instance. Pour que cet accès fonctionne, vous devez d'abord configurer un nom d'utilisateur et un mot de passe sur l'instance. 

Consultez notre guide « [Comment créer une instance Public Cloud et s'y connecter](/guides/public-cloud/compute/getting-started) » pour plus d'informations.
