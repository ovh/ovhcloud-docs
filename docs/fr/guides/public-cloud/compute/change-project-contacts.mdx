## Objectif

Vous pouvez modifier les contacts administrateur et facturation d'un projet Public Cloud dans la console OVHcloud.<br/>
La modification de ces contacts permet de dissocier la gestion technique de la gestion facturation, pour les services d'un projet.

**Ce guide vous explique comment modifier les contacts d'un projet Public Cloud dans la console OVHcloud.**

## Prérequis

- Avoir un projet [Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Contacts administrateur et facturation dans la même filiale OVHcloud

[[cpnav:publiccloud-contacts-rights]]

## En pratique

### Modifier les contacts

{/* CP-STEPS-START:instructions */}
Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">Gestion du projet</code>, puis sur l'onglet <code className="action">Contacts et droits</code>.

Cette page vous permet de voir les contacts administrateur et facturation associés à votre projet.

Cliquez sur l'un des liens <code className="action">Éditer</code> pour modifier les contacts actuels. Cela ouvrira la page **Gestion des contacts** de la console OVHcloud dans un nouvel onglet. Les liens <code className="action">Éditer</code> ne sont disponibles que pour les comptes de la zone UE, et pas pour un projet en mode découverte.

Les contacts de votre projet Public Cloud s'affichent dans l'onglet <code className="action">Mes services</code>. Cliquez sur le bouton <code className="action">...</code> puis sur <code className="action">Modifier les contacts</code>.

Dans la fenêtre **Modifier les contacts**, indiquez l'identifiant client souhaité pour chaque contact que vous souhaitez modifier (**Contact administrateur**, **Contact technique**, **Contact facturation**). Notez que les comptes OVHcloud pour les `Contact administrateur` et `Contact facturation` doivent être obligatoirement renseignés dans la même filiale OVHcloud.

Après avoir cliqué sur le bouton <code className="action">Confirmer</code>, les deux comptes OVHcloud concernés par le changement recevront un e-mail de confirmation. Cet e-mail contient un code (token) permettant de valider le changement de contact dans l'onglet <code className="action">Mes demandes</code> de la page **Gestion des contacts** : cliquez sur <code className="action">...</code> dans la ligne de la demande, puis sur <code className="action">Accepter la demande</code>, et saisissez le code dans le champ **Code de validation**.
{/* CP-STEPS-END:instructions */}

Pour une explication plus détaillée de cette procédure, nous vous invitons à consulter notre guide "[Gérer les contacts de ses services](/guides/account-and-service-management/account-information/managing-contacts)".
