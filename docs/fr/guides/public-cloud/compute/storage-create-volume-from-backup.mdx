## Objectif

Vous pouvez créer des disques supplémentaires pour vos instances Public Cloud à partir de Volume Snapshots créés au préalable.

Cela peut être utile dans les cas suivants :

- Si vous souhaitez restaurer les données du disque supplémentaire.
- Si vous souhaitez disposer d’un espace de stockage hautement disponible et performant avec vos données.
- Si vous souhaitez déplacer vos données vers une autre instance.

**Découvrez comment créer et configurer un disque supplémentaire sur une de vos instances à partir d'un Volume Snapshot.**

## Prérequis

- Avoir une [instance Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud.
- Avoir un Volume Snapshot dans la même région OpenStack.
- Avoir accès à votre instance via SSH en tant qu'administrateur (sudo).

## En pratique

### Créer le disque à partir d'un Volume Snapshot

Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">Volume Snapshot</code> sous **Stockage**.

Cliquez sur le bouton <code className="action">...</code> de la ligne du snapshot à partir duquel vous souhaitez créer un volume, puis sur <code className="action">Créer un volume</code>.

Dans la fenêtre **Créer un volume à partir du snapshot**, saisissez le **Nom du volume** et la **Capacité du volume** du nouveau disque, vérifiez le montant estimé, puis cliquez sur <code className="action">Créer un volume</code>.

Pour créer plutôt un volume à partir d'un Volume Backup, cliquez sur <code className="action">Volume Backup</code> sous **Stockage**, puis suivez les mêmes étapes depuis le bouton <code className="action">...</code> du Volume Backup.

La création du disque peut prendre quelques minutes, suivant la taille de celui-ci.

### Attacher le disque à une instance

Une fois le disque créé, vous pouvez décider de l'attacher à une instance. Pour cela, cliquez sur <code className="action">Block Storage</code> sous **Stockage** dans le menu de gauche.

Cliquez sur le bouton <code className="action">...</code> de la ligne du volume de votre choix, puis sur <code className="action">Attacher à une instance</code>.

Dans le panneau **Attacher le Volume à une instance**, sélectionnez l'**Instance** et cliquez sur <code className="action">Confirmer</code> pour attacher le disque.

Le processus d’attachement du disque à votre instance va alors commencer et peut prendre quelques minutes.

Une fois l'attachement effectué, vous pouvez suivre les étapes suivantes pour configurer votre disque supplémentaire [sous Linux](/guides/public-cloud/compute/create-and-configure-an-additional-disk-on-an-instance#sous-linux) ou [sous Windows](/guides/public-cloud/compute/create-and-configure-an-additional-disk-on-an-instance#sous-windows).
