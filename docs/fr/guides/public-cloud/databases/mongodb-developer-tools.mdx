## Objectif

Cette page présente les outils MongoDB pour vous aider à développer votre application avec MongoDB, exploiter votre base de données, migrer vos données, évaluer les performances de votre service, et bien plus encore.

## Outils MongoDB

### Outils de développement MongoDB

Les [outils de développement MongoDB](https://www.mongodb.com/products/tools) offrent le moyen le plus simple de vous connecter et de travailler avec vos données MongoDB depuis l'interface avec laquelle vous êtes le plus à l'aise et familier.

- [Extension Visual Studio Code](https://www.mongodb.com/products/tools/vs-code) : intègre MongoDB à Visual Studio Code, permettant aux développeurs de parcourir, modifier et interagir avec les bases de données MongoDB directement depuis l'environnement VS Code.
- [MongoDB Compass](https://www.mongodb.com/products/tools/compass) : une interface graphique (GUI) pour MongoDB, offrant une exploration visuelle de vos données, des analyses de performance et des outils de création de requêtes.
- [MongoDB Shell](https://www.mongodb.com/docs/mongodb-shell/) : une interface JavaScript interactive pour MongoDB, permettant un accès en ligne de commande aux opérations, requêtes et fonctions d'administration de l'instance MongoDB.

### Outils en ligne de commande MongoDB

Les [MongoDB Database Tools](https://www.mongodb.com/docs/database-tools/#the-mongodb-database-tools-documentation) sont un ensemble d'utilitaires en ligne de commande destinés à travailler avec un déploiement MongoDB. Les Database Tools incluent les binaires suivants :

- **mongodump** : crée des sauvegardes binaires de vos données MongoDB, utiles pour créer des instantanés complets de données.
- **mongorestore** : restaure les données à partir des sauvegardes binaires créées par `mongodump`, permettant la récupération et la migration de données.
- **mongoimport** : importe des données depuis des fichiers JSON, CSV ou TSV vers une collection MongoDB, facilitant l'ingestion de données depuis différents formats.
- **mongoexport** : exporte les données d'une collection MongoDB vers des fichiers JSON ou CSV, utile pour le partage et l'analyse des données.
- **mongostat** : fournit une vue d'ensemble en temps réel des métriques de performance du serveur MongoDB, facilitant la supervision et le dépannage.
- **mongotop** : affiche l'activité de lecture et d'écriture sur une instance MongoDB, triée par collection, aidant à identifier les goulots d'étranglement de performance.

### Outils de migration MongoDB

Les [outils de migration MongoDB](https://www.mongodb.com/docs/tools-and-connectors/#migrators--tools--and-connectors) facilitent le transfert de données en toute transparence, en prenant en charge les migrations d'un environnement MongoDB vers un autre, ainsi que des bases de données relationnelles (SGBDR) vers MongoDB, garantissant l'intégrité des données et une interruption de service minimale pendant la transition.

#### Relational Migrator

[MongoDB Relational Migrator](https://www.mongodb.com/docs/relational-migrator/) est un outil conçu pour faciliter la migration des données de bases de données relationnelles vers MongoDB. Il automatise le processus de conversion des schémas, d'importation des données et de transformation des requêtes SQL en langage de requête MongoDB. Cet outil facilite la transition en douceur des bases de données relationnelles traditionnelles vers le modèle flexible orienté document de MongoDB, en réduisant l'effort et la complexité liés à la migration de la base de données.

#### MongoDB Connector for Apache Kafka

Le [MongoDB Connector for Apache Kafka](https://www.mongodb.com/docs/kafka-connector/current/) est un outil puissant qui intègre MongoDB à Kafka pour le streaming de données en temps réel. Il inclut :

- **MongoSink** : un connecteur Kafka sink qui vous permet de diffuser des données depuis des topics Kafka vers MongoDB, permettant l'ingestion et le stockage de données en temps réel.
- **MongoSource** : un connecteur Kafka source qui diffuse des données depuis MongoDB vers des topics Kafka, facilitant les pipelines de données en temps réel et permettant aux applications de réagir immédiatement aux changements de la base de données.

Ces connecteurs offrent un moyen simple de connecter MongoDB à Kafka, en prenant en charge un flux de données évolutif et efficace entre les systèmes.

#### Mongosync

[MongoSync](https://www.mongodb.com/docs/cluster-to-cluster-sync/current/reference/mongosync/) est un outil conçu pour faciliter la synchronisation en temps réel des données entre des clusters MongoDB. Il prend en charge la synchronisation unidirectionnelle, garantissant la cohérence et l'intégrité des données entre différents environnements MongoDB. MongoSync est particulièrement utile pour des scénarios tels que la réplication inter-datacenters, la migration de données et la reprise après sinistre, permettant un flux de données fluide et efficace entre les instances MongoDB.

### Outils tiers MongoDB

#### Studio 3T

[Studio 3T](https://studio3t.com/) est une interface graphique et un IDE professionnels pour MongoDB qui améliorent la productivité grâce à des fonctionnalités telles qu'un générateur de requêtes visuel, la prise en charge des requêtes SQL, des capacités d'import/export et l'édition en place. Il est conçu pour simplifier les tâches MongoDB et la gestion des données pour les développeurs et les administrateurs de base de données.

Bien que Compass et Studio 3T proposent tous deux des interfaces graphiques pour MongoDB, Studio 3T offre des fonctionnalités avancées telles que la prise en charge des requêtes SQL et un environnement de développement intégré (IDE), tandis que MongoDB Compass se concentre davantage sur l'exploration visuelle des données et la création de requêtes de base.

#### Hatchet

[Hatchet](https://github.com/simagix/hatchet) est un analyseur et visualiseur de logs puissant et sophistiqué, spécialement conçu pour les logs JSON de MongoDB. Il offre des fonctionnalités avancées pour le traitement, l'agrégation et le stockage des données traitées. Vous devez configurer le transfert des logs avec OVHcloud afin de les collecter et de les analyser avec Hatchet.

#### mtools

[mtools](https://github.com/rueckstiess/mtools) est un ensemble de scripts d'aide permettant d'analyser, de filtrer et de visualiser les fichiers de logs MongoDB (mongod, mongos). mtools inclut également mlaunch, un utilitaire permettant de configurer rapidement des environnements de test MongoDB complexes sur une machine locale, ainsi que mtransfer, un outil de transfert de bases de données entre instances MongoDB.

#### SimRunner

[SimRunner](https://github.com/schambon/SimRunner) est un outil qui associe :

- un générateur de données puissant pour MongoDB.
- un générateur de charge de travail déclaratif et hautement évolutif.
