## Objectif

Public Cloud Databases vous permet de protéger votre service contre une suppression accidentelle.

**Ce guide explique comment configurer la protection contre la suppression pour votre service de bases de données Public Cloud, afin que le service ne puisse pas être supprimé tant que cette protection n'est pas désactivée.**

## Prérequis

- Un [service de bases de données Public Cloud](/links/public-cloud/databases) opérationnel
- Un accès à l'<ApiLink>API OVHcloud</ApiLink>

## En pratique

### Activer la protection contre la suppression de votre service

Vous pouvez activer la protection contre la suppression de votre service à l'aide de l'endpoint API suivant :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/mysql/\{clusterId\}"} />

Remplacez `mysql` dans la route par le moteur de votre service (par exemple `postgresql` ou `mongodb`).


La propriété booléenne `deletionProtection` doit être définie sur `true` pour activer la protection.
