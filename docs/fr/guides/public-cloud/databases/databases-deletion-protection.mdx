## Objectif

Public Cloud Databases vous permet de protéger votre service contre une suppression accidentelle.

**Ce guide explique comment configurer la protection contre la suppression pour votre service de bases de données Public Cloud, afin que le service ne puisse pas être supprimé tant que cette protection n'est pas désactivée.**

## Prérequis

- Un [service de bases de données Public Cloud](/links/public-cloud/databases) opérationnel
- Un accès à la <ManagerLink to="/">console OVHcloud</ManagerLink> ou à l'<ApiLink>API OVHcloud</ApiLink>

## En pratique

### Activer la protection contre la suppression de votre service

<Tabs>
  <Tab label="Depuis la console OVHcloud">
    Dans le menu de gauche de votre projet Public Cloud, cliquez sur votre moteur sous **Bases de données**, puis sur le nom de votre service.
    
    Ouvrez l'onglet <code className="action">Configuration</code>. Dans la section **Configuration**, activez l'interrupteur **Protection contre la suppression**. La modification est appliquée immédiatement.
    
    Tant que la protection est activée, le service ne peut pas être supprimé : la section **Zone de danger** de l'onglet <code className="action">Configuration</code> indique que la protection contre la suppression est activée.
    
    Pour désactiver la protection, désactivez l'interrupteur **Protection contre la suppression**, puis confirmez avec <code className="action">Désactiver</code>. Le service peut alors être supprimé.
  </Tab>
  <Tab label="Depuis l'API OVHcloud">
    Vous pouvez activer la protection contre la suppression de votre service à l'aide de l'endpoint API suivant :
    
    <Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/mysql/\{clusterId\}"} />
    
    Remplacez `mysql` dans la route par le moteur de votre service (par exemple `postgresql` ou `mongodb`).
    
    La propriété booléenne `deletionProtection` doit être définie sur `true` pour activer la protection.
  </Tab>
</Tabs>
