## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment se connecter à une instance de base de données PostgreSQL avec l'un des outils de gestion Open Source les plus connus au monde pour PostgreSQL : pgAdmin.**

## Prérequis

- Un accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>.
- Un [projet Public Cloud](/links/public-cloud/public-cloud) actif sur votre compte OVHcloud.
- Une base de données PostgreSQL fonctionnant sur votre Public Cloud Databases OVHcloud ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à remplir cette condition)
- [Configurer votre instance PostgreSQL](/guides/public-cloud/databases/postgresql-prepare-for-incoming-connections) pour accepter les connexions entrantes
- Une version stable de pgAdmin installée et une connectivité au réseau public (Internet). Ce guide a été réalisé avec pgAdmin 4 version 9.9.

## Concept

Une instance PostgreSQL peut être gérée de plusieurs façons.
L'une des plus simples, mais aussi des plus puissantes, consiste à utiliser une Command Line Interface (CLI), comme illustré dans notre guide : [Se connecter à PostgreSQL avec la CLI](/guides/public-cloud/databases/postgresql-connect-cli), ou en utilisant des langages de programmation tels que [PHP](/guides/public-cloud/databases/postgresql-connect-php) ou [Python](/guides/public-cloud/databases/postgresql-connect-python).

Une autre méthode consiste à interagir directement à l'aide d'un outil de gestion pour PostgreSQL : pgAdmin.

Pour cela, nous allons devoir installer pgAdmin, puis configurer nos instances Public Cloud Databases pour PostgreSQL afin qu'elles acceptent les connexions entrantes, et enfin configurer pgAdmin 4.

## En pratique

### Installation

Pour interagir avec votre instance PostgreSQL avec pgAdmin 4, vous devez l'installer.

Veuillez consulter la page officielle de [pgAdmin](https://www.pgadmin.org/download/) pour obtenir les informations les plus récentes.

Nous sommes maintenant prêts à apprendre comment nous connecter à notre instance PostgreSQL.

### Se connecter avec pgAdmin 4

#### Configuration

Une fois connecté à pgAdmin, depuis la vue du tableau de bord des serveurs, sélectionnez <code className="action">Ajouter un serveur</code>.

<img className="thumbnail" alt="Vue du tableau de bord pgAdmin non connecté" src="/images/public-cloud/databases/postgresql-06-connect-pgadmin/pgadmin_dashboard_not_connected.png" loading="lazy" />

Renseignez le `name` depuis l'onglet <code className="action">General</code> de la boîte de dialogue **Register - Server**.

<img className="thumbnail" alt="Register - Server - onglet General" src="/images/public-cloud/databases/postgresql-06-connect-pgadmin/pgadmin_register_server_general.png" loading="lazy" />

Sélectionnez ensuite l'onglet <code className="action">Connection</code> et renseignez les champs suivants avec les identifiants collectés :

- Host
- Port
- Maintenance database
- Username
- Password

<img className="thumbnail" alt="Register - Server - onglet Connection" src="/images/public-cloud/databases/postgresql-06-connect-pgadmin/pgadmin_register_server_connection.png" loading="lazy" />

Enfin, sélectionnez l'onglet <code className="action">Parameters</code> et définissez le **SSL mode** sur **require**.

<img className="thumbnail" alt="Register - Server - onglet Parameters" src="/images/public-cloud/databases/postgresql-06-connect-pgadmin/pgadmin_register_server_parameters.png" loading="lazy" />

Si besoin, vous pouvez également ajuster le délai de connexion depuis ce même onglet.

Une fois enregistré, sélectionnez votre serveur dans la liste des serveurs à gauche. Dans la vue du tableau de bord, vous pouvez constater que la connexion est active :

<img className="thumbnail" alt="Vue du tableau de bord pgAdmin connecté" src="/images/public-cloud/databases/postgresql-06-connect-pgadmin/pgadmin_dashboard_connected.png" loading="lazy" />
