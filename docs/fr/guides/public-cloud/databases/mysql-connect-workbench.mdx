## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment se connecter à une instance de base de données MySQL avec MySQL Workbench.**

## Prérequis

- Un accès à votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Une base de données MySQL active sur votre service OVHcloud Public Cloud Databases ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)
- [Configurer votre instance MySQL](/guides/public-cloud/databases/mysql-prepare-for-incoming-connections) pour qu'elle accepte les connexions entrantes
- Une version stable de MySQL Workbench installée et une connectivité au réseau public (Internet). *Ce guide a été réalisé avec MySQL Workbench version 8.0.28*.

## Concept

Une instance MySQL peut être gérée de plusieurs façons.
L'une des plus simples, tout en restant puissante, consiste à utiliser une interface en ligne de commande (CLI), comme le montre notre guide : [Se connecter à MySQL avec la CLI](/guides/public-cloud/databases/mysql-connect-cli), ou en utilisant des langages de programmation, tels que [PHP](/guides/public-cloud/databases/mysql-connect-php) ou [Python](/guides/public-cloud/databases/mysql-connect-python).

Une autre méthode consiste à interagir directement à l'aide d'un outil de gestion comme MySQL Workbench.

## En pratique

### Installation

MySQL Workbench peut être téléchargé gratuitement à l'adresse suivante : [https://dev.mysql.com/downloads/workbench/](https://dev.mysql.com/downloads/workbench/).

Une fois téléchargé et installé, suivez les étapes ci-dessous pour configurer une connexion distante à votre instance MySQL.

### Se connecter avec MySQL Workbench

#### Configuration

Cliquez sur <code className="action">New Connection</code>.

![Écran d'accueil de Workbench](/images/public-cloud/databases/mysql-06-connect-workbench/mysql_06_connect_workbench-20220210111228867.png)

Dans la boîte de dialogue **Setup New Connection**, renseignez le formulaire de l'onglet <code className="action">Parameters</code> avec les informations collectées précédemment.

![Configuration de la connexion dans Workbench](/images/public-cloud/databases/mysql-06-connect-workbench/mysql_06_connect_workbench-2022021011165750.png)

Enregistrez le mot de passe de connexion dans le trousseau.

![Enregistrement du mot de passe dans Workbench](/images/public-cloud/databases/mysql-06-connect-workbench/mysql_06_connect_workbench-2022021011180843.png)

Basculez vers l'onglet <code className="action">SSL</code> et définissez `Use SSL` sur `Require`.

![Configuration SSL dans Workbench](/images/public-cloud/databases/mysql-06-connect-workbench/mysql_06_connect_workbench-20220210111545457.png)

Une fois cela fait, sélectionnez votre nouvelle connexion.

![Écran d'accueil de Workbench avec la connexion créée](/images/public-cloud/databases/mysql-06-connect-workbench/mysql_06_connect_workbench-20220210113913361.png)

Félicitations, dans l'onglet <code className="action">Schemas</code>, vous verrez vos bases de données.

![Résultat de requête dans Workbench](/images/public-cloud/databases/mysql-06-connect-workbench/mysql_06_connect_workbench-20220210114125831.png)

:::info
Une fois connecté, MySQL Workbench facilite de nombreuses actions telles que l'interrogation de vos bases de données ainsi que la gestion ou même l'importation de données. Veuillez consulter la documentation officielle pour découvrir la liste complète des fonctionnalités : [https://www.mysql.com/products/workbench/features.html](https://www.mysql.com/products/workbench/features.html).

:::
