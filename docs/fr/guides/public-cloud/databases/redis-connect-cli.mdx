## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment se connecter à une instance de service Valkey avec une Command Line Interface (CLI).**

## Prérequis

- Un accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink> ;
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud ;
- Un service Valkey exécuté sur votre OVHcloud Public Cloud Databases ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)
- [Configurer votre service Valkey](/guides/public-cloud/databases/redis-prepare-for-incoming-connections) pour accepter les connexions entrantes

## Concept

Un service Valkey peut être géré de plusieurs façons.<br/>
L'une des plus simples, mais aussi des plus puissantes, consiste à utiliser une Command Line Interface (CLI), également appelée console ou terminal.
Pour interagir correctement avec l'instance, nous devons d'abord installer ce que l'on appelle un client, afin de nous connecter au service Valkey et de le contrôler à distance.<br/>
Il s'agit d'une interaction client-serveur.

## En pratique

### Installer redis-cli sur votre client

:::info
Veuillez noter que redis-cli est nativement intégré au package redis.

:::


Vous devez d'abord installer un logiciel pour interagir avec votre instance à distance. Ce logiciel officiel peut être installé sur différents supports comme votre propre ordinateur, un VPS, une machine virtuelle... La seule règle est de pouvoir accéder au réseau public (Internet) et de disposer des privilèges suffisants pour l'installer.

Pour ce faire, et selon votre configuration, vous devrez peut-être suivre la documentation officielle de Redis® pour installer redis-cli, qui fait partie du package du serveur redis : [https://redis.io/download](https://redis.io/download).

Nous sommes maintenant prêts à découvrir comment nous connecter à notre instance.

### Connexion

Nous allons maintenant suivre la documentation officielle de Redis® pour effectuer notre première connexion.

Dans votre terminal, saisissez `redis-cli -u rediss://<username>:<password>@<hostname>:<port> ping`.

Le résultat devrait ressembler à ceci :

```bash
$ redis-cli -u rediss://redisUser:3FAKExSW6Rez9Xw0admB@redis-9f6095f3-9f6095f3.database.cloud.ovh.net:20185 ping
Warning: Using a password with '-a' or '-u' option on the command line interface may not be safe.
PONG
```
Cela signifie que l'instance est active et répond à votre commande.

Pour être en mode interactif, n'utilisez aucune commande particulière :
`redis-cli -u rediss://<username>:<password>@<hostname>:<port>.<br/>`

Si vous souhaitez éviter de saisir le nom d'utilisateur et le mot de passe dans votre session shell, saisissez :
`redis-cli -u rediss://<username>:<password>@<hostname>:<port>`
pour vous connecter à l'instance, puis utilisez la commande `AUTH <username> <password>` pour basculer vers votre utilisateur disposant des privilèges minimaux pour exécuter d'autres commandes.

N'oubliez pas de modifier le nom d'utilisateur, le mot de passe, le nom d'hôte et le port.

Dans notre exemple, cela ressemblera à ceci :
```bash
$ redis-cli -u rediss://redisUser:3FAKExSW6Rez9Xw0admB@redis-9f6095f3-9f6095f3.database.cloud.ovh.net:20185    
Warning: Using a password with '-a' or '-u' option on the command line interface may not be safe.
redis-9f6095f3-9f6095f3.database.cloud.ovh.net:20185> PING
PONG
```

Félicitations ! Vous êtes maintenant pleinement en mesure d'interagir avec votre instance !

### Utilisation de redis-cli
Vous pouvez gérer votre instance à l'aide de la Command Line Interface en mode interactif ou en définissant des paramètres en tant qu'arguments de redis-cli.

Veuillez consulter la documentation officielle de Redis® sur [redis-cli](https://redis.io/commands).

### En cas de problèmes de connexion ou d'exécution de commandes
Si vous n'utilisez pas d'utilisateur défini dans votre ligne de commande ou si vous ne disposez pas de privilèges suffisants, vous obtiendrez une réponse NOAUTH ou AUTH failed.

```bash
redis-cli -u rediss://redis-9f6095f3-9f6095f3.database.cloud.ovh.net:20185 ping
(error) NOAUTH Authentication required.
```
Si l'utilisateur ne dispose pas du privilège adéquat, vous obtiendrez une réponse NOPERM. Dans ce cas, veuillez vérifier les rôles de votre utilisateur et l'ACL associée. Pour en savoir plus, veuillez consulter la [documentation officielle sur les ACL Redis®](https://redis.io/topics/acl).
