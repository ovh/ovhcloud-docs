## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment se connecter à une instance de service Valkey avec l'un des langages de programmation les plus célèbres au monde : Python.**

Vous pouvez trouver un exemple sur le [dépôt d'exemples GitHub](https://github.com/ovh/public-cloud-databases-examples/tree/main/databases/redis/python/hello-world).

## Prérequis

- Accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un service Valkey fonctionnant sur votre Public Cloud Databases OVHcloud ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)
- [Configurer votre service Valkey](/guides/public-cloud/databases/redis-prepare-for-incoming-connections) pour accepter les connexions entrantes
- Un environnement Python fonctionnel.

## Concept

Un service Valkey peut être géré de plusieurs façons.
L'une des plus simples, et pourtant puissante, consiste à utiliser une Command Line Interface (CLI), comme illustré dans notre guide : [Se connecter avec la CLI](/guides/public-cloud/databases/redis-connect-cli).

Une autre méthode consiste à interagir directement à l'aide de langages de programmation, tels que Python.

Nous allons devoir configurer notre environnement Python avec le client redis-py, puis coder en Python pour réaliser quelques actions d'exemple.

## En pratique

### Configurer votre environnement Python

Pour interagir avec votre instance en utilisant Python, votre environnement de développement doit être configuré avec :

- Une version compatible de Python
- Redis-py

Veuillez suivre le guide officiel [Redis-py](https://github.com/redis/redis-py#installation) pour obtenir les informations les plus récentes.

Une fois votre environnement Python configuré, lorsque vous exécutez **python --version** dans votre Command Line Interface (CLI), vous devriez voir des informations sur la version, comme illustré ci-dessous :

```python
laptop$ python3 --version
Python 3.12.0
```
Dans la même console, en tapant pip list, vérifiez que redis-py est correctement installé :

```python
laptop$ pip list
Package                Version
---------------------- -------
(...)
redis                  5.0.1
(...)

```
Nous sommes maintenant prêts à apprendre comment nous connecter à notre instance !

### Se connecter avec redis-py
Dans votre environnement Python, essayons une connexion. Pour être sûr que nous sommes bien connectés, définissons une paire de données puis vérifions que nous pouvons en récupérer la valeur.

```python
import redis
r = redis.Redis.from_url( url='rediss://redisUser:6D74VEUdiLb3XMzE@redis-0d42e4a5-o2626ab53.database.cloud.ovh.net:20185')
r.set("foo","bar")
print(r.get("foo"))
```

```bash
$ python redis-connect.py
$ b'bar'
```
Félicitations ! Tout fonctionne correctement.
