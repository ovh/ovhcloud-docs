## Objectif

Les bases de données Public Cloud vous permettent d'exporter des métriques de service à l'aide de Prometheus.

**Ce guide explique comment configurer un exportateur Prometheus pour votre service de bases de données Public Cloud afin qu'un serveur Prometheus puisse collecter les métriques.**

## Prérequis

- Un [service de bases de données Public Cloud](/links/public-cloud/databases) opérationnel,
- Un accès à l'<ApiLink>API OVHcloud</ApiLink>,
- Un serveur [Prometheus](https://prometheus.io) pour collecter les métriques.

## En pratique

### Activer l'exportateur Prometheus pour votre service

Vous pouvez activer un exportateur Prometheus pour votre service à l'aide de l'endpoint API :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/mysql/\{clusterId\}"} />

Remplacez `mysql` dans la route par le moteur de votre service (par exemple `postgresql` ou `mongodb`).


La propriété booléenne `enablePrometheus` doit être définie sur `true` pour activer l'exportateur Prometheus pour votre service.

### Récupérer les informations d'accès à l'exportateur Prometheus

Utilisez l'endpoint API suivant pour obtenir les données nécessaires à l'accès à l'exportateur Prometheus :

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/mysql/\{clusterId\}/prometheus"} />


Vous devrez également réinitialiser les identifiants afin d'obtenir le mot de passe nécessaire pour y accéder :

<Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\{serviceName\}/database/mysql/\{clusterId\}/prometheus/credentials/reset"} />


### Configurer votre serveur Prometheus et démarrer la collecte des métriques

Utilisez les données de l'étape précédente pour configurer votre serveur Prometheus et démarrer la collecte des métriques de votre service. Voici un exemple de configuration Prometheus pour un service MongoDB :

```yaml
scrape_configs:
- job_name: mongo-metrics
  scrape_interval: 10s
  metrics_path: /metrics
  scheme : https
  basic_auth:
    username: prometheus
    password: "xxx"
  dns_sd_configs:
    - names:
      - '_prometheus._tcp.mongodb-7bfb5d40-oa85dff3e.database.cloud.ovh.net' 
```

Les autres moteurs utilisent un format légèrement différent :

```yaml
scrape_configs:
- job_name: postgresql-metrics
  scrape_interval: 10s
  metrics_path: /metrics
  scheme : https
  basic_auth:
    username: prometheus
    password: "xxx"
  tls_config:
      insecure_skip_verify: true
  static_configs:
    - targets: 
        - postgresql-02d6a757-ovh-dev.database.cloud.ovh.net:9273
        - replica-postgresql-02d6a757-ovh-dev.database.cloud.ovh.net:9273
```

## Limitations

Les bases de données Public Cloud proposent des métriques de service via Prometheus pour les moteurs suivants :

- Valkey
- MongoDB
- MySQL
- PostgreSQL

Les endpoints Prometheus sont soumis aux mêmes limitations réseau que le service associé. Ainsi, les restrictions IP s'appliquent, et pour les services utilisant un réseau privé, l'endpoint de l'exportateur Prometheus n'est accessible que depuis le réseau privé auquel votre service est rattaché.
