## Concept

Une instance MySQL peut être gérée de plusieurs façons.
L'une des plus simples, mais aussi des plus puissantes, consiste à utiliser une Command Line Interface (CLI), comme le montre notre guide : [Se connecter à MySQL avec la CLI](/guides/public-cloud/databases/mysql-connect-cli).

Une autre méthode consiste à interagir directement à l'aide de langages de programmation, comme PHP.
PHP est utilisé sur près de 80 % des sites web dans le monde, tels que Facebook, Wikipedia ou WordPress.
MySQL fournit des drivers PHP, qui permettent de se connecter et de gérer une instance MySQL depuis le code.

Pour ce faire, nous devrons configurer notre environnement PHP avec les drivers MySQL, puis coder en PHP pour réaliser quelques exemples d'actions.

## En pratique

### Configurer votre environnement PHP

Pour interagir avec votre instance MySQL en PHP, votre environnement de développement doit être configuré avec :

- Une version compatible de PHP ;
- Les extensions PHP MySQLi, PDO et OpenSSL installées et activées dans `php.ini` ;

Veuillez consulter la documentation officielle [MySQL Drivers and Plugin](https://www.php.net/manual/en/set.mysqlinfo.php) pour obtenir les dernières informations.

Si vous pouvez modifier vous-même votre environnement PHP, installez les extensions et bibliothèques comme détaillé dans la page de documentation liée ci-dessus.

À l'inverse, si vous bénéficiez d'une solution d'hébergement web managée, comme les **offres OVHcloud Web Hosting**, vous devez activer la bonne version de PHP sur votre plan d'hébergement web. Vous trouverez [ici un guide sur la modification de votre version de PHP pour OVHcloud Web Hosting](/guides/web-cloud/web-hosting/configure-your-web-hosting).

Nous sommes maintenant prêts à découvrir comment nous connecter à notre instance MySQL.

### Se connecter avec PHP

#### Utiliser mysqli

```php
<?php
$host = "mysql-11xxxx20-o2xxxx53.database.cloud.ovh.net";
$user = "avnadmin";
$password = "K93xxxxxxxxxxxxxaBp";
$dbname = "defaultdb";
$port = "20184";

try {
  $db = mysqli_init();
  $link = mysqli_real_connect($db, $host, $user, $password, $dbname, $port, NULL, MYSQLI_CLIENT_SSL);
  $res = $db->query("SHOW GLOBAL STATUS LIKE 'Ssl_cipher';");
  $rows = $res->fetch_all();
  var_dump($rows[0]);
  $db->close();
}
catch (Throwable $e) {
  echo "Captured Throwable for connection : " . $e->getMessage() . PHP_EOL;
}
?>
```

Si vous êtes connecté, le résultat devrait ressembler à ceci :

```php
array(2) {
  [0]=>
  string(10) "Ssl_cipher"
  [1]=>
  string(22) "TLS_AES_256_GCM_SHA384"
}
```

#### Utiliser PDO

Cliquez sur <code className="action">Databases</code> dans le menu de navigation de gauche, puis sélectionnez votre instance MySQL.  
Sélectionnez l'onglet <code className="action">Informations générales</code>. Dans la section **Login Informations**, téléchargez le certificat CA.

```php
<?php
$host = "mysql-11xxxx20-o2xxxx53.database.cloud.ovh.net";
$user = "avnadmin";
$password = "K93xxxxxxxxxxxxxaBp";
$dbname = "defaultdb";
$port = "20184";
$options = array(
  PDO::MYSQL_ATTR_SSL_CA => '/<path to>/ca.pem',
  PDO::MYSQL_ATTR_SSL_VERIFY_SERVER_CERT => false
);

try {
  $conn = new PDO("mysql:host=$host; port=$port; dbname=$dbname", $user, $password, $options);
  var_dump($conn->query("SHOW STATUS LIKE 'Ssl_cipher';")->fetchAll());
  $conn = null;
}
catch (Throwable $e) {
  echo "Captured Throwable for connection : " . $e->getMessage() . PHP_EOL;
}
?>
```

Si vous êtes connecté, le résultat devrait ressembler à ceci :

```php
array(1) {
  [0]=>
  array(4) {
    ["Variable_name"]=>
    string(10) "Ssl_cipher"
    [0]=>
    string(10) "Ssl_cipher"
    ["Value"]=>
    string(22) "TLS_AES_256_GCM_SHA384"
    [1]=>
    string(22) "TLS_AES_256_GCM_SHA384"
  }
}
```
