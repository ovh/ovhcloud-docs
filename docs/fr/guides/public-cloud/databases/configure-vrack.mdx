## Objectif

Le vRack OVHcloud est une solution de réseau privé qui permet à nos clients d'acheminer le trafic entre les serveurs dédiés OVHcloud ainsi que d'autres services OVHcloud, tels que les bases de données. Le vRack permet également d'ajouter des instances Public Cloud à votre réseau privé pour créer une infrastructure de ressources physiques et virtuelles.

**Ce guide explique comment connecter une instance Public Cloud, hébergée dans un datacenter, à une base de données Public Cloud, hébergée dans un autre datacenter, comme ceci :**

## Points à prendre en compte
Voici quelques éléments à prendre en compte lors de l'utilisation d'un réseau privé :

- Les ports réseau sont créés dans le réseau privé de votre choix. Par conséquent, certaines opérations ultérieures sur ce réseau peuvent être restreintes - par exemple, vous ne pourrez pas supprimer le réseau si vous n'avez pas au préalable arrêté les services Public Cloud Databases.
- Lors d'une connexion depuis un sous-réseau externe, la passerelle IP OpenStack doit être activée dans le sous-réseau utilisé pour le service de base de données. Le client est responsable de toute autre configuration réseau personnalisée.
- Le dimensionnement du sous-réseau doit prendre en compte les nœuds du service, les autres services colocalisés au sein du même sous-réseau, ainsi qu'une réserve d'adresses IP disponibles supplémentaires à des fins de maintenance. Un dimensionnement insuffisant des sous-réseaux peut entraîner des difficultés opérationnelles et des dysfonctionnements des services.
- L'annonce des routes des sous-réseaux OpenStack ne sera pas appliquée à vos services. 

## En pratique

### Étape 1 - Créer un réseau virtuel

La première étape consiste à créer le réseau virtuel qui sera utilisé dans votre vRack. Pour ce faire, consultez ce [guide](/guides/public-cloud/network-services/vrack).

### Étape 2 - Créer une base de données Public Cloud connectée au réseau privé

Suivez ce [guide](/guides/public-cloud/databases/getting-started) pour créer une nouvelle base de données Public Cloud.

:::info
Choisissez le plan qui correspond le mieux à vos besoins. L'utilisation d'un réseau privé avec les bases de données est disponible avec tous les plans.

<img className="thumbnail" alt="Choisir le plan" src="/images/public-cloud/databases/databases-08-vrack/databases_01_order_control_panel-2022072719143198.png" loading="lazy" />

:::


:::info
- Sélectionnez **Private** dans la liste des types de réseau, puis sélectionnez **XXXX - my-private-nw**.
*La valeur XXX correspond à l'identifiant du vRack.*

- Dans la liste des sous-réseaux, sélectionnez **10.0.0.0/16 - YYY**.
*La valeur YYY correspond au nom du datacenter que vous avez choisi.*

<img className="thumbnail" alt="Configurer les options" src="/images/public-cloud/databases/databases-08-vrack/redis_08_vrack_12.png" loading="lazy" />

:::


### Étape 3 - Configurer votre instance de base de données Public Cloud pour accepter les connexions entrantes

Suivez le guide *Configurer votre instance `<database>` pour accepter les connexions entrantes* correspondant au type de base de données choisi, disponible [ici](/guides/public-cloud/databases/overview), pour configurer votre service après installation.

:::info
Autorisez l'ensemble du réseau privé, tel que défini aux étapes précédentes.

### Étape 5 - Exemple de vérification avec une base de données Public Cloud pour Valkey

Nous partons du principe que vous disposez déjà d'une clé SSH configurée sur votre projet. Pour plus de détails, consultez la page [Comment créer une instance Public Cloud et s'y connecter](/guides/public-cloud/compute/getting-started).

Connectez-vous à l'instance via SSH :

```bash
ssh debian@141.95.107.2
```

Installez maintenant le client en installant le paquet `redis-server` :

```bash
sudo apt-get update && sudo apt-get install redis-server -y
```

Connectez-vous maintenant au service Valkey à l'aide de l'URL récupérée depuis l'espace client OVHcloud, avec une commande telle que :

```bash
redis-cli --tls -u "rediss://my-redis-user@redis-2612345abc-abcd1234defg.database.cloud.ovh.net:20185"
```

Authentifiez-vous avec la commande AUTH :

```bash
AUTH my-redis-user myRedisUserPassword
```

Testez le bon fonctionnement global avec ces exemples de commandes :

```bash
redis-2612345abc-abcd1234defg.database.cloud.ovh.net:20185> ping
PONG
redis-2612345abc-abcd1234defg.database.cloud.ovh.net:20185> SET mykey.test test
OK
redis-2612345abc-abcd1234defg.database.cloud.ovh.net:20185> GET mykey.test
"test"
```
