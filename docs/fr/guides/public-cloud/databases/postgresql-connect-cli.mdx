## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment se connecter à une instance de base de données PostgreSQL à l'aide d'une Command Line Interface (CLI).**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) actif sur votre compte OVHcloud
- Un accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Une base de données PostgreSQL fonctionnant sur votre Public Cloud Databases OVHcloud ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à remplir cette condition)
- [Configurer votre instance PostgreSQL](/guides/public-cloud/databases/postgresql-prepare-for-incoming-connections) pour accepter les connexions entrantes

## Concept

Une instance PostgreSQL peut être gérée de plusieurs façons.
L'une des méthodes les plus simples, mais aussi des plus puissantes, consiste à utiliser une Command Line Interface (CLI), également appelée console ou terminal.

Pour interagir correctement avec l'instance PostgreSQL, nous devons d'abord installer ce que l'on appelle un client PostgreSQL, afin de nous connecter et de contrôler le service PostgreSQL à distance.
Il s'agit d'une interaction client-serveur.

## En pratique

### Installer le client PostgreSQL

:::info
Veuillez noter que PostgreSQL-Client est nativement intégré au package logiciel PostgreSQL.

:::


Vous devez d'abord installer un logiciel permettant d'interagir avec votre instance PostgreSQL à distance. Ce logiciel officiel peut être installé sur diverses machines clientes, telles que votre propre ordinateur, un VPS ou une machine virtuelle. La seule règle est de pouvoir accéder au réseau public (Internet) et de disposer des droits suffisants pour l'installer.

Pour ce faire, et selon votre configuration, vous devrez peut-être suivre la documentation officielle de PostgreSQL pour installer le client PostgreSQL (appelé psql).

Suivez les étapes ici après avoir sélectionné Windows, MacOS ou Linux comme système d'exploitation : [https://www.postgresql.org/download/](https://www.postgresql.org/download/)

Comme expliqué, le **postgresql-client** est souvent inclus par défaut.

Exemple avec Linux/Debian :

<img className="thumbnail" alt="Debian postgresql-client" src="/images/public-cloud/databases/postgresql-03-connect-cli/debian_postgresql.png" loading="lazy" />

Nous allons maintenant suivre la documentation officielle de PostgreSQL pour effectuer notre première connexion.

Dans votre CLI, tapez **psql --version**. Le résultat devrait ressembler à ceci :

```console
$ psql --version
psql (PostgreSQL) 13.4 (Ubuntu 13.4-1))
```

Cela signifie que psql est correctement installé et fonctionne correctement. Si vous n'obtenez pas un résultat similaire, veuillez revenir à l'étape précédente et réinstaller le client PostgreSQL.

### Se connecter à votre instance PostgreSQL

Nous allons suivre la documentation officielle de PostgreSQL : [https://www.postgresql.org/docs/devel/app-psql.html](https://www.postgresql.org/docs/devel/app-psql.html).

Pour effectuer une connexion, tapez simplement **psql** suivi de l'URI de service copié précédemment :

```console
$ psql "postgres://`<username>`:<password>@<hostname>:<port>/defaultdb?sslmode=require"
```

N'oubliez pas de modifier le nom d'utilisateur, le mot de passe, le nom d'hôte et le port.
Dans notre exemple, cela ressemblera à ceci :

```console
$ psql "postgres://avnadmin:Mysup3rs3cur3p4ssw0rd@postgresql-ab123456-cd7891011.database.cloud.ovh.net:20184/defaultdb?sslmode=require"
```

Une fois connecté correctement, vous devriez voir quelque chose de similaire à :

```console
psql (13.4 (Ubuntu 13.4-1))
SSL connection (protocol: TLSv1.3, cipher: TLS_AES_256_GCM_SHA384, bits: 256, compression: off)
Type "help" for help.

defaultdb=>
```

:::tip
Félicitations ! Vous êtes désormais pleinement en mesure d'interagir avec votre instance PostgreSQL !

:::


### Utilisation du client PostgreSQL

Une fois connecté, vous pouvez gérer votre instance PostgreSQL à l'aide des méthodes intégrées du client PostgreSQL.

Veuillez suivre la documentation officielle de PostgreSQL.

Pour vérifier :

- `\h CREATE DATABASE` affichera l'aide sur une commande spécifique (ici pour *CREATE DATABASE*) ;
- `\l+` listera toutes les bases de données ;
- `select * from pg_user;` affichera des informations sur les utilisateurs existants.

Dans notre exemple, cela ressemblera à ceci :

```sql
defaultdb=> \h CREATE DATABASE
Command:     CREATE DATABASE
Description: create a new database
Syntax:
CREATE DATABASE name
    [ [ WITH ] [ OWNER [=] user_name ]
           [ TEMPLATE [=] template ]
           [ ENCODING [=] encoding ]
           [ LOCALE [=] locale ]
           [ LC_COLLATE [=] lc_collate ]
           [ LC_CTYPE [=] lc_ctype ]
           [ TABLESPACE [=] tablespace_name ]
           [ ALLOW_CONNECTIONS [=] allowconn ]
           [ CONNECTION LIMIT [=] connlimit ]
           [ IS_TEMPLATE [=] istemplate ] ]

URL: https://www.postgresql.org/docs/13/sql-createdatabase.html
```

```sql
defaultdb=> \l+
```
