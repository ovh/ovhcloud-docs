## Objectif

Apprenez à ajuster l'espace de stockage de votre cluster selon vos besoins.

:::info
Cette fonctionnalité n'est disponible que pour les moteurs utilisant un espace de stockage.

:::


## Comment augmenter ou diminuer le stockage

Vous pouvez augmenter ou diminuer le stockage de votre service à tout moment, via l'<ApiLink>API</ApiLink> OVHcloud ou l'<ManagerLink to="/">espace client</ManagerLink>.

:::info
Lors de la modification de l'espace de stockage de votre service, le système vérifie qu'au moins 20 % de votre espace de stockage total reste libre après l'opération de redimensionnement. Par conséquent, il se peut que vous ne puissiez pas effectuer de diminution de l'espace de stockage si la nouvelle taille demandée est trop proche de votre utilisation actuelle de l'espace disque.

:::


### Comment ajuster l'espace de stockage depuis l'espace client

#### Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

---

### Accès à l'espace client OVHcloud

- **Lien direct :** <ManagerLink to="/#/pci/projects">Projets Public Cloud</ManagerLink>
- **Chemin de navigation :** <code className="action">Public Cloud</code> > Sélectionnez votre projet

---
{/* CP-NAV-END:publiccloud-projects */}

#### En pratique

Cliquez sur <code className="action">Databases</code> dans la barre de navigation de gauche, sélectionnez votre instance de moteur, puis cliquez sur l'onglet <code className="action">Configuration</code>.

![Vue d'ensemble du cluster](/images/public-cloud/databases/databases-11-resize-your-cluster-storage/cluster-overview.png)

Cliquez sur <code className="action">Modifier</code> sur la ligne « Storage » et ajustez l'espace de stockage de votre cluster. Utilisez le curseur pour augmenter ou diminuer l'espace de stockage.

![Modifier le stockage additionnel](/images/public-cloud/databases/databases-11-resize-your-cluster-storage/edit-additional-storage.png)

### Comment ajuster l'espace de stockage via l'API

#### Prérequis

- Un accès à l'<ApiLink>API</ApiLink> OVHcloud (créez vos identifiants en consultant [ce guide](/guides/manage-and-operate/api/first-steps))
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

#### En pratique

Par exemple, pour les services MongoDB, vous pouvez augmenter ou diminuer l'espace de stockage à l'aide de cet endpoint :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/mongodb/\{clusterId\}"} />

Les autres moteurs utilisant un espace de stockage proposent des endpoints similaires, par exemple :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/postgresql/\{clusterId\}"} />
