Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

Le tableau RACI ci-dessous détaille le partage des responsabilités entre OVHcloud et le client pour les services Public Cloud Databases.
Ce modèle partagé permet d'alléger la charge opérationnelle du client.

## Définition RACI

| Rôles |
| --- |
| R : est chargé de la réalisation du processus |
| A : garantit la bonne exécution du processus |
| C : est consulté pendant le processus |
| I : est informé des résultats du processus |

Pour information, un **Service** désigne un service Public Cloud Databases tel qu'un cluster MySQL, PostgreSQL, MongoDB, Valkey ou Cassandra.

### 1. Avant la souscription

#### 1.1. Définir le service selon les besoins

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
| Prendre connaissance des capacités et limites des services détaillées dans la documentation OVHcloud | RA | I |
| Choisir la localisation du service | RA | I |
| Dimensionner les services selon les besoins | RA | I |
| Choisir les options selon les besoins | RA | I |

| Acheter et détenir les licences et droits d'utilisation des solutions de sauvegarde fournies par OVHcloud |  | RA |

| **Activité** | **Client** | **OVHcloud** |
