## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment configurer votre instance PostgreSQL pour accepter les connexions entrantes.**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Une base de données PostgreSQL fonctionnant sur votre service Public Cloud Databases OVHcloud ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)

## En pratique

### Configurer votre instance PostgreSQL pour accepter les connexions entrantes

Avant d'établir une connexion, nous devons vérifier que notre instance PostgreSQL est correctement configurée.

Cliquez sur <code className="action">Databases</code> dans le menu de navigation de gauche et sélectionnez votre instance PostgreSQL.

#### Étape 1 : vérifier vos rôles utilisateur et votre mot de passe

Sélectionnez l'onglet <code className="action">Utilisateurs</code>. Vérifiez que vous disposez d'un utilisateur avec des droits suffisants et un mot de passe configuré. Si vous ne vous souvenez plus du mot de passe de l'utilisateur, vous pouvez soit créer un nouvel utilisateur, soit régénérer le mot de passe d'un utilisateur existant. Attention ! En procédant ainsi, vous devrez mettre à jour tous les endroits où vous utilisez déjà cette paire utilisateur/mot de passe.

Ce premier utilisateur **avnadmin** dispose des privilèges suivants :

```console
  LOGIN
  NOSUPERUSER
  INHERIT
  CREATEDB
  CREATEROLE
  REPLICATION
```

Nous nous appuyons sur les rôles et privilèges officiels de PostgreSQL. Vous pouvez les gérer vous-même via la CLI ou du code.
Pour l'instant, **la gestion des droits et privilèges des utilisateurs n'est pas prise en charge via l'espace client OVHcloud ou l'API OVHcloud**.

Veuillez consulter la [documentation officielle de PostgreSQL](https://www.postgresql.org/docs/current/database-roles.html) pour sélectionner les rôles adaptés à votre cas d'usage.

Pour simplement réinitialiser le mot de passe de **avnadmin**, cliquez sur <code className="action">...</code> à droite de l'utilisateur, puis sur <code className="action">Régénérer le mot de passe</code>.

<img className="thumbnail" alt="Utilisateur activé" src="/images/public-cloud/databases/postgresql-07-prepare-for-incoming-connections/postgresql_07_prepare_for_incoming_connections-20220408122659546.png" loading="lazy" />

Pour créer un nouvel utilisateur, cliquez sur <code className="action">Ajouter un utilisateur</code>, remplissez le formulaire, puis cliquez sur <code className="action">Créer un utilisateur</code>

<img className="thumbnail" alt="Créer un utilisateur" src="/images/public-cloud/databases/postgresql-07-prepare-for-incoming-connections/postgresql_07_prepare_for_incoming_connections-20220408132905528.png" loading="lazy" />

Une fois créé ou mis à jour, l'utilisateur doit être prêt et avoir le statut « Enabled » dans l'espace client.

#### Étape 2 : autoriser les connexions entrantes depuis le client PostgreSQL

À cette étape, sélectionnez l'onglet <code className="action">IPs autorisées</code> (liste de contrôle d'accès).
Par défaut, une base de données Public Cloud n'accepte aucune forme de connexion venant de l'extérieur.
Cela permet de prévenir les tentatives de connexion intrusives.

Cliquez pour autoriser une nouvelle IP, et saisissez l'IP de votre environnement pgAdmin. Dans notre cas, nous saisirons 109.190.200.59.

<img className="thumbnail" alt="Ajouter une IP" src="/images/public-cloud/databases/postgresql-07-prepare-for-incoming-connections/ip_authorize.png" loading="lazy" />

:::info
Si vous souhaitez autoriser les connexions depuis l'extérieur, vous pouvez saisir l'IP 0.0.0.0/0. Veuillez l'utiliser avec précaution.

:::


#### Collecter les informations requises

Sélectionnez l'onglet <code className="action">Informations générales</code> pour retrouver les identifiants de connexion requis dans la section `Login informations`.

<img className="thumbnail" alt="Onglet des informations de connexion" src="/images/public-cloud/databases/postgresql-07-prepare-for-incoming-connections/postgresql_07_prepare_for_incoming_connections-20220408134445538.png" loading="lazy" />

Sélectionnez l'onglet <code className="action">Databases</code> pour obtenir le nom de la base de données.

<img className="thumbnail" alt="Onglet Databases" src="/images/public-cloud/databases/postgresql-07-prepare-for-incoming-connections/postgresql_07_prepare_for_incoming_connections-20220408134547314.png" loading="lazy" />

Sélectionnez l'onglet <code className="action">Utilisateurs</code> pour obtenir le nom d'utilisateur.

<img className="thumbnail" alt="Tableau des utilisateurs" src="/images/public-cloud/databases/postgresql-07-prepare-for-incoming-connections/postgresql_07_prepare_for_incoming_connections-20220408134639441.png" loading="lazy" />
