## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment configurer votre instance MySQL pour accepter les connexions entrantes.**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Une base de données MySQL fonctionnant sur votre Public Cloud Databases OVHcloud ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)

## En pratique

### Configurer votre instance MySQL pour accepter les connexions entrantes

Avant d'établir une connexion, nous devons vérifier que notre instance MySQL est correctement configurée.

Cliquez sur <code className="action">Databases</code> dans la barre de navigation de gauche et sélectionnez votre instance MySQL.

#### Étape 1 : Vérifiez vos rôles utilisateur et votre mot de passe

Sélectionnez l'onglet <code className="action">Utilisateurs</code>. Vérifiez que vous disposez d'un utilisateur avec les droits suffisants et un mot de passe configuré. Si vous ne vous souvenez plus du mot de passe de l'utilisateur, vous pouvez soit créer un nouvel utilisateur, soit régénérer le mot de passe d'un utilisateur existant.

:::warning
Attention ! Ce faisant, vous devrez mettre à jour tous les endroits où vous utilisez déjà cette paire utilisateur/mot de passe.

:::


Ce premier utilisateur **avnadmin** est préconfiguré lors de l'installation du service et dispose des droits suivants :

```sql
GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, DROP, RELOAD, PROCESS, REFERENCES, INDEX, ALTER, SHOW DATABASES, CREATE TEMPORARY TABLES, LOCK TABLES, EXECUTE, REPLICATION SLAVE, REPLICATION CLIENT, CREATE VIEW, SHOW VIEW, CREATE ROUTINE, ALTER ROUTINE, CREATE USER, EVENT, TRIGGER ON *.* TO "avnadmin"@"%" WITH GRANT OPTION

GRANT REPLICATION_APPLIER,ROLE_ADMIN ON *.* TO "avnadmin"@"%" WITH GRANT OPTION
```

<img className="thumbnail" alt="Tableau des utilisateurs" src="/images/public-cloud/databases/mysql-07-prepare-for-incoming-connections/users_and_roles.png" loading="lazy" />

Vous pouvez ajouter d'autres utilisateurs en cliquant sur le bouton <code className="action">Ajouter un utilisateur</code>.

<img className="thumbnail" alt="Ajout d'un utilisateur" src="/images/public-cloud/databases/mysql-07-prepare-for-incoming-connections/add_user.png" loading="lazy" />

Saisissez un nom d'utilisateur puis cliquez sur <code className="action">Créer un utilisateur</code>.

:::info
Vous pouvez supprimer un utilisateur ou régénérer un mot de passe via le bouton <code className="action">...</code> dans le tableau `Users & Roles`.

:::


#### Étape 2 : Autorisez les connexions entrantes depuis le client MySQL

:::warning
Pour des raisons de sécurité, la configuration réseau par défaut n'autorise aucune connexion entrante. Il est donc essentiel d'autoriser les adresses IP appropriées afin de pouvoir accéder à votre base de données.

:::


Renseignez l'adresse IP ou le bloc CIDR à autoriser puis cliquez sur le bouton <code className="action">+</code>.


<img className="thumbnail" alt="Ajout d'une IP" src="/images/public-cloud/databases/mysql-07-prepare-for-incoming-connections/add_ip_1.png" loading="lazy" />

Validez les modifications en cliquant sur le bouton <code className="action">Sauvegarder les modifications</code>.

<img className="thumbnail" alt="Ajout d'une IP" src="/images/public-cloud/databases/mysql-07-prepare-for-incoming-connections/add_ip_2.png" loading="lazy" />


:::info
Si vous souhaitez autoriser les connexions depuis l'extérieur, vous pouvez saisir l'IP 0.0.0.0/0. Veuillez l'utiliser avec précaution.

:::


#### Collecter les informations requises

Sélectionnez l'onglet <code className="action">Dashboard</code> pour trouver les identifiants de connexion requis dans la section `Connection information`.

<img className="thumbnail" alt="Onglet des informations de connexion" src="/images/public-cloud/databases/mysql-07-prepare-for-incoming-connections/connection_information.png" loading="lazy" />

Sélectionnez l'onglet <code className="action">Databases</code> pour obtenir le nom de la base de données.

<img className="thumbnail" alt="Onglet Databases" src="/images/public-cloud/databases/mysql-07-prepare-for-incoming-connections/databases.png" loading="lazy" />

Sélectionnez l'onglet <code className="action">Utilisateurs</code> pour obtenir le nom d'utilisateur.

<img className="thumbnail" alt="Tableau des utilisateurs" src="/images/public-cloud/databases/mysql-07-prepare-for-incoming-connections/user.png" loading="lazy" />
