## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment configurer votre instance Dashboards pour accepter les connexions entrantes.**

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

## En pratique

### Configurer votre instance Dashboards pour accepter les connexions entrantes

Avant d'établir une connexion, nous devons vérifier que notre instance Dashboards est correctement configurée.
Cliquez sur <code className="action">Data Analysis</code> dans la barre de navigation de gauche et sélectionnez votre instance Dashboards.

#### Étape 1 : Vérifiez vos rôles utilisateur et votre mot de passe

Sélectionnez l'onglet <code className="action">Informations générales</code> et <code className="action">Reset the password</code> de l'utilisateur **avnadmin**, qui dispose du rôle **Admin**, dans la section `Login information`.

:::info
D'autres utilisateurs peuvent être créés dans l'interface web de votre instance Dashboards, depuis l'onglet `Users` du panneau <code className="action">Server Admin</code>.

:::


#### Étape 2 : Autorisez les connexions entrantes vers votre instance Dashboards

:::warning
Pour des raisons de sécurité, la configuration réseau par défaut n'autorise aucune connexion entrante. Il est donc essentiel d'autoriser les adresses IP appropriées afin de pouvoir accéder à votre service.

:::


Dans cette étape, sélectionnez l'onglet <code className="action">IPs autorisées</code>. Les adresses IP doivent être autorisées ici avant de pouvoir se connecter à votre service.

En cliquant sur <code className="action">Ajouter une adresse IP / masque</code>, une nouvelle fenêtre s'ouvre dans laquelle vous pouvez ajouter des adresses IP uniques ou des blocs pour autoriser l'accès au service.

<img className="thumbnail" alt="Ajout d'une IP" src="/images/public-cloud/databases/grafana-02-prepare-for-incoming-connections/ip_authorize.png" loading="lazy" />

Vous pouvez modifier et retirer l'accès à la base de données via le bouton <code className="action">...</code> dans le tableau des IPs.

:::info
Si vous souhaitez autoriser les connexions depuis l'extérieur, vous pouvez saisir l'IP 0.0.0.0/0. Veuillez l'utiliser avec précaution.

:::


### Se connecter à votre instance Dashboards

Dans votre instance Dashboards, récupérez l'URI dans la section `Login informations` de l'onglet <code className="action">Informations générales</code>.

<img className="thumbnail" alt="Onglet des informations de connexion" src="/images/public-cloud/databases/grafana-02-prepare-for-incoming-connections/grafana_02_prepare_for_incoming_connections-20220530065929522.png" loading="lazy" />

Connectez-vous ensuite à votre instance Dashboards :

![Bienvenue sur Grafana](/images/public-cloud/databases/grafana-02-prepare-for-incoming-connections/grafana_02_prepare_for_incoming_connections-20220530071539383.png)

Félicitations ! Vous êtes désormais connecté à votre instance Dashboards.

![Première connexion à Grafana](/images/public-cloud/databases/grafana-02-prepare-for-incoming-connections/grafana_02_prepare_for_incoming_connections-20220530071725524.png)

Pour en savoir plus sur Grafana®, consultez le tutoriel suivant : [Grafana fundamentals](https://grafana.com/tutorials/grafana-fundamentals/?utm_source=grafana_gettingstarted)
