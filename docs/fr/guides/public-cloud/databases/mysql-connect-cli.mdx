## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment se connecter à une instance de base de données MySQL à l'aide d'une interface en ligne de commande (CLI).**

## Prérequis

- Un accès à votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Une base de données MySQL active sur votre service OVHcloud Public Cloud Databases ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)
- [Configurer votre instance MySQL](/guides/public-cloud/databases/mysql-prepare-for-incoming-connections) pour qu'elle accepte les connexions entrantes

## Concept

Pour interagir correctement avec l'instance MySQL, nous devons d'abord installer un élément appelé client MySQL, afin de nous connecter et de contrôler le service MySQL à distance.
Il s'agit d'une interaction client-serveur.

## En pratique

### Installation du client MySQL

:::info
Veuillez noter qu'un client MySQL est nativement intégré au package logiciel MySQL, mais qu'il ne permet pas l'utilisation d'un Service URI.

:::


Vous devez d'abord installer un logiciel pour interagir avec votre instance MySQL à distance. Ce logiciel officiel peut être installé sur diverses machines clientes, telles que votre propre ordinateur, un VPS ou une machine virtuelle. La seule règle est de pouvoir accéder au réseau public (Internet) et de disposer des droits suffisants pour l'installer.

Pour ce faire, et selon votre configuration, vous devrez peut-être suivre la documentation officielle de MySQL pour installer MySQL Shell (*mysqlsh*), plus puissant que MySQL Client (*mysql*).

MySQL Shell n'est pas obligatoire, mais bien plus pratique à utiliser que les clients MySQL standards, car il permet de se connecter avec un Service URI plutôt qu'avec des paramètres individuels.

Suivez les étapes ci-après en sélectionnant Windows, MacOS ou Linux comme système d'exploitation : [https://dev.mysql.com/doc/mysql-shell/8.0/en/mysql-shell-install.html](https://dev.mysql.com/doc/mysql-shell/8.0/en/mysql-shell-install.html)

Nous sommes maintenant prêts à apprendre comment nous connecter à notre instance MySQL.

### Configuration

Nous allons maintenant suivre la documentation officielle de MySQL pour effectuer notre première connexion.

Dans votre CLI, saisissez `mysqlsh --version`. Le résultat devrait ressembler à ceci :

```console
laptop$mysqlsh --version
/snap/mysql-shell/29/bin/mysqlsh   Ver 8.0.23 for Linux on x86_64 - for MySQL 8.0.23 (Source distribution)
```

Cela signifie que mysqlsh est correctement installé et fonctionne normalement. Si vous n'obtenez pas un résultat similaire à celui-ci, revenez à l'étape précédente et réinstallez MySQL Shell.

### Se connecter à votre instance MySQL

Nous allons suivre la documentation officielle de MySQL : [https://dev.mysql.com/doc/refman/8.0/en/connecting-using-uri-or-key-value-pairs.html](https://dev.mysql.com/doc/refman/8.0/en/connecting-using-uri-or-key-value-pairs.html).

Pour effectuer une connexion, saisissez simplement `mysqlsh --sql` suivi du Service URI :

```console
laptop$mysqlsh --sql "mysql://`<username>`:<password@<hostname>t<port>/defaultdb?ssl-mode=REQUIRED"
```

N'oubliez pas de modifier le nom d'utilisateur, le mot de passe, le nom d'hôte et le port.
Dans notre exemple, cela ressemblera à ceci :

```console
laptop$mysqlsh --sql "mysql://avnadmin:Mysup3rs3cur3p4ssw0rd@mysql-ab123456-cd7891011.database.cloud.ovh.net:20184/defaultdb?ssl-mode=REQUIRED"
```

Une fois connecté correctement, vous devriez voir quelque chose de similaire à :

```console

Other names may be trademarks of their respective owners.

Type '\help' or '\?' for help; '\quit' to exit.

```

Félicitations ! Vous êtes maintenant pleinement en mesure d'interagir avec votre instance MySQL !

### Utilisation du client MySQL

Une fois connecté, vous pouvez gérer votre instance MySQL à l'aide des méthodes intégrées du client MySQL.

Veuillez suivre la documentation officielle de MySQL.

Pour vérifier :

- `SHOW DATABASES;` listera toutes les bases de données ;  
- `select * from mysql.user;` affichera les informations sur les utilisateurs existants.  

Dans notre exemple, cela ressemblera à ceci :

```sql
mysql-sql [defaultdb]> SHOW DATABASES;
+--------------------+
| Database           |
+--------------------+
| defaultdb          |
| information_schema |
| mysql              |
| performance_schema |
| sys                |
+--------------------+
5 rows in set (0.0046 sec)
```

```sql
defaultdb=> \h CREATE DATABASE
```
