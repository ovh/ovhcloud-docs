## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment se connecter à une instance de service Valkey à l'aide de l'un des langages de programmation les plus célèbres au monde : PHP.**

## Prérequis

- Un accès à votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un service Valkey actif sur votre service OVHcloud Public Cloud Databases ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)
- [Configurer votre service Valkey](/guides/public-cloud/databases/valkey-prepare-for-incoming-connections) pour qu'il accepte les connexions entrantes
- Un environnement PHP dans une version stable et disposant d'une connectivité au réseau public (Internet). Ce guide a été réalisé en PHP 8.4.

## Concept

Un service Valkey peut être géré de plusieurs façons.
L'une des plus simples, tout en restant puissante, consiste à utiliser une interface en ligne de commande (CLI), comme le montre notre guide : [Se connecter avec la CLI](/guides/public-cloud/databases/valkey-connect-cli).

Une autre méthode consiste à interagir directement à l'aide de langages de programmation, tels que PHP.
Valkey dispose de plusieurs clients PHP, permettant de se connecter à une instance et de la gérer depuis le code. Veuillez consulter la [liste officielle des clients Valkey](https://valkey.io/clients/) pour obtenir les informations les plus récentes sur les clients.

Nous allons devoir configurer notre environnement PHP avec le client phpredis, puis configurer notre service Public Cloud Databases pour Valkey afin qu'il accepte les connexions entrantes, et enfin coder en PHP pour effectuer quelques actions d'exemple.

## En pratique

### Configurer votre environnement PHP

Pour interagir avec votre instance en PHP, votre environnement de développement doit être configuré avec :

- Une version compatible de PHP ;
- Un client PHP prenant en charge Valkey et TLS, par exemple :
    - l'extension **phpredis** (version 6.3.0 au moment de la rédaction), qui prend en charge Valkey, installée avec `pecl install redis` ;
    - la bibliothèque **Predis** (version 3.6.1 au moment de la rédaction), un client Redis/Valkey écrit en PHP, installée avec `composer require predis/predis`.

Pour phpredis comme pour Predis, il est recommandé de consulter leurs sites respectifs pour connaître la procédure d'installation :

- [GitHub officiel de phpredis](https://github.com/phpredis/phpredis) ;
- [GitHub officiel de Predis](https://github.com/predis/predis).

Nous sommes maintenant prêts à apprendre comment nous connecter à notre instance. Nous utiliserons phpredis comme client PHP.

### Se connecter avec PHP

Récupérez l'hôte et le port de votre service dans l'onglet <code className="action">Dashboard</code>, section `Informations de connection`, comme expliqué dans le guide [Configurer les connexions entrantes](/guides/public-cloud/databases/valkey-prepare-for-incoming-connections).

TLS est obligatoire : les connexions sans TLS sont refusées. Avec phpredis, le préfixe `tls://` devant l'hôte active TLS. Le certificat du serveur est signé par une autorité de certification publique : PHP le vérifie par défaut (options de contexte SSL `verify_peer` et `verify_peer_name`) avec les certificats CA de votre système, vous n'avez donc besoin d'aucun fichier CA. Ne désactivez pas cette vérification.

Dans votre environnement PHP, essayons une connexion. Pour être sûr d'être bien connecté, définissez une paire de données puis vérifiez que vous pouvez en récupérer la valeur. Remplacez `<username>`, `<password>`, `<host>` et `<port>` par vos propres valeurs :

```php
<?php
    // PHP version 8.4 used here
    echo "\nConnection to server ongoing...";
    $valkey = new Redis(); // phpredis class, compatible with Valkey

    // TLS connection to the Valkey service, with certificate verification
    $valkey->connect('tls://<host>', <port>, 2.5, '', 0, 0, [
        'stream' => ['verify_peer' => true, 'verify_peer_name' => true],
    ]);

    // Authenticate with your user
    $valkey->auth(['<username>', '<password>']);

    // Ping the instance
    echo "\nServer is running: " . var_export($valkey->ping(), true);

    // Set the key pair
    echo "\nSet key pair (cache:foo,cowabunga).";
    $valkey->set('cache:foo', 'cowabunga');

    // Get the value of the key cache:foo
    $response = $valkey->get('cache:foo');
    echo "\nGet the value for key cache:foo: ";
    echo $response;

    if ($response == "cowabunga") {
        echo "\nPHP test with Valkey OK.\n";
    } else {
        echo "\nPHP Test FAILED\n";
    }
?>
```

Félicitations ! Tout fonctionne correctement.

:::tip
Évitez d'écrire votre mot de passe dans votre code source : lisez-le depuis une variable d'environnement (par exemple `getenv('VALKEY_PASSWORD')`) ou depuis un gestionnaire de secrets.

:::

Si vous obtenez une erreur `NOPERM`, les permissions de votre utilisateur n'autorisent pas la clé ou la commande utilisée. Dans notre exemple, l'utilisateur doit pouvoir lire et écrire les clés correspondant à `cache:*`. Vérifiez ses clés, catégories et commandes dans l'onglet <code className="action">Utilisateurs</code>, comme expliqué dans le guide [Configurer les connexions entrantes](/guides/public-cloud/databases/valkey-prepare-for-incoming-connections).
