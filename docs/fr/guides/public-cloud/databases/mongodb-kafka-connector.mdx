## Introduction

Le [MongoDB Kafka Connector](https://www.mongodb.com/docs/kafka-connector/current/#mongodb-kafka-connector) est un outil d'intégration qui relie MongoDB à Apache Kafka, permettant la synchronisation et le streaming de données en temps réel entre les deux plateformes. Ce connecteur facilite le transfert fluide des données, permettant à MongoDB d'être utilisé à la fois comme source et comme sink au sein d'un écosystème Kafka. En s'appuyant sur ce connecteur, les développeurs peuvent créer des pipelines de données robustes, garantissant un flux de données efficace et fiable au sein de leurs applications.

## Composants clés

1. [Source Connector](https://www.mongodb.com/docs/kafka-connector/current/source-connector/#source-connector) : capture les changements depuis MongoDB et les diffuse dans des topics Kafka. Il utilise les Change Streams de MongoDB pour surveiller les changements dans les collections et les bases de données.
2. [Sink Connector](https://www.mongodb.com/docs/kafka-connector/current/sink-connector/#std-label-kafka-sink-overview) : lit les données des topics Kafka et les écrit dans des collections MongoDB. Ce composant garantit que les données provenant de différents topics Kafka peuvent être persistées dans MongoDB pour un traitement ou une interrogation ultérieurs.

### Configurer les connecteurs Kafka Sink et Source

#### Étape 1 : créer les services `KafkaConnect` et `Kafka`

Sous `Data Streaming`, créez les services `KafkaConnect` et `Kafka`.

![Data Streaming Kafka](/images/public-cloud/databases/mongodb-23-kafka-connector/dataStreamingKafka.png)

#### Étape 2 : intégrer le service `Kafka` à `KafkaConnect`

Sélectionnez le service `Kafka Connect` et, sous `Service Integration`, cliquez sur le bouton `+ Add an Integration`, sélectionnez `KafkaConnect` comme type d'intégration, puis ajoutez le service `Kafka`.

![Intégration du service Kafka Connect](/images/public-cloud/databases/mongodb-23-kafka-connector/KafkaConnectServiceIntegration.png)

#### Étape 3 : ajouter le connecteur

Sous l'onglet `Connectors` de `KafkaConnect`, cliquez sur `+ Add a Connector`, puis sélectionnez soit `MongoDB Kafka Sink Connector`, soit `MongoDB Kafka Source Connector`.

![Connecteur Kafka Connect](/images/public-cloud/databases/mongodb-23-kafka-connector/KafkaConnectConnector.png)

#### Étape 4 : configurer le connecteur

Vous pouvez consulter [Sink Connector Configuration Properties](https://www.mongodb.com/docs/kafka-connector/current/sink-connector/configuration-properties/) et [Source Connector Configuration Properties](https://www.mongodb.com/docs/kafka-connector/current/source-connector/configuration-properties/#source-connector-configuration-properties) pour finaliser la configuration.

![Propriétés du connecteur](/images/public-cloud/databases/mongodb-23-kafka-connector/ConnectorProperties.png)

## Cas d'usage

- **Streaming de données** : streaming de données en temps réel depuis MongoDB vers Kafka pour l'analyse et la supervision.
- **Pipelines ETL** : utilisation de Kafka comme hub central pour les processus ETL, MongoDB servant de source ou de sink.
- **Intégration de microservices** : synchronisation des données au sein d'architectures de microservices, garantissant des états de données cohérents.
- **Architectures orientées événements** : création de systèmes orientés événements où MongoDB et Kafka fonctionnent ensemble pour gérer efficacement les événements et les déclencheurs.
