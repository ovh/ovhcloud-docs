## Objectif

Découvrez comment ajuster la flavor de votre cluster selon vos besoins.

## Comment faire évoluer votre flavor

Cette option est disponible via l'<ApiLink>API</ApiLink> OVHcloud et l'<ManagerLink to="/">espace client</ManagerLink>.

### Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un accès à l'<ApiLink>API OVHcloud</ApiLink> (facultatif)

{/* CP-NAV-START:publiccloud-projects */}
---

### Accès à l'espace client OVHcloud

- **Lien direct :** <ManagerLink to="/#/pci/projects">Projets Public Cloud</ManagerLink>
- **Chemin de navigation :** <code className="action">Public Cloud</code> > Sélectionnez votre projet

---
{/* CP-NAV-END:publiccloud-projects */}

### En pratique

Cliquez sur <code className="action">Databases</code> dans la barre de navigation de gauche, sélectionnez votre instance de moteur puis cliquez sur l'onglet <code className="action">Configuration</code>.

![Vue d'ensemble du cluster](/images/public-cloud/databases/databases-13-update-your-cluster-flavor/cluster_overview.png)

Cliquez sur <code className="action">Modifier</code> sur la ligne « Flavor » et ajustez la flavor de votre cluster.

![Modifier le modèle de nœud](/images/public-cloud/databases/databases-13-update-your-cluster-flavor/flavor_change_view.png)

## Comment revenir à une flavor inférieure

Cette option est actuellement disponible via l'<ApiLink>API</ApiLink> OVHcloud.

### Prérequis

- Un accès à l'<ApiLink>API OVHcloud</ApiLink> (créez vos identifiants en consultant [ce guide](/guides/manage-and-operate/api/first-steps))
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

### En pratique

Pour pouvoir revenir à une flavor inférieure, vous devez disposer d'un seuil de 20 % entre votre espace disque actuellement utilisé (stockage de base + stockage additionnel) et l'espace de stockage maximal autorisé pour la flavor.

![Modifier le modèle de nœud](/images/public-cloud/databases/databases-13-update-your-cluster-flavor/flavor_change_view.png)

Par exemple, si vous disposez d'un cluster PostgreSQL avec la flavor db1-15 et que vous utilisez moins de 384 Go (80 % de 480 Go) d'espace disque, vous pouvez passer à la flavor db1-7 sur cet endpoint :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/mongodb/\{clusterId\}"} />
