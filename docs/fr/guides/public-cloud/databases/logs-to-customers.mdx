## Objectif

Les bases de données managées Public Cloud vous permettent d'envoyer les logs de votre service vers votre propre flux de données Logs Data Platform (LDP).

**Ce guide explique comment transférer les logs de service vers votre propre flux LDP depuis la console OVHcloud ou avec l'API OVHcloud.**

## Prérequis

- Un [service de base de données Public Cloud](/links/public-cloud/databases) opérationnel
- Un accès à l'<ApiLink>API OVHcloud</ApiLink> (pour les étapes via l'API)
- Un compte Logs Data Platform au sein de ce compte OVHcloud avec au moins un flux de destination configuré
    - Si vous n'êtes pas familier avec toutes les possibilités de configuration des *Stream* LDP, créez simplement un nouveau flux avec les options par défaut (indexation et websocket activés, stockage à long terme désactivé) pour les besoins de ce guide.
- Un service de base de données opérationnel

## En pratique

### Créez votre abonnement

<Tabs>
  <Tab label="Depuis la console OVHcloud">
    Sur la page de votre service de base de données, ouvrez l'onglet <code className="action">Observabilité</code>, puis la vue **Journaux**. Cliquez sur <code className="action">Gérer le streaming</code>. Si votre service propose plusieurs types de journaux, sélectionnez d'abord le type à transférer dans la liste de la vue **Journaux** : le panneau gère un type de journal à la fois.

    Dans le panneau **Gérer le streaming des journaux**, sous **S'abonner à un flux**, sélectionnez votre **Compte LDP** et le **Flux**, puis cliquez sur <code className="action">S'abonner</code>.

    L'abonnement apparaît sous **Abonnements actuels** et les logs commencent à être transférés vers votre flux LDP. Si votre service propose plusieurs types de journaux, répétez l'opération pour chaque type à transférer.
  </Tab>
  <Tab label="Depuis l'API OVHcloud">
    1\. Récupérez les informations nécessaires
    
    **Récupérez le `streamId` de votre destination LDP :**
    
    Dans la console OVHcloud, ouvrez <code className="action">Observabilité</code> > <code className="action">Gestion des logs</code> dans le menu de gauche, sélectionnez votre compte Logs Data Platform, puis ouvrez l'onglet <code className="action">Flux de données</code>.
    
    Cliquez sur le nom de votre flux cible. L'identifiant du flux est la valeur qui suit `/streams/` dans l'adresse de la page qui s'ouvre (`.../logs-management/<compte-ldp>/streams/<streamId>/dashboard`) : copiez-la.
    
    **Récupérez le `serviceName` de votre destination LDP :**
    
    - Il s'agit de l'ID de votre projet Public Cloud. Pour le copier, cliquez sur le sélecteur <code className="action">Projet</code> en haut du menu de gauche de votre projet Public Cloud, puis sur l'icône de copie située sur la ligne de votre projet.
    
**Récupérez votre `clusterId` :**
    
    Dans le menu de gauche de votre projet Public Cloud, cliquez sur votre moteur sous **Bases de données**, puis sur le nom du service à gérer.
    
    Dans la carte **Informations générales** de l'onglet <code className="action">Vue d'ensemble</code>, vous trouverez le champ **Identifiant du service**, qui correspond à l'ID du cluster.
    
    2\. Commencez par récupérer les types de logs disponibles pour votre cluster de base de données avec l'appel API suivant :
    
    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/database/mysql/\\{clusterId\\}/log/kind"} />

Remplacez `mysql` dans la route par le moteur de votre service (par exemple `postgresql` ou `mongodb`).

Cela renverra la liste des valeurs kind valides que vous pouvez utiliser lors de l'abonnement aux logs.
    
    3\. Une fois le kind valide connu, utilisez-le pour vous abonner à un flux de logs avec cet appel API :
    
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/database/mysql/\\{clusterId\\}/log/subscription"} />

```console
    body : {
        kind: <log_type_from_previous_call>
        streamId: <your_stream_id>
    }
```
    
    Les logs commenceront alors à être transférés vers votre flux LDP.
  </Tab>
</Tabs>


### Retrouver les logs dans Graylog

Sur la page LDP, cliquez sur le bouton <code className="action">sample-data-stream</code> (le dernier flux de données modifié lors de votre précédent abonnement), ou cliquez sur le bouton <code className="action">Graylog</code>.

Vous devez vous connecter à l'aide de vos identifiants Graylog. Vous pouvez les récupérer depuis la page de détails LDP, dans la section `Configuration`. L'identifiant de connexion correspond à la valeur affichée sur la ligne `Logs Data Platform service`, et le mot de passe est affiché sous `Password`.

Une fois connecté, vous pouvez consulter les logs de votre service dans votre flux Graylog.

<img className="thumbnail" alt="Base de données LDP - résultat Graylog" src="/images/public-cloud/databases/databases-16-logs-to-customer/ldp_database_graylogs_result.png" loading="lazy" />

Vous pouvez également utiliser les requêtes Graylog suivantes pour un filtrage plus précis :

#### MongoDB

Requête : `cluster: "<HostID>"`

Vous pouvez trouver ce `HostID` dans la console OVHcloud :

- Ouvrez l'onglet <code className="action">Vue d'ensemble</code> de votre service MongoDB
- Dans la carte **Détails de connexion**, le champ **Hôte** est au format `<HostID>.database.cloud.ovh.net`

#### Autres moteurs

Requête : `clusterID: "<Engine>-<HostID>"`

Vous pouvez trouver ce `HostID` dans la console OVHcloud :

- Trouvez l'**Identifiant du service** (dans la carte **Informations générales** de l'onglet <code className="action">Vue d'ensemble</code>), au format UUID (AAAAAAAA-BBBB-CCCC-DDDDDDDDDDDD)
- `HostID` correspond à la première partie de l'UUID (AAAAAAAA)

### Supprimer un abonnement

Vous disposez de 2 méthodes pour supprimer un abonnement :

<Tabs>
  <Tab label="Depuis la console OVHcloud">
    Dans le panneau **Gérer le streaming des journaux** de l'onglet <code className="action">Observabilité</code> (vue **Journaux** > <code className="action">Gérer le streaming</code> ; si le service propose plusieurs types de journaux, sélectionnez d'abord le type), cliquez sur <code className="action">Se désabonner</code> sur l'abonnement concerné dans **Abonnements actuels**, puis sur <code className="action">Confirmer</code>.
  </Tab>
  <Tab label="Depuis l'API OVHcloud">
    - Vous pouvez supprimer des abonnements à l'aide du `subscriptionId` concerné dans cet appel API :
    
    <Api version="v1" section="/cloud" method="DELETE" route={"/cloud/project/\\{serviceName\\}/database/mysql/\\{clusterId\\}/log/subscription/\\{subscriptionId\\}"} />
  </Tab>
</Tabs>


- Si vous supprimez votre service de base de données, tous les abonnements de ce service sont automatiquement supprimés.
