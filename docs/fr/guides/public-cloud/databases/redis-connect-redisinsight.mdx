## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment se connecter à un service Valkey avec l'interface graphique gratuite : RedisInsight.**

## Prérequis

- Un accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet de service Valkey](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un service Valkey fonctionnant sur votre Public Cloud Databases OVHcloud ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)
- [Configurez votre service Valkey](/guides/public-cloud/databases/redis-prepare-for-incoming-connections) pour qu'il accepte les connexions entrantes
- Une version stable de RedisInsight installée et une connectivité réseau publique (Internet). Ce guide a été réalisé avec RedisInsight 1.11.1

## Concept

Un service Valkey peut être géré de plusieurs façons.
L'une des plus simples, mais aussi des plus puissantes, consiste à utiliser une interface en ligne de commande (CLI), comme illustré dans notre guide : [Se connecter avec la CLI](/guides/public-cloud/databases/redis-connect-cli), ou en utilisant des langages de programmation, tels que [PHP](/guides/public-cloud/databases/redis-connect-php).

Une autre méthode consiste à interagir directement via l'interface graphique : RedisInsight.

Pour ce faire, nous devrons installer RedisInsight, puis configurer notre service Public Cloud Databases pour Valkey afin qu'il accepte les connexions entrantes, et enfin configurer RedisInsight.

## En pratique

### Installation

Pour interagir avec votre service Valkey via RedisInsight, vous devez l'installer.

Suivez la documentation officielle [RedisInsight](https://docs.redis.com/latest/ri/installing) pour obtenir les dernières informations.

Nous sommes maintenant prêts à découvrir comment nous connecter à notre service Valkey.

### Se connecter avec RedisInsight

#### Rassembler les informations nécessaires

Sélectionnez l'onglet `Informations générales` pour trouver les informations de connexion nécessaires :

![Onglet des informations de connexion](/images/public-cloud/databases/redis-06-connect-redisinsight/redis_06_connect_redisinsight-20220209095337130.png)

#### Configuration

Une fois connecté à l'interface RedisInsight, cliquez sur le lien `I already have a database` :

![Premier écran Redis](/images/public-cloud/databases/redis-06-connect-redisinsight/redis_06_connect_redisinsight-20220207114821477.png)

Puis sur `Connect to a Valkey service` :

![Configurer votre service Valkey](/images/public-cloud/databases/redis-06-connect-redisinsight/redis_06_connect_redisinsight-2022020711515517.png)

Remplissez le formulaire avec les identifiants collectés précédemment. Cochez la case `Use TLS` et décochez la case `Verify TLS Certificate`. Cliquez ensuite sur `ADD REDIS DATABASE` :

![Ajouter une base de données Redis](/images/public-cloud/databases/redis-06-connect-redisinsight/redis_06_connect_redisinsight-20220207120005204.png)

Enfin, sélectionnez votre service Valkey :

![Dashboard](/images/public-cloud/databases/redis-06-connect-redisinsight/redis_06_connect_redisinsight-20220209095424435.png)

Félicitations ! Vous êtes désormais connecté à votre instance Valkey !

![Résultat](/images/public-cloud/databases/redis-06-connect-redisinsight/redis_06_connect_redisinsight-20220209095533690.png)

:::info
RedisInsight propose des fonctionnalités utiles.
Pour en savoir plus, consultez [cette page](https://redis.com/redis-enterprise/redis-insight/).

:::
