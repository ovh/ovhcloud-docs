## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment se connecter à une instance de base de données PostgreSQL avec l'un des langages de programmation les plus célèbres au monde : Python.**

Vous pouvez trouver un exemple sur le [dépôt d'exemples Github](https://github.com/ovh/public-cloud-databases-examples/tree/main/databases/postgresql/python/hello-world).

## Prérequis

- Un accès à l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>.
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud.
- Une base de données PostgreSQL exécutée sur votre service OVHcloud Public Cloud Databases ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)
- [Configurer votre instance PostgreSQL](/guides/public-cloud/databases/postgresql-prepare-for-incoming-connections) pour accepter les connexions entrantes
- Un environnement Python dans une version stable et une connectivité réseau publique (Internet). Ce guide a été réalisé avec Python 3.13.5.

## Concept

Une instance PostgreSQL peut être gérée de plusieurs façons.
L'une des plus simples, mais aussi des plus puissantes, consiste à utiliser une interface en ligne de commande (CLI), comme montré dans notre guide : [Se connecter à PostgreSQL avec la CLI](/guides/public-cloud/databases/postgresql-connect-cli).

Une autre façon consiste à interagir directement à l'aide d'un langage de programmation, tel que Python.
Python est l'un des principaux langages de programmation au monde, en particulier dans l'écosystème de la Data.

Pour cela, nous devrons configurer notre environnement Python avec les drivers PostgreSQL, puis configurer nos instances Public Cloud Databases for PostgreSQL pour qu'elles acceptent les connexions entrantes, et enfin coder en Python pour effectuer quelques actions d'exemple.

## En pratique

### Configurer votre environnement Python

Pour interagir avec votre instance PostgreSQL à l'aide de Python, votre environnement de développement doit être configuré avec :

- Une version compatible de Python
- Psycopg2

Merci de suivre la documentation officielle [Psycopg - l'adaptateur de base de données PostgreSQL pour Python](https://www.psycopg.org/docs/) pour obtenir les informations les plus récentes.

Une fois votre environnement Python configuré, en exécutant **python --version** dans votre interface en ligne de commande (CLI), vous devriez voir des informations sur la version, comme illustré ci-dessous :

```python
laptop$ python3 --version
Python 3.13.5
```

Dans la même console, en tapant **pip list**, vérifiez que **psycopg2** est correctement installé :

```python
laptop$  pip list | grep psycopg2
psycopg2               2.9.10
```

Nous sommes maintenant prêts à apprendre à nous connecter à notre instance PostgreSQL !

### Se connecter avec Python

#### Utilisation de psycopg2

Psycopg est l'adaptateur de base de données PostgreSQL le plus populaire pour le langage de programmation Python.

Dans votre environnement Python, essayons une connexion.

```python
import psycopg2

connection = psycopg2.connect(dbname='defaultdb', user='<user>', password='<password>', host='postgresql-xxxxxxxx-yyyyyyyy.database.cloud.ovh.net', port='20184', sslmode='require')

pid = connection.get_backend_pid()
cursor = connection.cursor()
cursor.execute(f'SELECT * FROM pg_stat_ssl WHERE pid = {pid}')
stat_ssl = cursor.fetchall()
print(stat_ssl)
```

Après avoir exécuté votre code Python, le résultat affiché dans la CLI devrait ressembler à ceci :

```python
[(3538261, True, 'TLSv1.3', 'TLS_AES_256_GCM_SHA384', 256, None, None, None)]
```
