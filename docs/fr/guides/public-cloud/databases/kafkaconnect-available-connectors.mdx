## Objectif

Cette page liste tous les connecteurs disponibles sur Kafka Connect managé par OVHcloud. Vous pouvez les parcourir avant de déployer un cluster.

Les connecteurs source ingèrent des données depuis des systèmes externes vers des topics Kafka. Les connecteurs sink exportent des données depuis des topics Kafka vers des destinations externes.

## Lister les connecteurs de votre service avec l'API

Cette liste a été vérifiée sur un service Kafka Connect 4.3. Pour obtenir les connecteurs disponibles sur votre service, avec leur identifiant, leur type et leur version, utilisez les appels API suivants :

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/kafkaConnect/\{clusterId\}/capabilities/connector"} />

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/kafkaConnect/\{clusterId\}/capabilities/connector/\{connectorId\}"} />

Consultez le guide « [Kafka Connect - Comment relier Kafka Connect à Kafka et créer un connecteur](/guides/public-cloud/data-analytics/analytics/kafkaconnect-create-connector) » pour créer un connecteur.
