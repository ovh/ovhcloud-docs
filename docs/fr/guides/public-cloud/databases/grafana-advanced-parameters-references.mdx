## Objectif

Ce guide répertorie tous les paramètres avancés pris en charge qui vous permettent de configurer votre Public Cloud Databases pour Dashboards selon vos cas d'usage.

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Une base de données fonctionnant sur votre Public Cloud Databases OVHcloud ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)
- Un accès à votre <ManagerLink to="/">espace client OVHcloud</ManagerLink> ou à l'<ApiLink>API OVHcloud</ApiLink>

## En pratique

:::warning
La gestion des paramètres avancés n'est pas prise en charge via Terraform.

:::


### Depuis l'API

Reportez-vous à ce [guide](/guides/public-cloud/databases/advanced-configuration#depuis-lapi) pour découvrir comment modifier vos paramètres avancés depuis l'API OVHcloud.

### Paramètres avancés pour Dashboards

Vous trouverez ci-dessous un récapitulatif de chaque option de configuration disponible pour le service Dashboards :

| | |
|---|---|
| Parameter | `smtp_server.from_address` |
| Value type | string |
| Minimum | |
| Maximum | |
| Values | |
| Description | Adresse utilisée pour l'envoi des e-mails |

| | |
|---|---|
| Parameter | `smtp_server.host` |
| Value type | string |
| Minimum | |
| Maximum | |
| Values | |
| Description | Nom d'hôte ou IP du serveur |

| | |
|---|---|
| Parameter | `smtp_server.port` |
| Value type | long |
| Minimum | 1 |
| Maximum | 65535  |
| Values | |
| Description | Port du serveur SMTP |

| | |
|---|---|
| Parameter | `smtp_server.skip_verify` |
| Value type | boolean |
| Minimum | |
| Maximum | |
| Values | |
| Description | Ignore la vérification du certificat du serveur. La valeur par défaut est false |

| | |
|---|---|
| Parameter | `smtp_server.starttls_policy` |
| Value type | string |
| Minimum | |
| Maximum | |
| Values | "MandatoryStartTLS", "NoStartTLS", "OpportunisticStartTLS" |
| Description | OpportunisticStartTLS, MandatoryStartTLS ou NoStartTLS. La valeur par défaut est OpportunisticStartTLS. |
