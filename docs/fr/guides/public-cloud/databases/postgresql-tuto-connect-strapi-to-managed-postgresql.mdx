## Objectif

Dans ce tutoriel, nous allons vous montrer comment créer une application [Strapi](https://strapi.io/) utilisant le service de base de données [PostgreSQL](https://www.postgresql.org/) managée [OVHcloud](/links/public-cloud/databases).

:::warning
OVHcloud fournit des services dont vous êtes responsable de la configuration et de la gestion. Vous êtes donc responsable de leur bon fonctionnement.

Ce tutoriel est conçu pour vous aider autant que possible dans les tâches courantes. Si vous rencontrez des difficultés pour réaliser ces actions, veuillez contacter un prestataire de services spécialisé et/ou en discuter avec notre [communauté d'utilisateurs](/links/community). OVHcloud ne peut pas vous fournir d'assistance technique à ce sujet.

:::


## Avant de commencer

Vous devez être en mesure de commander une solution de base de données dans l'espace client OVHcloud, comme expliqué dans notre guide [Bien démarrer avec Public Cloud Databases](/guides/public-cloud/databases/getting-started).

Comme [Strapi](https://strapi.io/) est écrit en Javascript, des paquets tels que [nodejs](https://nodejs.org/), [nvm](https://github.com/nvm-sh/nvm) et [yarn](https://classic.yarnpkg.com/en/) sont nécessaires pour ce tutoriel.

## En pratique

### Créer une base de données PostgreSQL

#### Souscrire au service

Cliquez sur <code className="action">Databases</code> dans le menu de navigation de gauche, sous **Storage**.

Cliquez sur le bouton <code className="action">Créer une instance</code>. (<code className="action">Créer un service</code> si votre projet contient déjà des bases de données.)

#### Étape 1 : sélectionner une base de données PostgreSQL

Cliquez sur la base de données PostgreSQL, puis sélectionnez la version à installer dans le menu déroulant.

<img className="thumbnail" alt="Choisir la base de données PostgreSQL" src="/images/public-cloud/databases/postgresql-tuto-01-connect-strapi-to-managed-postgresql/postgresql-tuto-01-connect-strapi-to-managed-postgresql01.png" loading="lazy" />

Cliquez sur <code className="action">Suivant</code> pour continuer.

#### Étape 2 : sélectionner une solution

À cette étape, choisissez le plan de service qui vous convient. Vous pourrez faire évoluer le plan après la création.

<img className="thumbnail" alt="Choisir un plan" src="/images/public-cloud/databases/postgresql-tuto-01-connect-strapi-to-managed-postgresql/postgresql-tuto-01-connect-strapi-to-managed-postgresql02.png" loading="lazy" />

Veuillez consulter la [page des capacités](/guides/public-cloud/databases/postgresql-capabilities) pour des informations détaillées sur les propriétés de chaque plan.

Cliquez sur <code className="action">Suivant</code> pour continuer.

#### Étape 3 : sélectionner un emplacement

Choisissez la région géographique du datacenter dans lequel votre base de données sera hébergée.

<img className="thumbnail" alt="Choisir la région" src="/images/public-cloud/databases/postgresql-tuto-01-connect-strapi-to-managed-postgresql/postgresql-tuto-01-connect-strapi-to-managed-postgresql03.png" loading="lazy" />

Cliquez sur <code className="action">Suivant</code> pour continuer.

#### Étape 4 : configurer les nœuds de la base de données

Vous pouvez choisir le modèle de nœud à cette étape. Le nombre initial et maximal de nœuds dépend de la solution choisie à l'étape 2.

<img className="thumbnail" alt="Commander des nœuds" src="/images/public-cloud/databases/postgresql-tuto-01-connect-strapi-to-managed-postgresql/postgresql-tuto-01-connect-strapi-to-managed-postgresql04.png" loading="lazy" />

Veuillez consulter la [page des capacités](/guides/public-cloud/databases/postgresql-capabilities) pour des informations détaillées sur les ressources matérielles et les autres propriétés de l'installation de la base de données MySQL.

Notez les informations tarifaires et cliquez sur <code className="action">Suivant</code> pour continuer.

#### Étape 5 : configurer vos options

Vous pouvez nommer votre base de données à cette étape.

<img className="thumbnail" alt="Configurer les options" src="/images/public-cloud/databases/postgresql-tuto-01-connect-strapi-to-managed-postgresql/postgresql-tuto-01-connect-strapi-to-managed-postgresql05.png" loading="lazy" />

Cliquez sur <code className="action">Suivant</code> pour continuer.

#### Étape 6 : résumé et confirmation

La dernière section affiche un résumé de votre commande ainsi que l'équivalent API de la création de cette instance de base de données avec l'[API OVHcloud](/guides/manage-and-operate/api/first-steps).

<img className="thumbnail" alt="Confirmer la commande" src="/images/public-cloud/databases/postgresql-tuto-01-connect-strapi-to-managed-postgresql/postgresql-tuto-01-connect-strapi-to-managed-postgresql06.png" loading="lazy" />

Cliquez sur <code className="action">Créer un service de base de données</code> pour continuer.

En quelques minutes, votre nouveau service de base de données sera déployé. Des messages dans l'espace client OVHcloud vous informeront lorsque la base de données sera prête à être utilisée.

Votre base de données est prête lorsque le statut du cluster est « Ready », le statut du nœud est vert et le nombre d'utilisateurs est réglé sur « 1 user ».

<img className="thumbnail" alt="Statuts verts dans l'espace client Databases" src="/images/public-cloud/databases/postgresql-tuto-01-connect-strapi-to-managed-postgresql/postgresql-tuto-01-connect-strapi-to-managed-postgresql08.png" loading="lazy" />

### Autoriser votre adresse IP

:::warning
Pour des raisons de sécurité, la configuration réseau par défaut n'autorise aucune connexion entrante.
Pour permettre à votre application ou à votre environnement de développement d'accéder à votre service de base de données PostgreSQL, vous devez ajouter vos adresses IP à la liste des adresses autorisées du service.

:::


#### Ajouter vos IP à la liste des IP autorisées de la base de données

En suivant la documentation associée sur la manière d'[autoriser les adresses IP appropriées](/guides/public-cloud/databases/mongodb-manage-control-panel#étape-2-autorisez-les-connexions-entrantes-depuis-le-client-mongodb), ajoutez vos IP à la liste des adresses autorisées.

### Tester la connexion à la base de données PostgreSQL

Un moyen simple et rapide de tester la connexion est d'utiliser l'interface en ligne de commande (CLI) de Postgre [psql](https://docs.postgresql.fr/14/app-psql.html).

> 💡 Astuce : si vous êtes familier avec [Docker](https://www.docker.com/) ou [Kubernetes](https://kubernetes.io/), vous pouvez utiliser l'outil psql à l'intérieur d'une [image](https://hub.docker.com/_/postgres) Docker postgres au lieu d'installer l'outil en local.
>
> Exemples :
>
> ```
> kubectl run postgres-client --image=postgres:latest -it --rm --restart=Never -- /bin/bash
> ```
>
> ou
>
> ```
> docker run -it --rm postgres /bin/bash
> ```
>

#### Se connecter à la base de données

Les paramètres utiles sont les suivants :

- L'hôte (db Host) et le port (db Port) de la base de données
    - Récupérez-les depuis l'onglet « General Information »
- Le nom de la base de données (db Name)
    - Récupérez-le depuis l'onglet « Databases », généralement « defaultdb »
- L'utilisateur de la base de données (db User)
    - Récupérez-le depuis l'onglet « Users », généralement « avnadmin »
- Le mot de passe de la base de données (db Password)
    - Récupérez-le après l'avoir régénéré.

<img className="thumbnail" alt="Mot de passe régénéré" src="/images/public-cloud/databases/postgresql-tuto-01-connect-strapi-to-managed-postgresql/postgresql-tuto-01-connect-strapi-to-managed-postgresql11.png" loading="lazy" />

Connectez-vous maintenant à la base de données avec la commande suivante

```sh
psql --dbname=defaultdb  --host=postgresql-ab1cd2ef-gh1ij2kl3.database.cloud.ovh.net --port=20184 --username=avnadmin  --password
```

Saisissez le mot de passe et appuyez sur <code className="action">Entrée</code>.

```console
$ psql --dbname=defaultdb  --host=postgresql-ab1cd2ef-gh1ij2kl3.database.cloud.ovh.net --port=20184 --username=avnadmin  --password
Password:
psql (14.1 (Debian 14.1-1.pgdg110+1))
SSL connection (protocol: TLSv1.3, cipher: TLS_AES_256_GCM_SHA384, bits: 256, compression: off)
Type "help" for help.

defaultdb=>
```

La configuration est terminée, votre base de données PostgreSQL managée est pleinement opérationnelle. Allons plus loin en l'utilisant avec [Strapi](https://strapi.io/).

### Avant de commencer, préparez votre environnement

Vous devez ici vérifier vos versions de `nodejs` et de `yarn`.
Selon la documentation officielle sur [GitHub](https://github.com/strapi/strapi), vérifiez que votre installation nodejs existante correspond à « NodeJS >= 12 &lt;= 16 ».

:::warning
Aucune version spécifique de yarn n'est requise ; ce tutoriel a été réalisé avec la version 1.22.17.

:::


Vous pouvez suivre ces différents tutoriels si vous avez besoin d'installer certains de ces outils :

- [nodejs](https://nodejs.org/en/download/package-manager/)
- [nvm](https://github.com/nvm-sh/nvm)
- [yarn](https://classic.yarnpkg.com/lang/en/docs/install/)

### Déclarer la version de nodejs

Nous voulons utiliser la dernière version LTS de nodejs. Dans votre environnement de développement, utilisez donc cette commande :

```sh
nvm use 16.13.1
```

Nous pouvons le corriger en modifiant manuellement le fichier de configuration de la base de données.<br/>
Ouvrez le fichier `config/database.js`.

Il devrait ressembler à ceci :

```console
module.exports = ({ env }) => ({
  connection: {
    client: 'postgres',
    connection: {
      host: env('DATABASE_HOST', 'postgresql-ab1cd2ef-gh1ij2kl3.database.cloud.ovh.net'),
      port: env.int('DATABASE_PORT', 20184),
      database: env('DATABASE_NAME', 'defaultdb'),
      user: env('DATABASE_USERNAME', 'avnadmin'),
      password: env('DATABASE_PASSWORD', 'MyStrongPassword'),
      ssl: env.bool('DATABASE_SSL', false),
    },
  },
});
```

Remplacez la ligne :

```console
ssl: env.bool('DATABASE_SSL', false),
```

par cette ligne :

```console
ssl: { rejectUnauthorized: env.bool('DATABASE_SSL_SELF', false), },
```

Enregistrez et fermez le fichier.

Maintenant, si vous choisissez `Yes` lorsqu'il vous est demandé d'activer la connexion SSL, récupérez le certificat CA depuis l'espace client OVHcloud :

<img className="thumbnail" alt="Télécharger le certificat" src="/images/public-cloud/databases/postgresql-tuto-01-connect-strapi-to-managed-postgresql/postgresql-tuto-01-connect-strapi-to-managed-postgresql16.png" loading="lazy" />

Enregistrez le fichier généré dans le dossier `config`, juste à côté du fichier `database.js`, et renommez-le en `ca-certificate.crt`.
Ouvrez maintenant le fichier `config/database.js` et modifiez le bloc `ssl` comme suit :

```console
const fs = require('fs');

module.exports = ({ env }) => ({
  connection: {
    client: 'postgres',
    connection: {
      host: env('DATABASE_HOST', 'postgresql-ab1cd2ef-gh1ij2kl3.database.cloud.ovh.net'),
      port: env.int('DATABASE_PORT', 20184),
      database: env('DATABASE_NAME', 'defaultdb'),
      user: env('DATABASE_USERNAME', 'avnadmin'),
      password: env('DATABASE_PASSWORD', 'MyStrongPassword'),
      ssl: {
	      ca: fs.readFileSync(`${__dirname}/ca-certificate.crt`).toString(),
      }
    },
  },
});
```

où `${__dirname}` est l'emplacement du dossier `config`.
Enregistrez et fermez le fichier, la configuration est terminée !

### Nettoyage

Pour nettoyer votre installation Strapi, assurez-vous qu'elle est bien arrêtée en appuyant sur <code className="action">CTRL+C</code> dans le terminal utilisé pour la lancer, puis supprimez votre dossier d'installation.

```sh
rm -rf /home/my/app/path/my-strapi/
```

Pour nettoyer votre base de données PostgreSQL, utilisez l'espace client OVHcloud pour supprimer votre service PostgreSQL managé :
