## Introduction

Le [MongoDB Relational Migrator](https://www.mongodb.com/fr-fr/products/tools/relational-migrator) est un outil puissant conçu pour faciliter la migration de données depuis des bases de données relationnelles traditionnelles, telles que MySQL, PostgreSQL et Oracle, vers MongoDB. Cet outil simplifie le processus complexe de migration de données grâce à une interface intuitive et des fonctionnalités automatisées garantissant l'intégrité et la cohérence des données.

## Fonctionnalités clés

1. **Découverte et analyse du schéma** : découvre et analyse automatiquement le schéma de votre base de données relationnelle, en fournissant des informations et des recommandations pour le processus de migration.
2. [**Transformation et mapping des données**](https://www.mongodb.com/docs/relational-migrator/mapping-rules/schema-mapping/#schema-mapping) : prend en charge des transformations et des mappings de données complexes, vous permettant d'adapter le modèle de données relationnel au modèle de documents de MongoDB.
3. [**Migration automatisée**](https://www.mongodb.com/developer/products/mongodb/easy-migration-relational-database-mongodb-relational-migrator/) : simplifie le processus de migration grâce à des fonctionnalités automatisées d'extraction, de transformation et de chargement des données (ETL).
4. [**Migration continue des données**](https://www.mongodb.com/docs/relational-migrator/jobs/sync-jobs/#sync-jobs) : permet une migration incrémentale des données afin de minimiser les temps d'interruption et de garantir la cohérence des données pendant la période de transition.
5. [**Validation des données**](https://www.mongodb.com/docs/relational-migrator/jobs/data-verification/use-data-verification/#use-data-verification) : fournit des outils permettant de valider l'intégrité et la cohérence des données après la migration.
6. [**Interface conviviale**](https://www.mongodb.com/docs/relational-migrator/getting-started/overview/#user-interface-overview) : propose une interface web intuitive pour gérer et suivre le processus de migration.

## Démarrage

### Prérequis

- Une instance MongoDB OVHcloud
- Un accès à la base de données relationnelle que vous souhaitez migrer
- Une compréhension de base des concepts de MongoDB et des bases de données relationnelles

### Processus de migration étape par étape

Vous pouvez vous référer à la documentation MongoDB pour un [guide de démarrage rapide](https://www.mongodb.com/docs/relational-migrator/getting-started/#get-started-with-relational-migrator).

## Scénarios de migration

Vous pouvez utiliser Relational Migrator pour migrer une application legacy à la fois vers MongoDB. Selon les besoins de votre application, vous pouvez migrer avec ou sans interruption de service.

- [Migrer pendant une interruption de service planifiée](https://www.mongodb.com/docs/relational-migrator/getting-started/migration-scenarios/#migrate-during-scheduled-downtime)
- [Migrer sans interruption de service](https://www.mongodb.com/docs/relational-migrator/getting-started/migration-scenarios/#migrate-without-downtime)
- [Scénarios de migration actuellement non pris en charge](https://www.mongodb.com/docs/relational-migrator/getting-started/migration-scenarios/#currently-unsupported-migration-scenarios)
