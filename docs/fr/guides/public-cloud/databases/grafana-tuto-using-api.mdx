## Objectif

L'utilisation de l'API Grafana® n'est pas évidente et n'est pas encore clairement documentée.
Ce tutoriel explique comment configurer Grafana® pour utiliser l'API et comment effectuer des appels vers l'API exposée.

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un service Dashboards exécuté sur votre projet Public Cloud OVHcloud (consultez [ce guide](/guides/public-cloud/databases/getting-started) pour créer un service Dashboards managé)

## En pratique

### Créer un compte de service Grafana®

Dans le menu de configuration, affichez l'onglet <code className="action">Service accounts</code> :

<img className="thumbnail" alt="Onglet des comptes de service Grafana" src="/images/public-cloud/databases/grafana-tuto-02-using-api/service-account-tab.png" loading="lazy" />

Créez un nouveau compte de service `sa-editor` avec le rôle `Editor` :

<img className="thumbnail" alt="Création d'un compte de service Grafana" src="/images/public-cloud/databases/grafana-tuto-02-using-api/service-account-creation.png" loading="lazy" />

Cliquez sur <code className="action">Add service account token</code> :

<img className="thumbnail" alt="Bouton de token de compte de service Grafana" src="/images/public-cloud/databases/grafana-tuto-02-using-api/add-service-account-token-button.png" loading="lazy" />

Saisissez le nom du token souhaité, `grafana-sa-token-editor`, puis cliquez sur <code className="action">Generate token</code> :

<img className="thumbnail" alt="Génération d'un token de compte de service Grafana" src="/images/public-cloud/databases/grafana-tuto-02-using-api/generate-sa-token.png" loading="lazy" />

Copiez le token généré :

<img className="thumbnail" alt="Token de compte de service Grafana généré" src="/images/public-cloud/databases/grafana-tuto-02-using-api/sa-account-generated-token.png" loading="lazy" />

:::warning
Après avoir fermé la pop-up, vous ne pourrez plus afficher le token !
:::


Le token créé apparaît dans la liste des tokens :

<img className="thumbnail" alt="Liste des tokens de comptes de service Grafana" src="/images/public-cloud/databases/grafana-tuto-02-using-api/sa-account-created-tokens-list.png" loading="lazy" />

Vous êtes prêt à utiliser ce token avec l'API Grafana®.

### Utiliser l'API Grafana®

:::info
Des instructions détaillées sur l'utilisation de l'API et les actions possibles sont disponibles dans la documentation officielle : [https://grafana.com/docs/grafana/latest/developers/http_api/](https://grafana.com/docs/grafana/latest/developers/http_api/)
:::


:::warning
N'oubliez pas de définir les `Authorised IP addresses` dans la configuration de Dashboards. Consultez notre guide [Configurer votre instance Grafana pour accepter les connexions entrantes](/guides/public-cloud/databases/grafana-prepare-for-incoming-connections) pour plus de détails.
:::


Pour envoyer une requête à l'API, vous devez utiliser le token créé précédemment et le renseigner dans l'en-tête de la requête en tant que « Bearer token » :

```bash
export GRAFANA_API_TOKEN=042footoken420

curl -H "Authorization: Bearer $GRAFANA_API_TOKEN" https://grafana-xxxxxxxxx-yyyyyyyyy.database.cloud.ovh.net/api/folders    
[
    {
        "id":11,
        "uid":"HnDCAp-4k",
        "title":"foo 1"
    },
    {
        "id":5,
        "uid":"cb_S6Pb4k",
        "title":"foo 2"
    },
    {
        "id":9,
        "uid":"Xav55taVk",
        "title":"foo 3"
    },
    {
        "id":10,
        "uid":"AH8sApaVz",
        "title":"foo 4"
    }
]

```

Et voilà, vous pouvez désormais exploiter toute la puissance de l'API Grafana®.
