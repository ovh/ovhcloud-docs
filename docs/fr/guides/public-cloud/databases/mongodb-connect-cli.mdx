## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment se connecter à une instance de base de données MongoDB avec une interface en ligne de commande (CLI).**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Une base de données MongoDB active sur votre service Public Cloud Databases OVHcloud (vous pouvez utiliser [ce guide](/guides/public-cloud/databases/getting-started) pour remplir ce prérequis)
- [Configurer votre instance MongoDB](/guides/public-cloud/databases/mongodb-manage-control-panel) pour accepter les connexions entrantes

## Concept

Une instance MongoDB peut être gérée de plusieurs façons.
L'une des plus simples, mais aussi des plus puissantes, consiste à utiliser une interface en ligne de commande (CLI), aussi appelée console ou terminal.
Pour interagir correctement avec l'instance MongoDB, nous devons d'abord installer un élément appelé client MongoDB, afin de nous connecter et de contrôler le service MongoDB à distance.
Il s'agit d'une interaction client-serveur.

## En pratique

### Installer MongoDB Shell sur votre client

:::info
Veuillez noter que MongoDB Shell est également intégré nativement dans le package logiciel communautaire de MongoDB.
:::


Vous devez d'abord installer un logiciel pour interagir avec votre instance MongoDB à distance. Ce logiciel officiel peut être installé sur divers supports comme votre propre ordinateur, un VPS, une machine virtuelle... la seule règle étant de pouvoir accéder au réseau public (Internet) et de disposer des droits suffisants pour l'installer.

Pour cela, et selon votre configuration, vous devrez peut-être suivre la documentation officielle de MongoDB pour installer MongoDB Shell (appelé mongosh).

Suivez les étapes ici après avoir sélectionné le système d'exploitation Windows, MacOS ou Linux : [https://docs.mongodb.com/mongodb-shell/install/#std-label-mdb-shell-install](https://docs.mongodb.com/mongodb-shell/install/#std-label-mdb-shell-install)

Nous allons maintenant suivre la documentation officielle de MongoDB pour effectuer notre première connexion.

Dans votre CLI, tapez *mongosh --version*. Le résultat devrait ressembler à ceci :

```
laptop$ mongosh --version
1.5.1
```

Cela signifie que mongosh est correctement installé et fonctionne normalement. Si vous n'obtenez pas un résultat similaire, veuillez revenir à l'étape précédente et réinstaller MongoDB Shell.

### Se connecter à votre instance MongoDB

Pour établir une connexion, tapez simplement *mongosh* suivi du Service URI copié précédemment :

```
laptop$mongosh "mongodb+srv://`<username>`:<password>@mongodb-e49d02ee-o2626ab53.database.cloud.ovh.net/admin?replicaSet=replicaset"
```

N'oubliez pas de modifier le nom d'utilisateur, le mot de passe et le nom d'hôte.

Une fois correctement connecté, vous devriez voir quelque chose de similaire à :

```
Current Mongosh Log ID: 6137881570829aa067222c24
Connecting to:      mongodb+srv://<credentials>@mongodb-e49d02ee-o2626ab53.database.cloud.ovh.net/admin?replicaSet=replicaset&appName=mongosh+1.5.1
Using MongoDB:      4.4.6
Using Mongosh Beta: 1.5.1

For mongosh info see: https://docs.mongodb.com/mongodb-shell/

replicaset [direct: primary]>
```

Félicitations ! Vous êtes maintenant pleinement capable d'interagir avec votre instance MongoDB !

### Utilisation de MongoDB Shell

Une fois connecté, vous pouvez gérer votre instance MongoDB avec les méthodes intégrées de MongoDB Shell.

Veuillez suivre la documentation officielle de MongoDB.

Pour vérifier :

- *db* : indiquera sur quelle base de données vous vous trouvez
- *use myNewDatabase* basculera vers une autre base de données (en créera une si elle n'existe pas)
- *db.myCollection.insertOne( ... )* insérera des données dans votre collection

Dans notre exemple, cela ressemblera à ceci :

```
replicaset [direct: primary]> db
admin
replicaset [direct: primary]> use myNewDatabase
switched to db myNewDatabase
replicaset [direct: primary]> db
myNewDatabase
replicaset [direct: primary]> db.myCollection.insertOne( { x: 1 } );
{
  acknowledged: true,
  insertedId: ObjectId("61378bc0fc37b3df64e48b18")
}
replicaset [direct: primary]> db.myCollection.find()
[ { _id: ObjectId("61378bc0fc37b3df64e48b18"), x: 1 } ]
replicaset [direct: primary]>
```
