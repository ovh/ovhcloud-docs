## Objectif

Ce guide répertorie tous les paramètres avancés pris en charge qui vous permettent de configurer votre Public Cloud Databases pour Valkey selon vos cas d'usage.

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Une base de données fonctionnant sur votre Public Cloud Databases OVHcloud ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)
- Un accès à votre <ManagerLink to="/">espace client OVHcloud</ManagerLink> ou à l'<ApiLink>API OVHcloud</ApiLink>

## En pratique

:::warning
La gestion des paramètres avancés n'est pas prise en charge via Terraform.

:::


### Depuis l'espace client OVHcloud

Reportez-vous à ce [guide](/guides/public-cloud/databases/advanced-configuration#depuis-lespace-client-ovhcloud) pour découvrir comment modifier vos paramètres avancés depuis l'espace client OVHcloud.

### Depuis l'API

Reportez-vous à ce [guide](/guides/public-cloud/databases/advanced-configuration#depuis-lapi) pour découvrir comment modifier vos paramètres avancés depuis l'API OVHcloud.

### Paramètres avancés pour Valkey

Vous trouverez ci-dessous un récapitulatif de chaque option de configuration disponible pour le service Valkey :

| | |
|---|---|
| Parameter | `redis_acl_channels_default` |
| Value type | string |
| Minimum | |
| Maximum | |
| Values | "allchannels", "resetchannels" |
| Description | Détermine l'ACL par défaut des canaux pub/sub pour les nouveaux utilisateurs si aucune ACL n'est fournie. Lorsque cette option n'est pas définie, all_channels est présumé par souci de compatibilité ascendante. Cette option n'affecte pas le paramètre Redis acl-pubsub-default. |

| | |
|---|---|
| Parameter | `redis_io_threads` |
| Value type | long |
| Minimum | 1 |
| Maximum | 32 |
| Values | |
| Description | Nombre de threads IO de Redis |

| | |
|---|---|
| Parameter | `redis_lfu_decay_time` |
| Value type | long |
| Minimum | 1 |
| Maximum | 120 |
| Values | |
| Description | Durée de décroissance du compteur LFU maxmemory-policy, en minutes |

| | |
|---|---|
| Parameter | `redis_lfu_log_factor` |
| Value type | long |
| Minimum | 0 |
| Maximum | 100 |
| Values | |
| Description | Facteur logarithmique du compteur pour les politiques maxmemory-policy volatile-lfu et allkeys-lfu |

| | |
|---|---|
| Parameter | `redis_notify_keyspace_events` |
| Value type | string |
| Minimum | |
| Maximum | |
| Values | |
| Description | Définit l'option notify-keyspace-events |

| | |
|---|---|
| Parameter | `redis_number_of_databases` |
| Value type | long |
| Minimum | 1 |
| Maximum | 128 |
| Values | |
| Description | Définit le nombre de bases de données Redis. La modification de ce paramètre entraînera un redémarrage du service Redis. |

| | |
|---|---|
| Parameter | `redis_persistence` |
| Value type | string |
| Minimum | |
| Maximum | |
| Values | "off", "rdb" |
| Description | Lorsque la persistance est réglée sur 'rdb', Redis effectue des dumps RDB toutes les 10 minutes si une clé est modifiée. Des dumps RDB sont également effectués selon la planification des sauvegardes à des fins de sauvegarde. Lorsque la persistance est réglée sur 'off', aucun dump RDB ni aucune sauvegarde n'est effectué, les données peuvent donc être perdues à tout moment si le service est redémarré pour une raison quelconque, ou s'il est mis hors tension. Le service ne peut pas non plus être forké. |

| | |
|---|---|
| Parameter | `redis_pubsub_client_output_buffer_limit` |
| Value type | long |
| Minimum | 32 |
| Maximum | 512 |
| Values | |
| Description | Définit la limite du tampon de sortie pour les clients pub/sub, en Mo. La valeur correspond à la limite stricte ; la limite souple équivaut à 1/4 de la limite stricte. Lors de la définition de la limite, tenez compte de la mémoire disponible dans le plan de service sélectionné. |

| | |
|---|---|
| Parameter | `redis_ssl` |
| Value type | boolean |
| Minimum | |
| Maximum | |
| Values | |
| Description | Exige SSL pour accéder à Redis |

| | |
|---|---|
| Parameter | `redis_timeout` |
| Value type | long |
| Minimum | 0 |
| Maximum | 31536000 |
| Values | |
| Description | Délai d'expiration des connexions inactives de Redis, en secondes |
