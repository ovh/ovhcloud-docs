## Objectif

Apprenez à mettre à niveau le plan de service de votre cluster selon vos besoins.

:::warning
Une fois votre solution mise à niveau, vous ne pourrez pas revenir à une solution inférieure.

:::


## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un accès à l'<ApiLink>API OVHcloud</ApiLink> (facultatif)

{/* CP-NAV-START:publiccloud-projects */}
---

### Accès à l'espace client OVHcloud

- **Lien direct :** <ManagerLink to="/#/pci/projects">Projets Public Cloud</ManagerLink>
- **Chemin de navigation :** <code className="action">Public Cloud</code> > Sélectionnez votre projet

---

## En pratique

### Depuis l'espace client OVHcloud

Cliquez sur <code className="action">Databases</code> dans la barre de navigation de gauche, sélectionnez votre instance de moteur, puis cliquez sur l'onglet <code className="action">Configuration</code>.

![Vue d'ensemble du cluster](/images/public-cloud/databases/databases-14-upgrade-your-cluster-plan/cluster_overview.png)

Cliquez sur <code className="action">Modifier</code> sur la ligne « Plan » et ajustez le plan de votre cluster.

![Changer de solution](/images/public-cloud/databases/databases-14-upgrade-your-cluster-plan/plan_change_view.png)

### Depuis l'API OVHcloud

:::tip
Si vous n'êtes pas familiarisé avec l'utilisation de l'API OVHcloud, veuillez consulter notre guide [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps).

:::


Pour mettre à niveau ou revenir à un plan de service inférieur pour votre cluster, utilisez l'appel API suivant :

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/mysql/\{clusterId\}"} />

Remplacez `mysql` dans la route par le moteur de votre service (par exemple `postgresql` ou `mongodb`).

```console
body : {
    plan: <essential|business|production|enterprise|advanced>
}
```

Si vous revenez à un plan Essential, votre gamme actuelle et/ou votre nombre de nœuds seront automatiquement réduits s'ils dépassent les limites du plan Essential.
