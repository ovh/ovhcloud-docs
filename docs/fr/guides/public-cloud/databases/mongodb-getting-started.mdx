## Objectif

**Ce guide vous explique comment créer un service de base de données managé MongoDB depuis la console OVHcloud et comment vous y connecter.**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) actif sur votre compte OVHcloud

[[cpnav:publiccloud-databases]]

## En pratique

Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">MongoDB</code> sous **Bases de données**, puis sur <code className="action">Créer un service</code>. La page **Créer une base de données infogérée** s'ouvre.

### Sélectionner le moteur de base de données

Sous **Moteur de base de données**, sélectionnez **MongoDB**. Vous pouvez modifier la version à installer sous **Version**.

### Sélectionner une région

Sous **Sélectionner une région**, sélectionnez la région dans laquelle votre service sera déployé.

### Sélectionner une offre

Sous **Offre**, sélectionnez l'offre adaptée à vos besoins :

- **Production** : un cluster de 3 nœuds, sauvegardé quotidiennement avec une rétention de 7 jours.
- **Advanced** : un cluster de 3 à 7 nœuds (dont, en option, un nœud d'analyse), sauvegardé quotidiennement avec une rétention de 30 jours et une restauration à un instant donné (PITR) sur les 24 dernières heures.

Pour une comparaison détaillée des offres, consultez le guide « [Capacités et limitations](/guides/public-cloud/databases/mongodb-concept-capabilities) ».

### Sélectionner le modèle de nœud

Sous **Type de nœud**, sélectionnez le modèle de nœud. Il définit les ressources de calcul (vCores et RAM) de chaque nœud de votre cluster. Consultez la [page des tarifs](/links/public-cloud/prices-mongodb) pour plus de détails sur les types de nœuds et leurs spécifications.

### Dimensionner votre cluster

Sous **Nœuds**, ajustez le nombre de nœuds (selon l'offre). Si le modèle de nœud propose une plage de stockage, sélectionnez le stockage additionnel sous **Stockage**.

### Configurer le réseau

Sous **Réseau**, sélectionnez le type de réseau :

- **Réseau public** : votre service est accessible depuis Internet.
- **Réseau privé (vRack)** : votre service est accessible uniquement depuis le réseau privé que vous sélectionnez (champs **Réseau privé** et **Sous-réseau**). Le réseau et le sous-réseau doivent exister avant la création du service.

Vous pouvez également ajouter des **Restrictions IP** dès maintenant (<code className="action">Ajouter une IP</code>, <code className="action">Ajouter mon IP actuelle</code>) ou une fois le service créé.

### Vérifier et créer le service

Vérifiez le **Récapitulatif**. Le nom de votre cluster est généré automatiquement ; vous pouvez le modifier dans le champ **Nom** avant de créer le service, ou par la suite.

Cliquez sur le bouton <code className="action">Créer la base de données</code>. Le bouton <code className="action">Équivalent API et Terraform</code> affiche l'appel API et la configuration Terraform équivalents.

En quelques minutes, votre service MongoDB sera déployé.

### Paramètres de connectivité

Une fois le service opérationnel, vous pourrez le configurer pour qu'il accepte les connexions entrantes. Un [guide dédié](/guides/public-cloud/databases/mongodb-manage-control-panel) est disponible pour vous aider à configurer votre service après l'installation.

### Tester le service

Lorsque le service est en cours d'exécution et accepte les connexions entrantes, l'étape suivante consiste à y accéder. La méthode la plus courante consiste à utiliser **MongoDB Compass** pour se connecter au service, en suivant [ce guide](/guides/public-cloud/databases/mongodb-connect-compass).

Si **MongoDB Compass** n'est pas votre méthode préférée, consultez ces autres guides pour vous connecter au service :

- [Se connecter avec la CLI](/guides/public-cloud/databases/mongodb-connect-cli)
- [Se connecter avec Python](/guides/public-cloud/databases/mongodb-connect-python)
- [Se connecter avec PHP](/guides/public-cloud/databases/mongodb-connect-php)

D'autres exemples d'intégration sont disponibles sur le dépôt suivant : [https://github.com/ovh/public-cloud-databases-examples/tree/main/databases/mongodb](https://github.com/ovh/public-cloud-databases-examples/tree/main/databases/mongodb).
