## Objectif

**Ce guide vous explique comment créer un service de base de données managé MongoDB depuis l'espace client OVHcloud et comment vous y connecter.**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) actif sur votre compte OVHcloud

[[cpnav:publiccloud-databases]]

## En pratique

Cliquez sur <code className="action">Databases</code> dans la barre de navigation de gauche, sous **Databases & Analytics**.

Cliquez sur le bouton <code className="action">Créer une instance</code> (cliquez sur <code className="action">Créer un service</code> si votre projet contient déjà des bases de données).

### Sélectionner le moteur de base de données

Sous **Engine**, sélectionnez **MongoDB**. Vous pouvez choisir de modifier la version à installer depuis le menu déroulant.

### Sélectionner une offre

Sous **Offre**, sélectionnez l'offre adaptée à vos besoins :

- **Production** : un cluster de 3 nœuds, sauvegardé quotidiennement avec une rétention de 7 jours.
- **Advanced** : un cluster de 3 à 7 nœuds (dont, en option, un nœud analytique), sauvegardé quotidiennement avec restauration à un instant donné (PITR) et une rétention de 30 jours.

Pour une comparaison détaillée des offres, consultez le guide [Capacités et limitations](/guides/public-cloud/databases/mongodb-concept-capabilities).

### Sélectionner une région

Sous **Datacentre**, sélectionnez la région dans laquelle votre service sera déployé.

### Sélectionner le modèle de nœud

Sous **Instance**, sélectionnez le modèle de nœud. Il définit les ressources de calcul (vCores et RAM) de chaque nœud de votre cluster. Consultez la [page des tarifs](/links/public-cloud/prices) pour plus de détails sur les types de nœuds et leurs spécifications.

### Dimensionner votre cluster

Sous **Dimensionnement du cluster**, ajustez le **Nombre de nœuds** (selon l'offre) et le **Stockage** de votre service.

### Configurer les options

Sous **Options**, sélectionnez le type de **Réseau** :

- **Réseau Public (Internet)** : votre service est accessible depuis internet.
- **Réseau Privé (vRack)** : votre service est accessible uniquement depuis le réseau privé que vous sélectionnez. Le réseau et le sous-réseau doivent exister avant la création du service.

Vous pouvez également ajouter des **IPs autorisées** dès maintenant, ou le faire une fois le service créé.

### Vérifier et commander

Vérifiez le récapitulatif de votre commande sous **Votre commande**. Le nom de votre cluster est généré automatiquement ; vous pourrez le modifier par la suite.

Cliquez sur le bouton <code className="action">Commander</code>.

En quelques minutes, votre service MongoDB sera déployé.

### Paramètres de connectivité

Une fois le service opérationnel, vous pourrez le configurer pour qu'il accepte les connexions entrantes. Un [guide dédié](/guides/public-cloud/databases/mongodb-manage-control-panel) est disponible pour vous aider à configurer votre service après l'installation.

### Tester le service

Lorsque le service est en cours d'exécution et accepte les connexions entrantes, l'étape suivante consiste à y accéder. La méthode la plus courante consiste à utiliser **MongoDB Compass** pour se connecter au service, en suivant [ce guide](/guides/public-cloud/databases/mongodb-connect-compass).

Si **MongoDB Compass** n'est pas votre méthode préférée, consultez ces autres guides pour vous connecter au service :

- [Se connecter avec la CLI](/guides/public-cloud/databases/mongodb-connect-cli)
- [Se connecter avec Python](/guides/public-cloud/databases/mongodb-connect-python)
- [Se connecter avec PHP](/guides/public-cloud/databases/mongodb-connect-php)

D'autres exemples d'intégration sont disponibles sur le dépôt suivant : [https://github.com/ovh/public-cloud-databases-examples/tree/main/databases/mongodb](https://github.com/ovh/public-cloud-databases-examples/tree/main/databases/mongodb).
