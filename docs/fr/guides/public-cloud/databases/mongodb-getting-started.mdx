## Objectif

**Ce guide vous accompagne dans vos premiers pas avec Public Cloud Databases pour MongoDB : créer un service, autoriser votre adresse IP, créer un utilisateur et vous connecter.**

:::warning
Le plan gratuit **Discovery** (type de nœud `db2-free`) n'est plus commercialisé. Les services Discovery existants sont suspendus le 31 octobre 2026, puis supprimés avec leurs données le 30 novembre 2026. Découvrez comment [passer votre service au plan Production ou exporter vos données](/guides/public-cloud/databases/mongodb-howto-backup-restore).
:::

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

## En pratique

### Créer le service

Cliquez sur <code className="action">Créer votre base de données managée</code>, ou sur <code className="action">Créer un service</code> si votre projet contient déjà des bases de données. Dans la page `Créer un service de base de données` :

1. Dans le champ `Engine`, sélectionnez **MongoDB**, puis sa `Version` : **7.0** ou **8.0**.
2. Dans le champ `Offre`, sélectionnez **Production** (3 nœuds) ou **Advanced**. La [page des capacités](/guides/public-cloud/databases/mongodb-concept-capabilities) détaille les différences entre les plans.
3. Sélectionnez le `Datacentre`, l'`Instance` (type de nœud) et, si besoin, du `Stockage` supplémentaire.
4. Sélectionnez le type de `Réseau`. Vous pouvez déjà ajouter l'adresse IP publique de votre machine dans `IPs autorisées`. Saisissez ensuite un `Nom` pour votre service.
5. Vérifiez `Votre commande`, puis cliquez sur <code className="action">Commander</code>.

Le service apparaît dans la liste de vos services. Il est utilisable lorsque son statut est `READY`, après plusieurs minutes.

### Autoriser votre adresse IP

Votre service refuse toutes les connexions tant que vous n'avez pas autorisé une adresse IP ou un bloc CIDR. Si vous n'avez pas ajouté votre adresse IP à la création du service, ouvrez votre service, puis l'onglet <code className="action">Configuration</code>. Dans la section `IPs`, ajoutez l'adresse IP publique de la machine qui se connecte au service, puis cliquez sur <code className="action">Sauvegarder les modifications</code>. Le [guide dédié](/guides/public-cloud/databases/mongodb-manage-control-panel) donne plus de détails.

### Créer votre premier utilisateur

Aucun utilisateur n'est créé avec le service. Ouvrez l'onglet <code className="action">Utilisateurs</code>, puis cliquez sur <code className="action">Ajouter un utilisateur</code> :

1. Saisissez un nom d'utilisateur.
2. Ajoutez un ou plusieurs rôles, par exemple `readWrite` sur la base utilisée par votre application, ou `readWriteAnyDatabase` sur la base `admin`.
3. Cliquez sur <code className="action">Créer un utilisateur</code>.

Notez le mot de passe affiché : il ne pourra pas être récupéré par la suite. Vous pouvez en générer un nouveau avec l'action <code className="action">Regénérer le mot de passe</code> de l'utilisateur.

:::info
Les utilisateurs se gèrent uniquement depuis l'espace client OVHcloud ou l'API OVHcloud. Un utilisateur créé avec la commande `createUser` est supprimé automatiquement quelques minutes plus tard.
:::

### Se connecter au service

Dans l'onglet <code className="action">Dashboard</code>, la section `Informations de connection` affiche l'URI de votre service. Remplacez `<username>` et `<password>` par les identifiants de votre utilisateur.

Suivez ensuite l'un de ces guides pour vous connecter :

- [Se connecter avec mongosh](/guides/public-cloud/databases/mongodb-connect-cli)
- [Se connecter avec MongoDB Compass](/guides/public-cloud/databases/mongodb-connect-compass)
- [Se connecter avec Python](/guides/public-cloud/databases/mongodb-connect-python)
- [Se connecter avec PHP](/guides/public-cloud/databases/mongodb-connect-php)

D'autres exemples d'intégration sont disponibles sur le dépôt suivant : [https://github.com/ovh/public-cloud-databases-examples/tree/main/databases/mongodb](https://github.com/ovh/public-cloud-databases-examples/tree/main/databases/mongodb).
