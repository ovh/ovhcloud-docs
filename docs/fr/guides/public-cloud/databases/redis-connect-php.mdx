## Objectif

Public Cloud Databases vous permet de vous concentrer sur la création et le déploiement de vos applications cloud, pendant qu'OVHcloud prend en charge l'infrastructure de base de données et son maintien en conditions opérationnelles.

**Ce guide explique comment se connecter à une instance de service Valkey à l'aide de l'un des langages de programmation les plus célèbres au monde : PHP.**

Vous trouverez un exemple sur le [dépôt d'exemples Github](https://github.com/ovh/public-cloud-databases-examples/tree/main/databases/redis/php/hello-world).

## Prérequis

- Un accès à votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>
- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- Un service Valkey actif sur votre service OVHcloud Public Cloud Databases ([ce guide](/guides/public-cloud/databases/getting-started) peut vous aider à répondre à ce prérequis)
- [Configurer votre service Valkey](/guides/public-cloud/databases/redis-prepare-for-incoming-connections) pour qu'il accepte les connexions entrantes
- Un environnement PHP dans une version stable et disposant d'une connectivité au réseau public (Internet). Ce guide a été réalisé en PHP 7.4.

## Concept

Un service Valkey peut être géré de plusieurs façons.
L'une des plus simples, tout en restant puissante, consiste à utiliser une interface en ligne de commande (CLI), comme le montre notre guide : [Se connecter avec la CLI](/guides/public-cloud/databases/redis-connect-cli).

Une autre méthode consiste à interagir directement à l'aide de langages de programmation, tels que PHP.
PHP est utilisé sur près de 80 % des sites web dans le monde, comme Facebook, Wikipedia ou WordPress.
Redis® propose plusieurs clients PHP, permettant de se connecter à une instance et de la gérer depuis le code. Veuillez consulter la [documentation officielle de Redis® pour les clients PHP](https://redis.io/clients#php) pour obtenir les informations les plus récentes sur les clients.

Nous allons devoir configurer notre environnement PHP avec le client phpredis, puis configurer notre service Public Cloud Databases pour Valkey afin qu'il accepte les connexions entrantes, et enfin coder en PHP pour effectuer quelques actions d'exemple.

## En pratique

### Configurer votre environnement PHP

Pour interagir avec votre instance en PHP, votre environnement de développement doit être configuré avec :

- Une version compatible de PHP ;
- Une extension PHP prenant en charge la version 6 du logiciel open source Redis® et TLS, comme recommandé par Redis® : les bibliothèques PHP phpredis ou Predis.

Pour phpredis comme pour Predis, il est recommandé de consulter leurs sites respectifs pour connaître la procédure d'installation :

- [GitHub officiel de phpredis](https://github.com/phpredis/phpredis) ;
- [GitHub officiel de Predis](https://github.com/predis/predis).

Nous sommes maintenant prêts à apprendre comment nous connecter à notre instance. Nous utiliserons phpredis comme client PHP.

### Se connecter avec PHP

Dans votre environnement PHP, essayons une connexion. Pour être sûr d'être bien connecté, définissez une paire de données puis vérifiez que vous pouvez en récupérer la valeur.

```php
<?php
   // PHP version 7.4 used here
	echo "\nConnection to server ongoing...";
	$redis = new Redis() or die("Cannot load Redis module in PHP.");

	// Connection to the Redis DB
	$redis->connect('tls://redis-9f6095f3-of5ff6e31.database.cloud.ovh.net', 20185);

	// Setup the user
	$redis->auth(['redisUser', '3FAKExSW6Rez9Xw0admB']);

	// Ping the instance
	echo "\nServer is running: ".$redis->ping("OK");

	// Set the key pair
	echo "\nSet key pair (foo,cowabunga).";
	$redis->set('foo', 'cowabunga');

	// Get the value of the key foo
	$response = $redis->get('foo');
	echo "\nGet the value for key foo :";
	echo $response;

	if ($response == "cowabunga") {
		echo "\nPHP test with Redis OK.\n";
	} else {
		echo "\nPHP Test FAILED\n";
	}
?>
```
Félicitations ! Tout fonctionne correctement.
