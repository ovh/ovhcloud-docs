## Introduction

Les outils de Business Intelligence (BI) comme Tableau et Power BI sont des produits très répandus pour la visualisation et l'analyse de données. Ils permettent aux utilisateurs de transformer des données brutes en informations exploitables grâce à des tableaux de bord et des rapports interactifs. Le [connecteur MongoDB BI](https://www.mongodb.com/docs/bi-connector/current/) vous permet de créer des requêtes en SQL pour visualiser, représenter graphiquement et générer des rapports sur vos données MongoDB tridimensionnelles à l'aide d'outils de business intelligence relationnels.

Le connecteur MongoDB BI agit comme un pont entre MongoDB et les outils de BI, vous permettant de visualiser et d'analyser vos données MongoDB sans transformations de données complexes. Ce guide couvre l'installation du connecteur BI, sa configuration, ainsi que la connexion de votre outil de BI au cluster OVHcloud.

## Connecter l'outil de BI au cluster OVHcloud

### Étape 1 : installer le connecteur BI

Consultez la documentation MongoDB pour [installer le connecteur BI](https://www.mongodb.com/docs/bi-connector/current/installation/#install-bi-connector-on-premises).

### Étape 2 : lancer le connecteur BI

Consultez la documentation MongoDB pour [lancer le connecteur BI](https://www.mongodb.com/docs/bi-connector/current/launch/#launch-bi-connector).

Voici un exemple de démarrage du connecteur avec le cluster OVHcloud via la ligne de commande :

```javascript
mongosqld --mongo-uri "mongodb://node2-0b70a1b78fff6c0e.database.cloud.ovh.net:27017,node1-0b70a1b78fff6c0e.database.cloud.ovh.net:27017,node3-0b70a1b78fff6c0e.database.cloud.ovh.net:27017/" --auth -u myuser -p mypassword --mongo-ssl
```

:::warning
Assurez-vous que l'adresse IP de la machine exécutant mongosqld est autorisée dans votre cluster MongoDB OVHcloud.
:::


Consultez la documentation MongoDB sur le lancement du connecteur BI via la [ligne de commande](https://www.mongodb.com/docs/bi-connector/current/launch/#start-mongosqld-from-the-command-line) ou en tant que [service système](https://www.mongodb.com/docs/bi-connector/current/launch/#install-mongosqld-as-a-system-service).

Consultez la documentation MongoDB pour des informations complémentaires sur le [démarrage de mongosqld](https://www.mongodb.com/docs/bi-connector/current/reference/mongosqld/).
