## Objectif

Une [Gateway](/links/public-cloud/gateway) offre une méthode de connexion sortante sécurisée depuis vos instances en réseau privé, ou la possibilité d'utiliser des adresses Floating IP avec votre instance ou votre Load Balancer pour l'exposition de services.

**Apprenez à créer un réseau privé avec une Gateway.**

## Prérequis

- Posséder un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud
- **Pour l'API OVHcloud :** des identifiants d'API ([Premiers pas avec l'API OVHcloud](/guides/manage-and-operate/api/first-steps))
- **Pour la CLI OVHcloud :** la [CLI OVHcloud](https://github.com/ovh/ovhcloud-cli) installée et configurée avec vos identifiants
- **Pour l'API OpenStack :** un environnement OpenStack configuré ([Préparer l'environnement](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment))
- **Pour Terraform :** Terraform installé et le provider OVHcloud configuré ([Comment utiliser Terraform sur le Public Cloud OVHcloud](/guides/public-cloud/cross-functional/how-to-use-terraform))

## En pratique

### Modèles de Gateway

Avant de créer une Gateway, choisissez le modèle adapté à vos besoins en bande passante :

:::info
Veuillez noter qu'actuellement, la taille 2XL n'est pas disponible dans les régions de Mumbai, Singapour et Sydney.
:::

| Modèle | Bande passante |
|--------|----------------|
| S | jusqu'à 200 Mbps |
| M | jusqu'à 500 Mbps |
| L | jusqu'à 2 Gbps |
| XL | jusqu'à 4 Gbps |
| 2XL | jusqu'à 8 Gbps |

### Créer un réseau privé avec une Gateway

<Tabs>
  <Tab label="Espace client OVHcloud">
    **Étape 1 — Accéder à la création**

    Cliquez sur <code className="action">Gateway</code> dans le menu de gauche sous l'onglet **Network**.

    Vous devez avoir activé le vRack avant de poursuivre. Si vous n'en possédez pas, consultez la section « [activation du vRack](/guides/public-cloud/network-services/vrack#activation) » du guide correspondant.

    Cliquez ensuite sur le bouton <code className="action">Créer une Gateway</code>.

    <img className="thumbnail" alt="création de la gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/firstgatewaycreation.png" loading="lazy" />

    **Étape 2 — Sélectionner la région et la taille**

    Sélectionnez la région dans laquelle vous souhaitez déployer la Gateway. Choisissez de préférence la région où se trouvent vos instances privées.

    <img className="thumbnail" alt="sélection de la région" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/select_region.png" loading="lazy" />

    Sélectionnez ensuite la taille de votre Gateway (voir le tableau des modèles ci-dessus).

    <img className="thumbnail" alt="sélection d'une taille de gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/select_size.png" loading="lazy" />

    **Étape 3 — Nommer la Gateway et associer un réseau privé**

    Éditez le nom par défaut de votre Gateway et sélectionnez un réseau privé existant via la liste déroulante.

    :::info
    Seuls les réseaux privés à région unique sont pris en charge par Gateway.
    :::

    <img className="thumbnail" alt="menu déroulant" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/gatewayandprivatenetwork.png" loading="lazy" />

    Vous pouvez aussi cliquer sur <code className="action">Ajouter un réseau privé</code> pour créer un nouveau réseau privé à la volée.

    <img className="thumbnail" alt="créer un réseau privé" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/newprivatenetwork.png" loading="lazy" />

    Dans la fenêtre, attribuez un nom à votre réseau privé, sélectionnez un sous-réseau puis cliquez sur <code className="action">Ajouter</code>.

    <img className="thumbnail" alt="créer un réseau privé" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/createprivatenetwork.png" loading="lazy" />

    **Étape 4 — Confirmer la création**

    Cliquez sur <code className="action">Créer une Gateway</code> pour lancer le déploiement.

    <img className="thumbnail" alt="créer une gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/confirmcreation.png" loading="lazy" />

    La création peut prendre plusieurs minutes. Rafraîchissez la page si nécessaire.

    Une fois la création terminée, le réseau privé est visible dans la section <code className="action">Private Network</code> du menu **Network**.

    <img className="thumbnail" alt="nouveau réseau privé" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/createdprivatenetwork.png" loading="lazy" />

    La Gateway apparaît dans la section <code className="action">Gateway</code>.

    <img className="thumbnail" alt="nouveau gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/mynewgateway.png" loading="lazy" />
  </Tab>
  <Tab label="API OVHcloud">
    Ouvrez l'interface APIv6 OVHcloud. Si besoin, consultez le guide « [Premiers pas avec l'API OVHcloud](/guides/manage-and-operate/api/first-steps) ».

    **Récupérer l'identifiant du projet**

    Si l'identifiant du projet est inconnu, utilisez les appels suivants :

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project"} />

    :::info
    Cet appel récupère la liste des projets.
    :::

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}"} />

    :::info
    Cet appel identifie le projet via le champ `description`.
    :::

    **Créer le réseau privé avec une Gateway**

    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/gateway"} />

    Remplissez les champs selon le tableau suivant :

    | Champ | Description |
    |-------|-------------|
    | `serviceName` | L'identifiant de votre projet |
    | `regionName` | Par exemple : `GRA9` |
    | `model` | Taille de la Gateway (`s`, `m`, `l`, `xl`, `2xl`) |
    | `name` | Nom de votre Gateway (`null` pour le nom par défaut) |
    | `network.name` | Nom du réseau privé (`null` pour le nom par défaut) |
    | `network.cidr` | Bloc d'adresses IP du sous-réseau (ex : `192.168.1.0/24`) |
    | `network.enableDhcp` | Cochez pour activer le DHCP |
    | `network.ipVersion` | `4` (IPv6 non disponible) |
    | `network.vlanId` | Valeur entre 2 et 4000, ou vide pour une attribution automatique |

    :::info
    Répétez l'opération pour chaque région où vos instances privées sont présentes.
    :::

    Pour vérifier les détails de votre Gateway :

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/gateway"} />

    Laissez `subnetId` vide pour lister toutes les Gateways de la région spécifiée.
  </Tab>
  <Tab label="CLI OVHcloud">
    Utilisez la [CLI OVHcloud](https://github.com/ovh/ovhcloud-cli) pour créer un réseau privé avec une Gateway. Définissez votre projet cloud avec `--cloud-project <project_id>` ou configurez-le dans votre profil.

    **Créer une Gateway avec un nouveau réseau privé :**

    ```bash
    ovhcloud cloud network gateway create <region> \
      --cloud-project <project_id> \
      --name my-gateway \
      --model s \
      --network-name my-network \
      --subnet-cidr 192.168.1.0/24 \
      --subnet-enable-dhcp \
      --wait
    ```

    **Créer une Gateway dans un réseau privé existant :**

    ```bash
    ovhcloud cloud network gateway create <region> \
      --cloud-project <project_id> \
      --name my-gateway \
      --model s \
      --network-id <network_id> \
      --subnet-id <subnet_id> \
      --wait
    ```

    Modèles disponibles : `s`, `m`, `l`, `xl`, `2xl`.

    :::info
    Seuls les réseaux privés à région unique sont pris en charge par Gateway.
    :::
  </Tab>
  <Tab label="API OpenStack">
    Avant de poursuivre, consultez les guides suivants :

    - [Préparer l'environnement pour utiliser l'API OpenStack](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment)
    - [Définir les variables d'environnement OpenStack](/guides/public-cloud/cross-functional/compute-set-openstack-environment-variables)

    **Étape 1 — Créer un réseau et un sous-réseau**

    ```console
    openstack network create my_network

    openstack subnet create my_subnet --subnet-range <my_private_ip_range/mask> --network my_network --no-dhcp
    ```

    **Étape 2 — Lister les niveaux de qualité de service**

    ```console
    openstack network qos policy list
    +--------------------------------------+---------------+--------+---------+----------------------------------+
    | ID                                   | Name          | Shared | Default | Project                          |
    +--------------------------------------+---------------+--------+---------+----------------------------------+
    | a5524eb5-944e-4106-b209-9478bbdcedab | large_router  | True   | False   | XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX |
    | c210f5b2-db59-4973-a25f-9131195b6bcf | medium_router | True   | False   | XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX |
    | ec0ee74d-a1f3-43f6-87aa-b0e69ef8ce45 | small_router  | True   | False   | XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX |
    +--------------------------------------+---------------+--------+---------+----------------------------------+
    ```

    **Étape 3 — Créer le routeur et configurer la Gateway**

    ```console
    openstack router create my_router

    openstack router add subnet my_router my_subnet

    openstack router set --external-gateway Ext-Net --qos-policy QOS_ID_OF_YOUR_CHOICE my_router
    ```

    Si vous ne renseignez pas le paramètre `--qos-policy`, la qualité de service `small` est appliquée.
  </Tab>
  <Tab label="Terraform">
    Avant de commencer, consultez le guide : « [Comment utiliser Terraform sur le Public Cloud OVHcloud](/guides/public-cloud/cross-functional/how-to-use-terraform) »

    Créez un fichier Terraform (par exemple `private_network_gateway.tf`) avec le contenu suivant :

    ```hcl
    resource "ovh_cloud_project_network_private" "mypriv" {
      service_name = "<project_id>"
      vlan_id      = "0"
      name         = "mypriv"
      regions      = ["GRA9"]
    }

    resource "ovh_cloud_project_network_private_subnet" "myprivsub" {
      service_name = ovh_cloud_project_network_private.mypriv.service_name
      network_id   = ovh_cloud_project_network_private.mypriv.id
      region       = "GRA9"
      start        = "10.0.0.2"
      end          = "10.0.255.254"
      network      = "10.0.0.0/16"
      dhcp         = true
    }

    resource "ovh_cloud_project_gateway" "gateway" {
      service_name = ovh_cloud_project_network_private.mypriv.service_name
      name         = "my-gateway"
      model        = "s"
      region       = ovh_cloud_project_network_private_subnet.myprivsub.region
      network_id   = tolist(ovh_cloud_project_network_private.mypriv.regions_attributes[*].openstackid)[0]
      subnet_id    = ovh_cloud_project_network_private_subnet.myprivsub.id
    }
    ```

    Appliquez la configuration :

    ```console
    terraform apply
    ```
