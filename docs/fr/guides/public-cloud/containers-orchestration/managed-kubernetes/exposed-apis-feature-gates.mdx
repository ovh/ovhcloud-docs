## Configuration Kubernetes

### API

Admission plugins (les valeurs par défaut ne sont pas listées ici) :

* `AlwaysPullImages` : force chaque nouveau pod à récupérer les images requises à chaque fois. Dans un cluster multi-tenant, les utilisateurs ont ainsi l'assurance que leurs images privées ne peuvent être utilisées que par les personnes disposant des identifiants nécessaires pour les récupérer.
* `NodeRestriction` : garantit que le kubelet est limité aux objets Node et Pod qu'il est autorisé à modifier, tel que défini. Ces kubelets ne pourront modifier que leur propre objet NodeAPI et les objets PodAPI liés à leur nœud.

Modes d'autorisation :

* [Node](https://kubernetes.io/docs/reference/access-authn-authz/node/) : autorise les requêtes API effectuées par les Kubelets.
* [RBAC](https://kubernetes.io/docs/reference/access-authn-authz/rbac/) : le contrôle d'accès basé sur les rôles est une méthode de régulation de l'accès aux ressources informatiques ou réseau en fonction des rôles des différents utilisateurs au sein d'une organisation.

Feature gates :

* `TTLAfterFinished` : permet à un contrôleur TTL de nettoyer les ressources une fois leur exécution terminée.

### Kubelet

* `protect-kernel-defaults` : empêche les paramètres kernel ajustés de remplacer les valeurs par défaut des paramètres kernel du kubelet.
