## Objectif

[JFrog Artifactory](https://jfrog.com/fr/artifactory/) est l'une des principales solutions de gestion des dépendances et des binaires empaquetés. Tous ces objets sont appelés _artefacts_.

## Prérequis

- Un cluster OVHcloud Managed Kubernetes.
- Le client Helm installé et configuré. Pour plus d'informations, suivez ce tutoriel OVHcloud : [Installer Helm sur OVHcloud Managed Kubernetes](/guides/public-cloud/containers-orchestration/managed-kubernetes/install-helm).
- Le client `kubectl` installé et configuré. Pour plus d'informations, suivez ce tutoriel OVHcloud : [Configurer kubectl sur un cluster OVHcloud Managed Kubernetes](/guides/public-cloud/containers-orchestration/managed-kubernetes/configure-kubectl).

## En pratique

:::info
Vous trouverez des étapes plus détaillées sur les différentes méthodes d'installation de JFrog Artifactory dans la [documentation officielle](https://www.jfrog.com/confluence/display/JFROG/Installing+Artifactory#InstallingArtifactory-HelmInstallation).

Ce tutoriel explique comment réaliser une installation à nœud unique. Pour une installation plus avancée (comme la HA), consultez la [documentation officielle](https://www.jfrog.com/confluence/display/JFROG/Installing+Artifactory#InstallingArtifactory-HAInstallation).
:::


### Configurer Helm pour utiliser le chart Helm JFrog

Dans un terminal, ajoutez le repository Helm de JFrog à votre installation Helm :

```bash
$ helm repo add jfrog https://charts.jfrog.io
$ helm repo update
```

Le résultat obtenu devrait ressembler à ceci :

```console
$ helm repo add jfrog https://charts.jfrog.io
"jfrog" has been added to your repositories

$ helm repo update
Hang tight while we grab the latest from your chart repositories...
...Successfully got an update from the "apache-airflow" chart repository
...Successfully got an update from the "ingress-nginx" chart repository
...Successfully got an update from the "jfrog" chart repository
Update Complete. ⎈Happy Helming!⎈
```

### Configurer la master key et la join key

À ce stade, il est fortement recommandé de configurer votre master key et votre join key. Pour en savoir plus sur ces clés, consultez la [documentation officielle](https://www.jfrog.com/confluence/display/JFROG/Managing+Keys).

Dans un terminal, configurez la master key comme suit :

```bash
$ export MASTER_KEY=$(openssl rand -hex 32)

$ echo ${MASTER_KEY}
```

Le résultat obtenu devrait ressembler à ceci :

```console
$ export MASTER_KEY=$(openssl rand -hex 32)
WARNING: can't open config file: /usr/local/etc/openssl/openssl.cnf

$ echo ${MASTER_KEY}
xxxxxxxxfffffffffffffxxxxxxxxxxxxxxxxxxxxxgggggggggggggxxxxxxxxxx
```

Ensuite, configurez la join key comme suit :

```bash
$ export JOIN_KEY=$(openssl rand -hex 32)

$ echo ${JOIN_KEY}
```

Le résultat obtenu devrait ressembler à ceci :

```console
$ export JOIN_KEY=$(openssl rand -hex 32)
WARNING: can't open config file: /usr/local/etc/openssl/openssl.cnf

$ echo ${JOIN_KEY}
xxxxxxxxyyyyyyyyyyyyyxxxxxxxxxxxxxxxxxxxxxyyyyyyyyyyyyxxxxxxxxxx
```

> Les deux messages d'avertissement ne sont pas importants et n'ont aucun impact.

### Installer JFrog Artifactory avec Helm

Commencez par créer le namespace `artifactory` :

```bash
$ kubectl create ns artifactory
```

Vous pouvez ensuite installer JFrog Artifactory à l'aide de la commande Helm suivante :

```bash
$ helm upgrade --install artifactory \
--set artifactory.masterKey=${MASTER_KEY} \
--set artifactory.joinKey=${JOIN_KEY} \
--namespace artifactory jfrog/artifactory
```

Le résultat obtenu devrait ressembler à ceci :

```console
$ helm upgrade --install artifactory \
--set artifactory.masterKey=${MASTER_KEY} \
--set artifactory.joinKey=${JOIN_KEY} \
--namespace artifactory jfrog/artifactory

Release "artifactory" does not exist. Installing it now.
NAME: artifactory
LAST DEPLOYED: Wed Oct 12 10:41:49 2022
NAMESPACE: artifactory
STATUS: deployed
REVISION: 1
TEST SUITE: None
NOTES:
Congratulations. You have just deployed JFrog Artifactory!

1. Get the Artifactory URL by running these commands:

   NOTE: It may take a few minutes for the LoadBalancer IP to be available.
         You can watch the status of the service by running 'kubectl get svc --namespace artifactory -w artifactory-artifactory-nginx'
   export SERVICE_IP=$(kubectl get svc --namespace artifactory artifactory-artifactory-nginx -o jsonpath='{.status.loadBalancer.ingress[0].ip}')
   echo http://$SERVICE_IP/

2. Open Artifactory in your browser
   Default credential for Artifactory:
   user: admin
   password: password
```

Ensuite, attendez que tous les Pods soient à l'état `Running` et *prêts* (c'est-à-dire que le nombre de Pods souhaité corresponde au nombre réel dans la colonne `Ready`) :

```bash
$ kubectl get pods -n artifactory -w
```

Le résultat obtenu devrait ressembler à ceci :

```console
$ kubectl get pods -n artifactory -w
NAME                                             READY   STATUS    RESTARTS   AGE
artifactory-0                                    1/1     Running   0          8m11s
artifactory-artifactory-nginx-7c556cb56b-x5wvm   1/1     Running   0          8m11s
artifactory-postgresql-0                         1/1     Running   0          8m11s
```

### Tester le JFrog Artifactory nouvellement installé

Récupérez l'URL de la console d'administration :

```
export SERVICE_IP=$(kubectl get svc --namespace artifactory artifactory-artifactory-nginx -o jsonpath='{.status.loadBalancer.ingress[0].ip}')
echo http://$SERVICE_IP/
```

Ouvrez l'URL du service dans un navigateur et saisissez les identifiants par défaut : `admin` pour *Username* et `password` pour *Password* :

<img className="thumbnail" alt="Page de connexion d'Artifactory" src="/images/public-cloud/containers-orchestration/managed-kubernetes/installing-artifactory/artifactory-login-page.png" loading="lazy" />

:::info
N'oubliez pas de changer le mot de passe par défaut !
:::


Vous pouvez maintenant commencer à utiliser votre instance JFrog Artifactory :

<img className="thumbnail" alt="Page d'accueil d'Artifactory" src="/images/public-cloud/containers-orchestration/managed-kubernetes/installing-artifactory/artifactory-welcome-page.png" loading="lazy" />

Une fois les étapes de configuration terminées (consultez la [documentation officielle](https://www.jfrog.com/confluence/display/JFROG/Repository+Management)), votre JFrog Artifactory est prêt à l'emploi :

<img className="thumbnail" alt="Repositories Maven d'Artifactory" src="/images/public-cloud/containers-orchestration/managed-kubernetes/installing-artifactory/artifactory-maven-repositories.png" loading="lazy" />

### Désinstaller JFrog Artifactory

Comme pour les autres étapes, la désinstallation s'effectue avec une commande Helm :

```bash
$ helm uninstall artifactory -n artifactory
```

Le résultat obtenu devrait ressembler à ceci :

```console
$ helm uninstall artifactory -n artifactory
release "artifactory" uninstalled
```

Supprimez ensuite le namespace `artifactory` :

```bash
$ kubectl delete ns artifactory
```
