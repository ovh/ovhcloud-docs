## Objectif

Suivez ce guide de démarrage rapide pour déployer une application *Hello World* conteneurisée sur votre cluster OVHcloud Managed Kubernetes Service, en utilisant l'espace client OVHcloud et l'API OVHcloud.

Dans ce guide, nous allons vous accompagner dans le déploiement d'une application Hello World sur votre OVHcloud Managed Kubernetes Service. Vous pouvez gérer votre cluster via l'<ManagerLink to="/">espace client OVHcloud</ManagerLink> ou l'<ApiLink>API OVHcloud</ApiLink>.

## Prérequis

- Vous devez déjà avoir créé un cluster sur le service OVHcloud Managed Kubernetes.
- Vous aurez également besoin de l'outil en ligne de commande [kubectl](https://kubernetes.io/docs/reference/kubectl/overview/). Vous trouverez les [instructions d'installation détaillées](https://kubernetes.io/docs/tasks/tools/install-kubectl/) de cet outil sur le site officiel de Kubernetes.

## En pratique

### Récupérer les informations de votre cluster

<Tabs>
  <Tab label="Via l'espace client OVHcloud">
    Accédez à l'interface d'administration de vos clusters OVHcloud Managed Kubernetes en cliquant sur <code className="action">Managed Kubernetes Service</code> dans le menu de gauche.
    
    <img className="thumbnail" alt="Sélectionnez votre cluster" src="/images/public-cloud/containers-orchestration/managed-kubernetes/deploying-hello-world/select-cluster.png" loading="lazy" />

Cliquez sur votre cluster pour accéder à ses informations.
    
    <img className="thumbnail" alt="Vue du cluster OVHcloud Managed Kubernetes" src="/images/public-cloud/containers-orchestration/managed-kubernetes/deploying-hello-world/cluster-infos.png" loading="lazy" />

Dans cette interface d'administration, plusieurs onglets sont disponibles :
    
    - **Service :** une vue globale de votre cluster, avec des informations importantes comme le statut, l'URL de l'API et le fichier de configuration `kubectl`.
    
    - **Pools de nœuds :** les pools de nœuds de votre cluster, avec les options pour les ajouter, les configurer ou les supprimer.
    
    - **Accès APIServer :** la possibilité de configurer l'accès à l'API-server.
    
    - **Logs d'Audit :** les logs du control plane de votre cluster Kubernetes.
  </Tab>
  <Tab label="Via l'API OVHcloud">
    #### Lister vos clusters OVHcloud Managed Kubernetes
    
    Le endpoint d'API `GET /cloud/project/{serviceName}/kube` liste tous les clusters Kubernetes disponibles :
    
    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/kube"} />

**Résultat :**
    
    ```json
    [
      "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
    ]
    ```
    
    En l'appelant, vous pouvez afficher une liste de valeurs. Notez l'ID du cluster que vous souhaitez utiliser. Dans cet exemple, nous y ferons référence sous le nom `kubeId`.
    
    #### Récupérer les informations
    
    Le endpoint d'API `GET /cloud/project/{serviceName}/kube/{kubeId}` fournit des informations importantes sur votre cluster Managed Kubernetes, notamment sa région, son statut et son URL.
    
    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/kube/\\{kubeId\\}"} />

**Résultat :**
    
    ```json
    {
      "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
      "region": "GRA5",
    ```

### Configurer les paramètres par défaut de la CLI kubectl

Consultez la documentation [Configurer kubectl sur un cluster OVHcloud Managed Kubernetes](/guides/public-cloud/containers-orchestration/managed-kubernetes/configure-kubectl) pour cette partie du processus.

### Ajouter un pool de nœuds

<Tabs>
  <Tab label="Via l'espace client OVHcloud">
    Dans l'onglet <code className="action">Pools de nœuds</code> de l'interface d'administration, cliquez sur le bouton <code className="action">Ajouter un pool de nœuds</code>.
    
    Saisissez un nom pour le pool de nœuds :
    
    <img className="thumbnail" alt="Ajouter un pool de nœuds - Définir un nom" src="/images/public-cloud/containers-orchestration/managed-kubernetes/deploying-hello-world/add-node-pool1.png" loading="lazy" />
    
    :::info
    Seuls les caractères alphanumériques et le « - » sont autorisés pour le nom du pool de nœuds. Vous ne pouvez pas utiliser de caractères comme « _ », « . » ou « / » comme séparateur dans le nom d'un pool de nœuds.

    :::

    
    Choisissez une flavor (type de machine) pour votre pool de nœuds, B2-7 par exemple :
    
    <img className="thumbnail" alt="Ajouter un pool de nœuds - Choisir une flavor" src="/images/public-cloud/containers-orchestration/managed-kubernetes/deploying-hello-world/add-node-pool2.png" loading="lazy" />

Configurez le nombre de nœuds que vous souhaitez ajouter à votre pool de nœuds, 3 par exemple, avec l'autoscaling désactivé.
    
    <img className="thumbnail" alt="Ajouter un pool de nœuds - Définir le nombre de nœuds" src="/images/public-cloud/containers-orchestration/managed-kubernetes/deploying-hello-world/add-node-pool3.png" loading="lazy" />

Définissez le mode de facturation : mensuel ou horaire.
    
    <img className="thumbnail" alt="Ajouter un pool de nœuds - Choisir une flavor" src="/images/public-cloud/containers-orchestration/managed-kubernetes/deploying-hello-world/add-node-pool4.png" loading="lazy" />
  </Tab>
  <Tab label="Via l'API OVHcloud">
    Le premier élément nécessaire pour déployer l'application *Hello World* est un pool de nœuds dans votre cluster. Pour le créer, vous pouvez utiliser l'endpoint `POST /cloud/project/{serviceName}/kube/{kubeId}/nodepool`, qui déploiera un pool de nœuds pour votre cluster sur le Public Cloud.
    
    Vous devrez fournir plusieurs informations, mais seul le paramètre `flavorName` (la flavor de l'instance que vous souhaitez créer) est obligatoire. Si vous ne renseignez pas de valeur pour le paramètre `desiredNodes`, la valeur par défaut sera 1 ; vous créerez donc un nouveau pool de nœuds avec un seul nœud.
    Pour ce tutoriel, nous choisissons un nœud à usage général, comme la flavor `b2-7`.
    
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/kube/\\{kubeId\\}/nodepool"} />

**Résultat :**

### Vérifier que votre pool de nœuds est prêt

<Tabs>
  <Tab label="Via l'espace client OVHcloud">
    Dans l'onglet *Computer Nodes*, vous pouvez inspecter l'état de vos pools de nœuds. Le pool de nœuds que vous venez de créer devrait maintenant être à l'état *Installing*. L'installation du pool de nœuds peut prendre une minute ; n'hésitez pas à faire une courte pause, puis à réessayer jusqu'à ce qu'il soit prêt.
    
    <img className="thumbnail" alt="Vérifiez que votre nœud est prêt" src="/images/public-cloud/containers-orchestration/managed-kubernetes/deploying-hello-world/node-pool-status.png" loading="lazy" />

Après sa création, cliquez sur le pool de nœuds afin d'afficher le détail de ses nœuds.
    
    <img className="thumbnail" alt="Détails du pool de nœuds" src="/images/public-cloud/containers-orchestration/managed-kubernetes/deploying-hello-world/node-pool.png" loading="lazy" />
  </Tab>
