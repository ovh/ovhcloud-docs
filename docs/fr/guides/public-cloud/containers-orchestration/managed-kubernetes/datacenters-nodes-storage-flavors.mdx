## Datacenters, worker nodes et flavors de stockage persistant disponibles

### Régions / datacenters disponibles

Managed Kubernetes Service déploie un Kubernetes Master au sein d'un datacenter OVHcloud donné.
Tous ses worker nodes et volumes persistants sont ensuite déployés par le cloud controller dans la même région.

Le service est actuellement disponible dans toutes les zones géographiques OVHcloud Public Cloud.
Notez que les projets utilisant des régions plus anciennes (comme SBG1 ou GRA1 par exemple) seront invités à activer de façon transparente les dernières régions de cette zone afin de bénéficier de Managed Kubernetes Service.

Les clients OVHcloud US peuvent également déployer le service dans nos datacenters américains Est et Ouest.

### Classes de stockage persistant disponibles

Lors de l'ajout d'un volume persistant via l'API Kubernetes (ou `kubectl`), celui-ci est en réalité déployé à l'aide de disques additionnels Public Cloud (Cinder Volumes). Nous prenons en charge les classes de stockage suivantes :

* `csi-cinder-high-speed-gen2` : cette classe de stockage repose sur du matériel incluant des disques SSD avec interfaces NVMe. L'allocation de performance est progressive et linéaire (30 IOPS alloués par Go et 0,5 Mo/s alloué par Go) avec un maximum de 20 000 IOPS et 1 Go/s par volume. Les performances en IOPS et en bande passante augmentent à mesure que vous augmentez l'espace de stockage.
* `csi-cinder-high-speed` : la performance est fixe. Vous obtenez jusqu'à 3 000 IOPS par volume, quelle que soit la taille du volume.
* `csi-cinder-classic` : utilise des disques mécaniques traditionnels (200 IOPS garantis, jusqu'à 64 Mo/s par volume).

Toutes ces `Storage Classes` sont basées sur Cinder, le service de stockage bloc d'OpenStack. La différence entre elles réside dans le type de support physique de stockage associé. Elles sont distribuées de façon transparente, sur trois réplicas physiques locaux.

Les performances High Speed sont théoriquement optimales pour des volumes allant jusqu'à 100 Go. Au-delà de 100 Go par volume, vous obtenez des performances renforcées avec un volume High Speed Gen2.
Ceci est détaillé dans le guide [Volumes persistants](/guides/public-cloud/containers-orchestration/managed-kubernetes/set-up-persistent-volume).

#### Classes de stockage chiffrées LUKS

OVHcloud Managed Kubernetes prend également en charge les volumes de stockage bloc chiffrés LUKS à l'aide d'OVHcloud Managed Keys (OMK). Les classes de stockage chiffrées suivantes sont disponibles dans les régions prises en charge :

* `csi-cinder-high-speed-gen2-luks` : version chiffrée de High Speed Gen2 (performance progressive, SSD NVMe)
* `csi-cinder-high-speed-luks` : version chiffrée de High Speed (3 000 IOPS fixes)
* `csi-cinder-classic-luks` : version chiffrée de Classic (disques mécaniques, 200 IOPS)

:::info
**Disponibilité régionale**

Le stockage chiffré LUKS est actuellement disponible dans les régions OVHcloud Public Cloud suivantes :

- **France** : RBX, SBG, GRA (GRA5, GRA7, GRA9, GRA11), EU-WEST-PAR
- **Allemagne** : DE1
- **Italie** : EU-SOUTH-MIL
- **Canada** : BHS5
- **États-Unis** : US-WEST-OR-1, US-EAST-VA-1

Des régions supplémentaires seront prises en charge dans les mois à venir.

Si votre cluster est déployé dans une région prise en charge mais que les classes de stockage chiffrées ne sont pas encore visibles, elles seront automatiquement déployées lors de la mise à jour de votre cluster.
:::
