## Objectif

Ce guide a pour objectif de fournir une méthode claire et détaillée pour la création et la mise à jour des Savings Plans pour vos ressources. Vous découvrirez comment gérer vos Savings Plans en utilisant la console OVHcloud, l'API OVHcloud, ainsi que Terraform. En suivant ce guide, vous serez en mesure de :

- Créer un Savings Plan pour vos ressources.
- Modifier un Savings Plan.
- Automatiser la gestion des Savings Plans via l'API OVHcloud ou Terraform pour une plus grande efficacité et flexibilité.

## Prérequis

- Un [projet Public Cloud OVHcloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud.
- Avoir accès à l'<ApiLink>API OVHcloud</ApiLink> (créez vos identifiants en consultant [ce guide](/guides/manage-and-operate/api/first-steps)).
- Être familier de l'utilisation de [Terraform](/guides/public-cloud/cross-functional/how-to-use-terraform) si vous souhaitez l'utiliser.
- Connaitre les principes d'un [Savings Plan](/links/public-cloud/savings-plan)

## En pratique

{/* CP-STEPS-START:savings-plans-navigation */}
Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">Centre de coûts</code>, puis sur l'onglet <code className="action">Savings Plan</code>. Vos Savings Plans sont listés dans le tableau **Mes Savings Plans**.
{/* CP-STEPS-END:savings-plans-navigation */}

### Créer un Savings plan

{/* CP-STEPS-START:create-savings-plan */}
Vous pouvez créer votre Savings Plan pour le type de ressource voulue en suivant ces étapes :

<Tabs>
  <Tab label="Via la console OVHcloud">
    1. Cliquez sur <code className="action">Créer un Savings Plan</code>.
    2. Dans la section **Saisissez un nom**, donnez un nom à votre Savings Plan.
    3. Dans la section **Sélectionnez une date**, choisissez la date de début du plan.
    4. Dans la section **Sélectionnez un service**, sélectionnez le type de ressource auquel le Savings Plan s'appliquera : **Instance** ou **Managed Rancher Service**.
    5. Pour les instances, choisissez le mode de déploiement (région 1-AZ ou 3-AZ) dans la section **Choisissez un mode de déploiement**.
    6. Dans la section **Choisissez une ressource engagée**, définissez le modèle de ressource et indiquez le nombre de ressources concernées par ce plan.
    7. Dans la section **Sélectionnez la durée d'engagement**, choisissez la durée de votre Savings Plan parmi les durées disponibles.
    8. Lisez attentivement les conditions générales, puis cochez la case **J'ai pris connaissance et j'accepte les termes des contrats suivants :** pour confirmer que vous les acceptez.
    9. Une fois tous les paramètres configurés, cliquez sur <code className="action">Créer un Savings Plan</code> pour finaliser la création.
  </Tab>
  <Tab label="Via Terraform">
    Pour créer un Savings plan, vous aurez besoin de 5 éléments minimum :
    
    - L'ID de votre projet Public Cloud
    - La flavor concernée par votre Savings Plan
    - La durée de votre Savings Plan (au format standard ISO 8601)
    - Le nombre de ressources concernées
    - Le nom de votre Savings Plan
    
    Dans notre exemple, nous allons créer un Savings Plan pour 10 instances de type **b3-8**, pour une durée de 1 mois. Ajoutez les lignes suivantes à un fichier nommé *savings_plan.tf* :
    
    ```python
    # création d'un Savings Plan
    resource "ovh_savings_plan" "Savings_plan_simple_b3_8" {
      service_name = "<public cloud project ID>"
      flavor = "b3-8" # type de l'instance ou rancher/rancher_standard ou rancher_ovhcloud_edition
      period = "P1M" # P obligatoire, chiffre pour la durée et M pour "mois", Y pour "year" ..
      size = 10
      display_name = "Savings_plan_simple_b3_8"
      auto_renewal = true # facultatif, "true" pour activer.
    }
    ```
    
    Vous pouvez créer votre Savings Plan en entrant la commande suivante dans votre console :
    
    ```console
    terraform apply
    ```
  </Tab>
</Tabs>

{/* CP-STEPS-END:create-savings-plan */}

### Modifier un Savings plan

{/* CP-STEPS-START:modify-savings-plan */}
<Tabs>
  <Tab label="Via la console OVHcloud">
    :::info
    Via la console OVHcloud, vous pouvez modifier le **nom** du Savings Plan et **activer/désactiver** son renouvellement automatique. Un plan qui n'a pas encore démarré peut aussi être annulé.
    :::

    Dans le tableau **Mes Savings Plans**, cliquez sur le bouton <code className="action">Actions</code> de la ligne de votre Savings Plan.

    Pour changer le nom, cliquez sur <code className="action">Modifier le nom</code>, modifiez le nom dans le champ **Nom**, puis cliquez sur <code className="action">Enregistrer</code>.

    Pour activer/désactiver le renouvellement automatique de votre Savings Plan, cliquez sur <code className="action">Modifier le renouvellement</code>. La fenêtre **Modifier le renouvellement** indique si le renouvellement automatique sera activé ou désactivé : cliquez sur <code className="action">Confirmer</code>.

    Si votre Savings Plan n'a pas encore démarré, vous pouvez l'annuler : cliquez sur <code className="action">Annuler</code> dans le menu <code className="action">Actions</code>, puis confirmez dans la fenêtre **Annuler le Savings Plan**.
  </Tab>
  <Tab label="Via l'API OVHcloud">
    Retrouvez d'abord l'id de votre service dans la liste de vos service qui s'obtient via l'appel suivant :
    
    <Api version="v1" section="/services" method="GET" route={"/services"} />
    
    Vous devez inscrire en paramètre, dans le champ **resourceName**, l'id de votre projet Public Cloud.
    
    Vous obtenez une liste contenant l'id de vos services comme suit :
    
    <img className="thumbnail" alt="Savings Plan services list" src="/images/public-cloud/cross-functional/how-to-manage-savings-plan/savings_plan_list_service.png" loading="lazy" />
    
    Vous pouvez vérifier si le service correspond au projet Public Cloud concerné via cette appel :
    
    <Api version="v1" section="/services" method="GET" route={"/services/\\{serviceId\\}"} />
    Le **serviceId** correspond à l'id récupéré via l'appel API précédent.
    
    Vous obtenez une liste contenant les détails de votre service comme ci-dessous. Vérifiez qu'il s'agit bien du bon projet grâce au champ `vars.value` :
    
    <img className="thumbnail" alt="Savings Plan details service list" src="/images/public-cloud/cross-functional/how-to-manage-savings-plan/savings_plan_list_service_details.png" loading="lazy" />
    
    Vous pouvez retrouver l'ID de votre Savings Plan dans la liste de vos Savings Plans qui s'obtient via l'appel suivant :
    
    <Api version="v1" section="/services" method="GET" route={"/services/\\{serviceId\\}/savingsPlans/subscribed"} />
    Le **serviceId** correspondant à l'id récupéré précédemment.
    
    Vous obtenez une liste de Savings Plans comme suit :
    
    <img className="thumbnail" alt="Savings Plan list" src="/images/public-cloud/cross-functional/how-to-manage-savings-plan/savings_plan_list_svp.png" loading="lazy" />
    
    Cherchez ensuite le Savings Plan concerné dans la liste et copiez le champ **id**.
    
    <details>
    <summary>Modifier le nom d'un Savings Plan</summary>

    Pour modifier le nom d'un Savings plan, utilisez l'appel API suivant :
    
    <Api version="v1" section="/services" method="PUT" route={"/services/\\{serviceId\\}/savingsPlans/subscribed/\\{savingsPlanId\\}"} />
    
    Le **savingsPlanId** correspondant à l'id de votre Savings Plan copié précédemment.

    </details>
    
    <details>
    <summary>Activer/désactiver le renouvellement automatique d'un Savings Plan</summary>

    Pour **activer/désactiver** le renouvellement automatique du Savings Plan, utilisez l'appel API suivant :
    
    <Api version="v1" section="/services" method="POST" route={"/services/\\{serviceId\\}/savingsPlans/subscribed/\\{savingsPlanId\\}/changePeriodEndAction"} />

    </details>
    
    <details>
    <summary>Augmenter le nombre de ressources d'un Savings Plan</summary>

    Pour augmenter le nombre de ressources souscrites par votre Savings Plan, utilisez cet appel API :
    
    :::info
    Le nombre de ressources peut uniquement être augmenté.
    :::
    
    <Api version="v1" section="/services" method="POST" route={"/services/\\{serviceId\\}/savingsPlans/subscribed/\\{savingsPlanId\\}/changeSize"} />

    </details>
  </Tab>
  <Tab label="Via Terraform">
    Modifiez votre ressource dans le fichier Terraform *savings_plan.tf* précédemment créé.
    
    :::info
    A noter que seuls les champs **service_name**, **size** et **auto_renewal** sont modifiables. La valeur de **size** peut uniquement être augmentée.
    :::
  </Tab>
</Tabs>
