## Objectif

En fonction de votre cas d'utilisation, vous pouvez être amené à devoir donner accès à votre projet à d'autres utilisateurs, sans pour autant leur donner un accès total à vos services.<br/>
Dans cet objectif, vous pouvez déléguer à d'autres comptes client OVHcloud des droits en lecture seule ou en lecture / écriture sur vos projets.

**Ce guide vous détaille comment déléguer des droits d'accès à un projet Public Cloud depuis la console OVHcloud.**

## Prérequis

- Avoir une instance [Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud.

[[cpnav:publiccloud-contacts-rights]]

## En pratique

{/* CP-STEPS-START:contacts-rights */}
Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">Gestion du projet</code>, puis sur l'onglet <code className="action">Contacts et droits</code>.

Cet onglet affiche le contact administrateur et le contact facturation de votre projet. Pour les modifier, cliquez sur <code className="action">Éditer</code> à côté du contact : la page de gestion de vos contacts s'ouvre dans un nouvel onglet. Suivez les instructions décrites dans notre guide « [Changer les contacts d’un projet](/guides/public-cloud/compute/change-project-contacts) » afin de finaliser cette manipulation.

:::info
Les liens <code className="action">Éditer</code> ne sont disponibles que pour les comptes de la zone UE, et pas pour un projet en mode découverte.
:::
{/* CP-STEPS-END:contacts-rights */}

### Ajouter des contacts et des droits

{/* CP-STEPS-START:add-contacts-permissions */}
Seul le contact administrateur du projet peut ajouter des contacts. Dans un projet en mode découverte, aucun contact ne peut être ajouté.

1. Cliquez sur <code className="action">Créer un contact</code>.
2. Dans la fenêtre **Créer un contact**, renseignez l'identifiant de l'utilisateur (sous la forme xx00000-ovh) dans le champ **Identifiant client (NIC handle)**.
3. Dans la liste **Permissions**, sélectionnez `Lecture seule` ou `Lecture/Écriture`.
4. Cliquez sur <code className="action">Ajouter</code> pour valider la délégation d'accès.

:::info
Notez que les droits de `lecture/écriture` autorisent des modifications sur le projet qui pourraient avoir une incidence sur la facturation future.
:::

Un e-mail de confirmation vous sera alors envoyé ainsi qu'au nouvel utilisateur qui pourra maintenant ouvrir le projet dans l'univers Public Cloud de sa console OVHcloud.

Les comptes clients OVHcloud ajoutés ainsi que leurs droits respectifs sont listés dans le tableau, dans les colonnes **Identifiant client (NIC handle)** et **Permissions**.

Pour révoquer un accès, cliquez sur l'icône <code className="action">Supprimer le contact</code> dans la colonne **Actions** de la ligne du compte, puis sur <code className="action">Supprimer</code> dans la fenêtre **Supprimer ce contact ?**.
{/* CP-STEPS-END:add-contacts-permissions */}
