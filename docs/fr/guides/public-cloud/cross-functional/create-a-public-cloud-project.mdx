## Objectif

La création d’un projet est la première étape indispensable pour déployer des [instances Public Cloud](/links/public-cloud/public-cloud).

**Ce guide vous guidera à travers les étapes de création de votre premier projet Public Cloud.**

## En pratique

### Création du projet

{/* CP-STEPS-START:project-creation */}
Les premières étapes dépendent du fait que vous ayez déjà ou non un projet Public Cloud :

- **Il s'agit de votre premier projet Public Cloud :** la console OVHcloud ouvre la page **Bienvenue dans l'écosystème Public Cloud**. Après en avoir pris connaissance, validez les termes des contrats en cochant la case correspondante dans la section **Contrats**, puis cliquez sur <code className="action">Découvrir l’univers Public Cloud</code>. Votre projet est créé en [mode découverte](#discovery).
- **Vous avez déjà un projet Public Cloud :** sur la page **Projets**, cliquez sur <code className="action">Créer un nouveau projet</code>. Vous pouvez aussi cliquer sur le sélecteur <code className="action">Projet</code> en haut du menu de gauche, puis sur <code className="action">Créer un projet</code>. Sur la page **Créer un projet Public Cloud** :
    1. Dans le champ **Nom du projet**, renseignez un nom pour votre projet.
    2. Après en avoir pris connaissance, validez les termes des contrats en cochant la case correspondante dans la section **Contrats**.
    3. Dans la section **Choisissez un moyen de paiement**, sélectionnez votre moyen de paiement. Si vous disposez d'un bon d'achat, renseignez-le dans la section **Vous avez un code promo ?** et cliquez sur <code className="action">Ajouter</code>.
    4. Cliquez sur <code className="action">Créer mon projet</code>.

Le mode découverte n'est pas proposé à certains comptes : leur premier projet est lui aussi créé depuis la page **Créer un projet Public Cloud**.

Une fois le processus de création terminé, votre nouveau projet Public Cloud s'affiche dans le sélecteur **Projet** en haut du menu de gauche de l'univers Public Cloud.

Vous avez dorénavant accès à tout l'écosystème Public Cloud OVHcloud, découvrez cette nouvelle interface en parcourant notre guide « [Se familiariser avec l'interface Public Cloud](/guides/public-cloud/cross-functional/public-cloud-interface-walk-me) ».
{/* CP-STEPS-END:project-creation */}

<a name="discovery"></a>

{/* CP-STEPS-START:discovery-mode */}
:::info
**Mode Découverte**

Votre premier projet Public Cloud est créé en `Mode découverte`. Cela signifie que vous pouvez parcourir et découvrir les produits Public Cloud mais que vous ne pouvez pas encore créer de ressources telles que des instances. Tant que ce projet est en mode découverte, vous ne pouvez pas non plus créer d'autre projet : la console OVHcloud vous demande d'abord de l'activer.

Pour exploiter pleinement le potentiel du Public Cloud et démarrer vos premières ressources, activez votre projet :

1. Sur la page d'accueil de votre projet, le bandeau **Démarrez le déploiement de vos ressources Cloud.** vous rappelle que vous êtes en mode découverte. Cliquez sur <code className="action">Activer</code> dans ce bandeau.
2. Dans la fenêtre qui s'ouvre, cliquez sur <code className="action">Activer votre projet</code>.
3. Sur la page **Activer votre projet**, validez un moyen de paiement, puis cliquez sur <code className="action">Activer votre projet</code>.
:::
{/* CP-STEPS-END:discovery-mode */}

### Activation du projet et essai gratuit

{/* CP-STEPS-START:project-activation */}
Lorsque vous activez un projet depuis le `Mode découverte` et enregistrez un moyen de paiement, un **crédit d'essai de 200 €** est appliqué si vous êtes éligible. Dans ce cas, le bandeau de la page d'accueil de votre projet et la page **Activer votre projet** affichent le montant de l'offre.
{/* CP-STEPS-END:project-activation */}

:::info
**Conditions de l'essai gratuit**

- Le crédit est activé au moment de l'activation du projet et est valable **un mois**.
- **Éligible :** tout client OVHcloud créant son premier projet Public Cloud, même s'il dispose déjà d'un compte OVHcloud.
- **Non éligible :** les clients disposant déjà ou ayant déjà disposé d'un projet Public Cloud, ou ayant déjà bénéficié d'un crédit d'essai gratuit.

En savoir plus sur la page [Essai gratuit Public Cloud OVHcloud](/links/public-cloud/free-trial).
:::

:::info
**Créer des projets supplémentaires avec Terraform**

Une fois votre premier projet Public Cloud créé et un moyen de paiement validé, vous pouvez créer d'autres projets par programmation à l'aide de la ressource Terraform `ovh_cloud_project`. Pour plus de détails, consultez le guide « [Comment utiliser Terraform sur le Public Cloud OVHcloud](/guides/public-cloud/cross-functional/how-to-use-terraform#création-dun-projet-public-cloud) ».

OVHcloud ne propose actuellement pas d'endpoint API ni de commande CLI dédiés à la création de projet.
:::
