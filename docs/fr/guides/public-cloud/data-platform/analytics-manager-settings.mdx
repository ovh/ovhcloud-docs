## Objectif

L'onglet des paramètres vous permet de gérer les [dépôts](/guides/public-cloud/data-platform/analytics-manager-settings#dépôts) et le [cache](/guides/public-cloud/data-platform/analytics-manager-settings#vider-le-cache) de votre Analytics Manager.

<img className="thumbnail" alt="settings1" src="/images/public-cloud/data-platform/product/am/picts/settings1.png" loading="lazy" />

## Dépôts

Le panneau *Dépôts* offre une vue d'ensemble de chacun de vos dépôts de requêtes, permettant non seulement un aperçu rapide de chacun d'entre eux, mais aussi les moyens d'éditer chaque dépôt, comme changer le compte Git lié *(bientôt disponible !)*.

## Vider le cache

L'Analytics Manager dispose d'un cache sur les requêtes exécutées.

Le bouton *vider le cache* vous offre la simplicité de vous débarrasser de la mémoire bloquée inutilement à cause de divers résultats de requêtes ou de métadonnées de cache et vous permet de travailler avec une vitesse et des performances améliorées.
