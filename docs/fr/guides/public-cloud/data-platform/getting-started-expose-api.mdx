## Objectif

Une API est indispensable, car elle constitue l'interface entre le monde extérieur (à savoir vos applications) et le reste de votre Projet (c'est-à-dire votre Lakehouse Manager et vos requêtes). Vous devrez appeler cette API lors de la création de votre application, dans le prochain et dernier tutoriel.

<img className="thumbnail" alt="Page d'accueil du Projet" src="/images/public-cloud/data-platform/getting-started/app-init/picts/homepage-api.png" loading="lazy" />

## Créer une nouvelle API

Depuis la page d'accueil de votre Projet, cliquez sur **+** dans le module API.

Vous pourrez choisir entre **un modèle d'API existant** depuis le *Store* interne, ou **importer votre propre code** en liant un dépôt Git.

Comme vous débutez, nous avons créé un modèle NodeJS simple rien que pour vous. Continuez en sélectionnant le seul modèle disponible : *API NodeJS*.

<img className="thumbnail" alt="Store d'API" src="/images/public-cloud/data-platform/getting-started/app-init/picts/api-store-new.png" loading="lazy" />

Choisissez un nom pour votre API, et activez l'option **auto build** & **auto deploy**. Cela permettra de télécharger le code source de votre API, de le construire automatiquement et de le déployer pour vous.

<img className="thumbnail" alt="Paramètres de l'API" src="/images/public-cloud/data-platform/getting-started/app-init/picts/api-settings-new.png" loading="lazy" />

À partir de là, patientez quelques instants, car la création de l'API peut prendre un moment. La construction prend quelques minutes.

<img className="thumbnail" alt="Accueil de la construction de l'API" src="/images/public-cloud/data-platform/getting-started/app-init/picts/api_building1.png" loading="lazy" />

:::info
La Platform utilise une **méthodologie de déploiement [blue-green](https://en.wikipedia.org/wiki/Blue-green_deployment)** garantissant une disponibilité de 100 % de vos données. Vous pouvez donc créer et déployer de nouvelles versions de votre API en toute transparence, sans risquer la moindre interruption de service !
:::

Lorsque le déploiement est terminé, le bouton **Open** apparaît.

<img className="thumbnail" alt="API déployée" src="/images/public-cloud/data-platform/getting-started/app-init/picts/api_deployed.png" loading="lazy" />

Lorsque vous ouvrez votre API, vous arrivez sur l'écran ci-dessous confirmant que votre API est bien vivante et fonctionnelle. C'est aussi simple que ça !

[<span aria-hidden="true">↪</span> En savoir plus sur les API de votre Projet](https://docs.dataplatform.ovh.net/#/en/technical/sdk/api/index)

<img className="thumbnail" alt="API ouverte" src="/images/public-cloud/data-platform/getting-started/app-init/picts/api_open.png" loading="lazy" />

La prochaine et dernière étape consistera à créer et déployer votre première application sur la Platform en moins de 5 minutes.

[Créer votre première application](/guides/public-cloud/data-platform/getting-started-visualize-data)
