## Objectif

L'action *CSV to PostgreSQL* vous permet d'**ingérer des données depuis un fichier CSV (provenant de toute connexion compatible dans vos Connectors) vers une table au sein d'une base de données PostgreSQL.** Par défaut, cette action ajoute des données à une table existante, avec une option explicite pour écraser entièrement son contenu.

## Configurer une action CSV to PostgreSQL

Pour créer une nouvelle action *CSV to PostgreSQL*, suivez ces étapes au sein du Data Processing Engine (DPE) :

1.  Accédez à l'**onglet Action** au sein de l'interface du Data Processing Engine (DPE).
2.  Cliquez sur le bouton **« New Action »**.
3.  Dans la liste des actions disponibles, sélectionnez **« CSV to PostgreSQL »**.
<img className="thumbnail" alt="Configurer une action CSV to PostgreSQL — Csv to postgresql" src="/images/public-cloud/data-platform/product/dpe/actions/csv-to-postgresql/picts/csv-to-postgresql-1.png" loading="lazy" />

### Choisir un fichier CSV pour le transfert

Tout d'abord, vous devez sélectionner le fichier CSV spécifique que vous souhaitez transférer. Cette liste comprendra les fichiers CSV accessibles depuis **toutes les sources compatibles** configurées dans vos Connectors.

1.  Une liste unifiée des fichiers CSV disponibles vous sera présentée. Ces fichiers proviennent de toutes les [sources Connectors](/guides/public-cloud/data-platform/landing-page-connectors-sources) contenant des données CSV.
2.  Parcourez ou recherchez dans cette liste pour localiser le fichier CSV que vous souhaitez transférer.
<img className="thumbnail" alt="Choisir un fichier CSV pour le transfert — Csv to postgresql" src="/images/public-cloud/data-platform/product/dpe/actions/csv-to-postgresql/picts/csv-to-postgresql-2.png" loading="lazy" />
3.  Sélectionnez le fichier CSV souhaité.
4.  **Choisir un délimiteur (optionnel) :** vous pouvez spécifier le délimiteur utilisé dans votre fichier CSV. Par défaut, le système tentera de **détecter automatiquement** le délimiteur. Sinon, vous pouvez sélectionner explicitement l'un des délimiteurs courants suivants : `,` (virgule), `;` (point-virgule), ou `|` (pipe).
<img className="thumbnail" alt="Choisir un fichier CSV pour le transfert — Csv to postgresql (2)" src="/images/public-cloud/data-platform/product/dpe/actions/csv-to-postgresql/picts/csv-to-postgresql-3.png" loading="lazy" />

### Sélectionner la table PostgreSQL de destination et les options

Ensuite, vous allez définir la table PostgreSQL cible et la façon dont les données doivent être chargées. Vous verrez une liste consolidée de toutes les tables provenant de toutes les sources PostgreSQL connectées.

<img className="thumbnail" alt="Sélectionner la table PostgreSQL de destination et les options — Csv to postgresql" src="/images/public-cloud/data-platform/product/dpe/actions/csv-to-postgresql/picts/csv-to-postgresql-4.png" loading="lazy" />

1.  **Sélectionner la table de destination :** vous verrez une liste complète de toutes les tables PostgreSQL disponibles dans l'ensemble de vos [sources Connectors](/guides/public-cloud/data-platform/landing-page-connectors-sources) PostgreSQL connectées.
    -   Pour faciliter l'identification, le **nom de la source PostgreSQL** sera mentionné sous chaque nom de table.
    -   **Limitation :** actuellement, cette action ne prend en charge l'envoi de données que vers des **tables existantes** dans votre base de données PostgreSQL.
    -   **Pour charger dans une nouvelle table :** vous devez d'abord créer une table vide dans votre base de données PostgreSQL (à l'aide de votre client ou de vos outils PostgreSQL préférés), puis la sélectionner dans cette liste.
2.  **Option de chargement :** par défaut, l'action **ajoutera** les nouvelles données de votre fichier CSV à la table PostgreSQL sélectionnée.
    -   Vous disposerez également d'une option explicite pour **écraser (Overwrite)** la table. Si elle est sélectionnée, cette option supprimera complètement toutes les données existantes de la table PostgreSQL choisie avant d'insérer les nouvelles données de votre fichier CSV. Utilisez cette option avec une extrême prudence, car elle effacera toutes les données précédentes de cette table.
3.  **Lancer l'action :** une fois votre fichier CSV, la table PostgreSQL de destination et l'option de chargement configurés, cliquez sur le bouton « Run » pour lancer le transfert.
<img className="thumbnail" alt="Sélectionner la table PostgreSQL de destination et les options — Csv to postgresql (2)" src="/images/public-cloud/data-platform/product/dpe/actions/csv-to-postgresql/picts/csv-to-postgresql-5.png" loading="lazy" />

## Vérifier votre transfert

Une fois l'action *CSV to PostgreSQL* terminée avec succès, vous pouvez vérifier le transfert en vous connectant à la base de données PostgreSQL correspondante (par exemple, à l'aide d'un client SQL) et en interrogeant la table de destination pour confirmer la présence et l'exactitude des données CSV chargées.
