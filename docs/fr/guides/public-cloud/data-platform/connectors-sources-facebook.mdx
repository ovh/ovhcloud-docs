## Obtenez vos identifiants d'accès

### Découvrez comment obtenir un token d'application Facebook Developer

Les étapes suivantes vous guideront dans la procédure de création d'un token d'application sur l'interface utilisateur de Facebook Developer.

#### Prérequis : token d'application

- Connectez-vous à votre compte Facebook qui dispose de toutes les permissions **Admin** sur les pages pour lesquelles vous souhaitez obtenir les access tokens.  
Si vous n'êtes pas administrateur de la page, demandez à votre administrateur de vous accorder un accès Analyst à la page.

- Veuillez noter que si le compte ayant accordé l'accès aux tokens ne dispose plus du rôle d'administrateur ou d'analyste sur la page, l'access token sera révoqué.

#### Procédure : token d'application

##### Étape 1. Créez votre application Facebook Developer

- Rendez-vous sur : https://developers.facebook.com/ et cliquez sur `Get Started` en haut à droite.

<img className="thumbnail" alt="Procédure : token d'application — Facebook dev2" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev2.png" loading="lazy" />

- Suivez les étapes dans la fenêtre pop-up qui vient de s'ouvrir. Il n'est pas obligatoire de créer une « First App », vous pouvez ignorer cette étape.

<img className="thumbnail" alt="Procédure : token d'application — Facebook dev3" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev3.jpg" loading="lazy" />

- Rendez-vous sur https://developers.facebook.com. Ouvrez le menu `My Apps` en haut à droite, juste à côté de la barre de recherche. Vous devriez maintenant pouvoir cliquer sur le bouton `Add a New App` en haut à droite.

<img className="thumbnail" alt="Procédure : token d'application — Facebook dev4" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev4.png" loading="lazy" />

- Remplissez les champs du formulaire qui vient de s'afficher et cliquez sur `Create App ID`

<img className="thumbnail" alt="Procédure : token d'application — Facebook dev5" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev5.png" loading="lazy" />

##### Étape 2. Récupérez votre App ID et votre App Secret

- Vous arriverez maintenant sur le Dashboard de votre nouvelle application. Cliquez sur `Settings` à gauche puis sur `Basic`, juste en dessous.

<img className="thumbnail" alt="Procédure : token d'application — Facebook dev6" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev6.png" loading="lazy" />

##### Étape 3. Générez le token de votre application

- Rendez-vous sur https://developers.facebook.com/tools/explorer/

- Cliquez sur le menu déroulant `Graph API Explorer` en haut à droite et sélectionnez votre application nouvellement créée (appelée `Data Platform Connector` sur la capture d'écran suivante).

<img className="thumbnail" alt="Comment valider votre application Facebook — Facebook dev10" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev10.png" loading="lazy" />

- Cliquez maintenant sur le bouton `Get token` et sélectionnez `Get User Access Token` dans le menu déroulant.

<img className="thumbnail" alt="Comment valider votre application Facebook — Facebook dev11" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev11.png" loading="lazy" />

- Dans la fenêtre qui vient de s'ouvrir, sélectionnez les différentes permissions dont vous avez besoin **(n'oubliez pas de cocher l'option `read_insights`)** et cliquez sur le bouton `Get Access Token`.

:::info
Remarque : comme indiqué ci-dessus, vous devez être connecté à Facebook avec un compte disposant d'un accès **Admin** ou **Analyst** pour que cela fonctionne
:::

<img className="thumbnail" alt="Comment valider votre application Facebook — Facebook dev12" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev12.png" loading="lazy" />

- Puis sur `OK` en bas à droite.

<img className="thumbnail" alt="Comment valider votre application Facebook — Facebook dev14" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev14.jpg" loading="lazy" />

- Vous venez de générer un access token de courte durée. Copiez-le et collez-le dans votre éditeur de texte, aux côtés de votre App ID et de votre App Secret.

<img className="thumbnail" alt="Comment valider votre application Facebook — Facebook dev15" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev15.png" loading="lazy" />

- Modifiez maintenant le modèle d'URL suivant en remplaçant **\{app_id\}**, **\{app_secret\}** et **\{access_token\}** par vos valeurs. 
> `https://graph.facebook.com/v2.12/oauth/access_token?grant_type=fb_exchange_token&client_id={app_id}&client_secret={app_secret}&fb_exchange_token={access_token}`

<img className="thumbnail" alt="Comment valider votre application Facebook — Facebook dev17" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev17.png" loading="lazy" />

- Une fois cela fait, collez votre URL dans votre navigateur web. Copiez le résultat et collez-le dans votre éditeur de texte.

<img className="thumbnail" alt="Comment valider votre application Facebook — Facebook dev18" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev18.png" loading="lazy" />

- Copiez cette nouvelle URL et remplacez **\{access token\}** par le contenu du champ `"access_token"` du résultat de l'étape précédente : 
> `https://graph.facebook.com/v2.12/me?access_token={access_token}`

<img className="thumbnail" alt="Comment valider votre application Facebook — Facebook dev19" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev19.png" loading="lazy" />

- Une nouvelle fois, copiez le résultat de l'étape précédente dans votre éditeur de texte et remplacez **\{account_id\}** et **\{access_token\}** par les champs **id** et **access_token** des étapes précédentes dans le modèle d'URL suivant : 
> `https://graph.facebook.com/v2.12/{account_id}/accounts?access_token={access_token}`

<img className="thumbnail" alt="Comment valider votre application Facebook — Facebook dev21" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/facebook_dev21.png" loading="lazy" />

- Une dernière fois, collez l'URL dans votre navigateur web. Vous pouvez maintenant enregistrer les informations affichées à l'écran dans un document .json.

## Ajoutez une source Facebook sur Data Platform

### Aperçu de l'écran de configuration

Une fois que vous avez trouvé *Facebook* dans le **Data Platform store**, cliquez sur *Select* et vous pourrez voir l'écran de configuration comme illustré ci-dessous :

<img className="thumbnail" alt="FB2" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/FB2.png" loading="lazy" />

### Configuration de votre source

#### Se connecter à Facebook

Lors de la création de la source, vous devrez saisir les informations suivantes :

- **Account** : votre Page ID Facebook
- **Access Token** : le token de votre application Facebook Developer  
- **Source default schema** : vous pouvez utiliser ce champ pour ajouter des colonnes à vos données, si nécessaire. Utilisez la syntaxe suivante *\{"name":"value"\}*, où *name* est le nom de votre colonne et *value* est la valeur qui sera renseignée dans toutes les lignes.

Une fois ces informations ajoutées, cliquez sur *Connect* pour établir une connexion avec Facebook.

#### Ajoutez les Accounts et Endpoints

Avant de continuer, vous devez ajouter des accounts et des endpoints.

- Les [Accounts](#comment-ajouter-un-account) sont des pages Facebook référencées par le Page ID - comme dans l'écran précédent - dont vous souhaitez récupérer des données.
- Les [Endpoints](#comment-ajouter-un-endpoint) sont les **différents types de données** sur les accounts que la Data Platform récupérera via l'API Facebook. Chaque endpoint correspond à une table finale, agrégeant les données pour tous les *accounts* sélectionnés.

<img className="thumbnail" alt="FB3" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/FB3.png" loading="lazy" />

:::info
La Data Platform utilisera les identifiants renseignés à l'étape [Se connecter à Facebook](#se-connecter-à-facebook) pour accéder à l'API Facebook, mais **vous pouvez écraser les identifiants** pour avoir plusieurs accounts et endpoints dans la même source. Ajoutez simplement les différents accounts à la Source après l'étape [Se connecter à Facebook](#se-connecter-à-facebook).
:::

##### Comment ajouter un account ?

Pour ajouter un account, cliquez sur *Add an Account*. Cela ouvrira la fenêtre suivante :

<img className="thumbnail" alt="FB4" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/FB4.png" loading="lazy" />

Par défaut, il utilise les mêmes identifiants que ceux saisis précédemment lors de l'établissement de la connexion, que vous pouvez écraser ici. Le *nom du compte* est le nom d'affichage interne.

##### Comment ajouter un endpoint ?

Sur la Data Platform, chaque endpoint enregistré correspondra à un objet source de données, que vous pourrez [charger](/guides/public-cloud/data-platform/dpe-actions-load) dans une [table](/guides/public-cloud/data-platform/lakehouse-manager-tables) distincte.

Pour ajouter un endpoint, cliquez sur *Add an Endpoint*. Cela ouvrira la fenêtre suivante :

<img className="thumbnail" alt="FB5" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/FB5.png" loading="lazy" />

Ensuite, sélectionnez le type d'endpoint que vous souhaitez ajouter. L'équipe Data Platform ajoute continuellement de nouveaux types d'endpoints aux connecteurs. Vous pouvez cliquer sur la liste déroulante sous le champ *Type* pour voir ceux disponibles.

Les plus courants sont :

- *page_data* : données générales sur la page.
- *day_insights* : données sur la page triées par jour.
- *post_insights* : données sur les publications de la page.

Certains types nécessitent d'ajouter des *Insights* à l'endpoint, ce qui est simplement une façon d'indiquer à la platform Data Platform quelles données récupérer. Pour ajouter un insight, commencez à taper dans le champ Insight et cliquez sur *Enter* pour sélectionner le data insight souhaité.

<img className="thumbnail" alt="FB6" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/facebook/picts/insight-endpoint.png" loading="lazy" />

:::info
Notez que vous pouvez ajouter plus d'un insight au même endpoint.
:::

Pour terminer, cliquez sur le bouton *Create* en haut à droite.

:::warning
N'oubliez pas de nommer votre source avant de la créer. Le nom technique ne peut pas être modifié après la création de la source et sera utilisé lors des tentatives d'ouverture de la source via le [SDK Python de la Data Platform](/guides/public-cloud/data-platform/landing-page-developers-python-sdk).
:::
