## Objectif

Supprimer une organisation garantit que toutes les ressources associées à cette organisation sont **définitivement supprimées**. Il n'est pas possible de récupérer une organisation qui a été supprimée.

Pour supprimer une organisation, une checklist doit être suivie. Si vous manquez un élément de la checklist, vous ne serez pas autorisé à supprimer l'organisation.  
Les 5 étapes suivantes doivent toutes être accomplies pour qu'une organisation puisse être supprimée :

1. [Supprimer tous les projets](/guides/public-cloud/data-platform/manage-projects-delete) au sein de l'organisation
2. [Supprimer tous les datasets](/guides/public-cloud/data-platform/lakehouse-manager-datasets#gestion-des-datasets) de l'organisation
3. Vérifier qu'il n'y a pas de solde en attente sur la [facturation](/guides/public-cloud/data-platform/manage-pricing#abonnements-et-comptes-de-facturation)
4. [Retirer tous les utilisateurs](/guides/public-cloud/data-platform/iam-users#gérer-les-utilisateurs-de-liam-de-lorganisation) de l'organisation
5. Supprimer l'organisation *(voir la documentation ci-dessous)*

## Supprimer l'organisation depuis l'interface utilisateur

:::info
Assurez-vous d'avoir suivi toutes les étapes mentionnées ci-dessus avant d'aller plus loin.
:::

L'option permettant de supprimer une organisation est accessible en accédant aux paramètres de l'organisation. Cliquez sur **organization settings** comme indiqué dans l'image ci-dessous.

<img className="thumbnail" alt="Supprimer l'organisation depuis l'interface utilisateur — Delete orga" src="/images/public-cloud/data-platform/product/organisations/picts/delete-orga-2.jpg" loading="lazy" />

Cliquez sur les paramètres et vous arriverez sur la page qui propose l'option de supprimer l'organisation. Le bouton de suppression ne sera visible que si vous avez suivi toutes les étapes de la checklist mentionnée ci-dessus.

<img className="thumbnail" alt="Supprimer l'organisation depuis l'interface utilisateur — Delete orga (2)" src="/images/public-cloud/data-platform/product/organisations/picts/delete-orga-3.jpg" loading="lazy" />

<img className="thumbnail" alt="Supprimer l'organisation depuis l'interface utilisateur — Delete orga (3)" src="/images/public-cloud/data-platform/product/organisations/picts/delete-orga-4.jpg" loading="lazy" />

Si la checklist n'a pas été suivie, un bouton **leave organization** s'affichera à la place de **delete organization**.

<img className="thumbnail" alt="Supprimer l'organisation depuis l'interface utilisateur — Delete orga (4)" src="/images/public-cloud/data-platform/product/organisations/picts/delete-orga-5.png" loading="lazy" />
