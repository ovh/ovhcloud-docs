## Qu'est-ce qu'une source ?

Une source est une connexion enregistrée vers un système externe : les identifiants, l'accès réseau, et l'ensemble des objets que ce système expose. Enregistrer une source ne déplace aucune donnée. Elle enregistre comment atteindre le système, afin que l'[Analyzer](/guides/public-cloud/data-platform/landing-page-connectors-analyzer) puisse l'inspecter et que le [Data Processing Engine](/guides/public-cloud/data-platform/landing-page-dpe) puisse charger depuis celle-ci par la suite.

Les sources sont choisies dans le Store de connecteurs, qui propose des connecteurs pour les systèmes de stockage de fichiers, les moteurs de bases de données, les protocoles réseau, les brokers de streaming et d'IoT, les plateformes sociales et les outils d'analyse. Une vingtaine d'entre eux disposent de leur propre guide couvrant les champs et les permissions dont ce connecteur a besoin. Les autres suivent le même modèle de configuration.

Deux chemins s'ouvrent une fois une source enregistrée. Le plus courant importe une copie des données dans le projet, en [créant](/guides/public-cloud/data-platform/lakehouse-manager-tables#créer-une-table) et en [chargeant](/guides/public-cloud/data-platform/dpe-actions-load) une [table](/guides/public-cloud/data-platform/lakehouse-manager-tables). L'alternative, disponible sur un sous-ensemble de connecteurs, marque la source comme directement interrogeable afin que l'[Analytics Manager](/guides/public-cloud/data-platform/landing-page-analytics-manager) exécute du SQL directement dessus, sans copie conservée sur la platform.

Les sources sont organisées en dossiers. L'enregistrement des identifiants est volontairement séparé de l'analyse et du chargement des données, afin que les deux puissent revenir à des équipes différentes et à des [rôles IAM](/guides/public-cloud/data-platform/iam-roles-conditions) différents.
