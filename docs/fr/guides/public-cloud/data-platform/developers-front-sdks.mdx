## Objectif

Le Front APP SDK (ReactJS) et le Front API SDK (NodeJS) sont tous deux en cours de remplacement. La réécriture n'a pas encore de date de livraison, leur documentation ne fait donc pas partie de cette section : les nouveaux guides arriveront ici lorsque les nouveaux SDK seront disponibles.

:::warning
**Refonte en attente, pas de date.** D'ici là, la documentation actuelle des deux SDK reste valide et demeure publiée sur le site de documentation legacy.
:::

- Front APP SDK, ReactJS, pour créer des tableaux de bord et des composants personnalisés au sein d'une application déployée : [docs.dataplatform.ovh.net/#/en/technical/sdk/app/index](https://docs.dataplatform.ovh.net/#/en/technical/sdk/app/index)
- Front API SDK, NodeJS, pour personnaliser l'API qu'une application appelle : [docs.dataplatform.ovh.net/#/en/technical/sdk/api/index](https://docs.dataplatform.ovh.net/#/en/technical/sdk/api/index)

Ces pages couvrent les versions actuelles des SDK et y sont maintenues jusqu'à ce que les remplacements soient disponibles. Le code écrit avec ces SDK continue de fonctionner ; rien n'est déprécié par ce changement.

Pour un travail sur la platform qui ne touche pas au front end, le [Custom Actions SDK](/guides/public-cloud/data-platform/landing-page-developers-python-sdk) en Python est documenté en intégralité dans cette section, et les [API de la Data Platform](/guides/public-cloud/data-platform/landing-page-developers-apis) couvrent les buckets et l'IAM.

:::info
Vous développez une application actuellement ? Les pages [Apps](/guides/public-cloud/data-platform/landing-page-app-services-apps) couvrent le parcours low-code, qui ne nécessite aucun SDK, et le tutoriel [Développer votre propre application](/guides/public-cloud/data-platform/tutorials-app-development) couvre l'import de votre propre code depuis Git.
:::
