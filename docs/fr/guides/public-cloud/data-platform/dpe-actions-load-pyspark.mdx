## Objectif

L'action *Load PySpark* **extrait des données brutes depuis des sources et les insère dans des tables primaires** de votre entrepôt de données à l'aide d'[Apache Spark™](https://spark.apache.org/). Il s'agit généralement de la première étape de tout système de traitement de données, nécessaire avant d'exécuter tout autre processus sur les données provenant des sources connectées.

:::info
Autrement dit, si vous avez [configuré un connecteur via les Connectors](/guides/public-cloud/data-platform/landing-page-connectors-sources), le Projet dispose des informations pour se connecter à la source ainsi que de ses métadonnées, mais ne contiendra pas les données réelles tant qu'elles n'auront pas été chargées à l'aide de l'action *Load PySpark*.
:::

:::warning
L'action *Load PySpark* n'est compatible qu'avec les connecteurs de source suivants : [MySQL](/guides/public-cloud/data-platform/connectors-sources-mysql), PostgreSQL, Snowflake, [Trino](/guides/public-cloud/data-platform/connectors-sources-trino), AWS S3<sup>1</sup>, [Microsoft Azure Blob Storage](/guides/public-cloud/data-platform/connectors-sources-blob-storage), [Data Platform Buckets](/guides/public-cloud/data-platform/connectors-sources-dataplatform-buckets), [File Upload](/guides/public-cloud/data-platform/connectors-sources-upload-files), et S3.
:::

## Configurer une action Load PySpark

Pour créer une nouvelle action *Load PySpark*, accédez à l'onglet *Actions* du Data Processing Engine (DPE), cliquez sur **New Action** et sélectionnez l'action *Load PySpark*.

### Choisir une source et une destination

Pour configurer l'action *Load PySpark*, commencez par sélectionner une **source** dans la liste que vous avez déjà configurée dans l'onglet [Sources](/guides/public-cloud/data-platform/landing-page-connectors-sources) des Connectors.

<img className="thumbnail" alt="Choisir une source et une destination — Load pyspark select source" src="/images/public-cloud/data-platform/product/dpe/actions/load-pyspark/picts/load-pyspark-select-source.png" loading="lazy" />

Ensuite, une table de **destination** vers laquelle envoyer vos données. Comme pour les sources, les tables doivent être configurées au préalable dans l'onglet [Tables](/guides/public-cloud/data-platform/lakehouse-manager-tables) du Lakehouse Manager. Assurez-vous d'avoir [construit](/guides/public-cloud/data-platform/lakehouse-manager-manage-tables) votre modèle de données, sinon les tables ne seront pas accessibles par les autres composants de la platform.

<img className="thumbnail" alt="Choisir une source et une destination — Load pyspark select destination" src="/images/public-cloud/data-platform/product/dpe/actions/load-pyspark/picts/load-pyspark-select-destination.png" loading="lazy" />

### Associer les attributs

Une fois la source et la destination sélectionnées, le système **associera automatiquement** les attributs de destination de votre table de destination avec les différentes colonnes qu'il a identifiées dans la source de données brutes.

<img className="thumbnail" alt="Associer les attributs — Load pyspark blueprint rules" src="/images/public-cloud/data-platform/product/dpe/actions/load-pyspark/picts/load-pyspark-blueprint-rules.png" loading="lazy" />

:::info
Sur l'image ci-dessous, vous pouvez voir que l'attribut *date* affiche une valeur de « 1 » à côté de l'icône de bloc-notes. Cela indique le nombre de **règles de validation des données, aussi appelées blueprint rules**, définies dans les Connectors, qui seront automatiquement appliquées lors du chargement des données. Les [blueprint rules](/guides/public-cloud/data-platform/connectors-analyzer-blueprint-rules) permettent aux utilisateurs de filtrer rapidement les données invalides comme les valeurs nulles ou les cellules vides, ou de reformater des valeurs telles que les dates ou les devises.
:::

<img className="thumbnail" alt="Associer les attributs — Load pyspark attribute select" src="/images/public-cloud/data-platform/product/dpe/actions/load-pyspark/picts/load-pyspark-attribute-select.png" loading="lazy" />

Notez que vous pourriez vouloir **insérer du texte brut** directement dans votre table de destination. Cela peut être utile par exemple lorsque vous souhaitez compter le nombre de points de données ou marquer une certaine source avec un label qui sera utilisé plus tard dans une table d'agrégation. Pour ce faire, sélectionnez *&lt; txt >*, ce qui définira l'attribut source comme un champ de saisie de texte brut.

<img className="thumbnail" alt="Associer les attributs — Load pyspark attribute txt" src="/images/public-cloud/data-platform/product/dpe/actions/load-pyspark/picts/load-pyspark-attribute-txt.png" loading="lazy" />

### Configurer les préférences de l'action

Une fois satisfait de l'association de vos attributs, accédez à l'[onglet préférences pour configurer les paramètres de l'action](/guides/public-cloud/data-platform/dpe-jobs-preferences).

<img className="thumbnail" alt="Configurer les préférences de l'action — Load pyspark settings" src="/images/public-cloud/data-platform/product/dpe/actions/load-pyspark/picts/load-pyspark-settings.png" loading="lazy" />

Lorsque vous avez terminé de modifier votre action, cliquez sur **Create** pour valider l'action.
