## Objectif

:::info
Au cœur de vos initiatives axées sur les données, **le Lakehouse Manager s'impose comme le hub central de tous vos actifs de données.** Avec le Lakehouse Manager, vous êtes prêt à accélérer votre progression axée sur les données, en évitant les tâches ardues de nettoyage et de gestion de l'infrastructure de données, pour vous concentrer plutôt sur ce qui compte vraiment, **libérer tout le potentiel de vos données.**
:::

Le composant Lakehouse Manager comporte 8 sous-menus, correspondant à ses principales fonctionnalités :

- **Overview** donnant des informations sur les différents actifs de données (comme leur répartition, les problèmes qui leur sont liés, les tags associés, l'utilisation du stockage, l'analyse d'exécution)

- [**Datasets**](/guides/public-cloud/data-platform/lakehouse-manager-datasets) pour regrouper et gérer logiquement les Tables facilement.

- [**Tables**](/guides/public-cloud/data-platform/lakehouse-manager-tables) pour créer des tables à partir de sources et les organiser dans des bases de données

- [**Attributes**](/guides/public-cloud/data-platform/lakehouse-manager-attributes) pour visualiser les attributs à travers votre data lake / data warehouse et leur lignage dans le Projet

- [**Buckets**](/guides/public-cloud/data-platform/lakehouse-manager-buckets) pour vous permettre de stocker des objets non structurés (des images par exemple)

- [**Explorer**](/guides/public-cloud/data-platform/lakehouse-manager-explorer) pour inspecter vos données directement avec des requêtes visuelles ou SQL.

- [**Policy Tags**](/guides/public-cloud/data-platform/lakehouse-manager-policy-tags) pour vous aider avec un contrôle d'accès aux données avancé et granulaire (Advanced Data Access Control)

- **Jobs** pour donner à tous les utilisateurs une vue d'ensemble de toutes les tâches et de leur statut

Le Lakehouse Manager va plus loin dans la modélisation des données en proposant la création de data lakes et de data warehouses sous l'onglet [tables](/guides/public-cloud/data-platform/lakehouse-manager-tables). Gérez toutes vos tables d'ingestion et vos tables primaires, et concevez des « data marts » puissants, c'est-à-dire les agrégations conçues pour répondre à des besoins spécifiques de visualisation de données ou d'IA. Le Lakehouse Manager permet en outre un travail collaboratif (avec sauvegarde automatique) en permettant à plusieurs utilisateurs de travailler ensemble sur le même ensemble de tables sous des vues distinctes qui peuvent être spécifiques à un Projet ou à un service. Les tables sont composées d'[attributs](/guides/public-cloud/data-platform/lakehouse-manager-attributes) qui peuvent être traités, interrogés ou utilisés comme features de ML.

[Buckets](/guides/public-cloud/data-platform/lakehouse-manager-buckets) est le sous-composant suivant, qui apporte de la flexibilité en vous permettant de stocker toute donnée non structurée dans un espace de stockage d'objets compatible S3<sup>1</sup>.

[Datasets](/guides/public-cloud/data-platform/lakehouse-manager-datasets) vous permet de regrouper et de gérer logiquement les Tables facilement.

[Policy Tags](/guides/public-cloud/data-platform/lakehouse-manager-policy-tags) a été développé pour aider l'utilisateur à définir des « policy tags » sur *tables, attributes, and datasets* pour un contrôle d'accès aux données avancé et granulaire (Advanced Data Access Control).

Enfin, via l'onglet **Jobs**, vous pourrez consulter le résumé des performances de vos tâches. Il vous fournit des informations rapides comme le statut des tâches, les tâches exécutées au fil du temps, le temps d'exécution des tâches, ainsi que les tâches en cours d'exécution, les tâches en file d'attente et les tâches passées exécutées.
