## Objectif

Dans une [action Custom](/guides/public-cloud/data-platform/dpe-actions-custom), vous pouvez avoir besoin d'utiliser des variables d'environnement. Vous pouvez définir les vôtres dans les préférences ou les définir dans le *Advanced Mode* JSON de l'action, dans l'objet JSON `params`, et les réutiliser dans votre action Custom.

```python
import sys
from logging import getLogger
from forepaas.core.settings import PARAMS

logger = logging.getLogger(__name__)

def my_custom(event):
	try:
		# Affiche la valeur du paramètre
		logger.info("Environment variable value is: ".format(PARAMS["env variable key"]))

	except Exception as err: 
		raise Exception("err:{} L:{}".format(err,sys.exc_info()[2].tb_lineno))
```
