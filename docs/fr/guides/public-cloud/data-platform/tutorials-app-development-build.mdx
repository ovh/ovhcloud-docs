## Objectif

Ici, vous apprendrez à configurer une application React et à l'exécuter localement.

À la fin de ce guide, vous serez capable d'éditer une application Data Platform en l'exécutant **localement**, en la **connectant** à l'écosystème de la Platform et en la **déployant** avec un dépôt git.

## Prérequis

Il y a quelques éléments dont vous avez besoin avant de commencer :

- Suivez le [guide de démarrage de l'Analytics App](/guides/public-cloud/data-platform/landing-page-getting-started) jusqu'à [ce point](/guides/public-cloud/data-platform/getting-started-create-queries). C'est là que vous exposez votre API.
- Installez [git](https://git-scm.com/).
- Installez [Node.js](https://nodejs.org/en/).
- Installez [yarn](https://yarnpkg.com/) (recommandé) ou [npm](https://www.npmjs.com/).
- Installez [npx](https://www.npmjs.com/package/npx).
- Disposez d'un **éditeur de texte**. Vous allez écrire du HTML, du CSS et du JavaScript.

:::info
Le point de communication entre votre **Data Platform Project** et votre application est l'**API Data Platform** que vous avez exposée dans Application Services. C'est pourquoi il est nécessaire de terminer le [guide de démarrage](/guides/public-cloud/data-platform/landing-page-getting-started) jusqu'à la partie où vous exposez vos données et vos requêtes sur l'API.
:::

## Configurer une application et la connecter à Data Platform

### Créer une application à partir d'un modèle existant

Clonez ce [dépôt](https://github.com/forepaas/getting-started/) et ouvrez-le :

```bash
git clone https://github.com/forepaas/getting-started.git
cd getting-started/
```

Basculez sur la branche release/basic

```bash
git checkout release/basic
```

Avant d'installer les modules Node, vous devez vous assurer que nos dépendances liées aux cartes sont configurées pour l'environnement actuel. Ouvrez votre fichier package.json et ajoutez les lignes suivantes à votre section dependencies, ou mettez-les à jour si elles existent déjà :

```json
	"dependencies": {
	    // ... autres dépendances existantes
	    "leaflet": "^1.6.0",
	    "react-leaflet": "^2.7.0",
	    "react-leaflet-markercluster": "^2.0.0"
	  },
```

Installez les modules node :

```bash
yarn
```

:::warning
Si vous obtenez une erreur concernant les **certificats** lors de l'installation de yarn, vous devez contacter votre service informatique pour résoudre le problème.
:::

Installez npx (ignorez cette étape si vous l'avez déjà installé globalement) :

```bash
yarn global add npx
```

Installez les modules de la Platform

```bash
npm run fppm i
```

:::warning
Si vous rencontrez des problèmes lors de l'installation des modules, cela peut être dû à vos configurations NodeJS. Désinstallez et réinstallez NodeJS pour résoudre le problème.
:::

:::warning
Si le problème persiste, cela pourrait être dû à un problème de compatibilité de version de NodeJS. Installez NodeJS v16.20.2 pour résoudre le problème.
:::

Lancez votre application :

```bash
yarn start
```

:::info
Ouvrez `http://localhost:3333` pour vérifier votre application. Si vous ne voyez aucune erreur mais un écran blanc, vous devez encore ajuster la configuration de l'application avant que les panneaux apparaissent. L'écran blanc signifie que votre application est bien démarrée et fonctionnelle.
:::
