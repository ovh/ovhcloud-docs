## Objectif

Créer un nouveau Projet ne prend que quelques minutes ! Il est possible de choisir le fournisseur cloud et la région pour vos données (cloud ou on-premise) ainsi que le template de Projet avec lequel vous souhaitez démarrer.

:::info
La Data Platform a été conçue pour faire évoluer facilement les Projets à mesure de leur croissance. À tout moment après la création de votre Projet, vous pourrez étendre ses capacités et son volume de stockage à travers le Projet grâce à la scalabilité horizontale et verticale.
:::

## Choisir un template

Commencez par choisir le template qui correspond le mieux à votre cas d'usage. Si aucun template ne répond parfaitement à vos besoins, vous pouvez ajouter des services au Projet plus tard. Pour vous assurer que tous vos besoins sont couverts, nous vous suggérons de **choisir le template End-to-end**.

<img className="thumbnail" alt="choix du template de Projet" src="/images/public-cloud/data-platform/product/project/picts/project_creation_template_choice.png" loading="lazy" />

## Choisir une région pour votre Projet

Il s'agit de l'emplacement du data center où : 

- la configuration de votre Projet sera stockée 
- votre object store sera stocké
- vos jobs de traitement de données, requêtes, API et applications s'exécuteront

<img className="thumbnail" alt="Choisir une région pour votre Projet — choix du fournisseur pour la création du projet" src="/images/public-cloud/data-platform/product/project/picts/project_creation_provider_choice.png" loading="lazy" />

Une fois votre choix effectué, saisissez le nom de votre Projet. **Ce nom ne pourra pas être modifié ultérieurement** et correspondra par défaut au Domain Name System (DNS) de votre Projet.

<img className="thumbnail" alt="Choisir une région pour votre Projet — projet nommé" src="/images/public-cloud/data-platform/product/project/picts/named_project.png" loading="lazy" />

:::info
Vous pouvez également **personnaliser le domaine et le sous-domaine** dans les options avancées de cette étape.
:::

## Vue d'ensemble et confirmation

Enfin, vous arriverez sur cet écran final récapitulant toutes les informations relatives à votre Projet.

En cliquant sur **Confirmer**, la création de votre Projet démarrera.

<img className="thumbnail" alt="Vue d'ensemble et confirmation — projection du coût du projet" src="/images/public-cloud/data-platform/product/project/picts/project_cost_projection.png" loading="lazy" />

Un ensemble de micro-services cloud est automatiquement mis en place en quelques minutes : pare-feux d'applications web, groupes de sécurité, CDN, configuration DNS, certificats SSL/TLS, endpoints API, planification de la capacité, load balancer, auto-scaling, Kubernetes, cache, ETL, moteur d'entrepôt de données, et plus encore…

Vous recevrez un e-mail une fois la création terminée, ce qui signifie que le Projet est prêt à être utilisé.
