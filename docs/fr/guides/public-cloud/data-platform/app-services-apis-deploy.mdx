## Objectif

Depuis la page d'accueil de votre projet, cliquez sur **+** dans le module API.

<img className="thumbnail" alt="Accueil du projet" src="/images/public-cloud/data-platform/product/api-manager/picts/api-home-new.png" loading="lazy" />

Vous pourrez choisir entre **un modèle d'API existant** depuis le *Platform Store* interne, ou **importer votre propre code** en liant un dépôt Git.

<img className="thumbnail" alt="Boutique d'API" src="/images/public-cloud/data-platform/product/api-manager/picts/api_store.PNG" loading="lazy" />

Choisissez un nom pour votre API, et activez l'option **build automatique**. Cela téléchargera le code source de votre API et le construira automatiquement pour vous. Vous pouvez également activer l'auto-déploiement dès maintenant, ou consulter plus bas comment déployer votre API manuellement.

<img className="thumbnail" alt="Paramètres de l'API" src="/images/public-cloud/data-platform/product/api-manager/picts/api_settings.PNG" loading="lazy" />

À partir de là, laissez quelques secondes le temps que la création de l'API se termine.

:::info
la Platform utilise une **méthodologie de déploiement [blue-green](https://en.wikipedia.org/wiki/Blue-green_deployment)** garantissant une disponibilité de 100 % de vos données. Vous pouvez donc créer et déployer de nouvelles versions de votre API en toute transparence, sans risque d'interruption de service !
:::

<img className="thumbnail" alt="Accueil de la construction de l'API" src="/images/public-cloud/data-platform/product/api-manager/picts/api_building1.PNG" loading="lazy" />

Sur la page d'accueil de votre API, vous trouverez trois parties :

- __Monitoring__ : statut de votre API une fois qu'elle a été déployée
- __Active__ : statut de votre version « active », c'est-à-dire celle sur laquelle vous travaillez actuellement
- __Versions__ : liste de toutes les versions (également appelées tags) disponibles dans votre API

<img className="thumbnail" alt="Accueil du projet" src="/images/public-cloud/data-platform/product/api-manager/picts/api_building.PNG" loading="lazy" />
Vous pouvez voir plus de détails sur la version que vous venez de créer à l'aide de la flèche à droite de celle-ci.

<img className="thumbnail" alt="Accueil du projet" src="/images/public-cloud/data-platform/product/api-manager/picts/api_buildinglogs.PNG" loading="lazy" />
Consultez le journal d'activité en cliquant sur « Open Console ». Comme vous avez activé le build automatique lors de la création de l'API, il a déjà démarré.

<img className="thumbnail" alt="Accueil du projet" src="/images/public-cloud/data-platform/product/api-manager/picts/api_logs.PNG" loading="lazy" />
Une fois terminé, vous devriez voir un dernier journal « EndBuild success ».

<img className="thumbnail" alt="Accueil du projet" src="/images/public-cloud/data-platform/product/api-manager/picts/api_dpl.PNG" loading="lazy" />
Pour démarrer le déploiement, cliquez sur « Deploy ».

<img className="thumbnail" alt="Accueil du projet" src="/images/public-cloud/data-platform/product/api-manager/picts/api_deploying.PNG" loading="lazy" />
Le déploiement démarre, et peut prendre quelques minutes.

<img className="thumbnail" alt="Accueil du projet" src="/images/public-cloud/data-platform/product/api-manager/picts/api_deployed.PNG" loading="lazy" />
Lorsque le déploiement est terminé, le bouton « Open » apparaît.

<img className="thumbnail" alt="Accueil du projet" src="/images/public-cloud/data-platform/product/api-manager/picts/open.png" loading="lazy" />
Lorsque vous ouvrez votre API, vous arrivez maintenant sur cet écran.

Pour accéder à votre API, il suffit d'installer une application et de la connecter à l'API. Vous pouvez également utiliser ses endpoints en direct.
