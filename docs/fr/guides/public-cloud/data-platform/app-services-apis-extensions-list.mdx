## Objectif

:::warning
L'ajout d'une extension nécessite de recharger votre API (sur la page Overview) afin de pouvoir la construire.
:::

| **ID**               | **Nom**              | **Description**                                           |
|:--------------------:| ------------------------ | ------------------------------------------------------------ |
| **sdk**              | SDK                      | Kit de développement essentiel au bon fonctionnement des autres modules. |
| **cache-controller** | Cache Controller    | Expose la fonctionnalité de vidage du cache de cette API.   |
| **cache-memory**     | Memory Cache            | Active le cache dans la RAM du nœud. |
| **cache-redis**      | Redis Cache              | Active le cache dans Redis.   |
| **iam**              | Identity Access Manager | Active la fonctionnalité de filtrage des utilisateurs via le système d'authentification de la Data Platform. |
| **qb**               | Analytics Manager        | Permet de faire transiter les requêtes de l'Analytics Manager via l'API. |
| **webstorage**       | Web Storage            | Fournit un stockage clé-valeur simple et active la fonctionnalité de sauvegarde front du SDK (similaire à localstorage) |
