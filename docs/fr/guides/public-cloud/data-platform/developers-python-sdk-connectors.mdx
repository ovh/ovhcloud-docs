## Objectif

Dans le projet de la Data Platform, toutes les **données** disponibles sont définies et configurées dans le [Lakehouse Manager](/guides/public-cloud/data-platform/landing-page-lakehouse-manager).

Dans le SDK Python, toutes ces **sources de données** sont nommées par une **chaîne de connexion** unique et accessibles via des **connecteurs** retournés par la fonction `connect()`. L'**objet Connector** retourné ainsi que ses méthodes disponibles dépendent du **type de la source de données**.

Un exemple simple pour lister les tables du dataset par défaut :
```python
from forepaas.dwh import connect

# se connecte au dataset par défaut
cn_prim = connect('dwh/default_dataset/')
# liste les tables de la base de données
tables = cn_prim.list()
print(tables)
```

:::info
Les **chaînes de connexion** sont utilisées dans tous les composants du projet pour référencer les **sources de données**, par exemple dans les actions Data Processing Engine [Load](/guides/public-cloud/data-platform/dpe-actions-load-advanced-mode) et [Aggregate](/guides/public-cloud/data-platform/dpe-actions-aggregate-advanced-mode) ou lors de l'[application de la segmentation](/guides/public-cloud/data-platform/tutorials-segmentation-table-attribute#comprendre-les-paramètres-avancés).
:::

## Buckets

Les [Buckets](/guides/public-cloud/data-platform/lakehouse-manager-buckets) sont le stockage objet intégré de la Data Platform. Ci-dessous, la chaîne de connexion et l'objet Connector correspondant retournés par la `connect function`.

| connection string | Connector | description |
| :---------------- | :-------: | :---------- |
| `connect("data_store")`| DataStore | Se connecte aux buckets |
| `connect("data_store/my-bucket")` | Bucket | Se connecte à un bucket spécifique |

En savoir plus sur les [connecteurs DataStore et Bucket](/guides/public-cloud/data-platform/developers-python-sdk-connect-bucket).

## Storage Engines

Les projets sont liés à des **Storage Engines** comme bases de données principales pour stocker et interroger les données au cœur de votre projet.
 
Un projet peut être défini avec plusieurs [datasets](/guides/public-cloud/data-platform/lakehouse-manager-datasets), mais par défaut vous recevrez 1 dataset : **default_dataset**. Vous pouvez également créer des datasets internes et externes personnalisés.

| connection string | Connector | description |
| :---------------- | :-------: | :---------- |
| `connect("dwh/default_dataset/")`| Dataset | Se connecte au dataset par défaut - **default_dataset** |
| `connect("dwh/exampleDataset/")`| Dataset | Se connecte au dataset personnalisé créé par vous - **exampleDataset** |

En savoir plus sur le [connecteur Database](/guides/public-cloud/data-platform/developers-python-sdk-connect-dataset).

## Query Engine (Trino)

| connection string | Connector | description |
| :---------------- | :-------: | :---------- |
| `connect("query_engine")`| Trino | Se connecte au query engine (Trino) |
| `connect(f"query_engine/{catalog}/{schema}")` | Trino | Se connecte directement à un **schéma** dans un **catalogue** |

## Sources

Vous pouvez également vous connecter à des sources de données externes déclarées dans [Connectors's Sources](/guides/public-cloud/data-platform/landing-page-connectors-sources). Chaque source externe possède une **chaîne de connexion** associée basée sur le nom initial donné à la source.
Par exemple, une nouvelle source de données nommée `My first data` aura pour chaîne de connexion `dwh/my_first_data`.  
Le **nom technique** est affiché sur la page principale des Connectors Source.

Les sources externes peuvent être réparties en quelques types :

- Les **connecteurs de bases de données** ont les mêmes méthodes que les storage engines, voir [connecteur Database](/guides/public-cloud/data-platform/developers-python-sdk-connect-dataset#méthodes-du-connecteur)  
(par exemple Snowflake, PostgreSQL, Oracle, Microsoft SQL Server, Amazon Redshift, MongoDB...)  

- Les **connecteurs de protocole** lors de l'accès à un stockage de fichiers ou un stockage objet (Data Platform Buckets, Data Platform File Upload, SFTP, Amazon S3<sup>1</sup>, ...)  
Ces connecteurs ont les mêmes méthodes que le [connecteur Bucket](/guides/public-cloud/data-platform/developers-python-sdk-connect-bucket#méthodes-du-connecteur-bucket)  

- **Stream** (par exemple Kafka, MQIT, Amazon Kinesis) ou **External APIs** (par exemple Google Analytics, Facebook, Twitter, Mailchimp..)  
Ces connecteurs sont principalement conçus pour être utilisés depuis [Connectors Analyzer](/guides/public-cloud/data-platform/landing-page-connectors-analyzer) et les [actions Load du Data Processing Engine](/guides/public-cloud/data-platform/dpe-actions-load).
