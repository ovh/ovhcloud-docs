## Objectif

Le connecteur X permet de **consolider les insights d'un compte X donné**. 
Vous pouvez par exemple récupérer des données de comptes concurrents.

<img className="thumbnail" alt="twitter1" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/twitter/picts/connector-select.png" loading="lazy" />

## Métriques disponibles

Grâce au connecteur X, vous pouvez obtenir des informations sur :  

- Un compte X :
 - Date
 - Nom du compte
 - Nombre total d'abonnés
 - Nombre total de tweets (tweets, retweets, réponses)
 - Nombre total de favoris
- Un tweet :
 - ID du tweet
 - Nom du compte
 - Date de création du tweet
 - Texte du tweet
 - Nombre total de retweets, y compris les retweets du tweet d'origine si c'est lui-même un retweet
 - Nombre total de retweets, hors retweets du tweet d'origine si c'est lui-même un retweet
 - Nombre de retweets pour le tweet d'origine (si c'est un retweet)
 - Nombre d'utilisateurs ayant ajouté ce tweet à leurs favoris
 - Type de tweet : citation d'un autre tweet
 - Type de tweet : réponse à un autre tweet
 - Type de tweet : retweet
 - Langue

## Récupérer vos identifiants d'accès

Pour accéder à l'API X, vous devrez d'abord créer une application sur X. Les tokens seront ensuite générés à partir de celle-ci.

Le connecteur utilisant l'API publique de X, vous n'avez pas besoin de créer cette application depuis un compte spécifique disposant de droits particuliers.

### Étape 1

Rendez-vous sur [X](https://apps.X.com/) et cliquez sur « Create New App ».

<img className="thumbnail" alt="Page de l'application" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/twitter/picts/twitter1.png" loading="lazy" />

### Étape 2

Remplissez le formulaire avec vos propres informations dans tous les champs obligatoires.
*N'oubliez pas le Developer Agreement*.

<img className="thumbnail" alt="Page de l'application" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/twitter/picts/twitter2.png" loading="lazy" />

### Étape 3

Rendez-vous dans l'onglet « Keys and Access Tokens ».

<img className="thumbnail" alt="Page de l'application" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/twitter/picts/twitter3.png" loading="lazy" />

### Étape 4

Rendez-vous sur « Your Access Token » et cliquez sur « Create my access token ».

<img className="thumbnail" alt="Page de l'application" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/twitter/picts/twitter4.png" loading="lazy" />

### Étape 5

Ouvrez un logiciel d'édition de texte et copiez/collez votre Consumer Key, Consumer Secret, Access Token et Access Token Secret.

<img className="thumbnail" alt="Page de l'application" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/twitter/picts/twitter5.png" loading="lazy" />

## Ajouter une source X sur la Platform

### Vue d'ensemble de l'écran de configuration

Une fois que vous avez trouvé *X* dans le **Platform store**, cliquez sur *Select* et vous pourrez voir l'écran de configuration comme indiqué ci-dessous :

<img className="thumbnail" alt="Vue d'ensemble de l'écran de configuration — Twitter conf" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/twitter/picts/twitter_conf.png" loading="lazy" />

### Configurer votre source

#### Se connecter à X

Lors de la création de la source, vous devrez saisir les informations suivantes :

- **Account** : votre Page ID X.
- **Consumer key** : clé fournie par X (que vous avez copiée précédemment).
- **Consumer secret** : secret associé à la Consumer key.
- **Access token** : votre token d'accès à l'API X.
- **Access token secret** : le secret associé à l'Access token.
- **Source default schema** : ce champ vous permet d'ajouter des colonnes à vos données, si nécessaire. Utilisez la syntaxe suivante *\{"name":"value"\}*, où *name* est le nom de votre colonne et *value* la valeur à renseigner dans toutes les lignes.

Une fois ces informations ajoutées, cliquez sur *Connect* pour établir une connexion avec l'API de X.

#### Ajouter les Accounts et Endpoints

Avant de continuer, vous devez ajouter des comptes et des endpoints.

- Les [Accounts](#comment-ajouter-un-compte) sont des pages X référencées par le Page ID - comme dans l'écran précédent - dont vous souhaitez récupérer des données.
- Les [Endpoints](#comment-ajouter-un-endpoint) sont les **différents types de données** sur les comptes que la Platform récupérera via l'API X. Chaque endpoint correspond à une table finale, agrégeant les données pour tous les *accounts* sélectionnés.

<img className="thumbnail" alt="Ajouter les comptes et les endpoints — Twitter conf2" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/twitter/picts/twitter_conf2.png" loading="lazy" />

:::info
La Platform utilisera les identifiants fournis pour accéder à l'API X, mais **vous pouvez écraser les identifiants** pour avoir plusieurs comptes et endpoints dans la même source. Ajoutez simplement les différents comptes à la Source après l'étape [Se connecter à X](#se-connecter-à-x).
:::

##### Comment ajouter un compte ?

Pour ajouter un compte, cliquez sur *Add an Account*. Cela ouvrira la fenêtre suivante :

<img className="thumbnail" alt="Ajouter les comptes et les endpoints — Add account" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/twitter/picts/add_account.png" loading="lazy" />

Par défaut, les mêmes identifiants que ceux saisis précédemment lors de l'établissement de la connexion sont utilisés, et vous pouvez les écraser ici. Le *account name* est le nom d'affichage interne.

##### Comment ajouter un Endpoint ?

Sur la Platform, chaque endpoint enregistré correspondra à un objet source de données, que vous pourrez [charger](/guides/public-cloud/data-platform/dpe-actions-load) dans une [table](/guides/public-cloud/data-platform/lakehouse-manager-tables) distincte.

Pour ajouter un endpoint, cliquez sur *Add an Endpoint*. Cela ouvrira la fenêtre suivante :

<img className="thumbnail" alt="Ajouter les comptes et les endpoints — Twitter endpoint" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/twitter/picts/twitter_endpoint.png" loading="lazy" />

Ensuite, sélectionnez le type d'Endpoint que vous souhaitez ajouter. L'équipe ajoute continuellement de nouveaux types d'Endpoints aux connecteurs. Vous pouvez cliquer sur la liste déroulante sous le champ *Type* pour voir ceux disponibles.

Les plus courants sont :

- *tweet_insights* : données générales sur la page.
- *account_insights* : données sur la page triées par jour.

Pour terminer, cliquez sur le bouton *Create* en haut à droite.

:::warning
N'oubliez pas de nommer votre source avant de la créer. Le nom technique ne peut pas être modifié après la création de la source et sera utilisé pour essayer d'ouvrir la source à l'aide du [SDK](/guides/public-cloud/data-platform/landing-page-developers-python-sdk).
:::

Pour en savoir plus sur l'API X, suivez [ce lien](https://developer.X.com/en/docs/api-reference-index).
