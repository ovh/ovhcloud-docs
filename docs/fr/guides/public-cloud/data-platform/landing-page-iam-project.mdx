## Que couvre l'IAM projet ?

L'IAM projet gère l'accès au sein d'un seul projet : les membres de l'équipe qui le construisent, et les utilisateurs finaux qui consomment les applications qu'il déploie.

<img className="thumbnail" alt="Que couvre l'IAM projet ? — Page d'accueil Identity Access Manager" src="/images/public-cloud/data-platform/product/iam/project-iam/picts/homepage-iam.png" loading="lazy" />

Trois éléments se trouvent ici.

**Applications** répertorie chaque application et API déployée dans le projet, et c'est là que la page de connexion de chacune est définie : son design, son URL d'accès, et les modes d'authentification qui y sont proposés.

**Auth providers** configure les annuaires contre lesquels les utilisateurs s'authentifient, du SSO SAML, JWT et OpenID jusqu'aux fournisseurs MFA, en plus des trois fournisseurs que chaque projet embarque par défaut.

**Utilisateurs, rôles et groupes** est le versant autorisation : quels principaux existent, ce qu'ils sont autorisés à faire, et comment ces droits sont regroupés.

L'authentification multifacteur est gérée avec les fournisseurs d'authentification, et s'applique uniquement à la méthode Projet ID. Pour un fournisseur externe, utilisez le MFA propre à ce fournisseur plutôt que celui de la platform.
