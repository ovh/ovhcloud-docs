## Objectif

:::warning
ForePaaS Legacy Platform n'accepte plus les nouvelles inscriptions. Si votre entreprise souhaite démarrer sur la platform, veuillez utiliser [OVHcloud Data Platform](https://eu.dataplatform.ovh.net/).
:::

Se connecter à OVHcloud Data Platform peut se faire de deux façons :

- en se connectant à l'aide d'un compte OVHcloud
- en se connectant à l'aide d'un compte local Data Platform (invitation requise)

<img className="thumbnail" alt="signup" src="/images/public-cloud/data-platform/product/organisations/picts/signup-option-both.png" loading="lazy" />

## Inscription avec un compte OVHcloud

:::info
Il s'agit de la méthode recommandée pour se connecter à Data Platform.
:::

Vous pouvez vous connecter à Data Platform à l'aide d'un compte OVHcloud en appuyant sur le bouton bleu de la page d'inscription/connexion.

<img className="thumbnail" alt="signup" src="/images/public-cloud/data-platform/product/organisations/picts/signup-option-ovh.png" loading="lazy" />

Vous aurez alors la possibilité d'utiliser un compte existant ou d'en créer un nouveau à cet endroit.

<img className="thumbnail" alt="signup" src="/images/public-cloud/data-platform/product/organisations/picts/signup-option-ovh2.png" loading="lazy" />

## Inscription avec un compte local Data Platform

:::warning
Pour utiliser cette option, il est **obligatoire d'[avoir été invité](/guides/public-cloud/data-platform/iam-users#gérer-les-utilisateurs-de-liam-de-lorganisation) dans une Organisation Data Platform existante** par un administrateur de votre entreprise au préalable. Par conséquent, au moins une personne de votre organisation doit s'être inscrite [à l'aide d'un compte OVHcloud](/guides/public-cloud/data-platform/manage-organizations-signin-signup#inscription-avec-un-compte-ovhcloud).
:::

Si vous rejoignez des membres de votre organisation déjà inscrits sur la platform, vous pouvez remplir le formulaire pour vous inscrire sur la platform à l'aide d'une combinaison e-mail et mot de passe.

<img className="thumbnail" alt="signup" src="/images/public-cloud/data-platform/product/organisations/picts/signup-option-local.png" loading="lazy" />

:::warning
Pour utiliser cette option, il est **obligatoire d'[avoir été invité](/guides/public-cloud/data-platform/iam-users#gérer-les-utilisateurs-de-liam-de-lorganisation) dans une Organisation Data Platform existante** par un administrateur de votre entreprise au préalable. Par conséquent, au moins une personne de votre organisation doit s'être inscrite [à l'aide d'un compte OVHcloud](/guides/public-cloud/data-platform/manage-organizations-signin-signup#inscription-avec-un-compte-ovhcloud).
:::
