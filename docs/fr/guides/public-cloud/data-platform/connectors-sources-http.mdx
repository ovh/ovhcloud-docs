## Objectif

*HTTP* est un protocole d'application standard qui vous permet d'importer des fichiers depuis une URL ou une adresse IP.

Veuillez noter que ce connecteur fonctionne uniquement si les fichiers sont directement listés sur une page HTML.
Dans la plupart des usages modernes, vous voudrez utiliser le [connecteur HTTP REST](/guides/public-cloud/data-platform/connectors-sources-rest).

<img className="thumbnail" alt="HTTP Files" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/http/picts/http-connector-selection.png" loading="lazy" />

## Ajouter une source HTTP (pour des fichiers)

### Vue d'ensemble de l'écran de configuration

Une fois que vous avez trouvé *HTTP Files* dans le **Platform Store**, cliquez sur *Sélectionner* et vous pourrez voir l'écran de configuration comme illustré ci-dessous :

<img className="thumbnail" alt="HTTP Files" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/http/picts/http-config.png" loading="lazy" />

### Fichiers et tailles pris en charge

Même si le connecteur HTTP est capable de lister tous les fichiers de votre serveur, gardez à l'esprit que l'extraction de métadonnées dans le [Connectors Analyzer](/guides/public-cloud/data-platform/landing-page-connectors-analyzer) ne prend en charge que les types de fichiers suivants : .csv, .xls, .xlsx, .xml, .json et .parquet.

De plus, il existe des limites de taille de fichier pour inspecter les données à la volée à l'aide de l'extraction de métadonnées, en particulier pour :

- Extraction complète : ~900 Mo
- Extraction d'échantillon : ~2,5 Go

### Configurer votre source

Vous aurez besoin des paramètres suivants pour configurer votre source :

- **URL** :  Adresse IP ou d'hôte avec un port (exemple : `127.0.0.1:8888`).
- **Vérification SSL (optionnel)** : Si vous souhaitez configurer une connexion sécurisée.
- **User/Password (optionnel)** : Si vous devez vous authentifier via un identifiant et un mot de passe

Cliquez sur *Connecter* pour tester votre connexion. Si la connexion est valide, les fichiers détectés seront affichés dans une liste comme sur l'image ci-dessous :

<img className="thumbnail" alt="HTTP Files" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/http/picts/http-filelist.png" loading="lazy" />

Cochez les fichiers que vous souhaitez importer sur la Platform et cliquez sur **Créer** en haut à droite pour créer la source.

:::info
Notez que vous pouvez cliquer sur *Fetch* pour actualiser la liste de fichiers, en cas de changements sur le serveur.
:::
