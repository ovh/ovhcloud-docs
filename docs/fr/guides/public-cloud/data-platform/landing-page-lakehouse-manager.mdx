## Qu'est-ce que le Lakehouse Manager ?

Le Lakehouse Manager est l'endroit où vivent les données d'un projet. C'est un lakehouse serverless construit sur [Apache Iceberg](https://iceberg.apache.org/), unifiant le stockage data lake et data warehouse dans un seul service : aucun cluster à dimensionner, et un format de table ouvert unique pour les fichiers bruts comme pour les tables analytiques.

<img className="thumbnail" alt="LHM" src="/images/public-cloud/data-platform/product/lakehouse-manager/picts/lakehouse-home.png" loading="lazy" />

Les données sont organisées en [datasets](/guides/public-cloud/data-platform/lakehouse-manager-datasets), qui regroupent des [tables](/guides/public-cloud/data-platform/lakehouse-manager-tables) de la même façon qu'un schéma regroupe des relations. Les tables portent des [attributs](/guides/public-cloud/data-platform/lakehouse-manager-attributes) avec leurs propres types et contraintes, et chaque écriture est versionnée, de sorte que [Time Travel](/guides/public-cloud/data-platform/lakehouse-manager-time-travel) peut lire une table telle qu'elle se présentait à un instant antérieur. Les [buckets](/guides/public-cloud/data-platform/lakehouse-manager-buckets) contiennent des fichiers non structurés et semi-structurés aux côtés de ces tables, et l'[Explorer](/guides/public-cloud/data-platform/lakehouse-manager-explorer) permet de parcourir les deux.

Deux capacités s'appliquent à l'ensemble du store. Le [lineage](/guides/public-cloud/data-platform/lakehouse-manager-lineage) cartographie la façon dont les données circulent dans le projet, depuis les pipelines qui alimentent une table jusqu'aux tables construites à partir d'elle. Les [policy tags](/guides/public-cloud/data-platform/lakehouse-manager-policy-tags) appliquent un contrôle d'accès jusqu'au niveau de l'attribut individuel, évalué via des conditions CEL par rapport à l'identité IAM de l'appelant.

Les tables sont alimentées par le [Data Processing Engine](/guides/public-cloud/data-platform/landing-page-dpe) à partir de sources enregistrées dans [Connectors](/guides/public-cloud/data-platform/landing-page-connectors), et lues par l'[Analytics Manager](/guides/public-cloud/data-platform/landing-page-analytics-manager).
