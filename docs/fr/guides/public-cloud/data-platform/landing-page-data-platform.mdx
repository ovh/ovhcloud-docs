## Qu'est-ce que Data Platform ?

Data Platform est une platform managée pour construire des produits de données, avec les décisions d'infrastructure déjà prises : il n'y a pas de cluster à dimensionner, pas d'orchestrateur à faire tourner et pas de pipeline de déploiement à construire. Connecter des sources, stocker et modéliser les données, les traiter, les analyser et exposer le résultat comme une API ou une application sont tous provisionnés et exploités par la platform, derrière quatre niveaux d'automatisation, de sorte que l'effort porte sur la logique métier plutôt que sur la logistique.

<img className="no-zoom" src="/images/public-cloud/data-platform/product/picts/automation_levels.png" alt="Les quatre niveaux d'automatisation" loading="lazy" />

Un [projet](/guides/public-cloud/data-platform/manage-projects) est l'unité de travail et l'unité d'isolation. Il contient les sources, les tables, les buckets, les pipelines, les requêtes, les dashboards, les API et les apps qui composent un système de données, ainsi que les règles d'accès qui s'y appliquent. Créer un projet déploie plus de 60 microservices et provisionne des machines dans la région cloud sélectionnée en moins de huit minutes, sans intervention supplémentaire.

:::info
L'accès à un projet est généralement partagé de manière collaborative selon des lignes de rôles : un groupe travaille sur l'ingestion et la transformation, un autre sur l'analytique, un autre sur la couche applicative. L'[Identity Access Manager](/guides/public-cloud/data-platform/landing-page-iam) décide qui peut lire et modifier quoi, jusqu'aux attributs individuels d'une table.
:::

Si Data Platform est nouveau pour vous, le moyen le plus rapide de démarrer est le guide en six étapes qui construit une application fonctionnelle sur des données d'exemple. À partir de là, la documentation des [services](/guides/public-cloud/data-platform/landing-page-services) couvre chaque composant dans l'ordre où les données y circulent.
