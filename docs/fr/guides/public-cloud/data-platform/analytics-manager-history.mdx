## Objectif

L'onglet historique vous permet de voir la liste des dernières exécutions de requêtes telles que :

- les requêtes exécutées depuis l'interface de l'Analytics Manager
- les requêtes transmises depuis une [API](/guides/public-cloud/data-platform/landing-page-app-services-apis) (ou une [application](/guides/public-cloud/data-platform/landing-page-app-services-apps))
- les requêtes exécutées à la volée dans l'[Explorer du Lakehouse Manager](/guides/public-cloud/data-platform/lakehouse-manager-explorer)

<img className="thumbnail" alt="history1" src="/images/public-cloud/data-platform/product/am/picts/history1.png" loading="lazy" />

Une colonne *SQL* est affichée pour montrer la **requête réellement exécutée par l'Analytics Manager** en coulisses. Cette requête est automatiquement convertie à partir de la requête originale écrite par l'utilisateur (soit en [SQL](/guides/public-cloud/data-platform/analytics-manager-queries-sql-editor#écrire-des-requêtes-dans-léditeur-sql), soit à l'aide du [visual builder](/guides/public-cloud/data-platform/analytics-manager-queries-visual-builder)) qui a généralement une syntaxe bien plus simple. Généralement, l'Analytics Manager va automatiquement :

- ajouter les informations de moteur/base de données/schéma lorsque nécessaire pour router la requête vers la [source de données](/guides/public-cloud/data-platform/landing-page-connectors-sources) correcte
- remplacer les [attributs virtuels](/guides/public-cloud/data-platform/lakehouse-manager-attributes#attributs-virtuels) par leur définition SQL correspondante
