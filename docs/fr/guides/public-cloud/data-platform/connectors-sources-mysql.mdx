## Objectif

MySQL est un système de gestion de bases de données relationnelles open source. La Platform vous permet d'utiliser les tables d'une base de données MySQL comme sources pour votre application.

<img className="thumbnail" alt="MySQL" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/mysql/picts/connector-selection.png" loading="lazy" />

## Ajouter une source MySQL sur la Platform

### Configurer votre connexion

Lors de la création de la source, vous devrez renseigner les informations suivantes :

- **Host** : le nom d'hôte de la base de données MySQL.
- **Port** : le port de la base de données MySQL.
- **Database** : le nom de la base de données MySQL.
- **Nom d'utilisateur** : le nom d'utilisateur de la base de données MySQL.
- **Mot de passe** : le mot de passe associé au nom d'utilisateur que vous utilisez.
- **SSL** : si cette option est activée, elle chiffre les informations échangées entre la Data Platform et la base de données.

### Sélectionner les tables souhaitées

Une fois la connexion établie avec votre base de données MySQL, vos tables sont récupérées et affichées :

<img className="thumbnail" alt="Sélection des tables MySQL" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/mysql/picts/select-tables.png" loading="lazy" />

Sélectionnez les tables à inclure dans la source en cochant les cases situées à gauche du nom de la table, comme indiqué sur l'image ci-dessus.

:::info
Si l'état de la base de données change, vous pouvez utiliser le bouton *Fetch* pour actualiser les tables affichées et les inclure dans votre source.
:::

Une fois ces étapes réalisées, cliquez sur le bouton *Créer* en haut à droite.

:::warning
N'oubliez pas de nommer votre source avant de la créer. Le nom technique ne peut plus être modifié après la création de la source et sera utilisé lors de l'ouverture de la source via le [SDK](/guides/public-cloud/data-platform/landing-page-developers-python-sdk).
:::
