## Objectif

Dropbox est un service de stockage cloud utilisé pour le partage de fichiers et le travail collaboratif. La Platform vous permet de récupérer les données que vous avez stockées sur Dropbox et de les importer directement dans votre platform.

<img className="thumbnail" alt="DB1" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/DB1.png" loading="lazy" />

## Ajouter une source Dropbox sur la Platform

### Vue d'ensemble de l'écran de configuration

Une fois que vous avez trouvé *Dropbox* dans le **Platform Store**, cliquez sur *Sélectionner* et vous pourrez voir l'écran de configuration comme illustré ci-dessous -

<img className="thumbnail" alt="DB2" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/DB2.png" loading="lazy" />
 

### Découvrir comment obtenir un token Dropbox

- Rendez-vous sur https://www.dropbox.com/developers/apps/create

Vous verrez l'écran ci-dessous pour Create an App –

<img className="thumbnail" alt="DB3" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/DB3.png" loading="lazy" />

- Suivez les étapes suivantes –

   1. Choisissez une `API`

   2. Choisissez le type d'accès dont vous avez besoin - `App Folder` ou `Full Dropbox`

   3. Donnez un `Name` à votre application

   4. Cliquez sur `Create app`
 

- Une fois votre application créée, vous serez redirigé vers la page des paramètres –

<img className="thumbnail" alt="DB5" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/DB5.png" loading="lazy" />

- Allez dans l'onglet `Permissions`, puis assurez-vous que les permissions `files.metadata.read` et `files.content.read` sont activées. Cliquez ensuite sur Submit.

<img className="thumbnail" alt="DB5" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/dropboxmetas.png" loading="lazy" />

<img className="thumbnail" alt="DB6" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/DB6.png" loading="lazy" />

- De retour dans `Settings` tb Cliquez sur `Generate` sous `Generated access token`

- Réglez `Access token expiration` sur `No expiration`

- Copiez votre `token`

### Configurer votre source

Lors de la création de la source, vous devrez renseigner les informations suivantes :

- Token : La clé d'accès à votre application (générée à l'étape précédente).
- Path : Le chemin vers le dossier.

:::info
Si le token est un token d'application lié à un dossier, vous n'avez pas besoin de renseigner le champ Path
:::

Une fois ces informations ajoutées, cliquez sur *Connecter* puis sur le bouton *Créer* en haut à droite.

:::warning
N'oubliez pas de nommer votre source avant de la créer. Le nom technique ne peut plus être modifié après la création de la source et sera utilisé lors de l'ouverture de la source via le [SDK](/guides/public-cloud/data-platform/landing-page-developers-python-sdk).
:::
