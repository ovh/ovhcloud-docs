## Objectif

Les données affichées dans les différents tableaux de bord d'une application sont souvent très différentes, provenant de sources variées.
Cela implique parfois que certaines données, qui devraient être affichées ensemble, n'ont pas le même ordre de grandeur ou la même unité. Pour pallier cela, il est possible de gérer, champ par champ :

- L'unité
- Le facteur multiplicateur
- Les séparateurs décimaux ou de milliers
- Le nombre de décimales avec lequel la valeur est affichée

Par ailleurs, pour les échelles, il est possible d'indiquer la temporalité des données. Tout cela est configurable dans l'onglet *Formatter* d'une application.

## Interface

L'onglet Formatter est divisé en 3 parties correspondant aux 2 types de données utilisées (*Measures et Scales*) et à un élément essentiel à la visualisation des données chiffrées : *Separators*.

<img className="thumbnail" alt="Figure 1 : Édition d'une mesure" src="/images/public-cloud/data-platform/product/app-manager/picts/edit-measure.png" loading="lazy" />
*Figure 1 : Édition d'une mesure*

Dans cet onglet, une mesure est le nom de l'un des champs disponibles dans le Lakehouse Manager. Ces champs représentent chacun une valeur. Le panneau d'édition présenté dans la figure 1 vous permet de modifier :

- **Unit** : l'unité de mesure de cette donnée (euros, heures, kilomètres, etc.)
- **Round** : le nombre de chiffres souhaité après la virgule
- **Multiplier** : le multiplicateur permet de modifier dynamiquement la donnée. Ce multiplicateur est particulièrement pertinent lorsque la donnée est un pourcentage sous la forme d'un nombre entre 0 et 1, qui doit donc être multiplié par 100.

<img className="thumbnail" alt="Figure 2 : Édition d'une dimension" src="/images/public-cloud/data-platform/product/app-manager/picts/editing-scale.png" loading="lazy" />
*Figure 2 : Édition d'une échelle*

Contrairement aux mesures qui représentent une valeur, les échelles sont des champs qui permettent le regroupement et la segmentation des données. Les échelles les plus courantes sont les dimensions temporelles, comme les dates, les mois ou les années. Le panneau d'édition présenté dans la figure 2 vous permet d'éditer :

- Le type d'échelle (par exemple : temporel)
- Le sous-type, donnant un peu plus de détail sur le type. En effet, une donnée temporelle peut être un jour, un mois, une année donné, etc. 
- Le format d'affichage

<img className="thumbnail" alt="Figure 3 : Édition d'un séparateur" src="/images/public-cloud/data-platform/product/app-manager/picts/editing-separator.png" loading="lazy" />
*Figure 3 : Édition d'un séparateur*

Enfin, il existe deux types de séparateurs :

- Decimals
- Thousands

Ces séparateurs peuvent être n'importe quel caractère et seront insérés pour rendre la valeur plus lisible.
