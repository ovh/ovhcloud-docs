## Objectif

L'action *Delete Bucket* vous permet de **supprimer des données d'un bucket, y compris les dossiers et les fichiers.** Vous pouvez choisir de supprimer l'intégralité du contenu du bucket ou de cibler des chemins spécifiques pour la suppression.

## Configurer une action Delete Bucket

Pour créer une nouvelle action, accédez à l'**onglet Action** du Data Processing Engine (DPE), cliquez sur **Nouvelle action** et sélectionnez l'action *Delete Bucket*.

<img className="thumbnail" alt="Configurer une action Delete Bucket — Delete bucket action" src="/images/public-cloud/data-platform/product/dpe/actions/delete-bucket/picts/delete-bucket-action-1.png" loading="lazy" />

### Choisir les éléments à supprimer

Après avoir sélectionné l'action *Delete Bucket*, une liste de vos [buckets du Projet](/guides/public-cloud/data-platform/lakehouse-manager-buckets) s'affichera sur le côté gauche de l'écran. Ce panneau vous permet de parcourir et de sélectionner les données que vous souhaitez supprimer.

<img className="thumbnail" alt="Choisir les éléments à supprimer — Delete bucket action" src="/images/public-cloud/data-platform/product/dpe/actions/delete-bucket/picts/delete-bucket-action-2.png" loading="lazy" />

1.  **Sélectionner le bucket cible :** Localisez le bucket depuis lequel vous souhaitez supprimer des données.
2.  **Développer le contenu du bucket (optionnel) :** Pour voir les dossiers et fichiers à l'intérieur d'un bucket, cliquez sur le **nom du bucket**. Cela développera la vue, affichant son contenu.
<img className="thumbnail" alt="Choisir les éléments à supprimer — Delete bucket action (2)" src="/images/public-cloud/data-platform/product/dpe/actions/delete-bucket/picts/delete-bucket-action-3.png" loading="lazy" />
3.  **Choisir les éléments à supprimer :**
    -   Pour supprimer un **bucket entier** et tout son contenu, cliquez sur l'**icône de flèche droite** (▶) à côté du nom du bucket.
    -   Pour supprimer un **dossier spécifique** (et tout son contenu), naviguez dans le bucket et cliquez sur l'**icône de flèche droite** (▶) à côté du nom du dossier souhaité.
    -   Pour supprimer un **fichier individuel**, naviguez dans le bucket et le dossier où se trouve le fichier, puis cliquez sur l'**icône de flèche droite** (▶) à côté du nom du fichier.
    <img className="thumbnail" alt="Choisir les éléments à supprimer — Delete bucket action (3)" src="/images/public-cloud/data-platform/product/dpe/actions/delete-bucket/picts/delete-bucket-action-4.png" loading="lazy" />
4.  **Vérifier les éléments sélectionnés :** À chaque clic sur la flèche droite, les buckets, dossiers ou fichiers sélectionnés seront déplacés dans la colonne de droite. Cette colonne indique tous les éléments actuellement marqués pour suppression.
<img className="thumbnail" alt="Choisir les éléments à supprimer — Delete bucket action (4)" src="/images/public-cloud/data-platform/product/dpe/actions/delete-bucket/picts/delete-bucket-action-5.png" loading="lazy" />

Vérifiez attentivement les éléments dans la colonne de droite afin de vous assurer que vous ne supprimez que ce qui est prévu. Une fois satisfait de votre sélection, poursuivez avec les étapes finales indiquées par l'interface du DPE pour confirmer la suppression. **Sachez que les actions de suppression sont permanentes et ne peuvent pas être annulées.**
