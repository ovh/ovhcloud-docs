## Objectif

Ce guide fournit des instructions étape par étape pour configurer votre Projet de données afin de faire vos premiers pas dans le FinOps avec un fichier FOCUS.

<img className="thumbnail" alt="Banner" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/banner.png" loading="lazy" />

## Vue d'ensemble

[FOCUS](https://focus.finops.org/) est une spécification au sein du monde FinOps permettant d'exposer la consommation de données à travers plusieurs fournisseurs cloud. Ce guide fournira un exemple de la façon de consommer ce type de fichier au sein de la Data Platform, et de tirer parti de la puissance de superset pour créer des dashboards utiles.

## Prérequis

Avant de commencer, assurez-vous d'avoir :

- Un compte OVHcloud actif avec accès à la facturation

## Configuration étape par étape

## 1. Récupérer le fichier FOCUS

Nous devons disposer d'un fichier au format FOCUS pour développer ce cas d'usage. Vous pouvez facilement extraire un fichier CSV avec la consommation de votre compte OVHcloud en suivant ce lien : [OVHcloud Focus Extractor](https://finops.labs.ovh.net/).

<img className="thumbnail" alt="1. Récupérer le fichier FOCUS — Finops lab" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/finops-lab-1.png" loading="lazy" />

Vous pouvez vous connecter à l'interface via le SSO OVHcloud. Cet outil est un POC développé par notre équipe interne OVHcloud, en attendant que nous travaillions à fournir une méthode plus standard pour extraire un fichier au format FOCUS.

<img className="thumbnail" alt="1. Récupérer le fichier FOCUS — Finops lab (2)" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/finops-lab-2.png" loading="lazy" />

Une fois connecté, vous pouvez cliquer sur "Load Services Consumption".

<img className="thumbnail" alt="1. Récupérer le fichier FOCUS — Finops lab (3)" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/finops-lab-3.png" loading="lazy" />

Une fois la table créée, vous pouvez maintenant cliquer sur "Export to CSV" pour extraire un fichier complet avec votre consommation.

<img className="thumbnail" alt="1. Récupérer le fichier FOCUS — Finops lab (4)" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/finops-lab-4.png" loading="lazy" />

Vous disposez maintenant d'un CSV au format FOCUS qui peut être chargé au sein de la Data Platform

## 2. Charger le fichier FOCUS dans le Lakehouse

### 2.1. Créer la source de données

Vous pouvez maintenant vous rendre sur [`Data Platform`](https://eu.dataplatform.ovh.net), à l'intérieur du `Project` de votre choix, puis dans la section `Connectors`, et enfin `Sources` afin de créer une nouvelle source `File Upload`.

<img className="thumbnail" alt="2.1. Créer la source de données — Datacatalog" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/datacatalog-1.png" loading="lazy" />

Vous pouvez nommer votre source `focus`, et ajouter le fichier `export.csv` que vous avez téléchargé à l'étape précédente. Vous pouvez maintenant cliquer sur `Create`.

<img className="thumbnail" alt="2.1. Créer la source de données — Datacatalog (2)" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/datacatalog-2.png" loading="lazy" />

Maintenant que le fichier est chargé, vous pouvez vous rendre dans la section `Explorer`, puis cliquer sur votre nouvelle source `finops`, puis démarrer l'analyse du fichier en cliquant sur `export.csv`. Après quelques secondes, votre fichier devrait être analysé avec succès.

<img className="thumbnail" alt="2.1. Créer la source de données — Datacatalog (3)" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/datacatalog-3.png" loading="lazy" />

### 2.3. Charger les données dans le Lakehouse

Vous pouvez maintenant vous rendre dans la section `Lakehouse Manager`, puis `Tables`. Vous pouvez cliquer sur `New Table` et `Create from a Connectors source`. Sélectionnez votre fichier `export.csv`, puis cliquez sur `next`, renommez la table en `consumption` et cliquez sur `create`.

<img className="thumbnail" alt="2.3. Charger les données dans le Lakehouse — Lakehouse" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/lakehouse-1.png" loading="lazy" />
<img className="thumbnail" alt="2.3. Charger les données dans le Lakehouse — Lakehouse (2)" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/lakehouse-2.png" loading="lazy" />
<img className="thumbnail" alt="2.3. Charger les données dans le Lakehouse — Lakehouse (3)" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/lakehouse-3.png" loading="lazy" />
<img className="thumbnail" alt="2.3. Charger les données dans le Lakehouse — Lakehouse (4)" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/lakehouse-4.png" loading="lazy" />

## 3. Créer l'application Superset

Maintenant que toutes les données sont prêtes à être analysées dans le Lakehouse, vous devez créer l'application Apache Superset. Vous pouvez le faire en suivant [ce tutoriel](/guides/public-cloud/data-platform/tutorials-install-apache-superset).

Concernant ce tutoriel, nous considérons que vous l'avez suivi jusqu'à l'étape `Step 5: Create your first Chart` et jusqu'à `3. New Dataset` où vous créez le Dataset pour :

- Database : `trino`
- Schema : `Default dataset`
- Table : `consumption`

<img className="thumbnail" alt="3. Créer l'application Superset — Dataset" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/dataset-1.png" loading="lazy" />

Vous pouvez maintenant cliquer sur `Create Dataset and create dashboard`

## 4. Créer les Charts

Pour l'instant, nous allons créer plusieurs charts, toujours selon le même processus :

- Cliquez sur `Charts`, puis `+ Chart`
- Choisissez le dataset `consumption`

Nous allons parcourir plusieurs charts que vous pouvez créer :

### Effective cost - current

- Type : `Big number with Trendline` 
- Temporal axis : `billingperiodstart`
- Metric : `Billed Cost` agrégat `SUM`
- Comparison Period Lag : `1`
- Show timestamp : true

<img className="thumbnail" alt="Effective cost - current — Chart" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/chart-1.png" loading="lazy" />

### Effective cost - previous month

- Type : `Big number` 
- Metric : `Billed Cost` agrégat `SUM`
- Filters : `billingperiodstart` avec `Range type: advanced` comme dans la capture d'écran
- Display settings
  - Subtitle : `1 month ago`

<img className="thumbnail" alt="Effective cost - previous month — Chart" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/chart-2.png" loading="lazy" />
<img className="thumbnail" alt="Effective cost - previous month — Chart (2)" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/chart-3.png" loading="lazy" />

### Effective cost - 2 month

- Type : `Big number` 
- Metric : `Billed Cost` agrégat `SUM`
- Filters : `billingperiodstart` avec `Range type: advanced` et `- 3 month` et `-2 month`

  - Subtitle : `2 month ago`

## 5. Créer le Dashboard

Maintenant que vous avez beaucoup de charts, vous pouvez les regrouper en un seul endroit : les Dashboards. Cliquez sur `Dashboard`, puis `Create`. Vous pouvez nommer votre dashboard `Billing Summary`, et glisser-déposer tous les charts que vous avez créés précédemment pour finaliser la vue.

<img className="thumbnail" alt="5. Créer le Dashboard — Banner" src="/images/public-cloud/data-platform/getting-further/finops-focus-superset/pics/banner.png" loading="lazy" />
