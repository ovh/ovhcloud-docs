## Objectif

Dans ce guide avancé étape par étape, vous apprendrez à créer vos propres composants d'application personnalisés, qu'il s'agisse de graphiques et de filtres dynamiques, à les personnaliser, à les intégrer dans la platform et bien plus encore.

Ici, vous allez poursuivre le développement de l'application que vous avez créée dans la [première partie du guide de démarrage](/guides/public-cloud/data-platform/landing-page-getting-started).

L'objectif ? Vous fournir tous les outils nécessaires pour créer du code personnalisé à partir des références d'API et des boilerplates fournis.

:::warning
Ceci est un guide avancé destiné aux développeurs, ingénieurs front-end ou architectes d'application. Nous recommandons d'être familiarisé avec les concepts de base du développement front-end.
:::

Voici un **aperçu rapide de ce que nous pourrons réaliser à la fin de ce guide**. Comme vous pouvez le voir, vous ajouterez un composant de carte personnalisé, des options de filtre plus complexes et un style plus soigné pour tous les autres graphiques.
