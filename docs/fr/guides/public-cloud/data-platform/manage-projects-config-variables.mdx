## Sous-domaine du Projet

Le sous-domaine de votre projet est utilisé dans l'URL de base des API de tous les services de la platform. Il s'agit de la **version stringifiée du nom de votre projet**.

Vous pouvez le trouver dans [Identity Access Manager](/guides/public-cloud/data-platform/landing-page-iam) **> Applications > Projet**, à la base du champ *URL*.
