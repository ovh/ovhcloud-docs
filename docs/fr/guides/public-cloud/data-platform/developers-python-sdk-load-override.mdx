## Objectif

Dans une [action Custom](/guides/public-cloud/data-platform/dpe-actions-custom), vous pouvez réutiliser des types d'action existants, en redéfinissant certains paramètres ou en créant des "hooks".

Voici un exemple de réutilisation d'une [action Load](/guides/public-cloud/data-platform/dpe-actions-load), ajoutant une valeur de mapping égale à la date contenue dans le nom du fichier source.

:::info
**Quelques prérequis à respecter :**

1. sélectionnez le module `aggregate` dans les modules requis
1. votre JSON `params` doit suivre le [format requis pour l'action load](/guides/public-cloud/data-platform/dpe-actions-load-advanced-mode)

:::
**Astuce** : vous pouvez d'abord créer votre configuration d'action via une action Load classique, puis copier / coller l'objet JSON "params" dans l'objet JSON `params` de votre action Custom.

```python
import sys,os
from logging import getLogger

from forepaas.core.settings import PARAMS
from forepaas.actions.aggregate.fpaggregate import aggregate

logger = getLogger(__name__)

def override_aggregate(event):
    
    try:
    	# Définit le nom du fichier. peut être récupéré via la segmentation ou les paramètres
	filename = "sales_2020-01-01.csv"
        
        # Redéfinit le nom du fichier source
        path = "/".join(PARAMS["load_from"][0]["source"].split("/")[:-1]) + "/" + filename
        PARAMS["load_from"][0]["source"] = path

        # redéfinit source_date dans le schema
        source_date = filename.replace("sales_","").replace(".csv","")
        PARAMS["schema"]["source_date"] = {"type":"replace", "value": str(source_date)}
        logger.info(f"{filename} {source_date}")
        
        # exécute l'action aggregate (=load), elle utilisera les PARAMS redéfinis.
        aggregate(event)

    except Exception as err: 
        message="error on file:{}: {} L:{}".format(filename,err,sys.exc_info()[2].tb_lineno)
        raise Exception(message)
```
