## Objectif

Vous ou vos coéquipiers maîtrisez déjà [Microsoft Power BI](https://powerbi.microsoft.com/en-us/getting-started-with-power-bi/) ? Si vous souhaitez l'utiliser comme solution d'analyse au-dessus de votre Data Platform, ce guide est fait pour vous.

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-001.png" loading="lazy" />

La configuration se fait en deux parties. Vous devez d'abord [configurer le consommateur sur la Data Platform](#comment-configurer-power-bi-avec-votre-data-platform), puis [configurer le connecteur sur Power BI Desktop](#configuration-sur-power-bi).

## Comment configurer Power BI avec votre Data Platform

Si vous ne l'avez pas encore fait, [ajoutez un nouveau](/guides/public-cloud/data-platform/landing-page-connectors-consumers) consommateur *Power BI* dans les Connectors. Sinon, éditez-le simplement.

Le connecteur Trino pour Power BI étant un projet open source pas encore certifié par Microsoft, vous devez **télécharger l'extension**, soit manuellement depuis [ce lien](https://raw.githubusercontent.com/CreativeDataEU/PowerBITrinoConnector/refs/heads/master/Trino/bin/AnyCPU/Debug/Trino.mez), soit depuis l'interface présentée ci-dessous.

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-download.png" loading="lazy" />

Les utilisateurs de Power BI devront être enregistrés dans l'Identity Access Manager (IAM) d'un Projet afin d'accéder à ses données. Ils n'accèderont qu'aux données associées à leur [clé API secrète](/guides/public-cloud/data-platform/tutorials-generate-api-keys).

Vous pouvez **facilement accorder un accès complet à un nouvel utilisateur Power BI** en lui attribuant le rôle *Analytics Consommateur*. Il s'agit d'un rôle par défaut qui peut être attribué à un groupe, un utilisateur ou un compte de service, et qui fournit les permissions appropriées pour visualiser les données depuis un consommateur externe.

Si vous préférez affiner les permissions, vous pouvez aussi vous rendre dans l'Identity Access Manager de votre projet et accorder à l'utilisateur les permissions spécifiques suivantes :

-   *Data Manager | Source | Read* et *Data Manager | Table | Read* : pour importer les données d'une table dans Power BI
-   *Advanced Data Access Control | Read* : pour accéder aux données au sein du projet

:::warning
Tout utilisateur ayant le rôle **Admin** aura également accès aux données du Projet
:::

## Configuration sur Power BI

Une fois que vous avez [téléchargé](https://raw.githubusercontent.com/CreativeDataEU/PowerBITrinoConnector/refs/heads/master/Trino/bin/AnyCPU/Debug/Trino.mez) le fichier connecteur *.MEZ*, suivez cette procédure pour l'utiliser sur **Power BI Desktop**.

### Autoriser votre Power BI Desktop à utiliser un connecteur personnalisé

Ouvrez *Power BI Desktop*. Cliquez sur **File** dans l'en-tête.

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-install1.png" loading="lazy" />

Ouvrez la section **Options and settings**, puis sélectionnez **Options**.

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-install2.png" loading="lazy" />

Trouvez la section **Global > Security**, puis activez l'option suivante : *(Not Recommended) Allow any extension to load without validation or warning*.

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-install3.png" loading="lazy" />

Cela vous permettra de récupérer des données depuis une source pas encore certifiée par Microsoft, en l'occurrence le connecteur Trino.

Maintenant, **fermez Power BI Desktop** pour que les changements soient appliqués.

### Installer le connecteur

Créez ce dossier dans votre répertoire utilisateur :

```yaml
C:\Users\[Your_Windows_User_Name]\Documents\Microsoft Power BI Desktop\Custom Connectors
```

Si les dossiers *Microsoft Power BI Desktop\Custom Connectors* existent déjà, vous n'avez pas besoin de les créer.

:::warning
Assurez-vous que les dossiers portent exactement les mêmes noms que ci-dessus, sinon vous ne pourrez pas retrouver le connecteur Trino dans Power BI Desktop.
:::

Copiez le fichier connecteur *.MEZ* que vous avez précédemment téléchargé dans ce nouveau répertoire.

Vous pouvez maintenant redémarrer Power BI Desktop.

### Importer vos premières données depuis la Data Platform

Cliquez sur **Get Data**.

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-get-data.png" loading="lazy" />

Recherchez *Trino*, et sélectionnez le connecteur.

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-forepaas-connector.png" loading="lazy" />

Vous devez maintenant saisir l'[URL du Projet Data Platform](/guides/public-cloud/data-platform/manage-projects-config-variables) auquel vous souhaitez vous connecter. Vous trouverez facilement cette URL sur la page du consommateur sur le projet Data Platform. Le port est 443.

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-dp-url-consumer.png" loading="lazy" />

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-dp-url.png" loading="lazy" />

Si vous n'êtes pas encore authentifié sur ce Projet, il vous sera demandé de vous authentifier à cette étape.

Choisissez le mode Basic et utilisez **API key** comme User name et **Secret key** comme Password, tels que configurés pour votre Service-Account/Utilisateur dans l'IAM.

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-auth1.png" loading="lazy" />

Une fois authentifié avec succès, appuyez sur **connect** pour continuer.

Vous verrez alors vos datasets, schémas et tables en mode aperçu.

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-import.png" loading="lazy" />

Vous pouvez maintenant créer vos premières visualisations sur vos données depuis votre projet Data Platform en utilisant Power BI Desktop.

:::info
Si les données sont mises à jour sur la Data Platform, les graphiques peuvent être rafraîchis manuellement avec les dernières données en appuyant sur le bouton de rafraîchissement dans l'en-tête de Power BI.
:::

<img className="thumbnail" alt="pbi" src="/images/public-cloud/data-platform/product/connectors/consumers/power-bi/picts/powerbi-dashboard.png" loading="lazy" />
