## Comment les tutoriels sont organisés

Du streaming d'un topic Kafka à la publication d'un dashboard Superset, chaque tutoriel ici est autonome, et la plupart sont fournis avec le code et les exemples de données nécessaires. Ils sont regroupés ci-dessous selon leur place dans le parcours des données.

:::info
Les tutoriels supposent l'existence d'un projet opérationnel. Si vous n'en avez pas encore, le guide [Premiers pas](/guides/public-cloud/data-platform/landing-page-getting-started) construit une première application de bout en bout, et ces tutoriels prennent le relais à partir de là.
:::

Ils se répartissent en quatre groupes.

**Configuration et paramétrage du projet** couvre le travail autour d'un projet : développer votre propre application, exporter et importer une configuration, générer des clés d'API, et le versionnage.

**Ingestion et transformation des données** couvre l'entrée des données et leur remodelage : Kafka, flottes IoT, le SDK Python, SQL, jeux de données externes, et la segmentation.

**Analytics et BI** couvre la relecture des données : Trino, PySpark, AI Endpoints, l'analyse de facturation, et Apache Superset.

**Export et gestion des données** couvre les limites : dossiers d'export datés, conditions de rôle sur les buckets, et gestion d'événements personnalisés.

Commencez par la [checklist de projet](/guides/public-cloud/data-platform/tutorials-project-checklist) si vous mettez en place un nouveau projet et souhaitez avoir une vue d'ensemble du travail avant les détails.
