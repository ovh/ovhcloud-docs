## Objectif

Pour extraire les métadonnées d'une source pour la première fois, sélectionnez simplement un objet source dans le panneau de gauche. Cela analysera un échantillon de 1 000 lignes de la source pour obtenir les informations suivantes :

- noms des attributs
- types des attributs
- valeurs minimale et maximale des attributs
- card. de l'attribut, c'est-à-dire le nombre de valeurs uniques dans l'échantillon
- valeurs nulles des attributs

<img className="thumbnail" alt="analyzer" src="/images/public-cloud/data-platform/product/connectors/analyzer/picts/analyzer-1.png" loading="lazy" />

Pour extraire à nouveau les métadonnées d'une source, vous pouvez cliquer sur le bouton **Extraire métadonnées** en haut à droite. Choisissez ensuite *Sample data* ou *Complete data* pour extraire sur les 1 000 premières lignes ou sur la totalité de la table respectivement.

:::info
Une extraction de métadonnées *complète* peut prendre un certain temps selon la taille de la table sélectionnée
:::

<img className="thumbnail" alt="analyzer" src="/images/public-cloud/data-platform/product/connectors/analyzer/picts/analyzer-2.png" loading="lazy" />

:::warning
Si votre extraction de métadonnées échoue, vérifiez pourquoi en consultant les **logs de l'onglet Jobs** des Connectors.
:::

Une fois les métadonnées extraites, vous pouvez commencer à définir des formats de structure standard pour vos données en ajoutant des règles de blueprint à n'importe quel attribut.

<img className="thumbnail" alt="analyzer" src="/images/public-cloud/data-platform/product/connectors/analyzer/picts/analyzer-3.png" loading="lazy" />
