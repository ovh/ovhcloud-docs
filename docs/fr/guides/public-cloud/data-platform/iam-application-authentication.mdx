## Objectif

Lorsqu'une application est déployée sur la platform, elle est automatiquement créée dans l'Identity Access Manager en tant qu'entité distincte pour laquelle vous pouvez gérer les **protocoles d'authentification**. Les applications incluent :

- **Vos applications analytiques** : des applications individuelles qui peuvent être déployées depuis l'[APP Manager](/guides/public-cloud/data-platform/landing-page-app-services-apps), ainsi que les consumers que vous pouvez connecter dans les [Connectors](/guides/public-cloud/data-platform/landing-page-connectors-consumers). Cela inclut généralement des interfaces conviviales pour exposer les données, telles que des dashboards, des outils de reporting ou d'alerting.

- **Identity Access Manager** : accessible en tant qu'URL indépendante, `https://project-name.eu.dataplatform.ovh.net/iam`, l'application externe Identity Access Manager est utilisée lorsque vous avez besoin que des utilisateurs (par exemple l'administrateur d'une application donnée) gèrent sa base d'utilisateurs sans avoir à accéder à la Platform.

Pour chaque application déployée, la platform vous permet de configurer les informations de l'application, les modes d'authentification visibles sur la page de connexion, ainsi que le style de cette page de connexion.

<img className="thumbnail" alt="aperçu" src="/images/public-cloud/data-platform/product/iam/project-iam/application/picts/application-overview2.png" loading="lazy" />

## Informations de l'application

- **ID** : l'ID de l'application dans l'IAM
- **Name** : le nom de l'application affiché par défaut sur sa page de connexion
- **Version** : version de l'application actuellement déployée (non requis, uniquement pour des cas d'usage personnalisés)
- **Description** : description de l'application
- **Tags** : tags de l'application
- **URL** : URL de base de l'application.
- **Bouton « Share URL »** : envoie par e-mail l'URL de l'application aux utilisateurs ou groupes d'utilisateurs sélectionnés.

:::info
Notez que vous pouvez modifier le modèle dans l'Identity Access Manager *Settings > Email > Application invitation > Edit*
:::

- **Display URL** : titre de l'application utilisé dans l'e-mail envoyé par le bouton « Share URL »

## Authentication Mode

La page d'authentification est un élément important de votre application Platform : c'est la page sur laquelle les utilisateurs se connectent pour accéder au contenu de l'application.

La liste **Authentication Mode** vous permet de gérer quelles méthodes d'authentification sont affichées sur la page de connexion de l'application. L'onglet [Auth. Provider](/guides/public-cloud/data-platform/iam-auth-providers) de votre IAM vous permet de configurer les méthodes d'authentification pouvant être utilisées dans votre projet, et ces méthodes peuvent ensuite être affichées ou masquées pour personnaliser visuellement votre page de connexion.

:::warning
Il s'agit d'une configuration de visibilité pure, et non d'un moyen d'empêcher les utilisateurs de se connecter à l'application via certains modes d'authentification.
:::

### Afficher un fournisseur d'authentification sur la page de connexion d'une application

Cliquez sur **Applications** et modifiez l'application souhaitée.

<img className="thumbnail" alt="Afficher un fournisseur d'authentification sur la page de connexion d'une application — Applications2" src="/images/public-cloud/data-platform/product/iam/project-iam/application/picts/applications2.png" loading="lazy" />

Repérez le panneau **Authentication Mode**

<img className="thumbnail" alt="Afficher un fournisseur d'authentification sur la page de connexion d'une application — Authentication mode21" src="/images/public-cloud/data-platform/product/iam/project-iam/application/picts/authentication-mode21.png" loading="lazy" />

Ajoutez votre nouveau fournisseur s'il n'apparaît pas automatiquement. Assurez-vous que les fournisseurs d'authentification de votre choix ne sont pas définis comme *masqués*. Ceux qui le sont ne seront pas visibles depuis la page de connexion de l'application.

<img className="thumbnail" alt="Afficher un fournisseur d'authentification sur la page de connexion d'une application — Authentication mode22" src="/images/public-cloud/data-platform/product/iam/project-iam/application/picts/authentication-mode22.png" loading="lazy" />

:::warning
Il n'est pas possible de **désactiver** un fournisseur d'authentification pour une application spécifique. Par exemple, un utilisateur déjà connecté via Azure AD pourra toujours accéder à l'application même si Azure AD est défini comme masqué sur la page de connexion de l'application.
:::

### Lien vers un fournisseur d'authentification spécifique

Vous pouvez générer des liens URL pour accéder à une page d'authentification spécifique pour votre application, même si vous avez plusieurs fournisseurs d'authentification actifs sur votre projet. Vous aurez besoin de :

- l'URL de votre application
- l'ID de votre méthode d'authentification

Vous pouvez obtenir l'URL de votre application dans les paramètres IAM de votre application :

<img className="thumbnail" alt="Lien vers un fournisseur d'authentification spécifique — App url2" src="/images/public-cloud/data-platform/product/iam/project-iam/application/picts/app-url2.png" loading="lazy" />

Vous pouvez obtenir l'ID de votre fournisseur d'authentification en accédant à sa page de paramètres dans l'IAM et en regardant l'URL :

<img className="thumbnail" alt="Lien vers un fournisseur d'authentification spécifique — Auth url2" src="/images/public-cloud/data-platform/product/iam/project-iam/application/picts/auth-url2.png" loading="lazy" />

Pour accéder à une page d'authentification spécifique pour votre application, utilisez le lien URL :

:::info
**your-app-URL**#/?auth_mode_id=**your-auth-method-ID**
:::

:::warning
Ce lien n'est actuellement valide que pour les applications créées depuis [Application Services](/guides/public-cloud/data-platform/landing-page-app-services), et non pour l'application « Project ».
:::

:::info
Raccourcis :
:::

- Un autre ID pour la méthode d'authentification [*the platform account*](/guides/public-cloud/data-platform/iam-auth-providers#data-platform) est `king`
- Un autre ID pour la méthode d'authentification [*Project*](/guides/public-cloud/data-platform/iam-auth-providers#project) est `password`

## Personnaliser la page de connexion

Le style visuel de votre page de connexion inclut les éléments suivants :

- **Welcome title** : modifie le message de bienvenue sur la page de connexion. S'il est vide, le nom de l'application sera affiché à la place.
- **Welcome message** : le message situé sous le titre de bienvenue
- **Color Theme** : couleur CSS primaire par défaut de la page de connexion
- **Background image** : ajoute une image de fond à la page de connexion.
