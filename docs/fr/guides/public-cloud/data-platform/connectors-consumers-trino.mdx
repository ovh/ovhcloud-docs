## Objectif

Un **consommateur Trino** génère une chaîne de connexion Trino prête à l'emploi en quelques clics. Auparavant, connecter un outil externe à votre projet via Trino signifiait créer un compte de service, générer des clés API et assembler la chaîne de connexion à la main. Un consommateur Trino fait tout cela pour vous.

Vous les trouverez dans le service Connectors, sous l'onglet **Consommateurs**, dans la section **Consommateurs Trino** de **Consommateurs enregistrés**.

<img className="thumbnail" alt="Section des consommateurs Trino" src="/images/public-cloud/data-platform/product/connectors/consumers/trino/picts/trino-consumers-section.png" loading="lazy" />

:::info
Contrairement aux consommateurs PowerBI et OpenLineage (que vous connectez une seule fois), vous pouvez créer autant de consommateurs Trino que nécessaire. Chacun avec son propre nom, son niveau de permission et ses identifiants.
:::

## Créer un consommateur Trino

1. Dans la section **Consommateurs Trino**, cliquez sur **+ New Trino consommateur**.

   <img className="thumbnail" alt="Créer un consommateur Trino — nouveau consommateur Trino" src="/images/public-cloud/data-platform/product/connectors/consumers/trino/picts/trino-consumer-new.png" loading="lazy" />

2. Donnez-lui un **nom**, une **description** optionnelle, et des **tags** optionnels.

3. Définissez la **permission** : le niveau d'accès que ce consommateur Trino a sur vos données :

   | Permission | Accès |
   | :--- | :--- |
   | **LECTURE** | Interroger et récupérer les données uniquement. |
   | **LECTURE & ÉCRITURE** | Interroger, récupérer et modifier les données. |

   <img className="thumbnail" alt="Créer un consommateur Trino — permission du consommateur Trino" src="/images/public-cloud/data-platform/product/connectors/consumers/trino/picts/trino-consumer-permission.png" loading="lazy" />

4. Cliquez sur **Créer**.

5. Votre **chaîne de connexion Trino** s'affiche.

   <img className="thumbnail" alt="Créer un consommateur Trino — chaîne de connexion du consommateur Trino" src="/images/public-cloud/data-platform/product/connectors/consumers/trino/picts/trino-consumer-connection-string.png" loading="lazy" />

:::warning
Copiez la chaîne de connexion maintenant et stockez-la en lieu sûr (par exemple, un gestionnaire de mots de passe). Vous ne pourrez plus la consulter après avoir fermé cette fenêtre ; si vous la perdez, vous devrez créer un nouveau consommateur Trino.
:::

## Gérer le compte de service lié

Chaque consommateur Trino possède un [compte de service](/guides/public-cloud/data-platform/iam-service-accounts) dédié dans l'Identity Access Manager de votre projet. Après avoir créé le consommateur, cliquez sur **Go to service account settings** pour le consulter et le gérer.

L'**admin du projet reçoit également un e-mail** contenant les identifiants du connecteur Trino.

## Utiliser la chaîne de connexion

La chaîne de connexion est prête à être collée dans n'importe quel client compatible Trino externe ou outil de BI. Elle intègre les identifiants et suit ce format :

```text
trino://<api-key>:<secret-key>@<project>-query.eu.dataplatform.ovh.net:443/<catalog>
```

Intégrez-la dans l'outil de votre choix, par exemple :

[Déployer Apache Superset](/guides/public-cloud/data-platform/tutorials-install-apache-superset)

[Connecter Metabase à la Data Platform via Trino](/guides/public-cloud/data-platform/tutorials-metabase-trino)

:::warning
Tout utilisateur se connectant via un consommateur Trino accède aux données selon la permission du consommateur et les [rôles et groupes IAM](/guides/public-cloud/data-platform/landing-page-iam-users) du projet. Traitez la chaîne de connexion comme un mot de passe.
:::

## Interroger un autre catalogue

Par défaut, la chaîne de connexion cible le catalogue **default dataset** de votre projet (le segment final `/<catalog>`, par exemple `db_<project>_default_dataset`).

Pour interroger un **catalogue différent** dans le projet, remplacez ce segment final `/<catalog>` de la chaîne de connexion. Pour lister les noms de catalogues disponibles, exécutez la commande suivante dans le [Lakehouse Manager Explorer](/guides/public-cloud/data-platform/lakehouse-manager-explorer) :

```sql
SHOW CATALOGS
```

Pour le détail complet de la chaîne de connexion et pour apprendre à en construire une à la main, consultez [Intégrer Trino à des outils externes](/guides/public-cloud/data-platform/tutorials-trino-external-tools).

:::info
L'écriture de données via Trino nécessite parfois un `CAST` explicite. Consultez [Types de données et conversions Trino](/guides/public-cloud/data-platform/tutorials-trino-types-and-casts) pour connaître la correspondance entre les types Lakehouse et les types Trino, et pour résoudre les erreurs `TYPE_MISMATCH`.
:::
