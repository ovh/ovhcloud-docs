## Objectif

L'onglet des paramètres vous permet de gérer les [référentiels](/guides/public-cloud/data-platform/dpe-settings#référentiels) et les [quotas](/guides/public-cloud/data-platform/dpe-settings#quotas) de votre Data Processing Engine.

## Référentiels

Le panneau *Référentiels* donne une vue d'ensemble de chacun de vos référentiels d'actions, permettant non seulement un aperçu rapide de chacun d'eux, mais aussi les moyens de modifier chaque référentiel, comme le changement du compte Git associé.

## Quotas

La section des quotas vous permet de demander davantage de ressources pour votre Data Processing Engine, selon vos besoins.
