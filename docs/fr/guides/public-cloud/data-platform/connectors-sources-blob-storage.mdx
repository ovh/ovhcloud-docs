## Objectif

Le connecteur Microsoft Azure Blob Storage vous permet de récupérer des fichiers stockés dans le système de stockage d'objets de Microsoft Azure : [Azure Blob Storage](https://azure.microsoft.com/en-us/services/storage/blobs/).

<img className="thumbnail" alt="FB1" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/blob-storage/picts/blob-store.png" loading="lazy" />

## Récupérer le nom et la clé de votre compte de stockage

Vous devez obtenir les informations suivantes auprès d'Azure :

- le nom du compte de stockage Azure auquel se connecter
- une clé pour ce compte de stockage
- le nom du blob container auquel se connecter

### Récupérer le nom et la clé de votre compte de stockage

Sur la console Microsoft Azure, ouvrez le **storage account** auquel vous souhaitez vous connecter et ouvrez l'onglet *Access keys*.

<img className="thumbnail" alt="FB1" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/blob-storage/picts/ABS-name-key.png" loading="lazy" />

Récupérez les informations suivantes :

- *storage account name*
- *key*

:::warning
Si vous êtes sur un [plan Dédié](/guides/public-cloud/data-platform/manage-pricing#abonnements-et-comptes-de-facturation) avec un cluster auto-hébergé, vous ne devez pas vous connecter au groupe de ressources/compte de stockage dédié aux ressources de la Platform.
:::

Si vous n'avez pas encore de compte de stockage séparé, utilisez la documentation ci-dessous pour en créer un.

#### Créer un nouveau compte de stockage

Pour créer un nouveau [compte de stockage Microsoft Azure](https://docs.microsoft.com/en-us/azure/storage/common/storage-account-overview?toc=%2Fazure%2Fstorage%2Fblobs%2Ftoc.json) depuis la console Microsoft Azure, sélectionnez *Storage accounts* et cliquez sur **Create**.

<img className="thumbnail" alt="FB1" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/blob-storage/picts/ABS-add-storage-account.png" loading="lazy" />

Suivez les étapes pour ajouter un compte de stockage en remplissant les champs requis et les paramètres personnalisés. Le *storage account name* sera nécessaire pour se connecter depuis la Platform.

:::warning
Si vous êtes sur un [plan Dédié](/guides/public-cloud/data-platform/manage-pricing#abonnements-et-comptes-de-facturation) avec un cluster auto-hébergé, vous ne devez pas utiliser le groupe de ressources dédié aux ressources de la Platform.
:::

<img className="thumbnail" alt="FB1" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/blob-storage/picts/ABS-add-storage-account2.png" loading="lazy" />

Une fois votre compte de stockage créé, retournez aux premières étapes ci-dessus pour récupérer son nom et sa clé.

### Récupérer le nom de votre blob container

Dans la console Microsoft Azure, ouvrez l'onglet *Storage browser*.

<img className="thumbnail" alt="FB1" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/blob-storage/picts/ABS-storage-browser.png" loading="lazy" />

Dans le compte de service que vous venez d'utiliser, ouvrez la section *Blob containers*.

<img className="thumbnail" alt="FB1" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/blob-storage/picts/ABS-blob-containers.png" loading="lazy" />

Si vous avez un container existant que vous souhaitez utiliser, récupérez son *nom* à cette étape. Sinon, créez un nouveau container.

#### Créer un nouveau blob container

Cliquez sur **Add container**. Le *nom* que vous renseignez sera nécessaire pour se connecter depuis la Platform.

<img className="thumbnail" alt="FB1" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/blob-storage/picts/ABS-add-blob-container.png" loading="lazy" />

## Ajouter une source Microsoft Azure Blob Storage sur la Platform

### Vue d'ensemble de l'écran de configuration

Une fois que vous avez trouvé *Microsoft Azure Blob Storage* dans le **Platform store**, cliquez sur *Select* et vous pourrez voir l'écran de configuration comme indiqué ci-dessous :

<img className="thumbnail" alt="FB2" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/blob-storage/picts/blob2.png" loading="lazy" />

### Configurer votre source

#### Se connecter à Microsoft Azure Blob Storage

Lors de la création de la source, vous devrez saisir les informations suivantes :

- **Nom du compte** : le nom du compte de stockage obtenu [ici](#récupérer-le-nom-et-la-clé-de-votre-compte-de-stockage)
- **Clé de compte** : la clé de ce compte de stockage obtenue [ici](#récupérer-le-nom-et-la-clé-de-votre-compte-de-stockage)
- **Nom du conteneur** : le nom du blob container obtenu [ici](#récupérer-le-nom-de-votre-blob-container)
- **Chemin d'accès des fichiers** *(optionnel)* : le chemin complet d'un dossier ou d'un fichier spécifique auquel se connecter

Une fois ces informations ajoutées, cliquez sur **Connecter** pour établir une connexion avec Microsoft Azure Blob Storage.

:::info
Si tout fonctionne correctement, vous devriez voir apparaître la liste des fichiers analysés sur la page. Cela peut prendre jusqu'à quelques secondes.
:::

Pour terminer, cliquez sur le bouton **Créer** en haut à droite.

:::warning
N'oubliez pas de nommer votre source avant de la créer. Le nom technique ne peut pas être modifié après la création de la source et sera utilisé pour accéder à la source via le [SDK](/guides/public-cloud/data-platform/landing-page-developers-python-sdk).
:::
