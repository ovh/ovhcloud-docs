## Objectif

Les applications créées sur la Platform sont multilingues par nature. Les champs à traduire ainsi que les langues disponibles pour l'application se trouvent dans l'onglet Traductions.

Cet onglet vous permet de :

- Ajouter des langues
- Lister toutes les expressions nécessitant une traduction
- Ajouter ou modifier la traduction de ces expressions dans toutes les langues ajoutées

Les thèmes proposés sur le Marketplace disposent d'un certain nombre de traductions permettant à l'application de fonctionner correctement. Il ne sera donc nécessaire d'ajouter des traductions que lorsque les expressions utilisées ne sont pas incluses dans le thème, comme le nom des champs de données. De même, si une application est uniquement construite à partir du SDK, la majorité des traductions devront être ajoutées.

## Intégration dans l'application

### Dans les graphiques

De nombreux graphiques prédéfinis fournissent un système de traduction simple.
#### Traduire un axe

```json
"site" : "Site"  
```
site sera remplacé par "Site" dans tous les graphiques

#### Traduire une valeur

Pour traduire une valeur d'axe, vous devez utiliser une combinaison du nom de l'axe et de la valeur
```json
"site-2" : "New York" 
```
Au lieu de "2", tous les graphiques afficheront "New York" pour un axe "site"
