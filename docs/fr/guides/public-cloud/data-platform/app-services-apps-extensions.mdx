## Objectif

Les extensions sont une liste de packages, accessibles via l'onglet extensions, qui peuvent apporter des fonctionnalités supplémentaires à votre application, comme un logiciel de graphiques tiers, des services de traduction, ou des paramètres dynamiques.

## Gérer vos extensions

L'onglet *Extensions* de l'APP Manager vous permet de visualiser et de gérer les différentes bibliothèques prises en charge :

<img className="thumbnail" alt="Gérer vos extensions — Extensions de l'app" src="/images/public-cloud/data-platform/product/app-manager/extensions/picts/app-extensions.png" loading="lazy" />

- **Ajouter** les extensions dont vous avez besoin pour votre projet
- **Configurer** les paramètres globaux de l'extension, le cas échéant
- **Supprimer** les extensions déjà installées si elles ne sont pas nécessaires, ou si vous avez besoin d'une nouvelle version de la bibliothèque.
- **Obtenir plus d'informations** concernant les extensions liées à des bibliothèques externes.
- **Importer** une extension open source ou propriétaire, spécifique à un projet ou à une organisation

:::warning
L'ajout d'une extension nécessite de recharger votre application (sur la page Overview) afin de pouvoir la construire.
:::

## Personnaliser les extensions

Chaque extension du marketplace de la Data Platform dispose de sa propre configuration spécifique dans un fichier JSON que vous pouvez éditer et personnaliser.

[Tutoriel pratique sur la configuration des extensions](/guides/public-cloud/data-platform/tutorials-app-development-custom-components)

## Extensions disponibles

Quatre types d'extensions sont disponibles : les extensions système, les utilitaires de la platform, les paramètres dynamiques et les bibliothèques de graphiques.

:::details Extensions système

Ces extensions constituent le cœur du SDK de la Data Platform pour construire des applications. Elles doivent toujours être installées.

| Identifiant            | Nom                 | Description                                               |
| :-------------------- | :------------------- | :-------------------------------------------------------- |
| **api**               | Api                  | Effectue des requêtes vers l'API de votre application front-end |
| **chart**             | Graphique            | Charge un graphique    |
| **core-ui**           | Core UI              | Ce composant inclut les composants graphiques nécessaires à la création de l'application  |
| **dashboarding**      | Dashboarding         | Construit un tableau de bord                          |
| **dynamic-parameter** | Paramètre dynamique  | Un composant central pour utiliser des boutons radio, un sélecteur de date, une liste déroulante... |
| **formatter**         | Formatter            | Vous permet de formater les données extraites de votre projet |
| **menu**              | Menu                 | Construit les menus de navigation             |
| **query-builder**     | Query builder        | Effectue des requêtes vers l'Analytics Manager via une API |
| **sdk**               | SDK                  | Kit de développement essentiel au bon fonctionnement des autres extensions |
| **store**             | Store                | Ajoute un data store à votre application. Essentiel au développement d'une application JavaScript moderne |
| **toaster**           | Toaster              | Affiche des messages sous forme de toast en bas de l'écran |
| **translate**         | Translate            | C'est le système de traduction de l'application      |
| **xhr**               | Xhr                  | Effectue des requêtes vers diverses API |
| **webpack**           | Webpack builder      | Un constructeur d'application utilisé pour faire fonctionner ensemble toutes les extensions |

:::

:::details Utilitaires de la platform

Ces extensions gèrent d'autres services de la Platform mais ne sont pas indispensables à 100 % pour créer une application.

| Identifiant            | Nom                 | Description                                               |
| :-------------------- | :------------------- | :-------------------------------------------------------- |
| **client-authority-manager**   | Identity Access Manager    | Connecte le gestionnaire d'authentification de la Platform |

:::

:::details Paramètres dynamiques

Voici tous les paramètres dynamiques possibles que vous pouvez utiliser pour filtrer dynamiquement les valeurs dans les applications.

Trouvez plus d'informations sur les paramètres dynamiques ici :

- [configurer les paramètres dynamiques](https://docs.dataplatform.ovh.net/#/en/technical/sdk/app/dynamic_parameters/index)
- [créer des paramètres dynamiques personnalisés](https://docs.dataplatform.ovh.net/#/en/technical/sdk/app/dynamic_parameters/create)

| Identifiant               | Nom                 | Description                                               |
| :----------------------- | :------------------- | :-------------------------------------------------------- |
| **dynamic-parameter-datepicker** | Date range selection | Sélectionne une plage de dates                     |
| **dynamic-parameter-selectbox**  | Select Box           | Choisit une ou plusieurs valeurs dans une liste déroulante |
| **dynamic-parameter-checkbox**   | Checkbox              | Choisit une ou plusieurs valeurs via des cases à cocher |
| **dynamic-parameter-radio**      | Radio                | Choisit une valeur via des boutons radio  |
| **dynamic-parameter-toggle**     | Toggle               | Choisit une valeur via un interrupteur On/Off |

:::

:::details Bibliothèques de graphiques

Ces extensions permettent d'intégrer des bibliothèques de graphiques pour la visualisation des données.

Trouvez plus d'informations sur les bibliothèques de graphiques ici :

- [configurer les graphiques](https://docs.dataplatform.ovh.net/#/en/technical/sdk/app/charts/index)
- [créer des graphiques personnalisés](https://docs.dataplatform.ovh.net/#/en/technical/sdk/app/custom-chart)

| Identifiant          | Nom                 | Description                                               |
| :------------------ | :------------------- | :-------------------------------------------------------- |
| **chart-table**     | Chart table          | Affiche sous forme de tableau |
| **chartist**        | Chartist JS          | Bibliothèque graphique responsive et facile à utiliser    |
| **chartjs**         | ChartJs              | Bibliothèque graphique JavaScript, flexible pour les designers et les développeurs  |
| **echarts**         | Echarts              | Une bibliothèque graphique très avancée qui dispose de tous les outils dont vous aurez besoin. |
| **google-chart**    | Google Chart         | Les outils graphiques de Google sont puissants, faciles à utiliser et gratuits  |
| **jvectormap**      | JVectorMap           | Ajoute des cartes SVG interactives à vos tableaux de bord |
| **morris**          | Morris Chart         | Morris Chart                                                 |
| **recharts**        | ReCharts             | ReCharts |

:::
