## Objectif

:::info
**Vous cherchez la méthode rapide ?** Vous pouvez désormais générer une chaîne de connexion Trino prête à l'emploi en quelques clics avec un [**consumer Trino**](/guides/public-cloud/data-platform/connectors-consumers-trino). Ce guide couvre la **méthode manuelle** : utile lorsque vous souhaitez configurer vous-même le service account, le rôle et la chaîne de connexion, ou lorsque vous avez besoin d'un contrôle précis sur le catalog et les permissions.
:::

Ce guide fournit une marche à suivre complète pour créer une intégration Trino destinée à être utilisée dans un outil tiers. Vous allez générer les identifiants nécessaires et construire une chaîne de connexion pour accéder à vos données via Trino.

## Étapes pour établir une connexion Trino

### Étape 1 : créer un nouveau service account

1.  Connectez-vous à la Data Platform.
2.  Accédez à **IAM** (Identity and Access Manager).
3.  Allez dans la section **Roles** et cliquez sur **New Role**.
    <img className="thumbnail" alt="Step 1: Create a New Service Account — Superset" src="/images/public-cloud/data-platform/getting-further/integrate-trino-with-external-tools/picts/superset-02.png" loading="lazy" />
4.  Indiquez un nom pour le rôle (par exemple, `TrinoServiceAccountRole`).
5.  Attribuez les permissions **Advanced Data Access Control** à ce rôle. Ce rôle sera assigné à votre service account pour accorder l'accès Trino nécessaire.
    <img className="thumbnail" alt="Step 1: Create a New Service Account — Superset (2)" src="/images/public-cloud/data-platform/getting-further/integrate-trino-with-external-tools/picts/superset-03.png" loading="lazy" />
    <img className="thumbnail" alt="Step 1: Create a New Service Account — Superset (3)" src="/images/public-cloud/data-platform/getting-further/integrate-trino-with-external-tools/picts/superset-04.png" loading="lazy" />
6.  Allez dans **Service Accounts**.
7.  Créez un nouveau service account, donnez-lui un nom (par exemple, `Apache Superset Service Account` ou `Metabase Service Account`) et une adresse e-mail.
    <img className="thumbnail" alt="Step 1: Create a New Service Account — Superset (4)" src="/images/public-cloud/data-platform/getting-further/integrate-trino-with-external-tools/picts/superset-05.png" loading="lazy" />
8.  Attribuez le rôle nouvellement créé (`TrinoServiceAccountRole`) à ce compte.
9.  Cliquez sur **Create**.

:::info
Pour une meilleure sécurité et une meilleure gestion des accès, créez un service account dédié lorsque vous autorisez des outils externes à accéder à vos données.
:::

### Étape 2 : générer une clé API et une clé secrète

1.  Une fois le *Service Account* créé, vous verrez la section **API Access**. Cliquez sur **+ ADD**.
    <img className="thumbnail" alt="Step 2: Generate an API Key and Secret Key — Superset" src="/images/public-cloud/data-platform/getting-further/integrate-trino-with-external-tools/picts/superset-06.png" loading="lazy" />
2.  Ici, vous pouvez modifier la durée de vie des clés et choisir d'en recevoir une copie à votre adresse e-mail enregistrée.
    <img className="thumbnail" alt="Step 2: Generate an API Key and Secret Key — Superset (2)" src="/images/public-cloud/data-platform/getting-further/integrate-trino-with-external-tools/picts/superset-07.png" loading="lazy" />
3.  **Important** : une fois la fenêtre modale fermée, les clés ne peuvent plus être récupérées. Veillez à les enregistrer immédiatement dans un endroit sécurisé, comme un gestionnaire de mots de passe. Cette clé API et cette clé secrète serviront de `Username` et de `Password` pour la connexion Trino.
    <img className="thumbnail" alt="Step 2: Generate an API Key and Secret Key — Superset (3)" src="/images/public-cloud/data-platform/getting-further/integrate-trino-with-external-tools/picts/superset-08.png" loading="lazy" />

### Étape 3 : préparer la chaîne de connexion

La chaîne de connexion que vous pourrez utiliser dans vos outils tiers sera la suivante :

```text
trino://{Username}:{Password}@{Project}-query.eu.dataplatform.ovh.net:{Port}/{Catalog}
```
-   **Project** : remplacez `{Project}` par le nom de votre projet spécifique. Vous pouvez trouver ce nom en accédant à l'un de vos projets existants, puis en cliquant sur l'icône Information représentée par ℹ️ en haut à droite de l'interface. Le nom de votre projet y sera affiché.
-   **Port** : remplacez `{Port}` par le port par défaut de la Data Platform (`443`) ou un port personnalisé fourni par votre configuration.
-   **Catalog** : remplacez `{Catalog}` par le catalog que vous souhaitez interroger. Vous pouvez trouver le catalog souhaité en exécutant cette commande SQL dans l'explorateur du Lakehouse Manager : `SHOW CATALOGS`.
    -   **Exemple de sortie de `SHOW CATALOGS` :**
        ```text
        Catalog
        -------
        tpcds
        tpch
        db_m8obb5ch_default_dataset
        ```
        Dans cet exemple, `db_m8obb5ch_default_dataset` est un nom de catalog valide.
-   **Username** : utilisez l'*API Key* générée précédemment depuis IAM à l'étape 2.
-   **Password** : utilisez la *Secret Key* générée précédemment depuis IAM à l'étape 2.

**Exemple :**
```text
trino://XXXX:YYYYYY@demo-query.eu.dataplatform.ovh.net:443/db_m8obb5ch_default_dataset
```

### Étape 4 : utiliser la chaîne de connexion dans votre outil tiers

Une fois votre chaîne de connexion préparée, vous pouvez l'utiliser pour connecter l'outil tiers de votre choix (par exemple, Apache Superset) à Trino sur la Data Platform OVHcloud.
