## Structure, versions et identifiants

Personnaliser votre première application prend le relais là où s'arrête le tutoriel Premiers pas : un graphique plus riche, des unités sur les valeurs, et une version reconstruite de la même application.

Développer votre propre application est le tutoriel le plus long ici, un guide en plusieurs parties sur l'import de code depuis un dépôt Git, le travail avec les fichiers de configuration, la création de composants et l'ajout de composants personnalisés. C'est la voie à suivre lorsque le créateur d'application low-code ne suffit pas.

Les autres sont plus courts et indépendants. Exporter et importer une configuration déplace la configuration d'un projet entre environnements, ce qui permet à un projet de préproduction de devenir un projet de production. Générer des clés d'API crée les identifiants qu'un système externe utilise pour s'authentifier auprès du projet. Les bases du versionnage couvre le contrôle de version propre à la platform sur les dépôts d'actions, et comment synchroniser un dépôt avec Git à la place.

:::warning
Le tutoriel de développement d'application est en cours de refonte, sans date fixée. Il reste exact pour la platform actuelle.
:::
