## Structure, versions et identifiants

Personnaliser votre première application prend le relais là où s'arrête le tutoriel Premiers pas : un graphique de classement, des chiffres en millions et une nouvelle version de la même application, déployée sans interruption de service.

Développer votre propre application est le tutoriel le plus long de cette section : un guide en plusieurs parties qui couvre l'import de code depuis un dépôt Git, le travail sur les fichiers de configuration, la création de composants et l'ajout de composants personnalisés. C'est la voie à suivre lorsque le créateur d'applications low-code ne suffit pas.

Les autres tutoriels sont plus courts et indépendants. Exporter et importer une configuration permet de déplacer la configuration d'un projet d'un environnement à un autre : c'est ainsi qu'un projet de préproduction devient un projet de production. Générer des clés d'API crée les identifiants qu'un système externe utilise pour s'authentifier auprès du projet. Les bases du versionnage présentent le contrôle de version propre à la Platform sur les dépôts d'actions, ainsi que son alternative, la synchronisation d'un dépôt avec Git.

:::warning
Le tutoriel de développement d'application est en cours de refonte, sans date fixée. Il reste exact pour la Platform actuelle.

:::
