## Objectif

Le connecteur vous permet d'utiliser les fichiers stockés dans les [buckets de votre Projet](/guides/public-cloud/data-platform/lakehouse-manager-buckets) comme sources de données.

:::info
Les Buckets sont un système de stockage traditionnel basé sur les fichiers et vous permettent d'organiser des données non structurées
:::

<img className="thumbnail" alt="Buckets" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/forepaas-buckets/picts/FPBuckets.png" loading="lazy" />

## Ajouter une source Buckets

### Vue d'ensemble de l'écran de configuration

Une fois que vous avez trouvé *Buckets* dans le **the Platform store**, cliquez sur *Sélectionner* et vous pourrez voir l'écran de configuration comme illustré ci-dessous -

<img className="thumbnail" alt="bucket" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/forepaas-buckets/picts/FPBucket1.png" loading="lazy" />

### Configurer votre source

Lors de la création de la source, vous devrez renseigner les informations suivantes :

- **Bucket :** Le nom du Bucket dans lequel vous souhaitez trouver les fichiers source
- **Path :** Le chemin optionnel vers le sous-dossier contenant les fichiers source

Une fois ces informations ajoutées, cliquez sur *Connecter* et 
vous verrez les fichiers de votre bucket. Un exemple est illustré ci-dessous :

<img className="thumbnail" alt="bucket" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/forepaas-buckets/picts/FPBucket2.png" loading="lazy" />

Cliquez ensuite sur le bouton *Créer* en haut à droite pour créer votre source.

:::warning
N'oubliez pas de nommer votre source avant de la créer. Le nom technique ne peut plus être modifié après la création de la source et sera utilisé lors de l'ouverture de la source via le [SDK](/guides/public-cloud/data-platform/landing-page-developers-python-sdk).
:::

L'encodage des fichiers source est automatiquement détecté par la Platform. Cependant, si la détection automatique échoue, vous avez la possibilité de spécifier l'encodage du fichier en cliquant sur l'**icône crayon** à côté de chaque objet source :

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/forepaas-buckets/picts/buckets-encoding.png" loading="lazy" />

Sélectionnez l'encodage de votre objet source dans la liste déroulante.

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/forepaas-buckets/picts/encoding2.png" loading="lazy" />

### Fichiers et tailles pris en charge

Le Datastore permet un **stockage objet compatible S3<sup>1</sup>**, ce qui vous permet de stocker toutes les données non structurées.

:::warning
Il y a une limite de taille de 10 Go sur les fichiers traités par le Data Store.
:::
