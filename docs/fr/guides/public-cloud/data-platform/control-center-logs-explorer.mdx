## Objectif

Le Logs Explorer est un outil complet pour **interroger et exporter les logs des exécutions de job et des déploiements actifs** sur la Data Platform.

<img className="thumbnail" alt="Logs explorer du Control Center" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-logs-explorer.png" loading="lazy" />

Comme tous les sous-composants du Control Center, le Logs Explorer peut être ouvert au niveau de l'organisation. Cependant, l'exploration des logs ne sera possible qu'à l'intérieur d'un Projet spécifique. Si le Logs Explorer est ouvert au niveau d'un Projet, alors ce champ ne peut pas être modifié.

<img className="thumbnail" alt="Control Center right dataplant" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-right-dataplant.png" loading="lazy" />

## Obtenir des logs

### Obtenir les logs des exécutions de job passées

Le Logs Explorer vous permet de consulter les logs :

- des exécutions de job des [actions du Data Processing Engine](/guides/public-cloud/data-platform/landing-page-dpe-actions)
- des exécutions de job des [workflows du Data Processing Engine](/guides/public-cloud/data-platform/dpe-workflows)
- des jobs d'[extraction de métadonnées Connectors](/guides/public-cloud/data-platform/connectors-analyzer-extract-metadata)
- des jobs de [build physique du Lakehouse Manager](/guides/public-cloud/data-platform/lakehouse-manager-manage-tables)

Choisissez *Jobs* comme **Resource** dans la colonne de gauche.

<img className="thumbnail" alt="Obtenir les logs des exécutions de job passées — Control Center right jobs" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-right-jobs.png" loading="lazy" />

Choisissez le **type de job** à explorer.

<img className="thumbnail" alt="Obtenir les logs des exécutions de job passées — Control Center jobs type" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-jobs-type.png" loading="lazy" />

Par défaut, le Logs Explorer affichera les logs de tous les jobs correspondant à ce type. Vous pouvez creuser sur un objet spécifique dans la liste en bas à gauche - classée par nombre d'exécutions.

<img className="thumbnail" alt="Obtenir les logs des exécutions de job passées — Control Center jobs object" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-jobs-object.png" loading="lazy" />

Vous pouvez creuser davantage en filtrant sur un **ID d'exécution** spécifique ou sur une plage temporelle spécifique au-dessus de l'affichage.

:::warning
Assurez-vous que l'exécution que vous souhaitez afficher est contenue dans la plage temporelle sur laquelle vous avez filtré.
:::

<img className="thumbnail" alt="Obtenir les logs des exécutions de job passées — Control Center jobs execution timeframe" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-jobs-execution-timeframe.png" loading="lazy" />

:::info
Notez que les logs seront interrogés par lots successifs d'au maximum 250 logs. Faites défiler la console vers le bas pour charger davantage de logs.
:::

### Obtenir les logs des déploiements

Le Logs Explorer vous permet également de consulter les logs :

- des [API](/guides/public-cloud/data-platform/landing-page-app-services-apis)
- des [Applications](/guides/public-cloud/data-platform/landing-page-app-services-apps) 
- des [Notebooks](/guides/public-cloud/data-platform/dpe-notebooks)
- des [déploiements always-up dans le Data Processing Engine](/guides/public-cloud/data-platform/dpe-jobs-preferences#always-up)
- du composant *App Service* : un service d'infrastructure pour contrôler les API et les applications

Choisissez *Deployments* comme **Resource** dans la colonne de gauche.

<img className="thumbnail" alt="Obtenir les logs des déploiements — Control Center right deployments" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-right-deployments.png" loading="lazy" />

Choisissez le **type de déploiement** à explorer.

<img className="thumbnail" alt="Obtenir les logs des déploiements — Control Center deployments type" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-deployments-type.png" loading="lazy" />

Par défaut, le Logs Explorer affichera les logs de tous les déploiements correspondant à ce type. Vous pouvez creuser sur un objet spécifique dans la liste en bas à gauche - classée par nombre de workers actifs. Par défaut, les logs de tous les workers de cet objet déployé sont agrégés ensemble dans l'affichage.

<img className="thumbnail" alt="Obtenir les logs des déploiements — Control Center deployments object" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-deployments-object.png" loading="lazy" />

Vous pouvez creuser davantage en filtrant sur un **ID de worker** spécifique ou sur une plage temporelle spécifique au-dessus de l'affichage.

<img className="thumbnail" alt="Obtenir les logs des déploiements — Control Center deployment worker timeframe" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-deployment-worker-timeframe.png" loading="lazy" />

:::info
Notez que les logs seront interrogés par lots successifs d'au maximum 250 logs. Faites défiler la console vers le bas pour charger davantage de logs.
:::

### Utiliser le mode streaming

Par défaut, le Logs Explorer doit être actualisé manuellement pour afficher les nouveaux logs.

<img className="thumbnail" alt="Utiliser le mode streaming — Control Center left refresh" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-left-refresh.png" loading="lazy" />

Activez le **mode streaming** pour recevoir les derniers logs en temps réel.

<img className="thumbnail" alt="Utiliser le mode streaming — Control Center left streaming" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-left-streaming.png" loading="lazy" />

## Filtrer les logs

### Rechercher dans les logs

Pour filtrer votre résultat de logs, il est possible de rechercher soit une sous-chaîne exacte, soit une correspondance avec une [expression régulière (Regex)](https://en.wikipedia.org/wiki/Regular_expression) en utilisant la barre de recherche au-dessus de la console. Rechercher quelque chose dans la barre de recherche **lancera une nouvelle requête de logs sur toute la plage temporelle** et retournera les logs correspondant aux filtres de recherche.

Par défaut, taper simplement du texte dans la barre de recherche recherchera tous les logs contenant cette sous-chaîne, en ignorant la casse.

<img className="thumbnail" alt="Rechercher dans les logs — Control Center left searchlog" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-left-searchlog.png" loading="lazy" />

Il est également possible de commencer votre recherche avec l'un des opérateurs suivants :

- `=` suivi de texte : recherche tous les logs contenant cette sous-chaîne (sensible à la casse)
- `!=` suivi de texte : recherche tous les logs ne contenant pas cette sous-chaîne (sensible à la casse)
- `~` suivi d'une regex : recherche tous les logs correspondant à l'expression régulière
- `!~` suivi d'une regex : recherche tous les logs qui ne correspondent pas à l'expression régulière

<img className="thumbnail" alt="Rechercher dans les logs — Control Center left searchlog2" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-left-searchlog2.png" loading="lazy" />

### Sévérité

Les logs ont différents niveaux de sévérité - allant de *INFO* à *CRITICAL* - sur lesquels filtrer.

:::info
Si vous ne voyez pas tous les niveaux que vous devriez voir, assurez-vous que vos jobs sont [configurés pour exporter le bon niveau](/guides/public-cloud/data-platform/dpe-jobs-preferences#niveau-de-logs) de logs.
:::

<img className="thumbnail" alt="Sévérité — Control Center left severity" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-left-severity.png" loading="lazy" />

### Horodatage

Comme mentionné plus haut, tous les logs sont associés à un horodatage spécifique, ils peuvent donc être filtrés sur une plage temporelle. Pour les logs d'exécution de job, il est également possible de filtrer sur une exécution spécifique.

<img className="thumbnail" alt="Horodatage — Control Center jobs execution timeframe" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-jobs-execution-timeframe.png" loading="lazy" />

## Partager des logs

Les logs peuvent être partagés de deux manières : en partageant le lien vers le Logs Explorer ou en exportant un fichier texte contenant les logs.

### Partager un lien Explorer

Cliquez sur l'icône **link** pour obtenir un lien vers la page avec la configuration de filtre actuelle.

<img className="thumbnail" alt="Partager un lien Explorer — Control Center left link" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-left-link.png" loading="lazy" />

### Exporter un fichier de logs

Cliquez sur l'icône **export** pour télécharger un fichier .log contenant les logs actuellement affichés dans l'interface.

<img className="thumbnail" alt="Exporter un fichier de logs — Control Center left export" src="/images/public-cloud/data-platform/product/cc/logs/picts/cc-left-export.png" loading="lazy" />

:::info
Partagez ces fichiers de logs à l'équipe Support Data Platform chaque fois que vous avez besoin d'aide pour déboguer un Projet sur Data Platform.
:::
