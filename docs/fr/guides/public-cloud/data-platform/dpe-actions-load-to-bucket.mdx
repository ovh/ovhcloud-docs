## Objectif

L'action *Load to Bucket* **extrait les données brutes des sources et les place dans un fichier** dans le bucket de votre Projet. Vous pouvez choisir le format de fichier.

:::info
**Note:** Cette action prend en charge la fonctionnalité permettant d'avoir une date personnalisée dans le nom du dossier. Vous pouvez trouver le tutoriel [ici](/guides/public-cloud/data-platform/tutorials-dated-export-folders).
:::

## Configurer une action Load to Bucket

Pour créer une nouvelle action, accédez à l'**onglet Action** du Data Processing Engine (DPE), cliquez sur **Nouvelle action** et sélectionnez l'action *Load to Bucket*.

### Choisir une source et une destination

Pour configurer l'action, commencez par sélectionner une source dans la liste que vous avez déjà configurée dans l'onglet [Sources](/guides/public-cloud/data-platform/landing-page-connectors-sources) des Connectors.

<img className="thumbnail" alt="Choisir une source et une destination — Load buckets select source" src="/images/public-cloud/data-platform/product/dpe/actions/load-buckets/picts/load-buckets-select-source.png" loading="lazy" />

Ensuite, choisissez le *bucket de destination* dans la liste des [buckets du Projet](/guides/public-cloud/data-platform/lakehouse-manager-buckets).

<img className="thumbnail" alt="Choisir une source et une destination — Load buckets list buckets" src="/images/public-cloud/data-platform/product/dpe/actions/load-buckets/picts/load-buckets-list-buckets.png" loading="lazy" />

Il vous sera ensuite demandé de choisir le format de fichier et le dossier de destination. Si vous laissez le nom du dossier vide, il sera automatiquement nommé d'après le nom de la source.

<img className="thumbnail" alt="Choisir une source et une destination — Load buckets select destination" src="/images/public-cloud/data-platform/product/dpe/actions/load-buckets/picts/load-buckets-select-destination.png" loading="lazy" />

:::warning
Notez que **les sources suivantes ne sont PAS prises en charge** dans cette action : Azure Blob Storage, Data Store, Dropbox, FTP, Google Drive, HTTP Files, HTTP REST, One Drive, S3<sup>1</sup>-compatible-storage, Amazon S3 et SFTP.
:::

:::info
Si vous choisissez une **source PostgreSQL**, votre action bénéficiera de performances optimisées, à l'image de l'[action PostgreSQL to Parquet](/guides/public-cloud/data-platform/dpe-actions-postgresql-to-parquet).
:::

### Fichier de destination

Vos données seront placées dans le dossier de destination dans un fichier nommé *part-1* avec le format que vous avez spécifié. Si votre fichier est trop volumineux, il sera divisé en plusieurs fichiers nommés *part-1*, *part-2*, *part-3*, et ainsi de suite.

L'ordre de vos lignes sera préservé au cours de ce processus. Ainsi, les premières lignes se trouveront dans le fichier *part-1* et les lignes suivantes se trouveront dans le fichier *part-2*.
