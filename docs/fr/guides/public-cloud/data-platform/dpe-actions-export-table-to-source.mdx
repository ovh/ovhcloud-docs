## Objectif

L'action *Export Table to Source* vous permet d'**exporter une ou plusieurs tables de votre Lakehouse Manager directement vers une source Connectors compatible.** Cette action facilite le déplacement des données traitées ou brutes de votre environnement Lakehouse managé vers des bases de données externes ou d'autres systèmes pris en charge par les connectors des Connectors.

## Configurer une action Export Table to Source

Pour créer une nouvelle action *Export Table to Source*, suivez ces étapes au sein du Data Processing Engine (DPE) :

1.  Accédez à l'**onglet Action** au sein de l'interface du Data Processing Engine (DPE).
2.  Cliquez sur le bouton **« Nouvelle action »**.
3.  Dans la liste des actions disponibles, sélectionnez **« Export Table to Source »**.
<img className="thumbnail" alt="Configurer une action Export Table to Source — Export table" src="/images/public-cloud/data-platform/product/dpe/actions/export-table-to-source/picts/export-table-1.png" loading="lazy" />

### Choisir les tables à exporter

Tout d'abord, vous devez sélectionner les tables de votre Lakehouse Manager que vous souhaitez exporter.

1.  Une liste des tables disponibles depuis votre [Lakehouse Manager](/guides/public-cloud/data-platform/lakehouse-manager-tables) s'affichera.
2.  Vous pouvez sélectionner **une ou plusieurs tables** dans cette liste pour l'export. Cliquez simplement sur les noms de tables pour les surligner en vue de leur sélection.
<img className="thumbnail" alt="Choisir les tables à exporter — Export table" src="/images/public-cloud/data-platform/product/dpe/actions/export-table-to-source/picts/export-table-2.png" loading="lazy" />
<img className="thumbnail" alt="Choisir les tables à exporter — Export table (2)" src="/images/public-cloud/data-platform/product/dpe/actions/export-table-to-source/picts/export-table-3.png" loading="lazy" />

### Sélectionner la source de destination

Ensuite, vous définirez la source externe vers laquelle les tables sélectionnées seront exportées.

1.  Une liste déroulante ou une liste apparaîtra, affichant les sources compatibles disponibles depuis vos [Connectors](/guides/public-cloud/data-platform/landing-page-connectors-sources).
<img className="thumbnail" alt="Sélectionner la source de destination — Export table" src="/images/public-cloud/data-platform/product/dpe/actions/export-table-to-source/picts/export-table-4.png" loading="lazy" />
2.  **Remarque sur la compatibilité :** Actuellement, cette action prend en charge les sources Connectors de **type base de données et protocoles**.
3.  **Important :** Si aucune destination n'apparaît, cela signifie que vous n'avez pas encore connecté de source de base de données ou de protocole compatible dans vos Connectors. Veuillez vous assurer d'avoir configuré au moins une telle source avant d'essayer d'utiliser cette action.
4.  Sélectionnez la source de destination souhaitée dans la liste.
5.  cliquez sur confirmer et exécuter.
<img className="thumbnail" alt="Sélectionner la source de destination — Export table (2)" src="/images/public-cloud/data-platform/product/dpe/actions/export-table-to-source/picts/export-table-5.png" loading="lazy" />

:::warning
**Remarque importante sur Export Table to Source :** L'action *Export Table to Source* peut **échouer** si la base de données de destination vers laquelle vous exportez a une configuration exigeant des clés primaires pour les tables créées ou insérées. Par exemple, certains systèmes de bases de données ou paramètres de table spécifiques (comme `REQUIRE PRIMARY KEY` dans certaines configurations MySQL/MariaDB ou des configurations NoSQL plus strictes) peuvent l'imposer.
:::

:::info
Par défaut, les tables au sein du Lakehouse Manager **n'ont pas intrinsèquement de clés primaires définies**. Si votre base de données de destination requiert une clé primaire et que le schéma de table entrant n'en fournit pas, l'opération d'export échouera. Pour réussir l'export vers de telles bases de données, vous devrez peut-être ajuster la configuration de la base de données de destination afin d'assouplir temporairement ou définitivement l'exigence de clé primaire.
:::

## Vérifier votre export

Une fois l'action *Export Table to Source* terminée avec succès, vous pouvez vérifier l'export en vous connectant à la base de données ou au système de destination choisi (par exemple, en utilisant un client SQL pour une base de données) et en vérifiant la présence des tables nouvellement exportées et de leurs données. Vous pouvez même vérifier la source des connectors pour contrôler la mise à jour.
