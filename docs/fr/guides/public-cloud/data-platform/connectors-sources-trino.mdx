## Objectif

Trino est un moteur de requêtes SQL distribué open source pour les requêtes ETL ad hoc et par lot sur plusieurs types de sources de données. La Platform vous permet d'utiliser Trino pour accéder aux sources de votre application.

<img className="thumbnail" alt="Trino" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/trino/picts/trino-connector-selection.png" loading="lazy" />

## Ajouter une source Trino sur la Platform

### Configurer votre connexion

Lors de la création de la source, vous devrez renseigner les informations suivantes :

- **Host** : le nom d'hôte du serveur Trino.
- **Port** : l'adresse de port du serveur Trino *(8080 par défaut)*.
- **Catalog** : le nom du catalogue du serveur Trino.
- **Schema** : le nom du Schema du serveur Trino.
- **Nom d'utilisateur** : le nom d'utilisateur pour le serveur Trino.
- **Mot de passe** : le mot de passe associé au nom d'utilisateur que vous utilisez.
- **SSL** : si cette option est activée, elle chiffre les informations échangées entre la Data Platform et la base de données.

<img className="thumbnail" alt="Trino" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/trino/picts/trino-connector-config.png" loading="lazy" />

### Sélectionner les tables souhaitées

Une fois la connexion établie avec votre serveur Trino, vos tables sont récupérées et affichées :

<img className="thumbnail" alt="Trino" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/trino/picts/trino-select-tables.png" loading="lazy" />

Sélectionnez les tables à inclure dans la source en cochant les cases situées à gauche du nom de la table, comme indiqué sur l'image ci-dessus.

:::info
Si l'état de la base de données change, vous pouvez utiliser le bouton *Fetch* pour actualiser les tables affichées et les inclure dans votre source.
:::

Une fois ces étapes réalisées, cliquez sur le bouton *Sauvegarder* en haut à droite.

:::warning
N'oubliez pas de nommer votre source avant de la créer. Le nom technique ne peut plus être modifié après la création de la source et sera utilisé lors de l'ouverture de la source via le [SDK](/guides/public-cloud/data-platform/landing-page-developers-python-sdk).
:::

## Connecter Trino à un Projet Platform existant

Vous pouvez utiliser **Trino** comme connecteur vers un projet existant sur la Platform. Cela sera utile dans le cas où vous devez extraire des données d'un projet vers un autre. Le tutoriel est disponible [ici](/guides/public-cloud/data-platform/tutorials-trino-connector).
