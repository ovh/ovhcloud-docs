## Qu'est-ce que l'Analyzer ?

L'Analyzer est le premier contrôle qualité appliqué aux données entrantes. Il s'exécute sur une source enregistrée avant que ces données n'atteignent une table de projet, de sorte que les problèmes de structure, de typage et de formatage sont détectés à l'entrée plutôt qu'après qu'un chargement les a écrits dans le Lakehouse.

<img className="thumbnail" alt="analyzer" src="/images/public-cloud/data-platform/product/connectors/analyzer/picts/analyzer-index.png" loading="lazy" />

Il remplit deux fonctions.

**L'extraction des métadonnées** lit la forme des objets sources : les champs qu'ils exposent, leurs types et les volumes concernés. Chaque [action de chargement](/guides/public-cloud/data-platform/dpe-actions-load) en aval s'appuie sur ces métadonnées, une source doit donc être analysée avant que ses objets puissent être chargés.

**Les règles de blueprint** constituent la couche de nettoyage appliquée par-dessus. Un blueprint est un ensemble nommé de conditions et de transformations appliqué à un objet source au fil du passage de ses données, afin que les formats de date, la casse, la précision numérique et la gestion des valeurs nulles suivent un standard unique pour chaque source alimentant le projet.

Extrayez d'abord les métadonnées. Les règles de blueprint s'écrivent sur des champs que l'Analyzer a déjà trouvés.
