## Objectif

Le File Transfer Protocol (FTP) est un protocole réseau standard utilisé pour le transfert de fichiers informatiques entre un client et un serveur sur un réseau informatique.
La Platform vous permet de vous connecter à un serveur FTP, de sélectionner vos fichiers sur celui-ci, et d'importer leurs données directement dans votre platform.

## Ajouter une source FTP sur la Platform

### Vue d'ensemble de l'écran de configuration

Une fois que vous avez trouvé *FTP* dans le **Platform Store**, cliquez sur *Sélectionner* et vous pourrez voir l'écran de configuration comme illustré ci-dessous -

### Fichiers et tailles pris en charge

Avant de continuer à apprendre comment configurer une source FTP, il est intéressant de noter que -

- Même si notre connecteur FTP est capable de lister tous les fichiers de votre serveur, gardez à l'esprit que l'extraction de meta/data ne prend en charge que les types suivants : .csv, .xls, .xlsx, .xml, .json, .parquet

- Pour l'extraction de métadonnées (voir la partie Analyze de notre guide des connecteurs), les limites réelles de taille pour un fichier téléchargé par notre connecteur FTP sont :
 - Extraction complète : environ 900 Mo
 - Extraction d'échantillon : environ 2,5 Go

### Configurer votre source

Lors de la création de la source, vous devrez renseigner les informations suivantes :

- Host : L'URL/IP du serveur FTP auquel vous souhaitez vous connecter (ex : 127.0.0.1)
- Port : Le port écouté par votre serveur FTP (21 par défaut pour la plupart des serveurs FTP)
- Nom d'utilisateur : L'identifiant utilisé pour s'authentifier
- Mot de passe : Le mot de passe associé
- Path : Le chemin nécessaire pour trouver vos fichiers sur le serveur (ex : Documents/data/export_2018.csv)

Une fois ces informations ajoutées, cliquez sur *Connecter* puis sur le bouton *Créer* en haut à droite.

:::warning
N'oubliez pas de nommer votre source avant de la créer. Le nom technique ne peut plus être modifié après la création de la source et sera utilisé lors de l'ouverture de la source via le [SDK](/guides/public-cloud/data-platform/landing-page-developers-python-sdk).
:::
