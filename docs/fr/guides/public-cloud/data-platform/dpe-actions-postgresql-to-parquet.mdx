## Objectif

L'action *PostgreSQL to Parquet* extrait des données d'une base de données PostgreSQL et les place dans un [fichier Parquet](https://parquet.apache.org/) dans le bucket de votre Projet. Vous pouvez choisir le format de fichier.

:::info
**Note:** Cette action prend en charge la fonctionnalité permettant d'avoir une date personnalisée dans le nom du dossier. Vous pouvez trouver le tutoriel [ici](/guides/public-cloud/data-platform/tutorials-dated-export-folders).
:::

## Configurer une action PostgreSQL to Parquet

Pour créer une nouvelle action, accédez à l'**onglet Action** du Data Processing Engine (DPE), cliquez sur **Nouvelle action** et sélectionnez l'action *PostgreSQL to Parquet*.

### Choisir une source et une destination

Pour configurer l'action, commencez par sélectionner une source dans la liste que vous avez déjà configurée dans l'onglet [Sources](/guides/public-cloud/data-platform/landing-page-connectors-sources) du Lakehouse Manager.

<img className="thumbnail" alt="Choisir une source et une destination — Sélectionner la source" src="/images/public-cloud/data-platform/product/dpe/actions/postgresql-to-parquet/picts/select-source.png" loading="lazy" />

Ensuite, choisissez le *bucket de destination* dans la liste des [buckets du Projet](/guides/public-cloud/data-platform/lakehouse-manager-buckets).

<img className="thumbnail" alt="Choisir une source et une destination — Liste des buckets" src="/images/public-cloud/data-platform/product/dpe/actions/postgresql-to-parquet/picts/list-buckets.png" loading="lazy" />

### Fichier de destination

Il vous sera ensuite demandé de choisir le dossier de destination. Si vous laissez le nom du dossier vide, il sera automatiquement nommé d'après le nom de la source.

<img className="thumbnail" alt="Fichier de destination — Sélectionner la destination" src="/images/public-cloud/data-platform/product/dpe/actions/postgresql-to-parquet/picts/select-destination.png" loading="lazy" />

Vos données seront placées dans le dossier de destination dans un fichier nommé *part-1*. Si votre fichier est trop volumineux, il sera divisé en plusieurs fichiers nommés *part-1*, *part-2*, *part-3*, et ainsi de suite.

L'ordre de vos lignes sera préservé au cours de ce processus. Ainsi, les premières lignes se trouveront dans le fichier *part-1* et les lignes suivantes se trouveront dans le fichier *part-2*.

:::info
Notez que cette action a sa **vitesse de transfert optimisée** pour la source PostgreSQL.
:::
