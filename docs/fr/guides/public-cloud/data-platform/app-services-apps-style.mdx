## Objectif

Au sein d'une application, la Platform permet de modifier le style et le design. La définition de la charte graphique à appliquer à l'application est centralisée dans l'onglet *Style*. Ces modifications en CSS / LESS peuvent être appliquées dans différents fichiers comme sur l'image ci-dessous :

<img className="thumbnail" alt="L'onglet Style, où les fichiers CSS et LESS sont édités" src="/images/public-cloud/data-platform/product/app-manager/picts/app-style.png" loading="lazy" />

Les modifications du style de l'application nécessitent de reconstruire l'artefact ainsi que de le redéployer.
