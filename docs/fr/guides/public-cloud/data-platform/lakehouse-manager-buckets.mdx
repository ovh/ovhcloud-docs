## Objectif

Les Buckets Data Platform sont des **espaces de stockage d'objets compatibles S3** qui vous permettent de stocker toute donnée non structurée. Considérez les buckets comme différents espaces de travail, par exemple, un dépôt de photos ou de vidéos.

<img className="thumbnail" alt="buckets" src="/images/public-cloud/data-platform/product/lakehouse-manager/buckets/picts/buckets-1.png" loading="lazy" />

## Créer un bucket

Pour créer un nouveau bucket, cliquez sur le bouton _+ New Bucket_ en bas à gauche de l'écran.

Ensuite, nommez votre bucket et cliquez sur _Confirm_.

<img className="thumbnail" alt="buckets" src="/images/public-cloud/data-platform/product/lakehouse-manager/buckets/picts/buckets-2.png" loading="lazy" />

## Téléverser des fichiers

Une fois votre bucket créé, vous verrez apparaître un bouton _+ Upload file_. Cliquez simplement dessus et glissez-déposez votre fichier pour le téléverser.

<img className="thumbnail" alt="upload file" src="/images/public-cloud/data-platform/product/lakehouse-manager/buckets/picts/buckets-3.png" loading="lazy" />

:::warning
Il existe une **limite de taille de 10 Go** sur les fichiers gérés par les PlatformBuckets.
:::

## Supprimer un bucket

Pour supprimer un bucket, cliquez sur _Remove Bucket_ dans le coin supérieur droit de l'écran. Vous devrez ensuite saisir le nom du bucket et cliquer sur _Confirm_ pour supprimer le bucket.

<img className="thumbnail" alt="delete bucket" src="/images/public-cloud/data-platform/product/lakehouse-manager/buckets/picts/buckets-4.png" loading="lazy" />

## Bucket Iceberg

L'écran Buckets liste également le **bucket Iceberg** de votre projet : l'espace de stockage d'objets contenant les données de vos [tables Lakehouse Manager](/guides/public-cloud/data-platform/lakehouse-manager-tables).

:::info
Le bucket Iceberg est **en lecture seule**. Vous pouvez parcourir ses fichiers, mais vous ne pouvez rien téléverser, modifier ou supprimer, et le bucket lui-même ne peut pas être supprimé. Pour travailler avec les données qu'il contient, utilisez les [tables](/guides/public-cloud/data-platform/lakehouse-manager-tables) de votre projet et l'[Explorer](/guides/public-cloud/data-platform/lakehouse-manager-explorer).
:::

## Gérer les permissions sur les buckets

Vous pouvez également gérer la manière dont chaque utilisateur est autorisé à interagir avec les buckets. Ces permissions sont gérées dans l'[Identity Access Manager](/guides/public-cloud/data-platform/landing-page-iam).

Pour plus de détails, consultez l'article suivant :
