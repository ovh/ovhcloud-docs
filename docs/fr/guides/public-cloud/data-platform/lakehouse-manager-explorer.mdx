## Objectif

L'Explorer est un outil puissant et flexible conçu pour **effectuer des analyses exploratoires de données** dans une interface facile à utiliser, à l'aide d'un outil de requête visuel sans code, ou de SQL.

Il offre un moyen simple de vérifier le contenu des tables et d'obtenir les informations dont vous avez besoin pour décider quoi construire ensuite, y compris les données que vous avez [chargées via le Data Processing Engine](/guides/public-cloud/data-platform/dpe-actions-load) dans le Lakehouse Manager, et les données auxquelles vous accédez via les points d'entrée ci-dessous.

## Trouver des tables dans l'Explorer

Dans l'Explorer, vous pouvez lister et ouvrir des tables de trois manières :

- **Folders** : parcourir la hiérarchie des dossiers.
- **Datasets** : parcourir par dataset. Une catégorie **Shared Datasets** est également listée ici lorsque d'autres projets de votre organisation ont [partagé des datasets](/guides/public-cloud/data-platform/lakehouse-manager-datasets#partage-inter-projets-bêta) avec ce projet. Les tables de datasets partagés ne peuvent être interrogées qu'à l'aide de l'éditeur SQL.
- **Direct query** : lorsqu'une source de données a **direct query** activé, elle apparaît dans cette liste. Vous pouvez la sélectionner et explorer les tables **directement** dans l'Explorer, sans avoir à importer ou charger ces tables dans le Lakehouse Manager au préalable.

<img className="thumbnail" alt="explorer with sql" src="/images/public-cloud/data-platform/product/lakehouse-manager/explorer/picts/explorer-overview.png" loading="lazy" />

L'Explorer est un outil collaboratif. Vous et votre équipe pouvez travailler sur plusieurs onglets en même temps, et vous pouvez voir les requêtes de vos coéquipiers en basculant sur leurs onglets. Vous ne pouvez modifier que les onglets que vous avez créés : les onglets de vos coéquipiers sont en mode lecture seule.

:::info
L'Explorer n'affiche les résultats que sous forme de table. Si vous souhaitez créer des graphiques et des visualisations, utilisez l'[Analytics Manager](/guides/public-cloud/data-platform/landing-page-analytics-manager)
:::
