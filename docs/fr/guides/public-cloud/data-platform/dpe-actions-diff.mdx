## Objectif

Lorsque vous avez des tables contenant des attributs datés décrivant des valeurs totales (total des commandes quotidiennes, revenu mensuel total, etc.) à un instant donné, l'action diff vous permet de calculer la différence de ces valeurs entre des incréments de temps consécutifs.

Par exemple, prenons l'attribut *total_fans* dans la table ci-dessous, calculé chaque jour pour une certaine page de profil de réseau social. En supposant que *total_fans* décrit le nombre total de fans depuis la création de ce profil, l'action **diff** vous permettra de calculer le nombre de nouveaux fans acquis ou perdus entre chaque jour.

 <img className="thumbnail" alt="diff" src="/images/public-cloud/data-platform/product/dpe/actions/diff/picts/diff_explain.png" loading="lazy" />

Veuillez noter que les premières dates de chaque id n'auront pas leur première valeur incrémentale calculée, car la date précédente n'est pas connue.
Il existe un paramètre avancé optionnel si vous disposez de la date de création afin que la première date incrémentale soit calculée comme égale à l'attribut total.

## Configuration de l'action

### Interface de configuration de l'action

Lors de la configuration de l'action **diff** depuis l'interface, il vous sera demandé de spécifier :

- le **nom de table** qui contient la valeur totale
- l'**attribut de timeline** qui sera utilisé pour obtenir les incréments de temps entre 2 valeurs totales
- la **mesure** à calculer, il peut y en avoir plusieurs pour une table donnée ; pour chacune, spécifiez l'**attribut de valeur cumulative** et l'**attribut de valeur incrémentale**

Les clés primaires de la table sont automatiquement assignées.

 <img className="thumbnail" alt="diff" src="/images/public-cloud/data-platform/product/dpe/actions/diff/picts/diff.png" loading="lazy" />

### Exemple de configuration JSON de l'action

Comme toute autre action du DPE, vous pouvez également configurer l'action en « Mode avancé » en éditant sa configuration JSON, dont un extrait est présenté ci-dessous.

```json
{
    "table": "dwh/default_dataset/posts",
    "attribute_timeline": "date",
    "attribute_total": ["total_impressions"],
    "attribute_diff": ["incr_impressions"],
    
    "table_attribute_created_at": "ref_posts",
    "attribute_created_at": "post_createdat",
}
```

### Paramètres de l'action

Voici une brève description de tous les attributs disponibles dans la configuration JSON.

|                Paramètre                | Description              | Exemple              | Requis              | 
| :------------------------------: | -------------------------- | -------------------------- | -------------------------- | 
|             **table**              | Nom de la table sur laquelle exécuter l'action diff                   |Dwh/agr_site_date| Oui              | 
|            **attribute_timeline**             | Nom de l'attribut de timeline                 |    date      | Oui              | 
|            **attribute_total**             | Liste des noms d'attributs contenant des totaux.    |    ["total_impressions"]      | Oui              | 
|            **attribute_diff**             | Liste des noms d'attributs contenant des valeurs incrémentales. |    ["incr_impressions"] | Oui             | 
|            **table_attribute_created_at**             | Table optionnelle contenant la date de création des id |    ref_posts | Non             | 
|            **attribute_created_at**             | Attribut optionnel contenant la date de création des id |    post_createdat | Non             |
