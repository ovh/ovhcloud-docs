## Objectif

La Platform est conçue pour évoluer facilement au fur et à mesure que les besoins de votre Projet de données changent.

Dans le Data Processing Engine, chaque action ou workflow peut être **dimensionné à la fois horizontalement et verticalement**, ce qui signifie que vous pouvez paralléliser les tâches de traitement et ajouter indéfiniment davantage de puissance de calcul à chacune d'elles.

## Dimensionner vos tâches horizontalement

Vous pouvez **paralléliser la charge de travail** de votre action ou workflow en sélectionnant le nombre d'instances parallèles dans lesquelles votre job sera exécuté. Généralement, plusieurs instances sont utilisées pour les processus suivants :

- L'utilisation de la [segmentation](/guides/public-cloud/data-platform/dpe-jobs-segmentation) pour un job
- L'exécution de workflows avec plusieurs actions dans le même [stage](/guides/public-cloud/data-platform/dpe-workflows#stages)
- L'exécution de plusieurs occurrences [concurrentes](/guides/public-cloud/data-platform/dpe-jobs-preferences#exécutions-concurrentes)
 de la même [action/workflow Always-up](/guides/public-cloud/data-platform/dpe-jobs-preferences#always-up)

:::info
Si vous n'allouez pas plusieurs instances pour les processus ci-dessus, les tâches décomposées seront simplement exécutées les unes après les autres sur l'instance unique.
:::

Pour changer le nombre d'instances parallèles allouées à une action ou un workflow, rendez-vous dans son onglet **Preferences**.

<img className="thumbnail" alt="Dimensionner vos tâches horizontalement — Preferences" src="/images/public-cloud/data-platform/product/dpe/jobs/picts/preferences.png" loading="lazy" />

Changez le nombre d'instances dans le panneau Ressources.

<img className="thumbnail" alt="Dimensionner vos tâches horizontalement — Instances" src="/images/public-cloud/data-platform/product/dpe/jobs/picts/instances.png" loading="lazy" />

## Dimensionner vos tâches verticalement

Vous pouvez allouer **davantage de puissance de calcul** à une action ou un workflow en augmentant le nombre de Data Platform Units (DPU) de chaque instance de calcul. Le DPU est une unité de capacité de traitement, représentant l'accès à une certaine quantité de CPU et de mémoire, comme suit :

- **DPU** : - correspond approximativement à *1 vCPU* et *4 Go de RAM*, selon la disponibilité du matériel.

:::info
Par défaut, les actions ou workflows nouvellement créés se voient allouer 2 DPU.
:::

Pour changer la quantité de DPU allouée à une action ou un workflow, rendez-vous dans son onglet **Preferences**.

<img className="thumbnail" alt="Dimensionner vos tâches verticalement — Preferences" src="/images/public-cloud/data-platform/product/dpe/jobs/picts/preferences.png" loading="lazy" />

Utilisez le curseur pour définir la taille de DPU souhaitée pour [chaque instance parallèle](/guides/public-cloud/data-platform/dpe-jobs-resources#dimensionner-vos-tâches-horizontalement) de l'exécution.

<img className="thumbnail" alt="Dimensionner vos tâches verticalement — Size" src="/images/public-cloud/data-platform/product/dpe/jobs/picts/size.png" loading="lazy" />

La quantité totale finale de DPU allouée à un job DPE correspond au nombre d'instances parallèles multiplié par la taille de DPU de chacune.

:::info
Si vous utilisez le [mode d'exécution Always-up](/guides/public-cloud/data-platform/dpe-jobs-preferences), vous pouvez tout de même mettre à jour vos ressources. La mise à jour prendra effet peu après le changement de vos paramètres et vos workflows/actions ne seront pas interrompus dans le processus.
:::
