## Objectif

Cette action permet de supprimer les entrées obsolètes qui ont existé à un moment donné mais qui n'existent plus. Compatible avec tous les moteurs de données de la Data Platform.

## Exemple de cas d'usage

Une entrée de données erronée a été effectuée dans un fichier source. Le DPE a automatiquement inséré l'entrée dans les tables primaire et d'agrégation. Une fois l'entrée incorrecte découverte, elle a été supprimée de la source, cependant, elle reste toujours présente dans les tables primaire et d'agrégation.

## Comment l'utiliser

Lorsque vous devez supprimer des éléments qui n'existent plus, nous vous recommandons de créer une table temporaire qui servira de zone de travail, ne contenant que les données que vous souhaitez conserver. Cela vous permettra de définir un périmètre sur le champ date qui vous permet d'agir uniquement pour une durée donnée. Si vous devez agir sur toutes les données, la solution la plus simple n'est pas d'utiliser delete diff, mais de simplement vider les tables au préalable avec flush tmp et de les remplir avec les nouvelles données via la source.

Créez une action delete diff pour chaque table dont vous souhaitez supprimer les enregistrements, en utilisant la table temporaire comme table de référence. Sélectionnez l'attribut sur lequel vous souhaitez effectuer la comparaison. Optionnellement, définissez un périmètre de date via la section des préférences.

## Exemple en mode avancé

```json
{ 
	"diffToCheck" : [
      {
        "tablecheck": "dwh/default_dataset/testfile",
        "tabletodelete": "dwh/default_dataset/testfile2",
        "uniqFields": "attr1,attr2"
      }
   ]
}
```
