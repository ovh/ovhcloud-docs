## Qu'est-ce qu'une app ?

Une app est une application web déployée servie depuis le projet, conçue pour présenter des dashboards et des données aux utilisateurs finaux sans faire tourner votre propre infrastructure front-end. Les apps sont créées soit à partir d'un modèle du Platform Store, soit en important du code existant depuis un dépôt Git.

<img className="thumbnail" alt="Application Services" src="/images/public-cloud/data-platform/product/app-manager/picts/appmanager-home-new.png" loading="lazy" />

Construire une app suit un ordre fixe : choisir un modèle ou importer du code, sélectionner des extensions dont les bibliothèques de visualisation, construire les dashboards, organiser la navigation et les menus, puis éventuellement ajuster le style, le formatage des valeurs et les traductions. Le versionnement et le déploiement viennent en dernier, et une modification n'atteint la production qu'à travers un build et un déploiement.

Chaque app est reliée à une [API](/guides/public-cloud/data-platform/landing-page-app-services-apis) déployée, c'est ainsi qu'elle lit les données du projet, et chaque app authentifie ses utilisateurs auprès de l'[IAM](/guides/public-cloud/data-platform/iam-application-authentication) du projet, de sorte qu'un utilisateur final ne voit que les données que ses rôles autorisent.

Les pages ci-dessous couvrent chaque partie d'une app : les dashboards et leurs graphiques, le catalogue d'extensions, le style, les menus, les traductions, le formatage des valeurs, l'intégration Git et les domaines personnalisés.

La création d'une app, sa construction, le déploiement d'une version et la configuration de ses paramètres sont couverts ensemble dans [Créer et déployer une app](/guides/public-cloud/data-platform/app-services-apps-deploy).
