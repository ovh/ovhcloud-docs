## Là où les données entrent dans le projet

Connectors regroupe chaque système externe dont le projet lit les données, les règles appliquées aux données entrantes, et les outils externes autorisés à relire les résultats.

Trois domaines se répartissent le travail. **Sources** enregistre la connexion à un système externe : identifiants, accès réseau, et les objets que cette source expose. L'**Analyzer** inspecte ces objets avant tout chargement, en extrayant les métadonnées et en appliquant des règles de blueprint afin que la structure et le formatage soient réglés à l'entrée. **Consumers** fonctionne dans l'autre sens, en exposant les données du projet à des outils externes tels que Power BI, un backend OpenLineage, ou tout client SQL via Trino.

La séparation entre l'enregistrement d'une connexion et le chargement de ses données est délibérée : les identifiants peuvent rester avec une équipe et la modélisation des données avec une autre. L'enregistrement se fait ici. Le chargement se fait dans le [Data Processing Engine](/guides/public-cloud/data-platform/landing-page-dpe), dans des tables gérées par le [Lakehouse Manager](/guides/public-cloud/data-platform/landing-page-lakehouse-manager).
