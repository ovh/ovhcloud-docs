## Objectif

Dans l'onglet Authentication Settings, vous pouvez définir des exigences et configurations globales d'authentification et de connexion pour les utilisateurs de l'organisation.

<img className="thumbnail" alt="Paramètres d'authentification" src="/images/public-cloud/data-platform/product/iam/orga-iam/picts/auth-settings.png" loading="lazy" />

## Configurer un fournisseur d'authentification unique (Single-Sign-On)

### Configuration

Vous pouvez configurer un fournisseur d'authentification unique (Single-Sign-On) externe qui pourra être utilisé à la place de leur compte Data Platform pour valider les identifiants de tous les utilisateurs lors de la connexion.

Pour ce faire, cliquez d'abord sur **+ Add Authentication provider** dans la section *Enterprise Authentication*.

<img className="thumbnail" alt="ajouter un fournisseur" src="/images/public-cloud/data-platform/product/iam/orga-iam/picts/auth-settings2.png" loading="lazy" />

Choisissez ensuite un [fournisseur d'authentification compatible](/guides/public-cloud/data-platform/iam-auth-providers#liste-des-fournisseurs-dauthentification) dans notre liste.

<img className="thumbnail" alt="liste des fournisseurs" src="/images/public-cloud/data-platform/product/iam/orga-iam/picts/provider-list.png" loading="lazy" />

Après avoir confirmé votre choix, vous devrez configurer votre fournisseur.

<img className="thumbnail" alt="configuration du fournisseur" src="/images/public-cloud/data-platform/product/iam/orga-iam/picts/provider-config.png" loading="lazy" />

Une fois votre fournisseur configuré, il est opérationnel et prêt à l'emploi.

<img className="thumbnail" alt="fournisseur ajouté" src="/images/public-cloud/data-platform/product/iam/orga-iam/picts/provider-added.png" loading="lazy" />

### Imposer la connexion SSO à tous les utilisateurs

Si vos besoins de sécurité exigent que tous les utilisateurs de votre organisation se connectent via votre SSO d'entreprise, vous pouvez imposer cette méthode de connexion en activant l'option *disable all other login methods*.

<img className="thumbnail" alt="désactiver toutes les autres méthodes de connexion" src="/images/public-cloud/data-platform/product/iam/orga-iam/picts/enforce-sso-toggle.png" loading="lazy" />

:::warning
Notez que si vous ne configurez pas correctement votre fournisseur puis désactivez les autres options de connexion, vous bloquerez l'accès à la platform pour tous les utilisateurs non authentifiés. Assurez-vous donc de bien configurer votre fournisseur avant de désactiver les autres méthodes de connexion.
:::

## Imposer l'authentification multifacteur

Vous pouvez également exiger que tous les utilisateurs configurent et utilisent l'authentification multifacteur (MFA) pour travailler sur des projets, en cochant l'option *Enforce MFA for all Data Platform accounts*.

<img className="thumbnail" alt="activer le MFA" src="/images/public-cloud/data-platform/product/iam/orga-iam/picts/mfa-toggle.png" loading="lazy" />

Activer cette option obligera tous les utilisateurs de l'organisation à vérifier un numéro de téléphone de leur choix avant de travailler sur un projet sur Data Platform.

## Autoriser les utilisateurs à demander à rejoindre l'organisation

Pour éviter d'avoir à ajouter de nombreux utilisateurs partageant le même domaine de messagerie (par exemple, le domaine de messagerie de votre entreprise), vous pouvez ajouter un domaine comme *allowed to request to join*. Pour ce faire, saisissez le domaine souhaité dans le champ indiqué ci-dessous, puis appuyez sur ENTER.

<img className="thumbnail" alt="demande à rejoindre par domaine" src="/images/public-cloud/data-platform/product/iam/orga-iam/picts/request-to-join.png" loading="lazy" />
