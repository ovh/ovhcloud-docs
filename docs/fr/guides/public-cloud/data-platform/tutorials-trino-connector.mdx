## Objectif

Ce tutoriel montre comment utiliser le [Trino Connector](/guides/public-cloud/data-platform/connectors-sources-trino) pour extraire des données d'un project vers un autre sur la Platform.

## Introduction

### Prérequis

Pour suivre ce tutoriel, vous devez être familiarisé avec les [Connectors](/guides/public-cloud/data-platform/landing-page-connectors), l'[Analytics Manager](/guides/public-cloud/data-platform/landing-page-analytics-manager), l'[Identity Access Manager](/guides/public-cloud/data-platform/landing-page-iam) et vous devriez idéalement avoir suivi le [guide de Démarrage](/guides/public-cloud/data-platform/landing-page-getting-started). L'essentiel est de savoir à quoi servent les [Sources](/guides/public-cloud/data-platform/landing-page-connectors-sources) et comment les utiliser.

### Aperçu des concepts

Il est courant d'avoir plusieurs projects s'exécutant sur la platform. Dans le scénario où vous souhaiteriez extraire et transférer des données d'un project existant vers un autre, le *Trino Connector* fait le travail.

Cela est rendu possible grâce au **moteur de requête Trino managé** qui fait partie du service [Analytics Manager](/guides/public-cloud/data-platform/landing-page-analytics-manager). Il permet d'interroger les datasets du project - et peut être connecté depuis l'extérieur.

Ce tutoriel suivra un processus en deux étapes :

- Apporter les modifications nécessaires sur le **project source** pour permettre l'extraction des données.
- Utiliser le Trino Connector sur le **project de destination** comme source pour déplacer les données.

Voyons maintenant comment tout cela fonctionne en pratique !

## Utiliser le Trino Connector

### Étapes à suivre sur le project source

Ces premières étapes utilisent le [Lakehouse Manager](/guides/public-cloud/data-platform/landing-page-lakehouse-manager) et l'[Identity Access Manager](/guides/public-cloud/data-platform/landing-page-iam).

1.  **Identifier le Catalog et le Schema source :**
    Trouvez le catalog et le schema auxquels vous souhaitez vous connecter dans l'[Explorer](/guides/public-cloud/data-platform/lakehouse-manager-explorer) du Lakehouse Manager

    Exécutez les commandes SQL suivantes pour récupérer les catalogs et schemas disponibles :

    ```sql
    SHOW CATALOGS
    ```
    Copiez et enregistrez le nom du catalog souhaité en tant que `CATALOG_NAME`.

    <img className="thumbnail" alt="Étapes à suivre sur le project source — Trino connector show catalogs" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-show-catalogs.png" loading="lazy" />

    ```sql
    SHOW SCHEMAS FROM CATALOG_NAME
    ```
:::info
**Remarque :** remplacez `CATALOG_NAME` par le catalog réel que vous avez sélectionné à l'étape précédente.
:::

    Cette commande affichera une liste des schemas disponibles dans le catalog choisi.

    <img className="thumbnail" alt="Étapes à suivre sur le project source — Trino connector show schemas" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-show-schemas.png" loading="lazy" />

    Copiez et enregistrez le nom du schema souhaité en tant que `SCHEMA_NAME`.

:::info
Lors de la création d'un nouveau project, le `default dataset` est fourni. Si vous n'avez pas créé de dataset supplémentaire dans votre project, il s'agit de la sélection appropriée.
:::

2. Ouvrez l'*Identity Access Manager* et créez un nouveau service account destiné à ce transfert.

    <img className="thumbnail" alt="Étapes à suivre sur le project source — Trino connector service account" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-service-account.png" loading="lazy" />

:::info
Veillez à ajouter *Platform Admin* comme groupe pour ce service account
:::

    Une fois le service account créé avec succès, vous devez générer une clé pour l'*API Access*. Cliquez sur le bouton d'ajout comme indiqué dans l'image ci-dessous, puis sur create.

    <img className="thumbnail" alt="Étapes à suivre sur le project source — Trino connector service account (2)" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-service-account-2.png" loading="lazy" />

    <img className="thumbnail" alt="Étapes à suivre sur le project source — Trino connector create api key" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-create-api-key.png" loading="lazy" />

    L'*API Key* et la *Secret Key* vous seront fournies. Veillez à les copier et à les enregistrer en lieu sûr, car vous ne pourrez plus accéder à la *Secret Key* une fois cette page quittée.

    <img className="thumbnail" alt="Étapes à suivre sur le project source — Trino connector created api key" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-created-api-key.png" loading="lazy" />

    Vous avez terminé avec succès toutes les étapes requises sur le project source ; la suite du tutoriel se poursuivra sur le project de destination.

### Étapes à suivre sur le project de destination

1. Rendez-vous dans les *Connectors* et ajoutez une nouvelle Trino Source.

<img className="thumbnail" alt="Étapes à suivre sur le project de destination — Trino connector add source" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-add-source.png" loading="lazy" />

2. Renseignez les détails ci-dessous et cliquez sur connect

 - **Host :** remplacez par votre *Project_Name* ***source*** + `-query.eu.dataplatform.ovh.net`
 - **Port :** 443
 - **Catalog :** remplacez par votre *CATALOG_NAME*
 - **Schema :** remplacez par votre *SCHEMA_NAME*
 - **Username :** remplacez par *API_KEY*
 - **Password :** remplacez par *SECRET_KEY*
 - **SSL :** activé

<img className="thumbnail" alt="Étapes à suivre sur le project de destination — Trino connector source settings" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-source-settings.png" loading="lazy" />

3. Une fois la connexion Trino établie avec succès, la liste des tables disponibles se remplira. Cochez la case en regard du nom de la table que vous souhaitez extraire de la source, puis cliquez sur create.

<img className="thumbnail" alt="Étapes à suivre sur le project de destination — Trino connector source connected" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-source-connected.png" loading="lazy" />

## Utiliser les données extraites

Une fois toutes les étapes précédentes terminées, vous pouvez consulter l'onglet *Analyzer* dans les *Connectors* pour vérifier les tables extraites.

Pour utiliser ces données extraites, vous pouvez suivre l'**étape trois** du tutoriel [Démarrage](/guides/public-cloud/data-platform/getting-started-prepare-data).
