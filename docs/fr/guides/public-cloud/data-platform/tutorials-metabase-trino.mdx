## Objectif

Ce guide propose un pas-à-pas pour configurer une connexion entre Metabase et Data Platform à l'aide de Trino. Les instructions incluent les détails de configuration, des conseils de dépannage courants et des captures d'écran pertinentes pour garantir une configuration sans accroc.

**Avant de commencer :**
Vous aurez besoin des détails de connexion pour Trino sur OVHcloud Data Platform (tels que `host`, `port`, `catalog`, `username (API Key)`, et `password (Secret Key)`). Le moyen le plus simple est de créer un [**consumer Trino**](/guides/public-cloud/data-platform/connectors-consumers-trino), qui génère une chaîne de connexion contenant toutes ces valeurs. Vous pouvez aussi les assembler manuellement en suivant [Intégrer Trino à des outils externes](/guides/public-cloud/data-platform/tutorials-trino-external-tools).

:::info
Pour les besoins de ce tutoriel, nous utiliserons une instance de Metabase hébergée localement, s'exécutant sur [Docker](https://docs.docker.com/desktop/). Cette configuration permet un déploiement facile et un isolement tout en gardant l'environnement cohérent entre différents systèmes.
:::

## Étapes pour connecter Metabase à Data Platform via Trino

### Étape 1 : configurer un Metabase auto-hébergé avec Docker-Compose

**1. Préparer l'environnement**

Assurez-vous d'avoir **Docker** et **Docker Compose** installés sur votre serveur ou machine locale.

**2. Créer un fichier Docker Compose**

Créez un fichier `docker-compose.yml` dans votre répertoire de travail et ajoutez la configuration suivante :

```yaml
version: "3.8"
services:
  metabase:
    image: metabase/metabase:latest
    container_name: metabase
    platform: linux/amd64
    ports:
      - "3000:3000"
    volumes:
      - ./data/metabase:/metabase-data # Aligner avec les autres chemins
      - ./data/metabase/plugins:/plugins
    environment:
      - MB_DB_FILE=/metabase-data/metabase.db
```

**3. Créer la structure de répertoires**

Avant d'exécuter `docker-compose up`, vous devez créer la structure de répertoires attendue par le fichier *docker-compose.yml*. Cela garantit que Metabase peut correctement stocker ses données et ses plugins.

Créez les répertoires suivants dans votre répertoire de travail :

:::info
1. ./data/metabase
2. ./data/metabase/plugins
:::

Vous pouvez créer ces répertoires à l'aide des commandes suivantes dans votre terminal :

```bash
mkdir -p ./data/metabase
mkdir -p ./data/metabase/plugins
```

Cela créera la structure de répertoires nécessaire pour que Metabase puisse conserver ses données et stocker ses plugins.

Pour démarrer Metabase à l'aide de Docker, exécutez la commande suivante :

```sh
docker-compose up -d
```

Une fois démarré, vous pouvez accéder à Metabase à l'adresse `http://localhost:3000` ou remplacer `localhost` par l'IP/domaine de votre serveur.

:::info
**Première configuration** : Si vous exécutez Metabase pour la première fois, le processus de configuration peut prendre un certain temps. Vous pouvez surveiller les logs pour vérifier quand Metabase est pleinement opérationnel à l'aide de :
:::

```sh
docker logs -f metabase
```
Cette commande affichera des logs en temps réel, vous permettant de vérifier que le service a démarré avec succès.

### Étape 2 : télécharger et ajouter le plugin Starburst

Rendez-vous sur la [**page du plugin Starburst**](https://github.com/starburstdata/metabase-driver/releases) et téléchargez le dernier **pilote JDBC** pour Starburst. Ce pilote permet à Metabase de se connecter à Trino (anciennement Starburst/PrestoSQL).

Repérez le fichier JDBC téléchargé (par exemple, `starburst-6.1.0.metabase-driver.jar`) et copiez-le dans le répertoire de plugins de Metabase (`./data/metabase/plugins` tel que configuré dans `docker-compose.yml`).

Assurez-vous que le conteneur Metabase a accès au répertoire de plugins, et **redémarrez Metabase** si nécessaire, à l'aide de :

```sh
docker-compose restart metabase
```

### Étape 4 : fournir les détails de connexion

En utilisant les détails de connexion Trino issus de la chaîne de connexion de votre [consumer Trino](/guides/public-cloud/data-platform/connectors-consumers-trino) (ou construits manuellement via le [guide d'intégration](/guides/public-cloud/data-platform/tutorials-trino-external-tools)), renseignez le formulaire de connexion Metabase avec les valeurs suivantes :

-   **Host** : L'hôte Trino, par exemple, `{ProjectName}-query.eu.dataplatform.ovh.net`.
-   **Port** : Le port Trino, généralement `443`.
-   **Catalog** : Le nom du catalogue Trino auquel vous souhaitez vous connecter.
-   **Schema (optionnel)** : Saisissez le nom du schéma souhaité, ou laissez vide pour autoriser l'accès à tous les schémas du catalogue. (Remarque : dans Metabase, 'Schema' désigne un regroupement logique de tables, et non une seule table.)
-   **Username** : Votre API Key Trino.
-   **Password** : Votre Secret Key Trino.

<img className="thumbnail" alt="Étape 4 : fournir les détails de connexion — Metabase" src="/images/public-cloud/data-platform/getting-further/metabase-trino-connector/picts/metabase-15.png" loading="lazy" />

### Étape 5 : paramètres avancés

Développez les **Advanced Options** et configurez les éléments suivants :

-   **Enable SSL** : Cochez cette option pour utiliser une communication sécurisée. Ceci est fortement recommandé pour les environnements de production.
<img className="thumbnail" alt="Étape 5 : paramètres avancés — Metabase" src="/images/public-cloud/data-platform/getting-further/metabase-trino-connector/picts/metabase-16.png" loading="lazy" />
-   **Extra JDBC Parameters** : Incluez tout paramètre supplémentaire nécessaire à votre configuration spécifique. Laissez vide si vous n'êtes pas sûr.

### Étape 6 : finaliser et tester la connexion

Après avoir saisi tous les détails nécessaires, cliquez sur le bouton **Save** pour finaliser la connexion à la base de données. Metabase tentera de se connecter à votre instance Trino OVHcloud Data Platform à l'aide des identifiants fournis.

Vous pouvez maintenant quitter le panneau Admin.

### Étape 7 : laisser le temps à la synchronisation de la base de données

Après avoir enregistré la connexion, Metabase commencera à se synchroniser avec votre base de données OVHcloud Data Platform. Ce processus peut prendre un certain temps, surtout si vous avez un grand nombre de tables.

<img className="thumbnail" alt="Étape 7 : laisser le temps à la synchronisation de la base de données — Metabase" src="/images/public-cloud/data-platform/getting-further/metabase-trino-connector/picts/metabase-17.png" loading="lazy" />
<img className="thumbnail" alt="Étape 7 : laisser le temps à la synchronisation de la base de données — Metabase (2)" src="/images/public-cloud/data-platform/getting-further/metabase-trino-connector/picts/metabase-18.png" loading="lazy" />

**Recommandation** : Laissez suffisamment de temps à Metabase pour terminer le processus de synchronisation. La durée dépend de la taille et de la complexité de votre base de données. Vous pouvez suivre la progression en arrière-plan ou consulter les logs de Metabase (`docker logs -f metabase`) pour vérifier l'achèvement.

### Étape 8 : explorer et utiliser les fonctionnalités de Metabase

<img className="thumbnail" alt="Étape 8 : explorer et utiliser les fonctionnalités de Metabase — Metabase" src="/images/public-cloud/data-platform/getting-further/metabase-trino-connector/picts/metabase-19.png" loading="lazy" />

Une fois la synchronisation de la base de données terminée, vous pouvez pleinement explorer et utiliser les fonctionnalités de Metabase :

-   **Data Exploration** : Parcourez vos bases de données et tables OVHcloud Data Platform directement dans Metabase.
-   **Querying** : Utilisez le générateur de requêtes de Metabase pour créer des requêtes SQL personnalisées et récupérer des données spécifiques.
-   **Dashboard Creation** : Construisez des dashboards interactifs avec des visualisations pour suivre les métriques et tendances clés.
-   **Reporting** : Générez et planifiez des rapports pour partager des insights avec votre équipe.
-   **Alerting** : Configurez des alertes pour être notifié des changements importants dans vos données.

Une fois la connexion établie avec succès, vous pouvez désormais tirer parti des puissantes fonctionnalités de Metabase pour analyser et visualiser vos données stockées dans OVHcloud Data Platform via Trino.
