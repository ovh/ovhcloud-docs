## Objectif

Les environnements vous permettent de sauvegarder et de réutiliser rapidement un ensemble de [configurations et de préférences d'exécution](/guides/public-cloud/data-platform/dpe-jobs-preferences) dans les actions et les workflows.

<img className="thumbnail" alt="env" src="/images/public-cloud/data-platform/product/dpe/environments/picts/environment.png" loading="lazy" />
*Figure 1 : Le panneau des environnements*

Les environnements ne sont pas permanents. À tout moment, vous pouvez [changer l'environnement d'une tâche](/guides/public-cloud/data-platform/dpe-jobs-preferences), même si un environnement avait déjà été appliqué.

:::info
Si vous apportez des modifications aux paramètres d'un environnement, ces changements seront répercutés sur toutes les actions et tous les workflows auxquels cet environnement est associé.
:::

- [Créer un environnement](/guides/public-cloud/data-platform/dpe-environments#créer-un-environnement)

## Créer un environnement

Lorsque vous accédez pour la première fois à l'onglet **Environment**, un espace vierge s'affiche afin que vous puissiez y créer vos environnements personnalisés.

<img className="thumbnail" alt="env" src="/images/public-cloud/data-platform/product/dpe/environments/picts/env.png" loading="lazy" />

Cliquez sur **New environment** et une version réduite de la section [préférences](/guides/public-cloud/data-platform/dpe-jobs-preferences) apparaît.

<img className="thumbnail" alt="env" src="/images/public-cloud/data-platform/product/dpe/environments/picts/env-panel.png" loading="lazy" />

À partir de là, sélectionnez vos *ressources*, *options* et *variables d'environnement* préférées. N'oubliez pas de donner un nom et une description à votre environnement.

[Comment configurer les préférences d'exécution](/guides/public-cloud/data-platform/dpe-jobs-preferences)
