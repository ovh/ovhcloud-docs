## Ce que vous allez construire

Le guide de démarrage vous apprendra **comment créer un projet analytique en utilisant la Platform**, à travers des exemples concrets et des bonnes pratiques. À la fin de ce tutoriel, vous serez complètement autonome. Vous serez capable de créer et de déployer votre propre application analytique personnalisée avec un traitement de données sophistiqué.

:::info
**Avant de commencer.** L'accès à Data Platform est configuré une fois par organisation : voir [S'inscrire et se connecter](/guides/public-cloud/data-platform/manage-organizations-signin-signup). Ensuite, [créez un projet](/guides/public-cloud/data-platform/manage-projects-create), ce qui prend environ huit minutes à provisionner. Le tutoriel ci-dessous suppose que les deux sont déjà faits.
:::

Le guide utilise des données d'exemple, et montre comment construire une application analytique avec des insights prédictifs corrélant le trafic du métro dans la ville de Chicago avec des variables météorologiques et la période de l'année.

Ce guide prend environ **1 heure** à réaliser.

Nous recommandons d'utiliser **Chrome** comme navigateur par défaut. Si vous utilisez un navigateur différent et rencontrez des problèmes, consultez le lien vers notre portail d'assistance pour nous contacter.

## Configuration de votre environnement

Avant de commencer à travailler avec des données, vous devrez configurer votre environnement de travail, appelé un **Projet**. Il inclut tous les outils nécessaires ainsi que les ressources de calcul et de stockage dédiées dont vous aurez besoin pour construire votre application analytique.

<img className="thumbnail" alt="Configuration de votre environnement — Dp new homepage" src="/images/public-cloud/data-platform/getting-started/picts/dp_new_homepage.png" loading="lazy" />

Lorsque cela vous est demandé, choisissez le modèle pour créer un **projet de bout en bout**. Cela instanciera tous les services de la Platform pour être prêts à l'emploi dans votre projet.

<img className="thumbnail" alt="Configuration de votre environnement — Create dataplant2 template" src="/images/public-cloud/data-platform/getting-started/picts/create-dataplant2-template.png" loading="lazy" />

Poursuivez avec la création. Une fois que vous avez fait démarrer un Projet, ouvrez-le pour [passer à la création de votre première application](/guides/public-cloud/data-platform/landing-page-getting-started) !

## Construire votre app analytique de zéro sur la Platform

L'objectif de ce tutoriel est de vous familiariser avec la Platform afin que vous puissiez commencer à créer vos propres applications aussi vite et aussi facilement que possible.

Nous allons vous guider à travers les principales étapes pour **construire une app de visualisation de données en moins d'une heure**.

L'application à construire sert à visualiser les trajets dans les stations de métro de Chicago. Elle ressemblera à ceci à la fin de ce tutoriel :

<img className="thumbnail" alt="Application Services" src="/images/public-cloud/data-platform/getting-started/app-init/picts/dashboard-final-new.png" loading="lazy" />

Vous utiliserez des datasets d'exemple, ainsi que toutes les fonctionnalités et le code pré-écrit fournis par la Platform.
