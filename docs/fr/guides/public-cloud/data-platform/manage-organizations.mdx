## Objectif

Les Organisations sont les équipes compartimentées qui relient les utilisateurs individuels (ou membres) et les [Projets](/guides/public-cloud/data-platform/manage-projects) ainsi que leurs services entre eux. Vous pouvez avoir autant de coéquipiers que vous le souhaitez dans votre organisation et chaque membre de l'organisation doit disposer d'un [profil utilisateur](/guides/public-cloud/data-platform/manage-organizations-profile) pour utiliser la platform.

Votre organisation peut travailler sur plusieurs [Projets](/guides/public-cloud/data-platform/manage-projects) en même temps et vous pouvez en créer autant que vous le souhaitez.

:::info
Pour rejoindre une organisation, assurez-vous de disposer déjà d'un [Profil Utilisateur](/guides/public-cloud/data-platform/manage-organizations-profile).
:::

## Créer une organisation

Lorsque vous vous connectez à la Data Platform depuis le Control Panel OVHcloud, une organisation est automatiquement créée. Cette organisation portera le même nom que le Projet Public Cloud correspondant.

**Remarque :** les organisations ne peuvent pas être créées par une autre méthode. Chaque organisation doit être liée à un Projet Public Cloud.

## Rejoindre une organisation existante

Pour rejoindre une organisation qui existe déjà (si votre équipe en possède déjà une, par exemple), vous devez demander à une personne déjà présente de vous inviter.

Vous recevrez un e-mail contenant un lien cliquable vous invitant à rejoindre son organisation.

## Gérer les paramètres de votre organisation

Vous pouvez gérer votre organisation en ouvrant le menu déroulant en haut à droite et en cliquant sur **Gérer les paramètres de l'organisation**.

<img className="thumbnail" alt="Go To Organization" src="/images/public-cloud/data-platform/product/organisations/picts/goToOrganization2.png" loading="lazy" />

À partir de là, vous pourrez configurer :

- Vos Projets
- D'autres paramètres : nom, description, certificats SSL, noms de domaine, etc.

[Découvrez comment configurer une organisation](/guides/public-cloud/data-platform/manage-organizations-settings)
