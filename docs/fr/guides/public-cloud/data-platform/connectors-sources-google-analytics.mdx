## Objectif

Google Analytics 4 (GA4) est la platform d'analytics nouvelle génération de Google qui vous aide à comprendre le comportement des clients sur les sites web et applications. La Data Platform vous permet d'intégrer les données GA4 pour créer des applications puissantes et pilotées par les données.

<img className="thumbnail" alt="Page du store Google Analytics" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-store-page-2.png" loading="lazy" />

## Prérequis

Avant de commencer, assurez-vous d'avoir :

1. **Une propriété Google Analytics 4** - Vous devez utiliser GA4 (et non Universal Analytics)
2. **Un accès à la Google Cloud Console** - La capacité de créer des projets et des comptes de service
3. **Des permissions Admin GA4** - Le rôle Editor ou Administrator sur la propriété GA4
4. **Un accès à la Data Platform** - Les permissions pour créer des sources dans les Connectors

:::info
**Remarque :** Universal Analytics (GA3) n'est plus pris en charge. Si vous utilisez encore Universal Analytics, vous devez d'abord migrer vers GA4.
:::

## Étapes de configuration

### Étape 1 : Récupérer votre Property ID GA4

Le Property ID identifie votre propriété GA4.

1. Connectez-vous à [Google Analytics](https://analytics.google.com)
2. Cliquez sur **Admin** (icône d'engrenage en bas à gauche)
3. Dans la colonne **Property**, cliquez sur **Property Details**
4. Copiez votre **Property ID** (format : `123456789`)

<img className="thumbnail" alt="Étape 1 : Récupérer votre Property ID GA4 — Google analytics property id" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-property-id.png" loading="lazy" />

:::info
Le Property ID est une valeur numérique, différente de l'ancien format View ID utilisé dans Universal Analytics.
:::

### Étape 2 : Créer un compte de service Google

Un compte de service permet à la Data Platform d'accéder de façon sécurisée à vos données GA4 sans nécessiter d'identifiants utilisateur individuels.

#### 2.1 Créer ou ouvrir un projet Google Cloud

1. Rendez-vous sur la [Google Cloud Console](https://console.cloud.google.com)
2. **Si vous avez déjà un projet :** cliquez sur **Create or Select a project** et choisissez votre projet existant
3. **Si vous devez créer un nouveau projet :**
  - Cliquez sur **Create or Select a project** → **NEW PROJECT**
  - Saisissez un **Project name** (par exemple, « DataPlatform-GA4-Integration »)
  - Cliquez sur **CREATE**

<img className="thumbnail" alt="2.1 Créer ou ouvrir un projet Google Cloud — Google analytics create project" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-create-project.png" loading="lazy" />

#### 2.2 Activer l'API Google Analytics Data

1. Dans la Cloud Console, allez dans **APIs & Services** depuis le menu d'accès rapide
2. Cliquez sur **+ Enable APIs and Services**
3. Recherchez **« Google Analytics Data API »**
4. Sélectionnez **Google Analytics Data API** (et non Analytics Reporting API)
5. Cliquez sur **ENABLE**

<img className="thumbnail" alt="2.2 Activer l'API Google Analytics Data — Google analytics api library" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-api-library.png" loading="lazy" />
<img className="thumbnail" alt="2.2 Activer l'API Google Analytics Data — Google analytics data api" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-data-api.png" loading="lazy" />

:::info
Assurez-vous d'activer l'**API Google Analytics Data** pour GA4, et non l'ancienne Analytics Reporting API.
:::

#### 2.3 Créer un compte de service

1. Allez dans **APIs & Services** → **Credentials**
2. Cliquez sur **CREATE CREDENTIALS** → **Service account**
3. Saisissez un **Service account name** (par exemple, « dataplatform-ga4-reader »)
4. Ajoutez une description (optionnel)
5. Cliquez sur **CREATE AND CONTINUE**

<img className="thumbnail" alt="2.3 Créer un compte de service — Google analytics service account" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-service-account.png" loading="lazy" />

#### 2.4 Assigner les permissions (optionnel)

1. Pour **Role**, sélectionnez **Viewer** (optionnel pour cette étape)
2. Cliquez sur **CONTINUE**
3. Cliquez sur **DONE**

#### 2.5 Générer la clé JSON

1. Trouvez le compte de service que vous venez de créer dans la liste
2. Cliquez sur l'**adresse e-mail du compte de service** pour ouvrir les détails
3. Allez dans l'onglet **KEYS**
4. Cliquez sur **ADD KEY** → **Create new key**
5. Sélectionnez le format **JSON**
6. Cliquez sur **CREATE**

<img className="thumbnail" alt="2.5 Générer la clé JSON — Google analytics json key" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-json-key.png" loading="lazy" />
<img className="thumbnail" alt="2.5 Générer la clé JSON — Google analytics json key type" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-json-key-type.png" loading="lazy" />
<img className="thumbnail" alt="2.5 Générer la clé JSON — Google analytics json key download" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-json-key-download.png" loading="lazy" />

:::info
Le fichier de clé JSON se téléchargera automatiquement. Conservez-le en lieu sûr - il contient les identifiants d'accès à vos données.
:::

#### 2.6 Copier l'adresse e-mail du compte de service

Depuis la page de détails du compte de service, copiez l'**adresse e-mail** (format : `service-account-name@project-id.iam.gserviceaccount.com`)

Vous en aurez besoin à l'étape suivante.

### Étape 3 : Accorder les permissions Analytics

Vous devez maintenant donner au compte de service la permission de lire vos données GA4.

1. Connectez-vous à [Google Analytics](https://analytics.google.com)
2. Cliquez sur **Admin** (icône d'engrenage en bas à gauche)
3. Dans la colonne **Property**, cliquez sur **Property access management**
4. Cliquez sur l'icône **+** (en haut à droite) → **Add users**
5. Saisissez l'**adresse e-mail du compte de service** obtenue à l'étape 2.6
6. Décochez **Notify new users by email**
7. Sélectionnez le rôle : **Viewer**
8. Cliquez sur **Add**

<img className="thumbnail" alt="Étape 3 : Accorder les permissions Analytics — Google analytics add user" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-add-user.png" loading="lazy" />
<img className="thumbnail" alt="Étape 3 : Accorder les permissions Analytics — Google analytics add user role" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-add-user-role.png" loading="lazy" />

:::info
Vous avez maintenant accordé à la Data Platform un accès en lecture seule à vos données GA4 via le compte de service.
:::

### Étape 4 : Configurer la source sur la Data Platform

1. Dans les **Connectors** de la Data Platform, trouvez **Google Analytics** dans le store des sources
2. Cliquez sur **Sélectionner** pour ouvrir l'écran de configuration

<img className="thumbnail" alt="Étape 4 : Configurer la source sur la Data Platform — Google analytics configure source" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/google-analytics/picts/google-analytics-configure-source.png" loading="lazy" />

3. Renseignez les champs requis :

| Champ | Description | Exemple |
|-------|-------------|---------|
| **Property ID** | Votre Property ID GA4 de l'étape 1 | `123456789` |
| **Service Account JSON** | Contenu du fichier de clé JSON de l'étape 2.5 | Collez le contenu JSON entier |

4. Cliquez sur **Connecter** pour tester la connexion
5. En cas de succès, cliquez sur **Créer** (en haut à droite)

:::warning
N'oubliez pas de nommer votre source avant de la créer. Le nom technique ne pourra plus être modifié par la suite et sera utilisé dans les appels SDK.
:::

:::info
Votre source Google Analytics 4 est maintenant connectée et prête à l'emploi !
:::

## Dépannage

### Problèmes courants

**Erreur « Invalid credentials »**

- Vérifiez que le contenu du fichier de clé JSON est complet et valide
- Assurez-vous qu'il n'y a pas d'espaces ou de caractères superflus lors du collage
- Vérifiez que l'adresse e-mail du compte de service est correcte

**Erreur « Permission denied »**

- Confirmez que le compte de service dispose d'un accès Viewer à la propriété GA4
- Attendez 5 à 10 minutes que les permissions se propagent
- Vérifiez que vous utilisez le bon Property ID

**Erreur « API not enabled »**

- Assurez-vous que l'**API Google Analytics Data** est activée dans votre projet Google Cloud
- Confirmez que vous êtes dans le bon projet Google Cloud

**Erreur « Property not found »**

- Vérifiez que le Property ID est correct (numérique, sans espaces)
- Assurez-vous d'utiliser un Property ID GA4, et non un View ID Universal Analytics
- Vérifiez que la propriété n'a pas été supprimée
