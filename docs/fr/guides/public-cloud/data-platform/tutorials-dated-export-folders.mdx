## Objectif

Ce tutoriel montre comment ajouter une date personnalisée aux noms de vos dossiers lors de la création des [Data Processing Actions](/guides/public-cloud/data-platform/landing-page-dpe-actions).

:::info
**Remarque :** cette fonctionnalité n'est disponible que pour les actions suivantes : *Load to Bucket*, *MySQL to Parquet* et *PostgreSQL to Parquet*.
:::

## Introduction

### Prérequis

Pour suivre ce tutoriel, vous devez être familiarisé avec le [Data Processing Engine](/guides/public-cloud/data-platform/landing-page-dpe) et vous devriez idéalement avoir suivi le [guide de Démarrage](/guides/public-cloud/data-platform/landing-page-getting-started). L'essentiel est de savoir à quoi servent les [Actions](/guides/public-cloud/data-platform/landing-page-dpe-actions) et comment les utiliser.

### Aperçu des concepts

Lorsque vous créez des actions, vous avez la possibilité de nommer le dossier qui contiendra vos fichiers exportés. Le token *$now* vous permet de définir facilement des dates personnalisées à l'aide de quelques patterns de base dans le nom du dossier.

Il existe 4 patterns disponibles sur la Data Platform :

- **$now(date)**
- **$now(datetime)**
- **$now(timestamp) :** l'horodatage sera affiché au format [UNIX epoch time](https://en.wikipedia.org/wiki/Unix_time)
- **$now(*insérer la séquence ici*) :** créez des séquences de dates personnalisées avec les [codes de format](https://docs.python.org/3/library/datetime.html#strftime-and-strptime-format-codes) disponibles.

Voyons maintenant comment tout cela fonctionne en pratique !

## Utiliser le token $now

Pour ce tutoriel, nous n'explorerons que l'utilisation du token *$now*. Pour savoir comment créer et exécuter des *Actions*, une documentation détaillée est disponible sur les [Actions](/guides/public-cloud/data-platform/landing-page-dpe-actions).

Pour faciliter la compréhension, nous choisirons de créer une action - *Load to Bucket*, censée s'exécuter quotidiennement pour l'avenir prévisible - ce qui entraînera la génération de dossiers sur une base journalière. Pour aider à trier et accéder facilement au bon dossier, le token **$now** peut être utilisé.

À l'étape où l'option de saisie du nom du dossier devient disponible, vous pouvez utiliser le token *$now* comme illustré dans l'exemple ci-dessous.

## Exemples

Voici quelques exemples supplémentaires de l'apparence du nom de dossier selon différents cas d'usage :

- **$now(date) :** 2023-08-15
- **$now(datetime) :** 2023-08-15_20-51-04 
- **$now(timestamp) :** 1692132664 *(Unix epoch time)*
- **$now(%a-%d-%b-%Y_%H-%M%) :** Tue-15-Aug-2023_20-53

:::info
Les noms de dossiers ne devant pas contenir de caractères spéciaux comme *deux-points*, *slash*, *astérisque*, etc., le caractère *tiret* est utilisé pour le format de la date et de l'heure.
:::
