## Objectif

Ce guide fournit une marche à suivre complète pour déployer Apache Superset sur la Data Platform OVHcloud, couvrant l'installation, la configuration et l'intégration Trino pour une configuration sécurisée et fiable.

**Avant de commencer :**
Vous aurez besoin d'une chaîne de connexion Trino active. Le moyen le plus simple est de créer un [**consumer Trino**](/guides/public-cloud/data-platform/connectors-consumers-trino) dans les Connectors ; sinon, construisez-en une manuellement en suivant [Intégrer Trino à des outils externes](/guides/public-cloud/data-platform/tutorials-trino-external-tools). Cette chaîne de connexion est essentielle pour configurer Trino dans Apache Superset.

## Étapes pour connecter Apache Superset à la Data Platform via Trino

### Étape 1 : ajouter Apache Superset dans les Application Services

1.  Accédez à votre project.
2.  Cliquez sur **Create an application** dans la tuile **Application Services**.
    <img className="thumbnail" alt="Étape 1 : ajouter Apache Superset dans les Application Services — Superset" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-09.png" loading="lazy" />
3.  Sélectionnez **Apache Superset**.
    <img className="thumbnail" alt="Étape 1 : ajouter Apache Superset dans les Application Services — Superset (2)" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-10.png" loading="lazy" />
4.  Dans l'Apache Superset Store, sélectionnez le Template souhaité (pour ce tutoriel, nous choisirons v5.0.0 avec SQLite).
    <img className="thumbnail" alt="Étape 1 : ajouter Apache Superset dans les Application Services — Superset (3)" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-11.png" loading="lazy" />

:::info
Le fichier SQLite sera stocké dans le dossier **appservice** du bucket S3<sup>1</sup> (section Lakehouse Manager). Nous recommandons vivement de sauvegarder ce fichier régulièrement.
:::

5.  Indiquez un nom pour la nouvelle application (par exemple, `dashboard`).
    <img className="thumbnail" alt="Étape 1 : ajouter Apache Superset dans les Application Services — Superset (4)" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-12.png" loading="lazy" />
6.  Construisez l'application.
7.  Une fois construite, déployez l'application en cliquant sur le bouton **Deploy**.

### Étape 2 : personnaliser le Template (onglet Editor)

Dans l'onglet **Editor** de votre application, vous avez accès à l'intégralité du code source du template. Vous pouvez le modifier selon vos besoins.

Cela inclut :

-   Le **code source d'Apache Superset** surchargé utilisé dans le template.
-   Un fichier technique **`README.md`** qui explique la structure et les points de personnalisation du template.
-   Le script **`entrypoint.sh`**, qui gère la sauvegarde et la restauration du fichier **`sqlite.db`**.
-   Le fichier standard **`forepaas.json`**, présent dans tous les déploiements AppService, qui définit :
    -   La version d'Apache Superset utilisée
    -   La configuration du **mapping des rôles** et des paramètres d'exécution

:::info
La modification de ce template permet une personnalisation avancée du comportement, de la mise en page et de la logique de déploiement de Superset.
:::

<img className="thumbnail" alt="Étape 2 : personnaliser le Template (onglet Editor) — Superset" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-23.png" loading="lazy" />

### Étape 3 : configurer Trino dans Apache Superset

1.  Ouvrez Apache Superset en cliquant sur le bouton **Open**.

<img className="thumbnail" alt="Étape 3 : configurer Trino dans Apache Superset — Superset" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-13.png" loading="lazy" />

2.  Cliquez sur **Sign In With DataPlatformSSO**. Une fois redirigé, vous serez connecté à Superset.

<img className="thumbnail" alt="Étape 3 : configurer Trino dans Apache Superset — Superset (2)" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-14.png" loading="lazy" />

3.  Dans le menu **Settings**, cliquez sur **Database Connections**.

<img className="thumbnail" alt="Étape 3 : configurer Trino dans Apache Superset — Superset (3)" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-15.png" loading="lazy" />

4.  Cliquez sur **+ Database**.

<img className="thumbnail" alt="Étape 3 : configurer Trino dans Apache Superset — Superset (4)" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-16.png" loading="lazy" />

5.  Sélectionnez **Trino** dans la liste **Supported databases**.

<img className="thumbnail" alt="Étape 3 : configurer Trino dans Apache Superset — Superset (5)" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-17.png" loading="lazy" />

6.  Collez la **chaîne de connexion Trino complète** (depuis votre [consumer Trino](/guides/public-cloud/data-platform/connectors-consumers-trino), ou construite manuellement selon le guide [Intégrer Trino à des outils externes](/guides/public-cloud/data-platform/tutorials-trino-external-tools)) dans le champ **SQLAlchemy URI** puis validez le formulaire.

<img className="thumbnail" alt="Étape 3 : configurer Trino dans Apache Superset — Superset (6)" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-19.png" loading="lazy" />

### Étape 4 : créer votre premier chart

1.  Cliquez sur **`Datasets`** dans le menu principal.
2.  Cliquez sur le bouton **`+ Dataset`**.
3.  Une fois la page **New dataset** chargée, remplissez le formulaire avec les éléments suivants :

    -   **Database** : la base de données Trino que vous venez de créer.
    -   **Schema** : le catalog que vous souhaitez interroger (par exemple, `db_m8obb5ch_default_dataset`).
    -   **Table** : une table de votre catalog sélectionné (par exemple, `dataset_history`).
    <img className="thumbnail" alt="Étape 4 : créer votre premier chart — Superset" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-20.png" loading="lazy" />

4.  Cliquez sur le bouton **Create dataset and create chart**.
5.  Une fois créé, vous serez redirigé vers le formulaire **Create a new chart**.
6.  Sélectionnez un chart (par exemple, **Pie Chart**).
    <img className="thumbnail" alt="Étape 4 : créer votre premier chart — Superset (2)" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-21.png" loading="lazy" />
7.  Complétez les champs **Query** (par exemple, **Dimensions** : **`cat_temperature`** et **Metric** : **`Sum(rides)`**).
8.  Cliquez sur le bouton **Create chart**.
    <img className="thumbnail" alt="Étape 4 : créer votre premier chart — Superset (3)" src="/images/public-cloud/data-platform/getting-further/install-apache-superset/picts/superset-22.png" loading="lazy" />

:::info
Pour plus d'informations, consultez la [documentation d'Apache Superset](https://superset.apache.org/docs/intro/).
:::
