## Objectif

Cette action permet de vider une ou plusieurs tables de la base de données. En utilisant le périmètre dans la section des préférences, vous pouvez limiter la suppression à un sous-ensemble spécifique de données. Le périmètre peut être défini sur :

- Based on predefined set (un attribut de table) 
- Date perimeter du workflow
- Based on attribute du Projet (un attribut du Projet)

:::info
*Pro-tip*

Le type de périmètre *Based on predefined set* peut avoir plusieurs valeurs, mais un seul attribut peut être sélectionné. Bien que ce ne soit pas conventionnel, vous pouvez utiliser la segmentation pour agir comme un attribut supplémentaire basé sur un attribut de table.
:::

## Exemple de configuration

```json
{ 
	"params": {
		"tables": [
			"dwh/default_dataset/table_1", 
			"dwh/analytics_dataset/table_2"
		]
	}
}
```

## Paramètres

|                Paramètre               | Description              | Exemple              | Requis              | 
| :------------------------------: | -------------------------- | -------------------------- | -------------------------- | 
|            **tables**             | Tables à supprimer.             |    `["dwh/default_dataset/table1", "dwh/analytics_dataset/table2"]`   | Oui              |

*Ce paramètre doit être utilisé avec précaution, car si l'action se termine prématurément, cela entraînera une suppression partielle des données, et si plusieurs tables sont sélectionnées, certaines tables peuvent ne pas être supprimées du tout.
