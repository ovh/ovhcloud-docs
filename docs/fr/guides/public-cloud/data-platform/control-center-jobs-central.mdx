## Objectif

Le Jobs Central est la tour de contrôle depuis laquelle toutes les exécutions de jobs sur la platform - passées, présentes, en file d'attente et planifiées - peuvent être surveillées.

Sur la platform, un « job » (ou « exécution de job ») est l'exécution unitaire de code, qui peut être soit lancée manuellement depuis l'UI ou l'API, soit planifiée sur la base de déclencheurs. De nombreux éléments de la platform, tels que les [workflows du Data Processing Engine](/guides/public-cloud/data-platform/dpe-workflows) et l'[extraction de métadonnées des Connectors](/guides/public-cloud/data-platform/connectors-analyzer-extract-metadata), s'exécutent sous forme de jobs. La [puissance de calcul allouée à ce job](/guides/public-cloud/data-platform/manage-pricing#unités-de-facturation) est généralement définie par l'utilisateur. D'autres processus sur la platform, comme la construction physique de votre modèle de données, sont également des jobs entièrement gérés par la platform

<img className="thumbnail" alt="jobs" src="/images/public-cloud/data-platform/product/cc/picts/cc-job-central.png" loading="lazy" />

Si la page est ouverte au niveau de l'organisation, tous les jobs de tous les Projets seront visibles.

## Surveiller les exécutions de jobs

La page *Job executions* liste les exécutions des types de jobs suivants :

- exécutions de jobs des [actions du Data Processing Engine](/guides/public-cloud/data-platform/landing-page-dpe-actions)
- exécutions de jobs des [workflows du Data Processing Engine](/guides/public-cloud/data-platform/dpe-workflows)
- jobs d'[extraction de métadonnées des Connectors](/guides/public-cloud/data-platform/connectors-analyzer-extract-metadata)
- jobs de [construction physique du Lakehouse Manager](/guides/public-cloud/data-platform/lakehouse-manager-manage-tables)

Si besoin, cette page peut être filtrée pour n'afficher que les exécutions déclenchées par une planification CRON.

## Surveiller les déclencheurs de jobs planifiés

La page *Scheduled triggers* liste tous les déclencheurs CRON définis sur les [actions et workflows du Data Processing Engine](/guides/public-cloud/data-platform/dpe-jobs-preferences#déclencheurs).

Elle vous permet d'avoir une vue d'ensemble de l'activité de calcul récurrente sur vos Projets.
