## Objectif

Ce connecteur simple vous permet de charger vos fichiers comme sources dans la platform.

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/upload-files/picts/file-upload-1.png" loading="lazy" />

## Ajouter une source de fichiers sur la Platform

### Vue d'ensemble de l'écran de configuration

Une fois que vous avez trouvé *File upload* dans le **Platform Store**, cliquez sur *Sélectionner* et vous pourrez voir l'écran de configuration comme illustré ci-dessous :

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/upload-files/picts/file-upload-2.png" loading="lazy" />

### Fichiers et tailles pris en charge

Ce connecteur vous permet de glisser-déposer des fichiers des types suivants : `.csv`, `.xls`, `.xlsx`, `.xml`, `.json` et `.parquet`.

:::warning
Il y a une **limite de taille de 1 Go** sur les fichiers traités par cet onglet. Pour traiter des fichiers de plus de 1 Go, vous devez les charger via les [Data Platform Buckets](/guides/public-cloud/data-platform/lakehouse-manager-buckets).
:::

### Configurer votre source

Pour ajouter un fichier, il vous suffit de le glisser-déposer directement dans la zone désignée au centre de l'écran, ou de cliquer sur le lien indiqué pour sélectionner le fichier depuis votre ordinateur.

Les fichiers chargés seront affichés dans la liste sous la zone de glisser-déposer, comme sur l'image ci-dessous :

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/upload-files/picts/file-upload-3.png" loading="lazy" />

:::info
Notez que vous pouvez ajouter plusieurs fichiers à une seule source *File Upload*.
:::

L'encodage du fichier source est automatiquement détecté par la Platform. Cependant, si la détection automatique échoue, vous avez la possibilité de spécifier l'encodage du fichier en cliquant sur l'**icône crayon** à côté de chaque objet source :

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/upload-files/picts/file-upload-4.png" loading="lazy" />

Sélectionnez l'encodage de votre objet source dans la liste déroulante.

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/upload-files/picts/file-upload-5.png" loading="lazy" />
