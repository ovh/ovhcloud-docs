## Objectif

Dans cette étape, vous apprendrez à **connecter votre première source de données** à votre Projet, à l'**analyser** et à la **nettoyer** de façon cohérente afin que les relations entre vos données puissent être comprises en un coup d'œil.

:::info
Cette étape suppose qu'un projet soit ouvert. Si vous n'en avez pas encore, [créez un projet](/guides/public-cloud/data-platform/manage-projects-create) d'abord.
:::

Les **Connectors** constituent le premier composant que vous devez utiliser en démarrant votre Projet. C'est le composant qui contrôle :

- La collecte des sources de données
- L'analyse et le nettoyage des données

<img className="thumbnail" alt="Connectors" src="/images/public-cloud/data-platform/getting-started/app-init/picts/connectors-home.png" loading="lazy" />

La source de données se compose de deux fichiers CSV contenant des données sur la météo de Chicago et les transports publics.

## Connecter votre première source

Allons chercher vos données !

:::info
Pour obtenir vos données, téléchargez les fichiers suivants [ici](https://eu.dataplatform.ovh.net/getting-started/chicago_files.zip). Une fois décompressés, vous trouverez 2 fichiers *.csv* :
:::

- *chicago_calendar_full.csv* - une table avec les conditions météorologiques par jour où chaque ligne représente un jour.
- *station_rides.csv* - une table avec les informations d'utilisation ferroviaire par station et par jour où chaque ligne représente un jour pour une station donnée.

Dans les Connectors, allez dans le menu **Sources** (1) et cliquez sur le bouton **New Source** (2) en haut à droite pour connecter votre toute première source de données.

<img className="thumbnail" alt="Connectors" src="/images/public-cloud/data-platform/getting-started/app-init/picts/datacatalog-step1.png" loading="lazy" />

De nombreux connecteurs sont pris en charge par la Platform. Dans ce tutoriel, vous utiliserez un simple téléversement de fichier.

Recherchez *File Upload* dans la barre de recherche, cliquez sur l'icône puis cliquez sur le bouton vert *Sélectionner*. Vous pouvez aussi cliquer directement sur le bouton *File Upload* en bas à droite.

<img className="thumbnail" alt="Connectors" src="/images/public-cloud/data-platform/getting-started/app-init/picts/datacatalog-step2.png" loading="lazy" />

Donnez un nom à votre source : par exemple *chicago_files*.

Vous pouvez ensuite **glisser-déposer ou téléverser les 2 fichiers** fournis au début du tutoriel, puis cliquer sur **Create**.

<img className="thumbnail" alt="Connectors" src="/images/public-cloud/data-platform/getting-started/app-init/picts/datacatalog-step3.png" loading="lazy" />

Vos fichiers sont maintenant chargés dans un [bucket](/guides/public-cloud/data-platform/lakehouse-manager-buckets) !

<img className="thumbnail" alt="Connectors" src="/images/public-cloud/data-platform/getting-started/app-init/picts/datacatalog-step4.png" loading="lazy" />

Passons maintenant à l'extraction de leurs métadonnées.

## Analyser vos données source

Vous devriez toujours être dans le composant Connectors. Cliquez sur **Analyzer** dans le menu de gauche. Ici, vous allez extraire les métadonnées (c'est-à-dire des informations sur vos données) de vos sources et choisir les colonnes que vous souhaitez afficher.

Les deux fichiers source que vous venez de téléverser apparaissent dans la barre latérale. Cliquez sur le nom de la source correspondante (c'est-à-dire *chicago_files*) pour la déplier. Ensuite, cliquez sur chacun des fichiers pour lancer automatiquement une extraction de métadonnées.

<img className="thumbnail" alt="Connectors" src="/images/public-cloud/data-platform/getting-started/app-init/picts/datacatalog-step5.png" loading="lazy" />

L'extraction des métadonnées devrait prendre environ 30 secondes.

:::info
L'Analyzer est également l'endroit où vous pouvez ajouter des règles de blueprint (en cliquant sur le bouton bleu *New Rule*). La Platform applique automatiquement une transformation de formatage sur les dates pour les définir dans un format standard *yyyy-mm-dd*.
:::
