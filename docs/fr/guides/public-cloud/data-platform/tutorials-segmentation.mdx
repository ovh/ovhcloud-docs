## Objectif

La [segmentation](/guides/public-cloud/data-platform/dpe-jobs-segmentation) vous permettra de libérer toute la puissance de scalabilité du Data Processing Engine. Lors de son exécution, vos [actions](/guides/public-cloud/data-platform/landing-page-dpe-actions) seront **divisées en plusieurs tâches**, chaque tâche traitant un dataset plus petit.

:::info
Un grand pouvoir implique de grandes responsabilités : les options de segmentation doivent être configurées avec soin. Selon vos choix de segmentation, votre action peut être bien plus rapide... ou bien plus lente.
:::
