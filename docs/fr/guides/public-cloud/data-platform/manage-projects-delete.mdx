## Objectif

:::info
Vous devez disposer de la **permission projet** `delete` pour pouvoir supprimer des projets. Ces permissions sont définies au niveau utilisateur dans l'[IAM de l'Organisation](/guides/public-cloud/data-platform/iam-organization#ressources-gérées-par-liam-de-lorganisation).
:::

Supprimer un Projet **efface complètement et définitivement ses données**. À utiliser uniquement en cas de nécessité !

## Choisir le Projet à supprimer

Vous pouvez supprimer un Projet via le [menu de la carte Projet](/guides/public-cloud/data-platform/manage-navigation#votre-liste-de-projets) dans la [Page d'accueil](/guides/public-cloud/data-platform/manage-navigation).

<img className="thumbnail" alt="supprimer un Projet" src="/images/public-cloud/data-platform/product/project/picts/project_menu_delete.png" loading="lazy" />

## Confirmer la décision en saisissant le nom du Projet

Après avoir cliqué sur *Delete Projet*, vous serez invité à confirmer votre décision en saisissant le nom de votre Projet.

<img className="thumbnail" alt="confirmer la suppression" src="/images/public-cloud/data-platform/product/project/picts/confirm_delete.png" loading="lazy" />

## Cliquer sur le lien de l'e-mail reçu

Vous recevrez un e-mail contenant un lien pour confirmer la suppression de votre Projet. Il vous suffit de cliquer sur le lien de confirmation pour supprimer le Projet.

<img className="thumbnail" alt="e-mail" src="/images/public-cloud/data-platform/product/project/picts/confirm_delete_email.png" loading="lazy" />
