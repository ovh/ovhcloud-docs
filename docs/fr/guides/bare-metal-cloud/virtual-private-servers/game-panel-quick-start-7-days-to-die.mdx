## Objectif

Le Game Panel vous permet de déployer un serveur 7 Days to Die avec une installation automatisée et la configuration des ports.

**Ce guide vous explique comment déployer un serveur 7 Days to Die sur le Game Panel et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel. Rendez-vous dans la section **Game Servers** du menu de gauche et cliquez sur <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Section Game Servers avec le bouton Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/game-servers-list.png" loading="lazy" />

### Étape 2 — Créer un serveur 7 Days to Die

Sélectionnez **7 Days to Die** dans la liste des jeux. Une fenêtre de configuration s'ouvre.

<img className="thumbnail" alt="Sélection de 7 Days to Die dans la liste des jeux" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/select-7-days-to-die.png" loading="lazy" />

### Étape 3 — Configurer le serveur 7 Days to Die

Saisissez un **Server Name** (par exemple, `7 Days to Die Server`). Les ports réseau requis sont configurés automatiquement lors de l'installation.

<img className="thumbnail" alt="Formulaire d'installation de 7 Days to Die" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/7-days-to-die-install-form.png" loading="lazy" />

Vous pouvez développer <code className="action">Advanced settings</code> pour ajuster des options telles que le mappage des ports (ports binding) et les limites de ressources. Les valeurs par défaut conviennent à la plupart des serveurs de jeu.

### Étape 4 — Lancer l'installation

Cliquez sur <code className="action">Install</code>. Le déploiement démarre automatiquement. Patientez quelques minutes le temps du téléchargement de l'image et de l'installation du serveur.

### Étape 5 — Suivre l'installation

Cliquez sur <code className="action">Log/Console</code> pour suivre la progression de l'installation en temps réel. Le statut affiche **Installing**.

### Étape 6 — Vérifier que le serveur est en cours d'exécution

Vérifiez que le statut du serveur affiche **Running** et que l'activité CPU/RAM est visible.

<img className="thumbnail" alt="Serveur 7 Days to Die avec le statut Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/7-days-to-die-running.png" loading="lazy" />

Actions disponibles :

- <code className="action">Log/Console</code> : ouvrez la console pour suivre le démarrage et consultez les logs en cas de problème.
- <code className="action">Settings</code> > <code className="action">Game Config</code> : accédez aux paramètres du jeu.

<img className="thumbnail" alt="Paramètres Game Config de 7 Days to Die" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/7-days-to-die-game-config.png" loading="lazy" />

### Étape 7 — Confirmer la fin de l'installation

Le statut passe à **Running** une fois l'installation terminée.

### Étape 8 — Récupérer les informations de connexion

Dans la colonne **Connection** de la liste Game Servers, copiez l'adresse IP et le port de votre serveur.

### Étape 9 — Rejoindre votre serveur sur 7 Days to Die

Pour rejoindre depuis le jeu :

1. Lancez **7 Days to Die** et cliquez sur **Join a Game**.
2. Collez l'adresse IP et le port issus de la colonne **Connection**.
3. Cliquez sur **Connect**.

### Bonnes pratiques

- Configurez les permissions via <code className="action">User Administration</code>.
- Effectuez des sauvegardes régulières.
- Personnalisez les paramètres du jeu.

:::info
Pour aller plus loin, ajoutez des mods ou des configurations compétitives, ajustez le tickrate et les paramètres de performance, ou restreignez l'accès avec un mot de passe ou une liste blanche.
:::
