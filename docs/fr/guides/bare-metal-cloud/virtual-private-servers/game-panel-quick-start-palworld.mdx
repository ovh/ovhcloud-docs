## Objectif

Le Game Panel OVHcloud vous permet de déployer un serveur Palworld avec une installation et une configuration des ports automatisées.

**Ce guide vous explique comment déployer un serveur Palworld sur le Game Panel OVHcloud et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel OVHcloud. Dans le menu de gauche, rendez-vous dans la section `Game Servers` et cliquez sur <code className="action">Add Game Server</code>.

### Étape 2 — Créer un serveur Palworld

Sélectionnez **Palworld** dans la liste des jeux. Une fenêtre de configuration s'ouvre.

<img className="thumbnail" alt="Sélection de Palworld dans la liste des jeux du Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/select-palworld.png" loading="lazy" />

### Étape 3 — Configurer le serveur Palworld

Dans cette section, vous pouvez définir un nom pour votre serveur. Un mot de passe administrateur est également généré automatiquement. Il peut être utilisé directement dans le jeu pour obtenir les droits d'administrateur et exécuter les commandes associées.

:::warning
Veillez à conserver ce mot de passe administrateur dans un endroit sécurisé.
:::

Vous pouvez développer <code className="action">Advanced settings</code> pour ajuster des options telles que le mappage des ports (ports binding) et les limites de ressources. Les valeurs par défaut conviennent à la plupart des serveurs de jeu.

<img className="thumbnail" alt="Formulaire de configuration du serveur Palworld avec le nom du serveur et le mot de passe administrateur" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/configure-server.png" loading="lazy" />

### Étape 4 — Lancer l'installation

Cliquez sur <code className="action">Install</code> pour lancer l'installation. Le déploiement démarre.

### Étape 5 — Suivre l'installation

Cliquez sur <code className="action">Log/Console</code> pour suivre la progression de l'installation en temps réel.

Pendant l'installation du serveur, le statut affiche **Installing**. Suivez la progression détaillée dans le panneau de logs.

<img className="thumbnail" alt="Suivi de l'installation du serveur Palworld dans le panneau de logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/installation-logs.png" loading="lazy" />

### Étape 6 — Vérifier que le serveur est en cours d'exécution

Vérifiez que le statut du serveur est **Running** et qu'une activité CPU et RAM est visible. Vous pouvez utiliser les commandes <code className="action">Log/Console</code> et <code className="action">Settings</code> pour gérer le serveur.

<img className="thumbnail" alt="Serveur Palworld avec le statut Running et l'activité CPU et RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/server-running.png" loading="lazy" />

### Étape 7 — Confirmer la fin de l'installation

Une fois l'installation terminée, le statut du serveur passe à **Running**.

### Étape 8 — Récupérer les informations de connexion

Une fois que votre serveur est au statut **Running**, copiez l'adresse IP et le port depuis la colonne **Connection** de la liste des Game Servers.

### Étape 9 — Rejoindre votre serveur sur Palworld

Pour rejoindre votre serveur depuis le client Palworld :

1. Ouvrez **Palworld** et cliquez sur **Join Multiplayer Game**.
2. Dans le champ de saisie situé en bas au centre, collez l'adresse IP et le port indiqués dans la colonne **Connection**.
3. Cliquez sur **Connect**.

### Commandes disponibles avec Palworld

Avec un serveur Palworld, vous pouvez exécuter différentes commandes directement depuis le champ de saisie situé en bas des logs. Voici quelques-unes des commandes disponibles :

| Commande | Arguments | Description |
|----------|-----------|-------------|
| `announce` | - | Envoie un message d'annonce visible par tous les joueurs connectés. |
| `players` | - | Affiche la liste des joueurs actuellement connectés au serveur. |
| `info` | - | Retourne les informations générales du serveur. |
| `settings` | - | Retourne la configuration actuelle du serveur. |
| `metrics` | - | Affiche différentes métriques et statistiques du serveur. |
| `kick` | `<PlayerId or SteamId>` | Expulse un joueur du serveur. |
| `ban` | `<PlayerId or SteamId>` | Bannit un joueur du serveur. |
| `unban` | `<PlayerId or SteamId>` | Retire le bannissement d'un joueur. |

:::info
Vous avez oublié le mot de passe administrateur du jeu ? Cliquez sur <code className="action">Settings</code>, ouvrez la section <code className="action">Game Config</code> et modifiez le mot de passe en bas de page.
:::

### Mettre à jour le serveur vers une nouvelle version du jeu

Par défaut, le serveur ne se met pas automatiquement à jour lorsqu'une nouvelle version est disponible, afin d'éviter d'éventuels problèmes de compatibilité ou l'interruption de parties en cours.

Pour activer les mises à jour automatiques, cliquez sur <code className="action">Settings</code>, ouvrez la section <code className="action">Game Config</code>, puis activez l'option **Update on start** en bas de page (désactivée par défaut). Sauvegardez, puis redémarrez le serveur pour appliquer les changements. Le serveur appliquera alors automatiquement toute nouvelle mise à jour disponible.
