## Objectif

Le Game Panel OVHcloud vous permet de déployer un serveur Project Zomboid avec une installation et une configuration des ports automatisées.

**Ce guide vous explique comment déployer un serveur Project Zomboid sur le Game Panel OVHcloud et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel OVHcloud. Dans le menu de gauche, rendez-vous dans la section `Game Servers` et cliquez sur <code className="action">Add Game Server</code>.

### Étape 2 — Créer un serveur Project Zomboid

Sélectionnez **Project Zomboid** dans la liste des jeux. Une fenêtre de configuration s'ouvre.

<img className="thumbnail" alt="Sélection de Project Zomboid dans la liste des jeux du Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/select-project-zomboid.png" loading="lazy" />

### Étape 3 — Configurer le serveur Project Zomboid

Dans cette section, vous pouvez définir un nom pour votre serveur et choisir la <code className="action">Branch</code> — la branche Steam du jeu à installer, dont la liste est mise à jour automatiquement. Choisissez-la avec soin : changer de branche ensuite peut corrompre un monde existant, c'est donc un choix à faire à l'installation.

Un mot de passe administrateur est également généré automatiquement. Il s'agit du mot de passe du compte administrateur en jeu, qui vous attribue les droits d'administrateur et donne accès aux commandes de console privilégiées : ce n'est **pas** le mot de passe utilisé par les joueurs pour rejoindre le serveur.

:::warning
Veillez à conserver ce mot de passe administrateur dans un endroit sécurisé.
:::

Vous pouvez développer <code className="action">Advanced Settings</code> pour ajuster des options telles que le mappage des ports (ports binding) et les limites de ressources. Les valeurs par défaut conviennent à la plupart des serveurs de jeu.

<img className="thumbnail" alt="Formulaire de configuration du serveur Project Zomboid avec branche et mot de passe administrateur" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/configure-server.png" loading="lazy" />

### Étape 4 — Lancer l'installation

Cliquez sur <code className="action">Install</code> pour lancer le déploiement du serveur.

### Étape 5 — Suivre l'installation

Cliquez sur <code className="action">Log/Console</code> pour suivre la progression de l'installation en temps réel. Dès le lancement de l'installation, le Game Panel propose également un bouton <code className="action">Open Logs / Console</code> qui ouvre la même vue.

Pendant l'installation du serveur, le statut affiche **Installing**. Suivez la progression détaillée dans le panneau de logs.

<img className="thumbnail" alt="Suivi de l'installation du serveur Project Zomboid dans le panneau de logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/installation-logs.png" loading="lazy" />

### Étape 6 — Confirmer la fin de l'installation

Une fois l'installation terminée, le statut du serveur passe à **Running**.

### Étape 7 — Vérifier que le serveur est en cours d'exécution

Vérifiez qu'une activité CPU et RAM est visible. Vous pouvez utiliser les commandes <code className="action">Log/Console</code> et <code className="action">Settings</code> pour gérer le serveur.

<img className="thumbnail" alt="Serveur Project Zomboid avec le statut Running et l'activité CPU et RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/server-running.png" loading="lazy" />

### Étape 8 — Récupérer les informations de connexion

Copiez l'adresse IP et le port depuis la colonne **Connection** de la liste des `Game Servers`.

### Étape 9 — Rejoindre votre serveur sur Project Zomboid

Pour rejoindre votre serveur depuis le client Project Zomboid :

1. Ouvrez **Project Zomboid** et cliquez sur **Multiplayer**, puis sur **Add server**.
2. Saisissez un nom pour le serveur, puis l'adresse IP et le port indiqués dans la colonne **Connection** du Game Panel. Renseignez également le mot de passe du serveur, si celui-ci en possède un : il s'agit du mot de passe utilisé par les joueurs pour se connecter, pas du mot de passe administrateur.
3. Cliquez sur **SAVE**.
4. Cliquez sur **Add new account** pour créer un compte de jeu pour ce serveur, puis renseignez un nom et un mot de passe.

### Se connecter en tant qu'administrateur

Une fois le serveur ajouté au menu **Multiplayer**, créez un nouveau personnage pour ce serveur. Lors de sa création, choisissez un nom d'utilisateur et saisissez le mot de passe administrateur du serveur.

Pour retrouver ce mot de passe, cliquez sur <code className="action">Settings</code> dans le Game Panel, ouvrez la section <code className="action">Game Config</code>, puis l'onglet <code className="action">Server Settings</code> : le champ **Admin Password** se trouve en bas de la page. La valeur est masquée, cliquez sur l'icône en forme d'œil pour l'afficher.

Une fois connecté avec ce personnage, une icône **Admin** apparaît à gauche de l'écran. Cliquez dessus pour accéder aux outils d'administration, exécuter des commandes et modérer votre serveur.

### Mettre à jour le serveur vers une nouvelle version du jeu

Par défaut, le serveur ne se met pas automatiquement à jour lorsqu'une nouvelle version est disponible, pour éviter d'éventuels problèmes de compatibilité ou l'interruption de parties en cours.

Pour activer les mises à jour automatiques, cliquez sur <code className="action">Settings</code>, ouvrez la section <code className="action">Game Config</code>, puis activez l'option <code className="action">Update on start</code> en bas de page (désactivée par défaut). Cliquez sur <code className="action">Save &amp; Restart</code> pour appliquer les changements. Le serveur appliquera automatiquement toute nouvelle mise à jour disponible.
