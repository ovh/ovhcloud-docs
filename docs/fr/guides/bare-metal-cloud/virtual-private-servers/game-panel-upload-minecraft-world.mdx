## Objectif

Le Game Panel d'OVHcloud vous permet de téléverser un monde Minecraft personnalisé en transférant les fichiers avec le File Manager et en ajustant la configuration du dossier du monde.

**Ce guide vous explique comment téléverser une carte personnalisée sur votre serveur Minecraft hébergé sur le Game Panel d'OVHcloud.**

## Prérequis

- Un [VPS](https://www.ovhcloud.com/fr/vps/) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un serveur Minecraft déployé sur le Game Panel. Consultez le guide [Déployer un serveur Minecraft sur le Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

:::warning
Assurez-vous que votre serveur Minecraft est **arrêté** avant d'effectuer l'une des actions suivantes.
:::


## En pratique

### Étape 1 — Ouvrir le File Manager

Sur votre serveur Minecraft, cliquez sur <code className="action">Settings</code>, puis ouvrez l'onglet <code className="action">File Manager</code>.

### Étape 2 — Localiser le dossier du monde

Dans le File Manager, naviguez jusqu'à :

```
data > serverfiles
```

Dans ce répertoire, vous verrez un dossier nommé `world`. Ce dossier contient votre carte Minecraft actuelle et est créé par défaut.

<img className="thumbnail" alt="Le dossier world par défaut dans la structure de fichiers du serveur" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder.png" loading="lazy" />

### Étape 3 — Préparer le serveur pour votre nouvelle carte

Avant de téléverser votre propre carte, vous devez libérer le nom de dossier `world`. Trois options s'offrent à vous :

- **Le supprimer** avec l'action <code className="action">Delete</code> si vous n'en avez plus besoin.
- **Le renommer** avec l'action <code className="action">Rename</code> pour le conserver comme sauvegarde.
- **Le télécharger en local** avec l'action <code className="action">Download</code>.

### Étape 4 — Téléverser votre carte personnalisée

Dans le File Manager, à l'intérieur de `data > serverfiles`, cliquez sur <code className="action">Upload files</code> ou glissez-déposez le dossier de votre carte dans la liste des fichiers.

### Étape 5 — Configurer le nom du monde (si nécessaire)

Si le dossier de votre carte ne s'appelle pas `world`, vous devez mettre à jour la configuration du serveur :

1. Retournez sur le Game Panel.
2. Ouvrez les <code className="action">Settings</code> de votre serveur.
3. Allez dans l'onglet <code className="action">Game Config</code>.
4. Repérez l'option **World folder name**.
5. Saisissez le nom exact du dossier de votre carte.

<img className="thumbnail" alt="Configuration du nom du dossier du monde dans Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder-name-config.png" loading="lazy" />

:::info
**Utiliser plusieurs cartes** : vous pouvez stocker plusieurs cartes sur votre serveur et basculer facilement entre elles. Modifiez le champ **World folder name** dans la section Game Config pour charger une carte différente. N'oubliez pas de redémarrer le serveur après avoir modifié ce paramètre.
:::


### Étape 6 — Démarrer le serveur

Redémarrez votre serveur depuis le Game Panel. Votre carte Minecraft personnalisée est désormais prête à être utilisée.
