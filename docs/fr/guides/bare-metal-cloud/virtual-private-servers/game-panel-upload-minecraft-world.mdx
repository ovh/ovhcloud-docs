## Objectif

Le Game Panel OVHcloud vous permet de téléverser un monde Minecraft personnalisé en transférant les fichiers avec le File Manager et en ajustant la configuration du nom du monde.

**Ce guide explique comment téléverser une carte personnalisée sur votre serveur Minecraft hébergé sur le Game Panel OVHcloud.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un serveur Minecraft utilisant l'un des logiciels suivants : Minecraft Java Edition, Minecraft Bedrock Edition, PaperMC, Fabric ou NeoForge. Consultez le guide [Déployer un serveur Minecraft sur le Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).
- Un dossier de carte prêt à être téléversé.

## En pratique

### Étape 1 — Arrêter le serveur Minecraft

Avant de téléverser un nouveau monde, vous devez arrêter votre serveur.

1. Ouvrez votre serveur dans le Game Panel.
2. Cliquez sur <code className="action">Stop</code> pour arrêter complètement le serveur.

:::warning
Ne téléversez ni ne remplacez jamais un monde pendant que le serveur est en cours d'exécution, car cela peut entraîner une corruption du monde.
:::

### Étape 2 — Téléverser votre carte personnalisée

1. Ouvrez votre serveur dans le Game Panel.
2. Rendez-vous dans <code className="action">Settings</code>.
3. Ouvrez l'onglet <code className="action">File Manager</code>.

<img className="thumbnail" alt="Le dossier du monde dans le File Manager" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder.png" loading="lazy" />

**Supprimer le monde existant**

Par défaut, le dossier du monde principal est nommé `world`. Vous pouvez soit supprimer le dossier `world` existant, soit le télécharger au préalable si vous souhaitez en conserver une sauvegarde.

**Téléverser votre nouveau monde**

Une fois l'ancien monde supprimé :

1. Repérez le dossier de votre carte personnalisée sur votre ordinateur.
2. Glissez-déposez le dossier directement dans le File Manager.
3. Patientez jusqu'à la fin du téléversement.

Votre carte personnalisée doit être téléversée sous la forme d'un dossier contenant les fichiers du monde.

:::warning
Nous vous recommandons fortement que la version Minecraft de la carte que vous importez corresponde à la version Minecraft de votre serveur. Une différence de version peut empêcher le chargement du monde ou provoquer un comportement inattendu.
:::

### Étape 3 — Vérifier le nom du monde

Le nom du dossier du monde doit correspondre au nom du monde configuré dans les paramètres de votre serveur.

**Vérifier le nom du dossier téléversé**

Dans le File Manager, notez le nom exact du dossier du monde que vous avez téléversé.

**Mettre à jour la configuration du serveur**

1. Allez dans l'onglet <code className="action">Game Config</code>.
2. Repérez l'option **World name**.
3. Assurez-vous que sa valeur correspond exactement au nom du dossier téléversé.

<img className="thumbnail" alt="Correspondance du paramètre World name dans Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder-name-config.png" loading="lazy" />

### Étape finale

Une fois le téléversement terminé et le paramètre **World name** correspondant au nom de votre dossier :

1. Enregistrez vos modifications.
2. Démarrez de nouveau le serveur.

Votre serveur Minecraft doit désormais charger et utiliser votre carte personnalisée.
