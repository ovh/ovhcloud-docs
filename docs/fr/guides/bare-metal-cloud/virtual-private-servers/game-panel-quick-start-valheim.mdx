## Objectif

Le Game Panel d'OVHcloud vous permet de déployer un serveur Valheim avec une installation et une configuration des ports automatisées.

**Ce guide vous explique comment déployer un serveur Valheim sur le Game Panel d'OVHcloud et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel d'OVHcloud.

### Étape 2 — Créer une nouvelle instance de serveur

Cliquez sur <code className="action">Add Game Server</code> et sélectionnez **Valheim**.

<img className="thumbnail" alt="Sélection de Valheim dans la liste des jeux" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/select-valheim.png" loading="lazy" />

:::info
S'il s'agit de votre premier serveur Valheim sur le Game Panel et que le Game Port par défaut est disponible, tous les ports requis sont configurés automatiquement. Aucune configuration manuelle n'est nécessaire.
:::


### Étape 3 — Suivre la progression de l'installation

Une fois l'installation lancée, un écran de confirmation s'affiche. Cliquez sur <code className="action">Log/Console</code> pour suivre la progression de l'installation en temps réel.

<img className="thumbnail" alt="Suivi de l'installation du serveur Valheim" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/installation-logs.png" loading="lazy" />

### Étape 4 — Confirmer la fin de l'installation

Une fois l'installation terminée, une notification apparaît : **Server status is now: Running**.

<img className="thumbnail" alt="Serveur Valheim avec le statut Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/server-running.png" loading="lazy" />

### Étape 5 — Récupérer les informations de connexion

Lorsque le statut de votre serveur est **Running**, copiez l'adresse IP et le port depuis la colonne **Connection** de la liste des Game Servers. Valheim utilise deux ports UDP : `2456` (Game) et `2457` (Query).

:::info
Un mot de passe est généré automatiquement lors de l'installation. Ouvrez le [File Manager](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/) depuis les <code className="action">Settings</code> de votre serveur et consultez `config-lgsm` > `vhserver` > `secrets-common.cfg` pour le récupérer.
:::


### Étape 6 — Rejoindre votre serveur dans Valheim

1. Ouvrez **Valheim**.
2. Cliquez sur **Start**, puis sur **Join Server**.
3. Cliquez sur **Join IP** et collez l'adresse IP et le port depuis la colonne **Connection**.
4. Saisissez le mot de passe et cliquez sur **Connect**.
