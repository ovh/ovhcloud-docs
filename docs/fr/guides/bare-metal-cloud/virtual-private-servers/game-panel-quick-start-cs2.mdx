## Objectif

Le Game Panel OVHcloud vous permet de déployer un serveur Counter-Strike 2 (CS2) avec une installation et une configuration des ports automatisées.

**Ce guide vous explique comment déployer un serveur Counter-Strike 2 sur le Game Panel OVHcloud et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel OVHcloud. Rendez-vous dans la section **Game Servers** du menu de gauche et cliquez sur <code className="action">Add Game Server</code>.

### Étape 2 — Créer un serveur Counter-Strike 2

Sélectionnez **Counter-Strike 2** dans la liste des jeux. Une fenêtre de configuration s'ouvre.

<img className="thumbnail" alt="Sélection de Counter-Strike 2 dans la liste des jeux" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/select-cs2.png" loading="lazy" />

### Étape 3 — Configurer le serveur Counter-Strike 2

Saisissez un **Server Name** (par exemple `CS2 Competitive Server`). Les ports réseau requis sont configurés automatiquement lors de l'installation.

Vous pouvez développer <code className="action">Advanced settings</code> pour ajuster des options telles que le mappage des ports (ports binding) et les limites de ressources. Les valeurs par défaut conviennent à la plupart des serveurs de jeu.

### Étape 4 — Lancer l'installation

Cliquez sur <code className="action">Install</code>. Le déploiement démarre automatiquement. Patientez quelques minutes le temps du téléchargement de l'image et de l'installation du serveur.

### Étape 5 — Suivre l'installation

Cliquez sur <code className="action">Log/Console</code> pour suivre la progression en temps réel. Le statut affiche **Installing**.

### Étape 6 — Vérifier que le serveur est en cours d'exécution

Vérifiez que le statut du serveur affiche **Running** et qu'une activité CPU/RAM est visible.

Actions disponibles :

- <code className="action">Log/Console</code> : ouvrez la console pour suivre le démarrage et consultez les logs en cas de problème.
- <code className="action">Settings</code> > <code className="action">Game Config</code> : accédez aux paramètres du jeu.

<img className="thumbnail" alt="Serveur Counter-Strike 2 avec le statut Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/cs2-running.png" loading="lazy" />

### Étape 7 — Confirmer la fin de l'installation

Une fois l'installation terminée, le statut passe à **Running** et le serveur est prêt à l'emploi.

### Étape 8 — Récupérer les informations de connexion

Dans la colonne **Connection** de la liste des Game Servers, copiez l'adresse IP et le port de votre serveur.

### Étape 9 — Rejoindre votre serveur sur Counter-Strike 2

Dans Counter-Strike 2 :

1. Activez la console dans les paramètres du jeu (**Settings** > **Game** > **Enable Developer Console**).
2. Ouvrez la console (`~`).
3. Saisissez la commande suivante en utilisant l'adresse IP et le port de la colonne **Connection** :

    ```console
    connect IP:PORT
    ```

### Bonnes pratiques

- Configurez les permissions via <code className="action">User Administration</code>.
- Effectuez des sauvegardes régulières.
- Personnalisez les paramètres de votre jeu.

:::info
Pour aller plus loin, ajoutez des mods ou des configurations compétitives, ajustez le tickrate et les paramètres de performance, ou restreignez l'accès avec un mot de passe ou une whitelist.
:::
