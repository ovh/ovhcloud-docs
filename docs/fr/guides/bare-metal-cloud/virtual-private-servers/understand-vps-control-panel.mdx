## Objectif

- Comprendre l'interface de gestion des VPS.
- Identifier les informations essentielles.
- Savoir où effectuer les principales actions.

## Prérequis

- Disposer d'une offre [VPS](/links/bare-metal/vps) active dans votre compte OVHcloud.

:::warning
Certaines fonctionnalités VPS mentionnées sur cette page ne sont pas disponibles dans les Local Zones OVHcloud.

Veuillez visiter notre [page Web des Local Zones](/links/bare-metal/vps-lz) pour obtenir plus d'informations.

:::

### Tableau de bord <a name="controlpanel"></a>

L'onglet <code className="action">Vue d'ensemble</code> constitue le **tableau de bord principal** de votre VPS.

Il centralise les **informations clés sur le service** et donne accès aux **actions essentielles de gestion**.

<img className="thumbnail" alt="Overview tab of a VPS in the OVHcloud Console" src="/images/bare-metal-cloud/virtual-private-servers/understand-vps-control-panel/console/vpshome.png" loading="lazy" />

#### Informations générales <a name="myvps"></a>

La section **Informations générales** présente les informations de base sur votre VPS. L'état du service est affiché à côté du nom de votre VPS, en haut de la page. Cliquez sur les onglets ci-dessous pour afficher les détails.

<Tabs>
  <Tab label="Nom">
    Pour personnaliser le nom de votre VPS, cliquez sur l'icône en forme de crayon à côté de son nom en haut de la page, saisissez le nouveau nom, puis cliquez sur l'icône en forme de coche pour l'enregistrer. Cette fonctionnalité est utile pour faciliter la navigation dans la console OVHcloud lorsque vous gérez plusieurs services VPS. Toutefois, le nom interne du service reste au format *vps-XXXXXXX.vps.ovh.net*.
  </Tab>
  <Tab label="Démarrage">
    Le mode de démarrage indiqué est soit :
    
    - en **mode normal** (*LOCAL*), où le serveur charge le système d'exploitation installé.
    - en **mode rescue**, fourni par OVHcloud en cas de dépannage.
    
    Cliquez sur le bouton <code className="action">⋮</code> dans la ligne **Actions supplémentaires** de la section, puis sélectionnez <code className="action">Redémarrer mon VPS</code> pour [redémarrer le VPS](#rebootvps) ou <code className="action">Redémarrer en mode rescue</code> pour le démarrer en mode rescue si nécessaire.
    
    Si besoin, retrouvez plus d'informations dans notre guide sur le [mode rescue](/guides/bare-metal-cloud/virtual-private-servers/rescue).
  </Tab>
  <Tab label="Distribution">
    Il s'agit du système d'exploitation actuellement installé. Cliquez sur le lien <code className="action">Réinstaller mon VPS</code> situé en dessous pour [réinstaller le même système d'exploitation ou en sélectionner un autre parmi les options disponibles](#reinstallvps).
    
    :::warning
    Une réinstallation entraînera l'effacement de toutes les données actuellement hébergées sur le VPS (à l'exception des disques additionnels).

    :::

    
    :::info
    Si vous avez commandé un VPS **Windows**, vous ne pouvez choisir qu'un OS Windows pour la réinstallation. De même, si Windows n'a pas été sélectionné lors de la commande, il ne pourra pas être installé après la livraison du VPS.

    :::

    
    Une fois le système installé, vous êtes responsable de l'application des mises à jour de sécurité du système d'exploitation. Vous trouverez plus d'informations dans la partie « [Réinstaller votre VPS](#reinstallvps) » ainsi que dans notre guide « [Sécuriser un VPS](/guides/bare-metal-cloud/virtual-private-servers/secure-your-vps) ».
  </Tab>
  <Tab label="Région">
    Le champ **Région** fournit des informations sur la localisation de votre VPS. Cela peut être utile pour identifier et évaluer les éventuels impacts sur votre service, comme ceux mentionnés dans les [rapports d'incidents ou de maintenance](https://bare-metal-servers.status-ovhcloud.com/).
  </Tab>
</Tabs>

Cliquez sur les onglets ci-dessous pour afficher les détails de cette section.

<Tabs>
  <Tab label="Modèle">
    Cet élément indique la référence commerciale identifiant le modèle de VPS, correspondant aux [offres VPS sur notre site](/links/bare-metal/vps).
  </Tab>
  <Tab label="Processeur / Mémoire / Disque principal">
    Les ressources actuelles de votre VPS sont affichées ici. Pour les augmenter, cliquez sur le lien <code className="action">Changer de gamme</code> sous **Modèle**. À noter que les mises à niveau sont limitées par le modèle de VPS choisi et peuvent uniquement être disponibles en passant à une [gamme supérieure](/links/bare-metal/vps).
  </Tab>
  <Tab label="Stockage additionnel">
    Cet élément indique si des disques additionnels sont activés sur votre VPS. Les disques additionnels augmentent la capacité de stockage de votre serveur au-delà de celle incluse dans la configuration initiale. Vous pouvez par exemple y stocker des données de sauvegarde. Gérez-les depuis l'onglet <code className="action">Disque additionnel</code>.
  </Tab>
</Tabs>


#### Détails de connexion <a name="ip"></a>

Cliquez sur les onglets ci-dessous pour afficher les détails de cette section.

<Tabs>
  <Tab label="IPv4">
    L'adresse IPv4 publique principale du VPS est configurée automatiquement à l'installation. Retrouvez plus d'informations sur la gestion des IP dans notre guide « [Configurer une adresse IP en alias](/guides/bare-metal-cloud/virtual-private-servers/configuring-ip-aliasing) ».
  </Tab>
  <Tab label="IPv6 / Gateway">
    Retrouvez ici l'adresse IPv6 publique et l'adresse de la passerelle associée (**Passerelle IPv6**). Celles-ci sont automatiquement attachées au VPS lors de l'installation. Retrouvez plus d'informations dans notre guide « [Configurer l'IPv6 sur un serveur VPS](/guides/bare-metal-cloud/virtual-private-servers/configure-ipv6) ».
  </Tab>
  <Tab label="Secondary DNS">
    Cet élément indique si des domaines sont configurés sur le DNS secondaire OVHcloud de votre VPS, une fonctionnalité utile pour héberger des services DNS. L'ajout ou la suppression d'un domaine du DNS secondaire n'est pas disponible dans la console OVHcloud. Consultez notre guide « [Configurer un DNS secondaire OVHcloud sur un VPS](/guides/bare-metal-cloud/virtual-private-servers/adding-secondary-dns-on-vps) » pour plus de détails à ce sujet.
  </Tab>
</Tabs>


#### Sauvegarde <a name="save"></a>

Ces options font référence à des services VPS supplémentaires pour les sauvegardes et la restauration de votre système.

<Tabs>
  <Tab label="Snapshot">
    Un snapshot sur un VPS est une sauvegarde instantanée de l'état du serveur, qui permet de restaurer rapidement le système en cas de problème. L'option `Snapshot` permet de créer un snapshot manuel comme point de restauration unique. Si l'option n'est pas active sur votre VPS, commandez-la via le lien <code className="action">Commander un snapshot</code>.
  </Tab>
  <Tab label="Backup automatisé">
    Une sauvegarde quotidienne du système (hors disques additionnels) est réalisée automatiquement et conservée durant 24 heures (applicable uniquement aux services commandés à partir du 7 août 2025). En passant l'option **Sauvegarde automatique** à **Premium**, vous disposerez des 7 dernières sauvegardes quotidiennes de votre VPS, que vous pourrez utiliser pour des montages et des restaurations.  
    Par rapport aux snapshots manuels, cette fonctionnalité augmente la sécurité des données en créant plusieurs points de restauration à intervalles réguliers.
  </Tab>
</Tabs>


Retrouvez toutes les informations sur les solutions de sauvegarde disponibles pour votre service sur la [page produit VPS](/links/bare-metal/vps-options) et dans nos guides « [Utiliser le snapshot](/guides/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps) » et « [Comment utiliser les sauvegardes automatisées sur un VPS](/guides/bare-metal-cloud/virtual-private-servers/using-automated-backups-on-a-vps) ».

#### Redémarrer votre VPS <a name="rebootvps"></a>

Un redémarrage peut s'avérer nécessaire afin d'appliquer des mises à jour de configuration ou pour résoudre un dysfonctionnement. Dans la mesure du possible, effectuez un « redémarrage logiciel » à partir de l'interface graphique du serveur (Windows, Plesk, etc.) ou via la ligne de commande ci-dessous :

```bash
sudo reboot
```

Cependant, vous pouvez effectuer un redémarrage forcé à tout moment dans la <ManagerLink to="/">console OVHcloud</ManagerLink>. Dans l'onglet <code className="action">Vue d'ensemble</code>, cliquez sur le bouton <code className="action">⋮</code> dans la ligne **Actions supplémentaires** de la section **Informations générales**. Sélectionnez <code className="action">Redémarrer mon VPS</code> et cliquez sur <code className="action">Confirmer</code> dans la fenêtre qui s'affiche.

<img className="thumbnail" alt="Additional actions menu of a VPS in the OVHcloud Console, with Reboot my VPS" src="/images/assets/screens/console/product-selection/bare-metal-cloud/vps/cp-reboot.png" loading="lazy" />

#### Réinstaller votre VPS <a name="reinstallvps"></a>

La réinstallation de votre VPS peut être effectuée depuis la console OVHcloud. Cette opération est généralement utilisée en cas de problème système, de changement d'environnement ou pour repartir d'une installation propre.

Dans la section **Informations générales** de l'onglet <code className="action">Vue d'ensemble</code>, cliquez sur le lien <code className="action">Réinstaller mon VPS</code> sous **Distribution**.

<img className="thumbnail" alt="Reinstall my VPS link under Distribution in the OVHcloud Console" src="/images/assets/screens/console/product-selection/bare-metal-cloud/vps/cp-reinst.png" loading="lazy" />

Dans le panneau **Réinstaller mon VPS** qui s'ouvre, choisissez un système d'exploitation dans la liste déroulante **Système d'exploitation**. Les options proposées sont [des images compatibles avec un VPS OVHcloud](/guides/public-cloud/compute/image-life-cycle) et sont immédiatement fonctionnelles après l'installation.

Si vous avez sélectionné un système d'exploitation compatible, vous pouvez fournir une **clé publique** à installer automatiquement. Deux possibilités s'offrent à vous :

- Copiez manuellement la chaîne de clé et collez-la dans le champ `Votre clé SSH Publique`.
- Si vous avez précédemment [stocké une clé publique](/guides/bare-metal-cloud/dedicated-servers/import-keys-control-panel) dans la <ManagerLink to="/">console OVHcloud</ManagerLink>, sélectionnez la clé souhaitée dans le menu déroulant `Clé SSH à pré-installer`.

<img className="thumbnail" alt="Reinstall my VPS panel in the OVHcloud Console" src="/images/bare-metal-cloud/virtual-private-servers/understand-vps-control-panel/console/reinstall.png" loading="lazy" />

Pour en savoir plus sur ce sujet, consultez nos guides :

- [Comment créer et utiliser des clés d'authentification pour les connexions SSH aux serveurs OVHcloud](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutoriel - Comment utiliser PuTTY pour les connexions SSH et l'authentification](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

Si vous avez sélectionné une clé stockée dans le menu déroulant `Clé SSH à pré-installer` et que vous n'avez pas besoin de mot de passe pour vous connecter, cochez la case `Je ne souhaite pas recevoir par e-mail les codes d'authentification de mon VPS.`.

:::warning
La réinstallation va formater tous les disques du serveur. Il est fortement recommandé de créer un snapshot de votre VPS avant de poursuivre, afin de pouvoir revenir à l'état précédent en cas de problème.

:::


:::info
**Licences**

Certains systèmes d'exploitation ou plateformes propriétaires, comme Plesk ou cPanel, nécessitent des licences qui génèrent des frais supplémentaires. Les licences sont administrables depuis la console OVHcloud : cliquez sur <code className="action">Bare Metal Cloud</code> dans la barre de navigation supérieure, puis sur <code className="action">Licences</code> dans le menu de gauche.

Pour avoir un système d'exploitation **Windows** fonctionnant sur un VPS, il faut l'avoir préalablement choisi **dans le processus de commande**. Un VPS avec un autre OS installé ne peut pas être réinstallé avec Windows via la méthode décrite ci-dessus.

:::


Le processus de réinstallation peut prendre quelques minutes.
