## Objectif

Le Game Panel vous permet de déployer un serveur Arma Reforger en quelques étapes. Le panel gère l'installation automatiquement, y compris la configuration des ports.

**Ce guide vous explique comment déployer un serveur Arma Reforger sur le Game Panel et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel. Dans le menu de gauche, rendez-vous dans la section `Game Servers` et cliquez sur <code className="action">Add Game Server</code>.

### Étape 2 — Créer un serveur Arma Reforger

Sélectionnez **Arma Reforger** dans la liste des jeux. Une fenêtre de configuration s'ouvre.

<img className="thumbnail" alt="Sélection d'Arma Reforger dans la liste des jeux" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/select-arma-reforger.png" loading="lazy" />

### Étape 3 — Configurer le serveur Arma Reforger

Renseignez le nom du serveur et vérifiez la configuration avant de lancer l'installation.

:::info
S'il s'agit de votre premier serveur Arma Reforger sur le Game Panel et que le Game Port par défaut est disponible, tous les ports requis seront configurés automatiquement lors de l'installation. Aucune configuration manuelle n'est nécessaire dans ce cas.
:::

Vous pouvez développer <code className="action">Advanced settings</code> pour ajuster des options telles que le mappage des ports (ports binding) et les limites de ressources. Les valeurs par défaut conviennent à la plupart des serveurs de jeu.

### Étape 4 — Lancer l'installation

Cliquez sur <code className="action">Install</code> pour lancer le déploiement.

### Étape 5 — Suivre l'installation

Cliquez sur <code className="action">Log/Console</code> pour suivre la progression de l'installation en temps réel. Pendant l'installation du serveur, le statut affiche **Installing**.

<img className="thumbnail" alt="Suivi de l'installation du serveur Arma Reforger dans le panneau de logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-logs.png" loading="lazy" />

### Étape 6 — Vérifier que le serveur est en cours d'exécution

Vérifiez que le statut du serveur est **Running**. Les commandes <code className="action">Log/Console</code> et <code className="action">Settings</code> restent disponibles pour gérer le serveur.

### Étape 7 — Confirmer la fin de l'installation

Une fois l'installation terminée, le statut du serveur passe à **Running**.

### Étape 8 — Récupérer les informations de connexion

Copiez l'adresse IP et le port depuis la colonne **Connection** de la liste des Game Servers.

<img className="thumbnail" alt="Détails de connexion du serveur Arma Reforger" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-connection-details.png" loading="lazy" />

### Étape 9 — Rejoindre votre serveur sur Arma Reforger

1. Ouvrez **Arma Reforger** et accédez au menu principal.
2. Cliquez sur **Multiplayer**, puis ouvrez l'onglet **Community**.
3. Recherchez le nom de votre serveur.
4. Une fois trouvé, cliquez dessus, puis cliquez sur **Join**.
