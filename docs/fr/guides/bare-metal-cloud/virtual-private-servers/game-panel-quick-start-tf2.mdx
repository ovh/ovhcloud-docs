## Objectif

Le Game Panel vous permet de déployer un serveur Team Fortress 2 en quelques étapes. Le Game Panel gère l'installation automatiquement, y compris la configuration des ports.

**Ce guide vous explique comment déployer un serveur Team Fortress 2 sur le Game Panel et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel. Dans le menu de gauche, rendez-vous dans la section `Game Servers` et cliquez sur <code className="action">Add Game Server</code>.

### Étape 2 — Créer un serveur Team Fortress 2

Sélectionnez **Team Fortress 2** dans la liste des jeux. Une fenêtre de configuration s'ouvre.

<img className="thumbnail" alt="Sélection de Team Fortress 2 dans la liste des jeux" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/select-tf2.png" loading="lazy" />

### Étape 3 — Configurer le serveur Team Fortress 2

Renseignez le nom du serveur et vérifiez la configuration.

:::info
S'il s'agit de votre premier serveur Team Fortress 2 sur le Game Panel et que le Game Port par défaut est disponible, tous les ports requis sont configurés automatiquement. Aucune configuration manuelle n'est nécessaire.
:::

Vous pouvez développer <code className="action">Advanced settings</code> pour ajuster des options telles que le mappage des ports (ports binding) et les limites de ressources. Les valeurs par défaut conviennent à la plupart des serveurs de jeu.

### Étape 4 — Lancer l'installation

Cliquez sur <code className="action">Install</code> pour démarrer le déploiement.

### Étape 5 — Suivre l'installation

Cliquez sur <code className="action">Log/Console</code> pour suivre la progression de l'installation en temps réel. Pendant l'installation du serveur, le statut affiche **Installing**.

<img className="thumbnail" alt="Suivi de l'installation du serveur Team Fortress 2 dans le panneau des logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-installation-logs.png" loading="lazy" />

### Étape 6 — Vérifier que le serveur est en cours d'exécution

Vérifiez que le statut est **Running** ; une activité CPU et RAM est visible. Vous pouvez utiliser les commandes <code className="action">Log/Console</code> et <code className="action">Settings</code> pour gérer le serveur.

<img className="thumbnail" alt="Serveur Team Fortress 2 avec le statut Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-running.png" loading="lazy" />

### Étape 7 — Confirmer la fin de l'installation

Une fois l'installation terminée, le statut du serveur passe à **Running**.

### Étape 8 — Récupérer les informations de connexion

Copiez l'adresse IP et le port depuis la colonne **Connection** de la liste des Game Servers.

### Étape 9 — Rejoindre votre serveur sur Team Fortress 2

Ajoutez d'abord votre serveur à vos favoris Steam :

1. Dans **Steam**, allez dans **View** > **Game Servers**.
2. Ouvrez l'onglet **Favorites** et cliquez sur **Add a server**.
3. Collez l'adresse IP et le port indiqués dans la colonne **Connection**, puis cliquez sur **OK**.

Lancez ensuite **Team Fortress 2** et cliquez sur **Connect** sur le serveur ajouté à vos favoris.
