## Objectif

Le Game Panel vous permet de déployer un serveur Team Fortress 2 en quelques étapes. Le Game Panel gère l'installation et la configuration des ports automatiquement.

**Ce guide vous explique comment déployer un serveur Team Fortress 2 sur le Game Panel et vous y connecter.**

## Prérequis

- Un [VPS](https://www.ovhcloud.com/fr/vps/) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- L'accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel.

### Étape 2 — Créer une nouvelle instance de serveur

Cliquez sur <code className="action">Add Game Server</code> et sélectionnez **Team Fortress 2**.

<img className="thumbnail" alt="Sélection de Team Fortress 2 dans la liste des jeux" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/select-tf2.png" loading="lazy" />

:::info
S'il s'agit de votre premier serveur Team Fortress 2 sur le Game Panel et que le Game Port par défaut est disponible, tous les ports requis sont configurés automatiquement. Aucune configuration manuelle n'est nécessaire.
:::


### Étape 3 — Suivre la progression de l'installation

Une fois l'installation lancée, un écran de confirmation s'affiche. Cliquez sur <code className="action">Log/Console</code> pour suivre la progression de l'installation en temps réel.

<img className="thumbnail" alt="Écran de démarrage de l'installation Team Fortress 2" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-installation-started.png" loading="lazy" />

Pendant l'installation du serveur, le statut affiche **Installing**. Suivez la progression détaillée dans le panneau des logs.

<img className="thumbnail" alt="Panneau des logs d'installation Team Fortress 2" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-installation-logs.png" loading="lazy" />

### Étape 4 — Confirmer la fin de l'installation

Une fois l'installation terminée, le statut du serveur passe à **Running**.

<img className="thumbnail" alt="Serveur Team Fortress 2 avec le statut Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-running.png" loading="lazy" />

### Étape 5 — Récupérer les informations de connexion

Lorsque le statut de votre serveur est **Running**, copiez les informations de connexion depuis le Game Panel.

### Étape 6 — Rejoindre votre serveur dans Team Fortress 2

1. Ouvrez **Team Fortress 2**.
2. Allez dans <code className="action">Community server</code> > <code className="action">Favorites</code>.
3. Cliquez sur <code className="action">Add a Server</code> et collez `servX.gamepanel.ovh:PORT`.
