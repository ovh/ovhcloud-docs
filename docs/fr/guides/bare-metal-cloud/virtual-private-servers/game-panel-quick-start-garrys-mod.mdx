## Objectif

Le Game Panel vous permet de déployer un serveur Garry's Mod avec une installation et une configuration des ports automatisées.

**Ce guide vous explique comment déployer un serveur Garry's Mod sur le Game Panel et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel. Rendez-vous dans la section `Game Servers` du menu de gauche et cliquez sur <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Section Game Servers avec le bouton Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/game-servers-list.png" loading="lazy" />

### Étape 2 — Créer un serveur Garry's Mod

Sélectionnez **Garry's Mod** dans la liste des jeux. Une fenêtre de configuration s'ouvre.

<img className="thumbnail" alt="Sélection de Garry's Mod dans la liste des jeux" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/select-garrys-mod.png" loading="lazy" />

### Étape 3 — Configurer le serveur Garry's Mod

Saisissez un **Server Name** (par exemple `Garry's Mod Server`). Les ports réseau requis sont configurés automatiquement lors de l'installation.

Vous pouvez développer <code className="action">Advanced settings</code> pour ajuster des options telles que le mappage des ports (ports binding) et les limites de ressources. Les valeurs par défaut conviennent à la plupart des serveurs de jeu.

### Étape 4 — Lancer l'installation

Cliquez sur <code className="action">Install</code>. Le déploiement démarre automatiquement. Patientez quelques minutes pendant le téléchargement de l'image et l'installation du serveur.

### Étape 5 — Suivre l'installation

Cliquez sur <code className="action">Log/Console</code> pour suivre la progression en temps réel. Le statut affiche **Installing**.

### Étape 6 — Confirmer la fin de l'installation

Une fois l'installation terminée et le serveur lancé, le statut passe à **Running**.

### Étape 7 — Vérifier que le serveur est en cours d'exécution

Vérifiez qu'une activité CPU et RAM est visible. Vous pouvez utiliser les commandes <code className="action">Log/Console</code> et <code className="action">Settings</code> pour gérer le serveur.

<img className="thumbnail" alt="Serveur Garry's Mod avec le statut Running et l'activité CPU et RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-running.png" loading="lazy" />

### Étape 8 — Récupérer les informations de connexion

Copiez l'adresse IP et le port depuis la colonne **Connection** de la liste des Game Servers.

### Étape 9 — Rejoindre votre serveur sur Garry's Mod

Commencez par ajouter votre serveur à vos favoris Steam :

1. Dans **Steam**, rendez-vous dans **View** > **Game Servers**.
2. Ouvrez l'onglet **Favorites** et cliquez sur **Add a server**.
3. Collez l'adresse IP et le port indiqués dans la colonne **Connection**, puis cliquez sur **OK**.

Rejoignez ensuite le serveur depuis le jeu :

1. Lancez **Garry's Mod** et cliquez sur **Find Multiplayer Game**.
2. Ouvrez l'onglet **Favorites**.
3. Sélectionnez votre serveur et double-cliquez dessus pour vous connecter.

### Configurer les paramètres du jeu

Accédez à <code className="action">Settings</code> > <code className="action">Game Config</code> pour ajuster les principaux paramètres de votre serveur sans éditer le moindre fichier de configuration.

<img className="thumbnail" alt="Les paramètres Game Config d'un serveur Garry's Mod" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-game-config.png" loading="lazy" />

| Paramètre | Description |
|-----------|-------------|
| `Server name` | Le nom affiché dans le navigateur de serveurs du jeu. |
| `Map` | La carte chargée au démarrage du serveur. |
| `Game mode` | Le mode de jeu du serveur. |
| `Workshop collection` | L'identifiant d'une collection Steam Workshop, téléchargée et montée à chaque démarrage. La collection doit être publique ou non répertoriée. |
| `Counter-Strike: Source content` | Télécharge le contenu de Counter-Strike: Source, réutilisé par de nombreux addons. Les joueurs doivent posséder le jeu de leur côté. Ajoute plusieurs gigaoctets au démarrage suivant. |
| `Maximum players` | Le nombre maximum de joueurs simultanés. |
| `Server password` | Le mot de passe demandé aux joueurs. Laissez-le vide pour un serveur public. |
| `Admin password (RCON)` | Le mot de passe d'administration à distance du serveur via la console. |
| `Steam GSL token` | Le jeton qui fait apparaître votre serveur dans le navigateur de serveurs officiel. Obtenez-le sur [steamcommunity.com](https://steamcommunity.com/dev/managegameservers). |
| `Update workshop addons` | Met à jour les addons de la collection à chaque démarrage. |
| `Update on start` | Vérifie et installe les mises à jour du jeu à chaque démarrage. |

Les modifications prennent effet au redémarrage du serveur.

### Changer de mode de jeu

Les champs `Game mode` et `Map` sont libres : le menu déroulant ne propose que les valeurs livrées avec le jeu, mais vous pouvez y saisir n'importe quel nom.

**Trouble in Terrorist Town** est fourni avec Garry's Mod. Sélectionnez-le dans `Game mode`, puis redémarrez votre serveur. Pensez à la carte : `Construct` et `Flatgrass` sont des cartes sandbox, un serveur TTT a besoin de cartes `ttt_` récupérées sur le Workshop.

**DarkRP** n'est pas fourni avec le jeu et passe par le Workshop :

1. Créez une collection Steam Workshop, publique ou non répertoriée, contenant DarkRP, ses dépendances et une carte `rp_`.
2. Renseignez son identifiant dans `Workshop collection`.
3. Saisissez `darkrp` dans `Game mode` et le nom de votre carte dans `Map`.
4. Activez `Counter-Strike: Source content`, dont de nombreux addons DarkRP réutilisent les textures.
5. Redémarrez votre serveur.

<img className="thumbnail" alt="Les réglages Game mode, Workshop collection et contenu Counter-Strike: Source" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/gameplay-settings.png" loading="lazy" />

:::warning
Le champ `Map` désigne la carte à charger, il ne la télécharge pas. Une carte absente de votre collection Workshop ne sera pas trouvée au démarrage, et le serveur ne se lancera pas.
:::
