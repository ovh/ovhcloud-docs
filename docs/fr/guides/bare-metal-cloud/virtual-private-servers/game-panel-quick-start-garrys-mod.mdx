## Objectif

Le Game Panel vous permet de déployer un serveur Garry's Mod avec une installation et une configuration des ports automatisées.

**Ce guide vous explique comment déployer un serveur Garry's Mod sur le Game Panel et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel. Rendez-vous dans la section <code className="action">Game Servers</code> du menu de gauche.

<img className="thumbnail" alt="Section Game Servers avec le bouton Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/game-servers-list.png" loading="lazy" />

### Étape 2 — Créer un serveur Garry's Mod

Cliquez sur <code className="action">Add Game Server</code> et sélectionnez **Garrys Mod** dans la liste.

<img className="thumbnail" alt="Sélection de Garry's Mod dans la liste des jeux" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/select-garrys-mod.png" loading="lazy" />

Saisissez un **Server Name** (par exemple `Garrys Mod Server`). Les ports réseau requis sont configurés automatiquement lors de l'installation.

### Étape 3 — Lancer l'installation

Cliquez sur <code className="action">Select</code>. Le déploiement démarre automatiquement. Patientez quelques minutes pendant le téléchargement de l'image et l'installation du serveur.

Cliquez ensuite sur <code className="action">Launch</code> pour démarrer le serveur.

### Étape 4 — Vérifier que le serveur fonctionne

Vérifiez que le statut du serveur affiche **Running** et qu'une activité CPU/RAM est visible.

<img className="thumbnail" alt="Serveur Garry's Mod avec le statut Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-running.png" loading="lazy" />

Actions disponibles :

- <code className="action">Log/Console</code> : ouvrez la console pour suivre le démarrage et consultez les logs en cas de problème.
- <code className="action">Settings</code> > <code className="action">Game Config</code> : accédez aux paramètres du jeu (carte de démarrage, tickrate, gamemode, limite de joueurs, mot de passe RCON, collection Workshop, GSLT).

<img className="thumbnail" alt="Paramètres Game Config de Garry's Mod" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-game-config.png" loading="lazy" />

### Étape 5 — Se connecter au serveur

Commencez par ajouter votre serveur à vos favoris Steam :

1. Dans **Steam**, rendez-vous dans **View** > **Game Servers**.
2. Ouvrez l'onglet **Favorites** et cliquez sur **Add a server**.
3. Collez l'adresse IP et le port indiqués dans la colonne **Connection**, puis cliquez sur **OK**.

Rejoignez ensuite le serveur depuis le jeu :

1. Lancez **Garry's Mod** et cliquez sur **Find Multiplayer Game**.
2. Ouvrez l'onglet **Favorites**.
3. Sélectionnez votre serveur et double-cliquez dessus pour vous connecter.

:::info
Pour aller plus loin, ajoutez des mods ou des collections Workshop, ajustez le tickrate et les paramètres de performance, ou restreignez l'accès avec un mot de passe ou une whitelist.
:::
