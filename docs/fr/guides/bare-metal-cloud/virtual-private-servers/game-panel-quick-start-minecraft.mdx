## Objectif

Le Game Panel OVHcloud vous permet de déployer un serveur Minecraft avec une installation et une configuration des ports automatisées.

**Ce guide vous explique comment déployer un serveur Minecraft sur le Game Panel OVHcloud et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel OVHcloud. Dans le menu de gauche, rendez-vous dans la section `Game Servers` et cliquez sur <code className="action">Add Game Server</code>.

### Étape 2 — Créer un serveur Minecraft

Sélectionnez **Minecraft** dans la liste des jeux. Une fenêtre de configuration s'ouvre.

<img className="thumbnail" alt="Sélection de Minecraft dans la liste des jeux" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/select-minecraft.png" loading="lazy" />

### Étape 3 — Choisir le type de serveur Minecraft

Lors de la création de votre serveur, vous devez choisir le type de serveur Minecraft que vous souhaitez installer. Chaque option répond à des besoins différents :

- **Minecraft Java Edition** : la version officielle de Minecraft pour PC. Elle convient aux serveurs qui souhaitent proposer une expérience Minecraft classique, sans système de plugin ou de mod spécifique préinstallé.
- **Minecraft Bedrock Edition** : la version conçue pour permettre aux joueurs de se connecter depuis différents appareils, notamment Windows, les consoles et les smartphones. C'est le choix idéal pour le jeu multiplateforme.
- **PaperMC** : une solution optimisée pour les serveurs communautaires qui utilisent des plugins. Les plugins ajoutent des fonctionnalités sans modifier le jeu des joueurs, comme des systèmes économiques, la téléportation, la protection de zones ou des mini-jeux.
- **Fabric** : une plateforme de mods légère et rapide. Elle est appréciée pour ses performances et son vaste écosystème de mods, tout en conservant une consommation de ressources relativement faible.
- **Forge** : la plateforme de mods historique de Minecraft. Elle offre le catalogue de mods le plus étendu et la meilleure compatibilité avec les modpacks anciens, ce qui en fait le choix à privilégier pour les mods qui n'existent que pour Forge.
- **NeoForge** : une plateforme de mods avancée offrant de vastes possibilités de personnalisation. Elle est particulièrement adaptée aux serveurs utilisant des mods complexes ou de grands modpacks qui nécessitent des fonctionnalités étendues.

### Étape 4 — Configurer le serveur Minecraft

Saisissez un nom pour votre serveur et vérifiez la configuration avant de lancer l'installation.

:::info
S'il s'agit de votre premier serveur Minecraft sur le Game Panel et que le Game Port par défaut est disponible, tous les ports requis sont configurés automatiquement. Aucune configuration manuelle n'est nécessaire.
:::

Vous pouvez développer <code className="action">Advanced settings</code> pour ajuster des options telles que le mappage des ports (ports binding) et les limites de ressources. Les valeurs par défaut conviennent à la plupart des serveurs de jeu.

### Étape 5 — Lancer l'installation

Cliquez sur <code className="action">Install</code> pour lancer l'installation. Le déploiement démarre.

### Étape 6 — Suivre l'installation

Cliquez sur <code className="action">Log/Console</code> pour suivre la progression de l'installation en temps réel.

Pendant l'installation du serveur, le statut affiche **Installing**. Suivez la progression détaillée dans le panneau de logs.

<img className="thumbnail" alt="Suivi de l'installation du serveur Minecraft" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/installation-logs.png" loading="lazy" />

### Étape 7 — Vérifier que le serveur est en cours d'exécution

Vérifiez que le statut du serveur est **Running** et qu'une activité CPU et RAM est visible. Vous pouvez utiliser les commandes <code className="action">Log/Console</code> et <code className="action">Settings</code> pour gérer le serveur.

<img className="thumbnail" alt="Serveur Minecraft avec le statut Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/server-running.png" loading="lazy" />

### Étape 8 — Confirmer la fin de l'installation

Une fois l'installation terminée, le statut du serveur passe à **Running**.

### Étape 9 — Récupérer les informations de connexion

Une fois que votre serveur est au statut **Running**, copiez l'adresse IP et le port depuis la colonne **Connection** de la liste des Game Servers.

### Étape 10 — Rejoindre votre serveur sur Minecraft

1. Ouvrez **Minecraft**.
2. Allez dans **Multiplayer**.
3. Cliquez sur **Direct Connect** et collez l'adresse IP et le port indiqués dans la colonne **Connection**.
