## VPS OVHcloud

Un [VPS OVHcloud](/links/bare-metal/vps) (Virtual Private Server) est une machine virtuelle avec un accès root complet, hébergée sur l'infrastructure OVHcloud — l'intermédiaire entre un hébergement web mutualisé et un serveur dédié. C'est le premier serveur idéal pour héberger vos propres services web et applications.

Avec un VPS OVHcloud, vous pouvez :

- Héberger des sites et applications web
- Exécuter des applications auto-hébergées (Docker, Nextcloud, n8n, agents IA...)
- Héberger des serveurs de jeu avec le Game Panel
- Faire évoluer vos ressources au rythme de votre projet
- Protéger vos données grâce aux snapshots et aux sauvegardes automatisées
