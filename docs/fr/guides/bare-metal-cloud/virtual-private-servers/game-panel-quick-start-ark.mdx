## Objectif

Le Game Panel OVHcloud vous permet de déployer un serveur ARK: Survival Evolved en quelques étapes. Le Game Panel gère automatiquement l'installation, y compris la configuration des ports.

**Ce guide vous explique comment déployer un serveur ARK: Survival Evolved sur le Game Panel OVHcloud et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel OVHcloud. Dans le menu de gauche, rendez-vous dans la section `Game Servers` et cliquez sur <code className="action">Add Game Server</code>.

### Étape 2 — Créer un serveur ARK: Survival Evolved

Sélectionnez **ARK: Survival Evolved** dans la liste des jeux. Une fenêtre de configuration s'ouvre.

<img className="thumbnail" alt="Sélection d'ARK: Survival Evolved dans la liste des jeux" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/select-ark.png" loading="lazy" />

### Étape 3 — Configurer le serveur ARK: Survival Evolved

Saisissez un nom pour votre serveur. Aucune autre configuration spécifique au jeu n'est requise pour ARK: Survival Evolved.

:::info
S'il s'agit de votre premier serveur ARK sur le Game Panel et que le port de jeu par défaut est disponible, tous les ports requis seront configurés automatiquement lors de l'installation. Aucune configuration manuelle n'est nécessaire dans ce cas.
:::

Vous pouvez développer <code className="action">Advanced settings</code> pour ajuster des options telles que le mappage des ports (ports binding) et les limites de ressources. Les valeurs par défaut conviennent à la plupart des serveurs de jeu.

### Étape 4 — Lancer l'installation

Cliquez sur <code className="action">Install</code> pour démarrer le déploiement.

### Étape 5 — Suivre l'installation

Cliquez sur <code className="action">Log/Console</code> pour suivre la progression de l'installation en temps réel. Pendant l'installation du serveur, le statut affiche **Installing**.

<img className="thumbnail" alt="Suivi de l'installation du serveur ARK dans le panneau des logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/installation-logs.png" loading="lazy" />

### Étape 6 — Vérifier que le serveur est en cours d'exécution

Vérifiez que le statut du serveur est **Running** et que l'activité CPU/RAM est visible. Les commandes <code className="action">Log/Console</code> et <code className="action">Settings</code> restent disponibles depuis cette vue.

<img className="thumbnail" alt="Serveur ARK avec le statut Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/server-running.png" loading="lazy" />

### Étape 7 — Confirmer la fin de l'installation

Une fois l'installation terminée, le statut du serveur passe à **Running**.

### Étape 8 — Récupérer les informations de connexion

Copiez l'adresse IP et le port depuis la colonne **Connection** de la liste des Game Servers.

<img className="thumbnail" alt="Détails de connexion du serveur ARK" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/connection-details.png" loading="lazy" />

### Étape 9 — Rejoindre votre serveur sur ARK

Commencez par ajouter votre serveur à vos favoris Steam :

1. Dans **Steam**, allez dans **View** > **Game Servers**.
2. Ouvrez l'onglet **Favorites** et cliquez sur **Add a server**.
3. Collez l'adresse IP et le port indiqués dans la colonne **Connection**, puis cliquez sur **OK**.

Rejoignez ensuite le serveur depuis le jeu :

1. Lancez **ARK: Survival Evolved** et cliquez sur **Join ARK**.
2. Réglez le **Session Filter** sur **Favorites**.
3. Sélectionnez votre serveur et cliquez sur **Join**.
