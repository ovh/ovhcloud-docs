## Objectif

Le Game Panel expose la configuration du serveur Counter-Strike 2 directement dans son interface. Les options de base, comme le nom du serveur, la carte et le mode de jeu, sont accessibles via un formulaire graphique, et vous pouvez également installer des frameworks serveur tels que MetaMod et CounterStrikeSharp.

**Ce guide vous explique comment modifier la configuration d'un serveur Counter-Strike 2 sur le Game Panel.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un serveur Counter-Strike 2 déployé sur le Game Panel. Consultez le guide [Déployer un serveur Counter-Strike 2 sur le Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/).

## En pratique

### Étape 1 — Ouvrir les paramètres du serveur

Depuis la page principale du Game Panel, repérez le serveur Counter-Strike 2 à configurer. Dans la colonne <code className="action">Management</code>, cliquez sur <code className="action">Settings</code>.

<img className="thumbnail" alt="Serveur Counter-Strike 2 avec le bouton Settings mis en évidence" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-server-settings.png" loading="lazy" />

### Étape 2 — Ouvrir l'onglet Game Config

Dans le panneau **Server Settings**, sélectionnez <code className="action">Game Config</code> dans la barre latérale gauche.

La section **Game Config** vous permet de gérer les principaux paramètres de votre serveur Counter-Strike 2 à l'aide de deux onglets :

- **Settings** : configurez les paramètres du serveur de jeu.
- **Frameworks** : installez et gérez les frameworks serveur pris en charge.

### Étape 3 — Configurer l'onglet Settings

L'onglet <code className="action">Settings</code> vous permet de modifier les principaux paramètres du serveur Counter-Strike 2 :

| Paramètre | Description |
|---------|-------------|
| Server Name | Le nom affiché dans le navigateur de serveurs Counter-Strike 2. |
| Max Players | Le nombre maximum de joueurs pouvant se connecter simultanément. |
| Map | La carte chargée au démarrage du serveur. Vous pouvez aussi saisir manuellement le nom d'une carte qui n'apparaît pas dans la liste. |
| Game Type | Définit la catégorie principale de jeu. |
| Game Mode | Définit le mode de jeu au sein du type de jeu sélectionné. Pour en savoir plus sur les modes disponibles, consultez le [guide de la Valve Developer Community](https://developer.valvesoftware.com/wiki/Counter-Strike:_Global_Offensive/Game_Modes). |
| Server Password | Oblige les joueurs à saisir un mot de passe avant de rejoindre le serveur. |
| Admin Password (RCON) | Active l'accès à la console distante (RCON) et définit le mot de passe utilisé pour administrer le serveur à distance. |
| Steam GSL Token | Un Game Server Login Token (GSLT) utilisé pour authentifier votre serveur dédié auprès des services Steam. Pour générer un token, consultez la [page de gestion des comptes de serveurs de jeu Steam](https://steamcommunity.com/dev/managegameservers). |
| VAC Anti-Cheat | Active ou désactive la protection Valve Anti-Cheat (VAC) sur le serveur. |

<img className="thumbnail" alt="L'onglet Settings de la Game Config Counter-Strike 2" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-settings.png" loading="lazy" />

:::info
Après avoir modifié l'un de ces paramètres, enregistrez vos modifications et redémarrez le serveur pour qu'elles prennent effet.
:::


### Étape 4 — Installer des frameworks

L'onglet <code className="action">Frameworks</code> vous permet d'installer des composants supplémentaires pour étendre les fonctionnalités de votre serveur Counter-Strike 2.

- **MetaMod** : un framework de plugins serveur qui agit comme une couche intermédiaire entre le serveur de jeu et les plugins. Il fournit la base requise par de nombreuses extensions serveur avancées et outils d'administration.
- **CounterStrikeSharp** : un framework de plugins moderne pour Counter-Strike 2 qui permet aux administrateurs serveur et aux développeurs de créer et d'exécuter des plugins personnalisés en C#. Il peut ajouter des fonctionnalités de gameplay, des outils de gestion du serveur et des extensions développées par la communauté.

Vous pouvez installer l'un ou l'autre de ces frameworks directement depuis le Game Panel, et les réinstaller ultérieurement pour les mettre à jour vers une version plus récente lorsqu'elle est disponible.

<img className="thumbnail" alt="L'onglet Frameworks affichant MetaMod et CounterStrikeSharp" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-frameworks.png" loading="lazy" />

:::info
Le serveur doit être arrêté avant d'installer un framework.
:::


### Étape 5 — Enregistrer et redémarrer

Après avoir enregistré vos modifications, redémarrez le serveur Counter-Strike 2 depuis le Game Panel pour appliquer la nouvelle configuration.
