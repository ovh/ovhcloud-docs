## Objectif

Le Game Panel OVHcloud vous permet de sauvegarder vos instances de serveurs de jeu pour les restaurer dans un état antérieur si nécessaire.

**Ce guide vous explique comment créer une sauvegarde de votre serveur de jeu sur le Game Panel OVHcloud.**

## Prérequis

- Un [VPS](https://www.ovhcloud.com/fr/vps/) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Une instance de serveur de jeu déployée sur le Game Panel. Consultez le guide [Premiers pas avec le Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

## En pratique

### Étape 1 — Se connecter au Game Panel

Connectez-vous à votre Game Panel. Si vous avez besoin d'aide, consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Étape 2 — Accéder aux paramètres de sauvegarde

Une fois connecté :

1. Sélectionnez votre serveur de jeu.
2. Cliquez sur <code className="action">Settings</code>.
3. Rendez-vous dans l'onglet <code className="action">Backup</code>.

<img className="thumbnail" alt="L'onglet des paramètres de sauvegarde" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/backup-tab.png" loading="lazy" />

### Étape 3 — Créer une sauvegarde

Cliquez sur <code className="action">Create backup now</code>.

:::info
Nous vous recommandons de conserver l'option **Stop server before backup** activée afin de garantir la cohérence des sauvegardes.
:::


<img className="thumbnail" alt="Création d'une sauvegarde avec l'option d'arrêt du serveur" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/create-backup.png" loading="lazy" />

Une fois la sauvegarde terminée, le fichier est disponible au téléchargement dans la même section des paramètres.
