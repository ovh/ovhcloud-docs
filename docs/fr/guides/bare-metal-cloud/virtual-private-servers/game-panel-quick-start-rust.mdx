## Objectif

Le Game Panel OVHcloud vous permet de déployer un serveur Rust avec une installation et une configuration des ports automatisées.

**Ce guide vous explique comment déployer un serveur Rust sur le Game Panel OVHcloud et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel OVHcloud. Dans le menu de gauche, rendez-vous dans la section `Game Servers` et cliquez sur <code className="action">Add Game Server</code>.

### Étape 2 — Créer un serveur Rust

Sélectionnez **Rust** dans la liste des jeux. Vous pouvez utiliser le champ de recherche situé en haut de la fenêtre pour le trouver plus rapidement. Une fenêtre de configuration s'ouvre.

<img className="thumbnail" alt="Sélection de Rust dans la liste des jeux du Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/select-rust.png" loading="lazy" />

### Étape 3 — Configurer le serveur Rust

Dans cette section, vous pouvez définir un nom pour votre serveur dans le champ **Server Name**.

Un **RCON Password** est également généré automatiquement. Il est utilisé par le système RCON du jeu pour administrer le serveur à distance. Cliquez sur <code className="action">Regenerate</code> pour en obtenir un nouveau, ou remplacez-le par un mot de passe de votre choix (8 caractères minimum). Vous pourrez le modifier à nouveau une fois le serveur installé.

:::warning
Veillez à conserver ce mot de passe dans un endroit sécurisé. Toute personne qui en a connaissance peut exécuter des commandes d'administration sur votre serveur.
:::

Vous pouvez développer <code className="action">Advanced Settings</code> pour ajuster des options telles que le mappage des ports (ports binding), les volumes, les variables d'environnement et les limites de ressources. Les valeurs par défaut conviennent à la plupart des serveurs de jeu.

<img className="thumbnail" alt="Formulaire de configuration du serveur Rust avec le nom du serveur et les paramètres avancés" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/configure-server.png" loading="lazy" />

:::info
S'il s'agit de votre premier serveur Rust sur le Game Panel et que les ports par défaut sont disponibles, tous les ports nécessaires sont configurés automatiquement. Aucune configuration manuelle n'est requise. L'image Rust utilise trois ports : `28015/UDP` (Game), `28017/UDP` (Steam Query) et `28082/TCP` (Rust+ companion app). Si ces ports sont déjà utilisés par un autre serveur de jeu, le Game Panel attribue des ports hôtes libres à la place.
:::

### Étape 4 — Lancer l'installation

Cliquez sur <code className="action">Install</code> pour lancer l'installation. Le déploiement démarre et une fenêtre de progression suit les étapes suivantes :

1. Téléchargement de l'image du conteneur.
2. Préparation des fichiers du serveur.
3. Création du conteneur.
4. Démarrage du conteneur.

### Étape 5 — Suivre l'installation

Une fois le conteneur démarré, une fenêtre de confirmation s'affiche. Cliquez sur <code className="action">Open Logs / Console</code> pour suivre la progression de l'installation en temps réel. Vous pouvez également l'ouvrir à tout moment avec le bouton <code className="action">Log/Console</code> de votre serveur.

<img className="thumbnail" alt="Fenêtre de confirmation avec le bouton Open Logs / Console" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/installation-started.png" loading="lazy" />

La console affiche les étapes de l'installation, puis le téléchargement des fichiers du serveur Rust via SteamCMD, avec un pourcentage de progression.

<img className="thumbnail" alt="Logs d'installation du serveur Rust dans la console du Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/installation-logs.png" loading="lazy" />

:::warning
Les fichiers du serveur Rust représentent un téléchargement de plusieurs gigaoctets. Le serveur conserve le statut **Installing** pendant toute la durée du téléchargement, puis pendant la génération du monde de jeu. Consultez la console pour suivre la progression réelle.
:::

### Étape 6 — Vérifier que le serveur est en cours d'exécution

Vérifiez que le statut du serveur est **Running** et qu'une activité CPU et RAM est visible. Vous pouvez utiliser les contrôles <code className="action">Log/Console</code> et <code className="action">Settings</code> pour gérer le serveur, ainsi que les contrôles <code className="action">Stop</code> et <code className="action">Restart</code> pour modifier son état d'alimentation.

<img className="thumbnail" alt="Serveur Rust avec le statut Running et l'activité CPU et RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/server-running.png" loading="lazy" />

### Étape 7 — Confirmer la fin de l'installation

Une fois le téléchargement terminé, la console affiche le démarrage du serveur Rust, puis la génération du monde de jeu (carte des hauteurs, biomes, monuments). Cette étape peut prendre plusieurs minutes.

Le statut peut afficher brièvement **Unhealthy** pendant que le serveur termine son démarrage et ne répond pas encore à la vérification d'état. Ce comportement est normal lors d'une première installation.

Le statut du serveur passe à **Running** une fois le monde généré et le serveur en écoute. Votre serveur Rust est alors prêt à accepter les connexions.

### Étape 8 — Récupérer les informations de connexion

Une fois votre serveur démarré, copiez l'adresse IP et le port depuis la colonne **Connection** de la liste des serveurs de jeu. Utilisez le bouton de copie pour les copier dans le presse-papiers.

### Étape 9 — Rejoindre votre serveur sur Rust

Pour rejoindre votre serveur depuis le client Rust :

1. Lancez **Rust**.
2. Appuyez sur la touche `F1` pour ouvrir la console du jeu.
3. Saisissez la commande suivante, en remplaçant `IP` et `PORT` par les valeurs de la colonne **Connection** :

```console
client.connect IP:PORT
```

### Configurer les paramètres du jeu

La section <code className="action">Game Config</code> vous permet d'ajuster les principaux paramètres de votre serveur Rust sans éditer les fichiers de configuration à la main :

| Paramètre | Description |
|-----------|-------------|
| `Server name` | Le nom affiché dans le navigateur de serveurs du jeu. |
| `Gamemode` | `vanilla`, `Softcore`, `Hardcore` ou `Primitive`. |
| `Map type` | `Procedural Map`, `Barren`, `Hapis Island` ou `Savas Island`. |
| `Map seed` | La graine utilisée pour générer une carte procédurale. |
| `Map size` | La taille de la carte générée. |
| `Player limit` | Le nombre maximum de joueurs simultanés. |
| `Save interval` | L'intervalle entre deux sauvegardes du monde de jeu. |
| `Tick rate` | La fréquence de rafraîchissement du serveur. |

D'autres options, telles que la description du serveur, le mode PvE ou les dégâts de chute, sont disponibles dans le fichier de configuration `server.cfg`, dans la même section.

Pour une configuration avancée, utilisez le [File Manager](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/) pour éditer directement les fichiers de configuration de Rust.
