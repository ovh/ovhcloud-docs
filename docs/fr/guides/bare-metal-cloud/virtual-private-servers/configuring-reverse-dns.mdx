## Objectif

Le Reverse DNS (*rDNS*) est le complément de la résolution DNS « *forward* » qui permet de résoudre les noms de domaine en adresses IP. Grâce au reverse DNS, une adresse IP peut être résolue en nom de domaine (ou nom d’hôte) auquel elle est reliée. Cela signifie que les requêtes DNS de l'adresse IP associée retourneront ce nom de domaine.

La configuration du reverse DNS d'un serveur est particulièrement utile lors de l'envoi d'e-mails. Les systèmes de protection antispam valident mieux un serveur e-mail si une requête DNS inverse de l'adresse IP se résout correctement.

**Ce guide vous explique comment configurer le reverse DNS de votre adresse IP depuis la console OVHcloud.**

## Prérequis

- Une adresse IP attachée à un service de votre compte OVHcloud
- Un nom de domaine avec son enregistrement `A` ou `AAAA` relié à votre service

## En pratique

Sur la page **Adresses IP**, vous pouvez affiner la liste à l'aide des filtres rapides situés au-dessus du tableau (**IPv4**, **IPv6**, **IP additionnelle**, **BYOIP**). Vous pouvez également rechercher une adresse IP spécifique dans le champ **Rechercher**.

<img className="thumbnail" alt="IP addresses page in the OVHcloud Console with the Search field" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/ip-list-search.png" loading="lazy" />

Cliquez sur l'adresse IP concernée pour ouvrir sa page, puis cliquez sur l'onglet <code className="action">Reverse DNS</code>. Cliquez sur le bouton <code className="action">Configurer</code> au-dessus du tableau.

<img className="thumbnail" alt="Reverse DNS tab of an IP address in the OVHcloud Console with the Configure button" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-tab.png" loading="lazy" />

Dans la fenêtre **Configurer le Reverse DNS**, renseignez votre reverse dans le champ **Nom d'hôte reverse DNS** et cliquez sur <code className="action">Configurer</code>.

<img className="thumbnail" alt="Configure Reverse DNS window in the OVHcloud Console with the Reverse DNS hostname field" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-configure.png" loading="lazy" />

Pour modifier un reverse existant, suivez les mêmes étapes : lorsque l'adresse IP dispose déjà d'un reverse, le champ **Nom d'hôte reverse DNS** s'ouvre prérempli avec celui-ci. Remplacez-le par la nouvelle valeur et cliquez sur <code className="action">Configurer</code>.

:::warning
Lorsque vous entrez votre nom de domaine dans le *reverse*, il vérifie immédiatement si l'enregistrement `A` / `AAAA` renvoie à la même IP. Ceci est utilisé dans les procédures anti-spam, donc votre enregistrement DNS doit être valide et propagé. Il y a certaines règles à suivre lors de la saisie du *reverse* :

 - Le *reverse* ne peut pas commencer par un `-`
 - Le *reverse* ne peut pas comporter plus de 63 caractères
 - Le *reverse* ne peut pas contenir de caractères majuscules
 - Le *reverse* peut se terminer par un `.` : la console OVHcloud accepte à la fois `domain.tld` et `domain.tld.`.

:::


:::info
Si la modification ne fonctionne pas comme prévu, vérifiez que l'enregistrement `A` / `AAAA` est correctement configuré dans la zone DNS de votre nom de domaine. L'application des changements dans la zone DNS peut prendre jusqu'à 24 heures, dans le cas où vous venez de modifier l'enregistrement.

Si le nom de domaine est géré par OVHcloud en tant que bureau d’enregistrement **et qu’il utilise les serveurs DNS OVHcloud**, vous pouvez consulter [ce guide](/guides/web-cloud/domains/dns-zone-edit).

:::
