## Objectif

Le Game Panel vous permet de déployer et de configurer un serveur vocal TeamSpeak 3 en quelques minutes, sans ligne de commande ni connaissance système.

**Ce guide vous explique comment déployer un serveur TeamSpeak 3 sur le Game Panel et vous y connecter.**

## Prérequis

- Un [VPS](/links/bare-metal/vps) ou un [serveur dédié](/links/bare-metal/bare-metal) dans votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Un client TeamSpeak 3 installé sur votre machine pour tester la connexion.

## En pratique

### Étape 1 — Accéder au Game Panel et sélectionner TeamSpeak 3

Depuis le tableau de bord de votre Game Panel, cliquez sur <code className="action">Add Game Server</code>. Dans la liste des jeux disponibles, recherchez et sélectionnez **TeamSpeak 3**.

<img className="thumbnail" alt="Sélection de TeamSpeak 3 dans la liste des jeux" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/select-teamspeak-3.png" loading="lazy" />

### Étape 2 — Configurer votre serveur

Une page de configuration s'ouvre. Les valeurs par défaut sont prêtes à l'emploi pour un lancement immédiat, mais vous pouvez les personnaliser selon vos besoins.

Parmi les paramètres disponibles, vous pouvez modifier :

- <code className="action">Server Name</code> : donnez un nom d'instance à votre serveur (par exemple, `My TS3 server`).
- <code className="action">Network Ports</code> : préconfigurés automatiquement :
    - `9987` (UDP) — voix
    - `10011` (TCP) — ServerQuery
    - `30033` (TCP) — transfert de fichiers

<img className="thumbnail" alt="Configuration des Network Ports pour TeamSpeak 3" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-network-ports.png" loading="lazy" />

:::info
Vous pouvez modifier ces paramètres, mais ce n'est pas obligatoire pour lancer le serveur.
:::


### Étape 3 — Lancer l'installation

Une fois la configuration vérifiée, cliquez sur <code className="action">Select</code> pour démarrer le déploiement.

<img className="thumbnail" alt="Formulaire de configuration de l'installation TeamSpeak 3 avec le bouton Select" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-install-form.png" loading="lazy" />

### Étape 4 — Suivre la progression de l'installation

Le déploiement démarre automatiquement. Laissez l'installation se poursuivre sans fermer la page.

Suivez le processus en temps réel en cliquant sur <code className="action">Log/Console</code> pour afficher les messages d'installation.

<img className="thumbnail" alt="Panneau des logs d'installation de TeamSpeak 3" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-installation-logs.png" loading="lazy" />

### Étape 5 — Vérifier que le serveur est en cours d'exécution

Une fois l'installation terminée, vérifiez que votre serveur affiche le statut **Running**.

<img className="thumbnail" alt="Serveur TeamSpeak 3 avec le statut Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-running.png" loading="lazy" />

Votre serveur est en ligne. Récupérez l'adresse IP et le port dans la section <code className="action">Connection</code> pour vous connecter depuis le client TeamSpeak 3.

### Étape 6 — Se connecter à votre serveur

Dans le client TeamSpeak 3 :

1. Cliquez sur <code className="action">Connections</code> > <code className="action">Connect</code>.
2. Saisissez l'adresse affichée dans la colonne **Connection** de la liste des Game Servers.
