## Objectif

Le Game Panel vous permet de déployer un serveur DayZ en quelques étapes. Le Game Panel gère l'installation, l'authentification Steam et la configuration des ports réseau.

**Ce guide vous explique comment déployer un serveur DayZ sur le Game Panel et vous y connecter.**

## Prérequis

- Un [VPS](https://www.ovhcloud.com/fr/vps/) sur votre compte OVHcloud avec la fonctionnalité Game Panel activée.
- Un accès au Game Panel. Consultez le guide [Se connecter au Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Un compte Steam pour authentifier l'installation du serveur DayZ.

## En pratique

### Étape 1 — Accéder au Game Panel

Connectez-vous à votre Game Panel.

Dans le menu de gauche, rendez-vous dans la section <code className="action">Game Servers</code> et cliquez sur <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Section Game Servers avec le bouton Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/add-game-server.png" loading="lazy" />

Sélectionnez **DayZ** dans la liste des jeux. Une fenêtre de configuration s'ouvre.

### Étape 2 — Configurer votre serveur

Dans la fenêtre de configuration :

- Saisissez un **Server Name**.
- Saisissez vos **Steam Username** et **Steam Password**.

:::warning
Il est fortement recommandé d'utiliser un compte Steam dédié à cet usage, et non votre compte personnel. Utilisez un mot de passe complexe et désactivez l'authentification à deux facteurs par e-mail (Steam Guard) sur ce compte avant de continuer.
:::


<img className="thumbnail" alt="Formulaire d'installation de DayZ affichant le nom du serveur et les champs d'identifiants Steam" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/install-dayz-form.png" loading="lazy" />

### Étape 3 — Configurer les ports réseau

Les ports UDP suivants sont préconfigurés dans le formulaire d'installation :

| Port | Usage |
|------|-------|
| 2302 | Game |
| 2304 | Steam |
| 2306 | BattlEye |
| 27016 | Query Steam |

:::info
S'il s'agit de votre premier serveur DayZ sur le Game Panel et que les ports par défaut sont disponibles, aucune modification manuelle n'est nécessaire.
:::


<img className="thumbnail" alt="Section des ports réseau avec les ports UDP DayZ préconfigurés" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/network-ports.png" loading="lazy" />

### Étape 4 — Lancer l'installation

Cliquez sur <code className="action">Select</code>. Le déploiement démarre automatiquement. Le Game Panel va :

1. Télécharger l'image du serveur DayZ.
2. Installer les fichiers du serveur.

Une fois l'installation terminée, cliquez sur <code className="action">Launch</code> pour démarrer votre serveur.

### Étape 5 — Vérifier que le serveur fonctionne

Vérifiez que le statut du serveur passe à **Running**. Une activité CPU et RAM doit être visible dans le Game Panel.

Les commandes suivantes sont disponibles :

- <code className="action">Log/Console</code> — suivez le démarrage et l'activité du serveur en temps réel, et consultez les logs en cas de problème.
- <code className="action">Settings</code> — accédez aux options de configuration du jeu.

<img className="thumbnail" alt="Serveur DayZ avec le statut Running et les contrôles de gestion" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/server-running.png" loading="lazy" />

### Étape 6 — Configurer les paramètres du jeu (facultatif)

Cliquez sur <code className="action">Settings</code> sur votre serveur, puis ouvrez <code className="action">Game Config</code> pour ajuster les options accessibles depuis le Game Panel, telles que les mises à jour automatiques.

Pour une configuration avancée, utilisez le **File Manager** afin de modifier directement le fichier de configuration du serveur DayZ.

<img className="thumbnail" alt="Panneau Server Settings avec les options Game Config et File Manager" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/game-config.png" loading="lazy" />

### Étape 7 — Se connecter à votre serveur

Dans la colonne **Connection** de la liste Game Servers, copiez l'adresse IP et le port de votre serveur.

Pour rejoindre depuis le client DayZ :

1. Lancez **DayZ**.
2. Allez dans **Servers** et cliquez sur **Direct Connect** en bas.
3. Saisissez votre adresse IP et le port (par exemple `192.168.1.1:2302`).
4. Cliquez sur **Connect**.

<img className="thumbnail" alt="Liste Game Servers avec l'adresse IP de connexion et le port mis en évidence" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/connection-details.png" loading="lazy" />
