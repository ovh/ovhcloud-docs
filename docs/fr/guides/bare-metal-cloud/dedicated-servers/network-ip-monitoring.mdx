## Objectif

Le service de monitoring permet de suivre l’état de votre machine et de déclencher automatiquement l’intervention d’un technicien dans le datacentre.

Tous les serveurs de nos clients ainsi que l'ensemble du réseau sont surveillés 24h/24 et 7j/7 par les équipes techniques d'OVHcloud.

OVHcloud intervient dès le déclenchement d'une alerte (non réponse aux pings) afin de limiter au maximum le temps d'indisponibilité des serveurs et du réseau.

Pour mettre en place un firewall restrictif, notamment sur l'ICMP, et continuer de bénéficier du monitoring OVHcloud, il est nécessaire d'autoriser les adresses IP que vous trouverez ci-après.

## Prérequis

- Un produit OVHcloud sur lequel vous avez installé un Firewall.
- Avoir accès aux règles du Firewall.

### Activer ou désactiver le monitoring <a name="enable"></a>

{/* CP-STEPS-START:server-monitoring */}

Vous pouvez activer ou désactiver le monitoring d’un serveur dédié à partir de l’onglet <code className="action">Serveur</code> de sa page. La ligne **Monitoring** de la section **Informations du serveur** indique son état actuel : **Désactivé**, **Activé avec intervention** ou **Activé sans intervention**.

Cliquez sur <code className="action">Configurer le monitoring</code>. Dans la fenêtre **Configurer le monitoring**, vous pouvez définir le comportement du monitoring :

- **Activer le monitoring** : désactivez cet interrupteur pour interrompre les messages d'alerte et les interventions d'OVHcloud. Choisissez cette option si vous exécutez sur le serveur des actions d'administration qui empêchent une réponse ICMP.
- **Mode d'intervention** (affiché lorsque le monitoring est activé) :
    - **Intervention proactive (OVHcloud agit si un problème est détecté)** : si le serveur ne répond plus, un e-mail d'alerte vous est envoyé et le serveur est vérifié par un technicien.
    - **Sans intervention (monitoring uniquement, aucune action)** : vous recevez un e-mail d'alerte si le serveur ne répond plus. Pour lancer une intervention, vous devez créer une demande d'assistance.

Cliquez sur <code className="action">Enregistrer</code> pour mettre à jour votre configuration du monitoring.
