## Objectif

Le RAID (Redundant Array of Independent Disks) est un ensemble de techniques qui atténuent la perte de données sur un serveur, en répliquant les informations sur plusieurs disques.

Le niveau de RAID par défaut des serveurs OVHcloud est le RAID 1\. Celui-ci double le volume occupé par vos données, réduisant ainsi l'espace disponible.

**Découvrez comment paramétrer les disques de votre serveur en RAID 0, afin d'exploiter le maximum d’espace utilisable.**

:::warning
Attention : le RAID 0 n’offre ni **tolérance aux pannes** ni **redondance des données**. Cela rend très probable la perte d’informations en cas de panne de disque.

:::


## Prérequis

- Disposer d’un [serveur dédié](/links/bare-metal/bare-metal) avec un RAID matériel.
- Avoir accès à votre serveur via SSH en tant qu’administrateur (sudo).

## En pratique

### Utiliser la console OVHcloud

{/* CP-STEPS-START:install-raid0 */}

Dans l'onglet <code className="action">Vue d'ensemble</code> de votre serveur, section **Informations générales**, cliquez sur <code className="action">Réinstaller</code> sur la ligne **Système d'exploitation**. La page **Installation / Réinstallation** s'ouvre.

À l'étape **Système d'exploitation**, sélectionnez le système d'exploitation à installer dans les listes déroulantes **Catégorie** et **Système d'exploitation**.

Cochez les cases <code className="action">Configurer le RAID matériel</code> et <code className="action">Personnaliser la configuration des partitions</code>, puis cliquez sur <code className="action">Suivant</code>. La case <code className="action">Configurer le RAID matériel</code> n'est proposée que si le groupe de disques sélectionné dispose d'un contrôleur RAID matériel.

À l'étape **RAID matériel**, sélectionnez <code className="action">RAID 0</code> dans la liste déroulante **Mode RAID**, choisissez le **Nombre de disques à configurer** et le **Nombre de tableaux**, puis cliquez sur <code className="action">Suivant</code>.

À l'étape **Partitions**, configurez les partitions selon vos besoins, puis cliquez sur <code className="action">Suivant</code>. Renseignez l'étape **Options** si nécessaire et cliquez sur <code className="action">Suivant</code>.

Enfin, à l'étape **Récapitulatif**, cochez la case <code className="action">Je comprends que toutes les données présentes sur les disques seront définitivement supprimées.</code> et cliquez sur <code className="action">Installer</code>.

{/* CP-STEPS-END:install-raid0 */}

Une fois votre serveur configuré, vérifiez la taille des partitions en vous y connectant via SSH et en exécutant la commande suivante :

```sh
df -h
```

### Utiliser le mode rescue

{/* CP-STEPS-START:boot-rescue */}

Dans l'onglet <code className="action">Vue d'ensemble</code> de votre serveur, section **Informations générales**, cliquez sur <code className="action">Mode rescue</code> sur la ligne **Mode de démarrage**. L'onglet **Serveur** s'ouvre sur le paramètre **Mode de démarrage** de la section **Système**.

Sélectionnez l'option <code className="action">Mode rescue</code>, puis choisissez <code className="action">Customer rescue system (Debian-12-based)</code> dans la liste déroulante **Noyau rescue**. Sous **Méthode d'authentification**, sélectionnez <code className="action">Mot de passe</code> pour recevoir les identifiants de connexion par e-mail.

Dans le champ **E-mail rescue**, indiquez une autre adresse e-mail si vous ne souhaitez pas que les identifiants de connexion soient envoyés à l'adresse principale de votre compte OVHcloud.

Cliquez sur <code className="action">Appliquer</code>. Dans la fenêtre **Appliquer le changement de mode de démarrage**, vérifiez le mode de démarrage actuel et le nouveau, puis cliquez sur <code className="action">Appliquer</code>.

Une fois la modification effectuée, redémarrez le serveur pour qu'il démarre en mode rescue : cliquez sur <code className="action">Redémarrer maintenant</code> dans la fenêtre **Redémarrer pour appliquer**. Si vous choisissez de redémarrer plus tard, cliquez sur le lien <code className="action">Redémarrer</code> sur la ligne **Mode de démarrage** de la section **Informations générales** (onglet **Vue d'ensemble**), puis sur <code className="action">Redémarrer</code> dans la fenêtre de confirmation.

{/* CP-STEPS-END:boot-rescue */}

Lorsque votre serveur redémarre, connectez-vous à ce dernier via SSH en utilisant vos identifiants du mode rescue. Ceux-ci vous ont été envoyés à l’adresse e-mail principale du compte ou dans le cas échéant, à l'adresse e-mail fournie précédemment.

Depuis la ligne de commande, tapez les commandes suivantes pour supprimer les paramètres RAID existants. Toutes les données du RAID seront supprimées :

```sh
MegaCli -CfgLdDel -L0 -a0
MegaCli -CfgLdDel -Lall -aAll
```

Entrez la commande suivante pour récupérer les identifiants d’emplacement de vos disques :

```sh
MegaCli -PdList -aALL | egrep "Slot|Device ID"
```

Entrez les commandes suivantes pour configurer le RAID 0 :

```sh
MegaCli -CfgLDAdd -R0[252:0,252:1] -a0
```

Dans cet exemple, 252 est l'identifiant du boîtier du disque.

Après avoir défini le nouveau niveau de RAID, vous pouvez vérifier les paramètres à l'aide de la commande suivante :

```sh
MegaCli -LDInfo -Lall -a0 | grep -i size
```
