## Objectif

Les tags sont des étiquettes attribuables à vos ressources, vous permettant de les organiser et de les gérer plus efficacement.

Chaque tag est constitué de deux parties :

- **La clé** : Représente un attribut ou une catégorie.
- **La valeur** : Correspond à l'information associée à cette clé.

Par exemple, vous pouvez catégoriser vos ressources par site, par service, ou encore par niveau de sécurité. L'utilisation des tags peut notamment faciliter la recherche, l'organisation de vos ressources, la gestion des coûts associés, ou encore l'application de stratégies avec la granularité souhaitée.

**Ce guide vous explique comment créer, attribuer et supprimer des tags pour chaque serveur dédié depuis la console OVHcloud.**

## Prérequis

- Disposer d’un [serveur dédié](/links/bare-metal/bare-metal).

[[cpnav:baremetal-dedicated-servers]]

## En pratique

### Attribuer un tag à un serveur dédié depuis la console OVHcloud


{/* CP-STEPS-START:assign-tag */}

Dans l'onglet **Vue d'ensemble** de votre serveur, la section **Tags** répertorie les tags déjà attribués. Cliquez sur <code className="action">Gérer mes tags</code>.

Vous êtes automatiquement redirigé vers la section **Tags** de l'onglet <code className="action">Serveur</code>. Vous pouvez aussi ouvrir directement l'onglet <code className="action">Serveur</code> et vous rendre dans sa section **Tags**.

Cliquez sur le bouton <code className="action">Assigner un tag</code>.

Dans le volet **Assigner un tag** qui s'ouvre, cliquez dans le champ **Sélectionnez ou saisissez une clé** pour ouvrir la liste déroulante, puis sélectionnez la clé souhaitée.

Cliquez ensuite dans le champ **Sélectionnez ou saisissez une valeur** et sélectionnez la valeur appropriée dans la liste déroulante.

:::warning
**Si vous souhaitez utiliser une clé ou une valeur qui n'existe pas encore**, vous pouvez la créer en la saisissant dans le champ, puis en cliquant sur <code className="action">Ajouter ce-texte</code>, où « ce-texte » correspond au texte que vous avez renseigné.

:::

Pour attribuer plusieurs tags à la fois, cliquez sur <code className="action">Ajouter une autre clé/valeur</code> et renseignez la nouvelle paire.

Enfin, cliquez sur le bouton <code className="action">Assigner</code> en bas du volet.

Un message de confirmation s'affiche, puis la liste des tags appliqués au serveur choisi apparaît dans la section **Tags**.

{/* CP-STEPS-END:assign-tag */}

### Supprimer un tag sur un serveur dédié

{/* CP-STEPS-START:delete-tag */}

Pour retrouver la liste des tags attribués à votre serveur :

1. Cliquez sur <code className="action">Serveurs dédiés</code> et sélectionnez votre serveur dans la liste.
1. Rendez-vous dans l'onglet <code className="action">Serveur</code>, puis dans sa section **Tags**.

Cochez la case du tag que vous souhaitez retirer de votre serveur. Seuls les tags dont le **Type de tag** est **Tag personnalisé** peuvent être sélectionnés.
Cliquez ensuite sur le bouton <code className="action">Actions</code> au-dessus du tableau et sélectionnez <code className="action">Désassigner</code>.

La fenêtre **Désassigner les tags** s'affiche. Cliquez sur le bouton <code className="action">Désassigner</code> pour désassigner le tag.

{/* CP-STEPS-END:delete-tag */}
