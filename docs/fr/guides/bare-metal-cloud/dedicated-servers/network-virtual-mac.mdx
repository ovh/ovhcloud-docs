## Objectif

OVHcloud vous permet d’associer une adresse MAC virtuelle à une adresse IP, afin de pouvoir mettre en place des machines virtuelles avec une configuration bridge sur votre serveur.

**Ce guide vous explique comment créer une adresse MAC virtuelle et comment l’associer à une adresse Additional IP.**

## Prérequis

- Posséder [un serveur dédié](/links/bare-metal/bare-metal) qui supporte les MAC virtuelles. Consultez [ce guide](/guides/bare-metal-cloud/dedicated-servers/network-support-virtual-mac) afin de le déterminer.
- Disposer d’une [adresse Additional IP](/links/network/additional-ip) ou un bloc d’Additional IP (RIPE).

:::warning
- Cette fonctionnalité peut être indisponible ou limitée sur les [serveurs dédiés **Eco**](/links/bare-metal/eco-about). Consultez notre [comparatif](/links/bare-metal/eco-compare) pour plus d’informations.

- Les serveurs Advance de troisième génération (équipés de processeurs EPYC 4004 Series) supportent 32 vMACs différentes.

- Depuis mai 2025, cette fonctionnalité est disponible sur les gammes Scale et High Grade.

:::


:::info
Si vous n'êtes pas familier avec l'utilisation de l'API OVHcloud, consultez notre guide « [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps) ».

:::

## En pratique

### Assigner une adresse MAC

:::warning
Si un bloc IP a été déplacé dans le vRack, il n’est plus assigné à un serveur physique à ce titre, il n’est plus possible d’assigner une MAC virtuelle à une IP.

:::


#### Via la console OVHcloud

{/* CP-STEPS-START:assign-vmac-cp */}

Dans le menu déroulant **Filtrer par service...**, sélectionnez <code className="action">Toutes les IP additionnelles</code>.

Repérez votre Additional IP (ou votre bloc) dans la liste et cliquez dessus pour ouvrir sa page, puis cliquez sur l'onglet <code className="action">MAC Virtuelle</code>. Pour un bloc, le menu déroulant **Afficher les MAC virtuelles pour** permet de choisir l'IP dont les MAC virtuelles sont affichées. Cliquez sur <code className="action">Ajouter une MAC virtuelle</code>.

Lorsque la fenêtre **Ajouter une MAC virtuelle** apparaît, sélectionnez l'adresse IP dans la liste **Adresse IP** (pour un bloc uniquement), sélectionnez un type dans la liste déroulante **Type**, entrez un nom de machine virtuelle, puis cliquez sur <code className="action">Ajouter</code>.

:::info
**Type** : il s'agit du type d’adresse MAC virtuelle (« vmware » sera une adresse MAC faite pour le système VMware ESXi tandis qu'« ovh » conviendra à tous les autres types de systèmes de virtualisation).

**Machine virtuelle** : il s'agit du nom souhaité pour l’adresse MAC virtuelle, pour retrouver ensuite plus facilement ce couple IP/MAC.

Si votre serveur dispose déjà d'adresses MAC virtuelles, la fenêtre vous permet de choisir entre **Créer une nouvelle MAC virtuelle** et **Utiliser une MAC virtuelle existante**. Avec la seconde option, sélectionnez l'adresse MAC à réutiliser au lieu d'un type.

:::

{/* CP-STEPS-END:assign-vmac-cp */}

:::info
N’oubliez pas d’assigner l’adresse MAC virtuelle créée lors de la configuration de votre machine virtuelle.

:::


#### Via l'API OVHcloud

Utilisez l'appel API suivant :

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/virtualMac"} />


### Supprimer une adresse MAC

:::warning
La suppression d'une adresse MAC est définitive, aucune récupération ultérieure ne sera possible.

:::


#### Via la console OVHcloud

{/* CP-STEPS-START:delete-vmac-cp */}

Sur la page **Adresses IP**, utilisez le menu déroulant **Filtrer par service...** ou la barre de recherche pour trouver l'Additional IP (ou le bloc IP), puis cliquez dessus pour ouvrir sa page et cliquez sur l'onglet <code className="action">MAC Virtuelle</code>. Pour un bloc, sélectionnez l'IP dans le menu déroulant **Afficher les MAC virtuelles pour**.

Chaque MAC virtuelle est affichée sous son adresse MAC. Cliquez sur <code className="action">Supprimer</code> sous la MAC virtuelle, puis sur <code className="action">Supprimer</code> dans la fenêtre **Supprimer la MAC virtuelle** pour confirmer.

{/* CP-STEPS-END:delete-vmac-cp */}

#### Via l'API OVHcloud

Utilisez l'appel API suivant :

<Api version="v1" section="/dedicated/server" method="DELETE" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


## FAQ

- **Que se passe-t-il si je déplace un bloc avec des vMACs sur un serveur Advance de troisième génération (équipé d'un processeur EPYC 4004 Series) possédant déjà 32 vMACs ?**

Le bloc ne sera pas déplacé.

Exemple : si vous tentez de déplacer un bloc de 4 IP avec des vMACs différentes attachées sur un serveur ayant déjà 30 vMACs le bloc ne sera pas déplacé car le total de vMACs serait supérieur aux 32 vMACs autorisées.
