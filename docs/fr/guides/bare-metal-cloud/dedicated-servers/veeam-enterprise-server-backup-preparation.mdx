## Objectif

La sauvegarde d’un serveur Bare Metal avec Veeam Enterprise implique plusieurs applications et services à utiliser ensemble. Le processus peut également changer en fonction de votre configuration et de vos préférences.

**Découvrez comment préparer la sauvegarde de votre serveur Bare Metal avec Veeam Backup and Replication (Enterprise).**

## Prérequis

- Un [serveur Bare Metal OVHcloud](/links/bare-metal/bare-metal)
- Une solution de sauvegarde [Veeam Enterprise](/links/hosted-private-cloud/veeam-enterprise)
- Un service [OVHcloud Object Storage](/links/public-cloud/object-storage) (facultatif)

[[cpnav:publiccloud-object-storage]]

## En pratique

### Installation de votre serveur dédié

Votre serveur Bare Metal OVHcloud doit être installé et configuré.

Consultez nos [guides de premiers pas pour les serveurs dédiés](/guides/bare-metal-cloud/dedicated-servers/getting-started-with-dedicated-server).

Vous pouvez également configurer votre serveur dédié pour utiliser un réseau privé en suivant les étapes de [ce guide](/guides/bare-metal-cloud/dedicated-servers/vrack-configuring-on-dedicated-server).

### Mise en place de votre serveur de backup Veeam Enterprise

Téléchargez, installez et créez une licence pour votre serveur de sauvegarde Veeam Enterprise à l'aide de notre guide « [Installer Veeam Backup & Replication](/guides/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication) ».

À partir de cette étape, vous pouvez continuer la lecture de ce guide pour apprendre à configurer Object Storage en tant que dépôt de sauvegarde ou vous pouvez passer directement à l'étape [Aller plus loin](#gofurther).

### Configuration de l’Object Storage

{/* CP-STEPS-START:object-storage-entry */}

La création et la configuration de l’Object Storage s’effectuent dans l’univers <code className="action">Public Cloud</code> de la <ManagerLink to="/">console OVHcloud</ManagerLink>, dans la section <code className="action">Object Storage</code> de votre projet Public Cloud.

{/* CP-STEPS-END:object-storage-entry */}

Si vous n'avez pas encore de projet Public Cloud dans votre compte OVHcloud, consultez notre guide [Créer votre premier projet Public Cloud](/guides/public-cloud/cross-functional/create-a-public-cloud-project).

[Créez un conteneur Object Storage](/guides/storage-and-backup/object-storage/s3-getting-started-with-object-storage) grâce à l’une des solutions **Object Storage (Standard ou High Performance)**. La solution Standard est recommandée car notre cas d'usage (effectuer une sauvegarde) ne nécessite généralement pas de stockage High Performance.

:::info
Lors de la commande d’un conteneur Object Storage auprès d’OVHcloud, sélectionnez uniquement l'**Object Storage Standard** ou l’**Object Storage High Performance**. Ces conteneurs prennent entièrement en charge le protocole Amazon S3<sup>1</sup> et sont conçus pour être utilisés comme dépôts de sauvegarde.

:::


Donnez à l'utilisateur Object Storage des droits sur le conteneur en copiant-collant le code ci-dessous dans un fichier JSON.

```json
{
  "Statement":[
    {
      "Action":
         [
             "s3:GetObject",
             "s3:PutObject",
             "s3:DeleteObject",
             "s3:ListBucket",
             "s3:ListMultipartUploadParts",
             "s3:ListBucketMultipartUploads",
             "s3:AbortMultipartUpload",
             "s3:GetBucketLocation"
          ],
      "Effect":"Allow",
      "Resource":
          [
              "arn:aws:s3:::<container name>",
              "arn:aws:s3::: :::<container name>/*"
          ],
      "Sid":"RWContainer"
     }
  ]
}
```

Veillez à remplacer `container name` par le nom réel de votre conteneur Object Storage.

{/* CP-STEPS-START:import-s3-policy */}

Dans l’onglet <code className="action">Utilisateurs</code> de la page **Object Storage**, cliquez sur le bouton <code className="action">⋮</code> dans la colonne **Actions** de l’utilisateur Object Storage et choisissez <code className="action">Importer une politique</code>.

Dans la fenêtre **Importer une politique**, sélectionnez le fichier JSON que vous venez de modifier et cliquez sur <code className="action">Importer</code>. La politique importée remplace la politique actuelle de l’utilisateur.

{/* CP-STEPS-END:import-s3-policy */}

### Configuration du repository Object Storage dans Veeam Enterprise

Depuis l'application Veeam, sélectionnez <code className="action">Backup Infrastructure</code>, <code className="action">Backup Repositories</code> et <code className="action">Add Repository</code>.

<img className="thumbnail" alt="Veeam - ajouter un référentiel" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-02.png" loading="lazy" />

Sélectionnez <code className="action">Object storage</code> comme type de dépôt.

<img className="thumbnail" alt="Veeam - Object Storage" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-03.png" loading="lazy" />

Sélectionnez <code className="action">S3 Compatible</code>.

<img className="thumbnail" alt="Veeam - compatible S3" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-04.png" loading="lazy" />

Attribuez un **Nom** au nouveau référentiel et cliquez sur <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - nom du dépôt" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-05.png" loading="lazy" />

Renseignez les informations **Service point** (Endpoint) et **Region** de votre service de stockage Object Storage.

{/* CP-STEPS-START:find-endpoint-region */}

> Vous pouvez retrouver ces informations dans l’univers <code className="action">Public Cloud</code> de la <ManagerLink to="/">console OVHcloud</ManagerLink>.
> Cliquez sur <code className="action">Object Storage</code> puis, dans l’onglet <code className="action">Conteneurs</code>, cliquez sur le nom de votre conteneur. La **Région** figure dans la section **Informations générales** de l’onglet <code className="action">Vue d'ensemble</code> (ainsi que dans la colonne **Région** de la liste des conteneurs), et le **Point d'accès** (Endpoint) dans la section **Détails de connexion**.

{/* CP-STEPS-END:find-endpoint-region */}

<img className="thumbnail" alt="Veeam - service endpoint and region" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-08.png" loading="lazy" />

Cliquez sur <code className="action">Add</code> pour entrer vos informations d'identification. Entrez votre **Access key** et votre **Secret key**, puis cliquez sur <code className="action">OK</code>.

{/* CP-STEPS-START:find-s3-credentials */}

> Ces informations sont disponibles dans la console OVHcloud, dans l’onglet <code className="action">Utilisateurs</code> de la page **Object Storage**. La **Clé d'accès** (Access key) figure dans la colonne **Clé d'accès** de la liste des utilisateurs.
> Pour obtenir la **Clé secrète** (Secret key), cliquez sur le bouton <code className="action">⋮</code> dans la colonne **Actions** de l’utilisateur et sélectionnez <code className="action">Afficher la clé secrète</code>. Elle s’affiche dans la fenêtre **Credentials S3**.

{/* CP-STEPS-END:find-s3-credentials */}

<img className="thumbnail" alt="Veeam - keys" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-10.png" loading="lazy" />

Cliquez sur <code className="action">Browse...</code> pour sélectionner le **Bucket**.

<img className="thumbnail" alt="Veeam - bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-11.png" loading="lazy" />

Sélectionnez le bucket et cliquez sur <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-12.png" loading="lazy" />

Cliquez sur <code className="action">Browse...</code> pour sélectionner le **Dossier** (Folder).

<img className="thumbnail" alt="Veeam - folder" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-13.png" loading="lazy" />

Cliquez sur <code className="action">New Folder</code>, entrez un nom pour le dossier, sélectionnez-le, puis cliquez sur <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - folder" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-14.png" loading="lazy" />

A l'étape de montage du serveur, cliquez sur <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - Mount Server" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-15.png" loading="lazy" />

Sur l'écran de récapitulatif, cliquez sur <code className="action">Apply</code>.

<img className="thumbnail" alt="Veeam - review" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-16.png" loading="lazy" />

Une fois les processus exécutés avec succès, cliquez sur <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - process end" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-17.png" loading="lazy" />

Passez en revue la page de résumé et cliquez sur <code className="action">Finish</code>.

<img className="thumbnail" alt="Veeam - summary" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-18.png" loading="lazy" />

Les dépôts de sauvegarde doivent maintenant ressembler à ceci :

<img className="thumbnail" alt="Veeam - dépôts" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-19.png" loading="lazy" />

Vous pouvez à présent effectuer une sauvegarde avec Veeam Enterprise.
