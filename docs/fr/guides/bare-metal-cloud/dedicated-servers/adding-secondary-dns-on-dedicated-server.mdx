## Objectif

Si vous configurez votre serveur dédié en tant que serveur DNS, vous pouvez utiliser le DNS OVHcloud secondaire pour héberger une zone secondaire. Ainsi, le DNS de votre domaine restera disponible même si le serveur DNS principal ne répond plus.

**Ce guide explique comment ajouter votre domaine dans la console OVHcloud afin d'utiliser un serveur DNS secondaire.**

## Prérequis

* Disposer d’un [serveur dédié](/links/bare-metal/bare-metal).
* Disposer d’un [nom de domaine](/links/web/domains) dont vous avez la gestion administrative ou technique.

:::warning
OVHcloud met à votre disposition des services dont la configuration, la gestion et la responsabilité vous incombent. Il vous revient de ce fait d'en assurer le bon fonctionnement.

Nous mettons à votre disposition ce guide afin de vous accompagner au mieux sur des tâches courantes. Néanmoins, nous vous recommandons de faire appel à un [prestataire spécialisé](/links/partner) si vous éprouvez des difficultés ou des doutes concernant l'administration, l'utilisation ou la mise en oeuvre des services sur un serveur.

:::

## En pratique

### Ajout d'un domaine <a name="addingdomain"></a>

{/* CP-STEPS-START:add-domain */}

Sur la page de votre serveur dédié, cliquez sur l'onglet <code className="action">Connectivité</code>. Dans la section **DNS**, sous **DNS secondaire**, cliquez sur <code className="action">Ajouter un domaine</code>.

Dans la fenêtre **Ajouter un DNS secondaire**, suivez les trois étapes :

1. Saisissez le domaine à ajouter dans le champ **Nom de domaine**, puis cliquez sur <code className="action">Suivant</code>.
2. Si vous le souhaitez, sélectionnez dans la liste déroulante **IP maître (optionnel)** l'adresse IP du serveur qui servira de maître. L'accès est autorisé par bloc d'IP. Cliquez sur <code className="action">Suivant</code>.
3. Vérifiez votre configuration, puis cliquez sur <code className="action">Ajouter</code>. Pour modifier une valeur avant de confirmer, cliquez sur <code className="action">Précédent</code>.

Une fois que vous avez cliqué sur <code className="action">Ajouter</code>, le domaine est ajouté au serveur DNS secondaire OVHcloud.

Les domaines ajoutés sont répertoriés sous **DNS secondaire**. La colonne **Serveur DNS** affiche le nom du serveur DNS secondaire à côté de chaque domaine. Pour supprimer un domaine, cliquez sur l'icône de corbeille dans la colonne **Actions** de sa ligne.

{/* CP-STEPS-END:add-domain */}

:::info
Les autres actions requises pour configurer votre propre DNS pour votre domaine sont généralement les suivantes:

- configuration d'un service DNS (tel que *BIND*)
- configuration des enregistrements GLUE
- autorisation des transferts de zone

Reportez-vous aux documentations externes appropriées si vous avez besoin d'informations supplémentaires pour compléter ces tâches administratives.

:::


### Vérification de l'autorisation pour le domaine <a name="verifyingdomain"></a>

{/* CP-STEPS-START:verify-domain */}

Il est nécessaire de confirmer votre autorisation à gérer le domaine concerné avant de pouvoir l'ajouter au DNS secondaire OVHcloud. Cela s'effectue via une recherche DNS automatisée sur le sous-domaine *ownercheck.votrenomdedomaine*. Une chaîne unique de caractères est générée à cette fin.

La fenêtre **Ajouter un DNS secondaire** de la console OVHcloud n'affiche pas cette valeur. Pour la récupérer, utilisez l'appel API suivant, en indiquant le nom interne du serveur (exemple : `ns3956771.ip-169-254-10.eu`) et le domaine dans le paramètre `domain` :

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/secondaryDnsNameDomainToken"} />

La réponse contient le type d'enregistrement (`TXT`), le sous-domaine (`ownercheck`) et la valeur à utiliser.

- Si le domaine est géré par un bureau d'enregistrement externe ou utilise des serveurs DNS externes, connectez-vous à l'interface de gestion de votre fournisseur DNS et ajoutez un enregistrement TXT avec le sous-domaine « ownercheck » et cette valeur.

- Si le domaine est géré par OVHcloud en tant que bureau d'enregistrement et qu'il utilise des serveurs DNS OVHcloud, suivez les instructions de [ce guide](/guides/web-cloud/domains/dns-zone-edit) pour ajouter l'enregistrement TXT dans la <ManagerLink to="/">console OVHcloud</ManagerLink>.

Après avoir correctement ajouté l'enregistrement TXT à la zone DNS du domaine, répétez les [étapes ci-dessus](#addingdomain) et terminez la procédure.

{/* CP-STEPS-END:verify-domain */}
