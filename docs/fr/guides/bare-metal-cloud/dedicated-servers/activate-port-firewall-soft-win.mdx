## Objectif

Pour protéger de manière optimale votre système, votre serveur sous Windows Server dispose de son propre pare-feu intégré. Son paramétrage vous permet  d’augmenter les niveaux de sécurité et de garantir ainsi la disponibilité et l’intégrité de tous les éléments hébergés sur le serveur, tels que les rôles, les services, les dossiers partagés.

**Ce guide vous explique comment appliquer les règles du pare-feu sous Windows.**

:::warning
OVHcloud met à votre disposition des services dont la responsabilité vous revient. En effet, n’ayant aucun accès à ces machines, nous n’en sommes pas les administrateurs et ne pourrons vous fournir d'assistance. Il vous appartient de ce fait d’en assurer la gestion logicielle et la sécurisation au quotidien.

Nous mettons à votre disposition ce guide afin de vous accompagner au mieux sur des tâches courantes. Néanmoins, nous vous recommandons de faire appel à un [prestataire spécialisé](/links/partner) et/ou d'échanger avec notre [communauté d'utilisateurs](/links/community) si vous éprouvez des difficultés ou avez des doutes concernant l’administration, l’utilisation ou la sécurisation d’un serveur. Plus d’informations dans la section « Aller plus loin » de ce guide.

:::


## Prérequis

- Disposer d’un [serveur dédié](/links/bare-metal/bare-metal) sous Windows dans votre compte OVHcloud.
- Disposer d'un accès administrateur à votre serveur via un bureau distant.

## En pratique

### Étape 1 : accéder au pare-feu Windows

Afin d’accéder au pare-feu Windows, vous pouvez suivre cet ordre :

- cliquez sur <code className="action">Démarrer</code>;
- cliquez sur <code className="action">Rechercher</code>;
- recherchez « Pare-feu Windows Defender » via la barre de recherche ;
- cliquez sur <code className="action">Pare-feu Windows Defender</code>.

Cliquez ensuite sur la ligne <code className="action">Configuration avancée</code>.

<img className="thumbnail" alt="Fenêtre du pare-feu Windows Defender avec le lien Configuration avancée" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step1.PNG" loading="lazy" />

### Étape 2 : activer une règle de trafic entrant

Dans la fenêtre affichée, vous trouverez des paramètres tels que :

- Règles d’entrée et de sortie
- Règles de sécurité de la connexion
- Options de surveillance du pare-feu du serveur

En sélectionnant les <code className="action">Règles de trafic entrant </code>, toutes les règles préconfigurées de Windows Server associées aux connexions réseau et aux paquets entrants s’affichent. Certaines de ces règles ne sont pas activées par défaut. Si vous souhaitez les activer, faites un clic-droit sur la règle et sélectionnez l’option <code className="action">Activer la règle </code>.

<img className="thumbnail" alt="Liste des règles entrantes avec option d'activation" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step2.PNG" loading="lazy" />

### Étape 3 : créer une nouvelle règle 

Pour créer une nouvelle règle, allez dans le menu <code className="action">Action</code> et sélectionnez <code className="action">Nouvelle règle</code>, ou cliquez sur <code className="action">Nouvelle règle</code> dans le panneau de droite.

<img className="thumbnail" alt="Menu Action de la console du pare-feu Windows Defender avec Nouvelle règle mis en évidence" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step3.PNG" loading="lazy" />

### Étape 4 : définir le type de règle à activer

L’assistant s’affiche pour définir le type de règle à créer. Sélectionnez l’option <code className="action">Port</code>.

<img className="thumbnail" alt="Page Type de règle de l’assistant Nouvelle règle de trafic entrant avec l’option Port sélectionnée" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step4.PNG" loading="lazy" />

### Étape 5 : définir le type de port à activer

À l'étape suivante, définissez le type de port à activer :

<img className="thumbnail" alt="Page Protocole et ports avec TCP et un port local spécifique sélectionnés" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step5.PNG" loading="lazy" />

:::info
- TCP (protocole de contrôle de transmission)

  C’est un protocole orienté connexion, c’est-à-dire qu’avec TCP, il sera possible de créer des connexions entre des hôtes afin d’envoyer des flux de données. Ce protocole garantit que les données sont livrées au destinataire sans erreur et dans le même ordre dans lequel elles ont été envoyées.

- UDP (User Datagram Protocol – Protocole de datagramme utilisateur)

  C’est un protocole non orienté vers la connexion. Son développement repose sur l’échange de datagrammes et facilite l’envoi de datagrammes à travers le réseau. Aucune connexion préalable avec la destination n’est nécessaire.

Vous pouvez également sélectionner l’option <code className="action">Tous les ports locaux</code> pour activer tous les ports TCP ou UDP sur un serveur non-sécurisé. Vous pouvez aussi sélectionner l’option <code className="action">Ports locaux spécifiques</code> pour déterminer quel port doit être autorisé. 

:::

### Étape 6 : autoriser ou bloquer la connexion

Pour définir l’action que cette règle va déclencher, les options suivantes sont disponibles. Sélectionnez celle qui vous convient.

- **Autoriser la connexion**. Cette option permet une communication complète via ce port.
- **Autoriser la connexion si elle est sécurisée**. Cette option permet aux données d’être transmises uniquement si la connexion est authentifiée via IPsec.
- **Bloquer la connexion**. Cette option empêche les données d’être acheminées via ce port.

Sélectionnez l’option <code className="action">Autoriser la connexion</code> et cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="Page Action de l’assistant avec l’option Autoriser la connexion sélectionnée" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step6.PNG" loading="lazy" />

### Étape 7 : définir le profil et le nom de la règle

Vous devez enfin choisir sur quels profils la règle doit s'appliquer, parmi les profils public, de domaine ou privé.
Vous pouvez tous les activer si vous le souhaitez.

<img className="thumbnail" alt="Page Profil de l’assistant avec les profils Domaine, Privé et Public cochés" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7.PNG" loading="lazy" />

Attribuez un nom et une description à la nouvelle règle (optionnel) afin de faciliter son utilisation :

<img className="thumbnail" alt="Page Nom de l’assistant avec le nom de la règle renseigné" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7-01.PNG" loading="lazy" />

Cliquez sur le bouton <code className="action">Terminer</code> pour terminer le processus et créer la nouvelle règle.

<img className="thumbnail" alt="Liste des règles de trafic entrant avec la nouvelle règle, activée" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7_02.PNG" loading="lazy" />

Par la suite, vous pouvez modifier les paramètres de la nouvelle règle créée.
