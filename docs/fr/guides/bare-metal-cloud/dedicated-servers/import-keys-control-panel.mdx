## Objectif

Les paires de clés sont utilisées pour authentifier les connexions SSH entre les hôtes, par exemple entre le client local de votre ordinateur et un serveur distant. Lors de la réinstallation d'un serveur dédié ou d'un VPS depuis la console OVHcloud, vous avez la possibilité d'ajouter une clé publique au système d'exploitation. Le stockage de clés SSH publiques dans la console facilite ce processus.

**Ce guide vous explique comment stocker vos clés SSH publiques dans la console OVHcloud.**

## Prérequis

- Un [serveur dédié](/links/bare-metal/bare-metal) ou un [VPS](/links/bare-metal/vps) dans votre compte OVHcloud

## En pratique

Si vous n'avez pas encore créé de paire de clés SSH, consultez d'abord nos guides :

- [Créer et utiliser des clés SSH](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutoriel - Comment utiliser PuTTY pour les connexions SSH et l'authentification](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

<img className="thumbnail" alt="Identity and Access Management group of the Console left menu, with the SSH keys entry" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/sidebar-iam-ssh-keys.png" loading="lazy" />

Dans le menu de gauche de la console OVHcloud, ouvrez **Gestion des identités et accès** et cliquez sur <code className="action">Clés SSH</code>.

<img className="thumbnail" alt="SSH keys page with the Add an SSH key button above the list of keys" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-button.png" loading="lazy" />

Ouvrez le menu <code className="action">Ajouter une clé SSH</code> au-dessus de la liste et sélectionnez <code className="action">Dédié</code>.

<img className="thumbnail" alt="Add an SSH key menu open, showing the Dedicated and Public Cloud options" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-menu.png" loading="lazy" />

Dans la fenêtre **Ajouter une clé SSH**, copiez l'intégralité de la chaîne de clé publique et collez-la dans le premier champ, **Clé publique**. Collez uniquement la clé publique (le contenu de votre fichier `.pub`), jamais la clé privée.  
Saisissez un nom pour la clé dans le deuxième champ, **Nom**, afin de la reconnaître (par exemple, le nom de votre ordinateur).

<img className="thumbnail" alt="Add an SSH key window with the Public key and Name fields and the Add button" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-dedicated-window.png" loading="lazy" />

Cliquez sur <code className="action">Ajouter</code>.

La clé sera désormais disponible lors de la réinstallation d'un serveur dédié ou d'un VPS dans la console OVHcloud.
