## Objectif

Les paires de clés sont utilisées pour authentifier les connexions SSH entre les hôtes, par exemple entre le client local de votre ordinateur et un serveur distant. Lors de la réinstallation d'un serveur dédié ou d'un VPS depuis la console OVHcloud, vous avez la possibilité d'ajouter une clé publique au système d'exploitation. Le stockage de clés SSH publiques dans la console OVHcloud facilite ce processus.

**Ce guide vous explique comment stocker vos clés SSH publiques dans la console OVHcloud.**

## Prérequis

- Un [serveur dédié](/links/bare-metal/bare-metal) ou un [VPS](/links/bare-metal/vps) dans votre compte OVHcloud

:::info

[Comment créer des clés SSH avec OpenSSH pour les instances Public Cloud](/guides/public-cloud/compute/creating-ssh-keys)

## En pratique

Si vous n'avez pas encore créé de paire de clés SSH, consultez d'abord nos guides :

- [Créer et utiliser des clés SSH](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutoriel - Comment utiliser PuTTY pour les connexions SSH et l'authentification](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

{/* CP-STEPS-START:add-ssh-key */}

Dans la console OVHcloud, ouvrez <code className="action">Gestion des identités et accès</code> et cliquez sur <code className="action">Clés SSH</code>. La page **Clés SSH** liste les clés enregistrées dans votre compte.

Cliquez sur <code className="action">Ajouter une clé SSH</code> et sélectionnez <code className="action">Dédié</code> dans le menu.

Dans la fenêtre **Ajouter une clé SSH**, copiez l'intégralité de la chaîne de clé publique et collez-la dans le champ **Clé publique**, puis saisissez un libellé pour la clé dans le champ **Nom**.

Cliquez sur <code className="action">Ajouter</code>.

La clé sera désormais disponible lors de la réinstallation d'un serveur dédié ou d'un VPS dans la console OVHcloud.

{/* CP-STEPS-END:add-ssh-key */}
