## Objectif

L'outil en ligne [Plik](https://plik.ovhcloud.com) permet de partager des fichiers entre différentes personnes, en offrant des options de sécurisation d'accès à ces fichiers.

**Découvrez comment utiliser l'outil en ligne Plik pour partager des fichiers.**

## Prérequis

- Disposer d'un [compte OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation)

## En pratique

### Se connecter avec votre compte OVHcloud

Pour téléverser des fichiers, vous devez vous connecter à Plik avec votre compte OVHcloud.

Connectez-vous à votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>.

:::info
Si vous avez activé la [double authentification](/guides/account-and-service-management/account-information/secure-ovhcloud-account-with-2fa) sur votre compte, vous devrez également saisir le code fourni par la méthode d'authentification que vous avez définie sur votre compte.
:::

Accédez au [site web de Plik](https://plik.ovhcloud.com).

Cliquez sur <code className="action">Authentication</code> en haut à droite.

Cliquez sur <code className="action">Login with OVH</code>.

![Page de connexion de Plik avec le bouton Login with OVH mis en évidence](/images/account-and-service-management/account-information/use-plik/plik01.png)

Cliquez sur <code className="action">Continuer</code>.

![Page OVHcloud indiquant le compte avec lequel vous êtes connecté](/images/account-and-service-management/account-information/use-plik/plik02.png)

Cliquez sur <code className="action">Autoriser</code>.

![Page d'autorisation OVHcloud demandant l'accès de Plik à votre compte](/images/account-and-service-management/account-information/use-plik/plik03.png)


### Téléverser des fichiers

Une fois connecté, cliquez sur le mot <code className="action">Plik</code> en haut à gauche pour accéder au menu d'ajout de fichiers.

Cliquez sur <code className="action">Add files</code> et sélectionnez le fichier à ajouter ou effectuez un « glisser-déposer » de vos fichiers.

:::info
La taille des fichiers est limitée à 10 Go.
:::


![Page de téléversement de Plik avec ses options et le bouton Add files](/images/account-and-service-management/account-information/use-plik/plik04.png)

Plusieurs options sont disponibles pour configurer vos téléversements :

- `Destruct after the first download` - Cette option supprimera votre fichier téléversé après le premier téléchargement.
- `Streaming` - Le fichier ne sera pas stocké sur le serveur. Au lieu de cela, le téléversement de fichier commence lorsque l'utilisateur distant commence le téléchargement.
- `Removable` - Permet aux utilisateurs finaux de supprimer le fichier téléversé.
- `Password` - Protégez votre téléversement en imposant un identifiant et un mot de passe que l'utilisateur distant devra renseigner.
- `Comments` - Ajoutez des commentaires à votre téléchargement. Le langage *markdown* est pris en charge.
- `Files will be automatically removed in` - Choisissez le nombre de jours (30 maximum), d'heures ou de minutes au bout desquels vous souhaitez que vos fichiers téléversés soient automatiquement supprimés.

:::info
Lorsque vous protégez votre téléversement avec un mot de passe, le nom d'utilisateur par défaut est « plik ».
:::


Après avoir ajouté vos fichiers et sélectionné les options souhaitées, cliquez sur le bouton <code className="action">Upload</code> vert sur le côté gauche. Cela ouvrira une nouvelle page avec vos fichiers joints.

![Page de téléversement de Plik avec un fichier ajouté et le bouton Upload](/images/account-and-service-management/account-information/use-plik/plik05.png)

Les options de téléchargement sont alors disponibles.

### Télécharger des fichiers

Sur la page de téléchargement, de nouvelles options sont disponibles :

- `Zip archive` - Place tous les fichiers que vous avez téléversés dans un dossier compressé.
- `Add files` - Vous permet d'ajouter d'autres fichiers.
- `Delete` - Supprime tous les fichiers préalablement téléversés.

Vous pouvez également supprimer des fichiers un par un en cliquant sur le bouton <code className="action">X</code> à droite de chaque fichier.

![Page de téléchargement de Plik avec le QR code, le lien et les options](/images/account-and-service-management/account-information/use-plik/plik06.png)

Pour permettre à d'autres personnes de télécharger vos fichiers, donnez-leur le lien vers le fichier individuel situé sous le nom du fichier.<br/>
Vous pouvez également leur donner le lien vers tous les fichiers de la session en leur partageant l'URL située dans la barre d'adresses de votre navigateur.<br/>
Vous pouvez aussi partager le QR code situé à gauche. Si vous avez téléversé plusieurs fichiers, le QR code permettra de télécharger chacun des fichiers.

### Options du compte

Cliquez sur votre identifiant en haut à droite pour accéder aux options du compte.

![Options du compte Plik avec la liste des téléversements et les boutons de gestion](/images/account-and-service-management/account-information/use-plik/plik07.png)

Via ce menu, vous pouvez vous déconnecter, générer des tokens pour utiliser l'outil Plik en ligne de commande, supprimer chaque téléversement (via le bouton <code className="action">Remove</code> situé à droite de chaque téléversement) ou les supprimer tous (via le bouton <code className="action">DELETE UPLOADS</code>).
