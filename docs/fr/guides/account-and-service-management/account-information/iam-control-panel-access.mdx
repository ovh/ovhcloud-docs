## Objectif

Ce guide explique comment fournir à un utilisateur les droits minimums lui permettant de se connecter à la console OVHcloud.

## Prérequis

- Disposer d'un [compte OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation)
- Savoir [gérer les utilisateurs du compte](/guides/account-and-service-management/account-information/ovhcloud-users-management)
- Savoir [comment configurer des politiques pour IAM](/guides/account-and-service-management/account-information/iam-policy-ui)

[[cpnav:iam-policies-console]]

## En pratique

Pour pouvoir se connecter à la console OVHcloud, un utilisateur doit disposer au moins de cet ensemble minimal de droits sur la ressource du compte :

- account:apiovh:me/get
- account:apiovh:me/supportLevel/get
- account:apiovh:me/certificates/get
- account:apiovh:me/tag/get

Grâce à ces droits, un utilisateur pourra se connecter à la console OVHcloud. Cependant, pour pouvoir effectuer des actions à l'intérieur de la console, des droits supplémentaires doivent être attribués via IAM.

### Via l'interface utilisateur

L'interface utilisateur permet de mettre en place une politique avec la configuration suivante. Depuis la page <ManagerLink to="/beta/#/iam/policies/my-policies">Mes politiques</ManagerLink>, cliquez sur <code className="action">Créer une politique</code>.

Dans la section **Identités**, ajoutez la ou les identités auxquelles vous souhaitez donner accès.

<img className="thumbnail" alt="Section Identités du formulaire de création de politique, avec l'onglet Utilisateurs sélectionné" src="/images/account-and-service-management/account-information/iam-control-panel-access/console/add_identities.png" loading="lazy" />

Dans la section **Types de produit**, sélectionnez <code className="action">Compte client OVHcloud</code> dans la liste déroulante **Types de produit**, puis sélectionnez votre compte dans la liste **Ressources**.

<img className="thumbnail" alt="Section Types de produit avec Compte client OVHcloud sélectionné et le compte dans Ressources" src="/images/account-and-service-management/account-information/iam-control-panel-access/console/account_ressourceType.png" loading="lazy" />

Ensuite, dans la section **Actions**, sélectionnez le groupe de permissions géré <code className="action">controlPanelAccess</code> dans la liste déroulante **Groupes de permissions gérés**.

<img className="thumbnail" alt="Section Actions avec controlPanelAccess sélectionné dans Groupes de permissions gérés" src="/images/account-and-service-management/account-information/iam-control-panel-access/console/controlPanelAccess.png" loading="lazy" />

Vous pouvez aussi ajouter les 4 droits listés ci-dessus en tant qu'actions : cochez chacun d'eux dans la catégorie **READ** de la liste d'actions **account**, ou saisissez-les un par un dans le champ **Ajouter des actions manuellement** en cliquant à chaque fois sur <code className="action">Ajouter</code>.

<img className="thumbnail" alt="Liste d'actions account de la section Actions, avec 4 actions sélectionnées" src="/images/account-and-service-management/account-information/iam-control-panel-access/console/add_actions.png" loading="lazy" />

Dans le panneau **Récapitulatif**, cliquez sur <code className="action">Créer une politique</code>.

Vous pouvez maintenant associer vos utilisateurs à cette politique pour leur donner le droit de se connecter à la console OVHcloud.

### Via l'API

L'API vous permet de mettre en place une policy selon l'exemple suivant :

```json
{
  "name": "manager_ro",
  "description": "manager_ro",
  "identities": [
    .... 
  ],
  "resources": [ 
     {
         "urn": "urn:v1:eu:resource:account:xx1111-ovh" 
     }],
  "permissions": {
    "allow": [
      {
        "action": "account:apiovh:me/get"
      },
      {
        "action": "account:apiovh:me/supportLevel/get"
      },
      {
        "action": "account:apiovh:me/certificates/get"
      },
      {
        "action": "account:apiovh:me/tag/get"
      }
    ]
  }
}
```
