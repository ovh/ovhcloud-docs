## Objectif

OVHcloud met à votre disposition des options pour renforcer la sécurité de votre compte client et de vos services.

Vous pouvez notamment restreindre à certaines adresses IP l'accès à la <ManagerLink to="/beta/#/">console OVHcloud</ManagerLink>.
La mise en place de cette option, couplée à la sécurisation de votre compte par une [double authentification](/guides/account-and-service-management/account-information/secure-ovhcloud-account-with-2fa), permet de sécuriser de manière optimale l'accès à la console OVHcloud contre d'éventuelles tentatives d'intrusion.

**Découvrez comment sécuriser votre compte OVHcloud en limitant les adresses IP autorisées à y accéder**

:::warning
La restriction d'accès par IP et/ou la double authentification ne sécurisent que l'accès à la console OVHcloud depuis laquelle vous pouvez commander, gérer, renouveler ou supprimer vos services OVHcloud. Ces options ne sécurisent pas vos services en eux-mêmes, pour lesquels vous devez mettre en place des mesures de sécurité spécifiques.

:::


## Prérequis

- Avoir pris connaissance des [recommandations sur la gestion du mot de passe d'accès à votre compte](/guides/account-and-service-management/account-information/manage-ovh-password).

## En pratique

### Étape 1 - Récupérer les adresses IP publiques autorisées à accéder à la console OVHcloud

Il existe deux types d'adresses IP :

- **Les adresses IP publiques** : elles sont visibles sur l'ensemble du réseau Internet. Celles-ci sont par exemple utilisées par votre point d'accès/box Internet afin que vous ayez une adresse sur Internet pour accéder à l'ensemble du réseau.
- **Les adresses IP privées** : invisibles et inutilisables sur le réseau Internet, elles sont allouées dans un réseau local. Pour reprendre notre exemple, votre box Internet va allouer une adresse IP privée à chacun des appareils (ordinateurs, smartphones, tablettes, ...) connectés à celle-ci. Votre point d'accès/box Internet permet ainsi à ces appareils d'utiliser son IP publique pour accéder à Internet. Ces adresses IP sont faciles à reconnaître car elles commencent généralement par 10.0.X.X, 172.16.X.X ou 192.168.X.X (où les X sont des valeurs comprises entre 0 et 255).

Pour utiliser l'option de restriction par IP de la console OVHcloud, vous devrez renseigner **uniquement** votre/vos adresse(s) IP publique(s).

Pour récupérer l'adresse IP publique d'un appareil qui sera autorisé à accéder à la console OVHcloud, rendez-vous sur le site [mon-ip.com](https://mon-ip.com) (non géré par OVHcloud).

Prenez note de l'adresse IP qui s'affiche puis répétez l'opération pour chacun des appareils qui sera autorisé à accéder à la console OVHcloud.

Si vous utilisez un réseau 4G/5G en complément, n'oubliez pas de récupérer également l'adresse IP de ce(s) réseau(x).

:::warning
La plupart des Fournisseurs d'Accès à Internet (FAI) allouent une adresse IP **dynamique** à votre point d'accès Internet/box. Ces adresses IP dynamiques changent au redémarrage de votre box ou toutes les 24/48 heures. Néanmoins, certains FAI peuvent vous allouer des adresses IP **fixes** sur demande.

Pour une connexion en 3G/4G/5G, les adresses IP sont systématiquement **dynamiques**.

**Avant** de mettre en place une restriction par IP sur la console OVHcloud, vérifiez auprès de votre FAI que les adresses IP récupérées précédemment sont bien des adresses IP **fixes**. Dans le cas contraire, vous risqueriez de perdre rapidement l'accès à la console OVHcloud en déclarant une IP dynamique.

:::


### Étape 2 - Mettre en place une restriction d'accès par IP

Rendez-vous dans l'onglet <ManagerLink to="/beta/#/customer/account/security-and-login/ip-restrictions">Restrictions IP</ManagerLink> de la page **Sécurité et connexion**. Vous pouvez également y accéder depuis le menu latéral : ouvrez <code className="action">Mon compte</code> > <code className="action">Sécurité et connexion</code>, puis cliquez sur l'onglet <code className="action">Restrictions IP</code>.

<img className="thumbnail" alt="Entrée Sécurité et connexion du menu latéral et onglet Restrictions IP" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/security-login-ip-tab.png" loading="lazy" />

#### Présentation de l'interface

<img className="thumbnail" alt="Sections Règle par défaut et IP configurées de l'onglet Restrictions IP" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/ip-restrictions-overview.png" loading="lazy" />

Deux sections sont présentes pour la mise en place des restrictions par IP :

- **Règle par défaut**. Le champ **Quand l'IP n'est pas dans la liste** permet de :
    - soit refuser l'accès à l'ensemble des adresses IP à l'exception de celles déclarées comme **autorisées** dans la seconde section, **IP configurées**.
    - soit autoriser l'accès à l'ensemble des adresses IP à l'exception de celles déclarées comme **refusées** dans la seconde section, **IP configurées**.
    > Cochez la case **M'alerter par e-mail** si vous voulez être notifié par e-mail, sur votre adresse e-mail de contact, lorsqu'une tentative de connexion non autorisée est effectuée pour accéder à la console OVHcloud.

- **IP configurées**. Cette section permet de déclarer les adresses IP qui feront l'objet d'une restriction ou d'une autorisation d'accès. Elle permet aussi de visualiser les règles préalablement mises en place.

:::danger
Attention avant de poursuivre vos actions.

Dans la section **Règle par défaut**, n'enregistrez **jamais** la règle par défaut avec <code className="action">Refuser l'accès</code> sélectionné **sans avoir autorisé au préalable** au moins une de vos adresses IP publiques dans la section **IP configurées**.

Dans le cas contraire, vous bloquerez **absolument toutes les IP publiques (y compris les vôtres)** sans aucune exception. Plus personne n'aura accès à la <ManagerLink to="/beta/#/">console OVHcloud</ManagerLink> et vous devrez réaliser une procédure administrative pour débloquer votre situation.

Tant qu'aucune adresse IP n'est autorisée, la console OVHcloud ne vous permet pas d'enregistrer cette règle par défaut. Assurez-vous que les adresses autorisées incluent la vôtre.

Soyez donc extrêmement vigilant sur ce point.

:::


#### Refuser toutes les adresses IP à l'exception des adresses légitimes

Pour n'autoriser l'accès à la console OVHcloud qu'à une ou plusieurs adresse(s) IP légitimes, cliquez sur le bouton <code className="action">Ajouter une IP</code> dans la section **IP configurées**.

> Dans les captures d'écran qui vont suivre, l'IP **203.0.113.1/24** sera à remplacer par une IP qui vous concerne.

<img className="thumbnail" alt="Fenêtre Ajouter une IP avec la règle Autoriser l'accès sélectionnée" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/add-an-ip-allow.png" loading="lazy" />

Dans la fenêtre **Ajouter une IP**, renseignez l'adresse IP publique que vous souhaitez autoriser dans le champ **Adresse IP** (une adresse IPv4 ou IPv6, seule ou sous forme de bloc). Cochez la case **M'alerter par e-mail** si vous souhaitez être notifié par e-mail des tentatives de connexion via cette adresse IP, puis laissez la **Règle** sur <code className="action">Autoriser l'accès</code>.

Cliquez sur <code className="action">Ajouter</code>. La règle devrait alors apparaître dans la section **IP configurées**.

:::info
**Avant** de poursuivre les actions décrites dans cette étape, répétez l'opération ci-dessus pour toutes les autres éventuelles adresses IP que vous souhaitez autoriser à accéder à la console OVHcloud.

:::


Une fois **l'ensemble** de vos adresses IP publiques renseignées dans la section **IP configurées**, sélectionnez <code className="action">Refuser l'accès</code> dans le champ **Quand l'IP n'est pas dans la liste** de la section **Règle par défaut**. Cochez la case **M'alerter par e-mail** si vous souhaitez être notifié par e-mail des tentatives de connexion, puis cliquez sur <code className="action">Enregistrer</code>.

> Désormais, **seules** les adresses IP publiques préalablement autorisées dans la section **IP configurées** peuvent accéder à la console OVHcloud.

#### Autoriser toutes les adresses IP à l'exception de certaines adresses

Depuis l'onglet **Restrictions IP**, vous pouvez aussi autoriser toutes les adresses IP à accéder à la console OVHcloud, à l'exception de quelques-unes que vous aurez préalablement identifiées comme illégitimes.

Pour bloquer l'accès à la console OVHcloud à une ou plusieurs adresse(s) IP, cliquez sur le bouton <code className="action">Ajouter une IP</code> dans la section **IP configurées**.

<img className="thumbnail" alt="Fenêtre Ajouter une IP avec une adresse IP saisie et la règle Refuser l'accès" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/add-an-ip-deny.png" loading="lazy" />

Dans la fenêtre **Ajouter une IP**, renseignez l'adresse IP publique que vous souhaitez bloquer dans le champ **Adresse IP** (une adresse IPv4 ou IPv6, seule ou sous forme de bloc). Cochez la case **M'alerter par e-mail** si vous souhaitez être notifié par e-mail des tentatives de connexion via cette adresse IP, puis passez la **Règle** sur <code className="action">Refuser l'accès</code>.

Cliquez sur <code className="action">Ajouter</code>. La règle devrait alors apparaître dans la section **IP configurées**.

:::info
**Avant** de poursuivre les actions décrites dans cette étape, répétez l'opération pour toutes les autres éventuelles adresses IP dont vous souhaitez bloquer l'accès à la console OVHcloud.

:::


Une fois l'ensemble des adresses IP publiques renseignées dans la section **IP configurées**, sélectionnez <code className="action">Autoriser l'accès</code> dans le champ **Quand l'IP n'est pas dans la liste** de la section **Règle par défaut**. Cochez la case **M'alerter par e-mail** si vous souhaitez être notifié par e-mail des tentatives de connexion, puis cliquez sur <code className="action">Enregistrer</code>.

> Désormais, **toutes** les adresses IP publiques peuvent accéder à la console OVHcloud, **à l'exception de** celles déclarées dans la section **IP configurées**.
