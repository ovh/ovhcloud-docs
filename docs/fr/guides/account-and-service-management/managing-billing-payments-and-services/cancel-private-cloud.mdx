## Objectif

Si votre offre Private Cloud ne vous convient plus, ou que vous avez commandé une nouvelle infrastructure pour remplacer l'ancienne, vous pouvez demander la résiliation de cette infrastructure, une fois toutes vos données récupérées.

**Découvrez comment demander la résiliation d'une offre Private Cloud** 

## Prérequis

- Posséder un produit [Private Cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/).

[[cpnav:privatecloud-vmware-vsphere-console]]

## En pratique

L'offre Private Cloud est sans engagement. Cependant, comme indiqué dans les [Conditions Particulières du Service](https://www.ovh.com/fr/support/documents_legaux/conditions_particulieres_dedicated_cloud_2014.pdf), tout mois commencé est dû et payable d’avance.

:::warning
Avant de résilier votre offre, veuillez prendre garde à récupérer toutes les données que vous souhaitez conserver. En effet, la résiliation entraînera la suppression intégrale de votre Private Cloud et toutes les données qu'il contient.

:::

### Étape 1 : demander la résiliation depuis la console OVHcloud

Dans l'onglet **Tableau de bord** de votre service, cliquez sur <code className="action">Résilier le service</code> en bas de la section **Abonnement**.

<img className="thumbnail" alt="Onglet Tableau de bord avec le lien Résilier le service dans la section Abonnement" src="/images/account-and-service-management/managing-billing-payments-and-services/cancel-private-cloud/console/dashboard-subscription-cancel.png" loading="lazy" />

> Pour les offres Private Cloud antérieures, la demande de résiliation se fait de la manière suivante : 
>
> Toujours dans l'onglet <code className="action">Informations Générales</code>, cliquez sur le bouton <code className="action">...</code> à droite du nom de votre Private Cloud dans le tableau « Informations Générales ». Cliquez ensuite sur <code className="action">Supprimer mon service</code>.
>
> <img className="thumbnail" alt="resiliation depuis l'espace client" src="/images/account-and-service-management/managing-billing-payments-and-services/cancel-private-cloud/resiliation1bis.png" loading="lazy" />
>

Prenez alors connaissance du fait que cette action supprimera toute donnée présente sur l'infrastructure dès la confirmation de la résiliation. Aucun remboursement au prorata ne sera effectué si l'infrastructure est résiliée avant la fin du mois.

Dans la fenêtre **Résilier mon service** qui s'ouvre, cliquez sur <code className="action">Valider</code> pour demander la résiliation.

<img className="thumbnail" alt="Fenêtre Résilier mon service, avec son avertissement et le bouton Valider" src="/images/account-and-service-management/managing-billing-payments-and-services/cancel-private-cloud/console/terminate-my-service-dialog.png" loading="lazy" />

Une notification de confirmation de votre demande vous sera alors présentée. La procédure de confirmation de la résiliation vous est envoyée par e-mail, à l'adresse liée au compte OVHcloud.

### Étape 2 : confirmer la résiliation

Suite à votre demande, un e-mail de confirmation de résiliation vous est envoyé à l'adresse liée au compte OVHcloud. 

Vous pouvez également retrouver cet e-mail dans la console OVHcloud. Cliquez sur le bouton affichant vos initiales en haut à droite, puis sur <code className="action">Mes communications</code> dans la liste **Accès rapide**.

<img className="thumbnail" alt="Menu du compte de la console OVHcloud, avec Mes communications dans la liste Accès rapide" src="/images/assets/screens/console/product-selection/right-menu/my-messages.png" loading="lazy" />

L'objet de l'e-mail est :

> **Suppression de votre Private Cloud pcc-xxx-xxx-xxx-xxx**".

L'e-mail contient un lien cliquable qui vous permettra de confirmer la résiliation de votre offre.

:::info
Attention, ce lien est valable pendant **72 heures**. Nous vous conseillons donc de formuler votre demande de résiliation à partir du 25 du mois.

:::

Vous pouvez également valider la demande de résiliation via l'API OVHcloud suivante :

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/confirmTermination"} />

Vous devrez alors renseigner le token de validation disponible dans l'e-mail de confirmation de résiliation.
