## Objectif

Dans le cadre de vos activités professionnelles ou par intérêt sur le sujet, vous pouvez être amené à devoir calculer l'empreinte carbone de vos services.

**Découvrez comment récupérer mensuellement l'empreinte carbone de vos services OVHcloud.**

## Prérequis

- Être contact « Facturation » des services pour lesquels vous souhaitez obtenir l'empreinte carbone. Pour plus d'informations, consultez [notre guide sur la gestion des contacts](/guides/account-and-service-management/account-information/managing-contacts).

[[cpnav:account-dashboard]]

**Le calcul de l'empreinte carbone est disponible pour les services suivants :**

- [Serveur Dédié](https://www.ovhcloud.com/fr/bare-metal/) (Advance, Game, Scale, High Grade, Storage)
- [Serveur Dédié Eco](https://eco.ovhcloud.com/fr/) (Rise, Kimsufi, So you Start)
- [VMware on OVHcloud](https://www.ovhcloud.com/fr/hosted-private-cloud/vmware/)
- [Public Cloud](https://www.ovhcloud.com/fr/public-cloud/)

## En pratique

:::info
Les données d’empreinte carbone ne sont pas encore disponibles pour les architectures 3AZ et les Local Zones.

:::

Plusieurs points sont à prendre en compte :

- Vous ne pouvez pas générer de bilan pour le mois en cours.
- Quelles que soient les dates saisies via l'API OVHcloud (début, milieu ou fin de mois), le bilan prend toujours en compte des mois complets.
- Aucun bilan ne peut être généré au-delà des 24 derniers mois.
- Aucun bilan ne peut être généré pour la période précédant la date de mise en place de la fonctionnalité pour chaque service OVHcloud (voir le tableau ci-dessous).

### Récupérer le bilan mensuel du mois précédent via l'espace client OVHcloud

1. Sur le <ManagerLink to="/#/account/useraccount/dashboard">Mon compte</ManagerLink>, dans la colonne de gauche, descendez jusqu'à la section contenant les **Liens utiles**, puis cliquez sur l'onglet <code className="action">Mon bilan carbone</code>.
1. Sur la nouvelle page qui apparaît, cliquez sur <code className="action">Télécharger mon empreinte de [Mois] [Année]</code>.

<img className="thumbnail" alt="Carbon footprint" src="/images/assets/screens/control-panel/product-selection/right-column/carbon-footprint/my-carbon-footprint.png" loading="lazy" />

Vous pourrez récupérer chaque mois l'empreinte carbone du mois précédent pour vos services éligibles.

Si vous avez besoin de l'empreinte carbone pour un mois antérieur au mois précédant le mois en cours, ou d'un bilan couvrant plusieurs mois, vous devrez obligatoirement passer par nos API pour le récupérer.

### Récupérer un bilan antérieur au mois précédent via nos API

Par défaut, les API OVHcloud sont mises à disposition pour permettre aux développeurs ou aux intégrateurs d'associer, par exemple, des fonctionnalités présentes ou non dans l'espace client OVHcloud directement dans leurs applications ou solutions.

#### Étape 1 - Se connecter à l'API OVHcloud

- Rendez-vous sur notre site <ApiLink>API OVHcloud</ApiLink> (vérifiez bien que vous êtes sur `https://api.eu.ovhcloud.com` si vos services sont hébergés en Europe et sur `https://api.ca.ovhcloud.com` s'ils sont hébergés en dehors de l'Europe).
- Sur la page qui s'affiche, cliquez sur <code className="action">Explore the OVHcloud API</code>.
- Sur la nouvelle page qui apparaît et dans la partie gauche de la page, positionnez-vous sur le formulaire situé à droite du champ <code className="action">v1</code>, puis sélectionnez/saisissez le choix `/me`.
- Parmi la liste d'appels API qui apparaît en dessous, recherchez et cliquez sur l'appel API correspondant au format souhaité : **POST /me/carbonCalculator/pdf** pour un bilan au format PDF, ou **POST /me/carbonCalculator/csv** pour un bilan au format CSV. Vous pouvez aussi cliquer directement sur l'un des appels API ci-dessous pour y accéder :

<Api version="v1" section="/me" method="POST" route={"/me/carbonCalculator/pdf"} />

<Api version="v1" section="/me" method="POST" route={"/me/carbonCalculator/csv"} />

- Sur la partie droite de la page s'affiche alors l'API avec son encadré à compléter.
- Cliquez sur le bouton situé en haut à droite intitulé <code className="action">Authenticate</code>, puis sur le bouton <code className="action">Login with OVHcloud SSO</code>.
- La page de connexion de l'<ManagerLink to="/#/account/useraccount/dashboard">espace client OVHcloud</ManagerLink> s'ouvre.
- Connectez-vous avec votre identifiant client, puis cliquez sur <code className="action">Authorize</code> pour utiliser les API OVHcloud avec vos services.
- Vous êtes ensuite automatiquement redirigé vers la page précédente de l'appel API choisi.

#### Étape 2 - Demander la génération du bilan et récupérer l'ID de la tâche demandée

Deux appels API sont disponibles, selon le format de bilan souhaité. Le `taskID` obtenu à cette étape produira un PDF ou un CSV selon l'appel choisi à l'étape 1. Sélectionnez l'onglet correspondant.

<Tabs>
  <Tab label="Format PDF">
    L'appel API **POST /me/carbonCalculator/pdf** génère un bilan portant sur un seul mois.

    Remplacez la date du jour qui apparaît dans l'encadré de l'API par une date du mois pour lequel vous souhaitez obtenir le bilan. Veuillez respecter le format de date suivant :

    ```bash
    {
      "month": "YYYY-MM-DD"
    }
    ```

    Le jour saisi n'a pas d'importance : quel qu'il soit, le bilan prend en compte le mois complet. Le mois demandé ne peut pas être le mois en cours, ni remonter au-delà des 24 derniers mois.

    <img className="thumbnail" alt="API" src="/images/assets/screens/api/post-me-carboncalculator-pdf.png" loading="lazy" />

    Une fois la date choisie et correctement saisie, cliquez sur le bouton bleu <code className="action">EXECUTE</code> situé en bas à droite de la section préalablement remplie.
  </Tab>
  <Tab label="Format CSV">
    L'appel API **POST /me/carbonCalculator/csv** génère un bilan portant sur une plage de mois.

    Remplacez les deux dates qui apparaissent dans l'encadré de l'API par le mois de début et le mois de fin du calcul. Veuillez respecter le format de date suivant :

    ```bash
    {
      "endMonth": "YYYY-MM-DD",
      "startMonth": "YYYY-MM-DD"
    }
    ```

    Le jour saisi n'a pas d'importance : quel qu'il soit, le bilan prend en compte des mois complets, avec un mois au minimum. La date de fin (`endMonth`) doit être postérieure à la date de début (`startMonth`), et la date de début ne peut pas remonter au-delà des 24 derniers mois.

    <img className="thumbnail" alt="API" src="/images/assets/screens/api/post-me-carboncalculator-csv.png" loading="lazy" />

    Une fois les deux dates correctement saisies, cliquez sur le bouton bleu <code className="action">EXECUTE</code> situé en bas à droite de la section préalablement remplie.
  </Tab>
</Tabs>

Quel que soit l'appel utilisé, si tout a été effectué correctement, un `taskID` apparaît dans la fenêtre <code className="action">RESPONSE</code> lorsque vous descendez sur la page, en dessous du bouton <code className="action">EXECUTE</code>.

Par exemple, si votre identifiant client OVHcloud est `aa00000-ovh` et que vous avez demandé un bilan au format PDF pour le mois de janvier 2025, alors vous obtiendrez le résultat suivant :

```bash
{
  "taskID": "aa00000-ovh_202501"
}
```

Copiez uniquement la valeur obtenue de votre côté et équivalente à la valeur de notre exemple `aa00000-ovh_202501` (sans copier les deux `"` situés aux extrémités).

#### Étape 3 - Récupérer le fichier contenant le bilan carbone de vos services au format PDF ou CSV

Grâce à la valeur du `taskID` précédemment récupérée (via l'appel PDF ou via l'appel CSV), vous pourrez récupérer le bilan carbone de vos services.

Restez sur notre site <ApiLink>API OVHcloud</ApiLink> et effectuez les actions suivantes :

- Dans la partie gauche de la page, positionnez-vous sur le formulaire situé à droite du formulaire <code className="action">v1</code>, puis sélectionnez/saisissez le choix <code className="action">/me</code>.
- Parmi la liste d'appels API qui apparaît en dessous, recherchez et cliquez sur l'appel API suivant : **GET /me/carbonCalculator/task/&#123;taskID&#125;**. Vous pouvez aussi cliquer directement sur l'appel API ci-dessous pour y accéder :

<Api version="v1" section="/me" method="GET" route={"/me/carbonCalculator/task/\{taskID\}"} />

- Sur la partie droite de la page s'affiche alors l'appel API avec un formulaire à remplir.

Remplissez le formulaire de la partie `PATH PARAMETERS` ainsi :

- `taskID` : copiez ici la valeur du `taskID` récupérée lors de l'étape 2, quel que soit le format demandé.

<img className="thumbnail" alt="API" src="/images/assets/screens/api/get-me-carboncalculator-task-taskid.png" loading="lazy" />

Une fois la valeur de votre `taskID` correctement saisie, cliquez sur le bouton bleu <code className="action">EXECUTE</code>.

Le résultat suivant apparaît dans la fenêtre <code className="action">RESPONSE</code> lorsque vous descendez sur la page, en dessous du bouton <code className="action">EXECUTE</code> :

```bash
{
  "link": "Find here the complete URL to download the carbon footprint",
  "status": "SUCCESS",
  "taskID": "aa00000-ovh_202501"
}
```

Dans ce résultat, copiez l'intégralité de l'URL en HTTPS (**sans les guillemets**) présente à droite de la mention `"link":`, puis collez-la dans la barre d'adresse de votre navigateur Internet pour initier le téléchargement du bilan carbone au format demandé.

Votre navigateur Internet télécharge automatiquement le fichier et peut l'afficher directement dans le cas d'un bilan au format PDF.

:::info
En fonction de la configuration de votre navigateur, le téléchargement et l'affichage du fichier peut se retrouver bloqué. Si tel est le cas, vérifiez la configuration de votre navigateur, puis rechargez la page.

:::

Une fois le fichier ouvert, vous y trouverez notamment les éléments suivants.

**Dans le bilan au format PDF :**

- Un tableau récapitulatif des émissions de CO2 par catégorie pour le mois demandé.
- Un tableau récapitulatif des émissions de CO2 par catégorie entre le début de l'année civile et le mois demandé.
- Un tableau détaillant les valeurs par type de produit souscrit.
- Un graphique présentant les émissions de CO2 par catégorie.

**Dans le bilan au format CSV :**

- Le récapitulatif des émissions de CO2 par serveur physique, ou par gamme de serveurs (PCI), pour le ou les mois demandés.

:::warning
Le lien généré n'est valide que pendant 24 heures. Veillez donc à télécharger le bilan carbone depuis votre navigateur une fois le lien ouvert.

:::
