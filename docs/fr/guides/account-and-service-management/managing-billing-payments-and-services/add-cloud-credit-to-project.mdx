## Objectif

L'option de « crédit cloud » vous permet d'allouer un montant spécifique à votre projet Public Cloud, qui servira de moyen de paiement par défaut pour la [facturation de votre projet](/guides/public-cloud/cross-functional/analyze-billing).<br/>
Cela signifie que ce crédit cloud est débité en premier et que toute dette sera ensuite payée par les autres moyens de paiement disponibles. N’hésitez pas à consulter les [guides de facturation de Public Cloud](/guides/account-and-service-management/managing-billing-payments-and-services/best-practices) pour en savoir plus sur le sujet.

**Ce guide vous explique comment ajouter du crédit sur votre compte Public Cloud à l’aide d’un voucher ou via la génération d’un bon de commande.**

## Prérequis

- Un projet [Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud

[[cpnav:publiccloud-credits-vouchers]]

## En pratique

{/* CP-STEPS-START:open-credits-vouchers */}
Dans le menu de gauche de votre projet Public Cloud, cliquez sur <code className="action">Centre de coûts</code>, puis sur l'onglet <code className="action">Crédits et bons d'achat</code>. Les boutons de cet onglet ne sont pas disponibles pour un projet en mode découverte.
{/* CP-STEPS-END:open-credits-vouchers */}

:::warning
Notez que les crédits ajoutés dans cette section ne peuvent pas être transférés ni remboursés. Ils n'ont aucune valeur monétaire et tout crédit non utilisé dans les 13 mois suivant son achat est perdu.

:::

### Ajouter du crédit

{/* CP-STEPS-START:add-credit */}
Cliquez sur le bouton <code className="action">Acheter du crédit cloud</code>.

Dans la fenêtre **Acheter du crédit cloud**, renseignez le montant (HT) que vous souhaitez ajouter, dans votre devise, dans le champ **Somme à créditer**. Cliquez sur <code className="action">Générer un bon de commande</code> pour valider.

Un bon de commande sera alors généré. Cliquez sur le lien dans le cadre vert de notification pour le consulter dans un nouvel onglet et initier le paiement.

Une fois le paiement effectué, votre crédit apparaîtra dans l'onglet <code className="action">Crédits et bons d'achat</code>.
{/* CP-STEPS-END:add-credit */}

### Utiliser un voucher

{/* CP-STEPS-START:redeem-voucher */}
Cliquez sur le bouton <code className="action">Activer un voucher</code>.

Dans la fenêtre **Activer un voucher**, renseignez le code du voucher dans le champ **Votre voucher** et cliquez sur <code className="action">Activer</code>.

Le solde du voucher apparaîtra dans l'onglet <code className="action">Crédits et bons d'achat</code>.
{/* CP-STEPS-END:redeem-voucher */}

:::info
Les périodes de validité des vouchers sont généralement limitées à 1 mois ; il est donc recommandé d'utiliser le voucher le plus tôt possible. Le solde du voucher sera utilisé avant le crédit Public Cloud.

:::
