## Objectif

Les administrations publiques appliquent une procédure d'engagement des dépenses : avant de régler une facture, la dépense correspondante doit avoir été engagée et identifiée par un numéro. Ce numéro d'engagement est attribué par l'administration elle-même et doit figurer sur la facture pour que la comptabilité publique puisse en autoriser le paiement.

OVHcloud vous permet de renseigner ce numéro directement sur votre bon de commande, depuis votre espace client.

**Ce guide vous explique comment renseigner un numéro d'engagement sur un bon de commande OVHcloud.**

:::info
Ne confondez pas le **numéro d'engagement** décrit dans ce guide avec l'**engagement** au sens contractuel (période d'engagement souscrite sur un service en échange d'une remise), traité dans le guide [Gérer les engagements depuis l'espace client OVHcloud](/guides/account-and-service-management/managing-billing-payments-and-services/manage-commitments). Il s'agit de deux notions distinctes.

:::

## Prérequis

- Disposer d'un compte client OVHcloud identifié comme administration publique. L'option décrite dans ce guide n'est proposée qu'à ces comptes.
- Être connecté avec le compte client sur lequel le bon de commande a été généré. Si la facturation de vos services est gérée par un compte client dédié, l'option est disponible depuis ce compte.
- Disposer d'une commande en cours, pour laquelle la facture n'a pas encore été émise.

## En pratique

:::warning
L'option `Saisir un numéro d'engagement` n'est disponible que tant que la commande est en cours. Elle n'apparaît plus une fois la facture émise. Renseignez donc votre numéro d'engagement dès la création du bon de commande.

:::

### Renseigner le numéro d'engagement

Ouvrez la page <ManagerLink to="/#/billing/orders">Mes commandes</ManagerLink>, puis cliquez sur le bouton <code className="action">...</code> à droite de la commande concernée. Sélectionnez <code className="action">Saisir un numéro d'engagement</code>.

<img className="thumbnail" alt="Option Saisir un numéro d'engagement dans le menu d'une commande" src="/images/account-and-service-management/managing-billing-payments-and-services/commitment-number/commitment01.png" loading="lazy" />

Saisissez le numéro attribué par votre administration dans le champ `Numéro d'engagement`, puis cliquez sur <code className="action">Valider</code>.

<img className="thumbnail" alt="Saisie du numéro d'engagement pour une commande" src="/images/account-and-service-management/managing-billing-payments-and-services/commitment-number/commitment02.png" loading="lazy" />

:::info
Le numéro saisi doit respecter le format alphanumérique `[0-9]` `[A-Z]` et n'accepte que les caractères spéciaux suivants : `-` `_` `+` `/`

:::

Un message confirme que le numéro d'engagement a bien été enregistré pour la commande. Cliquez sur <code className="action">Retourner à mes commandes</code> pour revenir à la liste de vos commandes.

<img className="thumbnail" alt="Confirmation de l'enregistrement du numéro d'engagement" src="/images/account-and-service-management/managing-billing-payments-and-services/commitment-number/commitment03.png" loading="lazy" />

Le numéro d'engagement est désormais associé à votre bon de commande et sera repris sur la facture correspondante.
