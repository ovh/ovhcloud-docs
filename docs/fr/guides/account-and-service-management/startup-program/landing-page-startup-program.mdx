## Startup Program OVHcloud

Le [Startup Program OVHcloud](/links/transversal/startup-program) aide les startups à construire et faire évoluer leur infrastructure serveur chez OVHcloud. Une fois votre candidature acceptée et votre contrat signé, vous recevez des crédits gratuits valables 12 mois, et nos Startup Program Managers vous accompagnent tout au long du programme.

En tant que membre du Startup Program, vous pouvez :

- Payer les produits éligibles avec vos crédits, comme Public Cloud et Hosted Private Cloud
- Demander des consultations techniques pour évaluer et faire évoluer votre infrastructure
- Contacter un Startup Program Manager pour obtenir des conseils à chaque étape
- Rencontrer nos équipes lors d'événements dédiés aux startups
