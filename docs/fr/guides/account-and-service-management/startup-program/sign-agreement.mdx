## Objectif

Pour participer au Startup Program d'OVHcloud, la signature du contrat est une étape indispensable. Une fois votre candidature acceptée, vous recevrez un e-mail vous demandant de signer le contrat dans la console OVHcloud.

**Ce guide vous explique comment accéder à ce contrat et le signer pour que vos crédits soient activés rapidement**

## Prérequis

- Votre candidature au Startup Program doit avoir été validée. Retrouvez plus d’informations dans notre guide « [Comment optimiser votre candidature au Startup Program](/guides/account-and-service-management/startup-program/optimise-application) ».

[[cpnav:account-contracts-console]]

## En pratique

### Signer le contrat dans la console OVHcloud

Vous pouvez accéder au contrat directement depuis votre compte client.

Assurez-vous de vous connecter avec le compte que vous avez utilisé pour l’inscription au Startup Program, puis rendez-vous sur la page <ManagerLink console to="/#/customer/account/contracts">Contrats</ManagerLink> de la console OVHcloud.

<img className="thumbnail" alt="Page Contrats de la console OVHcloud, avec le tableau des contrats" src="/images/account-and-service-management/startup-program/02-sign-agreement/console/contracts-list.png" loading="lazy" />

Recherchez votre contrat Startup Program dans le tableau : un contrat en attente de votre accord porte le statut **À confirmer**.

Cliquez sur le nom du contrat pour ouvrir sa page, où vous pouvez en prendre connaissance et le télécharger en cliquant sur <code className="action">Télécharger le PDF</code>.

<img className="thumbnail" alt="Page d’un contrat dans la console OVHcloud, avec son texte et le lien Télécharger le PDF" src="/images/account-and-service-management/startup-program/02-sign-agreement/console/contract-detail.png" loading="lazy" />

Sur la page de votre contrat Startup Program, cochez la case <code className="action">J'ai lu et j'accepte ce contrat.</code>, puis cliquez sur <code className="action">Accepter</code> pour valider l’acceptation du contrat.

Après la signature, vos crédits seront crédités sur votre compte sous 48 heures ouvrées et vous pourrez profiter pleinement des avantages du programme.

Votre contrat signé restera disponible sur la page **Contrats** pour être consulté à tout moment, avec le statut **Accepté le** suivi de la date.
