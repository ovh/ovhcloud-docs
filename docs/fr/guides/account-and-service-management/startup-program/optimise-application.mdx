## Objectif

Le Startup Program d'OVHcloud offre de nombreux avantages pour soutenir les startups dans leur développement. 

**Pour maximiser vos chances d'acceptation, ce guide vous détaille les étapes à suivre pour préparer et finaliser votre inscription.**

## Prérequis

- Avoir créé [votre compte OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation).

[[cpnav:account-profile-console]]

## En pratique

### Etape 1 - Mettre à jour votre compte OVHcloud

Assurez-vous que votre compte OVHcloud est correctement configuré avant de soumettre votre candidature.

Sur la page <ManagerLink console to="/#/customer/account/profile">Profil</ManagerLink>, définissez le type de compte sur `Entreprise` et complétez les informations requises. Ces informations se modifient dans deux sections de la page.

Dans la section **Administrateur du compte** (**Titulaire du compte** sur le compte d'un particulier), cliquez sur <code className="action">Modifier</code>. Dans le panneau **Modifier l’administrateur**, sélectionnez <code className="action">Entreprise</code> dans la liste déroulante **Type de compte** et complétez les informations personnelles du titulaire du compte : **Prénom**, **Nom** et **Téléphone**. Cliquez sur <code className="action">Enregistrer</code> : vos modifications s'appliquent immédiatement.

<img className="thumbnail" alt="Panneau « Modifier l’administrateur » avec « Entreprise » sélectionné comme type de compte" src="/images/account-and-service-management/startup-program/01-optimise-application/console/edit-administrator-account-type.png" loading="lazy" />

Utilisez une adresse e-mail professionnelle associée au nom de domaine de votre entreprise. L'adresse e-mail ne se modifie pas dans ce panneau : cliquez sur <code className="action">Changer l’e-mail</code> pour la modifier depuis la page **Sécurité et connexion**. Renseignez également une adresse e-mail de secours (privilégiez une adresse e-mail personnelle) : sur cette même page, cliquez sur <code className="action">Modifier</code> à côté de **Email de secours**.

Dans la section **Entreprise**, cliquez sur <code className="action">Modifier</code> et complétez les informations de votre entreprise : le **SIRET** (uniquement pour les comptes en France), l'**Identifiant fiscal** (numéro de TVA) et l'**Adresse du siège**. Pour une entreprise située en France, recherchez-la par son SIRET dans la recherche **Trouvez votre entreprise**, qui renseigne alors ces informations. Cliquez ensuite sur <code className="action">Enregistrer</code>.

Pour plus d'informations, consultez ce guide : [Sécuriser mon compte OVHcloud et gérer mes informations personnelles](/guides/account-and-service-management/account-information/all-about-username).

### Etape 2 - Ajouter un moyen de paiement valide

Un moyen de paiement valide est requis pour garantir la continuité de vos services. Il sera utilisé pour les produits non éligibles pendant votre participation au programme et pour tous les produits après la fin du programme.

Consultez ce guide pour plus d'informations : [Gérer mes moyens de paiement](/guides/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods).

### Etape 3 - Remplir soigneusement le formulaire d'inscription au Startup Program

Pour nous permettre d'étudier efficacement votre candidature, complétez le formulaire d'inscription avec précision et détail.

**Informations essentielles à renseigner** :

- Nom de votre société
- Site web
- Réseaux sociaux (LinkedIn, X)
- Description de votre projet et de votre modèle économique
- Besoins en infrastructure serveur
- État d'avancement de votre projet

**Précision et complétude** : Toute information manquante ou incorrecte pourrait entraîner le rejet de votre inscription ou des délais supplémentaires en cas de demande de mise à jour.

### Délai de traitement

Les inscriptions sont analysées sous 7 jours. Afin d'accélérer le processus, veillez à fournir toutes les informations demandées dès la première soumission.

En suivant ces étapes, vous augmenterez significativement vos chances d’être accepté au Startup Program d’OVHcloud.
