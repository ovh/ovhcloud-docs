## Objectif

Ce guide vous explique les étapes à suivre pour demander une augmentation de quota sur votre compte Cloud dans le cadre de l'utilisation de nos services. Si vous faites partie du Startup Program, il est important de prendre en compte certaines limitations, notamment concernant l’utilisation des crédits alloués par le programme lors de l'augmentation de quota.

## Points clés

- **Utilisation des crédits du Startup Program** : Il n'est pas possible de commander une augmentation de quota en utilisant les crédits fournis par le Startup Program. Il faudra alors suivre les étapes décrites ci-dessous si vous souhaitez quand-même augmenter le quota.
- **Paiement personnel** : Si vous êtes membre du Startup Program et que vous choisissez tout de même de payer avec vos propres fonds pour augmenter votre quota, le montant payé pourra être crédité (à votre demande) sur votre compte client en tant que crédit Cloud. Ce crédit sera utilisé en priorité pour vos futurs paiements, avant vos crédits du Startup Program.
- **Préparation** : Avant de demander une augmentation de quota, vous devez ajouter un moyen de paiement valide à votre compte client et vous assurer que vous êtes enregistré en tant que société.

## Prérequis

- Vous êtes membre du [Startup Program](https://startup.ovhcloud.com/fr/).
- Votre compte OVHcloud dispose d'un moyen de paiement valide. Consultez [ce guide](/guides/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods) pour vous aider à ajouter un moyen de paiement valide.
- Votre compte est enregistré sous le statut `Entreprise`. Consultez [ce guide](/guides/account-and-service-management/account-information/all-about-username) pour vous aider à modifier vos informations.

## En pratique

Cette procédure vous permet de demander manuellement une augmentation de quota et de la valider via un paiement initial (crédit Public Cloud).

### Etape 1 - Créer un ticket pour demander une augmentation de quota

Une fois les prérequis ci-dessus remplis, vous pouvez créer un ticket de support en suivant ces étapes :

Dans la <ManagerLink console to="/#/public-cloud/project">console OVHcloud</ManagerLink>, sélectionnez votre projet Public Cloud dans le sélecteur de projet, en haut du menu de gauche. Cliquez sur <code className="action">Gestion du projet</code> dans le menu de gauche, puis sur l'onglet <code className="action">Quotas</code>, et cliquez sur <code className="action">Contacter le support</code>.

<img className="thumbnail" alt="Onglet Quotas de la page Gestion du projet, avec le lien Contacter le support" src="/images/account-and-service-management/startup-program/07-increase-quota/console/quotas-tab.png" loading="lazy" style={{ maxWidth: '800px' }} />

La fenêtre **Demander une augmentation de quotas au support** s'ouvre. Votre demande ne pourra être acceptée que si vous répondez aux quatre questions :

- l'objectif de votre projet ;
- le volume dont vous avez besoin pour les prochains mois (nombre de processeurs, RAM, instances, etc.) ;
- si vous avez déjà tenté d'augmenter le quota depuis la console OVHcloud ;
- le site web de votre entreprise, ou toute URL publique permettant de trouver des informations sur vous ou sur votre activité.

Dans votre réponse sur l'objectif de votre projet, motivez votre demande d'augmentation de quota : précisez que vous participez au Startup Program d'OVHcloud et indiquez le nom du Startup Program Manager en charge du suivi de votre participation (consultez la [liste des Startup Program Managers](/links/transversal/startup-program-faq-managers)). Détaillez votre besoin technique dans votre réponse sur le volume nécessaire.

<img className="thumbnail" alt="Fenêtre Demander une augmentation de quotas au support, avec ses quatre questions et le bouton Envoyer" src="/images/account-and-service-management/startup-program/07-increase-quota/console/quota-support-dialog.png" loading="lazy" style={{ maxWidth: '800px' }} />

Cliquez sur <code className="action">Envoyer</code> pour soumettre votre demande. Elle est enregistrée sous la forme d'un ticket de support : nous vous invitons à ne créer qu'un seul ticket par demande.

### Etape 2 - Contacter votre Startup Program Manager

Après avoir soumis votre demande d’augmentation de quota, il est recommandé de contacter le Startup Program Manager de votre région pour assurer un suivi de votre ticket et obtenir une assistance rapide.

Retrouvez la liste des Startup Program Managers [ici](https://startup.ovhcloud.com/fr/faq-support/#SPManager).

## Conclusion

Demander une augmentation de quota peut être nécessaire pour adapter vos ressources Cloud à vos besoins en terme de croissance. Cependant, il est important de bien comprendre les modalités de paiement et l’ordre de priorité des crédits pour éviter les paiements inattendus avec vos fonds propres. En cas de doute, n'hésitez pas à contacter votre Startup Program Manager pour vous guider à chaque étape du processus.
