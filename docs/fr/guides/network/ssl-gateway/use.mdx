## Objectif

Après la commande de votre SSL Gateway, sa configuration s'effectue dans la console OVHcloud.

**Ce guide vous explique comment rattacher vos domaines à votre SSL Gateway, définir les serveurs vers lesquels le trafic est transmis, configurer ses paramètres réseau et suivre ses opérations et ses statistiques.**

## Prérequis

- Disposer d'une offre [SSL Gateway](/guides/network/ssl-gateway/order) Free ou Advanced
- Disposer d'un accès à la zone DNS de chaque domaine que vous souhaitez servir via votre SSL Gateway

## Introduction

[SSL Gateway](/links/web/ssl-gateway) est un front-end HTTPS managé pour votre site web. Le service se place devant vos propres serveurs, appelés serveurs backend : il détient le certificat SSL, gère la connexion TLS avec les navigateurs de vos visiteurs et protège le trafic contre les attaques DDoS, puis transmet les requêtes à vos serveurs.

L'offre de votre SSL Gateway détermine ce que vous pouvez configurer :

| Fonctionnalité | Free | Advanced |
|---|---|---|
| Domaines | 3 : 1 domaine, son `www` et 1 sous-domaine | Jusqu'à 1 000 domaines et sous-domaines, y compris des domaines de 4 niveaux et plus |
| Serveurs backend | 1 | Jusqu'à 3, avec répartition du trafic entre eux |
| Adresses IP dédiées | Non | Oui |
| Profil de chiffrement | Intermediate, fixe | Modern ou Intermediate |
| HSTS (HTTP Strict Transport Security) | Non | Oui |
| Sources autorisées | Non : toutes les sources sont autorisées | Oui |
| Reverse DNS modifiable | Non | Oui |
| Onglet <code className="action">Statistiques</code> | Non | Oui |
| Certificat EV (Extended Validation) | Non | En option (Sectigo) |

## En pratique

### Ouvrir votre SSL Gateway

{/* CP-STEPS-START:open-gateway */}

La liste affiche vos SSL Gateway avec les colonnes **Nom / ID**, **Région**, **Offre**, **IPv4** et **Statut**. Cliquez sur le nom de la SSL Gateway que vous souhaitez configurer.

<img className="thumbnail" alt="Liste des SSL Gateway avec les colonnes Nom / ID, Région, Offre, IPv4 et Statut" src="/images/network/ssl-gateway/use-ssl-gateway/console/ssl-gateway-list.png" loading="lazy" />

La page de votre SSL Gateway s'ouvre sur l'onglet <code className="action">Vue d'ensemble</code>, qui affiche quatre cartes :

- **Informations générales** : l'identifiant, la région, le reverse DNS, les adresses IPv4 et IPv6 de votre SSL Gateway, ainsi que les plages **IPv4 sortantes** utilisées pour joindre vos serveurs ;
- **Abonnement** : l'offre, la date de création, le mode de renouvellement et la date de renouvellement ;
- **Configuration réseau** : les paramètres TLS et d'accès de votre SSL Gateway ;
- **Backend** : les serveurs vers lesquels le trafic est transmis.

Les autres onglets sont <code className="action">Domaines</code>, <code className="action">Statistiques</code> (offre Advanced uniquement) et <code className="action">Opérations</code>.

<img className="thumbnail" alt="Onglet Vue d'ensemble d'une SSL Gateway Advanced avec les cartes Informations générales, Abonnement, Configuration réseau et Backend" src="/images/network/ssl-gateway/use-ssl-gateway/console/overview-advanced.png" loading="lazy" />

{/* CP-STEPS-END:open-gateway */}

### Ajouter et supprimer des domaines

Pour qu'un domaine soit validé, ses enregistrements DNS doivent pointer vers votre SSL Gateway : un enregistrement A vers son adresse IPv4 et, le cas échéant, un enregistrement AAAA vers son adresse IPv6. Ces deux adresses sont affichées dans la carte **Informations générales**. Si la zone DNS du domaine est gérée par OVHcloud, consultez nos guides sur les [enregistrements A](/guides/web-cloud/domains/dns-zone-a-record-creation) et les [enregistrements AAAA](/guides/web-cloud/domains/dns-zone-aaaa-record-creation).

{/* CP-STEPS-START:domains */}

Pour rattacher un domaine, ouvrez l'onglet <code className="action">Domaines</code> et cliquez sur <code className="action">Ajouter un domaine</code>.

<img className="thumbnail" alt="Onglet Domaines d'une SSL Gateway avec le bouton Ajouter un domaine et l'icône de suppression sur la ligne d'un domaine" src="/images/network/ssl-gateway/use-ssl-gateway/console/domains-tab.png" loading="lazy" />

Dans le champ **Domaine**, saisissez le nom d'hôte que vous souhaitez servir en HTTPS, par exemple `shop.example.com`, puis cliquez sur <code className="action">Ajouter le domaine</code>.

<img className="thumbnail" alt="Fenêtre Ajouter un domaine avec le champ Domaine" src="/images/network/ssl-gateway/use-ssl-gateway/console/add-domain-dialog.png" loading="lazy" />

La validation DNS peut prendre jusqu'à 72 heures. Tant qu'elle n'est pas terminée, le statut du domaine indique **Creating**.

L'offre Free inclut 3 domaines : 1 domaine, son `www` et 1 sous-domaine. Une fois 3 domaines rattachés, le bouton <code className="action">Ajouter un domaine</code> est désactivé.

Pour supprimer un domaine, cliquez sur l'icône de suppression sur sa ligne, puis sur <code className="action">Supprimer</code>. Le domaine est détaché de votre SSL Gateway et n'est plus servi en HTTPS.

{/* CP-STEPS-END:domains */}

### Configurer les serveurs backend

La carte **Backend** de l'onglet <code className="action">Vue d'ensemble</code> indique la destination du trafic reçu par votre SSL Gateway : l'adresse IP et le port de vos serveurs.

{/* CP-STEPS-START:backend */}

**Offre Free** : le trafic est transmis à 1 serveur. Cliquez sur <code className="action">Modifier le backend</code>, saisissez l'adresse IP du serveur dans le champ **Adresse IP** et, dans le champ **Port**, le port sur lequel il écoute le trafic de votre SSL Gateway, puis cliquez sur <code className="action">Enregistrer</code>.

<img className="thumbnail" alt="Panneau Modifier le backend d'une SSL Gateway Free avec les champs Adresse IP et Port" src="/images/network/ssl-gateway/use-ssl-gateway/console/edit-backend-drawer.png" loading="lazy" />

**Offre Advanced** : le trafic est réparti sur 3 serveurs au maximum. Cliquez sur <code className="action">Ajouter un serveur</code>, renseignez les champs **Adresse IP** et **Port**, puis cliquez sur <code className="action">Ajouter</code>. Pour modifier ou supprimer un serveur, utilisez le menu de sa ligne.

<img className="thumbnail" alt="Panneau Ajouter un serveur d'une SSL Gateway Advanced avec les champs Adresse IP et Port" src="/images/network/ssl-gateway/use-ssl-gateway/console/add-server-drawer.png" loading="lazy" />

L'adresse IP doit être l'adresse IPv4 publique de votre serveur : votre SSL Gateway ne peut pas joindre une adresse privée.

Chaque modification s'exécute sous forme d'opération et est appliquée dans quelques instants. Vous pouvez la suivre dans l'onglet <code className="action">Opérations</code>.

Votre SSL Gateway joint vos serveurs depuis les plages d'IP indiquées sous **IPv4 sortantes** dans la carte **Informations générales**. Autorisez ces plages dans les pare-feu de vos serveurs.

{/* CP-STEPS-END:backend */}

### Configurer les paramètres réseau

{/* CP-STEPS-START:network */}

Dans la carte **Configuration réseau**, cliquez sur <code className="action">Modifier la configuration réseau</code>. Vous pouvez définir :

- **Profil de chiffrement** : les suites de chiffrement que votre SSL Gateway propose aux navigateurs. <code className="action">Modern</code> conserve les plus robustes, pour les clients récents ; <code className="action">Intermediate</code> prend aussi en charge les plus anciens.
- <code className="action">HTTPS vers le backend</code> : chiffre aussi le trafic entre votre SSL Gateway et vos serveurs, et pas seulement entre les navigateurs et votre SSL Gateway.
- <code className="action">Redirection HTTPS</code> : redirige chaque requête HTTP vers HTTPS.
- <code className="action">HSTS</code> : indique aux navigateurs de ne joindre vos domaines qu'en HTTPS lors de leurs prochaines visites.
- **Sources autorisées** : les adresses ou blocs IPv4 ou IPv6 autorisés à joindre votre SSL Gateway. Saisissez une adresse ou un bloc, par exemple `203.0.113.0/24`, puis cliquez sur <code className="action">Ajouter</code>, une fois par source. Pour retirer une source, cliquez sur la croix à côté de celle-ci. Si aucune source n'est indiquée, toutes les sources peuvent joindre votre SSL Gateway.

Cliquez ensuite sur <code className="action">Enregistrer</code>.

<img className="thumbnail" alt="Panneau Modifier la configuration réseau avec la liste Profil de chiffrement, les cases HTTPS vers le backend, Redirection HTTPS et HSTS, et le champ Sources autorisées" src="/images/network/ssl-gateway/use-ssl-gateway/console/network-configuration-drawer.png" loading="lazy" />

Avec l'offre Free, le profil de chiffrement reste **Intermediate** ; HSTS et les sources autorisées ne sont pas disponibles. Si votre SSL Gateway Free conserve encore de tels paramètres, enregistrer une modification les remet aux valeurs de l'offre Free : Intermediate, HSTS désactivé, aucune restriction de sources.

{/* CP-STEPS-END:network */}

### Modifier le reverse DNS

{/* CP-STEPS-START:reverse */}

Avec l'offre Advanced, vous pouvez définir le reverse DNS de votre SSL Gateway : dans la carte **Informations générales**, cliquez sur l'icône en forme de crayon à côté de **Reverse DNS**, saisissez le nom d'hôte dans le champ **Reverse DNS**, puis cliquez sur <code className="action">Enregistrer</code>. Avec l'offre Free, le reverse DNS n'est pas modifiable.

<img className="thumbnail" alt="Panneau Modifier le reverse DNS avec le champ Reverse DNS" src="/images/network/ssl-gateway/use-ssl-gateway/console/reverse-dns-drawer.png" loading="lazy" />

{/* CP-STEPS-END:reverse */}

### Suivre les opérations

{/* CP-STEPS-START:operations */}

Chaque modification de votre SSL Gateway, comme l'ajout ou la suppression d'un domaine ou d'un serveur, ou un passage à Advanced, s'exécute sous forme d'opération. L'onglet <code className="action">Opérations</code> les affiche avec les colonnes **ID**, **Action**, **Statut**, **Progression** et **Date de création**. Pour afficher le détail d'une opération, cliquez sur <code className="action">Aller au détail</code> sur sa ligne.

{/* CP-STEPS-END:operations */}

### Consulter les statistiques

{/* CP-STEPS-START:statistics */}

Avec l'offre Advanced, l'onglet <code className="action">Statistiques</code> affiche le trafic de votre SSL Gateway. Sous **Période**, choisissez une durée, de <code className="action">1h</code> à <code className="action">1M</code> (un mois). L'onglet affiche la moyenne et le pic du nombre de requêtes et de connexions par seconde sur la période. Au-dessus du graphique, choisissez <code className="action">Requêtes/s</code> ou <code className="action">Connexions/s</code>.

<img className="thumbnail" alt="Onglet Statistiques d'une SSL Gateway Advanced avec le sélecteur de période, les valeurs moyenne et pic, et le graphique des requêtes" src="/images/network/ssl-gateway/use-ssl-gateway/console/statistics-tab.png" loading="lazy" />

{/* CP-STEPS-END:statistics */}

### Gérer l'offre et l'abonnement

{/* CP-STEPS-START:subscription */}

La carte **Abonnement** affiche l'offre, la date de création, le mode de renouvellement et la date de renouvellement. Cliquez sur <code className="action">Gérer mon abonnement</code> pour modifier le renouvellement. Pour résilier le service, cliquez sur <code className="action">Résilier</code>, puis à nouveau sur <code className="action">Résilier</code> dans la fenêtre de confirmation : vous recevez ensuite un e-mail pour confirmer la résiliation.

<Region zones={['eu']}>

Lorsque votre SSL Gateway peut passer à une offre supérieure, la carte **Abonnement** affiche aussi <code className="action">Passer à Advanced</code>.

<img className="thumbnail" alt="Onglet Vue d'ensemble d'une SSL Gateway Free avec Passer à Advanced dans la carte Abonnement" src="/images/network/ssl-gateway/use-ssl-gateway/console/overview-free.png" loading="lazy" />

Cliquez sur <code className="action">Passer à Advanced</code>. La fenêtre **Passer à Advanced** liste ce qu'apporte l'offre Advanced (jusqu'à 1 000 domaines et sous-domaines, des domaines de 4 niveaux et plus, une adresse IP dédiée, la répartition de charge sur 3 serveurs backend maximum), le montant à payer aujourd'hui, au prorata, et le montant facturé ensuite tous les mois.

La case <code className="action">Payer maintenant avec mon moyen de paiement par défaut</code> est cochée par défaut. Pour payer plutôt sur la page de commande, qui s'ouvre dans un nouvel onglet, décochez-la. Cliquez ensuite sur <code className="action">Passer à Advanced</code>.

<img className="thumbnail" alt="Fenêtre Passer à Advanced avec les montants, l'avertissement sur l'adresse IP et la case Payer maintenant avec mon moyen de paiement par défaut" src="/images/network/ssl-gateway/use-ssl-gateway/console/upgrade-dialog.png" loading="lazy" />

:::warning
L'offre Advanced utilise des adresses IP dédiées. À la fin du passage à Advanced, votre SSL Gateway reçoit une nouvelle adresse IPv4 et IPv6, et les anciennes cessent aussitôt de servir le trafic. Faites pointer vos domaines vers les nouvelles adresses, envoyées par e-mail et affichées dans la carte **Informations générales** : d'ici là, votre site web n'est plus joignable via votre SSL Gateway.

:::

Votre SSL Gateway conserve son identifiant et sa configuration. Le passage à Advanced s'exécute sous forme d'opération, à suivre dans l'onglet <code className="action">Opérations</code>.

</Region>

{/* CP-STEPS-END:subscription */}

### Renouveler le certificat SSL

Le certificat SSL de votre SSL Gateway est un certificat DV (Domain Validation) émis par Let's Encrypt et renouvelé automatiquement. Avec l'offre Advanced, un certificat SSL Sectigo EV est disponible en option.

Pour renouveler le certificat à la demande, utilisez l'appel API suivant :

<Api version="v1" section="/sslGateway" method="POST" route={"/sslGateway/\{serviceName\}/renewCertificate"} />
