## Objectif

[SSL Gateway](/links/web/ssl-gateway) sécurise les connexions vers votre site web en plaçant un front-end HTTPS managé, doté d'un certificat SSL, devant vos propres serveurs (VPS, serveur dédié, etc.).

:::warning
SSL Gateway n'est pas compatible avec les offres d'[hébergement web OVHcloud](/links/web/hosting). Pour utiliser un certificat SSL avec un hébergement web, consultez notre guide « [Hébergement web - Gérer un certificat SSL](/guides/web-cloud/web-hosting/ssl-on-webhosting) ».

:::

**Ce guide vous explique comment commander votre SSL Gateway.**

## Prérequis

- Disposer d'un [nom de domaine](/links/web/domains) ou d'un sous-domaine qui pointe déjà vers le serveur de votre site web
- Disposer d'un accès à la zone DNS du nom de domaine

[[cpnav:network-ssl-gateway-console]]

## En pratique

### Commande

Sur la page **SSL Gateway**, cliquez sur <code className="action">Commander une SSL Gateway</code>. Le formulaire de commande comporte 4 étapes.

**1. Offre** : choisissez <code className="action">Gratuit</code> (offre Free) ou <code className="action">Advanced</code>.

- **Gratuit** : 1 domaine, son `www` et 1 sous-domaine, des domaines de 3 niveaux maximum, une adresse IP partagée, 1 serveur back-end et un certificat Let's Encrypt renouvelé automatiquement, sans frais mensuels.
- **Advanced** : jusqu'à 1 000 domaines et sous-domaines, des domaines de 4 niveaux et plus, une adresse IP dédiée et la répartition de charge sur 3 serveurs back-end maximum.

Les deux offres sont facturées mensuellement, sans frais d'installation et sans engagement.

<img className="thumbnail" alt="Page Commander une SSL Gateway avec les offres Gratuit et Advanced, l'étape Nom de domaine et le récapitulatif de la commande" src="/images/network/ssl-gateway/order-ssl-gateway/console/order-offer.png" loading="lazy" />

**2. Nom de domaine** : dans le champ **Nom de domaine**, saisissez le domaine ou le sous-domaine que votre SSL Gateway dessert via HTTPS, puis cliquez sur <code className="action">Vérification</code>. Le domaine doit déjà pointer vers votre site web : sous **IP back-end**, le formulaire affiche l'adresse IPv4 vers laquelle il pointe, à laquelle votre SSL Gateway transmet le trafic. S'il y en a plusieurs, choisissez-en une.

:::warning
- Avec l'offre Free, le domaine peut compter jusqu'à 3 niveaux, comme `www.domain.tld`. Pour un sous-domaine de niveau supérieur, comme `blog.www.domain.tld`, choisissez Advanced.
- Le formulaire refuse un domaine qui pointe vers une adresse déjà utilisée par un autre service OVHcloud (Load Balancer, CDN, hébergement web ou SSL Gateway). Faites-le pointer vers l'adresse de votre propre serveur, puis vérifiez à nouveau.
- Avec l'offre Advanced, vous pouvez ajouter jusqu'à 2 serveurs back-end supplémentaires après la livraison, dans la carte **Backend** de votre SSL Gateway. Consultez notre guide « [Configurer et gérer votre SSL Gateway](/guides/network/ssl-gateway/use) ».

:::

**3. Localisation** : choisissez <code className="action">Roubaix (eu-west-rbx-a)</code> ou <code className="action">Beauharnois (ca-east-bhs-a)</code>.

**4. DNS** : si vous gérez la zone DNS du domaine chez OVHcloud, vous pouvez cocher la case <code className="action">Je gère la zone DNS de ce domaine et j'autorise OVHcloud à mettre à jour automatiquement l'enregistrement DNS requis.</code> L'enregistrement est alors mis à jour à votre place, et le récapitulatif de la commande affiche **Mise à jour des DNS** : Automatiques. Sinon, faites pointer vous-même le domaine vers votre SSL Gateway après la commande (voir ci-dessous).

<img className="thumbnail" alt="Étapes Nom de domaine, Localisation et DNS du formulaire de commande SSL Gateway après la vérification d'un domaine, avec l'IP back-end, le délai de 3 jours et le message sur le HTTPS" src="/images/network/ssl-gateway/order-ssl-gateway/console/order-domain-location-dns.png" loading="lazy" />

Vérifiez vos choix dans le récapitulatif de la commande, puis cliquez sur <code className="action">Continuer la commande</code>. La page de vérification de votre commande s'ouvre dans un nouvel onglet : suivez les étapes jusqu'au paiement. Votre SSL Gateway apparaît sur la page **SSL Gateway** dès sa livraison.

### Faire pointer votre nom de domaine vers votre SSL Gateway

Si vous n'avez pas coché la case DNS, faites pointer votre nom de domaine ou sous-domaine vers l'adresse IP de votre SSL Gateway dans un délai de 3 jours après la commande : notre e-mail vous communique l'adresse. Sans cela, la commande est annulée.

:::info
**Cas 1 : votre zone DNS est gérée par les serveurs DNS mutualisés OVHcloud**

- Si votre identifiant client est contact *administrateur* ou *technique* de cette zone DNS, modifiez la zone dans la <ManagerLink console to="/#/web-cloud/domains/listing">console OVHcloud</ManagerLink>.
- Sinon, demandez à la personne en charge de cette zone DNS de la modifier.

Si nécessaire, consultez notre guide « [Ajouter un enregistrement DNS de type A pour un nom de domaine](/guides/web-cloud/domains/dns-zone-a-record-creation) ».

:::

:::info
**Cas 2 : votre zone DNS n'est pas gérée par les serveurs DNS mutualisés OVHcloud**

Modifiez l'adresse IP dans votre zone DNS depuis l'interface de votre fournisseur DNS, ou sur votre propre serveur DNS.

:::

Dès la livraison, le HTTP simple transite déjà par votre SSL Gateway. Le HTTPS démarre une fois que votre domaine pointe vers votre SSL Gateway et que son certificat est émis, généralement sous 15 minutes.

:::warning
Une modification de votre zone DNS peut nécessiter jusqu'à 24 heures avant d'être effective, car les fournisseurs d'accès à Internet conservent les enregistrements DNS dans leur cache.

:::
