## Objectif

Avec OVHcloud Connect, vous pouvez relier votre réseau d'entreprise à votre réseau privé OVHcloud vRack, sans créer de tunnel VPN à travers Internet. Vous bénéficiez ainsi d’une connexion plus rapide et plus stable, avec une bande passante garantie.

**Ce guide vous explique comment obtenir un rapport sur l'état de vos services OVHcloud Connect depuis la console OVHcloud.**

## Prérequis

- Détenir une solution [OVHcloud Connect](https://www.ovhcloud.com/fr/network/ovhcloud-connect/) avec une configuration POP valide.

## Liste des diagnostics disponibles

### Mode L3

{/* CP-STEPS-START:diagnostics-list-layer-3 */}

En mode L3, la fenêtre **Vérifier le Peering BGP** propose trois diagnostics :

- **Default** : Extrait les états de session BGP et toutes les informations associées.
- **Routes** : Récupère la table de routage apprise par OVHcloud via BGP.
- **Advertised-Routes** : Récupère la table de routage annoncée par OVHcloud via BGP.

## En pratique

### Mode L3

{/* CP-STEPS-START:layer-3-diagnostic */}

Ouvrez le service pour lequel vous souhaitez obtenir un diagnostic, puis cliquez sur l'onglet <code className="action">Configurer</code>.

Dans la section **Configuration PoP**, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions** de votre port en mode L3, puis sélectionnez <code className="action">Vérifier le peering BGP</code>. Cette option est également disponible dans le menu <code className="action">⋮</code> de chaque route BGP, dans le tableau **Routage** d'une zone de disponibilité.

Une fenêtre s'ouvre. Sélectionnez le type de diagnostic que vous souhaitez utiliser, puis cliquez sur <code className="action">Lancer le diagnostic</code>.

Vous pouvez maintenant accéder à la liste de vos diagnostics en ouvrant l'onglet <code className="action">Diagnostic</code>. Si un diagnostic que vous venez de lancer n'apparaît pas encore, cliquez sur <code className="action">Rafraîchir</code>.

Chaque diagnostic est présenté avec son **ID Diagnostic**, sa **Date**, son **Nom**, son **Scope** et son **Statut**.
Pour accéder au contenu d'un diagnostic, une fois celui-ci terminé, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions** de sa ligne. Sélectionnez <code className="action">Voir le résultat</code> pour afficher son contenu dans la fenêtre **Résultat du diagnostic**, ou <code className="action">Télécharger</code> pour obtenir un fichier *.txt* avec le même contenu.

{/* CP-STEPS-END:layer-3-diagnostic */}

## Limites

- **Durée de rétention des diagnostics** : Seuls les diagnostics initiés **au cours des sept derniers jours** sont accessibles. Nous vous recommandons de les télécharger et de les archiver correctement, au cas où vous auriez besoin d'un accès ultérieur.

- **Nombre maximum de diagnostics** : Sur une période de 24 heures, vous pouvez lancer un maximum de 10 diagnostics par type de diagnostic et par service. Par exemple, si vous détenez deux services OVHcloud Connect dans votre console OVHcloud, tous deux configurés en mode Layer 3, vous pouvez théoriquement lancer 10 diagnostics de chaque type par service, pour un total de 60.<br/>
Cette limite a été fixée afin de limiter la quantité de ressources utilisées par l’infrastructure OVHcloud, les diagnostics étant lancés en temps réel.
