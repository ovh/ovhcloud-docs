Depuis le 6 octobre 2022, notre solution « IP Failover » s'appelle désormais [Additional IP](https://www.ovhcloud.com/fr/network/additional-ip/). Cela n'a pas d'impact sur ses fonctionnalités.

## Objectif

Comme tous les services OVHcloud, les services Additional IP peuvent être résiliés à tout moment.

**Découvrez comment résilier votre service Additional IP depuis la console OVHcloud ou via les API OVHcloud.**

## Prérequis

- Disposer d'un [service Additional IP](https://www.ovhcloud.com/fr/network/additional-ip/).
- Avoir accès à la <ApiLink>console API OVHcloud</ApiLink>.
- Consulter le guide [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps) pour vous familiariser avec les APIv6 OVHcloud.

[[cpnav:network-public-ip]]

## En pratique

### Résilier un service Additional IP depuis la console OVHcloud

Dans la liste des adresses IP, cliquez sur l'Additional IP à résilier.

1. Dans l'onglet <code className="action">Vue d'ensemble</code>, repérez la carte **Abonnement** et cliquez sur <code className="action">Résilier</code>. La page **Mes offres & services** s'ouvre dans un nouvel onglet et affiche la fenêtre **Résilier le service**.
2. Sous **Mode de résiliation**, sélectionnez <code className="action">Résilier le service immédiatement.</code> ou <code className="action">Résilier le service à la date d'expiration.</code>
3. Cliquez sur <code className="action">Oui, résilier</code> pour confirmer.

:::warning
La résiliation du service efface définitivement toutes les données correspondantes.
:::

Certaines Additional IP ne peuvent pas être résiliées seules :

- Si l'IP est rattachée à un autre service, <code className="action">Résilier</code> n'est pas disponible et le message suivant s'affiche : « Cette IP est rattachée au service … et doit être résiliée depuis ce service. » Résiliez-la depuis ce service.
- Si la carte **Abonnement** affiche « Cette IP n'est pas facturée comme un service distinct : elle est incluse dans un autre service. », l'IP ne dispose pas de son propre abonnement : elle est incluse dans un autre service.

### Résilier un service Additional IP via les API

Déterminez d'abord le nom du service à résilier. Pour cela, utilisez l'appel API suivant :

<Api version="v1" section="/ip" method="GET" route={"/ip/service"} />


Pour résilier le service, utilisez l'appel suivant :

<Api version="v1" section="/ip" method="POST" route={"/ip/service/\{serviceName\}/terminate"} />


- `serviceName` : le nom du service Additional IP obtenu via l'appel API précédent.

Vous recevrez ensuite un e-mail vous demandant de confirmer la résiliation. La résiliation sera effective après confirmation.
