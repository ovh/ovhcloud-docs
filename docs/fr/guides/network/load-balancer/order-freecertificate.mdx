## Objectif

Le service OVHcloud Load Balancer peut être configuré pour prendre en charge la terminaison SSL.

La terminaison SSL a pour but de déchiffrer le flux chiffré entrant avant de le faire suivre vers le service approprié, tel qu'un serveur web.

Le traitement de la terminaison SSL sur le Load Balancer réduit la charge de calcul sur vos serveurs backend et centralise la gestion des certificats. Cela facilite la maintenance et les mises à jour de sécurité.

**Découvrez comment commander un certificat SSL gratuit depuis la console OVHcloud ou via l'API OVHcloud.**

## Prérequis

- Posséder une offre [OVHcloud Load balancer](https://www.ovhcloud.com/fr/network/load-balancer/) dans votre compte OVHcloud.

## En pratique

### Depuis la console OVHcloud

#### Configurer le frontend pour la terminaison SSL

{/* CP-STEPS-START:configure-frontend-ssl */}

La première étape est de configurer votre frontend pour gérer la terminaison SSL.

Créez un nouveau frontend ou modifiez-en un existant.

Dans l'onglet <code className="action">Frontends</code>, cliquez sur le bouton <code className="action">Créer un frontend</code> pour en créer un nouveau.<br/>
Sur la page **Créer un frontend** qui s'ouvre, sélectionnez le protocole **HTTPS**. Ensuite, dans la section **Routage**, sous **Route par défaut**, sélectionnez **Router vers une ferme** et choisissez la ferme de serveurs qui recevra le trafic.<br/>
Pour rediriger plutôt le trafic vers une URL, sélectionnez **Rediriger vers une URL** comme route par défaut. Cliquez ensuite sur <code className="action">Créer le frontend</code>.

Une fois le frontend créé, appliquez la configuration pour déployer vos changements : dans l'onglet <code className="action">Vue d'ensemble</code>, section **Informations générales**, sous **Déploiement**, cliquez sur <code className="action">Appliquer N changements</code>, N étant le nombre de modifications en attente. La configuration est déployée dans toutes les zones du service.

{/* CP-STEPS-END:configure-frontend-ssl */}

#### Commander le certificate SSL gratuit

{/* CP-STEPS-START:order-free-certificate */}

Dans l'onglet <code className="action">SSL</code> de la console OVHcloud, section **Certificats TLS**, cliquez sur le bouton <code className="action">Ajouter un certificat</code> pour créer un nouveau certificat. Sur la page **Ajouter un certificat**, sous **Type de certificat**, sélectionnez **Gratuit (Let's Encrypt)** : un certificat gratuit et automatique, renouvelé tous les 90 jours. Saisissez votre nom de domaine dans le champ **Domaine(s)** et cliquez sur <code className="action">Ajouter</code> ; ajoutez les noms de domaine un par un. Cliquez ensuite sur <code className="action">Ajouter le certificat</code>.

{/* CP-STEPS-END:order-free-certificate */}

#### Suivi de la commande

{/* CP-STEPS-START:order-follow-up */}

Dans l'onglet <code className="action">Opérations</code> de la console OVHcloud, les opérations liées à la commande d'un certificat SSL gratuit sont de type `orderFreeCertificate`, indiqué dans la colonne **Action**.

{/* CP-STEPS-END:order-follow-up */}

### Depuis l'API OVHcloud

#### Configurer le frontend pour la terminaison SSL

Dans l'API, la terminaison SSL est spécifiée par le booléen `ssl`. Pour activer la terminaison SSL, réglez ce paramètre sur `true`, puis définissez `defaultFarmId` ou `redirectLocation` avec les valeurs correspondantes.

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/http/frontend"} />

Appliquez ensuite les modifications :

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/refresh"} />


#### Commander le certificat SSL gratuit

Dans l'API, la commande se fait via l'appel suivant :

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/freeCertificate"} />

Pour que la commande soit finalisée, il faut obligatoirement que le nom de domaine choisi pointe vers votre service OVHcloud Load Balancer.

#### Suivi de la commande

- Retourner la liste des tâches

Vous pouvez spécifier le type d'action `orderFreeCertificate` pour affiner la recherche.

<Api version="v1" section="/ipLoadbalancing" method="GET" route={"/ipLoadbalancing/\{serviceName\}/task"} />


- Retourner le statut d'une tâche en particulier

<Api version="v1" section="/ipLoadbalancing" method="GET" route={"/ipLoadbalancing/\{serviceName\}/task/\{id\}"} />

Une fois la commande finie, le certificat SSL est automatiquement installé sur votre service OVHcloud Load Balancer.
