## Objectif

Le Content Delivery Network (CDN) vous permet d'optimiser le temps de réponse de vos sites pour tous vos utilisateurs. Toute connexion à votre site va créer un flux de données consommant du quota (limitation du volume total qui peut transiter vers et depuis votre CDN).

**Ce guide vous détaille toutes les informations sur la gestion du quota sur votre CDN.**

## Prérequis

- Bénéficier du [Content Delivery Network (CDN) d'OVHcloud](https://www.ovhcloud.com/fr/network/cdn/).

[[cpnav:network-cdn]]

## En pratique

### Renouveler votre quota

{/* CP-STEPS-START:order-quota */}

Lors de votre commande, **1 To** de trafic vous est offert. Attention, ce quota n'est pas renouvelé chaque mois avec votre offre. En effet, une fois ce volume consommé (quelle que soit la durée), vous devrez en ajouter à nouveau.

Le trafic qu'il vous reste est indiqué dans l'onglet **Vue d'ensemble** de votre CDN, dans la partie **Utilisation**, sous **Volume de trafic**. Si vous avez besoin de quota supplémentaire, cliquez sur <code className="action">Ajouter un add-on</code> dans cette partie. Dans la fenêtre **Ajouter un add-on**, sélectionnez **Volume de trafic** dans la liste **Add-on**, choisissez la quantité de bande passante dans la liste **Option**, cochez **J'ai lu et j'accepte les conditions générales de vente**, puis cliquez sur <code className="action">Ajouter</code>. La page de paiement s'ouvre pour finaliser votre commande.

<img className="thumbnail" alt="Onglet Vue d'ensemble d'un CDN avec la partie Utilisation" src="/images/network/content-delivery-network-infrastructure/quota/overview-usage.png" loading="lazy" />

<img className="thumbnail" alt="Fenêtre Ajouter un add-on avec une option Volume de trafic" src="/images/network/content-delivery-network-infrastructure/quota/add-addon.png" loading="lazy" />

Retrouvez les tarifications de ce quota sur [notre site](https://www.ovhcloud.com/fr/network/cdn/).

Une alerte vous est automatiquement envoyée lorsqu'il vous reste **100 Go** de quota pour que vous puissiez planifier un nouvel achat de bande passante. S'il ne vous reste plus de quota, la fonction *bypass* sera automatiquement activée jusqu'à ce que vous possédiez de nouveau du quota disponible.

{/* CP-STEPS-END:order-quota */}

### Le trafic facturé sur l'offre CDN

:::info
L'ensemble du trafic sortant par le CDN vous est facturé.  

:::

{/* CP-STEPS-START:traffic-example */}

Le trafic de votre CDN se compose de deux types de requêtes, que vous pouvez suivre dans l'onglet <code className="action">Statistiques</code> (**Bande passante** et **Performance du cache**) :

- **Les fichiers déjà mis en cache** : le CDN répond directement aux requêtes concernant ces fichiers.

- **Les fichiers appelés sur le *back end*** : les règles de cache appliquées sur votre domaine, gérées dans l'onglet <code className="action">Règles de cache</code>, déterminent ce qui sera mis en cache et ce qui devra être appelé directement sur votre *back end*.

{/* CP-STEPS-END:traffic-example */}

Que les fichiers soient pris en cache ou appelés sur le *back end* en passant par le CDN, **les deux trafics seront soustraits de votre quota**. C'est pourquoi nous vous conseillons de créer un sous-domaine spécifique qui sera appelé pour les fichiers devant être pris en cache et conserver des domaines pointant vers votre *back end* pour les autres fichiers.
