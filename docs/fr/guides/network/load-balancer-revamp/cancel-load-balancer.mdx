## Objectif

La résiliation met fin à votre service Load Balancer, soit immédiatement, soit à l'expiration de sa période en cours, selon la méthode choisie.

**Ce guide explique comment résilier un OVHcloud Load Balancer depuis la <ManagerLink to="/">console OVHcloud</ManagerLink> ou via l'API OVHcloud.**

:::danger
La résiliation d'un Load Balancer est irréversible une fois la suppression confirmée. Lorsque le service est supprimé, son adresse IP, ses frontends, ses fermes de serveurs, ses sondes, ses routes et ses certificats SSL sont définitivement supprimés. Tout trafic pointant encore vers l'adresse IP du Load Balancer cessera d'être réparti vers vos serveurs backend. Assurez-vous d'avoir redirigé votre trafic de production ailleurs avant de poursuivre.
:::

## Prérequis

- Un <ManagerLink to="/">compte OVHcloud</ManagerLink> actif
- Un service OVHcloud Load Balancer existant dans votre compte
- Les droits d'administration nécessaires pour résilier un service

## Introduction

Les effets d'une résiliation dépendent du chemin que vous empruntez dans la console OVHcloud. La résiliation depuis la section **Abonnement** de l'onglet <code className="action">Vue d'ensemble</code> du Load Balancer est immédiate et irréversible. La résiliation de l'abonnement depuis la page **Mes offres & services** affiche la date d'expiration du service. Dans les deux cas, la configuration est supprimée lorsque le service est résilié ; planifiez donc votre migration de trafic à l'avance.

Avant de résilier, vérifiez qu'aucun enregistrement DNS, aucune application et aucun service en amont ne dépend encore de l'adresse IP du Load Balancer. Pour comprendre la structure du service, consultez le guide [Présentation d'OVHcloud Load Balancer](/guides/network/load-balancer-revamp/what-is-load-balancer).

## En pratique

Vous pouvez résilier votre Load Balancer depuis la console OVHcloud ou via l'API OVHcloud. Choisissez la méthode qui correspond à vos habitudes de travail.

{/* CP-STEPS-START:cancel-service */}
<Tabs>
<Tab label="Console">

La console OVHcloud propose deux façons de résilier un Load Balancer. Toutes deux partent de la section **Abonnement** de l'onglet <code className="action">Vue d'ensemble</code> de votre Load Balancer.

**Depuis la section Abonnement**

1. Dans la section **Abonnement**, cliquez sur <code className="action">Résilier</code>. La fenêtre **Résilier le service** s'ouvre.
2. Dans le champ **Confirmation**, saisissez `terminate`, puis cliquez sur <code className="action">Résilier</code>.

:::warning
Cette action est irréversible.
:::

**Depuis la page Mes offres & services**

1. Dans la section **Abonnement**, cliquez sur <code className="action">Gérer mon abonnement</code>. La page **Mes offres & services** s'ouvre dans un nouvel onglet du navigateur.
2. Sur la ligne de votre Load Balancer (type **Ip Load Balancing**), cliquez sur le bouton <code className="action">⋮</code>, puis sélectionnez <code className="action">Résilier mon service</code>. La fenêtre **Résilier le service** s'ouvre.
3. Répondez aux deux questions obligatoires : le motif de la résiliation et **Que prévoyez-vous de faire ?**
4. Cliquez sur <code className="action">Résilier</code> pour confirmer.

:::warning
Vous perdrez toutes les données associées à ce service.
:::

</Tab>
<Tab label="API OVHcloud">

La résiliation d'un service via l'API OVHcloud se déroule en deux étapes : vous demandez la résiliation, puis vous la confirmez à l'aide du jeton que vous recevez.

1. Demandez la résiliation du service. Cet appel renvoie un jeton de confirmation, généralement envoyé par e-mail.

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/confirmTermination"} />

| Paramètre | Obligatoire | Description | Exemple |
|---|---|---|---|
| `serviceName` | Oui | L'identifiant unique de votre service Load Balancer. | `loadbalancer-a1b2c3d4` |
| `token` (body) | Oui | Le jeton de confirmation reçu après la demande de résiliation. | `xxxxxxxxxxxxxxxx` |
| `reason` (body) | Non | Le motif de la résiliation, utilisé à des fins de retour d'expérience. | `MIGRATED_TO_ANOTHER_OVH_PRODUCT` |

2. Confirmez la résiliation en soumettant le jeton avec l'appel ci-dessus. Une fois l'appel réussi, la résiliation est planifiée selon les paramètres d'expiration du service.

:::info
Pour consulter ou ajuster le moment où le service cesse de se renouveler, examinez les informations du service avec `GET /ipLoadbalancing/{serviceName}/serviceInfos`.
:::

</Tab>
<Tab label="Terraform">

La résiliation d'un service est généralement gérée en dehors de Terraform. Supprimer la ressource `ovh_iploadbalancing` de votre configuration et exécuter `terraform destroy` supprime les ressources gérées, mais n'entraîne pas nécessairement la résiliation de l'abonnement au service sous-jacent. Résiliez le service depuis la console OVHcloud ou via l'API OVHcloud pour interrompre le renouvellement.

</Tab>
</Tabs>

### Vérifier la résiliation

Après avoir confirmé, vérifiez que la résiliation a bien été enregistrée.

{/* CP-STEPS-START:verify-cancellation */}
- Dans la console OVHcloud, ouvrez votre Load Balancer puis, dans la section **Abonnement** de l'onglet <code className="action">Vue d'ensemble</code>, vérifiez le **Mode de renouvellement** et la **Date de renouvellement** du service.
- Avec l'API, appelez `GET /ipLoadbalancing/{serviceName}/serviceInfos` et vérifiez les champs d'expiration et de renouvellement.
{/* CP-STEPS-END:verify-cancellation */}

:::warning
Tant que la date de résiliation n'est pas atteinte, le trafic continue d'être réparti si le Load Balancer est toujours configuré. Redirigez votre trafic de production hors de l'adresse IP du Load Balancer avant que le service ne soit résilié, afin d'éviter toute interruption de service.
:::
