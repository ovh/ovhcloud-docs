## Objectif

La solution Web Cloud Databases permet de bénéficier d’une instance de bases de données dont les ressources sont dédiées et garanties, vous offrant performances et flexibilité.
Par défaut, votre solution Web Cloud Databases est liée au réseau d’hébergements web OVHcloud. Vous pouvez aussi la lier à n’importe quel autre réseau, via une liste d’adresses IP autorisées.

**Découvrez comment bien débuter avec la solution Web Cloud Databases.**

## Prérequis

- Disposer d’une [instance Web Cloud Databases](/links/web/databases) (incluse dans une offre d’[hébergement web](/links/web/hosting) Performance, Agency, Agency Plus ou Agency Max).

[[cpnav:web-cloud-databases]]

## En pratique

### Activation de votre serveur Web Cloud Databases inclus avec votre offre d’hébergement web

{/* CP-STEPS-START:activation */}

Si votre offre d’hébergement inclut l’option Web Cloud Databases, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

:::warning
L’activation de cette option nécessite que vous soyez au minimum contact administrateur de l’hébergement web qui inclut le service Web Cloud Databases. Pour plus d’informations sur la gestion des contacts, consultez notre guide « [Gérer les contacts de ses services](/guides/account-and-service-management/account-information/managing-contacts) ».

:::

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans l’onglet <code className="action">Vue d'ensemble</code>, repérez la section **Bases de données**. La ligne **Web Cloud DB** indique que votre instance n’est pas encore activée. Cliquez sur <code className="action">Activer</code>, sous cette ligne.

    <img className="thumbnail" alt="Section Bases de données de l’hébergement avec le lien Activer de la ligne Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Sur la page **Activer Web Cloud DB** qui s’affiche, choisissez la capacité de votre instance (la capacité de 512 Mo est incluse dans votre offre d’hébergement, les capacités supérieures sont payantes), puis son moteur (PostgreSQL, MariaDB, MySQL ou Valkey) et sa **Version**. Cliquez ensuite sur <code className="action">Activer</code>.

    <img className="thumbnail" alt="Page Activer Web Cloud DB avec le choix de la capacité, du moteur et de la version" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate-page.png" loading="lazy" />

    Votre instance sera ensuite accessible depuis la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.
  </Tab>
</Tabs>

  </Tab>
  <Tab label="Étape 2">
    Assurez-vous d’être bien positionné sur l’onglet <code className="action">Vue d'ensemble</code>.

    |Information|Détails|
    |---|---|

    |Moteur|Affiche le système de bases de données utilisé par le serveur et sa version. Veillez à la compatibilité de votre site avec la version choisie.|
    |Région|Affiche la région du centre de données dans lequel l’instance a été créée.|
    |Host|Affiche le serveur OVHcloud dans lequel votre instance est créée. Il s’agit d’une information inhérente à l’infrastructure d’OVHcloud et peut être utilisée dans nos communications liées aux [incidents OVHcloud](https://www.status-ovhcloud.com/).|

    |RAM|Affiche la mémoire vive disponible pour votre instance ainsi que les éventuels dépassements de mémoire. Votre instance Web Cloud Databases dispose de ressources dédiées et garanties : sa mémoire RAM. Si besoin, vous pouvez faire évoluer cette dernière avec le lien **Commander plus de RAM**.|
    |Quota de stockage|Affiche l’espace occupé par vos données sur celui inclus dans votre offre. Une fois ce quota atteint, les écritures échouent : vous devez alors supprimer des données ou passer à une offre supérieure.|

    <img className="thumbnail" alt="Onglet Bases de données d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Cliquez sur <code className="action">Ajouter une base de données</code>, au-dessus du tableau des bases de données.

    <img className="thumbnail" alt="Bouton Ajouter une base de données au-dessus du tableau des bases" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    La création de schémas PostgreSQL est actuellement indisponible sur les serveurs Web Cloud Databases.

    :::

  </Tab>
  <Tab label="Étape 4">
    Le panneau **Ajouter une base de données** s’ouvre à droite. Renseignez les champs en respectant les critères indiqués sous chacun d’eux :

    - **Nom de la base** (obligatoire) : il s’agit du nom de votre future base de données.
    - **Accès à cette base** : choisissez qui pourra se connecter à la base de données et y effectuer des requêtes.
        - **Aucun accès pour l’instant** (choix par défaut) : la base de données est créée sans utilisateur. Vous pourrez attribuer des droits à un utilisateur par la suite.
        - **Un utilisateur existant** : sélectionnez l’**Utilisateur** puis ses **Droits** sur la base de données.
        - **Un nouvel utilisateur** : renseignez les champs ci-dessous pour créer l’utilisateur en même temps que la base de données.
    - **Nom d’utilisateur** (seulement avec **Un nouvel utilisateur**) : il s’agit de l’utilisateur qui pourra se connecter à votre base de données et y effectuer des requêtes.
    - **Droits** (avec **Un utilisateur existant** ou **Un nouvel utilisateur**) : il s’agit des droits qui seront associés à l’utilisateur sur la base de données. Pour une utilisation classique, sélectionnez `Admin`. Les droits peuvent être modifiés par la suite.
    - **Mot de passe**/**Confirmer le mot de passe** (seulement avec **Un nouvel utilisateur**) : saisissez un mot de passe, puis confirmez ce dernier.

    Cliquez sur <code className="action">Ajouter</code>.

    <img className="thumbnail" alt="Panneau Ajouter une base de données avec un nouvel utilisateur" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

### Création d’un utilisateur

{/* CP-STEPS-START:creation-utilisateur */}

:::info
Cette étape ne s’applique pas au système de bases de données Valkey.

:::

Si votre projet ne nécessite pas un utilisateur additionnel, vous pouvez passer à la manipulation suivante. Dans le cas contraire, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

### Importation d’une base de données

Cette étape s’applique si vous souhaitez importer une sauvegarde d’une base de données déjà existante. Si ce n’est pas le cas, passez à la manipulation suivante.

:::

### Autoriser une adresse IP

Afin que l’accès à votre instance Web Cloud Databases fonctionne, il est obligatoire d’indiquer les IP ou plages d’IP pouvant se connecter à vos bases de données.

{/* CP-STEPS-START:autoriser-ip */}

Pour cela, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances du compte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page qui s’affiche, cliquez sur l’onglet <code className="action">IP autorisées</code>.

    <img className="thumbnail" alt="Onglet IP autorisées d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Sur la page qui apparaît, cliquez sur le bouton <code className="action">Ajouter une IP</code> situé au-dessus du tableau.

    <img className="thumbnail" alt="Bouton Ajouter une IP au-dessus du tableau des IP autorisées" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Si vous souhaitez modifier une adresse IP ou une plage d’adresses IP déjà autorisée, cliquez directement dans le tableau sur le bouton <code className="action">⋮</code> de la colonne **Actions**, à droite de la ligne correspondant à l’adresse IP ou à la plage d’adresses IP à modifier, puis sur <code className="action">Modifier</code>. Vous pourrez changer son nom et ses autorisations ; l’adresse IP elle-même n’est pas modifiable.

    <img className="thumbnail" alt="Menu d’une ligne du tableau des IP autorisées" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Étape 4">
    Dans la fenêtre **Ajouter une IP autorisée** qui s’ouvre, plusieurs champs sont à compléter :

    <img className="thumbnail" alt="Fenêtre Ajouter une IP autorisée et ses champs" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (obligatoire) : Saisissez ici l’adresse IP (par exemple : `203.0.113.44`) ou la plage d’adresses IP (par exemple : `203.0.113.0/24` représentant toutes les adresses IP de `203.0.113.0` à `203.0.113.255`) que vous souhaitez autoriser sur votre solution Web Cloud Databases.
    - **Nom** (obligatoire) : Vous pouvez, par exemple, y indiquer le rôle de l’adresse IP ou de la plage d’adresses IP concernée.
    - **Autoriser l’accès au service** (cochée par défaut) : Cochez cette case pour que l’adresse IP ou la plage d’adresses IP soit autorisée à accéder aux bases de données présentes sur votre solution Web Cloud Databases.
    - **Autoriser l’accès SFTP** : Cochez cette case pour que l’adresse IP ou la plage d’adresses IP soit autorisée à accéder aux logs de votre solution Web Cloud Databases.

    :::warning
    Il est fortement déconseillé de cocher la case **Autoriser l’accès au service** pour autoriser la plage d’adresses IP `0.0.0.0/0` à accéder à vos bases de données.

    En effet, cela permettrait d’autoriser l’accès à vos bases de données à l’ensemble des adresses IPv4 existantes.

    :::

    Une fois les informations saisies, cliquez sur le bouton <code className="action">Ajouter</code>.
  </Tab>
</Tabs>

{/* CP-STEPS-END:autoriser-ip */}

### Autoriser la connexion à un hébergement web OVHcloud <a name="trustip"></a>

Par défaut, votre solution Web Cloud Databases est automatiquement liée aux hébergements web OVHcloud. Si vous le souhaitez, vous pouvez cependant désactiver l’accès des hébergements web OVHcloud à votre base de données Web Cloud Databases.

Pour cela, consultez les cas particuliers de notre guide « [Web Cloud Databases - Comment autoriser une adresse IP ?](/guides/web-cloud/databases/db-authorise-ip-mask) » pour activer / désactiver l’accès des hébergements web OVHcloud à votre base de données Web Cloud Databases.

### Lier votre site à la base de données

Maintenant que votre base de données est créée, qu’un ou plusieurs utilisateurs disposent de droits sur cette dernière et qu’au minimum une adresse IP ou que les hébergements web OVHcloud ont été autorisés sur votre instance Web Cloud Databases, il ne reste plus qu’à lier votre site à votre base de données. Cette étape peut s’effectuer de plusieurs manières, en fonction du site ou du CMS (WordPress, Joomla!, etc.) utilisé, ainsi que de l’étape à laquelle vous vous trouvez si vous installez un site web.

Pour cela, vous devez disposer des 5 informations suivantes :

|Information|Description|
|---|---|
|Nom de la base de données|Il s’agit du nom que vous avez défini lors de la création de la base de données.|
|Nom d’utilisateur|Il s’agit du nom d’utilisateur que vous avez défini lors de la création de la base de données ou d’un éventuel utilisateur additionnel que vous auriez ajouté.|
|Mot de passe de l’utilisateur|Il s’agit du mot de passe, lié à l’utilisateur, que vous avez défini lors des manipulations précédentes.|
|Nom d’hôte du serveur|Il s’agit du serveur à renseigner pour que votre site web puisse se connecter à votre base de données.|
|Port du serveur|Il s’agit du port de connexion à votre instance Web Cloud Databases pour que votre site puisse se connecter à votre base de données. |

{/* CP-STEPS-START:lier-site */}

Pour les retrouver, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances du compte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Récupérez les informations de connexion suivantes :

    - **Serveur (nom d’hôte) et port :** visibles dans l’onglet <code className="action">Vue d'ensemble</code>, section **SQL**, mentions **Nom d'hôte** et **Port**.
    - **Utilisateur :** visible dans l’onglet <code className="action">Utilisateurs et droits</code>.
    - **Mot de passe :** le mot de passe associé à l’utilisateur. Si vous l’avez oublié, rendez-vous dans l’onglet <code className="action">Utilisateurs et droits</code>, cliquez sur le bouton <code className="action">⋮</code> de l’utilisateur concerné, puis sur <code className="action">Modifier le mot de passe</code>.

    <img className="thumbnail" alt="Section SQL de la vue d’ensemble avec le nom d’hôte et le port" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />

    :::warning
    Si vous changez le mot de passe de l’utilisateur d’une base de données, toutes les applications/sites web qui accèdent à cette base doivent être mises à jour en conséquence.

    :::

  </Tab>
</Tabs>

:::warning
Le champ <code className="action">port</code> peut ne pas être proposé dans la configuration de votre site web. Vous devez ajouter ce champ après le nom d’hôte de votre serveur en les séparant par un *:* .

Par exemple, pour le nom d’hôte `aaXXXXX-XXX.eu.clouddb.ovh.net` avec comme port SQL `12345`, vous devrez renseigner `aaXXXXX-XXX.eu.clouddb.ovh.net:12345` dans la partie « Hôte » / « Nom d’hôte ».

:::

{/* CP-STEPS-END:lier-site */}

:::info
OVHcloud ne propose pas de port chiffré via TLS sur les serveurs de bases de données Valkey. Les communications doivent passer uniquement par le port par défaut, non chiffré.

:::
