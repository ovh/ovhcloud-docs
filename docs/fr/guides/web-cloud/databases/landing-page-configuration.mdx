## Configurer votre service Web Cloud Databases

Configurez et administrez votre service Web Cloud Databases OVHcloud : accès, bases de données, utilisateurs et droits, connexion, extensions PostgreSQL et logs.

Pour vous orienter selon votre besoin :

- **Vous souhaitez ouvrir l'accès et vous connecter à vos bases de données ?** Consultez la section *Accès et connexion*.
- **Vous désirez gérer vos bases de données, vos utilisateurs et leurs droits ?** Consultez la section *Bases de données et utilisateurs*.
- **Vous devez administrer le serveur (configuration, logs) ?** Consultez la section *Serveur et exploitation*.
