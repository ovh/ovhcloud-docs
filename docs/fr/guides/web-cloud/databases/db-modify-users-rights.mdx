## Objectif

La solution [Web Cloud Databases](/links/web/databases) peut contenir plusieurs bases de données. Elle permet de définir un ou plusieurs utilisateurs pour la gestion et l’utilisation de vos bases de données. Ces utilisateurs peuvent avoir des droits plus ou moins élevés en fonction de leurs rôles au niveau de vos bases de données.
Au cours de l’utilisation du produit, vous pouvez être amené à modifier les droits d’un utilisateur sur votre [Web Cloud Databases](/links/web/databases).

**Découvrez comment modifier les droits d’un utilisateur sur votre solution Web Cloud Databases.**

## Prérequis

- Disposer d’une solution [Web Cloud Databases](/links/web/databases) et d’un ou plusieurs utilisateurs.

[[cpnav:web-cloud-databases]]

## En pratique

:::info
Pour créer un nouvel utilisateur sur votre solution Web Cloud Databases, consultez la section **Créer un utilisateur** de notre guide « [Créer vos bases de données et vos utilisateurs sur votre serveur de bases de données](/guides/web-cloud/databases/db-create-databases-users) ».

:::

{/* CP-STEPS-START:modifier-droits */}
Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances du compte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page qui s’affiche, cliquez sur l’onglet <code className="action">Utilisateurs et droits</code>.

    <img className="thumbnail" alt="Onglet Utilisateurs et droits d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Chaque utilisateur s’affiche dans un encadré à son nom. Dans l’encadré de l’utilisateur concerné, cliquez sur le bouton <code className="action">⋮</code> situé à droite de la mention **Actions supplémentaires**, puis sur <code className="action">Gérer les droits</code>.

    <img className="thumbnail" alt="Menu Actions supplémentaires d’un utilisateur et entrée Gérer les droits" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Le panneau **Droits de** suivi du nom de l’utilisateur s’ouvre à droite. Il recense toutes les bases de données présentes sur votre solution Web Cloud Databases et indique, pour chacune d’elles, le niveau de droits dont votre utilisateur dispose, dans un menu déroulant à sa droite.

    <img className="thumbnail" alt="Panneau des droits d’un utilisateur, un niveau par base de données" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />

    C’est à cet endroit que vous pourrez modifier les droits de votre utilisateur pour chacune de vos bases de données. Pour cela et pour chacune des bases de données concernées, il vous suffit de sélectionner, dans le menu déroulant de la base, le niveau de droits que vous souhaitez attribuer à votre utilisateur. La modification est effective immédiatement : le message **Droit modifié** s’affiche.
  </Tab>
</Tabs>
{/* CP-STEPS-END:modifier-droits */}
