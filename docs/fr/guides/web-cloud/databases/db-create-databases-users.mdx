## Objectif

Une base de données (*database*, « DB » ou « BDD ») permet de stocker des éléments dits dynamiques, comme des commentaires ou des articles par exemple. Ces bases sont aujourd’hui utilisées par la quasi-totalité des systèmes de gestion de contenu (*Content Management System* ou CMS) comme WordPress ou Joomla!.

**Découvrez comment créer une base de données sur votre serveur de bases de données.**

## Prérequis

- Disposer d’une [instance Web Cloud Databases](/links/web/databases) (incluse dans une offre d’[hébergement web](/links/web/hosting) Performance, Agency, Agency Plus ou Agency Max).

[[cpnav:web-cloud-databases]]

## En pratique

### Créer une base de données

{/* CP-STEPS-START:creer-base-de-donnees */}
Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances du compte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Bases de données</code>.

    <img className="thumbnail" alt="Onglet Bases de données d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Cliquez sur <code className="action">Ajouter une base de données</code>, au-dessus du tableau des bases de données.

    <img className="thumbnail" alt="Bouton Ajouter une base de données au-dessus du tableau des bases" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    La création de schémas PostgreSQL est actuellement indisponible sur les serveurs Web Cloud Databases.

    :::

  </Tab>
  <Tab label="Étape 4">
    Le panneau **Ajouter une base de données** s’ouvre à droite. Renseignez les champs en respectant les critères indiqués sous chacun d’eux :

    - **Nom de la base** (obligatoire) : il s’agit du nom de votre future base de données.
    - **Accès à cette base** : choisissez qui pourra se connecter à la base de données et y effectuer des requêtes.
        - **Aucun accès pour l’instant** (choix par défaut) : la base de données est créée sans utilisateur. Vous pourrez attribuer des droits à un utilisateur par la suite.
        - **Un utilisateur existant** : sélectionnez l’**Utilisateur** puis ses **Droits** sur la base de données.
        - **Un nouvel utilisateur** : renseignez les champs ci-dessous pour créer l’utilisateur en même temps que la base de données.
    - **Nom d’utilisateur** (seulement avec **Un nouvel utilisateur**) : il s’agit de l’utilisateur qui pourra se connecter à votre base de données et y effectuer des requêtes.
    - **Droits** (avec **Un utilisateur existant** ou **Un nouvel utilisateur**) : il s’agit des droits qui seront associés à l’utilisateur sur la base de données. Pour une utilisation classique, sélectionnez `Admin`. Les droits peuvent être modifiés par la suite.
    - **Mot de passe**/**Confirmer le mot de passe** (seulement avec **Un nouvel utilisateur**) : saisissez un mot de passe, puis confirmez ce dernier.

    Cliquez sur <code className="action">Ajouter</code>.

    <img className="thumbnail" alt="Panneau Ajouter une base de données avec un nouvel utilisateur" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>
{/* CP-STEPS-END:creer-base-de-donnees */}

### Créer un utilisateur

Pour utiliser un serveur de bases de données OVHcloud, créez des utilisateurs avec des droits spécifiques de connexion à une base de données.

{/* CP-STEPS-START:creer-utilisateur */}
Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances du compte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Utilisateurs et droits</code>.

    <img className="thumbnail" alt="Onglet Utilisateurs et droits d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Cliquez sur <code className="action">Ajouter un utilisateur</code>.
  </Tab>
  <Tab label="Étape 4">
    Le panneau **Ajouter un utilisateur** s’ouvre à droite. Renseignez un **Nom d’utilisateur**, puis un **Mot de passe** que vous confirmez dans le champ **Confirmer le mot de passe**, en respectant les critères indiqués sous chaque champ. Cliquez ensuite sur <code className="action">Ajouter</code>.

    <img className="thumbnail" alt="Panneau Ajouter un utilisateur et ses trois champs" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/add-user.png" loading="lazy" />
  </Tab>
</Tabs>
{/* CP-STEPS-END:creer-utilisateur */}

### Gérer les droits des utilisateurs

Pour autoriser un utilisateur à effectuer des actions sur une base de données, il est nécessaire de lui attribuer des droits.

{/* CP-STEPS-START:gerer-droits-utilisateurs */}
Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances du compte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Utilisateurs et droits</code>.

    <img className="thumbnail" alt="Onglet Utilisateurs et droits d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Chaque utilisateur s’affiche dans un encadré à son nom. Dans l’encadré de l’utilisateur concerné, cliquez sur le bouton <code className="action">⋮</code> situé à droite de la mention **Actions supplémentaires**, puis sur <code className="action">Gérer les droits</code>.

    <img className="thumbnail" alt="Menu Actions supplémentaires d’un utilisateur et entrée Gérer les droits" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Le panneau **Droits de** suivi du nom de l’utilisateur s’ouvre à droite. Il liste les bases de données présentes sur votre serveur, chacune avec, à sa droite, un menu déroulant indiquant le niveau de droits de l’utilisateur sur cette base. Choisissez le niveau souhaité pour chaque base de données.

    4 niveaux de droits sont proposés :

    - `Admin` : autorisation des requêtes de type **Select / Insert / Update / Delete / Create / Alter / Drop**.
    - `Lecture / Écriture` : autorisation des requêtes de type **Select / Insert / Update / Delete**.
    - `Lecture seule` : autorisation des requêtes de type **Select**.
    - `Aucun` : aucun droit sur la base.

    :::info
    La segmentation des droits mentionnés ci-dessus est propre à OVHcloud. Ainsi un utilisateur ayant les droits `Admin` pourra faire du **DDL** (Data Definition Language) et du **DML** (Data Manipulation Language) alors qu’un utilisateur ayant les droits `Lecture / Écriture` ne fera que du **DML** (Data Manipulation Language).

    :::

    <img className="thumbnail" alt="Panneau des droits d’un utilisateur, un niveau par base de données" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />
  </Tab>
</Tabs>
{/* CP-STEPS-END:gerer-droits-utilisateurs */}

### Supprimer une base de données

:::warning
Pour supprimer une base de données sur un serveur de bases de données, il n’y a pas de
vérification sur le contenu de la base. Celle-ci sera donc supprimée même si
des données y sont encore enregistrées, il est donc recommandé de réaliser
une sauvegarde et de la télécharger de votre côté avant toute suppression.

:::

{/* CP-STEPS-START:supprimer-base-de-donnees */}
Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances du compte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Bases de données</code>.

    <img className="thumbnail" alt="Onglet Bases de données d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le tableau, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, à droite de la base de données concernée, puis sur <code className="action">Supprimer</code>.

    <img className="thumbnail" alt="Menu d’une ligne du tableau des bases de données Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    Dans la fenêtre **Supprimer la base de données** qui s’ouvre, confirmez la suppression en cliquant sur <code className="action">Supprimer</code>.

    <img className="thumbnail" alt="Fenêtre de confirmation de la suppression d’une base de données" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/delete-database-dialog.png" loading="lazy" />
  </Tab>
</Tabs>
{/* CP-STEPS-END:supprimer-base-de-donnees */}
