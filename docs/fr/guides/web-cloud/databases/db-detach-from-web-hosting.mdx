## Objectif

Les solutions [Web Cloud Databases](/links/web/databases) peuvent être activées gratuitement à partir de nos [offres d’hébergement web](/links/web/hosting) Performance, Agency, Agency Plus et Agency Max. Dans ce cas de figure, elles sont alors associées à l’hébergement web depuis lequel elles ont été activées. Au cours de l’utilisation de vos services, vous pouvez être amenés à devoir délier votre solution Web Cloud Databases de l’hébergement web auquel elle est associée.

**Découvrez comment délier votre solution Web Cloud Databases d’un hébergement web.**

## Prérequis

- Disposer d’une [instance Web Cloud Databases](/links/web/databases) associée à une offre d’[hébergement web](/links/web/hosting) Performance, Agency, Agency Plus ou Agency Max.
- Être, a minima, contact « [Administrateur](/guides/account-and-service-management/account-information/managing-contacts) » des services sur lesquels vous souhaitez agir.

[[cpnav:web-hosting]]

## En pratique

{/* CP-STEPS-START:delier-web-cloud-databases */}
Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans la section **Bases de données**, vous trouverez la mention **Web Cloud DB**. Cliquez sur le bouton <code className="action">⋮</code> à droite de celle-ci, puis sur <code className="action">Délier ma base de données PrivateSQL</code>.

    <img className="thumbnail" alt="Section Bases de données et menu de la ligne Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Sur la nouvelle page qui s’affiche, choisissez la durée d’**Engagement** désirée pour votre solution Web Cloud Databases. Le **Récapitulatif** rappelle que votre base de données sera désormais facturée au prix standard et que cette action est irréversible. Cliquez sur <code className="action">Suivant</code>, puis suivez les étapes indiquées jusqu’au paiement.

    <img className="thumbnail" alt="Page Délier ma base de données PrivateSQL, offre, engagement et récapitulatif" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/detach-web-cloud-db.png" loading="lazy" />
  </Tab>
</Tabs>

Une fois ces 3 étapes réalisées et le bon de commande payé, votre solution Web Cloud Databases sera déliée dans un délai de quelques heures maximum.
{/* CP-STEPS-END:delier-web-cloud-databases */}
