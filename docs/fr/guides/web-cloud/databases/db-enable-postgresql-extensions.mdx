## Objectif

Les extensions PostgreSQL sont des modules qui enrichissent votre base de données avec des fonctionnalités supplémentaires : nouveaux types de données, fonctions, opérateurs ou langages procéduraux. Sur une solution Web Cloud Databases, vous pouvez activer les extensions compatibles directement depuis votre espace client OVHcloud, sans intervention en ligne de commande.

**Ce guide vous explique comment activer les extensions disponibles sur une base de données PostgreSQL hébergée sur une solution Web Cloud Databases.**

## Prérequis

- Disposer d’une [instance Web Cloud Databases](/links/web/databases) utilisant **PostgreSQL**.
- Avoir consulté le guide « [Démarrez avec PostgreSQL](/guides/web-cloud/databases/db-getting-started-postgresql) ».

## En pratique

### Activer une extension

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/#/web/web/private_database">Web Cloud Databases</ManagerLink>, puis choisissez le service concerné.

    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Bases de données</code>. Dans la colonne **« Extensions »**, cliquez sur l’icône en forme de tableau pour la base de données concernée.

    <img className="thumbnail" alt="Accéder aux extensions d’une base de données" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/databases/extensions.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans la fenêtre qui s’affiche, repérez l’extension souhaitée dans la liste des extensions disponibles. Activez-la ensuite en cliquant sur l’icône correspondante dans la colonne **« Actif »**.

    <img className="thumbnail" alt="Liste des extensions PostgreSQL" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/databases/extensions-list.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
L’activation d’une extension s’applique à la base de données sélectionnée. Pour l’activer sur une autre base de données du même serveur, répétez l’opération en sélectionnant la base concernée.

:::

### Extensions disponibles

La liste des extensions proposées dépend de la version de PostgreSQL utilisée par votre serveur. Les extensions disponibles pour votre version sont affichées dans la fenêtre d’activation.

Voici la liste des extensions disponibles :

| Extension | Description |
|---|---|
| `address_standardizer` | Analyse une adresse pour la décomposer en éléments distincts. Généralement utilisée pour l’étape de normalisation d’adresse du géocodage. |
| `autoinc` | Fonctions pour l’auto-incrémentation de champs. |
| `bloom` | Méthode d’accès bloom — index basé sur un fichier de signatures. |
| `btree_gin` | Prise en charge de l’indexation des types de données courants dans GIN. |
| `btree_gist` | Prise en charge de l’indexation des types de données courants dans GiST. |
| `citext` | Type de données pour les chaînes de caractères insensibles à la casse. |
| `cube` | Type de données pour les cubes multidimensionnels. |
| `earthdistance` | Calcul des distances orthodromiques à la surface de la Terre. |
| `fuzzystrmatch` | Détermine les similarités et la distance entre des chaînes de caractères. |
| `hstore` | Type de données pour le stockage d’ensembles de paires (clé, valeur). |
| `intarray` | Fonctions, opérateurs et prise en charge de l’indexation pour les tableaux d’entiers à une dimension. |
| `isn` | Types de données pour les standards internationaux de numérotation de produits. |
| `ltree` | Type de données pour les structures arborescentes hiérarchiques. |
| `moddatetime` | Fonctions pour le suivi de la date de dernière modification. |
| `pg_trgm` | Mesure de similarité de texte et recherche par index basées sur les trigrammes. |
| `pgcrypto` | Fonctions cryptographiques. |
| `postgis` | Types et fonctions spatiales de PostGIS (géométrie, géographie et raster). |
| `postgis_raster` | Types et fonctions raster de PostGIS. |
| `postgis_tiger_geocoder` | Géocodeur (et géocodeur inverse) Tiger de PostGIS. |
| `postgis_topology` | Types et fonctions spatiales de topologie de PostGIS. |
| `seg` | Type de données pour représenter des segments de droite ou des intervalles de nombres à virgule flottante. |
| `unaccent` | Dictionnaire de recherche textuelle qui supprime les accents. |
| `uuid-ossp` | Génère des identifiants uniques universels (UUID). |
| `xml2` | Requêtes XPath et XSLT. |
