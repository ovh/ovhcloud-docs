## Objectif

Les solutions [Web Cloud Databases](/links/web/databases) peuvent être utilisées avec des services OVHcloud ou externes à OVHcloud.

Par défaut et pour des raisons de sécurité, sur ces solutions :

- Seules les adresses IP liées à notre infrastructure d’hébergements mutualisés sont autorisées à accéder au contenu des bases de données.
- L’accès aux logs de la solution n’est pas restreint en fonction des adresses IP. Cela permet d’y accéder via un ordinateur par exemple.

Vous avez besoin de modifier ces autorisations/restrictions ?

**Découvrez comment autoriser une ou plusieurs adresses IP à accéder à votre solution Web Cloud Databases.**

## Prérequis

- Disposer d’une solution [Web Cloud Databases](/links/web/databases).
- Connaître l’adresse IP (ou la plage d’adresses IP) à autoriser sur votre solution.

[[cpnav:web-cloud-databases]]

## En pratique

### Autoriser une adresse IP ou une plage d’adresses IP

:::info
Pour rappel, si vous venez d’activer votre solution [Web Cloud Databases](/links/web/databases) et que vous souhaitez l’utiliser avec une offre d’[hébergement web OVHcloud](/links/web/hosting), les adresses IP de ces offres sont déjà autorisées par défaut.

:::

{/* CP-STEPS-START:autoriser-ip */}
Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances du compte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page qui s’affiche, cliquez sur l’onglet <code className="action">IP autorisées</code>.

    <img className="thumbnail" alt="Onglet IP autorisées d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Sur la page qui apparaît, cliquez sur le bouton <code className="action">Ajouter une IP</code> situé au-dessus du tableau.

    <img className="thumbnail" alt="Bouton Ajouter une IP au-dessus du tableau des IP autorisées" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Si vous souhaitez modifier une adresse IP ou une plage d’adresses IP déjà autorisée, cliquez directement dans le tableau sur le bouton <code className="action">⋮</code> de la colonne **Actions**, à droite de la ligne correspondant à l’adresse IP ou à la plage d’adresses IP à modifier, puis sur <code className="action">Modifier</code>. Vous pourrez changer son nom et ses autorisations ; l’adresse IP elle-même n’est pas modifiable.

    <img className="thumbnail" alt="Menu d’une ligne du tableau des IP autorisées" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Étape 4">
    Dans la fenêtre **Ajouter une IP autorisée** qui s’ouvre, plusieurs champs sont à compléter :

    <img className="thumbnail" alt="Fenêtre Ajouter une IP autorisée et ses champs" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (obligatoire) : Saisissez ici l’adresse IP (par exemple : `203.0.113.44`) ou la plage d’adresses IP (par exemple : `203.0.113.0/24` représentant toutes les adresses IP de `203.0.113.0` à `203.0.113.255`) que vous souhaitez autoriser sur votre solution Web Cloud Databases.
    - **Nom** (obligatoire) : Vous pouvez, par exemple, y indiquer le rôle de l’adresse IP ou de la plage d’adresses IP concernée.
    - **Autoriser l’accès au service** (cochée par défaut) : Cochez cette case pour que l’adresse IP ou la plage d’adresses IP soit autorisée à accéder aux bases de données présentes sur votre solution Web Cloud Databases.
    - **Autoriser l’accès SFTP** : Cochez cette case pour que l’adresse IP ou la plage d’adresses IP soit autorisée à accéder aux logs de votre solution Web Cloud Databases.

    :::warning
    Il est fortement déconseillé de cocher la case **Autoriser l’accès au service** pour autoriser la plage d’adresses IP `0.0.0.0/0` à accéder à vos bases de données.

    En effet, cela permettrait d’autoriser l’accès à vos bases de données à l’ensemble des adresses IPv4 existantes.

    :::

    Une fois les informations saisies, cliquez sur le bouton <code className="action">Ajouter</code>.
  </Tab>
</Tabs>
{/* CP-STEPS-END:autoriser-ip */}

## Cas particuliers

**Cliquez sur les cas ci-dessous pour afficher les informations correspondantes.**

{/* CP-STEPS-START:cas-plage-0000 */}
<details>

<summary>La plage d’adresses IP 0.0.0.0/0</summary>

Lors de l’activation de votre solution Web Cloud Databases, une ligne pour la plage d’adresses IP `0.0.0.0/0` est déjà présente par défaut pour autoriser l’accès en **SFTP** à la solution.

Cette autorisation est volontairement mise en place pour vous permettre d’accéder aux fichiers de logs de votre solution Web Cloud Databases sans avoir à déclarer l’adresse IP de votre point d’accès à Internet.

En effet, cette adresse IP peut changer régulièrement en fonction des fournisseurs d’accès à Internet.

De plus, nous vous recommandons de **ne pas** modifier cette autorisation et de ne pas autoriser l’accès aux bases de données présentes sur votre solution Web Cloud Databases.

Effectivement, cela permettrait d’autoriser l’accès à vos bases de données à l’ensemble des adresses IPv4 existantes, ce qui représente un risque pour la sécurité de vos données.

</details>
{/* CP-STEPS-END:cas-plage-0000 */}

<summary>L’autorisation d’accès aux hébergements web OVHcloud</summary>

Lors de l’activation de votre solution Web Cloud Databases, l’autorisation d’accès aux hébergements web OVHcloud est activée par défaut.

Si vous souhaitez désactiver cette autorisation car vous n’utilisez pas d’hébergement web avec votre solution Web Cloud Databases, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances du compte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page qui s’affiche, cliquez sur l’onglet <code className="action">IP autorisées</code>.

    <img className="thumbnail" alt="Onglet IP autorisées d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    En haut de la page, dans la section **Accès aux hébergements web OVHcloud**, désactivez l’interrupteur **Autoriser les hébergements web OVHcloud à accéder à la base de données**.

    <img className="thumbnail" alt="Section Accès aux hébergements web OVHcloud et son interrupteur" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/web-hosting-access.png" loading="lazy" />

    :::info
    En désactivant cet accès, vous bloquez aussi l’accès à **phpMyAdmin** via le lien disponible dans votre espace client OVHcloud, et ce pour l’ensemble de votre solution Web Cloud Databases.
    :::

  </Tab>
</Tabs>
