## Objectif

**Valkey** est un magasin de données **en mémoire**, open source, compatible avec l’écosystème clients et protocoles de Redis (RESP, REdis Serialization Protocol). Il convient aux **caches**, **sessions**, **files d’attente légères** et **compteurs** à haute performance.

**Découvrez comment vous connecter à votre instance Valkey sur Web Cloud Databases : autorisation des adresses IP, récupération des paramètres de connexion et test depuis un client en ligne de commande.**

:::warning
Assurez-vous de sécuriser l’accès à votre instance (IP autorisées, mots de passe robustes) et de tester en pré-production avant mise en ligne.

:::

## En pratique

### Partie 1 — Autoriser l’adresse IP d’accès

Par défaut, votre instance Valkey refuse les connexions publiques. Pour autoriser (mettre en liste blanche) l’adresse IP source depuis laquelle vous vous connectez, consultez notre guide « [Web Cloud Databases - Comment autoriser une adresse IP ?](/guides/web-cloud/databases/db-authorise-ip-mask) ».

Répétez l’opération pour chaque machine qui doit accéder à votre instance Valkey.

### Partie 2 — Préparer les paramètres de connexion <a name="get-credentials"></a>

#### Récupérer les paramètres de connexion

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/#/web/private_database">Web Cloud Databases</ManagerLink>, puis choisissez votre instance Valkey.

    <img className="thumbnail" alt="Liste des services Web Cloud Databases dans l’espace client OVHcloud" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans l’onglet <code className="action">Informations générales</code>, notez les informations suivantes :

    - **Nom d’hôte** : par exemple `aaXXXXX-XXX.eu.clouddb.ovh.net`.
    - **Port** : par exemple `6379`.
  </Tab>
</Tabs>

:::info
OVHcloud ne propose pas de port chiffré via TLS sur les serveurs de bases de données Redis et Valkey. Les communications doivent passer uniquement par le port par défaut, non chiffré.

:::

#### Réinitialiser ou récupérer le mot de passe (si nécessaire)

Si vous ne connaissez plus le mot de passe du compte administrateur ou souhaitez en générer un nouveau :

1. Dans l’onglet <code className="action">Informations générales</code>, cliquez sur le bouton <code className="action">...</code> à droite du champ **Mot de passe du serveur**.

    <img className="thumbnail" alt="Bouton de modification du mot de passe du serveur dans l’onglet Informations générales" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/general-information/update-admin-password-button.png" loading="lazy" />

2. Cliquez sur <code className="action">Changer le mot de passe</code>.

3. Saisissez un mot de passe robuste, puis validez. Attendez quelques minutes que la modification soit appliquée avant de tester la connexion.

#### Mémoriser vos informations

Conservez les informations que vous venez de récupérer :

- Nom d’hôte
- Port
- Mot de passe du serveur

Ces éléments sont nécessaires pour tester la connexion à votre instance depuis un client Valkey ou votre application.

### Partie 3 — Tester la connexion avec un client en ligne de commande

Pour vérifier que votre instance Valkey est fonctionnelle, connectez-vous-y une première fois en suivant les étapes ci-dessous :

#### Installer le client de connexion

Dans cet exemple, nous utilisons le client `redis-cli`, compatible avec Valkey et facile à installer. Vous pouvez utiliser le client de votre choix. Ouvrez un terminal et exécutez la commande ci-dessous selon votre système d’exploitation.

<Tabs>
  <Tab label="Debian/Ubuntu">
    ```bash
    sudo apt update && sudo apt -y install redis-tools
    ```
  </Tab>
  <Tab label="AlmaLinux/Rocky">
    ```bash
    sudo dnf -y install redis
    ```
  </Tab>
  <Tab label="macOS">
    ```bash
    brew install redis
    ```
  </Tab>
  <Tab label="Windows">
    Dans le menu Démarrer, saisissez « PowerShell », faites un clic droit sur le résultat, puis cliquez sur <code className="action">Exécuter en tant qu’administrateur</code>.

    Installez [Chocolatey](https://chocolatey.org/install) en exécutant la commande ci-dessous :

    ```powershell
    Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
    ```

    Installez redis-cli :

    ```powershell
    choco install redis-64 -y
    ```
  </Tab>
</Tabs>

Une fois le client installé, vérifiez qu’il fonctionne en exécutant la commande ci-dessous :

```bash
redis-cli --version
```

#### Se connecter à l’instance

Dans votre terminal, exécutez la commande ci-dessous :

```bash
redis-cli -u "redis://:<password>@<hostname>:6379"
```

Remplacez :

- `<password>` : par le mot de passe du compte `admin`.
- `<hostname>` : par votre nom d’hôte.

Pour récupérer ces valeurs, reportez-vous à la section « [Partie 2 — Préparer les paramètres de connexion](#get-credentials) ».

#### Vérifier que tout fonctionne

Si la connexion réussit, vous devez voir un message semblable à celui-ci :

```console
Warning: Using a password with '-a' or '-u' option on the command line interface may not be safe.
aaXXXXX-XXX.eu.clouddb.ovh.net:6379>
```

Tapez ensuite :

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> PING
```

La base de données doit répondre :

```console
PONG
```

Essayez aussi :

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> SET test "hello"
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> GET test
```

Vous devez voir :

```console
"hello"
```

Pour quitter, tapez :

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> QUIT
```

Si les tests précédents fonctionnent, votre instance Valkey est opérationnelle.
