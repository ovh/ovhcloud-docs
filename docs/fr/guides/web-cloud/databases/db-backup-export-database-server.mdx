## Objectif

Votre base de données peut contenir un grand nombre d’informations essentielles pour votre site. Il est donc primordial de pouvoir la sauvegarder ou l’exporter.

**Découvrez comment sauvegarder et exporter votre base de données depuis votre serveur de bases de données.**

## Prérequis

- Disposer d’une [instance Web Cloud Databases](/links/web/databases) (incluse dans une offre d’[hébergement web](/links/web/hosting) Performance, Agency, Agency Plus ou Agency Max).

[[cpnav:web-cloud-databases]]

## En pratique

:::info
Les offres [Web Cloud Databases](/links/web/databases) ne donnent pas accès au système de gestion de base de données, mais aux bases de données hébergées sur celui-ci.

- Il n’y a pas d’accès super utilisateur « root ».
- Les commandes SQL génériques fonctionnent normalement, et les logiciels de type HeidiSQL, SQuirreL SQL ou Adminer sont pleinement compatibles.

:::

### Sauvegarder et exporter une base de données depuis l’espace client

{/* CP-STEPS-START:sauvegardes-automatiques */}

:::info
- Des sauvegardes sont effectuées automatiquement une fois par jour sur toutes vos bases de données.
- Les sauvegardes automatiques et manuelles sont conservées pendant 30 jours. Passé ce délai, elles sont automatiquement supprimées. La date de suppression de chaque sauvegarde est indiquée dans la liste des sauvegardes de la base de données.

:::

{/* CP-STEPS-END:sauvegardes-automatiques */}

#### Réaliser une sauvegarde manuelle

{/* CP-STEPS-START:sauvegarde-manuelle */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances du compte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Bases de données</code>.

    Dans la colonne **Sauvegardes**, le chiffre correspond au nombre de sauvegardes disponibles pour chaque base de données.

    <img className="thumbnail" alt="Onglet Bases de données d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le tableau, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, à droite de la base de données concernée, puis sur <code className="action">Sauvegarder maintenant</code>.

    <img className="thumbnail" alt="Menu d’une ligne du tableau des bases de données Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    La sauvegarde démarre immédiatement, sans confirmation. Le message **Sauvegarde lancée** s’affiche.
  </Tab>
</Tabs>

{/* CP-STEPS-END:sauvegarde-manuelle */}

#### Exporter une sauvegarde

{/* CP-STEPS-START:exporter-sauvegarde */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances du compte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Bases de données</code>.

    Dans la colonne **Sauvegardes**, le chiffre correspond au nombre de sauvegardes disponibles pour chaque base de données.

    <img className="thumbnail" alt="Onglet Bases de données d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le tableau, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, à droite de la base de données concernée, puis sur <code className="action">Afficher les sauvegardes</code>.

    <img className="thumbnail" alt="Menu d’une ligne du tableau des bases de données Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    Cliquez sur le bouton <code className="action">⋮</code> à droite de la sauvegarde choisie, puis sur <code className="action">Télécharger</code>. Le téléchargement démarre dans un nouvel onglet de votre navigateur.

    <img className="thumbnail" alt="Panneau des sauvegardes d’une base de données avec le menu d’une sauvegarde ouvert" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/backup-actions-menu.png" loading="lazy" />

### Sauvegarder et exporter une base de données hors espace client

Si la RAM disponible sur votre serveur ne permet pas de réaliser l’export souhaité, utilisez l’outil OVHcloud dans l’espace client, qui utilise des ressources externes à votre offre. Reportez-vous à la section « [Sauvegarder et exporter une base de données depuis l’espace client](#sauvegarder-et-exporter-une-base-de-données-depuis-lespace-client) » de cette documentation.

**Cliquez sur la méthode d’exportation de votre choix pour afficher le contenu.**

<details>

<summary>Exporter une base MySQL ou MariaDB depuis phpMyAdmin OVHcloud</summary>

Pour exporter votre base de données directement depuis phpMyAdmin, connectez-vous au préalable en vous aidant du guide « [Se connecter à une base de données](/guides/web-cloud/databases/db-connecting-database-server) ».

Une fois connecté sur phpMyAdmin, cliquez sur le nom de la base de données que vous souhaitez exporter et ensuite sur l’onglet <code className="action">Exporter</code> en haut.

Vous avez deux modes d’exportation possibles. Si vous n’avez pas de besoin spécifique, nous vous conseillons d’utiliser le mode **rapide** au format **SQL**.

<img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-export-backup-web-cloud-db.png" loading="lazy" />

</details>

<details>

<summary>Exporter une base MySQL ou MariaDB en ligne de commande</summary>

```bash
mysqldump --host=serveur --user=utilisateur --port=port --password=password nom_de_la_base > nom_de_la_base.sql
```

</details>

<details>

<summary>Exporter une base MySQL ou MariaDB depuis un script PHP</summary>

```php
1. <?php echo "Votre base est en cours de sauvegarde.......";
2. system("mysqldump --host=serveur --user=utilisateur --port=port --password=password nom_de_la_base > nom_de_la_base.sql");
3. echo "C'est fini. Vous pouvez récupérer la base par FTP";
4. ?>
```

:::warning
- Afin d’éviter qu’un tiers n’accède à ce fichier comportant des données sensibles, pensez à sécuriser l’accès à celui-ci en vous aidant du guide : [Comment protéger l’accès à un répertoire par une authentification ?](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password)
- Cette action est possible uniquement depuis un hébergement OVHcloud mutualisé.

:::

</details>

<details>

<summary>Exporter une base PostgreSQL en ligne de commande</summary>

```bash
pg_dump --host=serveur --port=port --user=utilisateur --password=password nom_de_la_base > nom_de_la_base.sql
```

</details>

<details>

<summary>Exporter une base PostgreSQL depuis un script PHP</summary>

```php
1. <?php echo "Votre base est en cours de sauvegarde.......";
2. system("PGPASSWORD=mot_de_passe pg_dump --host=serveur --port=port --user=utilisateur --password=password nom_de_la_base > nom_de_la_base.sql");
3. echo "C'est fini. Vous pouvez récupérer la base par FTP";
4. ?>
```

:::warning
- Afin d’éviter qu’un tiers n’accède à ce fichier comportant des données sensibles, pensez à sécuriser l’accès à celui-ci en vous aidant du guide : [Comment protéger l’accès à un répertoire par une authentification ?](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password)
- Cette action est possible uniquement depuis un hébergement OVHcloud mutualisé.

:::

</details>
