## Objectif

Votre compte OVHai Workspace vous donne accès à Email, Calendrier, Drive, Visio et Contacts avec un seul identifiant : votre adresse e-mail.

**Découvrez comment créer votre compte, vous connecter, le gérer et le sécuriser, personnaliser l'interface et récupérer vos accès si vous les avez perdus.**

## Prérequis

- Une invitation à créer votre compte (voir [Obtenir un compte](#obtenir-un-compte)).
- Un numéro de téléphone mobile français, pour recevoir un code par SMS.
- Une adresse e-mail hébergée hors d'OVHai Workspace, qui servira d'adresse de récupération.
- Avoir au moins 18 ans.

## En pratique <a name="en-pratique"></a>

### Obtenir un compte <a name="obtenir-un-compte"></a>

Pendant la phase de test (alpha), OVHai Workspace est gratuit et ouvert sur invitation. Vous créez vous-même votre compte.

1. Sur l'écran de connexion, cliquez sur <code className="action">Rejoindre la liste d'attente</code>. Saisissez votre adresse e-mail, puis cliquez sur <code className="action">Rejoindre la liste</code>.
2. Dès qu'une place se libère, vous recevez à cette adresse un lien pour créer votre espace. Pensez à vérifier vos courriers indésirables.
3. Ouvrez le lien. Dans **Adresse e-mail OVHai**, choisissez votre adresse : elle sera votre identifiant dans toutes les applications. Cliquez sur <code className="action">Commencer</code>.
4. Choisissez un **Mot de passe** d'au moins 8 caractères et confirmez-le dans **Confirmation du mot de passe**, puis cliquez sur <code className="action">Continuer</code>.
5. Saisissez votre numéro de téléphone mobile français dans **Numéro de mobile**, puis cliquez sur <code className="action">Continuer</code>. Saisissez le code reçu par SMS dans **Code de vérification**, puis cliquez sur <code className="action">Vérifier le code</code>.
6. Renseignez votre **Nom affiché** (votre prénom et votre nom) et votre **Adresse e-mail de récupération**, différente de votre adresse OVHai.
7. Cochez la case par laquelle vous confirmez avoir au moins 18 ans et acceptez les conditions générales d'utilisation et la politique de confidentialité, puis cliquez sur <code className="action">Créer mon compte</code>.

### Modifier votre nom

<CardGrid columns={2}>
<div>

1. Dans les paramètres, ouvrez l'onglet <code className="action">Compte</code>.
2. Modifiez **Prénom** et **Nom**.
3. Si vous le souhaitez, renseignez un **Nom d'affichage** : l'assistant IA vous appelle ainsi.
4. Cliquez sur <code className="action">Enregistrer</code>.

Le message « Profil mis à jour. » confirme l'enregistrement. Votre adresse e-mail s'affiche au-dessus de ces champs ; elle n'est pas modifiable.

### Suivre votre espace de stockage

La section **Stockage** de l'onglet <code className="action">Compte</code> affiche l'espace utilisé et l'espace total de votre compte ; la même jauge apparaît en bas du panneau de gauche d'Email, de Calendrier, de Drive et de Visio.

Tout est compté : vos fichiers et leurs versions, vos messages, vos pièces jointes, vos enregistrements de réunion et la corbeille d'Email. L'espace des éléments supprimés de cette corbeille est libéré environ une heure plus tard.

### Sécuriser votre compte

Les réglages de sécurité sont dans l'onglet <code className="action">Sécurité</code> des paramètres. Chaque modification demande votre mot de passe actuel.

<div>

#### Changer votre mot de passe

1. Dans la section **Changer le mot de passe**, saisissez votre mot de passe dans **Mot de passe actuel**.
2. Saisissez le nouveau mot de passe dans **Nouveau mot de passe**, puis confirmez-le dans **Confirmer le nouveau mot de passe**.
3. Cliquez sur <code className="action">Changer le mot de passe</code>.

Le bouton <code className="action">Changer le mot de passe</code> reste grisé tant que les champs sont vides.

</div>

#### Définir une adresse de récupération <a name="adresse-de-recuperation"></a>

L'adresse de récupération reçoit les alertes de sécurité et le lien de réinitialisation de votre mot de passe. Sans elle, vous ne pouvez pas [récupérer vos accès](#recuperer-vos-acces) si vous oubliez votre mot de passe. Choisissez une adresse que vous consultez régulièrement, hébergée hors d'OVHai Workspace.

1. Dans la section **Adresse de récupération**, cliquez sur <code className="action">Définir</code>.
2. Saisissez l'adresse dans **E-mail de récupération**, puis votre mot de passe dans **Mot de passe actuel**.
3. Cliquez sur <code className="action">Enregistrer</code>.

La section affiche ensuite l'adresse enregistrée, avec les boutons <code className="action">Modifier</code> et <code className="action">Supprimer</code>.

:::warning
Aucun e-mail de confirmation n'est envoyé à cette adresse : vérifiez-la soigneusement avant de l'enregistrer.

:::

#### Ajouter un numéro de téléphone <a name="numero-de-telephone"></a>

Le numéro de téléphone reçoit un code par SMS quand vous réinitialisez votre mot de passe. La section **Numéro de téléphone** affiche le numéro vérifié.

1. Dans la section **Numéro de téléphone**, cliquez sur <code className="action">Ajouter</code>, ou sur <code className="action">Modifier</code> pour changer de numéro.
2. Saisissez le numéro dans **Numéro de mobile**, au format international (+33 pour la France), puis votre mot de passe dans **Mot de passe actuel**.
3. Cliquez sur <code className="action">Envoyer un code</code>.
4. Saisissez le code reçu par SMS dans **Code de vérification**, puis cliquez sur <code className="action">Vérifier</code>.

#### Activer la double authentification <a name="double-authentification"></a>

Avec la double authentification, la connexion demande, en plus de votre mot de passe, un code à 6 chiffres généré par une application d'authentification installée sur votre téléphone.

1. Dans la section **Double authentification**, cliquez sur <code className="action">Activer</code>.
2. Saisissez votre mot de passe dans **Mot de passe actuel**, puis cliquez sur <code className="action">Continuer</code>.
3. Scannez le QR code affiché avec votre application d'authentification. Si vous ne pouvez pas le scanner, saisissez dans l'application la clé affichée sous **Impossible de le scanner ?**.
4. Saisissez le code à 6 chiffres que l'application affiche, puis cliquez sur <code className="action">Confirmer</code>.
5. 10 codes de récupération s'affichent. Conservez-les en lieu sûr, par exemple avec <code className="action">Copier les codes</code>, puis cliquez sur <code className="action">J'ai enregistré ces codes</code>.

:::warning
Les codes de récupération ne s'affichent qu'une fois. Chaque code ne permet qu'une seule connexion si vous perdez votre application d'authentification.

:::

La section indique ensuite la date d'activation et le nombre de codes de récupération restants. Pour remplacer vos codes, cliquez sur <code className="action">Générer de nouveaux codes de récupération</code>, puis saisissez votre mot de passe et un code de votre application (ou, avec <code className="action">Utiliser plutôt un code de récupération</code>, l'un de vos codes). Les anciens codes cessent alors de fonctionner.

### Personnaliser l'interface

<CardGrid columns={2}>
<div>

L'onglet <code className="action">Préférences</code> des paramètres règle l'apparence de tout votre espace :

- **Langue** : English ou Français. La page se recharge.
- **Thème** : Clair ou Sombre.
- **Position du panneau latéral** : le côté de l'écran où s'affiche l'assistant IA, à gauche ou à droite.
- **Ordre des applications** : les flèches déplacent une application vers le haut ou vers le bas dans la barre d'applications.
- **Sons** : active ou coupe les sons de notification, et règle leur volume.

</div>

### Vous déconnecter

Cliquez sur le menu de votre compte, puis sur <code className="action">Se déconnecter</code>. Sur un ordinateur partagé, déconnectez-vous systématiquement.

### Récupérer vos accès <a name="recuperer-vos-acces"></a>

<CardGrid columns={2}>
<div>

Si vous avez oublié votre mot de passe :

1. Sur l'écran de connexion, cliquez sur <code className="action">Mot de passe oublié ?</code>.
2. Saisissez l'adresse e-mail de votre compte OVHai Workspace, puis cliquez sur <code className="action">Continuer</code>.
3. Ouvrez le lien reçu à votre [adresse de récupération](#adresse-de-recuperation). S'il a expiré, cliquez sur <code className="action">Demander un nouveau lien</code>.
4. Confirmez votre identité : saisissez le code reçu par SMS sur votre [numéro de téléphone](#numero-de-telephone), ou le code de votre application d'authentification.
5. Saisissez votre nouveau mot de passe, confirmez-le dans **Confirmation du mot de passe**, puis cliquez sur <code className="action">Enregistrer et continuer</code>.

Sans adresse de récupération, votre mot de passe ne peut pas être réinitialisé : définissez-la tant que vous avez accès à votre compte.

</div>
