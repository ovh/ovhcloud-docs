## Objectif

Drive est l'application de stockage de fichiers d'OVHai Workspace. Elle affiche vos fichiers et dossiers, et permet de créer des documents bureautiques directement dans le navigateur.

**Découvrez comment stocker, créer et organiser vos fichiers dans OVHai Workspace.**

## Prérequis

- Disposer d'un compte OVHai Workspace.
- Être connecté à votre espace de travail.

## En pratique <a name="en-pratique"></a>

### Ouvrir l'application

Depuis la page d'accueil de votre espace, cliquez sur <code className="action">Commencer</code> sur la carte **Drive**, ou cliquez sur <code className="action">Drive</code> dans la barre d'applications, à gauche de l'écran.

### Se repérer

Le panneau de gauche sépare ce qui vous appartient (**Mon Drive**) de ce que d'autres ont partagé avec vous (**Partagés avec moi**), tandis que **Accueil** réunit les deux.

Triez la liste en cliquant sur les en-têtes **Nom**, **Modifié le** ou **Taille**. Les icônes au-dessus de la liste créent ou importent un dossier ou un fichier.

<img className="thumbnail" alt="L'application Drive sur Mon Drive, avec un dossier, un document et un fichier texte" src="/images/web-cloud/ovhai-workspace/drive/drive-home.png" loading="lazy" style={{ display: 'block', marginInline: 'auto' }} />

:::warning
La **Corbeille** n'est pas encore disponible : considérez toute suppression comme définitive.

:::

### Créer un dossier

1. Cliquez sur <code className="action">Nouveau</code> en haut du panneau de gauche, puis sur <code className="action">Nouveau dossier</code>.
2. Saisissez le **Nom du dossier**, puis cliquez sur <code className="action">Créer</code>.

Le dossier apparaît dans la liste, avec sa date de création dans la colonne **Modifié le**.

### Créer un document

<CardGrid columns={2}>
<div>

1. Cliquez sur <code className="action">Nouveau</code>, puis pointez <code className="action">Nouveau fichier</code>.
2. Choisissez le format voulu :
    - <code className="action">Nouveau document</code> pour un document texte ;
    - <code className="action">Nouveau tableur</code> pour un tableur ;
    - <code className="action">Nouvelle présentation</code> pour une présentation.
3. Saisissez le **Nom du fichier**, puis cliquez sur <code className="action">Créer</code>. L'extension (`.docx`, `.xlsx` ou `.pptx`) est ajoutée si vous ne l'indiquez pas.

</div>

### Importer un fichier

1. Cliquez sur <code className="action">Nouveau</code>, puis sur <code className="action">Importer un fichier</code>.
2. Sélectionnez le fichier sur votre ordinateur.

Les icônes au-dessus de la liste importent aussi un dossier entier.

### Ouvrir un fichier

Double-cliquez sur un fichier pour l'ouvrir dans l'application associée à son format. La barre en haut propose <code className="action">Retour</code>, pour revenir à la liste, et <code className="action">Télécharger</code>.

| Fichiers | S'ouvrent dans | Modifiables |
|---|---|---|
| Documents, tableurs et présentations : `.docx`, `.xlsx`, `.pptx`, `.odt`, `.ods`, `.odp` | OnlyOffice | Oui |
| Notes au format Markdown : `.md` | L'éditeur Markdown | Oui |
| PDF | La visionneuse PDF | Non |
| Images, sons et vidéos | La visionneuse d'images ou le lecteur multimédia | Non |
| Texte et données : `.txt`, `.csv`, `.json`, `.yaml`, `.xml`, `.log` | La visionneuse de texte | Non |

### Gérer un fichier ou un dossier

<div>

Cochez la case devant un élément pour afficher ses actions au-dessus de la liste : <code className="action">Télécharger</code>, <code className="action">Renommer</code> et <code className="action">Supprimer</code>. Le menu en bout de ligne propose <code className="action">Renommer</code> et <code className="action">Supprimer</code>.

</div>

Le partage, le déplacement et la copie apparaissent dans la barre d'actions, mais ne sont pas encore disponibles.

### Rechercher un fichier

Saisissez un mot dans le champ **Rechercher dans mes fichiers**, au-dessus de la liste. Le champ **Rechercher dans mon espace**, en haut de l'écran, cherche en revanche dans toutes les applications à la fois.

### Ce que l'assistant peut faire avec vos fichiers

L'assistant cherche dans votre espace et lit le contenu des fichiers, pas seulement leur nom :

Il travaille sur l'ensemble de l'espace de travail : il peut donc répondre à une question portant sur plusieurs applications, par exemple retrouver un fichier et le message auquel il était joint.
