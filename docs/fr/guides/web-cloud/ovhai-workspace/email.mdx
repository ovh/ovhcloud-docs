## Objectif

Email est l'application de messagerie d'OVHai Workspace. Elle affiche votre boîte aux lettres en trois panneaux : vos dossiers, la liste des messages et le message que vous lisez.

**Découvrez comment lire, rédiger, classer et rechercher vos messages dans OVHai Workspace.**

## Prérequis

- Disposer d'un compte OVHai Workspace.
- Être connecté à votre espace de travail.

## En pratique <a name="en-pratique"></a>

### Ouvrir l'application

Depuis la page d'accueil de votre espace, cliquez sur <code className="action">Commencer</code> sur la carte **Email**, ou cliquez sur <code className="action">Email</code> dans la barre d'applications, à gauche de l'écran.

### Se repérer

Les dossiers sont à gauche, la liste des messages au centre, le message ouvert à droite. L'assistant IA occupe le panneau latéral, à droite par défaut.

Les dossiers sont : **Boîte de réception**, **Suivis**, **Envoyés**, **Brouillons**, **Archives**, **Indésirables** et **Corbeille**. Un dossier **Boîte d'envoi** apparaît tant qu'un message attend d'être envoyé. Le chiffre à côté d'un dossier indique le nombre de messages non lus ou de brouillons en cours.

Cliquez sur <code className="action">Réduire le menu</code>, en bas du panneau des dossiers, pour donner plus de place à la liste des messages. La jauge au-dessus indique l'espace de stockage utilisé par votre compte.

### Rédiger un message

<CardGrid columns={2}>
<div>

1. Cliquez sur <code className="action">Nouveau message</code> en haut du panneau des dossiers.
2. Saisissez l'adresse de vos destinataires dans **À**, puis appuyez sur `Entrée`. Les liens <code className="action">Cc</code> et <code className="action">Cci</code> ajoutent des destinataires en copie et en copie cachée.
3. Saisissez un objet dans **Objet**.
4. Rédigez votre texte dans le corps du message.
5. Cliquez sur <code className="action">Envoyer</code>.

Si vous fermez la fenêtre sans envoyer, le message est enregistré dans **Brouillons**.

</div>
<div>

<img className="thumbnail" alt="La fenêtre Nouveau message, avec le destinataire, l'objet, le corps et la barre d'outils" src="/images/web-cloud/ovhai-workspace/email/email-compose.png" loading="lazy" style={{ display: 'block', marginInline: 'auto' }} />

</div>
</CardGrid>

La barre d'outils, en bas de la fenêtre, met en forme le texte (<code className="action">Texte enrichi</code>), insère un émoji, joint un fichier et supprime le brouillon. Le bouton en forme d'étincelle confie la rédaction à l'assistant IA (voir [Ce que l'assistant peut faire avec vos messages](#assistant)).

#### Annuler un envoi

Le message ne part pas tout de suite : il attend 10 secondes par défaut dans le dossier **Boîte d'envoi**. Pendant ce délai, la notification « Envoi en cours… » propose <code className="action">Annuler</code> : le message retourne alors dans **Brouillons**.

Vous pouvez régler ce délai dans les paramètres (voir [Régler Email](#reglages)).

<img className="thumbnail" alt="La notification Envoi en cours… avec le bouton Annuler, et le dossier Boîte d'envoi dans la liste des dossiers" src="/images/web-cloud/ovhai-workspace/email/email-undo.png" loading="lazy" style={{ display: 'block', marginInline: 'auto' }} />

#### Joindre un fichier

<CardGrid columns={2}>
<div>

Cliquez sur l'icône en forme de trombone (<code className="action">Joindre</code>), puis choisissez :

- <code className="action">Depuis votre ordinateur</code> pour envoyer un fichier de votre appareil ;
- <code className="action">Depuis une autre application</code> pour choisir un fichier de votre Drive.

Chaque pièce jointe s'affiche au-dessus de la barre d'outils, avec sa taille. Cliquez sur la corbeille à côté de son nom pour la retirer.

</div>
<div>

<img className="thumbnail" alt="Le menu Joindre ouvert, avec Depuis votre ordinateur et Depuis une autre application" src="/images/web-cloud/ovhai-workspace/email/email-attach.png" loading="lazy" style={{ display: 'block', marginInline: 'auto' }} />

</div>
</CardGrid>

#### Programmer l'envoi

<CardGrid columns={2}>
<div>

1. Cliquez sur la flèche à côté du bouton <code className="action">Envoyer</code> (**Options d'envoi**), puis sur <code className="action">Programmer l'envoi…</code>.
2. Indiquez la **Date d'envoi** et l'**Heure d'envoi**, puis cliquez sur <code className="action">Valider l'heure</code>.
3. Le bouton d'envoi devient « Envoyer dans … » : cliquez dessus pour confirmer.

La notification « Envoi programmé le … » le confirme et propose <code className="action">Annuler</code>. Le message attend dans **Boîte d'envoi** jusqu'à l'heure choisie.

</div>
<div>

<img className="thumbnail" alt="La fenêtre Programmer l'envoi, avec la date, l'heure et le bouton Valider l'heure" src="/images/web-cloud/ovhai-workspace/email/email-schedule.png" loading="lazy" style={{ display: 'block', marginInline: 'auto' }} />

</div>
</CardGrid>

### Lire et trier vos messages

<CardGrid columns={2}>
<div>

Cliquez sur un message de la liste pour l'ouvrir. Les réponses à un même message sont regroupées en conversation : le chiffre sous l'expéditeur indique le nombre de messages, et la flèche à côté déplie la conversation.

La barre au-dessus du message ouvert propose, de gauche à droite :

- **Répondre** et **Transférer** : la réponse ajoute « Re: » devant l'objet ; le transfert ajoute « Fwd: » et reprend les pièces jointes ;
- **Suivre** : marque le message d'une étoile et le place dans **Suivis** ; cliquez à nouveau (**Ne plus suivre**) pour l'en retirer ;
- **Marquer comme non lu** ;
- **Archiver** : déplace le message dans **Archives** ;
- **Marquer comme indésirable** ;
- **Placer dans la corbeille**.

Une pièce jointe reçue s'affiche sous le message. Le bouton à côté de son nom l'envoie dans votre Drive.

</div>
<div>

<img className="thumbnail" alt="Un message reçu avec sa pièce jointe, le bouton qui l'envoie vers le Drive, et les boutons Répondre et Transférer" src="/images/web-cloud/ovhai-workspace/email/email-attachment.png" loading="lazy" style={{ display: 'block', marginInline: 'auto' }} />

</div>
</CardGrid>

Au-dessus de la liste, les filtres <code className="action">Tous</code> et <code className="action">Non lus</code> la restreignent sans changer de dossier. Le bouton <code className="action">…</code> ajoute le filtre <code className="action">Avec pièce jointe</code>, qui s'affiche ensuite sous forme d'étiquette ; cliquez sur sa croix pour le retirer. L'icône d'actualisation récupère immédiatement les nouveaux messages.

### Rechercher dans vos messages

Saisissez un mot dans le champ **Rechercher des messages**, au-dessus de la liste. Il cherche dans tous vos dossiers, brouillons compris.

Le champ **Rechercher dans mon espace**, en haut de l'écran, cherche en revanche dans toutes les applications à la fois.

### Régler Email <a name="reglages"></a>

Ouvrez le menu de votre compte, puis <code className="action">Paramètres</code>, et choisissez l'onglet <code className="action">Email</code> :

- **Préférer le texte brut** : affiche les messages en texte brut, même lorsqu'une version HTML existe.
- **Bloquer les images distantes** : retire les images chargées depuis Internet, qui servent souvent à savoir si vous avez ouvert un message. Un bandeau au-dessus du message permet alors de les afficher pour ce seul message.
- **Toujours afficher les images de** : la liste des expéditeurs dont les images s'affichent sans bandeau.
- **Délai d'annulation de l'envoi** : le nombre de secondes pendant lesquelles vous pouvez annuler un envoi (10 par défaut). La valeur `0` envoie les messages immédiatement.
- **Son à l'arrivée d'un message**, **Son à l'envoi** et **Son à l'annulation d'un envoi** : le son joué, ou **Aucun**.

<img className="thumbnail" alt="L'onglet Email des paramètres, avec le texte brut, le blocage des images distantes, le délai d'annulation de l'envoi et les sons" src="/images/web-cloud/ovhai-workspace/email/email-settings.png" loading="lazy" style={{ display: 'block', marginInline: 'auto' }} />

### Ce que l'assistant peut faire avec vos messages <a name="assistant"></a>

L'assistant a accès à la boîte que vous consultez : vous pouvez donc lui confier la lecture comme la rédaction.

<CardGrid columns={2}>
<div>

Dans la fenêtre de rédaction, le bouton en forme d'étincelle demande à l'assistant de rédiger le message en cours. L'assistant lit le message ouvert, puis demande votre accord avant de modifier le brouillon, sauf pour les actions que vous avez toujours acceptées : <code className="action">Autoriser</code> exécute l'action une fois, <code className="action">Refuser</code> l'en empêche et <code className="action">Toujours accepter</code> l'autorise à la refaire sans vous le demander (voir [Garder la main sur ce qu'il fait](/guides/web-cloud/ovhai-workspace/landing-page-ovhai-workspace#garder-la-main)). Il vous demande le destinataire s'il ne le connaît pas.

</div>
<div>

<img className="thumbnail" alt="La demande d'autorisation de l'assistant, avec le texte proposé et les boutons Refuser, Toujours accepter et Autoriser" src="/images/web-cloud/ovhai-workspace/email/email-ai-approve.png" loading="lazy" style={{ display: 'block', marginInline: 'auto' }} />

</div>
</CardGrid>
