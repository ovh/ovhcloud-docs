## Objectif

Lors de l’utilisation de votre hébergement web ou de la mise à jour de votre site web, vous pouvez être amené à modifier des paramètres de votre nom de domaine ou de votre sous-domaine déjà associé à votre hébergement web.

:::info
Ce guide explique uniquement comment modifier un nom de domaine ou un sous-domaine déjà déclaré sur un hébergement web OVHcloud.

- Pour associer un nouveau nom de domaine ou sous-domaine à votre site web présent sur votre hébergement web, consultez notre guide « [Comment associer un nom de domaine à un site web existant ?](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website) ».
- Pour ajouter un nouveau site web sur votre hébergement web, consultez notre guide « [Partager son hébergement entre plusieurs sites](/guides/web-cloud/web-hosting/multisites-configure-multisite) ».

:::

**Découvrez comment modifier les paramètres d’association d’un nom de domaine/sous-domaine déjà déclaré sur votre offre d’hébergement web.**

## Prérequis

- Disposer d’une offre [d’hébergement web OVHcloud](/links/web/hosting).
- Disposer d’un ou plusieurs [noms de domaine](/links/web/domains).
- Disposer des droits suffisants sur l’ensemble des services concernés. Retrouvez plus d’informations sur notre guide « [Gérer les contacts de ses services](/guides/account-and-service-management/account-information/managing-contacts) ».

[[cpnav:web-hosting]]

## En pratique

:::warning
La modification des paramètres d’association d’un nom de domaine ou d’un sous-domaine peut, en cas de mauvaise manipulation, entraîner une interruption d’accès à vos services (votre site web). Si vous avez des doutes sur les modifications à réaliser, n’hésitez pas à faire appel à un prestataire spécialisé.

:::

{/* CP-STEPS-START:modifier-domaine */}

Pour modifier les paramètres d’association d’un nom de domaine ou d’un sous-domaine déjà déclaré sur votre offre d’hébergement web, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Mes sites</code>. Dans le tableau, cliquez sur le bouton <code className="action">⋮</code> situé dans la colonne **Actions**, à droite du site web concerné, puis, dans le groupe **Noms de domaine**, sur <code className="action">Gérer</code>.

    <img className="thumbnail" alt="Menu Actions d’un site web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Le panneau **Gérer mes domaines** s’ouvre à droite. Il liste les noms de domaine et sous-domaines associés au site web, chacun avec ses options, son état SSL et son diagnostic DNS.

    Sur le domaine concerné, cliquez sur le bouton <code className="action">⋮</code> situé à droite de son nom, puis sur <code className="action">Gérer mes options</code>.

    <img className="thumbnail" alt="Panneau Gérer mes domaines et menu Actions d’un domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/manage-domains-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    La fenêtre **Gérer les options** s’affiche :

    <img className="thumbnail" alt="Fenêtre Gérer les options d’un nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/country-ip-selection.png" loading="lazy" />

    Vous trouverez ci-dessous un descriptif de chacun des paramètres disponibles. Une fois vos modifications faites, cliquez sur <code className="action">Confirmer</code>.
  </Tab>
</Tabs>

### Description des paramètres modifiables <a name="step1"></a>

{/* CP-STEPS-START:description-parametres */}

:::info
Le nom du domaine et le dossier racine ne se modifient pas depuis cette fenêtre : ce sont des paramètres du site web lui-même.

- Pour associer un nouveau nom de domaine ou sous-domaine à un site web présent sur votre hébergement web, consultez notre guide « [Comment associer un nom de domaine à un site web existant ?](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website) ».
- Pour changer le dossier racine de votre site web, consultez notre guide « [Comment modifier le dossier racine d’un site web existant ?](/guides/web-cloud/web-hosting/my-websites-modify-root-folder) ».

:::

La fenêtre réunit les options en trois groupes.

#### Groupe « Performance et diffusion »

:::warning
Ce groupe se présente sous la forme de **trois choix exclusifs** : vous ne pouvez en retenir qu’un seul à la fois.

- <code className="action">Aucun</code> n’active ni le CDN ni l’IP du pays.
- <code className="action">Activer le CDN</code> désactive l’IP du pays.
- <code className="action">IP du pays</code> désactive le CDN.
:::

**Activer le CDN.** Pour pouvoir utiliser cette option, vous devez avoir au préalable souscrit à une offre CDN OVHcloud ou disposer d’une offre d’hébergement web Performance, Agency, Agency Plus ou Agency Max.

Retrouvez plus d’informations sur les options/offres CDN disponibles dans notre documentation dédiée « [Accélérer mon site web en utilisant le CDN](/guides/web-cloud/web-hosting/cdn-how-to-use-cdn) ».

<Region zones={['eu']}>
**IP du pays.** Cette option est principalement utilisée pour les sites web dont le public cible est situé à l’étranger. Cela permet d’améliorer le référencement SEO du site web dans le pays choisi. Un menu déroulant apparaît sous l’option pour choisir le pays.

Retrouvez plus d’informations sur cette option dans notre documentation dédiée « [Géolocaliser votre site web dans un pays spécifique](/guides/web-cloud/web-hosting/multisites-geolocation) ».
</Region>

#### Groupe « Sécurité »

**Activer le firewall.** Cette option permet de filtrer les requêtes entrantes pour protéger votre hébergement web des attaques les plus courantes.

Retrouvez plus d’informations sur cette option dans notre documentation dédiée « [Activation du pare-feu applicatif](/guides/web-cloud/web-hosting/multisites-activating-application-firewall) ».

#### Groupe « Statistiques et logs »

**Logs séparés.** Cochez cette option uniquement si vous souhaitez que ce nom de domaine dispose de son propre espace de statistiques et de journaux, au lieu de les partager avec le domaine principal.

Concernant cette option, apprenez-en plus grâce à notre [page sur les statistiques détaillées](/links/web/hosting-traffic-analysis).

Une fois vos modifications faites, cliquez sur le bouton <code className="action">Confirmer</code> situé en bas de la fenêtre.

En fonction des options sélectionnées, les modifications peuvent prendre de quelques minutes à quelques heures à être appliquées.

Si, pour les options **CDN**, **IP du pays** et **logs séparés**, les modifications ne sont pas prises en compte au bout de 24 heures, nous vous invitons à consulter les guides (et pages) respectifs indiqués pour chacune des options décrites ci-dessus, afin de vérifier que toutes les conditions requises ont bien été suivies, respectées et réalisées.
