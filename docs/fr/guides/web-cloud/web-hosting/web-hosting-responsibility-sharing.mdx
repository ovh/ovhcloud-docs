## Objectif

Le RACI ci-dessous détaille les responsabilités partagées entre OVHcloud et le client pour le service Hébergement Web. Ce modèle de partage permet d'alléger la charge opérationnelle du client.

| Rôles |
| --- |
| R : Est chargé de réaliser le processus |
| A : Est responsable du bon achèvement du processus |
| C : Est consulté pendant le processus |
| I : Est informé des résultats du processus |

### 1. Avant la souscription

#### 1.1. Spécifier le service selon les besoins

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
| Choisir le service adapté à vos usages | RA |  |
| Décider du nom de domaine que vous utiliserez pour le site Internet à héberger | RA |  |
| Choisir si un module en un clic doit être installé sur l'offre Hébergement Web | RA |  |
| Ajouter les options pertinentes si nécessaire (CDN, DNS Anycast, Web Cloud Databases…) | RA |  |
| Choisir le type de certificat SSL | RA |  |

### 2. Disponibilité du service

#### 2.1. Installer le service

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
| Produire, acheminer, livrer, configurer et maintenir l'infrastructure physique et la plateforme, et gérer la disponibilité des ressources |  | RA |
| Installer, configurer (configuration initiale) et livrer les ressources au client conformément au service souscrit | I | RA |
| Envoyer les moyens d'accès initiaux au client | I | RA |
| Personnaliser les identifiants d'accès | RA |  |
| Choisir l'emplacement du service | I | RA |

#### 2.2. Modèle de réversibilité

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
| Choisir le mode d'installation de l'application web en fonction de vos objectifs de réversibilité | RA |  |
| Installer manuellement votre application web | RA |  |
| Installer votre application web à l'aide du module en un clic | A | R |
| Fournir des protocoles standard et la documentation associée pour l'import et l'export des données | I | RA |
| Importer les données via des protocoles standard | RA |  |

#### 2.3. Configuration du système d'information du client

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
| Configurer votre application web (lien avec la base de données, session d'administration de l'application web…) | RA |  |
