## Objectif

Ce guide vous explique comment consulter les statistiques et les logs générés par l’[option CDN](/guides/web-cloud/web-hosting/cdn-how-to-use-cdn) disponible avec votre offre d’[hébergement web](/links/web/hosting).

**Découvrez comment consulter les statistiques et les logs CDN de votre site web grâce à votre offre d’hébergement web.**

## Prérequis

- Disposer d’une [offre d’hébergement web](/links/web/hosting) avec l’option CDN activée sur au moins un nom de domaine.

[[cpnav:web-hosting]]

## En pratique

### Visualiser les statistiques du CDN

{/* CP-STEPS-START:statistiques-cdn */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page qui s’affiche, cliquez sur l’onglet <code className="action">Statistiques et logs</code>.

    <img className="thumbnail" alt="Onglet Statistiques et logs d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/statistics-and-logs/tab.png" loading="lazy" />

    Dans la section **Statistiques de visite**, cliquez sur le lien <code className="action">Voir les statistiques</code>. La page s’ouvre dans un nouvel onglet de votre navigateur.

    <img className="thumbnail" alt="Lien Voir les statistiques de la section Statistiques de visite" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/statistics-and-logs/view-statistics.png" loading="lazy" />

    :::info
    La page qui s’ouvre vous demande l’identifiant et le mot de passe d’un utilisateur autorisé à accéder aux statistiques et aux logs. Si vous n’en avez pas encore, créez-le depuis la section **Accès** de l’onglet <code className="action">Statistiques et logs</code>, en suivant la partie « [Administration des utilisateurs](/guides/web-cloud/web-hosting/logs-and-statistics#admin-user) » de notre guide sur les statistiques et logs.

    :::

  </Tab>
  <Tab label="Étape 3">
    Une fois identifié, vous accédez à l’outil **OVHcloud Web Statistics**. Dans cet outil, cliquez sur le formulaire intitulé <code className="action">Sélection du domaine</code> situé en haut de la page, puis choisissez un nom de domaine pour lequel le CDN est actif.
  </Tab>
  <Tab label="Étape 4">
    {/* v8-review: TO DOCUMENT — external tool OVHcloud Web Statistics: no « Cache » entry in the left menu and no CDN-enabled domain in « Sélection du domaine » on two Performance hostings with CDN active (checked 2026-10-08). Confirm with the OWStats team whether CDN statistics still exist there. */}

    Dans la colonne de gauche, cliquez sur l’onglet <code className="action">Cache</code>.

    Vous visualisez désormais les statistiques du CDN pour votre nom de domaine.

    Si besoin, consultez notre guide « [Hébergement web - Consulter les statistiques et logs d’un site web](/guides/web-cloud/web-hosting/logs-and-statistics) » pour plus d’informations.
  </Tab>
</Tabs>

{/* CP-STEPS-END:statistiques-cdn */}

### Visualiser les logs du CDN

{/* CP-STEPS-START:logs-cdn */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page qui s’affiche, cliquez sur l’onglet <code className="action">Statistiques et logs</code>.

    <img className="thumbnail" alt="Onglet Statistiques et logs d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/statistics-and-logs/tab.png" loading="lazy" />

    Dans la section **Logs**, cliquez sur le lien <code className="action">Voir les logs</code>. La page s’ouvre dans un nouvel onglet de votre navigateur.

    <img className="thumbnail" alt="Lien Voir les logs de la section Logs" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/statistics-and-logs/view-logs.png" loading="lazy" />

    :::info
    La page qui s’ouvre vous demande l’identifiant et le mot de passe d’un utilisateur autorisé à accéder aux statistiques et aux logs. Si vous n’en avez pas encore, créez-le depuis la section **Accès** de l’onglet <code className="action">Statistiques et logs</code>, en suivant la partie « [Administration des utilisateurs](/guides/web-cloud/web-hosting/logs-and-statistics#admin-user) » de notre guide sur les statistiques et logs.

    :::

  </Tab>
  <Tab label="Étape 3">
    Une fois identifié, sur la page qui s’affiche, cliquez sur le bouton <code className="action">CDN</code> présent dans le bandeau en haut de page.

    <img className="thumbnail" alt="OSL CDN" src="/images/assets/screens/other/web-tools/logs/osl-cdn.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Sur la nouvelle page qui apparaît :

    - Sélectionnez le nom de domaine ou sous-domaine concerné via le menu déroulant <code className="action">Sous-domaine</code>.
    - Renseignez dans le champ <code className="action">Date</code> la date pour laquelle vous souhaitez consulter les logs CDN.
    - Cliquez ensuite sur le bouton <code className="action">Générer</code>.

    :::info
    Les logs CDN sont indisponibles le jour même où ils sont générés, vous devrez donc patienter le lendemain pour les consulter.

    :::

    <img className="thumbnail" alt="OSL CDN - Logs générés" src="/images/assets/screens/other/web-tools/logs/osl-cdn-subdomain-date-selection.png" loading="lazy" />

Dans le tableau qui s’affiche, cliquez sur le bouton <code className="action">Télécharger</code> à droite du nom de domaine ou sous-domaine concerné pour récupérer les logs CDN.

    Si besoin, consultez notre guide « [Hébergement web - Consulter les statistiques et logs d’un site web](/guides/web-cloud/web-hosting/logs-and-statistics) » pour plus d’informations.
  </Tab>
</Tabs>

{/* CP-STEPS-END:logs-cdn */}
