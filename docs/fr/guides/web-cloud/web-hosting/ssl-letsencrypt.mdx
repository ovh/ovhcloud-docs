## Objectif

Les certificats Secure Socket Layer (SSL) permettent de chiffrer les échanges effectués depuis ou vers votre site web. Cela évite qu’une personne ou un robot malveillant ne vienne « écouter » clairement les requêtes envoyées ou émises avec votre site web.

OVHcloud propose plusieurs types de certificats SSL sur nos offres d’[hébergement mutualisé OVHcloud](/links/web/hosting). Ils sont présentés dans notre guide « [Hébergement web - Gérer un certificat SSL](/guides/web-cloud/web-hosting/ssl-on-webhosting) ». Les certificats SSL sont incontournables pour la sécurité de votre site web.

Trois types de certificats SSL existent :

- Domain Validation (DV)
- Organization validation (OV)
- Extended Validation (EV)

Les niveaux de chiffrement SSL sont identiques entre ces trois types de certificat.

La principale différence réside dans le niveau de vérifications qui sera réalisé par l’Autorité de Certification (AC) qui délivre le certificat SSL et atteste de son authenticité.

Let's Encrypt est une autorité de certification gratuite, automatisée, ouverte et à but non-lucratif. Retrouvez plus d’informations sur [https://letsencrypt.org/fr/about/](https://letsencrypt.org/fr/about/).

**Découvrez comment activer un certificat SSL gratuit Let's Encrypt sur votre hébergement Web OVHcloud.**

## Prérequis

- Commander ou disposer d’un [hébergement mutualisé OVHcloud](/links/web/hosting).
- Commander ou disposer d’un [nom de domaine](/links/web/domains) et disposer des droits exclusifs sur son utilisation. Le ou les noms de domaine/sous-domaines ne doivent pas déjà être liés à un certificat SSL.

:::info
Depuis le **06/08/2025**, le certificat SSL Let's Encrypt est automatiquement activé par défaut pour :

- tous les nouveaux noms de domaine/sous-domaines associés à un hébergement web.
- toutes les nouvelles souscriptions d’un nom de domaine avec un nouvel hébergement web.

L’objectif étant de vous faire gagner du temps lors de la configuration de vos services. Vous pourrez toujours désactiver le certificat SSL Let's Encrypt depuis votre <ManagerLink to="/">espace client OVHcloud</ManagerLink> si vous souhaitez installer un autre certificat SSL (Sectigo DV, Sectigo EV ou un certificat SSL personnalisé).
Retrouvez plus d’informations dans notre guide « [Gérer un certificat SSL](/guides/web-cloud/web-hosting/ssl-on-webhosting) », partie **Désactiver un certificat SSL sur un hébergement web**.

:::

## En pratique

:::warning
**Avant de poursuivre**, vérifiez que **chaque nom de domaine et/ou sous-domaine** concerné par un futur certificat SSL Let's Encrypt :

- pointe vers l’adresse IP de votre hébergement web. 
- est déclaré sur l’un des sites web de votre hébergement web.
- ne dispose pas déjà d’un certificat SSL actif.

Pour vous en assurer, consultez si besoin nos guides ci-dessous :

- [Partager son hébergement entre plusieurs sites](/guides/web-cloud/web-hosting/multisites-configure-multisite).
- [Hébergement web - Liste des adresses IP par cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip).
- [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit).
- [Hébergement web - Gérer un certificat SSL](/guides/web-cloud/web-hosting/ssl-on-webhosting), partie **Désactiver un certificat SSL sur un hébergement web**.

:::

### Activer le certificat SSL Let's Encrypt

{/* CP-STEPS-START:activer-certificat-letsencrypt */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">SSL</code>.

    <img className="thumbnail" alt="Onglet SSL d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Au-dessus du tableau des certificats, cliquez sur <code className="action">Ajouter un certificat</code>.
  </Tab>
  <Tab label="Étape 4">
    Un panneau s’ouvre sur la droite. Sous **Type de certificat**, **Let's Encrypt** est déjà sélectionné : c’est l’option gratuite, renouvelée automatiquement, avec validation du domaine (DV). Sous **Domaines à sécuriser**, sélectionnez le ou les noms de domaine et sous-domaines concernés, puis cliquez sur <code className="action">Activer</code>.

    <img className="thumbnail" alt="Panneau Ajouter un certificat avec Let's Encrypt sélectionné" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/enable-ssl-lets-encrypt.png" loading="lazy" />
  </Tab>
</Tabs>

{/* CP-STEPS-END:activer-certificat-letsencrypt */}

La mise en place du certificat SSL Let's Encrypt peut prendre plusieurs heures.

### Vérifier l’activation du certificat SSL gratuit Let's Encrypt (DV)

{/* CP-STEPS-START:verifier-activation-letsencrypt */}

Pour vérifier que l’installation est terminée, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">SSL</code>.

    <img className="thumbnail" alt="Onglet SSL d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Repérez chaque nom de domaine et sous-domaine concerné dans la colonne **Domaine principal**, puis lisez sa colonne **Statut**. L’installation est terminée lorsqu’il affiche **Actif** ; tant qu’elle est en cours, il affiche **En création**.

    <img className="thumbnail" alt="Tableau des certificats SSL et sa colonne Statut" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/tab.png" loading="lazy" />

Le tableau n’indique pas le type de certificat. Pour le retrouver, cliquez sur <code className="action">Exporter en CSV</code> : le fichier obtenu contient une colonne **Type de certificat**.

    <img className="thumbnail" alt="Bouton Exporter en CSV au-dessus du tableau" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/export-csv.png" loading="lazy" />
  </Tab>
</Tabs>

{/* CP-STEPS-END:verifier-activation-letsencrypt */}

Votre certificat SSL gratuit Let's Encrypt (DV) est désormais installé et actif. Vous pouvez dès à présent l’utiliser avec votre site web en passant, par exemple, votre [site web en HTTPS](/guides/web-cloud/web-hosting/ssl-activate-https-website).
