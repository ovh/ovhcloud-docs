## Redirection et authentification avec le fichier .htaccess

Le fichier `.htaccess` permet de contrôler l'accès à votre site web et de rediriger ou réécrire ses URL, directement sur votre hébergement web OVHcloud. Cette page regroupe les guides pour protéger l'accès (mot de passe, blocage d'adresses IP), réécrire les URL et exploiter les autres possibilités du fichier `.htaccess`.
