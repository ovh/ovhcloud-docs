## Objectif

Vous pouvez héberger plusieurs sites web sur une même offre d'hébergement web, même si les noms de domaine ne sont pas enregistrés chez OVHcloud. De plus, vous pouvez associer un ou plusieurs noms de domaine ou sous-domaines à un même site web.

:::info
Si vous n'avez pas encore créé le site web concerné sur votre hébergement web, consultez **directement** [ce guide](/guides/web-cloud/web-hosting/multisites-configure-multisite).

:::

**Découvrez comment associer un nom de domaine ou un sous-domaine à un site web déjà existant sur votre hébergement web.**

## Prérequis

- Disposer d'une offre d'[hébergement web OVHcloud](https://www.ovhcloud.com/fr/web-hosting/uc-multisite/) compatible.
- Disposer d'un ou de plusieurs [noms de domaine](https://www.ovhcloud.com/fr/domains/).
- Pouvoir modifier la configuration de vos noms de domaine depuis leurs [zones DNS](/guides/web-cloud/domains/dns-zone-edit).

## En pratique

### Ajouter un nom de domaine ou un sous-domaine à un site web existant

**Cliquez sur l'un des titres ci-dessous pour afficher les explications.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Ajouter un nom de domaine géré depuis votre espace client OVHcloud</summary>

Cette partie s'applique uniquement si votre nom de domaine et/ou sa zone DNS active se trouvent **dans votre espace client OVHcloud**.

{/* CP-STEPS-START:ajouter-domaine-ovhcloud */}

Le formulaire tient sur une seule page : renseignez-la de haut en bas, puis validez. Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Mes sites</code>. Dans le tableau, cliquez sur le bouton <code className="action">⋮</code> situé dans la colonne **Actions**, à droite du site web concerné, puis, dans le groupe **Noms de domaine**, sur <code className="action">Ajouter un nom de domaine</code>.

    <img className="thumbnail" alt="Menu Actions d’un site web, entrée Ajouter un nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    La page **Ajouter un domaine** s’ouvre. Elle reprend le formulaire d’ajout de site, dans lequel le **dossier racine** et le **nom du site** sont déjà renseignés depuis le site web existant : laissez-les tels quels.

    <img className="thumbnail" alt="Page Ajouter un domaine et choix du type de nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    Dans la section **Association du nom de domaine**, choisissez la carte **Nom de domaine OVHcloud existant**.
  </Tab>
  <Tab label="Étape 4">
    La section **Configurer votre domaine** apparaît. Sélectionnez le nom de domaine à associer dans le menu déroulant **Nom de domaine**.

    <img className="thumbnail" alt="Configuration du domaine, options et configuration DNS" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-configure-domain.png" loading="lazy" />

    :::info
    Pour ajouter un sous-domaine, sélectionnez d’abord le nom de domaine dans la liste (par exemple : domain.tld). Cochez ensuite la case **Créer un sous-domaine**. Un champ de saisie apparaît pour vous permettre de renseigner le sous-domaine (par exemple : **sub**.domain.tld).

    **Cas particulier** : Les sous-domaines en `www` (par exemple : **www**.domain.tld) sont automatiquement ajoutés en complément du nom de domaine. Par conséquent, il est inutile de préciser ce sous-domaine spécifique dans le champ de saisie.
    :::

    La section **Options** réunit trois fonctionnalités, décochées par défaut. Selon votre [offre d’hébergement web](/links/web/hosting), certaines peuvent ne pas être sélectionnables.

    |Option|Description|
    |---|---|
    |IP du pays|Permet de bénéficier d’une adresse IP géolocalisée (parmi une liste de pays) pour le nom de domaine sélectionné.<br/> Apprenez-en plus grâce à [cette page](/links/web/hosting-options).|
    |Firewall|Permet d’activer un pare-feu (filtrage et analyse des requêtes) sur le nom de domaine sélectionné.<br/> Apprenez-en plus grâce à [cette page](/links/web/hosting-options).|
    |CDN|Permet d’activer le CDN (mise en cache des éléments statiques de votre site web, comme les images) sur le nom de domaine sélectionné.<br/> Apprenez-en plus grâce à [notre page CDN](/links/web/hosting-options-cdn).|

    :::info
    Ces options peuvent être activées plus tard. Pour cela, consultez [ce guide](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::

    La section **Configuration DNS** propose enfin deux modes :

    - **Pour une configuration automatique**, laissez la carte **Configuration automatique** sélectionnée : les enregistrements A et AAAA sont créés dans la zone DNS du domaine.
    - **Pour une configuration manuelle**, choisissez la carte **Configuration manuelle**, puis référez-vous aux guides suivants :
        - [Hébergement web - Liste des adresses IP par cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    Cliquez enfin sur <code className="action">Valider</code>. L’ajout peut prendre jusqu’à une heure.

    :::info
    La modification de la configuration DNS de votre nom de domaine nécessite un délai de propagation pouvant atteindre 48 heures avant d’être pleinement effective.
    :::
  </Tab>
</Tabs>

{/* CP-STEPS-END:ajouter-domaine-ovhcloud */}

</details>

<details>
<summary>Ajouter un nom de domaine externe</summary>

Cette partie s’applique uniquement si votre nom de domaine n’est pas présent dans votre compte OVHcloud.

{/* CP-STEPS-START:ajouter-domaine-externe */}

Le formulaire tient sur une seule page : renseignez-la de haut en bas, puis validez. Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Mes sites</code>. Dans le tableau, cliquez sur le bouton <code className="action">⋮</code> situé dans la colonne **Actions**, à droite du site web concerné, puis, dans le groupe **Noms de domaine**, sur <code className="action">Ajouter un nom de domaine</code>.

    <img className="thumbnail" alt="Menu Actions d’un site web, entrée Ajouter un nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    La page **Ajouter un domaine** s’ouvre. Elle reprend le formulaire d’ajout de site, dans lequel le **dossier racine** et le **nom du site** sont déjà renseignés depuis le site web existant : laissez-les tels quels.

    <img className="thumbnail" alt="Page Ajouter un domaine et choix du type de nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    Dans la section **Association du nom de domaine**, choisissez la carte **Nom de domaine externe**.
  </Tab>
  <Tab label="Étape 4">
    Dans la section **Configurer votre domaine**, saisissez le nom de domaine (par exemple : domain.tld) ou le sous-domaine (par exemple : **sub**.domain.tld) dans le champ **Nom de domaine**.

    :::tip
    **Cas particulier** : Les sous-domaines en `www` (par exemple : **www**.domain.tld) sont automatiquement ajoutés en complément du nom de domaine. Par conséquent, il est inutile de préciser ce sous-domaine spécifique dans le champ de saisie.
    :::

    La section **Gestion du domaine** affiche alors les enregistrements à créer, en deux temps. Cette vérification est obligatoire : elle nous permet de nous assurer que l’ajout du nom de domaine externe est légitime.

    <img className="thumbnail" alt="Gestion du domaine : enregistrements DNS à créer et enregistrement BIND" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-external-dns.png" loading="lazy" />

    1. **Vérifiez la propriété du domaine** : ajoutez l’enregistrement **TXT** indiqué dans la zone DNS de votre fournisseur.
    2. **Faites pointer le domaine vers l’hébergement** : ajoutez les enregistrements **A** et **AAAA** indiqués.

    Chaque valeur dispose d’un bouton de copie, et le bloc **Enregistrement BIND** reprend les trois lignes au format attendu par la plupart des hébergeurs de zone DNS.

    Cliquez enfin sur <code className="action">Valider</code>. Le nom de domaine est ajouté de manière temporaire, le temps que vous modifiiez sa configuration DNS.

    :::warning
    Vous devez effectuer ces modifications **rapidement** pour que votre nom de domaine soit correctement associé à votre site web.

    Les entrées DNS de type **A** et **TXT** doivent obligatoirement être placées dans la zone DNS active de votre nom de domaine. Seules les entrées DNS de type **AAAA** sont optionnelles.

    Notez que si vous souhaitez associer `sub.domain.tld`, vous devrez créer l’entrée TXT `ovhcontrol.domain.tld` et non l’entrée `ovhcontrol.sub.domain.tld`.

    Pour retrouver la zone DNS active de votre nom de domaine, retrouvez les [serveurs DNS](/guides/web-cloud/domains/dns-server-edit) auxquels celui-ci est lié.
    :::

    :::info
    La modification de la configuration DNS de votre nom de domaine nécessite un délai de propagation pouvant atteindre 48 heures avant d’être pleinement effective.
    :::
  </Tab>
</Tabs>

{/* CP-STEPS-END:ajouter-domaine-externe */}

</details>

  </Tab>
  <Tab label="Étape 2">

    <img className="thumbnail" alt="Menu Actions d’un site web, entrée Ajouter un nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    La page **Ajouter un domaine** s’ouvre. Elle reprend le formulaire d’ajout de site, dans lequel le **dossier racine** et le **nom du site** sont déjà renseignés depuis le site web existant : laissez-les tels quels.

    <img className="thumbnail" alt="Page Ajouter un domaine et choix du type de nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    Dans la section **Association du nom de domaine**, choisissez la carte **Commander un nouveau nom de domaine**. Le formulaire ne demande rien de plus : le bouton situé en bas de page reprend alors l’intitulé <code className="action">Commander un nouveau nom de domaine</code>. Cliquez dessus.

    Vous êtes alors redirigé vers notre page commerciale de souscription d’un nom de domaine. Choisissez votre nouveau nom de domaine en fonction des disponibilités du marché, puis suivez les instructions du tunnel de commande jusqu’à la validation du bon de commande, sans souscrire en complément à un nouvel hébergement web.

    Une fois votre commande payée et validée, patientez quelques instants, le temps qu’elle soit traitée.

    :::info
    Une fois que votre nom de domaine apparaît dans votre espace client OVHcloud, suivez la partie « [Ajouter un nom de domaine géré depuis votre espace client OVHcloud](#add-domain-ovhcloud) » de ce guide pour l’associer à votre site web.

### Offre e-mail incluse avec votre hébergement web

La plupart des offres d'[hébergement web OVHcloud](https://www.ovhcloud.com/fr/web-hosting/) disposent d'une option incluse de création d'adresses e-mail personnalisées avec votre nom de domaine.

Cette option e-mail peut être activée pour **un seul** nom de domaine. Cela signifie que si vous hébergez plusieurs sites web avec plusieurs noms de domaine différents sur votre hébergement web, vous ne pourrez activer cette option que pour un seul de vos noms de domaine.

N'hésitez pas à consulter [notre guide dédié](/guides/web-cloud/web-hosting/activate-email-hosting) pour plus de détails sur l'activation de cette option.
