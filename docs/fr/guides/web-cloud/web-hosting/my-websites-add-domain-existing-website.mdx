## Objectif

Vous pouvez héberger plusieurs sites web sur une même offre d'hébergement web, même si les noms de domaine ne sont pas enregistrés chez OVHcloud. De plus, vous pouvez associer un ou plusieurs noms de domaine ou sous-domaines à un même site web.

:::info
Si vous n'avez pas encore créé le site web concerné sur votre hébergement web, consultez **directement** [ce guide](/guides/web-cloud/web-hosting/multisites-configure-multisite).

:::

**Découvrez comment associer un nom de domaine ou un sous-domaine à un site web déjà existant sur votre hébergement web.**

:::info
Cette procédure s'applique à la <ManagerLink to="/beta/#/">nouvelle version de l'espace client OVHcloud</ManagerLink>, actuellement disponible en bêta. Pour la suivre, basculez vers cette interface depuis votre espace client habituel.

:::

## Prérequis

- Disposer d'une offre d'[hébergement web OVHcloud](https://www.ovhcloud.com/fr/web-hosting/uc-multisite/) compatible.
- Disposer d'un ou de plusieurs [noms de domaine](https://www.ovhcloud.com/fr/domains/).
- Pouvoir modifier la configuration de vos noms de domaine depuis leurs [zones DNS](/guides/web-cloud/domains/dns-zone-edit).

## En pratique

### Ajouter un nom de domaine ou un sous-domaine à un site web existant

**Cliquez sur l'un des titres ci-dessous pour afficher les explications.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Ajouter un nom de domaine géré depuis votre espace client OVHcloud</summary>

Cette partie s'applique uniquement si votre nom de domaine et/ou sa zone DNS active se trouvent **dans votre espace client OVHcloud**.

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **6** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hébergements</ManagerLink>, puis choisissez l'hébergement web concerné.

    <img className="thumbnail" alt="Hébergements" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page qui s'affiche, cliquez sur l'onglet <code className="action">Mes sites</code>.

    <img className="thumbnail" alt="Mes sites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le tableau qui apparaît, cliquez sur le bouton <code className="action">⁝</code> situé à droite du site web concerné, puis sur <code className="action">Ajouter un domaine</code>.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/website-options.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Cochez l'option <code className="action">Associer un domaine OVHcloud existant</code> et cliquez sur <code className="action">Continuer</code>.

    Sélectionnez ensuite le nom de domaine à associer dans le menu déroulant **Nom de domaine - obligatoire** qui apparaît en dessous.

    :::info
    Pour ajouter un sous-domaine, sélectionnez d'abord le nom de domaine dans la liste (par exemple : domain.tld). Cochez ensuite la case intitulée <code className="action">Créer un sous-domaine</code>. Un champ de saisie apparaît pour vous permettre de renseigner le sous-domaine (par exemple : **sub**.domain.tld).

    **Cas particulier** : Les sous-domaines en `www` (par exemple : **www**.domain.tld) sont automatiquement ajoutés en complément du nom de domaine. Par conséquent, il est inutile de préciser ce sous-domaine spécifique dans le champ de saisie.

    :::

    <img className="thumbnail" alt="Add domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-ovh-step-1.png" loading="lazy" />

    Si vous souhaitez utiliser l'une des **options avancées** disponibles, activez le bouton <code className="action">Configuration avancée</code> et passez directement à **l'étape 7**. Sinon, poursuivez à **l'étape 6**.
  </Tab>
  <Tab label="Étape 5">
    Vérifiez que toutes les informations saisies précédemment sont correctes, puis cliquez sur <code className="action">Continuer</code> pour finaliser l'ajout de votre nom de domaine ou de votre sous-domaine à votre site web.

    Cet ajout peut prendre jusqu'à une heure.

    La configuration DNS se réalisera automatiquement si la zone DNS active de votre nom de domaine est gérée dans votre espace client OVHcloud.

    Dans le cas contraire, consultez les guides suivants pour configurer manuellement votre zone DNS :

    - [Hébergement web - Liste des adresses IP par cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
    - [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    :::info
    La modification de la configuration DNS de votre nom de domaine nécessite un délai de propagation pouvant atteindre 24 heures avant d'être pleinement effective.

    :::

  </Tab>
  <Tab label="Étape 6">
    :::info
    Cette étape est **facultative**. Elle s'adresse uniquement aux clients souhaitant activer certaines fonctionnalités disponibles via le bouton <code className="action">Configuration avancée</code>.

    **Toutes ces fonctionnalités peuvent être activées ultérieurement, une fois le nom de domaine ajouté à votre site web.** Dans ce cas précis, consultez directement [ce guide](/guides/web-cloud/web-hosting/multisites-modify-domain).

    Retrouvez ci-dessous un descriptif de ces options.

    Selon votre offre d'[hébergement web](https://www.ovhcloud.com/fr/web-hosting/), certains éléments parmi les choix proposés ne pourront pas être sélectionnés.

    :::

    <img className="thumbnail" alt="Add domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-ovh-advanced-configurations.png" loading="lazy" />

    <Region zones={['eu']}>

    |Option|Description|
    |---|---|
    |IP du pays|Permet de bénéficier d'une adresse IP géolocalisée (parmi une liste de pays) pour le nom de domaine sélectionné.<br/> Apprenez-en plus grâce à [cette page](https://www.ovhcloud.com/fr/web-hosting/options/).|
    |Firewall|Permet d'activer un pare-feu (filtrage et analyse des requêtes) sur le nom de domaine sélectionné.<br/> Apprenez-en plus grâce à [cette page](https://www.ovhcloud.com/fr/web-hosting/options/).|
    |CDN|Permet d'activer le CDN (mise en cache des éléments statiques de votre site web, comme les images) sur le nom de domaine sélectionné.<br/> Apprenez-en plus grâce à [notre page CDN](https://www.ovhcloud.com/fr/web-hosting/options/cdn/).<br/> En activant le SSL et le CDN, vous pourrez également bénéficier du protocole **HTTP/2** (ce protocole est activé par défaut dans notre datacentre de Gravelines).|

    </Region>
    <Region zones={['ca', 'apac']}>

    |Option|Description|
    |---|---|
    |Firewall|Permet d'activer un pare-feu (filtrage et analyse des requêtes) sur le nom de domaine sélectionné.<br/> Apprenez-en plus grâce à [cette page](https://www.ovhcloud.com/fr/web-hosting/options/).|
    |CDN|Permet d'activer le CDN (mise en cache des éléments statiques de votre site web, comme les images) sur le nom de domaine sélectionné.<br/> Apprenez-en plus grâce à [notre page CDN](https://www.ovhcloud.com/fr/web-hosting/options/cdn/).|

    </Region>

    Une fois le bouton <code className="action">Configuration avancée</code> activé, vous pouvez également choisir le mode de configuration DNS de votre nom de domaine :

    - **Pour une configuration DNS automatique**, laissez la case <code className="action">Configuration automatique (recommandée)</code> cochée.
    - **Pour une configuration DNS manuelle**, cochez la case <code className="action">Configuration manuelle</code>. Pour réaliser ensuite le paramétrage, référez-vous aux guides suivants :
        - [Hébergement web - Liste des adresses IP par cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    Une fois vos choix réalisés, cliquez sur le bouton <code className="action">Continuer</code> pour finaliser l'ajout de votre nom de domaine ou de votre sous-domaine à votre site web. Cet ajout peut prendre jusqu'à une heure.

    Cependant, la modification de la configuration DNS de votre nom de domaine nécessite un délai de propagation pouvant atteindre 24 heures avant d'être pleinement effective.
  </Tab>
</Tabs>

</details>

<details>
<summary>Ajouter un nom de domaine externe</summary>

Cette partie s’applique uniquement si votre nom de domaine n’est pas présent dans votre compte OVHcloud.

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **6** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hébergements</ManagerLink>, puis choisissez l'hébergement web concerné.

    <img className="thumbnail" alt="Hébergements" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page qui s'affiche, cliquez sur l'onglet <code className="action">Mes sites</code>.

    <img className="thumbnail" alt="Mes sites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le tableau qui apparaît, cliquez sur le bouton <code className="action">⁝</code> situé à droite du site web concerné, puis sur <code className="action">Ajouter un domaine</code>.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/website-options.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Cochez l'option <code className="action">Associer un domaine externe</code> et cliquez sur <code className="action">Continuer</code>.

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-1.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 5">
    Saisissez le nom de domaine (par exemple : domain.tld) ou le sous-domaine (par exemple : **sub**.domain.tld) à associer dans le champ **Nom de domaine - obligatoire** qui apparaît en dessous.

    :::tip
    **Cas particulier** : Les sous-domaines en `www` (par exemple : **www**.domain.tld) sont automatiquement ajoutés en complément du nom de domaine. Par conséquent, il est inutile de préciser ce sous-domaine spécifique dans le champ de saisie.

    :::

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-2.png" loading="lazy" />

    Une fois les informations complétées, cliquez sur le bouton <code className="action">Continuer</code>.

    :::info
    Contrairement aux noms de domaine directement gérés depuis votre espace client OVHcloud, les **options avancées** ne sont pas directement disponibles lors de l'ajout d'un nom de domaine ou d'un sous-domaine externe à votre site web.

    Cependant, **toutes ces fonctionnalités peuvent être activées ultérieurement une fois le nom de domaine ou le sous-domaine externe ajouté à votre site web.** Pour cela, consultez directement [ce guide](/guides/web-cloud/web-hosting/multisites-modify-domain).

    :::

  </Tab>
  <Tab label="Étape 6">
    Tout ajout d'un nom de domaine externe à OVHcloud nécessite une validation supplémentaire obligatoire. Cela nous permet de nous assurer que l'ajout du nom de domaine externe est légitime. Un message vous invitera donc à modifier la configuration DNS du nom de domaine.

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-3.png" loading="lazy" />

    Notez les éléments qui s’affichent, puis cliquez sur le bouton <code className="action">Continuer</code>. Dès lors, le nom de domaine est ajouté de manière temporaire, le temps que vous puissiez modifier sa configuration DNS.

    :::warning
    Vous devez effectuer ces modifications **rapidement** pour que votre nom de domaine soit correctement ajouté. Sans cette action, l'ajout de votre nom de domaine sera annulé.

    Les entrées DNS de type **A** et **TXT** doivent obligatoirement être placées dans la zone DNS active de votre nom de domaine pour qu'il soit ajouté à votre site web. Seules les entrées DNS de type **AAAA** sont optionnelles.

    Notez que si vous souhaitez ajouter `sub.domain.tld`, vous devrez créer l'entrée TXT `ovhcontrol.domain.tld` et non l'entrée `ovhcontrol.sub.domain.tld`.

    Pour retrouver la zone DNS active de votre nom de domaine, retrouvez les [serveurs DNS](/guides/web-cloud/domains/dns-server-edit) auxquels celui-ci est lié. Vous devrez valider uniquement le nom de domaine à l'aide du champ **TXT**, pas tous ses sous-domaines.|

    :::

  </Tab>
</Tabs>

</details>

### Offre e-mail incluse avec votre hébergement web

La plupart des offres d'[hébergement web OVHcloud](https://www.ovhcloud.com/fr/web-hosting/) disposent d'une option incluse de création d'adresses e-mail personnalisées avec votre nom de domaine.

Cette option e-mail peut être activée pour **un seul** nom de domaine. Cela signifie que si vous hébergez plusieurs sites web avec plusieurs noms de domaine différents sur votre hébergement web, vous ne pourrez activer cette option que pour un seul de vos noms de domaine.

N'hésitez pas à consulter [notre guide dédié](/guides/web-cloud/web-hosting/activate-email-hosting) pour plus de détails sur l'activation de cette option.
