## Objectif

Vous souhaitez créer un site Internet pour votre entreprise ou un blog personnel ? Vous avez besoin d’une boutique e-commerce pour vendre vos produits en ligne ? Ce guide dédié aux premiers pas avec l’hébergement web OVHcloud vous indiquera les étapes clés pour le configurer. Vous trouverez également les explications pour créer des adresses e-mail professionnelles associées à votre nom de domaine. Il vous permettra une mise en ligne facile et rapide de votre projet afin de communiquer avec votre audience de manière efficace.

:::info
- Vous souhaitez migrer un site web existant déjà chez un autre hébergeur ? Consultez directement notre guide dédié : [Migrer son site web et ses services associés vers OVHcloud](/guides/web-cloud/web-hosting/hosting-migrating-to-ovh).
<Region zones={['eu']}>
- Vous souhaitez uniquement une page d’accueil simple pour votre activité professionnelle ? Consultez notre guide dédié : [Hébergement web - Activer l’hébergement gratuit](/guides/web-cloud/web-hosting/activate-start10m).
</Region>

:::

## Prérequis

<Region zones={['eu']}>
- Disposer d’une offre d'[hébergement web OVHcloud](/links/web/hosting) avec au moins une base de données disponible (hors offre d’hébergement gratuite).
</Region>
<Region zones={['ca','apac']}>
- Disposer d’une offre d'[hébergement web OVHcloud](/links/web/hosting) avec au moins une base de données disponible.
</Region>
- Avoir reçu l’e-mail vous confirmant l’installation de votre hébergement web.
- Disposer d’un [nom de domaine](/links/web/domains) et d’une zone DNS associée chez OVHcloud.
- Tous les services (Hébergement web, Nom de domaine, zone DNS) doivent être accessibles depuis un seul et même compte OVHcloud.

[[cpnav:web-hosting]]

## En pratique

### 1 - Associer votre nom de domaine à un site web sur votre hébergement web <a name="part-1"></a>

:::tip
Si vous avez souscrit à votre nom de domaine et à votre hébergement web dans une même commande, ces deux services sont déjà associés. Passez directement à la [Partie 2](#part-2) de ce guide.

:::

{/* CP-STEPS-START:associer-domaine */}

Cliquez sur les onglets ci-dessous pour afficher successivement les **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Mes sites</code>. Dans le tableau, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, à droite du site web créé automatiquement lors de la création de votre hébergement web, puis, dans le groupe **Noms de domaine**, sur <code className="action">Ajouter un nom de domaine</code>.

    <img className="thumbnail" alt="Menu Actions d’un site web et entrée Ajouter un nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    La page **Ajouter un domaine** s’ouvre. Renseignez-la de haut en bas, puis validez.
  </Tab>
</Tabs>

### 2 - Installer un « module en 1 clic » pour votre site web <a name="part-2"></a>

Sur ses hébergements web, OVHcloud propose d’installer gratuitement les CMS WordPress, Joomla!, PrestaShop et Drupal grâce à l’option « module en 1 clic ».

{/* CP-STEPS-START:installer-module */}

Cliquez sur les onglets ci-dessous pour afficher successivement les **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Modules</code>. Les trois cartes du haut indiquent le nombre de modules **Installés**, la **Version PHP** de votre hébergement web avec sa compatibilité, et le nombre de modules **disponibles**.

    <img className="thumbnail" alt="Onglet Modules et ses trois cartes de synthèse" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/tab.png" loading="lazy" />

    :::info
    Un module ne peut être installé que si la version PHP de votre hébergement web est compatible. Lorsqu’elle ne l’est pas, la carte affiche **Incompatible** et aucun module n’est proposé. Consultez la section « [Les versions de PHP](/guides/web-cloud/web-hosting/configure-your-web-hosting#php-versions) » de notre guide sur la configuration de votre hébergement web pour la faire évoluer.
    :::
  </Tab>
  <Tab label="Étape 3">
    Cliquez sur le bouton <code className="action">Ajouter un module</code>.
  </Tab>
  <Tab label="Étape 4">
    Un panneau s’ouvre sur la droite. Laissez le mode <code className="action">Simple</code> sélectionné, choisissez le CMS à installer sous **Choisir le module**, puis le nom de domaine sous **Domaine** — **sans les « www »** devant (exemple : `domain.tld` et non `www.domain.tld`). Cliquez enfin sur <code className="action">Installer</code>.

    <img className="thumbnail" alt="Panneau Installer un module, choix du CMS et du domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/install-module-drawer.png" loading="lazy" />
  </Tab>
</Tabs>

{/* CP-STEPS-END:installer-module */}

<details>

<summary>Cliquez ici pour plus d’informations.</summary>

Consultez nos guides détaillés :

- [Installer votre site web avec un « module en 1 clic » (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules).
- [Comment gérer votre module en 1 clic ?](/guides/web-cloud/web-hosting/cms-manage-1-click-module).

### 3 - Activer les adresses e-mail incluses avec votre hébergement web <a name="part-3"></a>

:::tip
Si vous avez souscrit votre nom de domaine et votre hébergement web dans une seule et même commande, les adresses e-mail incluses avec l’hébergement web sont déjà associées à votre nom de domaine. Passez directement à la [Partie 4](#part-4) de ce guide.

:::

{/* CP-STEPS-START:activer-email */}

Cliquez sur les onglets ci-dessous pour afficher successivement les **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans l’onglet <code className="action">Vue d’ensemble</code>, repérez la carte **Services offerts**. La mention **Adresses e-mails** y porte le nombre d’adresses incluses dans votre offre et l’état du service. Tant que celui-ci est **Inactif**, cliquez sur <code className="action">Activer mon offre e-mail</code> juste en dessous.

    <img className="thumbnail" alt="Carte Services offerts et lien Activer mon offre e-mail" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/complimentary-services.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Le parcours d’activation comporte deux étapes. Sous **Adresses e-mails**, sélectionnez le nom de domaine concerné. Sous **Activation**, acceptez les contrats puis validez : votre bon de commande OVHcloud s’ouvre, cette option étant incluse gratuitement dans votre offre d’hébergement web.
  </Tab>
</Tabs>

{/* CP-STEPS-END:activer-email */}

<details>

<summary>Cliquez ici pour plus d’informations.</summary>

Consultez notre guide détaillé « [Hébergement web - Activer les adresses e-mails incluses](/guides/web-cloud/web-hosting/activate-email-hosting) ».

</details>

### 4 - Créer une adresse e-mail personnalisée avec votre nom de domaine <a name="part-4"></a>

{/* CP-STEPS-START:creer-adresse-email */}

Cliquez sur les onglets ci-dessous pour afficher successivement les **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/email">Emails</ManagerLink>. Le tableau liste l’ensemble de vos services de messagerie ; repérez la ligne dont la colonne **Type d’offre** mentionne `MX Plan`, puis cliquez dessus.

    <img className="thumbnail" alt="Page Emails et colonne Type d’offre des services de messagerie" src="/images/assets/screens/console/product-selection/web-cloud/email-and-collaborative-solutions/emails-listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Compte email</code>. La carte **Quota de comptes e-mail** indique le nombre d’adresses déjà configurées sur le total inclus dans votre offre.

    <img className="thumbnail" alt="Onglet Compte email d’un service MX Plan et ses comptes" src="/images/assets/screens/console/product-selection/web-cloud/email-and-collaborative-solutions/mx-plan/email-account-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Cliquez sur le bouton <code className="action">Ajouter un compte</code>.
  </Tab>
  <Tab label="Étape 4">
    Un panneau s’ouvre sur la droite. Renseignez le **Nom du compte**, qui précède le `@` de votre nom de domaine, puis son **Mot de passe**. La **Description** est facultative et la **Taille du compte** est celle incluse dans votre offre. Cliquez enfin sur <code className="action">Ajouter</code>.

    <img className="thumbnail" alt="Panneau Ajouter un compte et ses champs de création" src="/images/assets/screens/console/product-selection/web-cloud/email-and-collaborative-solutions/mx-plan/add-account-drawer.png" loading="lazy" />
  </Tab>
</Tabs>

{/* CP-STEPS-END:creer-adresse-email */}

Répétez cette opération pour chaque adresse e-mail que vous souhaitez créer (dans la limite de votre offre d’hébergement web).

<details>

<summary>Cliquez ici pour plus d’informations.</summary>

Consultez notre guide détaillé « [Créer une adresse e-mail avec son offre MX Plan](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-creation) ».

</details>

### 5 - Options complémentaires disponibles avec votre hébergement web <a name="part-5"></a>

Votre hébergement web n’est pas limité à l’installation d’un « module en 1 clic ». Vous pouvez héberger des sites web créés par vos soins ou par un développeur web (blog, CMS, boutique en ligne, etc.). Si vous souhaitez en apprendre davantage sur les possibilités de votre hébergement web, n’hésitez pas à consulter notre guide plus détaillé « [Comment créer un site web - Réaliser votre projet en 5 étapes](/guides/web-cloud/web-hosting/website-project) ».
