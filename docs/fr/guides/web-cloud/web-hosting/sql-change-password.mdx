## Objectif

La majeure partie des sites Web utilisent une **base de données** pour y stocker leurs articles, les commentaires ou encore les adresses e-mail de leurs utilisateurs.

La connexion à cette base de données est rendue possible par un **fichier de configuration** contenu dans [l’espace de stockage de fichiers](/guides/web-cloud/web-hosting/ftp-connection) de votre hébergement. Il contient les informations permettant à votre site de « s’identifier » auprès de son **serveur de base de données**.

Le changement de mot de passe d’une base de données doit donc toujours être effectué :

- Dans le [fichier de configuration](/guides/web-cloud/web-hosting/cms-manage-1-click-module#etape-1-identifier-la-base-de-donnees-lie-a-votre-module) de votre site via [l’espace FTP de votre hébergement](/guides/web-cloud/web-hosting/ftp-connection);

- **Et** dans le serveur contenant sa base de données via votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>.

Tant que ce changement n’aura pas été effectué **dans ces deux endroits**, votre site affichera une « [erreur de connexion à la base de données](/guides/web-cloud/web-hosting/diagnosis-database-errors#erreur-lors-de-la-connexion-a-la-base-de-donnees) ».

Il est donc impératif, si vous souhaitez changer le mot de passe de votre base de données, que vous réalisiez **l’ensemble des opérations** indiquées dans ce guide. En cas de doutes sur les manipulations à réaliser, contactez votre webmaster ou faites appel à un [prestataire spécialisé](/links/partner).

La modification du mot de passe de la base de données de votre site nécessite quatre actions :

- [1 : identifier le fichier de configuration de votre site](#step1);
- [2 : identifier la base de données de votre site](#step2);
- [3 : modifier le mot de passe de la base de données de votre site dans son fichier de configuration](#step3);
- [4 : modifier le mot de passe de la base de données de votre site sur le serveur de bases de données](#step4).

**Découvrez comment changer le mot de passe d’une base de données de façon sécurisée.**

## Prérequis

- Disposer d’une [offre d’hébergement web OVHcloud](/links/web/hosting).
- Utiliser une [base de données associée à votre offre d’hébergement mutualisé](/links/web/hosting-options-startsql) ou à un [serveur Web Cloud Databases](/links/web/databases).
- Être en possession des identifiants FTP permettant de se connecter à l'[espace de stockage](/guides/web-cloud/web-hosting/ftp-connection) de votre hébergement.

## En pratique

### 1 : identifier le fichier de configuration de votre site <a name="step1"></a>

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Mes sites</code>.

    <img className="thumbnail" alt="Onglet Mes sites d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le tableau, repérez la ligne de votre site web grâce à la colonne **Site**, puis lisez sa colonne **Dossier racine**. Il s’agit du répertoire dans lequel se trouvent les fichiers et dossiers de votre site.

    <img className="thumbnail" alt="Tableau des sites et sa colonne Dossier racine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/root-folders.png" loading="lazy" />

    Accédez ensuite à l’espace de stockage FTP contenant les fichiers et dossiers de votre site en consultant [ce guide](/guides/web-cloud/web-hosting/ftp-connection).
  </Tab>
</Tabs>

{/* CP-STEPS-END:identifier-fichier-configuration */}

:::info
Si vous souhaitez modifier le mot de passe de votre espace FTP, consultez ce [guide](/guides/web-cloud/web-hosting/ftp-change-password).

:::

Ouvrez le `Dossier racine` identifié plus haut.

Recherchez et ouvrez le fichier de configuration de votre site :

- Pour un site WORDPRESS, il s’agit de **« wp-config.php »**;
- Pour un site JOOMLA, il s’agit de **« configuration.php »**;
- Pour un site DRUPAL, cliquez sur le dossier **« sites »** puis **« default »**. Le fichier de configuration est **« settings.php »**;
- Pour un site PRESTASHOP, cliquez sur le dossier **« app »** puis **« config »**. Le fichier de configuration est **« parameters.php »**.

### 2 : identifier la base de données de votre site <a name="step2"></a>

Deux cas sont possibles :

- Cas n°1 : la base de données de votre site fait partie de votre offre d’hébergement;
- Cas n°2 : elle est incluse dans une offre *Web Cloud Databases*, auquel cas vous devrez retrouver le **nom du serveur** et le **nom d’utilisateur** de votre base de données, afin d’identifier cette dernière sans risque d’erreur.

Afin de déterminer quel cas s’applique à votre site, dans le fichier de configuration identifié dans la [partie 1](#step1), commencez par noter le nom de sa base de données :

- Pour WORDPRESS : le nom apparaît sous la mention **« DB_NAME »**;
- Pour JOOMLA : le nom apparaît sous **« public $db »**;
- Pour DRUPAL : le nom apparaît sous **« database »**;
- Pour PRESTASHOP : le nom apparaît sous **« database_name »**.

{/* CP-STEPS-START:localiser-base-hebergement */}

Retournez ensuite dans votre <ManagerLink to="/beta/#/web-cloud/hosting">espace client OVHcloud</ManagerLink>, dans l’univers <code className="action">Web Cloud</code> :

- Rendez-vous dans la partie <code className="action">Hébergements web</code> puis dans l’hébergement concerné;
- Cliquez sur l’onglet <code className="action">Bases de données</code>, dans la barre d’onglets située sous le nom de votre hébergement;
- Recherchez le nom de la base de données trouvé précédemment dans la colonne **Nom de la base**;

{/* CP-STEPS-END:localiser-base-hebergement */}

Si vous avez retrouvé dans cette partie de votre espace client le nom de la base indiqué dans le fichier de configuration, passez à la [partie 3](#step3).

Dans le cas contraire, la base de données de votre site est liée à une offre [Web Cloud Databases](/links/web/databases).

Vous devez donc retourner dans le fichier de configuration de votre site, afin de noter le *nom du serveur* ainsi que le *nom d’utilisateur* de votre base de données :

- Pour WORDPRESS : le *nom du serveur* apparaît sous la mention **« DB_HOST »** et le *nom d’utilisateur* sous la mention **« DB_USER »**;
- Pour JOOMLA : le *nom du serveur* apparaît sous **« public $host »** et le *nom d’utilisateur* sous la mention **« public $user »**;
- Pour DRUPAL : le *nom du serveur* apparaît sous **« host »** et le *nom d’utilisateur* sous la mention **« username »**;
- Pour PRESTASHOP : le *nom du serveur* apparaît sous **« database_host »** et le *nom d’utilisateur* sous la mention **« database_user »**.

{/* CP-STEPS-START:localiser-base-wcdb */}

Rendez-vous ensuite dans la partie <code className="action">Web Cloud DB</code> de votre espace client, puis sélectionnez l’instance concernée.

Dans l’onglet <code className="action">Vue d’ensemble</code>, repérez la section **SQL** et son champ **Nom d’hôte** : il contient le nom du serveur de votre base de données trouvé précédemment.

:::warning
Ne confondez pas ce champ avec celui nommé **Hôte**, situé plus haut dans la section **Informations générales** : celui-ci désigne l’infrastructure qui héberge votre instance, et non l’adresse que votre site utilise pour s’y connecter.

:::

<img className="thumbnail" alt="Vue d’ensemble d’une instance Web Cloud DB et son champ Nom d’hôte" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/overview-hostname.png" loading="lazy" />

Toujours sur cette instance, rendez-vous dans l’onglet <code className="action">Utilisateurs et droits</code>, afin de repérer également le **nom d’utilisateur** de votre base de données. Chaque utilisateur y est présenté sous la forme d’une fiche portant son nom.

{/* CP-STEPS-END:localiser-base-wcdb */}

### 3 : Modifier le mot de passe de la base de données de votre site dans son fichier de configuration <a name="step3"></a>

:::info
Pour plus d’informations sur les bonnes pratiques en matière de gestion de mots de passe, suivez les instructions de ce [guide](/guides/account-and-service-management/account-information/manage-ovh-password).

:::

Choisissez le nouveau mot de passe de votre base de données et notez-le. Il devra respecter les conditions suivantes :

- Minimum 8 caractères;
- Maximum 30 caractères;
- Au moins une lettre majuscule;
- Au moins une lettre minuscule;
- Au moins un chiffre;
- Être composé uniquement de chiffres et de lettres.

De la même manière que dans la [partie 1](#step1), retournez dans l’espace de stockage de fichiers de votre hébergement puis ouvrez en édition le fichier de configuration de votre site.

**Avant toute modification**, enregistrez localement le contenu de ce fichier dans un document texte, afin d’en conserver une copie en cas d’erreur de manipulation.

Remplacez manuellement le mot de passe de votre base de données **en évitant de modifier ou supprimer tout autre élément du fichier de configuration** (Dans les extraits ci-dessous, seul le mot de passe d’exemple « *0VhCloudPa55w0rdDB123* » doit ainsi être remplacé) :

- Dans le fichier de configuration d’un site WORDPRESS, modifiez le **« DB_PASSWORD »** :

```php
// ** MySQL settings - You can get this info from your web host ** //
/** The name of the database for WordPress */
define('DB_NAME', 'dbname123');
 
/** MySQL database username */
define('DB_USER', 'dbname123');
 
/** MySQL database password */
define('DB_PASSWORD', '0VhCloudPa55w0rdDB123');
 
/** MySQL hostname */
define('DB_HOST', 'dbname123.mysql.db:3306');
```

- Dans le fichier de configuration d’un site JOOMLA, modifiez le **« public $password »** (tout à la fin du fichier de configuration) :

```php
public $host = 'dbname123.mysql.db:3306';
public $user = 'dbname123';
public $password = '0VhCloudPa55w0rdDB123';
public $db = 'dbname123';
```

- Dans le fichier de configuration d’un site DRUPAL, modifiez le **« password »** :

```php
$databases['default']['default'] = array (
  'database' => 'dbname123',
  'username' => 'dbname123',
  'password' => '0VhCloudPa55w0rdDB123',
  'prefix' => 'prefix123_',
  'host' => 'dbname123.mysql.db',
  'port' => '3306',
```

- Dans le fichier de configuration d’un site PRESTASHOP, modifiez le **« database_password »** :

```php
'database_host' => 'dbname123.mysql.db',
'database_port' => '3306',
'database_name' => 'dbname123',
'database_user' => 'dbname123',
'database_password' => '0VhCloudPa55w0rdDB123',
```

Sauvegardez cette modification.

### 4 : Modifier le mot de passe de la base de données de votre site sur le serveur de bases de données <a name="step4"></a>

{/* CP-STEPS-START:verifier-etat-operation */}

:::info
Cette opération nécessitera quelques minutes avant d’être effective. Après l’avoir lancée, pensez à vérifier son état dans l’onglet <code className="action">Opérations</code>, qui affiche le nombre d’opérations en cours.

:::

{/* CP-STEPS-END:verifier-etat-operation */}

A nouveau, deux cas sont possibles : 

- Si votre base de données se trouve dans la partie de votre <ManagerLink to="/">espace client OVHcloud</ManagerLink> dédiée à votre [hébergement web](/links/web/hosting), suivez ces [instructions](#case1).
- Si votre base de données se trouve dans la partie de votre <ManagerLink to="/">espace client OVHcloud</ManagerLink> dédiée à votre offre [Web Cloud Databases](/guides/web-cloud/databases/landing-page-databases), suivez ces [instructions](#case2).

#### Cas n°1 : la base de données de votre site fait partie de votre offre d’hébergement <a name="case1"></a>

{/* CP-STEPS-START:changer-mot-de-passe-hebergement */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Bases de données</code>.

    <img className="thumbnail" alt="Onglet Bases de données d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Sur la ligne de la base de données de votre site, cliquez sur le bouton <code className="action">⁝</code> de la colonne **Actions**, puis sur <code className="action">Changer le mot de passe</code>.

    <img className="thumbnail" alt="Menu d’une ligne du tableau des bases de données" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Dans la fenêtre qui s’affiche, renseignez le nouveau mot de passe de votre base de données (défini dans [la partie 3](#step3)), confirmez-le puis cliquez sur <code className="action">Modifier</code>.

    <img className="thumbnail" alt="Fenêtre de changement du mot de passe d’une base de données" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/change-password-window.png" loading="lazy" />

La fenêtre rappelle sous le champ la règle que ce mot de passe doit respecter : de **9 à 30 caractères**, dont une minuscule, une majuscule et un chiffre, et **uniquement des lettres et des chiffres**.
  </Tab>
</Tabs>

{/* CP-STEPS-END:changer-mot-de-passe-hebergement */}

#### Cas n°2 : la base de données de votre site fait partie d’une offre Web Cloud Databases <a name="case2"></a>

{/* CP-STEPS-START:changer-mot-de-passe-wcdb */}

Rendez-vous dans la partie <code className="action">Web Cloud DB</code> de votre espace client, sélectionnez l’instance concernée, puis cliquez sur l’onglet <code className="action">Utilisateurs et droits</code> :

<img className="thumbnail" alt="Onglet Utilisateurs et droits d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />

Chaque utilisateur est présenté sous la forme d’une fiche portant son nom. Sur celle du **nom d’utilisateur** identifié dans la [partie 2](#step2), cliquez sur le bouton <code className="action">⁝</code>, puis sur <code className="action">Modifier le mot de passe</code>.

<img className="thumbnail" alt="Menu d’une fiche utilisateur d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />

Dans la fenêtre qui s’affiche, renseignez le nouveau mot de passe de votre base de données (défini dans la [partie 3](#step3)), confirmez-le puis cliquez sur <code className="action">Enregistrer</code>.

<img className="thumbnail" alt="Fenêtre de modification du mot de passe d’un utilisateur" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password-window.png" loading="lazy" />

:::warning
La règle de complexité n’est pas la même que pour une base de données d’hébergement web : ici, le mot de passe doit comporter de **8 à 30 caractères**, dont une minuscule, une majuscule et un chiffre, et **les caractères spéciaux sont autorisés**. La fenêtre la rappelle sous le champ.

:::

{/* CP-STEPS-END:changer-mot-de-passe-wcdb */}
