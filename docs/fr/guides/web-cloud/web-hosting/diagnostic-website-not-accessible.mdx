## Prérequis

- Avoir la gestion des serveurs et de la [zone DNS](/guides/web-cloud/domains/dns-zone-edit) de votre domaine
- Être à jour dans les [paiements](/guides/account-and-service-management/managing-billing-payments-and-services/invoice-management#pay-bills) et [renouvellements](/guides/account-and-service-management/managing-billing-payments-and-services/automatic-renewal) des services liés (nom de domaine et hébergement web)

## En pratique

### 1 - Vérifier la validité de votre nom de domaine

:::warning
Le renouvellement de vos offres est sous votre entière responsabilité.<br/>
OVHcloud, en tant qu’hébergeur, a l’obligation de supprimer définitivement les services (domaines, hébergements, e-mails, etc.) qui n’ont pas été renouvelés à temps, ainsi que l’ensemble des données qu’ils contiennent.

De ce fait, nous vous recommandons fortement d’activer le [renouvellement automatique](/guides/account-and-service-management/managing-billing-payments-and-services/automatic-renewal#en-pratique) sur l’ensemble de vos abonnements OVHcloud.
:::

{/* CP-STEPS-START:renouvellement */}

Pour vérifier la validité de l’abonnement relatif à votre nom de domaine, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/customer/manage-services">Mes offres & services</ManagerLink>, puis repérez votre nom de domaine dans le tableau.

    <img className="thumbnail" alt="Page Mes offres & services filtrée sur les noms de domaine" src="/images/assets/screens/console/product-selection/account/manage-services-domains.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Renouvelez votre domaine si nécessaire via le bouton <code className="action">⋮</code> à droite de sa ligne, puis <code className="action">Renouveler le service</code>. Le renouvellement s’effectue dans une nouvelle fenêtre.

    <img className="thumbnail" alt="Menu Actions d’un nom de domaine en renouvellement manuel avec Renouveler le service" src="/images/assets/screens/console/product-selection/account/manage-services-domain-actions.png" loading="lazy" />

    L’action <code className="action">Renouveler le service</code> n’apparaît que pour un domaine en renouvellement manuel. Si votre domaine est en renouvellement automatique, le menu propose à la place <code className="action">Anticiper le paiement</code>.
  </Tab>
  <Tab label="Étape 3">
    Suite à ce renouvellement, votre site sera accessible sous 48 heures maximum.
  </Tab>
</Tabs>

{/* CP-STEPS-END:renouvellement */}

### 2 - Vérifier les serveurs DNS

{/* CP-STEPS-START:acces-domaine */}

Pour vérifier la validité de vos [serveurs DNS](/guides/web-cloud/domains/dns-server-edit), accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

{/* CP-STEPS-END:acces-domaine */}

**Cliquez sur le scénario correspondant à votre situation pour afficher le contenu.**

<details>
<summary>Scénario 1 - Aucune anomalie sur les serveurs DNS</summary>

{/* CP-STEPS-START:scenario-1 */}

Pour vérifier les serveurs DNS déclarés, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Le nom de domaine s’ouvre sur l’onglet <code className="action">Vue d’ensemble</code>. Vérifiez les serveurs indiqués dans la liste **Serveurs DNS hébergeant la zone** de la section **Serveurs DNS** :

    <img className="thumbnail" alt="Section Serveurs DNS avec la configuration et la liste des serveurs DNS hébergeant la zone" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/dns-servers-ovhcloud.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    S’ils sont identiques aux cibles des entrées de type `NS` dans l’onglet <code className="action">Zone DNS</code>, passez à la [partie 3](#etape3). Pour n’afficher que ces entrées, déroulez le menu <code className="action">Tous les types</code> et sélectionnez <code className="action">NS</code> :

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements NS d’un nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-ns.png" loading="lazy" />
  </Tab>
</Tabs>

{/* CP-STEPS-END:scenario-1 */}

</details>

{/* CP-STEPS-START:scenario-2 */}

<details>
<summary>Scénario 2 - Un avertissement apparaît au-dessus de la zone DNS</summary>

Au-dessus de la zone DNS présente dans votre console OVHcloud, un avertissement indique « **Cette zone DNS n’est pas autoritaire pour votre nom de domaine.** » : les serveurs DNS utilisés par votre domaine ne sont pas ceux indiqués dans votre zone. Pour savoir lesquels sont utilisés, consultez la liste **Serveurs DNS hébergeant la zone** dans la section **Serveurs DNS** de l’onglet <code className="action">Vue d’ensemble</code> du nom de domaine.

<img className="thumbnail" alt="Section Serveurs DNS avec la configuration et la liste des serveurs DNS hébergeant la zone" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/dns-servers-ovhcloud.png" loading="lazy" />

Deux cas sont possibles :

- Les serveurs indiqués sont du type « ns **?** .ovh.net » et « dns **?** .ovh.net » (remplacez le « **?** » par n’importe quel numéro) :

Modifiez les serveurs DNS en suivant les instructions de [ce guide](/guides/web-cloud/domains/dns-server-edit), afin qu’ils soient identiques aux cibles des entrées de type `NS` dans la **Zone DNS**.

Votre site sera de nouveau accessible sous 48 heures maximum.

- Les serveurs indiqués ne sont pas du type « ns **?** .ovh.net » et « dns **?** .ovh.net » (la ligne **Configuration** de la section indique alors **Personnalisée**) :

:::warning
Dans cette situation, contactez l’hébergeur de votre Zone DNS, votre webmaster ou les [partenaires OVHcloud](/links/partner) avant toute manipulation.

Il est en effet possible que les serveurs DNS utilisés par votre nom de domaine soient fonctionnels et que le problème d’accès à votre site soit lié à une entrée manquante ou erronée dans la [zone DNS](/guides/web-cloud/domains/dns-zone-general-information). Toute modification des serveurs DNS dans cette situation peut rendre vos adresses e-mails ou d’autres applications en ligne indisponibles.
:::

It does not list the DNS servers in use, hence the pointer to the Overview « DNS servers » section. */}

</details>

{/* CP-STEPS-END:scenario-2 */}

{/* CP-STEPS-START:scenario-3 */}

<details>
<summary>Scénario 3 - Aucune entrée de type NS n’apparaît dans la zone DNS</summary>

La **Zone DNS** de votre domaine ne contient pas d’entrée de type `NS` : avec le filtre <code className="action">NS</code> du menu <code className="action">Tous les types</code>, le tableau n’affiche aucune ligne.

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, sélectionnez le nom de domaine concerné, puis ouvrez l’onglet <code className="action">Zone DNS</code>.

  </Tab>
  <Tab label="Étape 2">
    Effectuez une sauvegarde de la zone actuelle : au-dessus du tableau, ouvrez le menu <code className="action">Actions sur ma zone</code> et cliquez sur <code className="action">Modifier en mode textuel</code>.

    Copiez/collez le contenu de votre **Zone DNS** dans un document texte. Enregistrez localement ce document. Cette sauvegarde est essentielle : la réinitialisation de l’étape 3 recrée les entrées de type `NS` manquantes, mais elle remplace l’ensemble des entrées de la zone. Elle vous permettra de recréer ensuite, à l’identique, les entrées dont vous avez encore besoin (sous-domaines, entrées `TXT`, `CNAME`, etc.). Le même menu propose également <code className="action">Exporter la zone</code>, qui enregistre directement la zone dans un fichier.

    <img className="thumbnail" alt="Menu Actions sur ma zone avec Modifier en mode textuel et Réinitialiser ma zone DNS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Au-dessus du tableau, ouvrez le menu <code className="action">Actions sur ma zone</code> et cliquez sur <code className="action">Réinitialiser ma zone DNS</code>. Dans le panneau **Réinitialiser la zone DNS**, sélectionnez **Valeurs personnalisées**.

    Indiquez vos serveurs d’hébergement (**Où doit pointer votre nom de domaine ?**) et e-mail (**Vers quel serveur vos e-mails doivent-ils être acheminés ?**), puis cliquez sur <code className="action">Réinitialiser la zone</code>.

    <img className="thumbnail" alt="Panneau Réinitialiser la zone DNS avec les valeurs personnalisées" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/reset-zone.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Votre site sera de nouveau accessible sous 24 heures maximum.
  </Tab>
</Tabs>

</details>

{/* CP-STEPS-END:scenario-3 */}

### 3 - Vérifier la zone DNS <a name="etape3"></a>

Dans cette partie, vous allez retrouver l’adresse IP de votre hébergement, puis l’ajouter à votre **Zone DNS**.

Si votre site web est hébergé en dehors de l’infrastructure OVHcloud ou géré par une tierce personne, contactez l’hébergeur ou le prestataire concerné.

{/* CP-STEPS-START:ip-hebergement */}

Si votre site web est hébergé sur l’une de nos [offres d’hébergement web](/links/web/hosting), cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    L’hébergement s’ouvre sur l’onglet <code className="action">Vue d’ensemble</code>. Dans la section **Informations générales**, vous trouverez les mentions **IPv4** et **IPv6**.

    <img className="thumbnail" alt="Section Informations générales, adresses IPv4 et IPv6" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/ipv4-ipv6.png" loading="lazy" />

    Copiez l’adresse IPv4 et/ou IPv6 à l’aide du bouton de copie situé à droite de chaque adresse.
  </Tab>
</Tabs>

Puis reportez-la dans la [zone DNS](/guides/web-cloud/domains/dns-zone-edit) de votre nom de domaine, en modifiant ou créant une ou plusieurs entrées de type `A`. Pour afficher les entrées existantes, utilisez le filtre <code className="action">A</code> du menu <code className="action">Tous les types</code> de l’onglet <code className="action">Zone DNS</code>.

<img className="thumbnail" alt="Menu Tous les types déroulé sur les types d’enregistrement" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-type.png" loading="lazy" />

{/* CP-STEPS-END:ip-hebergement */}

Votre site sera de nouveau accessible sous 24 heures maximum.
