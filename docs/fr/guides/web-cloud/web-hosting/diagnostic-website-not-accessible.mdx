## Objectif

Plusieurs retours d’erreur peuvent apparaître sur votre navigateur en cas d’inaccessibilité de votre site. Les exemples ci-dessous indiquent une configuration erronée de vos [serveurs DNS](/guides/web-cloud/domains/dns-server-edit), votre [zone DNS](/guides/web-cloud/domains/dns-zone-edit) ou un domaine suspendu (si votre site n’affiche pas l’un des messages d’erreur décrits ici, consultez la section [Aller plus loin](#go-further)) :

|Firefox :<br/>« Hum, nous ne parvenons pas à trouver ce site. »|<img className="thumbnail" alt="cantbereached_firefox" src="/images/assets/screens/other/browsers/errors/cant-be-reached-firefox.png" loading="lazy" />|

|Safari :<br/>« Safari ne parvient pas à trouver le serveur »|<img className="thumbnail" alt="cantbereached_safari" src="/images/assets/screens/other/browsers/errors/cant-be-reached-safari.png" loading="lazy" />|

**Découvrez comment résoudre les erreurs du type « Ce site est inaccessible »**

:::warning
OVHcloud met à votre disposition des services dont la configuration, la gestion et la responsabilité vous incombent. Il vous revient de ce fait d’en assurer le bon fonctionnement.

Nous mettons à votre disposition ce guide afin de vous accompagner au mieux sur des tâches courantes. Cependant, nous vous recommandons de faire appel à un [prestataire spécialisé](/links/partner) et/ou de contacter l’éditeur du service si vous éprouvez des difficultés. En effet, nous ne serons pas en mesure de vous fournir une assistance. Plus d’informations dans la section [Aller plus loin](#go-further) de ce guide.
:::

## En pratique

### 1 - Vérifier la validité de votre nom de domaine

:::warning
Le renouvellement de vos offres est sous votre entière responsabilité.<br/>
OVHcloud, en tant qu’hébergeur, a l’obligation de supprimer définitivement les services (domaines, hébergements, e-mails, etc.) qui n’ont pas été renouvelés à temps, ainsi que l’ensemble des données qu’ils contiennent.

De ce fait, nous vous recommandons fortement d’activer le [renouvellement automatique](/guides/account-and-service-management/managing-billing-payments-and-services/automatic-renewal#en-pratique) sur l’ensemble de vos abonnements OVHcloud.
:::

Pour vérifier la validité de l’abonnement relatif à votre nom de domaine, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/#/billing/autorenew/services">Mes offres et services</ManagerLink>.
  </Tab>
  <Tab label="Étape 2">
    Renouvelez votre domaine si nécessaire via le bouton <code className="action">...</code> à droite de l’écran, puis <code className="action">Renouveler le service</code>.

    <img className="thumbnail" alt="renew-service-button" src="/images/assets/screens/control-panel/product-selection/web-cloud/order/renew-service-button.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Suite à ce renouvellement, votre site sera accessible sous 48 heures maximum.
  </Tab>
</Tabs>

### 2 - Vérifier les serveurs DNS

Pour vérifier la validité de vos [serveurs DNS](/guides/web-cloud/domains/dns-server-edit), accédez à la page <ManagerLink to="/#/web-domains/domain">Noms de domaine</ManagerLink>, puis choisissez le nom de domaine concerné.

**Cliquez sur le scénario correspondant à votre situation pour afficher le contenu.**

<details>
<summary>Scénario 1 - Aucune anomalie sur les serveurs DNS</summary>

Pour vérifier les serveurs DNS déclarés, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/#/web-domains/domain">Noms de domaine</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Domain Names" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-names.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Vérifiez les serveurs indiqués dans l’onglet <code className="action">Serveurs DNS</code> :

    <img className="thumbnail" alt="srv-dns-ok2" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/name-dns-server.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    S’ils sont identiques aux cibles des entrées de type `NS` dans la **Zone DNS**, passez à la [partie 3](#etape3) :

    <img className="thumbnail" alt="Zone DNS affichant les enregistrements NS d’un nom de domaine" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-entry-ns.png" loading="lazy" />
  </Tab>
</Tabs>

</details>

<details>
<summary>Scénario 2 - Un avertissement apparaît au-dessus de la zone DNS</summary>

Au-dessus de la zone DNS présente dans votre espace client OVHcloud, un avertissement indique que les serveurs DNS utilisés par votre domaine ne sont pas ceux indiqués dans votre zone. Deux cas sont possibles :

- Les serveurs indiqués sont du type « ns **?** .ovh.net » et « dns **?** .ovh.net » (remplacez le « **?** » par n’importe quel numéro) :

<img className="thumbnail" alt="warning_other_ovh_dns_srv" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/message-other-ovh-dns-servers.png" loading="lazy" />

Modifiez les serveurs DNS en suivant les instructions de [ce guide](/guides/web-cloud/domains/dns-server-edit), afin qu’ils soient identiques aux cibles des entrées de type `NS` dans la **Zone DNS**.

Votre site sera de nouveau accessible sous 48 heures maximum.

- Les serveurs indiqués ne sont pas du type « ns **?** .ovh.net » et « dns **?** .ovh.net » :

<img className="thumbnail" alt="warning_external_dns_srv" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/message-external-dns-servers.png" loading="lazy" />

:::warning
Dans cette situation, contactez l’hébergeur de votre Zone DNS, votre webmaster ou les [partenaires OVHcloud](/links/partner) avant toute manipulation.

Il est en effet possible que les serveurs DNS utilisés par votre nom de domaine soient fonctionnels et que le problème d’accès à votre site soit lié à une entrée manquante ou erronée dans la [zone DNS](/guides/web-cloud/domains/dns-zone-general-information). Toute modification des serveurs DNS dans cette situation peut rendre vos adresses e-mails ou d’autres applications en ligne indisponibles.
:::

</details>

<details>
<summary>Scénario 3 - Aucune entrée de type NS n’apparaît dans la zone DNS</summary>

La **Zone DNS** de votre domaine ne contient pas d’entrée de type `NS` :

<img className="thumbnail" alt="Zone DNS ne contenant aucun enregistrement NS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-entry-ns-missing.png" loading="lazy" />

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Dans la section `Web Cloud`, cliquez sur <ManagerLink to="/#/web-domains/domain">Noms de domaine</ManagerLink>, sélectionnez le nom de domaine concerné, puis ouvrez l’onglet **Zone DNS**.

  </Tab>
  <Tab label="Étape 2">
    Effectuez une sauvegarde de la zone actuelle : au-dessus du tableau, ouvrez le menu <code className="action">Actions sur ma zone</code> et cliquez sur <code className="action">Modifier en mode textuel</code> :

    Copiez/collez le contenu de votre **Zone DNS** dans un document texte. Enregistrez localement ce document.
  </Tab>
  <Tab label="Étape 3">
    Au-dessus du tableau, ouvrez le menu <code className="action">Actions sur ma zone</code> et cliquez sur <code className="action">Réinitialiser ma zone DNS</code>, puis sélectionnez <code className="action">Non, mais je veux réinitialiser ma zone DNS.</code>.

    Indiquez vos serveurs e-mail et d’hébergement, puis cliquez sur <code className="action">Valider</code>.

    <img className="thumbnail" alt="Panneau de réinitialisation de la zone DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-reset-zone.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Votre site sera de nouveau accessible sous 24 heures maximum.
  </Tab>
</Tabs>

</details>

### 3 - Vérifier la zone DNS <a name="etape3"></a>

Dans cette partie, vous allez retrouver l’adresse IP de votre hébergement, puis l’ajouter à votre **Zone DNS**.

Si votre site web est hébergé en dehors de l’infrastructure OVHcloud ou géré par une tierce personne, contactez l’hébergeur ou le prestataire concerné.

Si votre site web est hébergé sur l’une de nos [offres d’hébergement web](/links/web/hosting), cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/#/web/hosting">Hébergements</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans le cadre **Informations générales**, vous trouverez les mentions **IPv4** et **IPv6**.

    <img className="thumbnail" alt="IPv4-IPv6" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-ipv4-and-ipv6.png" loading="lazy" />

    Copiez l’adresse IPv4 et/ou IPv6 de votre nom de domaine.
  </Tab>
</Tabs>

Puis reportez-la dans la [zone DNS](/guides/web-cloud/domains/dns-zone-edit) de votre nom de domaine, en modifiant ou créant une ou plusieurs entrées de type `A`.

<img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements A" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-a.png" loading="lazy" />

Votre site sera de nouveau accessible sous 24 heures maximum.
