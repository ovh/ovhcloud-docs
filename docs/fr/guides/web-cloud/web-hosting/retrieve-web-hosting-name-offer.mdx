import { Tab, Tabs } from '@rspress/core/theme';

## Objectif

Vous ne vous souvenez plus du nom de votre [offre d’hébergement web](/links/web/hosting) ?
Vous souhaitez consulter ses détails ou la comparer à une autre offre ?

Au cours de l’utilisation de vos services, vous pourriez avoir besoin du nom de votre offre d’hébergement web.

**Découvrez comment identifier le type d’offre d’hébergement web dont vous disposez depuis votre espace client OVHcloud.**

## Prérequis

- Disposer d’une [offre d’hébergement web](/links/web/hosting).

[[cpnav:web-hosting]]

## En pratique

{/* CP-STEPS-START:retrouver-nom-offre */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans l’onglet <code className="action">Vue d’ensemble</code>, repérez la carte **Abonnement**. Le nom de votre offre d’hébergement web y figure sous la mention **Offre** (par exemple : Perso, Pro, Performance).

    <img className="thumbnail" alt="Carte Abonnement et nom de l’offre sous la mention Offre" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/subscription-card.png" loading="lazy" />
  </Tab>
</Tabs>

{/* CP-STEPS-END:retrouver-nom-offre */}
