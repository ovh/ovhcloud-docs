## Objectif

Si vous avez commandé un hébergement web sans l’attacher directement à un nom de domaine, l’offre e-mail incluse avec votre hébergement devra être activée manuellement. Vous pourrez associer celle-ci au nom de domaine de votre choix.

**Découvrez comment activer les adresses e-mails incluses avec votre offre d’hébergement web.**

## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains) dans votre console OVHcloud.
<Region zones={['eu']}>
- Posséder une [offre d’hébergement web](/links/web/hosting) (hors offres « Hébergement gratuit » et « Start10m »).
</Region>
<Region zones={['ca', 'apac']}>
- Posséder une [offre d’hébergement web](/links/web/hosting).
</Region>

:::warning
Si vous souhaitez activer l’option « adresse(s) e-mail incluse(s) avec votre hébergement web » pour un nom de domaine externe (non enregistré chez OVHcloud) **dont vous devez être obligatoirement l’administrateur**, vous devez créer (a minima) une zone DNS chez OVHcloud pour votre nom de domaine externe. Consultez notre guide « [Créer une zone DNS chez OVHcloud](/guides/web-cloud/domains/dns-zone-create) » si nécessaire. Cela permettra à votre nom de domaine d’apparaître dans la liste des noms de domaine disponibles lors de l’activation de l’option.

Par ailleurs, si votre nom de domaine est déjà enregistré chez OVHcloud ou si une zone DNS existe déjà pour ce dernier dans un autre <ManagerLink to="/">compte OVHcloud</ManagerLink> que le vôtre, consultez notre documentation « [Gérer les contacts de ses services](/guides/account-and-service-management/account-information/managing-contacts) » pour en récupérer la gestion.

Enfin, si votre nom de domaine est déjà lié à l’option « adresse(s) e-mail incluse(s) avec votre hébergement web » d’un autre hébergement web, vous ne pourrez pas l’associer à votre propre hébergement web directement. Faites le point avec l’actuel gestionnaire de l’hébergement web en vous aidant de ce guide.

:::

## En pratique

### Activation de vos adresses e-mail incluses avec votre offre d’hébergement web

{/* CP-STEPS-START:activation */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    L’hébergement s’ouvre sur l’onglet <code className="action">Vue d’ensemble</code>. Dans la section **Services offerts**, vous trouverez la mention **Adresses e-mails**.
    Cliquez sur le lien <code className="action">Activer mon offre e-mail</code> situé en dessous.

    <img className="thumbnail" alt="Lien Activer mon offre e-mail dans la section Services offerts" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/activate-email-entry.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    La page **Activez vos adresses e-mails** s’affiche. Choisissez le nom de domaine auquel vous souhaitez attacher vos adresses e-mail dans la liste **Choisissez le nom de domaine que vous désirez utiliser avec vos e-mails**, puis cliquez sur <code className="action">Activer</code>.

    Votre bon de commande OVHcloud s’ouvre alors : validez votre choix pour confirmer la commande.

    <img className="thumbnail" alt="Page Activez vos adresses e-mails avec la liste des noms de domaine et le récapitulatif" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/activate-email-page.png" loading="lazy" />
  </Tab>
</Tabs>

{/* CP-STEPS-END:activation */}

:::info
Si vous souhaitez obtenir davantage de comptes e-mails inclus, nous vous invitons à commander une [offre d’hébergement web](/links/web/hosting) supérieure depuis notre page commerciale.

Attention : l’activation de l’option e-mail peut prendre quelques minutes. Vous recevrez un e-mail pour vous confirmer l’installation et l’activation de l’offre MXPLAN. Elle inclut notamment la gestion et la configuration de vos adresses e-mail.

:::

{/* CP-STEPS-START:delier-option */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    L’hébergement s’ouvre sur l’onglet <code className="action">Vue d’ensemble</code>. Dans la section **Services offerts**, vous trouverez la mention **Adresses e-mails**.
    Cliquez sur le bouton <code className="action">⋮</code> à droite puis sur <code className="action">Délier mon option e-mail</code>.

:::

  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

#### Cas particulier - Suppression de l’offre e-mail liée à votre hébergement web (afin de l’associer à un autre nom de domaine)

Pour des raisons de sécurité, la suppression définitive d’une offre e-mail peut prendre plusieurs jours après avoir cliqué sur le lien de validation de suppression.

Si vous souhaitez supprimer l’offre e-mail liée à votre hébergement web afin de l’associer à un autre nom de domaine, et **uniquement** dans ce cas précis, vous devez confirmer par écrit votre demande d’accélération de suppression de l’offre. Pour cela, contactez le support en créant un ticket d’assistance depuis votre [centre d’aide OVHcloud](/links/support-contact). Le ticket d’assistance doit **obligatoirement** être créé depuis le compte client (et l’identifiant client correspondant) qui administre le service à supprimer.

Une fois la demande traitée, vous pourrez alors associer l’offre e-mail liée à votre hébergement web à un autre nom de domaine.
