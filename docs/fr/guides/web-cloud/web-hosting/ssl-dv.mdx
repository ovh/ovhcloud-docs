## Objectif

Les certificats Secure Socket Layer (SSL) permettent de chiffrer les échanges effectués depuis ou vers votre site web. Cela évite qu’une personne ou un robot malveillant ne vienne « écouter » clairement les requêtes émises depuis votre site web.

Nous proposons plusieurs types de certificats SSL sur nos offres d’[hébergement mutualisé OVHcloud](/links/web/hosting). Ils sont présentés dans notre guide « [Hébergement web - Gérer un certificat SSL](/guides/web-cloud/web-hosting/ssl-on-webhosting) ». Les certificats SSL sont incontournables pour la sécurité de votre site web.

Trois types de certificats SSL existent :

- Domain Validation (DV)
- Organization validation (OV)
- Extended Validation (EV)

Les niveaux de chiffrement SSL sont identiques entre ces trois types de certificat.

La principale différence réside dans le niveau de vérifications qui sera réalisé par l’Autorité de Certification (AC) qui délivre le certificat SSL et atteste de son authenticité.

Pour les hébergements mutualisés OVHcloud, l’autorité de certification délivrant les certificats SSL DV est [Sectigo](https://sectigostore.com).

:::warning
Une fois la commande du certificat réalisée et transmise à notre fournisseur de certificats/autorité de certification Sectigo, **aucun remboursement de commande n’est possible**.

:::

**Découvrez comment activer un certificat SSL Sectigo DV sur votre hébergement Web OVHcloud.**

## Prérequis

- Commander ou disposer d’un [hébergement mutualisé OVHcloud](/links/web/hosting).
- Commander ou disposer d’un [nom de domaine](/links/web/domains) et disposer des droits exclusifs sur son utilisation. Le nom de domaine ne doit pas déjà être lié à un certificat SSL.

## En pratique

:::warning
Les certificats SSL Sectigo DV proposés chez OVHcloud ne sont valables que pour l’un des deux cas suivants sur votre hébergement web :

- Un seul nom de domaine + son sous-domaine en « www » (par exemple : `domain.tld` et `www.domain.tld`).
- Un seul sous-domaine (par exemple : `sub.domain.tld`).

Si d’autres noms de domaine ou sous-domaines sont déclarés sur votre hébergement web et que vous souhaitez également leur attribuer un certificat SSL, vous pouvez soit :

- [Activer un certificat SSL gratuit Let's Encrypt](/guides/web-cloud/web-hosting/ssl-letsencrypt) (si ce n’est pas déjà le cas par défaut).
- Activer un (ou plusieurs) autre(s) certificat(s) SSL payant(s) ([Sectigo DV](/guides/web-cloud/web-hosting/ssl-dv) ou [Sectigo EV](/guides/web-cloud/web-hosting/ssl-ev)).
- [Installer votre propre certificat SSL](/guides/web-cloud/web-hosting/ssl-custom).

:::

**Avant de commander le certificat SSL Sectigo DV sur votre hébergement web**, vérifiez que **le nom de domaine/sous-domaine** concerné par votre certificat SSL : 

- pointe vers l’adresse IP de votre hébergement web. 
- est déclaré sur l’un des sites web de votre hébergement web.
- ne dispose pas déjà d’un certificat SSL actif.

:::info
Si vous souhaitez souscrire un certificat SSL Sectigo DV pour un nom de domaine (par exemple : `domain.tld`), vérifiez bien que son sous-domaine en « www » (par exemple : `www.domain.tld`) pointe bien également vers l’adresse IP de votre hébergement web et est correctement déclaré sur l’un des sites web de votre hébergement web.

En effet, le cas échéant et si vous commandez le certificat SSL Sectigo DV sans vous en assurer, vous devrez effectuer un correctif a posteriori. Vous devrez alors supprimer le certificat SSL Sectigo DV précédemment souscrit **sans être remboursé**, puis en commander un nouveau. L’objectif est que le nouveau certificat SSL Sectigo DV englobe bien à la fois votre nom de domaine `domain.tld` et son sous-domaine en « www » `www.domain.tld`.

Pour rappel, si vous souscrivez à un certificat SSL Sectigo DV directement pour un sous-domaine (par exemple : `sub.domain.tld`), vous n’êtes pas concerné par cette situation.

:::

### Commander le certificat SSL Sectigo DV

{/* CP-STEPS-START:commander-certificat-sectigo-dv */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">SSL</code>.

    <img className="thumbnail" alt="Onglet SSL d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Au-dessus du tableau des certificats, cliquez sur <code className="action">Ajouter un certificat</code>.

    <img className="thumbnail" alt="Bouton Ajouter un certificat au-dessus du tableau" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/order-a-sectigo-ssl-certificate.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Un panneau s’ouvre sur la droite. Sous **Type de certificat**, **Let's Encrypt** est sélectionné par défaut : cochez la carte **Sectigo**. Sous **Domaine à sécuriser**, sélectionnez le nom de domaine ou le sous-domaine concerné, puis cliquez sur <code className="action">Commander</code>. Le bon de commande s’ouvre dans un nouvel onglet, hors de la console.

    <img className="thumbnail" alt="Panneau Ajouter un certificat avec la carte Sectigo cochée" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/order-a-sectigo-ssl-certificate-select-domain.png" loading="lazy" />

Poursuivez la commande jusqu’au paiement afin de valider la demande de création du certificat SSL Sectigo DV pour votre nom de domaine et/ou sous-domaine sur votre hébergement web.
  </Tab>
</Tabs>

{/* CP-STEPS-END:commander-certificat-sectigo-dv */}

:::danger
Une fois la commande validée, la demande de certificat SSL Sectigo DV est envoyée à l’autorité de certification Sectigo.

Dès lors, aucun remboursement du SSL Sectigo DV n’est possible.

:::

L’installation du certificat SSL Sectigo DV peut prendre jusqu’à **24** heures.

### Vérifier l’activation du certificat SSL Sectigo DV

{/* CP-STEPS-START:verifier-activation-sectigo-dv */}

Pour vérifier que l’installation est terminée, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">SSL</code>.

    <img className="thumbnail" alt="Onglet SSL d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Repérez chaque nom de domaine et sous-domaine concerné dans la colonne **Domaine principal**, puis lisez sa colonne **Statut**. L’installation est terminée lorsqu’il affiche **Actif** ; tant qu’elle est en cours, il affiche **En création**.

    <img className="thumbnail" alt="Tableau des certificats SSL et sa colonne Statut" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/tab.png" loading="lazy" />

Pour suivre où en est la validation par l’autorité de certification, cliquez sur le bouton <code className="action">⁝</code> de la colonne **Actions**, puis sur <code className="action">Rapport de validation</code>. Cette action n’est proposée que pour les certificats Sectigo.
  </Tab>
</Tabs>

{/* CP-STEPS-END:verifier-activation-sectigo-dv */}

Votre certificat SSL Sectigo DV est désormais installé et actif. Vous pouvez dès à présent l’utiliser avec votre site web en passant, par exemple, votre [site web en HTTPS](/guides/web-cloud/web-hosting/ssl-activate-https-website).
