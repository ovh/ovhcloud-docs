## Objectif

Les « modules en 1 clic » permettent l’installation facile et rapide d’un site web (sans compétences techniques requises). Les « modules en 1 clic » sont en réalité des **C**ontent **M**anagement **S**ystem **(CMS)**. Par ce biais, OVHcloud propose l’installation des CMS les plus connus : *WordPress*, *Joomla!*, *Drupal* et *PrestaShop*.

**Découvrez comment installer votre site via nos « modules en 1 clic ».**

## Prérequis

- Disposer d’une offre d'[hébergement web OVHcloud](/links/web/hosting) incluant au moins une base de données.
- Utiliser une version récente de PHP et un environnement d’exécution compatible sur votre hébergement web OVHcloud. Découvrez l’état des différentes versions disponibles sur cette [page](https://webhosting-infos.hosting.ovh.net/). Si besoin, consultez notre [guide](/guides/web-cloud/web-hosting/configure-your-web-hosting) sur le sujet pour changer rapidement cette configuration.
- Un fichier « [.ovhconfig](/guides/web-cloud/web-hosting/configure-your-web-hosting) » configuré doit être présent à la racine FTP de votre hébergement web.
- Le répertoire (dossier racine) où sera installé votre « module en 1 clic » doit être vide ou actuellement inexistant.
- Le domaine (avec sous-domaine si souhaité) qui sera utilisé pour votre site web doit être déclaré dessus via l’onglet [Mes sites](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website) de votre hébergement web.

## En pratique

:::info
Si vous rencontrez des difficultés en suivant l’une des étapes décrites ci-dessous, consultez notre documentation spécifique sur les [erreurs les plus fréquentes liées aux « modules en 1 clic »](/guides/web-cloud/web-hosting/diagnostic-errors-module1clic).

:::

### 1 - Choisir correctement son CMS

Un CMS permet de concevoir un site web via une interface facile d’utilisation. Plusieurs types de CMS existent, certains sont préconçus par exemple pour réaliser un site de E-commerce, d’autres pour mettre en place un site vitrine, un blog, etc. Vous pouvez ainsi bénéficier d’une structure de site prête à l’emploi et personnalisable (thème, extensions, textes, etc.) à votre convenance.

Parmi tous les CMS, OVHcloud en propose 4 en installation automatique avec ses « modules en 1 clic ».

En utilisant cette solution, vous devez choisir parmi les 4 CMS cités plus haut. Si votre choix est déjà fait, poursuivez la lecture des différentes étapes de ce guide. Dans le cas contraire, consultez notre [comparatif des CMS](/links/web/hosting-cms-comparison) pour faire votre choix.

Si vous souhaitez installer un CMS indisponible via nos « modules en 1 clic », vous pouvez l’installer manuellement sur votre hébergement. Ceci sous réserve que ce CMS soit compatible avec nos offres d'[hébergement web OVHcloud](/links/web/hosting).

### 2 - Ajouter un « module en 1 clic »

Deux modes d’installation sont proposés :

- Installation **rapide** (mode <code className="action">Simple</code>, sélectionné par défaut) : OVHcloud réalise l’installation du CMS et vous communique vos identifiants pour l’administrer par e-mail sur votre adresse e-mail de contact OVHcloud. Il s’agit de la manière la plus facile et la plus rapide pour installer un « module en 1 clic ».
- Installation **avancée** (mode <code className="action">Avancé</code>) : permet de personnaliser la configuration à appliquer pour l’installation du CMS. Vous devez renseigner toutes les informations nécessaires au bon fonctionnement du CMS :
    - informations de connexion à votre base de données (serveur, nom d’utilisateur, port, mot de passe, etc.)
    - chemin d’installation dans l’espace de stockage FTP de votre hébergement
    - langue du CMS
    - identifiants administrateur (Nom d’administrateur, mot de passe, adresse e-mail, etc.)

:::warning
Le répertoire d’installation de votre « module en 1 clic » doit être vide et vous devez disposer d’au moins une base de données disponible en création sur votre hébergement web OVHcloud pour que l’installation s’effectue.

Pour une installation rapide, ne créez pas la base de données au préalable, le robot d’installation s’en chargera.

:::

**Cliquez sur l’un des 2 modes d’installation pour afficher le contenu.**

    Dans l’onglet <code className="action">Modules</code> de votre hébergement, cliquez sur le bouton <code className="action">Ajouter un module</code> pour ajouter un nouveau « module en 1 clic ».

    Dans le panneau **Installer un module** qui s’ouvre sur la droite, sélectionnez le mode <code className="action">Avancé</code>. Choisissez ensuite le CMS souhaité sous **Choisir le module**, puis sélectionnez dans la liste **Domaine** le domaine avec lequel vous désirez installer votre site web.     :::info
    Vérifiez, dans la section **Installation** du panneau, que le **Dossier d’installation** est bien celui dans lequel vous souhaitez installer votre « module en 1 clic » : **Par défaut (www)**, ou **Personnalisé** pour saisir un autre répertoire.

    Renseignez les informations suivantes pour la configuration du module :

    - **Dossier d’installation** (section **Installation**) : laissez **Par défaut (www)**, ou choisissez **Personnalisé** pour y renseigner des sous-répertoires (pour les utilisateurs avertis).
    - **Identifiant administrateur** (section **Accès administrateur**) : identifiant que vous utiliserez pour vous connecter à l’interface d’administration de votre CMS (Back Office). PrestaShop attend une adresse e-mail ; pour les autres CMS, utilisez uniquement des lettres, des chiffres, des points, des tirets bas et des tirets.

    Pour rappel, ce répertoire doit être totalement vide.

    Si besoin, consultez notre guide « [Comment partager mon hébergement web entre plusieurs sites](/guides/web-cloud/web-hosting/multisites-configure-multisite) » pour modifier le répertoire cible de votre nom de domaine.

    Le dossier final indiqué dans le dossier d’installation renseigné doit être obligatoirement et entièrement vide pour que l’installation aboutisse.

    Pour récupérer les identifiants de connexion à votre base de données créée sur une instance Web Cloud Databases, consultez notre guide « [Premiers pas avec Web Cloud Databases](/guides/web-cloud/databases/db-getting-started) ».

Le champ **Utilisateur** est prérempli, et le serveur comme le port sont repris automatiquement.
    - La base de données n’est pas encore créée sur votre hébergement web : le panneau indique qu’aucune base de données MySQL n’est disponible. [Créez votre base de données incluse avec votre hébergement](/guides/web-cloud/web-hosting/sql-create-database) depuis l’onglet <code className="action">Bases de données</code> (le bouton <code className="action">Créer une base de données</code> du panneau vous y conduit), puis revenez ajouter votre module et choisissez la base dans la liste **Nom de la base de données**.
    - La base de données est [créée sur votre instance Web Cloud Databases](/guides/web-cloud/databases/db-create-databases-users) : sélectionnez **Base externe** et complétez les informations demandées. L’instance et l’hébergement web doivent être hébergés dans le même centre de données (datacentre).
    - La base de données est créée sur un autre hébergement web OVHcloud : sélectionnez **Base externe** et complétez les informations demandées. La base de données et l’hébergement web doivent être hébergés dans le même centre de données.

    <img className="thumbnail" alt="Section Base de données du panneau, base OVHcloud sélectionnée" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/install-module-advanced-database.png" loading="lazy" />

    Pour une **Base externe**, renseignez les informations suivantes :

    <img className="thumbnail" alt="Section Base de données du panneau, base externe sélectionnée" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/install-module-advanced-external-database.png" loading="lazy" />

    - **Hôte** : renseignez le nom du serveur de votre base de données, présent dans l’e-mail d’installation ou dans la console OVHcloud.

    :::info
    - Le nom du serveur d’une base de données incluse avec votre offre d’hébergement web a cette forme : `NameOfYourDatabase.mysql.db`.

    - Le nom du serveur d’une base de données Web Cloud Databases commence par votre identifiant client OVHcloud et a la forme suivante : `OVHID(without-ovh)-XXX.eu.clouddb.ovh.net` où les **« X »** sont à remplacer par la référence de votre service Web Cloud Databases.

    :::

    - **Nom de la base de données** : ce nom a été défini lors de la création de la base de données dans la console OVHcloud.

    - **Port** : indiquez systématiquement le numéro **3306** (port par défaut, déjà renseigné) pour une base de données incluse avec votre hébergement web. Pour une base présente sur une instance Web Cloud Databases, consultez notre guide « [Premiers pas avec Web Cloud Databases](/guides/web-cloud/databases/db-getting-started) ».

    - **Utilisateur** : identique au nom de la base de données si vous utilisez une base de données incluse avec votre hébergement web.
    Pour les bases de données créées sur une offre Web Cloud Databases, consultez notre guide « [Premiers pas avec Web Cloud Databases](/guides/web-cloud/databases/db-getting-started) ».

    - **Mot de passe de la base de données** : il vous a été envoyé par e-mail lors de la création de la base de données. Vous l’avez peut-être modifié depuis.

### 3 - Personnaliser mon site

L’installation peut prendre une dizaine de minutes.

Une fois terminée, vous recevrez un e-mail confirmant la bonne installation du CMS. Cet e-mail vous invitera à vous connecter à l’interface d’administration de votre CMS. Vous pouvez ainsi modifier le thème de votre site web et y publier vos premiers contenus.

:::warning
Le support OVHcloud n’effectue pas d’accompagnement sur l’utilisation des CMS. Nous les proposons uniquement en installation **en 1 clic**.

:::

Pour toute aide sur les fonctionnalités de votre CMS, contactez l’éditeur du CMS installé. Vous trouverez auprès de ce dernier de la documentation pour vous accompagner dans votre projet.

|CMS|Documentation officielle|
|---|---|
|WordPress|[Premiers pas avec WordPress](https://codex.wordpress.org/fr:Premiers_pas_avec_WordPress)|

|Joomla|[Infos techniques Joomla (en anglais)](https://www.joomla.org/about-joomla/getting-started.html)|
|Drupal|[Bien démarrer avec Drupal](https://www.drupal.fr/documentation/bien-demarrer-drupal)|
