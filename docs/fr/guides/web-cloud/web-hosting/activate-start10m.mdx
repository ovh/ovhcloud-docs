## Objectif

Avec [l’hébergement gratuit](/links/web/domains-free-hosting), OVHcloud vous offre un hébergement Web de 100 Mo et un compte e-mail disposant de 5 Go de stockage. 
Ce guide vous présente comment activer cette offre sur votre [nom de domaine](/links/web/domains).

:::warning
Cet hébergement gratuit de 100 Mo convient pour une simple page Web de présentation, il **n’inclut pas de base de données**.
Il convient également si vous n’avez pas besoin de plusieurs adresses e-mail de type « MX Plan ». 
Si vous souhaitez mettre en place un site Web comprenant plusieurs pages et nécessitant une base de données, tel qu’un CMS (WordPress, Joomla!, PrestaShop, Drupal, etc.), nous vous invitons à commander directement l’une de [nos offres d’hébergement Web](/links/web/hosting) depuis notre site ou votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>.

:::

**Découvrez comment activer votre hébergement gratuit**

## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains) dans votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>, détaché de tout hébergement Web et sans aucun [MX Plan](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-generalities) associé.

:::info
L’hébergement gratuit est **uniquement** disponible pour nos clients en Europe.

:::

## En pratique

{/* CP-STEPS-START:activation */}

Pour activer votre hébergement gratuit, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur le tableau de bord du nom de domaine, descendez jusqu’à la section **Services associés**. Dans la colonne **Services**, rattachée à la catégorie **Site & Hébergement**, cliquez sur <code className="action">Nouvel hébergement gratuit 100 Mo</code>.

    Cette entrée n’apparaît que si le nom de domaine remplit les conditions décrites dans les prérequis : aucun hébergement web ni aucun MX Plan ne doit lui être associé.

    <img className="thumbnail" alt="Entrée Nouvel hébergement gratuit 100 Mo dans la section Services associés d’un nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/free-hosting-entry.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    La page **Activer l’hébergement gratuit** s’affiche. La section **Votre offre** vous rappelle l’offre choisie, **Hébergement Free 100M**, incluse avec votre nom de domaine.

    Dans la section **Configuration DNS**, choisissez les modifications à apporter sur votre zone DNS en cochant une case, les deux ou aucune :

    <img className="thumbnail" alt="Page Activer l’hébergement gratuit avec les sections Votre offre, Configuration DNS et Engagement" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/free-hosting-order.png" loading="lazy" />

    | Choix                                       	| Description                                                                                                               							|
    |--------------------------------------------	|-----------------------------------------------------------------------------------------------------------------------------------------------------------|
    | Entrée DNS A                         	| Le nom de domaine pointera vers l’adresse IP de l’hébergement gratuit.                                               								|
    | Entrée DNS MX 	| Les serveurs e-mail OVHcloud (`mx1.mail.ovh.net`, `mx2.mail.ovh.net`, `mx3.mail.ovh.net`, etc.) seront appliqués au nom de domaine. 	|

    Si vous ne cochez aucune case, votre nom de domaine continue de pointer vers ses entrées actuelles, même une fois l’hébergement gratuit mis en place. Vous devrez alors modifier vous-même votre zone DNS lorsque votre nouveau site sera prêt. Ce choix convient si vous ne souhaitez pas interrompre un site déjà en production.

    :::warning
    Si vous cochez l’une des deux cases `Entrée DNS A` et `Entrée DNS MX` ou les deux, cela écrasera la configuration initialement mise en place dans la zone DNS de votre nom de domaine.
    Cochez les deux cases pour configurer automatiquement votre nom de domaine avec l’hébergement gratuit et son service e-mail inclus.

    Si votre zone DNS n’est pas gérée dans votre console OVHcloud, vous devrez effectuer les modifications manuellement dans votre zone DNS externe.

    Pour plus de détails, consultez notre guide sur [l’édition d’une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit).

    :::

    La section **Engagement** vous indique que l’hébergement gratuit est renouvelé automatiquement et gratuitement chaque année, jusqu’à l’expiration de votre nom de domaine. Le récapitulatif affiché à droite reprend le nom de domaine, l’offre et le total de la commande.

    Cliquez sur <code className="action">Continuer</code> pour ouvrir le bon de commande, prenez connaissance des contrats, puis validez votre commande pour terminer la demande d’activation de votre hébergement gratuit.

    {/* v8-review: TO DOCUMENT — the « Continue » / « Continue order » buttons open the OVHcloud order form (order.eu.ovhcloud.com, express/review) in a new tab; it signed the test session out on 2026-10-08, so the contracts step that v6 showed as section 4 was not seen in the Console flow. Confirm the contracts are presented there. */}
  </Tab>
</Tabs>

{/* CP-STEPS-END:activation */}

:::info
Si votre projet est amené à évoluer rapidement vers un hébergement disposant d’une base de données, d’un espace de stockage plus important ou davantage d’adresses e-mail, vous pourrez basculer directement et uniquement de l’hébergement gratuit vers une offre d’hébergement **Perso** depuis votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>.

Une bascule vers l’offre **Pro** ou **Performance** nécessite de passer préalablement de l’offre d’hébergement gratuit à l’offre **Perso**.

Vous pouvez aussi choisir de supprimer l’offre gratuite en prenant soin de récupérer au préalable vos données d’hébergement et le contenu de votre adresse mail.

Pour plus de détails, consultez nos [offres d’hébergement](/links/web/hosting).

:::

Une fois votre commande validée, un e-mail vous sera transmis avec les informations de [connexion FTP](/guides/web-cloud/web-hosting/ftp-connection) à votre **hébergement gratuit**.

Consultez le guide de [création d’un compte E-mail MX Plan](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-creation) pour profiter de l’adresse e-mail incluse avec votre **hébergement gratuit**.
