## Objectif

Il est possible de voir apparaître sur votre navigateur Internet la page d’erreur « **Site non installé** », notamment lors de la première installation de votre site web.

<img className="thumbnail" alt="website not installed" src="/images/assets/screens/other/browsers/errors/site-not-installed.png" loading="lazy" />

**Découvrez comment identifier et résoudre la page d’erreur « Site non installé »**

[[fragment:support-scope]]

## Prérequis

- Disposer d’une [offre d’hébergement mutualisé](/links/web/hosting) OVHcloud.
- Disposer également de la gestion de la [Zone DNS](/guides/web-cloud/domains/dns-zone-edit) à laquelle est rattachée votre nom de domaine.

[[cpnav:web-hosting]]

## En pratique

La page « **Site non installé** » s’affiche pour deux raisons :

- 1: [Votre nom de domaine ou votre sous-domaine n’est pas déclaré correctement sur l’un des sites web présents sur votre hébergement web](#check-my-websites).
- 2: [Votre nom de domaine ne pointe pas vers l’adresse IP de votre offre d’hébergement web](#check-dns-domain).

Les 2 parties suivantes vous permettront de corriger l’erreur `Site non installé` dans ces deux cas.

### 1 - Vérifier la déclaration de votre nom de domaine ou de votre sous-domaine sur votre site web présent sur votre hébergement web <a name="check-my-websites"></a>

{/* CP-STEPS-START:verifier-declaration-domaine */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Mes sites</code>. Dans le tableau, cliquez sur le bouton <code className="action">⋮</code> situé dans la colonne **Actions**, à droite du site web concerné, puis, dans le groupe **Noms de domaine**, sur <code className="action">Gérer</code>.

    <img className="thumbnail" alt="Menu Actions d’un site web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Le panneau **Gérer mes domaines** s’ouvre à droite et liste les noms de domaine et sous-domaines associés à ce site web.

    |Scénarios|Actions à entreprendre|
    |---|---|
    |Le nom de domaine ou le sous-domaine lié à votre site web **apparaît** dans le panneau.|Si vous venez d’ajouter votre nom de domaine ou votre sous-domaine sur votre site web présent sur votre hébergement web, patientez environ **vingt minutes** puis rafraîchissez le cache de votre navigateur Internet. Si le message « Site non installé » apparaît toujours, passez à la [partie 2](#check-dns-domain).|
    |Le nom de domaine ou le sous-domaine lié à votre site web **n’apparaît pas** dans le panneau.|Ajoutez votre nom de domaine ou votre sous-domaine en suivant notre guide « [Comment associer un nom de domaine à un site web existant ?](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website) ».|
    |Le nom de domaine ou le sous-domaine **a été supprimé** du panneau sans action de votre part.|Votre nom de domaine ou sa zone DNS sont peut-être gérés depuis un autre compte. Ajoutez votre nom de domaine ou votre sous-domaine en suivant notre guide « [Comment associer un nom de domaine à un site web existant ? - Ajouter un nom de domaine externe](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website) ».|
  </Tab>
</Tabs>

{/* CP-STEPS-END:verifier-declaration-domaine */}

### 2 - Vérifier le pointage IP dans la zone DNS active de votre nom de domaine <a name="check-dns-domain"></a>

Cette étape consiste à vérifier que votre nom de domaine ou sous-domaine pointe bien vers l’adresse IP de votre hébergement web, depuis sa zone DNS active.

:::info
Pour en savoir plus sur la notion de DNS, consultez les pages suivantes :

- [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit);
- [Créer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-create);
- [Modifier les serveurs DNS d’un nom de domaine OVHcloud](/guides/web-cloud/domains/dns-server-edit).

:::

#### 2\.1 Identifier l’adresse IP de votre hébergement web OVHcloud

{/* CP-STEPS-START:identifier-ip-hebergement */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    L’hébergement s’ouvre sur l’onglet <code className="action">Vue d’ensemble</code>. Dans la section **Informations générales**, repérez la mention **IPv4**.

    <img className="thumbnail" alt="Section Informations générales, adresses IPv4 et IPv6" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/ipv4-ipv6.png" loading="lazy" />

    Copiez l’adresse IPv4 à l’aide du bouton de copie situé à sa droite, puis poursuivez la lecture du guide.
  </Tab>
</Tabs>

{/* CP-STEPS-END:identifier-ip-hebergement */}

Vous pouvez également retrouver l’adresse IP associée à votre hébergement web dans notre guide « [Liste des adresses IP associées aux hébergements web OVHcloud](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip) ».

#### 2\.2 Vérifier l’adresse IP notée dans la zone DNS active de votre nom de domaine

Vous devez maintenant vérifier que l’adresse IP de votre hébergement web apparaît dans la zone DNS active de votre nom de domaine.

:::info
Avant de poursuivre, dès lors où une modification survient dans la **zone DNS** active d’un nom de domaine, un délai de propagation de **4 à 24 heures** peut être nécessaire pour mettre les informations à jour sur le réseau DNS.

Si vous modifiez directement les **serveurs DNS** associés à votre nom de domaine, ce délai peut aller jusqu’à **48 heures** maximum.

:::

{/* CP-STEPS-START:verifier-pointage-zone-dns */}

La zone DNS se consulte depuis le nom de domaine, et non depuis l’hébergement web. Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />

    Sous chaque nom, la mention **Domain + Zone** ou **Zone only** indique si le nom de domaine est enregistré chez OVHcloud ou si seule sa zone DNS y est gérée.

    Cliquez ensuite sur l’onglet <code className="action">Zone DNS</code>.

    :::info
    Vous pouvez également ouvrir la zone depuis l’onglet <code className="action">Vue d’ensemble</code> du nom de domaine : la section **Zone DNS** y indique le nombre d’enregistrements et porte un bouton <code className="action">Gérer la zone DNS</code>.
    :::
  </Tab>
  <Tab label="Étape 2">
    Le tableau qui apparaît affiche un enregistrement DNS par ligne, réparti en quatre colonnes : **Sous-domaine**, **Type**, **Cible** et **TTL (en secondes)**.

    <img className="thumbnail" alt="Onglet Zone DNS et tableau des enregistrements" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/tab.png" loading="lazy" />

    Pour ne garder que les enregistrements qui nous intéressent ici, déroulez le menu <code className="action">Tous les types</code> et sélectionnez <code className="action">A</code>, puis recommencez avec <code className="action">AAAA</code>. Un champ de recherche permet par ailleurs de retrouver un sous-domaine précis.

    <img className="thumbnail" alt="Menu Tous les types déroulé sur les types d’enregistrement" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-type.png" loading="lazy" />

    :::info
    Si la barre d’onglets de votre nom de domaine se limite à **Vue d’ensemble**, **Zone DNS**, **DynHost** et **Redirections**, sans les onglets **Contacts**, **DNSSEC** ni **Hosts**, c’est que seule la zone DNS est gérée depuis votre espace client : le nom de domaine lui-même est enregistré ailleurs.

    <img className="thumbnail" alt="Barre d’onglets réduite d’une zone DNS sans nom de domaine associé" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/standalone-zone.png" loading="lazy" />

    Déterminez son « bureau d’enregistrement » ainsi que les serveurs DNS auxquels il est associé via notre outil [WHOIS](/links/web/domains-whois). Retrouvez et modifiez la zone DNS concernée en conséquence en suivant la rubrique dédiée du guide « [Comment associer un nom de domaine à un site web existant ? - Ajouter un nom de domaine externe](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website) ».
    :::

    Passez à l’étape 3 pour visualiser les différents scénarios possibles et les actions à entreprendre.
  </Tab>
  <Tab label="Étape 3">
    |Scénarios possibles|Action à entreprendre|
    |---|---|
    |Un enregistrement de type **A** (adresse IPv4) ou **AAAA** (adresse IPv6) porte, dans la colonne **Cible**, l’adresse IP de votre hébergement web relevée à l’étape précédente.|Ceci indique que la configuration de votre nom de domaine est correcte.<br/>Patientez le temps de la propagation DNS si la modification est récente.<br/><br/>Redémarrez vos appareils (PC, smartphone, box, etc.) et videz le cache de votre navigateur Internet. En effet, il est possible que l’ancienne configuration de votre nom de domaine soit encore conservée en cache, ce qui peut retarder l’affichage de votre mise à jour.|
    |Le tableau ne comporte aucun enregistrement de type **A** ou **AAAA** pour votre nom de domaine ou sous-domaine.|Ajoutez le nouvel enregistrement DNS de type A ou AAAA en suivant [ce guide](/guides/web-cloud/domains/dns-zone-edit).|
    |L’enregistrement de type **A** ou **AAAA** existe, mais sa **Cible** est une autre adresse IP que celle de votre hébergement web.|Corrigez l’enregistrement existant en suivant [ce guide](/guides/web-cloud/domains/dns-zone-edit).|
    |Un bandeau signale que cette zone DNS n’est pas autoritaire pour votre nom de domaine.|Les modifications faites ici ne sont pas prises en compte : votre nom de domaine utilise d’autres serveurs DNS. Modifiez-les en suivant notre guide « [Modifier les serveurs DNS d’un nom de domaine OVHcloud](/guides/web-cloud/domains/dns-server-edit) ».|
  </Tab>
</Tabs>
