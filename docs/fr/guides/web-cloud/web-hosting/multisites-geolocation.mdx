## Objectif

Les moteurs de recherche (Google, Bing, Yahoo, ...) utilisent des robots d’indexation et de référencement sur l’ensemble des sites web. Ils référencent en priorité les sites géolocalisés dans le pays depuis lequel vous effectuez votre recherche.

**Exemple**: Si vous lancez une recherche via un moteur de recherche et que vous vous situez en Angleterre, les sites web géolocalisés en Angleterre s’afficheront plus haut dans les résultats de recherche que les autres sites web.

Cette géolocalisation est basée sur l’adresse IP de l’hébergement où se trouve votre site web.

L’option de géolocalisation sur votre hébergement peut être utile pour le référencement (SEO) si votre site web a pour vocation d’être principalement consulté dans un pays différent de celui où se situe votre hébergement mutualisé.

## En pratique

Pour les sites web principalement consultés à l’étranger et hébergés sur notre infrastructure d’hébergements mutualisés OVHcloud, nous proposons une option de géolocalisation par adresse IP. Elle permet de mieux référencer les sites web dans le pays où se situe l’adresse IP choisie avec l’option.

Pour utiliser l’option de géolocalisation par IP, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

{/* CP-STEPS-START:geolocate-website */}
<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Entrée Web hosting du menu et liste des hébergements" src="/images/assets/screens/console/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page qui s’affiche, cliquez sur l’onglet <code className="action">Mes sites</code>.

    <img className="thumbnail" alt="Onglet Mes sites d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le tableau qui apparaît, cliquez sur le bouton <code className="action">⋮</code> situé dans la colonne <code className="action">Actions</code>, à droite du site web concerné. Dans la partie **Noms de domaine** du menu, cliquez sur <code className="action">Gérer</code>.

    <img className="thumbnail" alt="Menu Actions d’un site web dans la console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Le panneau <code className="action">Gérer mes domaines</code> s’ouvre et liste les noms de domaine et sous-domaines associés à ce site. Cliquez sur le bouton <code className="action">⋮</code> situé à droite du nom de domaine ou sous-domaine concerné, puis sur <code className="action">Gérer mes options</code>.

    <img className="thumbnail" alt="Panneau Gérer mes domaines et ses noms de domaine associés" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/associated-domains-options.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 5">
    Dans le panneau <code className="action">Gérer les options</code>, sélectionnez <code className="action">IP du pays</code> pour faire apparaître le menu déroulant <code className="action">Choisissez un pays</code>.

    <img className="thumbnail" alt="Option IP du pays et menu déroulant des pays disponibles" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/multisite/country-ip-selection.png" loading="lazy" />

    Choisissez l’adresse IP du pays pour lequel vous souhaitez géolocaliser votre site, parmi les 13 pays proposés : *Belgique, République tchèque, Allemagne, Espagne, Finlande, France, Irlande, Italie, Lituanie, Pays-Bas, Pologne, Portugal, Royaume-Uni*.

    Cliquez enfin sur <code className="action">Confirmer</code>.

    :::warning
    L’option <code className="action">IP du pays</code> et l’option <code className="action">Activer le CDN</code> appartiennent au même choix **Performance et diffusion** : elles s’excluent mutuellement. Sélectionner <code className="action">IP du pays</code> désactive le CDN sur ce nom de domaine.
    :::
  </Tab>
</Tabs>
{/* CP-STEPS-END:geolocate-website */}

:::info
Après avoir réalisé les étapes ci-dessus et si la zone DNS active de votre nom de domaine est entièrement gérée dans votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>, l’entrée de type A dans la zone DNS de votre nom de domaine se changera automatiquement. Vérifiez que l’adresse IP a bien été mise à jour à l’aide de notre guide sur [l’édition d’une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit).

Dans le cas contraire, vous devrez effectuer la modification manuellement auprès du fournisseur qui gère la zone DNS active de votre nom de domaine. Retrouvez [ici](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip) la documentation qui recense toutes les adresses IP de notre infrastructure d’hébergements mutualisés OVHcloud.

Dans les deux cas, un délai de propagation de **4 à 24 heures** après la modification sera nécessaire pour que celle-ci soit pleinement effective et visible sur Internet.

:::
