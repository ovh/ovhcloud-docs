## Objectif

*ModSecurity* est un module Apache complémentaire qui filtre toutes les requêtes entrantes sur votre serveur Web. Il renforce la sécurité contre les vulnérabilités connues en interceptant et en filtrant les demandes avant qu’elles ne soient traitées par des scripts.

L’ensemble préconfiguré de règles de base, le « Core Rule Set » (CRS), de notre *ModSecurity* protège vos sites Web contre les attaques les plus courantes, par exemple :

- Trojans
- Injections d’e-mails
- Failles des fichiers PDF
- Injections de fichiers sur votre hébergement
- Injections de type SQL ou XSS
- etc.

**Découvrez comment activer le pare-feu applicatif depuis votre espace client OVHcloud, afin d’obtenir une protection améliorée.**

:::info
Du fait que votre hébergement web est présent sur une infrastructure mutualisée, vous ne pouvez pas modifier les paramètres de configuration du pare-feu.

:::

## Prérequis

- Disposer d’une offre d'[hébergement web OVHcloud](/links/web/hosting).
- Disposer d’au moins un [nom de domaine](/links/web/domains) attaché à l’hébergement.

## En pratique

**Cliquez sur les titres ci-dessous pour afficher les explications.**

<details>
<summary>Activer le pare-feu applicatif sur l’ensemble de votre hébergement web dans la configuration PHP</summary>

{/* CP-STEPS-START:firewall-global-php */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    L’hébergement s’ouvre sur l’onglet <code className="action">Vue d’ensemble</code>. Repérez la section **PHP**, qui affiche la mention **Version PHP globale**, puis cliquez sur <code className="action">Modifier la version de PHP</code>.

    <img className="thumbnail" alt="Section PHP de l’onglet Vue d’ensemble" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/php-section.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Le panneau de configuration s’ouvre à droite. Dans la section **Options avancées**, ouvrez le menu déroulant **Pare-feu applicatif**, puis sélectionnez la valeur <code className="action">sécurité</code> : elle active `mod_security`, qui protège votre hébergement contre les attaques courantes. La valeur <code className="action">désactivé</code> laisse le pare-feu inactif.

    <img className="thumbnail" alt="Options avancées de la configuration PHP et menu Pare-feu applicatif" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/php-config-firewall.png" loading="lazy" />

    Cliquez enfin sur <code className="action">Valider</code>.

    :::warning
    Un changement de configuration peut affecter vos sites : pensez à les tester après toute modification.
    :::
  </Tab>
</Tabs>

{/* CP-STEPS-END:firewall-global-php */}

</details>

<details>
<summary>Activer le pare-feu applicatif uniquement sur un nom de domaine ou un sous-domaine spécifique</summary>

{/* CP-STEPS-START:firewall-par-domaine */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Mes sites</code>. Dans le tableau, cliquez sur le bouton <code className="action">⋮</code> situé dans la colonne **Actions**, à droite du site web concerné, puis, dans le groupe **Noms de domaine**, sur <code className="action">Gérer</code>.

    <img className="thumbnail" alt="Menu Actions d’un site web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Le panneau **Gérer mes domaines** s’ouvre à droite et liste les noms de domaine et sous-domaines associés à ce site web. Sur le domaine concerné, cliquez sur le bouton <code className="action">⋮</code> situé à droite de son nom, puis sur <code className="action">Gérer mes options</code>.

    <img className="thumbnail" alt="Panneau Gérer mes domaines et menu Actions d’un domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/manage-domains-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Dans la fenêtre **Gérer les options**, groupe **Sécurité**, cochez la case <code className="action">Activer le firewall</code>, puis cliquez sur <code className="action">Confirmer</code>.

    <img className="thumbnail" alt="Fenêtre Gérer les options d’un nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/country-ip-selection.png" loading="lazy" />

    :::info
    Le réglage s’applique au seul nom de domaine ou sous-domaine sélectionné. Pour protéger également le sous-domaine `www`, répétez l’opération sur sa ligne dans le panneau **Gérer mes domaines**, s’il y est déclaré.
    :::

    Une fois le pare-feu activé, la colonne **Firewall** du tableau des sites indique le nombre de noms de domaine protégés sur le nombre total associés au site web, par exemple `1/4`. Si ce décompte n’évolue pas au bout de quelques minutes, rechargez la page.
  </Tab>
</Tabs>

{/* CP-STEPS-END:firewall-par-domaine */}

</details>
