## Objectif

*ModSecurity* est un module Apache complémentaire qui filtre toutes les requêtes entrantes sur votre serveur Web. Il renforce la sécurité contre les vulnérabilités connues en interceptant et en filtrant les demandes avant qu'elles ne soient traitées par des scripts.

L'ensemble préconfiguré de règles de base, le « Core Rule Set » (CRS), de notre *ModSecurity* protège vos sites Web contre les attaques les plus courantes, par exemple :

- Trojans
- Injections d'emails
- Failles des fichiers PDF
- Injections de fichiers sur votre hébergement
- Injections de type SQL ou XSS
- etc.

**Découvrez comment activer le pare-feu applicatif depuis votre espace client OVHcloud, afin d'obtenir une protection améliorée.**

:::info
Du fait que votre hébergement web est présent sur une infrastructure mutualisée, vous ne pouvez pas modifier les paramètres de configuration du pare-feu.

:::

:::info
Certaines procédures de ce guide s'appliquent à la <ManagerLink to="/beta/#/">nouvelle version de l'espace client OVHcloud</ManagerLink>.
Un rappel est présent au début de chaque section concernée.

:::

## Prérequis

- Disposer d'une offre d'[hébergement web OVHcloud](/links/web/hosting).
- Disposer d'au moins un [nom de domaine](/links/web/domains) attaché à l'hébergement.

## En pratique

**Cliquez sur les titres ci-dessous pour afficher les explications.**

<details>
<summary>Activer le pare-feu applicatif sur l'ensemble de votre hébergement web dans la configuration PHP</summary>

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/#/web/hosting">Hébergements</ManagerLink>, puis choisissez l'hébergement web concerné.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans le cadre **Configuration**, vous trouverez la mention **Version PHP Globale**.

    <img className="thumbnail" alt="Global PHP version" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/modify-hosting-configuration.png" loading="lazy" />

    Cliquez sur le bouton <code className="action">...</code> à droite de la mention **Version PHP Globale**, puis sur <code className="action">Modifier la configuration</code>.
  </Tab>
  <Tab label="Étape 3">
    Dans la fenêtre qui s'ouvre, sélectionnez l'élément <code className="action">Modifier la configuration courante</code> et cliquez sur le bouton <code className="action">Suivant</code>.

    <img className="thumbnail" alt="managephpconfig" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/application-firewall-step-2.png" loading="lazy" />

    Dans la nouvelle fenêtre, assurez-vous que l'option **Pare-feu applicatif** est définie sur <code className="action">Activé</code>. Cliquez ensuite sur le bouton <code className="action">Valider</code>.
  </Tab>
</Tabs>

</details>

<details>
<summary>Activer le pare-feu applicatif uniquement sur un nom de domaine ou un sous-domaine spécifique</summary>

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

:::info
Cette section s'applique à la <ManagerLink to="/beta/#/">nouvelle version de l'espace client OVHcloud</ManagerLink>.

:::

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hébergements</ManagerLink>, puis choisissez l'hébergement web concerné.

    <img className="thumbnail" alt="Hébergements" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page qui s'affiche, cliquez sur l'onglet <code className="action">Mes sites</code>.

    <img className="thumbnail" alt="Mes sites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le tableau qui apparaît, cliquez sur le bouton <code className="action">></code> situé à gauche du nom du site web concerné pour afficher les noms de domaine et sous-domaines associés.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />

    Cliquez ensuite sur le bouton <code className="action">⁝</code> situé à droite du nom de domaine ou sous-domaine concerné, puis sur <code className="action">Modifier le domaine</code>.

    <img className="thumbnail" alt="Associated domains options" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/associated-domains-options.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Dans la fenêtre de configuration, cochez la case <code className="action">Activer le pare-feu</code>. Vous pouvez également inclure le sous-domaine `www` dans cette configuration en cochant la case correspondante en haut (si ce dernier est également déclaré sur le même site web).

    <img className="thumbnail" alt="Modify a domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/modify-a-domain-enable-firewall-step-1.png" loading="lazy" />

    Cliquez sur <code className="action">Suivant</code>, puis sur <code className="action">Confirmer</code> pour valider la modification des paramètres.

    Une fois le pare-feu activé pour votre nom de domaine ou sous-domaine, la mention **Activé** apparaît dans la colonne **Firewall**.

    Si la mention **Activé** n'apparaît pas au bout de quelques minutes sur la ligne correspondante au nom de domaine ou sous-domaine concerné, rechargez la page.
  </Tab>
</Tabs>

</details>
