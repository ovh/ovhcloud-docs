## Objectif

*ModSecurity* est un module Apache complémentaire qui filtre toutes les requêtes entrantes sur votre serveur Web. Il renforce la sécurité contre les vulnérabilités connues en interceptant et en filtrant les demandes avant qu’elles ne soient traitées par des scripts.

L’ensemble préconfiguré de règles de base, le « Core Rule Set » (CRS), de notre *ModSecurity* protège vos sites Web contre les attaques les plus courantes, par exemple :

- Trojans
- Injections d’e-mails
- Failles des fichiers PDF
- Injections de fichiers sur votre hébergement
- Injections de type SQL ou XSS
- etc.

**Ce guide vous explique comment activer le pare-feu applicatif depuis votre espace client OVHcloud, afin d’obtenir une protection améliorée.**

:::info
Du fait que votre hébergement web est présent sur une infrastructure mutualisée, vous ne pouvez pas modifier les paramètres de configuration du pare-feu.

:::

## En pratique

Connectez-vous à votre <ManagerLink to="/">espace client OVHcloud</ManagerLink> et sélectionnez <code className="action">Web Cloud</code>. Cliquez sur la section <code className="action">Hébergements</code> puis sur l’hébergement concerné.

### Activer le pare-feu applicatif dans la configuration PHP

Cliquez sur l’onglet <code className="action">Informations générales</code>. La `version PHP globale` actuelle s’affiche dans la zone **Configuration**. Cliquez sur le bouton <code className="action">...</code> et sélectionnez <code className="action">Modifier la configuration</code>. Dans la fenêtre qui s’ouvre, sélectionnez l’élément <code className="action">Modifier la configuration actuelle</code> et cliquez sur le bouton <code className="action">Suivant</code>.

<img className="thumbnail" alt="managephpconfig" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/application-firewall-step-2.png" loading="lazy" />

Dans la nouvelle fenêtre, assurez-vous que **Application firewall** est défini sur <code className="action">Activé</code>. Pour confirmer la configuration, cliquez sur le bouton <code className="action">Confirmer</code>.

### Activer le pare-feu applicatif pour les noms de domaine individuels sur un multisite

Cliquez sur l’onglet <code className="action">Multisite</code> de votre offre d’hébergement. Cliquez sur le bouton <code className="action">...</code> à droite du nom de domaine concerné et sélectionnez l’option <code className="action">Modifier le domaine</code>.

<img className="thumbnail" alt="managemultisite" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/modify-domain-2.png" loading="lazy" />

Dans la fenêtre de configuration, cochez la case <code className="action">Activer le pare-feu</code>. Vous pouvez également inclure le sous-domaine `www` dans cette configuration en cochant la case en haut.

Cliquez sur <code className="action">Suivant</code>, puis sur <code className="action">Confirmer</code> pour modifier les paramètres multisites.

<img className="thumbnail" alt="modifydomain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/modify-a-domain-enable-firewall-step-1.png" loading="lazy" />

### Vérifier l’état de la tâche d’activation

<img className="thumbnail" alt="gestion en cours" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/ongoing-tasks/firewall-planned.png" loading="lazy" />

Les tâches de mise à jour de votre configuration multisite seront répertoriées dans l’onglet <code className="action">Opérations en cours</code> (le statut initial est « Planifié »). Le pare-feu sera actif dès que sa tâche de mise à jour n’apparaîtra plus dans la liste.

### Vérification des noms domaine pour lesquels le pare-feu est activé

L’onglet <code className="action">Multisite</code> de votre offre d’hébergement fournit des informations sur les noms domaine pour lesquels l’option de pare-feu est activée.

<img className="thumbnail" alt="gérageenabled" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/firewall-enabled.png" loading="lazy" />

Le tableau affiché contient tous les noms de domaine qui ont été ajoutés à votre offre d’hébergement Web. Dans la colonne « Pare-feu » s’affiche le statut d’activation de chaque nom de domaine.
