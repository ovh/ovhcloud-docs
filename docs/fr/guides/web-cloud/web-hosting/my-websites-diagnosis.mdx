## Objectif

Vous pouvez héberger plusieurs sites web sur une même offre d'hébergement web, même si les noms de domaine ne sont pas enregistrés chez OVHcloud. De plus, vous pouvez associer un ou plusieurs noms de domaine ou sous-domaines à un même site web.

**Utilisez notre outil de diagnostic pour vérifier que votre nom de domaine ou sous-domaine est bien déclaré avec votre site web sur votre hébergement web.**

## Prérequis

- Disposer d'une offre d'[hébergement web OVHcloud](https://www.ovhcloud.com/fr/web-hosting/uc-multisite/) compatible.
- Disposer d'un ou de plusieurs [noms de domaine](https://www.ovhcloud.com/fr/domains/).
- Pouvoir modifier la configuration de vos noms de domaine depuis la [zone DNS](/guides/web-cloud/domains/dns-zone-edit).

## En pratique

### Accéder à l'outil de diagnostic

{/* CP-STEPS-START:acceder-outil-diagnostic */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Mes sites</code>. La colonne **Diagnostic** du tableau résume l’état de chaque site web, sans aucune manipulation préalable.

    <img className="thumbnail" alt="Colonne Diagnostic du tableau des sites web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-column.png" loading="lazy" />

    Trois valeurs sont possibles :

    - <code className="action">DNS OK</code> : tous les noms de domaine du site web pointent correctement vers votre hébergement web.
    - <code className="action">DNS à vérifier</code>, suivi du nombre de noms de domaine concernés : au moins un domaine présente un défaut de pointage. Cette mention est cliquable.
    - <code className="action">0 domaine</code> : aucun nom de domaine n’est associé à ce site web.
  </Tab>
  <Tab label="Étape 3">
    Pour obtenir le détail, cliquez sur la mention <code className="action">DNS à vérifier</code>. Le panneau **Gérer mes domaines** s’ouvre à droite, **filtré sur les seuls domaines en défaut** ; le bouton <code className="action">Afficher tous les domaines</code> affiche la liste complète.

    Si la colonne indique <code className="action">DNS OK</code>, la mention n’est pas cliquable : ouvrez le panneau par le bouton <code className="action">⋮</code> de la colonne **Actions**, puis, dans le groupe **Noms de domaine**, par <code className="action">Gérer</code>.

    <img className="thumbnail" alt="Panneau Gérer mes domaines, diagnostic conforme" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-ok.png" loading="lazy" />

    Chaque nom de domaine y porte une ligne **Diagnostic** avec deux indicateurs, **A** et **AAAA**, et un bouton <code className="action">Relancer le diagnostic</code>.

    Consultez la partie « [Interprétation des couleurs de l’outil de diagnostic](#interpretation) » de ce guide pour connaître la signification de ces indicateurs.

    :::info
    Le nom technique de votre hébergement web, de la forme `ftplogin.clusterXXX.hosting.ovh.net`, apparaît dans cette liste avec la mention **Technique**. Il n’est pas diagnostiqué : il pointe vers votre hébergement web par construction.
    :::
  </Tab>
</Tabs>

{/* CP-STEPS-END:acceder-outil-diagnostic */}

### Interprétation des couleurs de l'outil de diagnostic <a name="interpretation"></a>

{/* CP-STEPS-START:interpretation-couleurs */}

Les indicateurs **A** et **AAAA** correspondent aux deux types d’enregistrement DNS qui font pointer un nom de domaine vers un hébergement web : **A** pour l’adresse IPv4, **AAAA** pour l’adresse IPv6. Ils sont **indépendants l’un de l’autre** : un même nom de domaine peut avoir un indicateur conforme et l’autre en défaut.

Chaque indicateur prend l’une des trois couleurs suivantes.

<details>
<summary>Indicateur vert</summary>

L’enregistrement pointe correctement vers l’adresse IP de votre hébergement web. La configuration DNS de votre nom de domaine est conforme, et aucun message n’accompagne l’indicateur.

<img className="thumbnail" alt="Indicateurs A et AAAA conformes" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-ok.png" loading="lazy" />

</details>

<details>
<summary>Indicateur orange</summary>

L’enregistrement pointe vers une adresse IP, mais pas vers celle de l’hébergement web que vous consultez. Le message indique l’adresse actuellement configurée et celle à utiliser à la place :

*Votre domaine `exemple.com` pointe actuellement vers l’adresse IP `X` d’un autre hébergement. Pour corriger cela, mettez à jour le champ A dans la zone DNS du domaine et remplacez-le par l’adresse IP `Y`.*

<img className="thumbnail" alt="Indicateur A orange et indicateur AAAA gris, avec leurs messages" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-issues.png" loading="lazy" />

Pour corriger le pointage, suivez les étapes décrites dans notre guide « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) ».

</details>

<details>
<summary>Indicateur gris</summary>

Aucun enregistrement de ce type n’existe dans la zone DNS du nom de domaine. Le message donne l’enregistrement à créer et l’adresse IP à y inscrire :

*Aucune configuration valide n’a été trouvée dans la zone DNS. Pour résoudre le problème, ajoutez un champ AAAA avec l’adresse IP `Y` dans la zone DNS du domaine `exemple.com`.*

Pour ajouter les enregistrements manquants, suivez les étapes décrites dans notre guide « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) ».

</details>

:::info
Une modification de zone DNS peut mettre jusqu’à 24 heures à se propager. Après correction, utilisez le bouton <code className="action">Relancer le diagnostic</code> du nom de domaine concerné plutôt que de recharger la page.
:::

{/* CP-STEPS-END:interpretation-couleurs */}
