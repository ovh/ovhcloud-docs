## Objectif

Votre <ManagerLink to="/">console OVHcloud</ManagerLink> permet d’augmenter les capacités de vos [offres d’hébergement web](/links/web/hosting). Vous pouvez ainsi disposer :

- d’un hébergement plus puissant ;
- de plus d’espace de stockage FTP ;
- de bases de données supplémentaires ;
- d’adresses e-mails additionnelles ;
- de fonctionnalités supplémentaires comme les [mailing-lists](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/feature-mailing-list) (à partir de [l’offre Pro](/links/web/hosting)) ou le [service Web Cloud Databases](/links/web/databases) (compris dans [les offres Performance](/links/web/hosting)).

**Découvrez comment faire évoluer votre offre d’hébergement OVHcloud, sans interruption de service.**

### Modifier votre offre d’hébergement web <a name="modify"></a>

{/* CP-STEPS-START:modifier-offre */}

Pour modifier votre abonnement, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans l’onglet <code className="action">Vue d’ensemble</code>, repérez la section **Abonnement**. Votre formule actuelle est indiquée en regard de la mention **Offre**. Cliquez sur <code className="action">Changer d’offre</code> juste en dessous.

    <img className="thumbnail" alt="Section Abonnement et son lien Changer d’offre" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/subscription-card.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Sur la page qui s’affiche, choisissez la gamme souhaitée dans la partie **Choisissez votre gamme d’hébergement** (*Eco*, *Business* ou *Agency*), puis votre nouvelle offre dans la partie **Choisissez votre hébergement**. Votre offre actuelle porte la mention `Votre offre actuelle`. Les offres qui ne peuvent pas être choisies apparaissent grisées.

    La partie **Durée** n’attend aucun choix : la date d’expiration de votre nouvelle offre est alignée sur celle de votre abonnement actuel, et un montant calculé au prorata est appliqué.

    <img className="thumbnail" alt="Page de changement d’offre, choix de la gamme, de l’hébergement et durée" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/change-offer-page.png" loading="lazy" />

    Cliquez sur <code className="action">Continuer la commande</code> : la commande est créée immédiatement. Le bon de commande s’ouvre dans un nouvel onglet : le changement d’offre est effectif une fois celui-ci réglé.
  </Tab>
</Tabs>

### Vérifier que votre hébergement web est compatible avec une offre de la gamme inférieure <a name="checks"></a>

:::warning
La modification de votre abonnement pour une offre de la gamme inférieure est possible uniquement que s’il s’agit de l’offre **immédiatement inférieure**.
Par exemple, vous ne pourrez pas passer d’une formule *Agency* à une formule *Pro* en une seule opération.
Vous devrez **d’abord** faire évoluer votre hébergement web depuis la formule *Agency* vers l’offre *Performance* **puis** vers l’offre *Pro*.
:::

**Avant de réaliser votre changement vers une gamme inférieure**, vérifiez les 6 points suivants :

#### 1 - Bases de données Start SQL

Assurez-vous que la nouvelle offre comporte assez de [bases de données](/links/web/hosting-options-startsql). Vérifiez aussi que leurs tailles sont suffisantes.

Dans le cas contraire, supprimez les bases de données inutilisées et réduisez, si nécessaire, la quantité de données qu’elles contiennent. Cette quantité ne devra pas dépasser la taille maximale des bases de données de la nouvelle offre. Pour toute demande d’assistance sur les manipulations à effectuer, contactez les [partenaires OVHcloud](/links/partner).

{/* CP-STEPS-START:recalculer-quota */}

Suite à la suppression de données sur vos bases, recalculez le quota utilisé. Pour cela, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page qui s’affiche, cliquez sur l’onglet <code className="action">Bases de données</code>.

    <img className="thumbnail" alt="Onglet Bases de données d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le tableau, cliquez sur le bouton <code className="action">⁝</code> de la colonne **Actions**, à droite de la base de données concernée, puis sur <code className="action">Recalculer le quota</code>. Le recalcul est lancé immédiatement, sans confirmation à valider.

    <img className="thumbnail" alt="Menu d’une ligne du tableau des bases de données" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/row-actions-menu.png" loading="lazy" />

    Une fois lancée, l’opération peut prendre plusieurs minutes. Lorsqu’elle se termine, le statut **Lecture seule** de votre base de données disparaît.
    Votre base de données est alors de nouveau pleinement opérationnelle.
  </Tab>
</Tabs>

{/* CP-STEPS-END:recalculer-quota */}

:::info
Recalculer le quota de votre base de données peut nécessiter jusqu’à **15 minutes**. N’hésitez pas à recharger la page depuis votre navigateur Internet si le quota recalculé ne s’affiche pas spontanément.
:::

#### 2 - Web Cloud Databases

Si vous utilisez l’offre [Web Cloud Databases](/guides/web-cloud/databases/db-getting-started) incluse avec votre hébergement web [Performance](/links/web/hosting) et que vous souhaitez passer votre hébergement web sur une offre [Pro](/links/web/hosting), vous devrez d’abord dissocier l’offre Web Cloud Databases de votre hébergement web.

{/* CP-STEPS-START:delier-wcdb */}

Pour cela, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans la section **Bases de données**, vous trouverez la mention **Web Cloud DB**. Cliquez sur le bouton <code className="action">⋮</code> à droite de celle-ci, puis sur <code className="action">Délier ma base de données PrivateSQL</code>.

    <img className="thumbnail" alt="Section Bases de données et menu de la ligne Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Sur la nouvelle page qui s’affiche, choisissez la durée d’**Engagement** désirée pour votre solution Web Cloud Databases. Le **Récapitulatif** rappelle que votre base de données sera désormais facturée au prix standard et que cette action est irréversible. Cliquez sur <code className="action">Suivant</code>, puis suivez les étapes indiquées jusqu’au paiement.

    <img className="thumbnail" alt="Page Délier ma base de données PrivateSQL, offre, engagement et récapitulatif" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/detach-web-cloud-db.png" loading="lazy" />
  </Tab>
</Tabs>

{/* CP-STEPS-END:delier-wcdb */}

Cette action vous permettra de commander une offre Web Cloud Databases indépendante de votre abonnement *Performance*. Les données de votre serveur seront conservées.

Si vous ne souhaitez pas conserver ces données, vous pouvez aussi supprimer votre offre Web Cloud Databases avant de passer sur l’offre *Pro* :

{/* CP-STEPS-START:supprimer-wcdb */}

1. Sauvegardez vos données en suivant les instructions de ce [guide](/guides/web-cloud/databases/db-backup-export-database-server).<br/>
2. Résiliez votre serveur Web Cloud Databases depuis la <ManagerLink to="/">console OVHcloud</ManagerLink>. Pour cela, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, puis choisissez l’instance concernée.

    <img className="thumbnail" alt="Page Web Cloud DB et liste des instances" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans l’onglet <code className="action">Vue d’ensemble</code>, repérez la section **Abonnement**, puis cliquez sur <code className="action">Résilier le service</code>. Si le renouvellement de votre instance est manuel, ce lien se trouve dans le menu <code className="action">Actions supplémentaires</code> de la section.
  </Tab>
  <Tab label="Étape 3">
    Dans la fenêtre **Résilier le service**, choisissez <code className="action">Résilier à l’expiration</code> ou <code className="action">Résilier immédiatement</code>, puis cliquez sur <code className="action">Confirmer la résiliation</code> (ou sur <code className="action">Résilier maintenant</code> si vous avez choisi <code className="action">Résilier immédiatement</code>). Avec <code className="action">Résilier immédiatement</code>, votre serveur et toutes ses données sont supprimés dès votre confirmation.

    <img className="thumbnail" alt="Fenêtre Résilier le service d’une instance Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/terminate-service.png" loading="lazy" />
  </Tab>
</Tabs>

{/* CP-STEPS-END:supprimer-wcdb */}

<Region zones={['eu']}>

#### Vous possédez une offre d’hébergement gratuit <a name="100m"></a>

Dans le cadre d’un changement depuis une offre d’[hébergement gratuit](/guides/web-cloud/web-hosting/activate-start10m), seule [l’offre Perso](/links/web/hosting) vous sera proposée. Néanmoins, après un changement vers l’offre Perso, vous pourrez faire évoluer cette dernière vers l’ensemble de nos [offres d’hébergement web](/links/web/hosting).

Suivez [ces instructions](#modify) pour réaliser votre changement d’offre.

</Region>

#### Booster temporairement votre hébergement Performance <a name="boost"></a>

Avec l’[option Boost](/links/web/hosting-options-boost), disponible sur nos offres *Performance*, vous pouvez augmenter temporairement les ressources CPU et RAM de votre hébergement web pour absorber une augmentation ponctuelle du trafic. Si cette augmentation se prolonge dans le temps, vous pouvez également [basculer vers une offre de la gamme Agency](#modify) afin de disposer de ces ressources de manière permanente.

:::warning
Lorsque vous décidez d’activer l’option Boost, celle-ci reste active et facturée **tant que vous ne l’avez pas désactivée**.
:::

Si l’option **Boost** convient à votre besoin, vous trouverez ci-dessous les instructions pour **activer** ou **désactiver** cette option sur votre hébergement.

{/* CP-STEPS-START:activer-boost */}

Pour **activer l’option Boost**, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>

#### La facturation en cas de changement d’offre <a name="billing"></a>

**Cas 1** : Lorsque vous modifiez votre offre initiale vers une offre supérieure, un calcul au *prorata temporis* est appliqué jusqu’à la prochaine date de renouvellement de cet abonnement initial.
Ce calcul correspond à la différence de tarif entre votre offre initiale et votre nouvelle offre.

> **Exemple :**
>
> Vous avez souscrit à un abonnement [Perso](/links/web/hosting) au 1er janvier 2024.
>
> Le 31 octobre 2024, vous passez de cette offre **Perso** à un abonnement sur l’offre [Pro](/links/web/hosting).
>
> Par conséquent, le montant correspondant à la durée restante sur l’abonnement **Perso** (2 mois, du 1er novembre 2024 au 1er janvier 2025) est automatiquement soustrait du coût du nouvel abonnement **Pro**, jusqu’au 1er janvier 2025. Vous ne paierez que la différence.  
> À partir du 1er janvier 2025, l’abonnement **Pro** vous est ensuite facturé à son tarif en vigueur.

Suivez [ces instructions](#modify) pour réaliser votre changement d’offre.

<Region zones={['eu']}>

**Cas 2** : Lorsque vous modifiez votre offre initiale vers une offre inférieure, le temps d’abonnement restant pour l’offre initiale est définitivement perdu. Aucun remboursement de ce temps restant ne sera effectué, même s’il vous restait plusieurs mois d’abonnement. Vous devrez donc directement payer l’intégralité de l’abonnement de l’offre inférieure.

> **Exemple :**
>
> Vous avez souscrit à un abonnement [Pro](/links/web/hosting) au 1er janvier 2024.
>
> Le 31 octobre 2024, vous passez de cette offre **Pro** à un abonnement sur l’offre [Perso](/links/web/hosting).
>
> Par conséquent, le montant correspondant à la durée restante sur l’abonnement **Pro** (2 mois, du 1er novembre 2024 au 1er janvier 2025) est perdu.
> À partir du 1er novembre 2024, l’abonnement **Perso** vous est directement facturé à son tarif en vigueur (même si vous aviez payé les 2 mois restants de l’offre **Pro**).

Suivez [ces instructions](#modify) pour réaliser votre changement d’offre.
