## Objectif

Sur votre hébergement web OVHcloud, vous pouvez utiliser des scripts pour automatiser certaines opérations. Une tâche planifiée (« tâche CRON ») permet à vos scripts de s’exécuter à des moments spécifiques, sans action de votre part.

**Découvrez comment créer des tâches CRON pour automatiser vos tâches planifiées sur un hébergement web.**

[[fragment:support-scope]]

## Prérequis

- Posséder une [offre d’hébergement web](/links/web/hosting)

[[cpnav:web-hosting]]

## En pratique

### Création d’une tâche automatisée

{/* CP-STEPS-START:creation */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Cron</code>.

    <img className="thumbnail" alt="Onglet Cron d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Vous aurez un aperçu de vos tâches planifiées et de leurs paramètres : chaque tâche est présentée sous la forme d’une carte indiquant sa commande, son **État**, sa **Fréquence**, son **Langage** et l’**E-mail** de rapport.

    Pour créer une tâche CRON, cliquez sur le bouton <code className="action">Créer une tâche</code>.

    <img className="thumbnail" alt="Cartes des tâches planifiées et bouton Créer une tâche" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/tasks.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Personnalisez les paramètres de la tâche dans le panneau **Créer une tâche cron** qui s’affiche.

    <img className="thumbnail" alt="Panneau Créer une tâche cron en mode Simple" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/create-task.png" loading="lazy" />

    |Option|Description|
    |---|---|
    |Commande|Définissez le chemin d’accès au fichier contenant votre script, relatif à la racine de votre hébergement. Exemple : www/jobs/cron.php|
    |Fréquence|Définissez la fréquence d’exécution de la tâche (voir ci-dessous).|
    |Langage|Sélectionnez la version PHP utilisée par le script.|
    |Description|Saisissez une description pour suivre l’exécution de vos tâches.|
    |E-mail de rapport|Si nécessaire, indiquez l’adresse e-mail à laquelle un rapport sera envoyé en cas d’erreur d’exécution.|

    La tâche est activée dès sa création. Si vous ne souhaitez pas qu’elle s’exécute tout de suite, désactivez-la ensuite (voir la section [Modifier ou supprimer une tâche planifiée](#modifier-ou-supprimer-une-tâche-planifiée)).

    Pour la **Fréquence**, l’interface offre deux modes :

    - **Simple** : choisissez une fréquence prédéfinie dans la liste (toutes les heures, tous les jours à minuit ou à midi, tous les lundis à minuit, le 1er de chaque mois à minuit).
    - **Avancé** : saisissez une expression comme dans une *crontab*, dont les positions correspondent, dans l’ordre, à **Min**, **Heure**, **J. Mois**, **Mois** et **J. Sem**. L’interface traduit l’expression en clair au-dessus du champ et rappelle le rôle des caractères `*` (n’importe quelle valeur), `,` (séparateur de liste), `-` (plage de valeurs) et `/` (pas). Par exemple, `0 * * * *` exécute la tâche **une fois par heure tous les jours**, à la minute 0.

    <img className="thumbnail" alt="Fréquence en mode Avancé avec l’expression cron et sa traduction" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/create-task-advanced.png" loading="lazy" />

    :::info
    La position **J. Mois** permet de définir des fréquences d’exécution sur un cycle mensuel.

    La position **J. Sem** permet de définir des fréquences d’exécution complémentaires mais sur un cycle hebdomadaire.
    :::

    Vous pouvez basculer entre les deux modes pendant la configuration. Notez également les [limitations lors de la planification d’une tâche sur un hébergement web](#limitations-des-tâches-planifiées-sur-votre-hébergement-web).

    Si tout est correct, cliquez sur <code className="action">Créer</code>.

    La tâche sera prête dans quelques minutes. Vous pouvez alors modifier tous ses paramètres ou supprimer la tâche à l’aide du bouton <code className="action">⋮</code> situé en haut à droite de sa carte.
  </Tab>
</Tabs>

{/* CP-STEPS-END:creation */}

### Limitations des tâches planifiées sur votre hébergement web

{/* CP-STEPS-START:limitations */}

|Étape|Description|
|---|---|
|Planification horaire|Les minutes sont ignorées par l’hébergement : une tâche ne peut être exécutée qu’une fois par heure, c’est la fréquence de répétition la plus faible pouvant être spécifiée. En mode **Avancé**, indiquez une minute fixe (par exemple `0`) : l’interface vous le signale si ce n’est pas le cas.|
|Durée|La durée d’exécution d’une tâche est de 60 minutes. Si un script dépasse cette durée d’exécution, il sera automatiquement arrêté par le système.|
|Variables|Vous ne pouvez définir que des variables dans un script. Les ajouter à l’URL appelant le script ne fonctionnera pas (Exemple : www/jobs/cron.php?variable=value).|
|Limite de données|Une tâche ne peut générer que 5 Mo de données (*stdin/stderr*). Par exemple, si un script écrit des données dans un fichier .txt, l’exécution s’arrête automatiquement lorsque le fichier atteint 5 Mo.|
|Scripts produisant des erreurs|Si un script est défectueux, il sera automatiquement désactivé après 10 tentatives d’exécution échouées. Le rapport d’erreur ne sera envoyé que lorsque les 10 tentatives auront échoué.<br/>Corrigez votre script en fonction du rapport d’erreur reçu puis réactivez la « tâche CRON » depuis l’onglet <code className="action">Cron</code> (cliquez sur <code className="action">⋮</code> sur la carte de la tâche, puis sur <code className="action">Activer</code>).|
|Rapports d’exécution|Les rapports ne seront envoyés à l’adresse électronique sélectionnée qu’une fois par jour (pendant les heures de nuit).|

{/* CP-STEPS-END:limitations */}

### Dépannage

#### Test de votre script avec un navigateur Web

Un test simple pour voir si votre script produira une erreur est de l’exécuter dans un navigateur Web. Par exemple, si le chemin d’accès de votre script est « www/cron.php » et que votre domaine d’hébergement est « mypersonaldomain.ovh », vous devez utiliser l’URL « http://<i></i>mypersonaldomain.ovh/cron.php ». Si aucune erreur ne s’affiche mais que le script ne fonctionne pas comme prévu, suivez les suggestions ci-dessous.

#### Vérification de l’utilisation des chemins absolus

Veillez toujours à utiliser des chemins d’accès absolus aux fichiers de vos scripts. La constante « DIR », par exemple, peut aider à recevoir le chemin courant dans les scripts PHP ([documentation PHP](https://www.php.net/manual/fr/language.constants.predefined.php)).

#### Vérification des logs d’exécution

Dans les logs de votre hébergement web, accessibles depuis votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>, vous verrez la catégorie de log intitulée « CRON ».

Consultez notre guide [« Consulter les statistiques et les logs de mon site hébergé sur une offre mutualisée »](/guides/web-cloud/web-hosting/logs-and-statistics) pour plus de détails.
