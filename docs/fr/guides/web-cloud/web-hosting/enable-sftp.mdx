## Objectif

Les offres d’hébergement web OVHcloud donnent accès à un espace de stockage permettant de mettre en ligne les fichiers de vos sites web ou de vos applications. L’accès à cet espace est possible via un utilisateur FTP ou SSH avec les mots de passe qui leur sont associés.

Tout comme le **F**ile **T**ransfer **P**rotocol (**FTP**), le **S**ecure **F**ile **T**ransfer **P**rotocol (**SFTP**) permet de transférer des données de votre appareil vers l’espace de stockage de votre hébergement web.

La seule différence est que le SFTP utilise un canal sécurisé pour échanger des données. Les données qui transitent via ce protocole sont automatiquement chiffrées.

**Découvrez comment activer l’accès SFTP sur votre hébergement web OVHcloud.**

## Prérequis

- Disposer d’une offre d’[hébergement web OVHcloud](/links/web/hosting).

## En pratique

### Activer l’accès SFTP pour un utilisateur FTP de votre hébergement web

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

{/* CP-STEPS-START:activer-sftp */}

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Onglet FTP-SSH d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans la section **Utilisateurs FTP et SSH**, vérifiez l’état affiché dans la colonne **SFTP** pour l’utilisateur FTP concerné :

    - **Activé** : le protocole SFTP est déjà actif pour cet utilisateur, il n’y a rien à faire.
    - **Désactivé** : dans la colonne **Actions**, cliquez sur le bouton <code className="action">⋮</code> situé à droite de la ligne concernée, puis sur <code className="action">Modifier</code>.

    <img className="thumbnail" alt="Tableau des utilisateurs FTP et état du protocole SFTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/ftp-users-sftp-status.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Le panneau **Modifier un utilisateur** s’ouvre à droite. Dans le menu déroulant **Protocole de connexion**, sélectionnez <code className="action">FTP et SFTP</code>, ou <code className="action">FTP, SFTP et SSH</code> si vous avez également besoin d’activer le protocole SSH.

    <img className="thumbnail" alt="Panneau Modifier un utilisateur et menu Protocole de connexion" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user-protocols.png" loading="lazy" />

Le menu propose une troisième valeur, <code className="action">FTP</code> seule, qui désactive le SFTP pour cet utilisateur.

    Cliquez enfin sur <code className="action">Valider</code>. Une fois l’option **SFTP** activée, vous pourrez utiliser le protocole SFTP de votre hébergement web avec l’utilisateur FTP concerné.
  </Tab>
</Tabs>

{/* CP-STEPS-END:activer-sftp */}

:::info
La valeur <code className="action">FTP, SFTP et SSH</code> n’est proposée que sur les offres incluant l’accès SSH : **Pro**, **Performance**, **Agency**, **Agency Plus** et **Agency Max**.

Sur les offres <Region zones={['eu']}>**gratuite**, **Starter**, **Perso** et **Startup**</Region><Region zones={['ca', 'apac']}>**Starter**, **Perso** et **Startup**</Region>, le menu **Protocole de connexion** ne propose que <code className="action">FTP</code> et <code className="action">FTP et SFTP</code>, et le tableau des utilisateurs n’affiche pas de colonne **SSH**.

:::
