## Sécuriser votre hébergement web

Protégez votre site web et vos visiteurs : activez le chiffrement HTTPS grâce à un certificat SSL, mettez en place un pare-feu applicatif et appliquez les bonnes pratiques en matière de sécurité sur votre hébergement web OVHcloud. Cette page regroupe tous les guides pour sécuriser votre site web.

Pour vous orienter selon votre besoin :

- **Sécurité du site** (bonnes pratiques, pare-feu applicatif) : commencez par la section *Sécuriser votre site web*.
- **Certificat SSL et HTTPS** (gérer un certificat, passer en HTTPS) : consultez la section *Certificat SSL et HTTPS*.
- **Choisir un certificat SSL** (Let's Encrypt gratuit, Sectigo DV/EV, certificat personnalisé) : reportez-vous à la section *Activer un certificat SSL*.

## Activer un certificat SSL

Choisissez le type de certificat adapté à votre site web, puis suivez le guide correspondant.

<Tabs>
  <Tab label="Let's Encrypt (gratuit)">

Certificat SSL gratuit disponible avec votre hébergement web.

[Activer un certificat SSL gratuit Let's Encrypt](/guides/web-cloud/web-hosting/ssl-letsencrypt)

  </Tab>
  <Tab label="Sectigo DV">

Certificat Sectigo à validation de domaine (Domain Validation), valable pour un nom de domaine et son sous-domaine « www ».

[Activer un certificat SSL Sectigo DV](/guides/web-cloud/web-hosting/ssl-dv)

  </Tab>
  <Tab label="Sectigo EV">

Certificat Sectigo à validation étendue (Extended Validation), valable pour un nom de domaine et son sous-domaine « www ».

[Activer un certificat SSL Sectigo EV](/guides/web-cloud/web-hosting/ssl-ev)

  </Tab>
  <Tab label="Personnalisé">

Pour importer votre propre certificat SSL lorsqu'aucune des solutions OVHcloud ne correspond à votre besoin.

[Installer un certificat SSL personnalisé](/guides/web-cloud/web-hosting/ssl-custom)

  </Tab>
