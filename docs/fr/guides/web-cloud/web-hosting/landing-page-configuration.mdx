## Configurer votre hébergement web

Configurez tous les aspects de votre hébergement web OVHcloud : héberger plusieurs sites web, gérer l'environnement et la version PHP, activer les adresses e-mail incluses, optimiser les performances et le CDN, suivre les logs, déployer (Git, CRON, API) et faire évoluer votre offre. Les bases de données, l'accès FTP/SSH, les CMS et la sécurité disposent par ailleurs de leur propre page dédiée.

Pour vous orienter selon votre besoin :

- **Vous souhaitez configurer vos sites web, associer vos noms de domaine ou paramétrer l'environnement (PHP, IPv6) ?** Consultez la section *Sites web, nom de domaine et environnement*.
- **Vous voulez améliorer les performances de vos services ou suivre les logs (CDN, statistiques) ?** Consultez la section *Performance, CDN et logs*.
- **Vous devez déployer, automatiser (Git, CRON, API) ou faire évoluer votre offre ?** Consultez la section *Déploiement, automatisation et offre*.
