## Objectif

Les offres d’hébergement web OVHcloud donnent accès à un espace de stockage FTP. Cet espace FTP permet, par exemple, de mettre en ligne les fichiers de vos sites web ou de vos applications. L’accès à cet espace est possible via un utilisateur FTP ou SSH et le mot de passe associé. Dans le cadre de vos activités, vous pouvez être amené à avoir plusieurs utilisateurs FTP pour vos différents collaborateurs.

**Découvrez comment créer, modifier ou supprimer des utilisateurs FTP sur votre hébergement web OVHcloud.**

:::info
Ce guide est valable uniquement pour les hébergements web de type **Pro**, **Performance**, **Agency**, **Agency Plus** ou **Agency Max**. Seules ces offres permettent l’activation de plusieurs utilisateurs FTP.

:::

## Prérequis

- Disposer d’une offre d’[hébergement web OVHcloud](/links/web/hosting) compatible.

## En pratique

### Créer un nouvel utilisateur FTP sur votre hébergement web <a name="create-ftp-user"></a>

{/* CP-STEPS-START:creer-un-utilisateur */}

Pour créer un nouvel utilisateur FTP sur votre hébergement web via votre espace client, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Onglet FTP-SSH d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans la section **Utilisateurs FTP et SSH**, cliquez sur <code className="action">Créer un utilisateur</code>.

    <img className="thumbnail" alt="Panneau de création d’un utilisateur FTP dans la console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/create-user.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Le panneau **Créer un utilisateur** s’ouvre et rassemble tous les paramètres sur un seul écran :

    - **Utilisateur** : le nom que votre collaborateur utilisera pour se connecter. Il est **toujours précédé du login FTP principal de votre hébergement web, suivi d’un trait d’union** : si ce login est `ftplogin` et que vous saisissez `user1`, l’identifiant complet sera `ftplogin-user1`. Le nom que vous ajoutez compte entre 1 et 12 caractères alphanumériques ;
    - **Dossier racine** : le répertoire dans lequel cet utilisateur pourra agir. **Laissez ce champ vide pour donner accès à tout l’espace de stockage** ; sinon, indiquez un répertoire ou un sous-répertoire, par exemple `www`, `blog`, `website1` ou `www/development` ;
    - **Protocole de connexion** : le ou les protocoles autorisés pour cet utilisateur. En choisissant **FTP, SFTP et SSH**, votre collaborateur pourra aussi bien gérer les fichiers que se connecter en ligne de commande ;
    - **Mot de passe** et **Confirmer le mot de passe** : respectez la politique rappelée sous les champs.

    Cliquez enfin sur <code className="action">Créer</code>.
  </Tab>
</Tabs>

{/* CP-STEPS-END:creer-un-utilisateur */}

:::info
Une fois la demande de création validée, la bonne prise en compte du nouvel utilisateur sur votre hébergement web peut prendre jusqu’à 15 minutes.

:::

Si besoin, testez ce nouvel utilisateur FTP à l’aide de notre guide « [Se connecter à l’espace de stockage FTP de son hébergement web](/guides/web-cloud/web-hosting/ftp-connection) ».

### Modifier un utilisateur FTP

{/* CP-STEPS-START:modifier-un-utilisateur */}

Pour modifier un utilisateur FTP, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Onglet FTP-SSH d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    La section **Utilisateurs FTP et SSH** liste les utilisateurs créés sur votre hébergement web. Dans la colonne **Actions**, cliquez sur le bouton <code className="action">⋮</code> situé à droite de l’utilisateur concerné, puis sur <code className="action">Modifier</code>.

    <img className="thumbnail" alt="Menu Actions d’un utilisateur FTP dans la console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Le panneau **Modifier un utilisateur** s’ouvre. Deux réglages y sont accessibles :

    - **Désactiver l’utilisateur** : cochez cette case pour empêcher un collaborateur d’accéder à votre espace de stockage FTP **sans supprimer les logs FTP et SSH qui lui sont associés**. Ces logs vous permettront de déterminer quelles opérations il a réalisées si vous constatez des interventions non désirées sur votre hébergement web ;
    - **Protocole de connexion** : le ou les protocoles autorisés pour cet utilisateur. Consultez la partie « [Créer un nouvel utilisateur FTP sur votre hébergement web](#create-ftp-user) » plus haut dans ce guide pour le détail des protocoles.

    Le nom de l’utilisateur, son **dossier racine** et son mot de passe ne se modifient pas ici : le dossier racine se définit à la création et n’est plus modifiable ensuite. Pour changer le mot de passe, utilisez l’entrée <code className="action">Changer le mot de passe</code> du même menu, décrite dans notre guide « [Modifier le mot de passe d’un utilisateur FTP](/guides/web-cloud/web-hosting/ftp-change-password) ».

    <img className="thumbnail" alt="Panneau de modification d’un utilisateur FTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user.png" loading="lazy" />

    Cliquez enfin sur <code className="action">Valider</code>.
  </Tab>
</Tabs>

{/* CP-STEPS-END:modifier-un-utilisateur */}

:::info
Si vous souhaitez uniquement changer le mot de passe de l’utilisateur FTP, consultez notre guide « [Modifier le mot de passe d’un utilisateur FTP](/guides/web-cloud/web-hosting/ftp-change-password) ».

Si vous souhaitez changer le nom de l’utilisateur FTP, sachez que cette fonctionnalité est indisponible. Vous devrez obligatoirement [créer un nouvel utilisateur FTP](#create-ftp-user) avec le nouveau nom d’utilisateur désiré. Libre à vous ensuite de [supprimer l’ancien utilisateur FTP](#delete-ftp-user) si besoin.

:::

### Supprimer un utilisateur FTP <a name="delete-ftp-user"></a>

{/* CP-STEPS-START:supprimer-un-utilisateur */}

Pour supprimer un utilisateur FTP, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Onglet FTP-SSH d’un hébergement web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans la colonne **Actions** de la section **Utilisateurs FTP et SSH**, cliquez sur le bouton <code className="action">⋮</code> situé à droite de l’utilisateur concerné, puis sur <code className="action">Supprimer</code>.

    <img className="thumbnail" alt="Menu Actions d’un utilisateur FTP dans la console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Une fenêtre vous demande de confirmer en rappelant l’identifiant concerné. Cliquez sur <code className="action">Supprimer</code> pour retirer définitivement cet utilisateur de votre hébergement web.

    <img className="thumbnail" alt="Fenêtre de confirmation de suppression d’un utilisateur FTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/delete-user-confirmation.png" loading="lazy" />
  </Tab>
</Tabs>

{/* CP-STEPS-END:supprimer-un-utilisateur */}
