## Gérer les bases de données de votre hébergement web

Créez, administrez et sauvegardez les bases de données de votre hébergement web OVHcloud. Cette page regroupe les guides pour gérer vos bases de données, sauvegarder, importer et restaurer leurs données, et résoudre les erreurs les plus courantes.

Pour vous orienter selon votre besoin :

- **Vous souhaitez créer ou configurer une base de données ?** Consultez la section *Gérer une base de données* (créer, mot de passe, dupliquer).
- **Vous souhaitez sauvegarder ou restaurer vos données ?** Consultez la section *Sauvegarde et restauration* (récupérer, importer, restaurer).
- **Vous rencontrez une erreur de base de données ?** Consultez la section *Dépannage* (erreurs courantes, base de données saturée).
