## Objectif

Vous pouvez héberger plusieurs sites web sur une même offre d'hébergement web, même si les noms de domaine ne sont pas enregistrés chez OVHcloud. De plus, vous pouvez associer un ou plusieurs noms de domaine ou sous-domaines à un même site web.

Vous ne souhaitez plus utiliser un nom de domaine ou un sous-domaine pour votre site web ?
Vous voulez associer votre nom de domaine ou votre sous-domaine à un autre site web sur l'un de vos hébergements web ?

**Découvrez comment détacher un nom de domaine ou un sous-domaine d'un site web déjà existant sur votre hébergement web.**

:::info
Cette procédure s'applique à la <ManagerLink to="/beta/#/">nouvelle version de l'espace client OVHcloud</ManagerLink>, actuellement disponible en bêta. Pour la suivre, basculez vers cette interface depuis votre espace client habituel.

:::

## Prérequis

- Disposer d'une offre d'[hébergement web OVHcloud](https://www.ovhcloud.com/fr/web-hosting/uc-multisite/) compatible.
- Disposer d'un ou de plusieurs [noms de domaine](https://www.ovhcloud.com/fr/domains/).
- Pouvoir modifier la configuration de vos noms de domaine depuis leurs [zones DNS](/guides/web-cloud/domains/dns-zone-edit).

## En pratique

:::warning
Détacher un nom de domaine ou un sous-domaine d'un site web présent sur votre hébergement web est une manipulation sensible. En effet, après cette opération, votre site web ne sera plus accessible sur Internet avec votre nom de domaine et/ou sous-domaine.

:::

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hébergements</ManagerLink>, puis choisissez l'hébergement web concerné.

  </Tab>
  <Tab label="Étape 3">
    Dans le tableau qui apparaît, cliquez sur le bouton <code className="action">></code> situé à gauche du nom du site web concerné pour afficher les noms de domaine et sous-domaines associés.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />

    Cliquez ensuite sur le bouton <code className="action">⁝</code> situé à droite du nom de domaine ou sous-domaine concerné, puis sur <code className="action">Détacher le domaine</code>.

    <img className="thumbnail" alt="Associated domains options" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/associated-domains-options.png" loading="lazy" />

    > ![!warning]
    >

    >

    >

### Cas particulier : Détachement d'un nom de domaine ou d'un sous-domaine pour l'utiliser avec un autre site web

- Si vous souhaitez ajouter votre nom de domaine ou votre sous-domaine à un autre site web existant sur un hébergement web, consultez [ce guide](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).
- Si vous souhaitez créer un nouveau site web sur un hébergement web avec votre nom de domaine ou sous-domaine récemment détaché, consultez [ce guide](/guides/web-cloud/web-hosting/multisites-configure-multisite).
