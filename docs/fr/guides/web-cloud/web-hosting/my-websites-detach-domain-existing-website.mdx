## Objectif

Vous pouvez héberger plusieurs sites web sur une même offre d'hébergement web, même si les noms de domaine ne sont pas enregistrés chez OVHcloud. De plus, vous pouvez associer un ou plusieurs noms de domaine ou sous-domaines à un même site web.

Vous ne souhaitez plus utiliser un nom de domaine ou un sous-domaine pour votre site web ?
Vous voulez associer votre nom de domaine ou votre sous-domaine à un autre site web sur l'un de vos hébergements web ?

**Découvrez comment détacher un nom de domaine ou un sous-domaine d'un site web déjà existant sur votre hébergement web.**

## Prérequis

- Disposer d'une offre d'[hébergement web OVHcloud](https://www.ovhcloud.com/fr/web-hosting/uc-multisite/) compatible.
- Disposer d'un ou de plusieurs [noms de domaine](https://www.ovhcloud.com/fr/domains/).
- Pouvoir modifier la configuration de vos noms de domaine depuis leurs [zones DNS](/guides/web-cloud/domains/dns-zone-edit).

[[cpnav:web-hosting]]

## En pratique

:::warning
Détacher un nom de domaine ou un sous-domaine d'un site web présent sur votre hébergement web est une manipulation sensible. En effet, après cette opération, votre site web ne sera plus accessible sur Internet avec votre nom de domaine et/ou sous-domaine.

:::

{/* CP-STEPS-START:detacher-domaine */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Mes sites</code>. Dans le tableau, cliquez sur le bouton <code className="action">⋮</code> situé dans la colonne **Actions**, à droite du site web concerné, puis, dans le groupe **Noms de domaine**, sur <code className="action">Gérer</code>.

    <img className="thumbnail" alt="Menu Actions d’un site web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Le panneau **Gérer mes domaines** s’ouvre à droite et liste les noms de domaine et sous-domaines associés à ce site web. Sur celui que vous souhaitez détacher, cliquez sur le bouton <code className="action">⋮</code> situé à droite de son nom, puis sur <code className="action">Détacher</code>.

    <img className="thumbnail" alt="Panneau Gérer mes domaines et menu Actions d’un domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/manage-domains-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    La fenêtre **Détacher un domaine** s’affiche et vous demande de confirmer votre choix. Deux réglages s’y trouvent :

    <img className="thumbnail" alt="Fenêtre Détacher un domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/detach-domain-dialog.png" loading="lazy" />

    - **Détacher également le sous-domaine**, suivi du sous-domaine `www` concerné : décochée par défaut, cette case le détache en même temps que le nom de domaine, s’il est lui aussi déclaré sur ce site web. La zone DNS de ce sous-domaine et toutes ses options sont alors supprimées.
    - <code className="action">Supprimer les champs de pointage (A et AAAA) dans la zone DNS du nom de domaine.</code> : cochée par défaut, cette case retire de la zone DNS les enregistrements qui pointent vers votre hébergement web. Décochez-la si vous souhaitez conserver ces enregistrements.

    Cliquez enfin sur <code className="action">Confirmer</code>.

    :::warning
    **Cas particulier : votre site web est associé à un dépôt Git**

    La fenêtre affiche alors un avertissement et une case supplémentaire, <code className="action">Oui, supprimer ma configuration Git</code>. Le bouton <code className="action">Confirmer</code> reste inactif tant que vous ne l’avez pas cochée : détacher le nom de domaine supprime du même coup l’[association Git](/guides/web-cloud/web-hosting/git-integration-webhosting) du site web.

    <img className="thumbnail" alt="Fenêtre Détacher un domaine sur un site associé à Git" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/detach-domain-git.png" loading="lazy" />

    :::
  </Tab>
</Tabs>

### Cas particulier : Détachement d'un nom de domaine ou d'un sous-domaine pour l'utiliser avec un autre site web

- Si vous souhaitez ajouter votre nom de domaine ou votre sous-domaine à un autre site web existant sur un hébergement web, consultez [ce guide](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).
- Si vous souhaitez créer un nouveau site web sur un hébergement web avec votre nom de domaine ou sous-domaine récemment détaché, consultez [ce guide](/guides/web-cloud/web-hosting/multisites-configure-multisite).
