## Objectif

Vous pouvez héberger plusieurs sites web sur une même offre d’hébergement web, même si les noms de domaine ne sont pas enregistrés chez OVHcloud.

Vous souhaitez ajouter un nouveau site web sur votre hébergement web ?

**Découvrez comment héberger différents sites web sur votre offre d’hébergement web.**

:::info
Si vous avez déjà créé le site web concerné sur votre hébergement web et que vous souhaitez y associer un nouveau nom de domaine ou sous-domaine, consultez **directement** [ce guide](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).

:::

## Prérequis

- Disposer d’une [offre d’hébergement web OVHcloud](/links/web/hosting-multisite) compatible.
- Disposer d’un ou plusieurs [noms de domaine](/links/web/domains).
- Pouvoir modifier la configuration de vos noms de domaine depuis la [zone DNS](/guides/web-cloud/domains/dns-zone-edit).

[[cpnav:web-hosting]]

## En pratique

### 1 - Ajouter un site web sur votre offre d’hébergement web

**Cliquez sur l’un des titres ci-dessous pour afficher les explications.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Ajouter un site web avec un nom de domaine géré depuis votre espace client OVHcloud</summary>

Cette partie s’applique uniquement si le nom de domaine (et/ou sa zone DNS active) avec lequel vous souhaitez créer votre site web se trouve **dans votre espace client OVHcloud**.

{/* CP-STEPS-START:ajouter-site-domaine-ovhcloud */}

Le formulaire d’ajout tient sur une seule page : renseignez-la de haut en bas, puis validez. Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Mes sites</code>, puis sur le bouton <code className="action">Ajouter un site</code>, au-dessus du tableau.

    <img className="thumbnail" alt="Onglet Mes sites et bouton Ajouter un site" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-button.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans la section **Dossier racine**, saisissez le nom du dossier qui contiendra les fichiers de votre site web. Laissez le champ vide pour que la Console le crée automatiquement.

    Dans la section **Association du nom de domaine**, choisissez la carte **Nom de domaine OVHcloud existant**.

    <img className="thumbnail" alt="Dossier racine et choix du type de nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    :::warning
    Le **dossier racine** est également créé dans l’espace de stockage de votre hébergement web, accessible en FTP, SFTP ou SSH selon votre offre. Si le contenu de votre site web se trouve déjà dans un dossier précis de cet espace, indiquez-en le nom ici.
    :::
  </Tab>
  <Tab label="Étape 4">
    La section **Configurer votre domaine** apparaît. Dans le champ **Nom du site**, saisissez le nom de votre choix : il ne sert qu’à identifier votre site dans votre espace client. Sélectionnez ensuite le nom de domaine à associer dans le menu déroulant **Nom de domaine**.

    <img className="thumbnail" alt="Configuration du domaine, options et configuration DNS" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-configure-domain.png" loading="lazy" />

    :::info
    Pour ajouter un sous-domaine, sélectionnez d’abord le nom de domaine (par exemple : domain.tld), puis cochez **Créer un sous-domaine**. Un champ apparaît pour le saisir (par exemple : **sub**.domain.tld).

    **Cas particulier** : les sous-domaines en `www` (par exemple : **www**.domain.tld) sont ajoutés automatiquement en complément du nom de domaine. Il est donc inutile de les préciser.
    :::

    La section **Options** réunit trois fonctionnalités, décochées par défaut. Selon votre [offre d’hébergement web](/links/web/hosting), certaines peuvent ne pas être sélectionnables.

    |Option|Description|
    |---|---|
    |IP du pays|Permet de bénéficier d’une adresse IP géolocalisée (parmi une liste de pays) pour le nom de domaine sélectionné.<br/> Apprenez-en plus grâce à [cette page](/links/web/hosting-options).|
    |Firewall|Permet d’activer un pare-feu (filtrage et analyse des requêtes) sur le nom de domaine sélectionné.<br/> Apprenez-en plus grâce à [cette page](/links/web/hosting-options).|
    |CDN|Permet d’activer le CDN (mise en cache des éléments statiques de votre site web, comme les images) sur le nom de domaine sélectionné.<br/> Apprenez-en plus grâce à [notre page CDN](/links/web/hosting-options-cdn).<br/> En activant le SSL et le CDN, vous pourrez également bénéficier du protocole **HTTP/2** (ce protocole est activé par défaut dans notre datacenter de Gravelines).|

    :::info
    Ces options peuvent être activées plus tard, une fois le site web créé. Pour cela, consultez [ce guide](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::

    La section **Configuration DNS** propose enfin deux modes :

    - **Pour une configuration automatique**, laissez la carte **Configuration automatique** sélectionnée : les enregistrements A et AAAA sont créés dans la zone DNS du domaine. Un bandeau précise que la Console tentera de résoudre les conflits en supprimant les entrées incompatibles.
    - **Pour une configuration manuelle**, choisissez la carte **Configuration manuelle**, puis référez-vous aux guides suivants :
        - [Hébergement web - Liste des adresses IP par cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit)
  </Tab>
  <Tab label="Étape 5">
    La section **Choisissez le module en 1 clic à installer** termine le formulaire. OVHcloud met à disposition les modules WordPress, Joomla!, PrestaShop et Drupal, installés automatiquement dans le dossier racine configuré plus haut. Pour en savoir plus, consultez notre documentation « [Installer votre site web avec un « module en 1 clic » (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules) ».

    <img className="thumbnail" alt="Choix du module en 1 clic à installer" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-1-click-module.png" loading="lazy" />

    Laissez **Sans module pré-installé** sélectionné si vous préférez mettre en ligne vous-même les fichiers de votre site web. Pour en savoir plus, consultez notre documentation « [Mettre en ligne un site web sur son hébergement web](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online) ».

    Vérifiez enfin les informations saisies, puis cliquez sur <code className="action">Valider</code>. L’ajout peut prendre jusqu’à une heure.

    :::info
    La modification de la configuration DNS de votre nom de domaine nécessite un délai de propagation pouvant atteindre 48 heures avant d’être pleinement effective.
    :::
  </Tab>
</Tabs>

{/* CP-STEPS-END:ajouter-site-domaine-ovhcloud */}

</details>

<details>
<summary>Ajouter un site web avec un nom de domaine non géré depuis votre espace client OVHcloud</summary>

Cette partie s’applique uniquement si vous souhaitez ajouter un site web avec un nom de domaine qui n’est pas présent dans votre compte OVHcloud. Il peut s’agir d’un nom de domaine présent dans un autre compte OVHcloud ou enregistré chez un autre fournisseur.

{/* CP-STEPS-START:ajouter-site-domaine-externe */}

Le formulaire d’ajout tient sur une seule page : renseignez-la de haut en bas, puis validez. Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/hosting">Hébergements web</ManagerLink>, puis choisissez l’hébergement web concerné.

    <img className="thumbnail" alt="Page Hébergements web et liste des hébergements du compte" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Mes sites</code>, puis sur le bouton <code className="action">Ajouter un site</code>, au-dessus du tableau.

    <img className="thumbnail" alt="Onglet Mes sites et bouton Ajouter un site" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-button.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans la section **Dossier racine**, saisissez le nom du dossier qui contiendra les fichiers de votre site web. Laissez le champ vide pour que la Console le crée automatiquement.

    Dans la section **Association du nom de domaine**, choisissez la carte **Nom de domaine externe**.

    <img className="thumbnail" alt="Dossier racine et choix du type de nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    :::warning
    Le **dossier racine** est également créé dans l’espace de stockage de votre hébergement web, accessible en FTP, SFTP ou SSH selon votre offre. Si le contenu de votre site web se trouve déjà dans un dossier précis de cet espace, indiquez-en le nom ici.
    :::
  </Tab>
  <Tab label="Étape 4">
    Dans la section **Configurer votre domaine**, saisissez le **Nom du site** de votre choix : il ne sert qu’à identifier votre site dans votre espace client. Saisissez ensuite le nom de domaine (par exemple : domain.tld) ou le sous-domaine (par exemple : **sub**.domain.tld) dans le champ **Nom de domaine**.

    :::tip
    **Cas particulier** : les sous-domaines en `www` (par exemple : **www**.domain.tld) sont ajoutés automatiquement en complément du nom de domaine. Il est donc inutile de les préciser.
    :::

    La section **Gestion du domaine** affiche alors les enregistrements à créer, en deux temps. Cette vérification est obligatoire : elle nous permet de nous assurer que l’ajout du nom de domaine externe est légitime.

    <img className="thumbnail" alt="Gestion du domaine : enregistrements DNS à créer et enregistrement BIND" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-external-dns.png" loading="lazy" />

    1. **Vérifiez la propriété du domaine** : ajoutez l’enregistrement **TXT** indiqué dans la zone DNS de votre fournisseur.
    2. **Faites pointer le domaine vers l’hébergement** : ajoutez les enregistrements **A** et **AAAA** indiqués.

    Chaque valeur dispose d’un bouton de copie, et le bloc **Enregistrement BIND** reprend les trois lignes au format attendu par la plupart des hébergeurs de zone DNS.

    :::warning
    Effectuez ces modifications **rapidement**. Sans cette action, l’ajout de votre nom de domaine sera annulé et votre site web récemment créé ne sera pas accessible.

    Les entrées DNS de type **A** et **TXT** doivent obligatoirement être placées dans la zone DNS active de votre nom de domaine. Seules les entrées de type **AAAA** sont optionnelles.

    Notez que si vous souhaitez associer `sub.domain.tld`, vous devrez créer l’entrée TXT `ovhcontrol.domain.tld` et non l’entrée `ovhcontrol.sub.domain.tld`.

    Pour retrouver la zone DNS active de votre nom de domaine, retrouvez les [serveurs DNS](/guides/web-cloud/domains/dns-server-edit) auxquels celui-ci est lié. Vous devrez valider uniquement le nom de domaine à l’aide du champ **TXT**, pas tous ses sous-domaines.
    :::

    :::info
    Contrairement aux noms de domaine gérés depuis votre espace client OVHcloud, les sections **Options** et **Configuration DNS** ne sont pas proposées pour un nom de domaine externe.

    Ces fonctionnalités restent activables une fois le site web créé. Pour cela, consultez [ce guide](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::
  </Tab>
  <Tab label="Étape 5">
    La section **Choisissez le module en 1 clic à installer** termine le formulaire. OVHcloud met à disposition les modules WordPress, Joomla!, PrestaShop et Drupal, installés automatiquement dans le dossier racine configuré plus haut. Pour en savoir plus, consultez notre documentation « [Installer votre site web avec un « module en 1 clic » (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules) ».

    <img className="thumbnail" alt="Choix du module en 1 clic à installer" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-1-click-module.png" loading="lazy" />

    Laissez **Sans module pré-installé** sélectionné si vous préférez mettre en ligne vous-même les fichiers de votre site web. Pour en savoir plus, consultez notre documentation « [Mettre en ligne un site web sur son hébergement web](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online) ».

    Cliquez enfin sur <code className="action">Valider</code>. Le nom de domaine est ajouté de manière temporaire, le temps que vous modifiiez sa configuration DNS.

    :::info
    La modification de la configuration DNS de votre nom de domaine nécessite un délai de propagation pouvant atteindre 48 heures avant d’être pleinement effective.
    :::
  </Tab>
</Tabs>

{/* CP-STEPS-END:ajouter-site-domaine-externe */}

</details>

    Le formulaire ne demande rien de plus : le bouton situé en bas de page reprend alors l’intitulé <code className="action">Commander un nouveau nom de domaine</code>. Cliquez dessus.

    Vous êtes alors redirigé vers notre page commerciale de souscription d’un nom de domaine. Choisissez votre nouveau nom de domaine en fonction des disponibilités du marché, puis suivez les instructions du tunnel de commande jusqu’à la validation du bon de commande, sans souscrire en complément à un nouvel hébergement web.

    Une fois votre commande payée et validée, patientez quelques instants, le temps qu’elle soit traitée.

    :::info
    Une fois que votre nom de domaine apparaît dans votre espace client OVHcloud, suivez la partie « [Ajouter un nom de domaine géré depuis votre espace client OVHcloud](#add-domain-ovhcloud) » de ce guide pour ajouter votre site web à votre hébergement web.
    :::
  </Tab>
</Tabs>

### 2 - Mettre votre site web en ligne <a name="site-online"></a>

Une fois le site web déclaré avec votre nom de domaine sur votre hébergement web, vous pouvez mettre en ligne le contenu de votre site web. Pour rappel, vous devez réaliser cette manipulation dans le **dossier racine** que vous avez défini lors de l’ajout du site web dans votre espace client OVHcloud.

:::info
Si vous souhaitez ajouter plusieurs sites web, répétez les actions décrites dans ce guide.

Nous vous invitons à être vigilant quant au nombre de sites web présents sur votre hébergement web. Plus ce nombre est élevé, plus les ressources allouées à votre hébergement web sont sollicitées. [La page de nos offres d’hébergement web](/links/web/hosting) indique le nombre recommandé de sites web que vous pouvez accueillir sur votre hébergement web.

:::
