## Objectif

L'Auto Configuration Server (ACS) est une couche de traduction entre votre modem et notre outil de configuration à distance disponible dans la console OVHcloud. Le modem communique avec nos infrastructures au travers du CPE WAN Management Protocol (CWMP) qui a plusieurs spécificités par rapport à la communication REST utilisée par l'espace client et l'API OVHcloud.

:::info
Depuis le 01/09/2020, l'ACSv2 est disponible. C'est un changement d'infrastructure majeur venant remplacer l'ACSv1 après huit années de loyaux services. Ce changement nous permet de proposer une nouvelle fonctionnalité : le choix de l'ACS backend. À l'heure actuelle, trois backends sont disponibles pour l'ACS, « Legacy » (par défaut), « Stable » et « Beta ».

:::


**Apprenez à modifier votre backend ACS.**

## Prérequis

- Disposer d’un [accès Internet xDSL ou fibre OVHcloud](https://www.ovhcloud.com/fr/internet/).
- Cette fonctionnalité est disponible même si la configuration à distance est désactivée.

## En pratique

### Étape 1 : Accéder à l'outil de configuration à distance

{/* CP-STEPS-START:acceder-outil-configuration */}

Dans la liste **Accès Internet**, cliquez sur votre accès à Internet FTTH ou xDSL dans la colonne **Nom/ID**, puis sur l'onglet <code className="action">Modem</code>.

<img className="thumbnail" alt="Onglet Modem d'un accès Internet avec la section Firmware et gestion à distance et la ligne Backend ACS" src="/images/assets/screens/console/product-selection/web-cloud/internet-access/modem-tab.png" loading="lazy" />

Dans la section **Firmware et gestion à distance**, la ligne **Backend ACS** indique le backend actuellement utilisé par votre modem. Cliquez sur <code className="action">Modifier</code> sous cette valeur : la fenêtre **Modifier le backend ACS** s'ouvre. Vous y retrouverez un menu déroulant **Backend ACS** vous permettant de choisir le backend cible.

{/* CP-STEPS-END:acceder-outil-configuration */}

### Étape 2 : Choisir un backend ACS

{/* CP-STEPS-START:choisir-backend-acs */}

Le menu déroulant **Backend ACS** propose les backends disponibles pour votre modem : vous devez choisir celui sur lequel vous souhaitez migrer. Le backend par défaut est « legacy ».

- **legacy** : le backend de l'ACSv1. Sélectionner ce backend configure le modem pour qu'il communique avec l'ancienne infrastructure.
- **stable** : le backend par défaut de l'ACSv2. Sélectionner ce backend ne permet pas de profiter immédiatement des nouvelles fonctionnalités, mais il permet de profiter d'une meilleure stabilité avec des changements moins fréquents et éprouvés sur le backend beta.
- **beta** : ce backend permet de profiter immédiatement des nouvelles fonctionnalités, mais peut être sujet à des instabilités dues à des changements plus fréquents et moins éprouvés.

{/* CP-STEPS-END:choisir-backend-acs */}

### Étape 3 : Appliquer la modification

{/* CP-STEPS-START:appliquer-modification */}

:::warning

Changer le backend ACS réinitialise le modem. Si la configuration à distance n'est pas activée sur votre modem, la configuration du modem sera perdue. Pensez à la sauvegarder au préalable.

:::

Une fois le backend choisi, sélectionnez-le dans le menu déroulant **Backend ACS** de la fenêtre **Modifier le backend ACS**, puis cliquez sur le bouton <code className="action">Modifier</code>.

Une tâche va alors modifier l'URL du serveur ACS sur le modem, puis va initier une réinitialisation du modem. Si la configuration à distance est activée sur votre modem, la configuration enregistrée dans la console OVHcloud sera de nouveau appliquée quand le modem aura terminé la réinitialisation.

<img className="thumbnail" alt="Fenêtre Modifier le backend ACS avec le menu déroulant Backend ACS et le bouton Modifier" src="/images/web-cloud/internet/internet-access/comment-changer-backend-acs/console/acs-backend-dialog.png" loading="lazy" />

{/* CP-STEPS-END:appliquer-modification */}

### Expert : Modifier le backend directement via l'API OVHcloud

Cette méthode s'adresse aux utilisateurs experts uniquement. Nous ne serons pas en mesure de vous fournir d'assistance.

:::info
Pour en savoir plus sur l'utilisation des API, consultez le guide « [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps) ».

:::


Rendez-vous sur la <ApiLink>console API</ApiLink>. 

Dès lors, utilisez les trois API ci-dessous pour configurer le backend ACS.

<Api version="v1" section="/xdsl" method="GET" route={"/xdsl/\{serviceName\}/modem/availableACSBackend"} />

Permet de récupérer les backends ACS disponibles pour votre modem.

<Api version="v1" section="/xdsl" method="GET" route={"/xdsl/\{serviceName\}/modem"} />

Permet de récupérer différentes informations sur votre modem, y compris le backend actuellement utilisé par votre modem.

<Api version="v1" section="/xdsl" method="PUT" route={"/xdsl/\{serviceName\}/modem"} />

Modifiez le champ `acsBackend` afin d'appliquer le changement de backend ACS.
