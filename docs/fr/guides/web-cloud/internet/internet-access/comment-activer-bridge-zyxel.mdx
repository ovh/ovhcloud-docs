## Objectif

Le mode bridge est utile si vous souhaitez que votre modem ne se comporte plus comme un routeur. Ce mode n'est utile que dans le cas où vous possédez un équipement agissant en tant que routeur sur votre réseau local. Cet équipement gérera alors entièrement votre connexion, OVHcloud ne pouvant intervenir sur celui-ci.

**Apprenez à activer le mode bridge sur votre modem Zyxel**

## Prérequis

- Disposer d’un [accès Internet xDSL ou FTTH OVHcloud](https://www.ovhcloud.com/fr/internet/) et d'un modem Zyxel fourni par OVHcloud.
- Cette fonctionnalité est disponible uniquement si la configuration à distance est désactivée.

## En pratique

{/* CP-STEPS-START:bridge-thomson-technicolor */}

:::info

Ce guide ne concerne que les modems de marque Zyxel. Pour un modem Thomson ou Technicolor, l'activation du mode bridge n'est pas disponible dans la console OVHcloud.

:::

{/* CP-STEPS-END:bridge-thomson-technicolor */}


### Étape 1 : Accéder à l'outil de configuration à distance

{/* CP-STEPS-START:desactiver-configuration-distance */}

Dans la liste **Accès Internet**, cliquez sur votre accès à Internet FTTH ou xDSL dans la colonne **Nom/ID**, puis sur l'onglet <code className="action">Modem</code>.

Dans la section **Firmware et gestion à distance**, vérifiez que l'interrupteur **Configuration à distance** est bien désactivé. Dès lors, deux possibilités :

- **La configuration à distance est désactivée** : poursuivez la lecture de cette documentation à l'étape 2 « [Connectez-vous à l'interface locale du modem](#étape-2--connectez-vous-à-linterface-locale-du-modem) » ;

- **la configuration à distance est activée** : vous devez désactiver la configuration à distance si vous souhaitez paramétrer votre modem Zyxel en mode bridge. Pour ce faire, désactivez l'interrupteur **Configuration à distance**, puis patientez quelques minutes le temps de la désactivation.

{/* v8-defect: CD-063 — the switch applies at once with no confirmation dialog; the v6 « confirmez la manipulation » is dropped */}

<img className="thumbnail" alt="Onglet Modem avec l'interrupteur Configuration à distance dans la section Firmware et gestion à distance" src="/images/web-cloud/internet/internet-access/comment-reutiliser-wifi-zyxel-otb/console/remote-configuration-switch.png" loading="lazy" />

{/* CP-STEPS-END:desactiver-configuration-distance */}

### Étape 2 : Connectez-vous à l'interface locale du modem

Connectez-vous à l'interface locale du modem, celle-ci est disponible à l'adresse IP locale de votre modem, 192.168.1.1 par défaut. Si vous avez modifié l'adresse IP locale de votre modem via la configuration du LAN, utilisez l'adresse IP que vous aviez définie.

Un couple user/password vous est alors demandé :

- Si la configuration à distance de votre modem était déjà désactivée à l'étape 1, utilisez l'utilisateur **admin** ainsi que le mot de passe que vous avez personnalisé.
- Si la configuration à distance de votre modem était déjà désactivée et que vous avez effectué un reset, utilisez l'utilisateur **admin** ainsi que le mot de passe sur l'étiquette au dos du modem.
- Si la configuration à distance de votre modem n'était pas désactivée, utilisez l'utilisateur **admin** ainsi que le mot de passe qui vous a été transmis par e-mail. L'objet de cet e-mail contient la mention « Réinitialisation du mot de passe du modem de votre accès ».

<img className="thumbnail" alt="activerBridge" src="/images/web-cloud/internet/internet-access/comment-activer-bridge-zyxel/activerBridge-step2.png" loading="lazy" />

{/* CP-STEPS-START:retrouver-identifiants-e-mail */}

:::info

L'ensemble des e-mails envoyés par OVHcloud sont accessibles depuis la console OVHcloud. Pour retrouver vos derniers identifiants de connexion reçus par e-mail, utilisez un autre accès à Internet ou un smartphone : dans la console OVHcloud, ouvrez le menu de votre compte en haut à droite de l'écran, puis cliquez sur <code className="action">Mes communications</code>. Vos e-mails sont listés dans l'onglet **Messages** de la page **Communications**.

:::

{/* CP-STEPS-END:retrouver-identifiants-e-mail */}


### Étape 3 : Accéder aux options de connexion broadband

Une fois connecté à l'interface locale du modem, accédez à la page de configuration `Broadband`. Cliquez sur l'icône du menu à tiroir (<code className="action">☰</code>) en haut à droite, la page `Broadband` se trouve dans le menu `Network Setting`.

<img className="thumbnail" alt="activerBridge" src="/images/web-cloud/internet/internet-access/comment-activer-bridge-zyxel/activerBridge-step3-1.png" loading="lazy" />

Sur cette page, éditez l'interface correspondant à votre type de connexion :

- **ADSL** : Pour une connexion de type ADSL
- **VDSL** : Pour une connexion de type VDSL
- **ETHWAN** : Pour une connexion de type FTTH

<img className="thumbnail" alt="activerBridge" src="/images/web-cloud/internet/internet-access/comment-activer-bridge-zyxel/activerBridge-step3-2.png" loading="lazy" />

{/* CP-STEPS-START:type-de-connexion */}

En cas de doute, le type de votre connexion est indiqué dans la console OVHcloud, à la ligne **Type d'accès** de la section **Informations générales**, dans l'onglet **Vue d'ensemble** de votre accès.

<img className="thumbnail" alt="Onglet Vue d'ensemble d'un accès Internet avec la ligne Type d'accès de la section Informations générales" src="/images/web-cloud/internet/internet-access/comment-reutiliser-wifi-zyxel-otb/console/overview-access-type.png" loading="lazy" />

{/* CP-STEPS-END:type-de-connexion */}

### Étape 4 : Modifier le mode de votre connexion

Une fois sur la page d'édition de votre connexion, sélectionnez le mode souhaité dans la liste déroulante.

<img className="thumbnail" alt="activerBridge" src="/images/web-cloud/internet/internet-access/comment-activer-bridge-zyxel/activerBridge-step4-1.png" loading="lazy" />

Validez le changement, le bridge est désormais activé sur les ports LAN 1, 2 et 3. Le port 4 vous permet d'accéder à l'interface du modem.

<img className="thumbnail" alt="activerBridge" src="/images/web-cloud/internet/internet-access/comment-activer-bridge-zyxel/activerBridge-step4-2.png" loading="lazy" />

### Étape 5 : Revenir en mode routeur

Pour revenir en mode routeur suivez le guide « [Redémarrer ou réinitialiser une box OVHcloud](/guides/web-cloud/internet/internet-access/restart-reboot-modem#reinitialiser-votre-box-ovh) » pour réinitialiser votre modem Zyxel et rétablir sa configuration par défaut.
