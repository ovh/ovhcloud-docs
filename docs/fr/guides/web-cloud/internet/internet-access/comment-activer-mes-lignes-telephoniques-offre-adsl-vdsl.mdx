## Objectif

Vous pouvez activer, selon votre [offre Internet](https://www.ovhcloud.com/fr/internet/), une ou plusieurs lignes téléphoniques sur votre pack ADSL/VDSL/FTTH. 
Ces dernières vous permettent d'émettre et recevoir des appels. Elles peuvent également être liées à un ou plusieurs numéros portés si vous en possédez.

**Ces lignes ne sont pas livrées en même temps que l'accès ADSL/VDSL/FTTH, ce guide vous explique comment les activer.**

## Prérequis

- Disposer d'un [pack ADSL/VDSL/FTTH](https://www.ovhcloud.com/fr/internet/) actif.
- Disposer d'une ou plusieurs ligne(s) non activée(s) dans ce pack.

[[cpnav:telecom-xdsl-fttx-console]]

## En pratique

### Combien de lignes puis-je activer ?

Selon l'offre ADSL/VDSL/FTTH à laquelle vous avez souscrit, vous disposez d'au minimum 1 emplacement pour des lignes téléphoniques et de 0 à 1 emplacement pour une ligne fax virtuelle. 
Lorsque vous activez une ligne, celle-ci va occuper un emplacement.

{/* CP-STEPS-START:combien-de-lignes */}

Pour connaître le nombre d'emplacements libres restants, dans la liste **Accès Internet**, cliquez sur votre accès dans la colonne **Nom/ID**.

Dans l'onglet **Vue d'ensemble**, la section **Services additionnels** vous donne une vue globale des services associés à votre pack. Pour chaque service, elle indique le nombre d'emplacements utilisés sur le nombre total d'emplacements (par exemple « 1 / 2 utilisé(s) ») : le nombre d'emplacements encore disponibles correspond à la différence entre les deux.

<img className="thumbnail" alt="Section Services additionnels de l'onglet Vue d'ensemble avec les emplacements Lignes VoIP et EcoFax utilisés" src="/images/web-cloud/internet/internet-access/comment-activer-mes-lignes-telephoniques-offre-adsl-vdsl/console/services-card.png" loading="lazy" />

Dans l'exemple ci-dessus, il y a :

- 1 emplacement téléphonique utilisé sur 2 (**Lignes VoIP** : « 1 / 2 utilisé(s) ») ;
- 0 emplacement fax utilisé sur 1 (**EcoFax** : « 0 / 1 utilisé(s) »).

Il reste donc deux emplacements libres : vous pouvez activer 1 ligne téléphonique et 1 ligne fax pour ce pack ADSL/VDSL/FTTH.

{/* CP-STEPS-END:combien-de-lignes */}

### Comment activer les lignes associées à mon Pack ?

S'il vous reste des emplacements libres, vous pouvez activer vos lignes téléphoniques/FAX. 

{/* CP-STEPS-START:activer-lignes-pack */}

Pour cela, dans la liste **Accès Internet**, cliquez sur votre accès dans la colonne **Nom/ID**. Dans l'onglet **Vue d'ensemble**, section **Services additionnels**, cliquez sur <code className="action">Voir les lignes configurées</code> sous la ligne **Lignes VoIP**. Le panneau **Lignes VoIP** s'ouvre : cliquez sur <code className="action">Activer un service</code>.

<img className="thumbnail" alt="Panneau Lignes VoIP ouvert depuis la section Services additionnels avec le bouton Activer un service" src="/images/web-cloud/internet/internet-access/comment-activer-mes-lignes-telephoniques-offre-adsl-vdsl/console/voip-lines-drawer.png" loading="lazy" />

Sur la page **Activation de lignes téléphoniques**, vous avez alors le choix d'activer la ligne **avec ou sans** téléphone.

{/* CP-STEPS-END:activer-lignes-pack */}

#### Sans téléphone

Une ligne sans téléphone est une ligne qui sera techniquement configurée directement dans le modem sans action de votre part. Il vous suffira de brancher un simple téléphone **analogique** sur le modem. Plus de détails dans la section [Comment utiliser les lignes activées sans téléphone](#comment-utiliser-les-lignes-activées-sans-téléphone).

Ce type d'activation nécessite que vous possédiez un téléphone analogique personnel.

Vous ne pouvez activer que deux lignes sans téléphone par accès car il n'y a que deux ports analogiques disponibles sur le modem.

{/* CP-STEPS-START:sans-telephone */}

Pour activer une ligne sans téléphone, choisissez le nombre de lignes à activer dans la section **Nombre de lignes à ajouter** (« 1 » est présélectionné lorsqu'un seul emplacement est disponible).

Sélectionnez ensuite l'option <code className="action">Ligne SIP sans téléphone</code> dans la section **Choisissez un téléphone**, puis cliquez sur <code className="action">Valider la commande</code> dans le récapitulatif **Votre activation**, à droite de la page.

<img className="thumbnail" alt="Page Activation de lignes téléphoniques avec l'option Ligne SIP sans téléphone sélectionnée et le bouton Valider la commande" src="/images/web-cloud/internet/internet-access/comment-activer-mes-lignes-telephoniques-offre-adsl-vdsl/console/activation-sip-line.png" loading="lazy" />

{/* CP-STEPS-END:sans-telephone */}

Cette ligne sera alors disponible dans un délai moyen d'une heure.

#### Avec un téléphone

L'activation d'une ligne avec téléphone inclut l'envoi d'un téléphone IP sous caution qu'il suffira de brancher sur le réseau de votre modem comme un simple ordinateur.

Vous pouvez consulter les détails techniques de chaque téléphone sur la [page comparatif des téléphones](https://www.ovhcloud.com/fr/phone/voip/telephone/).

{/* CP-STEPS-START:avec-un-telephone */}

Pour activer une ligne avec téléphone, choisissez le nombre de lignes à activer dans la section **Nombre de lignes à ajouter** (« 1 » est présélectionné lorsqu'un seul emplacement est disponible).

Sélectionnez alors le téléphone de votre choix dans la section **Choisissez un téléphone**. Vous devez ensuite choisir le type de livraison dans la section **Choisissez l'adresse et le mode de livraison de votre téléphone** :

- **Livraison par transporteur** : la livraison par transporteur à 9,99 € HT se fait via la société **DHL** sous 24h ouvrées après l'envoi du téléphone ;
- **Livraison en point relais** : la livraison en point relais **Mondial Relay** est gratuite et se fait sous 48h ouvrées après l'envoi du téléphone.

Pour une livraison en point relais, saisissez votre ville ou votre code postal dans le champ **Ville ou code postal**, cliquez sur <code className="action">Rechercher un point relais</code>, puis choisissez votre point relais. Pour une livraison par transporteur, choisissez l'adresse de livraison parmi celles proposées.

Cliquez sur <code className="action">Valider la commande</code> une fois votre choix effectué.

<img className="thumbnail" alt="Page Activation de lignes téléphoniques avec un téléphone sélectionné et les modes de livraison" src="/images/web-cloud/internet/internet-access/comment-activer-mes-lignes-telephoniques-offre-adsl-vdsl/console/activation-delivery.png" loading="lazy" />

{/* CP-STEPS-END:avec-un-telephone */}

Cette ligne sera alors disponible et utilisable après la réception et le branchement du téléphone sur votre modem.

### Activation d'une ligne Fax

{/* CP-STEPS-START:activation-ligne-fax */}

Pour activer une ligne fax, dans l'onglet **Vue d'ensemble** de votre accès, cliquez sur <code className="action">Activer une ligne fax</code> sous la ligne **EcoFax** de la section **Services additionnels**. Dans le panneau **Activer une ligne fax**, cliquez alors sur <code className="action">Activer</code> pour confirmer votre choix. Après l'activation, un e-mail vous est envoyé : il contient le numéro de la ligne et ses identifiants.

<img className="thumbnail" alt="Panneau Activer une ligne fax ouvert depuis la section Services additionnels avec le bouton Activer" src="/images/web-cloud/internet/internet-access/comment-activer-mes-lignes-telephoniques-offre-adsl-vdsl/console/ecofax-activation-drawer.png" loading="lazy" />

{/* CP-STEPS-END:activation-ligne-fax */}

Cette ligne sera alors disponible dans un délai moyen d'une heure.

Veuillez consulter [nos guides Fax](/guides/web-cloud/phone-and-fax/voip/faq-voip) afin d'avoir plus de détails sur l'utilisation de ce service.

### Comment utiliser les lignes activées sans téléphone

Si vous avez activé une ligne sans téléphone, vous devez posséder un simple téléphone analogique à fréquence vocale, c'est-à-dire un téléphone qui peut être utilisé sur une ligne fixe France Télécom par exemple.

Pour que cette ligne soit utilisable, **les conditions suivantes doivent être remplies** :

Le voyant **Voice** du modem doit être allumé sur les modems Technicolor (TG788 et TG799).

Le voyant **Phone** du modem doit être allumé sur les modems Zyxel.

Si ce n'est pas le cas, vérifiez que l'activation de la ligne a bien été effectuée dans la console OVHcloud et patientez une heure.

<img className="thumbnail" alt="voyants technicolor" src="/images/web-cloud/internet/internet-access/comment-activer-mes-lignes-telephoniques-offre-adsl-vdsl/2015-03-18-143620_120x314_scrot.png" loading="lazy" />

<img className="thumbnail" alt="voyants zyxel" src="/images/web-cloud/internet/internet-access/comment-activer-mes-lignes-telephoniques-offre-adsl-vdsl/Activation06-edit.png" loading="lazy" />

Votre téléphone analogique doit être branché sur le port **phone 1** du modem (ou le port **phone 2** si c'est la deuxième ligne sans téléphone).

:::info
Sur les modems Technicolor TG788, les ports **phone** sont inversés : le port **phone 2** est à gauche et le port **phone 1** est à droite.

:::

<img className="thumbnail" alt="schéma branchement tg788" src="/images/web-cloud/internet/internet-access/comment-activer-mes-lignes-telephoniques-offre-adsl-vdsl/untitled.jpg" loading="lazy" />

### Désactiver une ligne téléphonique associée à une offre FTTH / xDSL

La facturation des lignes téléphoniques incluses dans votre offre FTTH / xDSL est comprise dans la facturation globale de cette offre. Les désactiver n'aura donc pas d'impact sur cette facturation.

Si vous souhaitez diminuer le nombre de lignes incluses dans votre offre, nous vous conseillons d'envisager de changer d'offre. Consultez notre guide « [Comment changer mon offre xDSL/FTTH](/guides/web-cloud/internet/internet-access/comment-changer-mon-offre-xdsl) ».
