## Objectif

Pour faciliter la gestion de votre accès à Internet, vous pouvez paramétrer votre box OVHcloud directement depuis la console OVHcloud. Vous pouvez ainsi changer cette configuration à distance, sans devoir vous connecter à l'interface de votre box. Autre avantage, vous disposez toujours d'une sauvegarde de vos paramètres.

**Découvrez comment configurer à distance votre box OVHcloud depuis la console OVHcloud.**

## Prérequis

- Disposer d'un [accès Internet xDSL ou FTTH OVHcloud](https://www.ovhcloud.com/fr/internet/). 
- Avoir activé la gestion de votre box à distance.

[[cpnav:telecom-xdsl-fttx-console]]

## En pratique

### Étape 1 : modifier la gestion de votre box

{/* CP-STEPS-START:modifier-gestion-box */}

Dans la liste **Accès Internet**, cliquez sur votre accès à Internet FTTH ou xDSL dans la colonne **Nom/ID**, puis positionnez-vous sur l'onglet <code className="action">Modem</code>. L'interrupteur **Configuration à distance** se trouve dans la section **Firmware et gestion à distance**.

:::warning

L'activation de la configuration à distance écrasera le paramétrage actuel de votre box. Si une configuration spécifique est actuellement en place, celle-ci sera alors effacée.

:::

{/* v8-defect: CD-063 — the switch applies at once with no confirmation and no warning; the guide keeps its overwrite warning and the e-mailed password, and no longer says to confirm */}

- Si vous souhaitez utiliser l'outil de configuration à distance, vérifiez que l'interrupteur **Configuration à distance** est bien activé. Puis poursuivez la lecture de cette documentation à l'étape 2 « [Personnaliser la configuration de votre box](#custom-configuration) » ci-dessous.

:::info

La désactivation de la configuration à distance n'écrase pas le paramétrage de votre box. Vous pourrez accéder localement au modem, sans perdre votre configuration actuelle.

Un nouveau mot de passe utilisateur vous sera communiqué par e-mail. Il est possible qu'un redémarrage du modem soit nécessaire.

:::

- Si vous souhaitez configurer votre modem localement sans utiliser l'outil de configuration à distance, vérifiez que l'interrupteur **Configuration à distance** est bien désactivé.

### Étape 2 : personnaliser la configuration de votre box

{/* CP-STEPS-START:personnaliser-configuration */}

Pour paramétrer votre box, dans la liste **Accès Internet**, cliquez sur votre accès à Internet FTTH ou xDSL dans la colonne **Nom/ID**, puis positionnez-vous sur l'onglet <code className="action">Modem</code>. **Pour rappel, il est impératif que la configuration à distance soit activée pour que cette gestion soit possible.**

L'onglet **Modem** regroupe plusieurs sections. Chacune d'elles permet d'interagir avec la configuration de votre box. Poursuivez alors selon la manipulation que vous souhaitez effectuer :

|Partie du guide|Sections de l'onglet **Modem**|Permet de :|
|---|---|---|
|[Réseau](#21-réseau)|**Appareils connectés**|- Actualiser la liste des équipements connectés à votre box|
|[Configuration générale](#22-configuration-générale)|**Informations du modem**, **Firmware et gestion à distance**, **Réseaux WiFi**|- Redémarrer votre box<br/>- Activer ou désactiver la configuration à distance de votre box<br/>- Paramétrer vos réseaux Wi-Fi|
|[Configuration réseau](#23-configuration-reseau)|**IP LAN**, **DHCP**, **Baux DHCP**, **Redirection de ports**|- Configurer l'IP LAN de la box<br/>- Configurer le DHCP et les baux DHCP de la box<br/>- Configurer des redirections de ports|
|[Configurations avancées](#24-configurations-avancées)|**Informations du modem**, **Configuration avancée**, **Firmware et gestion à distance**|- Réinitialiser votre box<br/>- Configurer le MTU<br/>- Configurer une DMZ<br/>- Choisir le fichier de configuration (_firmware_) de votre box|
|[Services](#25-services)|**Services**|- Activer ou désactiver un service additionnel parmi ceux disponibles|

{/* CP-STEPS-END:personnaliser-configuration */}

#### 2.1 Réseau

{/* CP-STEPS-START:reseau */}

Depuis la section **Appareils connectés**, vous obtenez la liste des équipements connectés sur le réseau de votre box. Vous pouvez visualiser pour chaque équipement :

- son nom diffusé sur le réseau (colonne **Nom de l'appareil**) ;
- le type de connexion (filaire ou Wi-Fi, colonne **Type**) ;
- son adresse MAC ;
- son adresse IP locale ;
- son état de connexion (colonne **État**).

Vous pouvez actualiser cette liste en cliquant sur le bouton <code className="action">Actualiser la liste</code>. Le champ **Rechercher** permet de filtrer les équipements affichés.

<img className="thumbnail" alt="Section Appareils connectés de l'onglet Modem avec le bouton Actualiser la liste" src="/images/web-cloud/internet/internet-access/configuration-du-modem-a-partir-de-votre-espace-client/console/connected-devices.png" loading="lazy" />

{/* CP-STEPS-END:reseau */}

#### 2.2 Configuration générale

{/* CP-STEPS-START:configuration-generale */}

Depuis l'onglet **Modem**, plusieurs possibilités s'offrent à vous.

- **Redémarrer à distance votre box** : dans la section **Informations du modem**, cliquez sur <code className="action">Redémarrer</code>, puis confirmez l'action en cliquant sur <code className="action">Redémarrer</code> dans la fenêtre qui s'affiche. Votre accès à Internet et vos services téléphoniques sont interrompus pendant quelques minutes : patientez alors le temps que votre box redémarre.

- **Activer ou désactiver la configuration à distance de votre box** : dans la section **Firmware et gestion à distance**, activez ou désactivez l'interrupteur **Configuration à distance**. L'activation écrasera le paramétrage actuel de votre box. La désactivation rendra impossible la configuration de votre box depuis la console OVHcloud, celle-ci conservera cependant les paramètres en place au moment de la désactivation. Lors de la désactivation, un nouveau mot de passe est généré et transmis par e-mail pour vous permettre d'accéder à l'interface locale du modem. Pour plus d'informations sur la configuration d'un modem Zyxel sans la configuration à distance, veuillez consulter le [guide utilisateur du modem Zyxel](http://files.isp.ovhcloud.com/zyxel/VMG8825-T50K_V5.13_5.50-1.pdf).

{/* v8-gap: CG-090 — modem firewall level not in the Console; bullet kept from v6 until the Console team answers */}

- **Pare-feu** : lorsque vous gérez votre box à distance, le pare-feu n’est pas paramétrable. Celui-ci s’adapte automatiquement aux configurations en place dans l’espace client.

- **Paramétrer l'utilisation de vos réseaux Wi-Fi** : la section **Réseaux WiFi** liste vos réseaux Wi-Fi (un par bande de fréquence, pour le réseau principal comme pour le réseau invité) et indique dans la colonne **État** si chacun est activé ou désactivé. Pour modifier un réseau, cliquez sur le bouton <code className="action">⋮</code> à droite de sa ligne, puis sur <code className="action">Modifier</code>.

<img className="thumbnail" alt="Section Réseaux WiFi de l'onglet Modem avec le menu d'une ligne ouvert sur Modifier et Afficher le QR code" src="/images/assets/screens/console/product-selection/web-cloud/internet-access/wifi-row-menu.png" loading="lazy" />

Le panneau **Modifier le réseau WiFi** s'ouvre. Personnalisez alors les champs pour modifier la configuration du réseau Wi-Fi. Selon la box dont vous disposez, il se peut que vous puissiez modifier les paramètres Wi-Fi d'un ou de plusieurs réseaux, dont ceux dits « Invités ».

|Champ|Description|
|---|---|
|Activation du WiFi|Activez ou désactivez cet interrupteur pour activer ou désactiver le réseau Wi-Fi.|
|Visibilité du réseau|Permet de rendre visible ou de masquer la diffusion du nom du réseau Wi-Fi. Si vous décidez de le masquer, celui-ci n'apparaîtra plus dans la liste des réseaux disponibles sur vos appareils. Pour vous connecter une première fois à ce réseau, vous devrez le paramétrer manuellement sur vos appareils.|
|Nom du réseau (SSID)|Il s'agit du nom de votre réseau Wi-Fi. Celui-ci apparaîtra sur vos appareils lorsque vous afficherez la liste des réseaux disponibles. Vous pouvez personnaliser ce nom si vous le souhaitez.|
|Sécurité|Il s'agit du type de sécurité de votre réseau Wi-Fi. Pour une utilisation optimale, nous vous recommandons le `WPA3` si votre modem le supporte ou le `WPA2`.|
|Nouvelle clé / Confirmer la nouvelle clé|Permet de changer la clé Wi-Fi par celle de votre choix. Vous devrez également la confirmer. Laissez ces champs vides pour conserver la clé actuelle.|
|Canal|Par défaut, le canal est en `Automatique` ; la box sélectionne le premier canal disponible. Vous pouvez sélectionner un canal en particulier depuis la liste. Si cela s'avère nécessaire, effectuez plusieurs tests afin de trouver le plus stable et le mieux adapté à votre environnement.|

Une fois le réseau Wi-Fi modifié, cliquez sur le bouton <code className="action">Modifier</code>.

<img className="thumbnail" alt="Panneau Modifier le réseau WiFi avec ses champs et le bouton Modifier" src="/images/assets/screens/console/product-selection/web-cloud/internet-access/wifi-edit-drawer.png" loading="lazy" />

{/* CP-STEPS-END:configuration-generale */}

#### 2.3 Configuration réseau (IP LAN, DHCP, redirections de ports)

{/* CP-STEPS-START:configuration-reseau */}

Depuis les sections **IP LAN**, **DHCP**, **Baux DHCP** et **Redirection de ports** de l'onglet **Modem**, plusieurs possibilités de configuration s'offrent à vous.

- **Configurer l'IP LAN de la box** : permet de personnaliser l'adresse IP privée de votre box. C'est avec celle-ci que vous pourrez communiquer sur votre réseau local avec votre box.

Pour cela, cliquez sur <code className="action">Modifier la configuration IP LAN</code> en bas de la section **IP LAN**. Dans le panneau **Modifier l'IP LAN**, choisissez alors une configuration `Statique` ou `DHCP` dans le menu déroulant **Méthode de récupération d'adresse IP**.

|Configuration|Description|
|---|---|
|Statique|En choisissant cette configuration, vous devrez définir l'adresse IP (**Adresse IP LAN**) et le masque de sous-réseau de votre box.|
|DHCP|En choisissant cette configuration, la box se comportera comme n'importe quel équipement réseau. Elle effectuera une demande DHCP auprès d'un serveur et récupérera un bail DHCP pour un temps donné.|

Une fois la configuration de l'IP LAN modifiée, validez le changement en cliquant sur <code className="action">Modifier</code>.

<img className="thumbnail" alt="Panneau Modifier l'IP LAN avec le menu Méthode de récupération d'adresse IP" src="/images/web-cloud/internet/internet-access/configuration-du-modem-a-partir-de-votre-espace-client/console/lan-ip-edit-drawer.png" loading="lazy" />

- **Configurer le DHCP** : permet de personnaliser la configuration du serveur DHCP de votre box. Modifiez-la uniquement dans le cas d'une utilisation avancée de votre service.

Pour cela, cliquez sur <code className="action">Modifier la configuration DHCP</code> en bas de la section **DHCP**. Dans le panneau **Modifier le DHCP**, l'interrupteur **Activation du serveur** permet d'activer ou de désactiver le DHCP sur votre box. Le panneau permet également de paramétrer les éléments suivants, utilisés lorsque le DHCP est actif :

|Configuration|Description|
|---|---|
|Passerelle|Elle correspond à l'adresse IP locale de votre box OVHcloud. Celle-ci peut être différente dans des cas très spécifiques, comme avec des pare-feu ou OverTheBox.|
|DNS primaire / DNS secondaire|Les DNS primaires et secondaires sont les options DNS attribuées à un équipement lors d'une demande DHCP. Ils ne modifient pas les DNS internes de la box.|
|Nom de domaine|Permet l'ajout d'un suffixe DNS à votre réseau local.|
|Adresse de début / Adresse de fin|Correspondent au début et à la fin de la plage d'adresses distribuées par le DHCP.|
|Durée d'allocation d'une adresse|Temps, en secondes, avant que l’équipement ne relâche le bail DHCP qui lui a été attribué. Un renouvellement du bail DHCP est effectué à 80 % du temps total.|

Une fois la configuration DHCP modifiée, validez le changement en cliquant sur <code className="action">Modifier</code>.

<img className="thumbnail" alt="Panneau Modifier le DHCP avec l'interrupteur Activation du serveur et les paramètres du serveur" src="/images/web-cloud/internet/internet-access/configuration-du-modem-a-partir-de-votre-espace-client/console/dhcp-edit-drawer.png" loading="lazy" />

- **Configurer les baux DHCP** : permet de réserver des baux DHCP afin qu'un ou plusieurs équipements récupèrent toujours la même adresse IP locale.

Pour cela, cliquez sur <code className="action">Ajouter un bail DHCP</code> dans la section **Baux DHCP**, puis complétez les informations demandées.

|Information|Description|
|---|---|
|Nom du bail|Spécifiez un nom vous permettant de mieux identifier ce bail par la suite dans le tableau. Il ne remplace pas celui diffusé sur le [réseau](#21-réseau).|
|Adresse IP|Indiquez l'adresse IP locale réservée à l'équipement concerné.|
|Adresse MAC|Renseignez l'adresse MAC de l'équipement concerné.|

Une fois les informations complétées, validez l'ajout en cliquant sur <code className="action">Ajouter</code>.

<img className="thumbnail" alt="Panneau Ajouter un bail DHCP avec les champs Nom du bail, Adresse IP et Adresse MAC" src="/images/web-cloud/internet/internet-access/configuration-du-modem-a-partir-de-votre-espace-client/console/dhcp-lease-add-drawer.png" loading="lazy" />

- **Configurer des redirections de ports** : permet de rediriger des paquets réseau reçus sur un port ou une plage de ports par votre box vers un équipement local de votre réseau.

Pour cela, cliquez sur <code className="action">Ajouter une redirection de ports</code> dans la section **Redirection de ports**, puis complétez les informations demandées.

|Information|Description|
|---|---|
|Nom de la redirection|Spécifiez un nom vous permettant de mieux identifier la redirection de ports dans le tableau par la suite.|
|IP source|Permet de restreindre le champ d'application de la redirection de ports à une seule IP source. Laissez cet espace vide (le champ se complète alors automatiquement avec l'IP par défaut 0.0.0.0) pour que celle-ci s'applique qu'importe la source.|
|Port de début / Port de fin|Définissez le port ou la plage de ports sur lequel la redirection s'appliquera. Pour rediriger un seul port, renseignez-le en tant que port de début et de fin.|
|Protocole|Précisez le protocole sur lequel votre redirection s'appliquera. Pour l'appliquer aux deux protocoles, sélectionnez l'option combinant TCP et UDP.|
|IP de destination|Indiquez l'adresse IP sur le réseau local vers qui transmettre la redirection. Pour que celle-ci fonctionne, l'équipement cible doit posséder comme passerelle par défaut celle de la box qui transmet la redirection.|
|Port interne de début / Port interne de fin|Indiquez le port (ou la plage de ports) sur lequel l'équipement du réseau local cible écoute.|

Une fois les informations complétées, validez l'ajout en cliquant sur <code className="action">Ajouter</code>.

<img className="thumbnail" alt="Panneau Ajouter une redirection de ports avec ses champs" src="/images/web-cloud/internet/internet-access/configuration-du-modem-a-partir-de-votre-espace-client/console/port-forwarding-add-drawer.png" loading="lazy" />

#### 2.4 Configurations avancées

{/* CP-STEPS-START:configurations-avancees */}

Depuis l'onglet **Modem**, plusieurs possibilités s'offrent à vous.

- **Réinitialiser votre box** : permet de réinitialiser les paramètres de votre box, tout en conservant les configurations définies dans la console OVHcloud. Pour cela, cliquez sur <code className="action">Réinitialiser le modem</code> dans la section **Informations du modem**, puis confirmez l'action en cliquant sur <code className="action">Réinitialiser le modem</code> dans la fenêtre qui s'affiche. Patientez alors le temps que la manipulation s'effectue.

- **Réinitialiser la configuration OVHcloud** : permet de réinitialiser les paramètres de votre box sans conserver les configurations définies dans la console OVHcloud. Pour cela, cliquez sur <code className="action">Réinitialiser le modem</code> dans la section **Informations du modem**, activez l'interrupteur **Réinitialiser aussi la configuration OVHcloud** dans la fenêtre qui s'affiche, puis cliquez sur <code className="action">Réinitialiser le modem</code>. Patientez alors le temps que la manipulation s'effectue.

<img className="thumbnail" alt="Fenêtre Réinitialiser le modem avec l'interrupteur Réinitialiser aussi la configuration OVHcloud" src="/images/assets/screens/console/product-selection/web-cloud/internet-access/reset-modem-dialog.png" loading="lazy" />

- **Activer le mode bridge** : cette option n'est pas disponible dans la console OVHcloud.

- **Configurer le MTU** : lors d'une transmission de données informatiques, le Maximum Transmission Unit (MTU) est la taille maximale d'un paquet pouvant être échangé en une seule fois (c'est-à-dire sans fragmentation) sur une interface. Le MTU par défaut d'un accès OVHcloud en PPPoE est de 1 492.

Pour le modifier, cliquez sur <code className="action">Modifier</code> à côté de **MTU** dans la section **Configuration avancée**. Dans la fenêtre qui s'affiche, sélectionnez la nouvelle valeur dans le menu déroulant **MTU**, puis cliquez sur <code className="action">Modifier</code>.

- **Configurer une DMZ** : ceci permet de renvoyer tous les flux réseau vers un autre équipement réseau (un pare-feu, par exemple). Usuellement, la DMZ doit être sur un sous-réseau, séparé du réseau local et d'Internet par un pare-feu. Ce sous-réseau contient les machines susceptibles d'être contactées depuis Internet.

Pour configurer une DMZ, cliquez sur <code className="action">Modifier</code> sous **Adresse IP de la DMZ** dans la section **Configuration avancée**. Dans la fenêtre qui s'affiche, saisissez l'adresse IP de la DMZ, puis cliquez sur <code className="action">Modifier</code>. Votre modem est alors reconfiguré et votre connexion coupée pendant quelques minutes. Pour supprimer la DMZ, laissez ce champ vide.

<img className="thumbnail" alt="Section Configuration avancée de l'onglet Modem avec le MTU et l'adresse IP de la DMZ" src="/images/web-cloud/internet/internet-access/configuration-du-modem-a-partir-de-votre-espace-client/console/advanced-configuration-card.png" loading="lazy" />

:::warning

Une fois la DMZ activée, vous devenez responsable de la sécurité de votre réseau.

:::

- **Choisir le fichier de configuration (_firmware_) de votre box** : selon la box dont vous disposez, il se peut que plusieurs fichiers de configuration (_firmwares_) soient proposés. De manière générale — et pour éviter tout problème éventuel — les mises à jour dites « non critiques » ne sont pas effectuées automatiquement. Vous avez cependant la possibilité de les réaliser manuellement.

La version en place est indiquée sur la ligne **Firmware** de la section **Firmware et gestion à distance**. Lorsqu'une autre version est disponible, cliquez sur <code className="action">Mettre à jour</code> à côté de cette ligne (ou sur <code className="action">Modifier le firmware</code> si plusieurs versions sont proposées), choisissez la version à appliquer dans le champ **Version du firmware**, puis cliquez sur <code className="action">Mettre à jour</code>.

{/* CP-STEPS-END:configurations-avancees */}

#### 2.5 Services

{/* CP-STEPS-START:services */}

Vous pouvez, dans la section **Services**, activer ou désactiver des services additionnels de votre box. Les services y sont regroupés par thème et l'état de chacun est indiqué (**Activé** ou **Désactivé**). Cliquez sur <code className="action">Activer</code> ou <code className="action">Désactiver</code> sous le service concerné, puis confirmez l'action dans la fenêtre qui s'affiche. **Selon la box dont vous disposez, certains services de la liste ci-dessous peuvent ne pas être disponibles.**

|Service|Thème|Description|
|---|---|---|
|UPnP|Réseau|Active ou désactive la fonction UPnP de votre box (ouverture automatique des ports).|
|Bloc d'IP|Réseau|Si vous [disposez d'un bloc IP](/guides/web-cloud/internet/internet-access/comment-commander-et-gerer-un-bloc-ip-29), vous pouvez activer ou désactiver celui-ci. Toute la configuration de votre box va alors s'adapter automatiquement (par exemple : désactivation pare-feu + NAT).|
|Ipsec ALG|Réseau|Active ou désactive le processus ALG pour le tunneling IPsec.|
|Mise en attente d’appel|Téléphonie|Active ou désactive la mise en attente des appels, directement depuis la box (uniquement pour les téléphones branchés sur les prises RJ11 de la box).|
|SIP ALG|Téléphonie|Active ou désactive le SIP ALG. L’ALG permet de contrôler (en autorisant ou refusant) du trafic vers une application de serveur.|
|FTP|Partage de fichiers|Active ou désactive le serveur FTP de votre box.|
|Partage de contenu|Partage de fichiers|**Concerne uniquement les box Thomson (TG7XX).** Par défaut, le partage de contenu est activé pour ces dernières, ce qui utilise une adresse IP supplémentaire. <br/><br/>La console OVHcloud ne permet pas de configurer ce partage, mais vous pouvez le désactiver via l’accès à distance afin de libérer l’IP utilisée par défaut. La configuration du partage de contenu s'effectue uniquement en local.|
