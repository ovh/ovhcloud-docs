## Objectif

Le monitoring permet de vous alerter, selon une fréquence définie par vos soins, lorsque votre accès n'est plus joignable. Les notifications seront envoyées lorsque votre accès ne répondra plus aux requêtes ICMP (ping).
Les notifications sont envoyées par e-mail ou par SMS (il est alors nécessaire de disposer d'un compte SMS OVHcloud crédité).

**Découvrez comment activer des alertes de monitoring sur un accès à Internet OVHcloud.**

## Prérequis

- Disposer d'un [accès Internet xDSL ou FTTH OVHcloud](https://www.ovhcloud.com/fr/internet/) qui répond aux requêtes ICMP (c'est le cas par défaut sur les modems distribués par OVHcloud).
- Disposer d'une adresse e-mail pour recevoir les notifications.
- Détenir un [compte SMS crédité](https://www.ovhcloud.com/fr/sms/) si vous souhaitez recevoir les SMS de notifications sur votre mobile.

## En pratique

{/* CP-STEPS-START:afficher-les-alertes */}

Dans la liste **Accès Internet**, cliquez sur votre accès à Internet FTTH ou xDSL dans la colonne **Nom/ID**. L'onglet **Vue d'ensemble** s'affiche.

En bas de cet onglet, la section **Alertes personnalisées** liste les alertes déjà configurées sur votre accès et vous permet d'en créer de nouvelles.

<img className="thumbnail" alt="section Alertes personnalisées de l'onglet Vue d'ensemble avec une alerte e-mail" src="/images/web-cloud/internet/internet-access/monitoring/console/custom-alerts-card.png" loading="lazy" />

{/* CP-STEPS-END:afficher-les-alertes */}

### Activer les notifications par e-mail

{/* CP-STEPS-START:notifications-e-mail */}

Pour créer une notification par e-mail, cliquez sur <code className="action">Ajouter une alerte</code> dans la section **Alertes personnalisées**. Le panneau **Ajouter l'alerte** s'ouvre.

Dans le menu déroulant **Type**, sélectionnez **E-mail**.

Renseignez l'adresse e-mail à notifier dans le champ **Contact à notifier**.

Dans le menu déroulant **Fréquence d'envoi**, sélectionnez la fréquence d'envoi des notifications par e-mail lors d'une coupure. Si vous sélectionnez **Une seule fois**, vous recevrez un e-mail lors de la coupure et un e-mail lors du rétablissement de l'accès à Internet concerné.

Renseignez également les champs **Notification des incidents** et **Délai avant notification (en minutes)**, puis cliquez sur <code className="action">Ajouter l'alerte</code>.

Si vous ajoutez une adresse commune à plusieurs accès, vous recevrez un seul e-mail contenant toutes les notifications de coupure.

<img className="thumbnail" alt="panneau Ajouter l'alerte avec le type E-mail sélectionné" src="/images/web-cloud/internet/internet-access/monitoring/console/add-alert-dialog.png" loading="lazy" />

{/* CP-STEPS-END:notifications-e-mail */}

### Activer les notifications par SMS

{/* CP-STEPS-START:notifications-sms */}

Pour créer une notification par SMS, cliquez sur <code className="action">Ajouter une alerte</code> dans la section **Alertes personnalisées**. Le panneau **Ajouter l'alerte** s'ouvre.

Dans le menu déroulant **Type**, sélectionnez **SMS**.

Dans le menu déroulant **Compte SMS**, choisissez le compte SMS à utiliser pour envoyer les notifications.

Renseignez, dans le champ **Contact à notifier**, le numéro de mobile à notifier, au format international (par exemple +33612345678).

Dans le menu déroulant **Fréquence d'envoi**, sélectionnez la fréquence d'envoi des notifications SMS lors d'une coupure. Si vous sélectionnez **Une seule fois**, vous recevrez un SMS lors de la coupure et un SMS lors du rétablissement de l'accès à Internet concerné.

Renseignez également les champs **Notification des incidents** et **Délai avant notification (en minutes)**, puis cliquez sur <code className="action">Ajouter l'alerte</code>.

<img className="thumbnail" alt="panneau Ajouter l'alerte avec le type SMS et le champ Compte SMS" src="/images/web-cloud/internet/internet-access/monitoring/console/add-alert-dialog-sms.png" loading="lazy" />

{/* CP-STEPS-END:notifications-sms */}

Les SMS vous prévenant de l'injoignabilité de votre accès à Internet, ou de son rétablissement, se présentent sous la forme suivante :

<img className="thumbnail" alt="sms d'alerte" src="/images/web-cloud/internet/internet-access/monitoring/XDSL-monitoring-alertes-sms.png" loading="lazy" />

### Supprimer une alerte

{/* CP-STEPS-START:supprimer-alerte */}

Pour supprimer une alerte préalablement activée, cliquez sur l'icône de corbeille à droite de l'alerte, dans la section **Alertes personnalisées**. Confirmez la suppression en cliquant sur <code className="action">Supprimer</code> dans la fenêtre **Supprimer la notification**.

<img className="thumbnail" alt="fenêtre Supprimer la notification avec les boutons Annuler et Supprimer" src="/images/web-cloud/internet/internet-access/monitoring/console/delete-alert-dialog.png" loading="lazy" />
