## Objectif

Vous pouvez faire évoluer votre offre OverTheBox pour accéder à de nouvelles fonctionnalités et services.

Le changement d'offre permet de :

- Migrer d'une offre Starter 500Mbps à une offre Business 1Gbps.
- Migrer d'une offre Business 1Gbps à une offre Starter 500 Mbps.
- Migrer d'une ancienne offre de service à une nouvelle offre Starter ou Business.
- Commander un boîtier OTBv3

Lors d'une migration, l'adresse IP de votre service est conservée et votre appareil OverTheBox actuel reste compatible.

## Prérequis

- Disposer d'un service OverTheBox actif.

[[cpnav:telecom-otb-console]]

## En pratique

### Changer d’offre

{/* CP-STEPS-START:changer-d-offre */}

Sélectionnez le service OverTheBox que vous souhaitez faire évoluer. Dans la section **Abonnement** de l'onglet **Vue d'ensemble**, cliquez sur <code className="action">Changer d'offre</code> sous le nom de votre offre actuelle.

<img className="thumbnail" alt="lien Changer d'offre dans la section Abonnement" src="/images/web-cloud/internet/overthebox/offer-migration/console/overview-subscription-change-offer.png" loading="lazy" />

La section **Offres disponibles** présente votre offre actuelle, signalée par la mention **Offre actuelle**, avec son tarif. Les autres offres sont celles auxquelles vous pouvez souscrire.

Pour chacune de ces offres, vous pouvez, si vous le souhaitez, commander un boîtier en plus de votre changement d'offre : dans le menu déroulant **Matériel**, sélectionnez **OverTheBox v3** ou **OverTheBox v3 LTE**, ou conservez **Pas de matériel**.

Une fois votre choix effectué, sélectionnez l'offre que vous souhaitez souscrire, puis cliquez sur <code className="action">Suivant</code> dans la section **Récapitulatif de votre commande**.

<img className="thumbnail" alt="sélection d'une offre parmi les offres disponibles" src="/images/web-cloud/internet/overthebox/offer-migration/console/change-offer-available-offers.png" loading="lazy" />

{/* CP-STEPS-END:changer-d-offre */}

### Sélectionner une adresse de livraison

{/* CP-STEPS-START:selectionner-adresse-livraison */}

:::info

Si vous avez choisi l'option **Pas de matériel**, vous pouvez passer à la section « [Valider le changement d'offre](#validation) » de ce guide.

:::

Si vous avez choisi de commander un nouveau boîtier avec votre changement d'offre, vous devez choisir une adresse de livraison.

La section **Adresse de livraison** liste les contacts de votre compte OVHcloud, avec leur nom et leur adresse. Sélectionnez le contact auquel le boîtier doit être livré, puis cliquez sur <code className="action">Suivant</code>.

:::info

Les frais de livraison sont inclus dans le prix du boîtier.

:::

<img className="thumbnail" alt="sélection de l'adresse de livraison" src="/images/web-cloud/internet/overthebox/offer-migration/console/change-offer-delivery-address.png" loading="lazy" />

{/* CP-STEPS-END:selectionner-adresse-livraison */}

### Valider le changement d'offre <a name="validation"></a>

{/* CP-STEPS-START:valider-changement-offre */}

La section **Récapitulatif de la commande** résume la tarification mensuelle de la nouvelle offre, ainsi que le coût du boîtier (si l'option a été sélectionnée), puis le montant du premier mois et celui des mois suivants.

<img className="thumbnail" alt="récapitulatif de la commande de changement d'offre" src="/images/web-cloud/internet/overthebox/offer-migration/console/change-offer-order-summary.png" loading="lazy" />

Dans la section **Validation**, prenez connaissance des contrats afférents et cochez la case **J'ai lu et j'accepte les contrats ci-dessus**, puis cliquez sur <code className="action">Confirmer le changement d'offre</code>.

<img className="thumbnail" alt="section Validation avec la case des contrats et le bouton Confirmer le changement d'offre" src="/images/web-cloud/internet/overthebox/offer-migration/console/change-offer-validation.png" loading="lazy" />

{/* CP-STEPS-END:valider-changement-offre */}

### Payer le bon de commande

:::info
Une fois le bon de commande payé, le changement d'offre est immédiat si vous n'avez pas choisi de boîtier.
Dans le cas où vous avez choisi un boîtier, le changement d'offre sera réalisé à réception du boîtier.
Un remboursement au prorata de la facturation du mois en cours est alors établi.

:::


{/* CP-STEPS-START:payer-bon-de-commande-1 */}

Pour finaliser le changement d'offre, ainsi que la livraison du boîtier, vous devez payer le bon de commande généré lors de la confirmation de la migration. Une fois le changement d'offre confirmé, la section **Migration lancée** affiche le numéro de votre commande de migration : cliquez sur le lien <code className="action">Voir la commande</code> pour l'ouvrir et la payer.

{/* CP-STEPS-END:payer-bon-de-commande-1 */}

:::info
Pour plus d'informations sur le paiement d'un bon de commande, consultez le guide « [Gérer mes commandes OVHcloud](/guides/account-and-service-management/managing-billing-payments-and-services/ovh-orders) ».

:::
