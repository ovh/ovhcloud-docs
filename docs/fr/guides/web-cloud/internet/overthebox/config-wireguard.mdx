## Objectif

OverTheBox propose un mode de fonctionnement **WireGuard**<sup>1</sup>, une alternative au tunnel OverTheBox historique (glorytun / MPTCP).

**Ce guide vous explique comment basculer votre service OverTheBox en mode WireGuard et le configurer via l'API OVHcloud.**

## Prérequis

- Disposer d'un service **OverTheBox Starter** ou **OverTheBox Business** fourni par OVHcloud. WireGuard n'est pas disponible sur les anciennes offres : vous pouvez changer d'offre en consultant le guide « [Comment changer l'offre de mon service OverTheBox ?](/guides/web-cloud/internet/overthebox/offer-migration) ».
- Consultez notre guide des [premiers pas avec l'API OVHcloud](/guides/manage-and-operate/api/first-steps) afin de vous familiariser avec l'APIv6 OVHcloud.

:::warning
Le mode **WireGuard** d'OverTheBox est actuellement en phase **bêta**. Son comportement et les routes API associées sont susceptibles d'évoluer.

:::


:::warning
L'**IPv6 n'est pas disponible** en mode WireGuard. Si vous avez besoin de l'IPv6, utilisez le mode OverTheBox historique et consultez le guide « [Comment configurer IPv6 sur OverTheBox](/guides/web-cloud/internet/overthebox/config-ipv6) ».

:::


:::warning
Les modes de fonctionnement sont **exclusifs** : le tunnel OverTheBox historique (glorytun / MPTCP) et WireGuard ne peuvent pas fonctionner en même temps. Basculer vers un mode désactive automatiquement l'autre.

:::


## En pratique

Toutes les routes API de ce guide sont disponibles dans la <ApiLink section="/overTheBox">section */overTheBox*</ApiLink> de la console API.

:::info
Lors de l'utilisation de l'API, tous les champs marqués d'un astérisque (\*) sont obligatoires.
:::


### Vérifier le mode de fonctionnement actuel

Récupérez les informations de votre service, notamment le champ `operationMode`, à l'aide de la route suivante :

<Api version="v1" section="/overTheBox" method="GET" route={"/overTheBox/\{serviceName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service OverTheBox |

Le champ `operationMode` renvoyé indique le mode actif :

- `overthebox-legacy` : le tunnel OverTheBox historique (glorytun / MPTCP).
- `wireguard` : le mode WireGuard.

### Lister les modes de fonctionnement disponibles

Les modes disponibles dépendent de votre offre. Utilisez la route suivante pour connaître ceux qui sont accessibles sur votre service :

<Api version="v1" section="/overTheBox" method="GET" route={"/overTheBox/\{serviceName\}/availableOperationModes"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service OverTheBox |

Le mode `wireguard` n'apparaît dans la liste que si votre offre le permet (offres **Starter** ou **Business**).

### Basculer en mode WireGuard

Utilisez la route suivante pour changer le mode de fonctionnement de votre service :

<Api version="v1" section="/overTheBox" method="PUT" route={"/overTheBox/\{serviceName\}/operationMode"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service OverTheBox |
| `operationMode` | Yes | Le mode de fonctionnement à appliquer : `wireguard` (ou `overthebox-legacy` pour revenir au tunnel historique) |

:::warning
Le basculement en mode WireGuard désactive le tunnel OverTheBox historique et rend l'IPv6 indisponible. L'opération peut entraîner une courte interruption de service, le temps que la nouvelle configuration soit appliquée.

:::


### Récupérer la configuration du serveur WireGuard

Une fois le service en mode WireGuard, récupérez la configuration du serveur (nécessaire pour configurer vos clients) à l'aide de la route suivante :

<Api version="v1" section="/overTheBox" method="GET" route={"/overTheBox/\{serviceName\}/wireguard"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service OverTheBox |

La réponse contient les informations à reporter dans la configuration de vos clients WireGuard :

| Champ | Description |
|-------|-------------|
| `endpoint.ipv4` | Adresse IPv4 publique du serveur WireGuard |
| `endpoint.port` | Port de connexion du serveur WireGuard |
| `publicKey` | Clé publique du serveur WireGuard |
| `privateIpv4` | Plage d'adresses IPv4 privées du serveur WireGuard |
| `maxPeerActive` | Nombre maximum de peers actifs simultanément |
| `maxPeerAllowed` | Nombre maximum de peers configurables |

### Gérer les peers WireGuard

Un *peer* représente un client autorisé à se connecter au serveur WireGuard de votre OverTheBox.

#### Lister les peers

<Api version="v1" section="/overTheBox" method="GET" route={"/overTheBox/\{serviceName\}/wireguard/peers"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service OverTheBox |

#### Créer un peer

Générez d'abord une paire de clés WireGuard sur votre client, puis transmettez sa clé publique à l'aide de la route suivante :

<Api version="v1" section="/overTheBox" method="POST" route={"/overTheBox/\{serviceName\}/wireguard/peers"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service OverTheBox |
| `name` | Yes | Un nom pour identifier le peer |
| `description` | Yes | Une description du peer |
| `publicKey` | Yes | La clé publique WireGuard du client |
| `privateIpv4` | Yes | L'adresse IPv4 privée à attribuer au peer (dans la plage `privateIpv4` du serveur) |

#### Consulter un peer

<Api version="v1" section="/overTheBox" method="GET" route={"/overTheBox/\{serviceName\}/wireguard/peers/\{peerId\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service OverTheBox |
| `peerId` | Yes | L'identifiant du peer |

#### Modifier un peer

<Api version="v1" section="/overTheBox" method="PUT" route={"/overTheBox/\{serviceName\}/wireguard/peers/\{peerId\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service OverTheBox |
| `peerId` | Yes | L'identifiant du peer |
| `name` |  | Un nom pour identifier le peer |
| `description` |  | Une description du peer |
| `publicKey` |  | La clé publique WireGuard du client |
| `privateIpv4` |  | L'adresse IPv4 privée attribuée au peer |
| `active` |  | Active (`true`) ou désactive (`false`) le peer |

#### Supprimer un peer

<Api version="v1" section="/overTheBox" method="DELETE" route={"/overTheBox/\{serviceName\}/wireguard/peers/\{peerId\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service OverTheBox |
| `peerId` | Yes | L'identifiant du peer |

### Régénérer la configuration WireGuard

Cette opération régénère les clés du serveur WireGuard :

<Api version="v1" section="/overTheBox" method="POST" route={"/overTheBox/\{serviceName\}/wireguard/regenerate"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service OverTheBox |

:::warning
La régénération modifie la clé publique du serveur. Vous devrez mettre à jour la configuration de tous vos clients WireGuard pour rétablir la connexion.

:::


### Réinitialiser la configuration WireGuard

Cette opération réinitialise la configuration WireGuard du service :

<Api version="v1" section="/overTheBox" method="POST" route={"/overTheBox/\{serviceName\}/wireguard/reset"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Le nom interne de votre service OverTheBox |

:::warning
La réinitialisation est une opération destructive : elle supprime les peers configurés et restaure la configuration WireGuard par défaut.

:::
