## Présentation d'OverTheBox

[OverTheBox](/links/telecom/overthebox) agrège plusieurs accès Internet (xDSL, Fibre, 4G) pour améliorer le débit et la disponibilité de votre connexion. Retrouvez ici tous les guides pour installer, mettre en service, configurer et administrer votre OverTheBox.

Avec OverTheBox, vous pouvez :

- Agréger plusieurs accès Internet (xDSL, Fibre, 4G) pour plus de débit et de résilience
- Utiliser le boîtier fourni par OVHcloud ou installer OverTheBox sur votre propre matériel
- Configurer votre réseau local : pare-feu, QoS, IPv6 et routes statiques
- Accéder à distance à votre OverTheBox
- Gérer et faire évoluer votre offre
