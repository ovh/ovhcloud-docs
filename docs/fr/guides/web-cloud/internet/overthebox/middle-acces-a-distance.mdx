## Objectif

Ajouter un accès à distance à votre OverTheBox permet une gestion et une surveillance sécurisées de votre réseau depuis n'importe quel endroit. Cette fonctionnalité est essentielle pour les administrateurs réseau qui ont besoin de maintenir une continuité opérationnelle et de réagir rapidement à des événements critiques, quel que soit leur emplacement.

**Découvrez comment ajouter un accès à distance sur OverTheBox.**

## Prérequis

- Disposer d'un service **OverTheBox** fourni par OVHcloud.

[[cpnav:telecom-otb-console]]

## En pratique

### Création de l'accès à distance

{/* CP-STEPS-START:creation-acces-a-distance */}

Depuis la <ManagerLink to="/beta/#/web-cloud/overthebox">console OVHcloud</ManagerLink>, sélectionnez le service OverTheBox auquel vous souhaitez accéder à distance, puis cliquez sur l'onglet <code className="action">Accès à distance</code>.

Cliquez sur le bouton <code className="action">Ajouter un accès</code>. Informations à renseigner dans le panneau **Ajouter un accès** qui s'ouvre :

- **IP autorisée** : Cette adresse IP publique sera la seule autorisée à se connecter sur l'OverTheBox à distance. Laissez ce champ vide si l'IP autorisée doit être celle de votre connexion actuelle.
- **Port exposé** : Port de l'**OverTheBox** qui sera contacté lors de l'accès à distance. Dans le menu déroulant, sélectionnez **443 / HTTPS** pour un accès à distance via le navigateur ou **22 / SSH** pour un accès via SSH.
- **Date d'expiration** : Date à laquelle l'accès à distance sera fermé.
- **Clé publique** : Obligatoire pour les connexions de type SSH, cette clé permet une connexion sécurisée.
- Validez la création à l'aide du bouton <code className="action">Ajouter</code>.
- Une fois l'accès créé, patientez quelques minutes le temps que l'accès à distance se configure. Son statut passe de **Création en cours** à **Actif** : cliquez sur <code className="action">Rafraîchir</code> pour mettre la liste à jour.

:::info

L'**OverTheBox** se connecte sur notre infrastructure, aucune ouverture de port sur les modems en amont de l'**OverTheBox** n'est nécessaire.

:::

### Connexion à distance

:::info
Pour une connexion sur l'interface web, il est possible que le navigateur alerte sur un possible problème de sécurité. La connexion est bien chiffrée mais le navigateur ne reconnaît pas le certificat SSL car il n'est pas signé par une autorité de certification.

:::


{/* CP-STEPS-START:connexion-a-distance */}

<Tabs>
  <Tab label="HTTPS">
    Une fois l'accès à distance créé et son statut passé à **Actif**, copiez l'adresse affichée dans la colonne **Connexion** de l'onglet <code className="action">Accès à distance</code> (au format `https://<adresse IP>:<port>`), puis ouvrez-la dans votre navigateur pour vous connecter à votre **OverTheBox**.

    <img className="thumbnail" alt="onglet Accès à distance avec un accès HTTPS actif et son adresse de connexion" src="/images/web-cloud/internet/overthebox/middle-acces-a-distance/console/remote-access-list-connection.png" loading="lazy" />
  </Tab>
  <Tab label="SSH">
    Une fois l'accès à distance créé avec le port **22 / SSH** et son statut passé à **Actif**, connectez-vous à votre **OverTheBox** depuis votre terminal, avec la clé privée correspondant à la **Clé publique** renseignée lors de la création de l'accès.

### Suppression de l'accès à distance

{/* CP-STEPS-START:suppression-acces-a-distance */}

Pour supprimer un accès à distance, cliquez sur l'icône en forme de poubelle dans la colonne **Actions** de la ligne concernée, puis confirmez avec le bouton <code className="action">Supprimer</code> dans la fenêtre **Supprimer un accès distant**.

:::warning

Cette action est irréversible.

:::

<img className="thumbnail" alt="fenêtre Supprimer un accès distant avec les boutons Annuler et Supprimer" src="/images/web-cloud/internet/overthebox/middle-acces-a-distance/console/delete-remote-access-dialog.png" loading="lazy" />
