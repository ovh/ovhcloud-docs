## Objectif

Découvrez comment mettre à jour votre appareil OverTheBox, afin de profiter des dernières améliorations apportées sur cette solution.

## Prérequis

- Disposer d'un service **OverTheBox** fourni par OVHcloud.

[[cpnav:telecom-otb-console]]

## En pratique

La méthode recommandée est de mettre à jour votre appareil OverTheBox depuis la console OVHcloud.

### Consulter la version de son appareil

L'OverTheBox est un projet open-source hébergé sur la plateforme GitHub. Le code est librement accessible et vous permet de consulter concrètement ce qui change entre chaque version.
La version d'un appareil est au format [semver](https://semver.org/lang/fr/), vous pouvez consulter la version actuellement installée sur votre appareil depuis la console OVHcloud.

{/* CP-STEPS-START:consulter-version */}

Sélectionnez le service OverTheBox que vous souhaitez mettre à jour, puis cliquez sur l'onglet <code className="action">Équipement</code>.

Dans la section **Caractéristiques**, la ligne **Version du système d'exploitation** indique la version actuellement installée sur votre appareil. Elle est basée sur les tags du [dépôt git overthebox](https://github.com/ovh/overthebox/tags).

<img className="thumbnail" alt="Onglet Équipement d'une OverTheBox, ligne Version du système d'exploitation de la section Caractéristiques" src="/images/web-cloud/internet/overthebox/config-upgrade/console/equipment-os-version.png" loading="lazy" />

{/* CP-STEPS-END:consulter-version */}

### Vérifier si une mise à jour est disponible

{/* CP-STEPS-START:verifier-mise-a-jour */}

Sélectionnez le service OverTheBox que vous souhaitez mettre à jour, puis cliquez sur l'onglet <code className="action">Équipement</code>.

Si une mise à jour est disponible, une bannière **Une nouvelle version est disponible** s'affiche en haut de l'onglet.

<img className="thumbnail" alt="Bannière Une nouvelle version est disponible en haut de l'onglet Équipement d'une OverTheBox" src="/images/web-cloud/internet/overthebox/config-upgrade/console/equipment-update-available-banner.png" loading="lazy" />

{/* CP-STEPS-END:verifier-mise-a-jour */}

### Mise à jour via la console OVHcloud

:::warning
Cette action n'est possible que si votre appareil contacte notre serveur de provisioning. Si ce n'est pas le cas, vous devez [installer manuellement l'image](/guides/web-cloud/internet/overthebox/advanced-installer-limage-overthebox-sur-votre-materiel).

:::


{/* CP-STEPS-START:mise-a-jour-espace-client */}

Sélectionnez le service OverTheBox que vous souhaitez mettre à jour, puis cliquez sur l'onglet <code className="action">Équipement</code>.

Dans la bannière **Une nouvelle version est disponible**, cliquez sur <code className="action">Mettre à jour</code>. Dans la fenêtre **Mise à jour du système d'exploitation** qui s'ouvre, cliquez de nouveau sur <code className="action">Mettre à jour</code> pour confirmer : la mise à jour commence alors.

<img className="thumbnail" alt="Fenêtre Mise à jour du système d'exploitation ouverte depuis la bannière de l'onglet Équipement d'une OverTheBox" src="/images/web-cloud/internet/overthebox/config-upgrade/console/equipment-update-confirmation.png" loading="lazy" />

L'appareil est temporairement indisponible pendant la mise à jour. Attendez quelques minutes afin que l'appareil **OverTheBox** soit de nouveau opérationnel.

{/* CP-STEPS-END:mise-a-jour-espace-client */}

:::tip
Votre appareil OverTheBox est maintenant mis à jour, votre configuration a été réappliquée automatiquement.

:::


### Modifier le canal de version

:::warning
Pour un appareil avec un unique port ethernet RJ45 (comme un NUC Intel), seul le canal `v0.8_deprecated` est compatible

:::


Par défaut, un appareil OverTheBox est sur le canal `stable` qui contient la dernière version logicielle stable. Ce canal est recommandé, vous pourrez ainsi profiter des dernières fonctionnalités.

D'autres canaux sont disponibles :

- Le canal `beta` permet de tester la prochaine version du logiciel avant le déploiement sur le canal `stable`.
- Les canaux de versions, comme `v0.9`, `v1.0`, permettent de maintenir votre matériel sur une version majeure précise. Seules des mises à jour mineures, telles que des correctifs, seront proposées.

{/* CP-STEPS-START:modifier-canal-version */}

Sélectionnez le service OverTheBox que vous souhaitez modifier.

Dans la section **Informations générales**, cliquez sur <code className="action">Mettre à jour</code> à côté de la ligne **Version**. Dans la fenêtre **Mettre à jour la version**, sélectionnez le canal souhaité dans le menu déroulant **Canal de release**, puis cliquez sur <code className="action">Mettre à jour</code>.

<img className="thumbnail" alt="Fenêtre Mettre à jour la version d'une OverTheBox, menu déroulant Canal de release ouvert" src="/images/web-cloud/internet/overthebox/config-upgrade/console/overview-update-version-release-channel.png" loading="lazy" />

{/* CP-STEPS-END:modifier-canal-version */}

### Désactiver les mises à jour automatiques

Par défaut, un appareil OverTheBox est mis à jour automatiquement la nuit si une nouvelle version du logiciel est disponible. Vous pouvez désactiver cette fonctionnalité depuis la console OVHcloud.

{/* CP-STEPS-START:desactiver-mises-a-jour-auto */}

Sélectionnez le service OverTheBox que vous souhaitez modifier, puis cliquez sur l'onglet <code className="action">Équipement</code>.

Dans la section **Caractéristiques**, activez ou désactivez les mises à jour automatiques à l'aide de l'interrupteur **Mises à jour automatiques**.

<img className="thumbnail" alt="Interrupteur Mises à jour automatiques de la section Caractéristiques, onglet Équipement d'une OverTheBox" src="/images/web-cloud/internet/overthebox/config-upgrade/console/equipment-automatic-updates-switch.png" loading="lazy" />

{/* CP-STEPS-END:desactiver-mises-a-jour-auto */}

### Voir les différences entre versions

L'OverTheBox est un projet open-source hébergé sur la plateforme GitHub. Le code est librement accessible et vous permet de consulter concrètement ce qui change entre chaque version.

Le code est séparé sur trois dépôts git distincts :

- [overthebox-lede](https://github.com/ovh/overthebox-lede) contient les sources du système [openwrt](https://openwrt.org/) utilisé comme base pour le système d'exploitation d'OverTheBox.
- [overthebox-feeds](https://github.com/ovh/overthebox-feeds) contient les sources des différents paquets modifiés ou ajoutés pour améliorer le logiciel d'OverTheBox.
- [overthebox](https://github.com/ovh/overthebox) contient les sources qui permettent de construire l'image logicielle d'OverTheBox.

L'ensemble des modifications est consultable ici :

- [Changelog en Anglais](https://github.com/ovh/overthebox/releases).
- [Changelog en Français](https://github.com/ovh/overthebox/blob/master/CHANGELOG_fr.md).

## Aller plus loin

### Impossible de se connecter à l'OverTheBox après une mise à jour

Il est recommandé d'attendre environ dix minutes après le lancement de la mise à jour de l'OverTheBox avant de s'y connecter.
En effectuant une mise à jour ou une réinitialisation, les baux DHCP précédemment alloués aux appareils du LAN ne sont plus considérés comme étant émis par l'OverTheBox, cela peut potentiellement induire des problèmes pour les équipements du LAN.

Dans ce cas, les recommandations sont les suivantes :

- Débranchez le câble réseau entre l'ordinateur et l'OverTheBox puis rebranchez-le au bout d'environ une minute.
- Redémarrez les services réseau sur l'ordinateur.
- Redémarrez l'ordinateur pour le « forcer » à oublier l'ancien lease DHCP.
- Si aucune des étapes précédentes ne fonctionne, débranchez électriquement l'OverTheBox pendant environ une minute puis rebranchez-la.

### Revenir sur une version antérieure

Il n'est pas possible de revenir sur une version antérieure depuis la console OVHcloud, car cela nécessite une réinitialisation de la configuration de l'**OverTheBox**.
Il est toutefois possible de revenir sur une version antérieure depuis l'interface web locale, consultez la section `Mise à jour depuis l'interface web locale` du guide « [Installer l’image OverTheBox sur votre matériel](/guides/web-cloud/internet/overthebox/advanced-installer-limage-overthebox-sur-votre-materiel) ».
