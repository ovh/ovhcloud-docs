## Objectif

Le RACI ci-dessous détaille les responsabilités partagées entre OVHcloud et le client pour le service Noms de domaine. Ce modèle de partage permet d'alléger la charge opérationnelle du client.

| Rôles |
| --- |
| R : Est chargé de réaliser le processus |
| A : Est responsable du bon achèvement du processus |
| C : Est consulté pendant le processus |
| I : Est informé des résultats du processus |

### 1. Avant la souscription

#### 1.1. Spécifier le service selon les besoins

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
| Choisir le nom du service | RA |  |
| Définir la liste des TLD que vous souhaitez couvrir avec le nom | RA |  |
| Définir les noms de domaine proches que vous souhaitez protéger contre les utilisations malveillantes | RA |  |

### 2. Disponibilité du service

#### 2.1. Installer le service

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
| Vérifier la disponibilité des domaines souhaités | RA |  |
| Déposer la marque de votre service si nécessaire | RA |  |
| Enregistrer le domaine | I | RA |
| Générer l'interface client permettant de gérer sa zone DNS | I | RA |

#### 2.2. Modèle de réversibilité

Les noms de domaine sont entièrement réversibles par conception. Les zones DNS peuvent être sauvegardées dans des fichiers txt et déployées sur n'importe quel nouveau serveur DNS.

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
| Connaître les services qui dépendent de certains enregistrements DNS | RA |  |

#### 2.3. Configuration du système d'information du client

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
| Déployer la configuration sur la zone DNS en totale autonomie | RA |  |
| Déployer la configuration sur la zone DNS à l'aide des outils d'automatisation OVHcloud | RI | AI |

### 4. Réversibilité

#### 4.1. Modèle de réversibilité

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
| Documenter les services qui dépendent de certains enregistrements DNS | RA |  |
| Planifier la migration de la zone DNS conformément aux exigences de sécurité des services dépendant du DNS | RA |  |

#### 4.2. Récupération des données

| **Activité** | **Client** | **OVHcloud** |
| --- | --- | --- |
