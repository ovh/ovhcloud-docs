## Objectif

Le WHOIS, abréviation de l’anglais « Who is ? », est un protocole permettant d’accéder à différentes informations liées à un nom de domaine.

Par exemple, vous pouvez y trouver les informations suivantes (liste non exhaustive) :

- Coordonnées du titulaire (souscripteur), de l’administrateur et du contact technique du service.
- Indication de la disponibilité à l’achat.
- Dates de création, d’expiration, de dernière modification et de renouvellement.
- Statut (créé, bloqué, expiré, etc.).
- etc.

Au cours de l’utilisation de votre nom de domaine, vous pouvez être amené à devoir afficher ou masquer certaines informations présentes dans le WHOIS.

**Découvrez comment afficher ou masquer certaines informations contenues dans le WHOIS d’un nom de domaine depuis la console OVHcloud.**

## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains).

[[cpnav:web-domains]]

:::warning
Certains registres (organismes gérant les extensions des noms de domaine tels que *.com*, *.net*, etc.) n’autorisent pas à forcer le masquage ou l’affichage de certaines informations présentes dans le WHOIS.
En effet, ce sont les registres qui définissent les règles d’affichage et déterminent les informations que doit ou ne doit pas contenir le WHOIS de l’extension qu’ils gèrent.

Par conséquent, il est possible que malgré vos souhaits en termes d’affichage ou de masquage dans le WHOIS de votre nom de domaine, votre demande ne soit pas prise en compte.

:::

## En pratique

{/* CP-STEPS-START:configurer-whois */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné. L’onglet <code className="action">Vue d’ensemble</code> du nom de domaine s’affiche.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans la section **Contacts** de l’onglet <code className="action">Vue d’ensemble</code>, la ligne **Protection RDDS** indique l’état de la protection des données de votre nom de domaine dans le WHOIS. Cliquez sur <code className="action">Gérer la protection RDDS</code>.

    Si le registre gérant l’extension de votre nom de domaine impose l’affichage des informations, la ligne **Protection RDDS** indique **Désactivée**, avec le message « Le registre gérant cette extension n’autorise pas la gestion personnalisée de l’affichage des données en WHOIS/RDAP. » : le bouton <code className="action">Gérer la protection RDDS</code> n’apparaît pas et ce réglage ne peut pas être modifié.

    <img className="thumbnail" alt="Section Contacts de l’onglet Vue d’ensemble et ligne Protection RDDS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/data-protection-entry.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le panneau **Configurer la protection RDDS (WHOIS/RDAP)** qui s’ouvre, choisissez pour chaque contact proposé (titulaire, administrateur, technique, etc.) d’afficher ou de masquer ses informations dans le WHOIS, dans la limite des actions autorisées par le registre gestionnaire de l’extension :

    - **Case cochée** : les informations du contact sont affichées dans le WHOIS.
    - **Case décochée** : les informations du contact sont masquées (anonymisées avec la mention « REDACTED »).

    <img className="thumbnail" alt="Panneau Configurer la protection RDDS et contacts visibles dans le WHOIS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/data-protection-drawer.png" loading="lazy" />

    Les contacts proposés dépendent de l’extension de votre nom de domaine.

    Une fois vos choix effectués, cliquez sur le bouton <code className="action">Valider</code>.

    La prise en compte des modifications peut nécessiter jusqu’à **48** heures. Ces modifications seront appliquées **uniquement si elles sont autorisées par le registre gérant l’extension de votre nom de domaine**.
  </Tab>
</Tabs>

{/* CP-STEPS-END:configurer-whois */}
