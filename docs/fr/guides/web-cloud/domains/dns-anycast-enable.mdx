## Objectif 

Vous avez besoin que vos services (par exemple : votre site web) soient accessibles en un temps record sur l’ensemble du globe ? Vous souhaitez que la résolution DNS de votre nom de domaine soit optimisée ?
OVHcloud vous propose l’option [DNS Anycast](/links/web/domains-options-anycast).

**Découvrez comment accélérer l’accès à vos services web grâce à la vitesse de résolution DNS offerte par l’option DNS Anycast de votre nom de domaine.**

## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains).
- Le nom de domaine concerné doit posséder une extension compatible avec l’option DNS Anycast.

[[cpnav:web-domains]]

## En pratique

{/* CP-STEPS-START:activer-anycast */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné. L’onglet <code className="action">Vue d’ensemble</code> du nom de domaine s’affiche.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans la section **Serveurs DNS** de l’onglet <code className="action">Vue d’ensemble</code>, repérez l’encart **DNS Anycast**, qui présente les avantages et le prix de l’option. Cliquez sur le bouton <code className="action">Commander</code>.

    <img className="thumbnail" alt="Section Serveurs DNS de l’onglet Vue d’ensemble et encart de commande DNS Anycast" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/anycast-offer.png" loading="lazy" />

    :::info
    Le bouton <code className="action">Commander</code> est grisé si votre nom de domaine utilise des serveurs DNS externes : configurez d’abord votre nom de domaine sur les serveurs DNS OVHcloud. Si votre nom de domaine n’a pas de zone DNS OVHcloud, l’encart propose à la place le bouton <code className="action">Activer ma zone DNS</code>.

    :::
  </Tab>
  <Tab label="Étape 3">
    La page **Commander un DNS Anycast** s’affiche. Aucune durée n’est à choisir : comme l’indique la section **Engagement**, l’option DNS Anycast expire à la même date que votre zone DNS et son prix est calculé au prorata de la durée restante.

    <img className="thumbnail" alt="Page de commande de l’option DNS Anycast et récapitulatif de la commande" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/anycast-order.png" loading="lazy" />

    Dans le récapitulatif, cliquez sur <code className="action">Continuer la commande</code>. La page de commande s’ouvre, par défaut dans un nouvel onglet : poursuivez jusqu’à la validation de la commande à l’aide d’un moyen de paiement pour finaliser sa prise en compte.
  </Tab>
</Tabs>

{/* CP-STEPS-END:activer-anycast */}

L’activation de l’option DNS Anycast peut prendre plusieurs minutes.
