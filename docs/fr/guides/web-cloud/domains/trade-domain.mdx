## Objectif

En dehors de la [gestion des contacts](/guides/account-and-service-management/account-information/managing-contacts), l’enregistrement d’un nom de domaine nécessite de renseigner les informations relatives au titulaire de celui-ci. Dans ce contexte, le **titulaire** (parfois appelé « propriétaire ») désigne une personne, une société, une organisation ou encore une association détenant les droits sur ce nom de domaine. **Le changement de titulaire** fait référence au transfert des droits d’utilisation d’une personne ou entreprise vers une autre. Les informations du **titulaire** ont une valeur juridique. Ce processus est notamment obligatoire si une société change de nom.

:::info
Cette opération ne déplace pas votre nom de domaine vers un autre compte client OVHcloud.

Pour obtenir ce résultat, vous devez [modifier les contacts](/guides/account-and-service-management/account-information/managing-contacts) du nom de domaine.

Si vous devez réaliser un changement de titulaire ainsi qu’un changement de contact pour le même nom de domaine, il est fortement recommandé d’effectuer **d’abord** le changement de titulaire afin d’assurer une transition optimale. Cependant, c’est le contact administrateur qui est en mesure de lancer ces opérations. Ces deux changements se font, par conséquent, depuis le compte OVHcloud du contact administrateur du nom de domaine.

En effet, les informations relatives au titulaire d’un nom de domaine n’ont qu’une valeur administrative et sont totalement indépendantes des informations pouvant être associées à un identifiant client OVHcloud. Par conséquent, un particulier ou une organisation (société, association, etc.) uniquement déclaré en tant que titulaire d’un nom de domaine n’a donc pas accès au compte OVHcloud.

:::

**Découvrez comment changer le titulaire d’un nom de domaine ou mettre à jour les informations qui lui sont associées.**

## Prérequis

- Disposer d’un nom de domaine enregistré chez OVHcloud et pour lequel aucune opération (changement de titulaire, transfert, création) n’est en cours. Si une opération a été finalisée récemment sur votre nom de domaine, un délai d’au moins 60 jours calendaires est nécessaire avant de réaliser une nouvelle opération.
- Votre compte client est le [contact administrateur et de facturation](/guides/account-and-service-management/account-information/managing-contacts) du nom de domaine concerné.
- Disposer de l’accord du titulaire actuel du nom de domaine pour effectuer le changement de titulaire.

## En pratique

:::warning
Les instructions suivantes décrivent le moyen le plus courant de modifier le titulaire d’un nom de domaine. Elles sont valides pour la plupart des noms de domaine de niveau supérieur, communément appelés **T**op **L**evel **D**omain (**TLD**).

Les **TLD** désignent la fin de votre nom de domaine, comme par exemple le *.com*, *.net*, *.fr*, etc.

Les règles spécifiques des processus concernant les noms de domaine **TLD** sont uniquement définies par l’autorité d’allocation appropriée, c’est-à-dire le **registre**. Un bureau d’enregistrement (ou registrar) tel que OVHcloud doit respecter ces règles et n’a aucune influence sur les décisions d’enregistrement.

Il existe principalement deux types de **TLD** : Les **ccTLD** et les **gTLD**. Les **ccTLD** correspondent à des **TLD** relatifs à une région ou un pays (*.fr*, *.be*, *.uk*, *.de*, *.paris*, etc.). Les **gTLD** correspondant à des **TLD** plus génériques (*.net*, *.com*, *.info*, *.org*, etc.).

La procédure exacte pour le changement de titulaire d’un nom de domaine peut donc varier, en particulier pour certains **ccTLD** (*.lu*, *.hk*, *.ro*, *.be*, *.lt*, *.dk*, *.at*, *.fi*, etc.) et pour quelques **TLD** spéciaux (*.am*, *.fm*, etc.). Pour certains d’entre eux, un changement de titulaire est une opération payante. Le changement de titulaire peut également être suspendu pour diverses raisons, par exemple pour un impayé, un abus ou un blocage de la part du registre.

Nous vous recommandons de consulter les ressources suivantes en cas de doute :

- Le site Web du registre **TLD** correspondant ;
- La [liste des TLD disponibles sur le site OVHcloud](/links/web/domains-tld) ;
- Les mises à jour d’état du nom de domaine. Pour vérifier cela, rendez-vous sur la page <ManagerLink to="/beta/#/web-cloud/domains/operations">Opérations en cours</ManagerLink>.

:::

### Lancer la procédure de changement de titulaire ou modifier les informations qui lui sont associées <a name="holder-change-steps"></a>

{/* CP-STEPS-START:changer-titulaire */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné. L’onglet <code className="action">Vue d’ensemble</code> du nom de domaine s’affiche.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans la section **Contacts**, cliquez sur <code className="action">Modifier</code> sous la mention **Propriétaire**.

    <img className="thumbnail" alt="Section Contacts de la Vue d’ensemble et lien Modifier sous Propriétaire" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/contacts-owner.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Le panneau **Modifier le titulaire** s’affiche.

    :::warning
    Toute modification apportée au prénom, au nom, à l’organisation, au statut légal ou à l’adresse e-mail du titulaire est considérée comme un **changement de titulaire**. Dans le panneau, ces champs sont verrouillés (icône de cadenas) ; selon l’extension, d’autres champs, comme le pays, peuvent l’être également.

    Si vous modifiez **uniquement** des coordonnées du titulaire autres que celles mentionnées ci-dessus, faites vos modifications directement, puis cliquez sur <code className="action">Enregistrer</code>. Dans ce cas précis, il ne sera pas nécessaire de lancer une demande de changement de titulaire. Pour cette opération, vous n’avez pas besoin de confirmer les modifications par e-mail.

    Le cas échéant et pour initier la demande de changement de titulaire, cliquez sur le lien <code className="action">procédure de changement de titulaire</code> situé en haut du panneau.

    :::

    <img className="thumbnail" alt="Panneau Modifier le titulaire et champs verrouillés" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/edit-holder-drawer.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Un nouvel onglet de votre navigateur s’ouvre avec tous les noms de domaine éligibles au changement de titulaire. Sélectionnez un nom de domaine dans la liste en cochant la case située à gauche. Cette étape peut également être utilisée pour lancer une opération groupée. Ainsi, il est possible d’initier un changement de titulaire pour plusieurs noms de domaine à la fois, par exemple pour changer le titulaire de tous les noms de domaine *.ovh* si leurs titulaires actuels sont identiques.

    <img className="thumbnail" alt="Change owner domains list" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/general-information/available-domains.png" loading="lazy" />

    Une fois vos choix effectués, cliquez sur <code className="action">Continuer</code>.
  </Tab>
  <Tab label="Étape 5">
    Dans le formulaire des détails du titulaire, veillez à entrer des informations valides dans tous les champs obligatoires. Soyez vigilant sur les erreurs de saisie et utilisez des [caractères imprimables ASCII](http://facweb.cs.depaul.edu/sjost/it212/documents/ascii-pr.htm) dans la mesure du possible. Veuillez noter que toute information inexacte ou fausse peut entraîner une erreur technique et donc un retard de l’ensemble du processus.

    Une fois que vous avez confirmé votre demande, deux e-mails vous seront envoyés pour confirmer ou annuler celle-ci :

    - un e-mail envoyé au titulaire actuel ;
    - un e-mail envoyé au futur titulaire.

    Si l’adresse e-mail n’est pas modifiée dans le cadre du changement de titulaire, l’adresse e-mail de référence recevra les deux e-mails, mais chacun de ces deux e-mails doit faire l’objet d’une confirmation.

    Une fois que les deux destinataires ont confirmé la demande par e-mail, le changement de titulaire du nom de domaine prendra effet.

    Pour savoir comment confirmer ou refuser la demande à partir de l’e-mail que vous recevez, consultez [Confirmer un changement de titulaire ou un transfert sortant](/guides/web-cloud/domains/confirm-holder-change-or-transfer).
  </Tab>
</Tabs>

{/* CP-STEPS-END:changer-titulaire */}

:::warning
- La procédure doit être validée par les deux parties dans les 14 jours qui suivent la demande. **Passé ce délai, la procédure est annulée**.

- Si la modification est refusée par l’une des deux parties, la demande est annulée.

- Si l’adresse e-mail du titulaire actuel est obsolète ou inaccessible, vous pouvez valider le changement [en tant qu’agent désigné](/guides/web-cloud/domains/confirm-holder-change-or-transfer#designated-agent) si l’extension le permet (principalement les gTLD). Pour les autres extensions, et dans ce cas précis uniquement, contactez le support en créant un ticket d’assistance depuis votre [centre d’aide OVHcloud](/links/support-contact).

- Si le titulaire du nom de domaine a été modifié, le nom de domaine ne pourra pas être [transféré vers un autre bureau d’enregistrement](/guides/web-cloud/domains/transfer-outgoing-domain) pendant une période de 60 jours.

:::

### Récupérer un nom de domaine après le rachat d’une entreprise <a name="company-acquisition"></a>

Le rachat d’une entreprise ne vous donne pas automatiquement la propriété ni la gestion de ses noms de domaine. Deux opérations distinctes sont nécessaires :

- le **changement de titulaire**, décrit dans ce guide, qui transfère la propriété du nom de domaine à votre entreprise ;
- le **changement de contacts**, qui déplace la gestion du nom de domaine vers votre compte client OVHcloud. Consultez notre guide « [Gérer les contacts de ses services](/guides/account-and-service-management/account-information/managing-contacts) ».

La marche à suivre dépend de votre situation.

**Le gestionnaire actuel du nom de domaine coopère :**

1. Le contact administrateur actuel du nom de domaine lance le changement de titulaire depuis son espace client, en suivant les [étapes de changement de titulaire](#holder-change-steps).
2. L’ancien et le nouveau titulaire valident chacun l’e-mail de confirmation qu’ils reçoivent.
3. Le contact administrateur actuel effectue ensuite le changement de contacts vers votre identifiant client (contact administrateur et de facturation). Les deux parties valident la demande.

**Vous ne pouvez pas joindre le gestionnaire actuel, mais vous pouvez fournir les justificatifs du titulaire actuel :**

Dans ce cas, l’ordre recommandé plus haut est inversé, car seul le contact administrateur peut lancer le changement de titulaire.

1. Lancez la [procédure de changement de contacts](/guides/account-and-service-management/account-information/managing-contacts#procedures) « Modifier les contacts de votre nom de domaine » pour déplacer le nom de domaine vers votre compte client (contact administrateur et de facturation). Les justificatifs à fournir vous sont indiqués au cours de la procédure.
2. Une fois le nom de domaine dans votre compte, lancez le changement de titulaire en suivant les [étapes de changement de titulaire](#holder-change-steps).
3. Si l’extension le permet (principalement les gTLD), validez le changement de titulaire [en tant qu’agent désigné](/guides/web-cloud/domains/confirm-holder-change-or-transfer#designated-agent). Pour les autres extensions, si le titulaire actuel ne peut pas valider l’e-mail de confirmation, contactez le support en créant un ticket d’assistance depuis votre [centre d’aide OVHcloud](/links/support-contact).
