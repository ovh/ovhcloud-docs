## Objectif

La zone **D**omain **N**ame **S**ystem (**DNS**) d’un nom de domaine constitue le fichier de configuration de ce dernier. Elle se compose d’informations techniques, appelées *enregistrements DNS*. La zone DNS est, en quelque sorte, comme un centre d’aiguillage.

Pour plus d’explications, consultez nos guides suivants :

- [Tout savoir sur les serveurs DNS](/guides/web-cloud/domains/dns-server-general-information)
- [Tout savoir sur la zone DNS](/guides/web-cloud/domains/dns-zone-general-information)
- [Tout savoir sur les enregistrements DNS](/guides/web-cloud/domains/dns-zone-records)

Pour diverses raisons, vous pouvez être amené à créer une zone DNS pour votre nom de domaine chez OVHcloud.

**Découvrez comment créer une zone DNS chez OVHcloud pour votre nom de domaine via la console OVHcloud.**

## Prérequis

- Disposer d’un nom de domaine.
- Le nom de domaine concerné ne doit pas déjà disposer d’une zone DNS (active ou non) chez OVHcloud ou faire l’objet d’une opération ou d’une commande en cours chez OVHcloud.

[[cpnav:web-dns-zone-order]]

## En pratique

:::warning
Vous pouvez créer plusieurs zones DNS (chez différents fournisseurs/prestataires/hébergeur DNS) pour un même nom de domaine. Cependant, vous ne pouvez avoir qu’une seule zone DNS active pour votre nom de domaine. Cette restriction vise à éviter les *conflits DNS*.

L’activation/désactivation d’une zone DNS se fait à partir de la déclaration des **serveurs DNS** auprès de votre nom de domaine. Vous pouvez modifier cette déclaration et changer les **serveurs DNS** d’un nom de domaine auprès : 

- du *bureau d’enregistrement* où vous avez directement enregistré votre nom de domaine ;
- du prestataire qui le gère si vous passez par un prestataire spécialisé pour gérer votre nom de domaine.

En modifiant les **serveurs DNS** d’un nom de domaine, vous désactivez la configuration de l’ancienne zone DNS appliquée au profit de la configuration de la nouvelle zone DNS (présente sur les nouveaux **serveurs DNS** déclarés).

Par conséquent, vérifiez bien, avant de changer les **serveurs DNS** déclarés auprès de votre nom de domaine, que la configuration de la nouvelle zone DNS correspond bien à vos attentes.

:::

### 1 - Créer la zone DNS via la console OVHcloud

{/* CP-STEPS-START:creer-zone */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis cliquez sur le bouton <code className="action">Commander un domaine ou une zone DNS</code>. Dans la tuile **Zone DNS standalone**, cliquez sur <code className="action">Commander</code>.

    <img className="thumbnail" alt="Page de commande d’un nom de domaine ou d’une zone DNS et tuile Zone DNS standalone" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-choice.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sur la page **Commander une zone DNS** qui apparaît, renseignez dans le champ **Nom de domaine** le nom de domaine (par exemple : *domain.tld*) pour lequel vous souhaitez créer une zone DNS OVHcloud. Patientez quelques instants le temps que l’outil effectue des vérifications concernant le nom de domaine.

    Si un message indique que la zone DNS ne peut pas être créée (par exemple, « Une zone DNS existe déjà pour domain.tld. »), vérifiez que le nom de domaine respecte les prérequis nécessaires ou contactez la personne qui le gère. Dès que tout est correct, tentez de nouveau la manipulation.

    <img className="thumbnail" alt="Message indiquant qu’une zone DNS existe déjà pour le nom saisi" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-exists.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Une fois la vérification terminée, la section **Choisissez vos options** s’affiche. Cochez si besoin l’option **DNS Anycast** (payante). Le récapitulatif, à droite de la page, indique le contenu et le total de votre commande.

    <img className="thumbnail" alt="Options de la commande d’une zone DNS et récapitulatif de la commande" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-domain.png" loading="lazy" />

    Cliquez sur <code className="action">Continuer la commande</code>, puis suivez les étapes affichées jusqu’à la création de la zone DNS.

    :::info
    Le choix des entrées minimales ne se fait plus lors de la commande. Si vous souhaitez personnaliser vous-même la zone DNS en partant des seules entrées minimales (enregistrements NS et SOA), réinitialisez-la une fois créée : dans l’onglet <code className="action">Zone DNS</code>, ouvrez le menu <code className="action">Actions supplémentaires</code> de la carte **Zone DNS**, cliquez sur <code className="action">Réinitialiser la zone</code> et choisissez <code className="action">Oui — entrées minimales uniquement</code>. Consultez notre guide « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) ».

    :::
  </Tab>
</Tabs>

{/* CP-STEPS-END:creer-zone */}

### 2 - Éditer la zone DNS (facultatif)

La zone DNS pour votre nom de domaine étant maintenant créée, vous pouvez l’éditer. Cette manipulation est facultative, mais elle peut se révéler nécessaire si vous souhaitez assurer la continuité de la disponibilité des services liés à ce nom de domaine (comme un site web et/ou des e-mails).

Pour éditer cette zone DNS, consultez notre guide « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) ».

:::info
Si vous venez juste de créer la zone DNS et que le nom de domaine n’apparaît pas encore dans la liste de vos services, patientez 15 à 20 minutes puis rechargez la page.

:::

### 3 - Modifier les serveurs DNS du nom de domaine

{/* CP-STEPS-START:recuperer-ns */}

Une fois que la zone DNS chez OVHcloud est prête à être utilisée, activez-la en déclarant les serveurs DNS correspondants. Récupérez d’abord le nom des **serveurs DNS** OVHcloud sur lesquels la zone DNS de votre nom de domaine a été créée.

Pour les retrouver, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné. Cliquez ensuite sur l’onglet <code className="action">Zone DNS</code>.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans le tableau qui s’affiche, repérez les colonnes **Type** et **Cible**. Pour n’afficher que les enregistrements utiles, cliquez sur <code className="action">Filtres</code>, puis sélectionnez <code className="action">NS</code> dans la liste **Type d’enregistrement**.

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements NS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-ns.png" loading="lazy" />

    Récupérez les 2 valeurs présentes dans la colonne **Cible**. Les noms des serveurs DNS doivent avoir l’une des 3 formes suivantes :

    - `nsXX.ovh.net` et `dnsXX.ovh.net` ou, `nsXXX.ovh.net` et `dnsXXX.ovh.net` (où chaque `X` représente un chiffre compris entre **0** et **9**).
    - `nsXX.ovh.ca` et `dnsXX.ovh.ca` ou, `nsXXX.ovh.ca` et `dnsXXX.ovh.ca` (où chaque `X` représente un chiffre compris entre **0** et **9**).
    - `ns200.anycast.me` et `dns200.anycast.me` (si vous avez souscrit à l’option [DNS anycast](/links/web/domains-options)).
  </Tab>
</Tabs>

{/* CP-STEPS-END:recuperer-ns */}

Une fois les 2 noms de serveur DNS récupérés, 2 situations sont possibles.

:::info
Pour rappel, vérifiez bien, avant de changer les **serveurs DNS** déclarés auprès de votre nom de domaine, que la configuration de la nouvelle zone DNS correspond bien à vos attentes.

:::

**Cliquez sur l’une des 2 situations pour afficher le contenu.**

<details>

<summary>Le nom de domaine a sa zone DNS active chez OVHcloud</summary>

Consultez [ce guide](/guides/web-cloud/domains/dns-server-edit) pour vérifier ou modifier les serveurs DNS déclarés pour votre nom de domaine.

</details>

<details>

<summary>Le nom de domaine a sa zone DNS active chez un autre fournisseur</summary>

Dans ce cas précis, contactez votre fournisseur DNS en lui précisant que vous souhaitez remplacer les enregistrements DNS de type NS de votre nom de domaine.

Voici un exemple de demande à formuler auprès de votre fournisseur DNS :

<pre className="bgwhite"><code>
Bonjour,

Pour mon nom de domaine <b>domain.tld</b>, je souhaite remplacer les serveurs DNS actuels par les serveurs DNS suivants :

 - nsXX.ovh.net.
 - dnsXX.ovh.net.

Cordialement,
</code></pre>

Dans l’exemple ci-dessus, remplacez les valeurs **domain.tld**, **nsXX.ovh.net** et **dnsXX.ovh.net** par vos propres valeurs.

</details>

Après modification des serveurs DNS du nom de domaine, la propagation des modifications peut prendre jusqu’à **48 heures**.

:::tip
Si vous souhaitez personnaliser les noms des serveurs DNS associés à la zone DNS active de votre nom de domaine, consultez notre guide « [Personnaliser les serveurs DNS d’un nom de domaine (Glue Records)](/guides/web-cloud/domains/glue-registry) ».

:::
