## Objectif

Vous devez valider un processus de vérification ou de sécurité pour votre nom de domaine (association de services via un token de validation, clé de vérification, etc.) en utilisant votre zone DNS ? Vous souhaitez ajouter une valeur personnalisée au format texte dans la zone DNS de votre nom de domaine ?
Pour cela, vous devrez créer un enregistrement DNS de type TXT dans la zone DNS active de votre nom de domaine.

**Découvrez comment ajouter un enregistrement DNS de type TXT dans une zone DNS OVHcloud pour votre nom de domaine.**

:::info
Pour modifier ou supprimer un enregistrement DNS de type TXT d’une zone DNS OVHcloud, suivez notre guide « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) ».

:::

## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains).
- Disposer d’une zone DNS associée à ce nom de domaine chez OVHcloud.

[[cpnav:web-domain-dns-zone]]

## En pratique

:::warning
L’ajout, la modification ou la suppression d’enregistrements DNS dans une zone DNS active est une manipulation sensible. En cas de doute, contactez un [prestataire spécialisé](/links/partner).

:::

### Ajouter un enregistrement DNS de type TXT pour un nom de domaine

{/* CP-STEPS-START:ajout-domaine */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Zone DNS</code>, puis, au-dessus du tableau, sur <code className="action">Ajouter une entrée</code>.

    <img className="thumbnail" alt="Onglet Zone DNS d’un nom de domaine et bouton Ajouter une entrée" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le formulaire qui s’ouvre au-dessus du tableau, ouvrez la liste **Type** et faites-la défiler jusqu’à la section **Champs étendus**, puis sélectionnez `TXT — Texte libre (vérification, SPF…)`.

    <img className="thumbnail" alt="Liste Type du formulaire Ajouter une entrée, section Champs étendus et type TXT" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-txt.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Dans le champ **Sous-domaine**, saisissez `@` : ce symbole désigne le nom de domaine lui-même. Dans le champ **Valeur**, renseignez la chaîne TXT à ajouter (par exemple : `AbCdE-Value-of-TXT-fGhIjK`).

    <img className="thumbnail" alt="Formulaire Ajouter une entrée de la zone DNS, enregistrement TXT pour le nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-txt-record.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 5">
    Vérifiez l’**Aperçu de l’enregistrement**, puis cliquez sur <code className="action">Ajouter</code>.
  </Tab>
</Tabs>

{/* CP-STEPS-END:ajout-domaine */}

Patientez jusqu’à **24** heures pour que la propagation de l’ajout sur le réseau DNS soit pleinement effective.

### Ajouter un enregistrement DNS de type TXT pour le sous-domaine d’un nom de domaine

{/* CP-STEPS-START:ajout-sous-domaine */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Zone DNS</code>, puis, au-dessus du tableau, sur <code className="action">Ajouter une entrée</code>.

    <img className="thumbnail" alt="Onglet Zone DNS d’un nom de domaine et bouton Ajouter une entrée" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le formulaire qui s’ouvre au-dessus du tableau, ouvrez la liste **Type** et faites-la défiler jusqu’à la section **Champs étendus**, puis sélectionnez `TXT — Texte libre (vérification, SPF…)`.

    <img className="thumbnail" alt="Liste Type du formulaire Ajouter une entrée, section Champs étendus et type TXT" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-txt.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Dans le champ **Sous-domaine**, renseignez le sous-domaine concerné (par exemple : `www` pour `www.domain.tld`). Dans le champ **Valeur**, renseignez la chaîne TXT à ajouter (par exemple : `AbCdE-Value-of-TXT-fGhIjK`).

    <img className="thumbnail" alt="Formulaire Ajouter une entrée de la zone DNS, enregistrement TXT pour le sous-domaine www" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-txt-record-www.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 5">
    Vérifiez l’**Aperçu de l’enregistrement**, puis cliquez sur <code className="action">Ajouter</code>. Patientez jusqu’à **24** heures pour que la propagation de l’ajout sur le réseau DNS soit pleinement effective.
  </Tab>
</Tabs>
