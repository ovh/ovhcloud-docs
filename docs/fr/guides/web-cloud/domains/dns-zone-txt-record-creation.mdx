## Objectif

Vous devez valider un processus de vérification ou de sécurité pour votre nom de domaine (association de services via un token de validation, clé de vérification, etc.) en utilisant votre zone DNS ? Vous souhaitez ajouter une valeur personnalisée au format texte dans la zone DNS de votre nom de domaine ?
Pour cela, vous devrez créer un enregistrement DNS de type TXT dans la zone DNS active de votre nom de domaine.

**Découvrez comment ajouter un enregistrement DNS de type TXT dans une zone DNS OVHcloud pour votre nom de domaine.**

:::info
Pour modifier ou supprimer un enregistrement DNS de type TXT d’une zone DNS OVHcloud, suivez notre guide « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) ».

:::

## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains).
- Disposer d’une zone DNS associée à ce nom de domaine chez OVHcloud.

## En pratique

:::warning
L’ajout, la modification ou la suppression d’enregistrements DNS dans une zone DNS active est une manipulation sensible. En cas de doute, contactez un [prestataire spécialisé](/links/partner).

:::

### Ajouter un enregistrement DNS de type TXT pour un nom de domaine

Cliquez sur <code className="action">Ajouter une entrée</code> au-dessus du tableau et sélectionnez le type **TXT**. Dans le champ **Valeur**, renseignez la chaîne TXT à ajouter (par exemple : `AbCdE-Value-of-TXT-fGhIjK`), puis cliquez sur <code className="action">Ajouter</code>.

<img className="thumbnail" alt="Ajout d’un enregistrement TXT depuis la zone DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-txt-form.png" loading="lazy" />

Patientez jusqu’à **24** heures pour que la propagation de l’ajout sur le réseau DNS soit pleinement effective.

### Ajouter un enregistrement DNS de type TXT pour le sous-domaine d’un nom de domaine

Suivez les mêmes étapes que ci-dessus et, dans le champ **Sous-domaine**, renseignez le sous-domaine concerné (par exemple : `www` pour `www.domain.tld`) avant de renseigner la chaîne TXT dans le champ **Valeur** (par exemple : `AbCdE-Value-of-TXT-fGhIjK`). Cliquez ensuite sur <code className="action">Ajouter</code>.
