## Qu’est-ce qu’un nom de domaine ?

Un **nom de domaine** est l’adresse unique et lisible de votre présence en ligne : `mydomain.ovh`, par exemple. Il remplace l’adresse IP technique de vos serveurs par un nom facile à retenir et à partager, aussi bien pour un site web que pour vos adresses e-mail.

Un nom de domaine se compose de deux parties, lues de droite à gauche :

- l’**extension** (ou TLD, *Top-Level Domain*), le suffixe qui suit le dernier point : `.ovh`, `.com`, `.fr`… ;
- le **domaine** (le *label*), le nom que vous choisissez et réservez : `mydomain`.

Vous pouvez ensuite ajouter des **sous-domaines** devant votre domaine (`www.mydomain.ovh`, `blog.mydomain.ovh`) pour distinguer vos différents services.

Le nom de domaine est ainsi la **porte d’entrée** de votre présence en ligne : sans lui, vos visiteurs devraient retenir l’adresse IP technique de votre serveur pour accéder à votre site.

## Le cycle de vie d’un nom de domaine

De sa réservation à son renouvellement, un nom de domaine suit trois grandes étapes. À tout moment, vous pouvez aussi le transférer. Sélectionnez une étape pour accéder au guide de départ correspondant.

<DomainLifecycle />

### Enregistrer

Un nom de domaine s’obtient auprès d’un bureau d’enregistrement comme OVHcloud, pour une durée renouvelable. Vous pouvez réserver un nouveau domaine ou [transférer vers OVHcloud](/guides/web-cloud/domains/transfer-incoming-generic-domain) un domaine déjà enregistré ailleurs. La [FAQ sur les noms de domaine & DNS](/guides/web-cloud/domains/faq-domain-dns) répond aux questions les plus courantes.

### Configurer

Une fois le domaine enregistré, vous décidez de ce vers quoi il pointe : un site web, une adresse e-mail ou une [redirection](/guides/web-cloud/domains/redirect-domain-name). Tout cela repose sur sa [configuration DNS](/guides/web-cloud/domains/dns/landing-page-dns). Vous pouvez aussi [créer des sous-domaines](/guides/web-cloud/domains/domain-create-subdomains) (comme `blog.mydomain.ovh`) pour organiser vos différents services.

### Renouveler

Un nom de domaine est réservé pour une période définie : sans renouvellement, il expire et redevient disponible pour d’autres personnes. Activez le [renouvellement automatique](/guides/web-cloud/domains/autorenew-domain-name) pour ne jamais perdre votre adresse par simple oubli.

### Transférer

Vous restez libre de vos choix à tout moment : [transférez votre domaine vers OVHcloud](/guides/web-cloud/domains/transfer-incoming-generic-domain) depuis un autre bureau d’enregistrement, ou au contraire [transférez-le vers un autre registrar](/guides/web-cloud/domains/transfer-outgoing-domain).
