## Objectif

Le sigle **DNS**, signifiant **D**omain **N**ame **S**ystem, est un ensemble d’éléments (serveurs DNS, zones DNS, etc.) permettant de faire correspondre un nom de domaine avec une adresse IP.

Pour plus d’explications, consultez nos guides « [Tout savoir sur les serveurs DNS](/guides/web-cloud/domains/dns-server-general-information) » et « [Tout savoir sur la zone DNS](/guides/web-cloud/domains/dns-zone-general-information) ».

**Découvrez comment éditer votre zone DNS OVHcloud via votre espace client OVHcloud.**

## Prérequis

- Utiliser la configuration OVHcloud (ses serveurs DNS) pour le nom de domaine concerné.

:::warning
- Si votre nom de domaine n’utilise pas les serveurs DNS d’OVHcloud, vous devez réaliser la modification depuis l’interface du prestataire gérant la configuration de votre nom de domaine.

- Si votre nom de domaine est enregistré chez OVHcloud, vous pouvez vérifier si ce dernier utilise notre configuration. Si besoin, consultez notre guide « [Modifier les serveurs DNS d’un nom de domaine OVHcloud](/guides/web-cloud/domains/dns-server-edit) ».

Dans les deux cas ci-dessus, faites attention en effectuant vos changements de serveurs DNS. En effet, l’ancienne configuration pouvant être appliquée à votre nom de domaine ne sera plus active si vous n’avez pas préalablement reconfiguré et personnalisé la nouvelle zone DNS présente chez OVHcloud.

Vous ne pouvez avoir qu’une seule zone DNS active à la fois par nom de domaine.

:::

## En pratique

### Accéder à la gestion d’une zone DNS OVHcloud

:::info
Contrairement au nom de domaine, il n’y a pas de notion de titulaire pour une zone DNS, mais de gestion des contacts pour une zone DNS OVHcloud. Si vous souhaitez basculer la gestion de votre zone DNS vers un autre compte OVHcloud, suivez notre guide « [Gérer les contacts de ses services](/guides/account-and-service-management/account-information/managing-contacts) ».

:::

L’onglet **Zone DNS** liste vos enregistrements dans un tableau, à raison d’une ligne par enregistrement, affichant le **sous-domaine**, le **type** de l’enregistrement, sa **cible** et son **TTL**. Vous pouvez effectuer une recherche dans le tableau ou le filtrer par type d’enregistrement.

<img className="thumbnail" alt="Onglet Zone DNS dans l’espace client OVHcloud" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-zone-overview.png" loading="lazy" />

### Éditer la zone DNS OVHcloud de votre nom de domaine

**L’édition d’une zone DNS est une manipulation sensible** : réaliser un changement inopportun pourrait, par exemple, rendre indisponible l’accès à votre site internet ou la réception de nouveaux messages sur vos adresses e-mail.

:::tip
Consultez notre guide sur les [enregistrements DNS](/guides/web-cloud/domains/dns-zone-records) afin de mieux appréhender vos manipulations DNS.

Consultez également notre guide relatif aux [sous-domaines](/guides/web-cloud/domains/domain-create-subdomains) pour plus d’informations sur ce sujet.

:::

Depuis l’onglet **Zone DNS**, vous pouvez ajouter, modifier ou supprimer un enregistrement directement dans le tableau, éditer l’ensemble de la zone en mode textuel, réinitialiser la zone ou consulter son historique. **Cliquez sur les titres ci-dessous pour afficher les détails.**

<img className="thumbnail" alt="Menu Actions sur ma zone de la zone DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-actions-menu.png" loading="lazy" />

<details>

<summary>Ajouter un nouvel enregistrement DNS</summary>

Au-dessus du tableau, cliquez sur <code className="action">Ajouter une entrée</code>. Un formulaire s’ouvre entre la barre d’outils et le tableau :

1. Sélectionnez le **type de champ DNS** que vous souhaitez créer (A, AAAA, CNAME, MX, TXT, SPF, DKIM, DMARC, CAA, SRV, TLSA, HTTPS, etc.). Chaque type affiche une courte description de son utilité.
2. Renseignez les champs correspondant à ce type d’enregistrement (sous-domaine, cible et tout champ spécifique au type).
3. Définissez le **TTL** : laissez la valeur `Par défaut` ou choisissez `Personnalisé` pour saisir une valeur.
4. Cliquez sur <code className="action">Ajouter</code>.

Nous vous invitons à vérifier au préalable si cet enregistrement n’existe pas déjà et ne pointe pas vers une cible différente. Pour cela, utilisez le champ de recherche ou filtrez le tableau par type d’enregistrement. Si l’enregistrement existe déjà, modifiez-le à la place (voir ci-dessous).

> Lorsque la cible de votre enregistrement est une URL, pensez à ponctuer celle-ci. En effet, si vous ne le faites pas, votre nom de domaine sera automatiquement ajouté à la fin de votre cible.
> **Exemple** : vous souhaitez créer un enregistrement CNAME de `test.mydomain.ovh` vers `mydomain.ovh`.
> Vous devez alors avoir comme cible `mydomain.ovh.` et non pas `mydomain.ovh` sans le **.** à la fin.

<img className="thumbnail" alt="Ajout d’un enregistrement depuis la zone DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-add-entry.png" loading="lazy" />

</details>

<details>

<summary>Modifier un enregistrement DNS existant</summary>

Dans le tableau, sur la ligne de l’enregistrement concerné, ouvrez le menu d’actions <code className="action">⋮</code> et cliquez sur <code className="action">Modifier l'entrée</code>. La ligne se déploie en un formulaire d’édition : modifiez les valeurs, puis confirmez.

<img className="thumbnail" alt="Menu d’actions d’une ligne de la zone DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-row-menu.png" loading="lazy" />

</details>

<details>

<summary>Supprimer un enregistrement DNS</summary>

Dans le tableau, sur la ligne de l’enregistrement concerné, ouvrez le menu d’actions <code className="action">⋮</code> et cliquez sur <code className="action">Supprimer l'entrée</code>, puis confirmez.

Pour supprimer plusieurs enregistrements à la fois, cochez leurs cases sur la partie gauche du tableau, puis cliquez sur le bouton <code className="action">Supprimer</code> qui apparaît au-dessus du tableau.

<img className="thumbnail" alt="Suppression d’un enregistrement DNS depuis le menu d’actions" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-row-menu.png" loading="lazy" />

</details>

<details>

<summary>Éditer la zone en mode textuel</summary>

:::warning
Pour les utilisateurs avertis uniquement. Soyez également très vigilant sur la syntaxe lors de vos modifications.

:::

Au-dessus du tableau, ouvrez le menu <code className="action">Actions sur ma zone</code> et cliquez sur <code className="action">Modifier en mode textuel</code>. Sur la page qui s’ouvre, le contenu actuel de votre zone s’affiche et reste modifiable : éditez-le directement, ou importez un fichier de zone en le déposant dans l’espace prévu ou en cliquant sur <code className="action">Parcourir les fichiers</code> (fichiers acceptés : `.txt`, `.zone`). Cliquez ensuite sur <code className="action">Importer</code>.

:::warning
Ne modifiez pas les enregistrements DNS de votre zone DNS au profit de serveurs DNS externes à OVHcloud en mode textuel. En effet, cette zone DNS fonctionne **uniquement** avec des serveurs DNS OVHcloud.

:::

<img className="thumbnail" alt="Édition de la zone DNS en mode textuel" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-text-mode.png" loading="lazy" />

</details>

<details>

<summary>Réinitialiser la zone DNS</summary>

Réinitialiser votre zone DNS permet de revenir à une configuration minimale, avec les entrées OVHcloud par défaut ou celles de vos services. Vous pouvez également pointer votre nom de domaine vers des services d’hébergement Web et e-mail personnalisés.

:::danger
Avant de réinitialiser votre zone DNS, assurez-vous que votre nom de domaine n’est pas attaché à des services en cours d’utilisation, tels qu’un site web ou des adresses e-mail.

:::

Au-dessus du tableau, ouvrez le menu <code className="action">Actions sur ma zone</code> et cliquez sur <code className="action">Réinitialiser ma zone DNS</code>, puis suivez les étapes du panneau qui s’ouvre :

- Choisissez si vous souhaitez réinitialiser avec les **entrées minimales**. Définir des entrées minimales dans une zone DNS permet d’éviter qu’une requête vers le nom de domaine n’aboutisse sur une erreur.
- Définissez la cible de l’adresse IP de l’**hébergement Web** (enregistrement `A`) : la `Redirection` OVHcloud, l’`Hébergement Web OVHcloud` ou une adresse IPv4 `Personnalisé`.
- Définissez la cible du **serveur e-mail** (enregistrement `MX`) : la `Redirection` OVHcloud, le `Serveur E-mail OVHcloud` ou un serveur et une priorité `Personnalisé`.

<img className="thumbnail" alt="Panneau de réinitialisation de la zone DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-reset-zone.png" loading="lazy" />

</details>

<details>

<summary>Consulter l’historique de votre zone DNS</summary>

Au-dessus du tableau, ouvrez le menu <code className="action">Actions sur ma zone</code> et cliquez sur <code className="action">Voir l'historique de ma zone DNS</code>. Vous pouvez alors consulter, télécharger et restaurer une version précédente de votre zone. Pour plus de détails, consultez notre guide « [Gérer l’historique d’une zone DNS](/guides/web-cloud/domains/dns-zone-history) ».

</details>

### Le temps de propagation

Une fois la zone DNS de votre nom de domaine modifiée, un temps de propagation de 24 heures maximum est nécessaire afin que les modifications soient totalement effectives.

Si vous souhaitez réduire ce délai pour les prochaines éditions de votre zone DNS OVHcloud, vous pouvez ajuster le TTL (*Time To Live*) qui s’appliquera à tous les enregistrements de la zone DNS. Pour cela, ouvrez le menu <code className="action">Actions sur ma zone</code> au-dessus du tableau et cliquez sur <code className="action">Modifier le TTL par défaut</code>.

Vous pouvez aussi modifier le TTL d’un enregistrement DNS individuel lors de son ajout ou de sa modification.
