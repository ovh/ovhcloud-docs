## Objectif

<iframe className="video" width="560" height="315" src="https://www.youtube-nocookie.com/embed/BvrUi26ShzI" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen={true}></iframe>

Le sigle **DNS**, signifiant **D**omain **N**ame **S**ystem, est un ensemble d’éléments (serveurs DNS, zones DNS, etc.) permettant de faire correspondre un nom de domaine avec une adresse IP.

Pour plus d’explications, consultez nos guides « [Tout savoir sur les serveurs DNS](/guides/web-cloud/domains/dns-server-general-information) » et « [Tout savoir sur la zone DNS](/guides/web-cloud/domains/dns-zone-general-information) ».

**Découvrez comment éditer votre zone DNS OVHcloud via votre console OVHcloud.**

## Prérequis

- Utiliser la configuration OVHcloud (ses serveurs DNS) pour le nom de domaine concerné.

[[cpnav:web-domain-dns-zone]]

:::warning
- Si votre nom de domaine n’utilise pas les serveurs DNS d’OVHcloud, vous devez réaliser la modification depuis l’interface du prestataire gérant la configuration de votre nom de domaine.

- Si votre nom de domaine est enregistré chez OVHcloud, vous pouvez vérifier si ce dernier utilise notre configuration. Si besoin, consultez notre guide « [Modifier les serveurs DNS d’un nom de domaine OVHcloud](/guides/web-cloud/domains/dns-server-edit) ».

Dans les deux cas ci-dessus, faites attention en effectuant vos changements de serveurs DNS. En effet, l’ancienne configuration pouvant être appliquée à votre nom de domaine ne sera plus active si vous n’avez pas préalablement reconfiguré et personnalisé la nouvelle zone DNS présente chez OVHcloud.

Vous ne pouvez avoir qu’une seule zone DNS active à la fois par nom de domaine.

:::

## En pratique

### Accéder à la gestion d’une zone DNS OVHcloud

:::info
Contrairement au nom de domaine, il n’y a pas de notion de titulaire pour une zone DNS, mais de gestion des contacts pour une zone DNS OVHcloud. Si vous souhaitez basculer la gestion de votre zone DNS vers un autre compte OVHcloud, suivez notre guide « [Gérer les contacts de ses services](/guides/account-and-service-management/account-information/managing-contacts) ».

:::

{/* CP-STEPS-START:acceder-zone */}

Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, choisissez le nom de domaine concerné, puis cliquez sur l’onglet <code className="action">Zone DNS</code>. Il liste vos enregistrements dans un tableau, à raison d’une ligne par enregistrement, affichant le **Sous-domaine**, le **Type** de l’enregistrement, sa **Cible** et son **TTL**. Vous pouvez effectuer une recherche dans le tableau avec le champ **Rechercher** ou le filtrer par type d’enregistrement avec le bouton <code className="action">Filtres</code>.

<img className="thumbnail" alt="Onglet Zone DNS d’un nom de domaine et tableau des enregistrements" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />

{/* CP-STEPS-END:acceder-zone */}

### Éditer la zone DNS OVHcloud de votre nom de domaine

**L’édition d’une zone DNS est une manipulation sensible** : réaliser un changement inopportun pourrait, par exemple, rendre indisponible l’accès à votre site Internet ou la réception de nouveaux messages sur vos adresses e-mail.

:::tip
Consultez notre guide sur les [enregistrements DNS](/guides/web-cloud/domains/dns-zone-records) afin de mieux appréhender vos manipulations DNS.

Consultez également notre guide relatif aux [sous-domaines](/guides/web-cloud/domains/domain-create-subdomains) pour plus d’informations sur ce sujet.

:::

{/* CP-STEPS-START:editer-zone-intro */}

Depuis l’onglet <code className="action">Zone DNS</code>, vous pouvez ajouter, modifier ou supprimer un enregistrement directement dans le tableau de la carte **Enregistrements de zone**. La carte **Zone DNS**, en haut de l’onglet, vous permet également de modifier le TTL par défaut et, depuis son menu <code className="action">Actions supplémentaires</code>, d’éditer la zone en mode textuel, d’importer un fichier de zone, d’exporter la zone ou de la réinitialiser. L’historique de la zone s’affiche dans la carte **Historique de ma zone DNS**, en bas de l’onglet. **Cliquez sur les titres ci-dessous pour afficher les détails.**

<img className="thumbnail" alt="Menu Actions supplémentaires de la carte Zone DNS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-actions-menu.png" loading="lazy" />

{/* CP-STEPS-END:editer-zone-intro */}

<details>

<summary>Ajouter un nouvel enregistrement DNS</summary>

{/* CP-STEPS-START:ajouter-enregistrement */}

Dans l’onglet <code className="action">Zone DNS</code>, cliquez sur <code className="action">Ajouter une entrée</code> au-dessus du tableau. Un formulaire s’ouvre entre la barre d’outils et le tableau :

1. Dans la liste **Type**, sélectionnez le type d’enregistrement DNS que vous souhaitez créer (A, AAAA, CNAME, MX, TXT, SPF, DKIM, DMARC, CAA, SRV, TLSA, HTTPS, etc.). Chaque type affiche une courte description de son utilité, et un encadré explique l’enregistrement choisi. Le bouton <code className="action">Aide</code> détaille les valeurs attendues dans le formulaire.
2. Renseignez les champs correspondant à ce type d’enregistrement (**Sous-domaine**, **Cible** et tout champ spécifique au type). L’**Aperçu de l’enregistrement** affiche la ligne qui sera ajoutée à votre zone.
3. Définissez le **TTL** : laissez la valeur `Par défaut` ou choisissez `Personnalisé` pour saisir une valeur.
4. Cliquez sur <code className="action">Ajouter</code>.

Si vous maîtrisez la syntaxe des zones DNS, l’onglet <code className="action">Mode avancé</code> du formulaire vous permet de saisir directement un enregistrement au format DNS (par exemple : `www 3600 IN A 203.0.113.1`).

Nous vous invitons à vérifier au préalable si cet enregistrement n’existe pas déjà et ne pointe pas vers une cible différente. Pour cela, utilisez le champ **Rechercher** ou filtrez le tableau par type d’enregistrement avec le bouton <code className="action">Filtres</code>. Si l’enregistrement existe déjà, modifiez-le à la place (voir ci-dessous).

> Lorsque la cible de votre enregistrement est un nom de domaine ou un sous-domaine (types `CNAME`, `MX`, `NS`, `SRV` ou `DNAME`), le formulaire ajoute automatiquement le point final à la cible : l’**Aperçu de l’enregistrement** l’affiche (par exemple : `domain.tld.`).
> En mode textuel en revanche, pensez à ponctuer la cible. En effet, si vous ne le faites pas, votre nom de domaine sera automatiquement ajouté à la fin de votre cible.
> **Exemple** : pour un enregistrement CNAME de `test.domain.tld` vers `domain.tld`, la cible doit être `domain.tld.` et non pas `domain.tld` sans le **.** à la fin.

<img className="thumbnail" alt="Formulaire Ajouter une entrée de la zone DNS, type A sélectionné" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry.png" loading="lazy" />

{/* CP-STEPS-END:ajouter-enregistrement */}

</details>

<details>

<summary>Modifier un enregistrement DNS existant</summary>

{/* CP-STEPS-START:modifier-enregistrement */}

Dans le tableau de l’onglet <code className="action">Zone DNS</code>, sur la ligne de l’enregistrement concerné, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, puis sur <code className="action">Modifier</code>.

<img className="thumbnail" alt="Menu d’actions d’une ligne de la zone DNS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/row-actions.png" loading="lazy" />

La ligne se déploie en un formulaire d’édition : modifiez les valeurs, puis cliquez sur <code className="action">Modifier</code> pour confirmer.

<img className="thumbnail" alt="Formulaire de modification déployé sous la ligne d’un enregistrement A" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/edit-entry.png" loading="lazy" />

{/* CP-STEPS-END:modifier-enregistrement */}

</details>

<details>

<summary>Supprimer un enregistrement DNS</summary>

{/* CP-STEPS-START:supprimer-enregistrement */}

Dans le tableau de l’onglet <code className="action">Zone DNS</code>, sur la ligne de l’enregistrement concerné, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, puis sur <code className="action">Supprimer</code>. Dans la fenêtre **Supprimer l’entrée DNS** qui s’ouvre, confirmez en cliquant sur <code className="action">Supprimer</code>.

Pour supprimer plusieurs enregistrements à la fois, cochez leurs cases sur la partie gauche du tableau, puis cliquez sur le bouton <code className="action">Supprimer X entrée(s)</code> qui apparaît au-dessus du tableau (X étant le nombre d’enregistrements cochés), et confirmez.

<img className="thumbnail" alt="Suppression d’un enregistrement DNS depuis le menu d’actions" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/row-actions.png" loading="lazy" />

{/* CP-STEPS-END:supprimer-enregistrement */}

</details>

<details>

<summary>Éditer la zone en mode textuel ou importer un fichier de zone</summary>

{/* CP-STEPS-START:mode-textuel */}

:::warning
Pour les utilisateurs avertis uniquement. Soyez également très vigilant sur la syntaxe lors de vos modifications.

:::

Dans l’onglet <code className="action">Zone DNS</code>, ouvrez le menu <code className="action">Actions supplémentaires</code> de la carte **Zone DNS** et cliquez sur <code className="action">Modifier en mode textuel</code>. La carte **Enregistrements de zone** passe en <code className="action">Vue texte</code> : le contenu actuel de votre zone s’affiche et reste modifiable, éditez-le directement. Le bouton <code className="action">Utiliser le mode différentiel</code> affiche les différences entre la version actuelle et vos modifications. Cliquez ensuite sur <code className="action">Enregistrer</code>, ou sur <code className="action">Annuler les modifications</code> pour revenir au contenu enregistré.

:::warning
Ne modifiez pas les enregistrements DNS de votre zone DNS au profit de serveurs DNS externes à OVHcloud en mode textuel. En effet, cette zone DNS fonctionne **uniquement** avec des serveurs DNS OVHcloud.

:::

<img className="thumbnail" alt="Carte Enregistrements de zone en vue texte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/text-mode.png" loading="lazy" />

Pour remplacer le contenu de votre zone par celui d’un fichier de zone, ouvrez le menu <code className="action">Actions supplémentaires</code> de la carte **Zone DNS**, cliquez sur <code className="action">Importer un fichier</code> et choisissez votre fichier (fichiers acceptés : `.txt`, `.zone`). Son contenu s’ouvre dans la carte **Enregistrements de zone**, en <code className="action">Vue texte</code>, et le mode différentiel affiche ce qu’il change par rapport à votre zone actuelle. Rien n’est modifié tant que vous n’avez pas cliqué sur <code className="action">Enregistrer</code> : l’enregistrement remplace alors les enregistrements existants de votre zone.

{/* CP-STEPS-END:mode-textuel */}

</details>

<details>

<summary>Réinitialiser la zone DNS</summary>

Réinitialiser votre zone DNS permet de revenir à une configuration minimale, avec les entrées OVHcloud par défaut ou celles de vos services. Vous pouvez également pointer votre nom de domaine vers des services d’hébergement Web et e-mail personnalisés.

:::danger
Avant de réinitialiser votre zone DNS, assurez-vous que votre nom de domaine n’est pas attaché à des services en cours d’utilisation, tels qu’un site web ou des adresses e-mail.

:::

{/* CP-STEPS-START:reinitialiser-zone */}

Dans l’onglet <code className="action">Zone DNS</code>, ouvrez le menu <code className="action">Actions supplémentaires</code> de la carte **Zone DNS** et cliquez sur <code className="action">Réinitialiser la zone</code>.

<img className="thumbnail" alt="Menu Actions supplémentaires de la carte Zone DNS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-actions-menu.png" loading="lazy" />

Dans le panneau **Réinitialiser la zone DNS** qui s’ouvre :

- Choisissez comment réinitialiser votre zone : avec les `Valeurs par défaut` d’OVHcloud, ou avec des `Valeurs personnalisées` pour choisir vous-même où pointe votre nom de domaine et vers quel serveur sont acheminés vos e-mails.
- Choisissez si vous souhaitez recréer uniquement les **entrées minimales** (`NS` et `SOA`). Définir des entrées minimales dans une zone DNS permet d’éviter qu’une requête vers le nom de domaine n’aboutisse sur une erreur.
- Avec des valeurs personnalisées, définissez la cible de l’adresse IP de l’**hébergement Web** (enregistrement `A`) : la `Redirection` OVHcloud, l’`Hébergement Web OVHcloud` (choisissez alors l’hébergement concerné) ou une adresse IPv4 `Personnalisé`.
- Avec des valeurs personnalisées, définissez la cible du **serveur e-mail** (enregistrement `MX`) : la `Redirection` OVHcloud, le `Serveur E-mails OVHcloud` ou un serveur et une priorité `Personnalisé`.

Cliquez ensuite sur <code className="action">Réinitialiser la zone</code>.

<img className="thumbnail" alt="Panneau de réinitialisation de la zone DNS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/reset-zone.png" loading="lazy" />

{/* CP-STEPS-END:reinitialiser-zone */}

</details>

<details>

<summary>Consulter l’historique de votre zone DNS</summary>

{/* CP-STEPS-START:historique-zone */}

L’historique de votre zone s’affiche dans la carte **Historique de ma zone DNS**, en bas de l’onglet <code className="action">Zone DNS</code>. Vous pouvez y consulter, télécharger, comparer et restaurer une version précédente de votre zone. Pour plus de détails, consultez notre guide « [Gérer l’historique d’une zone DNS](/guides/web-cloud/domains/dns-zone-history) ».

{/* CP-STEPS-END:historique-zone */}

</details>

### Le temps de propagation

Une fois la zone DNS de votre nom de domaine modifiée, un temps de propagation de 24 heures maximum est nécessaire afin que les modifications soient totalement effectives.

{/* CP-STEPS-START:ttl-par-defaut */}

Si vous souhaitez réduire ce délai pour les prochaines éditions de votre zone DNS OVHcloud, vous pouvez ajuster le TTL (*Time To Live*) qui s’appliquera à tous les enregistrements de la zone DNS. Pour cela, dans l’onglet <code className="action">Zone DNS</code>, repérez la ligne **TTL par défaut** de la carte **Zone DNS** (la valeur actuelle y est indiquée) et cliquez sur <code className="action">Modifier le TTL par défaut</code>, juste en dessous. Dans la fenêtre qui s’ouvre, choisissez l’un des **Préréglages** ou saisissez une valeur `Personnalisé` en secondes, puis cliquez sur <code className="action">Enregistrer</code>.

{/* CP-STEPS-END:ttl-par-defaut */}

Vous pouvez aussi modifier le TTL d’un enregistrement DNS individuel lors de son ajout ou de sa modification.
