## Objectif

La zone **D**omain **N**ame **S**ystem (**DNS**) d’un nom de domaine constitue le fichier de configuration de ce dernier. Elle se compose d’informations techniques, appelées *enregistrements DNS*. La zone DNS est, en quelque sorte, comme un centre d’aiguillage.

Pour plus d’explications, consultez nos guides suivants :

- [Tout savoir sur les serveurs DNS](/guides/web-cloud/domains/dns-server-general-information)
- [Tout savoir sur la zone DNS](/guides/web-cloud/domains/dns-zone-general-information)
- [Tout savoir sur les enregistrements DNS](/guides/web-cloud/domains/dns-zone-records)

La mise à jour de manière « dynamique » d’un enregistrement DNS peut éviter une interruption prolongée de l’un de vos services si vous ne disposez pas d’une adresse IP dite « fixe » (qui ne change pas).

Par exemple, le **DynHost** peut être utilisé si vous *auto-hébergez* (dans les locaux de votre entreprise ou à votre domicile en passant par la *box* de votre **F**ournisseur d’**A**ccès à **I**nternet (**FAI**)) un serveur de jeux vidéo sans bénéficier d’une adresse IP « fixe ».

:::info
Tout enregistrement « A » ou « AAAA » avec un TTL (**T**ime **T**o **L**ive) de 60 secondes est considéré comme DynHost. Le TTL est une valeur qui indique la durée pendant laquelle un enregistrement DNS est mis en cache par les serveurs DNS avant d’être mis à jour.

:::

**Découvrez comment paramétrer un enregistrement DNS dynamique (DynHost) pour votre nom de domaine OVHcloud.**

## Prérequis

- Disposer d’un nom de domaine.
- Disposer d’une zone DNS OVHcloud pour le nom de domaine concerné.
- Utiliser les serveurs DNS proposés par OVHcloud pour le nom de domaine concerné.
- L’enregistrement DynHost que vous vous apprêtez à créer ne doit pas déjà exister dans la zone DNS OVHcloud de votre nom de domaine en tant qu’enregistrement « A » ou « AAAA ».

[[cpnav:web-dns-zones]]

**Si votre nom de domaine n’utilise pas les serveurs DNS fournis par OVHcloud**, rapprochez-vous du prestataire/fournisseur gérant sa configuration DNS afin de connaître la procédure à suivre.

**Si votre nom de domaine est enregistré chez OVHcloud**, vous pouvez vérifier si celui-ci utilise notre configuration. Pour cela, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

:::tip
Pour savoir si vous utilisez ou non les serveurs DNS d’OVHcloud, ceux-ci ont l’une des 2 formes suivantes :

- `nsXX.ovh.net` et `dnsXX.ovh.net` **ou** `nsXXX.ovh.net` et `dnsXXX.ovh.net` (où chaque `X` désigne un chiffre compris entre **0** et **9**)
- `ns200.anycast.me` et `dns200.anycast.me` (si vous avez souscrit à l’option [DNS anycast](/links/web/domains-options))

Si besoin, consultez notre guide relatif aux [serveurs DNS](/guides/web-cloud/domains/dns-server-general-information) pour plus d’informations.

:::

## En pratique

### 1 - Créer un utilisateur DynHost <a name="step1"></a>

{/* CP-STEPS-START:creer-identifiant */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">DynHost</code>, puis sur le sous-onglet <code className="action">Identifiants</code>. Cliquez ensuite sur le bouton <code className="action">Ajouter un identifiant</code>.

    <img className="thumbnail" alt="Onglet DynHost, sous-onglet Identifiants et bouton Ajouter un identifiant" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dynhost/logins-table.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le panneau **Ajouter un identifiant** qui s’affiche, complétez les informations demandées :

    |Informations|Description|
    |---|---|
    |Identifiant|Définissez un suffixe pour l’identifiant DynHost que vous êtes en train de créer. L’identifiant complet se compose de votre nom de domaine, d’un tiret et de ce suffixe (par exemple : `domain.tld-ident`). Le suffixe compte 10 caractères au maximum (lettres, chiffres, `.` et `-`).|
    |Mot de passe|Définissez le mot de passe associé à l’identifiant DynHost (entre 12 et 31 caractères), puis confirmez-le dans le champ **Confirmer le mot de passe**.|
    |Sous-domaine|Spécifiez le sous-domaine concerné par la création de l’enregistrement DNS dynamique. Si vous souhaitez gérer l’ensemble des sous-domaines avec un seul identifiant, précisez juste `*` dans le formulaire de saisie.|

    :::tip
    Pour mettre en place un DynHost directement pour votre nom de domaine, saisissez uniquement `*` dans le champ **Sous-domaine**.

    :::

    <img className="thumbnail" alt="Panneau Ajouter un identifiant rempli" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dynhost/add-login-drawer.png" loading="lazy" />

    Une fois les champs complétés, cliquez sur le bouton <code className="action">Ajouter</code>. L’identifiant apparaît alors dans le tableau du sous-onglet <code className="action">Identifiants</code>.
  </Tab>
</Tabs>

{/* CP-STEPS-END:creer-identifiant */}

Répétez cette étape autant de fois que nécessaire si vous avez besoin de créer plusieurs identifiants DynHost.

### 2 - Créer l’enregistrement DNS dynamique (DynHost) <a name="step2"></a>

La seconde étape consiste à créer l’enregistrement DNS qui devra être mis à jour dynamiquement. Pour rappel, celui-ci ne doit pas déjà exister dans la zone DNS OVHcloud de votre nom de domaine en tant qu’enregistrement « A » ou « AAAA ». Pour le vérifier, et le supprimer si nécessaire, reportez-vous aux informations de notre documentation « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) ».

Dès que vous êtes prêt à créer l’enregistrement DynHost, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

{/* CP-STEPS-START:creer-enregistrement */}

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">DynHost</code>. Dans le sous-onglet <code className="action">Enregistrements</code>, affiché par défaut, cliquez sur le bouton <code className="action">Ajouter un enregistrement</code>.

    <img className="thumbnail" alt="Onglet DynHost, sous-onglet Enregistrements et bouton Ajouter un enregistrement" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dynhost/records-table.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le panneau **Ajouter un enregistrement DynHost** qui s’affiche, complétez les informations demandées :

    |Informations|Description|
    |---|---|
    |Sous-domaine|Renseignez le sous-domaine dont l’enregistrement DNS devra être mis à jour dynamiquement. Ce sous-domaine doit correspondre à celui renseigné lors de la création de l’utilisateur DynHost. La mention **Enregistrement configuré** affiche le nom complet concerné.<br/><br/>**Si vous souhaitez mettre en place un DynHost directement pour votre nom de domaine, saisissez `@` dans ce formulaire de saisie.**|
    |IP actuelle de la destination|Renseignez l’adresse IP (IPv4 ou IPv6) qui doit être actuellement utilisée par l’enregistrement DNS. Il s’agit généralement de l’adresse IP publique de votre *box* Internet ou de votre serveur auto-hébergé.<br/><br/>Selon le principe du DynHost, celle-ci sera mise à jour automatiquement par la suite.<br/><br/>Une seule adresse IP doit être renseignée dans ce formulaire.|

    :::warning
    Pour la mise en place d’un enregistrement DNS dynamique (DynHost), l’utilisation d’un *wildcard* (en plaçant uniquement le caractère `*`) dans le champ **Sous-domaine** est indisponible.

    :::

    <img className="thumbnail" alt="Panneau Ajouter un enregistrement DynHost rempli" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dynhost/add-record-drawer.png" loading="lazy" />

    Une fois les champs complétés, cliquez sur le bouton <code className="action">Ajouter</code>. L’enregistrement DynHost apparaît alors dans le tableau.
  </Tab>
</Tabs>

{/* CP-STEPS-END:creer-enregistrement */}

Répétez cette étape autant de fois que nécessaire si vous avez besoin d’enregistrements DynHost supplémentaires.

:::info
Si votre nom de domaine ou sous-domaine doit être configuré dynamiquement avec, par exemple, une IPv4 et une IPv6, vous pouvez créer deux enregistrements DNS dynamiques pour le même nom de domaine ou sous-domaine. Le premier enregistrement DNS dynamique sera alors pour l’IPv4 et le second pour l’IPv6.

:::

### 3 - Automatiser le changement du DynHost

Une fois l’[utilisateur](#step1) et l’[enregistrement DynHost](#step2) créés, il vous faut automatiser la mise à jour de l’enregistrement DNS afin qu’elle soit réalisée de manière dynamique. Pour cela, vous devrez utiliser un logiciel/client qui se chargera de vérifier régulièrement si l’adresse IP de destination a changé afin de la mettre à jour automatiquement.

:::warning
L’installation et la configuration du logiciel/client doivent être réalisées selon vos propres connaissances. Quelques informations sur la manière de procéder sont présentes ci-dessous. Cependant, nous vous recommandons de faire appel à un [prestataire spécialisé](/links/partner) si vous éprouvez des difficultés. En effet, nous ne serons pas en mesure de vous fournir une assistance à ce sujet.
Plus d’informations dans la section [« Aller plus loin »](#go-further) de ce guide.

:::

Il existe plusieurs possibilités concernant le logiciel/client :

- il peut être installé sur votre serveur ou sur votre ordinateur ;
- il peut déjà être disponible dans l’interface de votre routeur/*box* Internet si ce dernier est compatible. Si vous éprouvez des difficultés dans ce cas de figure, rapprochez-vous du support de votre **FAI** pour effectuer la configuration.

Une fois le client choisi et installé, vous devrez le configurer en utilisant les informations de l’utilisateur DynHost créé précédemment dans la console OVHcloud.

Selon le client utilisé, une adresse URL de mise à jour peut être requise en plus des éléments de l’utilisateur DynHost et du sous-domaine concerné. Si tel est le cas, utilisez l’adresse URL ci-dessous en prenant soin d’y remplacer les informations génériques :

```bash
https://dns.eu.ovhapis.com/nic/update?system=dyndns&hostname=$HOSTNAME&myip=$IP
```

|Information|À remplacer par|
|---|---|
|$HOSTNAME|Le sous-domaine concerné par la modification.|
|$IP|La nouvelle adresse IPv4 ou IPv6 de destination.|

:::warning

Le comportement du paramètre `myip` dépend de la version du protocole IP utilisée :

- **IPv4** : le paramètre `myip` est optionnel. S’il est omis, l’adresse IP à l’origine de l’appel API est automatiquement utilisée.
- **IPv6** : l’adresse `dns.eu.ovhapis.com` n’étant pas joignable en IPv6, le paramètre `myip` est obligatoire pour transmettre l’adresse de destination.

:::

Vous pouvez vérifier si l’adresse IP de destination a bien été mise à jour. Pour cela, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

{/* CP-STEPS-START:verifier-ip */}

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">DynHost</code>. Dans le sous-onglet <code className="action">Enregistrements</code>, vérifiez l’adresse IP qui apparaît dans la colonne **Adresse IP** (affichage en tableau) ou à côté de la mention **Adresse IP** (affichage en cartes).

    <img className="thumbnail" alt="Sous-onglet Enregistrements de l’onglet DynHost et colonne Adresse IP" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dynhost/records-table.png" loading="lazy" />
  </Tab>
</Tabs>

{/* CP-STEPS-END:verifier-ip */}

:::warning
Toute modification dans la zone DNS active d’un nom de domaine via DynDNS peut entraîner un délai de propagation de la mise à jour de plusieurs minutes.

:::
