## Objectif

La création, le transfert ou le changement de titulaire d’un nom de domaine peuvent générer des erreurs nécessitant une intervention de votre part.

**Découvrez comment agir lorsqu’une erreur survient sur un nom de domaine.**

## Prérequis

- Être titulaire d’un ou plusieurs [noms de domaine](/links/web/domains).
- Être à jour dans les [paiements](/guides/account-and-service-management/managing-billing-payments-and-services/invoice-management#pay-bills) et [renouvellements](/guides/account-and-service-management/managing-billing-payments-and-services/automatic-renewal#renewal-management) de vos noms de domaine.

[[cpnav:web-ongoing-operations]]

## En pratique

### Présentation de l’interface de gestion des opérations en cours

{/* CP-STEPS-START:presentation */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/operations">Opérations en cours</ManagerLink>.
  </Tab>
  <Tab label="Étape 2">
    Un tableau liste toutes les opérations liées aux noms de domaine et aux zones DNS de votre compte OVHcloud. Les onglets situés au-dessus du tableau permettent de filtrer les opérations selon leur état (par exemple <code className="action">À traiter</code> ou <code className="action">Échouée</code>).

    <img className="thumbnail" alt="Page Opérations en cours, filtres d’état et liste des opérations" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/ongoing-operations-list.png" loading="lazy" />

    - **Ressource** : ressource concernée par l’opération (nom de domaine ou zone DNS).
    - **Opération** : opération en cours sur le nom de domaine.
    - **Commentaire** : détails sur l’opération en cours. Instructions.
    - **Date de création** : date de création de l’opération.
    - **Date de mise à jour** : horodatage de mise à jour de l’opération en cours.
    - **Statut** : état actuel de l’opération.
    - **Actions** : bouton d’accès au panneau de l’opération, présent lorsqu’une action est possible (relancer, annuler ou accélérer l’opération).
  </Tab>
</Tabs>

{/* CP-STEPS-END:presentation */}

Toutes les opérations listées dans ce tableau ne nécessitent pas votre intervention pour se dérouler normalement.

Ce guide traite des opérations **en erreur** au travers de situations récurrentes.

### Situations

{/* CP-STEPS-START:verifications */}

:::info
La liste de situations ci-dessous est non-exhaustive. Si vous rencontrez une erreur qui n’est pas détaillée dans ce guide :

- Vérifiez que vous êtes à jour dans les [paiements](/guides/account-and-service-management/managing-billing-payments-and-services/invoice-management#pay-bills) et [renouvellements](/guides/account-and-service-management/managing-billing-payments-and-services/automatic-renewal#renewal-management) de vos noms de domaine.
- Vérifiez si une action est possible : lorsque c’est le cas, un bouton apparaît dans la colonne **Actions**, à droite de l’opération concernée. Il ouvre le panneau de l’opération, qui présente les actions disponibles.
- Lisez le message descriptif et vérifiez s’il vous permet de résoudre l’erreur.

Si, malgré ces vérifications, vous ne pouvez pas résoudre l’erreur, [ouvrez un ticket d’assistance](/links/support) depuis la console OVHcloud.

:::

<summary>Code de transfert erroné</summary>

Lorsque vous transférez votre nom de domaine vers OVHcloud, vous devez saisir un code de transfert (**authInfo** / **AuthCode**) lors de la commande. Si ce code est incorrect, l’opération est suspendue. Vous pouvez la relancer avec le bon code.

{/* CP-STEPS-START:code-transfert */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/operations">Opérations en cours</ManagerLink>.
  </Tab>
  <Tab label="Étape 2">
    Repérez l’opération en erreur dans le tableau. Si besoin, filtrez la liste sur <code className="action">À traiter</code> ou <code className="action">Échouée</code>.

    Par exemple : une opération **Transfert entrant** au statut **À traiter**, dont la colonne **Commentaire** indique « The authInfo code is missing ». Si le code saisi lors de la commande est erroné, le commentaire indique que le code authInfo n’est pas valide.

    <img className="thumbnail" alt="Page Opérations en cours, filtres d’état et colonne Actions" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/ongoing-operations.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Cliquez sur le bouton situé dans la colonne **Actions**, à droite de l’opération concernée. Le panneau de l’opération s’ouvre.
  </Tab>
  <Tab label="Étape 4">
    Dans le panneau, sous **Suivi du transfert**, renseignez le code de transfert (**authInfo** / **AuthCode**) dans le champ prévu, puis cliquez sur <code className="action">Relancer</code> pour relancer l’opération.
  </Tab>
</Tabs>

<details>

<summary>Erreur sur un nom de domaine en .ie, .de ou .it après une mise à jour DNS</summary>

Lorsque vous modifiez vos serveurs DNS, le registre est susceptible de vérifier les nouveaux serveurs DNS ainsi que la zone DNS associée et bloquer le nom de domaine si la configuration n’est pas conforme.

{/* CP-STEPS-START:ie-de-it */}

:::warning
Ce type de blocage est initié par le registre et non par OVHcloud. Ainsi, même si le nom de domaine est bloqué par le registre, ses serveurs DNS apparaissent avec l’état **Actif** dans la console OVHcloud.

:::

Pour vérifier si votre nom de domaine fait l’objet d’un tel blocage, cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/operations">Opérations en cours</ManagerLink>.
  </Tab>
  <Tab label="Étape 2">
    Repérez l’opération en erreur dans le tableau. Si besoin, filtrez la liste sur <code className="action">À traiter</code> ou <code className="action">Échouée</code>.

    Par exemple : une opération **Mise à jour des DNS** au statut **À traiter**, dont la colonne **Commentaire** indique « error while updating domain name ».

    <img className="thumbnail" alt="Page Opérations en cours, filtres d’état et colonne Actions" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/ongoing-operations.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Pour vérifier votre nom de domaine, nous vous conseillons d’utiliser l’outil de vérification délivré par le registre :

    - Pour un nom de domaine en **.de** : [https://nast.denic.de/](https://nast.denic.de/).
    - Pour un nom de domaine en **.it** : [https://dns-check.nic.it/](https://dns-check.nic.it/).

    :::info
    Si votre registre ne fournit pas d’outil de vérification de serveurs DNS, il est possible d’interroger vos nouveaux serveurs DNS via la commande `nslookup` sur une « invite de commande » Windows ou via la commande `dig` sur un « terminal » Linux ou macOS.

    Si vos serveurs DNS sont joignables, l’outil vous retourne une adresse IP.

    Dans tous les cas, assurez-vous, auprès de l’administrateur du serveur DNS, que ce serveur DNS est bien configuré pour accueillir la zone DNS de votre nom de domaine.

    :::
  </Tab>
  <Tab label="Étape 4">
    Lorsque vous avez identifié l’origine de l’erreur et que vous l’avez corrigée, cliquez sur le bouton situé dans la colonne **Actions**, à droite de l’opération concernée. Dans le panneau de l’opération, cliquez sur <code className="action">Relancer</code> pour relancer l’opération de vérification DNS.

    Si la correction porte sur les serveurs DNS eux-mêmes, le panneau d’une mise à jour DNS propose aussi <code className="action">Modifier les serveurs DNS</code>.
  </Tab>
</Tabs>

{/* CP-STEPS-END:ie-de-it */}

</details>
