## Objectif

Vous êtes titulaire d’un nom de domaine chez OVHcloud et vous souhaitez le connecter à un Google Site. Ce guide explique comment préparer et configurer votre zone DNS OVHcloud pour votre Google Site.

**Découvrez comment connecter votre nom de domaine OVHcloud à un Google Site.**

[[fragment:support-scope]]

:::warning
L’assistance Google Site n’a pas accès aux paramètres de votre nom de domaine OVHcloud et ne peut donc pas vous conseiller sur les informations que vous devrez lui fournir.
:::


## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains) enregistré chez OVHcloud.
- Disposer des [autorisations appropriées](/guides/account-and-service-management/account-information/managing-contacts) pour gérer le nom de domaine.
- Disposer d’un Google Site et en être le propriétaire.

[[cpnav:web-domain-dns-zone]]

## En pratique

Avant de suivre les étapes de ce guide, nous vous conseillons de consulter notre guide « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) ».

:::warning
Votre zone DNS est potentiellement déjà préconfigurée ou liée à un hébergement web. Nous allons voir comment identifier chaque enregistrement DNS nécessaire à la connexion avec votre Google Site. Certains devront être supprimés pour éviter de rentrer en conflit avec des enregistrements DNS requis dans cette configuration. D’autres devront juste être modifiés ou créés. Pour une meilleure compréhension, nous utiliserons le nom de domaine « **domain.tld** » comme exemple. Remplacez celui-ci par votre nom de domaine lors de la configuration.

:::

### 1. Configurer votre Google Site

:::warning
Seul le propriétaire d’un Google Site peut le connecter à un nom de domaine. Si besoin, découvrez comment [modifier le propriétaire du Google site](https://support.google.com/sites/answer/97934).

:::

Préparez d’abord votre Google Site en suivant les instructions de la section **Configurer un nom de domaine personnalisé** depuis [**cette page du support Google**](https://support.google.com/sites/answer/9068867?hl=fr#zippy=).

### 2. Configurer vos enregistrements DNS sur votre compte OVHcloud

{/* CP-STEPS-START:configurer-dns */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, choisissez le nom de domaine concerné, puis cliquez sur l’onglet <code className="action">Zone DNS</code>.

    <img className="thumbnail" alt="Onglet Zone DNS listant les enregistrements d’un nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />

    Le tableau liste les enregistrements DNS du nom de domaine sélectionné.
  </Tab>
  <Tab label="Étape 2">
    **Configuration des enregistrements A**

    **1 - Identification :** cliquez sur <code className="action">Filtres</code> au-dessus du tableau, puis sélectionnez <code className="action">A</code> dans la liste **Type d’enregistrement**.

    :::info
    La liste **Type d’enregistrement** du bouton <code className="action">Filtres</code> ne propose que les types d’enregistrements présents dans votre zone DNS. Si un type n’apparaît pas dans la liste, votre zone ne contient aucun enregistrement de ce type.

    :::

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements A" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-a.png" loading="lazy" />

    Repérez les enregistrements « A » existants pour votre nom de domaine seul (sous-domaine `@`, exemple : `domain.tld.`) et pour le sous-domaine « www » (exemple : `www.domain.tld.`).

    **2 - Suppression :** supprimez tous les enregistrements « A » existants pour le sous-domaine « www ». Si plus de 4 enregistrements « A » existent pour le nom de domaine seul, supprimez les enregistrements excédentaires pour n’en conserver que 4. Pour chaque enregistrement à supprimer, sur la ligne concernée, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, puis sur <code className="action">Supprimer</code>, et confirmez dans la fenêtre **Supprimer l’entrée DNS**.

    **3 - Modification :** modifiez chaque enregistrement « A » conservé pour le nom de domaine seul : sur la ligne concernée, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, puis sur <code className="action">Modifier</code>. La ligne se déploie en un formulaire d’édition. Remplacez la **Cible (IPv4)** par l’une des 4 adresses IPv4 de Google Site (une adresse différente par enregistrement) :

    - `216.239.32.21`
    - `216.239.34.21`
    - `216.239.36.21`
    - `216.239.38.21`

    Cliquez sur <code className="action">Modifier</code> pour confirmer.

    **4 - Ajout :** si moins de 4 enregistrements « A » existaient, créez les enregistrements manquants. Cliquez sur <code className="action">Ajouter une entrée</code> au-dessus du tableau, puis sélectionnez `A — Pointer vers une IPv4` dans la liste **Type**. Saisissez `@` dans le champ **Sous-domaine** et, dans le champ **Cible (IPv4)**, chaque adresse IPv4 non encore attribuée. Cliquez sur <code className="action">Ajouter</code>.

    Les valeurs de ces adresses IP étant susceptibles de changer, vérifiez dans la documentation officielle [la valeur des enregistrements A](https://support.google.com/a/answer/2579934?hl=fr&ref_topic=2721296).

    Passez ensuite à l’étape 3.
  </Tab>
  <Tab label="Étape 3">
    **Suppression des enregistrements AAAA**

    **1 - Identification :** cliquez sur <code className="action">Filtres</code> au-dessus du tableau, puis sélectionnez <code className="action">AAAA</code> dans la liste **Type d’enregistrement**. Si la liste ne propose pas <code className="action">AAAA</code>, votre zone ne contient aucun enregistrement de ce type : passez directement à l’étape 4.

    <img className="thumbnail" alt="Bouton Filtres et liste Type d’enregistrement de la zone DNS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-type.png" loading="lazy" />

    Repérez les enregistrements « AAAA » existants pour votre nom de domaine seul (exemple : `domain.tld.`) et pour le sous-domaine « www » (exemple : `www.domain.tld.`).

    **2 - Suppression :** supprimez tous les enregistrements « AAAA » identifiés (nom de domaine seul et sous-domaine « www ») pour éviter un conflit avec les nouveaux enregistrements DNS. Pour chaque enregistrement, sur la ligne concernée, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, puis sur <code className="action">Supprimer</code>, et confirmez dans la fenêtre **Supprimer l’entrée DNS**.
  </Tab>
  <Tab label="Étape 4">
    **Configuration de l’enregistrement TXT**

    **1 - Identification :** cliquez sur <code className="action">Filtres</code> au-dessus du tableau, puis sélectionnez <code className="action">TXT</code> dans la liste **Type d’enregistrement**.

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements TXT" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-txt.png" loading="lazy" />

    Repérez les enregistrements « TXT » existants pour votre nom de domaine seul (exemple : `domain.tld.`) et pour le sous-domaine « www » (exemple : `www.domain.tld.`).

    **2 - Suppression :** supprimez tous les enregistrements « TXT » identifiés (nom de domaine seul et sous-domaine « www ») pour éviter un conflit avec les nouveaux enregistrements DNS. Pour chaque enregistrement, sur la ligne concernée, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, puis sur <code className="action">Supprimer</code>, et confirmez dans la fenêtre **Supprimer l’entrée DNS**.

    **3 - Ajout :** créez un enregistrement TXT de vérification. Cliquez sur <code className="action">Ajouter une entrée</code> au-dessus du tableau, puis sélectionnez `TXT — Texte libre (vérification, SPF…)` dans la liste **Type** (section **Champs étendus**). Complétez les champs **Sous-domaine** et **Valeur** avec les informations présentes sur la page « [Valeurs des enregistrements TXT](https://support.google.com/a/answer/2716802?hl=fr&ref_topic=2716886) » de la documentation officielle. Généralement, le champ **Sous-domaine** contient `@` et le champ **Valeur** est de type `google-site-verification=XXXXXXXXXXXX`. Cliquez sur <code className="action">Ajouter</code>.

    Passez ensuite à l’étape 5.
  </Tab>
  <Tab label="Étape 5">
    **Configuration de l’enregistrement CNAME**

    **1 - Identification :** cliquez sur <code className="action">Filtres</code> au-dessus du tableau, puis sélectionnez <code className="action">CNAME</code> dans la liste **Type d’enregistrement**.

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements CNAME" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-cname.png" loading="lazy" />

    Repérez les enregistrements « CNAME » existants pour le sous-domaine « www » (exemple : `www.domain.tld.`).

    **2 - Suppression :** si plusieurs enregistrements « CNAME » existent pour le sous-domaine « www », supprimez-les tous sauf un. Pour chaque enregistrement à supprimer, sur la ligne concernée, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, puis sur <code className="action">Supprimer</code>, et confirmez dans la fenêtre **Supprimer l’entrée DNS**.

    **3 - Modification :** si un enregistrement « CNAME » existe pour le sous-domaine « www », sur la ligne concernée, cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, puis sur <code className="action">Modifier</code>. La ligne se déploie en un formulaire d’édition. Remplacez uniquement la **Cible (nom d’hôte)** par `ghs.googlehosted.com.` : si vous omettez le point final, la console l’ajoute elle-même. Cliquez sur <code className="action">Modifier</code> pour confirmer.

    Si aucun enregistrement « CNAME » n’existe pour le sous-domaine « www », cliquez sur <code className="action">Ajouter une entrée</code> au-dessus du tableau, puis sélectionnez `CNAME — Alias vers un autre domaine` dans la liste **Type**, saisissez `www` dans le champ **Sous-domaine** et `ghs.googlehosted.com.` dans le champ **Cible (nom d’hôte)**. Cliquez sur <code className="action">Ajouter</code>.

    Ces valeurs étant susceptibles de changer, vérifiez-les sur la page « [Valeurs des enregistrements CNAME](https://knowledge.workspace.google.com/admin/support/troubleshooting/cname-record-values?hl=fr) » de la documentation officielle.
  </Tab>
</Tabs>

{/* CP-STEPS-END:configurer-dns */}

La zone DNS est maintenant configurée pour pointer vers votre Google Site.

:::info
La vérification de votre nom de domaine peut prendre jusqu’à 48 heures.

:::

Si vous utilisez une offre e-mail OVHcloud ou que vous prévoyez de souscrire à l’une de [nos offres e-mail](/links/web/emails), préparez votre zone DNS en conséquence. Consultez notre guide sur la [configuration d’un enregistrement MX](/guides/web-cloud/domains/dns-zone-mx).
