## Objectif

Vous êtes titulaire d’un nom de domaine chez OVHcloud et vous souhaitez le connecter à un hébergement Shopify. Ce guide explique comment préparer et configurer votre zone DNS OVHcloud pour votre hébergement Shopify.

**Découvrez comment connecter votre nom de domaine OVHcloud à un hébergement Shopify**

[[fragment:support-scope]]

:::warning
L’assistance Shopify n’a pas accès aux paramètres de votre nom de domaine OVHcloud et ne peut donc pas vous conseiller sur les informations que vous devrez lui fournir.
:::


## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains) enregistré chez OVHcloud.
- Disposer des [autorisations appropriées pour gérer](/guides/account-and-service-management/account-information/managing-contacts) le nom de domaine.
- Disposer d’un hébergement chez Shopify.
- Avoir accès à la gestion de cet hébergement chez Shopify.

## En pratique

Avant de suivre les étapes de ce guide, nous vous conseillons de consulter notre guide « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) ».

:::warning
Votre zone DNS est potentiellement déjà préconfigurée ou liée à un hébergement. Nous allons voir comment identifier chaque enregistrement DNS nécessaire à la connexion avec votre hébergement Shopify. Certains devront être supprimés pour éviter de rentrer en conflit avec des enregistrements DNS requis dans cette configuration. D’autres seront simplement à modifier ou à créer. Pour une meilleure compréhension, nous utiliserons le nom de domaine « **mydomain.ovh** » comme exemple. Remplacez celui-ci par votre nom de domaine lors de la configuration.

:::

### Configurer vos enregistrements DNS sur votre compte OVHcloud

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

<Tabs>
  <Tab label="Étape 1">
    Dans la section `Web Cloud`, cliquez sur <ManagerLink to="/#/web-domains/domain">Noms de domaine</ManagerLink>, sélectionnez le nom de domaine concerné, puis ouvrez l’onglet **Zone DNS**.

    <img className="thumbnail" alt="Onglet Zone DNS listant les enregistrements d’un nom de domaine" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-zone-overview.png" loading="lazy" />

Le tableau liste les enregistrements DNS du nom de domaine sélectionné.
  </Tab>
  <Tab label="Étape 2">
    **Configuration de l’enregistrement A**

    **1 - Identification :** filtrez les enregistrements DNS en sélectionnant le type `A` à l’aide du filtre au-dessus du tableau.

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements A" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-a.png" loading="lazy" />

Repérez les enregistrements « A » existants pour votre nom de domaine seul (exemple : `mydomain.ovh.`) et pour le sous-domaine « www » (exemple : `www.mydomain.ovh.`).

    **2 - Suppression :** supprimez tous les enregistrements « A » existants pour le sous-domaine « www ». Si plusieurs enregistrements « A » existent pour le nom de domaine seul, supprimez-les tous sauf un, que vous modifierez à la sous-étape suivante. Pour chaque enregistrement à supprimer, sur la ligne concernée, ouvrez le menu d’actions <code className="action">⋮</code> et cliquez sur <code className="action">Supprimer l'entrée</code>.

    **3 - Modification :** si un enregistrement « A » existe pour le nom de domaine seul, ouvrez le menu d’actions <code className="action">⋮</code> sur la ligne concernée et cliquez sur <code className="action">Modifier l'entrée</code>. La ligne se déplie en un formulaire d’édition. Laissez le champ **Sous-domaine** vide et remplacez la cible par l’adresse IPv4 de Shopify : `23.227.38.65`. Confirmez vos modifications.

    Si aucun enregistrement « A » n’existe, cliquez sur <code className="action">Ajouter une entrée</code> au-dessus du tableau, puis sélectionnez le type d’enregistrement DNS <code className="action">A</code>, laissez le champ **Sous-domaine** vide et saisissez `23.227.38.65` dans le champ **Cible**. Cliquez sur <code className="action">Ajouter</code>.

    Passez ensuite à l’étape 3.
  </Tab>
  <Tab label="Étape 3">
    **Configuration de l’enregistrement AAAA**

    **1 - Identification :** filtrez les enregistrements DNS en sélectionnant le type `AAAA` à l’aide du filtre au-dessus du tableau.

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements AAAA" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-aaaa.png" loading="lazy" />

Repérez les enregistrements « AAAA » existants pour votre nom de domaine seul (exemple : `mydomain.ovh.`) et pour le sous-domaine « www » (exemple : `www.mydomain.ovh.`).

    **2 - Suppression :** supprimez tous les enregistrements « AAAA » existants pour le sous-domaine « www ». Si plusieurs enregistrements « AAAA » existent pour le nom de domaine seul, supprimez-les tous sauf un, que vous modifierez à la sous-étape suivante. Pour chaque enregistrement à supprimer, sur la ligne concernée, ouvrez le menu d’actions <code className="action">⋮</code> et cliquez sur <code className="action">Supprimer l'entrée</code>.

    **3 - Modification :** si un enregistrement « AAAA » existe pour le nom de domaine seul, ouvrez le menu d’actions <code className="action">⋮</code> sur la ligne concernée et cliquez sur <code className="action">Modifier l'entrée</code>. La ligne se déplie en un formulaire d’édition. Laissez le champ **Sous-domaine** vide et remplacez la cible par l’adresse IPv6 de Shopify : `2620:0127:f00f:5::`. Confirmez vos modifications.

    Si aucun enregistrement « AAAA » n’existe, cliquez sur <code className="action">Ajouter une entrée</code> au-dessus du tableau, puis sélectionnez le type d’enregistrement DNS <code className="action">AAAA</code>, laissez le champ **Sous-domaine** vide et saisissez `2620:0127:f00f:5::` dans le champ **Cible**. Cliquez sur <code className="action">Ajouter</code>.

    Passez ensuite à l’étape 4.
  </Tab>
  <Tab label="Étape 4">
    **Suppression des enregistrements TXT**

    **1 - Identification :** filtrez les enregistrements DNS en sélectionnant le type `TXT` à l’aide du filtre au-dessus du tableau.

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements TXT" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-txt.png" loading="lazy" />

Repérez les enregistrements « TXT » existants pour votre nom de domaine seul (exemple : `mydomain.ovh.`) et pour le sous-domaine « www » (exemple : `www.mydomain.ovh.`).

    **2 - Suppression :** supprimez tous les enregistrements « TXT » identifiés (nom de domaine seul et sous-domaine « www ») pour éviter un conflit avec les nouveaux enregistrements DNS. Pour chaque enregistrement, sur la ligne concernée, ouvrez le menu d’actions <code className="action">⋮</code> et cliquez sur <code className="action">Supprimer l'entrée</code>.

    Si aucun enregistrement « TXT » n’existe, passez à l’étape 5.
  </Tab>
  <Tab label="Étape 5">
    **Configuration de l’enregistrement CNAME**

    **1 - Identification :** filtrez les enregistrements DNS en sélectionnant le type `CNAME` à l’aide du filtre au-dessus du tableau.

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements CNAME" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-cname.png" loading="lazy" />

Repérez les enregistrements « CNAME » existants pour le sous-domaine « www » (exemple : `www.mydomain.ovh.`).

    **2 - Suppression :** si plusieurs enregistrements « CNAME » existent pour le sous-domaine « www », supprimez-les tous sauf un. Pour chaque enregistrement à supprimer, sur la ligne concernée, ouvrez le menu d’actions <code className="action">⋮</code> et cliquez sur <code className="action">Supprimer l'entrée</code>.

    **3 - Modification :** si un enregistrement « CNAME » existe pour le sous-domaine « www », ouvrez le menu d’actions <code className="action">⋮</code> sur la ligne concernée et cliquez sur <code className="action">Modifier l'entrée</code>. La ligne se déplie en un formulaire d’édition. Remplacez uniquement la **Cible** par `shops.myshopify.com.`. Confirmez vos modifications.

    Si aucun enregistrement « CNAME » n’existe pour le sous-domaine « www », cliquez sur <code className="action">Ajouter une entrée</code> au-dessus du tableau, puis sélectionnez le type d’enregistrement DNS <code className="action">CNAME</code>, saisissez `www` dans le champ **Sous-domaine** et `shops.myshopify.com.` dans le champ **Cible**. Cliquez sur <code className="action">Ajouter</code>.
  </Tab>
</Tabs>

La zone DNS est maintenant configurée pour pointer vers votre hébergement Shopify.

### Connecter son nom de domaine à Shopify

Réalisez cette étape depuis l’espace de gestion Shopify en suivant l’étape 2 de [**ce guide Shopify**](https://help.shopify.com/fr/manual/domains/add-a-domain/connecting-domains/connect-domain-manual).

:::info
La vérification de votre nom de domaine peut prendre jusqu’à 48 heures.

:::

Si vous utilisez une offre e-mail OVHcloud ou que vous prévoyez de souscrire à l’une de [nos offres e-mail](/links/web/emails), vous devez également préparer votre zone DNS en conséquence. Consultez notre guide sur la [configuration d’un enregistrement MX](/guides/web-cloud/domains/dns-zone-mx).
