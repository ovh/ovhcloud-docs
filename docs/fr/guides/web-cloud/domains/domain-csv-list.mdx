## Objectif

Vous souhaitez récupérer la liste de tous les noms de domaine présents sur votre compte client OVHcloud ? Vous avez besoin de récupérer, en une seule fois, l’ensemble des informations relatives à vos noms de domaine (contacts associés, titulaire, options actives, dates de création et d’expiration, etc.) ?

**Découvrez comment exporter la liste de vos noms de domaine et leurs informations associées au format CSV depuis la console OVHcloud.**

## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains) enregistré chez OVHcloud.

[[cpnav:web-domains]]

## En pratique

{/* CP-STEPS-START:exporter-csv */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>. Au-dessus du tableau qui s’affiche, cliquez sur le bouton <code className="action">Exporter en CSV</code>, puis sur <code className="action">Exporter tout</code>.

    <img className="thumbnail" alt="Menu du bouton Exporter en CSV au-dessus de la liste des noms de domaine" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/export-csv/export-csv-menu.png" loading="lazy" />

    :::info
    Pour n’exporter que certains noms de domaine, cochez-les d’abord dans le tableau, puis choisissez <code className="action">Exporter la sélection</code> dans le même menu.

    :::
  </Tab>
  <Tab label="Étape 2">
    Dans le panneau **Exporter en CSV** qui s’ouvre, cochez les informations que vous souhaitez inclure dans le fichier CSV pour tous vos noms de domaine, dans les sections **Colonnes domaine** et **Colonnes contact**. Le nom de domaine au format ASCII est toujours inclus. Les zones DNS seules (sans nom de domaine dans votre compte) sont aussi exportées : la colonne **Type**, cochée par défaut, distingue domaine, domaine + zone et zone seule.

    <img className="thumbnail" alt="Panneau Exporter en CSV et choix des colonnes à exporter" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/export-csv/export-csv-drawer.png" loading="lazy" />

    Cliquez ensuite sur le bouton <code className="action">Exporter</code> pour démarrer la génération du fichier au format CSV.
  </Tab>
  <Tab label="Étape 3">
    La progression de l’export s’affiche dans le panneau. Patientez jusqu’à ce que la barre de progression atteigne 100 %.

    Dès que le fichier CSV est généré, le message « L’export CSV a été généré avec succès. » s’affiche et le téléchargement du fichier se lance automatiquement.

    <img className="thumbnail" alt="Message de réussite de l’export CSV et lien de téléchargement du fichier" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/export-csv/export-csv-success.png" loading="lazy" />

    Si le téléchargement du fichier CSV ne s’est pas lancé automatiquement, cliquez sur le lien <code className="action">Télécharger le fichier CSV</code> afin de le récupérer. Cliquez enfin sur <code className="action">Fermer</code> pour fermer le panneau.
  </Tab>
</Tabs>

{/* CP-STEPS-END:exporter-csv */}
