## Objectif

Ce guide vous explique comment utiliser un nom de domaine enregistré chez OVHcloud avec le service iCloud Mail d’Apple. Vous pouvez ainsi créer des adresses e-mail personnalisées (`john.smith@mydomain.ovh`), entièrement gérées et hébergées par Apple.

## Prérequis

- Un [nom de domaine](/links/web/domains) enregistré chez OVHcloud.
- Un identifiant Apple avec un abonnement **iCloud+**.

[[cpnav:web-dns-zones]]

## En pratique

### 1 - Activer le nom de domaine dans iCloud <a name="step1"></a>

Pour activer votre nom de domaine dans iCloud, suivez les instructions de la page « Add a domain you own to iCloud Mail on iCloud.com » de la [documentation officielle Apple](https://support.apple.com/fr-fr/guide/icloud/mma473945269/icloud). Concentrez-vous sur la section « Step 3: Update the records with your domain registrar » (Mettre à jour les enregistrements auprès de votre bureau d’enregistrement), pour relever les enregistrements DNS à ajouter dans votre <Tooltip term="dnsZone">zone DNS</Tooltip> OVHcloud.

À l’issue de cette étape, Apple vous communique la liste des enregistrements DNS (MX, CNAME, TXT) à configurer dans votre zone DNS OVHcloud. Conservez-la pour l’étape suivante.

### 2 - Configurer les enregistrements DNS dans votre espace client OVHcloud

Cliquez sur les onglets ci-dessous pour afficher chacune des **2** étapes.

<Tabs>
  <Tab label="Étape 1">
    Dans la section <code className="action">Zones DNS</code>, choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Capture d’écran de l’espace client OVHcloud affichant la liste des zones DNS." src="/images/assets/screens/control-panel/product-selection/web-cloud/dns-zones.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Pour savoir comment ajouter, modifier ou supprimer chaque type d’enregistrement DNS (MX, CNAME, TXT, etc.), consultez notre guide « [Tout savoir sur les enregistrements DNS](/guides/web-cloud/domains/dns-zone-records) ».

    À l’aide des enregistrements DNS relevés précédemment ([Partie 1](#step1)), créez ou mettez à jour les champs correspondants dans votre zone DNS OVHcloud :

    - **MX** : pour la réception des e-mails.
    - **CNAME** : pour les clés <Tooltip term="dkim">DKIM</Tooltip> (`sig1._domainkey...`, `sig2._domainkey...`).
    - <Tooltip term="txtRecord">**TXT**</Tooltip> : pour le <Tooltip term="spf">SPF</Tooltip> (fusionnez si un enregistrement SPF existe déjà).
    - **TXT DMARC** : facultatif mais recommandé ([Partie 3](#step3)).

    :::warning
    Utilisez uniquement des guillemets droits `"` tels qu’ils apparaissent dans la documentation technique d’Apple (généralement en version anglaise). Les guillemets typographiques « » ou “ ” affichés dans certaines traductions ne doivent pas être utilisés dans la configuration DNS.

    :::

  </Tab>
</Tabs>

### 3 - Ajouter un enregistrement DMARC (facultatif) <a name="step3"></a>

Pour améliorer la délivrabilité de vos e-mails et éviter qu’ils soient classés comme spam, ajoutez un enregistrement <Tooltip term="dmarc">**DMARC**</Tooltip>.

Pour savoir comment créer un enregistrement DMARC dans votre espace client OVHcloud, consultez notre guide « [Améliorer la sécurité des e-mails via un enregistrement DMARC](/guides/web-cloud/domains/dns-zone-dmarc) ».

### 4 - Vérifier et activer le domaine dans iCloud

Une fois les enregistrements DNS (MX, CNAME, TXT, DMARC) correctement ajoutés dans votre zone DNS OVHcloud, retournez sur [iCloud.com](https://www.icloud.com).

Suivez les instructions de la page « Add a domain you own to iCloud Mail on iCloud.com » de la [documentation officielle Apple](https://support.apple.com/fr-fr/guide/icloud/mma473945269/icloud). Concentrez-vous sur la section « Step 4: Finish setting up the domain » (Terminer la configuration du domaine).

Une fois cette étape terminée, votre nom de domaine personnalisé est pleinement activé et vous pouvez créer jusqu’à 3 adresses par membre de votre famille.

:::warning
La validation peut échouer si vos enregistrements DNS n’ont pas encore été propagés. Cette <Tooltip term="dnsPropagation">propagation</Tooltip> peut prendre plusieurs heures.

:::

### Dépannages courants

#### Vérifier où est gérée la zone DNS

Si votre nom de domaine est associé à des serveurs DNS externes à OVHcloud (Wix, Squarespace, Cloudflare, etc.), configurez les enregistrements dans l’interface de gestion de ces serveurs DNS, et non dans l’espace client OVHcloud.

#### CNAME déjà existant

- Un enregistrement **CNAME** ne peut pas cohabiter avec un enregistrement **A, AAAA ou TXT** configuré sur le même domaine ou sous-domaine.
- Supprimez l’ancien enregistrement avant de créer le CNAME demandé par Apple.

#### SPF en doublon

<Region zones={['eu']}>

- Il ne peut exister qu’**un seul enregistrement SPF** par nom de domaine. Si un enregistrement SPF OVHcloud existe déjà (ex. : `v=spf1 include:mx.ovh.com ~all`), fusionnez-le avec celui fourni par Apple (ex. : `v=spf1 include:mx.ovh.com include:icloud.com ~all`).

</Region>
<Region zones={['ca', 'apac']}>

- Il ne peut exister qu’**un seul enregistrement SPF** par nom de domaine. Si un enregistrement SPF OVHcloud existe déjà (ex. : `v=spf1 include:mx.ovh.ca ~all`), fusionnez-le avec celui fourni par Apple (ex. : `v=spf1 include:mx.ovh.ca include:icloud.com ~all`).

</Region>

#### DKIM incomplet

- Apple vous demande d’enregistrer plusieurs clés DKIM (`sig1`, `sig2`, etc.) : ajoutez-les toutes dans votre zone DNS.

#### Délai de propagation

- Les modifications DNS peuvent prendre plusieurs heures (jusqu’à 24 h) avant d’être prises en compte par Apple.
