## Objectif

Vous souhaitez que votre site web soit accessible via votre nom de domaine ? Pour cela, votre nom de domaine doit pointer vers l’adresse IP du service sur lequel votre site web est situé (hébergement web, serveur dédié, VPS, etc.). Vous devrez alors configurer la zone DNS active de votre nom de domaine à l’aide d’un enregistrement DNS de type A.

**Découvrez comment ajouter un enregistrement DNS de type A dans une zone DNS gérée chez OVHcloud pour votre nom de domaine.**

:::info
Pour modifier ou supprimer un enregistrement DNS de type A d’une zone DNS OVHcloud, suivez [ce guide](/guides/web-cloud/domains/dns-zone-edit).

:::

## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains).
- Disposer d’une zone DNS associée à ce nom de domaine chez OVHcloud.

[[cpnav:web-domain-dns-zone]]

## En pratique

:::warning
L’ajout, la modification ou la suppression d’enregistrements DNS dans une zone DNS active est une manipulation sensible. En cas de doute, contactez un [prestataire spécialisé](/links/partner).

:::

### Ajouter un enregistrement DNS de type A pour un nom de domaine

{/* CP-STEPS-START:ajout-domaine */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Zone DNS</code>, puis, au-dessus du tableau, sur <code className="action">Ajouter une entrée</code>.

    <img className="thumbnail" alt="Onglet Zone DNS d’un nom de domaine et bouton Ajouter une entrée" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le formulaire qui s’ouvre au-dessus du tableau, sélectionnez `A — Pointer vers une IPv4` dans la liste **Type**.

    <img className="thumbnail" alt="Liste Type du formulaire Ajouter une entrée et types d’enregistrement proposés" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Dans le champ **Sous-domaine**, saisissez `@` : ce symbole désigne le nom de domaine lui-même. Dans le champ **Cible (IPv4)**, renseignez l’adresse IP (par exemple : `203.0.113.0`) du service sur lequel votre site web est situé (hébergement web, serveur dédié, VPS, etc.).

    <img className="thumbnail" alt="Formulaire Ajouter une entrée de la zone DNS, enregistrement A pour le nom de domaine" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-a-record.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 5">
    Vérifiez l’**Aperçu de l’enregistrement**, puis cliquez sur <code className="action">Ajouter</code>.
  </Tab>
</Tabs>

{/* CP-STEPS-END:ajout-domaine */}

Patientez jusqu’à **24** heures pour que la propagation de l’ajout sur le réseau DNS soit pleinement effective.

### Ajouter un enregistrement DNS de type A pour le sous-domaine d’un nom de domaine

{/* CP-STEPS-START:ajout-sous-domaine */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Zone DNS</code>, puis, au-dessus du tableau, sur <code className="action">Ajouter une entrée</code>.

    <img className="thumbnail" alt="Onglet Zone DNS d’un nom de domaine et bouton Ajouter une entrée" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le formulaire qui s’ouvre au-dessus du tableau, sélectionnez `A — Pointer vers une IPv4` dans la liste **Type**.

    <img className="thumbnail" alt="Liste Type du formulaire Ajouter une entrée et types d’enregistrement proposés" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Dans le champ **Sous-domaine**, renseignez le sous-domaine concerné (par exemple : `www` pour `www.domain.tld`). Dans le champ **Cible (IPv4)**, renseignez l’adresse IP (par exemple : `203.0.113.0`) du service sur lequel votre site web est situé (hébergement web, serveur dédié, VPS, etc.).

    <img className="thumbnail" alt="Formulaire Ajouter une entrée de la zone DNS, enregistrement A pour le sous-domaine www" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-a-record-www.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 5">
    Vérifiez l’**Aperçu de l’enregistrement**, puis cliquez sur <code className="action">Ajouter</code>. Patientez jusqu’à **24** heures pour que la propagation de l’ajout sur le réseau DNS soit pleinement effective.
  </Tab>
</Tabs>
