## Objectif

L’option [DNS Anycast](/links/web/domains-options-anycast) accélère la résolution DNS de votre nom de domaine sur l’ensemble du globe. Vous n’avez plus besoin de cette optimisation ou ne souhaitez plus la renouveler à son échéance ?

**Découvrez comment résilier l’option DNS Anycast de votre nom de domaine depuis votre espace client OVHcloud.**

## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains) chez OVHcloud.
- L’option DNS Anycast doit être active sur le nom de domaine concerné. Pour le vérifier, consultez notre guide « [Activer les DNS Anycast pour votre nom de domaine](/guides/web-cloud/domains/dns-anycast-enable) ».
- Être connecté à votre espace client OVHcloud.

## En pratique

:::info
La résiliation n’est pas immédiate : l’option DNS Anycast reste active et fonctionnelle jusqu’à sa date d’échéance. Elle n’est pas renouvelée et est supprimée à cette date.
:::

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/#/web-domains/domain">Noms de domaine</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Liste des noms de domaine dans l’espace client OVHcloud" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-names.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sélectionnez l’onglet <code className="action">Serveurs DNS</code> une fois positionné sur le domaine concerné.

    <img className="thumbnail" alt="Onglet Serveurs DNS d’un nom de domaine" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans la colonne de droite de la page qui s’affiche, cliquez sur le bouton <code className="action">Résilier DNS Anycast</code>.

    <img className="thumbnail" alt="Bouton Résilier DNS Anycast dans l’onglet Serveurs DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    La page qui s’affiche rappelle le rôle de l’option ainsi que la date à laquelle elle doit être renouvelée automatiquement. Cliquez sur le bouton <code className="action">Résilier DNS Anycast</code>.

    <img className="thumbnail" alt="Page de résiliation de l’option DNS Anycast" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns-page.png" loading="lazy" />

    Dans la fenêtre de confirmation qui apparaît, cliquez sur <code className="action">Confirmer</code> pour valider la résiliation du service DNS Anycast.

    <img className="thumbnail" alt="Fenêtre de confirmation de la résiliation du service DNS Anycast" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns-confirm.png" loading="lazy" />
  </Tab>
</Tabs>

Une fois la résiliation enregistrée, vérifiez sa prise en compte depuis l’onglet <code className="action">Informations générales</code> de votre nom de domaine : la section **Configuration** y indique l’état de l’option DNS Anycast ainsi que la date d’effet.

:::info
Après la date d’effet de la résiliation, votre nom de domaine n’utilise plus les serveurs DNS Anycast. Prenez en compte le délai naturel de propagation du service DNS, qui peut durer jusqu’à 48 heures.
:::
