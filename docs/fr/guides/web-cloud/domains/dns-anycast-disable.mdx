## Objectif

L’option [DNS Anycast](/links/web/domains-options-anycast) accélère la résolution DNS de votre nom de domaine sur l’ensemble du globe. Vous n’avez plus besoin de cette optimisation ou ne souhaitez plus la renouveler à son échéance ?

**Découvrez comment résilier l’option DNS Anycast de votre nom de domaine depuis la console OVHcloud.**

## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains) chez OVHcloud.
- L’option DNS Anycast doit être active sur le nom de domaine concerné. Pour le vérifier, consultez notre guide « [Activer les DNS Anycast pour votre nom de domaine](/guides/web-cloud/domains/dns-anycast-enable) ».

[[cpnav:web-domains]]

## En pratique

:::info
La résiliation n’est pas immédiate : l’option DNS Anycast reste active et fonctionnelle jusqu’à sa date d’échéance. Elle n’est pas renouvelée et est supprimée à cette date.
:::

{/* CP-STEPS-START:resilier-anycast */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné. L’onglet <code className="action">Vue d’ensemble</code> du nom de domaine s’affiche.

    <img className="thumbnail" alt="Liste des noms de domaine dans la console OVHcloud" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans la section **Serveurs DNS** de l’onglet <code className="action">Vue d’ensemble</code>, la ligne **DNS Anycast** indique l’état de l’option, **Actif**. Cliquez sur <code className="action">Résilier</code>, juste en dessous.

    <img className="thumbnail" alt="Section Serveurs DNS avec l’option DNS Anycast active et le bouton Résilier" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/anycast-active.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    La fenêtre **Résilier le DNS Anycast** s’affiche. Elle rappelle la date d’expiration de l’option, à laquelle la résiliation prendra effet, et précise que vous ne bénéficierez plus de la résolution DNS haute disponibilité ni des performances accrues.

    Cliquez sur <code className="action">Résilier</code> pour valider la résiliation du service DNS Anycast.
  </Tab>
</Tabs>

Une fois la résiliation enregistrée, vérifiez sa prise en compte dans la section **Serveurs DNS** de l’onglet <code className="action">Vue d’ensemble</code> : l’état de l’option DNS Anycast passe à **En résiliation**. Le service reste actif jusqu’à sa date d’expiration, indiquée dans la fenêtre de résiliation. Tant que la résiliation n’a pas pris effet, le bouton <code className="action">Restaurer</code> vous permet de l’annuler.

{/* CP-STEPS-END:resilier-anycast */}

:::info
Après la date d’effet de la résiliation, votre nom de domaine n’utilise plus les serveurs DNS Anycast. Prenez en compte le délai naturel de propagation du service DNS, qui peut durer jusqu’à 48 heures.
:::
