## Qu'est-ce que le DNS ?

Le **DNS** (*Domain Name System*) est l'annuaire d'Internet : il traduit les noms de domaine lisibles par l'humain (comme `mydomain.ovh`) en adresses IP comprises par les machines. Sans lui, il faudrait retenir une suite de chiffres pour joindre chaque site web ou service en ligne.

Chez OVHcloud, la configuration DNS d'un nom de domaine repose sur trois briques :

- les **serveurs DNS**, qui hébergent et diffusent les informations de votre domaine ;
- la **zone DNS**, le fichier qui regroupe l'ensemble de vos enregistrements ;
- les **enregistrements DNS**, chaque ligne qui associe un nom à une valeur (adresse IP, serveur e-mail, texte…).

## Comment s'articule le DNS ?

De votre nom de domaine jusqu'à chaque enregistrement, la résolution DNS suit une chaîne en quatre maillons.

<DnsChain />

### Le serveur DNS

Les serveurs DNS hébergent et diffusent sur Internet les informations de votre domaine. Lorsqu'un internaute demande votre site, ce sont eux qui répondent en indiquant où le trouver. Par défaut, votre domaine utilise les serveurs DNS OVHcloud. [Tout savoir sur les serveurs DNS](/guides/web-cloud/domains/dns-server-general-information).

<DnsServerIllustration />

### La zone DNS

La zone DNS est le fichier de configuration rattaché à vos serveurs DNS. Elle regroupe l'ensemble des enregistrements de votre domaine : c'est ici que vous ajoutez, modifiez ou supprimez vos entrées. [Tout savoir sur la zone DNS](/guides/web-cloud/domains/dns-zone-general-information).

<DnsZoneIllustration />

### Les enregistrements DNS

Chaque enregistrement est une ligne de la zone qui relie un nom à une valeur : une adresse IP, un serveur e-mail, du texte… Son type détermine son rôle, repéré ci-dessous par sa couleur. Sélectionnez celui à configurer pour accéder au guide correspondant.
