## Objectif

Vous êtes titulaire d’un nom de domaine chez OVHcloud et vous souhaitez le connecter à un hébergement Webflow. Ce guide explique comment préparer et configurer votre zone DNS OVHcloud pour votre hébergement Webflow.

**Découvrez comment connecter votre nom de domaine OVHcloud à un hébergement Webflow**

[[fragment:support-scope]]

:::warning
L’assistance Webflow n’a pas accès aux paramètres de votre nom de domaine OVHcloud et ne peut donc pas vous conseiller sur les informations que vous devrez lui fournir.
:::


## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains) enregistré chez OVHcloud.
- Disposer des [autorisations appropriées pour gérer](/guides/account-and-service-management/account-information/managing-contacts) le nom de domaine.
- Disposer d’un hébergement chez Webflow.
- Avoir accès à la gestion de cet hébergement chez Webflow.

## En pratique

Avant de suivre les étapes de ce guide, nous vous conseillons de consulter notre guide « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) ».

:::warning
Votre zone DNS est potentiellement déjà préconfigurée ou liée à un hébergement. Nous allons voir comment identifier chaque enregistrement DNS nécessaire à la connexion avec votre hébergement Webflow. Certains devront être supprimés pour éviter de rentrer en conflit avec des enregistrements DNS requis dans cette configuration. D’autres seront simplement à modifier ou à créer. Pour une meilleure compréhension, nous utiliserons le nom de domaine « **mydomain.ovh** » comme exemple. Remplacez celui-ci par votre nom de domaine lors de la configuration.

:::

### 1. Configurer votre hébergement Webflow

Préparez d’abord votre hébergement Webflow en suivant les instructions de la section **How to connect your custom domain** depuis [**cette page de la documentation Webflow**](https://university.webflow.com/lesson/manually-connect-a-custom-domain?topics=hosting-code-export#how-to-connect-your-custom-domain).

### 2. Configurer vos enregistrements DNS sur votre compte OVHcloud

:::warning
Avant de poursuivre :

- Ouvrez un onglet en parallèle sur votre navigateur internet.
- Ouvrez [**cette page de la documentation Webflow**](https://university.webflow.com/lesson/manually-connect-a-custom-domain?topics=hosting-code-export).
- Positionnez-vous sur la partie « **How to set your DNS records** » de la documentation Webflow.<br/>
Les instructions suivantes vous aideront à configurer plus facilement votre zone DNS OVHcloud.

:::

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

<Tabs>
  <Tab label="Étape 1">
    Dans la section `Web Cloud`, cliquez sur <ManagerLink to="/#/web-domains/domain">Noms de domaine</ManagerLink>, sélectionnez le nom de domaine concerné, puis ouvrez l’onglet **Zone DNS**.

    <img className="thumbnail" alt="Onglet Zone DNS listant les enregistrements d’un nom de domaine" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-zone-overview.png" loading="lazy" />

Le tableau liste les enregistrements DNS du nom de domaine sélectionné.
  </Tab>
  <Tab label="Étape 2">
    **Configuration des enregistrements A**

    **1 - Identification :** filtrez les enregistrements DNS en sélectionnant le type `A` à l’aide du filtre au-dessus du tableau.

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements A" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-a.png" loading="lazy" />

Repérez les enregistrements « A » existants pour votre nom de domaine seul (exemple : `mydomain.ovh.`) et pour le sous-domaine « www » (exemple : `www.mydomain.ovh.`).

    **2 - Suppression :** supprimez tous les enregistrements « A » existants pour le sous-domaine « www ». Si plus de 2 enregistrements « A » existent pour le nom de domaine seul, supprimez les enregistrements excédentaires pour n’en conserver que 2. Pour chaque enregistrement à supprimer, sur la ligne concernée, ouvrez le menu d’actions <code className="action">⋮</code> et cliquez sur <code className="action">Supprimer l'entrée</code>.

    **3 - Modification :** modifiez chaque enregistrement « A » conservé pour le nom de domaine seul en ouvrant le menu d’actions <code className="action">⋮</code> sur la ligne concernée et en cliquant sur <code className="action">Modifier l'entrée</code>. Remplacez la cible par l’une des 2 adresses IPv4 de Webflow (une adresse différente par enregistrement) :

    - `75.2.70.75`
    - `99.83.190.102`

    Confirmez vos modifications.

    **4 - Ajout :** si moins de 2 enregistrements « A » existaient, créez les enregistrements manquants. Cliquez sur <code className="action">Ajouter une entrée</code> au-dessus du tableau, puis sélectionnez le type d’enregistrement DNS <code className="action">A</code>, laissez le champ **Sous-domaine** vide et saisissez dans le champ **Cible** chaque adresse IPv4 non encore attribuée. Cliquez sur <code className="action">Ajouter</code>.

    Passez ensuite à l’étape 3.
  </Tab>
  <Tab label="Étape 3">
    **Suppression des enregistrements AAAA**

    **1 - Identification :** filtrez les enregistrements DNS en sélectionnant le type `AAAA` à l’aide du filtre au-dessus du tableau.

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements AAAA" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-aaaa.png" loading="lazy" />

Repérez les enregistrements « AAAA » existants pour votre nom de domaine seul (exemple : `mydomain.ovh.`) et pour le sous-domaine « www » (exemple : `www.mydomain.ovh.`).

    **2 - Suppression :** supprimez tous les enregistrements « AAAA » identifiés (nom de domaine seul et sous-domaine « www ») pour éviter un conflit avec les nouveaux enregistrements DNS. Pour chaque enregistrement, sur la ligne concernée, ouvrez le menu d’actions <code className="action">⋮</code> et cliquez sur <code className="action">Supprimer l'entrée</code>.

    Si aucun enregistrement « AAAA » n’existe, passez à l’étape 4.
  </Tab>
  <Tab label="Étape 4">
    **Configuration de l’enregistrement TXT**

    **1 - Identification :** filtrez les enregistrements DNS en sélectionnant le type `TXT` à l’aide du filtre au-dessus du tableau.

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements TXT" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-txt.png" loading="lazy" />

Repérez les enregistrements « TXT » existants pour votre nom de domaine seul (exemple : `mydomain.ovh.`) et pour le sous-domaine « www » (exemple : `www.mydomain.ovh.`).

    **2 - Suppression :** supprimez tous les enregistrements « TXT » identifiés (nom de domaine seul et sous-domaine « www ») pour éviter un conflit avec les nouveaux enregistrements DNS. Pour chaque enregistrement, sur la ligne concernée, ouvrez le menu d’actions <code className="action">⋮</code> et cliquez sur <code className="action">Supprimer l'entrée</code>.

    **3 - Ajout :** créez un enregistrement TXT de vérification. Cliquez sur <code className="action">Ajouter une entrée</code> au-dessus du tableau, puis sélectionnez le type d’enregistrement DNS <code className="action">TXT</code>, saisissez `_webflow` dans le champ **Sous-domaine** et dans le champ **Cible** la valeur de type `one-time-verification=XXXXXXXX` présente dans la section <code className="action">Site settings > Publishing tab > Production</code> de votre compte Webflow. Cliquez sur <code className="action">Ajouter</code>.

    Passez ensuite à l’étape 5.
  </Tab>
  <Tab label="Étape 5">
    **Configuration de l’enregistrement CNAME**

    **1 - Identification :** filtrez les enregistrements DNS en sélectionnant le type `CNAME` à l’aide du filtre au-dessus du tableau.

    <img className="thumbnail" alt="Zone DNS filtrée sur les enregistrements CNAME" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-cname.png" loading="lazy" />

Repérez les enregistrements « CNAME » existants pour le sous-domaine « www » (exemple : `www.mydomain.ovh.`).

    **2 - Suppression :** si plusieurs enregistrements « CNAME » existent pour le sous-domaine « www », supprimez-les tous sauf un. Pour chaque enregistrement à supprimer, sur la ligne concernée, ouvrez le menu d’actions <code className="action">⋮</code> et cliquez sur <code className="action">Supprimer l'entrée</code>.

    **3 - Modification :** si un enregistrement « CNAME » existe pour le sous-domaine « www », ouvrez le menu d’actions <code className="action">⋮</code> sur la ligne concernée et cliquez sur <code className="action">Modifier l'entrée</code>. La ligne se déplie en un formulaire d’édition. Remplacez uniquement la **Cible** par `proxy-ssl.webflow.com.`. Confirmez vos modifications.

    Si aucun enregistrement « CNAME » n’existe pour le sous-domaine « www », cliquez sur <code className="action">Ajouter une entrée</code> au-dessus du tableau, puis sélectionnez le type d’enregistrement DNS <code className="action">CNAME</code>, saisissez `www` dans le champ **Sous-domaine** et `proxy-ssl.webflow.com.` dans le champ **Cible**. Cliquez sur <code className="action">Ajouter</code>.
  </Tab>
</Tabs>

La zone DNS est maintenant configurée pour pointer vers votre hébergement Webflow.

:::info
La vérification de votre nom de domaine peut prendre jusqu’à 48 heures.

:::

Si vous utilisez une offre e-mail OVHcloud ou que vous prévoyez de souscrire à l’une de [nos offres e-mail](/links/web/emails), vous devez également préparer votre zone DNS en conséquence. Consultez notre guide sur la [configuration d’un enregistrement MX](/guides/web-cloud/domains/dns-zone-mx).
