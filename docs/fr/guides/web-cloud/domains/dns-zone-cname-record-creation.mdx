## Objectif

Un enregistrement CNAME permet d’associer un sous-domaine à un nom de domaine ou sous-domaine, sans avoir à spécifier une adresse IP. Cela signifie que le sous-domaine sera redirigé vers l’adresse IP du nom de domaine ou sous-domaine cible, sans nécessiter de configuration supplémentaire.

Par exemple, si vous créez un enregistrement CNAME pour *www.domain.tld* qui pointe vers *domain.tld*, alors *www.domain.tld* utilisera la même adresse IP que *domain.tld*.

Les enregistrements CNAME sont utiles pour éviter de devoir modifier les adresses IP pour vos sous-domaines. Ils peuvent également être utilisés pour configurer des services comme les serveurs e-mail.

**Découvrez comment ajouter un enregistrement CNAME dans votre zone DNS OVHcloud.**

> **Vous avez déjà un enregistrement de type CNAME dans votre zone DNS ?** Suivez notre guide « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) ».

## Prérequis

- Disposer d’un [nom de domaine](/links/web/domains).
- Disposer d’une zone DNS associée à ce nom de domaine chez OVHcloud.

## En pratique

### Ajouter un enregistrement DNS de type CNAME pour le sous-domaine d’un nom de domaine

{/* CP-STEPS-START:ajout-sous-domaine */}

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **5** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/domains/listing">Domaines & DNS</ManagerLink>, puis choisissez le nom de domaine concerné.

    <img className="thumbnail" alt="Page Domaines & DNS et liste des noms de domaine du compte" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur l’onglet <code className="action">Zone DNS</code>, puis, au-dessus du tableau, sur <code className="action">Ajouter une entrée</code>.

    <img className="thumbnail" alt="Onglet Zone DNS d’un nom de domaine et bouton Ajouter une entrée" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Dans le formulaire qui s’ouvre au-dessus du tableau, sélectionnez `CNAME — Alias vers un autre domaine` dans la liste **Type**.

    <img className="thumbnail" alt="Liste Type du formulaire Ajouter une entrée, type CNAME sélectionné" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-cname.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Dans le champ **Sous-domaine**, renseignez le sous-domaine concerné (par exemple : `www` pour `www.domain.tld`). Dans le champ **Cible (nom d’hôte)**, renseignez le nom de domaine ou sous-domaine que vous souhaitez cibler (par exemple : `domain.tld`) : la console ajoute elle-même le point final.

    <img className="thumbnail" alt="Formulaire Ajouter une entrée de la zone DNS, enregistrement CNAME du sous-domaine www vers domain.tld" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-cname-record.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 5">
    Vérifiez l’**Aperçu de l’enregistrement**, puis cliquez sur <code className="action">Ajouter</code>.
  </Tab>
</Tabs>

{/* CP-STEPS-END:ajout-sous-domaine */}

Patientez jusqu’à **24** heures pour que la propagation de l’ajout sur le réseau DNS soit pleinement effective.

### Cas particuliers

Cliquez sur les liens ci-dessous pour plus d’informations :

<details>

<summary>Enregistrements CNAME et TXT pour un même sous-domaine</summary>

Ne configurez pas à la fois un enregistrement CNAME et un enregistrement TXT pour le même sous-domaine. En effet, cela peut entraîner des résultats aléatoires lors de la résolution DNS, car seule une réponse peut être renvoyée par requête DNS.

Par exemple, si vous avez les enregistrements suivants pour *www.domain.tld* :

- Un enregistrement CNAME pointant vers *domain.tld*.
- Un enregistrement TXT avec une valeur spécifique.

Une requête DNS pour *www.domain.tld* retournera soit la cible de l’enregistrement CNAME, soit la valeur de l’enregistrement TXT, de manière aléatoire.

</details>

<details>

<summary>Enregistrement CNAME sur un nom de domaine dans sa propre zone DNS</summary>

Par convention, **les enregistrements de type CNAME ne peuvent pas être utilisés sur un nom de domaine dans sa propre zone DNS**. En effet, le nom de domaine doit obligatoirement pointer directement vers une adresse IP avec un enregistrement de type [A](/guides/web-cloud/domains/dns-zone-a-record-creation) pour une IPv4, ou [AAAA](/guides/web-cloud/domains/dns-zone-aaaa-record-creation) pour une IPv6.

{/* CP-STEPS-START:cas-racine */}

Pour reprendre l’exemple donné plus haut, vous ne pourrez donc pas créer un enregistrement de type CNAME pour le nom de domaine *domain.tld* dans la zone DNS que vous avez créée pour celui-ci.
Vous pourrez cependant créer des enregistrements de type CNAME pour tous les sous-domaines (par exemple : *subdomain.domain.tld* ou *www.domain.tld*) du nom de domaine *domain.tld* dans la zone DNS créée pour *domain.tld*.

Dans la console OVHcloud, si vous saisissez `@` dans le champ **Sous-domaine** d’un enregistrement CNAME, le bouton <code className="action">Ajouter</code> reste désactivé et le formulaire affiche le message « Un enregistrement CNAME ne peut pas être créé à la racine du domaine (@). Vous pouvez utiliser le pointage SVCB. »

{/* CP-STEPS-END:cas-racine */}

</details>
