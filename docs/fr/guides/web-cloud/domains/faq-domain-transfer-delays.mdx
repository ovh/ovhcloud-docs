## Objectif

**Retrouvez ici les délais de transfert constatés pour chaque extension, ainsi que les réponses aux questions les plus fréquentes sur le déroulement d'un transfert.**

## En pratique

### Connaître le délai de transfert de son nom de domaine

**Combien de temps prend le transfert de mon nom de domaine ?**

Le délai dépend de l'extension de votre nom de domaine, car chaque registre applique ses propres règles. Consultez le tableau ci-dessous pour connaître le délai de votre extension.

| Catégorie | Extension | Délai de transfert |
|---|---|---|
| Extensions génériques | .com | 7 à 9 jours |
| | .net | 6 à 8 jours |
| | .org | 5 à 10 jours |
| | .info | 5 à 10 jours |
| | .io | 5 à 10 jours |
| Extensions européennes | .fr | 4 à 6 jours |
| | .eu | 3 à 5 jours |
| | .be | 3 à 5 jours |
| | .ch | 5 à 10 jours |
| | .de | 5 à 10 jours |
| | .es | 7 à 9 jours |
| | .it | 1 à 3 jours |
| | .lu | 5 à 10 jours |

> Si votre extension n'est pas dans ce tableau, vous pouvez retrouver les fiches de [toutes les extensions disponibles](https://www.ovhcloud.com/fr/domains/tld/).

### Comprendre le déroulement du transfert

**À partir de quand le délai de transfert commence-t-il ?**

Le délai commence à courir une fois votre demande de transfert validée, c'est-à-dire lorsque le code de transfert (code AUTH) est correct et que le nom de domaine est déverrouillé chez votre bureau d'enregistrement actuel.

**Pourquoi mon transfert prend-il plus de temps que prévu ?**

Plusieurs raisons peuvent allonger le délai de transfert :

- le code de transfert renseigné est incorrect ou a expiré ;
- le nom de domaine est toujours verrouillé chez votre bureau d'enregistrement actuel ;
- une validation par e-mail est attendue de la part du titulaire ou du contact administrateur ;
- le registre de l'extension traite la demande plus lentement que d'habitude.

:::tip
Avant de lancer votre transfert, vérifiez que l'adresse e-mail du titulaire du nom de domaine est valide. Vous pouvez la consulter avec un outil WHOIS.
:::

**Mon site web et mes e-mails seront-ils coupés pendant le transfert ?**

Non, si les serveurs DNS de votre nom de domaine restent inchangés pendant le transfert. Nous vous recommandons de ne pas modifier votre configuration DNS tant que le transfert n'est pas finalisé. Si besoin, vous pouvez contacter le support pour anticiper votre transfert.
