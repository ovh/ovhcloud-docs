## Objectif

La console OVHcloud vous permet de consulter et télécharger l'historique de vos SMS envoyés. Ce guide vous décrit comment effectuer ces actions.

## Prérequis

- Disposer d'un [compte SMS OVHcloud](/links/telecom/sms) avec au moins 1 SMS envoyé.

## En pratique

{/* CP-STEPS-START:en-pratique */}

L'historique comprend la date, l'heure, le type, l'expéditeur, le destinataire, le contenu et le statut de chaque SMS.

:::info

La console OVHcloud vous permet de consulter les SMS envoyés au cours des 6 derniers mois (ou les 5000 derniers SMS si vous avez envoyé plus de 5000 SMS au cours des 6 derniers mois).

Pour consulter des SMS plus anciens (jusqu'aux 12 derniers mois), vous devez télécharger l'historique de vos SMS au format CSV. Consultez [l'étape 2 de ce guide](#csv).

:::

{/* CP-STEPS-END:en-pratique */}

### Étape 1 : Consulter l'historique dans la console OVHcloud

{/* CP-STEPS-START:consulter-historique */}

Cliquez sur l'onglet <code className="action">SMS & Campagnes</code>. L'historique s'affiche directement dans cet onglet : sélectionnez **SMS** pour afficher l'historique de vos SMS unitaires, ou **Campagnes** pour afficher la liste de vos campagnes de SMS. Les statistiques de vos campagnes figurent dans l'onglet <code className="action">Vue d'ensemble</code>.

Par défaut, la liste affiche les SMS des 7 derniers jours. Pour afficher une autre période, modifiez-la depuis <code className="action">Filtres</code> (voir ci-dessous).

<img className="thumbnail" alt="Historique des SMS dans l'onglet SMS & Campagnes de la console OVHcloud" src="/images/web-cloud/messaging/sms/sms-history/console/sms-history-list.png" loading="lazy" />

Les SMS les plus récents s'affichent en premier.

Le bouton <code className="action">⋮</code> à droite de chaque SMS vous permet de le consulter (<code className="action">Voir</code>) ou de le supprimer (<code className="action">Supprimer</code>).

<img className="thumbnail" alt="Menu d'un SMS de l'historique avec les options Voir et Supprimer" src="/images/web-cloud/messaging/sms/sms-history/console/sms-row-menu.png" loading="lazy" />

Pour supprimer plusieurs SMS à la fois, cochez les cases à côté de chacun d'entre eux. Le bouton <code className="action">Supprimer</code>, suivi du nombre de SMS sélectionnés (par exemple <code className="action">Supprimer (1)</code>), apparaît au-dessus de l'historique, à côté de <code className="action">Actions</code>.

<img className="thumbnail" alt="Bouton Supprimer affiché au-dessus de l'historique après la sélection d'un SMS" src="/images/web-cloud/messaging/sms/sms-history/console/delete-selected-sms.png" loading="lazy" />

{/* CP-STEPS-END:consulter-historique */}

{/* CP-STEPS-START:filtrer-historique */}

Depuis <code className="action">Filtres</code>, vous pouvez filtrer l'historique par type (**Envoyés**, **Reçus** ou **Planifiés**), par période (**Aujourd'hui**, **7 derniers jours**, **30 derniers jours**, **Cette année** ou **Personnalisé**), par expéditeur, par destinataire ou par statut (**Livré**, **En cours**, **Échec temporaire** ou **Échoué**).

<img className="thumbnail" alt="Menu déroulant Filtres avec les filtres Type, Période, Expéditeur, Destinataire et Statut" src="/images/web-cloud/messaging/sms/sms-history/console/history-filters.png" loading="lazy" />

{/* CP-STEPS-END:filtrer-historique */}
 
### Étape 2 : Télécharger l'historique de vos SMS en CSV <a name="csv"></a>

{/* CP-STEPS-START:telecharger-historique-csv */}

Cliquez sur le bouton <code className="action">Actions</code> au-dessus de votre historique, puis sur <code className="action">Exporter en CSV</code> pour télécharger l'historique de vos SMS au format « .csv ».

<img className="thumbnail" alt="Menu Actions avec l'option Exporter en CSV" src="/images/web-cloud/messaging/sms/sms-history/console/actions-export-csv.png" loading="lazy" />

{/* CP-STEPS-END:telecharger-historique-csv */}

Vous pourrez alors consulter l'historique depuis un outil de type tableur. Les informations s'afficheront comme dans l'exemple ci-dessous.

<img className="thumbnail" alt="sms-history" src="/images/web-cloud/messaging/sms/sms-history/smshistory7.png" loading="lazy" />

Voici le détail des informations contenues dans cet historique :

|  Titre  |  Description  |
|  :-----          |  :-----          |
|  id |  l'identifiant unique sur nos serveurs du SMS envoyé |
|  date | la date et heure d'envoi du SMS  |
|  sender |  l'expéditeur depuis lequel le SMS a été envoyé |
|  receiver |  le numéro du mobile destinataire du SMS |
|  ptt |  le code de retour sur le statut du SMS |
|  operatorCode |  l'identifiant réseau de l'opérateur mobile à qui nous avons transmis le SMS |
|  descriptionDlr |  la description du code ptt reçu et donc du statut du SMS |
|  tag |  le tag attribué manuellement via les API (à un ou plusieurs SMS) ou automatiquement par nos serveurs à chacun des SMS (ou chaque campagne de SMS) envoyés |
|  message |  le contenu du SMS |

Vous trouverez plus de détails sur les codes ptt et les différents ID du DLR en consultant la dernière section du guide [Tout savoir sur les utilisateurs SMS](/guides/web-cloud/messaging/sms/sms-users#callback-url).
