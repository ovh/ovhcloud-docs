## Objectif

Avant d'envoyer un SMS, une requête [Home Location Register (HLR) Lookup](https://www.ovhcloud.com/fr/sms/home-location-register/) permet de vérifier si le numéro de téléphone mobile du destinataire est toujours valide et actif. Le résultat indique également l'opérateur auquel le numéro est rattaché.

En vérifiant vos numéros avec le HLR Lookup, vous améliorez la délivrabilité de vos campagnes SMS et évitez les échecs d'envoi.

<img className="thumbnail" alt="Schéma du flux HLR : tri des numéros valides et inactifs avant envoi" src="/images/web-cloud/messaging/sms/sms-hlr/img_4065.png" loading="lazy" />

Le HLR Lookup permet également de nettoyer vos listes de numéros en identifiant les numéros inactifs ou non attribués, afin de maintenir un fichier client à jour.

<img className="thumbnail" alt="Schéma du nettoyage d'une liste de numéros via HLR" src="/images/web-cloud/messaging/sms/sms-hlr/img_4067.png" loading="lazy" />

:::info
Le HLR Lookup est une action indépendante de l'envoi de SMS. C'est à vous de l'effectuer avant chaque campagne ou lors du nettoyage de vos listes de contacts.

:::

**Ce guide vous explique comment utiliser le HLR Lookup depuis la console OVHcloud.**

## Prérequis

- Disposer d'un [compte SMS OVHcloud](/links/telecom/sms) avec des crédits SMS.

[[cpnav:telecom-sms]]

## En pratique

{/* CP-STEPS-START:cp-access */}

<img className="thumbnail" alt="Liste des comptes SMS dans la console OVHcloud" src="/images/assets/screens/console/product-selection/web-cloud/sms-account-list.png" loading="lazy" />

Sélectionnez l'onglet <code className="action">SMS & Campagnes</code>, puis cliquez sur le bouton <code className="action">Actions</code>.

<img className="thumbnail" alt="Menu Actions de l'onglet SMS & Campagnes, avec l'option HLR" src="/images/web-cloud/messaging/sms/sms-hlr/console/actions-hlr.png" loading="lazy" />

Dans le menu qui s'affiche, cliquez sur <code className="action">HLR</code>.

<img className="thumbnail" alt="Page HLR dans la console OVHcloud" src="/images/web-cloud/messaging/sms/sms-hlr/console/hlr-page.png" loading="lazy" />

{/* CP-STEPS-END:cp-access */}

### Nouvelle requête HLR

{/* CP-STEPS-START:nouvelle-requete-hlr */}

Cliquez sur <code className="action">Envoyer une requête HLR</code>. Dans la fenêtre **Nouvelle requête HLR** qui s'ouvre, renseignez le numéro à tester dans le champ **Numéro de téléphone**, cochez la case **J'accepte les conditions particulières d'utilisation du service.**, puis cliquez sur <code className="action">Envoyer</code>.

<img className="thumbnail" alt="Fenêtre Nouvelle requête HLR avec le champ Numéro de téléphone" src="/images/web-cloud/messaging/sms/sms-hlr/console/hlr-new-request.png" loading="lazy" />

{/* CP-STEPS-END:nouvelle-requete-hlr */}

Chaque requête est facturée 0,1 crédit SMS. Consultez la [grille tarifaire SMS](/links/telecom/sms-prices) pour plus de détails.

### Consulter les requêtes passées

{/* CP-STEPS-START:consulter-requetes-passees */}

Les résultats de vos requêtes apparaissent dans le tableau en bas de page.

<img className="thumbnail" alt="Tableau des résultats de requêtes HLR" src="/images/web-cloud/messaging/sms/sms-hlr/console/hlr-results-table.png" loading="lazy" />

{/* CP-STEPS-END:consulter-requetes-passees */}

### Les différents états

{/* CP-STEPS-START:differents-etats */}

Les rapports HLR indiquent, dans les colonnes du tableau :

- **Date** : la date de la requête HLR ;
- **Coût** : le coût de la requête HLR (par exemple « 0,1 crédit ») ;
- **Statut** : le statut de la requête HLR (**En attente**, **En cours**, **Terminé** ou **Erreur**) ;
- **Numéro** : le numéro du destinataire ;
- **Opérateur** : l'opérateur du destinataire ;
- **Valide** : la validité du numéro du destinataire (**Oui** ou **Non**) ;
- **Joignable** : la joignabilité du destinataire (**Oui** ou **Non**) ;
- **Porté** : le statut porté du destinataire (**Oui** ou **Non**) ;
- **Itinérant** : le statut en itinérance du destinataire (**Oui** ou **Non**).

{/* CP-STEPS-END:differents-etats */}
### Importation du fichier de destinataires

{/* CP-STEPS-START:importation-fichier-destinataires */}

Cliquez sur l'onglet <code className="action">Destinataires</code>, puis sur <code className="action">Ajouter une liste</code>.

<img className="thumbnail" alt="Onglet Destinataires et bouton Ajouter une liste" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/console/recipients-add-list.png" loading="lazy" />

Dans le panneau **Ajouter une liste de destinataires** qui s'ouvre, ajoutez votre fichier au format `.csv` ou `.txt` dans la zone **Fichier CSV (.csv, .txt)**.

<img className="thumbnail" alt="Panneau Ajouter une liste de destinataires" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/console/add-recipient-list-panel.png" loading="lazy" />

{/* CP-STEPS-END:importation-fichier-destinataires */}

Consultez le guide « [Liste de destinataires SMS](/guides/web-cloud/messaging/sms/liste-de-destinataire-sms) » pour plus de détails.

### Nettoyer le fichier

{/* CP-STEPS-START:nettoyer-le-fichier */}

Une fois votre liste chargée dans la console OVHcloud, cliquez sur le bouton <code className="action">⋮</code> de sa ligne dans l'onglet <code className="action">Destinataires</code>, puis sur <code className="action">Nettoyer</code>.

<img className="thumbnail" alt="Option Nettoyer du menu d'une liste de destinataires" src="/images/web-cloud/messaging/sms/sms-hlr/console/recipient-list-clean.png" loading="lazy" />

Dans la fenêtre **Nettoyer la liste**, 2 options sont disponibles :

- **Freemium** : dédoublonnage et vérification de la syntaxe (gratuit).
- **Premium** : dédoublonnage, puis vérification auprès de l'opérateur que chaque numéro existe, via une requête HLR (cette action sera facturée 0,1 crédit SMS par contact).

Sélectionnez l'option souhaitée, puis cliquez sur <code className="action">Nettoyer</code>.

<img className="thumbnail" alt="Fenêtre Nettoyer la liste avec les options Freemium et Premium" src="/images/web-cloud/messaging/sms/sms-hlr/console/clean-list-options.png" loading="lazy" />

Le nettoyage de la base dédoublonnera vos contacts et éliminera ceux qui sont invalides.
La liste nettoyée remplacera l'ancienne, qui sera sauvegardée et accessible. Vous recevrez un rapport par e-mail à la fin de l'opération.

{/* CP-STEPS-END:nettoyer-le-fichier */}
