## Objectif

Tous les comptes SMS OVHcloud peuvent utiliser un ou plusieurs carnets d'adresses. Ce guide décrit comment les créer dans la console OVHcloud.

## Prérequis

- Disposer d'un [compte SMS OVHcloud](/links/telecom/sms).
- Disposer d'un outil de type tableur ou éditeur de texte.

## En pratique

### Étape 1 : Créer un carnet d'adresses dans la console OVHcloud

{/* CP-STEPS-START:creer-carnet */}

Choisissez l'onglet <code className="action">Contacts</code>.

<img className="thumbnail" alt="Onglet Contacts d'un compte SMS dans la console OVHcloud" src="/images/web-cloud/messaging/sms/sms-address-books/console/contacts-tab.png" loading="lazy" />

Cliquez sur <code className="action">Actions</code> puis sur <code className="action">Créer un carnet</code>. Dans la fenêtre **Créer un carnet d'adresses**, nommez votre nouveau carnet dans le champ **Nom**, puis cliquez sur <code className="action">Créer</code>.

<img className="thumbnail" alt="Fenêtre Créer un carnet d'adresses ouverte depuis le menu Actions de l'onglet Contacts" src="/images/web-cloud/messaging/sms/sms-address-books/console/create-address-book.png" loading="lazy" />

{/* CP-STEPS-END:creer-carnet */}

### Étape 2 : Ajouter des contacts dans votre carnet

Le carnet d'adresses est maintenant créé mais ne contient aucun contact. Plusieurs méthodes existent pour ajouter vos contacts.

### Ajout unitaire de contacts depuis la console OVHcloud

{/* CP-STEPS-START:ajout-unitaire-contact */}

Cliquez sur le bouton <code className="action">Ajouter un contact</code>, au-dessus de la liste des contacts.

<img className="thumbnail" alt="Bouton Ajouter un contact dans l'onglet Contacts d'un compte SMS" src="/images/web-cloud/messaging/sms/sms-address-books/console/add-contact-button.png" loading="lazy" />

Dans le panneau **Ajouter un contact**, renseignez les informations du contact : prénom, nom, société (facultatif) et numéros de téléphone fixe et mobile, domicile et professionnel.

<img className="thumbnail" alt="Panneau Ajouter un contact avec les champs du contact et ses numéros de téléphone" src="/images/web-cloud/messaging/sms/sms-address-books/console/add-contact-panel.png" loading="lazy" />

Remplissez les champs souhaités (au moins un numéro de téléphone est obligatoire), puis cliquez sur <code className="action">Enregistrer</code>. Le contact est alors ajouté à votre carnet. Répétez l'opération pour ajouter d'autres contacts.

{/* CP-STEPS-END:ajout-unitaire-contact */}

### Ajout de contacts multiples via un import de fichier de contacts depuis la console OVHcloud

#### Préparation du fichier dans votre tableur

Si vous souhaitez utiliser ou créer un document au format tableur, il vous faudra le présenter comme ci-dessous et l'exporter au format «.csv ».

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook-spreadsheet1.png" loading="lazy" />

Vous pouvez télécharger un <a href="/images/guides/web-cloud/messaging/sms/sms-address-books/phonebook.csv" download>modèle de carnet d'adresses au format .csv</a> à compléter par vos soins.

La grande majorité des tableurs ne prendra pas en compte le format international attendu pour les numéros de téléphone / fax (+33xxxxxxxxx). Il vous faudra donc modifier le format des cellules comportant ces numéros (workPhone, workMobile, ...). Pour ce faire, sélectionnez les colonnes concernées et appliquez un format “Texte” sur celles-ci.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook-spreadsheet2.png" loading="lazy" />

Une fois le document prêt, sauvegardez le au format tableur pour le modifier ultérieurement.

En parallèle, enregistrez-le ou exportez-le au format «.csv » afin d'en préparer l'import.

:::info
**Recommandations**

Enregistrez votre fichier tableur au format «.csv » (séparateur : point-virgule).

Les caractères spéciaux comme les accents ne sont pas acceptés dans l’import du fichier «.csv », les contacts comprenant ce type de caractères ne seront pas importés.

Respectez la forme internationale +33xxxxxxxxx pour vos numéros.

Nous conseillons des carnets d’adresses ne dépassant pas 2000 contacts.

Tous vos contacts devront être sur la même feuille de votre tableur.
:::

#### Import du fichier dans la console OVHcloud

{/* CP-STEPS-START:import-fichier-contacts */}

De retour dans la console OVHcloud, cliquez sur <code className="action">Actions</code> puis sur <code className="action">Importer</code>.

<img className="thumbnail" alt="Option Importer du menu Actions dans l'onglet Contacts" src="/images/web-cloud/messaging/sms/sms-address-books/console/actions-import.png" loading="lazy" />

Dans la fenêtre **Importer des contacts**, cliquez sur <code className="action">Parcourir les fichiers</code> pour sélectionner votre fichier « .csv », puis cliquez sur <code className="action">Importer</code>. Les contacts du fichier sont ajoutés au carnet sélectionné. La première ligne du fichier doit reprendre les en-têtes de colonnes du modèle (`group`, `surname`, `name`, `workPhone`, `workMobile`, `homePhone`, `homeMobile`) ; leur ordre est sans importance. Un fichier exporté depuis la console OVHcloud ne peut pas être réimporté tel quel : remplacez d'abord ses en-têtes par ceux du modèle.

<img className="thumbnail" alt="Fenêtre Importer des contacts avec la zone de sélection du fichier CSV" src="/images/web-cloud/messaging/sms/sms-address-books/console/import-contacts.png" loading="lazy" />

Patientez quelques secondes pendant le chargement du fichier dans la console OVHcloud.

{/* CP-STEPS-END:import-fichier-contacts */}

### Étape 3 : Éditer ou supprimer un carnet d'adresses

{/* CP-STEPS-START:renommer-carnet */}

Si vous souhaitez modifier le nom d'un carnet d'adresses, sélectionnez votre carnet dans le menu déroulant **Carnet de contacts** (si vous avez créé plusieurs carnets), puis cliquez sur <code className="action">Actions</code> et sur <code className="action">Renommer</code>. Dans la fenêtre **Renommer le répertoire**, saisissez le nouveau nom dans le champ **Nom**, puis cliquez sur <code className="action">Renommer</code>.

{/* CP-STEPS-END:renommer-carnet */}

{/* CP-STEPS-START:supprimer-carnet-editer-contact */}

Pour supprimer un carnet, sélectionnez-le dans le menu déroulant **Carnet de contacts**, puis cliquez sur <code className="action">Actions</code> et sur <code className="action">Supprimer</code>. Confirmez la suppression en cliquant sur <code className="action">Supprimer</code> dans la fenêtre **Confirmer la suppression**.

:::warning

La suppression d'un carnet d'adresses est irréversible.

:::

Pour modifier ou supprimer un contact, cliquez sur le bouton <code className="action">⋮</code> à la fin de la ligne du contact choisi, puis sur <code className="action">Modifier</code> ou <code className="action">Supprimer</code>.

<img className="thumbnail" alt="Menu d'un contact avec les options Modifier et Supprimer dans l'onglet Contacts" src="/images/web-cloud/messaging/sms/sms-address-books/console/contact-row-menu.png" loading="lazy" />

{/* CP-STEPS-END:supprimer-carnet-editer-contact */}
