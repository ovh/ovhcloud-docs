## Objectif

Ce guide vous explique comment créer et utiliser des expéditeurs pour l’envoi de vos SMS.

## Prérequis

- Disposer d'un [compte SMS OVHcloud](/links/telecom/sms).

## En pratique

### Types d'expéditeurs disponibles

OVHcloud vous permet de choisir un type d’expéditeur pour envoyer vos SMS.

L'expéditeur « Numéro court permettant la réponse » est disponible par défaut sur nos solutions SMS, il vous est cependant possible d'utiliser un expéditeur alphanumérique ou encore un numéro mobile virtuel.

#### Numéro court permettant la réponse

**Uniquement pour les comptes OVHcloud en France hors DOM-TOM.**

Il permet de recevoir une réponse via <code className="action">Message et campagne</code> > <code className="action">Gestion des SMS</code> > <code className="action">SMS reçus</code>.

:::warning
**Envoi de SMS contenant une URL**

Il n'est pas possible d'envoyer un SMS contenant une URL via un numéro court permettant la réponse. Tout envoi de ce type sera bloqué.

Si vous avez besoin d'envoyer des SMS contenant des URLs, vous devez utiliser un expéditeur alphanumérique.

:::

#### Expéditeur alphanumérique

Vous pouvez personnaliser votre expéditeur. Il n'est alors plus possible de recevoir une réponse de la part du destinataire de votre SMS. Pour accéder à la gestion des expéditeurs SMS, sélectionnez l'onglet <code className="action">Expéditeurs</code> (1) lorsque vous êtes sur le compte SMS concerné.

<img className="thumbnail" alt="envoi sms manager" src="/images/web-cloud/messaging/sms/sms-senders/sms-send-control-panel04E.png" loading="lazy" />

Si vous souhaitez ajouter un expéditeur SMS supplémentaire, cliquez sur le bouton <code className="action">Actions</code> au centre puis sur <code className="action">Ajouter</code> (2).

<img className="thumbnail" alt="envoi sms manager" src="/images/web-cloud/messaging/sms/sms-senders/sms-send-control-panel05E.png" loading="lazy" />

Une fois sur la page d'ajout, vous disposez de plusieurs options pour configurer un nouvel expéditeur SMS (3) :

- **Ajouter manuellement des expéditeurs** : Vous devez saisir l'expéditeur souhaité, la description et une justification pour l'utilisation de cet expéditeur (4). Une pièce justificative est également nécessaire.

**Exemple** : si vous souhaitez envoyer votre SMS avec le nom de votre société comme expéditeur, un justificatif de la société vous sera demandé.

La validation d'un expéditeur alphanumérique est effectuée en moyenne dans les 72 heures après sa création.

:::info
Nous vous demandons un justificatif dans le cadre de notre politique de sécurité. Il s'agit par défaut d'un papier à en-tête de la société ou de la marque, incluant l'autorisation d'un responsable avec signature et tampon de cette même société, d'un papier d'identité, ou extrait Kbis si ce n'est pas une marque déposée.

:::

- **Ajouter des expéditeurs à partir de données personnelles** : Vous pouvez demander un expéditeur se basant sur les coordonnées de votre compte OVHcloud. Une liste déroulante des expéditeurs disponibles s'affichera alors.

- **Ajouter des expéditeurs à partir de vos noms de domaines OVHcloud** : Vous pouvez utiliser un nom de domaine disponible dans votre compte OVHcloud en tant qu'expéditeur. Une liste déroulante des expéditeurs disponibles s'affichera alors.

##### Spécificités par pays <a name="country-specific-requirements"></a>

<details>
<summary>Espagne</summary>

L'Espagne impose une déclaration préalable de tout expéditeur alphanumérique auprès de son régulateur, la CNMC (Comisión Nacional de los Mercados y la Competencia). Cette obligation s'applique lorsque vous souhaitez créer ou faire valider un expéditeur alphanumérique pour envoyer des SMS vers l'Espagne.

**Informations à transmettre**

À la création d'un nouvel expéditeur alphanumérique pour l'Espagne, fournissez les informations suivantes :

| Information | Description |
|---|---|
| Alias | L'expéditeur alphanumérique à déclarer |
| Titulaire de l'expéditeur alphanumérique | Personne morale (*Legal*) ou personne physique (*Natural*) |
| Numéro d'identification fiscale (NIF) | NIF du titulaire (numéro de TVA pour une personne morale, ou copie recto verso de la pièce d'identité pour une personne physique) |
| Raison sociale ou nom et prénom(s) | Du titulaire |
| Représentant de l'expéditeur alphanumérique | NIF, nom, prénom(s), adresse et e-mail du représentant (personne morale ou physique). Si le représentant est une personne morale, indiquez également les informations de la personne physique qui la représente. |
| Tiers impliqué (*Tercero*) | Informations sur un éventuel tiers impliqué (hors OVHcloud) dans l'envoi, ou confirmation qu'il s'agit d'un envoi direct. Par exemple, une marque titulaire de l'alias « MaMarque » confie ses envois à son agence marketing, qui déclenche alors les campagnes via OVHcloud. L'agence est le *Tercero* : elle exploite l'alias pour le compte du titulaire sans être elle-même titulaire. |

:::warning
Toutes les informations du tableau sont obligatoires : une demande incomplète risque d'être refusée.

:::

**Ouvrir la demande**

Demandez d'abord votre expéditeur alphanumérique dans l'espace client OVHcloud, puis adressez cette déclaration au support OVHcloud :

1. Rendez-vous sur le [centre d'aide OVHcloud](/links/support-contact).
2. Créez une demande d'assistance en précisant qu'il s'agit d'une **déclaration de Sender ID SMS pour l'Espagne**.
3. Transmettez les informations listées ci-dessus.

:::info
Tant que la CNMC n'a pas validé la déclaration, vos destinataires en Espagne voient un numéro de téléphone à la place de votre expéditeur alphanumérique. La déclaration ne se fait qu'une fois par expéditeur : une fois validée, vous pouvez utiliser l'expéditeur autant de fois que nécessaire.

:::

</details>

#### Numéro mobile virtuel

**Uniquement pour les comptes OVHcloud en France.**

Si vous disposez d'une offre SMS avec numéro mobile virtuel, vous pouvez renseigner celui-ci comme expéditeur. Pour plus d'informations, consultez notre [page sur le numéro mobile virtuel](/links/telecom/sms-vln).

:::info
Si vous disposez déjà d'un compte SMS, la création d'un numéro mobile virtuel pour ce compte existant est impossible. Il sera nécessaire de commander un nouveau compte SMS via la page de l'offre [numéro mobile virtuel](/links/telecom/sms-vln).

:::
