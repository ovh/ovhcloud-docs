## Objectif

L'envoi de SMS aux États-Unis est soumis à des règles spécifiques. Ce guide vous les explique et vous montre comment les appliquer.

## Prérequis

- Disposer d'un [compte SMS OVHcloud](/links/telecom/sms) avec des crédits SMS.
- Avoir accès aux <ApiLink>API OVHcloud</ApiLink> (uniquement pour la méthode d'envoi via API).

## En pratique

### Étape 1 : Connaître les restrictions

En accord avec l'autorité de régulation des SMS des États-Unis (Neustar), l'envoi de SMS vers cette destination doit faire l'objet d'une validation préalable par nos services d'un modèle de message.
Seuls les messages d’alerte et de double authentification sont autorisés et aucun modèle de SMS publicitaire ne sera accepté. Une fois votre modèle validé, l’envoi se fera de la même manière que pour les autres destinations.

Vous pouvez demander la validation de plusieurs modèles de messages.

:::info
La validation des modèles de messages est gratuite et effectuée par les équipes de OVHcloud sous un à deux jours ouvrés.

:::

### Étape 2 : Ajouter un modèle

#### 2.1 Depuis la console OVHcloud

{/* CP-STEPS-START:ajouter-modele-espace-client */}

Cliquez sur l'onglet <code className="action">SMS & Campagnes</code>.

Ouvrez ensuite le menu déroulant <code className="action">Actions</code>, puis cliquez sur <code className="action">Modèles</code>.

<img className="thumbnail" alt="Onglet SMS & Campagnes d'un compte SMS, menu Actions ouvert sur l'entrée Modèles" src="/images/web-cloud/messaging/sms/envoi-de-sms-aux-etats-unis/console/sms-campaigns-actions-templates.png" loading="lazy" />

Sur la page **Modèles** qui s'affiche alors, cliquez sur <code className="action">Ajouter un modèle</code>.

<img className="thumbnail" alt="Page Modèles d'un compte SMS avec le bouton Ajouter un modèle" src="/images/web-cloud/messaging/sms/envoi-de-sms-aux-etats-unis/console/templates-add-template.png" loading="lazy" />

Le panneau **Ajouter un modèle** s'ouvre avec les champs à remplir.

<img className="thumbnail" alt="Panneau Ajouter un modèle avec les champs Nom, Type d'activité, Description et Message" src="/images/web-cloud/messaging/sms/envoi-de-sms-aux-etats-unis/console/add-template-panel.png" loading="lazy" />

| Champ           | Description                                                                                       |
|-----------------|---------------------------------------------------------------------------------------------------|
| Nom             | Nom du modèle (obligatoire)                                                                       |
| Type d'activité | Sélectionnez le type de modèle :<br/>- Alerte<br/>- Authentification<br/>- Transactionnel         |
| Description     | Description de l'usage du modèle (obligatoire)                                                    |
| Message         | Contenu du modèle, chaque partie variable étant délimitée par le caractère # (obligatoire)        |

Renseignez les champs, puis cliquez sur <code className="action">Enregistrer</code>.

{/* CP-STEPS-END:ajouter-modele-espace-client */}

#### 2.2 Via les API

:::tip
Si vous n'êtes pas familier avec l'utilisation de l'API OVHcloud, consultez notre guide « [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps) ».

:::

Rendez-vous sur l'<ApiLink>API OVHcloud</ApiLink> puis utilisez l’API suivante :

<Api version="v1" section="/sms" method="POST" route={"/sms/\{serviceName\}/templatesControl"} />

Remplissez les champs requis et cliquez sur <code className="action">Execute</code>.

#### Exemples de modèles

Vous trouverez ci-dessous 2 exemples de modèles de messages à destination des États-Unis.

- Exemple de template d'authentification :

```bash
Your security code is #CODE#, have a good day
```

- Exemple de template d'alerte :

```bash
Our monitoring system detected your server #SERVER# doesn't respond to ping requests
```

### Étape 3 : Analyser les retours

Une fois votre modèle de message créé et validé, l'envoi d'un SMS génère une comparaison automatique de son contenu avec vos modèles. Si la comparaison est positive, le SMS est envoyé de manière identique à un envoi vers une autre destination.

Si vous envoyez un SMS aux États-Unis sans avoir au préalable créé et validé un modèle, le SMS sera refusé et un Premium Tracking Transaction Code (PTT code) à 1999 vous sera adressé. Ce code correspond au message d'erreur « No templates available » (pas de modèle de messages créé).

Vous pouvez consulter les autres codes de retour possibles sur le guide « [Tout savoir sur les utilisateurs SMS](/guides/web-cloud/messaging/sms/sms-users) ».
