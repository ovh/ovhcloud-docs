## Objectif

L'Espagne impose une déclaration préalable de tout expéditeur alphanumérique (Sender ID) auprès de son régulateur (CNMC). Ce guide vous explique quelles informations transmettre et comment ouvrir la demande.

## Prérequis

- Disposer d'un [compte SMS OVHcloud](/links/telecom/sms).
- Souhaiter créer ou faire valider un [expéditeur alphanumérique](/guides/web-cloud/messaging/sms/sms-senders#expediteur-alphanumerique) pour envoyer des SMS vers l'Espagne.

## En pratique

### Informations à transmettre

À la création d'un nouveau Sender ID pour l'Espagne, les informations suivantes doivent être fournies :

| Information | Description |
|---|---|
| Alias (Sender ID) | L'expéditeur alphanumérique à déclarer |
| Titulaire du Sender ID | Personne morale (Legal) ou personne physique (Natural) |
| Numéro d'Identification Fiscale (NIF) | NIF du titulaire (numéro de TVA dans le cas d'une personne morale ou pièce d'identité dans le cas d'une personne physique) |
| Raison sociale ou nom et prénom(s) | Du titulaire |
| Représentant du Sender ID | NIF, nom, prénom(s), adresse et email du représentant (personne morale ou physique). Dans le cas d'une personne morale, il sera necessaire de completer ici les informations du representant de cette personne morale |
| Tiers impliqué (TERCERO) | Informations sur un éventuel tiers impliqué (hors OVHCloud) dans l'envoi, ou confirmation qu'il s'agit d'un envoi direct. Par exemple une marque titulaire de l'alias MaMarque confie ses envois à son agence marketing, qui déclenche alors les campagnes via OVHcloud. L'agence est le Tercero : elle exploite l'alias pour le compte du titulaire sans être lui-même titulaire |

### Ouvrir la demande

Cette déclaration se fait par l'intermédiaire du support OVHcloud :

1. Rendez-vous dans votre [espace client OVHcloud](/links/support-contact).
2. Créez une demande d'assistance en précisant qu'il s'agit d'une **déclaration de Sender ID SMS pour l'Espagne**.
3. Transmettez les informations listées ci-dessus.
