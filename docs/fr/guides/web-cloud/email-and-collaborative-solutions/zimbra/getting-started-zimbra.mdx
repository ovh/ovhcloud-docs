### Configurer votre service Zimbra <a name="zimbra-conf"></a>

Avant de débuter la configuration de vos comptes e-mail Zimbra, prenez connaissance des trois éléments qui structurent hiérarchiquement votre service Zimbra :

- [**Organisation**](#organizations) : elle permet de regrouper les noms de domaine afin de les associer.
- [**Nom de domaine**](#domains) : il est indispensable pour créer un compte e-mail. Vous devez gérer au moins un nom de domaine depuis votre espace client OVHcloud et l'ajouter à votre service Zimbra.
- [**Comptes e-mail**](#emails) : en utilisant les noms de domaines ajoutés à votre service Zimbra, vous pourrez créer une adresse e-mail.

:::info
L'*organisation* sert à représenter une entité (une entreprise, une association, un projet personnel, etc.). Elle permet le cloisonnement des comptes e-mail, l'application de politiques de sécurité spécifiques (fonctionnalité à venir) et de déléguer les droits des comptes e-mail qui la compose (fonctionnalité à venir). L'utilisation d'organisations permet de faciliter la navigation dans votre plateforme Zimbra ainsi que sa gestion.

:::

### Organisations <a name="organizations"></a>

{/* CP-STEPS-START:organisations */}

Si vous ajoutez un grand nombre de noms de domaine sur votre service Zimbra, il peut être utile de les regrouper en les associant à une « organisation ». La page **Zimbra** de la console OVHcloud liste vos organisations : pour chacune, le tableau indique ses noms de domaine et son nombre de comptes e-mail.

<img className="thumbnail" alt="Page Zimbra de la console OVHcloud, tableau des organisations" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_organization_tab.png" loading="lazy" />

{/* CP-STEPS-END:organisations */}

#### Créer une organisation <a name="organizations-create"></a>

{/* CP-STEPS-START:creer-organisation */}

Pour créer une organisation, cliquez sur <code className="action">Créer une nouvelle organisation</code>, au-dessus du tableau des organisations. Dans la fenêtre **Ajouter une organisation**, définissez le **Nom** de l'organisation et son **Label** (de 2 à 12 caractères), ce dernier étant une description courte de l'organisation vous permettant de vous repérer lorsque vous filtrez l'affichage des noms de domaine et comptes e-mail de votre service Zimbra. Cliquez ensuite sur <code className="action">Ajouter</code>.

{/* CP-STEPS-END:creer-organisation */}

#### Filtrer par organisation <a name="organizations-filters"></a>

{/* CP-STEPS-START:filtrer-par-organisation */}

Pour afficher uniquement les éléments liés à une organisation, cliquez sur son nom dans le tableau de la page **Zimbra**. Votre service Zimbra s'ouvre alors filtré sur cette organisation : les onglets <code className="action">Compte email</code> et <code className="action">Domaines associés</code> n'affichent que les comptes e-mail et les noms de domaine liés à cette organisation.

<img className="thumbnail" alt="Tableau des organisations de la page Zimbra, nom d'une organisation mis en évidence" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_organization_filter.png" loading="lazy" />

Le filtre reste appliqué lorsque vous passez d'un onglet à l'autre. Pour retirer le filtre, cliquez sur le nom de votre service Zimbra dans le fil d'Ariane, en haut de la page.

{/* CP-STEPS-END:filtrer-par-organisation */}

#### Ajouter un nom de domaine <a name="domains-add"></a>

{/* CP-STEPS-START:ajouter-nom-de-domaine */}

:::warning
Il est nécessaire de [créer une organisation](#organizations) pour pouvoir ajouter un nom de domaine à votre service Zimbra.

:::


Pour ajouter un nom de domaine à votre service Zimbra, cliquez sur l'onglet <code className="action">Domaines associés</code> puis cliquez sur <code className="action">Ajouter un domaine</code>.

Dans le panneau **Ajouter un domaine**, sélectionnez une organisation dans le menu déroulant **Organisation** puis sélectionnez l'une des deux options suivantes :

- **Sélectionner un domaine dans la liste** (domaine interne) : dans cette liste, vous trouverez les noms de domaine dont vous avez la gestion depuis votre console OVHcloud.
- **Saisir un nom de domaine non géré par votre compte OVHcloud** (domaine externe) : renseignez un nom de domaine qui n'est pas géré dans votre console OVHcloud ou qui est enregistré dans un autre bureau d'enregistrement et dont vous avez la gestion.

Sélectionnez l'onglet correspondant à votre choix :

<Tabs>
  <Tab label="Domaine interne">
    Sélectionnez dans la liste **Nom de domaine** un nom de domaine géré depuis votre console OVHcloud.
    
    Pour configurer votre zone DNS, sélectionnez l'une des deux options de la section **Configuration** :
    
    - **Configuration recommandée** : votre zone DNS sera configurée automatiquement. Cette option convient si vous n'avez pas configuré d'offre e-mail sur votre nom de domaine.
    - **Configuration personnalisée** : si vous avez déjà configuré une offre e-mail sur votre nom de domaine, vous pouvez choisir les éléments qui vous intéressent.
       - *Configurer l'enregistrement MX automatiquement (réception des emails)* : il permet de saisir automatiquement les serveurs de réception OVHcloud (s'applique à toutes les offres e-mail OVHcloud).
       - *Configurer l'enregistrement SPF automatiquement* : il permet de saisir automatiquement l'enregistrement autorisant les serveurs e-mail d'envoi OVHcloud à transmettre vos e-mails. Cet enregistrement est valable pour l'ensemble des offres e-mail OVHcloud.
       - *Configurer l'enregistrement DKIM automatiquement* : il permet de saisir automatiquement les enregistrements nécessaires pour authentifier vos envois d'e-mails.
       - *Configurer l'enregistrement SRV automatiquement (autodiscover)* : il permet la configuration automatique des paramètres d'un compte e-mail lorsque vous l'ajoutez sur un logiciel de messagerie (Outlook, Mail pour Mac, Thunderbird, etc.).
    
    Cliquez sur <code className="action">Ajouter</code> pour finaliser l'ajout de votre domaine et lancer le processus de configuration.
  </Tab>
  <Tab label="Domaine externe">
    Saisissez dans le champ **Nom de domaine** un nom de domaine qui n'est pas géré dans votre console OVHcloud. Assurez-vous que vous avez les accès pour modifier la zone DNS du nom de domaine concerné.
    
    Cliquez ensuite sur <code className="action">Ajouter</code>.
    
    Le nom de domaine apparaît dans le tableau de l'onglet **Domaines associés**. Dans sa colonne **Statut**, l'encadré **Vérification du domaine** indique l'enregistrement CNAME à créer : il est nécessaire de renseigner cet enregistrement CNAME dans la zone DNS du nom de domaine pour qu'il soit validé sur votre plateforme Zimbra. Cliquez sur cet encadré pour afficher le détail de l'enregistrement.
    
    :::warning
    Après 48 heures, si le CNAME n'est pas visible dans la zone DNS, l'opération est annulée. Il sera alors nécessaire de recommencer l'opération.

    :::

  </Tab>
</Tabs>

#### Modifier un nom de domaine <a name="domains-modify"></a>

{/* CP-STEPS-START:modifier-nom-de-domaine */}

Vous pouvez modifier votre nom de domaine pour changer son organisation ou vérifier ses enregistrements DNS associés.

Depuis l'onglet <code className="action">Domaines associés</code> de votre service Zimbra, cliquez sur le bouton <code className="action">⋮</code> à droite du nom de domaine concerné pour afficher les options.

<img className="thumbnail" alt="Onglet Domaines associés d'un service Zimbra, menu d'un nom de domaine ouvert" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_domain_modify01.png" loading="lazy" />

- Cliquez sur <code className="action">Modifier</code> pour modifier l'organisation associée à votre nom de domaine, dans la fenêtre **Modifier le domaine**.
- Cliquez sur <code className="action">Diagnostic</code> pour afficher la page de diagnostic des enregistrements DNS du nom de domaine. Il est nécessaire de s'assurer qu'aucune alerte n'est affichée pour chacun des enregistrements DNS mentionnés dans les onglets **MX**, **SRV**, **SPF** et **DKIM**. Suivez les instructions détaillées dans chaque onglet mentionnant une alerte pour configurer les enregistrements DNS :
    - **MX** : indispensable pour la réception de vos e-mails.
    - **SPF** : sécurité exigée par la majorité des serveurs e-mail destinataires pour légitimer les serveurs d'envoi e-mail d'OVHcloud avec votre nom de domaine.
    - **DKIM** : permet de mettre en place un système de signature pour chaque e-mail envoyé par votre service Zimbra. La signature est vérifiée par le destinataire à l'aide de la clé publique visible dans votre zone DNS.
    - **SRV** : facilite la configuration de votre compte Zimbra lorsque vous le configurez sur un logiciel de messagerie (Outlook, Mail pour Mac, Thunderbird, etc.).

<img className="thumbnail" alt="Page Diagnostic d'un nom de domaine, onglet SRV en alerte" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_domain_modify02.png" loading="lazy" />

{/* CP-STEPS-END:modifier-nom-de-domaine */}

#### Créer un compte e-mail <a name="emails-create"></a>

{/* CP-STEPS-START:creer-compte-email */}

Pour créer un compte e-mail sur votre service Zimbra, cliquez sur l'onglet <code className="action">Compte email</code>, puis sur <code className="action">Nouveau compte</code> et <code className="action">Configurer un compte</code>.

Sur la page **Configurer un compte email**, complétez les informations qui s'affichent.

- **Adresse email** : renseignez le *nom du compte* que portera votre adresse e-mail (votre prénom.nom, par exemple) et *sélectionnez un nom de domaine* dans le menu déroulant.

:::warning
Le choix du nom de votre adresse e-mail doit respecter les conditions suivantes :

- Minimum 2 caractères.
- Maximum 32 caractères.
- Aucun caractère accentué.
- Pas de caractères spéciaux, à l'exception des caractères suivants : `.`, `+`, `-` et `_`. Deux de ces caractères ne peuvent pas se suivre.
- La partie précédant le « @ » doit se terminer par une lettre ou un chiffre.

:::


- **Nom** : renseignez un nom.
- **Prénom** : renseignez un prénom.
- **Nom à afficher** : renseignez le nom qui s'affichera en tant qu'expéditeur lorsque des e-mails seront envoyés depuis cette adresse.
- **Mot de passe** : définissez un mot de passe fort composé de (au minimum) 10 caractères, une majuscule, un chiffre et un caractère spécial, ou générez-en un à l'aide de l'icône en forme de clé située à droite du champ. Pour des raisons de sécurité, n'utilisez pas deux fois le même mot de passe. Choisissez-en un qui n'a aucun rapport avec vos informations personnelles (évitez par exemple de mentionner vos nom, prénom et date de naissance). Changez-le régulièrement. L'option **Forcer le changement à la prochaine connexion**, cochée par défaut, demande à l'utilisateur du compte de changer ce mot de passe lors de sa prochaine connexion.

:::warning
Le choix du mot de passe doit respecter les conditions suivantes :

- Minimum 10 caractères.
- Maximum 64 caractères.
- Minimum 1 majuscule.
- Minimum 1 chiffre.
- Minimum 1 caractère spécial.
- Aucun caractère accentué.

:::


- **Offre** : sélectionnez dans le menu déroulant l'offre du compte (Zimbra Starter ou Zimbra Pro). Le nombre de comptes encore disponibles est indiqué pour chaque offre.

Cliquez sur <code className="action">Créer</code> pour lancer la création du compte.

<img className="thumbnail" alt="Page Configurer un compte email d'un service Zimbra" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/console/zimbra_emailaccounts_add.png" loading="lazy" />

{/* CP-STEPS-END:creer-compte-email */}

#### Changer d'offre <a name="emails-offer"></a>

{/* CP-STEPS-START:changer-offre */}

Il est possible de changer l'offre de n'importe quel compte Zimbra pour une offre supérieure ou inférieure.

1. Cliquez sur l'onglet <code className="action">Compte email</code>.
1. À droite du compte e-mail pour lequel vous souhaitez basculer vers l'offre supérieure, cliquez sur <code className="action">⋮</code>.
1. Cliquez sur <code className="action">Changer d'offre</code>.
1. Sur la page **Sélectionnez votre nouvelle offre**, choisissez l'offre souhaitée, puis cliquez sur <code className="action">Continuer ma commande</code>.

<img className="thumbnail" alt="Onglet Compte email d'un service Zimbra, menu d'un compte e-mail ouvert" src="/images/assets/screens/email-clients/zimbra/console/zimbra-change-offer.png" loading="lazy" />

{/* CP-STEPS-END:changer-offre */}

:::warning
Avant de basculer vers une offre inférieure, assurez-vous des points suivants :

- Aucun fichier n'est stocké sur votre volume de stockage « Mallette » si vous changez vers l'offre Starter.
- Le contenu de votre compte e-mail doit être inférieur à 15 Go si vous basculez vers l'offre Starter.

:::


### Services <a name="services"></a>

{/* CP-STEPS-START:services */}

Chaque compte e-mail occupe un service, c'est-à-dire un emplacement de l'offre Starter ou Pro que vous avez commandé. Pour afficher vos services, cliquez sur <code className="action">Gérer mes services</code> dans la section **Abonnement** de l'onglet <code className="action">Vue d'ensemble</code> de votre service Zimbra. La page **Services** affiche le nombre de comptes configurés pour chaque offre (par exemple **Starter** « 3 / 3 comptes configurés ») et la liste de vos services avec, pour chacun :

- **Compte email** : le compte qui occupe ce service ;
- **Coût / boîte email** : « Gratuit » pour un service lié à un nom de domaine ;
- **Service lié** : le nom de domaine auquel le service est rattaché.

Le tableau indique aussi la référence, l'offre, le renouvellement et la date de renouvellement de chaque service. La recherche de cette page porte sur l'adresse des comptes e-mail, la référence des services et les noms de domaine liés.

{/* CP-STEPS-END:services */}

#### Choisir le service d'un nouveau compte <a name="services-choice"></a>

{/* CP-STEPS-START:choisir-service-nouveau-compte */}

Lorsque vous créez un compte e-mail depuis la console OVHcloud, vous choisissez uniquement l'offre, dans le menu déroulant **Offre** : le compte est placé sur le premier service libre de cette offre, qui peut être lié à un autre nom de domaine que celui de l'adresse.

{/* CP-STEPS-END:choisir-service-nouveau-compte */}

Pour placer le compte sur un service précis, par exemple celui lié au nom de domaine de l'adresse, créez-le avec l'API OVHcloud.

Récupérez d'abord l'identifiant du service (`id`) et le nom de domaine auquel il est lié (`currentState.domainPromotionLink`) avec l'appel suivant :

<Api version="v2" section="/zimbra" method="GET" route={"/zimbra/platform/\{platformId\}/slot"} />

Créez ensuite le compte en indiquant cet identifiant dans le champ `targetSpec.slotId` :

<Api version="v2" section="/zimbra" method="POST" route={"/zimbra/platform/\{platformId\}/account"} />

:::info
Le service d'un compte ne peut plus être changé après sa création.
:::

### Redirections <a name="redirections"></a>

Pour créer une redirection sur une adresse e-mail Zimbra, connectez-vous au [webmail](https://www.ovhcloud.com/fr/mail/).
La création d'une redirection se fait par le biais de règles de boîte de réception, appelée « filtres » dans le webmail. En effet, ces règles que l'on applique lors de la réception d'un e-mail permettent de transférer ou rediriger un e-mail.

Pour rediriger les e-mails de votre compte Zimbra vers une autre adresse e-mail, nous allons appliquer une règle de transfert. Suivez les onglets ci-dessous pour mettre en place votre redirection.

:::info

:::

### Alias <a name="alias"></a>

Créer un alias pour votre adresse e-mail vous permet de communiquer une adresse « masque » à vos contacts, sans avoir à communiquer votre adresse e-mail personnelle à l'expéditeur.

Cliquez sur les étapes ci-dessous pour créer un alias :

{/* CP-STEPS-START:alias */}

<Tabs>
  <Tab label="Etape 1">

### Réponses automatiques <a name="autoreply"></a>

Lorsque vous devez vous absenter et que vous n'avez pas la possibilité de traiter vos e-mails, il est possible de mettre en place un message d'absence. Suivez les étapes ci-dessous :

- Cliquez sur le bouton &#9881; en haut à droite de votre fenêtre de webmail, puis cliquez sur <code className="action">Paramètres</code>.

<img className="thumbnail" alt="zimbra" src="/images/assets/screens/email-clients/zimbra/zimbra_settings01.png" loading="lazy" />

- Cliquez sur la section `Absent du bureau` depuis la fenêtre des paramètres.
- Cochez la case « Activer la réponse automatique pendant ces dates (incluses) ».
- Complétez la date de début de l'absence devant la mention « Du ».
- Décochez la case « Pas de date de fin » si vous souhaitez déterminer une date de fin d'absence et déterminez-la.
- Dans le cadre, renseignez votre message d'absence.
- Cliquez sur <code className="action">Enregistrer</code> pour finaliser la mise en place de votre message d'absence.

<img className="thumbnail" alt="zimbra" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/getting-started-zimbra/zimbra_autoreply01.png" loading="lazy" />

:::warning
Les e-mails qu'un filtre transfère avec la seule action <code className="action">Transférer à</code> ne restent pas dans votre boîte de réception, et leurs expéditeurs ne reçoivent pas votre réponse automatique. Ajoutez à ce filtre l'action <code className="action">Garder dans le dossier Réception</code> (voir la section « [Redirections](#redirections) »).
:::
