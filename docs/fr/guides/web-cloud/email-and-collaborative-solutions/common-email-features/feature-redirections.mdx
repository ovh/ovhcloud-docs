## Objectif

Retrouvez dans ce guide différentes informations et aides concernant la configuration de vos **redirections** et **alias** e-mail, par exemple pour renvoyer des e-mails reçus sur une adresse A vers une adresse B.

<img className="thumbnail" alt="emails" src="/images/web-cloud/email-and-collaborative-solutions/common-email-features/feature-redirections/schema-redirect00.png" loading="lazy" />

**Découvrez comment gérer vos alias et redirections e-mail.**

<details>

<summary>Qu'est-ce qu'une redirection e-mail ?</summary>


Une redirection permet de modifier le trajet initial d'un e-mail vers une ou plusieurs autres adresses e-mail.

Par exemple : vous souhaitez qu'à la réception d'un e-mail sur **contact@mydomain.ovh**, celui-ci soit également renvoyé vers **john.smith@otherdomain.ovh**. Une redirection permet de transmettre automatiquement un e-mail destiné à **contact@mydomain.ovh** vers **john.smith@otherdomain.ovh**.

</details>


<details>

<summary>Qu'est-ce qu'un alias e-mail ?</summary>


Contrairement à la redirection, l'adresse e-mail associée à l'alias n'est pas une adresse que l'on consulte, il s'agit d'un « masque ».

Créer un alias pour votre adresse e-mail vous permet de communiquer une adresse « masque » à vos contacts, sans avoir à communiquer votre adresse e-mail personnelle à l'expéditeur. Une adresse e-mail peut avoir plusieurs alias.

Par exemple : votre adresse e-mail est **john.smith@mydomain.ovh** et votre alias **information@mydomain.ovh**. Vous pouvez alors communiquer à vos contacts l'adresse **information@mydomain.ovh** et recevoir vos e-mails sur **john.smith@mydomain.ovh**, sans que l'expéditeur ait connaissance de **john.smith@mydomain.ovh**.

</details>


<details>

<summary>Redirection et alias en image <a name="diagram"></a></summary>


Cliquez sur les onglets suivants pour des explications illustrées sur le fonctionnement des alias et redirections.

- `From` : Désigne l'adresse de l'expéditeur.
- `To` : Désigne l'adresse du destinataire.
- `Redirect to` : Désigne l'adresse e-mail de redirection qui a été configurée.

##### MX Plan / redirect <a name="redirect-manager-mxplan"></a>

{/* CP-STEPS-START:creer-redirection-mx-plan */}

Depuis votre service MX Plan, sélectionnez le domaine concerné.

Dans notre exemple, il s'agit d'une **redirection avec copie locale** (voir le [schéma 2](#diagram) au début de ce guide). Si cela correspond à votre besoin, suivez les étapes ci-dessous. Elles sont identiques quelle que soit la technologie webmail utilisée par votre MX Plan, ainsi que pour l'offre Redirect :

1. Cliquez sur l'onglet <code className="action">Redirections</code>. Le tableau des redirections déjà actives s'affiche.
1. Cliquez sur le bouton <code className="action">Créer une redirection</code>, au-dessus du tableau.

    <img className="thumbnail" alt="Onglet Redirections d'un service MX Plan, bouton Créer une redirection" src="/images/web-cloud/email-and-collaborative-solutions/common-email-features/feature-redirections/console/mxplan-legacy-1.png" loading="lazy" />

1. Dans la fenêtre **Créer une redirection**, complétez les éléments suivants :
    - **De l'adresse** : renseignez ici l'adresse e-mail que vous souhaitez rediriger. Le champ du sous-domaine est facultatif : laissez-le vide pour utiliser le domaine principal.
    - **Vers l'adresse** : renseignez ici l'adresse de destination de votre redirection. Il peut s'agir de l'une de vos adresses e-mail OVHcloud, ou d'une adresse e-mail externe.
    - **Conserver une copie locale** : cochez cette case pour recevoir l'e-mail sur votre adresse principale ainsi que sur l'adresse de redirection (voir le [schéma 2](#diagram) au début de ce guide). Laissez-la décochée pour renvoyer directement l'e-mail vers l'adresse de redirection, sans que l'adresse principale ne le reçoive (voir le [schéma 1](#diagram) au début de ce guide).
1. Cliquez ensuite sur <code className="action">Créer</code> pour confirmer l'ajout de cette redirection.

    <img className="thumbnail" alt="Fenêtre Créer une redirection avec les champs De l'adresse et Vers l'adresse" src="/images/web-cloud/email-and-collaborative-solutions/common-email-features/feature-redirections/console/mxplan-legacy-3.png" loading="lazy" />

:::info
Pour modifier l'adresse de destination ou supprimer une redirection, cliquez sur le bouton <code className="action">⋮</code> à droite de la redirection concernée.

:::

:::info
Lorsque vous cochez la case « **Conserver une copie locale** », une redirection de l'adresse e-mail vers elle-même est créée automatiquement dans la liste des redirections, elle matérialise cette copie locale.

:::

{/* CP-STEPS-END:creer-redirection-mx-plan */}

##### Exchange <a name="redirect-manager-exchange"></a>

{/* CP-STEPS-START:creer-redirection-exchange */}

La redirection d'un compte Exchange se définit dans les paramètres du compte :

1. Dans l'onglet <code className="action">Gestion des comptes</code> de votre plateforme Exchange, onglet <code className="action">Compte email</code>, cliquez sur le bouton <code className="action">⋮</code> à droite du compte, puis sur <code className="action">Modifier</code>.
2. Sur la page **Modifier un compte Exchange**, saisissez dans le champ **E-mail de redirection** l'adresse vers laquelle rediriger les e-mails.
3. Cochez la case **Garder une copie** pour conserver une copie des e-mails dans le compte (**redirection avec copie locale**, [schéma 2](#diagram)). Si la case n'est pas cochée, il s'agit d'une **redirection simple** ([schéma 1](#diagram)).
4. Cliquez sur <code className="action">Enregistrer</code>.

    <img className="thumbnail" alt="Page Modifier un compte Exchange, champ E-mail de redirection et case Garder une copie" src="/images/web-cloud/email-and-collaborative-solutions/common-email-features/feature-redirections/console/exchange-redirect.png" loading="lazy" />

:::warning
La redirection transfère aussi les spams que reçoit le compte, ce qui peut le faire bloquer pour spam. Dans ce cas, retirez la redirection et consultez notre guide « [Que faire en cas d'adresse e-mail bloquée pour spam ?](/guides/web-cloud/email-and-collaborative-solutions/troubleshooting/locked-for-spam) ».
:::

Pour rediriger les e-mails de votre compte Zimbra vers une autre adresse e-mail, nous allons appliquer une règle de transfert.

:::info
Dans notre exemple ci-dessous, nous avons choisi de rediriger l'ensemble des e-mails entrants vers une autre adresse e-mail. Pour comprendre l'exemple dans les captures d'écrans, nous sommes connectés sur l'adresse **zimbra@mydomain.ovh** et nous souhaitons rediriger les e-mails de ce compte vers l'adresse **address@example.com**.

:::


Suivez les étapes ci-dessous en cliquant sur les onglets pour mettre en place votre redirection :

<Tabs>
  <Tab label="Étape 1">
    Cliquez sur le bouton &#9881; en haut à droite de votre fenêtre de webmail, puis cliquez sur <code className="action">Paramètres</code>.
    
    <img className="thumbnail" alt="zimbra" src="/images/assets/screens/email-clients/zimbra/zimbra_settings01.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur la section <code className="action">Filtres</code> depuis la fenêtre des paramètres, puis cliquez sur le bouton <code className="action">Ajouter un filtre</code>.
    
    <img className="thumbnail" alt="zimbra" src="/images/assets/screens/email-clients/zimbra/zimbra_redirection02.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    - Cliquez d'abord sur <u>Mode avancé</u> en haut à droite pour mettre en place cette règle.
    - Donnez un nom à votre filtre dans la case `Nom du filtre`.
    - Laissez le menu déroulant sur `toutes` dans la phrase « Si un message entrant réunit ... de ces conditions ».
    - Dans le premier menu déroulant des règles, choisissez `À` (To), laissez `contient` (contains), puis saisissez l'adresse e-mail sur laquelle vous êtes connecté dans la case juste à droite.
    - Sous la mention « Alors » (Then), sélectionnez `Transférer à` (Forward to) dans le menu déroulant, puis saisissez l'adresse e-mail de destination.
    - Cliquez sur <code className="action">+ Ajouter une action</code> (Add an action) plus bas, puis sélectionnez `Garder dans le dossier Réception` (Keep in Inbox).
    - Cliquez sur <code className="action">Enregistrer</code> depuis la fenêtre de votre filtre et également depuis celle des paramètres.
    
    <img className="thumbnail" alt="zimbra" src="/images/assets/screens/email-clients/zimbra/zimbra_redirection03.png" loading="lazy" />
  </Tab>
</Tabs>

:::warning
L'action <code className="action">Garder dans le dossier Réception</code> conserve une copie des e-mails dans votre compte (**redirection avec copie locale**, [schéma 2](#diagram)). Sans elle, il s'agit d'une **redirection simple** ([schéma 1](#diagram)) : les e-mails ne restent pas dans votre boîte de réception, et une réponse automatique activée sur le compte n'est pas envoyée à leurs expéditeurs.
:::

### Créer un alias <a name="alias"></a>

Créer un alias pour votre adresse e-mail vous permet de communiquer une adresse « masque » à vos contacts, sans avoir à communiquer votre adresse e-mail personnelle à l'expéditeur. 

#### Exchange / Email Pro / MX Plan <a name="alias-exchange-emp-mxplan"></a>

{/* CP-STEPS-START:creer-alias-exchange-email-pro-mx-plan */}

Depuis votre service e-mail (Exchange, Email Pro ou MX Plan), ouvrez la liste de vos comptes e-mail : onglet <code className="action">Gestion des comptes</code> puis <code className="action">Compte email</code> sur Exchange, onglet <code className="action">Comptes</code> sur Email Pro, onglet <code className="action">Compte email</code> sur MX Plan. Sur MX Plan, les alias se gèrent ainsi sur les services utilisant le webmail Zimbra ou OWA ; pour un service MX Plan Roundcube, consultez la partie « [MX Plan Roundcube](#alias-mxplan-roundcube) » ci-dessous.

Pour ajouter un alias à votre compte e-mail, suivez les étapes décrites en cliquant successivement sur chaque onglet ci-dessous :

<Tabs>
  <Tab label="Étape 1">
    Sur Exchange et Email Pro, le tableau comporte une colonne **Alias**, qui indique le nombre d'alias de chaque compte.

    <img className="thumbnail" alt="Tableau des comptes e-mail Exchange, colonne Alias" src="/images/web-cloud/email-and-collaborative-solutions/common-email-features/feature-redirections/console/email-alias012.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Cliquez sur le bouton <code className="action">⋮</code> à droite du compte e-mail concerné, puis sur <code className="action">Configurer les alias</code> (Exchange) ou <code className="action">Gérer les alias</code> (Email Pro et MX Plan).

    <img className="thumbnail" alt="Menu ⋮ d'un compte Exchange ouvert, option Configurer les alias" src="/images/web-cloud/email-and-collaborative-solutions/common-email-features/feature-redirections/console/email-alias02.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Sur la page des alias du compte, cliquez sur <code className="action">Ajouter un alias</code>. Dans la fenêtre qui s'affiche, saisissez l'adresse de votre alias et, si besoin, choisissez son nom de domaine. Cliquez ensuite sur <code className="action">Créer</code> (<code className="action">Ajouter</code> sur MX Plan).

    <img className="thumbnail" alt="Fenêtre Créer un alias avec le champ Adresse d'alias et le nom de domaine" src="/images/web-cloud/email-and-collaborative-solutions/common-email-features/feature-redirections/console/email-alias03.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
Certains caractères spéciaux ne sont pas acceptés dans le nom d'un alias, par exemple `+`, `?`, `/`, `(`, `)`, `[`, `]` et `;`.

:::

{/* CP-STEPS-END:creer-alias-exchange-email-pro-mx-plan */}

Suivez le chapitre [MX Plan / MX redirect](#redirect-manager-mxplan) dans la partie « créer une redirection » depuis ce guide.

### Supprimer un alias <a name="alias-delete"></a>

#### Exchange / Email Pro / MX Plan <a name="alias-delete-exchange-emp-mxplan"></a>

{/* CP-STEPS-START:supprimer-alias-exchange-email-pro-mx-plan */}

Depuis votre service e-mail (Exchange, Email Pro ou MX Plan), ouvrez la liste de vos comptes e-mail, comme pour [créer un alias](#alias-exchange-emp-mxplan).

Cliquez sur le bouton <code className="action">⋮</code> à droite de l'adresse e-mail concernée, puis sur <code className="action">Configurer les alias</code> (Exchange) ou <code className="action">Gérer les alias</code> (Email Pro et MX Plan).

Sur la page des alias du compte, cliquez sur l'icône en forme de corbeille à droite de l'alias concerné, puis confirmez la suppression.

#### MX Plan Roundcube <a name="alias-delete-mxplan-roundcube"></a>

{/* CP-STEPS-START:supprimer-alias-mx-plan-roundcube */}

Pour supprimer un alias sur un compte email MX Plan Roundcube, vous devez le faire de la même façon qu'une redirection. Vous devez donc vous rendre dans la gestion des redirections de votre service MX Plan.

Cliquez sur l'onglet <code className="action">Redirections</code>.

Cliquez sur le bouton <code className="action">⋮</code> à droite de la redirection concernée, puis sur <code className="action">Supprimer</code>.

Il n'est pas possible de modifier l'adresse d'origine d'une redirection ou d'un alias : vous devez la supprimer puis la recréer. Seule l'adresse de destination peut être modifiée, à l'aide de l'action <code className="action">Modifier</code>.
