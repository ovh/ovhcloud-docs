## Objectif

Vous venez d'acquérir une solution e-mail MX Plan. Celle-ci vous permet de bénéficier d'adresses e-mail associées à un nom de domaine.

**Découvrez comment créer une adresse e-mail avec votre offre MX Plan.**

## Prérequis

- Disposer d'une offre MX Plan. Celle-ci est disponible via :
    - Une offre d’[hébergement web](/links/web/hosting).
    <Region zones={['eu']}>
    - Un [hébergement gratuit](https://www.ovhcloud.com/fr/domains/free-web-hosting/) compris avec un nom de domaine (activé au préalable).
    </Region>
    - Une offre MX Plan commandée séparément.

{/* CP-STEPS-START:cas-particuliers */}
:::info
**Cas particuliers**

<Region zones={['eu']}>

Vous pouvez effectuer cette opération depuis la <ManagerLink to="/">console OVHcloud</ManagerLink>, en vous positionnant sur le nom de domaine concerné.

### OWA et Zimbra

Cette section documente les offres MX Plan utilisant la technologie webmail **OWA** et **Zimbra**.

#### Créer un compte e-mail

{/* CP-STEPS-START:creer-compte-email-owa-zimbra */}
Pour obtenir une nouvelle adresse e-mail, positionnez-vous sur l'onglet <code className="action">Compte email</code>. Le tableau qui s'affiche liste les comptes e-mail déjà configurés, et la section **Quota de comptes e-mail** indique combien de comptes sont configurés sur le nombre total dont vous disposez. Cliquez alors sur le bouton <code className="action">Ajouter un compte</code>, au-dessus du tableau.

Dans le panneau qui s'affiche, renseignez les informations demandées :

- **Adresse email** : Saisissez le nom que vous souhaitez pour votre adresse e-mail (votre prénom.nom, par exemple). Le nom de domaine composant l'adresse e-mail est déjà renseigné.

:::warning
Le choix du nom de votre adresse e-mail doit respecter les conditions suivantes :

- La partie précédant le « @ » doit se terminer par une lettre ou un chiffre
- Aucun caractère accentué
- Pas de caractères spéciaux, à l'exception des caractères suivants : `.`, `+`, `-` et `_`

:::


- **Prénom** : renseignez un prénom.
- **Nom** : renseignez un nom.
- **Nom d'affichage** : indiquez le nom qui s'affichera en tant qu'expéditeur lorsque des e-mails seront envoyés depuis cette adresse.
- **Mot de passe** : définissez un mot de passe fort. Pour des raisons de sécurité, n'utilisez pas deux fois le même mot de passe. Choisissez-en un qui n'a aucun rapport avec vos informations personnelles (évitez par exemple de mentionner vos nom, prénom et date de naissance). Changez-le régulièrement.

:::warning
Le choix du mot de passe doit respecter les conditions suivantes :

- Minimum 10 caractères
- Au moins 1 chiffre et 1 caractère spécial ($, !, &, …)
- Au moins 1 lettre majuscule

:::


Une fois les champs complétés, cliquez sur <code className="action">Ajouter</code>. Le compte nouvellement ajouté apparaît alors dans le tableau. Patientez quelques instants le temps que le compte soit disponible.

Réalisez cette étape autant de fois que nécessaire, selon le nombre de comptes à votre disposition.
{/* CP-STEPS-END:creer-compte-email-owa-zimbra */}

#### Supprimer un compte e-mail

{/* CP-STEPS-START:supprimer-compte-email-owa-zimbra */}
Sur les services MX Plan utilisant le webmail Zimbra ou OWA, on parle de *réinitialisation de compte* lorsque vous devez supprimer celui-ci.

:::warning
Avant de supprimer des comptes e-mail, assurez-vous qu'ils ne sont pas utilisés. Une sauvegarde de ces comptes peut s'avérer nécessaire. Au besoin, consultez le guide « [Migrer manuellement votre adresse e-mail](/guides/web-cloud/email-and-collaborative-solutions/migrating/manual-email-migration) » qui vous décrira comment exporter les données d'un compte depuis la console OVHcloud ou un logiciel de messagerie.

:::


Depuis l'onglet <code className="action">Compte email</code>, cliquez sur le bouton <code className="action">⋮</code> à droite du compte à supprimer, puis cliquez sur <code className="action">Réinitialiser</code>.

Dans la fenêtre **Réinitialiser le compte** qui s'affiche, confirmez la réinitialisation. Celle-ci supprime les données et le nom associés au compte, qui pourra ensuite être de nouveau configuré.
{/* CP-STEPS-END:supprimer-compte-email-owa-zimbra */}

### MX Plan Roundcube

Cette section est dédiée aux offres MX Plan utilisant la technologie webmail **Roundcube**.

#### Créer un compte e-mail

{/* CP-STEPS-START:creer-compte-email-roundcube */}
Pour obtenir une nouvelle adresse e-mail, positionnez-vous sur l'onglet <code className="action">Compte email</code>. Le tableau qui s'affiche contient tous les comptes e-mail créés dans le cadre de votre offre MX Plan. Cliquez alors sur le bouton <code className="action">Ajouter un compte</code>, au-dessus du tableau.

<img className="thumbnail" alt="Onglet Compte email d'un service MX Plan, bouton Ajouter un compte au-dessus du tableau" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-creation/console/mxplan-creation-legacy-step2.png" loading="lazy" />

Dans le panneau **Ajouter un compte** qui s'affiche, renseignez les informations demandées :

<img className="thumbnail" alt="Panneau Ajouter un compte avec les champs Nom du compte, Description, Taille et Mot de passe" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-creation/console/mxplan-creation-legacy-step3.png" loading="lazy" />

- **Nom du compte** : Renseignez le nom que vous souhaitez pour votre adresse e-mail (votre prénom.nom, par exemple). Le nom de domaine concerné est déjà complété par défaut.
- **Description** : Ce champ est facultatif. Indiquez une courte description vous permettant de reconnaître ce compte parmi d'autres affichés dans la console OVHcloud.
- **Taille du compte** : Sélectionnez la taille du compte souhaitée dans le menu déroulant. Il s'agit de l'espace dont bénéficiera votre adresse pour stocker les messages.
- **Mot de passe** : Définissez un mot de passe, ou générez-en un à l'aide de l'icône en forme de clé située à droite du champ. Il doit contenir entre 9 et 30 caractères, sans caractère accentué. Pour des raisons de sécurité, nous vous recommandons de ne pas utiliser deux fois le même mot de passe, d'en choisir un qui n'a aucun rapport avec vos informations personnelles (évitez les mentions à vos nom, prénom et date de naissance, par exemple) et de le renouveler régulièrement.

Une fois les champs complétés, cliquez sur <code className="action">Ajouter</code> pour lancer la création de l'adresse e-mail. Patientez quelques instants le temps que celle-ci soit disponible.

Réalisez cette étape autant de fois que nécessaire, selon le nombre de comptes à votre disposition.
{/* CP-STEPS-END:creer-compte-email-roundcube */}
