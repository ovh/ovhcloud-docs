## Objectif

Lorsque vous êtes absent et que vous n'êtes pas en mesure de consulter votre adresse e-mail, vous pouvez mettre en place une réponse automatique (ou répondeur) qui transmettra un e-mail aux interlocuteurs qui vous envoient un e-mail.

**Découvrez comment mettre en place une réponse automatique sur une adresse e-mail.**

## Prérequis

<Region zones={['eu']}>

- Disposer d’une offre MX Plan. Celle-ci est disponible via : une offre d’[hébergement web](https://www.ovhcloud.com/fr/web-hosting/), l’[hébergement gratuit](https://www.ovhcloud.com/fr/domains/free-web-hosting/) compris avec un nom de domaine (activé au préalable) ou l’offre MX Plan commandée séparément.

</Region>

<Region zones={['ca', 'apac']}>

- Disposer d’une offre MX Plan. Celle-ci est disponible via : une offre d’[hébergement web](https://www.ovhcloud.com/fr/web-hosting/) ou l’offre MX Plan commandée séparément.

</Region>

## En pratique

{/* CP-STEPS-START:en-pratique */}
:::warning
Si votre adresse e-mail est sur une offre [**Exchange**](https://www.ovhcloud.com/fr/emails/hosted-exchange/), [**Email Pro**](https://www.ovhcloud.com/fr/emails/email-pro/) ou qu'il n'y a pas d'onglet <code className="action">Répondeurs</code> dans votre MX Plan, vous devrez alors créer une réponse automatique depuis votre webmail en vous aidant de la documentation « [Mettre en place un répondeur automatique depuis l'interface OWA](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/owa-automatic-replies) ».

:::
{/* CP-STEPS-END:en-pratique */}


### Création d'une réponse automatique

{/* CP-STEPS-START:creation-reponse-automatique */}
Cliquez sur l'onglet <code className="action">Répondeurs</code> de votre service MX Plan.

Le tableau qui s'affiche liste l'ensemble des réponses automatiques e-mail en place sur votre offre e-mail.

Au-dessus du tableau, cliquez sur le bouton <code className="action">Ajouter un répondeur</code>.

<img className="thumbnail" alt="Onglet Répondeurs d'un service MX Plan, bouton Ajouter un répondeur au-dessus du tableau" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-auto-responses/console/email_responder01.png" loading="lazy" />

Le panneau **Ajouter un répondeur** s'affiche. Vous pouvez le compléter selon les informations ci-dessous.

- **Boîte email** : l'adresse e-mail ou l'alias concerné par la réponse automatique. Sélectionnez une adresse e-mail existante sur votre offre e-mail, ou saisissez un nom libre dans le cas d'un alias : le répondeur n'est alors pas lié à une adresse existante. Le nom de domaine est déjà renseigné.
- **Durée du répondeur** :
    - **Temporaire** : définissez une date de début (**À partir du**) et une date de fin (**Jusqu'au**) à prendre en compte pour le fonctionnement de votre réponse automatique (utile si vous partez en congé par exemple).
    - **Permanent** : la réponse automatique fonctionnera tant que vous ne l'aurez pas désactivée.
- **Envoyer une copie** ou **Garder les messages sur le serveur** : selon que vous avez saisi un nom libre ou sélectionné une adresse e-mail existante, cette case permet de renvoyer les messages reçus pendant votre absence vers l'adresse de votre choix ou de les conserver sur l'adresse e-mail.

:::warning
Si vous décochez cette case, les messages reçus pendant votre absence seront automatiquement supprimés.

:::


- **Adresse en copie** (seulement pour un nom libre, lorsque la case **Envoyer une copie** est cochée) : dans le cas d'un alias, sélectionnez l'adresse e-mail qui recevra les e-mails envoyés vers l'alias.
- **Message** : il s'agit du message que vos correspondants recevront lorsqu'ils vous enverront un e-mail. Rédigez-le uniquement en caractères latins : les autres caractères ne fonctionnent pas sur le répondeur.

Cliquez ensuite sur <code className="action">Ajouter</code> pour terminer la configuration de votre réponse automatique.
{/* CP-STEPS-END:creation-reponse-automatique */}

:::tip
Si vous souhaitez déléguer la gestion d'une réponse automatique pour une adresse e-mail, consultez notre guide [« Déléguer la gestion de vos comptes e-mails à une autre personne »](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/feature-delegation)

:::


### Modification ou suppression d'une réponse automatique

{/* CP-STEPS-START:modification-suppression-reponse-automatique */}
Lorsque votre réponse automatique a été créée, elle apparaît dans le tableau de l'onglet <code className="action">Répondeurs</code> de votre offre e-mail. Vous pouvez la supprimer ou la modifier en cliquant sur le bouton <code className="action">⋮</code> à droite de celle-ci, puis sur <code className="action">Supprimer</code> ou <code className="action">Modifier</code>.

<img className="thumbnail" alt="Menu ⋮ d'un répondeur de l'onglet Répondeurs, avec les entrées Modifier et Supprimer" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-auto-responses/console/email_responder02.png" loading="lazy" />

Le panneau **Modifier le répondeur** permet de changer la durée, les dates et le message de la réponse automatique, mais pas sa boîte e-mail. Cliquez sur <code className="action">Modifier</code> pour enregistrer vos changements.

Pour une suppression, confirmez en cliquant sur <code className="action">Supprimer</code> dans la fenêtre **Supprimer le répondeur** : cette action ne peut pas être annulée.
{/* CP-STEPS-END:modification-suppression-reponse-automatique */}
