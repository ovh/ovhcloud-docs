## Objectif <a name="objective"></a>

La délégation donne la possibilité à l'utilisateur d'un compte e-mail de gérer lui-même différentes fonctionnalités (le changement de mot de passe notamment). Ces fonctionnalités dépendent du type de délégation mis en place :

- Déléguer **l'ensemble de vos comptes e-mail** à un ou plusieurs comptes OVHcloud. Ce type de délégation permet aux comptes clients bénéficiaires de gérer les filtres, les répondeurs e-mails, les redirections/alias, ainsi que les Mailing Lists.

- Déléguer **un ou plusieurs comptes e-mails** et leurs filtres à un seul compte OVHcloud. Ce type de délégation ne permet pas aux bénéficiaires de gérer les répondeurs e-mails, les redirections, ni les Mailing Lists. Elle ne permet pas non plus aux bénéficiaires de supprimer le ou les comptes e-mail concernés, d'y importer les e-mails d'un autre compte ou de gérer les délégations.

**Découvrez comment déléguer les comptes e-mail de votre offre MX Plan.**

:::warning
La gestion des délégations dépend du webmail utilisé par votre service MX Plan :

- **Roundcube** : depuis l'espace client OVHcloud, comme décrit ci-dessous.
- **Zimbra** : depuis le webmail. Consultez la partie « [Délégations](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-zimbra#delegations) » de notre guide sur le webmail Zimbra.

Pour savoir quel webmail utilise votre service, consultez notre guide « [Premiers pas avec l'offre MX Plan](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-generalities#instructions) ».

:::


## En pratique <a name="oldmxplan"></a>

:::info
La mise en place d'une délégation sur un compte e-mail le fait apparaître dans <ManagerLink to="/">l'espace client</ManagerLink> concerné. Pour autant, seules les modifications indiquées dans la section « [Objectif](#objective) » de ce guide seront possibles dans cette situation.

:::


Pour afficher la liste des comptes e-mails de votre offre MX Plan, cliquez sur l'onglet <code className="action">Emails</code>.

<img className="thumbnail" alt="delegation" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-delegation/mxplan-delegation-01.png" loading="lazy" />

### Déléguer l'ensemble de vos comptes e-mail à un ou plusieurs comptes OVHcloud

Ce type de délégation permet à son bénéficiaire de gérer les mots de passe, les filtres, les répondeurs e-mails, les redirections/alias, ainsi que les Mailing Lists.

Cliquez sur <code className="action">Gérer vos partages pour toutes les adresses email</code>

<img className="thumbnail" alt="delegation" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-delegation/mxplan-delegation-02.png" loading="lazy" />

Une nouvelle fenêtre s'affiche. Cliquez sur le bouton <code className="action">+</code> à droite de la mention `Ajouter un identifiant`. Entrez l'identifiant OVHcloud qui bénéficiera de cette délégation et validez votre choix.

<img className="thumbnail" alt="delegation" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-delegation/mxplan-delegation-03.png" loading="lazy" />

Vous pouvez déléguer la gestion de votre service MX Plan à plusieurs identifiants OVHcloud.

### Déléguer un ou plusieurs comptes e-mails à un identifiant

Cette délégation vous permet de changer le mot de passe du compte e-mail concerné et de gérer ses filtres.

À droite du compte e-mail que vous souhaitez déléguer, cliquez sur le bouton <code className="action">...</code> puis sur <code className="action">Gestion de la délégation</code>.

<img className="thumbnail" alt="delegation" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-delegation/mxplan-delegation-04.png" loading="lazy" />

Saisissez l'identifiant OVHcloud qui bénéficiera de cette délégation et validez votre choix.

<img className="thumbnail" alt="delegation" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-delegation/mxplan-delegation-05.png" loading="lazy" />

Il est possible d'ajouter plusieurs identifiants OVHcloud pour gérer chaque adresse e-mail.
