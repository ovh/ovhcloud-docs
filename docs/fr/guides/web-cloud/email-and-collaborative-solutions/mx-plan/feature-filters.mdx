## Objectif

Un filtre e-mail permet d'appliquer différents traitements sur les messages que vous recevez, selon les critères de votre choix.

Par exemple : vous souhaitez que tout e-mail contenant « [SPAM] » dans le sujet soit supprimé.

- Critère = le sujet de l'e-mail contient *SPAM*
- Traitement = supprimer l'e-mail

**Découvrez comment créer et configurer un filtre sur votre adresse e-mail.**

## En pratique <a name="oldmxplan"></a>

{/* CP-STEPS-START:en-pratique */}

L'onglet <code className="action">Compte email</code> de votre service MX Plan liste vos adresses e-mail. Cliquez sur le bouton <code className="action">⋮</code> à droite du compte concerné, puis sur <code className="action">Gérer les filtres</code>.

<img className="thumbnail" alt="Menu ⋮ d'un compte de l'onglet Compte email, option Gérer les filtres" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-filters/console/mxplan-filters-01.png" loading="lazy" />

La page **Filtres de …** liste les filtres configurés pour cette adresse e-mail.

<img className="thumbnail" alt="Page des filtres d'une adresse e-mail, bouton Créer un filtre" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-filters/console/mxplan-filters-02.png" loading="lazy" />

Pour ajouter un filtre à votre adresse e-mail, cliquez sur le bouton <code className="action">Créer un filtre</code>. Dans la section **Information** du panneau qui s'ouvre, définissez les éléments suivants :

- **Nom du filtre :** choisissez un nom pour votre filtre.

- **Priorité :** définit l'ordre d'exécution de vos filtres sur un message entrant, de 1 à 99. Un filtre de priorité 1 s'exécute avant un filtre de priorité 2.

- **Activer le filtre :** décochez cette option si vous souhaitez appliquer ce filtre plus tard.

{/* CP-STEPS-END:en-pratique */}

### Comprendre la configuration des filtres d'e-mails

{/* CP-STEPS-START:comprendre-configuration-filtres */}

Le panneau **Créer un filtre**, qui s'affiche lorsque vous ajoutez un filtre, comporte 3 sections : **Information**, **Règles** et **Action**.

<img className="thumbnail" alt="Panneau Créer un filtre avec ses sections Information, Règles et Action" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/feature-filters/console/mxplan-filters-03.png" loading="lazy" />

{/* CP-STEPS-END:comprendre-configuration-filtres */}

#### Règles

{/* CP-STEPS-START:regles */}

La section **Règles** vous permet de définir les messages sur lesquels le filtre s'applique.

Premier choix (en-tête) :

- **Expéditeur (From) :** désigne l'adresse e-mail de l'expéditeur, par exemple : « Si l'expéditeur ... ».
- **Destinataire (To) :** désigne l'adresse e-mail du destinataire, par exemple : « Si le destinataire ... ».
- **Sujet (Subject) :** désigne le contenu du sujet du message, par exemple : « Si le sujet du message ... ».
- **Autre :** la console OVHcloud ne propose pas de champ permettant d'indiquer l'élément de l'en-tête de l'e-mail à prendre en compte.

Deuxième choix (règle) :

- **Contient :** exemple : « ... contient ... ».
- **Ne contient pas :** exemple : « ... ne contient pas ... ».
- **Vérification SPF :** indiquez une valeur du [champ SPF](/guides/web-cloud/domains/dns-zone-spf) à prendre en compte, par exemple : « ... n'a pas de champ SPF ... ».

:::info
Le SPF (Sender Policy Framework) permet au serveur qui reçoit un e-mail de s'assurer que ce dernier a bien été envoyé depuis un serveur de confiance.
Il permet de prévenir les potentielles usurpations d'identité venant d'adresses e-mail utilisant votre nom de domaine (spoofing). Pour plus d'infos sur le SPF, reportez-vous au guide « [Améliorer la sécurité des e-mails via un enregistrement SPF](/guides/web-cloud/domains/dns-zone-spf) ».

:::


Troisième choix (valeur) :

- Exemple : [SPAM]

Quatrième choix (<code className="action">Nouvelle règle</code>) :

- Ce bouton vous permet d'ajouter une ou plusieurs conditions pour la même action.

{/* CP-STEPS-END:regles */}

#### Action

{/* CP-STEPS-START:actions */}

La section **Action** vous permet de définir l'action à appliquer.

Dans le menu déroulant **Action**, vous avez le choix entre :

- **Accepter :** les e-mails remplissant les conditions sont reçus normalement.
- **Supprimer :** les e-mails remplissant les conditions sont supprimés.
- **Rediriger vers :** redirige les e-mails remplissant les conditions vers l'adresse e-mail de votre choix, à saisir dans le champ **Paramètre (email)**.
- **Transférer vers :** transfère les e-mails remplissant les conditions vers une des adresses e-mail de votre domaine, à saisir dans le champ **Paramètre (email)**.

Cliquez ensuite sur <code className="action">Créer</code> pour enregistrer le filtre.

{/* CP-STEPS-END:actions */}

### Exemples de filtres

#### Supprimer les spams

:::warning
Dans notre exemple nous évoquons la mention [SPAM] dans l'objet d'un e-mail. Cette mention apparaît lorsque l'antispam du serveur de réception délivre les e-mails, qu'il considère comme indésirable, directement dans la boite de réception. C'est le cas des services MX Plan utilisant le webmail Roundcube.

:::


{/* CP-STEPS-START:supprimer-spams */}

||En-tête|Règle|Valeur|Action|
|---|---|---|---|---|
|Paramètres du filtre|Sujet (Subject)|Contient|[SPAM]|Supprimer|
|Ce que le filtre va faire|Si le sujet du message|contient|[SPAM]|alors, supprimer le message.|

{/* CP-STEPS-END:supprimer-spams */}

#### Rediriger les e-mails d'un destinataire

{/* CP-STEPS-START:rediriger-emails-destinataire */}

||En-tête|Règle|Valeur|Action|
|---|---|---|---|---|
|Paramètres du filtre|Expéditeur (From)|Contient|contact@example.com|Rediriger vers : user@example.net|
|Ce que le filtre va faire|Si l'expéditeur|est|contact@example.com|alors, renvoyer l'e-mail vers user@example.net|

{/* CP-STEPS-END:rediriger-emails-destinataire */}

#### Rediriger les e-mails adressés à une Mailing-List

{/* CP-STEPS-START:rediriger-emails-mailing-list */}

||En-tête|Règle|Valeur|Action|
|---|---|---|---|---|
|Paramètres du filtre|Destinataire (To)|Contient|ml@example.com|Transférer vers : user@example.org|
|Ce que le filtre va faire|Si le message a été envoyé à la Mailing-List|appelée|ml@example.com|alors, renvoyer le message vers mon autre adresse : user@example.org|

{/* CP-STEPS-END:rediriger-emails-mailing-list */}

#### Supprimer les e-mails contenant une mention indésirable, à l'exception d'un expéditeur

{/* CP-STEPS-START:supprimer-mention-indesirable-exception-expediteur */}

Un seul filtre est à ajouter, avec deux règles. Après avoir renseigné la première, cliquez sur <code className="action">Nouvelle règle</code> pour ajouter la seconde :

||En-tête|Règle|Valeur|
|---|---|---|---|
|Paramètres de la règle 1|Sujet (Subject)|Contient|money|
|Paramètres de la règle 2|Expéditeur (From)|Ne contient pas|contact@example.net|

Action du filtre : **Supprimer**.

Si le sujet du message contient le mot « money », **et que** l'expéditeur du message n'est pas « contact@example.net », alors le message sera supprimé.

{/* CP-STEPS-END:supprimer-mention-indesirable-exception-expediteur */}
