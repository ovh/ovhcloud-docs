## Qu'est-ce que Microsoft Exchange ?

[Microsoft Exchange d'OVHcloud](https://www.ovhcloud.com/fr/emails/hosted-exchange/) est la solution de messagerie collaborative la plus complète (Hosted, Private et Dedicated) : adresses e-mail, agendas, contacts et tâches synchronisés sur tous vos appareils, ressources, comptes partagés et administration avancée. Retrouvez ici tous les guides pour commander, configurer et administrer vos comptes.

Avec Microsoft Exchange, vous pouvez :

- Commander et prendre en main une plateforme Hosted, Private ou Dedicated Exchange
- Associer votre nom de domaine à votre plateforme e-mail et valider sa configuration DNS
- Accéder à votre messagerie, vos agendas et vos contacts depuis le webmail Outlook Web App
- Configurer vos comptes dans un logiciel de messagerie sur ordinateur ou mobile
- Administrer des fonctionnalités avancées (groupes, délégation, ressources, comptes partagés, double authentification)

## Accéder à votre messagerie

Consultez votre messagerie, vos agendas et vos contacts en ligne via le webmail [Outlook Web App (OWA)](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/email-owa), sans installation.

## Retrouver le nom de votre serveur

La plupart des logiciels de messagerie configurent automatiquement votre compte via **Autodiscover** : il suffit de saisir votre adresse e-mail et votre mot de passe.

<Region zones={['eu']}>
Pour une configuration manuelle (ActiveSync ou EWS), le nom du serveur prend la forme `ex?.mail.ovh.net`.

Pour retrouver votre numéro de serveur, connectez-vous à votre <ManagerLink to="/#/web/exchange">espace client OVHcloud</ManagerLink> et sélectionnez votre plateforme Microsoft Exchange. Le nom complet du serveur est indiqué dans l'onglet **Informations générales** (par exemple : `ex3.mail.ovh.net`).

<img className="thumbnail" alt="Nom du serveur Exchange dans l'espace client OVHcloud, onglet Informations générales" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/overview/exchange-server-name.png" loading="lazy" />
</Region>
