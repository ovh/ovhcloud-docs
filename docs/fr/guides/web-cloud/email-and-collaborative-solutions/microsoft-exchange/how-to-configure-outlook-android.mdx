## Objectif

Vous pouvez configurer les adresses e-mail de votre offre Exchange dans l'application Outlook pour Android, disponible gratuitement sur le Google Play Store. Une fois configurée comme un compte **Exchange**, votre adresse e-mail se synchronise via le protocole ActiveSync : vous retrouvez vos e-mails, votre calendrier et vos contacts sur votre appareil.

**Apprenez à configurer un compte Exchange via ActiveSync sur l'application Outlook pour Android.**

[[fragment:support-scope]]

:::warning
Nous vous recommandons de faire appel à un [partenaire spécialisé](/links/transversal/marketplace-support-collaboration) et/ou de contacter l'éditeur du service si vous éprouvez des difficultés.
:::

## Prérequis

- Disposer d'une offre [Exchange](/links/web/emails-exchange).
- Disposer de l'[application Outlook](https://play.google.com/store/apps/details?id=com.microsoft.office.outlook&hl=fr) sur votre appareil Android.
- Disposer des identifiants relatifs à l'adresse e-mail que vous souhaitez paramétrer.

:::info
Cette documentation a été réalisée depuis un appareil utilisant la version 17 d'Android, avec la version 5.2645.1 de l'application Outlook.
:::

## En pratique

### Ajouter le compte <a name="add-account"></a>

La procédure diffère **si aucun compte n'est paramétré** ou **si un compte a déjà été paramétré** dans l'application Outlook. Sélectionnez l'onglet correspondant à votre situation :

  </Tab>

    2. Dans le volet qui s'ouvre, appuyez sur le bouton <code className="action">+</code>.
    3. Appuyez sur <code className="action">Ajouter un compte</code>.

    <CardGrid columns={2}>

    Dans la fenêtre « **Connexion à Exchange** », activez <code className="action">PARAMÈTRES AVANCÉS</code> si les champs avancés ne sont pas affichés, puis complétez les informations suivantes :

    - **Adresse e-mail** : votre adresse e-mail complète, déjà remplie.
    - **Mot de passe** : le mot de passe de votre adresse e-mail.
    - **Description** : un nom permettant d'identifier ce compte parmi vos autres comptes dans Outlook (facultatif).
    - **Serveur** : le nom de votre serveur Exchange, s'il n'est pas déjà rempli. Pour le retrouver, consultez la section « [Retrouver le nom de votre serveur](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/landing-page-microsoft-exchange#retrouver-le-nom-de-votre-serveur) » de la page « Microsoft Exchange - Messagerie OVHcloud ».
    - **Domaine** : laissez ce champ vide.
    - **Nom d'utilisateur** : votre adresse e-mail complète. Ce champ est obligatoire : tant qu'il est vide, la connexion ne se lance pas.

    Appuyez sur <code className="action">✓</code>, dans la partie supérieure droite de l'écran, pour vous connecter.

  </Tab>
  <Tab label="Étape 4">
    Une fois la connexion établie, Outlook vous demande si vous souhaitez ajouter un autre compte. Appuyez sur <code className="action">PEUT-ÊTRE PLUS TARD</code>, puis choisissez d'activer ou non les notifications.

    Votre boîte de réception s'affiche.
  </Tab>
</Tabs>

:::warning
Ne configurez pas votre adresse Exchange en **IMAP** ou en **POP3** : seul le type de compte **Exchange** synchronise votre calendrier et vos contacts.
:::

:::tip
Si le message « **Nous ne pouvons pas nous connecter** » s'affiche après l'étape 3, vérifiez votre mot de passe. Après un échec, Outlook vide les champs **Serveur** et **Nom d'utilisateur** : complétez-les à nouveau avant de réessayer.

:::

:::info
Avec un compte Exchange, l'application Outlook pour Android ne se connecte pas directement à votre serveur : un service cloud de Microsoft synchronise vos e-mails, votre calendrier et vos contacts entre le serveur Exchange et l'application. Pour plus d'informations, consultez la [documentation Microsoft](https://learn.microsoft.com/fr-fr/exchange/clients/outlook-for-ios-and-android/use-basic-auth).
:::

### Utiliser l'adresse e-mail

Une fois l'adresse e-mail configurée, vous pouvez envoyer et recevoir des messages, et consulter votre calendrier et vos contacts depuis l'application Outlook.

:::tip
OVHcloud propose une application web permettant d'accéder à votre adresse e-mail depuis un navigateur web, à l'adresse [webmail](/links/web/email). Vous pouvez vous y connecter grâce aux identifiants de votre adresse e-mail.
:::

### Modifier les paramètres du compte <a name="modify-settings"></a>

L'application Outlook ne permet pas de modifier les paramètres serveur d'un compte déjà configuré. Pour les modifier, supprimez le compte de l'application, puis ajoutez-le à nouveau :

<CardGrid columns={2}>
<div>

1. Appuyez sur l'icône de votre compte, dans la partie supérieure gauche de l'écran.
2. Appuyez sur l'icône des paramètres (<code className="action">⛭</code>), en bas du volet qui s'ouvre.
3. Dans la section « **Général** », appuyez sur <code className="action">Comptes</code>, puis sur le compte concerné.
4. Appuyez sur <code className="action">SUPPRIMER LE COMPTE</code>, puis confirmez la suppression.

La suppression retire le compte de l'application et les données stockées sur votre appareil. Vos e-mails restent sur le serveur Exchange.

En cas de problème de synchronisation, appuyez d'abord sur <code className="action">RÉINITIALISER LE COMPTE</code>, sur la même page.

</div>
<div>

<img className="thumbnail" alt="Outlook pour Android, paramètres du compte Exchange avec Supprimer le compte" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/how-to-configure-outlook-android/outlook-android-09-delete-account-fr.png" loading="lazy" />

</div>
</CardGrid>

:::tip
Une fois votre compte supprimé, suivez les étapes de la section « [Ajouter le compte](#add-account) » de ce guide.
:::
