## Objectif

Vous souhaitez bénéficier d'une licence Outlook pour consulter et gérer vos e-mails sur votre compte Exchange.

OVHcloud vous propose le client de messagerie Outlook au tarif de 2 euros HT par mois. Il sera associé à un compte Exchange OVHcloud dont vous avez la gestion.

Après votre souscription, vous pouvez télécharger Outlook parmi l'une des 3 versions suivantes :

- Outlook pour Windows 32 bits.
- Outlook pour Windows 64 bits.
- Outlook pour MAC 64 bits.

**Découvrez comment souscrire une licence Outlook depuis votre plateforme Exchange OVHcloud et l'installer.**

## En pratique

### Commander une licence Outlook

#### Pour un compte Hosted Exchange

{/* CP-STEPS-START:commander-licence-hosted-exchange */}

Dans l'onglet <code className="action">Gestion des comptes</code>, cliquez sur le bouton <code className="action">⋮</code> à droite du compte concerné, puis sur <code className="action">Commander une licence Outlook</code>.

<img className="thumbnail" alt="Menu ⋮ d'un compte Hosted Exchange, entrée Commander une licence Outlook" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/console/order-outlook01.png" loading="lazy" />

Dans la fenêtre **Commander des licences Outlook**, choisissez la période de renouvellement de votre licence (**1 mois** ou **1 an**), puis cochez la case d'acceptation des conditions. Cliquez ensuite sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="Fenêtre Commander des licences Outlook, choix de la période et acceptation des conditions" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/console/order-outlook02.png" loading="lazy" />

Le bon de commande est alors généré : cliquez sur <code className="action">Commander</code> pour ouvrir la page de paiement dans un nouvel onglet, puis réglez votre commande avec l'un des moyens de paiement à votre disposition.

Votre licence Outlook est disponible dans la console OVHcloud environ 2 heures après l'acceptation de votre paiement : la colonne **Outlook** du compte indique alors **Active**.

{/* CP-STEPS-END:commander-licence-hosted-exchange */}

<Region zones={['eu']}>

#### Pour un compte Private Exchange

{/* CP-STEPS-START:commander-licence-private-exchange */}

Dans l'onglet <code className="action">Gestion des comptes</code>, cliquez sur le bouton <code className="action">⋮</code> à droite du compte concerné, puis sur <code className="action">Activer la licence Outlook</code>. Cette option n'apparaît que sur un compte déjà configuré.

<img className="thumbnail" alt="Menu ⋮ d'un compte Private Exchange configuré, entrée Activer la licence Outlook" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/console/order-outlook03.png" loading="lazy" />

Dans la fenêtre **Activer la licence Outlook ?**, cliquez sur <code className="action">Confirmer</code> pour activer la licence sur le compte concerné. La licence est ensuite facturée tant qu'elle reste active.

<img className="thumbnail" alt="Fenêtre de confirmation Activer la licence Outlook, avec le bouton Confirmer" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/console/order-outlook04.png" loading="lazy" />

Votre licence Outlook est disponible dans la console OVHcloud après quelques instants.

{/* CP-STEPS-END:commander-licence-private-exchange */}

:::info
La facturation de votre licence Outlook sera intégrée dans celle de votre plateforme Private Exchange, chaque mois.

:::

</Region>


### Télécharger et installer Outlook

Il vous faut maintenant télécharger le fichier d'installation d'Outlook pour votre machine.

{/* CP-STEPS-START:telecharger-installer-outlook */}

Depuis l'onglet <code className="action">Gestion des comptes</code> de votre plateforme Exchange, cliquez sur le bouton <code className="action">⋮</code> à droite du compte concerné, puis sur <code className="action">Accéder à la licence Outlook</code>.

Dans la fenêtre **Licence Outlook**, si aucun lien n'a encore été généré pour ce compte, choisissez la version dans le menu déroulant **Version d'Outlook** en fonction de votre système d'exploitation, puis la langue dans le menu déroulant **Langue**. Cliquez ensuite sur <code className="action">Générer le lien</code>.

<img className="thumbnail" alt="Fenêtre Licence Outlook avec les menus déroulants Version d'Outlook et Langue" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/console/order-outlook05.png" loading="lazy" />

Après quelques instants, la fenêtre affiche le **Lien de téléchargement** et la **Clé de licence** à utiliser lors de l'installation sur votre machine. Ce lien a une durée de validité limitée : sa date d'expiration s'affiche juste en dessous.

<img className="thumbnail" alt="Fenêtre Licence Outlook affichant la clé de licence et le lien de téléchargement" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/console/order-outlook06.png" loading="lazy" />

{/* CP-STEPS-END:telecharger-installer-outlook */}

Le fichier téléchargé est au format .ISO, c'est-à-dire une image disque. Lancez l'installation et saisissez la clé de licence lorsqu'elle vous sera demandée.

### Résilier la licence Outlook de votre compte

{/* CP-STEPS-START:supprimer-licence-outlook */}

Dans l'onglet <code className="action">Gestion des comptes</code>, cliquez sur le bouton <code className="action">⋮</code> à droite du compte Hosted Exchange concerné, puis sur <code className="action">Résilier la licence Outlook</code>.

<img className="thumbnail" alt="Menu ⋮ d'un compte Hosted Exchange avec licence, entrée Résilier la licence Outlook" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/console/order-outlook07.png" loading="lazy" />

Une fois résiliée, la licence Outlook reste utilisable jusqu'à sa date d'expiration, puis n'est pas renouvelée. Dans la fenêtre **Résilier cette licence Outlook ?**, cliquez sur <code className="action">Résilier</code> pour confirmer.

{/* CP-STEPS-END:supprimer-licence-outlook */}
