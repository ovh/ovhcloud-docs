## Objectif

Pour renforcer la sécurité de votre compte Exchange, vous pouvez activer la double authentification (2FA). À chaque connexion au webmail OWA (Outlook Web App), vous saisissez alors un code en complément de votre mot de passe. Ce code est généré par une application *one-time password* (OTP) installée sur votre smartphone ou tablette.

:::warning
La double authentification protège uniquement l'accès au webmail OWA. Elle ne s'applique pas aux logiciels de messagerie (Outlook, Mail, Thunderbird, etc.) ni aux appareils mobiles : ces connexions (ActiveSync, EWS, IMAP, POP, etc.) restent protégées par le seul mot de passe du compte. Choisissez donc un mot de passe robuste.

:::

**Découvrez comment activer l'authentification à deux facteurs sur votre compte Exchange.**

## Prérequis

- Disposer d'une offre [Exchange OVHcloud](https://www.ovhcloud.com/fr/emails/).
- Avoir installé une application OTP sur un smartphone ou une tablette Android ou iOS.

:::info
**Les applications mobiles OTP**

De nombreuses applications OTP existent. En voici deux, gratuites :

- sur Android : Free OTP ;
- sur iOS : OTP Auth.

:::

## En pratique

### Première configuration

#### Étape 1 : activer la double authentification sur la plateforme

{/* CP-STEPS-START:activer-double-authentification-plateforme */}

Lors d'une première configuration, il est nécessaire d'activer la double authentification sur la plateforme avant de l'activer sur un compte.

Sélectionnez l'onglet <code className="action">Paramètres</code> de votre plateforme.

1. Dans la section **Sécurité des comptes**, cliquez sur le lien <code className="action">Modifier le verrouillage des comptes</code>.
1. Dans le panneau **Verrouillage des comptes** qui s'ouvre, activez l'interrupteur **Double authentification**.
1. Pour terminer, cliquez sur <code className="action">Enregistrer</code> en bas du panneau.

<img className="thumbnail" alt="Panneau Verrouillage des comptes ouvert depuis l'onglet Paramètres, avec l'interrupteur Double authentification" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-2fa-exchange/console/2fa-exchange-00.png" loading="lazy" />

{/* CP-STEPS-END:activer-double-authentification-plateforme */}

#### Étape 2 : activer la double authentification sur un compte

{/* CP-STEPS-START:activer-double-authentification-compte */}

Après activation de la double authentification sur votre plateforme, vous pouvez l'activer sur l'un de vos comptes.

Toujours depuis votre plateforme Exchange, cliquez sur l'onglet <code className="action">Gestion des comptes</code> (sous-onglet **Compte email**, ouvert par défaut). Cliquez sur le bouton <code className="action">⋮</code> à droite du compte sur lequel vous souhaitez activer la double authentification, puis cliquez sur <code className="action">Activer la double authentification</code>. Dans la fenêtre qui s'ouvre, cliquez sur <code className="action">Confirmer</code>.

À sa prochaine connexion, l'utilisateur du compte devra configurer une application d'authentification.

<img className="thumbnail" alt="Menu ⋮ d'un compte de l'onglet Gestion des comptes, entrée Activer la double authentification" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-2fa-exchange/console/2fa-exchange-01.png" loading="lazy" />

{/* CP-STEPS-END:activer-double-authentification-compte */}

Pour associer votre compte à votre application OTP, connectez-vous au [webmail](https://mail.ovh.net).

Lors de cette première connexion, un QR code apparaît. Utilisez votre application OTP pour le scanner, puis saisissez le code généré par celle-ci pour vous connecter.

<img className="thumbnail" alt="2fa-exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-2fa-exchange/2fa-exchange-02.png" loading="lazy" />

Lors de vos connexions suivantes, seul le code généré par votre application vous sera demandé.

### Désactiver la double authentification

{/* CP-STEPS-START:desactiver-double-authentification */}

La double authentification de votre compte peut être désactivée de trois manières.

Depuis l'onglet <code className="action">Gestion des comptes</code> de votre plateforme Exchange, dans le sous-onglet **Compte email** ouvert par défaut, cliquez sur le bouton <code className="action">⋮</code> à droite du compte sur lequel la double authentification est déjà active.

<img className="thumbnail" alt="Menu ⋮ d'un compte avec double authentification active, entrées Désactiver, Réinitialiser et Supprimer" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-2fa-exchange/console/2fa-exchange-04.png" loading="lazy" />

Sélectionnez l'option correspondant à votre besoin selon le tableau ci-dessous :

| N° | Fonction | Description
|----------------------------------|------------------|------------------|
| 1. | « Désactiver la double authentification » | Permet la suspension de la double authentification pendant une période définie en heures (de 1 à 8760), à indiquer dans le champ **Durée de désactivation**. Une fois le délai dépassé, la double authentification sera réactivée. <br/> *Exemple : un utilisateur a oublié son smartphone et ne peut pas s'authentifier avec l'application OTP.* |
| 2. | « Réinitialiser la double authentification » | Permet de réinitialiser le QR code demandé lors de votre première connexion au webmail.<br/> *Exemple : un utilisateur a changé de smartphone et doit reconfigurer son application OTP.* |
| 3. | « Supprimer la double authentification » | Supprime totalement la double authentification sur le compte. |

Dans la fenêtre qui s'ouvre, cliquez sur <code className="action">Confirmer</code> pour valider votre choix.

{/* CP-STEPS-END:desactiver-double-authentification */}
