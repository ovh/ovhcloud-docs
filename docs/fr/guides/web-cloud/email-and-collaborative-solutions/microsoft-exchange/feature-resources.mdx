## Objectif

Cette fonction collaborative de Exchange permet de créer des adresses de messagerie dédiées aux ressources de votre organisation, telles que les salles de conférence et les équipements partagés. L'utilisation de ces comptes de ressources permet d'optimiser l'organisation d'événements dans un environnement de travail collaboratif, en fournissant des contrôles de disponibilité et en intégrant les ressources de manière transparente à vos calendriers Exchange.

**Ce guide explique la gestion des ressources à l'aide de la console OVHcloud et de l'application Outlook Web App (OWA).**

## Prérequis

- Disposer d'une [solution Exchange OVHcloud](/links/web/emails-exchange) déjà configurée
- Disposer des identifiants de connexion pour le ou les comptes de messagerie ayant accès à la ressource

## En pratique

{/* CP-STEPS-START:en-pratique */}

Cliquez sur l'onglet <code className="action">Gestion des comptes</code>, puis sur le sous-onglet <code className="action">Ressources</code>.

{/* CP-STEPS-END:en-pratique */}

### Étape 1 : créer une ressource

{/* CP-STEPS-START:creer-ressource */}

<img className="thumbnail" alt="Sous-onglet Ressources d'un service Exchange, avec le bouton Ajouter un compte de ressource" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/console/exchange-resources-step1.png" loading="lazy" />

Cliquez sur le bouton <code className="action">Ajouter un compte de ressource</code> pour créer votre première ressource. Dans le panneau **Ajouter un compte de ressource** qui s'ouvre à droite de la page, renseignez les champs suivants :

<img className="thumbnail" alt="Panneau Ajouter un compte de ressource, avec les paramètres de Plus d'options" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/console/exchange-resources-step2.png" loading="lazy" />

|Nom|Description|
|---|---|
|Type de ressource|Sélectionnez le type de ressource : « Équipement » ou « Salle ».|
|Email de la ressource|Saisissez la partie de l'adresse qui précède le `@`, puis sélectionnez le nom de domaine dans le menu déroulant. Vous ne pouvez pas choisir une adresse de messagerie existante.|
|Nom de la ressource|Nom complet affiché dans la <ManagerLink to="/">console OVHcloud</ManagerLink> et dans [le webmail OVHcloud](/links/web/email) (OWA).|
|Capacité|Vous pouvez définir la taille maximale d'une ressource (en spécifiant par exemple le nombre de places assises d'une pièce ou les sièges d'un véhicule de société partagé).|
|Durée maximum (minutes)|Facultatif. Durée maximale d'une réservation de la ressource.|
|Société|Facultatif. Nom de la société à laquelle la ressource est rattachée.|
|Localisation|Facultatif, affiché uniquement pour une ressource de type « Salle ». Nom de l'emplacement de la salle.|

Si besoin, cliquez sur <code className="action">Plus d'options</code> pour afficher les paramètres de réservation de la ressource :

|Nom|Description|
|---|---|
|Confidentialité des reservations|Sélectionnez les informations des réservations visibles dans le calendrier de la ressource : « Disponibilité uniquement », « Titre / Organisateur uniquement » ou « Titre / Organisateur / contenu ».|
|Fenêtre de réservation (jours)|Facultatif. Nombre maximal de jours à l'avance pour réserver la ressource.|
|Permettre les conflits|Si cette case est cochée (c'est le cas par défaut), vous pourrez créer des événements de calendrier se chevauchant et impliquant la même ressource.|
|Supprimer les commentaires|Cochez cette case pour supprimer le texte du corps des demandes de réunion reçues par la ressource.|
|Supprimer le sujet|Cochez cette case pour supprimer l'objet des demandes de réunion reçues par la ressource.|

Une fois les champs renseignés, cliquez sur le bouton <code className="action">Ajouter</code>, en bas du panneau, pour créer la ressource.

{/* CP-STEPS-END:creer-ressource */}

### Étape 2 : utiliser des ressources

{/* CP-STEPS-START:utiliser-ressources */}

Gérez vos ressources depuis le tableau du sous-onglet **Ressources** : cliquez sur le bouton <code className="action">⋮</code> à droite de la ligne d'une ressource, puis sur <code className="action">Modifier</code> ou <code className="action">Supprimer</code>. Le menu propose également l'option <code className="action">Configurer les délégations</code>, qui permet de déléguer l'accès à la ressource à d'autres comptes. Pour plus d'informations sur les délégations, consultez notre guide « [Déléguer des droits sur un compte e-mail](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/permissions-delegation) ».

### Ajouter un calendrier de ressources dans OWA

:::info
Consultez également notre guide sur le [Partage de calendriers depuis l'interface OWA](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/owa-calendar-sharing).

:::


Connectez-vous à votre compte Exchange via le [webmail OVHcloud](/links/web/email). Basculez vers l'interface « Calendrier » en cliquant sur le « lanceur d'application » dans le coin supérieur gauche, puis en sélectionnant l'icône <code className="action">Calendrier</code>.

<img className="thumbnail" alt="ajouter calendrier" src="/images/assets/screens/email-clients/owa/exchange-calendars-step1.png" loading="lazy" />

Dans la barre de navigation supérieure, cliquez sur <code className="action">Ajouter un calendrier</code>, puis sur <code className="action">À partir de l'annuaire</code>.

<img className="thumbnail" alt="sélectionner ressource" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step4.png" loading="lazy" />

Saisissez du texte pour afficher les suggestions de vos contacts, entrez une adresse électronique complète ou utilisez l'option de recherche via <code className="action">À partir de l'annuaire</code>. Toutefois, l'adresse de messagerie de la ressource doit être suggérée à ce stade, car elle a été automatiquement ajoutée à la liste d'adresses globale (GAL) lors de sa création. Cliquez sur <code className="action">Ouvrir</code> pour ajouter le calendrier de cette ressource à la vue d'ensemble de votre calendrier.

### Créer un événement dans OWA

Pour planifier un événement, cliquez d'abord sur <code className="action">Nouveau</code> dans la barre de menu supérieure et sélectionnez <code className="action">Évènement de calendrier</code>. Dans la nouvelle fenêtre, vous pouvez définir les détails de votre événement et ajouter l'équipement requis et l'emplacement en ajoutant les ressources correspondantes.

<img className="thumbnail" alt="planification" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step5_1.png" loading="lazy" />

Le gestionnaire d'événements se compose de trois volets :

#### Détails

- (1) Ajouter un titre pour l'événement : ceci sera affiché dans les calendriers.
- (2) Ajouter un emplacement ou une salle : vous pouvez choisir parmi vos comptes de ressources.
- (3) Début/Fin : définissez la durée de l'événement.
- (4) Répéter : le cas échéant, choisissez un cycle de répétition (quotidien, le même jour chaque mois, etc.).
- (5) Rappel : OWA affiche une fenêtre de rappel à l'heure spécifiée.
- (6) Afficher comme : choisissez un état pour votre calendrier de disponibilité.
- (7) Ajouter un rappel par courrier : une option permettant d'envoyer des rappels par e-mail à vous-même ou à tous les participants.

Saisissez votre message d'invitation dans l'éditeur (8) et continuez à ajouter des participants à votre événement.

Si vous tentez d'ajouter une ressource déjà réservée (« occupée »), un message s'affiche et suggère d'utiliser l'[Assistant de planification](#planification) (9), qui fournit une vue d'ensemble plus large du calendrier de la période choisie.

#### Contacts

Comme un compte de ressources est également un contact, vous pouvez ajouter des salles et des équipements dans ce volet, exactement comme pour les autres participants (10). Commencez à taper pour afficher les suggestions de vos contacts, entrez un e-mail complet ou utilisez l'option de recherche (un clic sur <code className="action">+</code> ouvrira vos contacts).

Une fois que vous avez finalisé la planification en cliquant sur <code className="action">Envoyer</code> dans la barre de menus supérieure, le compte de ressources vous envoie un message pour confirmer qu'il est réservé pour votre événement. Cochez la case « Demander des réponses » si vous avez besoin d'une confirmation active de la part des invités pour mettre à jour automatiquement votre calendrier.

#### Planification

Un extrait de calendrier de vos propres événements, intitulé **Planifier**, s'affiche à droite dès que vous ajoutez une ressource ou une personne à l'événement. Il fournit un aperçu graphique de la disponibilité des ressources le jour choisi ; vous pouvez définir l'heure et la durée de l'événement directement en cliquant avec la souris et en sélectionnant le menu en haut à droite.

Si nécessaire, cliquez sur <code className="action">Assistant Planification</code> dans le volet **Contacts** pour ouvrir une vue d'ensemble encore plus détaillée. Cet assistant est utile pour les événements plus importants ou si vous devez gérer les conflits, car il visualise l'ensemble du processus de planification. Vous pouvez vérifier la disponibilité et ajuster votre planification en sélectionnant des emplacements et des contacts, sans quitter cette interface.

<img className="thumbnail" alt="assistant" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step6.png" loading="lazy" />

### Messages de réponse de la ressource

Après avoir créé l'événement (en cliquant sur <code className="action">Envoyer</code> dans la barre de menu supérieure), Exchange enverra automatiquement des messages :

- Les participants recevront des invitations (pour mettre à jour les calendriers concernés ou uniquement les leurs, selon votre choix de « Demander des réponses » auparavant).

- Vous recevrez un e-mail de confirmation provenant de chaque compte de ressource choisi (si la ressource est disponible, ou si elle est réservée mais que la case **Permettre les conflits** est cochée, ce qui est le cas par défaut).

<img className="thumbnail" alt="message d'acceptation" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step7.png" loading="lazy" />

- Vous recevrez un e-mail de refus provenant de chaque compte de ressource choisi (si la ressource n'est pas disponible et que la case **Permettre les conflits** a été décochée).

<img className="thumbnail" alt="message de refus" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step8.png" loading="lazy" />
