## En pratique

### Ajouter un nom de domaine

{/* CP-STEPS-START:ajouter-nom-de-domaine */}

1. Cliquez sur l'onglet <code className="action">Domaines associés</code> de votre plateforme Exchange ou Email Pro.
1. Le tableau qui s'affiche vous indique les noms de domaine actuellement associés à votre service.
1. Cliquez sur le bouton <code className="action">Ajouter un domaine</code>, au-dessus du tableau.

<img className="thumbnail" alt="Onglet Domaines associés d'un service Exchange, bouton Ajouter un domaine au-dessus du tableau" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain/console/add_domain_exchange_step1.png" loading="lazy" />

:::warning
Par défaut, l'ensemble des comptes e-mail d'une plateforme sont interconnectés. Toutes les adresses créées sur votre service e-mail seront en mesure de visualiser l'ensemble des adresses de ce service dans l'annuaire, y compris celles possédant un nom de domaine différent.

<Region zones={['eu']}>

Pour dissocier l'affichage des domaines, il est nécessaire de commander une autre plateforme [Exchange ou Email Pro](/links/web/emails) pour le ou les noms de domaine concernés.

</Region>

<Region zones={['ca']}>

Pour dissocier l'affichage des domaines, il est nécessaire de commander une autre plateforme [Exchange](/links/web/emails-exchange) pour le ou les noms de domaine concernés.

</Region>

:::


Le panneau **Ajouter un domaine** s'ouvre à droite de la page. Deux choix sont possibles :

- **Sélectionner un domaine dans la liste** : choisissez ensuite votre nom de domaine dans le menu déroulant **Nom de domaine**. Vous y retrouverez les noms de domaine dont vous avez la gestion complète (ou a minima celle de la zone DNS) dans la console OVHcloud.

- **Saisir un nom de domaine non géré par votre compte OVH** : saisissez ensuite votre nom de domaine dans le champ **Nom de domaine**. Vous devez pouvoir modifier la zone DNS de ce nom de domaine pour que le service puisse être configuré.

<img className="thumbnail" alt="Panneau Ajouter un domaine ouvert à droite de l'onglet Domaines associés" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain/console/add_domain_exchange_step2.png" loading="lazy" />

Une fois le nom de domaine indiqué, la section **Configuration** s'affiche juste en dessous, dans le même panneau : choisissez-y le mode de configuration du domaine.

- **Si vous avez sélectionné dans la liste un nom de domaine géré par votre compte OVHcloud** : vous avez le choix entre 2 modes.
    - **Configuration recommandée** : votre zone DNS est configurée automatiquement. Convient si vous n'avez pas de configuration spécifique dans votre zone DNS pour les enregistrements MX, SPF, DKIM et SRV. Tous les e-mails adressés à votre nom de domaine sont alors acheminés vers ce service dès l'ajout du domaine.
    - **Configuration personnalisée** : convient si vous avez déjà configuré une offre e-mail sur votre nom de domaine. Vous pouvez choisir les éléments qui vous intéressent : les 4 cases de configuration automatique sont cochées par défaut. Décochez celles des enregistrements que vous souhaitez configurer vous-même.
        - Si vous souhaitez utiliser un service e-mail privé ou externe à OVHcloud en complément de cette plateforme e-mail, renseignez le nom d'hôte du serveur e-mail dans le champ **URL du serveur email cible**.
        - *Configurer automatiquement l'enregistrement MX (réception)* : renseigne automatiquement les serveurs de réception OVHcloud (s'applique à toutes les offres e-mail OVHcloud).
        - *Configurer automatiquement l'enregistrement SRV (autodiscover)* : permet au logiciel de messagerie de configurer automatiquement les comptes Exchange sur votre nom de domaine.
        - *Configurer automatiquement l'enregistrement SPF* : renseigne automatiquement l'enregistrement SPF pour autoriser les serveurs d'envoi d'e-mails OVHcloud à transmettre vos e-mails. Cet enregistrement est valable pour l'ensemble des offres e-mail OVHcloud.
        - *Configurer et activer l'enregistrement DKIM automatiquement* : renseigne automatiquement les enregistrements nécessaires pour authentifier vos envois d'e-mails.

<img className="thumbnail" alt="Configuration personnalisée avec le champ URL du serveur email cible et les cases DNS" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain/console/add_domain_exchange_step2-1b.png" loading="lazy" />

- **Si vous avez renseigné un nom de domaine non géré par votre compte OVHcloud** : cela signifie que le nom de domaine, plus particulièrement sa zone DNS, n'est pas géré depuis la console OVHcloud. Il peut aussi être enregistré auprès d'un autre bureau d'enregistrement. Vous devez alors le configurer directement depuis son interface de gestion, quel que soit le mode choisi ensuite.
    - **Configuration recommandée** : convient si vous utilisez uniquement les offres e-mail OVHcloud.

    - **Configuration personnalisée** : le champ **URL du serveur email cible** et les 4 cases s'affichent comme pour un nom de domaine de la liste. Si vous souhaitez utiliser un service e-mail privé ou externe à OVHcloud en complément de cette plateforme e-mail, renseignez le nom d'hôte du serveur e-mail dans ce champ.

<img className="thumbnail" alt="Panneau Ajouter un domaine avec un nom de domaine non géré saisi" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain/console/add_domain_exchange_step2-2.png" loading="lazy" />

Une fois vos choix faits, cliquez sur le bouton <code className="action">Ajouter</code>, en bas du panneau, pour valider l'ajout du domaine.

{/* CP-STEPS-END:ajouter-nom-de-domaine */}

### Configurer le nom de domaine (zone DNS)

{/* CP-STEPS-START:configurer-nom-de-domaine-zone-dns */}

Une fois le nom de domaine ajouté, vérifiez sa configuration dans le tableau. Dans la colonne **Diagnostic**, une pastille de couleur verte indique que le nom de domaine est correctement configuré.

Si une pastille est rouge ou orange :

- **si vous avez choisi une configuration automatique lors de l'ajout du domaine** : l'affichage dans la console OVHcloud peut prendre quelques instants pour s'actualiser.

- **si vous avez renseigné un nom de domaine non géré par votre compte OVHcloud** :
    - Si la pastille `CNAME` est orange (nom de domaine en cours de validation), consultez notre guide « [Ajouter un enregistrement CNAME pour valider votre domaine sur votre offre e-mail](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-dns-cname) ».
    - Une fois le nom de domaine validé, cliquez sur le bouton <code className="action">⋮</code> à droite de la ligne du nom de domaine, puis sur <code className="action">Diagnostics</code> pour afficher les modifications que vous devez réaliser. La page qui s'ouvre comporte un onglet par enregistrement (`MX`, `SRV`, `SPF` et `DKIM`), avec son statut et les enregistrements à créer dans la zone DNS. Si ce nom de domaine n'utilise pas la configuration d'OVHcloud (ses serveurs DNS), vous devrez réaliser les modifications depuis l'interface de gestion de votre nom de domaine.

<img className="thumbnail" alt="Tableau de l'onglet Domaines associés avec les pastilles de la colonne Diagnostic" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain/console/add_domain_exchange_step4.png" loading="lazy" />

:::info
La modification de la configuration d'un nom de domaine nécessite un temps de propagation de 4 à 24 heures maximum avant d'être pleinement effective.

:::


Pour vérifier la configuration d'un nom de domaine, revenez à l'onglet <code className="action">Domaines associés</code> de votre service. Si la pastille est à présent verte, le nom de domaine est correctement configuré. Sinon, la propagation n'est peut-être pas encore terminée.

{/* CP-STEPS-END:configurer-nom-de-domaine-zone-dns */}

### Modifier le mode d'un domaine associé

Il est possible de modifier le mode d'un domaine associé sur votre plateforme. Au préalable, il est nécessaire de comprendre la différence de fonctionnement entre les modes autoritatif et non-autoritatif.

:::info
**Autoritatif / non-autoritatif**

- Le choix du mode **autoritatif** sur votre plateforme e-mail (*Server A*) implique l'hébergement de l'ensemble des adresses e-mail de votre nom de domaine sur cette plateforme.<br/>Par exemple, si l'on envoie un e-mail à l'adresse « *mary.johnson@mydomain.ovh* », le « *Server A* » renvoie un message d'échec à l'expéditeur car cette adresse n'existe pas sur le « *Server A* ».<br/><br/>

- Le mode **non-autoritatif** sur votre plateforme e-mail (*Server A*) permet une répartition des adresses e-mail de votre nom de domaine entre votre plateforme e-mail principale (*Server A*) et un autre service e-mail (*Server B*).<br/>Par exemple, si l'on envoie un e-mail à l'adresse « *mary.johnson@mydomain.ovh* », le « *Server A* » transmettra l'e-mail au « *Server B* » pour que ce dernier puisse le délivrer.<br/>

<img className="thumbnail" alt="Authoritative" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain/add_domain_exchange_authoritative.png" loading="lazy" />

:::


{/* CP-STEPS-START:modifier-mode-domaine-associe */}

1. Cliquez sur l'onglet <code className="action">Domaines associés</code>.
1. Cliquez sur le bouton <code className="action">⋮</code> à droite du nom de domaine concerné.
1. Cliquez sur <code className="action">Configuration</code>.
1. Dans la fenêtre **Configuration domaine**, sélectionnez le mode de votre choix dans le menu déroulant **Mode** : **Autoritatif** ou **Non-autoritatif**. En mode **Non-autoritatif**, renseignez également le champ **Serveur e-mail cible**.
1. Cliquez sur <code className="action">Suivant</code>, vérifiez le récapitulatif, puis cliquez sur <code className="action">Configurer</code>.


:::warning

Si un nom de domaine est déjà déclaré en mode **autoritatif** sur une autre plateforme e-mail, son ajout avec la **Configuration recommandée** est refusé. Pour que les deux plateformes cohabitent, le nom de domaine doit être en mode **non-autoritatif** sur chacune d'elles : choisissez la **Configuration personnalisée** lors de son ajout, puis passez-le en mode **non-autoritatif** sur l'autre plateforme.


:::

{/* CP-STEPS-END:modifier-mode-domaine-associe */}


### Configurer et utiliser les comptes

{/* CP-STEPS-START:configurer-utiliser-comptes */}

<Region zones={['eu']}>

Maintenant que vous avez ajouté les noms de domaine souhaités à votre service, vous pouvez configurer vos comptes e-mail avec ces derniers. Cette manipulation s'effectue depuis l'onglet <code className="action">Gestion des comptes</code>, dans le sous-onglet **Compte email** ouvert par défaut (onglet <code className="action">Comptes</code> sur Email Pro). Si besoin, vous pouvez commander des comptes supplémentaires grâce au bouton <code className="action">Commander des comptes</code> (Hosted Exchange et Email Pro) ou en créer grâce au bouton <code className="action">Ajouter un compte</code> (Private Exchange).

</Region>

<Region zones={['ca']}>

Maintenant que vous avez ajouté les noms de domaine souhaités à votre service, vous pouvez configurer vos comptes e-mail avec ces derniers. Cette manipulation s'effectue depuis l'onglet <code className="action">Gestion des comptes</code>, dans le sous-onglet **Compte email** ouvert par défaut (onglet <code className="action">Comptes</code> sur Email Pro). Si besoin, vous pouvez commander des comptes supplémentaires grâce au bouton <code className="action">Commander des comptes</code> (Hosted Exchange et Email Pro).

</Region>

{/* CP-STEPS-END:configurer-utiliser-comptes */}

Pour rappel, toutes les adresses créées sur votre service seront en mesure de visualiser dans l'annuaire l'ensemble des adresses de ce service, y compris celles possédant un nom de domaine différent.

Une fois les comptes totalement configurés, vous pouvez commencer à les utiliser. Pour cela, OVHcloud met à votre disposition le **webmail**, accessible [ici](/links/web/email). Pour une utilisation optimale de votre adresse sur un logiciel, assurez-vous de sa compatibilité avec le service.

</Region>

### Supprimer un nom de domaine d'une plateforme

<Region zones={['eu']}>

Si vous souhaitez retirer un nom de domaine attaché à votre service Exchange ou Email Pro, vous devez vérifier que celui-ci n'est pas lié à des comptes e-mail, alias, ressources, comptes partagés (uniquement sur Exchange), groupes, contacts externes ou pieds de page toujours configurés. Dans ce cas, il sera nécessaire d'**attacher ces comptes à un autre nom de domaine** sur votre plateforme ou de les **supprimer**.

</Region>

<Region zones={['ca']}>

Si vous souhaitez retirer un nom de domaine attaché à votre service Exchange, vous devez vérifier que celui-ci n'est pas lié à des comptes e-mail, alias, ressources, comptes partagés (uniquement sur Exchange), groupes, contacts externes ou pieds de page toujours configurés. Dans ce cas, il sera nécessaire d'**attacher ces comptes à un autre nom de domaine** sur votre plateforme ou de les **supprimer**.

</Region>

:::warning
Avant de supprimer des comptes e-mail, assurez-vous qu'ils ne sont pas utilisés. Une sauvegarde de ces comptes peut s'avérer nécessaire. Au besoin, consultez le guide « [Migrer manuellement votre adresse e-mail](/guides/web-cloud/email-and-collaborative-solutions/migrating/manual-email-migration) » qui vous décrira comment exporter les données d'un compte depuis la console OVHcloud ou un logiciel de messagerie.

:::


{/* CP-STEPS-START:supprimer-nom-de-domaine */}

Accédez à l'onglet <code className="action">Domaines associés</code> de votre plateforme. Dans le tableau, la colonne **Comptes** indique le nombre de comptes associés à chaque nom de domaine.

Vous ne pouvez pas supprimer un nom de domaine tant que des comptes e-mail y sont attachés. Dans ce cas, vous avez 2 possibilités :

**Attacher les comptes à un autre nom de domaine** :

1. Rendez-vous dans l'onglet <code className="action">Gestion des comptes</code> (<code className="action">Comptes</code> sur Email Pro).
1. À droite du compte à modifier, cliquez sur le bouton <code className="action">⋮</code>.
1. Cliquez sur <code className="action">Modifier</code>.

    <img className="thumbnail" alt="Onglet Gestion des comptes, menu ⋮ d'un compte Exchange ouvert sur l'entrée Modifier" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain/console/add_domain_exchange_step8.png" loading="lazy" />

1. Sur la page **Modifier un compte Exchange** (panneau **Modifier un compte E-mail Pro** sur Email Pro), sélectionnez le nouveau nom de domaine du compte dans le menu déroulant qui suit le `@` du champ **Compte email**.

    <img className="thumbnail" alt="Page Modifier un compte Exchange, liste des noms de domaine du champ Compte email" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain/console/add_domain_exchange_step9.png" loading="lazy" />

**Supprimer les comptes de votre plateforme** :

1. Rendez-vous dans l'onglet <code className="action">Gestion des comptes</code> (<code className="action">Comptes</code> sur Email Pro).
1. À droite du compte à supprimer, cliquez sur le bouton <code className="action">⋮</code>.
1. Cliquez sur <code className="action">Réinitialiser ce compte</code> (Hosted Exchange) ou <code className="action">Réinitialiser</code> (Email Pro).

<Region zones={['eu']}>

Sur un service Private Exchange, cliquez à l'étape 3 sur <code className="action">Supprimer ce compte</code>.

</Region>

<img className="thumbnail" alt="Menu ⋮ d'un compte de l'onglet Gestion des comptes, entrée Réinitialiser ce compte" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain/console/add_domain_exchange_step7.png" loading="lazy" />

Une fois les comptes rattachés à un autre nom de domaine, réinitialisés ou supprimés, vous pouvez supprimer le nom de domaine.

Depuis l'onglet <code className="action">Domaines associés</code> de votre plateforme, cliquez sur le bouton <code className="action">⋮</code> à droite du nom de domaine concerné, puis sur <code className="action">Supprimer ce domaine</code>.

<img className="thumbnail" alt="Menu ⋮ d'un nom de domaine de l'onglet Domaines associés, avec l'action Supprimer ce domaine" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain/console/add_domain_exchange_step10.png" loading="lazy" />

{/* CP-STEPS-END:supprimer-nom-de-domaine */}
