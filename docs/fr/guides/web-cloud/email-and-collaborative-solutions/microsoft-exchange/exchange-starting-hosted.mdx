## Objectif 

Le service Hosted Exchange permet de bénéficier d’adresses e-mail professionnelles facilitant le travail collaboratif grâce à des fonctionnalités comme la synchronisation du calendrier et celle des contacts.

**Découvrez comment débuter avec votre service Hosted Exchange.**

## Prérequis

- Avoir souscrit une offre [Hosted Exchange](https://www.ovhcloud.com/fr/emails/hosted-exchange/).
- Avoir reçu l’e-mail vous confirmant l’installation de votre solution Hosted Exchange.
- Disposer d’un nom de domaine.

## En pratique

### Accéder à la gestion de votre service

{/* CP-STEPS-START:acceder-gestion-service */}

Une fois votre service Hosted Exchange créé et disponible, sélectionnez-le dans la console OVHcloud.

:::info

Le nom d'un service Hosted Exchange dans la console OVHcloud débute par **hosted-**, puis contient une partie de votre référence client et se termine par un chiffre (1 pour le premier service Hosted Exchange installé, 2 pour le deuxième, etc.).

:::

{/* CP-STEPS-END:acceder-gestion-service */}


### Effectuer la première configuration du service

Votre service n'ayant encore jamais été utilisé, vous allez devoir réaliser sa première configuration. Celle-ci vous permettra par la suite de pouvoir utiliser vos nouvelles adresses e-mail Exchange.

{/* CP-STEPS-START:premiere-configuration-service */}

Pour ce faire, lorsque vous accédez pour la première fois à la gestion de votre service Hosted Exchange, la page **Ajouter un domaine** s'affiche directement. À droite de la page, la section **Votre configuration** récapitule les deux éléments à configurer : le **Domaine** et les **Comptes**.

Cette page de configuration vous permet plusieurs manipulations. Selon votre situation :

{/* CP-STEPS-END:premiere-configuration-service */}

#### Choisir un nom de domaine

{/* CP-STEPS-START:choisir-nom-de-domaine */}

Sur la page **Ajouter un domaine**, sélectionnez l'une des deux options suivantes :

- **Sélectionner un domaine dans la liste** : choisissez ensuite l'un de vos noms de domaine dans le menu déroulant **Nom de domaine**.
- **Saisir un nom de domaine non géré par votre compte OVH** : saisissez ensuite dans le champ **Nom de domaine** un nom de domaine qui n'est pas géré dans votre compte client OVHcloud **mais que vous pouvez configurer**.

<img className="thumbnail" alt="Page Ajouter un domaine d'un service Hosted Exchange, choix du nom de domaine" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-starting-hosted/console/exchange-wizard01.png" loading="lazy" />

{/* CP-STEPS-END:choisir-nom-de-domaine */}

#### Allez-vous utiliser uniquement l'offre Exchange OVHcloud avec ce domaine ?

{/* CP-STEPS-START:utiliser-uniquement-offre-exchange */}

Une fois le nom de domaine indiqué, la section **Configuration** s'affiche juste en dessous. La question « **Comment voulez-vous configurer votre domaine ?** » va déterminer le type de configuration de votre nom de domaine.

- Si vous utilisez une offre Exchange seule ou avec d'autres offres **e-mail OVHcloud**, la configuration pourra se faire automatiquement avec la **Configuration recommandée**, ou manuellement avec la **Configuration personnalisée**, en utilisant uniquement les serveurs e-mail d'OVHcloud. Avec la **Configuration recommandée**, tous les e-mails adressés à votre nom de domaine sont acheminés vers ce service dès l'enregistrement de la configuration.
- Si vous utilisez votre offre Exchange en complément d'un service e-mail **externe aux offres e-mail OVHcloud**, sélectionnez **Configuration personnalisée** : il vous sera demandé de renseigner, dans le champ **URL du serveur email cible**, l'URL du serveur de réception de votre service e-mail externe, à la place du serveur OVHcloud proposé.

<img className="thumbnail" alt="Section Configuration de la page Ajouter un domaine, choix entre configuration recommandée et personnalisée" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-starting-hosted/console/exchange-wizard02.png" loading="lazy" />

{/* CP-STEPS-END:utiliser-uniquement-offre-exchange */}

#### Comment souhaitez-vous configurer votre zone DNS ?

{/* CP-STEPS-START:configurer-zone-dns */}

- **Configuration recommandée** : Le nom de domaine renseigné sera automatiquement configuré au niveau de sa zone DNS (enregistrements MX, SRV, SPF et DKIM), si ce dernier est géré par OVHcloud sur le même identifiant client que votre service Exchange.
- **Configuration personnalisée** : Le nom de domaine n'est pas géré dans le même compte client OVHcloud que votre plateforme, il est géré chez un autre prestataire de nom de domaine, ou vous souhaitez simplement réaliser votre configuration vous-même. Les quatre cases de configuration automatique des enregistrements MX, SRV, SPF et DKIM sont cochées par défaut : décochez celles des enregistrements que vous souhaitez configurer vous-même. Vous retrouverez ensuite les valeurs à renseigner dans l'onglet <code className="action">Domaines associés</code> de votre plateforme : cliquez sur le bouton <code className="action">⋮</code> à droite du nom de domaine, puis sur <code className="action">Diagnostics</code>.

<img className="thumbnail" alt="Configuration personnalisée avec le champ URL du serveur email cible et les cases DNS" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-starting-hosted/console/exchange-wizard03.png" loading="lazy" />

{/* CP-STEPS-END:configurer-zone-dns */}

#### **Configuration des comptes Exchange**

{/* CP-STEPS-START:configuration-comptes-exchange */}

Une fois le nom de domaine enregistré avec le bouton <code className="action">Enregistrer la configuration</code>, la section **Créer les premiers comptes** s'affiche. Votre service est livré avec des comptes prêts à l'emploi : déterminez le nom de vos adresses e-mail Exchange (**Adresse e-mail**) et ajoutez des informations complémentaires (**Prénom**, **Nom**, **Mot de passe**), puis cliquez sur <code className="action">Créer les premiers comptes</code>. Les comptes que vous ne nommez pas maintenant pourront l'être plus tard : pour passer cette étape, cliquez sur <code className="action">Créer mes comptes plus tard</code>.

{/* CP-STEPS-END:configuration-comptes-exchange */}

#### **Cas particulier**

{/* CP-STEPS-START:cas-particulier */}

- Si vous configurez votre plateforme Exchange avec un nom de domaine qui n'est pas géré sur le même compte client OVHcloud que cette plateforme, ou chez un autre prestataire de nom de domaine, la page **Configuration DNS requise** s'affiche après l'enregistrement de la configuration.

Cette page vous invite à ajouter un **champ CNAME** dans la zone DNS du nom de domaine : l'enregistrement à créer est indiqué sous **Enregistrement CNAME à créer**, et sa valeur sous **Cible**. Cette entrée a pour but de vérifier que vous gérez bien ce nom de domaine. Une fois l'enregistrement CNAME validé, la section **Créer les premiers comptes** s'affiche.

:::warning

Sans cette validation par champ CNAME, il est impossible d'utiliser la plateforme avec ce nom de domaine.

:::

- Si vous configurez votre plateforme Exchange avec un nom de domaine qui n'est pas géré sur le même compte client OVHcloud que cette plateforme, qu'il est géré chez un autre prestataire de nom de domaine, ou si vous avez choisi de configurer manuellement votre nom de domaine avec la **Configuration personnalisée**, retrouvez les valeurs à renseigner dans votre zone DNS depuis l'onglet <code className="action">Domaines associés</code> de votre service : cliquez sur le bouton <code className="action">⋮</code> à droite du nom de domaine, puis sur <code className="action">Diagnostics</code>.

<img className="thumbnail" alt="Page de diagnostic d'un domaine, onglet MX avec les priorités et les cibles" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-starting-hosted/console/exchange-wizard06.png" loading="lazy" />

La page qui s'ouvre comporte un onglet par enregistrement (`MX`, `SRV`, `SPF` et `DKIM`), avec son statut et les valeurs à renseigner dans votre zone DNS (**Type**, **Priorité**, **Cible**). Les **champs MX** correspondent à la réception de vos e-mails. Le **champ SRV** correspond à la configuration automatique de vos adresses e-mail.

{/* CP-STEPS-END:cas-particulier */}

Retrouvez les détails de configuration de votre zone DNS concernant votre service e-mail sur notre page « [Ajouter un champ MX à la configuration de son nom de domaine](/guides/web-cloud/domains/dns-zone-mx) ».

### Ajouter des noms de domaines additionnels (facultatif)

Une fois la première configuration de votre domaine terminée, vous pouvez également configurer, via l'assistant, des noms de domaines additionnels si vous le souhaitez et si vous ne l'avez pas déjà fait.

:::warning
Toutes les adresses créées sur votre service Exchange seront visibles dans l'annuaire des adresses de ce service, y compris celles possédant un nom de domaine différent. Pour dissocier l'affichage des domaines, vous devez commander un nouveau service Hosted Exchange pour le ou les noms de domaine concernés.

:::


{/* CP-STEPS-START:ajouter-noms-de-domaines-additionnels */}

Pour ajouter un nouveau nom de domaine, sélectionnez le service Hosted Exchange concerné dans la <ManagerLink to="/">console OVHcloud</ManagerLink> et cliquez sur l'onglet <code className="action">Domaines associés</code>. Le tableau affiche les noms de domaines actuellement configurés ou en passe de l'être sur votre service. Pour en ajouter de nouveaux, cliquez sur le bouton <code className="action">Ajouter un domaine</code>, au-dessus du tableau, puis suivez les étapes du panneau **Ajouter un domaine** qui s'ouvre.

Pour en apprendre plus, vous pouvez consulter la documentation intitulée [Ajouter un nom de domaine sur son service Exchange](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain).

:::info
Si un nom de domaine requiert une action particulière concernant sa configuration, une pastille rouge s'affiche dans la colonne **Diagnostic** du tableau. Pour afficher les modifications à effectuer, cliquez sur le bouton <code className="action">⋮</code> à droite du nom de domaine, puis sur <code className="action">Diagnostics</code>. Si ce nom de domaine n'utilise pas la configuration d'OVHcloud (ses serveurs DNS), vous devrez réaliser les modifications depuis l'interface vous permettant de gérer la configuration de votre domaine.

:::

<img className="thumbnail" alt="Onglet Domaines associés d'un service Hosted Exchange, bouton Ajouter un domaine au-dessus du tableau" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-starting-hosted/console/first-steps-hosted-exchange-add-domain.png" loading="lazy" />

{/* CP-STEPS-END:ajouter-noms-de-domaines-additionnels */}

### Configurer des comptes Exchange supplémentaires (facultatif)

Vous pouvez configurer des comptes additionnels si vous le souhaitez et si vous ne l'avez pas déjà fait via l'assistant.

{/* CP-STEPS-START:configurer-comptes-exchange-supplementaires */}

Pour cela, cliquez sur le service Hosted Exchange concerné dans la <ManagerLink to="/">console OVHcloud</ManagerLink>, puis sur l'onglet <code className="action">Gestion des comptes</code>. Le tableau du sous-onglet **Compte email**, ouvert par défaut, affiche les comptes actuellement configurés ou en attente de l'être sur votre service.

Les comptes en attente de configuration s'affichent dans le tableau sous la forme « *@configureme.me* ». Pour les configurer, cliquez sur le bouton <code className="action">⋮</code> à droite du compte, puis sur <code className="action">Configurer</code>, et suivez les étapes.

:::info

Répétez cette étape autant de fois que nécessaire selon le nombre de comptes que vous possédez. Vous pouvez en commander de nouveaux grâce au bouton <code className="action">Commander des comptes</code>, au-dessus du tableau.

:::

<img className="thumbnail" alt="Onglet Gestion des comptes d'un service Hosted Exchange, bouton Commander des comptes" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-starting-hosted/console/first-steps-hosted-exchange-add-account.png" loading="lazy" />

{/* CP-STEPS-END:configurer-comptes-exchange-supplementaires */}

### Utiliser vos adresses e-mail

Une fois vos comptes configurés, il ne reste plus qu’à les utiliser. Pour cela, OVHcloud met à disposition le webmail **Outlook Web App** (OWA). Ce dernier est accessible à l’adresse [Webmail](https://www.ovhcloud.com/fr/mail/). Pour y accéder, vous devez y renseigner les identifiants relatifs à votre adresse e-mail. Si vous souhaitez obtenir de l'aide sur l'utilisation de OWA, [consultez notre documentation](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/landing-page-microsoft-exchange).

Si c'est la première fois que vous vous connectez à OWA avec cette adresse e-mail, vous serez invité à définir la langue de l'interface ainsi que le fuseau horaire. Ensuite, cliquez sur <code className="action">Enregistrer</code> pour continuer.

:::info
Les fuseaux horaires sont listés selon [la norme UTC (temps universel coordonné)](https://en.wikipedia.org/wiki/Coordinated_Universal_Time#/media/File:World_Time_Zones_Map.png), et non par ordre alphabétique des villes.

**Exemple** : Pour l'Europe de l'Ouest, il s'agit de UTC +1 (Bruxelles, Copenhague, Madrid, Paris).

:::


Si vous souhaitez configurer votre adresse e-mail sur un logiciel de messagerie ou un périphérique comme un smartphone ou une tablette, [consultez notre documentation](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/landing-page-microsoft-exchange). Pour une utilisation optimale de votre adresse Exchange sur un logiciel, assurez-vous de sa bonne compatibilité avec le service.

OVHcloud propose, depuis l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>, des licences Outlook en option avec votre compte e-mail Exchange.

Pour y souscrire, consultez notre page « [Obtenir une licence Outlook pour Exchange](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license) ».

<Region zones={['eu']}>

Vous pouvez également obtenir des licences [Microsoft 365](/links/web/ms365). Nous vous recommandons l'une de ces solutions si vous souhaitez bénéficier du logiciel de messagerie Outlook ou de plus de logiciels de la suite Office, selon vos besoins.

</Region>

:::info
Exchange permet une synchronisation complète de vos paramètres (filtres, signatures, dossiers, etc.), que vous utilisiez une application web ou un logiciel de messagerie compatible.
Ainsi, si vous utilisez Exchange sur trois appareils et via des moyens de connexion différents (webmail, logiciel de messagerie ou client compatibles), toutes vos informations seront disponibles en même temps.

:::


### Paramétrer les fonctions collaboratives (facultatif)

Maintenant que votre service Hosted Exchange est configuré et fonctionnel, vous pouvez mettre en place les fonctionnalités collaboratives inhérentes au service dans votre <ManagerLink to="/">espace client OVHcloud</ManagerLink>. Celles-ci peuvent vous donner la possibilité de créer des ressources (salles de réunion, équipements, etc.), mais aussi des groupes, entre autres.

{/* CP-STEPS-START:parametrer-fonctions-collaboratives */}

Pour activer ces différentes fonctions, sélectionnez le service Hosted Exchange concerné dans la <ManagerLink to="/">console OVHcloud</ManagerLink>. Selon la fonction, l'action à effectuer se trouve dans les sous-onglets de l'onglet <code className="action">Gestion des comptes</code> (comptes partagés, groupes et ressources) ou dans les sections de l'onglet <code className="action">Paramètres</code> (pieds de page et contacts externes).

{/* CP-STEPS-END:parametrer-fonctions-collaboratives */}

Pour obtenir de l'aide sur l'une des fonctionnalités, [consultez notre documentation](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/landing-page-microsoft-exchange).
