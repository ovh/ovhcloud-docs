## Objectif

Exporter une boîte e-mail au format PST vous en donne une copie locale : pour l'archiver avant de supprimer un compte, la transmettre au départ d'un collaborateur, la transférer vers un autre service de messagerie ou répondre à une obligation de conservation. Microsoft Exchange chez OVHcloud peut exporter une boîte e-mail côté serveur : vous demandez l'export, OVHcloud le construit, puis vous téléchargez une archive ZIP contenant un ou plusieurs fichiers `.pst`, `readme.md` et `checksum.txt`. L'export ne passe pas par Outlook : l'espace client OVHcloud et l'API OVHcloud couvrent chacun l'opération de bout en bout.

Cette fonctionnalité est disponible pour Hosted Exchange, Private Exchange et Trusted Exchange. Elle s'applique aux boîtes e-mail individuelles : les groupes ne peuvent pas être exportés.

**Ce guide vous explique comment exporter une boîte e-mail Exchange vers une archive PST, depuis l'espace client OVHcloud ou via l'API OVHcloud.**

## Prérequis

- Disposer d'un service [Hosted Exchange](/links/web/emails-hosted-exchange), [Private Exchange](/links/web/emails-private-exchange) ou [Trusted Exchange](/links/web/emails-trusted-exchange).
- Disposer des droits d'administration sur ce service dans l'<ManagerLink to="/">espace client OVHcloud</ManagerLink>.
- Disposer d'assez d'espace disque local pour l'archive ZIP et pour son contenu extrait.
- Pour la méthode API : disposer d'identifiants API générés via la <CreateToken rights="GET=/email/exchange/*&POST=/email/exchange/*&DELETE=/email/exchange/*">page de génération de tokens OVHcloud</CreateToken>, avec au minimum les droits `GET`, `POST` et `DELETE` sur `/email/exchange/*`.

:::warning
**Un export par boîte e-mail toutes les 24 heures.** Une fois un export demandé pour une adresse e-mail, le suivant n'est accepté que 24 heures plus tard. Tenez-en compte avant d'exporter plusieurs boîtes e-mail à la suite.

:::

## En pratique

### Exporter depuis l'espace client

1. Ouvrez l'onglet <code className="action">Comptes e-mail</code>.
2. Sur la ligne de la boîte e-mail à exporter, cliquez sur <code className="action">...</code>, puis sur <code className="action">Exporter au format PST</code>.

    <img className="thumbnail" alt="Menu d'actions d'un compte e-mail avec l'entrée Exporter au format PST" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-menu.png" loading="lazy" />

3. Dans la fenêtre <code className="action">Exporter au format .pst</code>, cliquez sur <code className="action">Télécharger</code> pour lancer l'export. Il s'exécute en arrière-plan et prend de quelques minutes à plusieurs heures selon la taille de la boîte e-mail. Vous pouvez fermer la fenêtre et quitter la page : rouvrez-la à tout moment pour voir la progression, affichée en pourcentage.

    <img className="thumbnail" alt="Fenêtre Exporter au format .pst affichant la progression de l'export" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-progress.png" loading="lazy" />

4. Une fois l'export terminé, ouvrez le même menu <code className="action">...</code> et cliquez de nouveau sur <code className="action">Exporter au format PST</code>. Le lien de téléchargement est alors généré automatiquement, ce qui prend 2 à 3 minutes.

    <img className="thumbnail" alt="Fenêtre Exporter au format .pst pendant la génération du lien de téléchargement" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-link.png" loading="lazy" />

5. Lorsque le lien est prêt, la fenêtre confirme que la boîte e-mail est disponible au format `.pst` et indique la date jusqu'à laquelle le fichier reste téléchargeable. Cliquez sur <code className="action">Télécharger</code> pour récupérer l'archive ZIP, puis extrayez-la et vérifiez-la (voir « [Vérifier et ouvrir l'archive](#vérifier-et-ouvrir-larchive) »).

    <img className="thumbnail" alt="Fenêtre d'export proposant le téléchargement de l'archive et un nouvel export" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-download.png" loading="lazy" />

:::info
Le lien de téléchargement est temporaire : la fenêtre affiche la date jusqu'à laquelle le fichier reste disponible. Passé cette date, l'archive est supprimée et un nouvel export est nécessaire. La même fenêtre permet de cliquer sur <code className="action">Lancer une nouvelle exportation</code>, ce qui **supprime immédiatement l'archive précédente**.

:::

### Exporter via l'API

Deux objets portent l'ensemble du processus : `export` construit l'archive et rend compte de sa progression, et `exportURL` fournit une URL de téléchargement temporaire. Tous les appels ci-dessous appartiennent à la <ApiLink section="/email/exchange">section `/email/exchange`</ApiLink> de l'API OVHcloud.

#### Trouver les paramètres de chemin

Chaque appel a besoin de 3 valeurs : le nom de l'organisation, le nom du service et l'adresse de la boîte e-mail. Les 2 premiers sont des noms internes, de la forme `ab12345-ovh`, et non les libellés affichés dans l'espace client OVHcloud. Récupérez-les dans l'ordre, chaque appel alimentant le suivant.

**1. Organisation** (`organizationName`) : listez les organisations Exchange de votre compte avec l'appel API suivant :

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange"} />

**2. Service** (`exchangeService`) : listez les services Exchange de l'organisation avec l'appel API suivant :

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service"} />

**3. Boîte e-mail** (`primaryEmailAddress`) : listez les comptes e-mail du service avec l'appel API suivant :

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account"} />

Chaque appel renvoie une liste de chaînes. Si l'adresse de la boîte e-mail contient des caractères non autorisés dans une URL, encodez-les en pourcentage dans le chemin (`+` devient `%2B`, etc.).

#### Demander l'export

Demandez l'export de la boîte e-mail avec l'appel API suivant :

<Api version="v1" section="/email/exchange" method="POST" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

L'appel ne prend aucun paramètre dans le corps de la requête et renvoie une tâche, qui confirme seulement que la demande est enregistrée :

```json
{
  "id": 123456789,
  "function": "addExportPstRequest",
  "status": "todo",
  "todoDate": "2026-09-01T10:12:33+02:00",
  "finishDate": null
}
```

#### Suivre la progression

Consultez la demande d'export pour suivre sa progression :

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

| Propriété | Type | Description |
|---|---|---|
| `creationDate` | datetime | Date de création de la demande d'export |
| `percentComplete` | long | Avancement de l'export, en pourcentage |
| `taskPendingId` | long | Identifiant de la tâche en cours, `0` quand aucune ne s'exécute |

```json
{
  "creationDate": "2026-09-01T10:12:33+02:00",
  "percentComplete": 42,
  "taskPendingId": 123456789
}
```

Répétez cet appel jusqu'à ce que `percentComplete` atteigne `100`, au plus une fois par minute. Une erreur `404` signifie qu'aucune demande d'export n'existe pour cette boîte e-mail : soit elle n'a jamais été créée, soit elle a déjà été supprimée.

Les statuts de tâche sont `todo`, `doing`, `done`, `error`, `standby` et `canceled`. Les fonctions de tâche liées à l'export sont `addExportPstRequest`, `deleteExportPstRequest` et `generatePstUrl`.

#### Obtenir l'URL de téléchargement

L'objet `export` ne renvoie jamais d'URL de téléchargement. Générer le lien demande 2 appels.

**1. Générer l'URL** : créez le lien de téléchargement, ce qui enregistre une tâche `generatePstUrl`, avec l'appel API suivant :

<Api version="v1" section="/email/exchange" method="POST" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/exportURL"} />

**2. Lire l'URL** : une fois la tâche terminée, lisez le lien généré avec l'appel API suivant :

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/exportURL"} />

| Propriété | Type | Description |
|---|---|---|
| `url` | string | URL de téléchargement de l'archive |
| `expiration` | datetime | Date d'expiration de l'URL |

```json
{
  "url": "https://exchange-export.storage.example/abc123/john.smith.zip?token=...",
  "expiration": "2026-09-01T11:15:00+02:00"
}
```

L'URL est déjà signée : téléchargez l'archive directement depuis cette URL, sans en-tête d'authentification. Une erreur `404` sur l'appel `GET` signifie que l'URL n'a pas encore été générée (la tâche `generatePstUrl` est toujours en cours) ou qu'elle a expiré.

:::info
**La durée de validité de l'URL est limitée.** Lisez `expiration` plutôt que de présumer du délai, et ne générez l'URL qu'au moment de télécharger. Une fois expirée, relancez l'appel `POST` sur `exportURL` pour obtenir un nouveau lien : tant que l'archive existe, inutile de refaire l'export.

:::

#### Supprimer la demande d'export

Supprimez la demande d'export avec l'appel API suivant :

<Api version="v1" section="/email/exchange" method="DELETE" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

Utilisez-le pour annuler un export en cours, ou pour supprimer la demande une fois l'archive téléchargée et pouvoir en demander une nouvelle (toujours dans la limite d'un export par 24 heures). L'appel supprime aussi l'archive côté OVHcloud : téléchargez-la d'abord.

### Vérifier et ouvrir l'archive

Quelle que soit la méthode, l'archive ZIP contient :

| Élément | Description |
|---|---|
| `*.pst` | Les données de la boîte e-mail. Une boîte volumineuse est répartie sur plusieurs fichiers PST. |
| `readme.md` | Les notes d'OVHcloud sur l'export et son contenu. |
| `checksum.txt` | L'empreinte SHA-256 de chaque fichier `.pst` de l'archive. |

{/* DRAFT: To document — which items the PST files contain (emails, calendar, contacts, tasks, shared folders?) and what is left out */}

Extrayez l'archive, puis vérifiez les fichiers PST avec `checksum.txt` avant de les importer : un téléchargement tronqué produit un fichier PST qu'Outlook refuse d'ouvrir ou ouvre incomplet. Les commandes ci-dessous supposent la disposition habituelle `<hash> <filename>`, une ligne par fichier.

Sous Windows, avec PowerShell :

```powershell
Get-Content .\checksum.txt | Where-Object { $_.Trim() } | ForEach-Object {
    $hash, $file = $_.Trim() -split '\s+', 2
    $file = $file.TrimStart('*')
    $actual = (Get-FileHash $file -Algorithm SHA256).Hash
    "{0,-8} {1}" -f $(if ($actual -eq $hash.ToUpper()) { "OK" } else { "MISMATCH" }), $file
}
```

Sous Linux ou macOS :

```bash
sha256sum -c checksum.txt
# john.smith.pst: OK
# john.smith-2.pst: OK
```

Si une empreinte ne correspond pas, téléchargez de nouveau l'archive. Si l'erreur persiste, demandez un nouvel export.

Pour ouvrir le résultat dans Outlook classique pour Windows, allez dans <code className="action">Fichier</code> > <code className="action">Ouvrir et exporter</code> > <code className="action">Ouvrir le fichier de données Outlook</code>, puis sélectionnez chaque fichier `.pst` extrait. À ce jour, le nouvel Outlook pour Windows n'ouvre pas les fichiers `.pst`.

:::info
**Limitations**

- La durée de l'export dépend de la taille de la boîte e-mail : quelques minutes pour une petite boîte, plusieurs heures pour une grosse. Il n'existe aucun moyen de l'accélérer.
- Une boîte e-mail ne porte qu'une seule demande d'export, et une nouvelle n'est acceptée que 24 heures après la précédente pour la même adresse e-mail.
- L'export ne s'applique qu'aux boîtes e-mail individuelles : les groupes, les comptes partagés et les comptes de ressource ne sont pas couverts.

:::
