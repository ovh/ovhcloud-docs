## Objectif 

Les logs correspondent aux événements survenus sur un système informatique (serveur, ordinateur, application, site web, base de données, réseau informatique, etc.). Par exemple, les logs peuvent enregistrer et contenir un ou plusieurs éléments parmi les suivants :

- L'horodatage (date, heure, minute, seconde) de l'événement.
- La nature de l'événement (connexion, déconnexion, erreur, download, upload, alerte, etc.).
- Des informations complémentaires sur l'événement (pages ou fichiers consultés, applications lancées, serveurs distants appelés, nom d'un fichier chargé ou téléchargé, etc.).
- L'origine de l'événement (identifiant de l'utilisateur, adresse IP source, programme source, etc.).
- L'état du système au moment de l'événement (ressources disponibles, mémoire restante, utilisation du CPU, etc.).

Généralement, les logs sont générés directement par les systèmes informatiques sur lesquels les événements se produisent. Ils sont stockés et historisés dans des fichiers texte également appelés fichiers de logs.

Les fichiers de logs permettent d'effectuer les actions suivantes :

- Analyser le comportement du système informatique générant les logs.
- Identifier les erreurs survenues sur le système informatique.
- Résoudre les erreurs rencontrées sur le système informatique.
- Optimiser le fonctionnement et les performances du système informatique.

Votre offre Private Exchange ou Trusted Exchange génère donc ses propres logs. Vous pouvez être amené à consulter/récupérer les logs pour analyser les accès à vos boîtes e-mail ou suivre les flux d'e-mails.

## En pratique

### Visualiser les logs de votre plateforme Exchange en temps réel

{/* CP-STEPS-START:visualiser-logs-temps-reel */}

Pour accéder aux logs en temps réel de votre service Private Exchange ou Trusted Exchange, cliquez sur son onglet <code className="action">Logs</code>. Un bandeau **Ces logs sont uniquement affichés en direct** rappelle qu'ils ne sont pas conservés, et une barre d'outils surmonte l'affichage des logs.

<img className="thumbnail" alt="Onglet Logs d'un service Private Exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-manage-logs/console/exchange-logs-tab.png" loading="lazy" />

:::warning
Comme il s'agit d'un affichage en temps réel, les logs n'apparaissent que lorsque vous vous trouvez sur l'onglet <code className="action">Logs</code>. Si vous quittez l'onglet <code className="action">Logs</code> puis revenez dessus, l'historique précédent aura disparu.

:::


Les services Private Exchange et Trusted Exchange proposent 2 types de logs, que vous sélectionnez dans la liste déroulante de la barre d'outils :

- **Access logs** : Permet de consulter l'activité des connexions sur votre service Exchange.
- **Message tracking** : Permet de consulter les logs détaillés du flux d'e-mails traversant votre service Exchange. Vous y retrouverez les informations suivantes :
    - le statut de remise d'e-mails sur vos comptes Exchange ;
    - le statut d'envoi d'e-mails depuis votre service Exchange ;
    - la taille des e-mails transmis ;
    - etc.

{/* CP-STEPS-END:visualiser-logs-temps-reel */}

### Intégrer les logs de votre solution Exchange sur Logs Data Platform

La solution Logs Data Platform peut vous être utile si vous disposez d'une infrastructure importante ou si vos services génèrent une grande quantité de logs. En effet, cette plateforme est conçue pour faciliter l'agrégation et la gestion des logs.

Elle fonctionne en récupérant les logs générés par votre infrastructure, vos sites web ou encore vos applications pour, par exemple :

- les stocker ;
- les afficher dans des tableaux de bord en temps réel ;
- permettre aux utilisateurs d'effectuer des requêtes complexes ;
- les filtrer par date, application, type ou contenu.

:::info
Pour plus de détails sur Logs Data Platform, consultez notre guide « [Introduction à Logs Data Platform](/guides/manage-and-operate/observability/logs-data-platform/introduction) ».

:::


Les solutions Exchange sont compatibles avec divers services tels que l'hébergement mutualisé, les VPS et les serveurs dédiés. Elles peuvent également être complétées par des flux de données sur Logs Data Platform, en complément des logs en temps réel déjà disponibles.

Pour abonner les logs de votre solution Exchange à un flux de données sur Logs Data Platform, effectuez les actions suivantes :

{/* CP-STEPS-START:integrer-logs-ldp */}

1. Cliquez sur l'onglet <code className="action">Logs</code> de votre service et sélectionnez le type de log dans la liste déroulante de la barre d'outils. L'abonnement ne concerne que le type de log sélectionné : pour transférer les 2 types, abonnez-vous une fois pour chacun.
1. Cliquez sur le bouton <code className="action">Configuration</code> de la barre d'outils. Le panneau **Liste des flux de données** s'ouvre.

<img className="thumbnail" alt="Bouton Configuration de la barre d'outils de l'onglet Logs" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-manage-logs/console/exchange-logs-configuration-button.png" loading="lazy" />

Dans ce panneau, sélectionnez le compte Logs Data Platform souhaité dans la liste **Service Observabilité**. Ses flux de données s'affichent ensuite sous la forme d'une liste.

<img className="thumbnail" alt="Panneau Liste des flux de données, liste Service Observabilité" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-manage-logs/console/exchange-logs-data-streams-panel.png" loading="lazy" />

Deux cas de figure se présentent alors pour abonner votre solution Exchange :

<Tabs>
  <Tab label="Cas n°1">
    **S'abonner à un flux déjà existant sur votre solution Logs Data Platform**
    
    Si le flux concerné existe déjà, il apparaît dans la liste. Pour abonner votre solution Exchange à ce flux existant, cliquez sur le bouton <code className="action">S'abonner</code> du flux concerné.
    
    Après quelques instants, si vous restez sur la page, le message « Votre abonnement a réussi. » s'affiche.
  </Tab>
  <Tab label="Cas n°2">
    **S'abonner à un nouveau flux de données sur votre solution Logs Data Platform**
    
    Si votre compte Logs Data Platform ne comporte encore aucun flux de données, cliquez sur <code className="action">Créer un flux de données</code> dans le panneau. Le formulaire de création d'un flux de données de Logs Data Platform s'ouvre dans un nouvel onglet de la console OVHcloud.
    
    Consultez nos guides « [Introduction à Logs Data Platform](/guides/manage-and-operate/observability/logs-data-platform/introduction) » et « [Démarrage rapide avec Logs Data Platform](/guides/manage-and-operate/observability/logs-data-platform/getting-started-quick-start) » pour réaliser cette action.
    
    Une fois le formulaire complété, cliquez sur le bouton <code className="action">Créer</code>.
    
    Vous êtes ensuite redirigé vers l'onglet <code className="action">Flux de données</code> de votre solution Logs Data Platform.
    
    Revenez ensuite sur l'onglet <code className="action">Logs</code> de votre service Exchange : vous pouvez à présent l'abonner à votre nouveau flux en suivant les instructions en début de chapitre.
  </Tab>
</Tabs>

{/* CP-STEPS-END:integrer-logs-ldp */}
