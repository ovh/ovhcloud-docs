## Objectif

Grâce aux groupes Exchange, de nombreux participants peuvent communiquer par envoi d’e-mails à une seule adresse, celle du groupe. Cette fonction collaborative vous permet de créer et gérer des listes de diffusion constituées aussi bien d’utilisateurs d’Exchange que de contacts externes.

**Ce guide va vous expliquer comment utiliser les groupes Exchange via l’espace client OVHcloud et le service Outlook Web App (OWA).**

## Prérequis

- Avoir souscrit une [solution Exchange OVHcloud](https://www.ovhcloud.com/fr/emails/hosted-exchange/)

## En pratique

### Créer un nouveau groupe

{/* CP-STEPS-START:creer-nouveau-groupe */}

Cliquez sur l'onglet <code className="action">Gestion des comptes</code>, puis sur le sous-onglet <code className="action">Groupes</code>.

<img className="thumbnail" alt="Sous-onglet Groupes d'un service Exchange, bouton Créer un groupe de contact au-dessus du tableau" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/console/exchange-groups-create01.png" loading="lazy" />

Cliquez sur le bouton <code className="action">Créer un groupe de contact</code>, au-dessus du tableau, afin d'ouvrir le panneau **Créer un groupe de contact**, à partir duquel vous pourrez définir les paramètres du groupe :

<img className="thumbnail" alt="Panneau Créer un groupe de contact ouvert à droite du sous-onglet Groupes" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/console/exchange-groups-create02.png" loading="lazy" />

- **Adresse e-mail du groupe** : Définissez une nouvelle adresse pour envoyer des messages à la liste de diffusion. Saisissez son nom, puis sélectionnez le domaine dans le menu déroulant qui suit le `@`. Veillez à ne pas utiliser une adresse déjà fonctionnelle.
- **Nom à afficher** : Indiquez le nom du groupe qui apparaîtra dans la <ManagerLink to="/">console OVHcloud</ManagerLink> et dans votre [messagerie Web OVHcloud](https://www.ovhcloud.com/fr/mail/) (OWA).
- **Société** : Ce champ est facultatif.
- **Taille maximale de réception (en Mo)** et **Taille maximale d'envoi (en Mo)** : Vous pouvez spécifier la taille maximale des e-mails entrants et des e-mails sortants. La case **Valeur maximum (100)** située sous chaque champ applique la taille maximale autorisée, soit 100 Mo.
- **Gestion des abonnements** et **Gestion des désabonnements** : Ces deux réglages obligatoires indiquent si les utilisateurs peuvent rejoindre ou quitter le groupe d'eux-mêmes (**Ouverte**, le réglage par défaut) ou non (**Fermée**).
- **Cacher l'adresse dans l'annuaire** : Lorsque cette case est cochée, l'adresse du groupe ne s'affichera pas dans la liste des adresses du service Exchange.
- **Authentification de l'expéditeur requise** : Lorsque cette case est cochée, seuls les utilisateurs de la même plate-forme pourront envoyer des messages avec l'adresse du groupe.

Cliquez sur le bouton <code className="action">Créer</code>, en bas du panneau, pour finaliser la création du groupe.

Les contacts et les administrateurs du groupe ne se choisissent pas lors de sa création. Une fois le groupe créé, vous les désignez à l'aide du bouton <code className="action">⋮</code> situé à droite du groupe dans le tableau, puis de l'option <code className="action">Configurer les utilisateurs</code>, comme décrit plus bas dans ce guide. Ces choix se feront uniquement parmi les adresses e-mail et les contacts externes déjà répertoriés dans le service.

- **Administrateur** : Compte e-mail autorisé à envoyer un e-mail à l'ensemble des contacts du groupe.
- **Contact** : Compte e-mail qui recevra les e-mails envoyés au groupe par les administrateurs.

:::info
Veuillez noter que les administrateurs doivent être configurés en tant que **Contact** afin de recevoir les e-mails du groupe.

:::

{/* CP-STEPS-END:creer-nouveau-groupe */}

### Gérer les groupes

{/* CP-STEPS-START:gerer-groupes */}

Après la création de votre groupe, vous pouvez modifier les paramètres que vous avez définis. Pour cela, cliquez sur le bouton <code className="action">⋮</code> à droite du groupe dans le tableau, puis sur <code className="action">Configurer le groupe</code>. Le panneau **Configurer le groupe** reprend les paramètres définis lors de la création. Une fois vos modifications faites, cliquez sur <code className="action">Configurer</code>.

<img className="thumbnail" alt="Menu ⋮ d'un groupe du sous-onglet Groupes, première entrée Configurer le groupe" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/console/exchange-groups-options01.png" loading="lazy" />

{/* CP-STEPS-END:gerer-groupes */}

#### Gérer les utilisateurs d'un groupe

{/* CP-STEPS-START:gerer-utilisateurs-groupe */}

Pour ajouter des contacts à votre groupe ou définir ses administrateurs, cliquez sur le bouton <code className="action">⋮</code> à droite du groupe dans le tableau, puis sur <code className="action">Configurer les utilisateurs</code>.

La page **Utilisateurs du groupe** qui s'affiche liste les comptes d'un seul domaine à la fois : si votre service compte plusieurs domaines, sélectionnez celui des comptes concernés dans le menu déroulant **Filtrer par domaine**. En face de chaque adresse de la colonne **Adresse e-mail**, cochez la case de la colonne **Administrateur**, celle de la colonne **Contact**, ou les deux, selon le rôle que vous souhaitez attribuer au compte. Les contacts externes ne peuvent pas être administrateurs du groupe.

Une fois vos choix faits, cliquez sur le bouton <code className="action">Enregistrer</code>.

:::info
Un groupe peut contenir un nombre maximum de 10 000 contacts.

:::


<img className="thumbnail" alt="Page Utilisateurs du groupe, avec les colonnes Administrateur et Contact à cocher" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/console/exchange-group-options-users01.png" loading="lazy" />

{/* CP-STEPS-END:gerer-utilisateurs-groupe */}

#### Gérer les délégations d'un groupe

{/* CP-STEPS-START:gerer-delegations-groupe */}

Pour déléguer l'accès au groupe, cliquez sur le bouton <code className="action">⋮</code> à droite du groupe dans le tableau, puis sur <code className="action">Configurer les délégations</code>. La page **Délégation du groupe** qui s'affiche vous permet de déléguer l'accès comme pour un compte Exchange. Retrouvez tous les détails dans [ce guide](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/permissions-delegation).

<img className="thumbnail" alt="Page Délégation du groupe, avec les cases Droit d'envoi et Droit d'envoyer de la part" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/console/exchange-groups-options-delegation01.png" loading="lazy" />

:::info
Veuillez noter que chaque modification à ce service peut prendre quelques minutes pour être appliquée. Vous pouvez vérifier l'état de la plupart des opérations en cliquant sur l'onglet <code className="action">Opérations</code> de votre service.

:::

{/* CP-STEPS-END:gerer-delegations-groupe */}


### Écrivez à un groupe via OWA

Vous pouvez déjà tester votre liste de diffusion via [la messagerie Web d’OVHcloud](https://www.ovhcloud.com/fr/mail/) (OWA). Il suffit d’envoyer un e-mail à l’adresse du groupe.
