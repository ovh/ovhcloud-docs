## Objectif

Lorsque vous ajoutez un nom de domaine sur votre plateforme e-mail, la configuration d'un enregistrement CNAME dans la zone DNS peut vous être demandée. Celle-ci a pour but de s'assurer que le nom de domaine concerné est bien légitime pour être utilisé sur la plateforme e-mail.

:::info
Si le nom de domaine ajouté est géré dans le même compte client que la plateforme e-mail, plus particulièrement sa zone DNS, il n'y a pas d'enregistrement CNAME à configurer.

:::


**Découvrez comment valider votre nom de domaine sur votre plateforme e-mail en ajoutant un enregistrement CNAME.**

## En pratique

### Pourquoi créer un enregistrement CNAME ?

L'enregistrement CNAME est utilisé ici en tant qu'alias, il pointe vers une cible qui elle-même renvoie vers une adresse IP. Il ne s'agit donc pas par nature d'un enregistrement lié à un service e-mail.

<Region zones={['eu']}>

Dans le cadre de nos offres [**Hosted Exchange**](https://www.ovhcloud.com/fr/emails/hosted-exchange/) et [**Email Pro**](https://www.ovhcloud.com/fr/emails/email-pro/), cet enregistrement CNAME est utilisé comme code de validation (token) qui sera visible dans la zone DNS du nom de domaine à valider. Le but est de vérifier que l'utilisateur de la plateforme e-mail est bien le gestionnaire du nom de domaine qu'il ajoute.

</Region>

Le but est de vérifier que l'utilisateur de la plateforme e-mail est bien le gestionnaire du nom de domaine qu'il ajoute.

Pour former les adresses e-mail vous ajoutez des comptes (ici représentés par « **contact** », « **john.smith** » et « **mary.johnson** »).<br/>
Le nom de domaine **mydomain.ovh** a été ajouté à la plateforme e-mail (référez-vous au guide « [Ajouter un nom de domaine sur une plateforme e-mail](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-adding-domain) »).<br/>
Un code de validation est généré par la plateforme (sous la forme « **abcd1-check** » dans notre exemple).<br/>
Si la zone DNS du nom de domaine **mydomain.ovh** n'est pas gérée dans le même compte client OVHcloud ou est gérée depuis une interface de gestion externe, ce code doit alors être ajouté sous la forme d'un enregistrement CNAME. Cet enregistrement est représenté par le cadre bleu dans l'exemple.<br/>
La plateforme e-mail est en mesure d'observer les enregistrements DNS du nom de domaine **mydomain.ovh** pour vérifier la présence du code de validation.

<img className="thumbnail" alt="email" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-dns-cname/email-dns-conf-cname01.png" loading="lazy" />

Une fois que la plateforme e-mail a pu lire le code de validation dans la zone DNS du nom de domaine **mydomain.ovh**, il devient possible de former les adresses **contact@mydomain.ovh**, **john.smith@mydomain.ovh** et **mary.johnson@mydomain.ovh**.

### Étape 1 - Comprendre le diagnostic CNAME d'OVHcloud <a name="step1"></a>

{/* CP-STEPS-START:comprendre-diagnostic-cname */}

La pastille de diagnostic **CNAME** apparaît dans l'onglet <code className="action">Domaines associés</code> de votre plateforme e-mail après l'ajout de votre nom de domaine.

<img className="thumbnail" alt="Onglet Domaines associés, pastille CNAME orange dans la colonne Diagnostic d'un domaine à valider" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-dns-cname/console/cname_exchange_diagnostic.png" loading="lazy" />

Dans l'exemple ci-dessus, la pastille est orange. Voici les raisons possibles de ce diagnostic :

- **le nom de domaine déclaré n'est pas géré dans le même compte client OVHcloud que votre plateforme e-mail** : réalisez [l'étape 3](#step3) de ce guide en vous connectant à la console OVHcloud avec le compte OVHcloud qui gère la zone DNS du nom de domaine.
- **le nom de domaine déclaré utilise des serveurs DNS externes à OVHcloud** : le nom de domaine est enregistré chez OVHcloud mais vous utilisez des serveurs DNS « personnalisés ». Pour le vérifier, depuis la section <code className="action">Domaines & DNS</code> du menu de gauche, sélectionnez le nom de domaine concerné. Dans l'onglet <code className="action">Vue d'ensemble</code>, ouvert par défaut, vérifiez la ligne **Configuration** de la section **Configuration DNS**. Si elle indique « Personnalisés », vous devrez vous connecter à l'interface de gestion des serveurs DNS indiqués sous **Serveurs DNS hébergeant la zone**, dans cette même section.

<img className="thumbnail" alt="Section Configuration DNS de l'onglet Vue d'ensemble d'un nom de domaine" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-dns-cname/console/email-dns-conf-cname02.png" loading="lazy" />

{/* CP-STEPS-END:comprendre-diagnostic-cname */}

- **le nom de domaine déclaré n'est pas enregistré chez OVHcloud et n'utilise pas des serveurs DNS OVHcloud** : le nom de domaine est enregistré dans un autre bureau d'enregistrement. Il vous faut vérifier depuis l'interface du bureau d'enregistrement du nom de domaine et vérifier les serveurs DNS utilisés pour identifier où vous devez configurer la zone DNS.

### Étape 2 - Récupérer le code de validation <a name="step2"></a>

{/* CP-STEPS-START:recuperer-code-validation */}

Positionnez-vous sur l'onglet <code className="action">Domaines associés</code> et survolez la pastille orange **CNAME**, dans la colonne **Diagnostic**, pour afficher les informations nécessaires.

L'enregistrement CNAME à créer est décrit dans l'encadré **Vérification propriétaire** qui s'affiche à côté de la pastille.

<img className="thumbnail" alt="Encadré Vérification propriétaire de la pastille CNAME, avec l'enregistrement à créer et sa cible" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-dns-cname/console/cname_exchange_informations.png" loading="lazy" />

Relevez alors le code unique affiché sous **Enregistrement CNAME à créer** (`a1bcd-check`, suivi de votre nom de domaine, dans l'exemple ci-dessus). La valeur affichée sous **Cible**, `ovh.com`, est la cible de cet enregistrement.

:::warning
Vous disposez de 48 heures pour créer cet enregistrement CNAME.

:::

{/* CP-STEPS-END:recuperer-code-validation */}

### Étape 3 - Créer l'enregistrement CNAME <a name="step3"></a>

Sélectionnez l'onglet correspondant à votre situation :

{/* CP-STEPS-START:creer-enregistrement-cname */}

<Tabs>
  <Tab label="Depuis la console OVHcloud">
    Cliquez sur <code className="action">Domaines & DNS</code> puis sur le nom de domaine concerné. Sélectionnez ensuite l'onglet <code className="action">Zone DNS</code>.

La configuration de votre zone DNS apparaît. Pour ajouter un enregistrement CNAME, cliquez sur le bouton <code className="action">Ajouter une entrée</code>.

Dans le formulaire qui s'affiche, sélectionnez **CNAME** dans le menu déroulant **Type**, puis complétez les champs en fonction des informations récupérées lors de [l'étape 2](#step2) de ce guide.

Par exemple, si le code de validation est « **a1bcd-check** », celui-ci doit être saisi dans le champ **Sous-domaine**. Enfin, renseignez « **ovh.com.** » dans le champ **Cible (nom d'hôte)** en n'oubliant pas le « **.** » final.

Une fois ces informations complétées, assurez-vous qu'elles sont correctes puis cliquez sur <code className="action">Ajouter</code>.
    
    :::warning
    La modification nécessite un temps de propagation généralement appliqué en quelques minutes. Il peut néanmoins aller jusqu'à 24 heures maximum.

    :::

  </Tab>
  <Tab label="Depuis une interface externe à OVHcloud">
    Connectez-vous à l'interface qui gère la zone DNS du nom de domaine et ajoutez un enregistrement de type CNAME à celle-ci, avec les paramètres suivants :
    
    - **sous-domaine** : saisissez la valeur sous la forme « **xxxxx-check** » en remplaçant les « **x** » par le code unique relevé à l'étape [l'étape 2](#step2) de ce guide.
    - **cible** : saisissez la valeur « **ovh.com.** » en n'oubliant pas le « **.** » final si votre interface de saisie ne le fait pas automatiquement.
    
    Validez cette modification dans votre zone DNS.
    
    :::warning
    Cette modification nécessite un temps de propagation, généralement appliqué en quelques minutes. Il peut néanmoins aller jusqu'à 24 heures maximum.

    :::

    
    Voici un exemple de réponse DNS après l'ajout d'un enregistrement CNAME de validation :
    
    ```bash
    ab1cd-check.mydomain.ovh. 3600	IN	CNAME	ovh.com.
    ```
  </Tab>
</Tabs>

Pour vérifier que la configuration de l'enregistrement CNAME a bien été lue par votre plateforme e-mail, retournez sur celle-ci et positionnez-vous dans l'onglet <code className="action">Domaines associés</code>. Si la pastille **CNAME** n'est plus présente dans la colonne **Diagnostic**, le nom de domaine est correctement ajouté. Dans le cas contraire, il se peut que la propagation ne soit pas encore terminée.

<img className="thumbnail" alt="Onglet Domaines associés, domaine validé sans pastille CNAME dans la colonne Diagnostic" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-dns-cname/console/cname_exchange_diagnostic_green.png" loading="lazy" />
