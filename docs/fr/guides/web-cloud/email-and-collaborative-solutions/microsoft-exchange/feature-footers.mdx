## Objectif

Dans la console OVHcloud, vous pouvez créer des signatures universelles (pieds de page) pour les adresses e-mail utilisant le même domaine (signature « d’entreprise »). Elles apparaîtront automatiquement dans les e-mails envoyés depuis le compte d'un utilisateur.

**Découvrez comment créer une signature automatique depuis la console OVHcloud.**

## En pratique

{/* CP-STEPS-START:en-pratique */}

Cliquez sur l'onglet <code className="action">Paramètres</code> de votre service, puis ouvrez la section **Pieds de page**.

<img className="thumbnail" alt="Onglet Paramètres d'un service Exchange, section Pieds de page ouverte avec son tableau" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-footers/console/exchange-footer-step1.png" loading="lazy" />

Le tableau liste vos domaines associés : chacun peut recevoir son propre modèle de pied de page. Cliquez sur le bouton <code className="action">⋮</code> à droite de la ligne du domaine concerné, puis sur <code className="action">Ajouter</code> pour ouvrir l'éditeur sur la page **Ajouter une signature**.

<img className="thumbnail" alt="Menu ⋮ d'un domaine de la section Pieds de page, avec l'action Ajouter" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-footers/console/exchange-footer-step2.png" loading="lazy" />

L'éditeur propose des variables qui correspondent aux données du compte de l'utilisateur. Vous pouvez, par exemple, rédiger un message de fin générique et ajouter une signature adaptée ou des informations de contact grâce aux variables. Sélectionnez une variable dans la liste **Insérer une variable**, puis cliquez sur le bouton <code className="action">Insérer une variable</code> pour l'ajouter dans le volet d'édition.

Le pied de page est rédigé en HTML, ce qui permet certaines options de mise en forme. Utilisez la barre d'outils au-dessus du volet d'édition pour personnaliser votre signature (gras, italique, souligné, listes, taille, couleur, alignement) et pour y ajouter un lien ou une image. Une image doit être hébergée à une adresse publique : renseignez cette adresse dans le champ **Adresse de l'image** du panneau **Insérer une image**, qui s'ouvre avec le bouton image de la barre d'outils, puis cliquez sur <code className="action">Insérer</code>.

{/* v8-gap: CG-030 (oversight) — v6 « Source »: showed the footer's HTML code in the editor so it could be checked */}

<img className="thumbnail" alt="Page Ajouter une signature, avec la liste des variables et la barre d'outils" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-footers/console/exchange-footer-step4.png" loading="lazy" />

Cochez la case **Activer la signature uniquement pour les envois vers l'extérieur** pour éviter d'ajouter ce pied de page aux e-mails envoyés entre utilisateurs d'un même domaine. Une fois votre signature terminée, cliquez sur <code className="action">Enregistrer</code>, en bas de la page. Elle apparaîtra ensuite dans les e-mails envoyés depuis les comptes de ce domaine.

Pour modifier ou supprimer une signature, cliquez dans la section **Pieds de page** sur le bouton <code className="action">⋮</code> à droite de la ligne du domaine, puis sur <code className="action">Modifier</code> ou <code className="action">Supprimer</code>.

{/* CP-STEPS-END:en-pratique */}

Veillez à prendre en considération les spécificités suivantes avant de créer des signatures pour les utilisateurs :

- En dehors des « Prénom », « Nom » et « Nom d'affichage », les informations du compte ne peuvent pas être éditées à partir de la console OVHcloud et doivent donc être spécifiées dans l'OWA de l'utilisateur (« Options », « Général », « Mon compte »).

<img className="thumbnail" alt="exchangesig" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-footers/exchange-footer-step5.png" loading="lazy" />

- La signature sera ajoutée au corps de l’e-mail sans espace, il est donc conseillé de commencer la signature par au moins une ligne vide.
- Dans OWA, il n'est pas indiqué si un pied de page est activé sur ce domaine et il n'y a **pas de synchronisation**. Si les utilisateurs ajoutent [leurs propres signatures](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/email-owa#ajouter-une-signature), les e-mails comprendront à la fois le pied de page individuel et celui de l'ensemble du domaine.
- L'éditeur prend en charge le formatage HTML, les hyperliens, les images, etc. Toutefois, les signatures ne devraient pas trop s'appuyer sur ces options. Les destinataires peuvent utiliser des clients de messagerie électronique qui empêchent le HTML et les images intégrées, les signatures apparaîtront alors d'une manière différente de celle prévue. Attention : les balises HTML seront complètement supprimées si un message est envoyé en « texte brut » depuis OWA.
- Les « initiales » ne sont pas actives sur ce service. Ajouter cette variable n’aura donc aucun effet.
