## Objectif

Vous venez d’acquérir une solution Email Pro. Celle-ci vous permet de bénéficier d'adresses e-mail professionnelles au prix le plus juste pour soutenir ou commencer votre activité.

**Découvrez comment réaliser la configuration de votre solution Email Pro.**

## Prérequis

- Disposer d’une offre [Email Pro](https://www.ovhcloud.com/fr/emails/email-pro/).
- Avoir reçu l’e-mail vous confirmant l’installation de votre solution Email Pro.
- Disposer d’un nom de domaine.

## En pratique

### Étape 1 : ajouter votre nom de domaine

{/* CP-STEPS-START:ajouter-nom-de-domaine */}

:::info
Le nom d'un service Email Pro dans la console OVHcloud débute par *emailpro-*, puis contient une partie de votre référence client et se termine par un chiffre (1 pour le premier service Email Pro installé, 2 pour le deuxième, etc.).

:::


Après la commande de votre service Email Pro, accédez à la page <ManagerLink to="/beta/#/web-cloud/email">Emails</ManagerLink> de la console OVHcloud. Dans le menu de gauche, dépliez <code className="action">Emails</code> et cliquez sur <code className="action">Exchange</code> : vos services Email Pro y figurent, avec la mention « Email Pro » dans la colonne **Type d’offre**. Cliquez sur le nom de votre service.

Tant qu'aucun domaine n'est associé à votre service, celui-ci s'ouvre directement sur la page **Ajouter un domaine**. Pour ajouter un domaine à un service qui en compte déjà, rendez-vous sur l'onglet <code className="action">Domaines associés</code> puis cliquez sur le bouton <code className="action">Ajouter un domaine</code>, au-dessus du tableau.

Deux choix sont possibles :

- **Sélectionner un domaine dans la liste** : choisissez ensuite votre domaine dans le menu déroulant **Nom de domaine**. Seuls s'affichent les noms de domaine dont vous avez la gestion dans la console OVHcloud. Si le nom de domaine est enregistré chez OVHcloud mais n'apparaît pas dans la liste, vous devrez l'ajouter avec l'option « Saisir un nom de domaine non géré par votre compte OVH ».
- **Saisir un nom de domaine non géré par votre compte OVH** : choisissez cette option si le nom de domaine concerné est enregistré chez OVHcloud mais configurable depuis un autre compte client OVHcloud, **ou** si votre nom de domaine est enregistré dans un autre bureau d'enregistrement. Vous devrez être en mesure de modifier la configuration du nom de domaine (sa zone DNS) afin que le service Email Pro puisse fonctionner correctement.

<img className="thumbnail" alt="Page Ajouter un domaine d'un service Email Pro, option Sélectionner un domaine dans la liste" src="/images/web-cloud/email-and-collaborative-solutions/email-pro/first-config/console/emailpro-01.png" loading="lazy" />

Une fois le nom de domaine indiqué, la section **Configuration** s'affiche juste en dessous.

<img className="thumbnail" alt="Section Configuration avec les options Configuration recommandée et Configuration personnalisée" src="/images/web-cloud/email-and-collaborative-solutions/email-pro/first-config/console/emailpro-02.png" loading="lazy" />

- **Si vous avez renseigné un nom de domaine non géré par OVHcloud** : le mode non-autoritatif sera configuré par défaut.

- **Si vous avez sélectionné dans la liste un nom de domaine géré par OVHcloud**, vous devrez choisir entre deux configurations, qui correspondent aux deux modes de fonctionnement du domaine.
    - **Configuration recommandée** (mode **autoritatif**) : convient si votre solution Email Pro est la seule solution de messagerie que vous utilisez avec votre nom de domaine. Tous les e-mails adressés à votre nom de domaine sont alors acheminés vers ce service dès l'enregistrement de la configuration. Elle ne permet pas l'usage d'une autre solution de messagerie avec votre service.
    - **Configuration personnalisée** (mode **non-autoritatif**) : convient si vous utilisez, avec votre nom de domaine, la solution Email Pro **ainsi qu'une autre solution de messagerie**.

Le mode appliqué à chaque domaine s'affiche ensuite dans la colonne **Mode** du tableau de l'onglet <code className="action">Domaines associés</code>.

> **Comprendre les modes Autoritatif et Non-autoritatif**
>
> - Lorsqu'un e-mail est transmis vers votre plateforme Email Pro (*Inbound mail server Email Pro*) en mode **autoritatif**, cela signifie que toutes les adresses e-mail de votre nom de domaine sont uniquement hébergées sur cette plateforme.<br/><br/>Par exemple, si on envoie un e-mail à l'adresse « *mary.johnson@mydomain.ovh* », le serveur Email Pro « *Inbound mail server Email Pro* » renvoie un message d'échec à l'expéditeur, car cette adresse n'existe pas sur le serveur Email Pro « *Inbound mail server Email Pro* ».
> - Lorsqu'un e-mail est transmis vers votre plateforme Email Pro (*Inbound mail server Email Pro*) en mode **non-autoritatif**, cela signifie que les adresses e-mail de votre nom de domaine sont réparties entre votre plateforme e-mail principale (*Inbound mail server Email Pro*) et un autre service e-mail (*Inbound mail server MX Plan*).<br/><br/>Par exemple, si on envoie un e-mail à l'adresse « *mary.johnson@mydomain.ovh* », le serveur Email Pro *Inbound mail server Email Pro* transmettra l'e-mail au serveur MX Plan « *Inbound mail server MX Plan* » pour que ce dernier puisse le délivrer.
>
> <img className="thumbnail" alt="Add Domain" src="/images/web-cloud/email-and-collaborative-solutions/email-pro/first-config/authoritative-mode.png" loading="lazy" />
>

:::warning
Si ce nom de domaine est déjà déclaré en mode **autoritatif** sur une autre plateforme e-mail, son ajout avec la **Configuration recommandée** est refusé. Pour que les deux plateformes cohabitent, le nom de domaine doit être en mode **non-autoritatif** sur chacune d'elles : choisissez ici la **Configuration personnalisée**, puis passez-le en mode **non-autoritatif** sur l'autre plateforme.

:::


Si vous choisissez la **Configuration personnalisée**, renseignez le champ **URL du serveur email cible** selon l'autre service e-mail que vous utilisez :

- **E-mail OVHcloud (Exchange ou MX Plan)** : conservez la valeur proposée par défaut, « *mx1.mail.ovh.net* » (fonctionne de la même façon avec *mx0.mail.ovh.net*, *mx2.mail.ovh.net*, *mx3.mail.ovh.net*, *mx4.mail.ovh.net*).
- **Email externe à OVHcloud (offre e-mail concurrente, serveur e-mail privé)** : saisissez dans le champ **URL du serveur email cible** le nom d'hôte du serveur entrant de ce service externe, en vous assurant que celui-ci autorise les requêtes e-mail provenant de votre service Email Pro.

Le choix du mode n'est pas définitif et peut être modifié par la suite depuis la console OVHcloud.

**Si vous avez sélectionné un nom de domaine géré par OVHcloud**, la configuration de ce dernier peut être réalisée automatiquement. Avec la **Configuration personnalisée**, quatre cases s'affichent sous le champ **URL du serveur email cible**. Elles sont cochées par défaut : décochez celles dont vous ne souhaitez pas la configuration automatique.

<img className="thumbnail" alt="Configuration personnalisée avec le champ URL du serveur email cible et les cases de configuration automatique des enregistrements DNS" src="/images/web-cloud/email-and-collaborative-solutions/email-pro/first-config/console/emailpro-03.png" loading="lazy" />

- **Configurer automatiquement l'enregistrement MX (réception)** : enregistrement DNS des serveurs e-mail nécessaire à la réception des e-mails sur le nom de domaine concerné.
- **Configurer automatiquement l'enregistrement SRV (autodiscover)** : enregistrement DNS permettant la configuration automatique de votre logiciel de messagerie lorsque vous y ajoutez votre adresse e-mail.
- **Configurer automatiquement l'enregistrement SPF** : enregistrement DNS indiquant les serveurs autorisés à envoyer des e-mails pour votre nom de domaine. Consultez notre guide « [Améliorer la sécurité des e-mails via un enregistrement SPF](/guides/web-cloud/domains/dns-zone-spf) » pour plus d'informations.
- **Configurer et activer l'enregistrement DKIM automatiquement** : mise en place d'une signature numérique chiffrée pour sécuriser les échanges e-mails. Consultez notre guide « [Améliorer la sécurité des e-mails via un enregistrement DKIM](/guides/web-cloud/domains/dns-zone-dkim) » pour plus d'informations.

**Pour un nom de domaine non géré par OVHcloud**, configurez manuellement sa zone DNS en suivant l'étape 2 de ce guide.

Une fois vos choix faits, cliquez sur le bouton <code className="action">Enregistrer la configuration</code> pour lancer l'ajout du domaine.

{/* CP-STEPS-END:ajouter-nom-de-domaine */}

### Étape 2 : configurer votre nom de domaine

{/* CP-STEPS-START:configurer-nom-de-domaine */}

Une fois le nom de domaine ajouté en tant que domaine associé, vérifiez son paramétrage grâce au tableau qui s'affiche.

La colonne **Diagnostic** vous permet de contrôler la configuration DNS du nom de domaine. Une pastille rouge apparaîtra si ces paramètres doivent être modifiés. Il y a deux possibilités :

- **Configuration automatique lors de l'ajout d'un nom de domaine OVHcloud** : si vous venez juste d'effectuer la modification, l'affichage dans la <ManagerLink to="/">console OVHcloud</ManagerLink> peut prendre quelques heures.

- **Configuration manuelle pour un nom de domaine non géré par OVHcloud** : cliquez sur le bouton <code className="action">⋮</code> à droite de la ligne du domaine, puis sur <code className="action">Diagnostics</code> afin de découvrir les modifications à réaliser. La page qui s'ouvre comporte un onglet par enregistrement (MX, SRV, SPF et DKIM), avec son statut et l'enregistrement attendu dans votre zone DNS.
    - *Pour un enregistrement CNAME*, aidez-vous de notre guide « [Créer un champ CNAME à l'ajout d'un domaine associé](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-dns-cname) ».
    - *Pour un enregistrement MX*, aidez-vous de notre guide « [Ajouter un champ MX à la configuration de son nom de domaine](/guides/web-cloud/domains/dns-zone-mx) ».
    - *Pour un enregistrement SRV*, complétez votre zone DNS à l'aide des informations de l'onglet <code className="action">SRV</code> de cette page. Vous pouvez vous aider du guide « [Éditer une zone DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit) » pour ajouter cet enregistrement.
    - *Pour un enregistrement SPF*, complétez votre zone DNS à l'aide des informations de l'onglet <code className="action">SPF</code>. Vous pouvez vous aider du guide « [Améliorer la sécurité des e-mails via un enregistrement SPF](/guides/web-cloud/domains/dns-zone-spf) » pour ajouter cet enregistrement.
    - *Pour un enregistrement DKIM*, complétez votre zone DNS à l'aide des informations de l'onglet <code className="action">DKIM</code>. Vous pouvez vous aider du guide « [Améliorer la sécurité des e-mails via un enregistrement DKIM](/guides/web-cloud/domains/dns-zone-dkim) » pour ajouter cet enregistrement.

<img className="thumbnail" alt="Onglet Domaines associés, menu ⋮ d'un domaine ouvert sur l'entrée Diagnostics" src="/images/web-cloud/email-and-collaborative-solutions/email-pro/first-config/console/emailpro-04.png" loading="lazy" />

{/* CP-STEPS-END:configurer-nom-de-domaine */}

### Étape 3 : configurer les comptes Email Pro

{/* CP-STEPS-START:configurer-comptes-email-pro */}

Pour configurer vos adresses e-mail, positionnez-vous sur l'onglet <code className="action">Comptes</code>. Le tableau affiche les comptes que vous avez commandés sous la forme « *@configureme.me* ».

Pour les configurer, cliquez sur le bouton <code className="action">⋮</code> à droite de la ligne du compte concerné, puis sur <code className="action">Modifier</code>.

<img className="thumbnail" alt="Onglet Comptes, menu ⋮ d'un compte e-mail ouvert sur l'entrée Modifier" src="/images/web-cloud/email-and-collaborative-solutions/email-pro/first-config/console/emailpro-05.png" loading="lazy" />

Complétez les informations du panneau **Modifier un compte E-mail Pro** qui s'affiche.

- **Compte email** : renseignez le nom que portera votre adresse e-mail (votre prénom.nom, par exemple) et sélectionnez le domaine concerné dans la liste.

:::warning
Le choix du nom de votre adresse e-mail doit respecter les conditions suivantes :

- Minimum 2 caractères
- Maximum 32 caractères
- Aucun caractère accentué
- Pas de caractères spéciaux, à l'exception des caractères suivants : `.`, `,`, `-` et `_`

:::


- **Prénom** : renseignez un prénom.
- **Nom** : renseignez un nom.
- **Nom à afficher** : renseignez le nom qui s'affichera en tant qu'expéditeur lorsque des e-mails seront envoyés depuis cette adresse.
- **Mot de passe** et **Confirmation** : définissez un mot de passe fort composé au minimum de 10 caractères, dont un chiffre, une lettre majuscule et un caractère spécial (par exemple `$`, `!` ou `&`). Pour des raisons de sécurité, n'utilisez pas deux fois le même mot de passe. Choisissez-en un qui n'a aucun rapport avec vos informations personnelles (évitez par exemple de mentionner vos nom, prénom et date de naissance). Changez-le régulièrement.

:::warning
Le choix du mot de passe doit respecter les conditions suivantes :

- Minimum 10 caractères
- Maximum 30 caractères
- Aucun caractère accentué

:::


Une fois les informations complétées, cliquez sur le bouton <code className="action">Modifier</code> du panneau pour lancer la configuration du compte.

:::info
Réalisez cette étape autant de fois que nécessaire, selon le nombre de comptes à votre disposition. Vous pouvez commander des comptes additionnels grâce au bouton <code className="action">Commander des comptes</code>.

:::

{/* CP-STEPS-END:configurer-comptes-email-pro */}


### Étape 4 : utiliser vos adresses e-mail

Une fois vos comptes configurés, il ne vous reste plus qu'à les utiliser ! Pour cela, OVHcloud met à disposition un applicatif en ligne (une *webapp*). Ce dernier est accessible à l’adresse [Webmail](https://www.ovhcloud.com/fr/mail/) et vous devrez y renseigner les identifiants relatifs à votre adresse e-mail.

Si c'est la première fois que vous vous connectez à OWA avec cette adresse e-mail, vous serez invité à définir la langue de l'interface ainsi que le fuseau horaire. Ensuite, cliquez sur <code className="action">Enregistrer</code> pour continuer.

:::info
Les fuseaux horaires sont listés selon [la norme UTC (temps universel coordonné)](https://en.wikipedia.org/wiki/Coordinated_Universal_Time#/media/File:World_Time_Zones_Map.png), et non par ordre alphabétique des villes.

**Exemple** : Pour l'Europe de l'Ouest, il s'agit de UTC +1 (Bruxelles, Copenhague, Madrid, Paris).

:::


Pour configurer votre adresse e-mail sur un logiciel de messagerie ou un appareil, comme un _smartphone_ ou une tablette, [aidez-vous de nos guides de configuration](/guides/web-cloud/email-and-collaborative-solutions/email-pro/landing-page-email-pro). Si vous désirez simplement obtenir les éléments nécessaires pour configurer votre compte Email Pro, retrouvez ci-dessous les paramètres à utiliser :

|Type de serveur|Nom du serveur|Type de sécurité|Port|
|---|---|---|---|
|Entrant|pro?.mail.ovh.net|SSL/TLS|993|
|Sortant|pro?.mail.ovh.net|STARTTLS|587|

{/* CP-STEPS-START:utiliser-adresses-email */}

:::info
Dans notre exemple, nous utilisons la mention serveur : pro?.mail.ovh.net. Remplacez le « ? » par le numéro du serveur de votre service Email Pro.

Dans l'onglet <code className="action">Vue d'ensemble</code>, ouvert par défaut, le nom du serveur s'affiche à la ligne **Serveur** de la section **Informations générales**.

:::

{/* CP-STEPS-END:utiliser-adresses-email */}
