## Objectif 

Office 365 Revendeurs (CSP2) est un service vous permettant de bénéficier de plusieurs types de licences Microsoft 365 aux tarifs préférentiels afin que vous puissiez les revendre auprès de vos clients.

**Découvrez comment souscrire et administrer un service Office 365 Revendeurs (CSP2) depuis votre espace client OVHcloud.**

## Prérequis

- Disposer d’un <ManagerLink to="/">compte client OVHcloud</ManagerLink>.
- Disposer d’un [MPN ID](https://learn.microsoft.com/partner-center/mpn-create-a-partner-center-account) (Microsoft Partner Network IDentifiant).
- Être inscrit au programme CSP (Cloud Solution Provider) de Microsoft en tant que revendeur indirect dans la région où vous exercez (par exemple : « UE » pour l’Europe)

:::warning
Depuis le 01/07/2022, tous les services Office 365 revendeurs (CSP2) qui ne disposent pas d’un MPN ID inscrit au programme « CSP revendeur indirect » sont désactivés par Microsoft.

Disposer d'un MPN ID est désormais obligatoire pour toute nouvelle souscription.

:::


Si vous ne disposez pas encore d’un MPN ID, vous pouvez vous en créer un (si vous êtes éligible aux conditions de Microsoft) en suivant la documentation officielle de Microsoft [« Qu’est-ce que le Microsoft Cloud Partner Program ? »](https://docs.microsoft.com/partner-center/mpn-create-a-partner-center-account).

Pour vous inscrire ensuite en tant que revendeur indirect, nous vous invitons à consulter la documentation Microsoft [« S’inscrire au programme Fournisseur de solutions Cloud »](https://docs.microsoft.com/partner-center/enrolling-in-the-csp-program#enroll-as-an-indirect-reseller).

Le MPN ID vous permettra d'obtenir un cashback sur les abonnements que vous commanderez via l'espace client OVHcloud. Ce cashback est soumis à des règles définies par Microsoft, en fonction des volumes d'abonnements que vous générerez.

## En pratique

### Commander un service Office 365 Revendeurs

{/* CP-STEPS-START:commander-service-office-365-revendeurs */}

Depuis la section Microsoft 365 de la console OVHcloud, cliquez sur <code className="action">Commander</code>, puis, sur la page **Commander un service Microsoft 365**, sur <code className="action">Commander</code> dans la section **Microsoft 365 Revendeur**. La commande se déroule en trois étapes :

- Dans la section **Information revendeur**, saisissez votre MPN ID préalablement créé auprès de Microsoft dans le champ **Id partenaire Microsoft**, puis cliquez sur <code className="action">Suivant</code>.

    <img className="thumbnail" alt="Page de commande Microsoft 365 Revendeur, champ Id partenaire Microsoft" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-office/office-csp2/console/csp2-01.png" loading="lazy" />

- Dans la section **Configuration plateforme et informations client final**, choisissez **Nouvelle plateforme**, ou **Délégation d'une plateforme créée au préalable chez Microsoft** pour une plateforme qui existe déjà chez Microsoft. Pour une nouvelle plateforme, complétez les informations de contact du client final (pays, code postal, prénom, nom et adresse e-mail) : celles-ci sont demandées pour définir le gestionnaire du groupe de licences (*Tenant*) que vous allez créer.
    - *Facultatif* : vous pouvez définir un **sous-domaine personnalisé** lors de la création d'une nouvelle plateforme en activant l'option **Je souhaite un sous-domaine personnalisé** (sous réserve des noms disponibles). Sinon, un sous-domaine générique est créé sous la forme `bizofficeXXX.onmicrosoft.com`.

    Cliquez ensuite sur <code className="action">Suivant</code>.
- Dans **Sélectionnez vos licences**, cochez les licences que vous souhaitez intégrer à votre groupe et indiquez leur nombre, puis cliquez sur <code className="action">Continuer ma commande</code> pour finaliser votre commande dans un nouvel onglet.

:::warning
Veuillez vous assurer de la validité de l'adresse e-mail renseignée lors de la création de votre groupe de licences, car celle-ci servira à recevoir les informations d'identification pour la plateforme Microsoft.

:::

:::info
Une fois la commande réalisée, rendez-vous sur le portail administrateur Microsoft 365 pour valider le contrat avec Microsoft. Vos licences vous sont livrées une fois cette validation effectuée.

:::

{/* CP-STEPS-END:commander-service-office-365-revendeurs */}

:::warning
S'agissant de produits sous licences, il n'est pas possible de basculer un *Tenant* Office 365 revendeurs d'un idenfiant client OVHcloud à un autre. Il est nécessaire d'arrêter l'abonnement sur le compte OVHcloud d'origine et souscrire ce même type de licence sur le nouveau compte OVHcloud.

:::


### Gérer votre service Office 365 Revendeur

{/* CP-STEPS-START:gerer-service-office-365-revendeur */}

Une fois le service Office 365 créé et disponible, vous pouvez le gérer depuis la console OVHcloud. Dans la section Microsoft 365, sélectionnez le service concerné : son type est **Revendeur**.

L'onglet **Vue d'ensemble**, affiché à l'ouverture du service, présente les informations suivantes :

- **Nom d'affichage du service** : il s'affiche en titre de la page. Pour le personnaliser, cliquez sur l'icône en forme de crayon à droite du titre, saisissez le nouveau nom, puis validez.
- **Référence du service** (section **Informations générales**) : nom interne de votre service. Il n'est visible que depuis la console OVHcloud. Il correspond aussi au *Tenant* chez Microsoft.
- **MPN ID** (section **Informations générales**) : votre identifiant partenaire Microsoft. Pour le modifier, cliquez sur l'icône en forme de crayon à sa droite.
- **Date de création** (section **Mon offre**) : date de création du service.

L'onglet <code className="action">Licences</code> présente également :

- **Portail d'administration Microsoft** : lien du portail Office qui permet d'administrer vos abonnements.
- La gestion du mot de passe administrateur de votre *Tenant* Microsoft se fait directement depuis l'interface d'administration Microsoft. N'hésitez pas à consulter [la documentation de Microsoft](https://support.microsoft.com/account-billing/reset-a-forgotten-microsoft-account-password-eff4f067-5042-c1a3-fe72-b04d60556c37).
- La gestion de domaines additionnels se fait également depuis l'interface d'administration de Microsoft. Consultez [la documentation de Microsoft](https://support.microsoft.com/office/connect-your-domain-to-office-365-cd74b4fa-6d34-4669-9937-ed178ac84515).

L'onglet <code className="action">Tâches</code> liste les tâches réalisées sur votre service, avec leur statut.

:::info
Si vous n'avez pas encore accepté le Microsoft Customer Agreement (MCA), acceptez-le depuis le portail administrateur Microsoft 365, puis cliquez sur <code className="action">J'ai approuvé le MCA</code> dans l'onglet **Vue d'ensemble**.

:::

{/* CP-STEPS-END:gerer-service-office-365-revendeur */}

### Gérer vos abonnements

{/* CP-STEPS-START:gerer-abonnements */}

La gestion de vos abonnements vous permet d'augmenter ou d'annuler les licences associées à votre groupe d'abonnements. Dans l'onglet <code className="action">Licences</code> de votre service, un tableau vous permet de visualiser les détails :

- **ID** : chaque type de licence commandée dispose d'un identifiant (ID) unique.
- **Statut** : correspond à l'état de votre licence.
- **Nom de la licence** : indique le type de licence souscrite.
- **Nombre de licences** : indique le nombre de licences disponibles.
- **Date de création** : indique la date de création de l'abonnement au type de licence sélectionné.
- **Dernière mise à jour** : indique la date de dernière mise à jour (comme l'ajout d'une licence par exemple) de l'abonnement.

Pour modifier le nombre total de licences d'un abonnement, cliquez sur le bouton <code className="action">⋮</code> à droite de l'abonnement, puis sur <code className="action">Modifier la quantité</code>. Dans la fenêtre **Éditer l'abonnement**, indiquez le **Nouveau nombre de licences**, puis cliquez sur <code className="action">Enregistrer</code>. Les licences supplémentaires vous sont facturées dès l'enregistrement.

Pour résilier l'abonnement ainsi que toutes ses licences, cliquez sur le bouton <code className="action">⋮</code> à droite de l'abonnement, puis sur <code className="action">Supprimer l'abonnement</code>, et confirmez la suppression.

Pour souscrire un type de licence que vous n'avez pas encore, cliquez sur <code className="action">Nouvel abonnement</code>, au-dessus du tableau.

:::info
Des conditions particulières d'utilisation fournies par Microsoft sont à respecter pour les licences Éducation. Vous pouvez retrouver ces documents officiels en fonction de votre langue et région [ici](https://www.microsoft.com/licensing/docs).

:::

{/* CP-STEPS-END:gerer-abonnements */}

### Gérer les utilisateurs

Maintenant que vous disposez d'un nombre de licences suffisant, vous devez gérer les utilisateurs qui utiliseront ces dernières. Cette partie s'effectue directement depuis le [portail d'administration Microsoft](https://portal.office.com/Admin/Default.aspx).

Pour vous y connecter, vous devez renseigner votre identifiant ainsi que le mot de passe envoyé dans l'e-mail OVHcloud vous confirmant l'installation de votre groupe de licences. Ces informations sont envoyées à l'adresse renseignée lors de la création du groupe de licences.
