## Objectif

**Managed Hosting for WordPress** est la solution OVHcloud d’hébergement WordPress géré : la maintenance technique (mises à jour, sécurité, sauvegardes) est prise en charge automatiquement. L’offre permet de gérer les noms de domaine depuis l’interface OVHcloud, sans intervention manuelle. Vous pouvez associer un nom de domaine ou un sous-domaine à chacun de vos sites WordPress, quelle que soit son origine.

2 parcours sont disponibles selon votre situation :

- **Nom de domaine interne** : le nom de domaine est déjà présent dans votre compte OVHcloud.
- **Nom de domaine externe** : le nom de domaine est géré chez un autre bureau d’enregistrement.

**Découvrez comment ajouter, modifier ou supprimer les noms de domaine de votre Managed Hosting WordPress depuis votre espace client OVHcloud.**

## Prérequis

- Disposer d’une offre **Managed Hosting for WordPress** active avec au moins un site WordPress créé.
- Pour un nom de domaine externe : avoir accès à la zone DNS (Domain Name System) active chez votre prestataire actuel.

## En pratique

### 1 - Accéder à la gestion des noms de domaine

{/* CP-STEPS-START:acceder-gestion-domaines */}

L’ajout d’un nom de domaine s’effectue depuis l’onglet <code className="action">Mes sites</code> de votre ressource Managed Hosting for WordPress. Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page <ManagerLink to="/beta/#/web-cloud/wordpress">Managed WordPress</ManagerLink> de la console OVHcloud. Vos ressources y sont affichées sous forme d’encadrés.

    <img className="thumbnail" alt="Page Managed WordPress de la console OVHcloud listant les ressources sous forme d’encadrés" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/managed-hosting-for-wordpress.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans l’encadré de la ressource concernée, cliquez sur le bouton <code className="action">⋮</code> situé à droite de la mention **Actions supplémentaires**, puis sur <code className="action">Gérer</code>. Si la ressource est au statut **À renouveler** ou **Résilié**, cliquez directement sur le lien <code className="action">Gérer</code> affiché en bas de son encadré.

    <img className="thumbnail" alt="Encadré d’une ressource Managed WordPress avec le menu du bouton ⋮ ouvert sur l’entrée Gérer" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/manage-ressource-button.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Cliquez sur l’onglet <code className="action">Mes sites</code>. Le tableau liste vos sites WordPress : la colonne **Nom du site** affiche le nom de domaine principal de chaque site (ou son URL technique si aucun nom de domaine ne lui est associé), la colonne **Domaines associés** indique le nombre de noms de domaine associés au site et la colonne **Actions** donne accès aux actions disponibles.

    <img className="thumbnail" alt="Onglet Mes sites affichant le tableau des sites WordPress" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/managed-hosting-for-wordpress-my-sites-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Dans la colonne **Actions**, cliquez sur le bouton <code className="action">⋮</code> à droite du site WordPress concerné, puis sur <code className="action">Ajouter un nom de domaine</code>. Un panneau intitulé **Ajouter un nom de domaine** s’ouvre sur la droite.

    <img className="thumbnail" alt="Menu du bouton ⋮ d’un site WordPress dans l’onglet Mes sites, avec l’entrée Ajouter un nom de domaine" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/adding-domain.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
Le **premier nom de domaine ajouté** à un site WordPress devient automatiquement le **nom de domaine principal**. Vous pourrez en ajouter d’autres par la suite (multi-domaine) et changer le nom de domaine principal depuis l’entrée <code className="action">Gérer mes domaines</code> de ce même menu.
:::

{/* CP-STEPS-END:acceder-gestion-domaines */}

### 2 - Ajouter un nom de domaine

**Cliquez sur l’une des situations ci-dessous pour afficher le contenu.**

<details>

<summary>Ajouter un nom de domaine interne</summary>

Un nom de domaine **interne** est un nom de domaine déjà présent dans votre compte OVHcloud (enregistré ou transféré).

{/* CP-STEPS-START:ajouter-domaine-interne */}

Une fois le panneau **Ajouter un nom de domaine** ouvert, choisissez l’association interne pour utiliser un nom de domaine déjà présent dans votre compte OVHcloud. Toutes les étapes s’effectuent dans ce même panneau, sans récapitulatif intermédiaire. Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Dans la section **Configuration du domaine** du panneau, sélectionnez <code className="action">Associer un domaine OVHcloud existant</code> (choix proposé par défaut).

    <img className="thumbnail" alt="Panneau Ajouter un nom de domaine avec le choix Associer un domaine OVHcloud existant sélectionné" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/attach-ovhcloud-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans le menu déroulant **Nom de domaine**, sélectionnez le nom de domaine souhaité parmi les noms de domaine disponibles sur votre compte OVHcloud.

    Pour associer un sous-domaine, cochez ensuite la case <code className="action">Créer un sous-domaine</code>, puis saisissez le préfixe du sous-domaine (par exemple : `blog` pour `blog.domain.tld`) dans le champ qui apparaît.

    <img className="thumbnail" alt="Menu déroulant Nom de domaine ouvert sur les noms de domaine OVHcloud disponibles dans le compte" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/select-ovh-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Cliquez sur le bouton <code className="action">Ajouter un nom de domaine</code> en bas du panneau. Ce bouton reste inactif tant que le nom de domaine sélectionné est déjà associé au site. Un message confirme ensuite la prise en compte de votre demande. La configuration DNS est prise en charge automatiquement.
  </Tab>
</Tabs>

{/* CP-STEPS-END:ajouter-domaine-interne */}

:::info
Pour un nom de domaine interne, la propagation DNS est automatique. Votre site sera accessible via ce nom de domaine en quelques minutes à quelques heures.
:::

</details>

<details>

<summary>Ajouter un nom de domaine externe</summary>

Un nom de domaine **externe** est géré chez un autre bureau d’enregistrement (Gandi, Namecheap, Google Domains, etc.). Vous devrez modifier manuellement votre zone DNS.

{/* CP-STEPS-START:ajouter-domaine-externe */}

Une fois le panneau **Ajouter un nom de domaine** ouvert, choisissez l’association externe pour utiliser un nom de domaine géré chez un autre bureau d’enregistrement. La saisie du nom de domaine et sa validation s’effectuent dans ce même panneau ; la procédure de configuration DNS vous est ensuite envoyée par e-mail. Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Dans la section **Configuration du domaine** du panneau, sélectionnez <code className="action">Associer un domaine externe</code>. Le menu déroulant **Nom de domaine** est alors remplacé par un champ de saisie.

    <img className="thumbnail" alt="Panneau Ajouter un nom de domaine avec le choix Associer un domaine externe sélectionné" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/attach-external-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Entrez votre nom de domaine (par exemple : `domain.tld`) dans le champ **Nom de domaine**, puis cliquez sur le bouton <code className="action">Ajouter un nom de domaine</code> en bas du panneau.

    <img className="thumbnail" alt="Champ Nom de domaine renseigné avec un nom de domaine externe d’exemple et bouton Ajouter un nom de domaine actif" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/associate-external-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Un message confirme la prise en compte de votre demande et vous informe qu’un e-mail contenant la procédure à suivre vous a été envoyé. La console OVHcloud n’affiche pas les enregistrements DNS à créer et ne propose aucune étape de confirmation : tout se poursuit à partir de cet e-mail.

    Suivez la procédure reçue pour configurer, depuis l’interface DNS de votre prestataire actuel, les enregistrements DNS requis (généralement un enregistrement de DNS type **A** ou **CNAME** : **C**anonical **NAME**).
  </Tab>
</Tabs>

{/* CP-STEPS-END:ajouter-domaine-externe */}

:::warning
La propagation DNS d’un nom de domaine externe peut prendre jusqu’à **24 à 48 heures** selon votre prestataire. Votre site WordPress ne sera pas accessible via ce nom de domaine pendant cette période.
:::

:::info
Le certificat SSL (Secure Sockets Layer) est généré automatiquement après validation de la propagation DNS. Aucune intervention manuelle n’est nécessaire de votre côté.
:::

</details>

### 3 - Gérer les noms de domaine d’un site WordPress

<Tabs>

Si la ressource est au statut **À renouveler** ou **Résilié**, cliquez directement sur le lien <code className="action">Gérer</code> affiché en bas de son encadré.

    Dans la fenêtre **Définir comme domaine principal** qui s’affiche, cliquez sur <code className="action">Valider</code> pour confirmer.

:::info
Le nom de domaine principal est celui utilisé par défaut pour accéder à votre site WordPress. Modifier le nom de domaine principal peut affecter votre référencement SEO (Search Engine Optimization) si votre site WordPress est déjà indexé. Pensez à configurer une redirection depuis l’ancien nom de domaine principal si nécessaire.
:::

</details>

<Tabs>

    Cliquez sur <code className="action">Supprimer</code> pour confirmer la suppression.
  </Tab>
</Tabs>

**Effets de la suppression :**

- **Votre site WordPress reste intact** : seul le lien avec le nom de domaine est rompu, le site continue de fonctionner.
- **L’URL technique permanente reste accessible** : votre site WordPress reste joignable via cette URL, même sans nom de domaine.
- **Le certificat SSL est révoqué** : il ne couvre plus le nom de domaine supprimé.
- **Le référencement SEO peut être impacté** : si le nom de domaine était indexé par les moteurs de recherche, son retrait affecte le positionnement.
- **Pensez à vérifier vos services e-mail** : les adresses liées à ce nom de domaine peuvent être affectées par la suppression.

:::info
**Cas particulier — nom de domaine principal unique :** si vous supprimez le seul nom de domaine principal d’un site WordPress, votre site WordPress bascule automatiquement sur son **URL technique permanente**. Cette URL reste toujours accessible et n’est jamais supprimée, même en l’absence de domaine associé.
:::

</details>

### L’URL technique permanente

Chaque site Managed Hosting for WordPress dispose d’une **URL technique permanente**, indépendante de tout nom de domaine. Cette URL est générée automatiquement à la création du site WordPress et ne peut pas être supprimée.

{/* CP-STEPS-START:url-technique-permanente */}

<img className="thumbnail" alt="Panneau Gérer mes domaines affichant le nom de domaine principal et l’URL technique d’un site WordPress" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/show-domain-linked-to-a-site.png" loading="lazy" />

Elle vous permet de :

- Accéder à votre site WordPress **en toutes circonstances**, même sans nom de domaine associé.
- Tester votre site WordPress avant d’y faire pointer un nom de domaine.
- Maintenir un accès de secours en cas de problème DNS.

:::info
L’URL technique est de la forme `*.mcms.ovh.net` ou similaire. Retrouvez-la dans l’onglet <code className="action">Mes sites</code> : cliquez sur le bouton <code className="action">⋮</code> de la colonne **Actions**, à droite du site WordPress concerné, puis sur <code className="action">Gérer mes domaines</code>. Le panneau qui s’ouvre l’affiche à côté des noms de domaine du site. Un site auquel aucun nom de domaine n’est associé est directement affiché sous son URL technique dans la colonne **Nom du site**.
:::

{/* CP-STEPS-END:url-technique-permanente */}
