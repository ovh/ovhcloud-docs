## Objectif

Le **Managed Hosting for WordPress** est une nouvelle offre OVHcloud permettant d’héberger et d’administrer vos sites web WordPress en toute simplicité. Pensé pour les professionnels, les agences et les indépendants, ce service vous libère des tâches techniques liées à la gestion de l’infrastructure et des mises à jour, afin que vous puissiez vous concentrer sur votre contenu et votre activité. Ce guide présente le concept du produit, ses principaux avantages et les fonctionnalités disponibles.

## Prérequis

- Disposer d’une offre [Managed Hosting for WordPress](/links/web/managed-hosting-wordpress) active.

[[cpnav:web-wordpress-hosting]]

## En pratique

### Présentation du produit

#### Une gestion WordPress 100 % OVHcloud

Avec Managed Hosting for WordPress, **OVHcloud s’occupe de tout** :

- Hébergement, infrastructure, cache et sécurité.
- Installation et maintenance de WordPress.
- Sauvegardes et mises à jour automatiques.
- Supervision des performances et de la disponibilité.
- Gestion simplifiée des domaines, des plugins et des environnements de staging.

Aucune connaissance serveur n’est nécessaire : tout est **accessible depuis l’espace client OVHcloud**. Vous pouvez ainsi **créer, importer et administrer vos sites WordPress en quelques clics**, sans jamais avoir à manipuler de FTP, de base de données ni de ligne de commande.

#### Une solution clé en main

Chaque site web bénéficie d’un environnement optimisé, prêt à l’emploi :

- **Installation WordPress automatique** dès la commande.
- **Infrastructure managée** : maintenance, patchs, mises à jour logicielles et sécurité gérés par OVHcloud.
- **Performances garanties** : cache WordPress intégré, hébergement sur infrastructure optimisée et monitoring continu.
- **Évolutivité intégrée** : surveillez l’utilisation en temps réel à l’aide d’indicateurs clés (stockage, trafic, nombre de sites) et adaptez-vous facilement à l’évolution de vos besoins.
- **Compatibilité totale** : accès via l’espace client OVHcloud, permettant l’intégration dans vos workflows existants.

### Fonctionnalités

#### Créer un site web

{/* CP-STEPS-START:creer-un-site-web */}

Pour créer un site web, cliquez sur le bouton <code className="action">Créer un site</code> situé au-dessus du tableau de l’onglet <code className="action">Mes sites</code>. Le panneau **Créer un site** s’ouvre sur la droite de l’écran :

<img className="thumbnail" alt="Panneau Créer un site ouvert à droite de l’onglet Mes sites" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/console/managed_wordpress_create_site.png" loading="lazy" />

Remplissez les champs du formulaire afin de définir les identifiants de votre site web WordPress :

- **E-mail** : saisissez l’adresse e-mail de l’administrateur du site WordPress. Ce champ est prérempli avec l’adresse e-mail de votre compte OVHcloud.
- **Mot de passe** : définissez le mot de passe associé à ce compte administrateur. Il doit comporter au minimum 8 caractères, dont des majuscules, des chiffres et des caractères spéciaux.
- **Confirmation du mot de passe** : saisissez à nouveau ce mot de passe.
- **Version PHP** : choisissez la version PHP souhaitée pour votre environnement WordPress. Consultez les versions disponibles de PHP sur [cette page](/guides/web-cloud/web-hosting/web-hosting-main-info).
- **Langue** : sélectionnez la langue par défaut de l’interface d’administration.

Les champs **E-mail**, **Mot de passe** et **Confirmation du mot de passe** sont obligatoires : le bouton <code className="action">Créer le site</code> reste inactif tant qu’ils ne sont pas correctement remplis. Cliquez ensuite sur <code className="action">Créer le site</code> pour valider les informations.

Vous restez sur l’onglet <code className="action">Mes sites</code> et un message vous confirme la création de votre site web.

Dans le tableau, une nouvelle ligne concernant votre nouveau site web apparaît :

- Colonne **Nom du site** : affiche le nom de domaine principal de votre site web ou, tant qu’aucun nom de domaine ne lui est associé, son URL technique. Cette URL technique sert d’URL de staging (pré-production) : elle vous permet d’accéder à votre site web avant de l’associer à votre propre nom de domaine.
- Colonne **Statut** : indique l’état d’avancement de la création du site web. Le statut apparaît d’abord comme **Création...**, le temps que l’infrastructure soit déployée et que WordPress soit installé. Une fois votre site web opérationnel, le statut passe à **Actif**, indiquant que votre WordPress est désormais disponible en ligne via son URL technique.

<img className="thumbnail" alt="Onglet Mes sites affichant le tableau des sites WordPress et leur statut" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/managed-hosting-for-wordpress-my-sites-tab.png" loading="lazy" />

Vous pouvez également suivre la progression de la création de votre site web en cliquant sur l’onglet <code className="action">Opérations</code>. Le tableau de cet onglet indique le statut et la progression de chaque opération en cours ou terminée.

<img className="thumbnail" alt="Onglet Opérations affichant le tableau des opérations d’une ressource Managed WordPress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/console/managed_wordpress_task_new_line.png" loading="lazy" />

#### Importer un site web

Vous pouvez importer un site web WordPress existant vers le Managed Hosting for WordPress. L’import vous permet de transférer automatiquement :

- Le contenu WordPress (plugins, themes, médias, articles, pages, utilisateurs).
- Les fichiers.
- La base de données.

{/* CP-STEPS-START:importer-un-site-web */}

Pour importer un site web WordPress, cliquez sur le bouton <code className="action">Importer un site</code> situé au-dessus du tableau de l’onglet <code className="action">Mes sites</code>.

Une fenêtre intitulée **Désactivez votre protection anti-robot** s’affiche d’abord. Afin d’éviter tout échec de connexion, elle vous invite à désactiver temporairement les protections anti-robot de votre site web source : extensions de sécurité, captchas, pare-feu réseau ou verrous tels que Cloudflare. Vous pourrez les réactiver une fois l’import terminé. Après avoir désactivé ces protections, cliquez sur <code className="action">Valider</code>. Le panneau **Importer un site** s’ouvre sur la droite de l’écran :

<img className="thumbnail" alt="Panneau Importer un site ouvert à droite de l’onglet Mes sites" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/console/managed_wordpress_import_site.png" loading="lazy" />

:::info
Un message d’information, en haut du panneau, vous indique que l’opération peut prendre jusqu’à 48 heures selon la complexité de votre site. Si nécessaire, nos équipes techniques interviendront pour finaliser l’import.

:::

Renseignez les champs du formulaire, tous obligatoires :

- **URL d'administration** : indiquez l’adresse utilisée pour vous connecter à l’interface d’administration de votre site web WordPress actuel, par exemple `https://www.domain.tld/wp-admin`.
- **Identifiant administrateur** : saisissez le nom d’utilisateur ou l’adresse e-mail d’un compte administrateur WordPress de votre site web actuel.
- **Mot de passe administrateur** : indiquez le mot de passe de ce compte administrateur WordPress.

Ces informations permettent au système d’accéder à votre site web existant afin d’en extraire automatiquement les fichiers, la base de données et la configuration nécessaire.

Le bouton <code className="action">Continuer</code> reste inactif tant que les champs obligatoires ne sont pas remplis. Une fois ceux-ci renseignés, cliquez sur <code className="action">Continuer</code> pour lancer le processus d’import.

Vous pourrez alors sélectionner les éléments à importer, y compris les plugins, thèmes, médias et bases de données.

:::warning
Pour garantir une parfaite cohérence des données, veillez à ne plus effectuer de modifications sur votre site jusqu’à la fin de l’import.

Nous vous invitons à prendre les mesures nécessaires pour éviter toute divergence de données pendant l’import.

:::

Une fois tous les éléments sélectionnés, cliquez sur <code className="action">Lancer l'import</code>.

{/* CP-STEPS-END:importer-un-site-web */}
#### Supprimer un site web

:::danger
La suppression d’un site web est définitive et entraîne la suppression de l’intégralité du contenu du site.
Prenez soin d’effectuer une sauvegarde de vos données avant toute action de suppression.

:::

##### Supprimer un seul site web

{/* CP-STEPS-START:supprimer-un-seul-site-web */}

Pour supprimer un site web, dirigez-vous dans l’onglet <code className="action">Mes sites</code> et identifiez la ligne du tableau correspondant à votre site web. Dans la colonne **Actions**, cliquez sur le bouton <code className="action">⋮</code> à droite de ce site, puis sur <code className="action">Supprimer le site</code>.

<img className="thumbnail" alt="Menu du bouton ⋮ d’un site, avec l’entrée Supprimer le site en dernière position" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/adding-domain.png" loading="lazy" />

Une fenêtre intitulée **Supprimer le site** s’affiche. Elle vous rappelle que cette action est irréversible : toutes les données du site seront définitivement supprimées. Cliquez sur <code className="action">Supprimer</code> pour confirmer la suppression de votre site web.

Vous restez sur l’onglet <code className="action">Mes sites</code> et un message vous confirme la suppression de votre site web.

Lorsque votre site web est définitivement supprimé, sa ligne correspondante dans le tableau disparaît.

{/* CP-STEPS-END:supprimer-un-seul-site-web */}
##### Supprimer plusieurs sites web à la fois

{/* CP-STEPS-START:supprimer-plusieurs-sites-web */}

Pour supprimer plusieurs sites web en même temps, dirigez-vous dans l’onglet <code className="action">Mes sites</code>. Identifiez les lignes du tableau correspondant aux sites web que vous souhaitez supprimer et cochez les cases situées à gauche. Le bouton <code className="action">Actions</code> situé au-dessus du tableau affiche alors le nombre de sites sélectionnés. Cliquez sur ce bouton, puis sur <code className="action">Supprimer</code>.

<img className="thumbnail" alt="Onglet Mes sites avec deux sites cochés et le menu Actions ouvert sur l’entrée Supprimer" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/console/managed_wordpress_delete_several_sites.png" loading="lazy" />

Une fenêtre intitulée **Supprimer X sites** s’affiche, X correspondant au nombre de sites sélectionnés. Elle vous rappelle que cette action est irréversible et que ces sites seront supprimés définitivement. Cliquez sur <code className="action">Supprimer X sites</code> pour confirmer la suppression de vos sites web.

Vous restez sur l’onglet <code className="action">Mes sites</code> et un message vous confirme la suppression de vos sites web. Si la suppression d’un ou de plusieurs sites échoue, ce message indique le nombre de sites supprimés et le nombre d’échecs.

Lorsque vos sites web sont définitivement supprimés, leurs lignes correspondantes dans le tableau disparaissent.

{/* CP-STEPS-END:supprimer-plusieurs-sites-web */}
#### Gérer ses sites web

{/* CP-STEPS-START:gerer-ses-sites-web */}

Pour gérer tous vos sites web, dirigez-vous dans l’onglet <code className="action">Mes sites</code>, cliquez sur le bouton <code className="action">Administrer</code> situé au-dessus du tableau, puis sur <code className="action">Gérer mes sites</code>. Cette entrée ouvre, dans un nouvel onglet de votre navigateur, le gestionnaire de flotte intégré au Managed Hosting for WordPress. Cet espace vous permet de gérer plusieurs sites web WordPress simultanément, depuis une interface unifiée.

L’entrée <code className="action">Gérer mes sites</code> figure également en tête du menu du bouton <code className="action">Actions</code>.

{/* CP-STEPS-END:gerer-ses-sites-web */}
##### Tableau de bord

Le gestionnaire de flotte est un outil de supervision et de gestion centralisée fourni automatiquement avec votre offre. Il vous permet d’administrer vos sites web WordPress managés sans avoir à vous connecter à chaque site web individuellement.

Depuis ce tableau de bord, vous pouvez notamment :

- Consulter l’état global de tous vos sites web : mises à jour disponibles, alertes, performances, sécurité.
- Gérer les mises à jour WordPress (plugins, thèmes, etc.) de manière centralisée.
- Accéder rapidement à chaque site web pour vérifier son état ou intervenir.
- Superviser les activités récentes (changements, mises à jour, synchronisations).
- Utiliser les fonctionnalités intégrées de sécurité, monitoring, sauvegardes, et analyses (dans les phases futures).

#### Mises à jour automatiques intelligentes

Les mises à jour automatiques peuvent entraîner des problèmes de compatibilité qui affectent la stabilité, les performances et l’expérience utilisateur du site. Lorsque vous gérez plusieurs sites WordPress, la gestion manuelle des mises à jour augmente les frais généraux opérationnels et le risque d’interruption de service pour les utilisateurs finaux.

La solution Managed Hosting for WordPress atténue ces risques grâce à un processus de mise à jour contrôlé :

- **Tests avant déploiement**
    Toutes les mises à jour, y compris celles du cœur de WordPress, des plugins et des thèmes, sont d’abord appliquées à un environnement cloné de votre site.
- **Contrôles de validation**
    Le site cloné est évalué en termes de performances, de fonctionnalités et d’expérience utilisateur afin de détecter les régressions ou les erreurs avant le déploiement.
- **Processus de décision automatisé**
    - Si aucun problème n’est détecté, la mise à jour est automatiquement déployée sur le site en ligne.
    - Si des problèmes sont identifiés, le site en ligne reste inchangé. Vous êtes averti via le tableau de bord et recevez un e-mail décrivant les problèmes détectés ainsi que les mesures correctives recommandées.

Cette approche garantit que les mises à jour sont appliquées en toute sécurité tout en préservant la fiabilité du site et en minimisant l’impact sur les utilisateurs finaux.
