## Objectif

Votre solution **Managed Hosting for WordPress** se pilote en langage naturel depuis un agent IA (Claude Code, Codex, etc.), grâce au protocole **MCP** (*Model Context Protocol*). Vous connectez vous-même un seul serveur, le **MCP OVHcloud**. Votre agent IA s'en sert ensuite pour configurer les deux autres : **MCP for WordPress**, pour le contenu d'un site, et **MainWP**, pour gérer plusieurs sites à la fois.

**Découvrez comment connecter votre agent IA au MCP OVHcloud, puis comment lui faire configurer MCP for WordPress et MainWP.**

## Prérequis

- Disposer d'une offre [Managed Hosting for WordPress](/guides/web-cloud/managed-hosting/wordpress) active avec au moins un site WordPress.
- Disposer d'un compte OVHcloud ayant accès à cette offre.
- Utiliser un agent IA compatible MCP **installé sur votre ordinateur** et capable d'exécuter des commandes, par exemple [Claude Code](https://code.claude.com/docs/fr/overview) ou [Codex](https://learn.chatgpt.com/docs/codex/cli).
- Pour MainWP : disposer de [Node.js](https://nodejs.org/fr) (version LTS) sur votre ordinateur.

:::info
Un assistant IA utilisé dans un navigateur peut se connecter au MCP OVHcloud, mais pas à MCP for WordPress ni à MainWP : ces deux connexions s'enregistrent dans la configuration de l'agent, sur votre ordinateur.
:::

## Introduction

Trois serveurs MCP couvrent chacun une partie de votre offre :

| Serveur MCP | Ce que votre agent IA peut piloter | Comment le connecter |
|---|---|---|
| **MCP OVHcloud** | L'hébergement : offres, sites, domaines, versions de PHP, cache CDN, logs, sauvegardes, mots de passe SFTP, phpMyAdmin et base de données | Vous l'ajoutez une fois, puis vous vous identifiez avec votre compte OVHcloud |
| **MCP for WordPress** | Un site WordPress : articles, pages, médias, commentaires, menus, réglages, extensions, thèmes et utilisateurs | Votre agent IA le configure, une connexion par site |
| **MainWP** | Plusieurs sites à la fois depuis le tableau de bord MainWP inclus dans votre offre : mises à jour, activation et désactivation des extensions, des thèmes et des traductions | Votre agent IA le configure, une connexion pour toute l'offre |

**MCP for WordPress** est une extension OVHcloud préinstallée sur les sites de votre offre. Elle donne à votre agent IA une liste fermée d'actions pour piloter votre site WordPress.

## En pratique

:::warning
Votre agent IA agit avec les droits que vous lui accordez : votre compte OVHcloud pour le MCP OVHcloud, un compte administrateur pour MCP for WordPress. Relisez chaque action qu'il vous propose avant de la valider, en particulier une suppression, une mise à jour ou une publication.
:::

### Étape 1 : connecter le MCP OVHcloud

Le MCP OVHcloud est un serveur distant hébergé par OVHcloud. Vous ne lui transmettez aucun mot de passe : votre agent IA ouvre la page de connexion OVHcloud dans votre navigateur et vous vous identifiez comme dans votre espace client.

Choisissez votre agent IA dans les onglets ci-dessous.

<Tabs>
  <Tab label="Claude Code">
    Dans un terminal, exécutez :

    ```bash
    claude mcp add --transport http --scope user ovhcloud https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    ```

    Lancez Claude Code, tapez `/mcp`, sélectionnez le serveur **ovhcloud**, puis **Authenticate**. Identifiez-vous avec votre compte OVHcloud dans la page qui s'ouvre.

    :::warning
    N'ajoutez pas d'option `--header` à cette commande. Un en-tête `Authorization` fixe empêche l'identification OVHcloud : le serveur s'affiche comme connecté, mais chaque demande échoue ensuite avec une erreur 401.
    :::
  </Tab>
  <Tab label="Codex">
    Dans un terminal, exécutez :

    ```bash
    codex mcp add ovhcloud --url https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    codex mcp login ovhcloud
    ```

    Identifiez-vous avec votre compte OVHcloud dans la page qui s'ouvre, puis relancez Codex.
  </Tab>
  <Tab label="Autre agent IA">
    Ajoutez un serveur MCP distant (transport *streamable HTTP*) dans la configuration de votre agent IA :

    - **URL** : `https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS`
    - **Authentification** : OAuth, sans en-tête ni jeton à saisir.

    Lancez l'authentification depuis votre agent IA et identifiez-vous avec votre compte OVHcloud.
  </Tab>
</Tabs>

Pour vérifier la connexion, demandez à votre agent IA :

> Liste mes offres Managed Hosting for WordPress et leurs sites.

Il vous répond avec vos offres et les adresses de vos sites.

### Étape 2 : faire configurer MCP for WordPress pour un site

Demandez à votre agent IA, en indiquant l'adresse de votre site :

> Configure le MCP for WordPress de mon site www.example.com

Si vous ne précisez pas de site, il vous propose la liste des sites de votre offre.

La configuration se déroule ensuite ainsi :

1. **Votre agent IA vous demande l'autorisation** de créer un mot de passe d'application sur le site. Ce mot de passe lui permet d'agir sur le site en tant qu'administrateur, dans les limites des actions de MCP for WordPress. Pour accepter, répondez explicitement :

    > Oui, crée le mot de passe d'application

    Répéter votre demande initiale ne vaut pas accord : votre agent IA attend cette réponse avant d'aller plus loin.

2. **Votre agent IA vérifie que l'extension MCP for WordPress est active** sur le site. Si elle ne l'est pas, il vous le signale : activez **MCP for WordPress** depuis le menu <code className="action">Extensions</code> de l'administration WordPress de votre site, puis renouvelez votre demande.
3. **Votre agent IA crée le mot de passe d'application** via le MCP OVHcloud, puis ajoute la connexion du site à sa configuration. Approuvez la commande qu'il exécute.
4. **Rechargez les serveurs MCP** : dans Claude Code, tapez `/mcp` puis reconnectez-vous, ou relancez Claude Code ; dans Codex, relancez-le. Les outils du site n'apparaissent qu'après ce rechargement.

Pour vérifier la connexion, demandez :

> Liste les 5 derniers articles de www.example.com

Répétez cette étape pour chaque site à piloter : chaque site a sa propre connexion.

### Étape 3 : faire configurer MainWP

Le tableau de bord MainWP inclus dans votre offre gère l'ensemble de vos sites. Demandez à votre agent IA :

> Configure le MCP MainWP

La configuration suit le même déroulement qu'à l'étape 2 :

1. **Votre agent IA vous demande l'autorisation** de créer un mot de passe d'application sur le tableau de bord MainWP. Pour accepter, répondez :

    > Oui, crée le mot de passe d'application

2. **Votre agent IA vérifie la présence de Node.js** sur votre ordinateur. S'il est absent, installez la version LTS depuis [nodejs.org](https://nodejs.org/fr), puis renouvelez votre demande.
3. **Votre agent IA crée le mot de passe d'application** via le MCP OVHcloud, puis ajoute le serveur MainWP à sa configuration. Approuvez la commande qu'il exécute.
4. **Rechargez les serveurs MCP** comme à l'étape 2.

Pour vérifier la connexion, demandez :

> Liste les sites de mon tableau de bord MainWP et les extensions à mettre à jour.

:::info
Le serveur MainWP est configuré pour vous demander une confirmation avant chaque action qui modifie vos sites.
:::

### Exemples de demandes

Une fois les trois serveurs connectés, formulez vos demandes comme à un collègue. Votre agent IA choisit le bon serveur.

| Vous souhaitez… | Exemple de demande |
|---|---|
| Rédiger du contenu | « Rédige un brouillon d'article sur nos horaires d'été pour www.example.com. » |
| Modérer les commentaires | « Affiche les commentaires en attente de modération sur www.example.com. » |
| Mettre à jour plusieurs sites | « Quelles extensions doivent être mises à jour sur l'ensemble de mes sites ? » |
| Diagnostiquer une erreur | « Mon site www.example.com renvoie des erreurs 500 : consulte les logs et dis-moi pourquoi. » |
| Vider le cache | « Vide le cache CDN de www.example.com. » |
| Sauvegarder un site | « Exporte une sauvegarde complète de www.example.com. » |

Avant de publier un article, votre agent IA vous demande quel compte WordPress en est l'auteur.

### Révoquer un accès

Vous pouvez retirer à tout moment l'accès accordé à votre agent IA :

- **MCP for WordPress** : dans l'administration WordPress du site, ouvrez <code className="action">Comptes</code> > <code className="action">Profil</code>, puis supprimez le mot de passe d'application dans la section **Mots de passe d'application**.
- **MainWP** : procédez de la même manière dans l'administration WordPress du tableau de bord MainWP.
- **MCP OVHcloud** : retirez le serveur de la configuration de votre agent IA, par exemple avec `claude mcp remove ovhcloud` dans Claude Code.

### En cas de problème

- **Votre agent IA indique qu'il ne peut pas se connecter au site ou à MainWP** : vérifiez qu'il s'exécute sur votre ordinateur et non dans un navigateur.
- **Les nouveaux outils n'apparaissent pas** : rechargez les serveurs MCP (`/mcp` dans Claude Code) ou relancez votre agent IA.
- **Votre agent IA s'arrête en signalant une action refusée** : il a bloqué la création du mot de passe ou l'exécution de la commande. Autorisez cette action dans ses réglages de permissions, ou nommez-la explicitement dans votre demande, par exemple « Crée un mot de passe d'application sur le site www.example.com ».
- **Les demandes au MCP OVHcloud échouent avec une erreur 401** : supprimez le serveur, ajoutez-le de nouveau sans en-tête, puis relancez l'authentification.
