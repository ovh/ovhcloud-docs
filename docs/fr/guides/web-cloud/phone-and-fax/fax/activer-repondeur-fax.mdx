## Objectif

Vous pouvez configurer votre ligne fax en tant que messagerie vocale directement depuis la console OVHcloud. 

**Découvrez comment activer et utiliser le répondeur de la ligne Fax.**

:::info
L'activation de la fonctionnalité répondeur désactive toutes les fonctionnalités fax de votre ligne.

:::


## Prérequis

- Disposer d’une [ligne Fax OVHcloud](https://www.ovhtelecom.fr/fax/).

[[cpnav:telecom-voip-fax]]

## En pratique

{/* CP-STEPS-START:selectionner-ligne-fax */}

Sélectionnez l'onglet <code className="action">Services</code>, puis cliquez sur le nom de la ligne dont la colonne **Type** indique « Fax ».

<img className="thumbnail" alt="Onglet Services du groupe de facturation, ligne de type Fax" src="/images/web-cloud/phone-and-fax/fax/activer-repondeur-fax/console/gestion-repondeur.png" loading="lazy" />

{/* CP-STEPS-END:selectionner-ligne-fax */}

### Activer le répondeur fax

{/* CP-STEPS-START:activer-repondeur */}

Pour activer le répondeur, cliquez sur l'onglet <code className="action">Messagerie</code> de votre ligne fax. Dans la section **Configuration de la messagerie**, activez l'interrupteur **Fonction répondeur**. L'activation est appliquée immédiatement, sans confirmation.

<img className="thumbnail" alt="Interrupteur Fonction répondeur dans l'onglet Messagerie" src="/images/web-cloud/phone-and-fax/fax/activer-repondeur-fax/console/activer-desactiver-repondeur.png" loading="lazy" />

{/* CP-STEPS-END:activer-repondeur */}

### Configurer un mot de passe

Vous pouvez consulter votre messagerie vocale depuis n'importe quel téléphone en composant le 0033972550000.

{/* CP-STEPS-START:configurer-mot-de-passe */}

Un mot de passe d'accès, composé de 4 chiffres, est nécessaire pour cette manipulation. Pour le configurer, dans la section **Configuration de la messagerie**, cliquez sur <code className="action">Modifier</code> sous **Mot de passe du répondeur**. Dans la fenêtre **Modifier le mot de passe**, renseignez les champs **Nouveau mot de passe** et **Confirmer le mot de passe**, puis cliquez sur <code className="action">Enregistrer</code>.

L'interrupteur **Demande du mot de passe à la connexion** détermine si ce mot de passe vous est demandé lorsque vous appelez votre répondeur.

<img className="thumbnail" alt="Fenêtre Modifier le mot de passe du répondeur" src="/images/web-cloud/phone-and-fax/fax/activer-repondeur-fax/console/mot-de-passe-repondeur.png" loading="lazy" />

{/* CP-STEPS-END:configurer-mot-de-passe */}

### Configurer le répondeur

{/* CP-STEPS-START:configurer-repondeur */}

Les paramètres du répondeur sont affichés directement dans l'onglet <code className="action">Messagerie</code>. La section **Configuration de la messagerie** vous permet de configurer l'enregistrement des messages, avec l'interrupteur **Enregistrement des messages**, ainsi que le message d'accueil de votre répondeur. Pour choisir ce dernier, cliquez sur l'icône en forme de crayon à côté de **Type de message**. Dans le panneau **Messages d'accueil**, sélectionnez **Par défaut**, **Personnalisé (court)** ou **Personnalisé (complet)**, puis, pour un message personnalisé, importez votre fichier audio à l'aide du bouton <code className="action">Téléverser</code>. Ce panneau permet également de définir un **Message temporaire**.

<img className="thumbnail" alt="Panneau Messages d'accueil avec les types de message et les boutons Téléverser" src="/images/web-cloud/phone-and-fax/fax/activer-repondeur-fax/console/configuration-repondeur-accueil.png" loading="lazy" />

Dans la section **Notifications**, vous pouvez aussi renseigner plusieurs adresses e-mail de notification, sur lesquelles vous pourrez également recevoir les messages. Cliquez sur <code className="action">Ajouter un email</code>, saisissez l'adresse dans la fenêtre **Ajouter un email de notification**, puis choisissez son type dans le menu déroulant **Type** : **Notification simple**, **Pièce jointe**, **Transcription uniquement** ou **Pièce jointe + transcription**. Vous pouvez définir différents formats audio à partir du menu déroulant **Format audio**. L'interrupteur **Conserver les messages après notification** détermine si les messages restent sur le répondeur après leur envoi par e-mail.

Personnalisez l'adresse e-mail et le nom de l'expéditeur des notifications que vous recevez, permettant d'éviter les filtres automatiques (type spam webmail) : cliquez sur l'icône en forme de crayon à côté de **Nom de l'expéditeur** ou de **Email de l'expéditeur**, modifiez la valeur, puis cliquez sur <code className="action">Enregistrer</code>.

<img className="thumbnail" alt="Section Notifications de l'onglet Messagerie" src="/images/web-cloud/phone-and-fax/fax/activer-repondeur-fax/console/configuration-repondeur.png" loading="lazy" />

{/* CP-STEPS-END:configurer-repondeur */}

### Écoute et gestion des messages

{/* CP-STEPS-START:ecoute-gestion-messages */}

La section **Messages vocaux**, en bas de l'onglet <code className="action">Messagerie</code>, vous permet de gérer l'historique de vos messages : pour chacun, le tableau indique la date, l'appelant, le numéro appelé, la durée et le statut. Pour écouter ou télécharger un message, cliquez sur le bouton <code className="action">⋮</code> à droite de sa ligne, puis sur <code className="action">Écouter</code> ou <code className="action">Télécharger</code>. Ce menu permet également d'obtenir une transcription écrite du message ou de le supprimer.

<img className="thumbnail" alt="Section Messages vocaux et menu d'un message" src="/images/web-cloud/phone-and-fax/fax/activer-repondeur-fax/console/messages.png" loading="lazy" />

{/* CP-STEPS-END:ecoute-gestion-messages */}

Nous conservons jusqu'à 100 messages sur votre boîte vocale pour une durée de 6 mois maximum. Ils sont effacés en dehors de ces conditions.
