## Objectif

Vous pouvez configurer votre ligne Fax directement via la console OVHcloud, pour optimiser la réception et l'envoi de vos fax sur votre télécopieur, préciser des adresses e-mail de notification ou d'envoi, ou encore appliquer des filtrages.

**Découvrez les différentes options de configuration disponibles dans la console OVHcloud.**

## Prérequis

- Disposer d’une [ligne Fax OVHcloud](https://www.ovhtelecom.fr/fax/).

[[cpnav:telecom-voip-fax]]

## En pratique

{/* CP-STEPS-START:selectionner-ligne-fax */}

Sélectionnez l'onglet <code className="action">Services</code> puis la ligne Fax concernée.

{/* CP-STEPS-END:selectionner-ligne-fax */}

### Mot de passe fax

L'envoi de télécopies par e-mail ou via le logiciel EcoFax nécessite de définir un mot de passe fax.

{/* CP-STEPS-START:mot-de-passe-fax */}

Pour le définir, sélectionnez votre ligne FAX, cliquez sur l'onglet <code className="action">Paramètres fax</code> puis, sous **Mot de passe FAX**, sur le bouton <code className="action">Modifier le mot de passe</code>. Dans la fenêtre qui s'ouvre, saisissez votre **Nouveau mot de passe** puis cliquez sur <code className="action">Modifier le mot de passe</code>.

<img className="thumbnail" alt="onglet Paramètres fax, fenêtre Modifier le mot de passe" src="/images/web-cloud/phone-and-fax/fax/configuration-fax-espace-client/console/motdepassefax.png" loading="lazy" />

Le mot de passe doit contenir de 8 à 20 caractères et au moins deux types de caractères parmi les chiffres, les lettres et les caractères spéciaux.

{/* CP-STEPS-END:mot-de-passe-fax */}


### Options de configuration

{/* CP-STEPS-START:options-de-configuration */}

Sélectionnez votre ligne FAX puis cliquez sur l'onglet <code className="action">Paramètres fax</code>. Cet onglet regroupe l'ensemble des réglages de la ligne, répartis en trois sections : **Paramètres fax**, **Notifications fax** et **Filtrage fax**.

<img className="thumbnail" alt="onglet Paramètres fax d'une ligne fax" src="/images/web-cloud/phone-and-fax/fax/configuration-fax-espace-client/console/configuration-fax.png" loading="lazy" />

{/* CP-STEPS-END:options-de-configuration */}


#### Options générales

{/* CP-STEPS-START:options-generales */}

Ces options se trouvent dans la section **Paramètres fax**.

La qualité d'envoi de vos télécopies peut avoir un impact sur vos émissions de télécopies à destination de certains numéros spéciaux.

Dans le menu déroulant **Qualité**, passez-la en « Meilleure » pour faciliter des envois vers les numéros spéciaux ou étrangers.

Vous pouvez aussi paramétrer, dans le menu déroulant **Tentatives max**, le nombre de tentatives d'envoi maximum (de 1 à 9), dans le cas d'un échec de transmission lors de la première tentative.

Chaque modification est enregistrée dès que vous sélectionnez une valeur.

<img className="thumbnail" alt="section Paramètres fax, menus Qualité et Tentatives max" src="/images/web-cloud/phone-and-fax/fax/configuration-fax-espace-client/console/options_generales.png" loading="lazy" />

{/* CP-STEPS-END:options-generales */}

#### En-tête des fax émis

{/* CP-STEPS-START:en-tete-des-fax-emis */}

L'en-tête des fax émis est un champ de texte libre : vous pouvez y saisir le contenu de votre choix (par exemple le nom de votre société). Dans la section **Paramètres fax**, cliquez sur <code className="action">Modifier</code> à côté de **Ligne d'en-tête**, saisissez votre texte puis cliquez sur <code className="action">Enregistrer</code>.

Vous pouvez également y insérer des variables, qui seront automatiquement remplacées par les informations correspondantes lors de l'envoi (numéro de fax, nombre de pages, nom du destinataire, etc.). Leur usage reste facultatif : pour afficher la liste complète, cliquez sur <code className="action">Aide</code> à côté de **Ligne d'en-tête**. La section **Aide entête des fax** s'affiche.

<img className="thumbnail" alt="Ligne d'en-tête et section Aide entête des fax" src="/images/web-cloud/phone-and-fax/fax/configuration-fax-espace-client/console/entete_des_fax_emis.png" loading="lazy" />

Une personnalisation défectueuse de l'en-tête peut être à l'origine de difficultés d'envoi de télécopies.

Dans ce cas, vous pouvez rétablir l'en-tête par défaut en copiant la valeur ci-dessous :

```console
De #02#|#04#|Page #06# sur #08#
```

{/* CP-STEPS-END:en-tete-des-fax-emis */}

#### Options de notifications

{/* CP-STEPS-START:options-de-notifications */}

Personnalisez le nom et l'adresse e-mail de l'expéditeur des notifications que vous recevez. Cela permet d'éviter les filtres automatiques (type spam webmail) :

- pour le nom, cliquez sur <code className="action">Modifier</code> à côté de **Nom de l'expéditeur**, dans la section **Paramètres fax** ;
- pour l'adresse e-mail, cliquez sur <code className="action">Modifier</code> à côté de **Email de notification**, dans la section **Notifications fax**.

Vous pouvez également définir le format de l'e-mail reçu : sous **Format d'email**, choisissez « HTML (avec aperçu) » ou « Texte uniquement ».

<img className="thumbnail" alt="Nom de l'expéditeur, Email de notification et Format d'email" src="/images/web-cloud/phone-and-fax/fax/configuration-fax-espace-client/console/options_de_notifications.png" loading="lazy" />

{/* CP-STEPS-END:options-de-notifications */}

#### Adresses à notifier

{/* CP-STEPS-START:adresses-a-notifier */}

Configurez les adresses e-mail sur lesquelles vous recevrez les télécopies. Dans la section **Notifications fax**, sous **Adresses e-mail à notifier**, saisissez une adresse dans le champ **Ajouter un email** puis cliquez sur <code className="action">Ajouter</code>. Pour retirer une adresse, cliquez sur la croix qui la suit.

<img className="thumbnail" alt="Adresses e-mail à notifier dans la section Notifications fax" src="/images/web-cloud/phone-and-fax/fax/configuration-fax-espace-client/console/adresses_notifications.png" loading="lazy" />

{/* CP-STEPS-END:adresses-a-notifier */}

### Options de filtrage

Vous pouvez appliquer des règles de filtrage sur votre ligne Fax afin de ne pas recevoir de télécopies indésirables.

{/* CP-STEPS-START:options-de-filtrage */}

Pour configurer ces filtrages, sélectionnez votre ligne FAX, cliquez sur l'onglet <code className="action">Paramètres fax</code> puis rendez-vous dans la section **Filtrage fax**, en bas de la page.

<img className="thumbnail" alt="section Filtrage fax de l'onglet Paramètres fax" src="/images/web-cloud/phone-and-fax/fax/configuration-fax-espace-client/console/filtrage_menu.png" loading="lazy" />

Vous pouvez configurer et activer soit une liste blanche, soit une liste noire de numéros à filtrer. Vous pouvez également rejeter les télécopies anonymes en activant l'interrupteur **Rejeter les anonymes**.

Commencez par ajouter les numéros à filtrer : cliquez sur <code className="action">Ajouter</code>. Dans la fenêtre **Ajouter un filtre**, choisissez la **Liste** (« Liste noire » ou « Liste blanche ») et le **Type** (« Numéro » ou « Identifiant de fax (TSI) »), renseignez le **Numéro** puis cliquez sur <code className="action">Ajouter</code>.

<img className="thumbnail" alt="fenêtre Ajouter un filtre avec les champs Liste, Type et Numéro" src="/images/web-cloud/phone-and-fax/fax/configuration-fax-espace-client/console/regles_filtrage.png" loading="lazy" />

Activez ensuite la liste blanche ou noire : dans le menu déroulant **Mode de filtrage**, sélectionnez « Liste blanche » ou « Liste noire » puis cliquez sur <code className="action">Appliquer</code>. Pour désactiver le filtrage, sélectionnez « Aucun filtrage ».

{/* CP-STEPS-END:options-de-filtrage */}
