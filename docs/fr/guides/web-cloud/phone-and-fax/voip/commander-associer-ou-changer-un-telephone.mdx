## Objectif

Votre ligne SIP OVHcloud vous permet de recevoir et d’émettre des appels depuis l'appareil de votre choix. Celui-ci peut notamment être un téléphone OVHcloud que vous pouvez gérer depuis votre espace client.

**Découvrez comment gérer les téléphones associés à vos lignes SIP OVHcloud depuis votre espace client.**

## Prérequis

- Disposer d'une [ligne SIP OVHcloud](https://www.ovhcloud.com/fr/phone/voip/).

[[cpnav:telecom-voip-fax]]

## En pratique

:::info
Nos téléphones sont fournis en l'échange d'une caution (restituée en fin de contrat). Retrouvez l'ensemble des téléphones proposés par OVHcloud sur [cette page](https://www.ovhcloud.com/fr/phone/voip/telephone/).

:::


Votre ligne SIP peut être associée à un téléphone OVHcloud. Vous pouvez ainsi le gérer depuis votre espace client. Cette gestion s'effectue par le biais de plusieurs manipulations. Poursuivez la lecture de cette documentation selon celle que vous souhaitez réaliser.

- [Commander un téléphone OVHcloud](#obtenir-telephone) : vous permet de commander un nouveau téléphone OVHcloud sur une ligne existante dans votre compte.
- [Changer ou renvoyer le téléphone de votre ligne](#changer-telephone) : vous permet de changer le téléphone OVHcloud actuellement associé à votre ligne SIP ou de le renvoyer si vous n'en avez plus l'utilité.
- [Rattacher votre ligne à un téléphone](#rattacher-telephone) : vous permet de rattacher une ligne SIP à un téléphone OVHcloud que vous possédez déjà.
- [Détacher votre ligne d'un téléphone](#detacher-telephone) : vous permet de détacher de votre ligne SIP le téléphone OVHcloud actuellement associé à celle-ci.
- [Commander des accessoires](#accessoires) : vous permet de commander des accessoires (casques, câbles, combinés, etc.) pour vos téléphones OVHcloud.

### Commander un téléphone OVHcloud <a name="obtenir-telephone"></a>

Vous pouvez commander un téléphone OVHcloud pour une ligne SIP qui n'est pas déjà rattachée à un téléphone OVHcloud.

{/* CP-STEPS-START:commander-telephone */}

Cliquez sur l'onglet <code className="action">Services</code>, puis sur le bouton <code className="action">Gérer</code> de la ligne SIP concernée.

Positionnez-vous ensuite sur l'onglet <code className="action">Téléphone</code>. Si aucun téléphone n'est associé à la ligne, cliquez sur <code className="action">Commander un téléphone</code>.

<img className="thumbnail" alt="bouton Commander un téléphone dans l'onglet Téléphone d'une ligne SIP sans téléphone" src="/images/web-cloud/phone-and-fax/voip/commander-associer-ou-changer-un-telephone/console/orderphone.png" loading="lazy" />

Sur la page **Commander un téléphone**, à l'étape **Choix du téléphone**, sélectionnez le téléphone que vous souhaitez commander parmi les modèles proposés, puis suivez les étapes **Livraison** et **Confirmation**.

{/* CP-STEPS-END:commander-telephone */}

Si vous souhaitez rattacher votre ligne SIP à un équipement OVHcloud que vous possédez déjà et qui s'affiche dans l'espace client, suivez les instructions de la section « [Rattacher votre ligne à un téléphone](#rattacher-telephone) » de cette documentation.

### Changer ou renvoyer le téléphone de votre ligne <a name="changer-telephone"></a>

Lorsque vous possédez une ligne SIP OVHcloud actuellement rattachée à un téléphone OVHcloud, vous pouvez :

- changer votre téléphone actuel pour un autre modèle ;
- renvoyer le téléphone que vous possédez actuellement.

:::warning
Selon l'offre dont vous disposez sur votre ligne SIP, l'option de renvoi du téléphone peut ne pas être disponible.

:::


{/* CP-STEPS-START:changer-renvoyer-telephone */}

Cliquez sur l'onglet <code className="action">Services</code>, puis sur le bouton <code className="action">Gérer</code> de la ligne SIP concernée.

Positionnez-vous ensuite sur l'onglet <code className="action">Téléphone</code>. Dans la section **Informations du téléphone**, cliquez sur <code className="action">Changer ou renvoyer mon téléphone</code>, sous le modèle de votre téléphone.

<img className="thumbnail" alt="lien Changer ou renvoyer mon téléphone dans la section Informations du téléphone" src="/images/web-cloud/phone-and-fax/voip/commander-associer-ou-changer-un-telephone/console/change-phone.png" loading="lazy" />

Sur la page **Changer de téléphone**, à l'étape **Choix du téléphone**, sélectionnez l'action que vous souhaitez réaliser, cliquez sur <code className="action">Suivant</code>, puis suivez les étapes **Livraison** et **Confirmation**.

|Actions|Description|
|---|---|
|Renvoyer mon équipement actuel|Permet de renvoyer le téléphone actuellement rattaché à votre ligne SIP, si votre offre le permet. Votre ligne reste active et n'est pas résiliée. Vous disposez de 15 jours pour nous retourner l'ancien matériel, et la caution vous est restituée sous 10 jours après sa réception.|
|Caution pour téléphone (modèle)|Permet de changer le téléphone actuellement rattaché à votre ligne SIP pour un autre équipement. Une option est proposée pour chaque modèle disponible.|

{/* CP-STEPS-END:changer-renvoyer-telephone */}

:::info
Retrouvez plus d'informations sur le déroulement d'un renvoi ou d'un échange d'un téléphone sur notre guide « [Déroulement d'un RMA](/guides/web-cloud/phone-and-fax/voip/deroulement-d-un-rma) ».

:::


### Rattacher votre ligne à un téléphone <a name="rattacher-telephone"></a>

{/* CP-STEPS-START:rattacher-ligne-telephone */}

:::info
Pour cette démarche, vous aurez besoin de récupérer l'adresse IP publique du téléphone. Dans la console OVHcloud, sélectionnez la ligne principale qui lui est associée, puis cliquez sur l'onglet <code className="action">Paramètres de ligne</code>. Vous trouverez l'adresse IP publique actuelle du téléphone dans la section **Informations SIP**, sous **Dernier enregistrement**, à la ligne **IP**. Attention, ne prenez pas note du port situé après les `:`. Le téléphone doit s'être enregistré récemment sur la ligne pour que son adresse IP publique soit connue.

<img className="thumbnail" alt="adresse IP du dernier enregistrement dans la section Informations SIP d'une ligne" src="/images/web-cloud/phone-and-fax/voip/commander-associer-ou-changer-un-telephone/console/public-ip.png" loading="lazy" />

:::

Certains téléphones OVHcloud peuvent être associés à plusieurs lignes SIP. Vous pouvez donc rattacher une ligne SIP OVHcloud à un téléphone que vous possédez déjà, seulement si :

- la ligne SIP sélectionnée n'est actuellement rattachée à aucun téléphone OVHcloud ;
- le téléphone OVHcloud sélectionné peut accueillir une ligne configurée supplémentaire.

Si tel est le cas, pour réaliser la manipulation, suivez les étapes ci-dessous :

Cliquez sur l'onglet <code className="action">Services</code>, puis sur le bouton <code className="action">Gérer</code> de la ligne SIP concernée (n'étant actuellement rattachée à aucun téléphone).

Positionnez-vous ensuite sur l'onglet <code className="action">Téléphone</code> et cliquez sur <code className="action">Rattacher la ligne à un équipement actuel</code>.

<img className="thumbnail" alt="bouton Rattacher la ligne à un équipement actuel dans l'onglet Téléphone" src="/images/web-cloud/phone-and-fax/voip/commander-associer-ou-changer-un-telephone/console/plug-and-phone-step1.png" loading="lazy" />

Dans le panneau **Rattacher la ligne à un équipement actuel**, sélectionnez, parmi les téléphones de votre groupe de téléphonie, celui sur lequel vous souhaitez rattacher votre ligne SIP. Choisissez ensuite l'emplacement du téléphone à utiliser dans le menu déroulant **Position (slot)**, indiquez l'adresse IP publique du téléphone dans le champ **Adresse IP publique**, puis cliquez sur le bouton <code className="action">Rattacher</code>.

{/* CP-STEPS-END:rattacher-ligne-telephone */}

Si vous préférez commander un nouveau téléphone OVHcloud, suivez les instructions de la section « [Commander un téléphone OVHcloud](#obtenir-telephone) » de ce guide.

### Détacher votre ligne d'un téléphone <a name="detacher-telephone"></a>

{/* CP-STEPS-START:detacher-ligne-telephone */}

:::info
Pour cette démarche, vous aurez besoin de récupérer l'adresse IP publique du téléphone. Dans la console OVHcloud, sélectionnez la ligne principale qui lui est associée, puis cliquez sur l'onglet <code className="action">Paramètres de ligne</code>. Vous trouverez l'adresse IP publique actuelle du téléphone dans la section **Informations SIP**, sous **Dernier enregistrement**, à la ligne **IP**. Attention, ne prenez pas note du port situé après les `:`. Le téléphone doit s'être enregistré récemment sur la ligne pour que son adresse IP publique soit connue.

<img className="thumbnail" alt="adresse IP du dernier enregistrement dans la section Informations SIP d'une ligne" src="/images/web-cloud/phone-and-fax/voip/commander-associer-ou-changer-un-telephone/console/public-ip.png" loading="lazy" />

:::

Vous pouvez détacher une ligne SIP d'un téléphone OVHcloud disposant de plusieurs lignes SIP configurées. Pour cela, suivez les étapes ci-dessous :

Cliquez sur l'onglet <code className="action">Services</code>, puis sur le bouton <code className="action">Gérer</code> de la ligne SIP concernée.

Positionnez-vous ensuite sur l'onglet <code className="action">Téléphone</code>. Dans la section **Informations du téléphone**, cliquez sur le bouton <code className="action">⋮</code> en haut à droite, puis sur <code className="action">Détacher l'équipement</code>.

<img className="thumbnail" alt="menu du bouton ⋮ de la section Informations du téléphone avec l'entrée Détacher l'équipement" src="/images/web-cloud/phone-and-fax/voip/commander-associer-ou-changer-un-telephone/console/detach-phone01.png" loading="lazy" />

Dans la fenêtre **Détacher l'équipement**, renseignez l'adresse IP publique du téléphone dans le champ **Adresse IP publique**, puis cliquez sur <code className="action">Détacher</code>.

<img className="thumbnail" alt="fenêtre Détacher l'équipement avec le champ Adresse IP publique renseigné" src="/images/web-cloud/phone-and-fax/voip/commander-associer-ou-changer-un-telephone/console/detach-phone02.png" loading="lazy" />

{/* CP-STEPS-END:detacher-ligne-telephone */}

### Commander des accessoires <a name="accessoires"></a>

Vous pouvez commander des accessoires (casques, câbles, combinés, etc.) pour vos téléphones OVHcloud. Pour cela, suivez les étapes ci-dessous :

{/* CP-STEPS-START:commander-accessoires */}

Cliquez sur l'onglet <code className="action">Services</code>, puis sur le bouton <code className="action">Gérer</code> de la ligne SIP concernée.

Positionnez-vous ensuite sur l'onglet <code className="action">Téléphone</code>. Dans la section **Informations du téléphone**, cliquez sur <code className="action">Commander des accessoires</code>.

<img className="thumbnail" alt="lien Commander des accessoires dans la section Informations du téléphone" src="/images/web-cloud/phone-and-fax/voip/commander-associer-ou-changer-un-telephone/console/accessoires01.png" loading="lazy" />

Sur la page **Commander des accessoires**, utilisez les onglets pour filtrer les accessoires par marque ou utilisez le filtre **Compatible avec mon téléphone**, à droite des onglets, pour vous assurer de la compatibilité des accessoires avec vos téléphones.

Sélectionnez l'accessoire de votre choix, puis suivez les étapes qui apparaissent.

{/* CP-STEPS-END:commander-accessoires */}
