## Objectif

Le Contact Center Solution (CCS) est la configuration la plus complète pour un numéro alias. Elle combine la [file d'appels](/guides/web-cloud/phone-and-fax/voip/les-files-d-appels) et le [serveur vocal interactif (SVI)](/guides/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif).

Vous pouvez par exemple proposer à vos appelants, via la seule composition de votre numéro principal, un choix de touches pour joindre chaque service de votre entreprise, chaque touche composée faisant sonner un ensemble de lignes selon une stratégie que vous définissez depuis l'espace client OVHcloud.

**Apprenez à configurer un CCS sur votre numéro alias depuis votre espace client OVHcloud.**

## Prérequis

- Disposer d'un [numéro alias](https://www.ovhcloud.com/fr/phone/numeros/).

## Lexique

|Nom|Définition|
|---|---|
|Agent|Un agent est une ligne téléphonique, interne au compte OVHcloud ou externe à celui-ci, en capacité de sonner lorsque le numéro alias sera appelé.|
|File|Une file est un groupe d'agents, sur le principe de la [file d'appels](/guides/web-cloud/phone-and-fax/voip/les-files-d-appels). La file permet de faire sonner ces agents selon une stratégie à définir.|
|Menu interactif|Un menu interactif propose à l'appelant des choix de touches pour faire sonner un agent/une file ou jouer un son, sur le principe du [serveur vocal interactif (SVI)](/guides/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif).|
|TTS|Un Text-To-Speech (TTS) est un son créé à partir d'un texte que vous définissez dans l'espace client OVHcloud.|

## En pratique

### Étape 1 : Appliquer la configuration « Contact Center Solution » <a name="appliquer-CCS"></a>

{/* CP-STEPS-START:appliquer-configuration-ccs */}

Sur la page de votre numéro, rendez-vous dans la section **Configuration** de l'onglet <code className="action">Vue d'ensemble</code>.

- Si votre numéro n'est actuellement pas configuré, cliquez sur <code className="action">Choisir une configuration</code>.

- Si votre numéro a déjà une configuration en place, cliquez sur <code className="action">Changer la configuration</code>.

Dans le panneau **Changer la configuration**, sélectionnez **Contact Center Solution**. Cliquez ensuite sur <code className="action">Paramétrer</code>.

:::warning
Le changement de configuration remplace la configuration actuellement en place, qui sera perdue.
:::

<img className="thumbnail" alt="panneau Changer la configuration avec le type Contact Center Solution" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/ccs-config-2026.png" loading="lazy" />

{/* CP-STEPS-END:appliquer-configuration-ccs */}

{/* CP-STEPS-START:appliquer-a-plusieurs-numeros */}

:::info
Pour appliquer le même type de configuration à plusieurs numéros, cochez la case **Appliquer à plusieurs numéros** dans le panneau **Changer la configuration**. Choisissez ensuite le **Groupe de facturation**, puis sélectionnez les numéros concernés dans la liste **Appliquer à plusieurs numéros**.

<img className="thumbnail" alt="case Appliquer à plusieurs numéros cochée avec le groupe de facturation et les numéros sélectionnés" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/selection-alias-conf.png" loading="lazy" />

Cliquez sur le bouton <code className="action">Paramétrer</code> et patientez quelques instants pendant l'application du paramétrage.

Si vous appliquez le même type de configuration à plusieurs numéros, vous devrez finaliser la configuration sur chacun des numéros concernés.

:::

{/* CP-STEPS-END:appliquer-a-plusieurs-numeros */}

### Étape 3 : Gérer les sons / gérer les TTS <a name="gerer-sons-tts"></a>

L'accueil téléphonique de vos appelants peut être amélioré grâce à l'ajout d'un ou plusieurs fichiers-sons, préalablement créés par vos soins ou définis via des Text-To-Speech (TTS) depuis l'espace client.

Il peut être intéressant de créer ou téléverser ces fichiers-sons dès le début de votre configuration.

#### Gérer les sons <a name="gerer-sons"></a>

Si vous disposez déjà de vos fichiers-sons, enregistrez-les dans votre configuration. Vous pouvez ainsi ajouter un son d'accueil d'un menu interactif ou encore une musique d'attente pour faire patienter vos appelants lorsque vos lignes sont occupées.

{/* CP-STEPS-START:gerer-sons */}

Au-dessus du plan de configuration, cliquez sur <code className="action">Gérer les sons</code>.

Dans le panneau **Sons**, cliquez sur <code className="action">Ajouter un son</code> pour téléverser un son depuis votre poste. Dans le panneau **Envoyer un son**, déposez votre fichier dans la zone prévue à cet effet ou cliquez sur celle-ci pour le sélectionner, puis cliquez sur <code className="action">Envoyer</code>. Le fichier ne doit pas dépasser 10 Mo et doit être au format wav, mp3, ogg ou wma.

<img className="thumbnail" alt="panneau Envoyer un son avec la zone de dépôt du fichier" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-sons2021.png" loading="lazy" />

{/* CP-STEPS-END:gerer-sons */}

#### Gérer les TTS <a name="gerer-tts"></a>

Si vous ne disposez pas de fichiers-sons, la fonctionnalité Text-To-Speech permet d'en créer directement depuis l'espace client OVHcloud. Il vous suffit de renseigner le texte qui sera automatiquement énoncé par la voix de votre choix.

{/* CP-STEPS-START:gerer-tts */}

Au-dessus du plan de configuration, cliquez sur <code className="action">Gérer la synthèse vocale</code>.

{/* SHOT-PENDING:web-cloud/phone-and-fax/voip/contact-center-solution.fr/gerer-tts/gerer-tts2021 <img className="thumbnail" alt="panneau Synthèse vocale listant les messages de synthèse vocale" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-tts2021.png" loading="lazy" /> */}

Dans le panneau **Synthèse vocale**, cliquez alors sur <code className="action">Ajouter une synthèse</code>, choisissez une voix dans la liste **Voix** parmi celles proposées puis renseignez dans le champ **Texte** le texte qui sera récité. Cliquez enfin sur <code className="action">Ajouter</code>.

<img className="thumbnail" alt="panneau Ajouter une synthèse vocale avec les champs Voix et Texte" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-tts2021b.png" loading="lazy" />

{/* CP-STEPS-END:gerer-tts */}

### Étape 4 : Créer les files <a name="creer-files"></a>

Les files d'appels regroupent plusieurs agents (des lignes téléphoniques internes ou externes) qui vont sonner selon une stratégie que vous définissez dans l'espace client.

Leur fonctionnement est identique à la configuration [File d'appels](/guides/web-cloud/phone-and-fax/voip/les-files-d-appels) applicable directement sur un numéro alias.

#### 4.1 Ajouter les agents <a name="ajouter-agents"></a>

Pour créer vos files d'appels, vous devez d'abord ajouter toutes les lignes qui pourront être contactées lorsque votre numéro alias sera appelé. Ces lignes sont ici désignées comme des **agents**.

{/* CP-STEPS-START:ajouter-agents */}

Au-dessus du plan de configuration, cliquez sur <code className="action">Gérer les agents</code>.

<img className="thumbnail" alt="panneau Agents avec le bouton Ajouter un agent" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-agents2021.png" loading="lazy" />

Vous pouvez ajouter deux types d'agents, des lignes SIP internes (appartenant à votre compte OVHcloud) et des lignes externes (fixes ou mobiles). Le numéro d'un agent doit appartenir au même pays que le numéro configuré en Contact Center Solution.

Dans le panneau **Agents**, cliquez sur <code className="action">Ajouter un agent</code>, puis procédez selon le type de ligne :

|Type de ligne|Méthode d'ajout|
|-----|---|
|**Ligne SIP interne**<br/><br/><img className="thumbnail" alt="liste des services du compte ouverte depuis la loupe du champ Numéro de téléphone" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/agent-interne2021.png" loading="lazy" />|Pour ajouter une ligne SIP interne, cliquez sur l'icône en forme de loupe à droite du champ **Numéro de téléphone**.<br/><br/>Dans la liste qui s'affiche, choisissez **Ce groupe** ou **Tous les groupes**, puis cliquez sur une ligne : son numéro est alors renseigné dans le champ **Numéro de téléphone**.<br/><br/>Confirmez en cliquant sur <code className="action">Ajouter</code>.<br/><br/>Les lignes doivent être ajoutées l'une après l'autre.|
|**Ligne externe**<br/><br/><img className="thumbnail" alt="formulaire d'ajout d'un agent avec un numéro externe renseigné" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/agent-externe2021.png" loading="lazy" />|Pour ajouter une ligne téléphonique externe, renseignez son numéro au format international (0033xxxxxxxxx pour la France) directement dans le champ **Numéro de téléphone**.<br/><br/>Validez l'ajout de chaque ligne en cliquant sur <code className="action">Ajouter</code>.|

{/* CP-STEPS-END:ajouter-agents */}
:::warning
L'ajout d'une ligne externe peut occasionner des frais car un appel reçu par celle-ci sera comptabilisé en hors-forfait. Vous pouvez consulter nos tarifs hors-forfait en vigueur sur [cette page](https://www.ovhtelecom.fr/telephonie/decouvrez/tarifs_telephonie.xml). Nous vous conseillons donc de privilégier les lignes internes ou de n'utiliser une ligne externe qu'en solution de repli.

:::

{/* CP-STEPS-START:modifier-attributs-agents */}

Les agents et leurs attributs sont visibles dans le panneau **Agents**. Vous pouvez modifier ces attributs en cliquant sur le bouton <code className="action">⋮</code> à droite de chaque agent, puis sur <code className="action">Modifier</code>. Effectuez vos changements dans le formulaire **Modifier l'agent**, puis cliquez sur <code className="action">Enregistrer</code>.

<img className="thumbnail" alt="panneau Agents avec le menu du bouton ⋮ d'un agent" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/ccs-step3-1-3.png" loading="lazy" />

Les attributs que vous pouvez modifier sont les suivants :

|Nom|Définition|
|---|---|
|Description|Permet de renommer l'agent.|
|Statut|Permet de rendre disponible ou déconnecter un agent au sein des files.|
|Durée de sonnerie|Permet de définir la durée (en secondes) pendant laquelle la ligne sonnera. Une fois ce temps écoulé, et selon la stratégie d'appels de la file, l'appel sera alors transmis vers un autre agent de cette file.|
|Temps de repos|Permet de définir la durée (en secondes) pendant laquelle l'agent ne prendra pas d'appel après avoir raccroché.|
|Appels simultanés|Permet de définir le nombre d'appels que la ligne pourra recevoir.|

{/* CP-STEPS-END:modifier-attributs-agents */}
#### 4.2 Créer les files d'appels <a name="creer-files"></a>

Vos agents sélectionnés, vous devez les organiser dans une ou plusieurs files d'appels.

{/* CP-STEPS-START:creer-files-ajouter-membres */}

Au-dessus du plan de configuration, cliquez sur <code className="action">Gérer les files d'attente</code>. Vous pouvez ici créer une ou plusieurs files d'appels à l'aide du bouton <code className="action">Ajouter une file</code>. La première file est déjà créée.

<img className="thumbnail" alt="panneau Files d'attente listant les files d'appels" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-files2021.png" loading="lazy" />

Pour ajouter des agents à une file, cliquez sur le bouton <code className="action">⋮</code> à droite de la file, puis sur <code className="action">Voir les détails</code>. Dans la section **Agents de la file**, cliquez sur <code className="action">Ajouter un agent à la file</code>, puis choisissez dans la liste **Sélectionner un agent** l'un des agents que vous avez préalablement créés. Cliquez sur <code className="action">Ajouter</code> et réitérez cette action pour chaque agent à ajouter.

{/* CP-STEPS-END:creer-files-ajouter-membres */}

{/* CP-STEPS-START:options-file */}

Sur la page de la file, vous pouvez également modifier les options de cette file : dans la section **Options**, cliquez sur <code className="action">Gérer les options</code>.

<img className="thumbnail" alt="section Options d'une file d'appels en cours de modification" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-files2021b.png" loading="lazy" />

Les options sont les suivantes :

|Option|Définition|
|---|---|
|Description|Cela vous permet de personnaliser le nom de votre file, affiché comme titre de la file. C'est recommandé si vous comptez créer plusieurs files, afin de bien les différencier dans la construction de votre CCS.|
|Stratégie|Choisissez une stratégie de sonnerie pour vos agents qui pourront, par exemple, sonner tous en même temps ou l'un après l'autre.|
|Suivre les renvois d'appels|Définissez si les renvois d'appels configurés sur les lignes de la file doivent être appliqués ou non.<br/><br/>**Attention**, cette option, même si elle n'est activée que sur une file, s'appliquera à l'ensemble des files d'appels configurées.|
|Nombre maximum d'appelants en attente|Définissez le nombre maximum d'appelants pouvant être en attente dans la file. Si ce nombre venait à être dépassé, les appelants suivants seraient pris en charge selon l'option **Annonce sur débordement**.|
|Temps d'attente maximum dans la file (en secondes)|Définissez la durée maximale d'attente dans cette file avant que l'appel ne passe à l'étape suivante de votre CCS.|
|Musique d'attente|Choisissez ce son parmi ceux que vous avez ajoutés. Il sera joué à l'entrée dans la file d'attente jusqu'au décrochage de l'appel par une ligne.|
|Annonce sur débordement|Si le nombre maximum d'appelants en attente est atteint, les appelants suivants sont dirigés vers l'option choisie : **Messagerie vocale** ou **Lecture d'un message**. Avec la lecture d'un message, vous pouvez diffuser un son invitant vos appelants à rappeler ultérieurement.|

**Détails des stratégies proposées :**

|Stratégie|Détails|
|---|---|
|Séquentiel par ordre d'agent|Le premier téléphone de la file sonne, puis le second, etc.|
|Sonnerie simultanée|Tous les téléphones sonnent en même temps. Le premier qui décroche prend l'appel sur son poste.|
|Aléatoire|Les téléphones sonnent les uns après les autres de manière aléatoire.|
|Agent en attente le plus long|Les téléphones sonnent les uns après les autres en suivant toujours le même ordre.|
|Agent inactif le plus long|Les téléphones sonneront suivant leur disponibilité depuis l'activation.|
|Tourniquet|Les téléphones sonneront suivant leur disponibilité depuis le dernier appel : le plus disponible en premier.|
|Cumul par ordre d'agent|Le premier téléphone de la file d'attente sonne. Le deuxième sonne à son tour après quelques secondes, en même temps que le premier. Le troisième commence à sonner quelques secondes après, etc.|

Validez vos modifications en cliquant sur <code className="action">Enregistrer</code>.

{/* CP-STEPS-END:options-file */}

Dans le cas d'une stratégie d'appel **Séquentiel par ordre d'agent**, l'agent le plus haut dans la liste **Agents de la file** sonnera le premier. Puis le deuxième agent sonnera et ainsi de suite.

Vous pouvez également modifier les attributs d'un agent ou supprimer celui-ci : cliquez sur le bouton <code className="action">⋮</code> à droite de l'agent, puis sur <code className="action">Modifier</code> ou <code className="action">Supprimer</code>.

<img className="thumbnail" alt="section Agents de la file avec le menu du bouton ⋮ d'un agent" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-agents-ordre-2021.png" loading="lazy" />

:::warning
Pour supprimer une file, celle-ci ne doit plus faire partie d'aucun menu interactif ou d'aucune étape du plan de configuration.

### Étape 5 : Créer les menus interactifs (facultatif) <a name="creer-svi"></a>

À la différence de la configuration d'un numéro alias en [Serveur Vocal Interactif (SVI)](/guides/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif), le CCS permet d'associer une file d'appels entière (et non plus une simple ligne) à une touche de téléphone composée par un appelant.

Pour plus d'informations sur le fonctionnement d'un SVI, consultez notre guide [Configurer un serveur vocal interactif](/guides/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif).

#### 5.1 Créer le premier menu <a name="creer-menu-svi"></a>

{/* CP-STEPS-START:creer-menu-interactif */}

Au-dessus du plan de configuration, cliquez sur <code className="action">Gérer les menus interactifs</code>.

<img className="thumbnail" alt="panneau Menus interactifs avec le bouton Ajouter un menu" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-svi2021.png" loading="lazy" />

Cliquez sur <code className="action">Ajouter un menu</code>. Nommez ce nouveau menu dans le champ **Nom**, puis choisissez l'accueil de votre menu interactif : un son dans la liste **Son d'accueil** ou un TTS dans la liste **TTS d'accueil**. Ces listes proposent les sons et les TTS déjà ajoutés : si besoin, créez-les au préalable à l'aide des boutons <code className="action">Gérer les sons</code> et <code className="action">Gérer la synthèse vocale</code>. **Ce son devra énoncer les différents choix de touches proposés à vos appelants (exemple : « Tapez 1 pour joindre l'accueil, tapez 2 pour joindre l'atelier... »)**.

Les mêmes choix vous sont proposés, dans les listes **Son d'erreur** et **TTS d'erreur**, pour définir un son ou un TTS en cas d'action invalide. Celui-ci sera joué si l'appelant appuie sur une touche non reconnue par le serveur vocal interactif.

<img className="thumbnail" alt="formulaire d'ajout d'un menu interactif" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-svi2021b.png" loading="lazy" />

Une fois ces informations définies, cliquez sur <code className="action">Ajouter</code>. Vous pouvez maintenant créer les entrées du menu interactif, c'est-à-dire les choix de touches proposés à vos appelants et les actions qui y sont liées.

Cliquez sur le bouton <code className="action">⋮</code> à droite du menu, puis sur <code className="action">Voir les entrées</code>. Cliquez ensuite sur <code className="action">Ajouter une entrée</code> pour ajouter votre première entrée.

<img className="thumbnail" alt="détail d'un menu interactif avec le bouton Ajouter une entrée" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/ccs-step4-1-3.png" loading="lazy" />

Dans le formulaire qui s'affiche, complétez les informations demandées.

<img className="thumbnail" alt="formulaire d'ajout d'une entrée de menu interactif" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-svi2021c.png" loading="lazy" />

|Information|Description|
|---|---|
|Touche DTMF|Choisissez une touche parmi celles proposées sur le clavier (1 à 9, *, 0 et #). L'option **DTMF personnalisé (multi-touches)** permet de définir une combinaison de plusieurs touches.|
|Action|Définissez l'action à déclencher lorsque l'appelant appuiera sur la touche correspondante : **Pont (appel direct)**, **File d'attente**, **Sous-menu**, **Menu précédent**, **Quitter le menu**, **Menu principal**, **Lecture audio**, **Lire DTMF** ou **Définir nom appelant**.|
|Paramètre d'action supplémentaire|Selon l'action que vous avez définie, renseignez le paramètre complémentaire demandé, par exemple un numéro de téléphone pour l'action **Pont (appel direct)** ou une file pour l'action **File d'attente**.|

Une fois les informations complétées, cliquez sur <code className="action">Ajouter</code>. Répétez l'opération pour les entrées de menu supplémentaires.

<img className="thumbnail" alt="détail du menu interactif avec ses entrées" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-svi2021d.png" loading="lazy" />

Selon vos besoins, répétez ces manipulations si vous voulez créer plusieurs menus interactifs. Vous pouvez également les imbriquer en tant que sous-menus d'un menu interactif principal (action **Sous-menu**), si vous souhaitez par exemple proposer plusieurs choix successifs à vos appelants.

{/* CP-STEPS-END:creer-menu-interactif */}

### Étape 6 : Configurer votre CCS <a name="configurer-CCS"></a>

Une fois vos files et menus interactifs créés, il faut maintenant les articuler dans le CCS.

Chaque appel entrant va suivre une ou plusieurs étapes successives que vous allez définir. Au sein de chaque étape, une ou plusieurs actions devront également être créées.

Voici un exemple de configuration d'un CCS :

- Une étape 1, conditionnée à des créneaux horaires de fermeture, dans laquelle une seule action consistera à jouer un son invitant l'appelant à rappeler votre numéro pendant les horaires d'ouverture.
- Une étape 2 dans laquelle une seule action fera sonner une première file d'appels.
- Une étape 3 dans laquelle une première action fera sonner une deuxième file d'appels, différente de la première. Puis, une seconde action qui renverra l'appel vers un répondeur au bout de la durée maximum d'attente de cette deuxième file d'appels.

#### Ajouter des étapes et actions

{/* CP-STEPS-START:ajouter-etapes-actions */}

Pour ajouter une étape, cliquez sur le bouton <code className="action">Ajouter une étape</code> situé à la suite des étapes déjà créées. L'étape est créée immédiatement.

Pour ajouter une action au sein d'une étape, sélectionnez l'étape concernée, puis cliquez sur l'icône <code className="action">+</code> de sa barre d'outils. Dans la fenêtre **Ajouter une action**, choisissez l'action dans la liste **Action** et renseignez si besoin le paramètre demandé. Cliquez enfin sur <code className="action">Ajouter</code>.

<img className="thumbnail" alt="plan de configuration avec le bouton Ajouter une étape et la barre d'outils d'une étape" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-etapes-actions2021.png" loading="lazy" />

{/* CP-STEPS-END:ajouter-etapes-actions */}

{/* CP-STEPS-START:afficher-masquer-actions */}

{/* CP-STEPS-END:afficher-masquer-actions */}

#### Réordonner les étapes et actions

{/* CP-STEPS-START:reordonner-etapes-actions */}

Pour réordonner les étapes et actions de votre plan de configuration, sélectionnez l'étape ou l'action à déplacer. Dans sa barre d'outils, cliquez sur l'icône <code className="action">↑</code> (**Déplacer avant**) ou <code className="action">↓</code> (**Déplacer après**). Chaque déplacement est enregistré immédiatement.

<img className="thumbnail" alt="barre d'outils d'une étape sélectionnée avec les icônes Déplacer avant et Déplacer après" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-etapes-actions2021b.png" loading="lazy" />

{/* CP-STEPS-END:reordonner-etapes-actions */}

#### Ajouter une condition à une étape <a name="ajouter-condition"></a>

Lorsqu'une ou plusieurs conditions sont ajoutées à une étape, celles-ci doivent être remplies pour que l'étape se déclenche. Si les conditions d'une étape ne sont pas remplies, l'appel entrant passera à l'étape suivante du CCS.

{/* CP-STEPS-START:ajouter-condition-etape */}

Pour ajouter une condition à une étape, sélectionnez l'étape, puis cliquez sur l'icône en forme d'engrenage (**Configurer**) de sa barre d'outils. Dans la fenêtre **Configuration avancée**, vous pouvez définir jusqu'à trois types de conditions. Poursuivez selon la condition que vous désirez paramétrer :

- [Condition de « Jours exceptionnels »](#condition-de-jours-exceptionnels)
- [Condition de « Plages horaires génériques »](#condition-de-plages-horaires-generiques)
- [Condition de « Filtrages d'appels »](#condition-de-filtrages-dappels)

<img className="thumbnail" alt="fenêtre Configuration avancée avec les trois types de conditions" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-conditions2021.png" loading="lazy" />

{/* CP-STEPS-END:ajouter-condition-etape */}

{/* CP-STEPS-START:actions-conditions-non-verifiees */}

Une fois vos conditions créées, vous pouvez définir une ou plusieurs action(s) correspondant aux conditions non vérifiées. Ces actions seront alors prises en compte pour les appels ne remplissant pas les conditions. Pour cela, ajoutez une action à l'étape comme indiqué plus haut et cochez la case **Action de repli** dans la fenêtre **Ajouter une action**.

Ainsi, dans l'exemple ci-dessous, un appel pendant les plages horaires définies à l'étape 1 fera sonner les membres de la file d'appels nommée « Service commercial ».

Un appel en dehors de ces plages horaires sera réceptionné sur le répondeur d'une ligne SIP OVHcloud.

<img className="thumbnail" alt="étape 1 reliée à la file Service commercial et à une action de repli" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/exemples-plages2021.png" loading="lazy" />

{/* CP-STEPS-END:actions-conditions-non-verifiees */}

##### **Condition de « Jours exceptionnels »** <a name="jours-exceptionnels"></a>

{/* CP-STEPS-START:condition-jours-exceptionnels */}

Après avoir cliqué sur <code className="action">Jours exceptionnels</code> dans la fenêtre **Configuration avancée**, choisissez le créneau que vous souhaitez appliquer : **Horaires de fermeture**, **Créneau 1**, **Créneau 2** ou **Créneau 3**. Cliquez ensuite sur <code className="action">Enregistrer</code>.

<img className="thumbnail" alt="page Jours exceptionnels de la fenêtre Configuration avancée avec le choix du créneau" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/creneaux-activation2021.png" loading="lazy" />

Configurez le créneau que vous venez de sélectionner (ou assurez-vous que celui-ci l'est correctement). Pour cela, cliquez sur <code className="action">Gérer les créneaux exceptionnels</code> au-dessus du plan de configuration.

<img className="thumbnail" alt="bouton Gérer les créneaux exceptionnels au-dessus du plan de configuration" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/gerer-creneaux2021.png" loading="lazy" />

La page **Créneaux exceptionnels** apparaît alors. Positionnez vos fermetures exceptionnelles sur le calendrier en cliquant sur les jours concernés, ou cliquez sur <code className="action">Ajouter un créneau</code>. Dans la fenêtre **Ajouter un créneau**, complétez les informations demandées :

|Information|Description|
|---|---|
|Titre|Définissez un titre vous permettant d'identifier cette fermeture exceptionnelle dans le calendrier.|
|Date de début / Date de fin|Définissez la date et l'heure de début et de fin de la fermeture exceptionnelle.|
|Catégorie|Choisissez le créneau dans lequel vous souhaitez ajouter la fermeture exceptionnelle.|

Vérifiez les dates indiquées, puis cliquez sur <code className="action">Enregistrer</code>. Chaque fermeture exceptionnelle est enregistrée immédiatement. Répétez cette manipulation afin d'ajouter toutes les fermetures exceptionnelles nécessaires.

<img className="thumbnail" alt="fenêtre Ajouter un créneau sur la page Créneaux exceptionnels" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/creneaux2021.png" loading="lazy" />

{/* CP-STEPS-END:condition-jours-exceptionnels */}

##### **Condition de « Plages horaires génériques »** <a name="plages-horaires"></a>

{/* CP-STEPS-START:condition-plages-horaires */}

Après avoir cliqué sur <code className="action">Plages horaires génériques</code> dans la fenêtre **Configuration avancée**, cliquez sur <code className="action">Ajouter des plages horaires</code>.

Configurez maintenant les plages horaires qui correspondent à vos besoins. Pour cela, sélectionnez les jours concernés puis renseignez les horaires dans les champs **De** et **À**. Cliquez sur l'icône <code className="action">✓</code> à droite pour enregistrer la plage.

Une fois toutes vos plages horaires définies, cliquez sur le bouton <code className="action">Enregistrer</code> pour les valider.

<img className="thumbnail" alt="page Plages horaires génériques avec une plage horaire enregistrée" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/plageshoraires2021.png" loading="lazy" />

:::info
Pour modifier une plage horaire déjà créée, il est nécessaire de la supprimer puis de créer une nouvelle plage horaire.

:::

{/* CP-STEPS-END:condition-plages-horaires */}

##### **Double condition : « Jours exceptionnels » et « Plages horaires génériques »**

{/* CP-STEPS-START:double-condition */}

Pour obtenir une configuration contenant à la fois des jours exceptionnels et des plages horaires génériques, il convient de placer les jours exceptionnels sur l'étape 1 et les plages horaires génériques sur l'étape 2.

En effet, le système lit les étapes dans l'ordre : si les conditions de l'étape 1 sont remplies, les actions associées à cette étape sont exécutées. Dans le cas contraire, le système passe automatiquement à l'étape 2.

<img className="thumbnail" alt="plan de configuration avec deux étapes successives" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/ccs-double-condition.png" loading="lazy" />

{/* CP-STEPS-END:double-condition */}

##### **Condition de « Filtrages d'appels »** <a name="filtrages-appels"></a>

{/* CP-STEPS-START:condition-filtrages-appels */}

Après avoir cliqué sur <code className="action">Filtrages d'appels</code> dans la fenêtre **Configuration avancée**, choisissez dans la liste **Type de liste** si vous souhaitez filtrer vos appels entrants selon une **Liste noire** ou une **Liste blanche**.

|Liste|Description|
|---|---|
|Liste noire|Les numéros ou les tranches de numéros inscrits dans la liste ne peuvent plus vous contacter.|
|Liste blanche|**Seuls** les numéros ou les tranches de numéros inscrits dans la liste sont autorisés à vous contacter.|

Une fois que vous avez sélectionné la liste que vous souhaitez utiliser, complétez-la en ajoutant les numéros ou les tranches de numéros adéquats. Pour cela, utilisez le champ **Ajouter un numéro à la liste**, puis cliquez sur le bouton <code className="action">Ajouter</code>. Vous pouvez supprimer une entrée de la **Liste des numéros** grâce à l'icône représentant une corbeille.

Pour enregistrer vos modifications, cliquez sur <code className="action">Enregistrer</code>.

<img className="thumbnail" alt="page Filtrages d'appels de la fenêtre Configuration avancée" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/filtrages2021.png" loading="lazy" />

{/* CP-STEPS-END:condition-filtrages-appels */}

### Gérer les options du CCS <a name="options"></a>

{/* CP-STEPS-START:options-ccs */}

Des options supplémentaires sont disponibles en cliquant sur le bouton <code className="action">⋮</code> du cadre **Appels reçus**, dans le plan de configuration :

<img className="thumbnail" alt="cadre Appels reçus du plan de configuration avec son bouton ⋮" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/modifieroption.png" loading="lazy" />

La fenêtre **Options du CCS** vous permet de :

- modifier le nom du CCS (champ **Nom**) ;
- gérer le timeout de transfert d'appel vers une ligne externe (champ **Timeout de transfert d'appel (s)**, exprimé en secondes). Lorsque votre configuration comporte un transfert vers une ligne externe, si cette ligne ne décroche pas avant la durée définie dans ce champ, l'appel passera à l'étape suivante de la configuration ;
- gérer la présentation du numéro de vos appelants (liste **Numéro à présenter**) ;
- accepter ou refuser les appels masqués (anonymes), à l'aide de la case **Accepter les appels masqués**.

Validez vos changements en cliquant sur <code className="action">Enregistrer</code>.

<img className="thumbnail" alt="fenêtre Options du CCS avec les champs Nom, Timeout et Numéro à présenter" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/optionsccs.png" loading="lazy" />

Trois options de présentation du numéro, sur le téléphone qui reçoit l'appel, sont possibles :

- **Le numéro de l'appelant** : présenter le numéro de l'appelant ;
- **Le numéro de l'alias** : présenter le numéro du CCS, c'est-à-dire le numéro alias qui a été composé par l'appelant, ce qui peut être utile si vous possédez plusieurs numéros alias configurés ;
- **Les deux** : présenter les deux numéros, celui de l'appelant et celui du CCS.

<img className="thumbnail" alt="liste Numéro à présenter de la fenêtre Options du CCS" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/numeropres2.png" loading="lazy" />

### Consulter les enregistrements <a name="enregistrements"></a>

Le CCS vous permet d'enregistrer les appels entrants sur les files d'appels actives dans votre configuration.

:::info
L'activation de l'enregistrement des appels entraînera le déclenchement automatique d'un message d'avertissement, pré-configuré par OVHcloud, lorsque votre numéro sera appelé. Ce message ne peut être supprimé ou modifié tant que l'enregistrement des appels est activé.

:::

{/* CP-STEPS-START:activer-enregistrement-appels */}

Pour activer l'enregistrement des appels, cliquez sur l'onglet <code className="action">Enregistrements</code> de votre numéro.

<img className="thumbnail" alt="onglet Enregistrements avec le choix de la file d'appels et la section Activation de l'enregistrement" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/records2021.png" loading="lazy" />

Sélectionnez, dans le menu déroulant de gauche, la file d'appels sur laquelle les appels seront enregistrés puis, dans la section **Activation de l'enregistrement**, cochez la case **Enregistrement des appels**.

Vous pouvez laisser à vos appelants la possibilité de ne pas être enregistrés. Pour cela, cochez la case **Demande de non-enregistrement**. Dans la liste **Langue de l'annonce**, sélectionnez la langue (**Français** ou **Anglais**) dans laquelle le message sera diffusé puis, dans **Touche de refus**, choisissez une touche pour que les appelants puissent activer cette option de non-enregistrement d'appel.

Cliquez enfin sur <code className="action">Appliquer</code> pour enregistrer vos choix.

<img className="thumbnail" alt="section Activation de l'enregistrement avec la demande de non-enregistrement cochée" src="/images/web-cloud/phone-and-fax/voip/contact-center-solution/console/records2021b.png" loading="lazy" />
