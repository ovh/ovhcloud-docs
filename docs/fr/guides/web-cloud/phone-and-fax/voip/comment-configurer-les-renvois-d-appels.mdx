## Objectif

Votre ligne SIP OVHcloud vous permet de recevoir et d'émettre des appels. Pour diverses raisons, comme vos disponibilités, vous pouvez être amené à filtrer et/ou renvoyer les appels entrants et sortants. Ceci passe par la mise en place de trois solutions : le verrouillage des appels sortants, les renvois d'appel et le filtrage d'appels.

**Découvrez comment filtrer et renvoyer les appels entrants et sortants de votre ligne SIP OVHcloud.**

## Prérequis

- Disposer d'une [ligne SIP OVHcloud](https://www.ovhcloud.com/fr/phone/voip/).

## En pratique

Il existe trois solutions pour filtrer et renvoyer les appels entrants et sortants de votre ligne SIP :

|Solutions|Description|
|---|---|  
|Verrouillage des appels sortants|Restreint l'utilisation de votre ligne aux appels entrants uniquement ; ceci verrouille la possibilité de passer un appel sortant. L'utilisation d'un code vous permettra de passer outre ce blocage en cas de nécessité. Les appels d'urgence restent bien évidemment accessibles, même si le verrouillage est actif.|
|Renvoi d'appel|Met en place un renvoi d'appel, dont vous pourrez définir le déclenchement ainsi que la destination.|
|Filtrage d'appels|Définit des listes blanches ou noires, afin d'autoriser uniquement certains correspondants à vous joindre ou, au contraire, de rejeter automatiquement les appels en provenance de certains numéros.|

Poursuivez la lecture de cette documentation en fonction de la solution que vous souhaitez activer.

- [Activer le verrouillage des appels sortants](#verrouillage)
- [Activer le renvoi d'appel](#renvoi)
- [Activer le filtrage d'appels](#filtrage)

### Activer le verrouillage des appels sortants <a name="verrouillage"></a>

{/* CP-STEPS-START:activer-verrouillage */}

Ouvrez l'onglet <code className="action">Paramètres de ligne</code> de votre ligne. Dans la section **Paramètres d'appel**, sous **Verrouillage des appels sortants**, cliquez sur <code className="action">Activer le verrouillage</code>.

<img className="thumbnail" alt="Verrouillage des appels sortants dans la section Paramètres d'appel de la ligne" src="/images/web-cloud/phone-and-fax/voip/comment-configurer-les-renvois-d-appels/console/manage-calls-locking-step1.png" loading="lazy" />

Dans la fenêtre **Activer le verrouillage des appels sortants**, renseignez un code à 4 chiffres dans le champ **Code de verrouillage**. Celui-ci vous permettra d'émettre tout de même des appels sortants depuis la ligne que vous verrouillez. Cliquez enfin sur le bouton <code className="action">Activer</code> pour appliquer la nouvelle configuration.

<img className="thumbnail" alt="Fenêtre Activer le verrouillage des appels sortants avec le champ Code de verrouillage" src="/images/web-cloud/phone-and-fax/voip/comment-configurer-les-renvois-d-appels/console/manage-calls-locking-step2.png" loading="lazy" />

Vous pouvez appliquer ce verrouillage à plusieurs lignes. Pour cela, ouvrez l'onglet <code className="action">Vue d'ensemble</code> de la ligne puis, dans la section **Configuration en masse**, cliquez sur <code className="action">Copier vers d'autres services</code>. Dans le panneau **Appliquer la configuration à d'autres services**, sélectionnez **Verrouillage des appels sortants** parmi les paramètres de la rubrique **Paramètres de ligne**.

<img className="thumbnail" alt="Panneau Appliquer la configuration à d'autres services ouvert depuis la vue d'ensemble" src="/images/web-cloud/phone-and-fax/voip/comment-configurer-les-renvois-d-appels/console/bulk-config.png" loading="lazy" />

{/* CP-STEPS-END:activer-verrouillage */}

### Activer le renvoi d'appel <a name="renvoi"></a>

:::warning
Le renvoi d'appel est différent du transfert d'appel. Ce dernier consiste à transférer un appel en cours vers un autre destinataire. Pour connaître les méthodes de transfert d'appel, consultez la documentation constructeur de votre téléphone.

:::

:::info
Si vous souhaitez renvoyer les appels **en fonction de plages horaires**, consultez notre guide « [Configurer des plages horaires et des fermetures exceptionnelles sur une ligne](/guides/web-cloud/phone-and-fax/voip/configure-time-slot-and-closing-time)».

:::

{/* CP-STEPS-START:activer-renvoi */}

Ouvrez l'onglet <code className="action">Gestion des appels</code> de votre ligne. Les renvois sont regroupés dans la section **Renvoi des appels**.

<img className="thumbnail" alt="Section Renvoi des appels de l'onglet Gestion des appels d'une ligne" src="/images/web-cloud/phone-and-fax/voip/configurer-consulter-repondeur-ligne-ovh/console/calls-forwarding.png" loading="lazy" />

Cette section vous permet de mettre en place un renvoi d'appel selon quatre configurations :

|Configurations|Description|
|---|---|
|Renvoi inconditionnel|L'intégralité des appels est renvoyée de façon inconditionnelle.|
|Renvoi si non-réponse|Les appels sont renvoyés en cas de non-réponse sur le téléphone contacté. Vous devez définir le temps avant que l'appel ne soit renvoyé, dans le champ **Délai avant renvoi (secondes)**.|
|Renvoi si occupé|Les appels sont renvoyés si la ligne est occupée (c'est-à-dire lorsque tous vos appels simultanés sont en cours).|
|Renvoi de secours|Les appels sont renvoyés dans le cas où notre serveur de téléphonie ne détecte aucune connexion vers votre ligne (par exemple, lors d'une interruption de votre connexion Internet).|

Chaque configuration s'active ou se désactive à l'aide de son interrupteur. Si aucune destination n'est encore définie pour ce renvoi, l'activation ouvre sa fenêtre de configuration. Si une destination est déjà définie, le changement est appliqué immédiatement. Pour modifier la destination d'un renvoi, cliquez sur l'icône en forme de crayon à côté de celle-ci.

Dans la fenêtre de configuration (par exemple **Configurer le renvoi si non-réponse**), activez **Activer le renvoi**, sélectionnez où renvoyer l'appel dans le menu déroulant **Type de destination**, puis renseignez le numéro correspondant dans le champ **Numéro de destination**.

|Type de destination|Description|
|---|---|
|Numéro|Permet de renvoyer l'appel vers une autre ligne présente dans votre parc téléphonique ou vers un numéro hors OVHcloud. Sachez que les communications vers un numéro non enregistré chez OVHcloud seront décomptées de votre forfait ou facturées selon le [forfait auquel vous avez souscrit](https://www.ovhcloud.com/fr/phone/voip/) (voir la note en bas de page) et [les tarifs en vigueur](https://www.ovhtelecom.fr/telephonie/decouvrez/tarifs_telephonie.xml).|
|Fax|Il s'agit du service fax. Cette fonctionnalité est réservée aux offres Fax.|
|Messagerie vocale|Permet de renvoyer l'appel vers la boîte vocale d'une des lignes présentes dans votre parc téléphonique.|

Cliquez enfin sur le bouton <code className="action">Enregistrer</code> pour terminer l'opération.

<img className="thumbnail" alt="Fenêtre Configurer le renvoi si non-réponse et menu déroulant Type de destination" src="/images/web-cloud/phone-and-fax/voip/comment-configurer-les-renvois-d-appels/console/manage-calls-fowarding-step2.png" loading="lazy" />

Vous pouvez appliquer vos choix de configuration à plusieurs lignes. Pour cela, ouvrez l'onglet <code className="action">Vue d'ensemble</code> de la ligne puis, dans la section **Configuration en masse**, cliquez sur <code className="action">Copier vers d'autres services</code>. Dans le panneau **Appliquer la configuration à d'autres services**, sélectionnez **Renvoi des appels** parmi les paramètres de la rubrique **Gestion des appels**.

{/* CP-STEPS-END:activer-renvoi */}

:::info
**Présentation du numéro**

Si vous renvoyez les appels de votre ligne OVHcloud vers un numéro externe (hors OVHcloud), la présentation du numéro sur le téléphone externe dépendra des paramètres de son opérateur de téléphonie.

**Exemple :**

- Vous avez configuré, sur votre ligne OVHcloud **A**, un renvoi de tous les appels vers un numéro de mobile **B**
- Un interlocuteur (**C**) vous appelle sur la ligne OVHcloud **A**.
- Vous recevez l'appel (via le renvoi d'appels) sur le mobile **B**. Peuvent alors être présentés à l'écran, suivant votre opérateur de téléphonie mobile, le numéro de l'appelant (**C**) et/ou le numéro de la ligne appelée (**B**).

:::

### Activer le filtrage d'appels <a name="filtrage"></a>

{/* CP-STEPS-START:activer-filtrage */}

Ouvrez l'onglet <code className="action">Gestion des appels</code> de votre ligne. Le filtrage des appels y est réparti en deux sections : **Mode de filtrage**, qui active les listes, et **Conditions de filtrage**, qui contient les numéros inscrits dans ces listes.

<img className="thumbnail" alt="Section Mode de filtrage de l'onglet Gestion des appels d'une ligne" src="/images/web-cloud/phone-and-fax/voip/comment-configurer-les-renvois-d-appels/console/manage-calls-filtering-step1.png" loading="lazy" />

La section **Mode de filtrage** vous permet de mettre en place un filtrage s'appliquant aux appels entrants et/ou sortants selon trois configurations :

|Configurations|Description|
|---|---|
|Filtre entrant|Permet de filtrer les appels reçus sur votre ligne selon une liste blanche ou noire que vous devez configurer.|
|Filtre sortant|Permet de filtrer les appels émis depuis votre ligne selon une liste blanche ou noire que vous devez configurer.|
|Rejet des appels anonymes|Permet de rejeter automatiquement les appels entrants provenant d'un correspondant anonyme.|

Pour activer ou désactiver le « rejet des appels anonymes », utilisez l'interrupteur **Rejet des appels anonymes**.

Deux autres configurations bloquent la réception des appels entrants. Elles se trouvent dans la section **Paramètres d'appel** de l'onglet <code className="action">Paramètres de ligne</code> :

|Configurations|Description|
|---|---|
|Ne pas déranger|Permet de bloquer automatiquement la réception des appels entrants sur votre ligne et d'indiquer aux interlocuteurs qui vous contactent que vous ne souhaitez pas être dérangé par le biais d'un message vocal (du type : « votre correspondant ne souhaite pas être dérangé, merci de le rappeler ultérieurement »).|
|Abonné absent|Permet de bloquer automatiquement la réception des appels entrants sur votre ligne et d'indiquer aux interlocuteurs qui vous contactent que vous êtes absent par le biais d'un message vocal (du type : « votre correspondant est momentanément absent, merci de le rappeler ultérieurement »).|

Pour activer ou désactiver l'une de ces configurations, utilisez l'interrupteur **Ne pas déranger** ou **Abonné absent**.

Concernant le « filtre entrant » et le « filtre sortant », sélectionnez dans le menu déroulant **Filtre entrant** ou **Filtre sortant** si vous souhaitez filtrer les appels en fonction d'une liste blanche (**Liste blanche (autorisés uniquement)**) ou d'une liste noire (**Liste noire (bloqués uniquement)**). La valeur **Désactivé** n'applique aucun filtrage. Le système des listes fonctionne de la manière suivante :

|Appel|Liste|Description|
|---|---|---|
|Lors d'un appel entrant|Liste blanche|Seuls les numéros ou les tranches de numéros inscrits dans la liste sont autorisés à vous contacter.|
|Lors d'un appel entrant|Liste noire|Les numéros ou les tranches de numéros inscrits dans la liste ne peuvent plus vous contacter.|
|Lors d'un appel sortant|Liste blanche|Seuls les numéros ou les tranches de numéros inscrits dans la liste peuvent être contactés depuis votre ligne.|
|Lors d'un appel sortant|Liste noire|Les numéros ou les tranches de numéros inscrits dans la liste ne peuvent plus être contactés depuis votre ligne.|

Si vous avez décidé d'activer un filtrage d'appels entrants et/ou sortants, vous devez à présent ajouter des conditions dans la ou les listes que vous avez sélectionnées.

Pour cela, toujours sur le même onglet, utilisez la section **Conditions de filtrage**. Ses boutons vous permettent d'ajouter des conditions à vos listes, et son tableau affiche les conditions actuellement en place.

<img className="thumbnail" alt="Section Conditions de filtrage avec la liste des conditions en place" src="/images/web-cloud/phone-and-fax/voip/comment-configurer-les-renvois-d-appels/console/manage-calls-filtering-step2.png" loading="lazy" />

Concernant l'ajout de conditions, trois moyens existent :

|Configurations|Description|
|---|---|
|Ajout en mode manuel|Cliquez sur <code className="action">Ajouter une condition</code>. Dans la fenêtre qui s'ouvre, renseignez le **Numéro de téléphone**, choisissez le **Type de liste** (par exemple « Entrant — Liste blanche ») et la **Nature** du numéro, puis cliquez sur le bouton <code className="action">Ajouter</code>. Ce mode vous permet également de filtrer les « services OVHcloud » (tels que le service de messagerie), grâce aux natures **Service OVHcloud** et **Messagerie vocale**.|
|Utiliser un assistant|L'assistant vous permet de créer des filtres sur des catégories de numéros (comme les numéros spéciaux). Pour accéder à celui-ci, cliquez sur <code className="action">Assistant</code>. Choisissez le **Type de liste** auquel les filtres seront ajoutés et la **Catégorie** de numéros, puis cliquez sur <code className="action">Appliquer</code>.|
|Importer un CSV|Cliquez sur <code className="action">Actions</code> puis sur <code className="action">Importer</code>. Dans la fenêtre **Importer des filtres**, sélectionnez sur votre propre machine le fichier CSV contenant les filtres que vous souhaitez importer, au format `callNumber;type;nature`, puis cliquez sur <code className="action">Importer</code>. Le lien <code className="action">Télécharger le template</code> vous fournit un fichier modèle.|

<img className="thumbnail" alt="Fenêtre Ajouter une condition de la section Conditions de filtrage" src="/images/web-cloud/phone-and-fax/voip/comment-configurer-les-renvois-d-appels/console/manage-calls-filtering-step3.png" loading="lazy" />

<img className="thumbnail" alt="Menu Actions de la section Conditions de filtrage avec l'option Importer" src="/images/web-cloud/phone-and-fax/voip/comment-configurer-les-renvois-d-appels/console/filtering-actions-menu.png" loading="lazy" />

Enfin, le tableau de la section **Conditions de filtrage** vous permet de visualiser les conditions en place sur vos listes mais aussi de les supprimer. Pour supprimer une condition, cliquez sur l'icône en forme de corbeille sur sa ligne. Pour retirer toutes les conditions en une fois, cliquez sur <code className="action">Actions</code> puis sur <code className="action">Tout retirer</code>.

:::warning
**Filtrage d'appels et renvoi d'appels vers le répondeur**

Lors de vos paramétrages, pensez à autoriser les services indispensables tels que le répondeur de votre ligne ou les « services OVHcloud ».

Si vous ne le faites pas, un renvoi d'appel vers le répondeur de votre ligne ne pourra pas fonctionner.

:::
