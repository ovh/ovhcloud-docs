Ce guide accompagne le déploiement conjoint de deux composants proposés par OVHcloud ou d'autres fournisseurs : un serveur et un service de téléphonie compatible. Un exemple de configuration permet de centraliser votre téléphonie rapidement avec un logiciel libre reposant sur Asterisk. L'installation est orchestrée en 20 à 40 minutes à l'aide d'un script exécuté directement depuis le serveur via SSH.

:::warning
Le support OVHcloud couvre les services souscrits (VPS, téléphonie SIP) indépendamment de ce guide. La maintenance, les niveaux de sécurité et de conformité appliqués restent sous votre responsabilité : il vous appartient de les adapter et de les renforcer selon votre contexte. Pour favoriser l'amélioration continue, vous avez la possibilité de cliquer sur le pouce vers le bas afin de partager des éléments anonymisés. Il est également recommandé d'activer la [double authentification](/guides/account-and-service-management/account-information/secure-ovhcloud-account-with-2fa) sur votre espace client OVHcloud.
:::

## Objectif

- Un serveur de téléphonie FreePBX 17 opérationnel, accessible depuis son interface d'administration web.
- Selon les options activées : trois postes de démonstration permettant de tester les appels internes entre extensions, même sans service de téléphonie externe, des appels externes avec un service de téléphonie compatible, ainsi que l'accès HTTPS à l'interface.

## Prérequis

- Un serveur sous **Debian 12 (Bookworm)**, 2 Go de RAM et 20 Go de disque minimum.
- Une **clé SSH** associée au serveur.
- Suivant les options activées, un service de téléphonie SIP ou un nom de domaine.

## En pratique

### Options disponibles à l'installation

Lors de l'installation, le script pose quelques questions et propose trois options. Toutes sont **facultatives et désactivées par défaut** ; elles peuvent aussi être configurées après le déploiement.

**Kit de démonstration (3 extensions) :** trois postes de démonstration avec des numéros à 5 chiffres attribués automatiquement.

**Ligne opérateur SIP (trunk)** *(prérequis à préparer)* : préciser le serveur SIP (registrar), l'identifiant et le mot de passe SIP de votre opérateur. Si vous utilisez OVHcloud, consultez [Modifier le mot de passe d'une ligne SIP](/guides/web-cloud/phone-and-fax/voip/modifier-mot-de-passe-ligne-sip). Il est recommandé de [sécuriser votre ligne SIP](/guides/web-cloud/phone-and-fax/voip/secure-sip-line) avant de la mettre en service : restriction par IP et, par exemple, liste blanche de filtrage d'appels sortants avec le type de numéro « Répondeur » et le « numéro court » `123`, pour rediriger ou tester les appels sortants vers le répondeur et consulter les messages.

**Nom de domaine (accès HTTPS)** *(prérequis à préparer)* : préciser un sous-domaine (enregistrement DNS de type A pointant vers l'IP du serveur) afin de sécuriser l'accès à l'interface graphique en HTTPS et de définir le registrar (serveur SIP) utilisé lors de la configuration des postes téléphoniques. Sans cette option, l'interface d'administration restera accessible en démarrant ponctuellement Apache suivant les consignes affichées et l'adresse IP devra être renseignée en tant que registrar.

### Étape 1 : préparer le serveur

Si votre VPS est déjà sous Debian 12 avec votre clé SSH associée, passez directement à l'étape 2.

1. Si vous n'avez pas encore de clé SSH, générez-en une en suivant le guide [Créer et utiliser des clés SSH](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys), puis revenez ici.
2. Depuis l'[espace client OVHcloud](https://www.ovhcloud.com/fr/manager/), sélectionnez votre VPS.
3. Onglet <code className="action">Accueil</code> → bouton <code className="action">Réinstaller votre VPS</code> → choisissez <code className="action">Debian 12</code> et associez votre clé SSH.
4. Une fois la réinstallation terminée, relevez l'**adresse IPv4** affichée dans l'espace client.

### Étape 2 : lancer l'installation

Lancez les commandes suivantes : (1) depuis votre poste, puis (2) depuis le serveur.

1. **Connectez-vous en SSH** sur le serveur (port 22 sur une installation fraîche Debian 12) :

   ```bash
   ssh debian@<ADRESSE_IP_SERVEUR>
   ```

   Si le message *WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED* s'affiche (VPS réinstallé), supprimez l'ancienne empreinte :

   ```bash
   ssh-keygen -R <ADRESSE_IP_SERVEUR>
   ```

   Puis relancez la connexion :

   ```bash
   ssh debian@<ADRESSE_IP_SERVEUR>
   ```

   Le serveur demande confirmation : tapez `yes` puis appuyez sur Entrée.

2. **Téléchargez et démarrez l'installation** (20-40 min, ne pas fermer le terminal) :

   ```bash
   wget -q -O /tmp/install.sh https://raw.githubusercontent.com/ovh/ovhcloud-docs/freepbx-VPS-trunk/install.sh && sudo bash /tmp/install.sh
   ```

### Étape 3 : répondre aux questions

Le terminal affiche des instructions pas-à-pas : suivez-les simplement, en notant le port SSH affiché en cours d'installation.

### En fin d'installation

Un rapport de livraison est généré sur le serveur. Il récapitule les accès, les options activées, les protections appliquées, les fichiers utiles et les commandes de vérification.

Le déploiement utilise UFW comme pare-feu principal. Si vous souhaitez activer le pare-feu intégré à FreePBX, consultez le rapport de livraison afin d'éviter toute configuration de sécurité en double.

En cas de perte d'accès, vérifiez le port SSH et l'IP autorisée qui étaient affichés en fin d'installation. Si nécessaire, utilisez la [console KVM](/guides/bare-metal-cloud/virtual-private-servers/using-kvm-for-vps), le [mode Rescue](/guides/bare-metal-cloud/virtual-private-servers/rescue) ou une réinstallation Debian 12.
