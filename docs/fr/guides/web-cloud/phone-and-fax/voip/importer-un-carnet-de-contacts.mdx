## Objectif

Votre ligne SIP OVHcloud vous permet de recevoir et d’émettre des appels. Pour faciliter les interactions avec vos correspondants, vous pouvez créer un carnet de contacts permettant de retrouver ou d'identifier ceux-ci directement depuis vos téléphones, dans le répertoire ou lors d'un appel entrant.

**Apprenez à gérer le carnet de contacts et les numéros abrégés de vos lignes SIP OVHcloud.**

## Prérequis

- Disposer au moins d'une [ligne SIP OVHcloud](https://www.ovhcloud.com/fr/phone/voip/).

## En pratique

### Étape 1 : accéder à la gestion du carnet de contacts

{/* CP-STEPS-START:etape-1-acceder-carnet-contacts */}

Vous pouvez gérer le carnet de contacts d'une seule ligne ou d'un groupe de lignes, permettant ainsi à toutes les lignes rattachées à ce groupe d'en bénéficier.

:::tip
L'avantage de l'ajout d'un carnet de contacts sur un **groupe de lignes** est qu'il permet d'avoir un carnet **commun** pour toutes les lignes du groupe.

:::

Pour bénéficier d'un carnet de contacts sur une seule ligne SIP, celle-ci doit être associée à un téléphone fourni par OVHcloud qui prend en charge le carnet de contacts. L'onglet <code className="action">Carnet de contacts</code> de la ligne n'apparaît que dans ce cas.

- **Pour accéder à la gestion du carnet de contacts d'une seule ligne** :

Sélectionnez la ligne, puis cliquez sur l'onglet <code className="action">Carnet de contacts</code>.

<img className="thumbnail" alt="Onglet Carnet de contacts d'une ligne SIP dans la console OVHcloud" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/console/carnetligne.png" loading="lazy" />

- **Pour accéder à la gestion du carnet de contacts d'un groupe de lignes** :

Sélectionnez le groupe de lignes, puis cliquez sur l'onglet <code className="action">Carnet de contacts</code>.

<img className="thumbnail" alt="Onglet Carnet de contacts d'un groupe de lignes dans la console OVHcloud" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/console/carnetgroupe.png" loading="lazy" />

{/* CP-STEPS-END:etape-1-acceder-carnet-contacts */}

### Étape 2 : gérer le carnet de contacts

{/* CP-STEPS-START:etape-2-gerer-carnet-contacts */}

La gestion du carnet de contacts s'effectue de la même manière, que vous ayez sélectionné une seule ligne ou un groupe de lignes. Poursuivez en fonction de la manipulation que vous souhaitez réaliser.

{/* CP-STEPS-END:etape-2-gerer-carnet-contacts */}

#### Créer un carnet de contacts

{/* CP-STEPS-START:creer-carnet-contacts */}

Si votre ligne ou votre groupe de lignes ne dispose pas encore d'un carnet de contacts, celui-ci est créé avec le premier contact que vous ajoutez ou le premier fichier que vous importez : vous lui donnez un nom dans le même formulaire. Il n'est pas possible de créer plusieurs carnets de contacts.

{/* CP-STEPS-END:creer-carnet-contacts */}

#### Ajouter ou modifier un contact

{/* CP-STEPS-START:ajouter-modifier-contact */}

Pour ajouter un nouveau contact, cliquez sur le bouton <code className="action">Ajouter un contact</code>.

Dans le panneau **Ajouter un contact**, remplissez ensuite les informations demandées : nom, prénom, groupe (facultatif) et numéros de téléphone (fixe et mobile, domicile et professionnel). Renseignez au moins un numéro de téléphone valide. Les numéros doivent être renseignés au format international (par exemple, « 0033199000001 » pour un numéro français). Une fois les informations complétées, cliquez sur le bouton <code className="action">Ajouter</code> pour ajouter le contact. Répétez cette manipulation autant de fois que nécessaire : pour enchaîner les ajouts, cochez la case **Ajouter un autre contact après l'enregistrement** avant de cliquer sur <code className="action">Ajouter</code>.

<img className="thumbnail" alt="Panneau Ajouter un contact ouvert depuis le carnet de contacts d'une ligne" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/console/creercarnetV2.png" loading="lazy" />

Pour modifier un contact existant, cliquez sur le bouton <code className="action">⋮</code> à droite du contact concerné, puis sur <code className="action">Modifier</code>.

<img className="thumbnail" alt="Menu d'un contact du carnet avec les options Modifier et Supprimer" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/console/carnet-contacts-step5.png" loading="lazy" />

{/* CP-STEPS-END:ajouter-modifier-contact */}

#### Importer des contacts

{/* CP-STEPS-START:importer-contacts */}

Pour importer des contacts dans le carnet de contacts, cliquez sur le bouton <code className="action">Importer</code>.

Dans la fenêtre **Importer des contacts**, cliquez dans la zone d'import ou faites-y glisser votre fichier. Pour être accepté par l'outil d'import, le fichier doit être au format CSV ou Excel (.xls, .xlsx) et respecter une forme précise dans son contenu, au format `group;surname;name;workPhone;workMobile;homePhone;homeMobile`. Pour partir d'un fichier d'exemple, cliquez sur <code className="action">Télécharger un modèle de fichier</code>. Vous trouverez également un exemple ci-dessous :

|group|surname|name|workPhone|workMobile|homePhone|homeMobile|countryCode|
|---|---|---|---|---|---|---|---|
|Aucune|SMITH|John|199000001| | |639980001|33|

Vous pouvez également utiliser une version texte en séparant chaque cellule du tableau par un point-virgule (donnant par exemple : « Aucune;SMITH;John;199000001;;;639980001;33 »). Une fois le fichier sélectionné, cliquez sur le bouton <code className="action">Importer</code>. Les contacts apparaissent dans le carnet une fois l'import terminé.

<img className="thumbnail" alt="Fenêtre Importer des contacts ouverte depuis le carnet de contacts d'une ligne" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/console/carnet-contacts-step6.png" loading="lazy" />

:::warning
Si aucun indicatif pays n'est renseigné dans la colonne « countryCode », nous y ajouterons automatiquement l'indicatif correspondant au pays de votre identifiant client.

:::

{/* CP-STEPS-END:importer-contacts */}

#### Télécharger le carnet de contacts

{/* CP-STEPS-START:telecharger-carnet-contacts */}

Pour télécharger la liste actuelle des contacts ajoutés dans le carnet, cliquez sur le bouton <code className="action">Exporter</code>, puis sur <code className="action">Tout exporter</code>. Pour n'exporter que certains contacts, cochez la case à gauche des contacts concernés, cliquez sur <code className="action">Exporter</code>, puis sur <code className="action">Exporter la sélection</code>.

Le fichier obtenu est au format .csv.

{/* CP-STEPS-END:telecharger-carnet-contacts */}

#### Supprimer un ou plusieurs contacts

{/* CP-STEPS-START:supprimer-contacts */}

Pour supprimer un seul contact, cliquez sur le bouton <code className="action">⋮</code> à droite du contact concerné, puis sur <code className="action">Supprimer</code>. Pour en supprimer plusieurs, cochez la case à gauche des contacts concernés, puis cliquez sur <code className="action">Supprimer la sélection</code>.

<img className="thumbnail" alt="Bouton Supprimer la sélection affiché après la sélection d'un contact du carnet" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/console/supprimercontact.png" loading="lazy" />

{/* CP-STEPS-END:supprimer-contacts */}

#### Supprimer un carnet de contacts

{/* CP-STEPS-START:supprimer-carnet-contacts */}

Pour supprimer un carnet de contacts, cliquez sur le bouton <code className="action">⋮</code> à droite du nom du carnet, puis sur <code className="action">Supprimer le carnet</code>. Dans la fenêtre **Supprimer le carnet d'adresses**, cliquez sur <code className="action">Supprimer</code>.

:::warning
La suppression d'un carnet de contacts est irréversible : tous les contacts qu'il contient sont également supprimés.

:::

{/* CP-STEPS-END:supprimer-carnet-contacts */}

### Étape 3 : utiliser le carnet de contacts sur votre téléphone

Afin que votre téléphone puisse utiliser le carnet de contacts ou récupérer les éventuelles modifications effectuées dans celui-ci, commencez par le redémarrer. Une fois votre téléphone redémarré, il devrait avoir téléchargé le nouveau carnet de contacts.
