## Objectif

Pour configurer le 3CX Phone System avec un SIP Trunk et deux DDI (**D**irect **D**ialling **I**nward), nous allons suivre le scénario suivant : 

>
> - 1 SIP Trunk : XX XX XX XX 90
> - 2 DDI : XX XX XX XX 26 et XX XX XX XX 10
> - 2 Extensions : 1000 et 1001
>
> Les deux extensions peuvent passer des appels sortants via le trunk. 
> L'extension 100 reçoit les appels du DDI XX XX XX XX 26 et présente ce DDI en appel sortant.
> L'extension 101 reçoit les appels du DDI XX XX XX XX 10 et présente ce DDI en appel sortant.
> Les appels reçus directement sur le numéro du trunk sont redirigés vers le répondeur de l'extension 100.
>

**Découvrez comment configurer un SIP Trunk OVHcloud avec l'IPBX 3CX et deux DDI.**

## Prérequis

- Un [SIP Trunk OVHcloud](https://www.ovhcloud.com/fr/phone/sip-trunk/)
- Deux [alias configurés](/guides/web-cloud/phone-and-fax/voip/redirection-avec-presentation) en redirection DDI vers le trunk
- Un [softphone](/guides/web-cloud/phone-and-fax/voip/register-sip-softphone) ou un téléphone SIP
- [3CX](https://www.3cx.fr/) installé, activé et à jour. 

Obtenez gratuitement 3CX en accédant à la [page de téléchargement 3CX](https://www.3cx.fr/pabx/download-pabx-ip/).

### Régler la durée d'enregistrement

:::tip
Nous vous recommandons de régler la durée d'enregistrement de votre trunk SIP sur **1800 secondes** (30 minutes) : une valeur trop faible génère des ré-enregistrements inutiles, tandis qu'une valeur trop élevée peut laisser la liaison entre votre équipement et le serveur se fermer et empêcher la réception des appels.
:::

Ce réglage se trouve dans les paramètres du trunk SIP, onglet **Options**, dans le champ **Timeout Ré-enregistrer** (exprimé en secondes) : indiquez `1800`.


### Création et configuration des extensions

L'objectif de cette étape est de configurer les extensions 1000 et 1001.

Configurez l’extension 1000 pour lui permettre de présenter le DDI XX XX XX XX 26.

- Dans l'interface d'administration de 3CX, rendez-vous sur la catégorie <code className="action">Utilisateurs</code>.
- Double-cliquez sur l'extension `1000`.
- Dans le champ **Numéro présenté**, saisissez le DDI à présenter. Dans notre cas : 0033XXXXXXX26.
- Cliquez sur <code className="action">OK</code> pour prendre en compte la modification.

<img className="thumbnail" alt="3CX Phone System" src="/images/web-cloud/phone-and-fax/voip/configuration-basique-dun-sip-trunk-ovh-sur-3cx-phone-system/3cx_phone_system-trunk05.png" loading="lazy" />

Créez et configurez l'extension 1001 :

- Dans l'interface d'administration de 3CX, rendez-vous sur la catégorie <code className="action">Utilisateurs</code>.
- Cliquez sur le bouton <code className="action">Ajouter</code>.
- Dans le champ **Extension**, saisissez `1001`.
- Saisissez ensuite les Nom, Prénom, Adresse e-mail et numéro de mobile sur la fiche de création de l'extension.
- Dans le champ **Identifiant d'appelant transmis**, saisissez le DDI à présenter. Dans l'exemple du guide, il s'agit du 0033XXXXXXX10.
- Cliquez sur <code className="action">Appliquer</code> pour prendre en compte la modification.

<img className="thumbnail" alt="3CX Phone System" src="/images/web-cloud/phone-and-fax/voip/configuration-basique-dun-sip-trunk-ovh-sur-3cx-phone-system/3cx_phone_system-trunk06.png" loading="lazy" />

### Création des règles entrantes pour les DDI

Créez des règles d'appel entrant lorsque les DDI sont appelés. 

- Dans l'interface d'administration de 3CX, rendez-vous sur la catégorie <code className="action">Règles Entrantes</code>.
- Cliquez sur le bouton <code className="action">Ajouter une règle SDA</code>.
- Dans le champ **Nom**, saisissez le nom de la route. Dans notre cas nous mettons `Call-In-XXXXXXX26`.
- Dans le champ **SDA/DID**, sélectionnez le DDI 0033XXXXXXX26.
- Dans le champ **Extension**, choisissez la 1000.
- Cliquez sur <code className="action">OK</code> pour valider la configuration.

<img className="thumbnail" alt="3CX Phone System" src="/images/web-cloud/phone-and-fax/voip/configuration-basique-dun-sip-trunk-ovh-sur-3cx-phone-system/3cx_phone_system-trunk08.png" loading="lazy" />

Pour configurer le second DDI il vous faut appliquer la même procédure, à la différence que vous devez changer le DDI présenté et l'extension cible de l'appel.
