## Objectif

Le logiciel [AlloDesk](https://allodesk.app/) est un softphone (logiciel de téléphonie) gratuit pour Windows 10 et 11, permettant d'enregistrer une ligne SIP fixe OVHcloud afin d'émettre et recevoir des appels via cette ligne depuis un ordinateur.

AlloDesk propose deux méthodes d'enregistrement :

- **la connexion à votre compte OVHcloud**, qui permet d'ajouter vos lignes SIP depuis une liste, sans saisir de serveur ni d'identifiant ;
- **la configuration manuelle**, à partir des identifiants SIP de votre ligne, sans connecter votre compte OVHcloud.

**Découvrez comment enregistrer votre ligne SIP OVHcloud sur AlloDesk.**

[[fragment:support-scope]]

:::info
AlloDesk est un logiciel tiers. Pour toute question sur le logiciel lui-même, consultez l'aide intégrée à AlloDesk (rubrique **Configurer ma ligne**, choix **OVHcloud**) ou contactez son éditeur.
:::

## Prérequis

- Disposer d'une [ligne SIP OVHcloud](https://www.ovhcloud.com/fr/phone/voip/) sans téléphone OVHcloud associé.
- Pour la configuration manuelle : [disposer des identifiants de votre ligne SIP OVHcloud](/guides/web-cloud/phone-and-fax/voip/register-sip-softphone).
- Disposer d'un ordinateur sous Windows 10 ou 11 (64 bits) avec le logiciel [AlloDesk](https://allodesk.app/) installé.
- Disposer d'un casque, ou d'un micro et de haut-parleurs.

## En pratique

### Méthode 1 : connecter votre compte OVHcloud

Dans AlloDesk, ouvrez <code className="action">Paramètres</code>, puis la rubrique <code className="action">Opérateurs</code>.

Dans le cadre **OVHcloud**, cliquez sur <code className="action">Se connecter à mon compte OVH</code>. Votre navigateur ouvre la page de connexion d'OVHcloud : identifiez-vous avec votre compte, puis acceptez les droits demandés par AlloDesk :

- lire vos lignes de téléphonie et leurs réglages ;
- changer le mot de passe SIP d'une ligne, uniquement si vous le choisissez à l'étape suivante ;
- lire vos comptes SMS et envoyer des SMS, pour la fonction optionnelle de SMS automatique d'AlloDesk (vous pouvez ne jamais l'activer).

<img className="thumbnail" alt="AlloDesk - connexion du compte OVHcloud" src="/images/web-cloud/phone-and-fax/voip/register-sip-softphone-allodesk/allodesk01-operators.png" loading="lazy" />

Une fois le compte connecté, ouvrez la rubrique <code className="action">Comptes SIP</code>, cliquez sur <code className="action">Ajouter une ligne SIP</code>, puis sur <code className="action">Ajouter une ligne OVH</code>. Vous pouvez aussi partir directement de ce bouton : si votre compte OVHcloud n'est pas encore connecté, AlloDesk vous propose la connexion à ce moment-là.

AlloDesk affiche la liste de vos lignes SIP. Cochez la ligne à enregistrer, puis choisissez comment AlloDesk obtient son mot de passe SIP :

- <code className="action">J'indique le mot de passe SIP actuel de la ligne</code> : saisissez le mot de passe SIP de la ligne, tel qu'il figure dans votre espace client OVHcloud. Rien n'est modifié côté OVHcloud.
- <code className="action">AlloDesk génère un nouveau mot de passe</code> : AlloDesk définit un nouveau mot de passe SIP sur la ligne, via votre compte OVHcloud, et l'utilise aussitôt. Tout autre téléphone ou logiciel qui utilisait cette ligne sera déconnecté ; AlloDesk vous demande confirmation avant de le faire. Pour les bonnes pratiques sur les mots de passe SIP, consultez le guide [Sécuriser sa ligne SIP OVHcloud](/guides/web-cloud/phone-and-fax/voip/secure-sip-line).

Le serveur, l'identifiant, le port et le transport sont renseignés automatiquement.

<img className="thumbnail" alt="AlloDesk - ajout d'une ligne OVHcloud" src="/images/web-cloud/phone-and-fax/voip/register-sip-softphone-allodesk/allodesk02-add-ovh-line.png" loading="lazy" />

Validez. Lorsque la ligne est enregistrée, la pastille d'état, en haut de la fenêtre d'AlloDesk, passe au vert. Vous pouvez dès lors être joint et composer des appels depuis votre ligne SIP OVHcloud.

### Méthode 2 : configuration manuelle

Cette méthode ne demande pas de connecter votre compte OVHcloud : seuls les identifiants SIP de la ligne sont nécessaires. Vous les retrouvez dans votre espace client OVHcloud, rubrique <code className="action">Télécom</code>, puis <code className="action">Téléphonie</code> : sélectionnez votre groupe, puis votre ligne, et dans l'onglet <code className="action">Gestion</code>, cliquez sur <code className="action">Informations générales</code>. Le cadre « Informations SIP » indique le **Login**, le **Domain** et le **Proxy sortant** de la ligne. Le mot de passe SIP, lui, n'est pas affiché : si vous ne le connaissez plus, [modifiez-le](/guides/web-cloud/phone-and-fax/voip/modifier-mot-de-passe-ligne-sip). Ces étapes sont détaillées dans le guide [Utiliser une ligne SIP OVHcloud sur un softphone](/guides/web-cloud/phone-and-fax/voip/register-sip-softphone).

Dans AlloDesk, ouvrez <code className="action">Paramètres</code>, puis la rubrique <code className="action">Comptes SIP</code>. Cliquez sur <code className="action">Ajouter une ligne SIP</code>, puis sur <code className="action">Ajouter une ligne SIP manuellement</code>.

Complétez les champs suivants :

| Champ AlloDesk | Information OVHcloud |
|---|---|
| Identifiant / numéro | **Login / User name** de la ligne, au format `0033912345678` |
| Mot de passe | **Mot de passe SIP** de la ligne |
| Serveur / domaine | **Domain** de la ligne, par exemple `sip-domain.io` |
| Port | Laissez la valeur par défaut, `5060` |
| Transport | **UDP**, les lignes SIP OVHcloud utilisant uniquement ce protocole |

À partir de la deuxième ligne ajoutée, AlloDesk demande aussi un **Nom de la ligne**, libre (par exemple « Ligne OVHcloud »), affiché dans l'application.

Si le **Proxy sortant** de votre ligne est différent du **Domain**, dépliez les options avancées et renseignez-le dans le champ <code className="action">Proxy sortant</code>, sous la forme `hôte` ou `hôte:port` si un port particulier est indiqué. S'il est identique au Domain, laissez ce champ vide. Les autres options avancées (identifiant d'authentification, transport TLS, chiffrement SRTP) ne concernent pas les lignes SIP OVHcloud.

<img className="thumbnail" alt="AlloDesk - configuration manuelle d'une ligne SIP" src="/images/web-cloud/phone-and-fax/voip/register-sip-softphone-allodesk/allodesk03-manual.png" loading="lazy" />

Validez. Lorsque la ligne est enregistrée, la pastille d'état passe au vert.

### Durée d'enregistrement

:::tip
OVHcloud recommande une durée d'enregistrement (`expires`) de 1800 secondes pour les équipements qui la laissent régler. AlloDesk ne propose pas ce réglage : il enregistre la ligne pour 60 secondes et renouvelle l'enregistrement automatiquement. Ce rythme court maintient ouverte la liaison entre votre ordinateur et le serveur OVHcloud derrière une box ou un pare-feu, pour que les appels entrants arrivent toujours, et permet à OVHcloud de constater rapidement qu'un ordinateur est éteint. Il n'y a rien à faire de votre côté.
:::

### Dépannage

Si l'enregistrement de votre ligne a échoué, vérifiez que vous avez bien saisi les identifiants SIP OVHcloud, notamment le mot de passe SIP. Le détail de l'erreur s'affiche au survol de la pastille d'état et dans <code className="action">Paramètres</code>, rubrique <code className="action">Comptes SIP</code>.

En cas d'échecs répétés, [modifiez votre mot de passe SIP depuis l'espace client OVHcloud](/guides/web-cloud/phone-and-fax/voip/modifier-mot-de-passe-ligne-sip) et refaites un essai d'enregistrement avec le nouveau mot de passe SIP. Avec la méthode 1, vous pouvez aussi reprendre l'ajout de la ligne en choisissant <code className="action">AlloDesk génère un nouveau mot de passe</code>.

Vérifiez également que l'adresse IP depuis laquelle vous utilisez AlloDesk fait partie des adresses IP autorisées à utiliser votre ligne SIP. Pour plus de détails, consultez le guide [Restreindre sa ligne SIP OVHcloud par IP](/guides/web-cloud/phone-and-fax/voip/sip-ip-restriction).

:::info
Une ligne SIP OVHcloud ne s'enregistre que sur un seul équipement à la fois. Si la ligne était utilisée sur un autre softphone ou téléphone, celui-ci ne recevra plus les appels une fois la ligne enregistrée sur AlloDesk.
:::
