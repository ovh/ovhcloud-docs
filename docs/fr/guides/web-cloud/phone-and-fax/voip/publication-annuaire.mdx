## Objectif

Lorsque vous disposez d'une ligne ou d'un numéro chez un opérateur, il est obligatoire d'y rattacher des coordonnées. Chez OVHcloud, vous pouvez réaliser cette démarche lors de votre commande ou par la suite, depuis votre espace client. Vous pouvez même choisir de publier ces informations dans les annuaires en ligne.

**Découvrez comment rattacher des informations à votre ligne ou numéro OVHcloud et les faire paraître dans les annuaires.**

## Prérequis

- Disposer d'un [numéro alias](https://www.ovhcloud.com/fr/phone/numeros/) ou d'une [ligne VoIP OVHcloud](https://www.ovhcloud.com/fr/phone/).

## En pratique

### Étape 1 : comprendre l'obligation de renseigner ses coordonnées

Renseigner vos coordonnées est obligatoire pour l'ensemble de vos lignes et numéros OVHcloud. Si vous n'avez pas fourni ces informations lors de votre commande, vous serez invité à le faire par la suite depuis votre espace client.

Cette démarche est nécessaire pour deux raisons :

- **permettre à OVHcloud d'assurer la liaison vers les bons services d'urgence** : lorsque vous composez un numéro d'urgence sur votre téléphone, votre opérateur assure l'acheminement de cet appel vers le service d'urgence le plus proche de l'adresse d'installation de votre ligne SIP ;

- **permettre à OVHcloud d'assurer la liaison vers votre nouvel opérateur lors d'une portabilité** : si vous décidez de porter votre numéro chez un autre opérateur, vous devrez alors lui fournir les informations de ce numéro. Celles-ci doivent correspondre aux données renseignées chez OVHcloud.

Assurez-vous ainsi d'indiquer et de maintenir à jour les coordonnées de l'ensemble de vos lignes et numéros OVHcloud.

### Étape 2 : modifier ses coordonnées et demander leur parution

{/* CP-STEPS-START:etape-2-modifier-coordonnees */}

Ouvrez le panneau de modification des coordonnées. Le chemin dépend du service concerné :

- **pour un numéro OVHcloud** : dans la section **Informations** de la page du numéro, cliquez sur le bouton <code className="action">⋮</code> à droite de **Actions supplémentaires**, puis sur <code className="action">Modifier les coordonnées</code> ;

- **pour une ligne OVHcloud** : sur la page **Vue d'ensemble** de la ligne, cliquez sur le lien <code className="action">Mettre à jour</code> à côté de **Modifier les coordonnées**.

<img className="thumbnail" alt="menu Actions supplémentaires d'un numéro OVHcloud, option Modifier les coordonnées" src="/images/web-cloud/phone-and-fax/voip/publication-annuaire/console/manage-telephone-directory-step1.png" loading="lazy" />

Le panneau **Modifier les coordonnées** s'ouvre sur la droite de l'écran.

Complétez ou modifiez les champs des sections **Informations** et **Adresse**. Dans la section **Parution dans les annuaires**, deux possibilités s'offrent à vous :

- **vous souhaitez publier vos informations dans les annuaires en ligne** : activez l'interrupteur <code className="action">Publication dans l'annuaire</code>, puis complétez les champs supplémentaires qui s'affichent : **Démarchage téléphonique accepté**, **Publication dans l'annuaire inversé**, **Affichage du nom**, **Publication de l'adresse** et **Désignation de la ligne** ;

- **vous ne souhaitez pas publier vos informations dans les annuaires en ligne** : laissez l'interrupteur <code className="action">Publication dans l'annuaire</code> désactivé.

La section suivante, **Portée de la modification**, propose également l'option **Appliquer à plusieurs numéros** si vous souhaitez appliquer ces coordonnées à plusieurs numéros.

Une fois toutes les informations complétées, cliquez sur le bouton <code className="action">Appliquer les modifications</code> en bas du panneau. Si vous avez choisi de publier vos informations, la parution dans les annuaires en ligne sera effective sous 1 à 30 jours. Ce délai est inhérent aux annuaires eux-mêmes, qui mettent à jour leur base de données une fois par mois.

<img className="thumbnail" alt="panneau Modifier les coordonnées avec les sections Informations et Adresse" src="/images/web-cloud/phone-and-fax/voip/publication-annuaire/console/manage-telephone-directory-step2.png" loading="lazy" />

{/* CP-STEPS-END:etape-2-modifier-coordonnees */}

### Étape 3 : suivre la parution de vos coordonnées

:::info
Cette étape s'applique uniquement si vous avez choisi de publier vos informations dans les annuaires en ligne. 

:::


{/* CP-STEPS-START:etape-3-suivre-parution */}

Vous pouvez suivre la parution de vos informations dans les annuaires en ligne depuis le panneau **Modifier les coordonnées** de la ligne ou du numéro OVHcloud concerné, ouvert comme indiqué à l'étape précédente.

Faites défiler le panneau jusqu'à la section **Parution dans les annuaires**. Vérifiez alors le statut qui s'affiche sous **Statut** :

- **le statut indique « Synchronisation programmée »** : la mise à jour de vos informations est toujours en cours dans les annuaires en ligne. Pour rappel, celle-ci peut nécessiter un délai de 1 à 30 jours avant d'être effective ;

- **le statut indique « Synchronisé »** : les informations renseignées dans la console OVHcloud sont celles qui s'affichent dans les annuaires en ligne. La dernière modification est donc terminée.

Pour vérifier la parution de vos coordonnées, vous pouvez également vous rendre directement sur le site de l'annuaire concerné. Vous devrez alors rechercher votre ligne ou numéro OVHcloud.

<img className="thumbnail" alt="section Parution dans les annuaires avec le statut Synchronisation programmée" src="/images/web-cloud/phone-and-fax/voip/publication-annuaire/console/manage-telephone-directory-step3.png" loading="lazy" />
