## Objectif

La redirection permet de rediriger vers une ligne SIP OVHcloud les appels reçus sur un numéro alias OVHcloud. 
Cette configuration permet notamment la réception d'appels sur votre numéro principal.

**Découvrez comment configurer une redirection d'appels sur votre numéro OVHcloud.**

:::info
Pour obtenir plus de détails sur la différence entre un **numéro alias** et une **ligne SIP**, consultez notre [FAQ](/guides/web-cloud/phone-and-fax/voip/faq-voip#ligne-ou-numero).

:::

:::info
À l'étape 2 (sélection de la ligne), la ligne de destination peut être une ligne SIP ou une **ligne SIP Trunk**. Dans ce dernier cas, l'option « Activer la présentation de votre numéro lors des appels sortants », spécifique aux redirections vers une ligne SIP, n'apparaît pas. La présentation de l'alias sur les appels sortants du Trunk se gère depuis votre IPBX.

:::

## Prérequis

- Disposer d'un [numéro alias fourni par OVHcloud](https://www.ovhcloud.com/fr/phone/numeros/) ou d'un [numéro porté](/guides/web-cloud/phone-and-fax/voip/demander-la-portabilite-de-mon-numero) depuis un autre opérateur.
- Disposer d'[une ligne SIP OVHcloud](https://www.ovhcloud.com/fr/phone/voip/).

## En pratique

### Étape 1 : Appliquer la configuration « Redirection d'appels »

{/* CP-STEPS-START:etape-1-appliquer-configuration */}
- Si votre numéro n'est actuellement pas configuré, dans la section <code className="action">Configuration</code> de la page de présentation du numéro, cliquez sur <code className="action">Choisir une configuration</code>. Dans la fenêtre <code className="action">Changer la configuration</code> qui s'ouvre, sélectionnez <code className="action">Redirection d'appels</code> puis cliquez sur <code className="action">Paramétrer</code>.

- Si votre numéro a déjà une configuration en place, ouvrez la page de présentation du numéro, puis cliquez sur <code className="action">Actions supplémentaires : Configuration</code>, à côté du résumé de la configuration. Dans le menu qui s'ouvre, sélectionnez <code className="action">Changer la configuration</code>. Sélectionnez ensuite <code className="action">Redirection d'appels</code> dans la fenêtre qui s'affiche et cliquez sur <code className="action">Paramétrer</code>.

<img className="thumbnail" alt="redirection d'appels" src="/images/web-cloud/phone-and-fax/voip/redirection-avec-presentation/console/changer-configuration-redirection.png" loading="lazy" />

:::info
Pour appliquer le même type de configuration à plusieurs numéros, cochez la case <code className="action">Appliquer à plusieurs numéros</code> dans la fenêtre <code className="action">Changer la configuration</code>, sélectionnez les numéros concernés, puis cliquez sur <code className="action">Paramétrer</code>.
:::
{/* CP-STEPS-END:etape-1-appliquer-configuration */}

### Étape 2 : Paramétrer la redirection d'appels

{/* CP-STEPS-START:etape-2-parametrer-redirection */}
Dans l'onglet <code className="action">Configuration</code> du numéro, la section <code className="action">Vos appels entrants</code> réunit à la fois le choix de la ligne de destination et l'activation de la présentation du numéro lors des appels sortants.

La ligne vers laquelle vos appels sont actuellement redirigés est affichée sous <code className="action">Ligne de destination</code>. Pour la changer, cliquez sur le lien <code className="action">Changer</code> à côté de ce champ.

Dans la fenêtre qui s'ouvre, utilisez le champ <code className="action">Rechercher une ligne</code> pour retrouver, parmi la liste de vos lignes et groupes, celle vers laquelle vous souhaitez rediriger les appels reçus sur votre numéro, puis sélectionnez-la. Cliquez ensuite sur <code className="action">Enregistrer</code> pour confirmer votre sélection.

<img className="thumbnail" alt="redirection d'appels" src="/images/web-cloud/phone-and-fax/voip/redirection-avec-presentation/console/redirection-appels-entrants.png" loading="lazy" />

La ligne sélectionnée apparaît alors sous <code className="action">Ligne de destination</code>.

:::warning
La législation interdit les redirections vers les numéros surtaxés.
:::

Pour rediriger vos appels vers une ligne extérieure à OVHcloud, cliquez sur <code className="action">File d'appels</code>.

Dans la même section <code className="action">Vos appels entrants</code>, l'interrupteur <code className="action">Présenter ce numéro lors des appels sortants</code> permet d'activer ou de désactiver la présentation de votre numéro lors d'un appel sortant.

Vous pouvez ainsi, lorsque vous émettez un appel depuis votre ligne SIP OVHcloud, présenter votre numéro alias (et non plus la ligne OVHcloud) sur les téléphones de vos destinataires.

Si vous souhaitez activer cette fonctionnalité, activez l'interrupteur <code className="action">Présenter ce numéro lors des appels sortants</code>.

Chaque réglage de cette section est enregistré dès sa modification ; patientez quelques instants afin que celle-ci soit prise en compte.
{/* CP-STEPS-END:etape-2-parametrer-redirection */}

:::info
Si vous avez appliqué le même type de configuration à plusieurs numéros, vous devrez finaliser la configuration sur chacun des numéros concernés.

:::
