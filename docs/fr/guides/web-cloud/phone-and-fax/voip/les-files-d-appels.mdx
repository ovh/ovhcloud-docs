## Objectif

La configuration en file d'appels permet de rediriger un appel entrant vers plusieurs lignes. Cette solution permet de créer une stratégie pour éviter la perte d'appels.

Vous pouvez ainsi décider, lorsqu'un appel entrant arrive sur votre numéro principal, de faire sonner plusieurs lignes en même temps ou l'une après l'autre.

**Découvrez comment configurer intégralement une file d'appels.**
 
## Prérequis

- Disposer d'un [numéro alias](https://www.ovhcloud.com/fr/phone/numeros/) dans votre compte OVHcloud.

:::info
Une file d'appels ne peut être configurée **que sur un numéro alias**.
Consultez notre [FAQ](/guides/web-cloud/phone-and-fax/voip/faq-voip) pour plus d'informations sur les différences entre un numéro alias et une ligne SIP.

:::

## En pratique

### Étape 1 : Appliquer la configuration « File d'appels »

{/* CP-STEPS-START:apply-queue-config */}

- Si votre numéro n'est actuellement pas configuré, ouvrez sa page depuis la liste **Numéros**. Dans la section **Configuration**, cliquez sur <code className="action">Choisir une configuration</code>, sélectionnez <code className="action">File d'appels</code> dans la fenêtre **Changer la configuration**, puis cliquez sur <code className="action">Paramétrer</code>.

<img className="thumbnail" alt="Fenêtre Changer la configuration d'un numéro" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/change-config.png" loading="lazy" />

- Si votre numéro a déjà une configuration en place, ouvrez l'onglet <code className="action">Configuration</code> puis, depuis le menu <code className="action">Actions</code>, revenez à la fenêtre **Changer la configuration**. Sélectionnez <code className="action">File d'appels</code> et cliquez sur <code className="action">Paramétrer</code>. Vous devrez alors confirmer la perte de la configuration actuellement en place.

:::info
Pour appliquer le même type de configuration à plusieurs numéros, cochez la case **Appliquer à plusieurs numéros** en bas de la fenêtre **Changer la configuration**, sélectionnez les numéros concernés, puis cliquez sur <code className="action">Paramétrer</code>.
:::

<img className="thumbnail" alt="Menu Actions d'un numéro configuré" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/actions-menu.png" loading="lazy" />

{/* CP-STEPS-END:apply-queue-config */}

### Étape 2 : Paramétrer la file d'appels

{/* CP-STEPS-START:queue-config-menus */}

Depuis la console OVHcloud, ouvrez **Téléphonie** puis **Numéros** et sélectionnez le numéro configuré en file d'appels. Ouvrez l'onglet <code className="action">Configuration</code>. La page réunit la gestion des agents et, dans le menu <code className="action">Actions</code>, les quatre écrans de configuration de la file : **Paramètres de la file**, **Sons d'attente**, **Conditions horaires** et **Filtrage d'appels**.

<img className="thumbnail" alt="Menu Actions d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/actions-menu.png" loading="lazy" />

{/* CP-STEPS-END:queue-config-menus */}

Quatre menus principaux vous sont proposés :

|Menu|Détails|
|---|---|
|Gestion des lignes dans la file |Ce menu permet de gérer les membres de la file d'appels ainsi que divers paramètres de cette dernière. Ce paramétrage est obligatoire pour que la file d'appels puisse fonctionner.|
|Gestion des sons et de l'attente |Ce menu permet de personnaliser et améliorer l'expérience des personnes qui vous contactent. Ce paramétrage est facultatif mais néanmoins fortement conseillé.|
|Plages horaires et fermetures|Ce menu permet de définir les horaires d'ouverture (habituels ou exceptionnels) de votre file d'appels. Nous vous recommandons d'effectuer ce paramétrage.|
|Filtrage des appels|Ce menu permet de définir des listes blanches ou noires, afin d'autoriser uniquement certains correspondants à vous joindre ou, au contraire, de rejeter automatiquement les appels en provenance de certains numéros.|

#### 2.1 Gérer la file d'appels et ses lignes <a name="manage-lines"></a>

{/* CP-STEPS-START:manage-lines-entry */}

Depuis la console OVHcloud, ouvrez **Téléphonie** puis **Numéros** et sélectionnez le numéro configuré en file d'appels. Ouvrez l'onglet <code className="action">Configuration</code>. Le tableau liste les lignes membres de la file, avec leur **Type**, leur **Numéro**, leur **Nom**, la **Durée sonnerie**, le **Repos**, le nombre d'**Appels simultanés** et leur **Statut**.

<img className="thumbnail" alt="Tableau des lignes d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/queue-agents.png" loading="lazy" />

{/* CP-STEPS-END:manage-lines-entry */}

##### 1. Ajouter une ligne à la file

{/* CP-STEPS-START:add-line */}

Au-dessus du tableau des lignes, cliquez sur <code className="action">Ajouter une ligne</code> pour ajouter un nouveau membre à votre file d'appels.

<img className="thumbnail" alt="Tableau des lignes et bouton Ajouter une ligne" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/queue-agents.png" loading="lazy" />

La fenêtre **Ajouter une ligne à la file** s'ouvre. Complétez les informations demandées.

<img className="thumbnail" alt="Fenêtre Ajouter une ligne à la file" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/add-line.png" loading="lazy" />

|Option|Détails|
|---|---|
|Ligne|Il s'agit de la ligne que vous souhaitez ajouter en tant que membre de la file d'appels. Déroulez la liste pour afficher les lignes et numéros rattachés à votre compte : chaque entrée indique le nom de la ligne, son numéro et son groupe de facturation. Sélectionnez celle à ajouter. Ce champ est obligatoire.<br/><br/> Les lignes s'ajoutent une par une : répétez l'opération pour chaque membre supplémentaire.|
|Durée de sonnerie (secondes)|Permet de définir la durée pendant laquelle la ligne sonnera. Une fois ce temps écoulé, et selon la stratégie de sonnerie de la file, l'appel sera transmis à un autre membre. La valeur par défaut est de 20 secondes.|
|Temps de repos (secondes)|Permet de définir la durée pendant laquelle le membre ne prendra pas d'appel après avoir raccroché. La valeur par défaut est de 0 seconde.|
|Appels simultanés|Permet de définir le nombre d'appels simultanés que la ligne pourra recevoir depuis la file. La valeur par défaut est de 1.|

Une fois ces informations complétées, cliquez sur <code className="action">Ajouter</code> pour réaliser l'ajout. La ligne apparaît alors dans le tableau.

{/* CP-STEPS-END:add-line */}

:::warning
Comme précisé dans le menu de configuration, les conditions particulières suivantes s'appliquent :

- La législation interdit la redirection sur des numéros surtaxés.
- Un appel redirigé vers une destination non-comprise dans votre forfait vous sera facturé.
- Les redirections vers un numéro mobile ou une ligne externe à OVHcloud ne sont pas comprises dans les [forfaits VoIP](https://www.ovhcloud.com/fr/phone/voip/#offers). Elles sont donc facturées à la seconde, sauf dans le cadre des forfaits mobile à l’heure.

Consultez les [tarifs de la téléphonie OVHcloud](https://www.ovhtelecom.fr/telephonie/decouvrez/tarifs_telephonie.xml) pour plus de détails.

:::

##### 2. Configurer une stratégie d’appels

{/* CP-STEPS-START:call-strategy */}

Ouvrez le menu <code className="action">Actions</code> puis <code className="action">Paramètres de la file</code>. La fenêtre réunit le numéro présenté aux agents et la stratégie de distribution des appels.

<img className="thumbnail" alt="Fenêtre Paramètres de la file" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/queue-settings.png" loading="lazy" />

|Paramètre|Détails|
|---|---|
|Numéro à afficher|Numéro présenté à l'agent lorsque la file lui transmet un appel : **Numéro de la file**, **Les deux numéros** ou **Numéro de l'appelant**.|
|Stratégie de sonnerie|Ordre dans lequel les lignes sont sollicitées : **Selon l'ordre défini**, **Tous en même temps**, **Aléatoire**, **Temps de repos le plus long**, **Temps d'inactivité le plus long**, **Rotation (Round Robin)** ou **Cumul selon l'ordre défini**.|
|Appliquer les renvois d'appels des lignes|Détermine si les renvois configurés sur chaque ligne s'appliquent aux appels reçus via la file.|

Cliquez sur <code className="action">Enregistrer</code> pour appliquer vos choix.

{/* CP-STEPS-END:call-strategy */}

**Détails des stratégies proposées :**

|Stratégie|Détails|
|---|---|
|Tous en même temps|Tous les téléphones sonnent en même temps. Le premier qui décroche prend l’appel sur son poste.|
|Selon l'ordre défini dans la liste|Le premier téléphone de la file sonne, puis le second, etc.|
|Selon l'ordre défini dans la liste, cumulé|Le premier téléphone de la file d’attente sonne. Le deuxième sonne à son tour après quelques secondes, en même temps que le premier. Le troisième commence à sonner quelques secondes après, etc.|
|Le plus ancien à avoir raccroché|Les téléphones sonnent les uns après les autres en suivant toujours le même ordre.|
|Du plus disponible au moins disponible|Les téléphones sonneront suivant leur disponibilité depuis l’activation.|
|Selon une répartition de charge| Les téléphones sonneront suivant leur disponibilité depuis le dernier appel : le plus disponible en premier.|
|Aléatoire|Les téléphones sonnent les uns après les autres de manière aléatoire.|

##### 3. Organiser les lignes de la file d’appels

{/* CP-STEPS-START:order-lines */}

L'ordre des lignes détermine la distribution des appels lorsque la stratégie **Selon l'ordre défini** ou **Cumul selon l'ordre défini** est retenue.

Pour le modifier, utilisez les flèches de la première colonne du tableau : selon sa position, chaque ligne propose <code className="action">Monter</code>, <code className="action">Descendre</code>, ou les deux. Le changement est enregistré immédiatement.

<img className="thumbnail" alt="Flèches d'ordonnancement des lignes d'une file" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/queue-agents.png" loading="lazy" />

{/* CP-STEPS-END:order-lines */}

##### 4. Modifier ou supprimer une ligne 

{/* CP-STEPS-START:edit-delete-line */}

Dans le tableau, cliquez sur l'icône <code className="action">⋮</code> à droite de la ligne concernée, puis choisissez <code className="action">Modifier</code> pour ajuster ses paramètres, ou <code className="action">Supprimer</code> pour la retirer de la file.

<img className="thumbnail" alt="Menu Modifier ou Supprimer d'une ligne" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/line-actions.png" loading="lazy" />

Retirer une ligne de la file ne résilie pas la ligne : elle reste disponible dans vos produits de téléphonie.

{/* CP-STEPS-END:edit-delete-line */}

:::tip
**Connexion/déconnexion dans la file d'appels depuis un téléphone**

Lorsque vous appelez le numéro de la file d'appels depuis une ligne qui en est membre, un menu vocal vous propose de :

- taper `1` pour vous connecter à la file d'appels (ne fonctionne que si votre ligne était préalablement déconnectée de la file) ;
- taper `2` pour vous déconnecter de la file d'appels (ne fonctionne que si votre ligne était préalablement connectée à la file) ;
- taper `3` pour rejoindre la file d'appels et ainsi faire sonner ses membres.

Vous pouvez ainsi gérer à la volée, directement depuis votre téléphone, l'activation de votre ligne au sein de la file d'appels.

:::

#### 2.2 Gérer les sons et l'attente <a name="manage-sounds"></a>

{/* CP-STEPS-START:manage-sounds-entry */}

Ouvrez le menu <code className="action">Actions</code> puis <code className="action">Sons d'attente</code>. La fenêtre regroupe la configuration de l'attente, le débordement et la fermeture de la file.

<img className="thumbnail" alt="Fenêtre Sons d'attente d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/waiting-sounds.png" loading="lazy" />

{/* CP-STEPS-END:manage-sounds-entry */}

##### Configuration de l'attente

[[fragment:support-scope]]

:::warning
La création des annonces sonores est de votre responsabilité. En cas de difficultés, nous vous conseillons de faire appel à un [prestataire spécialisé](https://partner.ovhcloud.com/fr/) car OVHcloud ne sera pas en mesure de créer ces fichiers pour vous.

Sachez qu'il est possible de créer des fichiers-sons via le logiciel open source et gratuit [Audacity](https://www.audacityteam.org/).
Nous vous rappelons que l'utilisation d'une musique non libre d'utilisation commerciale nécessite de s'acquitter de droits de diffusion auprès des sociétés d'auteurs/compositeurs/producteurs.
:::

{/* CP-STEPS-START:waiting-sounds */}

Dans la partie **Configuration de l'attente**, vous pouvez définir deux sons :

- **Annonce avant mise en attente** : ce son est joué intégralement au correspondant avant son entrée dans la file d'attente, donc avant qu'une ligne ne sonne. Privilégiez une annonce courte, afin de ne pas retarder la prise d'appel.
- **Musique d'attente** : ce son est joué en boucle pendant que le correspondant patiente dans la file.

Chaque son propose une liste déroulante (**Aucune** par défaut) et un bouton <code className="action">Télécharger un son</code> permettant d'importer votre propre fichier.

<img className="thumbnail" alt="Configuration de l'attente d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/waiting-sounds.png" loading="lazy" />

{/* CP-STEPS-END:waiting-sounds */}

##### Configuration du débordement

{/* CP-STEPS-START:overflow-config */}

Dans la même fenêtre, le champ **Nombre maximum d'appelants en attente** définit combien de correspondants peuvent patienter simultanément dans la file.

Si ce nombre venait à être dépassé, la liste **Action à jouer** définit le comportement de débordement à adopter, parmi les deux possibilités suivantes :

- **Renvoyer sur un répondeur.** : le ou les appelants concernés par le débordement seront renvoyés vers le répondeur de votre choix. Sélectionnez cette action, puis désignez le répondeur d'une de vos lignes SIP.
- **Jouer une annonce de débordement.** : le ou les appelants concernés entendront l'annonce que vous avez définie, et l'appel sera ensuite raccroché. Sélectionnez cette action, puis importez votre fichier audio à l'aide du bouton <code className="action">Télécharger un son</code>.

<img className="thumbnail" alt="Configuration du débordement d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/waiting-sounds.png" loading="lazy" />

Cliquez enfin sur <code className="action">Enregistrer</code> en bas de la fenêtre pour confirmer les changements.

{/* CP-STEPS-END:overflow-config */}

##### Configuration de fermeture

{/* CP-STEPS-START:closing-config */}

Toujours dans la même fenêtre, le champ **Durée maximale d'attente dans la file** définit la durée pendant laquelle un appelant patientera dans la file.

Si cette durée venait à être dépassée, la liste **Action à jouer** définit le comportement à adopter, parmi deux possibilités :

- **Renvoyer sur un répondeur.** : le ou les appelants concernés seront renvoyés vers le répondeur de votre choix, à désigner parmi les répondeurs de vos lignes SIP.
- **Jouer une annonce de fermeture.** : le ou les appelants concernés entendront l'annonce que vous avez définie, et l'appel sera ensuite raccroché. Importez votre fichier audio à l'aide du bouton <code className="action">Télécharger un son</code>.

<img className="thumbnail" alt="Configuration de la fermeture d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/waiting-sounds.png" loading="lazy" />

Cliquez sur <code className="action">Enregistrer</code> pour appliquer l'ensemble des réglages de la fenêtre.

{/* CP-STEPS-END:closing-config */}

#### 2.3 Gérer les plages horaires et les fermetures <a name="manage-agenda"></a>

{/* CP-STEPS-START:agenda-entry */}

Ouvrez le menu <code className="action">Actions</code> puis <code className="action">Conditions horaires</code>. La page **Conditions horaires** s'ouvre : elle réunit l'activation, les créneaux, le calendrier hebdomadaire et les fermetures exceptionnelles.

<img className="thumbnail" alt="Page Conditions horaires d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/time-conditions.png" loading="lazy" />

{/* CP-STEPS-END:agenda-entry */}

##### 1. Activer ou désactiver les plages horaires

{/* CP-STEPS-START:agenda-toggle */}

En haut de la page, choisissez **Activer les conditions horaires** ou **Désactiver les conditions horaires**, selon que vous souhaitez ou non utiliser les plages horaires mises en place plus bas.

<img className="thumbnail" alt="Activation des conditions horaires" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/time-conditions.png" loading="lazy" />

:::warning
Si votre numéro est déjà en production, n'activez les conditions horaires qu'une fois vos plages horaires configurées : tant qu'aucune plage n'est définie, la file applique son comportement par défaut en dehors des créneaux.
:::

{/* CP-STEPS-END:agenda-toggle */}

##### 2. Configuration des créneaux horaires

{/* CP-STEPS-START:agenda-slots */}

La partie **Configuration des créneaux horaires** définit les scénarios que vous appliquerez ensuite au calendrier. Cinq créneaux sont disponibles, chacun identifié par une couleur : **Disponible** (comportement par défaut, ici « File d'appels »), **Indisponible**, puis **Créneau 1**, **Créneau 2** et **Créneau 3**.

Cliquez sur l'icône en forme d'engrenage à droite d'un créneau pour définir le comportement à appliquer pendant celui-ci. Un créneau non paramétré affiche **Non configuré**.

<img className="thumbnail" alt="Configuration des créneaux horaires" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/time-conditions.png" loading="lazy" />

{/* CP-STEPS-END:agenda-slots */}

##### 3. Définir les plages horaires

{/* CP-STEPS-START:agenda-ranges */}

Une fois les créneaux configurés à votre convenance, la partie **Gestion des plages horaires et des fermetures** de la page permet de définir des plages horaires et de leur attribuer un créneau.

Cliquez sur un horaire et modifiez la plage associée, ou cliquez sur l'horaire de début souhaité puis glissez en maintenant le clic jusqu'à l'horaire de fin. Le calendrier couvre les sept jours de la semaine, de 00 h à 23 h.

<img className="thumbnail" alt="Calendrier hebdomadaire des plages horaires" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/time-conditions.png" loading="lazy" />

Définissez ensuite le créneau à appliquer à la plage créée, puis validez son ajout.

Vous pouvez également **déplacer des plages existantes** : cliquez sur l'une d'elles et, en maintenant le clic, glissez-la dans le tableau des horaires. Pour **supprimer une plage**, cliquez sur celle-ci, puis sur l'action de suppression proposée.

Dès que toutes vos plages horaires sont configurées, enregistrez vos changements.

{/* CP-STEPS-END:agenda-ranges */}

##### 4. Définir des fermetures exceptionnelles

{/* CP-STEPS-START:exceptional-closures */}

Une fois les plages horaires créées à votre convenance, vous pouvez définir des fermetures exceptionnelles. Celles-ci permettent de fermer votre file d'appels sur des plages horaires normalement considérées comme ouvertes.

Dans la partie **Gestion des plages horaires et des fermetures**, cliquez sur <code className="action">Gérer les fermetures exceptionnelles</code>.

<img className="thumbnail" alt="Vue Fermetures exceptionnelles d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/exceptional-closures.png" loading="lazy" />

:::info
Les fermetures exceptionnelles complètent vos plages horaires paramétrées. Il est donc indispensable que ces dernières soient activées pour que les fermetures exceptionnelles soient prises en compte.
:::

Sur la vue qui apparaît, cliquez sur <code className="action">Ajouter un événement</code>, ou directement sur le jour concerné dans le calendrier. Complétez les informations demandées :

|Information|Description|
|---|---|
|Titre|Définissez un intitulé vous permettant d'identifier cette fermeture exceptionnelle.|
|Date de début|Définissez la date, et si nécessaire l'heure, à laquelle la fermeture commence.|
|Date de fin|Définissez la date, et si nécessaire l'heure, à laquelle la fermeture prend fin.|
|Catégorie|Choisissez le créneau qui redirigera les appels reçus pendant la fermeture. Si nécessaire, configurez les créneaux depuis la partie **Configuration des créneaux horaires** de la page **Conditions horaires**.|

<img className="thumbnail" alt="Fenêtre Ajouter un événement de fermeture exceptionnelle" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/add-event.png" loading="lazy" />

Cliquez sur <code className="action">Enregistrer</code>, puis répétez la manipulation pour chaque fermeture exceptionnelle à créer. Les boutons <code className="action">Mois</code>, <code className="action">Semaine</code> et <code className="action">Jour</code> changent la granularité du calendrier, et les flèches permettent de naviguer d'une période à l'autre.

{/* CP-STEPS-END:exceptional-closures */}

#### 2.4 Gérer le filtrage des appels <a name="manage-filters"></a>

{/* CP-STEPS-START:filters-entry */}

Ouvrez le menu <code className="action">Actions</code> puis <code className="action">Filtrage d'appels</code>. La page **Filtrage d'appels** permet de rejeter automatiquement une liste de numéros (liste noire) ou, à l'inverse, de n'accepter que certains numéros (liste blanche).

<img className="thumbnail" alt="Page Filtrage d'appels d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/calls-filtering.png" loading="lazy" />

{/* CP-STEPS-END:filters-entry */}

##### 1. Configurer les filtrages d'appels

{/* CP-STEPS-START:configure-filters */}

La partie **Configuration des filtrages** réunit deux réglages.

**Rejeter automatiquement les appels anonymes** : choisissez **Activé** ou **Désactivé**. Lorsque l'option est activée, un correspondant qui appelle sans présenter son numéro entend un message lui indiquant que vous n'acceptez pas ce type de communication.

**Activation du filtrage** : choisissez le mode appliqué aux appels entrants.

|Mode|Détails|
|---|---|
|Aucun filtrage|Tous les appels entrants sont acceptés.|
|Appels entrants refusés (liste noire)|Seuls les numéros que vous déclarez sont rejetés.|
|Appels entrants autorisés (liste blanche)|Seuls les numéros que vous déclarez sont acceptés ; tous les autres sont rejetés.|

Cliquez sur <code className="action">Appliquer</code> pour valider votre choix.

<img className="thumbnail" alt="Configuration des filtrages d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/calls-filtering.png" loading="lazy" />

{/* CP-STEPS-END:configure-filters */}

##### 2. Configurer et gérer les listes

{/* CP-STEPS-START:manage-lists */}

Sous la configuration des filtrages, la seconde partie de la page recense les numéros et les types de numéros déclarés. Tant qu'aucun élément n'a été ajouté, elle affiche **Aucune condition.**

<img className="thumbnail" alt="Liste des numéros filtrés d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/calls-filtering.png" loading="lazy" />

Cliquez sur <code className="action">Ajouter un numéro</code>, puis complétez les informations demandées :

### Gérer les enregistrements d'appels <a name="manage-records"></a>

{/* CP-STEPS-START:call-records */}

La configuration en file d'appels vous permet d'enregistrer les appels entrants. Les enregistrements sont automatiquement supprimés de nos serveurs au bout de 60 jours.

Ouvrez l'onglet <code className="action">Enregistrements</code> du numéro. La page **Gestion des enregistrements** s'affiche.

<img className="thumbnail" alt="Onglet Enregistrements d'une file d'appels" src="/images/web-cloud/phone-and-fax/voip/les-files-d-appels/console/call-records.png" loading="lazy" />

Dans la partie **Files d'appels**, sélectionnez la file concernée. La partie **Activation de l'enregistrement** réunit ensuite deux réglages :

- **Enregistrement des appels** : activez ce réglage pour enregistrer les appels entrants de la file. Cette activation vaut pour acceptation des [conditions particulières](https://www.ovh.com/fr/support/documents_legaux/conditions_particulieres_du_service_d_enregistrement_des_communications_telephoniques.pdf) d'utilisation du service d'enregistrement des communications téléphoniques.
- **Demande de non-enregistrement** : activez ce réglage pour laisser à vos appelants la possibilité de ne pas être enregistrés, puis choisissez la touche qu'ils devront composer pour cela.

Validez vos choix en cliquant sur <code className="action">Appliquer</code>.

La partie **Liste des enregistrements** présente ensuite les enregistrements disponibles pour la file sélectionnée, et permet de les télécharger ou de les supprimer. Tant qu'aucun appel n'a été enregistré, elle affiche **Aucun enregistrement trouvé**.
