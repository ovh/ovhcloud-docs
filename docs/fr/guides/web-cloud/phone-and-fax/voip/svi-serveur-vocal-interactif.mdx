## Objectif

Configurer un numéro en Serveur Vocal Interactif (SVI) permet de proposer à vos correspondants un menu avec lequel ils pourront interagir, grâce aux touches de leurs téléphones.

L'exemple le plus courant consiste à orienter un appelant entre plusieurs services d'une société : « *Appuyez sur la touche 1 pour une demande commerciale ou sur la touche 2 pour une demande technique* ».

**Découvrez comment configurer un serveur vocal interactif depuis l'espace client OVHcloud.**

## Prérequis

- Disposer d'un [numéro alias](https://www.ovhcloud.com/fr/phone/numeros/).

## En pratique

### Étape 1 : Appliquer la configuration « Serveur Vocal Interactif »

{/* CP-STEPS-START:appliquer-configuration-svi */}

- Si votre numéro n'est actuellement pas configuré, depuis l'onglet <code className="action">Vue d'ensemble</code>, cliquez sur <code className="action">Choisir une configuration</code> dans la section **Configuration**. Dans le panneau qui s'affiche, sélectionnez **Serveur Vocal Interactif** puis cliquez sur <code className="action">Paramétrer</code>.

- Si votre numéro a déjà une configuration en place, depuis l'onglet <code className="action">Vue d'ensemble</code>, cliquez sur <code className="action">Changer la configuration</code> dans la section **Configuration**. Dans le panneau **Changer la configuration**, sélectionnez **Serveur Vocal Interactif** puis cliquez sur <code className="action">Paramétrer</code>.

:::warning
Le changement de configuration remplace la configuration actuellement en place, qui sera perdue.
:::

<img className="thumbnail" alt="Panneau Changer la configuration avec l'option Serveur Vocal Interactif sélectionnée" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/svi-1-2026.png" loading="lazy" />

:::info
Pour appliquer le même type de configuration à plusieurs numéros, cochez la case **Appliquer à plusieurs numéros** dans le panneau **Changer la configuration**, choisissez le **Groupe de facturation** puis sélectionnez les numéros concernés dans la liste.

<img className="thumbnail" alt="Case Appliquer à plusieurs numéros cochée et choix du groupe de facturation" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/selection-alias-conf.png" loading="lazy" />

Cliquez sur le bouton <code className="action">Paramétrer</code> et patientez quelques instants pendant l'application du paramétrage.

Si vous appliquez le même type de configuration à plusieurs numéros, vous devrez finaliser la configuration sur chacun des numéros concernés.

:::

{/* CP-STEPS-END:appliquer-configuration-svi */}

### Étape 3 : Configurer le serveur vocal interactif

Les étapes suivantes peuvent être suivies sans ordre particulier. Néanmoins, à des fins de facilité de prise en main, nous vous recommandons de suivre l'ordre ci-dessous.

#### 3.1 Gérer les sons

**L'ajout d'un son d'accueil est la première étape indispensable pour créer votre SVI**. Ce son d'accueil sera joué dès le début de l'appel. Il précise à l'appelant les différents choix offerts par les touches.

Vous pouvez ajouter plusieurs sons si vous souhaitez créer des choix de touches successifs. En effet, il vous faudra alors un son par menu interactif.

Nous vous conseillons également de créer un son dédié aux actions invalides. Ainsi, si un appelant compose une touche que vous n'avez pas configurée, un son peut lui rappeler les choix de touches possibles.

:::warning
La création des fichiers-sons est à votre charge. Nous vous conseillons de faire appel à un [prestataire spécialisé](https://partner.ovhcloud.com/fr/) car OVHcloud ne sera pas en mesure de créer ces fichiers pour vous.

Sachez qu'il est également possible de créer des fichiers-sons via le logiciel open source et gratuit [Audacity](https://www.audacityteam.org/).

:::

{/* CP-STEPS-START:gerer-sons */}

Dans l'onglet <code className="action">Configuration</code>, cliquez sur <code className="action">Gérer les sons</code> au-dessus du schéma. Le panneau **Sons** liste les sons déjà ajoutés : le bouton `⋮` situé à droite de chacun d'eux permet de l'écouter ou de le supprimer.

Cliquez alors sur <code className="action">Ajouter un son</code> pour téléverser un son depuis votre poste. Glissez votre fichier dans la zone prévue à cet effet ou cliquez sur celle-ci pour le sélectionner (10 Mo maximum, formats wav, mp3, ogg et wma).

<img className="thumbnail" alt="Panneau Envoyer un son avec la zone de dépôt du fichier" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/gerer-sons-svi.png" loading="lazy" />

Vérifiez ensuite le champ **Nom du fichier**, pré-rempli à partir du nom de votre fichier : il ne peut contenir que des lettres, des chiffres, des espaces et des tirets bas. Cliquez enfin sur <code className="action">Envoyer</code>.

{/* CP-STEPS-END:gerer-sons */}
#### 3.2 Créer un menu interactif <a name="creer-menu-interactif"></a>

{/* CP-STEPS-START:creer-menu-interactif */}

Dans l'onglet <code className="action">Configuration</code>, cliquez sur <code className="action">Gérer les menus interactifs</code> au-dessus du schéma.

<img className="thumbnail" alt="Panneau Menus interactifs ouvert depuis le bouton Gérer les menus interactifs" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/gerer-menus-svi.png" loading="lazy" />

Dans le panneau **Menus interactifs** qui s'affiche, cliquez sur <code className="action">Ajouter un menu</code>.

<img className="thumbnail" alt="Formulaire Ajouter un menu dans le panneau Menus interactifs" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/svi-menu-creation.png" loading="lazy" />

Le formulaire de création s'affiche dans le même panneau. Complétez les informations demandées :

|Information|Description|
|---|---|
|Nom|Définissez un nom pour ce menu interactif.|
|Timeout (s)|Définissez, en secondes, le délai d'attente de la saisie de l'appelant.|
|Délai inter-touches (ms)|Définissez, en millisecondes, le délai maximal entre deux touches lorsque l'appelant compose plusieurs chiffres.|
|Son d'accueil|Sélectionnez le son qui sera joué dès le début de l'appel. Celui-ci précise à l'appelant les différents choix offerts par les touches.|
|Son d'erreur|Choisissez le son qui sera joué si l'appelant appuie sur une touche non reconnue par le serveur vocal interactif.|

Une fois les informations renseignées, cliquez sur <code className="action">Ajouter</code>.

{/* CP-STEPS-END:creer-menu-interactif */}
#### 3.3 Ajouter des entrées dans le menu interactif

{/* CP-STEPS-START:ajouter-entrees-menu-interactif */}

Une fois votre menu interactif créé, vous pouvez y ajouter des entrées. Pour cela, dans le panneau **Menus interactifs**, cliquez sur le bouton `⋮` situé à droite du menu concerné, puis sur <code className="action">Voir les entrées</code>. Cliquez ensuite sur <code className="action">Ajouter une entrée</code>.

<img className="thumbnail" alt="Formulaire Ajouter une entrée avec le clavier de touches DTMF" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/svi-menu-creation-entree.png" loading="lazy" />

Dans le formulaire qui s'affiche, complétez les informations demandées :

|Information|Description|
|---|---|
|Touche DTMF|Sélectionnez sur le clavier la touche d'entrée du menu que vous souhaitez configurer. Pour définir une combinaison de plusieurs touches, cochez la case **DTMF personnalisé (multi-touches)**.|
|Action|Sélectionnez l'action qui se réalisera lorsque l'appelant appuiera sur la touche correspondante : **Pont (appel direct)**, **Sous-menu**, **Menu précédent**, **Quitter le menu**, **Menu principal**, **Lecture audio**, **Lire DTMF** ou **Définir nom appelant**.|
|Paramètre d'action supplémentaire|Selon l'action que vous avez définie, une case supplémentaire peut apparaître et vous inviter à renseigner un élément complémentaire (par exemple un **Numéro de téléphone** pour l'action **Pont (appel direct)**). Suivez alors les indications qui s'affichent.|

Une fois les informations complétées, cliquez sur <code className="action">Ajouter</code>. L'entrée apparaît dans la liste des entrées du menu.

<img className="thumbnail" alt="Liste des entrées d'un menu interactif" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/svi-sous-menu.png" loading="lazy" />

Selon vos besoins, répétez ces manipulations si vous voulez créer plusieurs menus interactifs. Vous pourrez alors les imbriquer dans votre serveur vocal interactif en tant que sous-menus, à l'aide de l'action **Sous-menu**, si vous souhaitez par exemple réaliser plusieurs embranchements.

{/* CP-STEPS-END:ajouter-entrees-menu-interactif */}
### Étape 4 : Configurer les étapes et actions

{/* CP-STEPS-START:retour-configuration-numero */}

Une fois vos menus interactifs créés, fermez le panneau **Menus interactifs** à l'aide de l'icône en forme de croix, en haut à droite, pour revenir au schéma de configuration.

{/* CP-STEPS-END:retour-configuration-numero */}
Vous devez à présent créer des étapes pour déclencher vos menus interactifs selon vos besoins. Vous pourrez par exemple définir des périodes de disponibilité (plages horaires) et les actions à déclencher en dehors de ces périodes.

#### 4.1 Créer une étape

{/* CP-STEPS-START:creer-etape */}

Pour créer une première étape, cliquez sur <code className="action">Ajouter une étape</code>, sous les étapes du schéma. L'étape est créée immédiatement.

<img className="thumbnail" alt="Bouton Ajouter une étape sur le schéma de configuration" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/svi-etape2021.png" loading="lazy" />

{/* CP-STEPS-END:creer-etape */}
{/* CP-STEPS-START:reordonner-etapes-actions */}

:::info
Pour réordonner les étapes et actions de votre plan de configuration, sélectionnez l'étape ou l'action concernée sur le schéma.

Dans sa barre d'outils, utilisez l'icône en forme de flèche vers le haut pour la déplacer avant l'élément précédent, ou l'icône en forme de flèche vers le bas pour la déplacer après l'élément suivant. Chaque déplacement est enregistré immédiatement.

:::

{/* CP-STEPS-END:reordonner-etapes-actions */}
#### 4.2 Ajouter une action à une étape

Les actions ajoutées à une étape s'activent lorsqu'un appelant contacte votre numéro.

{/* CP-STEPS-START:ajouter-action */}

Pour ajouter une action à une étape, sélectionnez l'étape concernée sur le schéma, puis cliquez sur l'icône **+** de sa barre d'outils.

<img className="thumbnail" alt="Formulaire Ajouter une action ouvert depuis la barre d'outils d'une étape" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/svi-action2021.png" loading="lazy" />

Dans le formulaire **Ajouter une action**, complétez les informations demandées :

|Information|Description|
|---|---|
|Action|Définissez l'action qui sera effectuée lorsque l'appelant contactera votre numéro : **Pont (appel direct)**, **Lecture en boucle**, **Raccrocher**, **Menu interactif**, **Lecture audio**, **Lire DTMF**, **Définir nom appelant**, **Attente** ou **Messagerie vocale**.<br/><br/> Afin de pouvoir utiliser un menu interactif ([créé lors de l'étape 3.2](#creer-menu-interactif)), vous devez sélectionner l'action « Menu interactif », puis choisir le menu concerné dans la liste **Menu interactif**.|
|Paramètre d'action supplémentaire|Selon l'action que vous avez définie, une case supplémentaire peut apparaître et vous inviter à renseigner un élément complémentaire. Suivez alors les indications qui s'affichent.|
|Action de repli|Cochez cette case pour que l'action soit exécutée lorsque les conditions de l'étape ne sont pas remplies.|

Une fois les informations complétées, cliquez sur <code className="action">Ajouter</code>.

<img className="thumbnail" alt="Action Menu interactif sélectionnée avec le menu Menu principal" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/svi-action2021b.png" loading="lazy" />

Selon vos besoins, répétez ces manipulations si vous souhaitez créer plusieurs actions dans une étape.

#### 4.3 Ajouter une condition à une étape

Lorsqu'une ou plusieurs conditions sont ajoutées à une étape, celles-ci doivent être remplies pour que l'étape se déclenche. Si les conditions ne sont pas remplies, soit une action correspondant aux **conditions non-vérifiées** se déclenche, soit l'étape suivante de votre plan de configuration se déclenche.

:::tip
Vous pouvez ainsi faire en sorte que votre SVI se déclenche uniquement lors de vos horaires d'ouverture. En dehors de ces horaires, vous pouvez, par exemple, diffuser un son rappelant les horaires d'ouverture de votre entreprise ou déclencher le [répondeur d'une ligne SIP OVHcloud](/guides/web-cloud/phone-and-fax/voip/configurer-consulter-repondeur-ligne-ovh).

:::

{/* CP-STEPS-START:ajouter-condition */}

Pour ajouter une condition à une étape, sélectionnez l'étape concernée sur le schéma, puis cliquez sur l'icône en forme d'engrenage de sa barre d'outils.

<img className="thumbnail" alt="Icône en forme d'engrenage dans la barre d'outils d'une étape" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/svi-conditions2021.png" loading="lazy" />

La fenêtre **Configuration avancée** qui apparaît vous permet de définir jusqu'à trois types de conditions : **Jours exceptionnels**, **Plages horaires génériques** et **Filtrages d'appels**.

<img className="thumbnail" alt="Fenêtre Configuration avancée avec les trois types de conditions" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/svi-conditions2021b.png" loading="lazy" />

Une fois vos conditions créées, vous pouvez définir une ou plusieurs action(s) correspondant aux conditions non vérifiées : lors de l'ajout d'une action à l'étape, cochez la case **Action de repli**. Ces actions seront alors prises en compte pour les appels ne remplissant pas les conditions.

Ainsi, dans l'exemple ci-dessous, un appel pendant les plages horaires définies pour l'étape 1 lancera le menu interactif nommé « Menu principal ».

Un appel en dehors de ces plages horaires sera réceptionné sur le répondeur d'une ligne SIP OVHcloud, défini comme action de repli.

<img className="thumbnail" alt="Exemple d'étape avec un menu interactif et une action de repli vers un répondeur" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/exemple-svi-plages2021.png" loading="lazy" />

{/* CP-STEPS-END:ajouter-condition */}

##### **Condition de « Jours exceptionnels »** <a name="jours-exceptionnels"></a>

{/* CP-STEPS-START:condition-jours-exceptionnels */}

Après avoir cliqué sur <code className="action">Jours exceptionnels</code> dans la fenêtre **Configuration avancée**, choisissez le créneau que vous souhaitez appliquer (**Horaires de fermeture**, **Créneau 1**, **Créneau 2** ou **Créneau 3**), puis cliquez sur <code className="action">Enregistrer</code>.

<img className="thumbnail" alt="Choix du créneau à appliquer dans Jours exceptionnels" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/creneaux-activation2021.png" loading="lazy" />

Vous devez à présent configurer le créneau que vous venez de sélectionner (ou vous assurer que celui-ci l'est correctement). Pour cela, cliquez sur <code className="action">Gérer les créneaux exceptionnels</code> au-dessus du schéma.

<img className="thumbnail" alt="Bouton Gérer les créneaux exceptionnels au-dessus du schéma" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/svi-creneaux2021.png" loading="lazy" />

La page **Créneaux exceptionnels** apparaît alors, avec un calendrier de vos fermetures exceptionnelles. Cliquez sur <code className="action">Ajouter un créneau</code> et complétez les informations demandées :

|Information|Description|
|---|---|
|Titre|Définissez un titre vous permettant d'identifier cette fermeture exceptionnelle dans le calendrier.|
|Date de début / Date de fin|Définissez la date et l'heure de début et de fin de la fermeture exceptionnelle.|
|Catégorie|Choisissez le créneau dans lequel vous souhaitez ajouter la fermeture exceptionnelle.|

Une fois les informations renseignées, cliquez sur <code className="action">Enregistrer</code> : la fermeture exceptionnelle est enregistrée immédiatement. Répétez cette manipulation afin d'ajouter toutes les fermetures exceptionnelles nécessaires.

<img className="thumbnail" alt="Formulaire Ajouter un créneau sur la page Créneaux exceptionnels" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/creneaux2021.png" loading="lazy" />

{/* CP-STEPS-END:condition-jours-exceptionnels */}
##### **Condition de « Plages horaires génériques »** <a name="plages-horaires"></a>

{/* CP-STEPS-START:condition-plages-horaires */}

Après avoir cliqué sur <code className="action">Plages horaires génériques</code> dans la fenêtre **Configuration avancée**, cliquez sur <code className="action">Ajouter des plages horaires</code>.

Configurez maintenant les plages horaires qui correspondent à vos besoins. Pour cela, sélectionnez les jours concernés puis renseignez les horaires dans les cases prévues à cet effet. Cliquez sur l'icône en forme de coche, à droite, pour enregistrer la plage.

Une fois toutes vos plages horaires définies, cliquez sur le bouton <code className="action">Enregistrer</code> pour les valider.

<img className="thumbnail" alt="Plages horaires génériques avec une plage du lundi au vendredi" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/plages-svi2021.png" loading="lazy" />

:::info
Pour modifier une plage horaire déjà créée, il est nécessaire de la supprimer puis de créer une nouvelle plage horaire.

:::

{/* CP-STEPS-END:condition-plages-horaires */}
##### **Double condition : « Jours exceptionnels » et « Plages horaires génériques »**

{/* CP-STEPS-START:double-condition */}

Pour obtenir une configuration contenant à la fois des jours exceptionnels et des plages horaires génériques, il convient de placer les jours exceptionnels sur l'étape 1 et les plages horaires génériques sur l'étape 2.

En effet, le système lit les étapes dans l'ordre : si les conditions de l'étape 1 sont remplies, les actions associées à cette étape sont exécutées. Dans le cas contraire, le système passe automatiquement à l'étape 2.

<img className="thumbnail" alt="Schéma de configuration avec deux étapes" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/svi-double-condition.png" loading="lazy" />

{/* CP-STEPS-END:double-condition */}
##### **Condition de « Filtrages d'appels »** <a name="filtrages-appels"></a>

{/* CP-STEPS-START:condition-filtrages-appels */}

Après avoir cliqué sur <code className="action">Filtrages d'appels</code> dans la fenêtre **Configuration avancée**, choisissez dans le menu déroulant **Type de liste** si vous souhaitez filtrer vos appels entrants selon une « liste noire » ou une « liste blanche ».

|Liste|Description|
|---|---|
|Liste noire|Les numéros ou les tranches de numéros inscrits dans la liste ne peuvent plus vous contacter.|
|Liste blanche|**Seuls** les numéros ou les tranches de numéros inscrits dans la liste sont autorisés à vous contacter.|

Une fois que vous avez sélectionné la liste que vous souhaitez utiliser, complétez-la en ajoutant les numéros ou les tranches de numéros adéquats. Pour cela, utilisez le champ **Ajouter un numéro à la liste**, puis cliquez sur le bouton <code className="action">Ajouter</code>. Vous pouvez supprimer une entrée de la **Liste des numéros** grâce à l'icône de suppression située à sa droite.

Pour enregistrer vos modifications, cliquez sur <code className="action">Enregistrer</code>.

<img className="thumbnail" alt="Filtrages d'appels avec une liste noire et un numéro ajouté" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/console/filtrages2021.png" loading="lazy" />
