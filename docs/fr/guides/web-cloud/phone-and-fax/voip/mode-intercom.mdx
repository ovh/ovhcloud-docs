## Objectif

Votre ligne téléphonique vous permet de recevoir et d'émettre des appels. Un mode, que vous pouvez activer dans votre espace client, permet à votre ligne de décrocher automatiquement un appel en haut-parleur lorsque celle-ci est contactée avec un préfixe à quatre chiffres.

**Découvrez comment gérer le mode intercom de votre ligne OVHcloud.**

## Prérequis

- Disposer d'une offre de téléphonie SIP.
- Disposer d'un téléphone ou d'un équipement compatible avec le mode intercom.

## En pratique

### Étape 1 : accéder à la gestion du mode intercom

{/* CP-STEPS-START:acceder-gestion-mode-intercom */}

Cliquez sur l'onglet <code className="action">Paramètres de ligne</code>. Le mode intercom se règle dans la section **Paramètres d'appel**, à la ligne **Mode Intercom**.

<img className="thumbnail" alt="Section Paramètres d'appel de l'onglet Paramètres de ligne avec la ligne Mode Intercom" src="/images/web-cloud/phone-and-fax/voip/mode-intercom/console/mode-intercom-step1.png" loading="lazy" />

{/* CP-STEPS-END:acceder-gestion-mode-intercom */}

### Étape 2 : gérer le mode intercom

{/* CP-STEPS-START:gerer-mode-intercom */}

Dans la section **Paramètres d'appel**, vous pouvez réaliser deux actions selon l'état d'activation du mode intercom. Le mode intercom s'applique aux appels composés avec le préfixe 3691.

{/* CP-STEPS-END:gerer-mode-intercom */}

Poursuivez la lecture de cette documentation selon la manipulation que vous souhaitez réaliser.

#### Activer le mode intercom

{/* CP-STEPS-START:activer-mode-intercom */}

Pour activer le mode intercom, activez l'interrupteur **Mode Intercom**. La modification est enregistrée immédiatement.

Si vous souhaitez activer ce mode sur plusieurs lignes, activez-le d'abord sur la ligne en cours : la configuration en masse applique aux autres lignes l'état actuel de cette ligne. Cliquez ensuite sur l'onglet <code className="action">Vue d'ensemble</code> puis, dans la section **Informations générales**, sous **Configuration en masse**, cliquez sur <code className="action">Copier vers d'autres services</code>. Dans le panneau **Appliquer la configuration à d'autres services** qui s'ouvre :

- sous **Fonctionnalités**, déployez **Paramètres de ligne** et sélectionnez **Intercom** ;
- sous **Services cibles**, choisissez les lignes concernées, dans **Groupe actuel** ou **Tous les groupes** ;
- vérifiez le **Résumé**, puis cliquez sur le bouton <code className="action">Appliquer à N service(s)</code>, N étant le nombre de lignes sélectionnées.

<img className="thumbnail" alt="Panneau Appliquer la configuration à d'autres services avec la fonctionnalité Intercom sélectionnée" src="/images/web-cloud/phone-and-fax/voip/mode-intercom/console/mode-intercom-step2.png" loading="lazy" />

{/* CP-STEPS-END:activer-mode-intercom */}

#### Désactiver le mode intercom

{/* CP-STEPS-START:desactiver-mode-intercom */}

Pour désactiver le mode intercom, désactivez l'interrupteur **Mode Intercom**. La modification est enregistrée immédiatement.

Si vous souhaitez désactiver ce mode sur plusieurs lignes, désactivez-le d'abord sur la ligne en cours : la configuration en masse applique aux autres lignes l'état actuel de cette ligne. Cliquez ensuite sur l'onglet <code className="action">Vue d'ensemble</code> puis, dans la section **Informations générales**, sous **Configuration en masse**, cliquez sur <code className="action">Copier vers d'autres services</code>. Dans le panneau **Appliquer la configuration à d'autres services** qui s'ouvre :

- sous **Fonctionnalités**, déployez **Paramètres de ligne** et sélectionnez **Intercom** ;
- sous **Services cibles**, choisissez les lignes concernées, dans **Groupe actuel** ou **Tous les groupes** ;
- vérifiez le **Résumé**, puis cliquez sur le bouton <code className="action">Appliquer à N service(s)</code>, N étant le nombre de lignes sélectionnées.

<img className="thumbnail" alt="Panneau Appliquer la configuration à d'autres services avec la fonctionnalité Intercom sélectionnée" src="/images/web-cloud/phone-and-fax/voip/mode-intercom/console/mode-intercom-step2.png" loading="lazy" />

{/* CP-STEPS-END:desactiver-mode-intercom */}

### Étape 3 : utiliser le mode intercom

Une fois le mode intercom activé, communiquez aux correspondants souhaités le numéro permettant de joindre votre ligne en mode intercom. Ce dernier se compose du préfixe que vous avez pu récupérer lors de l'étape précédente, ainsi que du numéro de ligne pour lequel le mode a été activé (par exemple : 36913100000000).

Sachez également que le mode intercom peut également être utilisé si vous souhaitez équiper votre installation d'un portier IP. Pour cela, vous devrez simplement configurer ce dernier pour qu'il appelle en mode intercom votre ligne (par le biais du numéro composé notamment du préfixe). Pour configurer votre propre équipement, consultez sa documentation ou contactez son constructeur.
