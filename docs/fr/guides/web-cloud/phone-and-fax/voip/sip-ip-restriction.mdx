## Objectif

La téléphonie sur IP utilise le web pour transmettre des communications. Elle capte des conversations voix, les transforme en données, pour finalement les transmettre à un interlocuteur. Du fait de son côté connecté, il est fortement conseillé de sécuriser votre téléphonie sur IP, surtout si celle-ci fait partie intégrante de votre activité d'entreprise.

**Découvrez comment sécuriser l’accès à vos lignes SIP grâce à une restriction par IP.**

## Prérequis

- Disposer d'une [ligne SIP OVHcloud](https://www.ovhcloud.com/fr/phone/voip/) (Découverte ou Entreprise).
- Connaître ses adresses IP publiques ou être en mesure de les récupérer.

## En pratique

Une solution fiable pour sécuriser votre téléphonie sur IP est de restreindre son utilisation à une ou plusieurs adresses IP publiques. Seules les adresses IP autorisées pourront alors utiliser vos lignes.

### Étape 1 : configurer la restriction par IP

{/* CP-STEPS-START:etape-1-configurer-restriction */}

Si vous souhaitez appliquer la configuration à plusieurs lignes SIP, la marche à suivre vous est indiquée dans la suite de ce guide. Pour le moment, sélectionnez la ligne SIP pour laquelle vous voulez appliquer la modification.

Une fois la ligne SIP sélectionnée, cliquez sur l'onglet <code className="action">Paramètres</code>, puis sur le sous-onglet <code className="action">Paramètres de ligne</code>. Sur une ligne sans fax, l'onglet s'intitule directement <code className="action">Paramètres de ligne</code>. Les restrictions par IP se trouvent dans la section **Sécurité et blocage** de cette page.

<img className="thumbnail" alt="securiser-sip" src="/images/web-cloud/phone-and-fax/voip/secure-sip-line-ovh/console/restriction01.png" loading="lazy" />

La section **Sécurité et blocage** présente deux listes de restrictions :

- **Restrictions de ligne** : les adresses IP ou plages d'IP autorisées pour la seule ligne SIP sélectionnée. Chaque restriction de la liste peut être modifiée avec <code className="action">Modifier</code> ou supprimée avec <code className="action">Supprimer</code>.
- **Restrictions de compte** : les adresses IP ou plages d'IP associées à votre code client OVHcloud.

:::info
Les restrictions de compte sont utilisées lors de l'installation des nouvelles lignes commandées avec votre code client OVHcloud.
:::

Pour ajouter une restriction, cliquez sur le lien <code className="action">Ajouter une restriction IP</code> en bas de la section. Dans la fenêtre **Ajouter une restriction IP** qui s'ouvre :

1. Sous **Cible**, choisissez <code className="action">Ligne</code> pour une restriction qui s'applique uniquement à la ligne sélectionnée, ou <code className="action">Compte</code> pour une restriction associée à votre code client.
2. Dans le champ **Sous-réseau**, renseignez l'adresse IP ou la plage d'IP concernée.
3. Cliquez sur <code className="action">Ajouter</code>.

:::info
Lors de la complétion, utilisez le format **XXX.XXX.XXX.XXX/32** pour une adresse IP publique et le format **XXX.XXX.XXX.XXX/29** pour une plage d'adresses IP.
:::

Chaque restriction est ajoutée individuellement : répétez l'opération pour chaque adresse IP ou plage d'IP à autoriser.

<img className="thumbnail" alt="securiser-sip" src="/images/web-cloud/phone-and-fax/voip/secure-sip-line-ovh/console/restriction02.png" loading="lazy" />

Pour répliquer les restrictions de la ligne sélectionnée sur d'autres lignes, cliquez sur l'onglet <code className="action">Vue d'ensemble</code> de la ligne, puis, dans la section **Configuration en masse**, cliquez sur <code className="action">Copier vers d'autres services</code>. Dans le panneau **Appliquer la configuration à d'autres services** qui s'ouvre, déployez **Paramètres**, puis **Paramètres de ligne**, et sélectionnez **Restrictions IP**. Cette option n'est proposée que pour une ligne qui possède déjà des restrictions IP.

<img className="thumbnail" alt="securiser-sip" src="/images/web-cloud/phone-and-fax/voip/secure-sip-line-ovh/console/restriction03.png" loading="lazy" />
