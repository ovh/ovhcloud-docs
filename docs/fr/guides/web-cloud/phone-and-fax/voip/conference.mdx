## Objectif

La conférence permet à toutes les personnes composant un numéro donné d’être en communication simultanément. Différentes fonctionnalités sont alors disponibles :

- protéger la conférence par un code ;
- définir une annonce personnalisée ;
- enregistrer les participants et recevoir un rapport par e-mail à la fin de la conférence. 

Une interface spécifique vous propose également de suivre en temps réel les discussions des participants, mais aussi de gérer leur audio et leur micro.

**Découvrez comment créer et gérer des conférences téléphoniques avec votre numéro OVHcloud.**

## Prérequis

- Disposer d'un [numéro alias](https://www.ovhcloud.com/fr/phone/numeros/).

## En pratique

### Étape 1 : Appliquer la configuration « Conférence »

{/* CP-STEPS-START:appliquer-configuration-conference */}

Sur la page de votre numéro, rendez-vous dans la section **Configuration** de l'onglet <code className="action">Vue d'ensemble</code>.

- Si votre numéro n'est actuellement pas configuré, cliquez sur <code className="action">Choisir une configuration</code>.

- Si votre numéro a déjà une configuration en place, cliquez sur <code className="action">Changer la configuration</code>. La configuration actuellement en place sera perdue lorsque vous appliquerez la configuration **Conférence**.

Dans le panneau **Changer la configuration**, sélectionnez <code className="action">Conférence</code> puis cliquez sur <code className="action">Paramétrer</code>.

L'application de la configuration prend quelques secondes.

<img className="thumbnail" alt="panneau Changer la configuration avec le type Conférence sélectionné pour un numéro non configuré" src="/images/web-cloud/phone-and-fax/voip/conference/console/conference2026-01.png" loading="lazy" />

:::info

Pour appliquer le même type de configuration à plusieurs numéros, cochez la case <code className="action">Appliquer à plusieurs numéros</code> dans le panneau **Changer la configuration**. Choisissez ensuite le **Groupe de facturation**, puis sélectionnez les numéros concernés dans la liste **Appliquer à plusieurs numéros**.

<img className="thumbnail" alt="case Appliquer à plusieurs numéros cochée avec le groupe de facturation et deux numéros sélectionnés" src="/images/web-cloud/phone-and-fax/voip/conference/console/selection-alias-conf.png" loading="lazy" />

Cliquez sur le bouton <code className="action">Paramétrer</code> et patientez quelques instants pendant l'application du paramétrage.

Si vous appliquez le même type de configuration à plusieurs numéros, vous devrez finaliser la configuration sur chacun des numéros concernés.

:::

{/* CP-STEPS-END:appliquer-configuration-conference */}


### Étape 2 : Accéder à la configuration de la conférence

{/* CP-STEPS-START:acceder-configuration-conference */}

Une fois la configuration appliquée, les paramètres de la conférence se trouvent dans l'onglet <code className="action">Configuration</code> de votre numéro, section **Conférence**.

Pour retrouver ces paramètres ultérieurement, cliquez sur l'onglet <code className="action">Configuration</code>. Vous pouvez également cliquer sur <code className="action">Paramétrer la configuration</code> dans la section **Configuration** de l'onglet <code className="action">Vue d'ensemble</code>.

{/* CP-STEPS-END:acceder-configuration-conference */}

### Étape 3 : Gérer les paramètres de la conférence

#### Configurer la conférence

{/* CP-STEPS-START:configurer-conference */}

Dans la section **Conférence**, définissez les paramètres de la conférence.

<img className="thumbnail" alt="section Conférence de l'onglet Configuration avec le code PIN, l'annonce personnalisée et la langue" src="/images/web-cloud/phone-and-fax/voip/conference/console/conference2022-02.png" loading="lazy" />

|Paramètres|Description|
|---|---|
|Code PIN d'accès|Le code PIN défini devra être renseigné lorsqu'un participant rejoindra la conférence. Celui-ci doit être compris entre 1 et 8 chiffres. Indiquez « 0 » ou laissez la case vide pour ne pas utiliser de code PIN.|
|Annonce personnalisée|Permet de personnaliser l'annonce d'entrée d'un nouveau participant dans la conférence. Pour cela, déposez votre fichier audio dans la zone **Glissez un fichier ici ou cliquez pour parcourir**. Les formats acceptés sont .aiff, .au, .flac, .ogg, .mp3, .wav et .wma.|
|Enregistrement de la conférence|Permet d'activer ou non l'enregistrement des conférences réalisées sur le numéro.|
|Microphone des participants à l'entrée|Permet d'activer ou de rendre muet le microphone des participants lorsqu'ils rejoignent la conférence.|
|Appels anonymes|Permet d'autoriser ou d'interdire l'accès à la conférence aux numéros anonymes.|
|Langue de votre conférence|Permet de définir la langue de la conférence parmi plusieurs options.|

Cliquez enfin sur le bouton <code className="action">Enregistrer</code>, situé sous la section **Administration**, afin de confirmer les changements. Ce bouton enregistre en une seule fois les paramètres des sections **Conférence** et **Administration**.

{/* CP-STEPS-END:configurer-conference */}

#### Administrer la conférence

{/* CP-STEPS-START:administrer-conference */}

Dans la section **Administration**, définissez également vos paramètres.

<img className="thumbnail" alt="sections Administration et Suivi et contrôle de la conférence de l'onglet Configuration" src="/images/web-cloud/phone-and-fax/voip/conference/console/conference2022-03.png" loading="lazy" />

|Paramètres|Description|
|---|---|
|Rapport de la conférence|Permet de définir si vous souhaitez recevoir un rapport concernant l'activité de la conférence ; et si oui, l'adresse e-mail sur laquelle le recevoir.|

Cliquez enfin sur le bouton <code className="action">Enregistrer</code> pour confirmer les changements.

La section **Suivi et contrôle de la conférence** permet d'activer des liens pour suivre et contrôler la conférence. Pour les activer, cliquez sur <code className="action">Générer les urls</code>.

Une fois générées, l'**URL de suivi** et l'**URL de contrôle** s'affichent dans cette section. Vous pouvez alors :

- <code className="action">Régénérer les urls</code> : permet de remplacer les URL existantes par d'autres ;
- <code className="action">Supprimer les urls</code> : permet de désactiver le suivi et le contrôle de la conférence.

{/* CP-STEPS-END:administrer-conference */}

### Étape 4 : Utiliser la conférence

Une fois votre conférence active et paramétrée, celle-ci est prête à être utilisée. Les participants peuvent donc appeler le numéro défini en tant que conférence, puis interagir selon la configuration que vous avez mise en place.

Les participants ont aussi la possibilité de se servir des raccourcis ci-dessous pendant une conférence :

|Raccourcis|Description|
|---|---|
|##|Quitter la conférence|
|00|Désactiver ou activer le mode muet|
|**|Désactiver ou activer le mode muet et sourd|
