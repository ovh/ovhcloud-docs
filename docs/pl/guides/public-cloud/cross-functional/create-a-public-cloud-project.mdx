## Wskazówki

### Tworzenie projektu

Pierwsze kroki zależą od tego, czy masz już projekt Public Cloud:

- **To Twój pierwszy projekt Public Cloud:** konsola OVHcloud otwiera stronę **Witamy w ekosystemie Public Cloud**. Po zapoznaniu się z warunkami umów zaznacz odpowiednie pole w sekcji **Umowy**, a następnie kliknij <code className="action">Poznaj naszą ofertę Public Cloud</code>. Twój projekt zostanie utworzony w [Trybie Discovery](#discovery).
- **Masz już projekt Public Cloud:** na stronie **Projekty** kliknij <code className="action">Utwórz nowy projekt</code>. Możesz również kliknąć selektor <code className="action">Projekt</code> w górnej części menu po lewej stronie, a następnie <code className="action">Utwórz projekt</code>. Na stronie **Utwórz projekt Public Cloud**:
    1. W polu **Nazwa projektu** wpisz nazwę projektu.
    2. Po zapoznaniu się z warunkami umów zaznacz odpowiednie pole w sekcji **Umowy**.
    3. W sekcji **Potwierdź swoją tożsamość za pomocą sposobu płatności** wybierz sposób płatności. Jeśli masz voucher, wpisz go w sekcji **Masz kod promocyjny?** i kliknij <code className="action">Dodaj</code>.
    4. Kliknij <code className="action">Utwórz projekt</code>.

Niektóre konta nie mają dostępu do Trybu Discovery: ich pierwszy projekt również jest tworzony na stronie **Utwórz projekt Public Cloud**.

Po zakończeniu procesu tworzenia Twój nowy projekt Public Cloud będzie wyświetlany w selektorze **Projekt** w górnej części menu po lewej stronie w sekcji Public Cloud.

Od tej pory masz dostęp do całego ekosystemu Public Cloud OVHcloud. Aby poznać ten nowy interfejs, zapoznaj się z naszym przewodnikiem "[Poznaj interfejs Public Cloud](/guides/public-cloud/cross-functional/public-cloud-interface-walk-me)".

<a name="discovery"></a>

:::info
**Tryb Discovery**

Twój pierwszy projekt Public Cloud jest tworzony w `Trybie Discovery`. Oznacza to, że możesz przeglądać i odkrywać produkty Public Cloud, ale nie możesz jeszcze tworzyć zasobów, takich jak instancje. Dopóki ten projekt jest w Trybie Discovery, nie możesz również utworzyć kolejnego projektu: konsola OVHcloud poprosi Cię najpierw o jego aktywację.

Aby w pełni wykorzystać potencjał Public Cloud i uruchomić pierwsze zasoby, aktywuj projekt:

1. Na stronie głównej projektu baner **Rozpocznij wdrażanie zasobów cloud.** przypomina, że korzystasz z Trybu Discovery. Kliknij <code className="action">Włącz</code> na tym banerze.
2. W oknie, które się otworzy, kliknij <code className="action">Aktywuj projekt</code>.
3. Na stronie **Aktywuj projekt** zatwierdź sposób płatności, a następnie kliknij <code className="action">Aktywuj projekt</code>.

### Aktywacja projektu i bezpłatny okres próbny

Gdy aktywujesz projekt w `Trybie Discovery` i zarejestrujesz metodę płatności, otrzymasz **bezpłatny kredyt próbny w wysokości 1 000 PLN**, jeśli spełniasz warunki kwalifikacji. W takim przypadku baner na stronie głównej projektu oraz strona **Aktywuj projekt** wyświetlają kwotę oferty.

:::info
**Warunki bezpłatnego okresu próbnego**

- Kredyt jest aktywowany w momencie aktywacji projektu i jest ważny przez **jeden miesiąc**.
- **Kwalifikujący się:** każdy klient OVHcloud tworzący swój pierwszy projekt Public Cloud, nawet jeśli posiada już konto OVHcloud.
- **Niekwalifikujący się:** klienci, którzy mają obecny lub miniony projekt Public Cloud lub którzy już skorzystali z bezpłatnego kredytu próbnego.

Więcej informacji znajdziesz na stronie [Bezpłatny okres próbny OVHcloud Public Cloud](/links/public-cloud/free-trial).
:::

:::info
**Tworzenie dodatkowych projektów za pomocą Terraform**

Po utworzeniu pierwszego projektu Public Cloud i zweryfikowaniu metody płatności możesz tworzyć kolejne projekty programowo za pomocą zasobu Terraform `ovh_cloud_project`. Więcej informacji znajdziesz w przewodniku [Terraform Tutorial (EN)](/guides/public-cloud/cross-functional/how-to-use-terraform#creating-a-public-cloud-project).

Obecnie nie istnieje dedykowany endpoint API ani polecenie CLI OVHcloud służące do tworzenia projektów.
:::
