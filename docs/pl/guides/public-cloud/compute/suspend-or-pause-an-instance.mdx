## Wprowadzenie

Częścią konfiguracji infrastruktury o wysokiej dostępności może być konieczność odcięcia dostępu do instancji w celu przeprowadzenia różnych testów. OpenStack pozwala przełączyć instancję w tryb Shelve, zatrzymać ją (Shutoff), zawiesić lub wstrzymać. W każdym przypadku Twój adres IP jest zachowywany.

:::warning
W konsoli OVHcloud dostępne są tylko akcje **Shelve** / **Unshelve** i **Hard stop** (akcja OpenStack *stop*, *Shut Off* w Horizon). Akcje **Suspend** / **Resume** i **Pause** / **Unpause** są dostępne przez API OVHcloud (v2), w Horizon i przez API OpenStack.

:::

**Dowiedz się, jak przełączyć instancję w tryb Shelve, zatrzymać ją (Hard stop), zawiesić lub wstrzymać.**

## W praktyce

:::warning
**Zakres:** Niniejszy przewodnik dotyczy wszystkich instancji Public Cloud, niezależnie od ich modelu rozliczeniowego (godzinowego lub miesięcznego).

**Rozliczenie miesięczne:** W przypadku instancji rozliczanych miesięcznie cena miesięczna instancji jest naliczana niezależnie od jej stanu. Instancja miesięczna w trybie Shelve jest rozliczana według ceny miesięcznej, powiększonej o koszt snapshotu.

**Uwaga:** Dopóki instancja nie zostanie usunięta, każda operacja będzie nadal generować opłaty za instancję.

:::

Poniższa tabela pozwoli Ci odróżnić opcje dostępne dla Twoich instancji. Kontynuuj lekturę przewodnika, klikając wybraną opcję. W nawiasach podano odpowiednią akcję OpenStack.

|Opcja|Stan pamięci|Dane na dysku|Zasoby hosta (CPU/RAM)|Wznowienie|Płatności|
|---|---|---|---|---|---|
|[Hard stop (*stop*)](#hard-stop-instance)|Utracony|Zachowane|Nadal przydzielone na hoście|Zimny start (system operacyjny uruchamia się ponownie)|Opłata jest naliczana według tej samej stawki.|
|[Shelve (*shelve*)](#shelve-instance)|Utracony|Zapisane w obrazie snapshotu|Zwolnione po odciążeniu hosta (*offloaded*)|Zimny start ze snapshotu, ewentualnie na innym hoście|Instancje godzinowe: naliczana jest tylko opłata za snapshot. Instancje miesięczne: cena miesięczna instancji powiększona o koszt snapshotu.|
|[Pause (*pause*)](#pause-instance)|Zachowany w pamięci RAM hosta|Zachowane|Nadal przydzielone i wykorzystywane|Natychmiastowe, dokładnie w miejscu zatrzymania|Opłata jest naliczana według tej samej stawki.|
|[Suspend (*suspend*)](#stop-suspend-instance)|Zapisany na dysku hosta|Zachowane|RAM/CPU zwolnione na hiperwizorze, przydział zachowany|Przywraca zapisany stan, podobnie jak hibernacja|Opłata jest naliczana według tej samej stawki.|

W każdym przypadku adres IP instancji jest zachowywany.

<a name="shelve-instance"></a>

### Przełączanie instancji w tryb Shelve

:::danger
Należy pamiętać, że przełączenie instancji IOPS lub T1/T2-180 w tryb Shelve spowoduje utratę danych na dyskach NVMe passthrough.

Przełączenie tego typu instancji w tryb Shelve prowadzi do jej wycofania z hosta, a tym samym z dysków w passthrough.

:::

Ta opcja pozwoli Ci zwolnić zasoby dedykowane Twojej instancji Public Cloud, ale adres IP pozostanie. Dane z dysku lokalnego będą przechowywane w snapshocie utworzonym automatycznie po przełączeniu instancji w tryb Shelve. Dane przechowywane w pamięci i poza nią nie będą zachowywane.

<Tabs>
  <Tab label="Konsola OVHcloud">
    W menu po lewej stronie projektu Public Cloud kliknij <code className="action">Instances</code> w sekcji **Compute**.

    Kliknij przycisk <code className="action">...</code> po prawej stronie instancji, którą chcesz przełączyć w tryb Shelve, a następnie <code className="action">Shelve</code>.

    W oknie **Przełącz instancję w tryb Shelve** zapoznaj się z komunikatem i kliknij przycisk <code className="action">Zatwierdź</code>.

    Po zakończeniu operacji stan Twojej instancji będzie widoczny jako **Shelve**.

    Aby wyświetlić snapshot, kliknij <code className="action">Instance Snapshot</code> w sekcji **Compute** w menu po lewej stronie. Snapshot o nazwie *xxxxx-shelved* będzie teraz widoczny.
  </Tab>
  <Tab label="CLI OVHcloud">
    Przed kontynuowaniem zalecamy zapoznanie się z następującymi przewodnikami:

    - [Pierwsze kroki z OVHcloud CLI](/guides/manage-and-operate/cli/getting-started)

    Wpisz następujące polecenie:

    ```shell
    ovhcloud cloud instance shelve <instance_id>
    ```
  </Tab>
  <Tab label="API OVHcloud">
    Użyj następującego wywołania API, gdzie `projectId` to ID Twojego projektu Public Cloud, a `instanceId` to ID instancji:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Z następującą treścią żądania:

    ```json
    {
      "type": "SHELVE"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Przed kontynuowaniem zalecamy zapoznanie się z następującymi przewodnikami:

    - [Przygotowanie środowiska dla API OpenStack](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment)
    - [Ustawianie zmiennych środowiskowych OpenStack](/guides/public-cloud/cross-functional/compute-set-openstack-environment-variables)

    Kiedy Twoje środowisko jest gotowe, wpisz w wierszu poleceń:

    ```bash
    openstack server shelve <UUID server>

    =====================================

    nova shelve <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    Aby kontynuować, należy [zalogować się do interfejsu Horizon](https://horizon.cloud.ovh.net/auth/login/):

    - Aby zalogować się za pomocą OVHcloud Single Sign-On: otwórz projekt Public Cloud w <ManagerLink to="/">konsoli OVHcloud</ManagerLink> i kliknij <code className="action">OpenStack Horizon</code> w widżecie **Dokumentacja i pomoc** na stronie głównej projektu.

    - Aby zalogować się za pomocą określonego użytkownika OpenStack: otwórz [stronę logowania Horizon](https://horizon.cloud.ovh.net/auth/login/) i wprowadź wcześniej utworzone [dane logowania użytkownika OpenStack](/guides/public-cloud/cross-functional/create-and-delete-a-user), a następnie kliknij przycisk <code className="action">Connect</code>.

    Jeśli wdrożyłeś instancje w różnych regionach, upewnij się, że jesteś we właściwym regionie. Weryfikacji dokonujesz w lewym górnym rogu w interfejsie Horizon.

    <img className="thumbnail" alt="horizon interface" src="/images/public-cloud/compute/suspend-or-pause-an-instance/firstaccesshorizon.png" loading="lazy" />

    <img className="thumbnail" alt="shelve instance" src="/images/public-cloud/compute/suspend-or-pause-an-instance/shelveinstancehorizon.png" loading="lazy" />

    Po ukończeniu procesu Twoja instancja będzie wyświetlana jako *Shelved Offloaded*.

    <img className="thumbnail" alt="shelved instance" src="/images/public-cloud/compute/suspend-or-pause-an-instance/newinstancestatushorizon.png" loading="lazy" />

<a name="unshelve-instance"></a>

### Wykonywanie Unshelve instancji

Ta opcja ponownie aktywuje instancję, abyś mógł z niej nadal korzystać. Uwaga: po tej operacji fakturowanie zostanie wznowione w trybie normalnym.

:::danger
**Operacje na snapshot**

Wszelkie działania na snapshotach inne niż *unshelve* mogą być bardzo niebezpieczne dla infrastruktury, jeśli zostaną niewłaściwie użyte. Po wykonaniu *unshelve* instancji snapshot jest automatycznie usuwany. Nie jest zalecane wdrażanie nowej instancji ze snapshotu utworzonego w wyniku przełączenia instancji w tryb Shelve.

OVHcloud oddaje do Twojej dyspozycji usługi, za które przejmujesz odpowiedzialność. Firma OVHcloud nie ma dostępu do Twoich serwerów, nie pełni funkcji administratora i w związku z tym nie będzie mogła udzielić Ci wsparcia. Oddajemy w Twojej ręce niniejszy przewodnik, którego celem jest pomoc w jak najlepszym wykonywaniu bieżących zadań. W przypadku problemów z administrowaniem, użytkowaniem czy zabezpieczeniem serwera rekomendujemy skorzystanie z usług wyspecjalizowanej firmy. Więcej informacji znajduje się w sekcji "Sprawdź również".
:::

<Tabs>
  <Tab label="Konsola OVHcloud">
    W menu po lewej stronie projektu Public Cloud kliknij <code className="action">Instances</code> w sekcji **Compute**.

    Kliknij przycisk <code className="action">...</code> po prawej stronie instancji, a następnie <code className="action">Unshelve</code>.

    W oknie **Unshelve instancji** kliknij przycisk <code className="action">Zatwierdź</code>.

    Po zakończeniu operacji stan Twojej instancji będzie widoczny jako **Aktywna**.
  </Tab>
  <Tab label="CLI OVHcloud">
    Wpisz następujące polecenie:

    ```shell
    ovhcloud cloud instance unshelve <instance_id>
    ```
  </Tab>
  <Tab label="API OVHcloud">
    Użyj następującego wywołania API, gdzie `projectId` to ID Twojego projektu Public Cloud, a `instanceId` to ID instancji:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Z następującą treścią żądania:

    ```json
    {
      "type": "UNSHELVE"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Kiedy Twoje środowisko jest gotowe, wpisz w wierszu poleceń:

    ```bash
    ~$ openstack server unshelve <UUID server>

    =========================================

    ~$ nova unshelve <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    W interfejsie Horizon kliknij menu <code className="action">Compute</code> po lewej stronie, a następnie wybierz pozycję <code className="action">Instancje</code>. Wybierz pozycję <code className="action">Unshelve Instance</code> z listy rozwijanej dla odpowiedniej instancji.

    <img className="thumbnail" alt="unshelve instance" src="/images/public-cloud/compute/suspend-or-pause-an-instance/unshelveinstancehorizon.png" loading="lazy" />

    Po ukończeniu procesu Twoja instancja będzie widoczna jako *Active*.
  </Tab>
</Tabs>

<a name="hard-stop-instance"></a>

### Wykonywanie Hard stop (*stop*) instancji

Ta opcja zatrzymuje instancję (akcja OpenStack *stop*, *Shut Off* w Horizon). Dane na dysku są zachowywane, ale stan pamięci zostaje utracony: instancja uruchamia się od nowa po ponownym włączeniu. Zasoby dedykowane instancji, w tym adres IP, pozostają zarezerwowane, a opłata jest nadal naliczana według tej samej stawki.

<Tabs>
  <Tab label="Konsola OVHcloud">
    W menu po lewej stronie projektu Public Cloud kliknij <code className="action">Instances</code> w sekcji **Compute**.

    Kliknij przycisk <code className="action">...</code> po prawej stronie instancji, którą chcesz zatrzymać, a następnie <code className="action">Hard stop</code>.

    W oknie **Hard stop instancji** zapoznaj się z komunikatem i kliknij przycisk <code className="action">Zatwierdź</code>.

    Po zakończeniu operacji stan Twojej instancji będzie widoczny jako **Hard stop (Shutoff)**.

    Aby ponownie **uruchomić** instancję, kliknij przycisk <code className="action">...</code> po prawej stronie instancji i wybierz <code className="action">Uruchom</code>, a następnie kliknij <code className="action">Zatwierdź</code> w oknie **Uruchom instancję**. W niektórych przypadkach może być konieczne wykonanie zimnego restartu.

    Po zakończeniu operacji stan Twojej instancji będzie widoczny jako **Aktywna**.
  </Tab>
  <Tab label="CLI OVHcloud">
    Wpisz następujące polecenie:

    ```shell
    ovhcloud cloud instance stop <instance_id>
    ```

    Aby ponownie **uruchomić** instancję, wpisz następujące polecenie:

    ```shell
    ovhcloud cloud instance start <instance_id>
    ```
  </Tab>
  <Tab label="API OVHcloud">
    Użyj następującego wywołania API, gdzie `projectId` to ID Twojego projektu Public Cloud, a `instanceId` to ID instancji:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Z następującą treścią żądania:

    ```json
    {
      "type": "STOP"
    }
    ```

    Aby **wznowić** instancję, użyj tego samego wywołania z typem `START`:

    ```json
    {
      "type": "START"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Kiedy Twoje środowisko jest gotowe, wpisz w wierszu poleceń:

    ```bash
    ~$ openstack server stop <UUID server>

    =========================================

    ~$ nova stop <UUID server>
    ```

    Aby ponownie **uruchomić** instancję, wpisz w wierszu poleceń:

    ```bash
    ~$ openstack server start <UUID server>

    =========================================

    ~$ nova start <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    W interfejsie Horizon kliknij menu <code className="action">Compute</code> po lewej stronie, a następnie wybierz pozycję <code className="action">Instancje</code>. Wybierz pozycję <code className="action">Shut Off Instance</code> z listy rozwijanej dla odpowiedniej instancji.

    Aby ponownie **uruchomić** instancję, wybierz pozycję <code className="action">Start Instance</code> z listy rozwijanej dla odpowiedniej instancji.
  </Tab>
</Tabs>

<a name="stop-suspend-instance"></a>

### Zawieszanie instancji

Ta opcja zawiesza instancję: stan pamięci jest zapisywany na dysku hosta, a RAM/CPU są zwalniane na hiperwizorze, przy czym przydział zostaje zachowany. Po wznowieniu instancji zapisany stan zostaje przywrócony, podobnie jak po hibernacji. Opłata jest naliczana według tej samej stawki.

Ta akcja nie jest dostępna w konsoli OVHcloud: użyj API OVHcloud, interfejsu Horizon lub API OpenStack/Nova.

<Tabs>
  <Tab label="API OVHcloud">
    Użyj następującego wywołania API, gdzie `projectId` to ID Twojego projektu Public Cloud, a `instanceId` to ID instancji:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Z następującą treścią żądania:

    ```json
    {
      "type": "SUSPEND"
    }
    ```

    Aby **wznowić** instancję, użyj tego samego wywołania z typem `RESUME`:

    ```json
    {
      "type": "RESUME"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Kiedy Twoje środowisko jest gotowe, wpisz w wierszu poleceń:

    ```bash
    ~$ openstack server suspend <UUID server>

    =========================================

    ~$ nova suspend <UUID server>
    ```

    Aby **wznowić** instancję, wpisz w wierszu poleceń:

    ```bash
    ~$ openstack server resume <UUID server>

    =========================================

    ~$ nova resume <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    W interfejsie Horizon kliknij menu <code className="action">Compute</code> po lewej stronie, a następnie wybierz pozycję <code className="action">Instancje</code>. Wybierz pozycję <code className="action">Suspend Instance</code> z listy rozwijanej dla odpowiedniej instancji.

    <img className="thumbnail" alt="suspend instance Horizon" src="/images/public-cloud/compute/suspend-or-pause-an-instance/suspendinstancehorizon.png" loading="lazy" />

    Pojawi się komunikat potwierdzenia wskazujący, że instancja została zawieszona.

    Aby **wznowić** instancję, wykonaj te same kroki, co opisane powyżej. Z listy rozwijanej odpowiedniej instancji wybierz pozycję <code className="action">Resume Instance</code>.
  </Tab>
</Tabs>

<a name="pause-instance"></a>

### Wstrzymywanie instancji

Ta akcja nie jest dostępna w konsoli OVHcloud: użyj API OVHcloud, interfejsu Horizon lub API OpenStack/Nova. Umożliwia ona *zamrożenie* instancji: stan pamięci jest zachowywany w pamięci RAM hosta, a instancja wznawia działanie natychmiast, dokładnie w miejscu, w którym została zatrzymana.

<Tabs>
  <Tab label="API OVHcloud">
    Użyj następującego wywołania API, gdzie `projectId` to ID Twojego projektu Public Cloud, a `instanceId` to ID instancji:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Z następującą treścią żądania:

    ```json
    {
      "type": "PAUSE"
    }
    ```

    Aby **wznowić** instancję, użyj tego samego wywołania z typem `UNPAUSE`:

    ```json
    {
      "type": "UNPAUSE"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Kiedy Twoje środowisko jest gotowe, wpisz w wierszu poleceń:

    ```bash
    ~$ openstack server pause <UUID server>

    =========================================

    ~$ nova pause <UUID server>
    ```

    Aby **wznowić** instancję, wpisz w wierszu poleceń:

    ```bash
    ~$ openstack server unpause <UUID server>

    =========================================

    ~$ nova unpause <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    W interfejsie Horizon kliknij menu <code className="action">Compute</code> po lewej stronie, a następnie wybierz pozycję <code className="action">Instancje</code>. Na liście rozwijanej zaznacz opcję <code className="action">Pause Instance</code> dla odpowiedniej instancji.

    <img className="thumbnail" alt="Pause instance" src="/images/public-cloud/compute/suspend-or-pause-an-instance/pauseinstancehorizon.png" loading="lazy" />

    Zostanie wyświetlony komunikat potwierdzenia z informacją o wstrzymaniu instancji.

    Aby **wznowić** instancję, wykonaj te same kroki, co opisane powyżej. Z listy rozwijanej odpowiedniej instancji wybierz pozycję <code className="action">Resume Instance</code>.
  </Tab>
</Tabs>
