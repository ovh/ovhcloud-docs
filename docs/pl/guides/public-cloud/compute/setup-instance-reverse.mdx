## Wprowadzenie

**Rewers DNS** (*rDNS*) to uzupełnienie konfiguracji "klasycznej" serwerów DNS, która pozwala na konwersję domeny na adres IP (rekord typu **A**). Dzięki tego typu zapytaniu, adres IP może zostać usunięty w nazwie domeny (rejestracja typu **PTR**). Oznacza to, że zapytania DNS na danym adresie IP będą miały nazwę domeny.

Konfiguracja **rewersu DNS** instancji jest szczególnie przydatna przy wysyłaniu e-maili. Ryzyko odrzucenia wiadomości przez system ochrony przed spamem zostanie zmniejszone, jeśli adres IP Twojego serwera poczty wychodzącej zostanie poprawnie rozwiązany w Twojej domenie.

**Dowiedz się, jak skonfigurować rewers DNS dla adresu lub adresów IP instancji Public Cloud.**

## Wymagania początkowe

- Posiadanie [instancji Public Cloud](/links/public-cloud/public-cloud) na koncie OVHcloud
- Nazwa domeny z polem `A` wskazującym na instancję

## W praktyce

Lista <code className="action">Filtruj według usługi...</code> na stronie **Adresy IP** pozwala filtrować adresy IP według usługi: wybierz swój projekt Public Cloud w grupie **Public Cloud**. Możesz również wyszukać konkretny adres IP w pasku wyszukiwania.

Kliknij odpowiedni adres IP, a następnie otwórz zakładkę <code className="action">Reverse DNS</code> i kliknij <code className="action">Skonfiguruj</code>.

W oknie **Konfiguruj Reverse DNS** wprowadź swój rewers w polu **Nazwa hosta reverse DNS** i kliknij <code className="action">Skonfiguruj</code>.

Aby usunąć rewers, kliknij ikonę usuwania w wierszu rewersu w zakładce **Reverse DNS**.

:::info
Jeśli modyfikacja nie działa zgodnie z oczekiwaniami, sprawdź, czy pole `A` jest poprawnie skonfigurowane w strefie DNS Twojej domeny. Uwaga, modyfikacja [strefy DNS](/guides/web-cloud/domains/dns-zone-edit) może trwać do 24 godzin, jeśli ostatnio zmieniłeś pole `A`.
:::
