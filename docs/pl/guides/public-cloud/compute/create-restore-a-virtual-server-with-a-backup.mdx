## Wprowadzenie

Konsola OVHcloud pozwala na tworzenie [snapshotów instancji](/guides/public-cloud/compute/save-an-instance) za pomocą kilku kliknięć oraz na automatyzację tego procesu.
Snapshoty instancji mogą być używane w dwóch podstawowych celach:

- Utworzenie nowej instancji z wykorzystaniem snapshotu jako szablonu, aby zduplikować oryginalną instancję, na przykład podczas konfigurowania infrastruktury równoważenia obciążenia (load balancing).
- Przywrócenie instancji ze snapshotu, na przykład jeśli ostatnie zmiany uszkodziły krytyczne konfiguracje instancji.

**Dowiedz się, jak używać snapshotów do duplikowania lub przywracania instancji.**

## Wymagania początkowe

- Posiadanie snapshotu [instancji Public Cloud](/links/public-cloud/instance-backup). Należy zapoznać się w tym celu z [instrukcją tworzenia snapshotu](/guides/public-cloud/compute/save-an-instance).

[[cpnav:publiccloud-instance-backup-console]]

## W praktyce

:::info
Dostępne są dwa typy snapshotów:

- Lokalny: przechowywany w tym samym regionie co Twoja instancja.
- Zdalny: automatycznie replikowany w innym wybranym przez Ciebie regionie.

Operacje **tworzenia** i **przywracania** instancji ze zdalnego snapshotu są w pełni obsługiwane przez API OVHcloud, co zapewnia większą elastyczność i łatwą integrację z procesami automatyzacji.

**Uwaga:** W konsoli OVHcloud możesz utworzyć instancję z dowolnego snapshotu wyświetlanego na stronie **Snapshoty instancji**, ale istniejącą instancję możesz przywrócić tylko ze snapshotu przechowywanego w jej własnym regionie.

:::


### Tworzenie instancji na podstawie snapshotu

<Tabs>
  <Tab label="Konsola OVHcloud">
    W menu po lewej stronie projektu Public Cloud kliknij <code className="action">Instance Snapshot</code> w sekcji **Compute**. Na stronie **Snapshoty instancji** wyświetlana jest lista Twoich snapshotów.

    Kliknij przycisk <code className="action">...</code> w wierszu odpowiedniego snapshotu, a następnie wybierz <code className="action">Utwórz instancję</code>.

    Otworzy się strona **Utwórz instancję** z niektórymi elementami wstępnie zdefiniowanymi:

    - **Region**: Twoja instancja zostanie utworzona w tym samym regionie co snapshot. Region jest określony przez snapshot i nie można go zmienić.
    - **Obraz**: Snapshot jest wstępnie wybrany w zakładce <code className="action">Snapshoty</code> sekcji **Wybierz obraz**.
    - **Model**: Dostępne są tylko modele kompatybilne z Twoim obrazem, w zależności od Twoich limitów.

    Wybierz nazwę nowej instancji, klucz SSH oraz ustawienia sieci i rozliczeń, a następnie kliknij przycisk <code className="action">Utwórz moją instancję</code>.

    Aby uzyskać więcej informacji na temat tworzenia instancji, skorzystaj z [tego przewodnika](/guides/public-cloud/compute/getting-started).

    :::info
    Aby utworzyć instancję w innym centrum danych, musisz najpierw przenieść snapshot do odpowiedniego regionu. Skorzystaj z naszego przewodnika, aby [przenieść kopię zapasową instancji](/guides/public-cloud/compute/transfer-instance-backup-from-one-datacentre-to-another).

    :::

  </Tab>
  <Tab label="API OVHcloud">
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/instance"} />

Wypełnij zmienne:
    
    - **serviceName** : ID projektu OVHcloud.
    - **regionName** : Nazwa regionu, w którym zostanie umieszczona instancja.
    
    Przykład treści żądania:
    
    ```json
    {
      "billingPeriod": "hourly",
      "bootFrom": {
        "imageId": "5cb8ea68-****-****-****-820be8346***"
      },
      "flavor": {
        "id": "e81b46f8-****-****-****-cad655e65***"
      },
      "name": "newInstance",
      "network": {
        "public": true
      },
      "sshKey": {
        "name": "MySSHKey"
      }
    }
    ```
  </Tab>
  <Tab label="CLI OpenStack">
    Aby utworzyć instancję ze snapshotu, użyj identyfikatora snapshotu jako obrazu w tym poleceniu:
    
    ```bash
    $ openstack server create --key-name SSHKEY --flavor 98c1e679-5f2c-4069-b4da-4a4f7179b758 --image 0a3f5901-2314-438a-a7af-ae984dcbce5c Server1_from_snap
    ```
  </Tab>
  <Tab label="Horizon">
    W interfejsie Horizon kliknij <code className="action">Compute</code> w lewym menu, a następnie <code className="action">Images</code>. Znajdź odpowiedni obraz i kliknij przycisk <code className="action">Launch</code> po prawej stronie wiersza obrazu.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon1.png" loading="lazy" />

Nadaj instancji nazwę w odpowiednim polu i określ liczbę instancji do utworzenia. Następnie kliknij kartę <code className="action">Flavor</code>.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-2" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon2.png" loading="lazy" />

Wybierz żądany model instancji, a następnie kliknij kartę <code className="action">Networks</code>.
    
    :::warning
    Jeśli Twoja instancja to serwer Windows, musisz wybrać model typu win-xx-xx (np. win-b2-15) i mieć publiczny interfejs na sieci Ext-Net. Bez tych warunków uwierzytelnienie z OVHcloud KMS nie będzie możliwe, a Twój serwer pozostanie z [nieaktywowaną licencją](/guides/public-cloud/compute/activate-windows-license-private-mode). Może to prowadzić do ograniczeń, w tym braku aktualizacji. Zwróć uwagę, że nie można zmienić rozmiaru instancji Linux (np. b2-15) na instancję Windows (np. win-b2-15). Aby dokonać tej zmiany, musisz utworzyć nową instancję.

    :::

    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-3" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon3.png" loading="lazy" />

Wybierz sieć, którą chcesz przypisać, a następnie kliknij przycisk <code className="action">Launch Instance</code>.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-4" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon4.png" loading="lazy" />

Status nowej instancji możesz sprawdzić w <code className="action">Compute</code> w lewym menu, a następnie klikając <code className="action">Instances</code>.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-5" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon5.png" loading="lazy" />
  </Tab>
</Tabs>


### Przywracanie instancji ze snapshotu

<Tabs>
  <Tab label="Konsola OVHcloud">
    W menu po lewej stronie projektu Public Cloud kliknij <code className="action">Instances</code> w sekcji **Compute**, a następnie kliknij nazwę odpowiedniej instancji.

    Na karcie **Informacje ogólne** w zakładce <code className="action">Przegląd</code> kliknij <code className="action">Edytuj obraz</code> w wierszu **Obraz**. Otworzy się panel **Edytuj obraz**.

    W sekcji **Wybierz dystrybucję** wybierz snapshoty, a następnie wybierz snapshot do przywrócenia w sekcji **Wybierz obraz**. Proponowane są tylko snapshoty przechowywane w regionie instancji. Kliknij <code className="action">Edytuj obraz</code>, jeśli masz pewność, że chcesz zastąpić bieżący obraz snapshotem.

    Instancja zostanie ponownie zainstalowana i uruchomiona ponownie do czasu zakończenia procesu.

    :::warning
    Zgodnie z komunikatem ostrzegawczym wszystkie dane instancji zostaną usunięte: dane dodane po utworzeniu snapshotu zostaną utracone.

    :::

  </Tab>
  <Tab label="API OVHcloud">
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/instance/\\{instanceId\\}/reinstall"} />

Uzupełnij zmienne:
    
    - **serviceName** : ID projektu OVHcloud.
    - **regionName** : Nazwa regionu, w którym znajduje się instancja źródłowa.
    - **instanceId** : unikalny identyfikator instancji.
    
    Przykład treści zapytania:
    
    ```json
    {
      "imageId": "5cb8ea68-****-****-****-820be8346***",
      "imageRegionName": "GRA11"
    }
    ```
  </Tab>
</Tabs>
