## Wprowadzenie

Potrzeba skonfigurowania adresu Additional IP na swoich instancjach może zajść z różnych powodów:

- Masz kilka stron na swojej instancji.
- Hostujesz projekty międzynarodowe.

Aby spełnić te potrzeby, możesz wykupić adres Additional IP dla swoich instancji Public Cloud.

Te adresy Additional IP można migrować tylko do instancji tego samego projektu.

**Z tego przewodnika dowiesz się, jak wykupić adres Additional IP na potrzeby projektu Public Cloud OVHcloud.**

## Wymagania początkowe

- Posiadanie co najmniej jednej instancji. W tym celu zapoznaj się z [przewodnikiem dotyczącym tworzenia instancji w konsoli OVHcloud](/guides/public-cloud/compute/getting-started).

:::warning
Ta funkcja nie jest aktualnie dostępna dla instancji Metal.

:::

## W praktyce

W menu po lewej stronie otwórz <code className="action">Public IP</code> w sekcji **Sieć**.

Otwórz kartę <code className="action">Additional IP</code> i kliknij <code className="action">Zamów adres Additional IP</code>.

W sekcji **Wybierz kraj dla nowego adresu Additional IP OVHcloud** wybierz kraj dla nowego adresu IP.

Dla geolokalizacji IP dostępne są następujące kraje:

|          |          |          |           |                |
|:--------:|:--------:|:--------:|:---------:|:--------------:|
| Belgia  | Finlandia  | Francja   | Niemcy   | Czechy |
| Irlandia  |  Włochy   | Litwa | Niderlandy | Wielka Brytania    |
| Portugalia |  Hiszpania   |  Polska |  Szwajcaria |                 |

:::info
**Dostępność**

Niektóre z tych krajów mogą nie być wymienione w zależności od dostępności obecnie adresów IPv4.
:::

:::info
**Dzierżawa**

Geolokalizacja IP opiera się wyłącznie na organizacjach referencyjnych.

Na przykład [RIPE NCC](https://www.ripe.net/) obsługuje Europę jako regionalny rejestr internetowy.

Jeśli chcesz sprawdzić geolokalizację w inny sposób, skontaktuj się bezpośrednio z odpowiednimi organizacjami. OVHcloud nie będzie mógł udzielić Ci wsparcia w tym zakresie.
:::

Następnie w sekcji **Przypisz IP do określonej instancji lub sieci** wybierz swoją instancję w polu **Instancja, którą chcesz przypisać**. Adres IP zostanie podłączony bezpośrednio do instancji (tryb legacy, bez Gateway). Sprawdź podsumowanie, a następnie kliknij <code className="action">Zamów adres Additional IP</code>.

Zamówienie zostanie automatycznie otwarte, aby sfinalizować zamówienie.

Więcej informacji znajdziesz w przewodniku dotyczącym [zarządzania zamówieniami OVHcloud](/guides/account-and-service-management/managing-billing-payments-and-services/ovh-orders).

Możesz również znaleźć zamówienie w sekcji **Moje zamówienia** Twojego konta klienta w konsoli OVHcloud.

Następnym krokiem jest konfiguracja IP w systemie operacyjnym. Zapoznaj się [z przewodnikiem dotyczącym tej konfiguracji](/guides/public-cloud/network-services/configure-additional-ip).
