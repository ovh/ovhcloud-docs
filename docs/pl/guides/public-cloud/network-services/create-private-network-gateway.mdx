## Wprowadzenie

Brama [Gateway](/links/public-cloud/gateway) zapewnia bezpieczną metodę połączenia wychodzącego z instancji w Twojej prywatnej sieci lub umożliwia korzystanie z adresów Floating IP z instancją albo Load Balancerem w celu udostępniania usług.

**Dowiedz się, jak utworzyć prywatną sieć z bramą Gateway.**

## Wymagania początkowe

- [projekt Public Cloud](/links/public-cloud/public-cloud) na koncie OVHcloud
- **Dla API OVHcloud:** dane uwierzytelniające API ([Pierwsze kroki z API OVHcloud](/guides/manage-and-operate/api/first-steps))
- **Dla CLI OVHcloud:** zainstalowane i skonfigurowane z Twoimi danymi uwierzytelniającymi [CLI OVHcloud](https://github.com/ovh/ovhcloud-cli)
- **Dla API OpenStack:** skonfigurowane środowisko OpenStack ([Przygotowanie środowiska](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment))
- **Dla Terraform:** zainstalowany Terraform oraz skonfigurowany provider OVHcloud ([Jak używać Terraform](/guides/public-cloud/cross-functional/how-to-use-terraform))

## W praktyce

### Modele bram Gateway

Przed utworzeniem bramy Gateway wybierz model dopasowany do Twoich potrzeb w zakresie przepustowości:

| Model | Przepustowość |
|-------|---------------|
| S | do 200 Mb/s |
| M | do 500 Mb/s |
| L | do 2 Gb/s |
| XL | do 4 Gb/s |
| 2XL | do 8 Gb/s |
| 3XL | do 16 Gb/s |

### Tworzenie prywatnej sieci z bramą Gateway

<Tabs>
  <Tab label="Panel klienta OVHcloud">
    **Krok 1 — Otwórz stronę tworzenia**

    Kliknij <code className="action">Gateway</code> w menu po lewej stronie pod **Sieć**.

    Pamiętaj, że przed kontynuowaniem musisz mieć aktywowany vRack. Jeśli nie masz vRacka, zapoznaj się z sekcją [aktywacja vRacka](/guides/public-cloud/network-services/vrack#activation) odpowiedniego przewodnika.

    Następnie kliknij <code className="action">Create a Gateway</code>.

    <img className="thumbnail" alt="tworzenie bramy gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/firstgatewaycreation.png" loading="lazy" />

    **Krok 2 — Wybierz region i rozmiar**

    Wybierz region, w którym chcesz wdrożyć bramę Gateway. Najlepiej wybrać region, w którym znajdują się Twoje prywatne instancje.

    <img className="thumbnail" alt="wybór lokalizacji" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/select_region.png" loading="lazy" />

    Następnie wybierz rozmiar swojej bramy Gateway (zobacz tabelę modeli powyżej).

    <img className="thumbnail" alt="wybór rozmiaru bramy gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/select_size.png" loading="lazy" />

    **Krok 3 — Nazwij bramę Gateway i podłącz prywatną sieć**

    Zmień domyślną nazwę swojej bramy Gateway i wybierz z listy rozwijanej istniejącą prywatną sieć.

    :::info
    Brama Gateway obsługuje wyłącznie prywatne sieci jednoregionowe.
    :::

    <img className="thumbnail" alt="lista rozwijana" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/gatewayandprivatenetwork.png" loading="lazy" />

    Możesz również kliknąć <code className="action">Add private network</code>, aby utworzyć nową prywatną sieć bezpośrednio na miejscu.

    <img className="thumbnail" alt="tworzenie prywatnej sieci" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/newprivatenetwork.png" loading="lazy" />

    W wyświetlonym oknie wprowadź nazwę swojej prywatnej sieci, wybierz podsieć i kliknij <code className="action">Add</code>.

    <img className="thumbnail" alt="tworzenie prywatnej sieci" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/createprivatenetwork.png" loading="lazy" />

    **Krok 4 — Potwierdź utworzenie**

    Kliknij <code className="action">Create a Gateway</code>, aby rozpocząć wdrażanie.

    <img className="thumbnail" alt="tworzenie bramy gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/confirmcreation.png" loading="lazy" />

    Tworzenie może zająć kilka minut. W razie potrzeby odśwież stronę.

    Po zakończeniu prywatna sieć jest widoczna w sekcji <code className="action">Private Network</code> pod **Sieć**.

    <img className="thumbnail" alt="nowa prywatna sieć" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/createdprivatenetwork.png" loading="lazy" />

    Brama Gateway pojawia się w sekcji <code className="action">Gateway</code>.

    <img className="thumbnail" alt="nowa brama gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/mynewgateway.png" loading="lazy" />
  </Tab>
  <Tab label="API OVHcloud">
    Zaloguj się do interfejsu APIv6 OVHcloud. W razie potrzeby zapoznaj się z przewodnikiem [Pierwsze kroki z API OVHcloud](/guides/manage-and-operate/api/first-steps).

    **Pobierz identyfikator projektu**

    Jeśli identyfikator projektu jest nieznany, użyj poniższych wywołań:

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project"} />

    :::info
    To wywołanie pobiera listę projektów.
    :::

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}"} />

    :::info
    To wywołanie identyfikuje projekt za pomocą pola "description".
    :::

    **Utwórz prywatną sieć z bramą Gateway**

    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/gateway"} />

    Wypełnij pola zgodnie z poniższą tabelą:

    | Pole | Opis |
    |------|------|
    | `serviceName` | Identyfikator Twojego projektu |
    | `regionName` | Przykład: `GRA9` |
    | `model` | Rozmiar bramy Gateway (`s`, `m`, `l`, `xl`, `2xl`, `3xl`) |
    | `name` | Nazwa Twojej bramy Gateway (`null` dla wartości domyślnej) |
    | `network.name` | Nazwa prywatnej sieci (`null` dla wartości domyślnej) |
    | `network.cidr` | Blok adresów IP dla Twojej podsieci (np. `192.168.1.0/24`) |
    | `network.enableDhcp` | Zaznacz pole, aby włączyć DHCP |
    | `network.ipVersion` | `4` (IPv6 niedostępne) |
    | `network.vlanId` | Wartość od 2 do 4000 lub pusta dla automatycznego przypisania |

    :::info
    Powtórz dla każdego regionu, w którym znajdują się Twoje prywatne instancje.
    :::

    Aby zweryfikować szczegóły swojej bramy Gateway:

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/gateway"} />

    Pozostaw pole `subnetId` puste, aby wyświetlić wszystkie bramy Gateway w określonym regionie.
  </Tab>
  <Tab label="CLI OVHcloud">
    Użyj [CLI OVHcloud](https://github.com/ovh/ovhcloud-cli), aby utworzyć prywatną sieć z bramą Gateway. Ustaw swój projekt cloud za pomocą `--cloud-project <project_id>` lub skonfiguruj go w swoim profilu.

    **Utwórz bramę Gateway z nową prywatną siecią:**

    ```bash
    ovhcloud cloud network gateway create <region> \
      --cloud-project <project_id> \
      --name my-gateway \
      --model s \
      --network-name my-network \
      --subnet-cidr 192.168.1.0/24 \
      --subnet-enable-dhcp \
      --wait
    ```

    **Utwórz bramę Gateway w istniejącej prywatnej sieci:**

    ```bash
    ovhcloud cloud network gateway create <region> \
      --cloud-project <project_id> \
      --name my-gateway \
      --model s \
      --network-id <network_id> \
      --subnet-id <subnet_id> \
      --wait
    ```

    Dostępne modele: `s`, `m`, `l`, `xl`, `2xl`, `3xl`.

    :::info
    Brama Gateway obsługuje wyłącznie prywatne sieci jednoregionowe.
    :::
  </Tab>
  <Tab label="OpenStack API">
    Przed kontynuowaniem zapoznaj się z poniższymi przewodnikami:

    - [Przygotowanie środowiska do korzystania z API OpenStack](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment)
    - [Konfiguracja zmiennych środowiskowych OpenStack](/guides/public-cloud/cross-functional/compute-set-openstack-environment-variables)

    **Krok 1 — Utwórz sieć i podsieć**

    ```console
    openstack network create my_network

    openstack subnet create my_subnet --subnet-range <my_private_ip_range/mask> --network my_network --no-dhcp
    ```

    **Krok 2 — Wyświetl listę polityk jakości usług**

    ```console
    openstack network qos policy list
    +--------------------------------------+---------------+--------+---------+----------------------------------+
    | ID                                   | Name          | Shared | Default | Project                          |
    +--------------------------------------+---------------+--------+---------+----------------------------------+
    | a5524eb5-944e-4106-b209-9478bbdcedab | large_router  | True   | False   | XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX |
    | c210f5b2-db59-4973-a25f-9131195b6bcf | medium_router | True   | False   | XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX |
    | ec0ee74d-a1f3-43f6-87aa-b0e69ef8ce45 | small_router  | True   | False   | XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX |
    +--------------------------------------+---------------+--------+---------+----------------------------------+
    ```

    **Krok 3 — Utwórz router i skonfiguruj bramę Gateway**

    ```console
    openstack router create my_router

    openstack router add subnet my_router my_subnet

    openstack router set --external-gateway Ext-Net --qos-policy QOS_ID_OF_YOUR_CHOICE my_router
    ```

    Jeśli pominiesz parametr `--qos-policy`, zostanie zastosowana jakość usług `small`.
  </Tab>
  <Tab label="Terraform">
    Przed kontynuowaniem zapoznaj się z przewodnikiem: [Jak używać Terraform](/guides/public-cloud/cross-functional/how-to-use-terraform)

    Utwórz plik Terraform (np. `private_network_gateway.tf`) o następującej zawartości:

    ```hcl
    resource "ovh_cloud_project_network_private" "mypriv" {
      service_name = "<project_id>"
      vlan_id      = "0"
      name         = "mypriv"
      regions      = ["GRA9"]
    }

    resource "ovh_cloud_project_network_private_subnet" "myprivsub" {
      service_name = ovh_cloud_project_network_private.mypriv.service_name
      network_id   = ovh_cloud_project_network_private.mypriv.id
      region       = "GRA9"
      start        = "10.0.0.2"
      end          = "10.0.255.254"
      network      = "10.0.0.0/16"
      dhcp         = true
    }

    resource "ovh_cloud_project_gateway" "gateway" {
      service_name = ovh_cloud_project_network_private.mypriv.service_name
      name         = "my-gateway"
      model        = "s"
      region       = ovh_cloud_project_network_private_subnet.myprivsub.region
      network_id   = tolist(ovh_cloud_project_network_private.mypriv.regions_attributes[*].openstackid)[0]
      subnet_id    = ovh_cloud_project_network_private_subnet.myprivsub.id
    }
    ```

    Zastosuj konfigurację:

    ```console
    terraform apply
    ```
  </Tab>
</Tabs>
