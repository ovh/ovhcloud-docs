## Wprowadzenie

Jeśli chcesz skonfigurować adres Additional IP w swoich instancjach, ponieważ:

- masz w instancji wiele witryn internetowych, 
- obsługujesz projekty międzynarodowe,
- chcesz migrować z serwera dedykowanego do instancji Public Cloud,

Można zaimportować adres Additional IP powiązany z inną usługą OVHcloud.

**Dowiedz się, jak zaimportować adres Additional IP do projektu OVHcloud Public Cloud.**

## Wymagania początkowe

- [Projekt Public Cloud](/links/public-cloud/public-cloud) na koncie OVHcloud
- [Adres Additional IP](/links/bare-metal/ip)

:::warning
Ta funkcja nie jest aktualnie dostępna dla instancji Metal.

:::


## W praktyce

W menu po lewej stronie otwórz <code className="action">Public IP</code> w sekcji **Sieć**.

Otwórz kartę <code className="action">Additional IP</code> i kliknij <code className="action">Importuj adres Additional IP</code>, aby wyświetlić wszystkie adresy IP, które mogą być importowane do Twojego projektu Public Cloud.

Kliknij ikonę <code className="action">Importuj ten adres Additional IP</code> w wierszu adresu IP, który chcesz zaimportować, a następnie zatwierdź, klikając <code className="action">Importuj</code>.

Odczekaj kilka minut, aż import zostanie zrealizowany. Otwórz zakładkę <code className="action">Additional IP</code>, aby wyszukać zaimportowany adres Additional IP. W razie potrzeby odśwież stronę.

Kliknij <code className="action">...</code> w wierszu adresu IP i wybierz <code className="action">Zmień przypisaną instancję</code>. W wyświetlonym panelu wybierz w polu **Wybierz instancję** instancję, do której ma zostać przypisany Twój adres IP.

Kliknij <code className="action">Podłącz</code>, aby potwierdzić.

:::warning
Dodatkowy adres IP nie może być przenoszony między różnymi strefami. Na przykład adres IP zlokalizowany w centrum danych SBG może zostać przeniesiony do GRA lub RBX, ale nie do BHS.

:::


Twój adres Additional IP zostanie teraz przypisany do Twojej instancji.

Następnym krokiem jest konfiguracja IP w systemie operacyjnym. Zapoznaj się [z przewodnikiem dotyczącym tej konfiguracji](/guides/public-cloud/network-services/configure-additional-ip).
