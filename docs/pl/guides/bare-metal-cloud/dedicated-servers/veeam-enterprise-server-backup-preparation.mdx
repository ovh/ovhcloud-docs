## W praktyce

### Konfiguracja serwera dedykowanego

Serwer Bare Metal OVHcloud musi być zainstalowany i skonfigurowany.

Zapoznaj się z naszymi [przewodnikami dla początkujących](/guides/bare-metal-cloud/dedicated-servers/getting-started-with-dedicated-server) dotyczącymi serwerów dedykowanych.

Możesz również skonfigurować serwer dedykowany do korzystania z sieci prywatnej, wykonując kroki opisane w [tym przewodniku](/guides/bare-metal-cloud/dedicated-servers/vrack-configuring-on-dedicated-server).

### Konfiguracja serwera kopii zapasowych Veeam Enterprise

Pobierz i zainstaluj serwer kopii zapasowych Veeam Enterprise oraz przypisz mu licencję, korzystając z naszego przewodnika [Konfiguracja Veeam Backup & Replication](/guides/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication).

Następnie możesz kontynuować lekturę, aby dowiedzieć się, jak skonfigurować Object Storage jako repozytorium, lub przejść bezpośrednio do sekcji [Sprawdź również](#gofurther).

### Konfiguracja Object Storage

Object Storage możesz utworzyć i skonfigurować w sekcji <code className="action">Public Cloud</code> konsoli OVHcloud, w części <code className="action">Object Storage</code> Twojego projektu Public Cloud.

Jeśli nie masz jeszcze projektu Public Cloud na koncie OVHcloud, zapoznaj się z naszym przewodnikiem [Tworzenie pierwszego projektu Public Cloud](/guides/public-cloud/cross-functional/create-a-public-cloud-project).

[Utwórz kontener Object Storage](/guides/storage-and-backup/object-storage/s3-getting-started-with-object-storage), korzystając z jednego z **rozwiązań Object Storage OVHcloud (Standard lub High Performance)**. Zalecamy rozwiązanie Standard, ponieważ ta kopia zapasowa zazwyczaj nie wymaga przestrzeni dyskowej High Performance.

:::info
Zamawiając kontener Object Storage w OVHcloud, wybierz wyłącznie **Standard Object Storage** lub **High Performance Object Storage**. Kontenery te w pełni obsługują protokół Amazon S3<sup>1</sup> i zostały zaprojektowane do użytku jako repozytoria kopii zapasowych.

:::


Nadaj użytkownikowi Object Storage uprawnienia do kontenera, kopiując i wklejając poniższy tekst do pliku JSON.

```json
{
  "Statement":[
    {
      "Action":
         [
             "s3:GetObject",
             "s3:PutObject",
             "s3:DeleteObject",
             "s3:ListBucket",
             "s3:ListMultipartUploadParts",
             "s3:ListBucketMultipartUploads",
             "s3:AbortMultipartUpload",
             "s3:GetBucketLocation"
          ],
      "Effect":"Allow",
      "Resource":
          [
              "arn:aws:s3:::<container name>",
              "arn:aws:s3:::<container name>/*"
          ],
      "Sid":"RWContainer"
     }
  ]
}
```

Zastąp `container name` rzeczywistą nazwą Twojego kontenera Object Storage.

W zakładce <code className="action">Użytkownicy</code> strony **Object Storage** kliknij przycisk <code className="action">⋮</code> w kolumnie **Akcje** użytkownika Object Storage i wybierz <code className="action">Importuj politykę</code>.

W oknie **Importuj politykę** wybierz zmodyfikowany przed chwilą plik JSON i kliknij <code className="action">Importuj</code>. Zaimportowana polityka zastępuje bieżącą politykę użytkownika: jeśli ten użytkownik ma już politykę, najpierw pobierz ją za pomocą opcji <code className="action">Pobierz politykę</code> (w tym samym menu) i dodaj tę deklarację do jej listy `Statement` przed zaimportowaniem.

### Konfiguracja repozytorium Object Storage w Veeam Enterprise

W aplikacji Veeam wybierz <code className="action">Backup Infrastructure</code>, <code className="action">Backup Repositories</code> i <code className="action">Add Repository</code>.

<img className="thumbnail" alt="Veeam - dodawanie repozytorium" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-02.png" loading="lazy" />

Wybierz <code className="action">Object storage</code> jako typ repozytorium.

<img className="thumbnail" alt="Veeam - Object Storage" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-03.png" loading="lazy" />

Wybierz <code className="action">S3 Compatible</code>.

<img className="thumbnail" alt="Veeam - zgodność z S3" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-04.png" loading="lazy" />

Wpisz nazwę nowego repozytorium w polu **Name** i kliknij <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - nazwa repozytorium" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-05.png" loading="lazy" />

Wprowadź informacje **Service point** (Endpoint) i **Region** dotyczące usługi Object Storage.

> Informacje te znajdziesz w sekcji <code className="action">Public Cloud</code> konsoli OVHcloud.
> Kliknij <code className="action">Object Storage</code>, następnie w zakładce <code className="action">Kontenery</code> kliknij nazwę Twojego kontenera, a potem otwórz jego zakładkę <code className="action">Przegląd</code>. **Region** jest wyświetlany w sekcji **Informacje ogólne** (a także w kolumnie **Region** listy kontenerów), a **Endpoint** w sekcji **Szczegóły połączenia**.

<img className="thumbnail" alt="Veeam - endpoint usługi i region" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-08.png" loading="lazy" />

Kliknij <code className="action">Add</code>, aby wprowadzić dane uwierzytelniające. Wpisz **Access key** i **Secret key**, a następnie kliknij <code className="action">OK</code>.

> Informacje te są dostępne w konsoli OVHcloud, w zakładce <code className="action">Użytkownicy</code> strony **Object Storage**. **Klucz dostępu** (Access key) jest wyświetlany w kolumnie **Klucz dostępu** listy użytkowników.
> Aby uzyskać **Klucz tajny** (Secret key), kliknij przycisk <code className="action">⋮</code> w kolumnie **Akcje** użytkownika i wybierz <code className="action">Pokaż klucz tajny</code>. Klucz zostanie wyświetlony w oknie **Poświadczenia S3**.

<img className="thumbnail" alt="Veeam - klucze" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-10.png" loading="lazy" />

Kliknij <code className="action">Browse...</code>, aby wybrać **Bucket**.

<img className="thumbnail" alt="Veeam - bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-11.png" loading="lazy" />

Wybierz bucket i kliknij <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-12.png" loading="lazy" />

Kliknij <code className="action">Browse...</code>, aby wybrać **Folder**.

<img className="thumbnail" alt="Veeam - folder" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-13.png" loading="lazy" />

Kliknij <code className="action">New Folder</code>, wpisz nazwę folderu, zaznacz go, a następnie kliknij <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - folder" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-14.png" loading="lazy" />

Na ekranie "Mount Server" kliknij <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - Mount Server" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-15.png" loading="lazy" />

Na ekranie "Review" kliknij <code className="action">Apply</code>.

<img className="thumbnail" alt="Veeam - przegląd" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-16.png" loading="lazy" />

Po pomyślnym zakończeniu procesów kliknij <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - zakończenie procesów" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-17.png" loading="lazy" />

Sprawdź stronę "Summary" i kliknij <code className="action">Finish</code>.

<img className="thumbnail" alt="Veeam - podsumowanie" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-18.png" loading="lazy" />

Lista Backup Repositories powinna teraz wyglądać podobnie do poniższej:

<img className="thumbnail" alt="Veeam - repozytoria" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-19.png" loading="lazy" />

Możesz teraz przejść do wykonania kopii zapasowej za pomocą Veeam Enterprise.
