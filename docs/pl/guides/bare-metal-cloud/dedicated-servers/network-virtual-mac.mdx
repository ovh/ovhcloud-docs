## Wprowadzenie

OVHcloud umożliwia Ci powiązanie wirtualnego adresu MAC z adresem IP, abyś mógł wdrażać na Twoim serwerze wirtualne maszyny z konfiguracją mostka sieciowego.

**Niniejszy przewodnik wyjaśnia, jak utworzyć wirtualny adres MAC i jak go powiązać z adresem Additional IP.**

## Wymagania początkowe

- Posiadanie [serwera dedykowanego](/links/bare-metal/bare-metal). Twój serwer musi obsługiwać wirtualne adresy MAC. Zapoznaj się [z tym przewodnikiem](/guides/bare-metal-cloud/dedicated-servers/network-support-virtual-mac).
- Posiadanie [adresu Additional IP](/links/network/additional-ip) lub bloku Additional IP (RIPE)

:::warning
- Funkcja ta może być niedostępna lub ograniczona na [serwerach dedykowanych **Eco**](/links/bare-metal/eco-about). Aby uzyskać więcej informacji, zapoznaj się z naszym [porównaniem](/links/bare-metal/eco-compare).

- Serwery Advance trzeciej generacji (wyposażone w procesory EPYC 4004 Series) obsługują 32 różne sieci vMAC.

- Od maja 2025 funkcja ta jest dostępna w ofercie Scale i High Grade.

:::


:::info
Jeśli nie jesteś zaznajomiony z korzystaniem z API OVHcloud, zapoznaj się z naszym przewodnikiem [Pierwsze kroki z API OVHcloud](/guides/manage-and-operate/api/first-steps).

:::

## W praktyce

### Przypisanie adresu MAC

:::warning
Jeśli blok IP został przeniesiony do sieci vRack, nie jest już przypisany do fizycznego serwera w tym celu, nie można przypisać wirtualnego adresu MAC do IP.

:::


#### Za pośrednictwem konsoli OVHcloud

Kliknij filtr <code className="action">Dodatkowy adres IP</code> nad listą, aby wyświetlić tylko Twoje adresy Additional IP.

Odszukaj na liście Twój adres Additional IP (lub blok) i kliknij go, aby otworzyć jego stronę, po czym kliknij zakładkę <code className="action">Wirtualny MAC</code>. W przypadku bloku rozwijana lista **Pokaż wirtualne MAC dla** pozwala wybrać adres IP, którego wirtualne adresy MAC są wyświetlane. Kliknij <code className="action">Dodaj wirtualny MAC</code>.

Po wyświetleniu okna **Dodaj wirtualny MAC** wybierz adres IP z listy **Adres IP** (tylko w przypadku bloku), wybierz typ z rozwijanej listy **Typ**, wprowadź nazwę w polu **Maszyna wirtualna** i kliknij <code className="action">Dodaj</code>.

:::info
**Typ**: jest to rodzaj wirtualnego adresu MAC (<code className="action">vmware</code> będzie adresem MAC utworzonym dla systemu VMware ESXi, podczas gdy <code className="action">ovh</code> będzie odpowiedni dla wszystkich innych systemów wirtualizacji).

**Maszyna wirtualna**: jest to nazwa dla wirtualnego adresu MAC ułatwiająca późniejsze odnalezienie pary IP/MAC.

Jeśli Twój serwer ma już wirtualne adresy MAC, w oknie możesz wybrać między <code className="action">Utwórz nowy wirtualny adres MAC</code> a <code className="action">Użyj istniejącego wirtualnego adresu MAC</code>. W przypadku drugiej opcji zamiast typu wybierz adres MAC, który chcesz ponownie wykorzystać.

:::

:::info
Pamiętaj, aby przypisać wirtualny adres MAC podczas konfiguracji Twojej wirtualnej maszyny.

:::


#### Za pośrednictwem API OVHcloud

Skorzystaj z następującego wywołania API:

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/virtualMac"} />


### Usuwanie adresu MAC

:::warning
Usunięcie adresu MAC jest nieodwracalne, nie jest możliwe jego późniejsze przywrócenie.

:::


#### Za pośrednictwem konsoli OVHcloud

Na stronie **Adresy IP** użyj rozwijanej listy **Filtruj według usługi...** lub paska wyszukiwania, aby znaleźć adres Additional IP (lub blok IP), po czym kliknij go, aby otworzyć jego stronę, i kliknij zakładkę <code className="action">Wirtualny MAC</code>. W przypadku bloku wybierz adres IP z rozwijanej listy **Pokaż wirtualne MAC dla**.

Każdy wirtualny MAC jest wyświetlany pod swoim adresem MAC. Kliknij <code className="action">Usuń</code> pod wirtualnym MAC, a następnie kliknij <code className="action">Usuń</code> w oknie **Usuń wirtualny adres MAC**, aby potwierdzić.

#### Za pośrednictwem API OVHcloud

Skorzystaj z następującego wywołania API:

<Api version="v1" section="/dedicated/server" method="DELETE" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


## FAQ

- **Co się stanie, jeśli przeniosę blok z vMAC na serwer Advance trzeciej generacji (wyposażony w procesor EPYC 4004 Series) posiadający już 32 vMAC?**

Blok nie zostanie przeniesiony.

Przykład: jeśli spróbujesz przenieść blok 4 adresów IP z różnymi adresami vMAC przypisanymi do serwera, który ma już 30 vMAC, blok nie zostanie przeniesiony, ponieważ całkowita liczba vMAC byłaby większa niż 32 dozwolone sieci vMAC.
