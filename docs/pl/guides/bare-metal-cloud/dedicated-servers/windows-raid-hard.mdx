## Wprowadzenie

Podczas instalacji systemu Windows na serwerze ze sprzętową konfiguracją RAID partycję RAID należy utworzyć ręcznie.

**Niniejszy przewodnik wyjaśnia, jak utworzyć partycję Windows na serwerze ze sprzętowym RAID.**

## Wymagania początkowe

- [Serwer dedykowany](/links/bare-metal/bare-metal) z zainstalowanym systemem Windows i sprzętową kartą RAID (LSI MegaRaid)
- Co najmniej dwa identyczne dyski

## W praktyce

:::warning
Wykonanie czynności opisanych w tym przewodniku wymaga usunięcia i ponownego utworzenia istniejącego wolumenu RAID. Oznacza to, że wszystkie istniejące dane zostaną utracone. Przed rozpoczęciem wykonaj kopię zapasową danych. Przewodnik przeznaczony jest dla doświadczonych użytkowników.
:::


### Wyświetlanie istniejących wolumenów RAID
Najpierw należy wyświetlić listę istniejących wolumenów RAID, aby móc je usunąć. W tym celu użyj następującego polecenia: <code className="action">MegaCli -LDInfo -Lall -aAll</code>.

```sh
# root@rescue:~# MegaCli -LDInfo -Lall -aAll
 
Adapter 0 -- Virtual Drive Information:
Virtual Drive: 0 (Target Id: 0)

Name                 :
RAID Level           : Primary-5, Secondary-0, RAID Level Qualifier-3
Size                 : 3.637 TB
Sector Size          : 512
Is VD emulated       : No
Parity Size          : 1.818 TB
State                : Optimal
Strip Size           : 256 KB
Number Of Drives     : 3
Span Depth           : 1
Default Cache Policy : WriteBack, ReadAhead, Direct, No Write Cache if Bad BBU
Current Cache Policy : WriteBack, ReadAhead, Direct, No Write Cache if Bad BBU
Default Access Policy: Read/Write
Current Access Policy: Read/Write
Disk Cache Policy    : Disk's Default
Encryption Type      : None
Bad Blocks Exist     : No
PI type              : No PI
 
Is VD Cached: No
 
Exit Code: 0x00
```

Powyższe wyniki pokazują, że na serwerze znajduje się obecnie tylko jeden wolumen RAID, a serwer ma **Virtual Drive** `0`.

### Usuwanie RAID
Teraz możesz usunąć istniejący RAID, a następnie utworzyć nowy.

W tym celu użyj poniższego polecenia. Potrzebny będzie numer **Virtual Drive** uzyskany w poprzednim kroku.

<code className="action">MegaCli -CfgLDDel -Lx -a0</code>

`x` to numer **Virtual Drive**.

Przykład:

```sh
# root@rescue:~# MegaCli -CfgLDDel -L0 -a0
 
Adapter 0: Deleted Virtual Drive-0(target id-0)
 
Exit Code: 0x00
```

:::info
Jeśli na serwerze istnieje już więcej niż jeden RAID, powtórz operację dla każdego numeru **Virtual Drive**.
:::


### Pobieranie identyfikatorów dysków
Teraz pobierz **Enclosure ID** i **SlotID** dysków serwera, aby utworzyć nowy RAID.

W tym celu użyj następującego polecenia: <code className="action">MegaCli -PdList -aALL | egrep -i "Adapter|Slot|Enclosure Device"</code>.

Przykład:

```sh
# root@rescue:~# MegaCli -PdList -aALL | egrep -i "Adapter|Slot|Enclosure Device"
Adapter #0
Enclosure Device ID: 252
Slot Number: 0
Enclosure Device ID: 252
Slot Number: 1
Enclosure Device ID: 252
Slot Number: 2
```

Na serwerze znajdują się trzy dyski. Ich **Enclosure ID** i **SlotID** to odpowiednio 252:0, 252:1 i 252:2.

### Tworzenie nowego RAID
Najpierw utwórz pierwszy RAID, który będzie używany przez system operacyjny.

Użyj następującego polecenia: <code className="action">MegaCli -CfgLdAdd -rX[EncID:SlotID,EncID:SlotID,...] -szYYYYY -a0</code>.

`X` to wybrany poziom RAID (0, 1, 5 lub 6).

`EncID` to identyfikator obudowy (Enclosure ID) dysku uzyskany w poprzednim kroku.

`SlotID` to identyfikator SlotID dysku uzyskany w poprzednim kroku.

`YYYYY` to rozmiar pierwszego dysku wirtualnego w MB.

W tym przykładzie utworzymy wolumen RAID 5 na trzech dyskach, z 200 GB dla systemu operacyjnego.

:::info
Zalecamy utworzenie wolumenu nieco większego niż wymagany rozmiar minimalny. Dzięki temu system będzie miał miejsce na aktualizacje i instalacje.
:::


```sh
# root@rescue:~# MegaCli -CfgLdAdd -r5[252:0,252:1,252:2] -sz204800 -a0
 
Adapter 0: Created VD 0
 
Adapter 0: Configured the Adapter!!
 
Exit Code: 0x00 
```

Pierwszy RAID został utworzony. Pozostaje tylko przydzielić resztę dostępnej przestrzeni.

Utwórz zatem drugi RAID za pomocą następującego polecenia: <code className="action">MegaCli -CfgLdAdd -rX[EncID:SlotID,EncID:SlotID,...] -a0</code>.

`X` to wybrany poziom RAID (0, 1, 5 lub 6).

`EncID` to identyfikator obudowy (Enclosure ID) dysku uzyskany w poprzednim kroku.

`SlotID` to identyfikator SlotID dysku uzyskany w poprzednim kroku.

Przykład:

```sh
# root@rescue:~# MegaCli -CfgLdAdd -r5[252:0,252:1,252:2] -a0
 
Adapter 0: Created VD 1
 
Adapter 0: Configured the Adapter!!
 
Exit Code: 0x00 
```

Gotowe. Pozostaje jedynie sprawdzić RAID.

### Instalacja systemu Windows z poziomu konsoli OVHcloud
Na koniec zainstaluj system Windows na serwerze.

Zaznacz pole <code className="action">Dostosuj konfigurację partycji</code> i zmień bieżący schemat partycji tak, aby określał tylko dysk **C** o maksymalnym rozmiarze 200 GB.

Po zainstalowaniu systemu zaloguj się do systemu Windows, otwórz narzędzie <code className="action">Zarządzanie dyskami</code>, a następnie utwórz partycję GPT na drugim dysku wirtualnym (odpowiadającym drugiemu RAID, wyświetlanym jako "Nieprzydzielone").
