## Wprowadzenie

Pary kluczy służą do uwierzytelniania połączeń SSH między hostami, na przykład między lokalnym klientem komputera a serwerem zdalnym. Podczas reinstalacji serwera dedykowanego lub VPS z poziomu konsoli OVHcloud możesz dodać klucz publiczny do systemu operacyjnego. Przechowywanie publicznych kluczy SSH w konsoli ułatwia ten proces.

**Niniejszy przewodnik wyjaśnia, jak przechowywać publiczne klucze SSH w konsoli OVHcloud.**

## W praktyce

Jeśli jeszcze nie utworzyłeś pary kluczy SSH, zapoznaj się z naszymi przewodnikami:

- [Tworzenie i używanie kluczy SSH](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutorial - Jak używać PuTTY do połączeń SSH i uwierzytelniania](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

<img className="thumbnail" alt="Identity and Access Management group of the Console left menu, with the SSH keys entry" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/sidebar-iam-ssh-keys.png" loading="lazy" />

W menu po lewej stronie konsoli OVHcloud otwórz **Zarządzanie tożsamością i dostępem** i kliknij <code className="action">Klucze SSH</code>.

<img className="thumbnail" alt="SSH keys page with the Add an SSH key button above the list of keys" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-button.png" loading="lazy" />

Otwórz menu <code className="action">Dodaj klucz SSH</code> nad listą i wybierz <code className="action">Serwery dedykowane</code>.

<img className="thumbnail" alt="Add an SSH key menu open, showing the Dedicated and Public Cloud options" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-menu.png" loading="lazy" />

W oknie **Dodaj klucz SSH** skopiuj cały ciąg klucza publicznego i wklej go w pierwszym polu, **Klucz publiczny**. Wklej wyłącznie klucz publiczny (zawartość pliku `.pub`), nigdy klucz prywatny.  
W drugim polu, **Nazwa**, wprowadź nazwę klucza, aby móc go rozpoznać (na przykład nazwę Twojego komputera).

<img className="thumbnail" alt="Add an SSH key window with the Public key and Name fields and the Add button" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-dedicated-window.png" loading="lazy" />

Kliknij <code className="action">Dodaj</code>.

Klucz będzie już dostępny podczas reinstalacji serwera dedykowanego lub serwera VPS w konsoli OVHcloud.
