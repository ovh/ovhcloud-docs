## Wprowadzenie

Windows Server to system operacyjny obsługiwany na serwerach dedykowanych OVHcloud. Po jego zainstalowaniu należy skonfigurować system Windows w taki sposób, aby mógł korzystać z usług sieciowych i przechowywania danych OVHcloud podłączonych do serwera.

Ten przewodnik przedstawia proces instalacji systemu Windows Server z poziomu Panelu klienta OVHcloud, połączenia z serwerem, a następnie wykonania po stronie systemu Windows konfiguracji niezbędnej do korzystania z głównych usług OVHcloud powiązanych z serwerem dedykowanym.

**Z tego przewodnika dowiesz się, jak:**

- Zainstalować system Windows Server z poziomu Panelu klienta
- Połączyć się z serwerem za pomocą pulpitu zdalnego i przeprowadzić wstępną konfigurację
- Skonfigurować system Windows do korzystania z usługi Additional IP
- Skonfigurować system Windows do korzystania z prywatnej sieci vRack
- Skonfigurować system Windows do korzystania z bloku adresów IPv6 dostarczonego wraz z serwerem
- Uzyskać dostęp do usługi OVHcloud Backup Storage z poziomu systemu Windows
- Zabezpieczyć serwer za pomocą zarządzanych kopii zapasowych z wykorzystaniem usługi OVHcloud Backup Agent

:::warning
Ponowna instalacja systemu operacyjnego powoduje usunięcie wszystkich danych z dysków serwera. Przed rozpoczęciem wykonaj kopię zapasową danych, które chcesz zachować.
:::

## Wymagania początkowe

- Posiadanie [serwera dedykowanego](/links/bare-metal/bare-metal) na koncie OVHcloud
- Posiadanie ważnej licencji Windows Server. Licencje można zamówić za pośrednictwem OVHcloud lub wykorzystać licencję od zewnętrznego sprzedawcy — zapoznaj się z przewodnikiem [Zarządzanie licencjami OVHcloud](/guides/bare-metal-cloud/dedicated-servers/windows-key).
- Posiadanie klienta protokołu Remote Desktop (RDP) na komputerze lokalnym (klient <code className="action">Podłączanie pulpitu zdalnego</code> jest dołączony do systemu Windows)

## Wstęp

Serwer dedykowany to fizyczny serwer ("bare metal") hostowany w centrum danych OVHcloud. OVHcloud dostarcza sprzęt, publiczne połączenie sieciowe, opcjonalną prywatną sieć vRack oraz bezpłatną przestrzeń Backup Storage. Za administrowanie systemem operacyjnym zainstalowanym na serwerze, w tym za całą konfigurację sieci i przechowywania danych w systemie Windows, odpowiadasz Ty.

Poniżej przedstawiono usługi, z którymi najczęściej współpracuje serwer dedykowany z systemem Windows.

| Usługa OVHcloud | Zastosowanie | Gdzie ją włączyć |
|---|---|---|
| Additional IP | Dodatkowe publiczne adresy IP powiązane z serwerem | Panel klienta — menu <code className="action">Network</code>, sekcja <code className="action">IP</code> |
| vRack | Prywatna sieć warstwy 2 łącząca usługi OVHcloud | Panel klienta — menu <code className="action">Network</code>, sekcja <code className="action">vRack</code> |
| IPv6 | Blok IPv6 /64 dostarczany z każdym serwerem | Dostarczany automatycznie |
| Backup Storage | Bezpłatna przestrzeń na kopie zapasowe FTP/CIFS (SMB)/NFS | Panel klienta — <ManagerLink to="/#/dedicated-servers/server">Serwery dedykowane</ManagerLink> > Wybierz serwer, zakładka <code className="action">Backup Storage</code> |
| Backup Agent | Zarządzane, codzienne kopie zapasowe w odizolowanym, niezmiennym magazynie Object Storage | Panel klienta — <ManagerLink to="/#/dedicated-servers/server">Serwery dedykowane</ManagerLink> > Wybierz serwer, zakładka <code className="action">Informacje ogólne</code>, sekcja <code className="action">Status usług</code> |

### Etap 1 — Instalacja systemu Windows Server z poziomu Panelu klienta <a name="install"></a>

Na tym etapie instalujesz (lub ponownie instalujesz) system Windows Server na swoim serwerze dedykowanym. Cały proces instalacji odbywa się z poziomu Panelu klienta.

W zakładce <code className="action">Informacje ogólne</code>, obok pozycji <code className="action">System operacyjny (OS)</code>, otwórz menu akcji i kliknij <code className="action">Reinstalacja serwera</code>. Otworzy się okno <code className="action">Instalacja szablonu OVHcloud</code>, które przeprowadzi Cię przez 4 etapy.

:::info
System Windows Server wymaga licencji, która wiąże się z dodatkowymi opłatami. Bez licencji Windows Server powiązanej z serwerem szablony systemu Windows nie są dostępne na liście systemów operacyjnych. Możesz zamówić licencję za pośrednictwem OVHcloud lub dostarczyć własną. Licencjami zarządzasz w sekcji **Bare Metal Cloud** > **Licencje**. Więcej informacji znajdziesz w przewodniku [Zarządzanie licencjami OVHcloud](/guides/bare-metal-cloud/dedicated-servers/windows-key).
:::

:::warning
Ta operacja jest nieodwracalna. Wszystkie dane na dyskach zostaną trwale usunięte.
:::

1. **Rodzaj systemu operacyjnego** — w polu <code className="action">Rodzaj systemu operacyjnego</code> wybierz żądany szablon Windows Server. Szablony są pogrupowane według kategorii (Linux, Windows itd.). Szablony systemu Windows pojawiają się tylko wtedy, gdy z serwerem dedykowanym powiązana jest licencja Windows Server (zobacz uwagę powyżej).
2. **Klaster docelowych dysków** — wybierz <code className="action">Klaster docelowych dysków</code>, na którym zostanie zainstalowany system Windows. Aby zdefiniować własną macierz lub układ, włącz opcję <code className="action">Spersonalizuj konfigurację RAID-u sprzętowego</code> lub <code className="action">Spersonalizuj konfigurację partycji</code>. Szczegółowe informacje na temat programowej macierzy RAID w systemie Windows znajdziesz w przewodniku [Konfiguracja programowej macierzy RAID na serwerze z systemem Windows](/guides/bare-metal-cloud/dedicated-servers/raid-soft-windows).
3. Kliknij <code className="action">Dalej</code> i wykonaj pozostałe etapy kreatora, aby sprawdzić dokonane wybory, a następnie potwierdź, aby rozpocząć instalację.

Serwer uruchomi się ponownie w trybie instalatora, a proces zakończy się automatycznie.

### Etap 2 — Połączenie z serwerem <a name="connect"></a>

Po zakończeniu instalacji OVHcloud wysyła wiadomość e-mail zawierającą nazwę użytkownika i hasło administratora Twojego serwera z systemem Windows.

Na lokalnym komputerze z systemem Windows otwórz klienta <code className="action">Podłączanie pulpitu zdalnego</code>. Wprowadź adres IPv4 swojego serwera, a następnie nazwę użytkownika i hasło. Przy pierwszym połączeniu zwykle pojawia się ostrzeżenie dotyczące certyfikatu — kliknij <code className="action">Tak</code>, aby kontynuować.
Jeśli Twoje urządzenie lokalne nie działa pod kontrolą systemu Windows, możesz skorzystać z dowolnego klienta zgodnego z protokołem RDP innej firmy.

:::tip
Jeśli protokół RDP jest niedostępny — na przykład po błędnej konfiguracji sieci — połącz się za pośrednictwem [konsoli Intelligent Platform Management Interface (IPMI)](/guides/bare-metal-cloud/dedicated-servers/ipmi) z poziomu zakładki <code className="action">IPMI / KVM</code> w Panelu klienta. Konsola IPMI działa niezależnie od stanu łączności systemu operacyjnego.
:::

Po pierwszym połączeniu zmień hasło administratora z poziomu systemu Windows (w sesji RDP naciśnij `Ctrl` + `Alt` + `End` > <code className="action">Zmień hasło</code>).

### Etap 3 — Wstępna konfiguracja systemu Windows <a name="initial-config"></a>

Zanim połączysz serwer z innymi usługami OVHcloud, przeprowadź podstawową konfigurację systemu Windows.

- Uruchom Windows Update i zainstaluj najnowsze aktualizacje.
- Ustaw nazwę hosta serwera, strefę czasową i układ klawiatury.
- Skonfiguruj Zaporę systemu Windows tak, aby zezwalała na usługi, które zamierzasz uruchamiać. Szczegółowy opis konfiguracji zapory w systemie Windows znajdziesz w przewodniku [Aktywacja zapory na serwerze z systemem Windows](/guides/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win).

:::warning
OVHcloud udostępnia Ci usługi, za których konfigurację i zarządzanie odpowiadasz samodzielnie. Jeśli potrzebujesz pomocy, skontaktuj się z [wyspecjalizowanym usługodawcą](/links/partner).
:::

### Etap 4 — Konfiguracja systemu Windows do współpracy z usługami OVHcloud <a name="services"></a>

Ta sekcja opisuje konfigurację po stronie systemu Windows dla usług OVHcloud najczęściej podłączanych do serwera dedykowanego. Każda podsekcja jest niezależna — wykonaj tylko te, które dotyczą Twojej konfiguracji. W każdej z nich pierwsza część jest wykonywana w Panelu klienta OVHcloud, a druga w systemie Windows Server.

#### 4a — Additional IP

Additional IP to dodatkowy publiczny adres IP kierowany do Twojego serwera. Po jego zamówieniu musisz zadeklarować go w systemie Windows, aby serwer odpowiadał na tym adresie.

**W Panelu klienta OVHcloud**

Zamów usługę Additional IP z menu <code className="action">Network</code> Panelu klienta, w sekcji <code className="action">IP</code>, klikając <code className="action">Zamów adresy IP</code>. Więcej informacji znajdziesz na stronie [Additional IP](/links/bare-metal/ip).

**W systemie Windows Server**

1. Otwórz <code className="action">Panel sterowania</code> > <code className="action">Centrum sieci i udostępniania</code> > <code className="action">Zmień ustawienia karty sieciowej</code>, a następnie otwórz właściwości karty sieciowej.
2. Wybierz <code className="action">Protokół internetowy w wersji 4 (TCP/IPv4)</code> > <code className="action">Właściwości</code> > <code className="action">Zaawansowane</code> i dodaj adres Additional IP.

W sieci OVHcloud adres Additional IP jest kierowany indywidualnie do serwera. Użyj maski podsieci i bramy zgodnych z konfiguracją głównego adresu IP Twojego serwera.

:::tip
Jeśli zamierzasz przypisać adres Additional IP do maszyny wirtualnej zamiast do hosta, zapoznaj się z przewodnikiem [Konfiguracja bloku adresów IP w sieci vRack](/guides/bare-metal-cloud/dedicated-servers/configuring-an-ip-block-in-a-vrack).
:::

#### 4b — Prywatna sieć vRack

vRack to prywatna sieć warstwy 2, która umożliwia Twojemu serwerowi dedykowanemu prywatną komunikację z innymi usługami OVHcloud (innymi serwerami dedykowanymi, instancjami Public Cloud itd.).

**W Panelu klienta OVHcloud**

Z menu <code className="action">Network</code> Panelu klienta otwórz sekcję <code className="action">vRack</code>, wybierz swoją sieć vRack i dodaj do niej ten serwer.

**W systemie Windows Server**

1. Otwórz właściwości **prywatnej** karty sieciowej (drugiego interfejsu przeznaczonego dla sieci vRack).
2. Przypisz statyczny prywatny adres IPv4 z planu adresacji Twojej sieci vRack. Pozostaw pole bramy domyślnej puste — vRack to sieć warstwy 2, dla której OVHcloud nie udostępnia bramy.

Pełną procedurę, uwzględniającą kwestie związane z OVHcloud Link Aggregation (OLA, agregacją łączy), znajdziesz w przewodniku [Konfiguracja sieci vRack na serwerze dedykowanym](/guides/bare-metal-cloud/dedicated-servers/vrack-configuring-on-dedicated-server).

#### 4c — IPv6

Każdy serwer dedykowany OVHcloud jest dostarczany z blokiem adresów IPv6 /64. Adres nie jest konfigurowany automatycznie w systemie Windows i należy dodać go ręcznie.

**W Panelu klienta OVHcloud**

Pobierz swój adres IPv6, prefiks i bramę z zakładki <code className="action">Informacje ogólne</code> swojego serwera: sekcja <code className="action">Sieć</code> zawiera pozycje <code className="action">IPv6</code> i <code className="action">Brama IPv6</code>.

**W systemie Windows Server**

1. Otwórz właściwości karty sieciowej i wybierz <code className="action">Protokół internetowy w wersji 6 (TCP/IPv6)</code> > <code className="action">Właściwości</code>.
2. Wprowadź adres IPv6, długość prefiksu oraz domyślną bramę IPv6.

Szczegółowe informacje o adresacji i konfiguracji bramy specyficznej dla OVHcloud znajdziesz w przewodniku [Konfiguracja IPv6](/guides/bare-metal-cloud/dedicated-servers/network-ipv6).

#### 4d — Backup Storage

Backup Storage to bezpłatna przestrzeń dyskowa dołączona do Twojego serwera dedykowanego. Dostęp do niej można uzyskać za pośrednictwem protokołów FTP, CIFS (SMB) lub NFS. Najlepiej sprawdza się jako uzupełniające miejsce docelowe kopii zapasowych.

**W Panelu klienta OVHcloud**

1. W zakładce <code className="action">Backup Storage</code> swojego serwera kliknij <code className="action">Uruchom Backup Storage</code>. Po aktywacji w zakładce wyświetlany jest adres serwera FTP oraz nazwa użytkownika, a także możliwość ustawienia hasła do tej przestrzeni.
2. Autoryzuj adres IP swojego serwera, aby uzyskać dostęp do tej przestrzeni.

**W systemie Windows Server**

Uzyskaj dostęp do tej przestrzeni za pomocą jednego z obsługiwanych protokołów:

- **CIFS (SMB)** — zmapuj ją jako dysk sieciowy (<code className="action">Ten komputer</code> > <code className="action">Mapuj dysk sieciowy</code>).
- **FTP** — połącz się za pomocą dowolnego klienta FTP, korzystając z danych połączenia z Panelu klienta oraz ustawionego hasła.

Szczegółowe informacje o aktywacji i protokołach znajdziesz w przewodniku [Backup Storage na serwerach dedykowanych](/guides/bare-metal-cloud/dedicated-servers/services-backup-storage) oraz na stronie [Backup Storage](/links/bare-metal/backup-storage).

#### 4e — Backup Agent

Backup Storage to pasywna przestrzeń dyskowa — samodzielnie nie wykonuje kopii zapasowych Twoich danych. W celu zapewnienia zarządzanej, automatycznej ochrony OVHcloud oferuje usługę **Backup Agent**, czyli odrębną usługę tworzenia kopii zapasowych dla serwerów Bare Metal. Po jej zamówieniu wdrażasz na serwerze z systemem Windows lekkiego agenta, który następnie wykonuje codzienne, przyrostowe, szyfrowane i niezmienne kopie zapasowe w odizolowanym magazynie Object Storage znajdującym się w innym regionie niż serwer.

**W Panelu klienta OVHcloud**

W zakładce <code className="action">Informacje ogólne</code>, w sekcji <code className="action">Status usług</code>, użyj pozycji <code className="action">Backup Agent</code> i kliknij <code className="action">Zarządzaj agentem kopii zapasowej</code>. Możesz również włączyć ją podczas ponownej instalacji systemu operacyjnego.

**W systemie Windows Server**

Po wdrożeniu agenta skonfiguruj swoją pierwszą kopię zapasową (dane źródłowe, harmonogram i retencję).

Pełną procedurę znajdziesz w przewodnikach [Backup Agent — informacje ogólne](/guides/storage-and-backup/backup-agent/overview) oraz [Konfiguracja pierwszej kopii zapasowej](/guides/storage-and-backup/backup-agent/first-configuration).

### Etap 5 — Weryfikacja konfiguracji <a name="verify"></a>

Sprawdź, czy każda skonfigurowana usługa działa zgodnie z oczekiwaniami.

| Kontrola | Sposób | Oczekiwany rezultat |
|---|---|---|
| Dostęp RDP | Połącz się przez <code className="action">Podłączanie pulpitu zdalnego</code> z głównym adresem IPv4 | Ładuje się pulpit systemu Windows |
| Additional IP | Z zewnętrznego hosta wykonaj `ping` na adres Additional IP | Serwer odpowiada |
| vRack | Z innego elementu sieci vRack wykonaj `ping` na prywatny adres IP | Serwer odpowiada |
| IPv6 | Wykonaj polecenie `ping -6 ipv6.google.com` z serwera | Odpowiedzi są odbierane |
| Backup Storage | Otwórz zmapowany dysk CIFS (SMB) lub połącz się przez FTP | Można odczytywać i zapisywać pliki |

### Rozwiązywanie problemów <a name="troubleshooting"></a>

| Problem | Możliwa przyczyna | Rozwiązanie |
|---|---|---|
| Połączenie RDP nie działa | Reguły firewalla lub ograniczenia sieciowe na urządzeniu lokalnym | Sprawdź lokalne ustawienia zapory i sieci; w ostateczności połącz się przez [konsolę IPMI](/guides/bare-metal-cloud/dedicated-servers/ipmi). |
| Adres Additional IP jest nieosiągalny | Nieprawidłowa maska lub brama w systemie Windows | Ponownie sprawdź wartości wprowadzone w zaawansowanych ustawieniach TCP/IPv4. |
| Element sieci vRack jest nieosiągalny | Nieprawidłowa podsieć prywatna lub brama ustawiona na prywatnej karcie sieciowej | Sprawdź prywatny plan adresacji i pozostaw pole bramy puste. |
| Serwer jest niedostępny po zmianie | Błędna konfiguracja podczas ustawień | Uruchom [tryb rescue](/guides/bare-metal-cloud/dedicated-servers/rescue-customer-windows), aby sprawdzić i naprawić konfigurację. |
