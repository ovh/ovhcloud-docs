## Wprowadzenie

Technologia OVHcloud Link Aggregation (OLA) została zaprojektowana przez nasze zespoły w celu zwiększenia dostępności serwera oraz podniesienia wydajności połączeń sieciowych. Za pomocą kilku kliknięć możesz połączyć karty sieciowe i sprawić, że Twoje połączenia sieciowe staną się redundantne. Oznacza to, że jeśli jedno połączenie zostanie zerwane, ruch zostanie automatycznie przekierowany do innego dostępnego łącza. Dostępna przepustowość jest również podwajana dzięki agregacji.
Agregacja wykorzystuje protokół LACP (Link Aggregation Control Protocol), zdefiniowany w standardzie IEEE 802.3ad.

**Niniejszy przewodnik wyjaśnia, jak skonfigurować NIC Teaming dla OLA w Windows Server 2019.**

## W praktyce

Ponieważ karty sieciowe w OLA mają konfigurację prywatną-prywatną, nie można połączyć się z serwerem przez SSH. W związku z tym, aby uzyskać dostęp do serwera, użyj konsoli IPMI/KVM.

W konsoli OVHcloud otwórz zakładkę <code className="action">Server</code> serwera. W bloku **KVM over IP** sekcji **Server connection** kliknij <code className="action">Z poziomu apletu java (KVM)</code>. Ta opcja jest wyświetlana tylko w przypadku serwerów, których IPMI nie oferuje KVM w przeglądarce (HTML5). W przypadku pozostałych serwerów kliknij <code className="action">Access console (KVM)</code> w tym samym bloku. W oknie **Access KVM console** kliknij <code className="action">Request access</code>, a następnie <code className="action">Open console</code>, aby otworzyć konsolę w przeglądarce. Jeśli w bloku wyświetla się **Not supported**, KVM nie jest dostępny na tym serwerze.

W przypadku apletu Java kliknij <code className="action">Przygotuj aplet java</code> w oknie **Z poziomu apletu java (KVM)**.

W przypadku apletu Java plik JNLP zostanie pobrany automatycznie: otwórz go, aby uzyskać dostęp do IPMI. W obu przypadkach zaloguj się, używając aktualnych danych do logowania do serwera.

Po połączeniu z serwerem otwórz Server Manager. Jeśli nie jest on otwarty domyślnie, znajdziesz go w menu Start.

<img className="thumbnail" alt="Server manager" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/local_server.png" loading="lazy" />

Po otwarciu aplikacji Server Manager, kliknij zakładkę **Local Server** na pasku bocznym po lewej stronie. Następnie kliknij przycisk **Disabled** obok `NIC Teaming`.

<img className="thumbnail" alt="Local server" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/server_manager.png" loading="lazy" />

W oknie dialogowym NIC Teaming, w menu rozwijanym **TASKS** w sekcji "TEAMS", kliknij przycisk **New Team**.

<img className="thumbnail" alt="nic teaming" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/nic_teaming.png" loading="lazy" />

Nadaj nazwę zespołowi i zaznacz karty sieciowe (NIC), których chcesz używać w powiązaniu z OLA. Kliknij strzałkę obok `Additional properties` i zmień tryb `Teaming mode` na **LACP**. Po sprawdzeniu poprawności informacji, kliknij przycisk **OK**.

<img className="thumbnail" alt="New team" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/new_team.png" loading="lazy" />

Uruchomienie zespołu kart sieciowych (NIC) może potrwać do kilku minut. Po zakończeniu tego procesu kliknij ikonkę połączenia sieciowego w prawym dolnym rogu. Teraz kliknij przycisk **Network & Internet settings**. Następnie kliknij przycisk **Ethernet** na pasku bocznym po lewej stronie w oknie.

<img className="thumbnail" alt="network button" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/network_button.png" loading="lazy" />

Kliknij przycisk **Change adapter options**.

<img className="thumbnail" alt="Ethernet" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/ethernet.png" loading="lazy" />

Następnie kliknij prawym przyciskiem myszy zespół kart sieciowych (NIC) i wybierz w menu rozwijanym **Properties**.

<img className="thumbnail" alt="Properties" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/properties.png" loading="lazy" />

W następnym oknie dialogowym, które się pojawi kliknij dwukrotnie przycisk **Internet Protocol Version 4 (TCP/IPv4)**.

<img className="thumbnail" alt="ipv4" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/ipv4.png" loading="lazy" />

Kliknij przycisk obok "Use the following IP address" i dodaj wybrany przez Ciebie prywatny adres IP oraz podsieć. Po sprawdzeniu poprawności ustawień kliknij przycisk **OK**.

<img className="thumbnail" alt="ipv42" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/ipv42.png" loading="lazy" />

Aby sprawdzić, czy zespół kart sieciowych działa, wyślij polecenie ping do innego serwera w tym samym vRack. Jeśli działa, wszystko jest gotowe. W przeciwnym razie sprawdź konfiguracje lub spróbuj zrestartować serwer.
