## Wprowadzenie

Utworzenie migawki jest szybkim i prostym sposobem na zabezpieczenie działania systemu przed wprowadzeniem zmian, które mogą mieć niepożądane lub nieprzewidziane konsekwencje, na przykład podczas testowania nowej konfiguracji albo oprogramowania. Nie stanowi to jednak pełnej strategii tworzenia kopii zapasowych systemu.

**Dowiedz się, jak korzystać z migawek na prywatnym serwerze wirtualnym (VPS) OVHcloud.**

:::info
Przed zastosowaniem opcji tworzenia kopii zapasowych zalecamy przejrzenie [stron produktów oraz często zadawanych pytań (FAQ)](/links/bare-metal/vps-options) w celu porównania cen i uzyskania szczegółowych informacji.

:::


## Wymagania początkowe

- skonfigurowana [usługa VPS](/links/bare-metal/vps) OVHcloud

:::warning
Funkcja ta nie jest aktualnie dostępna dla prywatnych serwerów wirtualnych w [Local Zones](/links/bare-metal/vps-lz).

:::

## W praktyce

### Krok 1: subskrybowanie opcji kopii zapasowej

Na karcie <code className="action">Przegląd</code> przewiń do sekcji **Kopia zapasowa**.  
Jeśli w wierszu **Migawka** widnieje "Włączony", przejdź od razu do etapu 2. Jeśli widnieje "Wyłączone", kliknij link <code className="action">Zamów snapshot</code> pod wierszem **Migawka**.

<img className="thumbnail" alt="Sekcja Kopia zapasowa serwera VPS w konsoli OVHcloud z linkiem Zamów snapshot" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_step1b.png" loading="lazy" />

W panelu, który się otworzy, przeczytaj informację o cenie i kliknij <code className="action">Zamów</code>. Po przejściu kolejnych kroków procesu zamówienia otrzymasz e-mail z potwierdzeniem.

Aby zrezygnować z opcji usługi, kliknij link <code className="action">Rezygnacja</code> pod wierszem **Migawka**, a następnie kliknij <code className="action">Zatwierdź</code> w oknie **Rezygnacja z opcji Snapshot**.

:::warning
Rezygnacja staje się skuteczna w dniu odnowienia opcji i nie można jej cofnąć.
:::

<img className="thumbnail" alt="Wiersz Migawka serwera VPS w konsoli OVHcloud z linkiem Rezygnacja" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_cancel.png" loading="lazy" />

### Krok 2: tworzenie migawki

Po włączeniu opcji kliknij link <code className="action">Utwórz Snapshot</code> pod wierszem **Migawka**. W oknie **Utwórz Snapshot** możesz wpisać opis, który zostanie dołączony do migawki, a następnie kliknij <code className="action">Zatwierdź</code>.

:::warning
Podczas tworzenia migawki Twój serwer VPS jest niedostępny, a poprzednia migawka zostanie utracona.
:::

Czas tworzenia migawki zależy od użytej przestrzeni dyskowej. Następnie odśwież stronę, aby zobaczyć datę utworzenia w wierszu **Migawka** sekcji **Kopia zapasowa**.

### Krok 3: usuwanie / przywracanie migawki

Ponieważ jednocześnie może być aktywna tylko jedna migawka, przed utworzeniem nowej migawki trzeba usunąć istniejącą. W tym celu po prostu kliknij link <code className="action">Usuń Snapshot</code> pod wierszem **Migawka**, a następnie potwierdź, klikając <code className="action">Usuń Snapshot</code> w wyświetlonym oknie.

<img className="thumbnail" alt="Wiersz Migawka serwera VPS w konsoli OVHcloud z linkami dotyczącymi migawki" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_step2.png" loading="lazy" />

Jeśli na pewno chcesz zresetować status prywatnego serwera wirtualnego do stanu z migawki, kliknij <code className="action">Przywróć Snapshot</code> i potwierdź zadanie przywracania w wyświetlonym oknie.

:::warning
Przywrócenie migawki usuwa aktualną wersję serwera VPS i przywraca go do stanu z migawki. Tej operacji nie można cofnąć.
:::

:::danger
Pamiętaj, że przywrócenie systemu ze snapshota spowoduje usunięcie samego snapshota. Jeśli chcesz zachować tę samą migawkę, musisz wykonać nową przed wprowadzeniem zmian w przywróconym systemie.

Jeśli funkcja snapshot jest zbyt ograniczona dla Twojego projektu, opcja [automatyczne kopie zapasowe](/guides/bare-metal-cloud/virtual-private-servers/using-automated-backups-on-a-vps) jest alternatywna.

:::


### Pobierz snapshot

Bieżący snapshot można pobrać za pomocą linku do pobrania. Kliknij link <code className="action">Pobierz snapshot</code> pod wierszem **Migawka**.

<img className="thumbnail" alt="Sekcja Kopia zapasowa serwera VPS w konsoli OVHcloud z linkiem Pobierz snapshot" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps03.png" loading="lazy" />

:::info
Jeśli Twój VPS pochodzi ze starej gamy, możliwe, że otrzymasz komunikat o błędzie, ponieważ opcja nie jest dostępna na starych serwerach VPS. Twój VPS pochodzi z poprzedniej gamy serwerów, jeśli jego model nazewnictwa jest podobny do: *vpsXXXX.ovh.net* (gdzie *X* oznacza liczbę). Możesz sprawdzić tę nazwę serwera w nagłówku strony Twojego serwera VPS w <ManagerLink to="/">konsoli OVHcloud</ManagerLink>.

:::

W panelu **Pobierz snapshot** kliknij <code className="action">Wygeneruj link do pobrania</code>.

<img className="thumbnail" alt="Panel Pobierz snapshot w konsoli OVHcloud z przyciskiem Wygeneruj link do pobrania" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps04.png" loading="lazy" />

Po kilku sekundach pojawi się komunikat o sukcesie. Poniżej możesz skopiować pełne polecenie pobrania za pomocą jednego kliknięcia, a następnie uruchomić je w terminalu.

<img className="thumbnail" alt="Panel Pobierz snapshot w konsoli OVHcloud z wygenerowanym poleceniem pobrania" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps05.png" loading="lazy" />

Rozmiar snapshota jest również wyświetlany w sekcji **Informacje**.

Link do pobrania wygaśnie po **24 godzinach**.

W poleceniu do pobrania stosuje się `curl` w następującym formacie:

```bash
curl "https://storage.sbg.cloud.ovh.net/v1/AUTH_f5fgh4674dd706f15f6ffgf4z667d3f4g5f05/glance/5ceg3f93-8b49-436b-aefe-4185f9fc3f78?
temp_url_sig=f508cacda60256d5f211ddddf3f81130e935f0e4&temp_url_expires=1678247579" --output vps-x11x11xyy.vps.ovh.net --fail
```

Polecenie to musi działać z dowolnego terminala wiersza poleceń. Jednakże, podczas korzystania z systemu Windows *PowerShell*, należy dostosować komendę w następujący sposób:

```powershell
curl -Uri "https://storage.sbg.cloud.ovh.net/v1/AUTH_f5fgh4674dd706f15f6ffgf4z667d3f4g5f05/glance/5ceg3f93-8b49-436b-aefe-4185f9fc3f78?
temp_url_sig=f508cacda60256d5f211ddddf3f81130e935f0e4&temp_url_expires=1678247579" -OutFile vps-x11x11xyy.vps.ovh.net
```

<img className="thumbnail" alt="snapshotvps" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/snapshot_vps06.png" loading="lazy" />

:::info
Aby uniknąć utraty zbyt dużej ilości przestrzeni dyskowej, zalecamy usunięcie kopii zapasowych snapshot bezpośrednio z serwera VPS.

Pobrany plik można zaimportować do projektu Public Cloud (QCOW2) jako obraz za pośrednictwem [OpenStack](/guides/public-cloud/compute/overview). (Przykład zastosowania znajduje się w [tym przewodniku](/guides/public-cloud/compute/upload-own-image).)

### Dobre praktyki dotyczące tworzenia migawek

#### Konfiguracja agenta QEMU na serwerze VPS

Migawki to kopie systemu tworzone w ściśle określonym momencie (“live snapshots”). Aby zapewnić dostępność systemu podczas tworzenia migawki, wykorzystywany jest agent QEMU, który pozwala przygotować system plików do tego procesu.

W większości dystrybucji wymagany *qemu-guest-agent* nie jest zainstalowany domyślnie. Ponadto, wymogi licencyjne mogą uniemożliwić OVHcloud włączenie go do dostępnych obrazów systemu operacyjnego. Dlatego zalecamy zainstalowanie agenta, jeśli nie jest on aktywowany na Twoim prywatnym serwerze wirtualnym. W tym celu połącz się z VPS przez SSH i postępuj zgodnie z poleceniami dotyczącymi Twojego systemu operacyjnego.

##### **Dystrybucje Debian (Debian, Ubuntu)**

Wprowadź poniższą komendę, aby sprawdzić, czy system został poprawnie skonfigurowany pod kątem tworzenia migawek:

```bash
file /dev/virtio-ports/org.qemu.guest_agent.0
/dev/virtio-ports/org.qemu.guest_agent.0: symbolic link to ../vport2p1
```

Jeśli wynik jest inny (“No such file or directory”), zainstaluj najnowszy pakiet:

```bash
sudo apt-get update
sudo apt-get install qemu-guest-agent
```

Uruchom usługę, aby upewnić się, że działa:

```bash
sudo service qemu-guest-agent start
```

##### **Dystrybucje Redhat (CentOS, Fedora)**

Wprowadź poniższą komendę, aby sprawdzić, czy system został poprawnie skonfigurowany pod kątem tworzenia migawek:

```bash
file /dev/virtio-ports/org.qemu.guest_agent.0
/dev/virtio-ports/org.qemu.guest_agent.0: symbolic link to ../vport2p1
```

Jeśli wynik jest inny (“No such file or directory”), zainstaluj i aktywuj agenta:

```bash
sudo yum install qemu-guest-agent
sudo chkconfig qemu-guest-agent on
```

Uruchom agenta i sprawdź, czy działa:

```bash
sudo service qemu-guest-agent start
sudo service qemu-guest-agent status
```

##### **Windows**

Możesz zainstalować agenta, korzystając z pliku MSI, dostępnego na stronie projektu Fedora [https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/latest-qemu-ga/](https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/latest-qemu-ga/).

Sprawdź, czy usługa działa za pomocą poniższej komendy *PowerShell*:

```powershell
PS C:\Users\Administrator> Get-Service QEMU-GA

Status   Name               DisplayName
------   ----               -----------
Running  QEMU-GA            QEMU Guest Agent
```
