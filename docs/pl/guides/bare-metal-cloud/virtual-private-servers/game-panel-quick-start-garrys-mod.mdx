## Wprowadzenie

Game Panel umożliwia wdrożenie serwera Garry's Mod z automatyczną instalacją i konfiguracją portów.

**Ten przewodnik wyjaśnia, jak wdrożyć serwer Garry's Mod w Game Panel i połączyć się z nim.**

## Wymagania początkowe

- [VPS](https://www.ovhcloud.com/pl/vps/) na koncie OVHcloud z włączoną funkcją Game Panel.
- Dostęp do Game Panel. Zapoznaj się z przewodnikiem [Logowanie do Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## W praktyce

### Etap 1 — Uzyskiwanie dostępu do Game Panel

Zaloguj się do Game Panel. Przejdź do sekcji <code className="action">Game Servers</code> w menu po lewej stronie.

<img className="thumbnail" alt="Sekcja Game Servers z przyciskiem Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/game-servers-list.png" loading="lazy" />

### Etap 2 — Tworzenie serwera Garry's Mod

Kliknij <code className="action">Add Game Server</code> i wybierz **Garrys Mod** z listy.

<img className="thumbnail" alt="Wybór Garry's Mod z listy gier" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/select-garrys-mod.png" loading="lazy" />

Skonfiguruj instalację:

- <code className="action">Server Name</code>: nadaj nazwę swojemu serwerowi (na przykład `Garrys Mod Server`).
- <code className="action">Network Ports</code>: pozostaw domyślne porty lub dodaj kolejne w razie potrzeby w sekcji zaawansowanej. Garry's Mod zwykle używa portów w okolicach `27015`.

### Etap 3 — Uruchamianie instalacji

Kliknij <code className="action">Select</code>. Wdrożenie rozpocznie się automatycznie. Poczekaj kilka minut, aż obraz zostanie pobrany, a serwer zainstalowany.

Następnie kliknij <code className="action">Launch</code>, aby uruchomić serwer.

### Etap 4 — Sprawdzanie, czy serwer działa

Upewnij się, że status serwera wyświetla **Running** oraz że widoczna jest aktywność CPU/RAM.

<img className="thumbnail" alt="Serwer Garry's Mod ze statusem Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-running.png" loading="lazy" />

Dostępne działania:

- <code className="action">Log/Console</code>: otwórz konsolę, aby monitorować uruchamianie i sprawdzić logi w razie problemów.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: uzyskaj dostęp do ustawień gry (mapa startowa, tickrate, gamemode, limit graczy, hasło RCON, kolekcja Workshop, GSLT).

<img className="thumbnail" alt="Ustawienia Game Config dla Garry's Mod" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-game-config.png" loading="lazy" />

### Etap 5 — Łączenie się z serwerem

W kolumnie <code className="action">Connection</code> znajdziesz adres IP i port (na przykład `xxx.xxx.xxx.xxx:27015`).

W Garry's Mod:

1. Otwórz konsolę (`~`).
2. Wpisz:

    ```console
    connect IP:PORT
    ```

:::info
Aby pójść dalej, dodaj mody lub kolekcje Workshop, dostosuj tickrate i ustawienia wydajności albo ogranicz dostęp za pomocą hasła lub białej listy.
:::
