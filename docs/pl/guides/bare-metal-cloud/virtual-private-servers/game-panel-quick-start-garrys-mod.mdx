## Objective

The Game Panel lets you deploy a Garry's Mod server with automated installation and port configuration.

**This guide explains how to deploy and connect to a Garry's Mod server on the Game Panel.**

## Requirements

- A [VPS](https://www.ovhcloud.com/en-gb/vps/) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your Game Panel. Go to the <code className="action">Game Servers</code> section in the left-hand menu.

<img className="thumbnail" alt="Game Servers section with Add Game Server button" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/game-servers-list.png" loading="lazy" />

### Step 2 — Create a Garry's Mod server

Click <code className="action">Add Game Server</code> and select **Garrys Mod** from the list.

<img className="thumbnail" alt="Selecting Garry's Mod from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/select-garrys-mod.png" loading="lazy" />

Configure the installation:

- <code className="action">Server Name</code>: Give your server a name (e.g., `Garrys Mod Server`).
- <code className="action">Network Ports</code>: Leave the default ports or add more if needed in the advanced section. Garry's Mod typically uses ports around `27015`.

### Step 3 — Launch the installation

Click <code className="action">Install</code>. The deployment starts automatically. Wait a few minutes while the image downloads and the server installs.

Then click <code className="action">Launch</code> to start the server.

### Step 4 — Verify the server is running

Check that the server status displays **Running** and that CPU/RAM activity is visible.

<img className="thumbnail" alt="Garry's Mod server with Running status" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-running.png" loading="lazy" />

Available actions:

- <code className="action">Console</code>: Open the console to monitor startup.
- <code className="action">Logs</code>: Check logs if there are any issues.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: Access game settings (startup map, tickrate, gamemode, player limit, RCON password, Workshop collection, GSLT).

<img className="thumbnail" alt="Garry's Mod Game Config settings" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-game-config.png" loading="lazy" />

### Step 5 — Connect to the server

In the <code className="action">Connection</code> column, you will find the IP address and port (e.g., `xxx.xxx.xxx.xxx:27015`).

In Garry's Mod:

1. Open the console (`~`).
2. Type:

    ```console
    connect IP:PORT
    ```

:::info
To go further, add mods or Workshop collections, adjust tickrate and performance settings, or restrict access with a password or whitelist.
:::
