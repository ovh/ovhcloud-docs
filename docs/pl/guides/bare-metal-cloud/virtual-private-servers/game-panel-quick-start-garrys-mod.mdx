## Wprowadzenie

Game Panel umożliwia wdrożenie serwera Garry's Mod z automatyczną instalacją i konfiguracją portów.

**Ten przewodnik wyjaśnia, jak wdrożyć serwer Garry's Mod w Game Panel i połączyć się z nim.**

## Wymagania początkowe

- [VPS](/links/bare-metal/vps) lub [serwer dedykowany](/links/bare-metal/bare-metal) na koncie OVHcloud z włączoną funkcją Game Panel.
- Dostęp do Game Panel. Zapoznaj się z przewodnikiem [Logowanie do Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## W praktyce

### Etap 1 — Uzyskanie dostępu do Game Panel

Zaloguj się do Game Panel. Przejdź do sekcji `Game Servers` w menu po lewej stronie i kliknij <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Sekcja Game Servers z przyciskiem Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/game-servers-list.png" loading="lazy" />

### Etap 2 — Utworzenie serwera Garry's Mod

Wybierz **Garry's Mod** z listy gier. Otworzy się okno konfiguracji.

<img className="thumbnail" alt="Wybór Garry's Mod z listy gier" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/select-garrys-mod.png" loading="lazy" />

### Etap 3 — Konfiguracja serwera Garry's Mod

Wprowadź **Server Name** (na przykład `Garry's Mod Server`). Wymagane porty sieciowe są konfigurowane automatycznie podczas instalacji.

Możesz rozwinąć sekcję <code className="action">Advanced settings</code>, aby dostosować opcje takie jak przypisanie portów (ports binding) i limity zasobów. Wartości domyślne są odpowiednie dla większości serwerów gier.

### Etap 4 — Uruchomienie instalacji

Kliknij <code className="action">Install</code>. Wdrożenie rozpocznie się automatycznie. Poczekaj kilka minut, aż obraz zostanie pobrany, a serwer zainstalowany.

### Etap 5 — Monitorowanie instalacji

Kliknij <code className="action">Log/Console</code>, aby śledzić postęp w czasie rzeczywistym. Status wyświetla się jako **Installing**.

### Etap 6 — Potwierdzenie zakończenia instalacji

Po zakończeniu instalacji i uruchomieniu serwera status zmienia się na **Running**.

### Etap 7 — Sprawdzenie, czy serwer działa

Upewnij się, że widoczna jest aktywność CPU i RAM. Do zarządzania serwerem możesz używać przycisków <code className="action">Log/Console</code> i <code className="action">Settings</code>.

<img className="thumbnail" alt="Serwer Garry's Mod ze statusem Running i widoczną aktywnością CPU i RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-running.png" loading="lazy" />

### Etap 8 — Pobranie informacji o połączeniu

Skopiuj adres IP i port z kolumny **Connection** na liście Game Servers.

### Etap 9 — Dołączenie do serwera w grze Garry's Mod

Najpierw dodaj serwer do ulubionych w Steam:

1. W **Steam** przejdź do **View** > **Game Servers**.
2. Otwórz kartę **Favorites** i kliknij **Add a server**.
3. Wklej adres IP i port z kolumny **Connection**, a następnie kliknij **OK**.

Następnie dołącz do serwera z poziomu gry:

1. Uruchom **Garry's Mod** i kliknij **Find Multiplayer Game**.
2. Otwórz kartę **Favorites**.
3. Wybierz swój serwer i kliknij go dwukrotnie, aby się połączyć.

### Konfiguracja ustawień gry

Przejdź do <code className="action">Settings</code> > <code className="action">Game Config</code>, aby dostosować główne ustawienia serwera bez edytowania żadnego pliku konfiguracyjnego.

<img className="thumbnail" alt="Ustawienia Game Config serwera Garry's Mod" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-game-config.png" loading="lazy" />

| Ustawienie | Opis |
|------------|------|
| `Server name` | Nazwa wyświetlana w przeglądarce serwerów w grze. |
| `Map` | Mapa ładowana podczas uruchamiania serwera. |
| `Game mode` | Tryb gry, w którym działa serwer. |
| `Workshop collection` | Identyfikator kolekcji Steam Workshop, pobieranej i montowanej przy każdym uruchomieniu. Kolekcja musi być publiczna lub niepubliczna. |
| `Counter-Strike: Source content` | Pobiera zawartość gry Counter-Strike: Source, z której korzysta wiele dodatków. Gracze również muszą posiadać tę grę. Przy następnym uruchomieniu dochodzi pobieranie o rozmiarze kilku gigabajtów. |
| `Maximum players` | Maksymalna liczba jednoczesnych graczy. |
| `Server password` | Hasło, które gracze muszą wprowadzić, aby dołączyć. W przypadku serwera publicznego pozostaw to pole puste. |
| `Admin password (RCON)` | Hasło używane do zdalnego sterowania serwerem z konsoli. |
| `Steam GSL token` | Token, dzięki któremu serwer pojawia się w oficjalnej przeglądarce serwerów. Możesz go uzyskać na stronie [steamcommunity.com](https://steamcommunity.com/dev/managegameservers). |
| `Update workshop addons` | Aktualizuje dodatki z kolekcji przy każdym uruchomieniu. |
| `Update on start` | Sprawdza i instaluje aktualizacje gry przy każdym uruchomieniu. |

Zmiany zostaną zastosowane po ponownym uruchomieniu serwera.

### Zmiana trybu gry

Pola `Game mode` i `Map` są polami tekstowymi: lista rozwijana podpowiada tylko wartości dostarczane z grą, ale możesz wpisać w nich dowolną nazwę.

**Trouble in Terrorist Town** jest dostarczany z Garry's Mod. Wybierz go w polu `Game mode`, a następnie uruchom ponownie serwer. Sprawdź mapę: `Construct` i `Flatgrass` to mapy trybu sandbox, a serwer TTT wymaga map `ttt_` z Workshopu.

**DarkRP** nie jest dostarczany z grą i pochodzi z Workshopu:

1. Utwórz publiczną lub niepubliczną kolekcję Steam Workshop zawierającą DarkRP, jego zależności i mapę `rp_`.
2. Wprowadź jej identyfikator w polu `Workshop collection`.
3. Wpisz `darkrp` w polu `Game mode`, a nazwę mapy w polu `Map`.
4. Włącz `Counter-Strike: Source content` — wiele dodatków DarkRP korzysta z tekstur tej gry.
5. Uruchom ponownie serwer.

<img className="thumbnail" alt="Ustawienia Game mode, Workshop collection i Counter-Strike: Source content" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/gameplay-settings.png" loading="lazy" />

:::warning
Pole `Map` wskazuje mapę do załadowania, ale jej nie pobiera. Mapa, której nie ma w kolekcji Workshop, nie zostanie znaleziona podczas uruchamiania, a serwer się nie uruchomi.
:::
