Witamy w dokumentacji poświęconej [OVHcloud Game Panel](https://www.ovhcloud.com/en-gb/vps/). Game Panel umożliwia wdrażanie serwerów gier dla szerokiej gamy popularnych tytułów oraz zarządzanie nimi bezpośrednio z poziomu Twojego VPS OVHcloud. Znajdziesz tu wszystkie dostępne przewodniki dotyczące instalacji, konfiguracji i administrowania serwerami gier.

## Czym jest Game Panel?

OVHcloud Game Panel to uproszczony interfejs do wdrażania serwerów gier na VPS i zarządzania nimi. Dzięki automatycznemu wdrażaniu i wbudowanym narzędziom możesz uruchamiać instancje, dostosowywać konfiguracje i monitorować wydajność — bez ręcznego zarządzania infrastrukturą bazową.

Za pomocą Game Panel możesz:

- Wdrażać serwery gier dla ponad 40 tytułów (Minecraft, ARK, Counter-Strike 2, Rust i innych)
- Uruchamiać kilka serwerów gier na jednym VPS
- Zarządzać plikami serwera, kopiami zapasowymi i zadaniami zaplanowanymi
- Kontrolować dostęp dzięki uprawnieniom przypisanym do poszczególnych użytkowników i serwerów
- Monitorować wykorzystanie CPU i RAM w czasie rzeczywistym
