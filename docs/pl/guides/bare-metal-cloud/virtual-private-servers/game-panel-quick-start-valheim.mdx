## Wprowadzenie

Game Panel OVHcloud umożliwia wdrożenie serwera Valheim z automatyczną instalacją i konfiguracją portów.

**Ten przewodnik wyjaśnia, jak wdrożyć serwer Valheim w Game Panel OVHcloud i połączyć się z nim.**

## Wymagania początkowe

- [VPS](https://www.ovhcloud.com/pl/vps/) na koncie OVHcloud z włączoną funkcją Game Panel.
- Dostęp do Game Panel. Zapoznaj się z przewodnikiem [Logowanie do Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## W praktyce

### Etap 1 — Uzyskiwanie dostępu do Game Panel

Zaloguj się do Game Panel OVHcloud.

### Etap 2 — Tworzenie nowej instancji serwera

Kliknij <code className="action">Add Game Server</code> i wybierz **Valheim**.

<img className="thumbnail" alt="Wybór Valheim z listy gier" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/select-valheim.png" loading="lazy" />

:::info
Jeśli jest to Twój pierwszy serwer Valheim w Game Panel, a domyślny Game Port jest dostępny, wszystkie wymagane porty zostaną skonfigurowane automatycznie. Konfiguracja ręczna nie jest potrzebna.
:::


### Etap 3 — Śledzenie postępu instalacji

Po rozpoczęciu instalacji wyświetli się ekran potwierdzenia. Kliknij <code className="action">Log/Console</code>, aby śledzić postęp instalacji w czasie rzeczywistym.

<img className="thumbnail" alt="Śledzenie instalacji serwera Valheim" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/installation-logs.png" loading="lazy" />

### Etap 4 — Potwierdzanie zakończenia instalacji

Po zakończeniu instalacji pojawi się powiadomienie: **Server status is now: Running**.

<img className="thumbnail" alt="Serwer Valheim ze statusem Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/server-running.png" loading="lazy" />

### Etap 5 — Pobieranie informacji o połączeniu

Gdy status serwera to **Running**, skopiuj informacje o połączeniu z Game Panel. Valheim używa dwóch portów UDP: `2456` (Game) i `2457` (Query).

:::info
Hasło serwera jest generowane automatycznie podczas instalacji. Otwórz <code className="action">File Manager</code> z poziomu <code className="action">Settings</code> swojego serwera i sprawdź `config-lgsm` > `vhserver` > `secrets-common.cfg`, aby je pobrać.
:::


### Etap 6 — Dołączanie do serwera w Valheim

1. Otwórz **Valheim**.
2. Kliknij <code className="action">Start</code>, a następnie <code className="action">Join game</code>.
3. Kliknij <code className="action">Add server</code>.
4. Wprowadź adres IP swojego VPS wraz z portem (na przykład `serv8.gamepanel.ovh:2456`).
5. Wprowadź hasło i kliknij <code className="action">Connect</code>.
