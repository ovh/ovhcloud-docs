## Wprowadzenie

Fabric i NeoForge to programy ładujące mody dla serwerów Minecraft. Zainstalowanie jednego z nich na serwerze Minecraft hostowanym na Game Panel pozwala korzystać z rozgrywki z modami i rozszerzonymi funkcjami.

**Ten przewodnik wyjaśnia, jak zainstalować Fabric lub NeoForge na serwerze Minecraft w Game Panel oraz dodać mody.**

## Wymagania początkowe

- [VPS](https://www.ovhcloud.com/pl/vps/) na koncie OVHcloud z włączoną funkcją Game Panel.
- Serwer Minecraft wdrożony na Game Panel. Zapoznaj się z przewodnikiem [Wdrożenie serwera Minecraft na Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

## W praktyce

### Etap 1 — Wyłączenie automatycznych aktualizacji

Aby uniknąć konfliktów z programami ładującymi mody, przed wprowadzeniem jakichkolwiek zmian wyłącz automatyczne aktualizacje:

1. Przejdź do <code className="action">Settings</code> serwera.
2. Otwórz zakładkę <code className="action">Game Config</code>.
3. Wyłącz automatyczne aktualizacje.

### Etap 2 — Zatrzymanie serwera

Z poziomu Game Panel zatrzymaj serwer Minecraft przed wprowadzeniem dalszych zmian.

### Etap 3 — Pobranie i przesłanie instalatora

Pobierz instalator odpowiadający wybranemu programowi ładującemu mody:

- **Fabric**: [https://fabricmc.net/use/server/](https://fabricmc.net/use/server/)
- **NeoForge**: [https://neoforged.net/](https://neoforged.net/)

Po pobraniu otwórz <code className="action">Settings</code> serwera, przejdź do zakładki <code className="action">File Manager</code> i prześlij plik `.jar` do katalogu `serverfiles` za pomocą opcji <code className="action">Upload files</code> lub metodą przeciągnij i upuść.

### Etap 4 — Uruchomienie instalatora

Otwórz zakładkę <code className="action">Terminal</code> z poziomu <code className="action">Settings</code> serwera i wykonaj polecenie odpowiednie dla Twojego programu ładującego mody.

Dla **Fabric**:

```bash
java -jar fabric-installer-X.X.X.jar server --downloadMinecraft
```

To polecenie pobiera pliki serwera Minecraft, instaluje program ładujący Fabric i generuje plik uruchamiający serwer Fabric.

Dla **NeoForge**:

```bash
java -jar neoforge-X.X.X-installer.jar --installServer
```

To polecenie instaluje NeoForge, pobiera pliki serwera Minecraft i generuje pliki uruchamiające serwer.

### Etap 5 — Konfiguracja LinuxGSM

Wskaż LinuxGSM, którego pliku wykonywalnego ma używać, w zależności od programu ładującego mody.

Dla **Fabric**:

```bash
printf '\nexecutable="./fabric-server-launch.jar"\n' >> /data/config-lgsm/mcserver/common.cfg
```

Dla **NeoForge**:

```bash
printf '\npreexecutable=""\nexecutable="./run.sh"\nstartparameters="nogui"\n' >> /data/config-lgsm/mcserver/common.cfg
```

:::warning
W przypadku korzystania z NeoForge z plikiem `run.sh` ustawienie **Max RAM** w Game Config nie jest już stosowane. Zmodyfikuj zamiast tego plik `/data/serverfiles/user_jvm_args.txt`. Przykład:

```
-Xms2G
-Xmx4G
```
:::


### Etap 6 — Uruchomienie serwera

Przed uruchomieniem serwera ustaw poprawne uprawnienia:

```bash
sudo chown -R linuxgsm:linuxgsm /data/serverfiles
```

Następnie uruchom serwer z poziomu Game Panel i sprawdź logi serwera, aby potwierdzić poprawne uruchomienie.

### Etap 7 — Dodawanie modów

Aby zainstalować mody na serwerze z modami:

1. Pobierz mody zgodne z Fabric lub NeoForge.
2. Otwórz zakładkę <code className="action">File Manager</code> z poziomu <code className="action">Settings</code> serwera.
3. Prześlij pliki `.jar` modów do `serverfiles/mods`.
4. Zresetuj uprawnienia:

    ```bash
    sudo chown -R linuxgsm:linuxgsm /data/serverfiles
    ```

5. Uruchom ponownie serwer. Sprawdź logi, aby potwierdzić, że mody zostały załadowane.
