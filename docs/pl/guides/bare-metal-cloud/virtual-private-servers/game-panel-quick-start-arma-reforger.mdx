## Wprowadzenie

Game Panel umożliwia wdrożenie serwera Arma Reforger w kilku krokach. Game Panel automatycznie zarządza instalacją, w tym konfiguracją portów.

**Ten przewodnik wyjaśnia, jak wdrożyć serwer Arma Reforger w Game Panel i jak się z nim połączyć.**

## Wymagania początkowe

- [VPS](https://www.ovhcloud.com/pl/vps/) na koncie OVHcloud z włączoną funkcją Game Panel.
- Dostęp do Game Panel. Zapoznaj się z przewodnikiem [Logowanie do Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## W praktyce

### Etap 1 — Uzyskanie dostępu do Game Panel

Zaloguj się do Game Panel.

### Etap 2 — Tworzenie nowej instancji serwera

Kliknij <code className="action">Add Game Server</code> i wybierz **Arma Reforger**.

<img className="thumbnail" alt="Wybór Arma Reforger z listy gier" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/select-arma-reforger.png" loading="lazy" />

:::info
Jeśli jest to Twój pierwszy serwer Arma Reforger w Game Panel, a domyślny port gry jest dostępny, wszystkie wymagane porty zostaną skonfigurowane automatycznie podczas instalacji. W takim przypadku nie jest potrzebna żadna ręczna konfiguracja.
:::


### Etap 3 — Śledzenie postępu instalacji

Po rozpoczęciu instalacji pojawia się ekran potwierdzenia. Kliknij <code className="action">Log/Console</code>, aby śledzić postęp instalacji w czasie rzeczywistym.

<img className="thumbnail" alt="Ekran rozpoczęcia instalacji Arma Reforger z przyciskiem Open Logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-started.png" loading="lazy" />

Podczas instalacji serwera status wyświetla się jako **Installing**. Szczegółowy postęp możesz śledzić bezpośrednio w panelu logów.

<img className="thumbnail" alt="Serwer Arma Reforger ze statusem Running i logami instalacji" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-logs.png" loading="lazy" />

### Etap 4 — Potwierdzenie zakończenia instalacji

Po zakończeniu instalacji status serwera zmienia się na **Running**.

### Etap 5 — Pobranie informacji o połączeniu

Gdy status serwera to **Running**, skopiuj informacje o połączeniu z Game Panel.

<img className="thumbnail" alt="Szczegóły połączenia serwera Arma Reforger" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-connection-details.png" loading="lazy" />

### Etap 6 — Dołączanie do serwera w grze Arma Reforger

1. Otwórz **Arma Reforger** i przejdź do menu głównego.
2. Kliknij <code className="action">Multiplayer</code>.
3. Wybierz <code className="action">Direct Join</code> lub naciśnij `v`.
4. Wprowadź adres IP i port, a następnie kliknij <code className="action">Join</code>.
