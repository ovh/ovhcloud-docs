## Wprowadzenie

Game Panel umożliwia wdrożenie serwera Arma Reforger w kilku krokach. Game Panel automatycznie zarządza instalacją, w tym konfiguracją portów.

**Ten przewodnik wyjaśnia, jak wdrożyć serwer Arma Reforger w Game Panel i jak się z nim połączyć.**

## Wymagania początkowe

- [VPS](/links/bare-metal/vps) lub [serwer dedykowany](/links/bare-metal/bare-metal) na koncie OVHcloud z włączoną funkcją Game Panel.
- Dostęp do Game Panel. Zapoznaj się z przewodnikiem [Logowanie do Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## W praktyce

### Etap 1 — Uzyskanie dostępu do Game Panel

Zaloguj się do Game Panel. W menu po lewej stronie przejdź do sekcji `Game Servers` i kliknij <code className="action">Add Game Server</code>.

### Etap 2 — Utworzenie serwera Arma Reforger

Wybierz **Arma Reforger** z listy gier. Otworzy się okno konfiguracji.

<img className="thumbnail" alt="Wybór Arma Reforger z listy gier" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/select-arma-reforger.png" loading="lazy" />

### Etap 3 — Konfiguracja serwera Arma Reforger

Ustaw nazwę serwera i sprawdź konfigurację przed uruchomieniem instalacji.

:::info
Jeśli jest to Twój pierwszy serwer Arma Reforger w Game Panel, a domyślny port gry jest dostępny, wszystkie wymagane porty zostaną skonfigurowane automatycznie podczas instalacji. W takim przypadku nie jest potrzebna żadna ręczna konfiguracja.
:::

Możesz rozwinąć sekcję <code className="action">Advanced settings</code>, aby dostosować opcje takie jak przypisanie portów (ports binding) i limity zasobów. Wartości domyślne są odpowiednie dla większości serwerów gier.

### Etap 4 — Uruchomienie instalacji

Kliknij <code className="action">Install</code>, aby rozpocząć wdrożenie.

### Etap 5 — Monitorowanie instalacji

Kliknij <code className="action">Log/Console</code>, aby śledzić postęp instalacji w czasie rzeczywistym. Podczas instalacji serwera status wyświetla się jako **Installing**.

<img className="thumbnail" alt="Monitorowanie instalacji serwera Arma Reforger w panelu logów" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-logs.png" loading="lazy" />

### Etap 6 — Sprawdzenie, czy serwer działa

Potwierdź, że status serwera to **Running**. Elementy sterujące <code className="action">Log/Console</code> i <code className="action">Settings</code> pozostają dostępne do zarządzania serwerem.

### Etap 7 — Potwierdzenie zakończenia instalacji

Po zakończeniu instalacji status serwera zmienia się na **Running**.

### Etap 8 — Pobranie informacji o połączeniu

Skopiuj adres IP i port z kolumny **Connection** na liście Game Servers.

<img className="thumbnail" alt="Szczegóły połączenia serwera Arma Reforger" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-connection-details.png" loading="lazy" />

### Etap 9 — Dołączenie do serwera w grze Arma Reforger

1. Otwórz **Arma Reforger** i przejdź do menu głównego.
2. Kliknij **Multiplayer**, a następnie otwórz zakładkę **Community**.
3. Wyszukaj nazwę swojego serwera.
4. Po jego znalezieniu kliknij go, a następnie kliknij **Join**.
