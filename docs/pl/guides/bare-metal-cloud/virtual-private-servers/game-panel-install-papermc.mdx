## Wprowadzenie

PaperMC to wysokowydajna implementacja serwera Minecraft, która obsługuje wtyczki rozszerzające możliwości rozgrywki. Game Panel pozwala wdrożyć serwer PaperMC w kilku kliknięciach i dostosować go poprzez przesyłanie wtyczek.

**Ten przewodnik wyjaśnia, jak zainstalować serwer PaperMC na Game Panel oraz dodać wtyczki.**

## Wymagania początkowe

- [VPS](https://www.ovhcloud.com/pl/vps/) na koncie OVHcloud z włączoną funkcją Game Panel.
- Dostęp do Game Panel. Zapoznaj się z przewodnikiem [Logowanie do Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## W praktyce

### Etap 1 — Instalacja serwera PaperMC

Na głównej stronie Game Panel kliknij <code className="action">Add Game Server</code>, odszukaj **PaperMC**, a następnie kliknij <code className="action">Select</code>.

Aby uzyskać więcej informacji na temat instalacji serwera, zapoznaj się z przewodnikiem [Pierwsze kroki z Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

### Etap 2 — Pobranie wtyczek

Pobierz wtyczki z zaufanego źródła, takiego jak repozytorium [PaperMC Hangar](https://hangar.papermc.io/).

### Etap 3 — Przesłanie wtyczek za pomocą File Manager

Na serwerze PaperMC kliknij <code className="action">Settings</code>, a następnie otwórz zakładkę <code className="action">File Manager</code>. Przejdź do folderu `serverfiles`, otwórz katalog `plugins` i prześlij pliki wtyczek za pomocą opcji <code className="action">Upload files</code> lub metodą przeciągnij i upuść.

### Etap 4 — Ponowne uruchomienie serwera

Na głównej stronie Game Panel uruchom ponownie serwer za pomocą dedykowanego przycisku.

:::info
Monitoruj logi serwera, aby potwierdzić, że uruchamia się on poprawnie i że wtyczki zostały załadowane.
:::
