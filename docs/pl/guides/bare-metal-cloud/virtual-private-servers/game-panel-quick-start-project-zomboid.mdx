## Wprowadzenie

Game Panel OVHcloud umożliwia wdrożenie serwera Project Zomboid z automatyczną instalacją i konfiguracją portów.

**Ten przewodnik wyjaśnia, jak wdrożyć serwer Project Zomboid w Game Panel OVHcloud i się z nim połączyć.**

## Wymagania początkowe

- [VPS](/links/bare-metal/vps) lub [serwer dedykowany](/links/bare-metal/bare-metal) na koncie OVHcloud z włączoną funkcją Game Panel.
- Dostęp do Game Panel. Zapoznaj się z przewodnikiem [Logowanie do Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## W praktyce

### Etap 1 — Uzyskanie dostępu do Game Panel

Zaloguj się do Game Panel OVHcloud. W menu po lewej stronie przejdź do sekcji `Game Servers` i kliknij <code className="action">Add Game Server</code>.

### Etap 2 — Utworzenie serwera Project Zomboid

Wybierz **Project Zomboid** z listy gier. Otworzy się okno konfiguracji.

<img className="thumbnail" alt="Wybór Project Zomboid z listy gier w Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/select-project-zomboid.png" loading="lazy" />

### Etap 3 — Konfiguracja serwera Project Zomboid

W tej sekcji możesz ustawić nazwę serwera oraz wybrać <code className="action">Branch</code> — gałąź Steam gry, która ma zostać zainstalowana. Lista dostępnych gałęzi jest aktualizowana automatycznie. Wybierz ją uważnie: późniejsza zmiana gałęzi może uszkodzić istniejący świat, dlatego decyzję należy podjąć już na etapie instalacji.

Automatycznie generowane jest również hasło administratora. Jest to hasło konta administratora w grze, służące do nadania sobie uprawnień administratora i uruchamiania poleceń konsoli wymagających tych uprawnień — **nie** jest to hasło, którego gracze używają do dołączenia do serwera.

:::warning
Pamiętaj, aby przechowywać to hasło administratora w bezpiecznym miejscu.
:::

Możesz rozwinąć <code className="action">Advanced Settings</code>, aby dostosować opcje takie jak przypisanie portów (ports binding) i limity zasobów. Wartości domyślne są odpowiednie dla większości serwerów gier.

<img className="thumbnail" alt="Formularz konfiguracji serwera Project Zomboid z gałęzią i hasłem administratora" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/configure-server.png" loading="lazy" />

### Etap 4 — Uruchomienie instalacji

Kliknij <code className="action">Install</code>, aby rozpocząć wdrożenie.

### Etap 5 — Monitorowanie instalacji

Kliknij <code className="action">Log/Console</code>, aby śledzić postęp instalacji w czasie rzeczywistym. Zaraz po rozpoczęciu instalacji Game Panel udostępnia również przycisk <code className="action">Open Logs / Console</code>, który otwiera ten sam widok.

Podczas instalacji serwera status wyświetla **Installing**. Panel logów pokazuje szczegółowy postęp.

<img className="thumbnail" alt="Monitorowanie instalacji serwera Project Zomboid w panelu logów" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/installation-logs.png" loading="lazy" />

### Etap 6 — Potwierdzenie zakończenia instalacji

Po zakończeniu instalacji status serwera zmienia się na **Running**.

### Etap 7 — Sprawdzenie, czy serwer działa

Sprawdź, czy widoczna jest aktywność CPU i RAM. Do zarządzania serwerem możesz użyć elementów sterujących <code className="action">Log/Console</code> i <code className="action">Settings</code>.

<img className="thumbnail" alt="Serwer Project Zomboid ze statusem Running oraz aktywnością CPU i RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/server-running.png" loading="lazy" />

### Etap 8 — Pobranie informacji o połączeniu

Skopiuj adres IP i port z kolumny **Connection** na liście `Game Servers`.

### Etap 9 — Dołączenie do serwera w grze Project Zomboid

Aby dołączyć do serwera z poziomu klienta Project Zomboid:

1. Otwórz **Project Zomboid** i kliknij **Multiplayer**, a następnie **Add server**.
2. Wpisz nazwę serwera, a następnie adres IP i port z kolumny **Connection** w Game Panel. Podaj również hasło serwera, jeśli zostało ono ustawione — jest to hasło, którego gracze używają do dołączenia, a nie hasło administratora.
3. Kliknij **SAVE**.
4. Utwórz konto gry dla tego serwera, klikając **Add new account**, a następnie podaj nazwę i hasło.

### Logowanie jako administrator

Po dodaniu serwera w menu **Multiplayer** utwórz nową postać dla tego serwera. Podczas jej tworzenia wybierz nazwę użytkownika i wpisz hasło administratora serwera.

Aby uzyskać to hasło, kliknij <code className="action">Settings</code> w Game Panel, otwórz sekcję <code className="action">Game Config</code>, a następnie zakładkę <code className="action">Server Settings</code>: pole **Admin Password** znajduje się na dole strony. Wartość jest zamaskowana — kliknij ikonę oka, aby ją wyświetlić.

Po zalogowaniu się tą postacią po lewej stronie ekranu pojawi się ikona **Admin**. Kliknij ją, aby uzyskać dostęp do narzędzi administracyjnych, wykonywać polecenia i moderować serwer.

### Aktualizacja serwera do nowej wersji gry

Domyślnie serwer nie aktualizuje się automatycznie, gdy dostępna jest nowa wersja, aby uniknąć problemów ze zgodnością lub przerwania trwających rozgrywek.

Aby włączyć automatyczne aktualizacje, kliknij <code className="action">Settings</code>, otwórz sekcję <code className="action">Game Config</code>, a następnie włącz opcję <code className="action">Update on start</code> na dole strony (domyślnie wyłączoną). Kliknij <code className="action">Save &amp; Restart</code>, aby zastosować zmiany. Serwer będzie wtedy automatycznie stosował każdą nową aktualizację.
