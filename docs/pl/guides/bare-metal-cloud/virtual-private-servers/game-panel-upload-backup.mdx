## Wprowadzenie

Game Panel OVHcloud pozwala przywrócić kopię zapasową poprzez pobranie archiwum, rozpakowanie go i przesłanie plików za pomocą File Manager.

**Ten przewodnik wyjaśnia, jak przywrócić kopię zapasową na serwerze Game Panel OVHcloud.**

## Wymagania początkowe

- [VPS](https://www.ovhcloud.com/pl/vps/) na koncie OVHcloud z włączoną funkcją Game Panel.
- Instancja serwera gry wdrożona na Game Panel.
- Istniejąca kopia zapasowa. Zapoznaj się z przewodnikiem [Tworzenie kopii zapasowej na Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/).

## W praktyce

### Etap 1 — Logowanie do Game Panel

Zaloguj się do Game Panel. Jeśli potrzebujesz pomocy, zapoznaj się z przewodnikiem [Logowanie do Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Etap 2 — Dostęp do ustawień kopii zapasowych

Po zalogowaniu:

1. Wybierz serwer gry.
2. Kliknij <code className="action">Settings</code>.
3. Przejdź do zakładki <code className="action">Backups</code>.

### Etap 3 — Pobranie kopii zapasowej

W dolnej części strony znajdź listę dostępnych kopii zapasowych. Kliknij <code className="action">Download</code> obok kopii, którą chcesz przywrócić.

Jeśli żadna kopia zapasowa nie jest dostępna, musisz ją najpierw utworzyć. Zapoznaj się z przewodnikiem [Tworzenie kopii zapasowej na Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/).

<img className="thumbnail" alt="Pobieranie kopii zapasowej z listy" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-backup/download-backup.png" loading="lazy" />

### Etap 4 — Rozpakowanie kopii zapasowej

Po pobraniu kopii zapasowej rozpakuj archiwum na swoim komputerze. Rozpakowana zawartość obejmuje katalog `serverfiles`.

### Etap 5 — Zatrzymanie serwera

Przed kontynuowaniem upewnij się, że serwer gry jest całkowicie zatrzymany z poziomu Game Panel. Zapobiega to uszkodzeniu plików lub konfliktom podczas przywracania.

### Etap 6 — Otwarcie File Manager

Na serwerze kliknij <code className="action">Settings</code>, a następnie otwórz zakładkę <code className="action">File Manager</code> i odszukaj folder `serverfiles`.

<img className="thumbnail" alt="Katalog serverfiles na serwerze" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-backup/serverfiles.png" loading="lazy" />

Przed przesłaniem kopii zapasowej należy wybrać jedną z poniższych opcji:

- **Usuń go** za pomocą akcji <code className="action">Delete</code>, jeśli już go nie potrzebujesz.
- **Zmień jego nazwę** za pomocą akcji <code className="action">Rename</code>, aby zachować go jako kopię zapasową.
- **Pobierz go lokalnie** za pomocą akcji <code className="action">Download</code>.

### Etap 7 — Przesłanie plików kopii zapasowej

W File Manager kliknij <code className="action">Upload files</code> lub przeciągnij i upuść lokalny folder `serverfiles` z rozpakowanej kopii zapasowej na listę plików.

W przypadku większości gier przywrócenie folderu `serverfiles` jest wystarczające. Niektóre gry mogą jednak przechowywać pliki konfiguracyjne w innych lokalizacjach. Jeśli konfiguracja gry została zmodyfikowana, zaleca się również przywrócenie folderu `config-lgsm`, gdy jest dostępny.

### Etap 8 — Uruchomienie serwera

Po zakończeniu przesyłania uruchom ponownie serwer z poziomu Game Panel. Serwer powinien teraz działać w przywróconym środowisku kopii zapasowej.
