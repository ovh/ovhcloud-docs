## Wprowadzenie

Game Panel OVHcloud umożliwia tworzenie kopii zapasowych instancji serwerów gier, dzięki czemu w razie potrzeby możesz przywrócić serwer do poprzedniego stanu.

**Ten przewodnik wyjaśnia, jak utworzyć kopię zapasową serwera gry w Game Panel OVHcloud.**

## Wymagania początkowe

- [VPS](https://www.ovhcloud.com/pl/vps/) na koncie OVHcloud z włączoną funkcją Game Panel.
- Instancja serwera gry wdrożona w Game Panel. Zapoznaj się z przewodnikiem [Pierwsze kroki z Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

## W praktyce

### Etap 1 — Zaloguj się do Game Panel

Zaloguj się do swojego Game Panel. Jeśli potrzebujesz pomocy, zapoznaj się z przewodnikiem [Logowanie do Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Etap 2 — Uzyskaj dostęp do ustawień kopii zapasowych

Po zalogowaniu:

1. Wybierz swój serwer gry.
2. Kliknij <code className="action">Settings</code>.
3. Przejdź do karty <code className="action">Backups</code>.

<img className="thumbnail" alt="Karta ustawień kopii zapasowych" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/backup-tab.png" loading="lazy" />

### Etap 3 — Utwórz kopię zapasową

Kliknij <code className="action">Create backup now</code>.

<img className="thumbnail" alt="Tworzenie kopii zapasowej z opcją zatrzymania serwera" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/create-backup.png" loading="lazy" />

Po zakończeniu tworzenia kopii zapasowej plik jest dostępny do pobrania na liście **Available Backups**, niżej na tej samej karcie.

### Etap 4 — Ustaw politykę przechowywania

W sekcji **Retention Policy** możesz określić, ile kopii zapasowych jest przechowywanych i przez jaki czas:

- **Keep the last backups**: maksymalna liczba kopii zapasowych do zachowania (ustaw `0`, aby zachować wszystkie).
- **Keep backups for days**: czas przechowywania kopii zapasowych (ustaw `0`, aby przechowywać je bezterminowo).
- **Stop server before backup**: zatrzymuje serwer podczas tworzenia kopii zapasowej, co zapewnia spójność zapisów.

:::info
Zalecamy pozostawienie włączonej opcji **Stop server before backup**, aby zapewnić spójność kopii zapasowych.
:::

Kliknij <code className="action">Save retention settings</code>, aby zastosować zmiany.
