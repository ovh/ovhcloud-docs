## Wprowadzenie

Game Panel udostępnia konfigurację serwera Counter-Strike 2 bezpośrednio w interfejsie. Podstawowe opcje, takie jak nazwa serwera, mapa i tryb gry, są dostępne za pomocą formularza graficznego, a dodatkowo możesz zainstalować frameworki serwerowe, takie jak MetaMod i CounterStrikeSharp.

**Ten przewodnik wyjaśnia, jak modyfikować konfigurację serwera Counter-Strike 2 w Game Panel.**

## Wymagania początkowe

- [VPS](/links/bare-metal/vps) lub [serwer dedykowany](/links/bare-metal/bare-metal) na koncie OVHcloud z włączoną funkcją Game Panel.
- Serwer Counter-Strike 2 wdrożony w Game Panel. Zapoznaj się z przewodnikiem [Wdrażanie serwera Counter-Strike 2 w Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/).

## W praktyce

### Etap 1 — Otwarcie ustawień serwera

Na głównej stronie Game Panel odszukaj serwer Counter-Strike 2, który chcesz skonfigurować. W kolumnie <code className="action">Management</code> kliknij <code className="action">Settings</code>.

<img className="thumbnail" alt="Serwer Counter-Strike 2 z wyróżnionym przyciskiem Settings" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-server-settings.png" loading="lazy" />

### Etap 2 — Otwarcie zakładki Game Config

W panelu **Server Settings** wybierz <code className="action">Game Config</code> w menu bocznym po lewej stronie.

Sekcja **Game Config** pozwala zarządzać głównymi ustawieniami serwera Counter-Strike 2 za pomocą dwóch zakładek:

- **Settings**: konfiguruj ustawienia serwera gry.
- **Frameworks**: instaluj obsługiwane frameworki serwerowe i zarządzaj nimi.

### Etap 3 — Konfiguracja zakładki Settings

Zakładka <code className="action">Settings</code> pozwala modyfikować główne parametry serwera Counter-Strike 2:

| Ustawienie | Opis |
|---------|-------------|
| Server Name | Nazwa wyświetlana na liście serwerów Counter-Strike 2. |
| Max Players | Maksymalna liczba graczy mogących połączyć się jednocześnie. |
| Map | Mapa ładowana przy uruchomieniu serwera. Możesz również ręcznie wpisać nazwę mapy, która nie znajduje się na liście. |
| Game Type | Określa główną kategorię gry. |
| Game Mode | Określa tryb gry w obrębie wybranej kategorii gry. Więcej informacji o dostępnych trybach znajdziesz w [przewodniku Valve Developer Community](https://developer.valvesoftware.com/wiki/Counter-Strike:_Global_Offensive/Game_Modes). |
| Server Password | Wymaga od graczy podania hasła przed dołączeniem do serwera. |
| Admin Password (RCON) | Włącza dostęp przez zdalną konsolę (RCON) i określa hasło używane do zdalnego administrowania serwerem. |
| Steam GSL Token | Token Game Server Login Token (GSLT) używany do uwierzytelniania serwera dedykowanego w usługach Steam. Aby wygenerować token, zapoznaj się ze [stroną zarządzania kontami serwerów gier Steam](https://steamcommunity.com/dev/managegameservers). |
| VAC Anti-Cheat | Włącza lub wyłącza ochronę Valve Anti-Cheat (VAC) na serwerze. |

<img className="thumbnail" alt="Zakładka Settings w sekcji Game Config serwera Counter-Strike 2" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-settings.png" loading="lazy" />

:::info
Po zmodyfikowaniu któregokolwiek z tych ustawień zapisz zmiany i uruchom ponownie serwer, aby zaczęły obowiązywać.
:::


### Etap 4 — Instalacja frameworków

Zakładka <code className="action">Frameworks</code> pozwala instalować dodatkowe komponenty rozszerzające funkcjonalność serwera Counter-Strike 2.

- **MetaMod**: framework wtyczek serwerowych działający jako warstwa pośrednia między serwerem gry a wtyczkami. Stanowi podstawę wymaganą przez wiele zaawansowanych rozszerzeń serwerowych i narzędzi administracyjnych.
- **CounterStrikeSharp**: nowoczesny framework wtyczek dla Counter-Strike 2, który pozwala administratorom serwerów i deweloperom tworzyć oraz uruchamiać niestandardowe wtyczki w języku C#. Może dodawać funkcje rozgrywki, narzędzia do zarządzania serwerem oraz rozszerzenia tworzone przez społeczność.

Każdy z frameworków możesz zainstalować bezpośrednio z poziomu Game Panel, a później zainstalować go ponownie, aby zaktualizować do nowszej wersji, gdy będzie dostępna.

<img className="thumbnail" alt="Zakładka Frameworks z frameworkami MetaMod i CounterStrikeSharp" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-frameworks.png" loading="lazy" />

:::info
Serwer musi zostać zatrzymany przed zainstalowaniem frameworka.
:::


### Etap 5 — Zapisanie i ponowne uruchomienie

Po zapisaniu zmian uruchom ponownie serwer Counter-Strike 2 z poziomu Game Panel, aby nowa konfiguracja zaczęła obowiązywać.
