## Wprowadzenie

Game Panel OVHcloud umożliwia dostosowanie serwera Project Zomboid poprzez instalację modów ze Steam Workshop.

**Niniejszy przewodnik wyjaśnia, jak instalować mody na serwerze Project Zomboid hostowanym w Game Panel OVHcloud.**

## Wymagania początkowe

- [VPS](/links/bare-metal/vps) lub [serwer dedykowany](/links/bare-metal/bare-metal) na koncie OVHcloud z włączoną funkcją Game Panel.
- Serwer Project Zomboid wdrożony w Game Panel. Zapoznaj się z przewodnikiem [Wdrażanie serwera Project Zomboid w Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/).
- Dostęp do Game Panel. Zapoznaj się z przewodnikiem [Logowanie do Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## W praktyce

### Etap 1 — Znalezienie wybranych modów

Mody do Project Zomboid są dystrybuowane za pośrednictwem [Steam Workshop](https://steamcommunity.com/app/108600/workshop/). Przejrzyj Workshop i znajdź mody, które chcesz zainstalować.

Po otwarciu strony moda spójrz na adres URL w przeglądarce. **Workshop ID** to numer wyświetlany po `?id=`.

Na przykład:

```text
https://steamcommunity.com/sharedfiles/filedetails/?id=3762296152
```

W tym przykładzie Workshop ID to `3762296152`. Skopiuj ten identyfikator, ponieważ będzie potrzebny w kolejnym etapie.

<img className="thumbnail" alt="Workshop ID wyróżniony na pasku adresu przeglądarki na stronie moda do Project Zomboid" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/steam-workshop-mod-page.png" loading="lazy" />

:::warning
Zawsze upewnij się, że mod jest zgodny z wersją gry działającą na serwerze. Na przykład mod przeznaczony dla Build 41 (B41) najprawdopodobniej nie zadziała na serwerze Build 42 (B42). Instalacja niezgodnych modów może uniemożliwić uruchomienie serwera.
:::

### Etap 2 — Dodanie moda w Game Panel

:::warning
Przed dodaniem lub usunięciem modów serwer musi być zatrzymany. Wprowadzone zmiany zostaną uwzględnione przy następnym uruchomieniu serwera.
:::

Jeśli serwer jest uruchomiony, najpierw go zatrzymaj: na liście `Game Servers` kliknij ikonę zatrzymania w kolumnie **Power** swojego serwera, a następnie potwierdź. Wszyscy połączeni gracze zostaną rozłączeni.

W Game Panel znajdź swój serwer Project Zomboid na liście `Game Servers`, a następnie przejdź do <code className="action">Settings</code> > <code className="action">Game Config</code> > <code className="action">Mods</code>.

<img className="thumbnail" alt="Zakładka Mods w Game Config w Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/game-config-mods-tab.png" loading="lazy" />

Kliknij <code className="action">Add mods</code>, a następnie wprowadź skopiowany wcześniej Workshop ID.

<img className="thumbnail" alt="Wprowadzanie Workshop ID w oknie Add Workshop mods" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/add-mods.png" loading="lazy" />

#### Dodawanie kilku modów naraz

Możesz dodać kilka Workshop ID jednocześnie, oddzielając je za pomocą:

- spacji
- przecinków
- znaków nowego wiersza

Po dodaniu modów możesz zmienić ich **kolejność wczytywania** za pomocą strzałek w górę i w dół w każdym wierszu.

#### Mody zawierające kilka Mod ID

Niektóre elementy Workshop zawierają kilka **Mod ID**. Na przykład przebudowa interfejsu może obejmować dwa Mod ID:

- `UI_Dark`
- `UI_Light`

W takim przypadku włącz tylko jeden z nich, a nie oba.

Poszczególne Mod ID możesz włączać i wyłączać za pomocą przełącznika znajdującego się na końcu każdego wiersza.

<img className="thumbnail" alt="Lista zainstalowanych modów z kolejnością wczytywania i przełącznikiem w każdym wierszu" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/mods-list.png" loading="lazy" />

### Etap 3 — Uruchomienie serwera

Wróć na stronę główną Game Panel i kliknij <code className="action">Start</code>, aby uruchomić serwer.

Gdy gracze będą się łączyć, klient Project Zomboid automatycznie pobierze mody Workshop zainstalowane na serwerze.

### Zwiększenie ilości pamięci RAM przydzielonej grze

Jeśli korzystasz z dużej liczby modów, Project Zomboid może wymagać większej ilości pamięci po stronie klienta. Jeśli gra ma trudności z uruchomieniem lub zawiesza się z powodu intensywnego korzystania z modów, przydziel jej więcej pamięci RAM.

Aby to zrobić:

1. Zamknij całkowicie Project Zomboid.
2. Otwórz **Steam** i znajdź **Project Zomboid** w swojej bibliotece.
3. Kliknij ikonę koła zębatego po prawej stronie.
4. Wybierz **Zarządzaj** > **Przeglądaj pliki lokalne**.
5. W folderze gry znajdź plik `ProjectZomboid64.json` i otwórz go w **Notatniku** (lub dowolnym innym edytorze tekstu).
6. Przewiń plik aż do sekcji `VMArgs`.
7. Znajdź wiersz zawierający `-Xmx3072m` i zastąp tę wartość większą, na przykład `-Xmx8g`. Spowoduje to przydzielenie grze 8 GB pamięci RAM, pod warunkiem, że komputer dysponuje wystarczającą ilością pamięci.
8. Zapisz plik, zamknij go i ponownie uruchom Project Zomboid.

:::info
Nie przydzielaj grze całej pamięci RAM systemu. Pozostaw wystarczającą ilość pamięci dla systemu operacyjnego i aplikacji działających w tle, aby system pozostał stabilny.
:::

### Ręczna instalacja modów

Mody możesz również zainstalować ręcznie, zamiast korzystać z automatycznego importera Workshop. Plikiem do ręcznej edycji jest `/zomboid/Server/<nazwa_serwera>.ini` (domyślnie `servertest.ini`).

Game Panel umożliwia bezpośredni dostęp do tego pliku: przejdź do <code className="action">Settings</code> > <code className="action">Game Config</code> > <code className="action">Server Settings</code>, rozwiń sekcję <code className="action">Advanced Configuration</code>, a następnie kliknij <code className="action">Open in File Manager</code> obok pozycji **INI**.

:::warning
Nie stosuj obu metod jednocześnie. Jeśli zainstalujesz mody ręcznie, a następnie skorzystasz z funkcji automatycznego importu, wprowadzone ręcznie zmiany mogą zostać nadpisane, co może prowadzić do konfliktów lub utraty konfiguracji. Wybierz instalację automatyczną albo ręczną, ale unikaj łączenia obu metod.
:::
