## Wprowadzenie

Game Panel umożliwia wdrożenie serwera DayZ w kilku krokach. Game Panel automatycznie zarządza instalacją, w tym uwierzytelnianiem Steam i konfiguracją portów sieciowych.

**Ten przewodnik wyjaśnia, jak wdrożyć serwer DayZ w Game Panel i jak się z nim połączyć.**

## Wymagania początkowe

- [VPS](/links/bare-metal/vps) lub [serwer dedykowany](/links/bare-metal/bare-metal) na koncie OVHcloud z włączoną funkcją Game Panel.
- Dostęp do Game Panel. Zapoznaj się z przewodnikiem [Logowanie do Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Konto Steam do uwierzytelnienia instalacji serwera DayZ.

## W praktyce

### Etap 1 — Uzyskanie dostępu do Game Panel

Zaloguj się do Game Panel.

W menu po lewej stronie przejdź do sekcji <code className="action">Game Servers</code> i kliknij <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Sekcja Game Servers z przyciskiem Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/add-game-server.png" loading="lazy" />

### Etap 2 — Utworzenie serwera DayZ

Wybierz **DayZ** z listy gier. Otworzy się okno konfiguracji.

### Etap 3 — Konfiguracja serwera DayZ

W oknie konfiguracji:

- Wprowadź wartość **Server Name**.
- Wprowadź swoje dane: **Steam Username** i **Steam Password**.

:::warning
Zdecydowanie zaleca się używanie dedykowanego konta Steam do tego celu, a nie konta osobistego. Użyj złożonego hasła i wyłącz uwierzytelnianie dwuskładnikowe oparte na e-mailu (Steam Guard) na tym koncie przed przejściem dalej.
:::

<img className="thumbnail" alt="Formularz instalacji DayZ z nazwą serwera i polami danych logowania Steam" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/install-dayz-form.png" loading="lazy" />

:::info
Wymagane porty sieciowe są konfigurowane automatycznie podczas instalacji. Jeśli jest to Twój pierwszy serwer DayZ w Game Panel, a domyślne porty są dostępne, żadne ręczne zmiany nie są konieczne.
:::

Możesz rozwinąć sekcję <code className="action">Advanced settings</code>, aby dostosować opcje takie jak przypisanie portów (ports binding) i limity zasobów. Wartości domyślne są odpowiednie dla większości serwerów gier.

### Etap 4 — Uruchomienie instalacji

Kliknij <code className="action">Install</code>. Wdrożenie rozpoczyna się automatycznie. Game Panel:

1. Pobierze obraz serwera DayZ.
2. Zainstaluje pliki serwera.

### Etap 5 — Monitorowanie instalacji

Kliknij <code className="action">Log/Console</code>, aby śledzić postęp instalacji w czasie rzeczywistym. Status serwera wyświetla się jako **Installing**, gdy pliki są wdrażane.

### Etap 6 — Sprawdzenie, czy serwer działa

Po uruchomieniu potwierdź, że status serwera to **Running**. Aktywność CPU i RAM powinna być widoczna w Game Panel.

Dostępne są następujące elementy sterujące:

- <code className="action">Log/Console</code> — monitoruj uruchamianie i aktywność serwera w czasie rzeczywistym oraz sprawdzaj logi w razie problemów.
- <code className="action">Settings</code> — uzyskaj dostęp do opcji konfiguracji gry.

<img className="thumbnail" alt="Serwer DayZ ze statusem Running i elementami sterującymi zarządzaniem" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/server-running.png" loading="lazy" />

Aby dostosować opcje dostępne z poziomu Game Panel, takie jak automatyczne aktualizacje, kliknij <code className="action">Settings</code> na swoim serwerze, a następnie otwórz <code className="action">Game Config</code>. W przypadku zaawansowanej konfiguracji użyj [Menedżera plików](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/), aby bezpośrednio edytować plik konfiguracyjny serwera DayZ.

<img className="thumbnail" alt="Panel Server Settings z opcjami Game Config i File Manager" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/game-config.png" loading="lazy" />

### Etap 7 — Potwierdzenie zakończenia instalacji

Status zmienia się na **Running** po zakończeniu instalacji. Twój serwer DayZ jest teraz gotowy do przyjmowania połączeń.

### Etap 8 — Pobranie informacji o połączeniu

W kolumnie **Connection** na liście Game Servers skopiuj adres IP i port swojego serwera.

<img className="thumbnail" alt="Lista Game Servers z wyróżnionym adresem IP i portem połączenia" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/connection-details.png" loading="lazy" />

### Etap 9 — Dołączenie do serwera w grze DayZ

Aby dołączyć z poziomu klienta DayZ:

1. Uruchom **DayZ**.
2. Przejdź do **Server** i kliknij **Direct connect**.
3. Wklej adres IP oraz port z kolumny **Connection**.
4. Kliknij **Connect**.
