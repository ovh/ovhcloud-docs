## Wprowadzenie

Game Panel pozwala dostosować serwer Rust poprzez zainstalowanie niestandardowej mapy. Plik mapy jest hostowany zewnętrznie i przywoływany z konfiguracji serwera.

**Ten przewodnik wyjaśnia, jak zainstalować niestandardową mapę na serwerze Rust hostowanym na Game Panel.**

## Wymagania początkowe

- [VPS](https://www.ovhcloud.com/pl/vps/) na koncie OVHcloud z włączoną funkcją Game Panel.
- Serwer Rust wdrożony na Game Panel.
- Plik niestandardowej mapy w formacie `.map`.

## W praktyce

### Etap 1 — Przygotowanie niestandardowej mapy

1. Zatrzymaj serwer Rust z poziomu Game Panel.
2. Upewnij się, że niestandardowa mapa jest w formacie `.map`.
3. Prześlij mapę do serwisu udostępniania plików.
4. Skopiuj uzyskany link do pobrania i zachowaj go — będzie potrzebny później.

:::warning
Dropbox nie jest odpowiedni do tego celu. Skorzystaj z innego serwisu udostępniania plików.
:::


### Etap 2 — Otwarcie File Manager

Na serwerze Rust kliknij <code className="action">Settings</code>, a następnie otwórz zakładkę <code className="action">File Manager</code>.

:::warning
Przed wykonaniem któregokolwiek z poniższych działań upewnij się, że serwer Rust jest **zatrzymany**.
:::


### Etap 3 — Edycja konfiguracji serwera

1. W File Manager przejdź do:

    ```
    /serverfiles/server/rustserver/cfg
    ```

2. Odszukaj plik `server.cfg` i otwórz go do edycji.
3. Znajdź linię zaczynającą się od `levelURL=` i wklej zapisany wcześniej link do pobrania po znaku `=`.
4. Upewnij się, że link kończy się na `dl=1` (a nie `dl=0`). W razie potrzeby zmień go.
5. Znajdź linię zaczynającą się od `serverLevel=` i wprowadź ten sam typ poziomu, który został użyty do wygenerowania niestandardowej mapy:

    - `Procedural Map`
    - `Barren`
    - `Craggy Island`
    - `Savas Island`

6. Zapisz zmiany.

### Etap 4 — Ponowne uruchomienie serwera

Po zapisaniu zmian uruchom ponownie serwer Rust z poziomu Game Panel.
