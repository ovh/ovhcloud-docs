Witamy w dokumentacji poświęconej [OVHcloud Game Panel](/links/bare-metal/game-hub). Game Panel umożliwia wdrażanie serwerów gier dla szerokiej gamy popularnych tytułów oraz zarządzanie nimi bezpośrednio z poziomu Twojego VPS lub serwera dedykowanego OVHcloud. Znajdziesz tu wszystkie dostępne przewodniki dotyczące instalacji, konfiguracji i administrowania serwerami gier.

## Czym jest Game Panel?

OVHcloud Game Panel to uproszczony interfejs do wdrażania serwerów gier na VPS lub serwerze dedykowanym i zarządzania nimi. Dzięki automatycznemu wdrażaniu i wbudowanym narzędziom możesz uruchamiać instancje, dostosowywać konfiguracje i monitorować wydajność — bez ręcznego zarządzania infrastrukturą bazową.

Za pomocą Game Panel możesz:

- Wdrażać serwery gier dla ponad 140 tytułów (Minecraft, ARK, Counter-Strike 2, Rust i innych)
- Uruchamiać kilka serwerów gier na jednym VPS lub serwerze dedykowanym
- Zarządzać plikami serwera, kopiami zapasowymi i zadaniami zaplanowanymi
- Kontrolować dostęp dzięki uprawnieniom przypisanym do poszczególnych użytkowników i serwerów
- Monitorować wykorzystanie CPU, RAM, dysku i sieci w czasie rzeczywistym
