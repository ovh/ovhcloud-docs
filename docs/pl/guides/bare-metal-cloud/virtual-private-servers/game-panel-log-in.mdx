## Wprowadzenie

Game Panel OVHcloud udostępnia dedykowany interfejs do zarządzania serwerami gier. Aby z niego korzystać, musisz zalogować się przy użyciu swoich danych uwierzytelniających.

**Ten przewodnik wyjaśnia, jak zalogować się do Game Panel OVHcloud oraz jak odzyskać utracone hasło.**

## Wymagania początkowe

- [VPS](/links/bare-metal/vps) lub [serwer dedykowany](/links/bare-metal/bare-metal) na koncie OVHcloud z włączoną funkcją Game Panel.
- Łącze dostępu do Game Panel udostępnione podczas instalacji.

## W praktyce

### Etap 1 — Uzyskaj dostęp do Game Panel

Przejdź do swojego Game Panel. Łącze dostępu zależy od domeny wybranej podczas instalacji.

<img className="thumbnail" alt="Strona logowania Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login.png" loading="lazy" />

### Etap 2 — Zaloguj się

Wprowadź swoją nazwę użytkownika i powiązane hasło, a następnie kliknij <code className="action">Sign In</code>, aby zalogować się do Game Panel.

<img className="thumbnail" alt="Wprowadzanie danych uwierzytelniających na stronie logowania" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login-form.png" loading="lazy" />

### Odzyskiwanie utraconego hasła

#### Konta bez uprawnień administratora

W przypadku utraty hasła poproś administratora o jego zresetowanie. Aby uzyskać szczegółowe informacje, zapoznaj się z przewodnikiem [Zarządzanie użytkownikami w Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-manage-users/).

#### Konto super administratora

Jeśli hasło super administratora zostało utracone, możesz je zresetować: połącz się przez SSH z maszyną hosta, przejdź do folderu wdrożenia instalacji, a następnie uruchom następujące polecenie. Jeśli nie znasz połączeń SSH, zapoznaj się z przewodnikiem [Jak rozpocząć korzystanie z połączeń SSH](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction/).

```bash
sudo bash tools/reset-admin-password.sh
```

Oczekiwany wynik:

```console
New admin password: XXXXXXXXXX
Confirm new admin password: XXXXXXXXXX
[INFO] Updating the root user password in the database...
[INFO] Rotating JWT secret...
[INFO] Recreating the backend to invalidate existing sessions...
[INFO] Admin password reset complete for user: admin
```

Połącz się ponownie z aplikacją przy użyciu nowego hasła administratora.

:::warning
Ta operacja rozłącza wszystkich aktualnie połączonych użytkowników.
:::
