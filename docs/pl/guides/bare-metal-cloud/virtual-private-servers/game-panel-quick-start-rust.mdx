## Wprowadzenie

Game Panel OVHcloud umożliwia wdrożenie serwera Rust z automatyczną instalacją i konfiguracją portów.

**Niniejszy przewodnik wyjaśnia, jak wdrożyć serwer Rust w Game Panel OVHcloud i połączyć się z nim.**

## Wymagania początkowe

- [VPS](/links/bare-metal/vps) lub [serwer dedykowany](/links/bare-metal/bare-metal) na koncie OVHcloud z aktywowaną funkcją Game Panel.
- Dostęp do Game Panel. Zapoznaj się z przewodnikiem [Logowanie do Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## W praktyce

### Etap 1 — Uzyskanie dostępu do Game Panel

Zaloguj się do Game Panel OVHcloud. W menu po lewej stronie przejdź do sekcji `Game Servers` i kliknij <code className="action">Add Game Server</code>.

### Etap 2 — Utworzenie serwera Rust

Wybierz **Rust** z listy gier. Aby szybciej odnaleźć grę, skorzystaj z pola wyszukiwania w górnej części okna. Otworzy się okno konfiguracji.

<img className="thumbnail" alt="Wybór gry Rust z listy gier w Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/select-rust.png" loading="lazy" />

### Etap 3 — Konfiguracja serwera Rust

W tej sekcji możesz nadać nazwę serwerowi w polu **Server Name**.

Automatycznie generowane jest również **RCON Password**. Jest ono wykorzystywane przez system RCON gry do zdalnego administrowania serwerem. Kliknij <code className="action">Regenerate</code>, aby wygenerować nowe hasło, lub zastąp je własnym hasłem (co najmniej 8 znaków). Możesz je zmienić ponownie po zainstalowaniu serwera.

:::warning
Przechowuj to hasło w bezpiecznym miejscu. Każda osoba, która je zna, może wykonywać polecenia administracyjne na Twoim serwerze.
:::

Możesz rozwinąć sekcję <code className="action">Advanced Settings</code>, aby dostosować opcje takie jak mapowanie portów (ports binding), wolumeny, zmienne środowiskowe i limity zasobów. Wartości domyślne są odpowiednie dla większości serwerów gier.

<img className="thumbnail" alt="Formularz konfiguracji serwera Rust z nazwą serwera i ustawieniami zaawansowanymi" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/configure-server.png" loading="lazy" />

:::info
Jeśli jest to Twój pierwszy serwer Rust w Game Panel, a domyślne porty są dostępne, wszystkie wymagane porty zostaną skonfigurowane automatycznie. Konfiguracja ręczna nie jest konieczna. Obraz Rust wykorzystuje trzy porty: `28015/UDP` (Game), `28017/UDP` (Steam Query) i `28082/TCP` (Rust+ companion app). Jeśli porty te są już zajęte przez inny serwer gier, Game Panel przydzieli w zamian wolne porty hosta.
:::

### Etap 4 — Uruchomienie instalacji

Kliknij <code className="action">Install</code>, aby uruchomić instalację. Rozpocznie się wdrażanie, a okno postępu przedstawi następujące etapy:

1. Pobieranie obrazu kontenera.
2. Przygotowanie plików serwera.
3. Tworzenie kontenera.
4. Uruchamianie kontenera.

### Etap 5 — Monitorowanie instalacji

Po uruchomieniu kontenera wyświetli się okno potwierdzenia. Kliknij <code className="action">Open Logs / Console</code>, aby śledzić postęp instalacji w czasie rzeczywistym. Konsolę możesz również otworzyć w dowolnym momencie przyciskiem <code className="action">Log/Console</code> przy serwerze.

<img className="thumbnail" alt="Okno potwierdzenia z przyciskiem Open Logs / Console" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/installation-started.png" loading="lazy" />

Konsola wyświetla kolejne etapy instalacji, a następnie pobieranie plików serwera Rust za pośrednictwem SteamCMD wraz z procentowym postępem.

<img className="thumbnail" alt="Logi instalacji serwera Rust w konsoli Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/installation-logs.png" loading="lazy" />

:::warning
Pliki serwera Rust to pobieranie o rozmiarze kilku gigabajtów. Serwer zachowuje status **Installing** przez cały czas pobierania, a następnie podczas generowania świata gry. Rzeczywisty postęp sprawdzisz w konsoli.
:::

### Etap 6 — Sprawdzenie, czy serwer działa

Upewnij się, że status serwera to **Running** oraz że widoczna jest aktywność CPU i RAM. Do zarządzania serwerem służą przyciski <code className="action">Log/Console</code> i <code className="action">Settings</code>, a do zmiany stanu zasilania przyciski <code className="action">Stop</code> i <code className="action">Restart</code>.

<img className="thumbnail" alt="Serwer Rust ze statusem Running oraz aktywnością CPU i RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/server-running.png" loading="lazy" />

### Etap 7 — Potwierdzenie zakończenia instalacji

Po zakończeniu pobierania konsola wyświetla uruchamianie serwera Rust, a następnie generowanie świata gry (mapa wysokości, biomy, monumenty). Ten etap może potrwać kilka minut.

Status może przez chwilę wyświetlać **Unhealthy**, gdy serwer kończy uruchamianie i nie odpowiada jeszcze na kontrolę stanu. Jest to normalne podczas pierwszej instalacji.

Status serwera zmienia się na **Running** po wygenerowaniu świata i uruchomieniu nasłuchu serwera. Twój serwer Rust jest wtedy gotowy do przyjmowania połączeń.

### Etap 8 — Pobranie informacji o połączeniu

Po uruchomieniu serwera skopiuj adres IP i port z kolumny **Connection** na liście serwerów gier. Skorzystaj z przycisku kopiowania, aby umieścić je w schowku.

### Etap 9 — Dołączenie do serwera w grze Rust

Aby dołączyć do serwera z poziomu klienta gry Rust:

1. Uruchom grę **Rust**.
2. Naciśnij klawisz `F1`, aby otworzyć konsolę gry.
3. Wpisz następujące polecenie, zastępując `IP` i `PORT` wartościami z kolumny **Connection**:

```console
client.connect IP:PORT
```

### Konfiguracja ustawień gry

Sekcja <code className="action">Game Config</code> umożliwia dostosowanie głównych ustawień serwera Rust bez ręcznej edycji plików konfiguracyjnych:

| Ustawienie | Opis |
|------------|------|
| `Server name` | Nazwa wyświetlana w przeglądarce serwerów w grze. |
| `Gamemode` | `vanilla`, `Softcore`, `Hardcore` lub `Primitive`. |
| `Map type` | `Procedural Map`, `Barren`, `Hapis Island` lub `Savas Island`. |
| `Map seed` | Ziarno używane do wygenerowania mapy proceduralnej. |
| `Map size` | Rozmiar wygenerowanej mapy. |
| `Player limit` | Maksymalna liczba graczy jednocześnie. |
| `Save interval` | Odstęp między dwoma zapisami świata gry. |
| `Tick rate` | Częstotliwość odświeżania serwera. |

Dodatkowe opcje, takie jak opis serwera, tryb PvE czy obrażenia od upadku, są dostępne w pliku konfiguracyjnym `server.cfg`, w tej samej sekcji.

W przypadku konfiguracji zaawansowanej skorzystaj z narzędzia [File Manager](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/), aby edytować pliki konfiguracyjne Rust bezpośrednio.
