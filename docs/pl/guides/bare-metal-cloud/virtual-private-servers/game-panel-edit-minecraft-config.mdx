## Wprowadzenie

Game Panel udostępnia konfigurację serwera Minecraft bezpośrednio w interfejsie. Podstawowe opcje, takie jak tryb gry i poziom trudności, są dostępne za pomocą formularza graficznego, a ustawienia zaawansowane pozwalają edytować plik `server.properties` bezpośrednio, zapewniając pełną kontrolę.

**Ten przewodnik wyjaśnia, jak modyfikować konfigurację serwera Minecraft w Game Panel.**

## Wymagania początkowe

- [VPS](https://www.ovhcloud.com/pl/vps/) na koncie OVHcloud z włączoną funkcją Game Panel.
- Serwer Minecraft wdrożony w Game Panel. Zapoznaj się z przewodnikiem [Wdrożenie serwera Minecraft na Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

## W praktyce

### Etap 1 — Otwarcie ustawień serwera

Na głównej stronie Game Panel odszukaj serwer Minecraft, który chcesz skonfigurować. W kolumnie <code className="action">Management</code> kliknij <code className="action">Settings</code>.

<img className="thumbnail" alt="Serwer Minecraft z wyróżnionym przyciskiem Settings" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-server-settings.png" loading="lazy" />

### Etap 2 — Otwarcie zakładki Game Config

W panelu **Server Settings** wybierz <code className="action">Game Config</code> w menu bocznym po lewej stronie.

<img className="thumbnail" alt="Zakładka Game Config w panelu Server Settings" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-game-config.png" loading="lazy" />

### Etap 3 — Konfiguracja gry

Sekcja **Game Configuration** pozwala:

- Włączyć lub wyłączyć **automatyczne aktualizacje**.
- Dostosować **tryb gry**, **poziom trudności** oraz inne opcje rozgrywki.

### Etap 4 — Modyfikacja ustawień zaawansowanych

Sekcja **Advanced Configuration** daje bezpośredni dostęp do pliku `server.properties`, oferując większą kontrolę niż podstawowe opcje interfejsu.

<img className="thumbnail" alt="Sekcja Advanced Configuration z edytorem pliku server.properties" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-advanced-config.png" loading="lazy" />

:::info
Pełną listę kluczy pliku `server.properties` wraz z opisami, wartościami domyślnymi i dopuszczalnymi zakresami znajdziesz na [oficjalnej stronie Minecraft Wiki dotyczącej server.properties](https://minecraft.wiki/w/Server.properties).
:::


Najczęściej modyfikowane klucze:

| Klucz | Opis | Wartość domyślna |
|-----|-------------|---------|
| `gamemode` | Domyślny tryb gry (`survival`, `creative`, `adventure`, `spectator`) | `survival` |
| `difficulty` | Poziom trudności serwera (`peaceful`, `easy`, `normal`, `hard`) | `easy` |
| `max-players` | Maksymalna liczba jednoczesnych graczy | `20` |
| `motd` | Komunikat wyświetlany na liście serwerów | `A Minecraft Server` |
| `online-mode` | Ogranicza dołączanie do uwierzytelnionych kont Minecraft | `true` |
| `view-distance` | Zasięg renderowania po stronie serwera w chunkach (3–32) | `10` |
| `simulation-distance` | Zasięg aktualizacji obiektów w chunkach (3–32) | `10` |
| `white-list` | Ogranicza połączenia do graczy z białej listy | `false` |
| `hardcore` | Włącza tryb hardcore | `false` |
| `pvp` | Włącza obrażenia w trybie gracz kontra gracz | `true` |

:::warning
Niektóre klucze (takie jak `level-seed`, `level-type`, `generator-settings`) działają tylko w momencie generowania świata. Zmiana ich w istniejącym świecie nie przynosi żadnego efektu.
:::


### Etap 5 — Zapisanie i ponowne uruchomienie

Po zapisaniu zmian uruchom ponownie serwer Minecraft z poziomu Game Panel, aby nowa konfiguracja zaczęła obowiązywać.
