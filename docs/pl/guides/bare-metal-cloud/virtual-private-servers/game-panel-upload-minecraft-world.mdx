## Wprowadzenie

Game Panel OVHcloud pozwala przesłać niestandardowy świat Minecraft poprzez przeniesienie plików za pomocą Menedżera plików i dostosowanie konfiguracji nazwy świata.

**Ten przewodnik wyjaśnia, jak przesłać niestandardowy świat na serwer Minecraft w Game Panel OVHcloud.**

## Wymagania początkowe

- [VPS](/links/bare-metal/vps) lub [serwer dedykowany](/links/bare-metal/bare-metal) na koncie OVHcloud z włączoną funkcją Game Panel.
- Serwer Minecraft działający na jednym z następujących wariantów: Minecraft Java Edition, Minecraft Bedrock Edition, PaperMC, Fabric lub NeoForge. Zapoznaj się z przewodnikiem [Wdrażanie serwera Minecraft w Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).
- Folder mapy gotowy do przesłania.

## W praktyce

### Etap 1 — Zatrzymaj serwer Minecraft

Przed przesłaniem nowego świata musisz zatrzymać serwer.

1. Otwórz serwer w Game Panel.
2. Kliknij <code className="action">Stop</code>, aby całkowicie wyłączyć serwer.

:::warning
Nigdy nie przesyłaj ani nie zastępuj świata, gdy serwer jest uruchomiony, ponieważ może to spowodować uszkodzenie świata.
:::

### Etap 2 — Prześlij niestandardowy świat

1. Otwórz serwer w Game Panel.
2. Przejdź do <code className="action">Settings</code>.
3. Otwórz zakładkę <code className="action">File Manager</code>.

<img className="thumbnail" alt="Folder świata w Menedżerze plików" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder.png" loading="lazy" />

**Usuń istniejący świat**

Domyślnie główny folder świata nosi nazwę `world`. Możesz usunąć istniejący folder `world` lub najpierw pobrać go, jeśli chcesz zachować kopię zapasową.

**Prześlij nowy świat**

Po usunięciu starego świata:

1. Znajdź folder niestandardowego świata na swoim komputerze.
2. Przeciągnij i upuść folder bezpośrednio do Menedżera plików.
3. Poczekaj na zakończenie przesyłania.

Niestandardowa mapa powinna zostać przesłana jako folder zawierający pliki świata.

:::warning
Zdecydowanie zalecamy, aby wersja Minecraft przesyłanego świata była zgodna z wersją Minecraft Twojego serwera. Różnica wersji może uniemożliwić wczytanie świata lub spowodować nieoczekiwane zachowanie.
:::

### Etap 3 — Zweryfikuj nazwę świata

Nazwa folderu świata musi być zgodna z nazwą świata skonfigurowaną w ustawieniach serwera.

**Sprawdź nazwę przesłanego folderu**

W Menedżerze plików zanotuj dokładną nazwę przesłanego folderu świata.

**Zaktualizuj konfigurację serwera**

1. Przejdź do zakładki <code className="action">Game Config</code>.
2. Odszukaj ustawienie **World name**.
3. Upewnij się, że jego wartość dokładnie odpowiada nazwie przesłanego folderu.

<img className="thumbnail" alt="Dopasowanie ustawienia World name w Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder-name-config.png" loading="lazy" />

### Ostatni etap

Gdy przesyłanie zostanie zakończone, a ustawienie **World name** będzie zgodne z nazwą folderu:

1. Zapisz zmiany.
2. Uruchom ponownie serwer.

Serwer Minecraft powinien teraz wczytać i używać Twojego niestandardowego świata.
