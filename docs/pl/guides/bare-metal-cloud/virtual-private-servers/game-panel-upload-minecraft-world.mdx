## Wprowadzenie

Game Panel OVHcloud pozwala przesłać niestandardowy świat Minecraft poprzez przeniesienie plików za pomocą File Manager i dostosowanie konfiguracji folderu świata.

**Ten przewodnik wyjaśnia, jak przesłać niestandardowy świat na serwer Minecraft w Game Panel OVHcloud.**

## Wymagania początkowe

- [VPS](https://www.ovhcloud.com/pl/vps/) na koncie OVHcloud z włączoną funkcją Game Panel.
- Serwer Minecraft wdrożony na Game Panel. Zapoznaj się z przewodnikiem [Wdrożenie serwera Minecraft na Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

:::warning
Przed wykonaniem któregokolwiek z poniższych działań upewnij się, że serwer Minecraft jest **zatrzymany**.
:::


## W praktyce

### Etap 1 — Otwarcie File Manager

Na serwerze Minecraft kliknij <code className="action">Settings</code>, a następnie otwórz zakładkę <code className="action">File Manager</code>.

### Etap 2 — Zlokalizowanie folderu świata

W File Manager przejdź do:

```
data > serverfiles
```

W tym katalogu znajdziesz folder o nazwie `world`. Zawiera on bieżącą mapę Minecraft i jest tworzony domyślnie.

<img className="thumbnail" alt="Domyślny folder world w strukturze plików serwera" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder.png" loading="lazy" />

### Etap 3 — Przygotowanie serwera na nową mapę

Zanim prześlesz własną mapę, musisz zwolnić nazwę folderu `world`. Masz trzy możliwości:

- **Usuń go** za pomocą akcji <code className="action">Delete</code>, jeśli już go nie potrzebujesz.
- **Zmień jego nazwę** za pomocą akcji <code className="action">Rename</code>, aby zachować go jako kopię zapasową.
- **Pobierz go lokalnie** za pomocą akcji <code className="action">Download</code>.

### Etap 4 — Przesłanie niestandardowej mapy

W File Manager, znajdując się w katalogu `data > serverfiles`, kliknij <code className="action">Upload files</code> lub przeciągnij i upuść folder mapy na listę plików.

### Etap 5 — Konfiguracja nazwy świata (w razie potrzeby)

Jeśli folder mapy nie nazywa się `world`, musisz zaktualizować konfigurację serwera:

1. Wróć do Game Panel.
2. Otwórz <code className="action">Settings</code> serwera.
3. Przejdź do zakładki <code className="action">Game Config</code>.
4. Odszukaj opcję **World folder name**.
5. Wprowadź dokładną nazwę folderu mapy.

<img className="thumbnail" alt="Konfiguracja nazwy folderu świata w Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder-name-config.png" loading="lazy" />

:::info
**Korzystanie z wielu map**: na serwerze możesz przechowywać wiele map i łatwo między nimi przełączać. Zmień pole **World folder name** w sekcji Game Config, aby wczytać inną mapę. Pamiętaj, aby po zmianie tego ustawienia ponownie uruchomić serwer.
:::


### Etap 6 — Uruchomienie serwera

Uruchom ponownie serwer z poziomu Game Panel. Twoja niestandardowa mapa Minecraft jest gotowa do użycia.
