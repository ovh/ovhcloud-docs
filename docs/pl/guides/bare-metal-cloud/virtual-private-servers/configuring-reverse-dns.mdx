## Wprowadzenie

Rewers DNS (*rDNS*) jest uzupełnieniem rozpoznawania DNS "*forward*", który pozwala na rozpoznawanie nazw domen na adresy IP. Dzięki rewersowi DNS adres IP może zostać rozpoznany jako domena (lub nazwa hosta), z którą jest powiązany. Oznacza to, że zapytania DNS skojarzonego adresu IP zwrócą tę domenę.

Konfiguracja rewersu DNS serwera jest szczególnie użyteczna podczas wysyłania e-maili. Weryfikacja serwera e-mail przez systemy ochrony antyspamowej będzie lepsza, jeśli zapytanie DNS adresu IP zostanie poprawnie rozwiązane.

**Niniejszy przewodnik wyjaśnia, jak skonfigurować rewers DNS Twojego adresu IP w konsoli OVHcloud.**

## Wymagania początkowe

- Adres IP przypisany do usługi Twojego konta OVHcloud
- Domena z jej rejestracją `A` lub `AAAA` powiązana z Twoją usługą

## W praktyce

Na stronie **Adresy IP** możesz zawęzić listę za pomocą szybkich filtrów nad tabelą (**IPv4**, **IPv6**, **Dodatkowy adres IP**, **BYOIP**). Możesz również wyszukać konkretny adres IP w polu **Szukaj**.

<img className="thumbnail" alt="Strona Adresy IP w konsoli OVHcloud z polem Szukaj" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/ip-list-search.png" loading="lazy" />

Kliknij odpowiedni adres IP, aby otworzyć jego stronę, a następnie kliknij zakładkę <code className="action">Reverse DNS</code>. Kliknij przycisk <code className="action">Skonfiguruj</code> nad tabelą.

<img className="thumbnail" alt="Zakładka Reverse DNS adresu IP w konsoli OVHcloud z przyciskiem Skonfiguruj" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-tab.png" loading="lazy" />

W oknie **Konfiguruj Reverse DNS** wprowadź swoją ścieżkę odwrotną w polu **Nazwa hosta reverse DNS** i kliknij <code className="action">Skonfiguruj</code>.

<img className="thumbnail" alt="Okno Konfiguruj Reverse DNS w konsoli OVHcloud z polem Nazwa hosta reverse DNS" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-configure.png" loading="lazy" />

Aby zmienić istniejącą ścieżkę odwrotną, wykonaj te same kroki: jeśli adres IP ma już rewers, pole **Nazwa hosta reverse DNS** otwiera się wstępnie wypełnione jego wartością. Zastąp ją nową wartością i kliknij <code className="action">Skonfiguruj</code>.

:::warning
Po wpisaniu domeny do rewers sprawdzi on natychmiast, czy rekordu `A` / `AAAA` odnosi się do tego samego IP. Jest to używane w procedurach antyspamowych, więc rekordu DNS musi być ważne i propagowane. Podczas wprowadzania rewers obowiązują następujące zasady:

 - rewers nie może się rozpocząć od `-`
 - rewers nie może zawierać więcej niż 63 znaków
 - rewers nie może zawierać wielkich liter
 - rewers może się kończyć znakiem `.`: konsola OVHcloud akceptuje zarówno `domain.tld`, jak i `domain.tld.`

:::


:::info
Jeśli modyfikacja nie działa zgodnie z oczekiwaniami, sprawdź, czy rekord `A` / `AAAA` jest poprawnie skonfigurowany w strefie DNS Twojej domeny. Wprowadzenie zmian w strefie DNS może potrwać do 24 godzin, w przypadku gdy właśnie zmieniłeś rekord.

Jeśli domena jest zarządzana przez OVHcloud jako operator **i korzysta z serwerów DNS OVHcloud**, zapoznaj się z [tym przewodnikiem](/guides/web-cloud/domains/dns-zone-edit).

:::
