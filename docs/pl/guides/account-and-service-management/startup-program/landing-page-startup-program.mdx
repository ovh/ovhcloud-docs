## OVHcloud Startup Program

[OVHcloud Startup Program](/links/transversal/startup-program) pomaga startupom budować i skalować infrastrukturę serwerową w OVHcloud. Po zaakceptowaniu zgłoszenia i podpisaniu umowy otrzymujesz bezpłatne kredyty ważne przez 12 miesięcy, a nasi Startup Program Managerowie wspierają Cię przez cały czas trwania programu.

Jako członek Startup Program możesz:

- Opłacać kwalifikujące się produkty, takie jak Public Cloud i Hosted Private Cloud, za pomocą kredytów
- Zamawiać konsultacje techniczne, aby ocenić i rozwijać swoją infrastrukturę
- Kontaktować się ze Startup Program Managerem, aby uzyskać poradę na każdym etapie
- Spotykać nasze zespoły na wydarzeniach dla startupów
