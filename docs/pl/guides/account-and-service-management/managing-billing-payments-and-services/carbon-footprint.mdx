## Wprowadzenie

W związku z Twoją działalnością lub zainteresowaniem tym tematem może być konieczne obliczenie śladu węglowego Twoich usług.

**Dowiedz się, jak w skali miesiąca pobrać ślad węglowy generowany przez Twoje usługi OVHcloud.**

## Wymagania początkowe

- Posiadanie statusu kontaktu "Płatności" za usługi, w przypadku których chcesz uzyskać ślad węglowy. Aby uzyskać więcej informacji, zapoznaj się z [przewodnikiem dotyczącym zarządzania kontaktami](/guides/account-and-service-management/account-information/managing-contacts).

[[cpnav:account-dashboard]]

**Obliczanie śladu węglowego jest dostępne dla następujących usług:**

- [Serwer dedykowany](https://www.ovhcloud.com/pl/bare-metal/) (Advance, Game, Scale, High Grade, Storage)
- [Serwer dedykowany Eco](https://eco.ovhcloud.com/pl/) (Rise, Kimsufi, So you Start)
- [VMware on OVHcloud](https://www.ovhcloud.com/pl/hosted-private-cloud/vmware/)
- [Public Cloud](https://www.ovhcloud.com/pl/public-cloud/)

## W praktyce

:::info
Dane dotyczące śladu węglowego nie są jeszcze dostępne dla architektur 3AZ i stref lokalnych.

:::

Należy wziąć pod uwagę kilka kwestii:

- Nie możesz wygenerować bilansu dla bieżącego miesiąca.
- Niezależnie od tego, czy za pośrednictwem API OVHcloud podasz datę na początku, w połowie czy na końcu miesiąca, bilans zawsze obejmuje pełne miesiące.
- Bilans nie może być generowany dłużej niż ostatnie 24 miesiące.
- Brak bilansu za okres przed datą wdrożenia funkcji dla każdej usługi OVHcloud (patrz tabela poniżej).

### Pobranie miesięcznego bilansu za poprzedni miesiąc w Panelu klienta OVHcloud

1. Na <ManagerLink to="/#/account/useraccount/dashboard">Panelu klienta</ManagerLink>, w kolumnie po lewej stronie przejdź do sekcji **Przydatne linki**, następnie kliknij zakładkę <code className="action">Mój ślad węglowy</code>.
1. Na nowej stronie, która się wyświetli, kliknij <code className="action">Pobierz dane dot. śladu węglowego z m-ca: [Miesiąc] [Rok]</code>.

<img className="thumbnail" alt="Carbon footprint" src="/images/assets/screens/control-panel/product-selection/right-column/carbon-footprint/my-carbon-footprint.png" loading="lazy" />

Co miesiąc będziesz mógł pobrać ślad węglowy z poprzedniego miesiąca w odniesieniu do wybranych usług.

Jeśli potrzebujesz śladu węglowego za miesiąc wcześniejszy niż poprzedni miesiąc lub bilansu obejmującego kilka miesięcy, musisz obowiązkowo przejść przez nasze API, aby go pobrać.

### Pobierz bilans sprzed poprzedniego miesiąca za pośrednictwem naszych API

Udostępniamy domyślnie API OVHcloud, które umożliwiają programistom lub integratorom łączenie, na przykład, funkcji dostępnych lub nie w Panelu klienta OVHcloud bezpośrednio z ich aplikacjami lub rozwiązaniami.

#### Etap 1 - Logowanie do API OVHcloud

- Przejdź do naszej strony <ApiLink>API OVHcloud</ApiLink> (upewnij się, że jesteś na `https://api.eu.ovhcloud.com`, jeśli Twoje usługi są zainstalowane w Europie, i na `https://api.ca.ovhcloud.com`, jeśli są zainstalowane poza Europą).
- Na stronie, która się wyświetli kliknij <code className="action">Explore the OVHcloud API</code>.
- Na nowej stronie, która się wyświetli i w lewej części strony, przejdź do formularza znajdującego się po prawej stronie pola <code className="action">v1</code>, następnie wybierz/wpisz opcję `/me`.
- Na liście wywołań API, która się wyświetla poniżej, wyszukaj i kliknij wywołanie API odpowiadające wybranemu formatowi: **POST /me/carbonCalculator/pdf** dla bilansu w formacie PDF lub **POST /me/carbonCalculator/csv** dla bilansu w formacie CSV. Możesz również kliknąć bezpośrednio na jedno z poniższych wywołań API, aby uzyskać do niego dostęp:

<Api version="v1" section="/me" method="POST" route={"/me/carbonCalculator/pdf"} />

<Api version="v1" section="/me" method="POST" route={"/me/carbonCalculator/csv"} />

- Po prawej stronie wyświetli się API z ramką do uzupełnienia.
- Kliknij przycisk znajdujący się w prawym górnym rogu o nazwie <code className="action">Authenticate</code>, a następnie przycisk <code className="action">Login with OVHcloud SSO</code>.
- Otworzy się interfejs logowania do <ManagerLink to="/#/account/useraccount/dashboard">Panelu klienta OVHcloud</ManagerLink>.
- Zaloguj się za pomocą identyfikatora klienta, następnie kliknij <code className="action">Authorize</code>, aby korzystać z API OVHcloud w połączeniu z Twoimi usługami.
- Zostaniesz automatycznie przekierowany do poprzedniej strony wybranego wywołania API.

#### Etap 2 - Poproś o wygenerowanie bilansu i pobierz identyfikator żądanego zadania

Dostępne są dwa wywołania API, w zależności od wybranego formatu bilansu. Uzyskany na tym etapie `taskID` wygeneruje plik PDF lub CSV, w zależności od wywołania wybranego na etapie 1. Wybierz odpowiednią zakładkę.

<Tabs>
  <Tab label="Format PDF">
    Wywołanie API **POST /me/carbonCalculator/pdf** generuje bilans obejmujący jeden miesiąc.

    Zastąp datę dzisiejszą, która pojawia się w ramce API, datą z miesiąca, dla którego chcesz uzyskać bilans. Zachowaj następujący format daty:

    ```bash
    {
      "month": "YYYY-MM-DD"
    }
    ```

    Wpisany dzień nie ma znaczenia: niezależnie od niego bilans obejmuje pełny miesiąc. Żądany miesiąc nie może być miesiącem bieżącym ani wykraczać poza ostatnie 24 miesiące.

    <img className="thumbnail" alt="API" src="/images/assets/screens/api/post-me-carboncalculator-pdf.png" loading="lazy" />

    Po wpisaniu daty kliknij niebieski przycisk <code className="action">EXECUTE</code> znajdujący się w prawym dolnym rogu poprzednio wypełnionej sekcji.
  </Tab>
  <Tab label="Format CSV">
    Wywołanie API **POST /me/carbonCalculator/csv** generuje bilans obejmujący zakres miesięcy.

    Zastąp dwie daty, które pojawiają się w ramce API, miesiącem początkowym i miesiącem końcowym obliczeń. Zachowaj następujący format daty:

    ```bash
    {
      "endMonth": "YYYY-MM-DD",
      "startMonth": "YYYY-MM-DD"
    }
    ```

    Wpisany dzień nie ma znaczenia: niezależnie od niego bilans obejmuje pełne miesiące, minimum jeden miesiąc. Data końcowa (`endMonth`) musi być późniejsza niż data początkowa (`startMonth`), a data początkowa nie może wykraczać poza ostatnie 24 miesiące.

    <img className="thumbnail" alt="API" src="/images/assets/screens/api/post-me-carboncalculator-csv.png" loading="lazy" />

    Po wpisaniu obu dat kliknij niebieski przycisk <code className="action">EXECUTE</code> znajdujący się w prawym dolnym rogu poprzednio wypełnionej sekcji.
  </Tab>
</Tabs>

Niezależnie od użytego wywołania, jeśli wszystko zostało wykonane prawidłowo, `taskID` pojawia się w oknie <code className="action">RESPONSE</code>, gdy przewiniesz stronę w dół, pod przyciskiem <code className="action">EXECUTE</code>.

Na przykład, jeśli Twoim identyfikatorem klienta OVHcloud jest `aa00000-ovh`, a żądany bilans dotyczy stycznia 2025 w formacie PDF, otrzymasz następujący wynik:

```bash
{
  "taskID": "aa00000-ovh_202501"
}
```

Skopiuj tylko uzyskaną wartość po Twojej stronie, która jest równa wartości z naszego przykładu `aa00000-ovh_202501` (bez kopiowania dwóch `"` znajdujących się na końcach).

#### Etap 3 - Pobieranie pliku z bilansem węglowym Twoich usług w formacie PDF lub CSV

Dzięki uzyskanej wcześniej wartości `taskID` (z wywołania PDF lub z wywołania CSV) możesz pobrać bilans dwutlenku węgla Twoich usług.

Pozostań na naszej stronie <ApiLink>API OVHcloud</ApiLink> i wykonaj następujące czynności:

- W lewej części strony przejdź do formularza znajdującego się po prawej stronie formularza <code className="action">v1</code>, następnie wybierz/wpisz wybór <code className="action">/me</code>.
- Na liście wywołań API, która się wyświetla poniżej, wyszukaj i kliknij następujące wywołanie API: **GET /me/carbonCalculator/task/&#123;taskID&#125;**. Możesz również kliknąć bezpośrednio na poniższe wywołanie API, aby uzyskać do niego dostęp:

<Api version="v1" section="/me" method="GET" route={"/me/carbonCalculator/task/\{taskID\}"} />

- Po prawej stronie wyświetla się wywołanie API z formularzem do wypełnienia.

Wypełnij formularz w części `PATH PARAMETERS` w następujący sposób:

- `taskID`: skopiuj tutaj wartość `taskID` pobraną podczas wykonywania etapu 2, niezależnie od żądanego formatu.

<img className="thumbnail" alt="API" src="/images/assets/screens/api/get-me-carboncalculator-task-taskid.png" loading="lazy" />

Po wpisaniu poprawnej wartości Twojego `taskID` kliknij niebieski przycisk <code className="action">EXECUTE</code>.

Następujący wynik pojawia się w oknie <code className="action">RESPONSE</code>, gdy przechodzisz na stronę, pod przyciskiem <code className="action">EXECUTE</code>:

```bash
{
  "link": "Find here the complete URL to download the carbon footprint",
  "status": "SUCCESS",
  "taskID": "aa00000-ovh_202501"
}
```

Następnie skopiuj cały adres URL jako HTTPS (**bez cudzysłowów**) po prawej stronie pozycji `"link":`, a następnie wklej go w pasku adresu przeglądarki internetowej, aby rozpocząć pobieranie bilansu dwutlenku węgla w żądanym formacie.

Przeglądarka internetowa pobierze plik automatycznie i może go wyświetlić bezpośrednio w przypadku bilansu w formacie PDF.

:::info
W zależności od ustawień przeglądarki pobieranie i wyświetlanie pliku może być zablokowane. Sprawdź poprawność konfiguracji przeglądarki i ponownie załaduj stronę.

:::

Po otwarciu pliku widoczne są w nim między innymi następujące elementy.

**W bilansie w formacie PDF:**

- Tabelaryczne zestawienie emisji CO2 według kategorii we wnioskowanym miesiącu.
- Tabelaryczne zestawienie emisji CO2 według kategorii między początkiem roku kalendarzowego a miesiącem, którego dotyczy wniosek.
- Tabela wyszczególniająca wartości według typu zamówionego produktu.
- Wykres przedstawiający emisje CO2 w poszczególnych kategoriach.

**W bilansie w formacie CSV:**

- Zestawienie emisji CO2 według serwera fizycznego lub według gamy serwerów (PCI), za wnioskowany miesiąc lub miesiące.

:::warning
Wygenerowany link jest ważny przez 24 godziny. Po otworzeniu linka pobierz bilans dwutlenku węgla z przeglądarki.

:::
