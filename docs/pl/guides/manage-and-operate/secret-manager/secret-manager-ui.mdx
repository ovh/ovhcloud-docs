## Wprowadzenie

Celem tego przewodnika jest przedstawienie korzystania z Secret Manager za pośrednictwem konsoli OVHcloud.

## Wymagania początkowe

- Posiadanie [konta klienta OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- Aby uzyskać dostęp do sekretów za pomocą API REST lub API zgodnego z HashiCorp Vault KV2, skonfiguruj [metodę uwierzytelniania](/guides/manage-and-operate/kms/okms-authentication-methods) dla swojej domeny OKMS (osobisty token dostępu, konto serwisowe lub certyfikat dostępu).

[[cpnav:security-secret-manager]]

## W praktyce

### Opis

Secret Manager to produkt umożliwiający bezpieczne przechowywanie danych uwierzytelniających, kluczy API, kluczy SSH lub dowolnego innego typu sekretu niezbędnego do działania Twoich aplikacji.

Sekret to zbiór jednej lub większej liczby par klucz-wartość zgrupowanych w ramach wersji.
Każda modyfikacja sekretu powoduje utworzenie nowej wersji tego sekretu, co pozwala cofnąć się w historii zmian sekretu.

### Tworzenie sekretu

W konsoli OVHcloud sekretami zarządza się w Key & Secret Manager. W menu po lewej stronie otwórz <code className="action">Bezpieczeństwo</code> i kliknij <code className="action">Key & Secret Manager</code>. Każda domena OKMS ma zakładkę <code className="action">Secrets</code>, która zawiera listę sekretów przechowywanych w tej domenie.

<img className="thumbnail" alt="Zakładka Secrets domeny OKMS z przyciskiem Utwórz sekret" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secrets-tab.png" loading="lazy" />

Aby utworzyć sekret, kliknij <code className="action">Utwórz sekret</code>.

W formularzu tworzenia nie wybiera się regionu: sekret jest tworzony w domenie OKMS wybranej na liście **Domena OKMS**, a więc w regionie tej domeny. Wybierz właściwą domenę, zanim klikniesz <code className="action">Utwórz sekret</code>.

:::info
Jeśli nie masz jeszcze domeny OKMS w regionie, w którym chcesz utworzyć sekret, najpierw ją utwórz: otwórz listę **Domena OKMS**, kliknij <code className="action">Utwórz domenę</code> i wybierz region.
Tworzenie domeny może potrwać kilka minut.
:::


Podaj **Path** sekretu, na przykład **prod/database/MySQL**. Ten Path służy do hierarchicznego uporządkowania sekretów.

Następnie podaj zawartość sekretu w sekcji **Konfiguracja wartości**. Sekret zawiera listę par klucz-wartość. Domyślnie wprowadza się je pojedynczo w widoku **Klucz-wartość** (<code className="action">Dodaj klucz/wartość</code> dodaje wiersz). W widoku **JSON** możesz je wprowadzić w formacie JSON:

```json
{
    "login": "admin",
    "password": "my_secret_password"
}
```

<img className="thumbnail" alt="Strona Utwórz sekret z sekcjami Path i Konfiguracja wartości" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/create-secret-form.png" loading="lazy" />

:::info
Nie ma ograniczeń co do liczby par klucz-wartość w sekrecie, jednak całkowity rozmiar danych nie może przekraczać 64 KB.
:::


Po utworzeniu sekret pojawia się na liście sekretów w zakładce **Secrets** domeny OKMS.

### Zarządzanie sekretami

Po utworzeniu sekretu lista sekretów wyświetla się w zakładce **Secrets** domeny OKMS w konsoli OVHcloud.
Aby wyświetlić sekrety innej domeny OKMS, wybierz ją z listy **Domena OKMS** nad zakładkami, na której Twoje domeny są pogrupowane według regionu.

Możesz uzyskać dostęp do konfiguracji sekretu, klikając jego ścieżkę na liście sekretów, aby wyświetlić jego zawartość, utworzyć nową wersję lub go usunąć.

Dashboard sekretu wyświetla kilka informacji, takich jak informacje ogólne oraz parametry mające zastosowanie do sekretu:

- **Maksymalna liczba wersji**: Po przekroczeniu wskazanej wartości najstarsza wersja zostaje usunięta.
- **Okres ważności wersji**: Po upływie wskazanego czasu wersja zostaje wyłączona.
- **CAS (Check-And-Set Version Control)**: Jeśli ta opcja jest włączona, podczas wprowadzania zmian musisz zawsze podawać numer bieżącej wersji.

<img className="thumbnail" alt="Dashboard sekretu z sekcjami Wartości, Informacje ogólne i Konfiguracja" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secret-dashboard.png" loading="lazy" />

#### Dostęp do zawartości sekretu

Użytkownik posiadający niezbędne uprawnienia IAM może uzyskać dostęp do zawartości sekretu. Skonfiguruj uwierzytelnianie i polityki IAM zgodnie z opisem w [Metody uwierzytelniania OKMS](/guides/manage-and-operate/kms/okms-authentication-methods).

:::info
Uprawnienia do wyświetlania listy wersji (**okms:apiovh:secret/get**) różnią się od uprawnienia do pobierania zawartości tej wersji (**okms:apiovh:secret/version/getData**).
:::


W tym celu kliknij <code className="action">Odsłoń wartość</code> w sekcji **Wartości** w Dashboardzie sekretu.

Sekcja **Wartości** rozwija się i wyświetla zawartość najnowszej wersji sekretu w postaci par klucz-wartość lub w formacie JSON. Każdą wartość można skopiować.

<img className="thumbnail" alt="Sekcja Wartości z parami klucz-wartość bieżącej wersji" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secret-values-revealed.png" loading="lazy" />

Selektor umożliwia nawigację między różnymi wersjami sekretu oraz sprawdzenie statusu wybranej wersji.
Jeśli wersja jest wyłączona lub usunięta, żadna wartość nie jest wyświetlana.

#### Zarządzanie wersjami

Aby uzyskać dostęp do wersji sekretu, kliknij zakładkę <code className="action">Wersje</code>. Zawiera ona listę wszystkich wersji sekretu wraz z ich numerem, datą utworzenia, datą wygaśnięcia i statusem.
Każda modyfikacja sekretu powoduje utworzenie nowej wersji.

<img className="thumbnail" alt="Zakładka Wersje z listą wersji sekretu i ich statusem" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secret-versions.png" loading="lazy" />

Wersja może być:

- Aktywna: Wartość tej wersji jest dostępna.
- Dezaktywowana: Wartość tej wersji jest nadal obecna w systemie, ale nie jest już dostępna, dopóki wersja nie zostanie ponownie aktywowana.
- Usunięta: Wartość tej wersji nie jest już obecna w systemie i nie można jej przywrócić.

Dla każdej wersji kliknij <code className="action">Odsłoń wersję</code>, aby wyświetlić jej wartość. Przycisk `⋮` otwiera menu umożliwiające wyłączenie (<code className="action">Wyłącz</code>) lub ponowną aktywację (<code className="action">Przywróć</code>) wersji albo jej usunięcie (<code className="action">Usuń</code>).

Wersja usunięta przez parametr **Maksymalna liczba wersji** nie pojawia się już na liście wersji.

### Zarządzanie domeną OKMS

Domena OKMS Secret Manager jest współdzielona z domeną OKMS usługi Key Management Service.
Utworzenie lub usunięcie domeny OKMS ma zatem konsekwencje dla obu produktów.

Konfigurację sekretów domeny OKMS możesz zmienić w jej zakładce **Przegląd**, w sekcji **Konfiguracja Secrets** (<code className="action">Zmień</code>).

#### Przypadek wielu domen OKMS

W tym samym regionie może istnieć kilka domen OKMS. Domenę OKMS wybiera się wcześniej z listy **Domena OKMS** nad zakładkami, na której Twoje domeny są pogrupowane według regionu. Sekrety, które wyświetlasz lub tworzysz, należą do domeny wybranej na tej liście: podczas tworzenia sekretu nie ma dodatkowego etapu wyboru.

<img className="thumbnail" alt="Lista Domena OKMS z domenami pogrupowanymi według regionu i pozycją Utwórz domenę" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/okms-domain-switcher.png" loading="lazy" />

Aby dodać domenę OKMS w regionie, kliknij <code className="action">Utwórz domenę</code> u góry tej listy, a następnie wybierz region.

### Korzystanie z Secret Manager przez API

Secret Manager jest dostępny za pomocą dwóch różnych zestawów API. Oba manipulują tymi samymi obiektami — sekret utworzony jedną z metod jest dostępny za pomocą drugiej.

Przed wywołaniem jednego lub drugiego API skonfiguruj [metodę uwierzytelniania](/guides/manage-and-operate/kms/okms-authentication-methods) oraz wymaganą [politykę IAM](/guides/manage-and-operate/kms/okms-authentication-methods#iam-rights-for-okms) w swojej domenie OKMS. W przypadku korzystania z API REST zalecany jest osobisty token dostępu (PAT) lub konto serwisowe.

- [API REST](/guides/manage-and-operate/secret-manager/rest-api) podobne do standardów API OVHcloud.
- [API zgodne z HashiCorp Vault KV2](/guides/manage-and-operate/secret-manager/kv2-api) zapewniające zgodność z aplikacjami już kompatybilnymi z HashiCorp Vault KV2.
