## Wprowadzenie

Z tego przewodnika dowiesz się, jak przypisywać tagi do produktów OVHcloud, jak nimi zarządzać i jak używać ich w politykach IAM.

## Wymagania początkowe

## W praktyce

### Zarządzanie tagami w konsoli OVHcloud

Tagami produktów OVHcloud możesz zarządzać za pomocą ogólnego interfejsu zarządzania tagami lub za pomocą dedykowanych interfejsów w produktach.

Tagi to metadane w postaci par klucz-wartość dodawane do zasobów OVHcloud, które można wykorzystać w politykach IAM lub do kategoryzacji zasobów.

#### Tag manager

<ManagerLink to="/beta/#/iam/tag-manager">Tag manager</ManagerLink> to interfejs, który pozwala zarządzać tagami we wszystkich produktach OVHcloud.

Na stronie wyświetlane są wszystkie tagi przypisane obecnie do Twoich zasobów.

<img className="thumbnail" alt="Strona Tag manager z listą rozwijaną Rodzaj tagu i kolumną Rodzaj tagu" src="/images/manage-and-operate/iam/iam-tag-manager/console/tag-manager-01.png" loading="lazy" />

Dla każdego tagu lista pokazuje liczbę zasobów powiązanych z tym tagiem oraz rodzaj tagu.

Istnieją trzy rodzaje tagów:

- Niestandardowy: tworzony i zarządzany przez Ciebie.
- Predefiniowany: tworzony przez OVHcloud; to Ty odpowiadasz za przypisanie tego rodzaju tagu do swoich zasobów.
- Systemowy: tworzony i automatycznie przypisywany do Twoich zasobów przez OVHcloud (nie można go usunąć).

Domyślnie lista rozwijana **Rodzaj tagu** jest ustawiona na <code className="action">Wszystkie typy</code>, a strona wyświetla również nieprzypisane tagi predefiniowane. Aby zawęzić listę, wybierz z tej listy rozwijanej <code className="action">Niestandardowy</code>, <code className="action">Predefiniowany</code>, <code className="action">Systemowy</code> lub <code className="action">Nieprzypisany</code>.

Kliknij tag, aby otworzyć jego szczegóły z listą zasobów, do których jest przypisany.

<img className="thumbnail" alt="Strona tagu z przyciskami Przypisz do zasobów i Usuń przypisanie tagu" src="/images/manage-and-operate/iam/iam-tag-manager/console/tag-manager-02.png" loading="lazy" />

Następnie możesz przypisać ten tag do innych zasobów za pomocą przycisku <code className="action">Przypisz do zasobów</code>. Wyświetli się wówczas lista wszystkich zasobów konta, umożliwiająca wybór wielu pozycji.

Pole wyszukiwania pomaga znaleźć zasoby.

Aby z kolei usunąć tag z zasobów, zaznacz je w szczegółach tagu, a następnie kliknij <code className="action">Usuń przypisanie tagu</code>.

#### Panel produktu

W przypadku niektórych produktów OVHcloud dodano interfejs umożliwiający zarządzanie tagami bezpośrednio z panelu zarządzania zasobem.

Interfejs zarządzania tagami umożliwia dodawanie tagów do zasobu i ich usuwanie.

Możesz wybrać jeden lub kilka tagów z listy tagów predefiniowanych lub wprowadzić własne tagi, wpisując klucze i wartości bezpośrednio w polach.

### Zarządzanie tagami przez API

Zarządzanie tagami jest scentralizowane w jednym API dla wszystkich produktów OVHcloud:

| **Metoda** |              **Ścieżka**               |          **Opis**           |
| :--------: | :------------------------------------: | :-------------------------: |
|    POST    |    /iam/resource/&#123;resourceURN&#125;/tag    |   Dodanie tagu do zasobu    |
|    DEL     | /iam/resource/&#123;resourceURN&#125;/tag/&#123;key&#125; | Usunięcie tagu z zasobu |

Tag należy podać w następującym formacie:

```json
{
  "key": "environment",
  "value": "production"
}
```

### Używanie tagów w politykach IAM

Tagi mogą być używane jako warunki w politykach IAM za pomocą warunku `resource.Tag(tag_key)`.

Na przykład poniższa polityka przyznaje uprawnienia do wszystkich serwerów VPS z tagiem `Environment:Production`:

```json
{
  "conditions": {
    "conditions": [
      {
        "operator": "MATCH",
        "values": {
          "resource.Tag(Environment)": "Production"
        }
      }
    ],
    "operator": "AND"
  },
  "description": "Give access to VPS with tag Environment:Production",
  "identities": [
    "urn:v1:eu:identity:group:aa1-ovh/devs"
  ],
  "name": "vps-production",
  "permissions": {
    "allow": [
      {
        "action": "vps:apiovh:*"
      }
    ]
  },
  "resources": [
    {
      "urn": "urn:v1:eu:resource:vps:*"
    }
  ]
}
```
