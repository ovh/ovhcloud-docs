## Wprowadzenie

Usługa NAS-HA OVHcloud pozwala na zarządzanie przestrzenią dyskową plików dostępną z poziomu sieci.

**Niniejszy przewodnik wyjaśnia, jak zarządzać partycjami usługi NAS-HA za pomocą interfejsu API OVHcloud.**

## Wymagania początkowe

- Usługa [NAS-HA OVHcloud](https://www.ovhcloud.com/pl/storage-solutions/nas-ha/)
- Zapoznaj się z naszym przewodnikiem Pierwsze kroki z [API OVHcloud](/guides/manage-and-operate/api/first-steps), aby zapoznać się z APIv6 OVHcloud

## W praktyce

Wszystkie drogi API w tym przewodniku są dostępne w <ApiLink section="/dedicated/nasha">sekcji */dedicated/nasha*</ApiLink> konsoli API.

:::info
Podczas korzystania z API wszystkie pola oznaczone gwiazdką (\*) są obowiązkowe.
:::


### Pobranie informacji o usłudze

Wszystkie Twoje aktywne usługi można odzyskać przy użyciu następującej drogi:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha"} />


### Lista wszystkich partycji

Użyj następującej drogi, aby pobrać partycje usługi:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Wewnętrzna nazwa usługi NAS |

### Ustalenie właściwości partycji

Aby wyświetlić szczegóły partycji, użyj następującej drogi:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nazwa wewnętrzna usługi NAS-HA |
| `partitionName` | Yes | Nazwa partycji |

### Odzyskiwanie statystyk partycji

Użyj następującej drogi, aby pobrać informacje dotyczące korzystania z partycji:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/use"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nazwa wewnętrzna usługi NAS-HA |
| `partitionName` | Yes | Nazwa partycji |
| `type` | Yes | Rodzaj statystyki do pobrania: *size*, *used* lub *usedbysnapshots* |

### Tworzenie partycji

Użyj następującej drogi, aby utworzyć nową partycję:

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Wewnętrzna nazwa usługi NAS |
| `partitionDescription` |  | Opis opcjonalny |
| `partitionName` | Yes | Nazwa partycji |
| `protocol` | Yes | *NFS*, *CIFS* lub *NFS_CIFS* dla |
| `size` | Yes | Rozmiar partycji |

Wybierz `NFS` jako protokół i rozmiar `10` Gigabajtów.

### Zmień właściwości partycji

Użyj następującej drogi, aby zmienić partycję:

<Api version="v1" section="/dedicated/nasha" method="PUT" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Wewnętrzna nazwa usługi NAS |
| `partitionName` | Yes | Nazwa partycji |
| `partitionDescription` |  | Nowy opis |
| `size` |  | Nowy rozmiar partycji |

### Pobierz parametry ZFS dla partycji

Użyj następującej drogi, aby pobrać ustawienia ZFS:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Wewnętrzna nazwa usługi NAS |
| `partitionName` | Yes | Nazwa partycji |

### Zmiana parametrów ZFS partycji

:::warning
Domyślne ustawienia ZFS są odpowiednie dla większości zastosowań. Zmieniaj je tylko wtedy, gdy znasz dane przechowywane na partycji. Szczegółowe informacje o każdym ustawieniu i o wartościach stosowanych przez poszczególne szablony użycia znajdziesz w naszym przewodniku "[Konfiguracja ustawień ZFS partycji](/guides/storage-and-backup/file-storage/ha-nas/nas-zfs-settings)".
:::


Użyj następującej drogi, aby zmienić ustawienia ZFS:

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Wewnętrzna nazwa usługi NAS |
| `partitionName` | Yes | Nazwa partycji |
| `templateName` |  | Szablon użycia do zastosowania: *Default*, *Virtual machines*, *Databases* lub *File Systems (big files)*. Wyślij go jako jedyny parametr, bez `atime`, `recordsize` i `sync` |
| `atime` |  | Parametr aktualizacji czasu dostępu: *off* (domyślnie) lub *on* |
| `recordsize` |  | Maksymalny rozmiar bloku w bajtach: *4096*, *8192*, *16384*, *32768*, *65536*, *131072* (domyślnie) lub *1048576* |
| `sync` |  | Parametr synchronizacji pliku: *always*, *disabled* lub *standard* (wartość domyślna) |

### Usuwanie partycji

Użyj następującej drogi, aby usunąć partycję:

<Api version="v1" section="/dedicated/nasha" method="DELETE" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nazwa wewnętrzna usługi NAS-HA |
| `partitionName` | Yes | Nazwa partycji |
