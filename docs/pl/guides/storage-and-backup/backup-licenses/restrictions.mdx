## Wprowadzenie

**Ten przewodnik szczegółowo opisuje znane ograniczenia produktu Backup Licenses, o których należy wiedzieć przed zamówieniem licencji.**

## Znane ograniczenia

### Wersja Veeam Backup & Replication

- Nasza infrastruktura obsługuje wyłącznie serwery Veeam Backup & Replication działające w **wersji 12 lub nowszej**. Serwer VBR działający we wcześniejszej wersji nie może zostać połączony z OVHcloud Veeam Service Provider Console (VSPC), a tym samym nie może mieć przypisanej licencji.

### System operacyjny i dostępne edycje

- Serwery VBR działające w systemie **Linux** (Veeam Software Appliance) obsługują wyłącznie licencje **Veeam Data Platform (VDP)**: Foundation, Advanced lub Premium.
- Edycja **Veeam Enterprise Plus** jest dostępna wyłącznie dla serwerów VBR działających w systemie **Windows**.

Poniższa tabela przedstawia możliwe kombinacje:

| System operacyjny VBR | Veeam Enterprise Plus | Veeam Data Platform (Foundation / Advanced / Premium) |
|---|:---:|:---:|
| **Windows** | Tak | Tak |
| **Linux** (Veeam Software Appliance) | Nie | Tak |

:::info
Szczegółowe informacje o każdej edycji i jej funkcjach znajdziesz w przewodniku "[Zamawianie i konfiguracja pierwszej licencji](/guides/storage-and-backup/backup-licenses/first-configuration)".

:::

### Serwery VBR licencjonowane w ramach Veeam Enterprise

- Serwer VBR, którego licencją nadal zarządza dawna oferta **Veeam Enterprise** od OVHcloud, nie może otrzymać licencji Backup Licenses: jego licencja jest kontrolowana przez serwer Veeam Backup Enterprise Manager, co uniemożliwia VSPC zastosowanie nowej licencji.
- Dlatego musisz **zrezygnować z dawnej usługi Veeam Enterprise (`backupserverenterprise`) i odczekać 24 godziny przed połączeniem serwera VBR z VSPC**. Pełna procedura jest opisana w przewodniku "[Migracja z Veeam Enterprise do Backup Licenses](/guides/storage-and-backup/backup-licenses/migration-veeam-enterprise)".
