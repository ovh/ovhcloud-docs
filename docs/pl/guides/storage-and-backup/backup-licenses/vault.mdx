## Wprowadzenie

**Vault** to przestrzeń dyskowa udostępniana przez OVHcloud, do której możesz wysyłać dane kopii zapasowych. W przypadku Backup Licenses pierwszy Vault jest dostarczany automatycznie wraz z pierwszą licencją.

**Niniejszy przewodnik wyjaśnia, jak działają Vaults w ramach Backup Licenses, jak są rozliczane oraz jak zamawiać dodatkowe.**

## Wymagania początkowe

- Posiadanie zamówionej licencji Backup Licenses. Więcej informacji znajdziesz w naszym przewodniku "[Zamawianie i konfiguracja pierwszej licencji](/guides/storage-and-backup/backup-licenses/first-configuration)".

## W praktyce

### Vault "bundle"

Vault typu **"bundle"** jest dostarczany domyślnie wraz z pierwszą licencją Backup Licenses.

- Ten Vault jest **powiązany z subskrypcją produktu**: zostaje **usunięty w przypadku rezygnacji z produktu Backup Licenses**.
- Jest **unikalny**: masz tylko jeden Vault "bundle", niezależnie od liczby posiadanych licencji.
- Jest **bezpłatny do 500 GB**. Ta przestrzeń może być wykorzystywana zarówno na potrzeby serwerów VBR, jak i innych potrzeb związanych z przechowywaniem danych.

:::danger
Rezygnacja z produktu Backup Licenses skutkuje **usunięciem Vault "bundle" oraz zawartych w nim danych**. Upewnij się, że pobrałeś swoje dane przed rezygnacją.

:::

### Pobieranie danych połączenia Vault

Vault "bundle" jest udostępniany jako **bucket S3<sup>1</sup>**. Aby pobrać dane połączenia (endpoint, dane uwierzytelniające), kliknij <code className="action">Pokaż dane uwierzytelniające</code> na stronie Vault w Panelu klienta OVHcloud.

Te dane pozwalają skonfigurować Vault jako repozytorium obiektów na serwerze Veeam Backup & Replication lub uzyskać do niego dostęp za pomocą dowolnego klienta zgodnego z S3.

### Rozliczanie Vault "bundle"

- **Pierwsze 500 GB jest wliczone** w subskrypcję Backup Licenses, bez dodatkowych opłat.
- **Powyżej 500 GB** każdy dodatkowy zużyty GB jest rozliczany **miesięcznie**, według **publicznej stawki OVHcloud Object Storage**.

:::info
Aktualne ceny są dostępne na [stronie z cennikiem Object Storage](/links/public-cloud/prices-object-storage).

:::

### Zamawianie dodatkowych Vault

Możesz zamówić **dodatkowe Vaults** z poziomu Panelu klienta OVHcloud.

Działają one dokładnie tak samo jak Vault "bundle" (bucket S3, te same zastosowania, te same metody dostępu), z jedną różnicą: są **rozliczane od pierwszego zużytego GB**, według publicznej stawki OVHcloud Object Storage. Nie obejmuje ich żaden bezpłatny limit.

Poniższa tabela podsumowuje różnice:

| | Vault "bundle" | Dodatkowy Vault |
|---|---|---|
| **Dostarczenie** | Dostarczany automatycznie z pierwszą licencją | Zamawiany na żądanie z Panelu klienta |
| **Liczba** | Jeden na subskrypcję | Dowolna liczba |
| **Wliczony limit** | 500 GB bezpłatnie | Brak |
| **Rozliczanie** | Od 501 GB, według publicznej stawki Object Storage | Od pierwszego GB, według publicznej stawki Object Storage |
| **Cykl życia** | Usuwany w przypadku rezygnacji z produktu Backup Licenses | Może zostać anulowany niezależnie |
