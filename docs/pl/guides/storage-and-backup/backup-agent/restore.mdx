## Wprowadzenie

**Dowiedz się, jak przywrócić dane, których kopię zapasową utworzono za pomocą Backup Agent.**

Masz do dyspozycji dwie metody przywracania, które możesz wybrać w zależności od potrzeb:

- **Przywracanie plików (kreator FLR)**: to główna i najczęściej stosowana metoda. Umożliwia przywrócenie jednego lub kilku plików lub folderów z kopii zapasowej, bez ponownego uruchamiania serwera.
- **Pełne przywracanie serwera (Bare Metal Recovery)**: umożliwia przywrócenie całego systemu z obrazu ISO odzyskiwania. Jest przeznaczone do scenariuszy odzyskiwania po awarii, gdy serwer już się nie uruchamia.

:::info
Więcej informacji o produkcie Backup Agent można znaleźć na [tej stronie](/guides/storage-and-backup/backup-agent/product-presentation).

:::


## Wymagania początkowe

- Posiadać serwer Bare Metal z zainstalowanym i skonfigurowanym Backup Agent. Zapoznaj się z naszym przewodnikiem "[Jak skonfigurować pierwszą kopię zapasową](/guides/storage-and-backup/backup-agent/first-configuration)", aby uzyskać więcej informacji.
- Wykonać co najmniej jedną kopię zapasową. Zapoznaj się z naszym przewodnikiem "[Zarządzanie kopiami zapasowymi](/guides/storage-and-backup/backup-agent/backup-restore)", aby uzyskać więcej informacji.

To główna metoda odzyskiwania jednego lub kilku plików lub folderów z kopii zapasowej.

Aby przywrócić pliki i foldery, kliknij na kartę odpowiadającą Twojemu systemowi operacyjnemu:

Wybierz żądany punkt przywracania w kreatorze:
    
    <img className="thumbnail" alt="Punkty przywracania Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-restore-points.png" loading="lazy" />

Następnie potwierdź:

  </Tab>
  <Tab label="Linux">
    Aby przywrócić pliki i foldery w systemie Linux, masz dwie opcje: przez interfejs graficzny lub przez linię poleceń.
    
    #### Przez interfejs graficzny
    
    1\. Połącz się z Twoim serwerem Bare Metal przez SSH.
    2\. Uruchom interfejs Veeam, wpisując poniższe polecenie:
    
    ```bash
    sudo veeam
    ```
    
    3\. W interfejsie wybierz opcję przywracania plików.
    4\. Wybierz kopię zapasową i żądany punkt przywracania.
    5\. Przejdź przez kopię zapasową, aby znaleźć pliki lub foldery do przywrócenia.
    6\. Wybierz pliki i wybierz akcję przywracania:
       - Przywróć do oryginalnego miejsca
       - Skopiuj do nowego miejsca
       - Przeglądaj kopię zapasową
    
    #### Przez linię poleceń
    
    Aby przywrócić pliki przez linię poleceń, musisz najpierw zamontować kopię zapasową:
    
    1\. Wyświetl swoje dostępne kopie zapasowe (użyj `--all`, aby pokazać wszystkie zaimportowane kopie zapasowe):
    
    ```bash
    sudo veeamconfig backup list --all
    ```
    
    2\. Wyświetl punkty przywracania kopii zapasowej:
    
    ```bash
    sudo veeamconfig backup info --id <id_kopii_zapasowej>
    ```
    
    3\. Zamontuj punkt przywracania:
    
    ```bash
    sudo veeamconfig point mount --id <id_punktu>
    ```

    Spowoduje to wyświetlenie potwierdzenia zamontowania i podanie identyfikatora sesji.

    ```bash
    Punkt przywracania został zamontowany.
    Identyfikator sesji: [{<id_sesji>}].
    Dzienniki zapisane w: [/var/log/veeam/Mount/Session_########_######_{<id_sesji>}].
    ```
    
    4\. Po zamontowaniu możesz uzyskać dostęp do plików przez punkt montowania (zazwyczaj w `/mnt/backup/`).
    
    5\. Skopiuj żądane pliki z punktu montowania do swojej docelowej lokalizacji.
    
    6\. Po zakończeniu przywracania odmontuj kopię zapasową; do jej odmontowania użyj identyfikatora sesji:
    
    ```bash
    sudo veeamconfig session stop --id <id_sesji>
    ```
    
    Aby uzyskać więcej informacji, zobacz [dokumentację Veeam](https://helpcenter.veeam.com/docs/agentforlinux/userguide/files_restore_gui.html?ver=13) oraz [dokumentację przywracania przez linię poleceń](https://helpcenter.veeam.com/docs/agentforlinux/userguide/files_restore_cmd.html?ver=13).
  </Tab>
</Tabs>

### Pełne przywracanie serwera (Bare Metal Recovery)

Bare Metal Recovery to funkcja Veeam, która polega na wcześniejszym utworzeniu niestandardowego obrazu ISO, który może być następnie używany do uruchomienia systemu i przywrócenia go z kopii zapasowej przechowywanej na innym serwerze. Ta metoda jest przeznaczona do scenariuszy odzyskiwania po awarii, gdy Twój serwer już się nie uruchamia.

Umożliwia ona:

- Utworzenie **obrazu ISO odzyskiwania**: ten plik umożliwia uruchomienie maszyny w przypadku problemów z uruchomieniem systemu.
- Użycie obrazu ISO w celu uzyskania dostępu do ostatniej kopii zapasowej i przywrócenia jej z infrastruktury OVHcloud.

:::warning
Ten przewodnik opiera się na Veeam Agent dla systemu Windows. Jeśli korzystasz z Veeam Agent dla systemu Linux, procedura jest podobna, choć interfejs działa w trybie tekstowym.
:::


Aby uruchomić z ISO odzyskiwania, użyj IPMI swojego serwera Bare Metal, aby załadować ISO.

#### Krok 1: Utworzenie obrazu ISO odzyskiwania

Jeśli Twój komputer już się nie uruchamia, będziesz potrzebować obrazu ISO odzyskiwania, aby uruchomić go ponownie.

:::warning
Ten obraz należy utworzyć przed wystąpieniem jakiegokolwiek incydentu. Jeśli Twój serwer nie będzie już dostępny, nie będziesz mógł go utworzyć.
:::


Oto jak go utworzyć:

1\. Otwórz na swojej maszynie narzędzie **Create Recovery Media**, dołączone do Veeam Agent.

<img className="thumbnail" alt="Uruchomienie narzędzia Create Recovery Media" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_01.png" loading="lazy" />

2\. Veeam zapyta, czy chcesz dołączyć dodatkowe sterowniki.

:::info
Jeśli korzystasz z określonego sprzętu (na przykład kontrolera RAID), wybierz wymagane sterowniki. W przeciwnym razie domyślne opcje są zazwyczaj wystarczające.
:::


<img className="thumbnail" alt="Wybór sterowników dla obrazu rozruchowego" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_02.png" loading="lazy" />

3\. Wybierz lokalizację zapisu obrazu ISO i nadaj mu nazwę.

<img className="thumbnail" alt="Ustawienie lokalizacji i nazwy obrazu ISO" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_03.png" loading="lazy" />

4\. Poczekaj na zakończenie operacji. Plik ISO zostanie wygenerowany.

<img className="thumbnail" alt="Utworzony obraz ISO odzyskiwania" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_04.png" loading="lazy" />

<img className="thumbnail" alt="Obraz ISO odzyskiwania" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_05.png" loading="lazy" />

Możesz teraz użyć tego obrazu ISO, aby utworzyć rozruchowy klucz USB za pomocą narzędzia takiego jak Rufus.

#### Krok 2: Uruchomienie maszyny z obrazu ISO odzyskiwania

Jeśli Twój system już się nie uruchamia i musisz go przywrócić:

1\. Zamontuj obraz ISO w konsoli swojego serwera, a następnie uruchom z niego maszynę.

:::tip
**Nie wiesz, jak uruchomić maszynę z obrazu ISO?**

Uruchom ponownie swoją maszynę fizyczną i naciśnij wskazany klawisz (zazwyczaj F2, F12, ESC lub DEL), aby uzyskać dostęp do menu rozruchu.
:::


2\. Po uruchomieniu systemu otworzy się kreator odzyskiwania Veeam. Kliknij <code className="action">Bare Metal Recovery</code>.

<img className="thumbnail" alt="Uruchomienie Bare Metal Recovery" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_01.png" loading="lazy" />

3\. Wybierz <code className="action">Network Storage</code>, aby uzyskać dostęp do swoich kopii zapasowych online.

:::warning
Jeśli sieć nie zostanie wykryta, może być konieczne skonfigurowanie jej ręcznie. Kliknij <code className="action">Configure network settings</code> i załaduj brakujące sterowniki.
:::


<img className="thumbnail" alt="Wybór Network Storage" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_02.png" loading="lazy" />

4\. Wybierz <code className="action">Veeam Cloud Connect repository</code>.

<img className="thumbnail" alt="Wybór repozytorium Veeam Cloud Connect" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_03.png" loading="lazy" />

5\. Wprowadź poniższy adres, gdy pojawi się prośba o podanie dostawcy usługi:

<img className="thumbnail" alt="Wprowadzenie DNS" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_04.png" loading="lazy" />

:::warning
Aby poznać DNS oraz dane uwierzytelniające, których należy użyć, musisz [skontaktować się z naszym zespołem wsparcia](/links/support-contact), aby je uzyskać.
:::


6\. Wprowadź swoją nazwę użytkownika i hasło, aby się zalogować.

<img className="thumbnail" alt="Wprowadzenie danych uwierzytelniających" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_05.png" loading="lazy" />

7\. Wybierz serwer, który chcesz przywrócić.

<img className="thumbnail" alt="Wybór serwera" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_06.png" loading="lazy" />

8\. Wybierz punkt przywracania (data/godzina), do którego chcesz powrócić.

Zalecamy użycie ostatniej udanej kopii zapasowej, chyba że masz szczególny powód, aby powrócić do wcześniejszej wersji.

<img className="thumbnail" alt="Wybór punktu przywracania" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_07.png" loading="lazy" />

9\. Wybierz tryb przywracania odpowiedni do Twojej sytuacji (wybierz **Entire computer** w celu pełnego przywrócenia).

<img className="thumbnail" alt="Tryb przywracania" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_08.png" loading="lazy" />

10\. Sprawdź podsumowanie, a następnie uruchom przywracanie.

<img className="thumbnail" alt="Uruchomienie przywracania - potwierdzenie" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_09.png" loading="lazy" />

<img className="thumbnail" alt="Uruchomienie przywracania - postęp" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_10.png" loading="lazy" />

:::warning
Czas trwania procesu przywracania zależy od rozmiaru Twojej kopii zapasowej oraz od szybkości Twojego połączenia internetowego. Po zakończeniu Twój system uruchomi się ponownie ze stanem odpowiadającym wybranemu punktowi przywracania.
:::
