## Wprowadzenie

Public Cloud Archive to rozwiązanie do archiwizacji danych o niskiej pojemności. Jest to rozwiązanie do przechowywania danych na zimno o dużej pojemności.

W przypadku rzadko używanych danych wymagane jest odblokowanie, co oznacza konieczność opóźnienia w odzyskiwaniu danych. Czas ten jest zmienny w zależności od czasu trwania i częstotliwości dostępu do Twoich danych.

## W praktyce

### Odblokuj obiekty w konsoli OVHcloud

W menu po lewej stronie projektu Public Cloud kliknij <code className="action">Cloud Archive</code> w sekcji **Pamięć masowa**. Kliknij przycisk <code className="action">...</code> w wierszu kontenera, a następnie <code className="action">Wyświetl archiwum</code>.

W zakładce <code className="action">Obiekty</code> kolumna **Dostępność** pokazuje stan każdego obiektu:

- **Zablokowany**: obiekt jest zarchiwizowany i należy go odblokować, zanim będzie można go pobrać.
- **Dostępny od** *data*: obiekt jest w trakcie odblokowywania i będzie można go pobrać od wskazanej daty.
- **Tak**: obiekt jest dostępny.

Aby odblokować obiekt, kliknij przycisk <code className="action">...</code> w jego wierszu, a następnie <code className="action">Odblokuj</code>. W kolumnie **Dostępność** wyświetli się wtedy data, od której można odzyskać obiekt.

Gdy obiekt będzie dostępny, kliknij przycisk <code className="action">...</code> w jego wierszu, a następnie <code className="action">Pobierz</code>. Możesz go również pobrać za pomocą [klienta Swift/SFTP/SCP](/guides/storage-and-backup/object-storage/pca-sftp).

#### Automatyzacja pobierania obiektu

:::info
Ta funkcjonalność wymaga pakietu `at`.

:::


```bash
swift download <pca_container> <object>
```
```
Error downloading object '<pca_container>/<object>': Object GET failed: https://storage.gra.cloud.ovh.net/v1/AUTH_702xxxxxxxxxxxxxxxxxxxxxxxxxxdaf/<pca_container>/<object> 429 Too Many Requests
```

```bash
X_OVH_RETRIEVAL_DELAY=$(swift download <pca_container> <object> | awk -F ": " '/X-Ovh-Retrieval-Delay/ {print $2}'
RETRIEVAL_DELAY=$((${X_OVH_RETRIEVAL_DELAY} / 60 + 2))
swift download <pca_container> <object> | at now + ${RETRIEVAL_DELAY} minutes
```
