## Wprowadzenie

Po zamówieniu SSL Gateway możesz go skonfigurować w konsoli OVHcloud.

**Dowiedz się, jak przypisać domeny do SSL Gateway, określić serwery, do których przekazuje on ruch, skonfigurować jego ustawienia sieciowe oraz śledzić jego operacje i statystyki.**

## Wymagania początkowe

- [SSL Gateway](/guides/network/ssl-gateway/order) w ofercie Free lub Advanced
- Dostęp do strefy DNS każdej domeny, którą chcesz obsługiwać przez SSL Gateway

## Wstęp

[SSL Gateway](/links/web/ssl-gateway) to zarządzany front-end HTTPS dla Twojej strony WWW. Działa przed Twoimi własnymi serwerami, nazywanymi serwerami backend: przechowuje certyfikat SSL, obsługuje połączenie TLS z przeglądarkami osób odwiedzających Twoją stronę i chroni ruch przed atakami DDoS, a następnie przekazuje żądania do Twoich serwerów.

Oferta Twojego SSL Gateway określa, co możesz skonfigurować:

| Funkcja | Free | Advanced |
|---|---|---|
| Domeny | 3: 1 domena, jej `www` i 1 subdomena | Do 1000 domen i subdomen, w tym domeny czwartego i wyższych poziomów |
| Serwery backend | 1 | Do 3, z rozkładaniem ruchu między nimi |
| Dedykowane adresy IP | Nie | Tak |
| Profil szyfrowania | Intermediate, bez możliwości zmiany | Modern lub Intermediate |
| HSTS (HTTP Strict Transport Security) | Nie | Tak |
| Dozwolone źródła | Nie: każde źródło może łączyć się z SSL Gateway | Tak |
| Możliwość zmiany reverse DNS | Nie | Tak |
| Zakładka <code className="action">Statystyki</code> | Nie | Tak |
| Certyfikat EV (extended validation) | Nie | Opcjonalnie (Sectigo) |

## W praktyce

### Otwieranie SSL Gateway

Na liście widoczne są wszystkie Twoje usługi SSL Gateway z kolumnami **Nazwa / ID**, **Region**, **Oferta**, **IPv4** i **Status**. Kliknij nazwę usługi SSL Gateway, którą chcesz skonfigurować.

<img className="thumbnail" alt="Lista usług SSL Gateway z kolumnami Nazwa / ID, Region, Oferta, IPv4 i Status" src="/images/network/ssl-gateway/use-ssl-gateway/console/ssl-gateway-list.png" loading="lazy" />

Strona SSL Gateway otworzy się na zakładce <code className="action">Przegląd</code>, która zawiera cztery karty:

- **Informacje ogólne**: identyfikator SSL Gateway, region, reverse DNS, adresy IPv4 i IPv6 oraz zakresy **Wychodzące IPv4**, z których SSL Gateway łączy się z Twoimi serwerami;
- **Subskrypcja**: oferta, data utworzenia, tryb odnowienia i data odnowienia;
- **Konfiguracja sieci**: ustawienia TLS i dostępu do SSL Gateway;
- **Backend**: serwery, do których SSL Gateway przekazuje ruch.

Pozostałe zakładki to <code className="action">Domeny</code>, <code className="action">Statystyki</code> (tylko w ofercie Advanced) i <code className="action">Operacje</code>.

<img className="thumbnail" alt="Zakładka Przegląd usługi SSL Gateway w ofercie Advanced z kartami Informacje ogólne, Subskrypcja, Konfiguracja sieci i Backend" src="/images/network/ssl-gateway/use-ssl-gateway/console/overview-advanced.png" loading="lazy" />

### Dodawanie i usuwanie domen

Aby domena mogła zostać zweryfikowana, jej rekordy DNS muszą wskazywać na SSL Gateway: rekord A na adres IPv4 SSL Gateway oraz, jeśli SSL Gateway ma adres IPv6, rekord AAAA na ten adres. Oba adresy są widoczne w karcie **Informacje ogólne**. Jeśli strefą DNS domeny zarządza OVHcloud, zapoznaj się z naszymi przewodnikami dotyczącymi [rekordów A](/guides/web-cloud/domains/dns-zone-a-record-creation) i [rekordów AAAA](/guides/web-cloud/domains/dns-zone-aaaa-record-creation).

Aby przypisać domenę, otwórz zakładkę <code className="action">Domeny</code> i kliknij <code className="action">Dodaj domenę</code>.

<img className="thumbnail" alt="Zakładka Domeny usługi SSL Gateway z przyciskiem Dodaj domenę i ikoną usuwania w wierszu domeny" src="/images/network/ssl-gateway/use-ssl-gateway/console/domains-tab.png" loading="lazy" />

W polu **Domena** wpisz nazwę hosta, którą chcesz obsługiwać przez HTTPS, na przykład `shop.example.com`, a następnie kliknij <code className="action">Dodaj domenę</code>.

<img className="thumbnail" alt="Okno Dodaj domenę z polem Domena" src="/images/network/ssl-gateway/use-ssl-gateway/console/add-domain-dialog.png" loading="lazy" />

Walidacja DNS może potrwać do 72 godzin. Do jej zakończenia domena ma status **Creating**.

SSL Gateway w ofercie Free obsługuje 3 domeny: 1 domenę, jej `www` i 1 subdomenę. Po przypisaniu 3 domen przycisk <code className="action">Dodaj domenę</code> jest nieaktywny.

Aby usunąć domenę, kliknij ikonę usuwania w jej wierszu, a następnie <code className="action">Usuń</code>. Domena zostanie odłączona od SSL Gateway i nie będzie już udostępniana przez HTTPS.

### Konfiguracja serwerów backend

Karta **Backend** w zakładce <code className="action">Przegląd</code> pokazuje, dokąd SSL Gateway przekazuje odbierany ruch: adres IP i port Twoich serwerów.

**Oferta Free**: SSL Gateway przekazuje ruch do 1 serwera. Kliknij <code className="action">Zmień backend</code>, wpisz **Adres IP** serwera i **Port**, na którym serwer odbiera ruch z SSL Gateway, a następnie kliknij <code className="action">Zapisz</code>.

<img className="thumbnail" alt="Panel Zmień backend usługi SSL Gateway w ofercie Free z polami Adres IP i Port" src="/images/network/ssl-gateway/use-ssl-gateway/console/edit-backend-drawer.png" loading="lazy" />

**Oferta Advanced**: SSL Gateway rozkłada ruch na maksymalnie 3 serwery. Kliknij <code className="action">Dodaj serwer</code>, wpisz jego **Adres IP** i **Port**, a następnie kliknij <code className="action">Dodaj</code>. Aby zmienić lub usunąć serwer, użyj menu w jego wierszu.

<img className="thumbnail" alt="Panel Dodaj serwer usługi SSL Gateway w ofercie Advanced z polami Adres IP i Port" src="/images/network/ssl-gateway/use-ssl-gateway/console/add-server-drawer.png" loading="lazy" />

Adres IP musi być publicznym adresem IPv4 Twojego serwera: SSL Gateway nie może połączyć się z adresem prywatnym.

Każda zmiana jest wykonywana jako operacja i zostaje zastosowana za chwilę. Możesz ją śledzić w zakładce <code className="action">Operacje</code>.

SSL Gateway łączy się z Twoimi serwerami z zakresów IP wymienionych w polu **Wychodzące IPv4** w karcie **Informacje ogólne**. Zezwól na ruch z tych zakresów w zaporach sieciowych (firewall) Twoich serwerów.

### Konfiguracja ustawień sieciowych

W karcie **Konfiguracja sieci** kliknij <code className="action">Zmień konfigurację sieci</code>. Możesz ustawić:

- **Profil szyfrowania**: zestawy szyfrów, które SSL Gateway oferuje przeglądarkom. <code className="action">Modern</code> zachowuje tylko najsilniejsze szyfry, przeznaczone dla nowszych klientów; <code className="action">Intermediate</code> obsługuje również starszych klientów.
- <code className="action">HTTPS do backendu</code>: szyfruje również ruch od SSL Gateway do Twoich serwerów, a nie tylko od przeglądarek do SSL Gateway.
- <code className="action">Przekierowanie HTTPS</code>: przekierowuje wszystkie żądania HTTP na HTTPS.
- <code className="action">HSTS</code>: informuje przeglądarki, że podczas kolejnych wizyt mają łączyć się z Twoimi domenami wyłącznie przez HTTPS.
- **Dozwolone źródła**: adresy lub bloki IPv4 lub IPv6, które mogą łączyć się z SSL Gateway. Wpisz adres lub blok, na przykład `203.0.113.0/24`, a następnie kliknij <code className="action">Dodaj</code>, osobno dla każdego źródła. Aby usunąć źródło, kliknij krzyżyk obok niego. Jeśli żadne źródła nie są podane, każde źródło może łączyć się z SSL Gateway.

Następnie kliknij <code className="action">Zapisz</code>.

<img className="thumbnail" alt="Panel Zmień konfigurację sieci z listą Profil szyfrowania, polami wyboru HTTPS do backendu, Przekierowanie HTTPS i HSTS oraz polem Dozwolone źródła" src="/images/network/ssl-gateway/use-ssl-gateway/console/network-configuration-drawer.png" loading="lazy" />

W ofercie Free profil szyfrowania pozostaje ustawiony na **Intermediate**, a HSTS i dozwolone źródła nie są dostępne. Jeśli SSL Gateway w ofercie Free nadal ma takie ustawienia, zapisanie zmiany przywróci je do wartości oferty Free: Intermediate, HSTS wyłączony, brak ograniczenia źródeł.

### Zmiana reverse DNS

W ofercie Advanced możesz ustawić reverse DNS SSL Gateway: w karcie **Informacje ogólne** kliknij ikonę ołówka obok pozycji **Reverse DNS**, wpisz nazwę hosta w polu **Reverse DNS**, a następnie kliknij <code className="action">Zapisz</code>. W ofercie Free nie można zmienić reverse DNS.

<img className="thumbnail" alt="Panel Zmień reverse DNS z polem Reverse DNS" src="/images/network/ssl-gateway/use-ssl-gateway/console/reverse-dns-drawer.png" loading="lazy" />

### Śledzenie operacji

Każda zmiana w SSL Gateway, taka jak dodanie lub usunięcie domeny albo serwera czy zmiana oferty, jest wykonywana jako operacja. Zakładka <code className="action">Operacje</code> wyświetla je w kolumnach **ID**, **Akcja**, **Status**, **Postęp** i **Data utworzenia**. Aby wyświetlić szczegóły operacji, kliknij <code className="action">Przejdź do szczegółów</code> w jej wierszu.

### Wyświetlanie statystyk

W ofercie Advanced zakładka <code className="action">Statystyki</code> przedstawia ruch SSL Gateway. W sekcji **Okres** wybierz przedział czasu, od <code className="action">1 godz.</code> do <code className="action">1 mies.</code> (jeden miesiąc). Zakładka pokazuje średnią i szczytową liczbę żądań i połączeń na sekundę w wybranym okresie. Nad wykresem wybierz <code className="action">Żądania/s</code> lub <code className="action">Połączenia/s</code>.

<img className="thumbnail" alt="Zakładka Statystyki usługi SSL Gateway w ofercie Advanced z wyborem okresu, wartościami średnią i szczytową oraz wykresem żądań" src="/images/network/ssl-gateway/use-ssl-gateway/console/statistics-tab.png" loading="lazy" />

### Zarządzanie ofertą i subskrypcją

Karta **Subskrypcja** pokazuje ofertę, datę utworzenia, tryb odnowienia i datę odnowienia. Kliknij <code className="action">Zarządzaj subskrypcją</code>, aby zmienić sposób odnawiania. Aby zrezygnować z usługi, kliknij <code className="action">Rezygnacja</code>, a następnie ponownie <code className="action">Rezygnacja</code> w oknie potwierdzenia: otrzymasz wtedy e-mail, w którym należy potwierdzić rezygnację.

<Region zones={['eu']}>

Jeśli ofertę Twojego SSL Gateway można zmienić na wyższą, w karcie **Subskrypcja** widoczny jest również link <code className="action">Zmień ofertę</code>.

<img className="thumbnail" alt="Zakładka Przegląd usługi SSL Gateway w ofercie Free z linkiem Zmień ofertę w karcie Subskrypcja" src="/images/network/ssl-gateway/use-ssl-gateway/console/overview-free.png" loading="lazy" />

Kliknij <code className="action">Zmień ofertę</code>. Okno **Przejdź na Advanced** wymienia, co dodaje oferta Advanced (do 1000 domen i subdomen, domeny czwartego i wyższych poziomów, dedykowany adres IP, rozkładanie ruchu na maksymalnie 3 serwery backend), kwotę do zapłaty dzisiaj, naliczoną proporcjonalnie, oraz kwotę pobieraną następnie co miesiąc.

Pole wyboru <code className="action">Zapłać teraz moją domyślną metodą płatności</code> jest domyślnie zaznaczone. Aby zamiast tego zapłacić na stronie zamówienia, która otworzy się w nowej karcie przeglądarki, odznacz je. Następnie kliknij <code className="action">Zmień ofertę</code>.

<img className="thumbnail" alt="Okno Przejdź na Advanced z kwotami, ostrzeżeniem dotyczącym adresu IP i polem wyboru Zapłać teraz moją domyślną metodą płatności" src="/images/network/ssl-gateway/use-ssl-gateway/console/upgrade-dialog.png" loading="lazy" />

:::warning
Oferta Advanced działa na dedykowanych adresach IP. Po zakończeniu zmiany oferty Twój SSL Gateway otrzymuje nowy adres IPv4 i IPv6, a dotychczasowe adresy natychmiast przestają obsługiwać ruch. Skieruj swoje domeny na nowe adresy, wysłane e-mailem i widoczne w karcie **Informacje ogólne**: do tego czasu Twoja strona nie jest dostępna przez SSL Gateway.

:::

SSL Gateway zachowuje swój identyfikator i konfigurację. Zmiana oferty jest wykonywana jako operacja, którą możesz śledzić w zakładce <code className="action">Operacje</code>.

</Region>

### Odnowienie certyfikatu SSL

Certyfikat SSL usługi SSL Gateway to certyfikat DV (domain validation) wydawany przez Let's Encrypt i odnawiany automatycznie. W ofercie Advanced dostępny jest opcjonalnie certyfikat EV wydawany przez Sectigo.

Aby odnowić certyfikat na żądanie, użyj następującego wywołania API:

<Api version="v1" section="/sslGateway" method="POST" route={"/sslGateway/\{serviceName\}/renewCertificate"} />
