## Wprowadzenie

Opcja [DNS Anycast](/links/web/domains-options-anycast) przyspiesza odczyt DNS Twojej nazwy domeny na całym świecie. Nie potrzebujesz już tego przyspieszenia lub nie chcesz go odnawiać po upływie terminu ważności?

**Dowiedz się, jak zrezygnować z opcji DNS Anycast Twojej nazwy domeny z poziomu Panelu klienta OVHcloud.**

## Wymagania początkowe

- Posiadanie [nazwy domeny](/links/web/domains) w OVHcloud.
- Opcja DNS Anycast musi być aktywna dla danej nazwy domeny. Aby to sprawdzić, zapoznaj się z naszym przewodnikiem "[Włączenie DNS Anycast dla Twojej domeny](/guides/web-cloud/domains/dns-anycast-enable)".
- Zalogowanie się do Panelu klienta OVHcloud.

## W praktyce

:::info
Rezygnacja nie następuje natychmiast: opcja DNS Anycast pozostaje aktywna i działa do dnia upływu terminu jej ważności. Nie zostaje odnowiona i jest usuwana w tym dniu.
:::

Kliknij poniższe zakładki, aby wyświetlić kolejne **4** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź do strony <ManagerLink to="/#/web-domains/domain">Domeny</ManagerLink>, a następnie wybierz daną nazwę domeny.

    <img className="thumbnail" alt="Lista nazw domen w Panelu klienta OVHcloud" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-names.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Po przejściu do danej nazwy domeny wybierz zakładkę <code className="action">Serwery DNS</code>.

    <img className="thumbnail" alt="Zakładka Serwery DNS nazwy domeny" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    W prawej kolumnie wyświetlonej strony kliknij przycisk <code className="action">Zrezygnuj z DNS Anycast</code>.

    <img className="thumbnail" alt="Przycisk Zrezygnuj z DNS Anycast w zakładce Serwery DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 4">
    Wyświetlona strona przedstawia przeznaczenie opcji oraz datę, w której ma zostać automatycznie odnowiona. Kliknij przycisk <code className="action">Zrezygnuj z DNS Anycast</code>.

    <img className="thumbnail" alt="Strona rezygnacji z opcji DNS Anycast" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns-page.png" loading="lazy" />

    W wyświetlonym oknie potwierdzenia kliknij <code className="action">Zatwierdź</code>, aby zatwierdzić rezygnację z usługi DNS Anycast.

    <img className="thumbnail" alt="Okno potwierdzenia rezygnacji z usługi DNS Anycast" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns-confirm.png" loading="lazy" />
  </Tab>
</Tabs>

Po zapisaniu rezygnacji sprawdź jej uwzględnienie w zakładce <code className="action">Informacje ogólne</code> Twojej nazwy domeny: sekcja **Konfiguracja** wskazuje status opcji DNS Anycast oraz datę jej wejścia w życie.

:::info
Po dacie wejścia w życie rezygnacji Twoja nazwa domeny nie korzysta już z serwerów DNS Anycast. Weź pod uwagę naturalny czas propagacji usługi DNS, który może trwać do 48 godzin.
:::
