## Czym jest DNS?

**DNS** (*Domain Name System*) to książka telefoniczna Internetu: tłumaczy czytelne dla człowieka nazwy domen (takie jak `mydomain.ovh`) na adresy IP zrozumiałe dla maszyn. Bez niego trzeba by było pamiętać ciąg cyfr, aby dotrzeć do każdej strony internetowej lub usługi online.

W OVHcloud konfiguracja DNS nazwy domeny opiera się na trzech elementach:

- **serwery DNS**, które hostują i rozpowszechniają informacje o Twojej domenie;
- **strefa DNS**, plik gromadzący wszystkie Twoje rekordy;
- **rekordy DNS**, gdzie każdy wiersz łączy nazwę z wartością (adres IP, serwer poczty, tekst itp.).

## Jak działa DNS?

Od nazwy Twojej domeny aż po każdy rekord rozpoznawanie DNS przebiega przez łańcuch czterech ogniw.

<DnsChain />

### Serwer DNS

Serwery DNS hostują i rozpowszechniają w Internecie informacje o Twojej domenie. Gdy internauta wywołuje Twoją stronę, to one odpowiadają, wskazując, gdzie ją znaleźć. Domyślnie Twoja domena korzysta z serwerów DNS OVHcloud. [Wszystko o serwerach DNS](/guides/web-cloud/domains/dns-server-general-information).

<DnsServerIllustration />

### Strefa DNS

Strefa DNS to plik konfiguracyjny powiązany z Twoimi serwerami DNS. Gromadzi wszystkie rekordy Twojej domeny: to tutaj dodajesz, edytujesz lub usuwasz swoje wpisy. [Wszystko o strefie DNS](/guides/web-cloud/domains/dns-zone-general-information).

<DnsZoneIllustration />

### Rekordy DNS

Każdy rekord to wiersz strefy, który łączy nazwę z wartością: adres IP, serwer poczty, tekst itp. Jego typ określa jego rolę, oznaczoną poniżej kolorem. Wybierz ten, który chcesz skonfigurować, aby otworzyć odpowiedni przewodnik.
