## W praktyce

### Etap 1: Zapoznanie się z ograniczeniami

Zgodnie z wymogami amerykańskiego organu regulacyjnego ds. SMS (Neustar), przed wysłaniem wiadomości SMS do tego kraju szablon wiadomości musi zostać zatwierdzony przez nasze służby.
Dozwolone są wyłącznie wiadomości z powiadomieniami oraz wiadomości związane z uwierzytelnianiem dwuskładnikowym, natomiast szablony reklamowych wiadomości SMS nie są akceptowane. Po zdefiniowaniu szablonów wiadomości SMS są wysyłane w taki sam sposób, jak do innych krajów.

Możesz wystąpić o zatwierdzenie wielu szablonów wiadomości.

:::info
Definiowanie szablonów wiadomości jest bezpłatne i wykonywane przez zespoły OVHcloud w ciągu dwóch dni roboczych.

:::

### Etap 2: Dodawanie szablonu

#### 2.1 Z poziomu Panelu klienta

Kliknij kartę <code className="action">Wiadomość SMS i kampania</code>, a następnie <code className="action">Zarządzanie SMS-ami</code>.

Na koniec kliknij <code className="action">Zarządzaj modelami</code>.

<img className="thumbnail" alt="SMS messages to the USA" src="/images/web-cloud/messaging/sms/envoi-de-sms-aux-etats-unis/smstousa1.png" loading="lazy" />

Na kolejnej stronie kliknij <code className="action">Operacje</code>, a następnie <code className="action">Dodaj</code>.

<img className="thumbnail" alt="SMS messages to the USA" src="/images/web-cloud/messaging/sms/envoi-de-sms-aux-etats-unis/smstousa2.png" loading="lazy" />

Pojawi się okno pop-up z polami do wypełnienia.

<img className="thumbnail" alt="SMS messages to the USA" src="/images/web-cloud/messaging/sms/envoi-de-sms-aux-etats-unis/smstousa3.png" loading="lazy" />

| Pole       | Opis                                                                                                      |
|-------------|------------------------------------------------------------------------------------------------------------------|
| Nazwa         | Nazwa szablonu                                                                                                  |
| Aktywność    | Wybierz typ szablonu:<br/>\- Powiadomienie<br/>\- Uwierzytelnianie<br/>\- System przetwarzania transakcji |
| Opis | Opis szablonu                                                                                            |
| Szablon      | Wpisz szablon zawierający zmienną umieszczoną między znakami #                                                                  |

#### 2.2 Z poziomu API

:::tip
Jeśli nie wiesz, jak korzystać z API OVHcloud, zapoznaj się z naszym przewodnikiem [Pierwsze kroki z API OVHcloud](/guides/manage-and-operate/api/first-steps).

:::

Zaloguj się na [api.ovh.com/](/links/api), a następnie użyj poniższego API:

<Api version="v1" section="/sms" method="POST" route={"/sms/\{serviceName\}/templatesControl"} />

#### Przykłady szablonów

Poniżej znajdziesz dwa przykłady szablonów wiadomości, które można wysyłać do Stanów Zjednoczonych.

- Przykład szablonu uwierzytelniającego:

```bash
Your security code is: #CODE#. Have a good day!
```

- Przykład szablonu powiadomienia:

```bash
Our monitoring system detected your server #SERVER# doesn't respond to ping requests
```

### Etap 3: Analiza zwracanych wyników

Po utworzeniu i zatwierdzeniu szablonu wiadomości wysyłana wiadomość SMS jest automatycznie porównywana z Twoimi szablonami. Jeśli wynik porównania jest pozytywny, wiadomość SMS zostaje wysłana w taki sam sposób, jak do dowolnego innego odbiorcy.

Jeśli wyślesz wiadomość SMS do Stanów Zjednoczonych bez uprzedniego utworzenia i zatwierdzenia szablonu, wiadomość zostanie odrzucona, a Ty otrzymasz Premium Tracking Transaction Code (kod PTT) 1999, który odpowiada komunikatowi błędu "No templates available".

Pozostałe możliwe kody zwracanych wyników znajdziesz w [przewodniku dotyczącym użytkowników SMS](/guides/web-cloud/messaging/sms/sms-users).
