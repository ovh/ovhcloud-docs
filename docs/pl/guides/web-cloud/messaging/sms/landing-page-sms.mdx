## Prezentacja usługi SMS OVHcloud

Usługa [SMS OVHcloud](/links/telecom/sms) umożliwia wysyłanie wiadomości SMS do klientów i kontaktów, pojedynczo lub w ramach masowych kampanii, z poziomu Panelu klienta OVHcloud lub bezpośrednio z własnych aplikacji za pośrednictwem API. Znajdziesz tu wszystkie przewodniki dotyczące konfiguracji, wysyłania i zarządzania wiadomościami SMS.

Dzięki tej usłudze możesz:

- Wysyłać wiadomości SMS z Panelu klienta, przez e-mail, z adresu URL (http2sms) lub za pośrednictwem API OVHcloud
- Uruchamiać i monitorować kampanie SMS marketingowe i transakcyjne
- Zarządzać nadawcami, użytkownikami i listami odbiorców
- Śledzić historię i automatycznie doładowywać środki na koncie SMS
