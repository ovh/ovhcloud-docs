## Wprowadzenie

Z poziomu Panelu klienta OVHcloud możesz sprawdzić i pobrać historię wysłanych wiadomości SMS. Z tego przewodnika dowiesz się, jak to zrobić.

## Wymagania początkowe

- [Konto SMS OVHcloud](/links/telecom/sms), z którego wysłano co najmniej 1 wiadomość SMS.

## W praktyce

Historia zawiera datę, godzinę, nadawcę, odbiorcę oraz treść wysłanej wiadomości SMS.

:::info
W Panelu klienta OVHcloud możesz wyświetlić wiadomości SMS wysłane w ciągu ostatnich 6 miesięcy (lub ostatnie 5000 wiadomości SMS, jeśli w ciągu ostatnich 6 miesięcy wysłałeś ich więcej niż 5000).

Aby wyświetlić starsze wiadomości SMS (do ostatnich 12 miesięcy), musisz pobrać historię wiadomości SMS w formacie CSV. Sprawdź [Etap 2 tego przewodnika](#csv).

:::

### Etap 1: Wyświetlanie historii w Panelu klienta

Na pasku kart kliknij <code className="action">Wiadomość SMS i kampania</code>, a następnie <code className="action">Zarządzanie SMS-ami</code>, aby uzyskać dostęp do historii pojedynczych wiadomości SMS, lub <code className="action">Zarządzanie kampaniami</code>, aby uzyskać dostęp do historii kampanii SMS.

Następnie kliknij <code className="action">Historia wysyłki</code> lub <code className="action">Statystyki i historia</code>.

<img className="thumbnail" alt="sms-history" src="/images/web-cloud/messaging/sms/sms-history/smshistory1.png" loading="lazy" />

Aby posortować historię według daty wysłania, kliknij kolumnę "Data" po lewej stronie.

<img className="thumbnail" alt="sms-history" src="/images/web-cloud/messaging/sms/sms-history/smshistory2.png" loading="lazy" />

Kolumna Operacje <code className="action">...</code> na końcu każdej wiadomości SMS umożliwia wyświetlenie lub usunięcie wiadomości.

<img className="thumbnail" alt="sms-history" src="/images/web-cloud/messaging/sms/sms-history/smshistory3.png" loading="lazy" />

Aby usunąć kilka wiadomości SMS jednocześnie, zaznacz pola obok każdej z nich. Nad historią pojawi się przycisk <code className="action">Usuń wybrane SMS-y</code>.

<img className="thumbnail" alt="sms-history" src="/images/web-cloud/messaging/sms/sms-history/smshistory4.png" loading="lazy" />

Przycisk <code className="action">Filtruj</code> umożliwia filtrowanie wyszukiwania według nadawcy (jeśli masz wielu nadawców) lub odbiorcy.

<img className="thumbnail" alt="sms-history" src="/images/web-cloud/messaging/sms/sms-history/smshistory5.png" loading="lazy" />

### Etap 2: Pobieranie historii wysyłki w formacie CSV <a name="csv"></a>

Kliknij przycisk <code className="action">Operacje</code> nad historią, a następnie <code className="action">Pobierz</code>, aby pobrać historię wiadomości SMS w formacie .csv.

<img className="thumbnail" alt="sms-history" src="/images/web-cloud/messaging/sms/sms-history/smshistory6.png" loading="lazy" />

Następnie możesz wyświetlić historię w arkuszu kalkulacyjnym. Informacje będą wyświetlane jak w poniższym przykładzie.

<img className="thumbnail" alt="sms-history" src="/images/web-cloud/messaging/sms/sms-history/smshistory7.png" loading="lazy" />

Poniżej znajdziesz opis informacji zawartych w historii:

|  Tytuł  |  Opis  |
|  :-----          |  :-----          |
|  id |  unikalny identyfikator wysłanej wiadomości SMS używany przez nasze serwery |
|  date | data i godzina wysłania wiadomości SMS  |
|  sender |  nadawca wiadomości SMS |
|  receiver |  numer telefonu odbiorcy |
|  ptt |  kod zwrotny dotyczący statusu wiadomości SMS |
|  operatorCode |  identyfikator sieci operatora komórkowego, do którego wysłaliśmy wiadomość SMS |
|  descriptionDlr |  opis otrzymanego kodu ptt, a tym samym status wiadomości SMS |
|  tag |  znacznik przydzielony ręcznie za pomocą API (jednej lub kilku wiadomościom SMS) albo automatycznie przez nasze serwery każdej wysłanej wiadomości SMS (lub każdej kampanii SMS) |
|  message |  treść wiadomości SMS |

Więcej informacji o kodach ptt oraz różnych identyfikatorach DLR znajdziesz w ostatniej sekcji przewodnika [Wszystko, co musisz wiedzieć o użytkownikach SMS](/guides/web-cloud/messaging/sms/sms-users#callback-url).
