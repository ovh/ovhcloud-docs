## Wprowadzenie

Twój hosting Cloud Web dysponuje przestrzenią dyskową, na której możesz hostować Twoje strony WWW lub aplikacje.

**Dowiedz się, jak pobrać kopię zapasową przestrzeni FTP Twojego hostingu Cloud Web**.

:::info
Kopie zapasowe proponowane przez OVHcloud dla hostingu Cloud Web są niezamówione. Są one dostępne do uzupełnienia Twoich własnych środków tworzenia kopii zapasowych w sytuacjach nadzwyczajnych. Zalecamy zatem regularne wykonywanie Twoich własnych kopii zapasowych, aby zapobiec ewentualnej utracie danych.

Wykonując kopię zapasową bezpieczeństwa Twojej strony WWW i korzystając z bazy danych, wykonaj również jej kopię zapasową. Aby [pobrać kopię zapasową bazy danych](/guides/web-cloud/web-hosting/sql-database-export), zapoznaj się z naszym przewodnikiem.
:::

**Dowiedz się, jak pobrać i przywrócić kopię zapasową FTP Twojego hostingu Cloud Web.**

## W praktyce

Hosting Cloud Web dysponuje automatycznymi kopiami zapasowymi uruchomionymi z następującymi częstotliwościami:

- tego samego dnia, po 0.00.
- wczoraj, po 0:00.
- przedwczoraj, po godz. 0.00.
- poprzednia niedziela, po 01.00.

OVHcloud może zaproponować wyłącznie kopie zapasowe, o których mowa powyżej, pod warunkiem, że Twój hosting Cloud Web istnieje już w wskazanych terminach i pod warunkiem, że infrastruktura będzie dostępna w momencie tworzenia kopii zapasowej.

### Odzyskaj kopię zapasową

W przeciwieństwie do hostingu współdzielonego OVHcloud, przywracanie przestrzeni FTP nie jest możliwe za pomocą jednego kliknięcia w <ManagerLink to="/">Panelu klienta OVHcloud</ManagerLink>.

Link do pobrania kopii zapasowej jest generowany, a następnie wysyłany e-mailem na adres e-mail powiązany z identyfikatorem klienta administratora hostingu Cloud Web.

Kliknij poniższe karty, aby wyświetlić kolejne **5** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/#/web/hosting">Hosting</ManagerLink> i wybierz odpowiedni Cloud Web.

    <img className="thumbnail" alt="Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Wybierz kartę <code className="action">FTP - SSH</code> i kliknij przycisk <code className="action">Utwórz kopię zapasową</code> po prawej stronie.

    <img className="thumbnail" alt="Przycisk Utwórz kopię zapasową" src="/images/assets/screens/control-panel/product-selection/web-cloud/cloud-web/ftp-ssh/generate-a-backup.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    W oknie, które się otworzy, wybierz jedną z dostępnych kopii zapasowych, po czym kliknij <code className="action">Dalej</code>.

    <img className="thumbnail" alt="Wybór kopii zapasowej" src="/images/assets/screens/control-panel/product-selection/web-cloud/cloud-web/ftp-ssh/generate-a-backup-step-1.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 4">
    Pojawi się drugie okno z informacją, że link do pobrania pliku kopii zapasowej zostanie przesłany e-mailem i że OVHcloud nie przywróci automatycznie danych z Twojego hostingu Cloud Web.

    <img className="thumbnail" alt="Potwierdzenie generowania kopii zapasowej" src="/images/assets/screens/control-panel/product-selection/web-cloud/cloud-web/ftp-ssh/generate-a-backup-step-2.png" loading="lazy" />

    Kliknij na <code className="action">Zatwierdź</code>, aby potwierdzić zlecenie.
  </Tab>
  <Tab label="Krok 5">
    Jeśli generowanie kopii zapasowej zostało uruchomione, w Panelu klienta OVHcloud pojawi się następujący komunikat:

    <img className="thumbnail" alt="Komunikat o postępie kopii zapasowej" src="/images/assets/screens/control-panel/product-selection/web-cloud/cloud-web/ftp-ssh/message-backup-progress.png" loading="lazy" />

    Tworzenie kopii zapasowej zajmuje od 10 do 15 minut.
  </Tab>
</Tabs>

### Pobierz kopię zapasową

Po sfinalizowaniu tworzenia kopii zapasowej otrzymasz e-mail na adres e-mail powiązany z identyfikatorem administratora Twojego hostingu Cloud Web.

E-mail ten zawiera link do pobrania **ważny przez 9 dni** od otrzymania wiadomości e-mail:

<img className="thumbnail" alt="E-mail z linkiem do pobrania kopii zapasowej" src="/images/assets/screens/email-sending-to-customer/cloud-web/backup-information.png" loading="lazy" />

Pobrany plik jest w formacie *.tar.gz*.

### Przywróć kopię zapasową

Po pobraniu plików możesz [połączyć się z przestrzenią FTP](/guides/web-cloud/web-hosting/ftp-connection) przy użyciu programu FTP, takiego jak [Filezilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide), a następnie wymienić wybrane pliki na pobrane pliki.

:::info
Korzystaj z portów podanych w <ManagerLink to="/">Panelu klienta OVHcloud</ManagerLink> do połączenia SFTP i SSH, ponieważ port 22 nie będzie działał dla Twojego hostingu Cloud Web.
:::
