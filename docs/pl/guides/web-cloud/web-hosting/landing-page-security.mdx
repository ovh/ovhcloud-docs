## Zabezpieczanie hostingu

Chroń swoją stronę i jej odwiedzających: włącz szyfrowanie HTTPS za pomocą certyfikatu SSL, skonfiguruj zaporę aplikacji i stosuj najlepsze praktyki bezpieczeństwa na swoim hostingu OVHcloud. Ta strona gromadzi wszystkie przewodniki, aby zabezpieczyć Twoją stronę.

Aby znaleźć odpowiedni przewodnik dla swoich potrzeb:

- **Bezpieczeństwo strony** (najlepsze praktyki, zapora aplikacji): zacznij od sekcji *Zabezpiecz swoją stronę*.
- **Certyfikat SSL i HTTPS** (zarządzanie certyfikatem, ustawienie HTTPS): zobacz sekcję *Certyfikat SSL i HTTPS*.
- **Wybór certyfikatu SSL** (darmowy Let's Encrypt, Sectigo DV/EV, własny certyfikat): zobacz sekcję *Aktywacja certyfikatu SSL*.

## Aktywacja certyfikatu SSL

Wybierz typ certyfikatu odpowiedni dla swojej strony, a następnie postępuj zgodnie z odpowiednim przewodnikiem.

<Tabs>
  <Tab label="Let's Encrypt (darmowy)">

Darmowy certyfikat SSL dostępny z Twoim hostingiem.

[Aktywacja darmowego certyfikatu SSL Let's Encrypt](/guides/web-cloud/web-hosting/ssl-letsencrypt)

  </Tab>
  <Tab label="Sectigo DV">

Certyfikat Sectigo z walidacją domeny (Domain Validation), ważny dla jednej nazwy domeny i jej subdomeny "www".

[Aktywacja certyfikatu SSL Sectigo DV](/guides/web-cloud/web-hosting/ssl-dv)

  </Tab>
  <Tab label="Sectigo EV">

Certyfikat Sectigo z rozszerzoną walidacją (Extended Validation), ważny dla jednej nazwy domeny i jej subdomeny "www".

[Aktywacja certyfikatu SSL Sectigo EV](/guides/web-cloud/web-hosting/ssl-ev)

  </Tab>
  <Tab label="Własny">

Aby zaimportować własny certyfikat SSL, gdy żadne z rozwiązań OVHcloud nie odpowiada Twoim potrzebom.

[Instalacja spersonalizowanego certyfikatu SSL](/guides/web-cloud/web-hosting/ssl-custom)

  </Tab>
</Tabs>
