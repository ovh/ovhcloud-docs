## Wprowadzenie <a name="objective"></a>

## Wymagania początkowe

- Zarządzanie [serwerami DNS](/guides/web-cloud/domains/dns-server-general-information) i [strefą DNS](/guides/web-cloud/domains/dns-zone-general-information) Twojej domeny

[[cpnav:web-hosting-console]]

## W praktyce

Aby usunąć tę anomalię, należy:

1. określić hosting, do którego jest podłączona Twoja domena, w celu przeprowadzenia interwencji na właściwym serwerze;
2. utworzyć, aktywować lub odnowić [certyfikat SSL](/guides/web-cloud/web-hosting/ssl-on-webhosting) dla Twojej domeny na wybranym hostingu.

### 1 - Sprawdź hosting przypisany do Twojej domeny

#### Sprawdź adres IP hostingu

[Powyższe](#objective) komunikaty błędów niekoniecznie oznaczają, że Twoja strona WWW jest zainstalowana na jednym z naszych [pakietów Web Cloud](/links/web/hosting). Należy zatem sprawdzić adres IP serwera, do którego jest podłączona Twoja [nazwa domeny](/links/web/domains).

Aby odnaleźć adres IP Twojego [hostingu OVHcloud](/links/web/hosting), kliknij poniższe zakładki, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź do strony <ManagerLink to="/beta/#/web-cloud/hosting">Hosting WWW</ManagerLink>, a następnie wybierz hosting WWW.

    <img className="thumbnail" alt="Strona Hosting WWW i lista hostingów na koncie" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Hosting otworzy się na zakładce <code className="action">Przegląd</code>. W sekcji **Informacje ogólne** znajdziesz pozycje **IPv4** i **IPv6**.

    <img className="thumbnail" alt="Sekcja Informacje ogólne, adresy IPv4 i IPv6" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/ipv4-ipv6.png" loading="lazy" />

    Zapisz adres IPv4 i/lub IPv6, korzystając z przycisku kopiowania znajdującego się po prawej stronie każdego adresu, a następnie kontynuuj czytanie przewodnika.
  </Tab>
</Tabs>

#### Sprawdź adres IP w strefie DNS

Teraz sprawdź, czy adres IP podany w [strefie DNS](/guides/web-cloud/domains/dns-zone-edit) odpowiada adresowi Twojego [hostingu Web Cloud](/links/web/hosting).

Kliknij poniższe zakładki, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/domains/listing">Domeny i DNS</ManagerLink>, wybierz odpowiednią domenę, a następnie otwórz zakładkę <code className="action">Strefa DNS</code>.

    <img className="thumbnail" alt="Strona Domeny i DNS oraz lista nazw domen na koncie" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Tabela wyświetla jeden rekord DNS w każdym wierszu, w kolumnach **Subdomena**, **Typ**, **Cel** i **TTL (w sekundach)**. Aby wyświetlić tylko rekordy typu `A`, kliknij <code className="action">Filtry</code>, a następnie wybierz <code className="action">A</code> na liście **Typ rekordu**.

    <img className="thumbnail" alt="Przycisk Filtry i lista Typ rekordu strefy DNS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-type.png" loading="lazy" />

    Zapisz **Cel** rekordu typu `A` dla Twojej domeny.
  </Tab>
</Tabs>

#### Wykonaj niezbędne operacje

**Kliknij scenariusz odpowiadający Twojej sytuacji, aby wyświetlić treść.**

<details>
<summary>Adres IP odpowiada adresowi IP Twojego hostingu</summary>

Adres IP podany w [strefie DNS](/guides/web-cloud/domains/dns-zone-edit) odpowiada adresowi IP Twojego hostingu. Przejdź do [części 2](#step2).

</details>

<details>
<summary>Adres IP nie dotyczy żadnego hostingu z Twojego konta, ale pojawia się w liście serwerów Web Cloud</summary>

Adres IP wskazany w strefie nie dotyczy hostingu na Twoim <ManagerLink to="/">koncie OVHcloud</ManagerLink>, ale pojawia się w [liście serwerów Web Cloud](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip).

Sprawdź, czy nie posiadasz hostingu z tym adresem IP na jednym z pozostałych <ManagerLink to="/">kont OVHcloud</ManagerLink>, jeśli utworzyłeś kilka z nich. W razie potrzeby skontaktuj się z webmasterem lub [partnerami OVHcloud](/links/partner) w tej sprawie.

</details>

<details>
<summary>Adres IP nie jest adresem Twojego hostingu i nie pojawia się w liście serwerów Web Cloud</summary>

Adres IP wskazany w strefie nie jest adresem Twojego hostingu i nie pojawia się również w [liście serwerów Web Cloud](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip).

Skontaktuj się ze swoim webmasterem lub [partnerami OVHcloud](/links/partner) w tym zakresie.

</details>

<details>
<summary>Twoja domena używa innych serwerów DNS OVHcloud (ns?.ovh.net / dns?.ovh.net)</summary>

Nad strefą DNS w Twojej konsoli OVHcloud wyświetla się ostrzeżenie „**Ta strefa DNS nie jest autorytatywna dla Twojej domeny.**”: Twoja domena używa innych serwerów [DNS](/guides/web-cloud/domains/dns-zone-edit), a zmiany wprowadzone w tej strefie nie są uwzględniane.

Aby sprawdzić, których serwerów DNS używa Twoja domena, otwórz zakładkę <code className="action">Przegląd</code> domeny i sprawdź sekcję **Konfiguracja DNS**: wyświetla je lista **Serwery DNS obsługujące strefę**. Jeśli mają one postać „ns **?** .ovh.net” lub „dns **?** .ovh.net” („**?**” oznacza numer danego serwera DNS), są to inne serwery DNS OVHcloud.

<img className="thumbnail" alt="Sekcja Konfiguracja DNS z konfiguracją i listą serwerów DNS obsługujących strefę" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/dns-servers-ovhcloud.png" loading="lazy" />

Zmień serwery DNS domeny, aby odpowiadały one tym, które są zapisane w rekordach typu `NS` strefy. Aby wykonać tę operację, postępuj zgodnie z instrukcjami z [tego przewodnika](/guides/web-cloud/domains/dns-server-edit).

{/* v8-review: TO DOCUMENT — the « This DNS zone is not authoritative for your domain name. » banner was not seen live (no domain on the test account uses servers other than its zone's); its wording comes from ZoneBanners.tsx and zone.json. Unlike v6, it does not list the DNS servers in use, hence the pointer to the Overview « DNS servers » section. */}

</details>

<details>
<summary>Twoja domena używa zewnętrznych serwerów DNS (nie OVHcloud)</summary>

Nad strefą DNS w Twojej konsoli OVHcloud wyświetla się to samo ostrzeżenie „**Ta strefa DNS nie jest autorytatywna dla Twojej domeny.**”. W sekcji **Konfiguracja DNS** zakładki <code className="action">Przegląd</code> domeny wiersz **Konfiguracja** wskazuje **Niestandardowa**, a wymienione serwery DNS nie mają postaci „ns **?** .ovh.net” ani „dns **?** .ovh.net”.

Skontaktuj się z webmasterem lub [partnerami OVHcloud](/links/partner) w tym zakresie.

</details>

<details>
<summary>Twoja domena nie wyświetla się w Twojej konsoli OVHcloud</summary>

Twoja domena nie pojawia się na stronie <ManagerLink to="/beta/#/web-cloud/domains/listing">Domeny i DNS</ManagerLink> w Twojej konsoli OVHcloud.

Oznacza to, że Twoja domena nie jest zarządzana z poziomu Twojej konsoli OVHcloud.

Sprawdź, czy domena nie jest zarządzana z poziomu jednego z Twoich pozostałych <ManagerLink to="/">kont OVHcloud</ManagerLink>, jeśli utworzyłeś kilka z nich.

Możesz również wskazać jej operatora oraz serwery DNS, z którymi jest powiązana, za pomocą naszego narzędzia [WHOIS](/links/web/domains-whois).

W razie potrzeby skontaktuj się z webmasterem lub [partnerami OVHcloud](/links/partner) w tym zakresie.

</details>

### 2 - Sprawdź certyfikat SSL na Twoim hostingu <a name="step2"></a>

Kliknij poniższe zakładki, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź do strony <ManagerLink to="/beta/#/web-cloud/hosting">Hosting WWW</ManagerLink>, a następnie wybierz hosting WWW.

    <img className="thumbnail" alt="Strona Hosting WWW i lista hostingów na koncie" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij zakładkę <code className="action">SSL</code>.

    <img className="thumbnail" alt="Zakładka SSL hostingu WWW" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates.png" loading="lazy" />

    Odszukaj swoją domenę w kolumnie **Domena główna**, a następnie sprawdź jej kolumnę **Status**. Jeśli Twoja domena nie pojawia się w tabeli, Twój hosting nie zawiera certyfikatu SSL dla tej domeny.

    <img className="thumbnail" alt="Tabela certyfikatów SSL i jej kolumna Status" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/tab.png" loading="lazy" />
  </Tab>
</Tabs>

#### Scenariusz 1: Twój hosting nie zawiera certyfikatu SSL

Włącz [certyfikat SSL](/links/web/hosting-options-ssl) na Twoim hostingu postępując zgodnie z instrukcjami zawartymi w tym [przewodniku](/guides/web-cloud/web-hosting/ssl-on-webhosting).

#### Scenariusz 2: certyfikat SSL nie działa

Jeśli wygenerowałeś **certyfikat SSL "Let's Encrypt"**, aktywuj opcję SSL dla swojego hostingu, postępując zgodnie z instrukcjami w [tym przewodniku](/guides/web-cloud/web-hosting/ssl-on-webhosting).

Jeśli posiadasz importowany **certyfikat SSL** i certyfikat ten nie działa, skontaktuj się z dostawcą.

Jeśli zamówiłeś jeden z płatnych **certyfikatów SSL** od naszego partnera [SECTIGO](https://sectigo.com/), sprawdź, czy otrzymałeś wiadomość e-mail z propozycją odnowienia certyfikatu.
<br/>W razie potrzeby skontaktuj się z [pomocą SECTIGO](https://sectigo.com/support) w tej sprawie.
