## W praktyce

Aby usunąć tę anomalię, należy:

1. określić hosting, do którego jest podłączona Twoja domena, w celu przeprowadzenia interwencji na właściwym serwerze;
2. utworzyć, aktywować lub odnowić [certyfikat SSL](/guides/web-cloud/web-hosting/ssl-on-webhosting) dla Twojej domeny na wybranym hostingu.

### 1 - Sprawdź hosting przypisany do Twojej domeny

#### Sprawdź adres IP hostingu

[Powyższe](#objective) komunikaty błędów niekoniecznie oznaczają, że Twoja strona WWW jest zainstalowana na jednym z naszych [pakietów Web Cloud](/links/web/hosting). Należy zatem sprawdzić adres IP serwera, do którego jest podłączona Twoja [nazwa domeny](/links/web/domains).

Aby odnaleźć adres IP Twojego [hostingu OVHcloud](/links/web/hosting), kliknij poniższe zakładki, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/#/web/hosting">Hosting</ManagerLink>, następnie wybierz odpowiedni hosting.

    <img className="thumbnail" alt="Strona Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    W ramce **Informacje ogólne** znajdziesz oznaczenia **IPv4** i **IPv6**.

    <img className="thumbnail" alt="Adresy IPv4 i IPv6" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-ipv4-and-ipv6.png" loading="lazy" />

    Zapisz adres IPv4 i/lub IPv6, a następnie kontynuuj czytanie przewodnika.
  </Tab>
</Tabs>

#### Sprawdź adres IP w strefie DNS

Teraz sprawdź, czy adres IP podany w [strefie DNS](/guides/web-cloud/domains/dns-zone-edit) odpowiada adresowi Twojego [hostingu Web Cloud](/links/web/hosting).

Kliknij poniższe zakładki, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    W sekcji `Web Cloud` kliknij <ManagerLink to="/#/web-domains/domain">Domeny</ManagerLink>, wybierz odpowiednią nazwę domeny, następnie otwórz zakładkę **Strefa DNS**.

  </Tab>
  <Tab label="Krok 2">
    Zapisz docelowy wpis typu `A` dla Twojej domeny:

    <img className="thumbnail" alt="Strefa DNS filtrowana według rekordów A" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-a.png" loading="lazy" />
  </Tab>
</Tabs>

#### Wykonaj niezbędne operacje

**Kliknij scenariusz odpowiadający Twojej sytuacji, aby wyświetlić treść.**

<details>
<summary>Adres IP odpowiada adresowi IP Twojego hostingu</summary>

Adres IP podany w [strefie DNS](/guides/web-cloud/domains/dns-zone-edit) odpowiada adresowi IP Twojego hostingu. Przejdź do [części 2](#step2).

</details>

<details>
<summary>Adres IP nie dotyczy żadnego hostingu z Twojego konta, ale pojawia się w liście serwerów Web Cloud</summary>

Adres IP wskazany w strefie nie dotyczy hostingu na Twoim <ManagerLink to="/">koncie OVHcloud</ManagerLink>, ale pojawia się w [liście serwerów Web Cloud](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip).

Sprawdź, czy nie posiadasz hostingu z tym adresem IP na jednym z pozostałych <ManagerLink to="/">kont OVHcloud</ManagerLink>, jeśli utworzyłeś kilka z nich. W razie potrzeby skontaktuj się z webmasterem lub [partnerami OVHcloud](/links/partner) w tej sprawie.

</details>

<details>
<summary>Adres IP nie jest adresem Twojego hostingu i nie pojawia się w liście serwerów Web Cloud</summary>

Adres IP wskazany w strefie nie jest adresem Twojego hostingu i nie pojawia się również w [liście serwerów Web Cloud](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip).

Skontaktuj się ze swoim webmasterem lub [partnerami OVHcloud](/links/partner) w tym zakresie.

</details>

<details>
<summary>Twoja domena używa innych serwerów DNS OVHcloud (ns?.ovh.net / dns?.ovh.net)</summary>

Powyżej strefy DNS w Panelu klienta OVHcloud komunikat wskazuje, że Twoja domena używa innych serwerów [DNS](/guides/web-cloud/domains/dns-zone-edit) i wyświetlają się one w formie "ns **?** .ovh.net" lub "dns **?** .ovh.net" (zastąp "**?**" odpowiednim numerem serwera DNS):

<img className="thumbnail" alt="warning_other_ovh_dns_srv" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/message-other-ovh-dns-servers.png" loading="lazy" />

Zmień serwery DNS domeny, aby odpowiadały one tym, które są zapisane w rekordach typu `NS` strefy. Aby wykonać tę operację, postępuj zgodnie z instrukcjami z [tego przewodnika](/guides/web-cloud/domains/dns-server-edit).

</details>

<details>
<summary>Twoja domena używa zewnętrznych serwerów DNS (nie OVHcloud)</summary>

Powyżej strefy DNS w Panelu klienta OVHcloud komunikat wskazuje, że Twoja domena używa innych serwerów [DNS](/guides/web-cloud/domains/dns-zone-edit), a te nie wyświetlają się w formie "ns **?** .ovh.net" lub "dns **?** .ovh.net":

<img className="thumbnail" alt="warning_external_dns_srv" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/message-external-dns-servers.png" loading="lazy" />

Skontaktuj się z webmasterem lub [partnerami OVHcloud](/links/partner) w tym zakresie.

</details>

<details>
<summary>Twoja domena nie wyświetla się w Panelu klienta OVHcloud</summary>

Twoja domena nie pojawia się na stronie <ManagerLink to="/#/web-domains/domain">Domeny</ManagerLink> w Panelu klienta OVHcloud.

Oznacza to, że Twoja domena nie jest zarządzana z poziomu <ManagerLink to="/">Panelu klienta OVHcloud</ManagerLink>.

Sprawdź, czy domena nie jest zarządzana z poziomu jednego z Twoich pozostałych <ManagerLink to="/">kont OVHcloud</ManagerLink>, jeśli utworzyłeś kilka z nich.

Możesz również wskazać jej operatora oraz serwery DNS, z którymi jest powiązana, za pomocą naszego narzędzia [WHOIS](/links/web/domains-whois).

W razie potrzeby skontaktuj się z webmasterem lub [partnerami OVHcloud](/links/partner) w tym zakresie.

</details>

### 2 - Sprawdź certyfikat SSL na Twoim hostingu <a name="step2"></a>

Kliknij poniższe zakładki, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/#/web/hosting">Hosting</ManagerLink>, następnie wybierz odpowiedni hosting.

    <img className="thumbnail" alt="Strona Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    W zakładce <code className="action">Informacje ogólne</code> sprawdź sekcję `Certyfikat SSL`:

    <img className="thumbnail" alt="Certyfikat SSL w zakładce informacji ogólnych" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/no-ssl-certificate.png" loading="lazy" />
  </Tab>
</Tabs>

#### Scenariusz 1: Twój hosting nie zawiera certyfikatu SSL

Włącz [certyfikat SSL](/links/web/hosting-options-ssl) na Twoim hostingu postępując zgodnie z instrukcjami zawartymi w tym [przewodniku](/guides/web-cloud/web-hosting/ssl-on-webhosting).

#### Scenariusz 2: certyfikat SSL nie działa

Jeśli wygenerowałeś **certyfikat SSL "Let's Encrypt"**, aktywuj opcję SSL dla swojego hostingu, postępując zgodnie z instrukcjami w [tym przewodniku](/guides/web-cloud/web-hosting/ssl-on-webhosting).

Jeśli posiadasz importowany **certyfikat SSL** i certyfikat ten nie działa, skontaktuj się z dostawcą.

Jeśli zamówiłeś jeden z płatnych **certyfikatów SSL** od naszego partnera [SECTIGO](https://sectigo.com/), sprawdź, czy otrzymałeś wiadomość e-mail z propozycją odnowienia certyfikatu.
<br/>W razie potrzeby skontaktuj się z [pomocą SECTIGO](https://sectigo.com/support) w tej sprawie.
