## Dostęp do hostingu przez FTP, SFTP i SSH

Przesyłaj pliki i zarządzaj swoim hostingiem OVHcloud za pomocą protokołów FTP, SFTP i SSH. Ta strona gromadzi przewodniki, aby połączyć się za pomocą klienta (FileZilla, Cyberduck, Visual Studio Code), zarządzać dostępami FTP i łączyć się przez SSH, za pomocą PuTTY lub bezpośrednio z wiersza poleceń.

Aby znaleźć odpowiedni przewodnik dla swoich potrzeb:

- **Chcesz przesłać pliki na swój hosting?** Zobacz sekcję *Połączenie przez FTP/SFTP* (FileZilla, Cyberduck, Visual Studio Code).
- **Chcesz zarządzać użytkownikami i hasłami FTP?** Zobacz sekcję *Zarządzanie dostępami FTP* (użytkownicy, hasła, SFTP).
- **Pracujesz w wierszu poleceń?** Zobacz sekcję *Dostęp SSH i narzędzia wiersza poleceń* (SSH, PuTTY, SCP, SVN).
