## Instalacja CMS na Twoim hostingu

CMS (Content Management System, system zarządzania treścią) to oprogramowanie, które umożliwia tworzenie strony internetowej i zarządzanie nią bez kodowania, z poziomu interfejsu administracyjnego.

Zainstaluj wybrany CMS na swoim hostingu OVHcloud. Ta strona gromadzi przewodniki dotyczące ręcznej instalacji najpopularniejszych systemów CMS (WordPress, Joomla, PrestaShop, Drupal i inne), lub instalację modułu jednym kliknięciem bezpośrednio z Panelu klienta OVHcloud.

Aby znaleźć odpowiedni przewodnik dla swoich potrzeb:

- **Zamierzasz zainstalować CMS dla swojej strony?** Zobacz sekcję *Jak zainstalować CMS*.
- **Chcesz zainstalować jeden z najpopularniejszych systemów CMS (WordPress, Joomla, PrestaShop, Drupal)?** Zobacz sekcję *Najpopularniejsze systemy CMS*.
- **Szukasz innego systemu CMS (Grav, Pico, Typo3, SPIP)?** Zobacz sekcję *Inne systemy CMS*.
