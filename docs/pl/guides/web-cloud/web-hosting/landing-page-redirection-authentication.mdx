## Przekierowania i uwierzytelnianie za pomocą pliku .htaccess

Plik `.htaccess` umożliwia kontrolowanie dostępu do Twojej witryny oraz przekierowywanie lub przepisywanie jej adresów URL, bezpośrednio na Twoim hostingu OVHcloud. Ta strona gromadzi przewodniki dotyczące zabezpieczania dostępu (hasło, blokowanie adresów IP), przepisywania adresów URL oraz wykorzystania innych możliwości pliku `.htaccess`.
