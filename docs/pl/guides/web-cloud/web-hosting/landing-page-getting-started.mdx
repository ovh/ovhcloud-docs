## Pierwsze kroki z hostingiem internetowym

Masz właśnie wykupiony hosting internetowy OVHcloud? Ta strona gromadzi przewodniki ułatwiające rozpoczęcie pracy: aktywuj ofertę, utwórz i opublikuj swoją pierwszą witrynę, aktywuj dołączone adresy e-mail, a następnie znajdź najważniejsze informacje o swoim hostingu. Aby skonfigurować hosting bardziej szczegółowo, zapoznaj się ze stroną Konfiguracja.

Aby znaleźć to, czego potrzebujesz:

- **Dopiero zaczynasz i chcesz utworzyć, a następnie opublikować swoją witrynę?** Zapoznaj się z sekcjami *Pierwsze kroki* i *Publikowanie i zarządzanie witrynami*.
- **Chcesz aktywować dołączone adresy e-mail lub zarządzać witrynami z poziomu Panelu klienta?** Zapoznaj się z sekcją *Publikowanie i zarządzanie witrynami*.
- **Szukasz informacji technicznych o swoim hostingu (oferta, klaster)?** Zapoznaj się z sekcją *Poznaj swój hosting*.
