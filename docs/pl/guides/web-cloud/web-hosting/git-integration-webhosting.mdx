## Wprowadzenie

W dzisiejszym świecie cyfrowym społeczeństwa stają się coraz bardziej dynamiczne i innowacyjne. Zdolność skutecznego zarządzania i wdrażania kodu strony WWW jest kluczowa dla utrzymania konkurencyjności i rentowności Twojej marki. Git, najpopularniejszy na świecie system zarządzania wersjami, pozwala na przechowywanie kodu strony internetowej na platformach takich jak GitHub, umożliwiając lepsze śledzenie zmian, a także szybszą automatyzację i wdrożenia. Jeśli jesteś klientem OVHcloud, dysponujesz solidną infrastrukturą do hostowania strony WWW, przy jednoczesnym wykorzystaniu zalet Git i GitHub do rozwoju i skalowania strony WWW.

**Dowiedz się, jak skonfigurować Git i korzystać z niego w ramach Twojego hostingu w Panelu klienta OVHcloud.**

:::info
Ta procedura dotyczy <ManagerLink to="/beta/#/">nowej wersji Panelu klienta OVHcloud</ManagerLink>, obecnie dostępnej w wersji beta. Aby ją wykonać, przełącz się na ten interfejs z poziomu swojego zwykłego Panelu klienta.

:::

#### Ustaw repozytorium GitHub

Wprowadź adres Twojego repozytorium GitHub. Jeśli nie masz jeszcze repozytorium GitHub dla swojego projektu, utwórz je.

Aby utworzyć nowe repozytorium:

- Zaloguj się do swojego konta GitHub.
- Kliknij na Twój obraz profilu w prawym górnym rogu, a następnie <code className="action">Your repositories</code>.
- Kliknij <code className="action">New</code> po prawej stronie ekranu, który się wyświetli.

Nadaj nazwę repozytorium i podaj wymagane informacje.

:::warning
Zaznacz opcję `Add a README file`, aby GitHub poprawnie zainicjował repozytorium.

:::

Na koniec kliknij przycisk <code className="action">Create Repository</code>.

Skopiuj adres repozytorium GitHub. Musi mieć formę:

- `https://github.com/<username>/<repository_name>.git` w repozytorium publicznym.
- `git@github.com:<username>/<repository_name>.git` w prywatnym repozytorium.

Wróć do formularza kojarzenia Git i wklej adres Twojego repozytorium GitHub w polu <code className="action">Repozytorium</code>. Jeśli adres ma niepoprawny format, wyświetlany jest następujący komunikat o błędzie:

<img className="thumbnail" alt="My websites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/error-wrong-git-branch-name.png" loading="lazy" />

Teraz zdefiniuj gałąź repozytorium GitHub. Domyślną gałęzią jest `main`, ale jeśli chcesz użyć innej gałęzi, utwórz ją w GitHubie wykonując poniższe kroki:

- Zaloguj się do swojego konta GitHub.
- Kliknij na Twój obraz profilu w prawym górnym rogu, a następnie <code className="action">Your repositories</code>.
- Przejdź do odpowiedniego repozytorium GitHub.
- Kliknij na <code className="action">Main</code>, następnie <code className="action">View all branches</code>, lub kliknij bezpośrednio na zakładkę <code className="action">x Branch</code>.
- Po prawej stronie ekranu, który się wyświetli kliknij <code className="action">New branch</code>.
- Nadaj nazwę nowej gałęzi i potwierdź, klikając na <code className="action">Create new branch</code>.

Powróć do formularza stowarzyszenia Git w Panelu klienta OVHcloud i podaj nazwę nowo utworzonej gałęzi.

Jeśli wprowadzasz adres prywatnego repozytorium w serwisie GitHub (typu `git@github.com:<username>/<repository_name>.git`), pod polem `Branch` wyświetli się pole `SSH key` (klucz SSH).

<img className="thumbnail" alt="My websites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/field-ssh-key.png" loading="lazy" />

Aby skonfigurować klucz SSH, zapoznaj się z etapem "Przypisanie klucza SSH do GitHuba (tylko w przypadku prywatnych repozytoriów GitHub)" poniżej.

#### Przypisz klucz SSH do GitHuba (tylko w przypadku prywatnych repozytoriów GitHub) <a name="linkSSHKey"></a>

:::info
**Dlaczego klucz SSH jest wymagany tylko w przypadku rejestracji prywatnej?**

Gdy repozytorium GitHub jest publiczne, pliki mogą być odzyskiwane bez uwierzytelniania, co oznacza, że Git może klonować i aktualizować kod bez potrzeby posiadania klucza SSH. Jeśli repozytorium jest prywatne, GitHub wymaga uwierzytelnienia, aby uzyskać do niego dostęp. Klucz SSH pozwala następnie na nawiązanie bezpiecznego połączenia i gwarantuje, że tylko autoryzowani użytkownicy mogą wchodzić w interakcje z repozytorium.

:::

:::info
Wygenerowanie klucza SSH jest kluczowym etapem, ponieważ ustanawia bezpieczne, zaszyfrowane połączenie między katalogiem Twojej strony WWW i repozytorium GitHub. Klucz ten gwarantuje, że transfer danych oraz modyfikacje kodu są realizowane w bezpieczny i uwierzytelniony sposób, zapobiegając nieautoryzowanemu dostępowi oraz zapewniając integralność kodu.

:::

Skopiuj klucz SSH, klikając przycisk po prawej stronie.

<img className="thumbnail" alt="My websites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/field-ssh-key-copy.png" loading="lazy" />

Zapisz klucz SSH na koncie GitHub:

- Zaloguj się do swojego konta GitHub.
- Kliknij na Twój obraz profilu w prawym górnym rogu, a następnie <code className="action">Settings</code>.
- Na nowej stronie kliknij <code className="action">SSH and GPG keys</code> w kolumnie po lewej stronie.
- Wybierz <code className="action">New SSH key</code> lub <code className="action">Add SSH key</code>.

Zostanie wyświetlony formularz dodawania nowego klucza SSH:

- **Title**: dodaj opis dla Twojego klucza SSH. Na przykład możesz nazwać ten klucz "OVHcloud".
- **Type of key**: pozostaw wartość domyślną <code className="action">authentication key</code>
- **Key**: wklej klucz SSH.

Aby zatwierdzić informacje, kliknij <code className="action">Add SSH key</code>. Jeśli zostanie wyświetlony monit, potwierdź dostęp do konta w GitHub.

#### Skonfiguruj automatyczne wdrażanie

W dolnej części formularza kojarzenia Git, wyświetla się sekcja <code className="action">Skonfiguruj automatyczne wdrożenie</code> wraz z adresem URL elementu webhook. Konfiguracja interfejsu webhook pozwala repozytorium GitHub na automatyczne powiadamianie hostingu OVHcloud o zdarzeniach, które mają miejsce w repozytorium GitHub (nowe wdrożenie, zmiana kodu, itp.). Funkcja ta jest szczególnie przydatna, jeśli pracujesz w grupie nad tym samym projektem i chcesz być na bieżąco ze wszystkimi zmianami w repozytorium GitHub. Aby dowiedzieć się więcej, sprawdź, jak [skonfigurować webhook na GitHubie](#configureWebhook).

#### Zatwierdź powiązanie Git

Przed zatwierdzeniem formularza skojarzenia Git, upewnij się, że:

- Twój klucz SSH został zarejestrowany na koncie GitHub.
- Adres repozytorium GitHub jest poprawny. Musi mieć formę `https://github.com/<username>/<repository_name>.git`.
- Nazwa gałęzi repozytorium GitHub jest poprawna.
- Twój katalog instalacyjny jest pusty.

Aby zatwierdzić informacje zawarte w formularzu powiązania Git, kliknij przycisk <code className="action">Zastosuj konfigurację</code>.

### Aktywacja powiązania Git

#### Sukces w powiązaniu z Git

Po potwierdzeniu formularza powiązania Git zostaniesz przekierowany na stronę karty <code className="action">Moje strony</code>.

<img className="thumbnail" alt="My websites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/git-activation-ongoing.png" loading="lazy" />

Zielony baner informuje, że Git jest aktywowany. Śledź aktywację Git, klikając link <code className="action">Zadania w trakcie</code>.

<img className="thumbnail" alt="My websites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/ongoing-tasks/ongoing-task-git-activation.png" loading="lazy" />

Status <code className="action">W realizacji</code> wskazuje, że trwa przypisywanie do Git. Proces może potrwać kilka minut. Po wykonaniu zadania pojawia się status <code className="action">Włączony</code>.

Możesz również śledzić postęp aktywacji Git w karcie <code className="action">Moje strony</code>. W kolumnie <code className="action">Git</code> tabeli, wpis <code className="action">W realizacji</code> na linii odpowiedniego strony internetowej informuje, że Git jest w trakcie aktywacji.

Gdy powiązanie Git zostanie wykonane, status <code className="action">Aktywny</code> pojawi się w kolumnie <code className="action">Git</code> dla odpowiedniego strony internetowej.

<img className="thumbnail" alt="My websites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/success-git-activation.png" loading="lazy" />

#### Błędy skojarzenia Git

W tabeli karty <code className="action">Moje strony</code> zidentyfikuj wiersze odpowiadające katalogowi strony internetowej, którą chcesz powiązać z Git. W kolumnie `Git`, jeśli pojawi się wpis `Błąd`, oznacza to, że wystąpiła co najmniej jedna z poniższych błędów:

- Klucz SSH nie został zapisany na Twoim koncie GitHub.
- Katalog instalacyjny nie jest pusty.
- Adres repozytorium GitHub nie istnieje lub jest nieprawidłowy.
- Gałąź repozytorium GitHub nie istnieje lub jej nazwa jest nieprawidłowa.

Aby dowiedzieć się, jaki dokładnie błąd wystąpił, sprawdź informacje ostatniego wdrożenia. W tabeli kliknij przycisk <code className="action">⁝</code> po prawej stronie odpowiedniego strony internetowej, a następnie <code className="action">Informacje o ostatnim wdrożeniu</code>.

<img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/website-options-git-enabled.png" loading="lazy" />

Po zidentyfikowaniu błędu(-ów), ponownie powiąż Git. Powtórz operację, klikając przycisk <code className="action">⁝</code> po prawej stronie odpowiedniego strony internetowej, a następnie <code className="action">Powiąż Git</code>.

#### Skonfiguruj webhook <a name="configureWebhook"></a>

Zaloguj się na swoje konto GitHub i przejdź do repozytorium, w którym chcesz skonfigurować webhook. Przejdź do zakładki <code className="action">Settings</code>, a następnie w bocznym menu ustawień kliknij <code className="action">Webhooks</code>. Kliknij przycisk <code className="action">Add webhook</code>, aby przejść do formularza:

- **Payload URL**: wprowadź adres URL podany w formularzu powiązania Git (<code className="action">URL webhooka</code>).
- **Content type**: wybierz <code className="action">application/json</code> jako typ treści dla przesłanych danych.
- **Secret**: klucz jest opcjonalny. GitHub będzie go używać do podpisywania wiadomości wysyłanych przez webhook, zwiększając tym samym bezpieczeństwo.
- **SSL verification**: jeśli Twoja strona WWW używa protokołu HTTPS, pozostaw tę opcję włączoną, aby zwiększyć bezpieczeństwo.
- **Which events would you like to trigger this webhook?**: wybierz zdarzenia, które spowodują wysłanie funkcji webhook. W przypadku wdrożenia automatycznego, <code className="action">Just the push event</code> (Just the push event) jest często wystarczające, ale możesz wybrać <code className="action">Send me everything</code>, aby otrzymywać powiadomienia o wszystkich zdarzeniach.
- **Active**: upewnij się, że zaznaczone jest pole wyboru pozwalające na aktywację elementu webhook.

Kliknij przycisk <code className="action">Add webhook</code>, aby zarejestrować i aktywować nowy webhook.

#### Przetestuj Twój webhook

Po utworzeniu elementu webhook w GitHubie przejdź do listy elementów webhook i wybierz ten, który właśnie utworzyłeś, lub kliknij na <code className="action">Edit</code>.

Na wyświetlonym ekranie kliknij zakładkę <code className="action">Recent Deliveries</code>. Aby wysłać zdarzenie testowe specjalnie, GitHub zazwyczaj wysyła zdarzenie `ping` podczas tworzenia elementu webhook, a do przetestowania tego zdarzenia możesz użyć przycisku <code className="action">Redeliver</code> obok tego zdarzenia.

Jeśli test się powiódł, zakładka <code className="action">Response</code> zwraca kod 200. Jeśli kod błędu zostanie zwrócony (zazwyczaj 500 lub 400), oznacza to, że webhook został nieprawidłowo skonfigurowany. Wróć do formularza dodawania elementu webhook i sprawdź informacje, a w szczególności adres URL elementu webhook dostarczony przez OVHcloud.

#### Korzystanie z funkcji webhook

Po skonfigurowaniu elementu webhook kod Twojej strony WWW będzie aktualizowany automatycznie za każdym razem, gdy pojawią się zmiany w repozytorium GitHub. Na przykład jeśli w repozytorium GitHub jedna ze współpracowników wprowadzi zmiany, kod Twojej strony WWW zostanie zaktualizowany lokalnie (na Twoim hostingu OVHcloud).

### Zakończenie

Powiązałeś kod Twojej strony WWW z Git za pomocą repozytorium GitHub. Możesz teraz wdrożyć zmiany w repozytorium GitHub na Twoim hostingu lub wdrożyć je automatycznie za pomocą interfejsu webhook, sprawdzić logi wdrożeń i wykonywać wiele operacji - wszystko to za pomocą kilku kliknięć w Panelu klienta.
