## Wprowadzenie

Dostępne wersje Informacje zawarte w tym przewodniku dotyczą wersji **PHP**, **Python**, **Perl** i **Apache*** używanych w ramach usług [Web Hosting](/links/web/hosting) dostępnych w sieci Web Hosting.

**Poznaj szczegóły wersji PHP, Python, Perl i Apache.**

## Wymagania początkowe

- Posiadanie [hostingu OVHcloud](/links/web/hosting).

## W praktyce

Poniższe tabele przedstawiają wersje języków programowania dostępne w ofertach hostingu OVHcloud oraz ich status. Każda wersja prowadzi do swojej strony informacyjnej, na której podano pełny numer wersji i konfigurację.

### Status wersji

<span style={{backgroundColor:"#198754", color:"white", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Wspierana</span>: wersja utrzymywana na hostingach OVHcloud.
