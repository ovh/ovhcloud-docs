## Konfiguracja Twojego hostingu

Skonfiguruj wszystkie aspekty swojego hostingu OVHcloud: hostuj wiele witryn, zarządzaj środowiskiem i wersją PHP, aktywuj dołączone adresy e-mail, optymalizuj wydajność i CDN, monitoruj logi, wdrażaj (Git, CRON, API) i rozwijaj swoją ofertę. Bazy danych, dostęp FTP/SSH, CMS i bezpieczeństwo mają ponadto własną dedykowaną stronę.

Aby znaleźć odpowiedni przewodnik dla swoich potrzeb:

- **Chcesz skonfigurować swoje witryny, przypisać nazwy domen lub przygotować środowisko (PHP, IPv6)?** Zobacz sekcję *Witryny, nazwa domeny i środowisko*.
- **Chcesz poprawić wydajność swoich usług lub monitorować logi (CDN, statystyki)?** Zobacz sekcję *Wydajność, CDN i logi*.
- **Musisz wdrażać, automatyzować (Git, CRON, API) lub rozwijać swoją ofertę?** Zobacz sekcję *Wdrażanie, automatyzacja i oferta*.
