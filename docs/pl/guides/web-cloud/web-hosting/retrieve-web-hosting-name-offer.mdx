## Wprowadzenie

Nie pamiętasz nazwy swojej [oferty hostingu](/links/web/hosting)?
Chcesz sprawdzić jej szczegóły lub porównać ją z inną ofertą?

W trakcie korzystania z usług może się zdarzyć, że będziesz potrzebował nazwy swojej oferty hostingu.

**Dowiedz się, jak zidentyfikować typ oferty hostingu, którą aktualnie posiadasz w konsoli OVHcloud.**

## Wymagania początkowe

- Posiadanie [oferty hostingu](/links/web/hosting).

[[cpnav:web-hosting-console]]

## W praktyce

Kliknij poniższe zakładki, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź do strony <ManagerLink to="/beta/#/web-cloud/hosting">Hosting WWW</ManagerLink>, a następnie wybierz hosting WWW.

    <img className="thumbnail" alt="Strona Hosting WWW i lista hostingów na koncie" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    W zakładce <code className="action">Przegląd</code> znajdź sekcję **Subskrypcja**. Nazwa oferty hostingu WWW jest wyświetlana pod pozycją **Oferta** (na przykład: Perso, Pro, Performance).

    <img className="thumbnail" alt="Sekcja Subskrypcja i nazwa oferty pod pozycją Oferta" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/subscription-card.png" loading="lazy" />
  </Tab>
</Tabs>
