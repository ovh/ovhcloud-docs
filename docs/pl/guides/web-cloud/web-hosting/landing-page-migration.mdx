## Migracja witryny do OVHcloud

Migruj swoją witrynę i jej dane na swój hosting OVHcloud. Ta strona gromadzi przewodniki, aby zmigrować całą witrynę do OVHcloud, eksportować i importować dane (pliki i bazę danych) oraz obsłużyć powiązane przypadki, takie jak zmiana domeny.

Aby znaleźć odpowiedni przewodnik dla swoich potrzeb:

- **Chcesz zmigrować całą witrynę, WordPress lub Xara?** Zobacz sekcję *Migracja witryny do OVHcloud*.
- **Chcesz wyeksportować lub zaimportować swoją witrynę i bazy danych?** Zobacz sekcję *Eksport i import danych*.
- **Chcesz przeprowadzić migrację na VPS, zmienić domenę lub przejść z MySQL na Percona?** Zobacz sekcję *Inne migracje*.
