## Wprowadzenie

Oferty OVHcloud Web Hosting dają dostęp do przestrzeni dyskowej, w której można udostępnić pliki swoich stron internetowych lub aplikacji. Dostęp do tej przestrzeni możliwy jest za pomocą użytkownika FTP lub SSH oraz hasła do niego przypisanego.

Podobnie jak **F**ile **T**ransfer **P**rotocol (**FTP**), **S**ecure **F**ile **T**ransfer **P**rotocol (**SFTP**) umożliwia przesyłanie danych z Twojego urządzenia do przestrzeni dyskowej Twojego Web Hostinga.

Jedyną różnicą jest to, że SFTP korzysta z bezpiecznego kanału komunikacji. Dane przesyłane za pomocą tego protokołu są automatycznie szyfrowane.

**Dowiedz się, jak włączyć dostęp SFTP na swoim OVHcloud Web Hosting.**

## Wymagania początkowe

- Posiadanie jednej z ofert [OVHcloud Web Hosting](/links/web/hosting).

## W praktyce

### Włączenie dostępu SFTP dla użytkownika FTP na Twoim Web Hostingu

Kliknij poniższe zakładki, aby kolejno wyświetlić każdy z **4** etapów.

<Tabs>
  <Tab label="Krok 1">
    Przejdź do strony <ManagerLink to="/beta/#/web-cloud/hosting">Hosting WWW</ManagerLink>, a następnie wybierz hosting WWW.

    <img className="thumbnail" alt="Strona Hosting WWW i lista hostingów na koncie" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij zakładkę <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Zakładka FTP-SSH hostingu WWW" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    W sekcji **Użytkownicy FTP i SSH** sprawdź stan wyświetlany w kolumnie **SFTP** dla wybranego użytkownika FTP:

    - **Włączony**: protokół SFTP jest już aktywny dla tego użytkownika, nie musisz nic robić.
    - **Wyłączony**: w kolumnie **Akcje** kliknij przycisk <code className="action">⋮</code> po prawej stronie odpowiedniego wiersza, a następnie <code className="action">Edytuj</code>.

    <img className="thumbnail" alt="Tabela użytkowników FTP i stan protokołu SFTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/ftp-users-sftp-status.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 4">
    Po prawej stronie otworzy się panel **Edytuj użytkownika**. W menu rozwijanym **Protokoły połączenia** wybierz <code className="action">FTP i SFTP</code> lub <code className="action">FTP, SFTP i SSH</code>, jeśli chcesz również włączyć protokół SSH.

    <img className="thumbnail" alt="Panel Edytuj użytkownika i menu Protokoły połączenia" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user-protocols.png" loading="lazy" />

Menu oferuje trzecią wartość, samo <code className="action">FTP</code>, która wyłącza SFTP dla tego użytkownika.

    Na koniec kliknij <code className="action">Zatwierdź</code>. Po włączeniu opcji **SFTP** możesz używać protokołu SFTP Twojego hostingu z wybranym użytkownikiem FTP.
  </Tab>
</Tabs>

:::info
Wartość <code className="action">FTP, SFTP i SSH</code> jest dostępna tylko w ofertach obejmujących dostęp SSH: **Pro**, **Performance**, **Agency**, **Agency Plus** i **Agency Max**.

W ofertach <Region zones={['eu']}>**Darmowy**, **Starter**, **Perso** i **Startup**</Region><Region zones={['ca', 'apac']}>**Starter**, **Perso** i **Startup**</Region> menu **Protokoły połączenia** oferuje tylko <code className="action">FTP</code> i <code className="action">FTP i SFTP</code>, a tabela użytkowników nie wyświetla kolumny **SSH**.

:::
