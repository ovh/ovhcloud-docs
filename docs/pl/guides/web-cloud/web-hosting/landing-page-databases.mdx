## Zarządzanie bazami danych hostingu

Twórz, zarządzaj i twórz kopie zapasowe baz danych swojego hostingu OVHcloud. Ta strona gromadzi przewodniki, aby zarządzać bazami danych, tworzyć kopie zapasowe, importować i przywracać ich dane oraz rozwiązywać najczęstsze błędy.

Aby znaleźć odpowiedni przewodnik dla swoich potrzeb:

- **Chcesz utworzyć lub skonfigurować bazę danych?** Zobacz sekcję *Zarządzanie bazą danych* (tworzenie, hasło, duplikowanie).
- **Chcesz utworzyć kopię zapasową lub przywrócić dane?** Zobacz sekcję *Kopia zapasowa i przywracanie* (pobieranie, importowanie, przywracanie).
- **Napotykasz błąd bazy danych?** Zobacz sekcję *Rozwiązywanie problemów* (typowe błędy, przeciążona baza danych).
