## Wprowadzenie

Baza danych (DB) pozwala na przechowywanie elementów dynamicznych, takich jak komentarze czy artykuły. Bazy danych są obecnie wykorzystywane przez niemal wszystkie systemy zarządzania treścią (CMS), takie jak WordPress lub Joomla!.

**Dowiedz się, jak utworzyć bazę danych na serwerze baz danych i przyznać dostęp użytkownikom.**

## Wymagania początkowe

- Posiadanie [instancji Web Cloud Databases](/links/web/databases) (zawartej w ofercie [hostingu www](/links/web/hosting) Performance, Agency, Agency Plus lub Agency Max).

[[cpnav:web-cloud-databases]]

## W praktyce

### Tworzenie bazy danych

Kliknij poniższe karty, aby wyświetlić kolejne **4** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij kartę <code className="action">Bazy danych</code>.

    <img className="thumbnail" alt="Karta Bazy danych instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    Kliknij <code className="action">Dodaj bazę danych</code> nad tabelą baz danych.

    <img className="thumbnail" alt="Przycisk Dodaj bazę danych nad tabelą baz danych" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    Tworzenie schematów PostgreSQL jest obecnie niedostępne na serwerach Web Cloud Databases.

    :::

  </Tab>
  <Tab label="Krok 4">
    Po prawej stronie otworzy się panel **Dodaj bazę danych**. Wypełnij pola zgodnie z kryteriami podanymi pod każdym z nich:

    - **Nazwa bazy danych** (wymagane): to nazwa przyszłej bazy danych.
    - **Dostęp do tej bazy danych**: wybierz, kto będzie mógł łączyć się z bazą danych i wykonywać zapytania.
        - **Na razie bez dostępu** (opcja domyślna): baza danych zostanie utworzona bez użytkownika. Uprawnienia możesz przypisać użytkownikowi później.
        - **Istniejący użytkownik**: w polu **Użytkownik** wybierz użytkownika, a następnie w polu **Uprawnienia** wybierz jego uprawnienia do bazy danych.
        - **Nowy użytkownik**: wypełnij poniższe pola, aby utworzyć użytkownika jednocześnie z bazą danych.
    - **Nazwa użytkownika** (tylko z opcją **Nowy użytkownik**): użytkownik, który będzie mógł się łączyć z bazą danych i wykonywać zapytania.
    - **Uprawnienia** (z opcją **Istniejący użytkownik** lub **Nowy użytkownik**): uprawnienia przypisane do użytkownika w bazie danych. W przypadku standardowego użycia wybierz `Admin`. Uprawnienia można zmienić w późniejszym czasie.
    - **Hasło**/**Potwierdź hasło** (tylko z opcją **Nowy użytkownik**): wpisz hasło, a następnie potwierdź je.

    Kliknij <code className="action">Dodaj</code>.

    <img className="thumbnail" alt="Panel Dodaj bazę danych z nowym użytkownikiem" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

### Tworzenie użytkownika

Aby korzystać z serwera baz danych OVHcloud, utwórz użytkowników z odpowiednimi uprawnieniami do łączenia się z bazą danych.

Kliknij poniższe karty, aby wyświetlić kolejne **4** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij kartę <code className="action">Użytkownicy i uprawnienia</code>.

    <img className="thumbnail" alt="Karta Użytkownicy i uprawnienia instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    Kliknij <code className="action">Dodaj użytkownika</code>.
  </Tab>
  <Tab label="Krok 4">
    Po prawej stronie otworzy się panel **Dodaj użytkownika**. W polu **Nazwa użytkownika** wpisz nazwę użytkownika, w polu **Hasło** wpisz hasło, a następnie potwierdź je w polu **Potwierdź hasło**, zgodnie z kryteriami podanymi pod każdym polem. Następnie kliknij <code className="action">Dodaj</code>.

    <img className="thumbnail" alt="Panel Dodaj użytkownika z trzema polami" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/add-user.png" loading="lazy" />
  </Tab>
</Tabs>

### Zarządzanie uprawnieniami użytkowników

Aby użytkownik mógł wykonywać operacje na bazie danych, konieczne jest przypisanie mu uprawnień.

Kliknij poniższe karty, aby wyświetlić kolejne **4** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij kartę <code className="action">Użytkownicy i uprawnienia</code>.

    <img className="thumbnail" alt="Karta Użytkownicy i uprawnienia instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    Każdy użytkownik jest wyświetlany w osobnej ramce ze swoją nazwą. W ramce odpowiedniego użytkownika kliknij przycisk <code className="action">⋮</code> znajdujący się po prawej stronie napisu **Dodatkowe działania**, a następnie <code className="action">Zarządzaj uprawnieniami</code>.

    <img className="thumbnail" alt="Menu Dodatkowe działania użytkownika z pozycją Zarządzaj uprawnieniami" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 4">
    Po prawej stronie otworzy się panel o tytule **Uprawnienia dla** z nazwą użytkownika. Zawiera on listę baz danych na Twoim serwerze; po prawej stronie każdej z nich znajduje się menu rozwijane wskazujące poziom uprawnień użytkownika do tej bazy danych. Wybierz żądany poziom dla każdej bazy danych. Zmiana jest stosowana natychmiast: wyświetlany jest komunikat **Uprawnienie zmienione**.

    Dostępne są 4 poziomy uprawnień:

    - `Admin`: autoryzacja zapytań typu **Select / Insert / Update / Delete / Create / Alter / Drop**.
    - `Odczyt / Zapis`: autoryzacja zapytań typu **Select / Insert / Update / Delete**.
    - `Tylko odczyt`: autoryzacja zapytań typu **Select**.
    - `Brak`: brak uprawnień do bazy danych.

    :::info
    Podział uprawnień wymienionych powyżej jest właściwy dla OVHcloud. Użytkownik z uprawnieniami `Admin` może korzystać z **DDL** (Data Definition Language) i **DML** (Data Manipulation Language), podczas gdy użytkownik z uprawnieniami `Odczyt / Zapis` może korzystać tylko z **DML** (Data Manipulation Language).

    :::

    <img className="thumbnail" alt="Panel uprawnień użytkownika, jeden poziom na bazę danych" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />
  </Tab>
</Tabs>

### Usuwanie bazy danych

:::warning
Podczas usuwania bazy danych na serwerze baz danych nie jest
przeprowadzana żadna weryfikacja zawartości bazy. Zostanie ona usunięta,
nawet jeśli zawiera dane. Dlatego zaleca się utworzenie
kopii zapasowej i pobranie jej na swoje urządzenie przed każdym usunięciem.

:::

Kliknij poniższe karty, aby wyświetlić kolejne **3** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij kartę <code className="action">Bazy danych</code>.

    <img className="thumbnail" alt="Karta Bazy danych instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    W tabeli kliknij przycisk <code className="action">⋮</code> w kolumnie **Akcje**, po prawej stronie odpowiedniej bazy danych, a następnie kliknij <code className="action">Usuń</code>.

    <img className="thumbnail" alt="Menu wiersza w tabeli baz danych Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    W oknie **Usuń bazę danych**, które się otworzy, potwierdź usunięcie, klikając <code className="action">Usuń</code>.

    <img className="thumbnail" alt="Okno potwierdzenia usunięcia bazy danych" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/delete-database-dialog.png" loading="lazy" />
  </Tab>
</Tabs>
