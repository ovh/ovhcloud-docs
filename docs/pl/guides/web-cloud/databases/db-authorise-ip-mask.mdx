## Wprowadzenie

Rozwiązania [Web Cloud Databases](/links/web/databases) mogą być używane z usługami OVHcloud lub zewnętrznymi wobec OVHcloud.

Domyślnie i ze względów bezpieczeństwa:

- Dostęp do zawartości baz danych jest możliwy tylko dla adresów IP powiązanych z naszą infrastrukturą hostingu.
- Dostęp do logów rozwiązania nie jest ograniczony na podstawie adresów IP. Pozwala to na przykład na dostęp do danych z komputera.

Chcesz zmienić te uprawnienia/ograniczenia?

**Dowiedz się, jak autoryzować jeden lub więcej adresów IP, aby uzyskać dostęp do rozwiązania Web Cloud Databases.**

## Wymagania początkowe

- Posiadanie rozwiązania [Web Cloud Databases](/links/web/databases).
- Sprawdź adres IP (lub zakres adresów IP), który chcesz autoryzować w Twoim rozwiązaniu.

[[cpnav:web-cloud-databases]]

## W praktyce

### Autoryzacja adresu IP lub zakresu adresów IP

:::info
Przypominamy, że jeśli rozwiązanie [Web Cloud Databases](/links/web/databases) zostało właśnie aktywowane i chcesz z niego korzystać w ramach oferty [hostingu www OVHcloud](/links/web/hosting), adresy IP tych ofert są już domyślnie autoryzowane.

:::

Kliknij poniższe zakładki, aby wyświetlić kolejno **4** kroki.

<Tabs>
  <Tab label="Etap 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, a następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 2">
    Na stronie, która się wyświetli, kliknij zakładkę <code className="action">Autoryzowane IP</code>.

    <img className="thumbnail" alt="Karta Autoryzowane IP instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 3">
    Na stronie, która się wyświetli, kliknij przycisk <code className="action">Dodaj IP</code> znajdujący się nad tabelą.

    <img className="thumbnail" alt="Przycisk Dodaj IP nad tabelą autoryzowanych adresów IP" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Jeśli chcesz zmienić już autoryzowany adres IP lub zakres adresów IP, kliknij w tabeli przycisk <code className="action">⋮</code> w kolumnie **Akcje**, po prawej stronie wiersza odpowiadającego adresowi IP lub zakresowi adresów IP do zmiany, a następnie kliknij <code className="action">Edytuj</code>. Możesz zmienić jego nazwę i uprawnienia; samego adresu IP nie można zmienić.

    <img className="thumbnail" alt="Menu wiersza w tabeli autoryzowanych adresów IP" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Etap 4">
    W oknie **Dodaj adres IP**, które się otworzy, wypełnij następujące pola:

    <img className="thumbnail" alt="Okno Dodaj adres IP i jego pola" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (wymagane): Wpisz adres IP (na przykład: `203.0.113.44`) lub zakres adresów IP (na przykład: `203.0.113.0/24`, obejmujący wszystkie adresy IP od `203.0.113.0` do `203.0.113.255`), który chcesz autoryzować w rozwiązaniu Web Cloud Databases.
    - **Nazwa** (wymagane): Możesz tu na przykład wskazać rolę danego adresu IP lub zakresu adresów IP.
    - **Zezwól na dostęp do usługi** (domyślnie zaznaczone): Zaznacz to pole, aby zezwolić adresowi IP lub zakresowi adresów IP na dostęp do baz danych Twojego rozwiązania Web Cloud Databases.
    - **Zezwól na dostęp SFTP**: Zaznacz to pole, aby zezwolić adresowi IP lub zakresowi adresów IP na dostęp do logów Twojego rozwiązania Web Cloud Databases.

    :::warning
    Zdecydowanie odradzamy zaznaczanie pola **Zezwól na dostęp do usługi**, aby zezwolić zakresowi adresów IP `0.0.0.0/0` na dostęp do Twoich baz danych.

    W ten sposób wszystkie istniejące adresy IPv4 uzyskałyby dostęp do Twoich baz danych.

    :::

    Po wpisaniu informacji kliknij przycisk <code className="action">Dodaj</code>.
  </Tab>
</Tabs>

## Szczególne przypadki

**Kliknij poniższe przypadki, aby wyświetlić odpowiednie informacje.**

<details>

<summary>Zakres adresów IP 0.0.0.0/0</summary>

Po aktywacji rozwiązania Web Cloud Databases wiersz dla zakresu adresów IP `0.0.0.0/0` jest już domyślnie obecny, aby zezwolić na dostęp **SFTP** do rozwiązania.

To uprawnienie jest celowo skonfigurowane, aby umożliwić dostęp do plików logów rozwiązania Web Cloud Databases bez konieczności deklarowania adresu IP punktu dostępu do Internetu.

Ten adres IP może się bowiem regularnie zmieniać w zależności od dostawcy usług internetowych.

Ponadto zalecamy, aby **nie** modyfikować tego uprawnienia i nie zezwalać na dostęp do baz danych w rozwiązaniu Web Cloud Databases.

W ten sposób wszystkie istniejące adresy IPv4 uzyskałyby dostęp do Twoich baz danych, co stanowi zagrożenie dla bezpieczeństwa Twoich danych.

</details>

<details>

<summary>Autoryzacja dostępu dla hostingu www OVHcloud</summary>

Po aktywacji rozwiązania Web Cloud Databases autoryzacja dostępu dla hostingu www OVHcloud jest domyślnie włączona.

Jeśli chcesz wyłączyć to uprawnienie, ponieważ nie korzystasz z hostingu www z rozwiązaniem Web Cloud Databases, kliknij poniższe zakładki, aby wyświetlić kolejno **3** kroki.

<Tabs>
  <Tab label="Etap 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, a następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 2">
    Na stronie, która się wyświetli, kliknij zakładkę <code className="action">Autoryzowane IP</code>.

    <img className="thumbnail" alt="Karta Autoryzowane IP instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 3">
    W górnej części strony, w sekcji **Dostęp do hostingu OVHcloud**, wyłącz przełącznik **Zezwól hostingom OVHcloud na dostęp do bazy danych**.

    <img className="thumbnail" alt="Sekcja Dostęp do hostingu OVHcloud i jej przełącznik" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/web-hosting-access.png" loading="lazy" />

    :::info
    Wyłączenie tego dostępu blokuje również dostęp do **phpMyAdmin** za pośrednictwem odnośnika dostępnego w konsoli OVHcloud, i to dla całego rozwiązania Web Cloud Databases.
    :::

  </Tab>
</Tabs>
