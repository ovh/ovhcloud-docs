## Wprowadzenie

Rozwiązanie Web Cloud Databases udostępnia instancję baz danych z dedykowanymi i gwarantowanymi zasobami, zapewniając wydajność i elastyczność.
Domyślnie rozwiązanie Web Cloud Databases jest powiązane z siecią hostingów WWW OVHcloud. Możesz je również powiązać z dowolną inną siecią za pomocą listy autoryzowanych adresów IP.

**Dowiedz się, jak rozpocząć korzystanie z rozwiązania Web Cloud Databases.**

## Wymagania początkowe

- [Instancja Web Cloud Databases](/links/web/databases) (zawarta w ofercie [hostingu www](/links/web/hosting) Performance, Agency, Agency Plus lub Agency Max).

[[cpnav:web-cloud-databases]]

## W praktyce

### Aktywacja serwera Web Cloud Databases zawartego w ofercie hostingu WWW

Jeśli Twoja oferta hostingu obejmuje opcję Web Cloud Databases, kliknij poniższe karty, aby wyświetlić kolejne **3** kroki.

:::warning
Aktywacja tej opcji wymaga posiadania co najmniej kontaktu administracyjnego hostingu, który obejmuje usługę Web Cloud Databases. Więcej informacji na temat zarządzania kontaktami znajdziesz w naszym przewodniku "[Zarządzanie kontaktami swoich usług](/guides/account-and-service-management/account-information/managing-contacts)".

:::

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/hosting">Hosting</ManagerLink>, następnie wybierz odpowiedni hosting WWW.

    <img className="thumbnail" alt="Strona Hosting z listą hostingów na koncie" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Na karcie <code className="action">Przegląd</code> znajdź sekcję **Bazy danych**. Wiersz **Web Cloud DB** wskazuje, że Twoja instancja nie jest jeszcze aktywowana. Kliknij <code className="action">Aktywuj</code> pod tym wierszem.

    <img className="thumbnail" alt="Sekcja Bazy danych hostingu z linkiem Aktywuj w wierszu Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    Na wyświetlonej stronie **Aktywuj Web Cloud DB** wybierz pojemność instancji (pojemność 512 MB jest zawarta w Twojej ofercie hostingu, wyższe pojemności są płatne), następnie jej silnik (PostgreSQL, MariaDB, MySQL lub Valkey), a na liście **Wersja** wybierz wersję. Następnie kliknij <code className="action">Aktywuj</code> (pojemność zawarta w ofercie) lub <code className="action">Zamów</code> (pojemność płatna) i zatwierdź zamówienie, które otworzy się w nowej karcie.

    <img className="thumbnail" alt="Strona Aktywuj Web Cloud DB z wyborem pojemności, silnika i wersji" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate-page.png" loading="lazy" />

    Instancja będzie następnie dostępna na stronie <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.
  </Tab>
</Tabs>

### Wyświetlanie informacji ogólnych instancji

Kliknij poniższe karty, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />

    :::info
    Nazwa usługi Web Cloud DB w konsoli OVHcloud zawiera część identyfikatora klienta i kończy się trzema cyframi (001 dla pierwszej zainstalowanej usługi Web Cloud Databases, 002 dla drugiej itd.).

    :::

  </Tab>
  <Tab label="Krok 2">
    Upewnij się, że jesteś na karcie <code className="action">Przegląd</code>.

    Sprawdź, czy informacje wyświetlane w sekcjach **Informacje ogólne** i **Wykorzystanie zasobów** są poprawne lub odpowiadają poniższym wskazówkom.

    |Informacja|Szczegóły|
    |---|---|
    |Stan|Wskazuje między innymi, czy instancja jest uruchomiona, w trakcie restartu lub zawieszona. Instancja musi być uruchomiona, aby można było na niej wykonywać operacje.|
    |Silnik|Wskazuje system baz danych używany przez serwer oraz jego wersję. Upewnij się, że Twoja strona WWW jest kompatybilna z wybraną wersją.|
    |Region|Wskazuje region centrum danych, w którym instancja została utworzona.|
    |Host|Wskazuje serwer OVHcloud, na którym instancja została utworzona. Jest to informacja związana z infrastrukturą OVHcloud i może być używana w komunikatach dotyczących [awarii OVHcloud](https://www.status-ovhcloud.com/).|
    |Nasycenie CPU|Wskazuje, jak często instancja jest ograniczana przez przydzielony jej CPU. Jeśli wartość jest wysoka, rozważ zamówienie większej ilości pamięci RAM.|
    |RAM|Wskazuje pamięć RAM dostępną dla instancji oraz ewentualne przekroczenia pamięci. Instancja Web Cloud Databases dysponuje dedykowanymi i gwarantowanymi zasobami: pamięcią RAM. W razie potrzeby można ją rozszerzyć za pomocą linku **Zamów więcej RAM**.|
    |Limit przestrzeni|Wskazuje przestrzeń zajmowaną przez dane w stosunku do przestrzeni zawartej w Twojej ofercie. Po osiągnięciu tego limitu zapisy kończą się niepowodzeniem: należy wtedy usunąć dane lub przejść na wyższą ofertę.|

    <img className="thumbnail" alt="Sekcje Informacje ogólne i Wykorzystanie zasobów na karcie Przegląd" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/overview.png" loading="lazy" />
  </Tab>
</Tabs>

### Tworzenie bazy danych

:::info
Ten krok nie dotyczy systemu baz danych Valkey.

:::

Kliknij poniższe karty, aby wyświetlić kolejne **4** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij kartę <code className="action">Bazy danych</code>.

    <img className="thumbnail" alt="Karta Bazy danych instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    Kliknij <code className="action">Dodaj bazę danych</code> nad tabelą baz danych.

    <img className="thumbnail" alt="Przycisk Dodaj bazę danych nad tabelą baz danych" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    Tworzenie schematów PostgreSQL jest obecnie niedostępne na serwerach Web Cloud Databases.

    :::

  </Tab>
  <Tab label="Krok 4">
    Po prawej stronie otworzy się panel **Dodaj bazę danych**. Wypełnij pola zgodnie z kryteriami podanymi pod każdym z nich:

    - **Nazwa bazy danych** (wymagane): to nazwa przyszłej bazy danych.
    - **Dostęp do tej bazy danych**: wybierz, kto będzie mógł łączyć się z bazą danych i wykonywać zapytania.
        - **Na razie bez dostępu** (opcja domyślna): baza danych zostanie utworzona bez użytkownika. Uprawnienia możesz przypisać użytkownikowi później.
        - **Istniejący użytkownik**: w polu **Użytkownik** wybierz użytkownika, a następnie w polu **Uprawnienia** wybierz jego uprawnienia do bazy danych.
        - **Nowy użytkownik**: wypełnij poniższe pola, aby utworzyć użytkownika jednocześnie z bazą danych.
    - **Nazwa użytkownika** (tylko z opcją **Nowy użytkownik**): użytkownik, który będzie mógł się łączyć z bazą danych i wykonywać zapytania.
    - **Uprawnienia** (z opcją **Istniejący użytkownik** lub **Nowy użytkownik**): uprawnienia przypisane do użytkownika w bazie danych. W przypadku standardowego użycia wybierz `Admin`. Uprawnienia można zmienić w późniejszym czasie.
    - **Hasło**/**Potwierdź hasło** (tylko z opcją **Nowy użytkownik**): wpisz hasło, a następnie potwierdź je.

    Kliknij <code className="action">Dodaj</code>.

    <img className="thumbnail" alt="Panel Dodaj bazę danych z nowym użytkownikiem" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

:::info

### Autoryzacja adresu IP

Aby instancja Web Cloud Databases działała, konieczne jest wskazanie adresów IP lub zakresów IP, które mogą łączyć się z bazami danych.

W tym celu kliknij poniższe karty, aby wyświetlić kolejne **4** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Na wyświetlonej stronie kliknij kartę <code className="action">Autoryzowane IP</code>.

    <img className="thumbnail" alt="Karta Autoryzowane IP instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    Na wyświetlonej stronie kliknij przycisk <code className="action">Dodaj IP</code> nad tabelą.

    <img className="thumbnail" alt="Przycisk Dodaj IP nad tabelą autoryzowanych adresów IP" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Jeśli chcesz zmienić już autoryzowany adres IP lub zakres adresów IP, kliknij przycisk <code className="action">⋮</code> w kolumnie **Akcje**, po prawej stronie wiersza odpowiadającego adresowi IP lub zakresowi adresów IP, który chcesz zmienić, a następnie <code className="action">Edytuj</code>. Możesz zmienić jego nazwę i uprawnienia; samego adresu IP nie można zmienić.

    <img className="thumbnail" alt="Menu wiersza w tabeli autoryzowanych adresów IP" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Krok 4">
    W oknie **Dodaj adres IP**, które się otworzy, należy wypełnić kilka pól:

    <img className="thumbnail" alt="Okno Dodaj adres IP i jego pola" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (wymagane): Wpisz adres IP (np. `203.0.113.44`) lub zakres adresów IP (np. `203.0.113.0/24` obejmujący wszystkie adresy IP od `203.0.113.0` do `203.0.113.255`), które chcesz autoryzować w rozwiązaniu Web Cloud Databases.
    - **Nazwa** (wymagane): Możesz tu na przykład wskazać rolę danego adresu IP lub zakresu adresów IP.
    - **Zezwól na dostęp do usługi** (domyślnie zaznaczone): Zaznacz to pole, aby adres IP lub zakres adresów IP mógł uzyskać dostęp do baz danych Twojego rozwiązania Web Cloud Databases.
    - **Zezwól na dostęp SFTP**: Zaznacz to pole, aby adres IP lub zakres adresów IP mógł uzyskać dostęp do logów Twojego rozwiązania Web Cloud Databases.

    :::warning
    Zdecydowanie odradzamy zaznaczanie pola **Zezwól na dostęp do usługi** w celu autoryzacji zakresu adresów IP `0.0.0.0/0` do dostępu do baz danych.

    Umożliwiłoby to dostęp do baz danych dla wszystkich istniejących adresów IPv4.

    :::

    Po uzupełnieniu informacji kliknij przycisk <code className="action">Dodaj</code>.
  </Tab>
</Tabs>

### Autoryzacja połączeń z hostingu WWW OVHcloud <a name="trustip"></a>

Domyślnie rozwiązanie Web Cloud Databases jest automatycznie powiązane z hostingami WWW OVHcloud. Jeśli chcesz, możesz wyłączyć dostęp hostingów WWW OVHcloud do Web Cloud Databases.

W tym celu zapoznaj się z przypadkami szczególnymi w przewodniku "[Web Cloud Databases - Jak autoryzować adres IP?](/guides/web-cloud/databases/db-authorise-ip-mask)", aby włączyć lub wyłączyć dostęp hostingów WWW OVHcloud do Web Cloud Databases.

### Powiązanie strony WWW z bazą danych

Teraz, gdy baza danych jest utworzona, co najmniej jeden użytkownik ma uprawnienia do niej, a przynajmniej jeden adres IP lub hostingi WWW OVHcloud zostały autoryzowane w instancji Web Cloud Databases, pozostaje tylko powiązać stronę WWW z bazą danych. Ten krok można wykonać na kilka sposobów, w zależności od strony WWW lub systemu CMS (WordPress, Joomla! itp.) oraz etapu instalacji strony WWW.

Do tego potrzebne jest 5 następujących informacji:

|Informacja|Opis|
|---|---|
|Nazwa bazy danych|Nazwa zdefiniowana podczas tworzenia bazy danych.|
|Nazwa użytkownika|Nazwa użytkownika zdefiniowana podczas tworzenia bazy danych lub ewentualny dodatkowy użytkownik.|
|Hasło użytkownika|Hasło powiązane z użytkownikiem, zdefiniowane w poprzednich krokach.|
|Nazwa hosta serwera|Serwer, który należy podać, aby strona WWW mogła połączyć się z bazą danych.|
|Port serwera|Port połączenia z instancją Web Cloud Databases, aby strona WWW mogła połączyć się z bazą danych.|

Aby je znaleźć, kliknij poniższe karty, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Pobierz następujące informacje o połączeniu:

    - **Serwer (nazwa hosta) i port:** widoczne na karcie <code className="action">Przegląd</code>, w sekcji **SQL**, w polach **Nazwa hosta** i **Port**.
    - **Użytkownik:** widoczny na karcie <code className="action">Użytkownicy i uprawnienia</code>.
    - **Hasło:** hasło powiązane z użytkownikiem. Jeśli je zapomniałeś, przejdź do karty <code className="action">Użytkownicy i uprawnienia</code>, kliknij przycisk <code className="action">⋮</code> odpowiedniego użytkownika, a następnie <code className="action">Zmień hasło</code>.

    <img className="thumbnail" alt="Sekcja SQL na karcie Przegląd z nazwą hosta i portem" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />

    :::warning
    W przypadku zmiany hasła użytkownika bazy danych wszystkie aplikacje/strony WWW, które korzystają z tej bazy danych, muszą zostać odpowiednio zaktualizowane.

    :::

  </Tab>
</Tabs>

:::warning
Pole <code className="action">port</code> może nie być dostępne w konfiguracji Twojej strony WWW. Należy dodać to pole po nazwie hosta serwera, oddzielając je znakiem *:*.

Na przykład, dla nazwy hosta `aaXXXXX-XXX.eu.clouddb.ovh.net` z portem SQL `12345` należy wpisać `aaXXXXX-XXX.eu.clouddb.ovh.net:12345` w polu "Host" / "Nazwa hosta".

:::

:::info
OVHcloud nie udostępnia portu szyfrowanego TLS dla serwerów baz danych Valkey. Komunikacja musi odbywać się wyłącznie przez domyślny, nieszyfrowany port.

:::
