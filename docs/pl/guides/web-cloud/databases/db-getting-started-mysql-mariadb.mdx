## Wprowadzenie

Chcesz korzystać z MySQL lub MariaDB dla swoich baz danych?

### Czym jest baza danych MySQL?

MySQL to system zarządzania relacyjnymi bazami danych przygotowany z myślą o zwiększonej wydajności odczytu, w przeciwieństwie do pozostałych systemów.

Jest to silnik open source firmy Oracle.

### Czym jest baza danych MariaDB?

MariaDB to pochodna systemu zarządzania bazami danych MySQL.

Silnik ten jest w 100% kompatybilny. Wszystkie bugi oraz roadmapy są w pełni dostępne, w przeciwieństwie do wersji Oracle.

**Dowiedz się, jak tworzyć bazy danych MySQL lub MariaDB**

## W praktyce

### Łączenie z bazą danych

:::info
Ta oferta nie daje dostępu do Hosta, lecz do baz danych na nim hostowanych. Ogólne polecenia SQL działają bez żadnych problemów, a oprogramowanie takie jak HeidiSQL czy SQuirreL SQL jest w pełni kompatybilne.

:::

:::info
Ponieważ MariaDB jest pochodną MySQL, polecenia są dokładnie takie same dla tych 2 typów baz danych.

:::

Aby połączyć się z bazą danych, upewnij się, że posiadasz:

- adres Twojej instancji Web Cloud Databases
- port Twojej instancji Web Cloud Databases
- nazwę użytkownika Twojej instancji Web Cloud Databases
- hasło przypisane do użytkownika
- nazwę Twojej bazy danych

Wszystkie te informacje są dostępne w konsoli OVHcloud, na stronie <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.

Dostępny jest również przewodnik: [Pierwsze kroki z usługą Web Cloud Databases](/guides/web-cloud/databases/db-getting-started).

#### Łączenie z poziomu wiersza poleceń

```bash
mysql --host=server --user=user --port=port --password=password database_name
```

#### Łączenie za pomocą skryptu PHP

```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

#### Łączenie za pomocą oprogramowania (SQuirreL SQL)

- Uruchom SQuirreL SQL i kliknij <code className="action">Aliases</code>, a następnie <code className="action">+</code>.

<img className="thumbnail" alt="uruchomienie SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

#### Łączenie za pomocą phpMyAdmin

Możesz użyć phpMyAdmin do przeglądania zawartości bazy danych. W tym celu zainstaluj phpMyAdmin na własnym serwerze lub hostingu www. Podczas instalacji poprawnie skonfiguruj dane Twojego serwera Web Cloud Databases i wybranej bazy danych, aby phpMyAdmin mógł się z nią połączyć.

### Eksportowanie i importowanie bazy danych MySQL lub MariaDB

- **Eksportuj moją bazę danych z wiersza poleceń**

```bash
mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql
```

- **Importuj moją bazę danych z wiersza poleceń**

```bash
cat database_name.sql | mysql --host=server --user=user --port=port --password=password database_name
```

:::info
W niektórych przypadkach pamięć RAM dostępna w Twojej instancji Web Cloud Databases może nie wystarczyć do wykonania żądanego eksportu lub importu. W takim przypadku zalecamy użycie narzędzia do importu udostępnionego przez OVHcloud. W razie potrzeby zapoznaj się z dokumentacją "[Pierwsze kroki z usługą Web Cloud Databases](/guides/web-cloud/databases/db-getting-started#import-bazy-danych)".

:::
