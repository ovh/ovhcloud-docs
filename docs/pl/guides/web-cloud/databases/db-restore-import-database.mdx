## Wprowadzenie

W wyniku błędu bazy danych musisz mieć możliwość przywrócenia kopii zapasowej lub importu lokalnej bazy danych.

**Dowiedz się, jak przywrócić i zaimportować bazę danych na serwer baz danych.**

## Wymagania początkowe

- Posiadanie [instancji Web Cloud Databases](/links/web/databases) (zawartej w ofercie [hostingu WWW](/links/web/hosting) Performance, Agency, Agency Plus lub Agency Max)

[[cpnav:web-cloud-databases-console]]

## W praktyce

:::info
Rozwiązania [Web Cloud Databases](/links/web/databases) nie dają dostępu do systemu zarządzania bazami danych, ale do baz danych na nim hostowanych.

- Nie ma dostępu superużytkownika "root".
- Ogólne polecenia SQL działają normalnie, a oprogramowanie takie jak HeidiSQL, SQuirreL SQL lub Adminer jest w pełni kompatybilne.

:::

### Przywracanie i importowanie bazy danych w konsoli OVHcloud <a name="przywracanie-i-importowanie-bazy-danych-w-panelu-klienta"></a>

#### Przywrócenie istniejącej kopii zapasowej

Kliknij na poniższe karty, aby wyświetlić kolejno każdy z **4** kroków.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij kartę <code className="action">Bazy danych</code>.

    W kolumnie **Kopie zapasowe** liczba oznacza liczbę kopii zapasowych dostępnych dla każdej bazy danych.

    <img className="thumbnail" alt="Zakładka Bazy danych instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    W tabeli kliknij przycisk <code className="action">⋮</code> w kolumnie **Akcje**, po prawej stronie bazy danych, a następnie <code className="action">Wyświetl kopie zapasowe</code>.

    <img className="thumbnail" alt="Menu wiersza tabeli baz danych Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 4">
    Po prawej stronie otworzy się panel zatytułowany **Kopie zapasowe**, a po nim nazwa bazy danych. Kliknij przycisk <code className="action">⋮</code> po prawej stronie wybranej kopii zapasowej, a następnie <code className="action">Przywróć</code>.

    <img className="thumbnail" alt="Panel kopii zapasowych bazy danych z otwartym menu kopii zapasowej" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/backup-actions-menu.png" loading="lazy" />

    W oknie **Przywróć kopię zapasową**, które się otworzy, potwierdź, klikając <code className="action">Przywróć</code>. Wyświetli się komunikat **Przywracanie rozpoczęte**.

    <img className="thumbnail" alt="Okno potwierdzenia przywracania kopii zapasowej" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/restore-backup-dialog.png" loading="lazy" />

    :::warning
    Przywrócenie bazy danych wiąże się z nadpisaniem jej zawartości, a tym samym z potencjalną utratą danych. Jeśli nie masz pewności, co robisz, zalecamy uprzednie wykonanie kopii zapasowej.

    :::

  </Tab>
</Tabs>

#### Import lokalnej kopii zapasowej

Kliknij na poniższe karty, aby wyświetlić kolejno każdy z **4** kroków.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij kartę <code className="action">Bazy danych</code>.

    <img className="thumbnail" alt="Zakładka Bazy danych instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    W tabeli kliknij przycisk <code className="action">⋮</code> w kolumnie **Akcje**, po prawej stronie wybranej bazy danych, a następnie <code className="action">Importuj</code>.

    <img className="thumbnail" alt="Menu wiersza tabeli baz danych Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 4">
    Otworzy się okno **Importuj bazę danych**. ***Masz dwie możliwości***, dostępne za pomocą dwóch przycisków u góry okna:

    **1 - Prześlij nowy plik**

    Ta możliwość jest domyślnie zaznaczona po otwarciu okna.

    W polu **Nazwa pliku** wpisz nazwę importowanego pliku. Następnie kliknij obszar <code className="action">Plik do importu</code>, aby wybrać plik na komputerze, lub przeciągnij go do tego obszaru.

    :::warning
    Plik musi być w formacie ".sql", ".txt" lub ".gz".

    :::

    <img className="thumbnail" alt="Okno Importuj bazę danych z zaznaczoną opcją Prześlij nowy plik" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/database-import-new-file-step-2.png" loading="lazy" />

    Jeśli chcesz, zaznacz pole **Wyczyść bazę danych przed importem**. Pole **Otrzymaj e-mail po zakończeniu importu** jest domyślnie zaznaczone: pozwala otrzymać informację o zakończeniu operacji na głównym adresie e-mail Twojego konta OVHcloud. Na koniec kliknij <code className="action">Potwierdź</code>: plik zostanie przesłany, a następnie rozpocznie się import.

    **2 - Użycie istniejącego pliku**

    Jeśli plik został już wcześniej zaimportowany, kliknij <code className="action">Użyj istniejącego pliku</code>.

    Następnie na liście rozwijanej **Istniejący dokument** wybierz plik spośród plików znajdujących się już na Twoim koncie OVHcloud.

    <img className="thumbnail" alt="Okno Importuj bazę danych z zaznaczoną opcją Użyj istniejącego pliku" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/database-import-existing-file-step-2.png" loading="lazy" />

    Jeśli chcesz, zaznacz pole **Wyczyść bazę danych przed importem**. Pole **Otrzymaj e-mail po zakończeniu importu** jest domyślnie zaznaczone: pozwala otrzymać informację o zakończeniu operacji na głównym adresie e-mail Twojego konta OVHcloud. Na koniec kliknij <code className="action">Potwierdź</code>, aby rozpocząć import.
  </Tab>
</Tabs>

### Import bazy danych poza konsolą OVHcloud <a name="import-bazy-danych-poza-panelem-klienta"></a>

W niektórych przypadkach pamięć RAM dostępna na serwerze baz danych nie pozwala na zrealizowanie żądanego importu poza konsolą OVHcloud. W takim przypadku zalecamy użycie narzędzia OVHcloud w konsoli OVHcloud. Przejdź do sekcji ["Przywracanie i importowanie bazy danych w konsoli OVHcloud"](#przywracanie-i-importowanie-bazy-danych-w-panelu-klienta) w tym przewodniku.

**Kliknij wybraną metodę importu, aby wyświetlić jej zawartość.**

<details>

<summary>Import bazy MySQL lub MariaDB z poziomu phpMyAdmin</summary>

Aby zaimportować bazę danych bezpośrednio z phpMyAdmin, należy się najpierw zalogować. W tym celu zapoznaj się z sekcją ["Logowanie do bazy danych MySQL lub MariaDB"](/guides/web-cloud/databases/db-connecting-database-server#logowanie-do-bazy-danych-mysql-lub-mariadb).

Po zalogowaniu się do phpMyAdmin wybierz bazę danych, klikając na jej nazwę.

Następnie kliknij kartę <code className="action">Importuj</code>.

Wybierz plik kopii zapasowej, klikając <code className="action">Przeglądaj</code> (plik nie może przekroczyć 100 MB).

:::info
Zalecamy podzielenie bazy danych na kilka plików, jeśli przekracza ona 100 MB, i wykonanie kilku importów z poziomu phpMyAdmin.
Import plików o rozmiarze większym niż 100 MB można wykonać z poziomu konsoli OVHcloud, postępując zgodnie z instrukcjami w sekcji ["Przywracanie i importowanie bazy danych w konsoli OVHcloud"](#przywracanie-i-importowanie-bazy-danych-w-panelu-klienta).

:::

Pozostaw domyślne opcje i kliknij <code className="action">Uruchom</code>, aby rozpocząć import.

<img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-upload-backup-web-cloud-db.png" loading="lazy" />

</details>

<details>

<summary>Import bazy MySQL lub MariaDB za pomocą wiersza poleceń</summary>

Operacja ta jest możliwa tylko przez [SSH](/guides/web-cloud/web-hosting/ssh-on-webhosting) z poziomu hostingu współdzielonego OVHcloud.

```bash
cat nazwa_bazy.sql | mysql --host=serwer --user=uzytkownik --port=port --password=haslo nazwa_bazy
```

</details>

<details>

<summary>Import bazy MySQL lub MariaDB z pliku PHP</summary>

```php
1. <?php
2. echo "Twoja baza danych jest w trakcie przywracania.......<br/>";
3. system("cat nazwa_bazy.sql | mysql --host=serwer --user=uzytkownik --port=port --password=haslo nazwa_bazy");
4. echo "Zakończono. Twoja baza danych jest zainstalowana na tym hostingu.";
5. ?>
```

:::warning
- Aby uniknąć dostępu osób trzecich do tego pliku zawierającego wrażliwe dane, zabezpiecz dostęp do niego, korzystając z przewodnika: [Jak chronić dostęp do katalogu hasłem?](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password)
- Operacja ta jest możliwa tylko z poziomu hostingu współdzielonego OVHcloud.

:::

</details>

<details>

<summary>Import bazy PostgreSQL za pomocą wiersza poleceń</summary>

Operacja ta jest możliwa wyłącznie przez [SSH](/guides/web-cloud/web-hosting/ssh-on-webhosting) z poziomu hostingu współdzielonego OVHcloud w wersji stabilnej lub wyższej.

```bash
psql --host=serwer --port=port --user=uzytkownik --password=haslo nazwa_bazy < nazwa_bazy.sql
```

</details>

<details>

<summary>Import bazy PostgreSQL z pliku PHP</summary>

```php
1. <?php
2. echo "Twoja baza danych jest w trakcie przywracania.......<br/>";
3. system("PGPASSWORD=haslo psql --host=serwer --port=port --user=uzytkownik --password=haslo nazwa_bazy < nazwa_bazy.sql");
4. echo "Zakończono. Twoja baza danych jest zainstalowana na tym hostingu.";
5. ?>
```

:::warning
- Aby uniknąć dostępu osób trzecich do tego pliku zawierającego wrażliwe dane, zabezpiecz dostęp do niego, korzystając z przewodnika: [Jak chronić dostęp do katalogu hasłem?](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password)
- Operacja ta jest możliwa tylko z poziomu hostingu współdzielonego OVHcloud.

:::

</details>
