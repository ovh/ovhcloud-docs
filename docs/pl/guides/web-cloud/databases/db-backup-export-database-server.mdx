## Wprowadzenie

Baza danych może zawierać dużą liczbę informacji niezbędnych dla Twojej strony WWW. Dlatego ważne jest, aby móc ją zapisać lub wyeksportować.

**Dowiedz się, jak tworzyć kopie zapasowe i eksportować bazę danych z serwera baz danych.**

## Wymagania początkowe

- Posiadanie [instancji Web Cloud Databases](/links/web/databases) (zawartej w ofercie [hostingu www](/links/web/hosting) Performance, Agency, Agency Plus lub Agency Max).

[[cpnav:web-cloud-databases]]

## W praktyce

:::info
Rozwiązania [Web Cloud Databases](/links/web/databases) nie dają dostępu do systemu zarządzania bazami danych, ale do baz danych na nim hostowanych.

- Brak dostępu superużytkownika "root".
- Ogólne polecenia SQL działają normalnie, a oprogramowanie takie jak HeidiSQL, SQuirreL SQL lub Adminer jest w pełni kompatybilne.

:::

### Tworzenie kopii zapasowych i eksportowanie bazy danych w konsoli OVHcloud <a name="sauvegarder-et-exporter-une-base-de-données-depuis-lespace-client"></a>

:::info
- Kopie zapasowe są wykonywane automatycznie raz dziennie dla wszystkich Twoich baz danych.
- Automatyczne i ręczne kopie zapasowe są przechowywane przez 30 dni. Po tym czasie są automatycznie usuwane. Data usunięcia każdej kopii zapasowej jest podana na liście kopii zapasowych bazy danych.

:::

#### Wykonanie ręcznej kopii zapasowej

Kliknij poniższe karty, aby wyświetlić kolejne **3** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij zakładkę <code className="action">Bazy danych</code>.

    W kolumnie **Kopie zapasowe** liczba odpowiada liczbie kopii zapasowych dostępnych dla każdej bazy danych.

    <img className="thumbnail" alt="Karta Bazy danych instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    W tabeli kliknij przycisk <code className="action">⋮</code> w kolumnie **Akcje**, po prawej stronie odpowiedniej bazy danych, a następnie kliknij <code className="action">Utwórz kopię teraz</code>.

    <img className="thumbnail" alt="Menu wiersza w tabeli baz danych Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    Tworzenie kopii zapasowej rozpoczyna się natychmiast, bez potwierdzenia. Wyświetli się komunikat **Tworzenie kopii zapasowej rozpoczęte**.
  </Tab>
</Tabs>

#### Eksport kopii zapasowej

Kliknij poniższe karty, aby wyświetlić kolejne **4** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij zakładkę <code className="action">Bazy danych</code>.

    W kolumnie **Kopie zapasowe** liczba odpowiada liczbie kopii zapasowych dostępnych dla każdej bazy danych.

    <img className="thumbnail" alt="Karta Bazy danych instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    W tabeli kliknij przycisk <code className="action">⋮</code> w kolumnie **Akcje**, po prawej stronie odpowiedniej bazy danych, a następnie kliknij <code className="action">Wyświetl kopie zapasowe</code>.

    <img className="thumbnail" alt="Menu wiersza w tabeli baz danych Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 4">
    Po prawej stronie otworzy się panel o tytule **Kopie zapasowe** z nazwą bazy danych. Kopie zapasowe są uporządkowane od najnowszej do najstarszej, a przy każdej z nich podana jest data utworzenia i data usunięcia.

    Kliknij przycisk <code className="action">⋮</code> po prawej stronie wybranej kopii zapasowej, a następnie kliknij <code className="action">Pobierz</code>. Pobieranie rozpocznie się w nowej karcie przeglądarki.

    <img className="thumbnail" alt="Panel Kopie zapasowe bazy danych z otwartym menu kopii zapasowej" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/backup-actions-menu.png" loading="lazy" />
  </Tab>
</Tabs>

### Tworzenie kopii zapasowych i eksportowanie bazy danych poza konsolą OVHcloud <a name="sauvegarder-et-exporter-une-base-de-données-hors-espace-client"></a>

Jeśli dostępna pamięć RAM na serwerze nie pozwala na przeprowadzenie pożądanego eksportu, skorzystaj z narzędzia OVHcloud dostępnego w konsoli OVHcloud, które wykorzystuje zasoby zewnętrzne wobec Twojej oferty. Zapoznaj się z sekcją "[Tworzenie kopii zapasowych i eksportowanie bazy danych w konsoli OVHcloud](#tworzenie-kopii-zapasowych-i-eksportowanie-bazy-danych-w-konsoli-ovhcloud)" niniejszego przewodnika.

**Kliknij wybraną metodę eksportu, aby wyświetlić jej zawartość.**

<details>

<summary>Eksport bazy MySQL lub MariaDB z poziomu phpMyAdmin OVHcloud</summary>

Aby wyeksportować bazę danych bezpośrednio z phpMyAdmin, należy najpierw się zalogować. W tym celu zapoznaj się z przewodnikiem "[Logowanie do bazy danych](/guides/web-cloud/databases/db-connecting-database-server)".

Po zalogowaniu się do phpMyAdmin kliknij nazwę bazy danych, którą chcesz wyeksportować, a następnie zakładkę <code className="action">Eksport</code> u góry.

Dostępne są dwa tryby eksportu. Jeśli nie masz szczególnych wymagań, zalecamy użycie trybu **Szybko** w formacie **SQL**.

<img className="thumbnail" alt="Zakładka Eksport w phpMyAdmin z metodą Szybko i formatem SQL" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-export-backup-web-cloud-db.png" loading="lazy" />

</details>

<details>

<summary>Eksport bazy MySQL lub MariaDB z wiersza poleceń</summary>

```bash
mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql
```

</details>

<details>

<summary>Eksport bazy MySQL lub MariaDB ze skryptu PHP</summary>

```php
1. <?php echo "Your database is being backed up.......";
2. system("mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql");
3. echo "Backup complete. You can retrieve the database via FTP";
4. ?>
```

:::warning
- Aby uniemożliwić osobom trzecim dostęp do pliku zawierającego wrażliwe dane, zabezpiecz go za pomocą przewodnika: [Chroń katalog lub interfejs administracyjny Twojej strony internetowej za pomocą plików .htaccess i .htpasswd](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password).
- Operacja ta jest możliwa tylko z poziomu hostingu WWW OVHcloud.

:::

</details>

<details>

<summary>Eksport bazy PostgreSQL z wiersza poleceń</summary>

```bash
pg_dump --host=server --port=port --username=user --password database_name > database_name.sql
```

</details>

<details>

<summary>Eksport bazy PostgreSQL ze skryptu PHP</summary>

```php
1. <?php echo "Your database is being backed up.......";
2. system("PGPASSWORD=password pg_dump --host=server --port=port --username=user database_name > database_name.sql");
3. echo "Backup complete. You can retrieve the database via FTP";
4. ?>
```

:::warning
- Aby uniemożliwić osobom trzecim dostęp do pliku zawierającego wrażliwe dane, zabezpiecz go za pomocą przewodnika: [Chroń katalog lub interfejs administracyjny Twojej strony internetowej za pomocą plików .htaccess i .htpasswd](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password).
- Operacja ta jest możliwa tylko z poziomu hostingu WWW OVHcloud.

:::

</details>
