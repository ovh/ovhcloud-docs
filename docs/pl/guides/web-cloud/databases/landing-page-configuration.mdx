## Konfiguracja usługi Web Cloud Databases

Skonfiguruj usługę OVHcloud Web Cloud Databases i zarządzaj nią: dostęp, bazy danych, użytkownicy i uprawnienia, połączenie, rozszerzenia PostgreSQL oraz logi.

Aby znaleźć to, czego potrzebujesz:

- **Chcesz otworzyć dostęp i połączyć się z bazami danych?** Zapoznaj się z sekcją *Dostęp i połączenie*.
- **Zarządzasz bazami danych, użytkownikami i ich uprawnieniami?** Zapoznaj się z sekcją *Bazy danych i użytkownicy*.
- **Administrujesz serwerem (konfiguracja, logi)?** Zapoznaj się z sekcją *Serwer i eksploatacja*.
