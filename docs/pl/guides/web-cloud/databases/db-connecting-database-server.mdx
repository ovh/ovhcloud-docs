## Wprowadzenie

Zawartość bazy danych można przeglądać za pomocą interfejsu. Istnieje kilka sposobów połączenia się z bazą danych.

**Dowiedz się, jak połączyć się z bazą danych na serwerze baz danych.**

## Wymagania początkowe

- Posiadanie [instancji Web Cloud Databases](/links/web/databases) (zawartej w ofercie [hostingu www](/links/web/hosting) Performance, Agency, Agency Plus lub Agency Max).

[[cpnav:web-cloud-databases]]

## W praktyce

:::info
Rozwiązania [Web Cloud Databases](/links/web/databases) nie dają dostępu do samego systemu zarządzania bazami danych, lecz do baz danych na nim hostowanych.

- Nie ma dostępu super użytkownika "root".
- Ogólne polecenia SQL działają normalnie, a oprogramowanie takie jak HeidiSQL, SQuirreL SQL lub Adminer jest w pełni kompatybilne.

:::

### Połączenie z bazą danych MySQL lub MariaDB

:::info
Ponieważ MariaDB jest pochodną MySQL, polecenia są dokładnie takie same dla obu typów baz danych.

:::

#### Połączenie przez phpMyAdmin OVHcloud

Kliknij poniższe karty, aby wyświetlić kolejne **4** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Pobierz następujące informacje o połączeniu:

    - **Serwer (nazwa hosta) i port:** widoczne na zakładce <code className="action">Przegląd</code>, w sekcji **SQL**, w polach **Nazwa hosta** i **Port**.
    - **Użytkownik:** widoczny na zakładce <code className="action">Użytkownicy i uprawnienia</code>.
    - **Hasło:** hasło powiązane z użytkownikiem. Jeśli nie pamiętasz hasła, przejdź do zakładki <code className="action">Użytkownicy i uprawnienia</code>, kliknij przycisk <code className="action">⋮</code> odpowiedniego użytkownika, a następnie <code className="action">Zmień hasło</code>.

    <img className="thumbnail" alt="Sekcja SQL na karcie Przegląd z nazwą hosta i portem" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />

    :::warning
    W przypadku zmiany hasła użytkownika bazy danych wszystkie aplikacje/strony WWW, które korzystają z tej bazy danych, muszą zostać odpowiednio zaktualizowane.

    :::

  </Tab>
  <Tab label="Krok 3">
    Na zakładce <code className="action">Przegląd</code>, w sekcji **SQL**, kliknij przycisk <code className="action">⋮</code> po prawej stronie pozycji **Dodatkowe akcje**, a następnie <code className="action">Interfejs administracyjny</code>. phpMyAdmin otworzy się w nowej karcie przeglądarki.

    <img className="thumbnail" alt="Menu Dodatkowe akcje w sekcji SQL z pozycją Interfejs administracyjny" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-additional-actions.png" loading="lazy" />

    :::info
    Jeśli pozycja **Interfejs administracyjny** nie jest widoczna w menu, phpMyAdmin OVHcloud nie jest dostępny dla Twojej instancji. W takim przypadku skorzystaj z jednej z metod opisanych w sekcji "[Połączenie z bazą danych poza konsolą OVHcloud](#connexion-à-la-base-de-données-hors-espace-client)".

    :::

  </Tab>
  <Tab label="Krok 4">
    Na stronie logowania phpMyAdmin wprowadź informacje pobrane w kroku 2:

    <img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-login-web-cloud-db.png" loading="lazy" />

    - **Serwer:** wpisz *nazwę hosta*, a następnie *numer portu*, oddzielone znakiem "**:**" lub "**spacją**". Na przykład: **aaXXXXX-XXX.eu.clouddb.ovh.net:12345**.
    - **Użytkownik:** wpisz *nazwę użytkownika*.
    - **Hasło:** wpisz *hasło*.
  </Tab>
</Tabs>

Jeśli połączenie zakończy się pomyślnie, wyświetli się następująca strona.

<img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-main-page-web-cloud-db.png" loading="lazy" />

:::warning
**W przypadku błędu:**

- Błąd #1045 oznacza, że dane logowania są nieprawidłowe. Sprawdź nazwę użytkownika i/lub hasło.
- Błąd #2005 oznacza, że należy sprawdzić nazwę serwera oraz czy działa on prawidłowo.

:::

#### Połączenie z bazą danych poza konsolą OVHcloud <a name="connexion-à-la-base-de-données-hors-espace-client"></a>

:::warning
Jeśli korzystasz z rozwiązania "Web Cloud Databases"/"Prywatny SQL", pamiętaj, aby autoryzować swój adres IP, korzystając z przewodnika dotyczącego [konfiguracji serwera bazy danych](/guides/web-cloud/databases/db-configure-optimise-database-server#zarządzanie-dostępami).

:::

Kliknij poniższe karty, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Pobierz następujące informacje o połączeniu:

    - **Serwer (nazwa hosta):** widoczny na zakładce <code className="action">Przegląd</code>, w sekcji **SQL**, w polu **Nazwa hosta**.
    - **Port:** widoczny w tym samym miejscu, w polu **Port**.
    - **Użytkownik:** widoczny na zakładce <code className="action">Użytkownicy i uprawnienia</code>.
    - **Hasło:** hasło powiązane z danym użytkownikiem.
    - **Nazwa bazy danych:** widoczna na zakładce <code className="action">Bazy danych</code>.

    <img className="thumbnail" alt="Sekcja SQL na karcie Przegląd z nazwą hosta i portem" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />
  </Tab>
</Tabs>

**Kliknij wybraną metodę połączenia, aby wyświetlić jej zawartość.**

<details>

<summary>Połączenie z poziomu wiersza poleceń</summary>

```bash
mysql --host=server --user=user --port=port --password=password database_name
```

</details>

<details>

<summary>Połączenie przez skrypt PHP</summary>

```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

</details>

<details>

<summary>Połączenie przez oprogramowanie (SQuirreL SQL)</summary>

:::info
W naszym przykładzie wykorzystujemy oprogramowanie open source SQuirreL, ale inne interfejsy, takie jak HeidiSQL lub Adminer, są w pełni kompatybilne.

:::

- Uruchom SQuirreL SQL i kliknij <code className="action">Aliases</code>, a następnie <code className="action">+</code>

<img className="thumbnail" alt="uruchomienie SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Wypełnij poniższe pola, a następnie zatwierdź przyciskiem <code className="action">OK</code>:
    - **Name**: Wybierz nazwę
    - **Driver**: Wybierz "MySQL Driver"
    - **URL**: Wpisz adres serwera i port w formacie `jdbc:mysql://server:port`
    - **User Name**: Wpisz nazwę użytkownika
    - **Password**: Wpisz hasło

<img className="thumbnail" alt="konfiguracja połączenia" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Zatwierdź ponownie przyciskiem <code className="action">Connect</code>

<img className="thumbnail" alt="zatwierdzenie połączenia" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

Połączenie z bazą danych zostało nawiązane:

<img className="thumbnail" alt="konfiguracja połączenia" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

</details>

<details>

<summary>Połączenie przez phpMyAdmin</summary>

Możesz skorzystać z własnego interfejsu phpMyAdmin, aby przeglądać zawartość bazy danych. W tym celu zainstaluj phpMyAdmin na swoim własnym serwerze lub hostingu www. Podczas instalacji upewnij się, że informacje dotyczące serwera baz danych i wybranej bazy danych są prawidłowo skonfigurowane, aby phpMyAdmin mógł się z nim połączyć.

</details>
