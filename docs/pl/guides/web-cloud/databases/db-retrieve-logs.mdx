## Wprowadzenie

Log odpowiada zdarzeniu, które wystąpiło w systemie informatycznym (serwer, komputer, aplikacja, strona internetowa, baza danych, sieć informatyczna itp.).
Log może na przykład rejestrować i zawierać jeden lub kilka z poniższych elementów:

- Znacznik czasu (data, godzina, minuta, sekunda itp.) zdarzenia.
- Charakter zdarzenia (połączenie, rozłączenie, błąd, pobieranie, przesyłanie, alert itp.).
- Dodatkowe informacje o zdarzeniu (odwiedzona strona lub plik, uruchomiona aplikacja, wywołany zdalny serwer, nazwa przesłanego lub pobranego pliku itp.)
- Pochodzenie zdarzenia (identyfikator użytkownika, źródłowy adres IP, program źródłowy itp.).
- Stan systemu, w którym występuje zdarzenie (dostępne zasoby, pozostała pamięć, użycie procesora itp.).

W większości przypadków logi są generowane bezpośrednio przez systemy informatyczne, w których zachodzą zdarzenia.
Są przechowywane w plikach tekstowych, zwanych również plikami logów.

Pliki logów umożliwiają wykonywanie następujących czynności:

- Analizowanie zachowania systemu informatycznego generującego logi.
- Identyfikowanie błędów, które wystąpiły w systemie informatycznym.
- Rozwiązywanie błędów napotkanych w systemie informatycznym.
- Optymalizowanie i poprawianie wydajności systemu informatycznego.

Twoja usługa [Web Cloud Databases](/links/web/databases) generuje własne logi.

W niektórych sytuacjach może zajść potrzeba przeglądania lub pobierania logów:

- Z serwera Web Cloud Databases.
- Dla jednej z baz danych hostowanych na serwerze Web Cloud Databases.

**Dowiedz się, jak wyświetlać logi usługi Web Cloud Databases i zarządzać nimi.**

Kliknij poniższe karty, aby wyświetlić kolejne **2** kroki.

<Tabs>

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />

  <Tab label="Krok 2">
    Kliknij zakładkę <code className="action">Logi</code>.

    <img className="thumbnail" alt="Zakładka Logi instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/logs/tab.png" loading="lazy" />

    Logi są dostępne tutaj wyłącznie w czasie rzeczywistym. Pojawią się tylko wtedy, gdy zostaną wygenerowane w czasie, gdy znajdujesz się w zakładce <code className="action">Logi</code>.

    Jeśli opuścisz zakładkę <code className="action">Logi</code> i wrócisz do niej później, wcześniej wyświetlana historia zniknie.

    :::

### Pobieranie historii logów rozwiązania Web Cloud Databases

Aby pobrać historię logów Twojego rozwiązania Web Cloud Databases, musisz połączyć się z nim przez SFTP.

:::warning
Przed połączeniem upewnij się, że publiczny adres IP urządzenia, którego używasz, jest autoryzowany na Twoim serwerze Web Cloud Databases i ma zaznaczone pole **Zezwól na dostęp SFTP**.

Aby to sprawdzić, pobierz publiczny adres IP swojego punktu dostępu do Internetu, a następnie zapoznaj się z sekcją **Autoryzacja adresu IP** w [tym przewodniku](/guides/web-cloud/databases/db-getting-started).

:::

Aby uzyskać informacje o połączeniu SFTP z Twoim rozwiązaniem Web Cloud Databases, kliknij poniższe karty, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    W zakładce <code className="action">Przegląd</code> znajdź sekcję **SFTP**. Zawiera ona informacje wymagane do połączenia przez SFTP: **Użytkownik SFTP**, **Nazwa hosta SFTP** i **Port SFTP**.

    :::info
    Jeśli nie znasz hasła SFTP, kliknij <code className="action">Zmień hasło SFTP</code> na dole sekcji **SFTP**, aby je zmienić.

    :::

    <img className="thumbnail" alt="Sekcja SFTP przeglądu z użytkownikiem, nazwą hosta i portem SFTP" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sftp-connection-info.png" loading="lazy" />
  </Tab>
</Tabs>

Po uzyskaniu danych dostępowych SFTP połącz się za pośrednictwem klienta FTP (FileZilla, Cyberduck, WinSCP itp.).

W FileZilla przejdź w lewym górnym rogu do menu <code className="action">Plik</code>, a następnie kliknij <code className="action">Menedżer Stron</code>.

Kliknij <code className="action">Nowy adres</code> i wprowadź wcześniej uzyskane parametry.

<img className="thumbnail" alt="Menedżer Stron w FileZilla z parametrami połączenia SFTP" src="/images/assets/screens/other/web-tools/filezilla/site-manager.png" loading="lazy" />

Plik logów o nazwie `stdout.log` znajduje się w katalogu głównym.

Pobierz go na swoje urządzenie, aby go przejrzeć.

:::info
Dodatkowy plik logów o nazwie `slow-query.log` może pojawić się w katalogu głównym SFTP Twojego serwera Web Cloud Databases.
Plik ten zawiera historię wolnych zapytań wykonanych na Twoim serwerze Web Cloud Databases.

Domyślnie wartość w zmiennej **long_query_time** jest ustawiona na 1 sekundę w rozwiązaniach Web Cloud Databases.

Dzięki temu plikowi możesz zoptymalizować skrypty i zawartość baz danych, aby poprawić wydajność powiązanych usług.

:::

### Subskrypcja logów rozwiązania Web Cloud Databases w Logs Data Platform <a name="wcdb-ldp"></a>

[Logs Data Platform](/links/manage-operate/ldp) to platforma do zarządzania logami. Ułatwia agregację i zarządzanie logami, szczególnie w przypadku infrastruktur generujących dużą ilość logów.

Działa poprzez pobieranie logów generowanych przez Twoją infrastrukturę, strony internetowe lub aplikacje, na przykład w celu:

- przechowywania;
- wyświetlania w panelach monitorujących w czasie rzeczywistym;
- umożliwienia użytkownikom wykonywania złożonych zapytań;
- filtrowania według daty, aplikacji, typu lub zawartości.

Aby uzyskać więcej informacji na temat Logs Data Platform, zapoznaj się z naszym przewodnikiem [Wprowadzenie do Logs Data Platform](/guides/manage-and-operate/observability/logs-data-platform/introduction) (EN).

Ponieważ rozwiązania [Web Cloud Databases](/links/web/databases) mogą być używane z wieloma usługami (hostingi www, VPS, serwery dedykowane itp.), mogą one, oprócz dostępnych już logów w czasie rzeczywistym, być subskrybowane w Logs Data Platform za pośrednictwem strumieni danych.

Aby subskrybować rozwiązanie Web Cloud Databases do strumienia danych w Logs Data Platform, możliwe są 2 scenariusze.

**Kliknij każdy przypadek, aby wyświetlić jego zawartość.**

Najpierw je utwórz, korzystając z naszego przewodnika [Szybki start z Logs Data Platform](/guides/manage-and-operate/observability/logs-data-platform/getting-started-quick-start) (EN), a następnie postępuj zgodnie z przypadkiem 1.
