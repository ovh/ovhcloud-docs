Chcesz korzystać z PostgreSQL? Sprawdź, jak w prosty sposób tworzyć bazy danych i nimi zarządzać!

## Informacje ogólne

### Wymagania początkowe

- Posiadanie instancji Web Cloud Databases
- Zapoznanie się z przewodnikiem na temat [Web Cloud Databases](/guides/web-cloud/databases/db-getting-started)

### Czym jest baza danych PostgreSQL?
PostgreSQL to system zarządzania relacyjnymi bazami danych oraz obiektami (SGBDRO).

Jest to mocny i skalowalny system, który może obsługiwać duże ilości danych. Dysponuje on również bardzo aktywną społecznością.

## Logowanie do bazy danych

:::info
Pamiętaj, że ta usługa nie daje dostępu do Hosta, lecz do baz danych, które są na nim hostowane. Podstawowe polecenia SQL działają bez problemu, a oprogramowanie takie jak HeidiSQL czy SQuirreL SQL jest w pełni kompatybilne.

:::

Aby zalogować się do bazy danych, upewnij się, że masz:

- adres instancji bazy danych
- port bazy danych
- nazwę użytkownika bazy danych
- hasło do bazy danych
- nazwę bazy danych

Wszystkie te informacje są dostępne w konsoli OVHcloud, na stronie <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.

Dostępny jest również przewodnik: [Pierwsze kroki z usługą Web Cloud Databases](/guides/web-cloud/databases/db-getting-started).

### Logowanie z linii poleceń

```bash
psql --host=server --port=port --username=user --password database_name
```

### Logowanie poprzez skrypt PHP

```php
1. <?php
2. $myPDO = new PDO('pgsql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

## Dostępne rozszerzenia PostgreSQL

Web Cloud Databases udostępnia kilka rozszerzeń PostgreSQL, które pozwalają dodać dodatkowe funkcje do Twoich baz danych. Możesz je włączać i wyłączać w konsoli OVHcloud, w zakładce <code className="action">Bazy danych</code> Twojej instancji.

Listę dostępnych rozszerzeń znajdziesz w przewodniku "[Włączanie rozszerzeń PostgreSQL](/guides/web-cloud/databases/db-enable-postgresql-extensions#dostępne-rozszerzenia)".

## Eksportowanie i importowanie bazy danych PostgreSQL

- **Eksportowanie bazy danych z linii poleceń**

```bash
pg_dump --host=server --port=port --username=user --password database_name > database_name.sql
```

- **Importowanie bazy danych z linii poleceń**

```bash
psql --host=server --port=port --username=user --password database_name < database_name.sql
```

:::info
W niektórych przypadkach pamięć RAM dostępna w instancji Web Cloud Databases może nie wystarczyć do przeprowadzenia eksportu lub importu. W takim przypadku zalecamy skorzystanie z narzędzia do importu udostępnionego przez OVHcloud. W razie potrzeby zapoznaj się z dokumentacją "[Pierwsze kroki z usługą Web Cloud Databases](/guides/web-cloud/databases/db-getting-started#import-bazy-danych)".

:::
