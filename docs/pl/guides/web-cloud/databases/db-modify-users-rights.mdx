## Wprowadzenie

Rozwiązanie [Web Cloud Databases](https://www.ovhcloud.com/pl/web-cloud/databases/) może zawierać kilka baz danych. Pozwala na zdefiniowanie jednego lub kilku użytkowników do zarządzania bazami danych i korzystania z nich. Ci użytkownicy mogą mieć wyższe lub niższe uprawnienia w zależności od ich ról na poziomie baz danych.
Podczas korzystania z produktu może być konieczna zmiana uprawnień użytkownika w rozwiązaniu [Web Cloud Databases](https://www.ovhcloud.com/pl/web-cloud/databases/).

**Dowiedz się, jak zmienić uprawnienia użytkownika w rozwiązaniu Web Cloud Databases.**

## Wymagania początkowe

- Posiadanie rozwiązania [Web Cloud Databases](https://www.ovhcloud.com/pl/web-cloud/databases/) oraz jednego lub kilku użytkowników.

## W praktyce

:::info
Aby utworzyć nowego użytkownika w rozwiązaniu Web Cloud Databases, zapoznaj się z sekcją **Tworzenie użytkownika** w naszym przewodniku "[Tworzenie baz danych i użytkowników na serwerze bazy danych](/guides/web-cloud/databases/db-create-databases-users)".

:::

Kliknij poniższe zakładki, aby wyświetlić kolejno każdy z **4** kroków.

<Tabs>
  <Tab label="Etap 1">
    Przejdź na stronę <ManagerLink to="/#/web/web/private_database">Web Cloud Databases</ManagerLink>, następnie wybierz odpowiednie rozwiązanie.

    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 2">
    Na wyświetlonej stronie kliknij zakładkę <code className="action">Użytkownicy i uprawnienia</code>.

    <img className="thumbnail" alt="Users and rights" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/users-and-rights.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 3">
    Kliknij przycisk <code className="action">...</code> po prawej stronie wybranego użytkownika, a następnie <code className="action">Zarządzanie uprawnieniami</code>.

    <img className="thumbnail" alt="Manage rights" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-rights-user-alone.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 4">
    Na nowej stronie znajdziesz tabelę z wszystkimi bazami danych dostępnymi w rozwiązaniu Web Cloud Databases. Tabela ta zawiera listę wszystkich uprawnień, którymi dysponuje użytkownik dla każdej bazy danych w rozwiązaniu Web Cloud Databases.

    <img className="thumbnail" alt="Changing user rights" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/users-and-rights/changing-user-rights-db-alone.png" loading="lazy" />

Tutaj możesz zmienić uprawnienia użytkownika dla każdej bazy danych. W tym celu, dla każdej bazy danych, której dotyczy operacja, kliknij puste kółka odpowiadające uprawnieniom, które chcesz przedefiniować dla użytkownika. Zmiana zostanie zastosowana w ciągu kilku chwil.
  </Tab>
</Tabs>
