## Wprowadzenie

Rozwiązanie [Web Cloud Databases](/links/web/databases) może zawierać kilka baz danych. Pozwala na zdefiniowanie jednego lub kilku użytkowników do zarządzania bazami danych i korzystania z nich. Ci użytkownicy mogą mieć wyższe lub niższe uprawnienia w zależności od ich ról na poziomie baz danych.
Podczas korzystania z produktu może być konieczna zmiana uprawnień użytkownika w rozwiązaniu [Web Cloud Databases](/links/web/databases).

**Dowiedz się, jak zmienić uprawnienia użytkownika w rozwiązaniu Web Cloud Databases.**

## Wymagania początkowe

- Posiadanie rozwiązania [Web Cloud Databases](/links/web/databases) oraz jednego lub kilku użytkowników.

[[cpnav:web-cloud-databases]]

## W praktyce

:::info
Aby utworzyć nowego użytkownika w rozwiązaniu Web Cloud Databases, zapoznaj się z sekcją **Tworzenie użytkownika** w naszym przewodniku "[Tworzenie baz danych i użytkowników na serwerze baz danych](/guides/web-cloud/databases/db-create-databases-users)".

:::

Kliknij poniższe zakładki, aby wyświetlić kolejno **4** kroki.

<Tabs>
  <Tab label="Etap 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, a następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 2">
    Na wyświetlonej stronie kliknij zakładkę <code className="action">Użytkownicy i uprawnienia</code>.

    <img className="thumbnail" alt="Karta Użytkownicy i uprawnienia instancji Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 3">
    Każdy użytkownik jest wyświetlany w osobnej ramce ze swoją nazwą. W ramce odpowiedniego użytkownika kliknij przycisk <code className="action">⋮</code> znajdujący się po prawej stronie napisu **Dodatkowe działania**, a następnie <code className="action">Zarządzaj uprawnieniami</code>.

    <img className="thumbnail" alt="Menu Dodatkowe działania użytkownika z pozycją Zarządzaj uprawnieniami" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 4">
    Po prawej stronie otworzy się panel o tytule **Uprawnienia dla** z nazwą użytkownika. Zawiera on listę wszystkich baz danych dostępnych w rozwiązaniu Web Cloud Databases i dla każdej z nich wskazuje, w menu rozwijanym po jej prawej stronie, poziom uprawnień, jaki posiada użytkownik.

    <img className="thumbnail" alt="Panel uprawnień użytkownika, jeden poziom na bazę danych" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />

    Tutaj możesz zmienić uprawnienia użytkownika dla każdej bazy danych. W tym celu dla każdej bazy danych, której dotyczy zmiana, wybierz w menu rozwijanym tej bazy poziom uprawnień, który chcesz przypisać użytkownikowi. Zmiana jest stosowana natychmiast: wyświetlany jest komunikat **Uprawnienie zmienione**.
  </Tab>
</Tabs>
