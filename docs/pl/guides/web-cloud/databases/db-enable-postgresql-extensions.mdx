## Wprowadzenie

Rozszerzenia PostgreSQL to moduły, które wzbogacają Twoją bazę danych o dodatkowe funkcje: nowe typy danych, funkcje, operatory lub języki proceduralne. W rozwiązaniu Web Cloud Databases możesz włączyć zgodne rozszerzenia bezpośrednio z poziomu konsoli OVHcloud, bez używania wiersza poleceń.

**Z niniejszego przewodnika dowiesz się, jak włączyć dostępne rozszerzenia w bazie danych PostgreSQL hostowanej w rozwiązaniu Web Cloud Databases.**

## Wymagania początkowe

- Posiadanie [instancji Web Cloud Databases](/links/web/databases) korzystającej z **PostgreSQL**.
- Zapoznanie się z przewodnikiem [Pierwsze kroki z PostgreSQL](/guides/web-cloud/databases/db-getting-started-postgresql).

## W praktyce

### Włączanie rozszerzenia

Kliknij poniższe karty, aby wyświetlić kolejne **3** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, następnie wybierz odpowiednią instancję.

    <img className="thumbnail" alt="Strona Web Cloud DB z listą instancji na koncie" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Kliknij zakładkę <code className="action">Bazy danych</code>. W kolumnie **Rozszerzenia** kliknij ikonę w kształcie puzzla przy odpowiedniej bazie danych.

    <img className="thumbnail" alt="Ikona w kolumnie Rozszerzenia w tabeli baz danych" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/extensions-column.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    Po prawej stronie otworzy się panel o tytule **Rozszerzenia** z nazwą bazy danych. Odszukaj żądane rozszerzenie na liście, w razie potrzeby korzystając z pola **Szukaj**.

    Następnie zaznacz pole wyboru rozszerzenia w kolumnie **Status**. Włączenie następuje natychmiast, bez potwierdzenia. Wyświetli się komunikat **Rozszerzenie włączone**.

    <img className="thumbnail" alt="Panel Rozszerzenia bazy danych PostgreSQL" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/extensions-panel.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
Włączenie rozszerzenia dotyczy wybranej bazy danych. Aby włączyć je w innej bazie danych na tym samym serwerze, powtórz operację, wybierając odpowiednią bazę danych.

:::

### Dostępne rozszerzenia

Lista oferowanych rozszerzeń zależy od wersji PostgreSQL używanej przez Twój serwer. Rozszerzenia dostępne dla Twojej wersji są wyświetlane w panelu **Rozszerzenia** każdej bazy danych.

Poniżej znajduje się lista dostępnych rozszerzeń:

| Rozszerzenie | Opis |
|---|---|
| `address_standardizer` | Służy do analizy adresu i rozłożenia go na części składowe. Zwykle używane do obsługi etapu normalizacji adresu w geokodowaniu. |
| `autoinc` | Funkcje do automatycznego zwiększania wartości pól. |
| `bloom` | Metoda dostępu bloom – indeks oparty na pliku sygnatur. |
| `btree_gin` | Obsługa indeksowania popularnych typów danych w GIN. |
| `btree_gist` | Obsługa indeksowania popularnych typów danych w GiST. |
| `citext` | Typ danych dla ciągów znaków bez rozróżniania wielkości liter. |
| `cube` | Typ danych dla wielowymiarowych kostek. |
| `earthdistance` | Obliczanie odległości po wielkim okręgu na powierzchni Ziemi. |
| `fuzzystrmatch` | Określa podobieństwa i odległość między ciągami znaków. |
| `hstore` | Typ danych do przechowywania zbiorów par (klucz, wartość). |
| `intarray` | Funkcje, operatory i obsługa indeksów dla jednowymiarowych tablic liczb całkowitych. |
| `isn` | Typy danych dla międzynarodowych standardów numeracji produktów. |
| `ltree` | Typ danych dla hierarchicznych struktur drzewiastych. |
| `moddatetime` | Funkcje do śledzenia czasu ostatniej modyfikacji. |
| `pg_trgm` | Pomiar podobieństwa tekstu i wyszukiwanie w indeksie na podstawie trigramów. |
| `pgcrypto` | Funkcje kryptograficzne. |
| `postgis` | Przestrzenne typy danych i funkcje PostGIS (geometria, geografia i raster). |
| `postgis_raster` | Rastrowe typy danych i funkcje PostGIS. |
| `postgis_tiger_geocoder` | Geokoder tiger i geokoder odwrotny PostGIS. |
| `postgis_topology` | Przestrzenne typy danych i funkcje topologii PostGIS. |
| `seg` | Typ danych do reprezentowania odcinków linii lub przedziałów zmiennoprzecinkowych. |
| `unaccent` | Słownik wyszukiwania tekstu, który usuwa akcenty. |
| `uuid-ossp` | Generuje uniwersalne unikatowe identyfikatory (UUID). |
| `xml2` | Zapytania XPath i XSLT. |
