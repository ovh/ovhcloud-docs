## Wprowadzenie

Rozwiązania [Web Cloud Databases](/links/web/databases) można włączyć bezpłatnie w naszej [ofercie hostingu](/links/web/hosting) Performance, Agency, Agency Plus i Agency Max. W takim przypadku są one przypisane do hostingu, z którego zostały aktywowane. Może zaistnieć konieczność odłączenia rozwiązania Web Cloud Databases od hostingu, do którego jest ono przypisane.

**Dowiedz się, jak odłączyć rozwiązanie Web Cloud Databases od hostingu.**

## Wymagania początkowe

- Posiadanie [instancji Web Cloud Databases](/links/web/databases) powiązanej z ofertą [hostingu www](/links/web/hosting) Performance, Agency, Agency Plus lub Agency Max.
- Posiadanie statusu przynajmniej kontaktu "[Administrator](/guides/account-and-service-management/account-information/managing-contacts)" dla usług, w odniesieniu do których chcesz podjąć działania.

[[cpnav:web-hosting]]

## W praktyce

Kliknij poniższe zakładki, aby wyświetlić kolejne **3** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/hosting">Hosting</ManagerLink>, następnie wybierz odpowiedni hosting WWW.

    <img className="thumbnail" alt="Strona Hosting z listą hostingów na koncie" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    W sekcji **Bazy danych** znajduje się pozycja **Web Cloud DB**. Kliknij przycisk <code className="action">⋮</code> po jej prawej stronie, a następnie <code className="action">Odłącz moją bazę danych PrivateSQL</code>.

    <img className="thumbnail" alt="Sekcja Bazy danych i menu wiersza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 3">
    Na nowej stronie, która się wyświetli, wybierz w sekcji **Zobowiązanie** okres dla rozwiązania Web Cloud Databases. Sekcja **Podsumowanie** przypomina, że Twoja baza danych będzie odtąd rozliczana według standardowej ceny i że ta operacja jest nieodwracalna. Kliknij <code className="action">Dalej</code>, a następnie wykonaj wskazane kroki aż do płatności.

    <img className="thumbnail" alt="Strona Odłącz moją bazę danych PrivateSQL z ofertą, zobowiązaniem i podsumowaniem" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/detach-web-cloud-db.png" loading="lazy" />
  </Tab>
</Tabs>

Po wykonaniu tych 3 kroków i opłaceniu zamówienia rozwiązanie Web Cloud Databases zostanie odłączone w ciągu maksymalnie kilku godzin.
