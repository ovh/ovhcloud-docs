## Wprowadzenie

**Managed Hosting for WordPress** to oferowane przez OVHcloud rozwiązanie zarządzanego hostingu WordPress: konserwacja techniczna (aktualizacje, bezpieczeństwo, kopie zapasowe) jest obsługiwana automatycznie. Oferta umożliwia zarządzanie nazwami domen z poziomu interfejsu OVHcloud, bez ręcznej interwencji. Możesz powiązać nazwę domeny lub subdomenę z każdą ze swoich stron WordPress, niezależnie od jej pochodzenia.

W zależności od sytuacji dostępne są dwie procedury:

- **Wewnętrzna nazwa domeny**: nazwa domeny jest już obecna na Twoim koncie OVHcloud.
- **Zewnętrzna nazwa domeny**: nazwa domeny jest zarządzana u innego rejestratora.

**Dowiedz się, jak dodawać, modyfikować lub usuwać nazwy domen Managed Hosting for WordPress z poziomu panelu klienta OVHcloud.**

## Wymagania początkowe

- Posiadanie aktywnej oferty **Managed Hosting for WordPress** z co najmniej jedną utworzoną stroną WordPress.
- Dla zewnętrznej nazwy domeny: dostęp do aktywnej strefy DNS (Domain Name System) u Twojego obecnego dostawcy.

## W praktyce

### 1 - Dostęp do zarządzania nazwami domen

Dodanie nazwy domeny odbywa się z poziomu zakładki <code className="action">Moje strony</code> Twojego zasobu Managed Hosting for WordPress. Kliknij na poniższe zakładki, aby kolejno wyświetlić każdy z **4** etapów.

<Tabs>
  <Tab label="Etap 1">
    Przejdź na stronę <ManagerLink to="/beta/#/web-cloud/wordpress">Managed hosting for WordPress</ManagerLink> w panelu klienta OVHcloud.

    <img className="thumbnail" alt="Widok zasobu Managed Hosting for WordPress na liście hostingów WordPress" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/managed-hosting-for-wordpress.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 2">
    Kliknij <code className="action">Zarządzaj</code> pod wybranym zasobem.

    <img className="thumbnail" alt="Zasób Managed Hosting for WordPress w datagrid z wyróżnionym przyciskiem Zarządzaj" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/manage-ressource-button.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 3">
    Kliknij zakładkę <code className="action">Moje strony</code>. Datagrid wyświetla Twoje strony WordPress wraz z, dla każdej strony, powiązaną domeną i dostępnymi akcjami.

    <img className="thumbnail" alt="Zakładka Moje strony wyświetlająca datagrid stron WordPress" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/managed-hosting-for-wordpress-my-sites-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 4">
    Po prawej stronie wybranej strony WordPress kliknij przycisk <code className="action">⋮</code>, a następnie <code className="action">Dodaj domenę</code>.

    <img className="thumbnail" alt="Przycisk Dodaj domenę w menu akcji strony WordPress w datagrid" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/adding-domain.png" loading="lazy" />

</Tabs>

:::info
**Pierwsza dodana nazwa domeny** do strony WordPress automatycznie staje się **główną nazwą domeny**. Możesz dodać kolejne później (multi-domena) i zmienić główną nazwę domeny z poziomu tego samego menu.
:::

### 2 - Dodawanie nazwy domeny

<details>

<Tabs>

    <img className="thumbnail" alt="Lista rozwijana nazw domen OVHcloud dostępnych na koncie" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/select-ovh-domain.png" loading="lazy" />

  <Tab label="Etap 3">

</details>

<details>

<summary>Dodaj zewnętrzną nazwę domeny</summary>

**Zewnętrzna** nazwa domeny jest zarządzana u innego rejestratora (Gandi, Namecheap, Google Domains itp.). Musisz ręcznie zmodyfikować swoją strefę DNS.

Po otwarciu tunelu dodawania wybierz procedurę zewnętrzną, aby użyć nazwy domeny zarządzanej u innego rejestratora. Kliknij na poniższe zakładki, aby kolejno wyświetlić każdy z **4** etapów.

<Tabs>
  <Tab label="Etap 1">
    W tunelu dodawania zaznacz <code className="action">Powiąż zewnętrzną domenę</code>.

    <img className="thumbnail" alt="Tunel dodawania na etapie wyboru procedury Powiąż zewnętrzną domenę" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/attach-external-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 2">
    Wprowadź swoją nazwę domeny (na przykład: `domain.tld`) w przewidzianym polu.

    <img className="thumbnail" alt="Pole wprowadzania zewnętrznej nazwy domeny z przykładową domeną wpisaną" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/associate-external-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 3">
    Interfejs wyświetla rekordy DNS do dodania u Twojego obecnego dostawcy. Zaloguj się do interfejsu DNS swojego dostawcy i dodaj wskazane rekordy (zazwyczaj rekord DNS typu **A** lub **CNAME**: **C**anonical **NAME**).

    {/* DRAFT: To screenshot — uchwycić wartości DNS do skonfigurowania (rekord A lub CNAME) wyświetlone przez interfejs OVHcloud */}
  </Tab>
  <Tab label="Etap 4">
    Po wykonaniu konfiguracji DNS u dostawcy wróć do panelu klienta OVHcloud i kliknij <code className="action">Potwierdź</code>.

    {/* DRAFT: To screenshot — uchwycić przycisk Potwierdź na końcu tunelu dodawania zewnętrznej domeny */}
  </Tab>
</Tabs>

:::warning
Propagacja DNS zewnętrznej nazwy domeny może trwać do **24 do 48 godzin** w zależności od dostawcy. Twoja strona WordPress nie będzie dostępna pod tą nazwą domeny w tym okresie.
:::

:::info
Certyfikat SSL (Secure Sockets Layer) jest generowany automatycznie po walidacji propagacji DNS. Nie jest wymagana żadna ręczna interwencja po Twojej stronie.
:::

</details>

**Efekty usunięcia:**

- **Twoja strona WordPress pozostaje nietknięta**: zostaje przerwane jedynie powiązanie z nazwą domeny, strona nadal działa.
- **Stały techniczny adres URL pozostaje dostępny**: Twoja strona WordPress jest nadal osiągalna pod tym adresem URL, nawet bez nazwy domeny.
- **Certyfikat SSL zostaje cofnięty**: nie obejmuje już usuniętej nazwy domeny.
- **Pozycjonowanie SEO może zostać naruszone**: jeśli nazwa domeny była zindeksowana przez wyszukiwarki, jej usunięcie wpływa na pozycjonowanie.
- **Pamiętaj o sprawdzeniu usług e-mail**: adresy powiązane z tą nazwą domeny mogą zostać naruszone usunięciem.

:::info
**Przypadek szczególny — jedyna główna nazwa domeny:** jeśli usuniesz jedyną główną nazwę domeny strony WordPress, Twoja strona WordPress automatycznie przełączy się na swój **stały techniczny adres URL**. Ten adres URL jest zawsze dostępny i nigdy nie zostaje usunięty, nawet w przypadku braku powiązanej domeny.
:::

### Stały techniczny adres URL

Każda strona Managed Hosting for WordPress dysponuje **stałym technicznym adresem URL**, niezależnym od jakiejkolwiek nazwy domeny. Ten adres URL jest generowany automatycznie przy tworzeniu strony WordPress i nie można go usunąć.

<img className="thumbnail" alt="Widok datagrid Moje strony wyświetlający nazwę domeny i techniczny adres URL strony WordPress" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/show-domain-linked-to-a-site.png" loading="lazy" />

Umożliwia:

- Dostęp do Twojej strony WordPress **w każdych okolicznościach**, nawet bez powiązanej nazwy domeny.
- Przetestowanie Twojej strony WordPress przed skierowaniem na nią nazwy domeny.
- Utrzymanie zapasowego dostępu w razie problemu z DNS.

:::info
Techniczny adres URL ma formę `*.mcms.ovh.net` lub podobną. Znajdź go w datagrid <code className="action">Moje strony</code>, naprzeciw każdej strony WordPress.
:::
