## Wprowadzenie

**MainWP** to samoobsługowy panel zarządzania o otwartym kodzie źródłowym, zintegrowany z ofertą **Managed Hosting for WordPress**. Pozwala zarządzać wszystkimi stronami WordPress z poziomu jednego, scentralizowanego interfejsu, bez konieczności korzystania z administracji każdej witryny z osobna.

:::info
MainWP jest narzędziem zewnętrznym, niezależnym od OVHcloud. OVHcloud udostępnia dostęp do interfejsu MainWP, lecz nie zapewnia wsparcia funkcjonalnego tego narzędzia. W razie zaawansowanych pytań dotyczących funkcji MainWP, należy zapoznać się z [oficjalną dokumentacją MainWP](https://docs.mainwp.com/).
:::

**Dowiedz się, jak zarządzać stronami WordPress przy użyciu MainWP.**

## Wymagania początkowe

- Posiadanie aktywnej oferty **Managed Hosting for WordPress** z co najmniej jedną utworzoną stroną WordPress.

### 2. Zrozumieć interfejs MainWP

Interfejs MainWP jest zorganizowany wokół 2 głównych pojęć:

- **Panel (Dashboard)**: centralny widok zawierający listę wszystkich podłączonych stron wraz z ich statusem.
- **Strony podrzędne (Child Sites)**: każda ze stron WordPress zarządzanych przez MainWP.

{/* DRAFT: To screenshot — uchwycić panel MainWP z listą podłączonych stron, wskaźnikami statusu (dostępne aktualizacje, status połączenia) i menu bocznym */}

Panel obejmuje 3 główne obszary:

- **Lista stron**: wyświetla wszystkie strony WordPress wraz z ich statusem (online/offline, dostępne aktualizacje).
- **Wskaźniki statusu**: liczba oczekujących aktualizacji (WordPress core, wtyczki, motywy).
- **Menu boczne**: nawigacja do sekcji Strony, Aktualizacje, Wtyczki, Bezpieczeństwo itd.

### 3. Zarządzanie stronami WordPress — działania indywidualne

#### 3.1 Dostęp do administracji strony WordPress

{/* DRAFT: To screenshot — uchwycić listę stron w MainWP z przyciskiem "WP Admin" lub odpowiednikiem umożliwiającym dostęp do administracji konkretnej strony */}

- **Znajdź stronę WordPress**: na liście stron WordPress w panelu MainWP odszukaj stronę WordPress, którą chcesz zarządzać.
- **Otwórz administrację**: kliknij <code className="action">WP Admin</code> obok strony WordPress, aby uzyskać bezpośredni dostęp do jej panelu WordPress.

#### 3.2 Indywidualna aktualizacja strony WordPress

{/* DRAFT: To screenshot — uchwycić widok szczegółów strony w MainWP z wyświetlonymi dostępnymi aktualizacjami (WordPress core, wtyczki, motywy) i przyciskiem aktualizacji */}

- **Otwórz szczegóły strony WordPress**: kliknij nazwę strony WordPress na liście.
- **Przejrzyj dostępne aktualizacje**: ekran szczegółów wyświetli oczekujące aktualizacje (WordPress core, wtyczki, motywy).
- **Aktualizuj**: kliknij <code className="action">Aktualizuj</code> obok każdego elementu lub <code className="action">Aktualizuj wszystko</code>, aby zastosować wszystkie aktualizacje jednocześnie.

:::warning
Wykonaj kopię zapasową lub snapshot strony WordPress przed każdą znaczącą aktualizacją. Niektóre aktualizacje wtyczek mogą powodować niezgodności. Zapoznaj się z przewodnikiem "[Tworzenie kopii zapasowych stron WordPress za pomocą MainWP](/guides/web-cloud/web-hosting/mainwp-backup)", aby utworzyć punkt przywracania.
:::

### 4. Akcje grupowe (bulk actions)

Akcje grupowe pozwalają zastosować operację do wielu stron WordPress jednocześnie, bez konieczności powtarzania jej dla każdej z nich.

{/* DRAFT: To screenshot — uchwycić interfejs wielokrotnego wyboru w MainWP (pola wyboru przed każdą stroną) i rozwijane menu dostępnych akcji grupowych */}

#### 4.1 Wybór wielu stron WordPress

- **Wyświetl listę stron WordPress**: z poziomu panelu MainWP przejdź do sekcji <code className="action">Strony</code>.
- **Wybierz docelowe strony WordPress**: zaznacz pola obok każdej strony WordPress, którą chcesz uwzględnić w akcji grupowej. Użyj <code className="action">Zaznacz wszystkie</code>, aby objąć wszystkie strony WordPress.

#### 4.2 Aktualizacja wielu stron WordPress jednocześnie

{/* DRAFT: To screenshot — uchwycić ekran aktualizacji grupowej z wyborem stron i przyciskiem "Zastosuj aktualizacje" lub odpowiednikiem */}

- **Wybierz strony WordPress**: zaznacz strony WordPress do aktualizacji (zob. §4.1).
- **Uruchom aktualizację grupową**: kliknij <code className="action">Aktualizacje</code> w menu akcji grupowych.
- **Wybierz komponenty do aktualizacji**: zaznacz odpowiednie elementy (WordPress core, wtyczki, motywy).
- **Zastosuj**: kliknij <code className="action">Aktualizuj</code>. MainWP zastosuje aktualizacje kolejno na każdej wybranej stronie WordPress.

:::info
Aktualizacje są stosowane w kolejności listy, co może zająć kilka minut w zależności od liczby stron WordPress.
:::

#### 4.3 Instalacja lub aktywacja wtyczki na wielu stronach WordPress

{/* DRAFT: To screenshot — uchwycić sekcję "Rozszerzenia" lub "Wtyczki" w MainWP z opcją instalacji/aktywacji grupowej i selektorem stron */}

- **Przejdź do zarządzania wtyczkami**: w menu MainWP kliknij <code className="action">Wtyczki</code> (lub **Rozszerzenia**).
- **Wybierz wtyczkę**: znajdź na liście wtyczkę do zainstalowania lub aktywacji.
- **Wybierz docelowe strony**: zaznacz strony WordPress, na których chcesz zastosować akcję.
- **Zastosuj**: kliknij <code className="action">Zainstaluj</code> lub <code className="action">Aktywuj</code>, zależnie od potrzeby.

#### 4.4 Inne dostępne akcje grupowe

- **Dezaktywacja wtyczki** na wszystkich wybranych stronach WordPress.
- **Usunięcie wtyczki** z wybranych stron WordPress.
- **Instalacja motywu** na wielu stronach WordPress jednocześnie.
- **Aktywacja motywu** na wybranych stronach WordPress.
- **Publikacja treści** (artykułu lub strony) na wielu stronach WordPress.

:::info
Niektóre zaawansowane akcje (raporty klientów, zaawansowany monitoring bezpieczeństwa, automatyczne kopie zapasowe) wymagają **rozszerzeń MainWP** (premium). Zapoznaj się z [listą rozszerzeń MainWP](https://docs.mainwp.com/).
:::

### 5. Jak monitorować status stron WordPress?

{/* DRAFT: To screenshot — uchwycić panel MainWP ze wskaźnikami statusu: strony online/offline, liczba oczekujących aktualizacji w podziale na kategorie, ewentualne alerty bezpieczeństwa */}

MainWP wyświetla stan kondycji stron WordPress w czasie rzeczywistym:

- **Strona WordPress online (zielona)**: strona WordPress odpowiada prawidłowo.
- **Strona WordPress offline (czerwona)**: strona WordPress jest niedostępna lub utracono połączenie z MainWP.
- **Dostępne aktualizacje**: liczba oczekujących aktualizacji (core / wtyczki / motywy).
- **Wykryte luki bezpieczeństwa**: wtyczka lub motyw zawierający znaną lukę bezpieczeństwa.

:::warning
Jeśli strona WordPress jest oznaczona jako "offline" w MainWP, nie oznacza to koniecznie, że jest niedostępna dla odwiedzających. Może to wskazywać na problem z połączeniem między MainWP a podrzędną stroną WordPress (wyłączona wtyczka Child Site, zmiana hasła itp.).
:::
