## Wprowadzenie

Rozwiązaniem **Managed Hosting for WordPress** możesz zarządzać w języku naturalnym z poziomu agenta AI (Claude Code, Codex itp.) dzięki protokołowi **MCP** (*Model Context Protocol*). Samodzielnie łączysz tylko jeden serwer: **MCP OVHcloud**. Twój agent AI używa go następnie do skonfigurowania dwóch pozostałych: **MCP for WordPress** do zarządzania treścią strony oraz **MainWP** do zarządzania wieloma stronami jednocześnie.

**Dowiedz się, jak połączyć agenta AI z MCP OVHcloud, a następnie zlecić mu konfigurację MCP for WordPress i MainWP.**

## Wymagania początkowe

- Aktywne rozwiązanie [Managed Hosting for WordPress](/guides/web-cloud/managed-hosting/wordpress) z co najmniej jedną stroną WordPress.
- Konto OVHcloud z dostępem do tego rozwiązania.
- Agent AI zgodny z MCP, **zainstalowany na Twoim komputerze** i zdolny do wykonywania poleceń, na przykład [Claude Code](https://code.claude.com/docs/en/overview) lub [Codex](https://learn.chatgpt.com/docs/codex/cli).
- W przypadku MainWP: [Node.js](https://nodejs.org/en) (wersja LTS) zainstalowany na Twoim komputerze.

:::info
Asystent AI używany w przeglądarce może połączyć się z MCP OVHcloud, ale nie z MCP for WordPress ani z MainWP: te dwa połączenia są zapisywane w konfiguracji agenta na Twoim komputerze.
:::

## Wstęp

Każdy z trzech serwerów MCP obsługuje część Twojego rozwiązania:

| Serwer MCP | Czym może zarządzać Twój agent AI | Jak go połączyć |
|---|---|---|
| **MCP OVHcloud** | Hostingiem: rozwiązania, strony, domeny, wersje PHP, cache CDN, logi, kopie zapasowe, hasła SFTP, phpMyAdmin i baza danych | Dodajesz go raz, a następnie logujesz się za pomocą konta OVHcloud |
| **MCP for WordPress** | Stroną WordPress: wpisy, strony, media, komentarze, menu, ustawienia, wtyczki, motywy i użytkownicy | Twój agent AI go konfiguruje, jedno połączenie na stronę |
| **MainWP** | Wieloma stronami jednocześnie z poziomu panelu MainWP zawartego w Twoim rozwiązaniu: aktualizacje, włączanie i wyłączanie wtyczek, motywów i tłumaczeń | Twój agent AI go konfiguruje, jedno połączenie dla całego rozwiązania |

**MCP for WordPress** to wtyczka OVHcloud preinstalowana na stronach Twojego rozwiązania. Udostępnia ona agentowi AI zamkniętą listę działań, które pozwalają zarządzać Twoją stroną WordPress.

## W praktyce

:::warning
Twój agent AI działa z uprawnieniami, które mu przyznasz: Twojego konta OVHcloud w przypadku MCP OVHcloud i konta administratora w przypadku MCP for WordPress. Sprawdź każde proponowane przez niego działanie, zanim je zatwierdzisz, zwłaszcza usunięcie, aktualizację lub publikację.
:::

### Etap 1: połączenie MCP OVHcloud

MCP OVHcloud to zdalny serwer hostowany przez OVHcloud. Nie przekazujesz mu żadnego hasła: Twój agent AI otwiera stronę logowania OVHcloud w przeglądarce, a Ty logujesz się tak samo jak do Panelu klienta.

Wybierz swojego agenta AI w poniższych zakładkach.

<Tabs>
  <Tab label="Claude Code">
    W terminalu wykonaj polecenie:

    ```bash
    claude mcp add --transport http --scope user ovhcloud https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    ```

    Uruchom Claude Code, wpisz `/mcp`, wybierz serwer **ovhcloud**, a następnie **Authenticate**. Zaloguj się za pomocą konta OVHcloud na stronie, która się otworzy.

    :::warning
    Nie dodawaj do tego polecenia opcji `--header`. Stały nagłówek `Authorization` uniemożliwia logowanie OVHcloud: serwer jest wyświetlany jako połączony, ale każde żądanie kończy się następnie błędem 401.
    :::
  </Tab>
  <Tab label="Codex">
    W terminalu wykonaj polecenia:

    ```bash
    codex mcp add ovhcloud --url https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    codex mcp login ovhcloud
    ```

    Zaloguj się za pomocą konta OVHcloud na stronie, która się otworzy, a następnie uruchom ponownie Codex.

    {/* DRAFT: To verify — Codex commands (add --url + mcp login) not tested against the OVHcloud hub */}
  </Tab>
  <Tab label="Inny agent AI">
    Dodaj zdalny serwer MCP (transport *streamable HTTP*) w konfiguracji agenta AI:

    - **URL**: `https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS`
    - **Uwierzytelnianie**: OAuth, bez nagłówka i tokena do wpisania.

    Rozpocznij uwierzytelnianie z poziomu agenta AI i zaloguj się za pomocą konta OVHcloud.
  </Tab>
</Tabs>

Aby sprawdzić połączenie, poproś agenta AI:

> Wyświetl moje rozwiązania Managed Hosting for WordPress i ich strony.

Agent odpowie, podając Twoje rozwiązania i adresy Twoich stron.

### Etap 2: konfiguracja MCP for WordPress dla strony

Poproś agenta AI, podając adres swojej strony:

> Skonfiguruj MCP for WordPress dla mojej strony www.example.com

Jeśli nie podasz strony, agent zaproponuje listę stron Twojego rozwiązania.

Konfiguracja przebiega następnie w ten sposób:

1. **Agent AI prosi Cię o zgodę** na utworzenie hasła aplikacji na stronie. To hasło pozwala mu działać na stronie jako administrator, w granicach działań MCP for WordPress. Aby wyrazić zgodę, odpowiedz wprost:

    > Tak, utwórz hasło aplikacji

    Powtórzenie pierwotnej prośby nie oznacza zgody: agent AI czeka na tę odpowiedź, zanim przejdzie dalej.

2. **Agent AI sprawdza, czy wtyczka MCP for WordPress jest włączona** na stronie. Jeśli nie jest, poinformuje Cię o tym: włącz **MCP for WordPress** w menu <code className="action">Wtyczki</code> panelu administracyjnego WordPress Twojej strony, a następnie ponów prośbę.
3. **Agent AI tworzy hasło aplikacji** za pośrednictwem MCP OVHcloud, a następnie dodaje połączenie ze stroną do swojej konfiguracji. Zatwierdź polecenie, które wykonuje.
4. **Załaduj ponownie serwery MCP**: w Claude Code wpisz `/mcp` i połącz się ponownie lub uruchom ponownie Claude Code; w przypadku Codex uruchom go ponownie. Narzędzia strony pojawią się dopiero po tym ponownym załadowaniu.

Aby sprawdzić połączenie, poproś:

> Wyświetl 5 ostatnich wpisów ze strony www.example.com

Powtórz ten etap dla każdej strony, którą chcesz zarządzać: każda strona ma własne połączenie.

### Etap 3: konfiguracja MainWP

Panel MainWP zawarty w Twoim rozwiązaniu zarządza wszystkimi Twoimi stronami. Poproś agenta AI:

> Skonfiguruj MCP MainWP

Konfiguracja przebiega tak samo jak w etapie 2:

1. **Agent AI prosi Cię o zgodę** na utworzenie hasła aplikacji w panelu MainWP. Aby wyrazić zgodę, odpowiedz:

    > Tak, utwórz hasło aplikacji

2. **Agent AI sprawdza, czy Node.js** jest zainstalowany na Twoim komputerze. Jeśli nie jest, zainstaluj wersję LTS ze strony [nodejs.org](https://nodejs.org/en), a następnie ponów prośbę.
3. **Agent AI tworzy hasło aplikacji** za pośrednictwem MCP OVHcloud, a następnie dodaje serwer MainWP do swojej konfiguracji. Zatwierdź polecenie, które wykonuje.
4. **Załaduj ponownie serwery MCP** tak jak w etapie 2.

Aby sprawdzić połączenie, poproś:

> Wyświetl strony z mojego panelu MainWP i wtyczki wymagające aktualizacji.

:::info
Serwer MainWP jest skonfigurowany tak, aby prosić Cię o potwierdzenie przed każdym działaniem, które modyfikuje Twoje strony.
:::

### Przykładowe prośby

Gdy trzy serwery są połączone, formułuj prośby tak, jak zwracałbyś się do współpracownika. Agent AI sam wybierze odpowiedni serwer.

| Chcesz… | Przykładowa prośba |
|---|---|
| Przygotować treść | "Napisz szkic wpisu o naszych letnich godzinach otwarcia dla www.example.com." |
| Moderować komentarze | "Wyświetl komentarze oczekujące na moderację na www.example.com." |
| Zaktualizować kilka stron | "Które wtyczki wymagają aktualizacji na wszystkich moich stronach?" |
| Zdiagnozować błąd | "Moja strona www.example.com zwraca błędy 500: przejrzyj logi i powiedz mi dlaczego." |
| Wyczyścić cache | "Wyczyść cache CDN strony www.example.com." |
| Wykonać kopię zapasową strony | "Wyeksportuj pełną kopię zapasową strony www.example.com." |

Przed opublikowaniem wpisu agent AI zapyta Cię, które konto WordPress ma być jego autorem.

### Odwołanie dostępu

W każdej chwili możesz odebrać dostęp przyznany agentowi AI:

- **MCP for WordPress**: w panelu administracyjnym WordPress strony otwórz <code className="action">Użytkownicy</code> > <code className="action">Profil</code>, a następnie usuń hasło aplikacji w sekcji **Hasła aplikacji**.
- **MainWP**: postępuj w ten sam sposób w panelu administracyjnym WordPress panelu MainWP.
- **MCP OVHcloud**: usuń serwer z konfiguracji agenta AI, na przykład poleceniem `claude mcp remove ovhcloud` w Claude Code.

### Rozwiązywanie problemów

- **Agent AI informuje, że nie może połączyć się ze stroną lub z MainWP**: sprawdź, czy działa na Twoim komputerze, a nie w przeglądarce.
- **Nowe narzędzia się nie pojawiają**: załaduj ponownie serwery MCP (`/mcp` w Claude Code) lub uruchom ponownie agenta AI.
- **Agent AI zatrzymuje się i zgłasza odrzucone działanie**: zablokował utworzenie hasła lub wykonanie polecenia. Zezwól na to działanie w jego ustawieniach uprawnień lub nazwij je wprost w swojej prośbie, na przykład "Utwórz hasło aplikacji na stronie www.example.com".
- **Żądania do MCP OVHcloud kończą się błędem 401**: usuń serwer, dodaj go ponownie bez nagłówka, a następnie ponów uwierzytelnianie.
