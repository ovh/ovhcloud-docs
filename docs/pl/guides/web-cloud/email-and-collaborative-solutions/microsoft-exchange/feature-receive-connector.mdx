## Wprowadzenie

Łącznik odbierania określa, które serwery mogą dostarczać e-maile do Twojej platformy Exchange i na jakich warunkach. Pozwala on umieścić przed platformą Exchange zewnętrzne rozwiązanie antyspamowe, nazywane również bramką filtrującą: <Tooltip term="mxRecord">rekordy MX</Tooltip> Twojej domeny wskazują na tę bramkę, która filtruje przychodzące e-maile, a następnie przekazuje je do Exchange.

Łącznik odbierania jest dostępny dla usług [Private Exchange](/links/web/emails-private-exchange) i [Trusted Exchange](/links/web/emails-trusted-exchange). Można go tworzyć i nim zarządzać wyłącznie za pomocą API OVHcloud.

**Ten przewodnik wyjaśnia, jak utworzyć, zmodyfikować, wyłączyć i usunąć łącznik odbierania na platformie Exchange za pomocą API OVHcloud.**

:::info
Aby kierować e-maile **wychodzące** z Twojej platformy przez serwer zewnętrzny, użyj zamiast tego łącznika wysyłania: zapoznaj się z naszym przewodnikiem "[Exchange - Konfiguracja łącznika wysyłania](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-send-connector)".
:::

## Wymagania początkowe

- Platforma [Private Exchange](/links/web/emails-private-exchange) lub [Trusted Exchange](/links/web/emails-trusted-exchange).
- Dane dostępowe API wygenerowane na <CreateToken rights="GET=/email/exchange&GET=/email/exchange/*&POST=/email/exchange/*&PUT=/email/exchange/*&PATCH=/email/exchange/*&DELETE=/email/exchange/*">stronie generowania tokenów OVHcloud</CreateToken>, z co najmniej uprawnieniem `GET` do `/email/exchange` oraz uprawnieniami `GET`, `POST`, `PUT`, `PATCH` i `DELETE` do `/email/exchange/*`. Skorzystaj z naszego przewodnika "[Pierwsze kroki z API OVHcloud](/guides/manage-and-operate/api/first-steps)".
- Adresy IP serwerów Twojego zewnętrznego rozwiązania antyspamowego, które będą dostarczać e-maile do Exchange. Poproś o nie dostawcę tego rozwiązania.

## W praktyce

### Informacje o domyślnym łączniku odbierania

Każda platforma Exchange posiada domyślny łącznik odbierania. Należy on do Exchange: nie możesz go zmodyfikować ani usunąć, możesz go jedynie włączyć lub wyłączyć. W API jego właściwość `default` ma wartość `true`.

:::warning
**Nie wyłączaj domyślnego łącznika odbierania.** Jeśli żaden inny łącznik nie ma zastosowania, jego wyłączenie zatrzymuje odbieranie wszystkich e-maili na platformie.
:::

### Znajdowanie parametrów ścieżki

Wywołania dotyczące łącznika odbierania wymagają nazwy organizacji (`organizationName`) i nazwy usługi (`exchangeService`) Twojej platformy. Pobierz je po kolei: pierwsze z poniższych wywołań zwraca organizację, której potrzebuje drugie.

**1. Organizacja** (`organizationName`)

Wyświetl listę organizacji Exchange Twojego konta za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange"} />

**2. Usługa** (`exchangeService`)

Wyświetl listę usług Exchange w organizacji za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service"} />

### Tworzenie łącznika odbierania

Utwórz łącznik za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="POST" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/receiveConnector"} regions={["eu"]} />

Wypełnij następujące pola w treści żądania. Wymagane są tylko pola `name`, `remoteIpRanges` i `requireTls`.

| Pole | Typ | Opis |
|---|---|---|
| `name` | string | Nazwa łącznika, maksymalnie 255 znaków |
| `remoteIpRanges` | string[] | Adresy IP serwerów uprawnionych do dostarczania e-maili przez ten łącznik (patrz niżej) |
| `requireTls` | boolean | `true`, aby wymagać TLS dla każdego e-maila odebranego przez ten łącznik |
| `maxMessageSize` | long | Opcjonalne. Maksymalny rozmiar e-maila odebranego przez ten łącznik, w MB |
| `enabled` | boolean | Opcjonalne. `true`, aby włączyć łącznik od razu po jego utworzeniu (domyślnie `false`) |

Każdy wpis `remoteIpRanges` może być:

- pojedynczym adresem IP, na przykład `203.0.113.10`;
- siecią w notacji CIDR, na przykład `203.0.113.0/28`;
- zakresem adresów "początek-koniec", z uwzględnieniem granic, na przykład `203.0.113.10-203.0.113.20`.

Akceptowane są zarówno adresy IPv4, jak i IPv6.

:::warning
**Ograniczenia `remoteIpRanges`**

- Ten sam adres IP nie może należeć do dwóch łączników odbierania platformy.
- Cała lista, po połączeniu jej wpisów przecinkami, nie może przekraczać 255 znaków. Zamiast długiej listy pojedynczych adresów użyj sieci CIDR.

:::

Wywołanie zwraca zadanie: łącznik zostanie utworzony po zakończeniu tego zadania.

### Wyświetlanie listy i szczegółów łączników odbierania

Wyświetl listę łączników odbierania platformy, w tym łącznika domyślnego, za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/receiveConnector"} regions={["eu"]} />

Wywołanie zwraca listę identyfikatorów łączników (`id`). Wyświetl szczegóły łącznika za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/receiveConnector/\{id\}"} regions={["eu"]} />

Oprócz pól podawanych przy tworzeniu odpowiedź zawiera pole `id`, czyli identyfikator łącznika, oraz pole `default`, które ma wartość `true` w przypadku domyślnego łącznika odbierania.

### Modyfikacja łącznika odbierania

Aby zmodyfikować jedno lub kilka pól bez zmiany pozostałych, użyj poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="PATCH" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/receiveConnector/\{id\}"} regions={["eu"]} />

Aby zastąpić całą konfigurację łącznika, wypełnij wszystkie pola w poniższym wywołaniu API:

<Api version="v1" section="/email/exchange" method="PUT" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/receiveConnector/\{id\}"} regions={["eu"]} />

:::info
Pole `remoteIpRanges` zastępuje zapisaną listę w całości. Aby dodać adres IP, wyślij pełną listę: istniejące adresy i nowy adres.
:::

Aby włączyć lub wyłączyć łącznik, zmień jego pole `enabled`. W przypadku domyślnego łącznika odbierania jest to jedyne pole, które możesz zmienić: zapoznaj się z ostrzeżeniem w sekcji "[Informacje o domyślnym łączniku odbierania](#informacje-o-domyślnym-łączniku-odbierania)".

Każda zmiana zwraca zadanie: zostanie ona zastosowana po zakończeniu tego zadania.

### Usuwanie łącznika odbierania

Usuń łącznik za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="DELETE" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/receiveConnector/\{id\}"} regions={["eu"]} />

Wywołanie zwraca zadanie: łącznik zostanie usunięty po zakończeniu tego zadania. Nie możesz usunąć domyślnego łącznika odbierania.
