## Wprowadzenie

Eksport skrzynki pocztowej do pliku w formacie Personal Storage Table (PST) daje Ci lokalną kopię jej danych. Skorzystaj z tej kopii, aby zarchiwizować skrzynkę pocztową przed usunięciem konta, przekazać dane po odejściu pracownika, przenieść je do innej usługi e-mail lub spełnić obowiązek przechowywania danych. Microsoft Exchange w OVHcloud może wyeksportować skrzynkę pocztową po stronie serwera: zlecasz eksport, OVHcloud go przygotowuje, a następnie pobierasz archiwum ZIP zawierające jeden lub więcej plików `.pst` oraz pliki `readme.md` i `checksum.txt`. Outlook nie bierze w tym udziału: całą operację obsługuje Panel klienta OVHcloud lub API OVHcloud.

Ta funkcja jest dostępna <Region zones={['eu']}>dla usług Hosted Exchange, Private Exchange i Trusted Exchange</Region><Region zones={['ca']}>dla usługi Hosted Exchange</Region>. Dotyczy ona indywidualnych skrzynek pocztowych: grup, kont współdzielonych i kont zasobów nie można wyeksportować.

**Ten przewodnik wyjaśnia, jak wyeksportować skrzynkę pocztową Exchange do archiwum PST z Panelu klienta OVHcloud lub za pomocą API OVHcloud.**

## W praktyce

### Eksport z Panelu klienta OVHcloud

1. Otwórz kartę <code className="action">Konta e-mail</code>.
2. W wierszu skrzynki pocztowej do wyeksportowania kliknij <code className="action">...</code>, a następnie <code className="action">Eksportuj w formacie PST</code>.

    <img className="thumbnail" alt="Menu akcji konta e-mail z opcją Eksportuj w formacie PST" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-menu.png" loading="lazy" />

3. W oknie **Eksportuj w formacie .pst** kliknij <code className="action">Pobierz</code>, aby uruchomić eksport. Działa on w tle i trwa od kilku minut do kilku godzin, w zależności od rozmiaru skrzynki pocztowej. Możesz zamknąć okno i opuścić stronę: otwórz je ponownie w dowolnym momencie, aby sprawdzić postęp wyrażony w procentach.

    <img className="thumbnail" alt="Okno Eksportuj w formacie .pst pokazujące postęp eksportu" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-progress.png" loading="lazy" />

4. Po zakończeniu eksportu otwórz to samo menu <code className="action">...</code> i ponownie kliknij <code className="action">Eksportuj w formacie PST</code>. Link do pobrania jest następnie generowany automatycznie, co trwa od 2 do 3 minut.

    <img className="thumbnail" alt="Okno Eksportuj w formacie .pst podczas generowania linku do pobrania" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-link.png" loading="lazy" />

5. Gdy link jest gotowy, okno potwierdza, że skrzynka pocztowa jest dostępna w formacie `.pst`. Kliknij <code className="action">Pobierz</code>, aby pobrać archiwum ZIP, a następnie rozpakuj je i sprawdź (zobacz [Sprawdzenie i otwarcie archiwum](#sprawdzenie-i-otwarcie-archiwum)).

    <img className="thumbnail" alt="Okno eksportu oferujące pobranie archiwum i nowy eksport" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-download.png" loading="lazy" />

:::info
Link do pobrania jest tymczasowy: okno pokazuje datę, do której plik pozostaje dostępny. Po tej dacie archiwum jest usuwane i musisz zlecić nowy eksport. W tym samym oknie możesz kliknąć <code className="action">Uruchom nowy eksport</code>, co **natychmiast usuwa poprzednie archiwum**.

:::

### Eksport za pomocą API OVHcloud

Proces opiera się na 2 obiektach: `export` tworzy archiwum i raportuje jego postęp, a `exportURL` udostępnia tymczasowy adres URL do pobrania. Wszystkie poniższe wywołania należą do <ApiLink section="/email/exchange">sekcji `/email/exchange`</ApiLink> API OVHcloud.

#### Znajdowanie parametrów ścieżki

Każde wywołanie wymaga 3 wartości: nazwy organizacji, nazwy usługi i adresu skrzynki pocztowej. Pierwsze 2 to nazwy wewnętrzne, takie jak `ab12345-ovh`, a nie etykiety wyświetlane w Panelu klienta OVHcloud. Pobierz je po kolei, ponieważ każde wywołanie dostarcza dane dla następnego.

**1. Organizacja** (`organizationName`)

Wyświetl listę organizacji Exchange Twojego konta za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange"} />

**2. Usługa** (`exchangeService`)

Wyświetl listę usług Exchange w organizacji za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service"} />

**3. Skrzynka pocztowa** (`primaryEmailAddress`)

Wyświetl listę kont e-mail usługi za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account"} />

Każde wywołanie zwraca listę ciągów znaków. Jeśli adres skrzynki pocztowej zawiera znaki, które nie są bezpieczne w adresach URL, zakoduj je procentowo w ścieżce (`+` staje się `%2B` itd.).

#### Zlecanie eksportu

Zleć eksport skrzynki pocztowej za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="POST" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

Wywołanie nie przyjmuje żadnego parametru w treści i zwraca zadanie, które potwierdza jedynie, że żądanie zostało zarejestrowane:

```json
{
  "id": 123456789,
  "function": "addExportPstRequest",
  "status": "todo",
  "todoDate": "2026-09-01T10:12:33+02:00",
  "finishDate": null
}
```

Zadanie ma jeden ze statusów `todo`, `doing`, `done`, `error` lub `cancelled`, a jego `function` to `addExportPstRequest`, `deleteExportPstRequest` lub `generatePstUrl`.

#### Śledzenie postępu

Odczytaj żądanie eksportu, aby śledzić jego postęp:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

| Właściwość | Typ | Opis |
|---|---|---|
| `creationDate` | datetime | Data utworzenia żądania eksportu |
| `percentComplete` | long | Postęp eksportu w procentach |
| `taskPendingId` | long | ID oczekującego zadania, `0`, gdy żadne nie jest w toku |

```json
{
  "creationDate": "2026-09-01T10:12:33+02:00",
  "percentComplete": 42,
  "taskPendingId": 123456789
}
```

Powtarzaj to wywołanie, aż `percentComplete` osiągnie `100`, odpytując nie częściej niż raz na minutę. Błąd `404` oznacza, że dla tej skrzynki pocztowej nie istnieje żadne żądanie eksportu: albo nigdy nie zostało utworzone, albo zostało już usunięte.

#### Uzyskiwanie adresu URL do pobrania

Obiekt `export` nigdy nie zwraca adresu URL do pobrania: w przeciwieństwie do Panelu klienta OVHcloud, który generuje link za Ciebie, API wymaga 2 wywołań.

**1. Wygeneruj adres URL**

Utwórz link do pobrania, co rejestruje zadanie `generatePstUrl`, za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="POST" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/exportURL"} />

**2. Odczytaj adres URL**

Po zakończeniu zadania odczytaj wygenerowany link za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/exportURL"} />

| Właściwość | Typ | Opis |
|---|---|---|
| `url` | string | Adres URL do pobrania archiwum |
| `expiration` | datetime | Data wygaśnięcia adresu URL |

```json
{
  "url": "https://exchange-export.storage.example/abc123/john.smith.zip?token=...",
  "expiration": "2026-09-01T11:15:00+02:00"
}
```

Adres URL jest już podpisany: pobierz archiwum bezpośrednio z niego, bez nagłówka uwierzytelniania. Błąd `404` przy wywołaniu `GET` oznacza, że adres URL nie został jeszcze wygenerowany (zadanie `generatePstUrl` nadal trwa) lub że wygasł.

:::info
**Adres URL ma ograniczoną ważność.** Opieraj się na wartości `expiration`, a nie na stałym czasie trwania, i generuj adres URL dopiero wtedy, gdy chcesz od razu pobrać archiwum. Po jego wygaśnięciu ponownie wywołaj `POST` na `exportURL`, aby uzyskać nowy link: dopóki archiwum nadal istnieje, nie musisz powtarzać eksportu.

:::

#### Usuwanie żądania eksportu

Usuń żądanie eksportu za pomocą poniższego wywołania API:

<Api version="v1" section="/email/exchange" method="DELETE" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

Użyj go, aby anulować trwający eksport lub, po pobraniu archiwum, usunąć żądanie i móc zlecić nowe (nadal z zachowaniem limitu jednego eksportu na 24 godziny). Wywołanie usuwa również archiwum po stronie OVHcloud: najpierw je pobierz.

### Sprawdzenie i otwarcie archiwum

Niezależnie od użytej metody archiwum ZIP zawiera:

| Element | Opis |
|---|---|
| `*.pst` | Dane skrzynki pocztowej. Duża skrzynka pocztowa jest dzielona na kilka plików PST. |
| `readme.md` | Uwagi OVHcloud dotyczące eksportu i jego zawartości |
| `checksum.txt` | Suma kontrolna SHA-256 każdego pliku `.pst` w archiwum |

Rozpakuj archiwum, a następnie porównaj pliki PST z sumami kontrolnymi z pliku `checksum.txt` przed ich zaimportowaniem: przerwane pobieranie tworzy plik PST, którego Outlook nie otworzy lub który otworzy niekompletny. Poniższe polecenia zakładają układ `<hash> <filename>`, po jednym wierszu na plik.

W systemie Windows, za pomocą PowerShell:

```powershell
Get-Content .\checksum.txt | Where-Object { $_.Trim() } | ForEach-Object {
    $hash, $file = $_.Trim() -split '\s+', 2
    $file = $file.TrimStart('*')
    $actual = (Get-FileHash $file -Algorithm SHA256).Hash
    "{0,-8} {1}" -f $(if ($actual -eq $hash.ToUpper()) { "OK" } else { "MISMATCH" }), $file
}
```

W systemie Linux lub macOS:

```bash
sha256sum -c checksum.txt
# john.smith.pst: OK
# john.smith-2.pst: OK
```

Jeśli suma kontrolna się nie zgadza, pobierz archiwum ponownie. Jeśli problem się powtarza, zleć nowy eksport.

Aby otworzyć pliki PST w klasycznym programie Outlook dla Windows, przejdź do <code className="action">Plik</code> > <code className="action">Otwórz i eksportuj</code> > <code className="action">Otwórz plik danych programu Outlook</code>, a następnie wybierz każdy rozpakowany plik `.pst`. W momencie pisania tego przewodnika nowy Outlook dla Windows nie otwiera plików `.pst`.

:::info
**Ograniczenia**

- Czas eksportu zależy od rozmiaru skrzynki pocztowej: minuty w przypadku małej skrzynki, kilka godzin w przypadku dużej. Nie ma możliwości jego przyspieszenia.
- Skrzynka pocztowa może mieć tylko jedno żądanie eksportu, a nowe jest przyjmowane dopiero 24 godziny po poprzednim żądaniu dla tego samego adresu e-mail.
- Eksport dotyczy wyłącznie indywidualnych skrzynek pocztowych: grupy, konta współdzielone i konta zasobów nie są obsługiwane.

:::
