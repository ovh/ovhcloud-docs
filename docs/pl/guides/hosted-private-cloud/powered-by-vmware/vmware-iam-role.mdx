## W praktyce

Domyślnie dostępne są 2 role IAM vSphere. Utworzenie dodatkowej roli jest więc opcjonalne.

Poniżej wyjaśniamy, jak utworzyć dodatkową rolę.

### Tworzenie roli IAM w konsoli OVHcloud

Wybierz infrastrukturę, a następnie przejdź do zakładki <code className="action">Użytkownicy</code>.

Kliknij <code className="action">Utwórz rolę IAM</code>.

<img className="thumbnail" alt="Zakładka Użytkownicy usługi Managed VMware vSphere z przyciskiem Utwórz rolę IAM" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role/console/iam_role_8.png" loading="lazy" />

W oknie **Utwórz nową rolę IAM OVHcloud**, które się otworzy, wpisz nazwę roli w polu **Nazwa roli**, a następnie kliknij <code className="action">Zatwierdź</code>.

:::info
Role IAM otrzymują automatycznie prefiks `iam-`.

:::

<img className="thumbnail" alt="Okno Utwórz nową rolę IAM OVHcloud, prefiks iam- w polu Nazwa roli" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role/console/iam_role_9.png" loading="lazy" />

Następnie możesz zmienić uprawnienia grupy w taki sam sposób jak w przypadku lokalnego użytkownika vSphere: kliknij przycisk <code className="action">⋮</code> w kolumnie **Akcje** w wierszu Twojej roli, a następnie wybierz <code className="action">Wyświetl/Edytuj uprawnienia wg DC</code>.

#### Tworzenie roli IAM za pomocą API OVHcloud

:::tip
Zapoznaj się z przewodnikiem [Pierwsze kroki z API OVHcloud](/guides/manage-and-operate/api/first-steps), aby dowiedzieć się, jak korzystać z API OVHcloud w wersji 6.

:::



Wykonaj następujące wywołanie API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/addRole"} />


:::warning
Pamiętaj, aby zastąpić `serviceName` referencją Twojej usługi Hosted Private Cloud w formacie `pcc-XXX-XXX-XXX-XXX`.

:::
