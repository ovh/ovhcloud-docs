## Wprowadzenie

Blok IP umożliwia udostępnianie witryn w Internecie. 

**Niniejszy przewodnik wyjaśnia, jak zamawiać, dodawać i przenosić blok IP powiązany z Twoją usługą Hosted Private Cloud.**

## Wymagania początkowe

- Posiadanie statusu kontaktu administratora infrastruktury [Hosted Private Cloud](https://www.ovhcloud.com/pl/enterprise/products/hosted-private-cloud/), aby otrzymywać dane do logowania.
- Posiadanie aktywnego identyfikatora użytkownika (utworzonego w <ManagerLink console to="/">konsoli OVHcloud</ManagerLink>)

[[cpnav:network-public-ip-console]]

## W praktyce

### Zamówienie bloku IP

Aby zamówić dodatkowy blok IP dla Twojej usługi **Hosted Private Cloud**, otwórz Twoją usługę w konsoli OVHcloud (**Private Cloud** › **Managed VMware vSphere**, a następnie Twoja usługa). W zakładce **Pulpit**, w sekcji **Opcje**, otwórz menu ⋮ wiersza **Liczba bloków IP** i kliknij <code className="action">Zamów bloki IP</code>. Ta sama strona zamówienia jest również dostępna w sekcji **Sieć** › **Adresy IP**: kliknij <code className="action">Zamów IP</code>, a następnie <code className="action">Zamów Additional IP</code>.

Na stronie **Zamów IP** wypełnij następujące sekcje, aby utworzyć blok IP:

- **Wybierz typ adresu IP**: wybierz **IPv4**.
- **Wybierz usługę, do której przypisać dodatkowy IP**: wybierz Twoją usługę **Hosted Private Cloud**. Region zostanie następnie określony automatycznie na podstawie wybranej usługi.
- **Wybierz ofertę**: wybierz wielkość bloku IP (od /28 do /24).

:::info
Dla przypomnienia, oto tabela podsumowująca liczbę IP obecnych w bloku i liczbę adresów IP do wykorzystania.

:::


|Wielkość bloku|IP w bloku|IP do wykorzystania w OVHcloud|
|:---:|:---:|:---:|
|28|16|11|
|27|32|27|
|26|64|59|
|25|128|123|
|24|256|251|

:::info
Zapoznaj się z naszym przewodnikiem dotyczącym [wtyczki OVHcloud Network](/guides/hosted-private-cloud/powered-by-vmware/plugin-ovh-network), aby dowiedzieć się, jakie IP zarezerwowano dla Twojego bloku oraz jak są wykorzystywane.

:::

- **Wybierz geolokalizację**: wybierz kraj bloku IP. Kraj, w którym hostowany jest blok IP, jest w niektórych przypadkach ważny dla pozycjonowania Twoich witryn (strona internetowa skierowana do Polaków będzie lepiej pozycjonowana, jeśli ma polski adres IP).

Nazwa i opis sieci widoczne w bazie WHOIS bloku IP nie są wymagane przy zamówieniu: nazwę sieci możesz zmienić na stronie **Adresy IP** po dostarczeniu bloku.

:::tip
Opłać koszty aktywacji bloku IP przed dostawą.

:::

Sprawdź **Podsumowanie**, a następnie kliknij <code className="action">Zamów</code>. Formularz zamówienia na blok IP otworzy się w nowej karcie. Jeśli odpowiada on Twoim oczekiwaniom, wystarczy go opłacić za pomocą jednej z oferowanych metod płatności, aby otrzymać zamówiony blok.

### Przenoszenie bloku IP między dwiema usługami Hosted Private Cloud

<iframe className="video" width="560" height="315" src="https://www.youtube-nocookie.com/embed/Gemao3Fd7rI" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen={true}></iframe>

Migracja bloku IP wymaga ręcznego przeniesienia bloków za pośrednictwem APIv6 OVHcloud.

Należy zastosować następujące wywołanie API:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/move"} />

Pola należy wypełnić w następujący sposób:

- ip: blok IP z /maską
- nexthop „newPrimaryIp” (wielkość liter jest rozróżniana)
- to: docelowa usługa Hosted Private Cloud w formie pcc-XXX-XXX-XXX-XXX

Wynik będzie następujący:

```json
{
  "function": "genericMoveFloatingIp",
  "status": "todo",
  "taskId": 178970672
}
```

Jeśli musisz odłączyć blok IP, możesz użyć tego wywołania API do przeniesienia IP na „parking adresów IP”:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/park"} />


:::warning
To wywołanie odcina dostęp do sieci maszynom wirtualnym, które wykorzystują dane adresy IP.

:::


Możesz również przenieść blok z poziomu konsoli OVHcloud: w zakładce **Pulpit** Twojej usługi, w sekcji **Opcje**, otwórz menu ⋮ wiersza **Liczba bloków IP** i kliknij <code className="action">Powiąż bloki IP z inną usługą</code>.

Możesz śledzić przenoszenie bloku IP w sekcji **Managed VMware vSphere**. Kliknij Twoją usługę Hosted Private Cloud, a następnie kartę <code className="action">Operacje</code>.

Odnośnik do operacji to `removeIpRipeBlock`.

Następnie IP pojawi się na liście **Adresy IP** (**Sieć** › **Adresy IP**) z typem **IP Parking**.
