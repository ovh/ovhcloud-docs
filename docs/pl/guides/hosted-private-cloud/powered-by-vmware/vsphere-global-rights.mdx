## Wprowadzenie

Globalne uprawnienia vSphere pozwalają zdefiniować prawa użytkownika w Twojej usłudze Hosted Private Cloud. Z poziomu Panelu klienta OVHcloud możesz włączać lub wyłączać te opcje dla każdego użytkownika za pomocą pól wyboru.

Ten przewodnik wyjaśnia, jak zarządzać tymi globalnymi uprawnieniami z poziomu panelu OVHcloud.

- **Ścieżka nawigacji:** <code className="action">Hosted Private Cloud</code> > <code className="action">Managed VMware vSphere</code> > Wybierz usługę vSphere

## Wymagania początkowe

- Aktywna [usługa Hosted Private Cloud](https://www.ovhcloud.com/pl/hosted-private-cloud/vmware/)
- [Użytkownik vSphere](/guides/hosted-private-cloud/powered-by-vmware/vsphere-interface-connexion) już utworzony w Twojej usłudze
- Dostęp do <ManagerLink to="/">Panelu klienta OVHcloud</ManagerLink> z odpowiednimi uprawnieniami do zarządzania użytkownikami

## W praktyce

### Dostęp do zarządzania prawami użytkowników

1. Otwórz <ManagerLink to="/">Panel klienta OVHcloud</ManagerLink>. Kliknij <code className="action">Hosted Private Cloud</code> na górnym pasku, a następnie <code className="action">Managed VMware vSphere</code> w menu po lewej stronie i wybierz usługę PCC.

2. Przejdź do zakładki <code className="action">Użytkownicy</code>.

	<img className="thumbnail" alt="Zakładka użytkownicy" src="/images/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud/en05users.png" loading="lazy" />

3. W wierszu dotyczącym odpowiedniego użytkownika otwórz menu <code className="action">...</code> i kliknij <code className="action">Edytuj</code>.

### Konfiguracja uprawnień globalnych

1. W oknie edycji użytkownika kilka pól wyboru odpowiada uprawnieniom globalnym.

2. Zaznacz lub odznacz opcje zgodnie z prawami, które chcesz nadać użytkownikowi.

	<img className="thumbnail" alt="Okno edycji praw użytkownika" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/user-global-rights.png" loading="lazy" />

3. Zatwierdź zmianę.

### Dostępne uprawnienia

Uprawnienia globalne są reprezentowane przez następujące pola wyboru w oknie edycji użytkownika:

| Uprawnienie | Opis |
|---|---|
| Token validator | Aktywuje token walidacji dla użytkownika, umożliwiając uwierzytelnianie w API OVHcloud. |
| Ip | Ogranicza dostęp użytkownika do określonych adresów IP. |
| Ip Failover | Pozwala użytkownikowi zarządzać adresami IP Failover powiązanymi z usługą. |
| Interface NSX | Nadaje dostęp do interfejsu zarządzania siecią NSX. |
| Encryption management | Pozwala użytkownikowi zarządzać szyfrowaniem maszyn wirtualnych (KMS). |

### Więcej informacji o prawach granularnych

Globalne uprawnienia opisane powyżej mają zastosowanie na poziomie inwentarza vSphere usługi Hosted Private Cloud, czyli na poziomie rozpatrywanego klastra VMware.

Jeśli musisz nadać użytkownikowi uprawnienia tylko do określonych obiektów inwentarza vSphere, na przykład maszyny wirtualnej, datastore lub folderu, musisz skorzystać z [praw granularnych na obiektach vSphere](/guides/hosted-private-cloud/powered-by-vmware/vsphere-granular-rights).
