## Wprowadzenie

Uprawnieniami i hasłami użytkowników klienta vSphere zarządzasz w konsoli OVHcloud.

**Dowiedz się, jak zmienić hasło użytkownika**

## Wymagania początkowe

- Dostęp do <ManagerLink console to="/">konsoli OVHcloud</ManagerLink>
- Posiadanie aktywnego użytkownika utworzonego w konsoli OVHcloud. Aby uzyskać więcej informacji, zapoznaj się z przewodnikiem "[Zarządzanie usługą Hosted Private Cloud w konsoli OVHcloud](/guides/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud#użytkownicy)".

[[cpnav:privatecloud-vmware-vsphere-console]]

## W praktyce

### Zmień hasło

W konsoli OVHcloud przejdź do **Private Cloud** › **Managed VMware vSphere** i wybierz usługę z listy. Kliknij zakładkę <code className="action">Użytkownicy</code>.

Otwórz menu ⋮ (kolumna **Akcje**) wybranego użytkownika i kliknij <code className="action">Zmień hasło</code>.

W oknie **Zmień hasło** wprowadź nowe hasło w polu **Nowe hasło**, potwierdź je w polu **Wpisz ponownie hasło**, a następnie kliknij <code className="action">Zatwierdź</code>.

:::info
Jeśli nie wprowadzisz swojego hasła, na adres powiązany z użytkownikiem zostanie wysłane losowo wygenerowane hasło.

:::

W przypadku usługi z certyfikowaną opcją zgodności (PCI DSS, HDS…) okno nie wyświetla formularza: podaje adres certyfikowanego interfejsu (`https://<twoja-usluga>/secure`), w którym zmienisz hasło.

:::warning
Aby zapewnić bezpieczeństwo infrastruktury, stosuj dobre praktyki wskazane poniżej. Twoje hasło:

- musi zawierać minimum 8 znaków;
- musi zawierać minimum trzy typy znaków;
- nie może figurować w słowniku;
- nie może zawierać osobistych danych;
- nie może być wykorzystane dla kilku użytkowników;
- musi być przechowywane w menedżerze haseł;
- musi być zmieniane co 3 miesiące;
- musi być inne niż poprzednie hasła.

:::
