## Wprowadzenie

Po zaplanowaniu prac konserwacyjnych na Twojej usłudze Hosted Private Cloud otrzymasz e-mail z powiadomieniem o dacie przeprowadzenia prac konserwacyjnych. Jeśli data ta nie jest dla Ciebie odpowiednia, na przykład ze względu na wymagania produkcyjne, możesz przełożyć tę konserwację na wybrany termin w konsoli OVHcloud lub za pośrednictwem API OVHcloud.

:::info
Staramy się jak najlepiej dopasować się do Twojego zapotrzebowania na infrastrukturę. Czasem jednak musimy zaplanować prace konserwacyjne, w przypadku których nie będzie można zmienić daty i/lub godziny (np. prace konserwacyjne w infrastrukturze z udziałem kilku klientów, pilne interwencje w celu uniknięcia incydentu itp.).

Jeśli data konserwacji może zostać zmieniona przez użytkownika, proponowane nowe daty mieszczą się w skróconym przedziale czasowym.

:::

**Dowiedz się, jak zmienić datę zaplanowanej konserwacji rozwiązania VMware on OVHcloud w konsoli OVHcloud lub za pośrednictwem API OVHcloud.**

## Wymagania początkowe

- Otrzymałeś e-mail z powiadomieniem o pracach konserwacyjnych informujący, że możesz **zmienić datę wykonania prac konserwacyjnych**. W przeciwnym razie data utrzymania nie może zostać zmieniona.
- Posiadanie kontaktu administracyjnego lub technicznego w infrastrukturze [VMware on OVHcloud](https://www.ovhcloud.com/pl/enterprise/products/hosted-private-cloud/).
- Dostęp do <ApiLink>interfejsu administracyjnego usług przez API</ApiLink>.

### W konsoli OVHcloud

Za pomocą konta administratora przejdź do sekcji **Private Cloud** › **Managed VMware vSphere** w konsoli OVHcloud, wybierz usługę z listy i kliknij zakładkę <code className="action">Operacje</code>. Na liście rozwijanej nad tabelą operacji, po prawej stronie, sprawdź, czy wybrana jest opcja <code className="action">W trakcie</code> (domyślna), aby wyświetlić operacje, które nie zostały jeszcze zakończone.

Następnie otwórz menu ⋮ (kolumna **Akcje**) operacji konserwacji i kliknij <code className="action">Zmień datę wykonania</code>.

:::info
Jeśli opcja <code className="action">Zmień datę wykonania</code> nie jest dostępna, tej konserwacji nie można przełożyć.

:::

W oknie **Zmień datę wykonania** wybierz datę w kalendarzu **Data przetwarzania**. Można wybrać tylko dostępne daty: dat spoza dozwolonego okna konserwacji nie można wybrać.

Następnie wprowadź nową godzinę konserwacji w polu **Godzina** lub pozostaw pierwotnie zaplanowaną godzinę bez zmian.

Na koniec kliknij przycisk <code className="action">Zmodyfikuj</code>, aby zatwierdzić zmiany.

### Za pośrednictwem API OVHcloud

Zapoznaj się z naszym przewodnikiem "[Pierwsze kroki z API OVHcloud](/guides/manage-and-operate/api/first-steps)".

Wykonaj następujące wywołanie API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/task/\{taskId\}/changeMaintenanceExecutionDate"} />

Wpisz zmienne:

- serviceName: numer referencyjny usługi Hosted Private Cloud w formie `pcc-XX-XX-XX-XX`.
- taskId: jest to "numer referencyjny operacji" konserwacji podany w przesłanym do Ciebie e-mailu z powiadomieniem.
- executionDate: wprowadź nową datę konserwacji w formacie `YYYY-MM-DDTHH:MM+01:SS` (np. 2023-01-02T08:00:00+01:00 dla konserwacji zaplanowanej na dzień 02/01/2023 o 0800 (UTC+1)).
