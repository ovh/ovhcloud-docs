## Wprowadzenie

**Niniejszy przewodnik wyjaśnia, jak aktywować IAM w usłudze Hosted Private Cloud - VMware on OVHcloud w konsoli OVHcloud lub za pomocą API OVHcloud**.

## Wymagania początkowe

- Posiadanie [konta OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation)
- Posiadanie jednego lub kilku produktów Hosted Private Cloud - VMware on OVHcloud powiązanych z tym kontem (Hosted Private Cloud powered by VMware, VMware Service Pack).

[[cpnav:privatecloud-vmware-vsphere-console]]

## W praktyce

### Aktywacja IAM

:::info
Operacja może potrwać do 30 minut.

:::


### W konsoli OVHcloud

Wybierz infrastrukturę, a następnie przejdź do zakładki <code className="action">Użytkownicy</code>.

W sekcji **OVHcloud IAM** na dole zakładki kliknij <code className="action">Aktywuj OVHcloud IAM</code>.

<img className="thumbnail" alt="Sekcja OVHcloud IAM ze statusem Wyłączony i linkiem Aktywuj OVHcloud IAM" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_2.png" loading="lazy" />

:::warning
Z OVHcloud IAM zintegrowany jest wyłącznie produkt vSphere. Infrastruktura z opcjami zwiększonego bezpieczeństwa lub z certyfikowaną usługą (HDS, PCI-DSS lub SNC) nie może obecnie korzystać z OVHcloud IAM. Jeśli później włączysz jedną z tych certyfikowanych opcji lub usług, konieczne będzie wyłączenie OVHcloud IAM.
:::

W oknie **Włącz IAM OVHcloud**, które się otworzy, kliknij <code className="action">Zatwierdź</code>.

:::tip
Po aktywacji IAM jego status zmieni się na `Aktywny` i zostanie wyświetlony na zielono.

:::

<img className="thumbnail" alt="Zakładka Użytkownicy z sekcją OVHcloud IAM ze statusem Aktywny" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_3.png" loading="lazy" />

### Za pomocą API OVHcloud

:::tip
Zapoznaj się z przewodnikiem [Pierwsze kroki z API OVHcloud](/guides/manage-and-operate/api/first-steps), aby dowiedzieć się, jak korzystać z API OVHcloud w wersji 6.

:::


:::warning
Pamiętaj, aby zastąpić `serviceName` referencją Twojej usługi Hosted Private Cloud w formacie `pcc-XXX-XXX-XXX-XXX`.

:::


Aby aktywować opcję IAM, wykonaj następujące wywołanie API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/enable"} />


#### Sprawdzenie, czy IAM jest aktywny

Aby sprawdzić aktywację IAM, wykonaj następujące wywołanie API:

<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\{serviceName\}/iam"} />

Odpowiedź API:

```shell
{
  "state": "enabled",
  "identityProviderId": 275
}
```

### Wyłączenie IAM

Możesz wyłączyć OVHcloud IAM w Twoim Hosted Private Cloud.

#### W konsoli OVHcloud

Wybierz infrastrukturę, a następnie przejdź do zakładki <code className="action">Użytkownicy</code>.

W sekcji **OVHcloud IAM** na dole zakładki kliknij <code className="action">Wyłącz OVHcloud IAM</code>. W oknie **Wyłącz IAM OVHcloud**, które się otworzy, kliknij <code className="action">Zatwierdź</code>.

#### Za pomocą API OVHcloud

Aby wyłączyć opcję IAM, wykonaj następujące wywołanie API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/disable"} />
