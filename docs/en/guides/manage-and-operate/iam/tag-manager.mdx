## Objective

In this guide, you will learn how to assign and manage tags on your OVHcloud products and how to use them in IAM policies.

## Requirements

- An [OVHcloud customer account](/guides/account-and-service-management/account-information/ovhcloud-account-creation).

[[cpnav:iam-tag-management-console]]

## Instructions

### Managing Tags via the OVHcloud Console

You can manage your OVHcloud product tags either through the general tag management interface or through dedicated interfaces within the products.

Tags are metadata in the form of key-value pairs added to OVHcloud resources, which can be used in IAM policies or for resource categorization.

#### Tag manager

{/* CP-STEPS-START:tag-manager */}

The <ManagerLink to="/beta/#/iam/tag-manager">Tag manager</ManagerLink> is the interface that allows you to manage your tags across all your OVHcloud products.

The page displays all the tags currently placed on your resources.

<img className="thumbnail" alt="Tag manager page with the Tag type drop-down list and the Tag type column" src="/images/manage-and-operate/iam/iam-tag-manager/console/tag-manager-01.png" loading="lazy" />

For each tag, the list shows the number of resources associated with this tag and the type of tag.

There are three types of tags:

- Custom: Created and managed by you.
- Predefined: Created by OVHcloud; you are responsible for assigning this type of tag to your resources.
- System: Created and automatically assigned by OVHcloud to your resources (cannot be deleted).

By default, the **Tag type** drop-down list is set to <code className="action">All types</code>, and the page also displays unassigned predefined tags. To narrow the list, select <code className="action">Custom</code>, <code className="action">Predefined</code>, <code className="action">System</code> or <code className="action">Unassigned</code> from this drop-down list.

Click a tag to open its details, with the list of resources it is assigned to.

<img className="thumbnail" alt="A tag's page with the Assign to resources and Unassign tag buttons" src="/images/manage-and-operate/iam/iam-tag-manager/console/tag-manager-02.png" loading="lazy" />

You can then assign this tag to other resources with the <code className="action">Assign to resources</code> button. The list of all resources in the account is then displayed, allowing multiple selections.

A search field helps you find resources.

Conversely, to remove the tag from resources, select them in the tag details, then click <code className="action">Unassign tag</code>.

{/* CP-STEPS-END:tag-manager */}

#### Product dashboard

{/* CP-STEPS-START:product-dashboard */}

For some OVHcloud products, an interface has been added to manage tags directly from the resource management dashboard.

The tag management interface allows you to add or remove tags from the resource.

It is possible to either select one or more tags from the list of predefined tags or enter your own tags by typing the keys and values directly into the fields.

{/* CP-STEPS-END:product-dashboard */}

### Managing Tags via API

Tag management is centralized in a single API for all OVHcloud products:

| **Method** |               **Path**                |       **Description**        |
| :--------: | :-----------------------------------: | :--------------------------: |
|    POST    |    /iam/resource/&#123;resourceURN&#125;/tag    |   Add a tag to a resource    |
|    DEL     | /iam/resource/&#123;resourceURN&#125;/tag/&#123;key&#125; | Remove a tag from a resource |

The tag must be specified in the following format:

```json
{
  "key": "environment",
  "value": "production"
}
```

### Using Tags in IAM Policies

Tags can be used as conditions in IAM policies using the `resource.Tag(tag_key)` condition.

For example, the following policy grants rights to all VPS with the tag `Environment:Production`:

```json
{
  "conditions": {
    "conditions": [
      {
        "operator": "MATCH",
        "values": {
          "resource.Tag(Environment)": "Production"
        }
      }
    ],
    "operator": "AND"
  },
  "description": "Give access to VPS with tag Environment:Production",
  "identities": [
    "urn:v1:eu:identity:group:aa1-ovh/devs"
  ],
  "name": "vps-production",
  "permissions": {
    "allow": [
      {
        "action": "vps:apiovh:*"
      }
    ]
  },
  "resources": [
    {
      "urn": "urn:v1:eu:resource:vps:*"
    }
  ]
}
```
