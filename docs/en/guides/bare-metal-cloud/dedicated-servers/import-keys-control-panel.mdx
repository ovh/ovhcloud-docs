## Objective

Key pairs are used to authenticate SSH connections between hosts, for example a desktop client and a remote server. When reinstalling a dedicated server or a VPS from the OVHcloud Console, you have the option to add a public key to the operating system. Storing public keys in the Console makes this process more convenient.

**This guide explains how to store your public authentication keys in the OVHcloud Console.**

## Requirements

- A [dedicated server](/links/bare-metal/bare-metal) or a [VPS](/links/bare-metal/vps) in your OVHcloud account

:::info
For information about using authentication keys with [Public Cloud](/links/public-cloud/public-cloud) services, refer to our dedicated guide:

[How to create SSH keys with OpenSSH for Public Cloud instances](/guides/public-cloud/compute/creating-ssh-keys)

:::

## Instructions

If you have not created a key pair yet, consult our guides first:

- [How to create and use keys for SSH authentication](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [How to create and use keys for SSH authentication with PuTTY](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

{/* CP-STEPS-START:import-ssh-key */}

<img className="thumbnail" alt="Identity and Access Management group of the Console left menu, with the SSH keys entry" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/sidebar-iam-ssh-keys.png" loading="lazy" />

In the left menu of the OVHcloud Console, open **Identity and Access Management** and click <code className="action">SSH keys</code>.

<img className="thumbnail" alt="SSH keys page with the Add an SSH key button above the list of keys" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-button.png" loading="lazy" />

Open the <code className="action">Add an SSH key</code> menu above the list and select <code className="action">Dedicated</code>.

<img className="thumbnail" alt="Add an SSH key menu open, showing the Dedicated and Public Cloud options" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-menu.png" loading="lazy" />

In the **Add an SSH key** window, copy the entire public key string and paste it into the first field, **Public key**. Paste only the public key (the content of your `.pub` file), never the private key.  
Enter a label for the key in the second field, **Name**, so you can recognise it (for example, the name of your computer).

<img className="thumbnail" alt="Add an SSH key window with the Public key and Name fields and the Add button" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-dedicated-window.png" loading="lazy" />

Click <code className="action">Add</code>.

{/* CP-STEPS-END:import-ssh-key */}

The key will now be available when you reinstall a dedicated server or a VPS in the OVHcloud Console.
