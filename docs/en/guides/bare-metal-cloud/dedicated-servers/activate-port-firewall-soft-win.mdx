## Objective

To best protect your system, your Windows Server dedicated server has its own built-in firewall. By configuring it, you can increase security levels, which guarantees the availability and integrity of all elements hosted on the server, such as roles, services and shared folders.

**This guide will show you how to apply firewall rules on Windows.**

:::warning
OVHcloud is providing you with services for which you are responsible, with regard to their configuration and management. You are therefore responsible for ensuring they function correctly.

This guide is designed to assist you in common tasks as much as possible. Nevertheless, we recommend that you contact a [specialist service provider](/links/partner) and/or discuss the issue with [our community](/links/community) if you face difficulties or doubts concerning the administration, usage or security of a server.
:::

## Requirements

- A [dedicated server](/links/bare-metal/bare-metal) with Windows installed in your OVHcloud account
- Administrative access via remote desktop to your server

## Instructions

### Step 1: Access Windows Firewall

To access Windows Firewall, you can follow this order:

- Click <code className="action">Start</code>.
- Click <code className="action">Search</code>.
- Search for "Windows Defender Firewall" in the search bar.
- Click <code className="action">Windows Defender Firewall</code>.

Then click <code className="action">Advanced settings</code>.

<img className="thumbnail" alt="Windows Defender Firewall window with the Advanced settings link" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step1.PNG" loading="lazy" />

### Step 2: Enable an inbound rule

In the window that appears, you will see settings such as:

- Inbound and Outbound Rules
- Connection Security Rules
- Server Firewall Monitoring Options

Selecting <code className="action">Inbound Rules</code> displays all preconfigured Windows Server rules associated with network connections and incoming packets. Some of these rules are not enabled by default. If you want to enable them, right-click the rule and select the <code className="action">Enable rule</code> option.

<img className="thumbnail" alt="Inbound rules list with enable rule option" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step2.PNG" loading="lazy" />

### Step 3: Create a new rule 

To create a new rule, go to the <code className="action">Action</code> menu and select <code className="action">New Rule</code>, or click <code className="action">New Rule</code> in the right-hand pane.

<img className="thumbnail" alt="Action menu of the Windows Defender Firewall console with New Rule highlighted" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step3.PNG" loading="lazy" />

### Step 4: Define the type of rule to activate

The Rule Wizard provides options to define the type of rule to create. Select the <code className="action">Port</code> option.

<img className="thumbnail" alt="Rule Type page of the New Inbound Rule Wizard with the Port option selected" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step4.PNG" loading="lazy" />

### Step 5: Define the port type to activate

In the next step, define the port type to enable:

<img className="thumbnail" alt="Protocol and Ports page with TCP and a specific local port selected" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step5.PNG" loading="lazy" />

:::info
- TCP (Transmission Control Protocol)

  It is a connection-orientated protocol, i.e. with TCP, it will be possible to create connections between hosts in order to send data streams. This protocol ensures that data is delivered to the recipient in the same order and in the same error-free manner.

- UDP (User Datagram Protocol)

  This is a non-connection-orientated protocol. Its development is based on the exchange of datagrams and facilitates the sending of datagrams across the network. No connection to the destination needs to be established beforehand.

You can also select the <code className="action">All local ports</code> option to enable all TCP or UDP ports on a non-secure server. You can also select the <code className="action">Specific local ports</code> option to determine which port should be allowed. 

:::

### Step 6: Allow or block the connection

To define the action this rule will trigger, the following options are available. Select the one that works for you.

- **Allow the connection**. This option allows full communication through this port.
- **Allow the connection if it is secure**. This option allows data to be transmitted only if the connection is authenticated via IPsec.
- **Block the connection**. This option prevents data from being routed through this port.

Select the <code className="action">Allow the connection</code> option and click <code className="action">Next</code>.

<img className="thumbnail" alt="Action page of the wizard with the Allow the connection option selected" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step6.PNG" loading="lazy" />

### Step 7: Define the profile and name of the rule

Finally, you must choose which profiles the rule should apply to, from public, domain or private profiles.
You can enable them all if you want.

<img className="thumbnail" alt="Profile page of the wizard with the Domain, Private and Public profiles checked" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7.PNG" loading="lazy" />

Give the new rule a name and description (optional) to make it easier to use:

<img className="thumbnail" alt="Name page of the wizard with the name of the rule filled in" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7-01.PNG" loading="lazy" />

Click the <code className="action">Finish</code> button to complete the process and create the new rule.

<img className="thumbnail" alt="Inbound Rules list showing the new rule, enabled" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7_02.PNG" loading="lazy" />

You can then make changes to the settings of the new rule you have created.
