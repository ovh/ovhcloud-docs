## Objective

Redundant Array of Independent Disks (RAID) is a utility that mitigates data loss on a server by replicating data across two or more disks.

The default RAID level for OVHcloud server installations is RAID 1, which doubles the space taken up by your data, effectively halving the usable disk space.

**This guide explains how to configure your server’s disks with RAID 0, which will allow you to use all your disks' usable space.**

:::warning
Please note: RAID 0 provides **NO FAULT TOLERANCE** and **NO DATA REDUNDANCY**, making data loss in the event of disk failure highly likely.

:::


## Requirements

- A [dedicated server](/links/bare-metal/bare-metal) with hardware RAID
- Administrative (sudo) access to the server via SSH

## Instructions

### Using the OVHcloud Console

{/* CP-STEPS-START:install-raid0 */}

On your server's <code className="action">Overview</code> tab, in the **General information** section, click <code className="action">Reinstall</code> on the **OS** row. The **OS Installation / Reinstallation** page opens.

In the **Operating system** step, select the operating system you want to install from the **Category** and **Operating System** drop-down lists.

Tick the boxes <code className="action">Configure hardware RAID</code> and <code className="action">Customise partition configuration</code>, then click <code className="action">Next</code>. The <code className="action">Configure hardware RAID</code> box is only offered if the selected disk group has a hardware RAID controller.

In the **Hardware RAID** step, select <code className="action">RAID 0</code> from the **RAID mode** drop-down list, choose the **Number of disks to configure** and the **Number of arrays**, then click <code className="action">Next</code>.

In the **Partitions** step, configure the partitions as you see fit and then click <code className="action">Next</code>. Fill in the **Options** step as needed and click <code className="action">Next</code>.

Finally, in the **Summary** step, tick the box <code className="action">I understand that all data on the disks will be permanently deleted.</code> and click <code className="action">Install</code>.

{/* CP-STEPS-END:install-raid0 */}

After your server has been installed, check the partition sizes by logging on to the server via SSH and running the following command:

```sh
df -h
```

### Using rescue mode

{/* CP-STEPS-START:boot-rescue */}

On your server's <code className="action">Overview</code> tab, in the **General information** section, click <code className="action">Rescue mode</code> on the **Boot Mode** row. The **Server** tab opens on the **Boot mode** setting of the **System** section.

Select the <code className="action">Rescue mode</code> option, then select <code className="action">Customer rescue system (Debian-12-based)</code> from the **Rescue kernel** drop-down list. Under **Authentication method**, select <code className="action">Password</code> to receive the login details by email.

In the **Rescue email** field, specify an alternative email address if you do not want the login credentials sent to your customer account's primary address.

Click <code className="action">Apply</code>. In the **Apply boot mode change** window, check the current and new boot modes, then click <code className="action">Apply</code>.

Once the change is completed, restart the server so that it boots into rescue mode: click <code className="action">Reboot now</code> in the **Reboot to apply** window. If you reboot later, click the <code className="action">Reboot</code> link on the **Boot Mode** row of the **General information** section (**Overview** tab), then click <code className="action">Reboot</code> in the confirmation window.

{/* CP-STEPS-END:boot-rescue */}

When your server reboots, log in to it via SSH using the rescue mode credentials that were emailed to you.

From the command line, type the following commands to delete the existing RAID settings. All data in the RAID will be deleted:

```sh
MegaCli -CfgLdDel -L0 -a0
MegaCli -CfgLdDel -Lall -aAll
```

Type the following command to retrieve the slot device IDs of your disks:

```sh
MegaCli -PdList -aALL | egrep "Slot|Device ID"
```

Type the following commands to configure RAID level 0:

```sh
MegaCli -CfgLDAdd -R0[252:0,252:1] -a0
```

In this example, 252 is the ID of the drive enclosure.

After setting the new RAID level you can check the settings with the following command:

```sh
MegaCli -LDInfo -Lall -a0 | grep -i size
```
