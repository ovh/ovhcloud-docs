## Objective

Rescue mode is a tool provided by OVHcloud that allows you to boot into a temporary operating system for the purpose of diagnosing and resolving issues on your server.  
The functionality of rescue mode in general is described on our guide page: 

[How to activate and use rescue mode](/guides/bare-metal-cloud/dedicated-servers/rescue-mode)

The option **Windows customer rescue system** is only available for dedicated servers that have a **Windows Server** operating system installed. The following conditions apply:

- The rescue system for Windows (`rescue-customer-windows`) runs in a virtual machine (VM) launched from the customer rescue system (`rescue-customer`, based on Debian GNU/Linux).
- The server disks are attached to the VM with *passthrough*, so it is possible to access them.
- Other server components will not be accessible (CPU, RAM, network card, RAID card).
- The network is mounted with *passthrough* but without direct access to the network card. The VM carries the IP address and the MAC address of the *bare metal* server.

:::warning
Backing up your data should be the first step in rescue mode if you do not already have recent backups available.

If you have any services still online, rescue mode will interrupt them as the machine is being rebooted into the auxiliary rescue environment.

:::


**This guide explains how to boot a server into the Windows customer rescue system.**
 
## Requirements

- Microsoft Windows installed on your [dedicated server](/links/bare-metal/bare-metal)
- At least 16 GB of RAM installed on the server

## Instructions

### Activating rescue mode for Windows

{/* CP-STEPS-START:open-server */}

Click your server's name to open its page. The server opens on the **Overview** tab, which holds the **General information** section.

{/* CP-STEPS-END:open-server */}

<a name="netboot"></a>

{/* CP-STEPS-START:activate-rescue-windows */}

In the **General information** section, click the <code className="action">Rescue mode</code> link on the **Boot Mode** row. The **Server** tab opens on the **Boot mode** setting of the **System** section. You can also click the <code className="action">Server</code> tab and go to the **Boot mode** setting directly.

Select the <code className="action">Rescue mode</code> option.

From the **Rescue kernel** drop-down list, select <code className="action">Windows customer rescue system v12 (Windows2022-based)</code>.

Under **Authentication method**, select <code className="action">Password</code>.

The rescue mode notification email including its login details will be sent to the contact email address of your OVHcloud account. To use a different email address, enter it in the **Rescue email** field.

Click <code className="action">Apply</code>. In the **Apply boot mode change** window, check the current and new boot modes, then click <code className="action">Apply</code>. The new boot mode takes effect at the next reboot.

The final step is to restart the server. In the **Reboot to apply** window, click <code className="action">Reboot now</code>. If you reboot later, click the <code className="action">Reboot</code> link on the **Boot Mode** row of the **General information** section (**Overview** tab), then click <code className="action">Reboot</code> in the confirmation window.

This "hard reboot" will take a few minutes to complete. You can check the current status in the <code className="action">Activities</code> tab.

:::info
After you have finished your actions in rescue mode, remember to change the **Boot mode** setting back to <code className="action">Boot from hard disk</code> before restarting the server.

:::

{/* CP-STEPS-END:activate-rescue-windows */}


### Accessing your server in rescue mode

{/* CP-STEPS-START:access-service-emails */}

Once you have received the email informing you that rescue mode is enabled, you can log on to the Windows rescue mode system and access your server.  
This email is also available in the <ManagerLink to="/">OVHcloud Console</ManagerLink> as soon as it is sent. Open the account menu in the top right-hand corner, then click <code className="action">My messages</code> under **Quick access**. The email is listed in the **Messages** tab of the **Communications** page.

{/* CP-STEPS-END:access-service-emails */}

To establish a remote session to the Windows rescue mode system, you will need these credentials:

- IP address of the server
- Username of the temporary admin account (`Administrator`)
- Password for the temporary admin account

You can use the following connections methods to access your server via the Windows rescue mode system:

- Remote Desktop Protocol (RDP)
- KVM over IP (if your server allows it)
- OpenSSH (official Windows Server component)

#### SSH

<details>

<summary>Unfold this section</summary>


Open the command line application on your local device and enter the following command:

```bash
ssh Administrator@SERVER_IP
```

Example:

```bash
ssh Administrator@203.0.113.100
```

Enter the temporary rescue mode password when prompted. Example:

```console
Administrator@ns9356771.ip-203-0-113.eu's password:
administrator@WINRESCUEOVH C:\Users\Administrator>
```

Find more information on SSH connections in our [SSH introduction guide](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction).  
You can also use any SSH connection tool, such as [PuTTY](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows).

</details>

### Exiting rescue mode

{/* CP-STEPS-START:exit-rescue */}

In the <ManagerLink to="/">OVHcloud Console</ManagerLink>, go to the [Boot mode](#netboot) setting of your server's **Server** tab, select <code className="action">Boot from hard disk</code> and click <code className="action">Apply</code>. Click <code className="action">Apply</code> again in the **Apply boot mode change** window.

Then restart the server: click <code className="action">Reboot now</code> in the **Reboot to apply** window, or use the <code className="action">Reboot</code> link on the **Boot Mode** row of the **General information** section.

{/* CP-STEPS-END:exit-rescue */}
