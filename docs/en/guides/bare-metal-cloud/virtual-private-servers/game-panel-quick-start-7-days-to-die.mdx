## Objective

The Game Panel lets you deploy a 7 Days to Die server with automated installation and port configuration.

**This guide explains how to deploy and connect to a 7 Days to Die server on the Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your Game Panel. Go to the **Game Servers** section in the left-hand menu and click <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Game Servers section with Add Game Server button" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/game-servers-list.png" loading="lazy" />

### Step 2 — Create a 7 Days to Die server

Select **7 Days to Die** from the game list. A configuration window opens.

<img className="thumbnail" alt="Selecting 7 Days to Die from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/select-7-days-to-die.png" loading="lazy" />

### Step 3 — Configure the 7 Days to Die server

Enter a **Server Name** (for example, `7 Days to Die Server`). The required network ports are configured automatically during installation.

<img className="thumbnail" alt="7 Days to Die installation form" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/7-days-to-die-install-form.png" loading="lazy" />

You can expand <code className="action">Advanced settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

### Step 4 — Launch the installation

Click <code className="action">Install</code>. The deployment starts automatically. Wait a few minutes while the image downloads and the server installs.

### Step 5 — Monitor the installation

Click <code className="action">Log/Console</code> to follow the installation progress in real time. The status shows **Installing**.

### Step 6 — Verify the server is running

Check that the server status displays **Running** and that CPU/RAM activity is visible.

<img className="thumbnail" alt="7 Days to Die server with Running status" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/7-days-to-die-running.png" loading="lazy" />

Available actions:

- <code className="action">Log/Console</code>: Open the console to monitor startup and check logs if there are any issues.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: Access game settings.

<img className="thumbnail" alt="7 Days to Die Game Config settings" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-7-days-to-die/7-days-to-die-game-config.png" loading="lazy" />

### Step 7 — Confirm installation is complete

The status changes to **Running** once the installation finishes.

### Step 8 — Retrieve connection information

In the **Connection** column of the Game Servers list, copy your server's IP address and port.

### Step 9 — Join your server in 7 Days to Die

To join from the game:

1. Launch **7 Days to Die** and click **Join a Game**.
2. Paste the IP address and port from the **Connection** column.
3. Click **Connect**.

### Best practices

- Configure permissions via <code className="action">User Administration</code>.
- Perform regular backups.
- Customise your game settings.
