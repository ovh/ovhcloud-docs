## Objective

The OVHcloud Game Panel lets you deploy a Valheim server with automated installation and port configuration.

**This guide explains how to deploy and connect to a Valheim server on the OVHcloud Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your OVHcloud Game Panel. From the left-hand menu, go to the `Game Servers` section and click <code className="action">Add Game Server</code>.

### Step 2 — Create a Valheim server

Select **Valheim** from the game list. A configuration window opens.

<img className="thumbnail" alt="Selecting Valheim from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/select-valheim.png" loading="lazy" />

### Step 3 — Configure the Valheim server

Set the server name and any required configuration.

The Game Panel automatically generates a **server password**, already filled in the `Server Password` field. This is the one your players enter to join you, so take note of it now. You can replace it with your own, as long as it is at least 5 characters long.

<img className="thumbnail" alt="The Valheim install window with the Server Password field" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/install-form.png" loading="lazy" />

You can expand <code className="action">Advanced settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

### Step 4 — Launch the installation

Click <code className="action">Install</code> to launch the deployment. The installation starts.

### Step 5 — Monitor the installation

Click <code className="action">Log/Console</code> to follow the installation progress in real time. The status shows **Installing**.

<img className="thumbnail" alt="Monitoring Valheim server installation" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/installation-logs.png" loading="lazy" />

### Step 6 — Verify the server is running

CPU and RAM activity becomes visible, and the <code className="action">Log/Console</code> and <code className="action">Settings</code> controls are available.

### Step 7 — Confirm installation is complete

Once the installation is finished, the status changes to **Running**.

### Step 8 — Retrieve connection information

Once your server status is **Running**, copy the IP address and port from the **Connection** column of the Game Servers list.

### Step 9 — Join your server in Valheim

1. Open **Valheim**.
2. Click **Start**, then the **Join Server** tab.
3. Click **Join IP** and paste the IP address and port from the **Connection** column.
4. Enter the password and click **Connect**.

### Enable crossplay

By default, your server is only reachable by players on Steam. Crossplay opens it to Xbox, PlayStation, and Nintendo Switch players.

Go to <code className="action">Settings</code> > <code className="action">Game Config</code> > <code className="action">Server Settings</code>, then turn on the **Crossplay** toggle in the **Network** group. Restart your server to apply the change.

<img className="thumbnail" alt="The Crossplay toggle in the Network group of the server settings" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/crossplay-setting.png" loading="lazy" />

On the next start, your server announces a **join code** in its logs. Open <code className="action">Log/Console</code> to retrieve it — console players join with this code rather than the IP address.

### Install mods with BepInEx

Valheim mods rely on a mod loader. The Game Panel installs **BepInEx**, the most widely used one, in a single click.

Stop your server first: BepInEx can only be installed while the server is stopped.

Then go to <code className="action">Settings</code> > <code className="action">Game Config</code> > <code className="action">Mods</code> and click <code className="action">Install BepInEx</code>. The **Version** field is set to `latest`: leave it as is to install the most recent version, or enter a specific one.

<img className="thumbnail" alt="The BepInEx block in the Mods tab" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/bepinex-install.png" loading="lazy" />

An upload area appears under the BepInEx block: drop your mod files there. Restart your server afterwards to load them.

:::warning
Mods are only supported by players on computer. Console players cannot install them: depending on the mods you use, they may not see the added content, or may no longer be able to join your server. Avoid combining mods and crossplay.
:::
