## Objective

The Game Panel allows you to deploy a DayZ server in a few steps. The panel handles the installation automatically, including Steam authentication and network port configuration.

**This guide explains how to deploy and connect to a DayZ server on the Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- A Steam account to authenticate the DayZ server installation.

## Instructions

### Step 1 — Access the Game Panel

Log in to your Game Panel.

From the left-hand menu, go to the <code className="action">Game Servers</code> section and click <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Game Servers section with the Add Game Server button" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/add-game-server.png" loading="lazy" />

### Step 2 — Create a DayZ server

Select **DayZ** from the game list. A configuration window opens.

### Step 3 — Configure the DayZ server

In the configuration window:

- Enter a **Server Name**.
- Enter your **Steam Username** and **Steam Password**.

:::warning
It is strongly recommended to use a dedicated Steam account for this purpose, not your personal one. Use a complex password and disable email-based two-factor authentication (Steam Guard) on that account before proceeding.
:::

<img className="thumbnail" alt="DayZ installation form showing server name and Steam credential fields" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/install-dayz-form.png" loading="lazy" />

:::info
The required network ports are configured automatically during installation. If this is your first DayZ server on the Game Panel and the default ports are available, no manual changes are needed.
:::

You can expand <code className="action">Advanced settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

### Step 4 — Launch the installation

Click <code className="action">Install</code>. The deployment starts automatically. The panel will:

1. Download the DayZ server image.
2. Install the server files.

### Step 5 — Monitor the installation

Click <code className="action">Log/Console</code> to follow the installation progress in real time. The server status shows **Installing** while the files are being deployed.

### Step 6 — Verify the server is running

Once started, confirm the server status is **Running**. CPU and RAM activity should be visible in the panel.

The following controls are available:

- <code className="action">Log/Console</code> — monitor server startup and activity in real time, and check logs if there are any issues.
- <code className="action">Settings</code> — access game configuration options.

<img className="thumbnail" alt="DayZ server with Running status and management controls" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/server-running.png" loading="lazy" />

To adjust in-panel options such as automatic updates, click <code className="action">Settings</code> on your server, then open <code className="action">Game Config</code>. For advanced configuration, use the [File Manager](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/) to edit the DayZ server configuration file directly.

<img className="thumbnail" alt="Server Settings panel with Game Config and File Manager options" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/game-config.png" loading="lazy" />

### Step 7 — Confirm installation is complete

The status changes to **Running** once installation finishes. Your DayZ server is now ready to accept connections.

### Step 8 — Retrieve connection information

In the **Connection** column of the Game Servers list, copy your server's IP address and port.

<img className="thumbnail" alt="Game Servers list with connection IP and port highlighted" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/connection-details.png" loading="lazy" />

### Step 9 — Join your server in DayZ

To join from the DayZ client:

1. Launch **DayZ**.
2. Go to **Server** and click **Direct connect**.
3. Paste the IP address and port from the **Connection** column.
4. Click **Connect**.
