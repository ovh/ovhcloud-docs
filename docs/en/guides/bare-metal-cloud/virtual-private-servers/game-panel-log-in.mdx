## Objective

The OVHcloud Game Panel provides a dedicated interface for managing your game servers. To use it, you need to log in with your credentials.

**This guide explains how to log in to the OVHcloud Game Panel and how to recover a lost password.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- The Game Panel access link provided during installation.

## Instructions

### Step 1 — Access the Game Panel

Go to your Game Panel. The access link depends on the domain you selected during installation.

<img className="thumbnail" alt="The Game Panel login page" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login.png" loading="lazy" />

### Step 2 — Log in

Enter your username and the associated password, then click <code className="action">Sign In</code> to log in to the Game Panel.

<img className="thumbnail" alt="Entering credentials on the login page" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login-form.png" loading="lazy" />

### Recover a lost password

#### Non-admin accounts

If a password has been lost, ask an administrator to reset it. Refer to [Manage users on the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-manage-users/) for details.

#### Super admin account

If the super admin password has been lost, you can reset it by connecting via SSH to the host machine, navigating to the deploy folder of the installation, and running the following command. If you are not familiar with SSH connections, refer to [How to get started with SSH connections](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction/).

```bash
sudo bash tools/reset-admin-password.sh
```

Expected output:

```console
New admin password: XXXXXXXXXX
Confirm new admin password: XXXXXXXXXX
[INFO] Updating the root user password in the database...
[INFO] Rotating JWT secret...
[INFO] Recreating the backend to invalidate existing sessions...
[INFO] Admin password reset complete for user: admin
```

Reconnect to the application with the new admin password.

:::warning
This operation disconnects all currently connected users.
:::
