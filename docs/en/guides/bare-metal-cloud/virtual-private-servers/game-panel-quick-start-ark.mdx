## Objective

The OVHcloud Game Panel allows you to deploy an ARK: Survival Evolved server in a few steps. The panel handles the installation automatically, including port configuration.

**This guide explains how to deploy and connect to an ARK: Survival Evolved server on the OVHcloud Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your OVHcloud Game Panel. From the left-hand menu, go to the `Game Servers` section and click <code className="action">Add Game Server</code>.

### Step 2 — Create an ARK: Survival Evolved server

Select **ARK: Survival Evolved** from the game list. A configuration window opens.

<img className="thumbnail" alt="Selecting ARK: Survival Evolved from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/select-ark.png" loading="lazy" />

### Step 3 — Configure the ARK: Survival Evolved server

Enter a name for your server. No further game-specific configuration is required for ARK: Survival Evolved.

:::info
If this is your first ARK server on the Game Panel and the default Game Port is available, all required ports will be automatically configured during installation. No manual setup is needed in this case.
:::

You can expand <code className="action">Advanced settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

### Step 4 — Launch the installation

Click <code className="action">Install</code> to start the deployment.

### Step 5 — Monitor the installation

Click <code className="action">Log/Console</code> to follow the installation progress in real time. While the server is installing, the status displays **Installing**.

<img className="thumbnail" alt="Monitoring ARK server installation in the logs panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/installation-logs.png" loading="lazy" />

### Step 6 — Verify the server is running

Confirm that the server status is **Running** and that CPU/RAM activity is visible. The <code className="action">Log/Console</code> and <code className="action">Settings</code> controls remain available from this view.

<img className="thumbnail" alt="ARK server with Running status" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/server-running.png" loading="lazy" />

### Step 7 — Confirm installation is complete

Once installation is finished, the server status changes to **Running**.

### Step 8 — Retrieve connection information

Copy the IP address and port from the **Connection** column of the Game Servers list.

<img className="thumbnail" alt="Connection details for the ARK server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/connection-details.png" loading="lazy" />

### Step 9 — Join your server in ARK

First, add your server to your Steam favourites:

1. In **Steam**, go to **View** > **Game Servers**.
2. Open the **Favorites** tab and click **Add a server**.
3. Paste the IP address and port from the **Connection** column, then click **OK**.

Then join from the game:

1. Launch **ARK: Survival Evolved** and click **Join ARK**.
2. Set the **Session Filter** to **Favorites**.
3. Select your server and click **Join**.
