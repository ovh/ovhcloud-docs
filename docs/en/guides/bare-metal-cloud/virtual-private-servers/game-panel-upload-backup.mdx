## Objective

The OVHcloud Game Panel lets you restore a backup by downloading an archive, extracting it, and uploading the files with the File Manager.

**This guide explains how to restore a backup on your OVHcloud Game Panel server.**

## Requirements

- A [VPS](https://www.ovhcloud.com/en-gb/vps/) in your OVHcloud account with the Game Panel feature enabled.
- A game server instance deployed on the Game Panel.
- An existing backup. Refer to [Create a backup on the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/).

## Instructions

### Step 1 — Log in to the Game Panel

Log in to your Game Panel. If you need help, refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Step 2 — Access backup settings

Once logged in:

1. Select your game server.
2. Click <code className="action">Settings</code>.
3. Go to the <code className="action">Backups</code> tab.

### Step 3 — Download a backup

At the bottom of the page, find the list of available backups. Click <code className="action">Download</code> next to the backup you want to restore.

If no backup is available, you must first create one. Refer to [Create a backup on the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/).

<img className="thumbnail" alt="Downloading a backup from the list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-backup/download-backup.png" loading="lazy" />

### Step 4 — Extract the backup

Once the backup is downloaded, extract the archive on your computer. The extracted contents include the `serverfiles` directory.

### Step 5 — Stop the server

Before continuing, ensure your game server is fully stopped from the Game Panel. This prevents file corruption or conflicts during the restore.

### Step 6 — Open the File Manager

On your server, click <code className="action">Settings</code>, then open the <code className="action">File Manager</code> tab and locate the `serverfiles` folder.

<img className="thumbnail" alt="Serverfiles directory on the server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-backup/serverfiles.png" loading="lazy" />

Before uploading the backup, you should either:

- **Delete it** with the <code className="action">Delete</code> action if you no longer need it.
- **Rename it** with the <code className="action">Rename</code> action to keep it as a backup.
- **Download it locally** with the <code className="action">Download</code> action.

### Step 7 — Upload the backup files

In the File Manager, click <code className="action">Upload files</code> or drag and drop the local `serverfiles` folder from the extracted backup into the file list.

For most games, restoring the `serverfiles` folder is sufficient. However, some games may store configuration files in other locations. If the game configuration was modified, it is also recommended to restore the `config-lgsm` folder when available.

### Step 8 — Start the server

Once the upload is complete, restart your server from the Game Panel. Your server should now run using the restored backup environment.
