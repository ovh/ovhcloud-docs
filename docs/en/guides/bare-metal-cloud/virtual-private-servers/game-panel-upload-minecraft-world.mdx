## Objective

The OVHcloud Game Panel lets you upload a custom Minecraft world by transferring files with the File Manager and adjusting the world folder configuration.

**This guide explains how to upload a custom world to your Minecraft server on the OVHcloud Game Panel.**

## Requirements

- A [VPS](https://www.ovhcloud.com/en-gb/vps/) in your OVHcloud account with the Game Panel feature enabled.
- A Minecraft server deployed on the Game Panel. Refer to [Deploy a Minecraft server on the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

:::warning
Make sure your Minecraft server is **stopped** before performing any of the following actions.
:::


## Instructions

### Step 1 — Open the File Manager

On your Minecraft server, click <code className="action">Settings</code>, then open the <code className="action">File Manager</code> tab.

### Step 2 — Locate the world folder

In the File Manager, navigate to:

```
data > serverfiles
```

Inside this directory, you will see a folder named `world`. This folder contains your current Minecraft map and is created by default.

<img className="thumbnail" alt="The default world folder in the server file structure" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder.png" loading="lazy" />

### Step 3 — Prepare the server for your new map

Before uploading your own map, you need to free up the `world` folder name. You have three options:

- **Delete it** with the <code className="action">Delete</code> action if you no longer need it.
- **Rename it** with the <code className="action">Rename</code> action to keep it as a backup.
- **Download it locally** with the <code className="action">Download</code> action.

### Step 4 — Upload your custom map

In the File Manager, while inside `data > serverfiles`, click <code className="action">Upload files</code> or drag and drop your map folder into the file list.

### Step 5 — Configure the world name (if needed)

If your map folder is not named `world`, you must update the server configuration:

1. Go back to the Game Panel.
2. Open your server <code className="action">Settings</code>.
3. Navigate to the <code className="action">Game Config</code> tab.
4. Locate the option **World folder name**.
5. Enter the exact name of your map folder.

<img className="thumbnail" alt="Configuring the world folder name in Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder-name-config.png" loading="lazy" />

:::info
**Using multiple maps**: You can store multiple maps on your server and switch between them easily. Change the **World folder name** in the Game Config section to load a different map. Do not forget to restart the server after changing the setting.
:::


### Step 6 — Start the server

Restart your server from the Game Panel. Your custom Minecraft map is now ready to use.
