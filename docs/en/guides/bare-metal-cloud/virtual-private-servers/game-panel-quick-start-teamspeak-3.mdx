## Objective

The Game Panel lets you deploy and configure a TeamSpeak 3 voice server in a few minutes — no command line or system knowledge required.

**This guide explains how to deploy and connect to a TeamSpeak 3 server on the Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- A TeamSpeak 3 client installed on your machine to test the connection.

## Instructions

### Step 1 — Access the Game Panel

From your Game Panel dashboard, click <code className="action">Add Game Server</code>.

### Step 2 — Create a TeamSpeak 3 server

In the list of available games, search for and select **TeamSpeak 3**. A configuration window opens.

<img className="thumbnail" alt="Selecting TeamSpeak 3 from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/select-teamspeak-3.png" loading="lazy" />

### Step 3 — Configure the TeamSpeak 3 server

A configuration page opens. Default values are ready to use for an immediate launch, but you can customise them to match your needs.

Among the available settings, you can modify:

- <code className="action">Server Name</code>: Give your server an instance name (e.g., `My TS3 server`).
- <code className="action">Network Ports</code>: Pre-configured automatically:
    - `9987` (UDP) — voice
    - `10011` (TCP) — ServerQuery
    - `30033` (TCP) — file transfer

<img className="thumbnail" alt="TeamSpeak 3 Network Ports configuration" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-network-ports.png" loading="lazy" />

:::info
You can modify these settings, but they are not required to launch the server.
:::

You can expand <code className="action">Advanced settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

### Step 4 — Launch the installation

Once you have reviewed the configuration, click <code className="action">Install</code> to start the deployment.

<img className="thumbnail" alt="TeamSpeak 3 install configuration form with Install button" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-install-form.png" loading="lazy" />

### Step 5 — Monitor the installation

The deployment starts automatically. Let the installation run without closing the page.

Track the process in real time by clicking <code className="action">Log/Console</code> to display the installation messages.

<img className="thumbnail" alt="TeamSpeak 3 installation logs panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-installation-logs.png" loading="lazy" />

### Step 6 — Verify the server is running

Confirm that your server displays the **Running** status.

<img className="thumbnail" alt="TeamSpeak 3 server with Running status" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-running.png" loading="lazy" />

### Step 7 — Confirm installation is complete

Once installation finishes, the status changes to **Running**. Your server is live.

### Step 8 — Retrieve connection information

Retrieve the IP address and port from the <code className="action">Connection</code> column of the Game Servers list to connect from the TeamSpeak 3 client.

### Step 9 — Join your server in TeamSpeak 3

In the TeamSpeak 3 client:

1. Click <code className="action">Connections</code> > <code className="action">Connect</code>.
2. Enter the address shown in the **Connection** column of the Game Servers list.
