## Objective

The OVHcloud Game Panel lets you deploy and manage game servers directly on your VPS. Before using it, you must install it on your server from the OVHcloud Control Panel.

**This guide explains how to install the Game Panel on your VPS.**

## Requirements

- A [VPS](/links/bare-metal/vps) in your OVHcloud account.
- Access to the <ManagerLink to="/">OVHcloud Control Panel</ManagerLink>.

## Instructions

### Step 1 — Log in to the OVHcloud Control Panel

Log in to your <ManagerLink to="/">OVHcloud Control Panel</ManagerLink>. If you need help logging in, refer to [Logging in to the OVHcloud Control Panel](/guides/account-and-service-management/account-information/ovhcloud-account-login/).

### Step 2 — Switch to the Beta version of the OVHcloud Control Panel

The Game Panel installation feature is currently available in the Beta version of the OVHcloud Control Panel.

In the upper-right corner of the page, click <code className="action">Discover the console</code> (marked with the **BETA** badge) to switch to the Beta interface.

<img className="thumbnail" alt="The Discover the console link in the OVHcloud Control Panel header" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/discover-the-console-beta.png" loading="lazy" />

### Step 3 — Open your VPS page

From the OVHcloud Control Panel:

1. In the menu at the top of the page, click <code className="action">Bare Metal Cloud</code>.
2. In the left-hand menu, select <code className="action">VPS</code>.
3. In the **Virtual private servers (VPS)** list, click the name of your VPS.

<img className="thumbnail" alt="The VPS list in the Bare Metal Cloud section of the OVHcloud Control Panel Beta" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/open-vps-page.png" loading="lazy" />

### Step 4 — Install the Game Panel

In the **Overview** tab, locate the **General information** section. Under the **Distribution** line, click <code className="action">Reinstall my VPS with Game Panel</code>.

<img className="thumbnail" alt="The Reinstall my VPS with Game Panel link in the General information section of the VPS Overview tab" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/reinstall-with-game-panel-entry.png" loading="lazy" />

Fill in the following fields, then start the installation.

<img className="thumbnail" alt="The Reinstall my VPS with Game Panel form" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/reinstall-with-game-panel-form.png" loading="lazy" />

**Choose an operating system**

In the **Operating system** list, select the operating system on which you want to install the Game Panel. All operating systems displayed in the list are fully compatible with the Game Panel.

**Configure the domain name**

By default, the **Domain name** field contains your server's default hostname, allowing you to access the Game Panel through an address similar to `https://vps-xxxx.vps.ovh.net`.

If you prefer, you can use your own domain name instead. Before continuing, make sure your domain's DNS A record points to your VPS public IP address. The form checks where the domain resolves: the message **The domain points to your VPS** confirms the SSL certificate can be issued.

If you do not already own a domain name or need to configure its DNS records, refer to the following resources:

- [OVHcloud domain names](/links/web/domains)
- [Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit/)

**Enter an email address**

The **Let's Encrypt email address** field is pre-filled with the email address associated with your OVHcloud account. You can replace it with another address. This address is used to set up the SSL certificate and receives certificate-related notifications, including expiry warnings.

**Choose the administrator account name**

In the **Administrator username** field, enter the username for the administrator account that will be created (`admin` by default). This account becomes the super administrator of the Game Panel and has the highest level of privileges.

**Save your generated admin password**

A password for the Game Panel is generated and displayed in the **Administrator password** field. Copy it with the copy icon, or click <code className="action">Generate another</code> to get a new password. Store this password in a safe place, as it cannot be viewed again later.

**(Optional) Add an SSH key**

The **SSH key to pre-install** section lets you pre-install on the server one of the SSH public keys stored in your OVHcloud account. This is an optional advanced configuration. If your account holds no SSH key, add one from the **My account** section of the Control Panel. For more information, refer to [How to store public authentication keys in the OVHcloud Control Panel](/guides/bare-metal-cloud/dedicated-servers/import-keys-control-panel/).

**Start the installation**

Click <code className="action">Confirm</code> to begin the installation. This button is only enabled once an operating system has been selected.

### Step 5 — Connect to the Game Panel

The selected operating system is installed first. Once it has been deployed, you receive an automatic email containing the SSH password for your server. Keep this password in a safe place, as you may need it later if you connect to the server directly via SSH.

A few minutes later, the Game Panel installation completes automatically.

You can then open your server's hostname in a web browser, for example `https://vps-xxxx.vps.ovh.net`. Sign in using the password that was generated during the installation to start using the Game Panel.

:::info
The generated admin password is shown only once during the installation. If you lose it, refer to the password recovery section of [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
:::
