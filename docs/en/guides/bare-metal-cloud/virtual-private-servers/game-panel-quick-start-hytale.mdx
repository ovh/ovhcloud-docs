## Objective

The OVHcloud Game Panel lets you deploy a Hytale server with automated installation and port configuration.

**This guide explains how to deploy and connect to a Hytale server on the OVHcloud Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- A Hytale account, required to authenticate during the installation.

## Instructions

### Step 1 — Access the Game Panel

Log in to your OVHcloud Game Panel. From the left-hand menu, go to the **Game Servers** section and click <code className="action">Add Game Server</code>.

### Step 2 — Create a Hytale server

Select **Hytale** from the game list. A configuration window opens.

<img className="thumbnail" alt="Selecting Hytale from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-hytale/select-hytale.png" loading="lazy" />

### Step 3 — Configure the Hytale server

Enter a **Server Name** (for example, `Hytale Server`). The required network ports are configured automatically during installation.

You can expand <code className="action">Advanced settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

### Step 4 — Launch the installation

Click <code className="action">Install</code>. The deployment starts automatically. Wait a few minutes while the image downloads and the server installs.

During the installation, the Game Panel prompts you to authenticate with your Hytale account through a button that redirects you to the official Hytale website using OAuth. You are asked to authenticate twice:

- The first authentication allows the Game Panel to download the server files.
- The second authentication occurs when the server starts for the first time and is required to obtain a game session from Hypixel.

Once each authentication is completed, the installation and startup process continues automatically.

### Step 5 — Monitor the installation

Click <code className="action">Log/Console</code> to follow progress in real time. The status shows **Installing**.

### Step 6 — Verify the server is running

Check that the server status displays **Running** and that CPU/RAM activity is visible.

Available actions:

- <code className="action">Log/Console</code>: Open the console to monitor startup and check logs if there are any issues.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: Access game settings.

<img className="thumbnail" alt="Hytale server with Running status" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-hytale/hytale-running.png" loading="lazy" />

### Step 7 — Confirm installation is complete

Once installation finishes, the status changes to **Running** and the server is ready to use.

### Step 8 — Retrieve connection information

In the **Connection** column of the Game Servers list, copy your server's IP address and port.

### Step 9 — Join your server in Hytale

In Hytale:

1. Launch the game and open the **Servers** menu.
2. Click **Direct Connect** and enter the IP address and port from the **Connection** column.
3. Click **Connect** to join your server.

### Best practices

- Configure permissions via <code className="action">User Administration</code>.
- Perform regular backups.
- Customise your game settings.

:::info
To go further, adjust your server settings, restrict access with a password or whitelist, or fine-tune performance options.
:::
