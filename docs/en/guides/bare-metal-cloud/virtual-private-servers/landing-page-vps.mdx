## OVHcloud VPS

An [OVHcloud VPS](/links/bare-metal/vps) (Virtual Private Server) is a virtual machine with full root access, hosted on OVHcloud infrastructure — the middle ground between a managed Web Hosting plan and a dedicated server. It is the ideal first server to host your own web services and applications.

With an OVHcloud VPS, you can:

- Host websites and web applications
- Run self-hosted applications (Docker, Nextcloud, n8n, AI agents...)
- Host game servers with the Game Panel
- Upgrade your resources as your project grows
- Protect your data with snapshots and automated backups
