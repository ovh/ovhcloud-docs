## Objective

- Identify essential information.
- Know where to perform the main actions.

- An active [VPS](/links/bare-metal/vps) offer in your OVHcloud account

### Dashboard <a name="controlpanel"></a>

{/* CP-STEPS-START:dashboard */}

The <code className="action">Overview</code> tab is the **main dashboard** of your VPS.

It centralises **key information about the service** and provides access to **essential management actions**.

#### General information <a name="myvps"></a>

{/* CP-STEPS-START:your-vps */}

The **General information** section shows the basic information about your VPS. The service status is displayed next to the name of your VPS, at the top of the page. Click the tabs below to display the details.

<Tabs>
  <Tab label="Name">
    To customise the name of your VPS, click the pencil icon next to its name at the top of the page, enter the new name, then click the check mark icon to save it. This feature is useful for easier navigation in the OVHcloud Console when managing multiple VPS services. However, the internal service name remains in the format *VPS-XXXXXXX.VPS.ovh.net*.
  </Tab>
  <Tab label="Boot">
    The boot mode indicated is either:
    
    - In **normal mode** (*LOCAL*), where the server loads the installed operating system.
    - In **rescue mode**, provided by OVHcloud for troubleshooting.
    
    Click the <code className="action">⋮</code> button in the **Additional actions** row of the section, then select <code className="action">Reboot my VPS</code> to [reboot the VPS](#rebootvps) or <code className="action">Reboot in rescue mode</code> to boot it in rescue mode if necessary.
    
    If needed, find more information in our guide on [rescue mode](/guides/bare-metal-cloud/virtual-private-servers/rescue).
  </Tab>
  <Tab label="Distribution">
    This is the currently installed operating system. Click the <code className="action">Reinstall my VPS</code> link under it to [reinstall the same operating system or choose another one from the available options](#reinstallvps).
    
    :::warning
    A reinstallation will delete all data currently hosted on the VPS (except for additional disks).

    :::

    
    :::info
    If you ordered a **Windows** VPS, you can only choose a Windows OS for reinstallation. Similarly, if Windows was not selected during the order, it cannot be installed after the VPS is delivered.

    :::

    
    Once the system is installed, you are responsible for applying the operating system security updates. You can find more information in the section "[Reinstall your VPS](#reinstallvps)" as well as in our guide "[Securing a VPS](/guides/bare-metal-cloud/virtual-private-servers/secure-your-vps)".
  </Tab>
  <Tab label="Region">
    The **Region** field provides information about the location of your VPS. This can be useful for identifying and assessing any potential impacts on your service, such as those mentioned in [incident or maintenance reports](https://bare-metal-servers.status-ovhcloud.com/).
  </Tab>
</Tabs>

{/* CP-STEPS-END:your-vps */}


#### Your configuration <a name="myconf"></a>

Click on the tabs below to display the details of this section.

{/* CP-STEPS-START:your-configuration */}

<Tabs>
  <Tab label="Model">
    This item indicates the commercial reference identifying the VPS model, corresponding to the [VPS offers on our website](/links/bare-metal/vps).
  </Tab>
  <Tab label="Processor/Memory/Primary disk">
    The current resources of your VPS are displayed here. To increase them, click the <code className="action">Upgrade</code> link under **Model**. Note that upgrades are limited by the chosen VPS model and may only be available by moving to a [higher range](/links/bare-metal/vps).
  </Tab>
  <Tab label="Additional storage">
    This item indicates whether additional disks are enabled on your VPS. Additional disks increase the server's storage capacity beyond that included in the initial configuration. You can, for example, store backup data on them. Manage them from the <code className="action">Additional disk</code> tab.
  </Tab>
</Tabs>

{/* CP-STEPS-END:your-configuration */}


#### Connection details <a name="ip"></a>

Click on the tabs below to display the details of this section.

{/* CP-STEPS-START:ip */}

<Tabs>
  <Tab label="IPv4">
    The main public IPv4 address of the VPS is automatically configured during installation. Find more information on IP management in our guide "[Configuring an alias IP address](/guides/bare-metal-cloud/virtual-private-servers/configuring-ip-aliasing)".
  </Tab>
  <Tab label="IPv6/Gateway">
    Find the public IPv6 address and the associated gateway address (**IPv6 gateway**) here. These are automatically attached to the VPS during installation. Find more information in our guide "[Configuring IPv6 on a VPS server](/guides/bare-metal-cloud/virtual-private-servers/configure-ipv6)".
  </Tab>
  <Tab label="Secondary DNS">
    This item indicates whether domains are configured on the OVHcloud secondary DNS of your VPS, a feature useful for hosting DNS services. Adding or deleting a secondary DNS domain is not available in the OVHcloud Console. Consult our guide "[Configuring an OVHcloud secondary DNS on a VPS](/guides/bare-metal-cloud/virtual-private-servers/adding-secondary-dns-on-vps)" for more details on this subject.
  </Tab>
</Tabs>

{/* CP-STEPS-END:ip */}


#### Backup <a name="save"></a>

{/* CP-STEPS-START:backup */}

These options refer to additional VPS services for backing up and restoring your system.

<Tabs>
  <Tab label="Snapshot">
    A snapshot on a VPS is an instant backup of the server's state, allowing you to quickly restore the system in case of a problem. The `Snapshot` option allows you to create a manual snapshot as a single restore point. If the option is not active on your VPS, order it with the <code className="action">Order a snapshot</code> link.
  </Tab>
  <Tab label="Automated backup">
    A daily system backup (excluding additional disks) is automatically performed and kept for 24 hours (applicable only to services ordered from 7 August 2025). By switching the **Automated backup** option to **Premium**, you will have the last 7 daily backups of your VPS, which you can use for mounting and restoring.  
    Compared to manual snapshots, this feature increases data security by creating multiple restore points at regular intervals.
  </Tab>
</Tabs>

{/* CP-STEPS-END:backup */}


Find all information on the backup solutions available for your service on the [VPS product page](/links/bare-metal/vps-options) and in our guides "[How to use snapshots on a VPS](/guides/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps)" and "[How to use automated backups on a VPS](/guides/bare-metal-cloud/virtual-private-servers/using-automated-backups-on-a-vps)".

#### Reboot your VPS <a name="rebootvps"></a>

A reboot may be necessary to apply configuration updates or to resolve a malfunction. Where possible, perform a "software reboot" from the server's graphical interface (Windows, Plesk, etc.) or via the command line below:

```bash
sudo reboot
```

{/* CP-STEPS-START:reboot-your-vps */}

However, you can perform a forced reboot at any time in the <ManagerLink to="/">OVHcloud Console</ManagerLink>. In the <code className="action">Overview</code> tab, click the <code className="action">⋮</code> button in the **Additional actions** row of the **General information** section. Select <code className="action">Reboot my VPS</code> and click <code className="action">Confirm</code> in the window that appears.

#### Reinstall your VPS <a name="reinstallvps"></a>

{/* CP-STEPS-START:reinstall-your-vps */}

The reinstallation of your VPS can be done from the OVHcloud Console. This operation is generally used in case of system problems, environment change or to start with a clean installation.

In the **General information** section of the <code className="action">Overview</code> tab, click the <code className="action">Reinstall my VPS</code> link under **Distribution**.

<img className="thumbnail" alt="Reinstall my VPS link under Distribution in the OVHcloud Console" src="/images/assets/screens/console/product-selection/bare-metal-cloud/vps/cp-reinst.png" loading="lazy" />

In the **Reinstall my VPS** panel that opens, choose an operating system from the **Operating system** drop-down list. The options offered are [images compatible with an OVHcloud VPS](/guides/public-cloud/compute/image-life-cycle) and are immediately functional after installation.

If you have selected a compatible operating system, you can provide a **public key** to be automatically installed. Two options are available:

- Manually copy the key string and paste it into the `Your Public SSH key` field.
- If you have previously [stored a public key](/guides/bare-metal-cloud/dedicated-servers/import-keys-control-panel) in the <ManagerLink to="/">OVHcloud Console</ManagerLink>, select the desired key from the `SSH key to pre-install` drop-down menu.

<img className="thumbnail" alt="Reinstall my VPS panel in the OVHcloud Console" src="/images/bare-metal-cloud/virtual-private-servers/understand-vps-control-panel/console/reinstall.png" loading="lazy" />

For more information on this topic, consult our guides:

- [How to create and use authentication keys for SSH connections to OVHcloud servers](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutorial - How to use PuTTY for SSH connections and authentication](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

If you have selected a stored key in the `SSH key to pre-install` drop-down menu and do not need a password to connect, tick the `I do not wish to receive my VPS authentication codes by email.` checkbox.

:::warning
Reinstallation will format all the server's disks. It is strongly recommended to create a snapshot of your VPS before proceeding, so that you can return to the previous state in case of a problem.

:::


:::info
**Licences**

Some operating systems or proprietary platforms, such as Plesk or cPanel, require licences that generate additional costs. Licences can be managed from the OVHcloud Console: click <code className="action">Bare Metal Cloud</code> in the top navigation bar, then click <code className="action">Licences</code> in the left-hand menu.

To have a **Windows** operating system running on a VPS, you must have previously chosen it **in the ordering process**. A VPS with another OS installed cannot be reinstalled with Windows via the method described above.

:::


The reinstallation process can take a few minutes.
