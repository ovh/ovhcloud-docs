## Objective

The OVHcloud Game Panel lets you create backups of your game server instances, so you can restore your server to a previous state if needed.

**This guide explains how to create a backup of your game server on the OVHcloud Game Panel.**

## Requirements

- A [VPS](https://www.ovhcloud.com/en-gb/vps/) in your OVHcloud account with the Game Panel feature enabled.
- A game server instance deployed on the Game Panel. Refer to [Getting started with the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

## Instructions

### Step 1 — Log in to the Game Panel

Log in to your Game Panel. If you need help, refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Step 2 — Access backup settings

Once logged in:

1. Select your game server.
2. Click <code className="action">Settings</code>.
3. Go to the <code className="action">Backup</code> tab.

<img className="thumbnail" alt="The backup settings tab" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/backup-tab.png" loading="lazy" />

### Step 3 — Create a backup

Click <code className="action">Create backup now</code>.

:::info
We recommend keeping the **Stop server before backup** option enabled to ensure consistent saves.
:::


<img className="thumbnail" alt="Creating a backup with the stop server option" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/create-backup.png" loading="lazy" />

Once the backup is complete, the file is available for download in the same settings section.


## Go further
