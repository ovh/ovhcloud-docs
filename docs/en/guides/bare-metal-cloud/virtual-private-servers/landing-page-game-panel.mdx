Welcome to the documentation dedicated to the [OVHcloud Game Panel](/links/bare-metal/game-hub). The Game Panel lets you deploy and manage game servers for a wide range of popular titles directly from your OVHcloud VPS or dedicated server. Here you will find every guide available to install, configure, and administer your game servers.

## What is the Game Panel?

The OVHcloud Game Panel is a streamlined interface for deploying and managing game servers on your VPS or dedicated server. With automated deployment and built-in tools, you can launch instances, customise configurations, and monitor performance — without managing the underlying infrastructure by hand.

With the Game Panel, you can:

- Deploy game servers for 140+ titles (Minecraft, ARK, Counter-Strike 2, Rust, and more)
- Run several game servers on a single VPS or dedicated server
- Manage server files, backups, and scheduled tasks
- Control access with per-user, per-server permissions
- Monitor CPU, RAM, disk, and network usage in real time
