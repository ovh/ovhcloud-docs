## Objective

The Game Panel lets you deploy an Arma Reforger server in a few steps. The panel handles the installation automatically, including port configuration.

**This guide explains how to deploy and connect to an Arma Reforger server on the Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your Game Panel. From the left-hand menu, go to the `Game Servers` section and click <code className="action">Add Game Server</code>.

### Step 2 — Create an Arma Reforger server

Select **Arma Reforger** from the game list. A configuration window opens.

<img className="thumbnail" alt="Selecting Arma Reforger from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/select-arma-reforger.png" loading="lazy" />

### Step 3 — Configure the Arma Reforger server

Set the server name and review the configuration before launching the installation.

:::info
If this is your first Arma Reforger server on the Game Panel and the default Game Port is available, all required ports will be automatically configured during installation. No manual setup is needed in this case.
:::

You can expand <code className="action">Advanced settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

### Step 4 — Launch the installation

Click <code className="action">Install</code> to launch the deployment.

### Step 5 — Monitor the installation

Click <code className="action">Log/Console</code> to follow the installation progress in real time. While the server is installing, the status displays **Installing**.

<img className="thumbnail" alt="Monitoring Arma Reforger server installation in the logs panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-logs.png" loading="lazy" />

### Step 6 — Verify the server is running

Confirm that the server status is **Running**. The <code className="action">Log/Console</code> and <code className="action">Settings</code> controls remain available to manage the server.

### Step 7 — Confirm installation is complete

Once installation is finished, the server status changes to **Running**.

### Step 8 — Retrieve connection information

Copy the IP address and port from the **Connection** column of the Game Servers list.

<img className="thumbnail" alt="Connection details for the Arma Reforger server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-connection-details.png" loading="lazy" />

### Step 9 — Join your server in Arma Reforger

1. Open **Arma Reforger** and access the main menu.
2. Click **Multiplayer**, then open the **Community** tab.
3. Search for your server name.
4. Once found, click it, then click **Join**.
