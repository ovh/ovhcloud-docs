## Objective

The Game Panel lets you deploy a Team Fortress 2 server in a few steps. The panel handles the installation automatically, including port configuration.

**This guide explains how to deploy and connect to a Team Fortress 2 server on the Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your Game Panel. From the left-hand menu, go to the `Game Servers` section and click <code className="action">Add Game Server</code>.

### Step 2 — Create a Team Fortress 2 server

Select **Team Fortress 2** from the game list. A configuration window opens.

<img className="thumbnail" alt="Selecting Team Fortress 2 from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/select-tf2.png" loading="lazy" />

### Step 3 — Configure the Team Fortress 2 server

Set the server name and review the configuration.

:::info
If this is your first Team Fortress 2 server on the Game Panel and the default Game Port is available, all required ports are configured automatically. No manual setup is needed.
:::

You can expand <code className="action">Advanced settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

### Step 4 — Launch the installation

Click <code className="action">Install</code> to start the deployment.

### Step 5 — Monitor the installation

Click <code className="action">Log/Console</code> to follow the installation progress in real time. While the server is installing, the status displays **Installing**.

<img className="thumbnail" alt="Monitoring Team Fortress 2 server installation in the logs panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-installation-logs.png" loading="lazy" />

### Step 6 — Verify the server is running

Confirm the status is **Running**; CPU and RAM activity is visible. You can use the <code className="action">Log/Console</code> and <code className="action">Settings</code> controls to manage the server.

<img className="thumbnail" alt="Team Fortress 2 server with Running status" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-running.png" loading="lazy" />

### Step 7 — Confirm installation is complete

Once installation finishes, the server status changes to **Running**.

### Step 8 — Retrieve connection information

Copy the IP address and port from the **Connection** column of the Game Servers list.

### Step 9 — Join your server in Team Fortress 2

First, add your server to your Steam favourites:

1. In **Steam**, go to **View** > **Game Servers**.
2. Open the **Favorites** tab and click **Add a server**.
3. Paste the IP address and port from the **Connection** column, then click **OK**.

Then launch **Team Fortress 2** and click **Connect** on your favourited server.
