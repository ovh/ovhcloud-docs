## Objective

The OVHcloud Game Panel lets you deploy a Project Zomboid server with automated installation and port configuration.

**This guide explains how to deploy and connect to a Project Zomboid server on the OVHcloud Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your OVHcloud Game Panel. From the left-hand menu, go to the `Game Servers` section and click <code className="action">Add Game Server</code>.

### Step 2 — Create a Project Zomboid server

Select **Project Zomboid** from the game list. A configuration window opens.

<img className="thumbnail" alt="Selecting Project Zomboid from the game list in the Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/select-project-zomboid.png" loading="lazy" />

### Step 3 — Configure the Project Zomboid server

In this section, you can set a name for your server and pick the <code className="action">Branch</code> — the Steam branch of the game to install, from a list that is updated automatically. Choose it carefully: changing the branch later can corrupt an existing world, so this is an install-time choice.

An administrator password is also generated automatically. It is the password of the in-game administrator account, used to grant yourself administrator rights and run the privileged console commands — it is **not** the password players use to join the server.

:::warning
Make sure you keep this administrator password in a secure place.
:::

You can expand <code className="action">Advanced Settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

<img className="thumbnail" alt="Project Zomboid server configuration form with the branch and administrator password" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/configure-server.png" loading="lazy" />

### Step 4 — Launch the installation

Click <code className="action">Install</code> to start the deployment.

### Step 5 — Monitor the installation

Click <code className="action">Log/Console</code> to follow the installation progress in real time. As soon as the installation starts, the Game Panel also offers an <code className="action">Open Logs / Console</code> button that opens the same view.

While the server is installing, the status displays **Installing**. The logs panel shows detailed progress.

<img className="thumbnail" alt="Monitoring Project Zomboid server installation in the logs panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/installation-logs.png" loading="lazy" />

### Step 6 — Confirm installation is complete

Once the installation is finished, the server status changes to **Running**.

### Step 7 — Verify the server is running

Confirm that CPU and RAM activity is visible. You can use the <code className="action">Log/Console</code> and <code className="action">Settings</code> controls to manage the server.

<img className="thumbnail" alt="Project Zomboid server with Running status and CPU and RAM activity" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/server-running.png" loading="lazy" />

### Step 8 — Retrieve connection information

Copy the IP address and port from the **Connection** column of the `Game Servers` list.

### Step 9 — Join your server in Project Zomboid

To join your server from the Project Zomboid client:

1. Open **Project Zomboid** and click **Multiplayer**, then **Add server**.
2. Enter a name for the server, then the IP address and port from the **Connection** column of the Game Panel. Also enter the server password, if the server has one — this is the password players use to join, not the administrator password.
3. Click **SAVE**.
4. Click **Add new account** to create a game account for this server, then set a name and a password.

### Connect as an administrator

Once you have added the server to the **Multiplayer** menu, create a new character for it, choosing a username and entering the server's administrator password.

To retrieve this password, click <code className="action">Settings</code> in the Game Panel, open the <code className="action">Game Config</code> section, then the <code className="action">Server Settings</code> tab: **Admin Password** sits at the bottom of the page. The value is masked — click the eye icon to reveal it.

Once you are logged in with this character, an **Admin** icon appears on the left-hand side of the screen. Click it to access the administration tools, run commands and moderate your server.

### Update the server to a new game version

By default, the server does not update automatically when a new version is available, to avoid compatibility issues or interrupted games.

To enable automatic updates, click <code className="action">Settings</code>, open the <code className="action">Game Config</code> section, then enable the <code className="action">Update on start</code> option at the bottom of the page (disabled by default). Click <code className="action">Save &amp; Restart</code> to apply the changes. The server then applies each new update automatically.
