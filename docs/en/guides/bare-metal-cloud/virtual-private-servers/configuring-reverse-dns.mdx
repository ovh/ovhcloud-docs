## Objective

Reverse DNS (*rDNS*) is the complement to "forward" DNS resolution which resolves domain names into IP addresses. With reverse DNS resolution, an IP address can resolve into the domain name (or host name) it is mapped to. This means that DNS queries of the associated IP address will return this domain name.

Configuring the reverse DNS resolution for a server is especially useful when sending emails. Spam protection systems will better validate a mail server if a reverse DNS lookup of the IP address resolves correctly.

**This guide explains how to configure the reverse DNS path for your IP address in the OVHcloud Console.**

## Requirements

- An IP address attached to a service in your OVHcloud account
- A domain name with its `A` record or `AAAA` record mapped to your service

## Instructions

{/* CP-STEPS-START:configure-reverse-dns */}

On the **IP addresses** page, you can narrow down the list using the quick filters above the table (**IPv4**, **IPv6**, **Parked IPs**, **BYOIP**). You can also search for a specific IP address in the **Search** field.

<img className="thumbnail" alt="IP addresses page in the OVHcloud Console with the Search field" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/ip-list-search.png" loading="lazy" />

Click the IP address concerned to open its page, then click the <code className="action">Reverse DNS</code> tab. Click the <code className="action">Configure</code> button above the table.

<img className="thumbnail" alt="Reverse DNS tab of an IP address in the OVHcloud Console with the Configure button" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-tab.png" loading="lazy" />

In the **Configure Reverse DNS** window, enter your reverse path in the **Reverse DNS hostname** field and click <code className="action">Configure</code>.

<img className="thumbnail" alt="Configure Reverse DNS window in the OVHcloud Console with the Reverse DNS hostname field" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-configure.png" loading="lazy" />

To edit an existing reverse path, follow the same steps: when the IP address already has a reverse, the **Reverse DNS hostname** field opens pre-filled with it. Replace it with the new value and click <code className="action">Configure</code>.

{/* CP-STEPS-END:configure-reverse-dns */}

:::warning
When you enter your domain name in the reverse, it immediately double-checks whether the `A` / `AAAA` record refers back to the same IP. This is used in anti-spam procedures, so your DNS record must be valid and propagated. There are certain rules to follow while entering the reverse:

 - It cannot start with a `-`.
 - It cannot be longer than 63 characters.
 - It cannot contain uppercase characters.
 - It can end with a `.`: the OVHcloud Console accepts both `domain.tld` and `domain.tld.`.

:::


:::info
If the modification does not work as expected, verify that the `A` / `AAAA` record is correctly configured in the DNS zone of your domain name. Bear in mind that it might take up to 24 hours for DNS zone changes to be effective, in case you have only recently edited a record.

If the domain name is managed by OVHcloud as its registrar **and it uses OVHcloud DNS servers**, you can refer to [this guide](/guides/web-cloud/domains/dns-zone-edit).

:::
