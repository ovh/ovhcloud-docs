## Objective

PaperMC is a high-performance Minecraft server implementation that supports plugins for extending gameplay. The Game Panel lets you deploy a PaperMC server in a few clicks and customise it by uploading plugins.

**This guide explains how to install a PaperMC server on the Game Panel and add plugins.**

## Requirements

- A [VPS](https://www.ovhcloud.com/en-gb/vps/) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Install a PaperMC server

From the main Game Panel page, click <code className="action">Add Game Server</code>, locate **PaperMC**, and click <code className="action">Select</code>.

For more details on server installation, refer to [Getting started with the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

### Step 2 — Download plugins

Download plugins from a trusted source such as the [PaperMC Hangar](https://hangar.papermc.io/) repository.

### Step 3 — Upload plugins with the File Manager

On your PaperMC server, click <code className="action">Settings</code>, then open the <code className="action">File Manager</code> tab. Navigate to the `serverfiles` folder, open the `plugins` directory, and upload your plugin files using <code className="action">Upload files</code> or drag and drop.

### Step 4 — Restart the server

From the main Game Panel page, restart your server using the dedicated button.

:::info
Monitor the server logs to confirm that the server starts correctly and that the plugins are loaded.
:::
