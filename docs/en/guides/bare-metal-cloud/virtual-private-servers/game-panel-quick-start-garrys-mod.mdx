## Objective

The Game Panel lets you deploy a Garry's Mod server with automated installation and port configuration.

**This guide explains how to deploy and connect to a Garry's Mod server on the Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps-game) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your Game Panel. Go to the `Game Servers` section in the left-hand menu and click <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Game Servers section with the Add Game Server button" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/game-servers-list.png" loading="lazy" />

### Step 2 — Create a Garry's Mod server

Select **Garry's Mod** from the game list. A configuration window opens.

<img className="thumbnail" alt="Selecting Garry's Mod from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/select-garrys-mod.png" loading="lazy" />

### Step 3 — Configure the Garry's Mod server

Enter a **Server Name** (for example `Garry's Mod Server`). The required network ports are configured automatically during installation.

You can expand <code className="action">Advanced settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

### Step 4 — Launch the installation

Click <code className="action">Install</code>. The deployment starts automatically. Allow a few minutes for the image download and the server installation.

### Step 5 — Monitor the installation

Click <code className="action">Log/Console</code> to follow the progress in real time. The status shows **Installing**.

### Step 6 — Confirm installation is complete

Once the installation is finished and the server has started, the status changes to **Running**.

### Step 7 — Verify the server is running

Confirm that CPU and RAM activity is visible. You can use the <code className="action">Log/Console</code> and <code className="action">Settings</code> controls to manage the server.

<img className="thumbnail" alt="Garry's Mod server with Running status and CPU and RAM activity" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-running.png" loading="lazy" />

### Step 8 — Retrieve connection information

Copy the IP address and port from the **Connection** column of the Game Servers list.

### Step 9 — Join your server in Garry's Mod

First, add your server to your Steam favourites:

1. In **Steam**, go to **View** > **Game Servers**.
2. Open the **Favorites** tab and click **Add a server**.
3. Paste the IP address and port from the **Connection** column, then click **OK**.

Then join the server from the game:

1. Launch **Garry's Mod** and click **Find Multiplayer Game**.
2. Open the **Favorites** tab.
3. Select your server and double-click it to connect.

### Configure the game settings

Go to <code className="action">Settings</code> > <code className="action">Game Config</code> to adjust your server's main settings without editing a single configuration file.

<img className="thumbnail" alt="The Game Config settings of a Garry's Mod server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-game-config.png" loading="lazy" />

| Setting | Description |
|---------|-------------|
| `Server name` | The name shown in the in-game server browser. |
| `Map` | The map loaded when the server starts. |
| `Game mode` | The game mode the server runs. |
| `Workshop collection` | The ID of a Steam Workshop collection, downloaded and mounted on every start. The collection must be public or unlisted. |
| `Counter-Strike: Source content` | Downloads Counter-Strike: Source content, which many addons reuse. Players need to own the game as well. Adds a multi-gigabyte download on the next start. |
| `Maximum players` | The maximum number of simultaneous players. |
| `Server password` | The password players must enter to join. Leave it empty for a public server. |
| `Admin password (RCON)` | The password used to control the server remotely from the console. |
| `Steam GSL token` | The token that makes your server appear in the official server browser. Get it from [steamcommunity.com](https://steamcommunity.com/dev/managegameservers). |
| `Update workshop addons` | Updates the collection addons on every start. |
| `Update on start` | Checks for and installs game updates on every start. |

Changes take effect when the server restarts.

### Change the game mode

The `Game mode` and `Map` fields are free text: the dropdown only suggests the values that ship with the game, but you can type any name into them.

**Trouble in Terrorist Town** ships with Garry's Mod. Select it in `Game mode`, then restart your server. Check the map: `Construct` and `Flatgrass` are sandbox maps, and a TTT server needs `ttt_` maps from the Workshop.

**DarkRP** does not ship with the game and comes from the Workshop:

1. Create a Steam Workshop collection, public or unlisted, holding DarkRP, its dependencies, and an `rp_` map.
2. Enter its ID in `Workshop collection`.
3. Type `darkrp` into `Game mode` and your map name into `Map`.
4. Turn on `Counter-Strike: Source content`, whose textures many DarkRP addons reuse.
5. Restart your server.

<img className="thumbnail" alt="The Game mode, Workshop collection and Counter-Strike: Source content settings" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/gameplay-settings.png" loading="lazy" />

:::warning
The `Map` field names the map to load, it does not download it. A map that is not in your Workshop collection will not be found at startup, and the server will fail to launch.
:::
