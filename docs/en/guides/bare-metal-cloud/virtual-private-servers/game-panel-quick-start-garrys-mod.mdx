## Objective

The Game Panel lets you deploy a Garry's Mod server with automated installation and port configuration.

**This guide explains how to deploy and connect to a Garry's Mod server on the Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your Game Panel. Go to the <code className="action">Game Servers</code> section in the left-hand menu and click <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Game Servers section with Add Game Server button" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/game-servers-list.png" loading="lazy" />

### Step 2 — Create a Garry's Mod server

Select **Garrys Mod** from the game list. A configuration window opens.

<img className="thumbnail" alt="Selecting Garry's Mod from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/select-garrys-mod.png" loading="lazy" />

### Step 3 — Configure the Garry's Mod server

Enter a **Server Name** (for example, `Garrys Mod Server`). The required network ports are configured automatically during installation.

You can expand <code className="action">Advanced settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

### Step 4 — Launch the installation

Click <code className="action">Install</code>. The deployment starts automatically. Wait a few minutes while the image downloads and the server installs.

### Step 5 — Monitor the installation

Click <code className="action">Log/Console</code> to follow progress in real time. The status shows **Installing**.

### Step 6 — Verify the server is running

Check that the server status displays **Running** and that CPU/RAM activity is visible.

<img className="thumbnail" alt="Garry's Mod server with Running status" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-running.png" loading="lazy" />

Available actions:

- <code className="action">Log/Console</code>: Open the console to monitor startup and check logs if there are any issues.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: Access game settings (startup map, tickrate, gamemode, player limit, RCON password, Workshop collection, GSLT).

<img className="thumbnail" alt="Garry's Mod Game Config settings" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-game-config.png" loading="lazy" />

### Step 7 — Confirm installation is complete

Once the installation finishes, the status changes to **Running** and the server is ready to start. Click <code className="action">Launch</code> to start the server.

### Step 8 — Retrieve connection information

Copy the IP address and port from the **Connection** column of the Game Servers list.

### Step 9 — Join your server in Garry's Mod

First, add your server to your Steam favourites:

1. In **Steam**, go to **View** > **Game Servers**.
2. Open the **Favorites** tab and click **Add a server**.
3. Paste the IP address and port from the **Connection** column, then click **OK**.

Then join from the game:

1. Launch **Garry's Mod** and click **Find Multiplayer Game**.
2. Open the **Favorites** tab.
3. Select your server and double-click it to connect.

:::info
To go further, add mods or Workshop collections, adjust tickrate and performance settings, or restrict access with a password or whitelist.
:::
