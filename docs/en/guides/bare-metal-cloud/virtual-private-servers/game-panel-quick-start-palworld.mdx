## Objective

The OVHcloud Game Panel lets you deploy a Palworld server with automated installation and port configuration.

**This guide explains how to deploy and connect to a Palworld server on the OVHcloud Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your OVHcloud Game Panel. From the left-hand menu, go to the `Game Servers` section and click <code className="action">Add Game Server</code>.

### Step 2 — Create a Palworld server

Select **Palworld** from the game list. A configuration window opens.

<img className="thumbnail" alt="Selecting Palworld from the game list in the Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/select-palworld.png" loading="lazy" />

### Step 3 — Configure the Palworld server

In this section, you can set a name for your server. An administrator password is also generated automatically. It can be used directly in the game to obtain administrator rights and run the associated commands.

:::warning
Make sure you keep this administrator password in a secure place.
:::

You can expand <code className="action">Advanced settings</code> to adjust options such as ports binding and resource limits. The defaults are suitable for most game servers.

<img className="thumbnail" alt="Palworld server configuration form with the server name and administrator password" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/configure-server.png" loading="lazy" />

### Step 4 — Launch the installation

Click <code className="action">Install</code> to launch the installation. The deployment starts.

### Step 5 — Monitor the installation

Click <code className="action">Log/Console</code> to follow the installation progress in real time.

While the server is installing, the status displays **Installing**. You can track detailed progress in the logs panel.

<img className="thumbnail" alt="Monitoring Palworld server installation in the logs panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/installation-logs.png" loading="lazy" />

### Step 6 — Verify the server is running

Confirm the server status is **Running** and that CPU and RAM activity is visible. You can use the <code className="action">Log/Console</code> and <code className="action">Settings</code> controls to manage the server.

<img className="thumbnail" alt="Palworld server with Running status and CPU and RAM activity" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/server-running.png" loading="lazy" />

### Step 7 — Confirm installation is complete

Once the installation is finished, the server status changes to **Running**.

### Step 8 — Retrieve connection information

Once your server status is **Running**, copy the IP address and port from the **Connection** column of the Game Servers list.

### Step 9 — Join your server in Palworld

To join your server from the Palworld client:

1. Open **Palworld** and click **Join Multiplayer Game**.
2. In the input field at the bottom centre, paste the IP address and port from the **Connection** column.
3. Click **Connect**.

### Commands available with Palworld

With a Palworld server, you can run various commands directly from the input field at the bottom of the logs. Here are some of the available commands:

| Command | Arguments | Description |
|---------|-----------|-------------|
| `announce` | - | Sends an announcement message visible to all connected players. |
| `players` | - | Displays the list of players currently connected to the server. |
| `info` | - | Returns general information about the server. |
| `settings` | - | Returns the current server configuration. |
| `metrics` | - | Displays various server metrics and statistics. |
| `kick` | `<PlayerId or SteamId>` | Kicks a player from the server. |
| `ban` | `<PlayerId or SteamId>` | Bans a player from the server. |
| `unban` | `<PlayerId or SteamId>` | Removes a player's ban. |

:::info
Forgotten the in-game administrator password? Click <code className="action">Settings</code>, open the <code className="action">Game Config</code> section, and change the password at the bottom of the page.
:::

### Update the server to a new game version

By default, the server does not update automatically when a new version is available, to avoid potential compatibility issues or interrupting ongoing games.

To enable automatic updates, click <code className="action">Settings</code>, open the <code className="action">Game Config</code> section, then enable the **Update on start** option at the bottom of the page (disabled by default). Save, then restart the server to apply the changes. The server will then automatically apply any new update that becomes available.
