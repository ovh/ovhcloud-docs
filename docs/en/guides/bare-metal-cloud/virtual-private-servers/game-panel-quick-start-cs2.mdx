## Objective

The OVHcloud Game Panel lets you deploy a Counter-Strike 2 (CS2) server with automated installation and port configuration.

**This guide explains how to deploy and connect to a Counter-Strike 2 server on the OVHcloud Game Panel.**

## Requirements

- A [VPS](/links/bare-metal/vps) or a [dedicated server](/links/bare-metal/bare-metal) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your OVHcloud Game Panel. Go to the **Game Servers** section in the left-hand menu.

### Step 2 — Create a CS2 server

Click <code className="action">Add Game Server</code> and select **Counter-Strike 2** from the list.

<img className="thumbnail" alt="Selecting Counter-Strike 2 from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/select-cs2.png" loading="lazy" />

Enter a **Server Name** (for example, `CS2 Competitive Server`). The required network ports are configured automatically during installation.

### Step 3 — Launch the installation

Click <code className="action">Select</code>. The deployment starts automatically. Wait a few minutes while the image downloads and the server installs.

Then click <code className="action">Launch</code> to start the server.

### Step 4 — Verify the server is running

Check that the server status displays **Running** and that CPU/RAM activity is visible.

Available actions:

- <code className="action">Log/Console</code>: Open the console to monitor startup and check logs if there are any issues.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: Access game settings.

<img className="thumbnail" alt="Counter-Strike 2 server with Running status" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/cs2-running.png" loading="lazy" />

### Step 5 — Connect to the server

In the **Connection** column of the Game Servers list, copy your server's IP address and port.

In Counter-Strike 2:

1. Enable the console in the game settings (**Settings** > **Game** > **Enable Developer Console**).
2. Open the console (`~`).
3. Type the following command, using the IP address and port from the **Connection** column:

    ```console
    connect IP:PORT
    ```

### Best practices

- Configure permissions via <code className="action">User Administration</code>.
- Perform regular backups.
- Customise your game settings.

:::info
To go further, add mods or competitive configurations, adjust tickrate and performance settings, or restrict access with a password or whitelist.
:::
