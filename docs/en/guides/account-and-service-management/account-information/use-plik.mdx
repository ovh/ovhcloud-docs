## Objective

The online [Plik](https://plik.ovhcloud.com) tool allows you to share files between different people, offering secure access options to these files.

**Learn how to use the Plik online tool to share files.**

## Requirements

- An [OVHcloud account](/guides/account-and-service-management/account-information/ovhcloud-account-creation)

## Instructions

### Log in with your OVHcloud account

To upload files, you must log in to Plik with your OVHcloud account.

Log in to the <ManagerLink to="/">OVHcloud Control Panel</ManagerLink>.

:::info
If you have enabled [two-factor authentication](/guides/account-and-service-management/account-information/secure-ovhcloud-account-with-2fa) on your OVHcloud account, you will also need to enter the code provided by the authentication method you have defined on your account.
:::

Go to the [Plik website](https://plik.ovhcloud.com).

Click <code className="action">Authentication</code> in the top right-hand corner.

Click <code className="action">Login with OVH</code>.

![Plik login page with the Login with OVH button highlighted](/images/account-and-service-management/account-information/use-plik/plik01.png)

Click <code className="action">Continue</code>.

![OVHcloud page showing the account you are logged in with](/images/account-and-service-management/account-information/use-plik/plik02.png)

Click <code className="action">Authorize</code>.

![OVHcloud authorization page for Plik with the Authorize button](/images/account-and-service-management/account-information/use-plik/plik03.png)


### Upload files

Once you have logged in, click on the word <code className="action">Plik</code> in the top left-hand corner to access the menu for adding files.

Click <code className="action">Add files</code> and select the file you want to add, or drag and drop your files.

:::info
Files are limited to 10 GB in size.
:::


![Plik upload page with the upload options and the Add files button](/images/account-and-service-management/account-information/use-plik/plik04.png)

There are several options for configuring your uploads:

- `Destruct after the first download` - This option will delete your uploaded file after the first download.
- `Streaming` - The file will not be stored on the server. Instead, the file upload begins when the remote user begins the download.
- `Removable` - Allows end users to delete the uploaded file.
- `Password` - Protect your upload by imposing a username and password that the remote user must enter.
- `Comments` - Add comments to your download. The *Markdown* language is supported.
- `Files will be automatically removed in` - Choose the number of days (30 maximum), hours or minutes after which you want your uploaded files to be automatically deleted.

:::info
When you protect your upload with a password, the default username is "plik".
:::


Once you have added your files and selected the options you want, click the green <code className="action">Upload</code> button on the left-hand side. This will open a new page with your attached files.

![Plik upload page with a file added and the Upload button](/images/account-and-service-management/account-information/use-plik/plik05.png)

The download options are then available.

### Download files

On the download page, new options are available:

- `Zip archive` - Places all files you uploaded into a compressed folder.
- `Add files` - Allows you to add other files.
- `Delete` - Deletes all previously uploaded files.

You can also delete files one by one by clicking the <code className="action">X</code> button to the right of each file.

![Plik download page with the QR code, file link and download options](/images/account-and-service-management/account-information/use-plik/plik06.png)

To allow others to download your files, give them the link to the individual file under the file name.<br/>
You can also link them to all files in the session by sharing the URL in your browser's address bar.<br/>
You can also share the QR code on the left. If you have uploaded several files, the QR code will display each file.

### Account options

Click on your username in the top right-hand corner to access your account options.

![Plik account options page with the upload list and account management buttons](/images/account-and-service-management/account-information/use-plik/plik07.png)

Using this menu, you can log out, generate tokens to use the Plik tool in the command line, delete each upload (via the <code className="action">Remove</code> button to the right of each upload) or delete all uploads (via the <code className="action">DELETE UPLOADS</code> button).
