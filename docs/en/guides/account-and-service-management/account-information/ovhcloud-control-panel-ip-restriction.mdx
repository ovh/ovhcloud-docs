## Objective

OVHcloud provides you with options to enhance the security of your OVHcloud Console and your services.

You can restrict access to your <ManagerLink to="/beta/#/">OVHcloud Console</ManagerLink> to certain IP addresses.
By setting this option and securing your account with [two-factor authentication](/guides/account-and-service-management/account-information/secure-ovhcloud-account-with-2fa), you can optimally secure your OVHcloud Console against intrusion attempts.

**This guide explains how to secure your OVHcloud account by limiting the IP addresses authorised to access it.**

:::warning
IP access restriction and/or two-factor authentication only secure access to the OVHcloud Console from which you can order, manage, renew or delete your OVHcloud services. These options do not secure your services themselves, for which you must implement specific security measures.

:::


## Requirements

- Knowledge of the [password management recommendations for accessing your account](/guides/account-and-service-management/account-information/manage-ovh-password)

## Instructions

### Step 1 - Retrieve public IP addresses authorised to access your OVHcloud Console

There are two types of IP addresses:

- **Public IP addresses**: They are visible throughout the Internet. For example, they are used by your Internet access point/box to provide access to public networks (Internet).
- **Private IP addresses**: They are not visible on the Internet and can only be allocated in a local network. For example, your Internet box will assign a private IP address to each of the devices (computers, smartphones, tablets, etc.) connected to it. Your Internet access point/box allows these devices to use the public IP address to access the Internet. Private IP addresses are easy to recognise because they usually start with 10.X.X.X, 172.16.X.X or 192.168.X.X (where X stands for a value between 0 and 255).

To use the IP restriction option in the OVHcloud Console, you will need to enter your public IP address(es) **only**.

To retrieve the public IP address of a device that will be authorised to access your OVHcloud Console, go to [whatismyip.com](https://www.whatismyip.com/) (not managed by OVHcloud).

Take note of the IP address that appears, then repeat the operation for each device that will be authorised to access your OVHcloud Console.

If you are using a 4G/5G network as an addition, remember to also retrieve the IP address of this network.

:::warning
Most Internet Service Providers (ISPs) allocate a **dynamic** IP address to your Internet access point/box. These dynamic IP addresses change when you reboot your box or every 24/48 hours. However, some ISPs may allocate **static** IP addresses to you on request.

For a 3G/4G/5G connection, IP addresses are systematically **dynamic**.

**Before** setting up an IP restriction on your OVHcloud Console, check with your ISP to make sure that the IP addresses retrieved previously are **static** IP addresses. Otherwise, you risk losing access to your OVHcloud Console by declaring a dynamic IP.

:::


### Step 2 - Set up access restriction by IP

{/* CP-STEPS-START:set-up-ip-restriction */}

Go to the <ManagerLink to="/beta/#/customer/account/security-and-login/ip-restrictions">IP restrictions</ManagerLink> tab of the **Security and login** page. You can also reach it from the side menu: open <code className="action">My account</code> > <code className="action">Security and login</code>, then click the <code className="action">IP restrictions</code> tab.

<img className="thumbnail" alt="Security and login entry of the side menu and the IP restrictions tab" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/security-login-ip-tab.png" loading="lazy" />

{/* CP-STEPS-END:set-up-ip-restriction */}

#### Interface Overview

{/* CP-STEPS-START:interface-overview */}

<img className="thumbnail" alt="Default rule and Configured IPs sections of the IP restrictions tab" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/ip-restrictions-overview.png" loading="lazy" />

There are two sections for setting IP restrictions:

- **Default rule**. Use the **When the IP is not in the list** field to:
    - deny access to all IP addresses except those previously declared as **allowed** in the second section, **Configured IPs**.
    - allow access to all IP addresses except those previously declared as **denied** in the second section, **Configured IPs**.
    > Check the **Alert me by e-mail** box if you want to be notified on your contact email address whenever an unauthorised login attempt is made to access your OVHcloud Console.

- **Configured IPs**. Use this section to declare IP addresses that will be restricted or authorised. You can also view the rules you have set up beforehand.

:::danger
Warning before continuing with your actions:

In the **Default rule** section, **never** save the default rule with <code className="action">Deny access</code> selected **without first allowing** at least one of your public IP addresses in the **Configured IPs** section.

Otherwise, you will block **all public IPs (including yours)** without any exceptions. Any login requests to your <ManagerLink to="/">OVHcloud Console</ManagerLink> will be denied, and you will need to carry out an administrative procedure to unblock your access.

While no IP address is allowed, the OVHcloud Console does not let you save this default rule. Make sure that the allowed addresses include your own.

Be extremely vigilant on this point.

:::

{/* CP-STEPS-END:interface-overview */}


#### Deny all IP addresses except legitimate addresses

{/* CP-STEPS-START:deny-all-except-legitimate */}

To authorise access to the OVHcloud Console only for one or more legitimate IP addresses, click the <code className="action">Add an IP</code> button in the **Configured IPs** section.

> The IP **203.0.113.1/24** used in the following screenshots needs to be replaced with one of your own IP addresses.

<img className="thumbnail" alt="Add an IP window with the Allow access rule selected" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/add-an-ip-allow.png" loading="lazy" />

In the **Add an IP** window, enter the public IP address you want to authorise in the **IP address** field (an IPv4 or IPv6 address, alone or as a block). Check the **Alert me by e-mail** box if you want to be notified by email of connection attempts via this IP address, then leave the **Rule** set to <code className="action">Allow access</code>.

Click <code className="action">Add</code>. The rule should then appear in the **Configured IPs** section.

:::info
**Before** you continue with the actions described in this step, repeat the above operation for any other IP addresses you wish to authorise to access your OVHcloud Console.

:::

Once you have **set all** of your public IP addresses in the **Configured IPs** section, select <code className="action">Deny access</code> in the **When the IP is not in the list** field of the **Default rule** section. Select the **Alert me by e-mail** check box if you want to receive email notification of login attempts, then click <code className="action">Save</code>.

> From now on, **only** public IP addresses previously authorised in the **Configured IPs** section can access your OVHcloud Console.

{/* CP-STEPS-END:deny-all-except-legitimate */}

#### Authorise all IP addresses except some addresses

{/* CP-STEPS-START:authorise-all-except-some */}

From the **IP restrictions** tab, you can also authorise all IP addresses to access your OVHcloud Console, with the exception of a few that you have previously identified as illegitimate.

To block access to your OVHcloud Console for one or more IP addresses, click the <code className="action">Add an IP</code> button in the **Configured IPs** section.

<img className="thumbnail" alt="Add an IP window with an IP address entered and the Deny access rule selected" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/add-an-ip-deny.png" loading="lazy" />

In the **Add an IP** window, enter the public IP address you want to block in the **IP address** field (an IPv4 or IPv6 address, alone or as a block). Check the **Alert me by e-mail** box if you want to be notified by email of connection attempts via this IP address, then set the **Rule** to <code className="action">Deny access</code>.

Click <code className="action">Add</code>. The rule should then appear in the **Configured IPs** section.

:::info
**Before** you continue with the actions described in this step, repeat the operation for any other IP addresses you wish to block from accessing your OVHcloud Console.

:::


Once you have entered all of the public IP addresses in the **Configured IPs** section, select <code className="action">Allow access</code> in the **When the IP is not in the list** field of the **Default rule** section. Select the **Alert me by e-mail** check box if you want to be notified by email of connection attempts, then click <code className="action">Save</code>.

> From now on, **all** public IP addresses can access your OVHcloud Console, **with the exception of** those declared in the **Configured IPs** section.

{/* CP-STEPS-END:authorise-all-except-some */}
