## Objective

This guide explains how to provide a user with the minimum rights to allow them to log in to the OVHcloud Console.

## Requirements

- You have an [OVHcloud account](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- You know [how to manage account users](/guides/account-and-service-management/account-information/ovhcloud-users-management).
- You know [how to configure policies for IAM](/guides/account-and-service-management/account-information/iam-policy-ui).

[[cpnav:iam-policies-console|en]]

## Instructions

To be able to log in to the OVHcloud Console, a user should have at least this set of rights on the account resource:

- account:apiovh:me/get
- account:apiovh:me/supportLevel/get
- account:apiovh:me/certificates/get
- account:apiovh:me/tag/get

With these rights, a user will be able to log in to the OVHcloud Console. To be able to perform any actions inside the Console however, additional rights have to be assigned through IAM.

### Using UI

{/* CP-STEPS-START:using-ui */}

Using the UI, you can set up a policy with the following configuration. From the <ManagerLink to="/beta/#/iam/policies/my-policies">My policies</ManagerLink> page, click <code className="action">Create a policy</code>.

In the **Identities** section, add the identities you want to give access to.

<img className="thumbnail" alt="Identities section of the Create a policy form, with the Users tab selected" src="/images/account-and-service-management/account-information/iam-control-panel-access/console/add_identities.png" loading="lazy" />

In the **Product types** section, select <code className="action">OVHcloud customer account</code> from the **Product types** drop-down list, then select your account from the **Resources** list.

<img className="thumbnail" alt="Product types section with OVHcloud customer account selected and the account in Resources" src="/images/account-and-service-management/account-information/iam-control-panel-access/console/account_ressourceType.png" loading="lazy" />

Then, in the **Actions** section, select the managed permissions group <code className="action">controlPanelAccess</code> from the **Managed permissions groups** drop-down list.

<img className="thumbnail" alt="Actions section with controlPanelAccess selected in Managed permissions groups" src="/images/account-and-service-management/account-information/iam-control-panel-access/console/controlPanelAccess.png" loading="lazy" />

Alternatively, add the 4 rights listed above as actions: tick each of them in the **READ** category of the **account** action list, or enter each one in the **Manually add actions** field and click <code className="action">Add</code>.

<img className="thumbnail" alt="The account action list of the Actions section, with 4 actions selected" src="/images/account-and-service-management/account-information/iam-control-panel-access/console/add_actions.png" loading="lazy" />

In the **Summary** panel, click <code className="action">Create a policy</code>.

You can now link your users to this policy to give them the right to log in to the OVHcloud Console.

{/* CP-STEPS-END:using-ui */}

### Using API

Using the API, you can set up a policy according to the following example:

```json
{
  "name": "manager_ro",
  "description": "manager_ro",
  "identities": [
    .... 
  ],
  "resources": [ 
     {
         "urn": "urn:v1:eu:resource:account:xx1111-ovh" 
     }],
  "permissions": {
    "allow": [
      {
        "action": "account:apiovh:me/get"
      },
      {
        "action": "account:apiovh:me/supportLevel/get"
      },
      {
        "action": "account:apiovh:me/certificates/get"
      },
      {
        "action": "account:apiovh:me/tag/get"
      }
    ]
  }
}
```
