## Objective

You can host multiple websites on the same web hosting plan, even if the domain names are not registered with OVHcloud. In addition, you can associate one or more domain names or subdomains with the same website.

:::info
If you have not yet created the relevant website on your web hosting, please consult **directly** [this guide](/guides/web-cloud/web-hosting/multisites-configure-multisite).

:::

**Discover how to associate a domain name or subdomain with an existing website on your web hosting.**

## Requirements

- A compatible [OVHcloud web hosting plan](https://www.ovhcloud.com/en-gb/web-hosting/uc-multisite/)
- One or more [domain names](https://www.ovhcloud.com/en-gb/domains/)
- Access to modify the configuration of the [DNS zones of your domain names](/guides/web-cloud/domains/dns-zone-edit)

## Instructions

### Add a domain name or subdomain to an existing website

**Click on one of the titles below to display the explanations.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Add a domain name managed in your OVHcloud account</summary>

This part only applies if your domain name and/or its active DNS zone are **in your OVHcloud account**.

The form fits on a single page: fill it in from top to bottom, then confirm. Click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click the <code className="action">My sites</code> tab. In the table, click the <code className="action">⋮</code> button in the **Actions** column, to the right of the website concerned, then, in the **Domain names** group, <code className="action">Add a domain name</code>.

    <img className="thumbnail" alt="Actions menu of a website, Add a domain name entry" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    The **Add a domain** page opens. It uses the add site form, in which the **root folder** and the **site name** are already filled in from the existing website: leave them as they are.

    <img className="thumbnail" alt="Add a domain page and choice of the domain name type" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    In the **Domain name association** section, choose the **Existing OVHcloud domain name** option.
  </Tab>
  <Tab label="Step 4">
    The **Configure your domain** section appears. Select the domain name to associate in the **Domain name** drop-down menu.

    <img className="thumbnail" alt="Domain configuration, options and DNS configuration" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-configure-domain.png" loading="lazy" />

    :::info
    To add a subdomain, first select the domain name in the list (for example: domain.tld). Then tick the **Create a subdomain** box. An input field appears for you to enter the subdomain (for example: **sub**.domain.tld).

    **Special case**: the `www` subdomain (for example: **www**.domain.tld) is not added automatically with the domain name. For it to display your site too, add it separately, repeating this procedure with `www.domain.tld`.
    :::

    The **Options** section brings together three features, unticked by default. Depending on your [web hosting plan](/links/web/hosting), some may not be selectable.

    |Option|Description|
    |---|---|
    |Country IP|Allows you to benefit from a geolocated IP address (from a list of countries) for the selected domain name.<br/> Learn more from [this page](/links/web/hosting-options).|
    |Firewall|Allows you to activate a firewall (filtering and analysis of requests) on the selected domain name.<br/> Learn more from [this page](/links/web/hosting-options).|
    |CDN|Allows you to activate the CDN (caching of static elements of your website, such as images) on the selected domain name.<br/> Learn more from [our CDN page](/links/web/hosting-options-cdn).<br/> By activating SSL and the CDN, you will also benefit from the **HTTP/2** protocol (this protocol is activated by default in our Gravelines datacentre).|

    :::info
    These options can be enabled later. To do this, see [this guide](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::

    Finally, the **DNS Configuration** section offers two modes:

    - **For an automatic configuration**, leave the **Automatic configuration** option selected: the A and AAAA records are created in the domain's DNS zone.
    - **For a manual configuration**, choose the **Manual configuration** option, then refer to the following guides:
        - [Web hosting - List of IP addresses by cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Edit an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit)

    Finally, click <code className="action">Validate</code>. The addition can take up to an hour.

    :::info
    Changes to your domain name's DNS configuration require a propagation period of up to 48 hours before they are fully effective.
    :::
  </Tab>
</Tabs>

</details>

<details>
<summary>Add an external domain name</summary>

This section applies only if your domain name is not present in your OVHcloud account.

The form fits on a single page: fill it in from top to bottom, then confirm. Click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click the <code className="action">My sites</code> tab. In the table, click the <code className="action">⋮</code> button in the **Actions** column, to the right of the website concerned, then, in the **Domain names** group, <code className="action">Add a domain name</code>.

    <img className="thumbnail" alt="Actions menu of a website, Add a domain name entry" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    The **Add a domain** page opens. It uses the add site form, in which the **root folder** and the **site name** are already filled in from the existing website: leave them as they are.

    <img className="thumbnail" alt="Add a domain page and choice of the domain name type" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    In the **Domain name association** section, choose the **External domain name** option.
  </Tab>
  <Tab label="Step 4">
    In the **Configure your domain** section, enter the domain name (for example: domain.tld) or the subdomain (for example: **sub**.domain.tld) in the **Domain name** field.

    :::tip
    **Special case**: the `www` subdomain (for example: **www**.domain.tld) is not added automatically with the domain name. For it to display your site too, add it separately, repeating this procedure with `www.domain.tld`.
    :::

    The **Domain management** section then displays the records to create, in two steps. This verification is mandatory: it allows us to make sure that adding the external domain name is legitimate.

    <img className="thumbnail" alt="Domain management: DNS records to create and BIND record" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-external-dns.png" loading="lazy" />

    1. **Verify domain ownership**: add the **TXT** record shown in your provider's DNS zone.
    2. **Point the domain to your hosting**: add the **A** and **AAAA** records shown.

    Each value has a copy button, and the **BIND record** block repeats the three lines in the format expected by most DNS zone hosts.

    Finally, click <code className="action">Validate</code>. The domain name is added temporarily, while you change its DNS configuration.

    :::warning
    You must make these changes **quickly** so that your domain name is correctly associated with your website.

    The **A** and **TXT** DNS entries must be placed in your domain name's active DNS zone. Only the **AAAA** DNS entries are optional.

    Note that if you want to associate `sub.domain.tld`, you will need to create the TXT entry `ovhcontrol.domain.tld` and not the entry `ovhcontrol.sub.domain.tld`.

    To find your domain name's active DNS zone, look up the [DNS servers](/guides/web-cloud/domains/dns-server-edit) it is linked to.
    :::

    :::info
    Changes to your domain name's DNS configuration require a propagation period of up to 48 hours before they are fully effective.
    :::
  </Tab>
</Tabs>

</details>

### Email offer included with your web hosting

Most [OVHcloud web hosting](https://www.ovhcloud.com/en-gb/web-hosting/) plans have an included option for creating custom email addresses with your domain name.

This email option can be activated for **only one** domain name. This means that if you host multiple websites with different domain names on your web hosting, you can only activate this option for one of your domain names.

Do not hesitate to consult [our dedicated guide](/guides/web-cloud/web-hosting/activate-email-hosting) for more details on activating this option.
