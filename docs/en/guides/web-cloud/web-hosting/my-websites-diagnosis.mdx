## Objective

You can host multiple websites on a single web hosting plan, even if the domain names are not registered with OVHcloud. You can also associate one or more domain names or subdomains with the same website.

**Use our diagnostic tool to verify that your domain name or subdomain is correctly declared with your website on your web hosting.**

:::info
This procedure applies to the <ManagerLink to="/beta/#/">new version of the OVHcloud Control Panel</ManagerLink>, currently available in beta. To follow it, switch to this interface from your usual Control Panel.

:::

## Requirements

- A compatible [OVHcloud web hosting plan](https://www.ovhcloud.com/en-gb/web-hosting/uc-multisite/)
- One or more [domain names](https://www.ovhcloud.com/en-gb/domains/)
- Access to modify the configuration of the [DNS zones of your domain names](/guides/web-cloud/domains/dns-zone-edit)

## Instructions

### Access the diagnostic tool

{/* CP-STEPS-START:diagnose-website */}
Click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hosting plans</ManagerLink> page, then select the web hosting plan concerned.

    <img className="thumbnail" alt="Hosting plans" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    On the page that opens, click on the <code className="action">My sites</code> tab.

    <img className="thumbnail" alt="My sites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the table that appears, click on the <code className="action">></code> button to the left of the name of the website to display the associated domain names or subdomains.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    The domain names or subdomains associated with your website appear. 

    <img className="thumbnail" alt="Domains associated websites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab-with-domains-associated-displayed.png" loading="lazy" />

    The `Diagnostic` column informs you whether your domain name is correctly pointing to the associated web hosting. It allows you to quickly verify that the DNS configuration of your domain name is correctly set up with your web hosting. This column helps you identify and resolve any potential pointing issues. For each domain name, three diagnostic results are possible:

    - Green `A/AAAA`
    - Yellow `A/AAAA`
    - Grey `A/AAAA`

    Refer to the "[Interpretation of the diagnostic tool's colours](#interpretation)" section of this guide to find out what these colours mean.
  </Tab>
</Tabs>

### Interpretation of the diagnostic tool's colours <a name="interpretation"></a>

**Click on the relevant status indicators below to see their explanations.**

<details>
<summary>Green A/AAAA</summary>

<img className="thumbnail" alt="A and AAAA green" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/diagnostic-green-info.png" loading="lazy" />

When the `A/AAAA` icon is green in the `Diagnostic` column, it means that the **A** record (for IPv4 addresses) and/or the **AAAA** record (for IPv6 addresses) of your domain name is correctly pointing to the IP address of your web hosting. The DNS configuration of your domain name is therefore correct to work with the website on your web hosting.

</details>

<details>
<summary>Yellow A/AAAA</summary>

<img className="thumbnail" alt="A and AAAA yellow" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/diagnostic-yellow-info.png" loading="lazy" />

When the `A/AAAA` icon is yellow in the `Diagnostic` column, it means that the **A** record (IPv4) and/or **AAAA** record (IPv6) of your domain name is pointing to an IP address, but it is not the one of the web hosting from which you are viewing the `Diagnostic` column.

To resolve DNS issues with your domain name and ensure it correctly points to the desired web hosting, follow the steps described in our guide "[Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit)".

</details>

<details>
<summary>Grey A/AAAA</summary>

<img className="thumbnail" alt="A and AAAA grey" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/diagnostic-grey-info.png" loading="lazy" />

When the `A/AAAA` icon is grey in the `Diagnostic` column, it means that the domain name is not currently pointing to any IP address and no **A** (IPv4) or **AAAA** (IPv6) records are configured for this domain name.

To add the **A** and/or **AAAA** records and correctly configure your domain name, follow the steps described in our guide "[Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit)".

</details>
