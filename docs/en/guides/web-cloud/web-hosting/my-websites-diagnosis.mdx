## Objective

You can host multiple websites on a single web hosting plan, even if the domain names are not registered with OVHcloud. You can also associate one or more domain names or subdomains with the same website.

**Use our diagnostic tool to verify that your domain name or subdomain is correctly declared with your website on your web hosting.**

## Requirements

- A compatible [OVHcloud web hosting plan](https://www.ovhcloud.com/en-gb/web-hosting/uc-multisite/)
- One or more [domain names](https://www.ovhcloud.com/en-gb/domains/)
- Access to modify the configuration of the [DNS zones of your domain names](/guides/web-cloud/domains/dns-zone-edit)

[[cpnav:web-hosting]]

## Instructions

### Access the diagnostic tool

Click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click the <code className="action">My sites</code> tab. The **Diagnostic** column of the table summarises the status of each website, without any prior action.

    <img className="thumbnail" alt="Diagnostic column of the websites table" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-column.png" loading="lazy" />

    Three values are possible:

    - <code className="action">DNS OK</code>: all the domain names of the website point correctly to your web hosting plan.
    - <code className="action">DNS to check</code>, followed by the number of domain names concerned: at least one domain has a pointing issue. This label can be clicked.
    - <code className="action">0 domains</code>: no domain name is associated with this website.
  </Tab>
  <Tab label="Step 3">
    For details, click the <code className="action">DNS to check</code> label. The **Manage my domains** panel opens on the right, **filtered on the failing domains only**; the <code className="action">Show all domains</code> button displays the full list.

    If the column shows <code className="action">DNS OK</code>, the label cannot be clicked: open the panel with the <code className="action">⋮</code> button in the **Actions** column, then, in the **Domain names** group, <code className="action">Manage my domains</code>.

    <img className="thumbnail" alt="Manage my domains panel, compliant diagnostic" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-ok.png" loading="lazy" />

    Each domain name has a **Diagnostic** line with two indicators, **A** and **AAAA**, and a <code className="action">Run the diagnostic again</code> button.

    See the "[Interpretation of the diagnostic tool's colours](#interpretation)" part of this guide to find out what these indicators mean.

    :::info
    The technical name of your web hosting plan, in the form `ftplogin.clusterXXX.hosting.ovh.net`, appears in this list with the label **Technical**. It is not diagnosed: it points to your web hosting plan by design.
    :::
  </Tab>
</Tabs>

### Interpretation of the diagnostic tool's colours <a name="interpretation"></a>

The **A** and **AAAA** indicators correspond to the two types of DNS record that point a domain name to a web hosting plan: **A** for the IPv4 address, **AAAA** for the IPv6 address. They are **independent of each other**: the same domain name can have one compliant indicator and the other failing.

Each indicator takes one of the following three colours.

<details>
<summary>Green indicator</summary>

The record points correctly to the IP address of your web hosting plan. Your domain name's DNS configuration is compliant, and no message accompanies the indicator.

<img className="thumbnail" alt="Compliant A and AAAA indicators" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-ok.png" loading="lazy" />

</details>

<details>
<summary>Orange indicator</summary>

The record points to an IP address, but not to that of the web hosting plan you are viewing. The message shows the address currently configured and the one to use instead:

*Your domain `exemple.com` currently points to IP address `X` of another hosting. To fix this, update the A record in the DNS zone of the domain and replace it with IP address `Y`.*

<img className="thumbnail" alt="Orange A indicator and grey AAAA indicator, with their messages" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-issues.png" loading="lazy" />

To correct the pointing, follow the steps described in our guide "[Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit)".

</details>

<details>
<summary>Grey indicator</summary>

No record of this type exists in the domain name's DNS zone. The message gives the record to create and the IP address to enter in it:

*No valid configuration was found in the DNS zone. To fix this, add a AAAA record with IP address `Y` in the DNS zone of domain `exemple.com`.*

To add the missing records, follow the steps described in our guide "[Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit)".

</details>

:::info
A DNS zone change can take up to 24 hours to propagate. After making a correction, use the <code className="action">Run the diagnostic again</code> button of the domain name concerned rather than reloading the page.
:::
