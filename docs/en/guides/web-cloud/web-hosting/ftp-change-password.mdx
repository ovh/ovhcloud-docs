## Objective

OVHcloud web hosting plans provide access to an online file storage space, which you can use via the **FTP** protocol: FTP storage space.

You can access this space using an **FTP user** and its associated password.

This access allows you to [put your website online](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online).

**This guide explains how to change the password for an FTP user created on your OVHcloud Web Hosting plan.**

[[fragment:support-scope]]

## Requirements

- An OVHcloud [Web Hosting plan](/links/web/hosting)

[[cpnav:web-hosting]]

## Instructions

### Modify the FTP user password

:::info
For more information on password management best practices, please refer to the guide "[Setting and managing an account password](/guides/account-and-service-management/account-information/manage-ovh-password)".
:::

Click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">FTP-SSH</code> tab.

    <img className="thumbnail" alt="FTP-SSH tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    The **FTP and SSH users** section lists the users created on your web hosting plan. Click the <code className="action">⋮</code> button in the **Actions** column, to the right of the user concerned, then <code className="action">Change password</code>.

    <img className="thumbnail" alt="Actions menu of an FTP user" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />

    In the <code className="action">Change password</code> panel that opens, enter the new password **following the password policy**, confirm it by entering it a second time, then click <code className="action">Change</code>.

    <img className="thumbnail" alt="Change password panel and its two input fields" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/change-password.png" loading="lazy" />
  </Tab>
</Tabs>

:::tip
For the **primary user** only, there is a shortcut: the <code className="action">Change the password</code> button in the **File transfer (FTP/SFTP)** section, at the top of the tab.

:::

:::info
Your new password must respect the following **password policy**:

- Minimum 9 characters
- Maximum 30 characters
- At least one capital letter
- At least one lower-case letter
- At least one number
- Be composed only of numbers and letters

:::

Check the <code className="action">Operations</code> tab and refresh the page regularly. Your change will be effective within a few minutes.

### Access your storage space

To access your FTP storage space, please refer to our guide ["Logging in to your Web Hosting plan's FTP storage space"](/guides/web-cloud/web-hosting/ftp-connection).
