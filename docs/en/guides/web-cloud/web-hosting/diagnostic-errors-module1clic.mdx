## Objective

The [1-click modules](/guides/web-cloud/web-hosting/cms-install-1-click-modules) allow you to create your website quickly. With this technology, you can create your website using the most popular **C**ontent **M**anagement **S**ystem (**CMS**), such as *WordPress*, *Joomla!*, *Drupal* or *PrestaShop*.
However, if they are not configured correctly, the 1-click module installation may fail and/or cause malfunctions.

**Find out how to diagnose the most common errors associated with 1-click module creations**

[[fragment:support-scope]]

## Requirements

- A compatible [web hosting plan](/links/web/hosting)
- The [1-click module](/guides/web-cloud/web-hosting/cms-install-1-click-modules) feature used to install your website

<summary>"An error has occurred loading the information (You need at least one free database)"</summary>

<img className="thumbnail" alt="Database section of the Install a module panel, with no database available" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/install-module-no-database.png" loading="lazy" />

This message appears when you launch the installation of your 1-click module while your web hosting plan does not yet have any MySQL database. In <code className="action">Advanced</code> mode, the **Install a module** panel tells you so as early as the **Database** section: "No MySQL database available. Create one from the Databases tab.", together with the <code className="action">Create a database</code> button. This button opens the creation of a database if you still have a free slot, and the order of an additional database otherwise.

#### Solution #1: Order a new database

If you no longer have any databases included with your web hosting plan, you can order a new [Start SQL database](/links/web/hosting-options-startsql) and combine it with your current web hosting plan. You can then relaunch the installation of the 1-click module. If you need more storage space (more than 1GB), we recommend using our [Web Cloud Databases](/links/web/databases) service instead.

Click on the tabs below to view each of the **2** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">Databases</code> tab. At the top of the tab, the **Included databases** section shows the number of slots still available in your plan. To order an additional database, click <code className="action">Order</code> in the **My options** section.

    <img className="thumbnail" alt="Databases tab, Included databases and My options sections" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/quota-cards.png" loading="lazy" />
  </Tab>
</Tabs>

Once complete, you will be able to install a new 1-click module.

#### Solution 4: Install your 1-click module on a database that is already in use

To install your 1-click module on an existing database, you will need to use the [advanced mode](/guides/web-cloud/web-hosting/cms-install-1-click-modules) installation feature of a new 1-click module.

To find your database credentials, please refer to our guide on [Setting up your website with a 1-click module (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules).

If you have a [Web Cloud Databases](/guides/web-cloud/databases/db-getting-started) server, you can create a database of the size of your choice, within the limit of the disk space allocated.

Once complete, you will be able to install a new 1-click module.

:::info
In this situation, you can back up data from a single website using a [PHP script or an SSH command](/guides/web-cloud/web-hosting/sql-database-export).

If you have any questions on how to proceed, please contact the [OVHcloud community](/links/community) or one of our [partners](/links/partner).<br/>
We will not be able to assist you with this.

<summary>"Either no configuration (ovhconfig or runtime), or the current configuration is not valid (please double check the module's requirement) (as a reminder, the global configuration is used for module)."</summary>

This message indicates that the .ovhconfig file is missing or incorrectly configured for your 1-click module installation. This file contains the PHP version and runtime environment applied to your web hosting plan.

We recommend using the most recent PHP version possible. **Before** you change the configuration of the .ovhconfig file, if you have other websites on your web hosting plan, please ensure that they are compatible with the new PHP version and/or the new runtime environment that you will apply to your web hosting plan.

To check this configuration, please read our guide on [Modifying your web hosting plan's configuration](/guides/web-cloud/web-hosting/configure-your-web-hosting).

</details>

<details>
<summary>The table prefix in your database is already in use on your database</summary>

This error only applies to 1-click module installations in *advanced mode*.

It informs you that the attempt to install the 1-click module failed, because the table prefix is already used in the database by another installation. The operation is then cancelled.

Retry the installation with a different table prefix or database to fix the problem.

</details>

<details>
<summary>The domain name DNS record does not point to an OVHcloud web hosting plan</summary>

This error informs you that the DNS records for the domain name used for your website do not point to an OVHcloud web hosting plan. However, you cannot install a 1-click module on a domain that does not point to an OVHcloud hosting plan.
To resolve this situation, you must edit your DNS zone. To find out more about the IP addresses you need to enter, read our guide [List of IP addresses for clusters and web hosting plans](/guides/web-cloud/databases/db-configure-optimise-database-server). You will then need to [Edit your DNS zone](/guides/web-cloud/domains/dns-zone-edit).
If your DNS zone is not hosted with OVHcloud, contact your DNS zone provider to perform the necessary actions.

Once you have finished installing a new 1-click module, restart it.

</details>

<details>
<summary>Your database must be in version "X", but it is currently in version "Y"</summary>

This message received by email informs you that the version of your database is too old to install your 1-click module.

In this same email, you will find the version your database should be in. There are three ways to do this:

- Update of the **D**ata**B**ase **M**anagement **S**ystem (DBMS such as MySQL, PostgreSQL, MariaDB, etc.) to a more recent version.
- Install a new database linked to your web hosting plan. This is to ensure that the DBMS and version are compatible with the desired 1-click module.
- If you have a [Web Cloud Databases](/guides/web-cloud/databases/db-getting-started) server, check that your server uses the correct DBMS and version, then create the database of your choice.

Once you have finished installing a new 1-click module, restart it.

</details>
