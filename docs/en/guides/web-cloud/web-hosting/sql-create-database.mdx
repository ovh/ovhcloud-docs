## Objective

A database is used to store dynamic elements (connection data, user data, display data, data required for your website to work properly, etc.). These databases are used in the majority of modern Content Management Systems (CMS), such as *WordPress*, *Joomla!*, *Drupal* or *PrestaShop*.

**Find out how to create a database on your OVHcloud web hosting plan.**

## Requirements

- You have an [OVHcloud web hosting plan](/links/web/hosting) that includes at least one database.
- You have a database available for creation from the databases included in your web hosting plan. If required, you can add [Start SQL](/links/web/hosting-options-startsql) databases to your web hosting plan.

## Instructions

### 1 - Access the web hosting database management tab

Click on the tabs below to view each of the **2** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    On the page that appears, click on the <code className="action">Databases</code> tab.

    <img className="thumbnail" alt="Databases tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />

    The table in this section contains all of the databases created with your web hosting plan. Each row shows the **Username**, the **Database name**, the **Server address**, the **Quota** used, the engine **Version**, the **Type**, the **State**, the **Status** and the number of available **Backups**.

    <img className="thumbnail" alt="Databases table and its columns" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/tab-no-spotlight.png" loading="lazy" />
  </Tab>
</Tabs>

Databases in the table can have several different types:

- **Included**: Indicates that the database is included in your web hosting plan. There is no additional cost.<br/><br/>
- **Optional**: Indicates that the database has been subscribed to in addition to the databases included with your web hosting plan. You pay an additional fee to have this additional database on your web hosting plan.<br/><br/>
- **Included - Discontinued**: Indicates that the included database will soon be discontinued and become obsolete. <br/>We recommend that you retrieve its contents and place it in a newer database (which has not yet been scheduled for end of sales) **before** the database becomes obsolete.<br/><br/>
- **Optional - Discontinued**: Indicates that the database you have subscribed to as an add-on to your web hosting plan will soon be removed from sale and become obsolete. <br/>We recommend that you retrieve its contents and place it in a newer database (which is not scheduled to end) **before** the database becomes obsolete.

:::tip
To quickly duplicate the content of a "**Included - Discontinued**" or "**Optional - Discontinued**" database in a new database that has not yet been scheduled for obsolescence, please read our guide on "[Duplicating the content of an OVHcloud database in another](/guides/web-cloud/web-hosting/copy-database)".
:::

### 2 - Create the database

To create a database, click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    On the page that appears, click on the <code className="action">Databases</code> tab, then on the <code className="action">Create a database</code> button above the table.

    :::info
    This button only appears if at least one database is still available in your plan. If your web hosting plan does not have any database created yet, the same button is also offered in the centre of the page, instead of the table.
    :::
  </Tab>
  <Tab label="Step 3">
    Fill in the information requested in the panel that opens on the right, then click <code className="action">Confirm</code>.

    <img className="thumbnail" alt="Database creation panel and its fields" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/create-a-database.png" loading="lazy" />

    |Information|Description|
    |---|---|
    |**Database type**|Choose the size of the database. For each size, the list shows how many slots you have left and whether it is **(included)** in your plan or **(optional)**.|
    |**Database engine**|This field cannot be modified. The databases included in your [OVHcloud web hosting plan](/links/web/hosting) are only available with the MySQL engine.|
    |**Database version**|This field cannot be modified either: the version is set by the plan. Make sure your website is compatible with the one displayed.|
    |**Username**|Username associated with your database, **required**. The prefix of your web hosting plan is set: complete it with lowercase letters and digits. The full name has a maximum of 16 characters, prefix included; the number of remaining characters is shown under the field. The database name will be identical to the username.|
    |**Password**|Enter a password for this user using the *criteria* shown under the field.|
    |**Confirmation**|Enter the password for this user again.|

    :::info
    Engine version update for a database already created is currently unavailable.
    :::
  </Tab>
</Tabs>

:::info
For security reasons, respect the requirements when you create your password.

We also recommend the following policies:

- Set a different password for each of your services.
- Create a password that contains no personal information (surname, first name, date of birth, etc.).
- Renew your password regularly.
- Do not keep written records of your password or send it to other people (including via email).
- Do not save your password in your web browser, even if your browser offers to do so.

:::

:::warning
Remember that if you change a database password, all applications that access the database must be updated accordingly.
:::

The creation of the database can take up to **15 minutes**. Reload the <ManagerLink to="/beta/#/">OVHcloud Console</ManagerLink> webpage if the database does not automatically appear in the table listing your databases.

Repeat this process as needed in order to create several databases (the total number of databases is limited by your web hosting plan).

:::warning
Once the database creation is validated, the user name and database name cannot be changed.
:::

### 3 - Manage your database <a name="step3"></a>

:::warning
This guide does not replace the support of a professional, such as a web developer. We recommend contacting a [specialist provider](/links/partner) or your solution's software publisher if you encounter any difficulties. OVHcloud cannot provide you with technical support in this regard. You can find more information in the [Go further](#go-further) section of this guide.
:::

You can now use your database. To do this, you will need your login details:

- The *username* and *password* you have set,
- The *name of the database*, identical to the username,
- The database *connection address*, in the form `username.mysql.db`.

:::info
If you are asked to enter the database port, regardless of which [Start SQL](/links/web/hosting-options-startsql) database is used by your OVHcloud web hosting plan, the **port** number to use is **3306**.
:::

This information is essential for your website to connect to the database.

If you need to retrieve this connection information, click on the tabs below to view each of the **2** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    On the page that appears, click on the <code className="action">Databases</code> tab. The table that appears shows this information, except for the *password* for security reasons:

    - the **Username** column gives both the username and the database name, since they are identical;
    - the **Database name** column gives the connection address, in the form `username.mysql.db`.

    :::warning
    The **Server address** column is **not** part of this information. It shows the infrastructure server hosting your database, in the form `mysqlXXX.euXXX`, which is useful to check whether it is affected by an incident. To find out more, read our guide "[How to identify your database server](/guides/web-cloud/web-hosting/sql-find-server)".
    :::
  </Tab>
</Tabs>

:::warning
If you do not have the password for your database connection, please read our guide on [Changing your database password](/guides/web-cloud/web-hosting/sql-change-password).
:::

Depending on the software used, this connection may need to be configured manually, or via an interface generated by the website's configuration interface (backend). Since this procedure concerns your website's configuration, and not your OVHcloud hosting plan, we recommend that you consult the resources available online, or contact a [specialist provider](/links/partner).

:::info
The databases linked to your web hosting plan can only be accessed via an application or script directly installed on your web hosting plan, or via the phpMyAdmin interface.
:::

#### Understanding common issues

**Too many connections**

Web hosting databases are limited to 30 concurrent connections (system variable *max_connections*). SQL requests must therefore be optimised to avoid this type of error. If problems persist nonetheless, alternative measures should be considered. For example, you can migrate your database to a [Web Cloud Databases](/links/web/databases) database, or even [upgrade your web hosting plan](/links/web/hosting-best-web).

**Connection / "not found" errors**

This usually occurs when the actual database name is not used in the database connection file on the database's website.

It is best practice to always use the actual database name for scripts and configuration files instead of IP addresses or *localhost*.

**Quota exceeded for databases**

If a web hosting database exceeds the recommended storage space, it will automatically switch to "Read Only" / "Select Only". The administrator will receive a notification by email.

Once the database has been optimised (purged), recalculate its quota in the OVHcloud Console to unblock it again. You can find more information on this in our guide: [What should I do if my database storage quota is exceeded?](/guides/web-cloud/web-hosting/sql-overquota-database)
