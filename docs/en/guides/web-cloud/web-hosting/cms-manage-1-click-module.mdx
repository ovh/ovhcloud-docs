## Objective

The 1-click modules are a quick and easy way to install an online website creation software (commonly called "CMS"). OVHcloud offers the most well-known of those solutions: WordPress, PrestaShop, Drupal and Joomla!.

**Find out how to manage your 1-click module from the OVHcloud Console.**

[[fragment:support-scope]]

## Requirements

<Region zones={['eu']}>
- An [OVHcloud Web Hosting plan](/links/web/hosting) that allows you to install a 1-click module (only [free hosting](/guides/web-cloud/web-hosting/activate-start10m) does not provide this feature)
</Region>
<Region zones={['ca', 'apac']}>
- An [OVHcloud Web Hosting plan](/links/web/hosting) that allows you to install a 1-click module.
</Region>
- A 1-click module on your Web Hosting plan (If you did not install one yet, follow the instructions in our guide "[Setting up your website with a 1-click module (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules)")

## Instructions

### Access your website

Click the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">

### Change your module password <a name="password-change"></a>

You can have a new administrator password generated for your module from the OVHcloud Console. Click on the tabs below to display each of the **4** steps in turn.

    <img className="thumbnail" alt="Actions menu of an installed module in the Modules tab" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/card-actions-menu.png" loading="lazy" />

  </Tab>
</Tabs>

To set a new password yourself, use your CMS administration interface.

:::info
See the official documentation for the different CMSs offered for installation on our shared hosting plans:

- WordPress: [https://wordpress.org/support/article/resetting-your-password/](https://wordpress.org/support/article/resetting-your-password/)
- Joomla!: [https://docs.joomla.org/How_do_you_recover_or_reset_your_admin_password%3F](https://docs.joomla.org/How_do_you_recover_or_reset_your_admin_password%3F)
- Drupal: The publisher of this software does not currently offer any documentation for changing the password for accessing the Drupal administration interface. Please contact the publisher directly on this subject. For more information, see the official page [drupal.org](https://www.drupal.org/).
- PrestaShop: The software publisher does not currently offer any documentation for changing the password for accessing the PrestaShop administration interface. Please contact the publisher directly on this subject. For more information, see the [official PrestaShop page](https://www.prestashop.com).

:::

You can also change the password for accessing your CMS admin interface directly from your database.

However, we strongly recommend using the documentation provided by your CMS publisher, or contacting a [specialist provider](/links/partner) if you encounter any difficulties. We will not be able to assist you. You can find more information in the [Go further](#go-further) section of this guide.

### Delete your module

:::warning
Backing up your data is essential to [securing your websites](/guides/web-cloud/web-hosting/secure-your-website). We recommend downloading your data backup regularly, and **before any deletion**, on a local device, such as a USB drive or external hard drive, following the instructions in our guide "[Exporting a website](/guides/web-cloud/web-hosting/exporter-son-site-web)".

:::

#### 1 - Identify the database linked to your module <a name="step1"></a>

To delete your 1-click module, you must first identify its database with **certainty**.

Click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">Databases</code> tab.

    <img className="thumbnail" alt="Databases tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    If you have only one database in this tab and you do not have a [Web Cloud Databases](/links/web/databases) offer, you can consider this to be your website's database.

    <img className="thumbnail" alt="Databases table and its columns" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/tab-no-spotlight.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    Otherwise, click on the <code className="action">My sites</code> tab. Note the name in the **Root folder** column on the line for the relevant website: this is the directory containing the files that make up your 1-click module on the FTP server.

    <img className="thumbnail" alt="Sites table and its Root folder column" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/root-folders.png" loading="lazy" />
  </Tab>
</Tabs>

Then log on to the [FTP space](/guides/web-cloud/web-hosting/ftp-connection) of your hosting plan. Open the `Root folder` found earlier in the <code className="action">My sites</code> tab and browse to the configuration file for your module:

- WordPress: **"wp-config.php"** (the database name appears as **"DB_NAME"**).
- Joomla!: **"configuration.php"** (the database name appears under **"public $db"**).
- Drupal: **"settings.php"** (Go to the **"sites"** folder then open the **"default"** directory. The database name appears under the name **"database"**).
- PrestaShop: **"parameters.php"** (To find it, go to the **"app"** folder, then click on **"config"**. The name of your module's database will appear as **"database_name"**).

#### 2 - Back up your data

To back up your website, follow the instructions of our guide "[Exporting a website](/guides/web-cloud/web-hosting/exporter-son-site-web)" to retrieve its files from both the FTP space on your hosting plan and its database.

#### 3 - Delete your module

:::danger
Deleting your 1-click module and its database will also delete **all of their backups**. Deleted data cannot be retrieved later on.

:::

Click on the tabs below to display each of the **3** steps in turn.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">Modules</code> tab.

    <img className="thumbnail" alt="Modules tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules.png" loading="lazy" />

    <img className="thumbnail" alt="Confirmation window for deleting a module" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/delete-module-dialog.png" loading="lazy" />

    :::tip
    Can't find the <code className="action">Delete</code> action? Or do you just want to delete files on your module?

    See our guides:

    - [Logging in to your web hosting plan's FTP storage space](/guides/web-cloud/web-hosting/ftp-connection).

  </Tab>
</Tabs>

:::warning
Deleting your 1-click module **will not automatically delete its database**. If you launch the installation of a new CMS without having previously deleted the database from the previous one and if your hosting plan does not allow the automatic creation of another database, the message "[An error has occurred loading the information (You need at least one free database)](/guides/web-cloud/web-hosting/diagnostic-errors-module1clic#an-error-has-occurred-loading-the-information-you-need-at-least-one-free-database)" will appear in the OVHcloud Console.

If you have already reached the maximum number of databases allowed by your [Web Hosting plan](/links/web/hosting), you will need to delete the database identified in [step 1](#step1) **BEFORE** creating a new 1-click module.

:::

### Best practices

Secure your website by following the instructions in our guide "[How to secure your website?](/guides/web-cloud/web-hosting/secure-your-website)".

Add CAPTCHA-type verification tools to the forms on your website.

Do not install plugins or templates that have not been recommended by the official website or the community of your CMS:

- [WordPress](https://wordpress.org/)
- [Joomla!](https://community.joomla.org/)
- [Drupal](https://www.drupal.org/community)
- [PrestaShop](https://www.prestashop.com/en)
