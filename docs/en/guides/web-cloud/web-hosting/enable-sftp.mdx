## Objective

OVHcloud web hosting offers provide access to a storage space where you can upload the files of your websites or applications. Access to this space is possible via an FTP or SSH user with the passwords associated with them.

Just like the **F**ile **T**ransfer **P**rotocol (**FTP**), the **S**ecure **F**ile **T**ransfer **P**rotocol (**SFTP**) allows you to transfer data from your device to the storage space of your web hosting.

The only difference is that SFTP uses a secure channel to exchange data. The data transmitted via this protocol is automatically encrypted.

**Find out how to enable SFTP access on your OVHcloud web hosting.**

## Requirements

- An [OVHcloud web hosting plan](/links/web/hosting-multisite)

[[cpnav:web-hosting-console]]

## Instructions

### Enable SFTP access for an FTP user on your web hosting

Click the tabs below to display each of the **4** steps in turn.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">FTP-SSH</code> tab.

    <img className="thumbnail" alt="FTP-SSH tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the **FTP and SSH users** section, check the status shown in the **SFTP** column for the FTP user concerned:

    - **Enabled**: the SFTP protocol is already active for this user, there is nothing to do.
    - **Disabled**: in the **Actions** column, click the <code className="action">⋮</code> button to the right of the row concerned, then <code className="action">Edit</code>.

    <img className="thumbnail" alt="FTP users table and SFTP protocol status" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/ftp-users-sftp-status.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    The **Edit a user** panel opens on the right. In the **Connection protocols** drop-down menu, select <code className="action">FTP and SFTP</code>, or <code className="action">FTP, SFTP and SSH</code> if you also need to enable the SSH protocol.

    <img className="thumbnail" alt="Edit a user panel and Connection protocols menu" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user-protocols.png" loading="lazy" />

The menu offers a third value, <code className="action">FTP</code> alone, which disables SFTP for this user.

    Finally, click <code className="action">Confirm</code>. Once the **SFTP** option is enabled, you will be able to use your web hosting plan's SFTP protocol with the FTP user concerned.
  </Tab>
</Tabs>

:::info
The <code className="action">FTP, SFTP and SSH</code> value is only offered on plans that include SSH access: **Pro**, **Performance**, **Agency**, **Agency Plus** and **Agency Max**.

On <Region zones={['eu']}>**Free hosting**, **Starter**, **Personal** and **Startup**</Region><Region zones={['ca', 'apac']}>**Starter**, **Personal** and **Startup**</Region> plans, the **Connection protocols** menu only offers <code className="action">FTP</code> and <code className="action">FTP and SFTP</code>, and the users table does not show an **SSH** column.

:::
