## Objective

The information contained in this guide concerns the versions of **PHP**, **Python**, **Perl** and **Apache** used with [Web Hosting](/links/web/hosting) services.

**Learn more about PHP, Python, Perl and Apache versions.**

## Requirements

- An OVHcloud [Web Hosting plan](/links/web/hosting)

## Instructions

The tables below list the language versions available on OVHcloud Web Hosting plans and their status. Each version links to its information page, which shows the full version number and the configuration.

### Version status

<span style={{backgroundColor:"#198754", color:"white", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Supported</span>: version maintained on Web Hosting plans.

<span style={{backgroundColor:"#ffc107", color:"#212529", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>End of life</span>: migrate to a supported version before its end of life at OVHcloud.

<span style={{backgroundColor:"#dc3545", color:"white", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Deprecated</span>: version no longer maintained; migrate to a supported version.
