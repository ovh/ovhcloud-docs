## Objective

OVHcloud web hosting plans provide access to an FTP storage space. You can use this FTP space to put your website or application files online, for example. You can access this space via an FTP or SSH user account, and the associated password. As part of your business, you may need to have several FTP user logins for your employees.

**This guide explains how to create, modify or delete FTP users on your OVHcloud web hosting plan.**

:::info
This guide is only valid for **Professional**, **Performance**, **Agency**, **Agency Plus** and **Agency Max** web hosting plans. Only these solutions allow you to activate multiple FTP users.

:::

## Requirements

- A compatible [OVHcloud web hosting plan](/links/web/hosting)

## Instructions

### Create a new FTP user on your web hosting plan <a name="create-ftp-user"></a>

To create a new FTP user on your web hosting plan via the OVHcloud Console, click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">FTP-SSH</code> tab.

    <img className="thumbnail" alt="FTP-SSH tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the **FTP and SSH users** section, click <code className="action">Create a user</code>.

    <img className="thumbnail" alt="FTP user creation panel in the Console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/create-user.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    The **Create a user** panel opens and gathers all the settings on a single screen:

    - **User**: the name your collaborator will use to log in. It is **always preceded by your web hosting plan's main FTP login, followed by a hyphen**: if this login is `ftplogin` and you enter `user1`, the full login will be `ftplogin-user1`. The name you add has between 1 and 12 alphanumeric characters;
    - **Root folder**: the directory in which this user will be able to work. **Leave this field empty to give access to the whole storage space**; otherwise, enter a directory or subdirectory, for example `www`, `blog`, `website1` or `www/development`;
    - **Connection protocols**: the protocol(s) allowed for this user. By choosing **FTP, SFTP and SSH**, your collaborator will be able to manage files as well as connect via the command line;
    - **Password** and **Confirm password**: follow the policy shown under the fields.

    Finally, click <code className="action">Create</code>.
  </Tab>
</Tabs>

:::info
Once the creation request has been validated, it can take up to 15 minutes for the new user to be registered on your web hosting plan.

:::

If necessary, test the new FTP user using our guide "[Logging in to your web hosting plan's FTP storage space](/guides/web-cloud/web-hosting/ftp-connection)".

### Modify an FTP user

To edit an FTP user, click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">FTP-SSH</code> tab.

    <img className="thumbnail" alt="FTP-SSH tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    The **FTP and SSH users** section lists the users created on your web hosting plan. In the **Actions** column, click the <code className="action">⋮</code> button to the right of the user concerned, then <code className="action">Edit</code>.

    <img className="thumbnail" alt="Actions menu of an FTP user in the Console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    The **Edit a user** panel opens. Three settings are available:

    - **Root folder**: the directory in which this user will be able to work. Leave this field empty to give them access to the whole storage space;
    - **Disable user**: tick this box to prevent a collaborator from accessing your FTP storage space **without deleting the FTP and SSH logs associated with them**. These logs will allow you to determine what operations they performed if you notice any unwanted interventions on your web hosting plan;
    - **Connection protocols**: the protocol(s) allowed for this user. See the "[Create a new FTP user on your web hosting plan](#create-ftp-user)" section earlier in this guide for details of the protocols.

    :::info
    The **root folder** of the **primary account** cannot be modified: the field remains greyed out and the console displays the message "The root folder of the primary account cannot be changed.". Only the users you have created can change it.
    :::

    The user name and password cannot be modified here. To change the password, use the <code className="action">Change password</code> entry of the same menu, described in our guide "[Changing an FTP user password](/guides/web-cloud/web-hosting/ftp-change-password)".

    <img className="thumbnail" alt="FTP user edit panel" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user.png" loading="lazy" />

    Finally, click <code className="action">Confirm</code>.
  </Tab>
</Tabs>

:::info
If you only want to change the FTP user password, please refer to our guide on "[Changing an FTP user password](/guides/web-cloud/web-hosting/ftp-change-password)".

If you would like to change the FTP username, you must [create a new FTP user](#create-ftp-user) with the new username you want. You are then free to [delete the old FTP user](#delete-ftp-user) if required.

:::

### Delete an FTP user <a name="delete-ftp-user"></a>

To delete an FTP user, click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">FTP-SSH</code> tab.

    <img className="thumbnail" alt="FTP-SSH tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the **Actions** column of the **FTP and SSH users** section, click the <code className="action">⋮</code> button to the right of the user concerned, then <code className="action">Delete</code>.

    <img className="thumbnail" alt="Actions menu of an FTP user in the Console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    A window asks you to confirm, showing the login concerned. Click <code className="action">Delete</code> to permanently remove this user from your web hosting plan.

    <img className="thumbnail" alt="Confirmation window for deleting an FTP user" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/delete-user-confirmation.png" loading="lazy" />
  </Tab>
</Tabs>
