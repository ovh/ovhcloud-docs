## Objective

Search engines (Google, Bing, Yahoo, etc.) use robots in order to index and rank websites. They prioritise geolocated sites in the country you are searching from.

**Example**: If you search through a search engine and are located in England, geolocated websites in England will show up higher in search results than other websites.

This geolocation is based on the IP address of the hosting plan where your website is located.

The geolocation option on your hosting can be useful for SEO if your website is mainly visited in a country different from where your shared hosting is located.

**This guide explains how to geolocate your website using our geolocated IP addresses.**

:::info
This procedure applies to the <ManagerLink to="/beta/#/">new version of the OVHcloud Control Panel</ManagerLink>, currently available in beta. To follow it, switch to this interface from your usual Control Panel.

:::

## Instructions

For websites hosted on the OVHcloud shared hosting infrastructure which are mainly accessed by international visitors, we offer a geolocation by IP address option. It allows for a better search ranking in the country where the IP address you have selected is located.

{/* CP-STEPS-START:configure-geolocation */}
To use the IP geolocation option, click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hosting plans</ManagerLink> page, then select the web hosting plan concerned.

    <img className="thumbnail" alt="Hosting plans" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    On the page that opens, click on the <code className="action">My sites</code> tab.

    <img className="thumbnail" alt="My sites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the table that appears, click on the <code className="action">></code> button to the left of the name of the website to display the associated domain names or subdomains.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />

    Then click on the <code className="action">⁝</code> button to the right of the relevant domain name or subdomain, then on <code className="action">Modify domain</code>.

    <img className="thumbnail" alt="Associated domains options" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/associated-domains-options.png" loading="lazy" />

Choose the IP address of the country for which you want to geolocate your site, from the 12 countries offered: *Czech Republic, Finland, France, Germany, Ireland, Italy, Lithuania, Netherlands, Poland, Portugal, Spain, United Kingdom*.

    Click <code className="action">Next</code> and then click <code className="action">Confirm</code> from the summary window.
  </Tab>
</Tabs>

{/* CP-STEPS-END:configure-geolocation */}

:::info
Once you have carried out the steps above, and if your domain name’s active DNS zone is fully managed in your <ManagerLink to="/">OVHcloud Control Panel</ManagerLink>, the A record in your domain name’s DNS zone will be automatically changed. You can check that the IP address has been updated using our guide on [Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit).

Otherwise, you will need to make the change manually with the provider that manages your domain name’s active DNS zone. Find [here](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip) the documentation that lists all the IP addresses in our OVHcloud shared hosting infrastructure.

In both cases, you will need to wait between **4 and 24 hours** for the changes to propagate fully, and be visible on the internet.

:::
