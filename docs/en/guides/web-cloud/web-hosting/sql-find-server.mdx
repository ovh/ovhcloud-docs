## Objective

During the use of your services, you may need to know the name of the SQL server on which your database is located (either included or ordered as an additional service via your [web hosting](/links/web/hosting)).

:::warning
This guide does not apply to databases hosted on a [Web Cloud Databases](/links/web/databases) solution.

:::

**Discover how to find the name of the server hosting your shared database, accessible with your web hosting.**

## Requirements

- An OVHcloud [Web Hosting plan](/links/web/hosting)
- A database included or [ordered as an additional service](/links/web/hosting-options-startsql) via your web hosting

[[cpnav:web-hosting-console]]

## Instructions

Click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">Databases</code> tab.

    <img className="thumbnail" alt="Databases tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the table, find the row of the database concerned using the **Database name** column, then read its **Server address** column.

    <img className="thumbnail" alt="Databases table and its Server address column" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/tab.png" loading="lazy" />

You will find the name of the SQL server (e.g., **mysqlXXX.euXXX**) on which your shared database is hosted.

    :::warning
    Despite its label, this column shows the **server**, not the connection address of your database. The two notions are distinct:

    - The **server** represents the infrastructure hosting your database, as well as other databases. Its name allows you to check whether it is affected by a maintenance operation or an incident reported on our [Web Cloud Status](https://web-cloud.status-ovhcloud.com/) page.
    - The **server address** is part of the login credentials specific to your database and allows your website to connect to it.

    :::

  </Tab>
</Tabs>
