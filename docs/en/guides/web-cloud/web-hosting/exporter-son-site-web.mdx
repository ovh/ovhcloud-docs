## Objective

This guideline will outline the steps to follow in order to export all elements of your website in a standard format, from an [OVHcloud web hosting plan](/links/web/hosting).

**Find out how to export an OVHcloud website.**

## Requirements

- an [OVHcloud web hosting plan](/links/web/hosting)

[[cpnav:web-hosting]]

## Instructions

### 1 - Retrieve files from your FTP storage space

#### 1.1 Log in to your storage space

To log in to your storage space, you will need the following:

- The active FTP or SSH user account
- The FTP or SSH user account password
- The server address
- The server connection port

This information was included in the email informing you that your web hosting plan has been set up.

If you don’t have this information, click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">FTP-SSH</code> tab.

    <img className="thumbnail" alt="FTP-SSH tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    The information associated with your storage space will now appear. The **File transfer (FTP/SFTP)** section contains the details you need to log in to it:

    - **Host**: the server address;
    - **Username**: the login of the primary account;
    - **File access method**: the connection port, **22** for SFTP or **21** for FTP.

    <img className="thumbnail" alt="File transfer and SSH access sections and users table" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/tab-pro.png" loading="lazy" />

    The other users created on your web hosting plan are listed in the **FTP and SSH users** section.

    If you need help with this, please refer to our guide on [Logging in to your Web Hosting plan’s storage space](/guides/web-cloud/web-hosting/ftp-connection).

    The password is not displayed in the OVHcloud Console. If you are no longer in possession of it, refer to the instructions set out in our documentation on [Modifying a FTP user password](/guides/web-cloud/web-hosting/ftp-change-password).
  </Tab>
</Tabs>

Once you have everything you need, there are two different ways of retrieving your files from the storage space:

- **Using FTP- or SFTP-compatible software.** You will need to install a compatible program on your computer (e.g. [FileZilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide)). Since OVHcloud did not create the software package you have installed, please contact the software's publisher if you are experiencing difficulties using it.

- **Using SSH access.** You will need to use commands from a terminal to interact with your storage space. More advanced knowledge and a specific [OVHcloud hosting plan](/links/web/hosting) are required to use this type of access. For further information on this, please refer to our guide on [Accessing your web hosting plan via SSH](/guides/web-cloud/web-hosting/ssh-on-webhosting). 

#### 2.1 Download the files from your storage space

Once connected to your storage space and depending on the websites hosted on it, several folders may appear.

If needed, identify the root folder where your website is stored. To do this, click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">My sites</code> tab.

    <img className="thumbnail" alt="My sites tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the table, find the row of your website using the **Site** column, then read its **Root folder** column. This is the directory where the files and folders of your website are located.

    <img className="thumbnail" alt="Sites table and its Root folder column" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/root-folders.png" loading="lazy" />
  </Tab>
</Tabs>

Still connected to your storage space, download the files of your website from the root folder identified above.

### 2 - Retrieve your database backup (optional)

:::info
This step is not required if your website does not use any databases.

:::

To retrieve a backup of your database, please read our guide on
[Retrieving the backup of a Web Hosting plan's database](/guides/web-cloud/web-hosting/sql-database-export).

If you are using a **Web Cloud Databases** database for your website, you can go to the ‘Databases’ tab, click the <code className="action">...</code> button to the right of the database, and click ‘Back up now’ in the drop-down menu.
You can also download, import and restore backups in this section. Please read our guide [Backing up and exporting a database of your database server](/guides/web-cloud/databases/db-backup-export-database-server)

### 3 - Retrieve the logs for your OVHcloud web hosting plan

Refer to our dedicated guide: [Web Hosting - Consulting the statistics and logs of a website](/guides/web-cloud/web-hosting/logs-and-statistics).
