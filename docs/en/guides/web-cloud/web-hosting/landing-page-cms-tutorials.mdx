## Installing a CMS on your Web Hosting plan

A CMS (Content Management System) is software that lets you create and manage a website without coding, from an administration interface.

Install the CMS of your choice on your OVHcloud Web Hosting plan. This page brings together the manual installation guides for the main CMS (WordPress, Joomla, PrestaShop, Drupal and more), or installing a 1-click module directly from your OVHcloud Control Panel.

To find the right guide for your needs:

- **Are you considering installing a CMS for your website?** See the *How to install a CMS* section.
- **Do you want to install one of the most popular CMS (WordPress, Joomla, PrestaShop, Drupal)?** See the *Most popular CMS* section.
- **Are you looking to install another CMS (Grav, Pico, Typo3, SPIP)?** See the *Other CMS* section.
