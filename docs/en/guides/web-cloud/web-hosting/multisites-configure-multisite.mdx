## Objective

You can host multiple websites on a single web hosting offer, even if the domain names are not registered with OVHcloud.

Would you like to add a new website to your web hosting?

**Discover how to host different websites on your web hosting offer.**

:::info
If you have already created the website on your web hosting and want to associate it with a new domain name or subdomain, please refer to [this guide](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website) **directly**.

:::

## Requirements

- A compatible [OVHcloud Web Hosting plan](/links/web/hosting-multisite)
- One or more [domain names](/links/web/domains)
- The right to modify your domain name's configuration (the [DNS Zone](/guides/web-cloud/domains/dns-zone-edit))

[[cpnav:web-hosting-console]]

## Instructions

### 1 - Add a website to your web hosting offer

**Click on one of the titles below to view the explanations.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Add a website with a domain name managed in your OVHcloud account</summary>

This part only applies if the domain name (and/or its active DNS zone) with which you want to create your website is **in your OVHcloud account**.

The add form fits on a single page: fill it in from top to bottom, then confirm. Click on the tabs below to view each of the **5** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click the <code className="action">My sites</code> tab, then the <code className="action">Add a site</code> button above the table.

    <img className="thumbnail" alt="My sites tab and Add a site button" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-button.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the **Root folder** section, enter the name of the folder that will contain your website files. Leave the field empty for the Console to create it automatically.

    In the **Domain name association** section, choose the **Existing OVHcloud domain name** option.

    <img className="thumbnail" alt="Root folder and choice of the domain name type" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    :::warning
    The **root folder** is also created in your web hosting storage space, accessible via FTP, SFTP or SSH depending on your plan. If your website content is already in a specific folder of this space, enter its name here.
    :::
  </Tab>
  <Tab label="Step 4">
    The **Configure your domain** section appears. In the **Site name** field, enter a name of your choice: it is only used to identify your site in the OVHcloud Console. Then select the domain name to associate in the **Domain name** drop-down menu.

    <img className="thumbnail" alt="Domain configuration, options and DNS configuration" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-configure-domain.png" loading="lazy" />

    :::info
    To add a subdomain, first select the domain name (for example: domain.tld), then tick **Create a subdomain**. A field appears for you to enter it (for example: **sub**.domain.tld).

    **Special case**: the `www` subdomain (for example: **www**.domain.tld) is not added automatically with the domain name. For it to display your site too, add it separately, repeating this procedure with `www.domain.tld`.
    :::

    The **Options** section brings together three features, unticked by default. Depending on your [web hosting plan](/links/web/hosting), some may not be selectable.

    |Option|Description|
    |---|---|
    |Country IP|Allows you to benefit from a geolocated IP address (from a list of countries) for the selected domain name.<br/> Learn more from [this page](/links/web/hosting-options).|
    |Firewall|Allows you to activate a firewall (filtering and analysis of requests) on the selected domain name.<br/> Learn more from [this page](/links/web/hosting-options).|
    |CDN|Allows you to activate the CDN (caching of static elements of your website, such as images) on the selected domain name.<br/> Learn more from [our CDN page](/links/web/hosting-options-cdn).<br/> By activating SSL and the CDN, you will also benefit from the **HTTP/2** protocol (this protocol is activated by default in our Gravelines datacenter).|

    :::info
    These options can be enabled later, once the website has been created. To do this, see [this guide](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::

    Finally, the **DNS Configuration** section offers two modes:

    - **For an automatic configuration**, leave the **Automatic configuration** option selected: the A and AAAA records are created in the domain's DNS zone. A banner states that the Console will try to resolve conflicts by deleting incompatible entries.
    - **For a manual configuration**, choose the **Manual configuration** option, then refer to the following guides:
        - [Web Hosting - List of IP addresses by cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Edit an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit)
  </Tab>
  <Tab label="Step 5">
    The **Choose a 1-click module to install** section completes the form. OVHcloud provides the WordPress, Joomla!, PrestaShop and Drupal modules, installed automatically in the root folder configured above. For more information, see our guide "[Setting up your website with a 1-click module (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules)".

    <img className="thumbnail" alt="Choice of the 1-click module to install" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-1-click-module.png" loading="lazy" />

    Leave **No pre-installed module** selected if you prefer to upload your website files yourself. For more information, see our guide "[Publishing a website on your Web Hosting plan](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online)".

    Finally, check the information entered, then click <code className="action">Validate</code>. The addition can take up to an hour.

    :::info
    Changes to your domain name's DNS configuration require a propagation period of up to 48 hours before they are fully effective.
    :::
  </Tab>
</Tabs>

</details>

<details>
<summary>Add a website with a domain name not managed in your OVHcloud account</summary>

This section applies only if you want to add a website with a domain name that is not present in your OVHcloud account. It may be a domain name in another OVHcloud account or registered with another provider.

The add form fits on a single page: fill it in from top to bottom, then confirm. Click on the tabs below to view each of the **5** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click the <code className="action">My sites</code> tab, then the <code className="action">Add a site</code> button above the table.

    <img className="thumbnail" alt="My sites tab and Add a site button" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-button.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the **Root folder** section, enter the name of the folder that will contain your website files. Leave the field empty for the Console to create it automatically.

    In the **Domain name association** section, choose the **External domain name** option.

    <img className="thumbnail" alt="Root folder and choice of the domain name type" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    :::warning
    The **root folder** is also created in your web hosting storage space, accessible via FTP, SFTP or SSH depending on your plan. If your website content is already in a specific folder of this space, enter its name here.
    :::
  </Tab>
  <Tab label="Step 4">
    In the **Configure your domain** section, enter the **Site name** of your choice: it is only used to identify your site in the OVHcloud Console. Then enter the domain name (for example: domain.tld) or the subdomain (for example: **sub**.domain.tld) in the **Domain name** field.

    :::tip
    **Special case**: the `www` subdomain (for example: **www**.domain.tld) is not added automatically with the domain name. For it to display your site too, add it separately, repeating this procedure with `www.domain.tld`.
    :::

    The **Domain management** section then displays the records to create, in two steps. This verification is mandatory: it allows us to make sure that adding the external domain name is legitimate.

    <img className="thumbnail" alt="Domain management: DNS records to create and BIND record" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-external-dns.png" loading="lazy" />

    1. **Verify domain ownership**: add the **TXT** record shown in your provider's DNS zone.
    2. **Point the domain to your hosting**: add the **A** and **AAAA** records shown.

    Each value has a copy button, and the **BIND record** block repeats the three lines in the format expected by most DNS zone hosts.

    :::warning
    Make these changes **quickly**. Without this action, the addition of your domain name will be cancelled and your newly created website will not be accessible.

    The **A** and **TXT** DNS entries must be placed in your domain name's active DNS zone. Only the **AAAA** entries are optional.

    Note that if you wish to associate `sub.domain.tld`, you will need to create the `ovhcontrol.domain.tld` TXT entry and not the `ovhcontrol.sub.domain.tld` entry.

    To find the active DNS zone of your domain name, find the [DNS servers](/guides/web-cloud/domains/dns-server-edit) to which it is linked. You will only need to validate the domain name using the **TXT** field, not all its subdomains.
    :::

    :::info
    Unlike domain names managed in your OVHcloud account, the **Options** and **DNS Configuration** sections are not offered for an external domain name.

    These features can still be enabled once the website has been created. To do this, see [this guide](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::
  </Tab>
  <Tab label="Step 5">
    The **Choose a 1-click module to install** section completes the form. OVHcloud provides the WordPress, Joomla!, PrestaShop and Drupal modules, installed automatically in the root folder configured above. For more information, see our guide "[Setting up your website with a 1-click module (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules)".

    <img className="thumbnail" alt="Choice of the 1-click module to install" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-1-click-module.png" loading="lazy" />

    Leave **No pre-installed module** selected if you prefer to upload your website files yourself. For more information, see our guide "[Publishing a website on your Web Hosting plan](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online)".

    Finally, click <code className="action">Validate</code>. The domain name is added temporarily, while you change its DNS configuration.

    :::info
    Changes to your domain name's DNS configuration require a propagation period of up to 48 hours before they are fully effective.
    :::
  </Tab>
</Tabs>

</details>

<summary>Add a website with a new domain name that has not yet been registered</summary>

This section applies only if you want to add a website with a domain name that has not yet been registered, either with OVHcloud or with another registrar. In other words, it concerns domain names that have not yet been subscribed to.

Click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click the <code className="action">My sites</code> tab, then the <code className="action">Add a site</code> button above the table.

    <img className="thumbnail" alt="My sites tab and Add a site button" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-button.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the **Domain name association** section, choose the **Order a new domain name** option.

    <img className="thumbnail" alt="Root folder and choice of the domain name type" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    The form asks for nothing more: the button at the bottom of the page then reads <code className="action">Order a new domain name</code>. Click it.

    You are then redirected to our domain name ordering page. Choose your new domain name according to market availability, then follow the instructions of the ordering process until the order form is validated, without also ordering a new web hosting plan.

    Once your order is paid and validated, wait a few moments for it to be processed.

    :::info
    Once your domain name appears in your OVHcloud account, follow the "[Add a domain name managed in your OVHcloud account](#add-domain-ovhcloud)" part of this guide to add your website to your web hosting plan.
    :::
  </Tab>
</Tabs>

</details>

### 2 - Put your website online <a name="site-online"></a>

Once the website has been declared with your domain name on your web hosting plan, you can upload your website content. As a reminder, you must do this in the **root folder** you defined when adding the website in the OVHcloud Console.

:::info
If you wish to add multiple websites, repeat the actions described in this guide.

We recommend that you be careful about the number of websites on your web hosting. The higher the number, the more your allocated resources will be used. [Our web hosting offers page](/links/web/hosting) indicates the recommended number of websites you can host on your web hosting.

:::
