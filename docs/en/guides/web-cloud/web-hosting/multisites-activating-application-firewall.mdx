## Objective

*ModSecurity* is a complementary Apache module that filters all incoming requests on your web server. It increases security against known vulnerabilities by intercepting and filtering requests before they are processed by any scripts. 

The preconfigured Core Rule Set (CRS) of our *ModSecurity* protects your websites against the most common attacks, for example:

- Trojans
- Email injections
- Broken PDF files
- File injections on your hosting system
- SQL or XSS type injections

**This guide explains how to enable the application firewall from your OVHcloud Control Panel, in order to benefit from enhanced protection.**

:::info
Since your web hosting plan is hosted on a shared infrastructure, modifying your firewall configuration settings is unavailable.

:::

:::info
Some procedures in this guide apply to the <ManagerLink to="/beta/#/">new version of the OVHcloud Control Panel</ManagerLink>.
A reminder is shown at the beginning of each affected section.

:::

## Requirements

- an [OVHcloud Web Hosting plan](/links/web/hosting)

## Instructions

**Click on the titles below to display the explanations.**

<details>
<summary>Enable the application firewall on your entire web hosting in the PHP configuration</summary>

{/* CP-STEPS-START:enable-firewall */}
Click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/#/web/hosting">Hosting plans</ManagerLink> page, then select the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    In the **Configuration** section, you will find the **Global PHP Version**.

    <img className="thumbnail" alt="Global PHP version" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/modify-hosting-configuration.png" loading="lazy" />

    Click on the <code className="action">...</code> button to the right of **Global PHP Version**, then on <code className="action">Modify configuration</code>.
  </Tab>
  <Tab label="Step 3">
    In the window that opens, select the <code className="action">Modify the current configuration</code> option and click on the <code className="action">Next</code> button.

    <img className="thumbnail" alt="managephpconfig" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/application-firewall-step-2.png" loading="lazy" />

    In the new window, make sure the **Application Firewall** option is set to <code className="action">Enabled</code>. Then click on the <code className="action">Confirm</code> button.
  </Tab>
</Tabs>

{/* CP-STEPS-END:enable-firewall */}

</details>

<details>
<summary>Enable the application firewall only on a specific domain name or subdomain</summary>

{/* CP-STEPS-START:disable-firewall */}
Click on the tabs below to view each of the **4** steps.

:::info
This section applies to the <ManagerLink to="/beta/#/">new version of the OVHcloud Control Panel</ManagerLink>.

:::

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hosting plans</ManagerLink> page, then select the web hosting plan concerned.

    <img className="thumbnail" alt="Hosting plans" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    On the page that opens, click on the <code className="action">My sites</code> tab.

    <img className="thumbnail" alt="My sites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the table that appears, click on the <code className="action">></code> button to the left of the name of the website to display the associated domain names or subdomains.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />

    Then click on the <code className="action">⁝</code> button to the right of the relevant domain name or subdomain, then on <code className="action">Modify domain</code>.

    <img className="thumbnail" alt="Associated domains options" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/associated-domains-options.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    In the configuration window, tick the box <code className="action">Enable the firewall</code>. You can also include the subdomain `www` in this configuration by ticking the corresponding box at the top (if it is also declared on the same website).

    <img className="thumbnail" alt="Modify a domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/modify-a-domain-enable-firewall-step-1.png" loading="lazy" />

    Click on <code className="action">Next</code>, then on <code className="action">Confirm</code> to validate the parameter changes.

    Once the firewall is enabled for your domain name or subdomain, the **Enabled** label appears in the **Firewall** column.

    If the **Enabled** label does not appear after a few minutes on the row corresponding to the relevant domain name or subdomain, refresh the page.
  </Tab>
</Tabs>
