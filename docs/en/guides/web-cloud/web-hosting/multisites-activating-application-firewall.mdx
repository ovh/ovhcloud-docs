## Objective

*ModSecurity* is a complementary Apache module that filters all incoming requests on your web server. It increases security against known vulnerabilities by intercepting and filtering requests before they are processed by any scripts. 

The preconfigured Core Rule Set (CRS) of our *ModSecurity* protects your websites against the most common attacks, for example:

- Trojans
- Email injections
- Broken PDF files
- File injections on your hosting system
- SQL or XSS type injections
- etc.

**This guide explains how to enable the application firewall from the OVHcloud Console, in order to benefit from enhanced protection.**

:::info
Since your web hosting plan is hosted on a shared infrastructure, modifying your firewall configuration settings is unavailable.

:::

## Requirements

- an [OVHcloud Web Hosting plan](/links/web/hosting)
- at least one [domain name](/links/web/domains) attached to the hosting

## Instructions

**Click on the titles below to display the explanations.**

<details>
<summary>Enable the application firewall on your entire web hosting in the PHP configuration</summary>

Click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    The hosting plan opens on the <code className="action">Overview</code> tab. Find the **PHP** section, which shows the **Global PHP version** entry, then click <code className="action">Change the PHP version</code>.

    <img className="thumbnail" alt="PHP section of the Overview tab" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/php-section.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    The configuration panel opens on the right. In the **Advanced options** section, open the **Application firewall** drop-down menu, then select the <code className="action">security</code> value: it enables `mod_security`, which protects your hosting plan against common attacks. The <code className="action">disabled</code> value leaves the firewall inactive.

    <img className="thumbnail" alt="Advanced options of the PHP configuration and Application firewall menu" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/php-config-firewall.png" loading="lazy" />

    Finally, click <code className="action">Confirm</code>.

    :::warning
    A configuration change can affect your websites: remember to test them after any modification.
    :::
  </Tab>
</Tabs>

</details>

<details>
<summary>Enable the application firewall only on a specific domain name or subdomain</summary>

Click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">My sites</code> tab. In the table, click the <code className="action">⋮</code> button in the **Actions** column, to the right of the website concerned, then, in the **Domain names** group, on <code className="action">Manage my domains</code>.

    <img className="thumbnail" alt="Actions menu of a website" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    The **Manage my domains** panel opens on the right and lists the domain names and subdomains associated with this website. On the domain concerned, click the <code className="action">⋮</code> button to the right of its name, then on <code className="action">Manage my options</code>.

    <img className="thumbnail" alt="Manage my domains panel and Actions menu of a domain" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/manage-domains-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    In the **Manage options** window, **Security** group, tick the <code className="action">Enable firewall</code> box, then click <code className="action">Confirm</code>.

    <img className="thumbnail" alt="Manage options window of a domain name" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/country-ip-selection.png" loading="lazy" />

    :::info
    The setting only applies to the selected domain name or subdomain. To also protect the `www` subdomain, repeat the operation on its row in the **Manage my domains** panel, if it is declared there.
    :::

    Once the firewall is enabled, the **Firewall** column of the websites table shows the number of protected domain names out of the total number associated with the website, for example `1/4`. If this count does not change after a few minutes, reload the page.
  </Tab>
</Tabs>

</details>
