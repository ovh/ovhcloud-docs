## Objective

You can host multiple websites on the same web hosting plan, even if the domain names are not registered with OVHcloud. In addition, you can associate one or more domain names or subdomains with the same website.

Do you no longer want to use a domain name or subdomain for your website?
Do you want to associate your domain name or subdomain with another website on one of your web hosting plans?

**Find out how to detach a domain name or subdomain from an existing website on your web hosting.**

## Requirements

- A compatible [OVHcloud web hosting plan](https://www.ovhcloud.com/en-gb/web-hosting/uc-multisite/)
- One or more [domain names](https://www.ovhcloud.com/en-gb/domains/)
- Access to modify the configuration of the [DNS zones of your domain names](/guides/web-cloud/domains/dns-zone-edit)

[[cpnav:web-hosting-console]]

## Instructions

:::warning
Detaching a domain name or subdomain from a website on your web hosting is a sensitive operation. Indeed, after this operation, your website will no longer be accessible on the Internet using your domain name and/or subdomain.

:::

Click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click the <code className="action">My sites</code> tab. In the table, click the <code className="action">⋮</code> button in the **Actions** column, to the right of the website concerned, then, in the **Domain names** group, <code className="action">Manage my domains</code>.

    <img className="thumbnail" alt="Actions menu of a website" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    The **Manage my domains** panel opens on the right and lists the domain names and subdomains associated with this website. On the one you want to detach, click the <code className="action">⋮</code> button to the right of its name, then <code className="action">Detach</code>.

    <img className="thumbnail" alt="Manage my domains panel and Actions menu of a domain" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/manage-domains-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    The **Detach a domain** window opens and asks you to confirm your choice. It contains two settings:

    <img className="thumbnail" alt="Detach a domain window" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/detach-domain-dialog.png" loading="lazy" />

    - **Also detach the subdomain**, followed by the `www` subdomain concerned: unticked by default, this box detaches it at the same time as the domain name, if it is also declared on this website. The DNS zone of this subdomain and all its options are then deleted.
    - <code className="action">Delete the pointing records (A and AAAA) in the domain name's DNS zone.</code>: ticked by default, this box removes the records pointing to your web hosting plan from the DNS zone. Untick it if you want to keep these records.

    Finally, click <code className="action">Confirm</code>.

    :::warning
    **Special case: your website is associated with a Git repository**

    The window then displays a warning and an additional box, <code className="action">Yes, delete my Git configuration</code>. The <code className="action">Confirm</code> button remains inactive until you tick it: detaching the domain name also deletes the website's [Git association](/guides/web-cloud/web-hosting/git-integration-webhosting).

    <img className="thumbnail" alt="Detach a domain window on a site associated with Git" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/detach-domain-git.png" loading="lazy" />

    :::
  </Tab>
</Tabs>

### Special case: Detaching a domain name or subdomain to use it with another website

- If you want to add your domain name or subdomain to another existing website on a web hosting, refer to [this guide](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).
- If you want to create a new website on a web hosting with your recently detached domain name or subdomain, refer to [this guide](/guides/web-cloud/web-hosting/multisites-configure-multisite).
