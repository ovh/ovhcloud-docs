## WordPress on your Web Hosting plan

Create, manage and secure your WordPress sites on your OVHcloud Web Hosting plan. This page brings together the guides to install and get started with WordPress, use it day to day (WooCommerce, .htaccess file, backup) and manage multiple WordPress sites with the MainWP plugin.

To find the right guide for your needs:

- **New to WordPress?** See the *Install and get started with WordPress* section (first steps, 1-click module, manual installation, migration).
- **Is your WordPress site already live?** See the *Use and manage WordPress* section (WooCommerce, .htaccess, admin password, backup).
- **Running several WordPress sites?** See the *Manage multiple sites with MainWP* section (administration, backup, security, clients).
