## Objective

You have forgotten the name of your [web hosting offer](https://www.ovhcloud.com/en-gb/web-hosting/)?
You want to check its details or compare it to another offer?

During the use of your services, you may need the name of your web hosting offer.

**Find out how to identify the type of web hosting offer you have from your OVHcloud Control Panel.**

## Requirements

- Have a [web hosting offer](https://www.ovhcloud.com/en-gb/web-hosting/).

{/* CP-NAV-START:web-hosting */}
---

### OVHcloud Control Panel Access

- **Direct link:** <ManagerLink to="/#/web/hosting">Hosting plans</ManagerLink>
- **Navigation path:** <code className="action">Web Cloud</code> > <code className="action">Hosting plans</code> > Select your web hosting plan

---
{/* CP-NAV-END:web-hosting */}

## Instructions

Click on the tabs below to view each of the **2** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/#/web/hosting">Hosting plans</ManagerLink> page, then select the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    In the **Plan** section, you will find the mention **Service plan**.

    <img className="thumbnail" alt="Plan" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-plan-pro.png" loading="lazy" />

Under this mention, you will find the name of your web hosting offer (e.g., Personal, Professional, Performance, etc.).
  </Tab>
</Tabs>
