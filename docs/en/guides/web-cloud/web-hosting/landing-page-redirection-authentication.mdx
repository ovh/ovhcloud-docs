## Redirection and authentication with the .htaccess file

The `.htaccess` file lets you control access to your website and redirect or rewrite its URLs, directly on your OVHcloud Web Hosting plan. This page brings together the guides to protect access (password, IP address blocking), rewrite URLs and make the most of the other capabilities of the `.htaccess` file.
