## Objective

You may see the error page “**Site not installed**” displayed on your web browser, particularly when your website is first installed.

<img className="thumbnail" alt="website not installed" src="/images/assets/screens/other/browsers/errors/site-not-installed.png" loading="lazy" />

**This guide explains how to identify and resolve the "Site not installed" error page.**

:::warning
OVHcloud provides services for which you are responsible with regard to their configuration and management. It is therefore your responsibility to ensure that they function correctly.

This guide is designed to help you with common tasks. Nevertheless, we recommend contacting a [specialist provider](https://partner.ovhcloud.com/en-gb/directory/) or reach out to the [OVHcloud community](https://community.ovhcloud.com/) if you encounter any difficulties. We will not be able to assist you. You can find more information in the [Go further](#go-further) section of this guide.

:::


:::info
Some procedures in this guide apply to the <ManagerLink to="/beta/#/">new version of the OVHcloud Control Panel</ManagerLink>.
A reminder is shown at the beginning of each affected section.

:::

## Requirements

- An [OVHcloud web hosting plan](https://www.ovhcloud.com/en-gb/web-hosting/)
- Administrative access to the [DNS zone](/guides/web-cloud/domains/dns-zone-edit) your domain name is attached to.

## Instructions

The “**Site not installed**” page appears for two reasons:

- 1: [Your domain name or subdomain is not correctly declared on one of the websites on your web hosting](#check-my-websites).
- 2: [Your domain name is not linked to the IP address of your web hosting plan.](#check-dns-domain).

The following steps will allow you to correct the “Site not installed” error in both cases.

### 1 - Check the declaration of your domain name or subdomain on your website on your web hosting <a name="check-my-websites"></a>

{/* CP-STEPS-START:check-my-websites */}
Click on the tabs below to view each of the **3** steps.

:::info
This section applies to the <ManagerLink to="/beta/#/">new version of the OVHcloud Control Panel</ManagerLink>.

:::

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hosting plans</ManagerLink> page, then select the web hosting plan concerned.
    
    <img className="thumbnail" alt="Hosting plans" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    On the page that opens, click on the <code className="action">My sites</code> tab.
    
    <img className="thumbnail" alt="My sites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the table that appears, click on the <code className="action">></code> button to the left of the name of the website concerned to display the domain names and subdomains associated.
    
    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
    
    |Scenarios|Actions to take|
    |---|---|
    |The domain name or subdomain associated with your website **appears** in the table.|If you have just added your domain name or subdomain to your website on your web hosting, wait approximately **twenty minutes** and then refresh the cache of your web browser. If the message "Site not installed" still appears, proceed to [part 2](#check-dns-domain).|
    |The domain name or subdomain associated with your website **does not appear** in the table.|Add your domain name or subdomain by following our guide "[How to associate a domain name with an existing website?](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".|
    |The domain name or subdomain **has been removed** from the table without your action.|Your domain name or its DNS zone may be managed from another account. Add your domain name or subdomain by following our guide "[How to associate a domain name with an existing website? - Add an external domain name](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".|
  </Tab>
</Tabs>

### 2 - Check the IP pointing in your domain name’s active DNS zone <a name="check-dns-domain"></a>

This step involves checking that your domain or subdomain points to your Web Hosting plan’s IP address from its active DNS zone.

:::info
To find out more about DNS, visit the following pages:

- [Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit)
- [Creating an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-create)
- [Modify an OVHcloud domain name’s DNS servers](/guides/web-cloud/domains/dns-server-edit)

:::


#### 2\.1 Identify the IP address of your OVHcloud web hosting plan

{/* CP-STEPS-START:check-dns-ip */}
Click on the tabs below to view each of the **2** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/#/web/hosting">Hosting plans</ManagerLink> page, then select the web hosting plan concerned.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    In the **General information** box, you will see the address under **IPv4**.
    
    <img className="thumbnail" alt="find-ipv4-and-ipv6" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-ipv4-and-ipv6.png" loading="lazy" />

Copy the IPv4 address, then continue reading the guide.
  </Tab>
</Tabs>

{/* CP-STEPS-END:check-dns-ip */}

You can also find the IP address associated with your Web Hosting plan in our guide “[Web Hosting - List of IP addresses by cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)”.

#### 2\.2 Verify the IP address recorded in your domain name’s active DNS zone

You will now need to check that your Web Hosting plan’s IP address appears in your domain name’s active DNS zone.

:::info
Before you continue, whenever a change occurs in a domain name’s active **DNS zone**, you may need to wait between **4 and 24 hours** to update the information on the DNS network.

If you modify the **DNS servers** associated with your domain name directly, this period can be up to **48 hours** maximum.

:::


{/* CP-STEPS-START:check-multisite-root-folder */}
To do this, click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">

    :::info

    This means that your domain name is not managed from your OVHcloud Control Panel.<br/> Determine its registrar and the DNS servers it is associated with using our [WHOIS](https://www.ovhcloud.com/en-gb/domains/whois/) tool.<br/> Identify and modify the relevant DNS zone accordingly by following the dedicated section of the guide "[How to associate a domain name with an existing website? - Add an external domain name](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".
