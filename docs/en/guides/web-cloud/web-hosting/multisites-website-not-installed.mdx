## Objective

You may see the error page “**Site not installed**” displayed on your web browser, particularly when your website is first installed.

<img className="thumbnail" alt="website not installed" src="/images/assets/screens/other/browsers/errors/site-not-installed.png" loading="lazy" />

**This guide explains how to identify and resolve the "Site not installed" error page.**

[[fragment:support-scope]]

:::warning
This guide is designed to help you with common tasks. Nevertheless, we recommend contacting a [specialist provider](/links/partner) or reach out to the [OVHcloud community](/links/community) if you encounter any difficulties. We will not be able to assist you.
:::

:::info
Some procedures in this guide apply to the <ManagerLink to="/beta/#/">new version of the OVHcloud Control Panel</ManagerLink>.
A reminder is shown at the beginning of each affected section.

:::

### 2 - Check the IP pointing in your domain name’s active DNS zone <a name="check-dns-domain"></a>

This step involves checking that your domain or subdomain points to your Web Hosting plan’s IP address from its active DNS zone.

:::info
To find out more about DNS, visit the following pages:

- [Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit)
- [Creating an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-create)
- [Modify an OVHcloud domain name’s DNS servers](/guides/web-cloud/domains/dns-server-edit)

:::

#### 2\.1 Identify the IP address of your OVHcloud web hosting plan

{/* CP-STEPS-START:check-dns-ip */}
Click on the tabs below to view each of the **2** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/#/web/hosting">Hosting plans</ManagerLink> page, then select the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    In the **General information** box, you will see the address under **IPv4**.

    <img className="thumbnail" alt="find-ipv4-and-ipv6" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-ipv4-and-ipv6.png" loading="lazy" />

Copy the IPv4 address, then continue reading the guide.
  </Tab>
</Tabs>

{/* CP-STEPS-END:check-dns-ip */}


<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/#/web/hosting">Hosting plans</ManagerLink> page, then select the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    The table that appears will display a DNS record for each row, linked to your domain name at OVHcloud. You can filter the table content by record type or by domain name.

    <img className="thumbnail" alt="dns zone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/tab.png" loading="lazy" />

    :::info
    If the <code className="action">DNS zone</code> tab of your domain name appears as follows:<br/><br/><img className="thumbnail" alt="DNS zone tab of a domain name that is not managed from the OVHcloud Control Panel" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/zone-without-domain-top-of-the-page.png" loading="lazy" /><br/>

    This means that your domain name is not managed from your OVHcloud Control Panel.<br/> Determine its registrar and the DNS servers it is associated with using our [WHOIS](/links/web/domains-whois) tool.<br/> Identify and modify the relevant DNS zone accordingly by following the dedicated section of the guide "[How to associate a domain name with an existing website? - Add an external domain name](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".

    :::

    Go to step 4 to view the various possible scenarios and the actions to be taken.
  </Tab>
  <Tab label="Step 3">
    |Possible Scenarios|Action to Take|
    |---|---|
    |In the active DNS zone, your domain or subdomain points to your Web Hosting plan's IP address with an A record (for an IPv4 address) or an AAAA record (for an IPv6 address).<br/><br/><img className="thumbnail" alt="DNS zone filtered on A records" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-a.png" loading="lazy" />|This indicates that your domain name is correctly configured.<br/>Wait for the DNS propagation time to complete if the change is recent.<br/><br/>Restart your PCs, devices, and clear your browser cache. Your domain name’s previous configuration may still be cached, which could delay your update from being displayed.|
    |The current DNS zone does not have A or AAAA records that link your domain name or subdomain to the IP address of your Web Hosting plan.|Add the new A or AAAA DNS record or correct the existing record by following [this guide](/guides/web-cloud/domains/dns-zone-edit).|
    |The existing A or AAAA DNS record in the DNS zone for your domain name or subdomain points to an IP address other than your Web Hosting plan’s.|Add the new A or AAAA DNS record or correct the existing record by following [this guide](/guides/web-cloud/domains/dns-zone-edit).|
    |This warning is displayed in the <code className="action">DNS zone</code>:<br/><br/><img className="thumbnail" alt="Warning shown in the DNS zone when the domain name uses other OVHcloud DNS servers" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/message-other-ovh-dns-servers.png" loading="lazy" />|Modify your domain name’s DNS servers accordingly by following our guide on "[How to modify the DNS servers of an OVHcloud domain name](/guides/web-cloud/domains/dns-server-edit)".|
  </Tab>
</Tabs>
