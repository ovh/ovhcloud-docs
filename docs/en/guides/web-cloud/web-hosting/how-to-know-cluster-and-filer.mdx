## Objective

Web Hosting plans run on a shared infrastructure called a *cluster*. OVHcloud has several clusters that host several web hosting plans.  
Each cluster, for efficiency and security reasons, is also divided virtually into several segments called *filers*. The filers themselves contain several web hosting plans.
When using your web hosting plan, you may need to know the cluster and filer your web hosting plan is located on.

**Find out how to find the cluster and filer numbers of your web hosting.**

## Requirements

- An [OVHcloud Web Hosting plan](/links/web/hosting)

[[cpnav:web-hosting-console]]

## Instructions

Click on the tabs below to view each of the **2** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    In the <code className="action">Overview</code> tab, locate the **General information** section. It shows, in turn, the **Region** where your web hosting plan is located, its **Cluster** and its **Filer**.

    The cluster is displayed in the form `clusterXXX`, where the three digits identify the cluster. The filer is a number of varying length.

    <img className="thumbnail" alt="General information section and Region, Cluster and Filer fields" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/region-cluster-filer.png" loading="lazy" />
  </Tab>
</Tabs>
