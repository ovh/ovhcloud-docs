## Accessing your Web Hosting plan via FTP, SFTP and SSH

Transfer your files and manage your OVHcloud Web Hosting plan via the FTP, SFTP and SSH protocols. This page brings together the guides to connect with a client (FileZilla, Cyberduck, Visual Studio Code), manage your FTP access and connect via SSH, using PuTTY or directly from the command line.

To find the right guide for your needs:

- **Need to transfer files to your Web Hosting plan?** See the *Connect via FTP/SFTP* section (FileZilla, Cyberduck, Visual Studio Code).
- **Need to manage your FTP users and passwords?** See the *Manage FTP access* section (users, passwords, SFTP).
- **Working from the command line?** See the *SSH access and command-line tools* section (SSH, PuTTY, SCP, SVN).
