## Configuring your Web Hosting plan

Configure every aspect of your OVHcloud Web Hosting plan: host multiple websites, manage the environment and PHP version, activate the included email addresses, optimise performance and the CDN, monitor logs, deploy (Git, CRON, API) and upgrade your plan. Databases, FTP/SSH access, CMS and security each have their own dedicated page.

To find the right guide for your needs:

- **Do you want to configure your websites, attach your domain names or set up the environment (PHP, IPv6)?** See the *Websites, domain name and environment* section.
- **Do you want to improve the performance of your services or monitor logs (CDN, statistics)?** See the *Performance, CDN and logs* section.
- **Do you need to deploy, automate (Git, CRON, API) or upgrade your plan?** See the *Deployment, automation and plan* section.
