## Objective

You can host several websites on the same web hosting plan, even if the domain names are not registered with OVHcloud. You can also associate one or more domain names or subdomains with the same website.

When using your services, you may need to:

- Replace the entire content of an existing website, without removing it from your web hosting plan. All done without any access interruption and in complete transparency for your website visitors.
- Install a [1-click module](/guides/web-cloud/web-hosting/cms-install-1-click-modules) or [another CMS](/guides/web-cloud/web-hosting/cms-manual-installation) to replace the content of an existing website, without deleting the old content from your web hosting plan. In this case, you then need to build the different pages of your new website via your web browser.
- Reorganise the root folder names of your websites in your web hosting plan's storage space without cutting access to your different websites.

**Find out how to modify the root folder declared for an existing website on your web hosting plan from the OVHcloud Console.**

:::info
If you have not yet created the website concerned on your web hosting plan, refer **directly** to [this guide](/guides/web-cloud/web-hosting/multisites-configure-multisite).

The Console lets you modify a website's root folder, including when it is associated with a Git repository (in this case, see our guide "[Configuring and using Git with an OVHcloud web hosting plan](/guides/web-cloud/web-hosting/git-integration-webhosting)"). Only the site that carries the main domain of your web hosting plan cannot change it: the field is then greyed out.

:::

## Requirements

- A compatible [OVHcloud web hosting plan](https://www.ovhcloud.com/en-gb/web-hosting/uc-multisite/).
- One or more [domain names](https://www.ovhcloud.com/en-gb/domains/).

## Instructions

:::warning
This guide exclusively covers the actions to perform from the <ManagerLink to="/beta/#/">OVHcloud Console</ManagerLink>.

Except in the case where you want to install a 1-click module to build the website gradually, you will first need to:

- Create the new root folder in the [storage space](/guides/web-cloud/web-hosting/ftp-connection) of your web hosting plan.
- Place the entire new content of your website inside this new folder.
- If the new content of your website uses a database, you will also need to [create a database](/guides/web-cloud/web-hosting/sql-create-database), then [import the content related to this database](/guides/web-cloud/web-hosting/sql-importing-mysql-database) into it.
- Place the database access credentials in the file containing the database connection information. This file must already be present in the new root folder.

**Without these actions, your website display will be interrupted**.

This guide only describes the procedure for modifying, from the OVHcloud Console, the root folder initially defined for your website. This action is required so that the website displays the content of the new folder, replacing the old one.

:::

Click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click the <code className="action">My sites</code> tab. In the table, click the <code className="action">⋮</code> button in the **Actions** column, to the right of the website concerned, then, in the **Site** group, <code className="action">Configure my site</code>.

    <img className="thumbnail" alt="Actions menu of a website" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    The **Configure my site** panel opens on the right. In the **Root folder** field, replace the old root folder with the new one.

    <img className="thumbnail" alt="Configure my site panel, Site name and Root folder fields" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/configure-site.png" loading="lazy" />

    :::info
    The panel also lets you rename your website, in the **Site name** field. This name is only used to identify the site in the OVHcloud Console and has no effect on its address or content. Leave it as it is if you only want to modify the root folder.
    :::

    Finally, click <code className="action">Confirm</code> at the bottom of the panel. If you have changed the folder, the **Edit root folder** window summarises the current folder, the new folder and the attached domains: click <code className="action">Confirm</code> again.
  </Tab>
</Tabs>
