## Objective

Your Cloud Web hosting plan has a storage space you can use to host your websites or applications.

**Find out how to retrieve a backup of the FTP space in your Cloud Web hosting plan.**

:::info
Backups offered by OVHcloud for Cloud Web hosting plans are non-contractual. They are available to supplement your own backup methods in urgent situations. We recommend regularly creating your own security backups, to avoid any potential data loss.

When you make a security backup for your site and it uses a database, also back up your database. Please refer to our guide on [retrieving a backup of your database](/guides/web-cloud/web-hosting/sql-database-export).
:::

**Find out how to retrieve and restore an FTP backup of your Cloud Web hosting plan.**

## Requirements

- A [Cloud Web hosting plan](https://www.ovhcloud.com/en-gb/web-hosting/cloud-web-offer/)

## Instructions

A Cloud Web hosting plan has automatic backups available from the following relative dates (24-hour format):

- The same day, after 0:00
- The day before, after 0:00
- The day before yesterday, after 0:00
- The previous Sunday, after 01:00

Only the backups mentioned above can be offered by OVHcloud, provided that your Cloud Web hosting already existed on the dates indicated, and subject to the infrastructure's availability at the requested point in time.

### Retrieve a backup

Unlike OVHcloud shared hosting, you cannot restore the FTP space in one click from the <ManagerLink to="/">OVHcloud Control Panel</ManagerLink>.

A link to download the backup is generated, then sent by email to the email address associated with the Cloud Web hosting plan's admin NIC handle.

### Download the backup

When the backup is ready, you will receive an email via the email address associated with the admin NIC handle for your Cloud Web hosting plan.

This email contains a download link **valid for 9 days** from receipt of the email:

<img className="thumbnail" alt="Backup download email" src="/images/assets/screens/email-sending-to-customer/cloud-web/backup-information.png" loading="lazy" />

The downloaded file is in the format *.tar.gz*.

### Restore your backup

Once you have downloaded your files, you can [connect to your FTP space](/guides/web-cloud/web-hosting/ftp-connection) using FTP software such as [Filezilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide), then replace the respective files on the hosting with the ones from the backup.

:::info
Please use the ports listed in your <ManagerLink to="/">OVHcloud Control Panel</ManagerLink> for SFTP and SSH connections, as port 22 will not work for your Cloud Web hosting.
:::
