## Objective

You can use Secure Socket Layer (SSL) certificates to encrypt any exchange of data on your website. This prevents unauthorized persons and malicious robots from viewing requests to or from your website.

OVHcloud offers several types of SSL certificates for [OVHcloud web hosting solutions](/links/web/hosting). They are set out in our guide on [Managing an SSL certificate on a web hosting plan](/guides/web-cloud/web-hosting/ssl-on-webhosting). SSL certificates are essential for the security of your website.

There are three types of SSL certificates:

- Domain Validation (DV)
- Organization Validation (OV)
- Extended Validation (EV)

SSL encryption levels are the same between these certificate types.

The main difference lies in the level of checks that will be carried out by the Certificate Authority (CA) that issues the SSL certificate and attests to its authenticity.

Let's Encrypt is a free, automated, open, non-profit certification authority. You can find more information on [https://letsencrypt.org/about/](https://letsencrypt.org/about/).

**Find out how to activate a free Let's Encrypt SSL certificate on your OVHcloud web hosting plan.**

## Requirements

- You plan to order or have an [OVHcloud web hosting plan](/links/web/hosting).
- You manage a [domain name](/links/web/domains) for which you have exclusive rights. The domain name must not already be linked to an SSL certificate.

:::info
As of **06/08/2025**, the Let's Encrypt SSL certificate is automatically enabled by default for:

- All new domain names/subdomains linked to a web hosting plan.
- All new domain name subscriptions with a new web hosting plan.

The goal is to save you time configuring your services. You can always disable the Let's Encrypt SSL certificate from the <ManagerLink to="/beta/#/">OVHcloud Console</ManagerLink> if you want to install another SSL certificate (Sectigo DV, Sectigo EV or a custom SSL certificate).
Find more information in our guide "[How to configure an SSL certificate](/guides/web-cloud/web-hosting/ssl-on-webhosting)", part **Disable an SSL certificate on a web hosting plan**.

:::

## Instructions

:::warning
**Before you continue**, please ensure that **each domain name and/or subdomain** covered by a future Let's Encrypt SSL certificate:

- Points to the IP address of your web hosting plan.
- Is declared on one of the websites on your web hosting.
- Does not already have an active SSL certificate.

To check if this is the case, please refer to our guides below:

- [Hosting multiple websites on your Web Hosting plan](/guides/web-cloud/web-hosting/multisites-configure-multisite)
- [Web Hosting - List of IP addresses by cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
- [Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit)
- [Web Hosting - How to configure an SSL certificate](/guides/web-cloud/web-hosting/ssl-on-webhosting), part **Disable an SSL certificate on a web hosting plan**

:::

### Activate the Let's Encrypt SSL certificate

Click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">SSL</code> tab.

    <img className="thumbnail" alt="SSL tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Above the certificates table, click <code className="action">Add a certificate</code>.
  </Tab>
  <Tab label="Step 4">
    A panel opens on the right. Under **Certificate type**, **Let's Encrypt** is already selected: this is the free option, renewed automatically, with domain validation (DV). Under **Domains to secure**, select the domain name(s) and subdomain(s) concerned, then click <code className="action">Activate</code>.

    <img className="thumbnail" alt="Add a certificate panel with Let's Encrypt selected" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/enable-ssl-lets-encrypt.png" loading="lazy" />
  </Tab>
</Tabs>

It may take several hours to set up the Let's Encrypt SSL certificate.

### Verify activation of the free Let's Encrypt (DV) SSL certificate

To verify that the installation is complete, click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/hosting">Web Hosting</ManagerLink> page, then choose the web hosting plan concerned.

    <img className="thumbnail" alt="Web Hosting page and list of the account's hosting plans" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">SSL</code> tab.

    <img className="thumbnail" alt="SSL tab of a web hosting plan" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Find each domain name and subdomain concerned in the **Main domain** column, then read its **Status** column. The installation is complete when it displays **Active**; while it is in progress, it displays **Creating**.

    <img className="thumbnail" alt="SSL certificates table and its Status column" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/tab.png" loading="lazy" />

The table does not show the certificate type. To find it, click <code className="action">Export as CSV</code>: the resulting file contains a **Certificate type** column.

    <img className="thumbnail" alt="Export as CSV button above the table" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/export-csv.png" loading="lazy" />
  </Tab>
</Tabs>

Your Let's Encrypt SSL certificate is now installed and active. You can now use it with your new website(s) by switching, for example, your new [website(s) to HTTPS](/guides/web-cloud/web-hosting/ssl-activate-https-website).
