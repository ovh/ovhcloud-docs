## Objective

Want your website to be accessible via your domain name? To do this, your domain name must point to the IP address of the service your website is located on (web hosting plan, dedicated server, VPS, etc.). You will then need to configure your domain name's active DNS zone using a type A DNS record.

**Find out how to add a DNS A record to an OVHcloud DNS zone for your domain name.**

:::info
To modify or delete an A record of an OVHcloud DNS zone, follow [this guide](/guides/web-cloud/domains/dns-zone-edit).

:::

## Requirements

- A [domain name](/links/web/domains)
- A DNS zone associated with this domain name at OVHcloud

## Instructions

:::warning
Adding, modifying or deleting DNS records in an active DNS zone can cause service interruptions. If in doubt, contact a [specialist provider](/links/partner).

:::

### Add a DNS A record for a domain name

Click <code className="action">Add an entry</code> above the table and select the **A** type. In the **Target** field, enter the IP address (e.g. `203.0.113.0`) of the service your website is hosted on (web hosting plan, dedicated server, VPS, etc.), then click <code className="action">Add</code>.

<img className="thumbnail" alt="Adding a record from the DNS zone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-add-entry.png" loading="lazy" />

It takes up to **24** hours for the change to propagate fully over the DNS network.

### Add a DNS A record for a domain name subdomain

Follow the same steps as above and, in the **Subdomain** field, enter the subdomain (e.g. `www` for `www.domain.tld`) before setting the **Target** to the IP address (e.g. `203.0.113.0`) of the service your website is hosted on. Then click <code className="action">Add</code>.
