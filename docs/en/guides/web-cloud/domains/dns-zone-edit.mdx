## Objective

<iframe className="video" width="560" height="315" src="https://www.youtube-nocookie.com/embed/BvrUi26ShzI" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen={true}></iframe>

**DNS** means **D**omain **N**ame **S**ystem and is a set of elements (DNS servers, DNS zones, etc.) that map a domain name to an IP address.

For further explanation, please refer to our guides "[Everything you need to know about DNS servers](/guides/web-cloud/domains/dns-server-general-information)" and "[Everything you need to know about DNS zone](/guides/web-cloud/domains/dns-zone-general-information)"

**Find out how to edit your OVHcloud DNS zone via the OVHcloud Console.**

## Requirements

- OVHcloud DNS servers in use for the domain name concerned

[[cpnav:web-domain-dns-zone]]

:::warning
- If your domain name does not use OVHcloud DNS servers, you will need to edit the configuration using the interface of your service provider that manages your domain name.

- If your domain name is registered with OVHcloud, you can check if it uses our configuration. If needed, refer to our guide on [Modifying the DNS servers for an OVHcloud domain name](/guides/web-cloud/domains/dns-server-edit).

In both of the above cases, be careful when making your DNS server changes. The old configuration that can be applied to your domain name will no longer be active if you have not previously reconfigured and customised the new DNS zone present at OVHcloud.

You can only have one active DNS zone per domain name at a time.

:::

## Instructions

### Access the area for managing an OVHcloud DNS zone

:::info
Unlike domain names, a DNS zone has no "holder", but is managed at OVHcloud through the contact management. If you wish to assign the management of your DNS zone to another OVHcloud customer account, follow our guide [Managing contacts for your services](/guides/account-and-service-management/account-information/managing-contacts).

:::

Go to the <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> page, choose the domain name concerned, then click the <code className="action">DNS Zone</code> tab. It lists your records in a table, one row per record, showing the **Subdomain**, the record **Type**, its **Target** and its **TTL**. You can search the table with the **Search** field or filter it by record type with the <code className="action">Filters</code> button.

<img className="thumbnail" alt="DNS Zone tab of a domain name and table of records" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />

### Edit your domain name's OVHcloud DNS zone

**Editing a DNS zone is a sensitive procedure**: An inappropriate change could, for example, make your website unavailable, or prevent your email addresses from receiving new emails.

:::tip
Read our guide on [DNS records](/guides/web-cloud/domains/dns-zone-records) to get a better understanding of your DNS changes.

See also our guide to [subdomains](/guides/web-cloud/domains/domain-create-subdomains) for more information on this topic.

:::

From the <code className="action">DNS Zone</code> tab, you can add, modify or delete a record directly in the table of the **Zone records** card. The **DNS zone** card, at the top of the tab, also lets you change the default TTL and, from its <code className="action">More actions</code> menu, edit the zone in text mode, import a zone file, export the zone or reset it. The zone history is displayed in the **My DNS zone history** card, at the bottom of the tab. **Click the headings below to display the details.**

<img className="thumbnail" alt="More actions menu of the DNS zone card" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-actions-menu.png" loading="lazy" />

<details>

<summary>Add a new DNS record</summary>

In the <code className="action">DNS Zone</code> tab, click <code className="action">Add an entry</code> above the table. A form opens between the toolbar and the table:

1. In the **Type** list, select the type of DNS record you want to create (A, AAAA, CNAME, MX, TXT, SPF, DKIM, DMARC, CAA, SRV, TLSA, HTTPS, etc.). Each type shows a short description of its purpose, and an insert explains the chosen record. The <code className="action">Help</code> button details the values expected in the form.
2. Fill in the fields for this record type (**Subdomain**, **Target** and any type-specific field). The **Record preview** shows the line that will be added to your zone.
3. Set the **TTL**: leave the `Default` value or choose `Custom` to enter a value.
4. Click <code className="action">Add</code>.

If you are familiar with DNS zone syntax, the <code className="action">Advanced mode</code> tab of the form lets you enter a record directly in DNS format (for example: `www 3600 IN A 203.0.113.1`).

We recommend first checking that this record does not already exist and does not point to a different target. To do this, use the **Search** field or filter the table by record type with the <code className="action">Filters</code> button. If the record already exists, modify it instead (see below).

> When the target of your record is a domain name or a subdomain (`CNAME`, `MX`, `NS`, `SRV` or `DNAME` types), the form automatically adds the final dot to the target: the **Record preview** shows it (for example: `domain.tld.`).
> In text mode, however, remember to add the final dot to the target. If you do not, your domain name will automatically be added to the end of your target.
> **Example**: for a CNAME record from `test.domain.tld` to `domain.tld`, the target must be `domain.tld.` and not `domain.tld` without the **.** at the end.

<img className="thumbnail" alt="Add an entry form of the DNS zone, type A selected" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry.png" loading="lazy" />

</details>

<details>

<summary>Modify an existing DNS record</summary>

In the table of the <code className="action">DNS Zone</code> tab, on the row of the record concerned, click the <code className="action">⋮</code> button in the **Actions** column, then <code className="action">Modify</code>.

<img className="thumbnail" alt="Actions menu of a DNS zone row" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/row-actions.png" loading="lazy" />

The row expands into an edit form: change the values, then click <code className="action">Modify</code> to confirm.

<img className="thumbnail" alt="Edit form expanded below the row of an A record" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/edit-entry.png" loading="lazy" />

</details>

<details>

<summary>Delete a DNS record</summary>

In the table of the <code className="action">DNS Zone</code> tab, on the row of the record concerned, click the <code className="action">⋮</code> button in the **Actions** column, then <code className="action">Delete</code>. In the **Delete DNS entry** window that opens, confirm by clicking <code className="action">Delete</code>.

To delete several records at once, tick their boxes on the left of the table, then click the <code className="action">Delete X entry(ies)</code> button that appears above the table (X being the number of records ticked), and confirm.

<img className="thumbnail" alt="Deleting a DNS record from the actions menu" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/row-actions.png" loading="lazy" />

</details>

<details>

<summary>Edit the zone in text mode or import a zone file</summary>

:::warning
For informed users only. Be careful with syntax when you make changes.

:::

In the <code className="action">DNS Zone</code> tab, open the <code className="action">More actions</code> menu of the **DNS zone** card and click <code className="action">Modify zone</code>. The **Zone records** card switches to <code className="action">Text view</code>: the current content of your zone is displayed and remains editable; edit it directly. The <code className="action">Use diff mode</code> button shows the differences between the current version and your changes. Then click <code className="action">Save</code>, or <code className="action">Discard changes</code> to return to the saved content.

:::warning
Do not modify the DNS records of your DNS zone in favour of DNS servers external to OVHcloud in text mode. This DNS zone works **only** with OVHcloud DNS servers.

:::

<img className="thumbnail" alt="Zone records card in text view" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/text-mode.png" loading="lazy" />

To replace the content of your zone with that of a zone file, open the <code className="action">More actions</code> menu of the **DNS zone** card, click <code className="action">Import a file</code> and choose your file (accepted files: `.txt`, `.zone`). Its content opens in the **Zone records** card, in <code className="action">Text view</code>, and diff mode shows what it changes compared with your current zone. Nothing is modified until you click <code className="action">Save</code>: saving then replaces the existing records of your zone.

</details>

<details>

<summary>Reset the DNS zone</summary>

By resetting your DNS zone, you can revert back to a minimal configuration, with OVHcloud default records, or your services’ records. You can also point your domain name to custom web hosting and email services.

:::danger
Before you reset your DNS zone, ensure that your domain name is not attached to services that are in use, such as a website or email addresses.

:::

In the <code className="action">DNS Zone</code> tab, open the <code className="action">More actions</code> menu of the **DNS zone** card and click <code className="action">Reset zone</code>.

<img className="thumbnail" alt="More actions menu of the DNS zone card" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-actions-menu.png" loading="lazy" />

In the **Reset DNS zone** panel that opens:

- Choose how to reset your zone: with OVHcloud `Default values`, or with `Custom values` to choose yourself where your domain name points and which server your emails are routed to.
- Choose whether you want to recreate only the **minimal entries** (`NS` and `SOA`). Setting minimal entries in a DNS zone prevents a request to the domain name from ending in an error.
- With custom values, set the target of the **web hosting** IP address (`A` record): the OVHcloud `Redirection`, `OVHcloud Web Hosting` (then choose the hosting plan concerned) or a `Custom` IPv4 address.
- With custom values, set the target of the **email server** (`MX` record): the OVHcloud `Redirection`, the `OVHcloud Email Server` or a `Custom` server and priority.

Then click <code className="action">Reset zone</code>.

<img className="thumbnail" alt="DNS zone reset panel" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/reset-zone.png" loading="lazy" />

</details>

<details>

<summary>View the history of your DNS zone</summary>

Your zone history is displayed in the **My DNS zone history** card, at the bottom of the <code className="action">DNS Zone</code> tab. There you can view, download, compare and restore a previous version of your zone. For more details, read our guide "[Managing a DNS zone's history](/guides/web-cloud/domains/dns-zone-history)".

</details>

### Propagation time

Once you have modified your domain name's DNS zone, you will need to allow a maximum of 24 hours for the changes to propagate fully, and be effective.

If you want to reduce this delay for future edits of your OVHcloud DNS zone, you can adjust the TTL (*Time To Live*) that will apply to all records in the DNS zone. To do this, in the <code className="action">DNS Zone</code> tab, find the **Default TTL** line of the **DNS zone** card (the current value is shown there) and click <code className="action">Edit the default TTL</code>, just below it. In the window that opens, choose one of the **Presets** or enter a `Custom` value in seconds, then click <code className="action">Save</code>.

You can also modify the TTL of an individual record when adding or editing it.
