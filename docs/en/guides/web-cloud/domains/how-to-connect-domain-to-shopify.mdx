## Objective

You are the holder of a domain name with OVHcloud and want to connect it to a Shopify hosting plan. This guide explains how to prepare and configure your OVHcloud DNS zone for your Shopify hosting plan.

**Find out how to connect your OVHcloud domain name to a Shopify hosting plan.**

:::warning
- Shopify support does not have access to your OVHcloud domain name settings and therefore cannot advise you on the information you will need to provide.

- OVHcloud provides services for which you are responsible with regard to their configuration and management. It is therefore up to you to ensure that they function correctly.<br/><br/> We have provided you with this guide in order to help you with common tasks. However, we recommend contacting a [specialist provider](/links/partner) and/or the service's publisher if you encounter any difficulties. We will not be able to assist you ourselves. You can find more information in the [Go further](#go-further) section of this guide.

:::

## Requirements

- A [domain name](/links/web/domains) registered with OVHcloud.
- The [necessary permissions to manage](/guides/account-and-service-management/account-information/managing-contacts) the domain name.
- A Shopify hosting plan.
- Access to manage this hosting plan with Shopify.

## Instructions

Before following the steps in this guide, we recommend reading our guide on [Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit).

:::warning
Your DNS zone is potentially already preconfigured or linked to a hosting plan. We will look at how to identify each DNS record required to connect to your Shopify hosting plan. Some records will need to be deleted to avoid conflicts with DNS records required in this configuration. Others will simply need to be modified or created. For a better understanding, we will use the domain name "**mydomain.ovh**" as an example. Replace it with your domain name during configuration.

:::

### Configure your DNS records on your OVHcloud account

Click the tabs below to view each of the **5** steps in sequence.

<Tabs>
  <Tab label="Step 1">
    In the `Web Cloud` section, click <ManagerLink to="/#/web-domains/domain">Domain names</ManagerLink>, select the domain name concerned, then open the **DNS zone** tab.

    <img className="thumbnail" alt="DNS zone tab listing the records of a domain name" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-zone-overview.png" loading="lazy" />

The table that appears lists all of the DNS records for the selected domain name.
  </Tab>
  <Tab label="Step 2">
    **Configuring the A record**

    **1 - Identification:** Filter the DNS records by selecting type `A` using the filter above the table.

    <img className="thumbnail" alt="DNS zone filtered on A records" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-a.png" loading="lazy" />

Identify any existing "A" records for your domain name alone (e.g. `mydomain.ovh.`) and for the "www" subdomain (e.g. `www.mydomain.ovh.`).

    **2 - Deletion:** Delete all existing "A" records for the "www" subdomain. If multiple "A" records exist for the domain name alone, delete all but one, which you will modify in the next sub-step. For each record to delete, on the corresponding row, open the actions menu <code className="action">⋮</code> and click <code className="action">Delete the entry</code>.

    **3 - Modification:** If an "A" record exists for the domain name alone, open the actions menu <code className="action">⋮</code> on the corresponding row and click <code className="action">Edit the entry</code>. The row expands into an edit form. Leave the **Subdomain** field blank and replace the target with the Shopify IPv4 address: `23.227.38.65`. Confirm your changes.

    If no "A" record exists, click <code className="action">Add an entry</code> above the table, then select the <code className="action">A</code> DNS record type, leave the **Subdomain** field blank and enter `23.227.38.65` in the **Target** field. Click <code className="action">Add</code>.

    Then proceed to step 3.
  </Tab>
  <Tab label="Step 3">
    **Configuring the AAAA record**

    **1 - Identification:** Filter the DNS records by selecting type `AAAA` using the filter above the table.

    <img className="thumbnail" alt="DNS zone filtered on AAAA records" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-aaaa.png" loading="lazy" />

Identify any existing "AAAA" records for your domain name alone (e.g. `mydomain.ovh.`) and for the "www" subdomain (e.g. `www.mydomain.ovh.`).

    **2 - Deletion:** Delete all existing "AAAA" records for the "www" subdomain. If multiple "AAAA" records exist for the domain name alone, delete all but one, which you will modify in the next sub-step. For each record to delete, on the corresponding row, open the actions menu <code className="action">⋮</code> and click <code className="action">Delete the entry</code>.

    **3 - Modification:** If an "AAAA" record exists for the domain name alone, open the actions menu <code className="action">⋮</code> on the corresponding row and click <code className="action">Edit the entry</code>. The row expands into an edit form. Leave the **Subdomain** field blank and replace the target with the Shopify IPv6 address: `2620:0127:f00f:5::`. Confirm your changes.

    If no "AAAA" record exists, click <code className="action">Add an entry</code> above the table, then select the <code className="action">AAAA</code> DNS record type, leave the **Subdomain** field blank and enter `2620:0127:f00f:5::` in the **Target** field. Click <code className="action">Add</code>.

    Then proceed to step 4.
  </Tab>
  <Tab label="Step 4">
    **Deleting TXT records**

    **1 - Identification:** Filter the DNS records by selecting type `TXT` using the filter above the table.

    <img className="thumbnail" alt="DNS zone filtered on TXT records" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-txt.png" loading="lazy" />

Identify any existing "TXT" records for your domain name alone (e.g. `mydomain.ovh.`) and for the "www" subdomain (e.g. `www.mydomain.ovh.`).

    **2 - Deletion:** Delete all "TXT" records identified (domain name alone and "www" subdomain) to avoid conflicts with the new DNS records. For each record, on the corresponding row, open the actions menu <code className="action">⋮</code> and click <code className="action">Delete the entry</code>.

    If no "TXT" records exist, proceed to step 5.
  </Tab>
  <Tab label="Step 5">
    **Configuring the CNAME record**

    **1 - Identification:** Filter the DNS records by selecting type `CNAME` using the filter above the table.

    <img className="thumbnail" alt="DNS zone filtered on CNAME records" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-cname.png" loading="lazy" />

Identify any existing "CNAME" records for the "www" subdomain (e.g. `www.mydomain.ovh.`).

    **2 - Deletion:** If multiple "CNAME" records exist for the "www" subdomain, delete all but one. For each record to delete, on the corresponding row, open the actions menu <code className="action">⋮</code> and click <code className="action">Delete the entry</code>.

    **3 - Modification:** If a "CNAME" record exists for the "www" subdomain, open the actions menu <code className="action">⋮</code> on the corresponding row and click <code className="action">Edit the entry</code>. The row expands into an edit form. Replace only the **Target** with `shops.myshopify.com.`. Confirm your changes.

    If no "CNAME" record exists for the "www" subdomain, click <code className="action">Add an entry</code> above the table, then select the <code className="action">CNAME</code> DNS record type, enter `www` in the **Subdomain** field and `shops.myshopify.com.` in the **Target** field. Click <code className="action">Add</code>.
  </Tab>
</Tabs>

The DNS zone is now configured to point to your Shopify hosting plan.

### Connect your domain name to Shopify

Carry out this step from the Shopify management interface by following step 2 of [**this Shopify guide**](https://help.shopify.com/en/manual/domains/add-a-domain/connecting-domains/connect-domain-manual).

:::info
It may take up to 48 hours to verify your domain name.

:::
