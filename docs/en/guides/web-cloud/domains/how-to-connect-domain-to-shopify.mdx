## Objective

You are the holder of a domain name with OVHcloud and want to connect it to a Shopify hosting plan. This guide explains how to prepare and configure your OVHcloud DNS zone for your Shopify hosting plan.

**Find out how to connect your OVHcloud domain name to a Shopify hosting plan.**

[[fragment:support-scope]]

:::warning
Shopify support does not have access to your OVHcloud domain name settings and therefore cannot advise you on the information you will need to provide.
:::

## Requirements

- A [domain name](/links/web/domains) registered with OVHcloud.
- The [necessary permissions to manage](/guides/account-and-service-management/account-information/managing-contacts) the domain name.
- A Shopify hosting plan.
- Access to manage this hosting plan with Shopify.

[[cpnav:web-domain-dns-zone]]

## Instructions

Before following the steps in this guide, we recommend reading our guide on [Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit).

:::warning
Your DNS zone may already be preconfigured or linked to a hosting plan. We will see how to identify each DNS record needed to connect to your Shopify hosting. Some will need to be deleted to avoid conflicts with the DNS records required in this configuration. Others will simply need to be modified or created. For a better understanding, we will use the domain name "**domain.tld**" as an example. Replace it with your domain name during configuration.

:::

### Configure your DNS records on your OVHcloud account

Click the tabs below to view each of the **5** steps in sequence.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> page, choose the domain name concerned, then click the <code className="action">DNS Zone</code> tab.

    <img className="thumbnail" alt="DNS Zone tab listing a domain name's records" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />

    The table lists the DNS records of the selected domain name.
  </Tab>
  <Tab label="Step 2">
    **Configuring the A record**

    **1 - Identification:** click <code className="action">Filters</code> above the table, then select <code className="action">A</code> in the **Record type** list.

    :::info
    The **Record type** list of the <code className="action">Filters</code> button only offers the record types present in your DNS zone. If a type does not appear in the list, your zone does not contain any record of that type.

    :::

    <img className="thumbnail" alt="DNS zone filtered on A records" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-a.png" loading="lazy" />

    Find the existing "A" records for your domain name alone (subdomain `@`, example: `domain.tld.`) and for the "www" subdomain (example: `www.domain.tld.`).

    **2 - Deletion:** delete all existing "A" records for the "www" subdomain. If several "A" records exist for the domain name alone, delete all but one, which you will modify in the next sub-step. For each record to be deleted, on the row concerned, click the <code className="action">⋮</code> button in the **Actions** column, then <code className="action">Delete</code>, and confirm in the **Delete DNS entry** window.

    **3 - Modification:** if an "A" record exists for the domain name alone, on the row concerned, click the <code className="action">⋮</code> button in the **Actions** column, then <code className="action">Modify</code>. The row expands into an edit form. Leave `@` in the **Subdomain** field and replace the **Target (IPv4)** with the Shopify IPv4 address: `23.227.38.65`. Click <code className="action">Modify</code> to confirm.

    If no "A" record exists, click <code className="action">Create a record</code> above the table, then select `A — Point to an IPv4` in the **Type** list. Enter `@` in the **Subdomain** field, then enter `23.227.38.65` in the **Target (IPv4)** field. Click <code className="action">Add</code>.

    Then proceed to step 3.
  </Tab>
  <Tab label="Step 3">
    **Configuring the AAAA record**

    **1 - Identification:** click <code className="action">Filters</code> above the table, then select <code className="action">AAAA</code> in the **Record type** list. If the list does not offer <code className="action">AAAA</code>, your zone does not contain any record of this type: create one directly as described at the end of sub-step 3.

    <img className="thumbnail" alt="Filters button and Record type list of the DNS zone" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-type.png" loading="lazy" />

    Find the existing "AAAA" records for your domain name alone (example: `domain.tld.`) and for the "www" subdomain (example: `www.domain.tld.`).

    **2 - Deletion:** delete all existing "AAAA" records for the "www" subdomain. If several "AAAA" records exist for the domain name alone, delete all but one, which you will modify in the next sub-step. For each record to be deleted, on the row concerned, click the <code className="action">⋮</code> button in the **Actions** column, then <code className="action">Delete</code>, and confirm in the **Delete DNS entry** window.

    **3 - Modification:** if an "AAAA" record exists for the domain name alone, on the row concerned, click the <code className="action">⋮</code> button in the **Actions** column, then <code className="action">Modify</code>. The row expands into an edit form. Leave `@` in the **Subdomain** field and replace the **Target (IPv6)** with the Shopify IPv6 address: `2620:0127:f00f:5::`. Click <code className="action">Modify</code> to confirm.

    If no "AAAA" record exists, click <code className="action">Create a record</code> above the table, then select `AAAA — Point to an IPv6` in the **Type** list. Enter `@` in the **Subdomain** field, then enter `2620:0127:f00f:5::` in the **Target (IPv6)** field. Click <code className="action">Add</code>.

    Then proceed to step 4.
  </Tab>
  <Tab label="Step 4">
    **Deleting TXT records**

    **1 - Identification:** click <code className="action">Filters</code> above the table, then select <code className="action">TXT</code> in the **Record type** list.

    <img className="thumbnail" alt="DNS zone filtered on TXT records" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-txt.png" loading="lazy" />

    Find the existing "TXT" records for your domain name alone (example: `domain.tld.`) and for the "www" subdomain (example: `www.domain.tld.`).

    **2 - Deletion:** delete all the "TXT" records identified (domain name alone and "www" subdomain) to avoid a conflict with the new DNS records. For each record, on the row concerned, click the <code className="action">⋮</code> button in the **Actions** column, then <code className="action">Delete</code>, and confirm in the **Delete DNS entry** window.

    If no "TXT" records exist, proceed to step 5.
  </Tab>
  <Tab label="Step 5">
    **Configuring the CNAME record**

    **1 - Identification:** click <code className="action">Filters</code> above the table, then select <code className="action">CNAME</code> in the **Record type** list.

    <img className="thumbnail" alt="DNS zone filtered on CNAME records" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-cname.png" loading="lazy" />

    Find the existing "CNAME" records for the "www" subdomain (example: `www.domain.tld.`).

    **2 - Deletion:** if several "CNAME" records exist for the "www" subdomain, delete all but one. For each record to be deleted, on the row concerned, click the <code className="action">⋮</code> button in the **Actions** column, then <code className="action">Delete</code>, and confirm in the **Delete DNS entry** window.

    **3 - Modification:** if a "CNAME" record exists for the "www" subdomain, on the row concerned, click the <code className="action">⋮</code> button in the **Actions** column, then <code className="action">Modify</code>. The row expands into an edit form. Replace only the **Target (hostname)** with `shops.myshopify.com.`: if you omit the final dot, the Console adds it automatically. Click <code className="action">Modify</code> to confirm.

    If no "CNAME" record exists for the "www" subdomain, click <code className="action">Create a record</code> above the table, then select `CNAME — Alias to another domain` in the **Type** list, enter `www` in the **Subdomain** field and `shops.myshopify.com.` in the **Target (hostname)** field. Click <code className="action">Add</code>.
  </Tab>
</Tabs>

The DNS zone is now configured to point to your Shopify hosting plan.

### Connect your domain name to Shopify

Carry out this step from the Shopify management interface by following step 2 of [**this Shopify guide**](https://help.shopify.com/en/manual/domains/add-a-domain/connecting-domains/connect-domain-manual).

:::info
It may take up to 48 hours to verify your domain name.

:::
