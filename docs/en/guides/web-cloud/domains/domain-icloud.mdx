## Objective

This guide explains how to use an OVHcloud-registered domain name with the Apple iCloud Mail service. You can then create custom email addresses (`john.smith@domain.tld`), which are fully managed and hosted by Apple.

## Requirements

- A [domain name](/links/web/domains) registered with OVHcloud.
- An Apple ID with an **iCloud+** subscription.

[[cpnav:web-dns-zones-console]]

## Instructions

### 1 - Activate the domain name in iCloud <a name="step1"></a>

To activate your domain name in iCloud, follow the instructions from the "Add a domain you own to iCloud Mail on iCloud.com" page in [Apple's official documentation](https://support.apple.com/guide/icloud/add-a-domain-you-own-mma473945269/icloud). Focus on the "Step 3: Update the records with your domain registrar" section to find the DNS records to add to your OVHcloud <Tooltip term="dnsZone">DNS zone</Tooltip>.

At the end of this step, Apple provides the DNS records (MX, CNAME, TXT) to configure in your OVHcloud DNS zone. Keep them for the next step.

### 2 - Configure the DNS records in the OVHcloud Console

Click on the tabs below to view each of the **2** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> page, choose the domain name concerned, then click the <code className="action">DNS Zone</code> tab.

    <img className="thumbnail" alt="Domains & DNS page and list of the account's domain names" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    To find out how to add, modify or delete each type of DNS record (MX, CNAME, TXT, etc.), read our guide "[Everything you need to know about DNS records](/guides/web-cloud/domains/dns-zone-records)".

    Using the DNS records retrieved in [step 1](#step1), create or update the corresponding records in your OVHcloud DNS zone:

    - **MX**: for receiving emails.
    - **CNAME**: for <Tooltip term="dkim">DKIM</Tooltip> keys (`sig1._domainkey...`, `sig2._domainkey...`).
    - <Tooltip term="txtRecord">**TXT**</Tooltip>: for <Tooltip term="spf">SPF</Tooltip> (merge if an SPF record already exists: in the DNS zone table, the OVHcloud SPF record appears with the `SPF` type).
    - **TXT DMARC**: optional but recommended ([Part 3](#step3)).

    <img className="thumbnail" alt="DNS Zone tab of a domain name and table of records" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />

    :::warning
    Use only straight quotation marks `"` as they appear in Apple's technical documentation (usually in English). The quotation marks « » or “ ” displayed in some translations should not be used in DNS configuration.

    :::

  </Tab>
</Tabs>

### 3 - Add a DMARC record (optional) <a name="step3"></a>

To improve deliverability and prevent your emails being treated as spam, add a <Tooltip term="dmarc">**DMARC**</Tooltip> record.

To find out how to create a DMARC record in the OVHcloud Console, refer to our guide "[How to improve email security with a DMARC record](/guides/web-cloud/domains/dns-zone-dmarc)".

### 4 - Verify and activate the domain in iCloud

Once the DNS records (MX, CNAME, TXT, DMARC) have been correctly added to your OVHcloud DNS zone, go back to [iCloud.com](https://www.icloud.com).

Follow the instructions from the "Add a domain you own to iCloud Mail on iCloud.com" page in [Apple's official documentation](https://support.apple.com/guide/icloud/add-a-domain-you-own-mma473945269/icloud). Focus on the "Step 4: Finish setting up the domain" section.

Once this step is complete, your custom domain name is fully activated and you can create up to 3 addresses per person within your family.

:::warning
Validation may fail if your DNS records have not yet been propagated. This <Tooltip term="dnsPropagation">propagation</Tooltip> may take several hours.

:::

### Common troubleshooting

#### Check where the DNS zone is managed

If your domain name uses DNS servers external to OVHcloud (Wix, Squarespace, Cloudflare, etc.), configure the records in that provider's interface instead of the OVHcloud Console.

#### CNAME already exists

- A **CNAME** record cannot coexist with an **A, AAAA, or TXT** record configured on the same domain or subdomain.
- Delete the old record before creating the CNAME requested by Apple.

#### Duplicate SPF

<Region zones={['eu']}>

- There can only be **one SPF record** per domain name. If an OVHcloud SPF record already exists (e.g.: `v=spf1 include:mx.ovh.com ~all`), merge it with the one provided by Apple (e.g.:
`v=spf1 include:mx.ovh.com include:icloud.com ~all`).

</Region>
<Region zones={['ca', 'apac']}>

- There can only be **one SPF record** per domain name. If an OVHcloud SPF record already exists (e.g.: `v=spf1 include:mx.ovh.ca ~all`), merge it with the one provided by Apple (e.g.:
`v=spf1 include:mx.ovh.ca include:icloud.com ~all`).

</Region>

#### Incomplete DKIM

- Apple asks you to add several DKIM keys (`sig1`, `sig2`, etc.) to your DNS zone: add all of them.

#### Propagation time

- DNS changes can take several hours (up to 24 hours) to be recognised by Apple.
