## Objective

Want to retrieve a list of all the domain names on your OVHcloud customer account? Do you need to retrieve all information related to your domain names (associated contacts, holder, active options, creation and expiry dates, etc.) in one go?

**Find out how to export a list of your domain names and their associated information in CSV format from the OVHcloud Console.**

## Requirements

- A [domain name](/links/web/domains) registered with OVHcloud

[[cpnav:web-domains-console]]

## Instructions

Click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> page. Above the table, click the <code className="action">Export as CSV</code> button, then <code className="action">Export all</code>.

    <img className="thumbnail" alt="Export as CSV button menu above the list of domain names" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/export-csv/export-csv-menu.png" loading="lazy" />

    :::info
    To export only some domain names, first tick them in the table, then choose <code className="action">Export selection</code> in the same menu.

    :::
  </Tab>
  <Tab label="Step 2">
    In the **Export as CSV** panel that opens, tick the information you want to include in the CSV file for all your domain names, in the **Domain columns** and **Contact columns** sections. The domain name in ASCII format is always included. Standalone DNS zones (without a domain name in your account) are also exported: the **Type** column, ticked by default, distinguishes domain, domain + zone and zone only.

    <img className="thumbnail" alt="Export as CSV panel and choice of columns to export" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/export-csv/export-csv-drawer.png" loading="lazy" />

    Then click the <code className="action">Export</code> button to start generating the file in CSV format.
  </Tab>
  <Tab label="Step 3">
    The progress of the export is displayed in the panel. Wait until the progress bar reaches 100%.

    As soon as the CSV file has been generated, the message "The CSV export has been generated successfully." is displayed and the file download starts automatically.

    <img className="thumbnail" alt="CSV export success message and file download link" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/export-csv/export-csv-success.png" loading="lazy" />

    If the CSV file download did not start automatically, click the <code className="action">Download CSV file</code> link to retrieve it. Finally, click <code className="action">Close</code> to close the panel.
  </Tab>
</Tabs>
