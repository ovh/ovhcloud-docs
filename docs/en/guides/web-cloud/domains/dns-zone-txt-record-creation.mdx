## Objective

Do you need to validate a verification or security process for your domain name (service association via a validation token, verification key, etc.) using your DNS zone? Want to add a custom text value to your domain name's DNS zone?  
To do this, you will need to create a TXT record in your domain name's active DNS zone.

**Find out how to add a DNS TXT record to an OVHcloud DNS zone for your domain name.**

:::info
To modify or delete a TXT record of an OVHcloud DNS zone, follow [this guide](/guides/web-cloud/domains/dns-zone-edit).

:::

## Requirements

- A [domain name](/links/web/domains)
- A DNS zone associated with this domain name at OVHcloud

[[cpnav:web-domain-dns-zone-console]]

## Instructions

:::warning
Adding, modifying or deleting DNS records in an active DNS zone can cause service interruptions. If in doubt, contact a [specialist provider](/links/partner).

:::

### Add a DNS TXT record for a domain name

Click the tabs below to view each of the **5** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> page, then choose the domain name concerned.

    <img className="thumbnail" alt="Domains & DNS page and list of the account's domain names" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click the <code className="action">DNS Zone</code> tab, then, above the table, <code className="action">Create a record</code>.

    <img className="thumbnail" alt="DNS Zone tab of a domain name and Create a record button" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the form that opens above the table, open the **Type** list and select `TXT — Free text (verification, SPF...)` in the **Text fields** section.

    <img className="thumbnail" alt="Type list of the record creation form, Text fields section and TXT type" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-txt.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    In the **Subdomain** field, enter `@`: this symbol refers to the domain name itself. In the **Value** field, enter the TXT string to add (for example: `AbCdE-Value-of-TXT-fGhIjK`).

    <img className="thumbnail" alt="Record creation form of the DNS zone, TXT record for the domain name" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-txt-record.png" loading="lazy" />
  </Tab>
  <Tab label="Step 5">
    Check the **Record preview**, then click <code className="action">Add</code>.
  </Tab>
</Tabs>

It takes up to **24** hours for the change to propagate fully over the DNS network.

### Add a DNS TXT record for a domain name subdomain

Click the tabs below to view each of the **5** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> page, then choose the domain name concerned.

    <img className="thumbnail" alt="Domains & DNS page and list of the account's domain names" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click the <code className="action">DNS Zone</code> tab, then, above the table, <code className="action">Create a record</code>.

    <img className="thumbnail" alt="DNS Zone tab of a domain name and Create a record button" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the form that opens above the table, open the **Type** list and select `TXT — Free text (verification, SPF...)` in the **Text fields** section.

    <img className="thumbnail" alt="Type list of the record creation form, Text fields section and TXT type" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-txt.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    In the **Subdomain** field, enter the subdomain concerned (for example: `www` for `www.domain.tld`). In the **Value** field, enter the TXT string to add (for example: `AbCdE-Value-of-TXT-fGhIjK`).

    <img className="thumbnail" alt="Record creation form of the DNS zone, TXT record for the www subdomain" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-txt-record-www.png" loading="lazy" />
  </Tab>
  <Tab label="Step 5">
    Check the **Record preview**, then click <code className="action">Add</code>. Allow up to **24** hours for the addition to fully propagate across the DNS network.
  </Tab>
</Tabs>
