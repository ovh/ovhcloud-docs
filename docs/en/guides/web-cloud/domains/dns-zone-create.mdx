## Objective

The **DNS** (**D**omain **N**ame **S**ystem) zone is a domain name's configuration file. It consists of DNS **records** that map the domain name to various services and functions.

For more information, please refer to our guides:

- [Everything you need to know about DNS servers](/guides/web-cloud/domains/dns-server-general-information)
- [Everything you need to know about DNS zone](/guides/web-cloud/domains/dns-zone-general-information)
- [Everything you need to know about DNS records](/guides/web-cloud/domains/dns-zone-records)

For a number of reasons, you may need to create a DNS zone for your domain name at OVHcloud.

**This guide explains how to create an OVHcloud DNS zone for your domain name via the OVHcloud Console.**

## Requirements

- You have administrative access to manage your domain name.
- The domain name concerned does not already have an active or inactive DNS zone with OVHcloud, nor is it the subject of an operation or order in progress with OVHcloud.

[[cpnav:web-dns-zone-order-console]]

## Instructions

:::warning
You can create multiple DNS zones (from different DNS/hosting providers) for the same domain name. However, you can only have one active DNS zone for your domain name. This restriction is designed to avoid *DNS conflicts*.

You can activate/deactivate a DNS zone by declaring the **DNS servers** of your domain name. You can change this declaration and change the **DNS servers** of a domain name at: 

- The *registrar* registered your domain name.
- The service provider that manages it, if you use a specialised service provider to manage your domain name.

By modifying the **DNS servers** of a domain name, you disable the configuration of the old DNS zone applied in favour of the configuration of the new DNS zone (present on the new **DNS servers** declared).

Therefore, please check that the configuration of the new DNS zone meets your expectations before changing the **DNS servers** registered with your domain name.

:::

### 1 - Create the DNS zone via the OVHcloud Console

Click the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> page, then click the <code className="action">Order a domain or DNS zone</code> button. In the **Standalone DNS zone** tile, click <code className="action">Order</code>.

    <img className="thumbnail" alt="Order page for a domain name or DNS zone and Standalone DNS zone tile" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-choice.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    On the **Order a DNS zone** page that appears, enter in the **Domain name** field the domain name (for example: *domain.tld*) for which you want to create an OVHcloud DNS zone. Wait a few moments while the tool checks the domain name.

    If a message indicates that the DNS zone cannot be created (for example, "A DNS zone already exists for domain.tld."), check that the domain name meets the necessary requirements or contact the person who manages it. Once everything is correct, try again.

    <img className="thumbnail" alt="Message stating that a DNS zone already exists for the name entered" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-exists.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Once the check is complete, the **Choose your options** section appears. Tick the **DNS Anycast** option (paid) if needed. The summary, on the right of the page, shows the content and total of your order.

    <img className="thumbnail" alt="Options for ordering a DNS zone and order summary" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-domain.png" loading="lazy" />

    Click <code className="action">Continue order</code>, then follow the steps displayed until the DNS zone is created.

    :::info
    Minimum records are no longer chosen when ordering. If you want to customise the DNS zone yourself starting from the minimum records only (NS and SOA records), reset it once it has been created: in the <code className="action">DNS Zone</code> tab, open the <code className="action">More actions</code> menu of the **DNS zone** card, click <code className="action">Reset zone</code> and choose <code className="action">Yes — minimal entries only</code>. Read our guide "[Editing an OVHcloud DNS zone](/guides/web-cloud/domains/dns-zone-edit)".

    :::
  </Tab>
</Tabs>

### 2 - Edit the DNS zone (optional)

Now that your domain name's DNS zone has been created, you can edit it. This step is optional, but it may be necessary if you want to ensure that the services associated with your domain name remain available (e.g. your website and/or emails).

To edit this DNS zone, please read our guide on [Editing a DNS zone at OVHcloud](/guides/web-cloud/domains/dns-zone-edit).

:::info
If you have just created the DNS zone and the domain name does not yet appear in your list of services, wait 15 to 20 minutes, then reload the page.

:::

### 3 - Modify the domain name's DNS servers

Once the OVHcloud DNS zone is ready to be used, activate it by declaring the corresponding DNS servers. First, retrieve the names of the OVHcloud **DNS servers** on which your domain name's DNS zone was created.

To find them, click the tabs below to view each of the **2** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/domains/listing">Domains & DNS</ManagerLink> page, then choose the domain name concerned. Then click the <code className="action">DNS Zone</code> tab.

    <img className="thumbnail" alt="Domains & DNS page and list of the account's domain names" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    In the table that appears, find the **Type** and **Target** columns. To display only the relevant records, click <code className="action">Filters</code>, then select <code className="action">NS</code> in the **Record type** list.

    <img className="thumbnail" alt="DNS zone filtered on NS records" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-ns.png" loading="lazy" />

    Note the 2 values in the **Target** column. The DNS server names must have one of the following 3 forms:

    - `nsXX.ovh.net` and `dnsXX.ovh.net` or, `nsXXX.ovh.net` and `dnsXXX.ovh.net` (where each `X` represents a number between **0** and **9**).
    - `nsXX.ovh.ca` and `dnsXX.ovh.ca` or, `nsXXX.ovh.ca` and `dnsXXX.ovh.ca` (where each `X` represents a number between **0** and **9**).
    - `ns200.anycast.me` and `dns200.anycast.me` (if you have subscribed to the [DNS anycast](/links/web/domains-options) option).
  </Tab>
</Tabs>

Once the two DNS server names have been retrieved, two situations are possible.

:::info
As a reminder, please check that the configuration of the new DNS zone meets your expectations before changing the **DNS servers** registered with your domain name.

:::

**Click on one of the two situations to display the content.**

<details>

<summary>The domain name has its active DNS zone with OVHcloud</summary>

Refer to [this guide](/guides/web-cloud/domains/dns-server-edit) to verify or modify the DNS servers registered for your domain name.

</details>

<details>

<summary>The domain name has its active DNS zone with another provider</summary>

In this specific case, contact your DNS provider and specify that you want to replace the NS-type DNS records for your domain name.

Here is an example of a request to send to your DNS provider:

<pre className="bgwhite"><code>
Hello,

For my domain name <b>domain.tld</b>, I would like to replace the current DNS servers with the following DNS servers:

 - nsXX.ovh.net.
 - dnsXX.ovh.net.

Kind regards,
</code></pre>

In the example above, replace the values **domain.tld**, **nsXX.ovh.net** and **dnsXX.ovh.net** with your own values.

</details>

After modifying the domain name's DNS servers, the propagation of changes may take up to **48 hours**.

:::tip
If you would like to customise the names of the DNS servers associated with your domain name's active DNS zone, please read our guide "[Customising a domain name's DNS servers (Glue Records)](/guides/web-cloud/domains/glue-registry)".

:::
