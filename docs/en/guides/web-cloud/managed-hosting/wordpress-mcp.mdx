## Objective

You can manage your **Managed Hosting for WordPress** solution in natural language from an AI agent (Claude Code, Codex, etc.), using the **MCP** protocol (*Model Context Protocol*). You connect only one server yourself, the **OVHcloud MCP**. Your AI agent then uses it to configure the other two: **MCP for WordPress**, for the content of a website, and **MainWP**, to manage several websites at once.

**Find out how to connect your AI agent to the OVHcloud MCP, then how to have it configure MCP for WordPress and MainWP.**

## Requirements

- An active [Managed Hosting for WordPress](/guides/web-cloud/managed-hosting/wordpress) solution with at least one WordPress website.
- An OVHcloud account with access to this solution.
- An MCP-compatible AI agent **installed on your computer** that can run commands, for example [Claude Code](https://code.claude.com/docs/en/overview) or [Codex](https://learn.chatgpt.com/docs/codex/cli).
- For MainWP: [Node.js](https://nodejs.org/en) (LTS version) installed on your computer.

:::info
An AI assistant used in a web browser can connect to the OVHcloud MCP, but not to MCP for WordPress or MainWP: these two connections are saved in the agent's configuration, on your computer.
:::

## Introduction

Three MCP servers each cover part of your solution:

| MCP server | What your AI agent can manage | How to connect it |
|---|---|---|
| **OVHcloud MCP** | The hosting: solutions, websites, domains, PHP versions, CDN cache, logs, backups, SFTP passwords, phpMyAdmin and database | You add it once, then log in with your OVHcloud account |
| **MCP for WordPress** | A WordPress website: posts, pages, media, comments, menus, settings, plugins, themes and users | Your AI agent configures it, one connection per website |
| **MainWP** | Several websites at once from the MainWP dashboard included in your solution: updates, activation and deactivation of plugins, themes and translations | Your AI agent configures it, one connection for the whole solution |

**MCP for WordPress** is an OVHcloud plugin preinstalled on the websites of your solution. It gives your AI agent a closed list of actions to manage your WordPress website.

## Instructions

:::warning
Your AI agent acts with the rights you grant it: your OVHcloud account for the OVHcloud MCP, an administrator account for MCP for WordPress. Review every action it proposes before you approve it, especially a deletion, an update or a publication.
:::

### Step 1: Connect the OVHcloud MCP

The OVHcloud MCP is a remote server hosted by OVHcloud. You do not give it any password: your AI agent opens the OVHcloud login page in your web browser, and you log in as you would to your Control Panel.

Choose your AI agent in the tabs below.

<Tabs>
  <Tab label="Claude Code">
    In a terminal, run:

    ```bash
    claude mcp add --transport http --scope user ovhcloud https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    ```

    Start Claude Code, type `/mcp`, select the **ovhcloud** server, then **Authenticate**. Log in with your OVHcloud account on the page that opens.

    :::warning
    Do not add a `--header` option to this command. A fixed `Authorization` header prevents the OVHcloud login: the server is shown as connected, but every request then fails with a 401 error.
    :::
  </Tab>
  <Tab label="Codex">
    In a terminal, run:

    ```bash
    codex mcp add ovhcloud --url https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    codex mcp login ovhcloud
    ```

    Log in with your OVHcloud account on the page that opens, then restart Codex.

    {/* DRAFT: To verify — Codex commands (add --url + mcp login) not tested against the OVHcloud hub */}
  </Tab>
  <Tab label="Other AI agent">
    Add a remote MCP server (*streamable HTTP* transport) to your AI agent's configuration:

    - **URL**: `https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS`
    - **Authentication**: OAuth, with no header or token to enter.

    Start the authentication from your AI agent and log in with your OVHcloud account.
  </Tab>
</Tabs>

To check the connection, ask your AI agent:

> List my Managed Hosting for WordPress solutions and their websites.

It replies with your solutions and the addresses of your websites.

### Step 2: Have MCP for WordPress configured for a website

Ask your AI agent, giving the address of your website:

> Configure MCP for WordPress for my website www.example.com

If you do not specify a website, it offers you the list of the websites in your solution.

The configuration then runs as follows:

1. **Your AI agent asks for your permission** to create an application password on the website. This password lets it act on the website as an administrator, within the limits of the MCP for WordPress actions. To accept, reply explicitly:

    > Yes, create the application password

    Repeating your initial request does not count as consent: your AI agent waits for this reply before going any further.

2. **Your AI agent checks that the MCP for WordPress plugin is active** on the website. If it is not, it tells you: activate **MCP for WordPress** from the <code className="action">Plugins</code> menu of your website's WordPress administration, then repeat your request.
3. **Your AI agent creates the application password** through the OVHcloud MCP, then adds the website connection to its configuration. Approve the command it runs.
4. **Reload the MCP servers**: in Claude Code, type `/mcp` then reconnect, or restart Claude Code; in Codex, restart it. The website's tools only appear after this reload.

To check the connection, ask:

> List the last 5 posts of www.example.com

Repeat this step for each website you want to manage: each website has its own connection.

### Step 3: Have MainWP configured

The MainWP dashboard included in your solution manages all your websites. Ask your AI agent:

> Configure the MainWP MCP

The configuration follows the same process as in step 2:

1. **Your AI agent asks for your permission** to create an application password on the MainWP dashboard. To accept, reply:

    > Yes, create the application password

2. **Your AI agent checks that Node.js is installed** on your computer. If it is not, install the LTS version from [nodejs.org](https://nodejs.org/en), then repeat your request.
3. **Your AI agent creates the application password** through the OVHcloud MCP, then adds the MainWP server to its configuration. Approve the command it runs.
4. **Reload the MCP servers** as in step 2.

To check the connection, ask:

> List the websites in my MainWP dashboard and the plugins that need updating.

:::info
The MainWP server is configured to ask you for confirmation before any action that modifies your websites.
:::

### Example requests

Once the three servers are connected, phrase your requests as you would to a colleague. Your AI agent picks the right server.

| You want to… | Example request |
|---|---|
| Write content | "Write a draft post about our summer opening hours for www.example.com." |
| Moderate comments | "Show the comments awaiting moderation on www.example.com." |
| Update several websites | "Which plugins need updating across all my websites?" |
| Diagnose an error | "My website www.example.com returns 500 errors: check the logs and tell me why." |
| Clear the cache | "Clear the CDN cache of www.example.com." |
| Back up a website | "Export a full backup of www.example.com." |

Before publishing a post, your AI agent asks you which WordPress account is its author.

### Revoking access

You can withdraw the access granted to your AI agent at any time:

- **MCP for WordPress**: in the website's WordPress administration, open <code className="action">Users</code> > <code className="action">Profile</code>, then delete the application password in the **Application Passwords** section.
- **MainWP**: proceed in the same way in the WordPress administration of the MainWP dashboard.
- **OVHcloud MCP**: remove the server from your AI agent's configuration, for example with `claude mcp remove ovhcloud` in Claude Code.

### Troubleshooting

- **Your AI agent says it cannot connect to the website or to MainWP**: check that it runs on your computer and not in a web browser.
- **The new tools do not appear**: reload the MCP servers (`/mcp` in Claude Code) or restart your AI agent.
- **Your AI agent stops and reports a denied action**: it blocked the creation of the password or the execution of the command. Allow this action in its permission settings, or name it explicitly in your request, for example "Create an application password on the website www.example.com".
- **Requests to the OVHcloud MCP fail with a 401 error**: remove the server, add it again without a header, then restart the authentication.
