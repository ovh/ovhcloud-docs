## Objective

**Managed Hosting for WordPress** is OVHcloud's managed WordPress hosting solution: technical maintenance (updates, security, backups) is handled automatically. The offer lets you manage domain names from the OVHcloud interface, without manual intervention. You can associate a domain name or subdomain with each of your WordPress websites, regardless of its origin.

Two flows are available depending on your situation:

- **Internal domain name**: the domain name is already in your OVHcloud account.
- **External domain name**: the domain name is managed by another registrar.

**Find out how to add, modify or remove domain names from your Managed Hosting WordPress from the OVHcloud Console.**

## Requirements

- An active **Managed Hosting for WordPress** offer with at least one WordPress website created.
- For an external domain name: have access to the active DNS (Domain Name System) zone at your current provider.

## Instructions

### 1 - Accessing the domain name management

Adding a domain name is done from the <code className="action">My sites</code> tab of your Managed Hosting for WordPress resource. Click the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/wordpress">Managed WordPress</ManagerLink> page in the OVHcloud Console. Your resources are displayed there as cards.

    <img className="thumbnail" alt="Managed WordPress page of the OVHcloud Console listing the resources as cards" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/managed-hosting-for-wordpress.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    In the card of the resource concerned, click the <code className="action">⋮</code> button to the right of **More actions**, then <code className="action">Manage</code>. If the resource has the status **To renew** or **Terminated**, click the <code className="action">Manage</code> link displayed at the bottom of its card directly.

    <img className="thumbnail" alt="Card of a Managed WordPress resource with the ⋮ button menu open on the Manage entry" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/manage-ressource-button.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Click the <code className="action">My sites</code> tab. The table lists your WordPress websites: the **Site name** column displays the primary domain name of each site (or its technical URL if no domain name is associated with it), the **Associated domains** column shows the number of domain names associated with the site and the **Actions** column gives access to the available actions.

    <img className="thumbnail" alt="My sites tab showing the table of WordPress websites" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/managed-hosting-for-wordpress-my-sites-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    In the **Actions** column, click the <code className="action">⋮</code> button to the right of the WordPress website concerned, then <code className="action">Add a domain name</code>. A panel titled **Add a domain name** opens on the right.

    <img className="thumbnail" alt="Menu of the ⋮ button of a WordPress website in the My sites tab, with the Add a domain name entry" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/adding-domain.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
The **first domain name added** to a WordPress website automatically becomes the **primary domain name**. You can add more later (multi-domain) and change the primary domain name from the <code className="action">Manage my domains</code> entry of the same menu.
:::

### 2 - Adding a domain name

**Click one of the situations below to view the content.**

<details>

<summary>Add an internal domain name</summary>

An **internal** domain name is a domain name already in your OVHcloud account (registered or transferred).

Once the **Add a domain name** panel is open, choose the internal association to use a domain name already in your OVHcloud account. All the steps take place in this same panel, with no intermediate summary. Click the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    In the **Domain configuration** section of the panel, select <code className="action">Attach an existing OVHcloud domain</code> (the default choice).

    <img className="thumbnail" alt="Add a domain name panel with the Attach an existing OVHcloud domain choice selected" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/attach-ovhcloud-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    In the **Domain name** drop-down menu, select the desired domain name from the domain names available in your OVHcloud account.

    To associate a subdomain, then tick the <code className="action">Create a subdomain</code> box and enter the subdomain prefix (for example: `blog` for `blog.domain.tld`) in the field that appears.

    <img className="thumbnail" alt="Domain name drop-down menu open on the OVHcloud domain names available in the account" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/select-ovh-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Click the <code className="action">Add a domain name</code> button at the bottom of the panel. This button remains inactive as long as the selected domain name is already associated with the site. A message then confirms that your request has been taken into account. The DNS configuration is handled automatically.
  </Tab>
</Tabs>

:::info
For an internal domain name, DNS propagation is automatic. Your site will be accessible via this domain name within a few minutes to a few hours.
:::

</details>

<details>

<summary>Add an external domain name</summary>

An **external** domain name is managed by another registrar (Gandi, Namecheap, Google Domains, etc.). You must modify your DNS zone manually.

Once the **Add a domain name** panel is open, choose the external association to use a domain name managed by another registrar. The domain name is entered and validated in this same panel; the DNS configuration procedure is then sent to you by email. Click the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    In the **Domain configuration** section of the panel, select <code className="action">Attach an external domain</code>. The **Domain name** drop-down menu is then replaced by an input field.

    <img className="thumbnail" alt="Add a domain name panel with the Attach an external domain choice selected" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/attach-external-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Enter your domain name (for example: `domain.tld`) in the **Domain name** field, then click the <code className="action">Add a domain name</code> button at the bottom of the panel.

    <img className="thumbnail" alt="Domain name field filled in with a sample external domain name and active Add a domain name button" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/associate-external-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    A message confirms that your request has been taken into account and informs you that an email containing the procedure to follow has been sent to you. The OVHcloud Console does not display the DNS records to create and offers no confirmation step: everything continues from this email.

    Follow the procedure you received to configure, from the DNS interface of your current provider, the required DNS records (typically a DNS record of type **A** or **CNAME**: **C**anonical **NAME**).
  </Tab>
</Tabs>

:::warning
DNS propagation of an external domain name can take up to **24 to 48 hours** depending on your provider. Your WordPress website will not be accessible via this domain name during this period.
:::

:::info
The SSL (Secure Sockets Layer) certificate is generated automatically after DNS propagation has been validated. No manual intervention is needed on your side.
:::

</details>

:::

    Click <code className="action">Delete</code> to confirm the deletion.
  </Tab>
</Tabs>

**Effects of deletion:**

- **Your WordPress website remains intact**: only the link with the domain name is broken, the site continues to work.
- **The permanent technical URL remains accessible**: your WordPress website is still reachable via this URL, even without a domain name.
- **The SSL certificate is revoked**: it no longer covers the deleted domain name.
- **SEO ranking may be impacted**: if the domain name was indexed by search engines, removing it affects positioning.
- **Remember to check your email services**: addresses linked to this domain name may be affected by the deletion.

:::info
**Special case — single primary domain name:** if you delete the only primary domain name of a WordPress website, your WordPress website automatically falls back to its **permanent technical URL**. This URL is always accessible and is never deleted, even when no domain is associated.
:::

</details>

### The permanent technical URL

Each Managed Hosting for WordPress site has a **permanent technical URL**, independent of any domain name. This URL is generated automatically when the WordPress website is created and cannot be deleted.

<img className="thumbnail" alt="Manage my domains panel displaying the primary domain name and the technical URL of a WordPress website" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/console/show-domain-linked-to-a-site.png" loading="lazy" />

It lets you:

- Access your WordPress website **in all circumstances**, even without an associated domain name.
- Test your WordPress website before pointing a domain name to it.
- Maintain a fallback access in case of a DNS issue.

:::info
The technical URL is of the form `*.mcms.ovh.net` or similar. Find it in the <code className="action">My sites</code> tab: click the <code className="action">⋮</code> button in the **Actions** column, to the right of the WordPress website concerned, then <code className="action">Manage my domains</code>. The panel that opens displays it next to the site's domain names. A site with no associated domain name is displayed directly under its technical URL in the **Site name** column.
:::
