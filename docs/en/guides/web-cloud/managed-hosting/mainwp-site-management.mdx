## Objective

**MainWP** is a self-hosted, open-source dashboard included with your **Managed Hosting for WordPress** offer. It lets you manage all your WordPress websites from a centralised interface, without going through each individual site's administration.

:::info
MainWP is a third-party tool, independent of OVHcloud. OVHcloud hosts and provides access to the MainWP interface, but does not handle functional support for the tool. For advanced questions about MainWP features, refer to the [official MainWP documentation](https://docs.mainwp.com/).
:::

**Find out how to manage your WordPress websites with MainWP.**

## Requirements

- An active **Managed Hosting for WordPress** offer with at least one WordPress website created.

### 2. Understanding the MainWP interface

The MainWP interface is organised around 2 main concepts:

- **Dashboard**: central view listing all your connected sites with their status.
- **Child Sites**: each of your WordPress websites managed via MainWP.

{/* DRAFT: To screenshot — capture the MainWP dashboard with the list of connected sites, status indicators (available updates, connection status) and the side menu */}

The dashboard groups 3 main areas:

- **Sites list**: displays all your WordPress websites with their status (online/offline, available updates).
- **Status indicators**: number of pending updates (WordPress core, plugins, themes).
- **Side menu**: navigation to the Sites, Updates, Plugins, Security sections, etc.

### 3. Managing your WordPress websites — individual actions

#### 3.1 Accessing the administration of a WordPress website

{/* DRAFT: To screenshot — capture the list of sites in MainWP with the "WP Admin" button or equivalent allowing access to a specific site's administration */}

- **Locate the WordPress website**: in the list of WordPress websites on the MainWP dashboard, find the WordPress website you want to administer.
- **Open the administration**: click <code className="action">WP Admin</code> next to the WordPress website to go directly to its WordPress dashboard.

#### 3.2 Updating a WordPress website individually

{/* DRAFT: To screenshot — capture the detail view of a site in MainWP with available updates listed (WordPress core, plugins, themes) and the update button */}

- **Open the WordPress website details**: click the name of the WordPress website in the list.
- **Review available updates**: the detail screen displays pending updates (WordPress core, plugins, themes).
- **Update**: click <code className="action">Update</code> next to each item, or <code className="action">Update All</code> to apply all updates at once.

:::warning
Back up or snapshot your WordPress website before any major update. Some plugin updates may cause incompatibilities. Refer to the "[Back up your WordPress websites with MainWP](/guides/web-cloud/web-hosting/mainwp-backup)" guide to create a restore point.
:::

### 4. Bulk actions

Bulk actions apply an operation to several WordPress websites at once, without having to repeat it for each one.

{/* DRAFT: To screenshot — capture the multi-selection interface in MainWP (checkboxes in front of each site) and the drop-down menu of available bulk actions */}

#### 4.1 Selecting several WordPress websites

- **Display the list of WordPress websites**: from the MainWP dashboard, go to the <code className="action">Sites</code> section.
- **Select the target WordPress websites**: tick the boxes next to each WordPress website to include in the bulk action. Use <code className="action">Select All</code> to include all your WordPress websites.

#### 4.2 Updating several WordPress websites at once

{/* DRAFT: To screenshot — capture the bulk update screen with the site selection and the "Apply updates" button or equivalent */}

- **Select the WordPress websites**: tick the WordPress websites to update (see §4.1).
- **Launch the bulk update**: click <code className="action">Updates</code> in the bulk actions menu.
- **Choose the components to update**: select the items concerned (WordPress core, plugins, themes).
- **Apply**: click <code className="action">Update</code>. MainWP applies the updates sequentially on each selected WordPress website.

:::info
Updates are applied in the order of the list, which may take a few minutes depending on the number of WordPress websites.
:::

#### 4.3 Installing or activating a plugin on several WordPress websites

{/* DRAFT: To screenshot — capture the "Extensions" or "Plugins" section of MainWP with the bulk install/activate option and the site selector */}

- **Access plugin management**: in the MainWP menu, click <code className="action">Plugins</code>.
- **Select the plugin**: find the plugin to install or activate in the list.
- **Choose the target sites**: select the WordPress websites to apply the action to.
- **Apply**: click <code className="action">Install</code> or <code className="action">Activate</code> as required.

#### 4.4 Other bulk actions available

- **Deactivate a plugin** on all selected WordPress websites.
- **Delete a plugin** from selected WordPress websites.
- **Install a theme** on several WordPress websites at once.
- **Activate a theme** on selected WordPress websites.
- **Publish content** (post or page) on several WordPress websites.

:::info
Some advanced actions (customer reports, advanced security monitoring, automated backups) require **MainWP extensions** (premium). Refer to the [list of MainWP extensions](https://docs.mainwp.com/).
:::

### 5. How to monitor the status of your WordPress websites?

{/* DRAFT: To screenshot — capture the MainWP dashboard with status indicators: online/offline sites, number of pending updates per category, possible security alerts */}

MainWP displays the health status of your WordPress websites in real time:

- **WordPress website online (green)**: the WordPress website responds correctly.
- **WordPress website offline (red)**: the WordPress website is unreachable, or the MainWP connection is lost.
- **Available updates**: number of pending updates (core / plugins / themes).
- **Detected vulnerabilities**: plugin or theme with a known security flaw.

:::warning
If a WordPress website appears "offline" in MainWP, the WordPress website is not necessarily unreachable for your visitors. It may indicate a connection problem between MainWP and the child WordPress website (Child Site plugin disabled, password change, etc.).
:::
