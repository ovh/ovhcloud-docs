## Objective

A database (DB) is used to store what are known as dynamic elements, such as comments or articles. These databases are used in virtually all modern content management systems (CMS), such as WordPress or Joomla!.

**This guide explains how to create a database on your database server and give access to users.**

## Requirements

- A [Web Cloud Databases instance](/links/web/databases) (included in a [Web Hosting](/links/web/hosting) Performance, Agency, Agency Plus or Agency Max plan).

[[cpnav:web-cloud-databases]]

## Instructions

### Creating a database

Click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> page, then select the instance concerned.

    <img className="thumbnail" alt="Web Cloud DB page and list of the account's instances" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">Databases</code> tab.

    <img className="thumbnail" alt="Databases tab of a Web Cloud DB instance" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Click <code className="action">Add a database</code>, above the databases table.

    <img className="thumbnail" alt="Add a database button above the databases table" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    PostgreSQL schema creation is currently unavailable on Web Cloud Databases servers.

    :::

  </Tab>
  <Tab label="Step 4">
    The **Add a database** panel opens on the right. Fill in the fields following the criteria shown under each of them:

    - **Database name** (required): this will be the name of your future database.
    - **Access to this database**: choose who will be able to log in to the database and perform queries.
        - **No access for now** (default choice): the database is created without a user. You can grant rights to a user afterwards.
        - **An existing user**: select the **User**, then their **Rights** on the database.
        - **A new user**: fill in the fields below to create the user at the same time as the database.
    - **Username** (only with **A new user**): the user who will be able to log in to your database and perform queries.
    - **Rights** (with **An existing user** or **A new user**): the rights associated with the user on the database. For standard usage, select `Admin`. The rights can be modified afterwards.
    - **Password**/**Confirm password** (only with **A new user**): enter a password, then confirm it.

    Click <code className="action">Add</code>.

    <img className="thumbnail" alt="Add a database panel with a new user" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

### Managing user rights

To allow a user to perform actions on a database, it is necessary to assign permissions to the user.

Click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> page, then select the instance concerned.

    <img className="thumbnail" alt="Web Cloud DB page and list of the account's instances" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">Users & grants</code> tab.

    <img className="thumbnail" alt="Users & grants tab of a Web Cloud DB instance" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Each user is shown in a card bearing their name. In the card of the user concerned, click the <code className="action">⋮</code> button to the right of the **More actions** label, then click <code className="action">Manage grants</code>.

    <img className="thumbnail" alt="More actions menu of a user and Manage grants entry" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    The panel titled **Grants for** followed by the user's name opens on the right. It lists the databases on your server, each with a drop-down menu to its right showing the user's level of rights on that database. Choose the level you want for each database. The change applies immediately: the message **Grant updated** is displayed.

    4 levels of rights are available:

    - `Admin`: authorisation for **Select / Insert / Update / Delete / Create / Alter / Drop** queries.
    - `Read / Write`: authorisation for **Select / Insert / Update / Delete** queries.
    - `Read only`: authorisation for **Select** queries.
    - `None`: no database rights.

    :::info
    The distribution of rights mentioned above is specific to OVHcloud. A user with `Admin` rights can use **DDL** (Data Definition Language) and **DML** (Data Manipulation Language), while a user with `Read / Write` rights can only use **DML** (Data Manipulation Language).

    :::

    <img className="thumbnail" alt="Rights panel of a user, one level per database" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />
  </Tab>
</Tabs>

### Deleting a database

:::warning
When deleting a database on a database server, there is no
verification of the database contents. It will be deleted even if
data is still stored in it. It is therefore recommended to create
a backup and download it locally before any deletion.

:::

Click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> page, then select the instance concerned.

    <img className="thumbnail" alt="Web Cloud DB page and list of the account's instances" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Click on the <code className="action">Databases</code> tab.

    <img className="thumbnail" alt="Databases tab of a Web Cloud DB instance" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    In the table, click the <code className="action">⋮</code> button in the **Actions** column, to the right of the database concerned, then click <code className="action">Delete</code>.

    <img className="thumbnail" alt="Menu of a row in the Web Cloud DB databases table" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    In the **Delete database** window that opens, confirm the deletion by clicking <code className="action">Delete</code>.

    <img className="thumbnail" alt="Confirmation window for deleting a database" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/delete-database-dialog.png" loading="lazy" />
  </Tab>
</Tabs>
