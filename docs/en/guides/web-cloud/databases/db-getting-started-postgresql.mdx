Do you want to use PostgreSQL? Learn how to easily manage your databases!

## Overview

### Prerequisites

- A Web Cloud Databases instance
- To have viewed [the Web Cloud Databases guide](/guides/web-cloud/databases/db-getting-started)

### What is a PostgreSQL database?
PostgreSQL is an object-relational database management system (ORDBMS). It's a reliable and extensible system, which can manipulate large volumes of data. It also has a very active community.

## Logging in to the database

:::info
Please note that this service does not give you access to the Host but to the databases hosted on it. Generic SQL commands work with no issues, and software such as HeidiSQL or SQuirreL SQL is fully compatible.

:::

To log in to your database, make sure that you have:

- the address of your database instance
- your database port
- your database username
- your database password
- your database name

All this information is available in the OVHcloud Console, on the <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> page.

There is also a guide available: [Getting started with the Web Cloud Databases service](/guides/web-cloud/databases/db-getting-started).

### Connect via the command line

```bash
psql --host=server --port=port --username=user --password database_name
```

### Connect from a PHP script

```php
1. <?php
2. $myPDO = new PDO('pgsql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

### Connect from software (SQuirreL SQL)
- Launch SQuirreL SQL and click on <code className="action">Aliases</code>, then on <code className="action">+</code>

    - **User Name**: Enter the username

## Available PostgreSQL extensions

Web Cloud Databases offers several PostgreSQL extensions to add extra features to your databases. You can enable and disable them in the OVHcloud Console, in the <code className="action">Databases</code> tab of your instance.

For the list of available extensions, refer to the "[Enabling PostgreSQL extensions](/guides/web-cloud/databases/db-enable-postgresql-extensions#available-extensions)" guide.

## Export and import a PostgreSQL database

- **Export your database via the command line**

```bash
pg_dump --host=server --port=port --username=user --password database_name > database_name.sql
```

- **Import your database via the command line**

```bash
psql --host=server --port=port --username=user --password database_name < database_name.sql
```

:::info
In some cases, the RAM available in your Web Cloud Databases instance may not be enough to perform the export or import you want. If this is the case, we recommend using the import tool provided by OVHcloud. Refer to the documentation "[Getting started with the Web Cloud Databases service](/guides/web-cloud/databases/db-getting-started#importing-a-database)" if necessary.

:::
