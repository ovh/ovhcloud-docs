## Objective

[Web Cloud Databases](/links/web/databases) solutions can be used with OVHcloud services, or external to OVHcloud.

By default, and for security reasons, on these solutions:

- Only IP addresses linked to our shared hosting infrastructure are authorized to access the contents of the databases.
- Access to the solution logs is not restricted depending on the IP addresses. You can access them via a computer, for example.

Need to change these permissions/restrictions?

**Find out how to authorize one or more IP addresses to access your Web Cloud Databases solution.**

## Requirements

- A [Web Cloud Databases](/links/web/databases) solution
- The IP address (or IP address range) to authorize on your solution

[[cpnav:web-cloud-databases]]

## Instructions

### Authorise an IP address or IP address range

:::info
As a reminder, if you have just activated your [Web Cloud Databases](/links/web/databases) solution and want to use it with an [OVHcloud web hosting](/links/web/hosting) plan, the IP addresses of these plans are already authorised by default.

:::

Click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> page, then select the instance concerned.

    <img className="thumbnail" alt="Web Cloud DB page and list of the account's instances" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    On the page that opens, click the <code className="action">Allowed IPs</code> tab.

    <img className="thumbnail" alt="Allowed IPs tab of a Web Cloud DB instance" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    On the page that appears, click the <code className="action">Add an IP</code> button above the table.

    <img className="thumbnail" alt="Add an IP button above the table of allowed IPs" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    If you want to modify an IP address or IP address range that is already authorised, click the <code className="action">⋮</code> button in the **Actions** column of the table, to the right of the row for the IP address or IP address range you want to modify, then click <code className="action">Edit</code>. You can change its name and permissions; the IP address itself cannot be modified.

    <img className="thumbnail" alt="Menu of a row in the table of allowed IPs" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Step 4">
    In the **Add an allowed IP** window that opens, fill in the following fields:

    <img className="thumbnail" alt="Add an allowed IP window and its fields" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (required): Enter the IP address (for example: `203.0.113.44`) or the IP address range (for example: `203.0.113.0/24`, representing all IP addresses from `203.0.113.0` to `203.0.113.255`) that you want to authorise on your Web Cloud Databases solution.
    - **Name** (required): For example, you can enter the role of the IP address or IP address range concerned.
    - **Allow service access** (ticked by default): Tick this box to authorise the IP address or IP address range to access the databases on your Web Cloud Databases solution.
    - **Allow SFTP access**: Tick this box to authorise the IP address or IP address range to access the logs of your Web Cloud Databases solution.

    :::warning
    We strongly advise against ticking the **Allow service access** box to authorise the IP address range `0.0.0.0/0` to access your databases.

    Indeed, this would authorise all existing IPv4 addresses to access your databases.

    :::

    Once you have entered the information, click the <code className="action">Add</code> button.
  </Tab>
</Tabs>

## Special cases

**Click on the cases below to view the corresponding information.**

<details>

<summary>The IP address range 0.0.0.0/0</summary>

When your Web Cloud Databases solution is activated, a row for the IP address range `0.0.0.0/0` is already present by default to authorise **SFTP** access to the solution.

This authorisation is deliberately set up so that you can access the log files of your Web Cloud Databases solution without having to declare the IP address of your Internet access point.

This is because this IP address can change regularly, depending on the Internet service provider.

In addition, we recommend that you **do not** modify this authorisation and that you do not authorise access to the databases on your Web Cloud Databases solution.

Indeed, this would authorise all existing IPv4 addresses to access your databases, which represents a risk for the security of your data.

</details>

<details>

<summary>Access authorisation for OVHcloud web hosting plans</summary>

When your Web Cloud Databases solution is activated, access authorisation for OVHcloud web hosting plans is enabled by default.

If you want to disable this authorisation because you do not use a web hosting plan with your Web Cloud Databases solution, click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> page, then select the instance concerned.

    <img className="thumbnail" alt="Web Cloud DB page and list of the account's instances" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    On the page that opens, click the <code className="action">Allowed IPs</code> tab.

    <img className="thumbnail" alt="Allowed IPs tab of a Web Cloud DB instance" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    At the top of the page, in the **OVHcloud web hosting access** section, turn off the **Allow OVHcloud web hosting services to access the database** switch.

    <img className="thumbnail" alt="OVHcloud web hosting access section and its switch" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/web-hosting-access.png" loading="lazy" />

    :::info
    By disabling this access, you also block access to **phpMyAdmin** via the link available in the OVHcloud Console, for your entire Web Cloud Databases solution.
    :::

  </Tab>
</Tabs>

</details>
