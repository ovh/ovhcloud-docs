## Objective

You can view the content of your database via an interface. There are several ways to connect to it.

**Find out how to connect to your database on your database server.**

## Requirements

- A [Web Cloud Databases instance](/links/web/databases) (included in a [Web Hosting](/links/web/hosting) Performance, Agency, Agency Plus or Agency Max plan).

[[cpnav:web-cloud-databases]]

## Instructions

:::info
[Web Cloud Databases](/links/web/databases) solutions do not provide access to the database management system itself, but to the databases hosted on it.

- There is no super user "root" access.
- Generic SQL commands work normally, and software such as HeidiSQL, SQuirreL SQL or Adminer is fully compatible.

:::

### Connect to a MySQL or MariaDB database

:::info
Since MariaDB is a fork of MySQL, the commands are exactly the same for both types of databases.

:::

#### Connection via OVHcloud phpMyAdmin

Click on the tabs below to view each of the **4** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> page, then select the instance concerned.

    <img className="thumbnail" alt="Web Cloud DB page and list of the account's instances" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Retrieve the following connection details:

    - **Server (hostname) and port:** visible in the <code className="action">Overview</code> tab, **SQL** section, **Hostname** and **Port** entries.
    - **User:** visible in the <code className="action">Users & grants</code> tab.
    - **Password:** the password associated with the user. If you have forgotten it, go to the <code className="action">Users & grants</code> tab, click the <code className="action">⋮</code> button of the user concerned, then click <code className="action">Change password</code>.

    <img className="thumbnail" alt="SQL section of the overview with the hostname and port" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />

    :::warning
    If you change a database user's password, all applications/websites that access this database must be updated accordingly.

    :::

  </Tab>
  <Tab label="Step 3">
    In the <code className="action">Overview</code> tab, **SQL** section, click the <code className="action">⋮</code> button to the right of **Additional actions**, then click <code className="action">Administration interface</code>. phpMyAdmin opens in a new tab of your browser.

    <img className="thumbnail" alt="Additional actions menu of the SQL section with the Administration interface entry" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-additional-actions.png" loading="lazy" />

    :::info
    If the **Administration interface** entry does not appear in the menu, OVHcloud phpMyAdmin is not available for your instance. In that case, use one of the methods in the "[Connection to the database outside the OVHcloud Console](#connexion-à-la-base-de-données-hors-espace-client)" section.

    :::

  </Tab>
  <Tab label="Step 4">
    On the phpMyAdmin login page, enter the information retrieved in step 2:

    <img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-login-web-cloud-db.png" loading="lazy" />

    - **Server:** enter the *hostname* followed by the *port number*, separated by "**:**" or a "**space**". For example: **aaXXXXX-XXX.eu.clouddb.ovh.net:12345**.
    - **Username:** enter the *username*.
    - **Password:** enter the *password*.
  </Tab>
</Tabs>

If the connection is successful, the following page will appear.

<img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-main-page-web-cloud-db.png" loading="lazy" />

:::warning
**In case of error:**

- Error #1045 means the credentials are incorrect. Check your username and/or password.
- Error #2005 means the server name should be checked, and whether it is functioning correctly.

:::

#### Connection to the database outside the OVHcloud Console <a name="connexion-à-la-base-de-données-hors-espace-client"></a>

:::warning
If you are using a "Web Cloud Databases"/"Private SQL" solution, remember to authorise your IP using the guide on [configuring your database server](/guides/web-cloud/databases/db-configure-optimise-database-server#manage-your-access).

:::

Click on the tabs below to view each of the **2** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> page, then select the instance concerned.

    <img className="thumbnail" alt="Web Cloud DB page and list of the account's instances" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Retrieve the following connection details:

    - **Server (hostname):** visible in the <code className="action">Overview</code> tab, **SQL** section, **Hostname** entry.
    - **Port:** visible in the same place, **Port** entry.
    - **User:** visible in the <code className="action">Users & grants</code> tab.
    - **Password:** the password associated with the user concerned.
    - **Database name:** visible in the <code className="action">Databases</code> tab.

    <img className="thumbnail" alt="SQL section of the overview with the hostname and port" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />
  </Tab>
</Tabs>

**Click on the connection method of your choice to view the content.**

<details>

<summary>Command line connection</summary>

```bash
mysql --host=server --user=user --port=port --password=password database_name
```

</details>

<details>

<summary>PHP script connection</summary>

```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

</details>

<details>

<summary>Software connection (SQuirreL SQL)</summary>

:::info
In our example, we use the open-source software SQuirreL, but other interfaces such as HeidiSQL or Adminer are fully compatible.

:::

- Launch SQuirreL SQL and click <code className="action">Aliases</code>, then <code className="action">+</code>

<img className="thumbnail" alt="launch SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Fill in the fields below, then confirm with the <code className="action">OK</code> button:
    - **Name**: Choose a name
    - **Driver**: Choose "MySQL Driver"
    - **URL**: Enter the server address and port in the form `jdbc:mysql://server:port`
    - **User Name**: Enter the username
    - **Password**: Enter the password

<img className="thumbnail" alt="config connection" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Confirm again with the <code className="action">Connect</code> button

<img className="thumbnail" alt="valid connection" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

You are now connected to your database:

<img className="thumbnail" alt="config connection" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

</details>

<details>

<summary>phpMyAdmin connection</summary>

You can use your own phpMyAdmin interface to explore the content of your database. To do this, install phpMyAdmin on your own server or web hosting plan. During installation, make sure you correctly configure the information for your database server and desired database so that phpMyAdmin can connect to it.

</details>

    <img className="thumbnail" alt="Web Cloud DB page and list of the account's instances" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">

    - **Port:** visible in the same place, **Port** entry.
