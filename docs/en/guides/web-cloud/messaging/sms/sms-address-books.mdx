## Objective

All OVHcloud SMS accounts can use one or more address books. This guide explains how to create them in the OVHcloud Console.

## Requirements

- an active [OVHcloud SMS account](/links/telecom/sms)
- a spreadsheet or text editor tool

## Instructions

### Step 1: Create an address book in the OVHcloud Console

Select the <code className="action">Contacts</code> tab.

<img className="thumbnail" alt="Contacts tab of an SMS account in the OVHcloud Console" src="/images/web-cloud/messaging/sms/sms-address-books/console/contacts-tab.png" loading="lazy" />

Click <code className="action">Actions</code>, then <code className="action">Create an address book</code>. In the **Create an address book** window, enter a name for your new address book in the **Name** field, then click <code className="action">Create</code>.

<img className="thumbnail" alt="Create an address book window opened from the Actions menu of the Contacts tab" src="/images/web-cloud/messaging/sms/sms-address-books/console/create-address-book.png" loading="lazy" />

### Step 2: Add contacts to your address book

You have now created the address book, but it does not contain any contacts. There are several ways of adding contacts.

### Add them individually via the OVHcloud Console

Click the <code className="action">Add a contact</code> button above the contact list.

<img className="thumbnail" alt="Add a contact button in the Contacts tab of an SMS account" src="/images/web-cloud/messaging/sms/sms-address-books/console/add-contact-button.png" loading="lazy" />

In the **Add a contact** panel, enter the contact's details: first name, last name, company (optional), and home and work landline and mobile numbers.

<img className="thumbnail" alt="Add a contact panel with the contact fields and phone numbers" src="/images/web-cloud/messaging/sms/sms-address-books/console/add-contact-panel.png" loading="lazy" />

Fill in the fields you need (at least one phone number is required), then click <code className="action">Save</code>. The contact is then added to your address book. Repeat this process to add more contacts.

### Add multiple contacts by importing a contact file to the OVHcloud Console

#### Prepare a file in your spreadsheet

If you would like to use or create a document in a spreadsheet format, you will need to design it as per the layout below, and export it in .csv format.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook-spreadsheet1.png" loading="lazy" />

You can download an <a href="/images/guides/web-cloud/messaging/sms/sms-address-books/phonebook.csv" download>address book template in .csv format</a> to fill in.

The vast majority of spreadsheet tools won't support the international format expected for telephone/fax numbers (+44xxxxxxxxxx). This means you will need to change the format of the cells that contain these numbers (workPhone, workMobile, etc.). To do this, select the columns concerned, and select a "Text" format for them.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook-spreadsheet2.png" loading="lazy" />

Once the document is ready, save it in a spreadsheet format to edit later.

At the same time, save or export it in .csv format to prepare the import.

:::info
**Recommendations**

Save your spreadsheet file in .csv format (separator: semi-colon).

Special characters like accents are not included in the .csv file import, and contacts that contain special characters will not be imported.

Please follow the international format +44xxxxxxxxxx for your phone numbers.

We advise ensuring that your address books do not contain more than 2,000 contacts.

All of your contacts must be on the same sheet in your spreadsheet file.

:::

#### Import the file into the OVHcloud Console

Go back to the OVHcloud Console, click <code className="action">Actions</code>, then <code className="action">Import</code>.

<img className="thumbnail" alt="Import option in the Actions menu of the Contacts tab" src="/images/web-cloud/messaging/sms/sms-address-books/console/actions-import.png" loading="lazy" />

In the **Import contacts** window, click <code className="action">Browse files</code> to select your .csv file, then click <code className="action">Import</code>. The contacts in the file are added to the selected address book. The first line of the file must contain the column headers of the template (`group`, `surname`, `name`, `workPhone`, `workMobile`, `homePhone`, `homeMobile`), in any order. A file exported from the OVHcloud Console cannot be re-imported as it is: first replace its headers with those of the template.

<img className="thumbnail" alt="Import contacts window with the CSV file selection area" src="/images/web-cloud/messaging/sms/sms-address-books/console/import-contacts.png" loading="lazy" />

Wait a few seconds while the file is imported into the OVHcloud Console.

### Step 3: Edit or delete an address book

If you would like to edit the name of an address book, select it in the **Address book** dropdown menu (if you have created several address books), then click <code className="action">Actions</code> and <code className="action">Rename</code>. In the **Rename the address book** window, enter the new name in the **Name** field, then click <code className="action">Rename</code>.

To delete an address book, select it in the **Address book** dropdown menu, then click <code className="action">Actions</code> and <code className="action">Delete</code>. Confirm the deletion by clicking <code className="action">Delete</code> in the **Confirm deletion** window.

:::warning

Deleting an address book is irreversible.

:::

To edit or delete a contact, click the <code className="action">⋮</code> button at the end of the contact's row, then <code className="action">Modify</code> or <code className="action">Delete</code>.

<img className="thumbnail" alt="Contact menu with the Modify and Delete options in the Contacts tab" src="/images/web-cloud/messaging/sms/sms-address-books/console/contact-row-menu.png" loading="lazy" />
