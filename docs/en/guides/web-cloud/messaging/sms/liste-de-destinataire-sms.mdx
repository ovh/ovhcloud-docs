## Objective

To send an SMS campaign to multiple contacts, you can import one or more recipient lists into the OVHcloud Console.

**Find out how to create a list of SMS recipients via a spreadsheet or text editor, and import it into the OVHcloud Console.**

## Requirements

- an active [OVHcloud SMS account](/links/telecom/sms)
- a spreadsheet or text editor tool

## Instructions

### Step 1: Creating your recipient list

#### Creating your list via a spreadsheet

You can create a recipient list via a spreadsheet, or use a list that already exists. This list must be in .csv format, and have the layout below in a spreadsheet:

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/img_4831.png" loading="lazy" />

:::warning
To ensure that the spreadsheet does not perform any automatic calculations on your numbers, you must customise the format of your `number` column.

In Microsoft Excel, select your entire `number` column, right-click, and click <code className="action">Format Cells</code>. Click <code className="action">Custom</code> and enter the following value in the `Type` field: ```[>0]+0;Standard```.

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/sms-recipientlist-2.png" loading="lazy" />

Under LibreOffice, select your entire `number` column, right-click, and click <code className="action">Format Cells...</code>. Enter the following value in the Format `Format code`: ```[>0]+0;Standard```

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/sms-recipientlist-2b.png" loading="lazy" />

:::

If you open a .csv file with a notepad program, it should look similar to this:

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/sms-recipientlist-1.png" loading="lazy" />

The following points are vital for your recipient list to be processed properly in the OVHcloud Console:

- All of your contacts must be on the same sheet in your spreadsheet file, in a `number` column.
- Delete special characters (like accents) — they won't be accepted when importing the .csv file into the OVHcloud Console.
- Phone numbers must be entered in international format (e.g. for a UK phone number: +44712345678).
- Save your spreadsheet file in .csv format (separator: semi-colon).

#### Creating your list with a text editor

An alternative method involves creating a .txt file via a text editor or notepad program.

- Enter `number` into the first line.
- Enter your phone numbers in international format (+44712345678), with one number per line.

You should end up with the result below:

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/sms-recipientlist-1.png" loading="lazy" />

### Step 2: Importing your list into the OVHcloud Console

Click the <code className="action">Recipients</code> tab, then <code className="action">Add a list</code>.

<img className="thumbnail" alt="Recipients tab and Add a list button" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/console/recipients-add-list.png" loading="lazy" />

You can create up to 9 recipient lists.

In the **Add a recipient list** panel that opens, name your list in the **List name** field, then import your local file into the OVHcloud Console: leave the **File** source selected and drop your file into the **CSV file (.csv, .txt)** area, or click this area to select it. A **URL** source is also available. Then click <code className="action">Add</code>.

<img className="thumbnail" alt="Add a recipient list panel" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/console/add-recipient-list-panel.png" loading="lazy" />

### Step 3: Sending an SMS to your recipient list

Now that your list has been imported, you can follow the instructions in our guide on [Sending SMS messages via the OVHcloud Console](/guides/web-cloud/messaging/sms/send-sms-control-panel) to send an SMS to the recipients of this list.
