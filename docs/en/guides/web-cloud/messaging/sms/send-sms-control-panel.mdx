## Objective

You can send SMS messages directly via the OVHcloud Control Panel. This guide gives step-by-step instructions on how to send your first SMS messages.

## Requirements

- an [OVHcloud SMS account](/links/telecom/sms) with SMS credits

## Instructions

The "Send an SMS" field is the first item available in the list of actions.

<img className="thumbnail" alt="send sms control panel" src="/images/web-cloud/messaging/sms/send-sms-control-panel/sms-send-control-panel01E.png" loading="lazy" />

### Step 1: Configure the sender and recipient. <a name="configure-sender-recipient"></a>

:::info
For more information on creating and using a sender, refer to our guide "[Everything you need to know about SMS senders](/guides/web-cloud/messaging/sms/sms-senders)".

:::

Once you have landed on the sending page for SMS messages, you will have different settings to enter, to adapt your SMS sending to suit your needs. 

<img className="thumbnail" alt="send sms control panel" src="/images/web-cloud/messaging/sms/send-sms-control-panel/sms-send-control-panel02E.png" loading="lazy" />

For the SMS sender (1), you can either select a short number that allows recipients to send back replies (available for OVHcloud accounts in France only), or you can set an alpha-numeric sender name.
Next, enter the recipient phone number (2) in international format (+44xxxxxxxxxx).

You can also send SMS messages to multiple recipients. There are two methods for doing this:

- Via a list of recipients in .csv format, via the "Manage recipients" button.
For further information on this, you can refer to our [guide on SMS recipient lists](/guides/web-cloud/messaging/sms/liste-de-destinataire-sms).

- By creating an address book (3). You can do this directly via the OVHcloud Control Panel, or import one as a .csv or .txt file.
Feel free to refer to our [guide on managing SMS address books](/guides/web-cloud/messaging/sms/sms-address-books) for further information.

### Step 2: Compose your SMS message. <a name="compose-sms"></a>

:::info
For legal reasons, commercial SMS messages will only be sent between **08:00 and 20:00, from Monday to Saturday**.

:::

Once you have selected a sender and entered your recipients, you can now start composing your message.

<img className="thumbnail" alt="send sms control panel" src="/images/web-cloud/messaging/sms/send-sms-control-panel/sms-send-control-panel03E.png" loading="lazy" />

Type your message in the box (1). You will see a counter showing the number of characters used, and the number of corresponding SMS messages (2).

:::info
We recommend not exceeding 8 SMS per message. Beyond this limit, operators can no longer guarantee message delivery.

:::

The two tables below list the characters that are authorised in 7bit encoding. The characters in the "**Extensions**" table count as double. 

The maximum size of an SMS message is 160 characters in 7bit encoding (GSM 03.38 standard).

If you use characters that do not appear in these tables, the encoding will switch to Unicode, reducing the maximum size of an SMS message to 70 characters.

<img className="thumbnail" alt="List of authorised SMS characters" src="/images/web-cloud/messaging/sms/send-sms-control-panel/smsauthorizedcharacters.png" loading="lazy" />

#### Commercial SMS size <a name="commercial-sms-size"></a>

A commercial SMS message must include the STOP clause. This contains 11 characters and is automatically deducted from the 160 base characters of the first SMS.
The table below therefore indicates the maximum number of characters allowed for commercial SMS messages.

Example: in 7bit encoding, if your message is longer than 149 characters, it will be sent as 2 SMS messages and will therefore cost 2 credits.

| Encoding | First SMS | Second SMS and following |
|---|---|---|
| 7bit (GSM 03.38 standard) | 149 characters | 153 characters |
| Unicode | 59 characters | 70 characters |
