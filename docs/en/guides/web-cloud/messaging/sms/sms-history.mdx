## Objective

You can view and download a log of your sent SMS messages from the OVHcloud Console. This guide will explain how to do this.

## Requirements

- An [OVHcloud SMS account](/links/telecom/sms) with at least 1 sent SMS.

[[cpnav:telecom-sms]]

<img className="thumbnail" alt="List of SMS accounts in the Web Cloud section of the OVHcloud Console" src="/images/assets/screens/console/product-selection/web-cloud/sms-account-list.png" loading="lazy" />

## Instructions

The log records the date, time, type, sender, recipient, contents and status of each SMS.

:::info

In the OVHcloud Console, you can view SMS messages sent in the last 6 months (or the last 5,000 SMS messages if you have sent more than 5,000 SMS messages in the last 6 months).

To view older SMS messages (up to the last 12 months), you will need to download your SMS history in CSV format. See [Step 2 of this guide](#csv).

:::

### Step 1: Viewing the log in the OVHcloud Console

Click the <code className="action">SMS & Campaigns</code> tab. The log is displayed directly in this tab: select **SMS** to display the log of your unit SMS messages, or **Campaigns** to display the list of your SMS campaigns. Your campaign statistics are shown in the <code className="action">Overview</code> tab.

By default, the list displays the SMS messages from the last 7 days. To display a different period, change it from <code className="action">Filters</code> (see below).

<img className="thumbnail" alt="SMS log in the SMS & Campaigns tab of the OVHcloud Console" src="/images/web-cloud/messaging/sms/sms-history/console/sms-history-list.png" loading="lazy" />

The most recent SMS messages are displayed first.

The <code className="action">⋮</code> button to the right of each SMS lets you view it (<code className="action">View</code>) or delete it (<code className="action">Delete</code>).

<img className="thumbnail" alt="Menu of an SMS in the log with the View and Delete options" src="/images/web-cloud/messaging/sms/sms-history/console/sms-row-menu.png" loading="lazy" />

To delete several SMS messages at once, tick the boxes next to each message. The <code className="action">Delete</code> button, followed by the number of SMS messages selected (for example <code className="action">Delete (1)</code>), appears above the log, next to <code className="action">Actions</code>.

<img className="thumbnail" alt="Delete button displayed above the log after an SMS is selected" src="/images/web-cloud/messaging/sms/sms-history/console/delete-selected-sms.png" loading="lazy" />

From <code className="action">Filters</code>, you can filter the log by type (**Sent**, **Received** or **Scheduled**), by period (**Today**, **Last 7 days**, **Last 30 days**, **This year** or **Custom**), by sender, by recipient or by status (**Delivered**, **In progress**, **Temporary failure** or **Failed**).

<img className="thumbnail" alt="Filters drop-down menu with the Type, Period, Sender, Recipient and Status filters" src="/images/web-cloud/messaging/sms/sms-history/console/history-filters.png" loading="lazy" />

### Step 2: Downloading the sending log as a CSV <a name="csv"></a>

Click the <code className="action">Actions</code> button above your log, then <code className="action">Export to CSV</code> to download your SMS log in .csv format.

<img className="thumbnail" alt="Actions menu with the Export to CSV option" src="/images/web-cloud/messaging/sms/sms-history/console/actions-export-csv.png" loading="lazy" />

You can then view the log using a spreadsheet program. The information will display as in the example below.

<img className="thumbnail" alt="sms-history" src="/images/web-cloud/messaging/sms/sms-history/smshistory7.png" loading="lazy" />

Here is a breakdown of the information included in the log:

|  Title  |  Description  |
|  :-----          |  :-----          |
|  id |  the unique id for the sent SMS used by our servers |
|  date | the date and time that the SMS was sent  |
|  sender |  the sender of the SMS message |
|  receiver |  the recipient’s phone number |
|  ptt |  the return code on the SMS status |
|  operatorCode |  the network ID of the mobile operator to which we sent the SMS |
|  descriptionDlr |  the description of the ptt code received and therefore the status of the SMS |
|  tag |  the tag attributed either manually via the APIs (to one or more SMS messages) or automatically by our servers to each sent SMS (or each SMS campaign) |
|  message |  the content of the SMS |

Further information about the ptt codes and various DLR IDs can be found in the final section of the guide [Everything you need to know about SMS users](/guides/web-cloud/messaging/sms/sms-users#callback-url).
