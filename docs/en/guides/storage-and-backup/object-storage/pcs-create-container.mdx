## Objective

The Object Storage Swift solution for Public Cloud offers unlimited storage with simple billing tailored to your needs. Containers can be configured for different use cases:

- Static hosting (static website)
- Private hosting (e.g. personal data storage)
- Public hosting (publicly accessible content)
- Cold storage (archiving)

**This guide explains how to create and manage your Swift Object Storage containers.**

## Requirements

- A [Public Cloud project](/guides/public-cloud/cross-functional/create-a-public-cloud-project) in your OVHcloud account

Depending on the tool you plan to use:

- **Swift S3<sup>1</sup> API**: An environment [prepared for the OpenStack API](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment) with `python-openstackclient` and `awscli` installed
- **Swift client**: An environment [prepared for the OpenStack API](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment) with `python-swiftclient` installed
- **OVHcloud CLI**: The [OVHcloud CLI](/guides/manage-and-operate/cli/getting-started) installed and configured

## Instructions

### Preparation

<Tabs>
  <Tab label="Via the OVHcloud Control Panel">
    Log in to your OVHcloud Control Panel and open <code className="action">Object Storage</code> in the left-hand menu under **Storage & backup**.
  </Tab>
  <Tab label="Via the Swift S3 API">
    **Set the OpenStack environment variables**

    ```bash
    source <user_name>-openrc.sh
    Please enter your OpenStack Password for project <project_name> as user <user_name>:
    ```

    **Install the OpenStack client if needed**

    ```bash
    pip install python-openstackclient
    ```

    OpenStack client command reference: [docs.openstack.org](https://docs.openstack.org/python-openstackclient/latest/)

    **Create EC2 credentials**

    S3 tokens require two parameters — **access** and **secret** — generated from Keystone:

    ```bash
    openstack ec2 credentials create
    +------------+----------------------------------------------------------------------------------------------------------------------------+
    | Field      | Value                                                                                                                      |
    +------------+----------------------------------------------------------------------------------------------------------------------------+
    | access     | 5a4d8b8d88104123a862c527ede5a3d3                                                                                           |
    | links      | {u'self': u'https://auth.cloud.ovh.net/v3/users/d74d05ff121b44bea9216495e7f0df61/credentials/OS-EC2/5a4d8b8d88104123a862c527ede5a3d3'} |
    | project_id | 20e124b71be141299e111ec26b1892fa                                                                                           |
    | secret     | 925d5fcfcd9f436d8ffcb20548cc53a2                                                                                           |
    | trust_id   | None                                                                                                                       |
    | user_id    | d74d05ff121b44bea9216495e7f0df61                                                                                           |
    +------------+----------------------------------------------------------------------------------------------------------------------------+
    ```

    **Configure the AWS client**

    Install `awscli`:

    <details>
    <summary>Python package</summary>

    ```bash
    pip install awscli
    ```

    </details>

    <details>
    <summary>Debian-based OS</summary>

    ```bash
    sudo apt install awscli
    ```

    </details>

    <details>
    <summary>RHEL-based OS</summary>

    ```bash
    sudo yum install awscli
    ```

    </details>

    Then configure it with the EC2 credentials generated above:

    <details>
    <summary>CLI method</summary>

    ```bash
    aws configure
    ```

    Follow the prompts and enter your access key and secret key when asked.

    </details>

    <details>
    <summary>Manual method</summary>

    ```bash
    cat ~/.aws/credentials
    ```

    ```text
    [default]
    aws_access_key_id = <access_key>
    aws_secret_access_key = <secret_key>
    ```

    ```bash
    cat ~/.aws/config
    ```

    ```text
    [plugins]
    endpoint = awscli_plugin_endpoint
    [default]
    region = <region>
    s3 =
      endpoint_url = https://s3.<region>.cloud.ovh.net
      signature_version = s3v4
    s3api =
      endpoint_url = https://s3.<region>.cloud.ovh.net
    ```

    </details>

    :::info
    Both virtual-hosted-style and path-style access are supported; virtual-hosted-style is recommended, as path-style was deprecated after September 30, 2020.
    :::

### Create a container

:::info
When using the **Swift S3 API**, bucket names must follow these rules:

- Between 3 and 63 characters long
- Lowercase letters, numbers, periods, and dashes only
- Must start with a lowercase letter or number
- No underscores, no consecutive periods, no dashes adjacent to periods
- Not formatted as an IP address (e.g. `198.51.100.24`)

:::

<Tabs>
  <Tab label="Via the OVHcloud Control Panel">
    Click <code className="action">Create an object container</code>.

    Fill in the creation form:

    - **Container name**: Enter a name for your container.
    - **Container type**: Select <code className="action">Swift API</code>.
    - **Location**: Choose an availability zone type (3-AZ Region, 1-AZ Region, or Local Zone), then select a geographic area.
    - **Container type**: Choose the access type **Static hosting**, **Private**, or **Public**.

    :::warning
    If you want to link your container to a domain name, the container name must not contain `.` or `_`, and must not use capital letters. See: [Linking a container to a domain name](/guides/storage-and-backup/object-storage/pcs-link-domain).
    :::

    Review the summary panel, then click <code className="action">Create</code>.
  </Tab>
  <Tab label="Via the Swift S3 API">
    ```bash
    aws s3 mb s3://<container_name>
    ```

    :::info
    S3 buckets can only be created on the PCS (Object Storage) policy.
    :::
  </Tab>
  <Tab label="Via the Swift client">
    Create the container:

    ```bash
    swift post container1
    ```

    To make the container publicly accessible:

    ```bash
    swift post --header "X-Container-Read: .r:*" container1
    ```

    Verify the configuration:

    ```bash
    swift stat container1

    Account: AUTH_b3e26xxxxxxxxxxxxxxxxxxxb0ba29
    Container: container1
    Objects: 0
    Bytes: 0
    Read ACL: .r:*
    Write ACL:
    Sync To:
    Sync Key:
    Accept-Ranges: bytes
    X-Trans-Id: B2210C05:8D93_052711A1:01BB_561CC9DF_1B305:30D7
    X-Storage-Policy: Policy-0
    Connection: close
    X-Timestamp: 1444726875.27475
    Content-Type: text/plain; charset=utf-8
    ```
  </Tab>
  <Tab label="Via the OVHcloud CLI">
    Container creation is not available via the OVHcloud CLI. Use the Control Panel, the Swift S3 API, or the Swift client instead.
  </Tab>
</Tabs>

### List your containers

<Tabs>
  <Tab label="Via the OVHcloud Control Panel">
    Navigate to <code className="action">Object Storage</code> in the left-hand menu. Your containers are listed under the <code className="action">My containers</code> tab.
  </Tab>
  <Tab label="Via the Swift S3 API">
    ```bash
    aws s3 ls
    ```

    :::info
    If you have more than one profile configured, add `--profile <profile_name>` to the command.
    :::
  </Tab>
  <Tab label="Via the Swift client">
    ```bash
    swift list
    ```
  </Tab>
  <Tab label="Via the OVHcloud CLI">
    ```bash
    ovhcloud cloud storage swift list
    ```
  </Tab>
</Tabs>

### Upload objects

<Tabs>
  <Tab label="Via the OVHcloud Control Panel">
    Click on the name of your container, then click <code className="action">Add objects</code> in the **Objects** tab.

    Select the file you want to upload and click <code className="action">Import</code>.
  </Tab>
  <Tab label="Via the Swift S3 API">
    ```bash
    aws s3 cp /path/to/<object_name> s3://<container_name>/<object_name>
    ```
  </Tab>
  <Tab label="Via the Swift client">
    Upload a single file:

    ```bash
    swift upload container1 file.txt
    ```

    Upload an entire folder (a prefix matching the folder name is automatically added to the objects):

    ```bash
    swift upload container1 images/

    images/OVHlogo.png
    images/OVHSummitKeynote.jpg
    ```
  </Tab>
  <Tab label="Via the OVHcloud CLI">
    Object upload is not available via the OVHcloud CLI. Use the Control Panel, the Swift S3 API, or the Swift client instead.
  </Tab>
</Tabs>

### List objects in a container

<Tabs>
  <Tab label="Via the OVHcloud Control Panel">
    Click on the name of your container to view its objects in the **Objects** tab.
  </Tab>
  <Tab label="Via the Swift S3 API">
    ```bash
    aws s3 ls s3://<container_name>
    ```
  </Tab>
  <Tab label="Via the Swift client">
    ```bash
    swift list container1

    images/OVHSummitKeynote.jpg
    images/OVHlogo.png
    text1.txt
    text2.txt
    text3.txt
    ```

    Filter by prefix:

    ```bash
    swift list container1 --prefix images

    images/OVHSummitKeynote.jpg
    images/OVHlogo.png
    ```

    If the container is public, objects are accessible directly via URL:

    ```text
    https://storage.gra1.cloud.ovh.net/v1/AUTH_b3e26xxxxxxxxxxxxxxxxxxxb0ba29/container1/images/OVHlogo.png
    ```

    This URL is composed of an endpoint (available from the [Horizon interface](/guides/public-cloud/cross-functional/compute-horizon-access-security)), the container name, and the object name (including prefix).
  </Tab>
  <Tab label="Via the OVHcloud CLI">
    Object listing is not available via the OVHcloud CLI. Use the Control Panel, the Swift S3 API, or the Swift client instead.
  </Tab>
</Tabs>

### Download objects

<Tabs>
  <Tab label="Via the OVHcloud Control Panel">
    Click the download icon on the object line.
  </Tab>
  <Tab label="Via the Swift S3 API">
    ```bash
    aws s3 cp s3://<container_name>/<object_name> .
    ```
  </Tab>
  <Tab label="Via the Swift client">
    Download a single file:

    ```bash
    swift download container1 text1.txt

    text1.txt [auth 0.328s, headers 0.452s, total 0.453s, 0.000 MB/s]
    ```

    Download all files with a given prefix:

    ```bash
    swift download container1 --prefix images

    images/OVHlogo.png [auth 0.383s, headers 0.520s, total 0.522s, 0.135 MB/s]
    images/OVHSummitKeynote.jpg [auth 0.371s, headers 0.514s, total 0.559s, 2.657 MB/s]
    ```
  </Tab>
  <Tab label="Via the OVHcloud CLI">
    Object download is not available via the OVHcloud CLI. Use the Control Panel, the Swift S3 API, or the Swift client instead.
  </Tab>
</Tabs>

### Delete objects and containers

<Tabs>
  <Tab label="Via the OVHcloud Control Panel">
    **Delete an object**: Click the delete icon (trash can) on the object line and confirm.

    **Delete a container**: Click the <code className="action">...</code> button on the container line, then select <code className="action">Delete</code> and confirm.
  </Tab>
  <Tab label="Via the Swift S3 API">
    **Delete an object:**

    ```bash
    aws s3 rm s3://<container_name>/<object_name>
    ```

    **Delete a container** (the container must be empty first):

    ```bash
    aws s3 rb s3://<container_name>
    ```
  </Tab>
  <Tab label="Via the Swift client">
    **Delete a file:**

    ```bash
    swift delete container1 text1.txt

    text1.txt
    ```

    Delete multiple files using a prefix:

    ```bash
    swift delete container1 images/*

    images/OVHSummitKeynote.jpg
    images/OVHlogo.png
    ```

    **Delete a container** (also deletes all objects inside it):

    ```bash
    swift delete container1

    text2.txt
    text3.txt
    ```
  </Tab>
  <Tab label="Via the OVHcloud CLI">
    Container and object deletion is not available via the OVHcloud CLI. Use the Control Panel, the Swift S3 API, or the Swift client instead.
  </Tab>
</Tabs>
