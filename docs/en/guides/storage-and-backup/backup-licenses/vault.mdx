## Objective

A **Vault** is a storage space provided by OVHcloud to which you can send your backup data. With Backup Licenses, a first Vault is delivered automatically with your first licence.

**This guide explains how Backup Licenses Vaults work, how they are billed, and how to order additional ones.**

## Requirements

- A Backup Licenses licence that you have ordered. See our "[Ordering and configuring your first licence](/guides/storage-and-backup/backup-licenses/first-configuration)" guide for more information.

## Instructions

### The "bundle" Vault

A **"bundle"** Vault is delivered by default with your first Backup Licenses licence.

- This Vault is **tied to the product subscription**: it is **deleted if the Backup Licenses product is cancelled**.
- It is **unique**: you only have one "bundle" Vault, regardless of how many licences you hold.
- It is **free of charge up to 500 GB**. This space can be used for your VBR servers as well as for other storage needs.

:::danger
Cancelling the Backup Licenses product results in the **deletion of the "bundle" Vault and the data it contains**. Make sure you have retrieved your data before cancelling.

:::

### Retrieving the Vault connection details

The "bundle" Vault is provided as an **S3<sup>1</sup> bucket**. To retrieve the connection details (endpoint, access credentials), click <code className="action">Show credentials</code> on the Vault page in the OVHcloud Control Panel.

These details let you configure the Vault as an object repository in your Veeam Backup & Replication server, or access it with any S3-compatible client.

### Billing of the "bundle" Vault

- The **first 500 GB are included** in your Backup Licenses subscription, at no extra cost.
- **Beyond 500 GB**, each additional GB consumed is billed **monthly**, at the **public OVHcloud Object Storage rate**.

:::info
Up-to-date prices are available on the [Object Storage pricing page](/links/public-cloud/prices-object-storage).

:::

### Ordering additional Vaults

You can order **additional Vaults** from the OVHcloud Control Panel.

They work exactly like the "bundle" Vault (S3 bucket, same uses, same access methods), with one difference: they are **billed from the first GB consumed**, at the public OVHcloud Object Storage rate. No free allowance is included.

The table below summarises the differences:

| | "Bundle" Vault | Additional Vault |
|---|---|---|
| **Delivery** | Delivered automatically with the first licence | Ordered on demand from the Control Panel |
| **Number** | One per subscription | As many as needed |
| **Included volume** | 500 GB free of charge | None |
| **Billing** | From the 501st GB, at the public Object Storage rate | From the first GB, at the public Object Storage rate |
| **Lifecycle** | Deleted when the Backup Licenses product is cancelled | Can be cancelled independently |
