## Objective

The OVHcloud HA-NAS service allows you to manage file storage that can be accessed over a network.

**This guide explains how to manage the partitions of your HA-NAS service via the OVHcloud API.**

## Requirements

- An OVHcloud [HA-NAS service](https://www.ovhcloud.com/en-gb/storage-solutions/nas-ha/)
- Consulting the [OVHcloud API first steps guide](/guides/manage-and-operate/api/first-steps) to familiarise yourself with the OVHcloud APIv6

## Instructions

All API routes in this guide are available in the <ApiLink section="/dedicated/nasha">*/dedicated/nasha* section</ApiLink> of the API console.

:::info
When using the API, all fields marked with an asterisk (\*) are required.
:::


### Retrieving information about your service

All your active services can be retrieved by using the following route:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha"} />


### Listing all partitions

Use the following route to retrieve the partitions of a service:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | The internal name of your HA-NAS service |

### Retrieving the properties of a partition

To view the details of a partition, use the following route:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | The internal name of your HA-NAS service |
| `partitionName` | Yes | Name of the partition |

### Retrieving statistics for a partition

Use the following route to retrieve usage information for a partition:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/use"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | The internal name of your HA-NAS service |
| `partitionName` | Yes | Name of the partition |
| `type` | Yes | The type of statistic to be fetched: *size*, *used* or *usedbysnapshots* |

### Creating a partition

Use the following route to create a new partition:

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | The internal name of your HA-NAS service |
| `partitionDescription` |  | Optional description |
| `partitionName` | Yes | A name for the partition |
| `protocol` | Yes | *NFS*, *CIFS*, or *NFS_CIFS* for both |
| `size` | Yes | The size of the partition |

Choose `NFS` as protocol and a size of `10` Gigabytes, for example.

### Modifying the properties of a partition

Use the following route to alter a partition:

<Api version="v1" section="/dedicated/nasha" method="PUT" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | The internal name of your HA-NAS service |
| `partitionName` | Yes | Name of the partition |
| `partitionDescription` |  | The new description |
| `size` |  | The new size of the partition |

### Retrieving the ZFS settings of a partition

Use the following route to retrieve the ZFS settings:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | The internal name of your HA-NAS service |
| `partitionName` | Yes | Name of the partition |

### Changing the ZFS settings of a partition

:::warning
The default ZFS settings suit most uses. Only change them if you know the workload stored on the partition. For details on each setting and the values applied by each usage template, read our guide on [configuring the ZFS settings of a partition](/guides/storage-and-backup/file-storage/ha-nas/nas-zfs-settings).
:::


Use the following route to edit the ZFS settings:

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | The internal name of your HA-NAS service |
| `partitionName` | Yes | Name of the partition |
| `templateName` |  | Usage template to apply: *Default*, *Virtual machines*, *Databases* or *File Systems (big files)*. Send it alone, without `atime`, `recordsize` or `sync` |
| `atime` |  | Access time update setting: *off* (default) or *on* |
| `recordsize` |  | Maximum block size, in bytes: *4096*, *8192*, *16384*, *32768*, *65536*, *131072* (default) or *1048576* |
| `sync` |  | File synchronisation setting: *always*, *disabled*, or *standard* (default) |

### Deleting a partition

Use the following route to delete a partition:

<Api version="v1" section="/dedicated/nasha" method="DELETE" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | The internal name of your HA-NAS service |
| `partitionName` | Yes | Name of the partition |
