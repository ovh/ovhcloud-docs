## Objective

This guide shows you how to create a new Cloud Disk Array user, using the OVHcloud Console or the OVHcloud API.

## Requirements

- A [Cloud Disk Array](/links/storage/cloud-disk-array) solution

[[cpnav:storage-cloud-disk-array|en]]

## Instructions

### Using the OVHcloud Console

:::info
Using the OVHcloud Console is the easiest way to create a user.

:::


On your Cloud Disk Array service page, open the <code className="action">Users</code> tab and click <code className="action">Add a user</code>.

In the **Add a user** panel, enter a **User name** (letters, digits and underscore only).

:::warning
Your username needs to contain at least three characters.
:::

Click <code className="action">Add a user</code>. An access key is generated automatically. You can configure the user's permissions once the user is created: see the [Change user rights](/guides/storage-and-backup/block-storage/cloud-disk-array/ceph-change-user-rights) guide.

### Using the API

:::tip
If you are not familiar with the OVHcloud API, read our [First Steps with the OVHcloud API](/guides/manage-and-operate/api/first-steps) guide.

:::


You can create a user using this API route:

<Api version="v1" section="/dedicated/ceph" method="POST" route={"/dedicated/ceph/\{serviceName\}/user"} />


`serviceName` is the fsid of your cluster.

You can also check the user creation by creating a list of users:

<Api version="v1" section="/dedicated/ceph" method="GET" route={"/dedicated/ceph/\{serviceName\}/user"} />

```bash
GET /dedicated/ceph/98d166d8-7c88-47b7-9cb6-63acd5a59c15/user
```
