## Using the OVHcloud Console
Using the OVHcloud Console is the easiest way to change user rights.

On your Cloud Disk Array service page, open the <code className="action">Users</code> tab. Click the <code className="action">...</code> button on the row of the user, then <code className="action">Edit permissions</code>.

The panel lists the pools of the cluster with the current rights of the user (by default, there are no rights). For each pool, tick the rights to grant: **Read**, **Write**, **Execute**, **Classread** or **Classwrite**.

:::warning
Saving entirely replaces the user's current permissions: a pool with every box unticked loses all its rights.
:::

Click <code className="action">Save</code>. You can follow the operation in progress in the <code className="action">Activities</code> tab.

## Using API

<Api version="v1" section="/dedicated/ceph" method="PUT" route={"/dedicated/ceph/\{serviceName\}/user/\{userName\}/pool"} />


<Api version="v1" section="/dedicated/ceph" method="GET" route={"/dedicated/ceph/\{serviceName\}/user"} />

Result example:

```bash
GET /dedicated/ceph/98d166d8-7c88-47b7-9cb6-63acd5a59c15/user
[
  {
    mdsCaps: "",
    monCaps: "allow r",
    serviceName: "98d166d8-7c88-47b7-9cb6-63acd5a59c15",
    name: "myuser"
    osdCaps: "allow class-read object_prefix rbd_children, allow rwx pool=mypool",
    key: "AQA9KpdXoBrDNhAAFCM7m/XOtmWh3LMSNlHVqw==",
  }
]
```
