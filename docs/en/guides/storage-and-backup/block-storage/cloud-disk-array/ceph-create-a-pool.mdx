## Objective

This guide shows you how to create a pool, using the OVHcloud Console or the OVHcloud API.

## Requirements

- A [Cloud Disk Array](/links/storage/cloud-disk-array) solution

[[cpnav:storage-cloud-disk-array|en]]

## Instructions

:::info
Using the OVHcloud Console is the easiest way to create a pool.

:::


### Using the OVHcloud Console

On your Cloud Disk Array service page, open the <code className="action">Pools</code> tab, which lists the existing pools, and click <code className="action">Add a pool</code>.

In the **Add a pool** panel, enter a **Pool name** (letters, digits and underscore only). It must contain at least three characters. Then click <code className="action">Add a pool</code>.

The pool creation request is then taken into account. You can follow the operation in progress in the <code className="action">Activities</code> tab.

### Using the API

:::tip
If you are not familiar with the OVHcloud API, read our [First Steps with the OVHcloud API](/guides/manage-and-operate/api/first-steps) guide.

:::


Use the following API call to create a pool:

<Api version="v1" section="/dedicated/ceph" method="POST" route={"/dedicated/ceph/\{serviceName\}/pool"} />


`serviceName` is the fsid of your cluster.

You can check the pool creation by listing pools with the following endpoint:

<Api version="v1" section="/dedicated/ceph" method="GET" route={"/dedicated/ceph/\{serviceName\}/pool"} />

For example:

```bash
GET /dedicated/ceph/98d166d8-7c88-47b7-9cb6-63acd5a59c15/pool
[
{

  }

```
