## Objective

Nutanix clusters on OVHcloud are scalable. You can now **add (scale out)** or **remove (scale in)** nodes directly from the OVHcloud Console or the OVHcloud API.

:::warning
OVHcloud provides services for which you are responsible, with regard to their configuration and management. You are therefore responsible for ensuring they function correctly.

This guide is designed to assist you in common tasks as much as possible. Nevertheless, we recommend that you contact the [OVHcloud Professional Services team](/links/professional-services) or a [specialist service provider](/links/partner) if you have difficulties or doubts concerning the administration, usage or implementation of services on a server.

:::

## Requirements

- A Nutanix cluster hosted in your OVHcloud account
- Access to the Prism Central administration interface
- Access to the <ApiLink>OVHcloud API</ApiLink>.

## Technical Information

- Your cluster must have between **3 and 32 nodes**
- All new nodes must run the **same AOS version** as the existing cluster

## Instructions

### Scale Out (add a node)

#### Add a node

{/* CP-STEPS-START:add-a-node */}

1. Select your Nutanix cluster. Its page opens on the **Overview** tab.

2. In the **General information** section, the **Number of nodes** row shows the number of nodes in your subscription. Click <code className="action">Add node</code> on that row. The same button is also available on the **Nodes** tab.

3. The **Add node** page opens. Review the configuration of the node (generation, model, storage and RAM) and the monthly price shown in the **Order summary** panel. You can add one node per order.

4. Click <code className="action">Order</code> to add the node. The express order opens in a new tab of your browser, where you complete your order.

Once the node is delivered, it is listed on the **Nodes** tab with the **Not installed** badge in the **Installed OS** column: it is a new node to install.

{/* CP-STEPS-END:add-a-node */}

#### Install an OS

<Tabs>
  <Tab label="OVHcloud Console">
    {/* CP-STEPS-START:install-an-os */}

    Click the <code className="action">Nodes</code> tab to see the list of your nodes. For any node with the **Not installed** badge in the **Installed OS** column, click the `⋮` button in the **Actions** column and select <code className="action">Install</code>.

    The **Install node** window opens. Enter the configuration details for your node: its **AHV IP** and **CVM IP** addresses, and the AOS version in the **Version** field. Be sure to install the same AOS version as your cluster.

    Click <code className="action">Confirm</code>.

    {/* CP-STEPS-END:install-an-os */}
  </Tab>
  <Tab label="OVHcloud API">
    To install your node via the <ApiLink>OVHcloud API</ApiLink>, use this call:
    
    <Api version="v1" section="/nutanix" method="PUT" route={"/nutanix/\{serviceName\}/nodes/\{server\}/deploy"} />
  </Tab>
</Tabs>


Once the node has been installed, you can connect to Prism Central/Element and expand your cluster. 

Please refer to the documentation below: 

- [Expanding a Cluster through Prism Central](https://portal.nutanix.com/page/documents/details?targetId=Prism-Central-Guide-vpc_2024_3_1:mul-node-add-pc-t.html)
- [Expanding a Cluster](https://portal.nutanix.com/page/documents/details?targetId=Web-Console-Guide-Prism-v7_0:wc-cluster-expand-wc-t.html)

### Scale In (remove a node)

#### Power down a node

{/* CP-STEPS-START:power-down-a-node-1 */}

1. Navigate to your Nutanix cluster via the <code className="action">Nutanix</code> menu.

2. On the **Overview** tab, the **Number of nodes** row of the **General information** section shows the number of nodes in your subscription. Click the <code className="action">Nodes</code> tab to see the list of your nodes.

3. Here, you have 2 options:

{/* CP-STEPS-END:power-down-a-node-1 */}

<Tabs>
  <Tab label="OVHcloud Console">
    {/* CP-STEPS-START:power-down-a-node-2 */}

    For the node you wish to remove, click the `⋮` button in the **Actions** column and select <code className="action">Power off</code>.

    The **Power off node** window opens and asks you to confirm. Click <code className="action">Power off</code>.

    :::info
    Powering down a Nutanix node may impact your cluster. Please check the [requirements on the Nutanix portal](https://portal.nutanix.com/page/documents/list?type=software) to complete this action.

    :::

    {/* CP-STEPS-END:power-down-a-node-2 */}
  </Tab>
  <Tab label="OVHcloud API">
    You can also power down your node via the <ApiLink>OVHcloud API</ApiLink>.
    
    - Get the Boot ID (enter *power* as the **bootType**):
    
    <Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/boot"} />
    
    - Set the Boot ID: 
    
    <Api version="v1" section="/dedicated/server" method="PUT" route={"/dedicated/server/\{serviceName\}"} />
    
    - Power down the node:
    
    <Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/reboot"} />
  </Tab>
</Tabs>


#### Uninstall the node

<Tabs>
  <Tab label="OVHcloud Console">
    {/* CP-STEPS-START:uninstall-the-node */}

    Once the node is powered off, click the `⋮` button in the **Actions** column and select <code className="action">Uninstall</code>.

    The **Uninstall node** window opens. Type `UNINSTALL` in the field to confirm, then click <code className="action">Uninstall</code>.

    :::info
    Uninstalling a Nutanix node may impact your cluster. Please check the [requirements on the Nutanix portal](https://portal.nutanix.com/page/documents/list?type=software) to complete this action.

    :::

    {/* CP-STEPS-END:uninstall-the-node */}
  </Tab>
  <Tab label="OVHcloud API">
    To uninstall your node via the <ApiLink>OVHcloud API</ApiLink>, use this call:
    
    <Api version="v1" section="/nutanix" method="POST" route={"/nutanix/\{serviceName\}/nodes/\{server\}/terminate"} />
  </Tab>
</Tabs>


#### Remove the node

{/* CP-STEPS-START:remove-the-node */}

Once the node is uninstalled, click the `⋮` button in the **Actions** column and select <code className="action">Terminate</code>.

The **Terminate node** window opens. Click <code className="action">Confirm</code> to terminate the node.

:::info
Your suspended service will appear in your nodes list for approximately one week before being permanently deleted. This allows you to reactivate the service if you need to reverse the deletion.

:::

{/* CP-STEPS-END:remove-the-node */}
