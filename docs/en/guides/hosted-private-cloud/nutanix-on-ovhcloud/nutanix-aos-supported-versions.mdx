## Objective

**Find out which versions of Nutanix AOS are supported on OVHcloud Nutanix clusters.**

## Requirements

- a Nutanix Cluster in your OVHcloud account
- access to the <ApiLink>OVHcloud API page</ApiLink>

## Overview of versions supported on an OVHcloud Nutanix cluster

Nutanix defines the support duration of each AOS release in the *End of Support Life (EOSL) Policy* section of its [Nutanix Support Policies and FAQs](https://www.nutanix.com/support-services/support-policies-and-faqs#accordion-item-f3dfcd8c1f) page.

OVHcloud qualifies each new AOS release before it is supported on the **Nutanix on OVHcloud** product.

:::warning
You can use **LCM** to make remedial AOS updates.

During these updates, **LCM** may offer a new version that is not yet qualified by OVHcloud. Please wait for OVHcloud to validate it to continue receiving support.

:::


Qualified versions can be viewed through the OVHcloud API.

## Instructions

We will check the versions supported through the OVHcloud API.

For more details on how the OVHcloud API works, please refer to our guide on [Getting started with the OVHcloud APIs](/guides/manage-and-operate/api/first-steps)

Use the following API call:

<Api version="v1" section="/nutanix" method="GET" route={"/nutanix/\{serviceName\}"} />

Enter this data:

- **ServiceName:** `FQDN name of your Nutanix Cluster`.

Click <code className="action">Execute</code> to retrieve version information.

The `availableVersions` field of the query result lists the AOS versions supported on your OVHcloud Nutanix cluster.
