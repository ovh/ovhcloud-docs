## Objective

This guide introduces the three graphical interfaces you use to manage an **SNC Cloud Platform** project:

- the **Global Panel** (`SNC Admin Console`), the organisation-wide console;
- the **Regional Panel** (`SNC Cloud Console`), the operational console for one region and one project;
- **Horizon**, the native OpenStack dashboard for detailed resource management.

## Requirements

To follow this guide, you need:

- the **Organisation ID** and the credentials delivered with the service (username or email and password);
- a configured **multi-factor authentication** device for one-time codes;
- the **management URLs** provided at delivery.

If you only need programmatic access, you can also drive the platform with the **OpenStack CLI and APIs** using application credentials (see the [Horizon application credentials](#application-credentials) section).

## Instructions

### The three interfaces at a glance

| Interface | Role | Typical use |
|---|---|---|
| **Global Panel** | Organisation-wide console | Select the organisation, manage **projects** and **users**, open a project's Regional Panel |
| **Regional Panel** | Region/project operational console | Review services of the project (instances, volumes, networks, Object Storage…), open Horizon, get application credentials |
| **Horizon** | Native OpenStack dashboard | Detailed management of instances, volumes, images, networks and OpenStack identity, with the full quota view |

### Connect to the Global Panel

#### Organisation selection

Open the Global Panel URL. On first connection you are asked to identify your organisation.

<img className="thumbnail" alt="Global Panel organisation selection" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_organisation.png" loading="lazy" />

Enter your **Organisation ID** and click <code className="action">Go to login</code>.

#### Authentication

The next screen is the platform authentication page. Enter your **username or email** and your **password**.

<img className="thumbnail" alt="Global Panel authentication" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_login.png" loading="lazy" />

#### Multi-factor authentication

Multi-factor authentication is required: select the authenticator method you want to use and enter the **one-time code**.

<img className="thumbnail" alt="Global Panel multi-factor authentication" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_mfa.png" loading="lazy" />

:::info
If more than one authenticator is configured on your account, make sure you select the one that matches your device before entering the code.
:::

Once authenticated, you land on the Global Panel dashboard.

:::info
Session behaviour: depending on how the session was established, the Global Panel may return to the organisation selection screen after a period of inactivity. If this happens, simply re-select your organisation; the platform SSO may then let you continue without re-entering your credentials.
:::

### Discover the Global Panel

The dashboard gives an overview of the organisation: **projects** and **users**.

<img className="thumbnail" alt="Global Panel dashboard" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_dashboard.png" loading="lazy" />

From the left menu you can open **Project management** and **User management**.

#### Projects

The **Project management** menu lists the projects of the organisation. Each project is an isolated environment with its own permissions and quotas.

<img className="thumbnail" alt="Global Panel projects list" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_projects.png" loading="lazy" />

Open a project to access its detail page. This page shows the **Project ID** and gives access to the project's **regional console** through the <code className="action">Login</code> button.

<img className="thumbnail" alt="Global Panel project detail" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_project_detail.png" loading="lazy" />

#### Users

The **User management** menu lists the users of the organisation. Use the <code className="action">New user</code> button to open the user creation form.

<img className="thumbnail" alt="Global Panel create user form" src="/images/hosted-private-cloud/cloud-platform/getting-started/global_panel/global_panel_user_create.png" loading="lazy" />

### Discover the Regional Panel

The Regional Panel is the operational console of the selected project in one region. Open it from a project's <code className="action">Login</code> button in the Global Panel, or directly from the regional URL.

The dashboard lists the main services of the project and the API access and documentation section.

<img className="thumbnail" alt="Regional Panel dashboard" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_dashboard.png" loading="lazy" />

#### Instances

The **Instances** page lists the instances of the project with their status, flavor, IP addresses, attached volumes and networks.

<img className="thumbnail" alt="Regional Panel instances list" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_instances.png" loading="lazy" />

Use <code className="action">Create instance</code> to provision a new instance, or <code className="action">Open horizon</code> for advanced actions.

#### Block Storage

The **Block Storage** page lists the volumes of the project with their size, type, bootable flag, snapshots and the attached instance.

<img className="thumbnail" alt="Regional Panel block storage list" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_block_storage.png" loading="lazy" />

#### Private Networks

The **Private Networks** page lists the networks of the project, their address range, gateway, DHCP state and attached instances.

<img className="thumbnail" alt="Regional Panel private networks list" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_private_networks.png" loading="lazy" />

:::info
On this platform, public connectivity is provided through **direct ports on the shared external network**. Floating IPs and Neutron routers are not available on a standard project (the corresponding quotas are set to 0 and Horizon shows them as exhausted).
:::

#### Security groups

The **Security groups** page lists the security groups of the project and shows how they are connected to instances.

<img className="thumbnail" alt="Regional Panel security groups list" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_security_groups.png" loading="lazy" />

#### IP management

The **IP management** page shows the floating IP status of the project. When no floating IP is allocated, the page displays the *stealth mode* state.

<img className="thumbnail" alt="Regional Panel IP management" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_ip_management.png" loading="lazy" />

:::info
Because floating IPs are not available on this platform, the <code className="action">Allocate floating IP</code> action is not usable on a standard project. To publish a service on the Internet, attach a public port to the instance instead (see the [public IP management guide](/guides/hosted-private-cloud/cloud-platform/snc-cloud-platform-public-ip-management)).
:::

#### Object Storage

The **Object Storage** page gives the S3<sup>1</sup> connection details and the access keys of the project.

<img className="thumbnail" alt="Regional Panel object storage connection details" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_object_storage_connect.png" loading="lazy" />

The **Access Keys** tab lists the access keys of the project and lets you request a new one.

<img className="thumbnail" alt="Regional Panel object storage access keys" src="/images/hosted-private-cloud/cloud-platform/getting-started/regional_panel/regional_panel_object_storage_access_keys.png" loading="lazy" />

:::info
Bucket management is performed through the **S3 API/CLI** with an access key and its secret. The Regional Panel does not currently provide a buckets page.
:::

### Discover Horizon

Horizon is the native OpenStack dashboard. Open it with the <code className="action">Open horizon</code> button available on the Regional Panel pages, or directly from the Horizon URL of your region.

The left menu is organised in two parent sections:

- **Project**, which gathers the resources of the project (*API Access*, *Compute* with its *Overview*, *Instances*, *Images* and *Key Pairs* pages, *Volumes*, *Network*);
- **Identity**, which gathers the OpenStack identity resources (*Projects*, *Users*, *Application Credentials*).

#### API Access

The **API Access** page lists the OpenStack service endpoints of the platform.

<img className="thumbnail" alt="Horizon API access" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_api_access.png" loading="lazy" />

Use <code className="action">View Credentials</code> to display the user, project and authentication URL details of your session.

#### Compute

The **Compute** section gathers the project overview and the resources used to run instances.

##### Overview

The **Overview** page shows the quotas allocated to the project and their current usage.

<img className="thumbnail" alt="Horizon overview" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_overview.png" loading="lazy" />

It is split in two parts:

- **Limit Summary**: the quota allocated for each resource type (Compute, Volume, Network);
- **Usage Summary**: the usage history of the resources over a period of time.

##### Instances

The **Instances** page lists the instances with their image, IP address, flavor, key pair, status and actions.

<img className="thumbnail" alt="Horizon instances list" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_instances.png" loading="lazy" />

Use <code className="action">Launch Instance</code> to create an instance, or the row actions (for example <code className="action">Create Snapshot</code>) to operate on an existing one.

##### Images

The **Images** page lists the images available to create instances. You can also create a new image with <code className="action">Create Image</code>.

<img className="thumbnail" alt="Horizon images list" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_images.png" loading="lazy" />

##### Key Pairs

The **Key Pairs** page manages the SSH key pairs used to connect to your instances.

<img className="thumbnail" alt="Horizon key pairs list" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_key_pairs.png" loading="lazy" />

Use <code className="action">Create Key Pair</code> or <code className="action">Import Public Key</code> to register a key.

#### Volumes

The **Volumes** section manages the block storage volumes of the project.

<img className="thumbnail" alt="Horizon volumes list" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_volumes.png" loading="lazy" />

Use <code className="action">Create Volume</code> to add a volume, or the row actions (for example <code className="action">Edit Volume</code>) to operate on an existing one.

#### Network

The **Network** section manages the networks of the project.

##### Network Topology

The **Network Topology** page visualises the networks of the project and the instances attached to them.

<img className="thumbnail" alt="Horizon network topology" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_network_topology_graph.png" loading="lazy" />

Use the <code className="action">Topology</code>/<code className="action">Graph</code> tabs to switch between the labelled view and the graph view.

##### Networks

The **Networks** page lists the networks of the project, their associated subnets and their state.

<img className="thumbnail" alt="Horizon networks list" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_networks.png" loading="lazy" />

:::info
The external network of the project is shared and comes from the public connectivity order. It is not created from Horizon.
:::

#### Identity

The **Identity** section manages the OpenStack identity resources of the project.

##### Application Credentials

The **Application Credentials** page manages the credentials used by the **OpenStack CLI and APIs**.

<img className="thumbnail" alt="Horizon application credentials" src="/images/hosted-private-cloud/cloud-platform/getting-started/horizon/horizon_application_credentials.png" loading="lazy" />

Use <code className="action">Create Application Credential</code> to create one, then download its `clouds.yaml` file from the confirmation window: the secret is shown only once.
