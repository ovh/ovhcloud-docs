## Objective

vSphere client user permissions and passwords are managed from the OVHcloud Console.

**Learn how to change your user password**

## Requirements

- access to the <ManagerLink console to="/">OVHcloud Console</ManagerLink>
- a user account created from the OVHcloud Console (see [Managing your Hosted Private Cloud in the OVHcloud Console](/guides/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud#users))

[[cpnav:privatecloud-vmware-vsphere-console|en]]

## Instructions

### Change Password

{/* CP-STEPS-START:change-password */}

In the OVHcloud Console, go to **Private Cloud** › **Managed VMware vSphere** and select your service from the list. Click the <code className="action">Users</code> tab.

Open the ⋮ menu (**Actions** column) of the user concerned and click <code className="action">Change password</code>.

In the **Change password** window, enter a new password in the **New password** field, confirm it in the **Confirm password** field, then click <code className="action">Confirm</code>.

:::info
If you do not enter a password, a randomly generated password will be emailed to the user's associated address.

:::

On a service with a certified compliance option (PCI DSS, HDS…), the window shows no form: it gives the address of the certified interface (`https://<your-service>/secure`), where you change the password.

{/* CP-STEPS-END:change-password */}

:::warning
We recommend that you follow these few best practices to ensure that your infrastructure is not compromised. Your password must:

- Have at least 8 characters.
- Have at least 3 character types.
- Not to be drawn from the dictionary.
- Not include personal information.
- Not be used for multiple access.
- Be stored in a password vault.
- Be changed every 3 months.
- Be different from previous passwords.

:::
