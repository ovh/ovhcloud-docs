## Objective

IP blocks can be used to make your services accessible online. 

**This guide will explain how to order, add and migrate an IP block linked to your Hosted Private Cloud.**

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://www.ovhcloud.com/en-gb/enterprise/products/hosted-private-cloud/) to receive login credentials
- A user account with access to vSphere (created in the <ManagerLink console to="/">OVHcloud Console</ManagerLink>)

[[cpnav:network-public-ip-console]]

## Instructions

### Order an IP block

{/* CP-STEPS-START:order-ip-block */}

To order an IP block for your **Hosted Private Cloud**, open your service in the OVHcloud Console (**Private Cloud** › **Managed VMware vSphere**, then your service). On the **Dashboard** tab, in the **Options** section, open the ⋮ menu of the **Number of IP blocks** row and click <code className="action">Order IP blocks</code>. The same order page is also available from **Network** › **IP addresses**: click <code className="action">Order an IP</code>, then <code className="action">Order an Additional IP</code>.

On the **Order an IP** page, fill in the following sections to create your IP block:

- **Select the IP address type**: choose **IPv4**.
- **Select the service to assign the Additional IP to**: select your **Hosted Private Cloud** service. The region is then determined automatically from the selected service.
- **Select an offer**: choose the size of the IP block (from /28 to /24).

:::info
As a reminder, here is a table listing the number of IPs present in a block, and the number of usable IPs.

:::


|Block size|IPs in the block|IPs usable with OVHcloud|
|:---:|:---:|:---:|
|28|16|11|
|27|32|27|
|26|64|59|
|25|128|123|
|24|256|251|

:::info
Please feel free to refer to our guide on the [OVHcloud Network plugin](/guides/hosted-private-cloud/powered-by-vmware/plugin-ovh-network) to find out which IPs are reserved for your block, as well as how they are used.

:::


- **Select a geolocation**: choose the country of the IP block. The country an IP block is hosted in is important in some cases, for your services' SEO ranking (a website based in France will have a higher SEO ranking in France if the IP address is French, too).

The network name and description visible in the WHOIS profile for the IP block are no longer requested when you order: you can edit the network name from the **IP addresses** page once the block is delivered.

:::tip
There is a one time setup fee for an IP block that will be due before delivery.

:::


Check the **Summary**, then click <code className="action">Order</code>. The purchase order for your IP block opens in a new tab. If everything looks correct in the purchase order, you will simply need to pay the total using one of the payment methods offered, and your order will then be delivered.

{/* CP-STEPS-END:order-ip-block */}

### Migrate an IP block between two Hosted Private Cloud solutions

<iframe className="video" width="560" height="315" src="https://www.youtube-nocookie.com/embed/Gemao3Fd7rI" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen={true}></iframe>

To migrate an IP block, you will need to move the blocks manually via the OVHcloud APIv6.

Use the following API call:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/move"} />

You will need to fill in the fields as follows:

- ip: IP block with the /mask
- nexthop “newPrimaryIp” (case-sensitive)
- to: Target Hosted Private Cloud in the following form: pcc-XXX-XXX-XXX-XXX

The result should look like this:

```json
{
  "function": "genericMoveFloatingIp",
  "status": "todo",
  "taskId": 178970672
}
```

If you need to detach the IP block, you can use the following API call to move the IP into the "IP parking" section:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/park"} />


:::warning
This call cuts the network on the VMs that use the IPs concerned.

:::


{/* CP-STEPS-START:migrate-ip-block */}

You can also move the block from the OVHcloud Console: on your service's **Dashboard** tab, in the **Options** section, open the ⋮ menu of the **Number of IP blocks** row and click <code className="action">Link IP blocks to another service</code>.

You can track the movement of your IP block in the **Managed VMware vSphere** section. Click on your Hosted Private Cloud service, then on the <code className="action">Operations</code> tab.

The operation reference is “removeIpRipeBlock”.

The IP will then appear in the **IP addresses** list (**Network** › **IP addresses**) with the type **IP Parking**.

{/* CP-STEPS-END:migrate-ip-block */}
