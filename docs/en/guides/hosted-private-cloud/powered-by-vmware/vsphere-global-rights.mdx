## Objective

Global vSphere permissions allow you to define a user's rights on your Hosted Private Cloud service. From the OVHcloud Control Panel, you can enable or disable these options for each user using checkboxes.

This guide explains how to manage these global permissions from the OVHcloud Manager.

## Requirements

- An active [Hosted Private Cloud service](https://www.ovhcloud.com/en/hosted-private-cloud/vmware/)
- A [vSphere user](/guides/hosted-private-cloud/powered-by-vmware/vsphere-interface-connexion) already created on your service
- Access to the <ManagerLink to="/">OVHcloud Control Panel</ManagerLink> with sufficient rights to manage users

## Instructions

### Access the user rights management

1. Open the <ManagerLink to="/">OVHcloud Control Panel</ManagerLink>. Click <code className="action">Hosted Private Cloud</code> in the top bar, then click <code className="action">Managed VMware vSphere</code> in the left-hand menu, and select your PCC service.

2. Go to the <code className="action">Users</code> tab.

	<img className="thumbnail" alt="Users tab" src="/images/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud/en05users.png" loading="lazy" />

3. On the row of the relevant user, open the <code className="action">...</code> menu and click <code className="action">Edit</code>.

### Configure global permissions

1. In the user edit window, several checkboxes correspond to the global permissions.

2. Tick or untick the options according to the rights you want to grant to the user.

	<img className="thumbnail" alt="User rights edit window" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/user-global-rights.png" loading="lazy" />

3. Confirm the change.

### Available permissions

The global permissions are represented by the following checkboxes in the user edit window:

| Permission | Description |
|---|---|
| Token validator | Enables the validation token for the user, allowing authentication to the OVHcloud API. |
| Ip | Restricts the user's access to specific IP addresses. |
| Ip Failover | Allows the user to manage the IP Failover addresses associated with the service. |
| Interface NSX | Grants access to the NSX network management interface. |
| Encryption management | Allows the user to manage virtual machine encryption (KMS). |

### Going further with granular rights

The global permissions described above apply at the Hosted Private Cloud vSphere inventory level, in other words at the VMware cluster level considered.

If you need to grant a user access only to specific objects in the vSphere inventory, for example a virtual machine, a datastore or a folder, you must use the [granular rights on vSphere objects](/guides/hosted-private-cloud/powered-by-vmware/vsphere-granular-rights).
