## Objective

**This guide details how to create or modify a global IAM policy and add a vSphere role**.

## Requirements

- An [OVHcloud account](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- One or more Hosted Private Cloud products - VMware on OVHcloud linked to this account (Hosted Private Cloud powered by VMware, VMware Service Pack).
- IAM enabled for your Hosted Private Cloud service - VMware on OVHcloud. Follow the steps in the guide [IAM for VMware on OVHcloud - How to enable IAM](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-activation).

[[cpnav:iam-policies]]

## Instructions

### Creating or editing a policy

{/* CP-STEPS-START:create-edit-policy */}

<img className="thumbnail" alt="My policies page of the OVHcloud Console, with the Create a policy button" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role-policy/console/iam_role_policy_9.png" loading="lazy" />

Click <code className="action">Create a policy</code>.

To edit a policy, click the <code className="action">⋮</code> button in the **Actions** column, to the right of the policy concerned, then <code className="action">Edit policy</code>.

<img className="thumbnail" alt="Product types section with VMware on OVHcloud and a vSphere service selected" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role-policy/console/iam_role_policy_10.png" loading="lazy" />

The policy form has five sections: **Policy information**, **Identities**, **Product types**, **Conditions** and **Actions**, with a **Summary** section on the right. Enter the requested settings:

- **Name**, in the **Policy information** section: Choose a name. It can contain letters, digits and the characters `-`, `/`, `_` and `+` only.
- **Description**, in the same section: Enter a description for your policy.
- **Identities** (mandatory): Select the identities concerned by your policy, in the **Users**, **Groups**, **Service accounts** and **Other OVHcloud accounts** tabs.
- **Product types**: Select <code className="action">VMware on OVHcloud</code> / <code className="action">Vmware Service Pack</code>.
- **Resources**, in the **Product types** section: Add the resources concerned by your policy (**pcc-XX-XX-XX-XX/servicepack**, **pcc-XX-XX-XX-XX.ovh.com (pccVMware)**, etc.).
- **Actions**: This is where you add your role (see below).

{/* CP-STEPS-END:create-edit-policy */}

#### Adding an IAM role to a global policy

When enabling IAM in vSphere, two roles are added by default (`iam-admin`, `iam-auditor`).

{/* CP-STEPS-START:add-iam-role-global-policy */}

Copy the roles from the code section below, paste them into the **Manually add actions** field in the **Actions** section, then click the <code className="action">Add</code> button.

```bash
pccVMware:vSphere:assumeRole?iam-admin
pccVMware:vSphere:assumeRole?iam-auditor
```

If you have created an additional IAM role (after following the steps in the guide "[IAM for VMware on OVHcloud - How to create an IAM vSphere role](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-role)"), you can also add it by copying the code below and adapting it to your role:

```bash
pccVMware:vSphere:assumeRole?{role_name}
```

<img className="thumbnail" alt="Actions section with an assumeRole action typed in the Manually add actions field" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role-policy/console/iam_role_policy_11.png" loading="lazy" />

Be sure to click the <code className="action">Add</code> button to add the action.

Finally, click <code className="action">Create</code> at the bottom of the form, or <code className="action">Create a policy</code> in the **Summary** section on the right. If you are editing a policy, click <code className="action">Save</code>, or <code className="action">Edit policy</code> in the **Summary** section.

{/* CP-STEPS-END:add-iam-role-global-policy */}
