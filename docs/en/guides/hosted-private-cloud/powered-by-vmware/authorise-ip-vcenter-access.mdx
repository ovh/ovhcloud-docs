## Objective

Access to your vCenter is restricted only to authorized IP addresses.

**This guide explains how to authorise IP addresses for vCenter access in the OVHcloud Console.**

## Requirements

- a [Hosted Private Cloud infrastructure](https://www.ovhcloud.com/en-gb/enterprise/products/hosted-private-cloud/)
- access to the <ManagerLink console to="/">OVHcloud Console</ManagerLink>

[[cpnav:privatecloud-vmware-vsphere-console|en]]

## Instructions

{/* CP-STEPS-START:authorise-ip */}

Select your service from the list by clicking its name, then click the <code className="action">Access control</code> tab.

In the section listing the IPs and blocks authorised to connect, click <code className="action">Associate an IP block</code>.

In the **Add a security rule** window, enter an IP address (range) that should be allowed access, or click <code className="action">Use my current IP address</code> to fill in the address you are connecting from. You can also add a description to make the list of authorised IPs easier to organise.

Click <code className="action">Next</code> when you have filled in the fields, then click <code className="action">Confirm</code> to apply your changes. Once the IP address shows **Authorised and set up** in the **Right** column, connections from it are possible.

{/* CP-STEPS-END:authorise-ip */}

:::info
Please note that for security reasons, you will only be able to allow a maximum of 2048 IP addresses to connect to your vCenter.

:::
