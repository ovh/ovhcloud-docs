## Objective

This guide explains how to configure encrypted backup jobs using the Veeam backup solution and the OVHcloud Key Management Service (OKMS).

## Requirements

- Access to the <ManagerLink console to="/">OVHcloud Console</ManagerLink>.
- A [VMware on OVHcloud](/links/hosted-private-cloud/vmware) offer.
- Read the following guides: 
    - [Integrating a KMS with VMware on OVHcloud](/guides/hosted-private-cloud/powered-by-vmware/vmware-overall-vm-encrypt).
    - [Getting started with OKMS](/guides/manage-and-operate/kms/quick-start).

## Instructions

### Step 1: Create a certificate in OKMS

You can create your access certificate in OKMS using either the <ApiLink>OVHcloud API</ApiLink> or the <ManagerLink console to="/">OVHcloud Console</ManagerLink>.

#### Option 1: Using the API

1. Generate the private key using the API (no CSR):

    <Api version="v2" section="/okms" method="POST" route={"/okms/resource/\\{okmsId\\}/credential"} />

2. Retrieve the certificate using a GET request:

    <Api version="v2" section="/okms" method="GET" route={"/okms/resource/\\{okmsId\\}/credential"} />

    {/* CP-STEPS-START:control-panel-equivalent */}

    :::info
    This method is equivalent to selecting **I don't have a private key** in the OVHcloud Console.
    You may also submit a CSR if you already have your own private key.

    :::

    {/* CP-STEPS-END:control-panel-equivalent */}

3. Download the private key.

4. Download the certificate.

    :::info
    The downloaded private key is used to generate the `.pfx` file in the next step.
    You don't need to import it manually into Veeam, but it is required to convert the certificate into a compatible format.
    Make sure to store it securely.

    :::

#### Option 2: Using the <ManagerLink console to="/">OVHcloud Console</ManagerLink>

{/* CP-STEPS-START:using-control-panel */}

1. In the OVHcloud Console, go to **Security** › **Key & Secret Manager**. The page opens on your last OKMS domain.

2. Select your KMS: if needed, choose it from the **OKMS domain** selector at the top of the page.

3. Open the <code className="action">Access certificates</code> tab.

4. Click <code className="action">Create an access certificate</code>.

5. Fill in the **General information** fields (**Display name**, **Description**) and the **Validity** of the certificate (1 month by default), then, under **Creation method**, select **I don't have a private key**.

    :::info
    This is the same as generating a certificate without a CSR, like with the API.
    You can also choose **I already have a private key** to generate a certificate using your own CSR.

    :::

6. Add user IDs to the certificate, in the **Add user IDs** section of the same page:
    - Select **Choose identities**
    - Tick the authorized users in the **Users**, **User groups** or **Service accounts** tabs
    - Click <code className="action">Create</code> to create the certificate with these identities

    :::info
    This step is required for the certificate to work with Veeam.

    :::

7. Download the private key and the certificate: on the page displayed after the creation, click <code className="action">Download private key</code>, tick **I have downloaded the private key**, then click <code className="action">Finish</code>.

    The certificate can be downloaded at any time from its row in the **Access certificates** tab, with the **Download certificate** action.

{/* CP-STEPS-END:using-control-panel */}

### Step 2: Convert the PEM certificate to PFX format

To import the certificate into Veeam, convert it to `.pfx` format using the command below:

```bash
openssl pkcs12 -export -out cert.pfx -inkey privatekey.pem -in certificate.pem
```

### Step 3: Import the certificate into the Veeam Windows Certificate Store

- Open the Windows Certificate Store on your Veeam server.
- Import the `.pfx` file generated in the previous step.
- Check the option to make the certificate exportable.

<img className="thumbnail" alt="Import Certificate - Exportable" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_4.png" loading="lazy" />

### Step 4: Register the KMS in Veeam

- Open Veeam Backup & Replication and go to <code className="action">Credentials & Passwords</code>, then click <code className="action">Key Management Servers</code>.

<img className="thumbnail" alt="Veeam Key Management Servers" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_5.png" loading="lazy" />

- Click <code className="action">Add</code> to add a new KMS server.

<img className="thumbnail" alt="Add KMS Server" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_6.png" loading="lazy" />

- Enter the following details:
    - Server address: `eu-west-rbx.okms.ovh.net`
    - Port: `5696`
    - Server certificate: `*.okms.ovh.net`
    - Client certificate: the `.pfx` file you just imported

<img className="thumbnail" alt="Add KMS Server Details" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_7.png" loading="lazy" />

### Step 5: Retrieve the server certificate

To retrieve the server certificate from OKMS, run the following command:

```bash
openssl s_client -connect eu-west-rbx.okms.ovh.net:443 2>/dev/null </dev/null | sed -ne '/-BEGIN CERTIFICATE-/,/-END CERTIFICATE-/p'
```

### Step 6: Configure backup job encryption

- Register the KMS server in your Veeam Backup & Replication console.
- Select the desired backup job and enable encryption using the registered KMS.

<img className="thumbnail" alt="Configure Backup Encryption" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_8.png" loading="lazy" />

- Once the backup has run, a padlock icon appears next to its name.

<img className="thumbnail" alt="Encrypted Backup" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_9.png" loading="lazy" />

- If you encounter the error `Unsupported attribute: OPERATION_POLICY_NAME`, check the documentation or contact support.

<img className="thumbnail" alt="Operation Policy Name Error" src="/images/hosted-private-cloud/powered-by-vmware/veeam-encrypt-backup-job-with-okms/veeam_okms_10.png" loading="lazy" />
