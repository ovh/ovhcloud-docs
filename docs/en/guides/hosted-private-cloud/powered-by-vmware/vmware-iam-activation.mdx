## Objective

**This guide details how to activate IAM with Hosted Private Cloud - VMware on OVHcloud via the OVHcloud Console or with the OVHcloud API**.

## Requirements

- An [OVHcloud account](/guides/account-and-service-management/account-information/ovhcloud-account-creation)
- One or more Hosted Private Cloud - VMware on OVHcloud products linked to this account (Hosted Private Cloud powered by VMware, VMware Service Pack).

[[cpnav:privatecloud-vmware-vsphere-console]]

## Instructions

### Enabling IAM

:::info
This may take up to 30 minutes.

:::


### Via the OVHcloud Console

{/* CP-STEPS-START:enable-iam-control-panel */}

Select your infrastructure, then go to the <code className="action">Users</code> tab.

In the **OVHcloud IAM** section at the bottom of the tab, click <code className="action">Enable OVHcloud IAM</code>.

<img className="thumbnail" alt="OVHcloud IAM section with the Disabled status and the Enable OVHcloud IAM link" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_2.png" loading="lazy" />

:::warning
Only the vSphere product is integrated with OVHcloud IAM. An infrastructure with enhanced security options or a certified service (HDS, PCI-DSS or SNC) cannot currently use OVHcloud IAM. If you enable one of these certified options or services later, you will need to disable OVHcloud IAM.
:::

In the **Enable OVHcloud IAM** window that opens, click <code className="action">Confirm</code>.

:::tip
Once IAM is enabled, its status will be `Enabled` and green.

:::

<img className="thumbnail" alt="Users tab with the OVHcloud IAM section showing the Enabled status" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_3.png" loading="lazy" />

{/* CP-STEPS-END:enable-iam-control-panel */}

### Via the OVHcloud API

:::tip
Read the guide [Getting started with OVHcloud APIs](/guides/manage-and-operate/api/first-steps) to get familiar with using OVHcloud APIv6.

:::


:::warning
Make sure to replace the `serviceName` with the reference of your Hosted Private Cloud service, in the form `pcc-XXX-XXX-XXX-XXX`.

:::


To enable the IAM option, execute the following API call:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/enable"} />


#### Checking that IAM is enabled

To control IAM activation, execute the following API call:

<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\{serviceName\}/iam"} />

API return:

```shell
{
  "state": "enabled",
  "identityProviderId": 275
}
```
