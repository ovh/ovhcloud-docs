## Objective

You can associate a name, first name, phone number, and email address with a vSphere user in your Private Cloud. The email address allows validation by token.

**Learn how to associate an email address with your vSphere user.**

## Requirements

- a [Hosted Private Cloud infrastructure](https://www.ovhcloud.com/en-gb/enterprise/products/hosted-private-cloud/)

[[cpnav:privatecloud-vmware-vsphere-console]]

## Instructions

{/* CP-STEPS-START:associate-email-user */}

Select your infrastructure.

Go to the <code className="action">Users</code> tab, open the ⋮ menu (**Actions** column) of the user concerned, then click <code className="action">Edit</code>.

The **Edit** window opens. You can set your name, first name, phone number and email address.

This window also allows you to grant the **Token validator**, **IP**, **Failover IP** and **Encryption management** permissions. The **Token validator** permission is used to approve certain sensitive actions on infrastructures that have the **Advanced Security** option enabled.

Click <code className="action">Save</code> to validate the modifications.
