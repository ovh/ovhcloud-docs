## Objective

**This guide will show you how to log in to your managed vSphere Web interface from the OVHcloud Console.**

## Requirements

- You must be the administrator of the [Hosted Private Cloud - managed vSphere](https://www.ovhcloud.com/en-gb/hosted-private-cloud/vmware/) infrastructure.
- IP addresses added in the <code className="action">Access control</code> tab of your service in the <ManagerLink console to="/">OVHcloud Console</ManagerLink>. For more information, please read our guide on [Authorizing IPs to connect to vCenter](/guides/hosted-private-cloud/powered-by-vmware/authorise-ip-vcenter-access).

To use IAM, you must enable the feature in order to delegate rights management with a role. Please read the guides:

- Guide 1: [IAM for VMware on OVHcloud - Introduction and FAQ](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-getting-started)
- Guide 2: [IAM for VMware on OVHcloud - How to enable IAM](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-activation)
- Guide 3: [IAM for VMware on OVHcloud - How to create an IAM vSphere role](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-role)

## Instructions

To log in to the managed vSphere Web interface, you need OVHcloud login credentials. It can be either a vSphere user (with a local user), or a vSphere rôle (with IAM).

### Step 1 - Users management with vSphere and OVHcloud

#### From the OVHcloud Console

{/* CP-STEPS-START:manage-users-control-panel */}

You can manage your login credentials via the OVHcloud Console for your VMware product managed on OVHcloud.

Your VMware environments are listed on the **Managed VMware vSphere** page (**Private Cloud** › **Managed VMware vSphere**). Select your infrastructure, then go to the <code className="action">Users</code> tab.

The users are listed under **Manage user permissions in the vSphere client**, at the top of the tab.

To create a user, click <code className="action">Create User</code>. To modify a user, open the ⋮ menu (**Actions** column) of the user and click <code className="action">Edit</code>.

From the same menu, you can also modify the permissions per DC (<code className="action">View/Edit the rights for each DC</code>), change the password (<code className="action">Change password</code>) or delete the user (<code className="action">Delete this user</code>). When OVHcloud IAM is enabled, IAM roles are listed in the same table and managed the same way.

{/* CP-STEPS-END:manage-users-control-panel */}

#### From the OVHcloud API

You can manage users via the OVHcloud API.

:::info
If you are not familiar with using the OVHcloud API, please refer to our guide on [Getting started with the OVHcloud API](/guides/manage-and-operate/api/first-steps).

:::


Here are some examples of API calls:

- Creating a user:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/user"} />


> **Parameters**:
>
> - `serviceName`: your service in the form of pcc-XX-XX-XX-XX.
> - `name`: the name of your user in the form below.
>

**Example**:

```shell
{
"name": "User name"
}
```

- Changing a user password:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/user/\{userId\}/changePassword"} />


> **Parameters**:
>
> - `serviceName`: your service in the form of pcc-XX-XX-XX-XX.
> - `userId`: the ID of your user in the form XXXXX.

**Example**:

```shell
{
"password": "XXX"
}
```
