## Objective

This guide lists all the supported advanced parameters that allow you to configure your Public Cloud Databases for OpenSearch according to your use cases.

## Requirements

- A [Public Cloud project](/links/public-cloud/public-cloud) in your OVHcloud account   
- An OpenSearch service running on your OVHcloud Public Cloud project ([this guide](/guides/public-cloud/data-analytics/analytics/getting-started) can help you to meet this requirement)   
- Access to your <ManagerLink to="/">OVHcloud Control Panel</ManagerLink> or to the <ApiLink>OVHcloud API</ApiLink>   

## Instructions

:::warning
Advanced parameters can also be managed with Terraform, through the `advanced_configuration` argument (key/value pairs) of the [`ovh_cloud_project_database`](https://registry.terraform.io/providers/ovh/ovh/latest/docs/resources/cloud_project_database) resource.

:::

:::info
Changing the advanced configuration may cause the service to restart.

:::

### Using the OVHcloud Control Panel

Please refer to this [guide](/guides/public-cloud/data-analytics/analytics/advanced-configuration#using-the-ovhcloud-control-panel) to find out how to change your advanced parameters from the OVHcloud Control Panel.

### Using API

Please refer to this [guide](/guides/public-cloud/data-analytics/analytics/advanced-configuration#using-api) to find out how to change your advanced parameters from the OVHcloud API.
