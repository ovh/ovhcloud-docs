## Objective

This page shows you how to update your Valkey service user ACLs with the OVHcloud API.

## Users and roles

As explained on this page: [Valkey Capabilities, Users & roles](/guides/public-cloud/databases/redis-capabilities#users-and-roles), the users' ACLs cannot be updated via the OVHcloud Control Panel.

You must therefore use the [OVHcloud API](/guides/manage-and-operate/api/first-steps).

## Requirements

- A [Public Cloud project](https://www.ovhcloud.com/en-gb/public-cloud/) in your OVHcloud account.
- An up and running Public Cloud Database for Valkey.

If you have never used the OVHcloud API before, then follow this tutorial: [First Steps with the OVHcloud APIs](/guides/manage-and-operate/api/first-steps).

For this tutorial, we use the <ApiLink>OVHcloud API</ApiLink>.

## Instructions

### Get your service, Valkey cluster and user IDs

You first need to identify the service, the Valkey cluster and the user you want to apply the changes to.

#### Get the desired service ID

Execute the following API call:

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project"} />


From the resulting list, select and copy the service identifier corresponding to the desired service, also known as **serviceName**.

Example response:

```json
[
  "702de32b692c4842b0bb751dc5085daf"
]
```

#### Get the cluster ID

Open the following API call, paste your service ID into the **serviceName** input field and click <code className="action">Execute</code>:

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/redis"} />


From the resulting list, select and copy the cluster ID, also known as **clusterId**.

Example response:

```json
[
  "aaaaaaaa-1234-56ab-78cd-123456abcdef"
]
```

#### Get the desired user ID

Open the following API call and do the following steps:

- paste your service ID into the **serviceName** input field
- paste the cluster ID into the **clusterId** input field
- click <code className="action">Execute</code>

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/redis/\{clusterId\}/user"} />


From the resulting list, find and select the desired **user**.

Example response:

```json
[
  "be794937-1234-5678-90ab-9e3e7be21456",
  "63458577-1234-5678-90ab-20376726c018",
  "7510d64a-1234-5678-90ab-d382033bed25"
]
```

To get more details on a user, open the following API call and do the following steps:

- paste your service ID into the **serviceName** input field
- the user ID into the **userId** input field
- the cluster ID into the **clusterId** input field
- click <code className="action">Execute</code>

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/redis/\{clusterId\}/user/\{userId\}"} />


Example:

```json
{
  "createdAt": "2022-03-07T16:33:28.607868+01:00",
  "id": "be794937-1234-5678-90ab-9e3e7be21456",
  "status": "READY",
  "username": "ro-user",
  "keys": ["*.*"],
  "categories": [],
  "commands": ["+get", "-set"],
  "channels": ["*"]
}
```

The result shows four string arrays, which represent the ACLs defined for the given user.

- Keys: Allow and disallow certain keys and key permissions.
- Categories: Add all the commands in such category to be called by the user, with valid categories being like @admin, @set, @sortedset,...
- Commands: Add or remove the command to the list of commands the user can call.
- Channels: Allow and disallow Pub/Sub channels.

You can follow the official Redis® documentation about users and ACL: [https://redis.io/topics/acl](https://redis.io/topics/acl).

### Update an ACL with the API

Open the following API call and paste the corresponding inputs (**serviceName**, **clusterId**, **user**).

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/redis/\{clusterId\}/user/\{userId\}"} />


Now, according to the strategy you chose, set the different values into the string arrays of the *request body*, such as in the example below:

```json
{
  "categories": [],
  "channels": ["*"],
  "commands": ["+get", "-set"],
  "keys": ["datas", "properties"]
}
```

When ready, click <code className="action">Execute</code> to update the ACL.

The result should be displayed similarly to the example below.

```json
{
  "createdAt": "2022-03-07T16:33:28.607868+01:00",
  "id": "be794937-1234-5678-90ab-9e3e7be21456",
  "status": "READY",
  "username": "ro-user",
  "keys": ["datas", "properties"],
  "categories": [],
  "commands": ["+get", "-set"],
  "channels": ["*"]
}
```
