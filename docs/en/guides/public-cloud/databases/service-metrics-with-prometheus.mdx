## Objective

Public Cloud databases allow you to export service metrics using Prometheus.

**This guide explains how to setup a Prometheus exporter for your Public Cloud databases service so that a Prometheus server can collect metrics.**

## Requirements

- A [Public Cloud databases service](/links/public-cloud/databases) up and running,
- Access to the <ManagerLink to="/">OVHcloud Console</ManagerLink> or to the <ApiLink>OVHcloud API</ApiLink>,
- A [Prometheus](https://prometheus.io) server to collect metrics.

## Instructions

### Enable the Prometheus exporter for your service

<Tabs>
  <Tab label="Via the OVHcloud Console">
    In the left-hand menu of your Public Cloud project, click your engine under **Databases**, then click the name of your service.
    
    Open the <code className="action">Configuration</code> tab and locate the **Prometheus integration** section (the <code className="action">Configure</code> link of the Prometheus block in the <code className="action">Observability</code> tab leads to the same place). Click <code className="action">Enable Prometheus</code>.
    
    Enabling it may take a few minutes. Once ready, the credentials and endpoint appear in the section.
    
    To stop the exporter later, click <code className="action">Disable Prometheus</code> in the same section, then <code className="action">Confirm</code>.
  </Tab>
  <Tab label="Via the OVHcloud API">
    You can enable a Prometheus exporter for your service using the API endpoint:
    
    <Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/database/mysql/\{clusterId\}"} />
    
    Replace `mysql` in the route with your service's engine (for example `postgresql` or `mongodb`).
    
    The boolean property `enablePrometheus` should be set to `true` to activate the Prometheus exporter for your service.
  </Tab>
</Tabs>

### Retrieve the Prometheus exporter access info

<Tabs>
  <Tab label="Via the OVHcloud Console">
    In the **Prometheus integration** section of the <code className="action">Configuration</code> tab, copy the access information:
    
    - **Username**;
    - for MongoDB, the **SRV domain**, which resolves to the nodes of the cluster;
    - for the other engines, the **Host** and **Port** of each node: when the cluster has several nodes, select the node in the **Prometheus target** list to display its host and port.
    
    To obtain the password, click <code className="action">Reset password</code>, then <code className="action">Confirm</code>. A new password is generated and the current one stops working immediately. Copy it right away: it cannot be shown again.
  </Tab>
  <Tab label="Via the OVHcloud API">
    Use the following API endpoint to get the data needed to access the Prometheus exporter:
    
    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/mysql/\{clusterId\}/prometheus"} />
    
    You will also need to reset the credentials in order to obtain the password required for access:
    
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\{serviceName\}/database/mysql/\{clusterId\}/prometheus/credentials/reset"} />
  </Tab>
</Tabs>


### Configure your Prometheus server and start pulling metrics

Use the data from the previous state to configure your Prometheus server and start pulling metrics for your service. Here is an example of such a Prometheus configuration for a MongoDB service:

```yaml
scrape_configs:
- job_name: mongo-metrics
  scrape_interval: 10s
  metrics_path: /metrics
  scheme : https
  basic_auth:
    username: prometheus
    password: "xxx"
  dns_sd_configs:
    - names:
      - '_prometheus._tcp.mongodb-7bfb5d40-oa85dff3e.database.cloud.ovh.net' 
```

The other engines use a slightly different format:

```yaml
scrape_configs:
- job_name: postgresql-metrics
  scrape_interval: 10s
  metrics_path: /metrics
  scheme : https
  basic_auth:
    username: prometheus
    password: "xxx"
  tls_config:
      insecure_skip_verify: true
  static_configs:
    - targets: 
        - postgresql-02d6a757-ovh-dev.database.cloud.ovh.net:9273
        - replica-postgresql-02d6a757-ovh-dev.database.cloud.ovh.net:9273
```

## Limitations

Public Cloud Databases offer service metrics via Prometheus for the following engines:

- Valkey
- MongoDB
- MySQL
- PostgreSQL

Prometheus endpoints are subject to the same networking limitations the associated service is. Thus, IP restrictions apply, and for services using private networking, the Prometheus exporter endpoint is only reachable from the private network your service is attached to.
