## Objective

This page lists all the connectors available on OVHcloud Managed Kafka Connect. You can browse them before deploying a cluster.

Source connectors ingest data from external systems into Kafka topics. Sink connectors export data from Kafka topics to external destinations.

## Listing the connectors of your service with the API

This list was checked on a Kafka Connect 4.3 service. To get the connectors available on your own service, with their identifier, type and version, use the following API calls:

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/kafkaConnect/\{clusterId\}/capabilities/connector"} />

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/kafkaConnect/\{clusterId\}/capabilities/connector/\{connectorId\}"} />

See the [Kafka Connect guide](/guides/public-cloud/data-analytics/analytics/kafkaconnect-create-connector) to create a connector.
