## Objective

This page lists all the connectors available on OVHcloud Managed Kafka Connect. You can browse them before deploying a cluster.

Source connectors ingest data from external systems into Kafka topics. Sink connectors export data from Kafka topics to external destinations.

## Source connectors

- Aiven - Amazon AWS S3 source
- Azure Blob Storage source
- [Couchbase Source](https://github.com/couchbase/kafka-connect-couchbase)
- [Debezium - MongoDB](https://debezium.io/docs/connectors/mongodb/)
- [Debezium - MySQL](https://debezium.io/docs/connectors/mysql/)
- [Debezium - Oracle](https://debezium.io/docs/connectors/oracle/)
- [Debezium - PostgreSQL](https://debezium.io/docs/connectors/postgresql/)
- [Debezium - SQL Server](https://debezium.io/docs/connectors/sqlserver/)
- [Google Cloud Pub/Sub Lite Source](https://github.com/googleapis/java-pubsub-group-kafka-connector)
- [Google Cloud Pub/Sub Source](https://github.com/googleapis/java-pubsub-group-kafka-connector)
- [JDBC Source](https://github.com/Aiven-Open/jdbc-connector-for-apache-kafka/blob/master/docs/source-connector.md)
- [MongoDB Kafka Source Connector](https://www.mongodb.com/docs/kafka-connector/current/)
- [Schema Source](https://github.com/confluentinc/kafka-connect-storage-common/blob/master/core/src/main/java/io/confluent/connect/storage/tools/SchemaSourceTask.java)
