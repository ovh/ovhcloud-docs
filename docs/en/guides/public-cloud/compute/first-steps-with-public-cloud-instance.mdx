## Objective

You can manage your Public Cloud instances in the <ManagerLink to="/">OVHcloud Console</ManagerLink>.

**This guide explains the available OVHcloud Console actions for a Public Cloud instance.**

## Requirements

- A [Public Cloud project](/links/public-cloud/public-cloud) in your OVHcloud account
- A [Public Cloud instance](/guides/public-cloud/compute/getting-started) in your project

[[cpnav:publiccloud-instances]]

## Instructions

### Using the management interface for instances

{/* CP-STEPS-START:instances-list */}
In the left-hand menu of your Public Cloud project, click <code className="action">Instances</code> under **Compute**.

This page lists all your Public Cloud instances and some of their properties:

- The instance name and ID, needed for certain API calls
- The location of the data centre i.e. the region of the instance
- The instance model
- The image i.e. the OS installed on the instance
- The public IP addresses of the instance
- The private IP addresses currently attached to the instance
- Additional volumes (disks) currently attached to the instance
- The status of the instance, indicating whether it is in the `Active` state

{/* CP-STEPS-END:instances-list */}
### Management options on the instance dashboard

{/* CP-STEPS-START:instance-dashboard */}
From the instance list, click on the name of the instance concerned.

This will take you to the <code className="action">Overview</code> tab of the instance. Its **General information** card centralizes the main details of your instance (model, region, image, resources and prices), alongside the **Connection details**, **Public network**, **Private network**, **Snapshot management** and **Storage management** cards. The page also offers the <code className="action">VNC console</code>, <code className="action">Observability</code> and <code className="action">Snapshots</code> tabs.

Most of these operations are also accessible from the instance list via the <code className="action">...</code> button in the instance table.
{/* CP-STEPS-END:instance-dashboard */}

#### Editing the configuration of the instance

{/* CP-STEPS-START:edit-instance-configuration */}
Each item of the instance configuration is edited from the <code className="action">Overview</code> tab:

- **Renaming the instance**: Edit the name of the instance in the page header. You can give a name to the instance for easier identification.
- **Changing the image**: In the **General information** card, click <code className="action">Edit image</code> on the **Image** row. You can choose a different operating system for the instance. (Note that reinstalling an instance will delete all data stored on it.)
- **Changing the model**: In the **General information** card, click <code className="action">Modify model</code> on the **Model** row, then choose the new model on the **Change model** page. Refer to [this guide](/guides/public-cloud/compute/getting-started#model) for more information about the options.
- **Changing the billing type**: In the **General information** card, click <code className="action">Switch to monthly</code> to change the billing period of the instance from hourly to monthly. Refer to [this guide](/guides/account-and-service-management/managing-billing-payments-and-services/changing-hourly-monthly-billing) for detailed information.

{/* CP-STEPS-END:edit-instance-configuration */}
#### Creating a snapshot of the instance

{/* CP-STEPS-START:create-backup */}
In the instance list, click <code className="action">...</code> on the instance row in the list, then select <code className="action">Create a snapshot</code>.
{/* CP-STEPS-END:create-backup */}

Refer to our guide [Taking a snapshot of an instance](/guides/public-cloud/compute/save-an-instance) for detailed information.

#### Deleting an instance

{/* CP-STEPS-START:delete-instance */}
In the instance list, click <code className="action">...</code> on the instance row in the list, then select <code className="action">Delete</code>. You can also click <code className="action">Delete</code> at the bottom of the **General information** card of the <code className="action">Overview</code> tab.

This action will permanently delete the instance, as well as all of the data stored on it.

Confirm the request by clicking <code className="action">Delete instance</code> in the **Delete instance** window.
{/* CP-STEPS-END:delete-instance */}

:::warning
Deleting an instance does not automatically delete all the options associated with it (storage, snapshot, backup, etc...), so make sure that all other options associated with the instance are also deleted to stop being billed.

:::


#### Attach a volume

{/* CP-STEPS-START:attach-volume */}
In the **Storage management** card of the <code className="action">Overview</code> tab, click <code className="action">Attach a volume</code>.

Then select the volume to associate with the instance and click <code className="action">Attach</code>. Once attached, the volume is immediately available and can be mounted from the instance's operating system.
{/* CP-STEPS-END:attach-volume */}

#### Change the reverse DNS

{/* CP-STEPS-START:change-reverse-dns */}
The reverse DNS of the instance's public IP address is managed with all your IP addresses: in the top bar of the OVHcloud Console, click <code className="action">Bare Metal Cloud</code>, then click <code className="action">IP addresses</code> under **Network** in the left-hand menu, and open the <code className="action">Reverse DNS</code> tab.
{/* CP-STEPS-END:change-reverse-dns */}

Refer to the guide [How to configure the reverse DNS of my connection](/guides/public-cloud/compute/setup-instance-reverse) for more information.

#### Configure the firewall

{/* CP-STEPS-START:configure-firewall */}
The Edge Network Firewall of the instance's public IP address is managed with all your IP addresses: in the top bar of the OVHcloud Console, click <code className="action">Bare Metal Cloud</code>, then click <code className="action">IP addresses</code> under **Network** in the left-hand menu, and open the <code className="action">Edge Firewall</code> tab.
{/* CP-STEPS-END:configure-firewall */}

Refer to the guide [Enabling and configuring the Edge Network Firewall](/guides/bare-metal-cloud/dedicated-servers/firewall-network) for more information.

#### Manage private networks

{/* CP-STEPS-START:manage-private-networks */}
In the **Private network** card of the <code className="action">Overview</code> tab, click <code className="action">Manage my private network</code>.
{/* CP-STEPS-END:manage-private-networks */}

Refer to the guide [Creating a private network with Gateway](/guides/public-cloud/network-services/create-private-network-gateway) for more information.

#### Attach a network

{/* CP-STEPS-START:attach-network */}
In the **Private network** card of the <code className="action">Overview</code> tab, click <code className="action">Attach a network</code>.

Select the desired network from the drop-down list, then click <code className="action">Confirm</code>.
{/* CP-STEPS-END:attach-network */}

#### Additional actions

{/* CP-STEPS-START:additional-actions */}
In the **General information** card of the <code className="action">Overview</code> tab, click <code className="action">Additional actions</code>. The same actions are available in the instance list, via the <code className="action">...</code> button of the instance row.
{/* CP-STEPS-END:additional-actions */}

##### Creating an automatic snapshot of the instance

{/* CP-STEPS-START:create-automatic-backup */}
In the instance list, click <code className="action">...</code> on the instance row in the list, then select <code className="action">Create an automatic snapshot</code>.
{/* CP-STEPS-END:create-automatic-backup */}

Refer to our guide [Taking a snapshot of an instance](/guides/public-cloud/compute/save-an-instance#creating-an-automatic-snapshot-of-an-instance) for detailed information.

##### Stop the instance

{/* CP-STEPS-START:stop-instance */}
Click on <code className="action">Turn off</code>, then click <code className="action">Confirm</code> in the **Turn off your instance** window.

This will put the instance in an `Off` state, but you will still be charged the same price for your instance. Refer to our guide [Shelve or pause an instance](/guides/public-cloud/compute/suspend-or-pause-an-instance#suspend-stop-an-instance) for detailed information.

Click on <code className="action">Start</code> to restart the instance.
{/* CP-STEPS-END:stop-instance */}

##### Using rescue mode

{/* CP-STEPS-START:rescue-mode */}
Click on <code className="action">Reboot in rescue mode</code>, then click <code className="action">Confirm</code> in the window that opens.
{/* CP-STEPS-END:rescue-mode */}

This will activate rescue mode for the instance. Refer to our guide [How to activate rescue mode on a Public Cloud instance](/guides/public-cloud/compute/put-an-instance-in-rescue-mode) for detailed information.

##### Restarting the instance

{/* CP-STEPS-START:restart-instance */}
:::warning
The Hot reboot option is currently not available for Metal instances.

:::


- Click on <code className="action">Hot reboot (soft)</code> to perform a software-level reboot.
- Click on <code className="action">Cold reboot (hard)</code> to perform a hardware-level reboot.

Confirm the reboot request by clicking <code className="action">Confirm</code> in the window that opens.
{/* CP-STEPS-END:restart-instance */}

##### Shelving the instance

{/* CP-STEPS-START:shelve-instance */}
Click on <code className="action">Suspend</code>, then click <code className="action">Confirm</code> in the **Suspension of your instance** window.

This will put the instance in the "shelved" state, displayed as `Shelved`. Consult our guide [Shelve or pause an instance](/guides/public-cloud/compute/suspend-or-pause-an-instance#shelve-suspend-an-instance) to learn more about the different states.

Click on <code className="action">Reactivate</code> to restore the `Active` state.
{/* CP-STEPS-END:shelve-instance */}

##### Reinstalling an instance

{/* CP-STEPS-START:reinstall-instance */}
Click on <code className="action">Reinstall</code>, then click <code className="action">Confirm</code> in the **Re-install an instance** window.

This action will reinstall the instance with the same operating system, provided the image is still supported.

Note that reinstalling **deletes all data** currently stored on your instance.
{/* CP-STEPS-END:reinstall-instance */}

### Accessing the VNC console <a name="accessvnc"></a>

{/* CP-STEPS-START:access-vnc-console */}
In the left-hand menu of your Public Cloud project, click <code className="action">Instances</code> under **Compute**, then click on the name of the instance in the table.

Open the <code className="action">VNC console</code> tab.
{/* CP-STEPS-END:access-vnc-console */}

The VNC console provides direct access to your instance. For this to work, first configure a username and password on the instance.

Consult our [Getting started guide](/guides/public-cloud/compute/getting-started#vnc-console) to learn more about the necessary steps.
