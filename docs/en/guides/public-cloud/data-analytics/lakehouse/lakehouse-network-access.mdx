## Objective

By default, every address can reach the endpoints of a Lakehouse, provided it holds a valid credential. IP filtering limits access to the addresses you list.

**This guide explains how to enable IP filtering on a Lakehouse.**

## Requirements

- A Lakehouse in your Public Cloud project. See [Lakehouse - Getting started](/guides/public-cloud/data-analytics/lakehouse/lakehouse-getting-started).
- The public IP addresses of the machines and networks that must reach the Lakehouse.

## Instructions

In the OVHcloud Control Panel, open your Public Cloud project, go to **Analytics** > **Lakehouse**, click the name of your Lakehouse and open the **Network access** tab.

![Network access tab with two IP addresses listed and filtering disabled](/images/guides/public-cloud/data-analytics/lakehouse/network-access/network-ip-filtering.png)

### Listing the allowed addresses

Click **Add** and enter a public IPv4 or IPv6 address, or a block in CIDR notation (for example `203.0.113.0/24` for a whole network), with an optional description. Repeat for each address, then click **Save**.

- Private and reserved ranges are refused: only public addresses can be listed.
- The list must hold at least one IPv4 entry; a list of IPv6 entries only would block every IPv4 client.

:::warning
Add the address you work from before enabling the filtering. Otherwise your tools lose access to the SQL endpoint and the Iceberg REST catalog from this address. The **Add my current IP** option fills in the address you are connected from.
:::

### Enabling the filtering

While the filtering is disabled, the listed addresses are saved but not applied: every address can reach the Lakehouse. Click **Apply the filtering** to apply the list.

The filtering applies to the SQL endpoint, the Iceberg REST catalog and the S3 keys of the Lakehouse. It takes effect within about a minute. A request from an address that is not listed is refused with the error `403` and the message `Source address not allowed`.

To change the list later, edit it and save again: the new list also takes effect within about a minute.
