## Objective

ClickHouse is an open-source, columnar analytical database system designed for real-time processing of massive data volumes, providing high performance, scalability, and low latency.

**This guide explains how to configure your ClickHouse cluster to accept incoming connections via the OVHcloud Console.**

## Requirements

- A [Public Cloud project](/links/public-cloud/public-cloud) in your OVHcloud account.
- A ClickHouse cluster running on OVHcloud Public Cloud.

[[cpnav:publiccloud-analytics]]

## Instructions

### Configuring the ClickHouse service

{/* CP-STEPS-START:configure-clickhouse-service */}
Once your ClickHouse service is up and running, you must define at least one user and one authorised IP (if not already provided during the order) to fully connect to the service (as producer or consumer).

The status of your service changes to **Active** when it is ready.

#### Setting up a user

Switch to the <code className="action">Users</code> tab. An admin user named `avnadmin` is preconfigured during the service installation.

You can add more users by clicking the <code className="action">Add a user</code> button.

Enter a **Username**, then click <code className="action">Create</code>. The password is displayed only once: note it down.

Passwords can be reset from the <code className="action">...</code> button on the row of the user in the <code className="action">Users</code> tab (<code className="action">Reset password</code>).

#### Configuring authorised IPs

:::warning
For security reasons, the default network configuration doesn't allow any incoming connections. You must therefore authorise the suitable IP addresses to access your ClickHouse cluster.
:::


If you did not define the IP restrictions during the order, you can do it in the **IP restrictions** section of the <code className="action">Configuration</code> tab. At least one IP address must be authorised here before you can connect to your service.

Click <code className="action">Add</code> and enter an IP address or a CIDR block in the **IP block (CIDR)** field, or add the IP address of your computer with the <code className="action">Add my current IP</code> button, then click <code className="action">Save</code>.

You can remove IPs from the list afterward.

Your ClickHouse service is now fully accessible!

{/* CP-STEPS-END:configure-clickhouse-service */}
