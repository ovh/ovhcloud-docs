## Objective

Apache Kafka is an open-source, distributed event streaming platform designed for real-time, large-scale data processing with high scalability, durability, and low latency.

This guide explains how to create Kafka topics via the OVHcloud Console or the OVHcloud API.

## Requirements

- A [Public Cloud project](/links/public-cloud/public-cloud) in your OVHcloud account
- A [Kafka cluster running](/guides/public-cloud/databases/kafka-getting-started) on OVHcloud Public Cloud [accepting incoming connections](/guides/public-cloud/databases/kafka-capabilities)

## Instructions

### Creating Kafka topics

Topics can be seen as categories, allowing you to organize your Kafka records. Producers write to topics, and consumers read from topics.

<Tabs>
  <Tab label="OVHcloud Console">
    {/* CP-STEPS-START:kafka-create-topics */}
    To create Kafka topics, first go to the <code className="action">Topics</code> tab then click on the <code className="action">Add a topic</code> button. In the **Add a topic** panel, enter the name of the topic.

    Under **Advanced settings**, you can change the default value for the following parameters:

    - **Min insync replicas** (2 by default)
    - **Partitions** (1 partition by default)
    - **Replication factor** (3 brokers by default)
    - **Retention bytes** (-1: no limitation by default)
    - **Retention hours** (-1: no limitation by default)
    - **Deletion policy**

    Then click <code className="action">Create</code>.
    {/* CP-STEPS-END:kafka-create-topics */}
  </Tab>
  <Tab label="OVHcloud API">
    Create a topic with the OVHcloud API:

    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\{serviceName\}/database/kafka/\{clusterId\}/topic"} />

    ```json
    {
      "name": "orders"
    }
    ```

    When you only provide the name, the API applies the following values, which differ from the OVHcloud Console defaults:

    ```json
    {
      "name": "orders",
      "partitions": 1,
      "replication": 2,
      "retentionBytes": -1,
      "retentionHours": 168,
      "minInsyncReplicas": 1
    }
    ```

    Set `partitions`, `replication`, `retentionBytes`, `retentionHours` and `minInsyncReplicas` in the request to use other values.
  </Tab>
</Tabs>

Once the topic is created, grant access to it with an [access control list (ACL)](/guides/public-cloud/data-analytics/analytics/kafka-configure-acl).
