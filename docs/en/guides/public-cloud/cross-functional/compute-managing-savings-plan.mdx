## Objective

This guide aims to provide a clear and detailed method for creating and updating Savings Plans for your resources. You will discover how to manage your Savings Plans using the OVHcloud Console, the OVHcloud API and Terraform. By following this guide, you will be able to:

- Create a Savings Plan for your resources.
- Modify a Savings Plan.
- Automate the management of Savings Plans via the API or Terraform for greater efficiency and flexibility.

## Instructions

{/* CP-STEPS-START:savings-plans-navigation */}
In the left-hand menu of your Public Cloud project, click <code className="action">Cost center</code>, then the <code className="action">Savings Plan</code> tab. Your Savings Plans are listed in the **My Savings Plans** table.
{/* CP-STEPS-END:savings-plans-navigation */}

### Create a Savings Plan

{/* CP-STEPS-START:create-savings-plan */}
You can create your Savings Plan for the type of resource you want by following these steps:

<Tabs>
  <Tab label="Via the OVHcloud Console">
    1. Click <code className="action">Create a Savings Plan</code>.
    2. In the **Enter a name** section, give your Savings Plan a name.
    3. In the **Select a date** section, choose the start date of the plan.
    4. In the **Select a service** section, select the type of resource for which the Savings Plan will apply: **Instance** or **Managed Rancher Service**.
    5. For instances, choose the deployment mode (1-AZ or 3-AZ region) in the **Choose a deployment mode** section.
    6. In the **Choose a committed resource** section, define the specific resource model and specify the number of resources affected by this plan.
    7. In the **Select the subscription period** section, choose the duration of your Savings Plan from the available durations.
    8. Read the Terms and Conditions carefully, then tick the box **I have read and agree to the terms of the following contracts:** to confirm you accept them.
    9. Once all the parameters have been configured, click <code className="action">Create a Savings Plan</code> to finalise the creation.
  </Tab>
  <Tab label="Via Terraform">
    To create a Savings Plan, you will need at least 5 elements:
    
    - The ID of your Public Cloud project.
    - The flavour concerned by your Savings Plan
    - The duration of your Savings Plan (in standard ISO 8601 format)
    - The number of resources concerned.
    - The name of your Savings Plan
    
    In our example, we are going to create a Savings Plan for 10 instances of type **b3-8**, for a duration of 1 month. Add the following lines to a file named *savings_plan.tf* :
    
    ```python
    # creation of a Savings Plan
    resource "ovh_savings_plan" "Savings_plan_simple_b3_8" {
      service_name = "<public cloud project ID>"
      flavor = "b3-8" # instance type or rancher/rancher_standard or rancher_ovhcloud_edition
      period = "P1M" #  P mandatory, number for duration and M for ‘month’, Y for ‘year’ ...
      size = 10
      display_name = "Savings_plan_simple_b3_8"
      auto_renewal = true # optional, ‘true’ to activate.
    }
    ```
    
    You can create your Savings Plan by entering the following command in your console:
    
    ```console
    terraform apply
    ```
  </Tab>
</Tabs>

{/* CP-STEPS-END:create-savings-plan */}

### Modifying a Savings plan

{/* CP-STEPS-START:modify-savings-plan */}
<Tabs>
  <Tab label="Via the OVHcloud Console">
    :::info
    Using the OVHcloud Console, you can edit the **name** of the Savings Plan and **activate/deactivate** its automatic renewal. A plan that has not started yet can also be cancelled.
    :::

    In the **My Savings Plans** table, click the <code className="action">Actions</code> button on the row of your Savings Plan.

    If you wish to change the name, click <code className="action">Edit name</code>, change the name in the **Name** field and then click <code className="action">Save</code>.

    If you wish to activate/deactivate the automatic renewal of your Savings Plan, click <code className="action">Change renewal</code>. The **Change the renewal** window states whether the automatic renewal will be enabled or disabled: click <code className="action">Confirm</code>.

    If your Savings Plan has not started yet, you can cancel it: click <code className="action">Cancel</code> in the <code className="action">Actions</code> menu, then confirm in the **Cancel the savings plan** window.
  </Tab>
  <Tab label="Via the OVHcloud API">
    First find the id of your service in the list of your services, which can be obtained via the following endpoint:
    
    <Api version="v1" section="/services" method="GET" route={"/services"} />
    You must enter the id of your Public Cloud project as a parameter in the **resourceName** field.
    
    You will obtain a list containing the id of your services as follows:
    
    <img className="thumbnail" alt="Savings Plan services list" src="/images/public-cloud/cross-functional/how-to-manage-savings-plan/savings_plan_list_service.png" loading="lazy" />
    
    You can use this route to check whether the service corresponds to the Public Cloud project concerned:
    
    <Api version="v1" section="/services" method="GET" route={"/services/\\{serviceId\\}"} />
    The **serviceId** corresponds to the id retrieved with the previous endpoint.
    
    You'll get a list containing the details of your service as follows. Check that it's the right project, using the `vars.value` field:
    
    <img className="thumbnail" alt="Savings Plan services list" src="/images/public-cloud/cross-functional/how-to-manage-savings-plan/savings_plan_list_service_details.png" loading="lazy" />
    
    You can find the id of your Savings Plan in the list of your Savings Plans obtained via this endpoint:
    
    <Api version="v1" section="/services" method="GET" route={"/services/\\{serviceId\\}/savingsPlans/subscribed"} />
    The **serviceId** corresponds to the previously retrieved id.
    
    You get a list of Savings Plans as follows:
    
    <img className="thumbnail" alt="Savings Plan list" src="/images/public-cloud/cross-functional/how-to-manage-savings-plan/savings_plan_list_svp.png" loading="lazy" />
    
    Then look for the Savings Plan concerned in the list and copy its **id**.
    
    <details>
    <summary>Changing the name of a Savings Plan</summary>

    To change the name of a Savings Plan, use the following endpoint:
    
    <Api version="v1" section="/services" method="PUT" route={"/services/\\{serviceId\\}/savingsPlans/subscribed/\\{savingsPlanId\\}"} />
    
    The **savingsPlanId** corresponds to the id of your previously copied Savings Plan.

    </details>
    
    <details>
    <summary>Activate/deactivate automatic renewal of a Savings Plan</summary>

    To **activate/disable** the automatic renewal of the Savings Plan, use the following endpoint:
    
    <Api version="v1" section="/services" method="POST" route={"/services/\\{serviceId\\}/savingsPlans/subscribed/\\{savingsPlanId\\}/changePeriodEndAction"} />

    </details>
    
    <details>
    <summary>Increase the number of Savings Plan resources</summary>

    To increase the number of resources subscribed to your Savings Plan, use this route:
    
    :::info
    The number of resources can only be increased.
    :::
    
    <Api version="v1" section="/services" method="POST" route={"/services/\\{serviceId\\}/savingsPlans/subscribed/\\{savingsPlanId\\}/changeSize"} />

    </details>
  </Tab>
  <Tab label="Via Terraform">
    Modify your resource in the *savings_plan.tf* Terraform file created earlier.
    
    :::info
    Note that only the **service_name**, **size** and **auto_renewal** fields can be modified. The **size** can only be increased.
    :::
  </Tab>
</Tabs>

{/* CP-STEPS-END:modify-savings-plan */}
