## Objective

Access to Horizon and the OpenStack APIs is established via username/password pairs called "OpenStack users". You can create as many OpenStack users as needed and assign them various access permissions.

Using the Horizon interface, you can also set passwords for each individual user. Please note that when you change a user password, the previous password will be immediately cancelled.

**This guide explains how to manage OpenStack users from the OVHcloud Console and the Horizon interface.**

## Instructions

### Creating an OpenStack user

{/* CP-STEPS-START:create-openstack-user */}
In the left-hand menu of your Public Cloud project, click <code className="action">Project Management</code>, then the <code className="action">Users</code> tab.

Click <code className="action">Create a user</code>. The **Create a user** window opens.

In the **User description** field, enter a description. The user description is not the username for the OpenStack user but a descriptive term to help you organise users and their permissions.

In the **Roles** section, select the user roles representing the permissions the user shall have. For each box checked, the user will gain the corresponding access privileges. To see the privileges granted by each role, click <code className="action">Show role matrix</code> on the **Users** tab.

Click <code className="action">Create</code> to create the OpenStack user. The password is automatically generated and displayed in the **Credentials created** window. The username is automatically generated and displayed in the users table.

Be sure to save the password to a password manager at this time: it is shown only once and cannot be recovered afterwards. Copy it with the <code className="action">Copy</code> button, then click <code className="action">Close</code>. However, you can always create a new password by clicking on <code className="action">...</code> on the user's row, selecting <code className="action">Generate a password</code>, then clicking <code className="action">Generate</code> in the **Generate a password** window.

With the OpenStack user created, you can use its credentials to log into the [Horizon interface](/guides/public-cloud/cross-functional/introducing-horizon) by clicking on <code className="action">...</code> on the user's row, then <code className="action">Launch OpenStack Horizon</code>.
{/* CP-STEPS-END:create-openstack-user */}

### Change an OpenStack user password

You can create an OpenStack password once you have logged in to your [OpenStack Horizon](https://horizon.cloud.ovh.net) interface:

<img className="thumbnail" alt="Horizon login" src="/images/public-cloud/cross-functional/create-and-delete-a-user/1_H_login_window.png" loading="lazy" />

Your user profile is visible in the top right-hand corner of the Horizon interface. Click on your profile to open a menu with various options, select <code className="action">Settings</code>, then <code className="action">Change password</code> on the left-hand side:

<img className="thumbnail" alt="Change password" src="/images/public-cloud/cross-functional/create-and-delete-a-user/2_H_pass_change_option.png" loading="lazy" />

Enter your current password into the first field, then re-enter and confirm your new password in the next two fields.

:::info
When you change your password, please ensure that it meets the following criteria:

- The password must contain a minimum of eight characters.
- The password must contain a maximum of 30 characters.
- The password must contain at least one upper-case letter.
- The password must contain at least one lower-case letter.
- The password must contain at least one number.
- The password must only contain letters and numbers.

:::


To confirm your new password, click <code className="action">Change</code>.

<img className="thumbnail" alt="Set password" src="/images/public-cloud/cross-functional/create-and-delete-a-user/3_H_set_new_passord.png" loading="lazy" />

Please note that when you change your user password, your previous password is immediately cancelled.

### Deleting an OpenStack user

{/* CP-STEPS-START:delete-openstack-user */}
In the left-hand menu of your Public Cloud project, click <code className="action">Project Management</code>, then the <code className="action">Users</code> tab.

Click on <code className="action">...</code> on the row of the user and select <code className="action">Delete</code>, then click <code className="action">Confirm</code> in the **Delete user** window.
{/* CP-STEPS-END:delete-openstack-user */}

:::warning
Deleting a user is permanent and will invalidate all associated tokens, even those with an expiry date not yet exceeded.

:::
