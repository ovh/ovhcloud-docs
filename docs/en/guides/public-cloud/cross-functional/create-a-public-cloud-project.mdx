## Objective

Creating a project is the first step in deploying [Public Cloud instances](/links/public-cloud/public-cloud).

**This guide will take you through the steps of creating your first Public Cloud project.**

## Instructions

### Project creation

{/* CP-STEPS-START:project-creation */}
The first steps depend on whether you already have a Public Cloud project:

- **This is your first Public Cloud project:** the OVHcloud Console opens the **Welcome to the Public Cloud ecosystem** page. Once you have read and understood the terms of the contracts, tick the corresponding box in the **Contracts** section, then click <code className="action">Discover the Public Cloud universe</code>. Your project is created in [discovery mode](#discovery).
- **You already have a Public Cloud project:** on the **Projects** page, click <code className="action">Create a new project</code>. You can also click the <code className="action">Project</code> selector at the top of the left-hand menu, then <code className="action">Create Project</code>. On the **Create a Public Cloud project** page:
    1. In the **Project name** field, enter a name for your project.
    2. Once you have read and understood the terms of the contracts, tick the corresponding box in the **Contracts** section.
    3. In the **Select a payment method** section, select your payment method. If you have a voucher, enter it in the **Do you have a promo code?** section and click <code className="action">Add</code>.
    4. Click <code className="action">Create my project</code>.

Some accounts are not offered discovery mode: their first project is also created from the **Create a Public Cloud project** page.

Once the creation process is complete, your new Public Cloud project is displayed in the **Project** selector at the top of the left-hand menu of the Public Cloud universe.

You now have access to the entire OVHcloud Public Cloud ecosystem. To discover this new interface, read our guide [How to use the Public Cloud interface ](/guides/public-cloud/cross-functional/public-cloud-interface-walk-me).
{/* CP-STEPS-END:project-creation */}

<a name="discovery"></a>

{/* CP-STEPS-START:discovery-mode */}
:::info
**Discovery Mode**

Your first Public Cloud project is created in `discovery mode`. This means that you can browse and discover Public Cloud products, but you cannot yet create resources such as instances. As long as this project is in discovery mode, you cannot create another project either: the OVHcloud Console asks you to activate it first.

To harness the full potential of the Public Cloud and start your first resources, activate your project:

1. On your project's home page, the banner **Start deploying your Cloud resources.** reminds you that you are in discovery mode. Click <code className="action">Enable</code> in this banner.
2. In the window that opens, click <code className="action">Activate project</code>.
3. On the **Activate project** page, validate a payment method, then click <code className="action">Activate project</code>.
:::
{/* CP-STEPS-END:discovery-mode */}

### Project activation and free trial

{/* CP-STEPS-START:project-activation */}
When you activate a project from `discovery mode` and register a payment method, a **£175 free trial credit** is applied if you are eligible. In this case, the banner on your project's home page and the **Activate project** page show the amount of the offer.
{/* CP-STEPS-END:project-activation */}

:::info
**Free trial conditions**

- The credit is activated at the time of project activation and is valid for **one month**.
- **Eligible:** Any OVHcloud customer creating their first Public Cloud project, even if they already have an OVHcloud account.
- **Not eligible:** Customers with a current or past Public Cloud project, or who have already used a free trial credit.

Learn more on the [OVHcloud Public Cloud free trial](/links/public-cloud/free-trial) page.
:::

:::info
**Creating additional projects via Terraform**

Once you have created your first Public Cloud project and validated a payment method, you can create further projects programmatically using the `ovh_cloud_project` Terraform resource. Refer to the [How to use Terraform](/guides/public-cloud/cross-functional/how-to-use-terraform#creating-a-public-cloud-project) guide for details.

There is currently no dedicated OVHcloud API endpoint or CLI command for project creation.
:::
