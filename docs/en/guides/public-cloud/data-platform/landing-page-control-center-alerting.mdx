## What is an alert?

An alert watches one target and notifies people when it misbehaves. Targets come in two kinds: the execution of jobs, such as [Data Processing Engine workflows](/guides/public-cloud/data-platform/dpe-workflows), and long-running deployments, such as [apps](/guides/public-cloud/data-platform/landing-page-app-services-apps) and [APIs](/guides/public-cloud/data-platform/landing-page-app-services-apis).

:::info
Alerting has been reworked and is available again on the platform. This is a **beta release**, so some issues may still surface. Please reach out on the Data Platform channel of the [Discord server](https://discord.com/channels/850031577277792286/1163465539981672559) if you run into anything unexpected.
:::

:::warning
In this release, alert notifications are delivered by **email only**. The previous integrations with Slack, AWS SNS, Opsgenie and custom webhooks are no longer available.
:::

<img className="thumbnail" alt="alerts" src="/images/public-cloud/data-platform/product/cc/alerting/picts/cc-alerts.png" loading="lazy" />

The behaviour is the same for every alert. The platform evaluates the trigger condition against the target every minute. Once the condition has held for the duration configured on that alert, the alert fires, which logs a triggering and sends an email to every linked subscriber. It stays firing until the condition is no longer met, at which point it resolves itself and returns to watching.

An alert therefore has three statuses:

- `watching`: the default state of a created alert. It is monitoring its target, and the triggers have not held long enough to fire.
- `active`: the alert is firing. The trigger conditions have been met for the configured waiting duration.
- `error`: the alert status could not be retrieved.

Creating an alert takes two steps: create it with a target and its triggers, then link the [subscribers](/guides/public-cloud/data-platform/control-center-alerting-subscribers) who receive the email. Pick the type when you create it, since a job execution alert and a health check alert watch different things and cannot be converted into one another.

:::info
After you create an alert, it may take a couple of minutes before it is completely operational.
:::
