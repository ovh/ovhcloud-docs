## What is the Control Center?

The Control Center is the observability surface of a Data Platform project. It collects metrics across data pipelines, applications and deployed instances, drills down into logs, raises alerts when something goes wrong, and is where components get more resources.

<img className="thumbnail" alt="cc" src="/images/public-cloud/data-platform/product/cc/picts/cc-overview.png" loading="lazy" />

It opens at two levels. From a project home page it reports on that project. From the header buttons it reports across every project in the organization the user [has permissions on](/guides/public-cloud/data-platform/iam-users#manage-organization-iam-users), each returning its own metrics. Most metrics can be filtered by timeframe, project and cloud provider.

<img className="thumbnail" alt="cc" src="/images/public-cloud/data-platform/product/cc/picts/ccc-overview-filters.png" loading="lazy" />

[Monitoring](/guides/public-cloud/data-platform/control-center-monitoring) covers CPU, memory, storage and network use per component. [Alerting](/guides/public-cloud/data-platform/landing-page-control-center-alerting) turns those metrics into email notifications with configurable trigger conditions. [Jobs Central](/guides/public-cloud/data-platform/control-center-jobs-central) tracks job executions from one place. [Logs Explorer](/guides/public-cloud/data-platform/control-center-logs-explorer) streams current activity or reads back past logs. [Auditing](/guides/public-cloud/data-platform/control-center-auditing) records who changed what in the project.

Scaling also happens here, from the monitoring panel of the component concerned. Project [APIs](/guides/public-cloud/data-platform/landing-page-app-services-apis), [apps](/guides/public-cloud/data-platform/landing-page-app-services-apps) and [Data Processing Engine jobs](/guides/public-cloud/data-platform/dpe-jobs-resources) scale both horizontally and vertically. The [Analytics Manager](/guides/public-cloud/data-platform/analytics-manager-resources) and the Application Service component scale vertically.
