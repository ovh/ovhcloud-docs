## Objective

The Jobs Central is the watchtower from where all job executions on the platform - past, present, queued and scheduled - can be monitored.

On the platform, a 'job' (or 'job execution') is the unitary execution of code, which can be either launch manually from UI or API, or scheduled based on triggers. Many elements on the platform, such as [Data Processing Engine workflows](/guides/public-cloud/data-platform/dpe-workflows) and [Connectors metadata extraction](/guides/public-cloud/data-platform/connectors-analyzer-extract-metadata), are executed in the form of jobs. The [computing power allocated to this job](/guides/public-cloud/data-platform/manage-pricing#billing-units) is usually set by the user. Some other processes on the platform, like the physical build of your data model, are also jobs fully managed by the platform

If the page is opened at the organization level, all jobs across all Projects will be visible.

## Monitor job executions

The *Job executions* page lists the executions of the following types of jobs:

- [Data Processing Engine actions](/guides/public-cloud/data-platform/landing-page-dpe-actions) job executions
- [Data Processing Engine workflows](/guides/public-cloud/data-platform/dpe-workflows) job executions
- [Connectors metadata extract](/guides/public-cloud/data-platform/connectors-analyzer-extract-metadata) jobs
- [Lakehouse Manager physical build](/guides/public-cloud/data-platform/lakehouse-manager-manage-tables) jobs

If needed, this page can be filtered on only the executions that have triggered by a CRON schedule.

## Monitor scheduled job triggers

The *Scheduled triggers* page lists all the CRON-triggers that have been set on [Data Processing Engine actions and workflows](/guides/public-cloud/data-platform/dpe-jobs-preferences#triggers).

It allows you to have an overview of the recurrent computing activity on your Projects.
