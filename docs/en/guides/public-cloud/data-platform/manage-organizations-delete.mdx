## Objective

Deleting an organization ensures that all resources associated in this organization are **permanently deleted**. It is not possible to recover an organization that has been deleted.

To delete an organization there is a checklist to be followed. In the chance that you miss out on something in the checklist, you will not be allowed to delete the organization.  
All following 5 steps must be completed for an organization to be deleted:

1. [Delete all projects](/guides/public-cloud/data-platform/manage-projects-delete) within the organization
2. [Delete all datasets](/guides/public-cloud/data-platform/lakehouse-manager-datasets#dataset-management) from the organization
3. Make sure there is no pending balance on [billing](/guides/public-cloud/data-platform/manage-pricing#subscriptions-and-billing-accounts)
4. [Remove all users](/guides/public-cloud/data-platform/iam-users#manage-organization-iam-users) from the organization
5. Delete the organization *(see documentation below)*

## Delete the organization from the user interface

:::info
Make sure you have followed all afore-mentioned steps before going further.
:::

The option to delete an organization can be accessed by going to the organization settings. Click on the **organization settings** as shown in the image below.

<img className="thumbnail" alt="Delete the organization from the user interface — Delete orga" src="/images/public-cloud/data-platform/product/organisations/picts/delete-orga-2.jpg" loading="lazy" />

Click on settings and you will land on the page which has the option to delete the organization. The button to delete will only be visible if you have followed all the steps in the checklist mentioned above.

<img className="thumbnail" alt="Delete the organization from the user interface — Delete orga (2)" src="/images/public-cloud/data-platform/product/organisations/picts/delete-orga-3.jpg" loading="lazy" />

<img className="thumbnail" alt="Delete the organization from the user interface — Delete orga (3)" src="/images/public-cloud/data-platform/product/organisations/picts/delete-orga-4.jpg" loading="lazy" />

If the checklist was not followed, you will be shown a **leave organization** button instead of the **delete organization**.

<img className="thumbnail" alt="Delete the organization from the user interface — Delete orga (4)" src="/images/public-cloud/data-platform/product/organisations/picts/delete-orga-5.png" loading="lazy" />
