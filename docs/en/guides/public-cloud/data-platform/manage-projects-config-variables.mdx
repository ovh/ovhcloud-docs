## Project subdomain

Your project's subdomain is used in the base URL for the APIs of all services of the platform. It is the **stringified version of your project's name**.

You can find it in [Identity Access Manager](/guides/public-cloud/data-platform/landing-page-iam) **> Applications > Project**, at the base of the field *URL*.
