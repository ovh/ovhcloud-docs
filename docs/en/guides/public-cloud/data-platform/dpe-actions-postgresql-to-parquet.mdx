## Objective

The *PostgreSQL to Parquet* action extracts data from a PostgreSQL database and puts it into a [Parquet file](https://parquet.apache.org/) in your Project bucket. You can choose the file format.

:::info
**Note:** This action supports the functionality to have customised date in the folder name. You can find the tutorial [here](/guides/public-cloud/data-platform/tutorials-dated-export-folders).
:::

## Configure a PostgreSQL to Parquet action

To create a new action, navigate to the **Action tab** of the Data Processing Engine (DPE), click on **New Action** and select the *PostgreSQL to Parquet* action.

### Choose a source and a destination

To set-up the action, start by selecting a source from the list that you have already set-up in the [Sources](/guides/public-cloud/data-platform/landing-page-connectors-sources) tab of the Lakehouse Manager.

<img className="thumbnail" alt="Choose a source and a destination — Select source" src="/images/public-cloud/data-platform/product/dpe/actions/postgresql-to-parquet/picts/select-source.png" loading="lazy" />

Then, choose the *destination bucket* from the list of [Project buckets](/guides/public-cloud/data-platform/lakehouse-manager-buckets).

<img className="thumbnail" alt="Choose a source and a destination — List buckets" src="/images/public-cloud/data-platform/product/dpe/actions/postgresql-to-parquet/picts/list-buckets.png" loading="lazy" />

### Destination file

You will then be prompted to choose the destination folder. If you leave the folder name empty, it will automatically be named as the source name.

<img className="thumbnail" alt="Destination file — Select destination" src="/images/public-cloud/data-platform/product/dpe/actions/postgresql-to-parquet/picts/select-destination.png" loading="lazy" />

Your data will be put into the destination folder in a file named *part-1*. If your file is too big, it will be split into multiple files named *part-1*, *part-2*, *part-3* and so on.

The order of your rows will be preserved in this process. Hence, the first rows will be in the *part-1* file and the following rows will be in the *part-2* file.

:::info
Note that this action has its **transfer speed optimised** for the PostgreSQL source.
:::
