:::info
This article is about actions that use Data Platform' proprietary Python data processing engine. To use Apache Spark clusters, see [Load PySpark action](/guides/public-cloud/data-platform/dpe-actions-load-pyspark).
:::

The *Load* action **extracts raw data from sources and inserts it into primary tables** in your data warehouse. It is usually the first step in any data processing system, necessary before running any other processes on data coming from connected sources.

:::info
In other terms, if you've [set-up a connector through the Connectors](/guides/public-cloud/data-platform/landing-page-connectors-sources), the Project has the information to connect to the source as well as its metadata, but won't contain the actual data until it is actually loaded using the *Load* action.
:::

## Configure a Load action

To create a new *Load* action, navigate to the *Action* tab of the Data Processing Engine (DPE), click on **New Action** and select the *Load* action.

### Choose a source and destination

To set-up the *Load* action, start by selecting a **source** from the list that you have already set-up in the [Sources](/guides/public-cloud/data-platform/landing-page-connectors-sources) tab of the Connectors.

<img className="thumbnail" alt="Choose a source and destination — Load select source" src="/images/public-cloud/data-platform/product/dpe/actions/load/picts/load-select-source.png" loading="lazy" />

Then a **destination** table to send your data to. Similarly to the sources, the tables have to be configured ahead of time in the [Tables](/guides/public-cloud/data-platform/lakehouse-manager-tables) tab of the Lakehouse Manager. Make sure you've [built](/guides/public-cloud/data-platform/lakehouse-manager-manage-tables#build-table) your data model otherwise the tables won't be accessible by other components in the platform.

<img className="thumbnail" alt="Choose a source and destination — Load select destination" src="/images/public-cloud/data-platform/product/dpe/actions/load/picts/load-select-destination.png" loading="lazy" />

### Map attributes

Once the source & destination have been selected, the system will **automatically map** the destination attributes of your destination table with the different columns that it has identified in the raw data source.

<img className="thumbnail" alt="Map attributes — Load blueprint rules" src="/images/public-cloud/data-platform/product/dpe/actions/load/picts/load-blueprint-rules.png" loading="lazy" />

:::info
On the picture below, you can see that the *date* attribute has a a value of '1' beside the notepad icon. This indicates the number of **data validation rules, also called blueprint rules**, defined in the Lakehouse Manager, that will be automatically applied when loading the data. [Blueprint rules](/guides/public-cloud/data-platform/connectors-analyzer-blueprint-rules) allow users to quickly filter out invalid data like nulls / empty cells or reformat values such as date or currencies.
:::

<img className="thumbnail" alt="Map attributes — Load attribute select" src="/images/public-cloud/data-platform/product/dpe/actions/load/picts/load-attribute-select.png" loading="lazy" />

Note that you might want to **insert raw text** directly inside your destination table. This might come in handy for instance when you want to count the number of data points or tag a certain source with a label that will be later used in an aggregate table. To do that, select *&lt; txt >* which will set the source attribute to a raw text input field.

<img className="thumbnail" alt="Map attributes — Load attribute txt" src="/images/public-cloud/data-platform/product/dpe/actions/load/picts/load-attribute-txt.png" loading="lazy" />

### Configure the action's preferences

Once you're satisfied with the mapping of your attributes, navigate to the [preferences tab to configure the action settings](/guides/public-cloud/data-platform/dpe-jobs-preferences).

<img className="thumbnail" alt="Configure the action's preferences — Load settings" src="/images/public-cloud/data-platform/product/dpe/actions/load/picts/load-settings.png" loading="lazy" />

When you are done editing your action, click on **Create** to validate the action.
