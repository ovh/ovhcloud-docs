## Objective

The Front APP SDK (ReactJS) and the Front API SDK (NodeJS) are both being replaced. The rewrite has no delivery date yet, so their documentation is not part of this section: new guides land here when the new SDKs ship.

:::warning
**Rework pending, no date.** Until then, the current documentation for both SDKs remains accurate and stays published on the legacy documentation site.
:::

- Front APP SDK, ReactJS, for building custom dashboards and components inside a deployed app: [docs.dataplatform.ovh.net/#/en/technical/sdk/app/index](https://docs.dataplatform.ovh.net/#/en/technical/sdk/app/index)
- Front API SDK, NodeJS, for customizing the API an app calls: [docs.dataplatform.ovh.net/#/en/technical/sdk/api/index](https://docs.dataplatform.ovh.net/#/en/technical/sdk/api/index)

Those pages cover the current SDK releases and are maintained there until the replacements are available. Code written against them keeps working; nothing is deprecated by this move.

For platform work that does not touch the front end, the [Custom Actions SDK](/guides/public-cloud/data-platform/landing-page-developers-python-sdk) in Python is documented in full in this section, and the [Data Platform APIs](/guides/public-cloud/data-platform/landing-page-developers-apis) cover buckets and IAM.

:::info
Building an app right now? The [Apps](/guides/public-cloud/data-platform/landing-page-app-services-apps) pages cover the low-code path, which needs no SDK, and the [Develop your own app](/guides/public-cloud/data-platform/tutorials-app-development) tutorial covers importing your own code from Git.
:::
