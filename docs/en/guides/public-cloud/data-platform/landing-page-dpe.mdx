## What is the Data Processing Engine?

The Data Processing Engine builds and runs the data pipelines of a project, from raw sources through to the tables analysts query. It covers extraction and loading from a registered source, transformation of data already held in the project, and the scheduling and triggering around both.

<img className="thumbnail" alt="What is the Data Processing Engine? — Homepage Data Processing Engine" src="/images/public-cloud/data-platform/product/dpe/picts/homepage-dpe.png" loading="lazy" />

Four objects make up the model:

- An [action](/guides/public-cloud/data-platform/landing-page-dpe-actions) is one unit of work: load a table, aggregate it, run SQL, run custom Python or PySpark.
- A [workflow](/guides/public-cloud/data-platform/dpe-workflows) chains actions into stages with a given execution order.
- An [environment](/guides/public-cloud/data-platform/dpe-environments) is a reusable set of execution settings, covering resources, perimeter, segmentation and variables, shared across actions and workflows.
- A [job](/guides/public-cloud/data-platform/landing-page-dpe-jobs) is one execution of an action or a workflow.

Execution is job-based rather than long-running. When an action or workflow is triggered, the platform builds a worker with the resources requested, runs the job, then shuts the worker down, so compute is billed for the execution only. An always-up execution mode is available for workloads that cannot wait for provisioning.

Every job runs as a [service account](/guides/public-cloud/data-platform/iam-service-accounts), and that identity's [IAM roles](/guides/public-cloud/data-platform/iam-roles-conditions) decide what the job can read and write. [Notebooks](/guides/public-cloud/data-platform/dpe-notebooks) are the interactive counterpart: Jupyter instances for exploring data before its logic becomes an action. For PySpark jobs, the [Spark History Server](/guides/public-cloud/data-platform/dpe-spark-history-server) keeps the Spark UI of past runs available, so a finished job can still be inspected stage by stage.
