## Objective

Trino is an open-source distributed SQL query engine for adhoc and batch ETL queries against multiple types of data sources. The Platform allows you to use Trino to access the sources for your application.

<img className="thumbnail" alt="Trino" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/trino/picts/trino-connector-selection.png" loading="lazy" />

## Add a Trino source on the Platform

### Configure your connection

When creating the source, you will be required to input the following information :

- **Host**: the Host name of the Trino server.
- **Port**: the Port address of the Trino server *(8080 by default)*.
- **Catalog**: the name of the catalog from the Trino server.
- **Schema**: the name of the Schema from the Trino server.
- **Username**: the Username for the Trino server.
- **Password**: the Password for the Username you are using.
- **SSL**: if activated, encrypts the information exchanged between the Data Platform and the database.

<img className="thumbnail" alt="Trino" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/trino/picts/trino-connector-config.png" loading="lazy" />

### Select the tables you want

After establishing a connection with your Trino Server your tables will be fetched and displayed :

<img className="thumbnail" alt="Trino" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/trino/picts/trino-select-tables.png" loading="lazy" />

Select which tables you want to be included in the source by checking the boxes to the left of the table name, as indicated in the image above.

:::info
If the state of the database changes, you can use the *Fetch* button to refresh the tables displayed and include them in your source.
:::

Once you follow the steps above, click on the *Save* button on the top right-hand corner.

:::warning
Don't forget to name your source before creating it. The technical name cannot be changed after creating the source and will be used when trying to open the source using the [SDK](/guides/public-cloud/data-platform/landing-page-developers-python-sdk).
:::

## Connect Trino to an existing Platform Project

You can use **Trino** as a connector to an existing project on the Platform. This will be useful in the scenario where there is a need to extract data from one project to another. The tutorial can be found [here](/guides/public-cloud/data-platform/tutorials-trino-connector).
