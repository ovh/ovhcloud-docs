## Objective

Dropbox is a cloud storage service used for file sharing and collaborative work. The Platform allows you to collect data you stored on Dropbox and import it directly into your platform.

<img className="thumbnail" alt="DB1" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/DB1.png" loading="lazy" />

## Add a Dropbox source on the Platform

### Configuration screen overview

Once you have found *Dropbox* in the **Platform store**, click on *Select* and you will be able to see the configuration screen as shown below -

<img className="thumbnail" alt="DB2" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/DB2.png" loading="lazy" />
 

### Learn how to get a Dropbox token

- Go to https://www.dropbox.com/developers/apps/create

You will see the below screen to Create an App –

<img className="thumbnail" alt="DB3" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/DB3.png" loading="lazy" />

- Do the following steps –

   1. Choose an `API`

   2. Choose the type of access you need - `App Folder` or `Full Dropbox`

   3. Give your app a `Name`

   4. Click on `Create app`
 

- Once your application has been created, you will be redirected to the settings page –

<img className="thumbnail" alt="DB5" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/DB5.png" loading="lazy" />

- Go into the `Permissions` tab, then make sure `files.metadata.read` and `files.content.read` permissions are enabled. Then click on Submit.

<img className="thumbnail" alt="DB5" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/dropboxmetas.png" loading="lazy" />

<img className="thumbnail" alt="DB6" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/dropbox/picts/DB6.png" loading="lazy" />

- Going back to `Settings` tb Click on `Generate` under `Generated access token`

- Set `Access token expiration` to `No expiration`

- Copy your `token`

### Configuring your source

When creating the source, you will be required to input the following information :

- Token: The access key to your app (generated in the previous step).
- Path: The path to the folder.

:::info
If the token is an application token linked to a folder, you don't need to put anything in the Path field 💡
:::

Once you add the above details click on *Connect* and then on the *Create* button on the top right-hand corner.

:::warning
Don't forget to name your source before creating it. The technical name cannot be changed after creating the source and will be used when trying to open the source using the [SDK](/guides/public-cloud/data-platform/landing-page-developers-python-sdk).
:::
