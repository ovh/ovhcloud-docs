## Objective

Environments allow you to save and re-use quickly a set of [configurations and execution preferences](/guides/public-cloud/data-platform/dpe-jobs-preferences) in actions and workflows.

<img className="thumbnail" alt="env" src="/images/public-cloud/data-platform/product/dpe/environments/picts/environment.png" loading="lazy" />
*Figure 1: The environment panel*

Environments are not permanent. At any time you can [change a jobs environment](/guides/public-cloud/data-platform/dpe-jobs-preferences) even if one had already been applied.

:::info
If you make changes to any of the environments parameters, the changes will be reflected in all the actions and workflows to which the environment is assigned.
:::

- [Create an environment](/guides/public-cloud/data-platform/dpe-environments#create-an-environment)

## Create an environment

When you first access the **Environment** tab, you will be greeted with a blank canvas for you to fill your custom environments.

<img className="thumbnail" alt="env" src="/images/public-cloud/data-platform/product/dpe/environments/picts/env.png" loading="lazy" />

Click on **New environment** and a reduced version of the [preferences](/guides/public-cloud/data-platform/dpe-jobs-preferences) section will appear.

<img className="thumbnail" alt="env" src="/images/public-cloud/data-platform/product/dpe/environments/picts/env-panel.png" loading="lazy" />

From here, select your preferred *resources*, *options* and *environment variables*. Don't forget to give your environment a name and a description.

[How to configure the execution preferences](/guides/public-cloud/data-platform/dpe-jobs-preferences)
