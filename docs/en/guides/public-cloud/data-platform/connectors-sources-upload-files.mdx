## Objective

This simple connector allows you to upload your files as sources in the platform.

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/upload-files/picts/file-upload-1.png" loading="lazy" />

## Add a File source on the Platform

### Configuration screen overview

Once you have found *File upload* in the **Platform store**, click on *Select* and you will be able to see the configuration screen as shown below:

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/upload-files/picts/file-upload-2.png" loading="lazy" />

### Supported files and sizes

This connector allows you to drag and drop files from the following types: `.csv`, `.xls`, `.xlsx`, `.xml`, `.json` and `.parquet`.

:::warning
There is a **1GB size limit** on files handled by this tab. In order to process files larger than 1GB, you need to upload them through the [Data Platform Buckets](/guides/public-cloud/data-platform/lakehouse-manager-buckets).
:::

### Configuring your source

To add a file just drag & drop it directly to the designated area in the middle of the screen or click on the indicated link to select the file from your computer.

Uploaded files will be displayed in the list below the drag & drop area, as in the picture below :

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/upload-files/picts/file-upload-3.png" loading="lazy" />

:::info
Note that you can add multiple files to a single *File Upload* source.
:::

The encoding of the source file is automatically detected by the Platform. However, if the automatic detection fails, you have the ability to specify the file encoding by clicking on the **pen icon** next to each source object:

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/upload-files/picts/file-upload-4.png" loading="lazy" />

Select the encoding of your source object in the dropdown selection.

<img className="thumbnail" alt="File Upload" src="/images/public-cloud/data-platform/product/connectors/sources/connectors/upload-files/picts/file-upload-5.png" loading="lazy" />
