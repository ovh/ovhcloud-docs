## What is Data Platform?

Data Platform is a managed platform for building data products, with the infrastructure decisions already made: there is no cluster to size, no orchestrator to run and no deployment pipeline to build. Connecting sources, storing and modelling data, processing it, analyzing it and exposing the result as an API or an application are all provisioned and operated by the platform, behind four levels of automation, so effort goes into business logic rather than logistics.

<img className="no-zoom" src="/images/public-cloud/data-platform/product/picts/automation_levels.png" alt="The four levels of automation" loading="lazy" />

A [project](/guides/public-cloud/data-platform/manage-projects) is the unit of work and the unit of isolation. It holds the sources, tables, buckets, pipelines, queries, dashboards, APIs and apps that make up one data system, together with the access rules over them. Creating a project deploys more than 60 microservices and provisions machines in the selected cloud region in under eight minutes, with no further input.

:::info
Access to a project is usually shared collaboratively along role lines: one group works on ingestion and transformation, another on analytics, another on the application layer. The [Identity Access Manager](/guides/public-cloud/data-platform/landing-page-iam) decides who can read and change what, down to individual table attributes.
:::

If Data Platform is new to you, the fastest way in is the six-step guide that builds a working application on sample data. From there, the [services](/guides/public-cloud/data-platform/landing-page-services) documentation covers each component in the order data moves through it.
