## What is Lakehouse Manager?

Lakehouse Manager is where a project's data lives. It is a serverless lakehouse built on [Apache Iceberg](https://iceberg.apache.org/), unifying data lake and data warehouse storage in one service: no cluster to size, and one open table format for both raw files and analytic tables.

<img className="thumbnail" alt="LHM" src="/images/public-cloud/data-platform/product/lakehouse-manager/picts/lakehouse-home.png" loading="lazy" />

Data is organized in [datasets](/guides/public-cloud/data-platform/lakehouse-manager-datasets), which group [tables](/guides/public-cloud/data-platform/lakehouse-manager-tables) the way a schema groups relations. Tables carry [attributes](/guides/public-cloud/data-platform/lakehouse-manager-attributes) with their own types and constraints, and every write is versioned, so [Time Travel](/guides/public-cloud/data-platform/lakehouse-manager-time-travel) can read a table as it stood at an earlier point. [Buckets](/guides/public-cloud/data-platform/lakehouse-manager-buckets) hold unstructured and semi-structured files alongside those tables, and the [Explorer](/guides/public-cloud/data-platform/lakehouse-manager-explorer) browses both.

Two capabilities sit across the whole store. [Lineage](/guides/public-cloud/data-platform/lakehouse-manager-lineage) maps how data flows through the project, from the pipelines that feed a table down to the tables built from it. [Policy tags](/guides/public-cloud/data-platform/lakehouse-manager-policy-tags) apply access control down to the individual attribute, evaluated through CEL conditions against the caller's IAM identity.

Tables are populated by the [Data Processing Engine](/guides/public-cloud/data-platform/landing-page-dpe) from sources registered in [Connectors](/guides/public-cloud/data-platform/landing-page-connectors), and read by the [Analytics Manager](/guides/public-cloud/data-platform/landing-page-analytics-manager).
