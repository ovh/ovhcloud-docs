## Querying and visualizing what you built

[Trino](https://trino.io/) is the distributed SQL engine behind interactive analytics on the platform, and four tutorials cover it: extracting data from one project into another, connecting external tools with a manual connection string, the type and cast rules that trip up cross-source queries, and Metabase as a worked example.

PySpark handles the analysis that does not fit in a single query. The NYC taxi series works through a real public dataset in four parts, from one table to a multi-dataset comparison, and ends with a cheat sheet worth keeping open.

Two tutorials go further afield. [AI Endpoints](https://endpoints.ai.cloud.ovh.net/) applies models to project data. OVHcloud billing analysis builds a cost dashboard from the OVHcloud API as a source, which doubles as a FinOps starting point.

Apache Superset covers the presentation layer: deploying it against a project, then a FOCUS-format FinOps use case built on top.
