## Objective

This tutorial demonstrates how to use the [Trino Connector](/guides/public-cloud/data-platform/connectors-sources-trino) to extract data from one project into another on the Platform.

## Introduction

### Requirements

To follow this tutorial, you need to be familiar with the [Connectors](/guides/public-cloud/data-platform/landing-page-connectors), [Analytics Manager](/guides/public-cloud/data-platform/landing-page-analytics-manager), [Identity Access Manager](/guides/public-cloud/data-platform/landing-page-iam) and you should preferably have done the [Getting Started guide](/guides/public-cloud/data-platform/landing-page-getting-started). The essential is that you know what [Sources](/guides/public-cloud/data-platform/landing-page-connectors-sources) are for and how to use them.

### Concepts Overview

It is common to have multiple projects running across the platform. In the scenario where you would want to extract and transfer data from an existing project into another, the *Trino Connector* does the work.

This is made possible thanks to the **managed Trino query engine** which is part of the [Analytics Manager](/guides/public-cloud/data-platform/landing-page-analytics-manager) service. It allows to query the datasets of the project - and can be connected to from the external world.

This tutorial will follow a two-step process:

- Make the required changes at the **source project** to allow the extraction of data.
- Use the Trino Connector at the **destination project** as a source to move the data.

Now let's see how all of this works in practice!

## Use the Trino Connector

### Steps to Follow at the Source Project

These initial steps leverage the [Lakehouse Manager](/guides/public-cloud/data-platform/landing-page-lakehouse-manager) and the [Identity Access Manager](/guides/public-cloud/data-platform/landing-page-iam).

1.  **Identify Source Catalog and Schema:**
    Find the catalog and schema you intend to connect to in Lakehouse Manager [Explorer](/guides/public-cloud/data-platform/lakehouse-manager-explorer)

    Execute the following SQL commands to retrieve the available catalogs and schemas:

    ```sql
    SHOW CATALOGS
    ```
    Copy and save the desired catalog name as `CATALOG_NAME`.

    <img className="thumbnail" alt="Steps to Follow at the Source Project — Trino connector show catalogs" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-show-catalogs.png" loading="lazy" />

    ```sql
    SHOW SCHEMAS FROM CATALOG_NAME
    ```
:::info
**Note:** Replace `CATALOG_NAME` with the actual catalog you selected in the previous step.
:::

    This command will display a list of available schemas within your chosen catalog.

    <img className="thumbnail" alt="Steps to Follow at the Source Project — Trino connector show schemas" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-show-schemas.png" loading="lazy" />

    Copy and save the desired schema name as `SCHEMA_NAME`.

:::info
Upon creation of a new project, the `default dataset` is provided. If you have not established any additional datasets within your project, this is the appropriate selection.
:::

2. Open the *Identity Access Manager* and create a new service account for the purpose of this transfer.

    <img className="thumbnail" alt="Steps to Follow at the Source Project — Trino connector service account" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-service-account.png" loading="lazy" />

:::info
Make sure to add *Platform Admin* as the group for this service account
:::

    Once the service account has been successfully create, you need to generate a key for the *API Access*. Click on the add button as shown in the picture below, followed by create.

    <img className="thumbnail" alt="Steps to Follow at the Source Project — Trino connector service account (2)" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-service-account-2.png" loading="lazy" />

    <img className="thumbnail" alt="Steps to Follow at the Source Project — Trino connector create api key" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-create-api-key.png" loading="lazy" />

    You will be provided with the *API Key* and the *Secret Key*. Make sure to copy and save them securely as you wont be able to access the *Secret Key* once you leave this page.

    <img className="thumbnail" alt="Steps to Follow at the Source Project — Trino connector created api key" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-created-api-key.png" loading="lazy" />

    You have successfully completed all the steps required at the source project; the next part of the tutorial will continue on the destination project.

### Steps to follow at destination project

1. Proceed to the *Connectors* and add a new Trino Source.

<img className="thumbnail" alt="Steps to follow at destination project — Trino connector add source" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-add-source.png" loading="lazy" />

2. Fill in the details as given below and click on connect

 - **Host:** replace by your ***source*** *Project_Name* + `-query.eu.dataplatform.ovh.net`
 - **Port:** 443
 - **Catalog:** replace with your *CATALOG_NAME*
 - **Schema:** replace with your *SCHEMA_NAME*
 - **Username:** replace with *API_KEY*
 - **Password:** replace with *SECRET_KEY*
 - **SSL:** activated

<img className="thumbnail" alt="Steps to follow at destination project — Trino connector source settings" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-source-settings.png" loading="lazy" />

3. Once the Trino Connection has been successfully established, the list of available tables will be populated. Click on the box next to table name you desire to extract from the source and click create.

<img className="thumbnail" alt="Steps to follow at destination project — Trino connector source connected" src="/images/public-cloud/data-platform/getting-further/trino-connector/picts/trino-connector-source-connected.png" loading="lazy" />

## Using the extracted data

Once all the previous steps have been completed, you can visit the *Analyzer* tab within the *Connectors* to verify the extracted tables.

To use this extracted data you can follow **step three** of the [Getting Started](/guides/public-cloud/data-platform/getting-started-prepare-data) Tutorial.
