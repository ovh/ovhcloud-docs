## Objective

The *Load to Bucket* action **extracts raw data from sources and puts it into a file** in your Project bucket. You can choose the file format.

:::info
**Note:** This action supports the functionality to have customised date in the folder name. You can find the tutorial [here](/guides/public-cloud/data-platform/tutorials-dated-export-folders).
:::

## Configure a Load to Bucket action

To create a new action, navigate to the **Action tab** of the Data Processing Engine (DPE), click on **New Action** and select the *Load to Bucket* action.

### Choose a source and a destination

To set-up the action, start by selecting a source from the list that you have already set-up in the [Sources](/guides/public-cloud/data-platform/landing-page-connectors-sources) tab of the Connectors.

<img className="thumbnail" alt="Choose a source and a destination — Load buckets select source" src="/images/public-cloud/data-platform/product/dpe/actions/load-buckets/picts/load-buckets-select-source.png" loading="lazy" />

Then, choose the *destination bucket* from the list of [Project buckets](/guides/public-cloud/data-platform/lakehouse-manager-buckets).

<img className="thumbnail" alt="Choose a source and a destination — Load buckets list buckets" src="/images/public-cloud/data-platform/product/dpe/actions/load-buckets/picts/load-buckets-list-buckets.png" loading="lazy" />

You will then be prompted to choose the file format and the destination folder. If you leave the folder name empty, it will automatically be named as the source name.

<img className="thumbnail" alt="Choose a source and a destination — Load buckets select destination" src="/images/public-cloud/data-platform/product/dpe/actions/load-buckets/picts/load-buckets-select-destination.png" loading="lazy" />

:::warning
Note that **the following sources are NOT supported** in this action: Azure Blob Storage, Data Store, Dropbox, FTP, Google Drive, HTTP Files, HTTP REST, One Drive, S3-compatible-storage, Amazon S3 and SFTP.
:::

:::info
If you choose a **PostgreSQL source** your action will be have optimised performance similarly to the [PostgreSQL to Parquet action](/guides/public-cloud/data-platform/dpe-actions-postgresql-to-parquet).
:::

### Destination file

Your data will be put into the destination folder in a file named *part-1* with the format you specified. If your file is too big, it will be split into multiple files named *part-1*, *part-2*, *part-3* and so on.

The order of your rows will be preserved in this process. Hence, the first rows will be in the *part-1* file and the following rows will be in the *part-2* file.
