## Objective

If you want to connect to the Data Platform from outside of the platform, you will need to generate **API and secret keys** to authenticate. The *API key* is the public key associated to the user who is connecting to an API. The *secret key* is the private key known only to the user. The combination of the two is used to authenticate, through the generation of temporary [authentication tokens](#generate-an-authentication-token).

API and secret keys can be generated per [user](/guides/public-cloud/data-platform/iam-users) or [service account](/guides/public-cloud/data-platform/iam-service-accounts).

## Generate a new set of API and secret keys

### For a user

Navigate to the **Users** tab of the Identity Access Manager. Search for the user for which you want to generate API & Secret keys, using the search bar on the top right if needed. Edit the user.

<img className="thumbnail" alt="For a user — Users search" src="/images/public-cloud/data-platform/getting-further/generate-api-key/picts/users-search.png" loading="lazy" />

In the user's settings, scroll down to the **API Access** panel and click on *Add access*.

<img className="thumbnail" alt="For a user — Users api key" src="/images/public-cloud/data-platform/getting-further/generate-api-key/picts/users-api-key.png" loading="lazy" />

Select the lifetime of the keys (i.e. the expiration date from today) and whether you want to send an email to the user with the API & secret key information. Then press **Create**.

:::info
The *Default* value can be changed in your Identity Access Manager settings.
:::

<img className="thumbnail" alt="For a user — Users api key options" src="/images/public-cloud/data-platform/getting-further/generate-api-key/picts/users-api-key-options.png" loading="lazy" />

A new window will open with the API and secret key values.

:::warning
After closing the window, there is no way to view the secret key again. Make sure you keep a record a the keys either by sending an email to the user or storing them in your code.
:::

<img className="thumbnail" alt="For a user — Users api key confirmation" src="/images/public-cloud/data-platform/getting-further/generate-api-key/picts/users-api-key-confirmation.png" loading="lazy" />

To delete a key, hover over the key that you would like to delete and click on the **trash** 🗑️ icon. Once the key is deleted, the credentials for the keys will become inactive and cannot be use to authenticate anymore.

<img className="thumbnail" alt="For a user — Users api key deleting" src="/images/public-cloud/data-platform/getting-further/generate-api-key/picts/users-api-key-deleting.png" loading="lazy" />

### For a service account

Navigate to the **Service Accounts** tab of the Identity Access Manager. Search for the service account for which you want to generate API & Secret keys, using the search bar on the top-right if needed.

<img className="thumbnail" alt="For a service account — Sa search" src="/images/public-cloud/data-platform/getting-further/generate-api-key/picts/sa-search.png" loading="lazy" />

In the service account settings, locate the **API Access** panel and click on *Add access*.

<img className="thumbnail" alt="For a service account — Sa api key" src="/images/public-cloud/data-platform/getting-further/generate-api-key/picts/sa-api-key.png" loading="lazy" />

After that, the [process is the same as for users](#for-a-user). Note that if you want to send an email with a record of the API and secret keys, you need to fill in an email address for the service account.

<img className="thumbnail" alt="For a service account — Sa email" src="/images/public-cloud/data-platform/getting-further/generate-api-key/picts/sa-email.png" loading="lazy" />

## Generate an authentication token

### Generation scripts

Once you've created API & secret keys, you need to generate a dynamic authentication token in order to authenticate to Data Platform via an API endpoint. Authentication tokens are only active for a short time: this duration can be configured in your IAM settings.

<img className="thumbnail" alt="Generation scripts — Token settings" src="/images/public-cloud/data-platform/getting-further/generate-api-key/picts/token-settings.png" loading="lazy" />

To generate a token, simply run the command samples below.

<Tabs>
<Tab label="cURL">

```bash
curl --request POST \
  --url https://{project_subdomain}.eu.dataplatform.ovh.net/iam/login \
  --header 'Content-Type: application/json' \
  --data '{
    "auth_mode": "apikey",
    "apikey": "",
    "secretkey": ""
  }'
```

</Tab>
<Tab label="Python 3+">

```python
import requests

url = "https://{project_subdomain}.eu.dataplatform.ovh.net/iam/login"

payload = {
  "auth_mode": "apikey",
  "apikey": "",
  "secretkey": ""
}

response = requests.request("POST", url, data=payload)

print(response.text)
```

</Tab>
</Tabs>

:::warning
Make to update the **\{project_subdomain\}** else your calls won't go through.
:::
