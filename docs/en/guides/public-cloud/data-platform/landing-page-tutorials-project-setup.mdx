## Structure, versions and credentials

Customize your first app picks up where the Getting started tutorial ends: a richer chart, units on the values, and a rebuilt version of the same app.

Building your own application is the longest tutorial here, a multi-part guide through importing code from a Git repository, working with the config files, creating components and adding custom ones. It is the path to take when the low-code app builder is not enough.

The rest are shorter and independent. Exporting and importing a configuration moves a project's setup between environments, which is how a staging project becomes a production one. Generating API keys creates the credentials an external system uses to authenticate against the project. Versioning basics covers the platform's own version control on action repositories, and how to sync a repository with Git instead.

The application development tutorial is being reworked, with no date set. It remains accurate for the current platform.
:::
