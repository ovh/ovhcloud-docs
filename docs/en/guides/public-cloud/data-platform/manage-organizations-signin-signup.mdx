:::warning
ForePaaS Legacy Platform no longer accepts new signups. If your company would like to get started on the platform, please use [OVHcloud Data Platform](https://eu.dataplatform.ovh.net/).
:::

Connecting to OVHcloud Data Platform can be done in either one of two ways:

- connecting by using an OVHcloud account
- connecting by using a local Data Platform account (invitation required)

<img className="thumbnail" alt="signup" src="/images/public-cloud/data-platform/product/organisations/picts/signup-option-both.png" loading="lazy" />

## Signup using an OVHcloud account

:::info
This is the recommended method to connect to Data Platform.
:::

You can connect to Data Platform using an OVHcloud account by pressing the blue button on the signup/signin page.

<img className="thumbnail" alt="signup" src="/images/public-cloud/data-platform/product/organisations/picts/signup-option-ovh.png" loading="lazy" />

You will then have the option to either use an existing account or to create a new one there.

<img className="thumbnail" alt="signup" src="/images/public-cloud/data-platform/product/organisations/picts/signup-option-ovh2.png" loading="lazy" />

## Signup using an local Data Platform account

:::warning
To use this option, it is **required to [have been invited](/guides/public-cloud/data-platform/iam-users#manage-organization-iam-users) in an existing Data Platform Organization** by an admin from your company beforehand. Consequently, at least one person in your organization needs to have signed up [using an OVHcloud account](/guides/public-cloud/data-platform/manage-organizations-signin-signup#signup-using-an-ovhcloud-account).
:::

If you are joining people from your organization that are already signed-up on the platform, you can fill out the form to signup to the platform using a email & password combination.

<img className="thumbnail" alt="signup" src="/images/public-cloud/data-platform/product/organisations/picts/signup-option-local.png" loading="lazy" />

:::warning
To use this option, it is **required to [have been invited](/guides/public-cloud/data-platform/iam-users#manage-organization-iam-users) in an existing Data Platform Organization** by an admin from your company beforehand. Consequently, at least one person in your organization needs to have signed up [using an OVHcloud account](/guides/public-cloud/data-platform/manage-organizations-signin-signup#signup-using-an-ovhcloud-account).
