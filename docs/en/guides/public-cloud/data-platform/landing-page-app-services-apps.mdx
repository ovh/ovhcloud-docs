## What is an app?

An app is a deployed web application served from the project, built to put dashboards and data in front of end users without running any front-end infrastructure of your own. Apps are created either from a template in the Platform Store or by importing existing code from a Git repository.

<img className="thumbnail" alt="Application Services" src="/images/public-cloud/data-platform/product/app-manager/picts/appmanager-home-new.png" loading="lazy" />

Building one follows a fixed order: pick a template or import code, choose extensions including the visualization libraries, build the dashboards, arrange navigation and menus, then optionally adjust style, value formatting and translations. Versioning and deployment come last, and a change reaches production only through a build and a deploy.

Each app is linked to a deployed [API](/guides/public-cloud/data-platform/landing-page-app-services-apis), which is how it reads project data, and each app authenticates its users against the project's [IAM](/guides/public-cloud/data-platform/iam-application-authentication), so an end user sees only the data their roles allow.

The pages below cover each part of an app: dashboards and their charts, the extension catalogue, style, menus, translations, value formatting, Git integration and custom domains.

Creating an app, building it, deploying a version and configuring its settings are covered together in [Create and deploy an app](/guides/public-cloud/data-platform/app-services-apps-deploy).
