## Objective

**This page lists the known limitations of the Gateway: performance limitations, functional limitations with their workarounds, and quotas.**

## Performance limitations

### Limits per model

| Limit | S | M | L | XL | 2XL |
|---|---|---|---|---|---|
| Bandwidth, each way (inbound and outbound) | 200 Mbit/s | 500 Mbit/s | 2 Gbit/s | 4 Gbit/s | 8 Gbit/s |

## Functional limitations

### No Gateway in a Local Zone

You cannot create a Gateway in a Local Zone, so no Subnet there can get outbound internet access through a Gateway.

**Workaround:** give each instance a Basic IP, which carries both inbound and outbound traffic without a Gateway.

### One Gateway cannot serve Subnets with overlapping CIDRs

A Gateway can be attached to Subnets of several Private Networks, but not to two Subnets whose address ranges overlap, such as two `10.0.0.0/24` Subnets in two different Private Networks: the second attachment fails.

**Workaround:** use one Gateway per Private Network whose Subnets overlap, or a disjoint addressing plan across the Private Networks that must share a Gateway.

### Same gateway IP in several regions of one private network segment

When Private Networks in several regions share the same VLAN ID and the same CIDR, nothing checks their Subnets' gateway IPs across regions. The gateway IP sits outside the allocation pools, so giving each region its own pool does not protect it: if two regions use the same gateway IP, attaching a Gateway in each region duplicates that address on the shared segment. See [No cross-region IP or MAC collision check](/guides/public-cloud/network-services/private-network/known-limits#no-cross-region-ip-or-mac-collision-check).

**Workaround:** give each region its own gateway IP, outside every region's allocation pools. If you do not need the same private network segment across regions, use a different VLAN ID in each region.

### Exactly one public IP per Gateway

A Gateway always has exactly one public IP, assigned automatically. You cannot create a Gateway without a public IP, add a second one, or choose the address.

**Workaround:** none.

## Quotas

The number of Gateways is limited by the **Gateways** quota of your project, per region, whatever the model. See [Quotas](/guides/public-cloud/network-services/known-limits#quotas).
