## Objective

You might need to configure an Additional IP address on your instances because:

- You have multiple websites on your instance.
- You host international projects.
- You want to migrate from a Dedicated Server to a Public Cloud instance.

Instead of buying more public IP addresses, you can import an Additional IP address that is linked to a different OVHcloud service.

**This guide explains how to import Additional IP addresses into your OVHcloud Public Cloud project.**

## Requirements

- A [Public Cloud project](/links/public-cloud/public-cloud) in your OVHcloud account
- An [Additional IP address](/links/bare-metal/ip)

[[cpnav:publiccloud-public-ips]]

:::warning
This feature is not currently available for Metal instances.

:::


## Instructions

In the left-hand menu, open <code className="action">Public IP</code> under **Network**.

Open the <code className="action">Additional IP</code> tab and click <code className="action">Import an Additional IP</code> to display all the IP addresses that can be imported into your Public Cloud project.

Click the <code className="action">Import this Additional IP</code> icon on the row of the IP address you would like to import, then confirm by clicking on <code className="action">Import</code>.

Allow a few minutes for the import process to complete. Open the <code className="action">Additional IP</code> tab to find the imported Additional IP address. Refresh the page if necessary.

Click on <code className="action">...</code> on the row of the IP and select <code className="action">Update attached instance</code>. In the panel that appears, choose the instance to which your IP address should be attached in **Select an instance**.

Click on <code className="action">Attach</code> to confirm.

:::warning
An Additional IP cannot be moved between different zones. For example, an IP located in the SBG data centre can be moved to GRA or RBX, but cannot be moved to BHS.

:::


The IP address is now associated with your instance.
The next step will be the IP configuration in your OS; please refer to our [guide](/guides/public-cloud/network-services/configure-additional-ip).
