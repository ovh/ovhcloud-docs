## Objective

**This page lists the known limitations of the Load Balancer: performance limitations, functional limitations with their workarounds, and quotas.**

## Performance limitations

### Limits per size

| Limit | Listener | Small | Medium | Large | XL |
|---|---|---|---|---|---|
| Bandwidth, each way (inbound and outbound) | All | 200 Mbit/s | 500 Mbit/s | 2 Gbit/s | 4 Gbit/s |
| Concurrent sessions per Load Balancer | HTTP, TCP, HTTPS | 50,000 | 50,000 | 50,000 | 50,000 |
| New sessions per second | HTTP, TCP, HTTPS | 8,000 | 10,000 | 10,000 | 10,000 |
| Requests per second | HTTP, HTTPS | 10,000 | 20,000 | 40,000 | 80,000 |
| New TLS sessions per second | TERMINATED_HTTPS | 250 | 500 | 1,000 | 2,000 |
| Requests per second | TERMINATED_HTTPS | 5,000 | 10,000 | 20,000 | 40,000 |
| Packets per second | UDP | 10,000 | 20,000 | 40,000 | 80,000 |

- These values are given as an indication, to help you choose a size. TBD: value to be determined. Actual capacity depends on your traffic (request and response sizes, TLS key type, keep-alive usage).
- The HTTPS listener is a passthrough listener: TLS is terminated by the pool members. The TERMINATED_HTTPS listener terminates TLS on the Load Balancer.
- A new connection costs much more than a request on an open connection, and a TLS handshake more than a plain connection: reuse connections (keep-alive) to get the most out of a Load Balancer.

## Functional limitations

### No Load Balancer in a Local Zone

You cannot create a Load Balancer in a Local Zone, so traffic to instances in a Local Zone cannot be distributed by a managed Load Balancer.

**Workaround:** none known.

### ICMP to the Load Balancer is filtered

ICMP traffic to the Load Balancer's IPs (private IP or Floating IP) is filtered: `ping` gets no answer.

**Workaround:** test the Load Balancer on its listeners' ports.

### An HTTPS listener cannot be created together with the Load Balancer

Creating a Load Balancer and a TERMINATED_HTTPS listener in the same request fails.

**Workaround:** create the Load Balancer first, with an HTTP listener or none, then add the TERMINATED_HTTPS listener.

### A Floating IP created with the Load Balancer is not deleted with it

Deleting a Load Balancer removes its listeners, pools, members, health monitors and L7 policies, but not a Floating IP created at the same time as the Load Balancer. The Floating IP stays in your project, and is still billed.

**Workaround:** delete the Floating IP after deleting the Load Balancer.

### A certificate for an IP address is refused

A TERMINATED_HTTPS listener refuses a certificate issued for an IP address only, such as a Let's Encrypt IP certificate: the certificate must name a domain.

**Workaround:** point a domain name at the Load Balancer's Floating IP and certify that name.

### TLS certificates must be a PKCS#12 bundle without passphrase

A TERMINATED_HTTPS listener expects its certificate as a single secret containing a PKCS#12 bundle (certificate, private key and optional chain), with no passphrase: a passphrase-protected bundle is not supported. Certificates stored in other forms, such as a certificate container, are deprecated.

**Workaround:** bundle the certificate, its key and its chain into a PKCS#12 file with no passphrase, and store it as one secret.

### No built-in Let's Encrypt certificate

The Load Balancer does not obtain or renew Let's Encrypt certificates by itself. You obtain the certificate with your own ACME client, store it, and replace it on the listener at every renewal, before it expires.

**Workaround:** automate the renewal with an ACME client that stores the new certificate as a PKCS#12 secret and replaces it on the listener; keep port 80 open to Let's Encrypt. See [Configuring a secure Load Balancer with Let's Encrypt](/guides/public-cloud/network-services/load-balancer-letsencrypt).

## Quotas

The following quotas of your project apply per region, whatever the Load Balancer size: **Load Balancers**, **listeners**, **pools**, **members**, **health monitors**, **L7 policies** and **L7 rules**. See [Quotas](/guides/public-cloud/network-services/known-limits#quotas).
