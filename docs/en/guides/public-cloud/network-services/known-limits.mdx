## Quotas

Quotas apply per project and per region. They depend on your project's quota level, not on the model or size of a resource.

You can view them in the OVHcloud Control Panel, in the <code className="action">Quotas</code> tab of <code className="action">Project Management</code>, or with the OVHcloud API v2:

<Api version="v2" section="/publicCloud" method="GET" route={"/publicCloud/project/\\{projectId\\}/quota"} />

To raise a quota, see [How to increase Public Cloud quotas](/guides/public-cloud/cross-functional/increasing-public-cloud-quota).

## Local Zones

Local Zones (region codes containing `-LZ-`, for example `EU-WEST-LZ-AMS-A`) offer a reduced network feature set:

- [no vRack](/guides/public-cloud/network-services/private-network/known-limits#no-vrack-in-a-local-zone);
- [no Gateway](/guides/public-cloud/network-services/gateway/known-limits#no-gateway-in-a-local-zone);
- [no Floating IP](/guides/public-cloud/network-services/public-ip/known-limits#no-floating-ip-in-a-local-zone);
- [no Load Balancer](/guides/public-cloud/network-services/load-balancer/known-limits#no-load-balancer-in-a-local-zone).

## Instance bandwidth

To reach the maximum bandwidth of an instance, you may need to use **several parallel flows**.

For example, when you test bandwidth with `iperf`, add the `-P n` (or `--parallel n`) option: with `n = 1`, the default, you only test a single flow. Increase `n` to reach the maximum bandwidth.
