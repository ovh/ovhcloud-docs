## Objective

As any other OVHcloud service, an Additional IP service can be cancelled at any time.

**This guide explains how to cancel an Additional IP service via the OVHcloud Console or the OVHcloud API.**

## Requirements

- An [Additional IP service](/links/network/additional-ip)
- Access to the <ApiLink>OVHcloud API console</ApiLink>
- Consulting the guide [First steps to use the OVHcloud API](/guides/manage-and-operate/api/first-steps) (to familiarise yourself with the OVHcloud API)

[[cpnav:network-public-ip]]

## Instructions

### Cancelling an Additional IP service via the OVHcloud Console

In the list of IP addresses, click the Additional IP you want to cancel.

1. In the <code className="action">Overview</code> tab, go to the **Subscription** card and click <code className="action">Terminate</code>. The **Manage my services** page opens in a new tab and displays the **Terminate service** window.
2. Under **Cancellation mode**, select <code className="action">Cancel service now.</code> or <code className="action">Cancel service on its expiry date.</code>
3. Click <code className="action">Yes, cancel</code> to confirm.

:::warning
Cancelling the service irretrievably erases all related data.
:::

Some Additional IPs cannot be cancelled on their own:

- If the IP is attached to another service, <code className="action">Terminate</code> is unavailable and the following message is displayed: "This IP is attached to the service … and must be terminated from that service." Cancel it from that service.
- If the **Subscription** card displays "This IP is not billed as a separate service: it is included in another service.", the IP has no subscription of its own: it is included in another service.

### Cancelling an Additional IP service via the API

You first need to find out the name of the service you need to cancel. Use the following call:

<Api version="v1" section="/ip" method="GET" route={"/ip/service"} />


To cancel the service, use the following API call:

<Api version="v1" section="/ip" method="POST" route={"/ip/service/\{serviceName\}/terminate"} />


- `serviceName` : name of the Additional IP service obtained with the previous call.

You will then receive an email asking you to confirm the cancellation. After confirmation, the cancellation will be effective.
