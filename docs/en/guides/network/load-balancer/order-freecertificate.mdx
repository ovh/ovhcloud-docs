## Objective

The OVHcloud Load Balancer service can be configured to support SSL termination.

The purpose of SSL termination is to decrypt the incoming encrypted stream before forwarding it to the appropriate service, such as a web server.

Handling SSL termination on the Load Balancer reduces the computational load on your backend servers and centralizes certificate management. This makes maintenance and security updates easier.

**Discover how to order a free SSL certificate via the OVHcloud Console or the API.**

## Requirements

- You must have an [OVHcloud Load balancer](https://www.ovhcloud.com/en-gb/network/load-balancer/) in your OVHcloud account.

[[cpnav:network-load-balancer|en]]

## Instructions

### Via the OVHcloud Console

#### Configure the frontend for SSL termination

{/* CP-STEPS-START:configure-frontend-ssl */}

To enable SSL termination, you must first configure your frontend.

Create a new frontend or edit an existing one.

In the <code className="action">Frontends</code> tab, click the <code className="action">Create frontend</code> button to create a new frontend. <br/>
On the **Create Frontend** page that opens, select the **HTTPS** protocol. Then, in the **Routing** section, under **Default route**, select **Route to farm** and choose the server farm that will receive the traffic. <br/>
To redirect the traffic to a URL instead, select **Redirect to URL** as the default route. Then click <code className="action">Create Frontend</code>.

Once the frontend has been created, apply the configuration to deploy your changes: in the <code className="action">Overview</code> tab, in the **General information** section, under **Deployment**, click <code className="action">Apply N changes</code>, where N is the number of pending changes. The configuration is deployed to every zone of the service.

{/* CP-STEPS-END:configure-frontend-ssl */}

#### Order the free SSL certificate

{/* CP-STEPS-START:order-free-certificate */}

In the <code className="action">SSL</code> tab of the OVHcloud Console, in the **TLS Certificates** section, click the <code className="action">Add Certificate</code> button to create a new certificate. On the **Add Certificate** page, under **Certificate type**, select **Free (Let's Encrypt)**: an automatic free certificate, renewed every 90 days. Enter your domain name in the **Domain(s)** field and click <code className="action">Add</code>; add the domain names one at a time. Then click <code className="action">Add Certificate</code>.

{/* CP-STEPS-END:order-free-certificate */}

#### Follow-up of the order

{/* CP-STEPS-START:order-follow-up */}

In the <code className="action">Operations</code> tab of the OVHcloud Console, the operations related to ordering a free SSL certificate are of the type `orderFreeCertificate`, shown in the **Action** column.

{/* CP-STEPS-END:order-follow-up */}

### Via the OVHcloud API

#### Configuring the frontend for SSL termination

In the API, the SSL termination is specified by the `ssl` boolean. To enable SSL termination, set this parameter to `true`, then set the `defaultFarmId` or `redirectLocation` to the corresponding values.

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/http/frontend"} />

Then apply the changes:

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/refresh"} />


#### Order the free SSL certificate

In the API, the call is as follows:

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/freeCertificate"} />

For the order to be finalized, the chosen domain name must point to your OVHcloud Load Balancer service.

#### Follow-up of the order

- Returning the task list

You can specify the action type `orderFreeCertificate` to refine the search:

<Api version="v1" section="/ipLoadbalancing" method="GET" route={"/ipLoadbalancing/\{serviceName\}/task"} />


- Returning the status of a particular task:

<Api version="v1" section="/ipLoadbalancing" method="GET" route={"/ipLoadbalancing/\{serviceName\}/task/\{id\}"} />

Once the order is complete, the SSL Certificate is automatically installed on your OVHcloud Load Balancer service.
