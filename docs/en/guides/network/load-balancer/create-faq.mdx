## Objective

This document provides a set of the most frequently asked questions and their corresponding OVHcloud API calls for performing common management and configuration tasks on your OVHcloud Load Balancer service.

## FAQ

### How do I configure my Firewall to accept traffic from the OVHcloud Load Balancer?

When using the Load Balancer, your clients do not connect directly to your servers. A good practice is to set up a firewall to allow only traffic from the OVHcloud Load Balancer service.

#### Via the OVHcloud API

To determine which IP addresses you need to allow in your firewall, you can use the following API call:

<Api version="v1" section="/ipLoadbalancing" method="GET" route={"/ipLoadbalancing/\{serviceName\}/natIp"} />


#### Via the OVHcloud Console

{/* CP-STEPS-START:firewall-outbound-ips */}

In the OVHcloud Console, open your Load Balancer service. On the <code className="action">Overview</code> tab, in the **General information** section, the **Outbound IPv4** field lists the IP ranges you need to allow in your firewall, separated by commas.

{/* CP-STEPS-END:firewall-outbound-ips */}

### How do I know the status of my service?

Sometimes it may be useful to know the status of your OVHcloud Load Balancer.

#### Via the OVHcloud API

To determine the status of your service, you can use the following API call:

<Api version="v1" section="/ipLoadbalancing" method="GET" route={"/ipLoadbalancing/\{serviceName\}/status"} />


The response gives the overall status of the service, along with a breakdown of your farms, frontends and servers, each with a total and a count per status.

The possible statuses are:

- `ok`: Operating normally.
- `warn`: Operating in a degraded state.
- `error`: Not operating.
- `unknown`: Status could not be determined.

#### Via the OVHcloud Console

{/* CP-STEPS-START:service-status */}

In the OVHcloud Console, open your Load Balancer service. The status of your Load Balancer is shown as a badge next to its name, at the top of the page (for example, **OK**). The internal service name of your Load Balancer is the **ID** shown in the **General information** section of the <code className="action">Overview</code> tab.

{/* CP-STEPS-END:service-status */}

### How to add an Additional IP to the OVHcloud Load Balancer?

An Additional IP is an secondary IP address which can be associated to your service in addition to your primary IP. The Additional IP can be switched from one server to another in seconds.

#### Via the OVHcloud API

- To add an Additional IP to an OVHcloud Load Balancer service:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/move"} />


- Apply the change:

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/refresh"} />


#### Via the OVHcloud Console

{/* CP-STEPS-START:add-additional-ip */}

In the OVHcloud Console, open your Load Balancer service. First, attach the Additional IP to your Load Balancer: in the <code className="action">Network</code> tab, in the **Additional IPs** section, click <code className="action">Attach IP</code>. In the **Attach Additional IP** window, select the Additional IP, then click <code className="action">Attach</code>.

Then, go to the <code className="action">Frontends</code> tab and click <code className="action">Create frontend</code>. Expand <code className="action">Advanced settings</code>, and select the Additional IPs you would like to add to your front-end in the **Additional IPs** field. Complete the other settings of your front-end, then click <code className="action">Create Frontend</code>.

{/* CP-STEPS-END:add-additional-ip */}

### How do I order a free SSL certificate?

#### Via the OVHcloud Console

{/* CP-STEPS-START:order-free-ssl */}

In the OVHcloud Console, open your Load Balancer service, go to the <code className="action">SSL</code> tab and click <code className="action">Add Certificate</code>.
Select <code className="action">Free (Let's Encrypt)</code> as the **Certificate type**. In the **Domain(s)** field, enter your FQDN and click <code className="action">Add</code> (add the domain names one at a time), then click <code className="action">Add Certificate</code>.

{/* CP-STEPS-END:order-free-ssl */}

For the order to be completed, it is required that the domain name points to your OVHcloud Load Balancer.

#### Via the OVHcloud API

It is possible to order a free SSL certificate for the OVHcloud Load Balancer.

- To order a free SSL certificate, you can use the following API call and enter your domain in the ‘fqdn’ field:

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/freeCertificate"} />


It is possible to order a multi-domain certificate; the `fqdn` field accepts a string type input.

For the order to be completed, it is required that the domain name points to your OVHcloud Load Balancer.

### How to list the SSL certificates associated with the OVHcloud Load Balancer?

#### Via the OVHcloud Console

{/* CP-STEPS-START:list-ssl-certificates */}

In the OVHcloud Console, open your Load Balancer service and go to the <code className="action">SSL</code> tab. The **TLS Certificates** table lists the certificates associated with that Load Balancer.

To retrieve the details of an SSL certificate, click the `⋮` button in the **Actions** column of the desired certificate, then click <code className="action">View details</code>. The details open in the **Certificate Details** window.

{/* CP-STEPS-END:list-ssl-certificates */}

#### Via the OVHcloud API

- To list the SSL certificates associated with the OVHcloud Load Balancer, you can use the following API call:

<Api version="v1" section="/ipLoadbalancing" method="GET" route={"/ipLoadbalancing/\{serviceName\}/ssl"} />


The SSL certificates that have been ordered (free or not) will appear as `built`. Those added by yourself will appear as `custom`.

An SSL certificate appearing as `built_not_routed` is a certificate that has been ordered and delivered, but whose domain cannot be validated. Usually, this is because the domain no longer points to the OVHcloud Load Balancer.

- To retrieve the details of an SSL certificate, you can use the following API call:

<Api version="v1" section="/ipLoadbalancing" method="GET" route={"/ipLoadbalancing/\{serviceName\}/ssl/\{id\}"} />
