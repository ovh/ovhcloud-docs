## Objetivo

Um **Vault** é um espaço de armazenamento fornecido pela OVHcloud para o qual pode enviar os dados das suas cópias de segurança. Com o Backup Licenses, um primeiro Vault é fornecido automaticamente com a sua primeira licença.

**Este guia explica como funcionam os Vaults do produto Backup Licenses, como são faturados e como encomendar Vaults adicionais.**

## Requisitos

- Ter encomendado uma licença Backup Licenses. Consulte o nosso guia "[Encomendar e configurar a sua primeira licença](/guides/storage-and-backup/backup-licenses/first-configuration)" para mais informações.

## Instruções

### O Vault "bundle"

Um Vault denominado **"bundle"** é fornecido por predefinição com a sua primeira licença Backup Licenses.

- Este Vault está **associado à subscrição do produto**: é **eliminado se o produto Backup Licenses for cancelado**.
- É **único**: dispõe apenas de um único Vault "bundle", independentemente do número de licenças.
- É **gratuito até 500 GB**. Este espaço pode ser utilizado tanto para os seus servidores VBR como para outras necessidades de armazenamento.

:::danger
O cancelamento do produto Backup Licenses implica a **eliminação do Vault "bundle" e dos dados que este contém**. Certifique-se de que recuperou os seus dados antes de qualquer cancelamento.

:::

### Obter as informações de ligação do Vault

O Vault "bundle" é disponibilizado sob a forma de um **bucket S3<sup>1</sup>**. Para obter as informações de ligação (endpoint, credenciais de acesso), clique em <code className="action">Mostrar as credenciais</code> a partir da ficha do Vault na sua Área de Cliente OVHcloud.

Estas informações permitem-lhe configurar o Vault como repositório objeto no seu servidor Veeam Backup & Replication, ou aceder ao mesmo com qualquer cliente compatível com S3.

### Faturação do Vault "bundle"

- Os **primeiros 500 GB estão incluídos** na sua subscrição Backup Licenses, sem custos adicionais.
- **Acima de 500 GB**, cada GB adicional consumido é faturado **mensalmente**, ao **preço público do OVHcloud Object Storage**.

:::info
Os preços atualizados estão disponíveis na página [preços Object Storage](/links/public-cloud/prices-object-storage).

:::

### Encomendar Vaults adicionais

Pode encomendar **Vaults adicionais** a partir da sua Área de Cliente OVHcloud.

Funcionam exatamente da mesma forma que o Vault "bundle" (bucket S3, mesmas utilizações, mesmas modalidades de acesso), com uma única diferença: são **faturados a partir do primeiro GB consumido**, ao preço público do OVHcloud Object Storage. Não têm qualquer volume gratuito associado.

A tabela abaixo resume as diferenças:

| | Vault "bundle" | Vault adicional |
|---|---|---|
| **Fornecimento** | Fornecido automaticamente com a primeira licença | Encomendado a pedido a partir da Área de Cliente |
| **Número** | Apenas um por subscrição | Tantos quantos forem necessários |
| **Volume incluído** | 500 GB gratuitos | Nenhum |
| **Faturação** | A partir do 501.º GB, ao preço público Object Storage | A partir do primeiro GB, ao preço público Object Storage |
| **Ciclo de vida** | Eliminado no cancelamento do produto Backup Licenses | Cancelável de forma independente |
