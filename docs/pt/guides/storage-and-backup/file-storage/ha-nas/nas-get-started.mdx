## Objetivo

O NAS (Network Attached Storage) é um servidor de ficheiros ligado a uma rede cuja principal função é o armazenamento de dados num volume centralizado para clientes de rede heterogéneos.

## Requisitos

- Dispor de um endereço IP associado a um serviço OVHcloud (Hosted Private Cloud, Servidor Dedicado, VPS, Instância Public Cloud, etc...)
- Dispor de um [NAS-HA](https://www.ovhcloud.com/pt/storage-solutions/nas-ha/)

## Instruções

Clique no serviço para aceder ao menu de administração.

<img className="thumbnail" alt="acesso ao NAS" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-01.png" loading="lazy" />

### Criar partição <a name="partition"></a>

Para adicionar uma nova partição, clique em <code className="action">Criar uma partição</code>.

<img className="thumbnail" alt="criar uma partição" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-02.png" loading="lazy" />

Basta introduzir o **nome da sua partição**, o **tamanho** desta, bem como o **protocolo autorizado** (NFS ou CIFS).

<img className="thumbnail" alt="atributos da partição" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-03.png" loading="lazy" />

### Modificar o tamanho de uma partição

Para alterar o tamanho de uma partição, clique no botão <code className="action">(...)</code> situado à direita da partição em causa e, a seguir, em <code className="action">Alterar o tamanho</code>.

<img className="thumbnail" alt="modificar o tamanho de uma partição" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-04.png" loading="lazy" />

Indique o novo tamanho e valide.

### Alterar a frequência das snapshots

De forma padrão, uma snapshot do conteúdo do NAS será realizada de hora em hora e será registada no NAS.

No entanto, é possível criar até 3 snapshots suplementares com frequências diferentes, caso seja necessário, que serão também registadas no seu NAS.

Para isso, clique no botão <code className="action">(...)</code> situado à direita da partição em causa e, a seguir, em <code className="action">Frequência dos snapshots</code>.

<img className="thumbnail" alt="alterar a frequência das snapshots" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-05.png" loading="lazy" />

Escolha a nova frequência e valide.

### Criar uma snapshot instantânea

Para além das snapshots realizadas automaticamente, pode a qualquer momento criar uma snapshot instantânea de uma partição, clicando no botão <code className="action">(...)</code> situado à direita da partição e, a seguir, no <code className="action">Snapshot instantâneo</code>.

<img className="thumbnail" alt="snapshot" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-10.png" loading="lazy" />

Dê um nome à snapshot e clique em <code className="action">Adicionar</code>

### Adicionar um acesso <a name="addaccess"></a>

Para poder aceder à partição que criou anteriormente, deve configurar um acesso.

:::info
Apenas os endereços IP dos serviços OVHcloud podem aceder ao seu NAS (ex: um servidor dedicado, um VPS, uma instância Public Cloud, etc..)

:::


Para autorizar um IP a aceder ao NAS, clique no botão <code className="action">(...)</code> situado à direita da partição existente e, a seguir, em <code className="action">Gerir os acessos</code>.

<img className="thumbnail" alt="gerir os acessos" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-06.png" loading="lazy" />

A seguir, clique em <code className="action">Adicionar acesso</code> e selecione o endereço IP do seu produto OVHcloud.
<br/>Deve igualmente definir se o acesso autorizado para este endereço IP está disponível apenas em leitura (*Read-only*) ou em leitura/escrita (*Read/Write*)

<img className="thumbnail" alt="adicionar um acesso" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-07.png" loading="lazy" />

#### Eliminar um acesso

Para eliminar um acesso a uma partição, clique no botão <code className="action">(...)</code> situado à direita do endereço IP em causa e, a seguir, em <code className="action">Eliminar</code>.

<img className="thumbnail" alt="createaccess" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-09.png" loading="lazy" />

### Parâmetros Z File System (ZFS)

:::warning
Os parâmetros ZFS predefinidos são adequados à maioria das utilizações. Altere-os apenas se conhecer os dados alojados na partição.

:::


Para modificar os parâmetros ZFS de uma partição, clique no botão <code className="action">(...)</code> à direita da partição em causa e, a seguir, em <code className="action">Configurar a utilização (ZFS)</code>.

Pode então aplicar um template de utilização adaptado aos seus dados (<code className="action">Default</code>, <code className="action">Virtual machines</code>, <code className="action">Databases</code> ou <code className="action">File Systems (big files)</code>) ou definir manualmente os valores *atime*, *recordsize* e *sync* com a opção <code className="action">Custom</code>.

Para mais informações sobre cada parâmetro e os valores aplicados por cada template, consulte o nosso guia "[Configurar os parâmetros ZFS de uma partição](/guides/storage-and-backup/file-storage/ha-nas/nas-zfs-settings)".

### Eliminar partição

:::danger
A eliminação de uma partição implica a eliminação total e definitiva de todos os dados nela contidos.

:::


Para eliminar uma partição, clique no botão <code className="action">(...)</code> situado à direita da partição existente e, a seguir, em <code className="action">Eliminar</code>.

<img className="thumbnail" alt="eliminar uma partição" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-08.png" loading="lazy" />
