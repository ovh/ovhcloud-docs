## Objetivo

**Descubra como restaurar os dados de que fez cópia de segurança com Backup Agent.**

Dispõe de dois métodos de restauração, a escolher consoante a sua necessidade:

- **Restauração de ficheiros (assistente FLR)**: é o método principal e mais comum. Permite restaurar um ou vários ficheiros ou pastas a partir de uma cópia de segurança, sem reiniciar o servidor.
- **Restauração completa do servidor (Bare Metal Recovery)**: permite restaurar todo o sistema a partir de uma imagem ISO de recuperação. Destina-se a cenários de recuperação após desastre, quando o servidor já não arranca.

:::info
Encontre mais informações sobre o produto Backup Agent em [esta página](/guides/storage-and-backup/backup-agent/product-presentation).

:::


## Requisitos

- Dispor de um servidor Bare Metal com o Backup Agent instalado e configurado. Consulte o nosso guia "[Como configurar a sua primeira cópia de segurança](/guides/storage-and-backup/backup-agent/first-configuration)" para mais informações.
- Ter efetuado pelo menos uma cópia de segurança. Consulte o nosso guia "[Gerir as suas cópias de segurança](/guides/storage-and-backup/backup-agent/backup-restore)" para mais informações.

## Instruções

### Restauração de ficheiros (assistente FLR)

É o método principal para recuperar um ou vários ficheiros ou pastas a partir de uma cópia de segurança.

Para restaurar ficheiros e pastas, clique no separador correspondente ao seu sistema operativo:

<Tabs>
  <Tab label="Windows">
    Abra a aplicação "Veeam Agent" no seu servidor Bare Metal:
    
    <img className="thumbnail" alt="Pesquisa da aplicação Veeam Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-bkpagent-search.png" loading="lazy" />

Vá ao menu e selecione <code className="action">Restore File</code>:
    
    <img className="thumbnail" alt="Menu de restauro do Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-menu.png" loading="lazy" />

Selecione o ponto de restauração desejado no assistente:
    
    <img className="thumbnail" alt="Pontos de restauro do Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-restore-points.png" loading="lazy" />

Em seguida, valide:
    
    <img className="thumbnail" alt="Resumo do ponto de restauro do Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-restore-point-summary.png" loading="lazy" />

Finalmente, procure o seu ficheiro e selecione uma opção:
    
    <img className="thumbnail" alt="Assistente de restauro do Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-wizard.png" loading="lazy" />
    
    - Restore - Overwrite: permite-lhe restaurar o ficheiro substituindo o que está atualmente no servidor.
    - Restore - Keep: permite-lhe restaurar o ficheiro mantendo o que está atualmente no servidor.
    - Copy To: permite-lhe copiar o ficheiro para um local no seu servidor.
    - Explore: permite-lhe explorar a cópia de segurança.
    - Properties: permite-lhe ver as propriedades do ficheiro.
    
    Iniciar uma restauração permitirá-lhe ter uma última janela que mostrará a transferência:
    
    <img className="thumbnail" alt="Transferência do restauro do Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-transfer.png" loading="lazy" />
  </Tab>
  <Tab label="Linux">
    Para restaurar ficheiros e pastas no Linux, tem duas opções: através da interface gráfica ou através da linha de comandos.
    
    #### Através da interface gráfica
    
    1\. Ligue-se ao seu servidor Bare Metal via SSH.
    2\. Inicie a interface Veeam introduzindo o seguinte comando:
    
    ```bash
    sudo veeam
    ```
    
    3\. Na interface, selecione a opção de restauração de ficheiros.
    4\. Selecione o Backup e o ponto de restauração desejado.
    5\. Navegue na cópia de segurança para encontrar os ficheiros ou pastas a restaurar.
    6\. Selecione os ficheiros e escolha a ação de restauração:
       - Restaurar para o local original
       - Copiar para um novo local
       - Explorar a cópia de segurança
    
    #### Através da linha de comandos
    
    Para restaurar ficheiros através da linha de comandos, tem primeiro de montar a cópia de segurança:
    
    1\. Liste os seus backups disponíveis:
    
    ```bash
    sudo veeamconfig backup list
    ```
    
    2\. Liste os pontos de restauração de um Backup:
    
    ```bash
    sudo veeamconfig restore list --backup <nome_do_backup>
    ```
    
    3\. Monte um ponto de restauração:
    
    ```bash
    sudo veeamconfig mount --backup <nome_do_backup> --restorepoint <nome_do_ponto>
    ```
    
    4\. Uma vez montado, pode aceder aos ficheiros através do ponto de montagem (geralmente em `/mnt/veeam/`).
    
    5\. Copie os ficheiros desejados a partir do ponto de montagem para o seu destino.
    
    6\. Uma vez terminada a restauração, desmonte a cópia de segurança:
    
    ```bash
    sudo veeamconfig unmount --backup <nome_do_backup>
    ```
    
    Para mais informações, consulte a [documentação Veeam](https://helpcenter.veeam.com/docs/agentforlinux/userguide/files_restore_gui.html?ver=13) e a [documentação sobre a restauração em linha de comandos](https://helpcenter.veeam.com/docs/agentforlinux/userguide/files_restore_cmd.html?ver=13).
  </Tab>
</Tabs>

### Restauração completa do servidor (Bare Metal Recovery)

Bare Metal Recovery é uma funcionalidade do Veeam que consiste em criar previamente uma imagem ISO personalizada, que pode depois ser utilizada para arrancar um sistema e restaurá-lo a partir de uma cópia de segurança armazenada num outro servidor. Este método destina-se a cenários de recuperação após desastre, quando o seu servidor já não arranca.

Permite:

- Criar uma **imagem ISO de recuperação**: este ficheiro permite arrancar a sua máquina em caso de falha no arranque do sistema.
- Utilizar a sua imagem ISO para aceder à sua última cópia de segurança e restaurá-la a partir da infraestrutura OVHcloud.

:::warning
Este procedimento baseia-se no Veeam Agent para Windows. Se utilizar o Veeam Agent para Linux, o procedimento é semelhante, embora a interface seja em modo de texto.
:::


Para arrancar a partir da ISO de recuperação, utilize o IPMI do seu servidor Bare Metal para carregar a ISO.

#### Etapa 1: Criar a ISO de recuperação

Se o seu computador já não arranca, vai precisar de uma imagem ISO de recuperação para o voltar a iniciar.

:::warning
Esta imagem deve ser criada antes de qualquer incidente. Se o seu servidor já não estiver disponível, não a poderá criar.
:::


Eis como criá-la:

1\. Abra a ferramenta **Create Recovery Media**, incluída com o Veeam Agent, na sua máquina.

<img className="thumbnail" alt="Iniciar a ferramenta Create Recovery Media" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_01.png" loading="lazy" />

2\. O Veeam irá perguntar-lhe se pretende incluir controladores adicionais.

:::info
Se utilizar hardware específico (como um controlador RAID), selecione os controladores necessários. Caso contrário, as opções predefinidas costumam ser suficientes.
:::


<img className="thumbnail" alt="Selecionar os controladores para a imagem de arranque" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_02.png" loading="lazy" />

3\. Escolha o local onde guardar a ISO e atribua-lhe um nome.

<img className="thumbnail" alt="Definir o local e o nome da ISO" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_03.png" loading="lazy" />

4\. Aguarde até ao fim da operação. O ficheiro ISO será gerado.

<img className="thumbnail" alt="ISO de recuperação criada" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_04.png" loading="lazy" />

<img className="thumbnail" alt="ISO de recuperação" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_05.png" loading="lazy" />

Pode agora utilizar esta ISO para criar uma pen USB de arranque com uma ferramenta como o Rufus.

#### Etapa 2: Arrancar a máquina a partir da ISO de recuperação

Se o seu sistema já não arranca e precisa de o restaurar:

1\. Monte a ISO na consola do seu servidor e, em seguida, arranque a máquina a partir dela.

:::tip
**Não sabe como arrancar a partir de uma ISO?**

Reinicie a sua máquina física e prima a tecla indicada (geralmente F2, F12, ESC ou DEL) para aceder ao menu de arranque.
:::


2\. Assim que o sistema arrancar, o assistente de recuperação Veeam abrir-se-á. Clique em <code className="action">Bare Metal Recovery</code>.

<img className="thumbnail" alt="Iniciar Bare Metal Recovery" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_01.png" loading="lazy" />

3\. Selecione <code className="action">Network Storage</code> para aceder às suas cópias de segurança em linha.

:::warning
Se a rede não for detetada, poderá ter de a configurar manualmente. Clique em <code className="action">Configure network settings</code> e carregue os controladores em falta.
:::


<img className="thumbnail" alt="Selecionar Network Storage" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_02.png" loading="lazy" />

4\. Selecione <code className="action">Veeam Cloud Connect repository</code>.

<img className="thumbnail" alt="Escolher o repositório Veeam Cloud Connect" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_03.png" loading="lazy" />

5\. Introduza o endereço seguinte quando lhe for pedido o fornecedor de serviço:

<img className="thumbnail" alt="Introduzir os DNS" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_04.png" loading="lazy" />

:::warning
Para saber qual o DNS e as credenciais a utilizar, deve [contactar o nosso suporte](/links/support-contact) para as obter.
:::


6\. Introduza o seu nome de utilizador e a sua palavra-passe para iniciar sessão.

<img className="thumbnail" alt="Introduzir as credenciais" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_05.png" loading="lazy" />

7\. Selecione o servidor que pretende restaurar.

<img className="thumbnail" alt="Selecionar o servidor" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_06.png" loading="lazy" />

8\. Escolha o ponto de restauração (data/hora) para o qual pretende regressar.

Recomendamos que utilize a cópia de segurança bem-sucedida mais recente, exceto se tiver um motivo específico para regressar a uma versão anterior.

<img className="thumbnail" alt="Escolher um ponto de restauração" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_07.png" loading="lazy" />

9\. Escolha o modo de restauração adequado à sua situação (escolha **Entire computer** para uma restauração completa).

<img className="thumbnail" alt="Modo de restauração" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_08.png" loading="lazy" />

10\. Verifique o resumo e, em seguida, inicie a restauração.

<img className="thumbnail" alt="Iniciar a restauração - confirmação" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_09.png" loading="lazy" />

<img className="thumbnail" alt="Iniciar a restauração - progresso" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_10.png" loading="lazy" />

:::warning
A duração do processo de restauração depende da dimensão da sua cópia de segurança e da velocidade da sua ligação à Internet. Assim que terminar, o seu sistema reiniciará com o estado correspondente ao ponto de restauração selecionado.
:::
