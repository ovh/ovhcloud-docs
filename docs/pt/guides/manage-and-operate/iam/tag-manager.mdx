## Objetivo

Neste guia, vai aprender a atribuir e gerir tags nos seus produtos OVHcloud e a utilizá-las nas políticas IAM.

## Requisitos

- Dispor de uma [conta de cliente OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation).

[[cpnav:iam-tag-management-console]]

## Instruções

### Gerir as tags a partir da consola OVHcloud

Pode gerir as tags dos seus produtos OVHcloud através da interface geral de gestão de tags ou através das interfaces dedicadas nos produtos.

As tags são metadados sob a forma de pares chave-valor adicionados aos recursos OVHcloud, que podem ser utilizados nas políticas IAM ou para a categorização dos recursos.

#### Tag manager

O <ManagerLink to="/beta/#/customer/iam/tag-manager">Tag manager</ManagerLink> é a interface que lhe permite gerir as suas tags em todos os seus produtos OVHcloud.

A página apresenta todas as tags atualmente colocadas nos seus recursos.

<img className="thumbnail" alt="Página Tag manager com a lista pendente Tipo de Tag e a coluna Tipo de Tag" src="/images/manage-and-operate/iam/iam-tag-manager/console/tag-manager-01.png" loading="lazy" />

Para cada tag, a lista indica o número de recursos associados a essa tag e o tipo de tag.

Existem três tipos de tags:

- Personalizado: criada e gerida por si.
- Predefinido: criada pela OVHcloud; cabe-lhe a si atribuir este tipo de tag aos seus recursos.
- Sistema: criada e atribuída automaticamente pela OVHcloud aos seus recursos (não pode ser eliminada).

Por predefinição, a lista pendente **Tipo de Tag** está definida como <code className="action">Todos os tipos</code>, e a página apresenta também as tags predefinidas não atribuídas. Para restringir a lista, selecione <code className="action">Personalizado</code>, <code className="action">Predefinido</code>, <code className="action">Sistema</code> ou <code className="action">Não atribuído</code> nesta lista pendente.

Clique numa tag para abrir os respetivos detalhes, com a lista dos recursos aos quais está atribuída.

<img className="thumbnail" alt="Página de uma tag com os botões Atribuir a recursos e Desatribuir tag" src="/images/manage-and-operate/iam/iam-tag-manager/console/tag-manager-02.png" loading="lazy" />

Pode então atribuir esta tag a outros recursos com o botão <code className="action">Atribuir a recursos</code>. É então apresentada a lista de todos os recursos da conta, que permite uma seleção múltipla.

Um campo de pesquisa ajuda-o a encontrar os recursos.

Inversamente, para retirar a tag de alguns recursos, selecione-os nos detalhes da tag e clique em <code className="action">Desatribuir tag</code>.

#### Painel de controlo do produto

Para alguns produtos OVHcloud, foi adicionada uma interface para gerir as tags diretamente a partir do painel de gestão do recurso.

A interface de gestão de tags permite adicionar ou retirar tags do recurso.

Pode selecionar uma ou várias tags da lista de tags predefinidas ou introduzir as suas próprias tags, escrevendo diretamente as chaves e os valores nos campos.

### Gerir as tags através da API

A gestão das tags está centralizada numa única API para todos os produtos OVHcloud:

| **Método** |              **Caminho**               |          **Descrição**           |
| :--------: | :------------------------------------: | :------------------------------: |
|    POST    |    /iam/resource/&#123;resourceURN&#125;/tag    |   Adicionar uma tag a um recurso   |
|    DEL     | /iam/resource/&#123;resourceURN&#125;/tag/&#123;key&#125; | Retirar uma tag de um recurso |

A tag deve ser indicada no seguinte formato:

```json
{
  "key": "environment",
  "value": "production"
}
```

### Utilizar as tags nas políticas IAM

As tags podem ser utilizadas como condições nas políticas IAM através da condição `resource.Tag(tag_key)`.

Por exemplo, a política seguinte concede direitos a todos os VPS com a tag `Environment:Production`:

```json
{
  "conditions": {
    "conditions": [
      {
        "operator": "MATCH",
        "values": {
          "resource.Tag(Environment)": "Production"
        }
      }
    ],
    "operator": "AND"
  },
  "description": "Give access to VPS with tag Environment:Production",
  "identities": [
    "urn:v1:eu:identity:group:aa1-ovh/devs"
  ],
  "name": "vps-production",
  "permissions": {
    "allow": [
      {
        "action": "vps:apiovh:*"
      }
    ]
  },
  "resources": [
    {
      "urn": "urn:v1:eu:resource:vps:*"
    }
  ]
}
```
