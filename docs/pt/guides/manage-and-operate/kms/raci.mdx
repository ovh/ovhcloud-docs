## Objetivo

O RACI abaixo detalha a partilha de responsabilidades entre a OVHcloud e o cliente para o serviço OKMS. Este modelo pode ajudar o cliente a tirar o máximo partido do serviço.

| Funções |
| --- |
|R : Está encarregado da **R**ealização do processo|
|A : É o **A**provador da realização do processo|
|C : É **C**onsultado durante o processo|
|I : É **I**nformado dos resultados do processo|
