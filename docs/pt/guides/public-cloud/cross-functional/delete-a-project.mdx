## Objetivo

Quando já não precisa de um [projeto Public Cloud](/links/public-cloud/public-cloud), pode eliminá-lo diretamente na <ManagerLink to="/">consola OVHcloud</ManagerLink>.

Ao eliminar um projeto Public Cloud, será emitida uma fatura final que conterá o montante por pagar.

:::warning
A eliminação de um projeto é diferente da desativação das suas instâncias Public Cloud.<br/>
Quando um projeto é eliminado, os recursos que contém são definitivamente perdidos. Esta operação não pode ser anulada.
:::

**Saiba como eliminar um projeto Public Cloud a partir da consola OVHcloud.**

## Requisitos

- Um [projeto Public Cloud](/links/public-cloud/public-cloud) na sua conta OVHcloud.

[[cpnav:publiccloud-project-settings-console]]

## Instruções

1. No menu à esquerda do seu projeto Public Cloud, clique em <code className="action">Gestão do projeto</code>.
2. Clique no separador <code className="action">Definições</code>.
3. Na secção **Eliminar o projeto**, clique em <code className="action">Eliminar o projeto</code>.
4. A janela **Cancelar projeto** informa-o de que todos os seus serviços, recursos, parâmetros e dados serão destruídos, com exceção dos IP failover, que serão estacionados. Clique em <code className="action">Sim, rescindir</code> para continuar.

:::info
Um projeto com um Savings Plan não pode ser eliminado: a secção **Eliminar o projeto** apresenta um aviso e a janela propõe <code className="action">Contactar o Apoio ao Cliente</code> em vez disso. Contacte as nossas equipas de assistência para eliminar este projeto.
:::

Ser-lhe-á então enviado um e-mail para o endereço de contacto, para confirmar ou anular a eliminação do projeto.

Depois de clicar na ligação de confirmação apresentada neste e-mail, será redirecionado para uma página web onde deverá introduzir a palavra-passe da sua conta.

Uma vez introduzida e confirmada a sua palavra-passe, o seu projeto entrará na fase de eliminação.

:::warning
Tenha em conta que, quando um projeto entra nesta fase de eliminação, fica suspenso durante 7 dias. Por conseguinte, o projeto não é imediatamente suprimido. Se esta situação o afetar, por exemplo se a sua quota de projetos for limitada, contacte as nossas equipas de assistência.

:::
