## Objetivo

A criação de um projeto é a primeira etapa na implantação de [instâncias Public Cloud](/links/public-cloud/public-cloud).

**Este guia o levará através das etapas de criação do seu primeiro projeto Public Cloud.**

## Instruções

### Criação do projeto

Os primeiros passos dependem de já ter ou não um projeto Public Cloud:

- **Trata-se do seu primeiro projeto Public Cloud:** a consola OVHcloud abre a página **Bem-vindo ao ecossistema Public Cloud**. Após ter tomado conhecimento, valide os termos dos contratos selecionando a caixa correspondente na secção **Contratos** e clique em <code className="action">Descobrir o universo Public Cloud</code>. O seu projeto é criado em [Modo Descoberta](#discovery).
- **Já tem um projeto Public Cloud:** na página **Projetos**, clique em <code className="action">Criar um novo projeto</code>. Também pode clicar no seletor <code className="action">Projeto</code> no topo do menu à esquerda e, a seguir, em <code className="action">Criar projeto</code>. Na página **Criar um projeto Public Cloud**:
    1. No campo **Nome do projeto**, introduza um nome para o seu projeto.
    2. Após ter tomado conhecimento, valide os termos dos contratos selecionando a caixa correspondente na secção **Contratos**.
    3. Na secção **Verifique a sua identidade com um método de pagamento**, selecione o seu método de pagamento. Se dispuser de um voucher, introduza-o na secção **Tem um código promocional?** e clique em <code className="action">Adicionar</code>.
    4. Clique em <code className="action">Criar o meu projeto</code>.

O Modo Descoberta não é proposto a algumas contas: o primeiro projeto destas contas também é criado a partir da página **Criar um projeto Public Cloud**.

Após a conclusão do processo de criação, o seu novo projeto Public Cloud é apresentado no seletor **Projeto** no topo do menu à esquerda do universo Public Cloud.

Já tem acesso a todo o ecossistema Public Cloud da OVHcloud. Descubra esta nova interface consultando o nosso guia "[Familiarizar-se com a interface Public Cloud](/guides/public-cloud/cross-functional/public-cloud-interface-walk-me)".

:::info
**Modo Descoberta**

O seu primeiro projeto Public Cloud é criado em "Modo Descoberta". Isto significa que pode procurar e descobrir os produtos Public Cloud, mas ainda não pode criar recursos como as instâncias. Enquanto este projeto estiver em Modo Descoberta, também não pode criar outro projeto: a consola OVHcloud pede-lhe primeiro que o ative.

Para explorar plenamente o potencial do Public Cloud e iniciar os seus primeiros recursos, ative o seu projeto:

1. Na página inicial do seu projeto, a faixa **Inicie a implementação dos seus recursos Cloud.** lembra-lhe que está em Modo Descoberta. Clique em <code className="action">Ativar</code> nesta faixa.
2. Na janela que se abre, clique em <code className="action">Ativar o seu projeto</code>.
3. Na página **Ativar o seu projeto**, valide um método de pagamento e clique em <code className="action">Ativar o seu projeto</code>.

:::

### Ativação do projeto e teste gratuito

Quando ativa um projeto a partir do `Modo Descoberta` e regista um método de pagamento, é aplicado um **crédito de teste de 200 €** se for elegível. Neste caso, a faixa da página inicial do seu projeto e a página **Ativar o seu projeto** apresentam o montante da oferta.

:::info
**Condições do teste gratuito**

- O crédito é ativado no momento da ativação do projeto e é válido durante **um mês**.
- **Elegível:** qualquer cliente OVHcloud que crie o seu primeiro projeto Public Cloud, mesmo que já disponha de uma conta OVHcloud.
- **Não elegível:** os clientes que disponham ou tenham disposto de um projeto Public Cloud, ou que já tenham beneficiado de um crédito de teste gratuito.

Saiba mais na página [Teste gratuito Public Cloud OVHcloud](/links/public-cloud/free-trial).
:::

:::info
**Criar projetos adicionais com o Terraform**

Depois de criar o seu primeiro projeto Public Cloud e validar um método de pagamento, pode criar outros projetos por programação com o recurso Terraform `ovh_cloud_project`. Para mais informações, consulte o guia [Terraform Tutorial (EN)](/guides/public-cloud/cross-functional/how-to-use-terraform#creating-a-public-cloud-project).

Atualmente não existe qualquer endpoint API nem comando CLI da OVHcloud dedicado à criação de projetos.
:::
