:::info
A partir de 6 de outubro de 2022, a nossa solução "Failover IP" passou a designar-se [Additional IP](/links/network/additional-ip). Isto não afeta as suas funcionalidades.

:::


## Objetivo

Se precisa de configurar um endereço Additional IP numa das suas instâncias, quer seja para:

- Tem vários sítios na sua instância. 
- Acolhe projectos internacionais.
- Deseja migrar a sua atividade de um servidor dedicado para uma instância Public Cloud.

Pode importar um endereço Additional IP associado a outro serviço OVHcloud.

**Este guia explica como poderá importar esse Additional IP para o seu projeto Public Cloud OVHcloud.**

## Requisitos

- Um [projeto Public Cloud](/links/public-cloud/public-cloud) criado na sua conta OVHcloud
- Um [endereço Additional IP](/links/bare-metal/ip)

[[cpnav:publiccloud-public-ips-console]]

:::warning
Esta funcionalidade não está atualmente disponível para as instâncias Metal.

:::


## Instruções

No menu à esquerda, abra <code className="action">Public IP</code> em **Rede**.

Abra o separador <code className="action">Additional IP</code> e clique em <code className="action">Importar um Additional IP</code> para apresentar todos os endereços IP que podem ser importados no seu projeto Public Cloud.

Clique no ícone <code className="action">Importar este Additional IP</code> na linha do endereço IP que deseja importar e, a seguir, valide clicando em <code className="action">Importar</code>.

Aguarde alguns minutos até que a importação seja concluída. Abra o separador <code className="action">Additional IP</code> para encontrar o endereço Additional IP importado. Atualize a página caso seja necessário.

Clique em <code className="action">...</code> na linha do IP e selecione <code className="action">Alterar a instância associada</code>. No painel que aparece, escolha em **Selecione uma instância** a instância à qual o seu endereço IP deve estar associado.

Clique em <code className="action">Anexar</code> para confirmar.

:::warning
Um IP adicional não pode ser migrado entre diferentes zonas. Por exemplo, um IP localizado no datacenter SBG pode ser migrado para GRA ou RBX mas não para BHS.

:::


O seu endereço Additional IP será associado à sua instância.

O próximo passo consiste em configurar o IP no seu sistema operativo. Consulte o [nosso guia dedicado a esta configuração](/guides/public-cloud/network-services/configure-additional-ip).
