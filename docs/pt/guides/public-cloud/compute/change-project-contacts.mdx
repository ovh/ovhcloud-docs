## Objetivo

Pode alterar os contactos de administrador e de faturação de um projeto Public Cloud na consola OVHcloud.

A modificação destes contactos permite dissociar a gestão técnica da gestão de faturação, para os serviços de um projeto.

**Este guia explica como alterar os contactos de um projeto Public Cloud na consola OVHcloud.**

## Requisitos

- Ter um projeto [Public Cloud](/links/public-cloud/public-cloud) na sua conta OVHcloud
- Contactos de administrador e faturação na mesma filial OVHcloud

[[cpnav:publiccloud-contacts-rights-console]]

## Instruções

### Modificar os contactos

No menu à esquerda do seu projeto Public Cloud, clique em <code className="action">Gestão do projeto</code> e, a seguir, no separador <code className="action">Contactos e direitos</code>.

Esta página permite-lhe ver os contactos de administrador e de faturação associados ao seu projeto.

Clique numa das ligações <code className="action">Editar</code> para modificar os contactos atuais. Esta ação abre a página **Gestão dos contactos** da consola OVHcloud num novo separador. As ligações <code className="action">Editar</code> só estão disponíveis para as contas da zona UE, e não para um projeto em modo Descoberta.

Os contactos do seu projeto Public Cloud aparecem no separador <code className="action">Serviços</code>. Clique no botão <code className="action">...</code> e, a seguir, em <code className="action">Alterar os contactos</code>.

Na janela **Alterar os contactos**, indique o identificador de cliente desejado para cada contacto que pretende alterar (**Contacto administrador**, **Contacto técnico**, **Contacto de faturação**). Tenha em conta que as contas OVHcloud para os `Contacto administrador` e `Contacto de faturação` devem estar obrigatoriamente registadas na mesma filial OVHcloud.

Depois de clicar no botão <code className="action">Confirmar</code>, as duas contas OVHcloud afetadas pela alteração receberão um e-mail de confirmação. Este e-mail contém um código (token) que permite validar a alteração de contacto no separador <code className="action">Os meus pedidos</code> da página **Gestão dos contactos**: clique em <code className="action">...</code> na linha do pedido, depois em <code className="action">Aceitar o pedido</code>, e introduza o código no campo **Código de validação**.

Para uma explicação mais detalhada deste procedimento, consulte o nosso guia "[Como gerir os contactos dos serviços OVHcloud](/guides/account-and-service-management/account-information/managing-contacts)".
