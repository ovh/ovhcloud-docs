## Objetivo

Pode criar uma snapshot única de uma instância ou configurar um planeamento para automatizar as snapshots das suas instâncias. As snapshots podem ser utilizadas para restaurar a sua instância para um estado anterior ou para criar uma nova instância idêntica.

**Este guia explica como criar snapshots manuais e automáticas de uma instância Public Cloud.**

## Requisitos

- Ter uma instância [Public Cloud](/links/public-cloud/public-cloud) na sua conta OVHcloud.
- CLI OpenStack. Consulte o nosso guia "[Preparar o ambiente para utilizar a API OpenStack](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment)". (opcional)

## Instruções

### Criar uma snapshot de uma instância

:::warning
Esta opção só está disponível através de um **Cold Snapshot** para as instâncias Metal. A instância Metal passará para o modo rescue e, uma vez efetuada a snapshot, a instância será reiniciada em modo normal.

:::


:::info
Estão disponíveis dois tipos de snapshots:

- Local: Uma snapshot local é armazenada na mesma região que a sua instância.
- Remota: Uma snapshot remota cria automaticamente uma cópia da snapshot local noutra região à sua escolha.

Cada snapshot é faturada separadamente. A snapshot remota será faturada de acordo com a tarifa de armazenamento da região remota selecionada.

**Nota:** As Local Zones não são elegíveis para snapshots remotas.

:::

    - **snapshotName**: Nome da snapshot local a criar.

### Criar uma snapshot automática de uma instância

:::info
Se desejar automatizar esta funcionalidade diretamente através do OpenStack, pode criar um workflow Mistral associado a um cron trigger.

:::


No menu à esquerda do seu projeto Public Cloud, clique em <code className="action">Instances</code> na secção **Compute**. Clique no botão <code className="action">...</code> à direita da instância e selecione <code className="action">Criar uma snapshot automática</code>.

Abre-se a página **Criar um planeamento**. Poderá configurar os seguintes parâmetros:

#### **O workflow** 

O planeamento cria uma snapshot automática da instância e do seu volume principal. Não é necessário escolher nenhum tipo de workflow.

#### **O recurso** 

Na secção **Selecione um recurso atribuído**, pode selecionar a instância da qual pretende criar uma snapshot.

#### **Nome** 

Na secção **Atribua um nome ao seu planeamento**, introduza um nome para o planeamento da snapshot automática. Consulte as informações tarifárias no resumo à direita e, em seguida, crie o planeamento clicando em <code className="action">Criar</code>.

#### **O planeamento** 

Na secção **Definir o planeamento**, pode definir um planeamento personalizado (**Personalizado**, em formato cron UNIX, em UTC) ou escolher uma das frequências predefinidas:

- **Rotação 7**: snapshot diária com retenção das últimas 7 snapshots
- **Rotação 14**: snapshot diária com retenção das últimas 14 snapshots

<details>

<summary>**Adicionar uma snapshot remota**</summary>


Ative <code className="action">Adicionar uma snapshot remota</code>, selecione uma localização, consulte as informações tarifárias e clique no botão <code className="action">Criar</code>.

</details>


### Gestão das snapshots e dos planeamentos

Os planeamentos são listados e eliminados na página **Gestão do fluxo de trabalho**: clique em <code className="action">Workflow</code> na secção **Compute** do menu à esquerda.

As snapshots das suas instâncias são geridas na página **Snapshots de instância**: clique em <code className="action">Instance Snapshot</code> na secção **Compute** do menu à esquerda.

:::warning
A opção de snapshot da instância deve ser eliminada separadamente se já não desejar que esta lhe seja faturada. A eliminação de uma instância não elimina as opções que lhe estão associadas.

:::


:::warning
**Tenha em atenção que não é possível eliminar uma snapshot de instância se uma instância gerada a partir desta snapshot estiver a ser executada no momento da eliminação.**

:::
