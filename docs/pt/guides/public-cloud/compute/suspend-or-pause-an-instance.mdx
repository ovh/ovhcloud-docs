## Objetivo

No âmbito da configuração de uma infraestrutura de alta disponibilidade, é possível que tenha de reduzir o acesso às suas instâncias para efetuar alguns testes. O OpenStack permite-lhe passar para Shelve, parar (Shutoff), suspender ou colocar em pausa a sua instância. Em cada caso, o seu endereço IP é mantido.

:::warning
Na consola OVHcloud, só estão disponíveis as ações **Shelve** / **Unshelve** e **Hard stop** (ação OpenStack *stop*, *Shut Off* no Horizon). **Suspend** / **Resume** e **Pause** / **Unpause** estão disponíveis através da API OVHcloud (v2), no Horizon e através da API OpenStack.

:::

**Este guia explica como passar para Shelve, parar (Hard stop), suspender ou colocar em pausa a sua instância.**

## Requisitos

- uma [instância Public Cloud](/guides/public-cloud/compute/getting-started) sobre faturação à **hora**
- acesso à [interface Horizon](/guides/public-cloud/cross-functional/introducing-horizon)
- Conhecimento da [API OpenStack](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment) e das [variáveis OpenStack](/guides/public-cloud/cross-functional/compute-set-openstack-environment-variables)

## Instruções

:::warning
**Âmbito:** Este guia aplica-se a todas as instâncias de Public Cloud, independentemente do modelo de faturação (à hora ou mensal).

**Faturação mensal:** para as instâncias faturadas ao mês, o preço mensal da instância continua a ser faturado seja qual for o seu estado. Uma instância mensal em Shelve é faturada ao seu preço mensal, mais a snapshot.

**Nota:** Enquanto a instância não for eliminada, qualquer operação continuará a gerar encargos de instância.

:::

A tabela abaixo permite-lhe diferenciar as opções disponíveis nas suas instâncias. Clique na opção que preferir para continuar a leitura deste guia. Indicamos entre parênteses a ação OpenStack correspondente.

|Opção|Estado da memória|Dados do disco|Recursos do anfitrião (CPU/RAM)|Retoma|Faturação|
|---|---|---|---|---|---|
|[Hard stop (*stop*)](#hard-stop-instance)|Perdido|Conservados|Continuam alocados no anfitrião|Arranque a frio (o SO reinicia)|É faturado ao mesmo preço.|
|[Shelve (*shelve*)](#shelve-instance)|Perdido|Guardados numa imagem snapshot|Libertados assim que a instância é descarregada (*offloaded*)|Arranque a frio a partir da snapshot, eventualmente noutro anfitrião|Instâncias à hora: só a snapshot é faturada. Instâncias ao mês: o preço mensal da instância, mais a snapshot.|
|[Pause (*pause*)](#pause-instance)|Conservado na RAM do anfitrião|Conservados|Continuam alocados e consumidos|Instantânea, exatamente onde tinha parado|É faturado ao mesmo preço.|
|[Suspend (*suspend*)](#stop-suspend-instance)|Gravado no disco do anfitrião|Conservados|RAM/CPU libertados no hipervisor, alocação conservada|Restaura o estado guardado, como uma hibernação|É faturado ao mesmo preço.|

Em cada caso, o endereço IP da instância é conservado.

### Passar uma instância para Shelve

:::danger
Tenha em atenção que passar para Shelve uma instância IOPS ou T1/T2-180 resultará na perda de dados nos discos NVMe em passthrough.

Passar para Shelve este tipo de instância leva à sua desativação do anfitrião e, por conseguinte, dos discos em passthrough.

:::

Esta opção permite libertar os recursos dedicados à sua instância de Public Cloud, mas o endereço IP fica. Os dados do seu disco local serão armazenados numa snapshot criada automaticamente após a passagem da instância para Shelve. Os dados armazenados na memória e noutros locais não serão conservados.

<Tabs>
  <Tab label="Consola OVHcloud">
    No menu à esquerda do seu projeto Public Cloud, clique em <code className="action">Instances</code> na secção **Compute**.

    Clique no botão <code className="action">...</code> à direita da instância que pretende passar para Shelve e, a seguir, em <code className="action">Shelve</code>.

    Na janela **Passar a instância para Shelve**, tome conhecimento da mensagem e clique em <code className="action">Confirmar</code>.

    Uma vez concluída a operação, o estado da sua instância aparecerá como **Shelve**.

    Para visualizar a snapshot, clique em <code className="action">Instance Snapshot</code> na secção **Compute** do menu à esquerda. Uma snapshot chamada *xxxxx-shelved* estará então visível.
  </Tab>
  <Tab label="CLI OVHcloud">
    Antes de continuar, recomendamos que consulte os seguintes guias:

    - [Conhecer as bases do CLI OVHcloud](/guides/manage-and-operate/cli/getting-started)

    Introduza o seguinte comando:

    ```shell
    ovhcloud cloud instance shelve <instance_id>
    ```
  </Tab>
  <Tab label="API OVHcloud">
    Utilize a seguinte chamada API, em que `projectId` é o ID do seu projeto Public Cloud e `instanceId` o ID da instância:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Com o seguinte corpo de pedido:

    ```json
    {
      "type": "SHELVE"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Antes de continuar, recomendamos que consulte os seguintes guias:

    - [Preparar o ambiente para utilizar a API OpenStack](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment)
    - [Carregar as variáveis de ambiente OpenStack](/guides/public-cloud/cross-functional/compute-set-openstack-environment-variables)

    Quando o ambiente estiver pronto, introduza o seguinte na linha de comandos:

    ```bash
    ~$ openstack server shelve <UUID server>

    =====================================

    ~$ nova shelve <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    Para utilizar este método, é necessário [ligar-se à interface Horizon](https://horizon.cloud.ovh.net/auth/login/):

    - Para se ligar com a autenticação única OVHcloud: abra o seu projeto Public Cloud na <ManagerLink to="/">consola OVHcloud</ManagerLink> e clique em <code className="action">OpenStack Horizon</code> no widget **Documentação e assistência** da página inicial do projeto.

    - Para se ligar com um utilizador OpenStack específico: abra a página de ligação ao [Horizon](https://horizon.cloud.ovh.net/auth/login/) e introduza os [identificadores OpenStack](/guides/public-cloud/cross-functional/create-and-delete-a-user) previamente criados, depois clique em <code className="action">Connect</code>.

    Se implementou instâncias em regiões diferentes, certifique-se de que se encontra na região apropriada. Pode verificá-lo no canto superior esquerdo da interface Horizon.

    <img className="thumbnail" alt="horizon interface" src="/images/public-cloud/compute/suspend-or-pause-an-instance/firstaccesshorizon.png" loading="lazy" />

    Clique no menu <code className="action">Compute</code> à esquerda e depois em <code className="action">Instâncias</code>. Selecione <code className="action">Shelve Instance</code> na lista pendente correspondente à instância.

    <img className="thumbnail" alt="shelve instance" src="/images/public-cloud/compute/suspend-or-pause-an-instance/shelveinstancehorizon.png" loading="lazy" />

    Uma vez terminado o processo, a sua instância terá o estado *Shelved Offloaded*.

    <img className="thumbnail" alt="shelved instance" src="/images/public-cloud/compute/suspend-or-pause-an-instance/newinstancestatushorizon.png" loading="lazy" />

    Para visualizar a snapshot, no menu <code className="action">Compute</code>, clique em <code className="action">Images</code>.

    <img className="thumbnail" alt="snapshot" src="/images/public-cloud/compute/suspend-or-pause-an-instance/snapshothorizon.png" loading="lazy" />
  </Tab>
</Tabs>

<a name="unshelve-instance"></a>

### Fazer o Unshelve de uma instância

Esta opção permite-lhe reativar a sua instância para que a possa continuar a utilizar. Tenha em conta que, uma vez efetuada esta operação, a faturação será retomada normalmente.

:::danger
**Ações na snapshot**

Qualquer ação na snapshot que não a reativação (*unshelve*) pode ser muito perigosa para a sua infraestrutura em caso de mau uso. Quando uma instância é "reativada" (*unshelved*), a snapshot é automaticamente eliminada. Não é recomendado implementar uma nova instância a partir de uma snapshot criada na sequência da passagem de uma instância para Shelve.

A OVHcloud disponibiliza-lhe serviços cuja responsabilidade lhe incumbe. Com efeito, não tendo qualquer acesso a estas máquinas, não somos os seus administradores e não poderemos fornecer-lhe assistência. Cabe-lhe, por conseguinte, assegurar a gestão de software e a segurança no quotidiano. Em caso de dificuldades ou de dúvidas relativas à administração, à utilização ou à segurança de um servidor, recomendamos que recorra a um [prestador especializado](/links/partner).
:::

<Tabs>
  <Tab label="Consola OVHcloud">
    No menu à esquerda do seu projeto Public Cloud, clique em <code className="action">Instances</code> na secção **Compute**.

    Clique no botão <code className="action">...</code> à direita da instância e, a seguir, em <code className="action">Unshelve</code>.

    Na janela **Unshelve da instância**, clique em <code className="action">Confirmar</code>.

    Uma vez concluída a operação, o estado da sua instância aparecerá como **Ativa**.
  </Tab>
  <Tab label="CLI OVHcloud">
    Introduza o seguinte comando:

    ```shell

    ```
  </Tab>

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Com o seguinte corpo de pedido:

    ```json

      "type": "UNSHELVE"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">

    =========================================

    ~$ nova unshelve <UUID server>

  </Tab>
  <Tab label="Horizon">

    <img className="thumbnail" alt="unshelve instance" src="/images/public-cloud/compute/suspend-or-pause-an-instance/unshelveinstancehorizon.png" loading="lazy" />

  </Tab>

<a name="hard-stop-instance"></a>

### Fazer o Hard stop (*stop*) de uma instância

Esta opção para a sua instância (ação OpenStack *stop*, *Shut Off* no Horizon). Os dados do disco são conservados, mas o estado da memória perde-se: a instância reinicia quando a voltar a iniciar. Os recursos dedicados à instância continuam reservados, incluindo o endereço IP, e a instância continua a ser faturada ao mesmo preço.

<Tabs>
  <Tab label="Consola OVHcloud">
    No menu à esquerda do seu projeto Public Cloud, clique em <code className="action">Instances</code> na secção **Compute**.

    Clique no botão <code className="action">...</code> à direita da instância que pretende parar e, a seguir, em <code className="action">Hard stop</code>.

    Na janela **Hard stop da instância**, tome conhecimento da mensagem e clique em <code className="action">Confirmar</code>.

    Uma vez concluída a operação, o estado da sua instância aparecerá como **Hard stop (Shutoff)**.

    Para **voltar a iniciar** a instância, clique no botão <code className="action">...</code> à direita da instância e selecione <code className="action">Iniciar</code>; depois, clique em <code className="action">Confirmar</code> na janela **Iniciar a instância**. Em alguns casos, poderá ser necessário efetuar um reinício a frio.

    Uma vez concluída a operação, o estado da sua instância aparecerá como **Ativa**.
  </Tab>
  <Tab label="CLI OVHcloud">
    Introduza o seguinte comando:

    ```shell
    ovhcloud cloud instance stop <instance_id>
    ```

    Para **voltar a iniciar** a instância, introduza o seguinte comando:

    ```shell
    ovhcloud cloud instance start <instance_id>
    ```
  </Tab>
  <Tab label="API OVHcloud">
    Utilize a seguinte chamada API, em que `projectId` é o ID do seu projeto Public Cloud e `instanceId` o ID da instância:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Com o seguinte corpo de pedido:

    ```json
    {
      "type": "STOP"
    }
    ```

    Para **retomar** a instância, utilize a mesma chamada com o tipo `START`:

    ```json
    {
      "type": "START"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Quando o ambiente estiver pronto, introduza o comando abaixo na linha de comandos:

    ```bash
    ~$ openstack server stop <UUID server>

    =========================================

    ~$ nova stop <UUID server>
    ```

    Para **voltar a iniciar** a instância, introduza o comando abaixo na linha de comandos:

    ```bash
    ~$ openstack server start <UUID server>

    =========================================

    ~$ nova start <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    Na interface Horizon, clique no menu <code className="action">Compute</code> à esquerda e depois selecione <code className="action">Instâncias</code>. Selecione <code className="action">Shut Off Instance</code> na lista pendente correspondente à instância.

    Para **voltar a iniciar** a instância, selecione <code className="action">Start Instance</code> na lista pendente correspondente à instância.
  </Tab>
</Tabs>

<a name="stop-suspend-instance"></a>

### Suspender (*Suspend*) uma instância

Esta opção suspende a sua instância: o estado da memória é gravado no disco do anfitrião, e a RAM e o CPU são libertados no hipervisor, mantendo-se a alocação. Na retoma, o estado guardado é restaurado, como após uma hibernação. É faturado ao mesmo preço.

Esta ação não está disponível na consola OVHcloud: utilize a API OVHcloud, a interface Horizon ou as API OpenStack/Nova.

<Tabs>
  <Tab label="API OVHcloud">
    Utilize a seguinte chamada API, em que `projectId` é o ID do seu projeto Public Cloud e `instanceId` o ID da instância:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Com o seguinte corpo de pedido:

    ```json
    {
      "type": "SUSPEND"
    }
    ```

    Para **retomar** a instância, utilize a mesma chamada com o tipo `RESUME`:

    ```json
    {
      "type": "RESUME"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Quando o ambiente estiver pronto, introduza o comando abaixo na linha de comandos:

    ```bash
    ~$ openstack server suspend <UUID server>

    =========================================

    ~$ nova suspend <UUID server>
    ```

    Para **retomar** a instância, introduza o comando abaixo na linha de comandos:

    ```bash
    ~$ openstack server resume <UUID server>

    =========================================

    ~$ nova resume <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    Na interface Horizon, clique no menu <code className="action">Compute</code> à esquerda e depois selecione <code className="action">Instâncias</code>. Selecione <code className="action">Suspend Instance</code> na lista pendente correspondente à instância.

    <img className="thumbnail" alt="instance suspension horizon" src="/images/public-cloud/compute/suspend-or-pause-an-instance/suspendinstancehorizon.png" loading="lazy" />

    Aparece uma mensagem de confirmação a indicar que a instância foi suspensa.

    Para **retomar** a instância, efetue as mesmas operações que as indicadas acima. Na lista pendente correspondente à instância, selecione <code className="action">Resume Instance</code>.
  </Tab>
</Tabs>

<a name="pause-instance"></a>

### Colocar em pausa uma instância

Esta ação não está disponível na consola OVHcloud: utilize a API OVHcloud, a interface Horizon ou as API OpenStack/Nova. Permite-lhe colocar em espera ou "congelar" a sua instância. O estado da memória é conservado na RAM do anfitrião, e a instância é retomada instantaneamente, exatamente onde tinha parado.

<Tabs>
  <Tab label="API OVHcloud">
    Utilize a seguinte chamada API, em que `projectId` é o ID do seu projeto Public Cloud e `instanceId` o ID da instância:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Com o seguinte corpo de pedido:

    ```json
    {
      "type": "PAUSE"
    }
    ```

    Para **retomar** a instância, utilize a mesma chamada com o tipo `UNPAUSE`:

    ```json
    {
      "type": "UNPAUSE"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Quando o ambiente estiver pronto, introduza o comando abaixo na linha de comandos:

    ```bash
    ~$ openstack server pause <UUID server>

    =========================================

    ~$ nova pause <UUID server>
    ```

    Para **reativar** a instância, introduza o comando abaixo na linha de comandos:

    ```bash
    ~$ openstack server unpause <UUID server>

    =========================================

    ~$ nova unpause <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    Na interface Horizon, clique no menu <code className="action">Compute</code> à esquerda e depois selecione <code className="action">Instâncias</code>. Selecione <code className="action">Pause Instance</code> na lista pendente correspondente à instância.

    <img className="thumbnail" alt="Pause instance" src="/images/public-cloud/compute/suspend-or-pause-an-instance/pauseinstancehorizon.png" loading="lazy" />

    Aparece a mensagem de confirmação a indicar a colocação em pausa da instância.

    Para **reativar** a instância, efetue as mesmas etapas que as indicadas anteriormente. Na lista pendente correspondente à instância, selecione <code className="action">Resume Instance</code>.
  </Tab>
</Tabs>
