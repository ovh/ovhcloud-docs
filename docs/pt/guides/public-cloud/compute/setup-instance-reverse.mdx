## Objetivo

O **Reverse DNS** (*rDNS*) é o complemento da resolução "clássica" dos DNS que permite converter um nome de domínio num endereço IP (registo do tipo **A**). Graças a um pedido deste tipo, um endereço IP pode ser resolvido em nome de domínio (registo do tipo **PTR**). Isto significa que os pedidos DNS no endereço IP em causa irão devolver um domínio.

Configurar a resolução **Reverse DNS** de uma instância é particularmente útil para o envio de e-mails. O risco de as suas mensagens serem rejeitadas por um sistema de proteção contra spam será diminuído se o endereço IP do seu servidor de envio se resolver corretamente em seu nome de domínio.

**Saiba como configurar a reverse DNS para o(s) endereço(s) de IP da sua instância Public Cloud.**

## Requisitos

- Ter uma [instância Public Cloud](/links/public-cloud/public-cloud) na sua conta OVHcloud.
- Um domínio com o seu campo `A` apontando para a instância.

[[cpnav:network-public-ip-console]]

## Instruções

A lista <code className="action">Filtrar por serviço...</code> da página **Endereços IP** permite-lhe filtrar os seus endereços IP por serviço: selecione o seu projeto Public Cloud no grupo **Public Cloud**. Também pode pesquisar um endereço IP específico através da barra de pesquisa.

Clique no endereço IP em questão, abra o separador <code className="action">Reverse DNS</code> e clique em <code className="action">Configurar</code>.

Na janela **Configurar o Reverse DNS**, introduza o seu reverse no campo **Nome de host reverse DNS** e clique em <code className="action">Configurar</code>.

Para eliminar um reverse, clique no ícone de eliminação na linha do reverse, no separador **Reverse DNS**.

:::info
Se a alteração não funcionar como previsto, verifique se o campo `A` está corretamente configurado na zona DNS do seu domínio. Atenção, a modificação da [zona DNS](/guides/web-cloud/domains/dns-zone-edit) pode demorar até 24 horas se apenas alterou recentemente o campo `A`.
:::
