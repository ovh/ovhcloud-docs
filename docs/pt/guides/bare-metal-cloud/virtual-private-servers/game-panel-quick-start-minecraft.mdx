## Objetivo

O Game Panel OVHcloud permite-lhe implementar um servidor Minecraft com uma instalação e uma configuração das portas automatizadas.

**Este guia explica-lhe como implementar um servidor Minecraft no Game Panel OVHcloud e como ligar-se a ele.**

## Requisitos

- Um [VPS](/links/bare-metal/vps) ou um [servidor dedicado](/links/bare-metal/bare-metal) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um acesso ao Game Panel. Consulte o guia [Ligar-se ao Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instruções

### Etapa 1 — Aceder ao Game Panel

Ligue-se ao seu Game Panel OVHcloud.

### Etapa 2 — Criar uma nova instância de servidor

Clique em <code className="action">Add Game Server</code> e selecione **Minecraft**.

<img className="thumbnail" alt="Seleção de Minecraft na lista de jogos" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/select-minecraft.png" loading="lazy" />

:::info
Se for o seu primeiro servidor Minecraft no Game Panel e a Game Port predefinida estiver disponível, todas as portas necessárias são configuradas automaticamente. Não é necessária qualquer configuração manual.
:::

### Etapa 3 — Escolher o tipo de servidor Minecraft

Ao criar o seu servidor, tem de escolher o tipo de servidor Minecraft que pretende instalar. Cada opção responde a necessidades diferentes:

- **Minecraft Java Edition**: a versão oficial de Minecraft para PC. É indicada para os servidores que pretendem proporcionar uma experiência Minecraft clássica, sem sistema de plugin ou de mod específico pré-instalado.
- **Minecraft Bedrock Edition**: a versão concebida para permitir que os jogadores se liguem a partir de diferentes dispositivos, nomeadamente Windows, consolas e smartphones. É a escolha ideal para o jogo multiplataforma.
- **PaperMC**: uma solução otimizada para os servidores comunitários que utilizam plugins. Os plugins adicionam funcionalidades sem modificar o jogo dos jogadores, como sistemas económicos, teletransporte, proteção de zonas ou minijogos.
- **Fabric**: uma plataforma de mods leve e rápida. É apreciada pelo seu desempenho e pelo seu vasto ecossistema de mods, mantendo um consumo de recursos relativamente baixo.
- **NeoForge**: uma plataforma de mods avançada que oferece vastas possibilidades de personalização. É particularmente indicada para os servidores que utilizam mods complexos ou grandes modpacks que requerem funcionalidades extensas.

### Etapa 4 — Acompanhar o progresso da instalação

Assim que a instalação for iniciada, é apresentado um ecrã de confirmação. Clique em <code className="action">Log/Console</code> para acompanhar o progresso da instalação em tempo real.

Durante a instalação do servidor, o estado apresenta **Installing**. Acompanhe o progresso detalhado no painel de logs.

<img className="thumbnail" alt="Acompanhamento da instalação do servidor Minecraft" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/installation-logs.png" loading="lazy" />

### Etapa 5 — Confirmar o fim da instalação

Assim que a instalação terminar, o estado do servidor passa automaticamente a **Running**.

<img className="thumbnail" alt="Servidor Minecraft com o estado Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/server-running.png" loading="lazy" />

### Etapa 6 — Obter as informações de ligação

Assim que o seu servidor estiver no estado **Running**, copie o endereço IP e a porta a partir da coluna **Connection** da lista de servidores de jogo.

### Etapa 7 — Juntar-se ao seu servidor no Minecraft

1. Abra o **Minecraft**.
2. Vá a **Multiplayer**.
3. Clique em **Direct Connect** e cole o endereço IP e a porta indicados na coluna **Connection**.
