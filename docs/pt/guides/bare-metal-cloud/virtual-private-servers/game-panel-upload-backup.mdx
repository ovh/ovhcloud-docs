## Objetivo

O Game Panel da OVHcloud permite-lhe restaurar uma cópia de segurança descarregando um arquivo, extraindo-o e carregando os ficheiros com o File Manager.

**Este guia explica-lhe como restaurar uma cópia de segurança no seu servidor Game Panel da OVHcloud.**

## Requisitos

- Um [VPS](https://www.ovhcloud.com/pt/vps/) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Uma instância de servidor de jogo implementada no Game Panel.
- Uma cópia de segurança existente. Consulte o guia [Criar uma cópia de segurança no Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/).

## Instruções

### Etapa 1 — Iniciar sessão no Game Panel

Inicie sessão no seu Game Panel. Se precisar de ajuda, consulte o guia [Iniciar sessão no Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Etapa 2 — Aceder aos parâmetros de cópia de segurança

Uma vez com sessão iniciada:

1. Selecione o seu servidor de jogo.
2. Clique em <code className="action">Settings</code>.
3. Vá ao separador <code className="action">Backups</code>.

### Etapa 3 — Descarregar uma cópia de segurança

Na parte inferior da página, localize a lista das cópias de segurança disponíveis. Clique em <code className="action">Download</code> junto à cópia de segurança que pretende restaurar.

Se não estiver disponível nenhuma cópia de segurança, deve criar uma primeiro. Consulte o guia [Criar uma cópia de segurança no Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/).

<img className="thumbnail" alt="Download de uma cópia de segurança a partir da lista" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-backup/download-backup.png" loading="lazy" />

### Etapa 4 — Extrair a cópia de segurança

Uma vez descarregada a cópia de segurança, extraia o arquivo no seu computador. O conteúdo extraído inclui o diretório `serverfiles`.

### Etapa 5 — Parar o servidor

Antes de continuar, verifique que o seu servidor de jogo está parado a partir do Game Panel, para evitar qualquer corrupção ou conflito durante o restauro.

### Etapa 6 — Abrir o File Manager

No seu servidor, clique em <code className="action">Settings</code> e, em seguida, abra o separador <code className="action">File Manager</code> e localize a pasta `serverfiles`.

<img className="thumbnail" alt="Diretório serverfiles no servidor" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-backup/serverfiles.png" loading="lazy" />

Antes de carregar a cópia de segurança, deve escolher uma das seguintes opções:

- **Eliminá-la** com a ação <code className="action">Delete</code> se já não precisar dela.
- **Renomeá-la** com a ação <code className="action">Rename</code> para a conservar como cópia de segurança.
- **Descarregá-la localmente** com a ação <code className="action">Download</code>.

### Etapa 7 — Carregar os ficheiros de cópia de segurança

No File Manager, clique em <code className="action">Upload files</code> ou arraste e largue a pasta `serverfiles` local proveniente da cópia de segurança extraída na lista dos ficheiros.

Para a maioria dos jogos, restaurar a pasta `serverfiles` é suficiente. No entanto, alguns jogos podem armazenar ficheiros de configuração noutros locais. Se a configuração do jogo tiver sido modificada, recomenda-se também restaurar a pasta `config-lgsm` quando esta estiver disponível.

### Etapa 8 — Iniciar o servidor

Uma vez concluído o carregamento, reinicie o seu servidor a partir do Game Panel. O seu servidor deverá agora funcionar com o ambiente da cópia de segurança restaurada.
