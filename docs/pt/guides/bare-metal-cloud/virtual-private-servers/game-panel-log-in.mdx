## Objetivo

O Game Panel OVHcloud disponibiliza uma interface dedicada para gerir os seus servidores de jogo. Para o utilizar, tem de iniciar sessão com as suas credenciais.

**Este guia explica-lhe como se ligar ao Game Panel OVHcloud e como recuperar uma palavra-passe perdida.**

## Requisitos

- Um [VPS](/links/bare-metal/vps) ou um [servidor dedicado](/links/bare-metal/bare-metal) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- O link de acesso ao Game Panel fornecido durante a instalação.

## Instruções

### Etapa 1 — Aceder ao Game Panel

Aceda ao seu Game Panel. O link de acesso depende do domínio selecionado durante a instalação.

<img className="thumbnail" alt="Página de início de sessão do Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login.png" loading="lazy" />

### Etapa 2 — Iniciar sessão

Introduza o seu nome de utilizador e a palavra-passe associada e, em seguida, clique em <code className="action">Sign In</code> para se ligar ao Game Panel.

<img className="thumbnail" alt="Introdução das credenciais na página de início de sessão" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login-form.png" loading="lazy" />

### Recuperar uma palavra-passe perdida

#### Contas não administradoras

Em caso de palavra-passe perdida, peça a um administrador que a reponha. Consulte o guia [Gerir os utilizadores no Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-manage-users/) para mais detalhes.

#### Conta de superadministrador

Se a palavra-passe do superadministrador tiver sido perdida, reponha-a: ligue-se por SSH à máquina anfitriã, aceda à pasta de implementação da instalação e, em seguida, execute o comando seguinte. Se não estiver familiarizado com as ligações SSH, consulte o guia [Como começar com as ligações SSH](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction/).

```bash
sudo bash tools/reset-admin-password.sh
```

Saída esperada:

```console
New admin password: XXXXXXXXXX
Confirm new admin password: XXXXXXXXXX
[INFO] Updating the root user password in the database...
[INFO] Rotating JWT secret...
[INFO] Recreating the backend to invalidate existing sessions...
[INFO] Admin password reset complete for user: admin
```

Ligue-se novamente à aplicação com a nova palavra-passe de administrador.

:::warning
Esta operação desliga todos os utilizadores atualmente ligados.
:::
