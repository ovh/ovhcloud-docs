## Objetivo

O Game Panel permite-lhe implementar e configurar um servidor de voz TeamSpeak 3 em poucos minutos, sem linha de comandos nem conhecimentos de sistema.

**Este guia explica-lhe como implementar um servidor TeamSpeak 3 no Game Panel e como ligar-se a ele.**

## Requisitos

- Um [VPS](/links/bare-metal/vps) ou um [servidor dedicado](/links/bare-metal/bare-metal) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um acesso ao Game Panel. Consulte o guia [Ligar-se ao Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Um cliente TeamSpeak 3 instalado na sua máquina para testar a ligação.

## Instruções

### Etapa 1 — Aceder ao Game Panel

A partir do painel de controlo do seu Game Panel, clique em <code className="action">Add Game Server</code>.

### Etapa 2 — Criar um servidor TeamSpeak 3

Na lista de jogos disponíveis, procure e selecione **TeamSpeak 3**. Abre-se uma janela de configuração.

<img className="thumbnail" alt="Seleção de TeamSpeak 3 na lista de jogos" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/select-teamspeak-3.png" loading="lazy" />

### Etapa 3 — Configurar o servidor TeamSpeak 3

Abre-se uma página de configuração. Os valores predefinidos estão prontos a utilizar para um lançamento imediato, mas pode personalizá-los de acordo com as suas necessidades.

Entre os parâmetros disponíveis, pode modificar:

- <code className="action">Server Name</code>: dê um nome de instância ao seu servidor (por exemplo, `My TS3 server`).
- <code className="action">Network Ports</code>: pré-configuradas automaticamente:
    - `9987` (UDP) — voz
    - `10011` (TCP) — ServerQuery
    - `30033` (TCP) — transferência de ficheiros

<img className="thumbnail" alt="Configuração das Network Ports para o TeamSpeak 3" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-network-ports.png" loading="lazy" />

:::info
Pode modificar estes parâmetros, mas não é obrigatório para lançar o servidor.
:::

Pode expandir <code className="action">Advanced settings</code> para ajustar opções como a atribuição de portas (ports binding) e os limites de recursos. Os valores predefinidos são adequados para a maioria dos servidores de jogo.

### Etapa 4 — Iniciar a instalação

Assim que a configuração for verificada, clique em <code className="action">Install</code> para iniciar a implementação.

<img className="thumbnail" alt="Formulário de configuração da instalação do TeamSpeak 3 com o botão Select" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-install-form.png" loading="lazy" />

### Etapa 5 — Acompanhar a instalação

A implementação inicia-se automaticamente. Deixe a instalação prosseguir sem fechar a página.

Acompanhe o processo em tempo real clicando em <code className="action">Log/Console</code> para apresentar as mensagens de instalação.

<img className="thumbnail" alt="Painel dos logs de instalação do TeamSpeak 3" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-installation-logs.png" loading="lazy" />

### Etapa 6 — Verificar se o servidor está em execução

Verifique que o seu servidor apresenta o estado **Running**.

<img className="thumbnail" alt="Servidor TeamSpeak 3 com o estado Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-running.png" loading="lazy" />

### Etapa 7 — Confirmar a conclusão da instalação

Assim que a instalação terminar, o estado passa a **Running**. O seu servidor está online.

### Etapa 8 — Obter as informações de ligação

Obtenha o endereço IP e a porta na coluna <code className="action">Connection</code> da lista de Game Servers para se ligar a partir do cliente TeamSpeak 3.

### Etapa 9 — Juntar-se ao seu servidor no TeamSpeak 3

No cliente TeamSpeak 3:

1. Clique em <code className="action">Connections</code> > <code className="action">Connect</code>.
2. Introduza o endereço apresentado na coluna **Connection** da lista de Game Servers.
