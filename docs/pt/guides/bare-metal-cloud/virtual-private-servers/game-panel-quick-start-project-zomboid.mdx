## Objetivo

O Game Panel OVHcloud permite-lhe implementar um servidor Project Zomboid com uma instalação e uma configuração das portas automatizadas.

**Este guia explica-lhe como implementar um servidor Project Zomboid no Game Panel OVHcloud e ligar-se a ele.**

## Requisitos

- Um [VPS](/links/bare-metal/vps) ou um [servidor dedicado](/links/bare-metal/bare-metal) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um acesso ao Game Panel. Consulte o guia [Ligar-se ao Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instruções

### Etapa 1 — Aceder ao Game Panel

Ligue-se ao seu Game Panel OVHcloud. No menu à esquerda, aceda à secção `Game Servers` e clique em <code className="action">Add Game Server</code>.

### Etapa 2 — Criar um servidor Project Zomboid

Selecione **Project Zomboid** na lista de jogos. Abre-se uma janela de configuração.

<img className="thumbnail" alt="Seleção de Project Zomboid na lista de jogos do Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/select-project-zomboid.png" loading="lazy" />

### Etapa 3 — Configurar o servidor Project Zomboid

Nesta secção, pode definir um nome para o seu servidor e escolher a <code className="action">Branch</code> — o ramo Steam do jogo a instalar, cuja lista é atualizada automaticamente. Escolha-o com cuidado: mudar de ramo posteriormente pode corromper um mundo existente, pelo que se trata de uma escolha a fazer no momento da instalação.

É igualmente gerada automaticamente uma palavra-passe de administrador. Trata-se da palavra-passe da conta de administrador no jogo, que lhe permite atribuir-se os direitos de administrador e executar os comandos de consola privilegiados: **não** é a palavra-passe utilizada pelos jogadores para se ligarem ao servidor.

:::warning
Certifique-se de que guarda esta palavra-passe de administrador num local seguro.
:::

Pode expandir <code className="action">Advanced Settings</code> para ajustar opções como o mapeamento das portas (ports binding) e os limites de recursos. Os valores predefinidos são adequados para a maioria dos servidores de jogo.

<img className="thumbnail" alt="Formulário de configuração do servidor Project Zomboid com o ramo e a palavra-passe de administrador" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/configure-server.png" loading="lazy" />

### Etapa 4 — Iniciar a instalação

Clique em <code className="action">Install</code> para iniciar a implementação.

### Etapa 5 — Acompanhar a instalação

Clique em <code className="action">Log/Console</code> para acompanhar o progresso da instalação em tempo real. Assim que a instalação for iniciada, o Game Panel apresenta também um botão <code className="action">Open Logs / Console</code> que abre a mesma vista.

Durante a instalação do servidor, o estado apresenta **Installing**. O painel de logs mostra o progresso detalhado.

<img className="thumbnail" alt="Acompanhamento da instalação do servidor Project Zomboid no painel de logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/installation-logs.png" loading="lazy" />

### Etapa 6 — Confirmar a conclusão da instalação

Assim que a instalação estiver concluída, o estado do servidor muda para **Running**.

### Etapa 7 — Verificar se o servidor está em execução

Verifique se está visível uma atividade de CPU e RAM. Pode utilizar os controlos <code className="action">Log/Console</code> e <code className="action">Settings</code> para gerir o servidor.

<img className="thumbnail" alt="Servidor Project Zomboid com o estado Running e atividade de CPU e RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/server-running.png" loading="lazy" />

### Etapa 8 — Obter as informações de ligação

Copie o endereço IP e a porta da coluna **Connection** da lista `Game Servers`.

### Etapa 9 — Juntar-se ao seu servidor no Project Zomboid

Para se juntar ao seu servidor a partir do cliente Project Zomboid:

1. Abra o **Project Zomboid** e clique em **Multiplayer** e, em seguida, em **Add server**.
2. Introduza um nome para o servidor e, em seguida, o endereço IP e a porta indicados na coluna **Connection** do Game Panel. Introduza também a palavra-passe do servidor, caso este tenha uma: trata-se da palavra-passe utilizada pelos jogadores para se ligarem, não da palavra-passe de administrador.
3. Clique em **SAVE**.
4. Crie uma conta de jogo para este servidor clicando em **Add new account** e, em seguida, introduza um nome e uma palavra-passe.

### Ligar-se como administrador

Assim que o servidor for adicionado ao menu **Multiplayer**, crie uma nova personagem para este servidor. Durante a sua criação, escolha um nome de utilizador e introduza a palavra-passe de administrador do servidor.

Para obter esta palavra-passe, clique em <code className="action">Settings</code> no Game Panel, abra a secção <code className="action">Game Config</code> e, em seguida, o separador <code className="action">Server Settings</code>: o campo **Admin Password** encontra-se no fundo da página. O valor está oculto. Clique no ícone em forma de olho para o revelar.

Assim que estiver ligado com esta personagem, é apresentado um ícone **Admin** no lado esquerdo do ecrã. Clique nele para aceder às ferramentas de administração, executar comandos e moderar o seu servidor.

### Atualizar o servidor para uma nova versão do jogo

Por predefinição, o servidor não se atualiza automaticamente quando está disponível uma nova versão, para evitar problemas de compatibilidade ou a interrupção de partidas.

Para ativar as atualizações automáticas, clique em <code className="action">Settings</code>, abra a secção <code className="action">Game Config</code> e ative a opção <code className="action">Update on start</code> no fundo da página (desativada por predefinição). Clique em <code className="action">Save &amp; Restart</code> para aplicar as alterações. O servidor aplica então automaticamente cada nova atualização.
