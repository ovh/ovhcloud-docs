## Objetivo

O Game Panel OVHcloud permite-lhe personalizar o seu servidor Project Zomboid instalando mods do Steam Workshop.

**Este guia explica como instalar mods no seu servidor Project Zomboid alojado no Game Panel OVHcloud.**

## Requisitos

- Um [VPS](/links/bare-metal/vps) ou um [servidor dedicado](/links/bare-metal/bare-metal) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um servidor Project Zomboid implementado no Game Panel. Consulte o guia [Implementar um servidor Project Zomboid no Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/).
- Aceder ao Game Panel. Consulte o guia [Ligar-se ao Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instruções

### Etapa 1 — Encontrar os mods pretendidos

Os mods do Project Zomboid são distribuídos através do [Steam Workshop](https://steamcommunity.com/app/108600/workshop/). Percorra o Workshop e localize os mods que pretende instalar.

Depois de abrir a página de um mod, observe o URL no seu navegador. O **Workshop ID** é o número que aparece a seguir a `?id=`.

Por exemplo:

```text
https://steamcommunity.com/sharedfiles/filedetails/?id=3762296152
```

Neste exemplo, o Workshop ID é `3762296152`. Copie este identificador: irá precisar dele na etapa seguinte.

<img className="thumbnail" alt="Workshop ID destacado na barra de endereço numa página de mod do Project Zomboid" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/steam-workshop-mod-page.png" loading="lazy" />

:::warning
Certifique-se sempre de que o mod é compatível com a versão do jogo do seu servidor. Por exemplo, um mod Build 41 (B41) muito provavelmente não funcionará num servidor Build 42 (B42). A instalação de mods incompatíveis pode impedir o arranque do seu servidor.
:::

### Etapa 2 — Adicionar o mod a partir do Game Panel

:::warning
O seu servidor deve estar parado antes de adicionar ou eliminar mods. As alterações aos mods são aplicadas no arranque seguinte.
:::

Se o seu servidor estiver em execução, comece por pará-lo: na lista `Game Servers`, clique no ícone de parar na coluna **Power** do seu servidor e, em seguida, confirme. Todos os jogadores ligados são desligados do servidor.

No Game Panel, localize o seu servidor Project Zomboid na lista `Game Servers` e aceda a <code className="action">Settings</code> > <code className="action">Game Config</code> > <code className="action">Mods</code>.

<img className="thumbnail" alt="O separador Mods em Game Config no Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/game-config-mods-tab.png" loading="lazy" />

Clique em <code className="action">Add mods</code> e, em seguida, introduza o Workshop ID copiado anteriormente.

<img className="thumbnail" alt="Introdução de um Workshop ID na janela Add Workshop mods" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/add-mods.png" loading="lazy" />

#### Adicionar vários mods de uma só vez

Pode adicionar vários Workshop ID em simultâneo, separando-os por:

- espaços
- vírgulas
- quebras de linha

Depois de adicionar os seus mods, pode reorganizar a respetiva **ordem de carregamento** com as setas para cima e para baixo de cada linha.

#### Mods com vários Mod ID

Alguns elementos do Workshop contêm vários **Mod ID**. Por exemplo, uma remodelação da interface pode incluir dois Mod ID:

- `UI_Dark`
- `UI_Light`

Neste caso, ative apenas um deles, não ambos.

Pode ativar ou desativar cada Mod ID através do interruptor situado no fim de cada linha.

<img className="thumbnail" alt="Lista dos mods instalados com a ordem de carregamento e o interruptor de cada linha" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/mods-list.png" loading="lazy" />

### Etapa 3 — Iniciar o seu servidor

Regresse à página principal do Game Panel e clique em <code className="action">Start</code> para iniciar o seu servidor.

Quando os jogadores se ligarem, o cliente Project Zomboid descarrega automaticamente os mods do Workshop instalados no servidor.

### Aumentar a memória atribuída ao jogo

Se utilizar um grande número de mods, o Project Zomboid pode necessitar de mais memória do lado do cliente. Se o jogo tiver dificuldade em arrancar ou se bloquear devido a uma utilização intensiva de mods, atribua mais memória RAM.

Para isso:

1. Feche completamente o Project Zomboid.
2. Abra o **Steam** e localize o **Project Zomboid** na sua biblioteca.
3. Clique no ícone em forma de roda dentada situado à direita.
4. Selecione **Gerir** > **Procurar ficheiros locais**.
5. Na pasta do jogo, localize o ficheiro `ProjectZomboid64.json` e abra-o com o **Bloco de notas** (ou qualquer outro editor de texto).
6. Desloque-se para baixo até à secção `VMArgs`.
7. Localize a linha que contém `-Xmx3072m` e substitua o valor de memória por um valor superior, por exemplo `-Xmx8g`. Isto atribui 8 GB de RAM ao jogo, desde que o seu computador disponha de memória suficiente.
8. Guarde o ficheiro, feche-o e volte a iniciar o Project Zomboid.

:::info
Não atribua ao jogo toda a memória RAM do seu sistema. Deixe memória suficiente disponível para o sistema operativo e para as aplicações em segundo plano, para que o seu sistema se mantenha estável.
:::

### Instalar mods manualmente

Também pode instalar os seus mods manualmente em vez de utilizar o importador automático do Workshop. O ficheiro a modificar manualmente é `/zomboid/Server/<nome_do_servidor>.ini` (por predefinição, `servertest.ini`).

O Game Panel dá-lhe acesso direto a este ficheiro: abra <code className="action">Settings</code> > <code className="action">Game Config</code> > <code className="action">Server Settings</code>, expanda <code className="action">Advanced Configuration</code> e clique em <code className="action">Open in File Manager</code> ao lado da entrada **INI**.

:::warning
Não utilize os dois métodos ao mesmo tempo. Se instalar os seus mods manualmente e utilizar depois a funcionalidade de importação automática, as suas alterações manuais poderão ser substituídas, o que pode originar conflitos ou a perda da sua configuração. Escolha a instalação automática ou a instalação manual, mas evite combinar as duas.
:::
