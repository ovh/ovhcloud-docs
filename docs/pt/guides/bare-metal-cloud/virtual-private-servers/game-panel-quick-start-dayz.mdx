## Objetivo

O Game Panel permite-lhe implementar um servidor DayZ em algumas etapas. O Game Panel gere a instalação, a autenticação Steam e a configuração das portas de rede.

**Este guia explica-lhe como implementar um servidor DayZ no Game Panel e ligar-se a ele.**

## Requisitos

- Um [VPS](https://www.ovhcloud.com/pt/vps/) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um acesso ao Game Panel. Consulte o guia [Ligar-se ao Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Uma conta Steam para autenticar a instalação do servidor DayZ.

## Instruções

### Etapa 1 — Aceder ao Game Panel

Ligue-se ao seu Game Panel.

No menu da esquerda, aceda à secção <code className="action">Game Servers</code> e clique em <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Secção Game Servers com o botão Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/add-game-server.png" loading="lazy" />

Selecione **DayZ** na lista de jogos. Abre-se uma janela de configuração.

### Etapa 2 — Configurar o seu servidor

Na janela de configuração:

- Introduza um **Server Name**.
- Introduza o seu **Steam Username** e **Steam Password**.

:::warning
Recomenda-se vivamente que utilize uma conta Steam dedicada a esta utilização, e não a sua conta pessoal. Utilize uma palavra-passe complexa e desative a autenticação de dois fatores por e-mail (Steam Guard) nessa conta antes de continuar.
:::


<img className="thumbnail" alt="Formulário de instalação de DayZ a apresentar o nome do servidor e os campos de identificadores Steam" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/install-dayz-form.png" loading="lazy" />

### Etapa 3 — Configurar as portas de rede

As seguintes portas UDP estão pré-configuradas no formulário de instalação:

| Porta | Utilização |
|------|-------|
| 2302 | Game |
| 2304 | Steam |
| 2306 | BattlEye |
| 27016 | Query Steam |

:::info
Se for o seu primeiro servidor DayZ no Game Panel e as portas predefinidas estiverem disponíveis, não é necessária qualquer modificação manual.
:::


<img className="thumbnail" alt="Secção das portas de rede com as portas UDP DayZ pré-configuradas" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/network-ports.png" loading="lazy" />

### Etapa 4 — Iniciar a instalação

Clique em <code className="action">Select</code>. A implementação inicia-se automaticamente. O Game Panel irá:

1. Descarregar a imagem do servidor DayZ.
2. Instalar os ficheiros do servidor.

Assim que a instalação estiver concluída, clique em <code className="action">Launch</code> para iniciar o seu servidor.

### Etapa 5 — Verificar se o servidor está a funcionar

Verifique se o estado do servidor passa a **Running**. Uma atividade CPU e RAM deve estar visível no Game Panel.

Os seguintes comandos estão disponíveis:

- <code className="action">Log/Console</code> — acompanhe o arranque e a atividade do servidor em tempo real, e consulte os logs em caso de problema.
- <code className="action">Settings</code> — aceda às opções de configuração do jogo.

<img className="thumbnail" alt="Servidor DayZ com o estado Running e os controlos de gestão" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/server-running.png" loading="lazy" />

### Etapa 6 — Configurar os parâmetros do jogo (facultativo)

Clique em <code className="action">Settings</code> no seu servidor, depois abra <code className="action">Game Config</code> para ajustar as opções acessíveis a partir do Game Panel, tais como as atualizações automáticas.

Para uma configuração avançada, utilize o **File Manager** para modificar diretamente o ficheiro de configuração do servidor DayZ.

<img className="thumbnail" alt="Painel Server Settings com as opções Game Config e File Manager" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/game-config.png" loading="lazy" />

### Etapa 7 — Ligar-se ao seu servidor

Na coluna **Connection** da lista Game Servers, copie o endereço IP e a porta do seu servidor.

Para se juntar a partir do cliente DayZ:

1. Inicie o **DayZ**.
2. Aceda a **Servers** e clique em **Direct Connect** na parte inferior.
3. Introduza o seu endereço IP e a porta (por exemplo `192.168.1.1:2302`).
4. Clique em **Connect**.

<img className="thumbnail" alt="Lista Game Servers com o endereço IP de ligação e a porta em destaque" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/connection-details.png" loading="lazy" />
