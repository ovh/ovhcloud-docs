## Objetivo

O PaperMC é uma implementação de alto desempenho do servidor Minecraft, compatível com plugins que alargam as funcionalidades de jogo. O Game Panel permite implementar um servidor PaperMC em poucos cliques e, em seguida, personalizá-lo carregando plugins.

**Este guia explica-lhe como instalar um servidor PaperMC no Game Panel e adicionar plugins.**

## Requisitos

- Um [VPS](https://www.ovhcloud.com/pt/vps/) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Acesso ao Game Panel. Consulte o guia [Ligar-se ao Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instruções

### Etapa 1 — Instalar um servidor PaperMC

A partir da página principal do Game Panel, clique em <code className="action">Add Game Server</code>, localize **PaperMC** e clique em <code className="action">Select</code>.

Para mais detalhes sobre a instalação de um servidor, consulte o guia [Primeiros passos com o Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

### Etapa 2 — Descarregar plugins

Descarregue plugins a partir de uma fonte de confiança, como o repositório [PaperMC Hangar](https://hangar.papermc.io/).

### Etapa 3 — Carregar os plugins com o File Manager

No seu servidor PaperMC, clique em <code className="action">Settings</code> e, em seguida, abra o separador <code className="action">File Manager</code>. Aceda à pasta `serverfiles`, abra o diretório `plugins` e carregue os seus ficheiros de plugins através de <code className="action">Upload files</code> ou por arrastar e largar.

### Etapa 4 — Reiniciar o servidor

A partir da página principal do Game Panel, reinicie o seu servidor através do botão dedicado.

:::info
Monitorize os logs do servidor para confirmar que este arranca corretamente e que os plugins são carregados.
:::
