## Objetivo

O Game Panel OVHcloud permite-lhe efetuar cópias de segurança das suas instâncias de servidores de jogos para as restaurar num estado anterior, se necessário.

**Este guia explica-lhe como criar uma cópia de segurança do seu servidor de jogo no Game Panel OVHcloud.**

## Requisitos

- Um [VPS](https://www.ovhcloud.com/pt/vps/) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Uma instância de servidor de jogo implementada no Game Panel. Consulte o guia [Primeiros passos com o Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

## Instruções

### Etapa 1 — Iniciar sessão no Game Panel

Inicie sessão no seu Game Panel. Se precisar de ajuda, consulte o guia [Iniciar sessão no Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Etapa 2 — Aceder aos parâmetros de cópia de segurança

Uma vez com sessão iniciada:

1. Selecione o seu servidor de jogo.
2. Clique em <code className="action">Settings</code>.
3. Dirija-se ao separador <code className="action">Backups</code>.

<img className="thumbnail" alt="O separador dos parâmetros de cópia de segurança" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/backup-tab.png" loading="lazy" />

### Etapa 3 — Criar uma cópia de segurança

Clique em <code className="action">Create backup now</code>.

<img className="thumbnail" alt="Criação de uma cópia de segurança com a opção de paragem do servidor" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/create-backup.png" loading="lazy" />

Uma vez concluída a cópia de segurança, o ficheiro fica disponível para download na lista **Available Backups**, mais abaixo no mesmo separador.

### Etapa 4 — Definir uma política de retenção

Em **Retention Policy**, pode controlar o número de cópias de segurança conservadas e a sua duração de conservação:

- **Keep the last backups**: o número máximo de cópias de segurança a conservar (indique `0` para conservar todas).
- **Keep backups for days**: a duração de conservação das cópias de segurança (indique `0` para as conservar indefinidamente).
- **Stop server before backup**: para o servidor durante a execução da cópia de segurança, para cópias de segurança coerentes.

:::info
Recomendamos que mantenha a opção **Stop server before backup** ativada, de modo a garantir a coerência das cópias de segurança.
:::

Clique em <code className="action">Save retention settings</code> para aplicar as suas modificações.
