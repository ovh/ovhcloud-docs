## Objetivo

O Game Panel OVHcloud permite-lhe implementar e gerir servidores de jogo diretamente no seu VPS. Antes de o utilizar, deve instalá-lo no seu servidor a partir da área de cliente OVHcloud.

**Este guia explica-lhe como instalar o Game Panel no seu VPS.**

## Requisitos

- Um [VPS](/links/bare-metal/vps) na sua conta OVHcloud.
- Um acesso à <ManagerLink to="/">área de cliente OVHcloud</ManagerLink>.

## Instruções

### Etapa 1 — Ligar-se à área de cliente OVHcloud

Ligue-se à sua <ManagerLink to="/">área de cliente OVHcloud</ManagerLink>. Se precisar de ajuda para se ligar, consulte o guia [Aceder à Área de Cliente OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-login/).

### Etapa 2 — Mudar para a versão Beta da área de cliente OVHcloud

A funcionalidade de instalação do Game Panel está atualmente disponível na versão Beta da área de cliente OVHcloud.

No canto superior direito da página, clique em <code className="action">Descobrir a consola</code> (assinalado com o distintivo **BETA**) para mudar para a interface Beta.

<img className="thumbnail" alt="A ligação Descobrir a consola no cabeçalho da área de cliente OVHcloud" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/discover-the-console-beta.png" loading="lazy" />

### Etapa 3 — Abrir a página do seu VPS

A partir da área de cliente OVHcloud:

1. No menu no topo da página, clique em <code className="action">Bare Metal Cloud</code>.
2. No menu da esquerda, selecione <code className="action">VPS</code>.
3. Na lista **Servidores privados virtuais (VPS)**, clique no nome do seu VPS.

<img className="thumbnail" alt="A lista dos VPS na secção Bare Metal Cloud da área de cliente OVHcloud Beta" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/open-vps-page.png" loading="lazy" />

### Etapa 4 — Instalar o Game Panel

No separador **Visão geral**, localize a secção **Informações gerais**. Por baixo da linha **Distribuição**, clique em <code className="action">Reinstalar o meu VPS com Game Panel</code>.

<img className="thumbnail" alt="A ligação Reinstalar o meu VPS com Game Panel na secção Informações gerais do separador Visão geral do VPS" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/reinstall-with-game-panel-entry.png" loading="lazy" />

:::warning
A instalação do Game Panel reinstala o seu VPS e formata todos os seus discos. Todos os dados presentes no servidor são eliminados. Para poder voltar atrás, crie uma [snapshot do seu VPS](/guides/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/) antes de continuar.
:::

Preencha os seguintes campos e, em seguida, inicie a instalação.

<img className="thumbnail" alt="O formulário Reinstalar o meu VPS com Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/reinstall-with-game-panel-form.png" loading="lazy" />

**Escolher um sistema operativo**

Na lista **Sistema operativo**, selecione o sistema operativo no qual pretende instalar o Game Panel. Todos os sistemas operativos apresentados na lista são totalmente compatíveis com o Game Panel.

**Configurar o nome de domínio**

Por predefinição, o campo **Domínio** contém o nome de anfitrião predefinido do seu servidor, o que lhe permite aceder ao Game Panel através de um endereço semelhante a `https://vps-xxxx.vps.ovh.net`.

Se preferir, pode utilizar o seu próprio nome de domínio. Antes de continuar, certifique-se de que o registo DNS A do seu domínio aponta para o endereço IP público do seu VPS. O formulário verifica a resolução do domínio: a mensagem **O domínio aponta para o seu VPS** confirma que o certificado SSL poderá ser emitido.

Se ainda não possui um nome de domínio ou se precisa de configurar os respetivos registos DNS, consulte os recursos seguintes:

- [Os nomes de domínio OVHcloud](/links/web/domains)
- [Editar uma zona DNS da OVHcloud](/guides/web-cloud/domains/dns-zone-edit/)

**Introduzir um endereço de e-mail**

O campo **Endereço de email Let's Encrypt** é pré-preenchido com o endereço de e-mail associado à sua conta OVHcloud. Pode substituí-lo por outro endereço. Este endereço serve para configurar o certificado SSL e recebe as notificações relativas ao certificado, nomeadamente os alertas de expiração.

**Escolher o nome da conta de administrador**

No campo **Nome de utilizador do administrador**, introduza o nome de utilizador da conta de administrador a criar (`admin` por predefinição). Esta conta torna-se o superadministrador do Game Panel e dispõe do mais elevado nível de privilégios.

**Conservar a palavra-passe de administrador gerada**

É gerada uma palavra-passe para o Game Panel, apresentada no campo **Palavra-passe do administrador**. Copie-a com o ícone de cópia ou clique em <code className="action">Gerar outra</code> para obter uma nova palavra-passe. Conserve esta palavra-passe num local seguro, pois não poderá voltar a ser consultada posteriormente.

**(Opcional) Adicionar uma chave SSH**

A secção **Chave SSH a pré-instalar** permite-lhe pré-instalar no servidor uma chave SSH pública registada na sua conta OVHcloud. Trata-se de uma configuração avançada opcional. Se a sua conta não contiver nenhuma chave SSH, adicione uma a partir da secção **A minha conta** da área de cliente. Para mais informações, consulte o guia [Como armazenar as chaves SSH na sua Área de Cliente](/guides/bare-metal-cloud/dedicated-servers/import-keys-control-panel/).

Uma vez selecionada uma chave, o formulário apresenta também a caixa <code className="action">Não quero receber os códigos de autenticação do meu VPS por e-mail</code>. Se a assinalar, não recebe o e-mail com a palavra-passe SSH do seu servidor (ver a etapa 5).

**Iniciar a instalação**

Clique em <code className="action">Confirmar</code> para iniciar a instalação. Este botão só fica ativo depois de selecionado um sistema operativo e quando todos os campos são válidos.

### Etapa 5 — Ligar-se ao Game Panel

O sistema operativo selecionado é instalado em primeiro lugar. Assim que estiver implementado, recebe um e-mail automático com a palavra-passe SSH do seu servidor, exceto se tiver assinalado a caixa <code className="action">Não quero receber os códigos de autenticação do meu VPS por e-mail</code>. Conserve esta palavra-passe num local seguro, pois poderá precisar dela mais tarde se se ligar diretamente ao servidor através de SSH.

Alguns minutos mais tarde, a instalação do Game Panel termina automaticamente.

Pode então abrir o nome de anfitrião do seu servidor num navegador web, por exemplo `https://vps-xxxx.vps.ovh.net`. Ligue-se com a palavra-passe gerada durante a instalação para começar a utilizar o Game Panel.

:::info
A palavra-passe de administrador gerada só é apresentada uma vez durante a instalação. Se a perder, consulte a secção de recuperação da palavra-passe do guia [Ligar-se ao Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
:::
