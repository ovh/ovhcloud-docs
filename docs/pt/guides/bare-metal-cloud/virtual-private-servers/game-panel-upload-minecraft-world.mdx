## Objetivo

O Game Panel da OVHcloud permite-lhe carregar um mundo Minecraft personalizado, transferindo os ficheiros com o File Manager e ajustando a configuração da pasta do mundo.

**Este guia explica-lhe como carregar um mapa personalizado no seu servidor Minecraft alojado no Game Panel da OVHcloud.**

## Requisitos

- Um [VPS](https://www.ovhcloud.com/pt/vps/) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um servidor Minecraft implementado no Game Panel. Consulte o guia [Implementar um servidor Minecraft no Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

:::warning
Certifique-se de que o seu servidor Minecraft está **parado** antes de efetuar qualquer uma das ações seguintes.
:::


## Instruções

### Etapa 1 — Abrir o File Manager

No seu servidor Minecraft, clique em <code className="action">Settings</code> e, em seguida, abra o separador <code className="action">File Manager</code>.

### Etapa 2 — Localizar a pasta do mundo

No File Manager, navegue até:

```
data > serverfiles
```

Neste diretório, verá uma pasta chamada `world`. Esta pasta contém o seu mapa Minecraft atual e é criada por predefinição.

<img className="thumbnail" alt="A pasta world predefinida na estrutura de ficheiros do servidor" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder.png" loading="lazy" />

### Etapa 3 — Preparar o servidor para o seu novo mapa

Antes de carregar o seu próprio mapa, deve libertar o nome de pasta `world`. Tem três opções à sua disposição:

- **Eliminá-la** com a ação <code className="action">Delete</code> se já não precisar dela.
- **Renomeá-la** com a ação <code className="action">Rename</code> para a conservar como cópia de segurança.
- **Descarregá-la localmente** com a ação <code className="action">Download</code>.

### Etapa 4 — Carregar o seu mapa personalizado

No File Manager, dentro de `data > serverfiles`, clique em <code className="action">Upload files</code> ou arraste e largue a pasta do seu mapa na lista dos ficheiros.

### Etapa 5 — Configurar o nome do mundo (se necessário)

Se a pasta do seu mapa não se chamar `world`, deve atualizar a configuração do servidor:

1. Regresse ao Game Panel.
2. Abra as <code className="action">Settings</code> do seu servidor.
3. Vá ao separador <code className="action">Game Config</code>.
4. Localize a opção **World folder name**.
5. Introduza o nome exato da pasta do seu mapa.

<img className="thumbnail" alt="Configuração do nome da pasta do mundo no Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder-name-config.png" loading="lazy" />

:::info
**Utilizar vários mapas**: pode armazenar vários mapas no seu servidor e alternar facilmente entre eles. Modifique o campo **World folder name** na secção Game Config para carregar um mapa diferente. Não se esqueça de reiniciar o servidor depois de modificar este parâmetro.
:::


### Etapa 6 — Iniciar o servidor

Reinicie o seu servidor a partir do Game Panel. O seu mapa Minecraft personalizado está agora pronto a ser utilizado.
