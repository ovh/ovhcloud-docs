## VPS OVHcloud

Um [VPS OVHcloud](/links/bare-metal/vps) (Virtual Private Server) é uma máquina virtual com acesso root completo, alojada na infraestrutura da OVHcloud: o meio-termo entre um alojamento web gerido e um servidor dedicado. É o primeiro servidor ideal para alojar os seus próprios serviços web e aplicações.

Com um VPS OVHcloud pode:

- Alojar sites e aplicações web
- Executar aplicações auto-alojadas (Docker, Nextcloud, n8n, agentes de IA...)
- Alojar servidores de jogo com o Game Panel
- Fazer evoluir os recursos ao ritmo do seu projeto
- Proteger os seus dados com snapshots e backups automatizados
