## Objetivo

O Game Panel permite-lhe personalizar o seu servidor Rust instalando um mapa personalizado. O ficheiro do mapa é alojado externamente e referenciado a partir da configuração do seu servidor.

**Este guia explica-lhe como instalar um mapa personalizado num servidor Rust alojado no Game Panel.**

## Requisitos

- Um [VPS](https://www.ovhcloud.com/pt/vps/) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um servidor Rust implementado no Game Panel.
- Um ficheiro de mapa personalizado no formato `.map`.

## Instruções

### Etapa 1 — Preparar o seu mapa personalizado

1. Pare o seu servidor Rust a partir do Game Panel.
2. Certifique-se de que o seu mapa personalizado está no formato `.map`.
3. Carregue o mapa para um serviço de partilha de ficheiros.
4. Copie o link de transferência obtido e guarde-o: irá precisar dele posteriormente.

:::warning
O Dropbox não é adequado para esta utilização. Utilize outro serviço de partilha de ficheiros.
:::


### Etapa 2 — Abrir o File Manager

No seu servidor Rust, clique em <code className="action">Settings</code> e, em seguida, abra o separador <code className="action">File Manager</code>.

:::warning
Certifique-se de que o seu servidor Rust está **parado** antes de efetuar qualquer uma das ações seguintes.
:::


### Etapa 3 — Modificar a configuração do servidor

1. No File Manager, aceda a:

    ```
    /serverfiles/server/rustserver/cfg
    ```

2. Localize o ficheiro `server.cfg` e abra-o para o modificar.
3. Encontre a linha que começa por `levelURL=` e cole o link de transferência guardado anteriormente a seguir ao sinal `=`.
4. Certifique-se de que o link termina por `dl=1` (e não `dl=0`). Modifique-o se necessário.
5. Encontre a linha que começa por `serverLevel=` e introduza o mesmo tipo de nível que o utilizado para gerar o mapa personalizado:

    - `Procedural Map`
    - `Barren`
    - `Craggy Island`
    - `Savas Island`

6. Guarde as suas modificações.

### Etapa 4 — Reiniciar o servidor

Depois de guardar as suas modificações, reinicie o seu servidor Rust a partir do Game Panel.
