## Objetivo

O Game Panel expõe a configuração do servidor Counter-Strike 2 diretamente na sua interface. As opções básicas, como o nome do servidor, o mapa e o modo de jogo, estão acessíveis através de um formulário gráfico, e também pode instalar frameworks de servidor, como o MetaMod e o CounterStrikeSharp.

**Este guia explica-lhe como editar a configuração de um servidor Counter-Strike 2 no Game Panel.**

## Requisitos

- Um [VPS](/links/bare-metal/vps) ou um [servidor dedicado](/links/bare-metal/bare-metal) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um servidor Counter-Strike 2 implementado no Game Panel. Consulte o guia [Implementar um servidor Counter-Strike 2 no Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/).

## Instruções

### Etapa 1 — Abrir as definições do servidor

A partir da página principal do Game Panel, localize o servidor Counter-Strike 2 que pretende configurar. Na coluna <code className="action">Management</code>, clique em <code className="action">Settings</code>.

<img className="thumbnail" alt="Servidor Counter-Strike 2 com o botão Settings em destaque" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-server-settings.png" loading="lazy" />

### Etapa 2 — Abrir o separador Game Config

No painel **Server Settings**, selecione <code className="action">Game Config</code> na barra lateral esquerda.

A secção **Game Config** permite-lhe gerir os principais parâmetros do seu servidor Counter-Strike 2 através de dois separadores:

- **Settings**: configure os parâmetros do servidor de jogo.
- **Frameworks**: instale e faça a gestão dos frameworks de servidor suportados.

### Etapa 3 — Configurar o separador Settings

O separador <code className="action">Settings</code> permite-lhe modificar os principais parâmetros do servidor Counter-Strike 2:

| Parâmetro | Descrição |
|---------|-------------|
| Server Name | O nome apresentado no navegador de servidores Counter-Strike 2. |
| Max Players | O número máximo de jogadores que se podem ligar em simultâneo. |
| Map | O mapa a carregar quando o servidor arranca. Também pode introduzir manualmente o nome de um mapa que não conste da lista. |
| Game Type | Define a categoria principal do jogo. |
| Game Mode | Define o modo de jogo dentro do tipo de jogo selecionado. Para mais informações sobre os modos disponíveis, consulte o [guia da Valve Developer Community](https://developer.valvesoftware.com/wiki/Counter-Strike:_Global_Offensive/Game_Modes). |
| Server Password | Exige que os jogadores introduzam uma palavra-passe antes de entrarem no servidor. |
| Admin Password (RCON) | Ativa o acesso à Remote Console (RCON) e define a palavra-passe utilizada para administrar o servidor remotamente. |
| Steam GSL Token | Um Game Server Login Token (GSLT) utilizado para autenticar o seu servidor dedicado junto dos serviços Steam. Para gerar um token, consulte a [página Steam Game Server Account Management](https://steamcommunity.com/dev/managegameservers). |
| VAC Anti-Cheat | Ativa ou desativa a proteção Valve Anti-Cheat (VAC) no servidor. |

<img className="thumbnail" alt="O separador Settings da Game Config do Counter-Strike 2" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-settings.png" loading="lazy" />

:::info
Depois de modificar qualquer uma destas definições, guarde as suas alterações e reinicie o servidor para que entrem em vigor.
:::


### Etapa 4 — Instalar frameworks

O separador <code className="action">Frameworks</code> permite-lhe instalar componentes adicionais para alargar as funcionalidades do seu servidor Counter-Strike 2.

- **MetaMod**: um framework de plugins de servidor que funciona como uma camada intermédia entre o servidor de jogo e os plugins. Fornece a base necessária a muitas extensões de servidor avançadas e ferramentas de administração.
- **CounterStrikeSharp**: um framework de plugins moderno para Counter-Strike 2 que permite aos administradores de servidor e aos programadores criar e executar plugins personalizados em C#. Pode adicionar funcionalidades de jogo, ferramentas de gestão do servidor e extensões desenvolvidas pela comunidade.

Pode instalar qualquer um dos frameworks diretamente a partir do Game Panel e reinstalá-los mais tarde para os atualizar para uma versão mais recente, quando disponível.

<img className="thumbnail" alt="O separador Frameworks a apresentar o MetaMod e o CounterStrikeSharp" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-frameworks.png" loading="lazy" />

:::info
O servidor tem de estar parado antes de instalar um framework.
:::


### Etapa 5 — Guardar e reiniciar

Depois de guardar as suas alterações, reinicie o servidor Counter-Strike 2 a partir do Game Panel para que a nova configuração entre em vigor.
