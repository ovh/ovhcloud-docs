## Objetivo

O Game Panel OVHcloud permite-lhe implementar um servidor Palworld com uma instalação e uma configuração das portas automatizadas.

**Este guia explica-lhe como implementar um servidor Palworld no Game Panel OVHcloud e ligar-se a ele.**

## Requisitos

- Um [VPS](/links/bare-metal/vps) ou um [servidor dedicado](/links/bare-metal/bare-metal) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um acesso ao Game Panel. Consulte o guia [Ligar-se ao Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instruções

### Etapa 1 — Aceder ao Game Panel

Ligue-se ao seu Game Panel OVHcloud. No menu à esquerda, aceda à secção `Game Servers` e clique em <code className="action">Add Game Server</code>.

### Etapa 2 — Criar um servidor Palworld

Selecione **Palworld** na lista de jogos. Abre-se uma janela de configuração.

<img className="thumbnail" alt="Seleção de Palworld na lista de jogos do Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/select-palworld.png" loading="lazy" />

### Etapa 3 — Configurar o servidor Palworld

Nesta secção, pode definir um nome para o seu servidor. É igualmente gerada automaticamente uma palavra-passe de administrador. Pode ser utilizada diretamente no jogo para obter os direitos de administrador e executar os comandos associados.

:::warning
Certifique-se de que guarda esta palavra-passe de administrador num local seguro.
:::

Pode expandir <code className="action">Advanced settings</code> para ajustar opções como o mapeamento das portas (ports binding) e os limites de recursos. Os valores predefinidos são adequados para a maioria dos servidores de jogo.

<img className="thumbnail" alt="Formulário de configuração do servidor Palworld com o nome do servidor e a palavra-passe de administrador" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/configure-server.png" loading="lazy" />

### Etapa 4 — Iniciar a instalação

Clique em <code className="action">Install</code> para iniciar a instalação. A implementação começa.

### Etapa 5 — Acompanhar a instalação

Clique em <code className="action">Log/Console</code> para acompanhar o progresso da instalação em tempo real.

Durante a instalação do servidor, o estado apresenta **Installing**. Acompanhe o progresso detalhado no painel de logs.

<img className="thumbnail" alt="Acompanhamento da instalação do servidor Palworld no painel de logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/installation-logs.png" loading="lazy" />

### Etapa 6 — Verificar se o servidor está em execução

Verifique se o estado do servidor é **Running** e se está visível uma atividade de CPU e RAM. Pode utilizar os controlos <code className="action">Log/Console</code> e <code className="action">Settings</code> para fazer a gestão do servidor.

<img className="thumbnail" alt="Servidor Palworld com o estado Running e atividade de CPU e RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/server-running.png" loading="lazy" />

### Etapa 7 — Confirmar a conclusão da instalação

Assim que a instalação estiver concluída, o estado do servidor muda para **Running**.

### Etapa 8 — Obter as informações de ligação

Assim que o estado do seu servidor for **Running**, copie o endereço IP e a porta da coluna **Connection** da lista Game Servers.

### Etapa 9 — Juntar-se ao seu servidor no Palworld

Para se juntar ao seu servidor a partir do cliente Palworld:

1. Abra o **Palworld** e clique em **Join Multiplayer Game**.
2. No campo de introdução situado em baixo ao centro, cole o endereço IP e a porta indicados na coluna **Connection**.
3. Clique em **Connect**.

### Comandos disponíveis com o Palworld

Com um servidor Palworld, pode executar diferentes comandos diretamente a partir do campo de introdução situado no fundo dos logs. Eis alguns dos comandos disponíveis:

| Comando | Argumentos | Descrição |
|---------|------------|-----------|
| `announce` | `<message>` | Envia uma mensagem de anúncio visível para todos os jogadores ligados. |
| `players` | - | Apresenta a lista dos jogadores atualmente ligados ao servidor. |
| `info` | - | Devolve as informações gerais do servidor. |
| `settings` | - | Devolve a configuração atual do servidor. |
| `metrics` | - | Apresenta diferentes métricas e estatísticas do servidor. |
| `kick` | `<PlayerId or SteamId>` | Expulsa um jogador do servidor. |
| `ban` | `<PlayerId or SteamId>` | Bane um jogador do servidor. |
| `unban` | `<PlayerId or SteamId>` | Remove o banimento de um jogador. |

:::info
Esqueceu-se da palavra-passe de administrador do jogo? Clique em <code className="action">Settings</code>, abra a secção <code className="action">Game Config</code> e altere a palavra-passe no fundo da página.
:::

### Atualizar o servidor para uma nova versão do jogo

Por predefinição, o servidor não se atualiza automaticamente quando está disponível uma nova versão, para evitar eventuais problemas de compatibilidade ou a interrupção de partidas em curso.

Para ativar as atualizações automáticas, clique em <code className="action">Settings</code>, abra a secção <code className="action">Game Config</code> e ative a opção **Update on start** no fundo da página (desativada por predefinição). Guarde e, em seguida, reinicie o servidor para aplicar as alterações. O servidor aplicará então automaticamente qualquer nova atualização disponível.
