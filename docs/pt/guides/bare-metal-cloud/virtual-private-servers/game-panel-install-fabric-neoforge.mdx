## Objetivo

O Fabric e o NeoForge são carregadores de mods para servidores Minecraft. Instalar um deles num servidor Minecraft alojado no Game Panel permite-lhe usufruir de uma experiência modificada com funcionalidades alargadas.

**Este guia explica-lhe como instalar o Fabric ou o NeoForge num servidor Minecraft no Game Panel e adicionar mods.**

## Requisitos

- Um [VPS](https://www.ovhcloud.com/pt/vps/) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um servidor Minecraft implementado no Game Panel. Consulte o guia [Implementar um servidor Minecraft no Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

## Instruções

### Etapa 1 — Desativar as atualizações automáticas

Para evitar conflitos com os carregadores de mods, desative as atualizações automáticas antes de qualquer modificação:

1. Aceda às <code className="action">Settings</code> do seu servidor.
2. Abra o separador <code className="action">Game Config</code>.
3. Desative as atualizações automáticas.

### Etapa 2 — Parar o servidor

A partir do Game Panel, pare o seu servidor Minecraft antes de qualquer modificação adicional.

### Etapa 3 — Descarregar e importar o instalador

Descarregue o instalador correspondente ao carregador de mods escolhido:

- **Fabric**: [https://fabricmc.net/use/server/](https://fabricmc.net/use/server/)
- **NeoForge**: [https://neoforged.net/](https://neoforged.net/)

Depois de descarregado, abra as <code className="action">Settings</code> do seu servidor, aceda ao separador <code className="action">File Manager</code> e importe o ficheiro `.jar` para o diretório `serverfiles` através de <code className="action">Upload files</code> ou por arrastar e largar.

### Etapa 4 — Executar o instalador

Abra o separador <code className="action">Terminal</code> a partir das <code className="action">Settings</code> do seu servidor e execute o comando adequado ao seu carregador de mods.

Para o **Fabric**:

```bash
java -jar fabric-installer-X.X.X.jar server --downloadMinecraft
```

Este comando descarrega os ficheiros do servidor Minecraft, instala o carregador Fabric e gera o ficheiro de lançamento do servidor Fabric.

Para o **NeoForge**:

```bash
java -jar neoforge-X.X.X-installer.jar --installServer
```

Este comando instala o NeoForge, descarrega os ficheiros do servidor Minecraft e gera os ficheiros de lançamento do servidor.

### Etapa 5 — Configurar o LinuxGSM

Indique ao LinuxGSM qual o executável a utilizar, consoante o seu carregador de mods.

Para o **Fabric**:

```bash
printf '\nexecutable="./fabric-server-launch.jar"\n' >> /data/config-lgsm/mcserver/common.cfg
```

Para o **NeoForge**:

```bash
printf '\npreexecutable=""\nexecutable="./run.sh"\nstartparameters="nogui"\n' >> /data/config-lgsm/mcserver/common.cfg
```

:::warning
Quando utiliza o NeoForge com `run.sh`, o parâmetro **Max RAM** do Game Config deixa de ser aplicado. Modifique antes o ficheiro `/data/serverfiles/user_jvm_args.txt`. Exemplo:

```
-Xms2G
-Xmx4G
```
:::


### Etapa 6 — Iniciar o servidor

Defina as permissões corretas antes de iniciar o servidor:

```bash
sudo chown -R linuxgsm:linuxgsm /data/serverfiles
```

Em seguida, inicie o servidor a partir do Game Panel e consulte os logs do servidor para confirmar o arranque correto.

### Etapa 7 — Adicionar mods

Para instalar mods no seu servidor modificado:

1. Descarregue mods compatíveis com o Fabric ou o NeoForge.
2. Abra o separador <code className="action">File Manager</code> a partir das <code className="action">Settings</code> do seu servidor.
3. Importe os ficheiros `.jar` dos mods para `serverfiles/mods`.
4. Reponha as permissões:

    ```bash
    sudo chown -R linuxgsm:linuxgsm /data/serverfiles
    ```

5. Reinicie o servidor. Consulte os logs para confirmar que os mods são carregados.
