## Objetivo

O Reverse DNS (*rDNS*) é o complemento da resolução DNS "*forward*" que permite resolver os nomes de domínio em endereços IP. Graças à reverse DNS, um endereço IP pode ser resolvido com um nome de domínio (ou nome de host) ao qual está associado. Isto significa que os pedidos DNS do endereço IP associado retornarão este domínio.

A configuração da reverse DNS de um servidor é particularmente útil durante o envio de e-mails. A validação de um servidor de e-mail pelos sistemas de proteção antisspam melhora se uma query DNS do endereço IP é resolvida corretamente.

**Este manual explica como configurar a reverse DNS do endereço IP a partir da consola OVHcloud.**

## Requisitos

- Um endereço IP associado a um serviço da sua conta OVHcloud
- Um nome de domínio com o seu registo `A` ou `AAAA` ligado ao seu serviço

## Instruções
Na página **Endereços IP**, pode restringir a lista através dos filtros rápidos situados por cima da tabela (**IPv4**, **IPv6**, **IP adicional**, **BYOIP**). Também pode pesquisar um endereço IP específico no campo **Pesquisar**.

<img className="thumbnail" alt="Página Endereços IP da consola OVHcloud com o campo Pesquisar" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/ip-list-search.png" loading="lazy" />

Clique no endereço IP em questão para abrir a respetiva página e, a seguir, clique no separador <code className="action">Reverse DNS</code>. Clique no botão <code className="action">Configurar</code> por cima da tabela.

<img className="thumbnail" alt="Separador Reverse DNS de um endereço IP na consola OVHcloud com o botão Configurar" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-tab.png" loading="lazy" />

Na janela **Configurar o Reverse DNS**, preencha o seu reverse no campo **Nome de host reverse DNS** e clique em <code className="action">Configurar</code>.

<img className="thumbnail" alt="Janela Configurar o Reverse DNS da consola OVHcloud com o campo Nome de host reverse DNS" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-configure.png" loading="lazy" />

Para modificar um reverse existente, siga os mesmos passos: quando o endereço IP já dispõe de um reverse, o campo **Nome de host reverse DNS** abre-se pré-preenchido com este. Substitua-o pelo novo valor e clique em <code className="action">Configurar</code>.

:::warning
Ao introduzir o seu nome de domínio na reverse, este verifica imediatamente se o registo `A` / `AAAA` remete para o mesmo IP. Isto é utilizado nos procedimentos antisspam, pelo que o seu registo DNS deve ser válido e propagado. Há certas regras a seguir aquando da introdução da reverse:

 - o *reverse* não pode começar com um `-`
 - o *reverse* não pode conter mais de 63 caracteres
 - o *reverse* não pode conter caracteres maiúsculos
 - o *reverse* pode terminar com um `.`: a consola OVHcloud aceita tanto `domain.tld` como `domain.tld.`.

:::


:::info
Se a alteração não funcionar como esperado, verifique se o registo `A` / `AAAA` está corretamente configurado na zona DNS do seu domínio. A aplicação das alterações na zona DNS pode demorar até 24 horas, no caso de ter alterado recentemente o registo.

Se o nome de domínio for gerido pela OVHcloud como um registo **e utilizar os servidores DNS da OVHcloud**, pode consultar [este guia](/guides/web-cloud/domains/dns-zone-edit).

:::
