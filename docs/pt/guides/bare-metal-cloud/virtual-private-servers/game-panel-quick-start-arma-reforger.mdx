## Objetivo

O Game Panel permite-lhe implementar um servidor Arma Reforger em algumas etapas. O painel gere a instalação automaticamente, incluindo a configuração das portas.

**Este guia explica-lhe como implementar um servidor Arma Reforger no Game Panel e ligar-se a ele.**

## Requisitos

- Um [VPS](/links/bare-metal/vps) ou um [servidor dedicado](/links/bare-metal/bare-metal) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um acesso ao Game Panel. Consulte o guia [Ligar-se ao Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instruções

### Etapa 1 — Aceder ao Game Panel

Ligue-se ao seu Game Panel. No menu à esquerda, aceda à secção `Game Servers` e clique em <code className="action">Add Game Server</code>.

### Etapa 2 — Criar um servidor Arma Reforger

Selecione **Arma Reforger** na lista de jogos. Abre-se uma janela de configuração.

<img className="thumbnail" alt="Seleção de Arma Reforger na lista de jogos" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/select-arma-reforger.png" loading="lazy" />

### Etapa 3 — Configurar o servidor Arma Reforger

Defina o nome do servidor e verifique a configuração antes de iniciar a instalação.

:::info
Se for o seu primeiro servidor Arma Reforger no Game Panel e a Game Port predefinida estiver disponível, todas as portas necessárias serão configuradas automaticamente durante a instalação. Neste caso, não é necessária qualquer configuração manual.
:::

Pode expandir <code className="action">Advanced settings</code> para ajustar opções como a atribuição de portas (ports binding) e os limites de recursos. Os valores predefinidos são adequados para a maioria dos servidores de jogo.

### Etapa 4 — Iniciar a instalação

Clique em <code className="action">Install</code> para iniciar a implementação.

### Etapa 5 — Acompanhar a instalação

Clique em <code className="action">Log/Console</code> para acompanhar o progresso da instalação em tempo real. Durante a instalação do servidor, o estado apresenta **Installing**.

<img className="thumbnail" alt="Acompanhamento da instalação do servidor Arma Reforger no painel de logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-logs.png" loading="lazy" />

### Etapa 6 — Verificar se o servidor está em execução

Confirme que o estado do servidor é **Running**. Os comandos <code className="action">Log/Console</code> e <code className="action">Settings</code> permanecem disponíveis para gerir o servidor.

### Etapa 7 — Confirmar a conclusão da instalação

Assim que a instalação estiver concluída, o estado do servidor passa a **Running**.

### Etapa 8 — Obter as informações de ligação

Copie o endereço IP e a porta a partir da coluna **Connection** da lista de Game Servers.

<img className="thumbnail" alt="Detalhes de ligação do servidor Arma Reforger" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-connection-details.png" loading="lazy" />

### Etapa 9 — Juntar-se ao seu servidor no Arma Reforger

1. Abra o **Arma Reforger** e aceda ao menu principal.
2. Clique em **Multiplayer** e, em seguida, abra o separador **Community**.
3. Procure o nome do seu servidor.
4. Depois de o encontrar, clique no mesmo e, em seguida, clique em **Join**.
