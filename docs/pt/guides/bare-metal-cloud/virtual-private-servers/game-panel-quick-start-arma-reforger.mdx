## Objetivo

O Game Panel permite-lhe implementar um servidor Arma Reforger em algumas etapas. O Game Panel gere a instalação automaticamente, incluindo a configuração das portas.

**Este guia explica-lhe como implementar um servidor Arma Reforger no Game Panel e ligar-se a ele.**

## Requisitos

- Um [VPS](https://www.ovhcloud.com/pt/vps/) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um acesso ao Game Panel. Consulte o guia [Ligar-se ao Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instruções

### Etapa 1 — Aceder ao Game Panel

Ligue-se ao seu Game Panel.

### Etapa 2 — Criar uma nova instância de servidor

Clique em <code className="action">Add Game Server</code> e selecione **Arma Reforger**.

<img className="thumbnail" alt="Seleção de Arma Reforger na lista de jogos" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/select-arma-reforger.png" loading="lazy" />

:::info
Se for o seu primeiro servidor Arma Reforger no Game Panel e a Game Port predefinida estiver disponível, todas as portas necessárias serão configuradas automaticamente durante a instalação. Neste caso, não é necessária qualquer configuração manual.
:::


### Etapa 3 — Acompanhar o progresso da instalação

Assim que a instalação for iniciada, surge um ecrã de confirmação. Clique em <code className="action">Log/Console</code> para acompanhar o progresso da instalação em tempo real.

<img className="thumbnail" alt="Ecrã de arranque da instalação de Arma Reforger com o botão Open Logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-started.png" loading="lazy" />

Durante a instalação do servidor, o estado apresenta **Installing**. Acompanhe o progresso detalhado diretamente no painel de logs.

<img className="thumbnail" alt="Servidor Arma Reforger com o estado Running e os logs de instalação" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-logs.png" loading="lazy" />

### Etapa 4 — Confirmar o fim da instalação

Assim que a instalação estiver concluída, o estado do servidor passa a **Running**.

### Etapa 5 — Obter as informações de ligação

Assim que o seu servidor estiver no estado **Running**, copie as informações de ligação a partir do Game Panel.

<img className="thumbnail" alt="Detalhes de ligação do servidor Arma Reforger" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-connection-details.png" loading="lazy" />

### Etapa 6 — Juntar-se ao seu servidor no Arma Reforger

1. Abra o **Arma Reforger** e aceda ao menu principal.
2. Clique em <code className="action">Multiplayer</code>.
3. Selecione <code className="action">Direct Join</code> ou prima `v`.
4. Introduza o endereço IP e a porta, depois clique em <code className="action">Join</code>.
