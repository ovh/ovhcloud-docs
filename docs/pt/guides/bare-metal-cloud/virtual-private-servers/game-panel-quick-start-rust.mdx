## Objetivo

O Game Panel OVHcloud permite-lhe implementar um servidor Rust com uma instalação e uma configuração das portas automatizadas.

**Este guia explica como implementar um servidor Rust no Game Panel OVHcloud e ligar-se ao mesmo.**

## Requisitos

- Um [VPS](/links/bare-metal/vps) ou um [servidor dedicado](/links/bare-metal/bare-metal) na sua conta OVHcloud com a funcionalidade Game Panel ativada.
- Um acesso ao Game Panel. Consulte o guia [Ligar-se ao Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instruções

### Etapa 1 — Aceder ao Game Panel

Ligue-se ao seu Game Panel OVHcloud. No menu à esquerda, aceda à secção `Game Servers` e clique em <code className="action">Add Game Server</code>.

### Etapa 2 — Criar um servidor Rust

Selecione **Rust** na lista de jogos. Pode utilizar o campo de pesquisa situado na parte superior da janela para o encontrar mais rapidamente. Abre-se uma janela de configuração.

<img className="thumbnail" alt="Seleção do Rust na lista de jogos do Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/select-rust.png" loading="lazy" />

### Etapa 3 — Configurar o servidor Rust

Nesta secção, pode definir um nome para o seu servidor no campo **Server Name**.

É igualmente gerada automaticamente uma **RCON Password**. É utilizada pelo sistema RCON do jogo para administrar o servidor remotamente. Clique em <code className="action">Regenerate</code> para obter uma nova ou substitua-a por uma palavra-passe à sua escolha (no mínimo 8 caracteres). Poderá alterá-la novamente após a instalação do servidor.

:::warning
Guarde esta palavra-passe num local seguro. Qualquer pessoa que a conheça pode executar comandos de administração no seu servidor.
:::

Pode expandir <code className="action">Advanced Settings</code> para ajustar opções como o mapeamento das portas (ports binding), os volumes, as variáveis de ambiente e os limites de recursos. Os valores predefinidos são adequados para a maioria dos servidores de jogo.

<img className="thumbnail" alt="Formulário de configuração do servidor Rust com o nome do servidor e as definições avançadas" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/configure-server.png" loading="lazy" />

:::info
Se este for o seu primeiro servidor Rust no Game Panel e as portas predefinidas estiverem disponíveis, todas as portas necessárias são configuradas automaticamente. Não é necessária qualquer configuração manual. A imagem Rust utiliza três portas: `28015/UDP` (Game), `28017/UDP` (Steam Query) e `28082/TCP` (Rust+ companion app). Se estas portas já estiverem ocupadas por outro servidor de jogo, o Game Panel atribui portas de host livres.
:::

### Etapa 4 — Iniciar a instalação

Clique em <code className="action">Install</code> para iniciar a instalação. A implementação começa e uma janela de progresso acompanha as seguintes fases:

1. Descarregamento da imagem do contentor.
2. Preparação dos ficheiros do servidor.
3. Criação do contentor.
4. Arranque do contentor.

### Etapa 5 — Acompanhar a instalação

Assim que o contentor arrancar, é apresentada uma janela de confirmação. Clique em <code className="action">Open Logs / Console</code> para acompanhar o progresso da instalação em tempo real. Pode igualmente abri-la a qualquer momento através do botão <code className="action">Log/Console</code> do seu servidor.

<img className="thumbnail" alt="Janela de confirmação com o botão Open Logs / Console" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/installation-started.png" loading="lazy" />

A consola apresenta as etapas da instalação e, em seguida, o descarregamento dos ficheiros do servidor Rust através do SteamCMD, com uma percentagem de progresso.

<img className="thumbnail" alt="Logs de instalação do servidor Rust na consola do Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/installation-logs.png" loading="lazy" />

:::warning
Os ficheiros do servidor Rust representam um descarregamento de vários gigabytes. O servidor mantém o estado **Installing** durante todo o descarregamento e, em seguida, durante a geração do mundo de jogo. Consulte a consola para acompanhar o progresso real.
:::

### Etapa 6 — Verificar se o servidor está em execução

Verifique se o estado do servidor é **Running** e se existe atividade de CPU e RAM visível. Pode utilizar os controlos <code className="action">Log/Console</code> e <code className="action">Settings</code> para gerir o servidor, bem como os controlos <code className="action">Stop</code> e <code className="action">Restart</code> para alterar o respetivo estado de alimentação.

<img className="thumbnail" alt="Servidor Rust com o estado Running e atividade de CPU e RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/server-running.png" loading="lazy" />

### Etapa 7 — Confirmar a conclusão da instalação

Assim que o descarregamento estiver concluído, a consola apresenta o arranque do servidor Rust e, em seguida, a geração do mundo de jogo (mapa de alturas, biomas, monumentos). Esta etapa pode demorar vários minutos.

O estado pode apresentar brevemente **Unhealthy** enquanto o servidor termina o arranque e ainda não responde à verificação de estado. Este comportamento é normal numa primeira instalação.

O estado do servidor muda para **Running** assim que o mundo estiver gerado e o servidor estiver à escuta. O seu servidor Rust fica então pronto para aceitar ligações.

### Etapa 8 — Obter as informações de ligação

Assim que o seu servidor arrancar, copie o endereço IP e a porta a partir da coluna **Connection** da lista de servidores de jogo. Utilize o botão de cópia para os copiar para a área de transferência.

### Etapa 9 — Juntar-se ao seu servidor no Rust

Para se juntar ao seu servidor a partir do cliente de jogo Rust:

1. Inicie o **Rust**.
2. Prima a tecla `F1` para abrir a consola do jogo.
3. Introduza o comando seguinte, substituindo `IP` e `PORT` pelos valores da coluna **Connection**:

```console
client.connect IP:PORT
```

### Configurar os parâmetros do jogo

A secção <code className="action">Game Config</code> permite-lhe ajustar os principais parâmetros do seu servidor Rust sem editar manualmente os ficheiros de configuração:

| Parâmetro | Descrição |
|-----------|-----------|
| `Server name` | O nome apresentado no navegador de servidores do jogo. |
| `Gamemode` | `vanilla`, `Softcore`, `Hardcore` ou `Primitive`. |
| `Map type` | `Procedural Map`, `Barren`, `Hapis Island` ou `Savas Island`. |
| `Map seed` | A semente utilizada para gerar um mapa procedural. |
| `Map size` | O tamanho do mapa gerado. |
| `Player limit` | O número máximo de jogadores em simultâneo. |
| `Save interval` | O intervalo entre duas gravações do mundo de jogo. |
| `Tick rate` | A frequência de atualização do servidor. |

Outras opções, como a descrição do servidor, o modo PvE ou os danos de queda, estão disponíveis no ficheiro de configuração `server.cfg`, na mesma secção.

Para uma configuração avançada, utilize o [File Manager](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/) para editar diretamente os ficheiros de configuração do Rust.
