## Objetivo

A consola IPMI (Intelligent Platform Management Interface) permite estabelecer uma ligação direta ao seu servidor dedicado, sem depender do estado de conectividade do sistema operativo. Este manual explica-lhe como iniciar esta consola.

## Requisitos

:::warning
Esta funcionalidade pode estar indisponível ou limitada nos [servidores dedicados **Eco**](/links/bare-metal/eco-about).

Para mais informações, consulte o nosso [comparativo](/links/bare-metal/eco-compare).

:::

## Instruções

A ligação ao IPMI pode ser efetuada através de vários métodos¹. As chaves SSH armazenadas no servidor não serão utilizadas para estas ligações. Aqui está um quadro recapitulativo:

|Nome Método|Outro Nome|Descrição|Copiar-Colar|Unidade ISO Virtual²|Exemplos de casos de uso|
|---|---|---|---|---|---| 
|**KVM**³ via **browser da Web**|**KVM HTML**|Emulação do ecrã de vídeo através de um **padrão HTML**, tal como se estivesse a ligar fisicamente um teclado/rato em USB e um monitor de vídeo em VGA ao seu servidor dedicado.|❌|⚠️⁴|- Diagnosticar um problema de boot do servidor dedicado.|
|**KVM**³ via **applet Java**|**KVM Java**|Idem apenas para o KVM HTML, exceto que a emulação se efetua através de um **applet Java** em vez de uma placa de expansão HTML.|❌|✅| Diagnosticar um problema de boot do servidor dedicado. <br />- Efetuar uma instalação de um SO específico (exceto [catálogo](/links/bare-metal/os)) manualmente⁵.|
|**SoL**⁶ via **browser da Web**|**SoL JavaScript**|Emulação de ligação série através do browser da Web, tal como se estivesse a ligar uma consola série fisicamente em RS-232 ao seu servidor dedicado.|✅|❌| Diagnosticar um problema de rede: recuperar os logs e manipular os ficheiros de configuração.|
|**SoL**⁶ via **SSH**|**SoL SSH**|O mesmo que para o SoL JavaScript, exceto que a emulação é realizada através de gateway SSH. Conecte-se com o seu cliente SSH favorito a um servidor distante em SSH, que transpõe os comandos em ligação série ao servidor dedicado.|✅|❌|- Idem SoL JavaScript mas a partir de uma máquina que não tem uma interface gráfica.|

¹ Consoante a compatibilidade material do seu servidor dedicado (certos métodos não serão apresentados na consola OVHcloud).<br />
² Funcionalidade que permite montar uma imagem ISO armazenada localmente na sua máquina ao servidor dedicado remoto e, assim, instalar um SO através do IPMI.<br />
³ KVM = Keyboard Video and Mouse<br />
⁴ Consoante a compatibilidade material do seu servidor dedicado. A consola OVHcloud só propõe o KVM Java nos servidores sem KVM através do browser.<br />
⁵ Se o SO que deseja instalar não estiver disponível no [catálogo de sistemas operativos disponíveis nos servidores dedicados OVHcloud](/links/bare-metal/os), tenha em conta que também pode utilizar uma imagem personalizada: consulte [Comparação entre Bring Your Own Image (BYOI) e Bring Your Own Linux (BYOLinux)](/guides/bare-metal-cloud/dedicated-servers/bring-your-own-image-versus-bring-your-own-linux) para mais pormenores.<br />
⁶ SoL = Serial over Lan

Para ativar um destes métodos, clique no separador <code className="action">Server</code> do seu servidor. Os métodos estão agrupados na secção **Server connection**.

### Abrir um KVM através de applet Java <a name="applet-java"></a>

:::info
Recomendamos instalar a versão mais recente do Java.

:::


Para que a applet Java funcione, é necessário que o Java esteja instalado no seu computador. Se ainda não o fez, aceda à [página oficial](https://www.java.com/en/download/).

No bloco **KVM over IP** da secção **Server connection** da consola OVHcloud, clique em <code className="action">A partir de applet java (KVM)</code>. Esta opção só aparece nos servidores cujo IPMI não propõe KVM através do browser (HTML5).

Na janela **A partir de applet java (KVM)**, clique em <code className="action">Preparar a applet java</code>.

O ficheiro da applet (`.jnlp`) é descarregado automaticamente assim que estiver pronto. Execute-o:

<img className="thumbnail" alt="Abertura KVM Java" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-02.png" loading="lazy" />

De seguida, aceda à página de ligação. Introduza as suas credenciais `root`, como durante uma ligação através de um terminal ou de um software externo:

<img className="thumbnail" alt="Visão geral KVM Java" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-03.png" loading="lazy" />

Pode desde já gerir o seu servidor.

### Abrir um KVM através do browser da Web <a name="kvm-browser"></a>

No bloco **KVM over IP** da secção **Server connection** da consola OVHcloud, clique em <code className="action">Access console (KVM)</code>.

Na janela **Access KVM console**, clique em <code className="action">Request access</code>. A ativação demora alguns segundos.

Clique em <code className="action">Open console</code> para abrir a consola num novo separador do seu browser.

### Abrir SoL via SSH <a name="sol-ssh"></a>

Para mais informações sobre a criação de pares de chaves SSH, consulte [esta página](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys).

No bloco **Serial over LAN** da secção **Server connection** da consola OVHcloud, clique em <code className="action">Connect via SSH key (SoL)</code>.

Na janela **Serial over LAN — SSH key session**, escolha uma das chaves registadas na sua conta na lista pendente **Select an existing SSH key**, ou cole no campo **Public key** a chave SSH pública com a qual pretende ligar-se. Em seguida, clique em <code className="action">Start session</code>.

Para registar previamente uma chave na sua conta, utilize <code className="action">Add SSH key</code> no bloco **SSH keys** da mesma secção.

Quando a sessão estiver pronta, copie para a área de transferência o comando SSH apresentado: este permite-lhe estabelecer uma ligação série (Serial over LAN) ao seu servidor dedicado através de SSH.

Para mais informações sobre a utilização de uma chave SSH para estabelecer a ligação em SSH, consulte [esta página](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys).

### Abrir SoL através do browser <a name="sol-browser"></a>

No bloco **Serial over LAN** da secção **Server connection** da consola OVHcloud, clique em <code className="action">Connect via browser (SoL)</code>.

Na janela **Access Serial over LAN console**, clique em <code className="action">Request access</code>. A ativação demora alguns segundos.

:::info
A consola não se abre sozinha: assim que o acesso estiver pronto, clique em <code className="action">Open console</code> para a abrir num novo separador do seu browser.

:::

### Testar e reiniciar o IPMI <a name="ipmi-test-reboot"></a>

É possível que o IPMI deixe de responder. Se não conseguir aceder-lhe, pode começar por testá-lo: no bloco **IPMI** da secção **Server connection** da consola OVHcloud, clique em <code className="action">Test IPMI</code> e, a seguir, em <code className="action">Run test</code> na janela **Test IPMI**. Os testes HTTP, de palavra-passe e de ping são então executados uns após os outros.

Se todos os testes forem bem-sucedidos, provavelmente trata-se de um problema local (ligação à Internet, computador local). Se o IPMI apresentar efetivamente uma anomalia, pode reiniciá-lo: clique em <code className="action">Restart IPMI</code> e confirme clicando em <code className="action">Restart IPMI</code> na janela **Restart IPMI interface**.

A reinicialização do IPMI demora alguns minutos.

:::info
Esta operação não afeta o funcionamento do servidor.

:::


### Instalação de um sistema operativo com o IPMI v1

:::warning
A OVHcloud não garante a funcionalidade dos sistemas operativos instalados através do IPMI. Este método só deve ser considerado por um administrador de servidores experiente.

As versões 64 bits de Java podem impedir a abertura dos menus `Redirect ISO`/`Redirect CDROM` e provocar o bloqueio do JViewer.

:::


Para começar, abra o [IPMI a partir de uma applet Java](#applet-java) através da consola OVHcloud (esta opção só é proposta nos servidores cujo IPMI não dispõe de KVM através do browser). A seguir, clique em <code className="action">Device</code> na barra de menus e selecione <code className="action">Redirect ISO</code> no menu pendente.

<img className="thumbnail" alt="Redirect_ISO" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/RedirectISO.jpg" loading="lazy" />

De seguida, selecione a norma ISO que deseja utilizar no sistema de ficheiros do seu computador local. Depois de selecionar a sua norma ISO, prima o botão <code className="action">Ctrl Alt Del</code> no canto superior direito do ecrã para reiniciar o servidor. Carregue na tecla `F` para aceder às opções de arranque.

:::info
Poderá ter de utilizar o teclado de software para registar as entradas no IPMI. Para aceder, clique na opção <code className="action">Keyboard</code> na barra de menus no topo da janela. De seguida, selecione `Soft Keyboard` no menu pendente e clique em <code className="action">Show</code>.

:::


Selecione a opção `UEFI Virtual CDROM 1.00` no menu de arranque (Boot) para iniciar o servidor a partir da ISO previamente associada.

<img className="thumbnail" alt="UEFI_Virt" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/UEFIVirt.jpg" loading="lazy" />

Siga os passos necessários para instalar o sistema operativo. Não se esqueça de eliminar a norma ISO da opção "Redirect ISO".

### Instalação de um sistema operativo com o IPMI v2

:::warning
A OVHcloud não garante a funcionalidade dos sistemas operativos instalados através do IPMI. Este método só deve ser considerado por um administrador de servidores experiente.

:::


Para começar, abra o [IPMI a partir de uma applet Java](#applet-java) através da consola OVHcloud (esta opção só é proposta nos servidores cujo IPMI não dispõe de KVM através do browser). A seguir, clique em <code className="action">Virtual Media</code> e, a seguir, em <code className="action">Virtual Storage</code>.

<img className="thumbnail" alt="Virtual storage" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/virtual_storage.png" loading="lazy" />

Na nova janela, selecione a opção `ISO File` na lista pendente "Logical Drive Type". A seguir, clique em <code className="action">Open Image</code> e navegue até ao seu ficheiro ISO. Finalmente, clique em <code className="action">Plug-in</code> e <code className="action">OK</code>.

<img className="thumbnail" alt="ISO_file" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/iso_file.png" loading="lazy" />

Para começar a partir do seu ficheiro ISO, deve aceder à BIOS e alterar as opções de arranque. Para isso, clique em <code className="action">Power Control</code> e, a seguir, em <code className="action">Set Power Reset</code>.

<img className="thumbnail" alt="Power_Reserver" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/power_reset.png" loading="lazy" />

:::info
Poderá ter de utilizar o teclado de software para registar as entradas no IPMI. Para aceder, clique na opção <code className="action">Virtual Media</code> na barra de menus no topo da janela. De seguida, selecione <code className="action">Virtual Keyboard</code> no menu pendente.

:::


Durante o processo de arranque, prima a tecla `SUPR` quando for convidado a aceder à BIOS. Também pode carregar na tecla `F11` e aceder à BIOS selecionando a opção <code className="action">Enter Setup</code>.

<img className="thumbnail" alt="Menu_arranque" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/boot_menu.png" loading="lazy" />

Na BIOS, navegue até ao separador <code className="action">Boot</code> e substitua `UEFI Boot Order #1` por `UEFI USB CD/DVD:UEFI: CDROM virtual ATEN YSOJ`.

<img className="thumbnail" alt="Bios" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/bios.png" loading="lazy" />

Por fim, carregue na tecla `F4` para registar as suas modificações e reiniciar o servidor.

A OVHcloud não garante a funcionalidade dos sistemas operativos instalados através do IPMI. Este método só deve ser considerado por um administrador de servidores experiente.

Na consola OVHcloud, abra a [consola KVM através do browser](#kvm-browser).

Aqui, tem acesso às mesmas informações e funcionalidades que nos módulos IPMI baseados em Java.

:::info
Certifique-se de que executa os próximos passos a um bom ritmo. O processo pode ser anulado se houver pausas mais longas entre as ações.

:::


Clique no botão <code className="action">Browse File</code> e selecione o seu ficheiro de imagem.

O tamanho do ficheiro apresentado não é o tamanho real. É normal, porque o ficheiro não é completamente descarregado nesta etapa.

<img className="thumbnail" alt="Instalação do KVM" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install03.png" loading="lazy" />

### Reiniciar um servidor no menu BIOS

Você pode entrar no BIOS enquanto estiver configurando ou solucionando problemas com seu servidor. Uma forma prática de o fazer é utilizar a ferramenta `ipmiutil` (ver [página do projeto](https://ipmiutil.sourceforge.net/) para mais informações).

Quando o servidor estiver em [modo rescue](/guides/bare-metal-cloud/dedicated-servers/rescue-mode) e quando estiver ligado, instale-o com o seguinte comando:

```bash
apt install ipmiutil
```

De seguida, reinicie o servidor com este comando:

```bash
ipmiutil reset -b
```

Aceda à [consola IPMI](#procedure) na consola OVHcloud. O menu BIOS do servidor deve ser exibido.

<img className="thumbnail" alt="KVM BIOS" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_bios.png" loading="lazy" />
