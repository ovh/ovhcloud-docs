## Objetivo

O backup de um servidor Bare Metal com o Veeam Enterprise implica que várias aplicações e serviços funcionem em conjunto. O processo pode também variar em função da sua configuração e das suas preferências.

**Saiba como preparar o backup do seu servidor Bare Metal com o Veeam Backup and Replication (Enterprise).**

## Requisitos

- Um [servidor Bare Metal OVHcloud](/links/bare-metal/bare-metal)
- Uma solução de backup [Veeam Enterprise](/links/hosted-private-cloud/veeam-enterprise)
- Um serviço [OVHcloud Object Storage](/links/public-cloud/object-storage) (opcional)

[[cpnav:publiccloud-object-storage-console]]

## Instruções

### Instalação do seu servidor dedicado

O seu servidor Bare Metal OVHcloud deve estar instalado e configurado.

Consulte os nossos [guias de primeiros passos com os servidores dedicados](/guides/bare-metal-cloud/dedicated-servers/getting-started-with-dedicated-server).

Pode também configurar o seu servidor dedicado para utilizar uma rede privada, seguindo os passos [deste guia](/guides/bare-metal-cloud/dedicated-servers/vrack-configuring-on-dedicated-server).

### Instalação do seu servidor de backup Veeam Enterprise

Descarregue e instale o seu servidor de backup Veeam Enterprise e crie uma licença para ele, com a ajuda do nosso guia "[Instalar o Veeam Backup & Replication](/guides/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication)".

A partir deste passo, pode continuar a leitura deste guia para aprender a configurar o Object Storage como repositório de backup ou passar diretamente para a secção [Quer saber mais?](#gofurther).

### Configuração do Object Storage

Pode criar e configurar o Object Storage no universo <code className="action">Public Cloud</code> da consola OVHcloud, na secção <code className="action">Object Storage</code> do seu projeto Public Cloud.

Se ainda não tiver um projeto Public Cloud na sua conta OVHcloud, consulte o nosso guia [Criar o seu primeiro projeto Public Cloud](/guides/public-cloud/cross-functional/create-a-public-cloud-project).

[Crie um contentor Object Storage](/guides/storage-and-backup/object-storage/s3-getting-started-with-object-storage) com uma das soluções **Object Storage (Standard ou High Performance)**. Recomendamos a solução Standard, uma vez que o nosso caso de utilização (efetuar um backup) geralmente não requer armazenamento High Performance.

:::info
Ao encomendar um contentor Object Storage à OVHcloud, selecione apenas o **Object Storage Standard** ou o **Object Storage High Performance**. Estes contentores suportam totalmente o protocolo Amazon S3<sup>1</sup> e foram concebidos para serem utilizados como repositórios de backup.

:::


Atribua ao utilizador Object Storage direitos sobre o contentor, copiando e colando o código abaixo num ficheiro JSON.

```json
{
  "Statement":[
    {
      "Action":
         [
             "s3:GetObject",
             "s3:PutObject",
             "s3:DeleteObject",
             "s3:ListBucket",
             "s3:ListMultipartUploadParts",
             "s3:ListBucketMultipartUploads",
             "s3:AbortMultipartUpload",
             "s3:GetBucketLocation"
          ],
      "Effect":"Allow",
      "Resource":
          [
              "arn:aws:s3:::<container name>",
              "arn:aws:s3:::<container name>/*"
          ],
      "Sid":"RWContainer"
     }
  ]
}
```

Certifique-se de que substitui `container name` pelo nome real do seu contentor Object Storage.

No separador <code className="action">Utilizadores</code> da página **Object Storage**, clique no botão <code className="action">⋮</code> na coluna **Ações** do utilizador Object Storage e escolha <code className="action">Importar uma política</code>.

Na janela **Importar uma política**, selecione o ficheiro JSON que acabou de modificar e clique em <code className="action">Importar</code>. A política importada substitui a política atual do utilizador: se este utilizador já tiver uma política, transfira-a primeiro com <code className="action">Transferir a política</code> (mesmo menu) e adicione esta declaração à sua lista `Statement` antes de a importar.

### Configuração do repositório Object Storage no Veeam Enterprise

Na aplicação Veeam, selecione <code className="action">Backup Infrastructure</code>, <code className="action">Backup Repositories</code> e <code className="action">Add Repository</code>.

<img className="thumbnail" alt="Veeam - adicionar um repositório" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-02.png" loading="lazy" />

Selecione <code className="action">Object storage</code> como tipo de repositório.

<img className="thumbnail" alt="Veeam - Object Storage" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-03.png" loading="lazy" />

Selecione <code className="action">S3 Compatible</code>.

<img className="thumbnail" alt="Veeam - compatível com S3" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-04.png" loading="lazy" />

Atribua um nome (**Name**) ao novo repositório e clique em <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - nome do repositório" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-05.png" loading="lazy" />

Introduza as informações **Service point** (Endpoint) e **Region** do seu serviço de armazenamento Object Storage.

> Pode encontrar estas informações no universo <code className="action">Public Cloud</code> da consola OVHcloud.
> Clique em <code className="action">Object Storage</code> e, no separador <code className="action">Containers</code>, clique no nome do seu contentor e abra o seu separador <code className="action">Visão geral</code>. A **Região** é apresentada na secção **Informações gerais** (bem como na coluna **Região** da lista de contentores), e o **Endpoint** na secção **Detalhes da ligação**.

<img className="thumbnail" alt="Veeam - endpoint do serviço e região" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-08.png" loading="lazy" />

Clique em <code className="action">Add</code> para introduzir as suas credenciais. Introduza a sua **Access key** e a sua **Secret key** e, a seguir, clique em <code className="action">OK</code>.

> Estas informações estão disponíveis na consola OVHcloud, no separador <code className="action">Utilizadores</code> da página **Object Storage**. A **Chave de acesso** (Access key) é apresentada na coluna **Chave de acesso** da lista de utilizadores.
> Para obter a **Chave secreta** (Secret key), clique no botão <code className="action">⋮</code> na coluna **Ações** do utilizador e selecione <code className="action">Mostrar a chave secreta</code>. A chave é apresentada na janela **Credenciais S3**.

<img className="thumbnail" alt="Veeam - chaves" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-10.png" loading="lazy" />

Clique em <code className="action">Browse...</code> para selecionar o **Bucket**.

<img className="thumbnail" alt="Veeam - bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-11.png" loading="lazy" />

Selecione o bucket e clique em <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-12.png" loading="lazy" />

Clique em <code className="action">Browse...</code> para selecionar a pasta (**Folder**).

<img className="thumbnail" alt="Veeam - pasta" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-13.png" loading="lazy" />

Clique em <code className="action">New Folder</code>, introduza um nome para a pasta, selecione-a e clique em <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - pasta" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-14.png" loading="lazy" />

No passo de montagem do servidor (Mount Server), clique em <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - Mount Server" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-15.png" loading="lazy" />

No ecrã de resumo (Review), clique em <code className="action">Apply</code>.

<img className="thumbnail" alt="Veeam - revisão" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-16.png" loading="lazy" />

Depois de os processos terem sido executados com sucesso, clique em <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - fim do processo" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-17.png" loading="lazy" />

Reveja a página de resumo (Summary) e clique em <code className="action">Finish</code>.

<img className="thumbnail" alt="Veeam - resumo" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-18.png" loading="lazy" />

Os repositórios de backup devem agora ter um aspeto semelhante a este:

<img className="thumbnail" alt="Veeam - repositórios" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-19.png" loading="lazy" />

Já pode efetuar um backup com o Veeam Enterprise.
