## Objetivo

Os pares de chaves são utilizados para autenticar as ligações SSH entre os hosts, por exemplo, entre o cliente local do computador e um servidor remoto. Quando reinstala um servidor dedicado ou um VPS a partir da consola OVHcloud, tem a possibilidade de adicionar uma chave pública ao sistema operativo. O armazenamento de chaves SSH públicas na consola facilita este processo.

**Este manual explica-lhe como armazenar as suas chaves SSH públicas na consola OVHcloud.**

## Requisitos

- Um [servidor dedicado](/links/bare-metal/bare-metal) ou um [VPS](/links/bare-metal/vps) na sua conta OVHcloud

:::info
Para mais informações sobre a utilização das chaves SSH com os serviços [Public Cloud](/links/public-cloud/public-cloud), consulte o nosso guia dedicado:

[Como criar chaves SSH com OpenSSH para as instâncias Public Cloud](/guides/public-cloud/compute/creating-ssh-keys)

:::

## Instruções

Se ainda não criou nenhum par de chaves SSH, consulte os nossos manuais:

- [Criar e utilizar chaves SSH](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutorial - Como utilizar o PuTTY para as ligações SSH e autenticação](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

<img className="thumbnail" alt="Identity and Access Management group of the Console left menu, with the SSH keys entry" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/sidebar-iam-ssh-keys.png" loading="lazy" />

No menu à esquerda da consola OVHcloud, abra **Gestão de identidades e acessos** e clique em <code className="action">Chaves SSH</code>.

<img className="thumbnail" alt="SSH keys page with the Add an SSH key button above the list of keys" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-button.png" loading="lazy" />

Abra o menu <code className="action">Adicionar chave SSH</code> por cima da lista e selecione <code className="action">Serviços Dedicados</code>.

<img className="thumbnail" alt="Add an SSH key menu open, showing the Dedicated and Public Cloud options" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-menu.png" loading="lazy" />

Na janela **Adicionar chave SSH**, copie a cadeia completa da chave pública e cole-a no primeiro campo, **Chave pública**. Cole apenas a chave pública (o conteúdo do seu ficheiro `.pub`), nunca a chave privada.  
Introduza um nome para a chave no segundo campo, **Nome**, para a poder reconhecer (por exemplo, o nome do seu computador).

<img className="thumbnail" alt="Add an SSH key window with the Public key and Name fields and the Add button" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-dedicated-window.png" loading="lazy" />

Clique em <code className="action">Adicionar</code>.

A chave ficará agora disponível durante a reinstalação de um servidor dedicado ou de um VPS na consola OVHcloud.

Consulte os nossos manuais "Primeiros passos" para mais pormenores sobre este assumpto:

- [Servidor dedicado da gama **Eco**](/guides/bare-metal-cloud/dedicated-servers/getting-started-with-dedicated-server-eco)
