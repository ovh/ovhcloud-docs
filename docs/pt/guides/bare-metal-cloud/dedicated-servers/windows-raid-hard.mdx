## Requisitos

:::warning
As operações descritas neste guia exigem a eliminação do RAID existente. Isto significa que todos os dados presentes serão perdidos. Certifique-se de que efetua previamente uma cópia de segurança dos seus dados.
Este guia destina-se a utilizadores experientes.
:::


Para criar o particionamento, será necessário criar novos volumes RAID na placa. Para isso, precisa de:

- Dispor de um servidor com RAID de hardware (placa LSI MegaRaid).
- Dispor de, pelo menos, dois discos idênticos (neste guia, utilizamos um servidor com 3 discos).
- Ter acesso ao modo rescue.

## Instruções

### Listar os volumes RAID
Em primeiro lugar, é necessário listar os volumes RAID para depois os poder eliminar.

Para isso, utilizamos o seguinte comando: <code className="action">MegaCli -LDInfo -Lall -aAll</code>

Exemplo:

```sh
# root@rescue:~# MegaCli -LDInfo -Lall -aAll

Virtual Drive: 0 (Target Id: 0)

Name                 :
RAID Level           : Primary-5, Secondary-0, RAID Level Qualifier-3

Sector Size          : 512

Parity Size          : 1.818 TB
State                : Optimal

Span Depth           : 1
Default Cache Policy : WriteBack, ReadAhead, Direct, No Write Cache if Bad BBU

Exit Code: 0x00
```
Constatamos que, de momento, só existe um volume RAID no servidor e que este corresponde ao **Virtual Drive** 0.

### Eliminar os RAID
Podemos agora eliminar os volumes RAID existentes para, em seguida, criar os novos volumes RAID.

Para isso, utilizaremos o comando abaixo, que deve adaptar com o número do **Virtual Drive** obtido anteriormente.

<code className="action">MegaCli -CfgLDDel -Lx -a0</code>

O número do **Virtual Drive**

Exemplo:

```sh
# root@rescue:~# MegaCli -CfgLDDel -L0 -a0
 
Adapter 0: Deleted Virtual Drive-0(target id-0)
 
Exit Code: 0x00
```

:::info
Se o seu servidor já tiver vários RAID, repita a operação com o número de cada Virtual Drive.
:::


### Obter os ID dos discos
Vamos agora obter o **Enclosure ID** e o **SlotID** dos discos presentes no servidor para criar os novos volumes RAID.

Para isso, utilizaremos o seguinte comando: <code className="action">MegaCli -PdList -aALL | egrep -i "Adapter|Slot|Enclosure Device"</code>

Exemplo:

```sh
# root@rescue:~# MegaCli -PdList -aALL | egrep -i "Adapter|Slot|Enclosure Device"
Adapter #0
Enclosure Device ID: 252
Slot Number: 0
Enclosure Device ID: 252
Slot Number: 1
Enclosure Device ID: 252
Slot Number: 2
```
Constatamos que temos 3 discos, cujos **Enclosure ID** e **SlotID** são, respetivamente, 252:0, 252:1 e 252:2.

### Criar os novos volumes RAID
Em primeiro lugar, criamos o primeiro volume RAID, que servirá para o sistema operativo.

Utilizamos então o seguinte comando: <code className="action">MegaCli -CfgLdAdd -rX[EncID:SlotID,EncID:SlotID,...] -szYYYYY -a0</code>

Corresponde ao RAID pretendido (0, 1, 5 ou 6)

Corresponde aos Enclosure ID dos discos obtidos anteriormente

Corresponde aos SlotID dos discos obtidos anteriormente

Corresponde ao tamanho do primeiro disco virtual

No nosso exemplo, vamos criar um RAID 5 nos 3 discos, com um tamanho de 200 GB para o sistema operativo.

:::info
Recomendamos que reserve um pouco mais de espaço para obter uma partição com o tamanho mínimo pretendido, uma vez que a configuração ocupa algum espaço.
:::


```sh
# root@rescue:~# MegaCli -CfgLdAdd -r5[252:0,252:1,252:2] -sz204800 -a0
 
Adapter 0: Created VD 0
 
Adapter 0: Configured the Adapter!!
 
Exit Code: 0x00 
```
O primeiro volume RAID está criado. Resta agora atribuir o restante espaço disponível.

Vamos então criar um segundo volume RAID através do seguinte comando: <code className="action">MegaCli -CfgLdAdd -rX[EncID:SlotID,EncID:SlotID,...] -a0</code>

Corresponde ao RAID pretendido (0, 1, 5 ou 6)

Corresponde aos Enclosure ID dos discos obtidos anteriormente

Corresponde aos SlotID dos discos obtidos anteriormente

Exemplo:

```sh
# root@rescue:~# MegaCli -CfgLdAdd -r5[252:0,252:1,252:2] -a0
 
Adapter 0: Created VD 1
 
Adapter 0: Configured the Adapter!!
 
Exit Code: 0x00 
```
Está feito. Resta apenas verificar os volumes RAID.

### Instalar o Windows a partir da consola OVHcloud
Por fim, aceda à consola OVHcloud para proceder à instalação do Windows no seu servidor.

Deverá então selecionar a caixa <code className="action">Personalizar a configuração de partições</code> e modificar o esquema de partições atual para especificar apenas o disco C, com um tamanho máximo de 200 GB.

Depois de instalado o sistema, aceda ao seu sistema Windows, abra o utilitário <code className="action">Gestão de Discos</code> e particione o segundo disco virtual (correspondente ao segundo RAID, apresentado como "Não alocado") no formato GPT.
