## Objetivo

Se configurar o seu servidor dedicado como servidor DNS, pode utilizar o DNS secundário para alojar uma zona secundária. Assim, o DNS do seu domínio ficará disponível mesmo que o servidor DNS principal não responda.

**Este guia explica como adicionar o seu domínio na consola OVHcloud para utilizar um servidor DNS secundário.**

## Requisitos

- Dispor de um [servidor dedicado](/links/bare-metal/bare-metal).
- Dispor de um [nome de domínio](/links/web/domains) para o qual tem a gestão administrativa ou técnica.

:::warning
A responsabilidade sobre a configuração e a gestão dos serviços que a OVHcloud disponibiliza recai sobre o utilizador. Assim, deverá certificar-se de que estes funcionam corretamente.

Este guia fornece as instruções necessárias para realizar as operações mais habituais. No entanto, se encontrar dificuldades ou dúvidas relativamente à administração, utilização ou implementação dos serviços num servidor, recomendamos que recorra a um [prestador de serviços especializado](/links/partner).

:::

## Instruções

### Adicionar um domínio <a name="addingdomain"></a>

Antes de começar, adicione o registo TXT ownercheck à zona DNS do domínio, tal como descrito em [Verificação da autorização para o domínio](#verifyingdomain). Se a adição falhar, a janela apresenta apenas a mensagem **Falha ao adicionar o dominio DNS secundario. Por favor tente novamente.**

Na página do seu servidor dedicado, clique no separador <code className="action">Connectivity</code>. Na secção **DNS**, em **DNS secundario**, clique em <code className="action">Add a domain</code>.

Na janela **Adicionar DNS secundario**, siga as três etapas:

1. Introduza o domínio a adicionar no campo **Nome de dominio** e, em seguida, clique em <code className="action">Seguinte</code>.
2. Se o desejar, selecione na lista pendente **IP mestre (opcional)** o endereço IP do servidor que funcionará como mestre. Clique em <code className="action">Seguinte</code>.
3. Verifique a sua configuração e, em seguida, clique em <code className="action">Adicionar</code>. Para modificar um valor antes de confirmar, clique em <code className="action">Anterior</code>.

Depois de clicar em <code className="action">Adicionar</code>, o domínio é adicionado ao servidor DNS secundário OVHcloud.

Os domínios adicionados são listados em **DNS secundario**. A coluna **Servidor DNS** apresenta o nome do servidor DNS secundário ao lado de cada domínio. Para eliminar um domínio, clique no ícone do caixote do lixo no fim da respetiva linha.

:::info
As outras ações necessárias para configurar o seu próprio DNS para o seu domínio são geralmente as seguintes:

- configuração de um serviço DNS (como *BIND*)
- configuração dos registos GLUE
- autorização das transferências de zona

Recorra à documentação externa adequada caso necessite de informações adicionais para completar estas tarefas administrativas.

:::


### Verificação da autorização para o domínio <a name="verifyingdomain"></a>

É necessário confirmar a sua autorização para gerir o domínio em questão antes de poder adicioná-lo ao DNS secundário da OVHcloud. Isto é feito através de uma pesquisa DNS automatizada no subdomínio *ownercheck.oseunomededominio*. Para este efeito, é gerada uma cadeia única de caracteres.

A janela **Adicionar DNS secundario** da consola OVHcloud não apresenta este valor. Para o obter, utilize a seguinte chamada API, indicando o nome interno do servidor (exemplo: `ns3956771.ip-169-254-10.eu`) e o domínio no parâmetro `domain`:

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/secondaryDnsNameDomainToken"} />

A resposta contém o tipo de registo (`TXT`), o subdomínio (`ownercheck`) e o valor a utilizar.

- Se o domínio for gerido por um agente de registo externo ou utilizar servidores DNS externos, aceda à interface de gestão do seu fornecedor DNS e adicione um registo TXT com o subdomínio "ownercheck" e este valor.

- Se o domínio for gerido pela OVHcloud enquanto agente de registo e utilizar servidores DNS da OVHcloud, siga as instruções [deste manual](/guides/web-cloud/domains/dns-zone-edit) para adicionar o registo TXT na consola OVHcloud.

Depois de adicionar corretamente o registo TXT à zona DNS do domínio, repita os [passos acima](#addingdomain) e conclua o procedimento.
