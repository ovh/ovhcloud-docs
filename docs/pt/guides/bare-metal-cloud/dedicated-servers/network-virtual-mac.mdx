## Sumário

A OVHcloud permite-lhe associar um endereço MAC virtual a um endereço de IP, de modo a poder instalar máquinas virtuais com uma configuração bridge no seu servidor.

**Este manual explica como criar um endereço MAC virtual e como associá-lo a um Additional IP.**

## Requisitos

- Dispor de [um servidor dedicado](/links/bare-metal/bare-metal) que suporte os MAC virtuais. Consulte [este guia](/guides/bare-metal-cloud/dedicated-servers/network-support-virtual-mac) para o determinar.
- Dispor de um [endereço de Additional IP](/links/network/additional-ip) ou de um bloco de Additional IP (RIPE).

:::warning
- Esta funcionalidade pode estar indisponível ou limitada nos [servidores dedicados **Eco**](/links/bare-metal/eco-about). Para mais informações, consulte o nosso [comparativo](/links/bare-metal/eco-compare).

- Os servidores Advance de terceira geração (equipados com processadores EPYC 4004 Series) suportam 32 vMACs diferentes.

- Desde maio de 2025, esta funcionalidade está disponível nas gamas Scale e High Grade.

:::


:::info
Se não está familiarizado com a utilização da API OVHcloud, consulte o nosso guia [Primeiros passos com as API OVHcloud](/guides/manage-and-operate/api/first-steps).

:::

## Instruções

### Atribuir um endereço MAC

:::warning
Se um bloco IP foi migrado para o vRack, já não é atribuído a um servidor físico. Já não é possível atribuir um MAC virtual a um IP.

:::


#### Através da consola OVHcloud

Clique no filtro <code className="action">IP adicional</code> acima da lista para mostrar apenas os seus Additional IP.

Localize o seu Additional IP (ou o seu bloco) na lista e clique nele para abrir a respetiva página. Em seguida, clique no separador <code className="action">MAC Virtual</code>. No caso de um bloco, o menu pendente **Mostrar MACs virtuais para** permite escolher o IP cujos MAC virtuais são apresentados. Clique em <code className="action">Adicionar MAC virtual</code>.

Quando aparecer a janela **Adicionar um MAC virtual**, selecione o endereço IP na lista **Endereço IP** (apenas para um bloco), selecione um tipo no menu pendente **Tipo**, introduza um nome no campo **Máquina virtual** e clique em <code className="action">Adicionar</code>.

:::info
**Tipo**: trata-se do tipo de endereço MAC virtual (<code className="action">vmware</code> será um endereço MAC feito para o sistema VMware ESXi, ao passo que <code className="action">ovh</code> servirá para todos os outros tipos de sistemas de virtualização).

**Máquina virtual**: trata-se do nome desejado para o endereço MAC virtual, para depois se encontrar mais facilmente o par IP/MAC.

Se o seu servidor já dispuser de endereços MAC virtuais, a janela permite escolher entre <code className="action">Criar um novo endereço MAC virtual</code> e <code className="action">Usar um endereço MAC virtual existente</code>. Com a segunda opção, selecione o endereço MAC a reutilizar em vez de um tipo.

:::

:::info
Não se esqueça de atribuir o endereço MAC virtual criado durante a configuração da máquina virtual.

:::


#### Através da API OVHcloud

Utilize a seguinte chamada API:

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/virtualMac"} />


### Eliminar um endereço MAC

:::warning
A eliminação de um endereço MAC é definitiva: não será possível recuperá-lo.

:::


#### Através da consola OVHcloud

Na página **Endereços IP**, utilize o menu pendente **Filtrar por serviço...** ou a barra de pesquisa para encontrar o Additional IP (ou o bloco IP). Clique nele para abrir a respetiva página e clique no separador <code className="action">MAC Virtual</code>. No caso de um bloco, selecione o IP no menu pendente **Mostrar MACs virtuais para**.

Cada MAC virtual é apresentado sob o respetivo endereço MAC. Clique em <code className="action">Eliminar</code> sob o MAC virtual e, em seguida, em <code className="action">Eliminar</code> na janela **Eliminar o endereço MAC virtual** para confirmar.

#### Através da API OVHcloud

Utilize a seguinte chamada API:

<Api version="v1" section="/dedicated/server" method="DELETE" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


## FAQ

- **O que acontece se mover um bloco com vMACs num servidor Advance de terceira geração (equipado com um processador EPYC 4004 Series) que já possua 32 vMACs?**

O bloco não será deslocado.

Exemplo: se tentar migrar um bloco de 4 endereços IP com vMACs diferentes ligados a um servidor que já tenha 30 vMACs, o bloco não será deslocado, pois o total de vMACs seria superior aos 32 vMACs autorizados.
