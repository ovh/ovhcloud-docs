## Objetivo

O modo rescue é uma ferramenta fornecida pela OVHcloud que permite iniciar num sistema operativo temporário. Tem como objetivo diagnosticar e resolver os problemas no seu servidor.

O funcionamento geral do modo rescue é descrito no nosso guia [Como ativar e utilizar o modo rescue](/guides/bare-metal-cloud/dedicated-servers/rescue-mode).

A opção **Windows customer rescue system** só está disponível para os servidores dedicados nos quais está instalado um sistema operativo **Windows Server**. São aplicáveis as seguintes condições:

- O sistema rescue para Windows (`rescue-customer-windows`) funciona numa máquina virtual (VM) lançada a partir do sistema rescue client (`rescue-customer`, baseado em Debian GNU/Linux).
- Os discos do servidor estão ligados à VM com *passthrough*. Assim, é possível aceder aos mesmos.
- Os outros componentes do servidor ficarão inacessíveis (CPU, RAM, NIC, RAID).
- A rede é montada com *passthrough* mas sem acesso direto ao adaptador de rede. A VM porta o endereço IP e o endereço MAC do servidor *bare metal*.

:::warning
Certifique-se de que efetua um backup dos seus dados se ainda não dispõe de um backup recente.

Se tiver serviços em produção no seu servidor, o modo rescue interrompe-os-á enquanto a máquina não for reiniciada em modo normal.

:::


**Saiba como iniciar um servidor no SO Windows Client.**

## Requisitos

- Microsoft Windows instalado no seu [servidor dedicado](/links/bare-metal/bare-metal)
- Pelo menos 16 GB de RAM instaladas no servidor

## Instruções

### Ativação do modo rescue para Windows

Clique no nome do seu servidor para abrir a respetiva página. Esta abre no separador **Visão geral**, que contém a secção **Informações gerais**.

<a name="netboot"></a>

Na secção **Informações gerais**, clique na ligação <code className="action">Modo rescue</code> da linha **Boot Mode**. O separador **Server** abre no parâmetro **Boot mode** da secção **System**. Também pode clicar diretamente no separador <code className="action">Server</code> e aceder ao parâmetro **Boot mode**.

Selecione a opção <code className="action">Rescue mode</code>.

Na lista pendente **Rescue kernel**, selecione <code className="action">Windows customer rescue system v12 (Windows2022-based)</code>.

O e-mail de notificação do modo rescue, bem como os seus dados de acesso, serão enviados para o endereço de e-mail de contacto da sua conta OVHcloud. Para utilizar outro endereço de e-mail, introduza-o no campo **Rescue email**. Se o campo **Rescue email** já apresentar um endereço, o e-mail é enviado para esse endereço.

Clique em <code className="action">Apply</code>. Na janela **Apply boot mode change**, verifique o modo de arranque atual e o novo e, a seguir, clique em <code className="action">Apply</code>. O novo modo de arranque será aplicado no próximo reinício.

O último passo consiste em reiniciar o servidor. Na janela **Reboot to apply**, clique em <code className="action">Reboot now</code>. Se reiniciar o servidor mais tarde, clique na ligação <code className="action">Reiniciar</code> da linha **Boot Mode** na secção **Informações gerais** (separador **Visão geral**) e, a seguir, em <code className="action">Reboot</code> na janela de confirmação.

Este *hard reboot* demorará alguns minutos a terminar. Pode verificar o estado atual no separador <code className="action">Atividades</code>.

:::info
Depois de concluir as suas ações em modo rescue, não se esqueça de redefinir o parâmetro **Boot mode** para <code className="action">Boot from hard disk</code> antes de reiniciar o servidor.

:::


### Aceder ao seu servidor em modo rescue

Depois de receber um e-mail a informar que o modo rescue está ativado, poderá aceder ao sistema através do modo rescue do Windows e aceder ao servidor.  
Este e-mail também está disponível na consola OVHcloud assim que for enviado. Abra o menu da conta no canto superior direito e, a seguir, clique em <code className="action">As minhas comunicações</code>, em **Acesso rápido**. O e-mail aparece no separador **Mensagens** da página **Communications**.

Para efetuar uma sessão remota no sistema em modo rescue do Windows, precisará das seguintes informações de identificação:

- Endereço IP do servidor
- Nome de utilizador da conta de administrador temporário (`Administrator`)
- Palavra-passe da conta de administrador temporário

Pode utilizar os seguintes métodos de ligação para aceder ao servidor através do sistema em modo Rescue do Windows:

- Remote Desktop Protocol (RDP)
- KVM over IP (se o seu servidor o permitir)
- OpenSSH (componente oficial do Windows Server)

#### SSH

<details>

<summary>Expanda esta secção</summary>


Abra a aplicação de linha de comandos no seu dispositivo local e introduza este comando:

```bash
ssh Administrator@SERVER_IP
```

Exemplo:

```bash
ssh Administrator@203.0.113.100
```

Introduza a palavra-passe do Modo Rescue Temporário quando tal lhe for solicitado. Exemplo:

```console
Administrator@ns9356771.ip-203-0-113.eu's password:
administrator@WINRESCUEOVH C:\Users\Administrator>
```

Encontre mais informações sobre as ligações SSH no nosso [guia de introdução ao SSH](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction).  
Também pode utilizar qualquer ferramenta de ligação SSH, como [PuTTY](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows).

</details>

### Saída do modo rescue

Na consola OVHcloud, aceda ao parâmetro [Boot mode](#netboot) do separador **Server** do seu servidor, selecione <code className="action">Boot from hard disk</code> e clique em <code className="action">Apply</code>. Clique novamente em <code className="action">Apply</code> na janela **Apply boot mode change**.

A seguir, reinicie o servidor: clique em <code className="action">Reboot now</code> na janela **Reboot to apply** ou utilize a ligação <code className="action">Reiniciar</code> da linha **Boot Mode** na secção **Informações gerais**.
