## Objetivo

O vRack é a possibilidade de ligar diferentes serviços cloud da OVHcloud entre si, no seio de uma ou várias redes privadas seguras (VLAN).

**Este guia explica como implementar**

## Requisitos

- Ter um serviço [vRack](/links/network/vrack) na sua conta ou encomendar um serviço se necessário.
- Ter contacto com o administrador da infraestrutura [Hosted Private Cloud](/links/hosted-private-cloud/enterprise), para receber dados de acesso.
- Ter um identificador de utilizador ativo criado na <ManagerLink console to="/">consola OVHcloud</ManagerLink>.

[[cpnav:network-vrack-console]]

## Instruções

### Consola OVHcloud

Aquando da entrega do seu serviço [Hosted Private Cloud](/links/hosted-private-cloud/enterprise), a parte *datacenter* já está dentro de um vRack. Para visualizar o conteúdo na consola OVHcloud, aceda a **Rede** › <code className="action">vRack</code>, selecione o seu vRack na lista e abra o separador <code className="action">Serviços associados</code>.

É possível mover o *datacenter* do seu Hosted Private Cloud para outro vRack: na respetiva linha **Private Cloud Datacenter**, clique em <code className="action">Mover</code>. Na janela **Migração de um datacenter Private Cloud**, selecione o **vRack de destino** e clique em <code className="action">Mover</code>. Esta operação implica uma interrupção do serviço de cerca de 5 minutos.

### Client vSphere

No vSphere, pode encontrar as *VLANs* compatíveis com vRack no switch virtual distribuído (vds), que está situado na pasta **vRack**.

:::tip
Por predefinição, a OVHcloud disponibiliza-lhe uma infraestrutura com 11 VLANs (VLAN10 a VLAN20).

:::


<img className="thumbnail" alt="vlan" src="/images/hosted-private-cloud/powered-by-vmware/using-private-cloud-in-vrack/vRackVsphere.png" loading="lazy" />

É possível alterar os parâmetros ou criar novos parâmetros de acordo com o guia de [criação da VLAN](/guides/hosted-private-cloud/powered-by-vmware/create-vlan).

Poderá de seguida atribuir estas *portgroup* às interfaces de rede das suas máquinas virtuais.
