## Objetivo

Quando uma manutenção é programada no seu Hosted Private Cloud, ser-lhe-á enviado um e-mail de notificação para o avisar da data dessa manutenção. Se esta data não lhe convém, por exemplo por razões de produção, pode adiar esta manutenção para uma data à sua escolha, através da consola OVHcloud ou da API OVHcloud.

:::info
Estamos a tentar adaptar-nos ao máximo à sua utilização da infraestrutura e às suas limitações. No entanto, por vezes temos de planear manutenções para as quais não será possível modificar a data e/ou a hora (manutenção de infraestruturas que envolvam vários clientes, intervenções urgentes para evitar um incidente, etc.).

Para informação, quando uma data de manutenção pode ser alterada por si, as novas datas propostas estão incluídas num intervalo de tempo reduzido.

:::

**Saiba como adiar a data de uma manutenção programada no seu VMware on OVHcloud a partir da consola OVHcloud ou da API OVHcloud.**

## Requisitos

- Ter recebido um e-mail de notificação de manutenção indicando especificamente que pode "**alterar a data de execução da manutenção**". Caso contrário, a data da manutenção não pode ser alterada.
- Ser o contacto administrador ou técnico da infraestrutura [VMware on OVHcloud](https://www.ovhcloud.com/pt/enterprise/products/hosted-private-cloud/).
- Ter acesso à <ApiLink>interface de administração dos seus serviços através da API</ApiLink>.

## Instruções

:::tip
Os e-mails enviados pela OVHcloud também estão acessíveis a partir do histórico dos e-mails de serviço da sua conta OVHcloud.

:::

### A partir da consola OVHcloud

Com uma conta de administrador, aceda a **Private Cloud** › **Managed VMware vSphere** na consola OVHcloud, selecione o seu serviço na lista e clique no separador <code className="action">Operações</code>. No menu pendente situado acima da tabela das operações, à direita, verifique se <code className="action">Em curso</code> (valor por defeito) está selecionado para apresentar as operações que ainda não estão concluídas.

A seguir, abra o menu ⋮ (coluna **Ações**) da operação de manutenção e clique em <code className="action">Modificar a data de tratamento</code>.

:::info
Se a opção <code className="action">Modificar a data de tratamento</code> não estiver disponível, esta manutenção não pode ser adiada.

:::

Na janela **Modificar a data de tratamento**, selecione uma data no calendário **Data de processamento**. Apenas as datas disponíveis podem ser selecionadas: as datas situadas fora da janela de manutenção autorizada não podem ser escolhidas.

Introduza depois uma nova hora para esta manutenção no campo **Hora** ou deixe inalterado o horário inicialmente previsto.

Por fim, clique no botão <code className="action">Alterar</code> para validar as suas modificações.

### A partir da API OVHcloud

Pode consultar o nosso manual "[Primeiros passos com as API OVHcloud](/guides/manage-and-operate/api/first-steps)".

Execute a seguinte chamada API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/task/\{taskId\}/changeMaintenanceExecutionDate"} />

Introduza as variáveis:

- serviceName: a referência do seu PCC sob a forma `pcc-XX-XX-XX-XX`.
- taskId: trata-se da "referência da operação" de manutenção introduzida no e-mail de notificação que lhe foi enviado.
- executionDate: indicar a nova data de manutenção em formato `YYYY-MM-DDTHH:MM+01:SS` (por exemplo, 2023-01-02T08:00:00+01:00 para manutenção programada a 02/01/2023 às 08h00 (UTC+1)).
