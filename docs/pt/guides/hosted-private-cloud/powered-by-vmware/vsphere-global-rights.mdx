## Objetivo

As permissões globais do vSphere permitem definir os direitos de um utilizador no seu serviço Hosted Private Cloud. A partir da Área de Cliente OVHcloud, pode ativar ou desativar estas opções para cada utilizador.

Este guia explica como gerir estas permissões globais.

## Requisitos

- Um [serviço Hosted Private Cloud](/links/hosted-private-cloud/vmware) ativo
- Um [utilizador do vSphere](/guides/hosted-private-cloud/powered-by-vmware/vsphere-interface-connection) já criado no seu serviço
- Acesso à <ManagerLink to="/">Área de Cliente OVHcloud</ManagerLink> com direitos suficientes para administrar os utilizadores

## Instruções

### Aceder à gestão dos direitos dos utilizadores

1. A partir do seu serviço vSphere, aceda ao separador <code className="action">Utilizadores</code>.

    <img className="thumbnail" alt="Separador utilizadores" src="/images/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud/en05users.png" loading="lazy" />

2. Na linha do utilizador correspondente, abra o menu <code className="action">...</code> e clique em <code className="action">Alterar</code>.

### Configurar as permissões globais

Na janela de modificação do utilizador, várias opções correspondem às permissões globais.

1. Ative ou desative as opções de acordo com os direitos que pretende conceder ao utilizador.

    <img className="thumbnail" alt="Janela de modificação dos direitos do utilizador" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/user-global-rights.png" loading="lazy" />

2. Valide a modificação.

### Permissões disponíveis

A janela de modificação do utilizador propõe as seguintes opções:

| Permissão               | Descrição                                                                                                                                                                                                                                                                   |
|-------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `Token validator`       | Permite ao utilizador validar as operações que exigem um token de validação. Esta permissão é geralmente útil quando a autenticação de dois fatores (2FA) está ativada no serviço, por exemplo no âmbito de certas certificações como o Alojamento de dados de saúde (HDS). |
| `IP`                    | Permite ao utilizador gerir os endereços IP associados ao serviço.                                                                                                                                                                                                          |
| `IP Failover`           | Permite ao utilizador gerir os endereços IP Failover associados ao serviço.                                                                                                                                                                                                 |
| `Interface NSX`         | Concede acesso à interface de gestão de rede NSX.                                                                                                                                                                                                                           |
| `Gestão da encriptação` | Permite ao utilizador gerir a encriptação das máquinas virtuais (KMS).                                                                                                                                                                                                      |

### Gerir os direitos por datacenter

Além das permissões globais do serviço, pode definir direitos para cada datacenter virtual do seu Hosted Private Cloud.

1. No separador <code className="action">Utilizadores</code>, na linha do utilizador correspondente, abra o menu <code className="action">...</code> e clique em <code className="action">Ver / Modificar as permissões por DC</code>.

    <img className="thumbnail" alt="Separador utilizadores e menu de ações" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/users-actions-menu.png" loading="lazy" />

2. Na página **Gestão de permissões do utilizador por datacenter**, localize a linha correspondente ao datacenter. Abra o menu <code className="action">...</code> e clique em <code className="action">modificar as permissões</code>.

    <img className="thumbnail" alt="Gerir direitos por datacenter" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/rights-by-datacentre.png" loading="lazy" />

3. Na janela **Alteração das permissões de acesso**, configure os direitos pretendidos e valide.

    <img className="thumbnail" alt="Janela de edição dos direitos" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/edit-rights-modal.png" loading="lazy" />

#### Referência dos direitos

**Acesso à interface vSphere** — direitos globais do utilizador no vSphere.

| Direito           | Descrição                              |
|-------------------|----------------------------------------|
| `Nenhum`          | Sem acesso                             |
| `Operador`        | Reservado aos administradores OVHcloud |
| `Apenas leitura`  | Acesso só de leitura                   |
| `Leitura/Escrita` | Acesso de leitura e escrita            |

**Acesso à vmNetwork** — direitos de gestão sobre a secção de rede pública ("VM Network" no vSphere).

| Direito          | Descrição                               |
|------------------|-----------------------------------------|
| `Nenhum`         | Sem acesso                              |
| `Operador`       | Permite configurar VM numa rede pública |
| `Apenas leitura` | Acesso só de leitura                    |

**Acesso às V(x)Lans** — direitos de gestão sobre a secção de rede privada (VXLAN para Hosted Private Cloud, VLAN para SDDC).

| Direito          | Descrição                                                                                               |
|------------------|---------------------------------------------------------------------------------------------------------|
| `Nenhum`         | Sem acesso                                                                                              |
| `Operador`       | Permite configurar VM numa rede privada                                                                 |
| `Administrador`  | Permite gerir os grupos de portas no switch virtual (criar, modificar, eliminar). Apenas SDDC e Premier |
| `Apenas leitura` | Acesso só de leitura                                                                                    |

**Gestão dos hosts e dos armazenamentos** — quando ativada, esta opção permite ao utilizador adicionar ou eliminar hosts e armazenamento através do plugin OVHcloud no cliente vSphere.

### Restringir o acesso a certos objetos do vSphere

As permissões acima aplicam-se a todo o serviço (cluster vSphere) ou a um datacenter virtual. Para autorizar um utilizador apenas em certos objetos do inventário do vSphere (máquina virtual, datastore ou pasta), utilize os [direitos granulares nos objetos do vSphere](/guides/hosted-private-cloud/powered-by-vmware/vsphere-granular-rights).
