## Sumário

As permissões globais do vSphere permitem definir os direitos de um utilizador no seu serviço Hosted Private Cloud. A partir da Área de Cliente OVHcloud, pode ativar ou desativar estas opções para cada utilizador através de caixas de seleção.

Este manual explica como gerir estas permissões globais a partir do Manager OVHcloud.

- **Caminho de navegação:** <code className="action">Hosted Private Cloud</code> > <code className="action">Managed VMware vSphere</code> > Selecione o seu serviço vSphere

## Requisitos

- Um [serviço Hosted Private Cloud](https://www.ovhcloud.com/pt/hosted-private-cloud/vmware/) ativo
- Um [utilizador do vSphere](/guides/hosted-private-cloud/powered-by-vmware/vsphere-interface-connexion) já criado no seu serviço
- Acesso à <ManagerLink to="/">Área de Cliente OVHcloud</ManagerLink> com direitos suficientes para administrar os utilizadores

## Instruções

### Aceder à gestão dos direitos dos utilizadores

1. Abra a <ManagerLink to="/">Área de Cliente OVHcloud</ManagerLink>. Clique em <code className="action">Hosted Private Cloud</code> na barra superior, depois em <code className="action">Managed VMware vSphere</code> no menu à esquerda e selecione o seu serviço PCC.

2. Aceda ao separador <code className="action">Utilizadores</code>.

	<img className="thumbnail" alt="Separador utilizadores" src="/images/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud/en05users.png" loading="lazy" />

3. Na linha do utilizador correspondente, abra o menu <code className="action">...</code> e clique em <code className="action">Modificar</code>.

### Configurar as permissões globais

1. Na janela de modificação do utilizador, várias caixas de seleção correspondem às permissões globais.

2. Marque ou desmarque as opções de acordo com os direitos que pretende conceder ao utilizador.

	<img className="thumbnail" alt="Janela de modificação dos direitos do utilizador" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/user-global-rights.png" loading="lazy" />

3. Valide a modificação.

### Permissões disponíveis

As permissões globais são representadas pelas seguintes caixas de seleção na janela de modificação do utilizador:

| Permissão | Descrição |
|---|---|
| Token validator | Permite ao utilizador validar as operações que exigem um token de validação. Esta permissão é geralmente útil quando a autenticação de dois fatores (2FA) está ativada no serviço, por exemplo no âmbito de certas certificações como o Alojamento de dados de saúde (HDS). |
| Ip | Permite ao utilizador gerir os endereços IP associados ao serviço. |
| Ip Failover | Permite ao utilizador gerir os endereços IP Failover associados ao serviço. |
| Interface NSX | Concede acesso à interface de gestão de rede NSX. |
| Encryption management | Permite ao utilizador gerir a encriptação das máquinas virtuais (KMS). |

### Saber mais sobre os direitos granulares

As permissões globais descritas acima aplicam-se ao nível do inventário do vSphere do Hosted Private Cloud, ou seja, ao nível do cluster VMware considerado.

Se precisar de autorizar um utilizador apenas em certos objetos do inventário do vSphere, por exemplo uma máquina virtual, um datastore ou uma pasta, deve utilizar os [direitos granulares nos objetos do vSphere](/guides/hosted-private-cloud/powered-by-vmware/vsphere-granular-rights).
