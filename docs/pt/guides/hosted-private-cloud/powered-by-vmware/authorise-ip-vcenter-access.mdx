## Objetivo

O acesso ao seu vCenter é restrito aos endereços IP autorizados.

**Saiba como autorizar endereços IP a ligarem-se ao vCenter.**

## Requisitos

* Ter acesso à <ManagerLink to="/">Área de Cliente OVHcloud</ManagerLink>.
* Dispor de uma [infraestrutura Hosted Private Cloud](https://www.ovhcloud.com/pt/enterprise/products/hosted-private-cloud/) na sua conta OVHcloud.

## Instruções

Por predefinição, o acesso ao seu vCenter é restrito. Por isso, é necessário adicionar os IP que serão autorizados a ligar-se ao serviço.

A operação pode ser realizada a partir da <ManagerLink to="/">Área de Cliente OVHcloud</ManagerLink>. Na secção <code className="action">Hosted Private Cloud</code>, clique na opção <code className="action">VMware</code>. 

Selecione a infraestrutura e aceda ao separador <code className="action">Segurança</code> e clique em <code className="action">Adicionar um novo intervalo de endereços IP</code>.

<img className="thumbnail" alt="vCenter" src="/images/hosted-private-cloud/powered-by-vmware/authorise-ip-vcenter-access/restrictIP.JPG" loading="lazy" />

Aqui, deve adicionar o IP em questão e eventualmente uma descrição para o encontrar facilmente na lista mais tarde.

Só precisa de validar clicando em <code className="action">Seguinte</code> e, uma vez que o IP está corretamente marcado como **Autorizado e implementado**, a ligação ao vSphere será possível a partir do IP em questão.

<img className="thumbnail" alt="vCenter" src="/images/hosted-private-cloud/powered-by-vmware/authorise-ip-vcenter-access/restrictIP2.JPG" loading="lazy" />

:::info
Tenha em conta que, por razões de segurança, só poderá autorizar um máximo de 2048 endereços IP a ligar-se ao seu vCenter.

:::
