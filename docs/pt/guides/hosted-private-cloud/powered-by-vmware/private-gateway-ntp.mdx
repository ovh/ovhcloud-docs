## Objective

The private gateway allows you to use an NTP server.

**This guide explains how to configure the NTP service on the private gateway of your Hosted Private Cloud infrastructure.**

## Requirements

- A [Hosted Private Cloud](https://www.ovhcloud.com/en-gb/hosted-private-cloud/vmware/) solution.
- Access to the vSphere management interface.
- Having enabled the private gateway.
- Having [created your OVHcloud API credentials](/guides/manage-and-operate/api/first-steps) and being connected to the [OVHcloud API](https://eu.api.ovh.com/).

## Instructions

### Architecture

The private gateway is not routed by default. Only machines on the same subnet can access the NTP server directly. For access from another network, a source NAT must be configured.

<img className="thumbnail" alt="NTP private gateway - Architecture" src="/images/hosted-private-cloud/powered-by-vmware/private-gateway-ntp/architecture.png" loading="lazy" />

### Configuring NTP on the private gateway

#### Retrieve the private gateway IP address

Make the following API call to retrieve the private gateway information and get the value of `customerIp`:

<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\{serviceName\}/datacenter/\{datacenterId\}/privateGateway"} />


<img className="thumbnail" alt="NTP private gateway - API call" src="/images/hosted-private-cloud/powered-by-vmware/private-gateway-ntp/apiGet.png" loading="lazy" />

#### Install chrony

On the relevant VM, run the following command:

```shell
apt-get install chrony
```

#### Configure chrony

Edit the `/etc/chrony.conf` file by adding the private gateway server IP address and removing the default configuration.

<img className="thumbnail" alt="NTP private gateway - Configuration" src="/images/hosted-private-cloud/powered-by-vmware/private-gateway-ntp/configFile.png" loading="lazy" />

#### Restart chrony

Restart the chrony service:

```shell
systemctl restart chrony
```

#### Check the client

Verify that the VM is correctly connecting to the server:

```shell
chronyc sources
```

<img className="thumbnail" alt="NTP private gateway - Server Check" src="/images/hosted-private-cloud/powered-by-vmware/private-gateway-ntp/ntpServer.png" loading="lazy" />

Verify that the synchronization is working:

```shell
chronyc tracking
```

<img className="thumbnail" alt="NTP private gateway - Synchronization check" src="/images/hosted-private-cloud/powered-by-vmware/private-gateway-ntp/ntpSynchro.png" loading="lazy" />
