## Objetivo

Um bloco IP pode servir para tornar os seus serviços acessíveis na Internet. 

**Este manual explica como encomendar, adicionar e migrar um bloco IP associado ao seu Hosted Private Cloud.**

## Requisitos

- Ter contacto com o administrador da infraestrutura [Hosted Private Cloud](https://www.ovhcloud.com/pt/enterprise/products/hosted-private-cloud/), para receber dados de acesso.
- Ter um identificador de utilizador ativo (criado na <ManagerLink console to="/">consola OVHcloud</ManagerLink>).

[[cpnav:network-public-ip-console]]

## Instruções

### Encomendar um bloco IP

Para encomendar um bloco IP adicional para o seu **Hosted Private Cloud**, abra o seu serviço na consola OVHcloud (**Private Cloud** › **Managed VMware vSphere** e, a seguir, o seu serviço). No separador **Painel de controlo**, secção **Opções**, abra o menu ⋮ da linha **Número de blocos de IP** e clique em <code className="action">Encomendar blocos de IP</code>. A mesma página de encomenda também está acessível a partir de **Rede** › **Endereços IP**: clique em <code className="action">Encomendar um IP</code> e, a seguir, em <code className="action">Encomendar uma Additional IP</code>.

Na página **Encomendar um IP**, preencha as seguintes secções para criar o seu bloco IP:

- **Selecionar o tipo de endereço IP**: escolha **IPv4**.
- **Selecione o serviço ao qual atribuir o IP adicional**: selecione o seu serviço **Hosted Private Cloud**. A região é então determinada automaticamente a partir do serviço selecionado.
- **Selecionar uma oferta**: escolha o tamanho do bloco IP (de /28 a /24).

:::info
Esta tabela recapitula o número de IP presentes num bloco e o número de IP utilizáveis.

:::


|Tamanho do bloco|IP no bloco|IP utilizáveis na OVHcloud|
|:---:|:---:|:---:|
|28|16|11|
|27|32|27|
|26|64|59|
|25|128|123|
|24|256|251|

:::info
Não hesite em consultar o nosso manual sobre o [plugin OVHcloud Network](/guides/hosted-private-cloud/powered-by-vmware/plugin-ovh-network) para saber quais são os IP reservados do seu bloco, assim como a sua utilização.

:::

- **Selecionar uma geolocalização**: escolha o país do bloco IP, importante em certos casos para o referenciamento dos seus serviços (um site português terá um melhor SEO em Portugal se o IP também for português).

O nome e a descrição da rede visíveis no whois do bloco IP não são pedidos no momento da encomenda: pode modificar o nome da rede a partir da página **Endereços IP** depois de o bloco ser entregue.

:::tip
Antes da entrega, terá de pagar as taxas de ativação do bloco IP.

:::

Verifique o **Resumo** e clique em <code className="action">Encomendar</code>. A nota de encomenda do seu bloco IP abre-se num novo separador. Se esta estiver correta, só precisará de a pagar através dos métodos de pagamento disponíveis para que o seu bloco seja entregue.

### Migrar um bloco IP entre dois Hosted Private Cloud

<iframe className="video" width="560" height="315" src="https://www.youtube-nocookie.com/embed/Gemao3Fd7rI" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen={true}></iframe>

A migração de um bloco IP requer a deslocação manual dos blocos através da APIv6 OVHcloud.

Utilize a seguinte chamada API:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/move"} />

Os campos devem ser preenchidos da seguinte forma:

- ip: bloco IP com /mask
- nexthop “newPrimaryIp” (sensível a maiúsculas/minúsculas)
- to: Hosted Private Cloud de destino sob a forma pcc-XXX-XXX-XXX-XXX

O resultado terá este formato:

```json
{
  "function": "genericMoveFloatingIp",
  "status": "todo",
  "taskId": 178970672
}
```

Se tiver de desassociar o bloco IP mais tarde, pode utilizar esta chamada API para mover o IP no “IP parking”:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/park"} />


:::warning
Esta chamada corta a rede nas VM que utilizam os IP em questão.

:::


Também pode mover o bloco a partir da consola OVHcloud: no separador **Painel de controlo** do seu serviço, secção **Opções**, abra o menu ⋮ da linha **Número de blocos de IP** e clique em <code className="action">Associar blocos de IP a outro serviço</code>.

Poderá acompanhar a transferência do bloco IP na secção **Managed VMware vSphere**. Clique no seu serviço Hosted Private Cloud e, depois, no separador <code className="action">Operações</code>.

A referência da operação é `removeIpRipeBlock`.

O IP aparecerá depois na lista **Endereços IP** (**Rede** › **Endereços IP**) com o tipo **IP Parking**.
