## Objetivo

**Neste guia, explicamos como criar uma função IAM no Hosted Private Cloud - VMware on OVHcloud**.

## Requisitos

- Dispor de uma [conta OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation)
- Dispor de um ou vários produtos Hosted Private Cloud - VMware on OVHcloud associados a esta conta (Hosted Private Cloud powered by VMware, VMware Service Pack).
- Ter ativado o IAM para o seu serviço Hosted Private Cloud - VMware on OVHcloud. Siga as etapas do guia [IAM para VMware on OVHcloud - Como ativar o IAM](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-activation).

[[cpnav:privatecloud-vmware-vsphere-console]]

## Instruções

Por predefinição, dispõe de 2 funções IAM do vSphere. A criação de uma função adicional é, portanto, opcional.

Explicamos a seguir como criar uma função adicional.

### Criar uma função IAM a partir da consola OVHcloud

Selecione a sua infraestrutura e aceda ao separador <code className="action">Utilizadores</code>.

Clique em <code className="action">Criar uma função IAM</code>.

<img className="thumbnail" alt="Separador Utilizadores de um serviço Managed VMware vSphere com o botão Criar uma função IAM" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role/console/iam_role_8.png" loading="lazy" />

Na janela **Criar uma nova função IAM da OVHcloud** que se abre, introduza o nome da sua função no campo **Nome da função** e clique em <code className="action">Confirmar</code>.

:::info
As funções IAM recebem automaticamente o prefixo `iam-`.

:::

<img className="thumbnail" alt="Janela Criar uma nova função IAM da OVHcloud, prefixo iam- no campo Nome da função" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role/console/iam_role_9.png" loading="lazy" />

Pode depois modificar as permissões do grupo da mesma forma que com um utilizador local do vSphere: clique no botão <code className="action">⋮</code> na coluna **Ações** da linha da sua função e selecione <code className="action">Ver/Editar as permissões por DC</code>.

#### Criar uma função IAM através da API OVHcloud

:::tip
Consulte o guia [Primeiros passos com as API OVHcloud](/guides/manage-and-operate/api/first-steps) para se familiarizar com a utilização das APIv6 OVHcloud.

:::



Execute a seguinte chamada API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/addRole"} />


:::warning
Certifique-se de que substitui `serviceName` pela referência do seu serviço Hosted Private Cloud, no formato `pcc-XXX-XXX-XXX-XXX`.

:::
