## Objetivo

**Este guia explica como ativar o IAM com o Hosted Private Cloud - VMware on OVHcloud a partir da consola OVHcloud ou com a API OVHcloud**.

## Requisitos

- Dispor de uma [conta OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation)
- Dispor de um ou vários produtos Hosted Private Cloud - VMware on OVHcloud associados a esta conta (Hosted Private Cloud powered by VMware, VMware Service Pack).

[[cpnav:privatecloud-vmware-vsphere-console]]

## Instruções

### Ativar o IAM

:::info
Esta operação pode demorar até 30 minutos.

:::


### A partir da consola OVHcloud

Selecione a sua infraestrutura e aceda ao separador <code className="action">Utilizadores</code>.

Na secção **OVHcloud IAM**, na parte inferior do separador, clique em <code className="action">Ativar OVHcloud IAM</code>.

<img className="thumbnail" alt="Secção OVHcloud IAM com o estado Desativado e a ligação Ativar OVHcloud IAM" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_2.png" loading="lazy" />

:::warning
Apenas o produto vSphere está integrado no OVHcloud IAM. Uma infraestrutura com opções de segurança reforçada ou com um serviço certificado (HDS, PCI-DSS ou SNC) não pode atualmente utilizar o OVHcloud IAM. Se ativar posteriormente uma destas opções ou um destes serviços certificados, terá de desativar o OVHcloud IAM.
:::

Na janela **Ativar o IAM da OVHcloud** que se abre, clique em <code className="action">Confirmar</code>.

:::tip
Uma vez ativado o IAM, o seu estado será `Ativado` e apresentado a verde.

:::

<img className="thumbnail" alt="Separador Utilizadores com a secção OVHcloud IAM no estado Ativado" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_3.png" loading="lazy" />

### Através da API OVHcloud

:::tip
Consulte o guia [Primeiros passos com as API OVHcloud](/guides/manage-and-operate/api/first-steps) para se familiarizar com a utilização das APIv6 OVHcloud.

:::


:::warning
Certifique-se de que substitui `serviceName` pela referência do seu serviço Hosted Private Cloud, no formato `pcc-XXX-XXX-XXX-XXX`.

:::


Para ativar a opção IAM, execute a seguinte chamada API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/enable"} />


#### Verificar se o IAM está ativado

Para verificar a ativação do IAM, execute a seguinte chamada API:

<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\{serviceName\}/iam"} />

Resposta da API:

```shell
{
  "state": "enabled",
  "identityProviderId": 275
}
```

### Desativar o IAM

Pode desativar o OVHcloud IAM no seu Hosted Private Cloud.

#### A partir da consola OVHcloud

Selecione a sua infraestrutura e aceda ao separador <code className="action">Utilizadores</code>.

Na secção **OVHcloud IAM**, na parte inferior do separador, clique em <code className="action">Desativar OVHcloud IAM</code>. Na janela **Desativar o IAM da OVHcloud** que se abre, clique em <code className="action">Confirmar</code>.

#### Através da API OVHcloud

Para desativar a opção IAM, execute a seguinte chamada API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/disable"} />
