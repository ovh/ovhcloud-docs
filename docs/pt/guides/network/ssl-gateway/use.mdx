## Objetivo

Depois de encomendar o seu SSL Gateway, a configuração é feita na consola OVHcloud.

**Este guia explica como associar os seus domínios ao seu SSL Gateway, definir os servidores para os quais o tráfego é encaminhado, configurar os parâmetros de rede e acompanhar as operações e as estatísticas.**

## Requisitos

- Dispor de um [SSL Gateway](/guides/network/ssl-gateway/order) com a oferta Free ou Advanced
- Ter acesso à zona DNS de cada domínio que pretende servir através do seu SSL Gateway

## Introdução

[SSL Gateway](/links/web/ssl-gateway) é um front-end HTTPS gerido para o seu site. O serviço coloca-se à frente dos seus próprios servidores, designados servidores backend: detém o certificado SSL, gere a ligação TLS com os browsers dos seus visitantes e protege o tráfego contra ataques DDoS e, depois, encaminha os pedidos para os seus servidores.

A oferta do seu SSL Gateway determina o que pode configurar:

| Funcionalidade | Free | Advanced |
|---|---|---|
| Domínios | 3: 1 domínio, o seu `www` e 1 subdomínio | Até 1000 domínios e subdomínios, incluindo domínios de 4 níveis ou mais |
| Servidores backend | 1 | Até 3, com o tráfego repartido entre eles |
| Endereços IP dedicados | Não | Sim |
| Perfil de cifragem | Intermediate, fixo | Modern ou Intermediate |
| HSTS (HTTP Strict Transport Security) | Não | Sim |
| Origens autorizadas | Não: todas as origens são autorizadas | Sim |
| Reverse DNS modificável | Não | Sim |
| Separador <code className="action">Estatísticas</code> | Não | Sim |
| Certificado EV (Extended Validation) | Não | Opcional (Sectigo) |

## Instruções

### Abrir o seu SSL Gateway

A lista apresenta os seus SSL Gateway com as colunas **Nome / ID**, **Região**, **Oferta**, **IPv4** e **Estado**. Clique no nome do SSL Gateway que pretende configurar.

<img className="thumbnail" alt="Lista dos SSL Gateway com as colunas Nome / ID, Região, Oferta, IPv4 e Estado" src="/images/network/ssl-gateway/use-ssl-gateway/console/ssl-gateway-list.png" loading="lazy" />

A página do seu SSL Gateway abre-se no separador <code className="action">Visão geral</code>, que apresenta quatro cartões:

- **Informações gerais**: o ID, a região, o reverse DNS e os endereços IPv4 e IPv6 do seu SSL Gateway, bem como os intervalos **IPv4 de saída** utilizados para aceder aos seus servidores;
- **Assinatura**: a oferta, a data de criação, o modo de renovação e a data de renovação;
- **Configuração de rede**: os parâmetros TLS e de acesso do seu SSL Gateway;
- **Backend**: os servidores para os quais o tráfego é encaminhado.

Os outros separadores são <code className="action">Domínios</code>, <code className="action">Estatísticas</code> (apenas na oferta Advanced) e <code className="action">Operações</code>.

<img className="thumbnail" alt="Separador Visão geral de um SSL Gateway Advanced com os cartões Informações gerais, Assinatura, Configuração de rede e Backend" src="/images/network/ssl-gateway/use-ssl-gateway/console/overview-advanced.png" loading="lazy" />

### Adicionar e eliminar domínios

Para que um domínio seja validado, os seus registos DNS devem apontar para o seu SSL Gateway: um registo A para o endereço IPv4 do SSL Gateway e, se este tiver um endereço IPv6, um registo AAAA para esse endereço. Os dois endereços são apresentados no cartão **Informações gerais**. Se a zona DNS do domínio for gerida pela OVHcloud, consulte os nossos guias sobre os [registos A](/guides/web-cloud/domains/dns-zone-a-record-creation) e os [registos AAAA](/guides/web-cloud/domains/dns-zone-aaaa-record-creation).

Para associar um domínio, abra o separador <code className="action">Domínios</code> e clique em <code className="action">Adicionar um domínio</code>.

<img className="thumbnail" alt="Separador Domínios de um SSL Gateway com o botão Adicionar um domínio e o ícone de eliminação na linha de um domínio" src="/images/network/ssl-gateway/use-ssl-gateway/console/domains-tab.png" loading="lazy" />

No campo **Domínio**, introduza o nome de host que pretende servir em HTTPS, por exemplo `shop.example.com`, e clique em <code className="action">Adicionar o domínio</code>.

<img className="thumbnail" alt="Janela Adicionar um domínio com o campo Domínio" src="/images/network/ssl-gateway/use-ssl-gateway/console/add-domain-dialog.png" loading="lazy" />

A validação DNS pode demorar até 72 horas. Enquanto não estiver concluída, o estado do domínio indica **Creating**.

A oferta Free inclui 3 domínios: 1 domínio, o seu `www` e 1 subdomínio. Depois de associar 3 domínios, o botão <code className="action">Adicionar um domínio</code> fica desativado.

Para eliminar um domínio, clique no ícone de eliminação na respetiva linha e, em seguida, em <code className="action">Eliminar</code>. O domínio é dissociado do seu SSL Gateway e deixa de ser servido em HTTPS.

### Configurar os servidores backend

O cartão **Backend** do separador <code className="action">Visão geral</code> indica para onde o seu SSL Gateway encaminha o tráfego que recebe: o endereço IP e a porta dos seus servidores.

**Oferta Free**: o tráfego é encaminhado para 1 servidor. Clique em <code className="action">Modificar o backend</code>, introduza o endereço IP do servidor no campo **Endereço IP** e, no campo **Porta**, a porta em que o servidor recebe o tráfego do seu SSL Gateway. Em seguida, clique em <code className="action">Guardar</code>.

<img className="thumbnail" alt="Painel Modificar o backend de um SSL Gateway Free com os campos Endereço IP e Porta" src="/images/network/ssl-gateway/use-ssl-gateway/console/edit-backend-drawer.png" loading="lazy" />

**Oferta Advanced**: o tráfego é repartido por 3 servidores no máximo. Clique em <code className="action">Adicionar um servidor</code>, preencha os campos **Endereço IP** e **Porta** e clique em <code className="action">Adicionar</code>. Para modificar ou eliminar um servidor, utilize o menu da respetiva linha.

<img className="thumbnail" alt="Painel Adicionar um servidor de um SSL Gateway Advanced com os campos Endereço IP e Porta" src="/images/network/ssl-gateway/use-ssl-gateway/console/add-server-drawer.png" loading="lazy" />

O endereço IP deve ser o endereço IPv4 público do seu servidor: o seu SSL Gateway não consegue alcançar um endereço privado.

Cada alteração é executada como uma operação e aplicada dentro de instantes. Pode acompanhá-la no separador <code className="action">Operações</code>.

O seu SSL Gateway acede aos seus servidores a partir dos intervalos de IP indicados em **IPv4 de saída**, no cartão **Informações gerais**. Autorize estes intervalos nas firewalls dos seus servidores.

### Configurar os parâmetros de rede

No cartão **Configuração de rede**, clique em <code className="action">Modificar a configuração de rede</code>. Pode definir:

- **Perfil de cifragem**: os conjuntos de cifras que o seu SSL Gateway propõe aos browsers. <code className="action">Modern</code> mantém apenas os mais robustos, para clientes recentes; <code className="action">Intermediate</code> suporta também os mais antigos.
- <code className="action">HTTPS para o backend</code>: cifra também o tráfego entre o seu SSL Gateway e os seus servidores, e não apenas entre os browsers e o seu SSL Gateway.
- <code className="action">Redirecionamento HTTPS</code>: redireciona cada pedido HTTP para HTTPS.
- <code className="action">HSTS</code>: indica aos browsers que, nas visitas seguintes, só devem aceder aos seus domínios em HTTPS.
- **Origens autorizadas**: os endereços ou blocos IPv4 ou IPv6 autorizados a aceder ao seu SSL Gateway. Introduza um endereço ou um bloco, por exemplo `203.0.113.0/24`, e clique em <code className="action">Adicionar</code>, uma vez por origem. Para retirar uma origem, clique na cruz ao lado dela. Se nenhuma origem for indicada, todas as origens podem aceder ao seu SSL Gateway.

Em seguida, clique em <code className="action">Guardar</code>.

<img className="thumbnail" alt="Painel Modificar a configuração de rede com a lista Perfil de cifragem, as caixas HTTPS para o backend, Redirecionamento HTTPS e HSTS, e o campo Origens autorizadas" src="/images/network/ssl-gateway/use-ssl-gateway/console/network-configuration-drawer.png" loading="lazy" />

Com a oferta Free, o perfil de cifragem mantém-se em **Intermediate**, e o HSTS e as origens autorizadas não estão disponíveis. Se o seu SSL Gateway Free ainda tiver parâmetros deste tipo, ao guardar uma alteração, estes são repostos com os valores da oferta Free: Intermediate, HSTS desativado, sem restrição de origens.

### Modificar o reverse DNS

Com a oferta Advanced, pode definir o reverse DNS do seu SSL Gateway: no cartão **Informações gerais**, clique no ícone em forma de lápis ao lado de **Reverse DNS**, introduza o nome de host no campo **Reverse DNS** e clique em <code className="action">Guardar</code>. Com a oferta Free, o reverse DNS não é modificável.

<img className="thumbnail" alt="Painel Modificar o reverse DNS com o campo Reverse DNS" src="/images/network/ssl-gateway/use-ssl-gateway/console/reverse-dns-drawer.png" loading="lazy" />

### Acompanhar as operações

Cada alteração do seu SSL Gateway, como a adição ou a eliminação de um domínio ou de um servidor, ou um upgrade para Advanced, é executada como uma operação. O separador <code className="action">Operações</code> apresenta-as com as colunas **ID**, **Ação**, **Estado**, **Progresso** e **Data de criação**. Para ver os detalhes de uma operação, clique em <code className="action">Ver detalhes</code> na respetiva linha.

### Consultar as estatísticas

Com a oferta Advanced, o separador <code className="action">Estatísticas</code> apresenta o tráfego do seu SSL Gateway. Em **Período**, escolha uma duração, de <code className="action">1 h</code> a <code className="action">1 m</code> (um mês). O separador apresenta a média e o pico do número de pedidos e de ligações por segundo no período escolhido. Por cima do gráfico, escolha <code className="action">Pedidos/s</code> ou <code className="action">Ligações/s</code>.

<img className="thumbnail" alt="Separador Estatísticas de um SSL Gateway Advanced com o seletor de período, os valores médio e de pico, e o gráfico dos pedidos" src="/images/network/ssl-gateway/use-ssl-gateway/console/statistics-tab.png" loading="lazy" />

### Gerir a oferta e a assinatura

O cartão **Assinatura** apresenta a oferta, a data de criação, o modo de renovação e a data de renovação. Clique em <code className="action">Gerir a minha subscrição</code> para alterar a renovação. Para rescindir o serviço, clique em <code className="action">Rescindir</code> e, novamente, em <code className="action">Rescindir</code> na janela de confirmação: receberá depois um e-mail para confirmar a rescisão.

<Region zones={['eu']}>

Quando for possível fazer o upgrade da oferta do seu SSL Gateway, o cartão **Assinatura** apresenta também <code className="action">Fazer upgrade</code>.

<img className="thumbnail" alt="Separador Visão geral de um SSL Gateway Free com Fazer upgrade no cartão Assinatura" src="/images/network/ssl-gateway/use-ssl-gateway/console/overview-free.png" loading="lazy" />

Clique em <code className="action">Fazer upgrade</code>. A janela **Passar para Advanced** lista o que a oferta Advanced acrescenta (até 1000 domínios e subdomínios, domínios de quatro níveis ou mais, um endereço IP dedicado, balanceamento de carga entre até 3 servidores backend), o montante a pagar hoje, proporcionalmente, e o montante cobrado depois todos os meses.

A caixa <code className="action">Pagar agora com o meu meio de pagamento predefinido</code> está marcada por predefinição. Para pagar na página de encomenda, que se abre num novo separador, desmarque-a. Em seguida, clique em <code className="action">Fazer upgrade</code>.

<img className="thumbnail" alt="Janela Passar para Advanced com os montantes, o aviso sobre o endereço IP e a caixa Pagar agora com o meu meio de pagamento predefinido" src="/images/network/ssl-gateway/use-ssl-gateway/console/upgrade-dialog.png" loading="lazy" />

:::warning
A oferta Advanced funciona com endereços IP dedicados. Quando o upgrade terminar, o seu SSL Gateway recebe um novo endereço IPv4 e IPv6, e os anteriores deixam imediatamente de servir o tráfego. Aponte os seus domínios para os novos endereços, enviados por e-mail e indicados no cartão **Informações gerais**: até lá, o seu site não está acessível através do seu SSL Gateway.

:::

O seu SSL Gateway mantém o ID e a configuração. O upgrade é executado como uma operação que pode acompanhar no separador <code className="action">Operações</code>.

</Region>

### Renovar o certificado SSL

O certificado SSL do seu SSL Gateway é um certificado DV (Domain Validation) emitido pela Let's Encrypt e renovado automaticamente. Com a oferta Advanced, está disponível como opção um certificado SSL Sectigo EV.

Para renovar o certificado a pedido, utilize a seguinte chamada API:

<Api version="v1" section="/sslGateway" method="POST" route={"/sslGateway/\{serviceName\}/renewCertificate"} />
