## Objetivo

Pretende criar um site para a sua empresa ou um blogue pessoal? Precisa de uma loja online para vender os seus produtos? Este guia dedicado aos primeiros passos com o alojamento web OVHcloud indicar-lhe-á as etapas chave para o configurar. Além disso, também encontrará explicações para criar endereços de e-mail profissionais associados ao seu domínio. Permite-lhe colocar online o seu projeto de forma fácil e rápida, a fim de comunicar com o seu público de forma eficaz.

:::info
- Deseja migrar um site já existente para fornecedor de alojamento? Consulte diretamente o nosso guia dedicado: [Migrar o seu website e os seus serviços associados para a OVHcloud](/guides/web-cloud/web-hosting/hosting-migrating-to-ovh).
<Region zones={['eu']}>
- Deseja apenas uma página inicial simples para a sua atividade profissional? Consulte o nosso guia dedicado: [Alojamento web - Ativar alojamento gratuito](/guides/web-cloud/web-hosting/activate-start10m).
</Region>

:::

## Requisitos

<Region zones={['eu']}>
- Ter um serviço de [alojamento web OVHcloud](/links/web/hosting) com, pelo menos, uma base de dados disponível (exceto a oferta de alojamento gratuita).
</Region>
<Region zones={['ca','apac']}>
- Ter um serviço de [alojamento web OVHcloud](/links/web/hosting) com, pelo menos, uma base de dados disponível.
</Region>
- Ter recebido o e-mail com a confirmação da instalação do alojamento web.
- Dispor de um [nome de domínio](/links/web/domains) e de uma zona DNS associada na OVHcloud.
- Todos os serviços (Alojamento web, Nome de domínio, zona DNS) devem estar acessíveis a partir de uma única conta OVHcloud.

## Instruções

### 1 - Atribuir o seu nome de domínio a um site no seu alojamento web <a name="part-1"></a>

:::tip
Se subscreveu o seu nome de domínio e o seu alojamento web na mesma encomenda, estes dois serviços já estão associados. Passe diretamente para [Parte 2](#part-2) deste manual.

:::

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Os meus sites</code>. Na tabela, clique no botão <code className="action">⋮</code> da coluna **Ações**, à direita do site criado automaticamente aquando da criação do seu alojamento web e, a seguir, no grupo **Nomes de domínio**, em <code className="action">Adicionar um nome de domínio</code>.

    <img className="thumbnail" alt="Menu Ações de um site e entrada Adicionar um nome de domínio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Abre-se a página **Adicionar um domínio**. Preencha-a de cima para baixo e valide.
  </Tab>
</Tabs>

### 2 - Instalar um "módulo 1 clique" para o seu website <a name="part-2"></a>

Nos seus alojamentos web, a OVHcloud propõe instalar gratuitamente os CMS WordPress, Joomla!, PrestaShop e Drupal graças à opção "módulo 1 clique".

Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Módulos</code>. As três secções do topo indicam o número de módulos **Instalados**, a versão de PHP do seu alojamento web com a respetiva compatibilidade (secção **PHP**) e o número de módulos **disponíveis**.

    <img className="thumbnail" alt="Separador Módulos e as suas três secções de resumo" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/tab.png" loading="lazy" />

    :::info
    Um módulo só pode ser instalado se a versão PHP do seu alojamento web for compatível. Quando não for, a secção apresenta **Incompatível** e nenhum módulo é proposto. Consulte a secção "[As versões de PHP](/guides/web-cloud/web-hosting/configure-your-web-hosting#php-versions)" do nosso guia sobre a configuração do seu alojamento web para a atualizar.
    :::
  </Tab>
  <Tab label="Etapa 3">
    Clique no botão <code className="action">Adicionar um módulo</code>.
  </Tab>
  <Tab label="Etapa 4">
    Abre-se um painel à direita. Deixe o modo <code className="action">Simples</code> selecionado, escolha o CMS a instalar em **Escolher o módulo** e, a seguir, o nome de domínio em **Domínio**, **sem os "www"** à frente (exemplo: `domain.tld` e não `www.domain.tld`). Por fim, clique em <code className="action">Instalar</code>.

    <img className="thumbnail" alt="Painel Instalar um módulo, escolha do CMS e do domínio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/install-module-drawer.png" loading="lazy" />
  </Tab>
</Tabs>

### 3 - Ativar os endereços de e-mail incluídos com o seu alojamento web <a name="part-3"></a>

:::tip
Se subscreveu o seu domínio e o seu alojamento web numa única encomenda, os endereços de e-mail incluídos com o alojamento web já estão associados ao seu domínio. Passe diretamente para [Secção 4](#part-4) deste manual.

:::

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    No separador <code className="action">Visão geral</code>, localize a secção **Serviços gratuitos**. A menção **Endereços de email** indica o número de endereços incluídos na sua oferta e o estado do serviço. Enquanto este estiver **Inativo**, clique em <code className="action">Ativar o meu plano de email</code> logo abaixo.

    <img className="thumbnail" alt="Secção Serviços gratuitos e ligação Ativar o meu plano de email" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/complimentary-services.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    O processo de ativação tem duas etapas. Em **Endereços de email**, selecione o nome de domínio em causa. Em **Ativação**, aceite os contratos e valide: abre-se a sua nota de encomenda OVHcloud, uma vez que esta opção está incluída gratuitamente na sua oferta de alojamento web.
  </Tab>
</Tabs>

<details>

<summary>Clique aqui para mais informações.</summary>

Consulte o nosso guia detalhado "[Alojamento web - Ativar os endereços de e-mail incluídos](/guides/web-cloud/web-hosting/activate-email-hosting)".

</details>

### 4 - Criar um endereço de e-mail personalizado com o seu nome de domínio <a name="part-4"></a>

Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/email">E-mails</ManagerLink>. A tabela lista todos os seus serviços de e-mail; localize a linha da sua oferta MX Plan e clique nela. A coluna **Tipo de oferta** indica o nome da oferta tal como devolvido pelo sistema, que nem sempre menciona `MX Plan`.

    <img className="thumbnail" alt="Página E-mails e coluna Tipo de oferta dos serviços de e-mail" src="/images/assets/screens/console/product-selection/web-cloud/email-and-collaborative-solutions/emails-listing.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Conta de e-mail</code>. A secção **Cota de contas de e-mail** indica o número de endereços já configurados sobre o total incluído na sua oferta.

    <img className="thumbnail" alt="Separador Conta de e-mail de um serviço MX Plan e respetivas contas" src="/images/assets/screens/console/product-selection/web-cloud/email-and-collaborative-solutions/mx-plan/email-account-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Clique no botão <code className="action">Adicionar a conta</code>.
  </Tab>
  <Tab label="Etapa 4">
    Abre-se um painel à direita. Indique o **Nome da conta**, que precede o `@` do seu nome de domínio, e a respetiva **Palavra-passe**. A **Descrição** é facultativa e o **Tamanho da conta** é o incluído na sua oferta. Por fim, clique em <code className="action">Adicionar</code>.

    <img className="thumbnail" alt="Painel Adicionar a conta e os respetivos campos de criação" src="/images/assets/screens/console/product-selection/web-cloud/email-and-collaborative-solutions/mx-plan/add-account-drawer.png" loading="lazy" />
  </Tab>
</Tabs>

Repita esta operação para cada endereço de e-mail que deseja criar (no limite da sua oferta de alojamento web).

<details>

<summary>Clique aqui para mais informações.</summary>

Consulte o nosso guia detalhado "[Criar um endereço de e-mail](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-creation)".

</details>

### 5 - Opções adicionais disponíveis com o seu alojamento web <a name="part-5"></a>

O seu alojamento web não está limitado à instalação de um "módulo 1 clique". Pode alojar websites criados por si ou por um programador web (blogue, CMS, loja online, etc.). Se pretender saber mais sobre as possibilidades do seu alojamento web, não hesite em consultar o nosso guia mais pormenorizado "[Como criar um website - Realizar o seu projeto em 5 etapas](/guides/web-cloud/web-hosting/website-project)".
