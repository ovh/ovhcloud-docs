## Objetivo

A utilização de software FTP durante a ligação ao seu [alojamento Web Cloud](/links/web/hosting) pode causar várias anomalias. Este guia permitir-lhe-á resolver os problemas mais comuns.

**Descubra como corrigir os erros relacionados com o software FTP.**

[[fragment:support-scope]]

## Requisitos

- Ter um [serviço de alojamento Web Cloud](/links/web/hosting).

[[cpnav:web-hosting]]

## Instruções

### "Este servidor não suporta FTP em TLS" (FileZilla)

<img className="thumbnail" alt="doesnt-support-ftp-on-tls" src="/images/assets/screens/other/web-tools/filezilla/doesnt-support-ftp-on-tls.png" loading="lazy" />

Esta mensagem no software [FileZilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide) indica que não ativou a opção SFTP ou SSH a partir da <ManagerLink to="/beta/#/">consola OVHcloud</ManagerLink>. Assim, as informações trocadas entre o seu servidor de alojamento OVHcloud e o seu computador não serão encriptadas.

Se os dados que deseja trocar por esta via não são confidenciais, clique em <code className="action">OK</code>.

Caso contrário, aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> da consola OVHcloud e selecione o alojamento em causa. No separador <code className="action">FTP-SSH</code>, secção **Utilizadores FTP e SSH**, modifique o utilizador FTP em causa para lhe ativar o protocolo SFTP.

O procedimento detalhado, idêntico qualquer que seja a sua oferta de alojamento, está descrito no nosso guia "[Alojamento web - Como ativar o acesso SFTP](/guides/web-cloud/web-hosting/enable-sftp)". Aguarde depois alguns minutos.

:::info
Para qualquer outra mensagem de erro, consulte a secção `Diagnóstico` dos nossos guias de [Hosting](/guides/web-cloud/web-hosting/landing-page-web-hosting).

:::

### Transferi os meus ficheiros com um software FTP, mas o meu site não aparece.

Em primeiro lugar, verifique se os ficheiros e as pastas do seu site estão presentes na [pasta raiz](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online#23-carregar-os-ficheiros-para-o-espaço-de-armazenamento) do seu alojamento.

Se efetuou uma alteração no seu [servidores DNS](/guides/web-cloud/domains/dns-server-edit) ou [zona DNS](/guides/web-cloud/domains/dns-zone-edit) há menos de 48 horas, aguarde e reinicie regularmente os seus dispositivos para limpar a cache.

### As minhas credenciais FTP não funcionam.

Se não conseguir autenticar-se, altere a sua palavra-passe FTP de acordo com as instruções deste [guia](/guides/web-cloud/web-hosting/ftp-change-password).

### Não consigo transferir os meus ficheiros para o servidor FTP.

Verifique que o seu software FTP está ligado ao "Modo Passivo" (Modo de configuração de um servidor FTP no qual o servidor determina a porta de ligação).

Por exemplo, para o [Filezilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide), clique em <code className="action">Editar</code> e, a seguir, <code className="action">Configurações</code>, <code className="action">Ligação</code>, <code className="action">FTP</code> e selecione o <code className="action">Passivo (recomendado)</code>.

Limite igualmente o tamanho das suas transferências de dados (não poderá enviar mais de **5000 ficheiros e pastas** para os servidores partilhados OVHcloud numa única transferência). Se necessário, realize as suas importações várias vezes com base em pastas comprimidas.

Se dispõe de uma fórmula **Pro**, **Performance**, **Agency**, **Agency Plus** ou **Agency Max**, utilize de preferência o [protocolo SSH](/guides/web-cloud/web-hosting/ssh-on-webhosting) para realizar as suas importações de ficheiros no espaço de armazenamento de ficheiros do seu alojamento.

### Não consigo eliminar o link simbólico "index.html" no meu espaço FTP

Esta ligação é instalada de forma padrão nos alojamentos partilhados da OVHcloud. Ele dá a seguinte apresentação:

<img className="thumbnail" alt="site-under-construction" src="/images/assets/screens/other/browsers/errors/site-under-construction.png" loading="lazy" />

Se não utilizou a funcionalidade "[Módulo 1 clique](/guides/web-cloud/web-hosting/cms-install-1-click-modules)" para criar o seu site, deverá ligar-se [ao espaço de armazenamento FTP](/guides/web-cloud/web-hosting/ftp-connection) do seu alojamento web de forma a eliminar manualmente a página "Site em construção".
