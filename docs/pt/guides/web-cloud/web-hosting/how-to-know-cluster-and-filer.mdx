## Objetivo

Os alojamentos web funcionam numa infraestrutura partilhada chamada *cluster*. A OVHcloud dispõe de vários clusters nos quais estão repartidos vários alojamentos web.
Cada cluster está também dividido virtualmente em vários segmentos, designados *filers*, por razões de eficiência e segurança. Os filers contêm vários alojamentos web.
Durante a utilização do alojamento web, poderá ser necessário conhecer o número do cluster e/ou do filer onde se situa o alojamento web.

**Saiba como encontrar o número de cluster e o número do filer na sua localização.**

## Requisitos

- Ter um serviço de [alojamento web OVHcloud](/links/web/hosting).

[[cpnav:web-hosting]]

## Instruções

Clique nos separadores abaixo para visualizar cada uma das **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    No separador <code className="action">Visão geral</code>, localize a secção **Informações gerais**. Esta indica sucessivamente a **Região** onde se encontra o seu alojamento web, o seu **Cluster** e o seu **Filer**.

    O cluster é apresentado sob a forma `clusterXXX`, em que os três algarismos identificam o cluster. O filer, por sua vez, é um número de comprimento variável.

    <img className="thumbnail" alt="Secção Informações gerais e campos Região, Cluster e Filer" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/region-cluster-filer.png" loading="lazy" />
  </Tab>
</Tabs>
