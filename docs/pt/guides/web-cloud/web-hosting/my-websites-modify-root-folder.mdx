## Objetivo

Pode alojar vários websites na mesma oferta de alojamento web, mesmo que os nomes de domínio não estejam registados na OVHcloud. Além disso, pode associar um ou vários nomes de domínio ou subdomínios a um mesmo website.

Ao utilizar os seus serviços, poderá necessitar de:

- Substituir a totalidade do conteúdo de um website existente, sem o eliminar do seu alojamento web. Tudo isto sem interrupção de acesso e com total transparência para os visitantes do seu website.
- Instalar um [módulo em 1 clique](/guides/web-cloud/web-hosting/cms-install-1-click-modules) ou um [outro CMS](/guides/web-cloud/web-hosting/cms-manual-installation) para substituir o conteúdo de um website existente, sem eliminar o antigo conteúdo do seu alojamento web. Neste caso específico, deverá construir as diferentes páginas do seu novo website através do seu navegador de Internet.
- Reorganizar os nomes das pastas raiz dos seus websites no espaço de armazenamento do seu alojamento web sem cortar o acesso aos seus diferentes websites.

**Saiba como alterar a pasta raiz declarada para um website já existente no seu alojamento web a partir da consola OVHcloud.**

:::info
Se ainda não criou o website em questão no seu alojamento web, consulte **diretamente** [este guia](/guides/web-cloud/web-hosting/multisites-configure-multisite).

A consola permite modificar a pasta raiz de um site, inclusive quando está associado a um repositório Git (neste caso, consulte o nosso guia "[Configurar e utilizar o Git com o seu alojamento web OVHcloud](/guides/web-cloud/web-hosting/git-integration-webhosting)"). Apenas o site que tem o domínio principal do seu alojamento web não a pode alterar: o campo fica então desativado.

:::

## Requisitos

- Dispor de uma oferta de [alojamento web OVHcloud](https://www.ovhcloud.com/pt/web-hosting/uc-multisite/) compatível.
- Dispor de um ou vários [nomes de domínio](https://www.ovhcloud.com/pt/domains/).

## Instruções

:::warning
Este guia apresenta exclusivamente as ações a realizar a partir da <ManagerLink to="/beta/#/">consola OVHcloud</ManagerLink>.

Com exceção do caso em que pretenda instalar um módulo em 1 clique para construir o website progressivamente, deverá previamente:

- Criar a nova pasta raiz no [espaço de armazenamento](/guides/web-cloud/web-hosting/ftp-connection) do seu alojamento web.
- Colocar a totalidade do novo conteúdo do seu website dentro desta nova pasta.
- Se o novo conteúdo do seu website funciona com uma base de dados, deverá igualmente [criar uma base de dados](/guides/web-cloud/web-hosting/sql-create-database) e depois [importar o conteúdo relativo a essa base de dados](/guides/web-cloud/web-hosting/sql-importing-mysql-database).
- Colocar as credenciais de acesso à base de dados no ficheiro que contém as informações de ligação à base de dados. Este ficheiro deve estar já presente na nova pasta raiz.

**Sem estas ações, a apresentação do seu website será interrompida**.

Este guia descreve unicamente o procedimento para modificar, a partir da consola OVHcloud, a pasta raiz inicialmente definida para o seu website. Esta ação é necessária para que o website apresente o conteúdo da nova pasta, em substituição da anterior.

:::

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Os meus sites</code>. Na tabela, clique no botão <code className="action">⋮</code> situado na coluna **Ações**, à direita do site em causa e, a seguir, no grupo **Site**, em <code className="action">Configurar o meu site</code>.

    <img className="thumbnail" alt="Menu Ações de um site" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    O painel **Configurar o meu site** abre-se à direita. No campo **Pasta raiz**, substitua a antiga pasta raiz pela nova.

    <img className="thumbnail" alt="Painel Configurar o meu site, campos Nome do site e Pasta raiz" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/configure-site.png" loading="lazy" />

    :::info
    O painel permite também mudar o nome do seu site, no campo **Nome do site**. Este nome serve apenas para identificar o site na consola OVHcloud e não tem qualquer efeito no seu endereço nem no seu conteúdo. Deixe-o como está se pretender alterar apenas a pasta raiz.
    :::

    Por fim, clique em <code className="action">Confirmar</code>, na parte inferior do painel. Se tiver mudado de pasta, a janela **Editar a pasta raiz** resume a pasta atual, a nova pasta e os domínios associados: clique novamente em <code className="action">Confirmar</code>.
  </Tab>
</Tabs>
