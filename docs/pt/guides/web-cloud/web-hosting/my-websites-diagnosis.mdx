## Objetivo

Pode alojar vários sites web na mesma oferta de alojamento web, mesmo que os nomes de domínio não estejam registados na OVHcloud. Além disso, pode associar um ou vários nomes de domínio ou subdomínios ao mesmo site web.

**Utilize a nossa ferramenta de diagnóstico para verificar que o seu nome de domínio ou subdomínio está bem declarado com o seu site web no seu alojamento web.**

## Requisitos

- Dispor de uma oferta de [alojamento web OVHcloud](https://www.ovhcloud.com/pt/web-hosting/uc-multisite/) compatível.
- Dispor de um ou vários [nomes de domínio](https://www.ovhcloud.com/pt/domains/).
- Poder modificar a configuração dos seus nomes de domínio a partir da [zona DNS](/guides/web-cloud/domains/dns-zone-edit).

## Instruções

### Aceder à ferramenta de diagnóstico

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Os meus sites</code>. A coluna **Diagnóstico** da tabela resume o estado de cada site, sem qualquer manipulação prévia.

    <img className="thumbnail" alt="Coluna Diagnóstico da tabela dos sites" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-column.png" loading="lazy" />

    São possíveis três valores:

    - <code className="action">DNS OK</code>: todos os nomes de domínio do site apontam corretamente para o seu alojamento web.
    - <code className="action">DNS a verificar</code>, seguido do número de nomes de domínio em causa: pelo menos um domínio apresenta um problema de apontamento. Esta menção é clicável.
    - <code className="action">0 domínios</code>: nenhum nome de domínio está associado a este site.
  </Tab>
  <Tab label="Etapa 3">
    Para obter o detalhe, clique na menção <code className="action">DNS a verificar</code>. O painel **Gerir os meus domínios** abre-se à direita, **filtrado apenas pelos domínios com problemas**; o botão <code className="action">Ver todos os domínios</code> apresenta a lista completa.

    Se a coluna indicar <code className="action">DNS OK</code>, a menção não é clicável: abra o painel através do botão <code className="action">⋮</code> da coluna **Ações** e, no grupo **Nomes de domínio**, através de <code className="action">Gerir os meus domínios</code>.

    <img className="thumbnail" alt="Painel Gerir os meus domínios, diagnóstico conforme" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-ok.png" loading="lazy" />

    Cada nome de domínio apresenta uma linha **Diagnóstico** com dois indicadores, **A** e **AAAA**, e um botão <code className="action">Executar o diagnóstico novamente</code>.

    Consulte a parte "[Interpretação das cores da ferramenta de diagnóstico](#interpretation)" deste guia para conhecer o significado destes indicadores.

    :::info
    O nome técnico do seu alojamento web, sob a forma `ftplogin.clusterXXX.hosting.ovh.net`, aparece nesta lista com a menção **Técnico**. Não é diagnosticado: aponta para o seu alojamento web por construção.
    :::
  </Tab>

### Interpretação das cores da ferramenta de diagnóstico <a name="interpretation"></a>

Os indicadores **A** e **AAAA** correspondem aos dois tipos de registo DNS que fazem apontar um nome de domínio para um alojamento web: **A** para o endereço IPv4, **AAAA** para o endereço IPv6. São **independentes um do outro**: um mesmo nome de domínio pode ter um indicador conforme e o outro com problema.

Cada indicador assume uma das três cores seguintes.

<details>
<summary>Indicador verde</summary>

O registo aponta corretamente para o endereço IP do seu alojamento web. A configuração DNS do seu nome de domínio está conforme e nenhuma mensagem acompanha o indicador.

<img className="thumbnail" alt="Indicadores A e AAAA conformes" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-ok.png" loading="lazy" />

</details>

<details>
<summary>Indicador laranja</summary>

O registo aponta para um endereço IP, mas não para o do alojamento web que está a consultar. A mensagem indica o endereço atualmente configurado e o que deve ser utilizado em vez dele:

*O seu domínio `exemple.com` aponta atualmente para o endereço IP `X` de outro alojamento. Para corrigir, atualize o registo A na zona DNS do domínio e substitua-o pelo endereço IP `Y`.*

<img className="thumbnail" alt="Indicador A laranja e indicador AAAA cinzento, com as respetivas mensagens" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/diagnostic-issues.png" loading="lazy" />

Para corrigir o apontamento, siga as etapas descritas no nosso guia "[Editar uma zona DNS da OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".

</details>

<details>
<summary>Indicador cinzento</summary>

Não existe nenhum registo deste tipo na zona DNS do nome de domínio. A mensagem indica o registo a criar e o endereço IP a introduzir:

*Nenhuma configuração válida foi encontrada na zona DNS. Para resolver o problema, adicione um registo AAAA com o endereço IP `Y` na zona DNS do domínio `exemple.com`.*

Para adicionar os registos em falta, siga as etapas descritas no nosso guia "[Editar uma zona DNS da OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".

</details>

:::info
Uma alteração da zona DNS pode demorar até 24 horas a propagar-se. Depois da correção, utilize o botão <code className="action">Executar o diagnóstico novamente</code> do nome de domínio em causa em vez de recarregar a página.
:::
