## Redirecionamento e autenticação com o ficheiro .htaccess

O ficheiro `.htaccess` permite controlar o acesso ao seu site e redirecionar ou reescrever os seus URL, diretamente no seu alojamento web OVHcloud. Esta página reúne os guias para proteger o acesso (palavra-passe, bloqueio de endereços IP), reescrever os URL e tirar partido das outras possibilidades do ficheiro `.htaccess`.
