## Objetivo

As informações contidas neste guia dizem respeito às versões de **PHP**, **Python**, **Perl** e **Apache** utilizadas no âmbito dos serviços [Web Hosting](/links/web/hosting), acessíveis através da rede Web Hosting.

**Descubra os detalhes das versões PHP, Python, Perl e Apache.**

## Requisitos

- Ter um serviço de [alojamento web OVHcloud](/links/web/hosting).

## Instruções

As tabelas abaixo indicam as versões das linguagens disponíveis nos alojamentos web OVHcloud e o respetivo estado. Cada versão remete para a sua página de informação, que indica o número de versão completo e a configuração.

### Estado das versões

<span style={{backgroundColor:"#198754", color:"white", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Suportada</span>: versão mantida nos alojamentos web.

<span style={{backgroundColor:"#ffc107", color:"#212529", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Fim de vida</span>: migre para uma versão suportada antes do seu fim de vida na OVHcloud.

<span style={{backgroundColor:"#dc3545", color:"white", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Obsoleta</span>: versão que já não é mantida; migre para uma versão suportada.
