## Gerir as bases de dados do seu alojamento web

Crie, faça a gestão e a cópia de segurança das bases de dados do seu alojamento web OVHcloud. Esta página reúne os guias para gerir as suas bases de dados, fazer a cópia de segurança, importar e restaurar os seus dados, e resolver os erros mais frequentes.

Para se orientar consoante a sua necessidade:

- **Pretende criar ou configurar uma base de dados?** Consulte a secção *Gerir uma base de dados* (criar, palavra-passe, duplicar).
- **Pretende fazer uma cópia de segurança ou restaurar os seus dados?** Consulte a secção *Cópia de segurança e restauro* (recuperar, importar, restaurar).
- **Tem um erro de base de dados?** Consulte a secção *Resolução de problemas* (erros comuns, base de dados saturada).
