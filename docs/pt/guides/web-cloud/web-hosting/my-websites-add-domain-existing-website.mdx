## Objetivo

Pode alojar vários sites web na mesma oferta de alojamento web, mesmo que os nomes de domínio não estejam registados na OVHcloud. Além disso, pode associar um ou vários nomes de domínio ou subdomínios ao mesmo site web.

:::info
Se ainda não criou o site web em questão no seu alojamento web, consulte **diretamente** [este guia](/guides/web-cloud/web-hosting/multisites-configure-multisite).

:::

**Saiba como associar um nome de domínio ou um subdomínio a um site web já existente no seu alojamento web.**

## Requisitos

- Dispor de uma oferta de [alojamento web OVHcloud](https://www.ovhcloud.com/pt/web-hosting/uc-multisite/) compatível.
- Dispor de um ou vários [nomes de domínio](https://www.ovhcloud.com/pt/domains/).
- Poder modificar a configuração dos seus nomes de domínio a partir das [zonas DNS](/guides/web-cloud/domains/dns-zone-edit).

## Instruções

### Adicionar um nome de domínio ou um subdomínio a um site web existente

**Clique num dos títulos abaixo para visualizar as explicações.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Adicionar um nome de domínio gerido na sua conta OVHcloud</summary>

Esta parte aplica-se apenas se o seu nome de domínio e/ou a respetiva zona DNS ativa se encontrarem **na sua conta OVHcloud**.

O formulário ocupa uma única página: preencha-o de cima para baixo e valide. Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Os meus sites</code>. Na tabela, clique no botão <code className="action">⋮</code> situado na coluna **Ações**, à direita do site em causa e, a seguir, no grupo **Nomes de domínio**, em <code className="action">Adicionar um nome de domínio</code>.

    <img className="thumbnail" alt="Menu Ações de um site, entrada Adicionar um nome de domínio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Abre-se a página **Adicionar um domínio**. Esta retoma o formulário de adição de site, no qual a **pasta raiz** e o **nome do site** já estão preenchidos a partir do site existente: deixe-os como estão.

    <img className="thumbnail" alt="Página Adicionar um domínio e escolha do tipo de nome de domínio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    Na secção **Associação do nome de domínio**, escolha a opção **Nome de domínio OVHcloud existente**.
  </Tab>
  <Tab label="Etapa 4">
    É apresentada a secção **Configurar o seu domínio**. Selecione o nome de domínio a associar no menu pendente **Nome de domínio**.

    <img className="thumbnail" alt="Configuração do domínio, opções e configuração DNS" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-configure-domain.png" loading="lazy" />

    :::info
    Para adicionar um subdomínio, selecione primeiro o nome de domínio na lista (por exemplo: domain.tld). A seguir, assinale a caixa **Criar um subdomínio**. Aparece um campo para introduzir o subdomínio (por exemplo: **sub**.domain.tld).

    **Caso particular**: o subdomínio em `www` (por exemplo: **www**.domain.tld) não é adicionado automaticamente com o nome de domínio. Para que também apresente o seu site, adicione-o separadamente, repetindo este procedimento com `www.domain.tld`.
    :::

    A secção **Opções** reúne três funcionalidades, desmarcadas por predefinição. Consoante a sua [oferta de alojamento web](/links/web/hosting), algumas podem não estar disponíveis.

    |Opção|Descrição|
    |---|---|
    |IP do país|Permite beneficiar de um endereço IP geolocalizado (a partir de uma lista de países) para o nome de domínio selecionado.<br/> Saiba mais com [esta página](/links/web/hosting-options).|
    |Firewall|Permite ativar um firewall (filtragem e análise das requisições) no nome de domínio selecionado.<br/> Saiba mais com [esta página](/links/web/hosting-options).|
    |CDN|Permite ativar o CDN (armazenamento em cache dos elementos estáticos do seu site web, como as imagens) no nome de domínio selecionado.<br/> Saiba mais com [a nossa página CDN](/links/web/hosting-options-cdn).<br/> Ao ativar o SSL e o CDN, também poderá beneficiar do protocolo **HTTP/2** (este protocolo está ativado por defeito no nosso datacenter de Gravelines).|

    :::info
    Estas opções podem ser ativadas mais tarde. Para isso, consulte [este guia](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::

    Por fim, a secção **Configuração DNS** propõe dois modos:

    - **Para uma configuração automática**, deixe a opção **Configuração automática** selecionada: os registos A e AAAA são criados na zona DNS do domínio.
    - **Para uma configuração manual**, escolha a opção **Configuração manual** e consulte os seguintes guias:
        - [Alojamento web - Lista dos endereços IP por cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Editar uma zona DNS da OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    Por fim, clique em <code className="action">Validate</code>. A adição pode demorar até uma hora.

    :::info
    A alteração da configuração DNS do seu nome de domínio requer um tempo de propagação que pode chegar às 48 horas até estar plenamente efetiva.
    :::
  </Tab>
</Tabs>

<details>
<summary>Adicionar um nome de domínio externo</summary>

Esta secção aplica-se apenas se o seu nome de domínio não estiver presente no seu conta OVHcloud.

O formulário ocupa uma única página: preencha-o de cima para baixo e valide. Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Os meus sites</code>. Na tabela, clique no botão <code className="action">⋮</code> situado na coluna **Ações**, à direita do site em causa e, a seguir, no grupo **Nomes de domínio**, em <code className="action">Adicionar um nome de domínio</code>.

    <img className="thumbnail" alt="Menu Ações de um site, entrada Adicionar um nome de domínio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Abre-se a página **Adicionar um domínio**. Esta retoma o formulário de adição de site, no qual a **pasta raiz** e o **nome do site** já estão preenchidos a partir do site existente: deixe-os como estão.

    <img className="thumbnail" alt="Página Adicionar um domínio e escolha do tipo de nome de domínio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    Na secção **Associação do nome de domínio**, escolha a opção **Nome de domínio externo**.
  </Tab>
  <Tab label="Etapa 4">
    Na secção **Configurar o seu domínio**, introduza o nome de domínio (por exemplo: domain.tld) ou o subdomínio (por exemplo: **sub**.domain.tld) no campo **Nome de domínio**.

    :::tip
    **Caso particular**: o subdomínio em `www` (por exemplo: **www**.domain.tld) não é adicionado automaticamente com o nome de domínio. Para que também apresente o seu site, adicione-o separadamente, repetindo este procedimento com `www.domain.tld`.
    :::

    A secção **Gestão do domínio** apresenta então os registos a criar, em duas etapas. Esta verificação é obrigatória: permite-nos garantir que a adição do nome de domínio externo é legítima.

    <img className="thumbnail" alt="Gestão do domínio: registos DNS a criar e registo BIND" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-external-dns.png" loading="lazy" />

    1. **Verifique a propriedade do domínio**: adicione o registo **TXT** indicado na zona DNS do seu fornecedor.
    2. **Aponte o domínio para o seu alojamento**: adicione os registos **A** e **AAAA** indicados.

    Cada valor dispõe de um botão de cópia, e o bloco **Registo BIND** retoma as três linhas no formato esperado pela maioria dos alojadores de zonas DNS.

    Por fim, clique em <code className="action">Validate</code>. O nome de domínio é adicionado temporariamente, enquanto altera a respetiva configuração DNS.

    :::warning
    Deve efetuar estas alterações **rapidamente** para que o seu nome de domínio fique corretamente associado ao seu site.

    As entradas DNS do tipo **A** e **TXT** devem obrigatoriamente ser colocadas na zona DNS ativa do seu nome de domínio. Apenas as entradas DNS do tipo **AAAA** são opcionais.

    Tenha em conta que, se pretender associar `sub.domain.tld`, terá de criar a entrada TXT `ovhcontrol.domain.tld` e não a entrada `ovhcontrol.sub.domain.tld`.

    Para encontrar a zona DNS ativa do seu nome de domínio, consulte os [servidores DNS](/guides/web-cloud/domains/dns-server-edit) aos quais este está associado.
    :::

    :::info
    A alteração da configuração DNS do seu nome de domínio requer um tempo de propagação que pode chegar às 48 horas até estar plenamente efetiva.
    :::
  </Tab>
</Tabs>

</details>

### Oferta de e-mail incluída com o seu alojamento web

A maioria das ofertas de [alojamento web OVHcloud](https://www.ovhcloud.com/pt/web-hosting/) dispõe de uma opção incluída de criação de endereços de e-mail personalizados com o seu nome de domínio.

Esta opção de e-mail pode ser ativada para **um único** nome de domínio. Isso significa que se alojar vários sites web com vários nomes de domínio diferentes no seu alojamento web, apenas poderá ativar esta opção para um dos seus nomes de domínio.

Não hesite em consultar [o nosso guia dedicado](/guides/web-cloud/web-hosting/activate-email-hosting) para mais detalhes sobre a ativação desta opção.
