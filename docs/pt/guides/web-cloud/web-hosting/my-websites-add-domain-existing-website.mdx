## Objetivo

Pode alojar vários sites web na mesma oferta de alojamento web, mesmo que os nomes de domínio não estejam registados na OVHcloud. Além disso, pode associar um ou vários nomes de domínio ou subdomínios ao mesmo site web.

:::info
Se ainda não criou o site web em questão no seu alojamento web, consulte **diretamente** [este guia](/guides/web-cloud/web-hosting/multisites-configure-multisite).

:::

**Saiba como associar um nome de domínio ou um subdomínio a um site web já existente no seu alojamento web.**

:::info
Este procedimento aplica-se à <ManagerLink to="/beta/#/">nova versão da Área de Cliente OVHcloud</ManagerLink>, atualmente disponível em beta. Para o seguir, mude para esta interface a partir da sua Área de Cliente habitual.

:::

## Requisitos

- Dispor de uma oferta de [alojamento web OVHcloud](https://www.ovhcloud.com/pt/web-hosting/uc-multisite/) compatível.
- Dispor de um ou vários [nomes de domínio](https://www.ovhcloud.com/pt/domains/).
- Poder modificar a configuração dos seus nomes de domínio a partir das [zonas DNS](/guides/web-cloud/domains/dns-zone-edit).

## Instruções

### Adicionar um nome de domínio ou um subdomínio a um site web existente

<details>
<summary>Adicionar um nome de domínio gerido a partir do seu Área de Cliente OVHcloud</summary>

Esta secção aplica-se apenas se o seu nome de domínio e/ou a sua zona DNS ativa se encontram **no seu Área de Cliente OVHcloud**.

Clique nos separadores abaixo para visualizar cada uma das **6** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting/sites">Alojamentos</ManagerLink> e escolha o alojamento web correspondente.

    <img className="thumbnail" alt="Alojamentos" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">

    <img className="thumbnail" alt="Meus sites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    No quadro que aparece, clique no botão <code className="action">⁝</code> localizado à direita do site web em questão, depois em <code className="action">Adicionar um domínio</code>.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/website-options.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Marque a opção <code className="action">Associar um domínio OVHcloud existente</code> e clique em <code className="action">Continuar</code>.

    Selecione depois o nome de domínio a associar no menu suspenso **Nome de domínio - obrigatório** que aparece em baixo.

    :::info
    Para adicionar um subdomínio, selecione primeiro o nome de domínio na lista (por exemplo: domain.tld). Marque depois a caixa intitulada <code className="action">Criar um subdomínio</code>. Aparece um campo de introdução para que possa indicar o subdomínio (por exemplo: **sub**.domain.tld).

    **Caso particular**: Os subdomínios em `www` (por exemplo: **www**.domain.tld) são automaticamente adicionados em complemento ao nome de domínio. Por isso, não é necessário especificar este subdomínio particular no campo de introdução.

    :::

    <img className="thumbnail" alt="Add domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-ovh-step-1.png" loading="lazy" />

    Se desejar utilizar uma das **opções avançadas** disponíveis, ative o botão <code className="action">Configuração avançada</code> e passe diretamente ao **etapa 7**. Caso contrário, continue ao **etapa 6**.
  </Tab>
  <Tab label="Etapa 5">
    Verifique que todas as informações introduzidas anteriormente estão corretas, depois clique em <code className="action">Continuar</code> para finalizar a adição do seu nome de domínio ou do seu subdomínio ao seu site web.

    Esta adição pode demorar até uma hora.

    A configuração DNS será realizada automaticamente se a zona DNS ativa do seu nome de domínio for gerida no seu área de cliente OVHcloud.

    Caso contrário, consulte os seguintes guias para configurar manualmente a sua zona DNS:

    - [Alojamento web - Lista dos endereços IP por cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
    - [Editar uma zona DNS da OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    :::info
    A modificação da configuração DNS do seu nome de domínio requer um período de propagação que pode atingir 24 horas antes de ser plenamente efetiva.

    :::

  </Tab>
  <Tab label="Etapa 6">
    :::info
    Esta etapa é **opcional**. Dirige-se apenas aos clientes que desejam ativar certas funcionalidades disponíveis através do botão <code className="action">Configuração avançada</code>.

    **Todas estas funcionalidades podem ser ativadas posteriormente, uma vez que o nome de domínio foi adicionado ao seu site web.** Neste caso específico, consulte diretamente [este guia](/guides/web-cloud/web-hosting/multisites-modify-domain).

    <Region zones={['eu']}>

    |Firewall|Permite ativar um firewall (filtragem e análise das requisições) no nome de domínio selecionado.<br/> Saiba mais com [esta página](https://www.ovhcloud.com/pt/web-hosting/options/).|
    |CDN|Permite ativar o CDN (armazenamento em cache dos elementos estáticos do seu site web, como as imagens) no nome de domínio selecionado.<br/> Saiba mais com [a nossa página CDN](https://www.ovhcloud.com/pt/web-hosting/options/cdn/).<br/> Ao ativar o SSL e o CDN, também poderá beneficiar do protocolo **HTTP/2** (este protocolo está ativado por defeito no nosso datacenter de Gravelines).|

    <Region zones={['ca', 'apac']}>

    |Opção|Descrição|
    |---|---|
    |Firewall|Permite ativar um firewall (filtragem e análise das requisições) no nome de domínio selecionado.<br/> Saiba mais com [esta página](https://www.ovhcloud.com/pt/web-hosting/options/).|
    |CDN|Permite ativar o CDN (armazenamento em cache dos elementos estáticos do seu site web, como as imagens) no nome de domínio selecionado.<br/> Saiba mais com [a nossa página CDN](https://www.ovhcloud.com/pt/web-hosting/options/cdn/).|

    </Region>

    Uma vez que o botão <code className="action">Configuração avançada</code> esteja ativado, pode também escolher o modo de configuração DNS do seu nome de domínio:

    - **Para uma configuração DNS automática**, deixe a caixa <code className="action">Configuração automática (Recomendado)</code> marcada.
    - **Para uma configuração DNS manual**, marque a caixa <code className="action">Configuração manual</code>. Para realizar depois a configuração, consulte os seguintes guias:
        - [Alojamento web - Lista dos endereços IP por cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Editar uma zona DNS da OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    Uma vez que as suas escolhas estejam feitas, clique no botão <code className="action">Continuar</code> para finalizar a adição do seu nome de domínio ou do seu subdomínio ao seu site web. Esta adição pode demorar até uma hora.

    No entanto, a modificação da configuração DNS do seu nome de domínio requer um período de propagação que pode atingir 24 horas antes de ser plenamente efetiva.

    :::tip

    :::info
    Ao contrário dos nomes de domínio diretamente geridos a partir do seu área de cliente OVHcloud, as **opções avançadas** não estão diretamente disponíveis durante a adição de um nome de domínio ou subdomínio externo ao seu site web.

    Toda a adição de um nome de domínio externo à OVHcloud requer uma validação obrigatória adicional. Isso permite-nos assegurar que a adição do nome de domínio externo é legítima. Uma mensagem vai pedir-lhe para modificar a configuração DNS do nome de domínio.

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-3.png" loading="lazy" />

    Note os elementos que aparecem, depois clique no botão <code className="action">Continuar</code>. A partir desse momento, o nome de domínio é adicionado temporariamente, enquanto pode modificar a sua configuração DNS.

    :::warning
    Deve realizar estas modificações **rapidamente** para que o seu nome de domínio seja corretamente adicionado. Sem esta ação, a adição do seu nome de domínio será cancelada.

    As entradas DNS do tipo **A** e **TXT** devem obrigatoriamente ser colocadas na zona DNS ativa do seu nome de domínio para que ele seja adicionado ao seu site web. Apenas as entradas DNS do tipo **AAAA** são opcionais.

    Note que se desejar adicionar `sub.domain.tld`, deverá criar a entrada TXT `ovhcontrol.domain.tld` e não a entrada `ovhcontrol.sub.domain.tld`.

    Para encontrar a zona DNS ativa do seu nome de domínio, encontre os [servidores DNS](/guides/web-cloud/domains/dns-server-edit) aos quais este está ligado. Deverá validar apenas o nome de domínio com o campo **TXT**, não todos os seus subdomínios.|

    :::

### Oferta de e-mail incluída com o seu alojamento web

A maioria das ofertas de [alojamento web OVHcloud](https://www.ovhcloud.com/pt/web-hosting/) dispõe de uma opção incluída de criação de endereços de e-mail personalizados com o seu nome de domínio.

Esta opção de e-mail pode ser ativada para **um único** nome de domínio. Isso significa que se alojar vários sites web com vários nomes de domínio diferentes no seu alojamento web, apenas poderá ativar esta opção para um dos seus nomes de domínio.

Não hesite em consultar [o nosso guia dedicado](/guides/web-cloud/web-hosting/activate-email-hosting) para mais detalhes sobre a ativação desta opção.
