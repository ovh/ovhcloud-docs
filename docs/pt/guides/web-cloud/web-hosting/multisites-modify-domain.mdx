## Objetivo

Ao utilizar o seu alojamento web ou ao atualizar o seu website, poderá ter de alterar as definições do seu domínio ou subdomínio já associado ao seu alojamento web.

:::info
Este guia explica unicamente como alterar um domínio ou um subdomínio já declarado num alojamento web da OVHcloud.

- Para associar um novo nome de domínio ou subdomínio ao seu site web no seu alojamento web, consulte o nosso guia "[Como associar um nome de domínio a um site web existente?](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".
- Para adicionar um novo site web ao seu alojamento web, consulte o nosso guia "[Partilhar o alojamento entre vários sites](/guides/web-cloud/web-hosting/multisites-configure-multisite)".

:::

**Saiba como alterar as definições de associação de um domínio/subdomínio já registado na sua oferta de alojamento web.**

## Requisitos

- Ter um plano [de alojamento web OVHcloud](/links/web/hosting).
- Dispor de um ou vários [nomes de domínio](/links/web/domains).
- Dispor de direitos suficientes sobre o conjunto dos serviços em causa. Encontre mais informações no nosso guia "[Como gerir os contactos (gestores) dos serviços OVHcloud](/guides/account-and-service-management/account-information/managing-contacts)".

## Instruções

:::warning
A modificação das configurações de associação de um domínio ou de um subdomínio pode, em caso de má manipulação, levar a uma interrupção do acesso aos seus serviços (o seu website). Se não tiver a certeza quanto às alterações a realizar, não hesite em contactar um fornecedor especializado

:::

Para modificar os parâmetros de associação de um nome de domínio ou subdomínio já declarado na sua oferta de alojamento web, clique nos separadores abaixo para visualizar cada uma das **4** etapas.

### Descrição dos parâmetros modificáveis <a name="step1"></a>

:::info
O nome do domínio e a pasta raiz não se modificam a partir desta janela: são parâmetros do próprio site.

- Para associar um novo nome de domínio ou subdomínio a um site web no seu alojamento web, consulte o nosso guia "[Como associar um nome de domínio a um site web existente?](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".
- Para alterar a pasta raiz do seu site, consulte o nosso guia "[Como alterar a pasta raiz de um site existente?](/guides/web-cloud/web-hosting/my-websites-modify-root-folder)".

:::

A janela reúne as opções em três grupos.

#### Grupo "Desempenho e distribuição"

:::warning
Este grupo apresenta-se sob a forma de **três escolhas exclusivas**: só pode selecionar uma de cada vez.

- <code className="action">Nenhum</code> não ativa nem a CDN nem o IP do país.
- <code className="action">Ativar CDN</code> desativa o IP do país.
- <code className="action">IP do país</code> desativa a CDN.
:::

**Ativar CDN.** Para poder utilizar esta opção, deve ter previamente subscrito uma oferta CDN da OVHcloud ou dispor de um serviço de alojamento web Performance, Agency, Agency Plus ou Agency Max.

Encontre mais informações sobre as opções/ofertas CDN disponíveis na nossa documentação dedicada "[Guia de utilização do acelerador CDN num alojamento web](/guides/web-cloud/web-hosting/cdn-how-to-use-cdn)".

<Region zones={['eu']}>
**IP do país.** Esta opção é utilizada principalmente para os websites cujo público-alvo esteja situado no estrangeiro. Isto permite um melhor referenciamento SEO do website no país escolhido. Por baixo da opção, aparece um menu pendente para escolher o país.

Encontre mais informações sobre esta opção na nossa documentação dedicada "[Geolocalizar o seu website num país específico](/guides/web-cloud/web-hosting/multisites-geolocation)".
</Region>

#### Grupo "Segurança"

**Ativar firewall.** Esta opção permite filtrar os pedidos recebidos para proteger o seu alojamento web contra os ataques mais comuns.

Encontre mais informações sobre esta opção na nossa documentação dedicada "[Partilhado: ativação da firewall](/guides/web-cloud/web-hosting/multisites-activating-application-firewall)".

#### Grupo "Estatísticas e registos"

**Logs separados.** Selecione esta opção unicamente se pretender que este nome de domínio disponha do seu próprio espaço de estatísticas e registos, em vez de os partilhar com o domínio principal.

Para saber mais sobre esta opção, consulte a nossa [página sobre estatísticas detalhadas](/links/web/hosting-traffic-analysis).

Depois de efetuar as suas modificações, clique no botão <code className="action">Confirmar</code> situado na parte inferior da janela.

Dependendo das opções selecionadas, as alterações podem levar de alguns minutos ou algumas horas para serem aplicadas.

Se, para as opções **CDN**, **IP do país** e **logs separados**, as modificações não forem aplicadas após 24 horas, consulte os respetivos guias (e páginas) indicados para cada uma das opções descritas acima, a fim de verificar que todas as condições exigidas foram corretamente respeitadas e realizadas.
