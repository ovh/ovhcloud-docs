## Objetivo

Pode alojar vários sites web na mesma oferta de alojamento web, mesmo que os nomes de domínio não estejam registados na OVHcloud. Além disso, pode associar um ou vários nomes de domínio ou subdomínios ao mesmo site web.

Já não deseja utilizar um nome de domínio ou subdomínio para o seu site web? 
Deseja associar o seu nome de domínio ou subdomínio a outro site web num dos seus alojamentos web? 

**Descubra como desassociar um nome de domínio ou subdomínio de um site web já existente no seu alojamento web.**

:::info
Este procedimento aplica-se à <ManagerLink to="/beta/#/">nova versão da Área de Cliente OVHcloud</ManagerLink>, atualmente disponível em beta. Para o seguir, mude para esta interface a partir da sua Área de Cliente habitual.

:::

## Requisitos

- Dispor de uma oferta de [alojamento web OVHcloud](https://www.ovhcloud.com/pt/web-hosting/uc-multisite/) compatível.
- Dispor de um ou vários [nomes de domínio](https://www.ovhcloud.com/pt/domains/).
- Poder modificar a configuração dos seus nomes de domínio a partir das [zonas DNS](/guides/web-cloud/domains/dns-zone-edit).

## Instruções

:::warning
Desassociar um nome de domínio ou subdomínio de um site web no seu alojamento web é uma operação sensível. De facto, após esta operação, o seu site web já não será acessível na Internet com o seu nome de domínio e/ou subdomínio.

:::

### Caso particular: Desassociação de um nome de domínio ou subdomínio para o utilizar com outro site web

- Se desejar adicionar o seu nome de domínio ou subdomínio a outro site web existente num alojamento web, consulte [este guia](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).
- Se desejar criar um novo site web num alojamento web com o seu nome de domínio ou subdomínio recentemente desassociado, consulte [este guia](/guides/web-cloud/web-hosting/multisites-configure-multisite).
