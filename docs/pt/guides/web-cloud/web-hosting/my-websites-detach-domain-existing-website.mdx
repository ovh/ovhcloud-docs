## Objetivo

Pode alojar vários sites web na mesma oferta de alojamento web, mesmo que os nomes de domínio não estejam registados na OVHcloud. Além disso, pode associar um ou vários nomes de domínio ou subdomínios ao mesmo site web.

Já não deseja utilizar um nome de domínio ou subdomínio para o seu site web? 
Deseja associar o seu nome de domínio ou subdomínio a outro site web num dos seus alojamentos web? 

**Descubra como desassociar um nome de domínio ou subdomínio de um site web já existente no seu alojamento web.**

## Requisitos

- Dispor de uma oferta de [alojamento web OVHcloud](https://www.ovhcloud.com/pt/web-hosting/uc-multisite/) compatível.
- Dispor de um ou vários [nomes de domínio](https://www.ovhcloud.com/pt/domains/).
- Poder modificar a configuração dos seus nomes de domínio a partir das [zonas DNS](/guides/web-cloud/domains/dns-zone-edit).

[[cpnav:web-hosting]]

## Instruções

:::warning
Desassociar um nome de domínio ou subdomínio de um site web no seu alojamento web é uma operação sensível. De facto, após esta operação, o seu site web já não será acessível na Internet com o seu nome de domínio e/ou subdomínio.

:::

Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

    <img className="thumbnail" alt="Painel Gerir os meus domínios e menu Ações de um domínio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/manage-domains-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    É apresentada a janela **Desassociar um domínio**, que lhe pede para confirmar a sua escolha. Contém duas definições:

    <img className="thumbnail" alt="Janela Desassociar um domínio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/detach-domain-dialog.png" loading="lazy" />

    - **Desanexar também o subdomínio**, seguido do subdomínio `www` em causa: desmarcada por predefinição, esta caixa desassocia-o ao mesmo tempo que o nome de domínio, se também estiver declarado neste site. A zona DNS deste subdomínio e todas as suas opções são então eliminadas.
    - <code className="action">Eliminar os registos de apontamento (A e AAAA) na zona DNS do nome de domínio.</code>: assinalada por predefinição, esta caixa retira da zona DNS os registos que apontam para o seu alojamento web. Desmarque-a se pretender manter estes registos.

    Por fim, clique em <code className="action">Confirmar</code>.

    :::warning
    **Caso particular: o seu site está associado a um repositório Git**

    A janela apresenta então um aviso e uma caixa adicional, <code className="action">Sim, eliminar a minha configuração Git</code>. O botão <code className="action">Confirmar</code> permanece inativo enquanto não a assinalar: desassociar o nome de domínio elimina também a [associação Git](/guides/web-cloud/web-hosting/git-integration-webhosting) do site.

### Caso particular: Desassociação de um nome de domínio ou subdomínio para o utilizar com outro site web

- Se desejar adicionar o seu nome de domínio ou subdomínio a outro site web existente num alojamento web, consulte [este guia](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).
- Se desejar criar um novo site web num alojamento web com o seu nome de domínio ou subdomínio recentemente desassociado, consulte [este guia](/guides/web-cloud/web-hosting/multisites-configure-multisite).
