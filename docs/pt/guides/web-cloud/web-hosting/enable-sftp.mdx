## Objetivo

As ofertas de alojamento web OVHcloud dão acesso a um espaço de armazenamento que permite publicar os ficheiros dos seus sites ou aplicações. O acesso a este espaço pode ser feito através de um utilizador FTP ou SSH com as respetivas palavras-passe associadas.

Assim como o **F**ile **T**ransfer **P**rotocol (**FTP**), o **S**ecure **F**ile **T**ransfer **P**rotocol (**SFTP**) permite transferir dados do seu dispositivo para o espaço de armazenamento da sua alojamento web.

A única diferença é que o SFTP utiliza um canal seguro para trocar dados. Os dados que transitam através deste protocolo são automaticamente encriptados.

**Saiba como ativar o acesso SFTP na sua alojamento web OVHcloud.**

## Requisitos

- Ter uma oferta de [alojamento web OVHcloud](/links/web/hosting).

[[cpnav:web-hosting]]

## Instruções

### Ativar o acesso SFTP para um utilizador FTP da sua alojamento web

Clique nos separadores abaixo para visualizar sucessivamente cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Separador FTP-SSH de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na secção **Utilizadores FTP e SSH**, verifique o estado apresentado na coluna **SFTP** para o utilizador FTP em causa:

    - **Ativado**: o protocolo SFTP já está ativo para este utilizador, não há nada a fazer.
    - **Desativado**: na coluna **Ações**, clique no botão <code className="action">⋮</code> situado à direita da linha em causa e, a seguir, em <code className="action">Editar</code>.

    <img className="thumbnail" alt="Tabela dos utilizadores FTP e estado do protocolo SFTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/ftp-users-sftp-status.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    O painel **Editar um utilizador** abre-se à direita. No menu pendente **Protocolos de ligação**, selecione <code className="action">FTP e SFTP</code>, ou <code className="action">FTP, SFTP e SSH</code> se também precisar de ativar o protocolo SSH.

    <img className="thumbnail" alt="Painel Editar um utilizador e menu Protocolos de ligação" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user-protocols.png" loading="lazy" />

O menu propõe um terceiro valor, <code className="action">FTP</code> sozinho, que desativa o SFTP para este utilizador.

    Por fim, clique em <code className="action">Confirmar</code>. Depois de ativada a opção **SFTP**, poderá utilizar o protocolo SFTP do seu alojamento web com o utilizador FTP em causa.
  </Tab>
</Tabs>

:::info
O valor <code className="action">FTP, SFTP e SSH</code> só é proposto nas ofertas que incluem o acesso SSH: **Pro**, **Performance**, **Agency**, **Agency Plus** e **Agency Max**.

Nas ofertas <Region zones={['eu']}>**gratuita**, **Starter**, **Perso** e **Startup**</Region><Region zones={['ca', 'apac']}>**Starter**, **Perso** e **Startup**</Region>, o menu **Protocolos de ligação** só propõe <code className="action">FTP</code> e <code className="action">FTP e SFTP</code>, e a tabela dos utilizadores não apresenta a coluna **SSH**.

:::
