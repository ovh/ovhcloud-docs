## Objetivo

A maior parte dos websites utiliza uma **base de dados** para armazenar artigos, comentários ou endereços de e-mail dos seus utilizadores.

A ligação a esta base de dados é possível graças a um **ficheiro de configuração** contido no [espaço de armazenamento de ficheiros](/guides/web-cloud/web-hosting/ftp-connection) do seu alojamento. Contém as informações que permitem ao seu site "identificar-se" junto do seu **servidor de base de dados**.

Por isso, a alteração da palavra-passe de uma base de dados deve ser sempre efetuada:

- No [ficheiro de configuração](/guides/web-cloud/web-hosting/cms-manage-1-click-module#etapa-1-identificar-a-base-de-dados-do-modulo) do seu site através do [espaço FTP do seu alojamento](/guides/web-cloud/web-hosting/ftp-connection);

- **E** no servidor que contém a base de dados através da <ManagerLink to="/beta/#/">consola OVHcloud</ManagerLink>.

Enquanto esta alteração não for efetuada **nestes dois locais**, o seu site irá apresentar um "[erro de ligação à base de dados](/guides/web-cloud/web-hosting/diagnosis-database-errors#error-establishing-a-database-connection)".

Assim, para alterar a palavra-passe da base de dados, é imperativo que realize **o conjunto das operações** indicadas neste guia. Se tiver dúvidas sobre as operações a realizar, contacte o seu webmaster ou um [fornecedor especializado](/links/partner).

A alteração da palavra-passe da base de dados do seu site faz-se em quatro partes:

- [1: Identificar o ficheiro de configuração do seu site](#step1);
- [2: Identificar a base de dados do seu site](#step2);
- [3: Alterar a palavra-passe da base de dados do seu site no seu ficheiro de configuração](#step3);
- [4: Alterar a palavra-passe da base de dados do seu site para o servidor de bases de dados](#step4).

**Descubra como alterar a palavra-passe de uma base de dados de forma segura.**

## Requisitos

- Ter um [plano de alojamento web OVHcloud](/links/web/hosting).
- Utilizar uma [base de dados associada à sua oferta de alojamento partilhado](/links/web/hosting-options-startsql) ou a um [Web Cloud Databases](/links/web/databases).
- Ter acesso às credenciais FTP para aceder ao [espaço de armazenamento do alojamento](/guides/web-cloud/web-hosting/ftp-connection).

  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Os meus sites</code>.

    <img className="thumbnail" alt="Separador Os meus sites de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na tabela, identifique a linha do seu site através da coluna **Site** e, a seguir, consulte a sua coluna **Pasta raiz**. Trata-se do diretório onde se encontram os ficheiros e pastas do seu site.

    <img className="thumbnail" alt="Tabela dos sites e a sua coluna Pasta raiz" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/root-folders.png" loading="lazy" />

    Em seguida, aceda ao espaço de armazenamento FTP que contém os ficheiros e pastas do seu site consultando [este guia](/guides/web-cloud/web-hosting/ftp-connection).
  </Tab>
</Tabs>

:::info
Se pretender alterar a palavra-passe do seu espaço FTP, consulte este [guia](/guides/web-cloud/web-hosting/ftp-change-password).

:::

Abra a `Pasta raiz` identificada acima.

Procure e abra o ficheiro de configuração do seu site:

- Para um website WORDPRESS, trata-se de **"wp-config.php"**;
- Para um site JOOMLA, trata-se de **"configuration.php"**;
- Para um site DRUPAL, clique na pasta **"sites"** e **"default"**. O ficheiro de configuração é **"settings.php"**;
- Para um website PRESTASHOP, clique na pasta **"app"** e **"config"**. O ficheiro de configuração é **"parameters.php"**.

### 2: Identificar a base de dados do seu site <a name="step2"></a>

Existem dois casos possíveis:

- Caso n°1: a base de dados do seu site faz parte da sua oferta de alojamento;
- Caso n°2: está incluída numa oferta *Web Cloud Databases*, caso em que deverá encontrar o **nome do servidor** e o **nome de utilizador** da sua base de dados, de forma a identificar a base de dados sem correr o risco de erro.

Para determinar o caso aplicável ao seu site, no ficheiro de configuração identificado na [parte 1](#step1), comece por anotar o nome da sua base de dados:

- Para WORDPRESS: O nome aparece sob a menção **"DB_NAME"**;
- Para JOOMLA: o nome aparece na rubrica **"public $db"**;
- Para o DRUPAL: o nome aparece na rubrica **"database"**;
- Para PRESTASHOP: o nome aparece em **"database_name"**.

De seguida, volte à <ManagerLink to="/beta/#/web-cloud/hosting">consola OVHcloud</ManagerLink>, no universo <code className="action">Web Cloud</code>:

- Aceda à secção <code className="action">Alojamento web</code> e, a seguir, ao alojamento correspondente;
- Clique no separador <code className="action">Bases de dados</code>, na barra de separadores situada por baixo do nome do seu alojamento;
- Verifique o nome da base de dados encontrada anteriormente na coluna **Nome do banco**;

Se localizar o nome da base de dados indicado no ficheiro de configuração nesta parte da consola OVHcloud, avance para a [parte 3](#step3).

Caso contrário, a base de dados do seu site está associada a uma oferta [Web Cloud Databases](/links/web/databases).

Para anotar o *nome do servidor* e o *nome de utilizador* da base de dados, deverá voltar ao ficheiro de configuração do seu site:

- Para WORDPRESS: O *nome do servidor* aparece com a menção **"DB_HOST"** e o *nome de utilizador* com a menção **"DB_USER"**;
- Para JOOMLA: o *nome do servidor* aparece na rubrica **"public $host"** e o *nome do utilizador* na menção **"public $user"**;
- Para o DRUPAL: o *nome do servidor* aparece em **"host"** e o *nome de utilizador* sob a menção **"username"**;
- Para PRESTASHOP: o *nome do servidor* aparece na rubrica **"database_host"** e o *nome de utilizador* na rubrica **"database_user"**.

Aceda depois à secção <code className="action">Web Cloud DB</code> da consola OVHcloud e selecione a instância em causa.

No separador <code className="action">Visão geral</code>, identifique a secção **SQL** e o seu campo **Nome do host**: contém o nome do servidor da sua base de dados encontrado anteriormente.

:::warning
Não confunda este campo com o campo **Host**, situado mais acima na secção **Informações gerais**: este designa a infraestrutura que aloja a sua instância, e não o endereço que o seu site utiliza para se ligar a ela.

:::

<img className="thumbnail" alt="Visão geral de uma instância Web Cloud DB e o seu campo Nome do host" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/overview-hostname.png" loading="lazy" />

Ainda nesta instância, aceda ao separador <code className="action">Utilizadores e permissões</code>, para que possa também consultar o **nome de utilizador** da sua base de dados. Cada utilizador é apresentado sob a forma de uma ficha com o seu nome.

### 3: Alterar a palavra-passe da base de dados do seu site no seu ficheiro de configuração <a name="step3"></a>

:::info
Para mais informações sobre as boas práticas de gestão de palavras-passe, siga as instruções deste [guia](/guides/account-and-service-management/account-information/manage-ovh-password).

:::

Escolha a nova palavra-passe da sua base de dados e anote-a. Deverá respeitar as seguintes condições:

- Mínimo de 8 caracteres;
- Máximo de 30 caracteres;
- Pelo menos uma letra maiúscula;
- Pelo menos uma letra minúscula;
- Pelo menos um número;
- Ser composto unicamente por números e letras.

Da mesma forma que na [Etapa 1](#step1), volte ao espaço de armazenamento de ficheiros do seu alojamento e abra para edição o ficheiro de configuração do seu site.

**Antes de efetuar qualquer modificação**, registe localmente o conteúdo deste ficheiro num documento de texto, de forma a conservar uma cópia em caso de erro de manipulação.

Substitua manualmente a palavra-passe da sua base de dados, **evitando modificar ou eliminar qualquer outro elemento do ficheiro de configuração** (Nos extratos abaixo, apenas a palavra-passe de exemplo "*0VhCloudPa55w0rdDB123*" deve ser substituída):

- No ficheiro de configuração de um website WORDPRESS, altere o **"DB_PASSWORD"**:

```php
// ** MySQL settings - You can get this info from your web host ** //
/** The name of the database for WordPress */
define('DB_NAME', 'dbname123');
 
/** MySQL database username */
define('DB_USER', 'dbname123');
 
/** MySQL database password */
define('DB_PASSWORD', '0VhCloudPa55w0rdDB123');
 
/** MySQL hostname */
define('DB_HOST', 'dbname123.mysql.db:3306');
```

- No ficheiro de configuração de um website JOOMLA, altere o **"public $password"** (no final do ficheiro de configuração):

```php
public $host = 'dbname123.mysql.db:3306';
public $user = 'dbname123';
public $password = '0VhCloudPa55w0rdDB123';
public $db = 'dbname123';
```

- No ficheiro de configuração de um website DRUPAL, altere a **"password"**:

```php
$databases['default']['default'] = array (
  'database' => 'dbname123',
  'username' => 'dbname123',
  'password' => '0VhCloudPa55w0rdDB123',
  'prefix' => 'prefix123_',
  'host' => 'dbname123.mysql.db',
  'port' => '3306',
```

- No ficheiro de configuração de um website PRESTASHOP, altere o **"database_password"**:

```php
'database_host' => 'dbname123.mysql.db',
'database_port' => '3306',
'database_name' => 'dbname123',
'database_user' => 'dbname123',
'database_password' => '0VhCloudPa55w0rdDB123',
```

Guarde esta modificação.

### 4: Alterar a palavra-passe da base de dados do seu site para o servidor de bases de dados <a name="step4"></a>

:::info
Esta operação demorará alguns minutos até ficar efetiva. Depois de a lançar, verifique o seu estado no separador <code className="action">Operações</code>, que indica o número de operações em curso.

:::

Novamente, dois casos são possíveis: 

- Se a base de dados estiver na parte da <ManagerLink to="/beta/#/">consola OVHcloud</ManagerLink> dedicada ao seu [alojamento web](/links/web/hosting), siga as [instruções](#case1).
- Se a sua base de dados estiver na parte da <ManagerLink to="/beta/#/">consola OVHcloud</ManagerLink> dedicada às suas ofertas [Web Cloud Databases](/guides/web-cloud/databases/landing-page-databases), siga as [instruções](#case2).

#### Caso n°1: a base de dados do seu site faz parte da sua oferta de alojamento <a name="case1"></a>

Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Bases de dados</code>.

    <img className="thumbnail" alt="Separador Bases de dados de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na linha da base de dados do seu site, clique no botão <code className="action">⁝</code> da coluna **Ações** e, a seguir, em <code className="action">Alterar senha</code>.

    <img className="thumbnail" alt="Menu de uma linha da tabela das bases de dados" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Na nova janela, introduza a nova palavra-passe da base de dados (definida no [parte 3](#step3)), confirme que está correta e clique em <code className="action">Alterar</code>.

    <img className="thumbnail" alt="Janela de alteração da palavra-passe de uma base de dados" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/change-password-window.png" loading="lazy" />

Por baixo do campo, a janela recorda a regra que esta palavra-passe deve respeitar: de **9 a 30 caracteres**, incluindo uma minúscula, uma maiúscula e um algarismo; **os caracteres especiais são permitidos**.
  </Tab>
</Tabs>

#### Caso n°2: a base de dados do seu site faz parte de uma oferta Web Cloud Databases <a name="case2"></a>

Aceda à secção <code className="action">Web Cloud DB</code> da consola OVHcloud, selecione a instância em causa e clique no separador <code className="action">Utilizadores e permissões</code>:

<img className="thumbnail" alt="Separador Utilizadores e permissões de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />

Cada utilizador é apresentado sob a forma de uma ficha com o seu nome. Na do **nome de utilizador** identificado na [parte 2](#step2), clique no botão <code className="action">⁝</code> e, a seguir, em <code className="action">Alterar palavra-passe</code>.

<img className="thumbnail" alt="Menu da ficha de um utilizador de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />

Na nova janela, introduza a nova palavra-passe da base de dados (definida na [parte 3](#step3)), confirme que está correta e clique em <code className="action">Guardar</code>.

<img className="thumbnail" alt="Janela de alteração da palavra-passe de um utilizador" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password-window.png" loading="lazy" />

:::warning
A regra de complexidade não é a mesma que para uma base de dados de alojamento web: aqui, a palavra-passe deve ter de **8 a 30 caracteres**, incluindo uma minúscula, uma maiúscula e um algarismo, e **os caracteres especiais são permitidos**. A janela recorda-a por baixo do campo.

:::
