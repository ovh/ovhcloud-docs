## Proteger o seu alojamento web

Proteja o seu website e os seus visitantes: ative a encriptação HTTPS com um certificado SSL, configure uma firewall de aplicação e aplique as boas práticas de segurança no seu alojamento web OVHcloud. Esta página reúne todos os guias para proteger o seu website.

Para se orientar consoante a sua necessidade:

- **Pretende proteger o seu site e os seus visitantes?** Consulte a secção *Proteger o seu site* (boas práticas, firewall de aplicação).
- **Pretende gerir um certificado ou passar para HTTPS?** Consulte a secção *Certificado SSL e HTTPS*.
- **Procura um certificado SSL adequado às suas necessidades?** Consulte a secção *Ativar um certificado SSL* (Let's Encrypt gratuito, Sectigo DV/EV, certificado personalizado).

## Ativar um certificado SSL

Escolha o tipo de certificado adequado ao seu website e siga o guia correspondente.

<Tabs>
  <Tab label="Let's Encrypt (gratuito)">

Certificado SSL gratuito disponível com o seu alojamento web.

[Ativar um certificado SSL gratuito Let's Encrypt](/guides/web-cloud/web-hosting/ssl-letsencrypt)

  </Tab>
  <Tab label="Sectigo DV">

Certificado Sectigo de validação de domínio (Domain Validation), válido para um nome de domínio e o seu subdomínio "www".

[Ativar um certificado SSL Sectigo DV](/guides/web-cloud/web-hosting/ssl-dv)

  </Tab>
  <Tab label="Sectigo EV">

Certificado Sectigo de validação alargada (Extended Validation), válido para um nome de domínio e o seu subdomínio "www".

[Ativar um certificado SSL Sectigo EV](/guides/web-cloud/web-hosting/ssl-ev)

  </Tab>
  <Tab label="Personalizado">

Para importar o seu próprio certificado SSL quando nenhuma das soluções OVHcloud corresponde às suas necessidades.

[Instalar um certificado SSL personalizado](/guides/web-cloud/web-hosting/ssl-custom)

  </Tab>
</Tabs>
