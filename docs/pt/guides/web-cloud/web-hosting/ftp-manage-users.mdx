## Objetivo

As ofertas de alojamento web da OVHcloud dão acesso a um espaço de armazenamento FTP. Este espaço FTP permite, por exemplo, publicar ficheiros nos seus websites ou aplicações. O acesso a este espaço é possível através de um utilizador FTP ou SSH e da respetiva palavra-passe. No âmbito das suas atividades, poderá ter de criar vários utilizadores FTP para os seus diferentes colaboradores.

**Saiba como criar, modificar ou eliminar utilizadores FTP no seu alojamento web da OVHcloud.**

:::info
Este guia só é válido para os alojamentos web do tipo **Pro**, **Performance**, **Agency**, **Agency Plus** ou **Agency Max**. Apenas estas ofertas permitem a ativação de vários utilizadores FTP.

:::

## Requisitos

- Ter um plano de [alojamento OVHcloud](/links/web/hosting) compatível.

[[cpnav:web-hosting-console]]

## Instruções

### Criar um novo utilizador FTP no seu alojamento web <a name="create-ftp-user"></a>

Para criar um novo utilizador FTP no seu alojamento web a partir da consola OVHcloud, clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Separador FTP-SSH de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na secção **Utilizadores FTP e SSH**, clique em <code className="action">Criar um usuário</code>.

    <img className="thumbnail" alt="Painel de criação de um utilizador FTP na consola" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/create-user.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    O painel **Criar um utilizador** abre-se e reúne todos os parâmetros num único ecrã:

    - **Utilizador**: o nome que o seu colaborador vai utilizar para se ligar. É **sempre precedido do login FTP principal do seu alojamento web, seguido de um hífen**: se este login for `ftplogin` e introduzir `user1`, o identificador completo será `ftplogin-user1`. O nome que adicionar tem entre 1 e 12 caracteres alfanuméricos;
    - **Pasta raiz**: o diretório no qual este utilizador poderá agir. **Deixe este campo vazio para dar acesso a todo o espaço de armazenamento**; caso contrário, indique um diretório ou subdiretório, por exemplo `www`, `blog`, `website1` ou `www/development`;
    - **Protocolos de ligação**: o ou os protocolos autorizados para este utilizador. Ao escolher **FTP, SFTP e SSH**, o seu colaborador poderá tanto gerir os ficheiros como ligar-se em linha de comandos;
    - **Palavra-passe** e **Confirmar a palavra-passe**: respeite a política indicada por baixo dos campos.

    Por fim, clique em <code className="action">Criar</code>.
  </Tab>
</Tabs>

:::info
Após a validação do pedido de criação, o novo utilizador pode demorar até 15 minutos até ser corretamente tomado em conta no alojamento web.

:::

Se necessário, teste este novo utilizador FTP através do nosso guia "[Aceder ao espaço de armazenamento FTP do alojamento web](/guides/web-cloud/web-hosting/ftp-connection)".

### Modificar um utilizador FTP

Para editar um utilizador FTP, clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Separador FTP-SSH de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    A secção **Utilizadores FTP e SSH** lista os utilizadores criados no seu alojamento web. Na coluna **Ações**, clique no botão <code className="action">⋮</code> situado à direita do utilizador em causa e, a seguir, em <code className="action">Editar</code>.

    <img className="thumbnail" alt="Menu Ações de um utilizador FTP na consola" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    O painel **Editar um utilizador** abre-se. Estão disponíveis três definições:

    - **Pasta raiz**: o diretório no qual este utilizador poderá agir. Deixe este campo vazio para lhe dar acesso a todo o espaço de armazenamento;
    - **Desativar utilizador**: marque esta caixa para impedir um colaborador de aceder ao seu espaço de armazenamento FTP **sem eliminar os logs FTP e SSH que lhe estão associados**. Estes logs permitir-lhe-ão determinar que operações realizou se constatar intervenções não desejadas no seu alojamento web;
    - **Protocolos de ligação**: o ou os protocolos autorizados para este utilizador. Consulte a parte "[Criar um novo utilizador FTP no seu alojamento web](#create-ftp-user)" mais acima neste guia para o detalhe dos protocolos.

    :::info
    A **pasta raiz** da **conta principal** não pode ser modificada: o campo permanece a cinzento e a consola apresenta a mensagem «A pasta raiz da conta principal não pode ser alterada.». Só os utilizadores que criou podem alterá-la.
    :::

    O nome do utilizador e a sua palavra-passe não se modificam aqui. Para alterar a palavra-passe, utilize a entrada <code className="action">Alterar palavra-passe</code> do mesmo menu, descrita no nosso guia "[Alterar a palavra-passe de um utilizador FTP](/guides/web-cloud/web-hosting/ftp-change-password)".

    <img className="thumbnail" alt="Painel de alteração de um utilizador FTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user.png" loading="lazy" />

    Por fim, clique em <code className="action">Confirmar</code>.
  </Tab>
</Tabs>

:::info
Se pretender alterar a palavra-passe de utilizador FTP, consulte o guia "[Modificar a palavra-passe de um utilizador FTP](/guides/web-cloud/web-hosting/ftp-change-password)".

Se pretender alterar o nome de utilizador FTP, note que esta funcionalidade não está disponível. É obrigatório que [criar um novo utilizador FTP](#create-ftp-user) com o novo nome de utilizador desejado. Poderá, em seguida, [eliminar o antigo utilizador FTP](#delete-ftp-user) se necessário.

:::

### Eliminar um utilizador FTP <a name="delete-ftp-user"></a>

Para eliminar um utilizador FTP, clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Separador FTP-SSH de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na coluna **Ações** da secção **Utilizadores FTP e SSH**, clique no botão <code className="action">⋮</code> situado à direita do utilizador em causa e, a seguir, em <code className="action">Excluir</code>.

    <img className="thumbnail" alt="Menu Ações de um utilizador FTP na consola" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Uma janela pede-lhe que confirme, indicando o identificador em causa. Clique em <code className="action">Excluir</code> para retirar definitivamente este utilizador do seu alojamento web.

    <img className="thumbnail" alt="Janela de confirmação da eliminação de um utilizador FTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/delete-user-confirmation.png" loading="lazy" />
  </Tab>
</Tabs>
