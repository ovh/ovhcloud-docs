<summary>Como colocar o meu website online?</summary>

Para publicar o seu website, deve primeiro dispor dos seguintes elementos:

- Um [nome de domínio](/links/web/domains) que corresponderá ao endereço Web a partir do qual o seu website será acessível através de um browser (por exemplo: *domain.tld*). Este domínio deve também estar associado ao seu alojamento web para poder ver o website.
- Um [alojamento web](/links/web/hosting) no qual pode instalar o seu website.

Aqui estão os principais passos a seguir:

1. Defina o seu projeto (site "chave na mão" (CMS) instalado manualmente ou graças aos módulos 1 clique da OVHcloud / site criado por si ou por um prestador de serviços / etc.).
2. Colocar os ficheiros do site online no espaço de armazenamento FTP do seu alojamento web.
3. Associe o website a uma base de dados (se o website utilizar uma base de dados).
4. Aceda ao seu website.

:::tip
Para mais informações sobre como publicar um site num alojamento web, consulte o guia detalhado "[Publicar um site num alojamento web](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online)".

Se optar por instalar um CMS (WordPress, Joomla!, PrestaShop, Drupal) com a nossa solução "Módulos 1 clique", consulte o guia detalhado "[Instalar o seu website com um Módulos "1 clique" (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules)".

Se o seu website já existe noutro fornecedor e se pretender migrá-lo para a OVHcloud, consulte o guia detalhado "[Migrar o seu website e os seus serviços associados para a OVHcloud](/guides/web-cloud/web-hosting/hosting-migrating-to-ovh)".

Para o ajudar a configurar o seu alojamento web, pode utilizar todos os [guias relativos às nossas soluções de alojamento web](/guides/web-cloud/web-hosting/landing-page-web-hosting).

:::

<summary>Como transferir, sem interrupção de serviço, o meu website, a minha base de dados, o meu nome de domínio e os meus e-mails para a OVHcloud?</summary>

Aqui estão os principais passos a seguir:

1. Encomendar o alojamento e os endereços de e-mail na OVHcloud.
2. Criar e pré-configurar uma zona DNS para o seu domínio na OVHcloud.
3. Recuperar um backup completo do seu site web.
4. Importar o backup do seu website para a sua oferta de alojamento OVHcloud.
5. Recriar os mesmos endereços de e-mail na OVHcloud.
6. Declarar os servidores de e-mail OVHcloud na zona DNS ativa do seu domínio.
7. Transferir o conteúdo dos seus antigos endereços de e-mail para os novos endereços na OVHcloud.
8. Reconfigurar os seus softwares de e-mail.
9. Substituir os servidores DNS ativos do seu domínio pelos da OVHcloud.
10. Transferir um domínio para a OVHcloud.

:::tip
Encontre todos os detalhes no nosso guia "[Migrar o seu website e os seus serviços associados para a OVHcloud](/guides/web-cloud/web-hosting/hosting-migrating-to-ovh)".

<summary>Como apresentar o meu website com um URL em "HTTPS"?</summary>

Para que o seu website esteja acessível com um URL em "HTTPS" (exemplo: `https://domain.tld`), são necessários dois pré-requisitos:

- Deve dispor de um certificado SSL ativo para o seu nome de domínio (ou instalado no seu alojamento web).
- No código-fonte do seu website, este deve forçar a reescrita dos URLs em "HTTPS".

A OVHcloud disponibiliza vários [certificados SSL](/links/web/hosting-options) nos alojamentos web.

Para ativar um certificado SSL no alojamento web do seu website, clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Na página apresentada, clique no separador <code className="action">SSL</code>.

    <img className="thumbnail" alt="Separador SSL de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Por cima da tabela dos certificados, clique em <code className="action">Adicionar um certificado</code>. No painel que se abre, escolha em **Tipo de certificado** o certificado pretendido entre os [certificados disponíveis](/guides/web-cloud/web-hosting/ssl-on-webhosting).

    <img className="thumbnail" alt="Painel Adicionar um certificado e escolha do tipo de certificado" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ssl-certificates/enable-ssl-lets-encrypt.png" loading="lazy" />

    Continue até que a instalação do certificado SSL esteja finalizada (após ter validado a nota de encomenda no caso de escolher um dos certificados SSL Sectigo).
  </Tab>
</Tabs>

:::tip
Encontre todos os detalhes nos seguintes guias:

- [Alojamento web - Gerir um certificado SSL](/guides/web-cloud/web-hosting/ssl-on-webhosting).
- [Alojamento web - Ativar um certificado SSL gratuito Let's Encrypt](/guides/web-cloud/web-hosting/ssl-letsencrypt).
- [Alojamento web - Ativar um certificado SSL Sectigo DV](/guides/web-cloud/web-hosting/ssl-dv).

<summary>Porque é que o preço de renovação do meu alojamento web aumentou?</summary>

Os nossos alojamentos web evoluíram em 2026: as ofertas e os respetivos preços foram alterados. Desde 1 de junho de 2026, as renovações dos alojamentos web são faturadas aos novos preços. Foi informado destas alterações por e-mail.

As novas ofertas trazem mais capacidade ao seu serviço, como mais bases de dados com mais espaço de armazenamento, bem como novas funcionalidades baseadas em inteligência artificial.

Para mais informações, consulte o nosso artigo de blogue "[Evolução do nosso alojamento web: o que muda e porquê](https://blog.ovhcloud.com/pt/posts/evolution-webhosting-2026/)".

<summary>Já não quero o meu alojamento web. Posso ser reembolsado?</summary>

Se não pretender manter o seu alojamento web, pode solicitar a sua eliminação. Se o eliminar antes da data de expiração, o período não utilizado é-lhe reembolsado proporcionalmente, mediante pedido expresso da sua parte e desde que todos os montantes em dívida tenham sido pagos.

Para mais informações, consulte a secção "Web Hosting" do nosso manual "[GDPR - How to immediately delete your OVHcloud services](/guides/account-and-service-management/managing-billing-payments-and-services/deletion)".

<summary>Quando rescindir um alojamento web que inclui uma oferta "Web Cloud Databases" gratuita, como conservá-la?</summary>

Os alojamentos web **Performance**, **Agency**, **Agency Plus** e **Agency Max** incluem uma oferta Web Cloud Databases ativável gratuitamente.<br/>
Quando rescindir ou eliminar o seu alojamento web, a oferta Web Cloud Databases eventualmente associada será igualmente rescindida. Para conservar a sua solução Web Cloud Databases, deverá desassociá-la **antes** da rescisão do alojamento.

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Na secção **Bases de dados**, clique no botão <code className="action">⋮</code> à direita de **Web Cloud DB** e, a seguir, em <code className="action">Desvincular a minha base de dados PrivateSQL</code>.

    <img className="thumbnail" alt="Secção Bases de dados e menu da linha Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png" loading="lazy" />

    :::tip

  </Tab>

Além disso, os nomes dos servidores DNS anotados na secção **Configuração DNS** não têm nenhuma das formas descritas no **Caso n°2**, exceto as seguintes: `sdnsX.ovh.net`, `sdnsX.ovh.ca`, `vpsXXXXXX.ovh.net` ou `vpsXXXXXX.ovh.ca` (onde cada `X` é um algarismo entre **0** e **9**).

<summary>O que fazer se o meu website apresentar um erro "Your request has been blocked"?</summary>

<img className="thumbnail" alt="your-request-has-been-blocked" src="/images/assets/screens/other/browsers/errors/your-request-has-been-blocked.png" loading="lazy" />

A página "Your request has been blocked" pode ser apresentada por vários motivos (lista não exaustiva):

- O pedido é efetuado a partir de um browser Internet (Firefox, Chrome, Safari, Edge, etc.) não atualizado.
- Um grande número de pedidos, semelhantes ou não, são efetuados num prazo extremamente curto.
- O pedido tenta executar ações não autorizadas na infraestrutura partilhada onde se encontra o seu alojamento web.

Nesta situação, são necessárias várias ações:

- Verifique se o seu browser da Internet está atualizado.
- Recupere o URL chamado (por exemplo: `https://www.domain.tld`), bem como todas as informações presentes na página "Your request has been blocked" (`IP address`, `Date` e `Request ID`).
- Transmita os elementos recuperados ao suporte através da criação de um [ticket de assistência](/links/support-contact).

Se tiver dúvidas sobre as ações a executar, contacte o seu Webmaster ou um dos nossos [parceiros](/links/partner).

:::tip
Consulte também o nosso guia detalhado: [O que acontece se a página "Your request has been blocked" aparecer?](/guides/web-cloud/web-hosting/request-has-been-blocked-diagnosis).

:::

<details>

<summary>Encomendei um nome de domínio com acentos e este aparece de forma estranha na consola OVHcloud. O que devo fazer?</summary>

Não precisa de realizar nenhuma ação nesta situação. Mesmo que o seu domínio apareça em [notação internacionalizada (IDN)](https://en.wikipedia.org/wiki/Internationalized_domain_name) na consola OVHcloud, funcionará e será apresentado de forma perfeitamente normal noutros locais. O endereço Web do seu site será apresentado tal como o pediu. Os seus endereços de e-mail também serão apresentados como pretende aos seus correspondentes.

:::danger
É desaconselhado utilizar um endereço de e-mail com um nome de domínio IDN (Internationalized Domain Name) a partir de um cliente de e-mail (Outlook, Mail de macOS, etc.). Alguns clientes de correio eletrónico não interpretam nomes de domínio com caracteres acentuados, o que bloqueia a transmissão de correio eletrónico. Um remetente que lhe envie um e-mail receberá uma mensagem automática indicando que o seu endereço de e-mail não existe.

**Recomenda-se a reserva do mesmo domínio sem acentos, em complemento do seu nome de domínio com caracteres acentuados, a fim de evitar incompatibilidades na troca de e-mails.**

:::

</details>
