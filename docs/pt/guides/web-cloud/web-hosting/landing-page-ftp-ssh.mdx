## Aceder ao seu alojamento web por FTP, SFTP e SSH

Transfira os seus ficheiros e faça a gestão do seu alojamento web OVHcloud através dos protocolos FTP, SFTP e SSH. Esta página reúne os guias para se ligar com um cliente (FileZilla, Cyberduck, Visual Studio Code), gerir os seus acessos FTP e ligar-se por SSH, através do PuTTY ou diretamente na linha de comandos.

Para se orientar consoante a sua necessidade:

- **Pretende transferir ficheiros para o seu alojamento web?** Consulte a secção *Ligar-se por FTP/SFTP* (FileZilla, Cyberduck, Visual Studio Code).
- **Pretende gerir os seus utilizadores e palavras-passe FTP?** Consulte a secção *Gerir os acessos FTP* (utilizadores, palavras-passe, SFTP).
- **Trabalha na linha de comandos?** Consulte a secção *Acesso SSH e ferramentas de linha de comandos* (SSH, PuTTY, SCP, SVN).
