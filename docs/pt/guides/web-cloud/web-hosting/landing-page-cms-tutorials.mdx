## Instalar um CMS no seu alojamento web

Um CMS (Content Management System, ou sistema de gestão de conteúdos) é um software que permite criar e gerir um website sem programar, a partir de uma interface de administração.

Instale o CMS da sua escolha no seu alojamento web OVHcloud. Esta página reúne os guias de instalação manual dos principais CMS (WordPress, Joomla, PrestaShop, Drupal e mais), ou a instalação de um módulo num clique diretamente a partir da sua área de cliente OVHcloud.

Para se orientar consoante a sua necessidade:

- **Está a pensar instalar um CMS para o seu website?** Consulte a secção *Como instalar um CMS*.
- **Pretende instalar um dos CMS mais utilizados (WordPress, Joomla, PrestaShop, Drupal)?** Consulte a secção *Os CMS mais utilizados*.
- **Procura instalar outro CMS (Grav, Pico, Typo3, SPIP)?** Consulte a secção *Outros CMS*.
