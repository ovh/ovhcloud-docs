## Objetivo

É possível que apareça no browser a página de erro “**Site não instalado**”, nomeadamente durante a primeira instalação do seu website.

<img className="thumbnail" alt="website not installed" src="/images/assets/screens/other/browsers/errors/site-not-installed.png" loading="lazy" />

**Saiba como identificar e resolver a página de erro "Site não instalado"**

[[fragment:support-scope]]

:::info
Alguns procedimentos deste guia aplicam-se à <ManagerLink to="/beta/#/">nova versão da Área de Cliente OVHcloud</ManagerLink>.
Existe um lembrete no início de cada secção afetada.

## Requisitos

- Dispor de um serviço [de alojamento partilhado](/links/web/hosting)
- Dispor igualmente da gestão da [Zona DNS](/guides/web-cloud/domains/dns-zone-edit) à qual está associada o seu domínio.

## Instruções

A página “**Site não instalado**” é apresentada por dois motivos:

- 1: [O seu nome de domínio ou subdomínio não está declarado corretamente num dos sites web presentes no seu alojamento web](#check-my-websites).
- 2: [O seu domínio não aponta para o endereço IP da sua oferta de alojamento web.](#check-dns-domain)

Os passos seguintes irão permitir-lhe corrigir o erro `Site não instalado` nestes dois casos.

### 1 - Verificar a declaração do seu nome de domínio ou subdomínio no seu site web presente no seu alojamento web <a name="check-my-websites"></a>

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

:::info
Esta secção aplica-se à <ManagerLink to="/beta/#/">nova versão da Área de Cliente OVHcloud</ManagerLink>.

:::

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting/sites">Alojamentos</ManagerLink> e escolha o alojamento web correspondente.

    <img className="thumbnail" alt="Alojamentos" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Na página que se abrir, clique no separador <code className="action">Meus sites</code>.

    <img className="thumbnail" alt="Meus sites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na tabela que aparece, clique no botão <code className="action">></code> à esquerda do nome do site web relevante para visualizar os nomes de domínio e subdomínios associados.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />

    |Cenários|Ações a tomar|
    |---|---|
    |O nome de domínio ou subdomínio associado ao seu site web **aparece** na tabela.|Se acabou de adicionar o seu nome de domínio ou subdomínio ao seu site web no seu alojamento web, aguarde cerca de **vinte minutos** e, em seguida, atualize o cache do seu navegador Internet. Se a mensagem "Site não instalado" continuar a aparecer, passe para a [parte 2](#check-dns-domain).|
    |O nome de domínio ou subdomínio associado ao seu site web **não aparece** na tabela.|Adicione o seu nome de domínio ou subdomínio seguindo o nosso guia "[Como associar um nome de domínio a um site web existente?](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".|
    |O nome de domínio ou subdomínio **foi removido** da tabela sem qualquer ação por sua parte.|O seu nome de domínio ou a sua zona DNS podem estar a ser geridos a partir de outra conta. Adicione o seu nome de domínio ou subdomínio seguindo o nosso guia "[Como associar um nome de domínio a um site web existente? - Adicionar um nome de domínio externo](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".|
  </Tab>
</Tabs>

### 2 - Verifique o apontamento de IP na zona DNS ativa do seu domínio <a name="check-dns-domain"></a>

Este passo consiste em verificar se o seu domínio ou subdomínio aponta corretamente para o endereço IP do seu alojamento web, a partir da sua zona DNS ativa.

:::info
Para saber mais sobre a noção de DNS, consulte as seguintes páginas:

- [Editar uma zona DNS da OVHcloud](/guides/web-cloud/domains/dns-zone-edit);
- [Criar uma zona DNS da OVHcloud para um domínio](/guides/web-cloud/domains/dns-zone-create);
- [Alterar os servidores DNS de um nome de domínio OVHcloud](/guides/web-cloud/domains/dns-server-edit).

:::

#### 2\.1 Identificar o endereço IP do seu alojamento web da OVHcloud

Clique nos separadores abaixo para visualizar cada uma das **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/#/web/hosting">Alojamentos</ManagerLink> e escolha o alojamento web correspondente.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    No marco **Informações gerais**, encontrará **IPv4**.

    <img className="thumbnail" alt="find-ipv4-and-ipv6" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-ipv4-and-ipv6.png" loading="lazy" />

Copie o endereço IPv4 e continue a ler o guia.
  </Tab>
</Tabs>

Pode também consultar o endereço IP associado ao seu alojamento web no nosso guia "[Alojamento web - Lista dos endereços IP por cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)".

#### 2\.2 Verifique o endereço IP anotado na zona DNS ativa do seu domínio

A seguir, deve verificar se o endereço IP do alojamento web está indicado na zona DNS ativa do domínio.

:::info
Antes de prosseguir, a partir do momento em que ocorre uma modificação na **zona DNS** ativa de um domínio, poderá ser necessário um prazo de propagação de **4 a 24 horas** para atualizar as informações sobre a rede DNS.

Se modificar diretamente os **servidores DNS** associados ao seu domínio, este prazo pode ir até **48 horas**, no máximo.

:::

Para isso, clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/#/web/hosting">Alojamentos</ManagerLink> e escolha o alojamento web correspondente.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    A tabela que aparece apresenta para cada linha um registo DNS associado ao seu domínio na OVHcloud. Esta opção permite filtrar o conteúdo da tabela por tipo de registo ou por nome de domínio.

    <img className="thumbnail" alt="dns zone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/tab.png" loading="lazy" />

    :::info
    Se o separador <code className="action">Zona DNS</code> do seu domínio aparecer da seguinte forma:<br/><br/> <img className="thumbnail" alt="zone-without-domain-top-of-the-page" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/zone-without-domain-top-of-the-page.png" loading="lazy" /><br/>

    Isto significa que o seu nome de domínio não é gerido a partir da sua área de cliente OVHcloud.<br/> Determine o seu "gabinete de registo" e os servidores DNS aos quais está associado através do nosso ferramenta [WHOIS](/links/web/domains-whois).<br/> Encontre e modifique a zona DNS relevante, seguindo a secção dedicada do guia "[Como associar um nome de domínio a um site web existente? - Adicionar um nome de domínio externo](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".
    :::

    Vá para a etapa 4 para visualizar os diferentes cenários possíveis e as ações a realizar.
  </Tab>
  <Tab label="Etapa 3">
    |Cenários possíveis|Ação a ser realizada|
    |---|---|
    |Na zona DNS ativa, o seu domínio ou subdomínio aponta para o endereço IP do seu alojamento web com um registo de tipo A (para um endereço IPv4) ou AAAA (para um endereço IPv6).<br/><br/><img className="thumbnail" alt="Zona DNS filtrada pelos registos A" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-a.png" loading="lazy" />|Isto indica que a configuração do seu domínio está correta.<br/>Aguarde o tempo para a propagação DNS recente alteração.<br/><br/>Reinicie os seus dispositivos (PC, smartphone, box, etc.) e esvazie a cache do seu browser. A antiga configuração do domínio pode ainda ser conservada em cache, o que pode atrasar a apresentação da atualização.|
    |A zona DNS ativa não contém registos do tipo A ou AAAA que liguem o seu domínio ou subdomínio ao endereço IP do seu alojamento web.|Adicione o novo registo DNS do tipo A ou AAAA ou corrija o registo existente seguindo [este manual](/guides/web-cloud/domains/dns-zone-edit).|
    |O registo DNS de tipo A ou AAAA existente na zona DNS para o seu domínio ou subdomínio aponta para um endereço IP diferente do do seu alojamento web.|Adicione o novo registo DNS de tipo A ou AAAA ou corrija o registo existente seguindo [este manual](/guides/web-cloud/domains/dns-zone-edit).|
    |Este aviso aparece no separador <code className="action">Zona DNS</code>:<br/><br/><img className="thumbnail" alt="message-other-ovh-dns-servers" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/message-other-ovh-dns-servers.png" loading="lazy" />|Modifique os servidores DNS do seu domínio de acordo com o nosso guia "[Alterar os servidores DNS de um nome de domínio OVHcloud](/guides/web-cloud/domains/dns-server-edit)"|.
  </Tab>
</Tabs>
