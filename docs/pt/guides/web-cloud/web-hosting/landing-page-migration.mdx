## Migrar o seu website para a OVHcloud

Migre o seu website e os seus dados para o seu alojamento web OVHcloud. Esta página reúne os guias para migrar um site completo para a OVHcloud, exportar e importar os seus dados (ficheiros e base de dados) e gerir os casos associados, como a mudança de domínio.

Para se orientar consoante a sua necessidade:

- **Pretende migrar um site completo, WordPress ou Xara?** Consulte a secção *Migrar um website para a OVHcloud*.
- **Pretende exportar ou importar o seu website e as suas bases de dados?** Consulte a secção *Exportar e importar os seus dados*.
- **Pretende migrar para um VPS, mudar de domínio ou passar de MySQL para Percona?** Consulte a secção *Outras migrações*.
