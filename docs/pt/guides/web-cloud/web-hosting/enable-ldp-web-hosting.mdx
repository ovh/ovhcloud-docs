## Objetivo

Um log é um evento ocorrido num sistema informático (servidor, computador, aplicação, site, base de dados, rede informática, etc.).
Por exemplo, um log pode registar e conter um ou vários dos seguintes elementos:

- A data e hora (data, hora, minuto, segundo, etc.) do evento.
- A natureza do evento (ligação, desconexão, erro, download, upload, alerta, etc.).
- Informações complementares sobre o evento (página ou ficheiro consultado, aplicação iniciada, servidor remoto contactado, nome de um ficheiro carregado ou transferido, etc.).
- A origem do evento (identificador do utilizador, endereço IP de origem, programa de origem, etc.).
- O estado do sistema onde decorre o evento (recursos disponíveis, memória restante, utilização do CPU, etc.).

Na maior parte dos casos, os logs são gerados diretamente pelos sistemas informáticos onde os eventos ocorrem.
São armazenados e historizados em ficheiros de texto, também designados por ficheiros de logs.

Por conseguinte, os ficheiros de logs permitem:

- Analisar o comportamento do sistema informático que gera os logs.
- Identificar os erros ocorridos no sistema informático.
- Resolver os erros encontrados no sistema informático.
- Otimizar o desempenho do sistema informático.

A sua oferta de [alojamento web](/links/web/hosting) gera, portanto, os seus próprios logs.

Em determinadas situações, poderá ter de consultar ou recuperar os logs:

- do seu alojamento web;
- de um dos sites ou de uma das aplicações presentes no seu alojamento web.

**Saiba como ativar, visualizar e gerir os logs dos sites ou das aplicações presentes no seu alojamento web.**

:::warning
Disponibilizamos-lhe este guia para o ajudar a realizar da melhor forma as tarefas mais comuns. No entanto, recomendamos que recorra a um [prestador especializado](/links/partner) caso tenha dificuldades. Com efeito, não poderemos prestar-lhe assistência na interpretação dos logs disponíveis com o seu alojamento web. Encontrará mais informações na secção ["Saiba mais"](#go-further) deste guia.
:::

### Subscrever os logs da sua oferta de alojamento web na Logs Data Platform <a name="webhosting-ldp"></a>

A [Logs Data Platform](/links/manage-operate/ldp) é uma plataforma que permite gerir os seus logs. Pode ser-lhe útil se dispuser de uma infraestrutura muito grande ou se os seus serviços gerarem uma enorme quantidade de logs. Com efeito, esta plataforma foi concebida para facilitar a agregação e a gestão dos logs.

Funciona recuperando os logs gerados pela sua infraestrutura, pelos seus sites ou ainda pelas suas aplicações para, por exemplo:

- armazená-los;
- apresentá-los em painéis de controlo em tempo real;
- permitir aos utilizadores efetuar consultas complexas;
- filtrá-los por data, aplicação, tipo ou conteúdo;

Para mais detalhes sobre a Logs Data Platform, consulte o nosso guia [Introdução à Logs Data Platform](/guides/manage-and-operate/observability/logs-data-platform/introduction) (EN).

Uma vez que as ofertas de [alojamento web](/links/web/hosting) podem ser utilizadas com inúmeros serviços (bases de dados, etc.), pode subscrevê-las por fluxo de dados na Logs Data Platform, para além dos logs em tempo real já disponíveis.

Com uma conta Logs Data Platform, dispõe gratuitamente de **1 GB** de retenção de logs. Para beneficiar disso, deve [ativar gratuitamente a sua conta Logs Data Platform](/guides/manage-and-operate/observability/logs-data-platform/getting-started-quick-start) e subscrever o seu alojamento web a um fluxo de dados.

:::danger
Em função:

- Dos logs gerados pelo seu alojamento web
- Do número de alojamentos web subscritos na sua conta Logs Data Platform

o **1 GB** de dados pode ser consumido mais ou menos rapidamente.

Com efeito, e em função das suas utilizações, este consumo de dados pode representar um volume de logs que pode ir de alguns dias até alguns meses ou mesmo anos.

Se pretender dispor de um volume superior a **1 GB** para a retenção dos seus logs, pode subscrever uma oferta paga complementar.
:::
