## WordPress no seu alojamento web

Crie, faça a gestão e proteja os seus sites WordPress no seu alojamento web OVHcloud. Esta página reúne os guias para instalar e começar com o WordPress, utilizá-lo no dia a dia (WooCommerce, ficheiro .htaccess, cópia de segurança) e administrar vários sites WordPress com o plugin MainWP.

Para se orientar consoante a sua necessidade:

- **É novo no WordPress?** Consulte a secção *Instalar e começar com WordPress* (primeiros passos, módulo 1 clique, instalação manual, migração).
- **O seu site WordPress já está online?** Consulte a secção *Utilizar e gerir o WordPress* (WooCommerce, .htaccess, palavra-passe de administrador, cópia de segurança).
- **Administra vários sites WordPress?** Consulte a secção *Gerir vários sites com MainWP* (administração, cópia de segurança, segurança, clientes).
