## Objetivo

No seu alojamento web OVHcloud, pode utilizar scripts para automatizar certas operações. Uma tarefa planificada ("tarefa CRON") permite que os seus scripts sejam executados em momentos específicos sem que seja necessário mais ações da sua parte.

**Saiba como criar tarefas CRON para automatizar as tarefas planeadas num alojamento web.**

[[fragment:support-scope]]

## Requisitos

- Ter um serviço de [alojamento web da OVHcloud](/links/web/hosting)

[[cpnav:web-hosting-console]]

## Instruções

### Criação de uma tarefa automatizada

Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Cron</code>.

    <img className="thumbnail" alt="Separador Cron de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Terá uma visão geral das tarefas planeadas e dos respetivos parâmetros: cada tarefa é apresentada sob a forma de uma caixa que indica o seu comando, o seu **Estado**, a sua **Frequência**, a sua **Linguagem** e o **E-mail** de relatório.

    Para criar uma tarefa CRON, clique no botão <code className="action">Criar uma tarefa</code>.

    <img className="thumbnail" alt="Caixas das tarefas planeadas e botão Criar uma tarefa" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/tasks.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Personalize os parâmetros da tarefa no painel **Criar uma tarefa cron** que aparece.

    <img className="thumbnail" alt="Painel Criar uma tarefa cron em modo Simples" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/create-task.png" loading="lazy" />

    |Opção|Descrição|
    |---|---|
    |Comando|Defina o caminho de acesso ao ficheiro que contém o script, relativo à raiz do seu alojamento. Exemplo: www/jobs/cron.php|
    |Frequência|Defina a frequência de execução da tarefa (ver abaixo).|
    |Linguagem|Selecione a versão PHP utilizada pelo script.|
    |Descrição|Introduza uma descrição para seguir a execução das suas tarefas.|
    |E-mail de relatório|Se necessário, indique o endereço de e-mail para o qual será enviado um relatório em caso de erro de execução.|

    A tarefa é ativada assim que é criada. Se não quiser que seja executada de imediato, desative-a em seguida (consulte a secção [Modificar ou eliminar uma tarefa agendada](#modificar-ou-eliminar-uma-tarefa-agendada)).

    Para a **Frequência**, a interface oferece dois modos:

    - **Simples**: escolha uma frequência predefinida na lista (todas as horas, todos os dias à meia-noite ou ao meio-dia, todas as segundas-feiras à meia-noite, no dia 1 de cada mês à meia-noite).
    - **Avançado**: introduza uma expressão como numa *crontab*, cujas posições correspondem, por ordem, a **Min**, **Hora**, **Dia**, **Mês** e **Dia sem.**. A interface traduz a expressão em linguagem clara por cima do campo e lembra a função dos caracteres `*` (qualquer valor), `,` (separador de lista), `-` (intervalo de valores) e `/` (passo). Por exemplo, `0 * * * *` executa a tarefa **uma vez por hora todos os dias**, ao minuto 0.

    <img className="thumbnail" alt="Frequência em modo Avançado com a expressão cron e a sua tradução" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/create-task-advanced.png" loading="lazy" />

    :::info
    A posição **Dia** permite definir frequências de execução num ciclo mensal.

    A posição **Dia sem.** permite definir frequências de execução complementares mas com um ciclo semanal.
    :::

    Pode alternar entre os dois modos durante a configuração. Tenha em atenção as [limitações durante o planeamento de uma tarefa num alojamento web](#limitações-das-tarefas-planificadas-no-seu-alojamento-web).

    Se estiver tudo correto, clique em <code className="action">Criar</code>.

    A tarefa estará pronta dentro de alguns minutos. Pode alterar todos os seus parâmetros ou eliminar a tarefa através do botão <code className="action">⋮</code> situado no canto superior direito da respetiva caixa.
  </Tab>
</Tabs>

### Limitações das tarefas planificadas no seu alojamento web

|Funcionalidade|Descrição|
|---|---|
|Planeamento horário|Os minutos são ignorados pelo alojamento: uma tarefa só pode ser executada uma vez por hora, sendo a frequência de repetição mais baixa que pode ser especificada. Em modo **Avançado**, indique um minuto fixo (por exemplo `0`): a interface avisa-o se não for o caso.|
|Duração|A duração de execução de uma tarefa é de 60 minutos. Se um script ultrapassar este tempo de execução, será automaticamente interrompido pelo sistema.|
|Variáveis|Apenas pode definir variáveis num script. Adicioná-las ao URL que chama o script não funcionará (Exemplo: www/jobs/cron.php?variável=value).|
|Limite de dados|Uma tarefa só pode gerar 5 MB de dados (*stdin/stderr*). Por exemplo, se um script escrever dados num ficheiro .txt, a execução será automaticamente interrompida quando o ficheiro atingir 5 MB.|
|Scripts que produzem erros|Se um script falhar, ele será automaticamente desativado após 10 tentativas de execução com falha. O relatório de erro só será enviado quando as 10 tentativas tiverem falhado.<br/>Corrija o script em função do relatório de erro recebido e reative a "tarefa CRON" a partir do separador <code className="action">Cron</code> (clique em <code className="action">⋮</code> na caixa da tarefa e, a seguir, em <code className="action">Ativar</code>).|
|Relatórios de execução|Os relatórios só serão enviados para o endereço eletrónico selecionado uma vez por dia (durante as horas noturnas).|

### Reparação

#### Teste do seu script com um browser

Um teste simples para ver se o script vai produzir um erro é executá-lo num browser. Por exemplo, se o caminho de acesso do seu script for "www/cron.php" e o seu domínio de alojamento for "mypersonaldomain.ovh", deve utilizar o URL "http://<i></i>mypersonaldomain.ovh/cron.php". Se não aparecer nenhum erro, mas o script não funcionar como previsto, siga as sugestões abaixo.

#### Verificação da utilização dos caminhos absolutos

Tenha o cuidado de utilizar caminhos de acesso absolutos aos ficheiros dos seus scripts. A constante "DIR", por exemplo, pode ajudar a receber o caminho corrente nos scripts PHP ([documentação PHP](https://www.php.net/manual/en/language.constants.predefined.php)).

#### Verificação dos logs de execução

Nos logs do seu alojamento web, acessíveis a partir da <ManagerLink to="/beta/#/">consola OVHcloud</ManagerLink>, poderá ver a categoria de log intitulada "CRON".

Para mais informações, consulte o nosso guia ["Consultar as estatísticas e os logs do meu site alojado numa oferta partilhada"](/guides/web-cloud/web-hosting/logs-and-statistics).
