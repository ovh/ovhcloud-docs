## Gerir um CMS num clique no seu alojamento web

Um CMS (Content Management System, ou sistema de gestão de conteúdos) é um software que permite criar e gerir um website sem programar, a partir de uma interface de administração. Um módulo num clique instala e pré-configura automaticamente um CMS (WordPress, PrestaShop, Joomla, etc.) no seu alojamento web OVHcloud, diretamente a partir da sua área de cliente e sem instalação manual.

Esta página reúne os guias para instalar e gerir um módulo num clique, alterar a palavra-passe de administrador e proteger o acesso ao seu CMS.

Para se orientar consoante a sua necessidade:

- **Pretende instalar ou gerir um CMS num clique?** Consulte a secção *Módulo num clique*.
- **Precisa de administrar ou proteger o seu CMS (palavra-passe, acesso à área de administração)?** Consulte a secção *Administrar e proteger um CMS*.

## Instalar um CMS manualmente

A instalação num clique não cobre todos os CMS. Também pode instalar manualmente o CMS da sua escolha (WordPress, Joomla, PrestaShop, Drupal e mais) no seu alojamento web.

Consulte a página [Instalar um CMS](/guides/web-cloud/web-hosting/landing-page-cms-tutorials).
