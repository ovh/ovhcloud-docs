## Objetivo

Este guia mostra-lhe as etapas para exportar todos os elementos do seu website para o formato padrão, a partir de um [alojamento web OVHcloud.](/links/web/hosting).

**Descubra como exportar o seu website OVHcloud.**

## Requisitos

- Ter um [plano de alojamento web OVHcloud](/links/web/hosting).

[[cpnav:web-hosting]]

## Instruções

### 1 - Recuperação dos ficheiros do seu espaço de armazenamento FTP

#### 1.1 Aceder ao espaço de armazenamento

Para se ligar ao seu espaço de armazenamento, deve dispor dos seguintes elementos:

- o nome de utilizador FTP ou SSH ativo;
- a palavra-passe associada ao nome de utilizador FTP ou SSH;
- o endereço do servidor;
- a porta de ligação ao servidor.

Estes elementos foram-lhe enviados no e-mail enviado após a instalação do seu alojamento web.

Se não possuir estas informações, clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Separador FTP-SSH de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Aparecerá a informação relativa ao seu espaço de armazenamento. A secção **Transferência de ficheiros (FTP/SFTP)** reúne os elementos necessários para aceder ao mesmo:

    - **Anfitrião**: o endereço do servidor;
    - **Nome de utilizador**: o identificador da conta principal;
    - **Método de ligação aos ficheiros**: a porta de ligação, **22** para o SFTP ou **21** para o FTP.

    <img className="thumbnail" alt="Secções Transferência de ficheiros e Acesso SSH e tabela dos utilizadores" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/tab-pro.png" loading="lazy" />

    Os outros utilizadores criados no seu alojamento web estão listados na secção **Utilizadores FTP e SSH**.

    Caso seja necessário, consulte o nosso manual: ["Aceder ao espaço de armazenamento do alojamento web"](/guides/web-cloud/web-hosting/ftp-connection).

    A palavra-passe não é apresentada na consola OVHcloud. Caso a tenha perdido, consulte o manual ["Modificar a palavra-passe de um utilizador FTP"](/guides/web-cloud/web-hosting/ftp-change-password).
  </Tab>
</Tabs>

Quando tiver obtido todos os elementos, a recuperação dos seus ficheiros no espaço de armazenamento pode ser realizado de duas formas:

- **Utilizar um programa compatível com o protocolo FTP ou SFTP**: terá de instalar no seu computador um programa compatível, como o [FileZilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide). Sugerimos que contacte o editor do programa instalado caso deseje obter ajuda na sua utilização, OVHcloud não criou esse programa;

- **Utilizar um acesso SSH**: terá de utilizar comandos a partir de um terminal para interagir com o seu espaço de armazenamento. Este tipo de acesso requer conhecimentos mais avançados, bem como um [plano de alojamento web da OVHcloud](/links/web/hosting) específica. Para mais informações, pode consultar o nosso guia ["Utilizar o acesso SSH do seu alojamento web"](/guides/web-cloud/web-hosting/ssh-on-webhosting). 

#### 1.2 Transferir os ficheiros a partir do seu espaço de armazenamento

Uma vez ligado ao seu espaço de armazenamento e consoante os seus sítios web alojados, vários diretórios podem aparecer.

Se necessário, identifique previamente no seu alojamento web o nome do diretório principal em que o seu sítio web está armazenado. Para isso, clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Os meus sites</code>.

    <img className="thumbnail" alt="Separador Os meus sites de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na tabela, identifique a linha do seu site através da coluna **Site** e, a seguir, consulte a sua coluna **Pasta raiz**. Trata-se do diretório onde se encontram os ficheiros e pastas do seu site.

    <img className="thumbnail" alt="Tabela dos sites e a sua coluna Pasta raiz" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/root-folders.png" loading="lazy" />
  </Tab>
</Tabs>

Ainda ligado ao seu espaço de armazenamento, basta descarregar os ficheiros do seu sítio web ao aceder à pasta raiz identificada anteriormente.

### 2 - Recuperar o backup da sua base de dados (opcional) 

:::info
Esta etapa é opcional se o seu website não utiliza uma base de dados.

:::

Para recuperar um backup da sua base de dados, consulte o nosso guia:
["Recuperar o backup da base de dados de um alojamento web"](/guides/web-cloud/web-hosting/sql-database-export).

Se utiliza uma base de dados **Web Cloud Databases** para o seu website, consulte a secção dedicada ao backup no nosso guia:
[Backup e exportação de uma base de dados no servidor de bases de dados](/guides/web-cloud/databases/db-backup-export-database-server).

### 3 - Recuperar os logs do seu alojamento OVHcloud

Consulte o nosso guia dedicado: [Alojamento web - Consultar as estatísticas e os logs de um site](/guides/web-cloud/web-hosting/logs-and-statistics).
