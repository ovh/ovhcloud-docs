## Objetivo

Ao longo da utilização dos seus serviços, pode vir a ter necessidade de conhecer o nome do servidor SQL onde se encontra a sua base de dados (incluída ou adquirida como complemento através do seu [alojamento web](/links/web/hosting)).

:::warning
Este guia não se aplica às bases de dados presentes numa solução [Web Cloud Databases](/links/web/databases).

:::

**Saiba como encontrar o nome do servidor que aloja a sua base de dados partilhada, acessível com o seu alojamento web.**

## Requisitos

- Dispor de uma [oferta de alojamento web OVHcloud](/links/web/hosting).
- Utilizar uma base de dados incluída ou [adquirida como complemento](/links/web/hosting-options-startsql) através do seu alojamento web.

[[cpnav:web-hosting-console]]

## Instruções

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Bases de dados</code>.

    <img className="thumbnail" alt="Separador Bases de dados de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na tabela, identifique a linha da base de dados em causa através da coluna **Nome do banco** e consulte a sua coluna **Endereço do servidor**.

    <img className="thumbnail" alt="Tabela das bases de dados e a sua coluna Endereço do servidor" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/tab.png" loading="lazy" />

Encontrará o nome do servidor SQL (por exemplo: **mysqlXXX.euXXX**) onde a sua base de dados partilhada está alojada.

    :::warning
    Apesar do seu título, esta coluna apresenta o **servidor**, e não o endereço de ligação à sua base de dados. Trata-se de duas noções distintas:

    - O **servidor** representa a infraestrutura que aloja a sua base de dados, bem como outras bases. O seu nome permite verificar se está afetado por uma operação de manutenção ou um incidente declarado na nossa página [Web Cloud Status](https://web-cloud.status-ovhcloud.com/).
    - O **endereço do servidor** faz parte dos identificadores de ligação específicos à sua base de dados e permite ligar o seu site web a esta.

    :::

  </Tab>
</Tabs>
