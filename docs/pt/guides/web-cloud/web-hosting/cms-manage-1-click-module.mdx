## Objetivo

Os módulos 1 clique permitem a instalação fácil e rápida de um software on-line de assistência à criação de um website (vulgarmente denominado "CMS"). A OVHcloud propõe-lhe os mais conhecidos: WordPress, PrestaShop, Drupal e Joomla!.

**Saiba como gerir o módulo 1 clique na consola OVHcloud.**

[[fragment:support-scope]]

## Requisitos

<Region zones={['eu']}>
- Ter um [serviço de alojamento Web Cloud](/links/web/hosting) que permite a instalação de um módulo 1 clique (apenas o [alojamento gratuito](/guides/web-cloud/web-hosting/activate-start10m) não está abrangido).
</Region>
<Region zones={['ca', 'apac']}>
- Ter um [serviço de alojamento Web Cloud](/links/web/hosting) que permite a instalação de um módulo 1 clique.
</Region>
- Ter criado um módulo 1 clique no alojamento (Se ainda não o fez, siga as instruções deste [manual](/guides/web-cloud/web-hosting/cms-install-1-click-modules)).

[[cpnav:web-hosting]]

## Instruções

### Aceder ao seu site

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Módulos</code>. Os seus módulos instalados são apresentados, cada um numa caixa com o seu nome.

    <img className="thumbnail" alt="Separador Módulos de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">

    <img className="thumbnail" alt="Apresentação em tabela dos módulos e menu de uma linha" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/row-actions-menu.png" loading="lazy" />

</Tabs>

### Modificar a palavra-passe do seu módulo <a name="password-change"></a>

Pode gerar uma nova palavra-passe de administrador para o seu módulo a partir da consola OVHcloud. Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Módulos</code>.

    <img className="thumbnail" alt="Separador Módulos de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Clique no botão <code className="action">⋮</code> situado à direita do nome do seu módulo e, a seguir, em <code className="action">Alterar palavra-passe</code>.

    <img className="thumbnail" alt="Menu de ações de um módulo instalado no separador Módulos" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/card-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    A janela **Regenerar palavra-passe** abre-se e recorda o módulo em causa. Clique em <code className="action">Regenerar</code>: é gerada automaticamente uma nova palavra-passe, que lhe é enviada por e-mail.
  </Tab>
</Tabs>

Para definir uma nova palavra-passe por si próprio, utilize a interface de administração do seu CMS.

:::info
Poderá consultar a documentação oficial para os diferentes CMS propostos em instalação nos nossos alojamentos partilhados:

- WordPress: [https://wordpress.org/support/article/resetting-your-password/](https://wordpress.org/support/article/resetting-your-password/)
- Joomla!: [https://docs.joomla.org/How_do_you_recover_or_reset_your_admin_password%3F](https://docs.joomla.org/How_do_you_recover_or_reset_your_admin_password%3F)
- Drupal: O editor deste programa não propõe, à data, documentação para alterar a palavra-passe de acesso à interface de administração do Drupal. Sugerimos que contacte diretamente o editor sobre este assunto. Para mais informações, consulte a página oficial [drupal.org](https://www.drupal.org/).
- PrestaShop: O editor deste software não propõe, à data, documentação para alterar a palavra-passe de acesso à interface de administração do PrestaShop. Sugerimos que contacte diretamente o editor sobre este assunto. Para mais informações, consulte a [página oficial do PrestaShop](https://www.prestashop.com).

:::

Também pode alterar a palavra-passe de acesso à interface de administração do seu CMS diretamente a partir da sua base de dados.

No entanto, se encontrar dificuldades, recomendamos vivamente que efetue a operação com a documentação proposta pelo editor do seu CMS ou que recorra a um [fornecedor especializado](/links/partner). Não poderemos proporcionar-lhe assistência técnica. Para mais informações, aceda à secção [Quer saber mais?](#go-further) deste manual.

### Eliminar o módulo

:::warning
O backup dos seus dados faz parte das operações essenciais à [segurança dos seus websites](/guides/web-cloud/web-hosting/secure-your-website). Sugerimos que importe regularmente e **antes de eliminar** o backup dos seus dados para um suporte local, como uma pen USB ou um disco rígido externo, de acordo com as instruções do nosso guia "[Exportar o seu website](/guides/web-cloud/web-hosting/exporter-son-site-web)".

:::

#### 1 - Identificar a base de dados do módulo <a name="step1"></a>

Para eliminar o módulo 1 clique, deve começar por identificar a sua base de dados de forma **segura**.

Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e escolha o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Bases de dados</code>.

    <img className="thumbnail" alt="Separador Bases de dados de um alojamento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Se dispõe de uma única base de dados neste separador e não dispõe de soluções [Web Cloud Databases](/links/web/databases), pode considerar que se trata da do seu site.

    <img className="thumbnail" alt="Tabela das bases de dados e as suas colunas" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/tab-no-spotlight.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Caso contrário, dirija-se ao separador <code className="action">Os meus sites</code>. Registe o nome presente na coluna **Pasta raiz** na linha do site em questão: trata-se do diretório onde se encontram os ficheiros que constituem o seu módulo 1 clique no servidor FTP.

    <img className="thumbnail" alt="Tabela dos sites e a sua coluna Pasta raiz" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/root-folders.png" loading="lazy" />
  </Tab>
</Tabs>

Aceda ao [espaço FTP](/guides/web-cloud/web-hosting/ftp-connection) do seu alojamento. Abra a `Pasta raiz` encontrada anteriormente no separador <code className="action">Os meus sites</code> e procure o ficheiro de configuração do seu módulo:

- Para WordPress: **"wp-config.php"** (o nome da base de dados aparece com a menção **"DB_NAME"**).
- Para Joomla!: **"configuration.php"** (o nome da base de dados aparece com a menção **"public $db"**).
- Para o Drupal: **"settings.php"** (Para encontrá-lo, aceda à pasta **"sites"** e **"default"**. O nome da base de dados aparece sob a menção **"database"**).
- Para PrestaShop: **"parameters.php"** (Para o encontrar, aceda à pasta **"app"** e **"config"**. O nome da base do módulo aparece na rubrica **"database_name"**).

#### 2 - Guardar o seu módulo

Para guardar o seu site, siga as instruções do nosso guia "[Exportar o seu website](/guides/web-cloud/web-hosting/exporter-son-site-web)" para recuperar os seus ficheiros no espaço FTP do seu alojamento e a sua base de dados.

#### 3 - Eliminar o módulo

:::danger
A eliminação do módulo 1 clique e da base de dados irá também resultar **na eliminação de todos os backups**. Os dados eliminados não poderão ser recuperados posteriormente.

:::

:::warning
A eliminação do módulo 1 clique **não levará automaticamente à eliminação da base de dados**. Se ativar a instalação de um novo CMS sem eliminar previamente a base de dados do anterior (e o alojamento não permitir a criação automática de uma nova base de dados), aparecerá a mensagem "[Ocorreu um erro aquando do carregamento das informações (You need at least one free database)](/guides/web-cloud/web-hosting/diagnostic-errors-module1clic#ocorreu-um-erro-aquando-do-carregamento-das-informações-you-need-at-least-one-free-database)" na consola OVHcloud.

Se já atingiu o número máximo de bases de dados permitido pela sua [solução de alojamento web](/links/web/hosting), deverá eliminar a base de dados identificada [no passo 1](#step1) **ANTES** de poder criar um novo módulo 1 clique.

### Boas práticas

Para proteger o seu site, siga as instruções do nosso guia "[Como proteger o seu website?](/guides/web-cloud/web-hosting/secure-your-website)".

Adicione ferramentas de teste do tipo CAPTCHA aos formulários do seu site.

Não instale no seu site plugins ou templates que não foram recomendados pelas comunidades oficiais do seu CMS: 

- [WordPress](https://wordpress.org/)
- [Joomla!](https://community.joomla.org/)
- [Drupal](https://www.drupal.org/community)
- [PrestaShop](https://www.prestashop.com/pt)
