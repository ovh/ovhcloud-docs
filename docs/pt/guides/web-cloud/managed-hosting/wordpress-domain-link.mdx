## Objetivo

O **Managed Hosting for WordPress** é a solução OVHcloud de alojamento WordPress gerido: a manutenção técnica (atualizações, segurança, cópias de segurança) é assegurada automaticamente. A oferta permite gerir os nomes de domínio a partir da interface OVHcloud, sem intervenção manual. Pode associar um nome de domínio ou um subdomínio a cada um dos seus sites WordPress, qualquer que seja a sua origem.

Estão disponíveis dois procedimentos consoante a sua situação:

- **Nome de domínio interno**: o nome de domínio já se encontra na sua conta OVHcloud.
- **Nome de domínio externo**: o nome de domínio está alojado num outro registador de domínios.

**Descubra como adicionar, modificar ou eliminar os nomes de domínio do seu Managed Hosting for WordPress a partir da sua área de cliente OVHcloud.**

## Requisitos

- Dispor de uma oferta **Managed Hosting for WordPress** ativa com, pelo menos, um site WordPress criado.
- Para um nome de domínio externo: ter acesso à zona DNS (Domain Name System) ativa no seu fornecedor atual.

## Instruções

### 1 - Aceder à gestão dos nomes de domínio

A adição de um nome de domínio efetua-se a partir do separador <code className="action">Os meus sites</code> do seu recurso Managed Hosting for WordPress. Clique nos separadores abaixo para visualizar sucessivamente cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/wordpress">Managed hosting for WordPress</ManagerLink> da sua área de cliente OVHcloud.

    <img className="thumbnail" alt="Vista do recurso Managed Hosting for WordPress na lista dos alojamentos WordPress" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/managed-hosting-for-wordpress.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique em <code className="action">Gerir</code> sob o recurso pretendido.

    <img className="thumbnail" alt="Recurso Managed Hosting for WordPress no datagrid com o botão Gerir destacado" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/manage-ressource-button.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Clique no separador <code className="action">Os meus sites</code>. O datagrid lista os seus sites WordPress com, para cada site, o domínio associado e as ações disponíveis.

    <img className="thumbnail" alt="Separador Os meus sites a apresentar o datagrid dos sites WordPress" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/managed-hosting-for-wordpress-my-sites-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    À direita do site WordPress pretendido, clique no botão <code className="action">⋮</code>, depois em <code className="action">Adicionar um domínio</code>.

    <img className="thumbnail" alt="Botão Adicionar um domínio no menu de ações de um site WordPress no datagrid" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/adding-domain.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
O **primeiro nome de domínio adicionado** a um site WordPress torna-se automaticamente o **nome de domínio principal**. Poderá adicionar outros mais tarde (multidomínio) e alterar o nome de domínio principal a partir do mesmo menu.
:::

<summary>Adicionar um nome de domínio externo</summary>

Assim que o túnel de adição estiver aberto, selecione o procedimento externo para utilizar um nome de domínio alojado num outro registador de domínios. Clique nos separadores abaixo para visualizar sucessivamente cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">

    {/* DRAFT: To screenshot — capturar o botão Confirmar no final do túnel de adição de domínio externo */}
  </Tab>
</Tabs>

:::warning
A propagação DNS de um nome de domínio externo pode demorar até **24 a 48 horas** consoante o seu fornecedor. O seu site WordPress não estará acessível através deste nome de domínio durante este período.
:::

:::info
O certificado SSL (Secure Sockets Layer) é gerado automaticamente após a validação da propagação DNS. Não é necessária qualquer intervenção manual da sua parte.
:::

**Efeitos da eliminação:**

- **O seu site WordPress permanece intacto**: apenas a ligação com o nome de domínio é interrompida, o site continua a funcionar.
- **O URL técnico permanente permanece acessível**: o seu site WordPress mantém-se acessível através deste URL, mesmo sem nome de domínio.
- **O certificado SSL é revogado**: deixa de cobrir o nome de domínio eliminado.
- **O posicionamento SEO pode ser afetado**: caso o nome de domínio tenha sido indexado pelos motores de pesquisa, a sua remoção afeta o posicionamento.
- **Lembre-se de verificar os seus serviços de e-mail**: os endereços associados a este nome de domínio podem ser afetados pela eliminação.

:::info
**Caso particular — nome de domínio principal único:** caso elimine o único nome de domínio principal de um site WordPress, o seu site WordPress passa automaticamente para o seu **URL técnico permanente**. Este URL está sempre acessível e nunca é eliminado, mesmo na ausência de domínio associado.

### O URL técnico permanente

Cada site Managed Hosting for WordPress dispõe de um **URL técnico permanente**, independente de qualquer nome de domínio. Este URL é gerado automaticamente aquando da criação do site WordPress e não pode ser eliminado.

<img className="thumbnail" alt="Vista do datagrid Os meus sites a apresentar o nome de domínio e o URL técnico de um site WordPress" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/show-domain-linked-to-a-site.png" loading="lazy" />

Permite-lhe:

- Aceder ao seu site WordPress **em qualquer circunstância**, mesmo sem nome de domínio associado.
- Testar o seu site WordPress antes de fazer apontar um nome de domínio para o mesmo.
- Manter um acesso de reserva em caso de problema DNS.

:::info
O URL técnico tem a forma `*.mcms.ovh.net` ou semelhante. Encontre-o no datagrid <code className="action">Os meus sites</code>, em frente a cada site WordPress.
:::
