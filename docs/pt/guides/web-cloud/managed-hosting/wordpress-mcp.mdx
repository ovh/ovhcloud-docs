## Objetivo

A sua solução **Managed Hosting for WordPress** pode ser gerida em linguagem natural a partir de um agente de IA (Claude Code, Codex, etc.), graças ao protocolo **MCP** (*Model Context Protocol*). O utilizador liga apenas um servidor: o **MCP OVHcloud**. O seu agente de IA utiliza-o depois para configurar os outros dois: o **MCP for WordPress**, para o conteúdo de um site, e o **MainWP**, para gerir vários sites ao mesmo tempo.

**Saiba como ligar o seu agente de IA ao MCP OVHcloud e como lhe pedir que configure o MCP for WordPress e o MainWP.**

## Requisitos

- Dispor de uma solução [Managed Hosting for WordPress](/guides/web-cloud/managed-hosting/wordpress) ativa com, pelo menos, um site WordPress.
- Dispor de uma conta OVHcloud com acesso a esta solução.
- Utilizar um agente de IA compatível com MCP **instalado no seu computador** e capaz de executar comandos, por exemplo [Claude Code](https://code.claude.com/docs/pt/overview) ou [Codex](https://learn.chatgpt.com/docs/codex/cli).
- Para o MainWP: dispor do [Node.js](https://nodejs.org/pt-br) (versão LTS) no seu computador.

:::info
Um assistente de IA utilizado num browser pode ligar-se ao MCP OVHcloud, mas não ao MCP for WordPress nem ao MainWP: estas duas ligações são guardadas na configuração do agente, no seu computador.
:::

## Introdução

Cada um dos três servidores MCP abrange uma parte da sua solução:

| Servidor MCP | O que o seu agente de IA pode gerir | Como o ligar |
|---|---|---|
| **MCP OVHcloud** | O alojamento: soluções, sites, domínios, versões de PHP, cache CDN, logs, cópias de segurança, palavras-passe SFTP, phpMyAdmin e base de dados | Adiciona-o uma vez e, em seguida, identifica-se com a sua conta OVHcloud |
| **MCP for WordPress** | Um site WordPress: artigos, páginas, multimédia, comentários, menus, definições, plugins, temas e utilizadores | O seu agente de IA configura-o, uma ligação por site |
| **MainWP** | Vários sites ao mesmo tempo a partir do painel de controlo MainWP incluído na sua solução: atualizações, ativação e desativação de plugins, temas e traduções | O seu agente de IA configura-o, uma ligação para toda a solução |

O **MCP for WordPress** é um plugin OVHcloud pré-instalado nos sites da sua solução. Disponibiliza ao seu agente de IA uma lista fechada de ações para gerir o seu site WordPress.

## Instruções

:::warning
O seu agente de IA atua com os direitos que lhe concede: a sua conta OVHcloud para o MCP OVHcloud e uma conta de administrador para o MCP for WordPress. Reveja cada ação que lhe propõe antes de a validar, em particular uma eliminação, uma atualização ou uma publicação.
:::

### Etapa 1: ligar o MCP OVHcloud

O MCP OVHcloud é um servidor remoto alojado pela OVHcloud. Não lhe transmite nenhuma palavra-passe: o seu agente de IA abre a página de início de sessão da OVHcloud no seu browser e identifica-se como na sua Área de Cliente.

Escolha o seu agente de IA nos separadores abaixo.

<Tabs>
  <Tab label="Claude Code">
    Num terminal, execute:

    ```bash
    claude mcp add --transport http --scope user ovhcloud https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    ```

    Inicie o Claude Code, escreva `/mcp`, selecione o servidor **ovhcloud** e, em seguida, **Authenticate**. Identifique-se com a sua conta OVHcloud na página que se abre.

    :::warning
    Não adicione a opção `--header` a este comando. Um cabeçalho `Authorization` fixo impede a identificação OVHcloud: o servidor aparece como ligado, mas cada pedido falha depois com um erro 401.
    :::
  </Tab>
  <Tab label="Codex">
    Num terminal, execute:

    ```bash
    codex mcp add ovhcloud --url https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    codex mcp login ovhcloud
    ```

    Identifique-se com a sua conta OVHcloud na página que se abre e, em seguida, reinicie o Codex.

    {/* DRAFT: To verify — Codex commands (add --url + mcp login) not tested against the OVHcloud hub */}
  </Tab>
  <Tab label="Outro agente de IA">
    Adicione um servidor MCP remoto (transporte *streamable HTTP*) na configuração do seu agente de IA:

    - **URL**: `https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS`
    - **Autenticação**: OAuth, sem cabeçalho nem token a introduzir.

    Inicie a autenticação a partir do seu agente de IA e identifique-se com a sua conta OVHcloud.
  </Tab>
</Tabs>

Para verificar a ligação, peça ao seu agente de IA:

> Lista as minhas soluções Managed Hosting for WordPress e os respetivos sites.

O agente responde com as suas soluções e os endereços dos seus sites.

### Etapa 2: pedir a configuração do MCP for WordPress para um site

Peça ao seu agente de IA, indicando o endereço do seu site:

> Configura o MCP for WordPress do meu site www.example.com

Se não indicar nenhum site, o agente propõe-lhe a lista dos sites da sua solução.

A configuração decorre depois da seguinte forma:

1. **O seu agente de IA pede-lhe autorização** para criar uma senha de aplicação no site. Esta senha permite-lhe atuar no site como administrador, dentro dos limites das ações do MCP for WordPress. Para aceitar, responda explicitamente:

    > Sim, cria a senha de aplicação

    Repetir o seu pedido inicial não equivale a uma autorização: o seu agente de IA aguarda esta resposta antes de continuar.

2. **O seu agente de IA verifica se o plugin MCP for WordPress está ativo** no site. Se não estiver, o agente informa-o: ative o **MCP for WordPress** a partir do menu <code className="action">Plugins</code> da administração WordPress do seu site e, em seguida, repita o seu pedido.
3. **O seu agente de IA cria a senha de aplicação** através do MCP OVHcloud e, em seguida, adiciona a ligação do site à sua configuração. Aprove o comando que o agente executa.
4. **Recarregue os servidores MCP**: no Claude Code, escreva `/mcp` e volte a ligar-se, ou reinicie o Claude Code; no Codex, reinicie-o. As ferramentas do site só aparecem após este recarregamento.

Para verificar a ligação, peça:

> Lista os 5 últimos artigos de www.example.com

Repita esta etapa para cada site a gerir: cada site tem a sua própria ligação.

### Etapa 3: pedir a configuração do MainWP

O painel de controlo MainWP incluído na sua solução gere o conjunto dos seus sites. Peça ao seu agente de IA:

> Configura o MCP MainWP

A configuração segue o mesmo processo da etapa 2:

1. **O seu agente de IA pede-lhe autorização** para criar uma senha de aplicação no painel de controlo MainWP. Para aceitar, responda:

    > Sim, cria a senha de aplicação

2. **O seu agente de IA verifica se o Node.js está instalado** no seu computador. Se não estiver, instale a versão LTS a partir de [nodejs.org](https://nodejs.org/pt-br) e, em seguida, repita o seu pedido.
3. **O seu agente de IA cria a senha de aplicação** através do MCP OVHcloud e, em seguida, adiciona o servidor MainWP à sua configuração. Aprove o comando que o agente executa.
4. **Recarregue os servidores MCP** como na etapa 2.

Para verificar a ligação, peça:

> Lista os sites do meu painel de controlo MainWP e os plugins a atualizar.

:::info
O servidor MainWP está configurado para lhe pedir uma confirmação antes de cada ação que modifique os seus sites.
:::

### Exemplos de pedidos

Depois de ligar os três servidores, formule os seus pedidos como faria a um colega. O seu agente de IA escolhe o servidor adequado.

| Pretende… | Exemplo de pedido |
|---|---|
| Redigir conteúdo | "Redige um rascunho de artigo sobre o nosso horário de verão para www.example.com." |
| Moderar os comentários | "Mostra os comentários a aguardar moderação em www.example.com." |
| Atualizar vários sites | "Que plugins devem ser atualizados no conjunto dos meus sites?" |
| Diagnosticar um erro | "O meu site www.example.com devolve erros 500: consulta os logs e diz-me porquê." |
| Limpar a cache | "Limpa a cache CDN de www.example.com." |
| Fazer uma cópia de segurança de um site | "Exporta uma cópia de segurança completa de www.example.com." |

Antes de publicar um artigo, o seu agente de IA pergunta-lhe qual a conta WordPress que figura como autor.

### Revogar um acesso

Pode retirar a qualquer momento o acesso concedido ao seu agente de IA:

- **MCP for WordPress**: na administração WordPress do site, abra <code className="action">Utilizadores</code> > <code className="action">Perfil</code> e, em seguida, elimine a senha de aplicação na secção **Senhas de aplicação**.
- **MainWP**: proceda da mesma forma na administração WordPress do painel de controlo MainWP.
- **MCP OVHcloud**: remova o servidor da configuração do seu agente de IA, por exemplo com `claude mcp remove ovhcloud` no Claude Code.

### Resolução de problemas

- **O seu agente de IA indica que não consegue ligar-se ao site ou ao MainWP**: verifique se é executado no seu computador e não num browser.
- **As novas ferramentas não aparecem**: recarregue os servidores MCP (`/mcp` no Claude Code) ou reinicie o seu agente de IA.
- **O seu agente de IA para e indica uma ação recusada**: bloqueou a criação da senha ou a execução do comando. Autorize esta ação nas definições de permissões do agente, ou indique-a explicitamente no seu pedido, por exemplo "Cria uma senha de aplicação no site www.example.com".
- **Os pedidos ao MCP OVHcloud falham com um erro 401**: remova o servidor, adicione-o novamente sem cabeçalho e, em seguida, reinicie a autenticação.
