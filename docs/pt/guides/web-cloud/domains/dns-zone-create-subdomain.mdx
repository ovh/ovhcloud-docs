## Objetivo

Quer criar uma zona DNS para um subdomínio?

A zona **D**omain **N**ame **S**ystem (**DNS**) de um nome de domínio constitui o ficheiro de configuração deste último. É composta por informações técnicas, designadas *registos DNS*. A zona DNS atua como um centro de encaminhamento.

Para mais explicações, consulte os nossos guias abaixo:

- [Saber tudo sobre os servidores DNS](/guides/web-cloud/domains/dns-server-general-information)
- [Saber tudo sobre a zona DNS](/guides/web-cloud/domains/dns-zone-general-information)
- [Saber tudo sobre os registos DNS](/guides/web-cloud/domains/dns-zone-records)

Geralmente, os registos DNS de um subdomínio configuram-se diretamente a partir da zona DNS ativa do nome de domínio do qual depende.
No entanto, também é possível criar uma zona DNS específica para um subdomínio.

Por diversas razões, pode ser necessário criar uma zona DNS para um subdomínio na OVHcloud.
Este terá então a sua própria zona para configurar os seus registos DNS.

:::tip
Para recordar:

- Um nome de domínio tem geralmente esta forma: **domain.tld**. Por exemplo: ovhcloud.com.
- Um subdomínio tem geralmente esta forma: **sub.domain.tld**. Por exemplo: help.ovhcloud.com.

Por defeito, um subdomínio depende de um nome de domínio para funcionar.
Concretamente, não poderá utilizar o subdomínio **sub.domain.tld** se não tiver acesso à gestão do nome de domínio **domain.tld**.

Se quiser criar uma zona DNS para um nome de domínio, consulte diretamente [este guia](/guides/web-cloud/domains/dns-zone-create).

:::

**Saiba como criar uma zona DNS na OVHcloud para o subdomínio de um domínio através da consola OVHcloud.**

## Requisitos

- Dispor do nome de domínio do qual o subdomínio escolhido vai depender.
- O subdomínio correspondente não deve já dispor de uma zona DNS (ativa ou não) na OVHcloud ou estar sujeito a uma operação ou a uma encomenda em curso na OVHcloud.

## Instruções

### 1 - Criar a zona DNS através da consola OVHcloud

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/domains/listing">Domínios & DNS</ManagerLink> e clique no botão <code className="action">Encomendar um domínio ou uma zona DNS</code>. No bloco **Zona DNS autónoma**, clique em <code className="action">Contratar</code>.

    <img className="thumbnail" alt="Página de encomenda de um nome de domínio ou de uma zona DNS e bloco Zona DNS autónoma" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-choice.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Na página **Encomendar uma zona DNS** que aparece, introduza no campo **Nome de domínio** o subdomínio (por exemplo: *sub.domain.tld*) para o qual pretende criar uma zona DNS OVHcloud. Aguarde alguns instantes enquanto a ferramenta efetua verificações relativas ao subdomínio.

    Se uma mensagem indicar que a zona DNS não pode ser criada (por exemplo, "Já existe uma zona DNS para sub.domain.tld."), verifique se o subdomínio cumpre os requisitos necessários ou contacte a pessoa que o gere. Quando tudo estiver correto, tente novamente.

    <img className="thumbnail" alt="Mensagem que indica que já existe uma zona DNS para o nome introduzido" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-exists.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Concluída a verificação, aparece a secção **Escolha as suas opções**. Selecione, se necessário, a opção **DNS Anycast** (paga). O resumo, à direita da página, indica o conteúdo e o total da sua encomenda.

    <img className="thumbnail" alt="Opções da encomenda de uma zona DNS para um subdomínio e resumo da encomenda" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-subdomain.png" loading="lazy" />

    Clique em <code className="action">Continuar a encomenda</code> e siga as etapas apresentadas até à criação da zona DNS.

    :::info
    A escolha dos registos mínimos já não é feita durante a encomenda. Se pretender personalizar a zona DNS a partir apenas dos registos mínimos (registos NS e SOA), reinicialize-a depois de criada: no separador <code className="action">Zona DNS</code>, abra o menu <code className="action">Ações adicionais</code> do cartão **Zona DNS**, clique em <code className="action">Redefinir a zona</code> e escolha <code className="action">Sim — somente entradas mínimas</code>. Consulte o nosso guia "[Editar uma zona DNS da OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".

    :::
  </Tab>
</Tabs>

### 2 - Editar a zona DNS (opcional)

A zona DNS do seu subdomínio está agora criada, pode editá-la imediatamente. Esta operação é opcional, mas pode revelar-se necessária se quiser garantir a continuidade da disponibilidade dos serviços ligados a este subdomínio (como um site web e/ou e-mails).

Para editar esta zona DNS, consulte o nosso guia "[Editar uma zona DNS da OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".

:::info
Se acabou de criar a zona DNS e o subdomínio ainda não aparece na lista dos seus serviços, aguarde 15 a 20 minutos e recarregue a página.

:::

### 3 - Declarar os servidores DNS na zona DNS ativa do nome de domínio do qual o subdomínio escolhido depende

A ativação de uma zona DNS para um subdomínio difere daquela de um nome de domínio, pois um subdomínio depende obrigatoriamente de um nome de domínio para funcionar.

Deve primeiro recuperar os nomes dos **servidores DNS** OVHcloud associados à zona DNS criada para o seu subdomínio.

Para os encontrar, clique nos separadores abaixo para visualizar cada uma das **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/domains/listing">Domínios & DNS</ManagerLink> e escolha a zona DNS do seu subdomínio (aparece como **Apenas zona** na lista). A seguir, clique no separador <code className="action">Zona DNS</code>.

    <img className="thumbnail" alt="Página Domínios & DNS e lista dos nomes de domínio da conta" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Na tabela apresentada, identifique as colunas **Tipo** e **Destino**. Para apresentar apenas os registos úteis, clique em <code className="action">Filtros</code> e selecione <code className="action">NS</code> na lista **Tipo de registo**.

    <img className="thumbnail" alt="Zona DNS filtrada pelos registos NS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-ns.png" loading="lazy" />

    Anote os 2 valores presentes na coluna **Destino**. Os nomes dos servidores DNS devem ter uma das 3 formas seguintes:

    - `nsXX.ovh.net` e `dnsXX.ovh.net` ou, `nsXXX.ovh.net` e `dnsXXX.ovh.net` (onde cada `X` representa um número entre **0** e **9**).
    - `nsXX.ovh.ca` e `dnsXX.ovh.ca` ou, `nsXXX.ovh.ca` e `dnsXXX.ovh.ca` (onde cada `X` representa um número entre **0** e **9**).
    - `ns200.anycast.me` e `dns200.anycast.me` (se subscreveu a opção [DNS anycast](/links/web/domains-options)).
  </Tab>
</Tabs>

Uma vez recuperados os dois nomes de servidor DNS, duas situações são possíveis.

**Clique numa das duas situações para visualizar o conteúdo.**

  <Tab label="Etapa 2">

    <img className="thumbnail" alt="Separador Zona DNS e formulário Adicionar uma entrada" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry.png" loading="lazy" />

  <Tab label="Etapa 3">
    Na lista **Tipo**, selecione <code className="action">NS — Delegar a um servidor DNS</code> (secção **Campos de apontamento**).

    <img className="thumbnail" alt="Lista dos tipos de registo com o tipo NS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-ns.png" loading="lazy" />

    No campo **Subdomínio**, introduza o subdomínio em causa (por exemplo: `sub` para o subdomínio `sub.domain.tld`); no campo **Destino (servidor DNS)**, introduza um dos 2 servidores DNS que anotou (por exemplo: `nsXX.ovh.net`). Verifique a **Pré-visualização do registro** e clique em <code className="action">Adicionar</code>.

    **Repita a operação para o segundo servidor DNS.**

    Se necessário, consulte também o nosso guia "[Editar uma zona DNS da OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".
  </Tab>
</Tabs>

</details>

<details>

<summary>O nome de domínio do qual o seu subdomínio depende tem a sua zona DNS ativa noutra fornecedora</summary>

Neste caso específico, contacte o seu fornecedor DNS informando-o que pretende adicionar 2 registos DNS do tipo NS para o seu subdomínio.

Aqui está um exemplo de pedido a formular junto do seu fornecedor DNS:

<pre className="bgwhite"><code>
Olá,

Quero adicionar na zona DNS ativa do nome de domínio <b>domain.tld</b> os seguintes registos DNS do tipo NS para o meu subdomínio <b>sub.domain.tld</b>:

 - sub IN NS nsXX.ovh.net.
 - sub IN NS dnsXX.ovh.net.

Para ativar uma zona DNS específica para o meu subdomínio <b>sub.domain.tld</b>.

Atenciosamente,
</code></pre>

No exemplo acima, substitua os valores **domain.tld**, **sub.domain.tld**, **nsXX.ovh.net** e **dnsXX.ovh.net** pelos seus próprios valores.

</details>

:::warning
**O ponto de atenção seguinte não se aplica aos 2 registos DNS do tipo NS que acabou de adicionar.**

Se houver outros registos DNS presentes na zona DNS ativa do nome de domínio do qual o seu subdomínio depende:

1. Não se esqueça de os duplicar na zona DNS criada para o seu subdomínio.
2. Uma vez duplicados, remova-os da zona DNS ativa do seu nome de domínio.

De facto, poderia haver um conflito na resolução DNS.

:::

Após a modificação da zona DNS do nome de domínio do qual o seu subdomínio depende, a propagação das modificações pode demorar até **48 horas**.
