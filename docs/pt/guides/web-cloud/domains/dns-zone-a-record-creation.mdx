## Objetivo

Deseja que o seu website esteja acessível através do seu nome de domínio? Para isso, o seu domínio deve apontar para o endereço IP do serviço no qual o seu website está situado (alojamento web, servidor dedicado, VPS, etc.). De seguida, deverá configurar a zona DNS ativa do seu domínio através de um registo DNS do tipo A.

**Saiba como adicionar um registo DNS do tipo A numa zona DNS gerida na OVHcloud para o seu domínio.**

:::info
Para alterar ou eliminar um registo DNS do tipo A de uma zona DNS da OVHcloud, siga [este manual](/guides/web-cloud/domains/dns-zone-edit).

:::

## Requisitos

- Ter um [nome de domínio](/links/web/domains).
- Ter uma zona DNS associada a este domínio na OVHcloud.

## Instruções

:::warning
A adição, modificação ou eliminação de registos DNS numa zona DNS ativa é uma operação sensível. Se não tiver a certeza, entre em contacto com um [fornecedor especializado](/links/partner).

:::

### Adicionar um registo DNS do tipo A para um domínio

Clique em <code className="action">Adicionar uma entrada</code> acima da tabela e selecione o tipo **A**. No campo **Destino**, introduza o endereço IP (por exemplo: `203.0.113.0`) do serviço em que se situa o seu website (alojamento web, servidor dedicado, VPS, etc.) e, em seguida, clique em <code className="action">Adicionar</code>.

<img className="thumbnail" alt="Adicionar um registo a partir da zona DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-add-entry.png" loading="lazy" />

Aguarde até **24** horas para que a propagação da adição na rede DNS seja plenamente efetiva.

### Adicionar um registo DNS do tipo A para o subdomínio de um domínio

Siga os mesmos passos acima e, no campo **Subdomínio**, introduza o subdomínio (por exemplo: `www` para `www.domain.tld`) antes de definir o **Destino** com o endereço IP (por exemplo: `203.0.113.0`) do serviço em que se situa o seu website. Em seguida, clique em <code className="action">Adicionar</code>.
