## Objetivo

Um registo CNAME permite associar um subdomínio a um nome de domínio ou subdomínio, sem ter de especificar um endereço IP. Isto significa que o subdomínio será reencaminhado para o endereço IP do nome de domínio ou subdomínio de destino, sem necessidade de configuração adicional.

Por exemplo, se criar um registo CNAME para *www.domain.tld* que aponta para *domain.tld*, então *www.domain.tld* utilizará o mesmo endereço IP que *domain.tld*.

Os registos CNAME são úteis para evitar a necessidade de alterar os endereços IP dos subdomínios. Também podem ser utilizados para configurar serviços como os servidores de correio eletrónico.

**Saiba como adicionar um registo CNAME na zona DNS da OVHcloud.**

> **Já tem um registo do tipo CNAME na sua zona DNS?** Siga o nosso guia "[Editar uma zona DNS da OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".

## Requisitos

- Ter um [nome de domínio](/links/web/domains).
- Ter uma zona DNS associada a este nome de domínio na OVHcloud.

## Instruções

### Adicionar um registo DNS do tipo CNAME para o subdomínio de um nome de domínio

Clique nos separadores abaixo para visualizar cada uma das **5** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/domains/listing">Domínios & DNS</ManagerLink> e escolha o nome de domínio em causa.

    <img className="thumbnail" alt="Página Domínios & DNS e lista dos nomes de domínio da conta" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Zona DNS</code> e, por cima da tabela, em <code className="action">Adicionar uma entrada</code>.

    <img className="thumbnail" alt="Separador Zona DNS de um nome de domínio e botão Adicionar uma entrada" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    No formulário que se abre por cima da tabela, selecione `CNAME — Alias para outro domínio` na lista **Tipo**.

    <img className="thumbnail" alt="Lista Tipo do formulário Adicionar uma entrada, tipo CNAME selecionado" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-cname.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    No campo **Subdomínio**, introduza o subdomínio em causa (por exemplo: `www` para `www.domain.tld`). No campo **Destino (nome de host)**, introduza o nome de domínio ou subdomínio para o qual pretende apontar (por exemplo: `domain.tld`): a consola acrescenta ela própria o ponto final.

    <img className="thumbnail" alt="Formulário Adicionar uma entrada da zona DNS, registo CNAME do subdomínio www para domain.tld" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-cname-record.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 5">
    Verifique a **Pré-visualização do registro** e clique em <code className="action">Adicionar</code>.
  </Tab>
</Tabs>

Aguarde até **24** horas para que a propagação da adição na rede DNS seja plenamente efetiva.

### Casos especiais

Clique nos links a seguir para obter mais informações:

<details>

<summary>Registos CNAME e TXT para o mesmo subdomínio</summary>

Não configure um registo CNAME e um registo TXT para o mesmo subdomínio. Isto pode levar a resultados aleatórios durante a resolução DNS, uma vez que apenas uma resposta pode ser devolvida através de consulta DNS.

Por exemplo, se tiver os seguintes registos para *www.domain.tld*:

- Um registo CNAME que aponta para *domain.tld*.
- Um registo TXT com um valor específico.

Um pedido DNS para *www.domain.tld* retornará o destino do registo CNAME ou o valor do registo TXT, de forma aleatória.

</details>

<details>

<summary>CNAME num nome de domínio na sua própria zona DNS</summary>

Por convenção, **os registos do tipo CNAME não podem ser utilizados num nome de domínio na sua própria zona DNS**. De facto, o nome de domínio deve obrigatoriamente apontar diretamente para um endereço IP com um registo do tipo [A](/guides/web-cloud/domains/dns-zone-a-record-creation) para um IPv4, ou [AAAA](/guides/web-cloud/domains/dns-zone-aaaa-record-creation) para um IPv6.

Como tal, e tomando como exemplo o exemplo acima, não poderá criar um registo do tipo CNAME para o nome de domínio *domain.tld* na zona DNS que criou para esse nome.
No entanto, pode criar registos do tipo CNAME para todos os subdomínios (por exemplo: *subdomain.domain.tld* ou *www.domain.tld*) do nome de domínio *domain.tld* na zona DNS criada para *domain.tld*.

Na consola OVHcloud, se introduzir `@` no campo **Subdomínio** de um registo CNAME, o botão <code className="action">Adicionar</code> permanece desativado e o formulário apresenta a mensagem "Um registro CNAME não pode ser criado na raiz do domínio (@). Você pode usar o apontamento SVCB."

</details>
