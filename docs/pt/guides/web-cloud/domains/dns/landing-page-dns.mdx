## O que é o DNS?

O **DNS** (*Domain Name System*) é a lista telefónica da Internet: traduz os nomes de domínio legíveis pelo ser humano (como `mydomain.ovh`) em endereços IP compreendidos pelas máquinas. Sem ele, seria necessário memorizar uma série de números para aceder a cada site ou serviço online.

Na OVHcloud, a configuração DNS de um nome de domínio assenta em três elementos:

- os **servidores DNS**, que alojam e difundem as informações do seu domínio;
- a **zona DNS**, o ficheiro que reúne todos os seus registos;
- os **registos DNS**, cada linha que associa um nome a um valor (endereço IP, servidor de e-mail, texto, etc.).

## Como funciona o DNS?

Do seu nome de domínio até cada registo, a resolução DNS segue uma cadeia de quatro elos.

<DnsChain />

### O servidor DNS

Os servidores DNS alojam e difundem na Internet as informações do seu domínio. Quando um internauta pede o seu site, são eles que respondem indicando onde o encontrar. Por predefinição, o seu domínio utiliza os servidores DNS da OVHcloud. [Saber tudo sobre os servidores DNS](/guides/web-cloud/domains/dns-server-general-information).

<DnsServerIllustration />

### A zona DNS

A zona DNS é o ficheiro de configuração associado aos seus servidores DNS. Reúne todos os registos do seu domínio: é aqui que adiciona, edita ou elimina as suas entradas. [Saber tudo sobre a zona DNS](/guides/web-cloud/domains/dns-zone-general-information).

<DnsZoneIllustration />

### Os registos DNS

Cada registo é uma linha da zona que associa um nome a um valor: um endereço IP, um servidor de e-mail, texto, etc. O seu tipo determina a sua função, indicada abaixo pela cor. Selecione o que pretende configurar para aceder ao guia correspondente.
