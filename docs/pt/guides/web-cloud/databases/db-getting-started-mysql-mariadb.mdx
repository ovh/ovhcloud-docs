## Objetivo

Deseja utilizar MySQL ou MariaDB para as suas bases de dados?

### O que é uma base de dados MYSQL?

O MYSQL é um sistema de gestão de bases de dados relacionais desenvolvido para performances elevadas em escrita, ao contrário de outros sistemas.

Este motor é open source, e a sua casa mãe é nada mais nada menos que a Oracle.

### O que é uma base de dados MariaDB?

A MariaDB é uma derivação (fork) do sistema de gestão de bases de dados MySQL.

Este motor é 100% compatível, e é mais "livre" que o seu irmão mais velho MySQL. Todos os bugs e roadmaps estão acessíveis gratuitamente, ao contrário da versão da Oracle.

**Descubra como criar e gerir as suas bases de dados MySQL ou MariaDB**

## Instruções

### Ligação à base de dados

:::info
Esta oferta não dá acesso ao Host, mas sim às bases de dados nele alojadas. Os comandos SQL genéricos funcionam sem qualquer problema, e programas como o HeidiSQL ou o SQuirreL SQL são totalmente compatíveis.

:::

:::info
Sendo o MariaDB um derivado do MySQL, os diferentes comandos são exatamente os mesmos para estes 2 tipos de bases de dados.

:::

Para se ligar à sua base de dados, certifique-se de que dispõe de:

- o endereço da sua instância Web Cloud Databases
- a porta da sua instância Web Cloud Databases
- o nome de utilizador da sua instância Web Cloud Databases
- a palavra-passe associada ao utilizador
- o nome da sua base de dados

Todas estas informações estão disponíveis na consola OVHcloud, na página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.

Também está disponível um guia: [Web Cloud Databases - Primeira utilização](/guides/web-cloud/databases/db-getting-started).

#### Ligação através da linha de comandos

```bash
mysql --host=server --user=user --port=port --password=password database_name
```

#### Ligação através de um script PHP

```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

#### Ligação através de um programa (SQuirreL SQL)

- Inicie o SQuirreL SQL e clique em <code className="action">Aliases</code> e, a seguir, em <code className="action">+</code>.

<img className="thumbnail" alt="iniciar o SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Preencha os campos abaixo e valide com o botão <code className="action">OK</code>:
    - **Name**: Escolha um nome
    - **Driver**: Escolha `MySQL Driver`
    - **URL**: Indique o endereço do servidor e a porta no formato `jdbc:mysql://server:port`
    - **User Name**: Indique o nome de utilizador
    - **Password**: Indique a palavra-passe

<img className="thumbnail" alt="configuração da ligação" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Valide novamente com o botão <code className="action">Connect</code>.

<img className="thumbnail" alt="validação da ligação" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

Está agora ligado à sua base de dados:

<img className="thumbnail" alt="configuração da ligação" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

#### Ligação através do phpMyAdmin

Pode utilizar o phpMyAdmin para explorar o conteúdo da sua base de dados. Para isso, instale o phpMyAdmin no seu próprio servidor ou alojamento web. Durante a instalação, certifique-se de que configura corretamente as informações do seu servidor Web Cloud Databases e da base de dados pretendida, para que o phpMyAdmin se possa ligar a ela.

### Exportar e importar uma base de dados MySQL ou MariaDB

- **Exportar a minha base de dados através da linha de comandos**

```bash
mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql
```

- **Importar a minha base de dados através da linha de comandos**

```bash
cat database_name.sql | mysql --host=server --user=user --port=port --password=password database_name
```

:::info
Em certos casos, é possível que a RAM disponível na sua instância Web Cloud Databases não permita realizar a exportação ou a importação pretendida. Se for o caso, recomendamos que utilize a ferramenta de importação disponibilizada pela OVHcloud. Consulte a documentação "[Web Cloud Databases - Primeira utilização](/guides/web-cloud/databases/db-getting-started#importar-uma-base-de-dados)" se necessário.

:::
