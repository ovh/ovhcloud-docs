## Configurar o seu serviço Web Cloud Databases

Configure e faça a gestão do seu serviço OVHcloud Web Cloud Databases: acesso, bases de dados, utilizadores e permissões, ligação, extensões PostgreSQL e logs.

Para se orientar consoante a sua necessidade:

- **Pretende abrir o acesso e ligar-se às suas bases de dados?** Consulte a secção *Acesso e ligação*.
- **Faz a gestão das suas bases de dados, utilizadores e respetivas permissões?** Consulte a secção *Bases de dados e utilizadores*.
- **Administra o servidor (configuração, logs)?** Consulte a secção *Servidor e exploração*.
