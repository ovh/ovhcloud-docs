## Objetivo

No seguimento de um erro numa base de dados, deve estar preparado para restaurar um backup ou importar uma base de dados local.

**Saiba como restaurar e importar uma base de dados no servidor de bases de dados.**

## Requisitos

- Dispor de uma [instância Web Cloud Databases](/links/web/databases) (incluída numa oferta de [alojamento web](/links/web/hosting) Performance, Agency, Agency Plus ou Agency Max)

[[cpnav:web-cloud-databases]]

## Instruções

:::info
As soluções [Web Cloud Databases](/links/web/databases) não dão acesso ao sistema de gestão de bases de dados, mas sim às bases de dados alojadas nele.

- Não há acesso de superutilizador "root".
- Os comandos SQL genéricos funcionam normalmente, e os programas de tipo HeidiSQL, SQuirreL SQL ou Adminer são plenamente compatíveis.

:::

### Restaurar e importar uma base de dados a partir da consola OVHcloud <a name="restaurar-e-importar-uma-base-de-dados-a-partir-da-área-de-cliente"></a>

#### Restaurar um backup existente

Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Bases de dados</code>.

    Na coluna **Cópias de segurança**, o número corresponde ao número de cópias de segurança disponíveis para cada base de dados.

    <img className="thumbnail" alt="Separador Bases de dados de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na tabela, clique no botão <code className="action">⋮</code> da coluna **Ações**, à direita da base de dados em causa, e depois em <code className="action">Ver cópias de segurança</code>.

    <img className="thumbnail" alt="Menu de uma linha da tabela das bases de dados Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Abre-se à direita um painel intitulado **Cópias de segurança**, seguido do nome da base de dados. Clique no botão <code className="action">⋮</code> à direita da cópia de segurança escolhida e depois em <code className="action">Restaurar</code>.

    <img className="thumbnail" alt="Painel das cópias de segurança de uma base de dados com o menu de uma cópia aberto" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/backup-actions-menu.png" loading="lazy" />

    Na janela **Restaurar uma cópia de segurança** que se abre, confirme clicando em <code className="action">Restaurar</code>. É apresentada a mensagem **Restauro iniciado**.

    <img className="thumbnail" alt="Janela de confirmação do restauro de uma cópia de segurança" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/restore-backup-dialog.png" loading="lazy" />

    :::warning
    O restauro implica a substituição do conteúdo da base de dados e, por conseguinte, uma potencial perda de dados. Caso não tenha a certeza do que está a fazer, recomendamos que efetue um backup antes.

    :::

  </Tab>
</Tabs>

#### Importar um backup local

Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Clique no separador <code className="action">Bases de dados</code>.

    <img className="thumbnail" alt="Separador Bases de dados de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na tabela, clique no botão <code className="action">⋮</code> da coluna **Ações**, à direita da base de dados em causa, e depois em <code className="action">Importar</code>.

    <img className="thumbnail" alt="Menu de uma linha da tabela das bases de dados Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Abre-se a janela **Importar uma base de dados**. ***Tem duas possibilidades***, propostas pelos dois botões situados no topo da janela:

    **1 - Carregar um novo ficheiro**

    Esta possibilidade está selecionada por predefinição na abertura da janela.

    No campo **Nome do ficheiro**, indique um nome para o ficheiro importado. Em seguida, clique na zona <code className="action">Ficheiro a importar</code> para selecionar o ficheiro no seu computador, ou arraste-o para esta zona.

    :::warning
    O ficheiro deve estar no formato ".sql", ".txt" ou ".gz".

    :::

    <img className="thumbnail" alt="Janela Importar uma base de dados com a opção Carregar um novo ficheiro selecionada" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/database-import-new-file-step-2.png" loading="lazy" />

    Se desejar, marque a caixa **Esvaziar a base de dados antes da importação**. A caixa **Receber um e-mail no final da importação** está marcada por predefinição: permite-lhe ser informado da conclusão da operação no endereço de e-mail de referência da sua conta OVHcloud. Por fim, clique em <code className="action">Confirmar</code>: o ficheiro é enviado e a importação é iniciada.

    **2 - Utilizar um ficheiro existente**

    Se já importou um ficheiro anteriormente, clique em <code className="action">Usar um ficheiro existente</code>.

    Na lista pendente **Documento existente**, selecione o ficheiro entre os que já estão presentes na sua conta OVHcloud.

    <img className="thumbnail" alt="Janela Importar uma base de dados com a opção Usar um ficheiro existente selecionada" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/database-import-existing-file-step-2.png" loading="lazy" />

    Se desejar, marque a caixa **Esvaziar a base de dados antes da importação**. A caixa **Receber um e-mail no final da importação** está marcada por predefinição: permite-lhe ser informado da conclusão da operação no endereço de e-mail de referência da sua conta OVHcloud. Por fim, clique em <code className="action">Confirmar</code> para iniciar a importação.
  </Tab>
</Tabs>

### Importar uma base de dados fora da consola OVHcloud <a name="importar-uma-base-de-dados-fora-da-área-de-cliente"></a>

Em certos casos, a RAM disponível no seu servidor de bases de dados não permite realizar a importação desejada fora da consola OVHcloud. Nesse caso, recomendamos que utilize a ferramenta OVHcloud disponível na consola OVHcloud. Consulte a secção "[Restaurar e importar uma base de dados a partir da consola OVHcloud](#restaurar-e-importar-uma-base-de-dados-a-partir-da-área-de-cliente)" deste guia.

**Clique no método de importação pretendido para visualizar o conteúdo.**

<details>

<summary>Importar uma base MySQL ou MariaDB a partir do phpMyAdmin</summary>

Para importar a base de dados diretamente a partir do phpMyAdmin, é necessário primeiro conectar-se. Consulte a secção "[Ligar-se a uma base de dados MySQL ou MariaDB](/guides/web-cloud/databases/db-connecting-database-server#ligar-se-a-uma-base-de-dados-mysql-ou-mariadb)".

Depois de se ter conectado ao phpMyAdmin, selecione a base de dados clicando no seu nome.

De seguida, clique no separador <code className="action">Importar</code>.

Selecione o ficheiro de backup clicando em <code className="action">Percorrer</code> (o ficheiro não pode ultrapassar os 100 MB).

:::info
Caso exceda os 100 MB, recomendamos que fraccione a base de dados em vários ficheiros e que efetue várias importações a partir do phpMyAdmin.
A importação de ficheiros que ultrapassem os 100 MB pode ser feita a partir da consola OVHcloud seguindo o passo "[Restaurar e importar uma base de dados a partir da consola OVHcloud](#restaurar-e-importar-uma-base-de-dados-a-partir-da-área-de-cliente)".

:::

Deixe as opções predefinidas e clique em <code className="action">Executar</code> para lançar a importação.

<img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-upload-backup-web-cloud-db.png" loading="lazy" />

</details>

<details>

<summary>Importar uma base MySQL ou MariaDB a partir da linha de comandos</summary>

Esta ação só é possível em [SSH](/guides/web-cloud/web-hosting/ssh-on-webhosting) a partir de um alojamento partilhado OVHcloud.

```bash
cat nome_da_base.sql | mysql --host=servidor --user=utilizador --port=port --password=password nome_da_base
```

</details>

<details>

<summary>Importar uma base MySQL ou MariaDB a partir de um ficheiro PHP</summary>

```php
1. <?php
2. echo "O restauro da sua base está em curso.......<br/>";
3. system("cat nome_da_base.sql | mysql --host=servidor --user=utilizador --port=port --password=password nome_da_base");
4. echo "Concluído. A base está instalada neste alojamento.";
5. ?>
```

:::warning
- De modo a evitar acessos indesejados a este ficheiro com dados sensíveis, proteja-o seguindo o guia: [Como proteger o acesso a um diretório com palavra-passe?](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password)
- Esta operação só é possível a partir de um alojamento partilhado OVHcloud.

:::

</details>

<details>

<summary>Importar uma base PostgreSQL a partir da linha de comandos</summary>

Esta ação só é possível em [SSH](/guides/web-cloud/web-hosting/ssh-on-webhosting) a partir de um alojamento partilhado OVHcloud em versão estável ou superior.

```bash
psql --host=servidor --port=port --user=utilizador --password=password nome_da_base < nome_da_base.sql
```

</details>

<details>

<summary>Importar uma base PostgreSQL a partir de um ficheiro PHP</summary>

```php
1. <?php
2. echo "O restauro da sua base está em curso.......<br/>";
3. system("PGPASSWORD=password psql --host=servidor --port=port --user=utilizador --password=password nome_da_base < nome_da_base.sql");
4. echo "Concluído. A base está instalada neste alojamento.";
5. ?>
```

:::warning
- De modo a evitar acessos indesejados a este ficheiro com dados sensíveis, proteja-o seguindo o guia: [Como proteger o acesso a um diretório com palavra-passe?](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password)
- Esta operação só é possível a partir de um alojamento partilhado OVHcloud.

:::

</details>
