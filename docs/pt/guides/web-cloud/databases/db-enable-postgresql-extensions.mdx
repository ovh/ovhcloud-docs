## Objetivo

As extensões PostgreSQL são módulos que enriquecem a sua base de dados com funcionalidades adicionais: novos tipos de dados, funções, operadores ou linguagens procedimentais. Numa solução Web Cloud Databases, pode ativar as extensões compatíveis diretamente a partir da consola OVHcloud, sem intervenção através da linha de comandos.

**Este guia explica-lhe como ativar as extensões disponíveis numa base de dados PostgreSQL alojada numa solução Web Cloud Databases.**

## Requisitos

- Dispor de uma [instância Web Cloud Databases](/links/web/databases) que utilize **PostgreSQL**.
- Ter consultado o guia [Começar com PostgreSQL](/guides/web-cloud/databases/db-getting-started-postgresql).

[[cpnav:web-cloud-databases]]

## Instruções

### Ativar uma extensão

Clique nos separadores abaixo para ver cada um dos **3** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    Clique no separador <code className="action">Bases de dados</code>. Na coluna **Extensões**, clique no ícone em forma de peça de puzzle da base de dados correspondente.

    <img className="thumbnail" alt="Ícone da coluna Extensões na tabela das bases de dados" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/extensions-column.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 3">
    Um painel intitulado **Extensões**, seguido do nome da base de dados, abre-se à direita. Localize a extensão pretendida na lista, se necessário com a ajuda do campo **Pesquisar**.

    Em seguida, selecione a caixa da extensão na coluna **Estado**. A ativação é imediata, sem validação. É apresentada a mensagem **Extensão ativada**.

    <img className="thumbnail" alt="Painel Extensões de uma base de dados PostgreSQL" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/extensions-panel.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
A ativação de uma extensão aplica-se à base de dados selecionada. Para a ativar noutra base de dados do mesmo servidor, repita a operação selecionando a base de dados correspondente.

:::

### Extensões disponíveis

A lista de extensões propostas depende da versão do PostgreSQL utilizada pelo seu servidor. As extensões disponíveis para a sua versão são apresentadas no painel **Extensões** de cada base de dados.

Segue-se a lista de extensões disponíveis:

| Extensão | Descrição |
|---|---|
| `address_standardizer` | Analisa um endereço para o decompor nos seus elementos constituintes. Geralmente utilizada para apoiar a etapa de normalização de endereços na geocodificação. |
| `autoinc` | Funções para a incrementação automática de campos. |
| `bloom` | Método de acesso bloom – índice baseado num ficheiro de assinaturas. |
| `btree_gin` | Suporte para a indexação de tipos de dados comuns em GIN. |
| `btree_gist` | Suporte para a indexação de tipos de dados comuns em GiST. |
| `citext` | Tipo de dados para cadeias de carateres que não distinguem maiúsculas de minúsculas. |
| `cube` | Tipo de dados para cubos multidimensionais. |
| `earthdistance` | Cálculo de distâncias ortodrómicas à superfície da Terra. |
| `fuzzystrmatch` | Determina as semelhanças e a distância entre cadeias de carateres. |
| `hstore` | Tipo de dados para armazenar conjuntos de pares (chave, valor). |
| `intarray` | Funções, operadores e suporte de indexação para arrays de inteiros de uma dimensão. |
| `isn` | Tipos de dados para as normas internacionais de numeração de produtos. |
| `ltree` | Tipo de dados para estruturas hierárquicas em árvore. |
| `moddatetime` | Funções para acompanhar a data da última modificação. |
| `pg_trgm` | Medição da semelhança de texto e pesquisa por índice baseadas em trigramas. |
| `pgcrypto` | Funções criptográficas. |
| `postgis` | Tipos e funções espaciais do PostGIS (geometria, geografia e raster). |
| `postgis_raster` | Tipos e funções raster do PostGIS. |
| `postgis_tiger_geocoder` | Geocodificador tiger e geocodificador inverso do PostGIS. |
| `postgis_topology` | Tipos e funções espaciais de topologia do PostGIS. |
| `seg` | Tipo de dados para representar segmentos de reta ou intervalos de vírgula flutuante. |
| `unaccent` | Dicionário de pesquisa de texto que remove os acentos. |
| `uuid-ossp` | Gera identificadores únicos universais (UUID). |
| `xml2` | Consultas XPath e XSLT. |
