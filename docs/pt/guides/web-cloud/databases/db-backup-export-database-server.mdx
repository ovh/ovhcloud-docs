## Objetivo

A sua base de dados pode conter um grande volume de informações essenciais para o seu site. Por isso, é fundamental poder salvaguardá-la ou exportá-la.

**Saiba como salvaguardar e exportar uma base de dados a partir do seu servidor de bases de dados.**

## Requisitos

- Dispor de uma [instância Web Cloud Databases](/links/web/databases) (incluída numa oferta de [alojamento web](/links/web/hosting) Performance, Agency, Agency Plus ou Agency Max).

[[cpnav:web-cloud-databases]]

## Instruções

:::info
As soluções [Web Cloud Databases](/links/web/databases) não dão acesso ao sistema de gestão de bases de dados, mas às bases de dados alojadas nesse sistema.

- Não existe acesso de superutilizador "root".
- Os comandos SQL genéricos funcionam normalmente e softwares como HeidiSQL, SQuirreL SQL ou Adminer são totalmente compatíveis.

:::

### Salvaguardar e exportar uma base de dados a partir da consola OVHcloud <a name="sauvegarder-et-exporter-une-base-de-données-depuis-lespace-client"></a>

:::info
- São realizadas automaticamente cópias de segurança uma vez por dia em todas as suas bases de dados.
- As cópias de segurança automáticas e manuais são conservadas durante 30 dias. Após este prazo, são eliminadas automaticamente. A data de eliminação de cada cópia de segurança é indicada na lista das cópias de segurança da base de dados.

:::

#### Realizar uma cópia de segurança manual

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

    <img className="thumbnail" alt="Separador Bases de dados de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />

### Salvaguardar e exportar uma base de dados fora da consola OVHcloud <a name="sauvegarder-et-exporter-une-base-de-données-hors-espace-client"></a>

Se a RAM disponível no servidor não permitir realizar a exportação desejada, utilize a ferramenta OVHcloud na consola OVHcloud, que utiliza recursos externos à sua solução. Consulte a secção "[Salvaguardar e exportar uma base de dados a partir da consola OVHcloud](#salvaguardar-e-exportar-uma-base-de-dados-a-partir-da-consola-ovhcloud)" deste guia.

**Clique no método de exportação pretendido para visualizar o conteúdo.**

<details>

<summary>Exportar uma base de dados MySQL ou MariaDB a partir do phpMyAdmin OVHcloud</summary>

Para exportar a sua base de dados diretamente a partir do phpMyAdmin, é necessário ligar-se primeiro. Para tal, consulte o guia "[Ligar-se a uma base de dados](/guides/web-cloud/databases/db-connecting-database-server)".

Depois de se ligar ao phpMyAdmin, clique no nome da base de dados que deseja exportar e, a seguir, no separador <code className="action">Exportar</code> no topo.

Existem dois modos de exportação. Se não tiver necessidades específicas, recomendamos o modo **rápido** no formato **SQL**.

<img className="thumbnail" alt="Separador Exportar do phpMyAdmin com o método rápido e o formato SQL" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-export-backup-web-cloud-db.png" loading="lazy" />

</details>

<details>

<summary>Exportar uma base de dados MySQL ou MariaDB a partir da linha de comandos</summary>

```bash
mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql
```

</details>

<details>

<summary>Exportar uma base de dados MySQL ou MariaDB a partir de um script PHP</summary>

```php
1. <?php echo "Your database is being backed up.......";
2. system("mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql");
3. echo "Backup complete. You can retrieve the database via FTP";
4. ?>
```

:::warning
- Para evitar que terceiros acedam a este ficheiro com dados sensíveis, proteja o acesso utilizando o guia: [Proteger um diretório ou a interface de administração do seu website por ficheiros .htaccess e .htpasswd](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password).
- Esta operação só é possível a partir de um alojamento web OVHcloud.

:::

</details>

<details>

<summary>Exportar uma base de dados PostgreSQL a partir da linha de comandos</summary>

```bash
pg_dump --host=server --port=port --username=user --password database_name > database_name.sql
```

</details>

<details>

<summary>Exportar uma base de dados PostgreSQL a partir de um script PHP</summary>

```php
1. <?php echo "Your database is being backed up.......";
2. system("PGPASSWORD=password pg_dump --host=server --port=port --username=user database_name > database_name.sql");
3. echo "Backup complete. You can retrieve the database via FTP";
4. ?>
```

:::warning
- Para evitar que terceiros acedam a este ficheiro com dados sensíveis, proteja o acesso utilizando o guia: [Proteger um diretório ou a interface de administração do seu website por ficheiros .htaccess e .htpasswd](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password).
- Esta operação só é possível a partir de um alojamento web OVHcloud.

:::

</details>
