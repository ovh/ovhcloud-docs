## Objetivo

Uma base de dados (DB) permite armazenar elementos ditos dinâmicos, como comentários ou artigos, por exemplo. Estas bases de dados são atualmente utilizadas pela quase totalidade dos sistemas de gestão de conteúdos (CMS) como o WordPress ou o Joomla!.

**Saiba como criar uma base de dados no servidor de bases de dados e dar acesso aos utilizadores.**

## Requisitos

- Dispor de uma [instância Web Cloud Databases](/links/web/databases) (incluída numa oferta de [alojamento web](/links/web/hosting) Performance, Agency, Agency Plus ou Agency Max).

[[cpnav:web-cloud-databases]]

## Instruções

### Criar uma base de dados

Clique nos separadores abaixo para ver cada um dos **4** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    Clique no separador <code className="action">Bases de dados</code>.

    <img className="thumbnail" alt="Separador Bases de dados de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 3">
    Clique em <code className="action">Adicionar uma base de dados</code>, acima da tabela das bases de dados.

    <img className="thumbnail" alt="Botão Adicionar uma base de dados acima da tabela das bases de dados" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    A criação de esquemas PostgreSQL não está atualmente disponível nos servidores Web Cloud Databases.

    :::

  </Tab>
  <Tab label="Passo 4">
    O painel **Adicionar uma base de dados** abre-se à direita. Preencha os campos de acordo com os critérios indicados por baixo de cada um deles:

    - **Nome da base de dados** (obrigatório): é o nome da sua futura base de dados.
    - **Acesso a esta base de dados**: escolha quem poderá ligar-se à base de dados e efetuar consultas.
        - **Sem acesso por agora** (opção predefinida): a base de dados é criada sem utilizador. Poderá atribuir permissões a um utilizador mais tarde.
        - **Um utilizador existente**: selecione o **Utilizador** e, em seguida, as respetivas **Permissões** na base de dados.
        - **Um novo utilizador**: preencha os campos abaixo para criar o utilizador ao mesmo tempo que a base de dados.
    - **Nome de utilizador** (apenas com **Um novo utilizador**): o utilizador que poderá ligar-se à base de dados e efetuar consultas.
    - **Permissões** (com **Um utilizador existente** ou **Um novo utilizador**): as permissões associadas ao utilizador na base de dados. Para uma utilização padrão, selecione `Admin`. As permissões podem ser alteradas posteriormente.
    - **Palavra-passe**/**Confirmar a palavra-passe** (apenas com **Um novo utilizador**): introduza uma palavra-passe e confirme-a.

    Clique em <code className="action">Adicionar</code>.

    <img className="thumbnail" alt="Painel Adicionar uma base de dados com um novo utilizador" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

Clique nos separadores abaixo para ver cada um dos **4** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    Clique no separador <code className="action">Utilizadores e permissões</code>.

    <img className="thumbnail" alt="Separador Utilizadores e permissões de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />

### Gerir as permissões dos utilizadores

Para permitir que um utilizador efetue ações numa base de dados, é necessário atribuir-lhe permissões.

Clique nos separadores abaixo para ver cada um dos **4** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    Clique no separador <code className="action">Utilizadores e permissões</code>.

    <img className="thumbnail" alt="Separador Utilizadores e permissões de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 3">
    Cada utilizador é apresentado num quadro com o seu nome. No quadro do utilizador em causa, clique no botão <code className="action">⋮</code> situado à direita da menção **Ações adicionais** e, a seguir, em <code className="action">Gerir permissões</code>.

    <img className="thumbnail" alt="Menu Ações adicionais de um utilizador e opção Gerir permissões" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 4">
    O painel **Permissões de**, seguido do nome do utilizador, abre-se à direita. Apresenta a lista das bases de dados do seu servidor, cada uma com, à sua direita, um menu pendente que indica o nível de permissões do utilizador nessa base de dados. Escolha o nível pretendido para cada base de dados. A alteração aplica-se imediatamente: é apresentada a mensagem **Permissão atualizada**.

    Estão disponíveis 4 níveis de permissões:

    - `Admin`: autorização das consultas do tipo **Select / Insert / Update / Delete / Create / Alter / Drop**.
    - `Leitura / Escrita`: autorização das consultas do tipo **Select / Insert / Update / Delete**.
    - `Apenas leitura`: autorização das consultas do tipo **Select**.
    - `Nenhum`: nenhuma permissão na base de dados.

    :::info
    A distribuição das permissões acima mencionadas é específica da OVHcloud. Assim, um utilizador com permissões de `Admin` poderá utilizar **DDL** (Data Definition Language) e **DML** (Data Manipulation Language), enquanto um utilizador com permissões de `Leitura / Escrita` apenas poderá utilizar **DML** (Data Manipulation Language).

    :::

    <img className="thumbnail" alt="Painel das permissões de um utilizador, um nível por base de dados" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />
  </Tab>
</Tabs>

### Eliminar uma base de dados

:::warning
Ao eliminar uma base de dados num servidor de bases de dados, não é
efetuada qualquer verificação do conteúdo da base de dados. Esta será eliminada
mesmo que ainda contenha dados. Por isso, recomenda-se criar
uma cópia de segurança e descarregá-la para o seu computador antes de qualquer eliminação.

:::

Clique nos separadores abaixo para ver cada um dos **3** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    Clique no separador <code className="action">Bases de dados</code>.

    <img className="thumbnail" alt="Separador Bases de dados de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 3">
    Na tabela, clique no botão <code className="action">⋮</code> da coluna **Ações**, à direita da base de dados em causa e, a seguir, em <code className="action">Eliminar</code>.

    <img className="thumbnail" alt="Menu de uma linha da tabela das bases de dados Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    Na janela **Eliminar base de dados** que se abre, confirme a eliminação clicando em <code className="action">Eliminar</code>.

    <img className="thumbnail" alt="Janela de confirmação da eliminação de uma base de dados" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/delete-database-dialog.png" loading="lazy" />
  </Tab>
</Tabs>
