## Objetivo

As soluções [Web Cloud Databases](/links/web/databases) podem ser utilizadas com serviços da OVHcloud ou externas à OVHcloud.

Por predefinição e por razões de segurança, nestas soluções:

- Apenas os endereços IP associados à nossa infraestrutura de alojamentos partilhados são autorizados a aceder ao conteúdo das bases de dados.
- O acesso aos logs da solução não é restrito em função dos endereços IP. Isto permite que um utilizador aceda à Internet através de um computador, por exemplo.

Precisa de alterar estas permissões/restrições?

**Saiba como autorizar um ou vários endereços IP a aceder à sua solução Web Cloud Databases.**

## Requisitos

- Dispor de uma solução [Web Cloud Databases](/links/web/databases).
- Conhecer o endereço IP (ou o intervalo de endereços IP) a autorizar na sua solução.

[[cpnav:web-cloud-databases]]

## Instruções

### Autorizar um endereço IP ou um intervalo de endereços IP

:::info
Lembrete: se acabou de ativar a sua solução [Web Cloud Databases](/links/web/databases) e pretende utilizá-la com uma oferta de [alojamento web OVHcloud](/links/web/hosting), os endereços IP dessas ofertas já são autorizados por predefinição.

:::

Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância correspondente.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Na página que se abre, clique no separador <code className="action">IPs autorizados</code>.

    <img className="thumbnail" alt="Separador IPs autorizados de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na página que aparece, clique no botão <code className="action">Adicionar um IP</code> situado por cima da tabela.

    <img className="thumbnail" alt="Botão Adicionar um IP acima da tabela dos IPs autorizados" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Se pretender alterar um endereço IP ou um intervalo de endereços IP já autorizado, clique diretamente na tabela no botão <code className="action">⋮</code> da coluna **Ações**, à direita da linha correspondente ao endereço IP ou ao intervalo de endereços IP a alterar e, a seguir, em <code className="action">Editar</code>. Poderá alterar o seu nome e as suas autorizações; o próprio endereço IP não pode ser alterado.

    <img className="thumbnail" alt="Menu de uma linha da tabela dos IPs autorizados" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Etapa 4">
    Na janela **Adicionar um endereço IP autorizado** que se abre, vários campos devem ser preenchidos:

    <img className="thumbnail" alt="Janela Adicionar um endereço IP autorizado e os seus campos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (obrigatório): Introduza aqui o endereço IP (por exemplo: `203.0.113.44`) ou o intervalo de endereços IP (por exemplo: `203.0.113.0/24`, que representa todos os endereços IP de `203.0.113.0` a `203.0.113.255`) que deseja autorizar na sua solução Web Cloud Databases.
    - **Nome** (obrigatório): Pode, por exemplo, indicar a função do endereço IP ou do intervalo de endereços IP em causa.
    - **Permitir acesso ao serviço** (selecionada por predefinição): Selecione esta caixa para que o endereço IP ou o intervalo de endereços IP seja autorizado a aceder às bases de dados presentes na sua solução Web Cloud Databases.
    - **Permitir acesso SFTP**: Selecione esta caixa para que o endereço IP ou o intervalo de endereços IP seja autorizado a aceder aos logs da sua solução Web Cloud Databases.

    :::warning
    É fortemente desaconselhado selecionar a caixa **Permitir acesso ao serviço** para autorizar o intervalo de endereços IP `0.0.0.0/0` a aceder às suas bases de dados.

    Com efeito, isto permitiria autorizar o acesso às suas bases de dados a todos os endereços IPv4 existentes.

    :::

    Depois de introduzir as informações, clique no botão <code className="action">Adicionar</code>.
  </Tab>
</Tabs>

## Casos particulares

**Clique nos casos abaixo para ver as respetivas informações.**

<details>

<summary>O intervalo de endereços IP 0.0.0.0/0</summary>

Aquando da ativação da sua solução Web Cloud Databases, já está presente por predefinição uma linha para o intervalo de endereços IP `0.0.0.0/0` para autorizar o acesso em **SFTP** à solução.

Esta autorização é implementada voluntariamente para lhe permitir aceder aos ficheiros de logs da sua solução Web Cloud Databases sem ter de declarar o endereço IP do seu ponto de acesso à Internet.

Com efeito, este endereço IP pode mudar regularmente em função dos fornecedores de acesso à Internet.

Além disso, recomendamos que **não** altere esta autorização e que não autorize o acesso às bases de dados presentes na sua solução Web Cloud Databases.

Efetivamente, isto permitiria autorizar o acesso às suas bases de dados a todos os endereços IPv4 existentes, o que representa um risco para a segurança dos seus dados.

</details>

<details>

<summary>A autorização de acesso aos alojamentos web da OVHcloud</summary>

Aquando da ativação da sua solução Web Cloud Databases, a autorização de acesso aos alojamentos web da OVHcloud está ativada por predefinição.

Se deseja desativar esta autorização porque não utiliza nenhum alojamento web com a sua solução Web Cloud Databases, clique nos separadores abaixo para visualizar cada uma das **3** etapas.
