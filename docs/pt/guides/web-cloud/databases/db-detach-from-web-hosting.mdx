## Objetivo

As soluções [Web Cloud Databases](/links/web/databases) podem ser ativadas gratuitamente a partir das nossas [ofertas de alojamento web](/links/web/hosting) Performance, Agency, Agency Plus e Agency Max. Neste caso, elas serão associadas ao alojamento web a partir do qual foram ativadas. Durante a utilização dos serviços, pode ser necessário desassociar a solução Web Cloud Databases do alojamento web ao qual está associada.

**Saiba como desassociar a sua solução Web Cloud Databases de um alojamento web.**

## Requisitos

- Ter uma [instância Web Cloud Databases](/links/web/databases) associada a uma oferta de [alojamento web](/links/web/hosting) Performance, Agency, Agency Plus ou Agency Max.
- Ser, no mínimo, o contacto "[Administrador](/guides/account-and-service-management/account-information/managing-contacts)" dos serviços sobre os quais deseja agir.

[[cpnav:web-hosting]]

## Instruções

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e selecione o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Na secção **Bases de dados**, encontrará a menção **Web Cloud DB**. Clique no botão <code className="action">⋮</code> situado à sua direita e, a seguir, em <code className="action">Desvincular a minha base de dados PrivateSQL</code>.

    <img className="thumbnail" alt="Secção Bases de dados e menu da linha Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na nova página que se abre, escolha a duração de **Compromisso** pretendida para a sua solução Web Cloud Databases. O **Resumo** lembra que a sua base de dados passará a ser faturada ao preço padrão e que esta ação é irreversível. Clique em <code className="action">Seguinte</code> e, a seguir, siga as etapas indicadas até ao pagamento.

    <img className="thumbnail" alt="Página Desvincular a minha base de dados PrivateSQL, com a oferta, o compromisso e o resumo" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/detach-web-cloud-db.png" loading="lazy" />
  </Tab>
</Tabs>

Depois de realizar estas 3 etapas e pagar a nota de encomenda, a sua solução Web Cloud Databases será desassociada num prazo máximo de algumas horas.
