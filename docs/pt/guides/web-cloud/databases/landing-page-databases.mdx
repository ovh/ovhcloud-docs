## Web Cloud Databases

As [OVHcloud Web Cloud Databases](/links/web/databases) são um serviço de bases de dados geridas (MySQL, PostgreSQL e MariaDB) para os seus sites e aplicações, utilizável com um alojamento web, um VPS ou outros produtos OVHcloud. Esta página reúne toda a documentação, organizada por tema: dos primeiros passos à configuração, passando pela migração.
