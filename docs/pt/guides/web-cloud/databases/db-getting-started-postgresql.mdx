Deseja utilizar PostgreSQL? Descubra como criar e gerir facilmente as suas bases de dados!

## Generalidades

### Pré-requisitos

- Uma instância Web Cloud Databases
- Ter consultado [o guia Web Cloud Databases](/guides/web-cloud/databases/db-getting-started)

### O que é uma base de dados PostgreSQL?
PostgreSQL é um sistema de gestão de bases de dados relacionais e de objetos (SGBDRO). Trata-se de um sistema robusto e extensível, capaz de manipular com total fiabilidade grandes volumes de dados. Dispõe igualmente de uma comunidade opensource bastante ativa.

## Ligação à base de dados

:::info
Tenha em conta que esta oferta não dá acesso ao Host, mas sim às bases de dados alojadas neste. Os comandos SQL genéricos funcionam sem qualquer problema, e os programas como o HeidiSQL ou o SQuirreL SQL são totalmente compatíveis.

:::

Para se ligar à sua base de dados, certifique-se de que dispõe de:

- o endereço da sua instância de base de dados
- a porta da sua base de dados
- o nome de utilizador da sua base de dados
- a palavra-passe da sua base de dados
- o nome da sua base de dados

Todas estas informações estão disponíveis na consola OVHcloud, na página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.

Está igualmente disponível um guia: [Web Cloud Databases - Primeira utilização](/guides/web-cloud/databases/db-getting-started).

### Ligação através de linha de comandos

```bash
psql --host=server --port=port --username=user --password database_name
```

### Ligação através de um script PHP

```php
1. <?php
2. $myPDO = new PDO('pgsql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

## Extensões PostgreSQL disponíveis

O Web Cloud Databases disponibiliza várias extensões PostgreSQL que permitem acrescentar funcionalidades suplementares às suas bases de dados. Pode ativá-las e desativá-las na consola OVHcloud, no separador <code className="action">Bases de dados</code> da sua instância.

Para ver a lista de extensões disponíveis, consulte o guia "[Ativar as extensões PostgreSQL](/guides/web-cloud/databases/db-enable-postgresql-extensions#extensões-disponíveis)".

## Exportar e importar uma base de dados PostgreSQL

- **Exportar a minha base de dados através de linha de comandos**

```bash
pg_dump --host=server --port=port --username=user --password database_name > database_name.sql
```

- **Importar a minha base de dados através de linha de comandos**

```bash
psql --host=server --port=port --username=user --password database_name < database_name.sql
```

:::info
Em alguns casos, a RAM disponível na sua instância Web Cloud Databases pode não permitir realizar a exportação ou a importação pretendida. Se for esse o caso, recomendamos que utilize a ferramenta de importação fornecida pela OVHcloud. Se necessário, consulte a documentação "[Web Cloud Databases - Primeira utilização](/guides/web-cloud/databases/db-getting-started#importar-uma-base-de-dados)".

:::
