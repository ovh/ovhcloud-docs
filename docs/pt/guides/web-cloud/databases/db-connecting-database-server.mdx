## Objetivo

Pode consultar o conteúdo da sua base de dados através de uma interface. Existem várias formas de se ligar a ela.

**Saiba como ligar-se à sua base de dados no seu servidor de bases de dados.**

## Requisitos

- Uma [instância Web Cloud Databases](/links/web/databases) (incluída numa oferta de [alojamento web](/links/web/hosting) Performance, Agency, Agency Plus ou Agency Max).

[[cpnav:web-cloud-databases]]

## Instruções

:::info
As soluções [Web Cloud Databases](/links/web/databases) não dão acesso ao sistema de gestão de bases de dados em si, mas às bases de dados alojadas nesse sistema.

- Não existe um acesso super-utilizador "root".
- Os comandos SQL genéricos funcionam normalmente e os softwares do tipo HeidiSQL, SQuirreL SQL ou Adminer são plenamente compatíveis.

:::

### Ligar-se a uma base de dados MySQL ou MariaDB

:::info
Uma vez que a MariaDB é um fork do MySQL, os comandos são exatamente iguais para estes dois tipos de bases de dados.

:::

#### Ligação através do phpMyAdmin OVHcloud

Clique nos separadores abaixo para ver cada um dos **4** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    Obtenha as seguintes informações de ligação:

    - **Servidor (nome do host) e porta:** visíveis no separador <code className="action">Visão geral</code>, secção **SQL**, campos **Nome do host** e **Porta**.
    - **Utilizador:** visível no separador <code className="action">Utilizadores e permissões</code>.
    - **Palavra-passe:** a palavra-passe associada ao utilizador. Se a esqueceu, aceda ao separador <code className="action">Utilizadores e permissões</code>, clique no botão <code className="action">⋮</code> do utilizador em causa e depois em <code className="action">Alterar palavra-passe</code>.

    <img className="thumbnail" alt="Secção SQL da visão geral com o nome do host e a porta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />

    :::warning
    Se alterar a palavra-passe de um utilizador da base de dados, todas as aplicações/websites que acedem a esta base de dados devem ser atualizados em conformidade.

    :::

  </Tab>
  <Tab label="Passo 3">
    No separador <code className="action">Visão geral</code>, secção **SQL**, clique no botão <code className="action">⋮</code> à direita de **Ações adicionais** e depois em <code className="action">Interface de administração</code>. O phpMyAdmin abre-se num novo separador do seu navegador.

    <img className="thumbnail" alt="Menu Ações adicionais da secção SQL com a entrada Interface de administração" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-additional-actions.png" loading="lazy" />

    :::info
    Se a entrada **Interface de administração** não aparecer no menu, o phpMyAdmin OVHcloud não está disponível para a sua instância. Nesse caso, utilize um dos métodos da secção "[Ligação à base de dados fora da consola OVHcloud](#connexion-à-la-base-de-données-hors-espace-client)".

    :::

  </Tab>
  <Tab label="Passo 4">
    Na página de início de sessão do phpMyAdmin, introduza as informações obtidas no passo 2:

    <img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-login-web-cloud-db.png" loading="lazy" />

    - **Servidor:** introduza o *nome do host* seguido do *número da porta*, separados por "**:**" ou por um "**espaço**". Por exemplo: **aaXXXXX-XXX.eu.clouddb.ovh.net:12345**.
    - **Utilizador:** introduza o *nome de utilizador*.
    - **Palavra-passe:** introduza a *palavra-passe*.
  </Tab>
</Tabs>

Se a ligação for bem-sucedida, será apresentada a página seguinte.

<img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-main-page-web-cloud-db.png" loading="lazy" />

:::warning
**Em caso de erro:**

- O erro #1045 significa que as credenciais estão incorretas. Verifique o nome de utilizador e/ou a palavra-passe.
- O erro #2005 significa que deve verificar o nome do servidor e se este está a funcionar corretamente.

:::

#### Ligação à base de dados fora da consola OVHcloud <a name="connexion-à-la-base-de-données-hors-espace-client"></a>

:::warning
Se utilizar uma solução "Web Cloud Databases"/"SQL Privado", não se esqueça de autorizar o seu IP com a ajuda do guia sobre a [configuração do seu servidor de bases de dados](/guides/web-cloud/databases/db-configure-optimise-database-server#gerir-os-seus-acessos).

:::

Clique nos separadores abaixo para ver cada um dos **2** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    Obtenha as seguintes informações de ligação:

    - **Servidor (nome do host):** visível no separador <code className="action">Visão geral</code>, secção **SQL**, campo **Nome do host**.
    - **Porta:** visível no mesmo local, campo **Porta**.
    - **Utilizador:** visível no separador <code className="action">Utilizadores e permissões</code>.
    - **Palavra-passe:** a palavra-passe associada ao utilizador em causa.
    - **Nome da base de dados:** visível no separador <code className="action">Bases de dados</code>.

    <img className="thumbnail" alt="Secção SQL da visão geral com o nome do host e a porta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />
  </Tab>
</Tabs>

**Clique no método de ligação pretendido para ver o conteúdo.**

<details>

<summary>Ligação através da linha de comandos</summary>

```bash
mysql --host=server --user=user --port=port --password=password database_name
```

</details>

<details>

<summary>Ligação através de um script PHP</summary>

```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

</details>

<details>

<summary>Ligação através de um programa (SQuirreL SQL)</summary>

:::info
Neste exemplo, utilizamos o programa open-source SQuirreL, mas outras interfaces como o HeidiSQL ou o Adminer são plenamente compatíveis.

:::

- Inicie o SQuirreL SQL e clique em <code className="action">Aliases</code> e, a seguir, em <code className="action">+</code>

<img className="thumbnail" alt="iniciar o SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Preencha os campos abaixo e valide com o botão <code className="action">OK</code>:
    - **Name**: Escolha um nome
    - **Driver**: Escolha "MySQL Driver"
    - **URL**: Indique o endereço do servidor e a porta no formato `jdbc:mysql://server:port`
    - **User Name**: Indique o nome de utilizador
    - **Password**: Indique a palavra-passe

<img className="thumbnail" alt="configuração da ligação" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Valide novamente com o botão <code className="action">Connect</code>

<img className="thumbnail" alt="validação da ligação" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

Está agora ligado à sua base de dados:

<img className="thumbnail" alt="configuração da ligação" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

</details>

<details>

<summary>Ligação através do phpMyAdmin</summary>

Pode utilizar a sua própria interface phpMyAdmin para explorar o conteúdo da base de dados. Para isso, instale o phpMyAdmin no seu próprio servidor ou alojamento web. Durante a instalação, certifique-se de que configura corretamente as informações do servidor de bases de dados e da base de dados pretendida, para que o phpMyAdmin consiga ligar-se.

</details>
