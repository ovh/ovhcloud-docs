## Objetivo

O **Valkey** é um sistema de armazenamento de dados **em memória**, de código aberto, compatível com os clientes e os protocolos do ecossistema Redis (RESP, REdis Serialization Protocol). É adequado para **caches**, **sessões**, **filas de espera ligeiras** e **contadores** de elevado desempenho.

**Saiba como ligar-se à sua instância Valkey no Web Cloud Databases: autorização dos endereços IP, obtenção dos parâmetros de ligação e teste a partir de um cliente de linha de comandos.**

:::warning
Proteja o acesso à sua instância (IP autorizados, palavras-passe robustas) e efetue testes em pré-produção antes da colocação em produção.

:::

## Instruções

### Parte 1 — Autorizar o endereço IP de acesso

Por predefinição, a sua instância Valkey recusa as ligações públicas. Para autorizar (colocar na lista branca) o endereço IP a partir do qual se liga, consulte o nosso guia "[Web Cloud Databases - Como autorizar um endereço IP?](/guides/web-cloud/databases/db-authorise-ip-mask)"

Repita a operação para cada máquina que deva aceder à sua instância Valkey.

#### Definir a palavra-passe do utilizador `default`

A sua instância Valkey é fornecida com um utilizador `default`, a única conta disponível: utilize-a para se ligar.

:::warning
A respetiva palavra-passe nunca é apresentada na Área de Cliente OVHcloud. Deve alterá-la pelo menos uma vez para a conhecer.

:::

#### Guardar as suas informações

Conserve as seguintes informações:

- Nome do host
- Porta
- Palavra-passe do utilizador `default`

Estes elementos são necessários para testar a ligação à sua instância a partir de um cliente Valkey ou da sua aplicação.

### Parte 3 — Testar a ligação com um cliente de linha de comandos

Para verificar se a sua instância Valkey está funcional, ligue-se a ela uma primeira vez:

#### Instalar o cliente de ligação

Neste exemplo, utilizamos o cliente `redis-cli`, compatível com o Valkey e fácil de instalar. Pode utilizar o cliente que preferir. Abra um terminal e execute o comando abaixo consoante o seu sistema operativo.

<Tabs>
  <Tab label="Debian/Ubuntu">
    ```bash
    sudo apt update && sudo apt -y install redis-tools
    ```
  </Tab>
  <Tab label="AlmaLinux/Rocky">
    ```bash
    sudo dnf -y install redis
    ```
  </Tab>
  <Tab label="macOS">
    Instale o [Homebrew](https://brew.sh/pt/) seguindo as instruções do respetivo site e, em seguida, instale o `redis-cli`:

    ```bash
    brew install redis
    ```
  </Tab>
  <Tab label="Windows">
    No menu Iniciar, escreva `PowerShell`, clique com o botão direito no resultado e, em seguida, clique em <code className="action">Executar como administrador</code>.

    Instale o [Chocolatey](https://chocolatey.org/install) executando o comando abaixo:

    ```powershell
    Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
    ```

    Instale o `redis-cli`:

    ```powershell
    choco install redis-64 -y
    ```
  </Tab>
</Tabs>

Depois de instalar o cliente, verifique se funciona executando o comando abaixo:

```bash
redis-cli --version
```

#### Ligar-se à instância

No seu terminal, execute o comando abaixo:

```bash
redis-cli -h <hostname> -p 6379
```

Substitua `<hostname>` pelo seu nome de anfitrião e `6379` pela sua porta, caso seja diferente. Para obter estes valores, consulte a secção "[Parte 2 — Preparar os parâmetros de ligação](#get-credentials)".

#### Verificar se tudo funciona

Se a ligação for bem-sucedida, é apresentada a linha de comandos da sua instância. Autentique-se com o comando `AUTH`, substituindo `<password>` pela palavra-passe do utilizador `default`:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> AUTH <password>
OK
```

Em seguida, verifique se o servidor responde:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> PING
```

A base de dados deve responder:

```console
PONG
```

Experimente também:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> SET ovh-test-connexion "hello"
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> GET ovh-test-connexion
```

Deve visualizar:

```console
"hello"
```

Elimine a chave de teste:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> DEL ovh-test-connexion
```

Para sair, escreva:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> QUIT
```

Se os testes anteriores funcionarem, a sua instância Valkey está operacional.
