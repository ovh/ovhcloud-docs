## Objetivo

A solução [Web Cloud Databases](/links/web/databases) pode conter várias bases de dados. Permite definir um ou vários utilizadores para a gestão e a utilização das suas bases de dados. Estes utilizadores podem ter direitos mais ou menos elevados em função das suas funções ao nível das suas bases de dados.
Durante a utilização do produto, pode ser necessário modificar os direitos de um utilizador no seu [Web Cloud Databases](/links/web/databases).

**Saiba como alterar os direitos de um utilizador no seu serviço Web Cloud Databases.**

## Requisitos

- Dispor de uma solução [Web Cloud Databases](/links/web/databases) e de um ou vários utilizadores.

[[cpnav:web-cloud-databases]]

## Instruções

:::info
Para criar um novo utilizador na sua solução Web Cloud Databases, consulte a secção **Criar um utilizador** do nosso guia "[Criar bases de dados e utilizadores no servidor de bases de dados](/guides/web-cloud/databases/db-create-databases-users)".

:::

Clique nos separadores abaixo para visualizar cada uma das **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância correspondente.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Na página que aparece, clique no separador <code className="action">Utilizadores e permissões</code>.

    <img className="thumbnail" alt="Separador Utilizadores e permissões de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Cada utilizador é apresentado num quadro com o seu nome. No quadro do utilizador em causa, clique no botão <code className="action">⋮</code> situado à direita da menção **Ações adicionais** e, a seguir, em <code className="action">Gerir permissões</code>.

    <img className="thumbnail" alt="Menu Ações adicionais de um utilizador e opção Gerir permissões" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    O painel **Permissões de**, seguido do nome do utilizador, abre-se à direita. Apresenta a lista de todas as bases de dados presentes na sua solução Web Cloud Databases e indica, para cada uma delas, o nível de permissões de que o seu utilizador dispõe, num menu pendente à sua direita.

    <img className="thumbnail" alt="Painel das permissões de um utilizador, um nível por base de dados" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />

    É aqui que poderá modificar as permissões do seu utilizador para cada uma das suas bases de dados. Para isso, em cada base de dados em causa, basta selecionar, no menu pendente da base de dados, o nível de permissões que pretende atribuir ao seu utilizador. A alteração fica efetiva imediatamente: é apresentada a mensagem **Permissão atualizada**.
  </Tab>
</Tabs>
