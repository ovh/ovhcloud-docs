## Objetivo

A solução Web Cloud Databases fornece uma instância de bases de dados com recursos dedicados e garantidos, proporcionando desempenho e flexibilidade.
Por predefinição, a solução Web Cloud Databases está associada à rede de alojamentos web da OVHcloud. Também pode associá-la a qualquer outra rede através de uma lista de endereços IP autorizados.

**Saiba como começar a utilizar a solução Web Cloud Databases.**

## Requisitos

- Uma [instância Web Cloud Databases](/links/web/databases) (incluída numa oferta de [alojamento web](/links/web/hosting) Performance, Agency, Agency Plus ou Agency Max).

[[cpnav:web-cloud-databases]]

## Instruções

### Ativação do servidor Web Cloud Databases incluído no plano de alojamento web

Se o seu plano de alojamento inclui a opção Web Cloud Databases, clique nos separadores abaixo para ver cada um dos **3** passos.

:::warning
Para ativar esta opção, deve ser, no mínimo, contacto administrador do alojamento web que inclui o serviço Web Cloud Databases. Para obter mais informações sobre a gestão dos contactos, consulte o nosso guia "[Como gerir os contactos (gestores) dos serviços OVHcloud](/guides/account-and-service-management/account-information/managing-contacts)".

:::

<Tabs>
  <Tab label="Passo 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamento web</ManagerLink> e selecione o alojamento web em causa.

    <img className="thumbnail" alt="Página Alojamento web e lista dos alojamentos da conta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    No separador <code className="action">Visão geral</code>, localize a secção **Bases de dados**. A linha **Web Cloud DB** indica que a sua instância ainda não está ativada. Clique em <code className="action">Ativar</code>, por baixo desta linha.

    <img className="thumbnail" alt="Secção Bases de dados do alojamento com a ligação Ativar da linha Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 3">
    Na página **Ativar Web Cloud DB** que é apresentada, escolha a capacidade da sua instância (a capacidade de 512 MB está incluída no seu plano de alojamento, as capacidades superiores são pagas) e, em seguida, o seu motor (PostgreSQL, MariaDB, MySQL ou Valkey) e a sua **Versão**. De seguida, clique em <code className="action">Ativar</code> (capacidade incluída) ou em <code className="action">Encomendar</code> (capacidade paga) e valide a nota de encomenda que se abre num novo separador.

    <img className="thumbnail" alt="Página Ativar Web Cloud DB com a escolha da capacidade, do motor e da versão" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate-page.png" loading="lazy" />

    A sua instância ficará depois acessível a partir da página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.
  </Tab>
</Tabs>

### Consultar as informações gerais da instância

Clique nos separadores abaixo para ver cada um dos **2** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />

    :::info
    O nome do serviço Web Cloud DB na consola OVHcloud contém uma parte da sua referência de cliente e termina com três algarismos (001 para o primeiro serviço Web Cloud Databases instalado, 002 para o segundo, etc.).

    :::

  </Tab>
  <Tab label="Passo 2">
    Certifique-se de que está no separador <code className="action">Visão geral</code>.

    Verifique se as informações apresentadas nas secções **Informações gerais** e **Utilização de recursos** estão corretas ou correspondem às indicações abaixo.

    |Informação|Detalhes|
    |---|---|
    |Estado|Indica, nomeadamente, se a instância está iniciada, a reiniciar ou suspensa. A instância deve estar iniciada para que possa realizar operações.|
    |Motor|Indica o sistema de bases de dados utilizado pelo servidor e a respetiva versão. Verifique a compatibilidade do seu website com a versão escolhida.|
    |Região|Indica a região do datacenter onde a instância foi criada.|
    |Host|Indica o servidor OVHcloud no qual a instância foi criada. Trata-se de uma informação inerente à infraestrutura da OVHcloud e pode ser utilizada nas comunicações relativas a [incidentes OVHcloud](https://www.status-ovhcloud.com/).|
    |Saturação CPU|Indica a frequência com que a instância é limitada pelo CPU que lhe está alocado. Se for elevada, considere encomendar mais RAM.|
    |RAM|Indica a memória RAM disponível para a instância, bem como eventuais excedentes de memória. A instância Web Cloud Databases dispõe de recursos dedicados e garantidos: a sua memória RAM. Se necessário, pode aumentá-la através da ligação **Encomendar mais RAM**.|
    |Quota de armazenamento|Indica o espaço ocupado pelos seus dados face ao espaço incluído na sua oferta. Quando esta quota é atingida, as escritas falham: deve então eliminar dados ou mudar para uma oferta superior.|

    <img className="thumbnail" alt="Secções Informações gerais e Utilização de recursos da visão geral" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/overview.png" loading="lazy" />
  </Tab>
</Tabs>

Clique nos separadores abaixo para ver cada um dos **4** passos.

  </Tab>
  <Tab label="Passo 2">
    Clique no separador <code className="action">Bases de dados</code>.

    <img className="thumbnail" alt="Separador Bases de dados de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 3">
    Clique em <code className="action">Adicionar uma base de dados</code>, acima da tabela das bases de dados.

    <img className="thumbnail" alt="Botão Adicionar uma base de dados acima da tabela das bases de dados" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    A criação de esquemas PostgreSQL não está atualmente disponível nos servidores Web Cloud Databases.

    :::

  </Tab>
  <Tab label="Passo 4">
    O painel **Adicionar uma base de dados** abre-se à direita. Preencha os campos de acordo com os critérios indicados por baixo de cada um deles:

    - **Nome da base de dados** (obrigatório): é o nome da sua futura base de dados.
    - **Acesso a esta base de dados**: escolha quem poderá ligar-se à base de dados e efetuar consultas.
        - **Sem acesso por agora** (opção predefinida): a base de dados é criada sem utilizador. Poderá atribuir permissões a um utilizador mais tarde.
        - **Um utilizador existente**: selecione o **Utilizador** e, em seguida, as respetivas **Permissões** na base de dados.
        - **Um novo utilizador**: preencha os campos abaixo para criar o utilizador ao mesmo tempo que a base de dados.
    - **Nome de utilizador** (apenas com **Um novo utilizador**): o utilizador que poderá ligar-se à base de dados e efetuar consultas.
    - **Permissões** (com **Um utilizador existente** ou **Um novo utilizador**): as permissões associadas ao utilizador na base de dados. Para uma utilização padrão, selecione `Admin`. As permissões podem ser alteradas posteriormente.
    - **Palavra-passe**/**Confirmar a palavra-passe** (apenas com **Um novo utilizador**): introduza uma palavra-passe e confirme-a.

    Clique em <code className="action">Adicionar</code>.

    <img className="thumbnail" alt="Painel Adicionar uma base de dados com um novo utilizador" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

### Autorizar um endereço IP

Para que a instância Web Cloud Databases funcione, é necessário indicar os IPs ou intervalos de IP autorizados a conectar-se às bases de dados.

Para isso, clique nos separadores abaixo para ver cada um dos **4** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    Na página apresentada, clique no separador <code className="action">IPs autorizados</code>.

    <img className="thumbnail" alt="Separador IPs autorizados de uma instância Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 3">
    Na página que aparece, clique no botão <code className="action">Adicionar um IP</code> situado acima da tabela.

    <img className="thumbnail" alt="Botão Adicionar um IP acima da tabela dos IPs autorizados" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Se pretender alterar um endereço IP ou intervalo de endereços IP já autorizado, clique diretamente na tabela no botão <code className="action">⋮</code> da coluna **Ações**, à direita da linha correspondente ao endereço IP ou ao intervalo de endereços IP a alterar, e depois em <code className="action">Editar</code>. Poderá alterar o seu nome e as suas autorizações; o endereço IP propriamente dito não pode ser alterado.

    <img className="thumbnail" alt="Menu de uma linha da tabela dos IPs autorizados" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Passo 4">
    Na janela **Adicionar um endereço IP autorizado** que se abre, vários campos devem ser preenchidos:

    <img className="thumbnail" alt="Janela Adicionar um endereço IP autorizado e os seus campos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (obrigatório): Introduza o endereço IP (p. ex., `203.0.113.44`) ou o intervalo de IP (p. ex., `203.0.113.0/24` que representa todos os endereços IP de `203.0.113.0` a `203.0.113.255`) que pretende autorizar na solução Web Cloud Databases.
    - **Nome** (obrigatório): Pode, por exemplo, indicar a função do endereço IP ou do intervalo de IP em questão.
    - **Permitir acesso ao serviço** (assinalada por predefinição): Assinale esta opção para que o endereço IP ou o intervalo de IP possa aceder às bases de dados da solução Web Cloud Databases.
    - **Permitir acesso SFTP**: Assinale esta opção para que o endereço IP ou o intervalo de IP possa aceder aos logs da solução Web Cloud Databases.

    :::warning
    É fortemente desaconselhado assinalar a opção **Permitir acesso ao serviço** para autorizar o intervalo de IP `0.0.0.0/0` a aceder às suas bases de dados.

    Isto permitiria que todos os endereços IPv4 existentes acedessem às suas bases de dados.

    :::

    Depois de introduzir as informações, clique no botão <code className="action">Adicionar</code>.
  </Tab>
</Tabs>

### Autorizar as ligações a partir de um alojamento web OVHcloud <a name="trustip"></a>

Por predefinição, a solução Web Cloud Databases está automaticamente associada aos alojamentos web da OVHcloud. Se desejar, pode desativar o acesso dos alojamentos web da OVHcloud ao Web Cloud Databases.

Para isso, consulte os casos particulares do nosso guia "[Web Cloud Databases - Como autorizar um endereço IP?](/guides/web-cloud/databases/db-authorise-ip-mask)" para ativar ou desativar o acesso dos alojamentos web da OVHcloud ao Web Cloud Databases.

### Associar o website à base de dados

Agora que a base de dados está criada, um ou mais utilizadores têm permissões sobre ela e pelo menos um endereço IP ou os alojamentos web da OVHcloud foram autorizados na instância Web Cloud Databases, só falta associar o website à base de dados. Este passo pode ser efetuado de várias formas, em função do website ou do CMS (WordPress, Joomla!, etc.) utilizado, bem como da etapa em que se encontra se estiver a instalar um website.

Para isso, necessita das seguintes 5 informações:

|Informação|Descrição|
|---|---|
|Nome da base de dados|O nome definido durante a criação da base de dados.|
|Nome de utilizador|O nome de utilizador definido durante a criação da base de dados ou um eventual utilizador adicional.|
|Palavra-passe do utilizador|A palavra-passe associada ao utilizador, definida nos passos anteriores.|
|Nome de host do servidor|O servidor a indicar para que o website se possa ligar à base de dados.|
|Porta do servidor|A porta de ligação à instância Web Cloud Databases, para que o website se possa ligar à base de dados.|

Para as obter, clique nos separadores abaixo para ver cada um dos **2** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> e escolha a instância em causa.

    <img className="thumbnail" alt="Página Web Cloud DB e lista das instâncias da conta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    Obtenha as seguintes informações de ligação:

    - **Servidor (nome de host) e porta:** visíveis no separador <code className="action">Visão geral</code>, secção **SQL**, campos **Nome do host** e **Porta**.
    - **Utilizador:** visível no separador <code className="action">Utilizadores e permissões</code>.
    - **Palavra-passe:** a palavra-passe associada ao utilizador. Se a esqueceu, aceda ao separador <code className="action">Utilizadores e permissões</code>, clique no botão <code className="action">⋮</code> do utilizador em causa e depois em <code className="action">Alterar palavra-passe</code>.

    <img className="thumbnail" alt="Secção SQL da visão geral com o nome do host e a porta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />

    :::warning
    Se alterar a palavra-passe de um utilizador da base de dados, todas as aplicações/websites que acedem a esta base de dados devem ser atualizados em conformidade.

    :::

  </Tab>
</Tabs>

:::warning
O campo <code className="action">porta</code> pode não estar disponível na configuração do seu website. Deve adicionar este campo após o nome de host do servidor, separando-os com *:*.

Por exemplo, para o nome de host `aaXXXXX-XXX.eu.clouddb.ovh.net` com a porta SQL `12345`, deverá introduzir `aaXXXXX-XXX.eu.clouddb.ovh.net:12345` na secção "Host" / "Nome de host".

:::

:::info
A OVHcloud não disponibiliza nenhuma porta encriptada através de TLS nos servidores de bases de dados Valkey. As comunicações devem efetuar-se unicamente através da porta predefinida, não encriptada.

:::
