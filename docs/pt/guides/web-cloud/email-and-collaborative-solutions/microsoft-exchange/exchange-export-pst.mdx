## Objetivo

Exportar uma caixa de correio no formato PST dá-lhe uma cópia local da mesma: para a arquivar antes de eliminar uma conta, entregá-la à saída de um colaborador, transferi-la para outro serviço de e-mail ou cumprir uma obrigação de conservação. O Microsoft Exchange na OVHcloud pode exportar uma caixa de correio do lado do servidor: pede a exportação, a OVHcloud constrói-a e, em seguida, descarrega um arquivo ZIP que contém um ou vários ficheiros `.pst`, `readme.md` e `checksum.txt`. A exportação não passa pelo Outlook: a Área de Cliente OVHcloud e a API OVHcloud cobrem, cada uma, a operação de ponta a ponta.

Esta funcionalidade está disponível para Hosted Exchange, Private Exchange e Trusted Exchange. Aplica-se às caixas de correio individuais: os grupos não podem ser exportados.

**Este guia explica como exportar uma caixa de correio Exchange para um arquivo PST, a partir da Área de Cliente OVHcloud ou através da API OVHcloud.**

## Requisitos

- Dispor de um serviço [Hosted Exchange](/links/web/emails-hosted-exchange), [Private Exchange](/links/web/emails-private-exchange) ou [Trusted Exchange](/links/web/emails-trusted-exchange).
- Dispor de direitos de administração sobre esse serviço na <ManagerLink to="/">Área de Cliente OVHcloud</ManagerLink>.
- Dispor de espaço em disco local suficiente para o arquivo ZIP e para o seu conteúdo extraído.
- Para o método API: dispor de credenciais API geradas através da <CreateToken rights="GET=/email/exchange/*&POST=/email/exchange/*&DELETE=/email/exchange/*">página de criação de tokens OVHcloud</CreateToken>, com, no mínimo, os direitos `GET`, `POST` e `DELETE` em `/email/exchange/*`.

:::warning
**Uma exportação por caixa de correio a cada 24 horas.** Depois de pedida uma exportação para um endereço de e-mail, a seguinte só é aceite 24 horas mais tarde. Tenha isto em conta antes de exportar várias caixas de correio em sequência.

:::

## Instruções

### Exportar a partir da Área de Cliente

1. Abra o separador <code className="action">Contas de e-mail</code>.
2. Na linha da caixa de correio a exportar, clique em <code className="action">...</code> e, em seguida, em <code className="action">Exportar para o formato PST</code>.

    <img className="thumbnail" alt="Menu de ações da conta com a entrada Exportar para o formato PST" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-menu.png" loading="lazy" />

3. Na janela <code className="action">Exportar para o formato .pst</code>, clique em <code className="action">Transferir</code> para iniciar a exportação. Esta é executada em segundo plano e demora entre alguns minutos e várias horas, consoante o tamanho da caixa de correio. Pode fechar a janela e sair da página: volte a abri-la a qualquer momento para ver a progressão, indicada em percentagem.

    <img className="thumbnail" alt="Janela Exportar para o formato .pst a mostrar a progressão da exportação" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-progress.png" loading="lazy" />

4. Concluída a exportação, abra o mesmo menu <code className="action">...</code> e clique novamente em <code className="action">Exportar para o formato PST</code>. A ligação de transferência é então gerada automaticamente, o que demora 2 a 3 minutos.

    <img className="thumbnail" alt="Janela Exportar para o formato .pst durante a geração da ligação de transferência" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-link.png" loading="lazy" />

5. Quando a ligação estiver pronta, a janela confirma que a caixa de correio está disponível no formato `.pst`. Clique em <code className="action">Transferir</code> para obter o arquivo ZIP e, em seguida, extraia-o e verifique-o (consulte "[Verificar e abrir o arquivo](#verificar-e-abrir-o-arquivo)").

    <img className="thumbnail" alt="Janela de exportação a propor a transferência do arquivo e uma nova exportação" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-download.png" loading="lazy" />

:::info
A ligação de transferência é temporária: a janela indica a data até à qual o ficheiro permanece disponível. Passada essa data, o arquivo é eliminado e é necessária uma nova exportação. A mesma janela permite clicar em <code className="action">Lançar uma nova exportação</code>, o que **elimina imediatamente o arquivo anterior**.

:::

### Exportar através da API

Dois objetos suportam todo o processo: `export` constrói o arquivo e dá conta da sua progressão, e `exportURL` fornece um URL de transferência temporário. Todas as chamadas abaixo pertencem à <ApiLink section="/email/exchange">secção `/email/exchange`</ApiLink> da API OVHcloud.

#### Encontrar os parâmetros de caminho

Cada chamada precisa de 3 valores: o nome da organização, o nome do serviço e o endereço da caixa de correio. Os 2 primeiros são nomes internos, do tipo `ab12345-ovh`, e não as designações apresentadas na Área de Cliente OVHcloud. Obtenha-os por ordem: cada chamada alimenta a seguinte.

**1. Organização** (`organizationName`): liste as organizações Exchange da sua conta com a seguinte chamada API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange"} />

**2. Serviço** (`exchangeService`): liste os serviços Exchange da organização com a seguinte chamada API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service"} />

**3. Caixa de correio** (`primaryEmailAddress`): liste as contas de e-mail do serviço com a seguinte chamada API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account"} />

Cada chamada devolve uma lista de cadeias de caracteres. Se o endereço da caixa de correio contiver caracteres não permitidos num URL, codifique-os em percentagem no caminho (`+` passa a `%2B`, etc.).

#### Pedir a exportação

Peça a exportação da caixa de correio com a seguinte chamada API:

<Api version="v1" section="/email/exchange" method="POST" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

A chamada não recebe nenhum parâmetro no corpo do pedido e devolve uma tarefa, que apenas confirma que o pedido foi registado:

```json
{
  "id": 123456789,
  "function": "addExportPstRequest",
  "status": "todo",
  "todoDate": "2026-09-01T10:12:33+02:00",
  "finishDate": null
}
```

#### Acompanhar a progressão

Consulte o pedido de exportação para acompanhar a sua progressão:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

| Propriedade | Tipo | Descrição |
|---|---|---|
| `creationDate` | datetime | Data de criação do pedido de exportação |
| `percentComplete` | long | Progressão da exportação, em percentagem |
| `taskPendingId` | long | Identificador da tarefa em curso, `0` quando nenhuma está em execução |

```json
{
  "creationDate": "2026-09-01T10:12:33+02:00",
  "percentComplete": 42,
  "taskPendingId": 123456789
}
```

Repita esta chamada até `percentComplete` atingir `100`, no máximo uma vez por minuto. Um erro `404` significa que não existe nenhum pedido de exportação para esta caixa de correio: ou nunca foi criado, ou já foi eliminado.

Os estados de tarefa são `todo`, `doing`, `done`, `error`, `standby` e `canceled`. As funções de tarefa associadas à exportação são `addExportPstRequest`, `deleteExportPstRequest` e `generatePstUrl`.

#### Obter o URL de transferência

O objeto `export` nunca devolve um URL de transferência. Gerar a ligação requer 2 chamadas.

**1. Gerar o URL**: crie a ligação de transferência, o que regista uma tarefa `generatePstUrl`, com a seguinte chamada API:

<Api version="v1" section="/email/exchange" method="POST" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/exportURL"} />

**2. Ler o URL**: concluída a tarefa, leia a ligação gerada com a seguinte chamada API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/exportURL"} />

| Propriedade | Tipo | Descrição |
|---|---|---|
| `url` | string | URL de transferência do arquivo |
| `expiration` | datetime | Data de expiração do URL |

```json
{
  "url": "https://exchange-export.storage.example/abc123/john.smith.zip?token=...",
  "expiration": "2026-09-01T11:15:00+02:00"
}
```

O URL já está assinado: descarregue o arquivo diretamente a partir deste URL, sem cabeçalho de autenticação. Um erro `404` na chamada `GET` significa que o URL ainda não foi gerado (a tarefa `generatePstUrl` continua em curso) ou que expirou.

:::info
**O período de validade do URL é limitado.** Leia `expiration` em vez de presumir o prazo e gere o URL apenas no momento de descarregar. Depois de expirado, repita a chamada `POST` em `exportURL` para obter uma nova ligação: enquanto o arquivo existir, não é preciso refazer a exportação.

:::

#### Eliminar o pedido de exportação

Elimine o pedido de exportação com a seguinte chamada API:

<Api version="v1" section="/email/exchange" method="DELETE" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

Utilize-a para cancelar uma exportação em curso ou para eliminar o pedido depois de descarregado o arquivo e poder pedir um novo (sempre dentro do limite de uma exportação por 24 horas). A chamada elimina também o arquivo do lado da OVHcloud: descarregue-o primeiro.

### Verificar e abrir o arquivo

Independentemente do método, o arquivo ZIP contém:

| Elemento | Descrição |
|---|---|
| `*.pst` | Os dados da caixa de correio. Uma caixa de correio volumosa é repartida por vários ficheiros PST. |
| `readme.md` | As notas da OVHcloud sobre a exportação e o seu conteúdo. |
| `checksum.txt` | O hash SHA-256 de cada ficheiro `.pst` do arquivo. |

Extraia o arquivo e, em seguida, verifique os ficheiros PST com `checksum.txt` antes de os importar: uma transferência truncada produz um ficheiro PST que o Outlook recusa abrir ou abre incompleto. Os comandos abaixo pressupõem uma disposição `<hash> <filename>`, uma linha por ficheiro.

No Windows, com o PowerShell:

```powershell
Get-Content .\checksum.txt | Where-Object { $_.Trim() } | ForEach-Object {
    $hash, $file = $_.Trim() -split '\s+', 2
    $file = $file.TrimStart('*')
    $actual = (Get-FileHash $file -Algorithm SHA256).Hash
    "{0,-8} {1}" -f $(if ($actual -eq $hash.ToUpper()) { "OK" } else { "MISMATCH" }), $file
}
```

No Linux ou macOS:

```bash
sha256sum -c checksum.txt
# john.smith.pst: OK
# john.smith-2.pst: OK
```

Se um hash não corresponder, descarregue novamente o arquivo. Se o erro persistir, peça uma nova exportação.

Para abrir o resultado no Outlook clássico para Windows, aceda a <code className="action">Ficheiro</code> > <code className="action">Abrir e Exportar</code> > <code className="action">Abrir Ficheiro de Dados do Outlook</code> e, em seguida, selecione cada ficheiro `.pst` extraído. Atualmente, o novo Outlook para Windows não abre ficheiros `.pst`.

:::info
**Limitações**

- A duração da exportação depende do tamanho da caixa de correio: alguns minutos para uma caixa pequena, várias horas para uma grande. Não existe nenhuma forma de a acelerar.
- Uma caixa de correio só suporta um pedido de exportação, e um novo só é aceite 24 horas após o anterior para o mesmo endereço de e-mail.
- A exportação aplica-se apenas às caixas de correio individuais: os grupos, as contas partilhadas e as contas de recurso não são abrangidos.

:::
