## Obiettivo

Drive è l'applicazione di archiviazione dei file di OVHai Workspace. Mostra i tuoi file e le tue cartelle e consente di creare documenti di produttività direttamente nel browser.

**Scopri come archiviare, creare e organizzare i tuoi file in OVHai Workspace.**

## Prerequisiti

- Disporre di un account OVHai Workspace.
- Aver effettuato l'accesso al tuo spazio di lavoro.

## Procedura <a name="instructions"></a>

### Aprire l'applicazione

Dalla home page del tuo spazio, fai clic su <code className="action">Get started</code> sulla scheda **Drive**, oppure fai clic su <code className="action">Drive</code> nella barra delle applicazioni, a sinistra dello schermo.

### Orientarsi

Il pannello di sinistra separa ciò che ti appartiene (**My drive**) da ciò che altri hanno condiviso con te (**Shared with me**), mentre **Home** riunisce entrambi.

Ordina l'elenco facendo clic sulle intestazioni **Name**, **Modified** o **Size**. Le icone sopra l'elenco creano o importano una cartella o un file.

<img className="thumbnail" alt="L'applicazione Drive su My drive, con una cartella, un documento e un file di testo" src="/images/web-cloud/ovhai-workspace/drive/drive-home-en.png" loading="lazy" style={{ display: 'block', marginInline: 'auto' }} />

:::warning
Il **Trash** non è ancora disponibile: considera ogni eliminazione come definitiva.

:::

### Creare una cartella

1. Fai clic su <code className="action">New</code> in alto nel pannello di sinistra, poi su <code className="action">New folder</code>.
2. Inserisci il **Folder name**, poi fai clic su <code className="action">Create</code>.

La cartella compare nell'elenco, con la data di creazione nella colonna **Modified**.

### Creare un documento

<CardGrid columns={2}>
<div>

1. Fai clic su <code className="action">New</code>, poi posizionati su <code className="action">New file</code>.
2. Scegli il formato desiderato:
    - <code className="action">New document</code> per un documento di testo;
    - <code className="action">New spreadsheet</code> per un foglio di calcolo;
    - <code className="action">New presentation</code> per una presentazione.
3. Inserisci il **File name**, poi fai clic su <code className="action">Create</code>. L'estensione (`.docx`, `.xlsx` o `.pptx`) viene aggiunta se non la indichi.

</div>

### Importare un file

1. Fai clic su <code className="action">New</code>, poi su <code className="action">Upload a file</code>.
2. Seleziona il file sul tuo computer.

Le icone sopra l'elenco consentono di importare anche un'intera cartella.

### Aprire un file

Fai doppio clic su un file per aprirlo nell'applicazione associata al suo formato. La barra in alto propone <code className="action">Back</code>, per tornare all'elenco, e <code className="action">Download</code>.

| File | Si aprono in | Modificabili |
|---|---|---|
| Documenti, fogli di calcolo e presentazioni: `.docx`, `.xlsx`, `.pptx`, `.odt`, `.ods`, `.odp` | OnlyOffice | Sì |
| Note in formato Markdown: `.md` | L'editor Markdown | Sì |
| PDF | Il visualizzatore PDF | No |
| Immagini, audio e video | Il visualizzatore di immagini o il lettore multimediale | No |
| Testo e dati: `.txt`, `.csv`, `.json`, `.yaml`, `.xml`, `.log` | Il visualizzatore di testo | No |

### Gestire un file o una cartella

<CardGrid columns={2}>
<div>

Seleziona la casella davanti a un elemento per visualizzarne le azioni sopra l'elenco: <code className="action">Download</code>, <code className="action">Rename</code> e <code className="action">Delete</code>. Il menu a fine riga propone <code className="action">Rename</code> e <code className="action">Delete</code>.

</div>
<div>

<img className="thumbnail" alt="Un file selezionato, con la barra delle azioni sopra l'elenco" src="/images/web-cloud/ovhai-workspace/drive/drive-selection-en.png" loading="lazy" style={{ display: 'block', marginInline: 'auto' }} />

La condivisione, lo spostamento e la copia compaiono nella barra delle azioni, ma non sono ancora disponibili.

### Cercare un file

Inserisci una parola nel campo **Search my files**, sopra l'elenco. Il campo **Search my workspace**, in alto nella schermata, cerca invece in tutte le applicazioni contemporaneamente.

### Cosa può fare l'assistente con i tuoi file

L'assistente cerca nel tuo spazio e legge il contenuto dei file, non soltanto il loro nome:
