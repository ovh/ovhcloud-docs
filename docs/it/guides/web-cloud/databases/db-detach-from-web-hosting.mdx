## Obiettivo

Le soluzioni [Web Cloud Databases](/links/web/databases) possono essere attivate gratuitamente a partire dalle nostre [offerte di hosting Web](/links/web/hosting) Performance, Agency, Agency Plus e Agency Max. In questo caso, vengono associate all'hosting Web da cui sono state attivate. Durante l'utilizzo dei servizi, potrebbe essere necessario scollegare la soluzione Web Cloud Databases dall'hosting Web al quale è associata.

**Questa guida ti mostra come scollegare la soluzione Web Cloud Databases da un hosting Web.**

## Prerequisiti

- Disporre di un’[istanza Web Cloud Databases](/links/web/databases) associata a una soluzione di [hosting Web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max.
- essere almeno contatto "[Amministratore](/guides/account-and-service-management/account-information/managing-contacts)" dei servizi sui quali si desidera agire.

[[cpnav:web-hosting]]

## Procedura

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi seleziona l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web e lista degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella sezione **Database** trovi la dicitura **Web Cloud DB**. Clicca sul pulsante <code className="action">⋮</code> alla sua destra, poi su <code className="action">Scollega il mio database PrivateSQL</code>.

    <img className="thumbnail" alt="Sezione Database e menu della riga Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella nuova pagina che si apre, scegli la durata di **Impegno** desiderata per la tua soluzione Web Cloud Databases. Il **Riepilogo** ricorda che il tuo database sarà ora fatturato al prezzo standard e che questa azione è irreversibile. Clicca su <code className="action">Avanti</code>, poi segui i passaggi indicati fino al pagamento.

    <img className="thumbnail" alt="Pagina Scollega il mio database PrivateSQL con offerta, impegno e riepilogo" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/detach-web-cloud-db.png" loading="lazy" />
  </Tab>
</Tabs>

Una volta completati questi 3 passaggi e pagato il buono d'ordine, la soluzione Web Cloud Databases sarà scollegata entro poche ore al massimo.
