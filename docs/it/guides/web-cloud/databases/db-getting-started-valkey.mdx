## Obiettivo

**Valkey** è un archivio dati **in memoria**, open source, compatibile con i client e i protocolli dell'ecosistema Redis (RESP, REdis Serialization Protocol). È adatto a **cache**, **sessioni**, **code leggere** e **contatori** ad alte prestazioni.

**Scopri come connetterti alla tua istanza Valkey su Web Cloud Databases: autorizzazione degli indirizzi IP, recupero dei parametri di connessione e test da un client a riga di comando.**

:::warning
Proteggi l'accesso alla tua istanza (IP autorizzati, password robuste) ed effettua i test in preproduzione prima della messa online.

:::

- Disporre di un'[istanza Valkey su Web Cloud Databases](/links/web/databases) (inclusa in un piano di [Hosting Web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max).

## Procedura

### Parte 1 — Autorizzare l'indirizzo IP di accesso

Per impostazione predefinita, la tua istanza Valkey rifiuta le connessioni pubbliche. Per autorizzare (inserire nella whitelist) l'indirizzo IP dal quale ti connetti, consulta la nostra guida "[Web Cloud Databases - Come autorizzare un indirizzo IP?](/guides/web-cloud/databases/db-authorise-ip-mask)"

Ripeti l'operazione per ogni macchina che deve accedere alla tua istanza Valkey.

#### Conservare le tue informazioni

Conserva le seguenti informazioni:

- Nome host
- Porta
- Password dell'utente `default`

Questi elementi sono necessari per testare la connessione alla tua istanza da un client Valkey o dalla tua applicazione.

### Parte 3 — Testare la connessione con un client a riga di comando

Per verificare che la tua istanza Valkey sia funzionante, connettiti a essa una prima volta:

#### Installare il client di connessione

In questo esempio utilizziamo il client `redis-cli`, compatibile con Valkey e semplice da installare. Puoi utilizzare il client che preferisci. Apri un terminale ed esegui il comando riportato di seguito in base al tuo sistema operativo.

<Tabs>
  <Tab label="Debian/Ubuntu">
    ```bash
    sudo apt update && sudo apt -y install redis-tools
    ```
  </Tab>
  <Tab label="AlmaLinux/Rocky">
    ```bash
    sudo dnf -y install redis
    ```
  </Tab>
  <Tab label="macOS">
    Installa [Homebrew](https://brew.sh/it/) seguendo le istruzioni del suo sito, poi installa `redis-cli`:

    ```bash
    brew install redis
    ```
  </Tab>
  <Tab label="Windows">
    Nel menu Start, digita `PowerShell`, clicca con il tasto destro sul risultato, poi clicca su <code className="action">Esegui come amministratore</code>.

    Installa [Chocolatey](https://chocolatey.org/install) eseguendo il comando riportato di seguito:

    ```powershell
    Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
    ```

    Installa `redis-cli`:

    ```powershell
    choco install redis-64 -y
    ```
  </Tab>
</Tabs>

Una volta installato il client, verifica che funzioni eseguendo il comando riportato di seguito:

```bash
redis-cli --version
```

#### Connettersi all'istanza

Nel tuo terminale, esegui il comando riportato di seguito:

```bash
redis-cli -h <hostname> -p 6379
```

Sostituisci `<hostname>` con il tuo nome host e `6379` con la tua porta, se diversa. Per recuperare questi valori, consulta la sezione "[Parte 2 — Preparare i parametri di connessione](#get-credentials)".

#### Verificare che tutto funzioni

Se la connessione va a buon fine, viene visualizzato il prompt dei comandi della tua istanza. Autenticati con il comando `AUTH`, sostituendo `<password>` con la password dell'utente `default`:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> AUTH <password>
OK
```

Verifica poi che il server risponda:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> PING
```

Il database deve rispondere:

```console
PONG
```

Prova anche:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> SET ovh-test-connexion "hello"
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> GET ovh-test-connexion
```

Devi visualizzare:

```console
"hello"
```

Elimina la chiave di test:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> DEL ovh-test-connexion
```

Per uscire, digita:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> QUIT
```

Se i test precedenti funzionano, la tua istanza Valkey è operativa.
