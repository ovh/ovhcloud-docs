## Obiettivo

La soluzione [Web Cloud Databases](/links/web/databases) può contenere diversi database. Permette di definire uno o più utenti per la gestione e l'utilizzo dei database. Questi utenti possono disporre di diritti più o meno elevati in base al loro ruolo a livello di database.
Durante l'utilizzo del prodotto, potrebbe essere necessario modificare i diritti di un utente sul tuo [Web Cloud Databases](/links/web/databases).

**Questa guida ti mostra come modificare i diritti di un utente sulla tua soluzione Web Cloud Databases.**

## Prerequisiti

- Disporre di una soluzione [Web Cloud Databases](/links/web/databases) e di uno o più utenti.

[[cpnav:web-cloud-databases]]

## Procedura

:::info
Per creare un nuovo utente sulla tua soluzione Web Cloud Databases, consulta la sezione **Creare un utente** della nostra guida "[Creare database e utenti sul tuo database server](/guides/web-cloud/databases/db-create-databases-users)".

:::

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella pagina che appare, clicca sulla scheda <code className="action">Utenti e autorizzazioni</code>.

    <img className="thumbnail" alt="Scheda Utenti e autorizzazioni di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Ogni utente viene visualizzato in un riquadro con il suo nome. Nel riquadro dell'utente interessato, clicca sul pulsante <code className="action">⋮</code> situato a destra della dicitura **Altre azioni**, poi su <code className="action">Gestire i permessi</code>.

    <img className="thumbnail" alt="Menu Altre azioni di un utente e voce Gestire i permessi" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Il pannello **Permessi per**, seguito dal nome dell'utente, si apre a destra. Elenca tutti i database presenti sulla tua soluzione Web Cloud Databases e indica, per ciascuno di essi, il livello di diritti di cui dispone l'utente, in un menu a tendina alla sua destra.

    <img className="thumbnail" alt="Pannello dei diritti di un utente, un livello per database" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />

    È qui che puoi modificare i diritti dell'utente per ciascun database. Per farlo, per ciascun database interessato, è sufficiente selezionare, nel menu a tendina del database, il livello di diritti che desideri assegnare al tuo utente. La modifica è effettiva immediatamente: viene visualizzato il messaggio **Permesso modificato**.
  </Tab>
</Tabs>
