## Obiettivo

Un database (DB) permette di archiviare elementi detti dinamici, come commenti o articoli. Questi database sono oggi utilizzati dalla quasi totalità dei sistemi di gestione dei contenuti (CMS) come WordPress o Joomla!.

**Questa guida ti mostra come creare un database sul tuo database server e dare accesso agli utenti.**

## Prerequisiti

- Disporre di un'[istanza Web Cloud Databases](/links/web/databases) (inclusa in un piano di [hosting Web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max).

[[cpnav:web-cloud-databases]]

## Procedura

### Creare un database

Clicca sulle schede qui sotto per visualizzare i **4** step in sequenza.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Clicca sulla scheda <code className="action">Database</code>.

    <img className="thumbnail" alt="Scheda Database di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Clicca su <code className="action">Aggiungere un database</code>, sopra la tabella dei database.

    <img className="thumbnail" alt="Pulsante Aggiungere un database sopra la tabella dei database" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    La creazione di schemi PostgreSQL non è attualmente disponibile sui server Web Cloud Databases.

    :::

  </Tab>
  <Tab label="Step 4">
    Il pannello **Aggiungere un database** si apre a destra. Compila i campi rispettando i criteri indicati sotto ciascuno di essi:

    - **Nome del database** (obbligatorio): è il nome del futuro database.
    - **Accesso a questo database**: scegli chi potrà connettersi al database ed eseguire query.
        - **Nessun accesso per ora** (scelta predefinita): il database viene creato senza utente. Potrai assegnare dei diritti a un utente in seguito.
        - **Un utente esistente**: seleziona l'**Utente** e le sue **Autorizzazioni** sul database.
        - **Un nuovo utente**: compila i campi qui sotto per creare l'utente contemporaneamente al database.
    - **Nome utente** (solo con **Un nuovo utente**): l'utente che potrà connettersi al database ed eseguire query.
    - **Autorizzazioni** (con **Un utente esistente** o **Un nuovo utente**): i diritti associati all'utente sul database. Per un utilizzo standard, seleziona `Admin`. I diritti possono essere modificati successivamente.
    - **Password**/**Conferma la password** (solo con **Un nuovo utente**): inserisci una password, poi confermala.

    Clicca su <code className="action">Aggiungi</code>.

    <img className="thumbnail" alt="Pannello Aggiungere un database con un nuovo utente" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

### Creare un utente

Per utilizzare un database server OVHcloud, crea degli utenti con diritti specifici per la connessione a un database.

Clicca sulle schede qui sotto per visualizzare i **4** step in sequenza.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Clicca sulla scheda <code className="action">Utenti e autorizzazioni</code>.

    <img className="thumbnail" alt="Scheda Utenti e autorizzazioni di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />

    <img className="thumbnail" alt="Pannello Aggiungere un utente e i suoi tre campi" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/add-user.png" loading="lazy" />

### Gestire i diritti degli utenti

Per consentire a un utente di eseguire operazioni su un database, è necessario assegnargli dei diritti.

Clicca sulle schede qui sotto per visualizzare i **4** step in sequenza.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Clicca sulla scheda <code className="action">Utenti e autorizzazioni</code>.

    <img className="thumbnail" alt="Scheda Utenti e autorizzazioni di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Ogni utente viene visualizzato in un riquadro con il suo nome. Nel riquadro dell'utente interessato, clicca sul pulsante <code className="action">⋮</code> situato a destra della dicitura **Altre azioni**, poi su <code className="action">Gestire i permessi</code>.

    <img className="thumbnail" alt="Menu Altre azioni di un utente e voce Gestire i permessi" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    Il pannello **Permessi per**, seguito dal nome dell'utente, si apre a destra. Elenca i database presenti sul tuo server, ciascuno con, alla sua destra, un menu a tendina che indica il livello di diritti dell'utente su quel database. Scegli il livello desiderato per ciascun database. La modifica si applica immediatamente: viene visualizzato il messaggio **Permesso modificato**.

    Sono disponibili 4 livelli di diritti:

    - `Admin`: autorizzazione delle query di tipo **Select / Insert / Update / Delete / Create / Alter / Drop**.
    - `Lettura / Scrittura`: autorizzazione delle query di tipo **Select / Insert / Update / Delete**.
    - `Solo lettura`: autorizzazione delle query di tipo **Select**.
    - `Nessuno`: nessun diritto sul database.

    :::info
    La distribuzione dei diritti sopra indicati è specifica di OVHcloud. Un utente con diritti di `Admin` potrà utilizzare **DDL** (Data Definition Language) e **DML** (Data Manipulation Language), mentre un utente con diritti di `Lettura / Scrittura` potrà utilizzare solo **DML** (Data Manipulation Language).

    :::

    <img className="thumbnail" alt="Pannello dei diritti di un utente, un livello per database" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />
  </Tab>
</Tabs>

### Eliminare un database

:::warning
Quando elimini un database su un database server, non viene eseguita alcuna
verifica del contenuto del database. Questo verrà eliminato anche se
contiene ancora dei dati. Si consiglia quindi di creare
un backup e scaricarlo sul tuo dispositivo prima di qualsiasi eliminazione.

:::

Clicca sulle schede qui sotto per visualizzare i **3** step in sequenza.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Clicca sulla scheda <code className="action">Database</code>.

    <img className="thumbnail" alt="Scheda Database di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Nella tabella, clicca sul pulsante <code className="action">⋮</code> della colonna **Azioni**, a destra del database interessato, poi su <code className="action">Elimina</code>.

    <img className="thumbnail" alt="Menu di una riga della tabella dei database Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    Nella finestra **Eliminare il database** che si apre, conferma l'eliminazione cliccando su <code className="action">Elimina</code>.

    <img className="thumbnail" alt="Finestra di conferma dell'eliminazione di un database" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/delete-database-dialog.png" loading="lazy" />
  </Tab>
</Tabs>
