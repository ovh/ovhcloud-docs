Vuoi utilizzare PostgreSQL? Scopri come creare e gestire i tuoi database con la massima semplicità!

## Introduzione

### Prerequisiti

- Un'istanza Web Cloud Databases attiva
- Aver consultato [la guida all'utilizzo di Web Cloud Databases](/guides/web-cloud/databases/db-getting-started)

### Cos'è un database PostgreSQL?
PostgreSQL è un modello di database relazionale a oggetti (ORDBMS). È un sistema solido ed estendibile, in grado di gestire con la massima affidabilità un grande volume di dati. Dispone anche di una Community open source molto attiva.

## Connettiti al database

:::info
Ricordiamo che questa offerta non dà accesso all'Host ma ai database ospitati su di esso. I comandi SQL generici funzionano senza alcun problema e i software come HeidiSQL o SQuirreL SQL sono totalmente compatibili.

:::

Per connetterti al tuo database, assicurati di disporre di:

- l'indirizzo della tua istanza di database
- la porta del tuo database
- il nome utente del tuo database
- la password del tuo database
- il nome del tuo database

Tutte queste informazioni sono disponibili nella console OVHcloud, nella pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.

È disponibile anche una guida: [Iniziare a utilizzare Web Cloud Databases](/guides/web-cloud/databases/db-getting-started).

### Connessione da riga di comando

```bash
psql --host=server --port=port --username=user --password database_name
```

### Connessione con script PHP

```php
1. <?php
2. $myPDO = new PDO('pgsql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

## Estensioni PostgreSQL disponibili

Web Cloud Databases propone diverse estensioni PostgreSQL che permettono di aggiungere funzionalità supplementari ai tuoi database. Puoi attivarle e disattivarle dalla console OVHcloud, nella scheda <code className="action">Database</code> della tua istanza.

Per visualizzare la lista delle estensioni disponibili, consulta la guida "[Attivare le estensioni PostgreSQL](/guides/web-cloud/databases/db-enable-postgresql-extensions#estensioni-disponibili)".

## Esportare e importare un database PostgreSQL

- **Esportare il tuo database da riga di comando**

```bash
pg_dump --host=server --port=port --username=user --password database_name > database_name.sql
```

- **Importare il tuo database da riga di comando**

```bash
psql --host=server --port=port --username=user --password database_name < database_name.sql
```

:::info
In alcuni casi, la RAM disponibile nella tua istanza Web Cloud Databases potrebbe non essere sufficiente per effettuare l'esportazione o l'importazione desiderata. In questo caso, ti consigliamo di utilizzare lo strumento di importazione fornito da OVHcloud. Se necessario, consulta la documentazione "[Iniziare a utilizzare Web Cloud Databases](/guides/web-cloud/databases/db-getting-started#importare-un-database)".

:::
