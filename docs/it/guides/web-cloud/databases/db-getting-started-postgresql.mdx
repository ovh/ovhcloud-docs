Vuoi utilizzare PostgreSQL? Scopri come creare e gestire i tuoi database con la massima semplicità!

## Introduzione

### Prerequisiti

- Un'istanza Web Cloud Databases attiva
- Aver consultato [la guida all'utilizzo di Web Cloud Databases](/guides/web-cloud/databases/db-getting-started)

### Cos'è un database PostgreSQL?
PostgreSQL è un modello di database relazionale a oggetti (ORDBMS). È un sistema solido ed estendibile, in grado di gestire con la massima affidabilità un grande volume di dati. Dispone anche di una Community open source molto attiva.

## Connettiti al database

:::info
Ricordiamo che questa offerta non dà accesso all'host ma ai database ospitati su di esso. È possibile utilizzare tutti i comandi SQL generici e i software come HeidiSQL o SQuirreL SQL sono totalmente compatibili.

:::

Per accedere al tuo database, sono necessarie queste informazioni:

- indirizzo della tua istanza
- porta
- nome utente
- password
- nome del database

Questi dati sono disponibili nella sezione Web del tuo <ManagerLink to="/#/web/web/private_database">Spazio Cliente OVHcloud</ManagerLink>.

Se necessario, consulta la guida: [Iniziare a utilizzare Web Cloud Databases](/guides/web-cloud/databases/db-getting-started)

### Connessione da riga di comando

```bash
psql --host=server --port=porta --user=utente --password=password nome_database
```

### Connessione con script PHP

```php
1. <?php
2. $myPDO = new PDO('pgsql:host=host;port=porta;dbname= nome_database', ' utente', 'password');
3. ?>
```

### Connessione da software (SQuirreL SQL)
- Avvia SQuirreL SQL, clicca su <code className="action">Aliases</code> e poi su <code className="action">+</code>

<img className="thumbnail" alt="launch SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Completa i campi qui sotto e clicca su <code className="action">OK</code> per confermare:
    - **Name**: scegli un nome
    - **Driver**: scegli "PostgreSQL"
    - **URL**: inserisci l'indirizzo del server e la porta in formato jdbc:postgresql://server:porta/nome_database
    - **User Name**: inserisci il nome utente
    - **Password**: inserisci la password

<img className="thumbnail" alt="config connection" src="/images/assets/screens/other/web-tools/squirrel/add-alias-pgsql.png" loading="lazy" />

- Clicca su <code className="action">Connect</code> per confermare

<img className="thumbnail" alt="valid connection" src="/images/assets/screens/other/web-tools/squirrel/connect-to-pgsql.png" loading="lazy" />

A questo punto, sei connesso al tuo database:

<img className="thumbnail" alt="config connection" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard-pgsql.png" loading="lazy" />

## Estensioni PostgreSQL disponibili

Web Cloud Databases propone diverse estensioni PostgreSQL che permettono di aggiungere funzionalità supplementari ai tuoi database. Puoi attivarle e disattivarle dal tuo Spazio Cliente OVHcloud.

Per consultare la lista delle estensioni disponibili, consulta la guida "[Attivare le estensioni PostgreSQL](/guides/web-cloud/databases/db-enable-postgresql-extensions#estensioni-disponibili)".

## Esporta un database PostgreSQL

### Esportare il tuo database da riga di comando

```bash
pg_dump --host=server --port=porta --user=utente --password=password nome_database > nome_database.sql
```

## Importa un database PostgreSQL

### Importare il tuo database da riga di comando

```bash
psql --host=server --port=porta --user=utemte --password=password nome_database < nome_database.sql
```
