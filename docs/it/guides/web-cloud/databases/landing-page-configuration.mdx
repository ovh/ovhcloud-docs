## Configurare il tuo servizio Web Cloud Databases

Configura e gestisci il tuo servizio OVHcloud Web Cloud Databases: accesso, database, utenti e diritti, connessione, estensioni PostgreSQL e log.

Per orientarti in base alle tue esigenze:

- **Vuoi aprire l'accesso e connetterti ai tuoi database?** Consulta la sezione *Accesso e connessione*.
- **Gestisci i tuoi database, i tuoi utenti e i loro diritti?** Consulta la sezione *Database e utenti*.
- **Amministri il server (configurazione, log)?** Consulta la sezione *Server e gestione*.
