## Obiettivo

La soluzione Web Cloud Databases offre un'istanza di database con risorse dedicate e garantite, per prestazioni e flessibilità ottimali.
Di default, la soluzione Web Cloud Databases è associata alla rete di hosting Web OVHcloud. È possibile associarla anche a qualsiasi altra rete tramite una lista di indirizzi IP autorizzati.

**Scopri come iniziare a utilizzare la soluzione Web Cloud Databases.**

## Prerequisiti

- Un'[istanza Web Cloud Databases](/links/web/databases) (inclusa in un piano di [hosting Web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max).

[[cpnav:web-cloud-databases]]

## Procedura

### Attivazione del server Web Cloud Databases incluso con il piano di hosting Web

Se il piano di hosting include l'opzione Web Cloud Databases, clicca sulle schede qui sotto per visualizzare i **3** step in sequenza.

:::warning
L'attivazione di questa opzione richiede che tu sia almeno contatto amministratore dell'hosting Web che include il servizio Web Cloud Databases. Per ulteriori informazioni sulla gestione dei contatti, consulta la nostra guida "[Gestire i contatti dei servizi OVHcloud](/guides/account-and-service-management/account-information/managing-contacts)".

:::

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi seleziona l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web e lista degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Nella scheda <code className="action">Panoramica</code>, individua la sezione **Database**. La riga **Web Cloud DB** indica che la tua istanza non è ancora attivata. Clicca su <code className="action">Attiva</code>, sotto questa riga.

    <img className="thumbnail" alt="Sezione Database dell'hosting con il link Attiva della riga Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Nella pagina **Attiva Web Cloud DB** che si apre, scegli la capacità della tua istanza (la capacità di 512 MB è inclusa nel piano di hosting, le capacità superiori sono a pagamento), poi il suo motore (PostgreSQL, MariaDB, MySQL o Valkey) e la sua **Versione**. Clicca quindi su <code className="action">Attiva</code> (capacità inclusa) o su <code className="action">Ordina</code> (capacità a pagamento), poi conferma il buono d'ordine che si apre in una nuova scheda.

    <img className="thumbnail" alt="Pagina Attiva Web Cloud DB con la scelta della capacità, del motore e della versione" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate-page.png" loading="lazy" />

    L'istanza sarà poi accessibile dalla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.
  </Tab>
</Tabs>

Clicca sulle schede qui sotto per visualizzare i **2** step in sequenza.

<Tabs>

  <Tab label="Step 2">

    |Informazione|Dettagli|
    |---|---|
    |Stato|Indica in particolare se l'istanza è avviata, in fase di riavvio o sospesa. L'istanza deve essere avviata per poter eseguire operazioni.|
    |Motore|Indica il sistema di database utilizzato dal server e la sua versione. Verifica la compatibilità del tuo sito Web con la versione scelta.|
    |Regione|Indica la regione del datacenter in cui è stata creata l'istanza.|
    |Host|Indica il server OVHcloud su cui è stata creata l'istanza. Si tratta di un'informazione inerente all'infrastruttura OVHcloud e può essere utilizzata nelle comunicazioni relative agli [incidenti OVHcloud](https://www.status-ovhcloud.com/).|
    |Saturazione CPU|Indica la frequenza con cui l'istanza è limitata dalla CPU che le è allocata. Se è elevata, valuta di ordinare più RAM.|
    |RAM|Indica la memoria RAM disponibile per l'istanza e gli eventuali superamenti di memoria. L'istanza Web Cloud Databases dispone di risorse dedicate e garantite: la sua memoria RAM. Se necessario, è possibile potenziarla con il link **Ordinare più RAM**.|
    |Quota di archiviazione|Indica lo spazio occupato dai tuoi dati rispetto a quello incluso nella tua offerta. Una volta raggiunta questa quota, le scritture non vanno a buon fine: è quindi necessario eliminare dei dati o passare a un'offerta superiore.|

### Creare un database

:::info
Questo step non si applica al sistema di database Valkey.

:::

Clicca sulle schede qui sotto per visualizzare i **4** step in sequenza.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Clicca sulla scheda <code className="action">Database</code>.

    <img className="thumbnail" alt="Scheda Database di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Clicca su <code className="action">Aggiungere un database</code>, sopra la tabella dei database.

    <img className="thumbnail" alt="Pulsante Aggiungere un database sopra la tabella dei database" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    La creazione di schemi PostgreSQL non è attualmente disponibile sui server Web Cloud Databases.

    :::

  </Tab>
  <Tab label="Step 4">
    Il pannello **Aggiungere un database** si apre a destra. Compila i campi rispettando i criteri indicati sotto ciascuno di essi:

    - **Nome del database** (obbligatorio): è il nome del futuro database.
    - **Accesso a questo database**: scegli chi potrà connettersi al database ed eseguire query.
        - **Nessun accesso per ora** (scelta predefinita): il database viene creato senza utente. Potrai assegnare dei diritti a un utente in seguito.
        - **Un utente esistente**: seleziona l'**Utente** e le sue **Autorizzazioni** sul database.
        - **Un nuovo utente**: compila i campi qui sotto per creare l'utente contemporaneamente al database.
    - **Nome utente** (solo con **Un nuovo utente**): l'utente che potrà connettersi al database ed eseguire query.
    - **Autorizzazioni** (con **Un utente esistente** o **Un nuovo utente**): i diritti associati all'utente sul database. Per un utilizzo standard, seleziona `Admin`. I diritti possono essere modificati successivamente.
    - **Password**/**Conferma la password** (solo con **Un nuovo utente**): inserisci una password, poi confermala.

    Clicca su <code className="action">Aggiungi</code>.

    <img className="thumbnail" alt="Pannello Aggiungere un database con un nuovo utente" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

### Creare un utente

:::info
Questo step non si applica al sistema di database Valkey.

:::

Se l'utente è stato creato contemporaneamente al database nello step precedente, questo passaggio è facoltativo. Tuttavia, un progetto potrebbe richiedere più utenti con diritti diversi (ad esempio, lettura/scrittura per uno e sola lettura per un altro).

Se il progetto non necessita di un utente aggiuntivo, è possibile passare allo step successivo. In caso contrario, clicca sulle schede qui sotto per visualizzare i **4** step in sequenza.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Clicca sulla scheda <code className="action">Utenti e autorizzazioni</code>.

    <img className="thumbnail" alt="Scheda Utenti e autorizzazioni di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Clicca su <code className="action">Aggiungere un utente</code>.
  </Tab>
  <Tab label="Step 4">
    Il pannello **Aggiungere un utente** si apre a destra. Inserisci un **Nome utente**, poi una **Password** da confermare nel campo **Conferma la password**, rispettando i criteri indicati sotto ciascun campo. Clicca quindi su <code className="action">Aggiungi</code>.

### Autorizzare un indirizzo IP

Affinché l'istanza Web Cloud Databases funzioni, è necessario indicare gli IP o gli intervalli di IP autorizzati a connettersi ai database.

Per farlo, clicca sulle schede qui sotto per visualizzare i **4** step in sequenza.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Nella pagina visualizzata, clicca sulla scheda <code className="action">IP autorizzati</code>.

    <img className="thumbnail" alt="Scheda IP autorizzati di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Step 3">
    Nella pagina che appare, clicca sul pulsante <code className="action">Aggiungere un IP</code> sopra la tabella.

    <img className="thumbnail" alt="Pulsante Aggiungere un IP sopra la tabella degli IP autorizzati" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Per modificare un indirizzo IP o un intervallo di IP già autorizzato, clicca direttamente nella tabella sul pulsante <code className="action">⋮</code> della colonna **Azioni**, a destra della riga corrispondente all'indirizzo IP o all'intervallo di IP da modificare, poi su <code className="action">Modifica</code>. Potrai cambiarne il nome e le autorizzazioni; l'indirizzo IP stesso non è modificabile.

    <img className="thumbnail" alt="Menu di una riga della tabella degli IP autorizzati" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Step 4">
    Nella finestra **Aggiungere un indirizzo IP** che si apre, diversi campi devono essere compilati:

    <img className="thumbnail" alt="Finestra Aggiungere un indirizzo IP e i suoi campi" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (obbligatorio): Inserisci l'indirizzo IP (ad esempio `203.0.113.44`) o l'intervallo di IP (ad esempio `203.0.113.0/24`, che rappresenta tutti gli indirizzi IP da `203.0.113.0` a `203.0.113.255`) da autorizzare sulla soluzione Web Cloud Databases.
    - **Nome** (obbligatorio): Puoi, ad esempio, indicare il ruolo dell'indirizzo IP o dell'intervallo di IP interessato.
    - **Consentire l'accesso al servizio** (selezionata di default): Seleziona questa casella per consentire all'indirizzo IP o all'intervallo di IP di accedere ai database della soluzione Web Cloud Databases.
    - **Consentire l'accesso SFTP**: Seleziona questa casella per consentire all'indirizzo IP o all'intervallo di IP di accedere ai log della soluzione Web Cloud Databases.

    :::warning
    Si sconsiglia fortemente di selezionare la casella **Consentire l'accesso al servizio** per autorizzare l'intervallo di IP `0.0.0.0/0` ad accedere ai database.

    Questo consentirebbe a tutti gli indirizzi IPv4 esistenti di accedere ai database.

    :::

    Una volta inserite le informazioni, clicca sul pulsante <code className="action">Aggiungi</code>.
  </Tab>
</Tabs>

### Autorizzare le connessioni da un hosting Web OVHcloud <a name="trustip"></a>

Di default, la soluzione Web Cloud Databases è automaticamente associata agli hosting Web OVHcloud. Se lo desideri, puoi disattivare l'accesso degli hosting Web OVHcloud al tuo Web Cloud Databases.

Per farlo, consulta i casi particolari nella guida "[Web Cloud Databases - Come autorizzare un indirizzo IP?](/guides/web-cloud/databases/db-authorise-ip-mask)" per attivare o disattivare l'accesso degli hosting Web OVHcloud al tuo Web Cloud Databases.

### Associare il sito Web al database

Ora che il database è stato creato, uno o più utenti dispongono dei diritti necessari e almeno un indirizzo IP o gli hosting Web OVHcloud sono stati autorizzati sull'istanza Web Cloud Databases, non resta che associare il sito Web al database. Questo step può essere eseguito in diversi modi, a seconda del sito Web o del CMS (WordPress, Joomla!, ecc.) utilizzato, nonché della fase di installazione del sito Web.

A tal fine, sono necessarie le seguenti 5 informazioni:

|Informazione|Descrizione|
|---|---|
|Nome del database|Il nome definito al momento della creazione del database.|
|Nome utente|Il nome utente definito al momento della creazione del database o un eventuale utente aggiuntivo aggiunto in seguito.|
|Password dell'utente|La password associata all'utente, definita negli step precedenti.|
|Hostname del server|Il server da indicare affinché il sito Web possa connettersi al database.|
|Porta del server|La porta di connessione all'istanza Web Cloud Databases, necessaria affinché il sito Web possa connettersi al database.|

Per recuperare queste informazioni, clicca sulle schede qui sotto per visualizzare i **2** step in sequenza.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Recupera le seguenti informazioni di connessione:

    - **Server (hostname) e porta:** visibili nella scheda <code className="action">Panoramica</code>, sezione **SQL**, voci **Nome host** e **Porta**.
    - **Utente:** visibile nella scheda <code className="action">Utenti e autorizzazioni</code>.
    - **Password:** la password associata all'utente. Se l'hai dimenticata, accedi alla scheda <code className="action">Utenti e autorizzazioni</code>, clicca sul pulsante <code className="action">⋮</code> dell'utente interessato, poi su <code className="action">Modificare la password</code>.

    <img className="thumbnail" alt="Sezione SQL della panoramica con il nome host e la porta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />

    :::warning
    Se modifichi la password di un utente del database, tutte le applicazioni/siti Web che accedono a questo database devono essere aggiornati di conseguenza.

    :::

  </Tab>
</Tabs>

:::warning
Il campo <code className="action">porta</code> potrebbe non essere disponibile nella configurazione del sito Web. È necessario aggiungere questo campo dopo l'hostname del server, separandoli con *:*.

Ad esempio, per l'hostname `aaXXXXX-XXX.eu.clouddb.ovh.net` con la porta SQL `12345`, sarà necessario inserire `aaXXXXX-XXX.eu.clouddb.ovh.net:12345` nella sezione "Host" / "Hostname".

:::

:::info
OVHcloud non offre una porta cifrata tramite TLS sui server di database Valkey. Le comunicazioni devono avvenire esclusivamente attraverso la porta predefinita, non cifrata.

:::
