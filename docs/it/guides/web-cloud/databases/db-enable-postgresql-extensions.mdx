## Obiettivo

Le estensioni PostgreSQL sono moduli che arricchiscono il tuo database con funzionalità aggiuntive: nuovi tipi di dati, funzioni, operatori o linguaggi procedurali. Su una soluzione Web Cloud Databases puoi attivare le estensioni compatibili direttamente dal tuo Spazio Cliente OVHcloud, senza intervenire dalla riga di comando.

**Questa guida ti mostra come attivare le estensioni disponibili su un database PostgreSQL ospitato su una soluzione Web Cloud Databases.**

## Prerequisiti

- Disporre di un'[istanza Web Cloud Databases](/links/web/databases) che utilizza **PostgreSQL**.
- Aver consultato la guida [Come utilizzare PostgreSQL](/guides/web-cloud/databases/db-getting-started-postgresql).

## Procedura

### Attivare un'estensione

Clicca sulle schede qui sotto per visualizzare ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/#/web/web/private_database">Web Cloud Databases</ManagerLink>, poi seleziona il servizio interessato.

    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Database</code>. Nella colonna **"Estensioni"**, clicca sull'icona della tabella del database interessato.

    <img className="thumbnail" alt="Accedere alle estensioni di un database" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/databases/extensions.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella finestra visualizzata, individua l'estensione desiderata nell'elenco delle estensioni disponibili. Attivala quindi cliccando sull'icona corrispondente nella colonna **"Attivo"**.

    <img className="thumbnail" alt="Elenco delle estensioni PostgreSQL" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/databases/extensions-list.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
L'attivazione di un'estensione si applica al database selezionato. Per attivarla su un altro database dello stesso server, ripeti l'operazione selezionando il database interessato.

:::

### Estensioni disponibili

L'elenco delle estensioni proposte dipende dalla versione di PostgreSQL utilizzata dal tuo server. Le estensioni disponibili per la tua versione sono visualizzate nella finestra di attivazione.

Di seguito trovi l'elenco delle estensioni disponibili:

| Estensione | Descrizione |
|---|---|
| `address_standardizer` | Analizza un indirizzo per scomporlo nei suoi elementi costitutivi. Generalmente utilizzata per supportare la fase di normalizzazione degli indirizzi nel geocoding. |
| `autoinc` | Funzioni per l'incremento automatico dei campi. |
| `bloom` | Metodo di accesso bloom – indice basato su un file di firme. |
| `btree_gin` | Supporto per l'indicizzazione dei tipi di dati comuni in GIN. |
| `btree_gist` | Supporto per l'indicizzazione dei tipi di dati comuni in GiST. |
| `citext` | Tipo di dati per stringhe di caratteri senza distinzione tra maiuscole e minuscole. |
| `cube` | Tipo di dati per cubi multidimensionali. |
| `earthdistance` | Calcolo delle distanze ortodromiche sulla superficie terrestre. |
| `fuzzystrmatch` | Determina le somiglianze e la distanza tra stringhe di caratteri. |
| `hstore` | Tipo di dati per l'archiviazione di insiemi di coppie (chiave, valore). |
| `intarray` | Funzioni, operatori e supporto agli indici per array di interi a una dimensione. |
| `isn` | Tipi di dati per gli standard internazionali di numerazione dei prodotti. |
| `ltree` | Tipo di dati per strutture gerarchiche ad albero. |
| `moddatetime` | Funzioni per tenere traccia dell'ora dell'ultima modifica. |
| `pg_trgm` | Misurazione della somiglianza del testo e ricerca tramite indice basata sui trigrammi. |
| `pgcrypto` | Funzioni crittografiche. |
| `postgis` | Tipi e funzioni spaziali di PostGIS (geometria, geografia e raster). |
| `postgis_raster` | Tipi e funzioni raster di PostGIS. |
| `postgis_tiger_geocoder` | Geocoder tiger e geocoder inverso di PostGIS. |
| `postgis_topology` | Tipi e funzioni spaziali di topologia di PostGIS. |
| `seg` | Tipo di dati per rappresentare segmenti di retta o intervalli in virgola mobile. |
| `unaccent` | Dizionario di ricerca testuale che rimuove gli accenti. |
| `uuid-ossp` | Genera identificatori univoci universali (UUID). |
| `xml2` | Query XPath e XSLT. |
