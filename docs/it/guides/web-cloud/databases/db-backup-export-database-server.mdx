## Obiettivo

Il tuo database può contenere numerose informazioni essenziali per il tuo sito Web. Per questo motivo, è fondamentale poterlo salvare o esportare.

**Questa guida ti mostra come salvare ed esportare il tuo database dal server di database.**

## Prerequisiti

- Disporre di un'[istanza Web Cloud Databases](/links/web/databases) (inclusa in un'offerta di [hosting Web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max).

[[cpnav:web-cloud-databases]]

## Procedura

:::info
Le soluzioni [Web Cloud Databases](/links/web/databases) non danno accesso al sistema di gestione dei database, ma ai database ospitati su di esso.

- Non è disponibile l'accesso superutente "root".
- I comandi SQL generici funzionano normalmente e software come HeidiSQL, SQuirreL SQL o Adminer sono completamente compatibili.

:::

### Salvare ed esportare un database dalla console OVHcloud <a name="sauvegarder-et-exporter-une-base-de-données-depuis-lespace-client"></a>

:::info
- I backup vengono effettuati automaticamente una volta al giorno su tutti i tuoi database.
- I backup automatici e manuali sono conservati per 30 giorni. Trascorso questo termine, vengono eliminati automaticamente. La data di eliminazione di ogni backup è indicata nella lista dei backup del database.

:::

#### Effettuare un backup manuale

Clicca sulle schede qui sotto per visualizzare ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Database</code>.

    Nella colonna **Backup**, il numero corrisponde al numero di backup disponibili per ciascun database.

    <img className="thumbnail" alt="Scheda Database di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella tabella, clicca sul pulsante <code className="action">⋮</code> della colonna **Azioni**, a destra del database interessato, poi su <code className="action">Backup immediato</code>.

    <img className="thumbnail" alt="Menu di una riga della tabella dei database Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    Il backup si avvia immediatamente, senza conferma. Viene visualizzato il messaggio **Backup avviato**.
  </Tab>
</Tabs>

### Salvare ed esportare un database al di fuori della console OVHcloud <a name="sauvegarder-et-exporter-une-base-de-données-hors-espace-client"></a>

Se la RAM disponibile sul server non consente di effettuare l'esportazione desiderata, utilizza lo strumento OVHcloud nella console OVHcloud, che utilizza risorse esterne alla tua soluzione. Consulta la sezione "[Salvare ed esportare un database dalla console OVHcloud](#salvare-ed-esportare-un-database-dalla-console-ovhcloud)" di questa guida.

**Clicca sul metodo di esportazione che preferisci per visualizzare il contenuto.**

<details>

<summary>Esportare un database MySQL o MariaDB da phpMyAdmin OVHcloud</summary>

Per esportare il tuo database direttamente da phpMyAdmin, è necessario effettuare prima l'accesso. Per farlo, consulta la guida "[Connettersi a un database](/guides/web-cloud/databases/db-connecting-database-server)".

Una volta connesso a phpMyAdmin, clicca sul nome del database da esportare e poi sulla scheda <code className="action">Esporta</code> in alto.

Sono disponibili due modalità di esportazione. Se non hai necessità specifiche, ti consigliamo di utilizzare la modalità **rapida** in formato **SQL**.

<img className="thumbnail" alt="Scheda Esporta di phpMyAdmin con il metodo rapido e il formato SQL" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-export-backup-web-cloud-db.png" loading="lazy" />

</details>

<details>

<summary>Esportare un database MySQL o MariaDB da riga di comando</summary>

```bash
mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql
```

</details>

<details>

<summary>Esportare un database MySQL o MariaDB da uno script PHP</summary>

```php
1. <?php echo "Your database is being backed up.......";
2. system("mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql");
3. echo "Backup complete. You can retrieve the database via FTP";
4. ?>
```

:::warning
- Per evitare che terzi accedano a questo file contenente dati sensibili, proteggi l'accesso utilizzando la guida: [Proteggere una directory o l'interfaccia di amministrazione del tuo sito web con file .htaccess e .htpasswd](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password).
- Questa azione è possibile solo da un hosting Web OVHcloud.

:::

</details>

<details>

<summary>Esportare un database PostgreSQL da riga di comando</summary>

```bash
pg_dump --host=server --port=port --username=user --password database_name > database_name.sql
```

</details>

<details>

<summary>Esportare un database PostgreSQL da uno script PHP</summary>

```php
1. <?php echo "Your database is being backed up.......";
2. system("PGPASSWORD=password pg_dump --host=server --port=port --username=user database_name > database_name.sql");
3. echo "Backup complete. You can retrieve the database via FTP";
4. ?>
```

:::warning
- Per evitare che terzi accedano a questo file contenente dati sensibili, proteggi l'accesso utilizzando la guida: [Proteggere una directory o l'interfaccia di amministrazione del tuo sito web con file .htaccess e .htpasswd](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password).
- Questa azione è possibile solo da un hosting Web OVHcloud.

:::

</details>
