## Obiettivo

In caso di errore sul database, è necessario essere in grado di ripristinare un backup o importare un database locale.

**Questa guida ti mostra come ripristinare e importare il database sul tuo server di database.**

## Prerequisiti

- Disporre di una [istanza Web Cloud Databases](/links/web/databases) (inclusa in un'offerta di [hosting Web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max)

[[cpnav:web-cloud-databases-console]]

## Procedura

:::info
Le soluzioni [Web Cloud Databases](/links/web/databases) non danno accesso al sistema di gestione dei database, ma ai database ospitati su di esso.

- Non è presente un accesso superutente "root".
- I comandi SQL generici funzionano normalmente e software come HeidiSQL, SQuirreL SQL o Adminer sono completamente compatibili.

:::

### Ripristinare e importare un database dalla console OVHcloud <a name="ripristinare-e-importare-un-database-dallo-spazio-cliente"></a>

#### Ripristinare un backup esistente

Clicca sulle schede qui sotto per visualizzare ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Database</code>.

    Nella colonna **Backup**, il numero corrisponde al numero di backup disponibili per ciascun database.

    <img className="thumbnail" alt="Scheda Database di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella tabella, clicca sul pulsante <code className="action">⋮</code> della colonna **Azioni**, a destra del database interessato, poi su <code className="action">Visualizzare i backup</code>.

    <img className="thumbnail" alt="Menu di una riga della tabella dei database Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Si apre a destra un pannello intitolato **Backup**, seguito dal nome del database. Clicca sul pulsante <code className="action">⋮</code> a destra del backup scelto, poi su <code className="action">Ripristina</code>.

    <img className="thumbnail" alt="Pannello dei backup di un database con il menu di un backup aperto" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/backup-actions-menu.png" loading="lazy" />

    Nella finestra **Ripristinare un backup** che si apre, conferma cliccando su <code className="action">Ripristina</code>. Viene visualizzato il messaggio **Ripristino avviato**.

    <img className="thumbnail" alt="Finestra di conferma del ripristino di un backup" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/restore-backup-dialog.png" loading="lazy" />

    :::warning
    Il ripristino comporta la sovrascrittura del contenuto del database e quindi una possibile perdita di dati. Se non sei sicuro di ciò che stai facendo, ti consigliamo di effettuare un backup prima.

    :::

  </Tab>
</Tabs>

#### Importare un backup locale

Clicca sulle schede qui sotto per visualizzare ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Database</code>.

    <img className="thumbnail" alt="Scheda Database di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella tabella, clicca sul pulsante <code className="action">⋮</code> della colonna **Azioni**, a destra del database interessato, poi su <code className="action">Importa</code>.

    <img className="thumbnail" alt="Menu di una riga della tabella dei database Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Si apre la finestra **Importare un database**. ***Hai due possibilità***, proposte dai due pulsanti situati in alto nella finestra:

    **1 - Carica un nuovo file**

    Questa possibilità è selezionata di default all'apertura della finestra.

    Nel campo **Nome del file**, indica un nome per il file importato. Clicca poi sull'area <code className="action">File da importare</code> per selezionare il file sul tuo computer, oppure trascinalo in quest'area.

    :::warning
    Il file deve essere in formato ".sql", ".txt" o ".gz".

    :::

    <img className="thumbnail" alt="Finestra Importare un database con l'opzione Carica un nuovo file selezionata" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/database-import-new-file-step-2.png" loading="lazy" />

    Se lo desideri, seleziona la casella **Svuota il database prima dell'importazione**. La casella **Ricevi un'e-mail al termine dell'importazione** è selezionata di default: ti permette di essere informato del completamento dell'operazione sull'indirizzo email di riferimento del tuo account OVHcloud. Clicca infine su <code className="action">Conferma</code>: il file viene inviato, poi l'importazione viene avviata.

    **2 - Utilizzare un file esistente**

    Se hai già importato un file in precedenza, clicca su <code className="action">Usa un file esistente</code>.

    Nell'elenco a tendina **Documento esistente**, seleziona il file tra quelli già presenti sul tuo account OVHcloud.

    <img className="thumbnail" alt="Finestra Importare un database con l'opzione Usa un file esistente selezionata" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/database-import-existing-file-step-2.png" loading="lazy" />

    Se lo desideri, seleziona la casella **Svuota il database prima dell'importazione**. La casella **Ricevi un'e-mail al termine dell'importazione** è selezionata di default: ti permette di essere informato del completamento dell'operazione sull'indirizzo email di riferimento del tuo account OVHcloud. Clicca infine su <code className="action">Conferma</code> per avviare l'importazione.
  </Tab>
</Tabs>

### Importare un database al di fuori della console OVHcloud <a name="importare-un-database-al-di-fuori-dello-spazio-cliente"></a>

In alcuni casi, la RAM disponibile sul tuo server di database potrebbe non essere sufficiente per effettuare l'importazione desiderata al di fuori della console OVHcloud. In questo caso, ti consigliamo di utilizzare lo strumento OVHcloud nella console OVHcloud. Consulta la sezione "[Ripristinare e importare un database dalla console OVHcloud](#ripristinare-e-importare-un-database-dallo-spazio-cliente)" di questa guida.

**Clicca sul metodo di importazione che preferisci per visualizzare il contenuto.**

<details>

<summary>Importare un database MySQL o MariaDB da phpMyAdmin</summary>

Per importare il database direttamente da phpMyAdmin, è necessario prima effettuare l'accesso seguendo la sezione "[Connettersi a un database MySQL o MariaDB](/guides/web-cloud/databases/db-connecting-database-server#connettersi-a-un-database-mysql-o-mariadb)".

Una volta connesso a phpMyAdmin, seleziona il database cliccando sul suo nome.

Clicca sulla scheda <code className="action">Importa</code>.

Seleziona il file di backup cliccando su <code className="action">Sfoglia</code> (il file non può superare i 100 MB).

:::info
Ti consigliamo di frazionare il database in più file quando supera i 100 MB ed effettuare diverse importazioni da phpMyAdmin.
L'importazione di file superiori a 100 MB può essere effettuata dalla console OVHcloud seguendo il passaggio "[Ripristinare e importare un database dalla console OVHcloud](#ripristinare-e-importare-un-database-dallo-spazio-cliente)".

:::

Lascia le opzioni predefinite e clicca su <code className="action">Esegui</code> per avviare l'importazione.

<img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-upload-backup-web-cloud-db.png" loading="lazy" />

</details>

<details>

<summary>Importare un database MySQL o MariaDB da riga di comando</summary>

Questa azione è possibile solo in [SSH](/guides/web-cloud/web-hosting/ssh-on-webhosting) da un hosting condiviso OVHcloud.

```bash
cat nome_database.sql | mysql --host=server --user=utente --port=port --password=password nome_database
```

</details>

<details>

<summary>Importare un database MySQL o MariaDB da un file PHP</summary>

```php
1. <?php
2. echo "Il tuo database è in corso di ripristino.......<br/>";
3. system("cat nome_database.sql | mysql --host=server --user=utente --port=port --password=password nome_database");
4. echo "Completato. Il tuo database è attivo su questo hosting.";
5. ?>
```

:::warning
- Per evitare che qualcuno acceda a questo file contenente dati sensibili, proteggi l'accesso seguendo la guida: [Come proteggere l'accesso a una directory tramite password?](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password)
- Questa azione è possibile solo da un hosting condiviso OVHcloud.

:::

</details>

<details>

<summary>Importare un database PostgreSQL da riga di comando</summary>

Questa azione è possibile solo in [SSH](/guides/web-cloud/web-hosting/ssh-on-webhosting) da un hosting condiviso OVHcloud in versione stabile o superiore.

```bash
psql --host=server --port=port --user=utente --password=password nome_database < nome_database.sql
```

</details>

<details>

<summary>Importare un database PostgreSQL da un file PHP</summary>

```php
1. <?php
2. echo "Il tuo database è in corso di ripristino.......<br/>";
3. system("PGPASSWORD=password psql --host=server --port=port --user=utente --password=password nome_database < nome_database.sql");
4. echo "Completato. Il tuo database è attivo su questo hosting.";
5. ?>
```

:::warning
- Per evitare che qualcuno acceda a questo file contenente dati sensibili, proteggi l'accesso seguendo la guida: [Come proteggere l'accesso a una directory tramite password?](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password)
- Questa azione è possibile solo da un hosting condiviso OVHcloud.

:::

</details>
