## Obiettivo

Le soluzioni [Web Cloud Databases](/links/web/databases) possono essere utilizzate con servizi OVHcloud o esterni a OVHcloud.

Di default, per motivi di sicurezza, su queste soluzioni:

- Solo gli indirizzi IP associati alla nostra infrastruttura di hosting condiviso sono autorizzati ad accedere al contenuto dei database.
- L'accesso ai log della soluzione non è limitato in funzione degli indirizzi IP. In questo modo è possibile accedervi, ad esempio, da un computer.

È necessario modificare queste autorizzazioni/restrizioni?

**Questa guida ti mostra come autorizzare uno o più indirizzi IP ad accedere alla tua soluzione Web Cloud Databases.**

## Prerequisiti

- Disporre di una soluzione [Web Cloud Databases](/links/web/databases).
- Conoscere l'indirizzo IP (o la classe di indirizzi IP) da autorizzare sulla soluzione.

[[cpnav:web-cloud-databases]]

## Procedura

### Autorizza un indirizzo IP o un intervallo di indirizzi IP

:::info
Ti ricordiamo che, se hai appena attivato la tua soluzione [Web Cloud Databases](/links/web/databases) e vuoi utilizzarla con un'offerta di [hosting Web OVHcloud](/links/web/hosting), gli indirizzi IP di queste offerte sono già autorizzati di default.

:::

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>, poi seleziona l'istanza interessata.

    <img className="thumbnail" alt="Pagina Web Cloud DB e lista delle istanze dell'account" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella pagina che si apre, clicca sulla scheda <code className="action">IP autorizzati</code>.

    <img className="thumbnail" alt="Scheda IP autorizzati di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella pagina che appare, clicca sul pulsante <code className="action">Aggiungere un IP</code> situato sopra la tabella.

    <img className="thumbnail" alt="Pulsante Aggiungere un IP sopra la tabella degli IP autorizzati" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Per modificare un indirizzo IP o un intervallo di indirizzi IP già autorizzato, clicca direttamente nella tabella sul pulsante <code className="action">⋮</code> della colonna **Azioni**, a destra della riga corrispondente all'indirizzo IP o all'intervallo di indirizzi IP da modificare, poi su <code className="action">Modifica</code>. Potrai cambiarne il nome e le autorizzazioni; l'indirizzo IP in sé non è modificabile.

    <img className="thumbnail" alt="Menu di una riga della tabella degli IP autorizzati" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Passaggio 4">
    Nella finestra **Aggiungere un indirizzo IP** che si apre, è necessario completare diversi campi:

    <img className="thumbnail" alt="Finestra Aggiungere un indirizzo IP e i suoi campi" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (obbligatorio): Inserisci qui l'indirizzo IP (ad esempio: `203.0.113.44`) o l'intervallo di indirizzi IP (ad esempio: `203.0.113.0/24`, che rappresenta tutti gli indirizzi IP da `203.0.113.0` a `203.0.113.255`) che vuoi autorizzare sulla tua soluzione Web Cloud Databases.
    - **Nome** (obbligatorio): Ad esempio, puoi indicare il ruolo dell'indirizzo IP o dell'intervallo di indirizzi IP in questione.
    - **Consentire l'accesso al servizio** (selezionata di default): Seleziona questa casella per autorizzare l'indirizzo IP o l'intervallo di indirizzi IP ad accedere ai database presenti sulla tua soluzione Web Cloud Databases.
    - **Consentire l'accesso SFTP**: Seleziona questa casella per autorizzare l'indirizzo IP o l'intervallo di indirizzi IP ad accedere ai log della tua soluzione Web Cloud Databases.

    :::warning
    È fortemente sconsigliato selezionare la casella **Consentire l'accesso al servizio** per autorizzare l'intervallo di indirizzi IP `0.0.0.0/0` ad accedere ai tuoi database.

    In questo modo, infatti, tutti gli indirizzi IPv4 esistenti sarebbero autorizzati ad accedere ai tuoi database.

    :::

    Una volta inserite le informazioni, clicca sul pulsante <code className="action">Aggiungi</code>.
  </Tab>
</Tabs>

## Casi particolari

**Clicca sui casi qui sotto per visualizzare le informazioni corrispondenti.**

<details>

<summary>L'intervallo di indirizzi IP 0.0.0.0/0</summary>

Quando attivi la tua soluzione Web Cloud Databases, è già presente di default una riga per l'intervallo di indirizzi IP `0.0.0.0/0`, che autorizza l'accesso in **SFTP** alla soluzione.

Questa autorizzazione è impostata volontariamente per permetterti di accedere ai file di log della tua soluzione Web Cloud Databases senza dover dichiarare l'indirizzo IP del tuo punto di accesso a Internet.

Questo indirizzo IP, infatti, può cambiare regolarmente in base ai provider di accesso a Internet.

Inoltre, ti consigliamo di **non** modificare questa autorizzazione e di non autorizzare l'accesso ai database presenti sulla tua soluzione Web Cloud Databases.

In questo modo, infatti, tutti gli indirizzi IPv4 esistenti sarebbero autorizzati ad accedere ai tuoi database, con conseguente rischio per la sicurezza dei tuoi dati.

</details>
