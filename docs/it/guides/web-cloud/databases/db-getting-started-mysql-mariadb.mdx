## Obiettivo

Vuoi utilizzare MySQL o MariaDB per i tuoi database?

### Cos'è un database MySQL?

MySQL è un modello di database relazionale sviluppato per ottimizzare le prestazioni in lettura.

Questo motore è open source e la sua casa madre è Oracle.

### Cos'è un database MariaDB?

MariaDB è un derivato (fork) del modello di database MySQL.

Questo motore è compatibile al 100% ed è stato progettato per essere più "libero" del suo fratello maggiore MySQL. Contrariamente alla versione di Oracle, tutti i bug e la roadmap sono pubblicamente accessibili.

**Scopri come creare e gestire i tuoi database MySQL o MariaDB**

## Procedura

### Connessione al database

:::info
Questa offerta non dà accesso all'Host ma ai database ospitati su di esso. I comandi SQL generici funzionano senza alcun problema e i software come HeidiSQL o SQuirreL SQL sono pienamente compatibili.

:::

:::info
Poiché MariaDB è un derivato di MySQL, i diversi comandi sono esattamente gli stessi per questi 2 tipi di database.

:::

Per connetterti al tuo database, assicurati di avere:

- l'indirizzo della tua istanza Web Cloud Databases
- la porta della tua istanza Web Cloud Databases
- il nome utente della tua istanza Web Cloud Databases
- la password associata all'utente
- il nome del tuo database

Tutte queste informazioni sono disponibili nella console OVHcloud, nella pagina <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.

È disponibile anche una guida: [Iniziare a utilizzare Web Cloud Databases](/guides/web-cloud/databases/db-getting-started).

#### Connessione da riga di comando

```bash
mysql --host=server --user=user --port=port --password=password database_name
```

#### Connessione tramite script PHP

```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

#### Connessione tramite software (SQuirreL SQL)

- Avvia SQuirreL SQL e clicca su <code className="action">Aliases</code>, poi su <code className="action">+</code>.

<img className="thumbnail" alt="avvio di SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Compila i campi qui sotto e conferma con il pulsante <code className="action">OK</code>:
    - **Name**: Scegli un nome
    - **Driver**: Scegli `MySQL Driver`
    - **URL**: Indica l'indirizzo del server e la porta nel formato `jdbc:mysql://server:port`
    - **User Name**: Indica il nome utente
    - **Password**: Indica la password

<img className="thumbnail" alt="configurazione della connessione" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Conferma di nuovo con il pulsante <code className="action">Connect</code>.

<img className="thumbnail" alt="convalida della connessione" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

Ora sei connesso al tuo database:

<img className="thumbnail" alt="configurazione della connessione" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

#### Connessione tramite phpMyAdmin

Puoi utilizzare phpMyAdmin per esplorare il contenuto del tuo database. Per farlo, installa phpMyAdmin sul tuo server o hosting Web. Durante l'installazione, assicurati di configurare correttamente le informazioni del tuo server Web Cloud Databases e del database desiderato in modo che phpMyAdmin possa connettersi.

### Esportare e importare un database MySQL o MariaDB

- **Esportare il mio database da riga di comando**

```bash
mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql
```

- **Importare il mio database da riga di comando**

```bash
cat database_name.sql | mysql --host=server --user=user --port=port --password=password database_name
```

:::info
In alcuni casi, è possibile che la RAM disponibile nella tua istanza Web Cloud Databases non permetta di effettuare l'esportazione o l'importazione desiderata. In questo caso, ti consigliamo di utilizzare lo strumento di importazione fornito da OVHcloud. Consulta la documentazione "[Iniziare a utilizzare Web Cloud Databases](/guides/web-cloud/databases/db-getting-started#importare-un-database)" se necessario.

:::
