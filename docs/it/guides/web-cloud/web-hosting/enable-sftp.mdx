## Obiettivo

Le offerte di web hosting OVHcloud danno accesso a uno spazio di archiviazione che permette di pubblicare i file del tuo sito web o delle tue applicazioni. L'accesso a questo spazio è possibile tramite un utente FTP o SSH con i rispettivi password associati.

Proprio come il **F**ile **T**ransfer **P**rotocol (**FTP**), il **S**ecure **F**ile **T**ransfer **P**rotocol (**SFTP**) permette di trasferire dati dal tuo dispositivo verso lo spazio di archiviazione del tuo web hosting.

L'unica differenza è che l'SFTP utilizza un canale sicuro per scambiare dati. I dati che transitano tramite questo protocollo vengono automaticamente crittografati.

**Questa guida ti mostra come attivare l'accesso SFTP sul tuo web hosting OVHcloud.**

## Prerequisiti

- Disporre di un'offerta di [web hosting OVHcloud](/links/web/hosting).

[[cpnav:web-hosting]]

## Procedura

### Attivare l'accesso SFTP per un utente FTP del tuo web hosting

Clicca sulle schede qui sotto per visualizzare in successione ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Scheda FTP-SSH di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella sezione **Utenti FTP e SSH**, verifica lo stato visualizzato nella colonna **SFTP** per l'utente FTP interessato:

    - **Attivo**: il protocollo SFTP è già attivo per questo utente, non devi fare nulla.
    - **Disattivato**: nella colonna **Azioni**, clicca sul pulsante <code className="action">⋮</code> a destra della riga interessata, poi su <code className="action">Modifica</code>.

    <img className="thumbnail" alt="Tabella degli utenti FTP e stato del protocollo SFTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/ftp-users-sftp-status.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Il pannello **Modifica un utente** si apre a destra. Nel menu a tendina **Protocolli di connessione**, seleziona <code className="action">FTP e SFTP</code>, oppure <code className="action">FTP, SFTP e SSH</code> se hai bisogno di attivare anche il protocollo SSH.

    <img className="thumbnail" alt="Pannello Modifica un utente e menu Protocolli di connessione" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user-protocols.png" loading="lazy" />

Il menu propone un terzo valore, <code className="action">FTP</code> da solo, che disattiva il SFTP per questo utente.

    Infine, clicca su <code className="action">Conferma</code>. Una volta attivata l'opzione **SFTP**, potrai utilizzare il protocollo SFTP del tuo hosting Web con l'utente FTP interessato.
  </Tab>
</Tabs>

:::info
Il valore <code className="action">FTP, SFTP e SSH</code> è proposto solo sulle offerte che includono l'accesso SSH: **Pro**, **Performance**, **Agency**, **Agency Plus** e **Agency Max**.

Sulle offerte <Region zones={['eu']}>**gratuito**, **Starter**, **Personale** e **Startup**</Region><Region zones={['ca', 'apac']}>**Starter**, **Personale** e **Startup**</Region>, il menu **Protocolli di connessione** propone solo <code className="action">FTP</code> e <code className="action">FTP e SFTP</code>, e la tabella degli utenti non mostra la colonna **SSH**.

:::
