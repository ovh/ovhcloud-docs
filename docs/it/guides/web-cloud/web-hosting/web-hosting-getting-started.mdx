## Obiettivo

Vuoi creare un sito Internet per la tua azienda o un blog personale? Hai bisogno di un e-commerce per vendere i tuoi prodotti online? Questa guida dedicata ai primi passi dell'hosting Web OVHcloud ti mostra gli step chiave per configurarlo. Trovi anche le spiegazioni per creare indirizzi email professionali associati al tuo dominio. Ti permette di pubblicare online il tuo progetto in modo semplice e rapido, per comunicare con il tuo pubblico in modo efficace.

:::info
- Vuoi migrare un sito Web esistente presso un altro provider? Consulta la nostra guida dedicata: [Migrare il proprio sito Web e i servizi associati a OVHcloud](/guides/web-cloud/web-hosting/hosting-migrating-to-ovh).
<Region zones={['eu']}>
- Vuoi solo una semplice home page per la tua attività professionale? Consulta la nostra guida dedicata: [Hosting Web - Attiva l'hosting gratuito](/guides/web-cloud/web-hosting/activate-start10m).
</Region>

:::

## Prerequisiti

<Region zones={['eu']}>
- Disporre di una soluzione di [hosting Web OVHcloud](/links/web/hosting) con almeno un database disponibile (escluso il servizio di hosting gratuito).
</Region>
<Region zones={['ca','apac']}>
- Disporre di una soluzione di [hosting Web OVHcloud](/links/web/hosting) con almeno un database disponibile.
</Region>
- Aver ricevuto l'email di conferma dell'installazione del tuo hosting Web.
- Disporre di un [dominio](/links/web/domains) e di una zona DNS associata in OVHcloud.
- Tutti i servizi (Hosting Web, Domini, Zona DNS) devono essere accessibili da un unico account OVHcloud.

[[cpnav:web-hosting-console]]

## Procedura

### 1 - Associare il tuo nome di dominio a un sito web sull'hosting web <a name="part-1"></a>

:::tip
Se il dominio e l'hosting Web sono stati registrati con lo stesso ordine, i due servizi sono già associati. Consulta la [Parte 2](#part-2) di questa guida.

:::

Clicca sulle schede qui sotto per visualizzare in sequenza i **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">I miei siti</code>. Nella tabella, clicca sul pulsante <code className="action">⋮</code> della colonna **Azioni**, a destra del sito web creato automaticamente alla creazione del tuo hosting Web, poi, nel gruppo **Nomi di dominio**, su <code className="action">Aggiungi un nome di dominio</code>.

    <img className="thumbnail" alt="Menu Azioni di un sito web e voce Aggiungi un nome di dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Si apre la pagina **Aggiungi un dominio**. Compilala dall'alto verso il basso, poi convalida.
  </Tab>
</Tabs>

### 2 - Installa un "CMS in 1 click" per il tuo sito web <a name="part-2"></a>

Negli hosting Web, OVHcloud propone di installare gratuitamente i CMS WordPress, Joomla!, PrestaShop e Drupal con l'opzione "CMS in 1 click".

Clicca sulle schede qui sotto per visualizzare successivamente i **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Moduli</code>. Le tre sezioni in alto indicano il numero di moduli **Installati**, la versione di PHP del tuo hosting Web con la relativa compatibilità (sezione **PHP**) e il numero di moduli **disponibili**.

    <img className="thumbnail" alt="Scheda Moduli e le sue tre sezioni di riepilogo" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/tab.png" loading="lazy" />

    :::info
    Un modulo può essere installato solo se la versione PHP del tuo hosting Web è compatibile. Quando non lo è, la sezione mostra **Incompatibile** e non viene proposto alcun modulo. Consulta la sezione "[Le versioni di PHP](/guides/web-cloud/web-hosting/configure-your-web-hosting#php-versions)" della nostra guida sulla configurazione del tuo hosting Web per aggiornarla.
    :::
  </Tab>
  <Tab label="Passaggio 3">
    Clicca sul pulsante <code className="action">Aggiungi un modulo</code>.
  </Tab>
  <Tab label="Passaggio 4">
    Si apre un pannello sulla destra. Lascia selezionata la modalità <code className="action">Semplice</code>, scegli il CMS da installare sotto **Scegli il modulo**, poi il dominio sotto **Dominio**, **senza "www"** davanti (ad esempio: `domain.tld` e non `www.domain.tld`). Infine, clicca su <code className="action">Installa</code>.

    <img className="thumbnail" alt="Pannello Installa un modulo, scelta del CMS e del dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/install-module-drawer.png" loading="lazy" />
  </Tab>
</Tabs>

<details>

<summary>Per ulteriori informazioni, fare clic qui.</summary>

Consulta le nostre guide dettagliate:

### 3 - Attiva gli indirizzi email inclusi con il tuo hosting Web <a name="part-3"></a>

:::tip
Se il dominio e l'hosting Web sono stati registrati con un unico ordine, gli indirizzi email inclusi nell'hosting Web sono già associati al dominio. Consulta la [Parte 4](#part-4) di questa guida.

:::

Clicca sulle schede qui sotto per visualizzare successivamente i **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella scheda <code className="action">Panoramica</code>, individua la sezione **Servizi gratuiti**. La voce **Indirizzi email** riporta il numero di indirizzi inclusi nella tua offerta e lo stato del servizio. Finché questo è **Inattivo**, clicca su <code className="action">Attiva la mia offerta email</code> subito sotto.

    <img className="thumbnail" alt="Sezione Servizi gratuiti e link Attiva la mia offerta email" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/complimentary-services.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Il processo di attivazione prevede due passaggi. Sotto **Indirizzi email**, seleziona il dominio interessato. Sotto **Attivazione**, accetta i contratti e convalida: si apre il tuo buono d'ordine OVHcloud, poiché questa opzione è inclusa gratuitamente nella tua offerta di hosting Web.
  </Tab>
</Tabs>

<details>

<summary>Per ulteriori informazioni, fare clic qui.</summary>

Consulta la nostra guida dettagliata "[Hosting Web - Attiva gli indirizzi email inclusi](/guides/web-cloud/web-hosting/activate-email-hosting)".

</details>

### 4 - Creare un indirizzo email personalizzato con il dominio <a name="part-4"></a>

Clicca sulle schede qui sotto per visualizzare successivamente i **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/email">Email</ManagerLink>. La tabella elenca tutti i tuoi servizi di posta; individua la riga della tua offerta MX Plan, poi cliccaci sopra. La colonna **Tipo di offerta** indica il nome dell'offerta così come restituito dal sistema, che non sempre menziona `MX Plan`.

    <img className="thumbnail" alt="Pagina Email e colonna Tipo di offerta dei servizi di posta" src="/images/assets/screens/console/product-selection/web-cloud/email-and-collaborative-solutions/emails-listing.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Account email</code>. La sezione **Quota account email** indica il numero di indirizzi già configurati sul totale incluso nella tua offerta.

    <img className="thumbnail" alt="Scheda Account email di un servizio MX Plan e relativi account" src="/images/assets/screens/console/product-selection/web-cloud/email-and-collaborative-solutions/mx-plan/email-account-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Clicca sul pulsante <code className="action">Aggiungi l'account</code>.
  </Tab>
  <Tab label="Passaggio 4">
    Si apre un pannello sulla destra. Inserisci il **Nome dell'account**, che precede la `@` del tuo dominio, poi la relativa **Password**. La **Descrizione** è facoltativa e la **Dimensione dell'account** è quella inclusa nella tua offerta. Infine, clicca su <code className="action">Aggiungi</code>.

    <img className="thumbnail" alt="Pannello Aggiungi l'account e i relativi campi di creazione" src="/images/assets/screens/console/product-selection/web-cloud/email-and-collaborative-solutions/mx-plan/add-account-drawer.png" loading="lazy" />
  </Tab>
</Tabs>

Ripeti l'operazione per ogni indirizzo email che vuoi creare (nel limite della tua offerta di hosting Web).

<details>

<summary>Per ulteriori informazioni, fare clic qui.</summary>

Consulta la nostra guida dettagliata "[Creare un indirizzo email](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-creation)".

</details>

### 5 - Opzioni aggiuntive disponibili con l’hosting Web <a name="part-5"></a>

Il tuo hosting Web non è limitato all'installazione di un "modulo in 1 click". Ospita siti creati da te o da uno sviluppatore Web (blog, CMS, negozio online, ecc...). Per saperne di più sulle possibilità degli hosting Web, consulta la nostra guida più dettagliata "[Come creare un sito Web - Realizzare un progetto in 5 step](/guides/web-cloud/web-hosting/website-project)".
