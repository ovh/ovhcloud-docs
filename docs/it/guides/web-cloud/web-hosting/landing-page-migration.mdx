## Migrare il tuo sito web su OVHcloud

Migra il tuo sito web e i suoi dati sul tuo Hosting Web OVHcloud. Questa pagina riunisce le guide per migrare un sito completo su OVHcloud, esportare e importare i tuoi dati (file e database) e gestire i casi associati come il cambio di dominio.

Per orientarti in base alla tua esigenza:

- **Vuoi migrare un sito completo, WordPress o Xara?** Consulta la sezione *Migrare un sito web su OVHcloud*.
- **Vuoi esportare o importare il tuo sito web e i tuoi database?** Consulta la sezione *Esportare e importare i tuoi dati*.
- **Vuoi migrare verso un VPS, cambiare dominio o passare da MySQL a Percona?** Consulta la sezione *Altre migrazioni*.
