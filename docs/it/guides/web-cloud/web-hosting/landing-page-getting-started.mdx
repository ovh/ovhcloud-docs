## Primi passi con il tuo Hosting Web

Hai appena sottoscritto un Hosting Web OVHcloud? Questa pagina riunisce le guide per iniziare: attivare la tua offerta, creare e pubblicare il tuo primo sito web, attivare gli indirizzi email inclusi e poi trovare le informazioni chiave del tuo Hosting Web. Per configurare il tuo hosting in modo più dettagliato, consulta la pagina Configurazione.

Per orientarti in base alle tue esigenze:

- **Stai iniziando e vuoi creare e pubblicare il tuo sito web?** Consulta le sezioni *Iniziare* e *Pubblicare e gestire i tuoi siti web*.
- **Vuoi attivare le email incluse o gestire i tuoi siti web dallo Spazio Cliente?** Consulta la sezione *Pubblicare e gestire i tuoi siti web*.
- **Cerchi le informazioni tecniche del tuo hosting (offerta, cluster)?** Consulta la sezione *Conoscere il tuo hosting*.
