## Obiettivo

Puoi ospitare diversi siti web sulla stessa offerta di hosting web, anche se i nomi di dominio non sono registrati su OVHcloud. Inoltre, puoi associare uno o più nomi di dominio o sottodomini allo stesso sito web.

Non desideri più utilizzare un nome di dominio o un sottodominio per il tuo sito web?
Vuoi associare il tuo nome di dominio o sottodominio a un altro sito web su uno dei tuoi hosting web?

**Questa guida ti mostra come scollegare un nome di dominio o un sottodominio da un sito web già esistente sul tuo hosting web.**

## Prerequisiti

- Disporre di un piano di [hosting web OVHcloud](https://www.ovhcloud.com/it/web-hosting/uc-multisite/) compatibile.
- Disporre di uno o più [nomi di dominio](https://www.ovhcloud.com/it/domains/).
- Poter modificare la configurazione dei tuoi nomi di dominio dalle loro [zone DNS](/guides/web-cloud/domains/dns-zone-edit).

[[cpnav:web-hosting]]

## Procedura

:::warning
Scollegare un nome di dominio o un sottodominio da un sito web presente sul tuo hosting web è un'operazione delicata. Infatti, dopo questa operazione, il tuo sito web non sarà più accessibile su Internet con il tuo nome di dominio e/o sottodominio.

:::

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">I miei siti</code>. Nella tabella, clicca sul pulsante <code className="action">⋮</code> nella colonna **Azioni**, a destra del sito web interessato, poi, nel gruppo **Nomi di dominio**, su <code className="action">Gestisci i miei domini</code>.

    <img className="thumbnail" alt="Menu Azioni di un sito web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Il pannello **Gestisci i miei domini** si apre a destra ed elenca i domini e i sottodomini associati a questo sito web. Su quello che vuoi scollegare, clicca sul pulsante <code className="action">⋮</code> a destra del suo nome, poi su <code className="action">Scollega</code>.

    <img className="thumbnail" alt="Pannello Gestisci i miei domini e menu Azioni di un dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/manage-domains-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Si apre la finestra **Scollega un dominio**, che ti chiede di confermare la scelta. Contiene due impostazioni:

    <img className="thumbnail" alt="Finestra Scollega un dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/detach-domain-dialog.png" loading="lazy" />

    - **Scollega anche il sottodominio**, seguito dal sottodominio `www` interessato: deselezionata per impostazione predefinita, questa casella lo scollega contemporaneamente al dominio, se anche questo è dichiarato su questo sito web. La zona DNS di questo sottodominio e tutte le sue opzioni vengono quindi eliminate.
    - <code className="action">Elimina i record di puntamento (A e AAAA) nella zona DNS del nome di dominio.</code>: selezionata per impostazione predefinita, questa casella rimuove dalla zona DNS i record che puntano al tuo hosting Web. Deselezionala se vuoi conservare questi record.

    Infine, clicca su <code className="action">Conferma</code>.

    :::warning
    **Caso particolare: il tuo sito web è associato a un repository Git**

    La finestra mostra allora un avviso e una casella aggiuntiva, <code className="action">Sì, elimina la mia configurazione Git</code>. Il pulsante <code className="action">Conferma</code> resta inattivo finché non la selezioni: scollegare il dominio elimina contemporaneamente l'[associazione Git](/guides/web-cloud/web-hosting/git-integration-webhosting) del sito web.

    <img className="thumbnail" alt="Finestra Scollega un dominio su un sito associato a Git" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/detach-domain-git.png" loading="lazy" />

    :::
  </Tab>
</Tabs>

### Caso particolare: Stacco di un nome di dominio o di un sottodominio per utilizzarlo con un altro sito web

- Se desideri aggiungere il tuo nome di dominio o sottodominio a un altro sito web esistente su un hosting web, consulta [questa guida](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).
- Se desideri creare un nuovo sito web su un hosting web con il tuo nome di dominio o sottodominio appena staccato, consulta [questa guida](/guides/web-cloud/web-hosting/multisites-configure-multisite).
