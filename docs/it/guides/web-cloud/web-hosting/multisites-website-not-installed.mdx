## Obiettivo

La pagina di errore "**Sito non installato**" può essere visualizzata sul browser, in particolare al momento della prima installazione del sito Web.

<img className="thumbnail" alt="website not installed" src="/images/assets/screens/other/browsers/errors/site-not-installed.png" loading="lazy" />

**Questa guida ti mostra come individuare e risolvere la pagina di errore "Sito non installato"**

[[fragment:support-scope]]

## Prerequisiti

- Disporre di una [offerta di hosting condiviso](/links/web/hosting)
- Disporre anche della gestione della [Zona DNS](/guides/web-cloud/domains/dns-zone-edit) alla quale è associato il dominio.

[[cpnav:web-hosting-console]]

## Procedura

La pagina "**Sito non installato**" viene visualizzata per due motivi:

- 1: [Il tuo dominio o sottodominio non è dichiarato correttamente su uno dei siti web presenti sul tuo hosting web](#check-my-websites).
- 2: [Il dominio non punta all'indirizzo IP della tua soluzione di hosting Web](#check-dns-domain)

Gli step successivi ti permetteranno di correggere l'errore `Sito non installato` in entrambi i casi.

### 1 - Verifica la dichiarazione del tuo dominio o sottodominio sul tuo sito web presente sul tuo hosting web <a name="check-my-websites"></a>

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">I miei siti</code>. Nella tabella, clicca sul pulsante <code className="action">⋮</code> nella colonna **Azioni**, a destra del sito web interessato, poi, nel gruppo **Nomi di dominio**, su <code className="action">Gestisci i miei domini</code>.

    <img className="thumbnail" alt="Menu Azioni di un sito web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Il pannello **Gestisci i miei domini** si apre sulla destra ed elenca i nomi di dominio e i sottodomini associati a questo sito Web.

    |Scenari|Azioni da intraprendere|
    |---|---|
    |Il dominio o sottodominio associato al tuo sito web **è presente** nel pannello.|Se hai appena aggiunto il tuo dominio o sottodominio sul tuo sito web presente sul tuo hosting web, attendi circa **venti minuti** e poi aggiorna la cache del tuo browser. Se appare comunque il messaggio "Sito non installato", passa alla [parte 2](#check-dns-domain).|
    |Il dominio o sottodominio associato al tuo sito web **non è presente** nel pannello.|Aggiungi il tuo dominio o sottodominio seguendo la guida "[Come associare un nome di dominio a un sito web esistente](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".|
    |Il dominio o sottodominio **è stato rimosso** dal pannello senza azione da parte tua.|Il tuo dominio o la sua zona DNS potrebbe essere gestita da un altro account. Aggiungi il tuo dominio o sottodominio seguendo la guida "[Come associare un nome di dominio a un sito web esistente](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".|
  </Tab>
</Tabs>

### 2 - Verifica il puntamento IP nella zona DNS attiva del tuo dominio <a name="check-dns-domain"></a>

Per prima cosa è necessario verificare che il dominio o sottodominio punti verso l'indirizzo IP dell'hosting Web, dalla sua zona DNS attiva.

:::info
Per saperne di più sul concetto di DNS, consulta le pagine seguenti:

- [Modificare una zona DNS di OVHcloud](/guides/web-cloud/domains/dns-zone-edit);
- [Creare una zona DNS OVHcloud per un dominio](/guides/web-cloud/domains/dns-zone-create);
- [Modificare i server DNS di un dominio OVHcloud](/guides/web-cloud/domains/dns-server-edit).

:::

#### 2\.1 Identificare l’indirizzo IP dell’hosting Web OVHcloud

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **2** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    L'hosting si apre sulla scheda <code className="action">Panoramica</code>. Nella sezione **Informazioni generali**, individua la voce **IPv4**.

    <img className="thumbnail" alt="Sezione Informazioni generali, indirizzi IPv4 e IPv6" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/ipv4-ipv6.png" loading="lazy" />

    Copia l'indirizzo IPv4 con il pulsante di copia situato alla sua destra, poi prosegui nella lettura della guida.
  </Tab>
</Tabs>

L’indirizzo IP associato all’hosting Web è disponibile anche nella nostra guida "[Hosting Web - Lista degli indirizzi IP per cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)".

#### 2\.2 Verifica l'indirizzo IP indicato nella zona DNS attiva del dominio

A questo punto, è necessario verificare che l'indirizzo IP dell'hosting Web compaia nella zona DNS attiva del dominio.

:::info
Prima di continuare, in caso di modifica nella **zona DNS** attiva di un dominio, potrebbe essere necessario un tempo di propagazione fino a **24 ore** per aggiornare le informazioni sulla rete DNS.

Se modifichi direttamente i **server DNS** associati al tuo dominio, l'intervallo di tempo massimo consentito è di **48 ore**.

:::

La zona DNS si consulta dal dominio, e non dall'hosting Web. Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi scegli il dominio interessato.

    <img className="thumbnail" alt="Pagina Domini e DNS ed elenco dei nomi di dominio dell'account" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />

    Sotto ogni nome, la voce **Dominio + Zona** o **Solo zona** indica se il dominio è registrato presso OVHcloud o se vi è gestita solo la sua zona DNS.

    Clicca poi sulla scheda <code className="action">Zona DNS</code>.

    :::info
    Puoi anche aprire la zona dalla scheda <code className="action">Panoramica</code> del dominio: la sezione **Zona DNS** indica il numero di record e presenta un pulsante <code className="action">Gestisci la zona DNS</code>.
    :::
  </Tab>
  <Tab label="Passaggio 2">
    La tabella che appare mostra un record DNS per riga, suddiviso in quattro colonne: **Sottodominio**, **Tipo**, **Destinazione** e **TTL (in secondi)**.

    <img className="thumbnail" alt="Scheda Zona DNS e tabella dei record" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/tab.png" loading="lazy" />

    Per mantenere solo i record che ci interessano, clicca su <code className="action">Filtri</code> e seleziona <code className="action">A</code> nell'elenco **Tipo di record**, poi ripeti con <code className="action">AAAA</code> se l'elenco lo propone (contiene solo i tipi presenti nella tua zona). Un campo di ricerca permette inoltre di trovare un sottodominio specifico.

    <img className="thumbnail" alt="Pulsante Filtri ed elenco Tipo di record della zona DNS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-type.png" loading="lazy" />

    :::info
    Se la barra delle schede del tuo dominio si limita a **Panoramica**, **Zona DNS**, **DynHost** e **Reindirizzamenti**, senza la scheda **Host**, nel tuo account OVHcloud è gestita solo la zona DNS: il dominio stesso è registrato altrove.

    <img className="thumbnail" alt="Barra delle schede ridotta di una zona DNS senza dominio associato" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/standalone-zone.png" loading="lazy" />

    Determina il suo "registrar" e i server DNS a cui è associato tramite il nostro strumento [WHOIS](/links/web/domains-whois). Trova e modifica di conseguenza la zona DNS interessata seguendo la sezione dedicata della guida "[Come associare un nome di dominio a un sito web esistente](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".
    :::

    Passare al passaggio 4 per visualizzare i diversi scenari possibili e le azioni da intraprendere.
  </Tab>
  <Tab label="Passaggio 3">
    |Possibili scenari|Azione da intraprendere|
    |---|---|
    |Un record di tipo **A** (indirizzo IPv4) o **AAAA** (indirizzo IPv6) riporta, nella colonna **Destinazione**, l'indirizzo IP del tuo hosting Web annotato al passaggio precedente.|Ciò indica che la configurazione del nome di dominio è corretta.<br/>Attendi il tempo di propagazione DNS se la modifica è recente.<br/><br/>Riavvia i tuoi dispositivi (PC, smartphone, box, ecc...) e svuota la cache del tuo browser. è possibile che la configurazione precedente del dominio resti ancora nella cache e che l'aggiornamento subisca dei ritardi.|
    |La tabella non contiene alcun record di tipo **A** o **AAAA** per il tuo dominio o sottodominio.|Aggiungi il nuovo record DNS di tipo A o AAAA seguendo [questa guida](/guides/web-cloud/domains/dns-zone-edit).|
    |Il record di tipo **A** o **AAAA** esiste, ma la sua **Destinazione** è un indirizzo IP diverso da quello del tuo hosting Web.|Correggi il record esistente seguendo [questa guida](/guides/web-cloud/domains/dns-zone-edit).|
    |Un banner segnala che questa zona DNS non è autoritativa per il tuo nome di dominio.|Le modifiche effettuate qui non vengono prese in considerazione: il tuo dominio utilizza altri server DNS. Modificali seguendo la nostra guida "[Modificare i server DNS di un nome di dominio OVHcloud](/guides/web-cloud/domains/dns-server-edit)".|
  </Tab>
</Tabs>
