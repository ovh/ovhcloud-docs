## Obiettivo

La pagina di errore "**Sito non installato**" può essere visualizzata sul browser, in particolare al momento della prima installazione del sito Web.

<img className="thumbnail" alt="website not installed" src="/images/assets/screens/other/browsers/errors/site-not-installed.png" loading="lazy" />

**Questa guida ti mostra come individuare e risolvere la pagina di errore "Sito non installato"**

[[fragment:support-scope]]

:::info
Alcune procedure di questa guida si applicano alla <ManagerLink to="/beta/#/">nuova versione dello Spazio Cliente OVHcloud</ManagerLink>.
Un promemoria è presente all'inizio di ogni sezione interessata.

:::

## Prerequisiti

- Disporre di una [offerta di hosting condiviso](/links/web/hosting)
- Disporre anche della gestione della [Zona DNS](/guides/web-cloud/domains/dns-zone-edit) alla quale è associato il dominio.

## Procedura

La pagina "**Sito non installato**" viene visualizzata per due motivi:

- 1: [Il tuo dominio o sottodominio non è dichiarato correttamente su uno dei siti web presenti sul tuo hosting web](#check-my-websites).
- 2: [Il dominio non punta all'indirizzo IP della tua soluzione di hosting Web](#check-dns-domain)

Gli step successivi ti permetteranno di correggere l’errore `Sito non installato` in entrambi i casi.

### 1 - Verifica la dichiarazione del tuo dominio o sottodominio sul tuo sito web presente sul tuo hosting web <a name="check-my-websites"></a>

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

:::info
Questa sezione si applica alla <ManagerLink to="/beta/#/">nuova versione dello Spazio Cliente OVHcloud</ManagerLink>.

:::

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hosting</ManagerLink> e seleziona l'hosting web interessato.

    <img className="thumbnail" alt="Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella pagina visualizzata, clicca sulla scheda <code className="action">I miei siti</code>.

    <img className="thumbnail" alt="I miei siti" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nel tavolo che appare, clicca sul pulsante <code className="action">></code> a sinistra del nome del sito web interessato per visualizzare i domini e sottodomini associati.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />

    |Scenari|Azioni da intraprendere|
    |---|---|
    |Il dominio o sottodominio associato al tuo sito web **è presente** nel tavolo.|Se hai appena aggiunto il tuo dominio o sottodominio sul tuo sito web presente sul tuo hosting web, attendi circa **venti minuti** e poi aggiorna la cache del tuo browser. Se appare comunque il messaggio "Sito non installato", passa alla [parte 2](#check-dns-domain).|
    |Il dominio o sottodominio associato al tuo sito web **non è presente** nel tavolo.|Aggiungi il tuo dominio o sottodominio seguendo la guida "[Come associare un dominio a un sito web esistente?](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".|
    |Il dominio o sottodominio **è stato rimosso** dal tavolo senza azione da parte tua.|Il tuo dominio o la sua zona DNS potrebbe essere gestita da un altro account. Aggiungi il tuo dominio o sottodominio seguendo la guida "[Come associare un dominio a un sito web esistente? - Aggiungere un dominio esterno](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".|
  </Tab>
</Tabs>

#### 2 - Verifica il puntamento IP nella zona DNS attiva del tuo dominio <a name="check-dns-domain"></a>

Per prima cosa è necessario verificare che il dominio o sottodominio punti verso l’indirizzo IP dell’hosting Web, dalla sua zona DNS attiva.

:::info
Per saperne di più sul concetto di DNS, consulta le pagine seguenti:

- [Modificare una zona DNS di OVHcloud](/guides/web-cloud/domains/dns-zone-edit);
- [Creare una zona DNS OVHcloud per un dominio](/guides/web-cloud/domains/dns-zone-create);
- [Modificare i server DNS di un dominio OVHcloud](/guides/web-cloud/domains/dns-server-edit).

:::

#### 2\.1 Identificare l’indirizzo IP dell’hosting Web OVHcloud

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **2** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/#/web/hosting">Hosting</ManagerLink>, poi seleziona l'hosting Web interessato.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nel riquadro **Informazioni generali**, trovi la dicitura **IPv4**.

    <img className="thumbnail" alt="find-ipv4-and-ipv6" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-ipv4-and-ipv6.png" loading="lazy" />

Copia l'indirizzo IPv4, poi prosegui nella lettura della guida.
  </Tab>
</Tabs>

L’indirizzo IP associato all’hosting Web è disponibile anche nella nostra guida "[Hosting Web - Lista degli indirizzi IP per cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)".

#### 2\.2 Verifica l'indirizzo IP indicato nella zona DNS attiva del dominio

A questo punto, è necessario verificare che l’indirizzo IP dell’hosting Web compaia nella zona DNS attiva del dominio.

:::info
Prima di continuare, in caso di modifica nella **zona DNS** attiva di un dominio, potrebbe essere necessario un tempo di propagazione di **4 a 24 ore** per aggiornare le informazioni sulla rete DNS.

Se modifichi direttamente i **server DNS** associati al tuo dominio, l'intervallo di tempo massimo consentito è di **48 ore**.

:::

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/#/web/hosting">Hosting</ManagerLink>, poi seleziona l'hosting Web interessato.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Visualizzi una tabella con tutti i record DNS associati al tuo dominio in OVHcloud. Il contenuto della tabella può essere filtrato in base al tipo di record o al dominio.

    <img className="thumbnail" alt="dns zone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/tab.png" loading="lazy" />

    :::info
    Se la scheda <code className="action">Zona DNS</code> del dominio viene visualizzata nel modo seguente:<br/><br/> <img className="thumbnail" alt="zone-without-domain-top-of-the-page" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/zone-without-domain-top-of-the-page.png" loading="lazy" /><br/>

    Questo significa che il tuo dominio non è gestito dal tuo Spazio Cliente OVHcloud.<br/> Determina il suo "ufficio di registrazione" e i server DNS a cui è associato tramite il nostro strumento [WHOIS](/links/web/domains-whois).<br/> Trova e modifica la zona DNS corrispondente seguendo la sezione dedicata della guida "[Come associare un dominio a un sito web esistente? - Aggiungere un dominio esterno](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website)".

    :::

    Passare al passaggio 4 per visualizzare i diversi scenari possibili e le azioni da intraprendere.
  </Tab>
  <Tab label="Passaggio 3">
    |Possibili scenari|Azione da intraprendere|
    |---|---|
    |Nella zona DNS attiva, il dominio o sottodominio punta all'indirizzo IP dell'hosting Web con un record di tipo A (per un indirizzo IPv4) o AAAA (per un indirizzo IPv6).<br/><br/><img className="thumbnail" alt="Zona DNS filtrata sui record A" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-filter-a.png" loading="lazy" />|Ciò indica che la configurazione del nome di dominio è corretta.<br/>Attendi il tempo di propagazione DNS se la modifica è recente.<br/><br/>Riavvia i tuoi dispositivi (PC, smartphone, box, ecc...) e svuota la cache del tuo browser. è possibile che la configurazione precedente del dominio resti ancora nella cache e che l'aggiornamento subisca dei ritardi.|
    |La zona DNS attiva non contiene record di tipo A o AAAA che collegano il dominio o il sottodominio all'indirizzo IP dell'hosting Web.|Aggiungere il nuovo record DNS di tipo A o AAAA o correggere il record esistente seguendo [questa guida](/guides/web-cloud/domains/dns-zone-edit).|
    |Il record DNS di tipo A o AAAA esistente nella zona DNS per il dominio o il sottodominio punta verso un indirizzo IP diverso da quello dell’hosting Web.|Aggiungere il nuovo record DNS di tipo A o AAAA o correggere il record esistente seguendo [questa guida](/guides/web-cloud/domains/dns-zone-edit).|
    |Questo avviso viene visualizzato nella scheda <code className="action">Zona DNS</code>:<br/><br/><img className="thumbnail" alt="message-other-ovh-dns-servers" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/message-other-ovh-dns-servers.png" loading="lazy" />|Modifica i server DNS del dominio di conseguenza seguendo la nostra guida "[Modificare i server DNS di un dominio OVHcloud](/guides/web-cloud/domains/dns-server-edit)."|
  </Tab>
</Tabs>
