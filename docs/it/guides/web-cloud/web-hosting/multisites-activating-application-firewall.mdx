## Obiettivo

*ModSecurity* è un modulo Apache complementare che filtra tutte le richieste in entrata sul tuo server Web. Aumenta la sicurezza contro le vulnerabilità note intercettando e filtrando le richieste prima che siano trattate con script.

L'insieme preconfigurato di regole di base, il "Core Rule Set" (CRS) della nostra *ModSecurity* protegge i tuoi siti Web dagli attacchi più diffusi, ad esempio:

- Trojans,
- Email injection,
- Bug sui file PDF,
- File injection sul tuo hosting,
- SQL o XSS injection,
- e tanto altro ancora

**Questa guida ti mostra come attivare il firewall applicativo dalla console OVHcloud, per ottenere una protezione migliorata.**

:::info
La modifica delle impostazioni di configurazione del firewall non è disponibile perché l'hosting Web è presente su un'infrastruttura condivisa.

:::

## Prerequisiti

- Disporre di un piano di [hosting Web OVHcloud](/links/web/hosting) attivo
- Disporre di almeno un [dominio](/links/web/domains) associato all'hosting

## Procedura

**Fai clic sui titoli qui sotto per visualizzare le spiegazioni.**

<details>
<summary>Abilitare il firewall applicativo sull'intero hosting web nella configurazione PHP</summary>

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    L'hosting si apre sulla scheda <code className="action">Panoramica</code>. Individua la sezione **PHP**, che mostra la voce **Versione PHP globale**, poi clicca su <code className="action">Modifica la versione di PHP</code>.

    <img className="thumbnail" alt="Sezione PHP della scheda Panoramica" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/php-section.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Il pannello di configurazione si apre sulla destra. Nella sezione **Opzioni avanzate**, apri il menu a tendina **Firewall applicativo**, poi seleziona il valore <code className="action">sicurezza</code>: attiva `mod_security`, che protegge il tuo hosting dagli attacchi più comuni. Il valore <code className="action">disattivato</code> lascia il firewall inattivo.

    <img className="thumbnail" alt="Opzioni avanzate della configurazione PHP e menu Firewall applicativo" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/php-config-firewall.png" loading="lazy" />

    Infine, clicca su <code className="action">Conferma</code>.

    :::warning
    Una modifica della configurazione può avere effetti sui tuoi siti: ricordati di testarli dopo ogni modifica.
    :::
  </Tab>
</Tabs>

</details>

<details>
<summary>Abilitare il firewall applicativo solo su un dominio o sottodominio specifico</summary>

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">I miei siti</code>. Nella tabella, clicca sul pulsante <code className="action">⋮</code> della colonna **Azioni**, a destra del sito Web interessato, poi, nel gruppo **Nomi di dominio**, su <code className="action">Gestisci i miei domini</code>.

    <img className="thumbnail" alt="Menu Azioni di un sito Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Il pannello **Gestisci i miei domini** si apre sulla destra ed elenca i nomi di dominio e i sottodomini associati a questo sito Web. Sul dominio interessato, clicca sul pulsante <code className="action">⋮</code> situato a destra del suo nome, poi su <code className="action">Gestisci le mie opzioni</code>.

    <img className="thumbnail" alt="Pannello Gestisci i miei domini e menu Azioni di un dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/manage-domains-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Nella finestra **Gestisci le opzioni**, gruppo **Sicurezza**, seleziona la casella <code className="action">Attivare il firewall</code>, poi clicca su <code className="action">Conferma</code>.

    <img className="thumbnail" alt="Finestra Gestisci le opzioni di un nome di dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/country-ip-selection.png" loading="lazy" />

    :::info
    L'impostazione si applica solo al nome di dominio o sottodominio selezionato. Per proteggere anche il sottodominio `www`, ripeti l'operazione sulla sua riga nel pannello **Gestisci i miei domini**, se vi è dichiarato.
    :::

    Una volta attivato il firewall, la colonna **Firewall** della tabella dei siti indica il numero di nomi di dominio protetti sul numero totale di quelli associati al sito Web, ad esempio `1/4`. Se questo conteggio non cambia dopo qualche minuto, ricarica la pagina.
  </Tab>
</Tabs>

</details>
