## Obiettivo

*ModSecurity* è un modulo Apache complementare che filtra tutte le richieste in entrata sul tuo server Web. Aumenta la sicurezza contro le vulnerabilità note intercettando e filtrando le richieste prima che siano trattate con script.

L'insieme preconfigurato di regole di base, il "Core Rule Set" (CRS) della nostra *ModSecurity* protegge i tuoi siti Web dagli attacchi più diffusi, ad esempio:

- Trojans,
- Email injection,
- Bug sui file PDF,
- File injection sul tuo hosting,
- SQL o XSS injection,
- e tanto altro ancora

**Questa guida ti mostra come attivare il firewall applicativo dal tuo Spazio Cliente OVHcloud, per ottenere una protezione migliorata.**

:::info
La modifica delle impostazioni di configurazione del firewall non è disponibile perché l’hosting Web è presente su un’infrastruttura condivisa.

:::

:::info
Alcune procedure di questa guida si applicano alla <ManagerLink to="/beta/#/">nuova versione dello Spazio Cliente OVHcloud</ManagerLink>.
Un promemoria è presente all'inizio di ogni sezione interessata.

:::

## Prerequisiti

- Disporre di un piano di [hosting Web OVHcloud](/links/web/hosting) attivo
- Disporre di almeno un [dominio](/links/web/domains) associato all'hosting

## Procedura

**Fai clic sui titoli qui sotto per visualizzare le spiegazioni.**

<details>
<summary>Abilitare il firewall applicativo sull'intero hosting web nella configurazione PHP</summary>

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/#/web/hosting">Hosting</ManagerLink>, poi seleziona l'hosting Web interessato.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nel riquadro **Configurazione**, troverai l'indicazione **Versione PHP**.

    <img className="thumbnail" alt="Versione PHP Globale" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/modify-hosting-configuration.png" loading="lazy" />

    Fai clic sul pulsante <code className="action">...</code> a destra dell'indicazione **Versione PHP**, quindi su <code className="action">Modifica la configurazione</code>.
  </Tab>
  <Tab label="Passaggio 3">
    Nella finestra che si apre, seleziona l'elemento <code className="action">Modifica la configurazione attuale</code> e fai clic sul pulsante <code className="action">Continua</code>.

    <img className="thumbnail" alt="managephpconfig" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/application-firewall-step-2.png" loading="lazy" />

    Nella nuova finestra, assicurati che l'opzione **Firewall a livello applicativo** sia impostata su <code className="action">Attivato</code>. Fai quindi clic sul pulsante <code className="action">Conferma</code>.
  </Tab>
</Tabs>

</details>

<details>
<summary>Abilitare il firewall applicativo solo su un dominio o sottodominio specifico</summary>

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passi.

:::info
Questa sezione si applica alla <ManagerLink to="/beta/#/">nuova versione dello Spazio Cliente OVHcloud</ManagerLink>.

:::

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hosting</ManagerLink> e seleziona l'hosting web interessato.

    <img className="thumbnail" alt="Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella pagina visualizzata, clicca sulla scheda <code className="action">I miei siti</code>.

    <img className="thumbnail" alt="I miei siti" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nel riquadro che appare, fai clic sul pulsante <code className="action">></code> a sinistra del nome del sito web desiderato per visualizzare i domini o sottodomini associati.

    <img className="thumbnail" alt="Sito web" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />

    Fai quindi clic sul pulsante <code className="action">⁝</code> a destra del nome del dominio o sottodominio desiderato, quindi su <code className="action">Modifica il dominio</code>.

    <img className="thumbnail" alt="Opzioni domini associati" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/associated-domains-options.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Nella finestra di configurazione, seleziona la casella <code className="action">Attiva il firewall</code>. Puoi inoltre includere il sottodominio `www` in questa configurazione selezionando la casella corrispondente in alto (se presente sullo stesso sito web).

    <img className="thumbnail" alt="Modifica un dominio" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/modify-a-domain-enable-firewall-step-1.png" loading="lazy" />

    Fai clic su <code className="action">Continua</code>, quindi su <code className="action">Conferma</code> per salvare le modifiche ai parametri.

    Una volta attivato il firewall per il tuo dominio o sottodominio, l'indicazione **Attivato** apparirà nella colonna **Firewall**.

    Se l'indicazione **Attivato** non dovesse apparire entro pochi minuti sulla riga corrispondente al dominio o sottodominio desiderato, ricarica la pagina.
  </Tab>
</Tabs>

</details>
