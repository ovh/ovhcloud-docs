## Obiettivo

La maggior parte dei siti Web utilizza un **database** per archiviare articoli, commenti e indirizzi email dei propri utenti.

La connessione a questo database è possibile tramite un **file di configurazione** contenuto nello [spazio di archiviazione dei file](/guides/web-cloud/web-hosting/ftp-connection) del tuo hosting. Che contiene le informazioni che permettono al tuo sito di "identificarsi" presso il suo **server di database**.

La modifica della password di un database deve quindi essere sempre effettuata:

- Nel [file di configurazione](/guides/web-cloud/web-hosting/cms-manage-1-click-module#step-1-identifica-il-database-associato-al-tuo-modulo) del tuo sito tramite lo [spazio FTP del tuo hosting](/guides/web-cloud/web-hosting/ftp-connection);

- **E** nel server che contiene il suo database attraverso la <ManagerLink to="/beta/#/">console OVHcloud</ManagerLink>.

Finché la modifica non sarà effettuata **in entrambi i punti**, il tuo sito mostrerà un "[errore di connessione al database](/guides/web-cloud/web-hosting/diagnosis-database-errors#error-establishing-a-database-connection)".

Per modificare la password del database è quindi necessario eseguire **tutte le operazioni** indicate in questa guida. In caso di dubbi sulle operazioni da effettuare, contatta il tuo webmaster o rivolgiti a un [provider specializzato](/links/partner).

Per modificare la password del database del tuo sito sono necessarie quattro azioni:

- [1: Identificare il file di configurazione del tuo sito](#step1);
- [2: Identificare il database del tuo sito](#step2);
- [3: Modificare la password del database del tuo sito nel file di configurazione](#step3);
- [4: Modificare la password del database del tuo sito sul server di database](#step4).

**Questa guida ti mostra come modificare la password di un database in modo sicuro.**

## Prerequisiti

- Disporre di una [soluzione di hosting Web OVHcloud](/links/web/hosting)
- Utilizza un [database associato alla tua offerta di hosting condiviso](/links/web/hosting-options-startsql) o [Web Cloud Databases](/links/web/databases).
- Disporre delle credenziali FTP per accedere allo [spazio di storage dell'hosting](/guides/web-cloud/web-hosting/ftp-connection)

  <Tab label="Passaggio 3">
    Nella tabella, individua la riga del tuo sito web grazie alla colonna **Sito**, poi leggi la sua colonna **Cartella radice**. Si tratta della directory in cui si trovano i file e le cartelle del tuo sito.

    <img className="thumbnail" alt="Tabella dei siti e colonna Cartella radice" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/root-folders.png" loading="lazy" />

    Procedi quindi all'accesso allo spazio di archiviazione FTP che contiene i file e le directory del tuo sito consultando [questa guida](/guides/web-cloud/web-hosting/ftp-connection).
  </Tab>

:::info
Per modificare la password del tuo spazio FTP, consulta questa [guida](/guides/web-cloud/web-hosting/ftp-change-password).

:::

Apri la `Cartella di root` identificata sopra.

Ricerca e apri il file di configurazione del tuo sito:

- Per un sito WORDPRESS si tratta di **"wp-config.php"**;
- Per un sito JOOMLA, si tratta di **"configuration.php"**;
- Per un sito DRUPAL, clicca sulla cartella "**sites"** e **"default"**. Il file di configurazione è **"settings.php"**;
- Per un sito PRESTASHOP, clicca sulla cartella **"app"** e **"config"**. Il file di configurazione è **"parameters.php"**.

### 2: Identificare il database del tuo sito <a name="step2"></a>

Sono possibili due casi:

- Caso 1: il database del tuo sito fa parte della tua offerta di hosting;
- Caso 2: è inclusa in un'offerta *Web Cloud Databases*, nel qual caso dovrai trovare il **nome del server** e il **nome utente** del tuo database per identificarlo senza rischio di errore.

Per verificare quale caso si applica al tuo sito, nel file di configurazione identificato nella [parte 1](#step1), inserisci il nome del database:

- Per WORDPRESS: il nome appare sotto la dicitura **"DB_NAME"**;
- Per JOOMLA: il nome appare sotto **"public $db"**;
- Per DRUPAL: il nome appare sotto **"database"**;
- Per PRESTASHOP: il nome appare sotto **"database_name"**.

Dopodiché torna alla <ManagerLink to="/beta/#/web-cloud/hosting">console OVHcloud</ManagerLink>, nell'universo <code className="action">Web Cloud</code>:

- Accedi alla sezione <code className="action">Hosting web</code> e poi all'hosting interessato.
- Clicca sulla scheda <code className="action">Database</code>, nella barra delle schede situata sotto il nome del tuo hosting.
- Cerca il nome del database trovato precedentemente nella colonna **Nome del database**;

Se hai ritrovato in questa sezione della console OVHcloud il nome del database indicato nel file di configurazione, passa alla [parte 3](#step3).

In caso contrario, il database del tuo sito è associato a un'offerta [Web Cloud Databases](/links/web/databases).

Per registrare il *nome del server* e il *nome utente* del database, è necessario ritornare al file di configurazione del tuo sito:

- Per WORDPRESS: il *nome del server* compare con la dicitura **"DB_HOST"** e il *nome utente* con la dicitura **"DB_USER"**;
- Per JOOMLA: il *nome del server* appare sotto **"public $host"** e il *nome utente* con la menzione **"public $user"**;
- Per DRUPAL: il *nome del server* appare sotto **"host"** e il *nome utente* sotto la dicitura **"username"**;
- Per PRESTASHOP: il *nome del server* appare sotto **"database_host"** e il *nome utente* sotto la voce **"database_user"**.

Accedi poi alla sezione <code className="action">Web Cloud DB</code> della console OVHcloud e seleziona l'istanza interessata.

Nella scheda <code className="action">Panoramica</code>, individua la sezione **SQL** e il suo campo **Nome host**: contiene il nome del server del tuo database trovato precedentemente.

:::warning
Non confondere questo campo con quello denominato **Host**, situato più in alto nella sezione **Informazioni generali**: quest'ultimo designa l'infrastruttura che ospita la tua istanza, e non l'indirizzo che il tuo sito utilizza per connettersi.

:::

<img className="thumbnail" alt="Panoramica di un'istanza Web Cloud DB e campo Nome host" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/overview-hostname.png" loading="lazy" />

Sempre su questa istanza, clicca sulla scheda <code className="action">Utenti e autorizzazioni</code>, per visualizzare anche il **nome utente** del tuo database. Ogni utente è presentato sotto forma di scheda che ne riporta il nome.

### 3: Modifica la password del database del tuo sito nel file di configurazione <a name="step3"></a>

:::info
Per maggiori informazioni sulle best practice di gestione delle password, segui le indicazioni di questa [guida](/guides/account-and-service-management/account-information/manage-ovh-password).

:::

Scegli la nuova password del tuo database e annotiamolo. Esso dovrà rispettare le seguenti condizioni:

- Minimo 8 caratteri;
- Massimo 30 caratteri;
- almeno una lettera maiuscola;
- almeno una lettera minuscola;
- almeno una cifra;
- Essere composto esclusivamente da cifre e lettere.

Allo stesso modo della [parte 1](#step1), torna allo spazio di storage dei file del tuo hosting e modifica il file di configurazione del tuo sito.

**Prima di apportare qualsiasi modifica**, registra localmente il contenuto di questo file in un documento di testo per conservarne una copia in caso di errore di manipolazione.

Sostituisci manualmente la password del tuo database **evitando di modificare o eliminare qualsiasi altro elemento del file di configurazione** (Negli estratti qui sotto, sarà necessario sostituire solo la password dell'esempio "*0VhCloudPa55w0rdDB123*"):

- Nel file di configurazione di un sito WORDPRESS, modifica il **"DB_PASSWORD"**:

```php
// ** MySQL settings - You can get this info from your web host ** //
/** The name of the database for WordPress */
define('DB_NAME', 'dbname123');
 
/** MySQL database username */
define('DB_USER', 'dbname123');
 
/** MySQL database password */
define('DB_PASSWORD', '0VhCloudPa55w0rdDB123');
 
/** MySQL hostname */
define('DB_HOST', 'dbname123.mysql.db:3306');
```

- Nel file di configurazione di un sito JOOMLA, modifica il **"public $password"** (alla fine del file di configurazione):

```php
public $host = 'dbname123.mysql.db:3306';
public $user = 'dbname123';
public $password = '0VhCloudPa55w0rdDB123';
public $db = 'dbname123';
```

- Nel file di configurazione di un sito DRUPAL, modifica la **"password"**:

```php
$databases['default']['default'] = array (
  'database' => 'dbname123',
  'username' => 'dbname123',
  'password' => '0VhCloudPa55w0rdDB123',
  'prefix' => 'prefix123_',
  'host' => 'dbname123.mysql.db',
  'port' => '3306',
```

- Nel file di configurazione di un sito PRESTASHOP, modifica la **"database_password"**:

```php
'database_host' => 'dbname123.mysql.db',
'database_port' => '3306',
'database_name' => 'dbname123',
'database_user' => 'dbname123',
'database_password' => '0VhCloudPa55w0rdDB123',
```

Salva questa modifica.

### 4: Modifica la password del database del tuo sito sul server di database <a name="step4"></a>

:::info
Questa operazione richiederà alcuni minuti prima di diventare effettiva. Una volta avviata la procedura, controlla lo stato nella scheda <code className="action">Operazioni</code>, che indica il numero di operazioni in corso.

:::

Di nuovo, sono possibili due casi: 

- Se il database si trova nella sezione della <ManagerLink to="/beta/#/">console OVHcloud</ManagerLink> dedicata al tuo [hosting Web](/links/web/hosting), segui queste [istruzioni](#case1).
- Se il tuo database si trova nella sezione della <ManagerLink to="/beta/#/">console OVHcloud</ManagerLink> dedicata alle tue offerte [Web Cloud Databases](/guides/web-cloud/databases/landing-page-databases), segui queste [istruzioni](#case2).

#### Caso 1: il database del tuo sito fa parte della tua offerta di hosting <a name="case1"></a>

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Database</code>.

    <img className="thumbnail" alt="Scheda Database di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Sulla riga del database del tuo sito, clicca sul pulsante <code className="action">⁝</code> della colonna **Azioni**, poi su <code className="action">Cambia password</code>.

    <img className="thumbnail" alt="Menu di una riga della tabella dei database" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Nella nuova finestra, inserisci la nuova password del tuo database (definita nella [parte 3](#step3)), confermala e clicca su <code className="action">Modifica</code>.

    <img className="thumbnail" alt="Finestra di modifica della password di un database" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/change-password-window.png" loading="lazy" />

Sotto il campo, la finestra ricorda la regola che questa password deve rispettare: da **9 a 30 caratteri**, di cui una minuscola, una maiuscola e una cifra; **i caratteri speciali sono consentiti**.
  </Tab>
</Tabs>

#### Caso 2: il database del tuo sito fa parte di un'offerta Web Cloud Databases <a name="case2"></a>

Accedi alla sezione <code className="action">Web Cloud DB</code> della console OVHcloud, seleziona l'istanza interessata e clicca sulla scheda <code className="action">Utenti e autorizzazioni</code>:

<img className="thumbnail" alt="Scheda Utenti e autorizzazioni di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />

Ogni utente è presentato sotto forma di scheda che ne riporta il nome. Su quella del **nome utente** identificato nella [parte 2](#step2), clicca sul pulsante <code className="action">⁝</code>, poi su <code className="action">Modificare la password</code>.

<img className="thumbnail" alt="Menu della scheda di un utente di un'istanza Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />

Nella nuova finestra, inserisci la nuova password del tuo database (definita nella [parte 3](#step3)), confermala e clicca su <code className="action">Salva</code>.

<img className="thumbnail" alt="Finestra di modifica della password di un utente" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password-window.png" loading="lazy" />

:::warning
La regola di complessità non è la stessa di un database di hosting Web: qui la password deve contenere da **8 a 30 caratteri**, di cui una minuscola, una maiuscola e una cifra, e **i caratteri speciali sono consentiti**. La finestra la ricorda sotto il campo.

:::
