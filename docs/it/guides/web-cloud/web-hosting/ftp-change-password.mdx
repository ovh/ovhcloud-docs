## Obiettivo

Le offerte di hosting Web OVHcloud danno accesso a uno spazio di archiviazione online dei file utilizzabile tramite il protocollo **FTP**: spazio di storage FTP.

L'accesso a questo spazio è possibile tramite **utente FTP** e la password associata.

Questo accesso permette in particolare di [pubblicare il vostro sito](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online).

**Questa guida ti mostra come modificare la password di un utente FTP creata sul tuo hosting Web OVHcloud.**

[[fragment:support-scope]]

## Prerequisiti

- Disporre di un piano di [hosting Web OVHcloud](/links/web/hosting) attivo

[[cpnav:web-hosting]]

## Procedura

### Modificare la password di un utente FTP

:::info
Per maggiori informazioni sulle best practice di gestione delle password, consulta la guida "[Impostare e gestire la password di un account OVHcloud](/guides/account-and-service-management/account-information/manage-ovh-password)".
:::

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Scheda FTP-SSH di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    La sezione **Utenti FTP e SSH** elenca gli utenti creati sul tuo hosting Web. Clicca sul pulsante <code className="action">⋮</code> nella colonna **Azioni**, a destra dell'utente interessato, poi su <code className="action">Cambia la password</code>.

    <img className="thumbnail" alt="Menu Azioni di un utente FTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />

    Nel pannello <code className="action">Cambia la password</code> che si apre, inserisci la nuova password **rispettando la politica delle password**, confermala digitandola una seconda volta, poi clicca su <code className="action">Cambia</code>.

    <img className="thumbnail" alt="Pannello Cambia la password e i suoi due campi" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/change-password.png" loading="lazy" />
  </Tab>
</Tabs>

:::tip
Solo per l'**utente principale**, esiste una scorciatoia: il pulsante <code className="action">Modifica la password</code> della sezione **Trasferimento di file (FTP/SFTP)**, in alto nella scheda.

:::

:::info
La nuova password dovrà rispettare la seguente **politica delle password**:

- Minimo 9 caratteri
- Massimo 30 caratteri
- Almeno una lettera maiuscola
- Almeno una lettera minuscola
- Almeno una cifra
- Essere composta esclusivamente da cifre e lettere

:::

Consulta la scheda <code className="action">Operazioni</code> e aggiorna regolarmente la pagina. La modifica richiede solo alcuni minuti per diventare effettiva.

### Accedere al tuo spazio di storage

Per accedere al tuo spazio di storage FTP, consulta la nostra guida ["Connettersi allo spazio di storage FTP di un hosting Web"](/guides/web-cloud/web-hosting/ftp-connection).
