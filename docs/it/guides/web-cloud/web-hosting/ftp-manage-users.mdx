## Obiettivo

Le offerte di hosting Web OVHcloud danno accesso a uno spazio di storage FTP. Questo spazio FTP permette, ad esempio, di pubblicare online i file dei tuoi siti Web o delle tue applicazioni. L'accesso a questo spazio è possibile tramite un utente FTP o SSH e la password associata. Nell'ambito delle vostre attività, potreste avere diversi utenti FTP per i vostri diversi collaboratori.

**Questa guida ti mostra come creare, modificare o eliminare utenti FTP su un hosting Web OVHcloud.**

:::info
Questa guida è valida esclusivamente per gli hosting Web di tipo **Pro**, **Performance**, **Agency**, **Agency Plus** o **Agency Max**. Solo queste offerte permettono l'attivazione di più utenti FTP.

:::

## Prerequisiti

- Disporre di una soluzione di [hosting Web OVHcloud](/links/web/hosting) compatibile.

## Procedura

### Creare un nuovo utente FTP sul tuo hosting Web <a name="create-ftp-user"></a>

Per creare un nuovo utente FTP sul tuo hosting Web dalla console OVHcloud, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Scheda FTP-SSH di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella sezione **Utenti FTP e SSH**, clicca su <code className="action">Crea un utente</code>.

    <img className="thumbnail" alt="Pannello di creazione di un utente FTP nella console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/create-user.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Si apre il pannello **Crea un utente**, che riunisce tutti i parametri in un'unica schermata:

    - **Utente**: il nome che il tuo collaboratore utilizzerà per connettersi. È **sempre preceduto dal login FTP principale del tuo hosting Web, seguito da un trattino**: se questo login è `ftplogin` e inserisci `user1`, l'identificativo completo sarà `ftplogin-user1`. Il nome che aggiungi conta tra 1 e 12 caratteri alfanumerici;
    - **Cartella radice**: la directory in cui questo utente potrà operare. **Lascia questo campo vuoto per dare accesso a tutto lo spazio di storage**; altrimenti, indica una directory o una sottodirectory, ad esempio `www`, `blog`, `website1` o `www/development`;
    - **Protocolli di connessione**: il protocollo o i protocolli autorizzati per questo utente. Scegliendo **FTP, SFTP e SSH**, il tuo collaboratore potrà sia gestire i file che connettersi da riga di comando;
    - **Password** e **Conferma la password**: rispetta la policy indicata sotto i campi.

    Infine, clicca su <code className="action">Crea</code>.
  </Tab>
</Tabs>

:::info
Una volta confermata la richiesta di creazione, l'upgrade del nuovo utente all'hosting Web potrebbe richiedere fino a 15 minuti.

:::

In caso di necessità, prova il nuovo utente FTP consultando la nostra guida "[Accedi allo spazio di storage FTP del tuo hosting Web](/guides/web-cloud/web-hosting/ftp-connection)".

### Modificare un utente FTP

Per modificare un utente FTP, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Scheda FTP-SSH di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    La sezione **Utenti FTP e SSH** elenca gli utenti creati sul tuo hosting Web. Nella colonna **Azioni**, clicca sul pulsante <code className="action">⋮</code> a destra dell'utente interessato, poi su <code className="action">Modifica</code>.

    <img className="thumbnail" alt="Menu Azioni di un utente FTP nella console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Si apre il pannello **Modifica un utente**. Sono disponibili tre impostazioni:

    - **Cartella radice**: la directory in cui questo utente potrà operare. Lascia questo campo vuoto per dargli accesso a tutto lo spazio di storage;
    - **Disattiva utente**: seleziona questa casella per impedire a un collaboratore di accedere al tuo spazio di storage FTP **senza eliminare i log FTP e SSH associati**. Questi log ti permetteranno di determinare quali operazioni ha effettuato se rilevi interventi indesiderati sul tuo hosting Web;
    - **Protocolli di connessione**: il protocollo o i protocolli autorizzati per questo utente. Consulta la sezione "[Creare un nuovo utente FTP sul tuo hosting Web](#create-ftp-user)" più in alto in questa guida per il dettaglio dei protocolli.

    :::info
    La **cartella radice** dell'**account principale** non è modificabile: il campo resta disattivato e la console mostra il messaggio "La cartella radice dell'account principale non può essere modificata.". Solo gli utenti che hai creato possono cambiarla.
    :::

    Il nome dell'utente e la sua password non si modificano qui. Per cambiare la password, utilizza la voce <code className="action">Cambia la password</code> dello stesso menu, descritta nella nostra guida "[Modificare la password di un utente FTP](/guides/web-cloud/web-hosting/ftp-change-password)".

    <img className="thumbnail" alt="Pannello di modifica di un utente FTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user.png" loading="lazy" />

    Infine, clicca su <code className="action">Conferma</code>.
  </Tab>
</Tabs>

:::info
Per modificare la password di un utente FTP, consulta la nostra guida "[Modificare la password di un utente FTP](/guides/web-cloud/web-hosting/ftp-change-password)".

Se vuoi modificare il nome dell'utente FTP, ricordati che questa funzionalità non è disponibile. Sarà necessario [creare un nuovo utente FTP](#create-ftp-user) con il nuovo nome utente. In seguito, se necessario, sarai libero di [eliminare il vecchio utente FTP](#delete-ftp-user).

:::

### Eliminare un utente FTP <a name="delete-ftp-user"></a>

Per eliminare un utente FTP, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Scheda FTP-SSH di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella colonna **Azioni** della sezione **Utenti FTP e SSH**, clicca sul pulsante <code className="action">⋮</code> a destra dell'utente interessato, poi su <code className="action">Elimina</code>.

    <img className="thumbnail" alt="Menu Azioni di un utente FTP nella console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Una finestra ti chiede di confermare, ricordando l'identificativo interessato. Clicca su <code className="action">Elimina</code> per rimuovere definitivamente questo utente dal tuo hosting Web.

    <img className="thumbnail" alt="Finestra di conferma dell'eliminazione di un utente FTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/delete-user-confirmation.png" loading="lazy" />
  </Tab>
</Tabs>
