## Obiettivo

Le informazioni contenute in questa guida riguardano le versioni di **PHP**, **Python**, **Perl** e **Apache** utilizzate nell'ambito dei servizi [Web Hosting](/links/web/hosting), accessibili tramite la rete di Web Hosting.

**Scopri i dettagli delle versioni di PHP, Python, Perl e Apache.**

## Prerequisiti

- Disporre di una soluzione di [hosting Web OVHcloud](/links/web/hosting).

## Procedura

Le tabelle seguenti indicano le versioni dei linguaggi disponibili sulle soluzioni Hosting Web OVHcloud e il relativo stato. Ogni versione rimanda alla sua pagina informativa, che indica il numero di versione completo e la configurazione.

### Stato delle versioni

<span style={{backgroundColor:"#198754", color:"white", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Supportata</span>: versione mantenuta sulle soluzioni Hosting Web.

<span style={{backgroundColor:"#ffc107", color:"#212529", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Fine vita</span>: migrate a una versione supportata prima della sua fine vita in OVHcloud.

<span style={{backgroundColor:"#dc3545", color:"white", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Obsoleta</span>: versione non più mantenuta; migrate a una versione supportata.
