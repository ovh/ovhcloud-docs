## Accedere al tuo Hosting Web via FTP, SFTP e SSH

Trasferisci i tuoi file e gestisci il tuo Hosting Web OVHcloud tramite i protocolli FTP, SFTP e SSH. Questa pagina riunisce le guide per connetterti con un client (FileZilla, Cyberduck, Visual Studio Code), gestire i tuoi accessi FTP e connetterti via SSH, tramite PuTTY o direttamente dalla riga di comando.

Per orientarti in base alla tua esigenza:

- **Vuoi trasferire file sul tuo Hosting Web?** Consulta la sezione *Connettersi via FTP/SFTP* (FileZilla, Cyberduck, Visual Studio Code).
- **Vuoi gestire i tuoi utenti e le password FTP?** Consulta la sezione *Gestire gli accessi FTP* (utenti, password, SFTP).
- **Lavori dalla riga di comando?** Consulta la sezione *Accesso SSH e strumenti da riga di comando* (SSH, PuTTY, SCP, SVN).
