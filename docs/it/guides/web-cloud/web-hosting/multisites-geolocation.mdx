## Obiettivo

I motori di ricerca (Google, Bing, Yahoo, ecc.) utilizzano robot di indicizzazione e posizionamento sull'insieme dei siti Web. Questi danno la priorità ai siti geolocalizzati nel Paese dal quale viene effettuata la ricerca.

**Esempio**: se effettui una ricerca tramite un motore di ricerca e ti trovi in Inghilterra, i siti Web geolocalizzati in Inghilterra compariranno più in alto nei risultati di ricerca rispetto agli altri siti Web.

Questa geolocalizzazione si basa sull'indirizzo IP dell'hosting su cui si trova il tuo sito Web.

L'opzione di geolocalizzazione sul tuo hosting può essere utile per il posizionamento (SEO) se il tuo sito Web è destinato a essere consultato principalmente in un Paese diverso da quello in cui si trova il tuo hosting condiviso.

**Scopri come geolocalizzare il tuo sito Web utilizzando i nostri indirizzi IP geolocalizzati.**

:::info
Questa procedura si applica alla <ManagerLink to="/beta/#/">console OVHcloud</ManagerLink>, attualmente disponibile in versione beta. Per seguirla, passa a questa interfaccia dal tuo Spazio Cliente abituale.

:::

## Prerequisiti

- Disporre di un [hosting condiviso OVHcloud](/links/web/hosting)
- Disporre di un [dominio](/links/web/domains)

## Procedura

Per i siti Web consultati principalmente dall'estero e ospitati sulla nostra infrastruttura di hosting condivisi OVHcloud, proponiamo un'opzione di geolocalizzazione tramite indirizzo IP. Questa permette di posizionare meglio i siti Web nel Paese in cui si trova l'indirizzo IP scelto con l'opzione.

Per utilizzare l'opzione di geolocalizzazione tramite IP, clicca sulle schede seguenti per visualizzare successivamente ciascuno dei **5** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, quindi seleziona l'hosting Web interessato.

    <img className="thumbnail" alt="Voce Hosting web del menu ed elenco degli hosting" src="/images/assets/screens/console/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella pagina visualizzata, clicca sulla scheda <code className="action">I miei siti</code>.

    <img className="thumbnail" alt="Scheda I miei siti di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella tabella visualizzata, clicca sul pulsante <code className="action">⋮</code> situato nella colonna <code className="action">Azioni</code>, a destra del sito Web interessato. Nella parte **Nomi di dominio** del menu, clicca su <code className="action">Gestisci</code>.

    <img className="thumbnail" alt="Menu Azioni di un sito Web nella console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Si apre il pannello <code className="action">Gestisci i miei domini</code>, che elenca i domini e i sottodomini associati a questo sito. Clicca sul pulsante <code className="action">⋮</code> situato a destra del dominio o sottodominio interessato, quindi su <code className="action">Gestisci le mie opzioni</code>.

    <img className="thumbnail" alt="Pannello Gestisci i miei domini e i suoi domini associati" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/associated-domains-options.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 5">
    Nel pannello <code className="action">Gestisci le opzioni</code>, seleziona <code className="action">IP del paese</code> per visualizzare il menu a tendina <code className="action">Scegli un paese</code>.

    <img className="thumbnail" alt="Opzione IP del paese e menu a tendina dei paesi disponibili" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/multisite/country-ip-selection.png" loading="lazy" />

    Scegli l'indirizzo IP del Paese in cui desideri geolocalizzare il tuo sito, tra i 13 Paesi proposti: *Belgio, Repubblica Ceca, Germania, Spagna, Finlandia, Francia, Irlanda, Italia, Lituania, Paesi Bassi, Polonia, Portogallo, Regno Unito*.

    Infine, clicca su <code className="action">Conferma</code>.

    :::warning
    L'opzione <code className="action">IP del paese</code> e l'opzione <code className="action">Attivare il CDN</code> appartengono alla stessa scelta **Prestazioni e distribuzione**: si escludono a vicenda. Selezionare <code className="action">IP del paese</code> disattiva il CDN su questo dominio.
    :::
  </Tab>
</Tabs>

:::info
Dopo aver effettuato i passaggi precedenti, se la zona DNS attiva del tuo dominio è interamente gestita nel tuo Spazio Cliente OVHcloud, il record di tipo A nella zona DNS del tuo dominio verrà modificato automaticamente. Verifica che l'indirizzo IP sia stato aggiornato correttamente utilizzando la nostra guida sulla [modifica di una zona DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit).

In caso contrario, sarà necessario effettuare la modifica manualmente presso il provider che gestisce la zona DNS attiva del tuo dominio. Consulta [qui](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip) la documentazione che raccoglie tutti gli indirizzi IP della nostra infrastruttura di hosting condivisi OVHcloud.

In entrambi i casi, sarà necessario un tempo di propagazione di **4-24 ore** dopo la modifica affinché questa sia pienamente effettiva e visibile su Internet.

:::
