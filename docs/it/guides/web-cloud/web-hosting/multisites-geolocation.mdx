## Obiettivo

I motori di ricerca (Google, Bing, Yahoo, ...) utilizzano robot di indicizzazione e referenziazione su tutti i siti Web. Indicano in via prioritaria i siti geolocalizzati nel paese dal quale effettui la tua ricerca.

**Esempio**: Se lanciate una ricerca attraverso un motore di ricerca e vi trovate in Inghilterra, i siti web geolocalizzati in Inghilterra appariranno più in alto nei risultati della ricerca rispetto agli altri siti web.

Questa geolocalizzazione è basata sull'indirizzo IP dell'hosting in cui si trova il tuo sito Web.

L'opzione di geolocalizzazione sul tuo hosting può essere utile per l'SEO se il tuo sito Web è principalmente consultato in un Paese diverso da quello in cui si trova il tuo hosting condiviso.

**Questa guida ti mostra come geolocalizzare il tuo sito Web utilizzando i nostri indirizzi IP geolocalizzati.**

:::info
Questa procedura si applica alla <ManagerLink to="/beta/#/">console OVHcloud</ManagerLink>, attualmente disponibile in versione beta. Per seguirla, passa a questa interfaccia dal tuo Spazio Cliente abituale.

:::

## Prerequisiti

- Disporre di un [hosting condiviso OVHcloud](/links/web/hosting)
- Disporre di un [dominio](/links/web/domains)

[[cpnav:web-hosting]]

## Procedura

Per i siti Web consultati principalmente all'estero e ospitati sulla nostra infrastruttura di hosting condivisi OVHcloud, proponiamo un'opzione di geolocalizzazione per indirizzo IP. Permette di indicizzare meglio i siti Web nel Paese in cui si trova l'indirizzo IP scelto con l'opzione.

Per utilizzare l'opzione di geolocalizzazione via IP, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **5** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella pagina visualizzata, clicca sulla scheda <code className="action">I miei siti</code>.

    <img className="thumbnail" alt="Scheda I miei siti di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella tabella che appare, clicca sul pulsante <code className="action">⋮</code> nella colonna **Azioni**, a destra del sito web interessato. Nella parte **Nomi di dominio** del menu, clicca su <code className="action">Gestisci i miei domini</code>.

    <img className="thumbnail" alt="Menu Azioni di un sito web nella console" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Il pannello <code className="action">Gestisci i miei domini</code> si apre ed elenca i nomi di dominio e i sottodomini associati a questo sito. Clicca sul pulsante <code className="action">⋮</code> a destra del nome di dominio o sottodominio interessato, poi su <code className="action">Gestisci le mie opzioni</code>.

    <img className="thumbnail" alt="Pannello Gestisci i miei domini e relativi nomi di dominio associati" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/associated-domains-options.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 5">
    Nel pannello <code className="action">Gestisci le opzioni</code>, seleziona <code className="action">IP del paese</code> per far apparire il menu a tendina <code className="action">Scegli un paese</code>.

    <img className="thumbnail" alt="Opzione IP del paese e menu a tendina dei paesi disponibili" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/country-ip-selection.png" loading="lazy" />

    Scegli l'indirizzo IP del Paese per il quale vuoi geolocalizzare il tuo sito, tra i 13 Paesi proposti: *Belgio, Finlandia, Francia, Germania, Irlanda, Italia, Lituania, Paesi Bassi, Polonia, Portogallo, Regno Unito, Repubblica Ceca, Spagna*.

    Infine, clicca su <code className="action">Conferma</code>.

    :::warning
    L'opzione <code className="action">IP del paese</code> e l'opzione <code className="action">Attivare il CDN</code> appartengono alla stessa scelta **Prestazioni e distribuzione**: si escludono a vicenda. Selezionare <code className="action">IP del paese</code> disattiva il CDN su questo nome di dominio.
    :::
  </Tab>
</Tabs>

:::info
Una volta completati gli step precedenti e se la zona DNS attiva del dominio è completamente gestita nel tuo <ManagerLink to="/">account OVHcloud</ManagerLink>, il record di tipo A nella zona DNS del dominio verrà modificato automaticamente. Per verificare che l'indirizzo IP sia stato aggiornato correttamente, consulta la guida su [modifica della zona DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit).

In caso contrario, sarà necessario effettuare la modifica manualmente presso il provider che gestisce la zona DNS attiva del dominio. Consulta [qui](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip) la documentazione che contiene tutti gli indirizzi IP della nostra infrastruttura di hosting condivisi OVHcloud.

In entrambi i casi, un periodo di propagazione da **4 a 24 ore** dopo la modifica sarà necessario per renderla pienamente efficace e visibile su Internet.

:::
