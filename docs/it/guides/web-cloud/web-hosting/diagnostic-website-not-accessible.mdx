Gli esempi seguenti indicano una configurazione errata dei tuoi [server DNS](/guides/web-cloud/domains/dns-server-edit), della tua [zona DNS](/guides/web-cloud/domains/dns-zone-edit) o di un dominio sospeso (se il tuo sito non visualizza uno dei messaggi di errore descritti qui, consulta la sezione [Per saperne di più](#go-further)):

## Prerequisiti

- Avere la gestione dei server e della [zona DNS](/guides/web-cloud/domains/dns-zone-edit) del dominio
- Essere aggiornato nei [pagamenti](/guides/account-and-service-management/managing-billing-payments-and-services/invoice-management#pay-bills) e [rinnovi](/guides/account-and-service-management/managing-billing-payments-and-services/automatic-renewal) dei servizi associati (dominio e hosting web)

[[cpnav:web-hosting]]

## Procedura

### 1 - Verifica la validità del tuo dominio

:::warning
Il rinnovo delle tue offerte è sotto la tua completa responsabilità.<br/>
OVHcloud, in qualità di hosting provider, ha l'obbligo di eliminare definitivamente i servizi (domini, hosting, email, ecc.) che non sono stati rinnovati in tempo utile e tutti i dati che contengono.

Per questo motivo, ti consigliamo di attivare il [rinnovo automatico](/guides/account-and-service-management/managing-billing-payments-and-services/automatic-renewal#procedura) su tutti gli abbonamenti OVHcloud.
:::

Per verificare la validità dell'abbonamento relativo al tuo dominio, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/customer/manage-services">Le mie offerte e servizi</ManagerLink>, poi individua il tuo dominio nella tabella.

    <img className="thumbnail" alt="Pagina Le mie offerte e servizi filtrata sui domini" src="/images/assets/screens/console/product-selection/account/manage-services-domains.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Rinnova il tuo dominio se necessario cliccando sul pulsante <code className="action">⋮</code> a destra della sua riga, poi su <code className="action">Rinnova il servizio</code>. Il rinnovo avviene in una nuova finestra.

    <img className="thumbnail" alt="Menu Azioni di un dominio in rinnovo manuale con Rinnova il servizio" src="/images/assets/screens/console/product-selection/account/manage-services-domain-actions.png" loading="lazy" />

    L'azione <code className="action">Rinnova il servizio</code> appare solo per un dominio in rinnovo manuale. Se il tuo dominio è in rinnovo automatico, il menu propone invece <code className="action">Anticipa il pagamento</code>.
  </Tab>
  <Tab label="Passaggio 3">
    Una volta terminato il rinnovo, il tuo sito web sarà disponibile entro 48 ore massimo.
  </Tab>
</Tabs>

### 2 - Verifica i server DNS

Per verificare la validità dei tuoi [server DNS](/guides/web-cloud/domains/dns-server-edit), accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi seleziona il dominio interessato.

**Clicca sullo scenario corrispondente alla tua situazione per visualizzare il contenuto.**

<details>
<summary>Scenario 1 - Nessuna anomalia sui server DNS</summary>

Per verificare i server DNS dichiarati, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi scegli il dominio interessato.

    <img className="thumbnail" alt="Pagina Domini e DNS ed elenco dei nomi di dominio dell'account" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Il dominio si apre sulla scheda <code className="action">Panoramica</code>. Verifica i server indicati nell'elenco **Server DNS che ospitano la zona** della sezione **Configurazione DNS**:

    <img className="thumbnail" alt="Scheda Configurazione DNS con la configurazione e l'elenco dei server DNS che ospitano la zona" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/dns-servers-ovhcloud.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Se sono identici ai target dei record di tipo `NS` nella scheda <code className="action">Zona DNS</code>, passa alla [parte 3](#step3). Per visualizzare solo questi record, clicca su <code className="action">Filtri</code> sopra la tabella, poi seleziona <code className="action">NS</code> nell'elenco **Tipo di record**:

    <img className="thumbnail" alt="Zona DNS filtrata sui record NS di un dominio" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-ns.png" loading="lazy" />
  </Tab>
</Tabs>

</details>

<details>
<summary>Scenario 2 - Sulla zona DNS compare un avviso</summary>

Sopra la zona DNS presente nella tua console OVHcloud, un avviso indica "**Questa zona DNS non è autoritativa per il tuo nome di dominio.**": i server DNS utilizzati dal tuo dominio non sono quelli indicati nella tua zona. Per sapere quali sono utilizzati, consulta l'elenco **Server DNS che ospitano la zona** nella sezione **Configurazione DNS** della scheda <code className="action">Panoramica</code> del dominio.

<img className="thumbnail" alt="Scheda Configurazione DNS con la configurazione e l'elenco dei server DNS che ospitano la zona" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/dns-servers-ovhcloud.png" loading="lazy" />

Sono possibili due casi:

- I server indicati sono del tipo "ns **?** .ovh.net" e "dns **?** .ovh.net" (sostituisci "**?**" da qualsiasi numero):

Modificare i server DNS seguendo le istruzioni di [questa guida](/guides/web-cloud/domains/dns-server-edit) in modo che siano identici agli obiettivi di record di tipo `NS` nella **Zona DNS**.

Il tuo sito web sarà disponibile entro 48 ore.

- I server indicati non sono del tipo "ns **?** .ovh.net" e "dns **?** .ovh.net" (la riga **Configurazione** della sezione indica allora **Personalizzata**):

:::warning
In questo caso, contatta l'hosting provider della tua Zona DNS, il tuo webmaster o i [partner OVHcloud](/links/partner) prima di effettuare qualsiasi operazione.

È possibile che i server DNS utilizzati dal tuo dominio siano funzionali e che il problema di accesso al tuo sito sia legato ad un ingresso mancante o errato nella [zona DNS](/guides/web-cloud/domains/dns-zone-general-information). Qualsiasi modifica dei server DNS in questa situazione può rendere indisponibili i tuoi indirizzi email o altre applicazioni online.
:::

It does not list the DNS servers in use, hence the pointer to the Overview « DNS servers » section. */}

</details>

<details>
<summary>Scenario 3 - Nella zona DNS non sono presenti record di tipo NS</summary>

La **Zona DNS** del tuo dominio non contiene record di tipo `NS`: l'elenco **Tipo di record** del pulsante <code className="action">Filtri</code>, che contiene solo i tipi presenti nella zona, non propone il tipo `NS`.

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, seleziona il dominio interessato, poi apri la scheda <code className="action">Zona DNS</code>.

  </Tab>
  <Tab label="Passaggio 2">
    Esegui un backup della zona attuale: apri il menu <code className="action">Altre azioni</code> della scheda **Zona DNS** e clicca su <code className="action">Modifica in modalità testuale</code>.

    Copia/incolla il contenuto della tua **Zona DNS** in un documento di testo. Salva questo documento localmente. Questo backup è essenziale: il ripristino dello step 3 ricrea i record di tipo `NS` mancanti, ma sostituisce tutti i record della zona. Ti permetterà poi di ricreare in modo identico i record di cui hai ancora bisogno (sottodomini, record `TXT`, `CNAME`, ecc.). Lo stesso menu propone anche <code className="action">Esporta la zona</code>, che salva direttamente la zona in un file.

    <img className="thumbnail" alt="Menu Altre azioni della scheda Zona DNS con Modifica in modalità testuale e Ripristina la zona" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Apri il menu <code className="action">Altre azioni</code> della scheda **Zona DNS** e clicca su <code className="action">Ripristina la zona</code>. Nel pannello **Ripristina la zona DNS**, seleziona **Valori personalizzati**.

    Indica i tuoi server di hosting (**Verso dove deve puntare il tuo nome di dominio?**) ed e-mail (**Verso quale server devono essere instradare le tue e-mail?**), poi clicca su <code className="action">Ripristina la zona</code>.

    <img className="thumbnail" alt="Pannello Ripristina la zona DNS con i valori personalizzati" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/reset-zone.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Il tuo sito web sarà disponibile entro 24 ore massimo.
  </Tab>
</Tabs>

</details>

### 3 - Verifica la zona DNS <a name="step3"></a>

In questo passaggio, visualizzerai l'indirizzo IP del tuo hosting e lo aggiungerai alla tua **Zona DNS**.

Se il tuo sito web non è ospitato sull'infrastruttura OVHcloud o se è gestito da un altro provider, contatta il supporto interessato.

Se il tuo sito web è ospitato su una delle nostre [soluzioni di hosting Web](/links/web/hosting), clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **2** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    L'hosting si apre sulla scheda <code className="action">Panoramica</code>. Nella sezione **Informazioni generali**, troverai le voci **IPv4** e **IPv6**.

    <img className="thumbnail" alt="Sezione Informazioni generali, indirizzi IPv4 e IPv6" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/ipv4-ipv6.png" loading="lazy" />

    Copia l'indirizzo IPv4 e/o IPv6 con il pulsante di copia situato a destra di ogni indirizzo.
  </Tab>
</Tabs>

E riportala nella [Zona DNS](/guides/web-cloud/domains/dns-zone-edit) del tuo dominio, modificandola o creando uno o più record di tipo `A`. Per visualizzare i record esistenti, clicca su <code className="action">Filtri</code> nella scheda <code className="action">Zona DNS</code>, poi seleziona <code className="action">A</code> nell'elenco **Tipo di record**.

<img className="thumbnail" alt="Pulsante Filtri ed elenco Tipo di record della zona DNS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-type.png" loading="lazy" />

Il tuo sito web sarà disponibile entro 24 ore massimo.
