## Obiettivo

È possibile ospitare più siti web su uno stesso piano di hosting web, anche se i domini non sono registrati presso OVHcloud. Inoltre, è possibile associare uno o più domini o sottodomini a uno stesso sito web.

Utilizzando i tuoi servizi, potresti aver bisogno di:

- Sostituire l'intero contenuto di un sito web esistente, senza rimuoverlo dal tuo hosting web. Il tutto senza interruzione dell'accesso e in totale trasparenza per i visitatori del tuo sito web.
- Installare un [modulo in 1 clic](/guides/web-cloud/web-hosting/cms-install-1-click-modules) o un [altro CMS](/guides/web-cloud/web-hosting/cms-manual-installation) per sostituire il contenuto di un sito web esistente, senza eliminare il vecchio contenuto dal tuo hosting web. In questo caso specifico, dovrai poi costruire le diverse pagine del tuo nuovo sito web tramite il tuo browser Internet.
- Riorganizzare i nomi delle cartelle root dei tuoi siti web nello spazio di storage del tuo hosting web senza interrompere l'accesso ai tuoi diversi siti web.

**Scopri come modificare la cartella root dichiarata per un sito web già esistente sul tuo hosting web dalla console OVHcloud.**

:::info
Se non hai ancora creato il sito web interessato sul tuo hosting web, consulta **direttamente** [questa guida](/guides/web-cloud/web-hosting/multisites-configure-multisite).

La console permette di modificare la cartella radice di un sito web, anche quando è associato a un repository Git (in questo caso, consulta la nostra guida "[Configurare e utilizzare Git con un hosting Web OVHcloud](/guides/web-cloud/web-hosting/git-integration-webhosting)"). Solo il sito che porta il dominio principale del tuo hosting Web non può cambiarla: il campo è allora disattivato.

:::

## Prerequisiti

- Disporre di un piano di [hosting Web OVHcloud](https://www.ovhcloud.com/it/web-hosting/uc-multisite/) compatibile.
- Disporre di uno o più [domini](https://www.ovhcloud.com/it/domains/).

## Procedura

:::warning
Questa guida descrive esclusivamente le operazioni da eseguire dalla <ManagerLink to="/beta/#/">console OVHcloud</ManagerLink>.

Ad eccezione del caso in cui si desideri installare un modulo in 1 clic per costruire il sito web progressivamente, sarà necessario preliminarmente:

- Creare la nuova cartella root nello [spazio di storage](/guides/web-cloud/web-hosting/ftp-connection) del tuo hosting web.
- Inserire l'intero nuovo contenuto del tuo sito web all'interno di questa nuova cartella.
- Se il nuovo contenuto del tuo sito web funziona con un database, sarà necessario anche [creare un database](/guides/web-cloud/web-hosting/sql-create-database), e poi [importare il contenuto relativo a questo database](/guides/web-cloud/web-hosting/sql-importing-mysql-database).
- Inserire le credenziali di accesso al database nel file contenente le informazioni di connessione al database. Questo file deve essere già presente nella nuova cartella root.

**Senza queste operazioni, la visualizzazione del tuo sito web verrà interrotta**.

Questa guida descrive unicamente la procedura per modificare, dalla console OVHcloud, la cartella root inizialmente definita per il tuo sito web. Questa azione è necessaria affinché il sito web mostri il contenuto della nuova cartella, in sostituzione della precedente.

:::

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">I miei siti</code>. Nella tabella, clicca sul pulsante <code className="action">⋮</code> nella colonna **Azioni**, a destra del sito web interessato, poi, nel gruppo **Sito**, su <code className="action">Configura il mio sito</code>.

    <img className="thumbnail" alt="Menu Azioni di un sito web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Il pannello **Configura il mio sito** si apre a destra. Nel campo **Cartella radice**, sostituisci la vecchia cartella radice con quella nuova.

    <img className="thumbnail" alt="Pannello Configura il mio sito, campi Nome del sito e Cartella radice" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/configure-site.png" loading="lazy" />

    :::info
    Il pannello permette anche di rinominare il tuo sito web, nel campo **Nome del sito**. Questo nome serve solo a identificare il sito nella console OVHcloud e non ha alcun effetto sul suo indirizzo né sul suo contenuto. Lascialo invariato se vuoi modificare solo la cartella radice.
    :::

    Infine, clicca su <code className="action">Conferma</code>, in fondo al pannello. Se hai cambiato cartella, la finestra **Modifica la cartella radice** riepiloga la cartella attuale, la nuova cartella e i domini collegati: clicca di nuovo su <code className="action">Conferma</code>.
  </Tab>
</Tabs>
