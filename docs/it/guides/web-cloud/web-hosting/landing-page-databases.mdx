## Gestire i database del tuo Hosting Web

Crea, amministra ed esegui il backup dei database del tuo Hosting Web OVHcloud. Questa pagina riunisce le guide per gestire i tuoi database, eseguire il backup, importare e ripristinare i loro dati e risolvere gli errori più frequenti.

Per orientarti in base alla tua esigenza:

- **Vuoi creare o configurare un database?** Consulta la sezione *Gestire un database* (creare, password, duplicare).
- **Vuoi eseguire il backup o ripristinare i tuoi dati?** Consulta la sezione *Backup e ripristino* (recuperare, importare, ripristinare).
- **Riscontri un errore del database?** Consulta la sezione *Risoluzione dei problemi* (errori comuni, database saturo).
