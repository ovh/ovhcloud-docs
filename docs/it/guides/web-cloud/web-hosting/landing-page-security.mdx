## Proteggere il tuo Hosting Web

Proteggi il tuo sito web e i suoi visitatori: attiva la cifratura HTTPS con un certificato SSL, configura un firewall applicativo e applica le best practice di sicurezza sul tuo Hosting Web OVHcloud. Questa pagina riunisce tutte le guide per proteggere il tuo sito web.

Per orientarti in base alla tua esigenza:

- **Vuoi proteggere il tuo sito web e i suoi visitatori?** Consulta la sezione *Proteggere il tuo sito web* (best practice, firewall applicativo).
- **Vuoi gestire un certificato o passare a HTTPS?** Consulta la sezione *Certificato SSL e HTTPS*.
- **Cerchi un certificato SSL adatto alle tue esigenze?** Consulta la sezione *Attivare un certificato SSL* (Let's Encrypt gratuito, Sectigo DV/EV, certificato personalizzato).

## Attivare un certificato SSL

Scegli il tipo di certificato adatto al tuo sito web, poi segui la guida corrispondente.

<Tabs>
  <Tab label="Let's Encrypt (gratuito)">

Certificato SSL gratuito disponibile con il tuo Hosting Web.

[Attivare un certificato SSL gratuito Let's Encrypt](/guides/web-cloud/web-hosting/ssl-letsencrypt)

  </Tab>
  <Tab label="Sectigo DV">

Certificato Sectigo con validazione del dominio (Domain Validation), valido per un nome a dominio e il suo sottodominio "www".

[Attivare un certificato SSL Sectigo DV](/guides/web-cloud/web-hosting/ssl-dv)

  </Tab>
  <Tab label="Sectigo EV">

Certificato Sectigo con validazione estesa (Extended Validation), valido per un nome a dominio e il suo sottodominio "www".

[Attivare un certificato SSL Sectigo EV](/guides/web-cloud/web-hosting/ssl-ev)

  </Tab>
  <Tab label="Personalizzato">

Per importare il tuo certificato SSL quando nessuna delle soluzioni OVHcloud corrisponde alle tue esigenze.

[Installare un certificato SSL personalizzato](/guides/web-cloud/web-hosting/ssl-custom)

  </Tab>
</Tabs>
