## Installare un CMS sul tuo Hosting Web

Un CMS (Content Management System, o sistema di gestione dei contenuti) è un software che consente di creare e gestire un sito web senza programmare, da un'interfaccia di amministrazione.

Installa il CMS che preferisci sul tuo Hosting Web OVHcloud. Questa pagina riunisce le guide di installazione manuale dei principali CMS (WordPress, Joomla, PrestaShop, Drupal e altri), o l'installazione di un modulo in 1 click direttamente dal tuo Spazio Cliente OVHcloud.

Per orientarti in base alla tua esigenza:

- **Stai pensando di installare un CMS per il tuo sito web?** Consulta la sezione *Come installare un CMS*.
- **Vuoi installare uno dei CMS più diffusi (WordPress, Joomla, PrestaShop, Drupal)?** Consulta la sezione *I CMS più diffusi*.
- **Cerchi di installare un altro CMS (Grav, Pico, Typo3, SPIP)?** Consulta la sezione *Altri CMS*.
