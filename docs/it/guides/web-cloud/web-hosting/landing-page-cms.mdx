## Gestire un CMS in 1 click sul tuo Hosting Web

Un CMS (Content Management System, o sistema di gestione dei contenuti) è un software che consente di creare e gestire un sito web senza programmare, da un'interfaccia di amministrazione. Un modulo in 1 click installa e preconfigura automaticamente un CMS (WordPress, PrestaShop, Joomla, ecc.) sul tuo Hosting Web OVHcloud, direttamente dal tuo Spazio Cliente e senza installazione manuale.

Questa pagina riunisce le guide per installare e gestire un modulo in 1 click, cambiare la password amministratore e proteggere l'accesso al tuo CMS.

Per orientarti in base alla tua esigenza:

- **Vuoi installare o gestire un CMS in 1 click?** Consulta la sezione *Modulo in 1 click*.
- **Devi amministrare o proteggere il tuo CMS (password, accesso all'area di amministrazione)?** Consulta la sezione *Amministrare e proteggere un CMS*.

L'installazione in 1 click non copre tutti i CMS. Puoi anche installare manualmente il CMS che preferisci (WordPress, Joomla, PrestaShop, Drupal e altri) sul tuo Hosting Web.
