## Obiettivo

Questa guida ti mostra come esportare tutti gli elementi del tuo sito Web in formato standard, da un [hosting Web OVHcloud](/links/web/hosting).

**Questa guida ti mostra come esportare il tuo sito Web OVHcloud.**

## Prerequisiti

- Disporre di una [soluzione di hosting Web OVHcloud](/links/web/hosting)

[[cpnav:web-hosting]]

## Procedura

### 1 - Recupero dei file del tuo spazio di storage FTP

#### 1.1 Accedere allo spazio di storage.

Per accedere allo spazio di storage sono necessari:

- utente FTP o SSH attivo.
- la password associata a questo utente FTP o SSH.
- l'indirizzo del server.
- porta di connessione al server

Questi dati sono indicati nell'email di conferma dell'installazione del tuo hosting ma.

Se non ne hai ancora uno, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Scheda FTP-SSH di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Visualizzi le informazioni associate allo spazio di storage. La sezione **Trasferimento di file (FTP/SFTP)** riunisce gli elementi necessari per accedervi:

    - **Host**: l'indirizzo del server;
    - **Nome utente**: l'identificativo dell'account principale;
    - **Metodo di connessione ai file**: la porta di connessione, **22** per l'SFTP o **21** per l'FTP.

    <img className="thumbnail" alt="Sezioni Trasferimento di file e Accesso SSH e tabella degli utenti" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/tab-pro.png" loading="lazy" />

    Gli altri utenti creati sul tuo hosting Web sono elencati nella sezione **Utenti FTP e SSH**.

    In caso di necessità, consulta la guida [Accedere allo spazio di storage di un hosting Web](/guides/web-cloud/web-hosting/ftp-connection).

    La password non è visualizzata nella console OVHcloud. Se l'hai smarrita, segui la procedura descritta nella guida [Modificare la password di un utente FTP](/guides/web-cloud/web-hosting/ftp-change-password).
  </Tab>
</Tabs>

Una volta recuperati tutti gli elementi, il recupero dei tuoi file sullo spazio di storage può essere effettuato in due modi diversi:

- **Utilizzare un software compatibile con il protocollo FTP o SFTP**: dovrai installare sul tuo computer un software compatibile, come [FileZilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide). Se hai bisogno di aiuto per utilizzarlo, contatta il produttore del software installato:

- **Accesso SSH**: questa opzione prevede l'utilizzo di comandi da un terminale per interagire con lo spazio di storage. Per utilizzare questo tipo di accesso sono necessarie conoscenze avanzate e un'[offerta di hosting Web OVHcloud](/links/web/hosting) specifica. Per maggiori informazioni, consulta la guida ["Utilizzare l'accesso SSH di un hosting Web"](/guides/web-cloud/web-hosting/ssh-on-webhosting). 

#### 1.2 Scarica i file dal tuo spazio di storage.

Una volta connesso al tuo spazio di archiviazione e in base ai siti web ospitati su di esso, potranno apparire diverse cartelle.

Se necessario, individua in precedenza nel tuo hosting web il nome della cartella radice in cui è conservato il tuo sito web. A tale scopo, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">I miei siti</code>.

    <img className="thumbnail" alt="Scheda I miei siti di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella tabella, individua la riga del tuo sito web grazie alla colonna **Sito**, poi leggi la sua colonna **Cartella radice**. Si tratta della directory in cui si trovano i file e le cartelle del tuo sito.

    <img className="thumbnail" alt="Tabella dei siti e colonna Cartella radice" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/root-folders.png" loading="lazy" />
  </Tab>
</Tabs>

Ancora connesso al tuo spazio di archiviazione, ti rimane solo da scaricare i file del tuo sito web accedendo alla cartella radice precedentemente identificata.

### 2 - Recuperare il backup del tuo database (facoltativo)

:::info
Se il tuo sito Web non utilizza un database, questo step è facoltativo.

:::

Per recuperare un backup del tuo database, consulta la nostra guida:
[Recuperare il backup del database di un hosting Web](/guides/web-cloud/web-hosting/sql-database-export).

Se utilizzi un database **Web Cloud Databases** per il tuo sito Web, consulta la sezione dedicata al backup della nostra guida:
[Salvare ed esportare un database sul tuo server di database](/guides/web-cloud/databases/db-backup-export-database-server).

### 3 - Recuperare i log del tuo hosting OVHcloud

Consulta la nostra guida dedicata: [Hosting Web - Consultare le statistiche e i log di un sito web](/guides/web-cloud/web-hosting/logs-and-statistics).
