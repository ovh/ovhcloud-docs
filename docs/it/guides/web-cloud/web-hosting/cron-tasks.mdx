## Obiettivo

Sull'hosting web OVHcloud è possibile utilizzare script per automatizzare alcune operazioni. Un task pianificato ("task CRON") permette ai tuoi script di eseguirsi in momenti specifici senza che tu debba effettuare altre azioni.

**Questa guida ti mostra come creare task CRON per automatizzare le operazioni pianificate su un hosting web.**

[[fragment:support-scope]]

## Prerequisiti

- Disporre di una soluzione di [hosting web](/links/web/hosting) attiva

[[cpnav:web-hosting]]

## Procedura

### Crea un task automatizzato

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Cron</code>.

    <img className="thumbnail" alt="Scheda Cron di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Visualizzi i tuoi task pianificati e i loro parametri: ogni task è presentato sotto forma di riquadro che indica il comando, lo **Stato**, la **Frequenza**, il **Linguaggio** e l'**E-mail** di report.

    Per creare un task CRON, clicca sul pulsante <code className="action">Crea un'attività</code>.

    <img className="thumbnail" alt="Riquadri dei task pianificati e pulsante Crea un'attività" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/tasks.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Personalizza le impostazioni del task nel pannello **Crea un'attività cron** che si apre.

    <img className="thumbnail" alt="Pannello Crea un'attività cron in modalità Semplice" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/create-task.png" loading="lazy" />

    |Opzione|Descrizione|
    |---|---|
    |Comando|Definisci il percorso per accedere al file che contiene il tuo script, relativo alla root del tuo hosting. Esempio: www/jobs/cron.php|
    |Frequenza|Definisci la frequenza di esecuzione del task (vedi sotto).|
    |Lingua|Seleziona la versione PHP utilizzata dallo script.|
    |Descrizione|Inserisci una descrizione per seguire l'esecuzione dei tuoi compiti.|
    |E-mail di report|Se necessario, indica l'indirizzo email al quale verrà inviato un report in caso di errore di esecuzione.|

    Il task viene attivato al momento della creazione. Se non vuoi che venga eseguito subito, disattivalo in seguito (vedi la sezione [Modificare o eliminare un'operazione pianificata](#modificare-o-eliminare-unoperazione-pianificata)).

    Per la **Frequenza**, l'interfaccia offre due modalità:

    - **Semplice**: scegli una frequenza predefinita nell'elenco (ogni ora, ogni giorno a mezzanotte o a mezzogiorno, ogni lunedì a mezzanotte, il 1° di ogni mese a mezzanotte).
    - **Avanzato**: inserisci un'espressione come in un *crontab*, le cui posizioni corrispondono, nell'ordine, a **Min**, **Ora**, **Giorno**, **Mese** e **Giorno sett.**. L'interfaccia traduce l'espressione in chiaro sopra il campo e ricorda il ruolo dei caratteri `*` (qualsiasi valore), `,` (separatore di elenco), `-` (intervallo di valori) e `/` (passo). Ad esempio, `0 * * * *` esegue il task **una volta all'ora tutti i giorni**, al minuto 0.

    <img className="thumbnail" alt="Frequenza in modalità Avanzato con l'espressione cron e la sua traduzione" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/cron/create-task-advanced.png" loading="lazy" />

    :::info
    La posizione **Giorno** permette di definire le frequenze di esecuzione su un ciclo mensile.

    La posizione **Giorno sett.** permette di definire frequenze di esecuzione complementari ma su un ciclo settimanale.
    :::

    Durante la configurazione è possibile passare da una modalità all'altra. Annota anche i [limiti durante la pianificazione di un'operazione su un hosting web](#limitazioni-delle-attività-pianificate-sul-tuo-hosting-web).

    Se tutto è corretto, clicca su <code className="action">Crea</code>.

    L'operazione sarà pronta tra pochi minuti. Potrai quindi modificare tutte le impostazioni o eliminare l'operazione con il pulsante <code className="action">⋮</code> in alto a destra del suo riquadro.
  </Tab>
</Tabs>

### Limitazioni delle attività pianificate sul tuo hosting web

|Funzionalità|Descrizione|
|---|---|
|Pianificazione oraria|I minuti vengono ignorati dall'hosting: un'operazione può essere eseguita solo una volta all'ora, con la frequenza di ripetizione più bassa che può essere specificata. In modalità **Avanzato**, indica un minuto fisso (ad esempio `0`): in caso contrario, l'interfaccia te lo segnala.|
|Durata|La durata di esecuzione di un'operazione è di 60 minuti. Se uno script supera il tempo di esecuzione, viene automaticamente arrestato dal sistema.|
|Variabile|Puoi definire solo delle variabili in uno script. Aggiungere all'URL che chiama lo script non funzionerà (esempio: www/jobs/cron.php?variabili=value).|
|Limite di dati|Un task può generare solo 5 MB di dati (*stdin/stderr*). Ad esempio, se uno script scrive dati in un file .txt, l'esecuzione si interrompe automaticamente quando il file raggiunge 5 MB.|
|Script che producono errori|Se uno script è difettoso, verrà automaticamente disattivato dopo 10 tentativi di esecuzione non andati a buon fine. La segnalazione degli errori verrà inviata solo quando tutti e 10 i tentativi avranno avuto esito negativo.<br/>Correggi lo script in base alla segnalazione degli errori ricevuta e riattiva il "task CRON" dalla scheda <code className="action">Cron</code> (clicca su <code className="action">⋮</code> nel riquadro del task, poi su <code className="action">Abilita</code>).|
|Relazioni di attuazione|I rapporti saranno inviati all'indirizzo elettronico selezionato una volta al giorno (durante le ore notturne).|

### Intervento tecnico

#### Test del vostro script con un browser web

Un semplice test per verificare se il tuo script produce un errore è eseguirlo su un browser web. Ad esempio, se il percorso di accesso del vostro script è "www/cron.php" e il vostro dominio di hosting è "mypersonaldomain.ovh", dovrete utilizzare l'URL "http://<i></i>mypersonaldomain.ovh/cron.php". Se non si verificano errori ma lo script non funziona come previsto, segui i suggerimenti qui sotto.

#### Verifica dell'utilizzo dei percorsi assoluti

Ti consigliamo di utilizzare percorsi di accesso assoluti ai file dei tuoi script. La costante "DIR", ad esempio, può aiutare a ricevere il percorso corrente negli script PHP ([documentazione PHP](https://www.php.net/manual/en/language.constants.predefined.php)).

#### Verifica dei log di esecuzione

Nei log del tuo hosting web, accessibili dalla <ManagerLink to="/beta/#/">console OVHcloud</ManagerLink>, visualizzerai la categoria di log intitolata "CRON".

Consulta la nostra guida ["Consulta le statistiche e i log del tuo sito su un'offerta condivisa"](/guides/web-cloud/web-hosting/logs-and-statistics) per maggiori dettagli.
