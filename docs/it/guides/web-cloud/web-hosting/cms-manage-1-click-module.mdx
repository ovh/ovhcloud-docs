## Obiettivo

I moduli in 1 click permettono di installare facilmente e rapidamente un software online di supporto alla creazione di siti Internet (comunemente chiamato "CMS"). OVHcloud ti propone i più conosciuti: WordPress, PrestaShop, Drupal e Joomla!.

**Questa guida ti mostra come gestire il tuo modulo in 1 click dalla console OVHcloud.**

[[fragment:support-scope]]

## Prerequisiti

<Region zones={['eu']}>
- Disporre di un'[offerta di hosting Web Cloud](/links/web/hosting) che consenta l'installazione di un modulo in 1 click (solo l'[offerta di hosting gratuito](/guides/web-cloud/web-hosting/activate-start10m) non è interessata)
</Region>
<Region zones={['ca', 'apac']}>
- Disporre di un'[offerta di hosting Web Cloud](/links/web/hosting) che consenta l'installazione di un modulo in 1 click
</Region>
- Aver creato un modulo in 1 click sul tuo hosting (Se non l'hai ancora installato, segui la nostra guida "[Installare il tuo sito Web con un CMS in 1 click](/guides/web-cloud/web-hosting/cms-install-1-click-modules)").

[[cpnav:web-hosting-console]]

## Procedura

### Accedi al tuo sito

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Moduli</code>. Vi sono visualizzati i moduli installati, ciascuno in un riquadro con il suo nome.

    <img className="thumbnail" alt="Scheda Moduli di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nel riquadro del tuo modulo, clicca sul link visualizzato sotto **URL**: il tuo sito si apre in una nuova scheda del browser.

    Puoi anche visualizzare i moduli sotto forma di tabella, con il pulsante a destra del campo di ricerca. Clicca allora sul pulsante <code className="action">⋮</code> della colonna **Azioni**, a destra della riga del tuo modulo, poi su <code className="action">Apri sito</code>.

    <img className="thumbnail" alt="Visualizzazione in tabella dei moduli e menu di una riga" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/row-actions-menu.png" loading="lazy" />
  </Tab>
</Tabs>

:::info

:::

### Modifica la password del tuo modulo <a name="password-change"></a>

Puoi far generare una nuova password amministratore per il tuo modulo dalla console OVHcloud. Clicca sulle schede seguenti per visualizzare uno alla volta i **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Moduli</code>.

    <img className="thumbnail" alt="Scheda Moduli di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Clicca sul pulsante <code className="action">⋮</code> a destra del nome del tuo modulo, poi su <code className="action">Cambia password</code>.

    <img className="thumbnail" alt="Menu delle azioni di un modulo installato nella scheda Moduli" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/card-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Si apre la finestra **Rigenera password**, che ricorda il modulo interessato. Clicca su <code className="action">Rigenera</code>: viene generata automaticamente una nuova password, che ti viene inviata via email.
  </Tab>
</Tabs>

Per definire tu stesso una nuova password, utilizza l'interfaccia di amministrazione del tuo CMS.

:::info
Consulta la documentazione ufficiale dei diversi CMS disponibili sull'hosting condiviso:

- WordPress: [https://wordpress.org/support/article/resetting-your-password/](https://wordpress.org/support/article/resetting-your-password/)
- Joomla!: [https://docs.joomla.org/How_do_you_recover_or_reset_your_admin_password%3F](https://docs.joomla.org/How_do_you_recover_or_reset_your_admin_password%3F)
- Drupal: L'editor di questo software non offre, alla data, la documentazione per modificare la password di accesso all'interfaccia di amministrazione di Drupal. Ti invitiamo a contattare direttamente l'editor su questo argomento. Per maggiori informazioni, consulta la pagina ufficiale [drupal.org](https://www.drupal.org/).
- PrestaShop: L'editor di questo software non offre, alla data, la documentazione necessaria per modificare la password di accesso all'interfaccia di amministrazione di PrestaShop. Ti invitiamo a contattare direttamente l'editor su questo argomento. Per maggiori informazioni, consulta la [pagina ufficiale di PrestaShop](https://www.prestashop.com).

:::

Puoi inoltre modificare la password di accesso all'interfaccia di gestione del tuo CMS direttamente dal tuo database.

Tuttavia, in caso di difficoltà o dubbi, ti consigliamo di eseguire l'operazione utilizzando la documentazione proposta dal tuo CMS o di rivolgerti a uno [specialista del settore](/links/partner). OVHcloud non potrà fornirti alcuna assistenza. Per maggiori informazioni consulta la sezione [Per saperne di più](#go-further) di questa guida.

### Elimina il tuo modulo

:::warning
Il backup dei tuoi dati è una delle operazioni principali per la [sicurezza dei tuoi siti](/guides/web-cloud/web-hosting/secure-your-website). Ti consigliamo di importare regolarmente e **prima di eliminare** il backup dei tuoi dati su un supporto locale, come una chiavetta USB o un hard disk esterno, seguendo le istruzioni della nostra guida "[Esporta il tuo sito Web](/guides/web-cloud/web-hosting/exporter-son-site-web)".

:::

#### 1 - Identifica il database associato al tuo modulo <a name="step1"></a>

Per eliminare il tuo modulo in 1 click, è necessario iniziare ad identificarne il database in modo **sicuro**.

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Database</code>.

    <img className="thumbnail" alt="Scheda Database di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Se disponi di un solo database in questa scheda e non disponi di soluzioni [Web Cloud Databases](/links/web/databases), puoi considerare che si tratta di quello del tuo sito.

    <img className="thumbnail" alt="Tabella dei database e relative colonne" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/tab-no-spotlight.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    In caso contrario, vai alla scheda <code className="action">I miei siti</code>. Annota il nome presente nella colonna **Cartella radice** sulla riga del sito web interessato: si tratta della directory in cui si trovano i file che costituiscono il tuo modulo in 1 click sul server FTP.

    <img className="thumbnail" alt="Tabella dei siti e colonna Cartella radice" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/root-folders.png" loading="lazy" />
  </Tab>
</Tabs>

Accedi allo [spazio FTP del tuo hosting](/guides/web-cloud/web-hosting/ftp-connection). Apri la `Cartella di root` trovata precedentemente nella scheda <code className="action">I miei siti</code> e cerca il file di configurazione del tuo modulo:

- Per WordPress: **"wp-config.php"** (il nome del database compare con la dicitura **"DB_NAME"**).
- Per Joomla!: **"configuration.php"** (il nome del database compare con la dicitura **"public $db"**).
- Per Drupal: **"settings.php"** (Per ritrovarlo, accedi alla cartella **"site"** e **"default"**. Il nome del database compare con la dicitura **"database"**).
- Per PrestaShop: **"parameters.php"** (Per ritrovarlo, accedi alla cartella **"app"** e **"config"**. Il nome del database del tuo modulo compare con la dicitura **"database_name"**).

#### 2 - Salvare il tuo modulo

Per effettuare il backup del tuo sito, segui le istruzioni della nostra guida "[Esporta il tuo sito Web](/guides/web-cloud/web-hosting/exporter-son-site-web)" per recuperare sia i file sullo spazio FTP del tuo hosting che i database.

#### 3 - Elimina il tuo modulo

:::danger
L'eliminazione del tuo modulo in 1 click e del suo database comporta anche la cancellazione di **tutti i backup**. I dati eliminati non potranno essere recuperati in seguito.

:::

Clicca sulle schede seguenti per visualizzare uno alla volta i **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Moduli</code>.

    <img className="thumbnail" alt="Scheda Moduli di un hosting Web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Clicca sul pulsante <code className="action">⋮</code> a destra del nome del tuo modulo, poi su <code className="action">Elimina</code>. Nella finestra **Elimina un modulo** che si apre, conferma l'eliminazione cliccando su <code className="action">Elimina</code>. Questa azione è irreversibile.

    <img className="thumbnail" alt="Finestra di conferma dell'eliminazione di un modulo" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/modules/delete-module-dialog.png" loading="lazy" />

    :::tip
    Non trovi l'azione <code className="action">Elimina</code>? O vuoi solo eliminare dei file sul tuo modulo?

    Consulta le nostre guide:

    - [Accedi allo spazio di storage FTP del tuo hosting Web](/guides/web-cloud/web-hosting/ftp-connection).

  </Tab>
</Tabs>

:::warning
L'eliminazione del modulo 1 click **non comporta automaticamente l'eliminazione del database**. Se avvii l'installazione di un nuovo CMS senza aver prima eliminato il database del precedente (e il tuo hosting non consente la creazione automatica di un nuovo database), il messaggio "[Si è verificato un errore durante il caricamento delle informazioni (You need at least one free database)](/guides/web-cloud/web-hosting/diagnostic-errors-module1clic#si-è-verificato-un-errore-durante-il-caricamento-delle-informazioni-you-need-at-least-one-free-database)" comparirà nella console OVHcloud.

Se hai già raggiunto il numero massimo di database consentito dal tuo [hosting Web](/links/web/hosting), dovrai eliminare il database identificato nella [parte 1](#step1) **PRIMA** di poter creare un nuovo modulo in 1 click.

:::

### Buone prassi

Rendi sicuro il tuo sito seguendo le istruzioni della nostra guida "[Come proteggere il tuo sito Web?](/guides/web-cloud/web-hosting/secure-your-website)".

Aggiungi strumenti di test del tipo CAPTCHA ai moduli del tuo sito.

Non installate sul vostro sito plugin o template che non sono stati consigliati dalle comunità ufficiali del vostro CMS: 

- [WordPress](https://wordpress.org/)
- [Joomla!](https://community.joomla.org/)
- [Drupal](https://www.drupal.org/community)
- [PrestaShop](https://www.prestashop.com/it)
