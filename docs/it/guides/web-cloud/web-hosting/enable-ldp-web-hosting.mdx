## Obiettivo

Un log è un evento verificatosi su un sistema informatico (server, computer, applicazione, sito web, database, rete informatica, ecc.).
Per esempio, un log può registrare e contenere uno o più dei seguenti elementi:

- La marca temporale (data, ora, minuto, secondo, ecc.) dell'evento.
- La natura dell'evento (connessione, disconnessione, errore, download, upload, avviso, ecc.).
- Informazioni aggiuntive sull'evento (pagina o file consultato, applicazione avviata, server remoto contattato, nome di un file caricato o scaricato, ecc.).
- L'origine dell'evento (identificativo dell'utente, indirizzo IP di origine, programma di origine, ecc.).
- Lo stato del sistema in cui si verifica l'evento (risorse disponibili, memoria rimanente, utilizzo della CPU, ecc.).

Nella maggior parte dei casi, i log sono generati direttamente dai sistemi informatici in cui si verificano gli eventi.
Vengono memorizzati e storicizzati in file di testo, chiamati anche file di log.

Per questo motivo, i file di log permettono di:

- Analizzare il comportamento del sistema informatico che genera i log.
- Identificare gli errori verificatisi sul sistema informatico.
- Risolvere gli errori riscontrati sul sistema informatico.
- Ottimizzare le prestazioni del sistema informatico.

La tua offerta di [hosting web](/links/web/hosting) genera quindi i propri log.

In alcune situazioni, potresti dover consultare o recuperare i log:

- del tuo hosting web;
- per uno dei siti web o una delle applicazioni presenti sul tuo hosting web.

**Scopri come attivare, visualizzare e gestire i log dei siti web o delle applicazioni presenti sul tuo hosting web.**

:::warning
Mettiamo a tua disposizione questa guida per aiutarti a svolgere al meglio le attività più comuni. ### Sottoscrivere i log della tua offerta di hosting web a Logs Data Platform <a name="webhosting-ldp"></a>

[Logs Data Platform](/links/manage-operate/ldp) è una piattaforma che permette di gestire i tuoi log. Può esserti utile se disponi di un'infrastruttura molto grande o se i tuoi servizi generano un'enorme quantità di log. Questa piattaforma è infatti concepita per facilitare l'aggregazione e la gestione dei log.

Funziona recuperando i log generati dalla tua infrastruttura, dai tuoi siti web o ancora dalle tue applicazioni per, ad esempio:

- memorizzarli;
- visualizzarli in dashboard in tempo reale;
- permettere agli utenti di effettuare query complesse;
- filtrarli per data, applicazione, tipo o contenuto;

Per maggiori dettagli su Logs Data Platform, consulta la nostra guida [Introduzione a Logs Data Platform](/guides/manage-and-operate/observability/logs-data-platform/introduction) (EN).

Poiché le offerte di [hosting web](/links/web/hosting) possono essere utilizzate con numerosi servizi (database, ecc.), puoi sottoscriverle tramite flusso di dati a Logs Data Platform, in aggiunta ai log in tempo reale già disponibili.

Con un account Logs Data Platform, disponi gratuitamente di **1 GB** di conservazione dei log. Per beneficiarne, devi [attivare gratuitamente il tuo account Logs Data Platform](/guides/manage-and-operate/observability/logs-data-platform/getting-started-quick-start) e sottoscrivere il tuo hosting web a un flusso di dati.

:::danger
In funzione di:

- I log generati dal tuo hosting web
- Il numero di hosting web sottoscritti al tuo account Logs Data Platform

l'**1 GB** di dati può essere consumato più o meno rapidamente.

In funzione dei tuoi utilizzi, questo consumo di dati può infatti rappresentare un volume di log che può andare da qualche giorno fino a qualche mese o addirittura anno.

Se desideri disporre di un volume superiore a **1 GB** per la conservazione dei tuoi log, puoi sottoscrivere un'offerta a pagamento complementare.
:::
