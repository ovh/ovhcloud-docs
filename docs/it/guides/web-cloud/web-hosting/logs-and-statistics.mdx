## Obiettivo

L'accesso ai log e alle statistiche del sito Web è incluso nella soluzione di hosting Web, accessibile dalla console OVHcloud.

**Questa guida ti mostra come consultare le statistiche e i log del tuo sito Web grazie alla tua soluzione di hosting Web.**

## Prerequisiti

- Disporre di un piano di [hosting Web](/links/web/hosting) attivo.

[[cpnav:web-hosting]]

### Statistiche delle visite <a name="website-stats"></a>

Per controllare e gestire al meglio il traffico dei siti Web, è possibile utilizzare **OVHcloud Web Statistics**, uno strumento di statistiche delle visite e di misurazione dell'audience dei siti Web ospitati sul piano di hosting.

<video className="thumbnail" autoPlay loop muted playsInline aria-label="ows dashboard" src="/images/assets/screens/other/web-tools/logs/ows-presentation.mp4" />

La dashboard di **OVHcloud Web Statistics** presenta 7 sezioni:

- **Dashboard**: visualizzazione del traffico sui siti del tuo hosting Web.
- **Browsers**: classifica dei browser Internet più utilizzati per consultare i tuoi siti.
- **Geolocalization**: percentuale di visitatori in base alla localizzazione.
- **Requests**: classifica delle pagine più consultate sui tuoi siti.
- **Robot**: visualizzazione dei robot che transitano sui vostri siti.
- **Status**: statistiche di fallimenti e successi in base ai codici HTTP restituiti.
- **FAQ**: sezione dedicata alle domande più frequenti. Vengono inoltre illustrati i termini tecnici che possono essere utilizzati nello strumento.

Il campo `Period selection` in alto a destra ti permette di selezionare un periodo preciso.

### Logs del sito web <a name="website-logs"></a>

:::info
Non saremo in grado di supportarti nell'interpretazione dei log del tuo hosting Web perché questa operazione riguarda esclusivamente lo sviluppo Web e non l'hosting Web.

In caso di difficoltà o dubbi, contatta il tuo [provider specializzato](/links/partner).
:::

Potrete visualizzare i log grezzi del vostro sito web con un ritardo di circa 5 minuti.

<img className="thumbnail" alt="osl statistiques dashboard" src="/images/assets/screens/other/web-tools/logs/osl-statistics-board.png" loading="lazy" />

Diversi tipi di log sono a tua disposizione:

- **Log Web**: contengono i diversi log di consultazione del sito Web, oltre alle diverse azioni realizzate a partire dal sito Web. Ciò consente, ad esempio, di individuare i tentativi di azioni dannose.
- **Log FTP**: le diverse connessioni / comandi in FTP saranno registrati e mantenuti in questi log.
- **Logs errore**: qui trovi i diversi errori generati dal tuo sito Web.
- **Logs CGI**: le varie chiamate agli script cgi.bin che sono stati realizzati sono registrati in questi logs.
- **Logs out**: contengono la cronologia delle diverse richieste esterne (connessioni in uscita TCP) realizzate dal tuo hosting Web verso infrastrutture remote.
- **Log SSH**: questi log indicano le diverse connessioni / comandi effettuati con il protocollo SSH.
- **Logs CRON**: visualizza qui i risultati dell'esecuzione delle operazioni pianificate [(CRON)](/guides/web-cloud/web-hosting/cron-tasks) sul tuo hosting Web.

:::tip
Per visualizzare le statistiche e/o i log della CDN, consulta la nostra guida dedicata: "[Hosting Web - Consulta le statistiche e i log della CDN](/guides/web-cloud/web-hosting/cdn-statistics-and-logs)".
:::

### Statistiche dell'infrastruttura <a name="infra-stats"></a>

In questa sezione sono riportate le attività dell'infrastruttura del tuo hosting Web, per visualizzare il consumo delle risorse messe a disposizione. Per farlo, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella pagina che appare, clicca sulla scheda <code className="action">Statistiche e log</code> e vai alla sezione **Statistiche infrastruttura**.
  </Tab>
  <Tab label="Passaggio 3">
    Dall'elenco in alto a sinistra della sezione è possibile visualizzare diversi tipi di grafici. Accanto, scegli il periodo visualizzato (**Giornaliero**, **Settimanale**, **Mensile** o **Annuale**). Il pulsante <code className="action">Esporta CSV</code> scarica i dati del grafico visualizzato.

    <img className="thumbnail" alt="Sezione Statistiche infrastruttura della scheda Statistiche e log" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/statistics-and-logs/infrastructure-statistics.png" loading="lazy" />

    - **Comandi FTP**: indica i comandi principali (upload, download, login, delete) effettuati utilizzando il protocollo FTP sul tuo hosting Web.
    - **Richieste HTTP**: numero e codice restituito delle richieste HTTP (2xx, 3xx, 4xx, 5xx).
    - **Tempo di risposta medio**: tempo di risposta medio delle richieste HTTP.
    - **Connessioni TCP in uscita**: richieste inviate dal tuo sito web verso un sito web esterno.
    - **Utilizzo CPU**: livello di consumo del processore sull'istanza di hosting Web.
    - **Sovraccarico worker**: indica i momenti in cui l'hosting Web supera le proprie risorse.

    Il numero di richieste SQL è presentato nella sezione **Statistiche database**, più in basso, per il database che scegli.
  </Tab>
</Tabs>

### Gestione degli utenti <a name="admin-user"></a>

La creazione di un utente consente a una persona di accedere alle statistiche del tuo hosting Web senza avere accesso al tuo account OVHcloud.

Per creare un nuovo utente, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella pagina che appare, clicca sulla scheda <code className="action">Statistiche e log</code> e poi, nella sezione **Accesso**, su <code className="action">Gestisci</code>. Il pannello **Statistiche — Accesso** si apre sulla destra.
  </Tab>
  <Tab label="Passaggio 3">
    Clicca su <code className="action">Aggiungi</code>.

    <img className="thumbnail" alt="Pannello Statistiche — Accesso con il pulsante Aggiungi" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/statistics-and-logs/users-panel.png" loading="lazy" />

    Inserisci un **Identificativo**, una **Descrizione** se lo desideri, poi una **Password** da confermare nel campo **Conferma**. La password deve contenere tra 9 e 30 caratteri, di cui una minuscola, una maiuscola e una cifra, e solo lettere e cifre. Clicca quindi su <code className="action">Crea</code>.

    <img className="thumbnail" alt="Modulo di creazione di un utente per le statistiche e i log" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/statistics-and-logs/add-user-form.png" loading="lazy" />
  </Tab>
</Tabs>

Per accedere alle statistiche del tuo sito Web con un utente che hai creato, inserisci questo indirizzo sostituendo `000` con il numero del cluster del tuo hosting Web e `domain.tld` con il nome di dominio del tuo sito Web (senza i `www`):

```bash
https://logs.cluster000.hosting.ovh.net/domain.tld/
```

Puoi anche recuperare il link di accesso alle statistiche / log direttamente dalla console OVHcloud. Per farlo, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella pagina che appare, clicca sulla scheda <code className="action">Statistiche e log</code> e vai alla sezione **Statistiche delle visite**.
  </Tab>
  <Tab label="Passaggio 3">
    Clicca sul link <code className="action">Visualizza statistiche</code>. Le statistiche si aprono in una nuova scheda del browser.

    :::info
    La pagina che si apre richiede l'identificativo e la password di un utente autorizzato ad accedere alle statistiche e ai log. Se non ne hai ancora uno, crealo seguendo la sezione "[Gestione degli utenti](#admin-user)" di questa guida.

    :::

    <img className="thumbnail" alt="Link Visualizza statistiche della sezione Statistiche di visita" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/statistics-and-logs/view-statistics.png" loading="lazy" />

    Nella nuova pagina, recupera l'URL che trovi nella barra degli indirizzi del tuo browser.
  </Tab>
</Tabs>

:::warning
Se i log separati sono stati abilitati su una [voce multisito](/guides/web-cloud/web-hosting/multisites-configure-multisite), gli utenti creati qui non potranno accedere alle statistiche relative a tale voce multisito specifica.
:::
