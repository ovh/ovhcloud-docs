## WordPress sul tuo Hosting Web

Crea, gestisci e proteggi i tuoi siti WordPress sul tuo Hosting Web OVHcloud. Questa pagina riunisce le guide per installare e iniziare con WordPress, utilizzarlo ogni giorno (WooCommerce, file .htaccess, backup) e gestire più siti WordPress con il plugin MainWP.

Per orientarti in base alla tua esigenza:

- **Hai appena scoperto WordPress?** Consulta la sezione *Installare e iniziare con WordPress* (primi passi, modulo in 1 click, installazione manuale, migrazione).
- **Il tuo sito WordPress è già online?** Consulta la sezione *Utilizzare e gestire WordPress* (WooCommerce, .htaccess, password amministratore, backup).
- **Amministri diversi siti WordPress?** Consulta la sezione *Gestire più siti con MainWP* (amministrazione, backup, sicurezza, clienti).
