## Configurare il tuo Hosting Web

Configura tutti gli aspetti del tuo Hosting Web OVHcloud: ospita più siti web, gestisci l'ambiente e la versione PHP, attiva gli indirizzi email inclusi, ottimizza le performance e il CDN, monitora i log, esegui il deployment (Git, CRON, API) e fai evolvere la tua offerta. I database, l'accesso FTP/SSH, i CMS e la sicurezza dispongono inoltre di una propria pagina dedicata.

Per orientarti in base alla tua esigenza:

- **Vuoi configurare i tuoi siti web, associare i tuoi nomi a dominio o predisporre l'ambiente (PHP, IPv6)?** Consulta la sezione *Siti web, nome a dominio e ambiente*.
- **Vuoi migliorare le performance dei tuoi servizi o monitorare i log (CDN, statistiche)?** Consulta la sezione *Performance, CDN e log*.
- **Devi eseguire il deployment, automatizzare (Git, CRON, API) o far evolvere la tua offerta?** Consulta la sezione *Deployment, automazione e offerta*.
