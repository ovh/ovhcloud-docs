## Obiettivo

Il tuo hosting Cloud Web dispone di uno spazio di storage in cui puoi ospitare siti e applicazioni.

**Questa guida ti mostra come recuperare un backup dello spazio FTP del tuo hosting Cloud Web**.

:::info
I backup proposti da OVHcloud per gli hosting Cloud Web sono non contrattuali. disponibili per completare i tuoi servizi di backup in caso di emergenze. Per evitare eventuali perdite di dati, ti consigliamo di effettuare regolarmente i tuoi backup di sicurezza.

Quando effettui un backup di sicurezza per il tuo sito e utilizzi un database, fai anche un backup di quest'ultimo. Per [recuperare un backup del tuo database](/guides/web-cloud/web-hosting/sql-database-export), consulta la nostra guida.
:::

**Questa guida ti mostra come recuperare e ripristinare un backup FTP del tuo hosting Cloud Web.**

- Disporre di un [hosting Cloud Web](https://www.ovhcloud.com/it/web-hosting/cloud-web-offer/)
- Avere accesso all'indirizzo email di contatto associato al tuo identificativo cliente

## Procedura

Un hosting Cloud Web dispone di backup automatici attivati alle seguenti frequenze:

- il giorno stesso, effettuato dopo le 00:00.
- il giorno precedente, effettuato dopo le 00:00.
- la due giorni prima, effettuata dopo le 00:00.
- la domenica precedente, effettuata dopo le 01.00.

OVHcloud può offrire solo i backup indicati, a condizione che il tuo hosting Cloud Web esista già alle date indicate e con riserva della disponibilità dell'infrastruttura al momento della richiesta del backup.

### Recupera un backup

Diversamente dagli hosting condivisi OVHcloud, il ripristino dello spazio FTP non può essere effettuato con un clic dallo <ManagerLink to="/">Spazio Cliente OVHcloud</ManagerLink>.

Viene generato un link per scaricare il backup e inviato via email all'indirizzo email associato all'identificativo cliente amministratore dell'hosting Cloud Web.

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **5** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/#/web/hosting">Hosting</ManagerLink> e seleziona il Cloud Web interessato.

    <img className="thumbnail" alt="Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Seleziona la scheda <code className="action">FTP - SSH</code> e clicca sul pulsante <code className="action">Genera un backup</code> a destra.

    <img className="thumbnail" alt="Pulsante Genera un backup" src="/images/assets/screens/control-panel/product-selection/web-cloud/cloud-web/ftp-ssh/generate-a-backup.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">

### Scaricare il backup

Una volta completata la generazione del backup, ricevi un'email all'indirizzo email associato all'identificativo amministratore del tuo hosting Cloud Web.

Questa email contiene un link di download **valido 9 giorni** a partire dalla ricezione dell'email:

<img className="thumbnail" alt="Email di download del backup" src="/images/assets/screens/email-sending-to-customer/cloud-web/backup-information.png" loading="lazy" />

Il file caricato è in formato *.tar.gz*.

### Ripristina il backup

Una volta scaricati i file, potrai [accedere al tuo spazio FTP](/guides/web-cloud/web-hosting/ftp-connection) utilizzando un software FTP come [Filezilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide) e sostituire i file che desideri con quelli recuperati.

:::info
Utilizza le porte indicate nello <ManagerLink to="/">Spazio Cliente OVHcloud</ManagerLink> per le connessioni SFTP e SSH perché la porta 22 non sarà funzionale per il tuo hosting Cloud Web.
:::
