## Obiettivo

L'utilizzo di software FTP durante la connessione al tuo [hosting Web Cloud](/links/web/hosting) può causare diverse anomalie. Questa guida ti mostra come risolvere il problema più comune.

**Questa guida ti mostra come risolvere gli errori associati ai software FTP.**

## Prerequisiti

- Disporre di una [soluzione di hosting Web Cloud](/links/web/hosting)

## Procedura

### "Questo server non supporta FTP su TLS" (FileZilla)

<img className="thumbnail" alt="doesnt-support-ftp-on-tls" src="/images/assets/screens/other/web-tools/filezilla/doesnt-support-ftp-on-tls.png" loading="lazy" />

Questo messaggio sul software [FileZilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide) indica che non hai attivato l'opzione SFTP o SSH dalla <ManagerLink to="/beta/#/">console OVHcloud</ManagerLink>. In questo modo, le informazioni scambiate tra il tuo server di hosting OVHcloud e il tuo computer non saranno cifrate.

Se i dati che vuoi scambiare tramite questo canale non sono riservati, clicca su <code className="action">OK</code>.

In caso contrario, accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink> della console OVHcloud e seleziona l'hosting interessato. Nella scheda <code className="action">FTP-SSH</code>, sezione **Utenti FTP e SSH**, modifica l'utente FTP interessato per attivargli il protocollo SFTP.

La procedura dettagliata, identica qualunque sia la tua offerta di hosting, è descritta nella nostra guida "[Web Hosting - Come attivare l'accesso SFTP](/guides/web-cloud/web-hosting/enable-sftp)". Attendi poi qualche minuto.

:::info
Per ulteriori messaggi di errore, consulta la sezione `Diagnostica` delle nostre guide [Hosting](/guides/web-cloud/web-hosting/landing-page-web-hosting).

:::

### Ho trasferito i miei file con un software FTP, ma il mio sito non appare.

Per prima cosa verifica che i file e le cartelle del tuo sito siano presenti nella [cartella root](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online#3-caricare-i-file) del tuo hosting.

Se hai effettuato una modifica nei tuoi [server DNS](/guides/web-cloud/domains/dns-server-edit) o nella tua [zona DNS](/guides/web-cloud/domains/dns-zone-edit) meno di 48 ore fa, attendi e riavvia regolarmente i tuoi dispositivi per svuotare la cache.

### Le credenziali FTP non funzionano

Se non riesci ad autenticarti, modifica la password FTP seguendo le indicazioni di questa [guida](/guides/web-cloud/web-hosting/ftp-change-password).

### Non riesco a trasferire i miei file verso il server FTP.

Verifica che il tuo client FTP sia collegato in "Modalità Passivo" (Modalità di configurazione di un server FTP in cui il server determina la porta di connessione).

Per esempio, per [Filezilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide), clicca su <code className="action">Modifica</code>, poi <code className="action">Impostazioni</code>, <code className="action">Connessione</code>, <code className="action">FTP</code> e seleziona <code className="action">Passiva (consigliata)</code>.

Limita anche la dimensione dei tuoi trasferimenti di dati (non puoi inviare più di **5.000 file e cartelle** sui server condivisi OVHcloud in un solo trasferimento). Effettua le tue importazioni in più volte, se necessario, utilizzando cartelle compresse.

Se disponi di una formula **Pro**, **Performance**, **Agency**, **Agency Plus** o **Agency Max**, utilizza preferibilmente il [protocollo SSH](/guides/web-cloud/web-hosting/ssh-on-webhosting) per effettuare l'importazione di file sullo spazio di archiviazione dei file del tuo hosting.

### Non riesco a eliminare il link simbolico "index.html" sul mio spazio FTP

Questo collegamento è installato di default sugli hosting condivisi OVHcloud. Dà questa visualizzazione:

<img className="thumbnail" alt="site-under-construction" src="/images/assets/screens/other/browsers/errors/site-under-construction.png" loading="lazy" />

Se non hai utilizzato la funzionalità "[Modulo in 1 click](/guides/web-cloud/web-hosting/cms-install-1-click-modules)" per creare il tuo sito, devi [accedere allo spazio di storage FTP](/guides/web-cloud/web-hosting/ftp-connection) del tuo hosting Web per eliminare manualmente la pagina "Sito in costruzione".
