## Obiettivo

Non ricordi più il nome della tua [offerta di hosting web](/links/web/hosting)?
Vuoi consultare i suoi dettagli o confrontarla con un'altra offerta?

Nell'utilizzo dei tuoi servizi, potresti aver bisogno del nome della tua offerta di hosting web.

**Questa guida ti mostra come identificare il tipo di offerta di hosting web che possiedi dalla console OVHcloud.**

## Prerequisiti

- Disporre di un'[offerta di hosting web](/links/web/hosting).

[[cpnav:web-hosting-console]]

## Procedura

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **2** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella scheda <code className="action">Panoramica</code>, individua la sezione **Abbonamento**. Il nome della tua offerta di hosting Web compare sotto la voce **Offerta** (ad esempio: Perso, Pro, Performance).

    <img className="thumbnail" alt="Sezione Abbonamento e nome dell'offerta sotto la voce Offerta" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/subscription-card.png" loading="lazy" />
  </Tab>
</Tabs>
