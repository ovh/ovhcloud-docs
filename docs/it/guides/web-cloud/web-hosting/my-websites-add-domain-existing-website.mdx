## Obiettivo

Puoi ospitare diversi siti web sulla stessa offerta di hosting web, anche se i domini non sono registrati su OVHcloud. Inoltre, puoi associare uno o più domini o sottodomini allo stesso sito web.

:::info
Se non hai ancora creato il sito web interessato sul tuo hosting web, consulta **direttamente** [questa guida](/guides/web-cloud/web-hosting/multisites-configure-multisite).

:::

**Questa guida ti mostra come associare un nome di dominio o un sottodominio a un sito web già esistente sul tuo hosting web.**

:::info
Questa procedura si applica alla <ManagerLink to="/beta/#/">nuova versione dello Spazio Cliente OVHcloud</ManagerLink>, attualmente disponibile in beta. Per seguirla, passa a questa interfaccia dal tuo Spazio Cliente abituale.

:::

## Prerequisiti

- Disporre di un'offerta di [hosting web OVHcloud](https://www.ovhcloud.com/it/web-hosting/uc-multisite/) compatibile.
- Disporre di uno o più [domini](https://www.ovhcloud.com/it/domains/).
- Poter modificare la configurazione dei tuoi domini dalle loro [zone DNS](/guides/web-cloud/domains/dns-zone-edit).

## Procedura

### Aggiungere un nome di dominio o un sottodominio a un sito web esistente

**Fai clic su uno dei titoli qui sotto per visualizzare le spiegazioni.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Aggiungere un nome di dominio gestito dal tuo Spazio Cliente OVHcloud</summary>

Questa parte si applica esclusivamente se il tuo nome di dominio e/o la sua zona DNS attiva si trovano **nel tuo Spazio Cliente OVHcloud**.

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **6** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting/sites">Hosting</ManagerLink> e seleziona l'hosting web interessato.

    <img className="thumbnail" alt="Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella pagina visualizzata, clicca sulla scheda <code className="action">I miei siti</code>.

    <img className="thumbnail" alt="I miei siti" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nel tavolo che appare, fai clic sul pulsante <code className="action">⁝</code> a destra del sito web interessato, quindi su <code className="action">Aggiungi un dominio</code>.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/website-options.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Seleziona l'opzione <code className="action">Associa un dominio OVHcloud esistente</code> e fai clic su <code className="action">Continua</code>.

    Seleziona quindi il nome di dominio da associare nel menu a discesa **Nome di dominio - obbligatorio** che appare in basso.

    :::info
    Per aggiungere un sottodominio, seleziona prima il nome di dominio nell'elenco (ad esempio: domain.tld). Seleziona quindi la casella intitolata <code className="action">Crea un sottodominio</code>. Un campo di testo appare per permetterti di inserire il sottodominio (ad esempio: **sub**.domain.tld).

    **Caso particolare**: I sottodomini in `www` (ad esempio: **www**.domain.tld) vengono automaticamente aggiunti in aggiunta al nome di dominio. Di conseguenza, non è necessario specificare questo sottodominio particolare nel campo di testo.

    :::

    <img className="thumbnail" alt="Add domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-ovh-step-1.png" loading="lazy" />

    Se desideri utilizzare una delle **opzioni avanzate** disponibili, attiva il pulsante <code className="action">Configurazione avanzata</code> e vai direttamente al **passagio 7**. Altrimenti, prosegui al **passagio 6**.
  </Tab>
  <Tab label="Passaggio 5">
    Verifica che tutte le informazioni inserite precedentemente siano corrette, quindi fai clic su <code className="action">Continua</code> per finalizzare l'aggiunta del tuo nome di dominio o del tuo sottodominio al tuo sito web.

    Questo aggiunta può richiedere fino a un'ora.

    La configurazione DNS verrà realizzata automaticamente se la zona DNS attiva del tuo nome di dominio è gestita nel tuo Spazio Cliente OVHcloud.

    Nel caso contrario, consulta le seguenti guide per configurare manualmente la tua zona DNS:

    - [Hosting Web - Lista degli indirizzi IP per cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
    - [Modificare una zona DNS di OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    :::info
    La modifica della configurazione DNS del tuo nome di dominio richiede un periodo di propagazione che può arrivare fino a 24 ore prima di essere pienamente efficace.

    :::

  </Tab>
  <Tab label="Passaggio 6">
    :::info
    Questo passo è **facoltativo**. Si rivolge esclusivamente ai clienti che desiderano attivare alcune funzionalità disponibili tramite il pulsante <code className="action">Configurazione avanzata</code>.

    **Tutte queste funzionalità possono essere attivate in un secondo momento, una volta che il nome di dominio è stato aggiunto al tuo sito web.** In questo caso specifico, consulta direttamente [questa guida](/guides/web-cloud/web-hosting/multisites-modify-domain).

    Di seguito troverai una descrizione di queste opzioni.

    A seconda della tua offerta di [hosting web](https://www.ovhcloud.com/it/web-hosting/), alcuni elementi tra le scelte proposte non potranno essere selezionati.

    :::

    <img className="thumbnail" alt="Add domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-ovh-advanced-configurations.png" loading="lazy" />

    <Region zones={['eu']}>

    |Opzione|Descrizione|
    |---|---|
    |IP del Paese|Permette di beneficiare di un indirizzo IP geolocalizzato (tra una lista di paesi) per il nome di dominio selezionato.<br/> Scopri di più grazie a [questa pagina](https://www.ovhcloud.com/it/web-hosting/options/).|
    |Firewall|Permette di attivare un firewall (filtraggio e analisi delle richieste) sul nome di dominio selezionato.<br/> Scopri di più grazie a [questa pagina](https://www.ovhcloud.com/it/web-hosting/options/).|
    |CDN|Permette di attivare il CDN (caching degli elementi statici del tuo sito web, come le immagini) sul nome di dominio selezionato.<br/> Scopri di più grazie alla [nostra pagina CDN](https://www.ovhcloud.com/it/web-hosting/options/cdn/).<br/> Attivando SSL e CDN, potrai beneficiare anche del protocollo **HTTP/2** (questo protocollo è attivato per default nel nostro datacenter di Gravelines).|

    </Region>
    <Region zones={['ca', 'apac']}>

    |Opzione|Descrizione|
    |---|---|
    |Firewall|Permette di attivare un firewall (filtraggio e analisi delle richieste) sul nome di dominio selezionato.<br/> Scopri di più grazie a [questa pagina](https://www.ovhcloud.com/it/web-hosting/options/).|
    |CDN|Permette di attivare il CDN (caching degli elementi statici del tuo sito web, come le immagini) sul nome di dominio selezionato.<br/> Scopri di più grazie alla [nostra pagina CDN](https://www.ovhcloud.com/it/web-hosting/options/cdn/).|

    </Region>

    Una volta che il pulsante <code className="action">Configurazione avanzata</code> è attivato, puoi anche scegliere la modalità di configurazione DNS del tuo nome di dominio:

    - **Per una configurazione DNS automatica**, lascia selezionata la casella <code className="action">Configurazione automatica (Consigliato)</code>.
    - **Per una configurazione DNS manuale**, seleziona la casella <code className="action">Configurazione manuale</code>. Per effettuare quindi la configurazione, consulta le seguenti guide:
        - [Hosting Web - Lista degli indirizzi IP per cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Modificare una zona DNS di OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    Una volta che le tue scelte sono state effettuate, fai clic sul pulsante <code className="action">Continua</code> per finalizzare l'aggiunta del tuo nome di dominio o del tuo sottodominio al tuo sito web. Questo aggiunta può richiedere fino a un'ora.

    Tuttavia, la modifica della configurazione DNS del tuo nome di dominio richiede un periodo di propagazione che può arrivare fino a 24 ore prima di essere pienamente efficace.
  </Tab>

    :::tip
    **Caso particolare**: I sottodomini in `www` (ad esempio: **www**.domain.tld) vengono automaticamente aggiunti in aggiunta al nome di dominio. Di conseguenza, non è necessario specificare questo sottodominio particolare nel campo di testo.

    :::

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-2.png" loading="lazy" />

    Una volta completate le informazioni, fai clic sul pulsante <code className="action">Continua</code>.

    :::info
    A differenza dei domini direttamente gestiti dal tuo Spazio Cliente OVHcloud, le **opzioni avanzate** non sono direttamente disponibili durante l'aggiunta di un nome di dominio o di un sottodominio esterno al tuo sito web.

    Tuttavia, **tutte queste funzionalità possono essere attivate in un secondo momento una volta che il nome di dominio o il sottodominio esterno è stato aggiunto al tuo sito web.** Per farlo, consulta direttamente [questa guida](/guides/web-cloud/web-hosting/multisites-modify-domain).

    :::

  </Tab>
  <Tab label="Passaggio 6">
    Ogni aggiunta di un nome di dominio esterno a OVHcloud richiede una validazione supplementare obbligatoria. Ciò ci permette di assicurarci che l'aggiunta del nome di dominio esterno sia legittima. Un messaggio ti inviterà quindi a modificare la configurazione DNS del nome di dominio.

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-3.png" loading="lazy" />

    Nota gli elementi che appaiono, quindi fai clic sul pulsante <code className="action">Continua</code>. Da allora, il nome di dominio viene aggiunto in modo temporaneo, il tempo necessario per modificare la sua configurazione DNS.

    :::warning
    Devi effettuare queste modifiche **rapidamente** affinché il tuo nome di dominio venga correttamente aggiunto. Senza questa azione, l'aggiunta del tuo nome di dominio verrà annullata.

    Le voci DNS di tipo **A** e **TXT** devono essere obbligatoriamente inserite nella zona DNS attiva del tuo nome di dominio affinché venga aggiunto al tuo sito web. Solo le voci DNS di tipo **AAAA** sono opzionali.

    Nota che se desideri aggiungere `sub.domain.tld`, dovrai creare l'entrata TXT `ovhcontrol.domain.tld` e non l'entrata `ovhcontrol.sub.domain.tld`.

    Per trovare la zona DNS attiva del tuo nome di dominio, trova i [server DNS](/guides/web-cloud/domains/dns-server-edit) a cui è collegato. Dovrai validare solo il nome di dominio utilizzando il campo **TXT**, non tutti i suoi sottodomini.|

    :::

  </Tab>

### Offerta email inclusa con il tuo hosting web

La maggior parte delle offerte di [hosting web OVHcloud](https://www.ovhcloud.com/it/web-hosting/) dispone di un'opzione inclusa per la creazione di indirizzi email personalizzati con il tuo nome di dominio.

Questa opzione email può essere attivata per **un solo** nome di dominio. Ciò significa che se ospiti diversi siti web con diversi domini sul tuo hosting web, potrai attivare questa opzione solo per uno dei tuoi domini.

Non esitare a consultare [la nostra guida dedicata](/guides/web-cloud/web-hosting/activate-email-hosting) per ulteriori dettagli sull'attivazione di questa opzione.
