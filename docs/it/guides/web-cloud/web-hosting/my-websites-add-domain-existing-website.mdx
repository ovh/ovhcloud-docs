## Obiettivo

Puoi ospitare diversi siti web sulla stessa offerta di hosting web, anche se i domini non sono registrati su OVHcloud. Inoltre, puoi associare uno o più domini o sottodomini allo stesso sito web.

:::info
Se non hai ancora creato il sito web interessato sul tuo hosting web, consulta **direttamente** [questa guida](/guides/web-cloud/web-hosting/multisites-configure-multisite).

:::

**Questa guida ti mostra come associare un nome di dominio o un sottodominio a un sito web già esistente sul tuo hosting web.**

## Prerequisiti

- Disporre di un'offerta di [hosting web OVHcloud](https://www.ovhcloud.com/it/web-hosting/uc-multisite/) compatibile.
- Disporre di uno o più [domini](https://www.ovhcloud.com/it/domains/).
- Poter modificare la configurazione dei tuoi domini dalle loro [zone DNS](/guides/web-cloud/domains/dns-zone-edit).

## Procedura

### Aggiungere un nome di dominio o un sottodominio a un sito web esistente

**Fai clic su uno dei titoli qui sotto per visualizzare le spiegazioni.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Aggiungere un dominio gestito nel tuo account OVHcloud</summary>

Questa parte si applica solo se il tuo dominio e/o la relativa zona DNS attiva si trovano **nel tuo account OVHcloud**.

Il modulo occupa una sola pagina: compilalo dall'alto verso il basso, poi convalida. Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">I miei siti</code>. Nella tabella, clicca sul pulsante <code className="action">⋮</code> nella colonna **Azioni**, a destra del sito web interessato, poi, nel gruppo **Nomi di dominio**, su <code className="action">Aggiungi un nome di dominio</code>.

    <img className="thumbnail" alt="Menu Azioni di un sito web, voce Aggiungi un nome di dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Si apre la pagina **Aggiungi un dominio**. Riprende il modulo di aggiunta del sito, in cui la **cartella root** e il **nome del sito** sono già compilati a partire dal sito web esistente: lasciali invariati.

    <img className="thumbnail" alt="Pagina Aggiungi un dominio e scelta del tipo di nome a dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    Nella sezione **Associazione del nome a dominio**, scegli l'opzione **Nome a dominio OVHcloud esistente**.
  </Tab>
  <Tab label="Passaggio 4">
    Compare la sezione **Configura il tuo dominio**. Seleziona il dominio da associare nel menu a tendina **Nome di dominio**.

    <img className="thumbnail" alt="Configurazione del dominio, opzioni e configurazione DNS" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-configure-domain.png" loading="lazy" />

    :::info
    Per aggiungere un sottodominio, seleziona prima il dominio nella lista (ad esempio: domain.tld). Seleziona poi la casella **Crea un sottodominio**. Compare un campo per inserire il sottodominio (ad esempio: **sub**.domain.tld).

    **Caso particolare**: il sottodominio in `www` (ad esempio: **www**.domain.tld) non viene aggiunto automaticamente con il dominio. Affinché visualizzi anch'esso il tuo sito, aggiungilo separatamente ripetendo questa procedura con `www.domain.tld`.
    :::

    La sezione **Opzioni** raggruppa tre funzionalità, deselezionate per impostazione predefinita. A seconda della tua [offerta di hosting Web](/links/web/hosting), alcune potrebbero non essere selezionabili.

    |Opzione|Descrizione|
    |---|---|
    |IP del paese|Permette di beneficiare di un indirizzo IP geolocalizzato (tra una lista di paesi) per il nome di dominio selezionato.<br/> Scopri di più grazie a [questa pagina](/links/web/hosting-options).|
    |Firewall|Permette di attivare un firewall (filtraggio e analisi delle richieste) sul nome di dominio selezionato.<br/> Scopri di più grazie a [questa pagina](/links/web/hosting-options).|
    |CDN|Permette di attivare il CDN (caching degli elementi statici del tuo sito web, come le immagini) sul nome di dominio selezionato.<br/> Scopri di più grazie alla [nostra pagina CDN](/links/web/hosting-options-cdn).<br/> Attivando SSL e CDN, potrai beneficiare anche del protocollo **HTTP/2** (questo protocollo è attivato per default nel nostro datacenter di Gravelines).|

    :::info
    Queste opzioni possono essere attivate in seguito. Per farlo, consulta [questa guida](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::

    Infine, la sezione **Configurazione DNS** propone due modalità:

    - **Per una configurazione automatica**, lascia selezionata l'opzione **Configurazione automatica**: i record A e AAAA vengono creati nella zona DNS del dominio.
    - **Per una configurazione manuale**, scegli l'opzione **Configurazione manuale**, poi consulta le guide seguenti:
        - [Hosting Web - Lista degli indirizzi IP per cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Modificare una zona DNS di OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    Infine, clicca su <code className="action">Validate</code>. L'aggiunta può richiedere fino a un'ora.

    :::info
    La modifica della configurazione DNS del tuo dominio richiede un tempo di propagazione che può arrivare a 48 ore prima di essere pienamente effettiva.
    :::
  </Tab>
</Tabs>

<details>
<summary>Aggiungere un nome di dominio esterno</summary>

Questa parte si applica esclusivamente se il tuo nome di dominio non è presente nel tuo account OVHcloud.

Il modulo occupa una sola pagina: compilalo dall'alto verso il basso, poi convalida. Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">I miei siti</code>. Nella tabella, clicca sul pulsante <code className="action">⋮</code> nella colonna **Azioni**, a destra del sito web interessato, poi, nel gruppo **Nomi di dominio**, su <code className="action">Aggiungi un nome di dominio</code>.

    <img className="thumbnail" alt="Menu Azioni di un sito web, voce Aggiungi un nome di dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Si apre la pagina **Aggiungi un dominio**. Riprende il modulo di aggiunta del sito, in cui la **cartella root** e il **nome del sito** sono già compilati a partire dal sito web esistente: lasciali invariati.

    <img className="thumbnail" alt="Pagina Aggiungi un dominio e scelta del tipo di nome a dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    Nella sezione **Associazione del nome a dominio**, scegli l'opzione **Nome a dominio esterno**.
  </Tab>
  <Tab label="Passaggio 4">
    Nella sezione **Configura il tuo dominio**, inserisci il dominio (ad esempio: domain.tld) o il sottodominio (ad esempio: **sub**.domain.tld) nel campo **Nome di dominio**.

    :::tip
    **Caso particolare**: il sottodominio in `www` (ad esempio: **www**.domain.tld) non viene aggiunto automaticamente con il dominio. Affinché visualizzi anch'esso il tuo sito, aggiungilo separatamente ripetendo questa procedura con `www.domain.tld`.
    :::

    La sezione **Gestione del dominio** mostra quindi i record da creare, in due fasi. Questa verifica è obbligatoria: ci permette di assicurarci che l'aggiunta del dominio esterno sia legittima.

    <img className="thumbnail" alt="Gestione del dominio: record DNS da creare e record BIND" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-external-dns.png" loading="lazy" />

    1. **Verifica la proprietà del dominio**: aggiungi il record **TXT** indicato nella zona DNS del tuo provider.
    2. **Fai puntare il dominio al tuo hosting**: aggiungi i record **A** e **AAAA** indicati.

    Ogni valore dispone di un pulsante di copia e il blocco **Record BIND** riprende le tre righe nel formato atteso dalla maggior parte dei provider di zone DNS.

    Infine, clicca su <code className="action">Validate</code>. Il dominio viene aggiunto temporaneamente, il tempo necessario per modificarne la configurazione DNS.

    :::warning
    Devi effettuare queste modifiche **rapidamente** affinché il tuo dominio sia correttamente associato al tuo sito web.

    I record DNS di tipo **A** e **TXT** devono obbligatoriamente essere inseriti nella zona DNS attiva del tuo dominio. Solo i record DNS di tipo **AAAA** sono facoltativi.

    Se vuoi associare `sub.domain.tld`, dovrai creare il record TXT `ovhcontrol.domain.tld` e non il record `ovhcontrol.sub.domain.tld`.

    Per trovare la zona DNS attiva del tuo dominio, individua i [server DNS](/guides/web-cloud/domains/dns-server-edit) a cui è collegato.
    :::

    :::info
    La modifica della configurazione DNS del tuo dominio richiede un tempo di propagazione che può arrivare a 48 ore prima di essere pienamente effettiva.
    :::
  </Tab>
</Tabs>

</details>

### Offerta email inclusa con il tuo hosting web

La maggior parte delle offerte di [hosting web OVHcloud](https://www.ovhcloud.com/it/web-hosting/) dispone di un'opzione inclusa per la creazione di indirizzi email personalizzati con il tuo nome di dominio.

Questa opzione email può essere attivata per **un solo** nome di dominio. Ciò significa che se ospiti diversi siti web con diversi domini sul tuo hosting web, potrai attivare questa opzione solo per uno dei tuoi domini.

Non esitare a consultare [la nostra guida dedicata](/guides/web-cloud/web-hosting/activate-email-hosting) per ulteriori dettagli sull'attivazione di questa opzione.
