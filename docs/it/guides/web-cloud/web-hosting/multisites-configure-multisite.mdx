## Obiettivo

Puoi ospitare diversi siti web su una stessa offerta di hosting web, anche se i nomi di dominio non sono registrati presso OVHcloud.

Desideri aggiungere un nuovo sito web al tuo hosting web?

**Questa guida ti mostra come ospitare diversi siti web sulla tua offerta di hosting web.**

:::info
Se hai già creato il sito web desiderato sul tuo hosting web e desideri associargli un nuovo nome di dominio o sottodominio, consulta **direttamente** [questa guida](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).

:::

## Prerequisiti

- Disporre di una [soluzione di hosting Web OVHcloud](/links/web/hosting-multisite) compatibile.
- Disporre di uno o più [nomi di dominio](/links/web/domains).
- Poter modificare la configurazione dei tuoi domini (la [zona DNS](/guides/web-cloud/domains/dns-zone-edit)).

[[cpnav:web-hosting-console]]

## Procedura

### 1 - Aggiungere un sito web sulla tua offerta di hosting web

**Fai clic su uno dei titoli qui sotto per visualizzare le spiegazioni.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Aggiungere un sito web con un dominio gestito nel tuo account OVHcloud</summary>

Questa parte si applica solo se il dominio (e/o la relativa zona DNS attiva) con cui vuoi creare il tuo sito web si trova **nel tuo account OVHcloud**.

Il modulo di aggiunta occupa una sola pagina: compilalo dall'alto verso il basso, poi convalida. Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **5** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">I miei siti</code>, poi sul pulsante <code className="action">Aggiungi un sito</code>, sopra la tabella.

    <img className="thumbnail" alt="Scheda I miei siti e pulsante Aggiungi un sito" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-button.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella sezione **Cartella root**, inserisci il nome della cartella che conterrà i file del tuo sito web. Lascia il campo vuoto affinché la console la crei automaticamente.

    Nella sezione **Associazione del nome a dominio**, scegli l'opzione **Nome a dominio OVHcloud esistente**.

    <img className="thumbnail" alt="Cartella root e scelta del tipo di nome a dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    :::warning
    La **cartella root** viene creata anche nello spazio di storage del tuo hosting Web, accessibile in FTP, SFTP o SSH a seconda della tua offerta. Se il contenuto del tuo sito web si trova già in una cartella specifica di questo spazio, indicane qui il nome.
    :::
  </Tab>
  <Tab label="Passaggio 4">
    Compare la sezione **Configura il tuo dominio**. Nel campo **Nome del sito**, inserisci il nome che preferisci: serve solo a identificare il tuo sito nella console OVHcloud. Seleziona poi il dominio da associare nel menu a tendina **Nome di dominio**.

    <img className="thumbnail" alt="Configurazione del dominio, opzioni e configurazione DNS" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-configure-domain.png" loading="lazy" />

    :::info
    Per aggiungere un sottodominio, seleziona prima il dominio (ad esempio: domain.tld), poi seleziona **Crea un sottodominio**. Compare un campo per inserirlo (ad esempio: **sub**.domain.tld).

    **Caso particolare**: il sottodominio in `www` (ad esempio: **www**.domain.tld) non viene aggiunto automaticamente con il dominio. Affinché visualizzi anch'esso il tuo sito, aggiungilo separatamente ripetendo questa procedura con `www.domain.tld`.
    :::

    La sezione **Opzioni** raggruppa tre funzionalità, deselezionate per impostazione predefinita. A seconda della tua [offerta di hosting Web](/links/web/hosting), alcune potrebbero non essere selezionabili.

    |Opzione|Descrizione|
    |---|---|
    |IP del Paese|Consente di beneficiare di un indirizzo IP geolocalizzato (tra una lista di paesi) per il nome di dominio selezionato.<br/> Scopri di più grazie a [questa pagina](/links/web/hosting-options).|
    |Firewall|Consente di attivare un firewall (filtraggio e analisi delle richieste) per il nome di dominio selezionato.<br/> Scopri di più grazie a [questa pagina](/links/web/hosting-options).|
    |CDN|Consente di attivare il CDN (caching degli elementi statici del tuo sito web, come le immagini) per il nome di dominio selezionato.<br/> Scopri di più grazie a [questa pagina CDN](/links/web/hosting-options-cdn).<br/> Attivando SSL e CDN, potrai beneficiare anche del protocollo **HTTP/2** (questo protocollo è attivo di default nel nostro datacenter di Gravelines).|

    :::info
    Queste opzioni possono essere attivate in seguito, una volta creato il sito web. Per farlo, consulta [questa guida](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::

    Infine, la sezione **Configurazione DNS** propone due modalità:

    - **Per una configurazione automatica**, lascia selezionata l'opzione **Configurazione automatica**: i record A e AAAA vengono creati nella zona DNS del dominio. Un banner precisa che la console tenterà di risolvere i conflitti eliminando le voci incompatibili.
    - **Per una configurazione manuale**, scegli l'opzione **Configurazione manuale**, poi consulta le guide seguenti:
        - [Hosting Web - Lista degli indirizzi IP per cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Modificare una zona DNS di OVHcloud](/guides/web-cloud/domains/dns-zone-edit)
  </Tab>
  <Tab label="Passaggio 5">
    La sezione **Scegli un modulo 1-click da installare** completa il modulo. OVHcloud mette a disposizione i moduli WordPress, Joomla!, PrestaShop e Drupal, installati automaticamente nella cartella root configurata in precedenza. Per maggiori informazioni, consulta la nostra guida "[Installare il tuo sito Web con un 'CMS in 1 click'](/guides/web-cloud/web-hosting/cms-install-1-click-modules)".

    <img className="thumbnail" alt="Scelta del modulo 1-click da installare" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-1-click-module.png" loading="lazy" />

    Lascia selezionato **Nessun modulo preinstallato** se preferisci pubblicare tu stesso i file del tuo sito web. Per maggiori informazioni, consulta la nostra guida "[Mettere online un sito Internet su un hosting Web](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online)".

    Infine, verifica le informazioni inserite, poi clicca su <code className="action">Validate</code>. L'aggiunta può richiedere fino a un'ora.

    :::info
    La modifica della configurazione DNS del tuo dominio richiede un tempo di propagazione che può arrivare a 48 ore prima di essere pienamente effettiva.
    :::
  </Tab>
</Tabs>

</details>

<details>
<summary>Aggiungere un sito web con un dominio non gestito nel tuo account OVHcloud</summary>

Questa parte è applicabile **solo** se desideri aggiungere un sito web con un nome di dominio che non è presente nel tuo account OVHcloud. Può trattarsi di un nome di dominio presente in un altro account OVHcloud o registrato da un altro fornitore.

Il modulo di aggiunta occupa una sola pagina: compilalo dall'alto verso il basso, poi convalida. Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **5** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">I miei siti</code>, poi sul pulsante <code className="action">Aggiungi un sito</code>, sopra la tabella.

    <img className="thumbnail" alt="Scheda I miei siti e pulsante Aggiungi un sito" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-button.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella sezione **Cartella root**, inserisci il nome della cartella che conterrà i file del tuo sito web. Lascia il campo vuoto affinché la console la crei automaticamente.

    Nella sezione **Associazione del nome a dominio**, scegli l'opzione **Nome a dominio esterno**.

    <img className="thumbnail" alt="Cartella root e scelta del tipo di nome a dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    :::warning
    La **cartella root** viene creata anche nello spazio di storage del tuo hosting Web, accessibile in FTP, SFTP o SSH a seconda della tua offerta. Se il contenuto del tuo sito web si trova già in una cartella specifica di questo spazio, indicane qui il nome.
    :::
  </Tab>
  <Tab label="Passaggio 4">
    Nella sezione **Configura il tuo dominio**, inserisci il **Nome del sito** che preferisci: serve solo a identificare il tuo sito nella console OVHcloud. Inserisci poi il dominio (ad esempio: domain.tld) o il sottodominio (ad esempio: **sub**.domain.tld) nel campo **Nome di dominio**.

    :::tip
    **Caso particolare**: il sottodominio in `www` (ad esempio: **www**.domain.tld) non viene aggiunto automaticamente con il dominio. Affinché visualizzi anch'esso il tuo sito, aggiungilo separatamente ripetendo questa procedura con `www.domain.tld`.
    :::

    La sezione **Gestione del dominio** mostra quindi i record da creare, in due fasi. Questa verifica è obbligatoria: ci permette di assicurarci che l'aggiunta del dominio esterno sia legittima.

    <img className="thumbnail" alt="Gestione del dominio: record DNS da creare e record BIND" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-external-dns.png" loading="lazy" />

    1. **Verifica la proprietà del dominio**: aggiungi il record **TXT** indicato nella zona DNS del tuo provider.
    2. **Fai puntare il dominio al tuo hosting**: aggiungi i record **A** e **AAAA** indicati.

    Ogni valore dispone di un pulsante di copia e il blocco **Record BIND** riprende le tre righe nel formato atteso dalla maggior parte dei provider di zone DNS.

    :::warning
    Effettua queste modifiche **rapidamente**. Senza questa operazione, l'aggiunta del tuo dominio sarà annullata e il sito web appena creato non sarà accessibile.

    I record DNS di tipo **A** e **TXT** devono obbligatoriamente essere inseriti nella zona DNS attiva del tuo dominio. Solo i record di tipo **AAAA** sono facoltativi.

    Nota che se desideri associare `sub.domain.tld`, dovrai creare l'entrata TXT `ovhcontrol.domain.tld` e non l'entrata `ovhcontrol.sub.domain.tld`.

    Per trovare la zona DNS attiva del tuo nome di dominio, trova i [server DNS](/guides/web-cloud/domains/dns-server-edit) a cui è collegato. Dovrai validare solo il nome di dominio utilizzando il campo **TXT**, non tutti i suoi sottodomini.
    :::

    :::info
    A differenza dei domini gestiti nel tuo account OVHcloud, le sezioni **Opzioni** e **Configurazione DNS** non sono proposte per un dominio esterno.

    Queste funzionalità restano attivabili una volta creato il sito web. Per farlo, consulta [questa guida](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::
  </Tab>
  <Tab label="Passaggio 5">
    La sezione **Scegli un modulo 1-click da installare** completa il modulo. OVHcloud mette a disposizione i moduli WordPress, Joomla!, PrestaShop e Drupal, installati automaticamente nella cartella root configurata in precedenza. Per maggiori informazioni, consulta la nostra guida "[Installare il tuo sito Web con un 'CMS in 1 click'](/guides/web-cloud/web-hosting/cms-install-1-click-modules)".

    <img className="thumbnail" alt="Scelta del modulo 1-click da installare" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-1-click-module.png" loading="lazy" />

    Lascia selezionato **Nessun modulo preinstallato** se preferisci pubblicare tu stesso i file del tuo sito web. Per maggiori informazioni, consulta la nostra guida "[Mettere online un sito Internet su un hosting Web](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online)".

    Infine, clicca su <code className="action">Validate</code>. Il dominio viene aggiunto temporaneamente, il tempo necessario per modificarne la configurazione DNS.

    :::info
    La modifica della configurazione DNS del tuo dominio richiede un tempo di propagazione che può arrivare a 48 ore prima di essere pienamente effettiva.
    :::
  </Tab>
</Tabs>

    Verrai reindirizzato alla nostra pagina commerciale di sottoscrizione di un dominio. Scegli il tuo nuovo dominio in base alle disponibilità, poi segui le istruzioni del processo d'ordine fino alla convalida del buono d'ordine, senza sottoscrivere anche un nuovo hosting Web.

    Una volta che la tua ordinazione è stata pagata e validata, attendi alcuni istanti, il tempo necessario per il suo trattamento.

    :::info
    Una volta che il tuo dominio compare nel tuo account OVHcloud, segui la parte "[Aggiungere un dominio gestito nel tuo account OVHcloud](#add-domain-ovhcloud)" di questa guida per aggiungere il tuo sito web al tuo hosting Web.

### 2 - Pubblica il tuo sito web <a name="site-online"></a>

Una volta dichiarato il sito web con il tuo dominio sul tuo hosting Web, puoi pubblicare il contenuto del tuo sito web. Ti ricordiamo che devi effettuare questa operazione nella **cartella root** che hai definito durante l'aggiunta del sito web nella console OVHcloud.

:::info
Se desideri aggiungere diversi siti web, ripeti le azioni descritte in questa guida.

Ti invitiamo a prestare attenzione al numero di siti web presenti sul tuo hosting web. Più questo numero è elevato, più le risorse allocate al tuo hosting web vengono sollecitate. [La pagina delle nostre offerte di hosting web](/links/web/hosting) indica il numero raccomandato di siti web che puoi ospitare sul tuo hosting web.

:::
