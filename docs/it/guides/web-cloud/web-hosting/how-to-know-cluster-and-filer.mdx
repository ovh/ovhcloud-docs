## Obiettivo

Gli hosting Web funzionano su un'infrastruttura condivisa chiamata *cluster*. OVHcloud dispone di diversi cluster sui quali sono ripartiti diversi hosting Web.
Per motivi di efficienza e sicurezza, ogni cluster è anche suddiviso virtualmente in diversi segmenti chiamati *filers*. I filer contengono essi stessi diversi hosting Web.
Durante l'utilizzo dell'hosting Web, potrebbe essere necessario conoscere il numero del cluster e/o del filer in cui si trova l'hosting.

**Questa guida ti mostra come recuperare il numero di cluster e il numero del filer in cui si trova il tuo hosting Web.**

## Prerequisiti

- Disporre di un piano di [hosting Web](/links/web/hosting) attivo.

[[cpnav:web-hosting]]

## Procedura

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **2** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/hosting">Hosting web</ManagerLink>, poi scegli l'hosting Web interessato.

    <img className="thumbnail" alt="Pagina Hosting web ed elenco degli hosting dell'account" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella scheda <code className="action">Panoramica</code>, individua la sezione **Informazioni generali**. Indica nell'ordine la **Regione** in cui si trova il tuo hosting Web, il suo **Cluster** e il suo **Filer**.

    Il cluster è visualizzato nella forma `clusterXXX`, dove le tre cifre identificano il cluster. Il filer, invece, è un numero di lunghezza variabile.

    <img className="thumbnail" alt="Sezione Informazioni generali e campi Regione, Cluster e Filer" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/region-cluster-filer.png" loading="lazy" />
  </Tab>
</Tabs>
