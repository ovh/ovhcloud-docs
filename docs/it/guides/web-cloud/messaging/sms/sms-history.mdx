## Obiettivo

La console OVHcloud ti permette di consultare e scaricare la cronologia degli SMS inviati. Questa guida descrive come effettuare queste operazioni.

## Prerequisiti

- Disporre di un [account SMS OVHcloud](/links/telecom/sms) con almeno 1 SMS inviato.

[[cpnav:telecom-sms]]

<img className="thumbnail" alt="Lista degli account SMS nella sezione Web Cloud della console OVHcloud" src="/images/assets/screens/console/product-selection/web-cloud/sms-account-list.png" loading="lazy" />

## Procedura

La cronologia comprende la data, l'ora, il tipo, il mittente, il destinatario, il contenuto e lo stato di ciascun SMS.

:::info

La console OVHcloud ti permette di consultare gli SMS inviati negli ultimi 6 mesi (o gli ultimi 5000 SMS se hai inviato più di 5000 SMS negli ultimi 6 mesi).

Per consultare SMS meno recenti (fino agli ultimi 12 mesi), devi scaricare la cronologia degli SMS in formato CSV. Consulta [il Passaggio 2 di questa guida](#csv).

:::

### Passaggio 1: Consultare la cronologia nella console OVHcloud

Clicca sulla scheda <code className="action">SMS e campagne</code>. La cronologia viene visualizzata direttamente in questa scheda: seleziona **SMS** per visualizzare la cronologia dei tuoi SMS singoli, oppure **Campagne** per visualizzare la lista delle tue campagne di SMS. Le statistiche delle tue campagne si trovano nella scheda <code className="action">Panoramica</code>.

Per impostazione predefinita, la lista mostra gli SMS degli ultimi 7 giorni. Per visualizzare un altro periodo, modificalo da <code className="action">Filtri</code> (vedi sotto).

<img className="thumbnail" alt="Cronologia degli SMS nella scheda SMS e campagne della console OVHcloud" src="/images/web-cloud/messaging/sms/sms-history/console/sms-history-list.png" loading="lazy" />

Gli SMS più recenti vengono visualizzati per primi.

Il pulsante <code className="action">⋮</code> a destra di ciascun SMS ti permette di consultarlo (<code className="action">Visualizza</code>) o di eliminarlo (<code className="action">Elimina</code>).

<img className="thumbnail" alt="Menu di un SMS della cronologia con le opzioni Visualizza ed Elimina" src="/images/web-cloud/messaging/sms/sms-history/console/sms-row-menu.png" loading="lazy" />

Per eliminare più SMS alla volta, spunta le caselle accanto a ciascuno di essi. Il pulsante <code className="action">Elimina</code>, seguito dal numero di SMS selezionati (ad esempio <code className="action">Elimina (1)</code>), appare sopra la cronologia, accanto ad <code className="action">Azioni</code>.

<img className="thumbnail" alt="Pulsante Elimina visualizzato sopra la cronologia dopo la selezione di un SMS" src="/images/web-cloud/messaging/sms/sms-history/console/delete-selected-sms.png" loading="lazy" />

Da <code className="action">Filtri</code>, puoi filtrare la cronologia per tipo (**Inviati**, **Ricevuti** o **Pianificati**), per periodo (**Oggi**, **Ultimi 7 giorni**, **Ultimi 30 giorni**, **Quest'anno** o **Personalizzato**), per mittente, per destinatario o per stato (**Consegnato**, **In corso**, **Errore temporaneo** o **Non riuscito**).

<img className="thumbnail" alt="Menu a discesa Filtri con i filtri Tipo, Periodo, Mittente, Destinatario e Stato" src="/images/web-cloud/messaging/sms/sms-history/console/history-filters.png" loading="lazy" />

### Passaggio 2: Scaricare la cronologia degli SMS in CSV <a name="csv"></a>

Clicca sul pulsante <code className="action">Azioni</code> sopra la tua cronologia, poi su <code className="action">Esporta in CSV</code> per scaricare la cronologia degli SMS in formato .csv.

<img className="thumbnail" alt="Menu Azioni con l'opzione Esporta in CSV" src="/images/web-cloud/messaging/sms/sms-history/console/actions-export-csv.png" loading="lazy" />

Potrai quindi consultare la cronologia da uno strumento di tipo foglio di calcolo. Le informazioni verranno visualizzate come nell'esempio seguente.

<img className="thumbnail" alt="sms-history" src="/images/web-cloud/messaging/sms/sms-history/smshistory7.png" loading="lazy" />

Ecco il dettaglio delle informazioni contenute in questa cronologia:

|  Titolo  |  Descrizione  |
|  :-----          |  :-----          |
|  id |  l'identificativo unico sui nostri server dell'SMS inviato |
|  date | la data e l'ora di invio dell'SMS  |
|  sender |  il mittente da cui è stato inviato l'SMS |
|  receiver |  il numero del cellulare destinatario dell'SMS |
|  ptt |  il codice di ritorno sullo stato dell'SMS |
|  operatorCode |  l'identificativo di rete dell'operatore di telefonia mobile a cui abbiamo trasmesso l'SMS |
|  descriptionDlr |  la descrizione del codice ptt ricevuto e quindi dello stato dell'SMS |
|  tag |  il tag attribuito manualmente tramite le API (a uno o più SMS) o automaticamente dai nostri server a ciascuno degli SMS (o a ciascuna campagna di SMS) inviati |
|  message |  il contenuto dell'SMS |

Trovi maggiori dettagli sui codici ptt e sui diversi ID del DLR consultando l'ultima sezione della guida [Tutto sugli utenti SMS](/guides/web-cloud/messaging/sms/sms-users#callback-url).
