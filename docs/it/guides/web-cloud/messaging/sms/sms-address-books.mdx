## Obiettivo

Tutti gli account SMS OVHcloud possono utilizzare una o più rubriche indirizzi. Questa guida descrive come crearle nel tuo Spazio Cliente OVHcloud.

## Prerequisiti

- Disporre di un [account SMS OVHcloud](/links/telecom/sms).
- Disporre di uno strumento di tipo foglio di calcolo o editor di testo.

## Procedura

### Passaggio 1: Creare una rubrica indirizzi nel tuo Spazio Cliente

Seleziona la scheda <code className="action">Contatti</code>, poi <code className="action">Rubrica indirizzi</code>.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook01.png" loading="lazy" />

Clicca su <code className="action">Aggiungi una rubrica indirizzi</code> e assegna quindi un nome alla tua nuova rubrica.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook2.png" loading="lazy" />

### Passaggio 2: Aggiungere contatti alla tua rubrica

La rubrica indirizzi è ora creata, ma non contiene alcun contatto. Esistono diversi metodi per aggiungere i tuoi contatti.

### Aggiunta singola di contatti dallo Spazio Cliente

Seleziona il pulsante <code className="action">Azioni</code> e clicca su <code className="action">Aggiungi</code>.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook3.png" loading="lazy" />

Accederai a una finestra che ti permette di inserire le informazioni del contatto.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook4.png" loading="lazy" />

Compila i campi desiderati e conferma per salvare le modifiche. Il contatto verrà quindi aggiunto alla tua rubrica. Dovrai ripetere la stessa operazione per aggiungere altri contatti.

### Aggiunta di più contatti tramite l'importazione di un file di contatti dallo Spazio Cliente

#### Preparazione del file nel tuo foglio di calcolo

Se desideri utilizzare o creare un documento in formato foglio di calcolo, dovrai presentarlo come mostrato di seguito ed esportarlo nel formato .csv.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook-spreadsheet1.png" loading="lazy" />

A <a href="https://raw.githubusercontent.com/ovh/ovhcloud-docs/develop/docs/public/images/guides/web-cloud/messaging/sms/sms-address-books/phonebook.csv" download>questo link</a> trovi un modello di rubrica indirizzi in formato .csv da compilare tu stesso.

La grande maggioranza dei fogli di calcolo non terrà conto del formato internazionale previsto per i numeri di telefono/fax (+39xxxxxxxxx). Dovrai quindi modificare il formato delle celle che contengono questi numeri (workPhone, workMobile, ...). Per farlo, seleziona le colonne interessate e applica a queste un formato "Testo".

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook-spreadsheet2.png" loading="lazy" />

Una volta pronto il documento, salvalo nel formato foglio di calcolo per modificarlo in seguito.

Allo stesso tempo, salvalo o esportalo nel formato .csv per prepararne l'importazione.

:::info
**Raccomandazioni**

Salva il tuo file foglio di calcolo nel formato .csv (separatore: punto e virgola).

I caratteri speciali come gli accenti non sono accettati nell'importazione del file .csv: i contatti che contengono questo tipo di caratteri non saranno importati.

Rispetta il formato internazionale +39xxxxxxxxx per i tuoi numeri.

Ti consigliamo di non superare i 2000 contatti per rubrica indirizzi.

Tutti i tuoi contatti dovranno trovarsi sullo stesso foglio del tuo foglio di calcolo.
:::

#### Importazione del file nel tuo Spazio Cliente

Tornato sul tuo Spazio Cliente OVHcloud, seleziona il pulsante <code className="action">Azioni</code> e clicca su <code className="action">Importa</code>.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook5.png" loading="lazy" />

Viene visualizzato un pop-up: clicca quindi su <code className="action">File di contatto</code> per selezionare il tuo file .csv, poi conferma.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook6.png" loading="lazy" />

Attendi qualche secondo durante il caricamento del file nel tuo Spazio Cliente.

### Passaggio 3: Modificare o eliminare una rubrica indirizzi

Se desideri modificare il nome di una rubrica indirizzi, seleziona la tua rubrica nel menu a tendina (1) (se hai creato più rubriche), poi clicca sulla matita (2) accanto al nome della rubrica.

Per eliminare una rubrica, selezionala nel menu a tendina (1), poi clicca su <code className="action">Elimina la rubrica indirizzi</code>.

Per modificare o eliminare un contatto, clicca, nella colonna "Azioni", su <code className="action">...</code> (4) accanto al contatto scelto. Avrai così accesso al menu che ti propone queste opzioni.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook7.png" loading="lazy" />
