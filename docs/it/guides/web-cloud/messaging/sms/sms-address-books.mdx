## Obiettivo

Tutti gli account SMS OVHcloud possono utilizzare una o più rubriche indirizzi. Questa guida descrive come crearle nella console OVHcloud.

## Prerequisiti

- Disporre di un [account SMS OVHcloud](/links/telecom/sms).
- Disporre di uno strumento di tipo foglio di calcolo o editor di testo.

[[cpnav:telecom-sms]]

<img className="thumbnail" alt="Lista degli account SMS nella sezione Web Cloud della console OVHcloud" src="/images/assets/screens/console/product-selection/web-cloud/sms-account-list.png" loading="lazy" />

## Procedura

### Passaggio 1: Creare una rubrica indirizzi nella console OVHcloud

Seleziona la scheda <code className="action">Contatti</code>.

<img className="thumbnail" alt="Scheda Contatti di un account SMS nella console OVHcloud" src="/images/web-cloud/messaging/sms/sms-address-books/console/contacts-tab.png" loading="lazy" />

Clicca su <code className="action">Azioni</code> e poi su <code className="action">Crea una rubrica</code>. Nella finestra **Crea una rubrica**, assegna un nome alla tua nuova rubrica nel campo **Nome**, poi clicca su <code className="action">Crea</code>.

<img className="thumbnail" alt="Finestra Crea una rubrica aperta dal menu Azioni della scheda Contatti" src="/images/web-cloud/messaging/sms/sms-address-books/console/create-address-book.png" loading="lazy" />

### Passaggio 2: Aggiungere contatti alla tua rubrica

La rubrica indirizzi è ora creata, ma non contiene alcun contatto. Esistono diversi metodi per aggiungere i tuoi contatti.

### Aggiunta singola di contatti dalla console OVHcloud

Clicca sul pulsante <code className="action">Aggiungi un contatto</code>, sopra l'elenco dei contatti.

<img className="thumbnail" alt="Pulsante Aggiungi un contatto nella scheda Contatti di un account SMS" src="/images/web-cloud/messaging/sms/sms-address-books/console/add-contact-button.png" loading="lazy" />

Nel pannello **Aggiungi un contatto**, inserisci le informazioni del contatto: nome, cognome, azienda (facoltativa) e numeri di telefono fisso e cellulare, personali e di lavoro.

<img className="thumbnail" alt="Pannello Aggiungi un contatto con i campi del contatto e i relativi numeri di telefono" src="/images/web-cloud/messaging/sms/sms-address-books/console/add-contact-panel.png" loading="lazy" />

Compila i campi desiderati (è obbligatorio almeno un numero di telefono), poi clicca su <code className="action">Salva</code>. Il contatto viene quindi aggiunto alla tua rubrica. Ripeti l'operazione per aggiungere altri contatti.

### Aggiunta di più contatti tramite l'importazione di un file di contatti dalla console OVHcloud

#### Preparazione del file nel tuo foglio di calcolo

Se desideri utilizzare o creare un documento in formato foglio di calcolo, dovrai presentarlo come mostrato di seguito ed esportarlo nel formato .csv.

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook-spreadsheet1.png" loading="lazy" />

Puoi scaricare un <a href="/images/guides/web-cloud/messaging/sms/sms-address-books/phonebook.csv" download>modello di rubrica indirizzi in formato .csv</a> da compilare tu stesso.

La grande maggioranza dei fogli di calcolo non terrà conto del formato internazionale previsto per i numeri di telefono/fax (+39xxxxxxxxx). Dovrai quindi modificare il formato delle celle che contengono questi numeri (workPhone, workMobile, ...). Per farlo, seleziona le colonne interessate e applica a queste un formato "Testo".

<img className="thumbnail" alt="phonebook" src="/images/web-cloud/messaging/sms/sms-address-books/smsphonebook-spreadsheet2.png" loading="lazy" />

Una volta pronto il documento, salvalo nel formato foglio di calcolo per modificarlo in seguito.

Allo stesso tempo, salvalo o esportalo nel formato .csv per prepararne l'importazione.

:::info
**Raccomandazioni**

Salva il tuo file foglio di calcolo nel formato .csv (separatore: punto e virgola).

I caratteri speciali come gli accenti non sono accettati nell'importazione del file .csv: i contatti che contengono questo tipo di caratteri non saranno importati.

Rispetta il formato internazionale +39xxxxxxxxx per i tuoi numeri.

Ti consigliamo di non superare i 2000 contatti per rubrica indirizzi.

Tutti i tuoi contatti dovranno trovarsi sullo stesso foglio del tuo foglio di calcolo.
:::

#### Importazione del file nella console OVHcloud

Torna nella console OVHcloud, clicca su <code className="action">Azioni</code> e poi su <code className="action">Importa</code>.

<img className="thumbnail" alt="Opzione Importa del menu Azioni nella scheda Contatti" src="/images/web-cloud/messaging/sms/sms-address-books/console/actions-import.png" loading="lazy" />

Nella finestra **Importa contatti**, clicca su <code className="action">Sfoglia i file</code> per selezionare il tuo file .csv, poi clicca su <code className="action">Importa</code>. I contatti del file vengono aggiunti alla rubrica selezionata. La prima riga del file deve riportare le intestazioni di colonna del modello (`group`, `surname`, `name`, `workPhone`, `workMobile`, `homePhone`, `homeMobile`); il loro ordine non ha importanza. Un file esportato dalla console OVHcloud non può essere reimportato così com'è: sostituisci prima le sue intestazioni con quelle del modello.

<img className="thumbnail" alt="Finestra Importa contatti con l'area di selezione del file CSV" src="/images/web-cloud/messaging/sms/sms-address-books/console/import-contacts.png" loading="lazy" />

Attendi qualche secondo durante il caricamento del file nella console OVHcloud.

### Passaggio 3: Modificare o eliminare una rubrica indirizzi

Se desideri modificare il nome di una rubrica indirizzi, seleziona la tua rubrica nel menu a tendina **Rubrica** (se hai creato più rubriche), poi clicca su <code className="action">Azioni</code> e su <code className="action">Rinomina</code>. Nella finestra **Rinomina la rubrica**, inserisci il nuovo nome nel campo **Nome**, poi clicca su <code className="action">Rinomina</code>.

Per eliminare una rubrica, selezionala nel menu a tendina **Rubrica**, poi clicca su <code className="action">Azioni</code> e su <code className="action">Elimina</code>. Conferma l'eliminazione cliccando su <code className="action">Elimina</code> nella finestra **Conferma eliminazione**.

:::warning

L'eliminazione di una rubrica indirizzi è irreversibile.

:::

Per modificare o eliminare un contatto, clicca sul pulsante <code className="action">⋮</code> alla fine della riga del contatto scelto, poi su <code className="action">Modifica</code> o <code className="action">Elimina</code>.

<img className="thumbnail" alt="Menu di un contatto con le opzioni Modifica ed Elimina nella scheda Contatti" src="/images/web-cloud/messaging/sms/sms-address-books/console/contact-row-menu.png" loading="lazy" />
