## Obiettivo

La console OVHcloud ti permette di recuperare le tue credenziali SMPP, modificare la password, gestire gli accessi al servizio e trasferire crediti SMS.

**Scopri come gestire le impostazioni di un account SMS SMPP dalla console OVHcloud.**

:::info
Ti consigliamo di prendere visione delle [specifiche tecniche dell'offerta SMPP OVHcloud](/guides/web-cloud/messaging/sms/smpp-specification).

:::

## Prerequisiti

- Disporre di un [account SMS SMPP OVHcloud](https://www.ovhcloud.com/it/sms/api-sms/).

[[cpnav:telecom-sms]]

## Procedura

Seleziona il tuo account SMPP. Si distingue dagli altri account SMS OVHcloud per il suo nome: inizia con `smpp-` anziché con `sms-` come gli account SMS classici. Il suo formato di account è **SMPP Marketing**.

<img className="thumbnail" alt="Lista degli account SMS nella console OVHcloud, con un account SMPP" src="/images/web-cloud/messaging/sms/smpp-control-panel/console/smpp-account-list.png" loading="lazy" />

### Informazioni di identificazione

Clicca sulla scheda <code className="action">Opzioni</code>. La sezione **Informazioni generali** ti permette di recuperare le credenziali necessarie all'utilizzo del tuo servizio: **Stato**, **System ID**, punti di accesso sicuro e non sicuro, **Windowing** e **Throughput**. Utilizza il pulsante a destra del System ID e di ogni punto di accesso per copiarne il contenuto.

<img className="thumbnail" alt="Sezione Informazioni generali della scheda Opzioni di un account SMPP" src="/images/web-cloud/messaging/sms/smpp-control-panel/console/smpp-credentials.png" loading="lazy" />

Se hai dimenticato la password SMPP, clicca su <code className="action">Genera una nuova password</code>.

Clicca su <code className="action">Invia</code> per confermare questa operazione. All'indirizzo email di contatto del tuo account OVHcloud viene inviata un'email con la procedura da seguire per modificare la password.

<img className="thumbnail" alt="Finestra di conferma della generazione di una nuova password SMPP" src="/images/web-cloud/messaging/sms/smpp-control-panel/console/smpp-generate-password.png" loading="lazy" />

### Gestione degli accessi

Clicca sulla scheda <code className="action">Opzioni</code>.

<img className="thumbnail" alt="Sezione IP autorizzati della scheda Opzioni di un account SMPP" src="/images/web-cloud/messaging/sms/smpp-control-panel/console/smpp-allowed-ips.png" loading="lazy" />

La sezione **IP autorizzati** elenca gli indirizzi IP dei tuoi client SMPP autorizzati ad accedere al server SMPP. Ogni indirizzo può essere eliminato dalla lista.

Clicca sul pulsante <code className="action">Aggiungere un IP</code> per aggiungere indirizzi IP a questa lista. Puoi autorizzare fino a 10 indirizzi IP. Nella finestra **Aggiungi un IP autorizzato**, inserisci un indirizzo IPv4 nel campo **Indirizzo IP**, poi clicca su <code className="action">Invia</code>.

<img className="thumbnail" alt="Finestra Aggiungi un IP autorizzato di un account SMPP" src="/images/web-cloud/messaging/sms/smpp-control-panel/console/smpp-add-ip.png" loading="lazy" />
