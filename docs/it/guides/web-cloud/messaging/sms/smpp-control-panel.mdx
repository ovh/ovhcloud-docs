## Obiettivo

Lo Spazio Cliente OVHcloud ti permette di recuperare le tue credenziali SMPP, modificare la password, gestire gli accessi al servizio e trasferire crediti SMS.

**Scopri come gestire le impostazioni di un account SMS SMPP dallo Spazio Cliente OVHcloud.**

:::info
Ti consigliamo di prendere visione delle [specifiche tecniche dell'offerta SMPP OVHcloud](/guides/web-cloud/messaging/sms/smpp-specification).

:::

## Prerequisiti

- Disporre di un [account SMS SMPP OVHcloud](https://www.ovhcloud.com/it/sms/api-sms/).

## Procedura

Seleziona il tuo account SMPP. Si distingue dagli altri account SMS OVHcloud per il suo nome: inizia infatti con `smpp-` anziché con `sms-` come gli account SMS classici.

<img className="thumbnail" alt="SMPP account" src="/images/web-cloud/messaging/sms/smpp-control-panel/smpp-account.png" loading="lazy" />

### Informazioni di identificazione

Il riquadro `Informazioni generali` ti permette di recuperare le credenziali necessarie all'utilizzo del tuo servizio. Utilizza il pulsante a destra di ogni campo per copiarne il contenuto.

<img className="thumbnail" alt="SMPP account" src="/images/web-cloud/messaging/sms/smpp-control-panel/smpp-account-ID.png" loading="lazy" />

In caso di dimenticanza della password SMPP, utilizza il pulsante <code className="action">Genera una nuova password</code>. Una nuova password verrà quindi inviata all'indirizzo e-mail di contatto del tuo account OVHcloud, che ti verrà mostrato.

Clicca su <code className="action">Invia</code> per confermare questa operazione.

<img className="thumbnail" alt="SMPP account" src="/images/web-cloud/messaging/sms/smpp-control-panel/smpp-account-password.png" loading="lazy" />

### Gestione degli accessi

Clicca sulla scheda <code className="action">Opzioni</code>, poi su <code className="action">Impostazioni SMPP</code>.

<img className="thumbnail" alt="SMPP account" src="/images/web-cloud/messaging/sms/smpp-control-panel/smpp-acl0.png" loading="lazy" />

Il riquadro `IP autorizzati` elenca gli indirizzi IP dei tuoi client SMPP autorizzati ad accedere al server SMPP.

Clicca sul pulsante <code className="action">Aggiungi un IP</code> per aggiungere indirizzi IP a questa lista.

<img className="thumbnail" alt="SMPP account" src="/images/web-cloud/messaging/sms/smpp-control-panel/smpp-acl1.png" loading="lazy" />
