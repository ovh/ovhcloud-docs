## Obiettivo 

I log corrispondono agli eventi verificatisi su un sistema informatico (server, computer, applicazione, sito web, database, rete informatica, ecc.). Per esempio, i log possono registrare e contenere uno o più elementi tra i seguenti:

- L'orario (data, ora, minuto, secondo) dell'evento.
- La natura dell'evento (connessione, disconnessione, errore, download, upload, allerta, ecc.).
- Informazioni aggiuntive sull'evento (pagine o file consultati, applicazioni avviate, server remoti chiamati, nome di un file caricato o scaricato, ecc.).
- L'origine dell'evento (identificativo dell'utente, indirizzo IP sorgente, programma sorgente, ecc.).
- Lo stato del sistema al momento dell'evento (risorse disponibili, memoria rimanente, utilizzo della CPU, ecc.).

In generale, i log vengono generati direttamente dai sistemi informatici sui quali si verificano gli eventi. Vengono memorizzati e archiviati in file di testo, noti anche come file log.

I file log permettono di effettuare le seguenti azioni:

- Analizzare il comportamento del sistema informatico che genera i log.
- Individuare gli errori verificatisi sul sistema informatico.
- Risolvere gli errori riscontrati sul sistema informatico.
- Ottimizzare il funzionamento e le prestazioni del sistema informatico.

La tua offerta Private Exchange o Trusted Exchange genera quindi i propri log. Potresti dover consultare o recuperare i log per analizzare gli accessi alle tue caselle di posta elettronica o seguire i flussi di posta elettronica.

**Scopri come visualizzare e gestire i log sulla tua offerta Private Exchange o Trusted Exchange**

## Procedura

### Visualizzare i log della tua piattaforma Exchange in tempo reale

Per accedere ai log in tempo reale del tuo servizio Private Exchange o Trusted Exchange, clicca sulla relativa scheda <code className="action">Log</code>. Un banner **Questi log sono visualizzati solo in tempo reale** ricorda che non vengono conservati e una barra degli strumenti sovrasta la visualizzazione dei log.

<img className="thumbnail" alt="Scheda Log di un servizio Private Exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-manage-logs/console/exchange-logs-tab.png" loading="lazy" />

:::warning
Poiché si tratta di una visualizzazione in tempo reale, i log appaiono solo quando sei sulla scheda <code className="action">Log</code>. Se esci dalla scheda <code className="action">Log</code> e ci ritorni, la cronologia precedente sarà scomparsa.

:::


I servizi Private Exchange e Trusted Exchange offrono 2 tipi di log, che puoi selezionare nell'elenco a tendina della barra degli strumenti:

- **Access logs**: permette di consultare l'attività delle connessioni sul tuo servizio Exchange.
- **Message tracking**: permette di consultare i log dettagliati del flusso di email che attraversa il tuo servizio Exchange. Troverai le seguenti informazioni:
    - lo stato di consegna delle email sui tuoi account Exchange;
    - lo stato di invio delle email dal tuo servizio Exchange;
    - la dimensione delle email trasmesse;
    - ecc.

### Integrare i log della tua soluzione Exchange su Logs Data Platform

La soluzione Logs Data Platform può rivelarsi utile se disponi di un'infrastruttura importante o se i tuoi servizi generano una grande quantità di log. Infatti, questa piattaforma è progettata per facilitare l'aggregazione e la gestione dei log.

Funziona recuperando i log generati dalla tua infrastruttura, dai tuoi siti web o applicazioni per, ad esempio:

- memorizzarli;
- visualizzarli in dashboard in tempo reale;
- permettere agli utenti di effettuare query complesse;
- filtrarli per data, applicazione, tipo o contenuto.

:::info
Per ulteriori dettagli su Logs Data Platform, consulta la nostra guida "[Introduction to Logs Data Platform (EN)](/guides/manage-and-operate/observability/logs-data-platform/introduction)".

:::


Le soluzioni Exchange sono compatibili con diversi servizi come l'hosting condiviso, i VPS e i server dedicati. Possono inoltre essere completate da flussi di dati su Logs Data Platform, in aggiunta ai log in tempo reale già disponibili.

Per abbonare i log della tua soluzione Exchange a un flusso di dati su Logs Data Platform, effettua le seguenti azioni:

1. Clicca sulla scheda <code className="action">Log</code> del tuo servizio e seleziona il tipo di log nell'elenco a tendina della barra degli strumenti. L'abbonamento riguarda solo il tipo di log selezionato: per trasferire i 2 tipi, abbonati una volta per ciascuno.
1. Clicca sul pulsante <code className="action">Configurazione</code> della barra degli strumenti. Si apre il pannello **Elenco dei flussi di dati**.

<img className="thumbnail" alt="Pulsante Configurazione della barra degli strumenti della scheda Log" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-manage-logs/console/exchange-logs-configuration-button.png" loading="lazy" />

In questo pannello, seleziona l'account Logs Data Platform desiderato nell'elenco **Servizio Observability**. I relativi flussi di dati vengono quindi visualizzati sotto forma di elenco.

<img className="thumbnail" alt="Pannello Elenco dei flussi di dati, elenco Servizio Observability" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-manage-logs/console/exchange-logs-data-streams-panel.png" loading="lazy" />

Si presentano due casi per abbonare la tua soluzione Exchange:

<Tabs>
  <Tab label="Caso n°1">
    **Iscriversi a un flusso già esistente sulla tua soluzione Logs Data Platform**
    
    Se il flusso esiste già, appare nell'elenco. Per abbonare la tua soluzione Exchange a questo flusso esistente, clicca sul pulsante <code className="action">Abbonati</code> del flusso corrispondente.
    
    Dopo qualche istante, se rimani sulla pagina, viene visualizzato il messaggio "L'iscrizione è andata a buon fine."
  </Tab>
  <Tab label="Caso n°2">
    **Iscriversi a un nuovo flusso di dati sulla tua soluzione Logs Data Platform**
    
    Se il tuo account Logs Data Platform non contiene ancora alcun flusso di dati, clicca su <code className="action">Crea un flusso di dati</code> nel pannello. Il modulo di creazione di un flusso di dati di Logs Data Platform si apre in una nuova scheda della console OVHcloud.
    
    Consulta le nostre guide "[Introduction to Logs Data Platform (EN)](/guides/manage-and-operate/observability/logs-data-platform/introduction)" e "[Quick start for Logs Data Platform (EN)](/guides/manage-and-operate/observability/logs-data-platform/getting-started-quick-start)" per effettuare questa azione.
    
    Una volta compilato il modulo, clicca sul pulsante <code className="action">Crea</code>.
    
    Verrai quindi reindirizzato alla scheda <code className="action">Flusso di dati</code> della tua soluzione Logs Data Platform.
    
    Torna quindi alla scheda <code className="action">Log</code> del tuo servizio Exchange: puoi ora abbonarlo al tuo nuovo flusso seguendo le istruzioni all'inizio del capitolo.
  </Tab>
</Tabs>
