## Obiettivo

La tua soluzione **Managed Hosting for WordPress** si gestisce in linguaggio naturale da un agente IA (Claude Code, Codex, ecc.), grazie al protocollo **MCP** (*Model Context Protocol*). Colleghi tu stesso un solo server, il **MCP OVHcloud**. Il tuo agente IA lo utilizza poi per configurare gli altri due: **MCP for WordPress**, per il contenuto di un sito, e **MainWP**, per gestire più siti contemporaneamente.

**Scopri come collegare il tuo agente IA al MCP OVHcloud e come fargli configurare MCP for WordPress e MainWP.**

## Prerequisiti

- Disporre di una soluzione [Managed Hosting for WordPress](/guides/web-cloud/managed-hosting/wordpress) attiva con almeno un sito WordPress.
- Disporre di un account OVHcloud con accesso a questa soluzione.
- Utilizzare un agente IA compatibile con MCP **installato sul tuo computer** e in grado di eseguire comandi, ad esempio [Claude Code](https://code.claude.com/docs/it/overview) o [Codex](https://learn.chatgpt.com/docs/codex/cli).
- Per MainWP: disporre di [Node.js](https://nodejs.org/en) (versione LTS) sul tuo computer.

:::info
Un assistente IA utilizzato in un browser può collegarsi al MCP OVHcloud, ma non a MCP for WordPress né a MainWP: queste due connessioni vengono salvate nella configurazione dell'agente, sul tuo computer.
:::

## Introduzione

Ciascuno dei tre server MCP copre una parte della tua soluzione:

| Server MCP | Cosa può gestire il tuo agente IA | Come collegarlo |
|---|---|---|
| **MCP OVHcloud** | L'hosting: soluzioni, siti, domini, versioni di PHP, cache CDN, log, backup, password SFTP, phpMyAdmin e database | Lo aggiungi una volta, poi ti identifichi con il tuo account OVHcloud |
| **MCP for WordPress** | Un sito WordPress: articoli, pagine, media, commenti, menu, impostazioni, plugin, temi e utenti | Il tuo agente IA lo configura, una connessione per sito |
| **MainWP** | Più siti contemporaneamente dalla dashboard MainWP inclusa nella tua soluzione: aggiornamenti, attivazione e disattivazione di plugin, temi e traduzioni | Il tuo agente IA lo configura, una connessione per l'intera soluzione |

**MCP for WordPress** è un plugin OVHcloud preinstallato sui siti della tua soluzione. Fornisce al tuo agente IA un elenco chiuso di azioni per gestire il tuo sito WordPress.

## Procedura

:::warning
Il tuo agente IA agisce con i diritti che gli concedi: il tuo account OVHcloud per il MCP OVHcloud, un account amministratore per MCP for WordPress. Verifica ogni azione che ti propone prima di confermarla, in particolare un'eliminazione, un aggiornamento o una pubblicazione.
:::

### Step 1: collegare il MCP OVHcloud

Il MCP OVHcloud è un server remoto ospitato da OVHcloud. Non gli trasmetti alcuna password: il tuo agente IA apre la pagina di accesso OVHcloud nel browser e ti identifichi come nello Spazio Cliente.

Scegli il tuo agente IA nelle schede qui sotto.

<Tabs>
  <Tab label="Claude Code">
    In un terminale, esegui:

    ```bash
    claude mcp add --transport http --scope user ovhcloud https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    ```

    Avvia Claude Code, digita `/mcp`, seleziona il server **ovhcloud**, poi **Authenticate**. Identificati con il tuo account OVHcloud nella pagina che si apre.

    :::warning
    Non aggiungere l'opzione `--header` a questo comando. Un header `Authorization` fisso impedisce l'identificazione OVHcloud: il server risulta connesso, ma ogni richiesta fallisce poi con un errore 401.
    :::
  </Tab>
  <Tab label="Codex">
    In un terminale, esegui:

    ```bash
    codex mcp add ovhcloud --url https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS
    codex mcp login ovhcloud
    ```

    Identificati con il tuo account OVHcloud nella pagina che si apre, poi riavvia Codex.

    {/* DRAFT: To verify — Codex commands (add --url + mcp login) not tested against the OVHcloud hub */}
  </Tab>
  <Tab label="Altro agente IA">
    Aggiungi un server MCP remoto (trasporto *streamable HTTP*) nella configurazione del tuo agente IA:

    - **URL**: `https://mcp.eu.ovhcloud.com/mcp/v2_managedCMS`
    - **Autenticazione**: OAuth, senza header né token da inserire.

    Avvia l'autenticazione dal tuo agente IA e identificati con il tuo account OVHcloud.
  </Tab>
</Tabs>

Per verificare la connessione, chiedi al tuo agente IA:

> Elenca le mie soluzioni Managed Hosting for WordPress e i loro siti.

Ti risponde con le tue soluzioni e gli indirizzi dei tuoi siti.

### Step 2: far configurare MCP for WordPress per un sito

Chiedi al tuo agente IA, indicando l'indirizzo del tuo sito:

> Configura MCP for WordPress per il mio sito www.example.com

Se non specifichi un sito, ti propone l'elenco dei siti della tua soluzione.

La configurazione si svolge poi così:

1. **Il tuo agente IA ti chiede l'autorizzazione** a creare una password per l'applicazione sul sito. Questa password gli permette di agire sul sito come amministratore, entro i limiti delle azioni di MCP for WordPress. Per accettare, rispondi esplicitamente:

    > Sì, crea la password per l'applicazione

    Ripetere la tua richiesta iniziale non vale come consenso: il tuo agente IA attende questa risposta prima di procedere.

2. **Il tuo agente IA verifica che il plugin MCP for WordPress sia attivo** sul sito. In caso contrario, te lo segnala: attiva **MCP for WordPress** dal menu <code className="action">Plugin</code> dell'amministrazione WordPress del tuo sito, poi ripeti la richiesta.
3. **Il tuo agente IA crea la password per l'applicazione** tramite il MCP OVHcloud, poi aggiunge la connessione del sito alla sua configurazione. Approva il comando che esegue.
4. **Ricarica i server MCP**: in Claude Code, digita `/mcp` e riconnettiti, oppure riavvia Claude Code; in Codex, riavvialo. Gli strumenti del sito compaiono solo dopo questo ricaricamento.

Per verificare la connessione, chiedi:

> Elenca gli ultimi 5 articoli di www.example.com

Ripeti questo step per ogni sito da gestire: ogni sito ha la propria connessione.

### Step 3: far configurare MainWP

La dashboard MainWP inclusa nella tua soluzione gestisce tutti i tuoi siti. Chiedi al tuo agente IA:

> Configura il MCP MainWP

La configurazione segue lo stesso procedimento dello step 2:

1. **Il tuo agente IA ti chiede l'autorizzazione** a creare una password per l'applicazione sulla dashboard MainWP. Per accettare, rispondi:

    > Sì, crea la password per l'applicazione

2. **Il tuo agente IA verifica la presenza di Node.js** sul tuo computer. Se non è presente, installa la versione LTS da [nodejs.org](https://nodejs.org/en), poi ripeti la richiesta.
3. **Il tuo agente IA crea la password per l'applicazione** tramite il MCP OVHcloud, poi aggiunge il server MainWP alla sua configurazione. Approva il comando che esegue.
4. **Ricarica i server MCP** come allo step 2.

Per verificare la connessione, chiedi:

> Elenca i siti della mia dashboard MainWP e i plugin da aggiornare.

:::info
Il server MainWP è configurato per chiederti una conferma prima di ogni azione che modifica i tuoi siti.
:::

### Esempi di richieste

Una volta collegati i tre server, formula le tue richieste come faresti con un collega. Il tuo agente IA sceglie il server giusto.

| Vuoi… | Esempio di richiesta |
|---|---|
| Scrivere contenuti | "Scrivi una bozza di articolo sui nostri orari estivi per www.example.com." |
| Moderare i commenti | "Mostra i commenti in attesa di moderazione su www.example.com." |
| Aggiornare più siti | "Quali plugin devono essere aggiornati su tutti i miei siti?" |
| Diagnosticare un errore | "Il mio sito www.example.com restituisce errori 500: consulta i log e dimmi perché." |
| Svuotare la cache | "Svuota la cache CDN di www.example.com." |
| Eseguire il backup di un sito | "Esporta un backup completo di www.example.com." |

Prima di pubblicare un articolo, il tuo agente IA ti chiede quale account WordPress ne è l'autore.

### Revocare un accesso

Puoi revocare in qualsiasi momento l'accesso concesso al tuo agente IA:

- **MCP for WordPress**: nell'amministrazione WordPress del sito, apri <code className="action">Utenti</code> > <code className="action">Profilo</code>, poi elimina la password per l'applicazione nella sezione **Password delle applicazioni**.
- **MainWP**: procedi allo stesso modo nell'amministrazione WordPress della dashboard MainWP.
- **MCP OVHcloud**: rimuovi il server dalla configurazione del tuo agente IA, ad esempio con `claude mcp remove ovhcloud` in Claude Code.

### Risoluzione dei problemi

- **Il tuo agente IA indica che non riesce a connettersi al sito o a MainWP**: verifica che sia eseguito sul tuo computer e non in un browser.
- **I nuovi strumenti non compaiono**: ricarica i server MCP (`/mcp` in Claude Code) o riavvia il tuo agente IA.
- **Il tuo agente IA si interrompe segnalando un'azione rifiutata**: ha bloccato la creazione della password o l'esecuzione del comando. Autorizza questa azione nelle sue impostazioni dei permessi, oppure indicala esplicitamente nella tua richiesta, ad esempio "Crea una password per l'applicazione sul sito www.example.com".
- **Le richieste al MCP OVHcloud falliscono con un errore 401**: rimuovi il server, aggiungilo di nuovo senza header, poi riavvia l'autenticazione.
