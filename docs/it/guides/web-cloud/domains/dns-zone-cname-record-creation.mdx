## Obiettivo

Un record CNAME permette di associare un sottodominio a un nome di dominio o sottodominio, senza dover specificare un indirizzo IP. Il sottodominio sarà reindirizzato verso l'indirizzo IP del nome di dominio o sottodominio di destinazione, senza necessità di configurazione aggiuntiva.

Ad esempio, se si crea un record CNAME per *www.domain.tld* che punta a *domain.tld*, *www.domain.tld* utilizzerà lo stesso indirizzo IP di *domain.tld*.

I record CNAME sono utili per evitare di modificare gli indirizzi IP dei sottodomini. Possono anche essere utilizzati per configurare servizi come i server di posta.

**Questa guida ti mostra come aggiungere un record CNAME alla zona DNS di OVHcloud.**

> **Hai già un record di tipo CNAME nella tua zona DNS?** Consulta la nostra guida "[Modificare una zona DNS di OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".

## Prerequisiti

- Disporre di un [nome di dominio](/links/web/domains).
- Disporre di una zona DNS associata a questo nome di dominio in OVHcloud.

[[cpnav:web-domain-dns-zone]]

:::warning
**L'aggiunta, la modifica o la cancellazione di record DNS in una zona DNS attiva è un'operazione delicata.**
In caso di dubbi, contatta un [provider specializzato](/links/partner).

:::

## Procedura

### Aggiungere un record DNS di tipo CNAME per il sottodominio di un nome di dominio

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **5** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi scegli il dominio interessato.

    <img className="thumbnail" alt="Pagina Domini e DNS ed elenco dei nomi di dominio dell'account" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Zona DNS</code>, poi, sopra la tabella, su <code className="action">Crea un record</code>.

    <img className="thumbnail" alt="Scheda Zona DNS di un dominio e pulsante Crea un record" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nel modulo che si apre sopra la tabella, seleziona `CNAME — Alias verso un altro dominio` nell'elenco **Tipo**.

    <img className="thumbnail" alt="Elenco Tipo del modulo di creazione del record, tipo CNAME selezionato" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-cname.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Nel campo **Sottodominio**, inserisci il sottodominio interessato (ad esempio: `www` per `www.domain.tld`). Nel campo **Destinazione (nome host)**, inserisci il dominio o sottodominio verso cui vuoi puntare (ad esempio: `domain.tld`): la console aggiunge automaticamente il punto finale.

    <img className="thumbnail" alt="Modulo di creazione del record della zona DNS, record CNAME del sottodominio www verso domain.tld" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-cname-record.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 5">
    Verifica l'**Anteprima del record**, poi clicca su <code className="action">Aggiungi</code>.
  </Tab>
</Tabs>

Attendi fino a **24** ore affinché la propagazione dell'aggiunta sulla rete DNS sia pienamente effettiva.

### Casi particolari

Per ulteriori informazioni, fare clic sui collegamenti seguenti:

<details>

<summary>Record CNAME e TXT per lo stesso sottodominio</summary>

Non configurare contemporaneamente un record CNAME e un record TXT per lo stesso sottodominio. Questo può generare risultati casuali durante la risoluzione DNS, in quanto solo una risposta può essere restituita da una query DNS.

Ad esempio, se sono presenti i seguenti record per *www.domain.tld*:

- Un record CNAME che punta a *domain.tld*.
- Un record TXT con un valore specifico.

Una richiesta DNS per *www.domain.tld* restituirà la destinazione del record CNAME o il valore del record TXT, in modo casuale.

</details>

<details>

<summary>CNAME su un nome di dominio nella propria zona DNS</summary>

Per convenzione, **i record di tipo CNAME non possono essere utilizzati su un nome di dominio nella propria zona DNS**. Il nome di dominio deve puntare direttamente verso un indirizzo IP con un record di tipo [A](/guides/web-cloud/domains/dns-zone-a-record-creation) per un IPv4, o [AAAA](/guides/web-cloud/domains/dns-zone-aaaa-record-creation) per un IPv6.

Seguendo l'esempio precedente, non è possibile creare un record di tipo CNAME per il nome di dominio *domain.tld* nella zona DNS creata per il nome di dominio.
È possibile creare record di tipo CNAME per tutti i sottodomini (ad esempio: *subdomain.domain.tld* o *www.domain.tld*) del nome di dominio *domain.tld* nella zona DNS creata per *domain.tld*.

Nella console OVHcloud, se inserisci `@` nel campo **Sottodominio** di un record CNAME, il pulsante <code className="action">Aggiungi</code> resta disattivato e il modulo mostra il messaggio "Un record CNAME non può essere creato alla radice del dominio (@). Puoi utilizzare il puntamento SVCB."

</details>
