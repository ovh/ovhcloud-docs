## Obiettivo

Vuoi recuperare la lista di tutti i domini presenti sul tuo account cliente OVHcloud? Hai bisogno di recuperare, in un solo gesto, tutte le informazioni relative ai tuoi domini (contatti associati, titolari, opzioni attive, date di creazione e di scadenza, ecc.)?

**Questa guida ti mostra come esportare la lista dei tuoi domini e le informazioni associate in formato CSV dalla console OVHcloud.**

## Prerequisiti

- Disporre di un [dominio](/links/web/domains) registrato in OVHcloud.

[[cpnav:web-domains]]

## Procedura

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>. Sopra la tabella che appare, clicca sul pulsante <code className="action">Esporta in CSV</code>, poi su <code className="action">Esporta tutto</code>.

    <img className="thumbnail" alt="Menu del pulsante Esporta in CSV sopra la lista dei domini" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/export-csv/export-csv-menu.png" loading="lazy" />

    :::info
    Per esportare solo alcuni domini, selezionali prima nella tabella, poi scegli <code className="action">Esporta la selezione</code> nello stesso menu.

    :::
  </Tab>
  <Tab label="Passaggio 2">
    Nel pannello **Esporta in CSV** che si apre, seleziona le informazioni che vuoi includere nel file CSV per tutti i tuoi domini, nelle sezioni **Colonne dominio** e **Colonne contatti**. Il dominio in formato ASCII è sempre incluso. Vengono esportate anche le zone DNS autonome (senza dominio nel tuo account): la colonna **Tipo**, selezionata di default, distingue dominio, dominio + zona e solo zona.

    <img className="thumbnail" alt="Pannello Esporta in CSV e scelta delle colonne da esportare" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/export-csv/export-csv-drawer.png" loading="lazy" />

    Clicca quindi sul pulsante <code className="action">Esporta</code> per avviare la generazione del file in formato CSV.
  </Tab>
  <Tab label="Passaggio 3">
    L'avanzamento dell'esportazione viene visualizzato nel pannello. Attendi che la barra di avanzamento raggiunga il 100%.

    Non appena il file CSV è generato, viene visualizzato il messaggio "L’esportazione CSV è stata generata correttamente." e il download del file si avvia automaticamente.

    <img className="thumbnail" alt="Messaggio di riuscita dell'esportazione CSV e link per scaricare il file" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/export-csv/export-csv-success.png" loading="lazy" />

    Se il download del file CSV non si è avviato automaticamente, clicca sul link <code className="action">Scarica il file CSV</code> per recuperarlo. Infine, clicca su <code className="action">Chiudi</code> per chiudere il pannello.
  </Tab>
</Tabs>
