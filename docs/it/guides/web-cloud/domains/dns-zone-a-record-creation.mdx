## Obiettivo

Vuoi che il tuo sito sia accessibile tramite il tuo dominio? Per fare ciò, il dominio deve puntare verso l'indirizzo IP del servizio su cui è situato il sito Web (hosting Web, server dedicato, VPS, ecc.). A questo punto, è necessario configurare la zona DNS attiva del dominio con un record DNS di tipo A.

**Questa guida ti mostra come aggiungere un record DNS di tipo A a una zona DNS gestita in OVHcloud per il tuo dominio.**

:::info
Per modificare o eliminare un record DNS di tipo A da una zona DNS di OVHcloud, segui [questa guida](/guides/web-cloud/domains/dns-zone-edit).

:::

## Prerequisiti

- Disporre di un [dominio](/links/web/domains).
- Disporre di una zona DNS associata a questo dominio in OVHcloud.

[[cpnav:web-domain-dns-zone]]

## Procedura

:::warning
L'aggiunta, la modifica o la cancellazione di record DNS in una zona DNS attiva è un'operazione delicata. In caso di dubbi, contatta un [provider specializzato](/links/partner).

:::

### Aggiungere un record DNS di tipo A per un dominio

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **5** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi scegli il dominio interessato.

    <img className="thumbnail" alt="Pagina Domini e DNS ed elenco dei nomi di dominio dell'account" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Zona DNS</code>, poi, sopra la tabella, su <code className="action">Crea un record</code>.

    <img className="thumbnail" alt="Scheda Zona DNS di un dominio e pulsante Crea un record" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nel modulo che si apre sopra la tabella, seleziona `A — Puntare verso un IPv4` nell'elenco **Tipo**.

    <img className="thumbnail" alt="Elenco Tipo del modulo di creazione del record e tipi di record proposti" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Nel campo **Sottodominio**, inserisci `@`: questo simbolo indica il nome di dominio stesso. Nel campo **Destinazione (IPv4)**, inserisci l'indirizzo IP (ad esempio: `203.0.113.0`) del servizio su cui si trova il tuo sito web (hosting Web, server dedicato, VPS, ecc.).

    <img className="thumbnail" alt="Modulo di creazione del record della zona DNS, record A per il dominio" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-a-record.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 5">
    Verifica l'**Anteprima del record**, poi clicca su <code className="action">Aggiungi</code>.
  </Tab>
</Tabs>

Attendi fino a **24** ore affinché la propagazione dell'aggiunta sulla rete DNS sia pienamente effettiva.

### Aggiungere un record DNS di tipo A per il sottodominio di un dominio

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **5** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi scegli il dominio interessato.

    <img className="thumbnail" alt="Pagina Domini e DNS ed elenco dei nomi di dominio dell'account" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Zona DNS</code>, poi, sopra la tabella, su <code className="action">Crea un record</code>.

    <img className="thumbnail" alt="Scheda Zona DNS di un dominio e pulsante Crea un record" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nel modulo che si apre sopra la tabella, seleziona `A — Puntare verso un IPv4` nell'elenco **Tipo**.

    <img className="thumbnail" alt="Elenco Tipo del modulo di creazione del record e tipi di record proposti" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list.png" loading="lazy" />
  </Tab>

    Nel campo **Sottodominio**, inserisci il sottodominio interessato (ad esempio: `www` per `www.domain.tld`). Nel campo **Destinazione (IPv4)**, inserisci l'indirizzo IP (ad esempio: `203.0.113.0`) del servizio su cui si trova il tuo sito web (hosting Web, server dedicato, VPS, ecc.).

    <img className="thumbnail" alt="Modulo di creazione del record della zona DNS, record A per il sottodominio www" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-a-record-www.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 5">
    Verifica l'**Anteprima del record**, poi clicca su <code className="action">Aggiungi</code>. Attendi fino a **24** ore affinché la propagazione dell'aggiunta sulla rete DNS sia pienamente effettiva.
  </Tab>
</Tabs>
