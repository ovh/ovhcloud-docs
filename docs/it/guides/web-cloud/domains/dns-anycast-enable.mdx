## Obiettivo

Vuoi che i tuoi servizi (ad esempio: il tuo sito Web) siano accessibili in tempi record in tutto il mondo? Vuoi che la risoluzione DNS del tuo dominio sia ottimizzata?
OVHcloud propone l'opzione [DNS Anycast](/links/web/domains-options-anycast).

**Questa guida ti mostra come accelerare l'accesso ai servizi Web grazie alla velocità di risoluzione DNS dell'opzione DNS Anycast del tuo dominio.**

## Prerequisiti

- Disporre di un [dominio](/links/web/domains).
- L'estensione del dominio deve essere compatibile con l'opzione DNS Anycast.

[[cpnav:web-domains]]

## Procedura

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi scegli il dominio interessato. Viene visualizzata la scheda <code className="action">Panoramica</code> del dominio.

    <img className="thumbnail" alt="Pagina Domini e DNS ed elenco dei nomi di dominio dell'account" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella sezione **Servizi associati** della scheda <code className="action">Panoramica</code>, parte **Sicurezza e SSL**, individua il riquadro **DNS Anycast**, che presenta i vantaggi e il prezzo dell'opzione. Clicca sul pulsante <code className="action">Ordina</code>.

    <img className="thumbnail" alt="Sezione Servizi associati della scheda Panoramica, parte Sicurezza e SSL, e riquadro di ordine DNS Anycast" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/anycast-offer.png" loading="lazy" />

    :::info
    Il pulsante <code className="action">Ordina</code> è disattivato se il tuo dominio utilizza server DNS esterni: configura prima il dominio sui server DNS OVHcloud. Se il dominio non dispone di una zona DNS OVHcloud, il riquadro propone invece il pulsante <code className="action">Attiva la mia zona DNS</code>.

    :::
  </Tab>
  <Tab label="Passaggio 3">
    Viene visualizzata la pagina **Ordina DNS Anycast**. Non è necessario scegliere alcuna durata: come indicato nella sezione **Impegno**, l'opzione DNS Anycast scade alla stessa data della tua zona DNS e il suo prezzo è calcolato in proporzione al periodo restante.

    <img className="thumbnail" alt="Pagina di ordine dell'opzione DNS Anycast e riepilogo dell'ordine" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/anycast-order.png" loading="lazy" />

    Nel riepilogo, clicca su <code className="action">Continua l’ordine</code>. La pagina dell'ordine si apre, per impostazione predefinita in una nuova scheda del browser: prosegui fino alla convalida dell'ordine con un metodo di pagamento per completarne la presa in carico.
  </Tab>
</Tabs>

L'attivazione dell'opzione DNS Anycast potrebbe richiedere alcuni minuti.
