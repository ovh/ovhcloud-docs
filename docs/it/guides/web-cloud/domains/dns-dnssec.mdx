## Obiettivo 

Un server DNS ospita una o più zone DNS. Una zona DNS contiene la configurazione DNS di un dominio. È questa configurazione che collega il dominio ai diversi servizi associati (server di hosting per il sito Web, server per gli indirizzi email personalizzati con il dominio, ecc...).

In alcuni casi, i flussi di dati che passano attraverso i server DNS possono essere dirottati da persone malintenzionate.
In sintesi, per fare ciò, queste persone avvelenano la cache dei server DNS con la configurazione DNS che vogliono applicare al tuo dominio: è quello che chiamano "Cache poisoning".
In questo modo, possono reindirizzare i flussi in entrata dal tuo dominio verso i loro siti Web e verso i loro indirizzi email.

Il **D**omain **N**ame **S**ystem **SEC**urity extensions (**DNSSEC**), permette di proteggere la configurazione DNS del tuo nome di dominio dal "Cache poisoning" verificando e autenticando le risposte DNS.

**Questa guida ti mostra come attivare il protocollo DNSSEC per proteggere il tuo dominio dal "Cache poisoning".**

Per maggiori informazioni sul funzionamento del **DNSSEC**, consulta la nostra pagina "[Comprendere il DNSSEC](/links/web/domains-dnssec)".

Per maggiori informazioni su questi argomenti, consulta le nostre guide disponibili su [server DNS OVHcloud](/guides/web-cloud/domains/dns-server-general-information) e sull’[edizione di una zona DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit).

## Prerequisiti

- Disporre di un dominio.
- l'estensione del dominio deve essere compatibile con DNSSEC.

## Procedura

Per verificare se il dominio utilizza la configurazione DNS di OVHcloud, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **2** passi.

:::warning
**Questi 2 step sono validi solo se il dominio è registrato presso OVHcloud.** In caso contrario, è necessario effettuare la verifica presso il Registrar del dominio.

Se i nomi dei server DNS terminano con *ovh.net* (ad eccezione del server *snds2.ovh.net*), *ovh.ca* o *anycast.me*, il dominio utilizza i server DNS di OVHcloud.

:::

:::info
L'attivazione/disattivazione del **DNSSEC** richiede **24** ore per essere effettiva.

Per modificare i server DNS associati al dominio in un secondo momento, la modifica dei server DNS sarà effettiva sul lato OVHcloud solo dopo la disattivazione del **DNSSEC**. In seguito, la propagazione DNS della modifica potrebbe richiedere da **24** a **48** ore.

In totale, la modifica dei server DNS di un dominio con la soluzione **DNSSEC** attiva sarà pienamente effettiva dopo **48** alle **72** ore.

:::

L'attivazione del **DNSSEC** è possibile in tre situazioni descritte di seguito.

### Caso n°1 - Il dominio è registrato in OVHcloud e utilizza i server DNS di OVHcloud

Per attivare (o disattivare) la soluzione **DNSSEC** per il tuo dominio, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi scegli il dominio interessato. Viene visualizzata la scheda <code className="action">Panoramica</code> del dominio.

    <img className="thumbnail" alt="Pagina Domini e DNS ed elenco dei nomi di dominio dell'account" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Zona DNS</code>. Il riquadro **DNSSEC** mostra lo stato del **DNSSEC** sul tuo dominio, alla riga **Firma della zona**: **Attivata** o **Disattivata**.

    <img className="thumbnail" alt="Riquadro DNSSEC della scheda Zona DNS con il DNSSEC attivato" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dnssec/dnssec-enabled.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Per attivare il **DNSSEC**, clicca su <code className="action">Attiva DNSSEC</code>, poi conferma nella finestra **Attivare DNSSEC** cliccando su <code className="action">Attivare DNSSEC</code>.

    <img className="thumbnail" alt="Riquadro DNSSEC della scheda Zona DNS con il DNSSEC disattivato e il pulsante Attiva DNSSEC" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dnssec/dnssec-disabled.png" loading="lazy" />

    Per disattivare il **DNSSEC**, clicca su <code className="action">Disattiva DNSSEC</code>, poi convalida la modifica nella finestra **Disattivare DNSSEC** cliccando su <code className="action">Disattivare DNSSEC</code>.

    <img className="thumbnail" alt="Finestra Disattivare DNSSEC" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dnssec/dnssec-disable-window.png" loading="lazy" />
  </Tab>
</Tabs>

### Caso n°2 - Il dominio è registrato in OVHcloud e non utilizza i server DNS di OVHcloud

In questo caso, contatta il provider che gestisce la configurazione DNS del tuo dominio per richiedere i parametri di attivazione del DNSSEC ("Key Tag" / "Algoritmo" / "Chiave pubblica (codificata in base64)"). Non è necessario richiedere il parametro "Flags": la console lo imposta a 257.

Una volta recuperati questi 3 parametri, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi scegli il dominio interessato. Viene visualizzata la scheda <code className="action">Panoramica</code> del dominio.

    <img className="thumbnail" alt="Pagina Domini e DNS ed elenco dei nomi di dominio dell'account" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Zona DNS</code>. Il riquadro **DNSSEC** permette di aggiungere e modificare i **Record DS**. È disponibile solo se il tuo dominio dispone di una zona DNS OVHcloud: senza zona DNS, la scheda mostra invece il modulo di ordine di una zona DNS e non è possibile aggiungere un record DS.
  </Tab>
  <Tab label="Passaggio 3">
    Sotto i **Record DS**, clicca su <code className="action">Aggiungi un record DS</code>.
  </Tab>
  <Tab label="Passaggio 4">
    Nel pannello **Aggiungere un record DS**, compila i 3 campi **Key Tag**, **Algoritmo** (menu a tendina) e **Chiave pubblica** con i dati comunicati dal tuo attuale provider. Il valore **Flags** è impostato automaticamente a 257, il valore richiesto dal registro.

    Per aggiungere un altro record (4 al massimo), clicca su <code className="action">Aggiungere un record</code>. Una volta compilati i campi, clicca sul pulsante <code className="action">Convalidare</code>.
  </Tab>
</Tabs>

### Caso n°3 - Il dominio non è registrato in OVHcloud e utilizza i server DNS di OVHcloud

:::warning
Prima di proseguire, assicurati presso il Registrar attuale che nessuna opzione DNSSEC sia già attiva.

:::

Diversamente dal **caso n. 2**, qui è necessario recuperare da OVHcloud i parametri di attivazione del DNSSEC ("Key Tag" / "Flag" / "Algoritmo" / "Chiave pubblica (codificata in base64)").

Per farlo, utilizza le [API OVHcloud](/guides/manage-and-operate/api/first-steps) ed effettua le seguenti operazioni:

- Accedi al nostro sito <ApiLink>API OVHcloud</ApiLink> (verifica di essere su `https://api.eu.ovhcloud.com` se i tuoi servizi sono ospitati in Europa e su `https://api.ca.ovhcloud.com` se i tuoi servizi sono ospitati al di fuori dell'Europa).
- Nella nuova pagina, clicca al centro su <code className="action">Explore the OVHcloud API</code>.
- Nella nuova pagina che appare e nella parte sinistra della pagina, utilizza il menu a tendina situato a destra del form <code className="action">v1</code>, poi seleziona/inserisci la scelta `/domain`.
- Dall'elenco di API che appare sotto nella colonna di sinistra, cerca e clicca su questa API: **POST /domain/zone/&#123;zoneName&#125;/dnssec**. In alternativa, clicca direttamente su questo link per accedervi:

<Api version="v1" section="/domain" method="POST" route={"/domain/zone/\{zoneName\}/dnssec"} />

- Sul lato destro della pagina compare l'API con i suoi moduli da compilare.
- Clicca sul pulsante in alto a destra intitolato <code className="action">Authenticate</code> e poi sul pulsante <code className="action">Login with OVHcloud SSO</code>.
- Si apre l'interfaccia di connessione al tuo <ManagerLink to="/">account OVHcloud</ManagerLink>.
- Accedi al tuo account e clicca su <code className="action">Authorize</code> per utilizzare le API OVHcloud con i servizi presenti nel tuo account OVHcloud.
- verrai reindirizzato automaticamente alla pagina precedente dell'API **POST /domain/zone/&#123;zoneName&#125;/dnssec**, dove verrai autenticato.
- Sul lato destro della pagina compare l'API con un form da compilare.
- Compila il modulo nella sezione `PATH PARAMETERS` come segue:
- `zoneName` : inserisci qui il nome di dominio pertinente (esempio: `domain.tld`).

<img className="thumbnail" alt="API" src="/images/assets/screens/api/post-domain-zone-zonename-dnssec.png" loading="lazy" />

Una volta completato il form, clicca sul pulsante blu <code className="action">EXECUTE</code> in basso a destra nella sezione precedentemente compilata.

Dopo qualche minuto, riceverai un'email da OVHcloud all'indirizzo di contatto della tua zona DNS.
Questa email conterrà i 4 parametri ("Key Tag" / "Flag" / "Algoritmo" / "Chiave pubblica (codificata in base64)") necessari per attivare DNSSEC presso il Registrar del tuo dominio.

:::tip
Controlla la posta indesiderata se non la ricevi entro un'ora.

:::

Per completare l'operazione, contatta il Registrar attuale del tuo dominio con le 4 impostazioni indicate per attivare l'opzione DNSSEC.
