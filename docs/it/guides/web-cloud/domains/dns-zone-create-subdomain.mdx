## Obiettivo

Desideri creare una zona DNS per un sottodominio?

La zona **D**omain **N**ame **S**ystem (**DNS**) di un dominio costituisce il file di configurazione di quest'ultimo. Essa è composta da informazioni tecniche, chiamate *record DNS*. La zona DNS agisce come un centro di instradamento.

Per ulteriori informazioni, consulta le nostre guide qui di seguito:

- [Scopri tutto sui server DNS](/guides/web-cloud/domains/dns-server-general-information)
- [Sapere tutto sulla zona DNS](/guides/web-cloud/domains/dns-zone-general-information)
- [Scopri tutto sui record DNS](/guides/web-cloud/domains/dns-zone-records)

Di norma, i record DNS di un sottodominio vengono configurati direttamente dalla zona DNS attiva del nome di dominio a cui appartiene.
Tuttavia, è anche possibile creare una zona DNS specifica per un sottodominio.

Per diversi motivi, potresti dover creare una zona DNS per un sottodominio su OVHcloud.
Quest'ultimo disporrà quindi della sua propria zona per configurare i propri record DNS.

:::tip
Per ricordo:

- Un nome di dominio ha generalmente questa forma: **domain.tld**. Ad esempio: ovhcloud.com.
- Un sottodominio ha generalmente questa forma: **sub.domain.tld**. Ad esempio: help.ovhcloud.com.

Per funzionare, un sottodominio dipende di default da un nome di dominio.
Concretamente, non potrai utilizzare il sottodominio **sub.domain.tld** se non hai accesso alla gestione del nome di dominio **domain.tld**.

Se desideri creare una zona DNS per un nome di dominio, consulta direttamente [questa guida](/guides/web-cloud/domains/dns-zone-create).

:::

**Questa guida ti mostra come creare una zona DNS OVHcloud per il sottodominio di un dominio dalla console OVHcloud.**

## Prerequisiti

- Disporre del nome di dominio da cui dipenderà il sottodominio scelto.
- Il sottodominio in questione non deve già disporre di una zona DNS (attiva o meno) su OVHcloud o essere oggetto di un'operazione o di un ordine in corso su OVHcloud.

[[cpnav:web-dns-zone-order]]

## Procedura

### 1 - Creare la zona DNS dalla console OVHcloud

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi clicca sul pulsante <code className="action">Ordina un dominio o una zona DNS</code>. Nel riquadro **Zona DNS autonoma**, clicca su <code className="action">Ordina</code>.

    <img className="thumbnail" alt="Pagina di ordine di un dominio o di una zona DNS e riquadro Zona DNS autonoma" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-choice.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella pagina **Ordina una zona DNS** che appare, inserisci nel campo **Nome di dominio** il sottodominio (ad esempio: *sub.domain.tld*) per il quale vuoi creare una zona DNS OVHcloud. Attendi qualche istante mentre lo strumento effettua le verifiche sul sottodominio.

    Se un messaggio indica che non è possibile creare la zona DNS (ad esempio, "Esiste già una zona DNS per sub.domain.tld."), verifica che il sottodominio rispetti i prerequisiti necessari o contatta la persona che lo gestisce. Quando tutto è corretto, riprova.

    <img className="thumbnail" alt="Messaggio che indica che esiste già una zona DNS per il nome inserito" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-exists.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Al termine della verifica, appare la sezione **Scegli le tue opzioni**. Seleziona se necessario l'opzione **DNS Anycast** (a pagamento). Il riepilogo, a destra della pagina, indica il contenuto e il totale del tuo ordine.

    <img className="thumbnail" alt="Opzioni dell'ordine di una zona DNS per un sottodominio e riepilogo dell'ordine" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-subdomain.png" loading="lazy" />

    Clicca su <code className="action">Continua l’ordine</code>, poi segui gli step visualizzati fino alla creazione della zona DNS.

    :::info
    La scelta dei record minimi non avviene più durante l'ordine. Se vuoi personalizzare tu stesso la zona DNS partendo dai soli record minimi (record NS e SOA), ripristinala una volta creata: nella scheda <code className="action">Zona DNS</code>, apri il menu <code className="action">Altre azioni</code> del riquadro **Zona DNS**, clicca su <code className="action">Ripristina la zona</code> e scegli <code className="action">Sì — solo voci minimali</code>. Consulta la nostra guida "[Modificare una zona DNS di OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".

    :::
  </Tab>
</Tabs>

### 2 - Modificare la zona DNS (facoltativo)

La zona DNS per il tuo sottodominio è ora creata, puoi modificarla immediatamente. Questa operazione è facoltativa, ma potrebbe rivelarsi necessaria se desideri assicurare la continuità della disponibilità dei servizi collegati a questo sottodominio (come un sito web e/o delle email).

Per modificare questa zona DNS, consulta la nostra guida "[Modifica una zona DNS OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".

:::info
Se hai appena creato la zona DNS e il sottodominio non appare ancora nell'elenco dei tuoi servizi, attendi 15 a 20 minuti e ricarica la pagina.

:::

### 3 - Dichiarare i server DNS nella zona DNS attiva del nome di dominio a cui appartiene il sottodominio scelto

L'attivazione di una zona DNS per un sottodominio differisce da quella di un nome di dominio, poiché un sottodominio dipende obbligatoriamente da un nome di dominio per funzionare.

Devi prima recuperare il nome dei **server DNS** OVHcloud associati alla zona DNS creata per il tuo sottodominio.

Per recuperarli, clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **2** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi scegli la zona DNS del tuo sottodominio (appare come **Solo zona** nell'elenco). Clicca quindi sulla scheda <code className="action">Zona DNS</code>.

    <img className="thumbnail" alt="Pagina Domini e DNS ed elenco dei nomi di dominio dell'account" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nella tabella che appare, individua le colonne **Tipo** e **Destinazione**. Per visualizzare solo i record utili, clicca su <code className="action">Filtri</code>, poi seleziona <code className="action">NS</code> nell'elenco **Tipo di record**.

    <img className="thumbnail" alt="Zona DNS filtrata sui record NS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-ns.png" loading="lazy" />

    Annota i 2 valori presenti nella colonna **Destinazione**. I nomi dei server DNS devono avere una delle 3 forme seguenti:

    - `nsXX.ovh.net` e `dnsXX.ovh.net` o, `nsXXX.ovh.net` e `dnsXXX.ovh.net` (dove ogni `X` rappresenta un numero compreso tra **0** e **9**).
    - `nsXX.ovh.ca` e `dnsXX.ovh.ca` o, `nsXXX.ovh.ca` e `dnsXXX.ovh.ca` (dove ogni `X` rappresenta un numero compreso tra **0** e **9**).
    - `ns200.anycast.me` e `dns200.anycast.me` (se hai sottoscritto l'opzione [DNS anycast](/links/web/domains-options)).
  </Tab>
</Tabs>

Una volta recuperati i 2 nomi dei server DNS, 2 situazioni sono possibili:

**Clicca su una delle 2 situazioni per visualizzare il contenuto.**

<details>

<summary>Il nome di dominio da cui dipende il tuo sottodominio ha la sua zona DNS attiva su OVHcloud</summary>

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi scegli il dominio da cui dipende il tuo sottodominio.

    <img className="thumbnail" alt="Pagina Domini e DNS ed elenco dei nomi di dominio dell'account" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Zona DNS</code>, poi sul pulsante <code className="action">Aggiungi una voce</code> sopra la tabella.

    <img className="thumbnail" alt="Scheda Zona DNS e modulo Aggiungi una voce" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nell'elenco **Tipo**, seleziona <code className="action">NS — Delegare a un server DNS</code> (sezione **Campi di puntamento**).

    <img className="thumbnail" alt="Elenco dei tipi di record con il tipo NS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-ns.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    Nel campo **Sottodominio**, inserisci il sottodominio interessato (ad esempio: `sub` per il sottodominio `sub.domain.tld`); nel campo **Destinazione (server DNS)**, inserisci uno dei 2 server DNS che hai annotato (ad esempio: `nsXX.ovh.net`). Verifica l'**Anteprima del record**, poi clicca su <code className="action">Aggiungi</code>.

    <img className="thumbnail" alt="Modulo di record NS compilato per un sottodominio" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-ns-record.png" loading="lazy" />

    **Ripeti l'operazione per il secondo server DNS.**

    Se necessario, consulta anche la nostra guida "[Modificare una zona DNS di OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".
  </Tab>
</Tabs>

</details>

<details>

<summary>Il nome di dominio da cui dipende il tuo sottodominio ha la sua zona DNS attiva da un altro fornitore</summary>

In questo caso specifico, contatta il tuo fornitore DNS specificandogli che desideri aggiungere 2 record DNS di tipo NS per il tuo sottodominio. 

Ecco un esempio di richiesta da formulare al tuo fornitore DNS:

<pre className="bgwhite"><code>
Buongiorno,

Desidero aggiungere nella zona DNS attiva del nome di dominio <b>domain.tld</b> i seguenti record DNS di tipo NS per il mio sottodominio <b>sub.domain.tld</b>:

 - sub IN NS nsXX.ovh.net.
 - sub IN NS dnsXX.ovh.net.

Al fine di attivare una zona DNS specifica per il mio sottodominio <b>sub.domain.tld</b>.

Cordiali saluti,
</code></pre>

Nell'esempio sopra, sostituisci i valori **domain.tld**, **sub.domain.tld**, **nsXX.ovh.net** e **dnsXX.ovh.net** con i tuoi valori personali.

</details>

:::warning
**L'attenzione che segue non riguarda i 2 record DNS di tipo NS che hai appena aggiunto.** 

Se erano presenti altri record DNS nella zona DNS attiva del nome di dominio da cui dipende il tuo sottodominio:

1. Non dimenticare di duplicarli nella zona DNS creata per il tuo sottodominio.
2. Una volta duplicati, rimuovili dalla zona DNS attiva del tuo nome di dominio.

Infatti, potrebbe verificarsi un conflitto nella risoluzione DNS.

:::

Dopo la modifica della zona DNS del nome di dominio da cui dipende il tuo sottodominio, la propagazione delle modifiche può richiedere fino a **48 ore**.
