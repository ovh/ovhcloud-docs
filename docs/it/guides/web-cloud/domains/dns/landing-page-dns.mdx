## Cos'è il DNS?

Il **DNS** (*Domain Name System*) è l'elenco telefonico di Internet: traduce i nomi a dominio leggibili dall'uomo (come `mydomain.ovh`) in indirizzi IP compresi dalle macchine. Senza di esso, dovresti ricordare una serie di cifre per raggiungere ogni sito web o servizio online.

Su OVHcloud, la configurazione DNS di un nome a dominio si basa su tre elementi:

- i **server DNS**, che ospitano e diffondono le informazioni del tuo dominio;
- la **zona DNS**, il file che raccoglie tutti i tuoi record;
- i **record DNS**, ogni riga che associa un nome a un valore (indirizzo IP, server e-mail, testo, ecc.).

## Come funziona il DNS?

Dal tuo nome a dominio fino a ogni record, la risoluzione DNS segue una catena di quattro anelli.

<DnsChain />

### Il server DNS

I server DNS ospitano e diffondono su Internet le informazioni del tuo dominio. Quando un utente richiede il tuo sito, sono loro a rispondere indicando dove trovarlo. Per impostazione predefinita, il tuo dominio utilizza i server DNS di OVHcloud. [Scopri tutto sui server DNS](/guides/web-cloud/domains/dns-server-general-information).

<DnsServerIllustration />

### La zona DNS

La zona DNS è il file di configurazione associato ai tuoi server DNS. Raccoglie tutti i record del tuo dominio: è qui che aggiungi, modifichi o elimini le tue voci. [Sapere tutto sulla zona DNS](/guides/web-cloud/domains/dns-zone-general-information).

<DnsZoneIllustration />

### I record DNS

Ogni record è una riga della zona che associa un nome a un valore: un indirizzo IP, un server e-mail, del testo, ecc. Il suo tipo ne determina il ruolo, indicato di seguito dal colore. Seleziona quello da configurare per accedere alla guida corrispondente.
