## Obiettivo

L'opzione [DNS Anycast](/links/web/domains-options-anycast) accelera la risoluzione DNS del tuo nome di dominio in tutto il mondo. Non hai più bisogno di questa accelerazione o non desideri più rinnovarla alla scadenza?

**Questa guida ti mostra come disattivare l'opzione DNS Anycast del tuo nome di dominio dal tuo Spazio Cliente OVHcloud.**

## Prerequisiti

- Disporre di un [nome di dominio](/links/web/domains) OVHcloud.
- L'opzione DNS Anycast deve essere attiva sul nome di dominio interessato. Per verificarlo, consulta la nostra guida "[Attivare i DNS Anycast per il tuo dominio](/guides/web-cloud/domains/dns-anycast-enable)".
- Essere connesso al tuo Spazio Cliente OVHcloud.

## Procedura

:::info
La disattivazione non è immediata: l'opzione DNS Anycast resta attiva e funzionante fino alla sua data di scadenza. Non viene rinnovata e viene eliminata in tale data.
:::

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **4** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/#/web-domains/domain">Domini</ManagerLink>, poi seleziona il nome di dominio interessato.

    <img className="thumbnail" alt="Elenco dei nomi di dominio nello Spazio Cliente OVHcloud" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-names.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Una volta sul nome di dominio interessato, seleziona la scheda <code className="action">Server DNS</code>.

    <img className="thumbnail" alt="Scheda Server DNS di un nome di dominio" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Nella colonna di destra della pagina visualizzata, clicca sul pulsante <code className="action">Disattiva DNS Anycast</code>.

    <img className="thumbnail" alt="Pulsante Disattiva DNS Anycast nella scheda Server DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    La pagina visualizzata ricorda la funzione dell'opzione e la data in cui deve essere rinnovata automaticamente. Clicca sul pulsante <code className="action">Disattiva DNS Anycast</code>.

    <img className="thumbnail" alt="Pagina di disattivazione dell'opzione DNS Anycast" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns-page.png" loading="lazy" />

    Nella finestra di conferma visualizzata, clicca su <code className="action">Conferma</code> per convalidare la disattivazione del servizio DNS Anycast.

    <img className="thumbnail" alt="Finestra di conferma della disattivazione del servizio DNS Anycast" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/terminate-anycast-dns-confirm.png" loading="lazy" />
  </Tab>
</Tabs>

Una volta registrata la disattivazione, verificane la presa in carico dalla scheda <code className="action">Informazioni generali</code> del tuo nome di dominio: la sezione **Configurazione** indica lo stato dell'opzione DNS Anycast e la sua data di decorrenza.

:::info
Dopo la data di decorrenza della disattivazione, il tuo nome di dominio non utilizza più i server DNS Anycast. Tieni conto del tempo naturale di propagazione del servizio DNS, che può durare fino a 48 ore.
:::
