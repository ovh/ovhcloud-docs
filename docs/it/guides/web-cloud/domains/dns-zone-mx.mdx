## Obiettivo

Il record MX permette di collegare un nome di dominio al server della sua piattaforma di posta. È indispensabile perché il servizio email del mittente possa raggiungere quello del destinatario.

**Questa guida ti mostra come configurare un record MX per un nome di dominio in OVHcloud.**

## Prerequisiti

- Il nome di dominio in questione deve utilizzare la configurazione OVHcloud (ad esempio i server DNS di OVHcloud).

<Region zones={['eu']}>

- Disporre di una soluzione MX Plan (inclusa nelle soluzioni di [hosting Web](/links/web/hosting), [hosting gratuito](/links/web/domains-free-hosting) o MX Plan ordinati separatamente), una delle nostre [offerte di posta elettronica OVHcloud](/links/web/emails) o un servizio di posta esterna.

</Region>

<Region zones={['ca', 'apac']}>

- Disporre di una soluzione MX Plan (inclusa nelle soluzioni di [hosting Web](/links/web/hosting) o MX Plan ordinati separatamente), una delle nostre [offerte di posta elettronica OVHcloud](/links/web/emails) o un servizio di posta esterna.

</Region>

[[cpnav:web-domain-dns-zone]]

:::info
- Se il nome di dominio non utilizza i server DNS di OVHcloud, la modifica dei record MX deve essere eseguita dall'interfaccia del provider che gestisce la configurazione del nome di dominio.

- Se il nome di dominio è registrato presso OVHcloud, è possibile verificare se utilizza la nostra configurazione. A tal fine e se necessario, consulta la nostra guida "[Modificare i server DNS di un nome di dominio OVHcloud](/guides/web-cloud/domains/dns-server-edit)".

:::

## Procedura

### Informazioni sul ruolo dei record MX

Il record MX (**M**ail e**X**change) è un tipo di record DNS che determina quali server di posta in arrivo sono associati al nome di dominio.

Per comprenderne il funzionamento, utilizzeremo un esempio:

- L'indirizzo **sender@otherdomain.tld** invia un'email a **contact@domain.tld**.
- Il server di invio delle email (**Outgoing mail server**) interroga la zona DNS del nome di dominio **domain.tld** e legge i record **MX**.
- L'email viene trasmessa verso l'URL del record **MX** letto.

<Region zones={['eu']}>

- L'email viene inviata verso la destinazione **mx0.mail.ovh.net**, preceduta dal valore **0**. Questo valore corrisponde alla priorità: il valore più basso viene interrogato per primo e il valore più alto per ultimo. Ciò significa che la presenza di più record MX consente di compensare un'assenza di risposta dal server designato dal record con la priorità più bassa, passando ai server successivi in ordine di priorità.

</Region>

<Region zones={['ca', 'apac']}>

- L'email viene inviata verso la destinazione **mx0.mail.ovh.ca**, preceduta dal valore **0**. Questo valore corrisponde alla priorità: il valore più basso viene interrogato per primo e il valore più alto per ultimo. Ciò significa che la presenza di più record MX consente di compensare un'assenza di risposta dal server designato dal record con la priorità più bassa, passando ai server successivi in ordine di priorità.

</Region>

<img className="thumbnail" alt="email" src="/images/assets/schemas/emails/mx-dns-resolution.png" loading="lazy" />

È possibile configurare più record MX per uno stesso nome di dominio. È quindi necessario definire un numero di priorità per ciascuno di essi. I record MX vengono interrogati in ordine crescente, dal numero più basso a quello più alto, fino a ottenere una risposta dal server di posta in arrivo.

:::warning
In generale, **modificare i record MX nella zona DNS del nome di dominio è un'operazione delicata**: un'azione errata potrebbe rendere impossibile la ricezione delle email sugli indirizzi. Ti consigliamo di prestare la massima attenzione durante questa operazione.
In caso di dubbi, ti consigliamo di rivolgerti a un [provider specializzato](/links/partner).

:::

### Configurare un record MX in una zona DNS OVHcloud

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **5** passaggi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina <ManagerLink to="/beta/#/web-cloud/domains/listing">Domini e DNS</ManagerLink>, poi scegli il dominio interessato.

    <img className="thumbnail" alt="Pagina Domini e DNS ed elenco dei nomi di dominio dell'account" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Clicca sulla scheda <code className="action">Zona DNS</code>. I tuoi record sono elencati in una tabella, con una riga per record.

    <img className="thumbnail" alt="Scheda Zona DNS di un dominio e tabella dei record" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 3">
    Verifica innanzitutto se esistono già record MX: clicca su <code className="action">Filtri</code> sopra la tabella, poi seleziona <code className="action">MX</code> nell'elenco **Tipo di record**, oppure utilizza il campo **Cerca**.

    <img className="thumbnail" alt="Zona DNS filtrata sui record MX" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-mx.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 4">
    - **Per modificare un record MX esistente**, sulla relativa riga, clicca sul pulsante <code className="action">⋮</code> della colonna **Azioni**, poi su <code className="action">Modifica</code>. La riga si espande in un modulo di modifica.

      <img className="thumbnail" alt="Menu delle azioni di un record MX della zona DNS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/mx-row-actions.png" loading="lazy" />

    - **Per aggiungere un nuovo record MX**, clicca su <code className="action">Aggiungi una voce</code> sopra la tabella. Nel modulo che si apre, seleziona `MX — Server di posta` nell'elenco **Tipo**.

      <img className="thumbnail" alt="Elenco Tipo del modulo Aggiungi una voce, tipo MX" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-mx.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 5">
    Compila i campi in base alla soluzione email che utilizzi:

    - **Se disponi di una soluzione email OVHcloud**, utilizza i valori forniti nella sezione "[Valori della configurazione MX di OVHcloud](#mxovhcloud)" qui sopra: `@` nel campo **Sottodominio**, poi la **Priorità** e la **Destinazione (server di posta)** di ciascun record.
    - **Se utilizzi un'altra soluzione email**, segui le indicazioni fornite dal provider del tuo servizio di posta.

    Inserisci il **TTL** (lascialo su `Predefinito` o scegli `Personalizzato`), poi clicca su <code className="action">Aggiungi</code> (o su <code className="action">Modifica</code> per un record esistente). Il modulo ricorda che la modifica manuale dei campi MX può causare la perdita di email: verifica i valori prima di confermare.

    <img className="thumbnail" alt="Modulo Aggiungi una voce della zona DNS, record MX verso mx0.mail.ovh.net" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-mx-record.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
La propagazione delle modifiche potrebbe richiedere da 4 a 24 ore.

:::
