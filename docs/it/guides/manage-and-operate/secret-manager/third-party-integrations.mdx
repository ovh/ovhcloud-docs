## Obiettivo

OVHcloud mantiene integrazioni dedicate per alcune applicazioni di terze parti che sincronizzano o utilizzano i secret archiviati in Secret Manager. Questa pagina di riferimento elenca tali integrazioni e rimanda alla documentazione necessaria per configurarle.

**Questa guida elenca le applicazioni di terze parti integrate ufficialmente con OVHcloud Secret Manager e rimanda alla relativa documentazione.**

## Prerequisiti

- Disporre di un [account cliente OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- Disporre di un [dominio OKMS](/guides/manage-and-operate/kms/quick-start) o aver [creato un primo secret](/guides/manage-and-operate/secret-manager/secret-manager-ui).

## Procedura

### Integrazioni ufficiali di terze parti

La tabella seguente viene aggiornata a ogni nuova integrazione mantenuta da OVHcloud. Sono elencati solo i prodotti di terze parti per i quali OVHcloud mantiene un'integrazione.

| Prodotto di terze parti | Tipo di integrazione | Plugin | Documentazione |
| :---------------------- | :------------------- | :------ | :------------- |
| **External Secrets Operator** (provider Vault) | Sincronizzazione dei secret Kubernetes tramite l'API Vault KV2 su OKMS | [External Secrets Operator](https://github.com/external-secrets/external-secrets) | [ESO — provider HashiCorp Vault](https://external-secrets.io/latest/provider/hashicorp-vault/)<br/>[Utilizzare Kubernetes External Secrets Operator con Secret Manager](/guides/manage-and-operate/secret-manager/external-secret-operator) |
| **External Secrets Operator** (provider OVHcloud) | Provider OKMS nativo (`provider.ovh`, ESO ≥ v2.3.0) | [External Secrets Operator](https://github.com/external-secrets/external-secrets) | [ESO — provider OVHcloud](https://external-secrets.io/latest/provider/ovhcloud/)<br/>[Discover the ESO OVHcloud Provider](https://blog.ovhcloud.com/en/posts/discover-the-external-secret-operator-eso-ovhcloud-provider-to-manage-your-kubernetes-secrets/) |
| **Infisical** | Sincronizzazione dei secret da Infisical verso un dominio OKMS | [Infisical](https://github.com/Infisical/infisical) | [Infisical — OVHcloud connection](https://infisical.com/docs/integrations/app-connections/ovh)<br/>[Infisical — OVHcloud sync](https://infisical.com/docs/integrations/secret-syncs/ovh) |

:::info
L'[API compatibile HashiCorp Vault KV2](/guides/manage-and-operate/secret-manager/kv2-api) è una superficie API OVHcloud, non un'integrazione di prodotto di terze parti. Pertanto non figura in questa tabella.
:::
