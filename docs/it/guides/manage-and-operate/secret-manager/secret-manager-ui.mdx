## Obiettivo

L'obiettivo di questa guida è presentare l'utilizzo del Secret Manager tramite la console OVHcloud.

## Prerequisiti

- Disporre di un [account cliente OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- Per accedere ai secret tramite l'API REST o l'API compatibile HashiCorp Vault KV2, configura un [metodo di autenticazione](/guides/manage-and-operate/kms/okms-authentication-methods) per il tuo dominio OKMS (token di accesso personale, account di servizio o certificato di accesso).

[[cpnav:security-secret-manager]]

## Procedura

### Descrizione

Il Secret Manager è un prodotto che ti permette di memorizzare in modo sicuro le credenziali, le chiavi API, le chiavi SSH o qualsiasi altro tipo di secret necessario al funzionamento delle tue applicazioni.

Un secret è una raccolta di una o più coppie chiave-valore raggruppate all'interno di una versione.
Ogni modifica di un secret comporta la creazione di una nuova versione di tale secret, consentendo di risalire nella cronologia delle modifiche del secret.

### Creare un secret

Nella console OVHcloud, i secret si gestiscono in Key & Secret Manager. Nel menu a sinistra, apri <code className="action">Sicurezza</code> e clicca su <code className="action">Key & Secret Manager</code>. Ogni dominio OKMS dispone di una scheda <code className="action">Secrets</code>, che elenca i secret memorizzati in tale dominio.

<img className="thumbnail" alt="Scheda Secrets di un dominio OKMS con il pulsante Creare un secret" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secrets-tab.png" loading="lazy" />

Per creare un secret, clicca su <code className="action">Creare un "secret"</code>.

Il modulo di creazione non propone alcuna regione: il secret viene creato nel dominio OKMS selezionato nell'elenco **Dominio OKMS**, e quindi nella regione di tale dominio. Seleziona il dominio corretto prima di cliccare su <code className="action">Creare un "secret"</code>.

:::info
Se non disponi ancora di un dominio OKMS nella regione in cui desideri creare il secret, creane prima uno: apri l'elenco **Dominio OKMS**, clicca su <code className="action">Crea un dominio</code> e scegli la regione.
La creazione del dominio può richiedere qualche minuto.
:::


Indica quindi il **Path** del secret, ad esempio **prod/database/MySQL**. Questo Path serve a organizzare i secret in modo gerarchico.

Poi indica il contenuto del secret nella sezione **Configurazione dei valori**. Il secret contiene un elenco di coppie chiave-valore. Per impostazione predefinita, queste si inseriscono una alla volta nella vista **Chiave-valore** (<code className="action">Aggiungi una chiave/valore</code> aggiunge una riga). Nella vista **JSON**, puoi inserirle in formato JSON:

```json
{
    "login": "admin",
    "password": "my_secret_password"
}
```

<img className="thumbnail" alt="Pagina di creazione di un secret con le sezioni Path e Configurazione dei valori" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/create-secret-form.png" loading="lazy" />

:::info
Non c'è alcun limite al numero di coppie chiave-valore di un secret, tuttavia la dimensione totale dei dati non deve superare i 64 KB.
:::


Una volta creato il secret, questo appare nell'elenco dei secret della scheda **Secrets** del dominio OKMS.

### Gestire i secret

Una volta creato un secret, l'elenco dei secret viene visualizzato nella scheda **Secrets** del dominio OKMS, nella console OVHcloud.
Per visualizzare i secret di un altro dominio OKMS, selezionalo nell'elenco **Dominio OKMS** sopra le schede, in cui i tuoi domini sono raggruppati per regione.

Puoi accedere alla configurazione del secret cliccando sul suo Path nell'elenco dei secret per visualizzarne il contenuto, creare una nuova versione o eliminarlo.

La dashboard del secret mostra diverse informazioni, come le informazioni generali e i parametri che si applicano al secret:

- **Numero massimo di versioni**: Oltre il valore indicato, la versione più vecchia viene eliminata.
- **Periodo di validità di una versione**: Oltre la durata indicata, la versione viene disattivata.
- **CAS (Check-And-Set Version Control)**: Se attivato, devi sempre specificare il numero della versione attuale durante le modifiche.

<img className="thumbnail" alt="Dashboard del secret con le sezioni Valori, Informazioni generali e Configurazione" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secret-dashboard.png" loading="lazy" />

#### Accedere al contenuto di un secret

Un utente che dispone dei diritti IAM necessari può accedere al contenuto di un secret. Configura l'autenticazione e le policy IAM come descritto in [Metodi di autenticazione OKMS](/guides/manage-and-operate/kms/okms-authentication-methods).

:::info
I diritti per elencare una versione (**okms:apiovh:secret/get**) sono diversi dal diritto per recuperare il contenuto di tale versione (**okms:apiovh:secret/version/getData**).
:::


A tale scopo, clicca su <code className="action">Rivelare il valore</code> nella sezione **Valori** della dashboard del secret.

La sezione **Valori** si espande e mostra il contenuto della versione più recente del secret, sotto forma di coppie chiave-valore o in formato JSON. Ogni valore può essere copiato.

<img className="thumbnail" alt="Sezione Valori che mostra le coppie chiave-valore della versione attuale" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secret-values-revealed.png" loading="lazy" />

Un selettore permette di navigare tra le diverse versioni del secret e di consultare lo stato della versione selezionata.
Se la versione è disattivata o eliminata, non viene visualizzato alcun valore.

#### Gestire le versioni

Per accedere alle versioni di un secret, clicca sulla scheda <code className="action">Versioni</code>. Questa elenca tutte le versioni del secret, con il numero, la data di creazione, la data di scadenza e lo stato di ciascuna.
Ogni modifica di un secret comporta la creazione di una nuova versione.

<img className="thumbnail" alt="Scheda Versioni che elenca le versioni di un secret con il relativo stato" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/secret-versions.png" loading="lazy" />

Una versione può essere:

- Attiva: Il valore di questa versione è accessibile.
- Disattivata: Il valore di questa versione è ancora presente nel sistema ma non è più accessibile finché la versione non viene riattivata.
- Eliminata: Il valore di questa versione non è più presente nel sistema e non può più essere ripristinato.

Per ogni versione, clicca su <code className="action">Rivelare la versione</code> per visualizzarne il valore. Il pulsante `⋮` apre un menu che permette di disattivare (<code className="action">Disattivare</code>) o riattivare (<code className="action">Riattivare</code>) la versione, oppure di eliminarla (<code className="action">Eliminare</code>).

Una versione eliminata dal parametro **Numero massimo di versioni** non appare più nell'elenco delle versioni.

### Gestire il dominio OKMS

Il dominio OKMS del Secret Manager è condiviso con il dominio OKMS del Key Management Service.
La creazione o l'eliminazione di un dominio OKMS ha quindi conseguenze su entrambi i prodotti.

Puoi modificare la configurazione dei secret del dominio OKMS dalla sua scheda **Panoramica**, nella sezione **Configurazione dei Secrets** (<code className="action">Modifica</code>).

#### Caso di più domini OKMS

In una stessa regione possono esistere più domini OKMS. Il dominio OKMS si sceglie in anticipo, nell'elenco **Dominio OKMS** sopra le schede, che raggruppa i tuoi domini per regione. I secret che visualizzi o crei appartengono al dominio selezionato in questo elenco: la creazione di un secret non prevede alcun passaggio di selezione aggiuntivo.

<img className="thumbnail" alt="Elenco dei domini OKMS con i domini raggruppati per regione e la voce Crea un dominio" src="/images/manage-and-operate/secret-manager/secret-manager-ui/console/okms-domain-switcher.png" loading="lazy" />

Per aggiungere un dominio OKMS in una regione, clicca su <code className="action">Crea un dominio</code> in cima a questo elenco, quindi scegli la regione.

### Utilizzare il Secret Manager tramite API

Il Secret Manager è accessibile tramite due set di API differenti. Entrambi manipolano gli stessi oggetti: un secret creato da uno dei metodi è accessibile dall'altro.

Prima di chiamare l'una o l'altra API, configura un [metodo di autenticazione](/guides/manage-and-operate/kms/okms-authentication-methods) e la [policy IAM](/guides/manage-and-operate/kms/okms-authentication-methods#iam-rights-for-okms) richiesta sul tuo dominio OKMS. Per l'utilizzo dell'API REST, si consiglia un token di accesso personale (PAT) o un account di servizio.

- Un'[API REST](/guides/manage-and-operate/secret-manager/rest-api) simile agli standard delle API di OVHcloud.
- Un'[API compatibile HashiCorp Vault KV2](/guides/manage-and-operate/secret-manager/kv2-api) che offre compatibilità con le applicazioni già compatibili con HashiCorp Vault KV2.
