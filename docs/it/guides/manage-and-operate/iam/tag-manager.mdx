## Obiettivo

In questa guida scoprirai come assegnare e gestire i tag sui tuoi prodotti OVHcloud e come utilizzarli nelle policy IAM.

## Prerequisiti

- Disporre di un [account cliente OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation).

[[cpnav:iam-tag-management-console]]

## Procedura

### Gestire i tag dalla console OVHcloud

Puoi gestire i tag dei tuoi prodotti OVHcloud tramite l'interfaccia generale di gestione dei tag oppure tramite le interfacce dedicate all'interno dei prodotti.

I tag sono metadati sotto forma di coppie chiave-valore aggiunti alle risorse OVHcloud, che possono essere utilizzati nelle policy IAM o per classificare le risorse.

#### Tag manager

Il <ManagerLink to="/beta/#/customer/iam/tag-manager">Tag manager</ManagerLink> è l'interfaccia che ti permette di gestire i tuoi tag su tutti i tuoi prodotti OVHcloud.

La pagina mostra tutti i tag attualmente applicati alle tue risorse.

<img className="thumbnail" alt="Pagina Tag manager con il menu a tendina Tipo di tag e la colonna Tipo di tag" src="/images/manage-and-operate/iam/iam-tag-manager/console/tag-manager-01.png" loading="lazy" />

Per ogni tag, l'elenco indica il numero di risorse associate a questo tag e il tipo di tag.

Esistono tre tipi di tag:

- Personalizzato: creato e gestito da te.
- Predefinito: creato da OVHcloud; spetta a te assegnare questo tipo di tag alle tue risorse.
- Sistema: creato e assegnato automaticamente da OVHcloud alle tue risorse (non può essere eliminato).

Di default, il menu a tendina **Tipo di tag** è impostato su <code className="action">Tutti i tipi</code> e la pagina mostra anche i tag predefiniti non assegnati. Per restringere l'elenco, seleziona <code className="action">Personalizzato</code>, <code className="action">Predefinito</code>, <code className="action">Sistema</code> o <code className="action">Non assegnato</code> in questo menu a tendina.

Clicca su un tag per aprirne i dettagli, con l'elenco delle risorse a cui è assegnato.

<img className="thumbnail" alt="Pagina di un tag con i pulsanti Assegna alle risorse e Rimuovi tag" src="/images/manage-and-operate/iam/iam-tag-manager/console/tag-manager-02.png" loading="lazy" />

Puoi quindi assegnare questo tag ad altre risorse con il pulsante <code className="action">Assegna alle risorse</code>. Viene allora visualizzato l'elenco di tutte le risorse dell'account, che consente una selezione multipla.

Un campo di ricerca ti aiuta a trovare le risorse.

Al contrario, per rimuovere il tag da alcune risorse, selezionale nei dettagli del tag, poi clicca su <code className="action">Rimuovi tag</code>.

#### Dashboard del prodotto

Per alcuni prodotti OVHcloud è stata aggiunta un'interfaccia che permette di gestire i tag direttamente dalla dashboard di gestione della risorsa.

L'interfaccia di gestione dei tag permette di aggiungere o rimuovere tag dalla risorsa.

Puoi selezionare uno o più tag dall'elenco dei tag predefiniti oppure inserire i tuoi tag digitando direttamente le chiavi e i valori nei campi.

### Gestire i tag tramite API

La gestione dei tag è centralizzata in un'unica API per tutti i prodotti OVHcloud:

| **Metodo** |              **Percorso**              |          **Descrizione**          |
| :--------: | :------------------------------------: | :-------------------------------: |
|    POST    |    /iam/resource/&#123;resourceURN&#125;/tag    |   Aggiungere un tag a una risorsa   |
|    DEL     | /iam/resource/&#123;resourceURN&#125;/tag/&#123;key&#125; | Rimuovere un tag da una risorsa |

Il tag deve essere indicato nel seguente formato:

```json
{
  "key": "environment",
  "value": "production"
}
```

### Utilizzare i tag nelle policy IAM

I tag possono essere utilizzati come condizioni nelle policy IAM tramite la condizione `resource.Tag(tag_key)`.

Ad esempio, la seguente policy concede i diritti su tutti i VPS con il tag `Environment:Production`:

```json
{
  "conditions": {
    "conditions": [
      {
        "operator": "MATCH",
        "values": {
          "resource.Tag(Environment)": "Production"
        }
      }
    ],
    "operator": "AND"
  },
  "description": "Give access to VPS with tag Environment:Production",
  "identities": [
    "urn:v1:eu:identity:group:aa1-ovh/devs"
  ],
  "name": "vps-production",
  "permissions": {
    "allow": [
      {
        "action": "vps:apiovh:*"
      }
    ]
  },
  "resources": [
    {
      "urn": "urn:v1:eu:resource:vps:*"
    }
  ]
}
```
