## Obiettivo

Le coppie di chiavi vengono utilizzate per autenticare le connessioni SSH tra gli host, ad esempio tra il client locale del computer e un server remoto. Durante la reinstallazione di un server dedicato o di un VPS dalla console OVHcloud, è possibile aggiungere una chiave pubblica al sistema operativo. L’archiviazione di chiavi SSH pubbliche nella console facilita questo processo.

**Questa guida ti mostra come archiviare le tue chiavi SSH pubbliche nella console OVHcloud.**

## Prerequisiti

- Un [server dedicato](/links/bare-metal/bare-metal) o un [VPS](/links/bare-metal/vps) nel tuo account OVHcloud

:::info
Per maggiori informazioni sull’utilizzo delle chiavi SSH con i servizi [Public Cloud](/links/public-cloud/public-cloud), consulta la nostra guida dedicata:

[Come creare chiavi SSH con OpenSSH per le istanze Public Cloud](/guides/public-cloud/compute/creating-ssh-keys)

:::

## Procedura

Se non hai ancora creato coppie di chiavi SSH, consulta le nostre guide:

- [Creare e utilizzare chiavi SSH](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutorial - Come utilizzare PuTTY per connessioni SSH e autenticazione](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

<img className="thumbnail" alt="Identity and Access Management group of the Console left menu, with the SSH keys entry" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/sidebar-iam-ssh-keys.png" loading="lazy" />

Nel menu a sinistra della console OVHcloud, apri **Gestione di identità e accessi** e clicca su <code className="action">Chiavi SSH</code>.

<img className="thumbnail" alt="SSH keys page with the Add an SSH key button above the list of keys" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-button.png" loading="lazy" />

Apri il menu <code className="action">Aggiungi una chiave SSH</code> sopra la lista e seleziona <code className="action">Dedicated</code>.

<img className="thumbnail" alt="Add an SSH key menu open, showing the Dedicated and Public Cloud options" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-menu.png" loading="lazy" />

Nella finestra **Aggiungi una chiave SSH**, copia l'intera stringa della chiave pubblica e incollala nel primo campo, **Chiave pubblica**. Incolla solo la chiave pubblica (il contenuto del tuo file `.pub`), mai la chiave privata.  
Inserisci un nome per la chiave nel secondo campo, **Nome**, per poterla riconoscere (ad esempio, il nome del tuo computer).

<img className="thumbnail" alt="Add an SSH key window with the Public key and Name fields and the Add button" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-dedicated-window.png" loading="lazy" />

Clicca su <code className="action">Aggiungi</code>.

La chiave sarà disponibile in caso di reinstallazione di un server dedicato o di un VPS dalla console OVHcloud.
