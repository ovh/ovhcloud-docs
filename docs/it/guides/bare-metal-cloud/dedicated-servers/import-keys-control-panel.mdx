## Obiettivo

Le coppie di chiavi vengono utilizzate per autenticare le connessioni SSH tra gli host, ad esempio tra il client locale del computer e un server remoto. Durante la reinstallazione di un server dedicato o di un VPS dalla console OVHcloud, è possibile aggiungere una chiave pubblica al sistema operativo. L’archiviazione di chiavi SSH pubbliche nella console OVHcloud facilita questo processo.

**Questa guida ti mostra come archiviare le tue chiavi SSH pubbliche nella console OVHcloud.**

## Prerequisiti

- Un [server dedicato](/links/bare-metal/bare-metal) o un [VPS](/links/bare-metal/vps) nel tuo account OVHcloud

## Procedura

Se non hai ancora creato coppie di chiavi SSH, consulta le nostre guide:

- [Creare e utilizzare chiavi SSH](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutorial - Come utilizzare PuTTY per connessioni SSH e autenticazione](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

La pagina **Chiavi SSH** elenca le chiavi salvate nel tuo account.

Clicca su <code className="action">Aggiungi una chiave SSH</code> e seleziona <code className="action">Dedicated</code> nel menu.

Nella finestra **Aggiungi una chiave SSH**, copia l'intera stringa della chiave pubblica e incollala nel campo **Chiave pubblica**, poi inserisci un'etichetta per la chiave nel campo **Nome**.

Clicca su <code className="action">Aggiungi</code>.

La chiave è ora disponibile durante la reinstallazione di un server dedicato o di un VPS nella console OVHcloud.

Puoi anche aggiungere una chiave dalla pagina di un server dedicato: nella sua scheda <code className="action">Server</code>, clicca su <code className="action">Add SSH key</code> nel blocco **SSH keys** della sezione **Server connection**. Nella finestra **Add SSH key**, inserisci un **Key name**, incolla la chiave nel campo **Public key** e clicca su <code className="action">Aggiungi una chiave SSH</code>. La chiave viene salvata nel tuo account, come una chiave aggiunta dalla pagina **Chiavi SSH**.
