## Obiettivo

Il backup di un server Bare Metal con Veeam Enterprise richiede che diverse applicazioni e servizi funzionino insieme. La procedura può inoltre variare in base alla configurazione e alle preferenze.

**Questa guida ti mostra come preparare il backup del tuo server Bare Metal con Veeam Backup and Replication (Enterprise).**

## Prerequisiti

- Disporre di un [server Bare Metal OVHcloud](/links/bare-metal/bare-metal)
- Disporre di una soluzione di backup [Veeam Enterprise](/links/hosted-private-cloud/veeam-enterprise)
- Disporre di un servizio [OVHcloud Object Storage](/links/public-cloud/object-storage) (opzionale)

[[cpnav:publiccloud-object-storage-console]]

## Procedura

### Installazione del server dedicato

Il tuo server Bare Metal OVHcloud deve essere installato e configurato.

Consulta le nostre [guide introduttive ai server dedicati](/guides/bare-metal-cloud/dedicated-servers/getting-started-with-dedicated-server).

È inoltre possibile configurare il server dedicato per utilizzare una rete privata seguendo gli step di [questa guida](/guides/bare-metal-cloud/dedicated-servers/vrack-configuring-on-dedicated-server).

### Configurazione del server di backup Veeam Enterprise

Scarica, installa e attiva la licenza del tuo server di backup Veeam Enterprise seguendo la nostra guida "[Installare Veeam Backup & Replication](/guides/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication)".

A partire da questo step, puoi continuare la lettura di questa guida per scoprire come configurare Object Storage come repository di backup oppure passare direttamente alla sezione [Per saperne di più](#gofurther).

### Configurazione dell'Object Storage

Puoi creare e configurare l'Object Storage nell'universo <code className="action">Public Cloud</code> della console OVHcloud, nella sezione <code className="action">Object Storage</code> del tuo progetto Public Cloud.

Se non disponi ancora di un progetto Public Cloud nel tuo account OVHcloud, consulta la nostra guida [Creare il primo progetto Public Cloud](/guides/public-cloud/cross-functional/create-a-public-cloud-project).

[Crea un container Object Storage](/guides/storage-and-backup/object-storage/s3-getting-started-with-object-storage) con una delle soluzioni **Object Storage (Standard o High Performance)**. Si consiglia la soluzione Standard, poiché il nostro caso d'uso (eseguire un backup) generalmente non richiede uno storage High Performance.

:::info
Al momento dell'ordine di un container Object Storage presso OVHcloud, seleziona unicamente l'**Object Storage Standard** o l'**Object Storage High Performance**. Questi container supportano pienamente il protocollo Amazon S3<sup>1</sup> e sono progettati per essere utilizzati come repository di backup.

:::


Assegna all'utente Object Storage i permessi sul container copiando e incollando il codice seguente in un file JSON.

```json
{
  "Statement":[
    {
      "Action":
         [
             "s3:GetObject",
             "s3:PutObject",
             "s3:DeleteObject",
             "s3:ListBucket",
             "s3:ListMultipartUploadParts",
             "s3:ListBucketMultipartUploads",
             "s3:AbortMultipartUpload",
             "s3:GetBucketLocation"
          ],
      "Effect":"Allow",
      "Resource":
          [
              "arn:aws:s3:::<container name>",
              "arn:aws:s3:::<container name>/*"
          ],
      "Sid":"RWContainer"
     }
  ]
}
```

Assicurati di sostituire `container name` con il nome effettivo del tuo container Object Storage.

Nella scheda <code className="action">Utenti</code> della pagina **Object Storage**, clicca sul pulsante <code className="action">⋮</code> nella colonna **Azioni** dell'utente Object Storage e scegli <code className="action">Importa una policy</code>.

Nella finestra **Importa una policy**, seleziona il file JSON appena modificato e clicca su <code className="action">Importare</code>. La policy importata sostituisce la policy attuale dell'utente: se questo utente dispone già di una policy, scaricala prima con <code className="action">Scarica la policy</code> (stesso menu) e aggiungi questa dichiarazione al suo elenco `Statement` prima di importarla.

### Configurazione del repository Object Storage in Veeam Enterprise

Dall'applicazione Veeam, seleziona <code className="action">Backup Infrastructure</code>, <code className="action">Backup Repositories</code> e <code className="action">Add Repository</code>.

<img className="thumbnail" alt="Veeam - aggiungere un repository" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-02.png" loading="lazy" />

Seleziona <code className="action">Object storage</code> come tipo di repository.

<img className="thumbnail" alt="Veeam - Object Storage" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-03.png" loading="lazy" />

Seleziona <code className="action">S3 Compatible</code>.

<img className="thumbnail" alt="Veeam - compatibile S3" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-04.png" loading="lazy" />

Assegna un nome (**Name**) al nuovo repository e clicca su <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - nome del repository" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-05.png" loading="lazy" />

Inserisci le informazioni **Service point** (Endpoint) e **Region** del tuo servizio di storage Object Storage.

> Queste informazioni sono disponibili nell'universo <code className="action">Public Cloud</code> della console OVHcloud.
> Clicca su <code className="action">Object Storage</code> e, nella scheda <code className="action">Container</code>, clicca sul nome del tuo container, quindi apri la sua scheda <code className="action">Panoramica</code>. La **Region** è indicata nella sezione **Informazioni generali** (oltre che nella colonna **Region** dell'elenco dei container), e l'**Endpoint** nella sezione **Dettagli di connessione**.

<img className="thumbnail" alt="Veeam - endpoint del servizio e regione" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-08.png" loading="lazy" />

Clicca su <code className="action">Add</code> per inserire le tue credenziali. Inserisci la tua **Access key** e la tua **Secret key**, quindi clicca su <code className="action">OK</code>.

> Queste informazioni sono disponibili nella console OVHcloud, nella scheda <code className="action">Utenti</code> della pagina **Object Storage**. La **Chiave di accesso** (Access key) è indicata nella colonna **Chiave di accesso** dell'elenco degli utenti.
> Per ottenere la **Chiave segreta** (Secret key), clicca sul pulsante <code className="action">⋮</code> nella colonna **Azioni** dell'utente e seleziona <code className="action">Mostra la chiave segreta</code>. La chiave viene visualizzata nella finestra **Credenziali S3**.

<img className="thumbnail" alt="Veeam - chiavi" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-10.png" loading="lazy" />

Clicca su <code className="action">Browse...</code> per selezionare il **Bucket**.

<img className="thumbnail" alt="Veeam - bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-11.png" loading="lazy" />

Seleziona il bucket e clicca su <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-12.png" loading="lazy" />

Clicca su <code className="action">Browse...</code> per selezionare la cartella (**Folder**).

<img className="thumbnail" alt="Veeam - cartella" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-13.png" loading="lazy" />

Clicca su <code className="action">New Folder</code>, inserisci un nome per la cartella, selezionala e clicca su <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - cartella" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-14.png" loading="lazy" />

Nello step di montaggio del server (Mount Server), clicca su <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - Mount Server" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-15.png" loading="lazy" />

Nella schermata di riepilogo (Review), clicca su <code className="action">Apply</code>.

<img className="thumbnail" alt="Veeam - verifica" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-16.png" loading="lazy" />

Una volta completati correttamente i processi, clicca su <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - fine del processo" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-17.png" loading="lazy" />

Verifica la pagina di riepilogo (Summary) e clicca su <code className="action">Finish</code>.

<img className="thumbnail" alt="Veeam - riepilogo" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-18.png" loading="lazy" />

I repository di backup dovrebbero ora avere un aspetto simile a questo:

<img className="thumbnail" alt="Veeam - repository" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-19.png" loading="lazy" />

A questo punto puoi effettuare un backup con Veeam Enterprise.
