## Prerequisiti

:::warning
Le operazioni descritte in questa guida richiedono l'eliminazione del RAID esistente. Questo significa che tutti i dati presenti andranno persi. Assicurati di effettuare un backup dei tuoi dati prima di procedere.
Questa guida è destinata a utenti esperti.
:::


Per creare il partizionamento, è necessario creare nuovi volumi RAID sulla scheda. Per farlo, è necessario:

- Disporre di un server con RAID hardware (scheda LSI MegaRaid).
- Disporre di almeno due dischi identici (in questa guida utilizziamo un server con 3 dischi).
- Avere accesso al Rescue mode.

## Procedura

### Elencare i volumi RAID
Per prima cosa, è necessario elencare i volumi RAID per poterli poi eliminare.

Per farlo, utilizziamo il comando seguente: <code className="action">MegaCli -LDInfo -Lall -aAll</code>

Esempio:

```sh
# root@rescue:~# MegaCli -LDInfo -Lall -aAll
 
Adapter 0 -- Virtual Drive Information:
Virtual Drive: 0 (Target Id: 0)

Name                 :
RAID Level           : Primary-5, Secondary-0, RAID Level Qualifier-3
Size                 : 3.637 TB
Sector Size          : 512
Is VD emulated       : No
Parity Size          : 1.818 TB
State                : Optimal
Strip Size           : 256 KB
Number Of Drives     : 3
Span Depth           : 1
Default Cache Policy : WriteBack, ReadAhead, Direct, No Write Cache if Bad BBU
Current Cache Policy : WriteBack, ReadAhead, Direct, No Write Cache if Bad BBU

```
Notiamo che attualmente sul server è presente un solo volume RAID, a cui corrisponde il **Virtual Drive** 0.

### Eliminare i RAID
Ora possiamo eliminare i volumi RAID esistenti per poi creare i nuovi volumi RAID.

Per farlo, utilizziamo il comando seguente, da adattare con il numero del **Virtual Drive** recuperato in precedenza.

<code className="action">MegaCli -CfgLDDel -Lx -a0</code>

Il numero del **Virtual Drive**

Esempio:

```sh
# root@rescue:~# MegaCli -CfgLDDel -L0 -a0
 
Adapter 0: Deleted Virtual Drive-0(target id-0)
 
Exit Code: 0x00
```

:::info
Se il tuo server dispone già di più RAID, ripeti l'operazione con il numero di ciascun Virtual Drive.
:::


### Recuperare gli ID dei dischi
Ora recuperiamo l'**Enclosure ID** e lo **SlotID** dei dischi presenti sul server per creare i nuovi volumi RAID.

Per farlo, utilizziamo il comando seguente: <code className="action">MegaCli -PdList -aALL | egrep -i "Adapter|Slot|Enclosure Device"</code>

Esempio:

```sh
# root@rescue:~# MegaCli -PdList -aALL | egrep -i "Adapter|Slot|Enclosure Device"
Adapter #0
Enclosure Device ID: 252
Slot Number: 0
Enclosure Device ID: 252
Slot Number: 1
Enclosure Device ID: 252
Slot Number: 2
```
Notiamo di avere 3 dischi, i cui **Enclosure ID** e **SlotID** sono rispettivamente 252:0, 252:1 e 252:2.

### Creare i nuovi volumi RAID
Per prima cosa, creiamo il primo volume RAID, che sarà utilizzato per il sistema operativo.

Utilizziamo quindi il comando seguente: <code className="action">MegaCli -CfgLdAdd -rX[EncID:SlotID,EncID:SlotID,...] -szYYYYY -a0</code>

Corrisponde al RAID desiderato (0, 1, 5 o 6)

Corrisponde agli Enclosure ID dei dischi recuperati in precedenza

Corrisponde agli SlotID dei dischi recuperati in precedenza

Corrisponde alla dimensione del primo disco virtuale

Nel nostro esempio, creiamo un RAID 5 sui 3 dischi, con una dimensione di 200 GB per il sistema operativo.

:::info
Ti consigliamo di prevedere un po' di spazio in più per ottenere una partizione della dimensione minima desiderata, poiché la configurazione occupa un po' di spazio.
:::


```sh
# root@rescue:~# MegaCli -CfgLdAdd -r5[252:0,252:1,252:2] -sz204800 -a0
 
Adapter 0: Created VD 0
 
Adapter 0: Configured the Adapter!!
 
Exit Code: 0x00 
```
Il primo volume RAID è stato creato. Ora non resta che assegnare lo spazio disponibile rimanente.

Creiamo quindi un secondo volume RAID con il comando seguente: <code className="action">MegaCli -CfgLdAdd -rX[EncID:SlotID,EncID:SlotID,...] -a0</code>

Corrisponde al RAID desiderato (0, 1, 5 o 6)

Corrisponde agli Enclosure ID dei dischi recuperati in precedenza

Corrisponde agli SlotID dei dischi recuperati in precedenza

Esempio:

```sh
# root@rescue:~# MegaCli -CfgLdAdd -r5[252:0,252:1,252:2] -a0
 
Adapter 0: Created VD 1
 
Adapter 0: Configured the Adapter!!
 
Exit Code: 0x00 
```
Fatto. Non resta che verificare i volumi RAID.

### Installare Windows dalla console OVHcloud
Infine, accedi alla console OVHcloud per installare Windows sul tuo server.

Seleziona la casella <code className="action">Personalizza la configurazione delle partizioni</code> e modifica lo schema di partizione attuale per specificare solo il disco C, con una dimensione massima di 200 GB.

Una volta installato il sistema, accedi al tuo sistema Windows, apri l'utilità <code className="action">Gestione disco</code> e partiziona il secondo disco virtuale (corrispondente al secondo RAID, visualizzato come "Non allocato") in formato GPT.
