**Scopri cosa succede quando la protezione Anti-Hack di OVHcloud si attiva sul tuo Server dedicato o sul tuo VPS.**

## Prerequisiti

- un Server dedicato o un VPS compromesso

## Informazioni Anti-Hack

### Server dedicato

Quando la protezione Anti-Hack viene attivata sul tuo Server dedicato, nella <ManagerLink to="/">console OVHcloud</ManagerLink> viene visualizzato un messaggio: "*Il tuo server è stato compromesso. Contatta il nostro team di assistenza per ricevere istruzioni sulla procedura da seguire.*"

In base alla criticità della protezione Anti-Hack attivata da OVHcloud, le seguenti azioni saranno consentite/richieste per ripristinare il servizio completo sul server.

| Stato | Azioni previste |
| ------ | ----------------- |
| Compromesso | Riavviare il server o chiedere a OVHcloud di reinstallarlo |
| CompromessoBloccato | Recuperare i dati via FTP sul server avviato in modalità Rescue FTP |

<img className="thumbnail" alt="informazioni antihack SD" src="/images/bare-metal-cloud/dedicated-servers/anti-hack-dedicated-vps/hacked-service.png" loading="lazy" />

Se il tuo server viene messo in modalità Rescue FTP, OVHcloud aprirà anche un ticket di assistenza a tuo nome con il seguente contenuto:

>
> Gentile Cliente,
>
> Poiché il suo server nsXXXXXXX.ip-XXX-XXX-XXX.eu rappresenta una minaccia troppo grave per la nostra rete,
abbiamo dovuto metterlo in modalità "rescue FTP". Le è stata inviata un'e-mail
contenente un nome utente e una password per permetterle di
recuperare facilmente i dati ancora presenti nello spazio di storage.
>
> Non esiti a contattare il nostro supporto tecnico per evitare che questa
situazione diventi critica.
>
> Di seguito trova i log rilevati dal nostro sistema che hanno generato questo avviso.
>
> - INIZIO DELLE INFORMAZIONI AGGIUNTIVE -
>
>  `<Dettagli dell'attacco>`
>
> - FINE DELLE INFORMAZIONI AGGIUNTIVE -
>
> Cordiali saluti,
>
> Supporto Clienti OVHcloud
> Il team OVHcloud

### VPS

Quando la protezione Anti-Hack viene attivata sul tuo VPS, questo può essere messo in modalità Rescue in base alla gravità della minaccia rilevata.

<img className="thumbnail" alt="informazioni antihack VPS" src="/images/bare-metal-cloud/dedicated-servers/anti-hack-dedicated-vps/hacked-vps.png" loading="lazy" />

Se il tuo VPS viene messo in modalità Rescue, OVHcloud aprirà anche un ticket di assistenza a tuo nome con il seguente contenuto:

>
> Gentile Cliente,
>
> È stata rilevata un'attività anomala sul suo VPS vps-XXXXXXXX.vps.ovh.net.
>
> Il suo VPS è stato messo in modalità Rescue. Questo le permetterà di intervenire
sul VPS per risolvere i problemi segnalati. Le è stata inviata un'e-mail contenente informazioni sulla modalità Rescue.
>
> Non è più possibile effettuare alcuna azione sul suo VPS tramite Manager/API. Sono possibili solo le seguenti azioni:
>
> - Reinstallazione del VPS.
> - Utilizzo della modalità Rescue per risolvere i problemi segnalati.
>
> Una volta risolti i problemi, contatti il nostro supporto tecnico per riportarlo in modalità normale.
>
> Non esiti a contattare il nostro team di supporto tecnico per evitare che questa situazione diventi critica.
>
> Di seguito trova i log rilevati dal nostro sistema che hanno generato questo avviso.
>

:::info
**Presta attenzione alla parte finale del messaggio, che indica:** "*Una volta risolti i problemi, contatti il nostro supporto tecnico per riportarlo in modalità normale. Non esiti a contattare il nostro team di supporto tecnico per evitare che questa situazione diventi critica.*"
:::
