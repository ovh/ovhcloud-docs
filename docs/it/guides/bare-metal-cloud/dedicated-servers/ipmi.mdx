## Obiettivo

La console IPMI (Intelligent Platform Management Interface) permette di stabilire una connessione diretta al server dedicato senza dipendere dallo stato di connettività del sistema operativo. Questa guida ti mostra come avviare la console.

## Prerequisiti

:::warning
Questa funzionalità può non essere disponibile o limitata sui [server dedicati **Eco**](/links/bare-metal/eco-about).

Per maggiori informazioni, consulta la nostra [a confronto](/links/bare-metal/eco-compare).

:::

## Procedura

Per connettersi all’IPMI è possibile utilizzare diversi metodi¹. Le chiavi SSH archiviate sul server non saranno utilizzate per queste connessioni. Ecco una tabella riassuntiva:

|Nome Metodo|Altro Nome|Descrizione|Copia-Incolla|Unità ISO Virtuale²|Esempi di casi d'uso|
|---|---|---|---|---|---|
|**KVM**³ via **browser Web**|**KVM HTML**|Emulazione dello schermo video attraverso un **canvas HTML**, esattamente come se si collegasse fisicamente una tastiera/mouse in USB e uno schermo video in VGA al proprio server dedicato.|❌|⚠️⁴|-- Diagnosi di un problema di boot del server dedicato.|
|**KVM**³ via **applet Java**|**KVM Java**|Come per il KVM HTML, ad eccezione che l'emulazione si effettua tramite un **applet Java** al posto del canale HTML.|❌|✅|- Diagnosticare un problema di boot del server dedicato. <br />- Eseguire l'installazione di un OS specifico (escluso [catalogo](/links/bare-metal/os)) manualmente.|
|**SoL**⁶ via **browser Web**|**SoL JavaScript**|Emulazione di un collegamento seriale tramite browser Web, esattamente come se si collegasse una console seriale in RS-232 fisicamente al server dedicato.|✅|❌|- Diagnosticare un problema di rete: recuperare i log e modificare i file di configurazione.|
|**SoL**⁶ via **SSH**|**SoL SSH**|Come per SoL JavaScript, ad eccezione del fatto che l'emulazione avviene tramite un gateway SSH. Accedi con il tuo client SSH preferito a un server remoto in SSH, che trasferisce in seguito gli ordini in collegamento seriale al server dedicato.|✅|❌|- Idem SoL JavaScript ma da una macchina che non ha interfaccia grafica.|

¹ In base alla compatibilità hardware del server dedicato (alcuni metodi non saranno disponibili nella console OVHcloud).<br />
² Funzionalità che permette di montare un'immagine ISO memorizzata localmente sulla tua macchina sul server dedicato remoto, e quindi di installare un OS tramite l'IPMI.<br />
³ KVM = Keyboard Video and Mouse<br />
⁴ In base alla compatibilità hardware del tuo server dedicato. La console OVHcloud propone il KVM Java solo sui server senza KVM tramite browser.<br />
⁵ Se il sistema operativo che vuoi installare non è disponibile nel [catalogo dei sistemi operativi disponibili sui server dedicati OVHcloud](/links/bare-metal/os), ti ricordiamo che puoi anche utilizzare un'immagine personalizzata: per maggiori dettagli, consulta [Bring Your Own Image (BYOI) e Bring Your Own Linux (BYOLinux)](/guides/bare-metal-cloud/dedicated-servers/bring-your-own-image-versus-bring-your-own-linux).<br />
⁶ SoL = Serial over Lan

Per attivare uno di questi metodi, clicca sulla scheda <code className="action">Server</code> del tuo server. I metodi sono raggruppati nella sezione **Server connection**.

### Aprire un KVM tramite applet Java <a name="applet-java"></a>

:::info
Si consiglia di installare l'ultima versione di Java.

:::


Per il corretto funzionamento dell'applet, è necessario che Java sia installato sul dispositivo. Se non lo hai ancora fatto, accedi alla [pagina ufficiale](https://www.java.com/en/download/).

Nel blocco **KVM over IP** della sezione **Server connection** della console OVHcloud, clicca su <code className="action">Da applet Java (KVM)</code>. Questa opzione è visibile solo sui server il cui IPMI non offre il KVM tramite browser (HTML5).

Nella finestra **Da applet Java (KVM)**, clicca su <code className="action">Prepara l'applet Java</code>.

Il file dell'applet (`.jnlp`) viene scaricato automaticamente non appena è pronto. Avvialo:

<img className="thumbnail" alt="Apertura KVM Java" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-02.png" loading="lazy" />

A questo punto accedi alla pagina di login. Inserisci le credenziali di `root`, come in caso di connessione da un terminale o da un software esterno:

<img className="thumbnail" alt="Anteprima KVM Java" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-03.png" loading="lazy" />

Da questo momento puoi gestire il tuo server.

### Aprire un KVM tramite browser Web <a name="kvm-browser"></a>

Nel blocco **KVM over IP** della sezione **Server connection** della console OVHcloud, clicca su <code className="action">Access console (KVM)</code>.

Nella finestra **Access KVM console**, clicca su <code className="action">Request access</code>. L'attivazione richiede alcuni secondi.

Clicca su <code className="action">Open console</code> per aprire la console in una nuova scheda del browser.

### Apri SoL via SSH <a name="sol-ssh"></a>

Per maggiori informazioni sulla creazione di coppie di chiavi SSH, consulta [questa pagina](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys).

Nel blocco **Serial over LAN** della sezione **Server connection** della console OVHcloud, clicca su <code className="action">Connect via SSH key (SoL)</code>.

Nella finestra **Serial over LAN — SSH key session**, scegli una delle chiavi registrate sul tuo account dal menu a tendina **Select an existing SSH key**, oppure incolla nel campo **Public key** la chiave SSH pubblica con cui vuoi connetterti. Clicca quindi su <code className="action">Start session</code>.

Per registrare prima una chiave sul tuo account, utilizza <code className="action">Add SSH key</code> nel blocco **SSH keys** della stessa sezione.

Quando la sessione è pronta, copia negli appunti il comando SSH visualizzato: ti permette di stabilire una connessione seriale (Serial over LAN) al tuo server dedicato via SSH.

Per maggiori informazioni sull'utilizzo di una chiave SSH per connettersi in SSH, consulta [questa pagina](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys).

### Apri SoL tramite browser Web <a name="sol-browser"></a>

Nel blocco **Serial over LAN** della sezione **Server connection** della console OVHcloud, clicca su <code className="action">Connect via browser (SoL)</code>.

Nella finestra **Access Serial over LAN console**, clicca su <code className="action">Request access</code>. L'attivazione richiede alcuni secondi.

:::info
La console non si apre automaticamente: quando l'accesso è pronto, clicca su <code className="action">Open console</code> per aprirla in una nuova scheda del browser.

:::

### Testare e riavviare l’IPMI <a name="ipmi-test-reboot"></a>

È possibile che l'IPMI non risponda più. Se non riesci ad accedervi, puoi prima testarlo: nel blocco **IPMI** della sezione **Server connection** della console OVHcloud, clicca su <code className="action">Test IPMI</code>, poi su <code className="action">Run test</code> nella finestra **Test IPMI**. I test HTTP, della password e di ping vengono quindi eseguiti uno dopo l'altro.

Se tutti i test hanno esito positivo, probabilmente ti trovi di fronte a un problema locale (connessione a Internet, postazione locale). Se l'IPMI riscontra effettivamente un problema, puoi riavviarlo: clicca su <code className="action">Restart IPMI</code>, poi conferma cliccando su <code className="action">Restart IPMI</code> nella finestra **Restart IPMI interface**.

Il riavvio dell'IPMI richiede alcuni minuti.

:::info
Questa operazione non incide sul funzionamento del server.

:::


### Installazione di un sistema operativo con IPMI v1

:::warning
OVHcloud non garantisce la funzionalità dei sistemi operativi installati tramite IPMI. Questo metodo deve essere preso in considerazione solo da un amministratore di server esperto.

Le versioni a 64 bit di Java possono impedire l’apertura dei menu `Redirect ISO`/`Redirect CDROM` e provocare il blocco di JViewer.

:::


Per iniziare, apri [IPMI da una applet Java](#applet-java) dalla console OVHcloud (questa opzione è disponibile solo sui server il cui IPMI non dispone del KVM tramite browser). Clicca su <code className="action">Device</code> nella barra dei menu e seleziona <code className="action">Redirect ISO</code> nel menu a tendina.

<img className="thumbnail" alt="Redirect_ISO" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/RedirectISO.jpg" loading="lazy" />

Seleziona l'ISO che vuoi utilizzare nel file system del tuo computer locale. Una volta selezionato il tuo ISO, premi il pulsante <code className="action">Ctrl Alt Del</code> nell'angolo superiore destro dello schermo per riavviare il server. Premi il tasto `F` per accedere alle opzioni di avvio.

:::info
Potrai utilizzare la tastiera software per registrare i record in IPMI. Per effettuare l'accesso, clicca sull'opzione <code className="action">Keyboard</code> nella barra dei menu in alto a destra. Seleziona `Soft Keyboard` nel menu a tendina e clicca su <code className="action">Show</code>.

:::


Seleziona l'opzione `UEFI Virtual CDROM 1.00` nel menu di avvio (Boot) per avviare il server a partire dall'ISO precedentemente associata.

<img className="thumbnail" alt="UEFI_Virt" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/UEFIVirt.jpg" loading="lazy" />

Segui gli step per installare il sistema operativo. Ricordati di eliminare l'ISO dall'opzione "Redirect ISO".

### Installazione di un sistema operativo con IPMI v2

:::warning
OVHcloud non garantisce la funzionalità dei sistemi operativi installati tramite IPMI. Questo metodo deve essere preso in considerazione solo da un amministratore di server esperto.

:::


Per iniziare, apri [IPMI da una applet Java](#applet-java) dalla console OVHcloud (questa opzione è disponibile solo sui server il cui IPMI non dispone del KVM tramite browser). Clicca su <code className="action">Virtual Media</code> e poi su <code className="action">Virtual Storage</code>.

<img className="thumbnail" alt="Virtual storage" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/virtual_storage.png" loading="lazy" />

Nella nuova finestra, seleziona `ISO File` nel menu a tendina "Logical Drive Type". Clicca su <code className="action">Open Image</code> e naviga fino al tuo file ISO. Infine clicca su <code className="action">Plug-in</code> e <code className="action">OK</code> per completare.

<img className="thumbnail" alt="ISO_file" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/iso_file.png" loading="lazy" />

Per iniziare dal tuo file ISO, è necessario accedere al BIOS e modificare le opzioni di avvio. Clicca su <code className="action">Power Control</code> e poi su <code className="action">Set Power Reset</code>.

<img className="thumbnail" alt="Power_Reserver" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/power_reset.png" loading="lazy" />

:::info
Potrai utilizzare la tastiera software per registrare i record in IPMI. Per accedervi, clicca sull'opzione <code className="action">Virtual Media</code> nella barra dei menu in alto alla finestra. Seleziona <code className="action">Virtual Keyboard</code> nel menu a tendina.

:::


Per accedere al BIOS, premi il tasto `SUPPR` durante il processo di avvio. Premi il tasto `F11` e accedi al BIOS selezionando l'opzione <code className="action">Enter Setup</code>.

<img className="thumbnail" alt="Menu_avvio" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/boot_menu.png" loading="lazy" />

Nel BIOS, naviga fino alla scheda <code className="action">Boot</code> e sostituisci `UEFI Boot Order #1` con `UEFI USB CD/DVD:UEFI: CDROM virtual ATEN YSOJ`.

<img className="thumbnail" alt="Bios" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/bios.png" loading="lazy" />

Premi il tasto `F4` per salvare le modifiche e riavviare il server.

### Riavvia un server dal menu BIOS

È possibile accedere al BIOS durante la configurazione o la risoluzione dei problemi del server. Un modo pratico per farlo è utilizzare lo strumento `ipmiutil` (per ulteriori informazioni, consulta la [pagina del progetto](https://ipmiutil.sourceforge.net/)).

Quando il server è in [modalità rescue](/guides/bare-metal-cloud/dedicated-servers/rescue-mode) e una volta effettuato l’accesso, installalo con il comando:

```bash
apt install ipmiutil
```

Riavvia il server con questo comando:

```bash
ipmiutil reset -b
```

Accedi alla [console IPMI](#procedure) dalla console OVHcloud. Verrà visualizzato il menu BIOS del server.

<img className="thumbnail" alt="KVM BIOS" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_bios.png" loading="lazy" />
