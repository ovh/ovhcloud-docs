## Obiettivo

Il RAID (Redundant Array of Independent Disks) è un insieme di tecniche che attenuano la perdita di dati su un server, replicando le informazioni su più dischi.

Il livello di RAID predefinito dei server OVHcloud è il RAID 1 che raddoppia il volume occupato dai tuoi dati, riducendo lo spazio disponibile.

**Questa guida ti mostra come configurare i dischi del tuo server in RAID 0, per sfruttare il massimo dello spazio disponibile.**

:::warning
Attenzione: il RAID 0 non offre **tolleranza ai guasti** né **ridondanza dei dati**. Questa operazione rende molto probabile la perdita di informazioni in caso di malfunzionamento del disco.

:::


## Prerequisiti

- Disporre di un [server dedicato](/links/bare-metal/bare-metal) con un RAID hardware
- Avere accesso al server via SSH come amministratore (sudo)

## Procedura

### Utilizza la console OVHcloud

Nella scheda <code className="action">Panoramica</code> del server, sezione **Informazioni generali**, clicca su <code className="action">Reinstalla</code> nella riga **Sistema operativo** (<code className="action">Installa</code> su un server senza sistema operativo, nel qual caso la pagina si intitola **Installazione SO**). Si apre la pagina **Installazione / Reinstallazione SO**.

Nello step **Sistema operativo**, seleziona il sistema operativo da installare dai menu a tendina **Categoria** e **Sistema operativo**.

Seleziona le caselle <code className="action">Configura RAID hardware</code> e <code className="action">Personalizza la configurazione delle partizioni</code>, poi clicca su <code className="action">Avanti</code>. La casella <code className="action">Configura RAID hardware</code> è proposta solo sui server dotati di un controller RAID hardware. Se il server possiede più gruppi di dischi, seleziona prima quello dotato del controller RAID hardware in **Scegli il gruppo di dischi su cui installare il sistema operativo**. In caso contrario, la casella è disattivata.

Nello step **RAID hardware**, seleziona <code className="action">RAID 0</code> dal menu a tendina **Modalità RAID**. Il **Numero di dischi da configurare** è precompilato con tutti i dischi del gruppo: mantieni questo valore per sfruttarne l'intera capacità. In RAID 0, il **Numero di array** è fissato a 1. Clicca su <code className="action">Avanti</code>.

Nello step **Partizioni**, configura le partizioni in base alle tue esigenze e clicca su <code className="action">Avanti</code>. Compila lo step **Opzioni**, se necessario, e clicca su <code className="action">Avanti</code>.

Infine, nello step **Riepilogo**, seleziona la casella <code className="action">Capisco che tutti i dati sui dischi verranno eliminati definitivamente.</code> e clicca su <code className="action">Installa</code>.

Una volta configurato il server, verifica la dimensione delle partizioni accedendo via SSH ed eseguendo il seguente comando:

```sh
df -h
```

### Utilizza la modalità Rescue

Nella scheda <code className="action">Panoramica</code> del server, sezione **Informazioni generali**, clicca su <code className="action">Modalità rescue</code> nella riga **Boot Mode**. Si apre la scheda **Server**, in corrispondenza dell'impostazione **Boot mode** della sezione **System**.

Seleziona l'opzione <code className="action">Rescue mode</code>, poi scegli <code className="action">Customer rescue system (Debian-12-based)</code> dal menu a tendina **Rescue kernel**. In **Authentication method**, seleziona <code className="action">Password</code> per ricevere le credenziali di accesso via e-mail.

Nel campo **Rescue email**, inserisci un altro indirizzo e-mail se non vuoi che le credenziali di accesso siano inviate all'indirizzo principale del tuo account OVHcloud.

Clicca su <code className="action">Apply</code>. Nella finestra **Apply boot mode change**, verifica la modalità di avvio attuale e quella nuova, poi clicca su <code className="action">Apply</code>.

Una volta effettuata la modifica, riavvia il server affinché si avvii in modalità Rescue: clicca su <code className="action">Reboot now</code> nella finestra **Reboot to apply**. Se scegli di riavviarlo più tardi, clicca sul link <code className="action">Riavvia</code> nella riga **Boot Mode** della sezione **Informazioni generali** (scheda **Panoramica**), poi su <code className="action">Reboot</code> nella finestra di conferma.

Quando il server si riavvia, accedi via SSH utilizzando le credenziali della modalità Rescue, che ti sono state inviate all'indirizzo e-mail principale dell'account o, se presente, all'indirizzo e-mail indicato in precedenza.

Dalla riga di comando, inserisci questi comandi per eliminare i parametri RAID esistenti. Tutti i dati del RAID verranno eliminati:

```sh
MegaCli -CfgLdDel -L0 -a0
MegaCli -CfgLdDel -Lall -aAll
```

Per recuperare gli identificativi di posizione dei dischi, esegui questo comando:

```sh
MegaCli -PdList -aALL | egrep "Slot|Device ID"
```

Inserisci questi comandi per configurare il RAID 0:

```sh
MegaCli -CfgLDAdd -R0[252:0,252:1] -a0
```

In questo esempio, 252 è l'identificativo del contenitore del disco.

Dopo aver definito il nuovo livello di RAID, puoi verificare le impostazioni utilizzando il seguente comando:

```sh
MegaCli -LDInfo -Lall -a0 | grep -i size
```
