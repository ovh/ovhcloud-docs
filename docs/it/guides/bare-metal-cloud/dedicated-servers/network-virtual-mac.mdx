## Obiettivo

OVHcloud ti permette di associare un indirizzo MAC virtuale a un indirizzo IP al fine di poter creare VM con una configurazione <i>bridge</i> sul tuo server.

**Questa guida ti mostra come creare un indirizzo MAC virtuale e come associarlo a un Additional IP.**

## Prerequisiti

- Disporre di [un server dedicato](/links/bare-metal/bare-metal) che supporta i MAC virtuali. Per determinarlo, consulta [questa guida](/guides/bare-metal-cloud/dedicated-servers/network-support-virtual-mac).
- Disporre di un [indirizzo Additional IP](/links/network/additional-ip) o di un blocco Additional IP (RIPE)

:::warning
- Questa funzionalità può non essere disponibile o limitata sui [server dedicati **Eco**](/links/bare-metal/eco-about). Per maggiori informazioni, consulta la nostra [a confronto](/links/bare-metal/eco-compare).

- I server Advance di terza generazione (dotati di processori EPYC 4004 Series) supportano 32 vMAC differenti.

- Da maggio 2025, questa funzionalità è disponibile sulle gamme Scale e High Grade.

:::


:::info
Se non conosci l'utilizzo dell'API OVHcloud, consulta la nostra guida [Iniziare a utilizzare le API OVHcloud](/guides/manage-and-operate/api/first-steps).

:::

## Procedura

### Assegna un indirizzo MAC

:::warning
Se un blocco IP è stato spostato nella vRack, non è più assegnato a un server fisico a questo titolo, non è più possibile assegnare un MAC virtuale a un IP.

:::


#### Tramite la console OVHcloud

Clicca sul filtro <code className="action">IP aggiuntivo</code> sopra la lista per visualizzare solo i tuoi Additional IP.

Individua il tuo Additional IP (o il tuo blocco) nella lista e cliccaci sopra per aprirne la pagina, poi clicca sulla scheda <code className="action">MAC Virtuale</code>. Per un blocco, il menu a tendina **Mostra MAC virtuali per** permette di scegliere l'IP di cui vengono mostrati i MAC virtuali. Clicca su <code className="action">Aggiungi MAC virtuale</code>.

Quando appare la finestra **Aggiungi un MAC virtuale**, seleziona l'indirizzo IP nella lista **Indirizzo IP** (solo per un blocco), seleziona un tipo dal menu a tendina **Tipo**, inserisci un nome nel campo **Macchina virtuale** e clicca su <code className="action">Aggiungere</code>.

:::info
**Tipo**: si tratta del tipo di indirizzo MAC virtuale (<code className="action">vmware</code> per il sistema VMware ESXi e <code className="action">ovh</code> per tutti gli altri sistemi di virtualizzazione).

**Macchina virtuale**: si tratta del nome che intendi assegnare all’indirizzo MAC virtuale per poi ritrovare più facilmente la coppia IP/MAC.

Se il tuo server dispone già di indirizzi MAC virtuali, la finestra ti permette di scegliere tra <code className="action">Crea un nuovo indirizzo MAC virtuale</code> e <code className="action">Usa un indirizzo MAC virtuale esistente</code>. Con la seconda opzione, seleziona l'indirizzo MAC da riutilizzare al posto di un tipo.

:::

:::info
Ricordati di assegnare l’indirizzo MAC virtuale creato durante la configurazione della tua macchina virtuale.

:::


#### Via API OVHcloud

Utilizza questa chiamata API:

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/virtualMac"} />


### Elimina un indirizzo MAC

:::warning
La rimozione di un indirizzo MAC è definitiva e non sarà quindi più possibile recuperarlo in seguito.

:::


#### Tramite la console OVHcloud

Nella pagina **Indirizzi IP**, utilizza il menu a tendina **Filtra per servizio...** o la barra di ricerca per trovare l'Additional IP (o il blocco IP), poi cliccaci sopra per aprirne la pagina e clicca sulla scheda <code className="action">MAC Virtuale</code>. Per un blocco, seleziona l'IP nel menu a tendina **Mostra MAC virtuali per**.

Ogni MAC virtuale è mostrato sotto il suo indirizzo MAC. Clicca su <code className="action">Elimina</code> sotto il MAC virtuale, poi su <code className="action">Eliminare</code> nella finestra **Elimina l'indirizzo MAC virtuale** per confermare.

#### Via API OVHcloud

Utilizza questa chiamata API:

<Api version="v1" section="/dedicated/server" method="DELETE" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


## FAQ

- **Cosa succede se trasferisco un blocco con vMAC su un server Advance di terza generazione (dotato di un processore EPYC 4004 Series) che possiede già 32 vMACs?**

Il blocco non verrà spostato.

Esempio: se tentate di spostare un blocco di 4 IP con vMAC diversi collegati su un server che ha già 30 vMAC, il blocco non verrà spostato perché il totale di vMAC sarebbe superiore ai 32 vMAC autorizzati.
