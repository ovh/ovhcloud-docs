## Obiettivo

Se configuri il tuo server dedicato come server DNS, puoi utilizzare il DNS OVHcloud secondario per ospitare una zona secondaria. In questo modo, il DNS del tuo dominio resterà disponibile anche se il server DNS principale non risponde più.

**Questa guida ti mostra come aggiungere un dominio nella console OVHcloud per utilizzare un server DNS secondario.**

## Prerequisiti

- Disporre di un [server dedicato](/links/bare-metal/bare-metal)
- Disporre di un [dominio](/links/web/domains) di gestione amministrativa o tecnica

:::warning
OVHcloud mette a tua disposizione servizi di cui tu sei responsabile per la configurazione e la gestione. Garantirne quotidianamente il corretto funzionamento è quindi responsabilità dell’utente.

Questa guida ti aiuta a realizzare le operazioni più ricorrenti. Tuttavia, in caso di difficoltà o dubbi relativi all'amministrazione, all'utilizzo o alla realizzazione dei servizi su un server, ti consigliamo di contattare un [provider specializzato](/links/partner).

:::

## Procedura

### Aggiungi un dominio <a name="addingdomain"></a>

Prima di iniziare, aggiungi il record TXT ownercheck alla zona DNS del dominio, come descritto in [Verifica dell'autorizzazione per il dominio](#verifyingdomain). Se l'aggiunta non riesce, la finestra mostra solo il messaggio **Impossibile aggiungere il dominio DNS secondario. Riprova.**

Nella pagina del tuo server dedicato, clicca sulla scheda <code className="action">Connectivity</code>. Nella sezione **DNS**, sotto **DNS secondario**, clicca su <code className="action">Add a domain</code>.

Nella finestra **Aggiungi DNS secondario**, segui i tre step:

1. Inserisci il dominio da aggiungere nel campo **Nome dominio**, quindi clicca su <code className="action">Avanti</code>.
2. Se lo desideri, seleziona nell'elenco a discesa **IP master (facoltativo)** l'indirizzo IP del server che fungerà da master. Clicca su <code className="action">Avanti</code>.
3. Verifica la tua configurazione, quindi clicca su <code className="action">Aggiungi</code>. Per modificare un valore prima di confermare, clicca su <code className="action">Indietro</code>.

Dopo aver cliccato su <code className="action">Aggiungi</code>, il dominio viene aggiunto al server DNS secondario OVHcloud.

I domini aggiunti sono elencati sotto **DNS secondario**. La colonna **Server DNS** mostra il nome del server DNS secondario accanto a ciascun dominio. Per eliminare un dominio, clicca sull'icona del cestino alla fine della sua riga.

:::info
Le altre azioni necessarie per configurare il tuo DNS per il tuo dominio sono generalmente:

- configurazione di un servizio DNS (come *BIND*)
- configurazione delle registrazioni GLUE
- autorizzazione dei trasferimenti di zona

Per completare questi compiti amministrativi, consulta la documentazione esterna pertinente.

:::


### Verifica dell'autorizzazione per il dominio <a name="verifyingdomain"></a>

Prima di poterlo aggiungere al DNS secondario OVHcloud, è necessario confermare l'autorizzazione a gestire il dominio. Questa verifica avviene tramite una ricerca DNS automatizzata sul sottodominio *ownercheck.tuodominio*. A questo scopo viene generata una stringa di caratteri unica.

La finestra **Aggiungi DNS secondario** della console OVHcloud non mostra questo valore. Per recuperarlo, utilizza la seguente chiamata API, indicando il nome interno del server (esempio: `ns3956771.ip-169-254-10.eu`) e il dominio nel parametro `domain`:

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/secondaryDnsNameDomainToken"} />

La risposta contiene il tipo di record (`TXT`), il sottodominio (`ownercheck`) e il valore da utilizzare.

- Se il dominio è gestito da un registrar esterno o utilizza server DNS esterni, accedi all'interfaccia di gestione del tuo provider DNS e aggiungi un record TXT con il sottodominio "ownercheck" e questo valore.

- Se il dominio è gestito da OVHcloud in qualità di registrar e utilizza server DNS OVHcloud, segui le istruzioni di [questa guida](/guides/web-cloud/domains/dns-zone-edit) per aggiungere il record TXT nella console OVHcloud.

Dopo aver aggiunto correttamente il record TXT alla zona DNS del dominio, ripeti gli [step precedenti](#addingdomain) e completa la procedura.
