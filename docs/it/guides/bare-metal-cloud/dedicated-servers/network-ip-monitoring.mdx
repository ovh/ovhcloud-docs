## Obiettivo

Il servizio di monitoring permette di controllare lo stato della tua macchina e di attivare automaticamente l'intervento di un tecnico nel datacenter.

Tutti i server dei nostri clienti e l'intera rete sono monitorati dai team tecnici OVHcloud 24 ore su 24 e 7 giorni su 7.

OVHcloud interviene al momento dell'attivazione di un alert (nessuna risposta ai ping) per limitare al massimo i tempi di indisponibilità dei server e della rete.

Per impostare un firewall restrittivo, in particolare sull'ICMP, e continuare a usufruire del monitoring OVHcloud, è necessario autorizzare gli indirizzi IP che trovi qui di seguito.

## Prerequisiti

- Un prodotto OVHcloud su cui hai installato un Firewall.
- Avere accesso alle regole del Firewall

### Attiva o disattiva il monitoring <a name="enable"></a>

È possibile attivare o disattivare il monitoring di un server dedicato dalla scheda <code className="action">Server</code> della sua pagina. La riga **Monitoring** della sezione **Informazioni sul server** indica il suo stato attuale: **Disabled**, **Enabled with intervention** o **Enabled without intervention**.

Clicca su <code className="action">Configure monitoring</code>. Nella finestra **Configure monitoring** puoi definire il comportamento del monitoring:

- <code className="action">Enable monitoring</code>: disattiva questo interruttore per interrompere i messaggi di alert e gli interventi di OVHcloud, ad esempio se esegui sul server azioni di amministrazione che impediscono una risposta ICMP.
- **Intervention mode** (visualizzato quando il monitoring è attivo):
    - <code className="action">Proactive intervention (OVHcloud will act if an issue is detected)</code>: se il server non risponde più, riceverai un'email di alert e il server sarà verificato da un tecnico.
    - <code className="action">No intervention (monitoring only, no action taken)</code>: riceverai un'email di alert se il server non risponde più. Per avviare un intervento è necessario creare una richiesta di assistenza.

Clicca su <code className="action">Save</code> per aggiornare la tua configurazione del monitoring.
