## Obiettivo

Windows Server è un sistema operativo supportato sui server dedicati OVHcloud. Una volta installato, devi configurare il sistema Windows affinché possa utilizzare i servizi di rete e di storage OVHcloud associati al server.

Questa guida ti accompagna nell'installazione di Windows Server dallo Spazio Cliente OVHcloud, nella connessione al server e nella configurazione lato Windows necessaria per interagire con i principali servizi OVHcloud associati a un server dedicato.

**In questa guida imparerai a:**

- Installare Windows Server dallo Spazio Cliente
- Connetterti al server tramite Desktop remoto ed effettuare la configurazione iniziale
- Configurare Windows per utilizzare un Additional IP
- Configurare Windows per utilizzare la rete privata vRack
- Configurare Windows per utilizzare il blocco IPv6 fornito con il server
- Accedere al Backup Storage OVHcloud da Windows
- Proteggere il server con backup gestiti grazie a OVHcloud Backup Agent

:::warning
La reinstallazione di un sistema operativo cancella tutti i dati presenti sui dischi del server. Effettua un backup dei dati che desideri conservare prima di iniziare.
:::

## Prerequisiti

- Disporre di un [server dedicato](/links/bare-metal/bare-metal) nel tuo account OVHcloud
- Disporre di una licenza Windows Server valida. Le licenze possono essere ordinate presso OVHcloud o presso un rivenditore esterno — consulta la guida [Gestire le tue licenze OVHcloud](/guides/bare-metal-cloud/dedicated-servers/windows-key).
- Disporre di un client RDP (Remote Desktop Protocol) sulla tua macchina locale (il client <code className="action">Connessione Desktop remoto</code> è incluso in Windows)

## Introduzione

Un server dedicato è un server fisico ("bare metal") ospitato in un data center OVHcloud. OVHcloud fornisce l'hardware, la connessione alla rete pubblica, una rete privata vRack opzionale e uno spazio Backup Storage incluso. Sei responsabile dell'amministrazione del sistema operativo installato sul server, inclusa tutta la configurazione di rete e di storage in Windows.

La tabella seguente presenta i principali servizi con cui interagisce un server dedicato con Windows.

| Servizio OVHcloud | Ruolo | Dove attivarlo |
|---|---|---|
| Additional IP | Indirizzi IP pubblici aggiuntivi associati al server | Spazio Cliente — menu <code className="action">Network</code>, sezione <code className="action">IP</code> |
| vRack | Rete privata di livello 2 tra i servizi OVHcloud | Spazio Cliente — menu <code className="action">Network</code>, sezione <code className="action">vRack</code> |
| IPv6 | Il blocco IPv6 /64 fornito con ogni server | Fornito automaticamente |
| Backup Storage | Spazio di backup incluso (FTP/CIFS (SMB)/NFS) | Spazio Cliente — <ManagerLink to="/#/dedicated-servers/server">Server dedicati</ManagerLink> > Seleziona il tuo server, scheda <code className="action">Backup Storage</code> |
| Backup Agent | Backup gestiti giornalieri verso un vault Object Storage isolato e immutabile | Spazio Cliente — <ManagerLink to="/#/dedicated-servers/server">Server dedicati</ManagerLink> > Seleziona il tuo server, scheda <code className="action">Informazioni generali</code>, sezione <code className="action">Stato dei servizi</code> |

### Step 1 — Installare Windows Server dallo Spazio Cliente <a name="install"></a>

In questo step, installi (o reinstalli) Windows Server sul tuo server dedicato. L'installazione si gestisce interamente dallo Spazio Cliente.

Nella scheda <code className="action">Informazioni generali</code>, accanto a <code className="action">Sistema operativo (OS)</code>, apri il menu delle azioni e clicca su <code className="action">Reinstallare il mio server</code>. Si apre la finestra <code className="action">Installazione a partire da un template OVHcloud</code>, che ti guida in 4 fasi.

:::info
Windows Server richiede una licenza, che genera costi aggiuntivi. Senza una licenza Windows Server associata al server, i modelli Windows non vengono proposti nell'elenco dei sistemi operativi. Puoi ordinare una licenza presso OVHcloud o fornire la tua. Gestisci le tue licenze in **Bare Metal Cloud** > **Licenze**. Per maggiori informazioni, consulta la guida [Gestire le tue licenze OVHcloud](/guides/bare-metal-cloud/dedicated-servers/windows-key).
:::

:::warning
Questa azione è irreversibile. Tutti i dati presenti sui dischi verranno eliminati definitivamente.
:::

1. **Tipo di sistema operativo** — imposta <code className="action">Tipo di sistema operativo</code> e seleziona il modello Windows Server desiderato. I modelli sono raggruppati per categoria (Linux, Windows, ecc.). I modelli Windows compaiono solo se una licenza Windows Server è associata al tuo server dedicato (vedi la nota qui sopra).
2. **Gruppo di dischi di destinazione** — scegli il <code className="action">Gruppo di dischi di destinazione</code> su cui verrà installato Windows. Per definire il tuo array o layout personalizzato, attiva <code className="action">Personalizza la configurazione del tuo RAID hardware</code> o <code className="action">Personalizza la configurazione delle partizioni</code>. Per il RAID software in Windows, consulta la guida [Configurare un RAID software su un server Windows](/guides/bare-metal-cloud/dedicated-servers/raid-soft-windows).
3. Clicca su <code className="action">Avanti</code> e segui le fasi restanti della procedura guidata per verificare le tue scelte, quindi conferma per avviare l'installazione.

Il server si riavvia e l'installazione si completa automaticamente.

### Step 2 — Connettersi al server <a name="connect"></a>

Una volta completata l'installazione, OVHcloud ti invia un'email contenente il nome utente e la password amministratore del tuo server Windows.

Sulla tua macchina Windows locale, apri il client <code className="action">Connessione Desktop remoto</code>. Inserisci l'indirizzo IPv4 del tuo server, quindi il tuo nome utente e la tua password. Alla prima connessione compare generalmente un avviso relativo al certificato — clicca su <code className="action">Sì</code> per continuare.
Puoi utilizzare qualsiasi client compatibile con RDP se il tuo dispositivo locale non funziona con Windows.

:::tip
Se il protocollo RDP non è disponibile — ad esempio dopo un errore di configurazione di rete — connettiti tramite la [console Intelligent Platform Management Interface (IPMI)](/guides/bare-metal-cloud/dedicated-servers/ipmi) dalla scheda <code className="action">IPMI/KVM</code> dello Spazio Cliente. La console IPMI funziona indipendentemente dallo stato di connettività del sistema operativo.
:::

Dopo la prima connessione, modifica la password amministratore da Windows (nella sessione RDP, premi `Ctrl` + `Alt` + `Fine` > <code className="action">Cambia una password</code>).

### Step 3 — Effettuare la configurazione iniziale di Windows <a name="initial-config"></a>

Prima di collegare il server agli altri servizi OVHcloud, effettua la configurazione di base di Windows.

- Avvia Windows Update e installa gli ultimi aggiornamenti.
- Imposta il nome host del server, il fuso orario e il layout della tastiera.
- Configura il firewall di Windows per autorizzare i servizi che intendi eseguire. Per una procedura specifica per il firewall in Windows, consulta la guida [Attivare il firewall su un server Windows](/guides/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win).

:::warning
OVHcloud mette a tua disposizione dei servizi di cui sei responsabile per quanto riguarda la configurazione e la gestione. Se hai bisogno di assistenza, contatta un [fornitore specializzato](/links/partner).
:::

### Step 4 — Configurare Windows per interagire con i servizi OVHcloud <a name="services"></a>

Questa sezione tratta la configurazione lato Windows dei servizi OVHcloud più frequentemente associati a un server dedicato. Ogni sottosezione è indipendente — segui solo quelle che corrispondono alla tua configurazione. In ciascuna, la prima parte si effettua nello Spazio Cliente OVHcloud e la seconda in Windows Server.

#### 4a — Additional IP

Un Additional IP è un indirizzo IP pubblico aggiuntivo instradato verso il tuo server. Dopo averlo ordinato, devi dichiararlo in Windows affinché il server risponda su questo indirizzo.

**Nello Spazio Cliente OVHcloud**

Ordina l'Additional IP dal menu <code className="action">Network</code> dello Spazio Cliente, nella sezione <code className="action">IP</code>: clicca su <code className="action">Ordina IP</code>. Per maggiori informazioni, consulta la pagina [Additional IP](/links/bare-metal/ip).

**In Windows Server**

1. Apri <code className="action">Pannello di controllo</code> > <code className="action">Centro connessioni di rete e condivisione</code> > <code className="action">Modifica impostazioni scheda</code>, quindi visualizza le proprietà della tua scheda di rete.
2. Seleziona <code className="action">Protocollo Internet versione 4 (TCP/IPv4)</code> > <code className="action">Proprietà</code> > <code className="action">Avanzate</code> e aggiungi l'indirizzo dell'Additional IP.

Sulla rete OVHcloud, un Additional IP viene instradato individualmente verso il server. Utilizza la maschera di sottorete e il gateway corrispondenti alla configurazione dell'IP principale del tuo server.

:::tip
Se intendi assegnare l'Additional IP a una macchina virtuale anziché all'host, consulta la guida [Configurare un blocco di IP in un vRack](/guides/bare-metal-cloud/dedicated-servers/configuring-an-ip-block-in-a-vrack).
:::

#### 4b — Rete privata vRack

Il vRack è una rete privata di livello 2 che consente al tuo server dedicato di comunicare in modo privato con altri servizi OVHcloud (altri server dedicati, istanze Public Cloud, ecc.).

**Nello Spazio Cliente OVHcloud**

Dal menu <code className="action">Network</code> dello Spazio Cliente, apri la sezione <code className="action">vRack</code>, seleziona il tuo vRack e aggiungi questo server.

**In Windows Server**

1. Apri le proprietà della scheda di rete **privata** (la seconda interfaccia, dedicata al vRack).
2. Assegna un indirizzo IPv4 privato statico tratto dal tuo piano di indirizzamento vRack. Lascia vuoto il gateway predefinito — il vRack è una rete di livello 2 senza gateway fornito da OVHcloud.

Per la procedura completa, così come per la configurazione dell'OVHcloud Link Aggregation (OLA, aggregazione dei link), consulta la guida [Configurare il vRack su un server dedicato](/guides/bare-metal-cloud/dedicated-servers/vrack-configuring-on-dedicated-server).

#### 4c — IPv6

Ogni server dedicato OVHcloud viene fornito con un blocco IPv6 /64. L'indirizzo non viene configurato automaticamente in Windows e deve essere aggiunto manualmente.

**Nello Spazio Cliente OVHcloud**

Recupera il tuo indirizzo IPv6, il prefisso e il gateway dalla sezione <code className="action">Rete</code> della scheda <code className="action">Informazioni generali</code> del tuo server, che mostra <code className="action">IPv6</code> e <code className="action">Gateway IPv6</code>.

**In Windows Server**

1. Apri le proprietà della tua scheda di rete e seleziona <code className="action">Protocollo Internet versione 6 (TCP/IPv6)</code> > <code className="action">Proprietà</code>.
2. Inserisci l'indirizzo IPv6, la lunghezza del prefisso e il gateway IPv6 predefinito.

Per i dettagli di indirizzamento e la configurazione del gateway specifici di OVHcloud, consulta la guida [Configurazione dell'IPv6](/guides/bare-metal-cloud/dedicated-servers/network-ipv6).

#### 4d — Backup Storage

Il Backup Storage è uno spazio di archiviazione incluso con il tuo server dedicato. È accessibile tramite i protocolli FTP, CIFS (SMB) o NFS ed è particolarmente adatto come backup complementare.

**Nello Spazio Cliente OVHcloud**

1. Nella scheda <code className="action">Backup Storage</code> del tuo server, clicca su <code className="action">Attiva il backup storage</code>. Una volta attivo, la scheda mostra l'indirizzo del server FTP e l'identificativo e ti consente di definire la password dello spazio.
2. Autorizza l'indirizzo IP del tuo server ad accedere allo spazio.

**In Windows Server**

Accedi allo spazio utilizzando uno dei protocolli supportati:

- **CIFS (SMB)** — montalo come unità di rete (<code className="action">Questo PC</code> > <code className="action">Connetti unità di rete</code>).
- **FTP** — connettiti con qualsiasi client FTP, utilizzando le informazioni di connessione dello Spazio Cliente e la password che hai definito.

Per la procedura di attivazione e i protocolli di accesso, consulta la guida [Backup Storage sui server dedicati](/guides/bare-metal-cloud/dedicated-servers/services-backup-storage) e la pagina [Backup Storage](/links/bare-metal/backup-storage).

#### 4e — Backup Agent

Il Backup Storage è uno spazio di archiviazione passivo — non esegue il backup dei tuoi dati autonomamente. Per una protezione gestita e automatizzata, OVHcloud propone **Backup Agent**, un servizio di backup separato per i server Bare Metal. Una volta ordinato, distribuisci un agent leggero sul tuo server Windows, che esegue quindi backup giornalieri incrementali, cifrati e immutabili verso un vault Object Storage isolato, situato in una regione diversa da quella del server.

**Nello Spazio Cliente OVHcloud**

Nella scheda <code className="action">Informazioni generali</code>, nella sezione <code className="action">Stato dei servizi</code>, utilizza la voce <code className="action">Backup Agent</code> e clicca su <code className="action">Gestisci Backup Agent</code>. Puoi anche attivarlo durante la reinstallazione del sistema operativo.

**In Windows Server**

Una volta distribuito l'agent, configura il tuo primo backup (dati sorgente, pianificazione e conservazione).

Per la procedura completa, consulta la guida [Backup Agent - Presentazione](/guides/storage-and-backup/backup-agent/overview) e la guida [Backup Agent - Come configurare il tuo primo backup](/guides/storage-and-backup/backup-agent/first-configuration).

### Step 5 — Verificare la configurazione <a name="verify"></a>

Verifica che ogni servizio configurato funzioni come previsto.

| Verifica | Come | Risultato atteso |
|---|---|---|
| Accesso RDP | Connettiti con <code className="action">Connessione Desktop remoto</code> all'IPv4 principale | Viene visualizzato il desktop di Windows |
| Additional IP | Da un host esterno, esegui un `ping` verso l'Additional IP | Il server risponde |
| vRack | Da un altro membro del vRack, esegui un `ping` verso l'IP privato | Il server risponde |
| IPv6 | Esegui `ping -6 ipv6.google.com` dal server | Ricevi le risposte |
| Backup Storage | Apri l'unità CIFS (SMB) montata o connettiti via FTP | Puoi leggere e scrivere file |

### Risoluzione dei problemi <a name="troubleshooting"></a>

| Problema | Possibile causa | Soluzione |
|---|---|---|
| La connessione RDP non riesce | Regole del firewall o restrizioni di rete sul dispositivo locale | Verifica le impostazioni del firewall e della rete locali; in alternativa, connettiti tramite la [console IPMI](/guides/bare-metal-cloud/dedicated-servers/ipmi). |
| Additional IP non raggiungibile | Maschera o gateway errati in Windows | Verifica nuovamente i valori inseriti nelle impostazioni avanzate TCP/IPv4. |
| Membro del vRack non raggiungibile | Sottorete privata errata o gateway impostato sulla scheda privata | Conferma il piano di indirizzamento privato e lascia vuoto il gateway. |
| Server offline dopo una modifica | Errore di configurazione durante l'impostazione | Avvia la [modalità rescue](/guides/bare-metal-cloud/dedicated-servers/rescue-customer-windows) per ispezionare e riparare la configurazione. |
