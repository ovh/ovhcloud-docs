## Obiettivo

La modalità Rescue è uno strumento fornito da OVHcloud che permette di avviare un sistema operativo temporaneo. con lo scopo di diagnosticare e risolvere i problemi sul tuo server.

Il funzionamento generale della modalità rescue è descritto nella nostra guida "[Come attivare e utilizzare la modalità rescue](/guides/bare-metal-cloud/dedicated-servers/rescue-mode)".

L'opzione **Windows customer rescue system** è disponibile solo per i server dedicati su cui è installato un sistema operativo **Windows Server**. Si applicano le seguenti condizioni:

- Il sistema rescue per Windows (`rescue-customer-windows`) funziona in una macchina virtuale (VM) avviata a partire dal sistema rescue client (`rescue-customer`, basato su Debian GNU/Linux).
- I dischi del server sono associati alla VM con *passthrough*, quindi è possibile accedervi.
- Gli altri componenti del server non saranno raggiungibili (CPU, RAM, scheda di rete, scheda RAID).
- La rete è montata con *passthrough* ma senza accesso diretto alla scheda di rete. La VM contiene l'indirizzo IP e l'indirizzo MAC del server *bare metal*.

:::warning
Assicurati di eseguire un backup dei tuoi dati se ancora non ne hai uno recente.

Se sul server sono presenti servizi in produzione, la modalità Rescue li interrompe fino al riavvio della macchina in modalità normale.

:::


**Questa guida ti mostra come avviare un server nel client di backup di Windows.**

## Prerequisiti

- Microsoft Windows installato sul tuo [server dedicato](/links/bare-metal/bare-metal)
- Almeno 16 GB di RAM installati sul server

## Procedura

### Attivazione della modalità Rescue per Windows

Clicca sul nome del tuo server per aprirne la pagina. La pagina si apre sulla scheda **Panoramica**, che contiene la sezione **Informazioni generali**.

<a name="netboot"></a>

Nella sezione **Informazioni generali**, clicca sul link <code className="action">Modalità rescue</code> della riga **Boot Mode**. La scheda **Server** si apre sul parametro **Boot mode** della sezione **System**. Puoi anche cliccare direttamente sulla scheda <code className="action">Server</code> e raggiungere il parametro **Boot mode**.

Seleziona l'opzione <code className="action">Rescue mode</code>.

Nel menu a tendina **Rescue kernel**, seleziona <code className="action">Windows customer rescue system v12 (Windows2022-based)</code>.

L'e-mail di notifica della modalità Rescue e le relative credenziali verranno inviate all'indirizzo e-mail di contatto del tuo account OVHcloud. Per utilizzare un altro indirizzo e-mail, inseriscilo nel campo **Rescue email**. Se il campo **Rescue email** mostra già un indirizzo, l'e-mail viene inviata a quell'indirizzo.

Clicca su <code className="action">Apply</code>. Nella finestra **Apply boot mode change**, verifica la modalità di avvio attuale e quella nuova, poi clicca su <code className="action">Apply</code>. La nuova modalità di avvio verrà applicata al prossimo riavvio.

L'ultimo step consiste nel riavviare il server. Nella finestra **Reboot to apply**, clicca su <code className="action">Reboot now</code>. Se riavvii il server più tardi, clicca sul link <code className="action">Riavvia</code> della riga **Boot Mode** nella sezione **Informazioni generali** (scheda **Panoramica**), poi su <code className="action">Reboot</code> nella finestra di conferma.

L'*hard reboot* richiederà alcuni minuti per terminare. Puoi verificare lo stato corrente nella scheda <code className="action">Attività</code>.

:::info
Dopo aver terminato le operazioni in modalità Rescue, ricordati di reimpostare il parametro **Boot mode** su <code className="action">Boot from hard disk</code> prima di riavviare il server.

:::


### Accedi al tuo server in modalità Rescue

Una volta ricevuta l'e-mail che ti informa che la modalità Rescue è attiva, puoi accedere al sistema in modalità Rescue da Windows e accedere al tuo server.  
Questa e-mail è disponibile anche nella console OVHcloud non appena viene inviata. Apri il menu dell'account in alto a destra, poi clicca su <code className="action">Le mie comunicazioni</code> in **Accesso rapido**. L'e-mail è elencata nella scheda **Messaggi** della pagina **Communications**.

Per stabilire una sessione remota sul sistema in modalità Rescue di Windows, sono necessarie le seguenti credenziali:

- Indirizzo IP del server
- Nome utente account Administrator temporaneo (`Administrator`)
- Password dell'account amministratore temporaneo

Per accedere al server tramite il sistema in modalità Rescue di Windows, è possibile utilizzare i seguenti metodi di connessione:

- Remote Desktop Protocol (RDP)
- KVM over IP (se il tuo server lo permette)
- OpenSSH (componente ufficiale di Windows Server)

#### SSH

<details>

<summary>Espandi questa sezione</summary>


Aprire l'applicazione da riga di comando sul dispositivo locale e immettere il comando seguente:

```bash
ssh Administrator@SERVER_IP
```

Esempio:

```bash
ssh Administrator@203.0.113.100
```

Quando richiesto, immetti la password della modalità Rescue temporanea. Esempio:

```console
Administrator@ns9356771.ip-203-0-113.eu's password:
administrator@WINRESCUEOVH C:\Users\Administrator>
```

Per maggiori informazioni sulle connessioni SSH, consulta la nostra [guida introduttiva a SSH](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction).  
È inoltre possibile utilizzare qualsiasi strumento di connessione SSH, ad esempio [PuTTY](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows).

</details>

### Uscita dalla modalità Rescue

Nella console OVHcloud, vai al parametro [Boot mode](#netboot) della scheda **Server** del tuo server, seleziona <code className="action">Boot from hard disk</code> e clicca su <code className="action">Apply</code>. Clicca di nuovo su <code className="action">Apply</code> nella finestra **Apply boot mode change**.

Riavvia quindi il server: clicca su <code className="action">Reboot now</code> nella finestra **Reboot to apply** oppure utilizza il link <code className="action">Riavvia</code> della riga **Boot Mode** nella sezione **Informazioni generali**.
