## Obiettivo

I server dedicati OVHcloud includono uno spazio di backup aggiuntivo per salvare i dati e i file di configurazione importanti. Questo spazio è scalabile, sicuro e indipendente dal server principale

**Questa guida ti mostra come attivare e utilizzare il tuo spazio di backup**.

:::info
Per maggiori informazioni, consulta la [pagina commerciale](/links/bare-metal/backup-storage) dell'opzione Backup Storage.

Questa guida non si applica ai servizi OVHcloud US.

:::


## Prerequisiti

- Disporre di un [server dedicato](/links/bare-metal/bare-metal) sul proprio account OVHcloud

[[cpnav:baremetal-dedicated-servers-console]]

:::warning
Questa funzionalità può non essere disponibile o limitata sui [server dedicati **Eco**](/links/bare-metal/eco-about).

Per maggiori informazioni, consulta la nostra [a confronto](/links/bare-metal/eco-compare).

:::


## Procedura

### Attiva il tuo Backup Storage

Nella scheda <code className="action">Archiviazione remota</code> del tuo server, clicca sul pulsante <code className="action">Attiva Backup FTP</code>. Non viene richiesta alcuna conferma: l'attivazione inizia immediatamente.

Il tuo Backup Storage sarà configurato in pochi minuti. Una volta completata la configurazione, riceverai un'email di conferma.

### Configura il controllo degli accessi

L'accesso allo spazio di storage è limitato per indirizzi IP tramite una lista di controllo degli accessi (<i>Access Control List</i> o ACL). Possono accedere allo storage solo gli indirizzi IP del tuo account OVHcloud registrati nell'ACL. I protocolli di accesso (FTP, NFS e CIFS) non sono autorizzati di default ma possono essere selezionati durante l'aggiunta di indirizzi IP.

#### Aggiungere un accesso backup

Nella scheda <code className="action">Archiviazione remota</code>, accedi alla sezione **Elenco degli accessi** e clicca sul pulsante <code className="action">Aggiungi accesso</code>.

Nella finestra **Aggiungi accesso Backup FTP**, seleziona nell'elenco **Blocchi IP** il blocco IP che vuoi autorizzare. Una volta selezionato, scegli in **Protocolli** il/i protocollo/i da autorizzare e clicca su <code className="action">Avanti</code>.

:::info
Dalla console OVHcloud è possibile aggiungere all'ACL solo blocchi di indirizzi IP del tuo account OVHcloud.

:::

Verifica la tua selezione e conferma cliccando su <code className="action">Aggiungi</code>. A questo punto è possibile accedere al Backup Storage del server dal blocco IP selezionato.

#### Modifica o elimina un accesso al backup

Una volta attivato il servizio, la tabella ACL viene visualizzata nella sezione **Elenco degli accessi** della scheda <code className="action">Archiviazione remota</code>. Ogni riga indica un blocco IP autorizzato (**IP / Network**), i relativi **Protocols** e il relativo **Status**, seguiti da due icone che permettono di modificare o eliminare l'accesso.

Per modificare i protocolli di un blocco IP autorizzato, clicca sull'icona di modifica (matita) della relativa riga. Nella finestra **Edit access**, seleziona o deseleziona i protocolli (CIFS, FTP, NFS) in **Protocolli**, poi salva le modifiche cliccando su <code className="action">Save</code>.

Per eliminare l'autorizzazione di un blocco IP, clicca sull'icona di eliminazione (cestino) della relativa riga, poi su <code className="action">Delete</code> nella finestra **Delete access**.

#### Accedi al Backup Storage da un IP esterno al tuo servizio <a name="accessbackup"></a>

L'accesso al Backup Storage può essere limitato al servizio associato tramite la console OVHcloud.

Per poter aggiungere altri indirizzi IP di servizi diversi, puoi utilizzare [l'API OVHcloud](/guides/manage-and-operate/api/first-steps).
In questo modo potrai recuperare i tuoi backup da un servizio situato in un'altra localizzazione.

:::warning
Possono essere autorizzati solo gli indirizzi IP OVHcloud.

:::


Accedi alla <ApiLink>console API OVHcloud</ApiLink> e utilizza la chiamata seguente:

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/features/backupFTP/access"} />

Modifica i parametri come indicato di seguito:

- `serviceName`: inserisci il nome interno del tuo server (`ns1111111.ip-203-0-113.eu`).
- `cifs`: imposta questo parametro su `true` se utilizzi questo protocollo.
- `ftp`: imposta questo parametro su `true` se utilizzi questo protocollo.
- `ipBlock`: inserisci l’indirizzo IP che vi avrà accesso, nella forma `203.0.113.100/32`.
- `nfs`: imposta questo parametro su `true` se utilizzi questo protocollo.

Clicca sul pulsante <code className="action">EXECUTE</code>.

Per verificare che il tuo indirizzo IP sia autorizzato, utilizza questa chiamata:

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/features/backupFTP/access"} />



### Reimposta la password

Nella scheda <code className="action">Archiviazione remota</code>, clicca sul pulsante <code className="action">Reset password</code>.

Nella finestra **Reset backup FTP password**, clicca su <code className="action">Reset password</code> per confermare. Una nuova password per il tuo Backup Storage sarà inviata all'indirizzo email del tuo account OVHcloud. Utilizzala per le prossime connessioni allo spazio di storage.

### Eliminare il Backup Storage

Nella scheda <code className="action">Archiviazione remota</code>, clicca sul pulsante <code className="action">Delete backup storage</code>.

Se clicchi su <code className="action">Delete storage</code> nella finestra **Delete backup storage**, il tuo Backup Storage sarà disattivato in pochi minuti. Tutti i dati dello spazio di storage verranno eliminati.

### Ordina spazio disco aggiuntivo

Nella scheda <code className="action">Archiviazione remota</code>, clicca sul pulsante <code className="action">Ordina spazio su disco aggiuntivo</code>. Questo pulsante appare solo se per il tuo server è possibile ordinare spazio disco aggiuntivo.

Nella finestra **Ordina spazio su disco aggiuntivo**, scegli in **Capacità** lo spazio di storage da aggiungere (ad esempio 1000 GB, 5000 GB o 10000 GB) e la **Durata di fatturazione**, poi clicca su <code className="action">Avanti</code>.

Leggi la tariffazione e le condizioni contrattuali visualizzate nella fase di riepilogo, poi clicca su <code className="action">Conferma ordine</code>.
Verrà creato un buono d'ordine. Una volta effettuato il pagamento, riceverai una notifica dell'estensione del tuo spazio di storage.

### Utilizza il Backup Storage

:::info
Il servizio di Backup Storage non effettua un backup automatico dei tuoi dati. Fornisce solo lo spazio e i protocolli di accesso. È tua responsabilità implementare una strategia di backup adeguata utilizzando gli strumenti che preferisci. OVHcloud non potrà essere considerata responsabile dei dati contenuti in questi spazi.

:::


:::warning
Il servizio di Backup Storage ha un limite di tre connessioni simultanee per IP.

:::


Per recuperare il nome host (*hostname*) del tuo Backup Storage, clicca sulla scheda <code className="action">Archiviazione remota</code> nell’interfaccia del server dedicato interessato. Il nome host è indicato nel campo **Name** e si presenta generalmente nel formato `ftpback-rbxX-YYY.ovh.net`, `ftpback-rbxX-YYY.ip-Z.Z.Z.net` o `ftpback-bhsX-YYY.ip-Z.Z.Z.net`.

#### FTP/FTPS

##### NcFTP (per Linux)

Per salvare un solo file, esegui il comando:

```sh
ncftpput -u FtpUserName -p FtpPassword HostName /FolderLocation /File
```

**Questo comando non supporta il protocollo FTPS. Per effettuare un trasferimento sicuro, utilizza il client LFTP o cURL.**

Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **FtpUsername**: nome utente FTP
- **FtpPassword**: password FTP
- **HostName**: nome del Backup Storage
- **FolderLocation**: percorso completo della cartella di destinazione in cui salvare il file
- **File**: nome del file di cui vuoi effettuare un backup

Per realizzare il backup di una directory è sufficiente archiviarla e trasferirla nello spazio di backup, con il comando: 

```sh
tar czf - /FolderName | ncftpput -u FtpUserName -p FtpPassword -c HostName ArchiveName.tar.gz
```

Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **FolderName**: percorso completo della cartella di cui vuoi effettuare un backup
- **FtpUsername**: nome utente FTP
- **FtpPassword**: password FTP
- **HostName**: nome del Backup Storage
- **ArchiveName**: nome della cartella di cui vuoi effettuare un backup

Per scaricare un file di backup dallo spazio di storage, utilizza questo il comando:

```sh
ncftpget -v -u FtpUsername -p FtpPassword HostName /LocalFolder /File
```

Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **FtpUsername**: nome utente FTP
- **FtpPassword**: password FTP
- **HostName**: nome del Backup Storage
- **LocalFolder**: percorso completo della cartella locale in cui vuoi salvare il file
- **File**: percorso completo del file da scaricare

##### cURL (per Linux)

:::info
Per utilizzare il protocollo FTPS è necessario modificare il nome del Backup Storage: “ftpback-rbxX-YYY.ip- Z.Z.Z.Z.net”, ad esempio, dovrà essere cambiato in “ftpback-rbxX-YYY.mybackup.ovh.net”. Dovrai inoltre aggiungere l'argomento `-ssl` al seguente comando.  
Se il Backup Storage si trova in Canada (BHS), è necessario cambiarlo nel formato “ftpback-bhsX-YYY.mybackup.ovh.ca”.

:::


Per salvare un solo file, esegui il comando:

```sh
curl -aT File ftp://FtpUsername:FtpPassword@HostName/FolderLocation
```

Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **File**: nome del file di cui vuoi effettuare un backup
- **FtpUsername**: nome utente FTP
- **FtpPassword**: password FTP
- **HostName**: nome del Backup Storage
- **FolderLocation**: percorso completo della cartella di destinazione in cui vuoi salvare il file

Per realizzare il backup di una directory è sufficiente archiviarla e trasferirla nello spazio di backup, con il comando: 

```sh
tar czf - /FolderName | curl ftp://FtpUsername:FtpPassword@HostName/FolderLocation/ArchiveName-$(date +%Y%m%d%H%M).tar.gz -T -
```

Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **FolderName**: percorso di accesso alla cartella di cui vuoi effettuare un backup
- **FtpUsername**: nome utente FTP
- **FtpPassword**: password FTP
- **HostName**: nome del Backup Storage
- **FolderLocation**: percorso completo della cartella locale di destinazione in cui vuoi salvare il file
- **ArchiveName**: nome della cartella di cui vuoi effettuare un backup

Per scaricare un file di backup dallo spazio di storage, utilizza questo il comando:

```sh
cd /LocalFolder
curl -u FtpUsername:FtpPassword ftp://HostName/File 
```

Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **FtpUsername**: nome utente FTP
- **FtpPassword**: password FTP
- **HostName**: nome del Backup Storage
- **LocalFolder**: nome della cartella locale in cui salvare il file
- **File**: percorso completo del file da scaricare

#### lftp (per Linux)

:::info
Di default, lftp utilizza FTP+SSL/TLS. È quindi necessario modificare il nome del Backup Storage: “ftpback-rbxX-YYY.ip- Z.Z.Z.Z.net”, ad esempio, dovrà essere cambiato in “ftpback-rbxX-YYY.mybackup.ovh.net”.  
Se il Backup Storage si trova in Canada (BHS), è necessario cambiarlo nel formato “ftpback-bhsX-YYY.mybackup.ovh.ca”.

:::


Per salvare un solo file, esegui il comando:

```sh
lftp ftp://FtpUsername:FtpPassword@HostName:21 -e "cd FolderLocation; put File; quit"
```

Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **File**: nome del file di cui vuoi effettuare un backup
- **FtpUsername**: nome utente FTP
- **FtpPassword**: password FTP
- **HostName**: nome del Backup Storage
- **FolderLocation**: percorso di accesso alla cartella di destinazione in cui salvare il file

Per realizzare il backup di una directory è sufficiente archiviarla e trasferirla nello spazio di backup, con il comando: 

```sh
tar czf - /FolderName | ftp://FtpUsername:FtpPassword@HostName:21 -e "cd FolderLocation; put /dev/stdin -o ArchiveName-$(date +%Y%m%d%H%M).tar.gz;quit"
```

Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **FolderName**: percorso di accesso alla cartella di cui vuoi effettuare un backup
- **FtpUsername**: nome utente FTP
- **FtpPassword**: password FTP
- **HostName**: nome del Backup Storage
- **FolderLocation**: percorso completo della cartella locale di destinazione in cui vuoi salvare il file
- **ArchiveName**: nome della cartella di cui vuoi effettuare un backup

Per scaricare un file archiviato dal tuo spazio di backup storage, utilizza questo comando:

```sh
cd /LocalFolder
lftp ftp://FtpUsername:FtpPassword@HostName:21 -e "get /File; quit"
```

Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **FtpUsername**: nome utente FTP
- **FtpPassword**: password FTP
- **HostName**: nome del Backup Storage
- **LocalFolder**: nome della cartella locale in cui salvare il file
- **File**: percorso completo del file da scaricare

##### FileZilla

Dopo aver installato FileZilla sul server, è possibile configurarlo per accedere al Backup Storage utilizzando le credenziali FTP ricevute al momento dell’attivazione. Per effettuare il login ti verranno richiesti il nome utente e la password associata.

#### NFS

Il backup storage è compatibile unicamente con NFSv3. Per prima cosa, accertati di aver autorizzato i blocchi di indirizzi IP ad accedere allo spazio di storage e utilizzare il protocollo NFS. In base al sistema operativo Linux utilizzato, è possibile che sia necessario installare il client NFS e avviare i servizi NFS e `portmap` prima di eseguire il mount della share NFS come una normale partizione:

```sh
mount -t nfs -o vers=3 HostName:/export/ftpbackup/ServiceName /FolderMount
```

Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **HostName**: nome del Backup Storage
- **ServiceName**: nome del server (ex:`ns1111111.ip-203-0-113.eu`)
- **FolderMount**: cartella in cui vuoi eseguire il mount della share NFS

Una volta effettuato il mount della share, è possibile utilizzare comandi come `cp` e `rsync` come in una normale directory.

In caso di problemi di connessione, verifica anche che le porte UDP e TCP necessarie per NFSv3 siano aperte nel firewall, sia in entrata che in uscita.
La porta 111 UDP/TCP deve essere aperta in entrambe le direzioni, così come la porta 2049/TCP (NFS) e l'intervallo di porte dinamiche (da 32768 a 60999 UDP/TCP). Queste porte sono utilizzate da RPC per i programmi `mountd`, `lockd` e `statd`.

Infine, autorizza tutte le connessioni in uscita verso l'indirizzo IP del server Backup Storage.

#### CIFS

##### Windows

Accedi al tuo server, apri il prompt dei comandi e digita questo comando:

```sh
net use z: \\HostName\ServiceName 
```

Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **HostName**: nome del Backup Storage
- **ServiceName**: nome del server (ex:`ns1111111.ip-203-0-113.eu`)

È possibile che venga visualizzato il seguente messaggio di errore:

```console
System error 1272 has occurred.

You can't access this shared folder because your organization's security policies block unauthenticated guest access. These policies help protect your PC from unsafe or malicious devices on the network.
```

:::info
Per correggere questo errore, è necessario modificare il registro di sistema di Windows. A tal fine, aprire l'editor del registro (regedit), quindi accedere alla chiave `HKLM\SYSTEM\CurrentControlSet\Services\LanmanWorkstation\Parameters`.<br/>
Assegnare il valore "1" al parametro `AllowInsecureGuestAuth`.<br/>
Trova ulteriori informazioni su questo argomento sulle [pagine di supporto Microsoft](https://learn.microsoft.com/it-it/windows-server/storage/file-server/enable-insecure-guest-logons-smb2-and-smb3).

:::


##### Linux

Accedi al tuo server in SSH ed esegui questo comando:

```sh
mount -t cifs -o vers=2.0,uid=root,gid=100,dir_mode=0700,username=root,password= //HostName/ServiceName /mnt/FolderMount
```

:::warning
Per effettuare il mount delle condivisioni per nome host (al contrario degli indirizzi IP), è necessario utilizzare l’utilità `mount.cifs`. Fa generalmente parte del pacchetto `cifs-utils`.

`mount.cifs` è un wrapper che risolve i nomi host e aggiunge il parametro `ip=` ai parametri di mount passati al kernel.

Senza `mount.cifs`, i tentativi di mount per hostname genereranno il seguente errore:

```text
mount: /mnt/FolderMount: mount(2) system call failed: No route to host.
       dmesg(1) may have more information after failed mount system call.
```

:::


:::info
SMB 2.1 e versioni successive non sono attualmente supportate.

:::


Sostituisci le variabili dell’esempio con le informazioni dei tuoi servizi.

- **HostName**: nome del Backup Storage
- **ServiceName**: nome del server (ex:`ns1111111.ip-203-0-113.eu`)
- **FolderMount**: la cartella in cui vuoi effettuare il mount della share (dovrebbe essere già esistente)
