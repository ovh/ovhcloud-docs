## Obiettivo

Il Game Panel espone la configurazione del server Minecraft direttamente nella sua interfaccia. Le opzioni di base, come la modalità di gioco e la difficoltà, sono accessibili tramite un modulo grafico, mentre i parametri avanzati vi permettono di modificare direttamente il file `server.properties` per un controllo completo.

**Questa guida vi spiega come modificare la configurazione di un server Minecraft sul Game Panel.**

## Prerequisiti

- Un [VPS](https://www.ovhcloud.com/it/vps/) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un server Minecraft distribuito sul Game Panel. Consultate la guida [Distribuire un server Minecraft sul Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

## Procedura

### Step 1 — Aprire i parametri del server

Dalla pagina principale del Game Panel, individuate il server Minecraft da configurare. Nella colonna <code className="action">Management</code>, cliccate su <code className="action">Settings</code>.

<img className="thumbnail" alt="Server Minecraft con il pulsante Settings evidenziato" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-server-settings.png" loading="lazy" />

### Step 2 — Aprire la scheda Game Config

Nel Game Panel **Server Settings**, selezionate <code className="action">Game Config</code> nella barra laterale sinistra.

<img className="thumbnail" alt="Scheda Game Config nel Game Panel Server Settings" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-game-config.png" loading="lazy" />

### Step 3 — Configurare il vostro gioco

La sezione **Game Configuration** vi permette di:

- Attivare o disattivare gli **aggiornamenti automatici**.
- Regolare la **modalità di gioco**, la **difficoltà** e altre opzioni di gameplay.

### Step 4 — Modificare i parametri avanzati

La sezione **Advanced Configuration** vi dà accesso diretto al file `server.properties`, offrendo un controllo maggiore rispetto alle opzioni grafiche di base.

<img className="thumbnail" alt="Sezione Advanced Configuration che mostra l'editor di server.properties" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-advanced-config.png" loading="lazy" />

:::info
Per l'elenco completo delle chiavi di `server.properties` con le relative descrizioni, i valori predefiniti e gli intervalli accettati, consultate la [pagina ufficiale del Wiki Minecraft su server.properties](https://minecraft.wiki/w/Server.properties).
:::


Alcune chiavi comuni che potreste voler modificare:

| Chiave | Descrizione | Valore predefinito |
|-----|-------------|---------|
| `gamemode` | Modalità di gioco predefinita (`survival`, `creative`, `adventure`, `spectator`) | `survival` |
| `difficulty` | Difficoltà del server (`peaceful`, `easy`, `normal`, `hard`) | `easy` |
| `max-players` | Numero massimo di giocatori simultanei | `20` |
| `motd` | Messaggio visualizzato nella lista dei server | `A Minecraft Server` |
| `online-mode` | Limita la connessione agli account Minecraft autenticati | `true` |
| `view-distance` | Distanza di rendering lato server, in chunk (3-32) | `10` |
| `simulation-distance` | Distanza di aggiornamento delle entità, in chunk (3-32) | `10` |
| `white-list` | Limita le connessioni ai giocatori presenti nella whitelist | `false` |
| `hardcore` | Attiva la modalità hardcore | `false` |
| `pvp` | Attiva i danni tra giocatori | `true` |

:::warning
Alcune chiavi (come `level-seed`, `level-type`, `generator-settings`) si applicano solo alla generazione del mondo. Modificarle su un mondo esistente non ha alcun effetto.
:::


### Step 5 — Salvare e riavviare

Salvate le vostre modifiche, quindi riavviate il server Minecraft dal Game Panel per applicare la nuova configurazione.
