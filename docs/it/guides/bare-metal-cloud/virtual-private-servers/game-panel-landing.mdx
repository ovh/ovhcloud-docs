Benvenuti nella documentazione dedicata al [Game Panel OVHcloud](https://www.ovhcloud.com/en-gb/vps/). Il Game Panel vi permette di distribuire e gestire server di gioco per un'ampia gamma di titoli popolari direttamente dal vostro VPS OVHcloud. Qui troverete tutte le guide disponibili per installare, configurare e amministrare i vostri server di gioco.

## Cos'è il Game Panel?

Il Game Panel OVHcloud è un'interfaccia semplificata per distribuire e gestire server di gioco sul vostro VPS. Grazie alla distribuzione automatizzata e agli strumenti integrati, potete avviare istanze, personalizzare le configurazioni e monitorare le prestazioni, senza dover gestire manualmente l'infrastruttura sottostante.

Con il Game Panel potete:

- Distribuire server di gioco per oltre 40 titoli (Minecraft, ARK, Counter-Strike 2, Rust e altri ancora)
- Eseguire più server di gioco su un unico VPS
- Gestire i file dei server, i backup e le attività pianificate
- Controllare gli accessi con autorizzazioni per utente e per server
- Monitorare in tempo reale l'utilizzo di CPU e RAM
