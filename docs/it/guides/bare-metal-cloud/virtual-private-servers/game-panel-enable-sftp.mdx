## Objective

SFTP lets you connect to your game server and access its files and directories. It is more powerful than the Game Panel File Manager and useful for uploading larger files and managing your server.

**This guide explains how to enable SFTP on a game server in the OVHcloud Game Panel.**

## Requirements

- A [VPS](https://www.ovhcloud.com/en-gb/vps/) in your OVHcloud account with the Game Panel feature enabled.
- A game server instance deployed on the Game Panel.
- An SFTP client such as [FileZilla](https://filezilla-project.org/).

:::info
Make sure to download the **client** version of FileZilla, not the server version.
:::


## Instructions

### Step 1 — Log in to the Game Panel

Log in to your Game Panel. If you need help, refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Step 2 — Access SFTP settings

Once logged in:

1. Select your game server.
2. Click <code className="action">Settings</code>.
3. Go to the <code className="action">SFTP</code> tab.

<img className="thumbnail" alt="The SFTP settings tab" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-enable-sftp/sftp-settings.png" loading="lazy" />

### Step 3 — Enable SFTP

Enable SFTP and set a secure password.

Password requirements:

- Minimum 10 characters
- At least one uppercase letter
- At least one number
- At least one special character

<img className="thumbnail" alt="Enabling SFTP with password configuration" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-enable-sftp/enable-sftp.png" loading="lazy" />

### Step 4 — Connect using an SFTP client

Once SFTP is enabled, connect to your server using your SFTP client. The connection information (host, port, username) can be found in the <code className="action">Connection Details</code> section of your Game Panel.

For instructions on using FileZilla, refer to [How to use SFTP to transfer files](/guides/bare-metal-cloud/dedicated-servers/transfer-data-via-sftp/).
