## Obiettivo

Il Game Panel vi permette di distribuire un server Garry's Mod con un'installazione e una configurazione delle porte automatizzate.

**Questa guida vi spiega come distribuire un server Garry's Mod sul Game Panel e come connettervi.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps-game) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel. Andate nella sezione `Game Servers` del menu a sinistra e cliccate su <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Sezione Game Servers con il pulsante Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/game-servers-list.png" loading="lazy" />

### Step 2 — Creare un server Garry's Mod

Selezionate **Garry's Mod** dalla lista dei giochi. Si apre una finestra di configurazione.

<img className="thumbnail" alt="Selezione di Garry's Mod nella lista dei giochi" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/select-garrys-mod.png" loading="lazy" />

### Step 3 — Configurare il server Garry's Mod

Inserite un **Server Name** (ad esempio `Garry's Mod Server`). Le porte di rete richieste vengono configurate automaticamente durante l'installazione.

Potete espandere <code className="action">Advanced settings</code> per regolare opzioni come l'assegnazione delle porte (ports binding) e i limiti delle risorse. I valori predefiniti sono adatti alla maggior parte dei server di gioco.

### Step 4 — Avviare l'installazione

Cliccate su <code className="action">Install</code>. La distribuzione si avvia automaticamente. Attendete qualche minuto durante il download dell'immagine e l'installazione del server.

### Step 5 — Monitorare l'installazione

Cliccate su <code className="action">Log/Console</code> per seguire l'avanzamento in tempo reale. Lo stato mostra **Installing**.

### Step 6 — Confermare il completamento dell'installazione

Una volta terminata l'installazione e avviato il server, lo stato passa a **Running**.

### Step 7 — Verificare che il server sia in esecuzione

Verificate che sia visibile un'attività CPU e RAM. Potete utilizzare i pulsanti <code className="action">Log/Console</code> e <code className="action">Settings</code> per gestire il server.

<img className="thumbnail" alt="Server Garry's Mod con lo stato Running e l'attività CPU e RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-running.png" loading="lazy" />

### Step 8 — Recuperare le informazioni di connessione

Copiate l'indirizzo IP e la porta dalla colonna **Connection** della lista dei Game Servers.

### Step 9 — Unirsi al vostro server su Garry's Mod

Per prima cosa, aggiungete il vostro server ai vostri preferiti Steam:

1. In **Steam**, andate in **View** > **Game Servers**.
2. Aprite la scheda **Favorites** e cliccate su **Add a server**.
3. Incollate l'indirizzo IP e la porta indicati nella colonna **Connection**, quindi cliccate su **OK**.

Raggiungete poi il server dal gioco:

1. Avviate **Garry's Mod** e cliccate su **Find Multiplayer Game**.
2. Aprite la scheda **Favorites**.
3. Selezionate il vostro server e fate doppio clic su di esso per connettervi.

### Configurare i parametri del gioco

Accedete a <code className="action">Settings</code> > <code className="action">Game Config</code> per regolare i principali parametri del vostro server senza modificare alcun file di configurazione.

<img className="thumbnail" alt="I parametri Game Config di un server Garry's Mod" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-game-config.png" loading="lazy" />

| Parametro | Descrizione |
|-----------|-------------|
| `Server name` | Il nome visualizzato nel browser dei server del gioco. |
| `Map` | La mappa caricata all'avvio del server. |
| `Game mode` | La modalità di gioco del server. |
| `Workshop collection` | L'identificativo di una collezione Steam Workshop, scaricata e montata a ogni avvio. La collezione deve essere pubblica o non in elenco. |
| `Counter-Strike: Source content` | Scarica i contenuti di Counter-Strike: Source, riutilizzati da numerosi addon. Anche i giocatori devono possedere il gioco. Aggiunge un download di diversi gigabyte al prossimo avvio. |
| `Maximum players` | Il numero massimo di giocatori simultanei. |
| `Server password` | La password richiesta ai giocatori. Lasciatela vuota per un server pubblico. |
| `Admin password (RCON)` | La password di amministrazione remota del server tramite la console. |
| `Steam GSL token` | Il token che fa apparire il vostro server nel browser dei server ufficiale. Ottenetelo su [steamcommunity.com](https://steamcommunity.com/dev/managegameservers). |
| `Update workshop addons` | Aggiorna gli addon della collezione a ogni avvio. |
| `Update on start` | Verifica e installa gli aggiornamenti del gioco a ogni avvio. |

Le modifiche diventano effettive al riavvio del server.

### Cambiare modalità di gioco

I campi `Game mode` e `Map` accettano testo libero: il menu a tendina propone solo i valori forniti con il gioco, ma potete inserire qualsiasi nome.

**Trouble in Terrorist Town** è fornito con Garry's Mod. Selezionatelo in `Game mode`, quindi riavviate il vostro server. Attenzione alla mappa: `Construct` e `Flatgrass` sono mappe di tipo sandbox, mentre un server TTT ha bisogno di mappe `ttt_` recuperate dal Workshop.

**DarkRP** non è fornito con il gioco e si ottiene tramite il Workshop:

1. Create una collezione Steam Workshop, pubblica o non in elenco, contenente DarkRP, le sue dipendenze e una mappa `rp_`.
2. Inserite il suo identificativo in `Workshop collection`.
3. Digitate `darkrp` in `Game mode` e il nome della vostra mappa in `Map`.
4. Attivate `Counter-Strike: Source content`, le cui texture sono riutilizzate da numerosi addon DarkRP.
5. Riavviate il vostro server.

<img className="thumbnail" alt="Le impostazioni Game mode, Workshop collection e Counter-Strike: Source content" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/gameplay-settings.png" loading="lazy" />

:::warning
Il campo `Map` indica la mappa da caricare, ma non la scarica. Una mappa assente dalla vostra collezione Workshop non verrà trovata all'avvio e il server non si avvierà.
:::
