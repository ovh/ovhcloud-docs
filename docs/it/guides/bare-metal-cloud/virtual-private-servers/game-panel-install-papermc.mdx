## Obiettivo

PaperMC è un'implementazione ad alte prestazioni del server Minecraft, compatibile con plugin che estendono le funzionalità di gioco. Il Game Panel permette di distribuire un server PaperMC in pochi clic, per poi personalizzarlo caricando dei plugin.

**Questa guida vi spiega come installare un server PaperMC sul Game Panel e aggiungere dei plugin.**

## Prerequisiti

- Un [VPS](https://www.ovhcloud.com/it/vps/) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Installare un server PaperMC

Dalla pagina principale del Game Panel, cliccate su <code className="action">Add Game Server</code>, individuate **PaperMC** e cliccate su <code className="action">Select</code>.

Per maggiori dettagli sull'installazione di un server, consultate la guida [Primi passi con il Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

### Step 2 — Scaricare dei plugin

Scaricate i plugin da una fonte affidabile come il repository [PaperMC Hangar](https://hangar.papermc.io/).

### Step 3 — Caricare i plugin con il File Manager

Sul vostro server PaperMC, cliccate su <code className="action">Settings</code>, poi aprite la scheda <code className="action">File Manager</code>. Accedete alla cartella `serverfiles`, aprite la directory `plugins` e caricate i file dei vostri plugin tramite <code className="action">Upload files</code> oppure trascinandoli.

### Step 4 — Riavviare il server

Dalla pagina principale del Game Panel, riavviate il vostro server tramite il pulsante dedicato.

:::info
Monitorate i log del server per verificare che si avvii correttamente e che i plugin siano caricati.
:::
