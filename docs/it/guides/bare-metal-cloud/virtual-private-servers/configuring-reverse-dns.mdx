## Obiettivo

Il Reverse DNS (*rDNS*) è il complemento della risoluzione DNS "*forward*" che permette di risolvere i nomi di dominio in indirizzi IP. Grazie al reverse DNS, un indirizzo IP può essere risolto in nome di dominio (o nome host) a cui è associato. Questo significa che le richieste DNS dell'indirizzo IP associato restituiranno questo nome di dominio.

La configurazione del reverse DNS di un server è particolarmente utile durante l'invio di email. La convalida di un server di posta da parte dei sistemi di protezione antispam migliora se una richiesta DNS dell'indirizzo IP viene risolta correttamente.

**Questa guida ti mostra come configurare il reverse DNS di un indirizzo IP dalla console OVHcloud.**

## Prerequisiti

- Un indirizzo IP associato a un servizio del tuo account OVHcloud
- Un dominio con il suo record `A` o `AAAA` associato al tuo servizio

## Procedura
Nella pagina **Indirizzi IP**, puoi restringere l'elenco con i filtri rapidi situati sopra la tabella (**IPv4**, **IPv6**, **IP aggiuntivo**, **BYOIP**). Puoi anche cercare un indirizzo IP specifico nel campo **Cerca**.

<img className="thumbnail" alt="Pagina Indirizzi IP della console OVHcloud con il campo Cerca" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/ip-list-search.png" loading="lazy" />

Clicca sull'indirizzo IP interessato per aprirne la pagina, quindi clicca sulla scheda <code className="action">Reverse DNS</code>. Clicca sul pulsante <code className="action">Configura</code> sopra la tabella.

<img className="thumbnail" alt="Scheda Reverse DNS di un indirizzo IP nella console OVHcloud con il pulsante Configura" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-tab.png" loading="lazy" />

Nella finestra **Configura il Reverse DNS**, inserisci il tuo reverse nel campo **Nome host reverse DNS** e clicca su <code className="action">Configura</code>.

<img className="thumbnail" alt="Finestra Configura il Reverse DNS della console OVHcloud con il campo Nome host reverse DNS" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-configure.png" loading="lazy" />

Per modificare un reverse esistente, segui la stessa procedura: se l'indirizzo IP dispone già di un reverse, il campo **Nome host reverse DNS** si apre precompilato con quest'ultimo. Sostituiscilo con il nuovo valore e clicca su <code className="action">Configura</code>.

:::warning
Quando inserisci il tuo dominio nel reverse, verifica immediatamente se il record `A` / `AAAA` restituisce lo stesso IP. Questa operazione viene utilizzata nelle procedure anti-spam e il record DNS deve essere valido e divulgato. Per inserire il reverse, è necessario seguire alcune regole:

 - il *reverse* non può iniziare con un `-`
 - il *reverse* non può contenere più di 63 caratteri
 - il *reverse* non può contenere caratteri maiuscoli
 - il *reverse* può terminare con un `.`: la console OVHcloud accetta sia `domain.tld` sia `domain.tld.`.

:::


:::info
Se la modifica non funziona come previsto, verifica che il record `A` / `AAAA` sia configurato correttamente nella zona DNS del dominio. L’applicazione delle modifiche nella zona DNS potrebbe richiedere fino a 24 ore, nel caso in cui il record sia stato modificato.

Se il nome di dominio è gestito da OVHcloud come registro **e utilizza i server DNS OVHcloud**, puoi fare riferimento a [questa guida](/guides/web-cloud/domains/dns-zone-edit).

:::
