## Obiettivo

Il Game Panel OVHcloud vi permette di installare un server ARK: Survival Evolved in pochi passaggi. Il Game Panel gestisce automaticamente l'installazione, compresa la configurazione delle porte.

**Questa guida vi spiega come installare un server ARK: Survival Evolved sul Game Panel OVHcloud e come connettervi.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel OVHcloud.

### Step 2 — Creare una nuova istanza di server

Cliccate su <code className="action">Add Game Server</code> e selezionate **ARK: Survival Evolved**.

<img className="thumbnail" alt="Selezione di ARK: Survival Evolved nella lista dei giochi" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/select-ark.png" loading="lazy" />

:::info
Se si tratta del vostro primo server ARK sul Game Panel e la porta di gioco predefinita è disponibile, tutte le porte richieste verranno configurate automaticamente durante l'installazione. In questo caso non è necessaria alcuna configurazione manuale.
:::


### Step 3 — Seguire l'avanzamento dell'installazione

Una volta avviata l'installazione, appare una schermata di conferma. Cliccate su <code className="action">Log/Console</code> per seguire l'avanzamento dell'installazione in tempo reale.

Durante l'installazione del server, lo stato mostra **Installing**. Seguite l'avanzamento dettagliato direttamente nel pannello dei log.

<img className="thumbnail" alt="Monitoraggio dell'installazione del server ARK nel pannello dei log" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/installation-logs.png" loading="lazy" />

### Step 4 — Confermare il completamento dell'installazione

Una volta terminata l'installazione, lo stato del server passa a **Running**.

<img className="thumbnail" alt="Server ARK con lo stato Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/server-running.png" loading="lazy" />

### Step 5 — Recuperare le informazioni di connessione

Quando lo stato del vostro server è **Running**, copiate le informazioni di connessione dal Game Panel.

<img className="thumbnail" alt="Dettagli di connessione del server ARK" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-ark/connection-details.png" loading="lazy" />

### Step 6 — Raggiungere il vostro server in ARK

Per prima cosa, aggiungete il vostro server ai vostri preferiti Steam:

1. In **Steam**, andate in **View** > **Game Servers**.
2. Aprite la scheda **Favorites** e cliccate su **Add a server**.
3. Incollate l'indirizzo IP e la porta indicati nella colonna **Connection**, quindi cliccate su **OK**.

Raggiungete poi il server dal gioco:

1. Avviate **ARK: Survival Evolved** e cliccate su **Join ARK**.
2. Impostate il **Session Filter** su **Favorites**.
3. Selezionate il vostro server e cliccate su **Join**.
