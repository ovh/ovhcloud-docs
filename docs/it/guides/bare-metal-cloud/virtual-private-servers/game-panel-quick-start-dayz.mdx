## Obiettivo

Il Game Panel vi permette di distribuire un server DayZ in pochi passaggi. Il Game Panel gestisce automaticamente l'installazione, compresi l'autenticazione Steam e la configurazione delle porte di rete.

**Questa guida vi spiega come distribuire un server DayZ sul Game Panel e come connettervi.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Un account Steam per autenticare l'installazione del server DayZ.

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel.

Nel menu a sinistra, andate nella sezione <code className="action">Game Servers</code> e cliccate su <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Sezione Game Servers con il pulsante Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/add-game-server.png" loading="lazy" />

Selezionate **DayZ** dalla lista dei giochi. Si apre una finestra di configurazione.

### Step 2 — Configurare il server

Nella finestra di configurazione:

- Inserite un **Server Name**.
- Inserite il vostro **Steam Username** e la vostra **Steam Password**.

:::warning
È fortemente consigliato utilizzare un account Steam dedicato a questo scopo, e non il vostro account personale. Utilizzate una password complessa e disattivate l'autenticazione a due fattori via e-mail (Steam Guard) su questo account prima di continuare.
:::


<img className="thumbnail" alt="Modulo di installazione di DayZ che mostra il nome del server e i campi delle credenziali Steam" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/install-dayz-form.png" loading="lazy" />

:::info
Le porte di rete richieste vengono configurate automaticamente durante l'installazione. Se si tratta del vostro primo server DayZ sul Game Panel e le porte predefinite sono disponibili, non è necessaria alcuna modifica manuale.
:::


### Step 3 — Avviare l'installazione

Cliccate su <code className="action">Select</code>. La distribuzione si avvia automaticamente. Il Game Panel:

1. Scaricherà l'immagine del server DayZ.
2. Installerà i file del server.

Una volta completata l'installazione, cliccate su <code className="action">Launch</code> per avviare il vostro server.

### Step 4 — Verificare che il server funzioni

Una volta avviato, verificate che lo stato del server sia **Running**. Un'attività CPU e RAM deve essere visibile nel Game Panel.

I seguenti comandi sono disponibili:

- <code className="action">Log/Console</code> — seguite l'avvio e l'attività del server in tempo reale, e consultate i log in caso di problema.
- <code className="action">Settings</code> — accedete alle opzioni di configurazione del gioco.

<img className="thumbnail" alt="Server DayZ con lo stato Running e i controlli di gestione" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/server-running.png" loading="lazy" />

### Step 5 — Configurare i parametri del gioco (facoltativo)

Cliccate su <code className="action">Settings</code> sul vostro server, poi aprite <code className="action">Game Config</code> per regolare le opzioni accessibili dal Game Panel, come gli aggiornamenti automatici.

Per una configurazione avanzata, utilizzate il [File Manager](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/) per modificare direttamente il file di configurazione del server DayZ.

<img className="thumbnail" alt="Pannello Server Settings con le opzioni Game Config e File Manager" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/game-config.png" loading="lazy" />

### Step 6 — Connettersi al server

Nella colonna **Connection** della lista Game Servers, copiate l'indirizzo IP e la porta del vostro server.

Per accedere dal client DayZ:

1. Avviate **DayZ**.
2. Andate in **Server** e cliccate su **Direct connect**.
3. Incollate l'indirizzo IP e la porta indicati nella colonna **Connection**.
4. Cliccate su **Connect**.

<img className="thumbnail" alt="Lista Game Servers con l'indirizzo IP di connessione e la porta evidenziati" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/connection-details.png" loading="lazy" />
