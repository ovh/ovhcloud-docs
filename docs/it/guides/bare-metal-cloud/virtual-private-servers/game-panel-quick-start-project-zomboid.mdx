## Obiettivo

Il Game Panel OVHcloud vi permette di distribuire un server Project Zomboid con un'installazione e una configurazione delle porte automatizzate.

**Questa guida vi spiega come distribuire un server Project Zomboid sul Game Panel OVHcloud e come connettervi.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel OVHcloud. Nel menu a sinistra, accedete alla sezione `Game Servers` e cliccate su <code className="action">Add Game Server</code>.

### Step 2 — Creare un server Project Zomboid

Selezionate **Project Zomboid** dalla lista dei giochi. Si apre una finestra di configurazione.

<img className="thumbnail" alt="Selezione di Project Zomboid dalla lista dei giochi del Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/select-project-zomboid.png" loading="lazy" />

### Step 3 — Configurare il server Project Zomboid

In questa sezione potete definire un nome per il vostro server e selezionare il <code className="action">Branch</code>, ovvero il ramo Steam del gioco da installare, la cui lista viene aggiornata automaticamente. Scegliete con attenzione: modificare il ramo in un secondo momento può corrompere un mondo esistente. Si tratta quindi di una scelta da effettuare al momento dell'installazione.

Viene inoltre generata automaticamente una password di amministratore. È la password dell'account amministratore nel gioco, utilizzata per attribuirvi i diritti di amministratore ed eseguire i comandi privilegiati della console: **non** è la password che i giocatori utilizzano per connettersi al server.

:::warning
Assicuratevi di conservare questa password di amministratore in un luogo sicuro.
:::

Potete espandere <code className="action">Advanced Settings</code> per regolare opzioni come la mappatura delle porte (ports binding) e i limiti delle risorse. I valori predefiniti sono adatti alla maggior parte dei server di gioco.

<img className="thumbnail" alt="Modulo di configurazione del server Project Zomboid con il branch e la password di amministratore" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/configure-server.png" loading="lazy" />

### Step 4 — Avviare l'installazione

Cliccate su <code className="action">Install</code> per avviare la distribuzione.

### Step 5 — Monitorare l'installazione

Cliccate su <code className="action">Log/Console</code> per seguire l'avanzamento dell'installazione in tempo reale. Non appena l'installazione inizia, il Game Panel propone anche un pulsante <code className="action">Open Logs / Console</code> che apre la stessa visualizzazione.

Durante l'installazione del server, lo stato visualizza **Installing**. Il pannello dei log mostra l'avanzamento dettagliato.

<img className="thumbnail" alt="Monitoraggio dell'installazione del server Project Zomboid nel pannello dei log" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/installation-logs.png" loading="lazy" />

### Step 6 — Confermare il completamento dell'installazione

Una volta completata l'installazione, lo stato del server passa a **Running**.

### Step 7 — Verificare che il server sia in esecuzione

Verificate che sia visibile un'attività CPU e RAM. Potete utilizzare i controlli <code className="action">Log/Console</code> e <code className="action">Settings</code> per gestire il server.

<img className="thumbnail" alt="Server Project Zomboid con lo stato Running e attività CPU e RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/server-running.png" loading="lazy" />

### Step 8 — Recuperare le informazioni di connessione

Copiate l'indirizzo IP e la porta dalla colonna **Connection** della lista `Game Servers`.

### Step 9 — Unirsi al vostro server su Project Zomboid

Per unirvi al vostro server dal client Project Zomboid:

1. Aprite **Project Zomboid** e cliccate su **Multiplayer**, poi su **Add server**.
2. Inserite un nome per il server, poi l'indirizzo IP e la porta indicati nella colonna **Connection** del Game Panel. Inserite anche la password del server, se ne è stata definita una: è la password che i giocatori utilizzano per connettersi, non la password di amministratore.
3. Cliccate su **SAVE**.
4. Create un account di gioco per questo server cliccando su **Add new account**, poi inserite un nome e una password.

### Connettersi come amministratore

Una volta aggiunto il server nel menu **Multiplayer**, create un nuovo personaggio per questo server. Durante la creazione, scegliete un nome utente e inserite la password di amministratore del server.

Per recuperare questa password, cliccate su <code className="action">Settings</code> nel Game Panel, aprite la sezione <code className="action">Game Config</code>, poi la scheda <code className="action">Server Settings</code>: il campo **Admin Password** si trova in fondo alla pagina. Il valore è mascherato: cliccate sull'icona a forma di occhio per visualizzarlo.

Una volta connessi con questo personaggio, un'icona **Admin** appare sulla sinistra dello schermo. Cliccateci sopra per accedere agli strumenti di amministrazione, eseguire comandi e moderare il vostro server.

### Aggiornare il server a una nuova versione del gioco

Per impostazione predefinita, il server non si aggiorna automaticamente quando è disponibile una nuova versione, per evitare problemi di compatibilità o l'interruzione delle partite.

Per attivare gli aggiornamenti automatici, cliccate su <code className="action">Settings</code>, aprite la sezione <code className="action">Game Config</code>, poi attivate l'opzione <code className="action">Update on start</code> in fondo alla pagina (disattivata per impostazione predefinita). Cliccate su <code className="action">Save &amp; Restart</code> per applicare le modifiche. Il server applica quindi automaticamente ogni nuovo aggiornamento.
