## Obiettivo

Il Game Panel OVHcloud vi permette di distribuire e gestire server di gioco direttamente sul vostro VPS. Prima di utilizzarlo, dovete installarlo sul vostro server dallo Spazio Cliente OVHcloud.

**Questa guida vi spiega come installare il Game Panel sul vostro VPS.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) nel vostro account OVHcloud.
- Un accesso allo <ManagerLink to="/">Spazio Cliente OVHcloud</ManagerLink>.

## Procedura

### Step 1 — Accedere allo Spazio Cliente OVHcloud

Connettetevi al vostro <ManagerLink to="/">Spazio Cliente OVHcloud</ManagerLink>. Se avete bisogno di aiuto per connettervi, consultate la guida [Accedi allo Spazio Cliente OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-login/).

### Step 2 — Passare alla versione Beta dello Spazio Cliente OVHcloud

La funzionalità di installazione del Game Panel è attualmente disponibile nella versione Beta dello Spazio Cliente OVHcloud.

In alto a destra nella pagina, cliccate su <code className="action">Discover our new Manager in Beta</code> per passare all'interfaccia Beta.

### Step 3 — Aprire la pagina del vostro VPS

Dallo Spazio Cliente OVHcloud:

1. Cliccate su <code className="action">Bare Metal Cloud</code>.
2. Nel menu a destra, selezionate <code className="action">Server Privati Virtuali</code>.

### Step 4 — Installare il Game Panel

Nella pagina **Dashboard**, individuate la sezione **Your VPS** e cliccate su <code className="action">Game Panel</code>.

<img className="thumbnail" alt="La voce Game Panel nella sezione Your VPS del dashboard del VPS" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/game-panel-entry.png" loading="lazy" />

Si apre il modulo di installazione del Game Panel. Compilate i campi seguenti, quindi avviate l'installazione.

<img className="thumbnail" alt="Il modulo di installazione del Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/install-form.png" loading="lazy" />

**Scegliere un sistema operativo**

Selezionate il sistema operativo su cui desiderate installare il Game Panel. Tutti i sistemi operativi visualizzati nella lista sono pienamente compatibili con il Game Panel.

**Configurare il nome a dominio**

Per impostazione predefinita, il Game Panel viene installato utilizzando il nome host predefinito del vostro server, permettendovi di accedervi tramite un indirizzo simile a `https://vps-xxxx.vps.ovh.net`.

Se preferite, potete utilizzare il vostro nome a dominio. Prima di continuare, assicuratevi che il vostro dominio punti all'indirizzo IP pubblico del vostro VPS.

Se non possedete ancora un nome a dominio o se dovete configurare i suoi record DNS, consultate le risorse seguenti:

- [I nomi a dominio OVHcloud](/links/web/domains)
- [Modificare una zona DNS di OVHcloud](/guides/web-cloud/domains/dns-zone-edit/)

**Inserire un indirizzo e-mail**

Vi viene richiesto un indirizzo e-mail. Per impostazione predefinita, è l'indirizzo e-mail associato al vostro account OVHcloud. Viene utilizzato durante la configurazione del certificato SSL e può anche ricevere notifiche occasionali relative al certificato qualora fosse necessaria un'azione.

**Scegliere il nome dell'account amministratore**

Inserite il nome utente dell'account amministratore che verrà creato. Questo account diventa il super amministratore del Game Panel e dispone del livello di privilegi più elevato.

**Conservare la password amministratore generata**

Viene generata e visualizzata una password per il Game Panel. Conservate questa password in un luogo sicuro, poiché non potrà più essere consultata in seguito.

**(Facoltativo) Aggiungere una chiave SSH**

Se lo desiderate, potete aggiungere una chiave SSH pubblica. Si tratta di una configurazione avanzata facoltativa.

**Avviare l'installazione**

Cliccate su <code className="action">Install Game Panel</code> per avviare l'installazione.

### Step 5 — Connettersi al Game Panel

Il sistema operativo selezionato viene installato per primo. Una volta distribuito, ricevete un'e-mail automatica contenente la password SSH del vostro server. Conservate questa password in un luogo sicuro, poiché potreste averne bisogno in seguito se vi connettete direttamente al server tramite SSH.

Qualche minuto più tardi, l'installazione del Game Panel si completa automaticamente.

Potete quindi aprire il nome host del vostro server in un browser web, ad esempio `https://vps-xxxx.vps.ovh.net`. Connettetevi con la password generata durante l'installazione per iniziare a utilizzare il Game Panel.

:::info
La password amministratore generata viene visualizzata una sola volta durante l'installazione. Se la perdete, consultate la sezione di recupero della password della guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
:::
