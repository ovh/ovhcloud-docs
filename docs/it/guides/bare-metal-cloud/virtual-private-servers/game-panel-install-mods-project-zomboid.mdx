## Obiettivo

Il Game Panel OVHcloud vi consente di personalizzare il vostro server Project Zomboid installando mod provenienti dallo Steam Workshop.

**Questa guida spiega come installare le mod sul vostro server Project Zomboid ospitato sul Game Panel OVHcloud.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un server Project Zomboid distribuito sul Game Panel. Consultate la guida [Distribuire un server Project Zomboid sul Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-project-zomboid/).
- Avere accesso al Game Panel. Consultate la guida [Connettersi al Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Trovare le mod desiderate

Le mod di Project Zomboid sono distribuite tramite lo [Steam Workshop](https://steamcommunity.com/app/108600/workshop/). Sfogliate il Workshop e individuate le mod che desiderate installare.

Una volta aperta la pagina di una mod, osservate l'URL nel vostro browser. Il **Workshop ID** è il numero che compare dopo `?id=`.

Ad esempio:

```text
https://steamcommunity.com/sharedfiles/filedetails/?id=3762296152
```

In questo esempio, il Workshop ID è `3762296152`. Copiate questo identificativo: vi servirà nello step successivo.

<img className="thumbnail" alt="Il Workshop ID evidenziato nella barra degli indirizzi sulla pagina di una mod" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/steam-workshop-mod-page.png" loading="lazy" />

:::warning
Verificate sempre che la mod sia compatibile con la versione del gioco del vostro server. Ad esempio, una mod Build 41 (B41) molto probabilmente non funzionerà su un server Build 42 (B42). L'installazione di mod incompatibili può impedire l'avvio del server.
:::

### Step 2 — Aggiungere la mod dal Game Panel

:::warning
Il vostro server deve essere arrestato prima di aggiungere o eliminare delle mod. Le modifiche alle mod vengono applicate al successivo avvio.
:::

Se il vostro server è in esecuzione, arrestatelo: nella lista `Game Servers`, cliccate sull'icona di arresto nella colonna **Power** del vostro server, poi confermate. Tutti i giocatori connessi vengono disconnessi.

Nel Game Panel, individuate il vostro server Project Zomboid nella lista `Game Servers`, poi accedete a <code className="action">Settings</code> > <code className="action">Game Config</code> > <code className="action">Mods</code>.

<img className="thumbnail" alt="La scheda Mods in Game Config sul Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/game-config-mods-tab.png" loading="lazy" />

Cliccate su <code className="action">Add mods</code>, poi inserite il Workshop ID copiato in precedenza.

<img className="thumbnail" alt="Inserimento di un Workshop ID nella finestra Add Workshop mods" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/add-mods.png" loading="lazy" />

#### Aggiungere più mod contemporaneamente

Potete aggiungere più Workshop ID contemporaneamente separandoli con:

- spazi
- virgole
- ritorni a capo

Dopo aver aggiunto le vostre mod, potete riorganizzarne l'**ordine di caricamento** con le frecce su e giù di ogni riga.

#### Mod che contengono più Mod ID

Alcuni elementi del Workshop contengono più **Mod ID**. Ad esempio, una revisione dell'interfaccia può includere due Mod ID:

- `UI_Dark`
- `UI_Light`

In questo caso, attivatene uno solo, non entrambi.

Potete attivare o disattivare ogni Mod ID tramite l'interruttore situato alla fine di ogni riga.

<img className="thumbnail" alt="Elenco delle mod installate con l'ordine di caricamento e l'interruttore di ogni riga" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-project-zomboid/mods-list.png" loading="lazy" />

### Step 3 — Avviare il vostro server

Tornate sulla pagina principale del Game Panel e cliccate su <code className="action">Start</code> per avviare il vostro server.

Quando i giocatori si connettono, il client Project Zomboid scarica automaticamente le mod Workshop installate sul server.

### Aumentare la memoria allocata al gioco

Se utilizzate un gran numero di mod, Project Zomboid potrebbe richiedere più memoria lato client. Se il gioco fatica ad avviarsi o si blocca a causa di un utilizzo intensivo di mod, allocate più RAM.

Per farlo:

1. Chiudete completamente Project Zomboid.
2. Aprite **Steam** e individuate **Project Zomboid** nella vostra libreria.
3. Cliccate sull'icona a forma di ingranaggio situata a destra.
4. Selezionate **Gestisci** > **Sfoglia i file locali**.
5. Nella cartella del gioco, individuate il file `ProjectZomboid64.json` e apritelo con il **Blocco note** (o con qualsiasi altro editor di testo).
6. Scorrete il file fino alla sezione `VMArgs`.
7. Individuate la riga contenente `-Xmx3072m` e sostituite il valore di memoria con un valore superiore, ad esempio `-Xmx8g`. In questo modo vengono allocati 8 GB di RAM al gioco, se il vostro computer dispone di memoria sufficiente.
8. Salvate il file, chiudetelo e riavviate Project Zomboid.

:::info
Non allocate al gioco tutta la memoria RAM del vostro sistema. Lasciate memoria sufficiente per il sistema operativo e per le applicazioni in background, in modo che il vostro sistema resti stabile.
:::

### Installare le mod manualmente

Potete anche installare le vostre mod manualmente invece di utilizzare l'importatore automatico del Workshop. Il file da modificare manualmente è `/zomboid/Server/<nome_del_server>.ini` (per impostazione predefinita `servertest.ini`).

Il Game Panel offre un collegamento diretto a questo file: aprite <code className="action">Settings</code> > <code className="action">Game Config</code> > <code className="action">Server Settings</code>, espandete <code className="action">Advanced Configuration</code>, poi cliccate su <code className="action">Open in File Manager</code> accanto alla voce **INI**.

:::warning
Non utilizzate i due metodi contemporaneamente. Se installate le vostre mod manualmente e successivamente utilizzate la funzionalità di importazione automatica, le vostre modifiche manuali rischiano di essere sovrascritte, con conseguenti conflitti o perdita della configurazione. Scegliete l'installazione automatica oppure quella manuale, ma evitate di combinare le due.
:::
