## Obiettivo

Il Game Panel OVHcloud vi permette di distribuire un server Hytale con un'installazione e una configurazione delle porte automatizzate.

**Questa guida vi spiega come distribuire un server Hytale sul Game Panel OVHcloud e come connettervi.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Un account Hytale, necessario per autenticarvi durante l'installazione.

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel OVHcloud. Andate nella sezione **Game Servers** del menu a sinistra e cliccate su <code className="action">Add Game Server</code>.

### Step 2 — Creare un server Hytale

Selezionate **Hytale** dalla lista dei giochi. Si apre una finestra di configurazione.

<img className="thumbnail" alt="Selezione di Hytale nella lista dei giochi" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-hytale/select-hytale.png" loading="lazy" />

### Step 3 — Configurare il server Hytale

Inserite un **Server Name** (ad esempio `Hytale Server`). Le porte di rete richieste vengono configurate automaticamente durante l'installazione.

Potete espandere <code className="action">Advanced settings</code> per regolare opzioni come l'assegnazione delle porte (ports binding) e i limiti delle risorse. I valori predefiniti sono adatti alla maggior parte dei server di gioco.

### Step 4 — Avviare l'installazione

Cliccate su <code className="action">Install</code>. La distribuzione si avvia automaticamente. Attendete qualche minuto durante il download dell'immagine e l'installazione del server.

Durante l'installazione, il Game Panel vi invita ad autenticarvi con il vostro account Hytale tramite un pulsante che vi reindirizza al sito ufficiale Hytale utilizzando OAuth. Vi viene richiesto di autenticarvi due volte:

- La prima autenticazione permette al Game Panel di scaricare i file del server.
- La seconda autenticazione avviene al primo avvio del server ed è necessaria per ottenere una sessione di gioco da Hypixel.

Una volta completata ciascuna autenticazione, il processo di installazione e avvio prosegue automaticamente.

### Step 5 — Monitorare l'installazione

Cliccate su <code className="action">Log/Console</code> per seguire l'avanzamento in tempo reale. Lo stato mostra **Installing**.

### Step 6 — Verificare che il server sia in esecuzione

Verificate che lo stato del server visualizzi **Running** e che sia visibile un'attività CPU/RAM.

Azioni disponibili:

- <code className="action">Log/Console</code>: aprite la console per seguire l'avvio e consultate i log in caso di problema.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: accedete ai parametri del gioco.

<img className="thumbnail" alt="Server Hytale con lo stato Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-hytale/hytale-running.png" loading="lazy" />

### Step 7 — Confermare il completamento dell'installazione

Una volta terminata l'installazione, lo stato passa a **Running** e il server è pronto all'uso.

### Step 8 — Recuperare le informazioni di connessione

Nella colonna **Connection** della lista dei Game Servers, copiate l'indirizzo IP e la porta del vostro server.

### Step 9 — Unirsi al vostro server su Hytale

In Hytale:

1. Avviate il gioco e aprite il menu **Servers**.
2. Cliccate su **Direct Connect** e inserite l'indirizzo IP e la porta della colonna **Connection**.
3. Cliccate su **Connect** per unirvi al vostro server.

### Buone pratiche

- Configurate i permessi tramite <code className="action">User Administration</code>.
- Effettuate backup regolari.
- Personalizzate i parametri del vostro gioco.

:::info
Per saperne di più, regolate i parametri del vostro server, limitate l'accesso con una password o una whitelist, oppure ottimizzate le opzioni di prestazione.
:::
