## Obiettivo

Il Game Panel OVHcloud vi permette di distribuire un server Rust con un'installazione e una configurazione delle porte automatizzate.

**Questa guida vi mostra come distribuire un server Rust sul Game Panel OVHcloud e connettervi ad esso.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel OVHcloud. Nel menù a sinistra, accedete alla sezione `Game Servers` e cliccate su <code className="action">Add Game Server</code>.

### Step 2 — Creare un server Rust

Selezionate **Rust** nella lista dei giochi. Per trovarlo più rapidamente, potete utilizzare il campo di ricerca situato nella parte superiore della finestra. Si apre una finestra di configurazione.

<img className="thumbnail" alt="Selezione di Rust nella lista dei giochi del Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/select-rust.png" loading="lazy" />

### Step 3 — Configurare il server Rust

In questa sezione potete definire un nome per il vostro server nel campo **Server Name**.

Viene inoltre generata automaticamente una **RCON Password**. È utilizzata dal sistema RCON del gioco per amministrare il server da remoto. Cliccate su <code className="action">Regenerate</code> per ottenerne una nuova oppure sostituitela con una password a vostra scelta (almeno 8 caratteri). Potrete modificarla nuovamente una volta installato il server.

:::warning
Conservate questa password in un luogo sicuro. Chiunque ne sia a conoscenza può eseguire comandi di amministrazione sul vostro server.
:::

Potete espandere <code className="action">Advanced Settings</code> per modificare opzioni come la mappatura delle porte (ports binding), i volumi, le variabili d'ambiente e i limiti delle risorse. I valori predefiniti sono adatti alla maggior parte dei server di gioco.

<img className="thumbnail" alt="Modulo di configurazione del server Rust con il nome del server e le impostazioni avanzate" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/configure-server.png" loading="lazy" />

:::info
Se si tratta del vostro primo server Rust sul Game Panel e le porte predefinite sono disponibili, tutte le porte necessarie vengono configurate automaticamente. Non è richiesta alcuna configurazione manuale. L'immagine Rust utilizza tre porte: `28015/UDP` (Game), `28017/UDP` (Steam Query) e `28082/TCP` (Rust+ companion app). Se queste porte sono già utilizzate da un altro server di gioco, il Game Panel assegna delle porte host libere.
:::

### Step 4 — Avviare l'installazione

Cliccate su <code className="action">Install</code> per avviare l'installazione. La distribuzione ha inizio e una finestra di avanzamento mostra le seguenti fasi:

1. Download dell'immagine del container.
2. Preparazione dei file del server.
3. Creazione del container.
4. Avvio del container.

### Step 5 — Monitorare l'installazione

Una volta avviato il container, viene visualizzata una finestra di conferma. Cliccate su <code className="action">Open Logs / Console</code> per seguire l'avanzamento dell'installazione in tempo reale. Potete aprirla in qualsiasi momento anche con il pulsante <code className="action">Log/Console</code> del vostro server.

<img className="thumbnail" alt="Finestra di conferma con il pulsante Open Logs / Console" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/installation-started.png" loading="lazy" />

La console mostra le fasi dell'installazione e successivamente il download dei file del server Rust tramite SteamCMD, con una percentuale di avanzamento.

<img className="thumbnail" alt="Log di installazione del server Rust nella console del Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/installation-logs.png" loading="lazy" />

:::warning
I file del server Rust corrispondono a un download di diversi gigabyte. Il server mantiene lo stato **Installing** per tutta la durata del download e successivamente durante la generazione del mondo di gioco. Consultate la console per seguire l'avanzamento reale.
:::

### Step 6 — Verificare che il server sia in esecuzione

Verificate che lo stato del server sia **Running** e che sia visibile un'attività della CPU e della RAM. Potete utilizzare i comandi <code className="action">Log/Console</code> e <code className="action">Settings</code> per gestire il server, e i comandi <code className="action">Stop</code> e <code className="action">Restart</code> per modificarne lo stato di alimentazione.

<img className="thumbnail" alt="Server Rust con lo stato Running e l'attività della CPU e della RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/server-running.png" loading="lazy" />

### Step 7 — Confermare il completamento dell'installazione

Una volta completato il download, la console mostra l'avvio del server Rust e successivamente la generazione del mondo di gioco (mappa delle altezze, biomi, monumenti). Questa fase può richiedere diversi minuti.

Lo stato può visualizzare brevemente **Unhealthy** mentre il server completa l'avvio e non risponde ancora alla verifica di stato. Questo comportamento è normale durante una prima installazione.

Lo stato del server passa a **Running** una volta generato il mondo e quando il server è in ascolto. Il vostro server Rust è quindi pronto ad accettare le connessioni.

### Step 8 — Recuperare le informazioni di connessione

Una volta avviato il server, copiate l'indirizzo IP e la porta dalla colonna **Connection** della lista dei server di gioco. Utilizzate il pulsante di copia per copiarli negli appunti.

### Step 9 — Unirsi al vostro server su Rust

Per unirvi al vostro server dal client di gioco Rust:

1. Avviate **Rust**.
2. Premete il tasto `F1` per aprire la console di gioco.
3. Inserite il comando seguente, sostituendo `IP` e `PORT` con i valori della colonna **Connection**:

```console
client.connect IP:PORT
```

### Configurare i parametri di gioco

La sezione <code className="action">Game Config</code> vi permette di modificare i principali parametri del vostro server Rust senza modificare manualmente i file di configurazione:

| Parametro | Descrizione |
|-----------|-------------|
| `Server name` | Il nome visualizzato nel browser dei server del gioco. |
| `Gamemode` | `vanilla`, `Softcore`, `Hardcore` o `Primitive`. |
| `Map type` | `Procedural Map`, `Barren`, `Hapis Island` o `Savas Island`. |
| `Map seed` | Il seed utilizzato per generare una mappa procedurale. |
| `Map size` | La dimensione della mappa generata. |
| `Player limit` | Il numero massimo di giocatori simultanei. |
| `Save interval` | L'intervallo tra due salvataggi del mondo di gioco. |
| `Tick rate` | La frequenza di aggiornamento del server. |

Altre opzioni, come la descrizione del server, la modalità PvE o i danni da caduta, sono disponibili nel file di configurazione `server.cfg`, nella stessa sezione.

Per una configurazione avanzata, utilizzate il [File Manager](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/) per modificare direttamente i file di configurazione di Rust.
