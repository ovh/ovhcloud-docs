## Obiettivo

- Comprendere l'interfaccia di gestione dei VPS.
- Identificare le informazioni essenziali.
- Sapere dove effettuare le principali azioni.

## Prerequisiti

- Disporre di un'offerta [VPS](/links/bare-metal/vps) attiva nel tuo account OVHcloud.

:::

### Dashboard <a name="controlpanel"></a>

La scheda <code className="action">Panoramica</code> costituisce la **dashboard principale** del tuo VPS.

Riunisce le **informazioni chiave sul servizio** e fornisce l'accesso alle **azioni essenziali di gestione**.

<img className="thumbnail" alt="Scheda Panoramica di un VPS nella console OVHcloud" src="/images/bare-metal-cloud/virtual-private-servers/understand-vps-control-panel/console/vpshome.png" loading="lazy" />

#### Informazioni generali <a name="myvps"></a>

La sezione **Informazioni generali** presenta le informazioni di base sul tuo VPS. Lo stato del servizio è visualizzato accanto al nome del tuo VPS, nella parte superiore della pagina. Clicca sulle schede sottostanti per visualizzare i dettagli.

<Tabs>
  <Tab label="Nome">
    Per personalizzare il nome del tuo VPS, clicca sull'icona a forma di matita accanto al suo nome nella parte superiore della pagina, inserisci il nuovo nome e clicca sull'icona a forma di spunta per salvarlo. Questa funzionalità è utile per facilitare la navigazione nella console OVHcloud quando si gestiscono diversi servizi VPS. Tuttavia, il nome interno del servizio rimane nel formato *vps-XXXXXXX.vps.ovh.net*.
  </Tab>
  <Tab label="Avvio">
    La modalità di avvio indicata è:
    
    - in **modalità normale** (*LOCAL*), dove il server carica il sistema operativo installato.
    - in **modalità Rescue**, fornita da OVHcloud in caso di risoluzione di problemi.
    
    Clicca sul pulsante <code className="action">⋮</code> nella riga **Azioni aggiuntive** della sezione, quindi seleziona <code className="action">Riavvia il tuo VPS</code> per [riavviare il VPS](#rebootvps) o <code className="action">Riavvia in modalità Rescue</code> per avviarlo in modalità Rescue se necessario.
    
    Se necessario, troverai ulteriori informazioni nel nostro manuale sulla [modalità rescue](/guides/bare-metal-cloud/virtual-private-servers/rescue).
  </Tab>
  <Tab label="Distribuzione">
    Si tratta del sistema operativo attualmente installato. Clicca sul link <code className="action">Reinstalla il tuo VPS</code> situato sotto per [reinstallare lo stesso sistema operativo o selezionarne un altro tra le opzioni disponibili](#reinstallvps).
    
    :::warning
    Una reinstallazione comporterà l'eliminazione di tutti i dati attualmente ospitati sul VPS (ad eccezione dei dischi aggiuntivi).

    :::

    
    :::info
    Se hai acquistato un VPS **Windows**, puoi scegliere solo un sistema operativo Windows per la reinstallazione. Allo stesso modo, se Windows non è stato selezionato al momento dell'acquisto, non potrà essere installato dopo la consegna del VPS.

    :::

    
    Una volta installato il sistema, sei responsabile dell'applicazione degli aggiornamenti di sicurezza del sistema operativo. Troverai ulteriori informazioni nella sezione "[Riinstalla il tuo VPS](#reinstallvps)" nonché nel nostro manuale "[Sicurezza di un VPS](/guides/bare-metal-cloud/virtual-private-servers/secure-your-vps)".
  </Tab>
  <Tab label="Region">
    Il campo **Region** fornisce informazioni sulla localizzazione del tuo VPS. Questo può essere utile per identificare e valutare gli eventuali impatti sul tuo servizio, come quelli menzionati nei [rapporti di incidenti o manutenzione](https://bare-metal-servers.status-ovhcloud.com/).
  </Tab>
</Tabs>


#### La tua configurazione <a name="myconf"></a>

Clicca sugli etichette sottostanti per visualizzare i dettagli di questa sezione.

<Tabs>
  <Tab label="Modello">
    Questo elemento indica la referenza commerciale che identifica il modello di VPS, corrispondente alle [offerte VPS sul nostro sito](/links/bare-metal/vps).
  </Tab>
  <Tab label="Processore / Memoria / Disco principale">
    Le risorse attuali del tuo VPS sono visualizzate qui. Per aumentarle, clicca sul link <code className="action">Cambia gamma</code> sotto **Modello**. Si noti che gli aggiornamenti sono limitati dal modello di VPS scelto e possono essere disponibili solo passando a una [gamma superiore](/links/bare-metal/vps).
  </Tab>
  <Tab label="Archiviazione aggiuntiva">
    Questo elemento indica se sul tuo VPS sono attivati dischi aggiuntivi. I dischi aggiuntivi aumentano la capacità di archiviazione del tuo server al di là di quella inclusa nella configurazione iniziale. Puoi ad esempio utilizzarli per archiviare dati di backup. Gestiscili dalla scheda <code className="action">Disco aggiuntivo</code>.
  </Tab>
</Tabs>


#### Dettagli di connessione <a name="ip"></a>

Clicca sugli etichette sottostanti per visualizzare i dettagli di questa sezione.

<Tabs>
  <Tab label="IPv4">
    L'indirizzo IPv4 pubblico principale del VPS è configurato automaticamente all'installazione. Troverai ulteriori informazioni sulla gestione delle IP nel nostro manuale "[Configurare un indirizzo IP in alias](/guides/bare-metal-cloud/virtual-private-servers/configuring-ip-aliasing)".
  </Tab>
  <Tab label="IPv6/Gateway">
    Troverai qui l'indirizzo IPv6 pubblico e l'indirizzo del gateway associato (**Gateway IPv6**). Questi vengono automaticamente collegati al VPS all'installazione. Troverai ulteriori informazioni nel nostro manuale "[Configurare l'IPv6 su un server VPS](/guides/bare-metal-cloud/virtual-private-servers/configure-ipv6)".
  </Tab>
  <Tab label="DNS secondario">
    Questo elemento indica se sono configurati domini sul DNS secondario OVHcloud del tuo VPS, una funzionalità utile per ospitare servizi DNS. L'aggiunta o la rimozione di un dominio dal DNS secondario non è disponibile nella console OVHcloud. Consulta il nostro manuale "[Configurare un DNS secondario OVHcloud su un VPS](/guides/bare-metal-cloud/virtual-private-servers/adding-secondary-dns-on-vps)" per ulteriori informazioni al riguardo.
  </Tab>
</Tabs>


#### Backup <a name="save"></a>

Queste Opzioni fanno riferimento a servizi VPS supplementari per i backup e il ripristino del tuo sistema.

<Tabs>
  <Tab label="Snapshot">
    Uno snapshot su un VPS è un backup istantaneo dello stato del server, che permette di ripristinare rapidamente il sistema in caso di problema. L'opzione `Snapshot` permette di creare uno snapshot manuale come punto di ripristino unico. Se l'opzione non è attiva sul tuo VPS, ordinala tramite il link <code className="action">Ordina uno snapshot</code>.
  </Tab>
  <Tab label="Backup automatico">
    Un backup giornaliero del sistema (esclusi i dischi aggiuntivi) viene effettuato automaticamente e conservato per 24 ore (applicabile solo ai servizi acquistati a partire dal 7 agosto 2025). Passando l'opzione **Backup automatico** a **Premium**, disporrai delle 7 ultime copie di backup giornaliere del tuo VPS, che potrai utilizzare per montaggi e ripristini.  
    Rispetto agli snapshot manuali, questa funzionalità aumenta la sicurezza dei dati creando diversi punti di ripristino a intervalli regolari.
  </Tab>
</Tabs>


Troverai tutte le informazioni sulle soluzioni di backup disponibili per il tuo servizio sulla [pagina prodotto VPS](/links/bare-metal/vps-options) e nei nostri manuali "[Usare snapshot su un VPS](/guides/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps)" e "[Come utilizzare i backup automatizzati su un VPS](/guides/bare-metal-cloud/virtual-private-servers/using-automated-backups-on-a-vps)".

#### Riavvia il tuo VPS <a name="rebootvps"></a>

Un riavvio può risultare necessario per applicare aggiornamenti di configurazione o per risolvere un malfunzionamento. Ove possibile, effettua un "riavvio software" dall'interfaccia grafica del server (Windows, Plesk, ecc.) o tramite il comando di seguito:

```bash
sudo reboot
```

Tuttavia, puoi effettuare un riavvio forzato in qualsiasi momento dalla <ManagerLink to="/">console OVHcloud</ManagerLink>. Nella scheda <code className="action">Panoramica</code>, clicca sul pulsante <code className="action">⋮</code> nella riga **Azioni aggiuntive** della sezione **Informazioni generali**. Seleziona <code className="action">Riavvia il tuo VPS</code> e clicca su <code className="action">Confermare</code> nella finestra che appare.

<img className="thumbnail" alt="Menu Azioni aggiuntive di un VPS nella console OVHcloud, con Riavvia il tuo VPS" src="/images/assets/screens/console/product-selection/bare-metal-cloud/vps/cp-reboot.png" loading="lazy" />

#### Riinstalla il tuo VPS <a name="reinstallvps"></a>

La reinstallazione del tuo VPS può essere effettuata dalla console OVHcloud. Questa operazione è generalmente utilizzata in caso di problema al sistema, di cambio ambiente o per ripartire da un'installazione pulita.

Nella sezione **Informazioni generali** della scheda <code className="action">Panoramica</code>, clicca sul link <code className="action">Reinstalla il tuo VPS</code> sotto **Distribuzione**.

<img className="thumbnail" alt="Link Reinstalla il tuo VPS sotto Distribuzione nella console OVHcloud" src="/images/assets/screens/console/product-selection/bare-metal-cloud/vps/cp-reinst.png" loading="lazy" />

Nel pannello **Reinstalla il tuo VPS** che si apre, scegli un sistema operativo dall'elenco a discesa **Sistema operativo**. Le opzioni proposte sono [immagini compatibili con un VPS OVHcloud](/guides/public-cloud/compute/image-life-cycle) e sono immediatamente operative dopo l'installazione.

Se hai selezionato un sistema operativo compatibile, puoi fornire una **chiave pubblica** da installare automaticamente. Due possibilità si presentano a te:

- Copia manualmente la stringa della chiave e incollala nel campo `La tua chiave SSH Pubblica`.
- Se hai precedentemente [archiviato una chiave pubblica](/guides/bare-metal-cloud/dedicated-servers/import-keys-control-panel) nella <ManagerLink to="/">console OVHcloud</ManagerLink>, seleziona la chiave desiderata nel menu a discesa `Chiave SSH da preinstallare`.

<img className="thumbnail" alt="Pannello Reinstalla il tuo VPS nella console OVHcloud" src="/images/bare-metal-cloud/virtual-private-servers/understand-vps-control-panel/console/reinstall.png" loading="lazy" />

Per saperne di più su questo argomento, consulta i nostri manuali:

- [Come creare e utilizzare chiavi di autenticazione per le connessioni SSH ai server OVHcloud](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutorial - Come utilizzare PuTTY per le connessioni SSH e l'autenticazione](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

Se hai selezionato una chiave archiviata nel menu a discesa `Chiave SSH da preinstallare` e non hai bisogno di password per accedere, seleziona la casella `Non voglio ricevere via email i codici di autenticazione del mio VPS.`.

:::warning
La reinstallazione formatta tutti i dischi del server. È fortemente consigliato creare uno snapshot del tuo VPS prima di procedere, in modo da poter tornare allo stato precedente in caso di problema.

:::


:::info
**Licenze**

Alcuni sistemi operativi o piattaforme proprietarie, come Plesk o cPanel, richiedono licenze che generano costi aggiuntivi. Le licenze sono gestibili dalla console OVHcloud: clicca su <code className="action">Bare Metal Cloud</code> nella barra di navigazione superiore, quindi su <code className="action">Licenze</code> nel menu a sinistra.

Per disporre di un sistema operativo **Windows** funzionante su un VPS, è necessario averlo precedentemente scelto **nel processo d'acquisto**. Un VPS con un altro OS installato non può essere reinstallato con Windows tramite il metodo descritto sopra.

:::


Il processo di reinstallazione può richiedere alcuni minuti.
