## Obiettivo

Il Game Panel vi permette di personalizzare il vostro server Rust installando una mappa personalizzata. Il file della mappa è ospitato esternamente e referenziato dalla configurazione del vostro server.

**Questa guida vi spiega come installare una mappa personalizzata su un server Rust ospitato sul Game Panel.**

## Prerequisiti

- Un [VPS](https://www.ovhcloud.com/it/vps/) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un server Rust distribuito sul Game Panel.
- Un file di mappa personalizzata in formato `.map`.

## Procedura

### Step 1 — Preparare la vostra mappa personalizzata

1. Arrestate il vostro server Rust dal Game Panel.
2. Assicuratevi che la vostra mappa personalizzata sia in formato `.map`.
3. Caricate la mappa su un servizio di condivisione file.
4. Copiate il link di download ottenuto e conservatelo: vi servirà in seguito.

:::warning
Dropbox non è adatto a questo scopo. Utilizzate un altro servizio di condivisione file.
:::


### Step 2 — Aprire il File Manager

Sul vostro server Rust, cliccate su <code className="action">Settings</code>, poi aprite la scheda <code className="action">File Manager</code>.

:::warning
Assicuratevi che il vostro server Rust sia **arrestato** prima di effettuare una delle seguenti azioni.
:::


### Step 3 — Modificare la configurazione del server

1. Nel File Manager, accedete a:

    ```
    /serverfiles/server/rustserver/cfg
    ```

2. Individuate il file `server.cfg` e apritelo per modificarlo.
3. Trovate la riga che inizia con `levelURL=` e incollate il link di download salvato in precedenza dopo il segno `=`.
4. Assicuratevi che il link termini con `dl=1` (e non `dl=0`). Modificatelo se necessario.
5. Trovate la riga che inizia con `serverLevel=` e inserite lo stesso tipo di livello utilizzato per generare la mappa personalizzata:

    - `Procedural Map`
    - `Barren`
    - `Craggy Island`
    - `Savas Island`

6. Salvate le vostre modifiche.

### Step 4 — Riavviare il server

Una volta salvate le vostre modifiche, riavviate il vostro server Rust dal Game Panel.
