## Obiettivo

Il Game Panel OVHcloud fornisce un'interfaccia dedicata per gestire i vostri server di gioco. Per utilizzarlo, dovete connettervi con le vostre credenziali.

**Questa guida vi spiega come connettervi al Game Panel OVHcloud e come recuperare una password persa.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Il link di accesso al Game Panel fornito durante l'installazione.

## Procedura

### Step 1 — Accedere al Game Panel

Andate sul vostro Game Panel. Il link di accesso dipende dal dominio selezionato durante l'installazione.

<img className="thumbnail" alt="Pagina di connessione del Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login.png" loading="lazy" />

### Step 2 — Connettersi

Inserite il vostro nome utente e la password associata, quindi cliccate su <code className="action">Sign In</code> per connettervi al Game Panel.

<img className="thumbnail" alt="Inserimento delle credenziali nella pagina di connessione" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login-form.png" loading="lazy" />

### Recuperare una password persa

#### Account non amministratori

In caso di password persa, chiedete a un amministratore di reimpostarla. Consultate la guida [Gestire gli utenti sul Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-manage-users/) per maggiori dettagli.

#### Account super amministratore

Se la password del super amministratore è stata persa, reimpostatela: connettetevi in SSH alla macchina host, accedete alla cartella di deploy dell'installazione, quindi eseguite il comando seguente. Se non avete familiarità con le connessioni SSH, consultate la guida [Come eseguire le prime operazioni sulle connessioni SSH](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction/).

```bash
sudo bash tools/reset-admin-password.sh
```

Output previsto:

```console
New admin password: XXXXXXXXXX
Confirm new admin password: XXXXXXXXXX
[INFO] Updating the root user password in the database...
[INFO] Rotating JWT secret...
[INFO] Recreating the backend to invalidate existing sessions...
[INFO] Admin password reset complete for user: admin
```

Riconnettetevi all'applicazione con la nuova password amministratore.

:::warning
Questa operazione disconnette tutti gli utenti attualmente connessi.
:::
