## Obiettivo

Il Game Panel vi permette di installare un server Arma Reforger in pochi passaggi. Il Game Panel gestisce automaticamente l'installazione, compresa la configurazione delle porte.

**Questa guida vi spiega come installare un server Arma Reforger sul Game Panel e come connettervi.**

## Prerequisiti

- Un [VPS](https://www.ovhcloud.com/it/vps/) sul vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel.

### Step 2 — Creare una nuova istanza di server

Cliccate su <code className="action">Add Game Server</code> e selezionate **Arma Reforger**.

<img className="thumbnail" alt="Selezione di Arma Reforger nella lista dei giochi" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/select-arma-reforger.png" loading="lazy" />

:::info
Se si tratta del vostro primo server Arma Reforger sul Game Panel e il Game Port predefinito è disponibile, tutte le porte richieste verranno configurate automaticamente durante l'installazione. In questo caso non è necessaria alcuna configurazione manuale.
:::


### Step 3 — Seguire l'avanzamento dell'installazione

Una volta avviata l'installazione, appare una schermata di conferma. Cliccate su <code className="action">Log/Console</code> per seguire l'avanzamento dell'installazione in tempo reale.

<img className="thumbnail" alt="Schermata di avvio dell'installazione di Arma Reforger con il pulsante Open Logs" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-started.png" loading="lazy" />

Durante l'installazione del server, lo stato mostra **Installing**. Seguite l'avanzamento dettagliato direttamente nel pannello dei log.

<img className="thumbnail" alt="Server Arma Reforger con lo stato Running e i log di installazione" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-logs.png" loading="lazy" />

### Step 4 — Confermare il completamento dell'installazione

Una volta terminata l'installazione, lo stato del server passa a **Running**.

### Step 5 — Recuperare le informazioni di connessione

Una volta che il vostro server è nello stato **Running**, copiate le informazioni di connessione dal Game Panel.

<img className="thumbnail" alt="Dettagli di connessione del server Arma Reforger" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-connection-details.png" loading="lazy" />

### Step 6 — Raggiungere il vostro server in Arma Reforger

1. Aprite **Arma Reforger** e accedete al menu principale.
2. Cliccate su <code className="action">Multiplayer</code>.
3. Selezionate <code className="action">Direct Join</code> oppure premete `v`.
4. Inserite l'indirizzo IP e la porta, poi cliccate su <code className="action">Join</code>.
