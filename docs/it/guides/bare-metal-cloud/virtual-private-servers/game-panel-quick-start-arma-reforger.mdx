## Obiettivo

Il Game Panel vi permette di installare un server Arma Reforger in pochi passaggi. Il panel gestisce automaticamente l'installazione, compresa la configurazione delle porte.

**Questa guida vi spiega come installare un server Arma Reforger sul Game Panel e come connettervi.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel. Dal menu a sinistra, accedete alla sezione `Game Servers` e cliccate su <code className="action">Add Game Server</code>.

### Step 2 — Creare un server Arma Reforger

Selezionate **Arma Reforger** dalla lista dei giochi. Si apre una finestra di configurazione.

<img className="thumbnail" alt="Selezione di Arma Reforger nella lista dei giochi" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/select-arma-reforger.png" loading="lazy" />

### Step 3 — Configurare il server Arma Reforger

Impostate il nome del server e verificate la configurazione prima di avviare l'installazione.

:::info
Se si tratta del vostro primo server Arma Reforger sul Game Panel e il Game Port predefinito è disponibile, tutte le porte richieste vengono configurate automaticamente durante l'installazione. In questo caso non è necessaria alcuna configurazione manuale.
:::

Potete espandere <code className="action">Advanced settings</code> per regolare opzioni come l'assegnazione delle porte (ports binding) e i limiti delle risorse. I valori predefiniti sono adatti alla maggior parte dei server di gioco.

### Step 4 — Avviare l'installazione

Cliccate su <code className="action">Install</code> per avviare la distribuzione.

### Step 5 — Monitorare l'installazione

Cliccate su <code className="action">Log/Console</code> per seguire l'avanzamento dell'installazione in tempo reale. Durante l'installazione del server, lo stato mostra **Installing**.

<img className="thumbnail" alt="Monitoraggio dell'installazione del server Arma Reforger nel pannello dei log" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-installation-logs.png" loading="lazy" />

### Step 6 — Verificare che il server sia in esecuzione

Verificate che lo stato del server sia **Running**. I comandi <code className="action">Log/Console</code> e <code className="action">Settings</code> restano disponibili per gestire il server.

### Step 7 — Confermare il completamento dell'installazione

Una volta terminata l'installazione, lo stato del server passa a **Running**.

### Step 8 — Recuperare le informazioni di connessione

Copiate l'indirizzo IP e la porta dalla colonna **Connection** della lista dei Game Servers.

<img className="thumbnail" alt="Dettagli di connessione del server Arma Reforger" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-arma-reforger/arma-connection-details.png" loading="lazy" />

### Step 9 — Unirsi al vostro server su Arma Reforger

1. Aprite **Arma Reforger** e accedete al menu principale.
2. Cliccate su **Multiplayer**, poi aprite la scheda **Community**.
3. Cercate il nome del vostro server.
4. Una volta trovato, cliccateci sopra, poi cliccate su **Join**.
