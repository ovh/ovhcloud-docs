## Obiettivo

Fabric e NeoForge sono dei mod loader per server Minecraft. Installarne uno su un server Minecraft ospitato sul Game Panel vi permette di godere di un'esperienza moddata con funzionalità estese.

**Questa guida vi spiega come installare Fabric o NeoForge su un server Minecraft sul Game Panel e aggiungervi dei mod.**

## Prerequisiti

- Un [VPS](https://www.ovhcloud.com/it/vps/) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un server Minecraft distribuito sul Game Panel. Consultate la guida [Distribuire un server Minecraft sul Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

## Procedura

### Step 1 — Disattivare gli aggiornamenti automatici

Per evitare conflitti con i mod loader, disattivate gli aggiornamenti automatici prima di qualsiasi modifica:

1. Andate nelle <code className="action">Settings</code> del vostro server.
2. Aprite la scheda <code className="action">Game Config</code>.
3. Disattivate gli aggiornamenti automatici.

### Step 2 — Arrestare il server

Dal Game Panel, arrestate il vostro server Minecraft prima di qualsiasi ulteriore modifica.

### Step 3 — Scaricare e importare l'installer

Scaricate l'installer corrispondente al mod loader scelto:

- **Fabric**: [https://fabricmc.net/use/server/](https://fabricmc.net/use/server/)
- **NeoForge**: [https://neoforged.net/](https://neoforged.net/)

Una volta scaricato, aprite le <code className="action">Settings</code> del vostro server, andate nella scheda <code className="action">File Manager</code> e importate il file `.jar` nella directory `serverfiles` tramite <code className="action">Upload files</code> oppure trascinandolo.

### Step 4 — Eseguire l'installer

Aprite la scheda <code className="action">Terminal</code> dalle <code className="action">Settings</code> del vostro server ed eseguite il comando appropriato per il vostro mod loader.

Per **Fabric**:

```bash
java -jar fabric-installer-X.X.X.jar server --downloadMinecraft
```

Questo comando scarica i file del server Minecraft, installa il loader Fabric e genera il file di avvio del server Fabric.

Per **NeoForge**:

```bash
java -jar neoforge-X.X.X-installer.jar --installServer
```

Questo comando installa NeoForge, scarica i file del server Minecraft e genera i file di avvio del server.

### Step 5 — Configurare LinuxGSM

Indicate a LinuxGSM quale eseguibile utilizzare, in base al vostro mod loader.

Per **Fabric**:

```bash
printf '\nexecutable="./fabric-server-launch.jar"\n' >> /data/config-lgsm/mcserver/common.cfg
```

Per **NeoForge**:

```bash
printf '\npreexecutable=""\nexecutable="./run.sh"\nstartparameters="nogui"\n' >> /data/config-lgsm/mcserver/common.cfg
```

:::warning
Quando utilizzate NeoForge con `run.sh`, il parametro **Max RAM** del Game Config non viene più applicato. Modificate invece il file `/data/serverfiles/user_jvm_args.txt`. Esempio:

```
-Xms2G
-Xmx4G
```
:::


### Step 6 — Avviare il server

Impostate i permessi corretti prima di avviare il server:

```bash
sudo chown -R linuxgsm:linuxgsm /data/serverfiles
```

Avviate poi il server dal Game Panel e consultate i log del server per verificare il corretto avvio.

### Step 7 — Aggiungere dei mod

Per installare dei mod sul vostro server moddato:

1. Scaricate dei mod compatibili con Fabric o NeoForge.
2. Aprite la scheda <code className="action">File Manager</code> dalle <code className="action">Settings</code> del vostro server.
3. Importate i file `.jar` dei mod in `serverfiles/mods`.
4. Reimpostate i permessi:

    ```bash
    sudo chown -R linuxgsm:linuxgsm /data/serverfiles
    ```

5. Riavviate il server. Consultate i log per verificare che i mod siano caricati.
