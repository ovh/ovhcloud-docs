## Obiettivo

Il Game Panel espone la configurazione del server Counter-Strike 2 direttamente nella sua interfaccia. Le opzioni di base, come il nome del server, la mappa e la modalità di gioco, sono accessibili tramite un modulo grafico ed è inoltre possibile installare framework per il server come MetaMod e CounterStrikeSharp.

**Questa guida vi spiega come modificare la configurazione di un server Counter-Strike 2 sul Game Panel.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un server Counter-Strike 2 distribuito sul Game Panel. Consultate la guida [Distribuire un server Counter-Strike 2 sul Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/).

## Procedura

### Step 1 — Aprire i parametri del server

Dalla pagina principale del Game Panel, individuate il server Counter-Strike 2 da configurare. Nella colonna <code className="action">Management</code>, cliccate su <code className="action">Settings</code>.

<img className="thumbnail" alt="Server Counter-Strike 2 con il pulsante Settings evidenziato" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-server-settings.png" loading="lazy" />

### Step 2 — Aprire la scheda Game Config

Nel pannello **Server Settings**, selezionate <code className="action">Game Config</code> nella barra laterale sinistra.

La sezione **Game Config** vi permette di gestire i principali parametri del vostro server Counter-Strike 2 tramite due schede:

- **Settings**: configurate i parametri del server di gioco.
- **Frameworks**: installate e gestite i framework per il server supportati.

### Step 3 — Configurare la scheda Settings

La scheda <code className="action">Settings</code> vi permette di modificare i principali parametri del server Counter-Strike 2:

| Parametro | Descrizione |
|---------|-------------|
| Server Name | Il nome visualizzato nel browser dei server di Counter-Strike 2. |
| Max Players | Il numero massimo di giocatori che possono connettersi simultaneamente. |
| Map | La mappa da caricare all'avvio del server. Potete anche inserire manualmente il nome di una mappa non presente nell'elenco. |
| Game Type | Definisce la categoria principale di gioco. |
| Game Mode | Definisce la modalità di gioco all'interno del tipo di gioco selezionato. Per maggiori informazioni sulle modalità disponibili, consultate la [guida della Valve Developer Community](https://developer.valvesoftware.com/wiki/Counter-Strike:_Global_Offensive/Game_Modes). |
| Server Password | Richiede ai giocatori di inserire una password prima di accedere al server. |
| Admin Password (RCON) | Attiva l'accesso Remote Console (RCON) e definisce la password utilizzata per amministrare il server da remoto. |
| Steam GSL Token | Un Game Server Login Token (GSLT) utilizzato per autenticare il vostro server dedicato presso i servizi Steam. Per generare un token, consultate la [pagina Steam Game Server Account Management](https://steamcommunity.com/dev/managegameservers). |
| VAC Anti-Cheat | Attiva o disattiva la protezione Valve Anti-Cheat (VAC) sul server. |

<img className="thumbnail" alt="La scheda Settings del Game Config di Counter-Strike 2" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-settings.png" loading="lazy" />

:::info
Dopo aver modificato uno qualsiasi di questi parametri, salvate le modifiche e riavviate il server affinché vengano applicate.
:::


### Step 4 — Installare i framework

La scheda <code className="action">Frameworks</code> vi permette di installare componenti aggiuntivi per estendere le funzionalità del vostro server Counter-Strike 2.

- **MetaMod**: un framework di plugin per server che funge da livello intermedio tra il server di gioco e i plugin. Fornisce le basi necessarie per molte estensioni avanzate del server e strumenti di amministrazione.
- **CounterStrikeSharp**: un moderno framework di plugin per Counter-Strike 2 che permette agli amministratori dei server e agli sviluppatori di creare ed eseguire plugin personalizzati utilizzando C#. Può aggiungere funzionalità di gioco, strumenti di gestione del server ed estensioni sviluppate dalla community.

Potete installare uno qualsiasi dei due framework direttamente dal Game Panel e reinstallarli in seguito per aggiornarli a una versione più recente, quando disponibile.

<img className="thumbnail" alt="La scheda Frameworks che mostra MetaMod e CounterStrikeSharp" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-frameworks.png" loading="lazy" />

:::info
Il server deve essere arrestato prima di installare un framework.
:::


### Step 5 — Salvare e riavviare

Dopo aver salvato le vostre modifiche, riavviate il server Counter-Strike 2 dal Game Panel affinché la nuova configurazione venga applicata.
