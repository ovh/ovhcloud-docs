## Obiettivo

Il Game Panel OVHcloud vi permette di caricare un mondo Minecraft personalizzato trasferendo i file con il File Manager e modificando la configurazione della cartella del mondo.

**Questa guida vi spiega come caricare una mappa personalizzata sul vostro server Minecraft ospitato sul Game Panel OVHcloud.**

## Prerequisiti

- Un [VPS](https://www.ovhcloud.com/it/vps/) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un server Minecraft implementato sul Game Panel. Consultate la guida [Implementare un server Minecraft sul Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

:::warning
Assicuratevi che il vostro server Minecraft sia **arrestato** prima di eseguire una delle seguenti azioni.
:::


## Procedura

### Step 1 — Aprire il File Manager

Sul vostro server Minecraft, cliccate su <code className="action">Settings</code>, quindi aprite la scheda <code className="action">File Manager</code>.

### Step 2 — Individuare la cartella del mondo

Nel File Manager, navigate fino a:

```
data > serverfiles
```

In questa directory, vedrete una cartella denominata `world`. Questa cartella contiene la vostra mappa Minecraft attuale ed è creata per impostazione predefinita.

<img className="thumbnail" alt="La cartella world predefinita nella struttura dei file del server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder.png" loading="lazy" />

### Step 3 — Preparare il server per la vostra nuova mappa

Prima di caricare la vostra mappa, dovete liberare il nome della cartella `world`. Avete tre opzioni:

- **Eliminarla** con l'azione <code className="action">Delete</code> se non vi serve più.
- **Rinominarla** con l'azione <code className="action">Rename</code> per conservarla come backup.
- **Scaricarla in locale** con l'azione <code className="action">Download</code>.

### Step 4 — Caricare la vostra mappa personalizzata

Nel File Manager, all'interno di `data > serverfiles`, cliccate su <code className="action">Upload files</code> oppure trascinate la cartella della vostra mappa nella lista dei file.

### Step 5 — Configurare il nome del mondo (se necessario)

Se la cartella della vostra mappa non si chiama `world`, dovete aggiornare la configurazione del server:

1. Tornate sul Game Panel.
2. Aprite le <code className="action">Settings</code> del vostro server.
3. Andate nella scheda <code className="action">Game Config</code>.
4. Individuate l'opzione **World folder name**.
5. Inserite il nome esatto della cartella della vostra mappa.

<img className="thumbnail" alt="Configurazione del nome della cartella del mondo in Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder-name-config.png" loading="lazy" />

:::info
**Utilizzare più mappe**: potete memorizzare più mappe sul vostro server e passare facilmente dall'una all'altra. Modificate il campo **World folder name** nella sezione Game Config per caricare una mappa diversa. Non dimenticate di riavviare il server dopo aver modificato questo parametro.
:::


### Step 6 — Avviare il server

Riavviate il vostro server dal Game Panel. La vostra mappa Minecraft personalizzata è ora pronta per l'uso.
