## Obiettivo

Il Game Panel OVHcloud vi consente di caricare un mondo Minecraft personalizzato trasferendo i file con il File Manager e modificando la configurazione del nome del mondo.

**Questa guida spiega come caricare una mappa personalizzata sul vostro server Minecraft ospitato sul Game Panel OVHcloud.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un server Minecraft che utilizza uno dei seguenti software: Minecraft Java Edition, Minecraft Bedrock Edition, PaperMC, Fabric o NeoForge. Consultate la guida [Distribuire un server Minecraft sul Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).
- Una cartella di mappa pronta per essere caricata.

## Procedura

### Step 1 — Arrestare il server Minecraft

Prima di caricare un nuovo mondo, dovete arrestare il vostro server.

1. Aprite il vostro server nel Game Panel.
2. Cliccate su <code className="action">Stop</code> per arrestare completamente il server.

:::warning
Non caricate né sostituite mai un mondo mentre il server è in esecuzione, poiché ciò può causare una corruzione del mondo.
:::

### Step 2 — Caricare la vostra mappa personalizzata

1. Aprite il vostro server nel Game Panel.
2. Andate in <code className="action">Settings</code>.
3. Aprite la scheda <code className="action">File Manager</code>.

<img className="thumbnail" alt="La cartella del mondo nel File Manager" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder.png" loading="lazy" />

**Eliminare il mondo esistente**

Per impostazione predefinita, la cartella del mondo principale è denominata `world`. Potete eliminare la cartella `world` esistente oppure scaricarla in anticipo se desiderate conservarne un backup.

**Caricare il vostro nuovo mondo**

Una volta eliminato il vecchio mondo:

1. Individuate la cartella della vostra mappa personalizzata sul vostro computer.
2. Trascinate e rilasciate la cartella direttamente nel File Manager.
3. Attendete la fine del caricamento.

La vostra mappa personalizzata deve essere caricata sotto forma di una cartella contenente i file del mondo.

:::warning
Si consiglia vivamente che la versione di Minecraft del mondo che caricate corrisponda alla versione di Minecraft del vostro server. Una differenza di versione può impedire il caricamento del mondo o causare comportamenti imprevisti.
:::

### Step 3 — Verificare il nome del mondo

Il nome della cartella del mondo deve corrispondere al nome del mondo configurato nei parametri del vostro server.

**Verificare il nome della cartella caricata**

Nel File Manager, annotate il nome esatto della cartella del mondo che avete caricato.

**Aggiornare la configurazione del server**

1. Andate nella scheda <code className="action">Game Config</code>.
2. Individuate l'opzione **World name**.
3. Assicuratevi che il suo valore corrisponda esattamente al nome della cartella caricata.

<img className="thumbnail" alt="Corrispondenza del parametro World name in Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder-name-config.png" loading="lazy" />

### Step finale

Una volta completato il caricamento e quando il parametro **World name** corrisponde al nome della vostra cartella:

1. Salvate le vostre modifiche.
2. Avviate nuovamente il server.

Il vostro server Minecraft dovrebbe ora caricare e utilizzare la vostra mappa personalizzata.
