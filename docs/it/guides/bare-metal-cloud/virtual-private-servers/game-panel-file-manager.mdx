## Obiettivo

Il File Manager vi consente di sfogliare, modificare, caricare, scaricare e organizzare i file del vostro server direttamente dal Game Panel OVHcloud.

**Questa guida spiega come utilizzare il File Manager del Game Panel.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un server di gioco distribuito sul Game Panel.
- Avere accesso al Game Panel. Consultate la guida [Connettersi al Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Accedere al File Manager

1. Aprite le <code className="action">Settings</code> del vostro server.
2. Accedete alla scheda <code className="action">File Manager</code>.

Una volta aperta la scheda, visualizzate l'elenco dei file e delle cartelle disponibili sul vostro server.

<img className="thumbnail" alt="Il File Manager del Game Panel che mostra l'elenco di file e cartelle" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/file-manager-list.png" loading="lazy" />

### Selezionare un volume di storage

Se sul vostro server sono configurati più volumi di storage, potete selezionare il volume desiderato tramite il menu a tendina situato nell'angolo in alto a sinistra del File Manager.

### Barra degli strumenti del File Manager

In alto nel File Manager trovate:

- Il percorso attuale.
- Un pulsante <code className="action">Refresh</code> per ricaricare la directory attuale.
- Un pulsante <code className="action">Create Folder</code>.
- Un pulsante <code className="action">Create File</code>.
- Un pulsante <code className="action">Upload</code> per i file e le cartelle.
- Un pulsante <code className="action">Copy Path</code> per copiare il percorso della directory attuale negli appunti.

<img className="thumbnail" alt="La barra degli strumenti del File Manager con il percorso e i pulsanti Aggiorna, Crea cartella, Crea file, Carica e Copia percorso" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/file-manager-toolbar.png" loading="lazy" />

### Sfogliare i file e le cartelle

**Aprire una cartella**

Fate doppio clic su una cartella per accedervi.

**Modificare un file**

Fate doppio clic su un file per aprirlo nell'editor di testo integrato.

:::info
I file di dimensioni superiori a 2 MB non possono essere modificati online. In questo caso, dovete scaricare il file, modificarlo localmente sul vostro computer, quindi caricare nuovamente la versione modificata sul server.
:::

### Azioni sui file e sulle cartelle

Quando passate il cursore sopra un file o una cartella, diventano disponibili azioni aggiuntive:

- **Download**
- **Rename**
- **Delete**

<img className="thumbnail" alt="Le azioni su file e cartelle al passaggio del mouse: Scarica, Rinomina ed Elimina" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/file-manager-actions.png" loading="lazy" />

:::warning
Rinominare o eliminare file mentre il server è in esecuzione può causare comportamenti imprevisti. Quando possibile, arrestate il server prima di effettuare queste operazioni.
:::

Durante il download di una cartella, questa viene automaticamente compressa in un archivio `.zip` per velocizzare il processo di download.

### Supporto del trascinamento

Il File Manager supporta le operazioni di trascinamento.

**Spostare file e cartelle**

Potete trascinare file o cartelle per:

- Spostarli in un'altra cartella.
- Spostarli nella directory superiore rilasciandoli sulla voce `..`, che rappresenta la cartella superiore.

**Caricare dal vostro computer**

Potete inoltre trascinare file e cartelle direttamente dal vostro computer nel File Manager. Vengono caricati automaticamente nella directory attualmente aperta. Per i caricamenti di grandi dimensioni, viene visualizzata una barra di avanzamento per ogni file, che vi consente di seguire lo stato del caricamento.

### Permessi

L'accesso al File Manager può essere limitato per alcuni utenti. Per configurare i permessi del File Manager, consultate la guida [Gestire gli utenti sul Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-manage-users/).
