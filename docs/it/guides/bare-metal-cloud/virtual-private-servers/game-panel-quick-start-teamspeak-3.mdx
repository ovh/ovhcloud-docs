## Obiettivo

Il Game Panel vi permette di distribuire e configurare un server vocale TeamSpeak 3 in pochi minuti, senza riga di comando né conoscenze di sistema.

**Questa guida vi spiega come distribuire un server TeamSpeak 3 sul Game Panel e come connettervi a esso.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Un client TeamSpeak 3 installato sulla vostra macchina per testare la connessione.

## Procedura

### Step 1 — Accedere al Game Panel e selezionare TeamSpeak 3

Dalla dashboard del vostro Game Panel, cliccate su <code className="action">Add Game Server</code>. Nell'elenco dei giochi disponibili, cercate e selezionate **TeamSpeak 3**.

<img className="thumbnail" alt="Selezione di TeamSpeak 3 nell'elenco dei giochi" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/select-teamspeak-3.png" loading="lazy" />

### Step 2 — Configurare il vostro server

Si apre una pagina di configurazione. I valori predefiniti sono pronti all'uso per un avvio immediato, ma potete personalizzarli in base alle vostre esigenze.

Tra i parametri disponibili, potete modificare:

- <code className="action">Server Name</code>: assegnate un nome di istanza al vostro server (ad esempio, `My TS3 server`).
- <code className="action">Network Ports</code>: preconfigurate automaticamente:
    - `9987` (UDP) — voce
    - `10011` (TCP) — ServerQuery
    - `30033` (TCP) — trasferimento di file

<img className="thumbnail" alt="Configurazione delle Network Ports per TeamSpeak 3" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-network-ports.png" loading="lazy" />

:::info
Potete modificare questi parametri, ma non è obbligatorio per avviare il server.
:::


### Step 3 — Avviare l'installazione

Una volta verificata la configurazione, cliccate su <code className="action">Select</code> per avviare la distribuzione.

<img className="thumbnail" alt="Modulo di configurazione dell'installazione di TeamSpeak 3 con il pulsante Select" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-install-form.png" loading="lazy" />

### Step 4 — Seguire l'avanzamento dell'installazione

La distribuzione si avvia automaticamente. Lasciate proseguire l'installazione senza chiudere la pagina.

Seguite il processo in tempo reale cliccando su <code className="action">Log/Console</code> per visualizzare i messaggi di installazione.

<img className="thumbnail" alt="Pannello dei log di installazione di TeamSpeak 3" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-installation-logs.png" loading="lazy" />

### Step 5 — Verificare che il server sia in esecuzione

Una volta completata l'installazione, verificate che il vostro server mostri lo stato **Running**.

<img className="thumbnail" alt="Server TeamSpeak 3 con lo stato Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-teamspeak-3/teamspeak-running.png" loading="lazy" />

Il vostro server è online. Recuperate l'indirizzo IP e la porta nella sezione <code className="action">Connection</code> per connettervi dal client TeamSpeak 3.

### Step 6 — Connettersi al vostro server

Nel client TeamSpeak 3:

1. Cliccate su <code className="action">Connections</code> > <code className="action">Connect</code>.
2. Inserite l'indirizzo visualizzato nella colonna **Connection** della lista dei Game Servers.
