## Obiettivo

Creare uno snapshot è un modo semplice e rapido per mettere al sicuro un sistema che funziona prima di effettuare modifiche che potrebbero avere conseguenze indesiderate o impreviste, ad esempio per testare una nuova configurazione o un nuovo software. Ciò non costituisce comunque una strategia completa di backup del sistema.

**Scopri come attivare e utilizzare l’opzione snapshot dalla console OVHcloud.**

:::info
Prima di applicare opzioni di backup, consigliamo di fare riferimento alle pagine prodotto [e alle domande frequenti](/links/bare-metal/vps-options) per confrontare i prezzi e per visualizzare ulteriori dettagli.

:::


## Prerequisiti

- un servizio [VPS OVHcloud](/links/bare-metal/vps) già impostato

:::warning
Questa funzionalità non è attualmente disponibile per i server privati virtuali nelle [Local Zones](/links/bare-metal/vps-lz).

:::

## Procedura

### Step 1: Attivare l’opzione snapshot

Nella scheda <code className="action">Panoramica</code>, scorri verso il basso fino alla sezione **Backup**.  
Se la riga **Snapshot** indica "Attivato", passa direttamente allo Step 2. Se indica "Disattivato", clicca sul link <code className="action">Ordina uno snapshot</code> sotto la riga **Snapshot**.

<img className="thumbnail" alt="Sezione Backup di un VPS nella console OVHcloud, con il link Ordina uno snapshot" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_step1b.png" loading="lazy" />

Nel pannello che si apre, esamina le informazioni sul prezzo, quindi clicca su <code className="action">Ordinare</code>. Sarai guidato attraverso la procedura per l’ordine e riceverai una e-mail di conferma.

Per disattivare l’opzione, clicca sul link <code className="action">Disattiva</code> sotto la riga **Snapshot**, quindi clicca su <code className="action">Confermare</code> nella finestra **Rimuovi l'opzione Snapshot**.

:::warning
La disattivazione diventa effettiva alla data di rinnovo dell’opzione e non può essere annullata.
:::

<img className="thumbnail" alt="Riga Snapshot di un VPS nella console OVHcloud, con il link Disattiva" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_cancel.png" loading="lazy" />

### Step 2: Acquisire uno snapshot

Una volta attivata l’opzione, clicca sul link <code className="action">Effettua uno Snapshot</code> sotto la riga **Snapshot**. Nella finestra **Effettua uno Snapshot**, puoi inserire una descrizione che verrà allegata allo snapshot, quindi clicca su <code className="action">Confermare</code>.

:::warning
Il tuo VPS non è accessibile durante la creazione dello snapshot e qualsiasi snapshot precedente andrà perso.
:::

La durata della creazione dello snapshot dipende dallo spazio di storage utilizzato. In seguito, aggiorna la pagina per visualizzare la data di creazione nella riga **Snapshot** della sezione **Backup**.

### Step 3: Cancellare/ripristinare uno snapshot

Dal momento che puoi attivare un solo snapshot alla volta, quello esistente deve essere eliminato prima di crearne uno nuovo. Per farlo è sufficiente cliccare sul link <code className="action">Elimina lo Snapshot</code> sotto la riga **Snapshot**, quindi su <code className="action">Elimina lo Snapshot</code> nella finestra che si apre per confermare.

<img className="thumbnail" alt="Riga Snapshot di un VPS nella console OVHcloud, con i relativi link dello snapshot" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_step2.png" loading="lazy" />

Se sei certo di voler ripristinare il tuo VPS allo stato dello snapshot, clicca su <code className="action">Ripristina lo Snapshot</code> e conferma il ripristino nella finestra che si apre.

:::warning
Il ripristino dello snapshot cancella la versione attuale del tuo VPS e lo riporta allo stato dello snapshot. Questa azione è irreversibile.
:::

:::danger
Ricorda che quando ripristini un VPS da un'istantanea, quest'ultima verrà eliminata. Per conservare la stessa istantanea, è necessario crearne una nuova prima di apportare modifiche al sistema ripristinato.

Se la funzione Snapshot è troppo limitata per il tuo progetto, l'opzione [Backup automatizzati](/guides/bare-metal-cloud/virtual-private-servers/using-automated-backups-on-a-vps) è un'alternativa.

:::


### Scarica uno Snapshot

Lo Snapshot in corso può essere recuperato tramite un link di download. Clicca sul link <code className="action">Scaricare lo Snapshot</code> sotto la riga **Snapshot**.

<img className="thumbnail" alt="Sezione Backup di un VPS nella console OVHcloud, con il link Scaricare lo Snapshot" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps03.png" loading="lazy" />

:::info
Se il tuo VPS proviene da una gamma precedente, potresti ricevere un messaggio di errore perché l'opzione non è disponibile sui VPS precedenti. I VPS OVHcloud utilizzano una gamma precedente se il modello di attribuzione del nome è simile a: *vpsXXXX.ovh.net* (dove *X* rappresenta un numero). Puoi verificare questo riferimento del server nell’intestazione della pagina del tuo VPS nella <ManagerLink to="/">console OVHcloud</ManagerLink>.

:::


Nel pannello **Scaricare Snapshot**, clicca su <code className="action">Generare il link di download</code>.

<img className="thumbnail" alt="Pannello Scaricare Snapshot nella console OVHcloud, con il pulsante Generare il link di download" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps04.png" loading="lazy" />

Dopo pochi secondi visualizzi un messaggio di successo. Di seguito, è possibile copiare il comando completo di download in un click, quindi eseguirlo nel tuo terminale.

<img className="thumbnail" alt="Pannello Scaricare Snapshot nella console OVHcloud con il comando di download generato" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps05.png" loading="lazy" />

La dimensione dello snapshot è visualizzata anche nella sezione **Informazioni**.

Ti ricordiamo che il link di download scadrà dopo **24 ore**.

L'ordine di download utilizza un `curl` nel seguente formato:

```bash
curl "https://storage.sbg.cloud.ovh.net/v1/AUTH_f5fgh4674dd706f15f6ffgf4z667d3f4g5f05/glance/5ceg3f93-8b49-436b-aefe-4185f9fc3f78?
temp_url_sig=f508cacda60256d5f211ddddf3f81130e935f0e4&temp_url_expires=1678247579" --output vps-x11x11xyy.vps.ovh.net --fail
```

Il comando deve essere azionato da qualsiasi terminale di linea di comando. Tuttavia, quando utilizzi Windows *PowerShell*, dovrai adattare il comando in questo modo:

```powershell
curl -Uri "https://storage.sbg.cloud.ovh.net/v1/AUTH_f5fgh4674dd706f15f6ffgf4z667d3f4g5f05/glance/5ceg3f93-8b49-436b-aefe-4185f9fc3f78?
temp_url_sig=f508cacda60256d5f211ddddf3f81130e935f0e4&temp_url_expires=1678247579" -OutFile vps-x11x11xyy.vps.ovh.net
```

<img className="thumbnail" alt="snapshotvps" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/snapshot_vps06.png" loading="lazy" />

:::info
Per evitare di consumare troppo spazio di storage, ti consigliamo di non scaricare gli Snapshot direttamente sul VPS.

Il file scaricato può essere importato in un Progetto Public Cloud come immagine (QCOW2) tramite [OpenStack](/guides/public-cloud/compute/overview). (Un esempio di utilizzo è disponibile in [questa guida](/guides/public-cloud/compute/upload-own-image).)

:::


### Best practice per la creazione di uno Snapshot

#### Configurazione del software QEMU su un VPS

Gli Snapshot sono istantanee del proprio sistema in esecuzione (“live snapshot”). Per garantire la disponibilità del sistema durante la creazione dello Snapshot è necessario utilizzare il software QEMU, che prepara il filesystem al processo.

Nella maggior parte delle distribuzioni, il *qemu-guest-agent* necessario non è installato di default e le eventuali restrizioni delle licenze possono impedire a OVHcloud di includerlo nelle immagini degli OS disponibili. Consigliamo pertanto di verificare la presenza del software sul VPS e, in caso contrario, di installarlo. Per eseguire queste operazioni, accedi in SSH al VPS e segui le istruzioni indicate, in base al sistema operativo utilizzato.

##### **Distribuzioni Debian (Debian, Ubuntu)**

Utilizza il comando seguente per verificare che il sistema sia correttamente configurato per effettuare Snapshot:

```bash
file /dev/virtio-ports/org.qemu.guest_agent.0
/dev/virtio-ports/org.qemu.guest_agent.0: symbolic link to ../vport2p1
```

Se il risultato è differente (“No such file or directory”), installa l’ultima versione del pacchetto:

```bash
sudo apt-get update
sudo apt-get install qemu-guest-agent
```

Avvia il servizio per assicurarti che sia in esecuzione:

```bash
sudo service qemu-guest-agent start
```

##### **Distribuzioni Red Hat (CentOS, Fedora)**

Utilizza il comando seguente per verificare che il sistema sia correttamente configurato per effettuare Snapshot:

```bash
file /dev/virtio-ports/org.qemu.guest_agent.0
/dev/virtio-ports/org.qemu.guest_agent.0: symbolic link to ../vport2p1
```

Se il risultato è differente (“No such file or directory”), installa e attiva il software:

```bash
sudo yum install qemu-guest-agent
sudo chkconfig qemu-guest-agent on
```

Avvia il servizio per assicurarti che sia in esecuzione:

```bash
sudo service qemu-guest-agent start
sudo service qemu-guest-agent status
```

##### **Windows**

È possibile installare il software utilizzando un file MSI disponibile sul sito del progetto Fedora: [https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/latest-qemu-ga/](https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/latest-qemu-ga/)

Per verificare che il servizio sia in esecuzione, esegui questo comando *PowerShell*:

```powershell
PS C:\Users\Administrator> Get-Service QEMU-GA

Status   Name               DisplayName
------   ----               -----------
Running  QEMU-GA            QEMU Guest Agent
```
