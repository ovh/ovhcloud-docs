## Obiettivo

Il Game Panel OVHcloud vi consente di creare e ripristinare i backup del vostro server di gioco. Le funzionalità di backup disponibili dipendono dal fornitore utilizzato dall'immagine del vostro server di gioco.

**Questa guida spiega come creare e ripristinare i backup dal Game Panel OVHcloud.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un server di gioco distribuito sul Game Panel.
- Avere accesso al Game Panel. Consultate la guida [Connettersi al Game Panel OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Accedere alla scheda Backups

1. Aprite il vostro server di gioco nel Game Panel.
2. Andate in <code className="action">Settings</code>.
3. Aprite la scheda <code className="action">Backups</code>.

Il contenuto di questa scheda varia in base al fornitore dell'immagine del vostro server di gioco. Il fornitore è visualizzato in alto nella finestra delle impostazioni:

- **Logo OVHcloud**: l'immagine del server di gioco è fornita da OVHcloud.
- **Logo LinuxGSM**: l'immagine del server di gioco è fornita da LinuxGSM.
- **External**: il server è stato aggiunto utilizzando un'immagine esterna. La gestione dei backup non è supportata per questo fornitore.

<img className="thumbnail" alt="Il logo del provider visualizzato in alto nella finestra delle impostazioni del server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-backups/backups-provider.png" loading="lazy" />

### Fornitore OVHcloud

#### Creare un backup

Dalla scheda <code className="action">Backups</code>, cliccate su <code className="action">Create Backup</code>. Dopo qualche istante, il backup compare nell'elenco sottostante.

<img className="thumbnail" alt="La sezione Backup con un backup nell'elenco e le azioni Scarica, Ripristina ed Elimina" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-backups/backups-create.png" loading="lazy" />

#### Gestire i backup

Per ciascun backup dell'elenco, potete:

- **Scaricare** l'archivio del backup.
- **Eliminare** il backup.
- **Ripristinare** il backup.
- **Rinominare** il backup.

### Fornitore LinuxGSM

LinuxGSM integra il proprio sistema di gestione dei backup. Di conseguenza, la funzionalità di backup funziona allo stesso modo per tutte le immagini di server di gioco fornite da LinuxGSM.

#### Creare un backup

Dalla scheda <code className="action">Backups</code>, cliccate su <code className="action">Create Backup</code>. Una volta completato il processo di backup, questo compare nell'elenco dei backup.

#### Gestire i backup

Per ciascun backup dell'elenco, potete:

- **Scaricare** l'archivio del backup.
- **Eliminare** il backup.
- **Rinominare** il backup.

Il ripristino automatico non è disponibile e deve essere effettuato manualmente. Consultate la sezione [Ripristinare un backup](#ripristinare-un-backup) qui di seguito.

#### Opzioni di backup

LinuxGSM offre diverse opzioni di configurazione dei backup:

- **Keep the last X backups**: definisce il numero di backup da conservare. Quando il limite viene raggiunto, il backup più vecchio viene automaticamente eliminato al momento della creazione di un nuovo backup.
- **Keep backups for X days**: definisce la durata di conservazione dei backup. I backup più vecchi del numero di giorni configurato vengono automaticamente eliminati.
- **Stop server before backup**: arresta il server di gioco prima di creare un backup. Questo consente di garantire l'integrità e la coerenza del backup, ma comporta un'interruzione temporanea del servizio durante la creazione del backup.

### Ripristinare un backup

#### Fornitore OVHcloud

Per ripristinare un backup:

1. Aprite la scheda <code className="action">Backups</code>.
2. Individuate il backup che desiderate ripristinare.
3. Cliccate su <code className="action">Restore</code>.

Il server si riavvia automaticamente durante il processo di ripristino.

:::warning
Se la versione locale del gioco è diversa dalla versione contenuta nel backup, dopo il ripristino possono verificarsi comportamenti imprevisti o problemi di gioco.
:::

#### Fornitore LinuxGSM

LinuxGSM non supporta il ripristino automatico dei backup tramite il Game Panel. Per ripristinare un backup manualmente:

1. Scaricate l'archivio del backup.
2. Estraete l'archivio sul vostro computer.
3. Aprite i file estratti.
4. Individuate la directory `serverfiles` (presente nella maggior parte dei backup LinuxGSM).

**Preparare il server**

1. Arrestate il server di gioco.
2. Andate in <code className="action">Settings</code> > <code className="action">File Manager</code>.
3. Individuate la directory `serverfiles` esistente.

Prima di sostituirla, potete eliminarla, rinominarla o scaricarla se desiderate conservarne una copia.

**Caricare i file del backup**

1. Eliminate o rinominate la directory `serverfiles` attuale.
2. Trascinate e rilasciate la directory `serverfiles` del backup nel File Manager.
3. Attendete che il caricamento sia completamente terminato.

**Avviare il server**

1. Avviate nuovamente il server di gioco.
2. Consultate i log del server per verificare che si avvii correttamente e che il ripristino sia riuscito.

:::info
Il monitoraggio dei log del server dopo un ripristino è vivamente consigliato, poiché consente di identificare rapidamente eventuali problemi legati a file mancanti, a modifiche della configurazione o a differenze di versione del gioco.
:::
