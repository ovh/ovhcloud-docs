## Obiettivo

Il Game Panel di OVHcloud vi permette di distribuire un server Valheim con un'installazione e una configurazione delle porte automatizzate.

**Questa guida vi spiega come distribuire un server Valheim sul Game Panel di OVHcloud e come connettervi a esso.**

## Prerequisiti

- Un [VPS](https://www.ovhcloud.com/it/vps/) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- L'accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel di OVHcloud.

### Step 2 — Creare una nuova istanza di server

Cliccate su <code className="action">Add Game Server</code> e selezionate **Valheim**.

<img className="thumbnail" alt="Selezione di Valheim nell'elenco dei giochi" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/select-valheim.png" loading="lazy" />

:::info
Se si tratta del vostro primo server Valheim sul Game Panel e la Game Port predefinita è disponibile, tutte le porte richieste vengono configurate automaticamente. Non è necessaria alcuna configurazione manuale.
:::


### Step 3 — Seguire l'avanzamento dell'installazione

Una volta avviata l'installazione, viene visualizzata una schermata di conferma. Cliccate su <code className="action">Log/Console</code> per seguire l'avanzamento dell'installazione in tempo reale.

<img className="thumbnail" alt="Monitoraggio dell'installazione del server Valheim" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/installation-logs.png" loading="lazy" />

### Step 4 — Confermare il completamento dell'installazione

Una volta completata l'installazione, appare una notifica: **Server status is now: Running**.

<img className="thumbnail" alt="Server Valheim con lo stato Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-valheim/server-running.png" loading="lazy" />

### Step 5 — Recuperare le informazioni di connessione

Quando lo stato del vostro server è **Running**, copiate le informazioni di connessione dal Game Panel. Valheim utilizza due porte UDP: `2456` (Game) e `2457` (Query).

:::info
Una password viene generata automaticamente durante l'installazione. Aprite il <code className="action">File Manager</code> dalle <code className="action">Settings</code> del vostro server e consultate `config-lgsm` > `vhserver` > `secrets-common.cfg` per recuperarla.
:::


### Step 6 — Unirsi al vostro server in Valheim

1. Aprite **Valheim**.
2. Cliccate su <code className="action">Start</code>, poi su <code className="action">Join game</code>.
3. Cliccate su <code className="action">Add server</code>.
4. Inserite l'indirizzo IP del vostro VPS e la porta (ad esempio, `serv8.gamepanel.ovh:2456`).
5. Inserite la password e cliccate su <code className="action">Connect</code>.
