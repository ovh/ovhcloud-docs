## Obiettivo

Il Game Panel OVHcloud vi permette di eseguire il backup delle vostre istanze di server di gioco per ripristinarle a uno stato precedente in caso di necessità.

**Questa guida vi spiega come creare un backup del vostro server di gioco sul Game Panel OVHcloud.**

## Prerequisiti

- Un [VPS](https://www.ovhcloud.com/it/vps/) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un'istanza di server di gioco implementata sul Game Panel. Consultate la guida [Primi passi con il Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

## Procedura

### Step 1 — Connettersi al Game Panel

Connettetevi al vostro Game Panel. Se avete bisogno di aiuto, consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Step 2 — Accedere ai parametri di backup

Una volta effettuata la connessione:

1. Selezionate il vostro server di gioco.
2. Cliccate su <code className="action">Settings</code>.
3. Andate nella scheda <code className="action">Backups</code>.

<img className="thumbnail" alt="La scheda dei parametri di backup" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/backup-tab.png" loading="lazy" />

### Step 3 — Creare un backup

Cliccate su <code className="action">Create backup now</code>.

<img className="thumbnail" alt="Creazione di un backup con l'opzione di arresto del server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/create-backup.png" loading="lazy" />

Una volta completato il backup, il file è disponibile per il download nella lista **Available Backups**, più in basso nella stessa scheda.

### Step 4 — Definire una politica di retention

In **Retention Policy**, potete controllare il numero di backup conservati e la loro durata di conservazione:

- **Keep the last backups**: il numero massimo di backup da conservare (indicate `0` per conservarli tutti).
- **Keep backups for days**: la durata di conservazione dei backup (indicate `0` per conservarli indefinitamente).
- **Stop server before backup**: arresta il server durante l'esecuzione del backup, per backup coerenti.

:::info
Vi consigliamo di mantenere attivata l'opzione **Stop server before backup** per garantire la coerenza dei backup.
:::

Cliccate su <code className="action">Save retention settings</code> per applicare le vostre modifiche.
