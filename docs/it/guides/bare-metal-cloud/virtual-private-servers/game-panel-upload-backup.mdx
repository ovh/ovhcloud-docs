## Obiettivo

Il Game Panel OVHcloud vi permette di ripristinare un backup scaricando un archivio, estraendolo e caricando i file con il File Manager.

**Questa guida vi spiega come ripristinare un backup sul vostro server Game Panel OVHcloud.**

## Prerequisiti

- Un [VPS](https://www.ovhcloud.com/it/vps/) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un'istanza di server di gioco implementata sul Game Panel.
- Un backup esistente. Consultate la guida [Creare un backup sul Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/).

## Procedura

### Step 1 — Connettersi al Game Panel

Connettetevi al vostro Game Panel. Se avete bisogno di aiuto, consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Step 2 — Accedere ai parametri di backup

Una volta effettuata la connessione:

1. Selezionate il vostro server di gioco.
2. Cliccate su <code className="action">Settings</code>.
3. Andate nella scheda <code className="action">Backups</code>.

### Step 3 — Scaricare un backup

In fondo alla pagina, individuate la lista dei backup disponibili. Cliccate su <code className="action">Download</code> accanto al backup che desiderate ripristinare.

Se non è disponibile alcun backup, dovete prima crearne uno. Consultate la guida [Creare un backup sul Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/).

<img className="thumbnail" alt="Download di un backup dalla lista" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-backup/download-backup.png" loading="lazy" />

### Step 4 — Estrarre il backup

Una volta scaricato il backup, estraete l'archivio sul vostro computer. Il contenuto estratto include la directory `serverfiles`.

### Step 5 — Arrestare il server

Prima di continuare, verificate che il vostro server di gioco sia arrestato dal Game Panel per evitare qualsiasi corruzione o conflitto durante il ripristino.

### Step 6 — Aprire il File Manager

Sul vostro server, cliccate su <code className="action">Settings</code>, quindi aprite la scheda <code className="action">File Manager</code> e individuate la cartella `serverfiles`.

<img className="thumbnail" alt="Directory serverfiles sul server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-backup/serverfiles.png" loading="lazy" />

Prima di caricare il backup, dovete scegliere una delle seguenti opzioni:

- **Eliminarla** con l'azione <code className="action">Delete</code> se non vi serve più.
- **Rinominarla** con l'azione <code className="action">Rename</code> per conservarla come backup.
- **Scaricarla in locale** con l'azione <code className="action">Download</code>.

### Step 7 — Caricare i file di backup

Nel File Manager, cliccate su <code className="action">Upload files</code> oppure trascinate la cartella `serverfiles` locale ottenuta dal backup estratto nella lista dei file.

Per la maggior parte dei giochi, ripristinare la cartella `serverfiles` è sufficiente. Tuttavia, alcuni giochi possono memorizzare i file di configurazione in altre posizioni. Se la configurazione del gioco è stata modificata, si consiglia di ripristinare anche la cartella `config-lgsm` quando disponibile.

### Step 8 — Avviare il server

Una volta completato il caricamento, riavviate il vostro server dal Game Panel. Il vostro server dovrebbe ora funzionare con l'ambiente del backup ripristinato.
