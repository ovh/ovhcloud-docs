## Objective

The Game Panel lets you deploy a Team Fortress 2 server in a few steps. The panel handles the installation automatically, including port configuration.

**This guide explains how to deploy and connect to a Team Fortress 2 server on the Game Panel.**

## Requirements

- A [VPS](https://www.ovhcloud.com/en-gb/vps/) in your OVHcloud account with the Game Panel feature enabled.
- Access to the Game Panel. Refer to [Log in to the Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Instructions

### Step 1 — Access the Game Panel

Log in to your Game Panel.

### Step 2 — Create a new server instance

Click <code className="action">Add Game Server</code> and select **Team Fortress 2**.

<img className="thumbnail" alt="Selecting Team Fortress 2 from the game list" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/select-tf2.png" loading="lazy" />

:::info
If this is your first Team Fortress 2 server on the Game Panel and the default Game Port is available, all required ports are configured automatically. No manual setup is needed.
:::


### Step 3 — Monitor installation progress

Once installation starts, a confirmation screen appears. Click <code className="action">Open Logs</code> to follow the installation progress in real time.

<img className="thumbnail" alt="Team Fortress 2 installation started screen" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-installation-started.png" loading="lazy" />

While the server is installing, the status displays **Installing**. Track detailed progress directly in the logs panel.

<img className="thumbnail" alt="Team Fortress 2 installation logs panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-installation-logs.png" loading="lazy" />

### Step 4 — Confirm installation is complete

Once installation is finished, the server status changes to **Running**.

<img className="thumbnail" alt="Team Fortress 2 server with Running status" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-running.png" loading="lazy" />

### Step 5 — Retrieve connection information

Once your server status is **Running**, copy the connection information from the Game Panel.

### Step 6 — Join your server in Team Fortress 2

1. Open **Team Fortress 2**.
2. Go to <code className="action">Community server</code> > <code className="action">Favorites</code>.
3. Click <code className="action">Add a Server</code> and paste `servX.gamepanel.ovh:PORT`.
