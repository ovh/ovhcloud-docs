## Obiettivo

Il Game Panel vi permette di distribuire un server Team Fortress 2 in pochi passaggi. Il Game Panel gestisce automaticamente l'installazione, compresa la configurazione delle porte.

**Questa guida vi spiega come distribuire un server Team Fortress 2 sul Game Panel e come connettervi a esso.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel.

### Step 2 — Creare una nuova istanza di server

Cliccate su <code className="action">Add Game Server</code> e selezionate **Team Fortress 2**.

<img className="thumbnail" alt="Selezione di Team Fortress 2 nell'elenco dei giochi" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/select-tf2.png" loading="lazy" />

:::info
Se si tratta del vostro primo server Team Fortress 2 sul Game Panel e la Game Port predefinita è disponibile, tutte le porte richieste vengono configurate automaticamente. Non è necessaria alcuna configurazione manuale.
:::


### Step 3 — Seguire l'avanzamento dell'installazione

Una volta avviata l'installazione, viene visualizzata una schermata di conferma. Cliccate su <code className="action">Log/Console</code> per seguire l'avanzamento dell'installazione in tempo reale.

Durante l'installazione del server, lo stato mostra **Installing**. Seguite l'avanzamento dettagliato nel pannello dei log.

<img className="thumbnail" alt="Monitoraggio dell'installazione del server Team Fortress 2 nel pannello dei log" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-installation-logs.png" loading="lazy" />

### Step 4 — Confermare il completamento dell'installazione

Una volta completata l'installazione, lo stato del server passa a **Running**.

<img className="thumbnail" alt="Server Team Fortress 2 con lo stato Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-tf2/tf2-running.png" loading="lazy" />

### Step 5 — Recuperare le informazioni di connessione

Quando lo stato del vostro server è **Running**, copiate le informazioni di connessione dal Game Panel.

### Step 6 — Unirsi al vostro server in Team Fortress 2

Aggiungete prima il vostro server ai vostri preferiti Steam:

1. In **Steam**, andate in **View** > **Game Servers**.
2. Aprite la scheda **Favorites** e cliccate su **Add a server**.
3. Incollate l'indirizzo IP e la porta indicati nella colonna **Connection**, quindi cliccate su **OK**.

Avviate quindi **Team Fortress 2** e cliccate su **Connect** sul server aggiunto ai vostri preferiti.
