## Obiettivo

Il Game Panel OVHcloud vi permette di distribuire un server Palworld con un'installazione e una configurazione delle porte automatizzate.

**Questa guida vi spiega come distribuire un server Palworld sul Game Panel OVHcloud e come connettervi.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel OVHcloud. Nel menu a sinistra, accedete alla sezione `Game Servers` e cliccate su <code className="action">Add Game Server</code>.

### Step 2 — Creare un server Palworld

Selezionate **Palworld** dalla lista dei giochi. Si apre una finestra di configurazione.

<img className="thumbnail" alt="Selezione di Palworld dalla lista dei giochi del Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/select-palworld.png" loading="lazy" />

### Step 3 — Configurare il server Palworld

In questa sezione potete definire un nome per il vostro server. Viene inoltre generata automaticamente una password di amministratore. Può essere utilizzata direttamente nel gioco per ottenere i diritti di amministratore ed eseguire i comandi associati.

:::warning
Assicuratevi di conservare questa password di amministratore in un luogo sicuro.
:::

Potete espandere <code className="action">Advanced settings</code> per regolare opzioni come la mappatura delle porte (ports binding) e i limiti delle risorse. I valori predefiniti sono adatti alla maggior parte dei server di gioco.

<img className="thumbnail" alt="Modulo di configurazione del server Palworld con il nome del server e la password di amministratore" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/configure-server.png" loading="lazy" />

### Step 4 — Avviare l'installazione

Cliccate su <code className="action">Install</code> per avviare l'installazione. La distribuzione ha inizio.

### Step 5 — Monitorare l'installazione

Cliccate su <code className="action">Log/Console</code> per seguire l'avanzamento dell'installazione in tempo reale.

Durante l'installazione del server, lo stato visualizza **Installing**. Seguite l'avanzamento dettagliato nel pannello dei log.

<img className="thumbnail" alt="Monitoraggio dell'installazione del server Palworld nel pannello dei log" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/installation-logs.png" loading="lazy" />

### Step 6 — Verificare che il server sia in esecuzione

Verificate che lo stato del server sia **Running** e che sia visibile un'attività CPU e RAM. Potete utilizzare i controlli <code className="action">Log/Console</code> e <code className="action">Settings</code> per gestire il server.

<img className="thumbnail" alt="Server Palworld con lo stato Running e attività CPU e RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-palworld/server-running.png" loading="lazy" />

### Step 7 — Confermare il completamento dell'installazione

Una volta completata l'installazione, lo stato del server passa a **Running**.

### Step 8 — Recuperare le informazioni di connessione

Quando lo stato del vostro server è **Running**, copiate l'indirizzo IP e la porta dalla colonna **Connection** della lista Game Servers.

### Step 9 — Unirsi al vostro server su Palworld

Per unirvi al vostro server dal client Palworld:

1. Aprite **Palworld** e cliccate su **Join Multiplayer Game**.
2. Nel campo di inserimento situato in basso al centro, incollate l'indirizzo IP e la porta indicati nella colonna **Connection**.
3. Cliccate su **Connect**.

### Comandi disponibili con Palworld

Con un server Palworld, potete eseguire diversi comandi direttamente dal campo di inserimento situato in fondo ai log. Ecco alcuni dei comandi disponibili:

| Comando | Argomenti | Descrizione |
|---------|-----------|-------------|
| `announce` | `<message>` | Invia un messaggio di annuncio visibile a tutti i giocatori connessi. |
| `players` | - | Mostra la lista dei giocatori attualmente connessi al server. |
| `info` | - | Restituisce le informazioni generali del server. |
| `settings` | - | Restituisce la configurazione attuale del server. |
| `metrics` | - | Mostra diverse metriche e statistiche del server. |
| `kick` | `<PlayerId or SteamId>` | Espelle un giocatore dal server. |
| `ban` | `<PlayerId or SteamId>` | Banna un giocatore dal server. |
| `unban` | `<PlayerId or SteamId>` | Rimuove il ban di un giocatore. |

:::info
Avete dimenticato la password di amministratore del gioco? Cliccate su <code className="action">Settings</code>, aprite la sezione <code className="action">Game Config</code> e modificate la password in fondo alla pagina.
:::

### Aggiornare il server a una nuova versione del gioco

Per impostazione predefinita, il server non si aggiorna automaticamente quando è disponibile una nuova versione, per evitare eventuali problemi di compatibilità o l'interruzione delle partite in corso.

Per attivare gli aggiornamenti automatici, cliccate su <code className="action">Settings</code>, aprite la sezione <code className="action">Game Config</code>, poi attivate l'opzione **Update on start** in fondo alla pagina (disattivata per impostazione predefinita). Salvate, poi riavviate il server per applicare le modifiche. Il server applicherà quindi automaticamente ogni nuovo aggiornamento disponibile.
