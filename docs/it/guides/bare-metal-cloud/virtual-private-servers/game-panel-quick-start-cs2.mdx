## Obiettivo

Il Game Panel OVHcloud vi permette di distribuire un server Counter-Strike 2 (CS2) con un'installazione e una configurazione delle porte automatizzate.

**Questa guida vi spiega come distribuire un server Counter-Strike 2 sul Game Panel OVHcloud e come connettervi.**

## Prerequisiti

- Un [VPS](/links/bare-metal/vps) o un [server dedicato](/links/bare-metal/bare-metal) nel vostro account OVHcloud con la funzionalità Game Panel attivata.
- Un accesso al Game Panel. Consultate la guida [Connettersi al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedura

### Step 1 — Accedere al Game Panel

Connettetevi al vostro Game Panel OVHcloud. Andate nella sezione **Game Servers** del menu a sinistra.

### Step 2 — Creare un server CS2

Cliccate su <code className="action">Add Game Server</code> e selezionate **Counter-Strike 2** dalla lista.

<img className="thumbnail" alt="Selezione di Counter-Strike 2 nella lista dei giochi" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/select-cs2.png" loading="lazy" />

Inserite un **Server Name** (ad esempio `CS2 Competitive Server`). Le porte di rete richieste vengono configurate automaticamente durante l'installazione.

### Step 3 — Avviare l'installazione

Cliccate su <code className="action">Select</code>. La distribuzione si avvia automaticamente. Attendete qualche minuto durante il download dell'immagine e l'installazione del server.

Cliccate quindi su <code className="action">Launch</code> per avviare il server.

### Step 4 — Verificare che il server funzioni

Verificate che lo stato del server visualizzi **Running** e che sia visibile un'attività CPU/RAM.

Azioni disponibili:

- <code className="action">Log/Console</code>: aprite la console per seguire l'avvio e consultate i log in caso di problema.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: accedete ai parametri del gioco.

<img className="thumbnail" alt="Server Counter-Strike 2 con lo stato Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/cs2-running.png" loading="lazy" />

### Step 5 — Connettersi al server

Nella colonna **Connection** della lista dei Game Servers, copiate l'indirizzo IP e la porta del vostro server.

In Counter-Strike 2:

1. Attivate la console nei parametri del gioco (**Settings** > **Game** > **Enable Developer Console**).
2. Aprite la console (`~`).
3. Inserite il comando seguente utilizzando l'indirizzo IP e la porta della colonna **Connection**:

    ```console
    connect IP:PORT
    ```

### Buone pratiche

- Configurate i permessi tramite <code className="action">User Administration</code>.
- Effettuate backup regolari.
- Personalizzate i parametri del vostro gioco.

:::info
Per saperne di più, aggiungete mod o configurazioni competitive, regolate il tickrate e i parametri di prestazione, oppure limitate l'accesso con una password o una whitelist.
:::
