## Obiettivo

Un **Vault** è uno spazio di archiviazione fornito da OVHcloud verso il quale potete inviare i dati dei vostri backup. Con Backup Licenses, un primo Vault viene fornito automaticamente con la vostra prima licenza.

**Questa guida spiega come funzionano i Vault del prodotto Backup Licenses, come vengono fatturati e come ordinarne di aggiuntivi.**

## Prerequisiti

- Aver ordinato una licenza Backup Licenses. Consultate la nostra guida "[Ordinare e configurare la vostra prima licenza](/guides/storage-and-backup/backup-licenses/first-configuration)" per maggiori informazioni.

## Procedura

### Il Vault "bundle"

Un Vault detto **"bundle"** viene fornito per impostazione predefinita con la vostra prima licenza Backup Licenses.

- Questo Vault è **legato alla sottoscrizione del prodotto**: viene **eliminato se il prodotto Backup Licenses viene disdetto**.
- È **unico**: disponete di un solo Vault "bundle", indipendentemente dal numero di licenze.
- È **gratuito fino a 500 GB**. Questo spazio può essere utilizzato per i vostri server VBR come per altre esigenze di archiviazione.

:::danger
La disdetta del prodotto Backup Licenses comporta l'**eliminazione del Vault "bundle" e dei dati che contiene**. Assicuratevi di aver recuperato i vostri dati prima di qualsiasi disdetta.

:::

### Recuperare le informazioni di connessione del Vault

Il Vault "bundle" viene messo a disposizione sotto forma di **bucket S3<sup>1</sup>**. Per recuperare le informazioni di connessione (endpoint, credenziali di accesso), cliccate su <code className="action">Mostra le credenziali</code> dalla scheda del Vault nel vostro Spazio Cliente OVHcloud.

Queste informazioni vi consentono di configurare il Vault come repository oggetto nel vostro server Veeam Backup & Replication, oppure di accedervi con qualsiasi client compatibile S3.

### Fatturazione del Vault "bundle"

- I **primi 500 GB sono inclusi** nella vostra sottoscrizione Backup Licenses, senza costi aggiuntivi.
- **Oltre i 500 GB**, ogni GB aggiuntivo consumato viene fatturato **mensilmente**, alla **tariffa pubblica di OVHcloud Object Storage**.

:::info
Le tariffe aggiornate sono disponibili nella pagina [tariffe Object Storage](/links/public-cloud/prices-object-storage).

:::

### Ordinare Vault aggiuntivi

Potete ordinare **Vault aggiuntivi** dal vostro Spazio Cliente OVHcloud.

Funzionano esattamente allo stesso modo del Vault "bundle" (bucket S3, stessi utilizzi, stesse modalità di accesso), con una sola differenza: vengono **fatturati a partire dal primo GB consumato**, alla tariffa pubblica di OVHcloud Object Storage. Non è associato loro alcun volume gratuito.

La tabella seguente riassume le differenze:

| | Vault "bundle" | Vault aggiuntivo |
|---|---|---|
| **Fornitura** | Fornito automaticamente con la prima licenza | Ordinato su richiesta dallo Spazio Cliente |
| **Numero** | Uno solo per sottoscrizione | Quanti necessari |
| **Volume incluso** | 500 GB gratuiti | Nessuno |
| **Fatturazione** | A partire dal 501° GB, alla tariffa pubblica Object Storage | Dal primo GB, alla tariffa pubblica Object Storage |
| **Ciclo di vita** | Eliminato alla disdetta del prodotto Backup Licenses | Disdicibile in modo indipendente |
