## Obiettivo

**Questa guida descrive nel dettaglio le restrizioni e le limitazioni note del prodotto Backup Licenses che dovete conoscere prima di ordinare la vostra licenza.**

## Limitazioni note

### Versione di Veeam Backup & Replication

- La nostra infrastruttura supporta solo i server Veeam Backup & Replication in **versione 12 minima**. Un VBR in una versione precedente non può essere collegato alla Veeam Service Provider Console (VSPC) di OVHcloud e la licenza non può quindi essergli assegnata.

### Sistema operativo ed edizioni disponibili

- I server VBR su **Linux** (Veeam Software Appliance) supportano solo le licenze **Veeam Data Platform (VDP)**: Foundation, Advanced o Premium.
- L'edizione **Veeam Enterprise Plus** è disponibile unicamente per i server VBR su **Windows**.

La tabella seguente riassume le combinazioni possibili:

| Sistema operativo del VBR | Veeam Enterprise Plus | Veeam Data Platform (Foundation / Advanced / Premium) |
|---|:---:|:---:|
| **Windows** | Sì | Sì |
| **Linux** (Veeam Software Appliance) | No | Sì |

:::info
Consultate la guida "[Ordinare e configurare la vostra prima licenza](/guides/storage-and-backup/backup-licenses/first-configuration)" per i dettagli sulle edizioni e sulle loro funzionalità.

:::

### Server VBR con licenza Veeam Enterprise

- Un server VBR la cui licenza è ancora gestita dalla vecchia offerta **Veeam Enterprise** di OVHcloud non può ricevere una licenza Backup Licenses: la sua licenza è controllata da un server Veeam Backup Enterprise Manager, che impedisce alla VSPC di applicarne una nuova.
- Dovete quindi **disdire il vostro servizio Veeam Enterprise prima di collegare il vostro server VBR alla VSPC**, poi attendere 24 ore. La procedura completa è descritta nella guida "[Migrare da Veeam Enterprise a Backup Licenses](/guides/storage-and-backup/backup-licenses/migration-veeam-enterprise)".
