## Guide Backup Licenses

Il prodotto **Backup Licenses** vi permette di noleggiare licenze Veeam da OVHcloud per il vostro server **Veeam Backup & Replication** (VBR), che sia ospitato presso OVHcloud o nella vostra infrastruttura. Scegliete il vostro livello di licenza, adattatelo verso l'alto o verso il basso senza impegni a lungo termine e lasciate che OVHcloud gestisca la licenza e lo storage mantenendo il pieno controllo del vostro server Veeam. La licenza viene applicata e rinnovata automaticamente non appena il vostro server VBR è collegato alla **Veeam Service Provider Console** (VSPC) di OVHcloud, e ogni licenza include un Vault gestito — 500 GB di Object Storage — destinato ad archiviare i vostri dati di backup. Backup Licenses sostituisce l'offerta Veeam Enterprise.

Che dobbiate ordinare la vostra prima licenza, migrare da Veeam Enterprise, gestire il vostro storage di backup o risolvere un problema di connessione, le guide seguenti coprono l'intero prodotto.
