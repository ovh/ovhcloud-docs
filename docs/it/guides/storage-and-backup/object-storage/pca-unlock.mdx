## Obiettivo

Il Public Cloud Archive è un'offerta di storage a freddo che permette di ospitare grandi volumi di dati, senza limiti di dimensione e con tariffe molto attraenti.

Per i dati raramente consultati, è necessaria una richiesta di sblocco che comporta un periodo di tempo prima del recupero. Questo tempo è variabile in base all'anzianità e alla frequenza di accesso ai tuoi dati.

## Procedura

### Sblocca i tuoi oggetti nella console OVHcloud

Nel menu a sinistra del tuo progetto Public Cloud, clicca su <code className="action">Cloud Archive</code> nella sezione **Storage**. Clicca sul pulsante <code className="action">...</code> nella riga del tuo container e poi su <code className="action">Visualizza l'archivio</code>.

Nella scheda <code className="action">Oggetti</code>, la colonna **Disponibilità** indica lo stato di ciascun oggetto:

- **Bloccato**: l'oggetto è archiviato e deve essere sbloccato prima di poter essere scaricato.
- **Disponibile dal** *data*: l'oggetto è in fase di sblocco e potrà essere scaricato a partire dalla data indicata.
- **Sì**: l'oggetto è disponibile.

Per sbloccare un oggetto, clicca sul pulsante <code className="action">...</code> nella sua riga e poi su <code className="action">Sblocca</code>. La colonna **Disponibilità** indica quindi la data a partire dalla quale l'oggetto potrà essere recuperato.

Quando l'oggetto è disponibile, clicca sul pulsante <code className="action">...</code> nella sua riga e poi su <code className="action">Scaricare</code>. Puoi anche scaricarlo tramite un [client Swift/SFTP/SCP](/guides/storage-and-backup/object-storage/pca-sftp).

#### Automatizza il download dell'oggetto

:::info
Questa funzionalità richiede il package `at`.

:::


```bash
swift download <pca_container> <object>
```
```
Error downloading object '<pca_container>/<object>': Object GET failed: https://storage.gra.cloud.ovh.net/v1/AUTH_702xxxxxxxxxxxxxxxxxxxxxxxxxxdaf/<pca_container>/<object> 429 Too Many Requests
```

```bash
X_OVH_RETRIEVAL_DELAY=$(swift download <pca_container> <object> | awk -F ": " '/X-Ovh-Retrieval-Delay/ {print $2}'
RETRIEVAL_DELAY=$((${X_OVH_RETRIEVAL_DELAY} / 60 + 2))
swift download <pca_container> <object> | at now + ${RETRIEVAL_DELAY} minutes
```
