## Obiettivo

**Scopri come ripristinare i dati di cui hai effettuato il backup con Backup Agent.**

Hai a disposizione due metodi di ripristino, da scegliere in base alle tue esigenze:

- **Ripristino dei file (assistente FLR)**: è il metodo principale e più comune. Permette di ripristinare uno o più file o cartelle da un backup, senza riavviare il server.
- **Ripristino completo del server (Bare Metal Recovery)**: permette di ripristinare l'intero sistema a partire da un'immagine ISO di ripristino. È destinato agli scenari di disaster recovery, quando il server non si avvia più.

:::info
Ulteriori informazioni sul prodotto Backup Agent sono disponibili su [questa pagina](/guides/storage-and-backup/backup-agent/product-presentation).

:::


## Prerequisiti

- Disporre di un server Bare Metal su cui è installato e configurato Backup Agent. Consulta la nostra guida "[Come configurare il tuo primo backup](/guides/storage-and-backup/backup-agent/first-configuration)" per ulteriori informazioni.
- Aver effettuato almeno un backup. Consulta la nostra guida "[Gestire i tuoi backup](/guides/storage-and-backup/backup-agent/backup-restore)" per ulteriori informazioni.

## Procedura

### Ripristino dei file (assistente FLR)

È il metodo principale per recuperare uno o più file o cartelle da un backup.

Per ripristinare file e cartelle, clicca sull'opzione corrispondente al tuo sistema operativo:

<Tabs>
  <Tab label="Windows">
    Apri l'applicazione "Veeam Agent" sul tuo server Bare Metal:
    
    <img className="thumbnail" alt="Ricerca dell'applicazione Veeam Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-bkpagent-search.png" loading="lazy" />

Vai nel menu e seleziona <code className="action">Restore File</code>:
    
    <img className="thumbnail" alt="Menu di ripristino di Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-menu.png" loading="lazy" />

Seleziona il punto di ripristino desiderato nell'assistente:
    
    <img className="thumbnail" alt="Punti di ripristino di Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-restore-points.png" loading="lazy" />

Poi conferma:
    
    <img className="thumbnail" alt="Riepilogo del punto di ripristino di Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-restore-point-summary.png" loading="lazy" />

Infine, cerca il tuo file e seleziona un'opzione:
    
    <img className="thumbnail" alt="Procedura guidata di ripristino di Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-wizard.png" loading="lazy" />
    
    - Restore - Overwrite: ti permette di ripristinare il file sovrascrivendo quello attualmente presente sul server.
    - Restore - Keep: ti permette di ripristinare il file mantenendo quello attualmente presente sul server.
    - Copy To: ti permette di copiare il file in un'ubicazione del tuo server.
    - Explore: ti permette di esplorare il backup.
    - Properties: ti permette di visualizzare le proprietà del file.
    
    Avviare un ripristino ti permetterà di ottenere un'ultima finestra che mostrerà il trasferimento:
    
    <img className="thumbnail" alt="Trasferimento del ripristino di Backup Agent" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-transfer.png" loading="lazy" />
  </Tab>
  <Tab label="Linux">
    Per ripristinare file e cartelle su Linux, hai due opzioni: tramite l'interfaccia grafica o tramite la riga di comando.
    
    #### Tramite l'interfaccia grafica
    
    1\. Connetti al tuo server Bare Metal tramite SSH.
    2\. Avvia l'interfaccia Veeam digitando il comando seguente:
    
    ```bash
    sudo veeam
    ```
    
    3\. Nell'interfaccia, seleziona l'opzione di ripristino file.
    4\. Seleziona il Backup e il punto di ripristino desiderato.
    5\. Naviga nel backup per trovare i file o le cartelle da ripristinare.
    6\. Seleziona i file e scegli l'azione di ripristino:
       - Ripristina alla posizione originale
       - Copia in una nuova posizione
       - Esplora il backup
    
    #### Tramite la riga di comando
    
    Per ripristinare file tramite la riga di comando, devi prima montare il backup:
    
    1\. Elenca i tuoi backup disponibili (usa `--all` per mostrare tutti i backup importati):
    
    ```bash
    sudo veeamconfig backup list --all
    ```
    
    2\. Elenca i punti di ripristino di un Backup:
    
    ```bash
    sudo veeamconfig backup info --id <id_backup>
    ```
    
    3\. Monta un punto di ripristino:
    
    ```bash
    sudo veeamconfig point mount --id <id_punto>
    ```

    Questo mostrerà una conferma del montaggio e indicherà l'ID della sessione.
    
    ```bash
    Il punto di ripristino è montato.
    ID sessione: [{<id_sessione>}].
    Log salvati in: [/var/log/veeam/Mount/Session_########_######_{<id_sessione>}].
    ```
    
    4\. Una volta montato, puoi accedere ai file tramite il punto di montaggio (di norma in `/mnt/backup/`).
    
    5\. Copia i file desiderati dal punto di montaggio alla destinazione.
    
    6\. Una volta completato il ripristino, smonta il backup; usa l'ID della sessione per smontare il backup:
    
    ```bash
    sudo veeamconfig session stop --id <id_sessione>
    ```
    
    Per ulteriori informazioni, consulta la [documentazione Veeam](https://helpcenter.veeam.com/docs/agentforlinux/userguide/files_restore_gui.html?ver=13) e la [documentazione sul ripristino tramite riga di comando](https://helpcenter.veeam.com/docs/agentforlinux/userguide/files_restore_cmd.html?ver=13).
  </Tab>
</Tabs>

### Ripristino completo del server (Bare Metal Recovery)

Bare Metal Recovery è una funzionalità di Veeam che consiste nel creare in anticipo un'immagine ISO personalizzata, che può essere utilizzata per avviare un sistema e ripristinarlo da un backup memorizzato su un altro server. Questo metodo è destinato agli scenari di disaster recovery, quando il tuo server non si avvia più.

Permette di:

- Creare un'**immagine ISO di ripristino**: questo file permette di avviare la tua macchina in caso di malfunzionamento all'avvio del sistema.
- Utilizzare la tua immagine ISO per accedere al tuo ultimo backup e ripristinarlo dall'infrastruttura OVHcloud.

:::warning
Questa procedura è basata sul Veeam Agent per Windows. Se utilizzi il Veeam Agent per Linux, la procedura è simile, sebbene l'interfaccia sia in modalità testo.
:::


Per avviare dall'ISO di ripristino, utilizza l'IPMI del tuo server Bare Metal per caricare l'ISO.

#### Fase 1: Creare la ISO di ripristino

Se il tuo computer non si avvia più, avrai bisogno di un'immagine ISO di ripristino per riavviarlo.

:::warning
Questa immagine deve essere creata prima di qualsiasi incidente. Se il tuo server non è più disponibile, non potrai più crearla.
:::


Ecco come crearla:

1\. Apri lo strumento **Create Recovery Media**, incluso nel Veeam Agent, sulla tua macchina.

<img className="thumbnail" alt="Avviare lo strumento Create Recovery Media" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_01.png" loading="lazy" />

2\. Veeam ti chiederà se desideri includere driver aggiuntivi.

:::info
Se utilizzi hardware specifico (come un controller RAID), seleziona i driver necessari. In caso contrario, le opzioni predefinite sono generalmente sufficienti.
:::


<img className="thumbnail" alt="Selezionare i driver per l'immagine di avvio" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_02.png" loading="lazy" />

3\. Scegli dove salvare la ISO e assegnale un nome.

<img className="thumbnail" alt="Definire l'ubicazione e il nome della ISO" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_03.png" loading="lazy" />

4\. Attendi il completamento dell'operazione. Il file ISO verrà generato.

<img className="thumbnail" alt="ISO di ripristino creata" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_04.png" loading="lazy" />

<img className="thumbnail" alt="ISO di ripristino" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_05.png" loading="lazy" />

Ora puoi utilizzare questa ISO per creare una chiavetta USB avviabile con uno strumento come Rufus.

#### Fase 2: Avviare la macchina dalla ISO di ripristino

Se il tuo sistema non si avvia più e devi ripristinarlo:

1\. Monta la ISO nella console del tuo server, poi avvia la macchina da essa.

:::tip
**Non sai come avviare da una ISO?**

Riavvia la tua macchina fisica e premi il tasto indicato (di norma F2, F12, ESC o DEL) per accedere al menu di avvio.
:::


2\. Una volta avviato il sistema, si aprirà l'assistente di ripristino Veeam. Clicca su <code className="action">Bare Metal Recovery</code>.

<img className="thumbnail" alt="Avviare Bare Metal Recovery" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_01.png" loading="lazy" />

3\. Seleziona <code className="action">Network Storage</code> per accedere ai tuoi backup online.

:::warning
Se la rete non viene rilevata, potresti doverla configurare manualmente. Clicca su <code className="action">Configure network settings</code> e carica i driver mancanti.
:::


<img className="thumbnail" alt="Selezionare Network Storage" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_02.png" loading="lazy" />

4\. Seleziona <code className="action">Veeam Cloud Connect repository</code>.

<img className="thumbnail" alt="Scegliere il repository Veeam Cloud Connect" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_03.png" loading="lazy" />

5\. Inserisci l'indirizzo seguente quando ti viene richiesto di indicare il fornitore di servizi:

<img className="thumbnail" alt="Inserire i DNS" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_04.png" loading="lazy" />

:::warning
Per conoscere il DNS e le credenziali da utilizzare, devi [contattare il nostro supporto](/links/support-contact) per ottenerli.
:::


6\. Inserisci il tuo nome utente e la tua password per accedere.

<img className="thumbnail" alt="Inserire le credenziali" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_05.png" loading="lazy" />

7\. Seleziona il server che desideri ripristinare.

<img className="thumbnail" alt="Selezionare il server" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_06.png" loading="lazy" />

8\. Scegli il punto di ripristino (data/ora) al quale desideri tornare.

Ti consigliamo di utilizzare l'ultimo backup riuscito, a meno che tu non abbia un motivo particolare per tornare a una versione precedente.

<img className="thumbnail" alt="Scegliere un punto di ripristino" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_07.png" loading="lazy" />

9\. Scegli la modalità di ripristino adatta alla tua situazione (scegli **Entire computer** per un ripristino completo).

<img className="thumbnail" alt="Modalità di ripristino" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_08.png" loading="lazy" />

10\. Verifica il riepilogo, poi avvia il ripristino.

<img className="thumbnail" alt="Avviare il ripristino - conferma" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_09.png" loading="lazy" />

<img className="thumbnail" alt="Avviare il ripristino - avanzamento" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_10.png" loading="lazy" />

:::warning
La durata del processo di ripristino dipende dalla dimensione del tuo backup e dalla velocità della tua connessione Internet. Al termine, il tuo sistema si riavvierà con lo stato corrispondente al punto di ripristino selezionato.
:::
