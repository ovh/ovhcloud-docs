## Obiettivo

**Scopri come ripristinare i dati di cui hai effettuato il backup con Backup Agent.**

Hai a disposizione due metodi di ripristino, da scegliere in base alle tue esigenze:

- **Ripristino dei file (assistente FLR)**: è il metodo principale e più comune. Permette di ripristinare uno o più file o cartelle da un backup, senza riavviare il server.
- **Ripristino completo del server (Bare Metal Recovery)**: permette di ripristinare l'intero sistema a partire da un'immagine ISO di ripristino. È destinato agli scenari di disaster recovery, quando il server non si avvia più.

:::info
Ulteriori informazioni sul prodotto Backup Agent sono disponibili su [questa pagina](/guides/storage-and-backup/backup-agent/product-presentation).

:::


## Prerequisiti

- Un server Bare Metal su cui è installato Backup Agent. Consulta la nostra guida "[Come configurare il tuo primo backup](/guides/storage-and-backup/backup-agent/first-configuration)" per ulteriori informazioni.
- Almeno un backup effettuato. Consulta la nostra guida "[Gestire i tuoi backup](/guides/storage-and-backup/backup-agent/backup-restore)" per ulteriori informazioni.

## Procedura

### Ripristino dei file (assistente FLR)

È il metodo principale per recuperare uno o più file o cartelle da un backup.

Per ripristinare file e cartelle, clicca sull'opzione corrispondente al tuo sistema operativo:

<Tabs>
  <Tab label="Windows">
    Apri l'applicazione "Veeam Agent" sul tuo server Baremetal:
    
    <img className="thumbnail" alt="Backup Agent BKP Agent Search" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-bkpagent-search.png" loading="lazy" />

Vai nel menu e seleziona <code className="action">Restore File</code>:
    
    <img className="thumbnail" alt="Backup Agent Restore Menu" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-menu.png" loading="lazy" />

Seleziona il punto di ripristino desiderato nell'assistente:
    
    <img className="thumbnail" alt="Backup Agent Restore Points" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-restore-points.png" loading="lazy" />

Poi conferma:
    
    <img className="thumbnail" alt="Backup Agent Restore Point Summary" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-restore-point-summary.png" loading="lazy" />

Infine, cerca il tuo file e seleziona un'opzione:
    
    <img className="thumbnail" alt="Backup Agent Restore Wizard" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-wizard.png" loading="lazy" />
    
    - Restore - Overwrite: ti permette di ripristinare il file sovrascrivendo quello attualmente presente sul server.
    - Restore - Keep: ti permette di ripristinare il file mantenendo quello attualmente presente sul server.
    - Copy To: ti permette di copiare il file in un'ubicazione del tuo server.
    - Explore: ti permette di esplorare il backup.
    - Properties: ti permette di visualizzare le proprietà del file.
    
    Avviare un ripristino ti permetterà di ottenere un'ultima finestra che mostrerà il trasferimento:
    
    <img className="thumbnail" alt="Backup Agent Restore Transfer" src="/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-restore-transfer.png" loading="lazy" />
  </Tab>
  <Tab label="Linux">
    Per ripristinare file e cartelle su Linux, hai due opzioni: tramite l'interfaccia grafica o tramite la riga di comando.
    
    #### Tramite l'interfaccia grafica
    
    1\. Connetti al tuo server Bare Metal tramite SSH.
    2\. Avvia l'interfaccia Veeam digitando il comando seguente:
    
    ```bash
    sudo veeam
    ```
    
    3\. Nell'interfaccia, seleziona l'opzione di ripristino file.
    4\. Seleziona il Backup e il punto di ripristino desiderato.
    5\. Naviga nel backup per trovare i file o le cartelle da ripristinare.
    6\. Seleziona i file e scegli l'azione di ripristino:
       - Ripristina alla posizione originale
       - Copia in una nuova posizione
       - Esplora il backup
    
    #### Tramite la riga di comando
    
    Per ripristinare file tramite la riga di comando, devi prima montare il backup:
    
    1\. Elenca i tuoi backup disponibili:
    
    ```bash
    sudo veeamconfig backup list
    ```
    
    2\. Elenca i punti di ripristino di un Backup:
    
    ```bash
    sudo veeamconfig restore list --backup <backup_name>
    ```
    
    3\. Monta un punto di ripristino:
    
    ```bash
    sudo veeamconfig mount --backup <backup_name> --restorepoint <point_name>
    ```
    
    4\. Una volta montato, puoi accedere ai file tramite il punto di montaggio (di norma in `/mnt/veeam/`).
    
    5\. Copia i file desiderati dal punto di montaggio alla destinazione.
    
    6\. Una volta completato il ripristino, smonta il backup:
    
    ```bash
    sudo veeamconfig unmount --backup <backup_name>
    ```
    
    Per ulteriori informazioni, consulta la [documentazione Veeam](https://helpcenter.veeam.com/docs/agentforlinux/userguide/files_restore_gui.html?ver=13) e la [documentazione sul ripristino tramite riga di comando](https://helpcenter.veeam.com/docs/agentforlinux/userguide/files_restore_cmd.html?ver=13).
  </Tab>
</Tabs>

### Ripristino completo del server (Bare Metal Recovery)

Bare Metal Recovery è una funzionalità di Veeam che consiste nel creare in anticipo un'immagine ISO personalizzata, che può essere utilizzata per avviare un sistema e ripristinarlo da un backup memorizzato su un altro server. Questo metodo è destinato agli scenari di disaster recovery, quando il tuo server non si avvia più.

Permette di:

- Creare un'**immagine ISO di ripristino**: questo file permette di avviare la tua macchina in caso di malfunzionamento all'avvio del sistema.
- Utilizzare la tua immagine ISO per accedere al tuo ultimo backup e ripristinarlo dall'infrastruttura OVHcloud.

:::warning
This guide is based on the Veeam Agent for Windows. If you are using the Veeam Agent for Linux, the procedure is similar, although the interface is text-based.
:::


Per avviare dall'ISO di ripristino, utilizza l'IPMI del tuo server Bare Metal per caricare l'ISO.

#### Step 1: Create the recovery ISO

If your computer no longer boots, you will need a recovery ISO image to start it again.

:::warning
This image must be created before any incident. If your server is no longer available, you will not be able to create it.
:::


Here is how to create it:

1\. Open the **Create Recovery Media** tool, included with the Veeam Agent, on your machine.

<img className="thumbnail" alt="Launch the Create Recovery Media tool" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_01.png" loading="lazy" />

2\. Veeam will ask if you want to include additional drivers.

:::info
If you are using specific hardware (such as a RAID controller), select the required drivers. Otherwise, the default options are usually sufficient.
:::


<img className="thumbnail" alt="Select drivers for boot image" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_02.png" loading="lazy" />

3\. Choose where to save the ISO and give it a name.

<img className="thumbnail" alt="Set ISO location and name" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_03.png" loading="lazy" />

4\. Wait until the operation completes. The ISO file will be generated.

<img className="thumbnail" alt="Recovery ISO created" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_04.png" loading="lazy" />

<img className="thumbnail" alt="Recovery ISO" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/bare_metal_recovery_05.png" loading="lazy" />

You can now use this ISO to create a bootable USB key using a tool like Rufus.

#### Step 2: Boot the machine from the recovery ISO

If your system no longer boots and you need to restore it:

1\. Mount the ISO in your server console, then boot the machine from it.

:::tip
**Not sure how to boot from an ISO?**

Restart your physical machine and press the key indicated (usually F2, F12, ESC or DEL) to access the boot menu.
:::


2\. Once the system has started, the Veeam recovery wizard will open. Click <code className="action">Bare Metal Recovery</code>.

<img className="thumbnail" alt="Launch Bare Metal Recovery" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_01.png" loading="lazy" />

3\. Select <code className="action">Network Storage</code> to access your online backups.

:::warning
If the network is not detected, you may need to configure it manually. Click <code className="action">Configure network settings</code> and load any missing drivers.
:::


<img className="thumbnail" alt="Select Network Storage" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_02.png" loading="lazy" />

4\. Select <code className="action">Veeam Cloud Connect repository</code>.

<img className="thumbnail" alt="Choose Veeam Cloud Connect repository" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_03.png" loading="lazy" />

5\. Enter the following address when prompted for the service provider:

<img className="thumbnail" alt="Enter DNS" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_04.png" loading="lazy" />

:::warning
The automatic credential recovery procedure to access your restore points is not yet available. If needed, [contact our support team](https://help.ovhcloud.com/csm?id=csm_get_help) to obtain them.
:::


6\. Enter your username and password to log in.

<img className="thumbnail" alt="Enter credentials" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_05.png" loading="lazy" />

7\. Select the <code className="action">server</code> you want to restore.

<img className="thumbnail" alt="Select server" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_06.png" loading="lazy" />

8\. Choose the <code className="action">restore point (date/time)</code> you want to go back to.

We recommend using the most recent successful backup unless you have a specific reason to go back to an earlier version.

<img className="thumbnail" alt="Choose a restore point" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_07.png" loading="lazy" />

9\. Choose the <code className="action">restore mode</code> that fits your situation (choose **Entire computer** for a full restore).

<img className="thumbnail" alt="Restore mode" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_08.png" loading="lazy" />

10\. Review the summary, then start the <code className="action">restore</code>.

<img className="thumbnail" alt="Launch restore - confirmation" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_09.png" loading="lazy" />

<img className="thumbnail" alt="Launch restore - progress" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-agent-bare-metal-recovery/step2_10.png" loading="lazy" />

:::warning
The duration of the restore process depends on the size of your backup and your internet connection speed. Once complete, your system will reboot with the state corresponding to the selected restore point.
:::
