## Obiettivo

[SSL Gateway](/links/web/ssl-gateway) rende sicure le connessioni al tuo sito web: colloca un front-end HTTPS gestito, dotato di un certificato SSL, davanti ai tuoi server (VPS, server dedicato, ecc.).

:::warning
SSL Gateway non è compatibile con le offerte di [hosting Web OVHcloud](/links/web/hosting). Per utilizzare un certificato SSL con un hosting Web, consulta la nostra guida "[Hosting Web - Gestire un certificato SSL](/guides/web-cloud/web-hosting/ssl-on-webhosting)".

:::

**Questa guida ti mostra come ordinare un SSL Gateway.**

## Prerequisiti

- Disporre di un [dominio](/links/web/domains) o sottodominio che punta già al server del tuo sito web
- Avere accesso alla zona DNS del dominio

[[cpnav:network-ssl-gateway-console]]

## Procedura

### Ordine

Nella pagina **SSL Gateway**, clicca su <code className="action">Ordina un SSL Gateway</code>. Il modulo d'ordine comprende 4 passaggi.

**1. Offerta**: scegli <code className="action">Free</code> o <code className="action">Advanced</code>.

- **Free**: 1 dominio, il suo `www` e 1 sottodominio, domini fino a 3 livelli, un indirizzo IP condiviso, 1 server backend e un certificato Let's Encrypt rinnovato automaticamente, senza canone mensile.
- **Advanced**: fino a 1.000 domini e sottodomini, domini di 4 livelli e oltre, un indirizzo IP dedicato e il bilanciamento del carico su un massimo di 3 server backend.

Entrambe le offerte sono fatturate mensilmente, senza costi di attivazione e senza vincoli.

<img className="thumbnail" alt="Pagina di ordine di un SSL Gateway con le offerte Free e Advanced, il passaggio Dominio e il riepilogo dell'ordine" src="/images/network/ssl-gateway/order-ssl-gateway/console/order-offer.png" loading="lazy" />

**2. Dominio**: nel campo **Dominio**, inserisci il dominio o sottodominio che il tuo SSL Gateway serve in HTTPS, quindi clicca su <code className="action">Verifica</code>. Il dominio deve già puntare al tuo sito web: sotto **IP del backend**, il modulo mostra l'indirizzo IPv4 verso cui punta, a cui il tuo SSL Gateway inoltra il traffico. Se ce ne sono diversi, scegline uno.

:::warning
- Con l'offerta Free, il dominio può avere fino a 3 livelli, come `www.example.com`. Per un sottodominio più profondo, come `blog.www.example.com`, scegli Advanced.
- Il modulo rifiuta un dominio che punta a un indirizzo già utilizzato da un altro servizio OVHcloud (Load Balancer, CDN, hosting Web o SSL Gateway). Fallo puntare all'indirizzo del tuo server, poi verifica di nuovo.
- Con l'offerta Advanced, puoi aggiungere fino a 2 server backend in più dopo la consegna, nel riquadro **Backend** del tuo SSL Gateway. Consulta la nostra guida "[Configurare e gestire il tuo SSL Gateway](/guides/network/ssl-gateway/use)".

:::

**3. Posizione**: scegli <code className="action">Roubaix (eu-west-rbx-a)</code> o <code className="action">Beauharnois (ca-east-bhs-a)</code>.

**4. DNS**: se gestisci la zona DNS del dominio presso OVHcloud, puoi selezionare la casella <code className="action">Gestisco la zona DNS di questo dominio e autorizzo OVHcloud ad aggiornare automaticamente il record DNS necessario.</code> Il record viene quindi aggiornato per te e il riepilogo dell'ordine mostra **Aggiornamento DNS**: Automatico. Altrimenti, dopo l'ordine fai puntare tu stesso il dominio al tuo SSL Gateway (vedi più avanti).

<img className="thumbnail" alt="Passaggi Dominio, Posizione e DNS del modulo d'ordine di SSL Gateway dopo la verifica di un dominio, con l'IP del backend, la scadenza di 3 giorni e l'avviso su HTTPS" src="/images/network/ssl-gateway/order-ssl-gateway/console/order-domain-location-dns.png" loading="lazy" />

Verifica le tue scelte nel riepilogo dell'ordine, poi clicca su <code className="action">Continua l'ordine</code>. La verifica dell'ordine si apre in una nuova scheda: segui i passaggi fino al pagamento dell'ordine. Il tuo SSL Gateway compare nella pagina **SSL Gateway** non appena viene consegnato.

### Far puntare il tuo dominio verso il tuo SSL Gateway

Se non hai selezionato la casella DNS, fai puntare il tuo dominio o sottodominio all'indirizzo IP del tuo SSL Gateway entro 3 giorni dall'ordine: l'indirizzo è indicato nella nostra email. In caso contrario, l'ordine viene annullato.

:::info
**Caso 1: la tua zona DNS è gestita dai server DNS condivisi OVHcloud**

- Se il tuo identificativo cliente è contatto *amministratore* o *tecnico* di questa zona DNS, modifica la zona nella <ManagerLink console to="/#/web-cloud/domains/listing">console OVHcloud</ManagerLink>.
- Altrimenti, chiedi al responsabile di questa zona DNS di modificarla.

Se necessario, consulta la nostra guida "[Aggiungere un record DNS di tipo A per un dominio](/guides/web-cloud/domains/dns-zone-a-record-creation)".

:::

:::info
**Caso 2: la tua zona DNS non è gestita dai server DNS condivisi OVHcloud**

Modifica l'indirizzo IP nella tua zona DNS dall'interfaccia del tuo provider DNS o sul tuo server DNS.

:::

Dalla consegna, il traffico HTTP non cifrato passa già attraverso il tuo SSL Gateway. HTTPS si attiva quando il tuo dominio punta al tuo SSL Gateway e il relativo certificato viene emesso, di solito entro 15 minuti.

:::warning
Una modifica della zona DNS può richiedere fino a 24 ore per diventare effettiva, perché i provider Internet conservano i record DNS nella loro cache.

:::
