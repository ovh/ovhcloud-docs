## Obiettivo

Una volta ordinato il tuo SSL Gateway, puoi configurarlo nella console OVHcloud.

**Questa guida ti mostra come associare i tuoi domini al tuo SSL Gateway, definire i server verso cui viene inoltrato il traffico, configurarne i parametri di rete e seguirne le operazioni e le statistiche.**

## Prerequisiti

- Disporre di un [SSL Gateway](/guides/network/ssl-gateway/order) con offerta Free o Advanced
- Avere accesso alla zona DNS di ciascun dominio che vuoi servire tramite il tuo SSL Gateway

## Introduzione

[SSL Gateway](/links/web/ssl-gateway) è un front-end HTTPS gestito per il tuo sito web. Il servizio si colloca davanti ai tuoi server, chiamati server backend: detiene il certificato SSL, gestisce la connessione TLS con i browser dei tuoi visitatori e protegge il traffico dagli attacchi DDoS, quindi inoltra le richieste ai tuoi server.

L'offerta del tuo SSL Gateway determina cosa puoi configurare:

| Funzionalità | Free | Advanced |
|---|---|---|
| Domini | 3: 1 dominio, il suo `www` e 1 sottodominio | Fino a 1.000 domini e sottodomini, inclusi i domini di 4 livelli e oltre |
| Server backend | 1 | Fino a 3, con il traffico ripartito tra di essi |
| Indirizzi IP dedicati | No | Sì |
| Profilo di cifratura | Intermediate, fisso | Modern o Intermediate |
| HSTS (HTTP Strict Transport Security) | No | Sì |
| Sorgenti autorizzate | No: tutte le sorgenti possono raggiungere il gateway | Sì |
| Reverse DNS modificabile | No | Sì |
| Scheda <code className="action">Statistiche</code> | No | Sì |
| Certificato EV (Extended Validation) | No | Opzionale (Sectigo) |

## Procedura

### Aprire il tuo SSL Gateway

L'elenco mostra i tuoi SSL Gateway con le colonne **Nome / ID**, **Regione**, **Offerta**, **IPv4** e **Stato**. Clicca sul nome dell'SSL Gateway che vuoi configurare.

<img className="thumbnail" alt="Elenco degli SSL Gateway con le colonne Nome / ID, Regione, Offerta, IPv4 e Stato" src="/images/network/ssl-gateway/use-ssl-gateway/console/ssl-gateway-list.png" loading="lazy" />

La pagina del tuo SSL Gateway si apre sulla scheda <code className="action">Panoramica</code>, che mostra quattro riquadri:

- **Informazioni generali**: l'ID, la regione, il reverse DNS, gli indirizzi IPv4 e IPv6 del tuo SSL Gateway, nonché gli intervalli **IPv4 in uscita** che utilizza per raggiungere i tuoi server;
- **Abbonamento**: l'offerta, la data di creazione, la modalità di rinnovo e la data di rinnovo;
- **Configurazione di rete**: i parametri TLS e di accesso del tuo SSL Gateway;
- **Backend**: i server verso cui viene inoltrato il traffico.

Le altre schede sono <code className="action">Domini</code>, <code className="action">Statistiche</code> (solo offerta Advanced) e <code className="action">Operazioni</code>.

<img className="thumbnail" alt="Scheda Panoramica di un SSL Gateway Advanced con i riquadri Informazioni generali, Abbonamento, Configurazione di rete e Backend" src="/images/network/ssl-gateway/use-ssl-gateway/console/overview-advanced.png" loading="lazy" />

### Aggiungere ed eliminare domini

Affinché un dominio venga validato, i suoi record DNS devono puntare al tuo SSL Gateway: un record A verso il suo indirizzo IPv4 e, se il gateway dispone di un indirizzo IPv6, un record AAAA verso quest'ultimo. Entrambi gli indirizzi sono indicati nel riquadro **Informazioni generali**. Se la zona DNS del dominio è gestita da OVHcloud, consulta le nostre guide sui [record A](/guides/web-cloud/domains/dns-zone-a-record-creation) e sui [record AAAA](/guides/web-cloud/domains/dns-zone-aaaa-record-creation).

Per associare un dominio, apri la scheda <code className="action">Domini</code> e clicca su <code className="action">Aggiungi un dominio</code>.

<img className="thumbnail" alt="Scheda Domini di un SSL Gateway con il pulsante Aggiungi un dominio e l'icona di eliminazione sulla riga di un dominio" src="/images/network/ssl-gateway/use-ssl-gateway/console/domains-tab.png" loading="lazy" />

Nel campo **Dominio**, inserisci il nome host che vuoi servire in HTTPS, ad esempio `shop.example.com`, quindi clicca su <code className="action">Aggiungi il dominio</code>.

<img className="thumbnail" alt="Finestra Aggiungi un dominio con il campo Dominio" src="/images/network/ssl-gateway/use-ssl-gateway/console/add-domain-dialog.png" loading="lazy" />

La validazione DNS può richiedere fino a 72 ore. Fino al suo completamento, lo stato del dominio indica **Creating**.

L'offerta Free include 3 domini: 1 dominio, il suo `www` e 1 sottodominio. Una volta associati 3 domini, il pulsante <code className="action">Aggiungi un dominio</code> viene disattivato.

Per eliminare un dominio, clicca sull'icona di eliminazione sulla sua riga, quindi su <code className="action">Eliminare</code>. Il dominio viene dissociato dal tuo SSL Gateway e non viene più servito in HTTPS.

### Configurare i server backend

Il riquadro **Backend** della scheda <code className="action">Panoramica</code> indica dove il tuo SSL Gateway inoltra il traffico che riceve: l'indirizzo IP e la porta dei tuoi server.

**Offerta Free**: il traffico viene inoltrato a 1 server. Clicca su <code className="action">Modifica il backend</code>, inserisci l'indirizzo IP del server nel campo **Indirizzo IP** e, nel campo **Porta**, la porta su cui il server riceve il traffico del tuo SSL Gateway, quindi clicca su <code className="action">Registra</code>.

<img className="thumbnail" alt="Pannello Modifica il backend di un SSL Gateway Free con i campi Indirizzo IP e Porta" src="/images/network/ssl-gateway/use-ssl-gateway/console/edit-backend-drawer.png" loading="lazy" />

**Offerta Advanced**: il traffico viene ripartito su un massimo di 3 server. Clicca su <code className="action">Aggiungi un server</code>, compila i campi **Indirizzo IP** e **Porta**, quindi clicca su <code className="action">Aggiungere</code>. Per modificare o eliminare un server, utilizza il menu della sua riga.

<img className="thumbnail" alt="Pannello Aggiungi un server di un SSL Gateway Advanced con i campi Indirizzo IP e Porta" src="/images/network/ssl-gateway/use-ssl-gateway/console/add-server-drawer.png" loading="lazy" />

L'indirizzo IP deve essere l'indirizzo IPv4 pubblico del tuo server: il tuo SSL Gateway non può raggiungere un indirizzo privato.

Ogni modifica viene eseguita come un'operazione e applicata tra pochi istanti. Puoi seguirla nella scheda <code className="action">Operazioni</code>.

Il tuo SSL Gateway raggiunge i tuoi server dagli intervalli IP indicati in **IPv4 in uscita** nel riquadro **Informazioni generali**. Autorizza questi intervalli nei firewall dei tuoi server.

### Configurare i parametri di rete

Nel riquadro **Configurazione di rete**, clicca su <code className="action">Modifica la configurazione di rete</code>. Puoi definire:

- **Profilo di cifratura**: le suite di cifratura che il tuo SSL Gateway offre ai browser. <code className="action">Modern</code> mantiene solo le più robuste, per i client recenti; <code className="action">Intermediate</code> supporta anche quelli meno recenti.
- <code className="action">HTTPS verso il backend</code>: cifra anche il traffico tra il tuo SSL Gateway e i tuoi server, e non solo tra i browser e il tuo SSL Gateway.
- <code className="action">Reindirizzamento HTTPS</code>: reindirizza ogni richiesta HTTP verso HTTPS.
- <code className="action">HSTS</code>: indica ai browser di raggiungere i tuoi domini solo in HTTPS nelle visite successive.
- **Sorgenti autorizzate**: gli indirizzi o i blocchi IPv4 o IPv6 autorizzati a raggiungere il tuo SSL Gateway. Inserisci un indirizzo o un blocco, ad esempio `203.0.113.0/24`, quindi clicca su <code className="action">Aggiungere</code>, una volta per ogni sorgente. Per rimuovere una sorgente, clicca sulla croce accanto a essa. Se non ne è indicata nessuna, tutte le sorgenti possono raggiungere il tuo SSL Gateway.

Quindi clicca su <code className="action">Registra</code>.

<img className="thumbnail" alt="Pannello Modifica la configurazione di rete con l'elenco Profilo di cifratura, le caselle HTTPS verso il backend, Reindirizzamento HTTPS e HSTS e il campo Sorgenti autorizzate" src="/images/network/ssl-gateway/use-ssl-gateway/console/network-configuration-drawer.png" loading="lazy" />

Con l'offerta Free, il profilo di cifratura resta **Intermediate**, e HSTS e le sorgenti autorizzate non sono disponibili. Se il tuo SSL Gateway Free mantiene ancora tali parametri, salvando una modifica verranno ripristinati ai valori dell'offerta Free: Intermediate, HSTS disattivato, nessuna restrizione delle sorgenti.

### Modificare il reverse DNS

Con l'offerta Advanced, puoi definire il reverse DNS del tuo SSL Gateway: nel riquadro **Informazioni generali**, clicca sull'icona a forma di matita accanto a **Reverse DNS**, inserisci il nome host nel campo **Reverse DNS**, quindi clicca su <code className="action">Registra</code>. Con l'offerta Free, il reverse DNS non è modificabile.

<img className="thumbnail" alt="Pannello Modifica il reverse DNS con il campo Reverse DNS" src="/images/network/ssl-gateway/use-ssl-gateway/console/reverse-dns-drawer.png" loading="lazy" />

### Seguire le operazioni

Ogni modifica del tuo SSL Gateway, come l'aggiunta o l'eliminazione di un dominio o di un server, o un upgrade, viene eseguita come un'operazione. La scheda <code className="action">Operazioni</code> le mostra con le colonne **ID**, **Azione**, **Stato**, **Avanzamento** e **Data di creazione**. Per visualizzare i dettagli di un'operazione, clicca su <code className="action">Andare ai dettagli</code> sulla sua riga.

### Consultare le statistiche

Con l'offerta Advanced, la scheda <code className="action">Statistiche</code> mostra il traffico del tuo SSL Gateway. In **Periodo**, scegli una durata, da <code className="action">1 h</code> a <code className="action">1 m</code> (un mese). La scheda mostra la media e il picco del numero di richieste e di connessioni al secondo nel periodo. Sopra il grafico, scegli <code className="action">Richieste/s</code> o <code className="action">Connessioni/s</code>.

<img className="thumbnail" alt="Scheda Statistiche di un SSL Gateway Advanced con il selettore del periodo, i valori medio e di picco e il grafico delle richieste" src="/images/network/ssl-gateway/use-ssl-gateway/console/statistics-tab.png" loading="lazy" />

### Gestire l'offerta e l'abbonamento

Il riquadro **Abbonamento** mostra l'offerta, la data di creazione, la modalità di rinnovo e la data di rinnovo. Clicca su <code className="action">Gestire il mio abbonamento</code> per modificare il rinnovo. Per disattivare il servizio, clicca su <code className="action">Disattivare</code>, quindi di nuovo su <code className="action">Disattivare</code> nella finestra di conferma: riceverai poi un'email per confermare la disattivazione.

<Region zones={['eu']}>

Se l'offerta del tuo SSL Gateway può essere aggiornata, il riquadro **Abbonamento** mostra anche <code className="action">Effettua l'upgrade</code>.

<img className="thumbnail" alt="Scheda Panoramica di un SSL Gateway Free con Effettua l'upgrade nel riquadro Abbonamento" src="/images/network/ssl-gateway/use-ssl-gateway/console/overview-free.png" loading="lazy" />

Clicca su <code className="action">Effettua l'upgrade</code>. La finestra **Passa a Advanced** elenca ciò che aggiunge l'offerta Advanced (fino a 1.000 domini e sottodomini, domini di quattro livelli e oltre, un indirizzo IP dedicato, il bilanciamento del carico su un massimo di 3 server backend), l'importo da pagare oggi, pro rata, e l'importo addebitato in seguito ogni mese.

La casella <code className="action">Paga ora con il mio metodo di pagamento predefinito</code> è selezionata per impostazione predefinita. Per pagare invece dalla pagina dell'ordine, che si apre in una nuova scheda del browser, deselezionala. Quindi clicca su <code className="action">Effettua l'upgrade</code>.

<img className="thumbnail" alt="Finestra Passa a Advanced con gli importi, l'avviso sull'indirizzo IP e la casella Paga ora con il mio metodo di pagamento predefinito" src="/images/network/ssl-gateway/use-ssl-gateway/console/upgrade-dialog.png" loading="lazy" />

:::warning
L'offerta Advanced utilizza indirizzi IP dedicati. Al termine dell'upgrade, il tuo SSL Gateway riceve un nuovo indirizzo IPv4 e IPv6 e quelli precedenti smettono subito di servire il traffico. Fai puntare i tuoi domini verso i nuovi indirizzi, inviati via email e indicati nel riquadro **Informazioni generali**: fino ad allora, il tuo sito web non è raggiungibile tramite il tuo SSL Gateway.

:::

Il tuo SSL Gateway mantiene il suo ID e la sua configurazione. L'upgrade viene eseguito come un'operazione che puoi seguire nella scheda <code className="action">Operazioni</code>.

</Region>

### Rinnovare il certificato SSL

Il certificato SSL del tuo SSL Gateway è un certificato DV (Domain Validation) emesso da Let's Encrypt e rinnovato automaticamente. Con l'offerta Advanced, è disponibile in opzione un certificato SSL Sectigo EV.

Per rinnovare il certificato su richiesta, utilizza la seguente chiamata API:

<Api version="v1" section="/sslGateway" method="POST" route={"/sslGateway/\{serviceName\}/renewCertificate"} />
