## Obiettivo

La *blocklist* (o lista di blocco, chiamata anche *Realtime Blackhole List* o RBL) è una tecnica di lotta contro lo spam che prende di mira indirizzi IP (o intervalli di indirizzi IP) per bloccare le email considerate come spam o che potrebbero contenere programmi dannosi. Quando un nome di dominio o un indirizzo IP viene bloccato, le email che ne provengono rischiano di non raggiungere i loro destinatari, compromettendo così la recapitabilità e la reputazione del mittente. Le email che riescono comunque ad arrivare a destinazione possono finire nella cartella spam del destinatario invece che nella sua casella di posta.

Le blocklist possono includere nomi di dominio e indirizzi IP che non rappresentano alcuna minaccia reale. Alcuni servizi di filtro dello spam, come SpamRATS, prendono inoltre in considerazione il reverse DNS durante la valutazione degli indirizzi IP.

:::info
Per conoscere le best practice di utilizzo di un server di posta elettronica, consulta la nostra guida su [come evitare che le tue email siano contrassegnate come spam](/guides/bare-metal-cloud/dedicated-servers/mail-sending-optimization).

:::


**Questa guida presenta le azioni possibili per far rimuovere i tuoi indirizzi IP OVHcloud da una blocklist.**

:::warning
Le informazioni contenute in questa guida sono soggette a modifica e si applicano agli indirizzi IP acquistati di recente. OVHcloud non può essere ritenuta responsabile delle azioni dei provider terzi.

In caso di difficoltà o dubbi relativamente ad amministrazione, utilizzo o implementazione dei servizi su un server, ti consigliamo di contattare un [provider di servizi specializzato](/links/partner) o la nostra [Community di utenti](/links/community).

:::


## Prerequisiti

- I tuoi servizi non sono attualmente interessati da una procedura di segnalazione di abusi.

## Procedura

### Provider supportati

- [Spamhaus](https://check.spamhaus.org/)

    - [Spamhaus Block List (SBL)](https://www.spamhaus.org/blocklists/spamhaus-blocklist/)  
    Se [l'IP figura nella lista di blocco (SBL) di Spamhaus](https://check.spamhaus.org/sbl/listings/ovh.net/), significa che il nostro team responsabile delle segnalazioni di abusi ti ha già contattato via email.

      L'email inviata dal nostro team proviene da un indirizzo simile a questo: `ticket+ABCDEFGHIJ.ID@abuse.ovh.net` (il numero di ticket è sempre in maiuscolo e l'ID che segue è composto da 4 caratteri alfanumerici).

      Segui le indicazioni fornite in questa email per risolvere la situazione. Una volta prese le misure correttive, le trasmetteremo a Spamhaus e chiederemo la rimozione del tuo IP dalla lista. Spamhaus rimane tuttavia l'unico giudice del seguito da dare alla nostra richiesta.
    - [Exploits Block List (XBL)](https://www.spamhaus.org/blocklists/exploits-blocklist/) o [Combined Spam Sources (CSS)](https://www.spamhaus.org/blocklists/combined-spam-sources/)  
    Se il tuo IP figura nell'*Exploits Block List* e/o nella lista *Combined Spam Sources*, ciò è generalmente dovuto a problemi di configurazione. Segui gli step descritti sul sito di Spamhaus per rimuovere l'IP dalla lista (vedi l'esempio qui sotto). Una volta completati questi step, puoi rimuovere l'IP autonomamente.

- [SpamCop](https://www.spamcop.net/bl.shtml)  
    Questa pagina ti permette di verificare lo stato attuale di un IP. La SpamCop Blocking List (SCBL) funziona su base temporale: un IP viene rimosso automaticamente non appena le segnalazioni di spam cessano. Generalmente non è quindi necessario inviare una richiesta di rimozione manuale.

- [Barracuda](https://www.barracudacentral.org/lookups)  
    Per essere rimosso dalla Barracuda Reputation Block List (BRBL), compila il [modulo di richiesta di rimozione di Barracuda](https://www.barracudacentral.org/rbl/removal-request). Poiché le registrazioni vengono verificate manualmente, la rimozione non è immediata.

- [SpamRATS](https://spamrats.com/lookup.php)  
    Se utilizzi un tuo server di posta elettronica, devi configurare il nome di dominio nel campo PTR, dove si trovano i dati di contatto del responsabile. Solo i server email configurati correttamente vengono rimossi da questa lista.  
    Devi inoltre [configurare la risoluzione DNS inversa](/guides/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns).
    
    :::info
    **Best practice:**
    
    Gli indirizzi IP utilizzati per l'invio di email devono corrispondere al nome di dominio del responsabile. Puoi inoltre utilizzare sottodomini per la risoluzione DNS inversa, ad esempio `mail.nome_dominio.com` o `gateway.nome_dominio.com`.

    :::



### Provider non supportati

#### s5h.net

<details>

<summary>Maggiori informazioni</summary>


Per richiedere la rimozione, vai alla [pagina di rimozione RBL di usenix](https://www.usenix.org.uk/content/rblremove) dall'indirizzo IP bloccato. L'IP dovrebbe essere rimosso dalla lista immediatamente.

È inoltre possibile utilizzare gli strumenti *telnet*, *curl* o *wget*.

Per rimuovere il tuo indirizzo IPv4 dalla lista tramite *curl*, accedi al server di posta indicato ed esegui il comando seguente:

```bash
curl -4 http://www.usenix.org.uk/content/rblremove
```

Per eseguire la stessa operazione utilizzando *telnet* da un host Windows/Linux, inserisci le righe *GET* e *Host* dopo il comando *telnet* come indicato di seguito.

```bash
telnet www.usenix.org.uk 80
```

```bash
GET /content/rblremove HTTP/1.1
```

```bash
Host: www.usenix.org.uk
```

Per una spiegazione dettagliata, consulta la [documentazione RBL di usenix](https://www.usenix.org.uk/content/rbl.html).

</details>


#### UCEprotect


<details>

<summary>Maggiori informazioni</summary>


UCEprotect inserisce regolarmente un gran numero di ASN nella sua blocklist di livello 3, e l'ASN di OVHcloud (AS16276) può essere interessato da questa situazione. Per consultare l'elenco degli ASN interessati e il numero di ASN aggiunti di recente, consulta i link seguenti:

- [UCEPROTECT Level 3 charts](https://www.uceprotect.net/en/l3charts.php)
- [UCEPROTECT statistics center](https://stats.uceprotect.net/?page=su)

Il nostro team responsabile delle segnalazioni di abusi contatta UCEprotect per chiedere la rimozione del nostro ASN dalla blocklist. UCEprotect impone agli operatori di rete degli ASN interessati di pagare per una rimozione rapida. Come tutti i grandi fornitori, OVHcloud non paga per essere rimosso da una blocklist, trattandosi di un servizio fuori dal nostro controllo. Pagare per una rimozione non fa che aggravare il fenomeno del blocco nel suo complesso e finisce per danneggiare l'intero settore.

UCEprotect indica di cancellare automaticamente gli ASN dopo una settimana. Poiché questo è fuori dal nostro controllo, non possiamo fornire alcuna garanzia in merito.

Se sei attualmente interessato da questa situazione, ti consigliamo quanto segue:

1. Utilizza indirizzi IPv6 per inviare le tue email. UCEprotect non blocca le email inviate tramite IPv6. Tutti i servizi OVHcloud includono almeno un indirizzo IPv6 configurabile, e tutti i grandi provider di posta elettronica supportano ormai l'IPv6.
2. Chiedi al destinatario di contattare il proprio provider di posta elettronica affinché smetta di utilizzare la blocklist UCEprotect.


</details>


#### Fabel Spamsources

<details>

<summary>Maggiori informazioni</summary>


Per rimuovere un IP dalla lista di Fabel Spamsources, accedi alla relativa [pagina di rimozione dalla lista](https://www.spamsources.fabel.dk/delist).

Clicca su <code className="action">Please login to continue</code>, inserisci il tuo indirizzo email e verifica la tua casella di posta. Utilizza il codice di verifica per completare la connessione.

Inserisci il tuo indirizzo IP, indica il motivo della richiesta di eliminazione, poi clicca su <code className="action">Submit Query</code>.

<img className="thumbnail" alt="Modulo di rimozione di Fabel Spamsources con i campi indirizzo IP e motivo" src="/images/network/additional-ip/blocklist-ip-delist/blocklist3.png" loading="lazy" />

La rimozione dalla lista dovrebbe richiedere tra i 20 e i 30 minuti.

</details>



#### MIPSpace

<details>

<summary>Maggiori informazioni</summary>


Per [rimuovere un IP da MIPSpace](https://www.mipspace.com/removal.php), accedi prima al tuo <ManagerLink to="/">Spazio Cliente OVHcloud</ManagerLink> e assicurati che le informazioni riportate di seguito siano aggiornate:

- [La risoluzione reverse DNS](/guides/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns) (campo PTR).
- I dettagli della tua organizzazione (*RWhois*). Vai su <code className="action">Network</code> > <code className="action">Rete pubblica</code> > <code className="action">Indirizzi IP pubblici</code>, poi apri la scheda <code className="action">Gestisci le mie organizzazioni</code>.

</details>
