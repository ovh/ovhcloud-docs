## Obiettivo

Le autorizzazioni e le password associate agli utenti del client vSphere possono essere gestite dalla console OVHcloud.

**Questa guida ti mostra come modificare la password di un utente.**

## Prerequisiti

- Avere accesso alla <ManagerLink console to="/">console OVHcloud</ManagerLink>
- Disporre di un account utente creato dalla console OVHcloud. Per maggiori informazioni, consulta la nostra guida "[Gestire il tuo Hosted Private Cloud dalla console OVHcloud](/guides/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud#utenti)"

[[cpnav:privatecloud-vmware-vsphere-console]]

## Procedura

### Modifica la password

Nella console OVHcloud, accedi a **Private Cloud** › **Managed VMware vSphere** e seleziona il tuo servizio dalla lista. Clicca sulla scheda <code className="action">Utenti</code>.

Apri il menu ⋮ (colonna **Azioni**) dell’utente interessato e clicca su <code className="action">Cambia la password</code>.

Nella finestra **Modificare la password**, inserisci una nuova password nel campo **Nuova password**, confermala nel campo **Conferma password** e clicca su <code className="action">Confermare</code>.

:::info
Se non viene inserita una password, ne verrà generata una in modo casuale che sarà poi inviata via email all’indirizzo associato all’utente.

:::

Su un servizio che dispone di un’opzione di conformità certificata (PCI DSS, HDS…), la finestra non mostra alcun modulo: indica l’indirizzo dell’interfaccia certificata (`https://<tuo-servizio>/secure`), da cui puoi modificare la password.

:::warning
Per non compromettere la sicurezza dell’infrastruttura, consigliamo di seguire alcune best practice. La password deve:

- contenere almeno 8 caratteri
- contenere almeno 3 tipi di caratteri
- non essere tratta dal dizionario
- non contenere informazioni personali
- non essere utilizzata per più accessi
- essere salvata in un <i>password manager</i>
- essere cambiata ogni 3 mesi
- essere diversa dalle password precedenti

:::
