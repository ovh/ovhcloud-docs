## Obiettivo

Oltre ai [diritti globali del datacenter](/guides/hosted-private-cloud/powered-by-vmware/vsphere-global-rights), puoi assegnare diritti granulari agli utenti su oggetti specifici del tuo inventario vSphere Hosted Private Cloud (ad esempio, una VM o un datastore). Questa guida spiega come aggiungere, consultare e rimuovere questi diritti tramite l'API OVHcloud.

> [!warning]
> I diritti granulari sugli oggetti vSphere non possono essere gestiti dallo Spazio Cliente OVHcloud. Devono essere configurati tramite l'API OVHcloud.

## Prerequisiti

- Un [servizio Hosted Private Cloud](/links/hosted-private-cloud/vmware) con versione vSphere 6.5 o superiore
- Accesso all'<ApiLink>API OVHcloud</ApiLink>
- Un [utente](/guides/hosted-private-cloud/powered-by-vmware/vsphere-interface-connection) già creato nel tuo servizio Hosted Private Cloud

## Procedura

### Aggiungere diritti a un oggetto vSphere

1. Chiama il seguente endpoint API:

    <Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\\{serviceName\\}/user/\\{userId\\}/objectRight"} />

2. Compila il corpo della richiesta con l'oggetto e l'utente a cui desideri concedere l'accesso.

    Puoi scegliere se propagare o meno il diritto agli oggetti figli, in modo simile ai diritti nativi di vSphere.

3. Conferma la richiesta. Viene creato un task di tipo `addUserObjectRight` e applicato all'oggetto vSphere.

    Ad esempio, per concedere l'accesso in lettura/scrittura a una VM:

    ```json
    {
      "propagate": false,
      "right": "readwrite",
      "type": "vm",
      "vmwareObjectId": "vm-92"
    }
    ```

### Consultare i diritti di un utente su un oggetto vSphere

Per consultare un diritto specifico, devi prima conoscerne l'identificatore `objectRightId`.

1. Elenca tutti i diritti concessi all'utente chiamando il seguente endpoint:

    <Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\\{serviceName\\}/user/\\{userId\\}/objectRight"} />

    Compila i campi con il `serviceName` (dominio del servizio) e il `userId` (identificativo dell'utente). La risposta restituisce la lista degli identificatori `objectRightId` dei diritti concessi all'utente:

    ```json
    [
      42,
      57,
      63
    ]
    ```

2. Chiama il seguente endpoint API per consultare il dettaglio di un diritto:

    <Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\\{serviceName\\}/user/\\{userId\\}/objectRight/\\{objectRightId\\}"} />

3. Compila i campi con l'`objectRightId` corrispondente al diritto che desideri consultare.

4. Conferma la richiesta. La risposta restituisce le informazioni relative al diritto concesso all'utente sull'oggetto vSphere:

    ```json
    {
      "name": "string",
      "objectRightId": 0,
      "propagate": false,
      "right": "admin",
      "type": "cluster",
      "vmwareObjectId": "string"
    }
    ```

### Rimuovere diritti da un oggetto vSphere

1. Chiama il seguente endpoint API:

    <Api version="v1" section="/dedicatedCloud" method="DELETE" route={"/dedicatedCloud/\\{serviceName\\}/user/\\{userId\\}/objectRight/\\{objectRightId\\}"} />

2. Compila i campi con l'`objectRightId` corrispondente al diritto che desideri rimuovere.

3. Conferma la richiesta. Viene creato un task di tipo `removeUserObjectRight` e rimuove il diritto dell'utente dall'oggetto vSphere.
