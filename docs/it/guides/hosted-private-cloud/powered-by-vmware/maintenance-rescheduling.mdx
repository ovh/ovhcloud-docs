## Obiettivo

In caso di manutenzione programmata sul tuo Hosted Private Cloud, riceverai un'email di notifica per avvisarti della data di questa manutenzione. Se questa data non è adatta alle tue esigenze, ad esempio per vincoli di produzione, puoi posticipare la manutenzione a una data di tua scelta tramite la console OVHcloud o l'API OVHcloud.

:::info
Cerchiamo di adattarci il più possibile al tipo di utilizzo dell'infrastruttura e ai tuoi vincoli. A volte, però, è necessario pianificare interventi di manutenzione per i quali non sarà possibile modificare la data e/o l'ora (interventi di manutenzione che coinvolgono più clienti, interventi urgenti per evitare un incidente, ecc...).

Quando una data di manutenzione può essere modificata da te, le nuove date proposte sono incluse in un intervallo di tempo ridotto.

:::

**Questa guida ti mostra come posticipare la data di una manutenzione programmata sul tuo VMware on OVHcloud dalla console OVHcloud o tramite l'API OVHcloud.**

## Prerequisiti

- Aver ricevuto un'email di notifica di manutenzione che indica specificamente che è possibile "**modificare la data di esecuzione della manutenzione**" In caso contrario, la data della manutenzione non può essere modificata.
- Essere contatto amministratore o tecnico dell'infrastruttura [VMware on OVHcloud](https://www.ovhcloud.com/it/enterprise/products/hosted-private-cloud/).
- Avere accesso all'<ApiLink>interfaccia di gestione dei servizi via API</ApiLink>.

## Procedura

:::tip
Le email inviate da OVHcloud sono accessibili anche dalla cronologia delle email di servizio del tuo account OVHcloud.

:::

### Dalla console OVHcloud

Con un account amministratore, accedi a **Private Cloud** › **Managed VMware vSphere** nella console OVHcloud, seleziona il tuo servizio nella lista e clicca sulla scheda <code className="action">Operazioni</code>. Nel menu a tendina situato sopra la tabella delle operazioni, a destra, verifica che sia selezionato <code className="action">In corso</code> (valore predefinito) per visualizzare le operazioni non ancora completate.

Apri quindi il menu ⋮ (colonna **Azioni**) dell'operazione di manutenzione e clicca su <code className="action">Modifica la data di elaborazione</code>.

:::info
Se l'opzione <code className="action">Modifica la data di elaborazione</code> non è disponibile, questa manutenzione non può essere posticipata.

:::

Nella finestra **Modifica la data di elaborazione**, seleziona una data nel calendario **Data di elaborazione**. Sono selezionabili solo le date disponibili: le date al di fuori della finestra di manutenzione autorizzata non possono essere scelte.

Inserisci quindi una nuova ora per questa manutenzione nel campo **Ora** o lascia invariato l'orario inizialmente previsto.

Infine, clicca sul pulsante <code className="action">Modificare</code> per confermare le modifiche.

### Via API OVHcloud

Accedi all'<ApiLink>interfaccia di gestione dei tuoi servizi via API</ApiLink>. Per maggiori informazioni, consulta la guida Iniziare a [utilizzare le API OVHcloud](/guides/manage-and-operate/api/first-steps).

Esegui questa chiamata API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/task/\{taskId\}/changeMaintenanceExecutionDate"} />

Inserisci le variabili:

- serviceName: il riferimento del tuo PCC in forma `pcc-XX-XX-XX-XX`.
- taskId: è il "riferimento dell'operazione" indicato nell'email di notifica inviata.
- executionDate: inserisci la nuova data di manutenzione in formato `YYYY-MM-DDTHH:MM+01:SS` (ad esempio, 2023-01-02T08:00:00+01:00 per una manutenzione programmata il 02/01/2023 alle 08:00 (UTC+1)).
