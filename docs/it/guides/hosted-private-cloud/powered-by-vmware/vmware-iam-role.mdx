## Obiettivo

**In questa guida ti spieghiamo come creare un ruolo IAM in Hosted Private Cloud - VMware on OVHcloud**.

## Prerequisiti

- Disporre di un [account OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation)
- Disporre di uno o più prodotti Hosted Private Cloud - VMware on OVHcloud associati a questo account (Hosted Private Cloud powered by VMware, VMware Service Pack).
- Aver attivato IAM per il tuo servizio Hosted Private Cloud - VMware on OVHcloud. Segui le istruzioni della guida [IAM per VMware on OVHcloud - Come attivare IAM](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-activation).

[[cpnav:privatecloud-vmware-vsphere-console]]

## Procedura

Di default disponi di 2 ruoli IAM vSphere. La creazione di un ruolo aggiuntivo è quindi facoltativa.

Ti spieghiamo come creare un ruolo aggiuntivo.

### Creare un ruolo IAM dalla console OVHcloud

Seleziona la tua infrastruttura, quindi accedi alla scheda <code className="action">Utenti</code>.

Clicca su <code className="action">Crea un ruolo IAM</code>.

<img className="thumbnail" alt="Scheda Utenti di un servizio Managed VMware vSphere con il pulsante Crea un ruolo IAM" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role/console/iam_role_8.png" loading="lazy" />

Nella finestra **Creare un nuovo ruolo IAM OVHcloud** che si apre, inserisci il nome del tuo ruolo nel campo **Nome del ruolo**, quindi clicca su <code className="action">Confermare</code>.

:::info
Ai ruoli IAM viene aggiunto automaticamente il prefisso `iam-`.

:::

<img className="thumbnail" alt="Finestra Creare un nuovo ruolo IAM OVHcloud, prefisso iam- nel campo Nome del ruolo" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role/console/iam_role_9.png" loading="lazy" />

Puoi quindi modificare i permessi del gruppo come per un utente locale vSphere: clicca sul pulsante <code className="action">⋮</code> nella colonna **Azioni** della riga del tuo ruolo, quindi seleziona <code className="action">Visualizza/Modifica i permessi per DC</code>.

#### Creare un ruolo IAM tramite l'API OVHcloud

:::tip
Consulta la guida [Iniziare a utilizzare le API OVHcloud](/guides/manage-and-operate/api/first-steps) per familiarizzare con l'utilizzo delle APIv6 OVHcloud.

:::



Esegui questa chiamata API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/addRole"} />


:::warning
Assicurati di sostituire `serviceName` con il riferimento del tuo servizio Hosted Private Cloud, nel formato `pcc-XXX-XXX-XXX-XXX`.

:::
