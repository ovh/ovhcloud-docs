## Obiettivo

**Questa guida ti mostra come attivare IAM con Hosted Private Cloud - VMware on OVHcloud dalla console OVHcloud o con l'API OVHcloud**.

## Prerequisiti

- Disporre di un [account OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation)
- Disporre di uno o più prodotti Hosted Private Cloud - VMware on OVHcloud associati a questo account (Hosted Private Cloud powered by VMware, VMware Service Pack).

[[cpnav:privatecloud-vmware-vsphere-console]]

## Procedura

### Attivare IAM

:::info
Questa operazione può richiedere fino a 30 minuti.

:::


### Dalla console OVHcloud

Seleziona la tua infrastruttura, quindi accedi alla scheda <code className="action">Utenti</code>.

Nella sezione **OVHcloud IAM** in fondo alla scheda, clicca su <code className="action">Attiva OVHcloud IAM</code>.

<img className="thumbnail" alt="Sezione OVHcloud IAM con lo stato Disattivato e il link Attiva OVHcloud IAM" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_2.png" loading="lazy" />

:::warning
Solo il prodotto vSphere è integrato in OVHcloud IAM. Un'infrastruttura con opzioni di sicurezza rinforzata o un servizio certificato (HDS, PCI-DSS o SNC) al momento non può utilizzare OVHcloud IAM. Se in seguito attivi una di queste opzioni o uno di questi servizi certificati, dovrai disattivare OVHcloud IAM.
:::

Nella finestra **Attivare IAM OVHcloud** che si apre, clicca su <code className="action">Confermare</code>.

:::tip
Una volta attivato IAM, il suo stato sarà `Attivato` e visualizzato in verde.

:::

<img className="thumbnail" alt="Scheda Utenti con la sezione OVHcloud IAM nello stato Attivato" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_3.png" loading="lazy" />

### Tramite l'API OVHcloud

:::tip
Consulta la guida [Iniziare a utilizzare le API OVHcloud](/guides/manage-and-operate/api/first-steps) per familiarizzare con l'utilizzo delle APIv6 OVHcloud.

:::


:::warning
Assicurati di sostituire `serviceName` con il riferimento del tuo servizio Hosted Private Cloud, nel formato `pcc-XXX-XXX-XXX-XXX`.

:::


Per attivare l'opzione IAM, esegui questa chiamata API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/enable"} />


#### Verificare che IAM sia attivato

Per controllare l'attivazione di IAM, esegui questa chiamata API:

<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\{serviceName\}/iam"} />

Risposta dell'API:

```shell
{
  "state": "enabled",
  "identityProviderId": 275
}
```

### Disattivare IAM

Puoi disattivare OVHcloud IAM sul tuo Hosted Private Cloud.

#### Dalla console OVHcloud

Seleziona la tua infrastruttura, quindi accedi alla scheda <code className="action">Utenti</code>.

Nella sezione **OVHcloud IAM** in fondo alla scheda, clicca su <code className="action">Disattiva OVHcloud IAM</code>. Nella finestra **Disattivare IAM OVHcloud** che si apre, clicca su <code className="action">Confermare</code>.

#### Tramite l'API OVHcloud

Per disattivare l'opzione IAM, esegui questa chiamata API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/disable"} />
