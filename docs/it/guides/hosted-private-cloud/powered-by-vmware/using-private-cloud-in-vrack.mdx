## Obiettivo

La vRack è la possibilità di connettere diversi servizi Cloud di OVHcloud all'interno di una o più reti private sicure (VLAN).

**Questa guida ti mostra come attivarlo**

## Prerequisiti

- Avere un servizio [vRack](/links/network/vrack) sul tuo account o ordinarne uno se necessario.
- Essere contatto amministratore dell'infrastruttura [Hosted Private Cloud](/links/hosted-private-cloud/enterprise) per ricevere le credenziali di accesso.
- Avere un utente attivo creato nella <ManagerLink console to="/">console OVHcloud</ManagerLink>.

[[cpnav:network-vrack-console]]

## Procedura

### Console OVHcloud

Al momento della consegna del servizio [Hosted Private Cloud](/links/hosted-private-cloud/enterprise), la sezione *datacenter* è già all'interno di una vRack. Per visualizzarne il contenuto nella console OVHcloud, accedi a **Rete** › <code className="action">vRack</code>, seleziona la tua vRack dall'elenco e apri la scheda <code className="action">Servizi associati</code>.

È possibile spostare il *datacenter* del tuo Hosted Private Cloud in un'altra vRack: nella sua riga **Private Cloud Datacenter**, clicca su <code className="action">Sposta</code>. Nella finestra **Sposta da un datacenter Private Cloud**, seleziona la **vRack di destinazione** e clicca su <code className="action">Sposta</code>. Questa operazione comporta un'interruzione del servizio di circa 5 minuti.

### Client vSphere

Nel client vSphere, le *VLANs* compatibili con la vRack sono disponibili nello switch virtuale distribuito (vds), a sua volta situato nella cartella **vrack**.

:::tip
Di default, OVHcloud fornisce un'infrastruttura con 11 VLAN (da VLAN10 a VLAN20).

:::


<img className="thumbnail" alt="VLAN" src="/images/hosted-private-cloud/powered-by-vmware/using-private-cloud-in-vrack/vRackVsphere.png" loading="lazy" />

È possibile modificare le impostazioni o crearne di nuove seguendo la guida alla [creazione di VLAN](/guides/hosted-private-cloud/powered-by-vmware/create-vlan).

Questi *portgroup* possono essere assegnati alle interfacce di rete delle macchine virtuali.
