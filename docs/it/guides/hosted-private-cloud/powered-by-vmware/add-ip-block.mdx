## Obiettivo

Un blocco IP può essere utilizzato per rendere i tuoi servizi accessibili su Internet.

**Questa guida ti mostra come ordinare, aggiungere e migrare un blocco IP associato al tuo Hosted Private Cloud.**

## Prerequisiti

- Essere contatto amministratore dell'infrastruttura [Hosted Private Cloud](https://www.ovhcloud.com/it/enterprise/products/hosted-private-cloud/) per ricevere le credenziali di accesso.
- Avere un utente attivo (creato nella <ManagerLink console to="/">console OVHcloud</ManagerLink>)

[[cpnav:network-public-ip-console]]

## Procedura

### Ordinare un blocco IP

Per ordinare un blocco IP aggiuntivo per il tuo **Hosted Private Cloud**, apri il tuo servizio nella console OVHcloud (**Private Cloud** › **Managed VMware vSphere**, poi il tuo servizio). Nella scheda **Dashboard**, sezione **Opzioni**, apri il menu ⋮ della riga **Numero di blocchi IP** e clicca su <code className="action">Ordina blocchi IP</code>. La stessa pagina di ordine è accessibile anche da **Rete** › **Indirizzi IP**: clicca su <code className="action">Ordina un IP</code>, poi su <code className="action">Ordina un'Additional IP</code>.

Nella pagina **Ordina un IP**, compila le seguenti sezioni per creare il tuo blocco IP:

- **Seleziona il tipo di indirizzo IP**: scegli **IPv4**.
- **Seleziona il servizio a cui assegnare l'IP aggiuntivo**: seleziona il tuo servizio **Hosted Private Cloud**. La regione viene poi determinata automaticamente in base al servizio selezionato.
- **Seleziona un'offerta**: scegli la dimensione del blocco IP (da /28 a /24).

:::info
Ecco una tabella con il riepilogo dei numeri di IP presenti in un blocco e il numero di IP utilizzabili.

:::


|Dimensione del blocco|IP nel blocco|IP utilizzabili in OVHcloud|
|:---:|:---:|:---:|
|28|16|11|
|27|32|27|
|26|64|59|
|25|128|123|
|24|256|251|

:::info
Per conoscere gli indirizzi IP riservati al tuo blocco e il relativo utilizzo, consulta la nostra guida sul [plugin OVHcloud Network](/guides/hosted-private-cloud/powered-by-vmware/plugin-ovh-network).

:::

- **Seleziona una geolocalizzazione**: scegli il Paese del blocco IP, importante in alcuni casi per il posizionamento dei tuoi servizi (un sito italiano avrà un SEO migliore in Italia se anche l’IP è italiano).

Il nome e la descrizione della rete visibili nel whois del blocco IP non vengono richiesti al momento dell’ordine: puoi modificare il nome della rete dalla pagina **Indirizzi IP** una volta consegnato il blocco.

:::tip
Prima della consegna, pagherai le spese di attivazione del tuo blocco IP.

:::

Verifica il **Riepilogo**, poi clicca su <code className="action">Ordinare</code>. Il buono d’ordine del tuo blocco IP si apre in una nuova scheda. Se il buono d’ordine è corretto, non ti resta che procedere al pagamento con uno dei metodi proposti per ricevere il blocco.

### Migrare un blocco IP tra due Hosted Private Cloud

<iframe className="video" width="560" height="315" src="https://www.youtube-nocookie.com/embed/Gemao3Fd7rI" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen={true}></iframe>

Per migrare un blocco IP è necessario spostare manualmente i blocchi tramite l’APIv6 OVHcloud.

Utilizza la seguente chiamata API:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/move"} />

Completa i campi nel modo seguente:

- ip:blocco IP con /Mask
- nexthop « newPrimaryIp » (sensibile alle maiuscole)
- to: Hosted Private Cloud di destinazione in formato pcc-XXX-XXX-XXX-XXX

Il risultato sarà di questo tipo:

```json
{
  "function": "genericMoveFloatingIp",
  "status": "todo",
  "taskId": 178970672
}
```

Se, in seguito, devi scollegare il blocco IP, puoi utilizzare questa chiamata API per spostare l’IP nel Parking degli IP. 

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/park"} />


:::warning
Questa chiamata interrompe la rete sulle VM che utilizzano gli IP in questione.

:::


Puoi anche spostare il blocco dalla console OVHcloud: nella scheda **Dashboard** del tuo servizio, sezione **Opzioni**, apri il menu ⋮ della riga **Numero di blocchi IP** e clicca su <code className="action">Associa blocchi IP a un altro servizio</code>.

È possibile seguire la migrazione del blocco IP nella sezione **Managed VMware vSphere**. Clicca sul tuo servizio Hosted Private Cloud, quindi sulla scheda <code className="action">Operazioni</code>.

Il riferimento dell’operazione è `removeIpRipeBlock`.

L’IP viene poi mostrato nella lista **Indirizzi IP** (**Rete** › **Indirizzi IP**) con il tipo **IP Parking**.
