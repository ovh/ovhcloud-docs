## Startup Program OVHcloud

Lo [Startup Program OVHcloud](/links/transversal/startup-program) aiuta le startup a costruire e scalare la propria infrastruttura server su OVHcloud. Una volta accettata la candidatura e firmato il contratto, riceverete crediti gratuiti validi 12 mesi, e i nostri Startup Program Manager vi accompagneranno per tutta la durata del programma.

In qualità di membri dello Startup Program, potete:

- Pagare i prodotti idonei con i vostri crediti, come Public Cloud e Hosted Private Cloud
- Richiedere consulenze tecniche per valutare e far evolvere la vostra infrastruttura
- Contattare uno Startup Program Manager per ricevere consigli in ogni fase
- Incontrare i nostri team agli eventi dedicati alle startup
