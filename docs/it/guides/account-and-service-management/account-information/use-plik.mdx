## Obiettivo

Il tool online [Plik](https://plik.ovhcloud.com) permette di condividere file tra diverse persone, offrendo opzioni di sicurezza di accesso a questi file.

**Questa guida ti mostra come utilizzare il tool online Plik per condividere file.**

## Prerequisiti

- Disporre di un [account OVHcloud attivo](/guides/account-and-service-management/account-information/ovhcloud-account-creation)

## Procedura

### Accedi con il tuo account OVHcloud

Per trasferire file, devi accedere a Plik con il tuo account OVHcloud.

Accedi allo <ManagerLink to="/">Spazio Cliente OVHcloud</ManagerLink>.

:::info
Se hai attivato la [doppia autenticazione](/guides/account-and-service-management/account-information/secure-ovhcloud-account-with-2fa) sul tuo account, inserisci anche il codice fornito con il metodo di autenticazione definito sul tuo account.
:::

Vai al [sito web di Plik](https://plik.ovhcloud.com).

Clicca su <code className="action">Authentication</code> in alto a destra.

Clicca su <code className="action">Login with OVH</code>.

![Pagina di accesso di Plik con il pulsante Login with OVH evidenziato](/images/account-and-service-management/account-information/use-plik/plik01.png)

Clicca su <code className="action">Continua</code>.

![Pagina OVHcloud che mostra l'account con cui hai effettuato l'accesso](/images/account-and-service-management/account-information/use-plik/plik02.png)

Clicca su <code className="action">Autorizza</code>.

![Pagina di autorizzazione OVHcloud che richiede l'accesso di Plik al tuo account](/images/account-and-service-management/account-information/use-plik/plik03.png)


### Trasferisci file

Una volta connesso, clicca sulla parola <code className="action">Plik</code> in alto a sinistra per accedere al menu di aggiunta dei file.

Clicca su <code className="action">Add files</code> e seleziona il file da aggiungere o effettua un "drag&drop" dei tuoi file.

:::info
La dimensione dei file è limitata a 10 GB.
:::


![Pagina di trasferimento di Plik con le opzioni e il pulsante Add files](/images/account-and-service-management/account-information/use-plik/plik04.png)

Sono disponibili diverse opzioni per configurare i tuoi trasferimenti:

- `Destruct after the first download` - L'opzione elimina il tuo file trasmesso dopo il primo download.
- `Streaming` - Il file non sarà archiviato sul server. Invece, il trasferimento di file inizia quando l'utente remoto inizia il download.
- `Removable` - Permette agli utenti finali di eliminare il file trasmesso.
- `Password` - Proteggi il tuo trasferimento inserendo un identificativo e una password che l'utente remoto dovrà inserire.
- `Comments` - Aggiungi commenti al download. Il linguaggio *markdown* è supportato.
- `Files will be automatically removed in` - Scegli il numero di giorni (massimo 30), di ore o di minuti dopo i quali desideri che i tuoi file trasferiti siano cancellati automaticamente.

:::info
Quando proteggi il tuo trasferimento tramite una password, il nome utente predefinito è "plik".
:::


Dopo aver aggiunto i tuoi file e selezionato le opzioni, clicca sul pulsante <code className="action">Upload</code> verde sul lato sinistro. Questa operazione aprirà una nuova pagina con i file associati.

![Pagina di trasferimento di Plik con un file aggiunto e il pulsante Upload](/images/account-and-service-management/account-information/use-plik/plik05.png)

Le opzioni di download sono disponibili

### Scarica file

Sulla pagina di download sono disponibili nuove opzioni:

- `Zip archive` - Inserisce tutti i file che hai trasmesso in una cartella compressa.
- `Add files` - Ti permette di aggiungere altri file.
- `Delete` - Elimina tutti i file preventivamente trasmessi.

Per rimuovere file, clicca sul pulsante <code className="action">X</code> in corrispondenza di ciascun file.

![Pagina di download di Plik con il QR code, il link e le opzioni](/images/account-and-service-management/account-information/use-plik/plik06.png)

Per consentire ad altre persone di scaricare i tuoi file, fornisci loro il link al singolo file che si trova sotto il nome del file.<br/>
Puoi anche fornire il link a tutti i file della sessione condividendo l'URL situato nella barra degli indirizzi del tuo browser.<br/>
Puoi anche condividere il QR code situato a sinistra. Se hai caricato più file, il QR code permetterà di scaricare ciascun file.

### Opzioni dell'account

Clicca sul tuo identificativo in alto a destra per accedere alle opzioni dell'account.

![Opzioni dell'account Plik con l'elenco dei trasferimenti e i pulsanti di gestione](/images/account-and-service-management/account-information/use-plik/plik07.png)

Tramite questo menu, puoi disconnetterti, generare token per utilizzare il tool Plik da riga di comando, eliminare ogni singolo trasferimento (tramite il pulsante <code className="action">Remove</code> situato a destra di ogni singolo trasferimento) o eliminarli tutti (tramite il pulsante <code className="action">DELETE UPLOADS</code>).
