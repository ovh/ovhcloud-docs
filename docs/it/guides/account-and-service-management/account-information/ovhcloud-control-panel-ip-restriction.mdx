## Obiettivo

OVHcloud mette a tua disposizione opzioni per rafforzare la sicurezza della tua console OVHcloud e dei tuoi servizi.

In particolare, è possibile limitare a determinati indirizzi IP l'accesso alla tua <ManagerLink console to="/#/">console OVHcloud</ManagerLink>.
L'attivazione di questa opzione, associata alla protezione del tuo account con una [doppia autenticazione](/guides/account-and-service-management/account-information/secure-ovhcloud-account-with-2fa), permette di proteggere in modo ottimale la tua console OVHcloud contro eventuali tentativi di intrusione.

**Questa guida ti mostra come proteggere il tuo account OVHcloud limitando gli indirizzi IP autorizzati ad accedervi**

:::warning
La restrizione degli accessi tramite IP e/o la doppia autenticazione proteggono solo l'accesso alla console OVHcloud dalla quale è possibile ordinare, gestire, rinnovare o eliminare i servizi OVHcloud. Queste opzioni non proteggono i tuoi servizi in sé, per i quali è necessario adottare misure di sicurezza specifiche.

:::


## Prerequisiti
  
- Aver letto le [raccomandazioni sulla gestione della password di accesso al tuo account](/guides/account-and-service-management/account-information/manage-ovh-password).

## Procedura

### Step 1 - Recuperare gli indirizzi IP pubblici autorizzati ad accedere alla tua console OVHcloud

Esistono due tipi di indirizzi IP:

- **Gli indirizzi IP pubblici**: sono visibili su tutta la rete Internet, che vengono utilizzate, ad esempio, dal vostro punto di accesso/box Internet per avere un indirizzo su Internet per accedere all'intera rete.
- **Gli indirizzi IP privati**: invisibili e inutilizzabili sulla rete Internet, sono allocate in una rete locale. Per citare il nostro esempio, il tuo box Internet assegnerà un indirizzo IP privato a ogni dispositivo (computer, smartphone, tablet,...) collegato ad esso. Il tuo punto di accesso/box Internet permette così a questi dispositivi di utilizzare il suo IP pubblico per accedere a Internet. Questi indirizzi IP sono facilmente riconoscibili perché iniziano generalmente con 10.0.X.X, 172.16.X.X o 192.168.X.X (dove le X sono tra 0 e 255).

Per utilizzare l'opzione di restrizione IP della console OVHcloud è necessario inserire **solo** il tuo indirizzo IP pubblico.

Per recuperare l'indirizzo IP pubblico di un dispositivo che sarà autorizzato ad accedere alla tua console OVHcloud, accedi al sito [whatismyip.com](https://www.whatismyip.com/) (non gestito da OVHcloud).

Annota l'indirizzo IP che appare e ripeti l'operazione per ogni dispositivo che sarà autorizzato ad accedere alla tua console OVHcloud.

Se utilizzi una rete 4G/5G in aggiunta, ricordati di recuperare anche l'indirizzo IP di questa(e) rete(e).

:::warning
La maggior parte dei provider Internet (ISP) assegna un indirizzo IP **dinamico** al tuo punto di accesso Internet/box. Questi indirizzi IP dinamici cambiano al riavvio del tuo box o ogni 24/48 ore. Tuttavia, alcuni provider possono assegnarti indirizzi IP **fissi** su richiesta.

Per una connessione in 3G/4G/5G, gli indirizzi IP sono sistematicamente **dinamici**.

**Prima** di impostare una restrizione IP sulla tua console OVHcloud, verifica presso il tuo Provider che gli indirizzi IP recuperati in precedenza siano effettivamente IP **fissi**. In caso contrario, potresti perdere rapidamente l'accesso alla console OVHcloud dichiarando un IP dinamico.

:::


### Step 2 - Attiva una restrizione di accesso per IP

Accedi alla scheda <ManagerLink console to="/#/customer/account/security-and-login/ip-restrictions">Restrizioni IP</ManagerLink> della pagina **Sicurezza e accesso**. Puoi accedervi anche dal menu laterale: apri <code className="action">Il mio account</code> > <code className="action">Sicurezza e accesso</code>, poi clicca sulla scheda <code className="action">Restrizioni IP</code>.

<img className="thumbnail" alt="Voce Sicurezza e accesso del menu laterale e scheda Restrizioni IP" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/security-login-ip-tab.png" loading="lazy" />

#### Presentazione dell'interfaccia

<img className="thumbnail" alt="Sezioni Regola predefinita e IP configurati della scheda Restrizioni IP" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/ip-restrictions-overview.png" loading="lazy" />

Per l'implementazione delle restrizioni IP sono presenti due sezioni:

- **Regola predefinita**. Il campo **Quando l’IP non è nell’elenco** permette di:
    - rifiutare l'accesso a tutti gli indirizzi IP tranne quelli precedentemente dichiarati come **autorizzati** nella seconda sezione, **IP configurati**.
    - autorizzare l'accesso a tutti gli indirizzi IP tranne quelli precedentemente dichiarati come **negati** nella seconda sezione, **IP configurati**.
    > Seleziona la casella **Avvisami via e-mail** per ricevere una notifica al tuo indirizzo email di contatto quando viene effettuato un tentativo di connessione non autorizzato per accedere alla tua console OVHcloud.

- **IP configurati**. Questa sezione permette di dichiarare gli indirizzi IP soggetti a restrizione o autorizzazione di accesso e di visualizzare le regole impostate in precedenza.

:::danger
Attenzione prima di proseguire.

Nella sezione **Regola predefinita**, non salvare **mai** la regola predefinita con <code className="action">Nega l’accesso</code> selezionato **senza aver prima autorizzato** almeno uno dei tuoi indirizzi IP pubblici nella sezione **IP configurati**.

In caso contrario, bloccherai **assolutamente tutti gli IP pubblici (inclusi i tuoi)** senza alcuna eccezione. Nessuno avrà più accesso alla tua <ManagerLink console to="/#/">console OVHcloud</ManagerLink> e dovrai effettuare una procedura amministrativa per sbloccare la tua situazione.

Finché nessun indirizzo IP è autorizzato, la console OVHcloud non ti permette di salvare questa regola predefinita. Assicurati che gli indirizzi autorizzati includano il tuo.

Prestare la massima attenzione su questo punto.

:::


#### Rifiuta tutti gli indirizzi IP ad eccezione degli indirizzi legittimi

Per autorizzare l'accesso alla console OVHcloud esclusivamente a uno o più indirizzi IP legittimi, clicca sul pulsante <code className="action">Aggiungi un IP</code> nella sezione **IP configurati**.

> Negli screenshot seguenti, sostituisci l'IP **203.0.113.0/24** con un IP che ti riguarda.

<img className="thumbnail" alt="Finestra Aggiungi un IP con la regola Consenti l’accesso selezionata" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/add-an-ip-allow.png" loading="lazy" />

Nella finestra **Aggiungi un IP**, inserisci l'indirizzo IP pubblico che vuoi autorizzare nel campo **Indirizzo IP** (un indirizzo IPv4 o IPv6, singolo o in blocco). Seleziona la casella **Avvisami via e-mail** per ricevere una notifica via email dei tentativi di connessione tramite questo indirizzo IP, poi lascia la **Regola** su <code className="action">Consenti l’accesso</code>.

Clicca su <code className="action">Aggiungi</code>. La regola dovrebbe quindi apparire nella sezione **IP configurati**.

:::info
**Prima** di proseguire con le azioni descritte in questo step, ripeti l'operazione per tutti gli altri indirizzi IP che vuoi autorizzare ad accedere alla tua console OVHcloud.

:::

Una volta inseriti **tutti** i tuoi indirizzi IP pubblici nella sezione **IP configurati**, seleziona <code className="action">Nega l’accesso</code> nel campo **Quando l’IP non è nell’elenco** della sezione **Regola predefinita**. Seleziona la casella **Avvisami via e-mail** per ricevere una notifica via email dei tentativi di connessione, poi clicca su <code className="action">Salva</code>.

> Da questo momento, **solo** gli indirizzi IP pubblici autorizzati precedentemente nella sezione **IP configurati** possono accedere alla tua console OVHcloud.

#### Autorizza tutti gli indirizzi IP ad eccezione di alcuni indirizzi

Dalla scheda **Restrizioni IP** puoi anche autorizzare tutti gli indirizzi IP ad accedere alla tua console OVHcloud, ad eccezione di alcuni che avrai precedentemente identificato come illegittimi.

Per bloccare l'accesso alla tua console OVHcloud a uno o più indirizzi IP, clicca sul pulsante <code className="action">Aggiungi un IP</code> nella sezione **IP configurati**.

<img className="thumbnail" alt="Finestra Aggiungi un IP con un indirizzo IP inserito e la regola Nega l’accesso" src="/images/account-and-service-management/account-information/ovhcloud-control-panel-ip-restriction/console/add-an-ip-deny.png" loading="lazy" />

Nella finestra **Aggiungi un IP**, inserisci l'indirizzo IP pubblico che vuoi bloccare nel campo **Indirizzo IP** (un indirizzo IPv4 o IPv6, singolo o in blocco). Seleziona la casella **Avvisami via e-mail** per ricevere una notifica via email dei tentativi di connessione tramite questo indirizzo IP, poi imposta la **Regola** su <code className="action">Nega l’accesso</code>.

Clicca su <code className="action">Aggiungi</code>. La regola dovrebbe quindi apparire nella sezione **IP configurati**.

:::info
**Prima** di continuare con le azioni descritte in questo step, ripeti l'operazione per tutti gli altri indirizzi IP di cui vuoi bloccare l'accesso alla tua console OVHcloud.

:::


Una volta inseriti tutti gli indirizzi IP pubblici nella sezione **IP configurati**, seleziona <code className="action">Consenti l’accesso</code> nel campo **Quando l’IP non è nell’elenco** della sezione **Regola predefinita**. Seleziona la casella **Avvisami via e-mail** per ricevere una notifica via email dei tentativi di connessione, poi clicca su <code className="action">Salva</code>.

> Da questo momento, **tutti** gli indirizzi IP pubblici possono accedere alla tua console OVHcloud, **ad eccezione di** quelli dichiarati nella sezione **IP configurati**.
