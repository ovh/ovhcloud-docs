## Obiettivo

La creazione di un progetto è il primo passo nella distribuzione delle [istanze Public Cloud](/links/public-cloud/public-cloud).

**Questa guida ti guiderà attraverso i passi della creazione del tuo primo progetto di Public Cloud.**

## Procedura

### Creazione del progetto

I primi passaggi dipendono dal fatto che tu abbia già o meno un progetto Public Cloud:

- **Si tratta del tuo primo progetto Public Cloud:** la console OVHcloud apre la pagina **Benvenuto nell'ecosistema Public Cloud**. Dopo averne preso visione, accetta i termini dei contratti selezionando la casella corrispondente nella sezione **Contratti**, quindi clicca su <code className="action">Scopri l'universo Public Cloud</code>. Il progetto viene creato in [Modalità Discovery](#discovery).
- **Hai già un progetto Public Cloud:** nella pagina **Progetti**, clicca su <code className="action">Crea un nuovo progetto</code>. Puoi anche cliccare sul selettore <code className="action">Progetto</code> in alto nel menu a sinistra, quindi su <code className="action">Crea un progetto</code>. Nella pagina **Creare un progetto Public Cloud**:
    1. Nel campo **Nome del progetto**, inserisci un nome per il progetto.
    2. Dopo averne preso visione, accetta i termini dei contratti selezionando la casella corrispondente nella sezione **Contratti**.
    3. Nella sezione **Verifica la tua identità con un metodo di pagamento**, seleziona il metodo di pagamento. Se disponi di un voucher, inseriscilo nella sezione **Hai un codice promozionale?** e clicca su <code className="action">Aggiungere</code>.
    4. Clicca su <code className="action">Crea il tuo progetto</code>.

La Modalità Discovery non è disponibile per alcuni account: anche il loro primo progetto viene creato dalla pagina **Creare un progetto Public Cloud**.

Una volta completato il processo di creazione, il nuovo progetto Public Cloud viene visualizzato nel selettore **Progetto** in alto nel menu a sinistra dell'universo Public Cloud.

Da questo momento hai accesso a tutto l'ecosistema Public Cloud OVHcloud. Scopri questa nuova interfaccia consultando la nostra guida "[Scopri l'interfaccia Public Cloud](/guides/public-cloud/cross-functional/public-cloud-interface-walk-me)".

<a name="discovery"></a>

:::info
**Modalità Discovery**

Il tuo primo progetto Public Cloud viene creato in `Modalità Discovery`. Questo significa che puoi sfogliare e scoprire i prodotti Public Cloud ma non puoi ancora creare risorse come le istanze. Finché questo progetto è in Modalità Discovery, non puoi nemmeno creare un altro progetto: la console OVHcloud ti chiede prima di attivarlo.

Per sfruttare appieno il potenziale del Public Cloud e avviare le prime risorse, attiva il tuo progetto:

1. Nella home page del progetto, il banner **Avvia il deploy delle tue risorse Cloud.** ti ricorda che sei in Modalità Discovery. Clicca su <code className="action">Attivare</code> in questo banner.
2. Nella finestra che si apre, clicca su <code className="action">Attivare il tuo progetto</code>.
3. Nella pagina **Attivare il tuo progetto**, convalida un metodo di pagamento, quindi clicca su <code className="action">Attivare il tuo progetto</code>.

### Attivazione del progetto e prova gratuita

Quando attivi un progetto dalla `Modalità Discovery` e registri un metodo di pagamento, viene applicato un **credito di prova di 200 €** se sei idoneo. In questo caso, il banner della home page del progetto e la pagina **Attivare il tuo progetto** mostrano l'importo dell'offerta.

:::info
**Condizioni della prova gratuita**

- Il credito viene attivato al momento dell'attivazione del progetto ed è valido **un mese**.
- **Idoneo:** qualsiasi cliente OVHcloud che crea il suo primo progetto Public Cloud, anche se dispone già di un account OVHcloud.
- **Non idoneo:** i clienti che dispongono già o hanno già disposto di un progetto Public Cloud, oppure che hanno già beneficiato di un credito di prova gratuita.

Per saperne di più, consulta la pagina [Prova gratuita Public Cloud OVHcloud](/links/public-cloud/free-trial).
:::

:::info
**Creare progetti aggiuntivi con Terraform**

Una volta creato il tuo primo progetto Public Cloud e validato un metodo di pagamento, puoi creare altri progetti in modo programmatico con la risorsa Terraform `ovh_cloud_project`. Per maggiori informazioni, consulta la guida [Terraform Tutorial (EN)](/guides/public-cloud/cross-functional/how-to-use-terraform#creating-a-public-cloud-project).

Attualmente non esiste un endpoint API né un comando CLI OVHcloud dedicati alla creazione di progetti.
:::
