## Obiettivo

Se non hai più bisogno di un [progetto Public Cloud](/links/public-cloud/public-cloud), è possibile eliminarlo direttamente dalla <ManagerLink to="/">console OVHcloud</ManagerLink>.

Una volta eliminato un progetto Public Cloud, viene emessa una fattura finale contenente l'importo da saldare.

:::warning
L'eliminazione di un progetto è diversa dalla disattivazione delle istanze Public Cloud.<br/>
Una volta eliminato un progetto, le risorse in esso contenute vengono definitivamente perse. Questa operazione è irreversibile.
:::

**Questa guida ti mostra come eliminare un progetto Public Cloud dalla console OVHcloud.**

## Prerequisiti

- Un [progetto Public Cloud](/links/public-cloud/public-cloud) nel tuo account OVHcloud

[[cpnav:publiccloud-project-settings-console]]

## Procedura

1. Nel menu a sinistra del tuo progetto Public Cloud, clicca su <code className="action">Gestione del progetto</code>.
2. Clicca sulla scheda <code className="action">Impostazioni</code>.
3. Nella sezione **Elimina il progetto**, clicca su <code className="action">Elimina il progetto</code>.
4. La finestra **Annulla progetto** ti informa che tutti i tuoi servizi, risorse, impostazioni e dati verranno distrutti, ad eccezione degli IP failover, che verranno parcheggiati. Clicca su <code className="action">Sì, disattiva</code> per continuare.

:::info
Un progetto con un Savings Plan non può essere eliminato: la sezione **Elimina il progetto** mostra un avviso e la finestra propone invece <code className="action">Contattare il servizio clienti</code>. Contatta i nostri team di assistenza per eliminare questo progetto.
:::

Riceverai quindi un'email all'indirizzo di contatto per confermare o annullare la rimozione del progetto.

Una volta cliccato sul link di conferma visualizzato in questa email, verrai reindirizzato verso una pagina Web in cui sarà necessario inserire la password del tuo account.

Una volta inserita e confermata la password, il progetto entrerà nella fase di cancellazione.

:::warning
Ti ricordiamo che, quando un progetto entra in questa fase di cancellazione, rimane in stato di sospensione per 7 giorni. Il progetto non viene quindi immediatamente eliminato. Se questa situazione ti colpisce, ad esempio se la tua quota di progetti è limitata, contatta i nostri team di assistenza.

:::
