## Obiettivo

A differenza delle istanze Windows create con un Basic IP, le istanze Windows create senza Basic IP (connesse unicamente a una rete privata) non hanno le licenze Windows attivate automaticamente.
In questo caso, dovete attivare la licenza manualmente per avere accesso a tutti i servizi Windows.

**Questa guida vi accompagna nella configurazione dell'interfaccia pubblica delle vostre istanze Public Cloud all'interno della vostra vRack.**

## Prerequisiti

- Disporre di un [progetto Public Cloud](/guides/public-cloud/cross-functional/create-a-public-cloud-project) nel vostro account OVHcloud
- [Aver creato un utente OpenStack](/guides/public-cloud/cross-functional/create-and-delete-a-user)

Per familiarizzare con Horizon, consultate la guida [Accedere all'interfaccia Horizon](/guides/public-cloud/cross-functional/introducing-horizon).

#### Attivare il vostro sistema Windows

Per attivare il vostro sistema Windows, dovete passare per Powershell.

Una volta connessi alla vostra istanza Windows, fate clic con il tasto destro sul menu <code className="action">Start</code> e selezionate <code className="action">Windows PowerShell</code>.

Inserite questo comando:

```bash
slmgr.vbs -ato
```

<img className="thumbnail" alt="attivazione chiave windows" src="/images/public-cloud/compute/activate-windows-license-private-mode/windowsactivation1.png" loading="lazy" />

La licenza Windows verrà attivata per 180 giorni.

Questa operazione dovrà essere ripetuta ogni 180 giorni.

:::info
Nel frattempo, per isolare la vostra istanza dalla rete pubblica, potete disattivare la porta pubblica creata tramite Horizon o l'API OpenStack.
Potete anche disattivare direttamente la porta di rete via Windows.

:::


Per verificare lo stato della licenza e la data di scadenza, utilizzate questo comando:

```bash
slmgr.vbs -dli
```
