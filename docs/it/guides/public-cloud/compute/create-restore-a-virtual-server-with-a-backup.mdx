## Obiettivo

La console OVHcloud ti permette di creare gli [snapshot delle tue istanze](/guides/public-cloud/compute/save-an-instance) in pochi click e di automatizzare questo processo.
Potresti dover ripristinare la tua istanza tramite uno snapshot, ad esempio in caso di operazione errata sulla sua configurazione. Puoi utilizzare questi snapshot di istanze per due ragioni principali:

- Creare un'istanza a partire dallo snapshot per duplicare l'istanza di origine, ad esempio se configuri un'infrastruttura di load balancing.
- Ripristinare un'istanza a partire da uno snapshot, ad esempio se modifiche recenti hanno compromesso configurazioni critiche dell'istanza.

**Scopri come utilizzare i tuoi snapshot per duplicare o ripristinare le tue istanze.**

## Prerequisiti

- Disporre di [uno snapshot di un'istanza Public Cloud](/links/public-cloud/instance-backup). A questo proposito, consulta [la guida dedicata alla creazione di uno snapshot](/guides/public-cloud/compute/save-an-instance).

[[cpnav:publiccloud-instance-backup-console]]

## Procedura

:::info
Sono disponibili due tipi di snapshot:

- Locale: memorizzato nella stessa regione della tua istanza.
- Remoto: replicato automaticamente in un'altra regione a tua scelta.

Le operazioni di **creazione** e **ripristino** di un’istanza da uno snapshot remoto sono totalmente supportate tramite l’API OVHcloud, offrendo una maggiore flessibilità e un'integrazione semplificata nei tuoi processi di automazione.

**Nota:** Nella console OVHcloud puoi creare un'istanza a partire da qualsiasi snapshot elencato nella pagina **Snapshot delle istanze**, ma puoi ripristinare un'istanza esistente solo a partire da uno snapshot archiviato nella sua stessa regione.

:::


### Creare un'istanza a partire da uno snapshot

<Tabs>
  <Tab label="Console OVHcloud">
    Nel menu a sinistra del tuo progetto Public Cloud, clicca su <code className="action">Instance Snapshot</code> sotto **Compute**. La pagina **Snapshot delle istanze** elenca i tuoi snapshot.

    Clicca sul pulsante <code className="action">...</code> nella riga dello snapshot scelto, quindi seleziona <code className="action">Crea un'istanza</code>.

    Si apre la pagina **Crea un'istanza** con alcuni elementi predefiniti:

    - **Localizzazione**: La tua istanza verrà creata nella stessa regione del tuo snapshot. La regione è determinata dallo snapshot e non può essere modificata.
    - **Immagine**: Lo snapshot è preselezionato nella scheda <code className="action">Snapshot</code> della sezione **Seleziona un'immagine**.
    - **Modello**: Saranno disponibili solo i modelli che possono ospitare la tua immagine, in base alla tua quota.

    Definisci il nome della nuova istanza, la chiave SSH, i parametri di rete e di fatturazione, quindi clicca sul pulsante <code className="action">Crea la mia istanza</code>.

    Per ulteriori informazioni sulla creazione di un'istanza, consulta [questa guida](/guides/public-cloud/compute/getting-started).

    :::info
    Per creare un'istanza in un data center diverso da quello dello snapshot, sarà necessario trasferire lo snapshot nella zona corrispondente. Consulta quindi la [guida sul trasferimento del backup di un'istanza da un data center a un altro](/guides/public-cloud/compute/transfer-instance-backup-from-one-datacentre-to-another).

    :::

  </Tab>
  <Tab label="API OVHcloud">
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/instance"} />

Compila le variabili:
    
    - **serviceName** : L'ID del progetto OVHcloud.
    - **regionName** : Il nome della regione dove verrà creata l'istanza.
    
    Esempio del corpo della richiesta:
    
    ```json
    {
      "billingPeriod": "hourly",
      "bootFrom": {
        "imageId": "5cb8ea68-****-****-****-820be8346***"
      },
      "flavor": {
        "id": "e81b46f8-****-****-****-cad655e65***"
      },
      "name": "newInstance",
      "network": {
        "public": true
      },
      "sshKey": {
        "name": "MySSHKey"
      }
    }
    ```
  </Tab>
  <Tab label="CLI OpenStack">
    Per creare un'istanza a partire dal tuo snapshot, utilizza l'ID dello snapshot come immagine con questo comando:
    
    ```bash
    $ openstack server create --key-name SSHKEY --flavor 98c1e679-5f2c-4069-b4da-4a4f7179b758 --image 0a3f5901-2314-438a-a7af-ae984dcbce5c Server1_from_snap
    ```
  </Tab>
  <Tab label="Horizon">
    Nell'interfaccia Horizon, clicca su <code className="action">Compute</code> nel menu a sinistra, quindi su <code className="action">Images</code>. Cerca l'immagine desiderata e clicca sul pulsante <code className="action">Launch</code> a destra della riga della tua immagine.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon1.png" loading="lazy" />

Assegna un nome alla tua istanza nel campo dedicato e determina il numero di istanze da creare. Poi clicca sulla scheda <code className="action">Flavor</code>.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-2" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon2.png" loading="lazy" />

Seleziona il modello di istanza desiderato, quindi clicca sulla scheda <code className="action">Networks</code>.
    
    :::warning
    Se la tua istanza è un server Windows, devi selezionare un flavor del tipo win-xx-xx (ad esempio, win-b2-15) e disporre di un'interfaccia pubblica sulla rete Ext-Net. Senza queste condizioni, l'autenticazione presso il KMS OVHcloud non sarà possibile, e il tuo server rimarrà con una [licenza non attivata](/guides/public-cloud/compute/activate-windows-license-private-mode). Questo potrebbe comportare limitazioni, in particolare l'assenza di aggiornamenti. Nota che non è possibile ridimensionare un'istanza Linux (ad esempio b2-15) in un'istanza Windows (come win-b2-15). Per effettuare questa transizione, è necessario creare una nuova istanza.

    :::

    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-3" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon3.png" loading="lazy" />

Seleziona la rete che desideri assegnare, quindi clicca sul pulsante <code className="action">Launch Instance</code>.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-4" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon4.png" loading="lazy" />

Puoi trovare lo stato della tua nuova istanza in <code className="action">Compute</code> nel menu a sinistra, quindi su <code className="action">Instances</code>.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-5" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon5.png" loading="lazy" />
  </Tab>
</Tabs>


### Ripristinare un'istanza a partire da uno snapshot

<Tabs>
  <Tab label="Console OVHcloud">
    Nel menu a sinistra del tuo progetto Public Cloud, clicca su <code className="action">Instances</code> sotto **Compute**, quindi clicca sul nome dell'istanza interessata.

    Nel riquadro **Informazioni generali** della scheda <code className="action">Panoramica</code>, clicca su <code className="action">Modifica immagine</code> nella riga **Immagine**. Si apre il pannello **Modifica immagine**.

    Nella sezione **Seleziona una distribuzione**, seleziona gli snapshot, quindi seleziona lo snapshot da ripristinare nella sezione **Seleziona un'immagine**. Vengono proposti solo gli snapshot archiviati nella regione dell'istanza. Clicca su <code className="action">Modifica immagine</code> se sei certo di voler sostituire l'immagine corrente con lo snapshot.

    L'istanza verrà reinstallata e riavviata fino al completamento del processo.

    :::warning
    Come indicato nel messaggio di avviso, tutti i dati dell'istanza verranno eliminati: non sarà possibile recuperare alcun dato aggiunto dopo la creazione dello snapshot.

    :::

  </Tab>
  <Tab label="API OVHcloud">
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/instance/\\{instanceId\\}/reinstall"} />

Compila le variabili:
    
    - **serviceName** : L'ID del progetto OVHcloud.
    - **regionName** : Il nome della regione dove si trova l'istanza di origine.
    - **instanceId** : L'ID unico dell'istanza.
    
    Esempio del corpo della richiesta:
    
    ```json
    {
      "imageId": "5cb8ea68-****-****-****-820be8346***",
      "imageRegionName": "GRA11"
    }
    ```
  </Tab>
</Tabs>
