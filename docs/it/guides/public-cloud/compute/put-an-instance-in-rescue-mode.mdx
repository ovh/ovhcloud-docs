## Obiettivo

Se non riesci ad accedere alla tua istanza a causa di una configurazione non corretta o perché hai smarrito la tua chiave SSH, puoi accedere ai tuoi dati e correggere i file di configurazione attivando la modalità di ripristino. 

**Questa guida ti mostra come riavviare un’istanza Public Cloud OVHcloud in modalità Rescue e accedere ai tuoi file.**

## Prerequisiti

- Aver creato un’istanza [Public Cloud](/links/public-cloud/compute) nel tuo account OVHcloud

[[cpnav:publiccloud-instances-console]]

## Procedura

:::danger
Ad oggi, la modalità Rescue per le istanze Metal non è disponibile nella console OVHcloud. Per maggiori informazioni, consulta la guida dedicata al [Rescue mode per le istanze Metal](/guides/public-cloud/compute/rescue-mode-metal-instance).
:::


### Attiva la modalità di ripristino

Nel menu a sinistra del tuo progetto Public Cloud, clicca su <code className="action">Instances</code> sotto **Compute**.

Clicca su <code className="action">...</code> a destra dell'istanza e seleziona <code className="action">Riavvia in modalità Rescue</code>.

Nella finestra **Riavvia in modalità rescue**, seleziona dal menu a tendina la distribuzione che vuoi utilizzare in modalità Rescue (la distribuzione rescue OVHcloud è preselezionata), poi clicca sul pulsante <code className="action">Confermare</code>.

Un messaggio conferma che l'istanza si sta riavviando in modalità Rescue.

La tua **password della modalità Rescue** temporanea verrà visualizzata solo nella console VNC. Clicca sull'istanza nella tabella e poi accedi alla scheda <code className="action">Console VNC</code> per recuperarla.

### Accedi ai tuoi dati

In modalità Rescue, i dati della tua istanza sono visibili come un disco aggiuntivo.  Per potervi accedere, è sufficiente configurare il disco seguendo questa procedura:

Accedi alla tua istanza via [SSH](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction). Una volta connesso, verifica i dischi disponibili:

```bash
lsblk
```

Il risultato sarà simile all'output di esempio seguente:

```console
NAME    MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
sda       8:0    0  2.9G  0 disk
└─sda1    8:1    0  2.9G  0 part /
sdb       8:16   0   25G  0 disk
├─sdb1    8:17   0   24G  0 part
├─sdb14   8:30   0    4M  0 part
├─sdb15   8:31   0  106M  0 part
└─sdb16 259:0    0  913M  0 part
```

In modalità Rescue, `sda` è il disco in modalità Rescue e `sda1` è la partizione di soccorso principale montata su `/`.

In questo esempio, il disco principale è `sdb` e la partizione di sistema è `sdb1` (indicata dalla dimensione).

Monta questa partizione con questo comando:

```bash
mount /dev/sdb1 /mnt/
```

A questo punto i tuoi dati sono accessibili nella cartella `/mnt`.

### Disattiva la modalità Rescue

Una volta completate queste operazioni, è possibile disattivare la modalità Rescue riavviando l'istanza dalla console OVHcloud. Per farlo, clicca su <code className="action">...</code> nella riga dell'istanza, seleziona <code className="action">Esci dalla modalità Rescue</code> e clicca su <code className="action">Confermare</code> nella finestra che si apre.

:::warning
Se il pulsante <code className="action">Esci dalla modalità Rescue</code> non compare in modalità Rescue, consigliamo di aggiornare la scheda.
:::


### Attiva la modalità Rescue con le API OpenStack

Per riavviare la tua istanza in Rescue mode utilizzando le API OpenStack, esegui questo comando:

```bash
nova rescue INSTANCE_ID
```

Per uscire dalla modalità Rescue, esegui questo comando:

```bash
nova unrescue INSTANCE_ID
```
