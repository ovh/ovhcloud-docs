## Obiettivo

Puoi creare uno snapshot unico di un'istanza o configurare una pianificazione per automatizzare gli snapshot delle tue istanze. Gli snapshot possono essere utilizzati per ripristinare l'istanza a uno stato precedente o per creare una nuova istanza identica.

**Questa guida ti mostra come creare snapshot manuali e automatici di un'istanza Public Cloud.**

## Prerequisiti

- Disporre di un'istanza [Public Cloud](/links/public-cloud/public-cloud) sul proprio account OVHcloud.
- CLI OpenStack. Consulta la nostra guida "[Preparare l’ambiente per utilizzare l’API OpenStack](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment)". (opzionale)

[[cpnav:publiccloud-instances-console]]

## Procedura

### Creare uno snapshot di un'istanza

:::warning
Questa opzione è disponibile solo via **Cold Snapshot** per le istanze Metal. L'istanza Metal passerà in modalità Rescue e, una volta effettuato lo snapshot, l'istanza sarà riavviata in modalità normale.

:::


:::info
Sono disponibili due tipi di snapshot:

- Locale: uno snapshot locale viene archiviato nella stessa regione della tua istanza.
- Remoto: uno snapshot remoto crea automaticamente una copia dello snapshot locale in un'altra regione a tua scelta.

Ogni snapshot è fatturato separatamente. Lo snapshot remoto verrà fatturato in base alla tariffa di archiviazione della regione remota selezionata.

**Nota:** le Local Zones non sono idonee per gli snapshot remoti.

:::

    Puoi elencare tutte le regioni disponibili utilizzando la seguente chiamata API:

Utilizza quindi la seguente chiamata API:
    
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/instance/\\{instanceId\\}/snapshot"} />

Compila le variabili:
    
    - **instanceId**: ID unico dell'istanza desiderata.
    - **regionName**: Nome della regione in cui si trova l'istanza di origine.
    - **serviceName**: ID del progetto OVHcloud.
    - **distantRegionName (opzionale)**: Nome della regione remota dove verrà archiviato lo snapshot remoto.
    - **distantSnapshotName (opzionale)**: Nome dello snapshot remoto da creare nella regione remota.
    - **snapshotName**: Nome dello snapshot locale da creare.
    
    :::info
    Crea uno snapshot remoto solo se i parametri relativi alla regione remota (**distantRegionName** e **distantSnapshotName**) sono compilati.

    :::

### Creare uno snapshot automatico di un'istanza

:::info
Se desideri automatizzare questa funzione direttamente tramite OpenStack, puoi creare un workflow Mistral associato a un cron trigger.

:::


Nel menu a sinistra del tuo progetto Public Cloud, clicca su <code className="action">Instances</code> sotto **Compute**. Clicca sul pulsante <code className="action">...</code> a destra dell'istanza e seleziona <code className="action">Crea uno snapshot automatico</code>.

Si apre la pagina **Aggiungi un intervento programmato**. Puoi configurare questi parametri:

#### **Il workflow** 

La pianificazione crea uno snapshot automatico dell'istanza e del suo volume principale. Non è necessario scegliere alcun tipo di workflow.

#### **La risorsa** 

Nella sezione **Seleziona una risorsa assegnata**, puoi selezionare l'istanza di cui creare uno snapshot.

#### **Il nome** 

Nella sezione **Assegna un nome al tuo intervento programmato**, inserisci un nome per la pianificazione dello snapshot automatico. Consulta le informazioni sui prezzi nel riepilogo a destra, quindi crea la pianificazione cliccando su <code className="action">Crea</code>.

#### **La pianificazione** 

Nella sezione **Definisci le operazioni pianificate**, puoi definire una pianificazione personalizzata (**Personalizzato**, in formato cron UNIX, in UTC) o scegliere una delle frequenze predefinite:

- **Rotazione 7**: snapshot giornaliero con conservazione degli ultimi 7 snapshot
- **Rotazione 14**: snapshot giornaliero con conservazione degli ultimi 14 snapshot

<details>

<summary>**Aggiunta di uno snapshot remoto**</summary>


Attiva <code className="action">Aggiungere uno snapshot remoto</code>, seleziona una località, consulta le informazioni sui prezzi e clicca sul pulsante <code className="action">Crea</code>.

</details>


### Gestione di snapshot e pianificazioni

Le pianificazioni vengono elencate ed eliminate nella pagina **Gestisci workflow**: clicca su <code className="action">Workflow</code> sotto **Compute** nel menu a sinistra.

Gli snapshot delle tue istanze sono gestiti nella pagina **Snapshot delle istanze**: clicca su <code className="action">Instance Snapshot</code> sotto **Compute** nel menu a sinistra.

:::warning
L’opzione di snapshot dell’istanza deve essere eliminata separatamente se non vuoi più che ti venga fatturata. L’eliminazione di un’istanza non comporta l’eliminazione delle opzioni ad essa associate.

:::


:::warning
**Ti ricordiamo che non è possibile eliminare uno snapshot di istanza se un'istanza creata da questo snapshot è in esecuzione al momento dell'eliminazione.**

:::
