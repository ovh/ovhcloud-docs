## Obiettivo

Durante la configurazione di un'infrastruttura ad alta disponibilità, potresti avere bisogno di interrompere l’esecuzione delle tue istanze per effettuare alcuni test. OpenStack ti permette di mettere in Shelve, arrestare (Shutoff), sospendere o mettere in pausa le tue istanze. In ogni caso, il tuo IP viene mantenuto.

:::warning
Nella console OVHcloud sono disponibili solo le azioni **Shelve** / **Unshelve** e **Hard stop** (azione OpenStack *stop*, *Shut Off* in Horizon). **Suspend** / **Resume** e **Pause** / **Unpause** sono disponibili tramite l'API OVHcloud (v2), in Horizon e tramite l'API OpenStack.

:::

**Questa guida ti mostra come mettere in Shelve, arrestare (Hard stop), sospendere o mettere in pausa un'istanza.**

## Prerequisiti

- un'[istanza Public Cloud](/guides/public-cloud/compute/getting-started) con la fatturazione **oraria**
- Avere accesso all’[interfaccia Horizon](/guides/public-cloud/cross-functional/introducing-horizon)
- Conoscenza dell’[API OpenStack](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment) e delle [variabili d’ambiente OpenStack](/guides/public-cloud/cross-functional/compute-set-openstack-environment-variables)

[[cpnav:publiccloud-instances-console]]

## Procedura

:::warning
**Ambito:** Questa guida si applica a tutte le istanze Public Cloud, indipendentemente dal loro modello di fatturazione (oraria o mensile).

**Fatturazione mensile:** per le istanze con fatturazione mensile, il prezzo mensile dell'istanza continua a essere fatturato qualunque sia il suo stato. Un'istanza mensile in Shelve viene fatturata al suo prezzo mensile, più lo snapshot.

**Nota:** Finché l'istanza non viene eliminata, qualsiasi operazione continuerà a generare addebiti per l'istanza.

:::

La tabella qui sotto ti permette di differenziare le opzioni disponibili sulle tue istanze. Prosegui nella lettura di questa guida cliccando sull'opzione che preferisci. Tra parentesi è indicata l'azione OpenStack corrispondente.

|Opzione|Stato della memoria|Dati del disco|Risorse dell'host (CPU/RAM)|Ripresa|Fatturazione|
|---|---|---|---|---|---|
|[Hard stop (*stop*)](#hard-stop-instance)|Perso|Conservati|Ancora allocate sull'host|Avvio a freddo (il sistema operativo si riavvia)|Vieni fatturato alla stessa tariffa.|
|[Shelve (*shelve*)](#shelve-instance)|Perso|Salvati in un'immagine snapshot|Liberate una volta scaricata l'istanza (*offloaded*)|Avvio a freddo dallo snapshot, eventualmente su un altro host|Istanze a ore: viene fatturato solo lo snapshot. Istanze mensili: il prezzo mensile dell'istanza, più lo snapshot.|
|[Pause (*pause*)](#pause-instance)|Conservato nella RAM dell'host|Conservati|Ancora allocate e consumate|Istantanea, esattamente dal punto in cui si era fermata|Vieni fatturato alla stessa tariffa.|
|[Suspend (*suspend*)](#stop-suspend-instance)|Scritto sul disco dell'host|Conservati|RAM/CPU liberate sull'hypervisor, allocazione conservata|Ripristina lo stato salvato, come un'ibernazione|Vieni fatturato alla stessa tariffa.|

In ogni caso, l'indirizzo IP dell'istanza viene conservato.

<a name="shelve-instance"></a>

### Mettere un'istanza in Shelve

:::danger
Si noti che mettere in Shelve un'istanza IOPS o T1/T2-180 comporta la perdita di dati sulle unità NVMe passthrough.

Mettere in Shelve questo tipo di istanza comporta la sua disattivazione dall'host e quindi dai dischi in passthrough.

:::

Questa opzione permette di liberare le risorse dedicate all'istanza Public Cloud, ma l'indirizzo IP resta. I dati del disco locale saranno salvati in uno snapshot creato automaticamente una volta che l'istanza è in Shelve. I dati archiviati nella memoria e altrove non saranno conservati.

<Tabs>
  <Tab label="Console OVHcloud">
    Nel menu a sinistra del tuo progetto Public Cloud, clicca su <code className="action">Instances</code> nella sezione **Compute**.

    Clicca sul pulsante <code className="action">...</code> a destra dell'istanza da mettere in Shelve, poi su <code className="action">Shelve</code>.

    Nella finestra **Metti l'istanza in Shelve**, prendi nota del messaggio e clicca su <code className="action">Confermare</code>.

    Una volta completata l'operazione, lo stato della tua istanza apparirà come **Shelve**.

    Per visualizzare lo snapshot, clicca su <code className="action">Instance Snapshot</code> nella sezione **Compute** del menu a sinistra. Sarà quindi visibile uno snapshot denominato *xxxxx-shelved*.
  </Tab>
  <Tab label="CLI OVHcloud">
    Prima di continuare, si raccomanda di consultare queste guide:

    - [Conoscere le basi della CLI OVHcloud](/guides/manage-and-operate/cli/getting-started)

    Esegui questo comando:

    ```shell
    ovhcloud cloud instance shelve <instance_id>
    ```
  </Tab>
  <Tab label="API OVHcloud">
    Utilizza la seguente chiamata API, dove `projectId` è l'ID del tuo progetto Public Cloud e `instanceId` l'ID dell'istanza:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Con il seguente corpo della richiesta:

    ```json
    {
      "type": "SHELVE"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Prima di continuare, si raccomanda di consultare le seguenti guide:

    - [Preparare l’ambiente per utilizzare l’API OpenStack](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment)
    - [Impostare le variabili d’ambiente OpenStack](/guides/public-cloud/cross-functional/compute-set-openstack-environment-variables)

    Una volta che l'ambiente è pronto, esegui questo comando:

    ```bash
    ~$ openstack server shelve <UUID server>

    =====================================

    ~$ nova shelve <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    Per utilizzare questo metodo, è necessario [connettersi all’interfaccia Horizon](https://horizon.cloud.ovh.net/auth/login/):

    - Per accedere con il Single Sign-On OVHcloud: apri il tuo progetto Public Cloud nella <ManagerLink to="/">console OVHcloud</ManagerLink> e clicca su <code className="action">OpenStack Horizon</code> nel widget **Documentazione e assistenza** della pagina iniziale del progetto.

    - Per accedere con un utente OpenStack specifico: apri la pagina di accesso a [Horizon](https://horizon.cloud.ovh.net/auth/login/) e inserisci le [credenziali OpenStack](/guides/public-cloud/cross-functional/create-and-delete-a-user) precedentemente create, poi clicca su <code className="action">Connect</code>.

    Se hai installato istanze in diverse regioni, assicurati di essere nella localizzazione giusta. Puoi verificarlo nell'angolo superiore sinistro dell'interfaccia Horizon.

    <img className="thumbnail" alt="horizon interface" src="/images/public-cloud/compute/suspend-or-pause-an-instance/firstaccesshorizon.png" loading="lazy" />

    Clicca su <code className="action">Compute</code> nel menu a sinistra e seleziona <code className="action">Istanze</code>. Seleziona <code className="action">Shelve Instance</code> nel menu a tendina dell'istanza.

    <img className="thumbnail" alt="instance shelve" src="/images/public-cloud/compute/suspend-or-pause-an-instance/shelveinstancehorizon.png" loading="lazy" />

    Una volta terminata la procedura, l'istanza apparirà come *Shelved Offloaded*.

    <img className="thumbnail" alt="istanza riservata" src="/images/public-cloud/compute/suspend-or-pause-an-instance/newinstancestatushorizon.png" loading="lazy" />

    Per visualizzare lo snapshot, nel menu <code className="action">Compute</code>, clicca su <code className="action">Images</code>.

    <img className="thumbnail" alt="snapshot" src="/images/public-cloud/compute/suspend-or-pause-an-instance/snapshothorizon.png" loading="lazy" />
  </Tab>
</Tabs>

<a name="unshelve-instance"></a>

### Effettuare l'Unshelve di un'istanza

Questa opzione ti permette di riattivare l'istanza per poterla utilizzare. Ti ricordiamo che, una volta completata l'operazione, la fatturazione riprenderà normalmente.

:::danger
**Azioni sullo snapshot**

Qualsiasi azione sullo snapshot diversa dalla riattivazione (*unshelve*) può essere molto pericolosa per la tua infrastruttura in caso di uso improprio. Quando un'istanza è riattivata (*unshelved*), lo snapshot viene eliminato automaticamente. Non è consigliabile creare una nuova istanza da uno snapshot creato in seguito alla messa in Shelve di un'istanza.

OVHcloud fornisce i servizi di cui sei responsabile. Non avendo accesso a queste macchine, non siamo noi gli amministratori e pertanto non possiamo fornirti alcuna assistenza. È responsabilità dell’utente garantire ogni giorno la gestione e la sicurezza del software. In caso di difficoltà o dubbi relativi ad amministrazione e sicurezza, ti consigliamo di contattare un [fornitore specializzato](/links/partner). Per maggiori informazioni consulta la sezione "Per saperne di più" di questa guida.
:::

<Tabs>
  <Tab label="Console OVHcloud">
    Nel menu a sinistra del tuo progetto Public Cloud, clicca su <code className="action">Instances</code> nella sezione **Compute**.

    Clicca sul pulsante <code className="action">...</code> a destra dell'istanza, poi su <code className="action">Unshelve</code>.

    Nella finestra **Unshelve dell'istanza**, clicca su <code className="action">Confermare</code>.

    Una volta completata l'operazione, lo stato della tua istanza apparirà come **Attiva**.
  </Tab>
  <Tab label="CLI OVHcloud">
    Esegui questo comando:

    ```shell
    ovhcloud cloud instance unshelve <instance_id>
    ```
  </Tab>
  <Tab label="API OVHcloud">
    Utilizza la seguente chiamata API, dove `projectId` è l'ID del tuo progetto Public Cloud e `instanceId` l'ID dell'istanza:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Con il seguente corpo della richiesta:

    ```json
    {
      "type": "UNSHELVE"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Una volta che l'ambiente è pronto, esegui questo comando:

    ```bash
    ~$ openstack server unshelve <UUID server>

    =========================================

    ~$ nova unshelve <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    Nell'interfaccia Horizon, clicca su <code className="action">Compute</code> nel menu a sinistra e seleziona <code className="action">Istanze</code>. Seleziona <code className="action">Unshelve Instance</code> nel menu a tendina dell'istanza.

    <img className="thumbnail" alt="unshelve instance" src="/images/public-cloud/compute/suspend-or-pause-an-instance/unshelveinstancehorizon.png" loading="lazy" />

    Una volta terminato il processo, l'istanza apparirà come *Active*.
  </Tab>
</Tabs>

<a name="hard-stop-instance"></a>

### Effettuare l'Hard stop (*stop*) di un'istanza

Questa opzione arresta la tua istanza (azione OpenStack *stop*, *Shut Off* in Horizon). I dati del disco vengono conservati, ma lo stato della memoria viene perso: l'istanza si riavvia quando la rilanci. Le risorse dedicate all'istanza restano riservate, compreso l'indirizzo IP, e l'istanza continua a essere fatturata allo stesso prezzo.

<Tabs>
  <Tab label="Console OVHcloud">
    Nel menu a sinistra del tuo progetto Public Cloud, clicca su <code className="action">Instances</code> nella sezione **Compute**.

    Clicca sul pulsante <code className="action">...</code> a destra dell'istanza da arrestare, poi su <code className="action">Hard stop</code>.

    Nella finestra **Hard stop dell'istanza**, prendi nota del messaggio e clicca su <code className="action">Confermare</code>.

    Una volta completata l'operazione, lo stato della tua istanza apparirà come **Hard stop (Shutoff)**.

    Per **rilanciare** l'istanza, clicca sul pulsante <code className="action">...</code> a destra dell'istanza e seleziona <code className="action">Avvia</code>, poi clicca su <code className="action">Confermare</code> nella finestra **Avvia l'istanza**. In alcuni casi, potrebbe essere necessario riavviare a freddo.

    Una volta completata l'operazione, lo stato della tua istanza apparirà come **Attiva**.
  </Tab>
  <Tab label="CLI OVHcloud">
    Esegui questo comando:

    ```shell
    ovhcloud cloud instance stop <instance_id>
    ```

    Per **rilanciare** l'istanza, esegui questo comando:

    ```shell
    ovhcloud cloud instance start <instance_id>
    ```
  </Tab>
  <Tab label="API OVHcloud">
    Utilizza la seguente chiamata API, dove `projectId` è l'ID del tuo progetto Public Cloud e `instanceId` l'ID dell'istanza:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Con il seguente corpo della richiesta:

    ```json
    {
      "type": "STOP"
    }
    ```

    Per **riprendere** l'istanza, utilizza la stessa chiamata con il tipo `START`:

    ```json
    {
      "type": "START"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Una volta che l'ambiente è pronto, esegui questo comando:

    ```bash
    ~$ openstack server stop <UUID server>

    =========================================

    ~$ nova stop <UUID server>
    ```

    Per **rilanciare** l'istanza, esegui questo comando:

    ```bash
    ~$ openstack server start <UUID server>

    =========================================

    ~$ nova start <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    Nell'interfaccia Horizon, clicca su <code className="action">Compute</code> nel menu a sinistra e seleziona <code className="action">Istanze</code>. Seleziona <code className="action">Shut Off Instance</code> nel menu a tendina dell'istanza.

    Per **rilanciare** l'istanza, seleziona <code className="action">Start Instance</code> nel menu a tendina dell'istanza.
  </Tab>
</Tabs>

<a name="stop-suspend-instance"></a>

### Sospendere (*Suspend*) un'istanza

Questa opzione sospende la tua istanza: lo stato della memoria viene scritto sul disco dell'host, e la RAM e la CPU vengono liberate sull'hypervisor mentre l'allocazione viene conservata. Alla ripresa, lo stato salvato viene ripristinato, come dopo un'ibernazione. Vieni fatturato alla stessa tariffa.

Questa azione non è disponibile nella console OVHcloud: utilizza l'API OVHcloud, l'interfaccia Horizon o le API OpenStack/Nova.

<Tabs>
  <Tab label="API OVHcloud">
    Utilizza la seguente chiamata API, dove `projectId` è l'ID del tuo progetto Public Cloud e `instanceId` l'ID dell'istanza:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Con il seguente corpo della richiesta:

    ```json
    {
      "type": "SUSPEND"
    }
    ```

    Per **riprendere** l'istanza, utilizza la stessa chiamata con il tipo `RESUME`:

    ```json
    {
      "type": "RESUME"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Una volta che l'ambiente è pronto, esegui questo comando:

    ```bash
    ~$ openstack server suspend <UUID server>

    =========================================

    ~$ nova suspend <UUID server>
    ```

    Per **riprendere** l'istanza, esegui questo comando:

    ```bash
    ~$ openstack server resume <UUID server>

    =========================================

    ~$ nova resume <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    Nell'interfaccia Horizon, clicca su <code className="action">Compute</code> nel menu a sinistra e seleziona <code className="action">Istanze</code>. Seleziona <code className="action">Suspend Instance</code> nel menu a tendina dell'istanza.

    <img className="thumbnail" alt="suspend instance Horizon" src="/images/public-cloud/compute/suspend-or-pause-an-instance/suspendinstancehorizon.png" loading="lazy" />

    Compare il messaggio di conferma che l'istanza è stata sospesa.

    Per **riprendere** l'istanza, effettua le stesse operazioni indicate in precedenza. Nella lista a tendina dell'istanza corrispondente, seleziona <code className="action">Resume Instance</code>.
  </Tab>
</Tabs>

<a name="pause-instance"></a>

### Mettere in pausa un'istanza

Questa azione non è disponibile nella console OVHcloud: utilizza l'API OVHcloud, l'interfaccia Horizon o le API OpenStack/Nova. Permette di mettere l'istanza in *standby* o di "congelarla". Lo stato della memoria viene conservato nella RAM dell'host, e l'istanza riprende istantaneamente, esattamente dal punto in cui si era fermata.

<Tabs>
  <Tab label="API OVHcloud">
    Utilizza la seguente chiamata API, dove `projectId` è l'ID del tuo progetto Public Cloud e `instanceId` l'ID dell'istanza:

    <Api version="v2" section="/publicCloud" method="POST" route={"/publicCloud/project/\{projectId\}/compute/instance/\{instanceId\}/action"} />

    Con il seguente corpo della richiesta:

    ```json
    {
      "type": "PAUSE"
    }
    ```

    Per **riprendere** l'istanza, utilizza la stessa chiamata con il tipo `UNPAUSE`:

    ```json
    {
      "type": "UNPAUSE"
    }
    ```
  </Tab>
  <Tab label="API OpenStack/Nova">
    Una volta che l'ambiente è pronto, esegui questo comando:

    ```bash
    ~$ openstack server pause <UUID server>

    =========================================

    ~$ nova pause <UUID server>
    ```

    Per **riattivare** l'istanza, esegui questo comando:

    ```bash
    ~$ openstack server unpause <UUID server>

    =========================================

    ~$ nova unpause <UUID server>
    ```
  </Tab>
  <Tab label="Horizon">
    Nell'interfaccia Horizon, clicca su <code className="action">Compute</code> nel menu a sinistra e seleziona <code className="action">Istanze</code>. Seleziona <code className="action">Pause Instance</code> nel menu a tendina dell'istanza.

    <img className="thumbnail" alt="Pause instance" src="/images/public-cloud/compute/suspend-or-pause-an-instance/pauseinstancehorizon.png" loading="lazy" />

    Compare il messaggio di conferma che l'istanza è stata messa in pausa.

    Per **riattivare** l'istanza, effettua le stesse operazioni indicate in precedenza. Nella lista a tendina dell'istanza corrispondente, seleziona <code className="action">Resume Instance</code>.
  </Tab>
</Tabs>
