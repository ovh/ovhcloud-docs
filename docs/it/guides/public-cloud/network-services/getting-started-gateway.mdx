## Obiettivo

Una [Gateway](/links/public-cloud/gateway) OVHcloud fornisce una connettività in uscita sicura (SNAT) per le istanze di una sottorete privata ed è necessaria su tale sottorete per utilizzare i [Floating IP](/links/public-cloud/floating-ip) per l'esposizione pubblica di queste risorse private.

**Questa guida vi spiega come creare, elencare, modificare ed eliminare una Gateway Public Cloud dallo Spazio Cliente OVHcloud, dall'API OVHcloud, da ovhcloud-cli o da Terraform.**

## Prerequisiti

- Possedere un [progetto Public Cloud](/links/public-cloud/public-cloud) sul vostro account OVHcloud
- Disporre di una rete privata con almeno una sottorete nella regione di destinazione (consultate [Configurare il vRack per il Public Cloud](/guides/public-cloud/network-services/vrack))
- **Per l'API OVHcloud:** delle credenziali API OVHcloud ([Primi passi con le API OVHcloud](/guides/manage-and-operate/api/first-steps))
- **Per ovhcloud-cli:** [ovhcloud-cli](https://github.com/ovh/ovhcloud-cli) installato e configurato con le vostre credenziali
- **Per Terraform:** Terraform installato e il provider OVH configurato ([Come utilizzare Terraform con OVHcloud](/guides/public-cloud/cross-functional/how-to-use-terraform))

## Procedura

### Modelli di Gateway

Prima di creare una Gateway, scegliete il modello corrispondente alle vostre esigenze di banda passante:

:::info
Vi informiamo che, al momento, la taglia 2XL non è disponibile nelle regioni di Mumbai, Singapore e Sydney.
:::

| Modello | Banda passante |
|---------|----------------|
| S | fino a 200 Mbps |
| M | fino a 500 Mbps |
| L | fino a 2 Gbps |
| XL | fino a 4 Gbps |
| 2XL | fino a 8 Gbps |

### Creare una Gateway

<Tabs>
  <Tab label="Spazio Cliente OVHcloud">
    Dal vostro progetto Public Cloud, cliccate su <code className="action">Gateway</code> nel menu a sinistra sotto **Network**, poi cliccate su <code className="action">Creare Gateway</code>.

    1. **Selezionate una regione.** Scegliete la regione in cui sono distribuite le vostre istanze private.
    2. **Selezionate una taglia.** Scegliete il modello di Gateway in base alle vostre esigenze di banda passante (consultate la tabella precedente).
    3. **Nominate e associate una rete.** Inserite un nome per la vostra Gateway e selezionate una rete privata esistente dall'elenco a discesa, oppure cliccate su <code className="action">Aggiungere una rete privata</code> per crearne una direttamente.
    4. Cliccate su <code className="action">Creare Gateway</code> per confermare. Il provisioning della Gateway richiede qualche minuto.

    Una volta creata, la Gateway compare nella sezione <code className="action">Gateway</code> e la rete privata associata è visibile sotto <code className="action">Reti private</code>.

    :::info
    Solo le reti private mono-regione sono supportate dalla Gateway.

    :::
  </Tab>
  <Tab label="API OVHcloud">
    Connettetevi all'<ApiLink>API OVHcloud</ApiLink> e utilizzate la seguente chiamata per creare una Gateway insieme a una nuova rete privata e una sottorete in una sola operazione:

    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/gateway"} />

    | Campo | Descrizione |
    |-------|-------------|
    | `serviceName` | L'identificativo del vostro progetto Public Cloud |
    | `regionName` | La regione di destinazione (es. `GRA9`) |
    | `model` | Taglia della Gateway: `s`, `m`, `l`, `xl`, `2xl`, `3xl` |
    | `name` | Nome della vostra Gateway |
    | `network.name` | Nome della nuova rete privata |
    | `network.cidr` | CIDR della sottorete (es. `192.168.1.0/24`) |
    | `network.enableDhcp` | `true` per attivare il DHCP sulla sottorete |
    | `network.ipVersion` | `4` (IPv6 non ancora disponibile) |
    | `network.vlanId` | Identificativo VLAN (2–4000), o vuoto per un'assegnazione automatica |

    La chiamata restituisce un oggetto `cloud.Operation`. Per associare una Gateway a una sottorete **esistente**, utilizzate:

    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/network/\\{networkId\\}/subnet/\\{subnetId\\}/gateway"} />

    Per recuperare l'identificativo del vostro progetto:

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project"} />
  </Tab>
  <Tab label="ovhcloud-cli">
    Utilizzate `ovhcloud cloud network gateway create` con la regione di destinazione e l'opzione `--wait` per attendere il completamento del provisioning.

    **Creare una Gateway in una rete privata esistente:**

    ```bash
    ovhcloud cloud network gateway create <region> \
      --cloud-project <project_id> \
      --name my-gateway \
      --model s \
      --network-id <network_id> \
      --subnet-id <subnet_id> \
      --wait
    ```

    **Creare una Gateway con una nuova rete privata:**

    ```bash
    ovhcloud cloud network gateway create <region> \
      --cloud-project <project_id> \
      --name my-gateway \
      --model s \
      --network-name my-network \
      --subnet-cidr 192.168.1.0/24 \
      --subnet-enable-dhcp \
      --wait
    ```

    Modelli disponibili: `s`, `m`, `l`, `xl`, `2xl`, `3xl`.
  </Tab>
  <Tab label="Terraform">
    Create un file di configurazione Terraform (es. `gateway.tf`) con le seguenti risorse:

    ```hcl
    resource "ovh_cloud_project_network_private" "mypriv" {
      service_name = "<project_id>"
      vlan_id      = "0"
      name         = "my-network"
      regions      = ["GRA9"]
    }

    resource "ovh_cloud_project_network_private_subnet" "myprivsub" {
      service_name = ovh_cloud_project_network_private.mypriv.service_name
      network_id   = ovh_cloud_project_network_private.mypriv.id
      region       = "GRA9"
      start        = "10.0.0.2"
      end          = "10.0.255.254"
      network      = "10.0.0.0/16"
      dhcp         = true
    }

    resource "ovh_cloud_project_gateway" "gateway" {
      service_name = ovh_cloud_project_network_private.mypriv.service_name
      name         = "my-gateway"
      model        = "s"
      region       = ovh_cloud_project_network_private_subnet.myprivsub.region
      network_id   = tolist(ovh_cloud_project_network_private.mypriv.regions_attributes[*].openstackid)[0]
      subnet_id    = ovh_cloud_project_network_private_subnet.myprivsub.id
    }
    ```

    Applicate la configurazione:

    ```bash
    terraform init
    terraform apply
    ```

    :::info
    Sostituite `GRA9` con la vostra regione di destinazione e `<project_id>` con l'identificativo del vostro progetto Public Cloud.

    :::
  </Tab>
</Tabs>

### Elencare le vostre Gateway

<Tabs>
  <Tab label="Spazio Cliente OVHcloud">
    Dal vostro progetto Public Cloud, cliccate su <code className="action">Gateway</code> nel menu a sinistra sotto **Network**.

    La pagina elenca tutte le Gateway del vostro progetto con la relativa regione, modello, stato e rete associata.
  </Tab>
  <Tab label="API OVHcloud">
    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/gateway"} />

    | Campo | Descrizione |
    |-------|-------------|
    | `serviceName` | L'identificativo del vostro progetto Public Cloud |
    | `regionName` | La regione di destinazione |
    | `subnetId` | (Opzionale) Filtrare per identificativo di sottorete associata |
    | `withSubnets` | (Opzionale) Includere i dettagli delle sottoreti nella risposta |
  </Tab>
  <Tab label="ovhcloud-cli">
    ```bash
    ovhcloud cloud network gateway list --cloud-project <project_id>
    ```

    Filtrare per modello di nome:

    ```bash
    ovhcloud cloud network gateway list \
      --cloud-project <project_id> \
      --filter 'name=~"^my-.*"'
    ```
  </Tab>
</Tabs>

### Modificare una Gateway

Potete modificare il nome o il modello (taglia) di una Gateway esistente.

<Tabs>
  <Tab label="Spazio Cliente OVHcloud">
    Dall'elenco <code className="action">Gateway</code>, cliccate sul menu <code className="action">...</code> accanto alla vostra Gateway, poi selezionate <code className="action">Modificare il tuo Gateway</code>.

    Modificate il nome o selezionate un nuovo modello, poi confermate.
  </Tab>
  <Tab label="API OVHcloud">
    <Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/gateway/\\{id\\}"} />

    Trasmettete i campi da modificare nel corpo della richiesta (`name`, `model`, o entrambi).
  </Tab>
  <Tab label="ovhcloud-cli">
    ```bash
    ovhcloud cloud network gateway edit <gateway_id> \
      --cloud-project <project_id> \
      --name new-name \
      --model m
    ```

    Potete utilizzare `--name`, `--model`, o entrambi.
  </Tab>
  <Tab label="Terraform">
    Modificate il campo `name` o `model` nel vostro blocco di risorsa `ovh_cloud_project_gateway`, poi applicate:

    ```bash
    terraform apply
    ```
  </Tab>
</Tabs>

### Eliminare una Gateway

:::warning
L'eliminazione di una Gateway è irreversibile. Le istanze che la utilizzano per la loro connettività in uscita perderanno il loro accesso a Internet.

:::

<Tabs>
  <Tab label="Spazio Cliente OVHcloud">
    Dall'elenco <code className="action">Gateway</code>, cliccate sul menu <code className="action">...</code> accanto alla vostra Gateway, poi selezionate <code className="action">Elimina</code> e confermate.
  </Tab>
  <Tab label="API OVHcloud">
    <Api version="v1" section="/cloud" method="DELETE" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/gateway/\\{id\\}"} />

    La chiamata restituisce un `cloud.Operation`. L'eliminazione è asincrona — verificate lo stato dell'operazione se necessario:

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/operation/\\{operationId\\}"} />
  </Tab>
  <Tab label="ovhcloud-cli">
    ```bash
    ovhcloud cloud network gateway delete <gateway_id> \
      --cloud-project <project_id>
    ```
  </Tab>
  <Tab label="Terraform">
    Eliminate il blocco di risorsa `ovh_cloud_project_gateway` dal vostro file di configurazione, poi applicate:

    ```bash
    terraform apply
    ```

    Per eliminare tutte le risorse della configurazione:

    ```bash
    terraform destroy
    ```
  </Tab>
</Tabs>
