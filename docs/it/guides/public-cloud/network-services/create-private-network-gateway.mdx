## Obiettivo

Una [Gateway](/links/public-cloud/gateway) offre un metodo di connessione in uscita sicuro dalle tue istanze in rete privata, oppure la possibilità di utilizzare indirizzi Floating IP con la tua istanza o il tuo Load Balancer per l'esposizione di servizi.

**Scopri come creare una rete privata con una Gateway.**

## Prerequisiti

- Avere un [progetto Public Cloud](/links/public-cloud/public-cloud) nel tuo account OVHcloud
- **Per l'API OVHcloud:** delle credenziali API ([Primi passi con l'API OVHcloud](/guides/manage-and-operate/api/first-steps))
- **Per la CLI OVHcloud:** la [CLI OVHcloud](https://github.com/ovh/ovhcloud-cli) installata e configurata con le tue credenziali
- **Per l'API OpenStack:** un ambiente OpenStack configurato ([Preparare l'ambiente](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment))
- **Per Terraform:** Terraform installato e il provider OVHcloud configurato ([Come utilizzare Terraform sul Public Cloud OVHcloud](/guides/public-cloud/cross-functional/how-to-use-terraform))

## Procedura

### Modelli di Gateway

Prima di creare una Gateway, scegli il modello adatto alle tue esigenze di larghezza di banda:

:::info
Vi informiamo che, al momento, la taglia 2XL non è disponibile nelle regioni di Mumbai, Singapore e Sydney.
:::

| Modello | Larghezza di banda |
|--------|----------------|
| S | fino a 200 Mbps |
| M | fino a 500 Mbps |
| L | fino a 2 Gbps |
| XL | fino a 4 Gbps |
| 2XL | fino a 8 Gbps |

### Creare una rete privata con una Gateway

<Tabs>
  <Tab label="Spazio Cliente OVHcloud">
    **Passo 1 — Accedere alla creazione**

    Clicca su <code className="action">Gateway</code> nel menu a sinistra sotto la scheda **Network**.

    Tieni presente che è necessario aver attivato il vRack prima di proseguire. Se non ne possiedi uno, consulta la sezione [attivazione del vRack](/guides/public-cloud/network-services/vrack#activation) della guida corrispondente.

    Clicca quindi sul pulsante <code className="action">Creare Gateway</code>.

    <img className="thumbnail" alt="creazione della gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/firstgatewaycreation.png" loading="lazy" />

    **Passo 2 — Selezionare la regione e la dimensione**

    Seleziona la regione in cui si trovano le tue istanze private.

    <img className="thumbnail" alt="selezione della regione" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/select_region.png" loading="lazy" />

    Seleziona quindi la dimensione della tua Gateway (vedi la tabella dei modelli qui sopra).

    <img className="thumbnail" alt="selezione di una dimensione di gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/select_size.png" loading="lazy" />

    **Passo 3 — Nominare la Gateway e associare una rete privata**

    Modifica il nome predefinito della tua Gateway e seleziona una rete privata esistente tramite il menu a discesa.

    :::info
    Solo le reti private a regione singola sono supportate dalla Gateway.
    :::

    <img className="thumbnail" alt="menu a discesa" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/gatewayandprivatenetwork.png" loading="lazy" />

    Puoi anche cliccare su <code className="action">Aggiungere una rete privata</code> per creare al volo una nuova rete privata.

    <img className="thumbnail" alt="creare una rete privata" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/newprivatenetwork.png" loading="lazy" />

    Nella finestra, assegna un nome alla tua rete privata, seleziona una sotto-rete e clicca su <code className="action">Aggiungi</code>.

    <img className="thumbnail" alt="creare una rete privata" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/createprivatenetwork.png" loading="lazy" />

    **Passo 4 — Confermare la creazione**

    Clicca su <code className="action">Creare Gateway</code> per avviare la distribuzione.

    <img className="thumbnail" alt="creare una gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/confirmcreation.png" loading="lazy" />

    La creazione può richiedere diversi minuti. Aggiorna la pagina se necessario.

    Una volta completata la creazione, la rete privata è visibile nella sezione <code className="action">Private Network</code> del menu **Network**.

    <img className="thumbnail" alt="nuova rete privata" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/createdprivatenetwork.png" loading="lazy" />

    La Gateway appare nella sezione <code className="action">Gateway</code>.

    <img className="thumbnail" alt="nuova gateway" src="/images/public-cloud/network-services/getting-started-02-create-private-network-gateway/mynewgateway.png" loading="lazy" />
  </Tab>
  <Tab label="API OVHcloud">
    Accedi all'interfaccia APIv6 OVHcloud. Se necessario, consulta la guida [Primi passi con l'API OVHcloud](/guides/manage-and-operate/api/first-steps).

    **Recuperare l'identificativo del progetto**

    Se l'identificativo del progetto è sconosciuto, utilizza le seguenti chiamate:

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project"} />

    :::info
    Questa chiamata recupera l'elenco dei progetti.
    :::

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}"} />

    :::info
    Questa chiamata identifica il progetto tramite il campo `description`.
    :::

    **Creare la rete privata con una Gateway**

    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/gateway"} />

    Compila i campi secondo la seguente tabella:

    | Campo | Descrizione |
    |-------|-------------|
    | `serviceName` | L'identificativo del tuo progetto |
    | `regionName` | Ad esempio: `GRA9` |
    | `model` | Dimensione della Gateway (`s`, `m`, `l`, `xl`, `2xl`) |
    | `name` | Nome della tua Gateway (`null` per il nome predefinito) |
    | `network.name` | Nome della rete privata (`null` per il nome predefinito) |
    | `network.cidr` | Blocco di indirizzi IP della sotto-rete (es: `192.168.1.0/24`) |
    | `network.enableDhcp` | Seleziona per attivare il DHCP |
    | `network.ipVersion` | `4` (IPv6 non disponibile) |
    | `network.vlanId` | Valore tra 2 e 4000, oppure vuoto per un'attribuzione automatica |

    :::info
    Ripeti l'operazione per ogni regione in cui sono presenti le tue istanze private.
    :::

    Per verificare i dettagli della tua Gateway:

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/gateway"} />

    Lascia `subnetId` vuoto per elencare tutte le Gateway della regione specificata.
  </Tab>
  <Tab label="CLI OVHcloud">
    Utilizza la [CLI OVHcloud](https://github.com/ovh/ovhcloud-cli) per creare una rete privata con una Gateway. Definisci il tuo progetto cloud con `--cloud-project <project_id>` oppure configuralo nel tuo profilo.

    **Creare una Gateway con una nuova rete privata:**

    ```bash
    ovhcloud cloud network gateway create <region> \
      --cloud-project <project_id> \
      --name my-gateway \
      --model s \
      --network-name my-network \
      --subnet-cidr 192.168.1.0/24 \
      --subnet-enable-dhcp \
      --wait
    ```

    **Creare una Gateway in una rete privata esistente:**

    ```bash
    ovhcloud cloud network gateway create <region> \
      --cloud-project <project_id> \
      --name my-gateway \
      --model s \
      --network-id <network_id> \
      --subnet-id <subnet_id> \
      --wait
    ```

    Modelli disponibili: `s`, `m`, `l`, `xl`, `2xl`.

    :::info
    Solo le reti private a regione singola sono supportate dalla Gateway.
    :::
  </Tab>
  <Tab label="API OpenStack">
    Prima di proseguire, consulta le seguenti guide:

    - [Preparare l'ambiente per utilizzare l'API OpenStack](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment)
    - [Impostare le variabili d'ambiente OpenStack](/guides/public-cloud/cross-functional/compute-set-openstack-environment-variables)

    **Passo 1 — Creare una rete e una sotto-rete**

    ```console
    openstack network create my_network

    openstack subnet create my_subnet --subnet-range <my_private_ip_range/mask> --network my_network --no-dhcp
    ```

    **Passo 2 — Elencare i livelli di qualità del servizio**

    ```console
    openstack network qos policy list
    +--------------------------------------+---------------+--------+---------+----------------------------------+
    | ID                                   | Name          | Shared | Default | Project                          |
    +--------------------------------------+---------------+--------+---------+----------------------------------+
    | a5524eb5-944e-4106-b209-9478bbdcedab | large_router  | True   | False   | XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX |
    | c210f5b2-db59-4973-a25f-9131195b6bcf | medium_router | True   | False   | XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX |
    | ec0ee74d-a1f3-43f6-87aa-b0e69ef8ce45 | small_router  | True   | False   | XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX |
    +--------------------------------------+---------------+--------+---------+----------------------------------+
    ```

    **Passo 3 — Creare il router e configurare la Gateway**

    ```console
    openstack router create my_router

    openstack router add subnet my_router my_subnet

    openstack router set --external-gateway Ext-Net --qos-policy QOS_ID_OF_YOUR_CHOICE my_router
    ```

    Se non specifichi il parametro `--qos-policy`, viene applicata la qualità del servizio `small`.
  </Tab>
  <Tab label="Terraform">
    Prima di iniziare, consulta la guida: [Come utilizzare Terraform sul Public Cloud OVHcloud](/guides/public-cloud/cross-functional/how-to-use-terraform)

    Crea un file Terraform (ad esempio `private_network_gateway.tf`) con il seguente contenuto:

    ```hcl
    resource "ovh_cloud_project_network_private" "mypriv" {
      service_name = "<project_id>"
      vlan_id      = "0"
      name         = "mypriv"
      regions      = ["GRA9"]
    }

    resource "ovh_cloud_project_network_private_subnet" "myprivsub" {
      service_name = ovh_cloud_project_network_private.mypriv.service_name
      network_id   = ovh_cloud_project_network_private.mypriv.id
      region       = "GRA9"
      start        = "10.0.0.2"
      end          = "10.0.255.254"
      network      = "10.0.0.0/16"
      dhcp         = true
    }

    resource "ovh_cloud_project_gateway" "gateway" {
      service_name = ovh_cloud_project_network_private.mypriv.service_name
      name         = "my-gateway"
      model        = "s"
      region       = ovh_cloud_project_network_private_subnet.myprivsub.region
      network_id   = tolist(ovh_cloud_project_network_private.mypriv.regions_attributes[*].openstackid)[0]
      subnet_id    = ovh_cloud_project_network_private_subnet.myprivsub.id
    }
    ```

    Applica la configurazione:

    ```console
    terraform apply
    ```
  </Tab>
