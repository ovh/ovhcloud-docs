## Startup Program de OVHcloud

El [Startup Program de OVHcloud](/links/transversal/startup-program) ayuda a las startups a construir y escalar su infraestructura de servidores en OVHcloud. Una vez aceptada su candidatura y firmado su contrato, recibirá créditos gratuitos válidos durante 12 meses, y nuestros Startup Program Managers le acompañarán durante todo el programa.

Como miembro del Startup Program, puede:

- Pagar los productos elegibles con sus créditos, como Public Cloud y Hosted Private Cloud
- Solicitar consultas técnicas para evaluar y hacer evolucionar su infraestructura
- Contactar con un Startup Program Manager para recibir asesoramiento en cualquier momento
- Conocer a nuestros equipos en eventos para startups
