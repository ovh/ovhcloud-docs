## Objetivo

El registro **inverso** (*rDNS*) es el complemento de la resolución "clásica" de los DNS que permite convertir un dominio en una dirección IP (registro de tipo **A**). Una solicitud de este tipo permite resolver una dirección IP en el dominio (registro de tipo **PTR**). Esto significa que las peticiones DNS a la dirección IP correspondiente devolverán un dominio.

La configuración de la resolución **inversa DNS** de una instancia resulta especialmente útil para el envío de mensajes de correo. Si la dirección IP de su servidor de envío se resuelve correctamente en su nombre de dominio, se reducirá el riesgo de que sus mensajes sean rechazados por un sistema de protección contra el spam.

**Esta guía explica cómo configurar el registro DNS inverso para la dirección o direcciones IP de una instancia de Public Cloud.**

## Requisitos

- Tener una [instancia de Public Cloud](/links/public-cloud/public-cloud) en su cuenta de OVHcloud.
- Un dominio con un registro `A` que apunta a la instancia.

[[cpnav:network-public-ip-console]]

## Procedimiento

La lista <code className="action">Filtrar por servicio...</code> de la página **Direcciones IP** le permite filtrar sus direcciones IP por servicio: seleccione su proyecto de Public Cloud en el grupo **Public Cloud**. También puede buscar una dirección IP específica utilizando la barra de búsqueda.

Haga clic en la dirección IP correspondiente, abra la pestaña <code className="action">Reverse DNS</code> y haga clic en <code className="action">Configurar</code>.

En la ventana **Configurar el Reverse DNS**, introduzca su reverse en el campo **Nombre de host reverse DNS** y haga clic en <code className="action">Configurar</code>.

Para eliminar un reverse, haga clic en el icono de eliminación en la línea del reverse, en la pestaña **Reverse DNS**.

:::info
Si la modificación no funciona como se esperaba, compruebe que el registro `A` esté bien configurado en la zona DNS del dominio. Atención: La modificación de la [zona DNS](/guides/web-cloud/domains/dns-zone-edit) puede tardar hasta 24 horas si solo ha cambiado recientemente el registro `A`.
:::
