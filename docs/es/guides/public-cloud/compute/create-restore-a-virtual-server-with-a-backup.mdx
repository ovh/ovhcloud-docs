## Objetivo

Desde la consola de OVHcloud podrá crear [snapshots de sus instancias](/guides/public-cloud/compute/save-an-instance) en pocos clics y automatizar el proceso.
Quizá necesite, en algún momento, restaurar su instancia utilizando un snapshot, por ejemplo, por haber configurado de manera incorrecta su instancia. Existen dos razones principales por las que puede utilizar estos snapshots de instancias:

- Crear una instancia basada en el snapshot para duplicar la instancia de origen. Por ejemplo, si configura una infraestructura de balanceo de carga (load balancing).
- Restaurar una instancia a partir de un snapshot. Por ejemplo, si recientes modificaciones han roto configuraciones críticas en la instancia.

**Descubra cómo utilizar sus snapshots para duplicar o restaurar sus instancias.**

## Requisitos

- Disponer de [un snapshot de una instancia de Public Cloud](/links/public-cloud/instance-backup). Para ello, consulte [la guía dedicada a la creación de un snapshot](/guides/public-cloud/compute/save-an-instance).

[[cpnav:publiccloud-instance-backup-console]]

## Procedimiento

:::info
Están disponibles dos tipos de snapshots:

- Local: almacenado en la misma región que su instancia.
- Remoto: replicado automáticamente en otra región de su elección.

Las operaciones de **creación** y **restauración** de una instancia desde un snapshot remoto son totalmente compatibles a través de la API de OVHcloud, ofreciendo una mayor flexibilidad y una integración más sencilla en sus procesos de automatización.

**Nota:** En la consola de OVHcloud, puede crear una instancia a partir de cualquier snapshot que aparezca en la página **Snapshots de instancia**, pero solo puede restaurar una instancia existente a partir de un snapshot almacenado en su propia región.

:::


### Crear una instancia a partir de un snapshot

<Tabs>
  <Tab label="Consola de OVHcloud">
    En el menú de la izquierda de su proyecto de Public Cloud, haga clic en <code className="action">Instance Snapshot</code> bajo **Compute**. La página **Snapshots de instancia** muestra la lista de sus snapshots.

    Haga clic en el botón <code className="action">...</code> en la fila del snapshot elegido y seleccione <code className="action">Crear una instancia</code>.

    Se abrirá la página **Crear una instancia** con algunos elementos predefinidos:

    - **Localización**: Su instancia se creará en la misma región que su snapshot. La región viene determinada por el snapshot y no se puede modificar.
    - **Imagen**: El snapshot está preseleccionado en la pestaña <code className="action">Snapshots</code> de la sección **Seleccione una imagen**.
    - **Modelo**: Solo estarán disponibles los modelos que puedan alojar su imagen, según su cuota.

    Defina el nombre de la nueva instancia, la clave SSH y los parámetros de red y de facturación, y haga clic en el botón <code className="action">Crear mi instancia</code>.

    Para obtener más información sobre la creación de una instancia, consulte [esta guía](/guides/public-cloud/compute/getting-started).

    :::info
    Para crear una instancia en un centro de datos diferente al del snapshot, deberá transferirlo a la zona correspondiente. Consulte la [guía sobre la transferencia de un snapshot de instancia entre centros de datos](/guides/public-cloud/compute/transfer-instance-backup-from-one-datacentre-to-another).

    :::

  </Tab>
  <Tab label="API de OVHcloud">
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/instance"} />

Rellene las variables:
    
    - **serviceName** : El ID del proyecto de OVHcloud.
    - **regionName** : El nombre de la región donde se creará la instancia.
    
    Ejemplo de cuerpo de la solicitud:
    
    ```json
    {
      "billingPeriod": "hourly",
      "bootFrom": {
        "imageId": "5cb8ea68-****-****-****-820be8346***"
      },
      "flavor": {
        "id": "e81b46f8-****-****-****-cad655e65***"
      },
      "name": "newInstance",
      "network": {
        "public": true
      },
      "sshKey": {
        "name": "MySSHKey"
      }
    }
    ```
  </Tab>
  <Tab label="CLI OpenStack">
    Para crear una instancia a partir de su snapshot, utilice el ID del snapshot como imagen con este comando:
    
    ```bash
    $ openstack server create --key-name SSHKEY --flavor 98c1e679-5f2c-4069-b4da-4a4f7179b758 --image 0a3f5901-2314-438a-a7af-ae984dcbce5c Server1_from_snap
    ```
  </Tab>
  <Tab label="Horizon">
    En la interfaz de Horizon, haga clic en <code className="action">Compute</code> en el menú izquierdo, luego en <code className="action">Images</code>. Busque la imagen deseada y haga clic en el botón <code className="action">Launch</code> a la derecha de la fila de su imagen.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon1.png" loading="lazy" />

Asigne un nombre a su instancia en el campo correspondiente y determine el número de instancias a crear. Luego haga clic en la pestaña <code className="action">Flavor</code>.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-2" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon2.png" loading="lazy" />

Elija el modelo de instancia deseado y haga clic en la pestaña <code className="action">Networks</code>.
    
    :::warning
    Si su instancia es un servidor Windows, debe seleccionar un sabor del tipo win-xx-xx (por ejemplo, win-b2-15) y tener una interfaz pública en la red Ext-Net. Sin estas condiciones, no será posible la autenticación con el KMS de OVHcloud, y su servidor permanecerá con una [licencia no activada](/guides/public-cloud/compute/activate-windows-license-private-mode). Esto podría provocar limitaciones, especialmente la falta de actualizaciones. Tenga en cuenta que no se puede escalar una instancia Linux (por ejemplo, b2-15) a una instancia Windows (como win-b2-15). Para realizar esta transición, es necesario crear una nueva instancia.

    :::

    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-3" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon3.png" loading="lazy" />

Elija la red que desea asignar y haga clic en el botón <code className="action">Launch Instance</code>.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-4" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon4.png" loading="lazy" />

Puede ver el estado de su nueva instancia en <code className="action">Compute</code> en el menú izquierdo, luego en <code className="action">Instances</code>.
    
    <img className="thumbnail" alt="public-cloud-instance-backup-horizon-5" src="/images/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/restorebackuphorizon5.png" loading="lazy" />
  </Tab>
</Tabs>


### Restaurar una instancia a partir de un snapshot

<Tabs>
  <Tab label="Consola de OVHcloud">
    En el menú de la izquierda de su proyecto de Public Cloud, haga clic en <code className="action">Instances</code> bajo **Compute** y, a continuación, haga clic en el nombre de la instancia correspondiente.

    En la tarjeta **Información general** de la pestaña <code className="action">Resumen</code>, haga clic en <code className="action">Editar imagen</code> en la fila **Imagen**. Se abrirá el panel **Editar imagen**.

    En la sección **Seleccionar una distribución**, seleccione los snapshots y, a continuación, seleccione el snapshot que desea restaurar en la sección **Seleccionar una imagen**. Solo se ofrecen los snapshots almacenados en la región de la instancia. Haga clic en <code className="action">Editar imagen</code> si está seguro de querer reemplazar la imagen actual por el snapshot.

    La instancia se reinstalará y se reiniciará hasta que el proceso haya finalizado.

    :::warning
    Como se indica en el mensaje de advertencia, se eliminarán todos los datos de la instancia: no se podrá recuperar ningún dato añadido después de la creación del snapshot.

    :::

  </Tab>
  <Tab label="API de OVHcloud">
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/instance/\\{instanceId\\}/reinstall"} />

Rellene las variables:
    
    - **serviceName** : El ID del proyecto de OVHcloud.
    - **regionName** : El nombre de la región donde se encuentra la instancia de origen.
    - **instanceId** : El ID único de la instancia.
    
    Ejemplo de cuerpo de la solicitud:
    
    ```json
    {
      "imageId": "5cb8ea68-****-****-****-820be8346***",
      "imageRegionName": "GRA11"
    }
    ```
  </Tab>
</Tabs>
