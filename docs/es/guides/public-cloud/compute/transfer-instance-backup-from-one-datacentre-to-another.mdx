## Objetivo

Es posible que tenga que mover su [instancia Public Cloud](https://www.ovhcloud.com/es-es/public-cloud/compute/) de una región de OpenStack a otra, ya sea porque prefiere migrar a una nueva región de OpenStack disponible o porque quiere migrar de OVHcloud Labs a Public Cloud.

**Esta guía explica cómo transferir una copia de seguridad de una instancia de una región de OpenStack a otra conservando la configuración y el estado de la instancia.**

## Requisitos

- Disponer de la CLI OpenStack. Consulte nuestra guía [Cómo preparar el entorno para utilizar la API de OpenStack](/guides/public-cloud/cross-functional/compute-prepare-openstack-api-environment).
- Tener conectividad a las API OpenStack de OVHcloud.
- Contar con espacio de almacenamiento suficiente correspondiente al tamaño del disco de la instancia (para el almacenamiento de backup temporal).

Este entorno se utilizará como "jump host" para transferir la copia de seguridad de una región a otra. Puede tratarse de una instancia alojada en OVHcloud o de su máquina local.

También necesitará una [instancia de Public Cloud](https://www.ovhcloud.com/es-es/public-cloud/compute/) en su cuenta de OVHcloud.

## Procedimiento

:::info
Si necesita crear una copia de seguridad con OpenStack, consulte nuestra guía "[Guardar una instancia](/guides/public-cloud/compute/save-an-instance)".
:::

### Paso 1 - Descargar la copia de seguridad

Enumere sus imágenes privadas para identificar la copia de seguridad que desea transferir:

```bash
openstack image list --private
```

Descargue la copia de seguridad en su almacenamiento local:

```bash
openstack image save --file backup.qcow2 <image-id>
```

### Paso 2 - Cambiar a la región de destino

Si transfiere la copia de seguridad a otra región dentro del mismo proyecto, actualice `OS_REGION_NAME`:

```bash
export OS_REGION_NAME=<región-destino>
```

Si transfiere la copia de seguridad a otro proyecto o cuenta, cargue el archivo RC correspondiente:

```bash
source openrc.sh
```

### Paso 3 - Importar la copia de seguridad en la región de destino

El comando de importación varía según si la región de destino es una región estándar o una Local Zone.

#### Región estándar

```bash
openstack image create \
  --disk-format qcow2 \
  --container-format bare \
  --file backup.qcow2 \
  <nombre-imagen>
```

#### Local Zone

Los nombres de las regiones Local Zone contienen `-lz-` (por ejemplo, `eu-central-lz-prg-a`). Estas regiones requieren `--disk-format raw`. La extensión del archivo de copia de seguridad no afecta a la importación: es el parámetro `--disk-format` el que indica a OpenStack cómo interpretar el archivo.

```bash
openstack image create \
  --disk-format raw \
  --container-format bare \
  --file backup.qcow2 \
  <nombre-imagen>
```

:::warning
**Solo para imágenes Windows**: debe añadir las siguientes propiedades, ya que de lo contrario no será posible asociar un flavor de tipo `win-x-x` desde el área de cliente de OVHcloud. Este tipo de flavor es necesario para la autenticación a través del [KMS OVHcloud](/guides/manage-and-operate/kms/quick-start).

Añada las propiedades al crear la imagen (región estándar):

```bash
openstack image create \
  --disk-format qcow2 \
  --container-format bare \
  --file backup.qcow2 \
  --property "_system_cloud_property=windows" \
  --property "distro_family=windows" \
  --property "os_type=windows" \
  <nombre-imagen>
```

Añada las propiedades al crear la imagen (Local Zone):

```bash
openstack image create \
  --disk-format raw \
  --container-format bare \
  --file backup.qcow2 \
  --property "_system_cloud_property=windows" \
  --property "distro_family=windows" \
  --property "os_type=windows" \
  <nombre-imagen>
```

O bien defínalas en una imagen ya existente:

```bash
openstack image set \
  --property "_system_cloud_property=windows" \
  --property "distro_family=windows" \
  --property "os_type=windows" \
  <image-uuid>
```
:::

:::info
Para volver a crear su instancia a partir de esta copia de seguridad, consulte nuestra guía "[Crear o restaurar un servidor virtual a partir de un snapshot](/guides/public-cloud/compute/create-restore-a-virtual-server-with-a-backup)".
:::
