## Objetivo

Es posible que tuviera que reparar el bootloader GRUB. Esta guía explica cómo reparar el bootloader y restablecer el funcionamiento de su instancia.

## Requisitos

- Tener una [instancia de Public Cloud](https://www.ovhcloud.com/es-es/public-cloud/) en su cuenta de OVHcloud

## Procedimiento

:::warning
La instancia debe estar en modo de rescate (puede consultar la guía [Pasar una instancia en modo de rescate](/guides/public-cloud/compute/put-an-instance-in-rescue-mode)).

:::


Conéctese a la instancia, ya sea a través del VNC desde <ManagerLink to="/">el área de cliente de OVHcloud</ManagerLink> o por SSH.

Introduzca los siguientes comandos para montar el sistema de archivos remoto e iniciar la reparación de GRUB:

```sh
mount /dev/sdb1 /mnt
mount -o bind /proc /mnt/proc
mount -o bind /sys /mnt/sys
mount -o bind /dev /mnt/dev
chroot /mnt /bin/bash
```

### Actualizar GRUB (o GRUB2)

Actualizar GRUB:

```sh
grub-install /dev/sdb
update-grub
```

Actualizar GRUB2:

```sh
grub2-install /dev/sdb
grub2-mkconfig -o /boot/grub2/grub.cfg
```

Ya puede sacar la instancia del modo de rescate. (Ver la guía [Convertir una instancia en modo de rescate](/guides/public-cloud/compute/put-an-instance-in-rescue-mode)).
