## Objetivo

En esta guía aprenderá a asignar y gestionar tags en sus productos de OVHcloud y a utilizarlos en las políticas IAM.

## Requisitos

- Disponer de una [cuenta de cliente de OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation).

[[cpnav:iam-tag-management-console]]

## Procedimiento

### Gestionar los tags desde la consola de OVHcloud

Puede gestionar los tags de sus productos de OVHcloud a través de la interfaz general de gestión de tags o a través de las interfaces específicas de los productos.

Los tags son metadatos en forma de pares clave-valor que se añaden a los recursos de OVHcloud y que pueden utilizarse en las políticas IAM o para categorizar los recursos.

#### Tag manager

El <ManagerLink console to="/#/customer/iam/tag-manager">Tag manager</ManagerLink> es la interfaz que le permite gestionar sus tags en todos sus productos de OVHcloud.

La página muestra todos los tags que se encuentran actualmente en sus recursos.

<img className="thumbnail" alt="Página Tag manager con la lista desplegable Tipo de etiqueta y la columna Tipo de etiqueta" src="/images/manage-and-operate/iam/iam-tag-manager/console/tag-manager-01.png" loading="lazy" />

Para cada tag, la lista indica el número de recursos asociados a ese tag y el tipo de tag.

Existen tres tipos de tags:

- Personalizado: creado y gestionado por usted.
- Predefinido: creado por OVHcloud; usted es responsable de asignar este tipo de tag a sus recursos.
- Sistema: creado y asignado automáticamente por OVHcloud a sus recursos (no se puede eliminar).

Por defecto, la lista desplegable **Tipo de etiqueta** está establecida en <code className="action">Todos los tipos</code>, y la página también muestra los tags predefinidos no asignados. Para restringir la lista, seleccione <code className="action">Personalizado</code>, <code className="action">Predefinido</code>, <code className="action">Sistema</code> o <code className="action">No asignado</code> en esta lista desplegable.

Haga clic en un tag para abrir sus detalles, con la lista de recursos a los que está asignado.

<img className="thumbnail" alt="Página de un tag con los botones Asignar a recursos y Desasignar tag" src="/images/manage-and-operate/iam/iam-tag-manager/console/tag-manager-02.png" loading="lazy" />

A continuación, puede asignar este tag a otros recursos con el botón <code className="action">Asignar a recursos</code>. Se mostrará la lista de todos los recursos de la cuenta, que permite realizar una selección múltiple.

Un campo de búsqueda le ayuda a encontrar los recursos.

Por el contrario, para retirar el tag de algunos recursos, selecciónelos en los detalles del tag y haga clic en <code className="action">Desasignar tag</code>.

#### Panel de control del producto

En algunos productos de OVHcloud se ha añadido una interfaz que permite gestionar los tags directamente desde el panel de gestión del recurso.

La interfaz de gestión de tags permite añadir o retirar tags del recurso.

Puede seleccionar uno o varios tags de la lista de tags predefinidos o introducir sus propios tags escribiendo directamente las claves y los valores en los campos.

### Gestionar los tags a través de la API

La gestión de tags está centralizada en una única API para todos los productos de OVHcloud:

| **Método** |               **Ruta**                |          **Descripción**           |
| :--------: | :-----------------------------------: | :--------------------------------: |
|    POST    |    /iam/resource/&#123;resourceURN&#125;/tag    |   Añadir un tag a un recurso    |
|    DEL     | /iam/resource/&#123;resourceURN&#125;/tag/&#123;key&#125; | Retirar un tag de un recurso |

El tag debe indicarse con el siguiente formato:

```json
{
  "key": "environment",
  "value": "production"
}
```

### Utilizar los tags en las políticas IAM

Los tags pueden utilizarse como condiciones en las políticas IAM mediante la condición `resource.Tag(tag_key)`.

Por ejemplo, la siguiente política concede permisos a todos los VPS que tengan el tag `Environment:Production`:

```json
{
  "conditions": {
    "conditions": [
      {
        "operator": "MATCH",
        "values": {
          "resource.Tag(Environment)": "Production"
        }
      }
    ],
    "operator": "AND"
  },
  "description": "Give access to VPS with tag Environment:Production",
  "identities": [
    "urn:v1:eu:identity:group:aa1-ovh/devs"
  ],
  "name": "vps-production",
  "permissions": {
    "allow": [
      {
        "action": "vps:apiovh:*"
      }
    ]
  },
  "resources": [
    {
      "urn": "urn:v1:eu:resource:vps:*"
    }
  ]
}
```
