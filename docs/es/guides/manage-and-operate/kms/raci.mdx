## Objetivo

El RACI que figura a continuación detalla el reparto de responsabilidades entre OVHcloud y el cliente para el servicio OKMS. Este modelo puede ayudar al cliente a sacar el máximo partido del servicio.

| Roles |
| --- |
|R : Está a cargo de la **R**ealización del proceso|
|A : Es el **A**probador de la realización del proceso|
|C : Es **C**onsultado durante el proceso|
|I : Es **I**nformado de los resultados del proceso|
