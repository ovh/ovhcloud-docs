## Objetivo

¿Quiere utilizar MySQL o MariaDB para sus bases de datos?

### Qué es una base de datos MySQL

MySQL es un sistema de gestión de bases de datos relacionales desarrollado para obtener un rendimiento en lectura superior al que ofrecen otros sistemas.

Este motor es *open source*, y actualmente es desarrollado por Oracle.

### Qué es una base de datos MariaDB

MariaDB es un derivado (*fork*) del sistema de gestión de bases de datos MySQL.

Este motor es 100% compatible y más "libre" que su hermano mayor MySQL. Al contrario que la versión de Oracle, todos los bugs y roadmaps están disponibles públicamente.

**Descubra cómo crear y gestionar sus bases de datos MySQL o MariaDB**

## Procedimiento

### Conexión a la base de datos

:::info
Esta oferta no da acceso al Host, sino a las bases de datos alojadas en él. Los comandos SQL genéricos funcionan sin ningún problema, y los programas como HeidiSQL o SQuirreL SQL son totalmente compatibles.

:::

:::info
Como MariaDB es un derivado de MySQL, los distintos comandos son exactamente los mismos para estos 2 tipos de bases de datos.

:::

Para conectarse a su base de datos, asegúrese de disponer de:

- la dirección de su instancia Web Cloud Databases
- el puerto de su instancia Web Cloud Databases
- el nombre de usuario de su instancia Web Cloud Databases
- la contraseña asociada al usuario
- el nombre de su base de datos

Toda esta información está disponible en la consola de OVHcloud, en la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.

También hay una guía disponible: [Primeros pasos con Web Cloud Databases](/guides/web-cloud/databases/db-getting-started).

#### Conexión en línea de comandos

```bash
mysql --host=server --user=user --port=port --password=password database_name
```

#### Conexión mediante un script PHP

```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

#### Conexión mediante software (SQuirreL SQL)

- Inicie SQuirreL SQL y haga clic en <code className="action">Aliases</code> y, a continuación, en <code className="action">+</code>.

<img className="thumbnail" alt="iniciar SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Rellene los campos siguientes y valide con el botón <code className="action">OK</code>:
    - **Name**: Elija un nombre
    - **Driver**: Elija `MySQL Driver`
    - **URL**: Indique la dirección del servidor y el puerto con el formato `jdbc:mysql://server:port`
    - **User Name**: Indique el nombre de usuario
    - **Password**: Indique la contraseña

<img className="thumbnail" alt="configuración de la conexión" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Valide de nuevo con el botón <code className="action">Connect</code>.

<img className="thumbnail" alt="validación de la conexión" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

Ya está conectado a su base de datos:

<img className="thumbnail" alt="configuración de la conexión" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

#### Conexión mediante phpMyAdmin

Puede utilizar phpMyAdmin para explorar el contenido de su base de datos. Para ello, instale phpMyAdmin en su propio servidor o en su alojamiento web. Durante la instalación, asegúrese de configurar correctamente la información de su servidor Web Cloud Databases y de la base de datos deseada para que phpMyAdmin pueda conectarse a ella.

### Exportar e importar una base de datos MySQL o MariaDB

- **Exportar mi base de datos en línea de comandos**

```bash
mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql
```

- **Importar mi base de datos en línea de comandos**

```bash
cat database_name.sql | mysql --host=server --user=user --port=port --password=password database_name
```

:::info
En algunos casos, es posible que la RAM disponible en su instancia Web Cloud Databases no permita realizar la exportación o la importación deseada. En ese caso, le recomendamos que utilice la herramienta de importación proporcionada por OVHcloud. Consulte la documentación "[Primeros pasos con Web Cloud Databases](/guides/web-cloud/databases/db-getting-started#importar-una-base-de-datos)" si es necesario.

:::
