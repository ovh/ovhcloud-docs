## Objetivo

**Valkey** es un almacén de datos **en memoria**, de código abierto, compatible con los clientes y los protocolos del ecosistema Redis (RESP, REdis Serialization Protocol). Resulta adecuado para **cachés**, **sesiones**, **colas ligeras** y **contadores** de alto rendimiento.

**Descubra cómo conectarse a su instancia Valkey en Web Cloud Databases: autorización de las direcciones IP, obtención de los parámetros de conexión y prueba desde un cliente de línea de comandos.**

:::warning
Proteja el acceso a su instancia (IP autorizadas, contraseñas robustas) y realice pruebas en preproducción antes de la puesta en producción.

:::

## Procedimiento

### Parte 1 — Autorizar la dirección IP de acceso

Por defecto, su instancia Valkey rechaza las conexiones públicas. Para autorizar (incluir en la lista blanca) la dirección IP desde la que se conecta, consulte nuestra guía "[Web Cloud Databases - ¿Cómo autorizar una dirección IP?](/guides/web-cloud/databases/db-authorise-ip-mask)"

Repita la operación para cada máquina que deba acceder a su instancia Valkey.

#### Definir la contraseña del usuario `default`

Su instancia Valkey incluye un usuario `default`, la única cuenta disponible: utilícela para conectarse.

:::warning
La contraseña de este usuario nunca se muestra en el área de cliente de OVHcloud. Debe cambiarla al menos una vez para conocerla.

:::

#### Guardar sus datos

Conserve los siguientes datos:

- Nombre del host
- Puerto
- Contraseña del usuario `default`

Estos elementos son necesarios para probar la conexión a su instancia desde un cliente Valkey o desde su aplicación.

### Parte 3 — Probar la conexión con un cliente de línea de comandos

Para comprobar que su instancia Valkey funciona, conéctese a ella por primera vez:

#### Instalar el cliente de conexión

En este ejemplo utilizamos el cliente `redis-cli`, compatible con Valkey y fácil de instalar. Puede utilizar el cliente que prefiera. Abra un terminal y ejecute el siguiente comando según su sistema operativo.

<Tabs>
  <Tab label="Debian/Ubuntu">
    ```bash
    sudo apt update && sudo apt -y install redis-tools
    ```
  </Tab>
  <Tab label="AlmaLinux/Rocky">
    ```bash
    sudo dnf -y install redis
    ```
  </Tab>
  <Tab label="macOS">
    Instale [Homebrew](https://brew.sh/es/) siguiendo las instrucciones de su sitio web y, a continuación, instale `redis-cli`:

    ```bash
    brew install redis
    ```
  </Tab>
  <Tab label="Windows">
    En el menú Inicio, escriba `PowerShell`, haga clic con el botón derecho en el resultado y, a continuación, haga clic en <code className="action">Ejecutar como administrador</code>.

    Instale [Chocolatey](https://chocolatey.org/install) ejecutando el siguiente comando:

    ```powershell
    Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
    ```

    Instale `redis-cli`:

    ```powershell
    choco install redis-64 -y
    ```
  </Tab>
</Tabs>

Una vez instalado el cliente, compruebe que funciona ejecutando el siguiente comando:

```bash
redis-cli --version
```

#### Conectarse a la instancia

En su terminal, ejecute el siguiente comando:

```bash
redis-cli -h <hostname> -p 6379
```

Sustituya `<hostname>` por su nombre de host y `6379` por su puerto si es diferente. Para obtener estos valores, consulte la sección "[Parte 2 — Preparar los parámetros de conexión](#get-credentials)".

#### Comprobar que todo funciona

Si la conexión se establece correctamente, aparecerá el prompt de su instancia. Autentíquese con el comando `AUTH`, sustituyendo `<password>` por la contraseña del usuario `default`:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> AUTH <password>
OK
```

A continuación, compruebe que el servidor responde:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> PING
```

La base de datos debe responder:

```console
PONG
```

Pruebe también:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> SET ovh-test-connexion "hello"
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> GET ovh-test-connexion
```

Debería ver:

```console
"hello"
```

Elimine la clave de prueba:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> DEL ovh-test-connexion
```

Para salir, escriba:

```console
aaXXXXX-XXX.eu.clouddb.ovh.net:6379> QUIT
```

Si las pruebas anteriores funcionan, su instancia Valkey está operativa.
