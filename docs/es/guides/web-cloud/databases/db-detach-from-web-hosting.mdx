## Objetivo

Las soluciones [Web Cloud Databases](/links/web/databases) pueden activarse gratuitamente desde nuestros [planes de alojamiento web](/links/web/hosting) Performance, Agency, Agency Plus y Agency Max. En ese caso, estarán asociadas al alojamiento web desde el que se hayan activado. Durante el uso de sus servicios, es posible que tenga que desvincular su solución Web Cloud Databases del alojamiento web al que está asociada.

**Descubra cómo desvincular su solución Web Cloud Databases de un alojamiento web.**

## Requisitos

- Disponer de una [instancia Web Cloud Databases](/links/web/databases) asociada a un plan de [alojamiento web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max.
- Ser, como mínimo, el contacto "[Administrador](/guides/account-and-service-management/account-information/managing-contacts)" de los servicios sobre los que quiera actuar.

[[cpnav:web-hosting]]

## Procedimiento

Haga clic en las pestañas siguientes para ver cada una de las **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y seleccione el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la sección **Bases de datos**, encontrará la mención **Web Cloud DB**. Haga clic en el botón <code className="action">⋮</code> situado a su derecha y luego en <code className="action">Desvincular mi base de datos PrivateSQL</code>.

    <img className="thumbnail" alt="Sección Bases de datos y menú de la línea Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la nueva página que se abre, seleccione la duración de **Compromiso** que desee para su solución Web Cloud Databases. El **Resumen** le recuerda que su base de datos se facturará a partir de ahora al precio estándar y que esta acción es irreversible. Haga clic en <code className="action">Siguiente</code> y siga los pasos indicados hasta el pago.

    <img className="thumbnail" alt="Página Desvincular mi base de datos PrivateSQL, con la oferta, el compromiso y el resumen" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/detach-web-cloud-db.png" loading="lazy" />
  </Tab>
</Tabs>

Una vez realizadas estas 3 etapas y pagada la orden de pedido, su solución Web Cloud Databases se desvinculará en un plazo máximo de unas horas.
