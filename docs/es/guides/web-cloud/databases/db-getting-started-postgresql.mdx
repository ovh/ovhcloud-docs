¿Quiere utilizar PostgreSQL en Web Cloud Databases? Descubra cómo crear y administrar fácilmente sus bases de datos alojadas en esta solución.

## Introducción

### Requisitos
Para seguir los pasos de esta guía, es necesario:

- tener una instancia Web Cloud Databases;
- haber consultado [esta guía](/guides/web-cloud/databases/db-getting-started).

### Qué es una base de datos PostgreSQL
PostgreSQL es un sistema de gestión de bases de datos relacional y orientado a objetos.

Es un sistema robusto y extensible, capaz de manipular con total fiabilidad grandes volúmenes de datos.

Además, tiene una comunidad *open source* muy activa.

## Conexión a la base de datos

:::info
Tenga en cuenta que esta solución no da acceso al Host, sino a las bases de datos alojadas en él. Los comandos SQL genéricos funcionan sin ningún problema, y los programas como HeidiSQL o SQuirreL SQL son totalmente compatibles.

:::

Para conectarse a su base de datos, asegúrese de disponer de lo siguiente:

- la dirección de su instancia de base de datos
- el puerto de su base de datos
- el nombre de usuario de su base de datos
- la contraseña de su base de datos
- el nombre de su base de datos

Toda esta información está disponible en la consola de OVHcloud, en la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.

También está disponible una guía: [Primeros pasos con Web Cloud Databases](/guides/web-cloud/databases/db-getting-started).

### Conexión en línea de comandos

```bash
psql --host=server --port=port --username=user --password database_name
```

### Conexión mediante un script PHP

```php
1. <?php
2. $myPDO = new PDO('pgsql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

### Conexión a través de la aplicación SQuirreL SQL
Ejecute SQuirreL SQL, abra el menú <code className="action">Aliases</code> y haga clic en <code className="action">+</code>.

<img className="thumbnail" alt="ejecutar SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

Cumplimente los campos como se indica a continuación y acepte con el botón <code className="action">OK</code>:

- **Name**: Indique un nombre.
- **Driver**: Seleccione <code className="action">PostgreSQL</code>.
- **URL**: Indique la dirección del servidor y el puerto en formato jdbc:postgresql://server:port/database.
- **User Name**: Indique el nombre de usuario.
- **Password**: Indique la contraseña.

<img className="thumbnail" alt="configuración de la conexión" src="/images/assets/screens/other/web-tools/squirrel/add-alias-pgsql.png" loading="lazy" />

Confirme con el botón <code className="action">Connect</code>.

<img className="thumbnail" alt="confirmación de la conexión" src="/images/assets/screens/other/web-tools/squirrel/connect-to-pgsql.png" loading="lazy" />

Se establecerá la conexión a la base de datos:

## Extensiones de PostgreSQL disponibles

Web Cloud Databases ofrece varias extensiones de PostgreSQL que permiten añadir funcionalidades adicionales a sus bases de datos. Puede activarlas y desactivarlas desde la consola de OVHcloud, en la pestaña <code className="action">Bases de datos</code> de su instancia.

Para ver la lista de extensiones disponibles, consulte la guía "[Activar las extensiones de PostgreSQL](/guides/web-cloud/databases/db-enable-postgresql-extensions#extensiones-disponibles)".

## Exportar e importar una base de datos PostgreSQL

- **Exportar mi base de datos en línea de comandos**

```bash
pg_dump --host=server --port=port --username=user --password database_name > database_name.sql
```

- **Importar mi base de datos en línea de comandos**

```bash
psql --host=server --port=port --username=user --password database_name < database_name.sql
```

:::info
En algunos casos, es posible que la RAM disponible en su instancia Web Cloud Databases no permita realizar la exportación o la importación deseada. En ese caso, le recomendamos utilizar la herramienta de importación proporcionada por OVHcloud. Si lo necesita, consulte la documentación "[Primeros pasos con Web Cloud Databases](/guides/web-cloud/databases/db-getting-started#importar-una-base-de-datos)".

:::
