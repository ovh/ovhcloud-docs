## Configurar su servicio Web Cloud Databases

Configure y administre su servicio OVHcloud Web Cloud Databases: acceso, bases de datos, usuarios y permisos, conexión, extensiones PostgreSQL y logs.

Para orientarse según sus necesidades:

- **¿Quiere abrir el acceso y conectarse a sus bases de datos?** Consulte la sección *Acceso y conexión*.
- **¿Gestiona sus bases de datos, usuarios y sus permisos?** Consulte la sección *Bases de datos y usuarios*.
- **¿Administra el servidor (configuración, logs)?** Consulte la sección *Servidor y explotación*.
