## Web Cloud Databases

[OVHcloud Web Cloud Databases](/links/web/databases) es un servicio de bases de datos gestionadas (MySQL, PostgreSQL y MariaDB) para sus sitios web y aplicaciones, que puede utilizarse con un alojamiento web, un VPS u otros productos de OVHcloud. Esta página reúne toda la documentación, organizada por tema: desde los primeros pasos hasta la configuración, pasando por la migración.
