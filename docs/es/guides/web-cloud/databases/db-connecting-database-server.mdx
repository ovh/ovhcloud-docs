## Objetivo

Es posible consultar el contenido de la base de datos a través de una interfaz. Para ello, existen varias formas de conectarse.

**Descubra cómo conectarse a una base de datos en su servidor de bases de datos.**

## Requisitos

- Una [instancia Web Cloud Databases](/links/web/databases) (incluida en un plan de [alojamiento web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max).

[[cpnav:web-cloud-databases]]

## Procedimiento

:::info
Las soluciones [Web Cloud Databases](/links/web/databases) no permiten acceder al sistema de gestión de bases de datos, sino a las bases de datos alojadas en él.

- No hay acceso de superusuario "root".
- Los comandos genéricos SQL funcionan con normalidad, y software como HeidiSQL, SQuirreL SQL o Adminer es totalmente compatible.

:::

### Conectarse a una base de datos MySQL o MariaDB

:::info
Como MariaDB es un derivado de MySQL, los comandos son exactamente los mismos para los dos tipos de bases de datos.

:::

#### Conexión a través de phpMyAdmin de OVHcloud

Haga clic en las pestañas de abajo para ver cada uno de los **4** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Obtenga la siguiente información de conexión:

    - **Servidor (nombre de host) y puerto:** visibles en la pestaña <code className="action">Vista general</code>, sección **SQL**, datos **Nombre de host** y **Puerto**.
    - **Usuario:** visible en la pestaña <code className="action">Usuarios y permisos</code>.
    - **Contraseña:** la contraseña asociada al usuario. Si la ha olvidado, acceda a la pestaña <code className="action">Usuarios y permisos</code>, haga clic en el botón <code className="action">⋮</code> del usuario correspondiente y luego en <code className="action">Cambiar contraseña</code>.

    <img className="thumbnail" alt="Sección SQL de la vista general con el nombre de host y el puerto" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />

    :::warning
    Si cambia la contraseña de un usuario de la base de datos, todas las aplicaciones o sitios web que acceden a esta base de datos deben actualizarse en consecuencia.

    :::

  </Tab>
  <Tab label="Paso 3">
    En la pestaña <code className="action">Vista general</code>, sección **SQL**, haga clic en el botón <code className="action">⋮</code> a la derecha de **Acciones adicionales** y luego en <code className="action">Interfaz de administración</code>. phpMyAdmin se abre en una nueva pestaña de su navegador.

    <img className="thumbnail" alt="Menú Acciones adicionales de la sección SQL con la entrada Interfaz de administración" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-additional-actions.png" loading="lazy" />

    :::info
    Si la entrada **Interfaz de administración** no aparece en el menú, phpMyAdmin de OVHcloud no está disponible para su instancia. En ese caso, utilice uno de los métodos de la sección "[Conexión a la base de datos fuera de la consola de OVHcloud](#connexion-à-la-base-de-données-hors-espace-client)".

    :::

  </Tab>
  <Tab label="Paso 4">
    En la página de conexión de phpMyAdmin, introduzca la información obtenida en el paso 2:

    <img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-login-web-cloud-db.png" loading="lazy" />

    - **Servidor:** introduzca el *nombre de host* seguido del *número de puerto*, separados por "**:**" o un "**espacio**". Por ejemplo: **aaXXXXX-XXX.eu.clouddb.ovh.net:12345**.
    - **Usuario:** introduzca el *nombre de usuario*.
    - **Contraseña:** introduzca la *contraseña*.
  </Tab>
</Tabs>

Si la conexión se ha realizado correctamente, se mostrará la siguiente página.

<img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-main-page-web-cloud-db.png" loading="lazy" />

:::warning
**En caso de error:**

- Error #1045 significa que las credenciales son incorrectas. Compruebe el nombre de usuario y/o la contraseña.
- Error #2005 significa que debe comprobar el nombre del servidor y si este está en funcionamiento.

:::

#### Conexión a la base de datos fuera de la consola de OVHcloud <a name="connexion-à-la-base-de-données-hors-espace-client"></a>

:::warning
Si utiliza una solución "Web Cloud Databases"/"SQL Privado", recuerde autorizar su IP utilizando la guía sobre la [configuración de su servidor de bases de datos](/guides/web-cloud/databases/db-configure-optimise-database-server#gestionar-los-accesos).

:::

Haga clic en las pestañas de abajo para ver cada uno de los **2** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Obtenga la siguiente información de conexión:

    - **Servidor (nombre de host):** visible en la pestaña <code className="action">Vista general</code>, sección **SQL**, dato **Nombre de host**.
    - **Puerto:** visible en el mismo lugar, dato **Puerto**.
    - **Usuario:** visible en la pestaña <code className="action">Usuarios y permisos</code>.
    - **Contraseña:** la contraseña asociada al usuario correspondiente.
    - **Nombre de la base de datos:** visible en la pestaña <code className="action">Bases de datos</code>.

    <img className="thumbnail" alt="Sección SQL de la vista general con el nombre de host y el puerto" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />
  </Tab>
</Tabs>

**Haga clic en el método de conexión que desee para ver su contenido.**

<details>

<summary>Conexión en línea de comandos</summary>

```bash
mysql --host=server --user=user --port=port --password=password database_name
```

</details>

<details>

<summary>Conexión mediante script PHP</summary>

```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

</details>

<details>

<summary>Conexión a través de la aplicación SQuirreL SQL</summary>

:::info
En nuestro ejemplo, utilizamos el software de código abierto SQuirreL, pero otras interfaces como HeidiSQL o Adminer son totalmente compatibles.

:::

- Inicie SQuirreL SQL y haga clic en <code className="action">Aliases</code> y, a continuación, en <code className="action">+</code>

<img className="thumbnail" alt="iniciar SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Rellene los campos siguientes y valide con el botón <code className="action">OK</code>:
    - **Name**: Elija un nombre
    - **Driver**: Elija "MySQL Driver"
    - **URL**: Indique la dirección del servidor y el puerto con el formato `jdbc:mysql://server:port`
    - **User Name**: Indique el nombre de usuario
    - **Password**: Indique la contraseña

<img className="thumbnail" alt="configuración de la conexión" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Valide de nuevo con el botón <code className="action">Connect</code>

<img className="thumbnail" alt="validación de la conexión" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

Ya está conectado a su base de datos:

<img className="thumbnail" alt="configuración de la conexión" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

</details>

<details>

<summary>Conexión mediante phpMyAdmin</summary>

Puede utilizar su propia interfaz phpMyAdmin para explorar el contenido de su base de datos. Para ello, instale phpMyAdmin en su propio servidor o alojamiento web. Durante la instalación, asegúrese de configurar correctamente la información de su servidor de bases de datos y de la base de datos deseada para que phpMyAdmin pueda conectarse a ella.

</details>
