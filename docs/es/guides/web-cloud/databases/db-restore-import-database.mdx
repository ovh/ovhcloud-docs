## Objetivo

Si se produce un error en la base de datos, es necesario poder restaurar una copia de seguridad o importar una base de datos local.

**Esta guía explica cómo restaurar e importar la base de datos en un servidor de bases de datos.**

## Requisitos

- Tener una [instancia Web Cloud Databases](/links/web/databases) (incluida en un plan de [alojamiento web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max).

[[cpnav:web-cloud-databases]]

## Procedimiento

:::info
Las soluciones [Web Cloud Databases](/links/web/databases) no permiten acceder al sistema de gestión de bases de datos, sino a las bases de datos alojadas en él.

- No hay acceso de superusuario "root".
- Los comandos genéricos SQL funcionan con normalidad, y software como HeidiSQL, SQuirreL SQL o Adminer es totalmente compatible.

:::

### Restaurar e importar una base de datos desde la consola de OVHcloud <a name="restaurar-e-importar-una-base-de-datos-desde-el-área-de-cliente"></a>

#### Restaurar una copia de seguridad existente

Haga clic en las pestañas siguientes para ver cada uno de los **4** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Bases de datos</code>.

    En la columna **Copias de seguridad**, la cifra corresponde al número de copias de seguridad disponibles para cada base de datos.

    <img className="thumbnail" alt="Pestaña Bases de datos de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    En la tabla, haga clic en el botón <code className="action">⋮</code> de la columna **Acciones**, a la derecha de la base de datos correspondiente, y luego en <code className="action">Ver copias de seguridad</code>.

    <img className="thumbnail" alt="Menú de una línea de la tabla de bases de datos de Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 4">
    Se abrirá a la derecha un panel titulado **Copias de seguridad**, seguido del nombre de la base de datos. Haga clic en el botón <code className="action">⋮</code> a la derecha de la copia de seguridad elegida y luego en <code className="action">Restaurar</code>.

    <img className="thumbnail" alt="Panel de copias de seguridad de una base de datos con el menú de una copia abierto" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/backup-actions-menu.png" loading="lazy" />

    En la ventana **Restaurar una copia de seguridad** que se abre, confirme haciendo clic en <code className="action">Restaurar</code>. Se mostrará el mensaje **Restauración iniciada**.

    <img className="thumbnail" alt="Ventana de confirmación de la restauración de una copia de seguridad" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/restore-backup-dialog.png" loading="lazy" />

    :::warning
    La restauración implica la sobrescritura del contenido de la base de datos y, por tanto, una posible pérdida de datos. Si no está seguro de lo que hace, le recomendamos que realice una copia de seguridad antes.

    :::

  </Tab>
</Tabs>

#### Importar una copia de seguridad local

Haga clic en las pestañas siguientes para ver cada uno de los **4** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Bases de datos</code>.

    <img className="thumbnail" alt="Pestaña Bases de datos de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    En la tabla, haga clic en el botón <code className="action">⋮</code> de la columna **Acciones**, a la derecha de la base de datos correspondiente, y luego en <code className="action">Importar</code>.

    <img className="thumbnail" alt="Menú de una línea de la tabla de bases de datos Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 4">
    Se abre la ventana **Importar una base de datos**. ***Tiene dos opciones***, que ofrecen los dos botones situados en la parte superior de la ventana:

    **1 - Subir un nuevo archivo**

    Esta opción está seleccionada por defecto al abrir la ventana.

    En el campo **Nombre del archivo**, indique un nombre para el archivo importado. A continuación, haga clic en la zona <code className="action">Archivo a importar</code> para seleccionar el archivo en su ordenador, o arrástrelo a esta zona.

    :::warning
    El archivo debe tener el formato ".sql", ".txt" o ".gz".

    :::

    <img className="thumbnail" alt="Ventana Importar una base de datos con la opción Subir un nuevo archivo seleccionada" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/database-import-new-file-step-2.png" loading="lazy" />

    Si lo desea, marque la casilla **Vaciar la base de datos antes de la importación**. La casilla **Recibir un correo electrónico al finalizar la importación** está marcada por defecto: le permite estar informado del fin de la operación en la dirección de correo electrónico de referencia de su cuenta de OVHcloud. Por último, haga clic en <code className="action">Confirmar</code>: el archivo se envía y, a continuación, se inicia la importación.

    **2 - Utilizar un archivo existente**

    Si ya ha importado un archivo anteriormente, haga clic en <code className="action">Usar un archivo existente</code>.

    En la lista desplegable **Documento existente**, seleccione el archivo entre los que ya están en su cuenta de OVHcloud.

    <img className="thumbnail" alt="Ventana Importar una base de datos con la opción Usar un archivo existente seleccionada" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/database-import-existing-file-step-2.png" loading="lazy" />

    Si lo desea, marque la casilla **Vaciar la base de datos antes de la importación**. La casilla **Recibir un correo electrónico al finalizar la importación** está marcada por defecto: le permite estar informado del fin de la operación en la dirección de correo electrónico de referencia de su cuenta de OVHcloud. Por último, haga clic en <code className="action">Confirmar</code> para iniciar la importación.
  </Tab>
</Tabs>

### Importar una base de datos fuera de la consola de OVHcloud <a name="importar-una-base-de-datos-fuera-del-área-de-cliente"></a>

En algunos casos, la RAM disponible en su servidor de bases de datos no permite realizar la importación deseada fuera de la consola de OVHcloud. En ese caso, le recomendamos que utilice la herramienta de OVHcloud en la consola de OVHcloud. Consulte la sección "[Restaurar e importar una base de datos desde la consola de OVHcloud](#restaurar-e-importar-una-base-de-datos-desde-el-área-de-cliente)" de esta guía.

**Haga clic en el método de importación que prefiera para ver el contenido.**

<details>

<summary>Importar una base MySQL o MariaDB desde phpMyAdmin</summary>

Para importar su base de datos directamente desde phpMyAdmin, es necesario conectarse previamente. Para ello, consulte el apartado "[Conectarse a una base de datos MySQL o MariaDB](/guides/web-cloud/databases/db-connecting-database-server#conectarse-a-una-base-de-datos-mysql-o-mariadb)".

Una vez conectado a phpMyAdmin, seleccione la base de datos haciendo clic en su nombre.

A continuación, abra la pestaña <code className="action">Importar</code>.

Seleccione el archivo de backup haciendo clic en <code className="action">Navegar</code> (el archivo no puede superar los 100 MB).

:::info
Le recomendamos que fraccione su base de datos en varios archivos cuando supere los 100 MB y realice varias importaciones desde phpMyAdmin.
La importación de archivos que superen los 100 MB puede realizarse desde la consola de OVHcloud siguiendo el paso "[Restaurar e importar una base de datos desde la consola de OVHcloud](#restaurar-e-importar-una-base-de-datos-desde-el-área-de-cliente)".

:::

Deje las opciones predeterminadas y haga clic en <code className="action">Ejecutar</code> para iniciar la importación.

<img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-upload-backup-web-cloud-db.png" loading="lazy" />

</details>

<details>

<summary>Importar una base de datos MySQL o MariaDB en línea de comandos</summary>

Esta operación solo es posible por [SSH](/guides/web-cloud/web-hosting/ssh-on-webhosting) desde un alojamiento compartido de OVHcloud.

```bash
cat nombre_de_la_base.sql | mysql --host=servidor --user=usuario --port=puerto --password=contraseña nombre_de_la_BD
```

</details>

<details>

<summary>Importar una base de datos MySQL o MariaDB desde un archivo PHP</summary>

```php
1. <?php
2. echo "La base de datos se está restaurando.......<br/>";
3. system("cat nombre_de_la_base.sql | mysql --host=servidor --user=usuario --port=puerto --password=contraseña nombre_de_la_BD");
4. echo "Completado. Su base de datos está instalada en este alojamiento.";
5. ?>
```

:::warning
- Para evitar que alguien acceda a este archivo, que contiene datos sensibles, proteja el acceso siguiendo la guía: [¿Cómo proteger con contraseña el acceso a un directorio?](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password)
- Esta acción solo es posible desde un alojamiento compartido de OVHcloud.

:::

</details>

<details>

<summary>Importar una base de datos PostgreSQL en línea de comandos</summary>

Esta operación solo es posible por [SSH](/guides/web-cloud/web-hosting/ssh-on-webhosting) desde un alojamiento compartido de OVHcloud en versión estable o superior.

```bash
psql --host=servidor --port=puerto --user=usuario --password=contraseña nombre_de_la_BD < nombre_de_la_BD.sql
```

</details>

<details>

<summary>Importar una base de datos PostgreSQL desde un archivo PHP</summary>

```php
1. <?php
2. echo "La base de datos se está restaurando.......<br/>";
3. system("PGPASSWORD=contraseña psql --host=servidor --port=puerto --user=usuario --password=contraseña nombre_de_la_BD < nombre_de_la_BD.sql");
4. echo "Completado. Su base de datos está instalada en este alojamiento.";
5. ?>
```

:::warning
- Para evitar que alguien acceda a este archivo con datos sensibles, proteja el acceso siguiendo la guía: [¿Cómo proteger con contraseña el acceso a un directorio?](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password)
- Esta acción solo es posible desde un alojamiento compartido de OVHcloud.

:::

</details>
