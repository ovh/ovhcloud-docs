## Objetivo

Una base de datos (DB) permite almacenar elementos denominados dinámicos, como comentarios o artículos, por ejemplo. Prácticamente todos los sistemas de gestión de contenidos (CMS), como WordPress o Joomla!, utilizan bases de datos.

**Esta guía explica cómo crear una base de datos en un servidor de bases de datos y dar acceso a los usuarios.**

## Requisitos

- Disponer de una [instancia Web Cloud Databases](/links/web/databases) (incluida en un plan de [alojamiento web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max).

[[cpnav:web-cloud-databases]]

## Procedimiento

### Crear una base de datos

Haga clic en las pestañas de abajo para ver cada uno de los **4** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Bases de datos</code>.

    <img className="thumbnail" alt="Pestaña Bases de datos de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    Haga clic en <code className="action">Añadir una base de datos</code>, encima de la tabla de bases de datos.

    <img className="thumbnail" alt="Botón Añadir una base de datos encima de la tabla de bases de datos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    La creación de esquemas PostgreSQL no está disponible actualmente en los servidores Web Cloud Databases.

    :::

  </Tab>
  <Tab label="Paso 4">
    El panel **Añadir una base de datos** se abre a la derecha. Complete los campos siguiendo los criterios indicados debajo de cada uno de ellos:

    - **Nombre de la base de datos** (obligatorio): es el nombre de su futura base de datos.
    - **Acceso a esta base de datos**: elija quién podrá conectarse a la base de datos y realizar consultas en ella.
        - **Ningún acceso por ahora** (opción por defecto): la base de datos se crea sin usuario. Podrá asignar permisos a un usuario más adelante.
        - **Un usuario existente**: seleccione el **Usuario** y, a continuación, sus **Permisos** sobre la base de datos.
        - **Un usuario nuevo**: complete los campos siguientes para crear el usuario al mismo tiempo que la base de datos.
    - **Nombre de usuario** (solo con **Un usuario nuevo**): el usuario que podrá conectarse a su base de datos y realizar consultas.
    - **Permisos** (con **Un usuario existente** o **Un usuario nuevo**): los permisos asociados al usuario en la base de datos. Para un uso estándar, seleccione `Admin`. Los permisos pueden modificarse posteriormente.
    - **Contraseña**/**Confirmar la contraseña** (solo con **Un usuario nuevo**): introduzca una contraseña y confírmela.

    Haga clic en <code className="action">Añadir</code>.

    <img className="thumbnail" alt="Panel Añadir una base de datos con un usuario nuevo" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

### Crear un usuario

Para utilizar un servidor de bases de datos de OVHcloud, cree usuarios con permisos específicos de conexión a una base de datos.

Haga clic en las pestañas de abajo para ver cada uno de los **4** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Usuarios y permisos</code>.

    <img className="thumbnail" alt="Pestaña Usuarios y permisos de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    Haga clic en <code className="action">Añadir un usuario</code>.
  </Tab>
  <Tab label="Paso 4">
    El panel **Añadir un usuario** se abre a la derecha. Introduzca un **Nombre de usuario** y, a continuación, una **Contraseña** que deberá confirmar en el campo **Confirmar la contraseña**, respetando los criterios indicados debajo de cada campo. Después, haga clic en <code className="action">Añadir</code>.

    <img className="thumbnail" alt="Panel Añadir un usuario y sus tres campos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/add-user.png" loading="lazy" />
  </Tab>
</Tabs>

### Gestionar los permisos de los usuarios

Para permitir que un usuario realice acciones en una base de datos, es necesario asignarle permisos.

Haga clic en las pestañas de abajo para ver cada uno de los **4** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Usuarios y permisos</code>.

    <img className="thumbnail" alt="Pestaña Usuarios y permisos de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    Cada usuario aparece en un recuadro con su nombre. En el recuadro del usuario correspondiente, haga clic en el botón <code className="action">⋮</code> situado a la derecha de la mención **Acciones adicionales** y luego en <code className="action">Gestionar permisos</code>.

    <img className="thumbnail" alt="Menú Acciones adicionales de un usuario y opción Gestionar permisos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 4">
    El panel **Permisos de**, seguido del nombre del usuario, se abre a la derecha. En él se enumeran las bases de datos de su servidor, cada una con un menú desplegable a su derecha que indica el nivel de permisos del usuario sobre esa base de datos. Elija el nivel deseado para cada base de datos. El cambio se aplica inmediatamente: se muestra el mensaje **Permiso modificado**.

    Existen 4 niveles de permisos:

    - `Admin`: autorización de las consultas de tipo **Select / Insert / Update / Delete / Create / Alter / Drop**.
    - `Lectura / Escritura`: autorización de las consultas de tipo **Select / Insert / Update / Delete**.
    - `Solo lectura`: autorización de las consultas de tipo **Select**.
    - `Ninguno`: ningún permiso en la base de datos.

    :::info
    La distribución de los permisos mencionados anteriormente es propia de OVHcloud. Así, un usuario con permisos de `Admin` podrá utilizar **DDL** (Data Definition Language) y **DML** (Data Manipulation Language), mientras que un usuario con permisos de `Lectura / Escritura` solo podrá utilizar **DML** (Data Manipulation Language).

    :::

    <img className="thumbnail" alt="Panel de permisos de un usuario, un nivel por base de datos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />
  </Tab>
</Tabs>

### Eliminar una base de datos

:::warning
Al eliminar una base de datos en un servidor de bases de datos,
no se realiza ninguna verificación de su contenido. La base de datos se
eliminará aunque contenga datos. Por lo tanto, se recomienda crear
una copia de seguridad y descargarla en su equipo antes de cualquier eliminación.

:::

Haga clic en las pestañas de abajo para ver cada uno de los **3** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Bases de datos</code>.

    <img className="thumbnail" alt="Pestaña Bases de datos de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    En la tabla, haga clic en el botón <code className="action">⋮</code> de la columna **Acciones**, a la derecha de la base de datos correspondiente, y luego en <code className="action">Eliminar</code>.

    <img className="thumbnail" alt="Menú de una línea de la tabla de bases de datos Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    En la ventana **Eliminar base de datos** que se abre, confirme la eliminación haciendo clic en <code className="action">Eliminar</code>.

    <img className="thumbnail" alt="Ventana de confirmación de la eliminación de una base de datos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/delete-database-dialog.png" loading="lazy" />
  </Tab>
</Tabs>
