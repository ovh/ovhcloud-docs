## Objetivo

Las extensiones de PostgreSQL son módulos que enriquecen su base de datos con funcionalidades adicionales: nuevos tipos de datos, funciones, operadores o lenguajes procedurales. En una solución Web Cloud Databases, puede activar las extensiones compatibles directamente desde su área de cliente de OVHcloud, sin necesidad de utilizar la línea de comandos.

**Esta guía le explica cómo activar las extensiones disponibles en una base de datos PostgreSQL alojada en una solución Web Cloud Databases.**

## Requisitos

- Disponer de una [instancia Web Cloud Databases](/links/web/databases) que utilice **PostgreSQL**.
- Haber consultado la guía [Empezar con PostgreSQL](/guides/web-cloud/databases/db-getting-started-postgresql).

## Procedimiento

### Activar una extensión

Haga clic en las pestañas de abajo para ver cada uno de los **3** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/#/web/web/private_database">Web Cloud Databases</ManagerLink> y seleccione el servicio correspondiente.

    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Bases de datos</code>. En la columna **"Extensiones"**, haga clic en el icono de la tabla de la base de datos correspondiente.

    <img className="thumbnail" alt="Acceder a las extensiones de una base de datos" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/databases/extensions.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    En la ventana que aparece, localice la extensión que desee en la lista de extensiones disponibles. A continuación, actívela haciendo clic en el icono correspondiente de la columna **"Activo"**.

    <img className="thumbnail" alt="Lista de extensiones de PostgreSQL" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/databases/extensions-list.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
La activación de una extensión se aplica a la base de datos seleccionada. Para activarla en otra base de datos del mismo servidor, repita la operación seleccionando la base de datos correspondiente.

:::

### Extensiones disponibles

La lista de extensiones propuestas depende de la versión de PostgreSQL utilizada por su servidor. Las extensiones disponibles para su versión aparecen en la ventana de activación.

A continuación se muestra la lista de extensiones disponibles:

| Extensión | Descripción |
|---|---|
| `address_standardizer` | Analiza una dirección para descomponerla en sus elementos constituyentes. Generalmente se utiliza para la fase de normalización de direcciones en la geocodificación. |
| `autoinc` | Funciones para el autoincremento de campos. |
| `bloom` | Método de acceso bloom: índice basado en un archivo de firmas. |
| `btree_gin` | Compatibilidad con la indexación de tipos de datos comunes en GIN. |
| `btree_gist` | Compatibilidad con la indexación de tipos de datos comunes en GiST. |
| `citext` | Tipo de datos para cadenas de caracteres que no distinguen entre mayúsculas y minúsculas. |
| `cube` | Tipo de datos para cubos multidimensionales. |
| `earthdistance` | Cálculo de distancias ortodrómicas sobre la superficie de la Tierra. |
| `fuzzystrmatch` | Determina las similitudes y la distancia entre cadenas de caracteres. |
| `hstore` | Tipo de datos para almacenar conjuntos de pares (clave, valor). |
| `intarray` | Funciones, operadores y compatibilidad de indexación para arrays de enteros de una dimensión. |
| `isn` | Tipos de datos para los estándares internacionales de numeración de productos. |
| `ltree` | Tipo de datos para estructuras jerárquicas en forma de árbol. |
| `moddatetime` | Funciones para el seguimiento de la fecha de última modificación. |
| `pg_trgm` | Medición de la similitud de texto y búsqueda por índice basadas en trigramas. |
| `pgcrypto` | Funciones criptográficas. |
| `postgis` | Tipos y funciones espaciales de PostGIS (geometría, geografía y ráster). |
| `postgis_raster` | Tipos y funciones ráster de PostGIS. |
| `postgis_tiger_geocoder` | Geocodificador tiger y geocodificador inverso de PostGIS. |
| `postgis_topology` | Tipos y funciones espaciales de topología de PostGIS. |
| `seg` | Tipo de datos para representar segmentos de línea o intervalos de coma flotante. |
| `unaccent` | Diccionario de búsqueda de texto que elimina los acentos. |
| `uuid-ossp` | Genera identificadores únicos universales (UUID). |
| `xml2` | Consultas XPath y XSLT. |
