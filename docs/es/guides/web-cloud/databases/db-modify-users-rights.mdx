## Objetivo

La solución [Web Cloud Databases](/links/web/databases) puede contener varias bases de datos. Permite definir uno o varios usuarios para la gestión y el uso de las bases de datos. Estos usuarios pueden tener permisos más o menos elevados en función de sus funciones en las bases de datos.
Durante el uso del producto, es posible que necesite modificar los permisos de un usuario en su [Web Cloud Databases](/links/web/databases).

**Descubra cómo modificar los permisos de un usuario en su solución Web Cloud Databases.**

## Requisitos

- Disponer de una solución [Web Cloud Databases](/links/web/databases) y de uno o varios usuarios.

[[cpnav:web-cloud-databases]]

## Procedimiento

:::info
Para crear un nuevo usuario en su solución Web Cloud Databases, consulte la sección **Crear un usuario** de nuestra guía "[Crear bases de datos y usuarios en un servidor de bases de datos](/guides/web-cloud/databases/db-create-databases-users)".

:::

Haga clic en las pestañas siguientes para ver cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la nueva página, haga clic en la pestaña <code className="action">Usuarios y permisos</code>.

    <img className="thumbnail" alt="Pestaña Usuarios y permisos de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Cada usuario aparece en un recuadro con su nombre. En el recuadro del usuario correspondiente, haga clic en el botón <code className="action">⋮</code> situado a la derecha de la mención **Acciones adicionales** y luego en <code className="action">Gestionar permisos</code>.

    <img className="thumbnail" alt="Menú Acciones adicionales de un usuario y opción Gestionar permisos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    El panel **Permisos de**, seguido del nombre del usuario, se abre a la derecha. En él se enumeran todas las bases de datos de su solución Web Cloud Databases y se indica, para cada una de ellas, el nivel de permisos del que dispone su usuario, en un menú desplegable a su derecha.

    <img className="thumbnail" alt="Panel de permisos de un usuario, un nivel por base de datos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-grants.png" loading="lazy" />

    Aquí es donde podrá modificar los permisos de su usuario para cada una de sus bases de datos. Para ello, en cada base de datos correspondiente, basta con seleccionar, en el menú desplegable de la base de datos, el nivel de permisos que quiera asignar a su usuario. La modificación se aplica inmediatamente: se muestra el mensaje **Permiso modificado**.
  </Tab>
</Tabs>
