## Objetivo

Las soluciones [Web Cloud Databases](/links/web/databases) pueden utilizarse con servicios de OVHcloud o externos a OVHcloud.

Por defecto y por motivos de seguridad, en estas soluciones:

- Solo las direcciones IP asociadas a nuestra infraestructura de alojamientos compartidos están autorizadas a acceder al contenido de las bases de datos.
- El acceso a los logs de la solución no está restringido en función de las direcciones IP. Esto permite acceder a ella a través de un ordenador, por ejemplo.

¿Necesita cambiar estos permisos o restricciones?

**Descubra cómo autorizar una o varias direcciones IP para acceder a su solución Web Cloud Databases.**

## Requisitos

- Disponer de una solución [Web Cloud Databases](/links/web/databases).
- Conocer la dirección IP (o el intervalo de direcciones IP) que quiere autorizar en su solución.

[[cpnav:web-cloud-databases]]

## Procedimiento

### Autorizar una dirección IP o un intervalo de direcciones IP

:::info
Le recordamos que, si acaba de activar su solución [Web Cloud Databases](/links/web/databases) y desea utilizarla con un plan de [alojamiento web de OVHcloud](/links/web/hosting), las direcciones IP de estos planes ya están autorizadas por defecto.

:::

Haga clic en las pestañas siguientes para ver cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la página que se abre, haga clic en la pestaña <code className="action">IPs autorizadas</code>.

    <img className="thumbnail" alt="Pestaña IPs autorizadas de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la página que aparece, haga clic en el botón <code className="action">Añadir una IP</code> situado encima de la tabla.

    <img className="thumbnail" alt="Botón Añadir una IP encima de la tabla de IPs autorizadas" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Si quiere modificar una dirección IP o un intervalo de direcciones IP ya autorizado, haga clic directamente en la tabla en el botón <code className="action">⋮</code> de la columna **Acciones**, a la derecha de la línea correspondiente a la dirección IP o al intervalo de direcciones IP que quiera modificar, y luego en <code className="action">Editar</code>. Podrá cambiar su nombre y sus permisos; la dirección IP en sí no puede modificarse.

    <img className="thumbnail" alt="Menú de una línea de la tabla de IPs autorizadas" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Etapa 4">
    En la ventana **Añadir una IP autorizada** que se abre, debe completar varios campos:

    <img className="thumbnail" alt="Ventana Añadir una IP autorizada y sus campos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (obligatorio): Introduzca aquí la dirección IP (por ejemplo, `203.0.113.44`) o el intervalo de direcciones IP (por ejemplo, `203.0.113.0/24`, que representa todas las direcciones IP de `203.0.113.0` a `203.0.113.255`) que desee autorizar en su solución Web Cloud Databases.
    - **Nombre** (obligatorio): Puede, por ejemplo, indicar el rol de la dirección IP o del intervalo de direcciones IP en cuestión.
    - **Permitir acceso al servicio** (marcada por defecto): Marque esta casilla para que la dirección IP o el intervalo de direcciones IP estén autorizados a acceder a las bases de datos presentes en su solución Web Cloud Databases.
    - **Permitir acceso SFTP**: Marque esta casilla para que la dirección IP o el intervalo de direcciones IP estén autorizados a acceder a los logs de su solución Web Cloud Databases.

    :::warning
    Para reforzar la seguridad de su servicio, el rango de direcciones `0.0.0.0/0` ya no está autorizado por defecto. Le invitamos a definir la lista de direcciones IP autorizadas directamente desde la consola de OVHcloud.

    :::

    Una vez introducidos los datos, haga clic en el botón <code className="action">Añadir</code>.
  </Tab>
</Tabs>

## Caso particular

**Haga clic en los siguientes casos para ver la información correspondiente.**

<details>

<summary>La autorización de acceso a los alojamientos web de OVHcloud</summary>

Al activar su solución Web Cloud Databases, la autorización de acceso a los alojamientos web de OVHcloud está activada por defecto.

Si quiere desactivar esta autorización porque no utiliza ningún alojamiento web con su solución Web Cloud Databases, haga clic en las pestañas siguientes para ver cada una de las **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la página que se abre, haga clic en la pestaña <code className="action">IPs autorizadas</code>.

    <img className="thumbnail" alt="Pestaña IPs autorizadas de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la parte superior de la página, en la sección **Acceso a los alojamientos web de OVHcloud**, desactive el interruptor **Permitir que los alojamientos web de OVHcloud accedan a la base de datos**.

    <img className="thumbnail" alt="Sección Acceso a los alojamientos web de OVHcloud y su interruptor" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/web-hosting-access.png" loading="lazy" />

    :::info
    Al desactivar este acceso, también bloqueará el acceso a **phpMyAdmin** a través del enlace disponible en la consola de OVHcloud, y ello para toda su solución Web Cloud Databases.
    :::

  </Tab>
</Tabs>

</details>
