## Objetivo

Su base de datos puede contener una gran cantidad de información esencial para su sitio web. Por lo tanto, es muy importante poder realizar una copia de seguridad o exportarla.

**Esta guía explica cómo realizar el backup y la exportación de la base de datos desde un servidor de bases de datos.**

## Requisitos

- Tener una [instancia Web Cloud Databases](/links/web/databases) (incluida en un plan de [alojamiento web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max).

[[cpnav:web-cloud-databases]]

## Procedimiento

:::info
Las soluciones [Web Cloud Databases](/links/web/databases) no permiten acceder al sistema de gestión de bases de datos, sino a las bases de datos alojadas en él.

- No hay acceso de superusuario "root".
- Los comandos SQL genéricos funcionan con normalidad, y software como HeidiSQL, SQuirreL SQL o Adminer es totalmente compatible.

:::

### Guardar y exportar una base de datos desde la consola de OVHcloud <a name="sauvegarder-et-exporter-une-base-de-données-depuis-lespace-client"></a>

:::info
- Las copias de seguridad se realizan automáticamente una vez al día en todas sus bases de datos.
- Las copias de seguridad automáticas y manuales se conservan durante 30 días. Una vez transcurrido este plazo, se eliminan automáticamente. La fecha de eliminación de cada copia de seguridad se indica en la lista de copias de seguridad de la base de datos.

:::

#### Realizar una copia de seguridad manual

Haga clic en las pestañas de abajo para ver cada uno de los **3** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Bases de datos</code>.

    En la columna **Copias de seguridad**, la cifra corresponde al número de copias de seguridad disponibles para cada base de datos.

    <img className="thumbnail" alt="Pestaña Bases de datos de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    En la tabla, haga clic en el botón <code className="action">⋮</code> de la columna **Acciones**, a la derecha de la base de datos correspondiente, y luego en <code className="action">Hacer copia ahora</code>.

    <img className="thumbnail" alt="Menú de una línea de la tabla de bases de datos Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />

    La copia de seguridad se inicia inmediatamente, sin confirmación. Se muestra el mensaje **Copia de seguridad iniciada**.
  </Tab>
</Tabs>

#### Exportar una copia de seguridad

Haga clic en las pestañas de abajo para ver cada uno de los **4** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Bases de datos</code>.

    En la columna **Copias de seguridad**, la cifra corresponde al número de copias de seguridad disponibles para cada base de datos.

    <img className="thumbnail" alt="Pestaña Bases de datos de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    En la tabla, haga clic en el botón <code className="action">⋮</code> de la columna **Acciones**, a la derecha de la base de datos correspondiente, y luego en <code className="action">Ver copias de seguridad</code>.

    <img className="thumbnail" alt="Menú de una línea de la tabla de bases de datos Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/row-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 4">
    Se abre a la derecha un panel titulado **Copias de seguridad**, seguido del nombre de la base de datos. Las copias de seguridad aparecen ordenadas de la más reciente a la más antigua, cada una con su fecha de creación y su fecha de eliminación.

    Haga clic en el botón <code className="action">⋮</code> a la derecha de la copia de seguridad elegida y luego en <code className="action">Descargar</code>. La descarga se inicia en una nueva pestaña de su navegador.

    <img className="thumbnail" alt="Panel Copias de seguridad de una base de datos con el menú de una copia de seguridad abierto" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/backup-actions-menu.png" loading="lazy" />
  </Tab>
</Tabs>

### Guardar y exportar una base de datos fuera de la consola de OVHcloud <a name="sauvegarder-et-exporter-une-base-de-données-hors-espace-client"></a>

Si la RAM disponible en su servidor no permite realizar la exportación deseada, utilice la herramienta de OVHcloud en la consola de OVHcloud, que utiliza recursos externos a su solución. Consulte el apartado "[Guardar y exportar una base de datos desde la consola de OVHcloud](#guardar-y-exportar-una-base-de-datos-desde-la-consola-de-ovhcloud)" de esta guía.

**Haga clic en el método de exportación que desee para ver el contenido.**

<details>

<summary>Exportar una base de datos MySQL o MariaDB desde phpMyAdmin OVHcloud</summary>

Para exportar su base de datos directamente desde phpMyAdmin, es necesario conectarse previamente. Para ello, consulte la guía "[Conectarse a una base de datos](/guides/web-cloud/databases/db-connecting-database-server)".

Una vez conectado a phpMyAdmin, haga clic en el nombre de la base de datos que quiera exportar y, a continuación, en la pestaña <code className="action">Exportar</code> en la parte superior.

Existen dos modos de exportación. Si no tiene necesidades específicas, le recomendamos que utilice el modo **rápido** en formato **SQL**.

<img className="thumbnail" alt="Pestaña Exportar de phpMyAdmin con el método rápido y el formato SQL" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-export-backup-web-cloud-db.png" loading="lazy" />

</details>

<details>

<summary>Exportar una base de datos MySQL o MariaDB en línea de comandos</summary>

```bash
mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql
```

</details>

<details>

<summary>Exportar una base de datos MySQL o MariaDB desde un script PHP</summary>

```php
1. <?php echo "Your database is being backed up.......";
2. system("mysqldump --host=server --user=user --port=port --password=password database_name > database_name.sql");
3. echo "Backup complete. You can retrieve the database via FTP";
4. ?>
```

:::warning
- Para evitar que un tercero acceda a este archivo con datos sensibles, proteja su acceso con la ayuda de la guía: [Proteger un directorio o el panel de administración de su sitio web con los archivos .htaccess y .htpasswd](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password).
- Esta acción solo es posible desde un alojamiento web de OVHcloud.

:::

</details>

<details>

<summary>Exportar una base de datos PostgreSQL en línea de comandos</summary>

```bash
pg_dump --host=server --port=port --username=user --password database_name > database_name.sql
```

</details>

<details>

<summary>Exportar una base de datos PostgreSQL desde un script PHP</summary>

```php
1. <?php echo "Your database is being backed up.......";
2. system("PGPASSWORD=password pg_dump --host=server --port=port --username=user database_name > database_name.sql");
3. echo "Backup complete. You can retrieve the database via FTP";
4. ?>
```

:::warning
- Para evitar que un tercero acceda a este archivo con datos sensibles, proteja su acceso con la ayuda de la guía: [Proteger un directorio o el panel de administración de su sitio web con los archivos .htaccess y .htpasswd](/guides/web-cloud/web-hosting/htaccess-protect-directory-by-password).
- Esta acción solo es posible desde un alojamiento web de OVHcloud.

:::

</details>
