## Objetivo

La solución Web Cloud Databases ofrece una instancia de bases de datos con recursos dedicados y garantizados, proporcionando rendimiento y flexibilidad.
Por defecto, su solución Web Cloud Databases está asociada a la red de alojamientos web de OVHcloud. También puede asociarla a cualquier otra red a través de una lista de direcciones IP autorizadas.

**Descubra cómo empezar a utilizar la solución Web Cloud Databases.**

## Requisitos

- Una [instancia Web Cloud Databases](/links/web/databases) (incluida en un plan de [alojamiento web](/links/web/hosting) Performance, Agency, Agency Plus o Agency Max).

[[cpnav:web-cloud-databases]]

## Procedimiento

### Activación de su servidor Web Cloud Databases incluido con su plan de alojamiento web

Si su plan de alojamiento incluye la opción Web Cloud Databases, haga clic en las pestañas de abajo para ver cada uno de los **3** pasos.

:::warning
Para activar esta opción, debe ser como mínimo contacto administrador del alojamiento web que incluye el servicio Web Cloud Databases. Para más información sobre la gestión de los contactos, consulte nuestra guía "[Gestionar los contactos de los servicios](/guides/account-and-service-management/account-information/managing-contacts)".

:::

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y seleccione el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    En la pestaña <code className="action">Vista general</code>, localice la sección **Bases de datos**. La línea **Web Cloud DB** indica que su instancia aún no está activada. Haga clic en <code className="action">Activar</code>, debajo de esta línea.

    <img className="thumbnail" alt="Sección Bases de datos del alojamiento con el enlace Activar de la línea Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    En la página **Activar Web Cloud DB** que se muestra, elija la capacidad de su instancia (la capacidad de 512 MB está incluida en su plan de alojamiento, las capacidades superiores son de pago) y, a continuación, su motor (PostgreSQL, MariaDB, MySQL o Valkey) y su **Versión**. Después, haga clic en <code className="action">Activar</code> (capacidad incluida) o en <code className="action">Pedir</code> (capacidad de pago) y valide la orden de pedido que se abre en una nueva pestaña.

    <img className="thumbnail" alt="Página Activar Web Cloud DB con la elección de la capacidad, del motor y de la versión" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/wcdb-activate-page.png" loading="lazy" />

    A continuación, su instancia estará accesible desde la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink>.
  </Tab>
</Tabs>

### Consultar la información general de la instancia

Haga clic en las pestañas de abajo para ver cada uno de los **2** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />

    :::info
    El nombre del servicio Web Cloud DB en la consola de OVHcloud contiene una parte de su referencia de cliente y termina con tres cifras (001 para el primer servicio Web Cloud Databases instalado, 002 para el segundo, etc.).

    :::

  </Tab>
  <Tab label="Paso 2">
    Asegúrese de estar en la pestaña <code className="action">Vista general</code>.

    Compruebe que la información mostrada en las secciones **Información general** y **Uso de recursos** es correcta o se corresponde con las indicaciones siguientes.

    |Información|Detalles|
    |---|---|
    |Estado|Muestra, entre otras cosas, si la instancia está iniciada, reiniciándose o suspendida. Su instancia debe estar iniciada para poder realizar acciones en ella.|
    |Motor|Muestra el sistema de bases de datos utilizado por el servidor y su versión. Asegúrese de que su sitio web es compatible con la versión elegida.|
    |Región|Muestra la región del centro de datos en el que se ha creado la instancia.|
    |Host|Muestra el servidor de OVHcloud en el que se ha creado su instancia. Se trata de una información inherente a la infraestructura de OVHcloud y puede utilizarse en las comunicaciones relativas a los [incidentes de OVHcloud](https://www.status-ovhcloud.com/).|
    |Saturación CPU|Indica la frecuencia con la que su instancia está limitada por la CPU que tiene asignada. Si es elevada, considere la posibilidad de pedir más RAM.|
    |RAM|Muestra la memoria RAM disponible para su instancia, así como los posibles desbordamientos de memoria. Su instancia Web Cloud Databases dispone de recursos dedicados y garantizados: su memoria RAM. Si lo necesita, puede ampliarla con el enlace **Pedir más RAM**.|
    |Cuota de almacenamiento|Muestra el espacio ocupado por sus datos respecto al espacio incluido en su plan. Una vez alcanzada esta cuota, las escrituras fallan: deberá eliminar datos o cambiar a un plan superior.|

    <img className="thumbnail" alt="Secciones Información general y Uso de recursos de la vista general" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/overview.png" loading="lazy" />
  </Tab>
</Tabs>

### Crear una base de datos

:::info
Este paso no se aplica al sistema de bases de datos Valkey.

:::

Haga clic en las pestañas de abajo para ver cada uno de los **4** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Bases de datos</code>.

    <img className="thumbnail" alt="Pestaña Bases de datos de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    Haga clic en <code className="action">Añadir una base de datos</code>, encima de la tabla de bases de datos.

    <img className="thumbnail" alt="Botón Añadir una base de datos encima de la tabla de bases de datos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database.png" loading="lazy" />

    :::info
    La creación de esquemas PostgreSQL no está disponible actualmente en los servidores Web Cloud Databases.

    :::

  </Tab>
  <Tab label="Paso 4">
    El panel **Añadir una base de datos** se abre a la derecha. Complete los campos siguiendo los criterios indicados debajo de cada uno de ellos:

    - **Nombre de la base de datos** (obligatorio): es el nombre de su futura base de datos.
    - **Acceso a esta base de datos**: elija quién podrá conectarse a la base de datos y realizar consultas en ella.
        - **Ningún acceso por ahora** (opción por defecto): la base de datos se crea sin usuario. Podrá asignar permisos a un usuario más adelante.
        - **Un usuario existente**: seleccione el **Usuario** y, a continuación, sus **Permisos** sobre la base de datos.
        - **Un usuario nuevo**: complete los campos siguientes para crear el usuario al mismo tiempo que la base de datos.
    - **Nombre de usuario** (solo con **Un usuario nuevo**): el usuario que podrá conectarse a su base de datos y realizar consultas.
    - **Permisos** (con **Un usuario existente** o **Un usuario nuevo**): los permisos asociados al usuario en la base de datos. Para un uso estándar, seleccione `Admin`. Los permisos pueden modificarse posteriormente.
    - **Contraseña**/**Confirmar la contraseña** (solo con **Un usuario nuevo**): introduzca una contraseña y confírmela.

    Haga clic en <code className="action">Añadir</code>.

    <img className="thumbnail" alt="Panel Añadir una base de datos con un usuario nuevo" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/databases/add-database-window.png" loading="lazy" />
  </Tab>
</Tabs>

Si su proyecto no necesita un usuario adicional, puede pasar al siguiente paso. En caso contrario, haga clic en las pestañas de abajo para ver cada uno de los **4** pasos.

### Importar una base de datos

:::info
Este paso se aplica si desea importar una copia de seguridad de una base de datos existente. Si no es el caso, pase al siguiente paso.

:::

Para importar una base de datos, consulte nuestra guía "[Restaurar e importar una base de datos en su servidor de bases de datos](/guides/web-cloud/databases/db-restore-import-database)".

Se describen varios métodos de importación.

### Autorizar una dirección IP

Para que su instancia Web Cloud Databases funcione, debe indicar las IP o rangos de IP autorizados a conectarse a sus bases de datos.

Para ello, haga clic en las pestañas de abajo para ver cada uno de los **4** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    En la página que se muestra, haga clic en la pestaña <code className="action">IPs autorizadas</code>.

    <img className="thumbnail" alt="Pestaña IPs autorizadas de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    En la página que aparece, haga clic en el botón <code className="action">Añadir una IP</code> situado encima de la tabla.

    <img className="thumbnail" alt="Botón Añadir una IP encima de la tabla de IPs autorizadas" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip.png" loading="lazy" />

    :::tip
    Si desea modificar una dirección IP o un rango de IP ya autorizado, haga clic directamente en la tabla en el botón <code className="action">⋮</code> de la columna **Acciones**, a la derecha de la línea correspondiente a la dirección IP o al rango de IP que quiera modificar, y luego en <code className="action">Editar</code>. Podrá cambiar su nombre y sus autorizaciones; la dirección IP en sí no puede modificarse.

    <img className="thumbnail" alt="Menú de una línea de la tabla de IPs autorizadas" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/row-actions-menu.png" loading="lazy" />

    :::

  </Tab>
  <Tab label="Paso 4">
    En la ventana **Añadir una IP autorizada** que se abre, deben completarse varios campos:

    <img className="thumbnail" alt="Ventana Añadir una IP autorizada y sus campos" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/allowed-ips/add-ip-window.png" loading="lazy" />

    - **IP** (obligatorio): Introduzca la dirección IP (p. ej., `203.0.113.44`) o el rango de IP (p. ej., `203.0.113.0/24`, que representa todas las direcciones IP de `203.0.113.0` a `203.0.113.255`) que desea autorizar en su solución Web Cloud Databases.
    - **Nombre** (obligatorio): Puede indicar, por ejemplo, la función de la dirección IP o del rango de IP en cuestión.
    - **Permitir acceso al servicio** (marcada por defecto): Marque esta casilla para que la dirección IP o el rango de IP pueda acceder a las bases de datos de su solución Web Cloud Databases.
    - **Permitir acceso SFTP**: Marque esta casilla para que la dirección IP o el rango de IP pueda acceder a los logs de su solución Web Cloud Databases.

    :::warning
    Se desaconseja encarecidamente marcar la casilla **Permitir acceso al servicio** para autorizar el rango de IP `0.0.0.0/0` a acceder a sus bases de datos.

    Esto permitiría que todas las direcciones IPv4 existentes accedan a sus bases de datos.

    :::

    Una vez introducida la información, haga clic en el botón <code className="action">Añadir</code>.
  </Tab>
</Tabs>

### Autorizar las conexiones desde un alojamiento web de OVHcloud <a name="trustip"></a>

Por defecto, su solución Web Cloud Databases está automáticamente asociada a los alojamientos web de OVHcloud. Si lo desea, puede desactivar el acceso de los alojamientos web de OVHcloud a su Web Cloud Databases.

Para ello, consulte los casos particulares de nuestra guía "[Web Cloud Databases - ¿Cómo autorizar una dirección IP?](/guides/web-cloud/databases/db-authorise-ip-mask)" para activar o desactivar el acceso de los alojamientos web de OVHcloud a su Web Cloud Databases.

### Asociar su sitio web a la base de datos

Ahora que su base de datos está creada, uno o varios usuarios tienen permisos sobre ella y al menos una dirección IP o los alojamientos web de OVHcloud han sido autorizados en su instancia Web Cloud Databases, solo queda asociar su sitio web a su base de datos. Este paso puede realizarse de varias formas, en función del sitio web o del CMS (WordPress, Joomla!, etc.) utilizado, así como de la etapa en la que se encuentre si está instalando un sitio web.

Para ello, necesita las siguientes 5 informaciones:

|Información|Descripción|
|---|---|
|Nombre de la base de datos|El nombre que definió al crear la base de datos.|
|Nombre de usuario|El nombre de usuario que definió al crear la base de datos o cualquier usuario adicional que haya añadido.|
|Contraseña del usuario|La contraseña asociada al usuario, que definió en los pasos anteriores.|
|Nombre de host del servidor|El servidor que debe indicar para que su sitio web pueda conectarse a su base de datos.|
|Puerto del servidor|El puerto de conexión a su instancia Web Cloud Databases para que su sitio web pueda conectarse a su base de datos.|

Para obtener esta información, haga clic en las pestañas de abajo para ver cada uno de los **2** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/databases">Web Cloud DB</ManagerLink> y seleccione la instancia correspondiente.

    <img className="thumbnail" alt="Página Web Cloud DB y lista de las instancias de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Obtenga la siguiente información de conexión:

    - **Servidor (nombre de host) y puerto:** visibles en la pestaña <code className="action">Vista general</code>, sección **SQL**, datos **Nombre de host** y **Puerto**.
    - **Usuario:** visible en la pestaña <code className="action">Usuarios y permisos</code>.
    - **Contraseña:** la contraseña asociada al usuario. Si la ha olvidado, acceda a la pestaña <code className="action">Usuarios y permisos</code>, haga clic en el botón <code className="action">⋮</code> del usuario correspondiente y luego en <code className="action">Cambiar contraseña</code>.

    <img className="thumbnail" alt="Sección SQL de la vista general con el nombre de host y el puerto" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/general-information/sql-connection-info.png" loading="lazy" />

    :::warning
    Si cambia la contraseña de un usuario de la base de datos, todas las aplicaciones o sitios web que acceden a esta base de datos deben actualizarse en consecuencia.

    :::

  </Tab>
</Tabs>

:::warning
Es posible que el campo <code className="action">puerto</code> no esté disponible en la configuración de su sitio web. Debe añadir este campo después del nombre de host de su servidor, separándolos con *:*.

Por ejemplo, para el nombre de host `aaXXXXX-XXX.eu.clouddb.ovh.net` con el puerto SQL `12345`, deberá indicar `aaXXXXX-XXX.eu.clouddb.ovh.net:12345` en el apartado "Host" / "Nombre de host".

:::

:::info
OVHcloud no ofrece ningún puerto cifrado mediante TLS en los servidores de bases de datos Valkey. Las comunicaciones deben realizarse únicamente a través del puerto por defecto, sin cifrar.

:::
