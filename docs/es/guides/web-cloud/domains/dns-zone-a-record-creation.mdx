## Objetivo

¿Desea que su sitio web sea accesible a través de su nombre de dominio? Para ello, el dominio debe apuntar a la dirección IP del servicio en el que esté alojado el sitio web (alojamiento web, servidor dedicado, VPS, etc.). A continuación, deberá configurar la zona DNS activa del dominio con un registro DNS de tipo A.

**Descubra cómo añadir un registro DNS de tipo A a una zona DNS gestionada en OVHcloud para un dominio.**

:::info
Para modificar o eliminar un registro DNS de tipo A de una zona DNS de OVHcloud, siga [esta guía](/guides/web-cloud/domains/dns-zone-edit).

:::

## Requisitos

- Tener un [dominio](/links/web/domains).
- Tener una zona DNS asociada al dominio en OVHcloud.

## Procedimiento

:::warning
Añadir, modificar o eliminar registros DNS en una zona DNS activa puede provocar interrupciones del servicio. En caso de duda, contacte con un [proveedor especializado](/links/partner).

:::

### Añadir un registro DNS de tipo A a un dominio

Haga clic en <code className="action">Añadir una entrada</code> encima de la tabla y seleccione el tipo **A**. En el campo **Destino**, introduzca la dirección IP (por ejemplo, `203.0.113.0`) del servicio en el que esté alojado su sitio web (alojamiento web, servidor dedicado, VPS, etc.) y, a continuación, haga clic en <code className="action">Añadir</code>.

<img className="thumbnail" alt="Añadir un registro desde la zona DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/nx-add-entry.png" loading="lazy" />

La propagación del cambio por toda la red DNS puede tardar hasta **24** horas.

### Añadir un registro DNS de tipo A para el subdominio de un dominio

Siga los mismos pasos que antes y, en el campo **Subdominio**, introduzca el subdominio (por ejemplo, `www` para `www.domain.tld`) antes de indicar en **Destino** la dirección IP (por ejemplo, `203.0.113.0`) del servicio en el que esté alojado su sitio web. A continuación, haga clic en <code className="action">Añadir</code>.
