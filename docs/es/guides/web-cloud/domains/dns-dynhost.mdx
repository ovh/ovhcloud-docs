## Objetivo

La zona **D**omain **N**ame **S**ystem (**DNS**) de un dominio constituye el fichero de configuración de este último. Y se compone de información técnica llamada *enregistrement DNS*. La zona DNS es, en cierto modo, un centro de afilamiento. 

Para más información, consulte nuestras guías:

- [Todo sobre los servidores DNS](/guides/web-cloud/domains/dns-server-general-information)
- [Todo sobre la zona DNS](/guides/web-cloud/domains/dns-zone-general-information)
- [Todo sobre los registros DNS](/guides/web-cloud/domains/dns-zone-records)

La actualización de forma "dinámica" de un registro DNS puede evitar una interrupción prolongada de uno de sus servicios si no dispone de una dirección IP denominada "fija" (que no cambia).

Por ejemplo, el **DynHost** se puede utilizar si *se aloja* (en los locales de su empresa o en su domicilio, pasando por la *box* de su **P**roveedor de **A**cceso a **I**nternet (**PAI**)) un servidor de videojuegos sin tener una dirección IP "fija".

:::info
Cualquier registro "A" o "AAAA" con un TTL (**T**ime **T**o **L**ive) de 60 segundos se considerará DynHost. El TTL es un valor que indica el tiempo que los servidores DNS almacenan en caché un registro DNS antes de actualizarlo.

:::

**Descubra cómo configurar un registro DNS dinámico (DynHost) para su dominio de OVHcloud.**

## Requisitos

- Tener un dominio.
- Tener una zona DNS de OVHcloud para el dominio en cuestión.
- Utilizar la configuración de OVHcloud (es decir, sus servidores DNS) para el dominio en cuestión. 
- El registro DynHost que vaya a crear no debe existir en la zona DNS de OVHcloud del dominio como registro "A" o "AAAA".

[[cpnav:web-dns-zones-console]]

**Si el dominio no utiliza los servidores DNS proporcionados por OVHcloud**, contacte con el proveedor que gestione su configuración DNS para conocer el procedimiento a seguir.

**Si su dominio está registrado en OVHcloud**, puede comprobar si utiliza nuestra configuración. Para ello, haga clic en las pestañas de abajo para ver cada uno de los **2** pasos.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/domains/listing">Dominios y DNS</ManagerLink> y elija el dominio correspondiente. Se mostrará la pestaña <code className="action">Vista general</code> del dominio.

    <img className="thumbnail" alt="Página Dominios y DNS y lista de los nombres de dominio de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la sección **Configuración DNS**, consulte la lista **Servidores DNS que alojan la zona**. Contiene los servidores DNS definidos actualmente para su dominio. Pueden aparecer varios servidores DNS, cada uno en su propia línea.

    <img className="thumbnail" alt="Tarjeta Configuración DNS con la configuración y la lista de los servidores DNS que alojan la zona" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/general-information/dns-servers-ovhcloud.png" loading="lazy" />
  </Tab>
</Tabs>

:::tip
Para saber si utiliza o no los servidores DNS de OVHcloud, estos tienen una de las dos formas siguientes:

- `nsXX.ovh.net` y `dnsXX.ovh.net` **o** `nsXXX.ovh.net` y `dnsXXX.ovh.net` (donde cada `X` representa un número comprendido entre **0** y **9**)
- `ns200.anycast.me` y `dns200.anycast.me` (si ha contratado la opción [DNS anycast](/links/web/domains-options))

Si lo necesita, consulte nuestra guía relativa a [servidores DNS](/guides/web-cloud/domains/dns-server-general-information) para más información.

:::

## Procedimiento

### 1 - Crear un usuario DynHost <a name="step1"></a>

Haga clic en las pestañas de abajo para ver cada uno de los **3** pasos.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/domains/listing">Dominios y DNS</ManagerLink> y elija el dominio correspondiente.

    <img className="thumbnail" alt="Página Dominios y DNS y lista de los nombres de dominio de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">DynHost</code> y, a continuación, en la subpestaña <code className="action">Identificadores</code>. Después, haga clic en el botón <code className="action">Añadir un identificador</code>.

    <img className="thumbnail" alt="Pestaña DynHost, subpestaña Identificadores y botón Añadir un identificador" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dynhost/logins-table.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En el panel **Añadir un identificador** que aparece, complete la información solicitada:

    |Campo|Descripción|
    |---|---|
    |Identificador|Defina un sufijo para el identificador DynHost que está creando. El identificador completo se compone de su dominio, un guion y este sufijo (por ejemplo: `domain.tld-ident`). El sufijo tiene como máximo 10 caracteres (letras, cifras, `.` y `-`).|
    |Contraseña|Defina la contraseña asociada al identificador DynHost (entre 12 y 31 caracteres) y confírmela en el campo **Confirmar la contraseña**.|
    |Subdominio|Indique el subdominio al que quiere crear el registro DNS dinámico. Si desea gestionar todos los subdominios con un único identificador, escriba el formulario de entrada `*`.|

    :::tip
    Para configurar un DynHost directamente para su dominio, introduzca únicamente `*` en el campo **Subdominio**.

    :::

    <img className="thumbnail" alt="Panel Añadir un identificador completado" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dynhost/add-login-drawer.png" loading="lazy" />

    Una vez completados los campos, haga clic en el botón <code className="action">Añadir</code>. El identificador aparecerá entonces en la subpestaña <code className="action">Identificadores</code>.
  </Tab>
</Tabs>

Repita esta operación para cada usuario DynHost que quiera crear.

### 2 - Crear un registro DNS dinámico (DynHost) <a name="step2"></a>

En segundo lugar, debe crear el registro DNS que se actualizará automáticamente. Le recordamos que el registro DynHost no debe existir en la zona DNS de OVHcloud del dominio como registro A o AAAA. Para comprobarlo y, en su caso, eliminar dicho registro, consulte nuestra guía [Editar una zona DNS de OVHcloud](/guides/web-cloud/domains/dns-zone-edit).

Cuando esté listo para crear el registro DynHost, haga clic en las pestañas de abajo para ver cada uno de los **3** pasos.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/domains/listing">Dominios y DNS</ManagerLink> y elija el dominio correspondiente.

    <img className="thumbnail" alt="Página Dominios y DNS y lista de los nombres de dominio de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">DynHost</code>. En la subpestaña <code className="action">Registros</code>, que se muestra por defecto, haga clic en el botón <code className="action">Añadir un registro</code>.

    <img className="thumbnail" alt="Pestaña DynHost, subpestaña Registros y botón Añadir un registro" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dynhost/records-table.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En el panel **Añadir un registro DynHost** que aparece, complete la información solicitada:

    |Campo|Descripción|
    |---|---|
    |Subdominio|Indique el subdominio cuyo registro DNS deberá actualizarse dinámicamente. Este subdominio debe coincidir con el que indicó al crear el usuario DynHost. La mención **Registro configurado** muestra el nombre completo correspondiente.<br/><br/>**Si desea configurar un DynHost directamente para su dominio, introduzca `@` en este formulario.**|
    |IP de destino actual|Introduzca la dirección IP (IPv4 o IPv6) que vaya a utilizar el registro DNS. Es generalmente la dirección IP pública de su *box* Internet o de su servidor alojado.<br/><br/>Según el principio DynHost, esta se actualizará automáticamente más adelante.<br/><br/>Este formulario solo debe incluir una dirección IP.|

    :::warning
    Para configurar un registro DNS dinámico (DynHost), no es posible utilizar un *wildcard* (indicando únicamente el carácter `*`) en el campo **Subdominio**.

    :::

    <img className="thumbnail" alt="Panel Añadir un registro DynHost completado" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dynhost/add-record-drawer.png" loading="lazy" />

    Una vez completados los campos, haga clic en el botón <code className="action">Añadir</code>. El registro DynHost aparecerá entonces en la subpestaña <code className="action">Registros</code>.
  </Tab>
</Tabs>

Repita esta operación para cada registro DynHost que quiera crear.

:::info
Si su dominio o subdominio necesita configurarse dinámicamente con, por ejemplo, una IPv4 y una IPv6, puede crear dos registros DNS dinámicos para el mismo dominio o subdominio. El primer registro DNS dinámico será para la IPv4 y el segundo para la IPv6.

:::

### 3 - Automatizar la actualización del DynHost

Una vez que haya creado el [usuario](#step1) y el [registro DynHost](#step2), deberá automatizar la actualización del registro DNS para que se realice dinámicamente. Para ello, debe utilizar un programa o cliente que le permita comprobar regularmente si la dirección IP de destino ha cambiado para actualizarla automáticamente.

:::warning
La instalación y la configuración del software/cliente deben realizarse según sus propios conocimientos. A continuación ofrecemos algunas indicaciones sobre cómo hacerlo. No obstante, si tiene alguna duda, le recomendamos que contacte con un [proveedor especializado](/links/partner). Nosotros no podremos asistirle. 
Más información en la sección ["Más información"](#go-further) de esta guía.

:::

Existen diversas posibilidades en lo que respecta al programa o cliente: 

- puede instalarse en el servidor o en el ordenador;
- ya puede estar disponible en la interfaz de su router/*box* Internet si este es compatible. Si necesita ayuda, puede ponerse en contacto con el equipo de soporte de su **PAI** para realizar la configuración.

Una vez que haya elegido e instalado el cliente, deberá configurarlo utilizando la información del usuario DynHost que haya creado anteriormente en la consola de OVHcloud.

Según el cliente utilizado, además de los elementos del usuario DynHost y del subdominio correspondiente, puede ser necesaria una URL de actualización. En ese caso, utilice la siguiente URL sustituyendo la información genérica:

```bash
https://dns.eu.ovhapis.com/nic/update?system=dyndns&hostname=$HOSTNAME&myip=$IP
```

|Valor|Sustituir por...|
|---|---|
|$HOSTNAME|El subdominio afectado por la actualización.|
|$IP|La nueva dirección IPv4 o IPv6 de destino.|

:::warning

El comportamiento del parámetro `myip` depende de la versión del protocolo IP utilizada:

- **IPv4**: el parámetro `myip` es opcional. Si se omite, se utiliza automáticamente la dirección IP desde la que se origina la llamada a la API.
- **IPv6**: dado que no se puede acceder a `dns.eu.ovhapis.com` mediante IPv6, el parámetro `myip` es obligatorio para transmitir la dirección de destino.

:::

Puede comprobar si la dirección IP de destino se ha actualizado correctamente. Para ello, haga clic en las fichas siguientes para ver cada una de las **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/domains/listing">Dominios y DNS</ManagerLink> y elija el dominio correspondiente.

    <img className="thumbnail" alt="Página Dominios y DNS y lista de los nombres de dominio de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">DynHost</code>. En la subpestaña <code className="action">Registros</code>, compruebe la dirección IP que aparece en la columna **Dirección IP** (vista de tabla) o junto a la mención **Dirección IP** (vista de tarjetas).

    <img className="thumbnail" alt="Subpestaña Registros de la pestaña DynHost y columna Dirección IP" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dynhost/records-table.png" loading="lazy" />
  </Tab>
</Tabs>

:::warning
Cualquier modificación en la zona DNS activa de un dominio a través de DynDNS puede provocar un retraso de propagación de la actualización de varios minutos.

:::
