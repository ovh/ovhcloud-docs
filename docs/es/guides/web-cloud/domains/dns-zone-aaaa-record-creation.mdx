## Objetivo

¿Desea que su sitio web sea accesible a través de su nombre de dominio? Para ello, el dominio debe apuntar a la dirección IP del servicio en el que esté alojado el sitio web (alojamiento web, servidor dedicado, VPS, etc.). A continuación, deberá configurar la zona DNS activa del dominio con un registro DNS de tipo AAAA.

**Descubra cómo añadir un registro DNS de tipo AAAA a una zona DNS gestionada en OVHcloud para un dominio.**

:::info
Para modificar o eliminar un registro DNS de tipo AAAA de una zona DNS de OVHcloud, siga [esta guía](/guides/web-cloud/domains/dns-zone-edit).

:::

## Requisitos

- Tener un [dominio](/links/web/domains).
- Tener una zona DNS asociada al dominio en OVHcloud.

[[cpnav:web-domain-dns-zone]]

## Procedimiento

:::warning
Añadir, modificar o eliminar registros DNS en una zona DNS activa puede provocar interrupciones del servicio. En caso de duda, contacte con un [proveedor especializado](/links/partner).

:::

### Añadir un registro DNS de tipo AAAA a un dominio

Haga clic en las pestañas de abajo para ver cada uno de los **5** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/domains/listing">Dominios y DNS</ManagerLink> y elija el dominio correspondiente.

    <img className="thumbnail" alt="Página Dominios y DNS y lista de los nombres de dominio de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Zona DNS</code> y, encima de la tabla, en <code className="action">Crear un registro</code>.

    <img className="thumbnail" alt="Pestaña Zona DNS de un dominio y botón Crear un registro" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    En el formulario que se abre encima de la tabla, seleccione `AAAA — Apuntar hacia una IPv6` en la lista **Tipo**.

    <img className="thumbnail" alt="Lista Tipo del formulario de creación de registro y tipos de registro disponibles" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 4">
    En el campo **Subdominio**, introduzca `@`: este símbolo designa el propio nombre de dominio. En el campo **Destino (IPv6)**, introduzca la dirección IPv6 (por ejemplo: `2001:db8:1:1b00:203:0:113:0`) del servicio en el que se encuentra su sitio web (alojamiento web, servidor dedicado, VPS, etc.).

    <img className="thumbnail" alt="Formulario de creación de registro de la zona DNS, registro AAAA para el dominio" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-aaaa-record.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 5">
    Compruebe la **Vista previa del registro** y haga clic en <code className="action">Agregar</code>.
  </Tab>
</Tabs>

La propagación del cambio por toda la red DNS puede tardar hasta **24** horas.

### Añadir un registro DNS de tipo AAAA para el subdominio de un dominio

Haga clic en las pestañas de abajo para ver cada uno de los **5** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/domains/listing">Dominios y DNS</ManagerLink> y elija el dominio correspondiente.

    <img className="thumbnail" alt="Página Dominios y DNS y lista de los nombres de dominio de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Zona DNS</code> y, encima de la tabla, en <code className="action">Crear un registro</code>.

    <img className="thumbnail" alt="Pestaña Zona DNS de un dominio y botón Crear un registro" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/zone-overview.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    En el formulario que se abre encima de la tabla, seleccione `AAAA — Apuntar hacia una IPv6` en la lista **Tipo**.

    <img className="thumbnail" alt="Lista Tipo del formulario de creación de registro y tipos de registro disponibles" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 4">
    En el campo **Subdominio**, introduzca el subdominio correspondiente (por ejemplo: `www` para `www.domain.tld`). En el campo **Destino (IPv6)**, introduzca la dirección IPv6 (por ejemplo: `2001:db8:1:1b00:203:0:113:0`) del servicio en el que se encuentra su sitio web (alojamiento web, servidor dedicado, VPS, etc.).

    <img className="thumbnail" alt="Formulario de creación de registro de la zona DNS, registro AAAA para el subdominio www" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-aaaa-record-www.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 5">
    Compruebe la **Vista previa del registro** y haga clic en <code className="action">Agregar</code>. Espere hasta **24** horas para que la propagación del cambio en la red DNS sea plenamente efectiva.
  </Tab>
</Tabs>
