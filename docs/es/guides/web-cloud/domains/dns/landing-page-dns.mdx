## ¿Qué es el DNS?

El **DNS** (*Domain Name System*) es la guía telefónica de Internet: traduce los nombres de dominio legibles para las personas (como `mydomain.ovh`) en direcciones IP que las máquinas comprenden. Sin él, habría que recordar una serie de cifras para acceder a cada sitio web o servicio en línea.

En OVHcloud, la configuración DNS de un nombre de dominio se basa en tres elementos:

- los **servidores DNS**, que alojan y difunden la información de su dominio;
- la **zona DNS**, el archivo que reúne todos sus registros;
- los **registros DNS**, cada línea que asocia un nombre a un valor (dirección IP, servidor de correo, texto, etc.).

## ¿Cómo funciona el DNS?

Desde su nombre de dominio hasta cada registro, la resolución DNS sigue una cadena de cuatro eslabones.

<DnsChain />

### El servidor DNS

Los servidores DNS alojan y difunden por Internet la información de su dominio. Cuando un internauta solicita su sitio web, son ellos los que responden indicando dónde encontrarlo. De forma predeterminada, su dominio utiliza los servidores DNS de OVHcloud. [Todo sobre los servidores DNS](/guides/web-cloud/domains/dns-server-general-information).

<DnsServerIllustration />

### La zona DNS

La zona DNS es el archivo de configuración asociado a sus servidores DNS. Reúne todos los registros de su dominio: aquí es donde añade, modifica o elimina sus entradas. [Todo sobre la zona DNS](/guides/web-cloud/domains/dns-zone-general-information).

<DnsZoneIllustration />

### Los registros DNS

Cada registro es una línea de la zona que asocia un nombre a un valor: una dirección IP, un servidor de correo, texto, etc. Su tipo determina su función, indicada a continuación por su color. Seleccione el que desee configurar para acceder a la guía correspondiente.
