## Objetivo

¿Desea crear una zona DNS para un subdominio?

La zona **D**omain **N**ame **S**ystem (**DNS**) de un nombre de dominio constituye su archivo de configuración. Se compone de información técnica, llamada *registros DNS*. La zona DNS actúa como un centro de enrutamiento.

Para más información, consulte nuestras guías:

- [Todo sobre los servidores DNS](/guides/web-cloud/domains/dns-server-general-information)
- [Todo sobre la zona DNS](/guides/web-cloud/domains/dns-zone-general-information)
- [Todo sobre los registros DNS](/guides/web-cloud/domains/dns-zone-records)

Normalmente, los registros DNS de un subdominio se configuran directamente desde la zona DNS activa del nombre de dominio del que depende.
Sin embargo, también es posible crear una zona DNS específica para un subdominio.

Por diversas razones, puede que necesite crear una zona DNS para un subdominio en OVHcloud.
Este subdominio dispondrá entonces de su propia zona para configurar sus registros DNS.

:::tip
Para recordar:

- Un nombre de dominio tiene normalmente esta forma: **domain.tld**. Por ejemplo: ovhcloud.com.
- Un subdominio tiene normalmente esta forma: **sub.domain.tld**. Por ejemplo: help.ovhcloud.com.

Por defecto, un subdominio depende de un nombre de dominio para funcionar.
En la práctica, no podrá utilizar el subdominio **sub.domain.tld** si no tiene acceso a la gestión del nombre de dominio **domain.tld**.

Si desea crear una zona DNS para un nombre de dominio, consulte directamente [esta guía](/guides/web-cloud/domains/dns-zone-create).

:::

**Descubra cómo crear una zona DNS en OVHcloud para el subdominio de un dominio desde la consola de OVHcloud.**

## Requisitos

- Disponer del nombre de dominio del que dependerá el subdominio elegido.
- El subdominio en cuestión no debe disponer ya de una zona DNS (activa o no) en OVHcloud o estar siendo objeto de una operación o un pedido en curso en OVHcloud.

[[cpnav:web-dns-zone-order-console]]

## Procedimiento

### 1 - Crear la zona DNS desde la consola de OVHcloud

Haga clic en las pestañas de abajo para ver cada uno de los **3** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/domains/listing">Dominios y DNS</ManagerLink> y haga clic en el botón <code className="action">Pedir un dominio o una zona DNS</code>. En la sección **Zona DNS independiente**, haga clic en <code className="action">Contratar</code>.

    <img className="thumbnail" alt="Página de pedido de un dominio o de una zona DNS y sección Zona DNS independiente" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-choice.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    En la página **Contratar una zona DNS** que aparece, introduzca en el campo **Nombre de dominio** el subdominio (por ejemplo: *sub.domain.tld*) para el que quiera crear una zona DNS de OVHcloud. Espere unos instantes mientras la herramienta realiza las comprobaciones del subdominio.

    Si un mensaje indica que no se puede crear la zona DNS (por ejemplo, "Ya existe una zona DNS para sub.domain.tld."), compruebe que el subdominio cumple los requisitos necesarios o póngase en contacto con la persona que lo gestiona. Cuando todo sea correcto, vuelva a intentarlo.

    <img className="thumbnail" alt="Mensaje que indica que ya existe una zona DNS para el nombre introducido" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-exists.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    Una vez finalizada la comprobación, aparece la sección **Elija sus opciones**. Marque si lo necesita la opción **DNS Anycast** (de pago). El resumen, a la derecha de la página, indica el contenido y el total de su pedido.

    <img className="thumbnail" alt="Opciones del pedido de una zona DNS para un subdominio y resumen del pedido" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/order-zone-subdomain.png" loading="lazy" />

    Haga clic en <code className="action">Continuar el pedido</code> y siga los pasos que se muestran hasta la creación de la zona DNS.

    :::info
    Los registros mínimos ya no se eligen durante el pedido. Si desea personalizar usted mismo la zona DNS partiendo únicamente de los registros mínimos (registros NS y SOA), reiníciela una vez creada: en la pestaña <code className="action">Zona DNS</code>, abra el menú <code className="action">Acciones adicionales</code> de la tarjeta **Zona DNS**, haga clic en <code className="action">Reinicializar la zona</code> y elija <code className="action">Sí — solo entradas mínimas</code>. Consulte nuestra guía "[Editar una zona DNS de OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".

    :::
  </Tab>
</Tabs>

### 2 - Editar la zona DNS (opcional)

Una vez que haya creado la zona DNS para el subdominio ya puede editarla. Esta operación es opcional, pero puede ser necesaria para garantizar la disponibilidad de los servicios asociados al subdominio (como un sitio web o los mensajes de correo electrónico).

Para editar esta zona DNS, consulte nuestra guía "[Editar una zona DNS en OVHcloud](/guides/web-cloud/domains/dns-zone-edit)". 

:::info
Si acaba de crear la zona DNS y el subdominio no aparece aún en la lista de sus servicios, espere entre 15 y 20 minutos y vuelva a cargar la página.

:::

### 3 - Declarar los servidores DNS en la zona DNS activa del nombre de dominio del que depende el subdominio elegido

La activación de una zona DNS para un subdominio es diferente a la de un nombre de dominio, ya que un subdominio depende obligatoriamente de un nombre de dominio para funcionar.

Primero, debe recuperar el nombre de los **servidores DNS** de OVHcloud asociados a la zona DNS creada para su subdominio.

Para encontrarlos, haga clic en las pestañas de abajo para ver cada uno de los **2** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/domains/listing">Dominios y DNS</ManagerLink> y elija la zona DNS de su subdominio (aparece como **Solo zona** en la lista). A continuación, haga clic en la pestaña <code className="action">Zona DNS</code>.

    <img className="thumbnail" alt="Página Dominios y DNS y lista de los nombres de dominio de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    En la tabla que aparece, localice las columnas **Tipo** y **Destino**. Para mostrar solo los registros útiles, haga clic en <code className="action">Filtros</code> y seleccione <code className="action">NS</code> en la lista **Tipo de registro**.

    <img className="thumbnail" alt="Zona DNS filtrada por los registros NS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/filter-ns.png" loading="lazy" />

    Anote los 2 valores que figuran en la columna **Destino**. Los nombres de los servidores DNS deben tener una de las 3 formas siguientes:

    - `nsXX.ovh.net` y `dnsXX.ovh.net` o, `nsXXX.ovh.net` y `dnsXXX.ovh.net` (donde cada `X` representa un número entre **0** y **9**).
    - `nsXX.ovh.ca` y `dnsXX.ovh.ca` o, `nsXXX.ovh.ca` y `dnsXXX.ovh.ca` (donde cada `X` representa un número entre **0** y **9**).
    - `ns200.anycast.me` y `dns200.anycast.me` (si ha contratado la opción [DNS anycast](/links/web/domains-options)).
  </Tab>
</Tabs>

Una vez recuperados los 2 nombres de servidor DNS, 2 situaciones son posibles:

**Pulse en una de las 2 situaciones para mostrar el contenido.**

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/domains/listing">Dominios y DNS</ManagerLink> y elija el dominio del que depende su subdominio.

    <img className="thumbnail" alt="Página Dominios y DNS y lista de los nombres de dominio de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/listing.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en la pestaña <code className="action">Zona DNS</code> y, seguidamente, en el botón <code className="action">Crear un registro</code> encima de la tabla.

    <img className="thumbnail" alt="Pestaña Zona DNS y formulario de creación de registro" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 3">
    En la lista **Tipo**, seleccione <code className="action">NS — Delegar a un servidor DNS</code> (sección **Campos de apuntamiento**).

    <img className="thumbnail" alt="Lista de tipos de registro con el tipo NS" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-entry-type-list-ns.png" loading="lazy" />

    En el campo **Subdominio**, introduzca el subdominio correspondiente (por ejemplo: `sub` para el subdominio `sub.domain.tld`); en el campo **Destino (servidor DNS)**, introduzca uno de los 2 servidores DNS que ha anotado (por ejemplo: `nsXX.ovh.net`). Compruebe la **Vista previa del registro** y haga clic en <code className="action">Agregar</code>.

    <img className="thumbnail" alt="Formulario de registro NS completado para un subdominio" src="/images/assets/screens/console/product-selection/web-cloud/domain-dns/dns-zone/add-ns-record.png" loading="lazy" />

    **Repita la operación para el segundo servidor DNS.**

    Si lo necesita, consulte también nuestra guía "[Editar una zona DNS de OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".
  </Tab>
</Tabs>

</details>

<details>

<summary>El nombre de dominio del que depende su subdominio tiene su zona DNS activa en otro proveedor</summary>

En este caso concreto, contacte con su proveedor DNS y indíquele que desea añadir 2 registros DNS de tipo NS para su subdominio. 

Este es un ejemplo de solicitud que puede formular a su proveedor DNS:

<pre className="bgwhite"><code>
Buenos días,

Deseo añadir en la zona DNS activa del nombre de dominio <b>domain.tld</b> los siguientes registros DNS de tipo NS para mi subdominio <b>sub.domain.tld</b>:

 - sub IN NS nsXX.ovh.net.
 - sub IN NS dnsXX.ovh.net.

Con el fin de activar una zona DNS específica para mi subdominio <b>sub.domain.tld</b>.

Atentamente,
</code></pre>

En el ejemplo anterior, reemplace los valores **domain.tld**, **sub.domain.tld**, **nsXX.ovh.net** y **dnsXX.ovh.net** por sus propios valores.

</details>

:::warning
**La observación siguiente no concierne a los 2 registros DNS de tipo NS que acaba de añadir.** 

Si había otros registros DNS presentes en la zona DNS activa del nombre de dominio del que depende su subdominio:

1. No olvide duplicarlos en la zona DNS creada para su subdominio.
2. Una vez duplicados, elimínelos de la zona DNS activa de su nombre de dominio.

De lo contrario, podría haber un conflicto en la resolución DNS.

:::

Después de modificar la zona DNS del nombre de dominio del que depende su subdominio, la propagación de los cambios puede tardar hasta **48 horas**.
