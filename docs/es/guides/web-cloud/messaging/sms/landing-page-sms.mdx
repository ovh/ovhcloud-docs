## Presentación del servicio SMS de OVHcloud

El [servicio SMS de OVHcloud](/links/telecom/sms) le permite enviar SMS a sus clientes y contactos, de forma individual o en campañas masivas, desde el área de cliente de OVHcloud o directamente desde sus aplicaciones mediante la API. Aquí encontrará todas las guías para configurar, enviar y gestionar sus SMS.

Con este servicio, puede:

- Enviar SMS desde el área de cliente, por correo electrónico, desde una URL (http2sms) o mediante la API de OVHcloud
- Lanzar y monitorizar sus campañas de SMS de marketing y transaccionales
- Gestionar sus remitentes, sus usuarios y sus listas de destinatarios
- Hacer un seguimiento de su historial y recargar automáticamente sus créditos de SMS
