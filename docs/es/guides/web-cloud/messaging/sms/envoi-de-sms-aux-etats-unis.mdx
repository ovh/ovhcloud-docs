## Objetivo

El envío de SMS a Estados Unidos está sujeto a normas específicas. Esta guía le explica en qué consisten y le muestra cómo aplicarlas.

## Requisitos

- Disponer de una [cuenta de SMS de OVHcloud](/links/telecom/sms) con créditos de SMS.
- Estar conectado a las [API de OVHcloud](/links/api) (únicamente para el método de envío a través de la API).

## Procedimiento

### Etapa 1: Conocer las restricciones

De acuerdo con la autoridad reguladora de los SMS en Estados Unidos (Neustar), el envío de SMS a este destino requiere la validación previa de una plantilla de mensaje por parte de nuestros equipos.
Solo se autorizan los mensajes de alerta y de doble autenticación, y no se aceptará ninguna plantilla de SMS publicitario. Una vez validada su plantilla, el envío se realizará de la misma forma que para los demás destinos.

Puede solicitar la validación de varias plantillas de mensajes.

:::info
La validación de las plantillas de mensajes es gratuita y la realizan los equipos de OVHcloud en un plazo de uno a dos días laborables.

:::

### Etapa 2: Añadir una plantilla

#### 2.1 Desde el área de cliente

Haga clic en la pestaña <code className="action">Mensaje y campaña</code> y, a continuación, en <code className="action">Gestión de SMS</code>.

Por último, haga clic en <code className="action">Gestionar las plantillas</code>.

<img className="thumbnail" alt="SMS a Estados Unidos" src="/images/web-cloud/messaging/sms/envoi-de-sms-aux-etats-unis/smstousa1.png" loading="lazy" />

En la página que aparece, haga clic en <code className="action">Acciones</code> y, a continuación, en <code className="action">Añadir</code>.

<img className="thumbnail" alt="SMS a Estados Unidos" src="/images/web-cloud/messaging/sms/envoi-de-sms-aux-etats-unis/smstousa2.png" loading="lazy" />

Aparece una ventana emergente con los campos que debe rellenar.

<img className="thumbnail" alt="SMS a Estados Unidos" src="/images/web-cloud/messaging/sms/envoi-de-sms-aux-etats-unis/smstousa3.png" loading="lazy" />

| Campo       | Descripción                                                                                                      |
|-------------|------------------------------------------------------------------------------------------------------------------|
| Nombre      | Nombre de la plantilla                                                                                            |
| Actividad   | Seleccione el tipo de plantilla:<br/>\- Alerta<br/>\- Autenticación<br/>\- Sistema de tratamiento transaccional |
| Descripción | Descripción de la plantilla                                                                                       |
| Plantilla   | Escribir la plantilla, incluyendo la variable entre #                                                            |

#### 2.2 A través de las API

:::tip
Si no está familiarizado con el uso de la API de OVHcloud, consulte nuestra guía [Primeros pasos con las API de OVHcloud](/guides/manage-and-operate/api/first-steps).

:::

Conéctese a [api.ovh.com](/links/api) y, a continuación, utilice la siguiente API:

Rellene los campos requeridos y haga clic en <code className="action">Execute</code>.

#### Ejemplos de plantillas

A continuación encontrará 2 ejemplos de plantillas de mensajes destinados a Estados Unidos.

- Ejemplo de plantilla de autenticación:

```bash
Your security code is #CODE#, have a good day
```

- Ejemplo de plantilla de alerta:

```bash
Our monitoring system detected your server #SERVER# doesn't respond to ping requests
```

### Etapa 3: Analizar los resultados

Una vez creada y validada su plantilla de mensaje, el envío de un SMS genera una comparación automática de su contenido con sus plantillas. Si la comparación es positiva, el SMS se envía de la misma forma que un envío hacia otro destino.

Si envía un SMS a Estados Unidos sin haber creado y validado previamente una plantilla, el SMS será rechazado y recibirá un Premium Tracking Transaction Code (PTT code) 1999. Este código corresponde al mensaje de error "No templates available" (no se ha creado ninguna plantilla de mensaje).

Puede consultar los demás códigos de retorno posibles en la guía [Todo sobre los usuarios de SMS](/guides/web-cloud/messaging/sms/sms-users).
