## Objetivo

Exportar un buzón en formato PST le proporciona una copia local del mismo: para archivarlo antes de eliminar una cuenta, entregarlo cuando un colaborador deja la empresa, transferirlo a otro servicio de correo o cumplir una obligación de conservación. Microsoft Exchange en OVHcloud puede exportar un buzón en el lado del servidor: usted solicita la exportación, OVHcloud la genera y, a continuación, usted descarga un archivo ZIP que contiene uno o varios ficheros `.pst`, `readme.md` y `checksum.txt`. La exportación no pasa por Outlook: tanto el área de cliente de OVHcloud como la API de OVHcloud cubren la operación de principio a fin.

Esta funcionalidad está disponible para Hosted Exchange, Private Exchange y Trusted Exchange. Se aplica a los buzones individuales: los grupos no se pueden exportar.

**Esta guía explica cómo exportar un buzón Exchange a un archivo PST, desde el área de cliente de OVHcloud o a través de la API de OVHcloud.**

## Requisitos

- Disponer de un servicio [Hosted Exchange](/links/web/emails-hosted-exchange), [Private Exchange](/links/web/emails-private-exchange) o [Trusted Exchange](/links/web/emails-trusted-exchange).
- Disponer de derechos de administración sobre este servicio en el <ManagerLink to="/">área de cliente de OVHcloud</ManagerLink>.
- Disponer de suficiente espacio en disco local para el archivo ZIP y para su contenido extraído.
- Para el método API: disponer de credenciales API generadas a través de la <CreateToken rights="GET=/email/exchange/*&POST=/email/exchange/*&DELETE=/email/exchange/*">página de generación de tokens de OVHcloud</CreateToken>, con al menos los derechos `GET`, `POST` y `DELETE` sobre `/email/exchange/*`.

:::warning
**Una exportación por buzón cada 24 horas.** Una vez solicitada una exportación para una dirección de correo electrónico, la siguiente solo se acepta 24 horas más tarde. Téngalo en cuenta antes de exportar varios buzones de forma consecutiva.

:::

## Procedimiento

### Exportar desde el área de cliente

1. Abra la pestaña <code className="action">Cuentas de correo</code>.
2. En la línea del buzón que desea exportar, haga clic en <code className="action">...</code> y, a continuación, en <code className="action">Exportar en formato PST</code>.

    <img className="thumbnail" alt="Menú de acciones de una cuenta de correo con la entrada Exportar en formato PST" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-menu.png" loading="lazy" />

3. En la ventana <code className="action">Exportar en formato .pst</code>, haga clic en <code className="action">Descargar</code> para iniciar la exportación. Esta se ejecuta en segundo plano y tarda entre unos minutos y varias horas según el tamaño del buzón. Puede cerrar la ventana y salir de la página: vuelva a abrirla en cualquier momento para ver el progreso, que se muestra en porcentaje.

    <img className="thumbnail" alt="Ventana Exportar en formato .pst mostrando el progreso de la exportación" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-progress.png" loading="lazy" />

4. Una vez finalizada la exportación, abra el mismo menú <code className="action">...</code> y haga clic de nuevo en <code className="action">Exportar en formato PST</code>. El enlace de descarga se genera entonces automáticamente, lo que tarda entre 2 y 3 minutos.

    <img className="thumbnail" alt="Ventana Exportar en formato .pst durante la generación del enlace de descarga" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-link.png" loading="lazy" />

5. Cuando el enlace esté listo, la ventana confirma que el buzón está disponible en formato `.pst`. Haga clic en <code className="action">Descargar</code> para obtener el archivo ZIP y, a continuación, extráigalo y compruébelo (consulte "[Comprobar y abrir el archivo](#comprobar-y-abrir-el-archivo)").

    <img className="thumbnail" alt="Ventana de exportación que ofrece la descarga del archivo y una nueva exportación" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-export-pst/exchange-export-pst-download.png" loading="lazy" />

:::info
El enlace de descarga es temporal: la ventana muestra la fecha hasta la que el fichero permanece disponible. Pasada esa fecha, el archivo se elimina y es necesaria una nueva exportación. La misma ventana permite hacer clic en <code className="action">Iniciar nueva exportación</code>, lo que **elimina inmediatamente el archivo anterior**.

:::

### Exportar a través de la API

Dos objetos sostienen todo el proceso: `export` genera el archivo e informa de su progreso, y `exportURL` proporciona una URL de descarga temporal. Todas las llamadas siguientes pertenecen a la <ApiLink section="/email/exchange">sección `/email/exchange`</ApiLink> de la API de OVHcloud.

#### Obtener los parámetros de la ruta

Cada llamada necesita 3 valores: el nombre de la organización, el nombre del servicio y la dirección del buzón. Los 2 primeros son nombres internos, con el formato `ab12345-ovh`, y no las etiquetas que se muestran en el área de cliente de OVHcloud. Obténgalos en orden, ya que cada llamada alimenta la siguiente.

**1. Organización** (`organizationName`): liste las organizaciones Exchange de su cuenta con la siguiente llamada API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange"} />

**2. Servicio** (`exchangeService`): liste los servicios Exchange de la organización con la siguiente llamada API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service"} />

**3. Buzón** (`primaryEmailAddress`): liste las cuentas de correo del servicio con la siguiente llamada API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account"} />

Cada llamada devuelve una lista de cadenas. Si la dirección del buzón contiene caracteres no permitidos en una URL, codifíquelos en formato porcentaje en la ruta (`+` se convierte en `%2B`, etc.).

#### Solicitar la exportación

Solicite la exportación del buzón con la siguiente llamada API:

<Api version="v1" section="/email/exchange" method="POST" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

La llamada no acepta ningún parámetro en el cuerpo de la petición y devuelve una tarea, que solo confirma que la solicitud se ha registrado:

```json
{
  "id": 123456789,
  "function": "addExportPstRequest",
  "status": "todo",
  "todoDate": "2026-09-01T10:12:33+02:00",
  "finishDate": null
}
```

#### Seguir el progreso

Consulte la solicitud de exportación para seguir su progreso:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

| Propiedad | Tipo | Descripción |
|---|---|---|
| `creationDate` | datetime | Fecha de creación de la solicitud de exportación |
| `percentComplete` | long | Progreso de la exportación, en porcentaje |
| `taskPendingId` | long | Identificador de la tarea en curso, `0` cuando no se ejecuta ninguna |

```json
{
  "creationDate": "2026-09-01T10:12:33+02:00",
  "percentComplete": 42,
  "taskPendingId": 123456789
}
```

Repita esta llamada hasta que `percentComplete` alcance `100`, como máximo una vez por minuto. Un error `404` significa que no existe ninguna solicitud de exportación para este buzón: o bien nunca se creó, o bien ya se ha eliminado.

Los estados de tarea son `todo`, `doing`, `done`, `error`, `standby` y `canceled`. Las funciones de tarea relacionadas con la exportación son `addExportPstRequest`, `deleteExportPstRequest` y `generatePstUrl`.

#### Obtener la URL de descarga

El objeto `export` nunca devuelve una URL de descarga. Generar el enlace requiere 2 llamadas.

**1. Generar la URL**: cree el enlace de descarga, lo que registra una tarea `generatePstUrl`, con la siguiente llamada API:

<Api version="v1" section="/email/exchange" method="POST" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/exportURL"} />

**2. Leer la URL**: una vez finalizada la tarea, lea el enlace generado con la siguiente llamada API:

<Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/exportURL"} />

| Propiedad | Tipo | Descripción |
|---|---|---|
| `url` | string | URL de descarga del archivo |
| `expiration` | datetime | Fecha de expiración de la URL |

```json
{
  "url": "https://exchange-export.storage.example/abc123/john.smith.zip?token=...",
  "expiration": "2026-09-01T11:15:00+02:00"
}
```

La URL ya está firmada: descargue el archivo directamente desde esa URL, sin cabecera de autenticación. Un error `404` en la llamada `GET` significa que la URL aún no se ha generado (la tarea `generatePstUrl` sigue en curso) o que ha expirado.

:::info
**La validez de la URL es limitada.** Lea `expiration` en lugar de presuponer el plazo, y genere la URL solo en el momento de descargar. Una vez expirada, vuelva a ejecutar la llamada `POST` sobre `exportURL` para obtener un nuevo enlace: mientras el archivo exista, no es necesario repetir la exportación.

:::

#### Eliminar la solicitud de exportación

Elimine la solicitud de exportación con la siguiente llamada API:

<Api version="v1" section="/email/exchange" method="DELETE" route={"/email/exchange/\{organizationName\}/service/\{exchangeService\}/account/\{primaryEmailAddress\}/export"} />

Utilícela para cancelar una exportación en curso, o para eliminar la solicitud una vez descargado el archivo y poder solicitar una nueva (siempre dentro del límite de una exportación cada 24 horas). La llamada también elimina el archivo del lado de OVHcloud: descárguelo antes.

### Comprobar y abrir el archivo

Sea cual sea el método, el archivo ZIP contiene:

| Elemento | Descripción |
|---|---|
| `*.pst` | Los datos del buzón. Un buzón voluminoso se reparte en varios ficheros PST. |
| `readme.md` | Las notas de OVHcloud sobre la exportación y su contenido. |
| `checksum.txt` | La huella SHA-256 de cada fichero `.pst` del archivo. |

Extraiga el archivo y, a continuación, compruebe los ficheros PST con `checksum.txt` antes de importarlos: una descarga truncada produce un fichero PST que Outlook se niega a abrir o abre de forma incompleta. Los comandos siguientes presuponen una disposición `<hash> <filename>`, una línea por fichero.

En Windows, con PowerShell:

```powershell
Get-Content .\checksum.txt | Where-Object { $_.Trim() } | ForEach-Object {
    $hash, $file = $_.Trim() -split '\s+', 2
    $file = $file.TrimStart('*')
    $actual = (Get-FileHash $file -Algorithm SHA256).Hash
    "{0,-8} {1}" -f $(if ($actual -eq $hash.ToUpper()) { "OK" } else { "MISMATCH" }), $file
}
```

En Linux o macOS:

```bash
sha256sum -c checksum.txt
# john.smith.pst: OK
# john.smith-2.pst: OK
```

Si una huella no coincide, vuelva a descargar el archivo. Si el error persiste, solicite una nueva exportación.

Para abrir el resultado en Outlook clásico para Windows, vaya a <code className="action">Archivo</code> > <code className="action">Abrir y exportar</code> > <code className="action">Abrir archivo de datos de Outlook</code> y, a continuación, seleccione cada fichero `.pst` extraído. A día de hoy, el nuevo Outlook para Windows no abre los ficheros `.pst`.

:::info
**Limitaciones**

- La duración de la exportación depende del tamaño del buzón: unos minutos para un buzón pequeño, varias horas para uno grande. No existe ningún medio de acelerarla.
- Un buzón solo admite una única solicitud de exportación, y una nueva solo se acepta 24 horas después de la anterior para la misma dirección de correo electrónico.
- La exportación solo se aplica a los buzones individuales: los grupos, las cuentas compartidas y las cuentas de recursos no están cubiertos.

:::
