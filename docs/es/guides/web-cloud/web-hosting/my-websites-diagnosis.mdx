## Objetivo

Puede alojar varios sitios web en la misma oferta de alojamiento web, incluso si los nombres de dominio no están registrados en OVHcloud. Además, puede asociar uno o varios nombres de dominio o subdominios a un mismo sitio web.

**Utilice nuestra herramienta de diagnóstico para comprobar que su nombre de dominio o subdominio está correctamente declarado con su sitio web en su alojamiento web.**

:::info
Este procedimiento se aplica a la <ManagerLink to="/beta/#/">nueva versión del área de cliente de OVHcloud</ManagerLink>, actualmente disponible en beta. Para seguirlo, cambie a esta interfaz desde su área de cliente habitual.

:::

## Requisitos

- Disponer de una oferta de [alojamiento web OVHcloud](https://www.ovhcloud.com/es-es/web-hosting/uc-multisite/) compatible.
- Disponer de uno o varios [nombres de dominio](https://www.ovhcloud.com/es-es/domains/).
- Poder modificar la configuración de sus nombres de dominio desde la [zona DNS](/guides/web-cloud/domains/dns-zone-edit).

## En práctica

### Acceder a la herramienta de diagnóstico

Haga clic en las fichas siguientes para ver cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting/sites">Alojamientos</ManagerLink> y seleccione el alojamiento web correspondiente.

    <img className="thumbnail" alt="Alojamientos" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la nueva página, haga clic en la pestaña <code className="action">Mis sitios</code>.

    <img className="thumbnail" alt="Mis sitios" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la tabla que aparece, haga clic en el botón <code className="action">></code> situado a la izquierda del nombre del sitio web correspondiente para mostrar los nombres de dominio o subdominios asociados.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Los nombres de dominio o subdominios asociados a su sitio web aparecen. 

    <img className="thumbnail" alt="Domains associated websites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab-with-domains-associated-displayed.png" loading="lazy" />

    La columna `Diagnóstico` le informa si su nombre de dominio apunta correctamente al alojamiento web asociado. Esta columna le permite comprobar rápidamente que la configuración DNS de su nombre de dominio está correctamente realizada con su alojamiento web. Así, esta columna le ayuda a identificar y resolver posibles problemas de apuntado. Para cada nombre de dominio, hay tres resultados posibles de diagnóstico:

    - `A/AAAA` verde.
    - `A/AAAA` amarillo.
    - `A/AAAA` gris.

    Consulte la sección "[Interpretación de los colores de la herramienta de diagnóstico](#interpretation)" de esta guía para conocer el significado de estos 3 colores.
  </Tab>
</Tabs>

### Interpretación de los colores de la herramienta de diagnóstico <a name="interpretation"></a>

**Haga clic en los indicadores de estado correspondientes a continuación para ver sus explicaciones.**

<details>
<summary>A/AAAA verde</summary>

<img className="thumbnail" alt="A and AAAA green" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/diagnostic-green-info.png" loading="lazy" />

Cuando el icono `A/AAAA` es verde en la columna `Diagnóstico`, esto significa que el registro **A** (para direcciones IPv4) y/o el registro **AAAA** (para direcciones IPv6) de su nombre de dominio apunta correctamente a la dirección IP de su alojamiento web. Por tanto, la configuración DNS de su nombre de dominio es coherente para funcionar con el sitio web de su alojamiento web.

</details>

<details>
<summary>A/AAAA amarillo</summary>

<img className="thumbnail" alt="A and AAAA yellow" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/diagnostic-yellow-info.png" loading="lazy" />

Cuando el icono `A/AAAA` es amarillo en la columna `Diagnóstico`, esto significa que el registro **A** (IPv4) y/o **AAAA** (IPv6) de su nombre de dominio apunta a una dirección IP, pero no es la del alojamiento web desde el cual está consultando la columna `Diagnóstico`.

Para resolver los problemas de apuntado DNS de su nombre de dominio y asegurarse de que apunta correctamente al alojamiento web deseado, siga los pasos descritos en nuestra guía "[Editar una zona DNS de OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".

</details>

<details>
<summary>A/AAAA gris</summary>

<img className="thumbnail" alt="A and AAAA grey" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/diagnostic-grey-info.png" loading="lazy" />

Cuando el icono `A/AAAA` es gris en la columna `Diagnóstico`, esto significa que el nombre de dominio no apunta actualmente a ninguna dirección IP y que no hay ningún registro **A** (IPv4) o **AAAA** (IPv6) configurado para este nombre de dominio.

Para añadir los registros **A** y/o **AAAA** y configurar correctamente su nombre de dominio, siga los pasos descritos en nuestra guía "[Editar una zona DNS de OVHcloud](/guides/web-cloud/domains/dns-zone-edit)".

</details>
