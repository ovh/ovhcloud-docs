## Objetivo

Los alojamientos web funcionan en una infraestructura compartida denominada *cluster*. OVHcloud dispone de varios clusters en los que se reparten varios alojamientos web.
Cada cluster, por motivos de eficacia y seguridad, también se divide virtualmente en varios segmentos denominados *filers*. Los filers contienen varios alojamientos web.
Al utilizar un alojamiento web, es posible que deba conocer el número del cluster o del filer en el que se encuentra el alojamiento web.

**Descubra cómo encontrar el número de cluster y el número de filer en el que se encuentra su alojamiento web.**

## Requisitos

- Tener contratado un plan de [alojamiento web](/links/web/hosting).

[[cpnav:web-hosting-console]]

## Procedimiento

Haga clic en las fichas siguientes para ver cada una de las **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la pestaña <code className="action">Vista general</code>, localice la sección **Información general**. Indica sucesivamente la **Región** en la que se encuentra su alojamiento web, su **Cluster** y su **Filer**.

    El cluster se muestra con el formato `clusterXXX`, donde las tres cifras identifican el cluster. El filer, por su parte, es un número de longitud variable.

    <img className="thumbnail" alt="Sección Información general y campos Región, Cluster y Filer" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/region-cluster-filer.png" loading="lazy" />
  </Tab>
</Tabs>
