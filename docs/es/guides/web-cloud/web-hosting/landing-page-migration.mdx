## Migrar su sitio web a OVHcloud

Migre su sitio web y sus datos a su alojamiento web OVHcloud. Esta página reúne las guías para migrar un sitio completo a OVHcloud, exportar e importar sus datos (archivos y base de datos) y gestionar los casos asociados como el cambio de dominio.

Para orientarse según su necesidad:

- **¿Desea migrar un sitio completo, WordPress o Xara?** Consulte la sección *Migrar un sitio web a OVHcloud*.
- **¿Desea exportar o importar su sitio web y sus bases de datos?** Consulte la sección *Exportar e importar sus datos*.
- **¿Desea migrar a un VPS, cambiar de dominio o pasar de MySQL a Percona?** Consulte la sección *Otras migraciones*.
