## Objetivo

Esta guía explica las versiones de **PHP**, **Python**, **Perl** y **Apache** utilizadas como parte de los servicios [Web Hosting](/links/web/hosting) a los que se puede acceder a través de la red de Web Hosting.

**Descubra los detalles de las versiones de PHP, Python, Perl y Apache.**

## Requisitos

- Tener contratado un [plan de alojamiento web de OVHcloud](/links/web/hosting).

## Procedimiento

Las siguientes tablas indican las versiones de los lenguajes disponibles en los planes de alojamiento web de OVHcloud y su estado. Cada versión remite a su página de información, que indica el número de versión completo y la configuración.

### Estado de las versiones

<span style={{backgroundColor:"#198754", color:"white", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Con soporte</span>: versión mantenida en los planes de alojamiento web.

<span style={{backgroundColor:"#ffc107", color:"#212529", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Fin de vida</span>: migre a una versión con soporte antes de su fin de vida en OVHcloud.

<span style={{backgroundColor:"#dc3545", color:"white", padding:"2px 6px", borderRadius:"6px", whiteSpace:"nowrap"}}>Obsoleta</span>: versión que ya no se mantiene; migre a una versión con soporte.
