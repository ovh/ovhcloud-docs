## Objetivo

La mayoría de los sitios web utilizan una **base de datos** para almacenar sus artículos, comentarios o direcciones de correo electrónico de sus usuarios.

La conexión a esta base de datos es posible gracias a un **archivo de configuración** que se encuentra en el [espacio de almacenamiento de archivos](/guides/web-cloud/web-hosting/ftp-connection) del alojamiento. Que contiene la información que permite al sitio web "identificarse" con el **servidor de la base de datos**.

Por lo tanto, siempre debe cambiar la contraseña de una base de datos:

- En el [archivo de configuración](/guides/web-cloud/web-hosting/cms-manage-1-click-module#etapa-1-identificar-la-base-de-datos-asociada-a-su-modulo) de su sitio web a través del [espacio FTP de su alojamiento](/guides/web-cloud/web-hosting/ftp-connection);

- **Y** en el servidor que contiene la base de datos desde la <ManagerLink to="/beta/#/">consola de OVHcloud</ManagerLink>.

Mientras no se realice el cambio **en estos dos lugares**, el sitio web mostrará un "[error al conectar a la base de datos](/guides/web-cloud/web-hosting/diagnosis-database-errors#error-al-conectar-a-la-base-de-datos)".

Si desea cambiar la contraseña de la base de datos, deberá realizar todas **las operaciones** que se indican en esta guía. En caso de duda sobre las operaciones a realizar, contacte con su webmaster o contacte con un [proveedor especializado](/links/partner).

La modificación de la contraseña de la base de datos del sitio web se realiza en cuatro partes:

- [1. Identificar el archivo de configuración del sitio web](#step1);
- [2. Identificar la base de datos del sitio web](#step2);
- [3. Cambiar la contraseña de la base de datos del sitio web en el archivo de configuración](#step3);
- [4. Cambiar la contraseña de la base de datos del sitio web en el servidor de bases de datos](#step4).

**Esta guía explica cómo cambiar la contraseña de una base de datos de forma segura.**

[[fragment:support-scope]]

## Requisitos

- Tener contratado un plan de [hosting de OVHcloud](/links/web/hosting).
- Utilizar una [base de datos asociada a su plan de hosting](/links/web/hosting-options-startsql) o a un [servidor Web Cloud Databases](/links/web/databases).
- Disponer de las claves FTP para conectarse al [espacio de almacenamiento](/guides/web-cloud/web-hosting/ftp-connection) del alojamiento.

## Procedimiento

### 1: Identificar el archivo de configuración del sitio web <a name="step1"></a>

Haga clic en las pestañas siguientes para ver cada uno de los **3** pasos.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">Mis sitios</code>.

    <img className="thumbnail" alt="Pestaña Mis sitios de un alojamiento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la tabla, localice la línea de su sitio web con la columna **Sitio** y consulte su columna **Carpeta raíz**. Se trata del directorio en el que se encuentran los archivos y carpetas de su sitio web.

    <img className="thumbnail" alt="Tabla de los sitios y su columna Carpeta raíz" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/root-folders.png" loading="lazy" />

    A continuación, acceda al espacio de almacenamiento FTP que contiene los archivos y carpetas de su sitio consultando [esta guía](/guides/web-cloud/web-hosting/ftp-connection).
  </Tab>
</Tabs>

:::info
Si desea cambiar la contraseña de su espacio FTP, consulte [esta guía](/guides/web-cloud/web-hosting/ftp-change-password).

:::

Abra la `Carpeta raíz` anteriormente indicada.

Busque y abra el archivo de configuración de su sitio web:

- Para un sitio web WORDPRESS, se trata de **"wp-config.php"**;
- Para un sitio web JOOMLA, se trata de **"configuration.php"**;
- Para un sitio web DRUPAL, haga clic en el directorio **"sites"** y luego en **"default"**. El archivo de configuración es **"settings.php"**;
- Para un sitio web PRESTASHOP, haga clic en el directorio **"app"** y luego en **"config"**. El archivo de configuración es **"parameters.php"**.

### 2: Identificar la base de datos del sitio web <a name="step2"></a>

Existen dos posibilidades:

- Caso n° 1: la base de datos de su sitio web forma parte de su plan de hosting;
- Caso n° 2: está incluida en una solución *Web Cloud Databases*, en cuyo caso deberá encontrar el **nombre del servidor** y el **nombre de usuario** de la base de datos para identificarla sin riesgo de error.

Para determinar qué casos se aplican al sitio web, en el archivo de configuración indicado en la [parte 1](#step1), empiece por anotar el nombre de la base de datos:

- Para WORDPRESS: el nombre aparece con la mención **"DB_NAME"**;
- Para JOOMLA: el nombre aparece en **"public $db"**;
- Para DRUPAL: el nombre aparece en **"database"**;
- Para PRESTASHOP: el nombre aparece en **"database_name"**.

Vuelva a la <ManagerLink to="/beta/#/web-cloud/hosting">consola de OVHcloud</ManagerLink>, en el universo <code className="action">Web Cloud</code>:

- Acceda a la sección <code className="action">Alojamiento web</code> y seleccione el alojamiento correspondiente.
- Haga clic en la pestaña <code className="action">Bases de datos</code>, en la barra de pestañas situada debajo del nombre de su alojamiento.
- Busque el nombre de la base de datos encontrada anteriormente en la columna **Nombre de la base**.

Si ha encontrado en esta sección de la consola de OVHcloud el nombre de la base de datos indicada en el archivo de configuración, pase a la [parte 3](#step3).

En caso contrario, la base de datos del sitio web está asociada a un servicio [Web Cloud Databases](/links/web/databases).

En ese caso, deberá volver al archivo de configuración del sitio web para registrar el *nombre del servidor* y el *nombre de usuario* de la base de datos:

- Para WORDPRESS: el *nombre del servidor* aparece bajo la mención **"DB_HOST"** y el *nombre de usuario* bajo la mención **"DB_USER"**;
- Para JOOMLA: el *nombre del servidor* aparece en **"public $host"** y el *nombre de usuario* bajo la mención **"public $user"**;
- Para DRUPAL: el *nombre del servidor* aparece en **"host"** y el *nombre de usuario* bajo la mención **"username"**;
- Para PRESTASHOP: el *nombre del servidor* aparece en **"database_host"** y el *nombre de usuario* bajo la mención **"database_user"**.

A continuación, acceda a la sección <code className="action">Web Cloud DB</code> de la consola de OVHcloud y seleccione la instancia correspondiente.

En la pestaña <code className="action">Vista general</code>, localice la sección **SQL** y su campo **Nombre de host**: contiene el nombre del servidor de la base de datos que haya encontrado antes.

:::warning
No confunda este campo con el denominado **Host**, situado más arriba en la sección **Información general**: este designa la infraestructura que aloja su instancia, y no la dirección que utiliza su sitio web para conectarse a ella.

:::

<img className="thumbnail" alt="Vista general de una instancia Web Cloud DB y su campo Nombre de host" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/overview-hostname.png" loading="lazy" />

En la misma instancia, abra la pestaña <code className="action">Usuarios y permisos</code> para identificar también el **nombre de usuario** de la base de datos. Cada usuario se presenta en forma de ficha con su nombre.

### 3: Cambiar la contraseña de la base de datos del sitio web en el archivo de configuración <a name="step3"></a>

:::info
Para más información sobre las buenas prácticas de gestión de contraseñas, consulte esta [guía](/guides/account-and-service-management/account-information/manage-ovh-password).

:::

Seleccione la nueva contraseña de la base de datos y anótela. Deberá cumplir las siguientes condiciones:

- Mínimo 8 caracteres;
- Máximo 30 caracteres;
- Al menos una letra mayúscula;
- Al menos una letra minúscula;
- Al menos una cifra;
- Estar compuesto únicamente por números y letras.

Así como en la [parte 1](#step1), vuelva al espacio de almacenamiento de archivos de su alojamiento y abra el archivo de configuración del sitio web editando.

**Antes de realizar cualquier modificación**, guarde localmente el contenido del archivo en un documento de texto para poder guardar una copia de él en caso de que se produzca algún error.

Sustituya manualmente la contraseña de su base de datos **evitando modificar o eliminar cualquier otro elemento del archivo de configuración** (en los siguientes extractos, solo debe sustituir la contraseña de ejemplo "*0VhCloudPa55w0rdDB123*"):

- En el archivo de configuración de un sitio web WORDPRESS, modifique el **"DB_PASSWORD"**:

```php
// ** MySQL settings - You can get this info from your web host ** //
/** The name of the database for WordPress */
define('DB_NAME', 'dbname123');
 
/** MySQL database username */
define('DB_USER', 'dbname123');
 
/** MySQL database password */
define('DB_PASSWORD', '0VhCloudPa55w0rdDB123');
 
/** MySQL hostname */
define('DB_HOST', 'dbname123.mysql.db:3306');
```

- En el archivo de configuración de un sitio web JOOMLA, cambie el **"public $password"** (justo al final del archivo de configuración):

```php
public $host = 'dbname123.mysql.db:3306';
public $user = 'dbname123';
public $password = '0VhCloudPa55w0rdDB123';
public $db = 'dbname123';
```

- En el archivo de configuración de un sitio web DRUPAL, modifique el **"password"**:

```php
$databases['default']['default'] = array (
  'database' => 'dbname123',
  'username' => 'dbname123',
  'password' => '0VhCloudPa55w0rdDB123',
  'prefix' => 'prefix123_',
  'host' => 'dbname123.mysql.db',
  'port' => '3306',
```

- En el archivo de configuración de PRESTASHOP, modifique el **"database_password"**:

```php
'database_host' => 'dbname123.mysql.db',
'database_port' => '3306',
'database_name' => 'dbname123',
'database_user' => 'dbname123',
'database_password' => '0VhCloudPa55w0rdDB123',
```

Guarde el cambio.

### 4: Cambiar la contraseña de la base de datos del sitio web en el servidor de bases de datos <a name="step4"></a>

:::info
Esta operación tardará unos minutos en aplicarse. Una vez iniciada, compruebe su estado en la pestaña <code className="action">Operaciones</code>, que muestra el número de operaciones en curso.

:::

De nuevo, existen dos posibles situaciones: 

- Si la base de datos se encuentra en la sección dedicada al [alojamiento web](/links/web/hosting) de la <ManagerLink to="/beta/#/">consola de OVHcloud</ManagerLink>, siga estas [instrucciones](#case1).
- Si su base de datos se encuentra en la sección de la <ManagerLink to="/beta/#/">consola de OVHcloud</ManagerLink> dedicada a sus productos de [Web Cloud Databases](/guides/web-cloud/databases/landing-page-databases), siga estas [instrucciones](#case2).

#### Caso n° 1: la base de datos de su sitio web forma parte de su plan de hosting <a name="case1"></a>

Haga clic en las fichas siguientes para ver cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">Bases de datos</code>.

    <img className="thumbnail" alt="Pestaña Bases de datos de un alojamiento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la línea de la base de datos de su sitio web, haga clic en el botón <code className="action">⁝</code> de la columna **Acciones** y seleccione <code className="action">Cambiar contraseña</code>.

    <img className="thumbnail" alt="Menú de una línea de la tabla de bases de datos" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/change-password.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Se abrirá una ventana en la que deberá introducir la nueva contraseña de la base de datos (definida en la [sección 3](#step3)). Confírmela y haga clic en <code className="action">Modificar</code>.

    <img className="thumbnail" alt="Ventana de cambio de contraseña de una base de datos" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/change-password-window.png" loading="lazy" />

Debajo del campo, la ventana recuerda la regla que debe cumplir esta contraseña: de **9 a 30 caracteres**, incluidos una minúscula, una mayúscula y una cifra; **se admiten caracteres especiales**.
  </Tab>
</Tabs>

#### Caso n° 2: la base de datos de su sitio web forma parte de una solución Web Cloud Databases. <a name="case2"></a>

Acceda a la sección <code className="action">Web Cloud DB</code> de la consola de OVHcloud, seleccione la instancia correspondiente y abra la pestaña <code className="action">Usuarios y permisos</code>:

<img className="thumbnail" alt="Pestaña Usuarios y permisos de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-tab.png" loading="lazy" />

Cada usuario se presenta en forma de ficha con su nombre. En la del **nombre de usuario** identificado en la [parte 2](#step2), haga clic en el botón <code className="action">⁝</code> y luego en <code className="action">Cambiar contraseña</code>.

<img className="thumbnail" alt="Menú de una ficha de usuario de una instancia Web Cloud DB" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password.png" loading="lazy" />

Se abrirá una ventana en la que deberá introducir la nueva contraseña de la base de datos (definida en la [parte 3](#step3)). Confírmela y haga clic en <code className="action">Guardar</code>.

<img className="thumbnail" alt="Ventana de modificación de la contraseña de un usuario" src="/images/assets/screens/console/product-selection/web-cloud/web-cloud-databases/users-and-rights/wcdb-change-password-window.png" loading="lazy" />

:::warning
La regla de complejidad no es la misma que para una base de datos de alojamiento web: aquí, la contraseña debe tener de **8 a 30 caracteres**, incluidos una minúscula, una mayúscula y una cifra, y **se admiten caracteres especiales**. La ventana la recuerda debajo del campo.

:::
