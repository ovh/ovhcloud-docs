## Objetivo

Las ofertas de alojamiento web de OVHcloud ofrecen acceso a un espacio de almacenamiento que permite subir los archivos de sus sitios web o aplicaciones. El acceso a este espacio es posible mediante un usuario FTP o SSH con las contraseñas asociadas a cada uno.

Al igual que el **F**ile **T**ransfer **P**rotocol (**FTP**), el **S**ecure **F**ile **T**ransfer **P**rotocol (**SFTP**) permite transferir datos de su dispositivo al espacio de almacenamiento de su alojamiento web.

La única diferencia es que el SFTP utiliza un canal seguro para intercambiar datos. Los datos que pasan a través de este protocolo se cifran automáticamente.

**Descubra cómo activar el acceso SFTP en su alojamiento web OVHcloud.**

## Requisitos

- Tener una oferta de [alojamiento web OVHcloud](/links/web/hosting).

[[cpnav:web-hosting]]

## Procedimiento

### Activar el acceso SFTP para un usuario FTP de su alojamiento web

Haga clic en las fichas siguientes para ver cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Pestaña FTP-SSH de un alojamiento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la sección **Usuarios FTP y SSH**, compruebe el estado que se muestra en la columna **SFTP** para el usuario FTP correspondiente:

    - **Activado**: el protocolo SFTP ya está activo para este usuario, no tiene que hacer nada.
    - **Desactivado**: en la columna **Acciones**, haga clic en el botón <code className="action">⋮</code> situado a la derecha de la línea correspondiente y luego en <code className="action">Editar</code>.

    <img className="thumbnail" alt="Tabla de los usuarios FTP y estado del protocolo SFTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/ftp-users-sftp-status.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Se abre el panel **Modificar un usuario** a la derecha. En el menú desplegable **Protocolos de conexión**, seleccione <code className="action">FTP y SFTP</code> o <code className="action">FTP, SFTP y SSH</code> si también necesita activar el protocolo SSH.

    <img className="thumbnail" alt="Panel Modificar un usuario y menú Protocolos de conexión" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user-protocols.png" loading="lazy" />

El menú ofrece un tercer valor, <code className="action">FTP</code> solo, que desactiva el SFTP para este usuario.

    Por último, haga clic en <code className="action">Confirmar</code>. Una vez activada la opción **SFTP**, podrá utilizar el protocolo SFTP de su alojamiento web con el usuario FTP correspondiente.
  </Tab>
</Tabs>

:::info
El valor <code className="action">FTP, SFTP y SSH</code> solo se ofrece en los planes que incluyen el acceso SSH: **Pro**, **Performance**, **Agency**, **Agency Plus** y **Agency Max**.

En los planes <Region zones={['eu']}>**gratuito**, **Starter**, **Personal** y **Startup**</Region><Region zones={['ca', 'apac']}>**Starter**, **Personal** y **Startup**</Region>, el menú **Protocolos de conexión** solo ofrece <code className="action">FTP</code> y <code className="action">FTP y SFTP</code>, y la tabla de usuarios no muestra la columna **SSH**.

:::
