## Objetivo

Puede alojar varios sitios web en un mismo plan de alojamiento web, incluso si los dominios no están registrados en OVHcloud. Además, puede asociar uno o varios dominios o subdominios a un mismo sitio web.

Al utilizar sus servicios, puede necesitar:

- Sustituir la totalidad del contenido de un sitio web existente, sin eliminarlo de su alojamiento web. Todo ello sin interrupción de acceso y con total transparencia para los visitantes de su sitio web.
- Instalar un [módulo en 1 clic](/guides/web-cloud/web-hosting/cms-install-1-click-modules) u [otro CMS](/guides/web-cloud/web-hosting/cms-manual-installation) para reemplazar el contenido de un sitio web existente, sin eliminar el antiguo contenido de su alojamiento web. En este caso concreto, deberá construir las diferentes páginas de su nuevo sitio web a través de su navegador de Internet.
- Reorganizar los nombres de las carpetas raíz de sus sitios web en el espacio de almacenamiento de su alojamiento web sin cortar el acceso a sus diferentes sitios web.

**Descubra cómo modificar la carpeta raíz declarada para un sitio web ya existente en su alojamiento web desde la consola de OVHcloud.**

:::info
Si aún no ha creado el sitio web en su alojamiento web, consulte **directamente** [esta guía](/guides/web-cloud/web-hosting/multisites-configure-multisite).

La consola permite modificar la carpeta raíz de un sitio web, incluso cuando está asociado a un repositorio Git (en ese caso, consulte nuestra guía "[Configurar y utilizar Git con un alojamiento web de OVHcloud](/guides/web-cloud/web-hosting/git-integration-webhosting)"). Solo el sitio que lleva el dominio principal de su alojamiento web no puede cambiarla: el campo aparece entonces en gris.

:::

## Requisitos

- Disponer de un plan de [alojamiento web de OVHcloud](https://www.ovhcloud.com/es-es/web-hosting/uc-multisite/) compatible.
- Disponer de uno o varios [dominios](https://www.ovhcloud.com/es-es/domains/).

## Procedimiento

:::warning
Esta guía presenta exclusivamente las acciones a realizar desde la <ManagerLink to="/beta/#/">consola de OVHcloud</ManagerLink>.

A excepción del caso en el que desee instalar un módulo en 1 clic para construir el sitio web progresivamente, deberá previamente:

- Crear la nueva carpeta raíz en el [espacio de almacenamiento](/guides/web-cloud/web-hosting/ftp-connection) de su alojamiento web.
- Colocar la totalidad del nuevo contenido de su sitio web dentro de esta nueva carpeta.
- Si el nuevo contenido de su sitio web funciona con una base de datos, deberá también [crear una base de datos](/guides/web-cloud/web-hosting/sql-create-database) e [importar el contenido relativo a dicha base de datos](/guides/web-cloud/web-hosting/sql-importing-mysql-database).
- Colocar las credenciales de acceso a la base de datos en el archivo que contiene la información de conexión a la base de datos. Este archivo debe estar ya presente en la nueva carpeta raíz.

**Sin estas acciones, la visualización de su sitio web se interrumpirá**.

Esta guía describe únicamente el procedimiento para modificar, desde la consola de OVHcloud, la carpeta raíz definida inicialmente para su sitio web. Esta acción es necesaria para que el sitio web muestre el contenido de la nueva carpeta, en sustitución de la antigua.

:::

Haga clic en las pestañas de abajo para ver cada uno de los **3** pasos.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">Mis sitios</code>. En la tabla, haga clic en el botón <code className="action">⋮</code> situado en la columna **Acciones**, a la derecha del sitio web correspondiente, y luego, en el grupo **Sitio**, en <code className="action">Configurar mi sitio</code>.

    <img className="thumbnail" alt="Menú Acciones de un sitio web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    El panel **Configurar mi sitio** se abre a la derecha. En el campo **Carpeta raíz**, sustituya la antigua carpeta raíz por la nueva.

    <img className="thumbnail" alt="Panel Configurar mi sitio, campos Nombre del sitio y Carpeta raíz" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/configure-site.png" loading="lazy" />

    :::info
    El panel también permite cambiar el nombre de su sitio web, en el campo **Nombre del sitio**. Este nombre solo sirve para identificar el sitio en la consola de OVHcloud y no afecta a su dirección ni a su contenido. Déjelo tal cual si solo desea modificar la carpeta raíz.
    :::

    Por último, haga clic en <code className="action">Confirmar</code>, en la parte inferior del panel. Si ha cambiado de carpeta, la ventana **Editar la carpeta raíz** resume la carpeta actual, la nueva carpeta y los dominios asociados: vuelva a hacer clic en <code className="action">Confirmar</code>.
  </Tab>
</Tabs>
