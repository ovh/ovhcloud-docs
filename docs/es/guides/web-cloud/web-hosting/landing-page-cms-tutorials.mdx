## Instalar un CMS en su alojamiento web

Un CMS (Content Management System, o sistema de gestión de contenidos) es un software que permite crear y gestionar un sitio web sin programar, desde una interfaz de administración.

Instale el CMS de su elección en su alojamiento web OVHcloud. Esta página reúne las guías de instalación manual de los principales CMS (WordPress, Joomla, PrestaShop, Drupal y más), o la instalación de un módulo en 1 clic directamente desde su área de cliente de OVHcloud.

Para orientarse según su necesidad:

- **¿Está pensando en instalar un CMS para su sitio web?** Consulte la sección *Cómo instalar un CMS*.
- **¿Desea instalar uno de los CMS más utilizados (WordPress, Joomla, PrestaShop, Drupal)?** Consulte la sección *Los CMS más utilizados*.
- **¿Busca instalar otro CMS (Grav, Pico, Typo3, SPIP)?** Consulte la sección *Otros CMS*.
