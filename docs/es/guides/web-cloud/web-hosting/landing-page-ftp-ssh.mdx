## Acceder a su alojamiento web por FTP, SFTP y SSH

Transfiera sus archivos y gestione su alojamiento web OVHcloud mediante los protocolos FTP, SFTP y SSH. Esta página reúne las guías para conectarse con un cliente (FileZilla, Cyberduck, Visual Studio Code), gestionar sus accesos FTP y conectarse por SSH, mediante PuTTY o directamente desde la línea de comandos.

Para orientarse según su necesidad:

- **Conectarse con un cliente** (FileZilla, Cyberduck, Visual Studio Code): empiece por la sección *Conectarse por FTP/SFTP*.
- **Gestionar sus accesos FTP** (usuarios, contraseñas, SFTP): consulte la sección *Gestionar los accesos FTP*.
- **Acceso SSH y línea de comandos** (SSH, PuTTY, SCP, SVN): consulte la sección *Acceso SSH y herramientas en línea de comandos*.
