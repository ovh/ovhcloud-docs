## Gestionar las bases de datos de su alojamiento web

Cree, administre y haga copias de seguridad de las bases de datos de su alojamiento web OVHcloud. Esta página reúne las guías para gestionar sus bases de datos, hacer copias de seguridad, importar y restaurar sus datos, y resolver los errores más frecuentes.

Para orientarse según su necesidad:

- **¿Desea crear o configurar una base de datos?** Consulte la sección *Gestionar una base de datos* (crear, contraseña, duplicar).
- **¿Desea hacer una copia de seguridad o restaurar sus datos?** Consulte la sección *Copia de seguridad y restauración* (recuperar, importar, restaurar).
- **¿Tiene un error de base de datos?** Consulte la sección *Resolución de problemas* (errores comunes, base de datos saturada).
