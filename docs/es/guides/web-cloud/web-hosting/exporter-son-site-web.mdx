## Objetivo

Esta guía explica los pasos que debe seguir para exportar todos los elementos de su sitio web al formato estándar desde un [alojamiento web de OVHcloud](/links/web/hosting).

**Esta guía explica cómo exportar un sitio web de OVHcloud.**

:::info
Algunos procedimientos de esta guía se aplican a la <ManagerLink to="/beta/#/">nueva versión del área de cliente de OVHcloud</ManagerLink>.
Aparece un recordatorio al principio de cada sección correspondiente.

:::

## Requisitos

- Tener contratado un plan de [hosting de OVHcloud](/links/web/hosting).

## Procedimiento

### 1 - Recuperación de los archivos de su espacio de almacenamiento FTP

#### 1.1 Conectarse al espacio de almacenamiento.

Para conectarse a su espacio de almacenamiento necesitará lo siguiente:

- el usuario FTP o SSH activo.
- la contraseña del usuario FTP o SSH.
- la dirección del servidor.
- el puerto de conexión al servidor.

Habrá recibido esta información por correo electrónico tras la instalación de su alojamiento.

Si no dispone de ellos, haga clic en las fichas siguientes para ver cada una de las **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/#/web/hosting">Alojamientos</ManagerLink> y seleccione el alojamiento web correspondiente.

    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la nueva página, haga clic en la pestaña <code className="action">FTP - SSH</code>.

    <img className="thumbnail" alt="FTP - SSH" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Se mostrará la información relativa a su espacio de almacenamiento. Entre esa información se encuentran los datos necesarios para conectarse a este último.

    <img className="thumbnail" alt="FTP - SSH tab" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/ftp-ssh/tab-pro.png" loading="lazy" />

Para más información, consulte nuestra guía [Conectarse al espacio de almacenamiento de un alojamiento web"](/guides/web-cloud/web-hosting/ftp-connection).

    Si no tiene la contraseña, consulte la guía [Cambiar la contraseña de un usuario FTP](/guides/web-cloud/web-hosting/ftp-change-password).
  </Tab>
</Tabs>

Una vez que disponga de todos los elementos necesarios, la recuperación de los archivos en el espacio de almacenamiento puede realizarse de dos formas diferentes:

- **Cliente FTP o SFTP**: deberá instalar en su ordenador un programa compatible, como [FileZilla](/guides/web-cloud/web-hosting/ftp-filezilla-user-guide). Si necesita ayuda, le recomendamos que se ponga en contacto con el editor del programa instalado, ya que OVHcloud no lo ha creado.

- **Acceso SSH**: Para interactuar con su espacio de almacenamiento, deberá ejecutar comandos desde un terminal. Este tipo de acceso requiere conocimientos técnicos avanzados y un [plan de hosting de OVHcloud](/links/web/hosting) específico. Para más información, consulte nuestra guía ["Utilizar el acceso SSH de un alojamiento web"](/guides/web-cloud/web-hosting/ssh-on-webhosting). 

#### 1.2. Descargar los archivos desde el espacio de almacenamiento.

Una vez conectado a su espacio de almacenamiento y según los sitios web alojados en él, pueden aparecer varios directorios.

Si es necesario, identifique previamente en su alojamiento web el nombre del directorio raíz en el que se almacena su sitio web. Para ello, haga clic en las fichas siguientes para ver cada una de las **3** etapas.

:::info
Esta sección se aplica a la <ManagerLink to="/beta/#/">nueva versión del área de cliente de OVHcloud</ManagerLink>.

:::

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting/sites">Alojamientos</ManagerLink> y seleccione el alojamiento web correspondiente.

    <img className="thumbnail" alt="Alojamientos" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la nueva página, haga clic en la pestaña <code className="action">Mis sitios</code>.

    <img className="thumbnail" alt="Mis sitios" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la tabla que aparece, para el sitio web deseado, mire el <code className="action">Carpeta raíz</code> que se muestra.

    <img className="thumbnail" alt="export-website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/root-folders.png" loading="lazy" />
  </Tab>
</Tabs>

Siempre conectado a su espacio de almacenamiento, solo le queda descargar los archivos de su sitio web accediendo al directorio raíz identificado anteriormente.

### 2 - Recuperar la copia de seguridad de la base de datos (opcional)

:::info
Si su sitio web no utiliza bases de datos, puede omitir este paso.

:::

Para obtener una copia de seguridad de la base de datos, consulte nuestra guía:
[Exportar una copia de seguridad de la base de datos de un alojamiento web](/guides/web-cloud/web-hosting/sql-database-export).

Si utiliza una base de datos **Web Cloud Databases** para su sitio web, consulte la sección relativa al backup de nuestra guía:
[Guardar y exportar una base de datos en un servidor de bases de datos](/guides/web-cloud/databases/db-backup-export-database-server).

### 3 - Obtener los logs de su alojamiento de OVHcloud

Consulte nuestra guía dedicada: [Alojamiento web - Consultar las estadísticas y logs de un sitio web](/guides/web-cloud/web-hosting/logs-and-statistics).
