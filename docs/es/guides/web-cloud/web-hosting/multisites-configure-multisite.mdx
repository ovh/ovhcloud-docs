## Objetivo

Puede alojar varios sitios web en una misma oferta de alojamiento web, incluso si los nombres de dominio no están registrados en OVHcloud.

¿Desea añadir un nuevo sitio web a su alojamiento web?

**Descubra cómo alojar diferentes sitios web en su oferta de alojamiento web.**

:::info
Si ya ha creado el sitio web en cuestión en su alojamiento web y desea asociarle un nuevo nombre de dominio o subdominio, consulte **directamente** [esta guía](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).

:::

## Requisitos

- Disponer de una [oferta de alojamiento web OVHcloud](/links/web/hosting-multisite) compatible.
- Tener uno o más [dominios](/links/web/domains).
- Poder modificar la configuración de sus dominios (la [zona DNS](/guides/web-cloud/domains/dns-zone-edit)).

[[cpnav:web-hosting-console]]

## Procedimiento

### 1 - Añadir un sitio web a su oferta de alojamiento web

**Haga clic en uno de los títulos siguientes para ver las explicaciones.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Añadir un sitio web con un dominio gestionado en su cuenta de OVHcloud</summary>

Esta parte solo se aplica si el dominio (y/o su zona DNS activa) con el que desea crear su sitio web se encuentra **en su cuenta de OVHcloud**.

El formulario de adición ocupa una sola página: complételo de arriba abajo y valídelo. Haga clic en las pestañas de abajo para ver cada uno de los **5** pasos.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">Mis sitios</code> y luego en el botón <code className="action">Añadir un sitio</code>, encima de la tabla.

    <img className="thumbnail" alt="Pestaña Mis sitios y botón Añadir un sitio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-button.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la sección **Carpeta raíz**, introduzca el nombre de la carpeta que contendrá los archivos de su sitio web. Deje el campo vacío para que la consola la cree automáticamente.

    En la sección **Asociación del nombre de dominio**, elija la opción **Nombre de dominio OVHcloud existente**.

    <img className="thumbnail" alt="Carpeta raíz y elección del tipo de nombre de dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    :::warning
    La **carpeta raíz** también se crea en el espacio de almacenamiento de su alojamiento web, accesible por FTP, SFTP o SSH según su plan. Si el contenido de su sitio web ya se encuentra en una carpeta concreta de este espacio, indique aquí su nombre.
    :::
  </Tab>
  <Tab label="Etapa 4">
    Aparecerá la sección **Configurar su dominio**. En el campo **Nombre del sitio**, introduzca el nombre que desee: solo sirve para identificar su sitio en la consola de OVHcloud. A continuación, seleccione el dominio que desea asociar en el menú desplegable **Nombre de dominio**.

    <img className="thumbnail" alt="Configuración del dominio, opciones y configuración DNS" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-configure-domain.png" loading="lazy" />

    :::info
    Para añadir un subdominio, seleccione primero el dominio (por ejemplo: domain.tld) y marque **Crear un subdominio**. Aparecerá un campo para introducirlo (por ejemplo: **sub**.domain.tld).

    **Caso particular**: el subdominio en `www` (por ejemplo: **www**.domain.tld) no se añade automáticamente con el dominio. Para que también muestre su sitio, añádalo por separado, repitiendo este procedimiento con `www.domain.tld`.
    :::

    La sección **Opciones** reúne tres funcionalidades, desmarcadas por defecto. Según su [plan de alojamiento web](/links/web/hosting), algunas pueden no estar disponibles.

    |Opción|Descripción|
    |---|---|
    |IP del país|Permite beneficiarse de una dirección IP geolocalizada (entre una lista de países) para el nombre de dominio seleccionado.<br/> Obtenga más información gracias a [esta página](/links/web/hosting-options).|
    |Firewall|Permite activar un firewall (filtrado y análisis de las solicitudes) sobre el nombre de dominio seleccionado.<br/> Obtenga más información gracias a [esta página](/links/web/hosting-options).|
    |CDN|Permite activar el CDN (caché de los elementos estáticos de su sitio web, como las imágenes) sobre el nombre de dominio seleccionado.<br/> Obtenga más información gracias a [nuestra página CDN](/links/web/hosting-options-cdn).<br/> Al activar SSL y CDN, también podrá beneficiarse del protocolo **HTTP/2** (este protocolo está activado por defecto en nuestro datacenter de Gravelines).|

    :::info
    Estas opciones pueden activarse más adelante, una vez creado el sitio web. Para ello, consulte [esta guía](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::

    Por último, la sección **Configuración DNS** ofrece dos modos:

    - **Para una configuración automática**, deje seleccionada la opción **Configuración automática**: los registros A y AAAA se crean en la zona DNS del dominio. Un aviso indica que la consola intentará resolver los conflictos eliminando las entradas incompatibles.
    - **Para una configuración manual**, elija la opción **Configuración manual** y consulte las siguientes guías:
        - [Web hosting - Lista de direcciones IP por cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Editar una zona DNS de OVHcloud](/guides/web-cloud/domains/dns-zone-edit)
  </Tab>
  <Tab label="Etapa 5">
    La sección **Elija el módulo en 1 clic a instalar** completa el formulario. OVHcloud pone a su disposición los módulos WordPress, Joomla!, PrestaShop y Drupal, que se instalan automáticamente en la carpeta raíz configurada anteriormente. Para más información, consulte nuestra guía "[Instalar su sitio web con un 'módulo en 1 clic' (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules)".

    <img className="thumbnail" alt="Elección del módulo en 1 clic que se instalará" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-1-click-module.png" loading="lazy" />

    Deje seleccionado **Sin módulo preinstalado** si prefiere publicar usted mismo los archivos de su sitio web. Para más información, consulte nuestra guía "[Publicar un sitio web en internet](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online)".

    Por último, compruebe la información introducida y haga clic en <code className="action">Validate</code>. La adición puede tardar hasta una hora.

    :::info
    La modificación de la configuración DNS de su dominio requiere un tiempo de propagación de hasta 48 horas para ser plenamente efectiva.
    :::
  </Tab>
</Tabs>

</details>

<details>
<summary>Añadir un sitio web con un dominio no gestionado en su cuenta de OVHcloud</summary>

Esta sección se aplica únicamente si desea añadir un sitio web con un nombre de dominio que no esté presente en su cuenta de OVHcloud. Puede tratarse de un nombre de dominio presente en otra cuenta de OVHcloud o registrado en otro proveedor.

El formulario de adición ocupa una sola página: complételo de arriba abajo y valídelo. Haga clic en las pestañas de abajo para ver cada uno de los **5** pasos.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">Mis sitios</code> y luego en el botón <code className="action">Añadir un sitio</code>, encima de la tabla.

    <img className="thumbnail" alt="Pestaña Mis sitios y botón Añadir un sitio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-button.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la sección **Carpeta raíz**, introduzca el nombre de la carpeta que contendrá los archivos de su sitio web. Deje el campo vacío para que la consola la cree automáticamente.

    En la sección **Asociación del nombre de dominio**, elija la opción **Nombre de dominio externo**.

    <img className="thumbnail" alt="Carpeta raíz y elección del tipo de nombre de dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-form-top.png" loading="lazy" />

    :::warning
    La **carpeta raíz** también se crea en el espacio de almacenamiento de su alojamiento web, accesible por FTP, SFTP o SSH según su plan. Si el contenido de su sitio web ya se encuentra en una carpeta concreta de este espacio, indique aquí su nombre.
    :::
  </Tab>
  <Tab label="Etapa 4">
    En la sección **Configurar su dominio**, introduzca el **Nombre del sitio** que desee: solo sirve para identificar su sitio en la consola de OVHcloud. A continuación, introduzca el dominio (por ejemplo: domain.tld) o el subdominio (por ejemplo: **sub**.domain.tld) en el campo **Nombre de dominio**.

    :::tip
    **Caso particular**: el subdominio en `www` (por ejemplo: **www**.domain.tld) no se añade automáticamente con el dominio. Para que también muestre su sitio, añádalo por separado, repitiendo este procedimiento con `www.domain.tld`.
    :::

    La sección **Gestión del dominio** muestra entonces los registros que deben crearse, en dos pasos. Esta verificación es obligatoria: nos permite asegurarnos de que la adición del dominio externo es legítima.

    <img className="thumbnail" alt="Gestión del dominio: registros DNS que se deben crear y registro BIND" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-external-dns.png" loading="lazy" />

    1. **Verifique la propiedad del dominio**: añada el registro **TXT** indicado en la zona DNS de su proveedor.
    2. **Haga que el dominio apunte a su alojamiento**: añada los registros **A** y **AAAA** indicados.

    Cada valor dispone de un botón de copia, y el bloque **Registro BIND** recoge las tres líneas en el formato esperado por la mayoría de los proveedores de zonas DNS.

    :::warning
    Realice estos cambios **rápidamente**. Si no lo hace, se cancelará la adición de su dominio y su sitio web recién creado no será accesible.

    Las entradas DNS de tipo **A** y **TXT** deben colocarse obligatoriamente en la zona DNS activa de su dominio. Solo las entradas de tipo **AAAA** son opcionales.

    Tenga en cuenta que si desea asociar `sub.domain.tld`, deberá crear la entrada TXT `ovhcontrol.domain.tld` y no la entrada `ovhcontrol.sub.domain.tld`.

    Para encontrar la zona DNS activa de su nombre de dominio, consulte los [servidores DNS](/guides/web-cloud/domains/dns-server-edit) a los que está vinculado. Solo deberá validar el nombre de dominio mediante el campo **TXT**, no todos sus subdominios.
    :::

    :::info
    A diferencia de los dominios gestionados en su cuenta de OVHcloud, las secciones **Opciones** y **Configuración DNS** no se ofrecen para un dominio externo.

    Estas funcionalidades pueden activarse una vez creado el sitio web. Para ello, consulte [esta guía](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::
  </Tab>
  <Tab label="Etapa 5">
    La sección **Elija el módulo en 1 clic a instalar** completa el formulario. OVHcloud pone a su disposición los módulos WordPress, Joomla!, PrestaShop y Drupal, que se instalan automáticamente en la carpeta raíz configurada anteriormente. Para más información, consulte nuestra guía "[Instalar su sitio web con un 'módulo en 1 clic' (CMS)](/guides/web-cloud/web-hosting/cms-install-1-click-modules)".

    <img className="thumbnail" alt="Elección del módulo en 1 clic que se instalará" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-1-click-module.png" loading="lazy" />

    Deje seleccionado **Sin módulo preinstalado** si prefiere publicar usted mismo los archivos de su sitio web. Para más información, consulte nuestra guía "[Publicar un sitio web en internet](/guides/web-cloud/web-hosting/hosting-how-to-get-my-website-online)".

    Por último, haga clic en <code className="action">Validate</code>. El dominio se añade de forma temporal, mientras modifica su configuración DNS.

    :::info
    La modificación de la configuración DNS de su dominio requiere un tiempo de propagación de hasta 48 horas para ser plenamente efectiva.
    :::
  </Tab>
</Tabs>

  </Tab>
  <Tab label="Etapa 2">

  <Tab label="Etapa 3">
    En la sección **Asociación del nombre de dominio**, elija la opción **Pedir un nuevo nombre de dominio**.

    Se le redirigirá a nuestra página comercial de contratación de un dominio. Elija su nuevo dominio en función de la disponibilidad y siga las instrucciones del proceso de pedido hasta validar la orden de pedido, sin contratar además un nuevo alojamiento web.

    Una vez que su pedido se haya pagado y validado, espere unos momentos para que se procese.

    :::info
    Una vez que su dominio aparezca en su cuenta de OVHcloud, siga la parte "[Añadir un dominio gestionado en su cuenta de OVHcloud](#add-domain-ovhcloud)" de esta guía para añadir su sitio web a su alojamiento web.

### 2 - Publicar un sitio web en internet <a name="site-online"></a>

Una vez declarado el sitio web con su dominio en su alojamiento web, podrá publicar el contenido de su sitio web. Recuerde que debe realizar esta operación en la **carpeta raíz** que definió al añadir el sitio web en la consola de OVHcloud.

:::info
Si desea añadir varios sitios web, repita las acciones descritas en este guía.

Le recomendamos que tenga cuidado con el número de sitios web presentes en su alojamiento web. Cuantos más sitios web tenga, más recursos se solicitarán a su alojamiento web. [La página de nuestras ofertas de alojamiento web](/links/web/hosting) indica el número recomendado de sitios web que puede alojar en su alojamiento web.

:::
