## Redirección y autenticación con el archivo .htaccess

El archivo `.htaccess` permite controlar el acceso a su sitio web y redirigir o reescribir sus URL, directamente en su alojamiento web OVHcloud. Esta página reúne las guías para proteger el acceso (contraseña, bloqueo de direcciones IP), reescribir las URL y aprovechar las demás posibilidades del archivo `.htaccess`.
