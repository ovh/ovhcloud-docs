## Objetivo

¿No recuerda el nombre de su [solución de alojamiento web](/links/web/hosting)?
¿Desea consultar sus detalles o compararla con otra solución?

Mientras utiliza sus servicios, es posible que necesite el nombre de su solución de alojamiento web.

**Descubra cómo identificar el tipo de solución de alojamiento web que posee desde la consola de OVHcloud.**

## Requisitos

- Tener un [plan de alojamiento web](/links/web/hosting).

[[cpnav:web-hosting]]

## Procedimiento

Haga clic en las fichas siguientes para ver cada una de las **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la pestaña <code className="action">Vista general</code>, localice la sección **Suscripción**. El nombre de su plan de alojamiento web aparece en **Oferta** (por ejemplo: Perso, Pro, Performance).

    <img className="thumbnail" alt="Sección Suscripción y nombre del plan en Oferta" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/general-information/subscription-card.png" loading="lazy" />
  </Tab>
</Tabs>
