## Objetivo

Puede alojar varios sitios web en la misma oferta de alojamiento web, incluso si los nombres de dominio no están registrados en OVHcloud. Además, puede asociar uno o varios nombres de dominio o subdominios al mismo sitio web.

¿Ya no quiere utilizar un nombre de dominio o subdominio para su sitio web?
¿Quiere asociar su nombre de dominio o subdominio a otro sitio web en uno de sus alojamientos web?

**Descubra cómo desvincular un nombre de dominio o subdominio de un sitio web ya existente en su alojamiento web.**

:::info
Este procedimiento se aplica a la <ManagerLink to="/beta/#/">nueva versión del área de cliente de OVHcloud</ManagerLink>, actualmente disponible en beta. Para seguirlo, cambie a esta interfaz desde su área de cliente habitual.

:::

## Requisitos

- Disponer de una oferta de [alojamiento web OVHcloud](https://www.ovhcloud.com/es-es/web-hosting/uc-multisite/) compatible.
- Disponer de uno o varios [nombres de dominio](https://www.ovhcloud.com/es-es/domains/).
- Poder modificar la configuración de sus nombres de dominio desde sus [zonas DNS](/guides/web-cloud/domains/dns-zone-edit).

## Procedimiento

:::warning
Desvincular un nombre de dominio o subdominio de un sitio web presente en su alojamiento web es una operación sensible. De hecho, después de esta operación, su sitio web ya no será accesible en Internet con su nombre de dominio y/o subdominio.

:::

Haga clic en las fichas siguientes para ver cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting/sites">Alojamientos</ManagerLink> y seleccione el alojamiento web correspondiente.

    <img className="thumbnail" alt="Alojamientos" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la nueva página, haga clic en la pestaña <code className="action">Mis sitios</code>.

    <img className="thumbnail" alt="Mis sitios" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la tabla que aparece, haga clic en el botón <code className="action">></code> situado a la izquierda del nombre del sitio web correspondiente para mostrar los dominios o subdominios asociados.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />

    A continuación, haga clic en el botón <code className="action">⁝</code> situado a la derecha del dominio o subdominio correspondiente, y luego en <code className="action">Desvincular el dominio</code>.

    <img className="thumbnail" alt="Associated domains options" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/associated-domains-options.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    La nueva ventana que se abre le pide que confirme el desvinculación del nombre de dominio o subdominio.

    <img className="thumbnail" alt="My websites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/detach-domain-popup.png" loading="lazy" />

    Según su elección, marque o no la casilla <code className="action">Configuración automática (recomendado)</code>, y haga clic en <code className="action">Aceptar</code> para confirmar su elección.

    > ![!warning]
    >
    > **Caso particular: Ha asociado Git en su sitio web y solo un nombre de dominio está asociado al sitio web**
    >
    > Si es así, encontrará la siguiente ventana:
    >
    > <img className="thumbnail" alt="My websites" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/multisite/detach-alone-domain.png" loading="lazy" />
    >
    > Como indica el mensaje, deberá [eliminar su asociación Git](/guides/web-cloud/web-hosting/git-integration-webhosting) en primer lugar, **antes** de desvincular su nombre de dominio.
  </Tab>
</Tabs>

### Caso particular: Desvincular un nombre de dominio o subdominio para utilizarlo con otro sitio web

- Si desea añadir su nombre de dominio o subdominio a otro sitio web existente en un alojamiento web, consulte [esta guía](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).
- Si desea crear un nuevo sitio web en un alojamiento web con su nombre de dominio o subdominio recientemente desvinculado, consulte [esta guía](/guides/web-cloud/web-hosting/multisites-configure-multisite).
