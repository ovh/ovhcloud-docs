## Objetivo

Puede alojar varios sitios web en la misma oferta de alojamiento web, incluso si los nombres de dominio no están registrados en OVHcloud. Además, puede asociar uno o varios nombres de dominio o subdominios al mismo sitio web.

¿Ya no quiere utilizar un nombre de dominio o subdominio para su sitio web?
¿Quiere asociar su nombre de dominio o subdominio a otro sitio web en uno de sus alojamientos web?

**Descubra cómo desvincular un nombre de dominio o subdominio de un sitio web ya existente en su alojamiento web.**

## Requisitos

- Disponer de una oferta de [alojamiento web OVHcloud](https://www.ovhcloud.com/es-es/web-hosting/uc-multisite/) compatible.
- Disponer de uno o varios [nombres de dominio](https://www.ovhcloud.com/es-es/domains/).
- Poder modificar la configuración de sus nombres de dominio desde sus [zonas DNS](/guides/web-cloud/domains/dns-zone-edit).

[[cpnav:web-hosting-console]]

## Procedimiento

:::warning
Desvincular un nombre de dominio o subdominio de un sitio web presente en su alojamiento web es una operación sensible. De hecho, después de esta operación, su sitio web ya no será accesible en Internet con su nombre de dominio y/o subdominio.

:::

Haga clic en las fichas siguientes para ver cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">Mis sitios</code>. En la tabla, haga clic en el botón <code className="action">⋮</code> situado en la columna **Acciones**, a la derecha del sitio web correspondiente, y luego, en el grupo **Nombres de dominio**, en <code className="action">Gestionar mis dominios</code>.

    <img className="thumbnail" alt="Menú Acciones de un sitio web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    El panel **Gestionar mis dominios** se abre a la derecha y muestra los dominios y subdominios asociados a este sitio web. En el que desee desvincular, haga clic en el botón <code className="action">⋮</code> situado a la derecha de su nombre y luego en <code className="action">Desvincular</code>.

    <img className="thumbnail" alt="Panel Gestionar mis dominios y menú Acciones de un dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/manage-domains-actions.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Se abrirá la ventana **Desvincular un dominio**, que le pide que confirme su elección. Contiene dos ajustes:

    <img className="thumbnail" alt="Ventana Desvincular un dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/detach-domain-dialog.png" loading="lazy" />

    - **Desasociar también el subdominio**, seguido del subdominio `www` correspondiente: desmarcada por defecto, esta casilla lo desvincula al mismo tiempo que el dominio, si también está declarado en este sitio web. La zona DNS de este subdominio y todas sus opciones se eliminan entonces.
    - <code className="action">Eliminar los registros de apuntamiento (A y AAAA) en la zona DNS del nombre de dominio.</code>: marcada por defecto, esta casilla elimina de la zona DNS los registros que apuntan a su alojamiento web. Desmárquela si desea conservar estos registros.

    Por último, haga clic en <code className="action">Confirmar</code>.

    :::warning
    **Caso particular: su sitio web está asociado a un repositorio Git**

    La ventana muestra entonces una advertencia y una casilla adicional, <code className="action">Sí, eliminar mi configuración Git</code>. El botón <code className="action">Confirmar</code> permanece inactivo hasta que la marque: desvincular el dominio elimina al mismo tiempo la [asociación Git](/guides/web-cloud/web-hosting/git-integration-webhosting) del sitio web.

    <img className="thumbnail" alt="Ventana Desvincular un dominio en un sitio asociado a Git" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/detach-domain-git.png" loading="lazy" />

    :::
  </Tab>
</Tabs>

### Caso particular: Desvincular un nombre de dominio o subdominio para utilizarlo con otro sitio web

- Si desea añadir su nombre de dominio o subdominio a otro sitio web existente en un alojamiento web, consulte [esta guía](/guides/web-cloud/web-hosting/my-websites-add-domain-existing-website).
- Si desea crear un nuevo sitio web en un alojamiento web con su nombre de dominio o subdominio recientemente desvinculado, consulte [esta guía](/guides/web-cloud/web-hosting/multisites-configure-multisite).
