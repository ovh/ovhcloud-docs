## Objetivo

Durante el uso de sus servicios, puede que necesite conocer el nombre del servidor SQL en el que se encuentra su base de datos (incluida o adquirida como complemento a través de su [alojamiento web](/links/web/hosting)).

:::warning
Esta guía no se aplica a las bases de datos presentes en una solución [Web Cloud Databases](/links/web/databases).

:::

**Descubra cómo encontrar el nombre del servidor que aloja su base de datos compartida, accesible con su alojamiento web.**

## Requisitos

- Disponer de una [oferta de alojamiento web OVHcloud](/links/web/hosting).
- Utilizar una base de datos incluida o [adquirida como complemento](/links/web/hosting-options-startsql) a través de su alojamiento web.

[[cpnav:web-hosting-console]]

## Procedimiento

Haga clic en las fichas siguientes para ver cada una de las **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">Bases de datos</code>.

    <img className="thumbnail" alt="Pestaña Bases de datos de un alojamiento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la tabla, localice la línea de la base de datos correspondiente con la columna **Nombre de la base** y consulte su columna **Dirección del servidor**.

    <img className="thumbnail" alt="Tabla de las bases de datos y su columna Dirección del servidor" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/tab.png" loading="lazy" />

Encontrará el nombre del servidor SQL (por ejemplo: **mysqlXXX.euXXX**) en el que se aloja su base de datos compartida.

    :::warning
    A pesar de su título, esta columna muestra el **servidor**, y no la dirección de conexión a su base de datos. Se trata de dos nociones distintas:

    - El **servidor** representa la infraestructura que aloja su base de datos, así como otras bases. Su nombre permite verificar si está afectado por una operación de mantenimiento o un incidente declarado en nuestra página [Web Cloud Status](https://web-cloud.status-ovhcloud.com/).
    - La **dirección del servidor** forma parte de las credenciales de conexión específicas de su base de datos y permite conectar su sitio web a esta última.

    :::

  </Tab>
</Tabs>
