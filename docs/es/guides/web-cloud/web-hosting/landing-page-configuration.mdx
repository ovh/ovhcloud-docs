## Configurar su alojamiento web

Configure todos los aspectos de su alojamiento web OVHcloud: aloje varios sitios web, gestione el entorno y la versión de PHP, active las direcciones de correo incluidas, optimice el rendimiento y el CDN, supervise los logs, despliegue (Git, CRON, API) y haga evolucionar su plan. Las bases de datos, el acceso FTP/SSH, los CMS y la seguridad disponen además de su propia página dedicada.

Para orientarse según su necesidad:

- **¿Desea configurar sus sitios web, asociar sus nombres de dominio o preparar el entorno (PHP, IPv6)?** Consulte la sección *Sitios web, nombre de dominio y entorno*.
- **¿Quiere mejorar el rendimiento de sus servicios o supervisar los logs (CDN, estadísticas)?** Consulte la sección *Rendimiento, CDN y logs*.
- **¿Necesita desplegar, automatizar (Git, CRON, API) o hacer evolucionar su plan?** Consulte la sección *Despliegue, automatización y plan*.
