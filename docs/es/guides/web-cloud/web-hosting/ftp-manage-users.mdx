## Objetivo

Los planes de hosting de OVHcloud permiten acceder a un espacio de almacenamiento FTP. Este espacio FTP permite, por ejemplo, publicar los archivos de sus sitios web o aplicaciones en internet. El acceso a este espacio es posible a través de un usuario FTP o SSH y la contraseña asociada. En el marco de sus actividades, puede tener varios usuarios FTP para sus diferentes colaboradores.

**Descubra cómo crear, modificar o eliminar usuarios FTP en un alojamiento web de OVHcloud.**

:::info
Esta guía solo es válida para los alojamientos web de tipo **Pro**, **Performance**, **Agency**, **Agency Plus** o **Agency Max**. Solo estos productos permiten activar varios usuarios FTP.

:::

## Requisitos

- Tener contratado un [plan de hosting de OVHcloud](/links/web/hosting) compatible.

[[cpnav:web-hosting]]

## Procedimiento

### Crear un nuevo usuario FTP en su alojamiento web <a name="create-ftp-user"></a>

Para crear un nuevo usuario FTP en su alojamiento web desde la consola de OVHcloud, haga clic en las fichas siguientes para ver cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Pestaña FTP-SSH de un alojamiento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la sección **Usuarios FTP y SSH**, haga clic en <code className="action">Crear un usuario</code>.

    <img className="thumbnail" alt="Panel de creación de un usuario FTP en la consola" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/create-user.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Se abre el panel **Crear un usuario**, que reúne todos los parámetros en una sola pantalla:

    - **Usuario**: el nombre que su colaborador utilizará para conectarse. Siempre va **precedido del login FTP principal de su alojamiento web, seguido de un guion**: si este login es `ftplogin` e introduce `user1`, el identificador completo será `ftplogin-user1`. El nombre que añada tiene entre 1 y 12 caracteres alfanuméricos;
    - **Carpeta raíz**: el directorio en el que este usuario podrá actuar. **Deje este campo vacío para dar acceso a todo el espacio de almacenamiento**; de lo contrario, indique un directorio o subdirectorio, por ejemplo `www`, `blog`, `website1` o `www/development`;
    - **Protocolos de conexión**: el protocolo o los protocolos autorizados para este usuario. Si elige **FTP, SFTP y SSH**, su colaborador podrá tanto gestionar los archivos como conectarse por línea de comandos;
    - **Contraseña** y **Confirmar la contraseña**: respete la política indicada debajo de los campos.

    Por último, haga clic en <code className="action">Crear</code>.
  </Tab>
</Tabs>

:::info
Una vez validada la solicitud de creación, el nuevo usuario puede tardar hasta 15 minutos en incluirse en el alojamiento web.

:::

Si lo necesita, pruebe el nuevo usuario FTP utilizando nuestra guía "[Conectarse al espacio de almacenamiento FTP de su alojamiento web](/guides/web-cloud/web-hosting/ftp-connection)".

### Editar un usuario FTP

Para editar un usuario FTP, haga clic en las fichas siguientes para ver cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Pestaña FTP-SSH de un alojamiento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    La sección **Usuarios FTP y SSH** muestra los usuarios creados en su alojamiento web. En la columna **Acciones**, haga clic en el botón <code className="action">⋮</code> situado a la derecha del usuario correspondiente y luego en <code className="action">Editar</code>.

    <img className="thumbnail" alt="Menú Acciones de un usuario FTP en la consola" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Se abre el panel **Modificar un usuario**. Ofrece tres ajustes:

    - **Carpeta raíz**: el directorio en el que este usuario podrá actuar. Deje este campo vacío para darle acceso a todo el espacio de almacenamiento;
    - **Desactivar usuario**: marque esta casilla para impedir que un colaborador acceda a su espacio de almacenamiento FTP **sin eliminar los logs FTP y SSH asociados a él**. Estos logs le permitirán determinar qué operaciones ha realizado si detecta intervenciones no deseadas en su alojamiento web;
    - **Protocolos de conexión**: el protocolo o los protocolos autorizados para este usuario. Consulte la sección "[Crear un nuevo usuario FTP en su alojamiento web](#create-ftp-user)" más arriba en esta guía para más información sobre los protocolos.

    :::info
    La **carpeta raíz** de la **cuenta principal** no se puede modificar: el campo permanece en gris y la consola muestra el mensaje «La carpeta raíz de la cuenta principal no se puede modificar.». Solo los usuarios que haya creado pueden cambiarla.
    :::

    El nombre del usuario y su contraseña no se modifican aquí. Para cambiar la contraseña, utilice la opción <code className="action">Cambiar la contraseña</code> del mismo menú, descrita en nuestra guía "[Cambiar la contraseña de un usuario FTP](/guides/web-cloud/web-hosting/ftp-change-password)".

    <img className="thumbnail" alt="Panel de modificación de un usuario FTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/edit-user.png" loading="lazy" />

    Por último, haga clic en <code className="action">Confirmar</code>.
  </Tab>
</Tabs>

:::info
Si solo desea cambiar la contraseña del usuario FTP, consulte nuestra guía "[Cambiar la contraseña de un usuario FTP](/guides/web-cloud/web-hosting/ftp-change-password)".

Si desea cambiar el nombre del usuario FTP, esta función no está disponible. Es obligatorio [crear un nuevo usuario FTP](#create-ftp-user) con el nuevo nombre de usuario deseado. A continuación, si lo necesita, puede [eliminar el antiguo usuario FTP](#delete-ftp-user).

:::

### Eliminar un usuario FTP <a name="delete-ftp-user"></a>

Para eliminar un usuario FTP, haga clic en las fichas siguientes para ver cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">FTP-SSH</code>.

    <img className="thumbnail" alt="Pestaña FTP-SSH de un alojamiento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la columna **Acciones** de la sección **Usuarios FTP y SSH**, haga clic en el botón <code className="action">⋮</code> situado a la derecha del usuario correspondiente y luego en <code className="action">Eliminar</code>.

    <img className="thumbnail" alt="Menú Acciones de un usuario FTP en la consola" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/user-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Una ventana le pide que confirme, recordando el identificador correspondiente. Haga clic en <code className="action">Eliminar</code> para retirar definitivamente este usuario de su alojamiento web.

    <img className="thumbnail" alt="Ventana de confirmación de eliminación de un usuario FTP" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/ftp-ssh/delete-user-confirmation.png" loading="lazy" />
  </Tab>
</Tabs>
