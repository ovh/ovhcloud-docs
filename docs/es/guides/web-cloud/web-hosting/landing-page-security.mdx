## Proteger su alojamiento web

Proteja su sitio web y a sus visitantes: active el cifrado HTTPS con un certificado SSL, configure un firewall de aplicación y aplique las buenas prácticas de seguridad en su alojamiento web OVHcloud. Esta página reúne todas las guías para proteger su sitio web.

Para orientarse según su necesidad:

- **Seguridad del sitio** (buenas prácticas, firewall de aplicación): empiece por la sección *Proteger su sitio web*.
- **Certificado SSL y HTTPS** (gestionar un certificado, habilitar HTTPS): consulte la sección *Certificado SSL y HTTPS*.
- **Elegir un certificado SSL** (Let's Encrypt gratuito, Sectigo DV/EV, certificado personalizado): consulte la sección *Activar un certificado SSL*.

## Activar un certificado SSL

Elija el tipo de certificado adaptado a su sitio web y siga la guía correspondiente.

<Tabs>
  <Tab label="Let's Encrypt (gratuito)">

Certificado SSL gratuito disponible con su alojamiento web.

[Activar un certificado SSL gratuito Let's Encrypt](/guides/web-cloud/web-hosting/ssl-letsencrypt)

  </Tab>
  <Tab label="Sectigo DV">

Certificado Sectigo de validación de dominio (Domain Validation), válido para un nombre de dominio y su subdominio "www".

[Activar un certificado SSL Sectigo DV](/guides/web-cloud/web-hosting/ssl-dv)

  </Tab>
  <Tab label="Sectigo EV">

Certificado Sectigo de validación extendida (Extended Validation), válido para un nombre de dominio y su subdominio "www".

[Activar un certificado SSL Sectigo EV](/guides/web-cloud/web-hosting/ssl-ev)

  </Tab>
  <Tab label="Personalizado">

Para importar su propio certificado SSL cuando ninguna de las soluciones de OVHcloud se ajusta a sus necesidades.

[Instalar un certificado SSL personalizado](/guides/web-cloud/web-hosting/ssl-custom)

  </Tab>
</Tabs>
