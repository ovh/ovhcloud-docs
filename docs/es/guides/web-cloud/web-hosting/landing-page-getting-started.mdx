## Primeros pasos con su alojamiento web

¿Acaba de contratar un alojamiento web OVHcloud? Esta página reúne las guías para empezar: activar su oferta, crear y publicar su primer sitio web, activar las direcciones de e-mail incluidas y, después, localizar la información clave de su alojamiento. Para configurar su alojamiento con más detalle, consulte la página Configuración.

Para orientarse según sus necesidades:

- **¿Está empezando y quiere crear y publicar su sitio web?** Consulte las secciones *Empezar* y *Publicar y gestionar sus sitios web*.
- **¿Quiere activar los e-mails incluidos o gestionar sus sitios web desde el área de cliente?** Consulte la sección *Publicar y gestionar sus sitios web*.
- **¿Busca la información técnica de su alojamiento (oferta, clúster)?** Consulte la sección *Conocer su alojamiento*.
