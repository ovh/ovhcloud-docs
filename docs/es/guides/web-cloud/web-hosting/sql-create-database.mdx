## Objetivo

Una base de datos (BD) se utiliza para almacenar elementos dinámicos (datos de conexión, datos de usuarios, datos de visualización, datos necesarios para el buen funcionamiento de su sitio web, etc.). Estas bases de datos se utilizan en la mayoría de los sistemas de gestión de contenidos (CMS) modernos, como *WordPress*, *Joomla!*, *Drupal* o *PrestaShop*.

**Descubra cómo crear una base de datos en un alojamiento web de OVHcloud**

## Requisitos

- Tener contratado un plan de [alojamiento web de OVHcloud](/links/web/hosting) que incluya al menos una base de datos.
- Disponer de una base de datos disponible en "creación" entre las que se incluyen en el plan de hosting. Si lo necesita, puede añadir bases de datos [Start SQL](/links/web/hosting-options-startsql) a su alojamiento web.

## Procedimiento

### 1 - Acceder a la pestaña de gestión de las bases de datos de un alojamiento web

Haga clic en las fichas siguientes para ver cada una de las **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la página que se muestra, abra la pestaña <code className="action">Bases de datos</code>.

    <img className="thumbnail" alt="Pestaña Bases de datos de un alojamiento web" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases.png" loading="lazy" />

    La tabla de esta sección contiene todas las bases de datos creadas con su alojamiento web. Cada línea indica el **Nombre de usuario**, el **Nombre de la base**, la **Dirección del servidor**, la **Cuota** utilizada, la **Versión** del motor, el **Tipo**, el **Estado** y el número de **Copias de seguridad** disponibles.

    <img className="thumbnail" alt="Tabla de las bases de datos y sus columnas" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/tab-no-spotlight.png" loading="lazy" />
  </Tab>
</Tabs>

En la tabla, las bases de datos pueden tener varios tipos diferentes:

- **Incluida**: indica que la base de datos está incluida en el plan de hosting. No genera ningún coste adicional.<br/><br/>
- **Opcional**: indica que la base de datos se ha contratado como complemento de las bases de datos incluidas con el alojamiento web. Pague un complemento para disponer de esta base de datos adicional en su alojamiento web.<br/><br/>
- **Incluida - retirada de la venta**: indica que la base de datos incluida va a retirarse pronto de la venta y quedar obsoleta. <br/>Le recomendamos que, **antes** de que la base de datos quede obsoleta, recupere el contenido y la coloque en una nueva base de datos más reciente (que aún no tenga programada su finalización).<br/><br/>
- **Opcional - retirada de la venta**: Indica que la base de datos contratada como complemento en su alojamiento web va a ser retirada de la venta y quedar obsoleta. <br/>Le recomendamos que, **antes** de que la base de datos quede obsoleta, recupere el contenido y la coloque en una base de datos nueva y más reciente (que aún no haya finalizado).

:::tip
Para duplicar rápidamente el contenido de una base de datos "**Incluida - retirada de la venta**" o "**Opcional - retirada de la venta**" en una nueva base de datos cuya obsolescencia aún no está programada, consulte nuestra guía "[Duplicar el contenido de una base de datos de OVHcloud en otra](/guides/web-cloud/web-hosting/copy-database)".
:::

### 2 - Crear la base de datos

Para crear una base de datos, haga clic en las fichas siguientes para ver cada una de las **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la página que se muestra, abra la pestaña <code className="action">Bases de datos</code> y haga clic en el botón <code className="action">Crear una base de datos</code>, situado encima de la tabla.

    :::info
    Este botón solo aparece si queda al menos una base de datos disponible en su plan. Si su alojamiento web todavía no tiene ninguna base de datos creada, el mismo botón también se propone en el centro de la página, en lugar de la tabla.
    :::
  </Tab>
  <Tab label="Etapa 3">
    Introduzca la información solicitada en el panel que se abre a la derecha y haga clic en <code className="action">Confirmar</code>.

    <img className="thumbnail" alt="Panel de creación de una base de datos y sus campos" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/create-a-database.png" loading="lazy" />

    |Información|Descripción|
    |---|---|
    |**Tipo de base de datos**|Elija el tamaño de la base de datos. Para cada tamaño, la lista indica el número de espacios que le quedan y si está **(incluidas)** en su plan o es **(opcional)**.|
    |**Motor de la base de datos**|Campo no modificable. Las bases de datos incluidas en su [plan de hosting de OVHcloud](/links/web/hosting) solo están disponibles con el motor MySQL.|
    |**Versión de la base de datos**|Campo tampoco modificable: la versión la impone el plan. Asegúrese de que su sitio web es compatible con la que se muestra.|
    |**Usuario**|Nombre de usuario asociado a la base de datos, **obligatorio**. El prefijo de su alojamiento web está impuesto: complételo con letras minúsculas y cifras. El nombre completo tiene como máximo 16 caracteres, prefijo incluido; el número de caracteres restantes se indica debajo del campo. El nombre de la base de datos será idéntico al nombre de usuario.|
    |**Contraseña**|Escriba una contraseña para este usuario según los *criterios* que se indican debajo del campo.|
    |**Repetir contraseña**|Vuelva a escribir la contraseña de este usuario.|

    :::info
    La actualización de la versión del motor de una base de datos ya creada no está disponible en este momento.
    :::
  </Tab>
</Tabs>

:::info
Por motivos de seguridad, siga los requisitos del sistema para crear la contraseña.

También se recomienda:

- establecer una contraseña diferente para cada uno de sus servicios;
- crear una contraseña que no contenga datos personales (nombre, apellidos, fecha de nacimiento, etc.);
- renovar su contraseña regularmente;
- no conservar ningún registro escrito de su contraseña y no enviarla a otras personas (incluso a través de su dirección de correo electrónico);
- no guardar su contraseña en su navegador de Internet, incluso si su navegador lo permite.

:::

:::warning
Recuerde que si cambia la contraseña de una base de datos, todas las aplicaciones que accedan a ella deben actualizarse en consecuencia.
:::

La creación de la base de datos puede tardar hasta **15 minutos**. Recargue la página web de la <ManagerLink to="/beta/#/">consola de OVHcloud</ManagerLink> si la base de datos no aparece automáticamente en la tabla que enumera sus bases de datos.

Repita este proceso tantas veces como desee para crear varias bases de datos (con el límite de las bases de datos disponibles en su plan).

:::warning
Una vez validada la creación de la base de datos, el nombre de usuario y el nombre de la base de datos no se podrán editar.
:::

### 3 - Gestionar la base de datos <a name="step3"></a>

:::warning
Esta guía no sustituye a la asistencia de un profesional en desarrollo. Le recomendamos que, si necesita ayuda, contacte con un [proveedor especializado](/links/partner) o con el editor del software de su solución. OVHcloud no podrá asistirle. Para más información, consulte la sección ["Más información"](#go-further) de esta guía.
:::

Ya puede utilizar su base de datos. Para ello, necesitará su información de conexión:

- el *nombre de usuario* y la *contraseña* que haya establecido,
- el *nombre de la base de datos*, idéntico al nombre de usuario,
- la *dirección de conexión* a la base de datos, con el formato `nombre-usuario.mysql.db`.

:::info
Si se le solicita, independientemente de cuál sea la base de datos [Start SQL](/links/web/hosting-options-startsql) añadida o incluida con su alojamiento web OVHcloud, el número de **puerto** que deberá utilizar será el **3306**.
:::

Esta información es esencial para que el sitio web pueda conectarse a la base de datos.

Si necesita recuperar esta información de conexión, haga clic en las fichas siguientes para ver cada una de las **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la página que se muestra, abra la pestaña <code className="action">Bases de datos</code>. La tabla que se muestra contiene esta información, excepto la *contraseña* por motivos de seguridad:

    - la columna **Nombre de usuario** indica a la vez el nombre de usuario y el nombre de la base de datos, ya que ambos son idénticos;
    - la columna **Nombre de la base** indica la dirección de conexión, con el formato `nombre-usuario.mysql.db`.

    :::warning
    La columna **Dirección del servidor** **no** forma parte de esta información. Muestra el servidor de infraestructura que aloja su base de datos, con el formato `mysqlXXX.euXXX`, útil para comprobar si se ve afectado por una incidencia. Para más información, consulte nuestra guía "[Cómo identificar el servidor de su base de datos](/guides/web-cloud/web-hosting/sql-find-server)".
    :::
  </Tab>
</Tabs>

:::warning
Si no recuerda su contraseña de conexión a la base de datos, consulte nuestra guía "[Cambiar la contraseña de la base de datos](/guides/web-cloud/web-hosting/sql-change-password)".
:::

Según el programa utilizado, es posible que esta conexión necesite ser configurada manualmente o a través de una interfaz generada por la interfaz de configuración (backend) del sitio web. Este procedimiento afecta a la configuración del sitio web y no al alojamiento de OVHcloud, por lo que le recomendamos que consulte los recursos disponibles en Internet o que contacte con un [proveedor especializado](/links/partner).

:::info
Solo es posible acceder a las bases de datos asociadas a un alojamiento web a través de una aplicación o un script directamente instalado en el alojamiento web o a través de la interfaz phpMyAdmin.
:::

OVHcloud ofrece una herramienta en línea para la gestión de bases de datos llamada phpMyAdmin. Para encontrar el enlace de acceso a esta aplicación, haga clic en las fichas siguientes para ver cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la página que se muestra, abra la pestaña <code className="action">Bases de datos</code>.
  </Tab>
  <Tab label="Etapa 3">
    En la tabla que se muestra, haga clic en el botón <code className="action">⁝</code> de la columna **Acciones**, a la derecha de la base de datos correspondiente, y luego en <code className="action">Acceder a phpMyAdmin</code>. La aplicación se abre en una nueva pestaña de su navegador.

    <img className="thumbnail" alt="Menú de una línea de la tabla de bases de datos" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/row-actions-menu.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Introduzca los datos de acceso a la base de datos y haga clic en <code className="action">Iniciar sesión</code>.

    <img className="thumbnail" alt="Página de conexión a phpMyAdmin" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-interface-login.png" loading="lazy" />

    Si lo necesita, consulte el [apartado 3](#step3) de esta guía para obtener la información de conexión a la base de datos.
  </Tab>
</Tabs>

#### Utilizar las copias de seguridad de las bases de datos

Para cada base de datos de alojamiento web, se crean snapshots automáticamente cada día (hasta un máximo de 32). Puede restaurar rápidamente una versión anterior de una base de datos desde la consola de OVHcloud.

Para comprobar las copias de seguridad disponibles, haga clic en las fichas siguientes para ver cada una de las **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la página que se muestra, abra la pestaña <code className="action">Bases de datos</code>.
  </Tab>
  <Tab label="Etapa 3">
    En la tabla que se muestra, la columna **Copias de seguridad** indica, para cada base de datos, el número de copias de seguridad disponibles actualmente.

    <img className="thumbnail" alt="Columna Copias de seguridad de la tabla de las bases de datos" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/databases/backups-column.png" loading="lazy" />

    Para actuar sobre estas copias de seguridad, haga clic en el botón <code className="action">⁝</code> de la columna **Acciones**, a la derecha de la base de datos correspondiente: <code className="action">Crear una copia de seguridad</code> genera una inmediatamente, <code className="action">Restaurar una copia de seguridad</code> permite elegir una y restablecerla.

#### Entender los problemas comunes

**Demasiadas conexiones**

Las bases de datos de alojamiento web están limitadas a 30 conexiones simultáneas (variable del sistema *max_connections*). Por lo tanto, las solicitudes SQL deben optimizarse para evitar este tipo de errores. Si los problemas persisten a pesar de todo, se deben considerar medidas alternativas. Por ejemplo, puede migrar su base de datos a una base de datos [Web Cloud Databases](/links/web/databases) o realizar una [actualización de su plan de hosting](/links/web/hosting-best-web).

**Errores de conexión / "no encontrado"**

Aparece normalmente cuando no se utiliza el nombre real de la base de datos en el archivo de conexión a base de datos que se encuentra en su sitio web.

La práctica recomendada es utilizar siempre el nombre real de la base de datos para scripts y archivos de configuración en lugar de direcciones IP o _localhost_.

**Se ha superado la cuota de las bases de datos**

Si una base de datos de alojamiento web supera el espacio de almacenamiento recomendado, cambiará automáticamente a "Solo lectura" o "Solo selección". El administrador recibirá una notificación por correo electrónico.

Una vez que la base de datos haya sido optimizada (depurada), vuelva a calcular su cuota en la consola de OVHcloud para desbloquearla de nuevo. Para más información, consulte nuestra guía "[Web hosting - Mi base de datos está saturada, ¿qué hago?](/guides/web-cloud/web-hosting/sql-overquota-database)".
