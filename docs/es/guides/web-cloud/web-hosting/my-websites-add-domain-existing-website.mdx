## Objetivo

Puede alojar varios sitios web en la misma oferta de alojamiento web, incluso si los dominios no están registrados en OVHcloud. Además, puede asociar uno o varios dominios o subdominios al mismo sitio web.

:::info
Si aún no ha creado el sitio web correspondiente en su alojamiento web, consulte **directamente** [esta guía](/guides/web-cloud/web-hosting/multisites-configure-multisite).

:::

**Descubra cómo asociar un nombre de dominio o un subdominio a un sitio web ya existente en su alojamiento web.**

:::info
Este procedimiento se aplica a la <ManagerLink to="/beta/#/">nueva versión del área de cliente de OVHcloud</ManagerLink>, actualmente disponible en beta. Para seguirlo, cambie a esta interfaz desde su área de cliente habitual.

:::

## Requisitos

- Disponer de una oferta de [alojamiento web OVHcloud](https://www.ovhcloud.com/es-es/web-hosting/uc-multisite/) compatible.
- Disponer de uno o varios [dominios](https://www.ovhcloud.com/es-es/domains/).
- Poder modificar la configuración de sus dominios desde sus [zonas DNS](/guides/web-cloud/domains/dns-zone-edit).

## Procedimiento

### Añadir un nombre de dominio o un subdominio a un sitio web existente

**Haga clic en uno de los títulos siguientes para mostrar las explicaciones.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Añadir un nombre de dominio gestionado desde su área de cliente de OVHcloud</summary>

Esta parte se aplica únicamente si su nombre de dominio y/o su zona DNS activa se encuentran **en su área de cliente de OVHcloud**.

Haga clic en las fichas siguientes para ver cada una de las **6** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting/sites">Alojamientos</ManagerLink> y seleccione el alojamiento web correspondiente.

    <img className="thumbnail" alt="Alojamientos" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la nueva página, haga clic en la pestaña <code className="action">Mis sitios</code>.

    <img className="thumbnail" alt="Mis sitios" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la tabla que aparece, haga clic en el botón <code className="action">⁝</code> situado a la derecha del sitio web correspondiente, y luego en <code className="action">Agregar un dominio</code>.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/website-options.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Marque la opción <code className="action">Asociar un dominio existente de OVHcloud</code> y haga clic en <code className="action">Continuar</code>.

    Seleccione a continuación el nombre de dominio a asociar en el menú desplegable **Nombre de dominio - obligatorio** que aparece debajo.

    :::info
    Para añadir un subdominio, seleccione primero el nombre de dominio en la lista (por ejemplo: domain.tld). Marque después la casilla titulada <code className="action">Crear un subdominio</code>. Aparecerá un campo de entrada para que pueda introducir el subdominio (por ejemplo: **sub**.domain.tld).

    **Caso particular**: Los subdominios en `www` (por ejemplo: **www**.domain.tld) se añaden automáticamente como complemento del nombre de dominio. Por lo tanto, no es necesario especificar este subdominio concreto en el campo de entrada.

    :::

    <img className="thumbnail" alt="Add domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-ovh-step-1.png" loading="lazy" />

    Si desea utilizar una de las **opciones avanzadas** disponibles, active el botón <code className="action">Configuración avanzada</code> y pase directamente a la **etapa 7**. En caso contrario, continúe con la **etapa 6**.
  </Tab>
  <Tab label="Etapa 5">
    Verifique que todas las informaciones introducidas anteriormente sean correctas, y haga clic en <code className="action">Continuar</code> para finalizar la adición de su nombre de dominio o de su subdominio a su sitio web.

    Esta adición puede tardar hasta una hora.

    La configuración DNS se realizará automáticamente si la zona DNS activa de su nombre de dominio está gestionada en su área de cliente de OVHcloud.

    En caso contrario, consulte las siguientes guías para configurar manualmente su zona DNS:

    - [Web hosting - Lista de direcciones IP por cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
    - [Editar una zona DNS de OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    :::info
    La modificación de la configuración DNS de su nombre de dominio requiere un tiempo de propagación que puede alcanzar las 24 horas antes de que sea plenamente efectiva.

    :::

  </Tab>
  <Tab label="Etapa 6">
    :::info
    Este paso es **opcional**. Se dirige únicamente a los clientes que desean activar ciertas funcionalidades disponibles mediante el botón <code className="action">Configuración avanzada</code>.

    **Todas estas funcionalidades pueden activarse posteriormente, una vez que el nombre de dominio se haya añadido a su sitio web.** En este caso concreto, consulte directamente [esta guía](/guides/web-cloud/web-hosting/multisites-modify-domain).

    A continuación, encontrará una descripción de estas opciones.

    Según su oferta de [alojamiento web](https://www.ovhcloud.com/es-es/web-hosting/), algunos elementos entre las opciones propuestas no podrán ser seleccionados.

    :::

    <img className="thumbnail" alt="Add domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-ovh-advanced-configurations.png" loading="lazy" />

    <Region zones={['eu']}>

    |Opción|Descripción|
    |---|---|
    |IP del país|Permite beneficiarse de una dirección IP geolocalizada (entre una lista de países) para el nombre de dominio seleccionado.<br/> Aprenda más gracias a [esta página](https://www.ovhcloud.com/es-es/web-hosting/options/).|
    |Firewall|Permite activar un firewall (filtrado y análisis de las solicitudes) en el nombre de dominio seleccionado.<br/> Aprenda más gracias a [esta página](https://www.ovhcloud.com/es-es/web-hosting/options/).|
    |CDN|Permite activar el CDN (caché de elementos estáticos de su sitio web, como las imágenes) en el nombre de dominio seleccionado.<br/> Aprenda más gracias a [nuestra página CDN](https://www.ovhcloud.com/es-es/web-hosting/options/cdn/).<br/> Al activar el SSL y el CDN, también podrá beneficiarse del protocolo **HTTP/2** (este protocolo está activado por defecto en nuestro datacenter de Gravelines).|

    </Region>
    <Region zones={['ca', 'apac']}>

    |Opción|Descripción|
    |---|---|
    |Firewall|Permite activar un firewall (filtrado y análisis de las solicitudes) en el nombre de dominio seleccionado.<br/> Aprenda más gracias a [esta página](https://www.ovhcloud.com/es-es/web-hosting/options/).|
    |CDN|Permite activar el CDN (caché de elementos estáticos de su sitio web, como las imágenes) en el nombre de dominio seleccionado.<br/> Aprenda más gracias a [nuestra página CDN](https://www.ovhcloud.com/es-es/web-hosting/options/cdn/).|

    </Region>

    Una vez activado el botón <code className="action">Configuración avanzada</code>, también puede elegir el modo de configuración DNS de su nombre de dominio:

    - **Para una configuración DNS automática**, deje la casilla <code className="action">Configuración automática (recomendado)</code> marcada.
    - **Para una configuración DNS manual**, marque la casilla <code className="action">Configuración manual</code>. Para realizar posteriormente la configuración, consulte las siguientes guías:
        - [Web hosting - Lista de direcciones IP por cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Editar una zona DNS de OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    Una vez realizadas sus opciones, haga clic en el botón <code className="action">Continuar</code> para finalizar la adición de su nombre de dominio o de su subdominio a su sitio web. Esta adición puede tardar hasta una hora.

    Sin embargo, la modificación de la configuración DNS de su nombre de dominio requiere un tiempo de propagación que puede alcanzar las 24 horas antes de que sea plenamente efectiva.
  </Tab>
</Tabs>

</details>

<details>
<summary>Añadir un nombre de dominio externo</summary>

Esta parte se aplica únicamente si su nombre de dominio no está presente en su cuenta OVHcloud.

Haga clic en las fichas siguientes para ver cada una de las **6** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting/sites">Alojamientos</ManagerLink> y seleccione el alojamiento web correspondiente.

    <img className="thumbnail" alt="Alojamientos" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En la nueva página, haga clic en la pestaña <code className="action">Mis sitios</code>.

    <img className="thumbnail" alt="Mis sitios" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-sites.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    En la tabla que aparece, haga clic en el botón <code className="action">⁝</code> situado a la derecha del sitio web correspondiente, y luego en <code className="action">Agregar un dominio</code>.

    <img className="thumbnail" alt="Website" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/website-options.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    Marque la opción <code className="action">Asociar un dominio externo</code> y haga clic en <code className="action">Continuar</code>.

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-1.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 5">
    Introduzca el nombre de dominio (por ejemplo: domain.tld) o el subdominio (por ejemplo: **sub**.domain.tld) a asociar en el campo **Nombre de dominio - obligatorio** que aparece debajo.

    :::tip
    **Caso particular**: Los subdominios en `www` (por ejemplo: **www**.domain.tld) se añaden automáticamente como complemento del nombre de dominio. Por lo tanto, no es necesario especificar este subdominio concreto en el campo de entrada.

    :::

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-2.png" loading="lazy" />

    Una vez completadas las informaciones, haga clic en el botón <code className="action">Continuar</code>.

    :::info
    A diferencia de los dominios gestionados directamente desde su área de cliente de OVHcloud, las **opciones avanzadas** no están disponibles directamente durante la adición de un nombre de dominio o de un subdominio externo a su sitio web.

    Sin embargo, **todas estas funcionalidades pueden activarse posteriormente una vez que el nombre de dominio o el subdominio externo se haya añadido a su sitio web.** Para ello, consulte directamente [esta guía](/guides/web-cloud/web-hosting/multisites-modify-domain).

    :::

  </Tab>
  <Tab label="Etapa 6">
    Todo añadido de un nombre de dominio externo a OVHcloud requiere una validación adicional obligatoria. Esto nos permite asegurarnos de que el añadido del nombre de dominio externo es legítimo. Se le mostrará un mensaje que le invitará a modificar la configuración DNS del nombre de dominio.

    <img className="thumbnail" alt="Add external domain" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/my-websites/add-a-domain-or-sub-domain-external-step-3.png" loading="lazy" />

    Tenga en cuenta los elementos que aparecen, y haga clic en el botón <code className="action">Continuar</code>. A partir de ahora, el nombre de dominio se añadirá de manera temporal, el tiempo suficiente para que pueda modificar su configuración DNS.

    :::warning
    Debe realizar estas modificaciones **rápidamente** para que su nombre de dominio se añada correctamente. Sin esta acción, el añadido de su nombre de dominio será cancelado.

    Las entradas DNS de tipo **A** y **TXT** deben colocarse obligatoriamente en la zona DNS activa de su nombre de dominio para que se añada a su sitio web. Solo las entradas DNS de tipo **AAAA** son opcionales.

    Tenga en cuenta que si desea añadir `sub.domain.tld`, deberá crear la entrada TXT `ovhcontrol.domain.tld` y no la entrada `ovhcontrol.sub.domain.tld`.

    Para encontrar la zona DNS activa de su nombre de dominio, consulte los [servidores DNS](/guides/web-cloud/domains/dns-server-edit) a los que está vinculado. Solo deberá validar el nombre de dominio mediante el campo **TXT**, no todos sus subdominios.|

    :::

  </Tab>
</Tabs>

</details>

    :::info

### Oferta de correo incluida con su alojamiento web

La mayoría de las ofertas de [alojamiento web OVHcloud](https://www.ovhcloud.com/es-es/web-hosting/) disponen de una opción incluida de creación de direcciones de correo electrónico personalizadas con su nombre de dominio.

Esta opción de correo puede activarse para **un solo** nombre de dominio. Esto significa que si aloja varios sitios web con varios dominios diferentes en su alojamiento web, solo podrá activar esta opción para uno de sus dominios.

No dude en consultar [nuestra guía dedicada](/guides/web-cloud/web-hosting/activate-email-hosting) para más detalles sobre la activación de esta opción.
