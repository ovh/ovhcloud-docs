## Objetivo

Puede alojar varios sitios web en la misma oferta de alojamiento web, incluso si los dominios no están registrados en OVHcloud. Además, puede asociar uno o varios dominios o subdominios al mismo sitio web.

:::info
Si aún no ha creado el sitio web correspondiente en su alojamiento web, consulte **directamente** [esta guía](/guides/web-cloud/web-hosting/multisites-configure-multisite).

:::

**Descubra cómo asociar un nombre de dominio o un subdominio a un sitio web ya existente en su alojamiento web.**

## Requisitos

- Disponer de una oferta de [alojamiento web OVHcloud](https://www.ovhcloud.com/es-es/web-hosting/uc-multisite/) compatible.
- Disponer de uno o varios [dominios](https://www.ovhcloud.com/es-es/domains/).
- Poder modificar la configuración de sus dominios desde sus [zonas DNS](/guides/web-cloud/domains/dns-zone-edit).

[[cpnav:web-hosting-console]]

## Procedimiento

### Añadir un nombre de dominio o un subdominio a un sitio web existente

**Haga clic en uno de los títulos siguientes para mostrar las explicaciones.**

<a name="add-domain-ovhcloud"></a>

<details>
<summary>Añadir un dominio gestionado en su cuenta de OVHcloud</summary>

Esta parte solo se aplica si su dominio y/o su zona DNS activa se encuentran **en su cuenta de OVHcloud**.

El formulario ocupa una sola página: complételo de arriba abajo y valídelo. Haga clic en las pestañas de abajo para ver cada uno de los **4** pasos.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">Mis sitios</code>. En la tabla, haga clic en el botón <code className="action">⋮</code> situado en la columna **Acciones**, a la derecha del sitio web correspondiente, y luego, en el grupo **Nombres de dominio**, en <code className="action">Añadir un nombre de dominio</code>.

    <img className="thumbnail" alt="Menú Acciones de un sitio web, entrada Añadir un nombre de dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Se abrirá la página **Añadir un dominio**. Retoma el formulario de adición de sitio, en el que la **carpeta raíz** y el **nombre del sitio** ya están completados a partir del sitio web existente: déjelos tal cual.

    <img className="thumbnail" alt="Página Añadir un dominio y elección del tipo de nombre de dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    En la sección **Asociación del nombre de dominio**, elija la opción **Nombre de dominio OVHcloud existente**.
  </Tab>
  <Tab label="Etapa 4">
    Aparecerá la sección **Configurar su dominio**. Seleccione el dominio que desea asociar en el menú desplegable **Nombre de dominio**.

    <img className="thumbnail" alt="Configuración del dominio, opciones y configuración DNS" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-configure-domain.png" loading="lazy" />

    :::info
    Para añadir un subdominio, seleccione primero el dominio en la lista (por ejemplo: domain.tld). A continuación, marque la casilla **Crear un subdominio**. Aparecerá un campo para que introduzca el subdominio (por ejemplo: **sub**.domain.tld).

    **Caso particular**: el subdominio en `www` (por ejemplo: **www**.domain.tld) no se añade automáticamente con el dominio. Para que también muestre su sitio, añádalo por separado, repitiendo este procedimiento con `www.domain.tld`.
    :::

    La sección **Opciones** reúne tres funcionalidades, desmarcadas por defecto. Según su [plan de alojamiento web](/links/web/hosting), algunas pueden no estar disponibles.

    |Opción|Descripción|
    |---|---|
    |IP del país|Permite beneficiarse de una dirección IP geolocalizada (entre una lista de países) para el nombre de dominio seleccionado.<br/> Aprenda más gracias a [esta página](/links/web/hosting-options).|
    |Firewall|Permite activar un firewall (filtrado y análisis de las solicitudes) en el nombre de dominio seleccionado.<br/> Aprenda más gracias a [esta página](/links/web/hosting-options).|
    |CDN|Permite activar el CDN (caché de elementos estáticos de su sitio web, como las imágenes) en el nombre de dominio seleccionado.<br/> Aprenda más gracias a [nuestra página CDN](/links/web/hosting-options-cdn).<br/> Al activar el SSL y el CDN, también podrá beneficiarse del protocolo **HTTP/2** (este protocolo está activado por defecto en nuestro datacenter de Gravelines).|

    :::info
    Estas opciones pueden activarse más adelante. Para ello, consulte [esta guía](/guides/web-cloud/web-hosting/multisites-modify-domain).
    :::

    Por último, la sección **Configuración DNS** ofrece dos modos:

    - **Para una configuración automática**, deje seleccionada la opción **Configuración automática**: los registros A y AAAA se crean en la zona DNS del dominio.
    - **Para una configuración manual**, elija la opción **Configuración manual** y consulte las siguientes guías:
        - [Web hosting - Lista de direcciones IP por cluster](/guides/web-cloud/web-hosting/clusters-and-shared-hosting-ip)
        - [Editar una zona DNS de OVHcloud](/guides/web-cloud/domains/dns-zone-edit)

    Por último, haga clic en <code className="action">Validate</code>. La adición puede tardar hasta una hora.

    :::info
    La modificación de la configuración DNS de su dominio requiere un tiempo de propagación de hasta 48 horas para ser plenamente efectiva.
    :::
  </Tab>
</Tabs>

</details>

<details>
<summary>Añadir un nombre de dominio externo</summary>

Esta parte se aplica únicamente si su nombre de dominio no está presente en su cuenta OVHcloud.

El formulario ocupa una sola página: complételo de arriba abajo y valídelo. Haga clic en las pestañas de abajo para ver cada uno de los **4** pasos.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/hosting">Alojamiento web</ManagerLink> y elija el alojamiento web correspondiente.

    <img className="thumbnail" alt="Página Alojamiento web y lista de los alojamientos de la cuenta" src="/images/assets/screens/console/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en la pestaña <code className="action">Mis sitios</code>. En la tabla, haga clic en el botón <code className="action">⋮</code> situado en la columna **Acciones**, a la derecha del sitio web correspondiente, y luego, en el grupo **Nombres de dominio**, en <code className="action">Añadir un nombre de dominio</code>.

    <img className="thumbnail" alt="Menú Acciones de un sitio web, entrada Añadir un nombre de dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Se abrirá la página **Añadir un dominio**. Retoma el formulario de adición de sitio, en el que la **carpeta raíz** y el **nombre del sitio** ya están completados a partir del sitio web existente: déjelos tal cual.

    <img className="thumbnail" alt="Página Añadir un dominio y elección del tipo de nombre de dominio" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-domain-form-top.png" loading="lazy" />

    En la sección **Asociación del nombre de dominio**, elija la opción **Nombre de dominio externo**.
  </Tab>
  <Tab label="Etapa 4">
    En la sección **Configurar su dominio**, introduzca el dominio (por ejemplo: domain.tld) o el subdominio (por ejemplo: **sub**.domain.tld) en el campo **Nombre de dominio**.

    :::tip
    **Caso particular**: el subdominio en `www` (por ejemplo: **www**.domain.tld) no se añade automáticamente con el dominio. Para que también muestre su sitio, añádalo por separado, repitiendo este procedimiento con `www.domain.tld`.
    :::

    La sección **Gestión del dominio** muestra entonces los registros que deben crearse, en dos pasos. Esta verificación es obligatoria: nos permite asegurarnos de que la adición del dominio externo es legítima.

    <img className="thumbnail" alt="Gestión del dominio: registros DNS que se deben crear y registro BIND" src="/images/assets/screens/console/product-selection/web-cloud/web-hosting/my-websites/add-site-external-dns.png" loading="lazy" />

    1. **Verifique la propiedad del dominio**: añada el registro **TXT** indicado en la zona DNS de su proveedor.
    2. **Haga que el dominio apunte a su alojamiento**: añada los registros **A** y **AAAA** indicados.

    Cada valor dispone de un botón de copia, y el bloque **Registro BIND** recoge las tres líneas en el formato esperado por la mayoría de los proveedores de zonas DNS.

    Por último, haga clic en <code className="action">Validate</code>. El dominio se añade de forma temporal, mientras modifica su configuración DNS.

    :::warning
    Debe realizar estos cambios **rápidamente** para que su dominio quede correctamente asociado a su sitio web.

    Las entradas DNS de tipo **A** y **TXT** deben colocarse obligatoriamente en la zona DNS activa de su dominio. Solo las entradas DNS de tipo **AAAA** son opcionales.

    Tenga en cuenta que, si desea asociar `sub.domain.tld`, deberá crear la entrada TXT `ovhcontrol.domain.tld` y no la entrada `ovhcontrol.sub.domain.tld`.

    Para encontrar la zona DNS activa de su dominio, consulte los [servidores DNS](/guides/web-cloud/domains/dns-server-edit) a los que está vinculado.
    :::

    :::info
    La modificación de la configuración DNS de su dominio requiere un tiempo de propagación de hasta 48 horas para ser plenamente efectiva.
    :::
  </Tab>
</Tabs>

</details>

### Oferta de correo incluida con su alojamiento web

La mayoría de las ofertas de [alojamiento web OVHcloud](https://www.ovhcloud.com/es-es/web-hosting/) disponen de una opción incluida de creación de direcciones de correo electrónico personalizadas con su nombre de dominio.

Esta opción de correo puede activarse para **un solo** nombre de dominio. Esto significa que si aloja varios sitios web con varios dominios diferentes en su alojamiento web, solo podrá activar esta opción para uno de sus dominios.

No dude en consultar [nuestra guía dedicada](/guides/web-cloud/web-hosting/activate-email-hosting) para más detalles sobre la activación de esta opción.
