## Objetivo

**Managed Hosting for WordPress** es una nueva oferta de OVHcloud que permite alojar y administrar sus sitios web WordPress con total simplicidad. Pensado para los profesionales, las agencias y los autónomos, este servicio le libera de las tareas técnicas relacionadas con la gestión de la infraestructura y las actualizaciones, para que pueda concentrarse en su contenido y su actividad. Esta guía presenta el concepto del producto, sus principales ventajas y las funcionalidades disponibles.

## Requisitos

- Tener acceso al programa [OVHcloud Labs](https://labs.ovhcloud.com/en/managed-wp/).
- Estar conectado al <ManagerLink to="/">área de cliente de OVHcloud</ManagerLink>.

## Procedimiento

### Presentación del producto

#### Una gestión WordPress 100% OVHcloud

Con Managed Hosting for WordPress, **OVHcloud se ocupa de todo**:

- Alojamiento, infraestructura, caché y seguridad.
- Instalación y mantenimiento de WordPress.
- Copias de seguridad y actualizaciones automáticas.
- Supervisión del rendimiento y de la disponibilidad.
- Gestión simplificada de los dominios, las extensiones y los entornos de staging.

No es necesario tener conocimientos de servidor: todo es **accesible desde el área de cliente de OVHcloud**. De este modo, puede **crear, importar y administrar sus sitios web WordPress en unos clics**, sin tener que manipular FTP, base de datos ni línea de comandos.

#### Una solución llave en mano

Cada sitio web disfruta de un entorno optimizado, listo para usar:

- **Instalación WordPress automática** en el momento del pedido.
- **Infraestructura gestionada**: mantenimiento, parches, actualizaciones de software y seguridad gestionados por OVHcloud.
- **Rendimiento garantizado**: caché WordPress integrado, alojamiento en infraestructura optimizada y monitorización continua.
- **Escalabilidad integrada**: supervise el uso en tiempo real mediante indicadores clave (almacenamiento, tráfico, número de sitios) y adáptese fácilmente a la evolución de sus necesidades.
- **Compatibilidad total**: acceso mediante el área de cliente de OVHcloud, lo que permite la integración en sus workflows existentes.

### Funcionalidades

Conéctese al <ManagerLink to="/">área de cliente de OVHcloud</ManagerLink>, acceda a la sección <code className="action">Web Cloud</code> y haga clic en <code className="action">Managed hosting for WordPress</code>.

#### Crear un sitio web

Para crear un sitio web, haga clic en el botón <code className="action">Crear un sitio</code>. Aparece la siguiente página:

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_create_site.png" loading="lazy" />

Rellene los campos del formulario para definir los identificadores de su sitio web WordPress:

- <code className="action">Idioma de la administración WordPress</code>: seleccione el idioma por defecto de la interfaz de administración.
- <code className="action">Versión PHP</code>: elija la versión PHP deseada para su entorno WordPress. Consulte las versiones de PHP disponibles en [esta página](/guides/web-cloud/web-hosting/web-hosting-main-info).
- <code className="action">E-mail del administrador</code>: introduzca la dirección de e-mail del administrador del sitio WordPress.
- <code className="action">Contraseña del administrador</code>: defina la contraseña asociada a esta cuenta de administrador.

Haga clic en <code className="action">Continuar</code> para validar la información.

Será redirigido a la pestaña <code className="action">Mis sitios</code>. En la parte superior de la pantalla aparece un mensaje de confirmación que indica que su solicitud de creación de sitio web ha sido procesada.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_banner_creation_site.png" loading="lazy" />

En la tabla aparece una nueva línea correspondiente a su nuevo sitio web:

- Columna <code className="action">Nombre de dominio</code>: corresponde al nombre de dominio técnico de su sitio web. Sirve de URL de staging (pre-producción), lo que permite acceder a su sitio web antes de asociarlo a su propio nombre de dominio.
- Columna <code className="action">Estado</code>: indica el progreso de la creación del sitio web. El estado aparece primero como <code className="action">En curso</code>, mientras se despliega la infraestructura y se instala WordPress. Una vez que su sitio web está operativo, el estado pasa a <code className="action">Activado</code>, indicando que su WordPress ya está disponible en línea a través de su nombre de dominio técnico.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_tab_new_line.png" loading="lazy" />

También puede seguir el progreso de la creación de su sitio web haciendo clic en la pestaña <code className="action">Tareas</code>.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_task_new_line.png" loading="lazy" />

#### Importar un sitio web

Puede importar un sitio web WordPress existente a Managed Hosting for WordPress. La importación le permite transferir automáticamente:

- El contenido WordPress (plugins, themes, medios, artículos, páginas, usuarios).
- Los archivos.
- La base de datos.

Para importar un sitio web WordPress, haga clic en el botón <code className="action">Importar un sitio</code>. Aparece la siguiente pantalla:

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_import_site.png" loading="lazy" />

:::info
Un mensaje informativo le indica que su sitio web se instalará en un entorno que utiliza una versión de PHP estable (PHP 8.4 en nuestro ejemplo) y la última versión de WordPress.

:::


Rellene los campos del formulario:

- <code className="action">URL de administración del sitio</code>: indique la dirección utilizada para conectarse a la interfaz de administración de su sitio web WordPress actual, por ejemplo `https://www.misitio.com/wp-admin`.
- <code className="action">Cuenta de administrador</code>: introduzca el nombre de usuario administrador WordPress.
- <code className="action">Contraseña del administrador</code>: indique la contraseña del usuario administrador WordPress.

Esta información permite al sistema acceder a su sitio web existente para extraer automáticamente los archivos, la base de datos y la configuración necesaria.

Una vez rellenados los campos obligatorios, haga clic en <code className="action">Continuar</code> para iniciar el proceso de importación.

A continuación podrá seleccionar los elementos que desea importar, incluyendo plugins, temas, medios y bases de datos.

:::warning
Para garantizar la perfecta coherencia de los datos, evite realizar modificaciones en su sitio hasta el final de la importación.

Le aconsejamos activar el modo de mantenimiento en su sitio a importar o tomar las medidas necesarias para evitar cualquier divergencia de datos durante la importación.

:::


Una vez seleccionados todos los elementos, haga clic en <code className="action">Iniciar la importación</code>.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_import_site_selection.png" loading="lazy" />

:::danger
La eliminación de un sitio web es definitiva y conlleva la eliminación de la totalidad del contenido del sitio.
Asegúrese de realizar una copia de seguridad de sus datos antes de cualquier acción de eliminación.

:::

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_delete_site_button.png" loading="lazy" />

Aparece un mensaje de confirmación. Haga clic en <code className="action">Eliminar</code> para confirmar la eliminación de su sitio web.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_delete_site_confirmation.png" loading="lazy" />

Será redirigido a la pestaña <code className="action">Mis sitios</code>. En la parte superior de la pantalla aparece un mensaje de confirmación que indica que el proceso de eliminación de su sitio web está en curso.

<img className="thumbnail" alt="managed_wordpress" src="/images/web-cloud/managed-hosting/01-managed-wordpress-getting-started/managed_wordpress_delete_site_banner_validation.png" loading="lazy" />

#### Gestionar sus sitios web

Para gestionar todos sus sitios web, acceda a la pestaña <code className="action">Mis sitios</code> y haga clic en <code className="action">Gestionar mis sitios web</code>. Este botón abre automáticamente el gestor de flota, integrado en Managed Hosting for WordPress. Este espacio le permite gestionar varios sitios web WordPress simultáneamente, desde una interfaz unificada.

##### Panel de control

El gestor de flota es una herramienta de supervisión y de gestión centralizada proporcionada automáticamente con su oferta. Le permite administrar sus sitios web WordPress gestionados sin tener que conectarse a cada sitio web individualmente.

Desde este panel de control, puede en particular:

- Consultar el estado global de todos sus sitios web: actualizaciones disponibles, alertas, rendimiento, seguridad.
- Gestionar las actualizaciones WordPress (plugins, temas, etc.) de manera centralizada.
- Acceder rápidamente a cada sitio web para verificar su estado o intervenir.
- Supervisar las actividades recientes (cambios, actualizaciones, sincronizaciones).
- Utilizar las funcionalidades integradas de seguridad, monitorización, copias de seguridad y análisis (en las fases futuras).

#### Actualizaciones automáticas inteligentes

Las actualizaciones automáticas pueden generar problemas de compatibilidad que afectan a la estabilidad, el rendimiento y la experiencia de usuario del sitio. Cuando gestiona varios sitios WordPress, la gestión manual de las actualizaciones aumenta los costes operativos generales y el riesgo de interrupción del servicio para los usuarios finales.

La solución Managed Hosting for WordPress reduce estos riesgos mediante un proceso de actualización controlado:

- **Pruebas antes del despliegue**
    Todas las actualizaciones, incluidas las del núcleo de WordPress, los plugins y los temas, se aplican primero a un entorno clonado de su sitio.
- **Controles de validación**
    El sitio clonado se evalúa en términos de rendimiento, funcionalidad y experiencia de usuario para detectar regresiones o errores antes del despliegue.
- **Proceso de decisión automatizado**
    - Si no se detecta ningún problema, la actualización se despliega automáticamente en el sitio en línea.
    - Si se identifican problemas, el sitio en línea permanece inalterado. Recibirá una notificación a través del panel de control y un correo electrónico que describe los problemas detectados así como las medidas correctivas recomendadas.

Este enfoque garantiza que las actualizaciones se apliquen con total seguridad preservando la fiabilidad del sitio y minimizando el impacto en los usuarios finales.
