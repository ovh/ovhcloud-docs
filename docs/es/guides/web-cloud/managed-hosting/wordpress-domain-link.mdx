## Objetivo

**Managed Hosting for WordPress** es la solución de OVHcloud para alojamiento WordPress gestionado: el mantenimiento técnico (actualizaciones, seguridad, copias de seguridad) se realiza automáticamente. La oferta permite gestionar los nombres de dominio desde la interfaz de OVHcloud, sin intervención manual. Puede asociar un nombre de dominio o un subdominio a cada uno de sus sitios WordPress, independientemente de su origen.

Hay dos procedimientos disponibles según su situación:

- **Nombre de dominio interno**: el nombre de dominio ya está presente en su cuenta OVHcloud.
- **Nombre de dominio externo**: el nombre de dominio está gestionado por otro registrador.

**Descubra cómo añadir, modificar o eliminar los nombres de dominio de su Managed Hosting for WordPress desde el área de cliente de OVHcloud.**

## Requisitos

- Disponer de una oferta **Managed Hosting for WordPress** activa con al menos un sitio WordPress creado.
- Para un nombre de dominio externo: tener acceso a la zona DNS (Domain Name System) activa en su proveedor actual.

## Procedimiento

### 1 - Acceder a la gestión de los nombres de dominio

La adición de un nombre de dominio se realiza desde la pestaña <code className="action">Mis sitios</code> de su recurso Managed Hosting for WordPress. Haga clic en las pestañas siguientes para visualizar sucesivamente cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página <ManagerLink to="/beta/#/web-cloud/wordpress">Managed hosting for WordPress</ManagerLink> de su área de cliente de OVHcloud.

    <img className="thumbnail" alt="Vista del recurso Managed Hosting for WordPress en la lista de alojamientos WordPress" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/managed-hosting-for-wordpress.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Haga clic en <code className="action">Gestionar</code> bajo el recurso correspondiente.

    <img className="thumbnail" alt="Recurso Managed Hosting for WordPress en el datagrid con el botón Gestionar resaltado" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/manage-ressource-button.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Haga clic en la pestaña <code className="action">Mis sitios</code>. El datagrid muestra sus sitios WordPress con, para cada sitio, el dominio asociado y las acciones disponibles.

    <img className="thumbnail" alt="Pestaña Mis sitios mostrando el datagrid de los sitios WordPress" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/managed-hosting-for-wordpress-my-sites-tab.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 4">
    A la derecha del sitio WordPress correspondiente, haga clic en el botón <code className="action">⋮</code> y, a continuación, en <code className="action">Añadir un dominio</code>.

    <img className="thumbnail" alt="Botón Añadir un dominio en el menú de acciones de un sitio WordPress del datagrid" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/adding-domain.png" loading="lazy" />
  </Tab>
</Tabs>

:::info
El **primer nombre de dominio añadido** a un sitio WordPress se convierte automáticamente en el **nombre de dominio principal**. Podrá añadir otros más adelante (multidominio) y cambiar el nombre de dominio principal desde el mismo menú.
:::

### 2 - Añadir un nombre de dominio

**Haga clic en una de las situaciones siguientes para mostrar el contenido.**

<details>

<summary>Añadir un nombre de dominio interno</summary>

Un nombre de dominio **interno** es un nombre de dominio ya presente en su cuenta OVHcloud (registrado o transferido).

Una vez abierto el túnel de adición, seleccione el procedimiento interno para utilizar un nombre de dominio ya presente en su cuenta OVHcloud. Haga clic en las pestañas siguientes para visualizar sucesivamente cada una de las **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    En el túnel de adición, seleccione <code className="action">Asociar un dominio OVHcloud existente</code>.

    <img className="thumbnail" alt="Túnel de adición en la etapa de selección del procedimiento Asociar un dominio OVHcloud existente" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/attach-ovhcloud-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Seleccione el nombre de dominio o subdominio deseado en la lista de nombres de dominio disponibles en su cuenta OVHcloud.

    <img className="thumbnail" alt="Lista desplegable de nombres de dominio OVHcloud disponibles en la cuenta" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/select-ovh-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Compruebe el resumen y haga clic en <code className="action">Añadir</code>. La configuración DNS se realiza automáticamente.

    {/* DRAFT: To screenshot — capturar el resumen de adición de dominio con el botón Añadir */}
  </Tab>
</Tabs>

:::info
Para un nombre de dominio interno, la propagación DNS es automática. Su sitio será accesible mediante este nombre de dominio en unos minutos a unas horas.
:::

</details>

<details>

<summary>Añadir un nombre de dominio externo</summary>

Un nombre de dominio **externo** está gestionado por otro registrador (Gandi, Namecheap, Google Domains, etc.). Deberá modificar manualmente su zona DNS.

Una vez abierto el túnel de adición, seleccione el procedimiento externo para utilizar un nombre de dominio gestionado por otro registrador. Haga clic en las pestañas siguientes para visualizar sucesivamente cada una de las **4** etapas.

<Tabs>
  <Tab label="Etapa 1">
    En el túnel de adición, seleccione <code className="action">Asociar un dominio externo</code>.

    <img className="thumbnail" alt="Túnel de adición en la etapa de selección del procedimiento Asociar un dominio externo" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/attach-external-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    Introduzca su nombre de dominio (por ejemplo: `domain.tld`) en el campo previsto.

    <img className="thumbnail" alt="Campo de introducción del nombre de dominio externo con un ejemplo de dominio informado" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/associate-external-domain.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    La interfaz muestra los registros DNS que hay que añadir en su proveedor actual. Conéctese a la interfaz DNS de su proveedor y añada los registros indicados (generalmente un registro DNS de tipo **A** o **CNAME**: **C**anonical **NAME**).

    {/* DRAFT: To screenshot — capturar los valores DNS que hay que configurar (registro A o CNAME) mostrados por la interfaz de OVHcloud */}
  </Tab>
  <Tab label="Etapa 4">
    Una vez realizada la configuración DNS en su proveedor, vuelva al área de cliente de OVHcloud y haga clic en <code className="action">Confirmar</code>.

    {/* DRAFT: To screenshot — capturar el botón Confirmar al final del túnel de adición de dominio externo */}
  </Tab>
</Tabs>

:::warning
La propagación DNS de un nombre de dominio externo puede tardar hasta **24 a 48 horas** según su proveedor. Su sitio WordPress no será accesible mediante este nombre de dominio durante este periodo.
:::

:::info
El certificado SSL (Secure Sockets Layer) se genera automáticamente tras la validación de la propagación DNS. No es necesaria ninguna intervención manual por su parte.
:::

</details>

**Efectos de la eliminación:**

- **Su sitio WordPress permanece intacto**: solo se rompe el enlace con el nombre de dominio, el sitio sigue funcionando.
- **La URL técnica permanente sigue siendo accesible**: su sitio WordPress sigue siendo accesible mediante esta URL, incluso sin nombre de dominio.
- **El certificado SSL se revoca**: ya no cubre el nombre de dominio eliminado.
- **El posicionamiento SEO puede verse afectado**: si el nombre de dominio estaba indexado por los motores de búsqueda, su retirada afecta al posicionamiento.
- **Recuerde comprobar sus servicios de correo electrónico**: las direcciones vinculadas a este nombre de dominio pueden verse afectadas por la eliminación.

:::info
**Caso particular — nombre de dominio principal único:** si elimina el único nombre de dominio principal de un sitio WordPress, su sitio WordPress se bascula automáticamente a su **URL técnica permanente**. Esta URL siempre es accesible y nunca se elimina, incluso en ausencia de dominio asociado.
:::

</details>

### La URL técnica permanente

Cada sitio Managed Hosting for WordPress dispone de una **URL técnica permanente**, independiente de cualquier nombre de dominio. Esta URL se genera automáticamente cuando se crea el sitio WordPress y no se puede eliminar.

<img className="thumbnail" alt="Vista del datagrid Mis sitios mostrando el nombre de dominio y la URL técnica de un sitio WordPress" src="/images/guides/web-cloud/managed-hosting/wordpress-domain-link/show-domain-linked-to-a-site.png" loading="lazy" />

Le permite:

- Acceder a su sitio WordPress **en todas las circunstancias**, incluso sin nombre de dominio asociado.
- Probar su sitio WordPress antes de hacer apuntar un nombre de dominio a él.
- Mantener un acceso de reserva en caso de problema DNS.

:::info
La URL técnica tiene la forma `*.mcms.ovh.net` o similar. Encuéntrela en el datagrid <code className="action">Mis sitios</code>, frente a cada sitio WordPress.
:::
