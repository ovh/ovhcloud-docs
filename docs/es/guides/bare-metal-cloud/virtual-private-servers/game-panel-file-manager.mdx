## Objetivo

El File Manager le permite explorar, modificar, subir, descargar y organizar los archivos de su servidor directamente desde el Game Panel de OVHcloud.

**Esta guía explica cómo utilizar el File Manager del Game Panel.**

## Requisitos

- Un [VPS](/links/bare-metal/vps) o un [servidor dedicado](/links/bare-metal/bare-metal) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Un servidor de juego desplegado en el Game Panel.
- Acceder al Game Panel. Consulte la guía [Conectarse al Game Panel de OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedimiento

### Acceder al File Manager

1. Abra los <code className="action">Settings</code> de su servidor.
2. Acceda a la pestaña <code className="action">File Manager</code>.

Una vez abierta la pestaña, verá la lista de archivos y carpetas disponibles en su servidor.

<img className="thumbnail" alt="El Gestor de archivos del Game Panel mostrando la lista de archivos y carpetas" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/file-manager-list.png" loading="lazy" />

### Seleccionar un volumen de almacenamiento

Si hay varios volúmenes de almacenamiento configurados en su servidor, puede seleccionar el volumen deseado mediante el menú desplegable situado en la esquina superior izquierda del File Manager.

### Barra de herramientas del File Manager

En la parte superior del File Manager, encontrará:

- La ruta actual.
- Un botón <code className="action">Refresh</code> para recargar el directorio actual.
- Un botón <code className="action">Create Folder</code>.
- Un botón <code className="action">Create File</code>.
- Un botón <code className="action">Upload</code> para los archivos y las carpetas.
- Un botón <code className="action">Copy Path</code> para copiar la ruta del directorio actual en su portapapeles.

<img className="thumbnail" alt="La barra de herramientas del Gestor de archivos con la ruta y los botones Actualizar, Crear carpeta, Crear archivo, Subir y Copiar ruta" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/file-manager-toolbar.png" loading="lazy" />

### Explorar los archivos y las carpetas

**Abrir una carpeta**

Haga doble clic en una carpeta para acceder a ella.

**Modificar un archivo**

Haga doble clic en un archivo para abrirlo en el editor de texto integrado.

:::info
Los archivos de más de 2 MB no pueden modificarse en línea. En ese caso, debe descargar el archivo, modificarlo localmente en su ordenador y, a continuación, volver a subir la versión modificada al servidor.
:::

### Acciones sobre los archivos y las carpetas

Cuando pasa el cursor sobre un archivo o una carpeta, hay acciones adicionales disponibles:

- **Download**
- **Rename**
- **Delete**

<img className="thumbnail" alt="Las acciones de archivos y carpetas al pasar el cursor: Descargar, Renombrar y Eliminar" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/file-manager-actions.png" loading="lazy" />

:::warning
Renombrar o eliminar archivos mientras el servidor está en ejecución puede provocar comportamientos inesperados. En la medida de lo posible, detenga el servidor antes de realizar estas operaciones.
:::

Al descargar una carpeta, esta se comprime automáticamente en un archivo `.zip` para acelerar el proceso de descarga.

### Compatibilidad con arrastrar y soltar

El File Manager admite las operaciones de arrastrar y soltar.

**Mover archivos y carpetas**

Puede arrastrar y soltar archivos o carpetas para:

- Moverlos a otra carpeta.
- Moverlos al directorio padre soltándolos sobre la entrada `..`, que representa la carpeta padre.

**Subir desde su ordenador**

También puede arrastrar archivos y carpetas directamente desde su ordenador al File Manager. Se suben automáticamente al directorio que esté abierto en ese momento. Para las subidas de gran tamaño, se muestra una barra de progreso para cada archivo, lo que le permite seguir el estado de la subida.

### Permisos

El acceso al File Manager puede restringirse para determinados usuarios. Para configurar los permisos del File Manager, consulte la guía [Gestionar los usuarios en el Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-manage-users/).
