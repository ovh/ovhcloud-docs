## Objetivo

El Game Panel de OVHcloud proporciona una interfaz dedicada para gestionar sus servidores de juego. Para utilizarlo, debe conectarse con sus credenciales.

**Esta guía explica cómo conectarse al Game Panel de OVHcloud y cómo recuperar una contraseña perdida.**

## Requisitos

- Un [VPS](/links/bare-metal/vps) o un [servidor dedicado](/links/bare-metal/bare-metal) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- El enlace de acceso al Game Panel proporcionado durante la instalación.

## Procedimiento

### Paso 1 - Acceder al Game Panel

Diríjase a su Game Panel. El enlace de acceso depende del dominio seleccionado durante la instalación.

<img className="thumbnail" alt="Página de inicio de sesión del Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login.png" loading="lazy" />

### Paso 2 - Conectarse

Introduzca su nombre de usuario y la contraseña asociada y, a continuación, haga clic en <code className="action">Sign In</code> para conectarse al Game Panel.

<img className="thumbnail" alt="Introducción de las credenciales en la página de inicio de sesión" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-log-in/game-panel-login-form.png" loading="lazy" />

### Recuperar una contraseña perdida

#### Cuentas no administradoras

En caso de contraseña perdida, solicite a un administrador que la restablezca. Consulte la guía [Gestionar los usuarios en el Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-manage-users/) para más información.

#### Cuenta de superadministrador

Si se ha perdido la contraseña del superadministrador, restablézcala: conéctese por SSH a la máquina host, acceda a la carpeta de despliegue de la instalación y, a continuación, ejecute el siguiente comando. Si no está familiarizado con las conexiones SSH, consulte la guía [Cómo empezar con buen pie con las conexiones SSH](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction/).

```bash
sudo bash tools/reset-admin-password.sh
```

Resultado esperado:

```console
New admin password: XXXXXXXXXX
Confirm new admin password: XXXXXXXXXX
[INFO] Updating the root user password in the database...
[INFO] Rotating JWT secret...
[INFO] Recreating the backend to invalidate existing sessions...
[INFO] Admin password reset complete for user: admin
```

Vuelva a conectarse a la aplicación con la nueva contraseña de administrador.

:::warning
Esta operación desconecta a todos los usuarios actualmente conectados.
:::
