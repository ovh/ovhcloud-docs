## Objetivo

El Game Panel expone la configuración del servidor Minecraft directamente en su interfaz. Las opciones básicas, como el modo de juego y la dificultad, son accesibles a través de un formulario gráfico, mientras que los parámetros avanzados le permiten editar directamente el archivo `server.properties` para un control completo.

**Esta guía explica cómo modificar la configuración de un servidor Minecraft en el Game Panel.**

## Requisitos

- Un [VPS](https://www.ovhcloud.com/es-es/vps/) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Un servidor Minecraft desplegado en el Game Panel. Consulte la guía [Desplegar un servidor Minecraft en el Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

## Procedimiento

### Paso 1 — Abrir los parámetros del servidor

Desde la página principal del Game Panel, localice el servidor Minecraft que desea configurar. En la columna <code className="action">Management</code>, haga clic en <code className="action">Settings</code>.

<img className="thumbnail" alt="Servidor Minecraft con el botón Settings resaltado" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-server-settings.png" loading="lazy" />

### Paso 2 — Abrir la pestaña Game Config

En el Game Panel **Server Settings**, seleccione <code className="action">Game Config</code> en la barra lateral izquierda.

<img className="thumbnail" alt="Pestaña Game Config en el Game Panel Server Settings" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-game-config.png" loading="lazy" />

### Paso 3 — Configurar su juego

La sección **Game Configuration** le permite:

- Activar o desactivar las **actualizaciones automáticas**.
- Ajustar el **modo de juego**, la **dificultad** y otras opciones de jugabilidad.

### Paso 4 — Modificar los parámetros avanzados

La sección **Advanced Configuration** le da acceso directo al archivo `server.properties`, ofreciendo más control que las opciones gráficas básicas.

<img className="thumbnail" alt="Sección Advanced Configuration que muestra el editor server.properties" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-minecraft-config/minecraft-advanced-config.png" loading="lazy" />

:::info
Para obtener la lista completa de las claves de `server.properties` con sus descripciones, valores por defecto y rangos aceptados, consulte la [página oficial de la Wiki de Minecraft sobre server.properties](https://minecraft.wiki/w/Server.properties).
:::


Algunas claves habituales que puede querer ajustar:

| Clave | Descripción | Valor por defecto |
|-----|-------------|---------|
| `gamemode` | Modo de juego por defecto (`survival`, `creative`, `adventure`, `spectator`) | `survival` |
| `difficulty` | Dificultad del servidor (`peaceful`, `easy`, `normal`, `hard`) | `easy` |
| `max-players` | Número máximo de jugadores simultáneos | `20` |
| `motd` | Mensaje mostrado en la lista de servidores | `A Minecraft Server` |
| `online-mode` | Restringe la conexión a las cuentas Minecraft autenticadas | `true` |
| `view-distance` | Distancia de renderizado del lado del servidor, en chunks (3-32) | `10` |
| `simulation-distance` | Distancia de actualización de las entidades, en chunks (3-32) | `10` |
| `white-list` | Restringe las conexiones a los jugadores presentes en la lista blanca | `false` |
| `hardcore` | Activa el modo hardcore | `false` |
| `pvp` | Activa el daño entre jugadores | `true` |

:::warning
Algunas claves (como `level-seed`, `level-type`, `generator-settings`) solo se aplican a la generación del mundo. Modificarlas en un mundo existente no tiene ningún efecto.
:::


### Paso 5 — Guardar y reiniciar

Guarde sus modificaciones y, a continuación, reinicie el servidor Minecraft desde el Game Panel para aplicar la nueva configuración.
