## Objetivo

PaperMC es una implementación de alto rendimiento del servidor de Minecraft, compatible con plugins que amplían las funcionalidades de juego. El Game Panel permite desplegar un servidor PaperMC con unos pocos clics y, a continuación, personalizarlo subiendo plugins.

**Esta guía le explica cómo instalar un servidor PaperMC en el Game Panel y añadir plugins.**

## Requisitos

- Un [VPS](https://www.ovhcloud.com/es-es/vps/) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Acceso al Game Panel. Consulte la guía [Conectarse al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedimiento

### Paso 1 - Instalar un servidor PaperMC

Desde la página principal del Game Panel, haga clic en <code className="action">Add Game Server</code>, localice **PaperMC** y haga clic en <code className="action">Select</code>.

Para obtener más información sobre la instalación de un servidor, consulte la guía [Primeros pasos con el Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

### Paso 2 - Descargar plugins

Descargue plugins desde una fuente de confianza, como el repositorio [PaperMC Hangar](https://hangar.papermc.io/).

### Paso 3 - Subir los plugins con el File Manager

En su servidor PaperMC, haga clic en <code className="action">Settings</code> y, a continuación, abra la pestaña <code className="action">File Manager</code>. Acceda a la carpeta `serverfiles`, abra el directorio `plugins` y suba sus archivos de plugins mediante <code className="action">Upload files</code> o arrastrando y soltando.

### Paso 4 - Reiniciar el servidor

Desde la página principal del Game Panel, reinicie su servidor con el botón correspondiente.

:::info
Vigile los logs del servidor para confirmar que arranca correctamente y que los plugins se cargan.
:::
