## Objetivo

El Game Panel de OVHcloud le permite personalizar su servidor Minecraft instalando mods y plugins, según el software de servidor que utilice.

**Esta guía explica cómo instalar mods y plugins en su servidor Minecraft alojado en el Game Panel de OVHcloud.**

## Requisitos

- Un [VPS](/links/bare-metal/vps) o un [servidor dedicado](/links/bare-metal/bare-metal) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Un servidor Minecraft que utilice uno de los siguientes softwares: **PaperMC**, **Fabric** o **NeoForge**.
- Acceder al Game Panel. Consulte la guía [Conectarse al Game Panel de OVHcloud](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedimiento

### Comprender la diferencia entre PaperMC, Fabric y NeoForge

Aunque estas tres plataformas le permiten personalizar su servidor Minecraft, funcionan de forma diferente.

- **PaperMC** es un software de servidor Minecraft de alto rendimiento que admite **plugins**. Los plugins son complementos ligeros que pueden añadir nuevos comandos, mecánicas de juego, sistemas de permisos, sistemas económicos y mucho más, sin que los jugadores tengan que instalar nada en su cliente de juego.
- **Fabric** es un **cargador de mods** ligero y moderno. Admite una amplia variedad de mods y es conocido por sus actualizaciones rápidas y su excelente rendimiento. El servidor y, en la mayoría de los casos, los jugadores conectados deben tener instalados los mods necesarios.
- **NeoForge** es un **cargador de mods** potente y moderno, diseñado para modpacks más grandes y avanzados. Ofrece amplias posibilidades de modding y se utiliza habitualmente para experiencias Minecraft muy modificadas con añadidos de gameplay complejos.

En resumen:

- PaperMC → Plugins
- Fabric → Mods
- NeoForge → Mods

### Paso 1: Descargar sus plugins o sus mods

Primero debe descargar el plugin o el mod que desea instalar. Numerosos sitios web ofrecen plugins y mods de Minecraft, pero uno de los más populares es [CurseForge](https://www.curseforge.com/minecraft).

1. Busque el plugin o el mod deseado.
2. Abra su página.
3. Haga clic en <code className="action">Download</code>.
4. Asegúrese de seleccionar la **versión de Minecraft** correcta y el **cargador de plugin/mod** adecuado (Paper, Fabric o NeoForge).

Esto garantiza que el plugin o el mod sea compatible con su servidor.

<img className="thumbnail" alt="Descarga de un plugin o un mod" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-plugins/download-plugin-mod.png" loading="lazy" />

### Paso 2: Detener el servidor

Antes de instalar un plugin o un mod, detenga su servidor Minecraft.

1. Abra su servidor en el Game Panel.
2. Haga clic en <code className="action">Stop</code>.

:::warning
Instalar archivos mientras el servidor está en ejecución puede provocar problemas o impedir que se carguen correctamente.
:::

### Paso 3: Subir el plugin o el mod

1. Abra su servidor en el Game Panel.
2. Acceda a <code className="action">Settings</code>.
3. Abra la pestaña <code className="action">Game Config</code>.
4. Seleccione la pestaña <code className="action">Plugins</code> o <code className="action">Mods</code>, según el software de su servidor.

<img className="thumbnail" alt="La pestaña Plugins o Mods en Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-plugins/plugins-mods-tab.png" loading="lazy" />

A continuación, suba el archivo:

1. Localice el archivo del plugin o del mod que ha descargado en su ordenador.
2. Arrastre y suelte el archivo en la zona de subida.

<img className="thumbnail" alt="Subida de un archivo de plugin o de mod" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-mods-plugins/upload-area.png" loading="lazy" />

Una vez finalizada la subida, el plugin o el mod aparece en la lista.

### Paso 4: Iniciar el servidor

Después de subir su plugin o su mod:

1. Inicie su servidor Minecraft.
2. Abra los registros del servidor.

Es muy recomendable supervisar los registros durante el inicio para asegurarse de que el servidor arranca correctamente, de que no se notifica ningún error y de que los plugins o los mods instalados se cargan correctamente.

Si todo se carga sin errores, la instalación ha finalizado. Puede repetir este proceso cada vez que desee añadir contenido adicional a su servidor.
