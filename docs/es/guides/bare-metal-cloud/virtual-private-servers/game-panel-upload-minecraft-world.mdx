## Objetivo

El Game Panel de OVHcloud le permite subir un mundo de Minecraft personalizado transfiriendo los archivos con el File Manager y ajustando la configuración de la carpeta del mundo.

**Esta guía le explica cómo subir un mapa personalizado a su servidor de Minecraft alojado en el Game Panel de OVHcloud.**

## Requisitos

- Un [VPS](https://www.ovhcloud.com/es-es/vps/) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Un servidor de Minecraft desplegado en el Game Panel. Consulte la guía [Desplegar un servidor de Minecraft en el Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

:::warning
Asegúrese de que su servidor de Minecraft esté **detenido** antes de realizar cualquiera de las siguientes acciones.
:::


## Procedimiento

### Paso 1 - Abrir el File Manager

En su servidor de Minecraft, haga clic en <code className="action">Settings</code> y, a continuación, abra la pestaña <code className="action">File Manager</code>.

### Paso 2 - Localizar la carpeta del mundo

En el File Manager, navegue hasta:

```
data > serverfiles
```

En este directorio verá una carpeta llamada `world`. Esta carpeta contiene su mapa de Minecraft actual y se crea por defecto.

<img className="thumbnail" alt="La carpeta world por defecto en la estructura de archivos del servidor" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder.png" loading="lazy" />

### Paso 3 - Preparar el servidor para su nuevo mapa

Antes de subir su propio mapa, debe liberar el nombre de carpeta `world`. Dispone de tres opciones:

- **Eliminarla** con la acción <code className="action">Delete</code> si ya no la necesita.
- **Renombrarla** con la acción <code className="action">Rename</code> para conservarla como copia de seguridad.
- **Descargarla en local** con la acción <code className="action">Download</code>.

### Paso 4 - Subir su mapa personalizado

En el File Manager, dentro de `data > serverfiles`, haga clic en <code className="action">Upload files</code> o arrastre y suelte la carpeta de su mapa en la lista de archivos.

### Paso 5 - Configurar el nombre del mundo (si es necesario)

Si la carpeta de su mapa no se llama `world`, debe actualizar la configuración del servidor:

1. Vuelva al Game Panel.
2. Abra los <code className="action">Settings</code> de su servidor.
3. Vaya a la pestaña <code className="action">Game Config</code>.
4. Localice la opción **World folder name**.
5. Introduzca el nombre exacto de la carpeta de su mapa.

<img className="thumbnail" alt="Configuración del nombre de la carpeta del mundo en Game Config" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-upload-minecraft-world/world-folder-name-config.png" loading="lazy" />

:::info
**Utilizar varios mapas**: puede almacenar varios mapas en su servidor y alternar fácilmente entre ellos. Modifique el campo **World folder name** en la sección Game Config para cargar un mapa diferente. No olvide reiniciar el servidor después de modificar este parámetro.
:::


### Paso 6 - Iniciar el servidor

Reinicie su servidor desde el Game Panel. Su mapa personalizado de Minecraft ya está listo para usarse.
