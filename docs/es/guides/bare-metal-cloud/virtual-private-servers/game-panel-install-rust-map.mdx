## Objetivo

El Game Panel le permite personalizar su servidor de Rust instalando un mapa personalizado. El archivo del mapa se aloja de forma externa y se referencia desde la configuración de su servidor.

**Esta guía le explica cómo instalar un mapa personalizado en un servidor de Rust alojado en el Game Panel.**

## Requisitos

- Un [VPS](https://www.ovhcloud.com/es-es/vps/) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Un servidor de Rust desplegado en el Game Panel.
- Un archivo de mapa personalizado en formato `.map`.

## Procedimiento

### Paso 1 - Preparar su mapa personalizado

1. Detenga su servidor de Rust desde el Game Panel.
2. Asegúrese de que su mapa personalizado esté en formato `.map`.
3. Suba el mapa a un servicio de intercambio de archivos.
4. Copie el enlace de descarga obtenido y consérvelo: lo necesitará más adelante.

:::warning
Dropbox no es adecuado para este uso. Utilice otro servicio de intercambio de archivos.
:::


### Paso 2 - Abrir el File Manager

En su servidor de Rust, haga clic en <code className="action">Settings</code> y, a continuación, abra la pestaña <code className="action">File Manager</code>.

:::warning
Asegúrese de que su servidor de Rust esté **detenido** antes de realizar cualquiera de las siguientes acciones.
:::


### Paso 3 - Modificar la configuración del servidor

1. En el File Manager, acceda a:

    ```
    /serverfiles/server/rustserver/cfg
    ```

2. Localice el archivo `server.cfg` y ábralo para modificarlo.
3. Busque la línea que comienza por `levelURL=` y pegue el enlace de descarga guardado anteriormente después del signo `=`.
4. Asegúrese de que el enlace termine en `dl=1` (y no en `dl=0`). Modifíquelo si es necesario.
5. Busque la línea que comienza por `serverLevel=` e introduzca el mismo tipo de nivel que el utilizado para generar el mapa personalizado:

    - `Procedural Map`
    - `Barren`
    - `Craggy Island`
    - `Savas Island`

6. Guarde sus modificaciones.

### Paso 4 - Reiniciar el servidor

Una vez guardadas sus modificaciones, reinicie su servidor de Rust desde el Game Panel.
