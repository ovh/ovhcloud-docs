## Objetivo

Crear una instantánea (<i>snapshot</i>) es una forma simple y rápida de proteger un sistema en funciones antes de realizar cambios (p. ej., probar una nueva configuración o <i>software</i>) que puedan tener consecuencias indeseadas o imprevistas. Sin embargo, no constituye una estrategia completa de copia de seguridad del sistema.

**Descubra cómo activar y usar la opción snapshot desde la consola de OVHcloud.**

:::info
Antes de aplicar las opciones de copia de seguridad, le recomendamos que consulte las [preguntas frecuentes y demás páginas del producto](/links/bare-metal/vps-options) para acceder a una comparativa de los precios y otras informaciones.

:::


## Requisitos

- Tener un [servicio de servidor virtual privado (VPS)](/links/bare-metal/vps) de OVHcloud configurado.

:::warning
Esta funcionalidad no está disponible actualmente para los servidores virtuales en las [Local Zones](/links/bare-metal/vps-lz).

:::

## Procedimiento

### Paso 1: Suscribirse a la opción "Snapshot"

En la pestaña <code className="action">Resumen</code>, desplácese hacia abajo hasta la sección **Copia de seguridad**.  
Si la línea **Instantánea** indica "Activado", vaya directamente al paso 2. Si indica "Desactivado", haga clic en el enlace <code className="action">Contratar un snapshot</code> bajo la línea **Instantánea**.

<img className="thumbnail" alt="Sección Copia de seguridad de un VPS en la consola de OVHcloud, con el enlace Contratar un snapshot" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_step1b.png" loading="lazy" />

En el panel que se abre, consulte la información sobre los precios y, a continuación, haga clic en <code className="action">Contratar</code>. Se le guiará por el proceso de contratación y recibirá un mensaje de correo electrónico de confirmación.

Para dar de baja la opción, haga clic en el enlace <code className="action">Dar de baja</code> bajo la línea **Instantánea** y, a continuación, en <code className="action">Confirmar</code> en la ventana **Dar de baja la opción Snapshot**.

:::warning
La baja se hará efectiva en la fecha de renovación de la opción y no podrá anularse.
:::

<img className="thumbnail" alt="Línea Instantánea de un VPS en la consola de OVHcloud, con el enlace Dar de baja" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_cancel.png" loading="lazy" />

### Paso 2: Tomar una instantánea

Una vez activada la opción, haga clic en el enlace <code className="action">Realizar un snapshot</code> bajo la línea **Instantánea**. En la ventana **Realizar un snapshot**, puede escribir una descripción que se asociará al snapshot y, a continuación, haga clic en <code className="action">Confirmar</code>.

:::warning
Su VPS no estará accesible mientras se realiza el snapshot, y cualquier snapshot anterior se perderá.
:::

El tiempo de creación del snapshot depende del espacio de almacenamiento utilizado. Después, actualice la página para ver la fecha de creación en la línea **Instantánea** de la sección **Copia de seguridad**.

### Paso 3: Eliminar o restaurar una instantánea

Puesto que solo se puede activar un snapshot a la vez, debe eliminar el snapshot existente antes de crear uno nuevo. Simplemente haga clic en el enlace <code className="action">Eliminar el snapshot</code> bajo la línea **Instantánea** y, a continuación, en <code className="action">Eliminar el snapshot</code> en la ventana que se abre para confirmar.

<img className="thumbnail" alt="Línea Instantánea de un VPS en la consola de OVHcloud, con sus enlaces de snapshot" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps_step2.png" loading="lazy" />

Si está seguro de que desea restaurar su VPS al estado del snapshot, haga clic en <code className="action">Restaurar el snapshot</code> y confirme la restauración en la ventana que se abre.

:::warning
La restauración del snapshot borra la versión actual de su VPS y lo devuelve al estado del snapshot. Esta acción es irreversible.
:::

:::danger
Tenga en cuenta que, al restaurar un VPS a partir de un snapshot, el snapshot se eliminará. Si desea conservar la misma instantánea, debe tomar una nueva antes de realizar cambios en el sistema restaurado.

Si la función snapshot es demasiado limitada para su proyecto, la opción [Backup automatizado](/guides/bare-metal-cloud/virtual-private-servers/using-automated-backups-on-a-vps) es una alternativa.

:::


### Descargar un snapshot

El snapshot actual puede recuperarse mediante un enlace de descarga. Haga clic en el enlace <code className="action">Descargar el snapshot</code> bajo la línea **Instantánea**.

<img className="thumbnail" alt="Sección Copia de seguridad de un VPS en la consola de OVHcloud, con el enlace Descargar el snapshot" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps03.png" loading="lazy" />

:::info
Si su VPS proviene de una antigua gama, es posible que reciba un mensaje de error, ya que la opción no está disponible en los antiguos VPS. Su VPS procede de una antigua gama si su modelo de denominación es similar a: *vpsXXXX.ovh.net* (donde *X* representa un número). Puede consultar esta referencia del servidor en el encabezado de la página de su VPS en la <ManagerLink to="/">consola de OVHcloud</ManagerLink>.

:::


En el panel **Descargar el snapshot**, haga clic en <code className="action">Generar el enlace de descarga</code>.

<img className="thumbnail" alt="Panel Descargar el snapshot en la consola de OVHcloud, con el botón Generar el enlace de descarga" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps04.png" loading="lazy" />

Al cabo de unos segundos, se mostrará un mensaje de éxito. Abajo, puede copiar el comando completo de descarga en un clic y, a continuación, ejecutarlo en su terminal.

<img className="thumbnail" alt="Panel Descargar el snapshot en la consola de OVHcloud con el comando de descarga generado" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/console/snapshot_vps05.png" loading="lazy" />

El tamaño del snapshot también se muestra en la sección **Información**.

Tenga en cuenta que el enlace de descarga expirará después de **24 horas**.

La orden de descarga utiliza un `curl` en el siguiente formato:

```bash
curl "https://storage.sbg.cloud.ovh.net/v1/AUTH_f5fgh4674dd706f15f6ffgf4z667d3f4g5f05/glance/5ceg3f93-8b49-436b-aefe-4185f9fc3f78?
temp_url_sig=f508cacda60256d5f211ddddf3f81130e935f0e4&temp_url_expires=1678247579" --output vps-x11x11xyy.vps.ovh.net --fail
```

Este comando debe funcionar desde cualquier terminal de línea de comandos. No obstante, cuando utilice Windows *PowerShell*, deberá ajustar el comando de la siguiente forma:

```powershell
curl -Uri "https://storage.sbg.cloud.ovh.net/v1/AUTH_f5fgh4674dd706f15f6ffgf4z667d3f4g5f05/glance/5ceg3f93-8b49-436b-aefe-4185f9fc3f78?
temp_url_sig=f508cacda60256d5f211ddddf3f81130e935f0e4&temp_url_expires=1678247579" -OutFile vps-x11x11xyy.vps.ovh.net
```

<img className="thumbnail" alt="snapshotvps" src="/images/bare-metal-cloud/virtual-private-servers/using-snapshots-on-a-vps/snapshot_vps06.png" loading="lazy" />

:::info
No obstante, para no consumir demasiado espacio de almacenamiento, le recomendamos que no descargue los snapshots directamente en el VPS.

El archivo cargado puede importarse en un proyecto de Public Cloud como imagen (QCOW2) mediante [OpenStack](/guides/public-cloud/compute/overview). (Consulte un ejemplo de uso en [esta guía](/guides/public-cloud/compute/upload-own-image).)

:::


### Buenas prácticas para la creación de un snapshot

#### Configuración del software QEMU en un VPS

Los snapshots son imágenes instantáneas de su sistema en ejecución (« live snapshots »). Para garantizar la disponibilidad de su sistema durante la creación del snapshot, el software QEMU permite preparar el sistema de archivos para este proceso.

El *qemu-guest-agent* necesario no está instalado por defecto en la mayoría de distribuciones. Además, las restricciones de licencia pueden impedir que OVHcloud lo incluya en las imágenes de los SO disponibles. Por lo tanto, le recomendamos que compruebe si este agente está activado en su VPS y, en caso negativo, que lo instale. Para ello, conéctese a su VPS por SSH y siga las instrucciones que se indican en función de su sistema operativo.

##### **Distribuciones Debian (Debian, Ubuntu)**

Utilice el siguiente comando para comprobar si el sistema está configurado correctamente para los snapshots:

```bash
file /dev/virtio-ports/org.qemu.guest_agent.0
/dev/virtio-ports/org.qemu.guest_agent.0: symbolic link to ../vport2p1
```

Si el resultado es diferente (« No such file or directory »), instale la última versión del paquete:

```bash
sudo apt-get update
sudo apt-get install qemu-guest-agent
```

Reinicie el VPS:

```bash
sudo reboot
```

Verifique el servicio para garantizar que está en ejecución:

```bash
sudo service qemu-guest-agent status
```

##### **Distribuciones Red Hat (CentOS, Fedora)**

Utilice el siguiente comando para comprobar si el sistema está configurado correctamente para los snapshots:

```bash
file /dev/virtio-ports/org.qemu.guest_agent.0
/dev/virtio-ports/org.qemu.guest_agent.0: symbolic link to ../vport2p1
```

Si el resultado es diferente (« No such file or directory »), instale y active el software:

```bash
sudo yum install qemu-guest-agent
sudo chkconfig qemu-guest-agent on
```

Reinicie el VPS:

```bash
sudo reboot
```

Verifique el software y compruebe que está en ejecución:

```bash
sudo service qemu-guest-agent status
```

##### **Windows**

Puede instalar el software mediante un archivo MSI disponible en el sitio web del proyecto Fedora: [https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/latest-qemu-ga/](https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/latest-qemu-ga/)

Compruebe que el servicio está en ejecución con el siguiente comando *PowerShell*:

```powershell
PS C:\Users\Administrator> Get-Service QEMU-GA

Status   Name               DisplayName
------   ----               -----------
Running  QEMU-GA            QEMU Guest Agent
```
