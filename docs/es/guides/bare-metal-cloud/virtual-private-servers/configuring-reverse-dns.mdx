## Objetivo

El registro inverso (*rDNS*) es el complemento de la resolución DNS "*forward*" que permite resolver los nombres de dominio en direcciones IP. Con el registro DNS inverso, una dirección IP puede resolverse en el nombre de dominio (o nombre de host) al que está conectada. Esto significa que las consultas DNS de la dirección IP asociada devolverán este nombre de dominio.

La configuración del registro DNS inverso de un servidor es especialmente útil cuando se envían mensajes de correo. La validación de un servidor de correo por los sistemas de protección antispam mejora si una petición DNS de la dirección IP se resuelve correctamente.

**Esta guía explica cómo configurar el registro DNS inverso de su dirección IP desde la consola de OVHcloud.**

## Requisitos

- Una dirección IP asociada a un servicio de su cuenta de OVHcloud
- Un dominio con su registro `A` o `AAAA` asociado a su servicio

## Procedimiento

En la página **Direcciones IP**, puede acotar la lista con los filtros rápidos situados encima de la tabla (**IPv4**, **IPv6**, **IP adicional**, **BYOIP**). También puede buscar una dirección IP específica en el campo **Buscar**.

<img className="thumbnail" alt="Página Direcciones IP de la consola de OVHcloud con el campo Buscar" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/ip-list-search.png" loading="lazy" />

Haga clic en la dirección IP correspondiente para abrir su página y, a continuación, haga clic en la pestaña <code className="action">Reverse DNS</code>. Haga clic en el botón <code className="action">Configurar</code> situado encima de la tabla.

<img className="thumbnail" alt="Pestaña Reverse DNS de una dirección IP en la consola de OVHcloud con el botón Configurar" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-tab.png" loading="lazy" />

En la ventana **Configurar el Reverse DNS**, introduzca el registro inverso en el campo **Nombre de host reverse DNS** y haga clic en <code className="action">Configurar</code>.

<img className="thumbnail" alt="Ventana Configurar el Reverse DNS de la consola de OVHcloud con el campo Nombre de host reverse DNS" src="/images/bare-metal-cloud/virtual-private-servers/configuring-reverse-dns/console/reverse-dns-configure.png" loading="lazy" />

Para modificar un registro inverso existente, siga los mismos pasos: si la dirección IP ya tiene un registro inverso, el campo **Nombre de host reverse DNS** se abre rellenado con este. Sustitúyalo por el nuevo valor y haga clic en <code className="action">Configurar</code>.

:::warning
Al introducir su dominio en el registro inverso, comprueba de inmediato si el registro `A` / `AAAA` devuelve la misma IP. Se utiliza en los procedimientos antispam, por lo que el registro DNS debe ser válido y propagado. Existen algunas reglas a seguir al introducir el registro inverso:

 - El *reverse* no puede comenzar con un `-`
 - El *reverse* no puede contener más de 63 caracteres
 - El *reverse* no puede contener caracteres mayúsculos
 - El *reverse* puede terminar con un `.`: la consola de OVHcloud acepta tanto `domain.tld` como `domain.tld.`.

:::


:::info
Si el cambio no funciona según lo previsto, compruebe que el registro `A` / `AAAA` esté correctamente configurado en la zona DNS del dominio. La aplicación de los cambios en la zona DNS puede tardar hasta 24 horas en caso de que acabe de modificar el registro.

Si el nombre de dominio está gestionado por OVHcloud como registrador **y utiliza los servidores DNS de OVHcloud**, puede consultar [esta guía](/guides/web-cloud/domains/dns-zone-edit).

:::
