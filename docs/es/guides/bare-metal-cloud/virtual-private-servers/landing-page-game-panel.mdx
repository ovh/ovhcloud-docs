Bienvenido a la documentación dedicada al [Game Panel de OVHcloud](/links/bare-metal/game-hub). El Game Panel le permite desplegar y gestionar servidores de juego para una amplia gama de títulos populares directamente desde su VPS o servidor dedicado de OVHcloud. Aquí encontrará todas las guías disponibles para instalar, configurar y administrar sus servidores de juego.

## ¿Qué es el Game Panel?

El Game Panel de OVHcloud es una interfaz simplificada para desplegar y gestionar servidores de juego en su VPS o servidor dedicado. Gracias al despliegue automatizado y a las herramientas integradas, puede iniciar instancias, personalizar las configuraciones y supervisar el rendimiento, sin tener que gestionar manualmente la infraestructura subyacente.

Con el Game Panel, puede:

- Desplegar servidores de juego para más de 140 títulos (Minecraft, ARK, Counter-Strike 2, Rust y muchos más)
- Ejecutar varios servidores de juego en un único VPS o servidor dedicado
- Gestionar los archivos del servidor, las copias de seguridad y las tareas programadas
- Controlar el acceso con permisos por usuario y por servidor
- Supervisar el uso de CPU, RAM, disco y red en tiempo real
