## Objetivo

El Game Panel le permite desplegar un servidor DayZ en unos pocos pasos. El Game Panel gestiona la instalación automáticamente, incluidas la autenticación de Steam y la configuración de los puertos de red.

**Esta guía le explica cómo desplegar un servidor DayZ en el Game Panel y conectarse a él.**

## Requisitos

- Un [VPS](/links/bare-metal/vps) o un [servidor dedicado](/links/bare-metal/bare-metal) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Acceso al Game Panel. Consulte la guía [Conectarse al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
- Una cuenta de Steam para autenticar la instalación del servidor DayZ.

## Procedimiento

### Paso 1 — Acceder al Game Panel

Conéctese a su Game Panel.

En el menú de la izquierda, diríjase a la sección <code className="action">Game Servers</code> y haga clic en <code className="action">Add Game Server</code>.

<img className="thumbnail" alt="Sección Game Servers con el botón Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/add-game-server.png" loading="lazy" />

### Paso 2 — Crear un servidor de DayZ

Seleccione **DayZ** en la lista de juegos. Se abre una ventana de configuración.

### Paso 3 — Configurar el servidor de DayZ

En la ventana de configuración:

- Introduzca un **Server Name**.
- Introduzca su **Steam Username** y su **Steam Password**.

:::warning
Se recomienda encarecidamente utilizar una cuenta de Steam dedicada a este uso, y no su cuenta personal. Utilice una contraseña compleja y desactive la autenticación de dos factores por correo electrónico (Steam Guard) en esta cuenta antes de continuar.
:::

<img className="thumbnail" alt="Formulario de instalación de DayZ con el nombre del servidor y los campos de credenciales de Steam" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/install-dayz-form.png" loading="lazy" />

:::info
Los puertos de red necesarios se configuran automáticamente durante la instalación. Si se trata de su primer servidor DayZ en el Game Panel y los puertos por defecto están disponibles, no es necesaria ninguna modificación manual.
:::

Puede desplegar <code className="action">Advanced settings</code> para ajustar opciones como la asignación de puertos (ports binding) y los límites de recursos. Los valores predeterminados son adecuados para la mayoría de los servidores de juego.

### Paso 4 — Iniciar la instalación

Haga clic en <code className="action">Install</code>. El despliegue se inicia automáticamente. El Game Panel va a:

1. Descargar la imagen del servidor DayZ.
2. Instalar los archivos del servidor.

### Paso 5 — Supervisar la instalación

Haga clic en <code className="action">Log/Console</code> para seguir el progreso de la instalación en tiempo real. El estado del servidor muestra **Installing** mientras se despliegan los archivos.

### Paso 6 — Comprobar que el servidor está en ejecución

Una vez arrancado, compruebe que el estado del servidor es **Running**. Una actividad de CPU y RAM debe ser visible en el Game Panel.

Los siguientes controles están disponibles:

- <code className="action">Log/Console</code>: siga el arranque y la actividad del servidor en tiempo real, y consulte los logs en caso de problema.
- <code className="action">Settings</code>: acceda a las opciones de configuración del juego.

<img className="thumbnail" alt="Servidor DayZ con el estado Running y los controles de gestión" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/server-running.png" loading="lazy" />

Para ajustar las opciones accesibles desde el Game Panel, como las actualizaciones automáticas, haga clic en <code className="action">Settings</code> en su servidor y, a continuación, abra <code className="action">Game Config</code>. Para una configuración avanzada, utilice el [File Manager](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/) para modificar directamente el archivo de configuración del servidor DayZ.

<img className="thumbnail" alt="Panel Server Settings con las opciones Game Config y File Manager" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/game-config.png" loading="lazy" />

### Paso 7 — Confirmar que la instalación ha finalizado

El estado pasa a **Running** una vez finalizada la instalación. Su servidor DayZ está ahora listo para aceptar conexiones.

### Paso 8 — Obtener la información de conexión

En la columna **Connection** de la lista Game Servers, copie la dirección IP y el puerto de su servidor.

<img className="thumbnail" alt="Lista Game Servers con la dirección IP de conexión y el puerto destacados" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-dayz/connection-details.png" loading="lazy" />

### Paso 9 — Unirse a su servidor en DayZ

Para unirse desde el cliente DayZ:

1. Inicie **DayZ**.
2. Vaya a **Server** y haga clic en **Direct connect**.
3. Pegue la dirección IP y el puerto indicados en la columna **Connection**.
4. Haga clic en **Connect**.
