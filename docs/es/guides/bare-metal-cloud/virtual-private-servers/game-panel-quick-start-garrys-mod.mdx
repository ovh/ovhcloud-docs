## Objetivo

El Game Panel le permite desplegar un servidor Garry's Mod con una instalación y una configuración de los puertos automatizadas.

**Esta guía explica cómo desplegar un servidor Garry's Mod en el Game Panel y conectarse a él.**

## Requisitos

- Un [VPS](https://www.ovhcloud.com/es-es/vps/) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Acceso al Game Panel. Consulte la guía [Conectarse al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedimiento

### Paso 1 - Acceder al Game Panel

Conéctese a su Game Panel. Diríjase a la sección <code className="action">Game Servers</code> del menú de la izquierda.

<img className="thumbnail" alt="Sección Game Servers con el botón Add Game Server" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/game-servers-list.png" loading="lazy" />

### Paso 2 - Crear un servidor Garry's Mod

Haga clic en <code className="action">Add Game Server</code> y seleccione **Garrys Mod** en la lista.

<img className="thumbnail" alt="Selección de Garry's Mod en la lista de juegos" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/select-garrys-mod.png" loading="lazy" />

Configure la instalación:

- <code className="action">Server Name</code>: asigne un nombre a su servidor (por ejemplo, `Garrys Mod Server`).
- <code className="action">Network Ports</code>: deje los puertos por defecto o añada otros si es necesario en la sección avanzada. Garry's Mod utiliza generalmente puertos cercanos a `27015`.

### Paso 3 - Iniciar la instalación

Haga clic en <code className="action">Select</code>. El despliegue se inicia automáticamente. Espere unos minutos mientras se descarga la imagen y se instala el servidor.

Haga clic en <code className="action">Launch</code> para iniciar el servidor.

### Paso 4 - Comprobar que el servidor funciona

Compruebe que el estado del servidor muestra **Running** y que se observa actividad de CPU/RAM.

<img className="thumbnail" alt="Servidor Garry's Mod con el estado Running" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-running.png" loading="lazy" />

Acciones disponibles:

- <code className="action">Log/Console</code>: abra la consola para seguir el arranque y consulte los logs en caso de problema.
- <code className="action">Settings</code> > <code className="action">Game Config</code>: acceda a los ajustes del juego (mapa de inicio, tickrate, gamemode, límite de jugadores, contraseña RCON, colección Workshop, GSLT).

<img className="thumbnail" alt="Ajustes Game Config de Garry's Mod" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-garrys-mod/garrys-mod-game-config.png" loading="lazy" />

### Paso 5 - Conectarse al servidor

En la columna <code className="action">Connection</code>, encontrará la dirección IP y el puerto (por ejemplo, `xxx.xxx.xxx.xxx:27015`).

En Garry's Mod:

1. Abra la consola (`~`).
2. Introduzca:

    ```console
    connect IP:PORT
    ```

:::info
Para ir más allá, añada mods o colecciones Workshop, ajuste el tickrate y los parámetros de rendimiento, o restrinja el acceso con una contraseña o una whitelist.
:::
