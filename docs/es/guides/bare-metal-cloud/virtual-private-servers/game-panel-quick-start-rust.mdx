## Objetivo

El Game Panel de OVHcloud le permite desplegar un servidor Rust con una instalación y una configuración de los puertos automatizadas.

**Esta guía explica cómo desplegar un servidor Rust en el Game Panel de OVHcloud y conectarse a él.**

## Requisitos

- Un [VPS](/links/bare-metal/vps) o un [servidor dedicado](/links/bare-metal/bare-metal) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Acceso al Game Panel. Consulte la guía [Conectarse al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

## Procedimiento

### Paso 1 — Acceder al Game Panel

Conéctese a su Game Panel de OVHcloud. En el menú de la izquierda, vaya a la sección `Game Servers` y haga clic en <code className="action">Add Game Server</code>.

### Paso 2 — Crear un servidor de Rust

Seleccione **Rust** en la lista de juegos. Puede utilizar el campo de búsqueda situado en la parte superior de la ventana para encontrarlo más rápidamente. Se abrirá una ventana de configuración.

<img className="thumbnail" alt="Selección de Rust en la lista de juegos del Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/select-rust.png" loading="lazy" />

### Paso 3 — Configurar el servidor de Rust

En esta sección puede definir un nombre para su servidor en el campo **Server Name**.

También se genera automáticamente una **RCON Password**. El sistema RCON del juego la utiliza para administrar el servidor de forma remota. Haga clic en <code className="action">Regenerate</code> para obtener una nueva o sustitúyala por una contraseña de su elección (8 caracteres como mínimo). Podrá modificarla de nuevo una vez instalado el servidor.

:::warning
Conserve esta contraseña en un lugar seguro. Cualquier persona que la conozca podrá ejecutar comandos de administración en su servidor.
:::

Puede desplegar <code className="action">Advanced Settings</code> para ajustar opciones como la asignación de puertos (ports binding), los volúmenes, las variables de entorno y los límites de recursos. Los valores por defecto son adecuados para la mayoría de los servidores de juego.

<img className="thumbnail" alt="Formulario de configuración del servidor Rust con el nombre del servidor y los ajustes avanzados" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/configure-server.png" loading="lazy" />

:::info
Si se trata de su primer servidor Rust en el Game Panel y los puertos por defecto están disponibles, todos los puertos necesarios se configurarán automáticamente. No es necesaria ninguna configuración manual. La imagen de Rust utiliza tres puertos: `28015/UDP` (Game), `28017/UDP` (Steam Query) y `28082/TCP` (Rust+ companion app). Si estos puertos ya están ocupados por otro servidor de juego, el Game Panel asigna puertos de host libres en su lugar.
:::

### Paso 4 — Iniciar la instalación

Haga clic en <code className="action">Install</code> para iniciar la instalación. El despliegue comenzará y una ventana de progreso mostrará las siguientes etapas:

1. Descarga de la imagen del contenedor.
2. Preparación de los archivos del servidor.
3. Creación del contenedor.
4. Arranque del contenedor.

### Paso 5 — Supervisar la instalación

Una vez arrancado el contenedor, se mostrará una ventana de confirmación. Haga clic en <code className="action">Open Logs / Console</code> para seguir el progreso de la instalación en tiempo real. También puede abrirla en cualquier momento con el botón <code className="action">Log/Console</code> de su servidor.

<img className="thumbnail" alt="Ventana de confirmación con el botón Open Logs / Console" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/installation-started.png" loading="lazy" />

La consola muestra las etapas de la instalación y, a continuación, la descarga de los archivos del servidor Rust mediante SteamCMD, con un porcentaje de progreso.

<img className="thumbnail" alt="Logs de instalación del servidor Rust en la consola del Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/installation-logs.png" loading="lazy" />

:::warning
Los archivos del servidor Rust representan una descarga de varios gigabytes. El servidor mantiene el estado **Installing** durante toda la descarga y, a continuación, mientras se genera el mundo de juego. Consulte la consola para seguir el progreso real.
:::

### Paso 6 — Comprobar que el servidor está en ejecución

Compruebe que el estado del servidor es **Running** y que se observa actividad de CPU y RAM. Puede utilizar los controles <code className="action">Log/Console</code> y <code className="action">Settings</code> para gestionar el servidor, así como los controles <code className="action">Stop</code> y <code className="action">Restart</code> para modificar su estado de encendido.

<img className="thumbnail" alt="Servidor Rust con el estado Running y actividad de CPU y RAM" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-rust/server-running.png" loading="lazy" />

### Paso 7 — Confirmar que la instalación ha finalizado

Una vez finalizada la descarga, la consola muestra el arranque del servidor Rust y, a continuación, la generación del mundo de juego (mapa de alturas, biomas, monumentos). Este paso puede tardar varios minutos.

El estado puede mostrar brevemente **Unhealthy** mientras el servidor termina de arrancar y todavía no responde a la comprobación de estado. Este comportamiento es normal en una primera instalación.

El estado del servidor cambia a **Running** una vez generado el mundo y cuando el servidor está a la escucha. Su servidor Rust ya está listo para aceptar conexiones.

### Paso 8 — Obtener la información de conexión

Una vez arrancado su servidor, copie la dirección IP y el puerto de la columna **Connection** de la lista de servidores de juego. Utilice el botón de copia para copiarlos al portapapeles.

### Paso 9 — Unirse a su servidor en Rust

Para unirse a su servidor desde el cliente de Rust:

1. Inicie **Rust**.
2. Pulse la tecla `F1` para abrir la consola del juego.
3. Introduzca el siguiente comando, sustituyendo `IP` y `PORT` por los valores de la columna **Connection**:

```console
client.connect IP:PORT
```

### Configurar los parámetros del juego

La sección <code className="action">Game Config</code> le permite ajustar los principales parámetros de su servidor Rust sin editar manualmente los archivos de configuración:

| Parámetro | Descripción |
|-----------|-------------|
| `Server name` | El nombre que se muestra en el navegador de servidores del juego. |
| `Gamemode` | `vanilla`, `Softcore`, `Hardcore` o `Primitive`. |
| `Map type` | `Procedural Map`, `Barren`, `Hapis Island` o `Savas Island`. |
| `Map seed` | La semilla utilizada para generar un mapa procedural. |
| `Map size` | El tamaño del mapa generado. |
| `Player limit` | El número máximo de jugadores simultáneos. |
| `Save interval` | El intervalo entre dos guardados del mundo de juego. |
| `Tick rate` | La frecuencia de actualización del servidor. |

Otras opciones, como la descripción del servidor, el modo PvE o el daño por caída, están disponibles en el archivo de configuración `server.cfg`, en la misma sección.

Para una configuración avanzada, utilice el [File Manager](/guides/bare-metal-cloud/virtual-private-servers/game-panel-file-manager/) para editar directamente los archivos de configuración de Rust.
