## VPS de OVHcloud

Un [VPS de OVHcloud](/links/bare-metal/vps) (Virtual Private Server) es una máquina virtual con acceso root completo, alojada en la infraestructura de OVHcloud: el punto intermedio entre un alojamiento web gestionado y un servidor dedicado. Es el primer servidor ideal para alojar sus propios servicios web y aplicaciones.

Con un VPS de OVHcloud puede:

- Alojar sitios y aplicaciones web
- Ejecutar aplicaciones autoalojadas (Docker, Nextcloud, n8n, agentes de IA...)
- Alojar servidores de juego con el Game Panel
- Escalar sus recursos al ritmo de su proyecto
- Proteger sus datos con snapshots y backups automatizados
