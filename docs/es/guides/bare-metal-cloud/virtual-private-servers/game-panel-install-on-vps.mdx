## Objetivo

El Game Panel de OVHcloud le permite desplegar y gestionar servidores de juego directamente en su VPS. Antes de utilizarlo, debe instalarlo en su servidor desde el área de cliente de OVHcloud.

**Esta guía le explica cómo instalar el Game Panel en su VPS.**

## Requisitos

- Un [VPS](/links/bare-metal/vps) en su cuenta de OVHcloud.
- Acceso al <ManagerLink to="/">área de cliente de OVHcloud</ManagerLink>.

## Procedimiento

### Paso 1 — Conectarse al área de cliente de OVHcloud

Conéctese a su <ManagerLink to="/">área de cliente de OVHcloud</ManagerLink>. Si necesita ayuda para conectarse, consulte la guía [Conectarse al área de cliente de OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-login/).

### Paso 2 — Cambiar a la versión Beta del área de cliente de OVHcloud

La funcionalidad de instalación del Game Panel está disponible actualmente en la versión Beta del área de cliente de OVHcloud.

En la esquina superior derecha de la página, haga clic en <code className="action">Discover our new Manager in Beta</code> para cambiar a la interfaz Beta.

### Paso 3 — Abrir la página de su VPS

Desde el área de cliente de OVHcloud:

1. Haga clic en <code className="action">Bare Metal Cloud</code>.
2. En el menú de la derecha, seleccione <code className="action">Servidores privados virtuales</code>.

### Paso 4 — Instalar el Game Panel

En la página **Dashboard**, localice la sección **Your VPS** y haga clic en <code className="action">Game Panel</code>.

<img className="thumbnail" alt="La entrada Game Panel en la sección Your VPS del dashboard del VPS" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/game-panel-entry.png" loading="lazy" />

Se abre el formulario de instalación del Game Panel. Rellene los siguientes campos y, a continuación, inicie la instalación.

<img className="thumbnail" alt="El formulario de instalación del Game Panel" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-install-on-vps/install-form.png" loading="lazy" />

**Elegir un sistema operativo**

Seleccione el sistema operativo en el que desea instalar el Game Panel. Todos los sistemas operativos que aparecen en la lista son totalmente compatibles con el Game Panel.

**Configurar el nombre de dominio**

De forma predeterminada, el Game Panel se instala utilizando el nombre de host predeterminado de su servidor, lo que le permite acceder a él mediante una dirección similar a `https://vps-xxxx.vps.ovh.net`.

Si lo prefiere, puede utilizar su propio nombre de dominio. Antes de continuar, asegúrese de que su dominio apunta a la dirección IP pública de su VPS.

Si todavía no dispone de un nombre de dominio o necesita configurar sus registros DNS, consulte los siguientes recursos:

- [Los nombres de dominio de OVHcloud](/links/web/domains)
- [Editar una zona DNS de OVHcloud](/guides/web-cloud/domains/dns-zone-edit/)

**Introducir una dirección de correo electrónico**

Se le solicita una dirección de correo electrónico. De forma predeterminada, es la dirección de correo electrónico asociada a su cuenta de OVHcloud. Se utiliza durante la configuración del certificado SSL y también puede recibir notificaciones puntuales relativas al certificado en caso de que alguna vez sea necesaria una acción.

**Elegir el nombre de la cuenta de administrador**

Introduzca el nombre de usuario de la cuenta de administrador que se creará. Esta cuenta se convierte en el superadministrador del Game Panel y dispone del nivel de privilegios más alto.

**Guardar la contraseña de administrador generada**

Se genera y se muestra una contraseña para el Game Panel. Guarde esta contraseña en un lugar seguro, ya que no podrá volver a consultarse posteriormente.

**(Opcional) Añadir una clave SSH**

Si lo desea, puede añadir una clave SSH pública. Se trata de una configuración avanzada opcional.

**Iniciar la instalación**

Haga clic en <code className="action">Install Game Panel</code> para iniciar la instalación.

### Paso 5 — Conectarse al Game Panel

El sistema operativo seleccionado se instala en primer lugar. Una vez desplegado, recibirá un correo electrónico automático con la contraseña SSH de su servidor. Guarde esta contraseña en un lugar seguro, ya que podría necesitarla más adelante si se conecta directamente al servidor por SSH.

Unos minutos más tarde, la instalación del Game Panel finaliza automáticamente.

A continuación, puede abrir el nombre de host de su servidor en un navegador web, por ejemplo `https://vps-xxxx.vps.ovh.net`. Conéctese con la contraseña generada durante la instalación para empezar a utilizar el Game Panel.

:::info
La contraseña de administrador generada solo se muestra una vez durante la instalación. Si la pierde, consulte la sección de recuperación de contraseña de la guía [Conectarse al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).
:::
