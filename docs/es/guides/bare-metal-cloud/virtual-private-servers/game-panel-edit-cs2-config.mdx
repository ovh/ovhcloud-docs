## Objetivo

El Game Panel expone la configuración del servidor Counter-Strike 2 directamente en su interfaz. Las opciones básicas, como el nombre del servidor, el mapa y el modo de juego, son accesibles a través de un formulario gráfico, y también puede instalar frameworks de servidor como MetaMod y CounterStrikeSharp.

**Esta guía explica cómo modificar la configuración de un servidor Counter-Strike 2 en el Game Panel.**

## Requisitos

- Un [VPS](/links/bare-metal/vps) o un [servidor dedicado](/links/bare-metal/bare-metal) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Un servidor Counter-Strike 2 desplegado en el Game Panel. Consulte la guía [Desplegar un servidor Counter-Strike 2 en el Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-cs2/).

## Procedimiento

### Paso 1 — Abrir los parámetros del servidor

Desde la página principal del Game Panel, localice el servidor Counter-Strike 2 que desea configurar. En la columna <code className="action">Management</code>, haga clic en <code className="action">Settings</code>.

<img className="thumbnail" alt="Servidor Counter-Strike 2 con el botón Settings resaltado" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-server-settings.png" loading="lazy" />

### Paso 2 — Abrir la pestaña Game Config

En el panel **Server Settings**, seleccione <code className="action">Game Config</code> en la barra lateral izquierda.

La sección **Game Config** le permite gestionar los principales parámetros de su servidor Counter-Strike 2 mediante dos pestañas:

- **Settings**: configure los parámetros del servidor de juego.
- **Frameworks**: instale y gestione los frameworks de servidor compatibles.

### Paso 3 — Configurar la pestaña Settings

La pestaña <code className="action">Settings</code> le permite modificar los principales parámetros del servidor Counter-Strike 2:

| Parámetro | Descripción |
|---------|-------------|
| Server Name | El nombre que se muestra en el explorador de servidores de Counter-Strike 2. |
| Max Players | El número máximo de jugadores que pueden conectarse simultáneamente. |
| Map | El mapa que se carga al iniciar el servidor. También puede introducir manualmente el nombre de un mapa que no figure en la lista. |
| Game Type | Define la categoría principal de juego. |
| Game Mode | Define el modo de juego dentro del tipo de juego seleccionado. Para obtener más información sobre los modos disponibles, consulte la [guía de la Valve Developer Community](https://developer.valvesoftware.com/wiki/Counter-Strike:_Global_Offensive/Game_Modes). |
| Server Password | Exige que los jugadores introduzcan una contraseña antes de unirse al servidor. |
| Admin Password (RCON) | Activa el acceso por consola remota (RCON) y define la contraseña utilizada para administrar el servidor de forma remota. |
| Steam GSL Token | Un Game Server Login Token (GSLT) utilizado para autenticar su servidor dedicado con los servicios de Steam. Para generar un token, consulte la [página de gestión de cuentas de servidores de juego de Steam](https://steamcommunity.com/dev/managegameservers). |
| VAC Anti-Cheat | Activa o desactiva la protección Valve Anti-Cheat (VAC) en el servidor. |

<img className="thumbnail" alt="La pestaña Settings de la sección Game Config de Counter-Strike 2" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-settings.png" loading="lazy" />

:::info
Después de modificar cualquiera de estos parámetros, guarde sus cambios y reinicie el servidor para que surtan efecto.
:::


### Paso 4 — Instalar frameworks

La pestaña <code className="action">Frameworks</code> le permite instalar componentes adicionales para ampliar las funcionalidades de su servidor Counter-Strike 2.

- **MetaMod**: un framework de plugins de servidor que actúa como capa intermedia entre el servidor de juego y los plugins. Proporciona la base necesaria para muchas extensiones de servidor avanzadas y herramientas de administración.
- **CounterStrikeSharp**: un framework de plugins moderno para Counter-Strike 2 que permite a los administradores y desarrolladores crear y ejecutar plugins personalizados utilizando C#. Puede añadir funcionalidades de juego, herramientas de gestión del servidor y extensiones desarrolladas por la comunidad.

Puede instalar cualquiera de los dos frameworks directamente desde el Game Panel y reinstalarlos posteriormente para actualizarlos a una versión más reciente cuando esté disponible.

<img className="thumbnail" alt="La pestaña Frameworks mostrando MetaMod y CounterStrikeSharp" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-edit-cs2-config/cs2-game-config-frameworks.png" loading="lazy" />

:::info
El servidor debe estar detenido antes de instalar un framework.
:::


### Paso 5 — Guardar y reiniciar

Después de guardar sus cambios, reinicie el servidor Counter-Strike 2 desde el Game Panel para que la nueva configuración surta efecto.
