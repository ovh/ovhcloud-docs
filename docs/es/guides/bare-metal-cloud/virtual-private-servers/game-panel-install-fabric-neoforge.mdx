## Objetivo

Fabric y NeoForge son cargadores de mods para servidores de Minecraft. Instalar uno de ellos en un servidor de Minecraft alojado en el Game Panel le permite disfrutar de una experiencia modeada con funcionalidades ampliadas.

**Esta guía le explica cómo instalar Fabric o NeoForge en un servidor de Minecraft en el Game Panel y añadir mods.**

## Requisitos

- Un [VPS](https://www.ovhcloud.com/es-es/vps/) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Un servidor de Minecraft desplegado en el Game Panel. Consulte la guía [Desplegar un servidor de Minecraft en el Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-quick-start-minecraft/).

## Procedimiento

### Paso 1 - Desactivar las actualizaciones automáticas

Para evitar conflictos con los cargadores de mods, desactive las actualizaciones automáticas antes de realizar cualquier modificación:

1. Acceda a los <code className="action">Settings</code> de su servidor.
2. Abra la pestaña <code className="action">Game Config</code>.
3. Desactive las actualizaciones automáticas.

### Paso 2 - Detener el servidor

Desde el Game Panel, detenga su servidor de Minecraft antes de realizar cualquier modificación adicional.

### Paso 3 - Descargar e importar el instalador

Descargue el instalador correspondiente al cargador de mods elegido:

- **Fabric**: [https://fabricmc.net/use/server/](https://fabricmc.net/use/server/)
- **NeoForge**: [https://neoforged.net/](https://neoforged.net/)

Una vez descargado, abra los <code className="action">Settings</code> de su servidor, vaya a la pestaña <code className="action">File Manager</code> e importe el archivo `.jar` en el directorio `serverfiles` mediante <code className="action">Upload files</code> o arrastrando y soltando.

### Paso 4 - Ejecutar el instalador

Abra la pestaña <code className="action">Terminal</code> desde los <code className="action">Settings</code> de su servidor y ejecute el comando correspondiente a su cargador de mods.

Para **Fabric**:

```bash
java -jar fabric-installer-X.X.X.jar server --downloadMinecraft
```

Este comando descarga los archivos del servidor de Minecraft, instala el cargador Fabric y genera el archivo de lanzamiento del servidor Fabric.

Para **NeoForge**:

```bash
java -jar neoforge-X.X.X-installer.jar --installServer
```

Este comando instala NeoForge, descarga los archivos del servidor de Minecraft y genera los archivos de lanzamiento del servidor.

### Paso 5 - Configurar LinuxGSM

Indique a LinuxGSM qué ejecutable utilizar, en función de su cargador de mods.

Para **Fabric**:

```bash
printf '\nexecutable="./fabric-server-launch.jar"\n' >> /data/config-lgsm/mcserver/common.cfg
```

Para **NeoForge**:

```bash
printf '\npreexecutable=""\nexecutable="./run.sh"\nstartparameters="nogui"\n' >> /data/config-lgsm/mcserver/common.cfg
```

:::warning
Cuando utilice NeoForge con `run.sh`, el parámetro **Max RAM** del Game Config ya no se aplica. En su lugar, modifique el archivo `/data/serverfiles/user_jvm_args.txt`. Ejemplo:

```
-Xms2G
-Xmx4G
```
:::


### Paso 6 - Iniciar el servidor

Defina los permisos correctos antes de iniciar el servidor:

```bash
sudo chown -R linuxgsm:linuxgsm /data/serverfiles
```

A continuación, inicie el servidor desde el Game Panel y consulte los logs del servidor para confirmar que arranca correctamente.

### Paso 7 - Añadir mods

Para instalar mods en su servidor modeado:

1. Descargue mods compatibles con Fabric o NeoForge.
2. Abra la pestaña <code className="action">File Manager</code> desde los <code className="action">Settings</code> de su servidor.
3. Importe los archivos `.jar` de los mods en `serverfiles/mods`.
4. Restablezca los permisos:

    ```bash
    sudo chown -R linuxgsm:linuxgsm /data/serverfiles
    ```

5. Reinicie el servidor. Consulte los logs para confirmar que los mods se cargan.
