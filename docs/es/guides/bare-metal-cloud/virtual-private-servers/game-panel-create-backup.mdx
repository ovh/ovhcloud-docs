## Objetivo

El Game Panel de OVHcloud le permite realizar copias de seguridad de sus instancias de servidores de juego para restaurarlas a un estado anterior si es necesario.

**Esta guía explica cómo crear una copia de seguridad de su servidor de juego en el Game Panel de OVHcloud.**

## Requisitos

- Un [VPS](https://www.ovhcloud.com/es-es/vps/) en su cuenta de OVHcloud con la funcionalidad Game Panel activada.
- Una instancia de servidor de juego desplegada en el Game Panel. Consulte la guía [Primeros pasos con el Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-getting-started/).

## Procedimiento

### Paso 1 - Conectarse al Game Panel

Conéctese a su Game Panel. Si necesita ayuda, consulte la guía [Conectarse al Game Panel](/guides/bare-metal-cloud/virtual-private-servers/game-panel-log-in/).

### Paso 2 - Acceder a los parámetros de copia de seguridad

Una vez conectado:

1. Seleccione su servidor de juego.
2. Haga clic en <code className="action">Settings</code>.
3. Diríjase a la pestaña <code className="action">Backups</code>.

<img className="thumbnail" alt="La pestaña de parámetros de copia de seguridad" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/backup-tab.png" loading="lazy" />

### Paso 3 - Crear una copia de seguridad

Haga clic en <code className="action">Create backup now</code>.

<img className="thumbnail" alt="Creación de una copia de seguridad con la opción de detener el servidor" src="/images/bare-metal-cloud/virtual-private-servers/game-panel-create-backup/create-backup.png" loading="lazy" />

Una vez finalizada la copia de seguridad, el archivo estará disponible para su descarga en la lista **Available Backups**, más abajo en la misma pestaña.

### Paso 4 - Definir una política de retención

En **Retention Policy**, puede controlar el número de copias de seguridad conservadas y su duración de conservación:

- **Keep the last backups**: el número máximo de copias de seguridad que se conservarán (indique `0` para conservarlas todas).
- **Keep backups for days**: la duración de conservación de las copias de seguridad (indique `0` para conservarlas indefinidamente).
- **Stop server before backup**: detiene el servidor durante la ejecución de la copia de seguridad, para obtener copias de seguridad coherentes.

:::info
Le recomendamos que mantenga activada la opción **Stop server before backup** para garantizar la coherencia de las copias de seguridad.
:::

Haga clic en <code className="action">Save retention settings</code> para aplicar sus cambios.
