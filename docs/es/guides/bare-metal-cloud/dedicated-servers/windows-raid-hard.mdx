## Requisitos

:::warning
Las operaciones descritas en esta guía requieren eliminar el RAID existente. Esto significa que se perderán todos los datos almacenados. Asegúrese de realizar previamente una copia de seguridad de sus datos.
Esta guía está dirigida a usuarios experimentados.
:::


Para crear el particionamiento, será necesario crear nuevos volúmenes RAID en la tarjeta. Para ello, necesitará:

- Disponer de un servidor con RAID de hardware (tarjeta LSI MegaRaid).
- Disponer de al menos dos discos idénticos (en esta guía utilizamos un servidor con 3 discos).
- Tener acceso al modo de rescate.

## Procedimiento

### Listar los volúmenes RAID
En primer lugar, necesitamos listar los volúmenes RAID para poder eliminarlos a continuación.

Para ello, utilizamos el siguiente comando: <code className="action">MegaCli -LDInfo -Lall -aAll</code>

Ejemplo:

```sh
# root@rescue:~# MegaCli -LDInfo -Lall -aAll
 
Adapter 0 -- Virtual Drive Information:
Virtual Drive: 0 (Target Id: 0)

Name                 :
RAID Level           : Primary-5, Secondary-0, RAID Level Qualifier-3
Size                 : 3.637 TB
Sector Size          : 512
Is VD emulated       : No
Parity Size          : 1.818 TB
State                : Optimal
Strip Size           : 256 KB
Number Of Drives     : 3
Span Depth           : 1
Default Cache Policy : WriteBack, ReadAhead, Direct, No Write Cache if Bad BBU
Current Cache Policy : WriteBack, ReadAhead, Direct, No Write Cache if Bad BBU

Exit Code: 0x00
```
Comprobamos que actualmente solo tenemos un volumen RAID en el servidor y que este tiene el **Virtual Drive** 0.

### Eliminar los RAID
Ahora podemos eliminar los volúmenes RAID existentes para poder crear después nuestros nuevos volúmenes RAID.

Para ello, utilizaremos el siguiente comando, que deberá adaptar con el número del **Virtual Drive** obtenido anteriormente.

<code className="action">MegaCli -CfgLDDel -Lx -a0</code>

El número del **Virtual Drive**

Ejemplo:

```sh
# root@rescue:~# MegaCli -CfgLDDel -L0 -a0
 
Adapter 0: Deleted Virtual Drive-0(target id-0)
 
Exit Code: 0x00
```

:::info
Si su servidor ya tiene varios RAID, repita la operación con el número de cada Virtual Drive.
:::


### Obtener los ID de los discos
Ahora vamos a obtener el **Enclosure ID** y el **SlotID** de los discos del servidor para crear nuestros nuevos volúmenes RAID.

Para ello, utilizaremos el siguiente comando: <code className="action">MegaCli -PdList -aALL | egrep -i "Adapter|Slot|Enclosure Device"</code>

Ejemplo:

```sh
# root@rescue:~# MegaCli -PdList -aALL | egrep -i "Adapter|Slot|Enclosure Device"
Adapter #0
Enclosure Device ID: 252
Slot Number: 0
Enclosure Device ID: 252
Slot Number: 1
Enclosure Device ID: 252
Slot Number: 2
```
Comprobamos que tenemos 3 discos, cuyos **Enclosure ID** y **SlotID** son, respectivamente, 252:0, 252:1 y 252:2.

### Crear los nuevos volúmenes RAID
En primer lugar, creamos el primer volumen RAID, que servirá para nuestro sistema operativo.

Utilizamos entonces el siguiente comando: <code className="action">MegaCli -CfgLdAdd -rX[EncID:SlotID,EncID:SlotID,...] -szYYYYY -a0</code>

Corresponde al RAID deseado (0, 1, 5 o 6)

Corresponde a los Enclosure ID de los discos obtenidos anteriormente

Corresponde a los SlotID de los discos obtenidos anteriormente

Corresponde al tamaño de nuestro primer disco virtual

En nuestro ejemplo, vamos a crear un RAID 5 en nuestros 3 discos, con un tamaño de 200 GB para nuestro sistema operativo.

:::info
Le recomendamos reservar algo más de espacio para obtener una partición del tamaño mínimo deseado, ya que la configuración necesita algo de espacio.
:::


```sh
# root@rescue:~# MegaCli -CfgLdAdd -r5[252:0,252:1,252:2] -sz204800 -a0
 
Adapter 0: Created VD 0
 
Adapter 0: Configured the Adapter!!
 
Exit Code: 0x00 
```
Ya hemos creado nuestro primer volumen RAID. Ahora solo queda asignar el resto del espacio disponible.

Por lo tanto, vamos a crear un segundo volumen RAID con el siguiente comando: <code className="action">MegaCli -CfgLdAdd -rX[EncID:SlotID,EncID:SlotID,...] -a0</code>

Corresponde al RAID deseado (0, 1, 5 o 6)

Corresponde a los Enclosure ID de los discos obtenidos anteriormente

Corresponde a los SlotID de los discos obtenidos anteriormente

Ejemplo:

```sh
# root@rescue:~# MegaCli -CfgLdAdd -r5[252:0,252:1,252:2] -a0
 
Adapter 0: Created VD 1
 
Adapter 0: Configured the Adapter!!
 
Exit Code: 0x00 
```
Hecho. Solo nos queda comprobar nuestros volúmenes RAID.

### Instalar Windows desde la consola de OVHcloud
Por último, acceda a la consola de OVHcloud para instalar Windows en su servidor.

Deberá marcar la casilla <code className="action">Personalizar configuración de particiones</code> y modificar el esquema de particiones actual para especificar únicamente el disco C, con un tamaño máximo de 200 GB.

Una vez instalado el sistema, acceda a su sistema Windows, abra la utilidad <code className="action">Administración de discos</code> y particione el segundo disco virtual (correspondiente a nuestro segundo RAID, que aparece como "No asignado") en formato GPT.
