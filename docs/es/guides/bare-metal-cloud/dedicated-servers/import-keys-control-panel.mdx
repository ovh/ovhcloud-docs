## Objetivo

Los pares de claves se utilizan para autenticar las conexiones SSH entre los hosts, por ejemplo, entre el cliente local del equipo y un servidor remoto. Al reinstalar un servidor dedicado o un VPS desde la consola de OVHcloud, puede añadir una clave pública al sistema operativo. El almacenamiento de claves SSH públicas en la consola facilita este proceso.

**Esta guía explica cómo almacenar las llaves SSH públicas en la consola de OVHcloud.**

## Requisitos

- Un [servidor dedicado](/links/bare-metal/bare-metal) o un [VPS](/links/bare-metal/vps) en su cuenta de OVHcloud

:::info
Para más información sobre el uso de las llaves SSH con los servicios [Public Cloud](/links/public-cloud/public-cloud), consulte nuestra guía dedicada:

[Cómo crear llaves SSH con OpenSSH para instancias Public Cloud](/guides/public-cloud/compute/creating-ssh-keys)

:::

## Procedimiento

Si aún no ha creado ningún par de llaves SSH, consulte nuestras guías:

- [Crear y utilizar llaves SSH](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys)
- [Tutorial - Cómo utilizar PuTTY para conexiones SSH y autenticación](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows)

<img className="thumbnail" alt="Identity and Access Management group of the Console left menu, with the SSH keys entry" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/sidebar-iam-ssh-keys.png" loading="lazy" />

En el menú de la izquierda de la consola de OVHcloud, abra **Gestión de identidades y accesos** y haga clic en <code className="action">Claves SSH</code>.

<img className="thumbnail" alt="SSH keys page with the Add an SSH key button above the list of keys" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-button.png" loading="lazy" />

Abra el menú <code className="action">Añadir una clave SSH</code> situado encima de la lista y seleccione <code className="action">Dedicado</code>.

<img className="thumbnail" alt="Add an SSH key menu open, showing the Dedicated and Public Cloud options" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-menu.png" loading="lazy" />

En la ventana **Añadir una clave SSH**, copie toda la cadena de la clave pública y péguela en el primer campo, **Clave pública**. Pegue únicamente la clave pública (el contenido de su archivo `.pub`), nunca la clave privada.  
Introduzca un nombre para la clave en el segundo campo, **Nombre**, para poder reconocerla (por ejemplo, el nombre de su ordenador).

<img className="thumbnail" alt="Add an SSH key window with the Public key and Name fields and the Add button" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/console/ssh-keys-add-dedicated-window.png" loading="lazy" />

Haga clic en <code className="action">Añadir</code>.

La llave estará disponible cuando reinstale un servidor dedicado o un VPS en la consola de OVHcloud.
