## Objetivo

El servicio de monitorización le permite a OVHcloud monitorear el estado de su máquina y activar automáticamente la intervención de un técnico en el centro de datos.

Todos los servidores de nuestros clientes y toda la red son monitoreados 24/7 por equipos técnicos de OVHcloud.
OVHcloud interviene tan pronto como se activa una alerta (ninguna respuesta de ping) para minimizar el tiempo de inactividad de los servidores y la red.

Para implementar un firewall restrictivo, especialmente en ICMP, y continuar beneficiándose del monitorización de OVHcloud, es necesario autorizar las IPs que encontrará a continuación.

## Requisitos

- Un producto OVHcloud en el que ha instalado un firewall.
- Tener acceso a las reglas de Firewall.

### Activar o desactivar la monitorización <a name="enable"></a>

Puede activar o desactivar la monitorización de un servidor dedicado desde la pestaña <code className="action">Server</code> de su página. La línea **Monitoring** de la sección **Información del servidor** indica su estado actual: **Disabled**, **Enabled with intervention** o **Enabled without intervention**.

Haga clic en <code className="action">Configure monitoring</code>. En la ventana **Configure monitoring**, puede definir el comportamiento de la monitorización:

- <code className="action">Enable monitoring</code>: desactive este interruptor para detener los mensajes de alerta y las intervenciones de OVHcloud, por ejemplo si realiza en el servidor acciones de administración que impiden una respuesta ICMP.
- **Intervention mode** (se muestra cuando la monitorización está activada):
    - <code className="action">Proactive intervention (OVHcloud will act if an issue is detected)</code>: si el servidor deja de responder, recibirá un mensaje de correo electrónico de alerta y un técnico verificará el servidor.
    - <code className="action">No intervention (monitoring only, no action taken)</code>: recibirá un mensaje de correo electrónico de alerta si el servidor deja de responder. Para iniciar una intervención, debe crear una solicitud de asistencia.

Haga clic en <code className="action">Save</code> para actualizar su configuración de monitorización.
