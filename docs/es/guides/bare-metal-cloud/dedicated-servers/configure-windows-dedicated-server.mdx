## Objetivo

Windows Server es un sistema operativo compatible con los servidores dedicados de OVHcloud. Una vez instalado, debe configurar el sistema Windows para que pueda utilizar los servicios de red y de almacenamiento de OVHcloud asociados al servidor.

Esta guía le acompaña para instalar Windows Server desde el área de cliente de OVHcloud, conectarse al servidor y, a continuación, llevar a cabo la configuración necesaria en Windows para interactuar con los principales servicios de OVHcloud asociados a un servidor dedicado.

**En esta guía aprenderá a:**

- Instalar Windows Server desde el área de cliente
- Conectarse al servidor mediante el Escritorio remoto y llevar a cabo la configuración inicial
- Configurar Windows para utilizar una Additional IP
- Configurar Windows para utilizar la red privada vRack
- Configurar Windows para utilizar el bloque IPv6 incluido con el servidor
- Acceder al Backup Storage de OVHcloud desde Windows
- Proteger el servidor con copias de seguridad gestionadas mediante OVHcloud Backup Agent

:::warning
La reinstalación de un sistema operativo borra todos los datos presentes en los discos del servidor. Haga una copia de seguridad de los datos que desee conservar antes de empezar.
:::

## Requisitos

- Disponer de un [servidor dedicado](/links/bare-metal/bare-metal) en su cuenta de OVHcloud
- Disponer de una licencia válida de Windows Server. Las licencias se pueden contratar a través de OVHcloud o de un distribuidor externo. Consulte la guía [Gestionar sus licencias de OVHcloud](/guides/bare-metal-cloud/dedicated-servers/windows-key).
- Disponer de un cliente RDP (Remote Desktop Protocol) en su equipo local (el cliente <code className="action">Conexión a Escritorio remoto</code> viene incluido con Windows)

## Introducción

Un servidor dedicado es un servidor físico ("bare metal") alojado en un centro de datos de OVHcloud. OVHcloud proporciona el hardware, la conexión a la red pública, una red privada vRack opcional y un espacio de Backup Storage incluido. Usted es responsable de la administración del sistema operativo instalado en el servidor, incluida toda la configuración de red y de almacenamiento en Windows.

La siguiente tabla presenta los principales servicios con los que interactúa un servidor dedicado con Windows.

| Servicio de OVHcloud | Función | Dónde activarlo |
|---|---|---|
| Additional IP | Direcciones IP públicas adicionales asociadas al servidor | Área de cliente — menú <code className="action">Network</code>, sección <code className="action">IP</code> |
| vRack | Red privada de nivel 2 entre los servicios de OVHcloud | Área de cliente — menú <code className="action">Network</code>, sección <code className="action">vRack</code> |
| IPv6 | El bloque IPv6 /64 incluido con cada servidor | Proporcionado automáticamente |
| Backup Storage | Espacio de copia de seguridad incluido (FTP/CIFS (SMB)/NFS) | Área de cliente — <ManagerLink to="/#/dedicated-servers/server">Servidores dedicados</ManagerLink> > Seleccione su servidor, pestaña <code className="action">Backup Storage</code> |
| Backup Agent | Copias de seguridad gestionadas diarias hacia un vault de Object Storage aislado e inmutable | Área de cliente — <ManagerLink to="/#/dedicated-servers/server">Servidores dedicados</ManagerLink> > Seleccione su servidor, pestaña <code className="action">Información general</code>, sección <code className="action">Estado de los servicios</code> |

### Paso 1 — Instalar Windows Server desde el área de cliente <a name="install"></a>

En este paso, instalará (o reinstalará) Windows Server en su servidor dedicado. La instalación se gestiona por completo desde el área de cliente.

En la pestaña <code className="action">Información general</code>, junto a <code className="action">Sistema operativo (SO)</code>, abra el menú de acciones y haga clic en <code className="action">Reinstalar mi servidor</code>. Se abre la ventana <code className="action">Instalación desde una plantilla de OVHcloud</code>, que le guía en 4 pasos.

:::info
Windows Server requiere una licencia, que genera gastos adicionales. Sin una licencia de Windows Server asociada al servidor, las plantillas de Windows no aparecen en la lista de sistemas operativos. Puede contratar una licencia a través de OVHcloud o aportar la suya propia. Gestione sus licencias en **Bare Metal Cloud** > **Licencias**. Para más información, consulte la guía [Gestionar sus licencias de OVHcloud](/guides/bare-metal-cloud/dedicated-servers/windows-key).
:::

:::warning
Esta acción es irreversible. Todos los datos presentes en los discos se eliminarán de forma permanente.
:::

1. **Tipo de SO**: indique el <code className="action">Tipo de SO</code> y seleccione la plantilla de Windows Server que desee. Las plantillas se agrupan por categoría (Linux, Windows, etc.). Las plantillas de Windows solo aparecen si hay una licencia de Windows Server asociada a su servidor dedicado (consulte la nota anterior).
2. **Conjunto de discos de destino**: elija el <code className="action">Conjunto de discos de destino</code> en el que se instalará Windows. Para definir su propia agrupación o distribución, active <code className="action">Personalizar la configuración del RAID por hardware</code> o <code className="action">Personalizar la configuración de las particiones</code>. Para el RAID por software en Windows, consulte la guía [Configurar un RAID por software en un servidor Windows](/guides/bare-metal-cloud/dedicated-servers/raid-soft-windows).
3. Haga clic en <code className="action">Siguiente</code> y siga los pasos restantes del asistente para comprobar sus opciones; a continuación, confirme para iniciar la instalación.

El servidor se reinicia y la instalación finaliza automáticamente.

### Paso 2 — Conectarse a su servidor <a name="connect"></a>

Una vez finalizada la instalación, OVHcloud le envía un correo electrónico con el nombre de usuario y la contraseña de administrador de su servidor Windows.

En su equipo Windows local, abra el cliente <code className="action">Conexión a Escritorio remoto</code>. Introduzca la dirección IPv4 de su servidor y, a continuación, su nombre de usuario y su contraseña. Durante la primera conexión suele aparecer una advertencia de certificado; haga clic en <code className="action">Sí</code> para continuar.
Puede utilizar cualquier cliente compatible con RDP si su dispositivo local no funciona con Windows.

:::tip
Si el protocolo RDP no está disponible (por ejemplo, tras un error de configuración de red), conéctese mediante la [consola Intelligent Platform Management Interface (IPMI)](/guides/bare-metal-cloud/dedicated-servers/ipmi) desde la pestaña <code className="action">IPMI / KVM</code> del área de cliente. La consola IPMI funciona independientemente del estado de conectividad del sistema operativo.
:::

Después de su primera conexión, cambie la contraseña de administrador desde Windows (en la sesión RDP, pulse `Ctrl` + `Alt` + `Fin` > <code className="action">Cambiar una contraseña</code>).

### Paso 3 — Llevar a cabo la configuración inicial de Windows <a name="initial-config"></a>

Antes de conectar el servidor a los demás servicios de OVHcloud, realice la configuración básica de Windows.

- Inicie Windows Update e instale las últimas actualizaciones.
- Defina el nombre de host del servidor, la zona horaria y la distribución del teclado.
- Configure el firewall de Windows para autorizar los servicios que tenga previsto ejecutar. Para un procedimiento específico del firewall en Windows, consulte la guía [Activar el firewall en un servidor Windows](/guides/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win).

:::warning
OVHcloud pone a su disposición servicios cuya configuración y gestión son responsabilidad suya. Si necesita ayuda, póngase en contacto con un [proveedor especializado](/links/partner).
:::

### Paso 4 — Configurar Windows para interactuar con los servicios de OVHcloud <a name="services"></a>

Esta sección cubre la configuración en Windows de los servicios de OVHcloud que se asocian con mayor frecuencia a un servidor dedicado. Cada subsección es independiente; siga únicamente las que correspondan a su configuración. En cada una, la primera parte se realiza en el área de cliente de OVHcloud y la segunda en Windows Server.

#### 4a — Additional IP

Una Additional IP es una dirección IP pública adicional enrutada hacia su servidor. Después de contratarla, debe declararla en Windows para que el servidor responda en esa dirección.

**En el área de cliente de OVHcloud**

Contrate la Additional IP desde el menú <code className="action">Network</code> del área de cliente, en la sección <code className="action">IP</code>, haciendo clic en <code className="action">Contratar direcciones IP</code>. Para más información, consulte la página [Additional IP](/links/bare-metal/ip).

**En Windows Server**

1. Abra <code className="action">Panel de control</code> > <code className="action">Centro de redes y recursos compartidos</code> > <code className="action">Cambiar configuración del adaptador</code> y, a continuación, muestre las propiedades de su adaptador de red.
2. Seleccione <code className="action">Protocolo de Internet versión 4 (TCP/IPv4)</code> > <code className="action">Propiedades</code> > <code className="action">Opciones avanzadas</code> y añada la dirección de la Additional IP.

En la red de OVHcloud, una Additional IP se enruta individualmente hacia el servidor. Utilice la máscara de subred y la puerta de enlace que correspondan a la configuración de la IP principal de su servidor.

:::tip
Si tiene previsto asignar la Additional IP a una máquina virtual en lugar de al host, consulte la guía [Configurar un bloque de IP en un vRack](/guides/bare-metal-cloud/dedicated-servers/configuring-an-ip-block-in-a-vrack).
:::

#### 4b — Red privada vRack

El vRack es una red privada de nivel 2 que permite a su servidor dedicado comunicarse de forma privada con otros servicios de OVHcloud (otros servidores dedicados, instancias de Public Cloud, etc.).

**En el área de cliente de OVHcloud**

Desde el menú <code className="action">Network</code> del área de cliente, abra la sección <code className="action">vRack</code>, seleccione su vRack y añada este servidor.

**En Windows Server**

1. Abra las propiedades del adaptador de red **privado** (la segunda interfaz, dedicada al vRack).
2. Asigne una dirección IPv4 privada estática de su plan de direccionamiento vRack. Deje la puerta de enlace predeterminada vacía, ya que el vRack es una red de nivel 2 sin puerta de enlace proporcionada por OVHcloud.

Para el procedimiento completo, así como para la configuración de la OVHcloud Link Aggregation (OLA, agregación de enlaces), consulte la guía [Configurar el vRack en un servidor dedicado](/guides/bare-metal-cloud/dedicated-servers/vrack-configuring-on-dedicated-server).

#### 4c — IPv6

Cada servidor dedicado de OVHcloud se entrega con un bloque IPv6 /64. La dirección no se configura automáticamente en Windows y debe añadirse manualmente.

**En el área de cliente de OVHcloud**

Obtenga su dirección IPv6, el prefijo y la puerta de enlace desde la sección <code className="action">Red</code> de la pestaña <code className="action">Información general</code> de su servidor, que muestra <code className="action">IPv6</code> y <code className="action">Gateway IPv6</code>.

**En Windows Server**

1. Abra las propiedades de su adaptador de red y seleccione <code className="action">Protocolo de Internet versión 6 (TCP/IPv6)</code> > <code className="action">Propiedades</code>.
2. Introduzca la dirección IPv6, la longitud del prefijo y la puerta de enlace IPv6 predeterminada.

Para los detalles de direccionamiento y la configuración de la puerta de enlace específicos de OVHcloud, consulte la guía [Configuración de la IPv6](/guides/bare-metal-cloud/dedicated-servers/network-ipv6).

#### 4d — Backup Storage

El Backup Storage es un espacio de almacenamiento incluido con su servidor dedicado. Es accesible mediante los protocolos FTP, CIFS (SMB) o NFS y resulta especialmente adecuado como copia de seguridad complementaria.

**En el área de cliente de OVHcloud**

1. En la pestaña <code className="action">Backup Storage</code> de su servidor, haga clic en <code className="action">Activar el Backup Storage</code>. Una vez activo, la pestaña muestra la dirección del servidor FTP y el identificador, y le permite definir la contraseña del espacio.
2. Autorice la dirección IP de su servidor a acceder al espacio.

**En Windows Server**

Acceda al espacio utilizando uno de los protocolos compatibles:

- **CIFS (SMB)**: móntelo como una unidad de red (<code className="action">Este equipo</code> > <code className="action">Conectar a unidad de red</code>).
- **FTP**: conéctese con cualquier cliente FTP, utilizando los datos de conexión del área de cliente y la contraseña que haya definido.

Para el procedimiento de activación y los protocolos de acceso, consulte la guía [Backup Storage en los servidores dedicados](/guides/bare-metal-cloud/dedicated-servers/services-backup-storage) y la página [Backup Storage](/links/bare-metal/backup-storage).

#### 4e — Backup Agent

El Backup Storage es un espacio de almacenamiento pasivo: no realiza copias de seguridad de sus datos por sí mismo. Para una protección gestionada y automatizada, OVHcloud ofrece **Backup Agent**, un servicio de copia de seguridad independiente para los servidores Bare Metal. Una vez contratado, despliega un agente ligero en su servidor Windows, que realiza copias de seguridad diarias incrementales, cifradas e inmutables hacia un vault de Object Storage aislado, situado en una región diferente a la del servidor.

**En el área de cliente de OVHcloud**

En la pestaña <code className="action">Información general</code>, en la sección <code className="action">Estado de los servicios</code>, utilice la entrada <code className="action">Backup Agent</code> y haga clic en <code className="action">Gestionar Agente de Backup</code>. También puede activarlo durante la reinstalación del sistema operativo.

**En Windows Server**

Una vez desplegado el agente, configure su primera copia de seguridad (datos de origen, planificación y retención).

Para el procedimiento completo, consulte la guía [Backup Agent - Presentación](/guides/storage-and-backup/backup-agent/overview) y la guía [Backup Agent - Cómo configurar su primera copia de seguridad](/guides/storage-and-backup/backup-agent/first-configuration).

### Paso 5 — Verificar la configuración <a name="verify"></a>

Compruebe que cada servicio configurado funciona como se espera.

| Comprobación | Cómo | Resultado esperado |
|---|---|---|
| Acceso RDP | Conéctese con <code className="action">Conexión a Escritorio remoto</code> a la IPv4 principal | Se muestra el escritorio de Windows |
| Additional IP | Desde un host externo, ejecute `ping` hacia la Additional IP | El servidor responde |
| vRack | Desde otro miembro del vRack, ejecute `ping` hacia la IP privada | El servidor responde |
| IPv6 | Ejecute `ping -6 ipv6.google.com` desde el servidor | Recibe respuestas |
| Backup Storage | Abra la unidad CIFS (SMB) montada o conéctese por FTP | Puede leer y escribir archivos |

### Solución de problemas <a name="troubleshooting"></a>

| Problema | Causa posible | Solución |
|---|---|---|
| La conexión RDP falla | Reglas de firewall o restricciones de red en el dispositivo local | Compruebe la configuración del firewall y de la red locales; conéctese mediante la [consola IPMI](/guides/bare-metal-cloud/dedicated-servers/ipmi) como alternativa. |
| Additional IP inaccesible | Máscara o puerta de enlace incorrectas en Windows | Vuelva a comprobar los valores introducidos en las opciones avanzadas de TCP/IPv4. |
| Miembro del vRack inaccesible | Subred privada incorrecta o puerta de enlace definida en el adaptador privado | Confirme el plan de direccionamiento privado y deje la puerta de enlace vacía. |
| Servidor fuera de línea tras una modificación | Error de configuración durante la implementación | Arranque en [modo rescue](/guides/bare-metal-cloud/dedicated-servers/rescue-customer-windows) para inspeccionar y reparar la configuración. |
