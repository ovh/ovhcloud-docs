## Objetivo

El backup de un servidor Bare Metal con Veeam Enterprise requiere que varias aplicaciones y servicios funcionen conjuntamente. El proceso también puede variar en función de su configuración y de sus preferencias.

**Descubra cómo preparar el backup de su servidor Bare Metal con Veeam Backup and Replication (Enterprise).**

## Requisitos

- Un [servidor Bare Metal de OVHcloud](/links/bare-metal/bare-metal)
- Una solución de backup [Veeam Enterprise](/links/hosted-private-cloud/veeam-enterprise)
- Un servicio [OVHcloud Object Storage](/links/public-cloud/object-storage) (opcional)

[[cpnav:publiccloud-object-storage-console]]

## Procedimiento

### Instalación del servidor dedicado

Su servidor Bare Metal de OVHcloud debe estar instalado y configurado.

Consulte nuestras [guías de primeros pasos con los servidores dedicados](/guides/bare-metal-cloud/dedicated-servers/getting-started-with-dedicated-server).

También puede configurar su servidor dedicado para utilizar una red privada siguiendo los pasos de [esta guía](/guides/bare-metal-cloud/dedicated-servers/vrack-configuring-on-dedicated-server).

### Instalación del servidor de backup Veeam Enterprise

Descargue e instale su servidor de backup Veeam Enterprise y cree una licencia para él con ayuda de nuestra guía "[Instalar Veeam Backup & Replication](/guides/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication)".

A partir de este paso, puede seguir leyendo esta guía para aprender a configurar Object Storage como repositorio de backup o pasar directamente al apartado [Más información](#gofurther).

### Configuración del Object Storage

Puede crear y configurar el Object Storage en el universo <code className="action">Public Cloud</code> de la consola de OVHcloud, en la sección <code className="action">Object Storage</code> de su proyecto de Public Cloud.

Si todavía no tiene un proyecto de Public Cloud en su cuenta de OVHcloud, consulte nuestra guía [Crear su primer proyecto de Public Cloud](/guides/public-cloud/cross-functional/create-a-public-cloud-project).

[Cree un contenedor Object Storage](/guides/storage-and-backup/object-storage/s3-getting-started-with-object-storage) con una de las soluciones **Object Storage (Standard o High Performance)**. Se recomienda la solución Standard, ya que nuestro caso de uso (realizar un backup) no suele requerir almacenamiento High Performance.

:::info
Al contratar un contenedor Object Storage en OVHcloud, seleccione únicamente el **Object Storage Standard** o el **Object Storage High Performance**. Estos contenedores son totalmente compatibles con el protocolo Amazon S3<sup>1</sup> y están diseñados para utilizarse como repositorios de backup.

:::


Conceda al usuario de Object Storage permisos sobre el contenedor copiando y pegando el siguiente código en un archivo JSON.

```json
{
  "Statement":[
    {
      "Action":
         [
             "s3:GetObject",
             "s3:PutObject",
             "s3:DeleteObject",
             "s3:ListBucket",
             "s3:ListMultipartUploadParts",
             "s3:ListBucketMultipartUploads",
             "s3:AbortMultipartUpload",
             "s3:GetBucketLocation"
          ],
      "Effect":"Allow",
      "Resource":
          [
              "arn:aws:s3:::<container name>",
              "arn:aws:s3:::<container name>/*"
          ],
      "Sid":"RWContainer"
     }
  ]
}
```

Asegúrese de sustituir `container name` por el nombre real de su contenedor Object Storage.

En la pestaña <code className="action">Usuarios</code> de la página **Object Storage**, haga clic en el botón <code className="action">⋮</code> de la columna **Acciones** del usuario de Object Storage y seleccione <code className="action">Importar una política</code>.

En la ventana **Importar una política**, seleccione el archivo JSON que acaba de modificar y haga clic en <code className="action">Importar</code>. La política importada sustituye a la política actual del usuario: si este usuario ya tiene una política, descárguela primero con <code className="action">Descargar la política</code> (en el mismo menú) y añada esta declaración a su lista `Statement` antes de importarla.

### Configuración del repositorio Object Storage en Veeam Enterprise

En la aplicación Veeam, seleccione <code className="action">Backup Infrastructure</code>, <code className="action">Backup Repositories</code> y <code className="action">Add Repository</code>.

<img className="thumbnail" alt="Veeam - añadir un repositorio" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-02.png" loading="lazy" />

Seleccione <code className="action">Object storage</code> como tipo de repositorio.

<img className="thumbnail" alt="Veeam - Object Storage" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-03.png" loading="lazy" />

Seleccione <code className="action">S3 Compatible</code>.

<img className="thumbnail" alt="Veeam - compatible con S3" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-04.png" loading="lazy" />

Asigne un nombre (**Name**) al nuevo repositorio y haga clic en <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - nombre del repositorio" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-05.png" loading="lazy" />

Introduzca la información **Service point** (Endpoint) y **Region** de su servicio de almacenamiento Object Storage.

> Puede consultar esta información en el universo <code className="action">Public Cloud</code> de la consola de OVHcloud.
> Haga clic en <code className="action">Object Storage</code> y, en la pestaña <code className="action">Contenedores</code>, haga clic en el nombre de su contenedor y abra su pestaña <code className="action">Vista general</code>. La **Región** aparece en la sección **Información general** (así como en la columna **Región** de la lista de contenedores), y el **Endpoint** en la sección **Detalles de conexión**.

<img className="thumbnail" alt="Veeam - endpoint del servicio y región" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-08.png" loading="lazy" />

Haga clic en <code className="action">Add</code> para introducir sus credenciales. Introduzca su **Access key** y su **Secret key** y haga clic en <code className="action">OK</code>.

> Esta información está disponible en la consola de OVHcloud, en la pestaña <code className="action">Usuarios</code> de la página **Object Storage**. La **Clave de acceso** (Access key) aparece en la columna **Clave de acceso** de la lista de usuarios.
> Para obtener la **Clave secreta** (Secret key), haga clic en el botón <code className="action">⋮</code> de la columna **Acciones** del usuario y seleccione <code className="action">Mostrar la clave secreta</code>. Esta se muestra en la ventana **Claves S3**.

<img className="thumbnail" alt="Veeam - claves" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-10.png" loading="lazy" />

Haga clic en <code className="action">Browse...</code> para seleccionar el **Bucket**.

<img className="thumbnail" alt="Veeam - bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-11.png" loading="lazy" />

Seleccione el bucket y haga clic en <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - bucket" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-12.png" loading="lazy" />

Haga clic en <code className="action">Browse...</code> para seleccionar la carpeta (**Folder**).

<img className="thumbnail" alt="Veeam - carpeta" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-13.png" loading="lazy" />

Haga clic en <code className="action">New Folder</code>, introduzca un nombre para la carpeta, selecciónela y haga clic en <code className="action">OK</code>.

<img className="thumbnail" alt="Veeam - carpeta" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-14.png" loading="lazy" />

En el paso de montaje del servidor (Mount Server), haga clic en <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - Mount Server" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-15.png" loading="lazy" />

En la pantalla de resumen (Review), haga clic en <code className="action">Apply</code>.

<img className="thumbnail" alt="Veeam - revisión" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-16.png" loading="lazy" />

Una vez que los procesos se hayan ejecutado correctamente, haga clic en <code className="action">Next</code>.

<img className="thumbnail" alt="Veeam - fin del proceso" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-17.png" loading="lazy" />

Revise la página de resumen (Summary) y haga clic en <code className="action">Finish</code>.

<img className="thumbnail" alt="Veeam - resumen" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-18.png" loading="lazy" />

Los repositorios de backup deberían tener ahora un aspecto similar a este:

<img className="thumbnail" alt="Veeam - repositorios" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/backup-preparation-19.png" loading="lazy" />

Ya puede realizar un backup con Veeam Enterprise.
