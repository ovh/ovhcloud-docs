## Objetivo

OVHcloud permite asociar una dirección MAC virtual a una dirección IP para poder desplegar máquinas virtuales con una configuración bridge en los servidores.

**Esta guía explica cómo crear una MAC virtual y asociarle una Additional IP.**

## Requisitos

- Tener [un servidor dedicado](/links/bare-metal/bare-metal) que soporte las MAC virtuales. Consulte [esta guía](/guides/bare-metal-cloud/dedicated-servers/network-support-virtual-mac) para averiguarlo.
- Tener una [dirección Additional IP](/links/network/additional-ip) o un bloque de Additional IP (RIPE).

:::warning
- Esta funcionalidad puede no estar disponible o estar limitada en los [servidores dedicados **Eco**](/links/bare-metal/eco-about). Para más información, consulte nuestra [comparativa](/links/bare-metal/eco-compare).

- Los servidores Advance de tercera generación (equipados con procesadores EPYC 4004 Series) soportan 32 vMAC diferentes.

- Desde mayo de 2025, esta funcionalidad está disponible en las gamas Scale y High Grade.

:::


:::info
Si no está familiarizado con el uso de la API de OVHcloud, consulte nuestra guía [Primeros pasos con las API de OVHcloud](/guides/manage-and-operate/api/first-steps).

:::

## Procedimiento

### Asignar una dirección MAC

:::warning
Si un bloque IP ha sido movido al vRack, ya no está asignado a un servidor físico por este motivo, ya no es posible asignar una MAC virtual a una IP.

:::


#### Desde la consola de OVHcloud

Haga clic en el filtro <code className="action">IP adicional</code> situado encima de la lista para mostrar únicamente sus Additional IP.

Localice su Additional IP (o su bloque) en la lista y haga clic en ella para abrir su página. A continuación, haga clic en la pestaña <code className="action">MAC Virtual</code>. Para un bloque, el menú desplegable **Mostrar MAC virtuales para** permite elegir la IP cuyas MAC virtuales se muestran. Haga clic en <code className="action">Añadir MAC virtual</code>.

Cuando aparezca la ventana **Añadir una MAC virtual**, seleccione la dirección IP en la lista **Dirección IP** (solo para un bloque), seleccione un tipo en la lista desplegable **Tipo**, introduzca un nombre en el campo **Máquina virtual** y haga clic en <code className="action">Añadir</code>.

:::info
**Tipo**: Se trata del tipo de dirección MAC virtual (<code className="action">vmware</code> será una dirección MAC para el sistema VMware ESXi, mientras que <code className="action">ovh</code> servirá para todos los demás sistemas de virtualización).

**Máquina virtual**: Nombre que quiera asignar a la dirección MAC virtual, para luego encontrar más fácilmente la pareja IP/MAC.

Si su servidor ya dispone de direcciones MAC virtuales, la ventana le permite elegir entre <code className="action">Crear una nueva dirección MAC virtual</code> y <code className="action">Usar una dirección MAC virtual existente</code>. Con la segunda opción, seleccione la dirección MAC que desea reutilizar en lugar de un tipo.

:::

:::info
No olvide asignar la dirección MAC virtual creada en la configuración de su máquina virtual.

:::


#### Vía la API OVHcloud

Utilice la siguiente llamada a la API:

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/virtualMac"} />


### Eliminar una dirección MAC

:::warning
Si elimina una dirección MAC, no será posible recuperarla más adelante.

:::


#### Desde la consola de OVHcloud

En la página **Direcciones IP**, utilice el menú desplegable **Filtrar por servicio...** o la barra de búsqueda para encontrar la Additional IP (o el bloque IP). Haga clic en ella para abrir su página y haga clic en la pestaña <code className="action">MAC Virtual</code>. Para un bloque, seleccione la IP en el menú desplegable **Mostrar MAC virtuales para**.

Cada MAC virtual se muestra bajo su dirección MAC. Haga clic en <code className="action">Eliminar</code> bajo la MAC virtual y, a continuación, en <code className="action">Eliminar</code> en la ventana **Eliminar la dirección MAC virtual** para confirmar.

#### Vía la API OVHcloud

Utilice la siguiente llamada a la API:

<Api version="v1" section="/dedicated/server" method="DELETE" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


## FAQ

- **¿Qué ocurre si muevo un bloque con vMAC a un servidor Advance de tercera generación (equipado con un procesador EPYC 4004 Series) que ya tenga 32 vMACs?**

El bloque no se moverá.

Ejemplo: si intenta mover un bloque de 4 IP con diferentes vMAC asociadas a un servidor que ya tiene 30 vMAC, el bloque no se moverá porque el total de vMAC sería superior a las 32 vMAC autorizadas.
