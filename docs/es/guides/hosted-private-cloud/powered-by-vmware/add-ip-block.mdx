## Objetivo

Los bloques de IP permiten que sus servicios estén accesibles online. 

**Esta guía explica cómo contratar, añadir y migrar un bloque de IP asociado a su Hosted Private Cloud.**

## Requisitos

- Ser contacto administrador de la infraestructura [Hosted Private Cloud](https://www.ovhcloud.com/es-es/enterprise/products/hosted-private-cloud/), para recibir claves de conexión.
- Tener un usuario activo (creado en la <ManagerLink console to="/">consola de OVHcloud</ManagerLink>).

[[cpnav:network-public-ip-console]]

## Procedimiento

### Contratar un bloque de IP

Para contratar un bloque de IP adicional en su **Hosted Private Cloud**, abra su servicio en la consola de OVHcloud (**Private Cloud** › **Managed VMware vSphere** y, a continuación, su servicio). En la pestaña **Panel de control**, sección **Opciones**, abra el menú ⋮ de la línea **Número de bloques de IP** y haga clic en <code className="action">Pedir bloques de IP</code>. También puede acceder a la misma página de pedido desde **Red** › **Direcciones IP**: haga clic en <code className="action">Pedir una IP</code> y, a continuación, en <code className="action">Pedir una Additional IP</code>.

En la página **Pedir una IP**, rellene las siguientes secciones para crear su bloque de IP:

- **Seleccionar el tipo de dirección IP**: elija **IPv4**.
- **Seleccione el servicio al que asignar la IP adicional**: seleccione su servicio **Hosted Private Cloud**. La región se determina automáticamente a partir del servicio seleccionado.
- **Seleccionar una oferta**: elija el tamaño del bloque de IP (de /28 a /24).

:::info
Incluimos a continuación una tabla para recordarle el número de IP presentes en un bloque, así como el número de IP utilizables.

:::


|Tamaño del bloque|IP en el bloque|IP utilizables en OVHcloud|
|:---:|:---:|:---:|
|28|16|11|
|27|32|27|
|26|64|59|
|25|128|123|
|24|256|251|

:::info
Para más información sobre las IP reservadas en su bloque y su utilización, consulte la siguiente guía: [Utilizar el plugin OVHcloud Network](/guides/hosted-private-cloud/powered-by-vmware/plugin-ovh-network).

:::

- **Seleccionar una geolocalización**: elija el país del bloque de IP, importante en algunos casos para el posicionamiento de sus servicios (por ejemplo, un sitio web español tendrá un mejor posicionamiento en España si la IP es española).

El nombre y la descripción de la red visibles en el Whois del bloque de IP no se solicitan al realizar el pedido: puede modificar el nombre de la red desde la página **Direcciones IP** una vez entregado el bloque.

:::tip
Deberá abonar los gastos de activación de su bloque de IP antes de la entrega.

:::

Compruebe el **Resumen** y haga clic en <code className="action">Contratar</code>. La orden de pedido de su bloque de IP se abrirá en una nueva pestaña. Si la orden de pedido es correcta, solo tendrá que realizar el pago con cualquiera de los métodos de pago disponibles para que se le entregue el bloque.

### Migrar un bloque de IP entre dos Hosted Private Cloud

<iframe className="video" width="560" height="315" src="https://www.youtube-nocookie.com/embed/Gemao3Fd7rI" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen={true}></iframe>

Para migrar un bloque de IP, deberá mover manualmente los bloques a través de la APIv6 de OVHcloud.

Para ello, utilice la siguiente llamada:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/move"} />

Rellene los campos utilizando los siguientes parámetros:

- ip: bloque IP con /mask
- nexthop «newPrimaryIp» (preste atención a las mayúsculas)
- to: Hosted Private Cloud de destino con forma «pcc-XXX-XXX-XXX-XXX»

Obtendrá el siguiente resultado:

```json
{
  "function": "genericMoveFloatingIp",
  "status": "todo",
  "taskId": 178970672
}
```

Si más adelante tiene que desvincular el bloque IP, puede utilizar la siguiente llamada para mover la IP en el parking de IP:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/park"} />


:::warning
Esta llamada interrumpe la red en las MV que utilizan las IP en cuestión.

:::


También puede mover el bloque desde la consola de OVHcloud: en la pestaña **Panel de control** de su servicio, sección **Opciones**, abra el menú ⋮ de la línea **Número de bloques de IP** y haga clic en <code className="action">Asociar bloques de IP a otro servicio</code>.

Podrá seguir la migración del bloque de IP en el menú **Managed VMware vSphere**. Haga clic en su servicio Hosted Private Cloud y, a continuación, en la pestaña <code className="action">Operaciones</code>.

La referencia de la operación es `removeIpRipeBlock`.

A continuación, la IP aparecerá en la lista **Direcciones IP** (**Red** › **Direcciones IP**) con el tipo **IP Parking**.
