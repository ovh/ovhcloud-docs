## Objetivo

**En esta guía le explicamos cómo crear un rol IAM en Hosted Private Cloud - VMware on OVHcloud**.

## Requisitos

- Tener una [cuenta de OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- Tener uno o varios productos Hosted Private Cloud - VMware on OVHcloud vinculados a esta cuenta (Hosted Private Cloud powered by VMware, VMware Service Pack).
- Haber activado IAM en su servicio Hosted Private Cloud - VMware on OVHcloud. Siga los pasos de la guía [IAM para VMware on OVHcloud - Cómo activar IAM](/guides/hosted-private-cloud/powered-by-vmware/vmware-iam-activation).

[[cpnav:privatecloud-vmware-vsphere-console]]

## Procedimiento

Por defecto, dispone de 2 roles IAM de vSphere. Por lo tanto, la creación de un rol adicional es opcional.

A continuación le explicamos cómo crear un rol adicional.

### Crear un rol IAM desde la consola de OVHcloud

Seleccione su infraestructura y abra la pestaña <code className="action">Usuarios</code>.

Haga clic en <code className="action">Crear un rol IAM</code>.

<img className="thumbnail" alt="Pestaña Usuarios de un servicio Managed VMware vSphere con el botón Crear un rol IAM" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role/console/iam_role_8.png" loading="lazy" />

En la ventana **Crear un nuevo rol IAM OVHcloud** que se abre, introduzca el nombre de su rol en el campo **Nombre del rol** y haga clic en <code className="action">Confirmar</code>.

:::info
Los roles IAM llevan automáticamente el prefijo `iam-`.

:::

<img className="thumbnail" alt="Ventana Crear un nuevo rol IAM OVHcloud, prefijo iam- en el campo Nombre del rol" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-role/console/iam_role_9.png" loading="lazy" />

A continuación, puede modificar los permisos del grupo del mismo modo que con un usuario local de vSphere: haga clic en el botón <code className="action">⋮</code> de la columna **Acciones** en la fila de su rol y seleccione <code className="action">Ver/Editar los permisos por DC</code>.

#### Crear un rol IAM a través de la API de OVHcloud

:::tip
Consulte la guía [Primeros pasos con las API de OVHcloud](/guides/manage-and-operate/api/first-steps) para familiarizarse con el uso de la APIv6 de OVHcloud.

:::



Ejecute la siguiente llamada a la API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/addRole"} />


:::warning
Asegúrese de sustituir `serviceName` por la referencia de su servicio Hosted Private Cloud, con el formato `pcc-XXX-XXX-XXX-XXX`.

:::
