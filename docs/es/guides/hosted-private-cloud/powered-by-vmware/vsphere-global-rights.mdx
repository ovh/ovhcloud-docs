## Objetivo

Los permisos globales de vSphere permiten definir los derechos de un usuario en su servicio Hosted Private Cloud. Desde el área de cliente de OVHcloud, puede activar o desactivar estas opciones para cada usuario mediante casillas de verificación.

Esta guía explica cómo gestionar estos permisos globales desde el Manager de OVHcloud.

## Requisitos

- Un [servicio Hosted Private Cloud](https://www.ovhcloud.com/es/hosted-private-cloud/vmware/) activo
- Un [usuario de vSphere](/guides/hosted-private-cloud/powered-by-vmware/vsphere-interface-connexion) ya creado en su servicio
- Acceso al <ManagerLink to="/">área de cliente de OVHcloud</ManagerLink> con derechos suficientes para administrar usuarios

## Procedimiento

### Acceder a la gestión de derechos de usuario

1. Abra el <ManagerLink to="/">área de cliente de OVHcloud</ManagerLink>. Haga clic en <code className="action">Hosted Private Cloud</code> en la barra superior, luego en <code className="action">Managed VMware vSphere</code> en el menú de la izquierda y seleccione su servicio PCC.

2. Acceda a la pestaña <code className="action">Usuarios</code>.

	<img className="thumbnail" alt="Pestaña usuarios" src="/images/hosted-private-cloud/powered-by-vmware/manager-ovh-private-cloud/en05users.png" loading="lazy" />

3. En la línea del usuario correspondiente, abra el menú <code className="action">...</code> y haga clic en <code className="action">Modificar</code>.

### Configurar los permisos globales

1. En la ventana de modificación del usuario, varias casillas de verificación corresponden a los permisos globales.

2. Marque o desmarque las opciones según los derechos que desee conceder al usuario.

	<img className="thumbnail" alt="Ventana de modificación de los derechos de usuario" src="/images/hosted-private-cloud/powered-by-vmware/vsphere-global-rights/user-global-rights.png" loading="lazy" />

3. Valide la modificación.

### Permisos disponibles

Los permisos globales están representados por las siguientes casillas de verificación en la ventana de modificación del usuario:

| Permiso | Descripción |
|---|---|
| Token validator | Activa el token de validación para el usuario, permitiendo la autenticación en la API de OVHcloud. |
| Ip | Restringe el acceso del usuario a direcciones IP específicas. |
| Ip Failover | Permite al usuario gestionar las direcciones IP Failover asociadas al servicio. |
| Interface NSX | Concede acceso a la interfaz de gestión de red NSX. |
| Encryption management | Permite al usuario gestionar el cifrado de las máquinas virtuales (KMS). |

### Más información sobre los derechos granulares

Los permisos globales descritos anteriormente se aplican a nivel del inventario de vSphere de Hosted Private Cloud, es decir, a nivel del clúster de VMware considerado.

Si necesita autorizar a un usuario solo en ciertos objetos del inventario de vSphere, por ejemplo una máquina virtual, un datastore o una carpeta, debe utilizar los [derechos granulares en los objetos de vSphere](/guides/hosted-private-cloud/powered-by-vmware/vsphere-granular-rights).
