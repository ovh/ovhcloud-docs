## Objetivo

**Esta guía explica cómo activar IAM con Hosted Private Cloud - VMware on OVHcloud desde la consola de OVHcloud o con la API de OVHcloud**.

## Requisitos

- Tener una [cuenta de OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation).
- Tener uno o varios productos Hosted Private Cloud - VMware on OVHcloud vinculados a esta cuenta (Hosted Private Cloud powered by VMware, VMware Service Pack).

[[cpnav:privatecloud-vmware-vsphere-console]]

## Procedimiento

### Activar IAM

:::info
Esta operación puede tardar hasta 30 minutos.

:::


### Desde la consola de OVHcloud

Seleccione su infraestructura y abra la pestaña <code className="action">Usuarios</code>.

En la sección **OVHcloud IAM**, en la parte inferior de la pestaña, haga clic en <code className="action">Activar OVHcloud IAM</code>.

<img className="thumbnail" alt="Sección OVHcloud IAM con el estado Desactivado y el enlace Activar OVHcloud IAM" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_2.png" loading="lazy" />

:::warning
Solo el producto vSphere está integrado en OVHcloud IAM. Una infraestructura con opciones de seguridad reforzada o un servicio certificado (HDS, PCI-DSS o SNC) no puede utilizar OVHcloud IAM por el momento. Si más adelante activa alguna de estas opciones o alguno de estos servicios certificados, deberá desactivar OVHcloud IAM.
:::

En la ventana **Activar IAM OVHcloud** que se abre, haga clic en <code className="action">Confirmar</code>.

:::tip
Una vez activado IAM, su estado será `Activado` y se mostrará en verde.

:::

<img className="thumbnail" alt="Pestaña Usuarios con la sección OVHcloud IAM en estado Activado" src="/images/hosted-private-cloud/powered-by-vmware/vmware-iam-activation/console/iam_enable_3.png" loading="lazy" />

### A través de la API de OVHcloud

:::tip
Consulte la guía [Primeros pasos con las API de OVHcloud](/guides/manage-and-operate/api/first-steps) para familiarizarse con el uso de la APIv6 de OVHcloud.

:::


:::warning
Asegúrese de sustituir `serviceName` por la referencia de su servicio Hosted Private Cloud, con el formato `pcc-XXX-XXX-XXX-XXX`.

:::


Para activar la opción IAM, ejecute la siguiente llamada a la API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/enable"} />


#### Comprobar que IAM está activado

Para comprobar la activación de IAM, ejecute la siguiente llamada a la API:

<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\{serviceName\}/iam"} />

Respuesta de la API:

```shell
{
  "state": "enabled",
  "identityProviderId": 275
}
```

### Desactivar IAM

Puede desactivar OVHcloud IAM en su Hosted Private Cloud.

#### Desde la consola de OVHcloud

Seleccione su infraestructura y abra la pestaña <code className="action">Usuarios</code>.

En la sección **OVHcloud IAM**, en la parte inferior de la pestaña, haga clic en <code className="action">Desactivar OVHcloud IAM</code>. En la ventana **Desactivar IAM OVHcloud** que se abre, haga clic en <code className="action">Confirmar</code>.

#### A través de la API de OVHcloud

Para desactivar la opción IAM, ejecute la siguiente llamada a la API:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/disable"} />
