## Objetivo

Es posible asociar un nombre, un apellido, un número de teléfono y una dirección de correo electrónico a un usuario vSphere de Hosted Private Cloud. Asociar una dirección de correo electrónico permite activar la validación por token.

**Esta guía explica cómo asociar una dirección de correo electrónico a un usuario vSphere**.

## Requisitos

- Tener una solución [Hosted Private Cloud](https://www.ovhcloud.com/es-es/enterprise/products/hosted-private-cloud/).

[[cpnav:privatecloud-vmware-vsphere-console]]

## Procedimiento

Seleccione la infraestructura correspondiente.

Acceda a la pestaña <code className="action">Usuarios</code>, abra el menú ⋮ (columna **Acciones**) del usuario correspondiente y haga clic en <code className="action">Editar</code>.

Se abrirá la ventana **Editar**. Desde ella podrá introducir su nombre, apellido, número de teléfono y dirección de correo electrónico.

Esta ventana también permite asignar los permisos **Token de validación**, **IP**, **IP Failover** y **Gestión del cifrado**. El permiso **Token de validación** se utiliza para aprobar algunas acciones sensibles en las infraestructuras que tengan activada la opción **Seguridad avanzada**.

Haga clic en el botón <code className="action">Guardar</code> para confirmar los cambios.
