## Objetivo

El servicio NAS-HA de OVHcloud le permite gestionar un almacenamiento de archivos al que podrá acceder desde una red.

**Esta guía explica cómo gestionar las particiones del servicio NAS-HA a través de la API de OVHcloud.**

## Requisitos

- Un servicio [NAS-HA de OVHcloud](https://www.ovhcloud.com/es-es/storage-solutions/nas-ha/)
- Consulte nuestra guía de [primeros pasos con la API de OVHcloud](/guides/manage-and-operate/api/first-steps) para familiarizarse con la APIv6 de OVHcloud.

## Procedimiento

Todas las rutas API de esta guía están disponibles en la <ApiLink section="/dedicated/nasha">sección */dedicated/nasha*</ApiLink> de la consola API.

:::info
Al utilizar la API, todos los campos marcados con asterisco (\*) son obligatorios.
:::


### Obtener información sobre el servicio

Todos los servicios activos se pueden recuperar utilizando la siguiente ruta:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha"} />


### Lista de todas las particiones

Utilice la siguiente ruta para recuperar las particiones de un servicio:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nombre interno del servicio NAS |

### Obtener las propiedades de una partición

Para ver los detalles de una partición, utilice la siguiente ruta:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nombre interno del servicio NAS-HA |
| `partitionName` | Yes | Nombre de la partición |

### Obteniendo las estadísticas de una partición

Utilice la siguiente ruta para obtener la información de uso de una partición:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/use"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nombre interno del servicio NAS-HA |
| `partitionName` | Yes | Nombre de la partición |
| `type` | Yes | Tipo de estadística: *size*, *used* or *usedbysnapshots* |

### Creación de una partición

Utilice la siguiente ruta para crear una nueva partición:

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nombre interno del servicio NAS |
| `partitionDescription` |  | Descripción opcional |
| `partitionName` | Yes | Un nombre para la partición |
| `protocol` | Yes | *NFS*, *CIFS* o *NFS_CIFS* para ambos |
| `size` | Yes | El tamaño de la partición |

Elija `NFS` como protocolo y un tamaño de `10` Gigabytes, por ejemplo.

### Modificar las propiedades de una partición

Utilice la siguiente ruta para modificar una partición:

<Api version="v1" section="/dedicated/nasha" method="PUT" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nombre interno del servicio NAS |
| `partitionName` | Yes | Nombre de la partición |
| `partitionDescription` |  | La nueva descripción |
| `size` |  | El nuevo tamaño de la partición |

### Obtener los parámetros ZFS de una partición

Utilice la siguiente ruta para obtener los parámetros ZFS:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nombre interno del servicio NAS |
| `partitionName` | Yes | Nombre de la partición |

### Modificación de los parámetros ZFS de una partición

:::warning
Los parámetros ZFS por defecto son adecuados para la mayoría de los usos. Modifíquelos solo si conoce los datos alojados en la partición. Para más información sobre cada parámetro y los valores que aplica cada plantilla de uso, consulte nuestra guía "[Configurar los parámetros ZFS de una partición](/guides/storage-and-backup/file-storage/ha-nas/nas-zfs-settings)".
:::


Utilice la siguiente ruta para modificar los parámetros ZFS:

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nombre interno del servicio NAS |
| `partitionName` | Yes | Nombre de la partición |
| `templateName` |  | Plantilla de uso que se aplicará: *Default*, *Virtual machines*, *Databases* o *File Systems (big files)*. Este parámetro debe enviarse solo, sin `atime`, `recordsize` ni `sync` |
| `atime` |  | Parámetro de actualización del tiempo de acceso: *off* (por defecto) o *on* |
| `recordsize` |  | Tamaño máximo de bloque, en bytes: *4096*, *8192*, *16384*, *32768*, *65536*, *131072* (por defecto) o *1048576* |
| `sync` |  | Parámetro de sincronización de archivos: *always*, *disabled* o *standard* (valor por defecto) |

### Eliminación de una partición

Utilice la siguiente ruta para eliminar una partición:

<Api version="v1" section="/dedicated/nasha" method="DELETE" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nombre interno del servicio NAS-HA |
| `partitionName` | Yes | Nombre de la partición |
