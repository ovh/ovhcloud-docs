## Objetivo

Un **Vault** es un espacio de almacenamiento proporcionado por OVHcloud al que puede enviar los datos de sus copias de seguridad. Con Backup Licenses, se incluye automáticamente un primer Vault con su primera licencia.

**Esta guía explica cómo funcionan los Vaults del producto Backup Licenses, cómo se facturan y cómo solicitar Vaults adicionales.**

## Requisitos

- Haber solicitado una licencia Backup Licenses. Consulte nuestra guía "[Solicitar y configurar su primera licencia](/guides/storage-and-backup/backup-licenses/first-configuration)" para obtener más información.

## Procedimiento

### El Vault "bundle"

Un Vault denominado **"bundle"** se incluye por defecto con su primera licencia Backup Licenses.

- Este Vault está **vinculado a la suscripción del producto**: se **elimina si el producto Backup Licenses se cancela**.
- Es **único**: solo dispone de un único Vault "bundle", independientemente del número de licencias.
- Es **gratuito hasta 500 GB**. Este espacio puede utilizarse tanto para sus servidores VBR como para otras necesidades de almacenamiento.

Sus Vaults aparecen en la pestaña <code className="action">Vaults</code> del producto Backup Licenses, en su área de cliente de OVHcloud. El Vault "bundle" lleva la etiqueta <code className="action">Incluido</code>. Para cada Vault se muestran su **región**, su **inmutabilidad** (activada, 14 días), su **cifrado** (activado, SSE OMK) y su **estado**.

<img className="thumbnail" alt="Pestaña Vaults del producto Backup Licenses" src="/images/storage-and-backup/backup-licenses/vault/bl_vault_en.png" loading="lazy" />

:::danger
La cancelación del producto Backup Licenses conlleva la **eliminación del Vault "bundle" y de los datos que contiene**. Asegúrese de haber recuperado sus datos antes de cualquier cancelación.

:::

### Obtener los datos de conexión del Vault

El Vault "bundle" se pone a disposición en forma de un **bucket S3<sup>1</sup>**. Para obtener sus datos de conexión, haga clic en el menú <code className="action">...</code> situado a la derecha del Vault y después en <code className="action">Mostrar las credenciales</code>.

<img className="thumbnail" alt="Menú de acciones de un Vault con la opción Mostrar las credenciales" src="/images/storage-and-backup/backup-licenses/vault/bl_vault_show_creds_en.png" loading="lazy" />

La ventana <code className="action">S3 credentials</code> muestra entonces todos los elementos necesarios para la conexión:

- **Bucket name**
- **Region**
- **S3 Endpoint**
- **Access key**
- **Secret key**, oculta por defecto: haga clic en <code className="action">Show</code> para mostrarla.

<img className="thumbnail" alt="Ventana S3 credentials de un Vault" src="/images/storage-and-backup/backup-licenses/vault/bl_vault_creds_en.png" loading="lazy" />

Estos datos le permiten configurar el Vault como repositorio de objetos en su servidor Veeam Backup & Replication, o acceder a él con cualquier cliente compatible con S3.

### Facturación del Vault "bundle"

- Los **primeros 500 GB están incluidos** en su suscripción Backup Licenses, sin coste adicional.
- **A partir de 500 GB**, cada GB adicional consumido se factura **mensualmente**, según la **tarifa pública del OVHcloud Object Storage**.

Puede seguir su consumo del periodo de facturación en curso en la pestaña <code className="action">Facturación</code> del producto Backup Licenses.

<img className="thumbnail" alt="Pestaña Facturación del producto Backup Licenses" src="/images/storage-and-backup/backup-licenses/control-panel/bl_billing_en.png" loading="lazy" />

:::info
Las tarifas actualizadas están disponibles en la página [tarifas Object Storage](/links/public-cloud/prices-object-storage).

:::

### Solicitar Vaults adicionales

Desde la pestaña <code className="action">Vaults</code> de su área de cliente de OVHcloud, haga clic en <code className="action">Solicitar un vault</code> para añadir un **Vault adicional**. Indique su **nombre** (de 1 a 50 caracteres, únicamente caracteres alfanuméricos y guiones), el **país** y la **región de almacenamiento** deseados, y haga clic en <code className="action">Pedir</code>.

<img className="thumbnail" alt="Ventana de pedido de un vault adicional" src="/images/storage-and-backup/backup-licenses/vault/bl_vault_order_en.png" loading="lazy" />

Funcionan exactamente de la misma manera que el Vault "bundle" (bucket S3, mismos usos, mismas modalidades de acceso), con una diferencia: se **facturan desde el primer GB consumido**, según la tarifa pública del OVHcloud Object Storage. No llevan asociado ningún volumen gratuito.

La siguiente tabla resume las diferencias:

| | Vault "bundle" | Vault adicional |
|---|---|---|
| **Entrega** | Incluido automáticamente con la primera licencia | Solicitado bajo demanda desde el área de cliente |
| **Número** | Uno solo por suscripción | Todos los que sean necesarios |
| **Volumen incluido** | 500 GB gratuitos | Ninguno |
| **Facturación** | A partir del GB 501, según la tarifa pública Object Storage | Desde el primer GB, según la tarifa pública Object Storage |
| **Ciclo de vida** | Eliminado al cancelar el producto Backup Licenses | Cancelable de forma independiente |
