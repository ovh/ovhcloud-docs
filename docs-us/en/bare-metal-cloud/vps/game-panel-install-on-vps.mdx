## Objective

The OVHcloud Game Panel lets you deploy and manage game servers directly on your VPS. Before using it, you must install it on your server from the OVHcloud Console.

**This guide explains how to install the Game Panel on your VPS.**

## Requirements

- A [VPS](https://us.ovhcloud.com/vps/) in your OVHcloud account.
- Access to the [OVHcloud Console](https://console.us.ovhcloud.com/).

## Instructions

### Step 1 — Log in to the OVHcloud Console

Log in to your [OVHcloud Console](https://console.us.ovhcloud.com/). If you need help logging in, refer to [Logging in to the OVHcloud Control Panel](/account/account-information/log-in-console).

### Step 2 — Open your VPS page

From the OVHcloud Console:

1. In the menu at the top of the page, click <code className="action">Bare Metal Cloud</code>.
2. In the left-hand menu, select <code className="action">VPS</code>.
3. In the **Virtual private servers (VPS)** list, click the name of your VPS.

![The VPS list in the Bare Metal Cloud section of the OVHcloud Console](/images/bare-metal-cloud/vps/game-panel-install-on-vps/open-vps-page.png)

### Step 3 — Install the Game Panel

In the **Overview** tab, locate the **General information** section. Under the **Distribution** line, click <code className="action">Reinstall my VPS with Game Panel</code>.

![The Reinstall my VPS with Game Panel link in the General information section of the VPS Overview tab](/images/bare-metal-cloud/vps/game-panel-install-on-vps/reinstall-with-game-panel-entry.png)

:::warning
Installing the Game Panel reinstalls your VPS and formats all its disks. Any data on the server is deleted. To be able to go back, take a [snapshot of your VPS](/bare-metal-cloud/vps/using-snapshots) before you continue.
:::

Fill in the following fields, then start the installation.

![The Reinstall my VPS with Game Panel form](/images/bare-metal-cloud/vps/game-panel-install-on-vps/reinstall-with-game-panel-form.png)

**Choose an operating system**

In the **Operating system** list, select the operating system on which you want to install the Game Panel. All operating systems displayed in the list are fully compatible with the Game Panel.

**Configure the domain name**

By default, the **Domain name** field contains your server's default hostname, allowing you to access the Game Panel through an address similar to `https://vps-xxxx.vps.ovh.us`.

If you prefer, you can use your own domain name instead. Before continuing, make sure your domain's DNS A record points to your VPS public IP address. The form checks where the domain resolves: the message **The domain points to your VPS** confirms the SSL certificate can be issued.

**Enter an email address**

The **Let's Encrypt email address** field is pre-filled with the email address associated with your OVHcloud account. You can replace it with another address. This address is used to set up the SSL certificate and receives certificate-related notifications, including expiry warnings.

**Choose the administrator account name**

In the **Administrator username** field, enter the username for the administrator account that will be created (`admin` by default). This account becomes the super administrator of the Game Panel and has the highest level of privileges.

**Save your generated admin password**

A password for the Game Panel is generated and displayed in the **Administrator password** field. Copy it with the copy icon, or click <code className="action">Generate another</code> to get a new password. Store this password in a safe place, as it cannot be viewed again later.

**(Optional) Add an SSH key**

The **SSH key to pre-install** section lets you pre-install on the server one of the SSH public keys stored in your OVHcloud account. This is an optional advanced configuration. If your account holds no SSH key, add one from the **My account** section of the OVHcloud Console. For more information, refer to [How to store public authentication keys in the OVHcloud Console](/bare-metal-cloud/dedicated-servers/import-keys).

Once a key is selected, the form also displays the <code className="action">I do not wish to receive my VPS authentication codes by email</code> checkbox. If you tick it, you do not receive the email containing your server's SSH password (see Step 4).

**Start the installation**

Click <code className="action">Confirm</code> to begin the installation. This button is only enabled once an operating system is selected and all fields are valid.

### Step 4 — Connect to the Game Panel

The selected operating system is installed first. Once it has been deployed, you receive an automatic email containing the SSH password for your server, unless you ticked the <code className="action">I do not wish to receive my VPS authentication codes by email</code> checkbox. Keep this password in a safe place, as you may need it later if you connect to the server directly via SSH.

A few minutes later, the Game Panel installation completes automatically.

You can then open your server's hostname in a web browser, for example `https://vps-xxxx.vps.ovh.us`. Sign in using the password that was generated during the installation to start using the Game Panel.

:::info
The generated admin password is shown only once during the installation. If you lose it, refer to the password recovery section of [Log in to the Game Panel](/bare-metal-cloud/vps/game-panel-log-in).
:::
