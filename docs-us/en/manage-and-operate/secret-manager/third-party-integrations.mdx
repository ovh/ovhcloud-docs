# Official third-party integrations with OVHcloud Secret Manager

**This guide lists the third-party applications officially integrated with OVHcloud Secret Manager and links to their documentation.**

 

## Objective

OVHcloud maintains dedicated integrations for selected third-party applications that sync or consume secrets stored in Secret Manager. This reference page lists those integrations and links to the documentation you need to set them up.

 

## Requirements

- An [OVHcloud customer account](/account/account-information/create-account).
- An [OKMS domain](/manage-and-operate/kms/quick-start) or [first secret created](/manage-and-operate/secret-manager/use-secret-manager).

 

## Instructions

### Official third-party integrations

The table below is updated as new OVHcloud-maintained integrations are released. Only third-party products with an integration maintained by OVHcloud are listed.

| Third-party product                               | Integration type                                    | Plugin                                                                            | Documentation                                                                                                                                                                                                                                                |
| ------------------------------------------------- | --------------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **External Secrets Operator** (Vault provider)    | Sync Kubernetes secrets via Vault KV2 API on OKMS   | [External Secrets Operator](https://github.com/external-secrets/external-secrets) | [ESO — HashiCorp Vault provider](https://external-secrets.io/latest/provider/hashicorp-vault/) [How to use Kubernetes External Secrets Operator with Secret Manager](/manage-and-operate/secret-manager/external-secret-operator)                       |
| **External Secrets Operator** (OVHcloud provider) | Native OKMS provider (`provider.ovh`, ESO ≥ v2.3.0) | [External Secrets Operator](https://github.com/external-secrets/external-secrets) | [ESO — OVHcloud provider](https://external-secrets.io/latest/provider/ovhcloud/) [Discover the ESO OVHcloud Provider](https://blog.ovhcloud.com/discover-the-external-secret-operator-eso-ovhcloud-provider-to-manage-your-kubernetes-secrets-%f0%9f%8e%89/) |

:::info

The [HashiCorp Vault KV2–compliant API](/manage-and-operate/secret-manager/kv2-api) is an OVHcloud API surface, not a third-party product integration. It is therefore not listed in this table.

:::
