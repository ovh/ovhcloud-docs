# MySQL® - Configure an instance to accept incoming connections

**Learn how to configure your MySQL® instance to accept incoming connections.**

Cloud Databases allow you to focus on building and deploying cloud applications while OVHcloud takes care of the database infrastructure and maintenance in operational conditions.

 

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- Access to the [OVHcloud Console](https://console.us.ovhcloud.com/)
- A MySQL® database running on your OVHcloud Cloud Databases ([this guide](/public-cloud/databases/getting-started) can help you to meet this requirement)

 

## Instructions

### Configure your MySQL[®](#go-further) instance to accept incoming connections

Before establishing a connection, we must verify that our MySQL® instance is properly configured.

Log in to the [OVHcloud Console](https://console.us.ovhcloud.com/#/public-cloud/project) and select your Public Cloud project. In the left-hand menu, click `MySQL` under **Databases**, then click the name of your MySQL® service.

{/* cp-shot: ![Manager database - MySQL configure instance accept incoming connections - step 3](/images/public-cloud/databases/mysql-configure-instance-accept-incoming-connections/manager-database-3.png) */}

 

#### Step 1: Verify your user roles and password

Select the `Users` tab. Verify that you have a user with sufficient rights and a configured password. If you don't remember the user's password, you can either create a new user or regenerate the password of an existing user.

:::warning

**NOTE:** Be careful! By doing so, you will need to update all the places where you already use this user/password pair.

:::

This first user, **avnadmin**, is pre-configured during the service installation and comes with the following grants:

```sql
GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, DROP, RELOAD, PROCESS, REFERENCES, INDEX, ALTER, SHOW DATABASES, CREATE TEMPORARY TABLES, LOCK TABLES, EXECUTE, REPLICATION SLAVE, REPLICATION CLIENT, CREATE VIEW, SHOW VIEW, CREATE ROUTINE, ALTER ROUTINE, CREATE USER, EVENT, TRIGGER ON *.* TO "avnadmin"@"%" WITH GRANT OPTION

GRANT REPLICATION_APPLIER,ROLE_ADMIN ON *.* TO "avnadmin"@"%" WITH GRANT OPTION
```

 

You can add more users by clicking the `Add a user` button.

{/* cp-shot: ![Manager database - MySQL configure instance accept incoming connections - step 2](/images/public-cloud/databases/mysql-configure-instance-accept-incoming-connections/manager-database-2.png) */}

Enter a username, then click `Create`. No role can be set in this form: only a name is required. The password is generated and displayed only once, at creation. Note it down, as it cannot be retrieved later.

{/* cp-shot: ![Manager database - MySQL configure instance accept incoming connections](/images/public-cloud/databases/mysql-configure-instance-accept-incoming-connections/manager-database.png) */}

:::info

You can delete a user or reset its password via the `⋮` button on the row of the user in the users table, then `Delete` or `Reset password`. A user cannot be modified after its creation.

{/* cp-shot: ![Manager database - MySQL configure instance accept incoming connections - step 4](/images/public-cloud/databases/mysql-configure-instance-accept-incoming-connections/manager-database-4.png) */}

:::

 

#### Step 2: Authorize incoming connections from the MySQL® client

:::warning

**NOTE:** For security reasons, the default network configuration doesn't allow any incoming connections. It is thus critical that you authorize suitable IP addresses to successfully access your database.

:::

In this step, select the `Configuration` tab. IP addresses must be authorized here before they can connect to your database.

Click `Add`, enter an IP address or a CIDR block and a description to identify its origin, then click `Save`.

You can also click `Add my current IP` to add the public IP address from which you are browsing the OVHcloud Console. This is convenient for a development workstation, provided your address is static.

{/* cp-shot: ![Manager database - MySQL configure instance accept incoming connections - step 6](/images/public-cloud/databases/mysql-configure-instance-accept-incoming-connections/manager-database-6.png) */}

:::info

If you want to allow connections from the outside, you can enter the IP 0.0.0.0/0. Please use it carefully.

:::

 

#### Collect required information

Select the `Overview` tab to find the required login credentials: host, port, protocol, connection URI and the CA certificate of the service.

{/* cp-shot: ![Manager database - MySQL configure instance accept incoming connections - step 7](/images/public-cloud/databases/mysql-configure-instance-accept-incoming-connections/manager-database-7.png) */}

 

Select the `Databases` tab to get the database name.

{/* cp-shot: ![Manager database - MySQL configure instance accept incoming connections - step 5](/images/public-cloud/databases/mysql-configure-instance-accept-incoming-connections/manager-database-5.png) */}

Select the `Users` tab to get the username.
