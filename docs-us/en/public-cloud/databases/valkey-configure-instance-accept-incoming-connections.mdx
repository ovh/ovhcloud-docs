# Valkey - Configure an instance to accept incoming connections

**Learn how to configure your Valkey instance to accept incoming connections.**

Cloud Databases allow you to focus on building and deploying cloud applications while OVHcloud takes care of the database infrastructure and maintenance in operational conditions.

 

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- Access to the [OVHcloud Console](https://console.us.ovhcloud.com/)
- A Valkey service running on your OVHcloud Cloud Databases ([this guide](/public-cloud/databases/getting-started) can help you to meet this requirement)

 

## Instructions

### Configure your Valkey instance to accept incoming connections

Before making a connection, we need to verify that our Valkey instance is correctly configured.

Log in to the [OVHcloud Console](https://console.us.ovhcloud.com/#/public-cloud/project) and select your Public Cloud project. In the left-hand menu, click `Valkey` under **Databases**, then click the name of your Valkey service.

{/* cp-shot: ![Manager database - Valkey configure instance accept incoming connections - step 2](/images/public-cloud/databases/valkey-configure-instance-accept-incoming-connections/manager-database-2.png) */}

 

#### Step 1: Verify your user roles and password

Select the `Users` tab. Verify that you have a user with sufficient rights and a password. If you don't remember the user's password, you can either create a new user or regenerate the password of an existing user (click the `⋮` button on the row of the user, then `Reset password`). Be careful! By doing so, you will need to update all the places where you already use this user/password pair.

To create a new user, click `Add a user`, enter a username and its rights (**Keys**, **Categories**, **Commands** and **Channels**), then click `Create`.

In our example, we will create a user called *User* and rights for:

- Keys:\
  \* (for *all keys*)
- Commands:\
  **+ping** (for the *ping* command)\
  **+info** (for the *info* command)\
  **+echo** (for the *echo* command)\
  **+get** (for the *get* command)\
  **+set** (for the *set* command)\
  **+client** (for the *client* command)
- Channels:\
  \* (for *all channels*)

{/* cp-shot: ![Manager database - Valkey configure instance accept incoming connections](/images/public-cloud/databases/valkey-configure-instance-accept-incoming-connections/manager-database.png) */}

 

Once created or updated, the user must have the `Active` status in the OVHcloud Console.

To change the rights of an existing user, click the `⋮` button on the row of the user, then `Edit`.

{/* cp-shot: ![Manager database - Valkey configure instance accept incoming connections - step 3](/images/public-cloud/databases/valkey-configure-instance-accept-incoming-connections/manager-database-3.png) */}

:::info

Follow the [Commands Official Documentation](https://redis.io/commands/) to learn more.\
Follow [this guide](/public-cloud/databases/valkey-capabilities-limitations) to learn more about users, roles, capabilities, and limitations.

:::

 

#### Step 2: Authorize incoming connections from the service

:::warning

**NOTE:** For security reasons, the default network configuration doesn't allow any incoming connections. You must authorize suitable IP addresses to successfully access your database.

:::

Select the `Configuration` tab, then go to the **IP restrictions** section. IP addresses must be authorized here before they can connect to your database.

Click `Add`, enter an IP address or a CIDR block and a description to identify its origin, then click `Save`.

You can remove an authorized IP from the same section, then save your changes.

{/* cp-shot: ![Manager database - Valkey configure instance accept incoming connections - step 5](/images/public-cloud/databases/valkey-configure-instance-accept-incoming-connections/manager-database-5.png) */}

:::info

If you want to allow connections from the outside, you can enter the IP 0.0.0.0/0. Please use it carefully.

:::

 

#### Collect required information

Select the `Overview` tab to find the connection details of the service: host, port, protocol and connection URI.

Select the `Users` tab to get the username.
