# Managing your Public Cloud instances

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- A [Public Cloud instance](/public-cloud/compute/getting-started) in your project

### OVHcloud Console access

- **Direct link:** [Public Cloud Projects](https://console.us.ovhcloud.com/#/public-cloud/project)
- **Navigation path:** `Public Cloud` > `Projects` > Select your project > `Compute` > `Instances`

 

## Instructions

### Using the management interface for instances

In the left-hand menu of your Public Cloud project, click `Instances` under **Compute**.

This page lists all your Public Cloud instances and some of their properties:

- The instance name and ID, needed for certain API calls
- The location of the data center, i.e., the region of the instance
- The instance model
- The image, i.e., the OS installed on the instance
- The public IP addresses of the instance
- The private IP addresses currently attached to the instance
- Additional volumes (disks) currently attached to the instance
- The status of the instance, indicating whether it is in the **Active** state

 

### Management options on the instance dashboard

From the instance list, click the name of the instance.

This will take you to the `Overview` tab of the instance. Its **General information** card centralizes the main details of your instance (model, region, image, resources and prices), alongside the **Connection details**, **Public network**, **Private network**, **Snapshot management** and **Storage management** cards. The page also offers the `VNC console`, `Observability` and `Snapshots` tabs.

Most of these operations are also accessible from the instance list via the `⋮` button in the instance table.

 

#### Editing the configuration of the instance

Each item of the instance configuration is edited from the `Overview` tab:

- **Renaming the instance**: Edit the name of the instance in the page header. You can give a name to the instance for easier identification.
- **Changing the image**: In the **General information** card, click `Edit image` on the **Image** row. You can choose a different operating system for the instance. (Note that reinstalling an instance will delete all data stored on it.)
- **Changing the model**: In the **General information** card, click `Modify model` on the **Model** row, then choose the new model on the **Change model** page. Please refer to [this guide](/public-cloud/compute/getting-started) for more information about the options.
- **Changing the billing type**: In the **General information** card, click `Switch to monthly` to change the billing period of the instance from hourly to monthly. Please refer to [this guide](/public-cloud/compute/changing-hourly-monthly-billing) for detailed information.

 

#### Creating a backup of the instance

In the instance list, click `⋮` on the instance row, then select `Create a snapshot`.

Refer to our guide on [taking a snapshot of an instance](/public-cloud/compute/save-an-instance) for more information.

 

#### Deleting an instance

In the instance list, click `⋮` on the instance row, then select `Delete`. You can also click `Delete` at the bottom of the **General information** card of the `Overview` tab.

This will permanently delete the instance, as well as all of the data stored on it.

Confirm the request by clicking `Delete instance` in the **Delete instance** window.

:::warning

**NOTE:** Deleting an instance does not automatically delete all the options associated with it (storage, snapshot, backup, etc.), so make sure that all other options associated with the instance are also deleted to stop being billed.

:::

 

#### Attach a volume

In the **Storage management** card of the `Overview` tab, click `Attach a volume`.

Then select the volume to associate with the instance and click `Attach`. Once attached, the volume is immediately available and can be mounted from the instance's operating system.

 

#### Change the reverse DNS

The reverse DNS of the instance's public IP address is managed with all your IP addresses: in the top bar of the OVHcloud Console, click `Bare Metal Cloud`, then click `IP addresses` under **Network** in the left-hand menu, and open the `Reverse DNS` tab.

 

#### Configure the firewall

The Edge Network Firewall of the instance's public IP address is managed with all your IP addresses: in the top bar of the OVHcloud Console, click `Bare Metal Cloud`, then click `IP addresses` under **Network** in the left-hand menu, and open the `Edge Firewall` tab.

Refer to our [Enabling and configuring the Edge Network Firewall](/bare-metal-cloud/dedicated-servers/firewall-network) guide for more information.

 

#### Manage private networks

In the **Private network** card of the `Overview` tab, click `Manage my private network`.

Refer to our [Creating a private network with Gateway](/public-cloud/network-services/create-private-network-gateway) guide for more information.

 

#### Attach a network

In the **Private network** card of the `Overview` tab, click `Attach a network`.

Select the desired network from the drop-down list, then click `Confirm`.

 

#### Additional actions

In the **General information** card of the `Overview` tab, click `Additional actions`. The same actions are available in the instance list, via the `⋮` button of the instance row.

 

**Creating an automatic backup of an instance**

In the instance list, click `⋮` on the instance row, then select `Create an automatic snapshot`.

Refer to our [Taking a snapshot of an instance](/public-cloud/compute/save-an-instance) guide for more information.

 

**Stop the instance**

Click on `Hard stop`, then click `Confirm` in the window that opens.

This will put the instance in the **Hard stop (Shutoff)** state: the data on the disk is preserved, but the memory state is lost, and you will still be charged the same price for your instance. Refer to our [Shelve or pause an instance](/public-cloud/compute/suspend-or-pause-an-instance) guide for detailed information.

Click on `Start` to restart the instance.

 

**Using rescue mode**

Click on `Reboot in rescue mode`, then click `Confirm` in the window that opens.

This will activate rescue mode for the instance. Refer to our guide on [putting an instance in rescue mode](/public-cloud/compute/activating-rescue-mode-public-cloud-instance) for detailed information.

 

**Restarting the instance**

**Shelving the instance**

Click on `Shelve`, then click `Confirm` in the window that opens.

This will put the instance in the **Shelve** state. Consult our [Shelve or pause an instance](/public-cloud/compute/suspend-or-pause-an-instance) guide to learn more about the different states.

Click on `Unshelve` to restore the **Active** state.

 

**Reinstalling an instance**

Click on `Reinstall`, then click `Confirm` in the window that opens.

This action will reinstall the instance with the same operating system, provided the image is still supported. **Please note that if you choose to reinstall, all of the data currently stored on your instance will be erased.**

Note that reinstalling **deletes all data** currently stored on your instance.

 

### Accessing the VNC console

In the left-hand menu of your Public Cloud project, click `Instances` under **Compute**, then click on the name of the instance in the table.

Open the `VNC console` tab.

{/* cp-shot: ![Instances vnc console tab](/images/public-cloud/compute/first-steps-with-public-cloud-instance/instances-vnc-console-tab.png) */}

The VNC console provides direct access to your instance. For this access to work, configure a username and password on the instance first.

Consult our [getting started guide](/public-cloud/compute/getting-started#54-vnc-console-access) to learn more about the necessary steps.
