# Activating rescue mode on a Public Cloud instance

**Learn how to restart your OVHcloud Public Cloud instance in rescue mode and access your files.**

Your Public Cloud instance may become inaccessible due to a lost SSH key or configuration errors. In such circumstances, you can use the rescue mode to reconfigure your instance or to recover your data.

 

## Requirements

- A [Public Cloud instance](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- Access to the [OVHcloud Console](https://console.us.ovhcloud.com/)

 

## Instructions

### Step 1: Activating rescue mode

From the [OVHcloud Console](https://console.us.ovhcloud.com/#/public-cloud/project):

1. Select your Public Cloud project.
2. In the left-hand menu of your project, click `Instances` under **Compute**.
3. Click `⋮` in the row of your instance.
4. Select `Reboot in rescue mode`.

{/* cp-shot: ![Compute - Activating rescue mode public cloud instance - step 1](/images/public-cloud/compute/activating-rescue-mode-public-cloud-instance/compute-01.png) */}

ic In the **Reboot in rescue mode** window, select the distribution you would like to use in rescue mode in the drop-down list (the OVHcloud rescue distribution is preselected), then click the `Confirm` button.

{/* cp-shot: ![Compute - Activating rescue mode public cloud instance - step 2](/images/public-cloud/compute/activating-rescue-mode-public-cloud-instance/compute-02.png) */}

A message confirms that the instance is rebooting in rescue mode.

{/* cp-shot: ![Compute - Activating rescue mode public cloud instance - step 3](/images/public-cloud/compute/activating-rescue-mode-public-cloud-instance/compute-03.png) */}

Your temporary **rescue mode password** will only be shown in the VNC console. Click on your instance in the table, then switch to the `VNC console` tab to retrieve it.

{/* cp-shot: ![Compute - Activating rescue mode public cloud instance - step 5](/images/public-cloud/compute/activating-rescue-mode-public-cloud-instance/compute-05.png) */}

 

### Step 2: Accessing your data

When rescue mode has been activated, your instance's data will be attached as an additional disk. You will now need to mount it, by taking the following steps.

First, establish an SSH connection to your instance. Once you are connected, verify the available disks with this command:

```
lsblk
```

The result will look similar to the following:

```
NAME    MAJ:MIN RM  SIZE  RO TYPE  MOUNTPOINT
sda     253:0   0     1G  0  disk
└─sda1  253:1   0  1023M  0  part  /
sdb     253:16  0    10G  0  disk
└─sdb1  253:17  0    10G  0  part
```

In rescue mode, `sda` is the rescue mode disk and `sda1` is the primary rescue partition mounted on `/`.

In this example, the primary disk is `sdb` and the system partition is `sdb1` (indicated by the larger size).

Next, mount the partition:

```bash
mount /dev/sdb1 /mnt/
```

Your data will now be accessible from the `/mnt` folder.

 

### Step 3: Deactivating rescue mode

Once you have completed your tasks, you can deactivate rescue mode by rebooting your instance from the OVHcloud Console. To execute this, click `⋮` in the row of the instance and select `Exit rescue mode`, then click `Confirm` in the window that opens.

{/* cp-shot: ![Compute - Activating rescue mode public cloud instance - step 6](/images/public-cloud/compute/activating-rescue-mode-public-cloud-instance/compute-06.png) */}

:::warning

**NOTE:** If the `Exit rescue mode` button is not displayed while the instance is in rescue mode, we recommend that you refresh your browser tab.

:::

 

### Activating rescue mode using the OpenStack API

You can also activate rescue mode via the OpenStack API using the following command:

```
nova rescue <INSTANCE_ID>
```

To exit rescue mode, use the following command:

```
nova unrescue <INSTANCE_ID>
```
