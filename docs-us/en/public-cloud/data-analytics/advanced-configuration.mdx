# Analytics - Advanced configuration

## Objective

**Learn about the advanced configuration options available for Analytics through the OVHcloud Console and via API.**

Analytics engines are managed services, which means that they are not fully configurable.

:::info

Advanced configuration is available for the following Analytics engines:

- Managed Dashboards (Grafana®)
- Kafka®
- Kafka® Connect
- OpenSearch™

:::

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- An Analytics service running in your OVHcloud account ([this guide](/public-cloud/data-analytics/getting-started) can help you to meet this requirement)
- Access to the [OVHcloud API](https://api.us.ovhcloud.com/)

#### OVHcloud Console access

- **Direct link:** [Public Cloud projects](https://console.us.ovhcloud.com/#/public-cloud/project)
- **Navigation path:** `Public Cloud` > Select your project > **Analytics** group

## Instructions

:::warning

**NOTE:** Please note that changes to the advanced settings apply at the cluster level and therefore to all the Analytics services in the cluster.

:::

:::info

Depending on the engine, some settings may already be defined.

:::

:::info

Once the advanced configuration has been submitted, it is not possible to reset it to initial values. It is only possible to update the values, so we recommend that you take note of the initial values before changing them.

To verify the values you submitted, see the [Get the existing advanced configuration](#get-the-existing-advanced-configuration) section below.

:::

### Using the OVHcloud Console

In the left-hand menu of your Public Cloud project, click your product under **Analytics**, then click the name of your service. Open the `Configuration` tab and locate the **Advanced configuration** section.

Select the parameter you want to define in **Add a parameter** (you can search for it), click `Add`, then set its value.

When ready, click `Save`. Changing the advanced configuration may restart the cluster.

:::info

The settings which are already defined are listed in the **Advanced configuration** section.

:::

### Using API

:::info

If you are not familiar with using the OVHcloud API, please refer to our guide on [First Steps with the OVHcloud API](/manage-and-operate/api/first-steps).

:::

#### Get your service and cluster IDs

You first need to identify the service and the cluster to which you want to apply the changes.

##### Get the desired service ID

Execute the following API call:

<Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project"} regions={["us"]} />

From the resulting list, select and copy the service identifier corresponding to the desired service, also known as serviceName.

##### Get the desired cluster ID

Open the following API call, paste your service ID into the `serviceName` input field and click `Execute`:

| Engine         | API call |
| -------------- | -------- |
| Dashboards     | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/grafana"} regions={["us"]} /> |
| Kafka®         | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/kafka"} regions={["us"]} /> |
| Kafka® Connect | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/kafkaConnect"} regions={["us"]} /> |
| OpenSearch™    | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/opensearch"} regions={["us"]} /> |

From the resulting list, select and copy the cluster ID, also known as clusterId.

#### Get the existing advanced configuration

Open the following API call, paste the corresponding inputs (**serviceName**, **clusterId**), and click `Execute`:

| Engine         | API call |
| -------------- | -------- |
| Dashboards     | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/grafana/\{clusterId\}/advancedConfiguration"} regions={["us"]} /> |
| Kafka®         | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/kafka/\{clusterId\}/advancedConfiguration"} regions={["us"]} /> |
| Kafka® Connect | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/kafkaConnect/\{clusterId\}/advancedConfiguration"} regions={["us"]} /> |
| OpenSearch™    | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/opensearch/\{clusterId\}/advancedConfiguration"} regions={["us"]} /> |

#### Advanced configuration settings list

Open the following API call, paste the corresponding inputs (**serviceName**, **clusterId**), and click `Execute`:

| Engine         | API call |
| -------------- | -------- |
| Dashboards     | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/grafana/\{clusterId\}/capabilities/advancedConfiguration"} regions={["us"]} /> |
| Kafka®         | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/kafka/\{clusterId\}/capabilities/advancedConfiguration"} regions={["us"]} /> |
| Kafka® Connect | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/kafkaConnect/\{clusterId\}/capabilities/advancedConfiguration"} regions={["us"]} /> |
| OpenSearch™    | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/opensearch/\{clusterId\}/capabilities/advancedConfiguration"} regions={["us"]} /> |

#### Change advanced configuration

Open the following API call and paste the corresponding inputs (**serviceName**, **clusterId**):

| Engine         | API call |
| -------------- | -------- |
| Dashboards     | <Api version="v1" section="/cloud/project" method="PUT" route={"/cloud/project/\{serviceName\}/database/grafana/\{clusterId\}/advancedConfiguration"} regions={["us"]} /> |
| Kafka®         | <Api version="v1" section="/cloud/project" method="PUT" route={"/cloud/project/\{serviceName\}/database/kafka/\{clusterId\}/advancedConfiguration"} regions={["us"]} /> |
| Kafka® Connect | <Api version="v1" section="/cloud/project" method="PUT" route={"/cloud/project/\{serviceName\}/database/kafkaConnect/\{clusterId\}/advancedConfiguration"} regions={["us"]} /> |
| OpenSearch™    | <Api version="v1" section="/cloud/project" method="PUT" route={"/cloud/project/\{serviceName\}/database/opensearch/\{clusterId\}/advancedConfiguration"} regions={["us"]} /> |

Now, according to the settings you chose, set the different values into the string arrays, such as in the example below:

![DBaaS advconfig - step 5](/images/public-cloud/databases/advanced-configuration/dbaas-advconfig-05.png)

When ready, click `Execute` to update the advanced configuration.
