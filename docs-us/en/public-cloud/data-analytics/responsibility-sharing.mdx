# Analytics - Responsibility sharing

Analytics services allow you to focus on building and deploying cloud applications while OVHcloud takes care of the engine infrastructure and maintenance in operational conditions.

The RACI below details shared responsibilities between OVHcloud and the customer for Analytics services. This shared model can help relieve the customer’s operational burden.

## RACI definition

| Roles |
| --- |
| R: Is in charge of carrying out the process |
| A: Guarantees the successful completion of the process |
| C: Is consulted during the process |
| I: Is informed of the results of the process |

For your information, a **Service** is considered an Analytics service[\*](#go-further) such as Kafka®, Kafka Connect, Kafka MirrorMaker, OpenSearch, or Managed Dashboards (Grafana®).
