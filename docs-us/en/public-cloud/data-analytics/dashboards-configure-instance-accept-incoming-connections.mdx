# Dashboards - Configure your Dashboards instance to accept incoming connections

**Learn how to configure your Dashboards instance to accept incoming connections.**

Cloud Analytics allow you to focus on building and deploying cloud applications while OVHcloud takes care of the engine infrastructure and maintenance in operational conditions.

 

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- Access to the [OVHcloud Console](https://console.us.ovhcloud.com/)
- A Dashboards service running on your OVHcloud Cloud Analytics ([this guide](/public-cloud/databases/getting-started) can help you to meet this requirement)

 

## Instructions

### Configure your Dashboards instance to accept incoming connections

Before making a connection, we need to verify that our Dashboards instance is correctly configured.

From the [OVHcloud Console](https://console.us.ovhcloud.com/#/public-cloud/project), select your Public Cloud project. In the left-hand menu of your Public Cloud project, click `Managed Dashboards` under **Analytics**, then click the name of your Dashboards instance.

 

#### Step 1: Verify your user roles and password

Select the `Users` tab. Click the `⋮` button on the row of your user, then `Reset password`.

{/* cp-shot: ![Users - Dashboards configure dashboards instance accept incoming connections](/images/public-cloud/data-analytics/dashboards-configure-instance-accept-incoming-connections/users.png) */}

 

#### Step 2: Authorize incoming connections to your Dashboards instance

:::warning

**NOTE:** For security reasons, the default network configuration doesn't allow any incoming connections. It is thus critical that you authorize suitable IP addresses to successfully access your service.

:::

In this step, open the `Configuration` tab and locate the IP restrictions section. IP addresses must be authorized here before they can connect to your service.

Click `Add`, enter the IP address or IP block you wish to authorize, then click `Save`.

{/* cp-shot: ![Dashabords - Dashboards configure dashboards instance accept incoming connections](/images/public-cloud/data-analytics/dashboards-configure-instance-accept-incoming-connections/dashabords.png) */}

You can remove an authorized IP from the same section.

:::info

If you want to allow connections from the outside, you can enter the IP 0.0.0.0/0. Please use it carefully.

:::

 

### Connect to your Dashboards instance

From the [OVHcloud Console](https://console.us.ovhcloud.com/#/public-cloud/project), select your Public Cloud project. In the left-hand menu of your Public Cloud project, click `Managed Dashboards` under **Analytics**, then click the name of your Dashboards instance.

In the `Overview` tab, retrieve the URI of your service from the connection details card.

{/* cp-shot: ![Dashboards configure dashboards instance accept incoming connections](/images/public-cloud/data-analytics/dashboards-configure-instance-accept-incoming-connections/dashboard.png) */}

Then connect to your Dashboards instance:

![Grafana - Dashboards configure dashboards instance accept incoming connections](/images/public-cloud/data-analytics/dashboards-configure-instance-accept-incoming-connections/grafana.png)

:::tip

**Congratulations!** You are now connected to your Grafana[®](#go-further) instance.

:::

![Grafana - Dashboards configure dashboards instance accept incoming connections - step 2](/images/public-cloud/data-analytics/dashboards-configure-instance-accept-incoming-connections/grafana-2.png)

Learn more about Grafana® in the following tutorial: [Grafana® fundamentals](https://grafana.com/tutorials/grafana-fundamentals/?utm_source=grafana_gettingstarted).
