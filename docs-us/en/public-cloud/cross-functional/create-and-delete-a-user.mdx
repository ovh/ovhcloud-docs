# Managing OpenStack users

**Learn how to manage OpenStack users in the OVHcloud Console.**

Access to Horizon and the OpenStack APIs is established via username/password pairs called "OpenStack users". You can create as many OpenStack users as needed and assign them various access permissions.

 

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- Access to the [OVHcloud Console](https://console.us.ovhcloud.com/#/public-cloud/project), then select your Public Cloud project

 

## Instructions

### Creating an OpenStack user

Log in to the [OVHcloud Console](https://console.us.ovhcloud.com/#/public-cloud/project) and select your Public Cloud project. In the left-hand menu, click `Project Management`, then the `Users` tab.

Click `Create a user`.

{/* cp-shot: ![OpenStack users - Create and delete a user - step 1](/images/public-cloud/cross-functional/create-and-delete-a-user/openstack-users-01.png) */}

In the user description field, enter a description. The user description is not the username for the OpenStack user but a descriptive term to help you organize users and their permissions.

{/* cp-shot: ![OpenStack users - Create and delete a user - step 2](/images/public-cloud/cross-functional/create-and-delete-a-user/openstack-users-02.png) */}

In the roles section, select the user roles representing the permissions the user shall have.

For each box checked, the user will gain access privileges according to the table below. To see the privileges granted by each role, click `Show role matrix` on the `Users` tab.

{/* cp-shot: ![OpenStack users - Create and delete a user - step 3](/images/public-cloud/cross-functional/create-and-delete-a-user/openstack-users-03.png) */}

Click `Create` to create the OpenStack user.

{/* cp-shot: ![OpenStack users - Create and delete a user - step 4](/images/public-cloud/cross-functional/create-and-delete-a-user/openstack-users-04.png) */}

The username and password will be automatically generated: the password is displayed in the credentials window and the username in the users table. Be sure to save the password to a password manager at this time. The password cannot be recovered afterward. Copy it with the `Copy` button, then click `Close`.

{/* cp-shot: ![OpenStack users - Create and delete a user - step 5](/images/public-cloud/cross-functional/create-and-delete-a-user/openstack-users-05.png) */}

You can edit the roles of a user at any time from the `⋮` menu on the user's row. The `Show role matrix` button will display the access privileges of each role.

{/* cp-shot: ![OpenStack users - Create and delete a user - step 7](/images/public-cloud/cross-functional/create-and-delete-a-user/openstack-users-07.png) */}

With the OpenStack user created, you can use its credentials to log into the [Horizon interface](/public-cloud/cross-functional/introducing-horizon) by clicking `⋮` on the user's row, then `Launch OpenStack Horizon`.

 

### Change an OpenStack user password

You can always create a new password by clicking `⋮` on the user's row, selecting `Generate a password`, then clicking `Generate`.

{/* cp-shot: ![OpenStack users - Create and delete a user - step 6](/images/public-cloud/cross-functional/create-and-delete-a-user/openstack-users-06.png) */}

If you would like to choose your new password, you can do so from the [Horizon interface](/public-cloud/cross-functional/introducing-horizon).

Select your `username` in the upper right corner and then `⛭Settings` .

![Compute OpenStack users - step 10](/images/public-cloud/cross-functional/create-and-delete-a-user/compute-openstack-users-10.png)

Select `Change Password` from the left-hand menu. Type in your current password and the new password you wish to use.

:::info

When you change your password, please ensure that it meets the following criteria:

- The password must contain a minimum of eight characters.
- The password must contain a maximum of 30 characters.
- The password must contain at least one upper-case letter.
- The password must contain at least one lower-case letter.
- The password must contain at least one number.
- The password must only contain letters and numbers.

:::

When you have chosen your new password, click `Change`.

![Compute OpenStack users - step 11](/images/public-cloud/cross-functional/create-and-delete-a-user/compute-openstack-users-11.png)

 

### Deleting an OpenStack user

Log in to the [OVHcloud Console](https://console.us.ovhcloud.com/#/public-cloud/project) and select your Public Cloud project. In the left-hand menu, click `Project Management`, then the `Users` tab.

{/* cp-shot: ![OpenStack users - Create and delete a user - step 8](/images/public-cloud/cross-functional/create-and-delete-a-user/openstack-users-08.png) */}

Click `⋮` on the user's row and select `Delete`, then click `Confirm`.

:::warning

**NOTE:** Deleting a user is permanent and will invalidate all associated tokens, even those with an expiry date not yet exceeded.

:::

{/* cp-shot: ![OpenStack users - Create and delete a user - step 9](/images/public-cloud/cross-functional/create-and-delete-a-user/openstack-users-09.png) */}
