# How to use the Public Cloud interface

|                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Free trial:** Create your first Public Cloud project and get **$200** free credit\[1]. [Get started now!](https://console.us.ovhcloud.com/) |

You have just created your Public Cloud project, and you would like to find out more about the user interface in the OVHcloud Console.

 

## Requirements

- A [Public Cloud project](/public-cloud/cross-functional/create-a-public-cloud-project)

#### OVHcloud Console access

- **Direct link:** [Public Cloud projects](https://console.us.ovhcloud.com/#/public-cloud/project)
- **Navigation path:** `Public Cloud` > `Projects` > Select your project

 

## Instructions

Once you have created your first Public Cloud project, you are redirected to its home page in the OVHcloud Console. The page title is the name of your project.

The home page is made up of widgets. You can remove a widget with the icon in its top-right corner, add one with `Add a widget` and restore the default layout with `Reset layout`.

 

### Your Public Cloud project

Since you can manage multiple projects according to your quotas, the name of the current project is always displayed in the `Project` selector at the top of the left-hand menu, regardless of the screen you are viewing. This lets you know which environment you are working in.

The ID may be required when using the CLI, for certain support requests, etc. To copy it:

1. At the top of the left-hand menu, click the `Project` selector. The list of your projects opens, with the ID of each project under its name.
2. Click the copy icon on the row of your project.

To rename your project:

1. In the left-hand menu, click `Project Management`.
2. Click the `Settings` tab.
3. In the project name field, enter the new name.
4. Click `Confirm`.
 

### The Public Cloud main menu

The left-hand menu of your project groups the Public Cloud products by section. Click a section to display its products.

| Section                        | Options description                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| **Compute**                    | This section allows you to launch instances, which are cloud servers available on demand.                    |
| **Network**                    | This section allows you to connect your Public Cloud resources to each other and to other OVHcloud products. |
| **Storage**                    | Here you will find various storage solutions, each tailored to specific needs.                               |
| **Containers**                 | This section offers tools to automate your architectures and improve flexibility.                            |
| **Databases**                  | This section offers managed databases.                                                                       |
| **Analytics**                  | These services help you manage your Big Data and data analysis challenges.                                   |
| **AI**                         | Here you will find OVHcloud tools dedicated to artificial intelligence.                                      |

Below these sections, the **Project Management** and **Cost center** links give access to the project's management tools (see [Management tools](#management-tools)).

At the top of the menu, click `My services` to list only the services created in your project, and `Products` to come back to the full list.

 

### Shortcuts

The Quick access widget of the project home page provides shortcuts to the most useful configuration wizards, such as `Create an instance`, `Create a cluster` or `Create a private network`. Guides are available in the Documentation and support widget.

 

#### Assistance for the creation of resources

For each resource you want to create, a configuration page guides you through the settings, section by section, so that you can set up the resource according to your needs.

Most of the time, you will have to choose the location of the resource (its region), the model, some customizable settings, and (in some cases) the billing method. For example, the page for creating an instance groups the instance name, the region, the model, the storage, the image, the SSH key, the backup, network and advanced settings, then the `Create my instance` button.

 

### Management tools

In your Public Cloud project, several management tools are available to configure your resources, users, and settings. You can access them from the two links at the bottom of the left-hand menu, below the product sections: `Project Management`, which includes the project configuration options (users, quotas, locations, SSH keys, logs, settings), and `Cost center`, which includes billing.

To open the Horizon interface, click `OpenStack Horizon` in the Documentation and support widget of the project home page. Horizon is the [graphical interface](/public-cloud/cross-functional/introducing-horizon) usually available on OpenStack. It is not altered, which allows users who are used to this interface to easily navigate it.

The `Project Management` link opens the following tabs:

| Tab | Description |
| --- | --- |
| SSH keys | A tool that allows you to [manage your SSH keys](/public-cloud/compute/creating-ssh-keys) in a centralized way. |
| Quotas | Based on certain criteria (number of bills already paid, use of other OVHcloud products), our system sets quotas (limits) on the number of resources you can create, to avoid any outstanding amounts. By default, the system increases your quotas automatically when certain criteria are met. However, you can [manually increase a quota](/public-cloud/cross-functional/increasing-public-cloud-quota) from this tab. |
| Locations | Public Cloud is available in several locations around the United States, including OVHcloud data centers in Vint Hill, Virginia, and Hillsboro, Oregon, as well as several [Local Zones](/public-cloud/compute/getting-started-local-zones). |
| Logs | Allows you to view the logs of your project and to forward them to Logs Data Platform. |
| Users | Allows you to [create users](/public-cloud/cross-functional/create-and-delete-a-user) and assign them a role. These users can also access the APIs or the Horizon interface directly. For example, you can create a user for your standard maintenance operations and a user for your automation tools, such as Terraform. |
| Settings | With this tab, you can configure the project’s general settings, such as its name, its configuration as a "default project for the account", HDS compatibility, or [delete your Public Cloud project](/public-cloud/cross-functional/delete-a-project). |

The `Cost center` link opens the following tabs:

| Tab | Description |
| --- | --- |
| Current usage, estimate of your next invoice, history | Since the Public Cloud is based on *pay-as-you-go*, invoices are issued at the end of the month. In these tabs, you can track your current usage, see a forecast for the next invoice, and see your previous invoices. |
| Savings Plan | This is a pricing model that offers discounts on specific resources when you opt for a commitment period of 12 or 36 months. |
