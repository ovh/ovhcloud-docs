# Deleting a Public Cloud Project

**Learn how to delete a Public Cloud project.**

When you no longer need your [Public Cloud](https://us.ovhcloud.com/public-cloud/) project, you can delete it directly from the [OVHcloud Console](https://console.us.ovhcloud.com/).

When you delete your Public Cloud project, a final invoice is issued for the outstanding amount.

:::warning

**NOTE:** Please note that deleting a project is not the same as deactivating your Public Cloud instances. When you delete a project, the resources contained in it will be permanently lost. This action can not be undone.

:::

 

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- Access to the [OVHcloud Console](https://console.us.ovhcloud.com/)

 

## Instructions

Log in to the [OVHcloud Console](https://console.us.ovhcloud.com/#/public-cloud/project) and select your Public Cloud project.

In the left-hand menu of your Public Cloud project, click `Project Management`, then click the `Settings` tab.

In the **Delete project** section, click `Delete project`.

{/* cp-shot: ![Manager project delete](/images/public-cloud/cross-functional/delete-a-project/manager-project-delete.png) */}

The **Cancel project** window appears, informing you about the removal of the project's resources, with the exception of any Additional IP addresses attached. Click `Yes, cancel` to proceed.

{/* cp-shot: ![Manager confirm cancel](/images/public-cloud/cross-functional/delete-a-project/manager-confirm-cancel.png) */}

When you click on the button, you will receive a "success" message, but **your project is not deleted yet**.

{/* cp-shot: ![Manager banner - Delete a project](/images/public-cloud/cross-functional/delete-a-project/manager-banner.png) */}

:::warning

**NOTE:** The project is not immediately deleted. In situations where this may affect the creation of new projects on accounts with limited project quotas, please [contact our support team](/account/account-information/contact-us-support) for further assistance.

:::
