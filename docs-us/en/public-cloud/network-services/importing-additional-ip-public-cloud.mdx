# Importing an Additional IP

**Learn how to import Additional IP addresses into your OVHcloud Public Cloud project.**

|                                                                                                                                                                                    |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Since October 6th, 2022 our service "Failover IP" is named [Additional IP](https://us.ovhcloud.com/network/additional-ip/). This renaming has no effect on its technical features. |

You might need to configure an Additional IP address on your instances because:

- You have multiple websites on your instance.
- You host international projects.
- You want to migrate from a Dedicated Server to a Public Cloud instance.

Instead of buying more public IP addresses, you can import an Additional IP address that is linked to a different OVHcloud service.

 

## Requirements

- a [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- access to the [OVHcloud Console](https://console.us.ovhcloud.com/)
- an [Additional IP address](https://us.ovhcloud.com/network/additional-ip/)

 

## Instructions

From the [OVHcloud Console](https://console.us.ovhcloud.com/#/public-cloud/project), select your Public Cloud project.

1. In the left-hand menu, open `Public IP` under **Network**.
2. Open the `Additional IP` tab.
3. Click `Actions` and select `Import an Additional IP` to display all the IP addresses that can be imported into your Public Cloud project.

{/* cp-shot: ![Network OpenStack import - step 1](/images/public-cloud/network-services/importing-additional-ip-public-cloud/network-op-import-01.png) */}

 

If you do not currently have an Additional IP on your Public Cloud project, the option to import one will be displayed on the homepage.

Click `⋮` on the row of the IP address you would like to import and click `Import this Additional IP`.

{/* cp-shot: ![Network OpenStack import - step 2](/images/public-cloud/network-services/importing-additional-ip-public-cloud/network-op-import-02.png) */}

 

Confirm by clicking `Import`.

{/* cp-shot: ![Network OpenStack import - step 3](/images/public-cloud/network-services/importing-additional-ip-public-cloud/network-op-import-03.png) */}

 

Allow a few minutes for the import process to complete. Open the `Additional IP` tab to find the imported Additional IP address. Refresh the page if necessary.

Click `⋮` on the row of the IP address and select `Update attached instance`.

{/* cp-shot: ![Network IP import - step 4](/images/public-cloud/network-services/importing-additional-ip-public-cloud/network-ip-import-04.png) */}

 

In the panel that appears, choose the instance to which your IP address should be attached.

Click `Attach` to confirm.

{/* cp-shot: ![Network IP import - step 5](/images/public-cloud/network-services/importing-additional-ip-public-cloud/network-ip-import-05.png) */}

 

:::warning
An Additional IP cannot be moved between different zones.

:::

The IP address is now associated with your instance. The next step will be the IP configuration in your OS; please refer to our [guide](/public-cloud/network-services/configuring-additional-ip-public-cloud).
