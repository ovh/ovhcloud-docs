# How to Install OVHcloud Connect Provider from the OVHcloud Control Panel

## Objective

With OVHcloud Connect, you can link your company network to your private OVHcloud vRack network, without creating a VPN tunnel through the internet. This will give you a quicker, more stable connection with guaranteed bandwidth.

**This guide will show you how to set up the OVHcloud Connect Provider solution via the OVHcloud Control Panel**

## Requirements

:::warning

To ensure correct operation of this service, you must be aware of the [technical capabilities and limitations of the OVHcloud Connect solution](/guides/network/ovhcloud-connect/technical-capabilities-limitations) and configure your network devices accordingly.

:::

- An [OVHcloud Connect Provider solution](https://us.ovhcloud.com/network/ovhcloud-connect/)
- An OVHcloud vRack
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)

## Instructions

### Step 1: Ordering your solution

Once you have ordered your OVHcloud Connect Provider solution, you will receive an order confirmation via email, along with a service key.

Depending on the provider you have chosen, go to their portal to log in via the link provided in the order confirmation email. Then enter your service key and confirm the order presented to you.

Next, check the activation status of your solution in the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/). To do this, go to the `Bare Metal Cloud` section and click on `Network`. Next, open `OVHcloud Connect` and click on your solution. Your solution’s status should have changed to “Active”.

### Step 2: Associating a vRack

Log in to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), go to the `Bare Metal Cloud` section and click on `Network`. Next, open `OVHcloud Connect` and click on your solution.

![OVHcloud Connect provider - Install provider from control panel - step 1](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-1.png)

You will need to link a vRack to your solution first. Click the `Attach a vRack` button and select an existing vRack from the drop-down menu.

![OVHcloud Connect provider - Install provider from control panel - step 2](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-2.png)

A message will confirm the vRack association.

### Step 3: Adding a PoP configuration

:::warning

The OVHcloud Connect Provider solution requires an L3 level configuration.

:::

Once you have connected your vRack, click `Add a PoP configuration` and select the L3 configuration from the drop-down menu.

![OVHcloud Connect provider - Install provider from control panel - step 3](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-3.png)

You will then need to enter the following:

![OVHcloud Connect provider - Install provider from control panel - step 4](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-4.png)

![OVHcloud Connect provider - Install provider from control panel - step 5](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-5.png)

The `PoP configuration` menu will then appear.

![OVHcloud Connect provider - Install provider from control panel - step 6](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-6.png)

### Step 4: Adding a data center configuration

When your PoP configuration has been set, click `Add a configuration` under the `DC configuration` menu.

![OVHcloud Connect provider - Install provider from control panel - step 7](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-7.png)

Select a data center from the dropdown menu, then enter the information required.

![OVHcloud Connect provider - Install provider from control panel - step 8](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-8.png)

![OVHcloud Connect provider - Install provider from control panel - step 9](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-9.png)

You can add additional data center configurations by clicking on the `...` button, then `Add a configuration`.

![OVHcloud Connect provider - Install provider from control panel - step 10](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-10.png)

You must also add a routing configuration.

##### **Adding a routing configuration**

Click on the `...` button on the desired data center then on `Add routing configuration`.

![OVHcloud Connect provider - Install provider from control panel - step 11](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-11.png)

Then choose the routing type between Static and BGP.

![OVHcloud Connect provider - Install provider from control panel - step 12](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-12.png)

If you choose the BGP type, then enter the required information:

![OVHcloud Connect provider - Install provider from control panel - step 13](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-13.png)

![OVHcloud Connect provider - Install provider from control panel - step 14](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-14.png)

If you choose the Static type, enter the required information:

![OVHcloud Connect provider - Install provider from control panel - step 15](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-15.png)

![OVHcloud Connect provider - Install provider from control panel - step 16](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-16.png)

You can add multiple routing configurations within the same data center. The configuration type (BGP or Static) chosen for your first configuration will then apply to the next configuration in the same data center.

![OVHcloud Connect provider - Install provider from control panel - step 17](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-17.png)

### Deletion of vCenter resources

Each resource (PoP or DC) can be deleted individually, but deleting a parent resource such as DC or POP will automatically delete all the subresources.

Recursive removal is slower than sequential removal of each resource.

:::info

If a DC configuration is shared between two or more OVHcloud Connect services, removing the PoP configuration from a single OVHcloud Connect service will not affect the DC resource.

:::

#### Deleting a Routing Configuration

To delete a routing configuration, click the `...` button on the routing configuration to delete, then click `Delete`.

![OVHcloud Connect provider - Install provider from control panel - step 18](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-18.png)

#### Deleting a DC configuration

To delete a DC configuration, click the `...` button on the DC configuration to delete, then click `Delete`.

![OVHcloud Connect provider - Install provider from control panel - step 19](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-19.png)

:::info

Deleting a DC configuration will delete the related routing configurations.

:::

#### Enabling the configuration

To delete a PoP configuration, click the `...` button on the PoP configuration, then click `Delete configuration`.

![OVHcloud Connect provider - Install provider from control panel - step 20](/images/network/ovhcloud-connect/install-provider-from-control-panel/occ-provider-20.png)

:::info

Deleting a PoP configuration will delete the DC and routing configurations.

:::
