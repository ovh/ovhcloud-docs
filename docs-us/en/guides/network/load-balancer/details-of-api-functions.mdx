# Details of API functions

**This guide provides detailed descriptions of all API functions for the OVHcloud Load Balancer.**

 

## Requirements

- Consult our [First steps with the OVHcloud API](https://support.us.ovhcloud.com/hc/en-us/articles/360018130839) guide to familiarize yourself with the OVHcloud APIv6.

 

## Instructions

### Manage your OVHcloud Load Balancer service via the API

All API calls that are made in the section */ipLoadbalancing* are available in the [OVHcloud API](https://api.us.ovhcloud.com/console/#/ipLoadbalancing).

:::info

In the calls below, all fields marked with an asterisk `*` are mandatory.

:::

:::info

The Front-ends, Server clusters (Farms), and Servers are specific to the protocol (HTTP or TCP) in which they are defined. Compatibility between these components is only possible within the same protocol. For example, an HTTP Front-end can only be paired with an HTTP Server cluster (Farm) and cannot be used with a TCP Server cluster (Farm).

:::

### Routes HTTP

Routes are evaluated one by one, testing their routing rules. The first route validating all its rules sees its action executed, and stops the evaluation of the remaining routes. The order of execution is defined by the type and weight of the route.
