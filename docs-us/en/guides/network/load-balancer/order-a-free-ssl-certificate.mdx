# Order a free SSL certificate

The OVHcloud Load Balancer service can be configured to support SSL termination.

The purpose of SSL termination is to decrypt the incoming encrypted stream before forwarding it to the appropriate service, such as a web server.

Handling SSL termination on the Load Balancer reduces the computational load on your backend servers and centralizes certificate management. This makes maintenance and security updates easier.

 

## Requirements

- An [OVHcloud Load Balancer](https://us.ovhcloud.com/network/load-balancer/) service in your OVHcloud account.
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) or [OVHcloud API](https://api.us.ovhcloud.com/)

 

## Instructions

### Configure the frontend for SSL termination

To enable SSL termination, you must first configure your frontend.

<Tabs>

<Tab label="Via the OVHcloud Control Panel">

You can configure your SSL termination in the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) via the `Network` and then `Load Balancer` menus.

:::warning

**NOTE:** If you are not using the [beta version](https://support.us.ovhcloud.com/hc/en-us/articles/40734337787283) of the OVHcloud Control Panel, you can find the OVHcloud Load Balancer via the `Bare Metal Cloud` or `Hosted Private Cloud` sections.

:::

After selecting the Load Balancer you wish to modify, create a new frontend or edit an existing one.

In the `Front-ends` tab, click on the `Add a front-end` button to create a new frontend.

In the configuration window that opens, select the `HTTPS` protocol. Then, select the `Default server cluster`.

Finally, open the **Advanced settings** and fill in the `HTTPS Redirection` field.

![IPLB\_addFrontend\_https.png](/images/network/load-balancer/order-a-free-ssl-certificate/46608113453331.png)

Once the frontend has been created, a banner will appear prompting you to `Apply configuration` to deploy your changes in the appropriate zone.

![IPLB\_addFrontend\_applyConfiguration.png](/images/network/load-balancer/order-a-free-ssl-certificate/46608113463443.png)

</Tab>

<Tab label="Via the OVHcloud API">

From the [OVHcloud API](https://api.us.ovhcloud.com/), the SSL termination is specified by the `ssl` boolean. To enable SSL termination, set this parameter to `true`, then set the `defaultFarmId` or `redirectLocation` to the corresponding values.

:::info

To find your defaultFarmId, use the

<Api version="v1" section="/ipLoadbalancing" method="GET" route={"/ipLoadbalancing/\{serviceName\}/http/farm"} regions={["us"]} />

API call.

:::

Create a front-end:

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/http/frontend"} regions={["us"]} />

Then apply the changes:

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/refresh"} regions={["us"]} />

</Tab>

</Tabs>

 

### Order the free SSL certificate

<Tabs>

<Tab label="OVHcloud Control Panel">

From the `SSL certificates` tab, click `Order an SSL certificate`.

In the pop-up window, select `Free`, enter a `FQDN`, and click `Order`.

![IPLB\_sslCertificate\_order-2.png](/images/network/load-balancer/order-a-free-ssl-certificate/46608113469587.png)

</Tab>

<Tab label="OVHcloud API">

From the [OVHcloud API](https://api.us.ovhcloud.com/), use the following command.

For the order to be finalized, the chosen domain name must point to your OVHcloud Load Balancer service.

<Api version="v1" section="/ipLoadbalancing" method="POST" route={"/ipLoadbalancing/\{serviceName\}/freeCertificate"} regions={["us"]} />

</Tab>

</Tabs>

 

### Follow up on the order

<Tabs>

<Tab label="Via the OVHcloud Control Panel">

Select the `Tasks` tab, and look at the **Task** column for those labeled as `orderFreeCertificate`.

![IPLB\_tasks.png](/images/network/load-balancer/order-a-free-ssl-certificate/46608097776787.png)

</Tab>

<Tab label="Via the OVHcloud API">

- Get a task list, and specify `orderFreeCertificate` as the action type:

  <Api version="v1" section="/ipLoadbalancing" method="GET" route={"/ipLoadbalancing/\{serviceName\}/task"} regions={["us"]} />

* Get the status of a particular task:

  <Api version="v1" section="/ipLoadbalancing" method="GET" route={"/ipLoadbalancing/\{serviceName\}/task/\{id\}"} regions={["us"]} />

</Tab>

</Tabs>
