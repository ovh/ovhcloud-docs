# Find Your Additional IP Limit

**Learn how to find the number of Additional IPs that can be ordered for your OVHcloud service.**

:::info

Since October 6th, 2022 our service "Failover IP" has been named [Additional IP](https://us.ovhcloud.com/network/additional-ip/). This renaming does not affect its technical features.

:::

 

## Requirements

- a [dedicated server](https://us.ovhcloud.com/bare-metal/)
- access to the [OVHcloud API](https://api.us.ovhcloud.com/)
- if unfamiliar with the OVHcloud API, read our [First Steps with the OVHcloud API](https://support.us.ovhcloud.com/hc/en-us/articles/360018130839) guide

 

## Instructions

First, access the [OVHcloud API](https://api.us.ovhcloud.com/) and open the [/dedicated/server section](https://api.us.ovhcloud.com/console/#/dedicated/server).

 

### Find the service name

You will need the internal name of your dedicated server to find your Additional IP limit. If you do not know, or know how to find, this information you can use the OVHcloud API or the OVHcloud Control Panel to retrieve it.

:::tip

Click each tab across the top to view all content.

:::

<Tabs>

<Tab label="OVHcloud API">

In the [OVHcloud API](https://api.us.ovhcloud.com/), locate the API call below and click `Execute`.

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/"} regions={["us"]} />

The result will show the internal name of your service.

![network\_additionalIP\_blockLimits02\*\*.png](/images/network/additional-ip/find-your-additional-ip-limit/29145272476435.png)

</Tab>

<Tab label="OVHcloud Control Panel">

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/):

1. Select `Bare Metal Cloud` from the top navigation bar.
2. Click the `Dedicated servers` section and select your server.
3. Find the internal server name. Even if you have renamed your server, the internal name will be visible beneath the new one you created.

![network\_additionalIP\_blockLimits03\*\*\*.png](/images/network/additional-ip/find-your-additional-ip-limit/29145226537619.png)

</Tab>

</Tabs>

 

### Find your Additional IP limit

In the [OVHcloud API](https://api.us.ovhcloud.com/), locate the following API call. You can find it quickly by using the **Filter** option as shown in the picture below.

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/orderable/ip"} regions={["us"]} />

Enter the **serviceName** you found in the [previous step](#service-name), then click `Execute`.

![network\_additionalIP\_blockLimits04b.png](/images/network/additional-ip/find-your-additional-ip-limit/29145226546323.png)

 

### Interpret the result

In the output, the **blockSizes**, **ipNumber**, and **number** fields (shown below in green) determine the Additional IPs available to you.

Example result:

```
{
  -ipv4: [
     - {
         number: 16,
       - blockSizes: [
            1,
            4,
            8,
            16,
         ],
         optionRequired: null,
         ipNumber: 128,
         included: false,
         type: "failover"
       },
     - {
         type: "failover",
         included: true,
         ipNumber: 128,
         optionRequired: null,
         number: 16,
       - blockSizes: [
            1,
            4,
            8,
            16,
        ]
     }
  ],
  ipv6: [ ]
}
```

 

The factors that limit the number of Additional IPs/Blocks are **ipNumber** and **number**.

- **ipNumber:** Shows the total number of IPs (single Additional IP *and* IPs in Additional IP blocks) that can be routed to the server.
- **number:** Shows the number of additional IP products (single Additional IPs *or* Additional IP blocks) that can be routed to the server.

So, in this example, the **number** is 16 and the **ipNumber** is 128, this means that up to 16 Additional IP products can be attached to the server but the total number of IPs (single and as part of a block) routed to the server cannot exceed 128.
