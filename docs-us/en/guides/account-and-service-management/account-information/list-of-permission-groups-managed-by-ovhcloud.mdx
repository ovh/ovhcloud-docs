# List of permission groups managed by OVHcloud

OVHcloud provides permission groups that group together all of the actions required for specific use cases.

This guide lists all of these permission groups and details the actions contained in each group.

 

## Requirements

- An [OVHcloud customer account](https://support.us.ovhcloud.com/hc/en-us/articles/115001286870)
- [How to set up IAM policies via the Control Panel](https://support.us.ovhcloud.com/hc/en-us/articles/19185780752019)
- [How to implement IAM policies via the API](https://support.us.ovhcloud.com/hc/en-us/articles/16583913962771)

 

## Instructions

Permission groups allow you to set up turn-key access policies without having to know the full list of necessary actions. This list will change over time as new permission groups are created.

If a permission group is updated, a new permission group will be created and the old permission group will be deprecated to avoid impacting existing IAM policies.

 

### Using permission groups

#### Listing permission groups

The permission groups are accessible via the following API:

<Api version="v2" section="/iam" method="GET" route={"/iam/permissionsGroup"} regions={["us"]} />

```
{
    "id": "00000000-0000-0000-0001-000000000001",
    "urn": "urn:v1:us:permissionsGroup:ovh:globalAdmin",
    "name": "globalAdmin",
    "owner": "ovh",
    "description": "Give global admin access across all OVHcloud products",
    "permissions": {
        "allow": [
        {
            "action": "*"
        }
        ]
    },
    "createdAt": "2023-03-14T09:10:57.40418Z",
    "updatedAt": null
},
```

 

#### Use permission groups from the Control Panel

These permission groups can then be used in addition to or in place of unit actions in access policies:

![IAM\_permissiongroups01.png](/images/account-and-service-management/account-information/list-of-permission-groups-managed-by-ovhcloud/43234972770067.png)

 

#### Using permission groups in the API

These permission groups can then be used in addition to or in place of unit actions in access policies:

```
{
  "description": "",
  "identities": [...],
  "name": "",
  "permissions": {
    "allow": [
      {
        "action": "..."
      },
    ]
  },
  "permissionsGroups": [
      {
        "urn": "urn:v1:us:permissionsGroup:ovh:globalAdmin"
      }
  ],
  "resources": [...]
}
```
