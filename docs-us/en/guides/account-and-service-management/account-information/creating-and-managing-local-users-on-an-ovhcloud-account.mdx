# Creating and managing local users on an OVHcloud account

**Learn about the privileges a user can hold, as well as the methods for adding and managing users and groups through the OVHcloud Control Panel.**

With OVHcloud, you can create additional users with read or write access to your customer account. This means that you can grant other members of your company access to your OVHcloud services, without having to resort to risky practices like sharing passwords or two-factor authentication details.

:::info

- User management is different from contact management. A user will have access to all sections of the OVHcloud Control Panel according to the level of rights he's granted.
- The purpose of contact management is to delegate full management of the administrative, technical, and billing aspects of one or more services on your OVHcloud account.

:::

 

## Requirements

- An active OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)

 

## Instructions

### Understanding identities

Local users are one of the types of identities that can be set up on your OVHcloud account. Other account types are described in the [related documentation](https://support.us.ovhcloud.com/hc/en-us/articles/30670050869267).

 

### User management

#### Add a user

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), navigate to the `Identities` section via the `Identity, Security & Operation` menu.

In the `Local users` tab, click the `Add user` button.

![identities\_localUsersTab.png](/images/account-and-service-management/account-information/creating-and-managing-local-users-on-an-ovhcloud-account/45222401011987.png)

In the pop-up window, fill in the fields and select a **Group**. Click `Confirm` to add your new user.

|             |                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Field**   | **Details**                                                                                                                                                                                                                                                                                                                                                                                                              |
| Login       | Enter the user's name or their role, for example.                                                                                                                                                                                                                                                                                                                                                                        |
| Email       | Enter the user's full email address.                                                                                                                                                                                                                                                                                                                                                                                     |
| Password    | Set the user password. The user can then change this password once their access has been created. We also suggest reading our [guide on password management](https://support.us.ovhcloud.com/hc/en-us/articles/19376441290131) to define this password.                                                                                                                                                                  |
| Group       | Choose a group from those available.* `ADMIN` (Administrator): Gives write access to the OVHcloud Control Panel and all of its sections, **including** user management.
* `DEFAULT` (Restricted Admin): Gives write access to the OVHcloud Control Panel and all of its sections, **except for** user management.
* `UNPRIVILEGED` (Read-Only): Gives read access to the OVHcloud Control Panel and all of its sections. |
| Description | You can add a user description (such as their role within the company).                                                                                                                                                                                                                                                                                                                                                  |

**WARNING:** Any user with an "ADMIN" role has complete control over your account and services, including:

- Creating services for which you will be charged,
- Deleting services, which is sometimes irreversible,
- Adding **or deleting** other users with an ADMIN role, and
- Changing the account's contact, billing, and payment information.

![identities\_addUser.png](/images/account-and-service-management/account-information/creating-and-managing-local-users-on-an-ovhcloud-account/45222433119123.png)

The user then gets their own ID made up of your account’s numeric ID (which is listed in the “Local users” tab) and their username, with the two values separated by a “/”.

Example: **1234-567-89/user**.

The user you have created can then log in to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub) using this ID.

They can also change their password and secure their own access to your account by enabling two-factor authentication (this is only for their access as a user). To find out how to enable two-factor authentication, you can refer to [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/115001825710).

 

#### Manage users

You can update, delete, or disable a user by clicking on the *more options* `...` button to the right of the user’s name.

![identities\_localUsersTab\_moreOptions.png](/images/account-and-service-management/account-information/creating-and-managing-local-users-on-an-ovhcloud-account/45222433120659.png)

When you update a user you can update their email address, group, and description.

:::warning

**NOTE:** After the creation of a new group, you will have to update the **Group** field for any users you wish to add to it.

:::

![identities\_updateUser.png](/images/account-and-service-management/account-information/creating-and-managing-local-users-on-an-ovhcloud-account/45222433121811.png)

 

### Group management

#### Add a group

Switch to the `User groups` tab, click `Declare a group`.

![identities\_userGroupsTab.png](/images/account-and-service-management/account-information/creating-and-managing-local-users-on-an-ovhcloud-account/45222433124243.png)

A window will pop up and you will need to complete the required fields.

Groups give a default privilege level for the users they contain, according to the role you choose:

| Role                     | Details                                                                                                    |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Administrator            | Give write access to the OVHcloud Control Panel and all of its selections, **including** user management.  |
| Restricted administrator | Give write access to the OVHcloud Control Panel and all of its selections, **except for** user management. |
| Read-only                | Gives read access to the OVHcloud Control Panel and all of its sections.                                   |
| None                     | Gives no access to the OVHcloud Control Panel if no IAM policy is set up.                                  |

**WARNING:** Any user with an "ADMIN" role has complete control over your account and services, including:

- Creating services for which you will be charged,
- Deleting services, which is sometimes irreversible,
- Adding **or deleting** other users with an ADMIN role, and
- Changing the account's contact, billing, and payment information.

Click `Confirm` to create the user.

:::warning

**NOTE:** After the creation of a new group, you will have to update the **Group** field for any users you wish to add to it. See the [Manage users](#manage-users) section of this article for more information.

:::

![identities\_addGroup.png](/images/account-and-service-management/account-information/creating-and-managing-local-users-on-an-ovhcloud-account/45222401022483.png)

 

#### Manage groups

You can update or remove a group by clicking on the *more options* `...` button to the right of the group name.

![identities\_userGroupsTab\_moreOptions.png](/images/account-and-service-management/account-information/creating-and-managing-local-users-on-an-ovhcloud-account/45222433130771.png)

When you update a group you can update its description and role.

![identities\_updateGroup.png](/images/account-and-service-management/account-information/creating-and-managing-local-users-on-an-ovhcloud-account/45222401027603.png)

 

### Rights management

On top of the role assigned to user groups, you can fine-tune access privileges using OVHcloud IAM. OVHcloud IAM policies management is covered by the [dedicated guide](https://support.us.ovhcloud.com/hc/en-us/articles/19185780752019).
