# Increasing the size of an additional disk

If you have reached the maximum capacity of your additional disk, you can add more storage by increasing its size.

 

## Requirements

- A [Public Cloud instance](https://us.ovhcloud.com/public-cloud/) in your Public Cloud project
- An [additional disk](https://support.us.ovhcloud.com/hc/en-us/articles/20566582694291) created in your project
- Administrative (root) access to your instance [via SSH (Linux) or RDP (Windows)](https://support.us.ovhcloud.com/hc/en-us/articles/360002245164#step-4-connecting-to-your-instance)

#### OVHcloud Control Panel Access

- **Direct link:** [Public Cloud Projects](https://manager.us.ovhcloud.com/#/public-cloud/pci/projects)
- **Navigation path:** `Public Cloud` > Select your project

 

## Instructions

The following steps presume that you have configured an additional disk according to [our guide](https://support.us.ovhcloud.com/hc/en-us/articles/20566582694291).

 

### Monitoring disk usage before resizing

:::warning

**NOTE:** We recommend that you always maintain 20% free space on your storage volumes. This ensures optimum performance and avoids the risk of system degradation or failure when the volume reaches its maximum capacity.

:::

To ensure that you resize your disk at the right moment, it is essential to monitor disk usage regularly. Below are quick tutorials for both Windows and Linux to help you track disk space and anticipate when an upgrade is needed.

<Tabs>

<Tab label="On Windows">

<details>
<summary>Using Command Prompt</summary>

Open Command Prompt (Win + R → cmd → Enter).

Run the following command:

```bash
wmic logicaldisk get name, size, freespace
```

This will display the free space and total size of each disk.

</details>

<details>
<summary>Using PowerShell</summary>

Open PowerShell as Administrator.

Run the following command:

```bash
Get-PSDrive | Where-Object {$_.Free -ne $null} | Select-Object Name, Used, Free
```

This will show the used and available disk space.

</details>

</Tab>

<Tab label="On Linux">

<details>
<summary>Using the 'df' command</summary>

To check overall disk usage, run:

```bash
df -h
```

This will display disk usage in a human-readable format.

</details>

<details>
<summary>Using the 'lsblk' command</summary>

To view disk partitions and their sizes:

```bash
lsblk
```

</details>

</Tab>

</Tabs>

 

### Modifying the size of the disk

Click on `Block Storage` in the left-hand menu.

If the volume is attached to a **Windows instance**, click on the *more options* `...` button in the row of the volume and select `Detach from instance`.

Click on `...` in the row of the volume and select `Edit`.

![blockStorage\_serviceList\_moreOptions\_detach.PNG](/images/storage-and-backup/block-storage/increasing-the-size-of-an-additional-disk/48655449689491.png)

In the next screen, increase **Volume capacity** and click `Modify the volume`.

![manager\_blockStorage\_editVolume.png](/images/storage-and-backup/block-storage/increasing-the-size-of-an-additional-disk/41054686848147.png)

 

### Extending the partition

<Tabs>

<Tab label="Windows instance">

Before proceeding, reattach the volume to the instance. Click the *more options* `...` button to the right of the volume and select `Attach to instance`.

Establish a remote desktop (RDP) connection to your Windows instance.

Once logged in, right-click on the `Start Menu` button and open `Disk Management`.

![windows\_blockStorage\_extendPartition1.png](/images/storage-and-backup/block-storage/increasing-the-size-of-an-additional-disk/41054686848787.png)

The extended disk now displays the additional capacity as unallocated space.

![windows\_blockStorage\_extendPartition2.png](/images/storage-and-backup/block-storage/increasing-the-size-of-an-additional-disk/41054686849427.png)

Right-click on the volume and select `Extend Volume` from the context menu.

![windows\_blockStorage\_extendPartition3.png](/images/storage-and-backup/block-storage/increasing-the-size-of-an-additional-disk/41054669278995.png)

In the "Extend Volume Wizard", click on `Next` to proceed.

You can modify the disk space in this step if you want to add less than the entire amount to the partition. Click on `Next`.

![windows\_blockStorage\_extendPartition4.png](/images/storage-and-backup/block-storage/increasing-the-size-of-an-additional-disk/41054686850835.png)

Click on `Finish` to complete the process.

The resized volume now includes the additional disk space.

![windows\_blockStorage\_extendPartition5.png](/images/storage-and-backup/block-storage/increasing-the-size-of-an-additional-disk/41054686851603.png)

Once this is completed, detach and reattach the volume to the instance to ensure the updated QoS settings (IOPS and bandwidth) are properly applied.

</Tab>

<Tab label="Linux instance">

Establish an SSH connection to your instance in order to adjust the partition to the resized disk.

Unmount the disk first by using this command:

```bash
sudo umount /mnt/disk
```

Recreate the partition:

```bash
sudo fdisk /dev/sdb
```
