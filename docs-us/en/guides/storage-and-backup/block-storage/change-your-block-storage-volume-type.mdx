# Change your Block Storage volume type

The Block Storage volumes can be upgraded or downgraded; for example, changed from Classic to High-speed-gen-2 and back again.

:::info

Volume retyping is not available for encrypted volumes. To learn how to migrate a Block Storage volume to an encrypted LUKS volume, see our [Migrating a Block Storage volume to an encrypted LUKS volume](https://support.us.ovhcloud.com/hc/en-us/articles/47097596363283) guide.

:::

To learn more about our Block Storage volume types, see [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/23175497535507).

 

## Requirements

- Access to the [Horizon Interface](https://support.us.ovhcloud.com/hc/en-us/articles/20719718436115)
- A [Block Storage volume](https://support.us.ovhcloud.com/hc/en-us/articles/20566582694291) created in your [Public Cloud project](https://us.ovhcloud.com/public-cloud/)

#### OVHcloud Control Panel Access

- **Direct link:** [Public Cloud Projects](https://manager.us.ovhcloud.com/#/public-cloud/pci/projects)
- **Navigation path:** `Public Cloud` > Select your project

 

## Instructions

:::warning

**NOTE:** All snapshots and instances connected to the Block Storage volume must be deleted/detached before proceeding. For more information, see the **Detach a volume** section of the guide "[Creating and configuring an additional disk on an instance](https://support.us.ovhcloud.com/hc/en-us/articles/20566582694291#detach-a-volume)".

Changing the volume type (retyping) via the OVHcloud Control Panel or the OVHcloud API is available only for unencrypted volumes. Encrypted volumes of type **-LUKS** cannot be retyped.

Conversions from **-LUKS** to **non -LUKS** (or vice versa) are not supported, including via OpenStack / Horizon.

:::

### Access your Block Storage volumes

<Tabs>

<Tab label="Via the OVHcloud Control Panel">

#### Via the OVHcloud Control Panel

Click on `Block Storage` in the left-hand menu under **Storage**.

</Tab>

<Tab label="Via the Horizon Interface">

#### Via the Horizon Interface

Log in to the [Horizon interface](https://horizon.cloud.ovh.us/auth/login/) and make sure you are in the correct region. You can verify this in the top left corner.

![horizon\_selectRegion.png](/images/storage-and-backup/block-storage/change-your-block-storage-volume-type/41059877176467.png)

Next, open the **Volumes** menu on the left side and click on `Volumes`.

![horizon\_volumes\_classic.PNG](/images/storage-and-backup/block-storage/change-your-block-storage-volume-type/48168774348947.png)

</Tab>

<Tab label="Via OpenStack CLI">

#### Via the OpenStack CLI

:::info

Make sure to consult the following guide before proceeding: [Preparing an environment for using the OpenStack API](https://support.us.ovhcloud.com/hc/en-us/articles/1500009262762).

:::

Find the volume ID of the Block Storage volume you wish to retype. With this command, you will also be able to see the volumes' current type.

```bash
openstack volume list --long
```

</Tab>

</Tabs>

 

### Change your Block Storage volume type

<Tabs>

<Tab label="Via the OVHcloud Control Panel">

#### Via the OVHcloud Control Panel

Click the *more options* `...` button to the right of your volume and choose `Change the volume type`.

A panel will appear on the right-hand edge of the page. Select a new type for your volume and click `Edit`.

</Tab>

<Tab label="Via the Horizon Interface">

#### Via the Horizon Interface

:::info

When trying to change a block storage volume type, the migration policy will need to be changed to `On-demand`.

The migration policy is set to `Never` by default, as the volume stays on the same CEPH cluster. However, for retyping, the volume will need to be migrated to a new cluster.

:::

Find the row for your volume in the table, click on the drop-down arrow next to `Edit Volume`, and select `Change Volume Type`.

![horizon\_volumes\_changeType.png](/images/storage-and-backup/block-storage/change-your-block-storage-volume-type/41059913186963.png)

In the pop-up window:

- For **Type**, select a new volume type.
- For **Migration Policy**, select `On Demand`.

Once done, click on `Change Volume Type` to confirm the change.

![horizon\_selectNewVolumeType.png](/images/storage-and-backup/block-storage/change-your-block-storage-volume-type/41059913189779.png)

</Tab>

<Tab label="Via OpenStack CLI">

#### Via the OpenStack CLI

List available volume types:

First, list the types of volumes available in your region with the following command:

:::warning

**NOTE:** Please note that if "high-speed-gen2" does not appear in the list, it means that it is not available in this region.

:::

```
openstack image list
+--------------------------------------+-----------------------------------------------+----------+
| ID                                   | Name                                          | Is Public|
+--------------------------------------+-----------------------------------------------+----------+
| 27844ef7-1a9a-4944-be59-6e4eb19a71f6 | high-speed-gen2                               |      True|
| 23f75fef-d4f6-416a-a884-95aa3fd45695 | classic                                       |      True|
| 2f78e8af-93c9-4e5c-b177-83c4a7ec456a | high-speed                                    |      True|
----------------------------------------------------------------------------------------------------
```

Switch volume types with the following command:

:::info

When trying to change a block storage volume type, the migration policy will need to be changed to `On-demand`.

The migration policy is set by default to `Never`, as the volume stays on the same CEPH cluster. However, for retyping, the volume will need to be migrated to a new cluster.

:::

```
openstack volume set --type VOLUME_TYPE --retype-policy on-demand VOLUME_NAME_OR_ID
```

</Tab>

</Tabs>

 

### Verify the retyping

:::warning

**NOTE:** The larger your volume, the longer it may take for the retyping process to complete.

:::

<Tabs>

<Tab label="Via the OVHcloud Control Panel">

#### From the OVHcloud Control Panel

After some time, you will be able to see the new volume type when you refresh the Block Storage home page.

</Tab>

<Tab label="Via the Horizon Interface">

#### From the Horizon Interface

The Volumes page will refresh itself, and you will see the change reflected in the **Type** column.

![horizon\_volumes\_highSpeed.PNG](/images/storage-and-backup/block-storage/change-your-block-storage-volume-type/48168774356243.png)

</Tab>

<Tab label="Via OpenStack CLI">

#### Using the OpenStack CLI

Run the command to retrieve a list of your block storage volumes. With this command, you will also be able to see the volumes' current type.

```bash
openstack volume list --long
```

</Tab>

</Tabs>
