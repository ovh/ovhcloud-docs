# Object Storage - Manage an Object Storage bucket with Terraform

## Requirements

- [Terraform CLI](https://developer.hashicorp.com/terraform) installed

- Access to the [OVHcloud API](https://api.us.ovhcloud.com/) (create your login by consulting [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/360018130839))

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account

- Access to the OVHcloud [Terraform provider](http://registry.terraform.io/providers/ovh/ovh/latest), which is available in the official Terraform registry

  :::info

  You have a version >= 2.0 installed. You can follow our [How to Use Terraform](https://support.us.ovhcloud.com/hc/en-us/articles/15974268257299) guide.

  :::

 

## Getting information about your API tokens

The “OVH provider” must be configured with a set of credentials:

- an `application_key`
- an `application_secret`
- a `consumer_key`

 

### Why?

Because, behind the scenes, the OVH Terraform provider makes requests to the OVHcloud APIs.

To retrieve this necessary information, please follow the tutorial [First steps with the OVHcloud APIs](https://support.us.ovhcloud.com/hc/en-us/articles/360018130839).

Once you've successfully generated your OVHcloud tokens, keep them. You'll need to set them in the next few minutes.

The last piece of information you'll need is the `service_name`: this is the ID of your Public Cloud project.

 

### How do I get it?

In the Public Cloud section of the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), you can retrieve your service name ID using the `Copy to clipboard` button.

You can also use this information in Terraform resource definition files.

## Instructions

If you would like to access the provider's documentation on Object Storage, [click here](https://registry.terraform.io/providers/ovh/ovh/latest/docs/resources/cloud_project_storage).

 

### Configuration

First, create a `provider.tf` file with the minimum version, the US endpoint (“ovh-us”), and the keys you obtained in this guide.

Terraform:

```
terraform {
  required_providers {
    ovh = {
      source  = "ovh/ovh"
      version = "~> 2.1" # greater than or equal to 2.1
    }
  }
}

provider "ovh" {
  endpoint           = "ovh-us"
  application_key    = "<your_access_key>"
  application_secret = "<your_application_secret>"
  consumer_key       = "<your_consumer_key>"
}
```

Here, we've defined the `ovh-us` endpoint because we want to call the OVHcloud US API, but other endpoints exist, depending on your needs:

- `ovh-eu` pour OVHcloud Europe API
- `ovh-ca` pour OVHcloud North-America API

 

### Create a bucket

You can create a file named `object_storage_simple.tf` and write the following:

```
# Create an Object Storage bucket
resource "ovh_cloud_project_storage" "my_bucket" {
 service_name = "service_name" # Replace with your OVHcloud project ID
 region_name = "US-EAST-VA" # Replace with the desired region in uppercase.
  name = "object-storage-simple"
  versioning = {
    status = "enabled"
  }
  encryption = {
    sse_algorithm = "AES256"
  }
}
```

You can create your resource by entering the following command:

```
terraform apply
```

 

### Delete a bucket

You can delete your bucket and all the objects it contains by entering the following command:

:::info

This process may fail if the bucket contains locked objects. In this case, you'll need to delete these objects manually before you can run the command again.

:::

```
terraform destroy
```
