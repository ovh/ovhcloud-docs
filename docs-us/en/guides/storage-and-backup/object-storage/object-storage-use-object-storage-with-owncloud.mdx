# Object Storage - Use Object Storage with Owncloud

**Learn how to set up storage in Owncloud to use an Object Storage container.**

Owncloud is a suite of client-server software for creating and using file hosting services.

 

## Requirements

- a container (see our [Getting Started with Object Storage](https://support.us.ovhcloud.com/hc/en-us/articles/4603838122643) guide)
- a user with the required access rights on the container
- your Object Storage credentials (access\_key and secret\_access\_key)

:::info

To identify the endpoint corresponding to your storage class, please refer to our [Endpoints and Object Storage Geoavailability](https://support.us.ovhcloud.com/hc/en-us/articles/10667991081107) guide.

:::

 

## Instructions

If needed, install the `External Storage: S3` plugin from the `Market`.

![openioowncloud1.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-owncloud/4765640372755.png)

Search for the `External Storage: S3` plugin.

![openioowncloud2.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-owncloud/4765815416083.png)

`Install` it.

![openioowncloud3.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-owncloud/4765837054611.png)

Go to the `Settings`.

![openioowncloud4.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-owncloud/4765815451283.png)

Then :

1. in `Storage`
2. enable `Enable external storage`
3. name your folder
4. add an `Amazon S3 compatible storage (SDK v3)`

![openioowncloud5.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-owncloud/4765815480083.png)

Fill in the following information:

1. Enter the name of your container
2. Set the host as: `s3.<region_in_lowercase>.io.cloud.ovh.us`
3. Set the port to 443
4. Specify the region
5. Activate SSL
6. Enter your access key
7. Enter your secret key

![openioowncloud6.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-owncloud/4765640391827.png)

Go to `Files`.

![openioowncloud7.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-owncloud/4765824472467.png)

Then navigate to `External storage`.

![openioowncloud8.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-owncloud/4765808310291.png)

The result should be similar to this:

![openioowncloud9.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-owncloud/4765815551123.png)
