# Getting started with Cloud Archive Storage

The Public Cloud Archive offer is an unlimited storage solution with simple billing tailored to your needs. There are many types of object containers:

- For static hosting (static website).
- For private hosting (e.g., storage of personal data).
- For public hosting (to store everything that is accessible to the public).
- For cold storage (archiving).

 

## Requirements

- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- A [Public Cloud project](https://support.us.ovhcloud.com/hc/en-us/articles/360002245784) in your account

 

## Instructions

### Creating a Public Cloud Archive container

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), navigate to the `Cloud Archive` section via the `Public Cloud` menu.

Click `Create an archive container` (or `+ Create an archive container` if this is not your first container).

![manager\_cloudArchive\_onboarding.png](/images/storage-and-backup/object-storage/getting-started-with-cloud-archive-storage/42488547984275.png)

Select the region for your container and then click `Next`:

![manager\_cloudArchive\_order\_region.png](/images/storage-and-backup/object-storage/getting-started-with-cloud-archive-storage/42488547986195.png)

Name your container, then click `Create the container`:

:::warning

**NOTE:** If you want to link your container to a domain name, your container name must not contain the following characters:

- \[ . ]
- \[ \_ ]
- And you must not use capital letters.

:::

![manager\_cloudArchive\_order\_containerName.png](/images/storage-and-backup/object-storage/getting-started-with-cloud-archive-storage/42488532660371.png)

 

### Managing and canceling your container

Once your container is created, you can manage or cancel your container by clicking the *more options* `...` button to the right of your container.

![manager\_cloudArchive\_serviceCreation\_moreOptions.png](/images/storage-and-backup/object-storage/getting-started-with-cloud-archive-storage/42488532661267.png)
