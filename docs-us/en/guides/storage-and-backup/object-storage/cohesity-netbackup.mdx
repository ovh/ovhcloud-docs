# Object Storage – Use Object Storage with Cohesity NetBackup

This guide covers the steps to add a cloud volume, configure optional WORM (Write Once Read Many) settings, and integrate the storage into NetBackup backup policies.

 

## Requirements

- A NetBackup Primary Server installed and configured. See the following documentation: "[Installing NetBackup Primary Server](https://www.veritas.com/support/en_US/doc/27801100-157469020-0/v13834345-157469020)".
- A Media Server with a deduplication option installed on Red Hat Enterprise or SUSE Linux Enterprise Server. See the following documentation: "[Deduplication Guide](https://www.veritas.com/support/en_US/doc/25074086-168257404-0/index)".
- Approximately 1 TB of local disk space is available for deduplication metadata management.

 

## Instructions

This section provides a step-by-step guide to configuring a deduplicated Disk Pool using OVHcloud Object Storage as a cloud volume in Cohesity[\[1\]](#go-further) NetBackup.

You will be guided through the entire process, from selecting the Storage Server to integrating the configuration into your backup policies. Each step is accompanied by a screenshot to assist with setup.

1. Ensure that an MSDP Storage Server is already created.

2) Log in to the NetBackup interface as an administrator.

   ![Login screen - Cohesity netbackup](/images/storage-and-backup/object-storage/cohesity-netbackup/login-screen.png)

3. Access the `Storage` menu, the `Disk storage` submenu, then click the `Storage Servers` tab.

   ![Storage servers tab](/images/storage-and-backup/object-storage/cohesity-netbackup/storage-servers-tab.png)

4) Open the `Disk Pools` tab and click on `+ Add` to create a new Disk Pool.

   ![Disk pools tab](/images/storage-and-backup/object-storage/cohesity-netbackup/disk-pools-tab.png)

5. Select the `Storage Server MSDP` on which you want to create the deduplicated pool.

   ![Select msd pserver](/images/storage-and-backup/object-storage/cohesity-netbackup/select-msd-pserver.png)

6) When selecting the volume, click on `Add Cloud Volume`.

   ![Add cloud volume](/images/storage-and-backup/object-storage/cohesity-netbackup/add-cloud-volume.png)

7. Choose `OVHcloud Standard Object Storage` as the cloud storage type.

   ![Select OVHcloud](/images/storage-and-backup/object-storage/cohesity-netbackup/select-ov-hcloud.png)

8) Select the desired endpoint, and add the OVHcloud credential if not already done.

   ![Select endpoint - Cohesity netbackup](/images/storage-and-backup/object-storage/cohesity-netbackup/select-endpoint.png)

9. (Optional) To enable WORM mode (S3 Object Lock), check `Use Object Lock`. Select the NetBackup lock mode matching the OVHcloud Object Lock mode:

   - Compliance -> Compliance
   - Enterprise -> Governance

   Then, set the minimum and maximum retention periods for the lock.

   ![Enable worm - Cohesity netbackup](/images/storage-and-backup/object-storage/cohesity-netbackup/enable-worm.png)

10) Enter the name of the bucket you want to use, or create a new one.

    ![Name bucket - Cohesity netbackup](/images/storage-and-backup/object-storage/cohesity-netbackup/name-bucket.png)

11. Click on `Next`, then review the settings in the Review tab.

    ![Review settings - Cohesity netbackup](/images/storage-and-backup/object-storage/cohesity-netbackup/review-settings.png)

12) Click on `Add Storage Unit` at the top of the screen, then name the storage unit.

    ![Add storage unit](/images/storage-and-backup/object-storage/cohesity-netbackup/add-storage-unit.png)

    ![Name storage unit](/images/storage-and-backup/object-storage/cohesity-netbackup/name-storage-unit.png)

13. (Optional) To enable WORM locking, check `Lock until Expiration`.

    :::info

    Note: WORM and non-WORM data can coexist within the same deduplicated Disk Pool.

    :::

14) Review all settings in the Review tab, then confirm.

    ![Confirm settings - Cohesity netbackup](/images/storage-and-backup/object-storage/cohesity-netbackup/confirm-settings.png)

15. You can now:

    - Use the storage unit directly in your backup jobs,
    - Or use it as a secondary target via a Storage Lifecycle Policy (SLP).

16) Modify your backup policies accordingly to integrate OVHcloud Object Storage.

    ![Backup policies - Cohesity netbackup - step 1](/images/storage-and-backup/object-storage/cohesity-netbackup/backup-policies-01.png)

    ![Backup policies - Cohesity netbackup - step 2](/images/storage-and-backup/object-storage/cohesity-netbackup/backup-policies-02.png)

    ![Backup policies - Cohesity netbackup - step 3](/images/storage-and-backup/object-storage/cohesity-netbackup/backup-policies-03.png)

    ![Backup policies - Cohesity netbackup - step 4](/images/storage-and-backup/object-storage/cohesity-netbackup/backup-policies-04.png)
