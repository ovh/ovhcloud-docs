# Object Storage – Use Object Storage with Pure Storage Flashblade

**Learn how you can easily configure, manage, and start replicating Pure Storage FlashBlade S3™\*-compatible objects to OVHcloud Object Storage.**

This guide aims to help you configure and use OVHcloud Object Storage as a replication target for Pure Storage [Flashblade unified storage platform](https://www.purestorage.com/uk/products/unstructured-data-storage/flashblade-s.html).

 

## Requirements

- An OVHcloud Object Storage container/bucket (get started with [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/4603838122643))
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- A user with the required access rights on the bucket
- Your Object Storage credentials (`access_key` and `secret_access_key`)

 

## Instructions

### Create an S3-compatible Target Connection

1. Sign in to the PureStorage FlashBlade GUI.

2. Go to the `Storage` section and then `Array`.

3. Click the `+` button next to `S3 Target Connections` to create a *Target Connections* cloud object storage.

4. Name the connection (for example, `OVHCLOUD_OBJECT_STORAGE`) and add the associated OVHcloud Object Storage endpoints in the `Address` field.

   ![editS3Target.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-pure-storage-flashblade/43580149100051.png)

The list of all OVHcloud Object Storage endpoints can be found [here](https://support.us.ovhcloud.com/hc/en-us/articles/10667991081107).

 

### Add Remote Cloud Object Storage Credentials

1. Go to the `Protection` section and then click on `Object Replica Links`.

2. Click the `+` button to add remote credentials for object replication.

3. Select `OVHCLOUD_OBJECT_STORAGE` for Remote Array.

4. Add the name of your connection (for example, `OVHcloud_credentials`), and add your Access and Secret keys from the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/).

5. Confirm by clicking on `Create`, and your remote credentials will be created.

   ![editRemoteCredentials.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-pure-storage-flashblade/43580181073299.png)

 

### Create a bucket that will be replicated to OVHcloud Object Storage

1. If not already done, go to the `Storage` section, then `Object Storage`, and finally `Accounts` to create the account.
2. Configure the different parameters: `account name`, `quota limit`, and `bucket default quota limit` to create the account.
3. Click the `Buckets` section and select the account name.
4. Enter a bucket name `OVHcloud-source-2025` and click on `Create`.

 

### Set up the Bucket Replication to OVHcloud Object Storage

1. Go to `Protection` > `Object Replication` and `Bucket Replication Link`.

2. Click the `+` button to create a bucket replica link.

3. Select the bucket you just created.

4. Select `OVHCLOUD_OBJECT_STORAGE` for Remote Array.

5. Add the name of your OVHcloud Object Storage bucket: `OVHcloud-dest-2025`.

6. Add your remote credentials: `OVHcloud_credentials`. The bucket replica link will be created.

   ![editObjectReplicaLink.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-pure-storage-flashblade/43580181074067.png)

7. You can now test and validate the bucket replication from Pure Storage Flashblade platform to OVHcloud Object Storage.
