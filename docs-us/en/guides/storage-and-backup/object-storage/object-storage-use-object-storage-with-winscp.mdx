# Object Storage - Use Object Storage with WinSCP

**Learn how to configure WinSCP to manage your buckets and objects.**

[WinSCP](https://winscp.net/) is an open-source free SFTP client, FTP client, WebDAV client, S3 client, SCP client, and file manager for Windows.

 

## Requirements

- A bucket
- A user with the required access rights on the bucket
- Your Object Storage credentials (`access_key` and `secret_access_key`; see our [Getting started with Object Storage](https://support.us.ovhcloud.com/hc/en-us/articles/4603838122643) guide)

 

## Instructions

Start WinSCP. The login dialog will appear. Fill in the fields as follows:

1. Make sure the `New Site` node is selected.

   ![PCI\_OS\_configOS\_useWinSCP01.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-winscp/37728087966995.png)

2. On the `New Site` node, select `Amazon S3` protocol.

   ![PCI\_OS\_configOS\_useWinSCP02.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-winscp/37728087971347.png)

3. Enter your endpoint (without `https://`) corresponding to your storage class and set the `Port number` field to `443`.

   :::info

   To identify your endpoint corresponding to your storage class, please refer to this guide: [Endpoints and Object Storage Geoavailability](https://support.us.ovhcloud.com/hc/en-us/articles/10667991081107).

   :::

   ![PCI\_OS\_configOS\_useWinSCP03.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-winscp/37728092961427.jpg)

4. Enter your user's `access_key`.

   To respect best practices, please fill in only the `Access key ID` field at this stage.

   ![PCI\_OS\_configOS\_useWinSCP04.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-winscp/37728087979667.jpg)

5. Save your site settings using the `Save` button.

   ![PCI\_OS\_configOS\_useWinSCP05.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-winscp/37728087982099.png)

6. Log in using the `Login` button.

   ![PCI\_OS\_configOS\_useWinSCP06.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-winscp/37728087985555.jpg)

   Then enter your `secret_access_key`.

   ![PCI\_OS\_configOS\_useWinSCP07.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-winscp/37728087989139.png)

7. Once you are connected, you will see a list of your S3 buckets as *folders* in the root folder.

   :::warning

   **NOTE:** The `Create directory` command in the root folder creates a new bucket.

   :::

   ![PCI\_OS\_configOS\_useWinSCP08.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-winscp/37728087991955.png)
