# Object Storage – Use Object Storage with Cohesity NetBackup

This guide covers the steps to add a cloud volume, configure optional WORM (Write Once Read Many) settings, and integrate the storage into NetBackup backup policies.

 

## Requirements

- A NetBackup Primary Server installed and configured. See the following documentation: "[Installing NetBackup Primary Server](https://www.veritas.com/support/en_US/doc/27801100-157469020-0/v13834345-157469020)".
- A Media Server with a deduplication option installed on Red Hat Enterprise or SUSE Linux Enterprise Server. See the following documentation: "[Deduplication Guide](https://www.veritas.com/support/en_US/doc/25074086-168257404-0/index)".
- Approximately 1 TB of local disk space is available for deduplication metadata management.

 

## Instructions

This section provides a step-by-step guide to configuring a deduplicated Disk Pool using OVHcloud Object Storage as a cloud volume in Cohesity[\[1\]](#go-further) NetBackup.

You will be guided through the entire process, from selecting the Storage Server to integrating the configuration into your backup policies. Each step is accompanied by a screenshot to assist with setup.

1. Ensure that an MSDP Storage Server is already created.

2) Log in to the NetBackup interface as an administrator.

   ![cohesity\_loginScreen.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775487495571.png)

3. Access the `Storage` menu, the `Disk storage` submenu, then click the `Storage Servers` tab.

   ![cohesity\_storageServersTab.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775503661587.png)

4) Open the `Disk Pools` tab and click on `+ Add` to create a new Disk Pool.

   ![cohesity\_diskPoolsTab.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775487500051.png)

5. Select the `Storage Server MSDP` on which you want to create the deduplicated pool.

   ![cohesity\_selectMSDPserver.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775487502227.png)

6) When selecting the volume, click on `Add Cloud Volume`.

   ![cohesity\_addCloudVolume.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775487506195.png)

7. Choose `OVHcloud Standard Object Storage` as the cloud storage type.

   ![cohesity\_selectOVHcloud.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775487507603.png)

8) Select the desired endpoint, and add the OVHcloud credential if not already done.

   ![cohesity\_selectEndpoint.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775503669907.png)

9. (Optional) To enable WORM mode (S3 Object Lock), check `Use Object Lock`. Select the NetBackup lock mode matching the OVHcloud Object Lock mode:

   - Compliance -> Compliance
   - Enterprise -> Governance

   Then, set the minimum and maximum retention periods for the lock.

   ![cohesity\_enableWORM.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775487510547.png)

10) Enter the name of the bucket you want to use, or create a new one.

    ![cohesity\_nameBucket.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775503673363.png)

11. Click on `Next`, then review the settings in the Review tab.

    ![cohesity\_reviewSettings.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775503678227.png)

12) Click on `Add Storage Unit` at the top of the screen, then name the storage unit.

    ![cohesity\_addStorageUnit.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775487515283.png)

    ![cohesity\_nameStorageUnit.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775503681171.png)

13. (Optional) To enable WORM locking, check `Lock until Expiration`.

    :::info

    Note: WORM and non-WORM data can coexist within the same deduplicated Disk Pool.

    :::

14) Review all settings in the Review tab, then confirm.

    ![cohesity\_confirmSettings.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775503682835.png)

15. You can now:

    - Use the storage unit directly in your backup jobs,
    - Or use it as a secondary target via a Storage Lifecycle Policy (SLP).

16) Modify your backup policies accordingly to integrate OVHcloud Object Storage.

    ![cohesity\_backupPolicies01.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775487518611.png)

    ![cohesity\_backupPolicies02.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775487522067.png)

    ![cohesity\_backupPolicies03.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775487523987.png)

    ![cohesity\_backupPolicies04.png](/images/storage-and-backup/object-storage/object-storage-use-object-storage-with-cohesity-netbackup/42775487525523.png)
