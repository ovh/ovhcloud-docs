# Object Storage - Use Object Storage with WinSCP

**Learn how to configure WinSCP to manage your buckets and objects.**

[WinSCP](https://winscp.net/) is an open-source free SFTP client, FTP client, WebDAV client, S3 client, SCP client, and file manager for Windows.

 

## Requirements

- A bucket
- A user with the required access rights on the bucket
- Your Object Storage credentials (`access_key` and `secret_access_key`; see our [Getting started with Object Storage](/guides/storage-and-backup/object-storage/getting-started) guide)

 

## Instructions

Start WinSCP. The login dialog will appear. Fill in the fields as follows:

1. Make sure the `New Site` node is selected.

   ![Object storage configuration WinSCP - step 1](/images/storage-and-backup/object-storage/winscp/object-storage-config-winscp-step-1.png)

2. On the `New Site` node, select `Amazon S3` protocol.

   ![Object storage configuration WinSCP - step 2](/images/storage-and-backup/object-storage/winscp/object-storage-config-winscp-step-2.png)

3. Enter your endpoint (without `https://`) corresponding to your storage class and set the `Port number` field to `443`.

   :::info

   To identify your endpoint corresponding to your storage class, please refer to this guide: [Endpoints and Object Storage Geoavailability](/guides/storage-and-backup/object-storage/endpoints-geoavailability).

   :::

   ![Object storage configuration WinSCP - step 3](/images/storage-and-backup/object-storage/winscp/object-storage-config-winscp-step-3.jpg)

4. Enter your user's `access_key`.

   To respect best practices, please fill in only the `Access key ID` field at this stage.

   ![Object storage configuration WinSCP - step 4](/images/storage-and-backup/object-storage/winscp/object-storage-config-winscp-step-4.jpg)

5. Save your site settings using the `Save` button.

   ![Object storage configuration WinSCP - step 5](/images/storage-and-backup/object-storage/winscp/object-storage-config-winscp-step-5.png)

6. Log in using the `Login` button.

   ![Object storage configuration WinSCP - step 6](/images/storage-and-backup/object-storage/winscp/object-storage-config-winscp-step-6.jpg)

   Then enter your `secret_access_key`.

   ![Object storage configuration WinSCP 6](/images/storage-and-backup/object-storage/winscp/object-storage-config-winscp-step-6-b.png)

7. Once you are connected, you will see a list of your S3 buckets as *folders* in the root folder.

   :::warning

   **NOTE:** The `Create directory` command in the root folder creates a new bucket.

   :::

   ![Object storage configuration WinSCP - step 7](/images/storage-and-backup/object-storage/winscp/object-storage-config-winscp-step-7.png)
