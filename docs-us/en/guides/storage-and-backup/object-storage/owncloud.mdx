# Object Storage - Use Object Storage with Owncloud

**Learn how to set up storage in Owncloud to use an Object Storage container.**

Owncloud is a suite of client-server software for creating and using file hosting services.

 

## Requirements

- a container (see our [Getting Started with Object Storage](/guides/storage-and-backup/object-storage/getting-started) guide)
- a user with the required access rights on the container
- your Object Storage credentials (access\_key and secret\_access\_key)

:::info

To identify the endpoint corresponding to your storage class, please refer to our [Endpoints and Object Storage Geoavailability](/guides/storage-and-backup/object-storage/endpoints-geoavailability) guide.

:::

 

## Instructions

If needed, install the `External Storage: S3` plugin from the `Market`.

![OpenIO ownCloud - ownCloud - step 1](/images/storage-and-backup/object-storage/owncloud/openio-owncloud-1.png)

Search for the `External Storage: S3` plugin.

![OpenIO ownCloud - ownCloud - step 2](/images/storage-and-backup/object-storage/owncloud/openio-owncloud-2.png)

`Install` it.

![OpenIO ownCloud - ownCloud - step 3](/images/storage-and-backup/object-storage/owncloud/openio-owncloud-3.png)

Go to the `Settings`.

![OpenIO ownCloud - ownCloud - step 4](/images/storage-and-backup/object-storage/owncloud/openio-owncloud-4.png)

Then :

1. in `Storage`
2. enable `Enable external storage`
3. name your folder
4. add an `Amazon S3 compatible storage (SDK v3)`

![OpenIO ownCloud - ownCloud - step 5](/images/storage-and-backup/object-storage/owncloud/openio-owncloud-5.png)

Fill in the following information:

1. Enter the name of your container
2. Set the host as: `s3.<region_in_lowercase>.io.cloud.ovh.us`
3. Set the port to 443
4. Specify the region
5. Activate SSL
6. Enter your access key
7. Enter your secret key

![OpenIO ownCloud - ownCloud - step 6](/images/storage-and-backup/object-storage/owncloud/openio-owncloud-6.png)

Go to `Files`.

![OpenIO ownCloud - ownCloud - step 7](/images/storage-and-backup/object-storage/owncloud/openio-owncloud-7.png)

Then navigate to `External storage`.

![OpenIO ownCloud - ownCloud - step 8](/images/storage-and-backup/object-storage/owncloud/openio-owncloud-8.png)

The result should be similar to this:

![OpenIO ownCloud - ownCloud - step 9](/images/storage-and-backup/object-storage/owncloud/openio-owncloud-9.png)
