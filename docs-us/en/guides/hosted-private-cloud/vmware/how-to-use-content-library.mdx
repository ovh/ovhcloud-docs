# Deploy an OVF Template through Content Libraries

**Learn how to deploy OVF templates offered by OVHcloud.**

OVHcloud offers OVF templates that you can deploy directly from your vSphere *(version 7.0 or later)* across [content libraries](https://docs.vmware.com/en/VMware-vSphere/7.0/com.vmware.vsphere.vm_admin.doc/GUID-254B2CE8-20A8-43F0-90E8-3F6776C2C896.html).

 

## Requirements

- web client access (HTML5)

 

## Instructions

### Step 1 - Deploying a template

:::tip

Click each tab across the top to view all content.

:::

<Tabs>

<Tab label="From a content library">

You can find the content libraries your vSphere has signed up to via your vSphere homepage, by clicking the `Content Libraries` icon.

![VM managing deploy ovf - step 1](/images/hosted-private-cloud/vmware/how-to-use-content-library/vm-managing-deploy-ovf-01.png)

Then click on one of the libraries to view their contents and deploy a new virtual machine from the `OVF & OVA Templates` tab.

![VM managing deploy ovf - step 2](/images/hosted-private-cloud/vmware/how-to-use-content-library/vm-managing-deploy-ovf-02.png)

</Tab>

<Tab label="Directly from the Cluster view">

You can also deploy content from libraries directly from the *Cluster* view by right-clicking one of your clusters and selecting `New Virtual Machine`.

![VM managing deploy ovf - step 3](/images/hosted-private-cloud/vmware/how-to-use-content-library/vm-managing-deploy-ovf-03.png)

Then select the `Deploy from template` option.

![VM managing deploy ovf - step 4](/images/hosted-private-cloud/vmware/how-to-use-content-library/vm-managing-deploy-ovf-04.png)

Click on one of the templates offered by the content libraries installed on your vSphere.

![VM managing deploy ovf - step 5](/images/hosted-private-cloud/vmware/how-to-use-content-library/vm-managing-deploy-ovf-05.png)

</Tab>

</Tabs>

 

### Step 2 - Configuring the template

The template deployment process will ask you to confirm the details and a destination for the new virtual machine (data center, cluster, datastore, etc.).

![VM managing deploy ovf - step 6](/images/hosted-private-cloud/vmware/how-to-use-content-library/vm-managing-deploy-ovf-06.png)

Some templates accept deployment properties that allow you to quickly configure the new virtual machine by creating, for example, a privileged user or configuring the main network interface.

![VM managing deploy ovf - step 7](/images/hosted-private-cloud/vmware/how-to-use-content-library/vm-managing-deploy-ovf-07.png)

Templates that do not offer customization will have the default credentials specified in the virtual machine notes.
