# DHCP Configuration in NSX

**In this guide, you will learn how to configure a DHCP server in a segment.**

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://us.ovhcloud.com/hosted-private-cloud/vmware/) to receive login credentials.
- A user account with access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub).
- Having **NSX** deployed with two overlay and VLAN segments configured in your NSX configuration. Use our guide on [Segment Management in NSX](/guides/hosted-private-cloud/vmware/nsx-segment-management) for more information.

## Instructions

We will configure DHCP for :

- An overlay segment behind the gateway **ovh-T1-gw**
- A segment on a VLAN connected to the gateway **ovh-T1-gw**.

### Common DHCP configuration for all overlay segments

First we will create a DCHP server common to all segments in Overlay.

1. Through the NSX interface, go to the `Networking` tab.
2. Click on `Networking Profiles` on the left in the **Settings** section.
3. Go to the `DHCP` tab and click `ADD DHCP PROFILE`.

![DHCP configuration - step 1](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-01.jpg)

 

Type `Name` in **Name** and click `SAVE`.

![DHCP configuration - step 2](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-02.jpg)

 

The DCHP server is active, it uses a network in 100.96.0.1/30, do not use this network in one of your segments.

![DHCP configuration - step 3](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-03.jpg)

### DHCP assignment to the ovh-T1-gw gateway

In the `Networking` tab, click on `Tier-1-Gateways` on the left in the **Connectivity** section.

![DHCP configuration - step 4](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-04.jpg)

 

Click the `three vertical dots` and choose `Edit` from the menu.

![DHCP configuration - step 5](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-05.jpg)

 

Click `Set DHCP Configuration`.

![DHCP configuration - step 6](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-06.jpg)

 

Choose `DHCP Server` from **Type** and your `DHCP profile` from **DHCP Server Profile**. Then click `SAVE`.

![DHCP configuration - step 7](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-07.jpg)

 

Click `SAVE`.

![DHCP configuration - step 8](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-08.jpg)

 

Click `CLOSE EDITING`.

![DHCP configuration - step 9](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-09.jpg)

### Setting up DHCP on an Overlay segment

From the NSX interface, go to the `Networking` tab and click on `Segments` on the left in the **Connectivity** section.

Go to the `Segments` section, click on the configuration icon indicated with `three vertical dots` to the left of your segment and choose `Edit`.

![DHCP configuration - step 10](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-10.jpg)

 

Click `Set DHCP CONFIG`.

![DHCP configuration - step 11](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-11.jpg)

Fill in this information :

- **DHCP Type** : Leave `Gateway DHCP Server`.
- **DHCP Ranges** : Enter your range `192.168.1.10-192.168.1.200`.
- **DNS Servers** : Add OVHcloud DNS server `213.186.33.99`.

Click on `APPLY`.

![DHCP configuration - step 12](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-12.jpg)

 

Click `SAVE`.

![DHCP configuration - step 13](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-13.jpg)

 

Click `CLOSE EDITING`.

![DHCP configuration - step 14](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-14.jpg)

Virtual machines in this segment can now be configured with DHCP.

### Setting up DCHP on a VLAN segment

On a VLAN segment it is not possible to use the profile created for Overlay segments.

In order to have a DHCP server on this segment, we will create a DHCP configuration with a new profile directly attached to the segment.

If you do not have a VLAN type segment, use the [Segment Management in NSX](/guides/hosted-private-cloud/vmware/nsx-segment-management) guide to create it with these settings :

- **VLAN Subnet**: 192.168.100.0/24.
- **Gateway and interface IP address** : 192.168.100.254/24.

Go to the `Networking` tab, click on `Segments` on the left in the **Connectivity** section, then click on the `three vertical dots` on the left of your VLAN segment and choose `Edit` from the menu.

![DHCP configuration - step 15](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-15.jpg)

 

Click `SET DHCP CONFIG`.

![DHCP configuration - step 16](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-16.jpg)

 

Leave `Local DHCP Server` in **DHCP Type**, click the `three vertical dots` to the right of **DHCP Profile** and choose `Create New` from the menu.

![DHCP configuration - step 17](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-17.jpg)

Enter this information :

- **Name**: Leave `DHCP-VLAN100`.
- **Server IP Address** : IP address of DHCP server `192.168.100.253/24`.

Then select your `Edge Cluster` and click `SAVE`.

![DHCP configuration - step 18](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-18.jpg)

Verify in **DHCP Profile** that the profile is present and enter this information :

- **DHCP Server** : DHCP server address `192.168.100.253/24`.
- **DHCP Ranges** : DHCP Server range `192.168.100.10-192.168.100.200`.
- **DNS Servers** : OVHcloud DNS server IP address `213.186.33.99`.

Then click `APPLY`.

![DHCP configuration - step 19](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-19.jpg)

 

Click `SAVE`.

![DHCP configuration - step 20](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-20.jpg)

 

Click `CLOSE EDITING`.

![DHCP configuration - step 21](/images/hosted-private-cloud/vmware/nsx-configure-dhcp-onsegment/dhcp-config-21.jpg)

The DHCP server is active on this VLAN segment.

## Conclusion

Having read this guide, you should be able to configure a DHCP server in a segment.
