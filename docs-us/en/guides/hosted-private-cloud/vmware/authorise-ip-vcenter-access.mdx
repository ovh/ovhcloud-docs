# Authorizing IP addresses for vCenter access

Access to your vCenter environment can be restricted by allowing only certain IP addresses or ranges to connect to it.

 

## Requirements

- Access to the [OVHcloud Control Panel](https://manager.us.ovhcloud.com/manager/)
- A [VMware on OVHcloud](https://us.ovhcloud.com/hosted-private-cloud/vmware/) service in your account
- An active vSphere user (see [this guide](/guides/hosted-private-cloud/vmware/introduction-ovhcloud-control-panel))

**Navigation**

- Access your [Managed VMware vSphere services list](https://manager.us.ovhcloud.com/#/dedicated/dedicated_cloud/) directly, or
- Click `Hosted Private Cloud` > `Managed VMware vSphere` > `your PCC` > `Security` tab

 

## Instructions

### Authorizing IP addresses for vCenter access

From the `Security` tab, click the `Add a new IP address range` button in the right-hand menu.

![VMware security tab](/images/hosted-private-cloud/vmware/authorise-ip-vcenter-access/vmware-security-tab.png)

In the new window, enter an IP address range that should be allowed access to vCenter.

You can also add a description to make the organization of the whitelist easier.

Click `Next`.

![VMware security tab add IP - step 1](/images/hosted-private-cloud/vmware/authorise-ip-vcenter-access/vmware-security-tab-add-ip-1.png)

Once you have confirmed the information is correct, click `Confirm` to apply your changes. Connections from this IP address (range) will now be possible.

![VMware security tab add IP - step 2](/images/hosted-private-cloud/vmware/authorise-ip-vcenter-access/vmware-security-tab-add-ip-2.png)

:::info

Please note that for security reasons, you will only be able to allow a maximum of 2048 IP addresses to connect to your vCenter.

:::
