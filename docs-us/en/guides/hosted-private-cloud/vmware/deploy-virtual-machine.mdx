# Deploying a virtual machine

**Learn how to deploy a virtual machine by in the vSphere interface.**

In the vSphere interface, multiple methods to deploy a virtual machine (VM).

 

## Requirements

- A [Hosted Private Cloud infrastructure](https://us.ovhcloud.com/hosted-private-cloud/vmware/)
- A user account with access to vSphere (created in the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/))

 

## Instructions

### Deploying a virtual machine

A new VM can be deployed from the vSphere client. Right-click on your data centre (or use the `ACTIONS` button) and select `New Virtual Machine`.

![Deploy virtual machine - step 1](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-01.png)

There are multiple methods for creating a new VM:

- It is possible to create it and select an ISO from your datastore in the process. You can upload ISO files by connecting via SFTP.
- You can deploy a VM from your own template, an external template, or an OVHcloud template.
- You can clone an existing VM (be careful to avoid IP address conflicts).
- You can clone a VM into a template so that you can deploy your next VM more quickly.
- You can clone a template into another template. Make use of this, for example, to have the template available on different datastores and thus prevent performance loss during a massive deployment.
- You can convert a template into a VM. This will cause the template to be lost but may be useful if you want to modify it.

![Deploy virtual machine - step 2](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-02.png)

The following instructions will focus on deploying a VM using an ISO (`Create a new virtual machine`).

The next step allows you to define a name for the VM and choose a location. If you do not choose a folder, it will be created at the root of the data center.

![Deploy virtual machine - step 3](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-03.png)

You can then choose the cluster, host, [resource pool](https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/6-7/vsphere-resource-management-6-7.html), or [vApp](https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/6-7/vsphere-virtual-machine-administration-guide-6-7.html) to place it.

In this case, the VM will be deployed according to the configured DRS rules, and will be placed at the root of the cluster.

![Deploy virtual machine - step 4](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-04.png)

Next, you can choose the database in which you would like to store the configuration and disk files.

We do not recommend placing your VM in "storageLocal", which corresponds to the local storage of your host. If your host fails, your VM will not be able to restart and will no longer be accessible.

![Deploy virtual machine - step 5](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-05.png)

Then select the compatibility between your VM and the host. Unless otherwise noted, it is recommended that you choose the latest one.

![Deploy virtual machine - step 6](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-06.png)

In this step, choose a guest OS. This does not install the OS; it pre-configures the VM for its usage (CPU/RAM, type of NIC, support for VMware Tools installation).

![Deploy virtual machine - step 7](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-07.png)

 

### Configuring the virtual machine

Follow the next steps to configure your VM's resources.

The row `New Network` allows to add a network adapter:

- "VM Network" is used for the public network and direct internet access
- The VLANs will allow you to use the private network between your virtual machines (and other OVHcloud services when using vRack)

![Deploy virtual machine - step 8](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-08.png)

In the row `New CD/DVD Drive`, you can select "Datastore ISO File".

A new window will open where you can browse to your ISO file. It can also be added after the VM is created.

![Deploy virtual machine - step 9](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-09.png)

Once the file is selected, it will be displayed as shown below. Do not forget to tick the `Connect At Power On` option.

![Deploy virtual machine - step 10](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-10.png)

A summary of the VM specifications will be displayed. To change your configuration, you can click one of the configuration steps on the left-hand sidebar.

Click on `FINISH` to finalize the deployment.

![Deploy virtual machine - step 11](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-11.png)

 

Once the VM is ready, you can start it by right-clicking on it and then clicking on `Power` and `Power On`.

Finally, click on `Open Remote Console` to access the 'screen' of the VM and begin the installation of the operating system.

![Deploy virtual machine - step 12](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-12.png)

The console will open in a new tab and, after you have completed the installation, you will be able to use your VM.

![Deploy virtual machine - step 13](/images/hosted-private-cloud/vmware/deploy-virtual-machine/vm-13.png)

:::info

Once your VM is installed, it is recommended that you disconnect the ISO in the settings. Otherwise, you will not be able to move the VM.

:::
