# Adding a New Tier-1 Gateway in NSX

OVHcloud provides you with NSX with two gateways, a north-south gateway (ovh-T0-gw) and an east-west gateway (ovh-T1-gw). You can create additional east-west gateways.

**Learn how to add an east-west (Tier-1 Gateway) gateway to your NSX configuration.**

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://us.ovhcloud.com/hosted-private-cloud/vmware/) to receive login credentials.
- A user account with access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub).
- Having **NSX** deployed.

:::warning

**NOTE:&#x20;**&#x54;hrough your NSX interface, you can create north-south gateways. We strongly advise you not to do it because some options are not available and you will not be able to make such a gateway work correctly.

:::

For more information on NSX at OVHcloud, please refer to our [Getting Started with NSX](/guides/hosted-private-cloud/vmware/nsx-first-steps) guide.

## Instructions

We will add a new east-west gateway (Tier-1-Gateways) and link it to the north-south gateway provided by OVHcloud (ovh-T0-gw).

Next, we will create a segment and attach a virtual machine to it.

### Creation of the new east-west gateway

In the NSX interface, go to the `Networking` tab.

- Click on `Tier-1 Gateway` on the left.
- Then click on `ADD TIER-1 GATEWAY`.

![Tier 1 - NSX add new tier1 gateway - step 1](/images/hosted-private-cloud/vmware/nsx-add-new-tier1-gateway/tier-1-01.png)

Enter the name of your new gateway as `new-T1-gw` below **Name** and fill in these parameters:

- **Linked Tier-0-Gateway** : Your north-south gateway `ovh-T0-gw`.
- **Edge Cluster** : Your `edgeXXX-X`.
- **Fail Over** : `Non Preemptive`.
- **Edge Pool Allocation Size** : `Routing`.

Then click the `Arrow` to the left of **Route Advertisement**.

![Tier 1 - NSX add new tier1 gateway - step 2](/images/hosted-private-cloud/vmware/nsx-add-new-tier1-gateway/tier-1-02.png)

 

Select the `button` to the right of **All Connected Segment & Service Ports** if you want to connect outside this gateway, then click `SAVE`.

![Tier 1 - NSX add new tier1 gateway - step 3](/images/hosted-private-cloud/vmware/nsx-add-new-tier1-gateway/tier-1-03.png)

 

Click `NO`.

![Tier 1 - NSX add new tier1 gateway - step 4](/images/hosted-private-cloud/vmware/nsx-add-new-tier1-gateway/tier-1-04.png)

 

Your new gateway is displayed and we can see it connected to your north-south gateway (ovh-T0-gw).

![Tier 1 - NSX add new tier1 gateway - step 5](/images/hosted-private-cloud/vmware/nsx-add-new-tier1-gateway/tier-1-05.png)

 

Click `Network Topology` in the vertical menu bar to the left to view your network topology and to display your new **new-T1-gw** gateway connected to **ovh-T0-gw**.

![Tier 1 - NSX add new tier1 gateway - step 6](/images/hosted-private-cloud/vmware/nsx-add-new-tier1-gateway/tier-1-06.png)

### Adding a segment on your new gateway

Go to `Segments` on the left and click `ADD SEGMENT`.

![Tier 1 - NSX add new tier1 gateway - step 7](/images/hosted-private-cloud/vmware/nsx-add-new-tier1-gateway/tier-1-07.png)

Fill in this information :

- **Name** : Name of your segment `ov3-segment`.
- **Connected Gateway** : Your new gateway `new-T1-gw`.
- **Transport Zone** : Your subnet `192.168.120.254/24`.

Click `SAVE`.

![Tier 1 - NSX add new tier1 gateway - step 8](/images/hosted-private-cloud/vmware/nsx-add-new-tier1-gateway/tier-1-08.png)

 

Click `NO`.

![Tier 1 - NSX add new tier1 gateway - step 9](/images/hosted-private-cloud/vmware/nsx-add-new-tier1-gateway/tier-1-09.png)

Your new segment is created and connected to your new **new-T1-gw** gateway.

### Displaying a complete configuration with a virtual machine on your segment

The new segment is an Overlay segment but it is possible to add a VLAN segment and connect it to your new gateway.

Use our guide on [Segment Management in NSX](/guides/hosted-private-cloud/vmware/nsx-segment-management) to add a new virtual machine to your new segment.

Then click `Network Topology`.

![Tier 1 - NSX add new tier1 gateway - step 10](/images/hosted-private-cloud/vmware/nsx-add-new-tier1-gateway/tier-1-10.png)

## Conclusion

Having read this guide, you should be able to add an east-west (Tier-1 Gateway) gateway to your NSX configuration.
