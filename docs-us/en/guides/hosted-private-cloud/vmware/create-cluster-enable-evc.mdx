# Cluster creation and EVC activation

**Learn how to create multiple clusters in your environment to segment your activities and configure their functionalities (DRS, HA, and EVC).**

 

## Requirements

- be an administrative contact of your [Hosted Private Cloud infrastructure](https://us.ovhcloud.com/hosted-private-cloud/vmware/) to receive login credentials
- a user account with access to vSphere (created in the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/))

 

## Instructions

### Cluster creation

In the vSphere interface menu, go to the `Hosts and Clusters` dashboard.

![VMware sphere creation evc - step 1](/images/hosted-private-cloud/vmware/create-cluster-enable-evc/vmware-sphere-creation-evc-01.png)

Right-click your Datacenter and select `New Cluster`.

![VMware sphere creation evc - step 2](/images/hosted-private-cloud/vmware/create-cluster-enable-evc/vmware-sphere-creation-evc-02.png)

In the pop-up window, name your cluster and select the relevant options you want set.\
Click `OK` when done.

:::info

vSAN requires vSAN-compatible hosts. Find more details [here](/guides/hosted-private-cloud/vmware/introduction-ovhcloud-control-panel) on how to order them if needed.

:::

![VMware sphere creation evc - step 3](/images/hosted-private-cloud/vmware/create-cluster-enable-evc/vmware-sphere-creation-evc-03.png)

 

### DRS

DRS spreads the compute load across your hosts. If you activate the option, it is set to "Fully Automated" by default.

Select your cluster. In the `Configure` tab, select `vSphere DRS` and click `Edit`.

![VMware sphere creation evc - step 4](/images/hosted-private-cloud/vmware/create-cluster-enable-evc/vmware-sphere-creation-evc-04.png)

Three options are available to you:

- **Manual Mode:** DRS generates both power-on placement and migration recommendations for virtual machines. Recommendations need to be manually applied or ignored.
- **Partially Automated:** DRS automatically places virtual machines onto hosts at VM power-on. Migration recommendations need to be manually applied or ignored.
- **Fully Automated:** DRS automatically places virtual machines onto hosts at VM power-on, and virtual machines are automatically migrated from one host to another to optimize resource utilization.

Automated modes also allow to set the sensitivity of the service, from the most conservative to the most aggressive threshold.\
Click `OK` when done.

![VMware sphere creation evc - step 5](/images/hosted-private-cloud/vmware/create-cluster-enable-evc/vmware-sphere-creation-evc-05.png)

 

### HA

High Availability allows for redundancy so a failing host will not impact the services running in your VMs. If you activate the option, it is set to its default settings.

To modify them, select your cluster. In the `Configure` tab, select `vSphere HA` and click `Edit`.

![VMware sphere creation evc - step 6](/images/hosted-private-cloud/vmware/create-cluster-enable-evc/vmware-sphere-creation-evc-06.png)

The response types for the different host failures can be custom-set to your needs.\
Click `OK` when done.

![VMware sphere creation evc - step 7](/images/hosted-private-cloud/vmware/create-cluster-enable-evc/vmware-sphere-creation-evc-07.png)

 

### EVC

EVC (Enhanced vMotion Compatibility) allows for migration of live VMs between hosts.

Before activating the functionality, check your hosts' summary pages to determine their types.

![VMware sphere creation evc - step 8](/images/hosted-private-cloud/vmware/create-cluster-enable-evc/vmware-sphere-creation-evc-08.png)

Select your cluster. In the `Configure` tab, select `VMware EVC` and click `Edit`.

![VMware sphere creation evc - step 9](/images/hosted-private-cloud/vmware/create-cluster-enable-evc/vmware-sphere-creation-evc-09.png)

Enable EVC for the type of CPUs your hosts hold.\
Downward compatibility is assured. To help you verify the settings are working, you will see a compatibility validation at the bottom of the window.\
Click `OK` when done.

![VMware sphere creation evc - step 10](/images/hosted-private-cloud/vmware/create-cluster-enable-evc/vmware-sphere-creation-evc-10.png)

:::warning

**NOTE:** EVC activation can only happen on a cluster with no active VM running. Make sure to turn off or evacuate all VMs before doing it.

:::
