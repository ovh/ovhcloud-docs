# How to Use the VMware Update Manager

**Learn about the Update Manager functionalities in vSphere.**

VMware Update Manager allows you to keep your hosts up to date by installing Bug Fixes and Security Patches without intervention from our team.

:::info

vCenter updates or major updates will still require our involvement.

:::

 

## Requirements

- being an administrative contact of your [Hosted Private Cloud infrastructure](https://us.ovhcloud.com/hosted-private-cloud/) to receive login credentials.
- a user account with access to vSphere (created in the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/))

 

## Instructions

### Maintenance Mode

Before working on a host, you will need to put it in maintenance mode. Patching often requires a host restart, which would impact your live VMs. With that in mind, in the vSphere interface menu, go to the `Hosts and Clusters` dashboard.

![VMware sphere update manager - step 1](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-01.png)

 

On the left side, find your host and right-click on it. In the `Maintenance Mode` section, select `Enter Maintenance Mode`.

![VMware sphere update manager - step 2](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-02.png)

 

Make sure the box in the following window is checked and click `OK`.

![VMware sphere update manager - step 3](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-03.png)

 

Assuming DRS is implemented, any live VM will be moved.

:::info

If you customized your environment, you may have to manually move live VMs from your host before putting it in Maintenance Mode.

:::

You may see the following warning:

![VMware sphere update manager - step 4](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-04.png)

 

Your host is now showing in maintenance mode.

![VMware sphere update manager - step 5](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-05.png)

 

### Update Manager

Select your host and go to the `Update` tab.

You can see a summary of what is set and its compliance.\
Before trusting what is shown, let’s set the baseline against which compliance will be checked.

![VMware sphere update manager - step 6](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-06.png)

 

In the `Attached Baselines` section, click on `Attach` then `Attach Baseline or Baseline Group`.

![VMware sphere update manager - step 7](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-07.png)

 

There are predefined Baselines which are the recommended patching level for your hosts depending on the criticality of the updates.

:::info

We’ll be using the Critical Patches in this example but you can either use or create your own baselines. You can also apply several baselines to cover different scopes for the same host.

:::

Select the required baseline and click `Attach`.

![VMware sphere update manager - step 8](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-08.png)

 

Now, the compliance summary may look very different than it used to.

![VMware sphere update manager - step 9](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-09.png)

 

Back in the `Attached Baselines` section, check the box to select all assigned baselines and click on `Stage`.

![VMware sphere update manager - step 10](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-10.png)

 

Select the host and click on `Stage` again.

![VMware sphere update manager - step 11](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-11.png)

 

The staging process starts and will last for a while.

![VMware sphere update manager - step 12](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-12.png)

 

In the `Attached Baselines` section, check the box to select all assigned baselines and click on `Remediate`.

![VMware sphere update manager - step 13](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-13.png)

 

Select the host and click on `Remediate` again.

![VMware sphere update manager - step 14](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-14.png)

 

The updating process starts and will last for a while. Your host will restart if needed.

![VMware sphere update manager - step 15](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-15.png)

 

Once the process has gone through, the compliance check will happen again (you can force it by clicking on the check compliance link) and you will see a green checkmark on the Compliance level.

![VMware sphere update manager - step 16](/images/hosted-private-cloud/vmware/use-update-manager/vmware-sphere-update-manager-16.png)

 

:::tip

**SUCCESS!** Your host is now fully up-to-date. Take it out of maintenance mode and it will be back in production.

:::
