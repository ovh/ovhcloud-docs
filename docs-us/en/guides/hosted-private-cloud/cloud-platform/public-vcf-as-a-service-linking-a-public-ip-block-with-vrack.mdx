# Public VCF as-a-Service - Linking a public IP block with vRack

When you order a new Public VCF as-a-Service organization, a vRack and a block of public IP addresses are delivered to you. This IP block is not directly linked to your vRack. You will need to link it manually.

 

## Requirements

- A [Public VCF as-a-Service](https://us.ovhcloud.com/public-vcf-aas/) on OVHcloud solution
- Being the technical administrator of the managed [VMware vSphere on OVHcloud](https://us.ovhcloud.com/hosted-private-cloud/vmware/) infrastructure

#### OVHcloud Control Panel Access

- **Direct link:** [Public VCF as-a-Service](https://manager.us.ovhcloud.com/#/vmware/public-vcf-aas/)
- **Navigation path:** `Hosted Private Cloud` > `Public VCF as-a-Service` > Select your organization

 

## Instructions

### Retrieve the vRack ID

From your VCF as-a-Service organization, select the `Virtual Datacenters` tab. Locate the vRack associated with your organization; it will appear with an ID in the format `pn-xxxxxxx`.

Click `the name` of your vRack.

![VCD\_virtualDatacenters.PNG](/images/hosted-private-cloud/cloud-platform/public-vcf-as-a-service-linking-a-public-ip-block-with-vrack/53703239408275.png)

 

### Add the IP block to the vRack

Select [the vRack](https://manager.us.ovhcloud.com/#/dedicated/vrack/) that you just identified.

Select the IP block to link to your vRack/organization and click `Add`.

![VCD\_ip-to-vrack.PNG](/images/hosted-private-cloud/cloud-platform/public-vcf-as-a-service-linking-a-public-ip-block-with-vrack/53703239409939.png)

The public IP block is now linked to your vRack.

To make these addresses usable inside your Public VCF as-a-Service environment, you also need to declare the public gateway in VMware Cloud Director (VCD).

Follow the guide [Public VCF as-a-Service - Declare the public IP gateway in VCD](https://support.us.ovhcloud.com/hc/en-us/articles/45827602588947) to complete this step.
