# How to change the user password

## Requirements

- Access to the [OVHcloud Control Panel](https://manager.us.ovhcloud.com/manager/)
- A [VMware on OVHcloud](https://us.ovhcloud.com/hosted-private-cloud/vmware/) service in your account
- An active vSphere user (see [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/18004084382355))

**Navigation**

- Access your [Managed VMware vSphere services list](https://manager.us.ovhcloud.com/#/dedicated/dedicated_cloud/) directly, or
- Click `Hosted Private Cloud` > `Managed VMware vSphere` > `your PCC` > `Users` tab

 

## Instructions

### Change password

From the `Users` tab, click the *more options* `...` button to the right of the user concerned and choose `Change password`.

![VMware\_usersTab\_moreOptions.PNG](/images/hosted-private-cloud/powered-by-vmware/how-to-change-the-user-password/49453184650387.png)

Enter a new password and click `Confirm`.

:::info

If you do not enter a password, a randomly generated password will be emailed to the user's associated address.

:::

![VMware\_usersTab\_changePassword.PNG](/images/hosted-private-cloud/powered-by-vmware/how-to-change-the-user-password/49453184652947.png)

:::warning

We recommend that you follow these best practices to ensure that your infrastructure is not compromised. Your password must:

- Have at least 8 characters.
- Have at least 3 character types.
- Not to be drawn from the dictionary.
- Not include personal information.
- Not be used for multiple access.
- Be stored in a password vault.
- Be changed every 3 months.
- Be different from previous passwords.

:::
