# Log in to the vSphere web interface

## Requirements

- You must be the administrator of the [Hosted Private Cloud - Managed vSphere](https://us.ovhcloud.com/hosted-private-cloud/vmware/) infrastructure.
- IP addresses added in the `Security` section of your OVHcloud Control Panel. For more information, please read our [Authorizing IP addresses for vCenter access](https://support.us.ovhcloud.com/hc/en-us/articles/1500007893502) guide.

#### OVHcloud Control Panel Access

- Direct link: [VMware vSphere](https://manager.us.ovhcloud.com/#/dedicated/dedicated_cloud/)
- Navigation path: `Hosted Private Cloud` > `Managed VMware vSphere` > Select your vSphere service

 

## Instructions

To log in to the managed vSphere Web interface, you need to use your OVHcloud account to generate a vSphere user.

 

### Step 1 - User management with vSphere and OVHcloud

<Tabs>

<Tab label="Via the OVHcloud Control Panel">

You can manage your login credentials via the OVHcloud Control Panel for your VMware product managed on OVHcloud.

Once you have selected your infrastructure, choose the `Users` tab.

From here you can `Create User`, or modify an existing user by clicking the *more options* `...` button on the right edge of that user's row.

</Tab>

<Tab label="Via the OVHcloud API">

:::info

If you are not familiar with using the oVHcloud API, please refer to our [First steps with the OVHcloud API](https://support.us.ovhcloud.com/hc/en-us/articles/360018130839) guide.

:::

Some example API calls are:

- Create a user

  <Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/user"} regions={["us"]} />

  > **Parameters:**
  >
  > `serviceName`: your service, i.e. pcc-xx-xx-xx-xx.
  >
  > `name`: the name of your user.

- Change a user password

  <Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/user/\{userId\}/changePassword"} regions={["us"]} />

  > **Parameters:**
  >
  > `serviceName`: your service, i.e. pcc-xx-xx-xx-xx.
  >
  > `name`: the ID of your user.

</Tab>

</Tabs>

 

### Step 2 - Log in to the managed vSphere Web interface

The HTML5 web client link is available in the `General information` tab of your service in the OVHcloud Control Panel. Alternatively, you customize the following URL for your service and type it directly into your browser: `https://pcc-xxx-xxx-xxx-xxx.ovh.us/ui/.`

Sign in to a local account using the credentials created in Step 1, and you will reach the **Summary** page of the vSphere Client.
