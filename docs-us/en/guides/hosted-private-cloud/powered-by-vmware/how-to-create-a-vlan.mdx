# How to Create a VLAN

OVHcloud sets up a base of 11 VLANs on your vRack.

**This guide explains how to create additional VLANs.**

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://us.ovhcloud.com/hosted-private-cloud/vmware/) to receive login credentials
- A user account with access to vSphere as well as the specific rights for Networking (created in the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub))

## Instructions

In the Hosted Private Cloud solutions, VLANs can be used to isolate private communications between different OVHcloud services that are vRack-compatible (Dedicated Server, Public Cloud instance, etc.).

First, go to your vSphere client's `Networking` view. Deploy the **vrack** folder then `right-click` on the **dVS** ending in *-vrack* and finally click on `New Distributed Port Group`.

![vlan01.png](/images/hosted-private-cloud/powered-by-vmware/how-to-create-a-vlan/17971944330643.png)

 

Choose a name for your **Port Group**, then click `NEXT`.

![vlan02.png](/images/hosted-private-cloud/powered-by-vmware/how-to-create-a-vlan/17971959780627.png)

 

Then configure the settings recommended by OVHcloud:

- **Port binding**: Static (reserving and assigning the port to a virtual machine)
- **Port allocation**: Elastic (allows the number of ports to be hot-wired)
- **Number of ports**: 24
- **VLAN type**: VLAN (the others are [PVLAN](https://kb.vmware.com/s/article/1010691) and Trunk)
- **VLAN ID**: 21 (knowing that the ID can be configured from 1 to 4096)
- Check the option *Customize default policies configuration*.

When you have made your selections, click `NEXT`.

![vlan03.png](/images/hosted-private-cloud/powered-by-vmware/how-to-create-a-vlan/17983796742035.png)

You have three security settings that can be activated according to your needs:

- *Promiscuous mode*: eliminates any filtering that the VM adapter can perform so that the guest operating system receives all observed traffic on the network.
- *MAC address changes*: when set to **Accept**, ESXi will accept requests to change the effective MAC address to an address other than the initial MAC address.
- *Forged transmits*: affects traffic transmitted from a virtual machine. When set to **Accept**, ESXi does not compare the source and effective MAC addresses.

When you have made your selections, click `NEXT`.

:::info

**NOTE:&#x20;**&#x54;he most frequent use of these three parameters is the CARP, especially used on **pfSense**.

:::

![vlan04.png](/images/hosted-private-cloud/powered-by-vmware/how-to-create-a-vlan/17974425142291.png)

 

Leave [Traffic shaping](https://docs.vmware.com/en/VMware-vSphere/6.5/com.vmware.vsphere.networking.doc/GUID-CF01515C-8525-4424-92B5-A982489BACE2.html) disabled, then click `NEXT`.

![vlan05.png](/images/hosted-private-cloud/powered-by-vmware/how-to-create-a-vlan/17974425144467.png)

 

In terms of load balancing, select *Route Based on IP hash*, which is the best method for redundancy and load balancing.

:::warning

**NOTE:&#x20;**&#x42;e careful when configuring the failover order: It is necessary to set the `lag1` uplink to *Active* (connection between the virtual network and the physical network), otherwise no communication between the hosts will be possible.

When you have made your selections, click `NEXT`.

:::

![vlan06.png](/images/hosted-private-cloud/powered-by-vmware/how-to-create-a-vlan/17974410987027.png)

 

Set `NetFlow` to disabled (traffic flow activity report), then click `NEXT`.

![vlan07.png](/images/hosted-private-cloud/powered-by-vmware/how-to-create-a-vlan/17974410990355.png)

 

Leave the `Block All Ports` value at "No" and click `NEXT`.

![vlan08.png](/images/hosted-private-cloud/powered-by-vmware/how-to-create-a-vlan/17974425176595.png)

 

You will then be presented with a summary of the changes. Click `FINISH` to confirm the creation.

![vlan09.png](/images/hosted-private-cloud/powered-by-vmware/how-to-create-a-vlan/17974425178899.png)

 

Here we can see that **VLAN21** is available and functional.

![vlan10.png](/images/hosted-private-cloud/powered-by-vmware/how-to-create-a-vlan/17974410994835.png)
