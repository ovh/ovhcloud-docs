# How to Restore a VM with Veeam Backup & Replication (Enterprise)

This article explores using the Veeam Backup & Replication application to perform a restore of a VM running in an HPC (Hosted Private Cloud) environment.

### **Prerequisites&#xA0;**

- [Veeam Backup & Replication Installed and Registered](https://support.us.ovhcloud.com/hc/en-us/articles/360002270130)
- [Veeam Configured to Interact with an HPC environment](https://support.us.ovhcloud.com/hc/en-us/articles/360002390824)
- [How to Backup a VM with Veeam Backup & Replication](https://support.us.ovhcloud.com/hc/en-us/articles/360002422384)

### **Topics**

- [Restoring an Entire VM (Linux and Windows)](#entire)
- []()[Restoring Guest File(s) - Microsoft Windows ONLY](#file)

### **Restoring an Entire VM (Linux and Windows)**

To start, from the **Home** tab, click the **Restore** button and then select the **VMware vSphere backup...** option.

![restore.png](/images/hosted-private-cloud/powered-by-vmware/how-to-restore-a-vm-with-veeam-backup-replication-enterprise/restore-png.png)

From the "Restore Wizard" pop-up window, select the **Entire VM (including registration)** option and then click the **Next** button.

![restore\_wizard.jpg](/images/hosted-private-cloud/powered-by-vmware/how-to-restore-a-vm-with-veeam-backup-replication-enterprise/restore-wizard-jpg.jpg)

In the first section, "Virtual Machines", from the "Full VM Restore Wizard" pop-up window, click the **Add VM** button and then select the **From backup...** option.

In the "Backups Browser" pop-up window, select the appropriate restore point.

![backups\_browser.png](/images/hosted-private-cloud/powered-by-vmware/how-to-restore-a-vm-with-veeam-backup-replication-enterprise/backups-browser-png.png)

After making your selection, click the **Add** button to return to the "Restore Wizard" windows.

Then, click the **Next** button.

In the next section, "Restore Mode", select the location to restore the VM to. For the purpose of this article, we will select the **Restore to the original location** option.

**Note:** If VM tags are not used in your vSphere environment, then the "Restore VM tags" option may be unchecked. If you would like to know more about VM tags, please consult the [User Guide for VMware vSphere](https://helpcenter.veeam.com/docs/backup/vsphere/vm_tags.html?ver=95) provided by Veeam.

Then, click the **Next** button.

![restore\_mode.png](/images/hosted-private-cloud/powered-by-vmware/how-to-restore-a-vm-with-veeam-backup-replication-enterprise/restore-mode-png.png)

In the next section, "Reason", you may explain why you are performing a restore.

Then, click the **Next** button.

**Note:** If the VM is powered on, then you will receive the following notice:\
![power.png](/images/hosted-private-cloud/powered-by-vmware/how-to-restore-a-vm-with-veeam-backup-replication-enterprise/power-png.png)\
Click the **OK** button to continue.\
\
Additionally, you will receive the following notice:\
![delete.png](/images/hosted-private-cloud/powered-by-vmware/how-to-restore-a-vm-with-veeam-backup-replication-enterprise/delete-png.png)\
When a VM is restored to a destination where it already exists, Veeam deletes it and then performs the restore.\
\
Click the **OK** button to continue.

In the final section, "Summary", you may select the checkbox, **Power on target VM after restoring**, which will automatically power on the VM after the restore completes.

Lastly, click the **Finish** button to execute the restore.

You will see the progress of the restore job.

![progress.png](/images/hosted-private-cloud/powered-by-vmware/how-to-restore-a-vm-with-veeam-backup-replication-enterprise/progress-png.png)

Congratulations! You have successfully restored a VM[]().

### **Restoring Guest File(s) - Microsoft Windows ONLY**

**Warning:** In order to proceed with a guest file restore, the Microsoft Windows VM must be able to communicate with the Veeam Backup & Replication appliance via a network.

To start, from the **Home** tab, click the **Restore** button and then select the **VMware vSphere backup...** option.

![restore2.png](/images/hosted-private-cloud/powered-by-vmware/how-to-restore-a-vm-with-veeam-backup-replication-enterprise/restore2-png.png)

From the "Restore Wizard" pop-up window, select the **Guest files (Microsoft Windows)** option and then click the **Next** button.

![restore\_wizard2.png](/images/hosted-private-cloud/powered-by-vmware/how-to-restore-a-vm-with-veeam-backup-replication-enterprise/restore-wizard2-png.png)

From the "File Level Restore" pop-up window, select the VM that you wish to perform a restore to and then click the **Next** button.

![file\_level\_restore.png](/images/hosted-private-cloud/powered-by-vmware/how-to-restore-a-vm-with-veeam-backup-replication-enterprise/file-level-restore-png.png)

In the next section, "Restore Point", select the backup that you wish to use to pull data from and then click the **Next** button.

In the final section, "Summary", review the information and then click the **Finish** button.

The "File Level Restore" window will close, but shortly thereafter the "BACKUP BROWSER" pop-up window will appear.

Navigate through the browser and choose the file or files that you wish to restore. Once you have selected a file(s), right-click on one of them, mouseover **Restore** and then select the **Keep** option.

![backup\_browser.png](/images/hosted-private-cloud/powered-by-vmware/how-to-restore-a-vm-with-veeam-backup-replication-enterprise/backup-browser-png.png)

The "Restore files to ..." pop-up window displays the progress of the restore. Once the process is complete, the file has been restored, and you can close the "BACKUP BROWSER" window.

### **Conclusion**

If you're unable to restore data from a backup, it serves no purpose. Having read this article, you should have a clear understanding of how to restore an entire VM or an individual file using Veeam Backup & Replication.
