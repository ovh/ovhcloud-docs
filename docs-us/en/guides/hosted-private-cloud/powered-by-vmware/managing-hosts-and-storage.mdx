# Managing hosts and storage

**Learn how to add and remove hosts and datastores via the OVHcloud Control Panel and vSphere for a Hosted Private Cloud environment.**

:::info

Resources will be billed monthly if added through the OVHcloud Control Panel. Resources added through vSphere will need to be modified in OVHcloud Control Panel to monthly billing.

:::

 

## Instructions

### Adding a host

<Tabs>

<Tab label="Via OVHcloud Control Panel">

To add a host in the [OVHcloud Control Panel](https://manager.us.ovhcloud.com/):

1. Select `Hosted Private Cloud` from the top navigation bar.
2. In the left-hand menu, select `VMware`, your PCC, and then the datacenter to which you want to add a host.
3. On the next screen, choose the `Hosts` tab.
4. Click the `Order a host` button.
5. Select your host and quantity, and click `Confirm order`.

![HPC\_VMware\_ManageResources\_managingResources01.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998858603795.png)

</Tab>

<Tab label="Via vSphere">

:::warning

**NOTE:** When a host is added to your HPC environment via vSphere, it will be billed hourly. You must switch the billing from hourly to monthly by going to your datacenter in the OVHcloud Control Panel and selecting the `Hosts` tab. Click the *more options* `...` button next to the host and select `Switch to monthly subscription`.

![HPC\_VMware\_ManageResources\_managingResources02\*\*.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998844324243.png)

:::

To start, log in to your vSphere Web Client. From the left-hand menu:

1. Click the arrow next to your PCC name and then select the datacenter on which you wish to add a host.
2. Click the `Configure` tab.
3. Click `Add host` under the **OVHcloud** heading.
4. Choose the host you wish to add and then click `Next`. On the following page, confirm the details are correct and press `Next` again.

![HPC\_VMware\_ManageResources\_managingResources03\*\*.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998858614803.png)

If you already have a host with the specifications that you desire, you can quickly order more of that host. To do so, on the Navigator panel, `right-click the host` with the configurations you wish to add, select `OVHcloud`, and click `More of this Host...`.

This will bring up an order funnel. Confirm the host, and it will be delivered.

![HPC\_VMware\_ManageResources\_managingResources04\*.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998858621587.png)

</Tab>

</Tabs>

 

### Adding a datastore

<Tabs>

<Tab label="Via OVHcloud Control Panel">

To add a datastore in the [OVHcloud Control Panel](https://manager.us.ovhcloud.com/):

1. Select `Hosted Private Cloud` from the top navigation bar.
2. In the left-hand menu, select `VMware`, your PCC, and then the datacenter to which you want to add a host.
3. On the next screen, choose the `Datastores` tab.
4. Click the `Order a datastore` button.
5. Select your type and quantity, and click `Confirm order`.

![HPC\_VMware\_ManageResources\_managingResources05.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998844340883.png)

</Tab>

<Tab label="Via vSphere">

:::warning

**NOTE:** When a datastore is added to your HPC environment via vSphere, it will be billed hourly. You must switch the billing from hourly to monthly by going to your datacenter in the OVHcloud Control Panel and selecting the `Datastores` tab. Click the *more options* `...` button next to the host and select `Switch to monthly subscription`.

![HPC\_VMware\_ManageResources\_managingResources06\*.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998844350483.png)

:::

To start, log in to your vSphere Web Client. From the left-hand menu:

1. Click the arrow next to your PCC name and then select the datacenter on which you wish to add a datastore.
2. Click the `Configure` tab.
3. Click `Add storage` under the **OVHcloud** heading.
4. Choose the datastore you wish to add and then click `Next`. On the following page, confirm the details are correct and press `Next` again.

![HPC\_VMware\_ManageResources\_managingResources07\*\*\*.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998858639635.png)

If you already have a datastore with the storage specifications that you desire, you can quickly order more of that datastore. To do so, select the storage icon on the left-hand sidebar, `right-click the datastore` you wish to add more of, select `OVHcloud`, and click `More of this storage...`.

This will bring up an order funnel. Confirm the datastore, and it will be delivered.

![HPC\_VMware\_ManageResources\_managingResources08\*\*.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998844356755.png)

</Tab>

</Tabs>

 

### Removing a host

On the **Host and Clusters** screen, `right-click the host` you would like to remove. Choose `Maintenance Mode` and select `Enter Maintenance Mode`.

![HPC\_VMware\_ManageResources\_managingResources09\*.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998858648083.png)

Once in maintenance mode, `right-click the host` again, choose `OVHcloud`, and select `Remove this host...`.

![HPC\_VMware\_ManageResources\_managingResources10\*.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998858657939.png)

Once the task is completed, you will see a confirmation page. Confirm that this is indeed the host you wish to remove and click `NEXT` to remove it.

![HPC\_VMware\_ManageResources\_managingResources11\*.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998844368019.png)

 

### Removing a datastore

:::warning

**NOTE:** For security reasons, the removal request will be blocked if you have virtual machines (VMs) on the datastore concerned (they will be listed in the confirmation window).

Also check that none of the following remain:

- ISO or snapshot attached to a VM;
- template present on the datastore;
- residual file or directory;
- vCLS file.

:::

**WARNING:** Do not select `Unmount Datastore...` when attempting to remove storage. The datastore will no longer be accessible in your HPC environment, but will still appear in your OVHcloud Control Panel and will still be billed.

To remove a datastore, navigate to the `Datastores` tab. Next, `right-click the datastore` you would like to remove and click `Delete Datastore`.

On the pop-up window, confirm that the datastore has no VMs attached to it and select the `NEXT` button. Your datastore will be removed in a few moments.

![HPC\_VMware\_ManageResources\_managingResources12\*.png](/images/hosted-private-cloud/powered-by-vmware/managing-hosts-and-storage/33998844369939.png)
