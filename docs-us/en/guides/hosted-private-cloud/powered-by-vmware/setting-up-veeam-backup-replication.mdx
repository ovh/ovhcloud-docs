# Setting up Veeam Backup & Replication

Veeam Backup & Replication is a data protection software. It offers its users a wide range of options for backing up, replicating, and restoring their data.

:::warning

**NOTE:** If a virtual machine is protected using multiple backup methods (for example, [VM backup](https://helpcenter.veeam.com/docs/vbr/qsg/vm_backup.html?ver=13) and [Agent backup](https://helpcenter.veeam.com/docs/vbr/userguide/protect_comp.html?ver=13)), each method consumes a separate license and is billed independently.

To avoid additional charges, protect each virtual machine using **only one backup method**.

:::

 

## Requirements

- A [Veeam Enterprise solution](https://us.ovhcloud.com/storage-solutions/veeam-enterprise/)

- Windows Server 2012 or a newer version

- Veeam Backup & Replication v12.3 or earlier

- *For&#x20;*[*Hosted Private Cloud*](https://us.ovhcloud.com/hosted-private-cloud/)*&#x20;customers willing to use their private infrastructure:* outbound/established TCP traffic must be allowed towards the service IP and the port range 950-999

  :::info

  **Example:** For the service pcc-1.2.3.4.ovh.us with IP 1.2.3.4, the customer's network appliance should have an outbound rule allowing TCP traffic against port range 950-999 and IP 1.2.3.4 to allow NFC communication to the ESXi hosts.

  :::

 

## Instructions

### Setting up Veeam Backup & Replication

Download and install the **Veeam Backup & Replication 12.0** solution from the [Veeam website](https://www.veeam.com/download_add_packs/vmware-esx-backup/12.0). If you do not have an account, you will need to set one up (account setup is free). Once you have logged in, your download should start automatically.

The files will appear in ISO disk image format. Double-click the ISO image and run the installation setup.

On the server, you can then launch the installation wizard. Select `Install Veeam Backup & Replication`.

![](/images/hosted-private-cloud/powered-by-vmware/setting-up-veeam-backup-replication/22408652987411.png)

After you have read the license agreement, click `I Accept`.

![](/images/hosted-private-cloud/powered-by-vmware/setting-up-veeam-backup-replication/22408653002771.png)

Click `Next` to skip the step of opening a license file.

![](/images/hosted-private-cloud/powered-by-vmware/setting-up-veeam-backup-replication/22408653007507.png)

Review the installation settings and click `Install`.

![](/images/hosted-private-cloud/powered-by-vmware/setting-up-veeam-backup-replication/22408663868307.png)

Next, wait for the installation to complete.

![](/images/hosted-private-cloud/powered-by-vmware/setting-up-veeam-backup-replication/22408663876371.png)

Once it is complete, exit the installation wizard by clicking `Finish`.

![](/images/hosted-private-cloud/powered-by-vmware/setting-up-veeam-backup-replication/22408653029907.png)

 

### Creating a Veeam Enterprise service account

<details>
<summary>Step 1: Launch a service account</summary>

Generate a **complex password** for your service account.

To ensure that the Veeam licence activation works correctly, the username and password must use only supported characters:

- Lowercase and uppercase letters **without accents** (a-z, A-Z)
- Numbers (0-9)
- Special characters: `! @ = # % & ' " { } * ( ) [ ] ? . , ; : - _ \ / +`

:::warning

**NOTE:** If the username or password contains unsupported characters, the license activation may fail.

:::

Next, launch Windows PowerShell as an administrator and create the service account, for example:

```
New-LocalUser "OVHVeeamEnterprise" -Password (ConvertTo-SecureString -AsPlainText "P@ssword01" -Force)-Description "OVHcloud Service Account for Veeam Enterprise" -PasswordNeverExpires:$true -UserMayNotChangePassword:$true -AccountNeverExpires:$true
```

Please note that the account name and password shown here are examples, and must be replaced with your own details:

- Account name: OVHVeeamEnterprise
- Password: P\@ssword01

</details>

**Launch and Activation Permissions**

The OVHVeeamEnterprise user is only accessible locally, so it is necessary to add permissions in the Windows graphical user interface to enable the remote connection.

In your Windows search bar, **type "Component Services"** and launch the service.

1. On the left menu and following the tree structure, click on `Component Services`, `Computers`, and then `My Computer`.
2. Under the **Actions** tab, click on `More Actions`.
3. Select `Properties`.
4. Go to `COM Security`.
5. In the **Launch and Activation Permissions** section, click `Edit Limits`.

![veeamenterprise17.png](/images/hosted-private-cloud/powered-by-vmware/setting-up-veeam-backup-replication/27412755291411.png)

6. Click on `Add...`.
7. Click on `Advanced`.
8. Click on `Find Now`, select the `OVHVeeamEnterprise` user from the list below, and then click `OK` to confirm the selection.

![veeamenterprise18.png](/images/hosted-private-cloud/powered-by-vmware/setting-up-veeam-backup-replication/27412755314067.png)

9. Select the `OVHVeeamEnterprise` user from the list, **Allow** `☑` all permissions, and click `OK`.
10. Click `Apply` to validate the changes.

![veeamenterprise19.png](/images/hosted-private-cloud/powered-by-vmware/setting-up-veeam-backup-replication/27412755324307.png)

:::tip

**SUCCESS!** Your OVHVeeamEnterprise user is now accessible locally and remotely.

:::

<Tab label="Using the OVHcloud API">

You can also accomplish this via the [OVHcloud API](https://api.us.ovhcloud.com/).

First, retrieve your serviceName:

<Api version="v1" section="/veeam/veeamEnterprise" method="GET" route={"/veeam/veeamEnterprise"} regions={["us"]} />

Then register it:

<Api version="v1" section="/veeam/veeamEnterprise" method="POST" route={"/veeam/veeamEnterprise/\{serviceName\}/register"} regions={["us"]} />

You will need the following information:

- the public IP address that can be used to contact your **Veeam Backup & Replication** server
- your server’s **Veeam Backup & Replication** port (usually **9392/TCP**)
- the login for the account you have just created
- the password for your service account

You can retrieve the public IP used by Veeam Enterprise to contact your **Veeam Backup & Replication** server via:

<Api version="v1" section="/veeam/veeamEnterprise" method="GET" route={"/veeam/veeamEnterprise/\{serviceName\}"} regions={["us"]} />

:::info

When your license activation has finished, the result of this API call will show `activationStatus: "done"`.

:::
