# Configuring DNS Forwarder in NSX

You can use a DNS forwarder in NSX that centralises all DNS queries and redirects them to external DNS servers, which reduces network traffic. You can attach the DNS forwarder to the north-south gateway (ovh-T0-gw) or the east-west gateway (ovh-T1-gw), depending on your needs.

**Discover how to configure a DNS forwarder.**

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://us.ovhcloud.com/hosted-private-cloud/vmware/) to receive login credentials.
- A user account with access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub).
- You need to have **NSX** deployed with a segment configured in your NSX configuration. Use our guide on [Segment Management in NSX](https://support.us.ovhcloud.com/hc/en-us/articles/15878504155667) for more information.

## Instructions

We will create a DNS redirector and attach it to the north-south gateway (ovh-t0-gw), it will be usable on all segments of NSX.

### DNS forwarder configuration

Through the NSX interface go to the `Networking` tab and click on `DNS` on the left in the **IP Management** section. Then click `ADD DNS SERVICE`.

![configdns01.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910393033747.jpg)

Enter this information :

- **Name** : Your service name, such as `dns-forwarder`.
- **Tier-0/Tier-1 Gateway** : Your North-South gateway `ovh-T0-gw`.
- **DNS Service IP** : a private IP address not used in your segments, such as `192.168.200.1`.

Next, click the `three vertical dots` below **Default DNS Zone**.

![configdns02.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910381821075.jpg)

 

Click `Add New Default Zone`.

![configdns03.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910381927187.jpg)

Fill in these values :

- **Name** : The name of the zone, such as `cdns.ovh.net`.
- **DNS Servers** : OVHcloud DNS server `213.186.33.99`.

Then click `SAVE`.

![configdns04.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910393147667.jpg)

 

Click `SAVE`.

![configdns05.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910382016275.jpg)

Your DNS forwarder is active and usable on all your overlay or VLAN segments connected to your north-south gateway (ovh-t0-gw).

![configdns06.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910382017811.jpg)

### Editing the DHCP server to use a DNS forwarder

If you have configured DHCP servers in NSX as described in our [DHCP Configuration](https://support.us.ovhcloud.com/hc/en-us/articles/15898393204627) guide, you have the option to modify the configuration to use the DNS forwarder in your DHCP configurations.

We will see how to modify the DNS server on the DHCP configuration of one of your segments.

Still from the `Networking` tab, click `Segments` on the left in the **Connectivity** section.

Then click on the `three vertical dots` next to your segment and choose `Edit` from the menu.

![configdns07.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910393366547.jpg)

 

Click `EDIT DHCP CONFIG`.

![configdns08.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910393373715.jpg)

 

Click the `X` to the right of the existing DNS in the **DNS Servers** option to remove it from the configuration.

![configdns09.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910393442067.jpg)

 

Add your DNS redirector IP address in **DNS Servers** as `192.168.200.1` and click `APPLY`.

![configdns10.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910393456403.jpg)

 

Click `SAVE`.

![configdns11.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910382303123.jpg)

 

Click `CLOSE EDITING`.

![configdns12.jpeg](/images/hosted-private-cloud/powered-by-vmware/configuring-dns-forwarder-in-nsx/15910382303251.jpg)

Your segment's DHCP settings now use the DNS forwarder you created earlier.

## Conclusion

Having read this guide, you should be able to configure a DNS forwarder.
