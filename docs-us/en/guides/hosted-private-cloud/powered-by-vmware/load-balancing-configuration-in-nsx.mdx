# Load Balancing Configuration in NSX

## Objective

NSX allows load balancing on a level 4 (TCP or UDP) layer or level 7 (HTTP or HTTPS) layer.

**Learn how to set up load balancing in NSX.**

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://us.ovhcloud.com/hosted-private-cloud/vmware/) to receive login credentials.
- A user account with access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub).
- Having **NSX** deployed with two segments configured in your NSX configuration, you can use the [Segment Management in NSX](https://support.us.ovhcloud.com/hc/en-us/articles/15878504155667) guide for reference.
- Two virtual machines with NGINX enabled on one segment.

## Instructions

We will :

- Enable Load Balancing on the gateway **ovh-T1-gw**.
- Create a server pool from two virtual machines that use a web server running on port 80.
- Add a virtual server in the Load Balancer configuration which contains our server pool.
- Set a NAT rule to redirect to the virtual server.

### Creating the tag on both virtual machines.

To simplify the administration of the Load Balancer, we will use a tag on the two virtual machines in the future server pool.

In the NSX interface go to the `Inventory` tab and click on `Virtual Machines` on the left.

- Then click on the `three vertical dots` to the left of the first virtual machine.
- Choose `Edit` from the menu.

![loadbalance01.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944648123667.png)

 

Replace **Tag** with `loadbl`, then click `Add Item(s) loadbl` below.

![loadbalance02.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944649502099.png)

 

Change **Scope** to `nginx`, then click `Add Item(s) nginx` below.

![loadbalance03.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944644899731.png)

 

Click the `+` sign next to your tag to add it to your virtual machine.

![loadbalance04.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944653099283.png)

 

When the tag appears, click `SAVE`.

![loadbalance05.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944701595283.png)

 

Click the `three vertical dots` to the left of the second virtual machine and choose `Edit` from the menu.

![loadbalance06.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944741065875.png)

 

Replace **Tag** with `load` and select the `Tag: loadbl Scope: nginx` from the list below.

![loadbalance07.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944742359699.png)

 

Click the `+` sign next to your tag to add it to your second virtual machine.

![loadbalance08.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944750624531.png)

 

Click `SAVE` to add the tag to your virtual machine.

![loadbalance09.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944790022547.png)

 

Stay on **Inventory**, click `Tags` and click on the `number` to the right of the marker you created.

![loadbalance10.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944791650323.png)

 

You can see your two virtual machines using the same tag. Click `CLOSE` when done.

![loadbalance11.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944840214803.png)

### Add group with created tag

Select `Groups` on the left and click `ADD GROUP`.

![loadbalance12.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944797600147.png)

 

Enter `nginx-server` below **Name** and click `SET` under **Compute Members**.

![loadbalance13.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944844563987.png)

 

Click `+ ADD CRITERION`.

![loadbalance14.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944847265043.png)

 

Keep **Virtual Machine Tag Equals** and select your `loadbl` tag with its `nginx` scope and click `APPLY`.

![loadbalance15.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944855687315.png)

 

Click `SAVE`.

![loadbalance16.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944902012307.png)

 

Click `View Members` to the right of the group.

![loadbalance17.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944904599699.png)

 

The list of virtual machines is automatically added to the group based on the criteria in your tag.

![loadbalance18.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944940908435.png)

### Activating the Load Balancer

Go to the `Networking` tab.

- In the **Network Services** section on the left, click on `Load Balancing`.
- Go to the `Load Balancers` tab.
- Click `ADD LOAD BALANCER`.

![loadbalance19.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15944955063827.png)

 

Enter `loadbalancer-on-t1` below **Name**, select `ovh-T1-gw` under **Attachment** and click `SAVE`.

![loadbalance20.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945049832595.png)

 

Click `NO`.

![loadbalance21.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945053658515.png)

 

The Load Balancer is created and activated on the **ovh-T1-gw** gateway.

![loadbalance22.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945049198995.png)

### Server pool creation

Go to the `Server Pools` tab and click `ADD SERVER POOL`.

![loadbalance23.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945103479571.png)

 

Enter `sp-nginx` below **Name** and click `Select Members` under **Members/Group**.

![loadbalance24.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945145351699.png)

 

Click `Select a group` and choose the `nginx-servers` group you created then click `APPLY`.

![loadbalance25.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945148004883.png)

 

Click `SAVE` to apply your changes.

![loadbalance26.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945157159699.png)

 

Your server pool is created with your two virtual machines that are members of the group.

![loadbalance27.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945206737299.png)

### Virtual server creation

Your server pool is created with your two virtual machines which are members of the group. Go to the `Virtual Servers` tab and click on `ADD VIRTUAL SERVER`.

![loadbalance28.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945246001939.png)

 

Select `L4 TCP`.

![loadbalance29.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945248887443.png)

Fill in this information :

- **Name** : Name of your virtual server `vs-nginx`.
- **IP Address**: Front-end IP address of your virtual server on the same network as your NGINX virtual machines `192.168.102.3`.
- **Port** : Port `80`.
- **Load Balancer**: Your load balancer `loadbalancer-on-t1`.
- **Server Pool**: Your server pool `sp-nginx`.

Then click `SAVE`.

![loadbalance30.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945278581395.png)

Your virtual server is active. If you connect from a machine that uses a segment on a gateway of type **Tier-1 Gateways** with this URL `http://192.168.102.3`, the Load Balancer will connect to one of the two virtual machines configured in your group.

### Adding a NAT rule

Go to `NAT` in the **Network Services** section on the left and click `ADD NAT RULE`.

![loadbalance31.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945281812115.png)

Enter `to-lb-virtual-server` in your rule **Name** with these options :

- **Action** : `DNAT`.
- **Destination IP** : A virtual IP address of your T0 such as `198.51.100.1`.
- **Translated IP** : IP address of your virtual server `192.168.102.103`.
- **Service PORT** : Choose the predefined port `HTTP| 80`.

Then click `SAVE`.

![loadbalance32.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945293640211.png)

 

Your rule is active. If you click on `http://virtual-ip-address-on-T0` you will be connected to your virtual server which will redirect the flow to one of the servers in your group.

![loadbalance33.png](/images/hosted-private-cloud/powered-by-vmware/load-balancing-configuration-in-nsx/15945328358931.png)

## Conclusion

Having read this guide, you should be able to enable Load Balancing, create a server pool from two virtual machines, add a virtual server in the Load Balancer configuration, and set a NAT rule to redirect to the virtual server.
