# Configuring a vROps alert by the SMTP protocol

**Learn how to configure your SMTP server to automate sending alerts and reports by email to vROps.**

 

## Requirements

- A working SMTP server
- STMP flows allowed between your SMTP server and your vROps instance

 

## Instructions

### Open the flow

The first step is to open a *flow* on the OVHcloud API to enable vROps to communicate with your SMTP server.

You can check that the flow has been opened using the [OVHcloud API](https://api.us.ovhcloud.com/).

To do this, use the following API call:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/vrops/outgoingFlow"} regions={["us"]} />

Fill in the API call fields. If the results are not as expected, check your server port openings.

| PARAMETER   | DESCRIPTION                                                   |
| ----------- | ------------------------------------------------------------- |
| serviceName | Domain of the service                                         |
| description | Outgoing flow description (for example, here connect to SMTP) |
| ip          | IP address of the remote service, e.g., 123.100.200.0         |
| servicePort | Remote service port (587)                                     |

![HPC\_VMware\_Maintenance\_configAlert01\*.png](/images/hosted-private-cloud/powered-by-vmware/configuring-a-vrops-alert-by-the-smtp-protocol/36946260797075.png)

 

### Configuring vROps alerting

Once the flow has been opened, you need to configure the email alert on your vROps. To do this, go to the `Configure` section, then the `Alerts` section. Several types of alerts are available. Select `Outbound Settings`.

![HPC\_VMware\_Maintenance\_configAlert02\*.png](/images/hosted-private-cloud/powered-by-vmware/configuring-a-vrops-alert-by-the-smtp-protocol/36946239094803.png)

The page shows a summary of all your Outbound Settings. Click on the `ADD` button.

![HPC\_VMware\_Maintenance\_configAlert03\*.png](/images/hosted-private-cloud/powered-by-vmware/configuring-a-vrops-alert-by-the-smtp-protocol/36946239096979.png)

In th&#x65;**&#x20;Plugin Type&#x20;**&#x6F;ption, select `Standard Email Plugin`. A series of options will appear; fill in the fields.

| OPTION                  | DESCRIPTION                                                                                                                                                                             |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Use Secure Connection   | Activates secure communication encryption using SSL/TLS. If you select this option, you must select a method in the `Secure Connection Type` drop-down menu.                            |
| Requires Authentication | Activates authentication on the email user account that you use to configure this SMTP instance. If you select this option, you must provide a password for the user account.           |
| SMTP Host               | URL or IP address of your email host server.                                                                                                                                            |
| SMTP Port               | Default port SMTP uses to connect with the server.                                                                                                                                      |
| Secure Connection Type  | Select either SSL/TLS as the communication encryption method used in your environment from the drop-down menu. You must select a connection type if you select `Use Secure Connection`. |
| User Name               | Email user account that is used to connect to the email server.                                                                                                                         |
| Password                | Password for the connection user account. A password is required if you select `Requires Authentication`.                                                                               |
| Sender Email Address    | Email address that appears on the notification message.                                                                                                                                 |
| Sender Name             | Displayed name for the sender email address.                                                                                                                                            |
| Receiver Email Address  | Receiver's email address.                                                                                                                                                               |

![HPC\_VMware\_Maintenance\_configAlert04.png](/images/hosted-private-cloud/powered-by-vmware/configuring-a-vrops-alert-by-the-smtp-protocol/36946260804115.png)

:::warning

**NOTE:** For the sake of this documentation, no authentication has been configured on the SMTP server. However, for obvious security reasons, we strongly advise you to do so!

:::

You can test your configuration using the `Test` button at the bottom of the page.

Once these operations are complete, you will find the details of your alert configuration in the previous summary.

Finally, check that your alert is working properly by verifying that the emails are received correctly.

![HPC\_VMware\_Maintenance\_configAlert05\*.png](/images/hosted-private-cloud/powered-by-vmware/configuring-a-vrops-alert-by-the-smtp-protocol/36946260806291.png)

 

### Modification of an existing alert

You can modify an existing alert by selecting `☑️` the alert, clicking the *more options* `...` button, and selecting `Edit`.

![HPC\_VMware\_Maintenance\_configAlert06.png](/images/hosted-private-cloud/powered-by-vmware/configuring-a-vrops-alert-by-the-smtp-protocol/36946239105299.png)
