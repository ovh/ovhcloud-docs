# How to Enable NSX Management Access for a Hosted Private Cloud User via APIs

When a new user is added to the Hosted Private Cloud environment with administrator rights (read/write access to all datacenters), NSX management access is not enabled by default, as shown below.

![NSXaccessAPI01.PNG](/images/hosted-private-cloud/powered-by-vmware/how-to-enable-nsx-management-access-for-a-hosted-private-cloud-user-via-apis/18266986012435.png)

**This guide will show you how to use the API call to enable NSX management access.**

To check the status of NSX management access for your user(s), log in to [OVHcloud Control Panel](https://us.ovhcloud.com/manager/).

1. Select `Hosted Private Cloud`.
2. Click `VMware` and select your environment.
3. Click `Users`.
4. Check the status for each user in the **NSX Interface** column.

![NSXaccessAPI02.png](/images/hosted-private-cloud/powered-by-vmware/how-to-enable-nsx-management-access-for-a-hosted-private-cloud-user-via-apis/18267676656147.png)

 

## Instructions

To execute the API call, log in to [OVHcloud API](https://api.us.ovhcloud.com/) using your OVHcloud Control Panel credentials. Open [/dedicatedCloud](https://api.us.ovhcloud.com/console/#/dedicatedCloud) and select<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud"} regions={["us"]} />. Click the `Execute` button.

![NSXaccessAPI03.png](/images/hosted-private-cloud/powered-by-vmware/how-to-enable-nsx-management-access-for-a-hosted-private-cloud-user-via-apis/18267824966419.png)

 

Copy the relevant environment from the response. An example is shown below.

![NSXaccessAPI04.PNG](/images/hosted-private-cloud/powered-by-vmware/how-to-enable-nsx-management-access-for-a-hosted-private-cloud-user-via-apis/18268443935379.png)

 

Scroll down and click on<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\{serviceName\}/user"} regions={["us"]} />.

- Enter the environment name from the previous step into the **serviceName** field.
- Enter the **name** of the user (i.e., "admin") whose ID number you need.
- Click on `Execute` button.
- Copy the 5-digit user ID from the result.

![NSXaccessAPI05.png](/images/hosted-private-cloud/powered-by-vmware/how-to-enable-nsx-management-access-for-a-hosted-private-cloud-user-via-apis/18692410639763.png)

 

Select<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/user/\{userId\}/changeProperties"} regions={["us"]} />and you can see that the **serviceName** is already mentioned.

1. Enter the 5-digit user ID in the **userId** field.
2. Select the rights `checkboxes` for **canManageIpFailOvers**, **canManageNetwork**, and **nsxRight**.
3. Click on the `Execute` button.

![NSXaccessAPI06.PNG](/images/hosted-private-cloud/powered-by-vmware/how-to-enable-nsx-management-access-for-a-hosted-private-cloud-user-via-apis/18269196426899.png)

 

Wait for some time and you can see that the NSX management access has been granted to the user within the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), as shown below.

![NSXaccessAPI07.PNG](/images/hosted-private-cloud/powered-by-vmware/how-to-enable-nsx-management-access-for-a-hosted-private-cloud-user-via-apis/18269196428307.png)

 

The user can now log in to the NSX-T environment using the following credentials.

- **Username:** \<username>@pcc-XXX-XXX-XX-XX.ovh.us
- **Password:** \<same password used while creating the user>
- **URL:** https\://nsxt.pcc-XXX-XXX-XX-XX.ovh.us

![NSXaccessAPI08.PNG](/images/hosted-private-cloud/powered-by-vmware/how-to-enable-nsx-management-access-for-a-hosted-private-cloud-user-via-apis/18269225346579.png)
