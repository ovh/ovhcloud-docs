# VMware Storage vMotion

The Storage vMotion allows you to change the storage location of a virtual machine's files while keeping the VM powered on. VMs can be moved completely or disk by disk.

 

## Requirements

- Being an administrative contact of your [VMware on OVHcloud](https://us.ovhcloud.com/hosted-private-cloud/vmware/) infrastructure (to receive login credentials)
- A [user account with access to vSphere](https://support.us.ovhcloud.com/hc/en-us/articles/18004084382355#exploring-the-pcc-dashboard) (created in the OVHcloud Control Panel)

 

## Instructions

### Moving a VM disk

To move a virtual machine’s files to another datastore, right-click on the virtual machine and select `Migrate...`.

![VM\_options.PNG](/images/hosted-private-cloud/powered-by-vmware/vmware-storage-vmotion/52447071562899.png)

 

### Choosing a migration type

The menu offers several options for vMotion.

:::info

The option **Change compute resource only** allows for migrating the VM to another host.

:::

In this example, we will migrate the VM storage to another datastore by selecting \[action]Change storage only\[/action].

![VM\_migrate01.PNG](/images/hosted-private-cloud/powered-by-vmware/vmware-storage-vmotion/52447100514323.png)

 

### Choosing a datastore

Choose which storage to migrate the data to. You can also change the storage policy during this operation.

For example, you can apply the storage policies created if you have [vSAN storage](https://support.us.ovhcloud.com/hc/en-us/articles/18051829337491) or the [VM encryption](https://support.us.ovhcloud.com/hc/en-us/articles/18041666127123) option.

:::info

If you have several virtual disks on the same machine, you can also move only one disk of the VM by using the `Configure per disk` button.

:::

![VM\_migrateStorage02.PNG](/images/hosted-private-cloud/powered-by-vmware/vmware-storage-vmotion/52447071565715.png)

 

### Finalizing the operation

Click on `FINISH` to launch the migration task.

![VM\_migrateStorage03.PNG](/images/hosted-private-cloud/powered-by-vmware/vmware-storage-vmotion/52447071566483.png)

You can track the status of the migration in the `Recent Tasks` panel at the bottom of the screen.
