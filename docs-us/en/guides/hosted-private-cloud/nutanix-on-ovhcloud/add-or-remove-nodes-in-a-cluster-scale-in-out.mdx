# Add or remove nodes in a cluster (Scale In/Out)

**Learn how to add or remove a node in a Nutanix cluster.**

Nutanix clusters are scalable; you can add (Scale Out) or remove (Scale In) nodes directly from the OVHcloud Control Panel or the OVHcloud API.

:::warning

**NOTE:** OVHcloud provides services for which you are responsible for their configuration and management. You are therefore responsible for their proper functioning.\
\
This tutorial is designed to help you as much as possible with common tasks. If you are having difficulty performing these actions, please contact a specialized service provider. OVHcloud cannot provide you with technical support in this regard.

:::

 

## Requirements

- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) or [OVHcloud API](https://api.us.ovhcloud.com/)
- A Nutanix cluster in your OVHcloud account
- Access to the cluster's Prism Central administration interface

 

## Technical information

- Your cluster must have between **3 and 32 nodes**
- All new nodes must run the **same AOS version** as the existing cluster

 

## Instructions

### Scale Out (add a node)

#### Add a node

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), navigate to your Nutanix cluster via the `Hosted Private Cloud` and `Nutanix` menus.

![manager\_navigation\_selectNTNXcluster.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959465603091.png)

In the **General information** tab, you can see the **Number of nodes**. Click `Manage my nodes →`.

![manager\_NTNXcluster\_generalinformation\_3installed.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959465605395.png)

In the **Nodes** tab, select `Add nodes`.

![manager\_NTNXcluster\_addNode.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959465606419.png)

In the pop-up window, review the configuration information and pricing. Click `Order` to add the node(s).

![nutanix\_orderNodes.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/43810047059347.png)

Once the node is delivered, you can see the status in the **General information** tab.

The **Number of nodes** area will show a new node to install.

![manager\_NTNXcluster\_generalinformation\_1uninstalled.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959465610515.png)

 

#### Install an OS

<Tabs>

<Tab label="OVHcloud Control Panel">

If you click `Manage my nodes →` again, you will see a list of your nodes. For any node with a `OS not installed` status, click the *more options* `...` button and select `Install`.

![manager\_NTNXcluster\_installNode.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959456260883.png)

Enter the configuration details for your node. Be sure to install the same AOS version as your cluster.

Click `Install`.

![manager\_NTNXcluster\_nodeConfiguration\*.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959456262675.png)

A confirmation message will appear.

![manager\_NTNXcluster\_nodeConfigurationConfirmation.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959456264339.png)

</Tab>

<Tab label="OVHcloud API">

To install your node via the [OVHcloud API](https://api.us.ovhcloud.com/), use this call:

<Api version="v1" section="/nutanix" method="PUT" route={"/nutanix/\{serviceName\}/nodes/\{server\}/deploy"} regions={["us"]} />

</Tab>

</Tabs>

Once the node has been installed, you can connect to Prism Central/Element and expand your cluster. Please refer to the documentation below:

- [Expanding a Cluster through Prism Central](https://portal.nutanix.com/page/documents/details?targetId=Prism-Central-Guide-vpc_2024_3_1:mul-node-add-pc-t.html)
- [Expanding a Cluster](https://portal.nutanix.com/page/documents/details?targetId=Web-Console-Guide-Prism-v7_0:wc-cluster-expand-wc-t.html)

 

### Scale In (remove a node)

#### Power down a node

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), navigate to your Nutanix cluster via the `Hosted Private Cloud` and `Nutanix` menus.

![manager\_navigation\_selectNTNXcluster.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959465603091.png)

In the **General information** tab, you can see the **Number of nodes**. Click `Manage my nodes →`.

![manager\_NTNXcluster\_generalinformation\_4installed.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959465621651.png)

<Tabs>

<Tab label="OVHcloud Control Panel">

For the node you wish to remove, click the *more options* `...` button and select `Power down`.

![manager\_NTNXcluster\_powerDown.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959456271251.png)

A warning pop-up will appear. Type the required term and click `Power down`.

:::warning

**NOTE:** Powering down a Nutanix node may impact your cluster. Please check the [requirements on the Nutanix portal](https://portal.nutanix.com/page/documents/list?type=software) to complete this action.

:::

![manager\_NTNXcluster\_powerDownConfirm.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959456274195.png)

A confirmation banner will appear to confirm that your request is processing.

![manager\_NTNXcluster\_powerDownConfirmation.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959465627283.png)

</Tab>

<Tab label="OVHcloud API">

You can also power down your node via the [OVHcloud API](https://api.us.ovhcloud.com/).

Get the Boot ID:

Enter *power* as the **bootType**.

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/boot"} regions={["us"]} />

Set the Boot ID:

<Api version="v1" section="/dedicated/server" method="PUT" route={"/dedicated/server/\{serviceName\}"} regions={["us"]} />

Power down the node:

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/reboot"} regions={["us"]} />

</Tab>

</Tabs>

 

#### Uninstall the node

<Tabs>

<Tab label="OVHcloud Control Panel">

Once the node is powered down, click the *more options* `...` button and select `Uninstall`.

![manager\_NTNXcluster\_uninstall.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959465629203.png)

A warning pop-up will appear. Type the required term and click `Uninstall`.

:::warning

**NOTE:** Uninstalling a Nutanix node may impact your cluster. Please check the [requirements on the Nutanix portal](https://portal.nutanix.com/page/documents/list?type=software) to complete this action.

:::

![manager\_NTNXcluster\_uninstallConfirm.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959456280211.png)

A confirmation banner will appear to confirm that your request is processing.

![manager\_NTNXcluster\_uninstallConfirmation.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959456281107.png)

</Tab>

<Tab label="OVHcloud API">

To uninstall your node via the [OVHcloud API](https://api.us.ovhcloud.com/), use the following call:

<Api version="v1" section="/nutanix" method="POST" route={"/nutanix/\{serviceName\}/node/\{server\}/terminate"} regions={["us"]} />

</Tab>

</Tabs>

 

#### Remove the node

Once the node is uninstalled, click the *more options* `...` button and select `Terminate`.

![manager\_NTNXcluster\_terminate.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959465639059.png)

A warning pop-up will appear. Type the required term and click `Confirm`.

![manager\_NTNXcluster\_terminateConfirm.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/add-or-remove-nodes-in-a-cluster-scale-in-out/40959465641235.png)

:::warning

**NOTE:** Your suspended service will appear in your nodes list for approximately one week before being permanently deleted. This allows you to reactivate the service if you need to reverse the deletion.

:::
