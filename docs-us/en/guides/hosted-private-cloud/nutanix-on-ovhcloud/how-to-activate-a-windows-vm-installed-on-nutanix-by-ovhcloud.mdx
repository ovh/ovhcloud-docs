# How to Activate a Windows VM Installed on Nutanix by OVHcloud

**This tutorial describes how to activate Windows licenses provided by OVHcloud on a Nutanix by OVHcloud solution.**

:::warning

**NOTE:** This tutorial will show you how to use one or more OVHcloud solutions with external tools, and will describe the actions to be carried out in a specific context. You may need to adapt the instructions according to your situation.

:::

## Requirements

- A Nutanix cluster in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)
- You must be connected to the cluster via Prism Central
- A Windows license provided by OVHcloud
- A virtual machine running Windows Server. You can use this guide to install a virtual machine on Windows: [Virtual Machine Management](https://support.us.ovhcloud.com/hc/en-us/articles/16885296986899)
- The virtual machine connects to the Internet through the rtVrack (e.g. via the default gateway)

## Instructions

### Uninstall the default product key

When your operating system is in trial mode, a default product key is installed. To modify it, open the `Run` dialogue box by pressing the Windows key on your keyboard + `R`.

![activatewindowsVM01.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-activate-a-windows-vm-installed-on-nutanix-by-ovhcloud/17494446434835.png)

![activatewindowsVM02.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-activate-a-windows-vm-installed-on-nutanix-by-ovhcloud/17494441405075.png)

 

In this box, enter the following command:

```
 cscript.exe c:\windows\system32\slmgr.vbs -upk
```

 

### Install the new product key

You can now install the new product key. To do so, go back to the `Run` box, and enter the following command:

```
cscript.exe c:\windows\system32\slmgr.vbs -ipk PRODUCT KEY
```

### Associate your product key

To associate your key with our automated activation system, enter the command below in the `Run` dialogue box:

```
cscript.exe c:\windows\system32\slmgr.vbs -skms kms.ovh.us
```

### Activate the system

Lastly, to activate your Windows operating system, simply enter the command below:

```
cscript.exe c:\windows\system32\slmgr.vbs -ato
```
