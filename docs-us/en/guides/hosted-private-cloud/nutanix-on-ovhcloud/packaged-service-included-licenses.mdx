# Nutanix: OVHcloud Packaged Service - Included Licenses

Nutanix Cloud Platform license packs can be purchased through our Nutanix on OVHcloud packaged service. These license packs consist of different license combinations of two Nutanix products:

- [Nutanix Cloud Infrastructure (NCI)](https://www.nutanix.com/products/cloud-platform/software-options#nci): the software suite that manages the cluster’s infrastructure resources (storage, compute, virtualization, resilience, etc.)
- [Nutanix Cloud Manager (NCM)](https://www.nutanix.com/products/cloud-platform/software-options#ncm): your infrastructure management platform (cost management, automation, monitoring, security, etc.)

:::warning

**NOTE:** There are three possible licenses for each of these products. You can read more about the features of each license using the links above, but it is important to note that, **at this time, the "Starter" licenses for NCI and NCM are not included in any of the license packs**. Please refer to the [GitHub roadmap](https://github.com/orgs/ovh/projects/16/views/1?sliceBy%5Bvalue%5D=Nutanix+on+OVHcloud) for future availability. If you have an immediate need, we recommend considering our [Nutanix on OVHcloud BYOL](https://us.ovhcloud.com/hosted-private-cloud/nutanix/byol/) service.

:::

 

The chart below is meant to help you see what is included in each license pack and which will suit your needs best. As a reminder:

- NCI = Nutanix Cloud Infrastructure
- NCM = Nutanix Cloud Manager

| Nutanix on OVHcloud license pack | NCI version included | NCM version included | Use case                                                                                                                                                                                                                                                 |
| -------------------------------- | -------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Starter                          | Pro                  | Pro                  | This pack is designed for deploying new production sites at large scale and running multiple applications. It enables also advanced management in terms of cost governance.                                                                              |
| Pro                              | Ultimate             | Pro                  | This pack is designed for multi-site deployments requiring advanced management in terms of security requirements, application resilience, and cost governance.                                                                                           |
| Ultimate                         | Ultimate             | Ultimate             | This pack includes everything you need for Enterprise multi-site deployments and the most complex use cases. It supports integrated governance workflows, advanced security and resilience features, and multiserver applications deployment automation. |

 

:::info

Again, take note that the "Starter" licenses for NCI or NCM are not part of the Nutanix on OVHcloud packaged service.

:::
