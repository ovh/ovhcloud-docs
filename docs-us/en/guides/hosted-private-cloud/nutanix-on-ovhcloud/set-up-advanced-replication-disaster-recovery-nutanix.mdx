# How to Set Up Advanced Replication and Disaster Recovery with Nutanix

This guide details how to set up advanced replication and disaster recovery plans with **Nutanix Disaster Recovery** (formerly Leap) in **Prism Central**.

## Introduction

Nutanix Disaster Recovery allows:

- Asynchronous and synchronous replication based on the chosen license pack
- Test replicas
- Advanced disaster recovery plans with virtual machine startup and, in some cases, cluster-to-cluster failover automation (only with synchronous replication and a cluster witness)
- a destination to the Nutanix cloud with **Disaster Recovery** (note that this solution is not available with licenses provided by OVHcloud)

## Requirements

- Two Nutanix clusters in your OVHcloud account

- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)

- Access to your clusters via **Prism Central**

- An interconnection between two clusters, for example using these technologies:

  - via an IPsec VPN as detailed in the guide [Interconnecting IPsec between two sites](/guides/hosted-private-cloud/nutanix-on-ovhcloud/interconnect-two-nutanix-clusters-ipsec-vpn)
  - or via a [vRack](https://us.ovhcloud.com/network/vrack/) connection.

- **Prism Central** needs more resources depending on the mode:

  - Single Mode: 4GB additional RAM.
  - Scale Mode with 3 **Prism Central** virtual machines: 8 GB additional RAM per virtual machine.

## Instructions

Our Disaster Recovery Plan will be set up between two clusters, both of which are located in remote OVHcloud datacenters, one in Datacenter 1 and the other in Datacenter 2. The two clusters are connected by an IPSec VPN with this network configuration:

- Cluster administration LAN in Datacenter 2: **192.168.0.0/24**.

- Cluster administration LAN in Datacenter 1: **192.168.10.0/24**.

- Production LAN for VMs, common to both clusters: **192.168.50.0/24** on VLAN 50.

- Test LAN common to both clusters: **192.168.51.0/25** on VLAN 51.

#### Creating the protection policy

A protection policy creates a scheduled replication between two *Availability zones*. You can choose this type of schedule depending on your license:

- asynchronous every hour
- *nearsync* between 1 and 15 minutes
- synchronous with a delay of 0 seconds (this mode requires a network latency of less than 5ms between the two clusters)

From the main menu, click `Protection Policies` under `Data Protection`.

#### Enabling a disaster recovery plan following an incident on the original cluster

The disaster recovery plan is also used in the event of a problem with the original cluster. In this case, the activation will be done without the data modified since the last synchronization.

If a synchronous replication solution is used, no data loss will occur.

In our case, replication is scheduled every 15 minutes, the risk of data loss can, in the worst case, corresponds to this duration.

From **Prism Central**, connect to the cluster that is receiving replicas.

From the main menu, choose `Recovery Plan` from the `Data Protection` submenu.

![Leap - Set up advanced replication disaster recovery Nutanix - step 68](/images/hosted-private-cloud/nutanix-on-ovhcloud/set-up-advanced-replication-disaster-recovery-nutanix/leap-68.png)

 

Select the Disaster Recovery Plan with the `checkbox` and click the `Actions` button.

![Leap - Set up advanced replication disaster recovery Nutanix - step 69](/images/hosted-private-cloud/nutanix-on-ovhcloud/set-up-advanced-replication-disaster-recovery-nutanix/leap-69.png)

 

Choose `Failover` from the menu.

![Leap - Set up advanced replication disaster recovery Nutanix - step 70](/images/hosted-private-cloud/nutanix-on-ovhcloud/set-up-advanced-replication-disaster-recovery-nutanix/leap-70.png)

 

Check `Unplanned Failover` and click `Failover`.

![Leap - Set up advanced replication disaster recovery Nutanix - step 71](/images/hosted-private-cloud/nutanix-on-ovhcloud/set-up-advanced-replication-disaster-recovery-nutanix/leap-71.png)

 

Type `Failover` in the confirmation field and click `Failover`.

![Leap - Set up advanced replication disaster recovery Nutanix - step 72](/images/hosted-private-cloud/nutanix-on-ovhcloud/set-up-advanced-replication-disaster-recovery-nutanix/leap-72.png)

The virtual machine that is a member of the disaster recovery plan will boot to the destination cluster with the contents of the last replication.
