# Getting Started with Your Nutanix Cluster

**Find out how to get started with your Nutanix cluster.**

This guide will outline the steps you need to take to get started with your Nutanix on OVHcloud cluster:

- [Deploy a rebound VM](#deploy-a-rebound-vm)
- [Secure cluster](#secure-the-cluster)

:::warning

**NOTE:** OVHcloud provides services for which you are responsible for their configuration and management. You are therefore responsible for their proper functioning.\
\
This tutorial is designed to help you as much as possible with common tasks. If you are having difficulty performing these actions, please contact a specialized service provider. OVHcloud cannot provide you with technical support in this regard.

:::

 

## Requirements

- a Nutanix cluster in your OVHcloud account
- access to your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- you must be logged in to Prism Central on the cluster

:::warning

**NOTE:** Some software, such as Microsoft products, require a license. You must therefore ensure that all installed systems and software have these licenses.

:::

 

## Instructions

### Deploy a rebound VM

The rebound VM will serve as an entry point for the operations you must carry out to secure your cluster. It can also be used as a relay to reach other VMs after being put into production.

Continue reading this guide, depending on your OS: [Linux - Rebound via SSH](#linux-ssh) or [Windows - Rebound via RDP](#windows-rdp).

 

#### Rebound via SSH

##### Creating and configuring the Linux VM

In this example, the network configuration is as follows:

- Network: 172.16.0.0/22
- Mask: 255.255.252.0
- Gateway: 172.16.3.254

:::warning

**NOTE:** Adapt this configuration to your cluster. You can find this information by using the

<Api version="v1" section="/nutanix" method="GET" route={"/nutanix/\{serviceName\}"} regions={["us"]} />

API call.

:::

Import your Linux image into the cluster. For more details, please refer to our guide on [importing images into Nutanix](/guides/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central).

In the left-hand menu of **Prism Central**, expand `Compute & Storage` and click `VMs`.

![Nutanix getting started with cluster - First steps - step 1](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-01.png)

 

Click the `Create VM` button.

![Nutanix getting started with cluster - First steps - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-02.png)

 

Customize the name and features of the VM.

![Nutanix getting started with cluster - First steps - step 3](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-03.png)

 

Click `Next`.

You then need to attach a disk. To do this, you can select the image already present on your cluster (Alpine Linux).

![Nutanix getting started with cluster - First steps - step 4](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-04.png)

![Nutanix getting started with cluster - First steps - step 5](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-05.png)

 

Click `Save`.

Then click `Attach Subnet`.

Select the "infra" network and click `Save`.

![Nutanix getting started with cluster - First steps - step 6](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-06.png)

 

Click `Next`.

Select cloud-init, copy the "cloud-init" script, then click `Next` and finally `Create VM`.

![Nutanix getting started with cluster - First steps - step 7](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-07.png)

 

:::warning

**NOTE:** Adapt this configuration to your cluster. You can find this information by using the

<Api version="v1" section="/nutanix" method="GET" route={"/nutanix/\{serviceName\}"} regions={["us"]} />

API call. Make sure to adapt your password and IP configuration.

:::

```
#cloud-config
hostname: bastion-ssh
fqdn: bastion-ssh.domain.local
users:
  - name: bastion
    sudo: ALL=(ALL) NOPASSWD:ALL
    groups: sudo
    shell: /bin/ash
    ssh_pwauth: true
    lock_passwd: false
    plain_text_passwd: OVHcloudR0cks!

growpart:
  mode: growpart
  devices: ["/dev/sda2"]
  ignore_growroot_disabled: true

write_files:
   - path: /etc/network/interfaces
     content: |
        auto lo
        iface lo inet loopback

        auto eth0
        iface eth0 inet static
        address 172.16.2.200
        netmask 255.255.255.252
        gateway 172.16.3.254

runcmd:
   - echo "nameserver 213.186.33.99"  /etc/resolv.conf
   - rc-service networking restart
   - apk update
   - apk upgrade
   - apk add sudo
   - sed -i s/'PasswordAuthentication no'/'PasswordAuthentication yes'/g /etc/ssh/sshd_config
   - sed -i s/'#KbdInteractiveAuthentication yes'/'KbdInteractiveAuthentication yes'/g /etc/ssh/sshd_config
   - rc-service sshd restart
   - lvextend -l +100%FREE /dev/vg0/lv_root
   - resize2fs /dev/vg0/lv_root
   - reboot

final_message: "The system is finally up, after $UPTIME seconds"
```

 

Open the console after restarting the VM. You can see that the VM has taken the settings from the cloud-init file.

![Nutanix getting started with cluster - First steps - step 8](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-08.png)

 

#### Load Balancer configuration

Log in to your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/). Open the Nutanix Cluster configuration page.

In the `Cluster network` box at the bottom of the page, click on the Load Balancer.

![Nutanix getting started with cluster - First steps - step 9](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-09.png)

 

In the `Server clusters` tab, click `Add a server cluster`.

![Nutanix getting started with cluster - First steps - step 10](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-10.png)

 

Name your server farm, then select `TCP` and enter this information:

- Port: 22
- Datacenter: ALL
- Private network: nutanix

![Nutanix getting started with cluster - First steps - step 11](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-11.png)

 

Click `Add` to confirm the creation of the server cluster.

Then click `Add a server`.

![Nutanix getting started with cluster - First steps - step 12](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-12.png)

 

Enter these values:

- **Name (optional)**: `SSH`
- **IPv4 address**: `IP address of your Windows VM`
- **Port**: `22`

Click `Add` to confirm the server creation.

![Nutanix getting started with cluster - First steps - step 13](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-13.png)

 

Then click on the `Front-ends` tab, and on `Add a front-end`.

![Nutanix getting started with cluster - First steps - step 14](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-14.png)

 

Name your front-end, choose the `TCP` protocol, and modify these values:

- **Port**: `22`
- **Datacenter**: `ALL`
- **Default server cluster**: `rebound-ssh (TCP)`

Click `Add`.

![Nutanix getting started with cluster - First steps - step 15](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-15.png)

 

Click `Apply configuration`.

![Nutanix getting started with cluster - First steps - step 16](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-16.png)

 

Select the `Datacenter` and click `Apply configuration`.

![Nutanix getting started with cluster - First steps - step 17](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-17.png)

 

You can track the progress of the changes in the `Tasks` tab.

![Nutanix getting started with cluster - First steps - step 18](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-18.png)

 

The Load Balancer is now configured. Use your preferred terminal to connect to your machine. You can enter your cluster’s DNS name or Load Balancer’s IP address:

![Nutanix getting started with cluster - First steps - step 19](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-19.png)

 

You can now rebound on the different elements of the cluster:

- CVMs
- Hosts
- Prism Element

For example, for a CVM, enter the following in the terminal:

```
ssh nutanix@ipcvm
```

![Nutanix getting started with cluster - First steps - step 20](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-20.png)

 

#### Rebound via RDP[]()

##### Creating and configuring the Windows VM

Import your Windows image into the cluster. Read our guide on [importing images into Nutanix](/guides/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central).

In the left-hand menu of **Prism Central**, expand `Compute & Storage` and click `VMs`.

![Nutanix getting started with cluster - First steps - step 21](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-21.png)

 

Click the `Create VM` button.

![Nutanix getting started with cluster - First steps - step 22](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-22.png)

 

Enter a name in `Name`, choose the options in `VM Properties`, and click `Next`.

![Nutanix getting started with cluster - First steps - step 23](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-23.png)

1. **Adding a system disk**

   Click the button`Attach Disk`.

   ![Nutanix getting started with cluster - First steps - step 24](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-24.png)

   Enter **60** in the `capacity` field and click `Save` to create a 60 GB disk.

   ![Nutanix getting started with cluster - First steps - step 25](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-25.png)

2) **Adding the Windows Server 2022 installation ISO image**

   The image must be imported before it can be used in a new virtual machine.

   For more details on importing images, please refer to our guide on [importing images into Nutanix](/guides/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central).

   Click `Attach Disk`.

   ![Nutanix getting started with cluster - First steps - step 26](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-26.png)

   Change the `Type` parameters to **CD-ROM**, `Operation` to **Clone from Image**, `Image` to **WS2022EN.ISO**.

   Click `Save`.

   ![Nutanix getting started with cluster - First steps - step 27](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-27.png)

3. **Adding ISO image containing AHV-specific drivers**

   This image contains the disk controller driver and must also be imported. It is available on the Nutanix website if you have a Nutanix customer account.

   Click `Attach Disk`.

   ![Nutanix getting started with cluster - First steps - step 28](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-28.png)

   Change the `Type` parameters to **CD-ROM**, `Operation` to **Clone from Image**, and `Image` to **Nutanix-VirtIO-1.1.7.iso**.

   Click `Save`.

   ![Nutanix getting started with cluster - First steps - step 29](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-29.png)

4) **Network configuration**

   Click `Attach Subnet`.

   ![Nutanix getting started with cluster - First steps - step 30](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-30.png)

   Select the "infra" network and click `Save`.

   ![Nutanix getting started with cluster - First steps - step 31](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-31.png)

 

Click `Next`.

![Nutanix getting started with cluster - First steps - step 32](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-32.png)

Select the time zone of your country in the `Timezone` field and click `Next`.

![Nutanix getting started with cluster - First steps - step 33](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-33.png)

 

Click `Create VM`.

![Nutanix getting started with cluster - First steps - step 34](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-34.png)

The newly created virtual machine will then appear in the dashboard.

![Nutanix getting started with cluster - First steps - step 35](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-35.png)

 

#### Installation of Windows Server 2022

Select the virtual machine on which you want to install Windows Server 2022, by ticking the box on the left of the VM.

![Nutanix getting started with cluster - First steps - step 36](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-36.png)

1. **Boot the VM**

   Click the `Actions` menu, then `Power ON`.

   ![Nutanix getting started with cluster - First steps - step 37](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-37.png)

2) **Launch the console**

   Click the `Actions` menu, then `Launch Console`.

   ![Nutanix getting started with cluster - First steps - step 38](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-38.png)

3. **Start the installation**

   Choose your locale and click `Next`.

   ![Nutanix getting started with cluster - First steps - step 39](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-39.png)

   Click `Install now`.

   ![Nutanix getting started with cluster - First steps - step 40](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-40.png)

   Select **Windows Server 2022 Standard (Desktop Experience)** and click `Next`.

   ![Nutanix getting started with cluster - First steps - step 41](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-41.png)

   Read the Microsoft software license terms and conditions, confirm their acceptance, and click `Next`.

   ![Nutanix getting started with cluster - First steps - step 42](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-42.png)

   Click `Custom: Install Microsoft Server Operating System only (advanced)`.

   ![Nutanix getting started with cluster - First steps - step 43](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-43.png)

   Click `Load driver`.

   ![Nutanix getting started with cluster - First steps - step 44](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-44.png)

   Click `Browse`.

   ![Nutanix getting started with cluster - First steps - step 45](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-45.png)

   Select the correct folder `e:\Windows Server 2022\amd64` and click `OK`.

   ![Nutanix getting started with cluster - First steps - step 46](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-46.png)

   Select these drivers:

   - `Nutanix VirtIO Balloon Driver`
   - `Nutanix VirtIO Ethernet Adapter`
   - `Nutanix VirtIO SCSI pass-through controller`
   - `QEMU FWCfg Device`

   Click `Next`.

   ![Nutanix getting started with cluster - First steps - step 47](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-47.png)

   The 60 GB disk appears, click `Next`.

   ![Nutanix getting started with cluster - First steps - step 48](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-48.png)

   Enter and confirm the password in the two fields provided, and click `Finish`.

   ![Nutanix getting started with cluster - First steps - step 49](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-49.png)

   Windows Server 2022 and WS2022-specific drivers for the **AHV** hypervisor have been successfully installed.

   ![Nutanix getting started with cluster - First steps - step 50](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-50.png)

4) **Windows Configuration**

   Log in and assign an IP address to the machine in the "infra" network. In this example, the network configuration is as follows:

   - Network: 172.16.0.0/22
   - Mask: 255.255.252.0
   - Gateway: 172.16.3.254

   :::warning

   **NOTE:** Adapt this configuration to your cluster. You can find this information by using the

   <Api version="v1" section="/nutanix" method="GET" route={"/nutanix/\{serviceName\}"} regions={["us"]} />

   API call.

   :::

   ![Nutanix getting started with cluster - First steps - step 51](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-51.png)

   In the system settings, enable "Remote Desktop".

   :::warning

   **NOTE:** Check the firewall configuration if necessary.

   :::

   ![Nutanix getting started with cluster - First steps - step 52](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-52.png)

 

#### Load Balancer configuration

Log in to your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/). Open the Nutanix Cluster configuration page. In the `Cluster network` box at the bottom of the page, click on the Load Balancer.

![Nutanix getting started with cluster - First steps - step 53](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-53.png)

![Nutanix getting started with cluster - First steps - step 54](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-54.png)

 

Name your server farm, then select `TCP` and enter this information:

- **Port**: `3389`
- **Datacenter**: `ALL`
- **Private network**: `nutanix`

![Nutanix getting started with cluster - First steps - step 55](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-55.png)

Then click on the `Front-ends` tab, and on `Add a front-end`.

![Nutanix getting started with cluster - First steps - step 61](/images/hosted-private-cloud/nutanix-on-ovhcloud/first-steps/nutanix-gettingstartedwithcluster-61.png)

 

You can track the progress of the changes in the `Tasks` tab.

- CVMS
