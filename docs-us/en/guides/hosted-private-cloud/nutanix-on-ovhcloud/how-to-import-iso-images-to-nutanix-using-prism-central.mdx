# How to Import ISO Images to Nutanix Using Prism Central

You can add ISO images to the Nutanix system for later use when installing an operating system.

**This guide details how to import ISO images to Nutanix using Prism Central.**

## Requirements

- a Nutanix cluster in your OVHcloud account
- access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hu)
- connection to Prism Central on the cluster

## Overview of the image system in Nutanix

Images are imported files of various formats, such as ISO images, but it is also possible to import most images of existing virtual machines (vhdx, qcow2, etc.).

Images are imported from Prism Central or Prism Element. This documentation describes how to import an image from Prism Central.

You can import images from a local file or a URL link.

## Instructions

From Prism Central, open the main menu via the top left button.

![ISOimport01.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-import-iso-images-to-nutanix-using-prism-central/16865232135443.png)

 

Unfold `Compute & Storage` and click `Images`.

![ISOimport02.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-import-iso-images-to-nutanix-using-prism-central/16865254966675.png).

 

Click `Add Image`.

![ISOimport03.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-import-iso-images-to-nutanix-using-prism-central/16865267803539.png)

 

Click the `Add File` button.

![ISOimport04.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-import-iso-images-to-nutanix-using-prism-central/16865280527635.png)

 

Select the image file and click `Open`.

![ISOimport05.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-import-iso-images-to-nutanix-using-prism-central/16865272995603.png)

 

Type the file name, add a description, and then click `Next`.

![ISOimport06.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-import-iso-images-to-nutanix-using-prism-central/16865290758931.png)

 

Leave the default options and click `Save`.

![ISOimport07.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-import-iso-images-to-nutanix-using-prism-central/16865308284051.png)

 

The imported image appears in the images dashboard in Prism Central.

![ISOimport08.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-import-iso-images-to-nutanix-using-prism-central/16865309818643.png)
