# How to Configure and Use Nutanix Flow

Nutanix Flow is available on all **Nutanix on OVHcloud** offers. This option secures the network in one or more clusters managed by **Prism Central**

**Learn how to use Nutanix Flow for network security within a Nutanix cluster.**

## Instructions

Log in to **Prism Central**.

To connect to a Nutanix cluster, if required, see the [Go further](#gofurther) section in this guide.

### Enabling **Nutanix Flow**

Click the gear in the top right to change the settings.

![nutanixflow01.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841114143635.png)

 

Scroll down through the settings. Under the **Flow** submenu, click `Microsegmentation`.

![nutanixflow02.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144110099.png)

 

Select the **Enable Microsegmentation** checkbox and click `Save`.

![nutanixflow03.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144113171.png)

 

Microsegmentation is enabled. You can always disable it.

![nutanixflow04.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841114154003.png)

 

### Category configuration[]()

A category is an object that can contain one or more values.

When installing a cluster, some categories already exist and can be modified, and other categories can be added.

Entities, such as virtual machines, subnets, or images, can be among the categories used for a tool like **Flow**, for example.

#### Creating a category

From the main menu, click the `Administration` heading, then click `Categories`.

![nutanixflow05.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144122899.png)

 

Click `New Category`.

![nutanixflow06.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841114161683.png)

 

Type the name of the category in the **Name** box.

Type the name(s) of the value(s) you want associated with that category in the **Values** box.

Then, click `Save`.

![nutanixflow07.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144132755.png)

 

The new category appears in the category list.

![nutanixflow08.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144138643.png)

 

#### Modifying a Category

Select the `Special-Computers category`.

![nutanixflow09.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144140563.png)

 

In the `Actions` menu, click `Update`.

![nutanixflow10.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841114173843.png)

 

Click `Add More Values`. Add the name(s) of the other value(s) you want to include.

Click `Save`.

![nutanixflow11.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144147347.png)

 

The category is visible in the category dashboard with these two new values.

![nutanixflow12.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144151059.png)

 

#### Assigning a Category to a Virtual Machine

In the main menu, under `Compute & Storage` click `VMs`.

![nutanixflow13.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841114185619.png)

 

Select the virtual machine by selecting the checkbox to the left of its name.

![nutanixflow14.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144162067.png)

 

Click `Actions`, then click `Manage Categories`.

![nutanixflow15.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841114195859.png)

 

Type `categoryName:value` and click the `+` sign.

![nutanixflow16.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144170259.png)

 

Click `Save` to save the virtual machine to a category.

![nutanixflow17.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841114201107.png)

 

#### Assigning a category to multiple VMs

`Select` three virtual machines using the checkboxes on the left.

![nutanixflow18.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144174739.png)

 

Click the `Actions` menu and select `Manage Categories`.

![nutanixflow19.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144178195.png)

 

Type `categoryName:value` and click `+`.

![nutanixflow20.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144186259.png)

 

Click `Save`.

![nutanixflow21.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841114230803.png)

 

#### Assigning a Category to Subnets

From the main menu, under `Network & Security` click `Subnets`.

![nutanixflow22.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841114233107.png)

 

Select the subnets by checking the boxes to the left of their names.

![nutanixflow23.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144197395.png)

 

Click the `Actions` menu and select `Manage Categories`.

![nutanixflow24.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841114251795.png)

 

Choose a category by clicking the `+` sign to the left of its name. Then click `Save`.

![nutanixflow25.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841144205587.png)

 

### Network quarantine management

Network quarantine allows you to isolate a virtual machine from the entire network, or allow it restricted access to certain repair tools that are on the network.

#### VM quarantine

In the main menu, under `Compute & Storage` click `VMs`.

![nutanixflow26.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841541299731.png)

 

Select the virtual machine by ticking the box to the left.

![nutanixflow27.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841541308051.png)

 

Click `Actions` and choose `Quarantine VMs` from the menu.

![nutanixflow28.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841571320339.png)

 

Select `Forensic` in `Quarantine Method` and click `Quarantine`.

![nutanixflow29.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18841571326867.png)

The virtual machine is now in quarantine.

 

#### Customizing the network quarantine

There are currently no blockages affecting the quarantined virtual machine. Follow these instructions to configure the quarantine.

From the main menu, select the `Network & Security` submenu, then click `Security Policies`.

![nutanixflow30.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763304979.png)

 

Click the number next to `Quarantined` to view the quarantined virtual machines.

![nutanixflow31.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763308435.png)

 

The list of quarantined VMs appears in the **Name** column. Click `Close` to return to the previous menu.

![nutanixflow32.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842758576403.png)

 

Click `Quarantine` below the **Name** column to edit the rule.

![nutanixflow33.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842758580243.png)

 

The rule status is in `monitoring` mode, as shown in the top left-hand corner.

Traffic is not blocked, but monitored. Connections between the quarantined VMs and the rest of the network are represented by orange lines attached to rectangles representing the IP address of the source or destination.

Click `Enforce` in the top right-hand corner to switch from **Monitoring** mode to **Enforcing** mode with traffic blocking.

![nutanixflow34.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763319315.png)

 

Type `ENFORCE` and click `Confirm`.

![nutanixflow35.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763321747.png)

The rule status is now `Enforced`.

Traffic is blocked. We see attempts to access VMs in quarantines via red dotted lines to blocks containing the IP address of the VM.

Click `Update` in the top right-hand corner to edit the rule to allow certain network streams.

![nutanixflow36.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763324051.png)

 

Click `Next`.

![nutanixflow37.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763329043.png)

 

Move your mouse over an incoming connection attempt and click `Allow Traffic`.

![nutanixflow38.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842758613523.png)

 

Select the checkbox to the left of the **Source** to select the incoming discovered traffic, then click `Allow 1 Discovered Traffic` to allow only the discovered traffic, such as ICMP below.

![nutanixflow39.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763334803.png)

 

Move your mouse over an outgoing connection attempt and click `Allow Traffic`.

![nutanixflow40.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763337107.png)

 

Select the checkbox to the left of the **Source** to select the outbound discovered traffic, then click `Allow 1 Discovered Traffic` to allow only the discovered traffic.

![nutanixflow41.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763344275.png)

 

The authorized traffic is now visible via gray lines, while the blocked traffic is in red.

To create a rule manually without going through network discovery, left-click `Add Source` to allow an incoming connection to the quarantine.

![nutanixflow42.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842758623379.png)

 

Enter the category name and its value in `Add source by: Category`, then click `Add`.

![nutanixflow43.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763349779.png)

 

The source appears in **Configured**.

Click `+` to the left of **Quarantine: Forensics**.

![nutanixflow44.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842758634643.png)

 

Select **Allow all traffic** and click `Save`.

![nutanixflow45.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763355155.png)

 

Right-click `Add Destination` to allow an outgoing rule from quarantine.

![nutanixflow46.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842758645011.png)

 

Enter the category name and its value in `Add source by: Category`, and then click `Add`.

![nutanixflow47.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842758648339.png)

 

Click `+` to the right of **Quarantine: Forensics**.

![nutanixflow48.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763363347.png)

 

Allow all traffic and click `Save`.

![nutanixflow49.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763365395.png)

 

 

Click `Next`.

![nutanixflow50.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763369747.png)

 

Click `Save and Enforce` to apply the quarantine rule changes.

![nutanixflow51.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763376147.png)

 

Click `Quarantine` to view quarantine rule details.

![nutanixflow52.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842758671635.png)

 

The rule status is now `Enforced`, and the **Forensic** mode has been customized.

A virtual machine in **Strict** mode will be completely isolated from the network, while in **Forensic** mode it will have access to the areas defined in the quarantine rule.

![nutanixflow53.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842763385619.png)

 

### Creating an isolation rule

An isolation rule allows the blocking of network communications between two categories (virtual machines or subnets).

For more information about managing categories, see the [Setting up categories](#categoryconfig) section in this guide.

From the main menu, click the `Network & Security` submenu, then `Securities Policies`.

![nutanixflow54.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842936688659.png)

 

Click `Create Security Policy`.

![nutanixflow55.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18842936703635.png)

 

Select `Isolation Environments (Isolation Policy)` and click `Create`.

![nutanixflow56.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843911680275.png)

 

Type the rule name in `Name` and then add a comment in `Purpose`, choose a category in `Isolate this category`, followed by another category in `From this category`.

Select `Enforce` in **Select a Policy mode**, then click `Save and Enforce`.

![nutanixflow57.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843906602131.png)

 

The rule is active in the list of security rules.

Click `the rule's name` below the **Name** column to view details.

![nutanixflow58.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843906603667.png)

 

The status of the rule indicates `Enforced`, and you can see that no connection attempt between the two zones is detected, as this message indicates: **No Traffic between them has been discovered**.

![nutanixflow59.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843911688595.png)

 

If a network connection attempt is detected between these two zones, the message changes to **Traffic between them has been discovered**.

![nutanixflow60.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843906616723.png)

 

### Setting up an application rule

An application rule limits access to certain ports, protocols, or services for members of a category from another category.

This rule can only be used with a category named **Applications** that can be edited but not deleted.

For more information about managing categories, see the [Setting up categories](#categoryconfig) section in this guide.

From the main menu, click `Security Policies` in the `Network & Security` submenu.

![nutanixflow61.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843911695891.png)

 

Click `Create Security Policy`.

![nutanixflow62.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843911697939.png)

 

Select `Secure Application (App Policy)` and click `Create`.

![nutanixflow63.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843906627347.png)

 

Enter the **Name** fields for the rule name, **Purpose** for comment, **Secure this App** by choosing an existing application category, and click `Next`.

![nutanixflow64.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843906643859.png)

 

Click `Add Source` on the left.

![nutanixflow65.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843906649107.png)

 

Choose the `category` for the VLAN and click `Add`.

![nutanixflow66.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843911712403.png)

 

Click `+` to connect the application to the source.

![nutanixflow67.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843911714451.png)

 

Select `Select a Service`, choose the category in **Protocol/Service**, search for the service name in **Port/Service Details**, and click `Save`.

![nutanixflow68.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843906662419.png)

 

Click `Next`.

![nutanixflow69.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843906664083.png)

 

Select `Enforce` and click `Save and Enforce` to enable this rule.

![nutanixflow70.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843906666899.png)

 

The rule you created is in the list of rules.

![nutanixflow71.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-configure-and-use-nutanix-flow/18843911724179.png)
