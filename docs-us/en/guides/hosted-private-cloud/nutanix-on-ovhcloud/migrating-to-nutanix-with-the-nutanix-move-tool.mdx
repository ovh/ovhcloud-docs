## Requirements

- A Nutanix cluster in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- You must be connected to the cluster via Prism Central
- A connection to an environment other than Nutanix

 

## Nutanix Move Overview

**Nutanix Move** is a tool that allows virtual machine migrations from **VMware ESXI**, **Hyper-V**, **Azure**, and **AWS** to **AHV**.

It can also be used to migrate from Nutanix **AHV** to **AWS**.

This software works on a virtual machine whose sources are available on the Nutanix website with a customer account.

For optimal use, we recommend installing **Nutanix Move** as close as possible to the destination.

The **Nutanix Move** software is the only software that communicates between the source and the destination.

:::warning

**Note:** It is strongly discouraged to use **Nutanix Move** with virtual machines on a Windows Server running **Active Directory** or **Microsoft Exchange**. It is best to migrate as recommended by Microsoft.\
\
For VMs that use databases in **Microsoft SQL**, it is best to stop the database service when completing a migration.\
\
Ensure that the original virtual machine is compatible with the destination Nutanix environment.

:::

 

## Instructions

We will look at how to migrate between a remote environment on Hyper-V to an OVHcloud Nutanix environment.

The source and the destination are on two interconnected private networks through an **IPSEC VPN**.

 

### Preparing the original virtual machines before migration

The virtual machine must be in the list of supported virtual machines in the compatibility matrix for the migration to work.

Log in to the [Nutanix Accounting Matrix](https://portal.nutanix.com/page/documents/compatibility-interoperability-matrix/guestos) site to verify the compatibility of the source machines with the destination environment on Nutanix.

 

#### Specificity of virtual machines on LINUX

Some virtual machines will not start correctly after migration via **Nutanix Move**.\
Check the compatibility list as it is likely that the SCSI driver is not supported and needs to be changed with the PCI driver.\
In this case, you will need to follow this procedure to [change the disk controller of a Virtual Machine](#changediskcontroller) after the virtual machine is migrated.

 

#### Specificity of the Microsoft environment

Microsoft does not provide the SCSI adapter and network card **Virtio** drivers. These drivers must be installed before migration. These drivers are available on the Nutanix website with a customer account.

:::warning

**Note:&#x20;**&#x4D;icrosoft Windows 2008 is no longer supported by Microsoft or Nutanix. However, you can install older **Virtio** drivers and attempt a migration.

:::

Login to the Nutanix website with a customer account to download the [VIRTIO drivers](https://portal.nutanix.com/page/downloads?product=ahv\&bit=VirtIO).

Enter your user name in `Email`, your password in `Password`, and click `Log In`.

![nutanixmove01.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424542292755.png)

Click the `Download` link that suits your needs.

For our example, we will download the driver for **amd64**.

![nutanixmove02.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424542296339.png)

From a Windows virtual machine in the Hyper-V environment, double-click `Nutanix-VirtIO-1.1.7-amd64`.

![nutanixmove03.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424514184083.png)

Read the license terms and conditions, accept them by ticking the box, and then click `Install`.

![nutanixmove04.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424542299155.png)

Click `Finish` to complete the installation without having to restart the virtual machine.

![nutanixmove05.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424542300819.png)

### Installing Move on the Nutanix Cluster

#### Downloading and importing sources

Retrieve the file in **qcow2** format from this site: [Download link for Nutanix Move](https://portal.nutanix.com/page/downloads?product=move).

Sign in with an account registered with Nutanix.

![nutanixmove06.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424542302739.png)

Click `Download` to the right of `Move QCOW2 file for AHV`.

![nutanixmove07.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424514190227.png)

Import the downloaded image from **Nutanix Move** into the cluster. For more information on importing images, see our guide on [importing images](https://support.us.ovhcloud.com/hc/en-us/articles/16864667698451). 

 

#### Installing the **Move** virtual machine

Create a virtual machine from the Move image.

From **Prism Central**, open the main menu by clicking on the button in the top left-hand corner.

![nutanixmove08.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424542307603.png)

Click `VMs` in the menu.

![nutanixmove09.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424514197139.png)

Click `Create VM`.

![nutanixmove10.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424514200211.png)

Type **Nutanix Move** in the `Name` field.

Choose the **2 vCPU**, **2 Cores**, and **8 GB** options in the `VM Properties` fields and click `Next`.

![nutanixmove11.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424542323347.png)

Click `Attach Disk`.

![nutanixmove12.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424542327571.png)

Choose the **Disk**, **Clone from Image**, and **move-4.3.0.qcow2** options and click `Save`.

![nutanixmove13.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424514211731.png)

Click on `Attach to Subnet`.

![nutanixmove14.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424514213651.png)

Choose the network in `Subnet`, make sure it is connected in `Network Connection State`, and click `Save`.

![nutanixmove15.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424514214931.png)

Click `Next`.

![nutanixmove16.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424787358739.png)

Leave the default time zone options and click `Next`.

![nutanixmove17.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424787361043.png)

Click `Create VM` to complete the installation of the **Nutanix Move** virtual machine.

![nutanixmove18.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424818921491.png)

Select the **Nutanix Move** virtual machine and click the `Actions` menu.

![nutanixmove19.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424787366803.png)

Click `Power On` in the `Actions` menu to start the virtual machine.

![nutanixmove20.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424787370771.png)

The virtual machine is started and an IP address is obtained if a **DHCP** server is operational on that network.

![nutanixmove21.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17424787374611.png)

This installation of **Nutanix Move** is done on a network that has a DHCP server, but it is possible to configure the virtual machine on a network without a **DHCP server**.

### Configuring **Nutanix Move**

#### Logging in to the web interface and creating environments for migration

Connect to the IP address of the **Nutanix Move** virtual machine through a web browser in HTTPS, as follows: `https://IPaddressNutanixMove/`.

Read the license conditions, accept them and click `Continue`.

![nutanixmove22.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488521020179.png)

Click `OK` to continue.

![nutanixmove23.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488521027091.png)

Select and confirm a password in the fields provided, then click `Set Password` to validate the creation of the Nutanix Move password.

![nutanixmove24.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488490114707.png)

Type the password in `Password` and click `Log In` to log into the **Nutanix Move** web interface.

![nutanixmove25.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488521034387.png)

Click `+ Add Environment`.

![nutanixmove26.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488490134163.png)

Choose `Nutanix AOS`.

![nutanixmove27.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488521041811.png)

Enter the following information:

- **PRISM-CENTRAL-DESTINATION** in the `Environment Name` field
- the private IP address of **Prism Central** in the `Nutanix Environment` field
- a **Prism Central** administration account in the `Username` field
- the account password in the `Password` field

Click `ADD` to add the **Prism Central** environment.

![nutanixmove28.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488521043859.png)

Click `Add Environment`.

![nutanixmove29.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488521046291.png)

Choose `Microsoft Hyper-V`.

![nutanixmove30.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488490152723.png)

Enter the following information:

- **HyperV-SOURCE** in the `Environment Name` field
- the private IP address of the **Hyper-V** server in the `Hyper-V Server/Cluster` field
- a **Hyper-V** administration account in the `Username` field
- the password for this account in the `Password` field

Click `ADD` to add the **Hyper-V** environment.

![nutanixmove31.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488521051795.png)

![nutanixmove32.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488490163091.png)

 

#### Creating a migration plan

We will create a migration plan from the two environments created previously.

The source will be the **Hyper-V** server, and the destination will be the **Nutanix** cluster.

Click `Create a Migration Plan`.

![nutanixmove33.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488521067155.png)

Choose a name in the `Plan Name` field and click `Proceed`.

![nutanixmove34.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488521074323.png)

Enter the following information:

- **HyperV-SOURCE** in the `Select a Source` field
- **PRISM-CENTRAL-DESTINATION** in the `Hyper-V Server/Cluster` field
- the CLUSTER name in the `Target Cluster` field
- the name of the destination container in the `Target Container` field

Then click `Next` to continue to the next step.

![nutanixmove35.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488521080339.png)

Select the virtual machines you want to migrate from the **Hyper-V** environment to **AOS** by clicking on the `+` icon to the left of the VM.\
Click `Next` to continue creating the migration plan.

![nutanixmove36.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488615754643.png)

Choose the network in `Target Network` and click `Next`.

![nutanixmove37.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488599115283.png)

Click `Next` to confirm the migration.

![nutanixmove38.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488599116819.png)

Click `Save` to save the migration plan without running it.

![nutanixmove39.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488599118355.png)

#### Launching the migration

After the migration plan is created, you can manually launch it.

Check the box next to the desired migration plan.

![nutanixmove40.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488615773203.png)

On the `Actions` menu, click `Start`.

![nutanixmove41.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488599125523.png)

The migration is in progress. The `Status` column gives you information on the status of the migration.

![nutanixmove42.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17488615781907.png)

#### Finalizing the migration

Check the status of the migration by hovering over the `In Progress` status.\
A window with the information **Ready to Cutover N** should appear, listing the number of VMs that can be migrated.

Click `In Progress` to start the completion process.

![nutanixmove43.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490288217235.png)

Select all the VMs by ticking the `VM Name` box then click `Cutover`.

![nutanixmove44.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271313939.png)

Click `Continue`.

![nutanixmove45.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271316243.png)

Wait a few moments while it completes.

![nutanixmove46.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490288227091.png)

The migration is complete when **Completed** appears in the `Migration Status` column.

![nutanixmove47.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490288228755.png)

Log into **Prism Central** to view the three migrated VMs that are present and running.

#### Changing the Disk Controller on a Linux Virtual Machine

If the virtual machine does not start properly after the migration, it may be due to a bad disk controller in the virtual machine configuration. In this case, it should be changed by following this procedure:

Go to the main menu of **Prism Central** and click on `VMs`.

![nutanixmove49.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490288241299.png)

Make sure the virtual machine is turned off.

![nutanixmove50.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271337747.png)

Return to the main menu and click `Images`.

![nutanixmove51.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271339283.png)

Click `Add Image`.

![nutanixmove52.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490288249363.png)

Select **VM Disk** as the `Image Source`. Type a name in `Search by VM Name` and click `+`.

![nutanixmove53.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271343891.png)

Type a name in the `Image Name` field and click `Next`.

![nutanixmove54.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490288257555.png)

Select `Place image on source VM's cluster` and click `Save`.

![nutanixmove55.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271347603.png)

The image created from the virtual machine appears after a few moments.

![nutanixmove56.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271349523.png)

Open the main menu and click `VMs`.

![nutanixmove57.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271354131.png)

Check the box to the left of the virtual machine.

![nutanixmove58.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271356563.png)

Open the `Actions` menu and choose `Update`.

![nutanixmove59.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490288275219.png)

Click on the `trash can` icon next to the CDROM drive.

![nutanixmove60.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271362067.png)

Click on the `trash can` icon next to the disk drive.

![nutanixmove61.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271364371.png)

Click `Attach Disk`.

![nutanixmove62.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271370387.png)

Select:

- **Disk** In `Type`
- Select **Clone from image**
- Enter the **name of the image created** in `Image`
- Select PCI as the `Bus type` and click `Save`

![nutanixmove63.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271375379.png)

Click `Next`.

![nutanixmove64.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490288287891.png)

Click `Next`.

![nutanixmove65.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490271388051.png)

Click `Save`.

![nutanixmove66.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/migrating-to-nutanix-with-the-nutanix-move-tool/17490288293651.png)

The disk controller has been modified and the virtual machine boots properly.
