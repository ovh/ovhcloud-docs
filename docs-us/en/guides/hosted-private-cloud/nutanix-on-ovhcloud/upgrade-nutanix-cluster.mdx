# How to Upgrade Your Nutanix Cluster

Once an upgrade of one Nutanix software component is needed, let's review all the main steps to apply it.

**This guide explains the steps to upgrade your Nutanix Cluster.**

## Requirements

- A Nutanix Cluster in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)

## Instructions

### Official documentation for upgrades

You can either look for this document: "The Nutanix upgrades: Life Cycle Manager" or visit the official Nutanix website for archived documents: [Software Documentation: Upgrade Guide](https://portal.nutanix.com/page/documents/details?targetId=Acropolis-Upgrade-Guide-v5_20:Acropolis-Upgrade-Guide-v5_20).

### Backup

As for any action on the configuration of the cluster system, it is strongly recommended to create a new backup or check the latest one.

### Items to update

Some updates are done from **Prism Central**. These are updates for:

- **Prism Central** itself
- \**NCC*

Some other updates must be run from the **Prism Element**. These are updates for:

- **LCM**
- **AOS**
- **Foundation**
- **AHV**

**Note:&#x20;**&#x42;efore performing an update, make sure that the versions of **Prism Element** are supported by OVHcloud and that the version of **Prism Central** to be updated is compatible with **Prism Element**.\
\
Supported versions of **Prism Element** by OVHcloud are 5.20 LTS and 6.1 STS. You can update these subversions, but it is best to wait a month after a new subversion is released.\
\
The compatibility of the version of **Prism Central** with **Prism Element** can be checked on the [NUTANIX Interoperability](https://portal.nutanix.com/page/documents/compatibility-interoperability-matrix/interoperability) website if you have a customer account on the Nutanix website. 

### Prism Central Upgrade

#### LCM Inventory

As documented in the official upgrade process, you should first launch an LCM Inventory to get a view of the software status of the Nutanix Cluster. To do this, select the `main menu icon` in the upper-left corner. Then, select the `Administration` submenu and then click `LCM`.

![Update cluster - Upgrade Nutanix cluster - step 1](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-01.png)

 

Select the `Inventory` tab, then select the `Perform Inventory` button.

![Update cluster - Upgrade Nutanix cluster - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-02.png)

 

After a pre-check phase, you will receive the results as soon as the inventory is done. The available upgrades will be displayed:

![Update cluster - Upgrade Nutanix cluster - step 3](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-03.png)

Select the upgrades you want or update all components. You can also decide to manage those upgrades directly as explained in the next two sections.

####  

#### Performing the upgrade

Once you are certain that you can launch the upgrade, open the `Prism Central Settings`:

![Update cluster - Upgrade Nutanix cluster - step 4](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-04.png)

 

If there are available upgrades, you can select the ones you need to apply, then choose to only do the pre-check or upgrade immediately:

![Update cluster - Upgrade Nutanix cluster - step 5](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-05.png)

 

The pre-check will be executed in any case:

![Update cluster - Upgrade Nutanix cluster - step 6](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-06.png)

 

If you have selected the upgrade process, the process itself will be initiated:

![Update cluster - Upgrade Nutanix cluster - step 7](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-07.png)

 

During the execution, you might lose the connection to Prism Central:

![Update cluster - Upgrade Nutanix cluster - step 8](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-08.png)

 

After a few minutes, you can connect back to the Prism Central interface, and you can then check or wait for the end of the upgrade process:

![Update cluster - Upgrade Nutanix cluster - step 9](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-09.png)

####  

#### NCC upgrade

If there is one or more NCC upgrades available, you can download the ones you need and then launch the upgrade:

![Update cluster - Upgrade Nutanix cluster - step 10](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-10.png)

####  

#### Validation

##### **LCM Inventory update**

Update the LCM inventory. If no upgrades are available anymore, then only the list of installed software components releases will be presented:

![Update cluster - Upgrade Nutanix cluster - step 11](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-11.png)

 

##### **Prism Central upgrade validation**

You can also check that the Nutanix Cluster Prism Central is up-to-date if there is no upgrade available for your cluster: Click on the `Prism Central Settings` and open `Upgrade Prism Central`. There should be no available versions:

![Update cluster - Upgrade Nutanix cluster - step 12](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-12.png)

 

##### **NCC upgrade validation**

You can also check that the Nutanix Cluster NCC is up-to-date if there is no upgrade available for your cluster: Click on the `Prism Central Settings` and open `Upgrade Prism Central`. There should be no available versions in the NCC tab:

![Update cluster - Upgrade Nutanix cluster - step 13](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-13.png)

 

### Updating Prism Element

From the **Prism Central** dashboard, in the **Cluster Quick Access** frame, click your cluster.

![Update cluster - Upgrade Nutanix cluster - step 14](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-14.png)

 

Open the Menu and click on `LCM`.

![Update cluster - Upgrade Nutanix cluster - step 15](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-15.png)

 

Click on the `Inventory` tab, then on the `Perform Inventory` button.

![Update cluster - Upgrade Nutanix cluster - step 16](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-16.png)

 

When the check is complete, click `Return to Inventory`.

![Update cluster - Upgrade Nutanix cluster - step 18](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-18.png)

 

First, we will update **NCC**.

Check `NCC` and click `View Update Plan`.

![Update cluster - Upgrade Nutanix cluster - step 19](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-19.png)

 

Click `Apply 1 Updates`.

![Update cluster - Upgrade Nutanix cluster - step 20](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-20.png)

 

Click `Back to Software Updates`.

![Update cluster - Upgrade Nutanix cluster - step 21](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-21.png)

 

Click `NCC Check` to check the system before major updates.

![Update cluster - Upgrade Nutanix cluster - step 22](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-22.png)

 

Leave `All Checks` and click `Run`.

![Update cluster - Upgrade Nutanix cluster - step 23](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-23.png)

 

Wait for the `Health check` task to complete. You can view it in the `Tasks` menu.

![Update cluster - Upgrade Nutanix cluster - step 24](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-24.png)

 

Select all available updates and click `View Update Plan`.

![Update cluster - Upgrade Nutanix cluster - step 25](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-25.png)

 

Click `Next`.

![Update cluster - Upgrade Nutanix cluster - step 26](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-26.png)

 

Click `Apply # Updates`.

![Update cluster - Upgrade Nutanix cluster - step 27](/images/hosted-private-cloud/nutanix-on-ovhcloud/upgrade-nutanix-cluster/update-cluster-27.png)

**Note:&#x20;**&#x54;he update process can be very long, it is possible that some slowdowns occur but no downtime is to be expected.
