# How to Configure and Use Nutanix Flow

Nutanix Flow is available on all **Nutanix on OVHcloud** offers. This option secures the network in one or more clusters managed by **Prism Central**

**Learn how to use Nutanix Flow for network security within a Nutanix cluster.**

## Instructions

Log in to **Prism Central**.

To connect to a Nutanix cluster, if required, see the [Go further](#gofurther) section in this guide.

### Enabling **Nutanix Flow**

Click the gear in the top right to change the settings.

![Configure use Nutanix flow - step 1](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-01.png)

 

Scroll down through the settings. Under the **Flow** submenu, click `Microsegmentation`.

![Configure use Nutanix flow - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-02.png)

 

Select the **Enable Microsegmentation** checkbox and click `Save`.

![Configure use Nutanix flow - step 3](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-03.png)

 

Microsegmentation is enabled. You can always disable it.

![Configure use Nutanix flow - step 4](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-04.png)

 

### Category configuration[]()

A category is an object that can contain one or more values.

When installing a cluster, some categories already exist and can be modified, and other categories can be added.

Entities, such as virtual machines, subnets, or images, can be among the categories used for a tool like **Flow**, for example.

#### Creating a category

From the main menu, click the `Administration` heading, then click `Categories`.

![Configure use Nutanix flow - step 5](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-05.png)

 

Click `New Category`.

![Configure use Nutanix flow - step 6](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-06.png)

 

Type the name of the category in the **Name** box.

Type the name(s) of the value(s) you want associated with that category in the **Values** box.

Then, click `Save`.

![Configure use Nutanix flow - step 7](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-07.png)

 

The new category appears in the category list.

![Configure use Nutanix flow - step 8](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-08.png)

 

#### Modifying a Category

Select the `Special-Computers category`.

![Configure use Nutanix flow - step 9](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-09.png)

 

In the `Actions` menu, click `Update`.

![Configure use Nutanix flow - step 10](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-10.png)

 

Click `Add More Values`. Add the name(s) of the other value(s) you want to include.

Click `Save`.

![Configure use Nutanix flow - step 11](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-11.png)

 

The category is visible in the category dashboard with these two new values.

![Configure use Nutanix flow - step 12](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-12.png)

 

#### Assigning a Category to a Virtual Machine

In the main menu, under `Compute & Storage` click `VMs`.

![Configure use Nutanix flow - step 13](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-13.png)

 

Select the virtual machine by selecting the checkbox to the left of its name.

![Configure use Nutanix flow - step 14](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-14.png)

 

Click `Actions`, then click `Manage Categories`.

![Configure use Nutanix flow - step 15](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-15.png)

 

Type `categoryName:value` and click the `+` sign.

![Configure use Nutanix flow - step 16](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-16.png)

 

Click `Save` to save the virtual machine to a category.

![Configure use Nutanix flow - step 17](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-17.png)

 

#### Assigning a category to multiple VMs

`Select` three virtual machines using the checkboxes on the left.

![Configure use Nutanix flow - step 18](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-18.png)

 

Click the `Actions` menu and select `Manage Categories`.

![Configure use Nutanix flow - step 19](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-19.png)

 

Type `categoryName:value` and click `+`.

![Configure use Nutanix flow - step 20](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-20.png)

 

Click `Save`.

![Configure use Nutanix flow - step 21](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-21.png)

 

#### Assigning a Category to Subnets

From the main menu, under `Network & Security` click `Subnets`.

![Configure use Nutanix flow - step 22](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-22.png)

 

Select the subnets by checking the boxes to the left of their names.

![Configure use Nutanix flow - step 23](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-23.png)

 

Click the `Actions` menu and select `Manage Categories`.

![Configure use Nutanix flow - step 24](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-24.png)

 

Choose a category by clicking the `+` sign to the left of its name. Then click `Save`.

![Configure use Nutanix flow - step 25](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-25.png)

 

### Network quarantine management

Network quarantine allows you to isolate a virtual machine from the entire network, or allow it restricted access to certain repair tools that are on the network.

#### VM quarantine

In the main menu, under `Compute & Storage` click `VMs`.

![Configure use Nutanix flow - step 26](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-26.png)

 

Select the virtual machine by ticking the box to the left.

![Configure use Nutanix flow - step 27](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-27.png)

 

Click `Actions` and choose `Quarantine VMs` from the menu.

![Configure use Nutanix flow - step 28](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-28.png)

 

Select `Forensic` in `Quarantine Method` and click `Quarantine`.

![Configure use Nutanix flow - step 29](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-29.png)

The virtual machine is now in quarantine.

 

#### Customizing the network quarantine

There are currently no blockages affecting the quarantined virtual machine. Follow these instructions to configure the quarantine.

From the main menu, select the `Network & Security` submenu, then click `Security Policies`.

![Configure use Nutanix flow - step 30](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-30.png)

 

Click the number next to `Quarantined` to view the quarantined virtual machines.

![Configure use Nutanix flow - step 31](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-31.png)

 

The list of quarantined VMs appears in the **Name** column. Click `Close` to return to the previous menu.

![Configure use Nutanix flow - step 32](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-32.png)

 

Click `Quarantine` below the **Name** column to edit the rule.

![Configure use Nutanix flow - step 33](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-33.png)

 

The rule status is in `monitoring` mode, as shown in the top left-hand corner.

Traffic is not blocked, but monitored. Connections between the quarantined VMs and the rest of the network are represented by orange lines attached to rectangles representing the IP address of the source or destination.

Click `Enforce` in the top right-hand corner to switch from **Monitoring** mode to **Enforcing** mode with traffic blocking.

![Configure use Nutanix flow - step 34](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-34.png)

 

Type `ENFORCE` and click `Confirm`.

![Configure use Nutanix flow - step 35](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-35.png)

The rule status is now `Enforced`.

Traffic is blocked. We see attempts to access VMs in quarantines via red dotted lines to blocks containing the IP address of the VM.

Click `Update` in the top right-hand corner to edit the rule to allow certain network streams.

![Configure use Nutanix flow - step 36](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-36.png)

 

Click `Next`.

![Configure use Nutanix flow - step 37](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-37.png)

 

Move your mouse over an incoming connection attempt and click `Allow Traffic`.

![Configure use Nutanix flow - step 38](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-38.png)

 

Select the checkbox to the left of the **Source** to select the incoming discovered traffic, then click `Allow 1 Discovered Traffic` to allow only the discovered traffic, such as ICMP below.

![Configure use Nutanix flow - step 39](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-39.png)

 

Move your mouse over an outgoing connection attempt and click `Allow Traffic`.

![Configure use Nutanix flow - step 40](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-40.png)

 

Select the checkbox to the left of the **Source** to select the outbound discovered traffic, then click `Allow 1 Discovered Traffic` to allow only the discovered traffic.

![Configure use Nutanix flow - step 41](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-41.png)

 

The authorized traffic is now visible via gray lines, while the blocked traffic is in red.

To create a rule manually without going through network discovery, left-click `Add Source` to allow an incoming connection to the quarantine.

![Configure use Nutanix flow - step 42](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-42.png)

 

Enter the category name and its value in `Add source by: Category`, then click `Add`.

![Configure use Nutanix flow - step 43](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-43.png)

 

The source appears in **Configured**.

Click `+` to the left of **Quarantine: Forensics**.

![Configure use Nutanix flow - step 44](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-44.png)

 

Select **Allow all traffic** and click `Save`.

![Configure use Nutanix flow - step 45](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-45.png)

 

Right-click `Add Destination` to allow an outgoing rule from quarantine.

![Configure use Nutanix flow - step 46](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-46.png)

 

Enter the category name and its value in `Add source by: Category`, and then click `Add`.

![Configure use Nutanix flow - step 47](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-47.png)

 

Click `+` to the right of **Quarantine: Forensics**.

![Configure use Nutanix flow - step 48](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-48.png)

 

Allow all traffic and click `Save`.

![Configure use Nutanix flow - step 49](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-49.png)

 

 

Click `Next`.

![Configure use Nutanix flow - step 50](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-50.png)

 

Click `Save and Enforce` to apply the quarantine rule changes.

![Configure use Nutanix flow - step 51](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-51.png)

 

Click `Quarantine` to view quarantine rule details.

![Configure use Nutanix flow - step 52](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-52.png)

 

The rule status is now `Enforced`, and the **Forensic** mode has been customized.

A virtual machine in **Strict** mode will be completely isolated from the network, while in **Forensic** mode it will have access to the areas defined in the quarantine rule.

![Configure use Nutanix flow - step 53](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-53.png)

 

### Creating an isolation rule

An isolation rule allows the blocking of network communications between two categories (virtual machines or subnets).

For more information about managing categories, see the [Setting up categories](#categoryconfig) section in this guide.

From the main menu, click the `Network & Security` submenu, then `Securities Policies`.

![Configure use Nutanix flow - step 54](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-54.png)

 

Click `Create Security Policy`.

![Configure use Nutanix flow - step 55](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-55.png)

 

Select `Isolation Environments (Isolation Policy)` and click `Create`.

![Configure use Nutanix flow - step 56](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-56.png)

 

Type the rule name in `Name` and then add a comment in `Purpose`, choose a category in `Isolate this category`, followed by another category in `From this category`.

Select `Enforce` in **Select a Policy mode**, then click `Save and Enforce`.

![Configure use Nutanix flow - step 57](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-57.png)

 

The rule is active in the list of security rules.

Click `the rule's name` below the **Name** column to view details.

![Configure use Nutanix flow - step 58](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-58.png)

 

The status of the rule indicates `Enforced`, and you can see that no connection attempt between the two zones is detected, as this message indicates: **No Traffic between them has been discovered**.

![Configure use Nutanix flow - step 59](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-59.png)

 

If a network connection attempt is detected between these two zones, the message changes to **Traffic between them has been discovered**.

![Configure use Nutanix flow - step 60](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-60.png)

 

### Setting up an application rule

An application rule limits access to certain ports, protocols, or services for members of a category from another category.

This rule can only be used with a category named **Applications** that can be edited but not deleted.

For more information about managing categories, see the [Setting up categories](#categoryconfig) section in this guide.

From the main menu, click `Security Policies` in the `Network & Security` submenu.

![Configure use Nutanix flow - step 61](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-61.png)

 

Click `Create Security Policy`.

![Configure use Nutanix flow - step 62](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-62.png)

 

Select `Secure Application (App Policy)` and click `Create`.

![Configure use Nutanix flow - step 63](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-63.png)

 

Enter the **Name** fields for the rule name, **Purpose** for comment, **Secure this App** by choosing an existing application category, and click `Next`.

![Configure use Nutanix flow - step 64](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-64.png)

 

Click `Add Source` on the left.

![Configure use Nutanix flow - step 65](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-65.png)

 

Choose the `category` for the VLAN and click `Add`.

![Configure use Nutanix flow - step 66](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-66.png)

 

Click `+` to connect the application to the source.

![Configure use Nutanix flow - step 67](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-67.png)

 

Select `Select a Service`, choose the category in **Protocol/Service**, search for the service name in **Port/Service Details**, and click `Save`.

![Configure use Nutanix flow - step 68](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-68.png)

 

Click `Next`.

![Configure use Nutanix flow - step 69](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-69.png)

 

Select `Enforce` and click `Save and Enforce` to enable this rule.

![Configure use Nutanix flow - step 70](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-70.png)

 

The rule you created is in the list of rules.

![Configure use Nutanix flow - step 71](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-use-nutanix-flow/nutanixflow-71.png)
