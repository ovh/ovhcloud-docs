## Requirements

- A Nutanix cluster in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)
- Being connected to the cluster via the Prism Element web interface

 

## Overview of storage operations in a Nutanix cluster

When a Nutanix cluster is created, the system connects all the nodes' disks in a **Storage Pool**. It is not recommended to have multiple Storage Pools.

By default, the **replication factor** is set to 2, and it can be changed to 3 if you have at least five nodes.

The data is not stored directly in the Storage Pool, it is stored in **Storage Containers** where it is possible to enable options for compression, deduplication, etc. to optimize storage utilization.

There are also **Volume Groups** that provide the ability to access via ISCSI or directly in SCSI simulation for:

- A third-party computer outside the cluster or a cluster VM
- Multiple third-party computers or VMs in the cluster for applications that require shared storage, such as Microsoft SQL databases in Cluster mode

 

## Instructions

### Modifying replication factor

Click the gear in the top right of the Prism Element interface.

![Overview storage management Nutanix cluster - step 1](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-01.png)

 

Scroll through the settings and click `Redundancy state`.

If you have five nodes, you can change the **Desired Redundancy factor** setting from 2 to 3. It will take some time for the data to be on three nodes.

![Overview storage management Nutanix cluster - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-02.png)

 

### Creating a Storage Container

We will create a **Storage Container**, with a minimum of 300 GB reserved for this storage. The other settings are default ones.

From the menu, select `Storage`.

![Overview storage management Nutanix cluster - step 3](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-03.png)

 

Select the `Storage Container` tab and click `+ Storage Container` on the right.

![Overview storage management Nutanix cluster - step 4](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-04.png)

 

Enter a name for the storage container in the **NAME** entry box.\
Then click `Advanced Settings`.

![Overview storage management Nutanix cluster - step 5](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-05.png)

 

In the **RESERVED CAPACITY** field, enter the size of your container. Other options are also available.

![Overview storage management Nutanix cluster - step 6](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-06.png)

 

Then click `Save` to finish creating the **Storage Container**.

![Overview storage management Nutanix cluster - step 7](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-07.png)

 

The new **Storage Container** is then visible in the dashboard.

![Overview storage management Nutanix cluster - step 8](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-08.png)

 

### Create a Volume Group

Select the `Volume Group` tab and click `+ Volume Group` on the right.

![Overview storage management Nutanix cluster - step 9](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-09.png)

 

Click **+ Add New Disk**.

![Overview storage management Nutanix cluster - step 10](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-10.png)

 

Enter a **size** in the dedicated field and click `Add`.

![Overview storage management Nutanix cluster - step 11](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-11.png)

 

The disk appears in the **Volume Group**. You can then add several other disks.

![Overview storage management Nutanix cluster - step 12](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-12.png)

 

Once you have created your disk(s), browse the available options and confirm that you want to create the **Volume Group** by clicking `Save`.

![Overview storage management Nutanix cluster - step 13](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-13.png)

 

The **Volume Group** will then appear in the list.

![Overview storage management Nutanix cluster - step 14](/images/hosted-private-cloud/nutanix-on-ovhcloud/overview-storage-management-nutanix-cluster/nutanix-storage-14.png)
