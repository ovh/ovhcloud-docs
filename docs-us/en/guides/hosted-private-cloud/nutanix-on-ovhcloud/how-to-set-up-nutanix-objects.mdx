# How to Set Up Nutanix Objects

Nutanix Objects implements an **Object Storage** S3™ \* compatible solution on your Nutanix cluster, using Prism Central. You can read the description on [this link](https://www.nutanix.com/content/dam/nutanix/resources/datasheets/ds-objects.pdf).

**This guide will show you how to set up Nutanix Objects on your cluster.**

## Requirements

- A Nutanix cluster in your OVHcloud account.
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub).
- You must be connected to the cluster via Prism Central.

## Instructions

From Prism Central, click your cluster in the **Cluster Quick Access** widget to connect to Prism Element.

![setupobjects01.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735191443.png)

 

Click your cluster's name in the top left-hand corner next to the **X**.

![setupobjects02.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735203987.png)

 

Verify the IP Address in the **ISCSI Data Services IP** section, then click `Save`.

![setupobjects03.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635742885651.png)

 

### Configuring VLANs in Prism Central

You need to create two additional VLANs in your cluster configuration and have these VLANs access Prism Central and Prism Element to configure **Nutanix Objects**. These two VLANs must be able to distribute IP addresses. IPAM will be enabled on both VLANs.

From Prism Central, go to the main menu and click on `Subnets` in the **Network & Security** category.

![setupobjects04.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635742888595.png)

 

Click `Create Subnet`.

![setupobjects05.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635742891539.png)

 

Check the `IP Address Management` box and fill in this information :

- **Name**: Type `object-storage`.
- **Type**: Select `VLAN`.
- **VLAN ID**: Type your VLAN number as `100`.
- **Virtual Switch**: Keep `vs0`.
- **Network IP Address / Prefix**: Write your subnet `192.168.100.0/24`.
- **Gateway IP Address**: Enter the address of your gateway `192.168.100.254`.

Then click `Add IP Pool`.

![setupobjects06.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635742893843.png)

 

Enter this information :

- **Start Address**: Start address of your scope as `192.168.100.10`.
- **End Address**: End address of your scope as `192.168.100.200`.

Then click the blue validation button `✓` on the right.

![setupobjects07.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735221011.png)

 

Scroll down and enter the OVHcloud DNS address `213.186.33.99` in **Domain Name Servers** and click `Create`.

![setupobjects08.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735223315.png)

 

Your first VLAN is created. We will create the second VLAN, click on `Create Subnet`.

![setupobjects09.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635742917011.png)

 

Check the `IP Address Management` box and fill in this information :

- **Name**: Type `public-storage`.
- **Type**: Select `VLAN`.
- **VLAN ID**: Type your VLAN number as `101`.
- **Virtual Switch**: Keep `vs0`.
- **Network IP Address / Prefix**: Write your subnet `192.168.101.0/24`.
- **Gateway IP Address**: Enter your gateway address `192.168.101.254`.

Then click `Add IP Pool`.

![setupobjects10.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735228563.png)

 

Enter this information :

- **Start Address**: Start address of your scope as `192.168.101.10`.
- **End Address**: End address of your scope as `192.168.101.200`.

Next, click the blue validation button `✓` on the right.

![setupobjects11.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735232659.png)

 

Scroll down and enter the OVHcloud DNS address `213.186.33.99` in **Domain Name Servers** and click `Create`.

![setupobjects12.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735234195.png)

 

Your two VLANs are created, make sure they can connect to Prism Element and Prism Central through your gateway. You can use this guide to replace the default gateway and use your VLANs: [OVHgateway replacement](https://support.us.ovhcloud.com/hc/en-us/articles/18875377642387).

![setupobjects13.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635742934675.png)

 

### Enabling Nutanix objects in Prism Central

Go to the main menu, scroll to the **Services** section, and click `Objects`.

![setupobjects14.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635742938643.png)

 

Click `Enable`.

![setupobjects15.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735257363.png)

 

Click `Enable` to validate the activation of **Nutanix Objects**.

![setupobjects16.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735264403.png)

 

The service checks your system compatibility.

![setupobjects17.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735266707.png)

 

Click `Next`.

![setupobjects18.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735270419.png)

 

Click `Create Object Store`.

![setupobjects19.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635742972563.png)

 

Fill in this information :

- **Object Store Name**: the name of your object storage, such as `nutanix-objects`.
- **Domain**: The domain name that will be used to access your storage, such as `mydomain.com`.
- **Cluster**: The cluster that must have Nutanix Objects enabled.
- **Worker Nodes**: The number of nodes that your Object storage will use, select the number `1`.

Then click `Next`.

![setupobjects20.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17635735274131.png)

 

Select the VLAN `object-storage` in **Storage Network** and enter these two addresses `192.168.100.1,192.168.100.2` in **Object Store Storage Network static IPs (2 IPs required)**. These addresses must not be within the scope of the VLAN DHCP.

Then click `Next`.

![setupobjects21.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636254899987.png)

 

Select the `public-storage` VLAN in **Storage Network** and enter this range of four addresses `192.168.101.1-192.168.100.4` in **Public Network static IPs**. These addresses should not be within the scope of the VLAN DHCP.

Next, click `Save & Continue`.

![setupobjects22.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636282395155.png)

 

A connection check is performed between the VLANs, Prism Element, and Prism Central.

![setupobjects23.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636282397971.png)

 

When validation is complete, click `Create Object Store`.

![setupobjects24.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636282401811.png)

 

Wait twenty minutes for your Object Storage to be active and accessible through the address **192.168.101.1** that is located in your **public-storage** VLAN.

![setupobjects25.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636282404883.png)

 

### Creating an Access Key to your storage

To be able to use Object storage, it is necessary to create associated **Access Keys**.

Go to the `Access Keys` tab.

![setupobjects26.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636282410643.png)

 

Click `+ Add People`.

![setupobjects27.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636282415507.png)

 

Check `Add people not in a directory service`, type `user@mydomain.com` in **Email Address**, and click `Next`.

![setupobjects28.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636254920979.png)

 

Click `Generate Keys`.

![setupobjects29.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636282421395.png)

 

Click `Download Keys`.

![setupobjects30.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636254926227.png)

**Note:** Your access credentials are only displayed once in your web browser. Please note down this information (Access Key and Secret Key) before closing this window.

![setupobjects31.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636282425107.png)

 

Your user is created with its login details. You can regenerate Access Keys and create a new login.

![setupobjects32.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636282428051.png)

 

### Validation and functional testing

To confirm that our Object storage is working properly, we will use the AWS awscli command-line tool and create a bucket. You can use [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/4603838122643) for more information.

The awscli tool is available on Windows, Linux, and macOS.

Use the following command for help:

```
aws s3 help
```

After installing awscli, we will create two configuration files on a computer that has access to the public-storage VLAN and use the aws command to create a bucket.

Create a `.aws` subfolder in your `%USERPROFILE%` folder on Windows, or `$HOME` on Linux and macOS.

Add the `credentials` file and fill it in with this data:

```
[default]
aws_access_key_id=your-access-key
aws_secret_access_key=secret-access key
```

Then add a second file named `config` with this information :

```
[default]
region=region = us-east-1
```

Then use this command to create a bucket.

```
aws --endpoint-url https://192.168.101.1 s3 mb s3://my-bucket --region=us-east-1 --no-verify-ssl
```

The bucket is created with a warning message about the SSL certificate. In a production environment, it is necessary to use an SSL certificate.

Now that the bucket is created we will use a browser to connect to the web interface provided by Nutanix to check the existence of our bucket.

Using a web browser, connect to this URL `https://192.168.101.1/objectsbrowser` which corresponds to your **Nutanix Objects** access point, and enter your credentials (access\_key and secret\_key). Then click on `Login`.

![setupobjects33.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636282431123.png)

 

You can see the bucket you created in the command line. You can create and delete buckets or objects in your web interface.

![setupobjects34.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-set-up-nutanix-objects/17636282432403.png)
