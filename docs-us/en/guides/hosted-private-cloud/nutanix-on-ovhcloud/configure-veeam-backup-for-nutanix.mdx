# Configure Veeam Backup for Nutanix

**Learn how to install, configure, and use Veeam on a Nutanix cluster.**

Veeam Backup is a backup software available for Nutanix.

:::warning

**NOTE:** OVHcloud provides services for which you are responsible for their configuration and management. You are therefore responsible for their proper functioning.\
\
This tutorial is designed to help you as much as possible with common tasks. If you are having difficulty performing these actions, please contact a specialized service provider. OVHcloud cannot provide you with technical support in this regard.

:::

 

## Requirements

- A Nutanix cluster in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- You must be connected to the cluster via **Prism Central**.
- **Veeam Backup & Replication** installed on a virtual machine in your Nutanix cluster via this procedure: [Setting up Veeam Backup & Replication](https://support.us.ovhcloud.com/hc/en-us/articles/360002270130)
- Knowing the public IP address used by **Veeam Backup** to access the internet
- You must have 4 GB of RAM, 60 GB of storage, and 4 vCPUs to add an additional virtual machine when configuring extensions for **Veeam Backup & Replication**
- You must have remote storage outside of the cluster, such as [OVHcloud Object Storage](https://us.ovhcloud.com/public-cloud/object-storage/)

 

## Instructions

We will customize **Veeam Backup & Replication** for use on a Nutanix cluster, with a remote repository for this cluster at OVHcloud, using the [OVHcloud Object Storage solution](https://us.ovhcloud.com/public-cloud/object-storage/).

 

### Add a user in Prism Element for Veeam Backup

First, you need to create a specific user in Prism Element to use Veeam Backup.

Through **Prism Central**, connect to **Prism Element** by clicking on the cluster under `Cluster Quick Access`.

![ntnxVeeam01.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19060590870803.png)

Once in the **Prism Element**, go to the settings by clicking on the `gear` icon in the top right.

![ntnxVeeam02.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19060590876947.png)

Scroll down the menu on the left using the scroll bar. Click `Local User Management`.

![ntnxVeeam03.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19060590879763.png)

Click the `New User` button.

![ntnxVeeam04.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19060566054291.png)

Enter the information:

- **Username**: `svc_veeam`
- **First Name**: `Veeam`
- **Last Name**: `Backup`
- **Email**: `veeam@example.com`
- **Password**: `password`

:::info

This data is provided as an example. The email address is mandatory, but is not used.

:::

Select the `Cluster Admin` checkbox and click `Save`.

![ntnxVeeam05.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19060590885011.png)

This user account is created and added to the **Prism Element** user list.

![ntnxVeeam06.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19060590887443.png)

 

### Download and install the extension for a Nutanix cluster under AHV

Log in to the virtual machine where Veeam Backup is located.

From a web browser, download the latest version of the [AHV extension for Veeam](https://www.veeam.com/availability-nutanix-ahv-download.html). You must have a user account on the **Veeam** website, which you can create free of charge.

Start the installation of the extension.

:::warning

**NOTE:&#x20;**&#x42;efore starting the installation, make sure that the **Veeam Backup & Replication** console is closed.

:::

Open the "NutanixAHPlugin" installer.

![ntnxVeeam07.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19060566070675.png)

Accept the General Terms and Conditions of Use and click `Next`.

![ntnxVeeam08.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19060566073235.png)

Click `Next`.

![ntnxVeeam09.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19060590896787.png)

Click `Install`.

![ntnxVeeam10.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19060566087059.png)

Once the installation is complete, click `Finish`.

![ntnxVeeam11.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19060590901395.png)

#### Modifying the interface virtual machine host file

:::info

This operation is required if you do not use an internal DNS server to resolve VM names. Notably, the VM is used for the Veeam Backup software.

:::

Via **Prism Central**, connect to the NUTANIX-PROXY virtual machine.

Open the main menu at the top left and choose `VMs`.

![ntnxVeeam35.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062249431059.png)

Click on the NUTANIX-PROXY virtual machine.

![ntnxVeeam36.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062281264019.png)

Click `Launch console`.

![ntnxVeeam37.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062249435155.png)

Log in with the user account you created earlier and the password associated with that account.

![ntnxVeeam38.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062249438611.png)

From the console, edit the `/etc/hosts` file:

```
proxy_user@NUTANIX-PROXY~$sudo nano /etc/hosts
[sudo] password for proxy_user:
```

Add this information, which corresponds to the IP address and name of the virtual machine where Veeam Backup is installed:

```
192.168.0.245 VEEAM-BACKUP 
```

Save the file and run this command:

```
proxy_user@NUTANIX-PROXY~$sudo /etc/init.d/networking restart
[sudo] password for proxy_user:
```

### Setting up an automated backup

In **Veeam backup**, open the `Home` menu (bottom left), then the `Backup Job` menu, and choose `Nutanix AHV`.

![ntnxVeeam57.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062291162259.png)

The **AHV Proxy** web interface opens.

Name the task you want to create, tick the `Backup job` option, and click `Next`.

![ntnxVeeam58.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062291169811.png)

Click `Add`.

![ntnxVeeam59.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062323226515.png)

Select the virtual machines you want to back up and click `Add`.

![ntnxVeeam60.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062648354323.png)

Click `Next`.

![ntnxVeeam61.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062648358419.png)

Select the repository in `Backup repository` and click `Next`.

![ntnxVeeam62.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062640642195.png)

Select the `Run the job automatically` check box, set the frequency, and click `Next`.

![ntnxVeeam63.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062640643987.png)

Click `Finish` to save the backup job.

![ntnxVeeam64.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062648369555.png)

The backup is visible through the **AHV Proxy** web interface.

![ntnxVeeam65.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062648373267.png)

Return to the **Veeam Backup** console via the `Home` menu (at the bottom left). Click `Jobs` to view the backup job you created.

![ntnxVeeam66.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configure-veeam-backup-for-nutanix/19062648374931.png)
