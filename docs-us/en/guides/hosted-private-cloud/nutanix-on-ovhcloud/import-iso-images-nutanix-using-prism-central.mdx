# How to Import ISO Images to Nutanix Using Prism Central

You can add ISO images to the Nutanix system for later use when installing an operating system.

**This guide details how to import ISO images to Nutanix using Prism Central.**

## Requirements

- a Nutanix cluster in your OVHcloud account
- access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hu)
- connection to Prism Central on the cluster

## Overview of the image system in Nutanix

Images are imported files of various formats, such as ISO images, but it is also possible to import most images of existing virtual machines (vhdx, qcow2, etc.).

Images are imported from Prism Central or Prism Element. This documentation describes how to import an image from Prism Central.

You can import images from a local file or a URL link.

## Instructions

From Prism Central, open the main menu via the top left button.

![ISO import - Import ISO images Nutanix using prism central - step 1](/images/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central/iso-import-01.png)

 

Unfold `Compute & Storage` and click `Images`.

![ISO import - Import ISO images Nutanix using prism central - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central/iso-import-02.png).

 

Click `Add Image`.

![ISO import - Import ISO images Nutanix using prism central - step 3](/images/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central/iso-import-03.png)

 

Click the `Add File` button.

![ISO import - Import ISO images Nutanix using prism central - step 4](/images/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central/iso-import-04.png)

 

Select the image file and click `Open`.

![ISO import - Import ISO images Nutanix using prism central - step 5](/images/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central/iso-import-05.png)

 

Type the file name, add a description, and then click `Next`.

![ISO import - Import ISO images Nutanix using prism central - step 6](/images/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central/iso-import-06.png)

 

Leave the default options and click `Save`.

![ISO import - Import ISO images Nutanix using prism central - step 7](/images/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central/iso-import-07.png)

 

The imported image appears in the images dashboard in Prism Central.

![ISO import - Import ISO images Nutanix using prism central - step 8](/images/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central/iso-import-08.png)
