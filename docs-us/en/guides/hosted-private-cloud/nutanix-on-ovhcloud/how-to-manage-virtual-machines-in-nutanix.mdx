# How to Manage Virtual Machines in Nutanix

**Find out how to manage virtual machines in a Nutanix cluster, and how to create and migrate a virtual machine.**

## Requirements

- a Nutanix cluster in your OVHcloud account
- access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)
- You must be connected to Prism Central on the cluster

## Overview of Virtual Machine Management in Prism Central

The Nutanix system uses the same interfaces to manage storage and virtualization and it can be installed with multiple hypervisors (**Hyper-V, VMware ESXi, AHV**). **AHV** comes with Nutanix without the need to purchase additional licenses for the hypervisor.

The OVHcloud solution is delivered with the **AHV hypervisor**.

**AHV** enables:

- Using virtual machines on Windows and Linux.
- Migrating virtual machines from one node to another in a cluster.
- Micro-segmentation and network security between virtual machines using **Flow** software.

The **Move** tool makes it easy to migrate existing virtual machines in other environments (**ESXi, Hyper-V & AWS**) to Nutanix and its **AHV** hypervisor.

## Instructions

The following instructions show the creation of a virtual machine in Windows Server 2022 and the migration of a virtual machine.

### Creating a Virtual Machine for a Windows 2022 Operating System

Installing a virtual machine on Windows Server 2022 requires a particular setup because Microsoft does not provide the driver for the **AHV** hypervisor disk controller.

#### Creating a Windows Server 2022 VM

In the left-hand menu of **Prism Central**, expand `Compute & Storage` and click `VMs`.

![manageVMs01.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887396117267.png)

 

Click the `Create VM` button.

![manageVMs02.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887418742931.png)

 

Type a name in `Name`, choose the options in `VM Properties`, and click `Next`.

![manageVMs03.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887419955731.png)

 

##### **Adding a system disk**

Click the `Attach Disk` button.

![manageVMs04.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887421019539.png)

 

Enter **60** in the `Capacity` field and click `Save` to create a 60 GB disk.

![manageVMs05.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887444597395.png)

#####  

##### **Adding Windows Server 2022 Installation ISO Image**

The image must be imported before it can be used in a new virtual machine.

Click `Attach Disk`.

![manageVMs06.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887446132243.png)

 

Change the `Type` settings to **CD-ROM**, `Operation` to **Clone from Image**, `Image` to **WS2022EN.ISO**.

Click `Save`.

![manageVMs07.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887447734163.png)

#####  

##### **Adding an ISO image containing AHV-specific drivers**

This image contains the disk controller driver and should also be imported. It is available on the Nutanix website if you have a Nutanix customer account.

Click `Attach Disk`.

![manageVMs08.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887449064083.png)

 

Change the `Type` settings to **CD-ROM**, `Operation` to **Clone from Image**, `Image` to **Nutanix-VirtIO-1.1.7.iso**.

Click `Save`.

![manageVMs09.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887480622099.png)

#####  

##### **Network configuration**

Click `Attach Subnet`.

![manageVMs10.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887471728531.png)

 

Leave the default fields and click `Save`.

![manageVMs11.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887505510931.png)

 

Click `Next`.

![manageVMs12.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887496858259.png)

 

Select your timezone and click `Next`.

![manageVMs13.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887513828627.png)

 

Click `Create VM`.

![manageVMs14.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887578527379.png)

 

The newly created virtual machine will then appear in the dashboard.

![manageVMs15.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887541560083.png)

 

#### Windows Server 2022 setup

Select the virtual machine on which you want to install Windows Server 2022, by ticking the box to the left of the VM.

![manageVMs16.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887593920787.png)

#####  

##### **Powering on the virtual machine**

Click the `Actions` menu then `Power ON`.

![manageVMs17.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887595301139.png)

#####  

##### **Launching the console**

Click the `Actions` menu then `Launch Console`.

![manageVMs18.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887607018387.png)

#####  

##### **Starting the installation**

Choose your local settings and click `Next`.

![manageVMs19.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887627386259.png)

 

Click `Install now`.

![manageVMs20.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887661062931.png)

 

Select **Windows Server 2022 Standard (Desktop Experience)** and click `Next`.

![manageVMs21.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887630622867.png)

 

Review the Microsoft software license terms and conditions, accept them, and click `Next`.

![manageVMs22.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887625217683.png)

 

Click `Custom: Install Microsoft Server Operating System only (advanced)`.

![manageVMs23.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887678354579.png)

 

Click on `Load driver`.

![manageVMs24.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887670331283.png)

 

Click `Browse`.

![manageVMs25.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887674368403.png)

 

Select the correct folder `e:\Windows Server 2022\amd64` and click `OK`.

![manageVMs26.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887697790227.png)

 

Select these drivers:

- `Nutanix VirtIO Balloon Driver`
- `Nutanix VirtIO Ethernet Adapter`
- `Nutanix VirtIO SCSI pass-through controller`
- `QEMU FWCfg Device`

Click `Next`.

![manageVMs27.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887699980051.png)

 

The 60 GB disk will appear, click `Next`.

![manageVMs28.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887729390867.png)

 

Enter and confirm the password in both fields and click `Finish`.

![manageVMs29.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887746563859.png)

 

Windows Server 2022 and WS2022 specific drivers for the **AHV** hypervisor have been installed.

![manageVMs30.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887738013331.png)

####  

#### Installing NGT (Nutanix Guest Tools)

NGT are tools that enable better interaction with Nutanix, particularly in terms of backups and snapshots.

Start the virtual machine console, right-click a CDROM drive, and click `Eject`.

![manageVMs31.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887739627539.png)

 

Go back to Prism Central and select the virtual machine.

![manageVMs32.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887769468947.png)

 

On the `Actions` menu, click `Install NGT`.

![manageVMs33.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887758262675.png)

 

Click `Confirm & Enter Password`.

![manageVMs34.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887772781843.png)

 

Click `Skip and Mount`.

![manageVMs35.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887807474963.png)

 

Return to the virtual machine console and right-click the CDROM drive containing the NGT.

Click `Install Nutanix Guest Tools`.

![manageVMs36.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887808972563.png)

 

Review the terms and conditions, accept them, then click `Install`.

![manageVMs37.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887847002131.png)

 

The installation will then begin.

![manageVMs38.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887838771731.png)

 

Once the installation is complete, close the installation wizard using the `Close` button.

![manageVMs39.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887817303571.png)

The installation of a virtual machine on Windows is then complete.

### Migrating a virtual machine

Migrating a virtual machine involves moving a hot VM from one node to another in a cluster.

If you have several clusters and the appropriate licenses, you can also migrate a VM from one cluster to another.

This guide only shows you how to migrate a VM within the same cluster.

In Prism Central VM Management, click `WS2022N`.

![manageVMs40.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887841532819.png)

 

Check which node the VM is currently running on. It is displayed next to **Host**.

![manageVMs41.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887869701139.png)

 

Click the `More` button, then `Migrate`.

![manageVMs42.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887872824979.png)

 

Choose a destination node.

![manageVMs43.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887889573395.png)

 

The name of the new node will appear next to **Host** if the migration is complete.

![manageVMs44.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-manage-virtual-machines-in-nutanix/16887913468435.png)
