# Replacing OVHgateway

:::warning

**NOTE:** OVHcloud provides services for which you are responsible for their configuration and management. You are therefore responsible for their proper functioning.\
\
This tutorial is designed to help you as much as possible with common tasks. If you are having difficulty performing these actions, please contact a specialized service provider. OVHcloud cannot provide you with technical support in this regard.

:::

 

## Requirements

- One Nutanix cluster provided by OVHcloud
- Access to the [OVHcloud Control Panel](https://manager.us.ovhcloud.com/manager/)
- Access to your clusters via Prism Central

 

## Instructions

The OVHgateway uses two network cards by default:

- One on VLAN 0 (base) connected to the internet with an additional OVHcloud IP address.
- One on VLAN 1 (infra) connected to the local administration network with a range of IP addresses, in this example in 192.168.10.0/24.

In our guide, we will replace this gateway with the network operating system **pfSense Community edition** without software support.

:::info

It is entirely possible to use this guide to install other network operating systems compatible with AHV.

:::

 

### Download sources for pfSense installation

Download an ISO image for the **pfSense** installation from this link: [Downloading pfSense](https://www.pfsense.org/download/).

Using [this documentation](/guides/hosted-private-cloud/nutanix-on-ovhcloud/import-iso-images-nutanix-using-prism-central), add the **pfSense ISO** image to your Nutanix cluster.

 

### Create the GW-PFSENSE virtual machine

In **Prism Central**, navigate to `Infrastructure` > `Compute` > `VMs` > `Create VM`.

<details>
<summary>Click here for the full VM specifications.</summary>

Create a virtual machine with these settings:

- **Name**: `GW-PFSENSE`

- **vCPU(s)**: `2`

- **Number Of Cores Per vCPU**: `1`

- **Memory**: `4 GB`

- **Boot Configuration:** `Legacy BIOS`

- **Disk (1)**

  - **Type**: `CD-ROM`
  - **Operation**: `Clone from image`
    - **Image**: Your pfSense ISO file
  - **Bus Type**: `SATA`

- **Disk (2)**

  - **Type**: `DISK`
  - **Operation**: `Allocate on Storage Container`
  - **Bus Type**: `SCSI`
  - **Storage Container**: Select an Object Storage container with at least 100 GB of storage space.

- **Network**: two network cards

  - `VLAN 0 (base)`
  - `VLAN 1 (infra)`

You can use [our guide on virtual machine management](/guides/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix) to create this virtual machine.

![Prism pfSense create VM](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/prism-pfsense-create-vm.png)

</details>

<details>

Click on the `OVHgateway` virtual machine.

![Prism VMs overview hgateway](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/prism-vms-ovhgateway.png)

![Prism VMs overview hgateway shutdown](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/prism-vms-ovhgateway-shutdown.png)

</details>

 

### Retrieve the public address in the OVHcloud Control Panel

Retrieve information about the OVHcloud gateway network settings.

Log in to the [OVHcloud Control Panel](https://manager.us.ovhcloud.com/), select your Nutanix cluster, and find the information in the `IPFO` field.

![Manager Nutanix general information tab - step 3](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/manager-nutanix-general-information-tab-3.png)

**IPFO** is a range of four addresses. The first and last are reserved, the third is on OVHcloud hardware and serves as an **Internet** gateway. The only usable IP address is the second address in the range.

During installation, we will reuse this information to assign it to the new **GW-PFSENSE virtual machine**.

```
XX.XX.XX.N Reserved network address that appears on the OVHcloud client site
XX.XX.XX.N+1 IP address to be assigned to the GW-PFSENSE virtual machine WAN interface
XX.XX.XX.N+2 Address to be used as a gateway on the GW-PFSENSE VM WAN interface
XX.XX.XX.N+3 Reserved broadcast IP address
```

For example, if the **IPFO** address displayed on the client site is 198.51.100.0/30, use:

- **198.51.100.1** for the **WAN** interface address.
- **198.51.100.2** for the gateway on the **WAN** interface.

### Install pfSense

:::warning

**NOTE:** These images and instructions are specific to the pfSense `ISO`. See the [pfSense official documentation](https://docs.netgate.com/pfsense/en/latest/install/install-walkthrough.html) for more information.

:::

<summary>Click here for full installation instructions.</summary>

#### Accept the license information

Review the pfSense license information and press the `Enter` key to accept it.

 

#### Welcome

Choose `Install`, switch to `OK` with the `Tab` key, and press `Enter`.

![pfSense installation - Software gateway replacement - step 1](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-installation-1.png)

 

#### Network Installation

Choose `OK` by pressing `Enter`.

![pfSense installation - Software gateway replacement - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-installation-2.png)

 

#### WAN Interface Assignment and Configuration

Leave `vtnet0` selected, and press `OK`.

![pfSense installation - Software gateway replacement - step 3](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-installation-3.png)

 

#### WAN (vtnet0) Network Mode Setup

Change the `Interface Mode` to **Static** by pressing `OK`.

![pfSense installation - Software gateway replacement - step 4](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-installation-4.png)

Modify the following areas with the correct configuration settings:

| Section           | Input                                                                                                                                                                |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `IP Address`      | Enter the IP address for the OVHgateway, which is the second address in the IP block identified [above](#retrieve-the-public-address-in-the-ovhcloud-control-panel). |
| `Default Gateway` | Enter the gateway IP, which is the third address in the IP block identified [above](#retrieve-the-public-address-in-the-ovhcloud-control-panel).                     |
| `DNS Server`      | Enter your DNS (e.g., 8.8.8.8).                                                                                                                                      |

Choose `Continue` and select `OK`.

![pfSense installation - Software gateway replacement - step 9](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-installation-9.png)

 

#### LAN Interface Assignment and Configuration

![pfSense installation - Software gateway replacement - step 10](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-installation-10.png)

Choose `Continue` and select `OK`.

![pfSense installation - Software gateway replacement - step 11](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-installation-11.png)

![pfSense installation - Software gateway replacement - step 12](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-installation-12.png)

### Configure some options through the web interface

Connect to the pfSense Web Console with the URL https\://192.168.10.254 from a cluster virtual machine on the **AHV LAN: Base**.

Enter the following information:

- **User account**: admin
- **Default password**: pfsense

Then click `SIGN IN`.

![pfSense login screen](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-login-screen.png)

 

<details>
<summary>Change the pfSense default password</summary>

From the `System` menu, choose `User Manager`.

![pfSense home system menu](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-home-system-menu.png)

Click the `Pen` icon on the right-hand side.

![pfSense users](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-users.png)

On the following screen, choose a new password, retype it to confirm, then scroll to the bottom of the page and click `Save`.

</details>

<details>
<summary>Add a rule to allow remote administration from a public address</summary>

Go to the `Firewall` menu and choose `Rules`.

![pfSense home firewall menu](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-home-firewall-menu.png)

Check that you are on the `WAN` tab, then click the `⬆️ Add` button (at the bottom) to create a firewall rule.

![pfSense wan rules](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-wan-rules.png)

Set these options:

- **Edit Firewall Rule**

  - Action: `Pass`
  - Interface: `WAN`
  - Address Family: `IPv4`
  - Protocol: `TCP`

- **Source**

  - Select `Address or alias` from the drop-down menu.
  - Enter the `public address` that can connect to the **pfSense** firewall.

- **Destination**

  - Destination: `WAN address`
  - Destination Port Range From: `HTTPS`
  - Destination Port Range To: `HTTPS`

Click `Save` at the bottom of the page.

![pfSense create wan rule](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-create-wan-rule.png)

Once you have returned to the rules list, click `Apply Changes` to activate the rule.

The **pfSense** administration interface is then accessible from the Internet, only from the authorized network in HTTPS, here `https://198.51.100.1`.

![pfSense wan rules apply changes](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-wan-rules-apply-changes.png)

</details>

 

### Configuring Internet Access in a New VLAN

We will create a new subnet in VLAN 2 with an address range in 192.168.2.0/24 and a gateway in 192.168.2.254.

<details>
<summary>PfSense VM modification</summary>

Log in to Prism Central to make these changes:

Use the [Isolating management machines from production](/guides/hosted-private-cloud/nutanix-on-ovhcloud/isolate-management-machines-from-production) guide to create a new VLAN on your Nutanix cluster with these settings:

- **VLAN name**: `Production`
- **VLAN number**: `2`

Your new network must appear in **Subnets**.

![Prism subnets list](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/prism-subnets-list.png)

Now that the new subnet has been created, we will add an adapter to the configuration of your **GW-PFSENSE** virtual machine.

Via the virtual machine management, click on your **GW-PFSENSE** virtual machine, go to the `Update` menu, and choose `Network`.

On the next page, click `+ Attach to Subnet`.

Choose the `Production` subnet and click `Save`.

![Prism VMs attach subnet mod](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/prism-vms-attach-subnet-mod.png)

</details>

<details>
<summary>Enable and configure the new network adapter on pfSense</summary>

Log in to the pfSense interface in https, with the public address (for example, **https\://198.51.100.1**) in your pfSense administration interface, and follow these instructions:

Go to the `Interfaces` menu and click `Assignments`.

![pfSense home interfaces menu](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-home-interfaces-menu.png)

Click `+ Add` to the right of **Available network ports**.

![pfSense interfaces assignments](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-interfaces-assignments.png)

Select the `vtnet2` interface and click `Save`.

![pfSense interface assignments add](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-interface-assignments-add.png)

In the `Interfaces` menu, click `OPT1`.

![pfSense home interfaces menu - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-home-interfaces-menu-2.png)

Check **Enable Interfaces** and modify these settings :

- **Description**: `VLAN2`
- **IPv4 Address**: `192.168.2.254/24`

Click `Save`.

![pfSense interfaces enable](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-interfaces-enable.png)

Click `Apply Changes`.

![pfSense interfaces apply changes](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-interfaces-apply-changes.png)

Go to the `Firewall` menu and click `Rules`.

![pfSense home firewall menu](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-home-firewall-menu.png)

Go to the `VLAN2` tab and click the `⬆️ Add` button on the left.

![pfSense firewall rules VLAN - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-firewall-rules-vlan-2.png)

Change these values:

- **Protocol**: `Any`
- **Source** : `VLAN2 subnet`
- **Destination**: `Any`

Click `Save`.

![pfSense firewall rules add rule](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-firewall-rules-add-rule.png)

Click `Apply Changes`.

![pfSense VLAN 2 rules apply changes](/images/hosted-private-cloud/nutanix-on-ovhcloud/software-gateway-replacement/pfsense-vlan-2-rules-apply-changes.png)

Your VLAN 2 is now connected to the Internet!

</details>
