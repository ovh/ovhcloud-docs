# Configure Veeam Backup for Nutanix

**Learn how to install, configure, and use Veeam on a Nutanix cluster.**

Veeam Backup is a backup software available for Nutanix.

:::warning

**NOTE:** OVHcloud provides services for which you are responsible for their configuration and management. You are therefore responsible for their proper functioning.\
\
This tutorial is designed to help you as much as possible with common tasks. If you are having difficulty performing these actions, please contact a specialized service provider. OVHcloud cannot provide you with technical support in this regard.

:::

 

## Requirements

- A Nutanix cluster in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- You must be connected to the cluster via **Prism Central**.
- **Veeam Backup & Replication** installed on a virtual machine in your Nutanix cluster via this procedure: [Setting up Veeam Backup & Replication](/guides/hosted-private-cloud/vmware/veeam-veeam-backup-replication)
- Knowing the public IP address used by **Veeam Backup** to access the internet
- You must have 4 GB of RAM, 60 GB of storage, and 4 vCPUs to add an additional virtual machine when configuring extensions for **Veeam Backup & Replication**
- You must have remote storage outside of the cluster, such as [OVHcloud Object Storage](https://us.ovhcloud.com/public-cloud/object-storage/)

 

## Instructions

We will customize **Veeam Backup & Replication** for use on a Nutanix cluster, with a remote repository for this cluster at OVHcloud, using the [OVHcloud Object Storage solution](https://us.ovhcloud.com/public-cloud/object-storage/).

 

### Add a user in Prism Element for Veeam Backup

First, you need to create a specific user in Prism Element to use Veeam Backup.

Through **Prism Central**, connect to **Prism Element** by clicking on the cluster under `Cluster Quick Access`.

![Nutanix - Veeam backup - step 1](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-01.png)

Once in the **Prism Element**, go to the settings by clicking on the `gear` icon in the top right.

![Nutanix - Veeam backup - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-02.png)

Scroll down the menu on the left using the scroll bar. Click `Local User Management`.

![Nutanix - Veeam backup - step 3](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-03.png)

Click the `New User` button.

![Nutanix - Veeam backup - step 4](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-04.png)

Enter the information:

- **Username**: `svc_veeam`
- **First Name**: `Veeam`
- **Last Name**: `Backup`
- **Email**: `veeam@example.com`
- **Password**: `password`

:::info

This data is provided as an example. The email address is mandatory, but is not used.

:::

Select the `Cluster Admin` checkbox and click `Save`.

![Nutanix - Veeam backup - step 5](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-05.png)

This user account is created and added to the **Prism Element** user list.

![Nutanix - Veeam backup - step 6](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-06.png)

 

### Download and install the extension for a Nutanix cluster under AHV

Log in to the virtual machine where Veeam Backup is located.

From a web browser, download the latest version of the [AHV extension for Veeam](https://www.veeam.com/availability-nutanix-ahv-download.html). You must have a user account on the **Veeam** website, which you can create free of charge.

Start the installation of the extension.

:::warning

**NOTE:&#x20;**&#x42;efore starting the installation, make sure that the **Veeam Backup & Replication** console is closed.

:::

Open the "NutanixAHPlugin" installer.

![Nutanix - Veeam backup - step 7](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-07.png)

Accept the General Terms and Conditions of Use and click `Next`.

![Nutanix - Veeam backup - step 8](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-08.png)

Click `Next`.

![Nutanix - Veeam backup - step 9](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-09.png)

Click `Install`.

![Nutanix - Veeam backup - step 10](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-10.png)

Once the installation is complete, click `Finish`.

![Nutanix - Veeam backup - step 11](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-11.png)

 

### Integrate the Nutanix cluster in **Veeam Backup Configuration**

When configuring Veeam Backup for Nutanix, a new virtual machine is added to the cluster, which serves as the interface between the **Veeam Backup** software and the cluster.

Launch the **Veeam Backup** console and click `Connect`.

![Nutanix - Veeam backup - step 12](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-12.png)

Go to `Backup Infrastructure` in the menu at the bottom left, choose `Managed Servers`, and click `Add Server`.

![Nutanix - Veeam backup - step 13](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-13.png)

Click `Nutanix AHV`.

![Nutanix - Veeam backup - step 14](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-14.png)

Enter the `private IP address` of **Prism Element** in `DNS name or IP address` and click `Next`.

![Nutanix - Veeam backup - step 15](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-15.png)

Click `Add` to add the **Prism Element** user account.

![Nutanix - Veeam backup - step 16](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-16.png)

Enter the information for the account created earlier in **Prism Element**:

- **Username**: `svc_veeam`
- **Password**: `Password`

Click `OK`.

![Nutanix - Veeam backup - step 17](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-17.png)

Check that the account you have created has been selected in the "Credentials" field, then click `Next`.

![Nutanix - Veeam backup - step 18](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-18.png)

Click `Continue` to validate the certificate warning message.

![Nutanix - Veeam backup - step 19](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-19.png)

Check `Use the following IP address` and choose an unused private IP address (this address is used when backing up and restoring files), then click `Next`.

![Nutanix - Veeam backup - step 20](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-20.png)

Click `Next`.

![Nutanix - Veeam backup - step 21](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-21.png)

Click `Finish`.

![Nutanix - Veeam backup - step 22](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-22.png)

Click `Yes`.

![Nutanix - Veeam backup - step 23](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-23.png)

Select `Deploy a new proxy`, then click `Next`.

![Nutanix - Veeam backup - step 24](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-24.png)

Name the VM in the “Name” field, then click `Next`.

![Nutanix - Veeam backup - step 25](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-25.png)

Click `Configure`.

![Nutanix - Veeam backup - step 26](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-26.png)

Choose an unused `IP address` on the LAN for the virtual machine and click `OK`.

![Nutanix - Veeam backup - step 27](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-27.png)

Click `Next`.

![Nutanix - Veeam backup - step 28](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-28.png)

Click on `Add` to add and create the **NUTANIX-PROXY** VM login account. This VM is added when a Nutanix cluster is added to the **Veeam Backup and replication** console.

:::warning

**NOTE:&#x20;**&#x54;ake note of the user account and password created. These credentials allow you to connect to the new virtual machine via the web browser, without going through the **Veeam backup** software. The URL will be similar to `https://privateipaddress:8100`.

:::

![Nutanix - Veeam backup - step 29](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-29.png)

Enter the information for the account you created earlier in Prism Element:

- **Username**: `proxy_user`
- **Password**: `password`

Click `OK`.

![Nutanix - Veeam backup - step 30](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-30.png)

Check the user account in the "Credentials" field and click `Next`.

![Nutanix - Veeam backup - step 31](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-31.png)

Check the box `Allow access to all backup repositories` and click `Next`.

![Nutanix - Veeam backup - step 32](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-32.png)

Wait a few minutes.

![Nutanix - Veeam backup - step 33](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-33.png)

The installation ends with a warning message. Please ignore this, as it is the public DNS server that cannot resolve the Veeam server name.

Click `Next`.

![Nutanix - Veeam backup - step 34](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-34.png)

 

#### Modifying the interface virtual machine host file

:::info

This operation is required if you do not use an internal DNS server to resolve VM names. Notably, the VM is used for the Veeam Backup software.

:::

Via **Prism Central**, connect to the NUTANIX-PROXY virtual machine.

Open the main menu at the top left and choose `VMs`.

![Nutanix - Veeam backup - step 35](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-35.png)

Click on the NUTANIX-PROXY virtual machine.

![Nutanix - Veeam backup - step 36](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-36.png)

Click `Launch console`.

![Nutanix - Veeam backup - step 37](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-37.png)

Log in with the user account you created earlier and the password associated with that account.

![Nutanix - Veeam backup - step 38](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-38.png)

From the console, edit the `/etc/hosts` file:

```
proxy_user@NUTANIX-PROXY~$sudo nano /etc/hosts
[sudo] password for proxy_user:
```

Add this information, which corresponds to the IP address and name of the virtual machine where Veeam Backup is installed:

```
192.168.0.245 VEEAM-BACKUP 
```

Save the file and run this command:

```
proxy_user@NUTANIX-PROXY~$sudo /etc/init.d/networking restart
[sudo] password for proxy_user:
```

### Setting up an automated backup

In **Veeam backup**, open the `Home` menu (bottom left), then the `Backup Job` menu, and choose `Nutanix AHV`.

![Nutanix - Veeam backup - step 57](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-57.png)

The **AHV Proxy** web interface opens.

Name the task you want to create, tick the `Backup job` option, and click `Next`.

![Nutanix - Veeam backup - step 58](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-58.png)

Click `Add`.

![Nutanix - Veeam backup - step 59](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-59.png)

Select the virtual machines you want to back up and click `Add`.

![Nutanix - Veeam backup - step 60](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-60.png)

Click `Next`.

![Nutanix - Veeam backup - step 61](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-61.png)

Select the repository in `Backup repository` and click `Next`.

![Nutanix - Veeam backup - step 62](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-62.png)

Select the `Run the job automatically` check box, set the frequency, and click `Next`.

![Nutanix - Veeam backup - step 63](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-63.png)

Click `Finish` to save the backup job.

![Nutanix - Veeam backup - step 64](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-64.png)

The backup is visible through the **AHV Proxy** web interface.

![Nutanix - Veeam backup - step 65](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-65.png)

Return to the **Veeam Backup** console via the `Home` menu (at the bottom left). Click `Jobs` to view the backup job you created.

![Nutanix - Veeam backup - step 66](/images/hosted-private-cloud/nutanix-on-ovhcloud/veeam-backup/ntnx-66.png)
