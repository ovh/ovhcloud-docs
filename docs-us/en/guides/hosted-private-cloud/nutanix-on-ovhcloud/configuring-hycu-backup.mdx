# Configuring HYCU backup

:::warning

**NOTE:** OVHcloud provides services for which you are responsible for their configuration and management. You are therefore responsible for their proper functioning.\
\
This tutorial is designed to help you as much as possible with common tasks. If you are having difficulty performing these actions, please contact a specialized service provider. OVHcloud cannot provide you with technical support in this regard.

:::

 

## Requirements

- A valid HYCU license

  :::info

  For more information on purchasing or managing a HYCU license through OVHcloud, please see our [Ordering and managing a HYCU for OVHcloud license](https://support.us.ovhcloud.com/hc/en-us/articles/46833190186387) guide.

  :::

* A [Nutanix on OVHcloud](https://us.ovhcloud.com/hosted-private-cloud/nutanix/) cluster in your OVHcloud account

* Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)

* [Access to the cluster via Prism Central](https://support.us.ovhcloud.com/hc/en-us/articles/16038767836307#prism-central-access)

* A Public Cloud project with a High Performance Object Storage type storage bucket, with a user with read and write permissions for this bucket.

  :::info

  You can find more information on how to create a Public Cloud project and how to use the High Performance Object Storage service on the following pages:

  - [Creating your first OVHcloud Public Cloud project](https://support.us.ovhcloud.com/hc/en-us/articles/360002245784)
  - [Getting started with Object Storage](https://support.us.ovhcloud.com/hc/en-us/articles/4603838122643)
  - [Managing Object Immutability with Object Lock (WORM)](https://support.us.ovhcloud.com/hc/en-us/articles/10694926634003)

  :::

* 60 GB of storage, 8 GB of memory, and 8 cores on your Nutanix Cluster for the HYCU Instance/Appliance.

## Instructions

### Install and configure HYCU

#### Adding the HYCU installation image

Log in to **Prism Central** (see [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/16038767836307#prism-central-access) for instructions).

From the main menu `☰`, under **Compute & Storage** click `Images` menu.

Then, click `Add Image`.

![HYCUbackup01.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903258643.png)

1. Choose `URL` as the source type, enter the download URL for the latest version, and click `Upload file`.

   :::warning

   **NOTE:** The latest version can be found on the [HYCU support page](https://support.hycu.com/hc/en-us) in the **Downloads** section. If you do not have access to this area, you can create a ticket for the [OVHcloud Support team](https://support.us.ovhcloud.com/hc/en-us/articles/115001819764), who will retrieve the image for you.

   :::

2) In the **Name** field, remove the **.qcow2** extension behind the name, but leave `hycu-X.X.X-XXXX`. Enter a description and click `Next`.

   :::warning

   **NOTE:** It is important to remove the extension in the name to facilitate the HYCU configuration process.

   :::

3. Click `Save` to import the image.

   ![HYCUbackup02.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903262611.png)

- **\< IP address >**: The local IP address of the virtual machine with the subnet mask as XX.XX.XX.XX/XX.
- **\< GATEWAY >**: Local gateway for the virtual machine to access the Internet.
- **\< DNS >**: DNS used on the Internet.

```
#cloud-config
bootcmd:
- /opt/grizzly/bin/cloud_init_setup.sh hycubc < IP address > < GATEWAY > < DNS > `hycu.local,ntnx.local`
```

Modify **Guest Customization** options by selecting `Cloud-init (Linux)` in the **Script Type** drop-down menu. Select `Custom Script` in the **Configuration Method** drop-down menu.

Copy the contents of the yaml script and paste it into the field below **Clear Script**. Then click `Next`.

![HYCUbackup29.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/18957010586515.png)

Click`Actions` and select `Power On`.

![HYCUbackup30.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/18957026705427.png)

The virtual machine is started and has the IP address defined in **cloud-init**.

#### Configuring HYCU

Connect with a web browser to the HYCU administration interface, which should be similar to **https\://nutanixfqdncluster:8443**. The `fqdn` variable corresponds to the URL provided when the Nutanix cluster was created.

<details>
<summary>Click here for full instructions.</summary>

Enter the default password and click `Sign In`.

![HYCUbackup31.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914773523.png)

Change the login password for more security.

Click `Change Password` in the `admin` menu in the top right-hand corner of the interface.

Enter the default password in the **OLD PASSWORD** field, and the new password in the **PASSWORD** and **CONFIRM PASSWORD** fields.

Then click `Save`.

![HYCUbackup32.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914775059.png)

We will now connect HYCU to the Nutanix cluster.

Click the *Settings* `⚙️` icon in the top right corner and choose `Sources`.

![HYCUbackup44.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/18957742332179.png)

Enter information about **Prism Element**:

- **URL**: `https://url_prism_element_local:9440`

- **PASSWORD**: `Prism Element user password`

Click `Next`.

![HYCUbackup34.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914777107.png)

Enter this information about **Prism Central**:

- **URL**: `https://url_prism_central_local:9440`

![HYCUbackup35.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914778387.png)

- ACCESS KEY ID: `Object Storage User Access Key`
- SECRET ACCESS KEY: `Object Storage User Secret Key`

Enable `TARGET ENCRYPTION` and click `Save`.

![HYCUbackup40.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914789907.png)

The target is enabled for Nutanix cluster backups.

![HYCUbackup41.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914793363.png)

### Updating HYCU

HYCU regularly provides updates, for which we detail the process below.

#### Adding sources for a new version of HYCU

<details>
<summary>Click here for full instructions.</summary>

From the **Prism Central** main menu `☰`, under **Compute & Storage**, click `Images`.

Then, click `Add Image`.

![HYCUbackup42.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914795155.png)

Select `URL`.

Enter the URL for the qcow2 image of the latest version of HYCU, such as:

- `https://download.hycu.com/ec/v4.X.X/hotfixes/4.X.X-XXXX/hycu-4.X.X-XXXX.qcow2`

:::info

The URL used for the download is the latest version available on the HYCU website.

:::

Click `Upload file`.

![HYCUbackup43.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914798483.png)

Remove the extension **.qcow2** behind the name `hycu-'4.X.X-XXXX`, enter a description, and click `Next`.

:::warning

**NOTE:** It is important to remove the extension in the name to facilitate the HYCU update process.

:::

![HYCUbackup44.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914801171.png)

Click `Save` to import the image.

![HYCUbackup45.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914804371.png)

</details>

 

#### Running the update from HYCU

<details>
<summary>Click here for full instructions.</summary>

Log in via the URL provided when you created the Nutanix cluster, replacing the port **https\://fqdnclusternutanix:8443**.

Go to the HYCU configuration by clicking the *Settings* `⚙️` icon and choose `Power Options`.

Select `Suspend All`, check `AUTO RESUME AFTER` and leave the **Hours** field at `1`, then click `Save`.

![HYCUbackup46.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914808595.png)

Click `Software Upgrade` from the *Settings* `⚙️` menu .

Choose the latest version from the **AVAILABLE VERSIONS** drop-down menu and click `Software Upgrade`.

Click `Yes` to start the update process.

![HYCUbackup47.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914810131.png)

A backup copy is made during the update process so that it can be restored if there are any issues.

![HYCUbackup63.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/18958518627475.png)

Click the *Settings* `⚙️` icon and click `Power Options`.

Uncheck `🔲` **Suspend All** and click `Save`.

![HYCUbackup49.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903347859.png)

</details>

### Restoring from HYCU

Use the `Virtual Machines` menu and click a backed-up virtual machine.

![HYCUbackup74.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903394451.png)

 

#### Restoring a virtual machine

<details>
<summary>Click here for full instructions.</summary>

Click the `Restore VM` button in the bottom right-hand corner.

![HYCUbackup75.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903395219.png)

Select `Restore VM` and click `Next`.

![HYCUbackup76.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914856851.png)

Leave the default options and click `Restore`.

![HYCUbackup77.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903397267.png)

The virtual machine is fully restored.

</details>

 

#### Retrieving a file

<details>
<summary>Click here for full instructions.</summary>

Click the `Restore files` button in the bottom right-hand corner.

![HYCUbackup78.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903399059.png)

Leave `AUTOMATIC` in the **RESTORE FROM** drop-down menu and click `Next`.

![HYCUbackup79.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903402003.png)

Select the file to restore and click `Next`.

![HYCUbackup80.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836914867475.png)

Leave the default options and click `Next`.

![HYCUbackup81.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903404051.png)

Choose `Rename restored` and click `Restore`.

![HYCUbackup82.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903405203.png)

The restored file is located inside the virtual machine with a new name so as not to delete the old file.

</details>

 

#### Restoring an application

<details>
<summary>Click here for full instructions.</summary>

Click the `Applications` menu and then choose an application to restore by clicking an application below **Name**.

![HYCUbackup103.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/18958732407059.png)

Click the `Restore` button in the bottom right-hand corner.

![HYCUbackup104.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/18958732409875.png)

Select `Restore databases` and click `Next`.

![HYCUbackup85.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903407123.png)

Choose a database and click `Next`.

![HYCUbackup86.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903411347.png)

Disable `OVERWRITE EXISTING DATABASES` and click `Restore`.

![HYCUbackup87.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/configuring-hycu-backup/46836903414419.png)

The database is restored into a new database.

</details>
