# How to Find the Nutanix AOS Versions Supported by OVHcloud

**Find out which versions of Nutanix AOS are supported on OVHcloud Nutanix clusters.**

## Requirements

- a Nutanix Cluster in your OVHcloud account
- access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)
- access to the [OVHcloud API page](https://api.us.ovhcloud.com/)

## Overview of versions supported on an OVHcloud Nutanix cluster

Nutanix offers two versions of AOS that are regularly updated:

- **An LTS (*Long Term Support*) version** updated once per year. These versions are maintained for a longer period and provide bug fixes for an extended time.
- **An STS (*Short Term Support*) version** updated two to four times per year. These versions offer new features and regular upgrades.

When an **LTS** or **STS** version is released, the previous version is supported for three months.

OVHcloud integrates LTS versions with the **Nutanix on OVHcloud** product on their release dates, once a year. For STS versions, OVHcloud includes a maximum of three STS versions per year in the **Nutanix on OVHcloud** product, on Nutanix release dates.

**Note:** You can use **LCM** to make remedial updates to **LTS** and **STS** versions.\
\
During these updates, **LCM** may offer a new version that is not yet qualified by OVHcloud. Please wait for OVHcloud to validate it to continue receiving support.

Qualified versions can be viewed through the OVHcloud API.

## Instructions

We will check the versions supported through the OVHcloud API.

Log in to the [OVHcloud API](https://api.us.ovhcloud.com/). For more details on how the OVHcloud API works, please refer to our guide [First Steps with the OVHcloud API](https://support.us.ovhcloud.com/hc/en-us/articles/360018130839).

Use the following API call:

<Api version="v1" section="/nutanix" method="GET" route={"/nutanix/\{serviceName\}"} regions={["us"]} />

Enter this data:

- **ServiceName:** `FQDN name of your Nutanix Cluster`.

Click `Execute` to retrieve version information.
