# How to Restrict Prism Central Web Access

After delivery, Prism Central is accessible on the public Internet. Access restriction to one or more IP addresses can be achieved through the OVHcloud Load Balancer.

**This guide explains how to secure access to Prism Central.**

## Requirements

- A Nutanix cluster in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)

## Instructions

### Step 1: Find the relevant Load Balancer

Log in to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub) and open the Nutanix cluster vRack configuration page.

Identify the name of your Load Balancer.

![restrictprism01.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-restrict-prism-central-web-access/18832790041491.png)

 

### Step 2: Access your Load Balancer front-ends

Select your Load Balancer identified in the previous step.

![restrictprism02.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-restrict-prism-central-web-access/18832760296467.png)

 

Open the `Front-ends` tab.

![restrictprism03.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-restrict-prism-central-web-access/18832760297619.png)

 

### Step 3: Edit the Prism Central front-end

Click on the `...` button in the table and select `Edit`.

![restrictprism04.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-restrict-prism-central-web-access/18832760300179.png)

 

### Step 4: Add the authorized IPs

In the advanced settings, you can now add your public ISP IP address or any IP addresses from which access should be granted to Prism Central Web.

![restrictprism05.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/how-to-restrict-prism-central-web-access/18832760302483.png)
