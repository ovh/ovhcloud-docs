# Getting Started with Your Nutanix Cluster

**Find out how to get started with your Nutanix cluster.**

This guide will outline the steps you need to take to get started with your Nutanix on OVHcloud cluster:

- [Deploy a rebound VM](#deploy-a-rebound-vm)
- [Secure cluster](#secure-the-cluster)

:::warning

**NOTE:** OVHcloud provides services for which you are responsible for their configuration and management. You are therefore responsible for their proper functioning.\
\
This tutorial is designed to help you as much as possible with common tasks. If you are having difficulty performing these actions, please contact a specialized service provider. OVHcloud cannot provide you with technical support in this regard.

:::

 

## Requirements

- a Nutanix cluster in your OVHcloud account
- access to your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- you must be logged in to Prism Central on the cluster

:::warning

**NOTE:** Some software, such as Microsoft products, require a license. You must therefore ensure that all installed systems and software have these licenses.

:::

 

## Instructions

### Deploy a rebound VM

The rebound VM will serve as an entry point for the operations you must carry out to secure your cluster. It can also be used as a relay to reach other VMs after being put into production.

Continue reading this guide, depending on your OS: [Linux - Rebound via SSH](#linux-ssh) or [Windows - Rebound via RDP](#windows-rdp).

 

#### Rebound via SSH

##### Creating and configuring the Linux VM

In this example, the network configuration is as follows:

- Network: 172.16.0.0/22
- Mask: 255.255.252.0
- Gateway: 172.16.3.254

:::warning

**NOTE:** Adapt this configuration to your cluster. You can find this information by using the

<Api version="v1" section="/nutanix" method="GET" route={"/nutanix/\{serviceName\}"} regions={["us"]} />

API call.

:::

Import your Linux image into the cluster. For more details, please refer to our guide on [importing images into Nutanix](https://support.us.ovhcloud.com/hc/en-us/articles/16864667698451).

In the left-hand menu of **Prism Central**, expand `Compute & Storage` and click `VMs`.

Click the `Create VM` button.

Customize the name and features of the VM.

![Nutanix\_GS\_gettingstartedwithcluster03.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24542915677203.png)

 

Click `Next`.

You then need to attach a disk. To do this, you can select the image already present on your cluster (Alpine Linux).

![Nutanix\_GS\_gettingstartedwithcluster04.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24542867861779.png)

Then click `Attach Subnet`.

Select the "infra" network and click `Save`.

![Nutanix\_GS\_gettingstartedwithcluster06.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544909517971.png)

 

Click `Next`.

Select cloud-init, copy the "cloud-init" script, then click `Next` and finally `Create VM`.

![Nutanix\_GS\_gettingstartedwithcluster07.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544909552915.png)

 

:::warning

**NOTE:** Adapt this configuration to your cluster. You can find this information by using the

<Api version="v1" section="/nutanix" method="GET" route={"/nutanix/\{serviceName\}"} regions={["us"]} />

API call. Make sure to adapt your password and IP configuration.

:::

```
#cloud-config
hostname: bastion-ssh
fqdn: bastion-ssh.domain.local
users:
  - name: bastion
    sudo: ALL=(ALL) NOPASSWD:ALL
    groups: sudo
    shell: /bin/ash
    ssh_pwauth: true
    lock_passwd: false
    plain_text_passwd: OVHcloudR0cks!

growpart:
  mode: growpart
  devices: ["/dev/sda2"]
  ignore_growroot_disabled: true

write_files:
   - path: /etc/network/interfaces
     content: |
        auto lo
        iface lo inet loopback

        auto eth0
        iface eth0 inet static
        address 172.16.2.200
        netmask 255.255.255.252
        gateway 172.16.3.254

runcmd:
   - echo "nameserver 213.186.33.99"  /etc/resolv.conf
   - rc-service networking restart
   - apk update
   - apk upgrade
   - apk add sudo
   - sed -i s/'PasswordAuthentication no'/'PasswordAuthentication yes'/g /etc/ssh/sshd_config
   - sed -i s/'#KbdInteractiveAuthentication yes'/'KbdInteractiveAuthentication yes'/g /etc/ssh/sshd_config
   - rc-service sshd restart
   - lvextend -l +100%FREE /dev/vg0/lv_root
   - resize2fs /dev/vg0/lv_root
   - reboot

final_message: "The system is finally up, after $UPTIME seconds"
```

 

Open the console after restarting the VM. You can see that the VM has taken the settings from the cloud-init file.

![Nutanix\_GS\_gettingstartedwithcluster08.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544909583251.png)

 

#### Load Balancer configuration

Log in to your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/). Open the Nutanix Cluster configuration page.

In the `Cluster network` box at the bottom of the page, click on the Load Balancer.

![Nutanix\_GS\_gettingstartedwithcluster09.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/25239075708819.png)

 

In the `Server clusters` tab, click `Add a server cluster`.

![Nutanix\_GS\_gettingstartedwithcluster10.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544909609491.png)

 

Name your server farm, then select `TCP` and enter this information:

- Port: 22
- Datacenter: ALL
- Private network: nutanix

![Nutanix\_GS\_gettingstartedwithcluster11.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544877781651.png)

 

Click `Add` to confirm the creation of the server cluster.

Then click `Add a server`.

![Nutanix\_GS\_gettingstartedwithcluster12.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544909629843.png)

 

Enter these values:

- **Name (optional)**: `SSH`
- **IPv4 address**: `IP address of your Windows VM`
- **Port**: `22`

Click `Add` to confirm the server creation.

![Nutanix\_GS\_gettingstartedwithcluster13.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544877807251.png)

 

Then click on the `Front-ends` tab, and on `Add a front-end`.

![Nutanix\_GS\_gettingstartedwithcluster14.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544877816339.png)

 

Name your front-end, choose the `TCP` protocol, and modify these values:

- **Port**: `22`
- **Datacenter**: `ALL`
- **Default server cluster**: `rebound-ssh (TCP)`

Click `Add`.

![Nutanix\_GS\_gettingstartedwithcluster15.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544877829011.png)

 

Click `Apply configuration`.

![Nutanix\_GS\_gettingstartedwithcluster16.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544909666067.png)

 

Select the `Datacenter` and click `Apply configuration`.

![Nutanix\_GS\_gettingstartedwithcluster17.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/25239027891475.png)

 

You can track the progress of the changes in the `Tasks` tab.

![Nutanix\_GS\_gettingstartedwithcluster18.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544877869459.png)

 

The Load Balancer is now configured. Use your preferred terminal to connect to your machine. You can enter your cluster’s DNS name or Load Balancer’s IP address:

![Nutanix\_GS\_gettingstartedwithcluster19.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/25239075750547.png)

 

You can now rebound on the different elements of the cluster:

- CVMs
- Hosts
- Prism Element

For example, for a CVM, enter the following in the terminal:

```
ssh nutanix@ipcvm
```

![Nutanix\_GS\_gettingstartedwithcluster20.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544877914515.png)

   ![Nutanix\_GS\_gettingstartedwithcluster25.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544877996563.png)

2) **Adding the Windows Server 2022 installation ISO image**

   The image must be imported before it can be used in a new virtual machine.

   For more details on importing images, please refer to our guide on [importing images into Nutanix](https://support.us.ovhcloud.com/hc/en-us/articles/16864667698451).

   Click `Attach Disk`.

   ![Nutanix\_GS\_gettingstartedwithcluster26.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544909822739.png)

   Change the `Type` parameters to **CD-ROM**, `Operation` to **Clone from Image**, `Image` to **WS2022EN.ISO**.

   Click `Save`.

   ![Nutanix\_GS\_gettingstartedwithcluster27.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24544909885331.png)

3. **Adding ISO image containing AHV-specific drivers**

   This image contains the disk controller driver and must also be imported. It is available on the Nutanix website if you have a Nutanix customer account.

   Click `Attach Disk`.

   ![Nutanix\_GS\_gettingstartedwithcluster28.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24547622757779.png)

   Change the `Type` parameters to **CD-ROM**, `Operation` to **Clone from Image**, and `Image` to **Nutanix-VirtIO-1.1.7.iso**.

   Click `Save`.

   ![Nutanix\_GS\_gettingstartedwithcluster29.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24547622787603.png)

4) **Network configuration**

   Click `Attach Subnet`.

   ![Nutanix\_GS\_gettingstartedwithcluster30.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24547639149331.png)

   Select the "infra" network and click `Save`.

   ![Nutanix\_GS\_gettingstartedwithcluster31.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24547622815507.png)

 

Click `Next`.

![Nutanix\_GS\_gettingstartedwithcluster32.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24547622833939.png)

Select the time zone of your country in the `Timezone` field and click `Next`.

![Nutanix\_GS\_gettingstartedwithcluster33.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/25239075767443.png)

![Nutanix\_GS\_gettingstartedwithcluster34.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24547639210003.png)

Select the virtual machine on which you want to install Windows Server 2022, by ticking the box on the left of the VM.

   Choose your locale and click `Next`.

   ![Nutanix\_GS\_gettingstartedwithcluster39.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24556719116435.png)

   ![Nutanix\_GS\_gettingstartedwithcluster40.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24556691116819.png)

   Click `Load driver`.

   Click `Browse`.

   ![Nutanix\_GS\_gettingstartedwithcluster45.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24556719199123.png)

   Select the correct folder `e:\Windows Server 2022\amd64` and click `OK`.

   ![Nutanix\_GS\_gettingstartedwithcluster46.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24556691217811.png)

   - `Nutanix VirtIO Balloon Driver`
   - `Nutanix VirtIO Ethernet Adapter`

   - `QEMU FWCfg Device`

   Click `Next`.

   ![Nutanix\_GS\_gettingstartedwithcluster47.png](/images/hosted-private-cloud/nutanix-on-ovhcloud/getting-started-with-your-nutanix-cluster/24556719221651.png)
