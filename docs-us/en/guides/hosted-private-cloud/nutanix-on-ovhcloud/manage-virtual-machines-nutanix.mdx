# How to Manage Virtual Machines in Nutanix

**Find out how to manage virtual machines in a Nutanix cluster, and how to create and migrate a virtual machine.**

## Requirements

- a Nutanix cluster in your OVHcloud account
- access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)
- You must be connected to Prism Central on the cluster

## Overview of Virtual Machine Management in Prism Central

The Nutanix system uses the same interfaces to manage storage and virtualization and it can be installed with multiple hypervisors (**Hyper-V, VMware ESXi, AHV**). **AHV** comes with Nutanix without the need to purchase additional licenses for the hypervisor.

The OVHcloud solution is delivered with the **AHV hypervisor**.

**AHV** enables:

- Using virtual machines on Windows and Linux.
- Migrating virtual machines from one node to another in a cluster.
- Micro-segmentation and network security between virtual machines using **Flow** software.

The **Move** tool makes it easy to migrate existing virtual machines in other environments (**ESXi, Hyper-V & AWS**) to Nutanix and its **AHV** hypervisor.

## Instructions

The following instructions show the creation of a virtual machine in Windows Server 2022 and the migration of a virtual machine.

### Creating a Virtual Machine for a Windows 2022 Operating System

Installing a virtual machine on Windows Server 2022 requires a particular setup because Microsoft does not provide the driver for the **AHV** hypervisor disk controller.

#### Creating a Windows Server 2022 VM

In the left-hand menu of **Prism Central**, expand `Compute & Storage` and click `VMs`.

![VMs - Manage virtual machines Nutanix - step 1](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-01.png)

 

Click the `Create VM` button.

![VMs - Manage virtual machines Nutanix - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-02.png)

 

Type a name in `Name`, choose the options in `VM Properties`, and click `Next`.

![VMs - Manage virtual machines Nutanix - step 3](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-03.png)

 

##### **Adding a system disk**

Click the `Attach Disk` button.

![VMs - Manage virtual machines Nutanix - step 4](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-04.png)

 

Enter **60** in the `Capacity` field and click `Save` to create a 60 GB disk.

![VMs - Manage virtual machines Nutanix - step 5](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-05.png)

#####  

##### **Adding Windows Server 2022 Installation ISO Image**

The image must be imported before it can be used in a new virtual machine.

Click `Attach Disk`.

![VMs - Manage virtual machines Nutanix - step 6](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-06.png)

 

Change the `Type` settings to **CD-ROM**, `Operation` to **Clone from Image**, `Image` to **WS2022EN.ISO**.

Click `Save`.

![VMs - Manage virtual machines Nutanix - step 7](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-07.png)

#####  

##### **Adding an ISO image containing AHV-specific drivers**

This image contains the disk controller driver and should also be imported. It is available on the Nutanix website if you have a Nutanix customer account.

Click `Attach Disk`.

![VMs - Manage virtual machines Nutanix - step 8](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-08.png)

 

Change the `Type` settings to **CD-ROM**, `Operation` to **Clone from Image**, `Image` to **Nutanix-VirtIO-1.1.7.iso**.

Click `Save`.

![VMs - Manage virtual machines Nutanix - step 9](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-09.png)

#####  

##### **Network configuration**

Click `Attach Subnet`.

![VMs - Manage virtual machines Nutanix - step 10](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-10.png)

 

Leave the default fields and click `Save`.

![VMs - Manage virtual machines Nutanix - step 11](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-11.png)

 

Click `Next`.

![VMs - Manage virtual machines Nutanix - step 12](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-12.png)

 

Select your timezone and click `Next`.

![VMs - Manage virtual machines Nutanix - step 13](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-13.png)

 

Click `Create VM`.

![VMs - Manage virtual machines Nutanix - step 14](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-14.png)

 

The newly created virtual machine will then appear in the dashboard.

![VMs - Manage virtual machines Nutanix - step 15](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-15.png)

 

#### Windows Server 2022 setup

Select the virtual machine on which you want to install Windows Server 2022, by ticking the box to the left of the VM.

![VMs - Manage virtual machines Nutanix - step 16](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-16.png)

#####  

##### **Powering on the virtual machine**

Click the `Actions` menu then `Power ON`.

![VMs - Manage virtual machines Nutanix - step 17](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-17.png)

#####  

##### **Launching the console**

Click the `Actions` menu then `Launch Console`.

![VMs - Manage virtual machines Nutanix - step 18](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-18.png)

#####  

##### **Starting the installation**

Choose your local settings and click `Next`.

![VMs - Manage virtual machines Nutanix - step 19](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-19.png)

 

Click `Install now`.

![VMs - Manage virtual machines Nutanix - step 20](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-20.png)

 

Select **Windows Server 2022 Standard (Desktop Experience)** and click `Next`.

![VMs - Manage virtual machines Nutanix - step 21](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-21.png)

 

Review the Microsoft software license terms and conditions, accept them, and click `Next`.

![VMs - Manage virtual machines Nutanix - step 22](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-22.png)

 

Click `Custom: Install Microsoft Server Operating System only (advanced)`.

![VMs - Manage virtual machines Nutanix - step 23](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-23.png)

 

Click on `Load driver`.

![VMs - Manage virtual machines Nutanix - step 24](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-24.png)

 

Click `Browse`.

![VMs - Manage virtual machines Nutanix - step 25](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-25.png)

 

Select the correct folder `e:\Windows Server 2022\amd64` and click `OK`.

![VMs - Manage virtual machines Nutanix - step 26](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-26.png)

 

Select these drivers:

- `Nutanix VirtIO Balloon Driver`
- `Nutanix VirtIO Ethernet Adapter`
- `Nutanix VirtIO SCSI pass-through controller`
- `QEMU FWCfg Device`

Click `Next`.

![VMs - Manage virtual machines Nutanix - step 27](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-27.png)

 

The 60 GB disk will appear, click `Next`.

![VMs - Manage virtual machines Nutanix - step 28](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-28.png)

 

Enter and confirm the password in both fields and click `Finish`.

![VMs - Manage virtual machines Nutanix - step 29](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-29.png)

 

Windows Server 2022 and WS2022 specific drivers for the **AHV** hypervisor have been installed.

![VMs - Manage virtual machines Nutanix - step 30](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-30.png)

####  

#### Installing NGT (Nutanix Guest Tools)

NGT are tools that enable better interaction with Nutanix, particularly in terms of backups and snapshots.

Start the virtual machine console, right-click a CDROM drive, and click `Eject`.

![VMs - Manage virtual machines Nutanix - step 31](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-31.png)

 

Go back to Prism Central and select the virtual machine.

![VMs - Manage virtual machines Nutanix - step 32](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-32.png)

 

On the `Actions` menu, click `Install NGT`.

![VMs - Manage virtual machines Nutanix - step 33](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-33.png)

 

Click `Confirm & Enter Password`.

![VMs - Manage virtual machines Nutanix - step 34](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-34.png)

 

Click `Skip and Mount`.

![VMs - Manage virtual machines Nutanix - step 35](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-35.png)

 

Return to the virtual machine console and right-click the CDROM drive containing the NGT.

Click `Install Nutanix Guest Tools`.

![VMs - Manage virtual machines Nutanix - step 36](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-36.png)

 

Review the terms and conditions, accept them, then click `Install`.

![VMs - Manage virtual machines Nutanix - step 37](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-37.png)

 

The installation will then begin.

![VMs - Manage virtual machines Nutanix - step 38](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-38.png)

 

Once the installation is complete, close the installation wizard using the `Close` button.

![VMs - Manage virtual machines Nutanix - step 39](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-39.png)

The installation of a virtual machine on Windows is then complete.

### Migrating a virtual machine

Migrating a virtual machine involves moving a hot VM from one node to another in a cluster.

If you have several clusters and the appropriate licenses, you can also migrate a VM from one cluster to another.

This guide only shows you how to migrate a VM within the same cluster.

In Prism Central VM Management, click `WS2022N`.

![VMs - Manage virtual machines Nutanix - step 40](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-40.png)

 

Check which node the VM is currently running on. It is displayed next to **Host**.

![VMs - Manage virtual machines Nutanix - step 41](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-41.png)

 

Click the `More` button, then `Migrate`.

![VMs - Manage virtual machines Nutanix - step 42](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-42.png)

 

Choose a destination node.

![VMs - Manage virtual machines Nutanix - step 43](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-43.png)

 

The name of the new node will appear next to **Host** if the migration is complete.

![VMs - Manage virtual machines Nutanix - step 44](/images/hosted-private-cloud/nutanix-on-ovhcloud/manage-virtual-machines-nutanix/vms-44.png)
