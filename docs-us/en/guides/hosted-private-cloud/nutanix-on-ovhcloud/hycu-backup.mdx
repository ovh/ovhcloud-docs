# Configuring HYCU backup

:::warning

**NOTE:** OVHcloud provides services for which you are responsible for their configuration and management. You are therefore responsible for their proper functioning.\
\
This tutorial is designed to help you as much as possible with common tasks. If you are having difficulty performing these actions, please contact a specialized service provider. OVHcloud cannot provide you with technical support in this regard.

:::

 

## Requirements

- A valid HYCU license

  :::info

  For more information on purchasing or managing a HYCU license through OVHcloud, please see our [Ordering and managing a HYCU for OVHcloud license](/guides/hosted-private-cloud/nutanix-on-ovhcloud/ordering-managing-hycu-ovhcloud-license) guide.

  :::

* A [Nutanix on OVHcloud](https://us.ovhcloud.com/hosted-private-cloud/nutanix/) cluster in your OVHcloud account

* Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)

* [Access to the cluster via Prism Central](/guides/hosted-private-cloud/nutanix-on-ovhcloud/overview-nutanix-ovhcloud#prism-central-access)

* A Public Cloud project with a High Performance Object Storage type storage bucket, with a user with read and write permissions for this bucket.

  :::info

  You can find more information on how to create a Public Cloud project and how to use the High Performance Object Storage service on the following pages:

  - [Creating your first OVHcloud Public Cloud project](/guides/public-cloud/cross-functional/create-a-public-cloud-project)
  - [Getting started with Object Storage](/guides/storage-and-backup/object-storage/getting-started)
  - [Managing Object Immutability with Object Lock (WORM)](/guides/storage-and-backup/object-storage/managing-object-lock)

  :::

* 60 GB of storage, 8 GB of memory, and 8 cores on your Nutanix Cluster for the HYCU Instance/Appliance.

## Instructions

### Install and configure HYCU

#### Adding the HYCU installation image

Log in to **Prism Central** (see [this guide](/guides/hosted-private-cloud/nutanix-on-ovhcloud/overview-nutanix-ovhcloud#prism-central-access) for instructions).

From the main menu `☰`, under **Compute & Storage** click `Images` menu.

Then, click `Add Image`.

![HYCU backup - step 1](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-01.png)

1. Choose `URL` as the source type, enter the download URL for the latest version, and click `Upload file`.

   :::warning

   **NOTE:** The latest version can be found on the [HYCU support page](https://support.hycu.com/hc/en-us) in the **Downloads** section. If you do not have access to this area, you can create a ticket for the [OVHcloud Support team](/guides/account/account-information/contact-us-support), who will retrieve the image for you.

   :::

2) In the **Name** field, remove the **.qcow2** extension behind the name, but leave `hycu-X.X.X-XXXX`. Enter a description and click `Next`.

   :::warning

   **NOTE:** It is important to remove the extension in the name to facilitate the HYCU configuration process.

   :::

3. Click `Save` to import the image.

   ![HYCU backup - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-02.png)

#### Creating the virtual machine for HYCU

You can create a virtual machine for HYCU from the **Prism Central** interface.

<details>
<summary>Click here for full instructions.</summary>

From the main menu `☰`, under **Compute & Storage**, click `VMs`.

Then, click `Create VM`.

![HYCU backup - step 8](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-08.png)

- **Cores Per CPU**: `2 Cores`

Click `Next`.

![HYCU backup - step 19](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-19.png)

![HYCU backup - step 20](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-20.png)

Click `Save`.

![HYCU backup - step 11](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-11.png)

Click `Attach Disk`.

![HYCU backup - step 22](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-22.png)

Choose these options:

- **Type**: `Disk`
- **Operation**: `Allocate on Storage Container`
- **Image**: `default-container`
- **Capacity**: `32Gib`

Click `Save`.

![HYCU backup - step 13](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-13.png)

Click `Attach to Subnet`.

![HYCU backup - step 24](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-24.png)

Select the `infra` network from the **Subnet** drop-down menu, and select `Connected` in the **Network Connection State** drop-down menu. Then click `Save`.

![HYCU backup 15 - HYCU backup - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-15-2.png)

Click `Next`.

![HYCU backup - step 26](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-26.png)

Create a **yaml** file by editing these values:

- **\< IP address >**: The local IP address of the virtual machine with the subnet mask as XX.XX.XX.XX/XX.
- **\< GATEWAY >**: Local gateway for the virtual machine to access the Internet.
- **\< DNS >**: DNS used on the Internet.

```
#cloud-config
bootcmd:
- /opt/grizzly/bin/cloud_init_setup.sh hycubc < IP address > < GATEWAY > < DNS > `hycu.local,ntnx.local`
```

Modify **Guest Customization** options by selecting `Cloud-init (Linux)` in the **Script Type** drop-down menu. Select `Custom Script` in the **Configuration Method** drop-down menu.

Copy the contents of the yaml script and paste it into the field below **Clear Script**. Then click `Next`.

![HYCU backup - step 27](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-27.png)

Click `Create VM`.

![HYCU backup - step 28](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-28.png)

Select the virtual machine created by using the checkbox `☑️` to the right of the virtual machine.

![HYCU backup - step 29](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-29.png)

Click`Actions` and select `Power On`.

![HYCU backup - step 30](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-30.png)

The virtual machine is started and has the IP address defined in **cloud-init**.

![HYCU backup - step 31](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-31.png)

</details>

#### Configuring HYCU

Connect with a web browser to the HYCU administration interface, which should be similar to **https\://nutanixfqdncluster:8443**. The `fqdn` variable corresponds to the URL provided when the Nutanix cluster was created.

<details>
<summary>Click here for full instructions.</summary>

Enter the default password and click `Sign In`.

![HYCU backup 31 - HYCU backup - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-31-2.png)

Change the login password for more security.

Click `Change Password` in the `admin` menu in the top right-hand corner of the interface.

Enter the default password in the **OLD PASSWORD** field, and the new password in the **PASSWORD** and **CONFIRM PASSWORD** fields.

Then click `Save`.

![HYCU backup - step 32](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-32.png)

We will now connect HYCU to the Nutanix cluster.

Click the *Settings* `⚙️` icon in the top right corner and choose `Sources`.

![HYCU backup - step 44](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-44.png)

Enter information about **Prism Element**:

- **URL**: `https://url_prism_element_local:9440`
- **USERNAME**: `Prism Element user`
- **PASSWORD**: `Prism Element user password`

Click `Next`.

![HYCU backup - step 34](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-34.png)

Enter this information about **Prism Central**:

- **URL**: `https://url_prism_central_local:9440`
- **USERNAME**: `Prism Central user`
- **PASSWORD**: `Prism Central password`

Click `Next`.

![HYCU backup - step 35](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-35.png)

The `VALIDATION SUCCESSFUL` information appears to indicate that the entered information is correct. Click `Save`.

![HYCU backup - step 36](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-36.png)

Click `Close`.

![HYCU backup - step 37](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-37.png)

Select `Targets` from the left-hand menu and click `+ Add` at the top of the interface.

![HYCU backup - step 38](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-38.png)

Enter the configuration settings and authentication keys for your Object Storage user with read/write access to the Object Storage bucket used as explained below:

- **name** Name
- **Size**: Storage size
- **Type**: `AWS S3/Compatible`\*

:::warning

**NOTE:** OVHcloud **High Performance Object Storage** service has no storage limits and is billed on a per-use basis. In the HYCU software configuration, it is necessary to set a size as in the example below. You can choose another value.

:::

Turn `ENABLE COMPRESSION` on and scroll down through the window.

![HYCU backup - step 50](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-50.png)

Complete the information:

- SERVICE ENDPOINT: `Object Storage Storage URL`
- BUCKET NAME: `Bucket name`
- ACCESS KEY ID: `Object Storage User Access Key`
- SECRET ACCESS KEY: `Object Storage User Secret Key`

Enable `TARGET ENCRYPTION` and click `Save`.

![HYCU backup - step 40](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-40.png)

The target is enabled for Nutanix cluster backups.

![HYCU backup - step 41](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-41.png)

</details>

 

### Updating HYCU

HYCU regularly provides updates, for which we detail the process below.

#### Adding sources for a new version of HYCU

<details>
<summary>Click here for full instructions.</summary>

From the **Prism Central** main menu `☰`, under **Compute & Storage**, click `Images`.

Then, click `Add Image`.

![HYCU backup - step 42](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-42.png)

Select `URL`.

Enter the URL for the qcow2 image of the latest version of HYCU, such as:

- `https://download.hycu.com/ec/v4.X.X/hotfixes/4.X.X-XXXX/hycu-4.X.X-XXXX.qcow2`

:::info

The URL used for the download is the latest version available on the HYCU website.

:::

Click `Upload file`.

![HYCU backup - step 43](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-43.png)

Remove the extension **.qcow2** behind the name `hycu-'4.X.X-XXXX`, enter a description, and click `Next`.

:::warning

**NOTE:** It is important to remove the extension in the name to facilitate the HYCU update process.

:::

![HYCU backup 44 - HYCU backup - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-44-2.png)

Click `Save` to import the image.

![HYCU backup - step 45](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-45.png)

</details>

 

#### Running the update from HYCU

<details>
<summary>Click here for full instructions.</summary>

Log in via the URL provided when you created the Nutanix cluster, replacing the port **https\://fqdnclusternutanix:8443**.

Go to the HYCU configuration by clicking the *Settings* `⚙️` icon and choose `Power Options`.

Select `Suspend All`, check `AUTO RESUME AFTER` and leave the **Hours** field at `1`, then click `Save`.

![HYCU backup - step 46](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-46.png)

Click `Software Upgrade` from the *Settings* `⚙️` menu .

Choose the latest version from the **AVAILABLE VERSIONS** drop-down menu and click `Software Upgrade`.

Click `Yes` to start the update process.

![HYCU backup - step 47](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-47.png)

A backup copy is made during the update process so that it can be restored if there are any issues.

![HYCU backup - step 63](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-63.png)

Click the *Settings* `⚙️` icon and click `Power Options`.

Uncheck `🔲` **Suspend All** and click `Save`.

![HYCU backup - step 49](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-49.png)

</details>

#### Creating backup policies

<details>
<summary>Click here for full instructions.</summary>

Go to the P`olicies` menu on the left and click the *Add* `+` button in the top right corner.

![HYCU backup - step 61](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-61.png)

![HYCU backup - step 62](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-62.png)

![HYCU backup 63 - HYCU backup - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-63-2.png)

Change the backup options in **Backup** and change the **BACKUP THRESHOLD** value to `25`. Then scroll down the page.

![HYCU backup - step 64](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-64.png)

![HYCU backup - step 65](/images/hosted-private-cloud/nutanix-on-ovhcloud/hycu-backup/ubackup-65.png)

This strategy makes a backup on OVHcloud Object Storage and also takes **snapshots** inside the Nutanix cluster, allowing for faster recovery.

</details>
