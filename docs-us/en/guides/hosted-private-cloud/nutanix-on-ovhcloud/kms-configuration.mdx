# KMS configuration with Nutanix on OVHcloud

**Learn how to configure the OVHcloud Key Management System (KMS) with Nutanix on OVHcloud.**

Nutanix provides two options for securing data at rest:

- **Self-Encrypted Drives (SEDs)**
- **Software-only encryption**, which offers key-based access management through either the cluster's native key manager or an **external key management system (KMS)**.

By following this guide, you will learn how to leverage **Nutanix's data-at-rest encryption** capabilities using the **OVHcloud KMS**.

 

## Requirements

- A **valid OVHcloud KMS key** in your [OVHcloud account](https://us.ovhcloud.com/manager/) (see [this guide](/guides/manage-and-operate/kms/quick-start) for instructions)

- A [Nutanix on OVHcloud](https://us.ovhcloud.com/hosted-private-cloud/nutanix/) cluster in your OVHcloud account

  :::info

  The cluster must be **compatible with Data-At-Rest Encryption**. Please confirm this with your OVHcloud sales representative or with [the support teams](/guides/account/account-information/contact-us-support).

  A **Nutanix license** that [supports the **Data-At-Rest Encryption** feature](/guides/hosted-private-cloud/nutanix-on-ovhcloud/packaged-service-included-licenses#some-key-features-and-differences-between-packs).

  :::

* Access to the Nutanix cluster via **Prism Central/Prism Element**
* Compliance with Nutanix’s feature guidelines (e.g., [Nutanix Security Guide](https://portal.nutanix.com/page/documents/details?targetId=Nutanix-Security-Guide-v7_0:wc-security-data-encryption-wc-c.html) and [Nutanix KMS Compatibility Matrix](https://portal.nutanix.com/page/documents/compatibility-interoperability-matrix/software?partnerName=OVHCloud\&solutionType=KMS%20%28Key%20Management%20Solutions%29\&componentVersion=External%20Key%20Managers\&hypervisor=all\&validationType=all))

 

## Instructions

### Step 1 - Access Prism Central and Prism Element

Log in to Prism Central (see full instructions here).

Navigate to *Prism Element* by clicking your cluster in the **Cluster Quick Access** panel.

![Network security KMS configuration - step 1](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-01.png)

Select `Home` and choose `Settings`.

![Network security KMS configuration - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-02.png)

 

### Step 2 - Configure Data-at-Rest Encryption

Scroll to the **Security** section and click `Data-at-rest Encryption`.

Click on `Edit Configuration`.

![Network security KMS configuration - step 3](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-03.png)

Complete all fields and supply the requested files while scrolling through the following page.

Click each tab below for more information on each section.

<Tabs>

<Tab label="Encryption Type">

Select an encryption type based on your service and license compatibility. See the [requirements](#requirements) section for more information.

![Network security KMS configuration - step 4](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-04.png)

</Tab>

<Tab label="Select Key Management Server (KMS)">

Select `An external KMS`.

![Network security KMS configuration - step 5](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-05.png)

</Tab>

<Tab label="Certificate Signing Request Information">

Enter your configuration details to generate the Certificate Signing Request (CSR).

:::warning

**NOTE:** This is required to complete this process.

:::

Click `Save CSR Info` and then click `Download CSRs`. Take note of where the file is saved on your computer.

:::info

You will need to generate **Access Certificates** for each node in your cluster using the CSRs you downloaded. See our [Getting started with Key Management Services](/guides/manage-and-operate/kms/quick-start#creating-an-access-certificate) guide for full instructions.

:::

![Network security KMS configuration - step 6](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-06.png)

</Tab>

<Tab label="Key Management Server">

Click `Add New Key Management Server`.

![Network security KMS configuration - step 7](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-07.png)

Enter a Name, Address, and Port for your KMS service and click `Save`.

<details>
<summary>Click here for instructions on retrieving the Address and Port.</summary>

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), navigate to the `Hosted Private Cloud` tab. In the left-hand menu, select `Identity, Security & Operations`, then `Key Management Service`, and then your KMS service. In the **General information** tab, copy the **KMIP**.

![Network security KMS configuration - step 8](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-08.png)

</details>

![Network security KMS configuration - step 9](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-09.png)

 

Click on `Manage Certificates`.

![Network security KMS configuration - step 10](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-10.png)

Upload the Access Certificates for each of the nodes on your cluster by clicking `Upload Files`, selecting your file(s), and clicking `Submit`.

:::info

If you are unsure how to make Access Certificates, see the information in the *Certificate Signing Request Information* tab.

:::

![Network security KMS configuration - step 11](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-11.png)

</Tab>

<Tab label="Add New Certificate Authority">

Click `Add New Certificate Authority`.

![Network security KMS configuration - step 12](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-12.png)

On the next screen, name and upload a Certificate Authority file with a `.cert` extension.

<details>
<summary>Click here for instructions on retrieving the Certificate Authority.</summary>

1. From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), copy the **Id** for your KMS service.

   ![Network security KMS configuration - step 13](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-13.png)

2) From the [OVHcloud API](https://api.us.ovhcloud.com/), run the following API call.

   > Parameters
   >
   > - **okmsId:** retrieved in the previous step
   > - **publicCA:** set to "true"

   <Api version="v2" section="/okms" method="GET" route={"/okms/resource/\{okmsId\}"} regions={["us"]} />

3. Save the "publicCA" line of the results as a text file.

4) Convert the `.txt` into the correct format.

   The text file will need to be edited so that all instances of `/n` are replaced with carriage returns.

   Once that process is complete, change the file extension to `.cert`.

</details>

</Tab>

</Tabs>

 

### Step 3 - Test and Enable Encryption

Back at the **Key Management Server** menu, click `Manage Certificates` again.

![Network security KMS configuration - step 10](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-10.png)

`Test all nodes` in the cluster.

![Network security KMS configuration 10 - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-10-2.png)

If the test is successful, you can now enable encryption for your Nutanix cluster.

![Network security KMS configuration 11 - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-11-2.png)

You can enable both **software encryption** and **Self-Encrypting Drives (SEDs)**.

![Network security KMS configuration 12 - step 2](/images/hosted-private-cloud/nutanix-on-ovhcloud/kms-configuration/network-security-kms-config-12-2.png)
