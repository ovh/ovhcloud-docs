## OVHcloud VPS

An OVHcloud Virtual Private Server bridges the gap between shared web hosting and
a dedicated server, combining performance and reliability without the hassle of
managing hardware. You get full root access to a virtual machine hosted on
OVHcloud infrastructure, with anti-DDoS protection and backup options included.

A VPS is commonly used for:

- Hosting websites — e-commerce, content and visual media
- Hosting software applications — portals, extranets, collaborative tools, wikis and CRM
- Running databases and WordPress multisite platforms
- Hosting game servers
- Running test and sandbox environments
