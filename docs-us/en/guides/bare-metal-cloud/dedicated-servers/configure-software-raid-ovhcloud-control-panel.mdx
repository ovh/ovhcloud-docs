# How to configure Software RAID in the OVHcloud Control Panel

Learn how to configure Software RAID from the OVHcloud Control Panel to protect your data and optimize your storage.

:::warning

**NOTE:** Software RAID can only be configured from the OVHcloud Control Panel before installation.

:::

 

## Requirements

- If you are unfamiliar with RAID, you can read this [Understanding RAID](/guides/bare-metal-cloud/dedicated-servers/configure-software-raid-ubuntu-18-04#understanding-raid) excerpt
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- A [dedicated server](https://us.ovhcloud.com/bare-metal/) in your account

 

## Instructions

### Configuring Software RAID in the OVHcloud Control Panel

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/):

1. Select `Bare Metal Cloud` from the top navigation bar.
2. In the left-hand menu, select `Dedicated servers` and choose your server.
3. In the **General information** panel, click the *more options* `...` button next to **Operating system (OS)**.
4. Choose to `Install from an OVHcloud template` or `Install from one of your templates`.

![RAID disks - Configure software OVHcloud control panel - step 1](/images/bare-metal-cloud/dedicated-servers/configure-software-raid-ovhcloud-control-panel/raid-disks-01.png)

Select your operating system and then check `☑` the **Customize the partition configuration** box.

Click `Next`.

![RAID disks - Configure software OVHcloud control panel - step 2](/images/bare-metal-cloud/dedicated-servers/configure-software-raid-ovhcloud-control-panel/raid-disks-02.png)

Now click the `pencil icon ✏️` next to the partition you wish to edit.

![RAID disks - Configure software OVHcloud control panel - step 3](/images/bare-metal-cloud/dedicated-servers/configure-software-raid-ovhcloud-control-panel/raid-disks-03.png)

You can change the RAID level in the `drop-down menu`.

![RAID disks - Configure software OVHcloud control panel - step 4](/images/bare-metal-cloud/dedicated-servers/configure-software-raid-ovhcloud-control-panel/raid-disks-04.png)

:::warning

**NOTE:** The root (`/`) partition must be configured in RAID 1. If you want to leverage other RAID levels, you can do so by creating other partitions. For example, if you are running a website in Linux, creating a partition for `/var` will allow your website to leverage the increased speed of RAID 10.

:::

Once you have finished the installation, your OS will be ready to go with the RAID level you have chosen.
