# Backup Agent - Managing your backups

:::tip

Need to restore your data? File-level restore is the primary and most common method; full server restore (Bare Metal Recovery) is not supported. See our [Triggering restores](https://support.us.ovhcloud.com/hc/en-us/articles/52099397586963) guide.

:::

:::info

Find more information on the Backup Agent product on [this page](https://support.us.ovhcloud.com/hc/en-us/articles/51706411167635).

:::

 

## Requirements

- A Bare Metal server with the Backup Agent installed on it. Read our guide "[How to configure your first backup](https://support.us.ovhcloud.com/hc/en-us/articles/52033454950291)" for more information.

#### OVHcloud Control Panel Access

- **Direct link:** [Backup Agent](https://manager.us.ovhcloud.com/#/bmc-backup-agent-baremetal/service)
- **Navigation path:** `Bare Metal Cloud` > `Backup Agent`

 

## Instructions

### Backup

You have two options for making backups: Automatic Backup and Manual Backup.

 

#### Automatic backup

Automatic backup is included in the backup policy that we apply to your Backup Agent.

This will back up all your files and send them to your remote storage location.

:::warning

**NOTE:** Automatic backups will begin between 10 p.m. and 6 a.m., based on the time zone of your vault.

:::

:::info

You cannot change or disable this automatic backup. Currently, you cannot modify the policy that backs up your files; we are working to improve this configuration.

:::

You can view the success of this backup via the "Backup Jobs" dashboard of the Veeam Service Provider Console.

![VSPC\_backupJobs.png](/images/bare-metal-cloud/dedicated-servers/backup-agent-managing-your-backups/53561075016723.png)

 

#### Manual backup

If necessary, you can trigger a manual backup.

It will also back up all your files, which will always be sent to your remote storage point.

To create a manual backup, click on the tab corresponding to your Operating System:

<Tabs>

<Tab label="Windows">

Open the "Veeam Agent" application on your Bare Metal server:

![Backup Agent BKP Agent Search](/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-bkpagent-search.png)

Click the `Backup Now` button to launch a backup:

![Backup Agent BKP Agent](/images/storage-and-backup/backup-agent/backup-agent-backup-restore/01-backup-agent-bkpagent.png)

</Tab>

<Tab label="Linux">

To start a manual backup on Linux, you can use the command line.

Connect to your Bare Metal server via SSH and run the following command to list your backup jobs:

```
sudo veeamconfig job list
```

To start a manual backup, use the following command, replacing `<job_name>` with your backup job name:

```
sudo veeamconfig job start --name <job_name>
```

If you want to start all backup jobs, use:

```
sudo veeamconfig job start --all
```

You can monitor the backup progress by viewing active sessions:

```
sudo veeamconfig session list
```

You can also access an interface to interact with the product by typing this command:

```
sudo veeam
```

</Tab>
