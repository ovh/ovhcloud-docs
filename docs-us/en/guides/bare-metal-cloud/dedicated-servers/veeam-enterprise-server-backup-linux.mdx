# Backing Up a Bare Metal Linux Server with Veeam Enterprise

**Learn how to back up your Bare Metal Server using Veeam Backup and Replication (Enterprise).**

Whether it is a hardware failure or accidentally deleting an important file, maintaining frequent backups is extremely important and can save you countless hours of unnecessary work.

 

## Requirements

- [Veeam Backup & Replication installed and registered](/guides/hosted-private-cloud/vmware/veeam-veeam-backup-replication)

 

## Instructions

Open the Veeam Backup and Replication panel for your backup server.

To begin, from the **Home** tab, click the `Backup Job` button and select the `Linux computer...` option to backup.

![Veeam backup - Enterprise server Linux - step 1](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/veeam-backup-01.png)

 

In the **Job Mode** section, select the server `Type` and the `Mode` for backup.

Then, click the `Next` button.

![Veeam backup - Enterprise server Linux - step 2](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/veeam-backup-02.png)

 

In the **Name** section, give your backup job a `Name` and `Description`.

Then, click the `Next` button.

![Veeam backup - Enterprise server Linux - step 3](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/veeam-backup-03.png)

 

In the **Computers** section, click the `Add...` button.

![Veeam backup - Enterprise server Linux - step 4](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/veeam-backup-04.png)

 

In the **Add Computer** pop-up, enter the `Host name or IP address` of the server.

Click the `Add...` button, select `Stored`, and then `Linux account...`.

![Veeam backup - Enterprise server Linux - step 5](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/veeam-backup-05.png)

 

Enter the `Username` and `Password`. Select the **Elevate account privileges automatically** box `☑` and then click `OK`.

![Veeam backup - Enterprise server Linux - step 6](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/veeam-backup-06.png)

 

In the **Backup Mode** section, select the backup mode for this job.

Then, click the `Next` button.

![Veeam backup - Enterprise server Linux - step 7](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/veeam-backup-07.png)

 

In the **Storage** section, choose the `Backup repository` and settings.

Then, click the `Next` button.

![Veeam backup - Enterprise server Linux - step 8](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/veeam-backup-08.png)

 

:::info

Click the `Next` button again to skip the **Guest Processing** section, as no configurations are needed.

:::

 

In the **Schedule** section, you can click "Run the job automatically" if you would like to configure the backup job to be reoccurring. For this article, we will be executing the backup manually so we will click the `Apply` button to proceed.

![Veeam backup - Enterprise server Linux - step 9](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/veeam-backup-09.png)

 

Review the **Summary** section to ensure that everything is correct.

:::warning

**NOTE:** To run the job as soon as you finish setup, select the `Run the job when I click Finish` checkbox.

:::

![Veeam backup - Enterprise server Linux - step 10](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/veeam-backup-10.png)

 

Click the `Finish` button to conclude setting up the backup job. This will open a new window where you can view the details of the backup being performed.

![Veeam backup - Enterprise server Linux - step 11](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/veeam-backup-11.png)

 

:::tip

**SUCCESS!** Once the job is complete, you will have created your backup.

:::
