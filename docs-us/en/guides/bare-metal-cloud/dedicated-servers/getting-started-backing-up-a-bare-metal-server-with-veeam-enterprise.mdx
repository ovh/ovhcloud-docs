# Getting Started - Backing Up a Bare Metal Server with Veeam Enterprise

**Learn how to prepare to back up your Bare Metal Server using Veeam Backup and Replication (Enterprise).**

 

## Requirements

- a [Bare Metal server](https://us.ovhcloud.com/bare-metal/prices/)
- a [Veeam Enterprise Backup solution](https://us.ovhcloud.com/storage-solutions/veeam-enterprise/)
- OVHcloud Standard [Object Storage](https://us.ovhcloud.com/public-cloud/object-storage/) (optional)

 

## Introduction

Backing up a Bare Metal server with Veeam Enterprise involves several applications and services to work together. The process may also change based on your configuration and preferences. Steps 1 through 3 below are meant to give you a bird's eye view of the process and provide you with links to the guides necessary for your unique backup experience.

 

### Step 1: Setting up hardware and software

The [instructions below](#instructions) will cover the purchase and setup for:

- a Dedicated Server
- Veeam Enterprise
- Object Storage (optional for use as a repository)

 

### Step 2: Back up

Back up your environment using the Linux or Windows (as appropriate) guide below:

- For Linux: [Backing Up a Bare Metal Linux Server with Veeam Enterprise](https://support.us.ovhcloud.com/hc/en-us/articles/24060566548755)
- For Windows: [Backing Up a Bare Metal Server Using Veeam Agent for Windows](https://support.us.ovhcloud.com/hc/en-us/articles/27017288196755)

 

### Step 3: Restore (optional)

To restore a Bare Metal Server or an individual file, follow the process in our [Restoring a Bare Metal Server with Veeam Enterprise](https://support.us.ovhcloud.com/hc/en-us/articles/24101748660371) guide.

### Setting up your Object Storage

:::warning

**NOTE:** If you do not already have a [Public Cloud project](https://support.us.ovhcloud.com/hc/en-us/articles/360002245784), you will need to create one before continuing.

:::

You can view and purchase the OVHcloud Object Storage options on [our website](https://us.ovhcloud.com/public-cloud/object-storage/) or through the OVHcloud Control Panel by following the steps below.

1. Select `Public Cloud` from the top navigation bar.
2. Under **Storage** select `Object Storage`.
3. Click `Create an object container`.

![DS\_backupwithVeeam02.5\*\*\*.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24027830280723.png)

:::warning

**NOTE:** When ordering an Object Storage container from OVHcloud, only order Standard Object Storage or the High Performance Object Storage. These containers support the Amazon S3® \* protocol fully and are designed for use as backup repositories.

:::

[Create an object container](https://support.us.ovhcloud.com/hc/en-us/articles/10695902938899) using one of OVHcloud's Object Storage solutions (Standard or High Performance). Standard is recommended since this backup usually does not require High Performance storage.

Give the Object Storage user rights to the container by copying and pasting the text below into a JSON file.

```
{
  "Statement":[
    {
      "Action":
         [
             "s3:GetObject",
             "s3:PutObject",
             "s3:DeleteObject",
             "s3:ListBucket",
             "s3:ListMultipartUploadParts",
             "s3:ListBucketMultipartUploads",
             "s3:AbortMultipartUpload",
             "s3:GetBucketLocation"
          ],
      "Effect":"Allow",
      "Resource":
          [
              "arn:aws:s3:::<container name>",
              "arn:aws:s3::: :::<container name>/*"
          ],
      "Sid":"RWContainer"
     }
  ]
}
```

From the OVHcloud Control Panel, select `Public Cloud` and then `Object Storage` under the **Storage** section. Click the `Object Storage users` tab and then the *more options* `...` button to the right of the Object Storage user and choose `Import Policy (JSON)`.

Select the JSON file you just edited and click `Import`.

![DS\_GS\_backupwithVeeam03\*\* copy.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/27363585573395.png)

 

### Configuring the Object Storage repository in Veeam Enterprise

From the Veeam application, select `Backup Infrastructure`, `Backup Repositories`, and `Add Repository`.

![DS\_backupwithVeeam04\*\*.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025178987795.png)

 

Select `Object storage` as the repository type.

![DS\_backupwithVeeam05.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025164512403.png)

 

Select `S3 Compatible`.

![DS\_backupwithVeeam06.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025164519059.png)

 

Give the new repository a **Name** and click `Next`.

![DS\_backupwithVeeam07\*.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025179011603.png)

 

Enter the **Service point (Endpoint)** and **Region** information for your Object Storage service.

:::info

You can find this information in the OVHcloud Control Panel by clicking the *more options* `...` button in the row of the container and then `Display objects`.

![DS\_backupwithVeeam07.5.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24027820191507.png)

![DS\_backupwithVeeam08.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025179019667.png)

:::

 

![DS\_backupwithVeeam09\*.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025179032595.png)

 

Click `Add` to enter your credentials. Enter your **Access key** and **Secret key** and then click `OK`.

:::info

This information is available in the OVHcloud Control Panel under the **Object Storage Users** tab. The Access key is visible on the main page. The Secret key can be found by clicking the *more options* `...` button and selecting `View the secret key`.

![DS\_backupwithVeeam10.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025297817747.png)

:::

![DS\_backupwithVeeam11.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025253228435.png)

 

Click `Browse...` to select the **Bucket**.

![DS\_backupwithVeeam12.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025663705491.png)

 

Select the bucket and click `OK`.

![DS\_backupwithVeeam13.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025633944083.png)

 

Click `Browse...` to select the **Folder**.

![DS\_backupwithVeeam14.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025633951635.png)

 

Click `New Folder`, enter a name for the folder, select it, and then click `OK`.

![DS\_backupwithVeeam15.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24025806136595.png)

 

On the Mount Server screen, click `Next`.

![DS\_backupwithVeeam16.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24026494494355.png)

 

On the Review screen, click `Apply`.

![DS\_backupwithVeeam17.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24026466163475.png)

 

After the processes run successfully, click `Next`.

![DS\_backupwithVeeam18.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24026466184467.png)

 

Review the Summary page and click `Finish`.

![DS\_backupwithVeeam19.png](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-a-bare-metal-server-with-veeam-enterprise/24026494561811.png)

 

The Backup Repositories should now look similar to this:

**SUCCESS!** From here, you can continue to [Step 2 (at the top of this guide)](#step-2) to begin your backup.
