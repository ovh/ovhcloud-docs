# Restoring a Bare Metal Server with Veeam Enterprise

**Learn how to restore a Bare Metal Server using Veeam Backup & Replication (Enterprise).**

If you are unable to restore data from a backup, it serves no purpose. After reading this article, you should have a clear process for restoring a Bare Metal Server or an individual file using Veeam Backup & Replication.

 

## Requirements

- [Veeam Backup & Replication installed and registered](https://support.us.ovhcloud.com/hc/en-us/articles/360002270130)
- [Backing Up a Bare Metal Server with Veeam Enterprise](https://support.us.ovhcloud.com/hc/en-us/articles/24060566548755)

 

## Instructions

There are several options for restoring data on a server. In this guide, we will be showing you "Guest files restore."

In the Veeam Backup & Replication application, from the **Home** tab, click `Restore` and select the `Agent...` option.

![DS\_restore\_Veeam01.png](/images/bare-metal-cloud/dedicated-servers/restoring-a-bare-metal-server-with-veeam-enterprise/24104642277907.png)

 

In the pop-up window, select `Guest files restore`.

![DS\_restore\_Veeam02.png](/images/bare-metal-cloud/dedicated-servers/restoring-a-bare-metal-server-with-veeam-enterprise/24104620448019.png)

 

`Choose` the operating system of the machine from which you are restoring.

![DS\_restore\_Veeam03.png](/images/bare-metal-cloud/dedicated-servers/restoring-a-bare-metal-server-with-veeam-enterprise/24104620456979.png)

 

Select the **Machine** that has the files you wish to restore. Click the `Next` button.

![DS\_restore\_Veeam04.png](/images/bare-metal-cloud/dedicated-servers/restoring-a-bare-metal-server-with-veeam-enterprise/24104642312467.png)

 

Choose the **Restore Point** from which to restore the files. Click the `Next` button.

![DS\_restore\_Veeam05.png](/images/bare-metal-cloud/dedicated-servers/restoring-a-bare-metal-server-with-veeam-enterprise/24107284910483.png)

 

Enter the **Restore** reason. Click the `Next` button.

![DS\_restore\_Veeam06.png](/images/bare-metal-cloud/dedicated-servers/restoring-a-bare-metal-server-with-veeam-enterprise/24107284920979.png)

 

At the Summary section, click the `Browse` button.

![DS\_restore\_Veeam07.png](/images/bare-metal-cloud/dedicated-servers/restoring-a-bare-metal-server-with-veeam-enterprise/24107272617875.png)

 

Navigate through the browser and choose the file or files that you wish to restore. Once you have selected a file(s), right-click on one of them, hover your mouse over `Restore`, and select `Keep`.

![DS\_restore\_Veeam08.png](/images/bare-metal-cloud/dedicated-servers/restoring-a-bare-metal-server-with-veeam-enterprise/24107284940691.png)

 

A pop-up window will appear that displays the progress of the restore. Once the progress is complete, the file has been restored and you can close the "Backup Browser" window.

![DS\_restore\_Veeam09.png](/images/bare-metal-cloud/dedicated-servers/restoring-a-bare-metal-server-with-veeam-enterprise/24107272635027.png)
