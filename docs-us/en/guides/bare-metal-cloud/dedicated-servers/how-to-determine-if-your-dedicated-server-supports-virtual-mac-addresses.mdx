# How to determine if your dedicated server supports virtual MAC addresses

**Learn how to check in the OVHcloud API if your dedicated server supports the virtual MAC feature.**

In order to use virtual MAC (vMAC) addresses on a dedicated server, you first need to make sure your server supports this feature.

Support for the vMAC function is a prerequisite for all actions concerning virtual MACs.

 

## Requirements

- a [dedicated server](https://us.ovhcloud.com/bare-metal/) in your OVHcloud account
- access to the OVHcloud [API](https://api.us.ovhcloud.com/)

:::info

If you are not familiar with using the OVHcloud API, please refer to our guide on [getting started with the OVHcloud API](https://support.us.ovhcloud.com/hc/en-us/articles/360018130839).

:::

 

## Instructions

Open the following API endpoint in the API console:

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/specifications/network"} regions={["us"]} />

Enter the internal server name into the `serviceName` field, then clic `Execute`.

![DS\_ntwk\_supportvMAC01-c.png](/images/bare-metal-cloud/dedicated-servers/how-to-determine-if-your-dedicated-server-supports-virtual-mac-addresses/36401039524115.png)

The result will show a "vmac / supported" entry which can be "true" or "false" (boolean value).

![supportvMAC02-b.png](/images/bare-metal-cloud/dedicated-servers/how-to-determine-if-your-dedicated-server-supports-virtual-mac-addresses/36401002618387.png)

> **Interpretation of the result**
>
> - **false**: You cannot use the virtual MAC feature on this server.
>
> - **true**: You can use the virtual MAC feature on this server.
