# Restoring a Bare Metal Server with Veeam Enterprise

**Learn how to restore a Bare Metal Server using Veeam Backup & Replication (Enterprise).**

If you are unable to restore data from a backup, it serves no purpose. After reading this article, you should have a clear process for restoring a Bare Metal Server or an individual file using Veeam Backup & Replication.

 

## Requirements

- [Veeam Backup & Replication installed and registered](/guides/hosted-private-cloud/vmware/veeam-veeam-backup-replication)
- [Backing Up a Bare Metal Server with Veeam Enterprise](/guides/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux)

 

## Instructions

There are several options for restoring data on a server. In this guide, we will be showing you "Guest files restore."

In the Veeam Backup & Replication application, from the **Home** tab, click `Restore` and select the `Agent...` option.

![Restore Veeam - Enterprise server - step 1](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-restore/restore-veeam-01.png)

 

In the pop-up window, select `Guest files restore`.

![Restore Veeam - Enterprise server - step 2](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-restore/restore-veeam-02.png)

 

`Choose` the operating system of the machine from which you are restoring.

![Restore Veeam - Enterprise server - step 3](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-restore/restore-veeam-03.png)

 

Select the **Machine** that has the files you wish to restore. Click the `Next` button.

![Restore Veeam - Enterprise server - step 4](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-restore/restore-veeam-04.png)

 

Choose the **Restore Point** from which to restore the files. Click the `Next` button.

![Restore Veeam - Enterprise server - step 5](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-restore/restore-veeam-05.png)

 

Enter the **Restore** reason. Click the `Next` button.

![Restore Veeam - Enterprise server - step 6](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-restore/restore-veeam-06.png)

 

At the Summary section, click the `Browse` button.

![Restore Veeam - Enterprise server - step 7](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-restore/restore-veeam-07.png)

 

Navigate through the browser and choose the file or files that you wish to restore. Once you have selected a file(s), right-click on one of them, hover your mouse over `Restore`, and select `Keep`.

![Restore Veeam - Enterprise server - step 8](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-restore/restore-veeam-08.png)

 

A pop-up window will appear that displays the progress of the restore. Once the progress is complete, the file has been restored and you can close the "Backup Browser" window.

![Restore Veeam - Enterprise server - step 9](/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-restore/restore-veeam-09.png)
