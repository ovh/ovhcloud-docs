# How to store public authentication keys in the OVHcloud Control Panel

**Learn how to store your public authentication keys in the OVHcloud Control Panel.**

Key pairs are used to authenticate SSH connections between hosts, for example a desktop client and a remote server. When reinstalling a dedicated server or a VPS from the OVHcloud Control Panel, you have the option to add a public key to the operating system. Storing public keys in your Control Panel makes this process more convenient.

 

## Requirements

- A [dedicated server](https://us.ovhcloud.com/bare-metal/) or a [VPS](https://us.ovhcloud.com/vps/) in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)

:::info

For information about using authentication keys with [Public Cloud](https://us.ovhcloud.com/public-cloud/) services, refer to our dedicated guide:

[How to create SSH keys with OpenSSH for Public Cloud instances](/guides/public-cloud/compute/creating-ssh-keys)

:::

 

## Instructions

If you have not created a key pair yet, consult our [How to create and use keys for SSH authentication](/guides/bare-metal-cloud/dedicated-servers/create-use-authentication-keys-ssh-connections-ovhcloud-server) guide.

Log in to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), click on the account `name` at the top right and then click on your `initials`.

![Store SSH - Import keys control panel - step 1](/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/store-ssh-01.png)

In the left-hand menu, select `My solutions & services`.

Click the `Add an SSH key` button and select `Dedicated` from the menu.

![Store SSH - Import keys control panel - step 2](/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/store-ssh-02.png)

In the pop-up window, enter a name for the key in the first field.\
Copy the entire public key string and paste it into the second field.

Click `Confirm`.

![Store SSH - Import keys control panel - step 3](/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/store-ssh-03.png)

The key will now be available when you reinstall a dedicated server or a VPS in the OVHcloud Control Panel.

Consult our "Getting started" guides for further details on this topic:

- [Dedicated server](/guides/bare-metal-cloud/dedicated-servers/getting-started-dedicated-server-windows-linux)
- [Dedicated server of the Eco product line](/guides/bare-metal-cloud/dedicated-servers/getting-started-with-dedicated-server-eco)
- [VPS](/guides/bare-metal-cloud/vps/starting-with-a-vps)

You can manage your keys from this area by clicking the *more options* `...` button to the right of the key.

![Store SSH - Import keys control panel - step 4](/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/store-ssh-04.png)
