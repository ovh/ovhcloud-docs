# How to configure OVHcloud Link Aggregation in Windows Server 2019

OVHcloud Link Aggregation (OLA) technology is designed by our teams to increase your server’s availability and boost the efficiency of your network connections. In just a few clicks, you can aggregate your network cards and make your network links redundant. This means that if one link goes down, traffic is automatically redirected to another available link.

 

## Requirements

- [Configuring OVHcloud Link Aggregation in the OVHcloud Control Panel](/guides/bare-metal-cloud/dedicated-servers/ola-enable-manager)
- Access to the [OVHcloud Control Panel](https://manager.us.ovhcloud.com/)

 

## Instructions

Because you have a private-private configuration for your NICs in OLA, you will be unable to SSH into the server. Thus, you will need to leverage the IPMI tool to access the server.

To do so, first log in to your [OVHcloud Control Panel](https://manager.us.ovhcloud.com/). In the `Bare Metal Cloud` section, select your server from `Dedicated Servers` and click the `IPMI` tab.

Next, click the `From a Java applet (KVM)` button.

![Dedicated IPMI - Configure OVHcloud link aggregation Windows server 2019](/images/bare-metal-cloud/dedicated-servers/configure-ovhcloud-link-aggregation-windows-server-2019/dedicated-ipmi.png)

A JNLP program will download. Open the program once it is finished to enter the IPMI. Log in using valid credentials for the server.

Once you are in the server, open Server Manager. If it is not already open by default, you will see it pinned to the `Start` menu.

![Manager - Configure OVHcloud link aggregation Windows server 2019](/images/bare-metal-cloud/dedicated-servers/configure-ovhcloud-link-aggregation-windows-server-2019/manager.png)

Once you have opened Server Manager, click the `Local Server` tab on the left-hand sidebar. Next, click the `Disabled` button next to **NIC Teaming**.

![Local server - Configure OVHcloud link aggregation Windows 2019](/images/bare-metal-cloud/dedicated-servers/configure-ovhcloud-link-aggregation-windows-server-2019/local-server.png)

In the NIC Teaming pop-up, click the `TASKS` button and select `New Team` from the dropdown menu.

![Nic teaming - Configure OVHcloud link aggregation Windows server 2019](/images/bare-metal-cloud/dedicated-servers/configure-ovhcloud-link-aggregation-windows-server-2019/nic-teaming.png)

Give your team a name and check the NICs you wish to use with OLA. Click the dropdown arrow `▼` next to **Additional properties** and change the **Teaming mode** to `LACP`. Click `OK` once you have confirmed that the information is correct.

![New team - Configure OVHcloud link aggregation Windows server 2019](/images/bare-metal-cloud/dedicated-servers/configure-ovhcloud-link-aggregation-windows-server-2019/new-team.png)

It could take a few minutes for the NIC team to come online. Once it is finished, click the network connection icon in the bottom-right corner. Next, click the `Network & Internet settings` button. Then click the `Ethernet` button on the left-hand sidebar of the following pop-up.

![Network button - Configure OVHcloud link aggregation Windows server 2019](/images/bare-metal-cloud/dedicated-servers/configure-ovhcloud-link-aggregation-windows-server-2019/network-button.png)

Click the `Change adapter options` button. 

![Ethernet - Configure OVHcloud link aggregation Windows server 2019](/images/bare-metal-cloud/dedicated-servers/configure-ovhcloud-link-aggregation-windows-server-2019/ethernet.png)

Next, right-click on your NIC team and select `Properties` from the drop-down menu.

![Properties - Configure OVHcloud link aggregation Windows server 2019](/images/bare-metal-cloud/dedicated-servers/configure-ovhcloud-link-aggregation-windows-server-2019/properties.png)

On the following pop-up window, double-click the `Internet Protocol Version 4 (TCP/IPv4)` button.

![IPv - Configure OVHcloud link aggregation Windows server 2019 - step 4](/images/bare-metal-cloud/dedicated-servers/configure-ovhcloud-link-aggregation-windows-server-2019/ipv-4.png)

Choose `Use the following IP address` and add your chosen private IP and subnet. Click the `OK` button once you have confirmed that your settings are correct.

![IPv - Configure OVHcloud link aggregation Windows server 2019 - step 42](/images/bare-metal-cloud/dedicated-servers/configure-ovhcloud-link-aggregation-windows-server-2019/ipv-42.png)

To test that our NIC team is working, ping another server on the same vRack. If it works, you are all set. If it does not, double-check your configurations or try rebooting the server.
