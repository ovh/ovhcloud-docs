# Configure Your Windows Server for the BYOI API in QCOW2

**Learn how to set up your Windows virtual machine for compatibility with the BYOI API in QCOW2.**

BYOI stands for Bring Your Own Image this is a common method for customers to bring their own pre-configured cloud-init capable ISO provided in QCOW2 or raw format to the OVHcloud environment.

 

## Requirements

- virtual software capable of running a Windows server ([Virtual Box](https://www.virtualbox.org/wiki/Downloads), [VMware Workstation](https://www.vmware.com/content/vmware/vmware-published-sites/us/products/desktop-hypervisor.html.html.html), etc.)
- [qemu-img](https://www.qemu.org/download/) for Windows or Linux
- a [Bare Metal Server](https://us.ovhcloud.com/bare-metal/)
- [Cloudbase-Init Installer](https://cloudbase.it/cloudbase-init/)

 

## Instructions

### Set up your virtual environment

Mount your Windows Server installation via your virtualization software and configure the virtual hardware to fit your needs.

Once configured and booted, you can install Windows updates, configure SSH, etc.

 

### Create your image

Download [Cloudbase-Init](https://cloudbase.it/cloudbase-init/), open the setup wizard, and click `Next`.

### Convert your image

Once your VM has shut down, you can use qemu-img - a powerful and simple tool - to convert your image to QCOW2 format.

:::tip

Click each tab for your operating system.

:::

<Tabs>

<Tab label="Windows">

1. Download qemu-img using [this link](https://cloudbase.it/qemu-img-windows/).
2. Open PowerShell and navigate to the qemu-img.exe.
3. We recommend copying an extract of the qemu-img download contents to the directory of the source image.
   ```
   qemu-img -h
   ```

4) Convert your source image to dest.qcow2 using the command below, where `-O` is the output format.
   ```
   qemu-img.exe convert source.vmdk -O qcow2 dest.qcow2
   ```

</Tab>

<Tab label="Linux">

1. Download qemu-img using the following command:
   ```
   apt install qemu
   ```

2) We recommend copying an extract of the qemu-img download contents to the directory of the source image.
   ```
   qemu-img --help
   ```

3. Convert your source image to dest.qcow2 using the command below, where `-O` is the output format.
   ```
   qemu-img.exe convert source.vmdk -O qcow2 dest.qcow2
   ```

</Tab>

</Tabs>

After converting your image, you are now ready to self-host and use BYOI to install via the link. More information can be found in [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/360018521100).
