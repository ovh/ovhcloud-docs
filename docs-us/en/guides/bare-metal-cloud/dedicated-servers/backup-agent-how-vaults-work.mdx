# Backup Agent - How Vaults work

## Requirements

- A Backup Agent service, which can be ordered via the `Backup Agent` menu in your OVHcloud Control Panel.

#### OVHcloud Control Panel Access

- **Direct link:** [Backup Agent](https://manager.us.ovhcloud.com/#/bmc-backup-agent-baremetal/service)
- **Navigation path:** `Bare Metal Cloud` > `Storage and backups` > `Backup Agent`

 

## Instructions

### Vault Overview

A Vault is a storage space where your data is sent during each backup. OVHcloud automatically creates vaults based on our Object Storage buckets. You can learn more about our Object Storage options on the [OVHcloud website](https://us.ovhcloud.com/public-cloud/object-storage/).

To find your Vaults, click [this link](https://manager.us.ovhcloud.com/#/bmc-backup-agent-baremetal/vaults) to access the `Vaults` tab.

![backupAgent\_vaults.png](/images/bare-metal-cloud/dedicated-servers/backup-agent-how-vaults-work/53531376813715.png)

 

### Location Principle

:::warning

**NOTE:** Backup data is always sent to a Vault located in a different data center from the one where your Bare Metal server is located. This ensures the resilience and security of your data.

:::

#### Example 1: A Bare Metal server in VIN

If you have a Bare Metal server located in **Vint Hill (VIN)** and you order the Backup Agent:

- Your Bare Metal server with the Backup Agent installed is located in **VIN**.
- Your backup data is automatically sent to a Vault created in **Hillsboro (us-west-or)**, named **backup-vault-paygo-standard-us-west-or-1**.
- This ensures that your data is stored in a different data center from your server.

 

#### Example 2: Two Bare Metal servers in VIN and HIL

If you have two Bare Metal servers, one in **Vint Hill (VIN)** and the other in **Hillsboro (HIL)**:

- The Bare Metal server in **VIN** sends its data to **backup-vault-paygo-standard-us-west-or-1** in **Hillsboro**.
- The Bare Metal server in **HIL** sends its data to **backup-vault-paygo-standard-us-east-va-1** in **Vint Hill**.
- Each server uses a Vault in a different data center from its own.

 

### Important Points

- OVHcloud automatically creates vaults; you cannot create them manually.
- You cannot change the Vault for an agent once it is configured.
- The Vault location is always different from your Bare Metal server location to ensure resilience.
- The Vault name generally follows the convention: `backup-vault-paygo-standard-<location>-<number>`.
- The same Vault will be used when multiple Backup Agents have the same backup destination.
