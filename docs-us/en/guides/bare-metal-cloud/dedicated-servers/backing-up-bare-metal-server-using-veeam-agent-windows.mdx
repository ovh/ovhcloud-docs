# Backing Up a Bare Metal Server Using Veeam Agent for Windows

**Learn how to configure the Veeam Agent for Microsoft Windows to back up your Bare Metal server.**

 

## Requirements

- a [Dedicated Server](https://us.ovhcloud.com/bare-metal/)
- [Veeam Backup and Replication 12.0](https://www.veeam.com/download-version.html?ad=downloads\&tab=previous) installed
- Veeam Agent for Microsoft Windows 6.0.2 [installation software](https://login.veeam.com/realms/veeamsso/protocol/openid-connect/auth?client_id=veeam-com\&response_type=code\&redirect_uri=https%3A%2F%2Fwww.veeam.com%2Foauth\&scope=profile\&state=e9a55dcbf050f86c5eb69ea264b8fb86) (Veeam account required)

 

## Instructions

### Download and install Veeam Agent

Download [Veeam Agent for Microsoft Windows 6.0.2](https://login.veeam.com/realms/veeamsso/protocol/openid-connect/auth?client_id=veeam-com\&response_type=code\&redirect_uri=https%3A%2F%2Fwww.veeam.com%2Foauth\&scope=profile\&state=e9a55dcbf050f86c5eb69ea264b8fb86) on the target server for your backup.

Install the Veeam Agent and select `No` when prompted to install a license file.

![License - Backing up bare metal server using Veeam agent Windows](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/01-license.png)

 

Click the *menu* `☰` button and select `+ Add New Job...`.

![Add job](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/01-c-add-job.png)

 

### Backup configuration

#### Name

Modify the default **Name** and/or **Description**, if you want to, and click `Next`.

![Name copy](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/02-name-copy.png)

 

#### Backup Mode

Choose what data you want to back up and click `Next`.

![Backup mode](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/02-backup-mode.png)

 

#### Destination

Choose `Veeam backup repository` and click `Next`.

![Choose - Backing up bare metal server using Veeam agent Windows](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/03-choose.png)

 

#### Backup server

Enter the **Veeam backup server name or IP address** and **Specify your personal credentials** (from a valid [Veeam Enterprise service account](/guides/hosted-private-cloud/vmware/veeam-veeam-backup-replication#creating-a-veeam-enterprise-service-account)).

Click `Next`.

It will take a moment for your license to load.

![Backup - Backing up bare metal server using Veeam agent Windows](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/04-backup.png)

 

#### Backup repository

Select your **Backup repository** and, if desired, modify the retention policy.

Click `Next`.

![Backup - step 3](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/04-backup-s3.png)

 

:::warning

**NOTE:** If you do not see *Standard S3* as an option for your backup repository, use the steps below to check the access permissions.\
\
From the Veeam Enterprise application interface, select `Backup Repositories`, `right-click` on your repository, and select `Access permissions...`.

![Backup with 02](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/backupwith-02-b.png)

In the `Standalone applications` tab, make sure one of the **Allow** options is selected for repository access. If you need to add your account or group, you can use the `Add...` button.\
If you made changes, select `OK` to apply them.

![Backup with 02](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/backupwith-02-c.png)

:::

 

#### Backup cache (optional)

If desired, you can enable the backup cache if the remote backup target is temporarily unavailable.

Click `Next`.

![Backup cache](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/06-backup-cache.png)

 

#### Guest processing (optional)

If you want, you can choose guest processing options.

Click `Next`.

![Guest - Backing up bare metal server using Veeam agent Windows](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/07-guest.png)

 

#### Schedule

Choose your backup schedule preferences and click `Apply`.

![Schedule - Backing up bare metal server using Veeam agent Windows](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/08-schedule.png)

 

#### Summary

Review your settings. If you want the backup job to run as soon as you finish, tick the checkbox `☑` at the bottom of the window.

Click `Finish`.

![Summary - Backing up bare metal server using Veeam agent Windows](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/09-summary.png)

 

### Start your backup

Click the *menu* `☰` button, select the job you just created, and click `Backup Now`.

![Start backup](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/10-start-backup.png)

 

You can view the progress of your backup in the Veeam Agent application:

![Backup - Backing up bare metal server using Veeam agent Windows](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/10-backup.png)

 

On the Veeam Backup and Recovery server, the backup job will appear:

![Vbr jobs](/images/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows/11-vbr-jobs.png)
