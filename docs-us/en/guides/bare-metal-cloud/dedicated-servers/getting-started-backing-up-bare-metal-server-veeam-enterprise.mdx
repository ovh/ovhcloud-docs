# Getting Started - Backing Up a Bare Metal Server with Veeam Enterprise

**Learn how to prepare to back up your Bare Metal Server using Veeam Backup and Replication (Enterprise).**

 

## Requirements

- a [Bare Metal server](https://us.ovhcloud.com/bare-metal/prices/)
- a [Veeam Enterprise Backup solution](https://us.ovhcloud.com/storage-solutions/veeam-enterprise/)
- OVHcloud Standard [Object Storage](https://us.ovhcloud.com/public-cloud/object-storage/) (optional)

 

## Introduction

Backing up a Bare Metal server with Veeam Enterprise involves several applications and services to work together. The process may also change based on your configuration and preferences. Steps 1 through 3 below are meant to give you a bird's eye view of the process and provide you with links to the guides necessary for your unique backup experience.

 

### Step 1: Setting up hardware and software

The [instructions below](#instructions) will cover the purchase and setup for:

- a Dedicated Server
- Veeam Enterprise
- Object Storage (optional for use as a repository)

 

### Step 2: Back up

Back up your environment using the Linux or Windows (as appropriate) guide below:

- For Linux: [Backing Up a Bare Metal Linux Server with Veeam Enterprise](/guides/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux)
- For Windows: [Backing Up a Bare Metal Server Using Veeam Agent for Windows](/guides/bare-metal-cloud/dedicated-servers/backing-up-bare-metal-server-using-veeam-agent-windows)

 

### Step 3: Restore (optional)

To restore a Bare Metal Server or an individual file, follow the process in our [Restoring a Bare Metal Server with Veeam Enterprise](/guides/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-restore) guide.

### Setting up your Object Storage

:::warning

**NOTE:** If you do not already have a [Public Cloud project](/guides/public-cloud/cross-functional/create-a-public-cloud-project), you will need to create one before continuing.

:::

You can view and purchase the OVHcloud Object Storage options on [our website](https://us.ovhcloud.com/public-cloud/object-storage/) or through the OVHcloud Control Panel by following the steps below.

1. Select `Public Cloud` from the top navigation bar.
2. Under **Storage** select `Object Storage`.
3. Click `Create an object container`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 2](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-2.png)

:::warning

**NOTE:** When ordering an Object Storage container from OVHcloud, only order Standard Object Storage or the High Performance Object Storage. These containers support the Amazon S3® \* protocol fully and are designed for use as backup repositories.

:::

[Create an object container](/guides/storage-and-backup/object-storage/getting-started) using one of OVHcloud's Object Storage solutions (Standard or High Performance). Standard is recommended since this backup usually does not require High Performance storage.

Give the Object Storage user rights to the container by copying and pasting the text below into a JSON file.

```
{
  "Statement":[
    {
      "Action":
         [
             "s3:GetObject",
             "s3:PutObject",
             "s3:DeleteObject",
             "s3:ListBucket",
             "s3:ListMultipartUploadParts",
             "s3:ListBucketMultipartUploads",
             "s3:AbortMultipartUpload",
             "s3:GetBucketLocation"
          ],
      "Effect":"Allow",
      "Resource":
          [
              "arn:aws:s3:::<container name>",
              "arn:aws:s3::: :::<container name>/*"
          ],
      "Sid":"RWContainer"
     }
  ]
}
```

From the OVHcloud Control Panel, select `Public Cloud` and then `Object Storage` under the **Storage** section. Click the `Object Storage users` tab and then the *more options* `...` button to the right of the Object Storage user and choose `Import Policy (JSON)`.

Select the JSON file you just edited and click `Import`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 3](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-3.png)

 

### Configuring the Object Storage repository in Veeam Enterprise

From the Veeam application, select `Backup Infrastructure`, `Backup Repositories`, and `Add Repository`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 4](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-4.png)

 

Select `Object storage` as the repository type.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 5](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-5.png)

 

Select `S3 Compatible`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 6](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-6.png)

 

Give the new repository a **Name** and click `Next`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 8](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-8.png)

 

Enter the **Service point (Endpoint)** and **Region** information for your Object Storage service.

:::info

You can find this information in the OVHcloud Control Panel by clicking the *more options* `...` button in the row of the container and then `Display objects`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 7](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-7.png)

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 12](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-12.png)

:::

 

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 13](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-13.png)

 

Click `Add` to enter your credentials. Enter your **Access key** and **Secret key** and then click `OK`.

:::info

This information is available in the OVHcloud Control Panel under the **Object Storage Users** tab. The Access key is visible on the main page. The Secret key can be found by clicking the *more options* `...` button and selecting `View the secret key`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 9](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-9.png)

:::

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 11](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-11.png)

 

Click `Browse...` to select the **Bucket**.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 15](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-15.png)

 

Select the bucket and click `OK`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 10](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-10.png)

 

Click `Browse...` to select the **Folder**.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 14](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-14.png)

 

Click `New Folder`, enter a name for the folder, select it, and then click `OK`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 16](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-16.png)

 

On the Mount Server screen, click `Next`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 20](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-20.png)

 

On the Review screen, click `Apply`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 17](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-17.png)

 

After the processes run successfully, click `Next`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 21](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-21.png)

 

Review the Summary page and click `Finish`.

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 19](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-19.png)

 

The Backup Repositories should now look similar to this:

![Backup with - Getting started backing up bare metal server Veeam enterprise - step 18](/images/bare-metal-cloud/dedicated-servers/getting-started-backing-up-bare-metal-server-veeam-enterprise/backupwith-18.png)
