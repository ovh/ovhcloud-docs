# SQL Server and Windows Server compatibility

:::warning

**NOTE:**

- Since September 2023, SQL2016 licenses are no longer available through OVHcloud. Customers with an existing SQL2016 license can still reinstall a server, since the *templates* are still available.
- SSMS 20.x is installed for all SQL versions.
- SQL Reporting Services are included for all SQL versions.
- SQL templates contain an up-to-date install of SQL Server. At first log on, SQL installation and configuration are required via an auto-launched script. The default user is `sa`.

:::

 

### Compatibility matrix

|                                    | SQL2016 (web/std) | SQL2016 (web/std) | SQL2019         | SQL2022 (web/std/ent) |
| ---------------------------------- | ----------------- | ----------------- | --------------- | --------------------- |
| **Windows Server 2016 (Standard)** | ✅\*               | ✅                 | ✅(web/std)      | ❌                     |
| **Windows Server 2019 (Standard)** | ✅\*               | ✅                 | ✅(web/std/ent)  | ✅                     |
| **Windows Server 2022 (Standard)** | ❌                 | ❌                 | ✅ (web/std/ent) | ✅                     |
| **Windows Server 2025 (Standard)** | ❌                 | ❌                 | ❌               | ✅                     |

**Legend:**

\* = The license cannot be ordered anymore, but the template is still available

✅ = There is a dedicated template available for this Windows/SQL combination

❌ = There is **no** dedicated template available for this Windows/SQL combination

**web** = SQL Server **Web** edition

**std** = SQL Server **Standard** edition

**ent** = SQL Server **Enterprise** edition
