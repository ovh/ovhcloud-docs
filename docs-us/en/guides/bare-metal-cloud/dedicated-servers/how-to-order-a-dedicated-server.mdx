# How to order a Dedicated Server

**Learn how to order a Dedicated Server through the OVHcloud Control Panel or the OVHcloud API.**

 

## Requirements

- An [OVHcloud account](https://support.us.ovhcloud.com/hc/en-us/articles/115001286870)
- A [default payment method](https://support.us.ovhcloud.com/hc/en-us/articles/115001824230) set on your account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) or [OVHcloud API](https://api.us.ovhcloud.com/)

:::info

To see our full range of Dedicated Server options, see our [pricing comparison page](https://us.ovhcloud.com/bare-metal/prices/).

:::

 

## Instructions

:::tip

✔ Select a method to create your server order.

:::

<Tabs>

<Tab label="Via the OVHcloud Control Panel">

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), select `Bare Metal Cloud`, `Dedicated servers`, and `Order a dedicated server`.

Alternatively, you can click the `+ Add a service` button.

![manager\_dedicated\_order.png](/images/bare-metal-cloud/dedicated-servers/how-to-order-a-dedicated-server/41452076862611.png)

 

You will be redirected to an order funnel where you will:

- choose your server
- configure your options
- select data centers and quantities
- your commitment duration
- review your order and click `Checkout →`
- confirm your address
- confirm your payment method
- review our Terms of Service

When you have made all of your selections and confirmed your information, click `Continue →`.

</Tab>

<Tab label="Via the OVHcloud API">

#### Create a cart

<Api version="v1" section="/order" method="POST" route={"/order/cart/"} regions={["us"]} />

You must specify `"US"` for the **ovhSubsidiary** parameter.

```
{
  "ovhSubsidiary": "US"
}
```

 

#### Assign the cart to your account

<Api version="v1" section="/order" method="POST" route={"/order/cart/\{cartId\}/assign"} regions={["us"]} />

 

#### Choose a plan

<Api version="v1" section="/order" method="GET" route={"/order/cart/\{cartId\}/baremetalServers"} regions={["us"]} />

Save your chosen **planCode**, **duration**, and **pricingMode** from the response.

Example:

```
"planCode": "24rise01-us"
"duration": "P1M"
"pricingMode": "default"
```

 

#### Add the server to your cart

<Api version="v1" section="/order" method="POST" route={"/order/cart/\{cartId\}/baremetalServers"} regions={["us"]} />

Save the **itemId** from the response.

Example:

```
"itemId": 12345678
```

 

#### Configure the server

<Api version="v1" section="/order" method="POST" route={"/order/cart/\{cartId\}/item/\{itemId\}/configuration"} regions={["us"]} />

You must specify a **data center**, an **operating system**, and a **region**. Each configuration will require a separate submission through the API.

Example:

```
{
  "label": "dedicated_datacenter",
  "value": "hil"
}
```

```
{
  "label": "dedicated_os",
  "value": "none_64.en"
}
```

```
{
  "label": "region",
  "value": "united_states"
}
```

 

#### Check available options for your server

<Api version="v1" section="/order" method="GET" route={"/order/cart/\{cartId\}/baremetalServers/options"} regions={["us"]} />

 

#### Apply options to your server

<Api version="v1" section="/order" method="POST" route={"/order/cart/\{cartId\}/baremetalServers/options"} regions={["us"]} />

 

#### Read the Terms of Service and verify your cart

<Api version="v1" section="/order" method="GET" route={"/order/cart/\{cartId\}/checkout"} regions={["us"]} />

 

#### Submit your order

<Api version="v1" section="/order" method="POST" route={"/order/cart/\{cartId\}/checkout"} regions={["us"]} />

Set the **autoPayWithPreferredPaymentMethod** parameter to `"true"` to use your default payment method.

```
{
  "autoPayWithPreferredPaymentMethod": true,
  "waiveRetractationPeriod": false
}
```

</Tab>

#### Create and configure your order

```
terraform {
  required_providers {
    ovh = {
      source  = "ovh/ovh"
      version = "~ 1.0"  # Specify the version you want to use
    }
  }
}
 
provider "ovh" {
  application_key    = "xxx"
  application_secret = "xxx"
  consumer_key       = "xxx"
  endpoint           = "ovh-us"
}
 
data "ovh_me" "account" {}
 
resource "ovh_dedicated_server" "server1" {
  ovh_subsidiary = data.ovh_me.account.ovh_subsidiary
  display_name = "TFE Made me a Server"
  os = "debian12_64"
  plan = [
    {
      plan_code = "24rise012-us"
      duration = "P1M"
      pricing_mode = "default"
 
      configuration = [
        {
          label = "dedicated_datacenter"
          value = "hil"
        },
        {
          label = "dedicated_os"
          value = "none_64.en"
        },
        {
          label = "region"
          value = "us"
        }
      ]
    }
  ]
}
 
resource "ovh_dedicated_server" "client1" {
  ovh_subsidiary = data.ovh_me.account.ovh_subsidiary
  display_name = "TFE Made me a Client"
  os = "debian12_64"
  plan = [
    {
      plan_code = "24rise012-us"
      duration = "P1M"
      pricing_mode = "default"
 
      configuration = [
        {
          label = "dedicated_datacenter"
          value = "hil"
        },
        {
          label = "dedicated_os"
          value = "none_64.en"
        },
        {
          label = "region"
          value = "us"
        }
      ]
    }
  ]
}
```
