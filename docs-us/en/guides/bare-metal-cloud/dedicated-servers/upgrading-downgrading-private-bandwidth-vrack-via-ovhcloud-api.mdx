# Upgrading and downgrading private bandwidth (vRack) via OVHcloud API

**Learn how to upgrade or downgrade the public vRack bandwidth for your OVHcloud Dedicated Server via the OVHcloud API.**

 

## Requirements

- access to [OVHcloud API](https://api.us.ovhcloud.com/) (to get started, use [this guide](/guides/manage-and-operate/api/first-steps))
- a [Dedicated Server](https://us.ovhcloud.com/bare-metal/)
- a [vRack](https://us.ovhcloud.com/network/vrack/) service activated on your account

 

## Instructions

### Find available services

Use the following API call to list all the available services for upgrade (or downgrade) and verify that the service you wish to upgrade/downgrade is listed:

<Api version="v1" section="/order/upgrade" method="GET" route={"/order/upgrade/baremetalPrivateBandwidth"} regions={["us"]} />

![General - Upgrading downgrading private bandwidth vRack via OVHcloud API](/images/bare-metal-cloud/dedicated-servers/upgrading-downgrading-private-bandwidth-vrack-via-ovhcloud-api/general.png)

 

### Find the plan code

List available offers and find the **planCode** of your choice with the API call below:

<Api version="v1" section="/order/upgrade" method="GET" route={"/order/upgrade/baremetalPrivateBandwidth/\{serviceName\}"} regions={["us"]} />

![General - Upgrading downgrading private bandwidth vRack via OVHcloud API - step 5](/images/bare-metal-cloud/dedicated-servers/upgrading-downgrading-private-bandwidth-vrack-via-ovhcloud-api/general-5.png)

 

### Review your order

Use the following API call for a preview of your order, including pricing:

<Api version="v1" section="/order/upgrade" method="GET" route={"/order/upgrade/baremetalPrivateBandwidth/\{serviceName\}/\{planCode\}"} regions={["us"]} />

![General - Upgrading downgrading private bandwidth vRack via OVHcloud API - step 2](/images/bare-metal-cloud/dedicated-servers/upgrading-downgrading-private-bandwidth-vrack-via-ovhcloud-api/general-2.png)

 

### Submit your order

To officially submit the order, use the following API call:

<Api version="v1" section="/order/upgrade" method="POST" route={"/order/upgrade/baremetalPrivateBandwidth/\{serviceName\}/\{planCode\}"} regions={["us"]} />

![General - Upgrading downgrading private bandwidth vRack via OVHcloud API - step 3](/images/bare-metal-cloud/dedicated-servers/upgrading-downgrading-private-bandwidth-vrack-via-ovhcloud-api/general-3.png)

 

### Verify

Use the API call below to retrieve the network information of your Dedicated Server:

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/specifications/network"} regions={["us"]} />

![General - Upgrading downgrading private bandwidth vRack via OVHcloud API - step 4](/images/bare-metal-cloud/dedicated-servers/upgrading-downgrading-private-bandwidth-vrack-via-ovhcloud-api/general-4.png)
