# How to use the IPMI console with a dedicated server

**Learn how to access your dedicated server directly through the IPMI (Intelligent Platform Management Interface) console without depending on the operating system connectivity state.**

 

## Requirements

- access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)

:::warning

**NOTE:** This feature might be unavailable or limited on servers of the [Eco product line](https://eco.us.ovhcloud.com/about-us/). Please visit our [comparison page](https://eco.us.ovhcloud.com/compare/) for more information.

:::

## Instructions

### Access the IPMI console

You can access the IPMI using several different methods1. SSH keys stored on the server will not be used for these connections. Here is a summary:

| Method Name                  | Short Name         | Description                                                                                                                                                                                                        | Copy-Paste | Virtual ISO reader² | Use Case Example                                                                                                                                                        |
| ---------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **KVM**³ via **web browser** | **HTML KVM**       | Redirection of the video screen to an **HTML canvas**, exactly as if you were physically connecting a keyboard/mouse via USB and a screen via VGA to your dedicated server.                                        | ❌          | ⚠️⁴                 | - Troubleshoot a boot issue on your dedicated server.                                                                                                                   |
| **KVM**³ via **Java applet** | **Java KVM**       | Same as HTML KVM, except that it uses **Java applet** rather than HTML canvas.                                                                                                                                     | ❌          | ✅                   | - Troubleshoot a boot issue on your dedicated server. - Perform a manual installation of a specific OS (not in the [catalog](https://us.ovhcloud.com/bare-metal/os/))⁵. |
| **SoL**⁶ via **web browser** | **JavaScript SoL** | Redirection of a serial connection to the web browser, exactly as if you were physically connecting a serial console via RS-232 to your dedicated server.                                                          | ✅          | ❌                   | - Troubleshoot a network issue: get system logs and manipulate configuration files.                                                                                     |
| **SoL**⁶ via **SSH**         | **SSH SoL**        | Same as JavaScript SoL, except redirection is done to an SSH gateway. You then connect via your preferred SSH client to a remote SSH server that converts SSH commands to serial commands to the dedicated server. | ✅          | ❌                   | - Same as JavaScript SoL but from a machine without any graphical interface.                                                                                            |

1 Depending on your dedicated server hardware compatibility (some methods will not be shown in the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)).\
2 Feature that enables the user to mount an ISO image stored locally on your machine to your remote dedicated server so you can install an OS via IPMI.\
3 KVM = Keyboard Video and Mouse\
4 Depending on your dedicated server hardware compatibility: use Java KVM instead if not compatible.\
5 If the OS you want to install is not in the list of [operating systems available with OVHcloud Bare Metal servers](https://us.ovhcloud.com/bare-metal/os/), please note that you can also use a custom image: See [Bring Your Own Image (BYOI) / Bring Your Own Linux (BYOLinux), a comparison sheet](/guides/bare-metal-cloud/dedicated-servers/bring-your-own-image-versus-bring-your-own-linux) for more details.\
⁶ SoL = Serial over Lan

To enable one of these methods, log in to your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/). In the `Bare Metal Cloud` section, select your server from `Dedicated Servers` and click on the `IPMI/KVM` tab.

![IPMI - Use console - step 1](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-01.png)

:::tip

Click the tab for your method of choice.

:::

### Test and reboot the IPMI

Your IPMI may stop responding. If you cannot access it, you can test it first by clicking on `Test the IPMI`, and checking the results of the diagnostic.

![IPMI - Use console - step 12](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-12.png)

If everything appears to be normal, you may be experiencing a local technical issue (internet connection, local desktop). If the IPMI encounters any issues, you can reboot it by clicking `Reboot the IPMI`.

![IPMI - Use console - step 13](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-13.png)

It will take several minutes for the IPMI to reboot.

:::info

This operation will not affect the applications, data, and services running on your dedicated server.

:::

 

### Installing an OS

:::tip

Click each tab across the top to view all content.

:::

<Tabs>

<Tab label="Using IPMI v1">

:::warning

OVHcloud does not guarantee the functionality of any operating systems installed via IPMI. This route should only be taken by an experienced server administrator.

64-bit versions of Java can prevent the `Redirect ISO`/`Redirect CDROM` menus from opening and cause JViewer to crash.

:::

To begin, open [IPMI in a Java applet](#access-the-ipmi-console) from the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/). Then, click `Device` from the menu bar and select `Redirect ISO` from the drop-down menu.

![IPMI - Use console - step 14](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-14.jpg)

Next, select the ISO you wish to use from your local computer's file system. Once you have selected your ISO, press the `Ctrl Alt Del` button in the top-right corner of the screen to reboot the server. Press the appropriate `F` key to access the boot options.

:::info

You may need to use the soft keyboard for inputs to register in IPMI. To access this, click the `Keyboard` option from the menu bar at the top of the window. Then, select `Soft Keyboard` from the dropdown menu and click `Show`.

:::

Select the **UEFI Virtual CDROM 1.00** option from the boot menu to start the server from the ISO attached previously.

![IPMI - Use console - step 15](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-15.jpg)

Complete the steps required to install the operating system. Do not forget to remove the ISO from the "Redirect ISO" option.

</Tab>

<Tab label="Using IPMI v2">

:::warning

OVHcloud does not guarantee the functionality of any operating systems installed via IPMI. This route should only be taken by an experienced server administrator.

:::

To begin, open [IPMI in a Java applet](#access-the-ipmi-console) from the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/). Then, click `Virtual Media` and select `Virtual Storage`.

![IPMI - Use console - step 16](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-16.png)

From the new screen, select `ISO File` from the "Logical Drive Type" drop-down menu. Next, click `Open Image` and navigate to your ISO file. Finally, click `Plug-in` and `OK` to finish.

![IPMI - Use console - step 17](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-17.png)

To be able to boot from our ISO file, we need to access the BIOS and switch our boot options. To do so, select `Power Control` and click `Set Power Reset`.

![IPMI - Use console - step 18](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-18.png)

:::info

You may need to use the soft keyboard for inputs to register in IPMI. To access this, click the `Virtual Media` option from the menu bar at the top of the window. Then, select `Virtual Keyboard` from the drop-down menu.

:::

During the bootup process, press the `DEL` key when prompted to access the BIOS. You may also press the `F11` key and navigate to the BIOS by selecting the option `Enter Setup`.

![IPMI - Use console - step 19](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-19.png)

In the BIOS navigate to the `Boot` tab and change the **UEFI Boot Order #1** to `UEFI USB CD/DVD:UEFI: CDROM virtual ATEN YSOJ`.

![IPMI - Use console - step 20](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-20.png)

Lastly, press the `F4` key to save your changes and restart the server.

</Tab>

<Tab label="Using web browser KVM(latest servers only)">

:::warning

OVHcloud does not guarantee the functionality of any operating systems installed via IPMI. This route should only be taken by an experienced server administrator.

:::

In the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), open the [KVM web browser console](#access-the-ipmi-console).

Here you have access to the same information and functionalities as in the Java-based IPMI modules.

:::info

Be sure to execute the next steps at a good pace. The process might be cancelled if there are longer pauses between actions.

:::

Click on the `Browse File` button and select your image file.

![IPMI - Use console - step 21](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-21.png)

Click on `Start Media`. This will prepare the ISO for the installation process.

![IPMI - Use console - step 22](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-22.png)

The file size displayed is not the actual size. This is normal, since the file is not fully uploaded in this step.

![IPMI - Use console - step 23](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-23.png)

Click on `Power` and select `Reset Server` from the drop-down menu.

![IPMI - Use console - step 24](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-24.png)

Wait for the boot selection screen to appear and press the appropriate key to enter the boot menu (`F11` in this example).

![IPMI - Use console - step 25](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-25.png)

In the boot menu, select the optical drive (`UEFI: AMI Virtual CDROM0` in this example) and press `Enter`.

![IPMI - Use console - step 26](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-26.png)

The ISO file will now be uploaded, then the server will boot from the file.

![IPMI - Use console - step 27](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-27.png)

</Tab>

</Tabs>

 

### Rebooting a server into the BIOS menu

You might want to access the BIOS when configuring or troubleshooting your server. A convenient way to achieve this is by using the tool `ipmiutil` (refer to the [project page](https://ipmiutil.sourceforge.net/) for more information).

When the server is in [rescue mode](/guides/bare-metal-cloud/dedicated-servers/rescue-mode) and you have logged in, install it with the following commands:

```bash
apt install ipmiutil
```

Then reboot the server with this command:

```bash
ipmiutil reset -b
```

Afterwards, access the [IPMI console](#access-the-ipmi-console) in your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/). You should see the server's BIOS menu displayed.

![IPMI - Use console - step 28](/images/bare-metal-cloud/dedicated-servers/use-ipmi-console/ipmi-28.png)
