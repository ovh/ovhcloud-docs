# How to activate and use Windows rescue mode

**Learn how to boot a server into the Windows customer rescue system.**

Rescue mode is a tool provided by OVHcloud that allows you to boot into a temporary operating system to diagnose and resolve issues on your server.\
The functionality of rescue mode in general is described on our [How to activate and use rescue mode](https://support.us.ovhcloud.com/hc/en-us/articles/115001754490) guide.

The **Windows customer rescue system** option is only available for dedicated servers that have a **Windows Server** operating system installed. The following conditions apply:

- The rescue system for Windows (`rescue-customer-windows`) runs in a virtual machine (VM) launched from the customer rescue system (`rescue-customer`, based on Debian GNU/Linux).
- The server disks are attached to the VM with *passthrough*, so it is possible to access them.
- Other server components will not be accessible (CPU, RAM, network card, RAID card).
- The network is mounted with *passthrough* but without direct access to the network card. The VM carries the IP address and the MAC address of the *bare metal* server.

:::warning

**NOTE:** Backing up your data should be the first step in rescue mode if you do not already have recent backups available.

If you have any services still online, rescue mode will interrupt them as the machine is being rebooted into the auxiliary rescue environment.

:::

 

## Requirements

- Microsoft Windows installed on your [dedicated server](https://us.ovhcloud.com/bare-metal/)
- At least 16 GB of RAM installed on the server
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)

 

## Instructions

### Activating rescue mode for Windows

Log in to your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), open the `Bare Metal Cloud` section, and then `Dedicated servers`.

Click on your server's name to open the `General information` tab.

In the **General information** box, click the *more options* `...` button next to `Boot`. Click on `Edit` in the context menu.

![dedicated\_general\_boot\_edit.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744853951123.png)

On the page **Change the netboot**, select `Boot in rescue mode`.

Select `Windows customer rescue system` in the drop-down menu.

![dedicated\_rescueMode\_windows\_start.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744853953555.png)

The rescue mode notification email, including its login details, will be sent to the contact email address of your OVHcloud account. To use a different email address, enter it in the field `Send new login details to the following email address`.

Click `Next`.

In the **Summary** step, click `Confirm`.

![dedicated\_rescueMode\_windows\_submit.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744878953491.png)

You should now have a notification regarding the `Netboot` setting in the `General information` tab.

![dedicated\_netboot\_banner.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744853961363.png)

The final step is to restart the server. Click the button `...` next to "Status" in the **Service status** box, then click `Restart`. Click `Confirm` in the pop-up window.

![dedicated\_serviceStatus\_moreOptions.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744853962259.png)

This "hard reboot" will take a few minutes to complete. You can check the current status in the tab named `Tasks`.

:::info

After you have finished your actions in rescue mode, remember to change the `Netboot` setting back to `Boot from the hard disk` before restarting the server.

:::

 

### Accessing your server in rescue mode

Once you have received the email informing you that rescue mode is enabled, you can log on to the Windows rescue mode system and access your server.

To establish a remote session to the Windows rescue mode system, you will need these credentials:

- IP address of the server
- Username of the temporary admin account (`Administrator`)
- Password for the temporary admin account

You can use the following connection methods to access your server via the Windows rescue mode system:

- Remote Desktop Protocol (RDP)
- KVM over IP (if your server allows it)
- OpenSSH (official Windows Server component)

<details>
<summary>RDP</summary>

To connect, use the `Remote Desktop Connection` client of Windows or any compatible application.

![windows\_rdp\_connect.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744853964563.png)

</details>

<details>
<summary>KVM</summary>

From the KVM login screen, you can select a different keyboard language.

![KVM\_windows\_login.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744853965971.png)

![KVM\_windows\_language.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744853966995.png)

You can change the accessibility options and enable the virtual keyboard:

![KVM\_windows\_accessibilityOptions-1.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744878967955.png)

![KVM\_windows\_accessibilityOptions-2.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744878968851.png)

You can find further information in our guide: [How to use the IPMI console with a dedicated server](https://support.us.ovhcloud.com/hc/en-us/articles/360007816120)

</details>

<details>
<summary>SSH</summary>

Open the command line application on your local device and enter the following command:

```bash
ssh Administrator@SERVER_IP
```

Example:

```bash
ssh Administrator@203.0.113.100
```

Enter the temporary rescue mode password when prompted. Example:

```console
Administrator@ns9356771.ip-203-0-113.eu's password:
administrator@WINRESCUEOVH C:\Users\Administrator>
```

Find more information on SSH connections in our [SSH introduction guide](https://support.us.ovhcloud.com/hc/en-us/articles/360000416484).\
You can also use any SSH connection tool, such as [PuTTY](https://support.us.ovhcloud.com/hc/en-us/articles/41209176606227).

</details>

 

### Importing disks to access your files

Once logged in to the Windows customer rescue system, you need to import (mount) the Windows server's disks before you can access the file system.

<details>
<summary>Expand for instructions</summary>

:::warning

**NOTE:** The following exemplary instructions and screenshots will illustrate the mounting process based on a server with two mirrored disks (RAID1). The details displayed by the Disk Management tool depend on your server's disk configuration.\
For additional information, consult the [official Microsoft documentation](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/overview-of-disk-management).

If you require professional assistance with server administration, consider the details in the [Go further](#go-further) section of this guide.

:::

Right-click on the `Start Menu` button and open `Disk Management`.

![windows\_start\_diskManagement.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744878975379.png)

`Disk 0` contains the rescue system (volume `C:`). The disks of your Windows server will be displayed as `Offline`.

![windows\_rescue\_disks.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744878977427.png)

Right-click on each disk and select `Online` from the context menu.

![windows\_rescue\_diskOnline.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744853982099.png)

The server disks are now [recognized by the rescue system as Foreign](https://learn.microsoft.com/en-us/troubleshoot/windows-server/backup-and-storage/troubleshoot-disk-management#a-dynamic-disks-status-is-foreign), a status indicating, in this case, that the attached disks belong to a different operating system.

![windows\_rescue\_disks\_foreign.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744853982867.png)

Right-click on a disk and select `Import Foreign Disks...` from the context menu.

![windows\_rescue\_importForeignDisks-1.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744853984019.png)

If applicable, select the disks to import. Click `OK`.

![windows\_rescue\_importForeignDisks-2.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744878984851.png)

Click `OK`.

![windows\_rescue\_importForeignDisks-3.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744853987987.png)

In this example, the two disks of the server are mirrored; therefore, the status `Resynching` will be displayed. This is the normal process; the resynchronization will continue once the server is rebooted into its installed OS.

![windows\_rescue\_disks\_resyncing.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744878988947.png)

To access your files, right-click on the Windows partition of your `Disk 1` and select `Open` from the context menu.

![windows\_rescue\_openDisk.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744878991251.png)

</details>

### Exiting rescue mode

In the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), [change the boot mode](#activating-rescue-mode-for-windows) back to `Boot from the hard disk` and confirm.

![dedicated\_rescueMode.png](/images/bare-metal-cloud/dedicated-servers/how-to-activate-and-use-windows-rescue-mode/43744878992403.png)

Then use the `Restart` function in your OVHcloud Control Panel.
