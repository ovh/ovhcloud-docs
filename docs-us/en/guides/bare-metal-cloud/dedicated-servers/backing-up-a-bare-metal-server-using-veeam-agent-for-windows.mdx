# Backing Up a Bare Metal Server Using Veeam Agent for Windows

**Learn how to configure the Veeam Agent for Microsoft Windows to back up your Bare Metal server.**

 

## Requirements

- a [Dedicated Server](https://us.ovhcloud.com/bare-metal/)
- [Veeam Backup and Replication 12.0](https://www.veeam.com/download-version.html?ad=downloads\&tab=previous) installed
- Veeam Agent for Microsoft Windows 6.0.2 [installation software](https://login.veeam.com/realms/veeamsso/protocol/openid-connect/auth?client_id=veeam-com\&response_type=code\&redirect_uri=https%3A%2F%2Fwww.veeam.com%2Foauth\&scope=profile\&state=e9a55dcbf050f86c5eb69ea264b8fb86) (Veeam account required)

 

## Instructions

### Download and install Veeam Agent

Download [Veeam Agent for Microsoft Windows 6.0.2](https://login.veeam.com/realms/veeamsso/protocol/openid-connect/auth?client_id=veeam-com\&response_type=code\&redirect_uri=https%3A%2F%2Fwww.veeam.com%2Foauth\&scope=profile\&state=e9a55dcbf050f86c5eb69ea264b8fb86) on the target server for your backup.

Install the Veeam Agent and select `No` when prompted to install a license file.

![01a - License-Choose No.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27022603982227.png)

 

Click the *menu* `☰` button and select `+ Add New Job...`.

![01c - Add Job\*.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27028654951955.png)

 

### Backup configuration

#### Name

Modify the default **Name** and/or **Description**, if you want to, and click `Next`.

![02 - Name copy.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27058435031187.png)

 

#### Backup Mode

Choose what data you want to back up and click `Next`.

![02a - Backup Mode copy.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27058276892563.png)

 

#### Destination

Choose `Veeam backup repository` and click `Next`.

![03 - Choose Destination.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27028659659027.png)

 

#### Backup server

Enter the **Veeam backup server name or IP address** and **Specify your personal credentials** (from a valid [Veeam Enterprise service account](https://support.us.ovhcloud.com/hc/en-us/articles/360002270130#creating-a-veeam-enterprise-service-account)).

Click `Next`.

It will take a moment for your license to load.

![04 - Backup Server - Credentials are key.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27028659671571.png)

 

#### Backup repository

Select your **Backup repository** and, if desired, modify the retention policy.

Click `Next`.

![04 - Agent Backup to S3\*.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27272973513491.png)

 

:::warning

**NOTE:** If you do not see *Standard S3* as an option for your backup repository, use the steps below to check the access permissions.\
\
From the Veeam Enterprise application interface, select `Backup Repositories`, `right-click` on your repository, and select `Access permissions...`.

![DS\_GS\_backupwithVeeam02b.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27544711009683.png)

In the `Standalone applications` tab, make sure one of the **Allow** options is selected for repository access. If you need to add your account or group, you can use the `Add...` button.\
If you made changes, select `OK` to apply them.

![DS\_GS\_backupwithVeeam02c.png](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27544694445203.png)

:::

 

#### Backup cache (optional)

If desired, you can enable the backup cache if the remote backup target is temporarily unavailable.

Click `Next`.

![06 - Backup Cache - OPTIONAL.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27028655061395.png)

 

#### Guest processing (optional)

If you want, you can choose guest processing options.

Click `Next`.

![07 - Guest Processing - None Selected.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27058292656275.png)

 

#### Schedule

Choose your backup schedule preferences and click `Apply`.

![08 - Schedule.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27028659744403.png)

 

#### Summary

Review your settings. If you want the backup job to run as soon as you finish, tick the checkbox `☑` at the bottom of the window.

Click `Finish`.

![09 - Summary.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27058276919699.png)

 

### Start your backup

Click the *menu* `☰` button, select the job you just created, and click `Backup Now`.

![10 - Start Backup.png](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27028659784979.png)

 

You can view the progress of your backup in the Veeam Agent application:

![10a - Backup Processing.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27028659821203.png)

 

On the Veeam Backup and Recovery server, the backup job will appear:

![11 - VBR Jobs.PNG](/images/bare-metal-cloud/dedicated-servers/backing-up-a-bare-metal-server-using-veeam-agent-for-windows/27028659847571.png)
