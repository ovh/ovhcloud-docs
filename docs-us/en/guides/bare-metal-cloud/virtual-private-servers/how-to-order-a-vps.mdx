# How to order a VPS

**Learn how to order a VPS through the OVHcloud Control Panel or the OVHcloud API.**

 

## Requirements

- An [OVHcloud account](https://support.us.ovhcloud.com/hc/en-us/articles/115001286870)
- A [default payment method](https://support.us.ovhcloud.com/hc/en-us/articles/115001824230) set on your account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) or [OVHcloud API](https://api.us.ovhcloud.com/)

:::info

To see our full range of VPS options, see our [pricing comparison page](https://us.ovhcloud.com/vps/compare/).

:::

 

## Instructions

:::tip

✔ Select a method to create your VPS order.

:::

<Tabs>

<Tab label="Via the OVHcloud Control Panel">

From the OVHcloud Control Panel, select `Bare Metal Cloud`, `Order`, and `VPS`.

![VPS\_GS\_ordering01\*.png](/images/bare-metal-cloud/virtual-private-servers/how-to-order-a-vps/39505563239699.png)

 

You will be redirected to an order funnel where you will:

- configure your VPS
- choose an image
- select data centers and quantities
- choose whether to add on features, such as snapshot backup or additional storage
- select your renewal frequency
- review your order
- confirm your address
- confirm your payment method
- review our Terms of Service

When you have made all of your selections and confirmed your information, click `Continue →`.

</Tab>

<Tab label="Via the OVHcloud API">

#### Create a cart

<Api version="v1" section="/order" method="POST" route={"/order/cart"} regions={["us"]} />

You must specify `"US"` for the **ovhSubsidiary** parameter.

```
{
  "ovhSubsidiary": "US"
}
```

 

#### Assign the cart to your account

<Api version="v1" section="/order" method="POST" route={"/order/cart/\{cartId\}/assign"} regions={["us"]} />

 

#### Choose a plan

<Api version="v1" section="/order" method="GET" route={"/order/cart/\{cartId\}/vps"} regions={["us"]} />

Save your chosen **planCode**, **duration**, and **pricingMode** from the response.

Example:

```
"planCode": "vps-starter-1-2-20"
"duration": "P1M"
"pricingMode": "default"
```

 

#### Add the VPS to your cart

<Api version="v1" section="/order" method="POST" route={"/order/cart/\{cartId\}/vps"} regions={["us"]} />

Save the **itemId** from the response.

Example:

```
"itemId": 12345678
```

 

#### Configure the VPS

<Api version="v1" section="/order" method="POST" route={"/order/cart/\{cartId\}/item/\{itemId\}/configuration"} regions={["us"]} />

You must specify a data center and operating system. Each configuration will require a separate submission through the API.

Example:

```
{
  "label": "vps_datacenter",
  "value": "US-EAST-VA"
}
```

```
{
  "label": "vps_os",
  "value": "Ubuntu 24.04"
}
```

#### Read the Terms of Service and verify your cart

<Api version="v1" section="/order" method="GET" route={"/order/cart/\{cartId\}/checkout"} regions={["us"]} />

 

#### Submit your order

<Api version="v1" section="/order" method="POST" route={"/order/cart/\{cartId\}/checkout"} regions={["us"]} />

Set the **autoPayWithPreferredPaymentMethod** parameter to `"true"` to use your default payment method.

```
{
  "autoPayWithPreferredPaymentMethod": true,
  "waiveRetractationPeriod": false
}
```
