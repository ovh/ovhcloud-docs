# Shelve or pause an instance

As part of the configuration of a high-availability infrastructure, you may need to cut access to your instances to perform different tests. OpenStack allows you to [suspend](#suspend-shelve-an-instance), [turn off](#turn-off-suspend-an-instance), or [pause](#pause-an-instance) your instance. In each case, your IP is maintained.

:::warning

**NOTE:** The naming of these options in the OVHcloud Control Panel is different from the naming in OpenStack/Horizon. If you are doing this via the OVHcloud Control Panel, make sure you select the correct option.

:::

 

## Requirements

- An [OVHcloud Public Cloud instance](https://support.us.ovhcloud.com/hc/en-us/articles/360002245164) on **hourly** billing
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) or [Horizon interface](https://support.us.ovhcloud.com/hc/en-us/articles/360008644539)
- Knowledge of [OpenStack API](https://support.us.ovhcloud.com/hc/en-us/articles/1500009262762) and [OpenStack variables](https://support.us.ovhcloud.com/hc/en-us/articles/16319212049555)

 

## Instructions

**Scope:** This guide applies to all Public Cloud instances, regardless of their billing model (hourly or monthly).

**Monthly billing:** An instance that remains shelved for the entire month will not be billed. As soon as the instance is unshelved, even briefly, the full month's billing applies.

**NOTE:** You will be billed for an instance as long as it is not deleted.

The table below allows you to differentiate the options available on your instances. Continue reading this guide by clicking on the option of your choice. **The terminology used in the Horizon interface is in parentheses.**

|                                                     |                                                                                                                                       |                                       |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| **Term**                                            | **Description**                                                                                                                       | **Billing**                           |
| [Suspend (shelve)](#suspend-shelve-an-instance)     | Retains the resources and data on your disk by creating a snapshot; all other resources are released. The main IP is also maintained. | You are only billed for the snapshot. |
| [Turn off (suspend)](#turn-off-suspend-an-instance) | Stores the VM state on disk; the resources remain reserved.                                                                           | You are billed at the same rate.      |
| [Pause](#pause-an-instance)                         | Stores the VM state in RAM; the instance remains frozen.                                                                              | You are billed at the same rate.      |

 

Content Overview

### Suspend (shelve) an instance

**WARNING:** Suspending a T2-180 instance will result in the loss of data on the NVMe passthrough drives.

Suspending this type of instance leads to its decommissioning from the host and, therefore, from the disks in passthrough.

This option releases the resources dedicated to your Public Cloud instance, but the IP address will remain. The data on your local disk will be stored in a snapshot automatically created once the instance is shelved. Data stored in the memory and elsewhere will not be retained.

<Tabs>

<Tab label="OVHcloud Control Panel">

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), navigate to the `Public Cloud` section, select your project, and click on `Instances` in the left side menu.

Click on the *more options* `⋮` button to the right of the instance you want to suspend, then click on `Suspend`.

![PCI\_instances\_moreOptions.png](/images/public-cloud/compute/shelve-or-pause-an-instance/46547556372755.png)

In the pop-up window, take note of the message and click on `Confirm`.

![PCI\_instances\_confirmSuspension.PNG](/images/public-cloud/compute/shelve-or-pause-an-instance/46547566856979.png)

Once the process is completed, your instance will now appear as *Suspended*.

![PCI\_instance\_suspended.png](/images/public-cloud/compute/shelve-or-pause-an-instance/46547556379155.png)

To view the snapshot, go to the left side menu and click on `Instance Backup`. A snapshot named *xxxxx-shelved* will now be visible:

![PCI\_instanceBackup\_shelvedInstance.png](/images/public-cloud/compute/shelve-or-pause-an-instance/46547556380435.png)

</Tab>

<Tab label="Horizon">

To proceed, you need to [log in to the Horizon interface](https://horizon.cloud.ovh.us/auth/login/).

- To log in with OVHcloud Single Sign-On: Use the `Horizon` link in the left-hand menu under **Management Interfaces** after opening your Public Cloud project in the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/).
- To log in with a specific OpenStack user: open the [Horizon login page](https://horizon.cloud.ovh.us/auth/login/) and enter the [OpenStack user credentials](https://support.us.ovhcloud.com/hc/en-us/articles/360008644539) previously created, then click on `Connect`.

If you have deployed instances in different regions, make sure you are in the correct region. You can verify this on the top left corner in the Horizon interface.

Click on the `Compute` menu on the left side and select `Instances`. Select `Shelve Instance` in the drop list for the corresponding instance.

![PCI\_compute\_suspendStopPause06\*.png](/images/public-cloud/compute/shelve-or-pause-an-instance/38543783585683.png)

Once the process is completed, your instance will now appear as *Shelved Offloaded*.

![PCI\_compute\_suspendStopPause07\*.png](/images/public-cloud/compute/shelve-or-pause-an-instance/38543783589523.png)

To view the snapshot, in the `Compute` menu, click on `Images`.

![PCI\_compute\_suspendStopPause08\*.png](/images/public-cloud/compute/shelve-or-pause-an-instance/38543783592723.png)

</Tab>

<Tab label="OpenStack API">

Before proceeding, it is recommended that you consult these guides:

- [Prepare the environment to use the OpenStack API](https://support.us.ovhcloud.com/hc/en-us/articles/1500009262762)
- [Set OpenStack environment variables](https://support.us.ovhcloud.com/hc/en-us/articles/16319212049555)

Once your environment is ready, type the following at the command line:

```bash
openstack server shelve <UUID server>

```

### Reactivate (unshelve) an instance

This option will allow you to re-up your instance so that you can continue using it. Please note that once this is done, the regular billing will resume.

**WARNING:** Any actions on the snapshot other than *unshelve* can be very dangerous for your infrastructure in case of misuse. Once you *unshelve* an instance, the snapshot is automatically deleted. It is not recommended to deploy a new instance from any snapshot created as a result of shelving (suspending) an instance.

<Tabs>

<Tab label="OVHcloud Control Panel">

In the OVHcloud Control Panel, select your project from the `Public Cloud` section and click on `Instances` in the left side menu.

Click on the *more options* `⋮` button to the right of the instance, then click on `Reactivate`.

![PCI\_instance\_reactivate.png](/images/public-cloud/compute/shelve-or-pause-an-instance/46547566860563.png)

In the pop-up window, take note of the message and click on `Confirm`.

Once the process is completed, your instance will now appear as *Enabled*.

</Tab>

<Tab label="Horizon">

In the Horizon interface, click on the `Compute` menu on the left and then select `Instances`. Select `Unshelve Instance` in the drop list for the corresponding instance.

Once the process is completed, your instance will now appear as *Active*.

![PCI\_compute\_suspendStopPause09\*.png](/images/public-cloud/compute/shelve-or-pause-an-instance/38543794693267.png)

</Tab>

<Tab label="OpenStack API">

Once your environment is ready, type the following at the command line:

```bash
openstack server unshelve <UUID server>

=========================================

nova unshelve <UUID server>
```

</Tab>

</Tabs>

 

### Turn off (suspend) an instance

This option shuts down your instance and stores the VM state on disk, including memory.

<Tabs>

<Tab label="OVHcloud Control Panel">

In the OVHcloud Control Panel, select your project from the `Public Cloud` section and click on `Instances` in the left side menu.

Click on the *more options* `⋮` button to the right of the instance you want to stop, then click on `Turn off`.

![PCI\_instances\_moreOptions.png](/images/public-cloud/compute/shelve-or-pause-an-instance/46547556372755.png)

In the pop-up window, take note of the message and click on `Confirm`.

Once the process is completed, your instance will now appear as *Off*.

To **resume** the instance, perform the same steps as mentioned above. Click on the *more options* `...` button to the right of the instance and select `Start`. In some cases, you might need to do a cold reboot.

![PCI\_instances\_start-reboot.png](/images/public-cloud/compute/shelve-or-pause-an-instance/46547566863123.png)

</Tab>

<Tab label="Horizon">

In the Horizon interface, click on the `Compute` menu on the left and then select `Instances`. Select `Suspend Instance` in the drop list for the corresponding instance.

![PCI\_compute\_suspendStopPause13\*.png](/images/public-cloud/compute/shelve-or-pause-an-instance/38543783601939.png)

The confirmation message will appear, indicating that the instance has been suspended.

To **resume** the instance, perform the same steps as mentioned above. In the drop list for the corresponding instance, select `Resume Instance`.

</Tab>

<Tab label="OpenStack API">

Once your environment is ready, type the following at the command line:

```bash
openstack server suspend <UUID server>

=========================================

nova suspend <UUID server>
```

To **resume** the instance, type the following at the command line:

```bash
openstack server unsuspend <UUID server>

=========================================

nova unsuspend <UUID server>
```

</Tab>

</Tabs>

 

### Pause an instance

This action is **only** possible in the Horizon interface or via the OpenStack/Nova API. It allows you to *freeze* your instance.

<Tabs>

<Tab label="Horizon">

In the Horizon interface, click on the `Compute` menu on the left and then select `Instances`. Select `Pause Instance` in the drop list for the corresponding instance.

![PCI\_compute\_suspendStopPause14\*.png](/images/public-cloud/compute/shelve-or-pause-an-instance/38543794698259.png)

The confirmation message will appear, indicating that the instance has been paused.

To **unpause** the instance, perform the same steps as mentioned above. In the drop list for the corresponding instance, select `Resume Instance`.

</Tab>

<Tab label="OpenStack API">

Once your environment is ready, type the following at the command line:

```bash
openstack server pause <UUID server>

=========================================

nova pause <UUID server>
```

To **unpause** the instance, type the following at the command line:

```bash
openstack server unpause <UUID server>

=========================================

nova unpause <UUID server>
```

</Tab>

</Tabs>
