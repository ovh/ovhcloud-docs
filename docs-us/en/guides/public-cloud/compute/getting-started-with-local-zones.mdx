# Getting started with Local Zones

**Learn how to create your first instance in a Local Zone.**

 

## Introduction

Local Zones are an extension of Regions that bring OVHcloud services closer to specific locations, offering reduced latency and improved performance for applications. Local Zones are strategically placed in proximity to areas with high user demand. Their goals are to:

- minimize the time it takes to transfer data between the user and the cloud,
- make services faster and more responsive, and
- meet Data residency requirements.

Find more information on our [dedicated Local Zone Compute page](https://us.ovhcloud.com/public-cloud/local-zone-compute/).

### Capabilities and limitations

Support for unavailable features, like Volume Snapshots or Object Storage, will be released in the next few months. Our goal is to support the entire feature set that is currently supported in global regions.

 

## Requirements

- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- A [Public Cloud project](https://support.us.ovhcloud.com/hc/en-us/articles/360002245784)

 

## Instructions

### Create an instance

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), select your `Public Cloud` project and click `Instances` in the left-hand menu under **Compute**.

Click `+ Create an instance`.

![manager\_createInstance.png](/images/public-cloud/compute/getting-started-with-local-zones/41161789914259.png)

 

### Select a model

Choose an instance model that has the `Local Zone` label and click `Next`.

![manager\_selectInstanceModel.png](/images/public-cloud/compute/getting-started-with-local-zones/41161789921299.png)

 

### Location

(Optional) Select a deployment zone: You can choose to only filter for `1-AZ` regions or `Local Zone` locations.

![manager\_selectInstanceDeploymentZone.png](/images/public-cloud/compute/getting-started-with-local-zones/41161789922067.png)

If you select a Local Zone that has not been activated on your account, clicking `Next` will activate it for you.

![manager\_localZones\_regions.png](/images/public-cloud/compute/getting-started-with-local-zones/41796720559507.png)

 

### Select an image

Select an image, add an SSH key, and click `Next`.

![manager\_selectInstanceImage.png](/images/public-cloud/compute/getting-started-with-local-zones/41161789925267.png)

 

### Configure your instance

![manager\_selectInstanceConfiguration.png](/images/public-cloud/compute/getting-started-with-local-zones/41161789927827.png)

 

### Configure your network

:::warning

**NOTE:** If you want to connect to the **Public network**, you need to check `☑` the box.

:::

![manager\_selectInstanceNetwork\_public.png](/images/public-cloud/compute/getting-started-with-local-zones/41161789928339.png)

<details>
<summary>If you want to connect to a Private network (click here)</summary>

Select `Local Private Network compatible with Local Zone` and then `Create a local private network`.

Give your private network a name.

**WARNING:** If you choose to disable DHCP, you **MUST ALSO** untick the box for "Declare the first address of a CIDR given as the default gateway (DHCP option 3)." Otherwise, instances created with this private network attached will not be accessible on their public IP.

Click `Next` to proceed.

![manager\_selectInstanceNetwork\_private.png](/images/public-cloud/compute/getting-started-with-local-zones/41161789929747.png)

</details>

 

### Select a billing period

An Hourly billing period will automatically be selected. Click `Create an instance` to complete your order.

![manager\_instanceOrder\_finalize.png](/images/public-cloud/compute/getting-started-with-local-zones/41161789931155.png)
