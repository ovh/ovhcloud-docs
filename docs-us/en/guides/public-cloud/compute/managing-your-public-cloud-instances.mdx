# Managing your Public Cloud instances

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- A [Public Cloud instance](https://support.us.ovhcloud.com/hc/en-us/articles/360002245164) in your project

### OVHcloud Control Panel Access

- **Direct link:** [Public Cloud Projects](https://manager.us.ovhcloud.com/#/public-cloud/pci/projects/)
- **Navigation path:** `Public Cloud` > Select your project

 

## Instructions

### Using the management interface for instances

Select `Instances` in the left-hand menu:

This page lists all your Public Cloud instances and some of their properties:

- The instance ID, needed for certain API calls
- The location of the datacenter, i.e., the region of the instance
- The instance model
- The image, i.e., the OS installed on the instance
- The IPv4 address of the instance
- Additional volumes (disks) currently attached to the instance
- The status of the instance

 

### Management options on the instance dashboard

From the instance management page, click the name of the instance.

This will take you to the `General information` tab, which centralizes the main details and operating status of your instance.

Some of these operations are also accessible from the instance management page via the *more options* `⋮` button in the row of the instance you want to modify.

 

#### Editing the configuration of the instance

Click `Edit image →`, or open `Additional actions` and then select `Edit`.

The new page displays a modified version of the [instance creation options](https://support.us.ovhcloud.com/hc/en-us/articles/360002245164), where you can edit the following items:

- **Instance name**: You can give a name to the instance for easier identification.
- **Image**: You can choose a different operating system for the instance. (Note that reinstalling an instance will delete all data stored on it.)
- **Template**: You can switch to a different instance model. Please refer to [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/360002245164) for more information about the options.
- **Changing the billing type**: You can change the billing period of the instance from hourly to monthly. Please refer to [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/22143514040083) for detailed information.

 

#### Creating a backup of the instance

Click on `Create a backup →`.

Refer to our guide on [backing up an instance](https://support.us.ovhcloud.com/hc/en-us/articles/4460743125395) for more information.

 

#### Deleting an instance

Click on `Delete`.

This will permanently delete the instance, as well as all of the data stored on it.

Confirm the request in the pop-up window.

:::warning

**NOTE:** Deleting an instance does not automatically delete all the options associated with it (storage, snapshot, backup, etc.), so make sure that all other options associated with the instance are also deleted to stop being billed.

:::

 

#### Attach a volume

Click on `Attach a volume →`.

Then select the volume to associate with the instance and click `Confirm`. Once attached, the volume is immediately available and can be mounted from the instance's operating system.

 

#### Change the reverse DNS

Click on the *more options* `⋮` in the **Public networks** section and choose `Change reverse DNS`.

 

#### Configure the firewall

Click on the *more options* `⋮` in the **Public networks** section and choose `Configure the firewall`.

Refer to our [Enabling and configuring the Edge Network Firewall](https://support.us.ovhcloud.com/hc/en-us/articles/115001729044) guide for more information.

 

#### Manage private networks

Click on the *more options* `⋮` in the **Private networks** section and choose `Manage private networks`.

Refer to our [Creating a private network with Gateway](https://support.us.ovhcloud.com/hc/en-us/articles/18534335915667) guide for more information.

 

#### Attach a network

Click on the *more options* `⋮` in the **Private networks** section and choose `Attach a network`.

Select the desired network from the drop-down list, then click `Confirm`.

 

#### Additional actions

Click on `Additional actions`.

 

**Creating an automatic backup of an instance**

Click on `Create and automatic backup`.

Refer to our [Backing up an instance](https://support.us.ovhcloud.com/hc/en-us/articles/4460743125395) guide for more information.

 

**Stop the instance**

Click on `Turn off`.

This will put the instance in the `Off` state, but you will still be charged the same price for your instance. Refer to our [Shelve or pause an instance](https://support.us.ovhcloud.com/hc/en-us/articles/16145141990163) guide for detailed information.

Click on `Start` to reactivate the instance.

 

**Using rescue mode**

Click on `Reboot in rescue mode`.

This will activate rescue mode for the instance. Refer to our guide on [putting an instance in rescue mode](https://support.us.ovhcloud.com/hc/en-us/articles/20041782509203) for detailed information.

 

**Restarting the instance**

**Shelving the instance**

Click on `Suspend`.

This will put the instance in the "shelved" state, here displayed as `Suspended`. Consult our [Shelve or pause an instance](https://support.us.ovhcloud.com/hc/en-us/articles/16145141990163) guide to learn more about the different states.

Click on `Reactivate` to restore the `Enabled` state.

 

**Reinstalling an instance**

Click on `Reinstall`.

This action will reinstall the instance with the same operating system, provided the image is still supported. **Please note that if you choose to reinstall, all of the data currently stored on your instance will be erased.**

Note that reinstalling **deletes all data** currently stored on your instance.

 

### Accessing the VNC console

Click on `Instances` in the left-hand menu. On the instance management page, click on the name of the instance in the table.

Switch from the `General information` tab to the `VNC console` tab.

:::warning

**NOTE:** If the VNC console does not appear, scroll to the bottom of the page and click `Open in a new window`.

:::

![PCI\_instances\_VNC-console-tab.png](/images/public-cloud/compute/managing-your-public-cloud-instances/45900444336659.png)

The VNC console provides direct access to your instance. For this access to work, configure a username and password on the instance first.

Consult our [getting started guide](https://support.us.ovhcloud.com/hc/en-us/articles/360002245164-How-to-Create-and-Connect-a-Public-Cloud-Instance#5.4-vnc-console-access) to learn more about the necessary steps.
