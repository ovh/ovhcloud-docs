# How to revert a flex instance

**Learn how to revert and resize your flex instance from the OpenStack Horizon interface.**

A flex instance is a single-size disk (50GB) instance that offers faster processing for snapshots. It allows resizing to higher or lower models with a fixed storage space, whereas classic models can only be resized to higher models.

As your infrastructure is constantly evolving, you may need to increase the storage space of your instance. In this case, you will need to « revert » your flex instance to a classic model. This action can only be done from the Horizon interface.

 

## Requirements

- An [OVHcloud Public Cloud instance](https://support.us.ovhcloud.com/hc/en-us/articles/360002245164) with the flex option
- [Access to the Horizon interface](https://support.us.ovhcloud.com/hc/en-us/articles/20719718436115)

 

## Instructions

:::warning

**NOTE:**

- If you switch from a flex instance to a classic instance with more resources, this is considered an upgrade. In this case, you will be billed for the difference. At the end of your billing period, you will receive two invoices.

- If you switch from a flex instance to a classic instance with fewer resources, this is a downgrade. In this case, you will not be billed.

- If you switch from a flex instance to a classic instance with the same resources, you will not be billed.

:::

Log in to the [Horizon interface](https://horizon.cloud.ovh.us/auth/login/) and make sure you are in the correct region. You can verify this in the top left corner.

![horizon\_selectRegion.png](/images/public-cloud/compute/how-to-revert-a-flex-instance/41199680392211.png)

Next, click on the `Compute` menu on the left side and click on `Instances`. Select `Resize Instance` in the drop-down list for the corresponding instance.

![horizon\_instances\_moreOptions.png](/images/public-cloud/compute/how-to-revert-a-flex-instance/41199695690131.png)

 

**Flavor Choice**

This section allows you to select the new instance template (flavor). You can either revert your instance to a classic model and maintain the same template or resize your instance by selecting a different template.

In our example, our flavor is `b3-8-flex`; we can either revert to a `b3-8` flavor or upgrade it to a `b3-16` flavor. In our case, we want to upgrade our instance to a `b3-16` classic model.

![horizon\_resizeInstance\_flavor\_flex.png](/images/public-cloud/compute/how-to-revert-a-flex-instance/41199695692947.png)

:::warning

**NOTE:**

- You can only switch from one Linux model to another Linux model or from one Windows model to another Windows model.

- The flex option is not available for all models.

:::

 

**Advanced Options**

Use this section to manage the **Disk Partition** and **Server Group**.

![horizon\_resizeInstance\_advanceOptions.png](/images/public-cloud/compute/how-to-revert-a-flex-instance/41199695695251.png)

To proceed, click on the `Resize` button.

Once the process is complete, your instance will be reverted to the selected model. In our case, our instance was reverted to a classic model with more storage space.

If you want to switch back to a flex model, you can do this by performing the same steps mentioned above and selecting a flex flavor instead of a classic one.

Alternatively, you can [edit the configuration of the instance](https://support.us.ovhcloud.com/hc/en-us/articles/4481009956243) in the OVHcloud Control Panel.
