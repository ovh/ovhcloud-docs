# Creating an Instance via the Horizon interface

**Learn how to create an Instance via the Horizon interface.**

You can create multiple Instances directly in the Horizon interface, and also configure a security group to apply to your Instances.

 

## Requirements

- A [Public Cloud project](https://support.us.ovhcloud.com/hc/en-us/articles/360002245784) in your OVHcloud account
- [Access to the Horizon interface](https://support.us.ovhcloud.com/hc/en-us/articles/20719718436115)

 

## Instructions

### Create a private network

As a general rule, we recommend creating a private network before creating an instance. You can later attach this network to your instance.

To begin, log in to the Horizon interface. If you are unsure about how to do this, please refer to [our guide](https://support.us.ovhcloud.com/hc/en-us/articles/20719718436115).

Next, click on `Network` in the left-hand menu, then `Networks`.

Click on `Create Network`.

![horizon\_networks\_dashboard.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178119777683.png)

<Tabs>

<Tab label="Network">

**Network Name:** Enter a name for your network.

**Enable Admin State:** Leave this option checked to activate the network.

**Create Subnet:** Leave this option checked to create the subnet.

**Availability Zone Hints:** Leave the default option.

![horizon\_network\_createNetwork\_network.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178119780115.png)

</Tab>

<Tab label="Subnet">

**Subnet Name:** Enter a name for your subnet.

**Network Address:** Choose a private network range. For example: `192.168.0.0/24`.

**IP Version:** Leave this value at IPv4.

**Gateway IP:** This is optional. If it is not defined, a Gateway IP is automatically selected.

**Disable Gateway:** Leave this unchecked.

![horizon\_network\_createNetwork\_subnet.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178119786643.png)

</Tab>

<Tab label="Subnet Details">

**Enable DHCP:** Leave this option checked.

**Allocation Pools:** Optional. You can specify the range from which IPs are selected.

**DNS Name Servers:** Optional. You can specify any DNS name servers.

**Host Routes:** Optional. You can specify any host routes.

![horizon\_network\_createNetwork\_subnetDetails.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178119790995.png)

</Tab>

</Tabs>

 

### Create Instance

In the Horizon interface, click on `Compute` in the left-hand menu, then `Instances`.

The page that opens can be used to view the Instances that are currently launched. To launch a new one, click the `Launch Instance` button.

![horizon\_instances\_dashboard.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178143140115.png)

You will then need to fill in the information requested. Please note that this list is not exhaustive.

 

#### Details

| Information       | Details                                                           |
| ----------------- | ----------------------------------------------------------------- |
| Instance name     | Specify the name you want for the Instance that will be launched. |
| Description       | This is Optional. Set a description if applicable.                |
| Availability zone | Leave "nova" (default choice).                                    |
| Count             | Specify the number of Instances to launch.                        |

![horizon\_launchInstance\_details.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178143141395.png)

 

#### Source

| Information                                            | Details                                                                                                                               |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| Select Boot Source                                     | Click on the drop-down arrow to select the source for launching an instance (e.g. "Image" or "Instance snapshot").                    |
| Create New Volume                                      | You may choose to check this option if you wish to create a volume into which the specified operating system image is copied.         |
| Volume size (GB)                                       | If you have chosen to create a volume, allow the system to determine the size for you.                                                |
| Delete Volume on Instance Delete                       | You can leave the default option **No**. If **Yes** is selected, when the instance is deleted, so is the volume.                      |
| Image name (only when launching from an image)         | Select the Instance image by clicking on the upward arrow next to the image of your choice. In our example, we use selected CentOS 7. |
| Instance snapshot (only for launching from a snapshot) | Choose an Instance snapshot by clicking on the upward arrow next to the instance snapshot image of your choice.                       |

![horizon\_instances\_launch\_source.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178119795987.png)

 

#### Flavor

Pre-built flavors are available for you. Select the flavor of your choice underneath the `Available` tab.

![horizon\_instances\_launch\_flavor.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178119799443.png)

 

#### Networks

| Information        | Details                                                                                        |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| Network            | Select the network(s) for the Instance you want to create from the list of available networks. |
| Ext-Net            | Represents the Public Network.                                                                 |
| All other networks | Represent the Private networks.                                                                |

:::warning

**NOTE:** If you want to attach a Private/vRack network to your instance it will fail unless you either:

- Use the OpenStack CLI to enable port security on the private network, which only needs to be done once, using the following command:
  ```
  openstack network set --enable-port-security <my_private_network_id>
  ```

* Remove the default security group from the [security groups area](#security-groups), which needs to be done for each instance created with a private network. This results in the default security group being applied to the public port but no the private port.

:::

![horizon\_instances\_launch\_network.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178143146387.png)

 

#### Security Groups

#### Key Pair

:::warning

**NOTE:** Although the "Key Pair" field is not mandatory in the Horizon interface when creating an instance, registering an SSH key is absolutely necessary to be able to connect to an instance. Without an SSH key, you will be required to reboot the instance in rescue mode to either create a password or add an SSH key to the appropriate file (for more information, please refer to the guide on [Replacing your lost SSH key pair](https://support.us.ovhcloud.com/hc/en-us/articles/20697029189523)).

:::

In this section, you have the option to (1) use an existing key pair, (2) create a key pair, or (3) import a key pair.

For more information on how to create an SSH key, consult [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/33773177952659).

![horizon\_instances\_launch\_keyPair\_annotated.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178119807379.png)

<Tabs>

<Tab label="Create Key Pair">

To create a key pair, click on the `+ Create Key Pair` button. Please note that with this option, additional steps have to be made before you can connect to the instance, especially if you are using the software PuTTY to connect to your instance. See the corresponding section of [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/33773177952659).

**Key Pair Name:** Enter a name for your key.

**Key Type:** Click on the `drop down arrow` and select `SSH Key`.

Next, click on `Create Keypair` to begin the creation of the key pair.

Once the Key Pair is created, click on `Copy Private Key to Clipboard`, then on `Done`.

![horizon\_instances\_launch\_keyPair\_createNew.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178143151635.png)

Once done, the newly created key will be automatically selected. Click on `Launch Instance` to begin the creation of your instance.

</Tab>

<Tab label="Import Key Pair">

If you prefer to import a previously created SSH key, click on the `Import Key Pair` button.

**Key Pair Name:** Enter a name for your key.

**Key Type:** Click on the `drop down arrow` and select `SSH Key`.

*Load Public Key from a file:* Click on `Browse` to specify the location of the public key on your computer.

**Public Key:** Copy and paste your public key here.

Click on `Import Key Pair` to import the key.

![horizon\_instances\_launch\_keyPair\_import.png](/images/public-cloud/compute/creating-an-instance-via-the-horizon-interface/41178143153683.png)

Once done, the imported key will be automatically selected. Click on `Launch Instance` to begin the creation of your instance.

</Tab>

</Tabs>

 

**Other options**

Please note that these options are not mandatory for the creation of a basic instance. If you wish to explore these options further, consult the [official OpenStack documentation](https://docs.openstack.org/horizon/latest/user/launch-instances.html).

| Information          | Details                                                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Custom script source | Specify the source between a "direct entry" or a "file".                                                                             |
| Script data          | Enter the script code in the input field (16KB maximum).                                                                             |
| Script file          | Click `Browse` to select the post-installation script.                                                                               |
| Disk partitioning    | Choose between "automatic" or "manual".                                                                                              |
| Configuration disk   | Configure OpenStack to write metadata on to a specific configuration disk that will be attached to the Instance when it is launched. |
