# Activate a Windows License for an Instance in Private Mode

**Learn how to configure the public interface for your Public Cloud instances within your vRack.**

Unlike Windows instances created in the public network, Windows instances created with private network mode (vRack) do not have their Windows licenses automatically enabled. In this case, you must activate the license manually to access all Windows services.

 

## Requirements

- a [Public Cloud project](https://support.us.ovhcloud.com/hc/en-us/articles/360002245784) in your OVHcloud account
- access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)
- an [OpenStack user account](https://support.us.ovhcloud.com/hc/en-us/articles/360008644539)

We recommend that you read our guide on [Accessing the Horizon](https://support.us.ovhcloud.com/hc/en-us/articles/20719718436115) interface to familiarize yourself with Horizon.

 

## Instructions

### Attach an "Ext-Net" public port to an instance

#### Via Horizon

Log in to the [Horizon](https://horizon.cloud.ovh.us/auth/login/) interface using the method listed in the [first part of this guide](https://support.us.ovhcloud.com/hc/en-us/articles/360002093130).

Choose the proper work zone.

![activate\_windows\_license01.png](/images/public-cloud/compute/activate-a-windows-license-for-an-instance-in-private-mode/21238456597907.png)

 

Select `Compute` and then `Instances` from the menu.

To add an interface, click on the arrow in the “Actions” column to access the possible actions on the instance. Select `Attach Interface`:

![activate\_windows\_license02.png](/images/public-cloud/compute/activate-a-windows-license-for-an-instance-in-private-mode/21238456615827.png)

 

Select your interface and confirm.

![activate\_windows\_license03.png](/images/public-cloud/compute/activate-a-windows-license-for-an-instance-in-private-mode/21238456622995.png)

#### Activate your Windows license

To activate Windows, you must go through Powershell.

Once you have logged in to your Windows instance, right-click on the `Start` menu and select `Windows PowerShell`.

Enter the following command:

```
slmgr.vbs -ato
```

The Windows license will be activated for 180 days.

You will need to repeat this operation every 180 days.

:::info

In the meantime, if you want to isolate your instance from the public network, you can disable the public port you have created via Horizon or the OpenStack API. You can also disable the network port directly via Windows.

:::

To check the license status and expiration date, use the following command:

```
slmgr.vbs -dli
```
