# Resize an instance via Horizon

**Learn how to resize your instance using the OpenStack Horizon interface.**

As a result of increased activity, or simply new needs, your instance may not be able to meet this new burden due to a lack of resources. However, with the Public Cloud, you can increase the resources available to your instance, and this can be done with just a few clicks.

:::warning

**NOTE:** Only upscaling is possible for classic models. In addition, this manipulation causes the instance to be shut down for the time of the operation.

:::

:::tip

Flex instances allow resizing to higher or lower models due to a locked single disk size.

:::

 

## Requirements

- An [OVHcloud Public Cloud instance](https://support.us.ovhcloud.com/hc/en-us/articles/360002245164)
- [Access to the Horizon interface](https://support.us.ovhcloud.com/hc/en-us/articles/20719718436115)

 

## Instructions

Log into the [Horizon interface](https://horizon.cloud.ovh.us/auth/login/), and make sure you are in the correct region. You can verify this in the top left corner.

![horizon\_selectRegion.png](/images/public-cloud/compute/resize-an-instance-via-horizon/41173137851027.png)

Next, click on the `Compute` menu on the left side and select `Instances`. Select `Resize Instance` in the drop-down list for the corresponding instance.

![horizon\_instances\_moreOptions.png](/images/public-cloud/compute/resize-an-instance-via-horizon/41173137858579.png)

 

### Template Selection Tab (Flavor Choice)

This section shows the current template (old flavor) and allows you to select a new template (new flavor) for the instance resource.

 

#### Flavor Details

In this section, you will see the resources associated with the new template you have chosen.

![horizon\_resizeInstance\_flavor.png](/images/public-cloud/compute/resize-an-instance-via-horizon/41173137864851.png)

 

#### Project Limits

Under this section, you can view the occupied resources compared with the total resources allocated to the project.

:::warning

**NOTE:** Please note that you cannot switch models when resizing an instance. A resizing can only be done from one Linux model to another Linux model, or from one Windows model to another Windows model.

:::

 

### Advanced Options

Use this section to manage the **Disk Partition** and **Server Group**.

Once the configuration is complete, click on `Resize`.

![horizon\_resizeInstance\_advanceOptions.png](/images/public-cloud/compute/resize-an-instance-via-horizon/41173137869331.png)

 

### Resizing a disk in Windows

When performing a resize for a Windows Instance, please note that the partition size is not automatically updated, so you will have to extend it using the **disk manager**:

- Right-click on the `Start` menu and launch the disk manager by clicking on `Disk Management`:

  ![windows\_diskManagement.png](/images/public-cloud/compute/resize-an-instance-via-horizon/41173152503315.png)

* Right-click on the main partition, then click on `Extend Volume`.

  ![windows\_extendVolume.png](/images/public-cloud/compute/resize-an-instance-via-horizon/41173137883667.png)

- In the `Extend Volume Wizard` menu, click on `Next` to proceed. In the next tab, choose the disk resources to extend and click on `Next`.

  ![windows\_extendVolumeWizard\_configure.png](/images/public-cloud/compute/resize-an-instance-via-horizon/41173137889171.png)

  Once done, click on `Finish` to confirm your choice.

  ![windows\_extendVolumeWizard\_finish.png](/images/public-cloud/compute/resize-an-instance-via-horizon/41173137899923.png)

* The new disk size will then be displayed in the disk manager.

  ![windows\_diskManager\_confirmation.png](/images/public-cloud/compute/resize-an-instance-via-horizon/41173137901843.png)
