# Uploading your own image

**Learn the steps to upload your own images to your project.**

OVHcloud offers ready-to-go images for Public Cloud instances. However, we also enable customers to use their own images.

:::info

The new version will not be reflected in OVHcloud Control Panel, OVHcloud API, Horizon, or OpenStack API when you upgrade the operating system instead of reinstalling it.

:::

:::warning

**NOTE:** At this time, this feature is not supported on Local Zones instances.

:::

 

## Requirements

- A [Public Cloud instance](https://support.us.ovhcloud.com/hc/en-us/articles/360002245164#step-3-creating-an-instance) in your OVHcloud account
- Your own RAW/QCOW2 (recommended formats) image
- An [OpenStack user](https://support.us.ovhcloud.com/hc/en-us/articles/360008644539)
- An [OpenStack CLI ready environment](https://support.us.ovhcloud.com/hc/en-us/articles/1500009262762) (if using CLI)

 

## Instructions

### Before starting

It is advisable to either use cloud-ready images already provided by the distribution vendor or build your own image using solutions such as [Packer OpenStack builder](https://support.us.ovhcloud.com/hc/en-us/articles/30275721022483).

Cloud-ready images can be found here:

- [https://cloud.centos.org/centos/](https://cloud.centos.org/centos/)
- [https://cloud.debian.org/images/cloud/](https://cloud.debian.org/images/cloud/)
- [https://cloud-images.ubuntu.com/releases/](https://cloud-images.ubuntu.com/releases/)
- [https://alt.fedoraproject.org/cloud/](https://alt.fedoraproject.org/cloud/)

Other operating systems tend to offer ISO images which are also applicable when [building images with Packer](https://www.packer.io/docs/builders) such as QEMU and VirtualBox builders.

We recommend ensuring the following is installed on your images for them to be cloud-ready:

- *QEMU Guest Agent*: this will provide better snapshot experience as it will allow the host to communicate to the instance for live snapshots. Not all operating systems are compatible with this package but most of them are.
- *cloud-init*: this will allow you to bootstrap your instance on the first boot, such as adding SSH keys and configuring network. Most operating systems are compatible with this.

Finally we recommend images to be either in RAW or QCOW2 format. As best practice, keep the size of the image as small as possible so that you are billed less per month and spawns of your instances are quicker.

 

### Uploading your image

With OpenStack there are two ways of uploading your own image. You can either upload it via the OpenStack command line interface or with the [Horizon web interface](https://horizon.cloud.ovh.us/auth/login/).

 

#### Using CLI

Once your image is ready to upload, you can use the following steps to upload it using the OpenStack CLI. From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/):

1. Select `Public Cloud` from the top navigation bar.
2. On the left, under **Project Management**, click `Users & Roles`.
3. To the right of your OpenStack user, click the *more options* `...` button and select `Download OpenStack's RC file`.
4. Select the region you want to upload it to and click `Download`.

![PCI\_compute\_openStack\_uploadYourImage01.png](/images/public-cloud/compute/uploading-your-own-image/30266302812307.png)

Source the openrc file:

```sh
source openrc.sh
```

Once the file is sourced, you will be asked to enter the password for the OpenStack user. Enter your password.

Now you can upload your image. This example command will do the following:

- Disk format is "RAW"
- Upload an image from the current path called "debian9.raw"
- Call the image "Debian 9 - My Image"
- Set the image to private state
- Set properties which are recommended to set. Set optimal configuration which allow features like *live-snapshot* and *cloud-init* to work (requires the username to be used)

```sh
openstack image create --disk-format raw --container-format bare --file debian9.raw "Debian 9 - My Image" --private --property distribution=debian --property hw_disk_bus=scsi --property hw_scsi_model=virtio-scsi --property hw_qemu_guest_agent=yes --property image_original_user=debian
```

 

#### Using Horizon

Once your image is ready to upload, you can use the following steps to upload it using the OpenStack [Horizon interface](https://horizon.cloud.ovh.us/auth/login/).

At the top left, select the `region` to which you want to upload your image.

In the left-side menu, click `Compute` and then `Images`, and click on `+ Create Image`.

![PCI\_compute\_openStack\_uploadYourImage02\*\*.png](/images/public-cloud/compute/uploading-your-own-image/30269711121043.png)

Enter the details of your image and select the file from your computer.

![horizon\_3](/images/public-cloud/compute/uploading-your-own-image/public-cloud-compute-upload-own-image-images-horizon-3-png.png)

Enter the instance metadata (any custom ones you may have you can also add) and then click `Create Image`.

![horizon\_4](/images/public-cloud/compute/uploading-your-own-image/public-cloud-compute-upload-own-image-images-horizon-4-png.png)
