# Managing Users and Projects in Managed Private Registry (Harbor)

**Learn how to manage users and projects on your OVHcloud Managed Private Registry service.**

OVHcloud Managed Private Registry service provides you with a managed Harbor, an authenticated Docker registry where you can privately store your Docker images.

 

## Requirements

- an OVHcloud Managed Private Registry (see the [creating a private registry](/guides/public-cloud/managed-private-registry/create-private-registry) guide for more information)
- access to the Harbor UI to operate the private registry (see the [connecting to the UI](/guides/public-cloud/managed-private-registry/connecting-harbor-user-interface) guide for more information)

 

## Instructions

Using the Harbor UI, you can manage projects, users, and rights on your private registry.

### Creating a new project

A project in Harbor contains all repositories of an application. No images can be pushed to Harbor before the project is created.

There are two types of projects in Harbor:

- Public: All users can read from a public Harbor project.
- Private: Only users with proper privileges can read from this project.

Let's create a private project:

1. Create a new project on Harbor UI by clicking `+ NEW PROJECT`.

   ![Manage users - Managing users projects harbor - step 1](/images/public-cloud/managed-private-registry/managing-users-projects-harbor/manageusers-01.png)

2. Call it *private*, leave the public checkbox unchecked, and click `OK`.

:::info

Keep `-1` for the storage quota if you don't want limitations.

:::

![Manage users - Managing users projects harbor - step 2](/images/public-cloud/managed-private-registry/managing-users-projects-harbor/manageusers-02.png)

 

After the project is created, you can browse repositories, helm charts, members, labels, scanner, policy, robot accounts, webhooks, logs, and configuration using the navigation tabs.

![Manage users - Managing users projects harbor - step 3](/images/public-cloud/managed-private-registry/managing-users-projects-harbor/manageusers-03.png)

 

### Creating a new user and giving it rights to the *private* project

Now you're going to create a new user and give him developer rights over the *private* project.

1. Go to the `Users` section of Harbor UI and click on `+ NEW USER`.

   ![Manage users - Managing users projects harbor - step 4](/images/public-cloud/managed-private-registry/managing-users-projects-harbor/manageusers-04.png)

2. Add a new *private-user* user. For the e-mail domain, use the domain found in the URL of your Harbor UI. Click `OK`.

   ![Manage users - Managing users projects harbor - step 5](/images/public-cloud/managed-private-registry/managing-users-projects-harbor/manageusers-05.png)

3. The new user is now visible in your Harbor UI.

   ![Manage users - Managing users projects harbor - step 6](/images/public-cloud/managed-private-registry/managing-users-projects-harbor/manageusers-06.png)

4. Go back to the `Projects` section and choose the `private` project.

   ![Manage users - Managing users projects harbor - step 7](/images/public-cloud/managed-private-registry/managing-users-projects-harbor/manageusers-07.png)

5. Select the `Members` tab and click on `+ USER`.

   ![Manage users 07](/images/public-cloud/managed-private-registry/managing-users-projects-harbor/manageusers-07-b.png)

6. Add the *private-user* as member of the project, and give him a *Developer* role.

   ![Manage users - Managing users projects harbor - step 8](/images/public-cloud/managed-private-registry/managing-users-projects-harbor/manageusers-08.png)

The *private-user* is now a member of the *private* project.

![Manage users - Managing users projects harbor - step 9](/images/public-cloud/managed-private-registry/managing-users-projects-harbor/manageusers-09.png)
