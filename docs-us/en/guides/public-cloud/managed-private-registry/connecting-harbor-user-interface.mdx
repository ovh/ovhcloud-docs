# Connecting to the Harbor User Interface

**Learn how to connect to Harbor UI to operate your OVHcloud Managed Private Registry service.**

OVHcloud Managed Private Registry service provides you with a managed, authenticated Docker registry where you can privately store your Docker images. This managed private registry is an instance of [Harbor](https://goharbor.io/), an open-source trusted cloud native registry project that stores, signs, and scans Docker images.

 

## Requirements

- an OVHcloud Managed Private Registry (see the [creating a private registry](/guides/public-cloud/managed-private-registry/create-private-registry) guide for more information)

 

## Instructions

In your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/):

1. Click `Public Cloud` from the top navigation bar.
2. Select your `Managed Private Registry`.
3. Click on the *more options* (`...`) button at the right end.
4. Click on `Harbor user interface`.

![Connecting harbor user interface - step 1](/images/public-cloud/managed-private-registry/connecting-harbor-user-interface/connect-01.png)

 

On the login page of the Harbor UI, the open source engine running your OVHcloud Managed Private Registry, enter the credentials (user and password) of your OVHcloud Managed Private Registry.

:::info

Steps to retrieve your credentials are provided in the [creating a private registry](/guides/public-cloud/managed-private-registry/create-private-registry) guide.

:::

![Connecting harbor user interface - step 2](/images/public-cloud/managed-private-registry/connecting-harbor-user-interface/connect-02.png)

 

Now you can use the Harbor UI to manage your private registry.

![Connecting harbor user interface - step 3](/images/public-cloud/managed-private-registry/connecting-harbor-user-interface/connect-03.png)
