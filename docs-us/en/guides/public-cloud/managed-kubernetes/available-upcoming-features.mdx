## Recent Features

### LUKS Encrypted Persistent Volumes (Available)

OVHcloud Managed Kubernetes now supports LUKS-encrypted block storage volumes using OVHcloud Managed Keys (OMK). This feature is available in specific regions.

For more information, see:

- [Datacenters, nodes, and storage flavors - LUKS Encrypted Storage Classes](https://support.us.ovhcloud.com/hc/en-us/articles/1500005132102#luks-encrypted-storage-classes)
- [LUKS encrypted volumes documentation](https://support.us.ovhcloud.com/hc/en-us/articles/1500005048361#luks-encrypted-persistent-volumes)
