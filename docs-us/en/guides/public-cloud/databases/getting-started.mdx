# Databases & Analytics - Getting started

**Learn how to order a database or analytics solution in the OVHcloud Control Panel.**

Cloud Databases and Analytics[\*](#go-further) services allow you to focus on building and deploying cloud applications while OVHcloud takes care of the service infrastructure and maintenance.

 

## Requirements

- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)
- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account

 

## Instructions

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub), navigate to the `Databases` section by clicking the `Public Cloud` menu and selecting your Public Cloud project.

:::info

- Selecting `Data Streaming` will give you access to the [Kafka®](/guides/public-cloud/data-analytics/kafka-getting-started), [Kafka® Connect](/guides/public-cloud/data-analytics/kafka-connect-capabilities-limitations), and [Kafka® MirrorMaker](/guides/public-cloud/data-analytics/kafka-mirrormaker-capabilities-limitations) services.
- Selecting `Data Analysis` will give you access to [Dashboards](/guides/public-cloud/data-analytics/dashboards-configure-dashboards-instance-accept-incoming-connections) and [OpenSearch™](/guides/public-cloud/data-analytics/opensearch-getting-started) services.1

:::

Click on the button `Create a managed database` (click `Create a service` if your project already contains services.)

![Manager database onboarding page](/images/public-cloud/databases/getting-started/manager-database-onboarding-page.png)

 

### Step 1: Select your engine type

Click on the type of engine you want to use and then (if available) select the version to install from the respective drop-down menu.

![Manager database order types](/images/public-cloud/databases/getting-started/manager-database-order-types.png)

 

### Step 2: Select a service plan

Choose an appropriate service plan. You will be able to upgrade the plan after creation.

Please visit the [capabilities page](/guides/public-cloud/databases/capabilities-limitations) of your selected engine type for detailed information on each plan's properties.

![Manager database order service plans](/images/public-cloud/databases/getting-started/manager-database-order-service-plans.png)

 

### Step 3: Select a region

Choose the geographical region of the data center in which your service will be hosted.

![Manager database order regions](/images/public-cloud/databases/getting-started/manager-database-order-regions.png)

 

### Step 4: Node type

You can choose the node template in this step.

Please visit the [capabilities page](/guides/public-cloud/databases/capabilities-limitations) of your selected engine type for detailed information on the hardware resources and other properties of the engine installation.

Take note of the pricing information.

![Manager database order node type](/images/public-cloud/databases/getting-started/manager-database-order-node-type.png)

 

### Step 5: Cluster sizing

Additional storage can be ordered and, depending on the engine, the number of nodes in your cluster can be adjusted:

![Manager database order cluster sizing](/images/public-cloud/databases/getting-started/manager-database-order-cluster-sizing.png)

 

### Step 6: Configure your options

Choose your network configuration:

![Manager database order public network](/images/public-cloud/databases/getting-started/manager-database-order-public-network.png)

 

#### Connecting a private network (optional)

If you already have a private subnet available, check the box **Private** and select it from the drop-down menu. Note that this option might not be available for the selected service type.

You can be forwarded to create a private network or subnet by clicking on the respective links. You will have to start the ordering process over in that case.

Please follow [this guide](/guides/public-cloud/network-services/configure-vrack) for detailed instructions.

![Manager database order private network](/images/public-cloud/databases/getting-started/manager-database-order-private-network.png)

 

### Step 7: Summary and confirmation

The panel on the right side of the page will display a summary of your order.

![Manager database order summary](/images/public-cloud/databases/getting-started/manager-database-order-summary.png)

Within a few minutes, your new service will be deployed. Messages in the OVHcloud Control Panel will inform you when the service is ready to use.

Continue with the *Configure your instance to accept incoming connections&#x20;*&#x67;uide of your selected engine type available [here](/guides/public-cloud/databases/capabilities-limitations) to configure your service after installation.

Note that the configuration options might be different, depending on the engine type. You will find an example in this repository: [https://github.com/ovh/public-cloud-databases-examples](https://github.com/ovh/public-cloud-databases-examples).
