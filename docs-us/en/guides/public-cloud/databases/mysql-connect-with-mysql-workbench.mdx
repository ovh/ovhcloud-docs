# MySQL® - Connect with MySQL Workbench

**Learn how to connect to a MySQL® database instance with MySQL® Workbench.**

Cloud Databases allow you to focus on building and deploying cloud applications while OVHcloud takes care of the database infrastructure and maintenance in operational conditions.

 

## Requirements

- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- A MySQL® database running on your OVHcloud Cloud Databases ([this guide](https://support.us.ovhcloud.com/hc/en-us/articles/20611621210515) can help you to meet this requirement)
- [Configure your MySQL® instance](https://support.us.ovhcloud.com/hc/en-us/articles/20814040973331) to accept incoming connections
- A MySQL® Workbench stable version installed and public network connectivity (Internet). *This guide was made with MySQL® Workbench version 8.0.28*.

 

## Concept

A MySQL® instance can be managed in multiple ways. One of the easiest, yet powerful, is to use a Command Line Interface (CLI), as shown in our guide: [Connect to MySQL® with CLI](https://support.us.ovhcloud.com/hc/en-us/articles/20805146473875) or by using programming languages, such as [PHP](https://support.us.ovhcloud.com/hc/en-us/articles/20815696722963) or [Python](https://support.us.ovhcloud.com/hc/en-us/articles/20840434483219).

Another way is to interact directly using a management tool like MySQL® Workbench.

 

## Instructions

### Installation

MySQL Workbench can be downloaded for free by [clicking here](https://dev.mysql.com/downloads/workbench/).

Once you have downloaded and installed it, follow the steps below to set up a remote connection to your MySQL® instance.

 

### Connect with MySQL® Workbench

#### Configuration

Click the *new connection* `+` button.

![mysql\_workbench01.png](/images/public-cloud/databases/mysql-connect-with-mysql-workbench/20846481144595.png)

In the **Setup New Connection** dialog box, fill in the `Parameters` tab form with the previously collected information.

![mysql\_workbench02.png](/images/public-cloud/databases/mysql-connect-with-mysql-workbench/20846496544403.png)

Store the password for connection in the keychain.

![mysql\_workbench03.png](/images/public-cloud/databases/mysql-connect-with-mysql-workbench/20846481179411.png)

Switch to the `SSL` tab and set `Use SSL` to `Require`.

![mysql\_workbench04.png](/images/public-cloud/databases/mysql-connect-with-mysql-workbench/20846496565395.png)

Once done, select your new connection.

![mysql\_workbench05.png](/images/public-cloud/databases/mysql-connect-with-mysql-workbench/20846481214611.png)

Congratulations, in the `Schemas` tab, you will see your databases.

![mysql\_workbench06.png](/images/public-cloud/databases/mysql-connect-with-mysql-workbench/20846481227539.png)

:::info

Once connected, MySQL® Workbench facilitates many actions such as querying your databases and managing used or even imported data. Please read the official documentation to discover the [whole feature list](https://www.mysql.com/products/workbench/features.html).

:::
