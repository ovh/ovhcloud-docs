# Databases & Analytics - Capabilities and limitations

## Cloud Databases and Analytics[\*](#go-further)

With our Cloud Databases and Analytics services, we manage the infrastructure and administration, including set-up, backup, scalability, and security. Choose from a large portfolio of popular engines.

We continuously improve our offers. You can follow and submit ideas to add to our [roadmap](https://github.com/orgs/ovh/projects/16/views/5?filterQuery=main-product%3A%22Managed+Databases%22%2C%22Data+Platform%22%2C%22Data+Processing%22%2C%22Data+Integration%22).

##  

### Databases for...

<Tabs>

<Tab label="MongoDB®">

MongoDB® is a fully managed and scalable document-oriented database management system that does not require a predefined data schema.

See our [MongoDB® Capabilities and Limitations](https://support.us.ovhcloud.com/hc/en-us/articles/22442835364243) guide.

</Tab>

<Tab label="MySQL®">

MySQL® is an open-source fully-managed relational database service. It's fast, reliable, scalable, and user-friendly.

See our [MySQL® Capabilities and Limitations](https://support.us.ovhcloud.com/hc/en-us/articles/20887483746067) guide.

</Tab>

<Tab label="PostgreSQL®">

PostgreSQL® is an open-source fully managed and hosted relational database service. It's a high-performance engine that offers flexibility through a variety of included advanced extensions.

See our [PostgreSQL® Capabilities and Limitations](https://support.us.ovhcloud.com/hc/en-us/articles/21411650440211) guide.

</Tab>

<Tab label="Valkey">

Valkey is an open-source fully managed in-memory NoSQL database based on the Redis® open-source software. It helps you store and access data quickly and efficiently.

See our [Valkey Capabilities and Limitations](https://support.us.ovhcloud.com/hc/en-us/articles/21729352981907) guide.

</Tab>

</Tabs>

 

### Analytics with...

<Tabs>

<Tab label="Dashboards">

Dashboards is not a database; it is a monitoring and analysis solution commonly used to visualize and analyze data from various sources, including databases.1

Kafka® is a high-performance distributed streaming system designed for durability, scalability, and real-time data streaming across multiple applications and platforms.

Kafka® Connect is a Kafka® extension to facilitate connection to your external data systems.

</Tab>

<Tab label="Kafka® MirrorMaker">

Kafka® MirrorMaker is a data replication system between two Kafka® clusters.

</Tab>

OpenSearch™ is an open-source fully managed search, analytics, and observability engine. It is ideal for logs management and offers search and analytical aggregations.\
OpenSearch™ is an open-source fork derived from Elasticsearch.

See our [OpenSearch™ Capabilities and Limitations](https://support.us.ovhcloud.com/hc/en-us/articles/21913096243219) guide.

</Tab>

## Specific feature Plans

:::warning

**NOTE:** The MongoDB® engine has different plan names. See [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/22442835364243#plans) for more information about MongoDB® plans.

:::

#### Essential/Discovery

The Essential/Discovery plan typically offers the basic features and functionalities required for managing an engine. It is designed for test and development environments or non-critical projects.

 

#### Business/Production

The Business/Production plan is more comprehensive and suitable for organizations with higher engine demands. This is the first production-ready offering.

 

#### Enterprise

The enterprise pricing plan is the most advanced and robust option available for managed engines. It is dedicated to organizations with complex and high-performance engine requirements.

 

#### Plan capabilities overview

Here is an overview of the various plans' capabilities:

|                   |                         |                         |                |
| ----------------- | ----------------------- | ----------------------- | -------------- |
| **Feature**       | **Essential/Discovery** | **Business/Production** | **Enterprise** |
| SLA               | None                    | 99.9%                   | 99.95%         |
| High Availability |                         | ✓                       | ✓              |

Your choice of plan affects the number of nodes your cluster can run.
