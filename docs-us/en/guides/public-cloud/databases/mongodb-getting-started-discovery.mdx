# MongoDB® - Getting started: Discovery

**Learn the first steps of creating and connecting to a forever-free MongoDB[®](#go-further) Discovery Cloud Database service.**

 

## Requirements

- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account

 

## Instructions

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/):

1. Navigate to the `Public Cloud` section.
2. In the left-hand menu under **Databases & Analytics**, choose `Databases`.
3. Click the `Create a database instance` button (click `+ Create a service` if your project already contains databases).

![manager\_database\_onboardingPage.png](/images/public-cloud/databases/mongodb-getting-started-discovery/41904866620435.png)

 

### Select the database type

Between all database engines, select **MongoDB**. You can choose to change the version to install from the drop-down menu.

![manager\_database\_mongo\_selectVersion.png](/images/public-cloud/databases/mongodb-getting-started-discovery/41904866623379.png)

 

### Review the order

The **Discovery** plan is selected by default along with the following options:

- The region is set to `Virginia (US-EAST-VA)`.
- The node type is set to `db2-free` (with 512 MB storage).
- The number of nodes is set to `3`.
- The network type is `Public (internet)`.

:::info

The **Discovery** plan will let you start with MongoDB® for **free** with limited settings options and storage. However, you may only have one Discovery instance per project.

:::

Review the service settings and click on the `Order` button.

Within a few minutes, your **Discovery** MongoDB® service will be deployed.

 

### Connectivity settings

Once the service is up and running, you will be able to configure it to accept incoming connections. A [dedicated guide](https://support.us.ovhcloud.com/hc/en-us/articles/22402510170643) is available to help you configure your service after installation.

 

### Testing the service

When the service is running and accepting incoming connections, the next step is to access the service. The common way to do so is to use **MongoDB® Compass** to connect to the service, following [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/22483342560403).

If **MongoDB® Compass** is not your preferred method, read these other guides to connect to the service :

- [Connect with CLI](https://support.us.ovhcloud.com/hc/en-us/articles/22451464476947)
- [Connect with Python](https://support.us.ovhcloud.com/hc/en-us/articles/22457305632787)
- [Connect with PHP](https://support.us.ovhcloud.com/hc/en-us/articles/22453394373779)

Other integration examples can be found in our [GitHub repository](https://github.com/ovh/public-cloud-databases-examples/tree/main/databases/mongodb).
