# Databases & Analytics - Advanced configuration

**Learn about the advanced configuration options available for Cloud Databases and Analytics through the OVHcloud Control Panel and via API.**

Cloud Databases and Analytics[\*](#go-further) are managed services, meaning they are not fully configurable. For example, it is not possible to modify *pg\_hba.conf*.

:::info

Advanced configuration is available for the following databases and analytics engines:

- Dashboards
- Kafka®
- Kafka® Connect
- MySQL®
- OpenSearch™
- PostgreSQL®
- Valkey

:::

 

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- A Cloud Databases or Analytics[\*](#go-further) service running in your OVHcloud account ([this guide](https://support.us.ovhcloud.com/hc/en-us/articles/20611621210515) can help you to meet this requirement)
- Access to your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) or the [OVHcloud API](https://api.us.ovhcloud.com/).

 

## Instructions

:::warning

**NOTE:** Please note that changes to the advanced settings apply at the cluster level and therefore to all the services in the cluster.

:::

:::info

Depending on the engine, some settings may already be defined.

:::

:::info

Once the advanced configuration has been submitted, it is not possible to reset it to initial values. It is only possible to update the values, so we recommend that you take note of the initial values before changing them.

See the [Checking](#checking) section below.

:::

### Using the OVHcloud Control Panel

To change the advanced configuration, you first need to log in to your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/). Navigate to the `Databases` (or `Data Streaming` or `Data Analysis`) area via the `Public Cloud` menu.

Select your engine instance, then the `Advanced configuration` tab.

![manager\_database\_configurationTab.png](/images/public-cloud/databases/databases-analytics-advanced-configuration/41875095348627.png)

Scroll to the bottom of the page. Select the key of the advanced setting you want to define, click the add `+` button, and then set its value.

When ready, click `Save changes`.

![manager\_database\_addConfiguration.png](/images/public-cloud/databases/databases-analytics-advanced-configuration/41875075398675.png)

 

### Using API

:::info

If you are not familiar with using the OVHcloud API, please refer to our guide on [First Steps with the OVHcloud API](https://support.us.ovhcloud.com/hc/en-us/articles/360018130839).

:::

#### Get your service and cluster IDs

You first need to identify the service and the cluster to which you want to apply the changes.

***Get the desired service ID***

Execute the following API call:

<Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project"} regions={["us"]} />

From the resulting list, select and copy the service identifier corresponding to the desired service, also known as serviceName.

***Get the desired cluster ID***

Open the following API call, paste your service ID into the `serviceName` input field and click `Execute`:

| Engine         | API call                                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Dashboard      | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/grafana"} regions={["us"]} />      |
| Kafka®         | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/kafka"} regions={["us"]} />        |
| Kafka® Connect | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/kafkaConnect"} regions={["us"]} /> |
| MySQL®         | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/mysql"} regions={["us"]} />        |
| OpenSearch™    | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/opensearch"} regions={["us"]} />   |
| PostgreSQL®    | <Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/database/postgresql"} regions={["us"]} />   |
| Valkey         | <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/valkey"} regions={["us"]} />               |

From the resulting list, select and copy the **clusterId**.
