# Databases & Analytics - How to set up logs forwarding

Cloud Databases and Analytics allow you to send logs of your service to your own Logs Data Platform (LDP) data stream.

 

## Requirements

- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) and [OVHcloud API](https://api.us.ovhcloud.com/)

- A [Cloud Database service](https://us.ovhcloud.com/public-cloud/databases/) up and running

  :::info

  We will use Valkey as the example in this guide.

  :::

- A [Logs Data Platform account](https://support.us.ovhcloud.com/hc/en-us/articles/28017122298771) within this OVHcloud account with at least one destination stream configured

  :::warning

  **NOTE:** If you are not familiar with all the LDP *Stream* configuration possibilities, create a new one with the default options (indexing and websocket enabled, long-term storage disabled) for this guide.

  :::

 

## Instructions

### Create your subscription

<Tabs>

<Tab label="Via OVHcloud Control Panel">

#### Logs direct access

From the OVHcloud Control Panel, navigate to your engine via the `Public Cloud` and `Databases` (or `Data Analysis`) menus.

Once there, click the `Logs` tab.

![manager\_database\_logsTab.png](/images/public-cloud/databases/databases-analytics-how-to-set-up-logs-forwarding/42427300034323.png)

 

#### Logs access through LDP

From the `Logs` tab, you can `Subscribe` to an LDP data stream. Once the subscription is enabled, all the logs will be pushed to [Logs Data Platform](https://us.ovhcloud.com/identity-security-operations/logs-data-platform/) to archive generated logs and perform advanced searches, and create alerts or visualizations.

For more information, please refer to our [Quick Start for Logs Data Platform](https://support.us.ovhcloud.com/hc/en-us/articles/28017122298771) guide.

![manager\_database\_logsTab\_subscribe.png](/images/public-cloud/databases/databases-analytics-how-to-set-up-logs-forwarding/42427286526355.png)

</Tab>

<Tab label="Via OVHcloud API">

<details>
<summary>Retrieve the required information</summary>

Retrieve your LDP destination `streamId`:

- In the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), go to the `Logs Data Platform` section and select your service.
- Go to the `Data stream` tab.
- Choose your target stream, select the *more options*`...` button, and then `Copy stream ID`.

![manager\_ldp\_datastreamTab\_moreOptions.png](/images/public-cloud/databases/databases-analytics-how-to-set-up-logs-forwarding/42427286528403.png)

Retrieve your LDP destination `serviceName`:

- This is your Public Cloud project ID.

Retrieve your `clusterId`:

- In the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), go to your database.
- You can see the field `Name/ID`.

Retrieve the available `kind` values for your service:

- <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/database/valkey/\{clusterId\}/log/kind"} regions={["us"]} />

 

</details>

Use the following API call:

<Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\{serviceName\}/database/\{engine\}/\{clusterId\}/log/subscription"} regions={["us"]} />

**Request Body:**

```console
{
  kind: "string",
  streamId: <LDP destination stream ID>
}
```

</Tab>

</Tabs>

 

### Find logs in Graylog

To find logs of your service in your Graylog stream, you can use the following Graylog queries:

#### MongoDB[®](#go-further)

Query: `cluster: "<HostID>"`

You can find this `HostID` in your manager:

- In `Login information` switch the `Service` to `mongodb`
- Now you can see the `Host` field with the format `<HostID>.database.cloud.ovh.us`

 

#### Other Engines

Query: `clusterID: "<Engine>-<HostID>"`

You can find this `HostID` in your manager:

- Find the Cluster ID formatted as a UUID (AAAAAAAA-BBBB-CCCC-DDDDDDDDDDDD)
- `HostID` is the first part of the UUID (AAAAAAAA)

 

### Delete your subscription

<Tabs>

<Tab label="Via OVHcloud Control Panel">

#### Method 1: Unsubscribe

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), navigate to your engine and select the `Logs` tab.

Click `Unsubscribe`.

![manager\_database\_logsTab\_unsubscribe.png](/images/public-cloud/databases/databases-analytics-how-to-set-up-logs-forwarding/42427300041363.png)

 

#### Method 2: Cancel the database service

If you delete your database service, all subscriptions of this service are deleted automatically.

For instructions to cancel a Database or Analytics service, see our [Databases & Analytics - FAQ](https://support.us.ovhcloud.com/hc/en-us/articles/20351785242515#service-plans-and-instances) guide.

</Tab>

<Tab label="Via OVHcloud API">

#### Method 1: Unsubscribe

You can delete subscriptions using the `subscriptionId` concerned in this API call:

<Api version="v1" section="/cloud" method="DELETE" route={"/cloud/project/\{serviceName\}/database/\{engine\}/\{clusterId\}/log/subscription/\{subscriptionId\}"} regions={["us"]} />

 

#### Method 2: Cancel the database service

If you delete your database service, all subscriptions of this service are deleted automatically.

<Api version="v1" section="/cloud" method="DELETE" route={"/cloud/project/\{serviceName\}/database/\{engine\}/\{clusterId\}"} regions={["us"]} />

</Tab>
