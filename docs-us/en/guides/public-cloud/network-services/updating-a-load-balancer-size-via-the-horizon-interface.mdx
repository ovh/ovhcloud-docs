# Updating a Load Balancer size via the Horizon interface

**Learn how to change the size of your Public Cloud Load Balancer using the Horizon interface.**

:::info

Find more information about the different Load Balancer sizes and their capacities on our [Load Balancer page](https://us.ovhcloud.com/public-cloud/load-balancer/).

:::

 

## Requirements

- Access to the [OVHcloud Horizon interface](https://horizon.cloud.ovh.us/project/)
- A Load Balancer [already created and available](https://support.us.ovhcloud.com/hc/en-us/articles/18610207964051)
- User privileges to modify the Load Balancer settings

 

## Instructions

### Access the Horizon interface

Go to the [OVHcloud Horizon interface](https://horizon.cloud.ovh.us/project/) and log in with your credentials. For more information on how to connect to Horizon, read the [Introducing Horizon](https://support.us.ovhcloud.com/hc/en-us/articles/20719718436115) guide.

Once you are logged in, find your [existing Load Balancer](https://horizon.cloud.ovh.us/project/load_balancer) by selecting `Network` from the left-hand menu and clicking `Load Balancers`.

![PCI\_network\_tutorial\_resizeLBhorizon01\*.png](/images/public-cloud/network-services/updating-a-load-balancer-size-via-the-horizon-interface/38418689332627.png)

 

### Resize your Load Balancer

To the right of your Load Balancer's name, open the drop-down menu and select `Resize Load Balancer`.

![PCI\_network\_tutorial\_resizeLBhorizon02\*.png](/images/public-cloud/network-services/updating-a-load-balancer-size-via-the-horizon-interface/38418662747027.png)

A window will prompt you to select a new size (small, medium, large, or XL) for your load balancer.

Once the new flavor is selected, click `✔️ Resize` to update the size of your Load Balancer.

![PCI\_network\_tutorial\_resizeLBhorizon03A\*.png](/images/public-cloud/network-services/updating-a-load-balancer-size-via-the-horizon-interface/38418662749331.png)
