# Creating a private network with Gateway

A [Gateway](https://us.ovhcloud.com/public-cloud/gateway/) offers a secure outbound connection method from your private network instances or the ability to use Floating IPs with your instance or Load Balancer for service exposition.

 

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- **For the OVHcloud API:** API credentials ([First steps with the OVHcloud API](https://support.us.ovhcloud.com/hc/en-us/articles/360018130839))
- **For the OVHcloud CLI:** the [OVHcloud CLI ](https://github.com/ovh/ovhcloud-cli)installed and configured with your credentials
- **For the OpenStack API:** an OpenStack environment configured ([Preparing an environment](https://support.us.ovhcloud.com/hc/en-us/articles/1500009262762))
- **For Terraform:** Terraform installed and the OVHcloud provider configured ([How to use Terraform](https://support.us.ovhcloud.com/hc/en-us/articles/15974268257299))

## Instructions

### Gateway models

Before creating a Gateway, choose the model suited to your bandwidth needs:

| Model | Bandwidth      |
| ----- | -------------- |
| S     | up to 200 Mbps |
| M     | up to 500 Mbps |
| L     | up to 2 Gbps   |
| XL    | up to 4 Gbps   |
| 2XL   | up to 8 Gbps   |

 

### Create a private network with a Gateway

<Tabs>

<Tab label="OVHcloud Control Panel">

**Step 1 — Access the creation page**

Click on `Gateway` in the left-hand menu under **Network**.

You must have an active vRack before proceeding. If you do not have a vRack, please consult [this section](https://support.us.ovhcloud.com/hc/en-us/articles/360002093130#configure-vrack-PCI-instructions) of the relevant guide.

Next, click `Create a Gateway`.

![PCI\_createGateway.png](/images/public-cloud/network-services/creating-a-private-network-with-gateway/40630295372179.png)

**Step 2 — Select the region and size**

Select the region where your private instances are located.

![PCI\_createGateway\_selectLocation.png](/images/public-cloud/network-services/creating-a-private-network-with-gateway/40630295375507.png)

Then select your gateway size (see the models table above).

![PCI\_createGateway\_selectSize.png](/images/public-cloud/network-services/creating-a-private-network-with-gateway/40630308208147.png)

**Step 3 — Name the Gateway and attach a private network**

Edit the default name of your Gateway and select an existing private network from the drop-down list.

:::info

Only single-region private networks are supported by Gateway.

:::

![PCI\_createGateway\_attachExistingNetwork.png](/images/public-cloud/network-services/creating-a-private-network-with-gateway/40630308212627.png)

You can also click `Add a private network` to create a new private network inline.

In the pop-up window, enter a name for your private network, select a subnet, and click `Add`.

![PCI\_createGateway\_attachNewNetwork.png](/images/public-cloud/network-services/creating-a-private-network-with-gateway/40630295386899.png)

**Step 4 — Confirm creation**

Click `Create a gateway` to start the deployment.

![PCI\_createGateway\_attachExistingNetwork.png](/images/public-cloud/network-services/creating-a-private-network-with-gateway/40630308212627.png)

The creation may take several minutes. Refresh the page if necessary.

Once done, the private network is visible in the `Private Network` section.

:::warning

**NOTE:** You can cancel a Private Network by clicking the *trash* `🗑️` icon to the right of the network.

:::

![PCI\_listPrivateNetworks.png](/images/public-cloud/network-services/creating-a-private-network-with-gateway/40630308219155.png)

The Gateway appears in the `Gateway` section.

:::warning

**NOTE:** You can cancel a Gateway by clicking the *more options* `...` button and selecting `Delete`.

:::

![PCI\_listGateways.png](/images/public-cloud/network-services/creating-a-private-network-with-gateway/40630295388307.png)

<Tab label="OVHcloud API">

**Step 1 — Retrieve the project ID**

Log in to the OVHcloud APIv6 interface according to the relevant guide ([First steps with the OVHcloud API](https://support.us.ovhcloud.com/hc/en-us/articles/360018130839)).

In case the project ID is unknown, the calls below allow you to retrieve it.

To retrieve a list of projects:

<Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project"} regions={["us"]} />

To identify the project via the "description" field:

<Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}"} regions={["us"]} />

**Step 2 — Create the private network with a Gateway**

Create your private network and gateway:

<Api version="v1" section="/cloud/project" method="POST" route={"/cloud/project/\{serviceName\}/region/\{regionName\}/gateway"} regions={["us"]} />

Fill in the fields according to the following table.

| **Field**    | **Description**                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------------ |
| serviceName  | 'The ID of your project'                                                                                     |
| regionName   | Example: US-VA-EAST-1                                                                                        |
| model        | size of your gateway (s, m, l, xl, 2xl) depending on your needs                                              |
| name         | set a name for your gateway, you can click on the dropdown arrow and select "null" for a default one         |
| network.name | set a name for your private network, you can click on the dropdown arrow and select "null" for a default one |
| cidr         | IP block for your subnet                                                                                     |
| enableDhcp   | check the box for yes                                                                                        |
| ipVersion    | 4                                                                                                            |
| vlanId       | Value between 2 and 4000, or empty for automatic assignment                                                  |

:::info

Repeat for each region where your private instances are present.

:::

To verify the details of your Gateway:

<Api version="v1" section="/cloud/project" method="GET" route={"/cloud/project/\{serviceName\}/region/\{regionName\}/gateway"} regions={["us"]} />

Leave `subnetId` blank to list all Gateways in the specified region.

<Tab label="OVHcloud CLI">

Use the OVHcloud CLI to create a private network with a Gateway. Set your cloud project with `--cloud-project <project_id>` or configure it in your profile.

**Create a Gateway with a new private network:**

```bash
ovhcloud cloud network gateway create <region> \
  --cloud-project <project_id> \
  --name my-gateway \
  --model s \
  --network-name my-network \
  --subnet-cidr 192.168.1.0/24 \
  --subnet-enable-dhcp \
  --wait
```

**Create a Gateway in an existing private network:**

```bash
ovhcloud cloud network gateway create <region> \
  --cloud-project <project_id> \
  --name my-gateway \
  --model s \
  --network-id <network_id> \
  --subnet-id <subnet_id> \
  --wait
```

Available models: `s`, `m`, `l`, `xl`, `2xl`, `3xl`.

:::info

Only single-region private networks are supported by Gateway.

:::

**Step 3 — Create the router and configure the Gateway**

```
openstack router create my_router 
 
openstack router add subnet my_router my_subnet
 
openstack router set --external-gateway Ext-Net --qos-policy QOS_ID_OF_YOUR_CHOICE my_router
```

If you omit the `--qos-policy` parameter the "small" quality of service will be applied.

<Tab label="Terraform">

Before proceeding, consult our [How to Use Terraform](https://support.us.ovhcloud.com/hc/en-us/articles/15974268257299) guide.

Create a Terraform file (e.g., `private_network_gateway.tf`) with the following information:

```python
# Create a Private Network
resource "ovh_cloud_project_network_private" "mypriv" {
  service_name  = "my_service_name"  # Replace with your OVHcloud project ID
  vlan_id       = "0"             # VLAN ID (usually 0)
  name          = "mypriv"
  regions       = ["US-EAST-VA-1"]
}
# Create a private subnet
resource "ovh_cloud_project_network_private_subnet" "myprivsub" {
  service_name  = ovh_cloud_project_network_private.mypriv.service_name
  network_id    = ovh_cloud_project_network_private.mypriv.id
  region        = "US-EAST-VA-1"
  start         = "10.0.0.2"
  end           = "10.0.255.254"
  network       = "10.0.0.0/16"
  dhcp          = true
}
# Create a custom gateway
resource "ovh_cloud_project_gateway" "gateway" {
  service_name = ovh_cloud_project_network_private.mypriv.service_name
  name         = "my-gateway"
  model        = "s"  # Gateway model ("s" for small, "m" for medium, etc.)
  region       = ovh_cloud_project_network_private_subnet.myprivsub.region
  network_id   = tolist(ovh_cloud_project_network_private.mypriv.regions_attributes[*].openstackid)[0]
  subnet_id    = ovh_cloud_project_network_private_subnet.myprivsub.id
}
```

You can create your resources by entering the following command:

```
terraform apply
```
