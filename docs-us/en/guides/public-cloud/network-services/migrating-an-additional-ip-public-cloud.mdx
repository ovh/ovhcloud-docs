# Migrating an Additional IP (Public Cloud)

**Learn how to migrate an Additional IP from one OVHcloud Public Cloud instance to another.**

|                                                                                                                                                                                    |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Since October 6th, 2022 our service "Failover IP" is named [Additional IP](https://us.ovhcloud.com/network/additional-ip/). This renaming has no effect on its technical features. |

Being able to migrate IP addresses generally limits or removes the possibility that your service becomes unavailable. For example, you can effectively update a whole website to a new version or you can keep a replicated server active while running maintenance or installing updates on your production server.

 

## Requirements

- at least two [Public Cloud instances](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- an Additional IP address
- access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)

 

## Instructions

From the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/):

1. Select your project from the `Public Cloud` section.
2. In the left-hand menu, open `Public IPs` under **Network**.
3. Click on the `Additional IP` tab.
4. Click on the *more options* `...` button in the row of the Additional IP and select `Update attached instance`.

:::info

In this example, the Additional IP address routed to "Echo" will be migrated to "Bravo".

:::

![PCI\_network\_additionalIP\_migrate01\*\*\*.png](/images/public-cloud/network-services/migrating-an-additional-ip-public-cloud/24245480979731.png)

 

Click on the drop-down menu to choose the destination instance from the list.

Confirm by clicking on `Attach`.

![PCI\_network\_additionalIP\_migrate02\*\*.png](/images/public-cloud/network-services/migrating-an-additional-ip-public-cloud/24245488187155.png)

 

After a few seconds, the Control Panel will be updated and a confirmation message will be displayed if the migration was done successfully.

![PCI\_network\_additionalIP\_migrate03\*\*.png](/images/public-cloud/network-services/migrating-an-additional-ip-public-cloud/24245481020819.png)

:::info

The Additional IP can be configured on the destination server before or after carrying out the migration. If it is preconfigured, it will begin to respond as soon as the routing operation is completed.

:::
