# Dashboards - Tutorial: How to use the Grafana® API

**Learn how to configure Grafana® to use the API and how to make calls to the exposed API.**

 

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- A Dashboards service running on your OVHcloud Public Cloud project (see [this guide](/guides/public-cloud/databases/getting-started))1

 

## Instructions

### Create a Grafana[®](#go-further) service account

From the Grafana® home screen, select `Administration`, `Users and access`, then `Service` Accounts.

Click `Add Service Account`.

![Service accounts - Dashboards tutorial use Grafana API](/images/public-cloud/data-analytics/dashboards-tutorial-use-grafana-api/service-accounts.png)

Create a new service account `sa-editor` with the role `Editor`.

Click `Create`.

![Create service account](/images/public-cloud/data-analytics/dashboards-tutorial-use-grafana-api/create-service-account.png)

Click on `Add service account token`:

![Service acount details](/images/public-cloud/data-analytics/dashboards-tutorial-use-grafana-api/service-acount-details.png)

Enter the name of the desired token, `grafana-sa-token-editor`, and click on `Generate token`:

![Add token - Dashboards tutorial use Grafana API](/images/public-cloud/data-analytics/dashboards-tutorial-use-grafana-api/add-token.png)

Copy the generated token.

:::warning

**NOTE:** After closing the pop-up, you will no longer be able to display the token!

:::

![Service token - Dashboards tutorial use Grafana API](/images/public-cloud/data-analytics/dashboards-tutorial-use-grafana-api/service-token.png)

The created token appears in the tokens list:

![Service acount details token](/images/public-cloud/data-analytics/dashboards-tutorial-use-grafana-api/service-acount-details-token.png)

 

### Create a folder

Before using the Grafana® API, you must have at least one folder on your Dashboard. To create one, click `Dashboards` in the left-hand navigation menu. Then click `New` and select `New folder`.

![New - Dashboards tutorial use Grafana API](/images/public-cloud/data-analytics/dashboards-tutorial-use-grafana-api/new.png)

Give your folder a name, then click `Create`.

![New folder - Dashboards tutorial use Grafana API](/images/public-cloud/data-analytics/dashboards-tutorial-use-grafana-api/new-folder.png)

You are ready to use this token with the Grafana® API.

 

### Use the Grafana® API

:::info

Detailed instructions on how to use the API and the possible actions can be found in the [official documentation](https://grafana.com/docs/grafana/latest/developers/http_api/).

:::

:::warning

**NOTE:** Don't forget to set the `Authorized IP addresses` in the Grafana® configuration. See our [Configure your Dashboards instance to accept incoming connections](/guides/public-cloud/data-analytics/dashboards-configure-dashboards-instance-accept-incoming-connections) guide for more details.

:::

To send a request to the API, you must use the previously created token and set it in the request header as a "Bearer token":

```bash
export GRAFANA_API_TOKEN=042footoken420

curl -H "Authorization: Bearer $GRAFANA_API_TOKEN" https://grafana-xxxxxxxxx-yyyyyyyyy.database.cloud.ovh.us/api/folders    
[
    {
        "id":11,
        "uid":"HnDCAp-4k",
        "title":"foo 1"
    },
    {
        "id":5,
        "uid":"cb_S6Pb4k",
        "title":"foo 2"
    },
    {
        "id":9,
        "uid":"Xav55taVk",
        "title":"foo 3"
    },
    {
        "id":10,
        "uid":"AH8sApaVz",
        "title":"foo 4"
    }
]
```

:::tip

**Congratulations!** You can now use all the power of the Grafana® API.

:::
