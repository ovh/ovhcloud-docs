# AI Tools - Remote SSH Connection

This tutorial covers the process of starting a job using Visual Studio Code Remote via SSH.

 

## Requirements

- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- An AI Notebook **or** AI Training project created inside a [Public Cloud project](https://us.ovhcloud.com/public-cloud/)
- An [AI user](https://support.us.ovhcloud.com/hc/en-us/articles/34504142321171)
- The [OVHcloud AI CLI](https://support.us.ovhcloud.com/hc/en-us/articles/34692499017619) installed on your computer

:::warning

**NOTE:** The deployed image needs to contain the `bash` binary and a glibc-based Linux (Ubuntu / Debian).

:::

 

## Instructions

### Installation

1. Install an [OpenSSH-compatible SSH client](https://code.visualstudio.com/docs/remote/troubleshooting#_installing-a-supported-ssh-client) if one is not already present.
2. Install [Visual Studio Code](https://code.visualstudio.com/).
3. Install the [Remote Development extension pack](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.vscode-remote-extensionpack).

 

### Generate an SSH keypair

If you don’t already have an SSH key, you will need to create one. To do so, open a Terminal / PowerShell, and run the key generation command:

```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```

:::info

- `-t ed25519` creates a modern, secure key (recommended).
- `-C` lets you add a label (usually your email) to identify the key.

:::

This will create a private key (e.g., `id_ed25519`, not to share) and a public key (e.g., `id_ed25519.pub`) in your `~/.ssh/` directory.

 

### Specify the SSH key during AI Notebook or AI Training job creation

<Tab label="Using ovhai CLI">

To follow this part, make sure you have installed the [ovhai CLI](https://support.us.ovhcloud.com/hc/en-us/articles/34692499017619) on your computer or on an instance.

When creating your AI resource using the `ovhai` CLI, specify the SSH public key using the `--ssh-public-keys` option, or `-s` shortcut:

```bash
ovhai job run <job_image> \
  --gpu <nb-gpus> \
  --ssh-public-keys ~/.ssh/id_ed25519.pub
```

 

```bash
ovhai job run --gpu <nb-gpus> -s ~/.ssh/id_ed25519.pub ovhcom/ai-training-tensorflow:2.3.0
```

Once the job is `Running`, you can see the `sshUrl` with *job get*:

```bash
ovhai job get <job-id>
```

Once your job is created, regardless of the method chosen, you will be able to copy your job id (e.g., `bfa1d77a-9746-4128-9974-f94139937927`), which will be needed in the following steps.

:::warning

**NOTE:** In order to work, the deployed image needs to contain the `bash` binary and a glibc-based Linux (Ubuntu / Debian).

### Verify you can connect to the SSH host

Verify you can connect to the SSH host by running the following command from a terminal / PowerShell window replacing `<job-id>` with the ID of your job:

```bash
ssh <job-id>@us-east-va.ai.cloud.ovh.us

Welcome to OVHcloud AI Training Jobs SSH
job-0d916855-1cd4-4b66-8803-b4782bc13902:~$
```

 

### Configure VSCode Remote Connection

In Visual Studio Code, click on the `Remote Explorer` icon.

![PaaS\_AI\_training\_connectVScode01.png](/images/public-cloud/ai-machine-learning/ai-tools-remote-ssh-connection/37109367756051.png)

From there, click the gear icon on the SSH feature to access the SSH configuration file for VSCode, typically located at `~/.ssh/config`, and open it.

![PaaS\_AI\_training\_connectVScode02.png](/images/public-cloud/ai-machine-learning/ai-tools-remote-ssh-connection/45044597380243.png)

Add the following section for your new host:

```
Host my_ai_training_job
HostName <region>.ai.cloud.ovh.us # Adapt to your resource location (gra, bhs)
User bfa1d77a-9746-4128-9974-f94139937927 # ID of your AI Training Job or AI Notebook
IdentityFile C:\Path\To\id_ed25519 # Path to your private key file (not .pub)
```

Save the `config` file. Then refresh remotes by clicking on this icon:

![PaaS\_AI\_training\_connectVScode03.png](/images/public-cloud/ai-machine-learning/ai-tools-remote-ssh-connection/45044597383443.png)

Your resource should now appear in the SSH menu on the left. Connect to it by clicking the arrow next to your resource. VSCode will restart to connect to your remote resource:

![PaaS\_AI\_training\_connectVScode04.png](/images/public-cloud/ai-machine-learning/ai-tools-remote-ssh-connection/45044613990419.png)

If the connection is well established, you should see this message in the bottom-left corner of VSCode:

![PaaS\_AI\_training\_connectVScode05.png](/images/public-cloud/ai-machine-learning/ai-tools-remote-ssh-connection/45044613992339.png)

 

### Develop and Run Your Code

Once connected, you can start developing and running your code in the default `/workspace` folder, by clicking on the `Open folder` blue button, and select `/workspace`.

![PaaS\_AI\_training\_connectVScode06.png](/images/public-cloud/ai-machine-learning/ai-tools-remote-ssh-connection/45044613995283.png)

You can also open a terminal and run commands from it. Enjoy!

![PaaS\_AI\_training\_connectVScode04.png](/images/public-cloud/ai-machine-learning/ai-tools-remote-ssh-connection/37109337003923.png)
