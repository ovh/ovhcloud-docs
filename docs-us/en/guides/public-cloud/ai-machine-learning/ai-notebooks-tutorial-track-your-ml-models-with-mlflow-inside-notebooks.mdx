# AI Notebooks - Tutorial - Track your ML models with MLflow inside notebooks

**Learn how to integrate [MLflow](https://mlflow.org/) inside AI Notebooks to track and compare your Machine Learning models.**

**MLflow** is an open-source platform for *Machine Learning workflow management*. You can use this tool for ML model tracking and versioning but also storage and deployment.

- **How to use MLflow inside AI Notebooks?**

![PaaS\_AI\_notebooks\_MLflow01.png](/images/public-cloud/ai-machine-learning/ai-notebooks-tutorial-track-your-ml-models-with-mlflow-inside-notebooks/38475547506451.png)

For this purpose, we will compare **image classification** models: [EfficientNets](https://paperswithcode.com/method/efficientnet).

:::info

EfficientNet models are pre-trained on the [ImageNet](https://www.image-net.org/) dataset.

:::

In this context, several EfficientNet models will be trained on the same dataset: ([stanford\_dogs](https://www.tensorflow.org/datasets/catalog/stanford_dogs#:~:text=The%20Stanford%20Dogs%20dataset%20contains,training%20and%208580%20for%20testing.)). The **Stanford Dogs** dataset contains images of 120 breeds of dogs from around the world.

The different models will be tracked and compared based on their performance thanks to **MLflow**:

- EfficientNet-b0
- EfficientNet-b1
- EfficientNet-b2
- EfficientNet-b3
- EfficientNet-b4
- EfficientNet-b5
- EfficientNet-b6
- EfficientNet-b7

## Instructions

You can launch the notebook from the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) or via the [ovhai CLI](https://support.us.ovhcloud.com/hc/en-us/articles/34697540152723).

 

### Launching a Jupyter notebook with "TensorFlow" via UI (Control Panel)

To launch your notebook from the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/), refer to the following steps.

 

#### Code editor

Choose the `Jupyterlab` code editor.

 

#### Framework

In this tutorial, the `TensorFlow` framework is used. You can choose the `2.12` version: `tf2.12-py311-cudaDevel11.8`.

 

#### Resources

Using GPUs is recommended to train the **EfficientNet** models.

:::info

Here, using `1 GPU` is sufficient.

:::

 

### Launching a Jupyter notebook with "TensorFlow" via CLI

*If you have not used our CLI yet, follow [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/34692499017619) to install it.*

To launch your notebook with the OVHcloud AI CLI, choose the `jupyterlab` editor and the `tensorflow` framework.

To access the different versions of `tensorflow` available, run the following command:

```console
ovhai capabilities framework get tensorflow -o yaml
```

:::info

Here, you can use the version `2.12` of TensorFlow (`tf2.12-py311-cudaDevel11.8`).

:::

You will also need to choose the number of GPUs to use in your notebook, using `<nb-gpus>`.

To launch your notebook, run the following command:

```console
ovhai notebook run tensorflow jupyterlab \
        --name <notebook-name> \
        --framework-version tf2.12-py311-cudaDevel11.8 \
        --gpu <nb-gpus>
```

You can then reach your notebook’s URL once the notebook is running.

 

### Accessing the notebooks

Once our [AI examples repository](https://github.com/ovh/ai-training-examples/) has been cloned in your environment, find the fine-tuning notebook tutorial by following this path: `ai-training-examples` > `notebooks` > `go-further` > `mlflow` > `notebook-tutorial-mlflow-integration.ipynb`.

A preview of this notebook can be found on GitHub [here](https://github.com/ovh/ai-training-examples/blob/main/notebooks/go-further/mlflow/notebook-tutorial-mlflow-integration.ipynb).
