# Managing Users and Projects in Managed Private Registry (Harbor)

**Learn how to manage users and projects on your OVHcloud Managed Private Registry service.**

OVHcloud Managed Private Registry service provides you with a managed Harbor, an authenticated Docker registry where you can privately store your Docker images.

 

## Requirements

- an OVHcloud Managed Private Registry (see the [creating a private registry](https://support.us.ovhcloud.com/hc/en-us/articles/19464979390099) guide for more information)
- access to the Harbor UI to operate the private registry (see the [connecting to the UI](https://support.us.ovhcloud.com/hc/en-us/articles/19464177566227) guide for more information)

 

## Instructions

Using the Harbor UI, you can manage projects, users, and rights on your private registry.

### Creating a new project

A project in Harbor contains all repositories of an application. No images can be pushed to Harbor before the project is created.

There are two types of projects in Harbor:

- Public: All users can read from a public Harbor project.
- Private: Only users with proper privileges can read from this project.

Let's create a private project:

1. Create a new project on Harbor UI by clicking `+ NEW PROJECT`.

   ![manageusers01.png](/images/public-cloud/containers-orchestration/managing-users-and-projects-in-managed-private-registry-harbor/19534464499859.png)

2. Call it *private*, leave the public checkbox unchecked, and click `OK`.

:::info

Keep `-1` for the storage quota if you don't want limitations.

:::

![manageusers02.png](/images/public-cloud/containers-orchestration/managing-users-and-projects-in-managed-private-registry-harbor/19534495724819.png)

 

After the project is created, you can browse repositories, helm charts, members, labels, scanner, policy, robot accounts, webhooks, logs, and configuration using the navigation tabs.

![manageusers03.png](/images/public-cloud/containers-orchestration/managing-users-and-projects-in-managed-private-registry-harbor/19534697870611.png)

 

### Creating a new user and giving it rights to the *private* project

Now you're going to create a new user and give him developer rights over the *private* project.

1. Go to the `Users` section of Harbor UI and click on `+ NEW USER`.

   ![manageusers04\*.png](/images/public-cloud/containers-orchestration/managing-users-and-projects-in-managed-private-registry-harbor/22983945148435.png)

2. Add a new *private-user* user. For the e-mail domain, use the domain found in the URL of your Harbor UI. Click `OK`.

   ![manageusers05\*.png](/images/public-cloud/containers-orchestration/managing-users-and-projects-in-managed-private-registry-harbor/22983963865747.png)

3. The new user is now visible in your Harbor UI.

   ![manageusers06\*.png](/images/public-cloud/containers-orchestration/managing-users-and-projects-in-managed-private-registry-harbor/22983963868051.png)

4. Go back to the `Projects` section and choose the `private` project.

   ![manageusers07A.PNG](/images/public-cloud/containers-orchestration/managing-users-and-projects-in-managed-private-registry-harbor/22609372787987.png)

5. Select the `Members` tab and click on `+ USER`.

   ![manageusers07B.png](/images/public-cloud/containers-orchestration/managing-users-and-projects-in-managed-private-registry-harbor/22609372792211.png)

6. Add the *private-user* as member of the project, and give him a *Developer* role.

   ![manageusers08.png](/images/public-cloud/containers-orchestration/managing-users-and-projects-in-managed-private-registry-harbor/19535437976211.png)

The *private-user* is now a member of the *private* project.

![manageusers09.png](/images/public-cloud/containers-orchestration/managing-users-and-projects-in-managed-private-registry-harbor/19535437986067.png)
