# Scanning Docker Images for Vulnerabilities with OVHcloud Managed Private Registry (Harbor)

**Learn how to activate the vulnerabilities scanner and manually scan an image in an OVHcloud Managed Private Registry service.**

OVHcloud Managed Private Registry service is a composite cloud-native registry that supports both container image management and [Helm](https://helm.sh/) [chart](https://helm.sh/docs/topics/charts/) management.

 

## Before you begin

This tutorial assumes that you already have a working OVHcloud Managed Private Registry and you have followed the guides on [creating a private registry](https://support.us.ovhcloud.com/hc/en-us/articles/19464979390099), [connecting to the UI](https://support.us.ovhcloud.com/hc/en-us/articles/19464177566227), [managing users and projects](https://support.us.ovhcloud.com/hc/en-us/articles/19532505224211) and [creating and using private images](https://support.us.ovhcloud.com/hc/en-us/articles/19618059634579).

You should have at least one image in your Private Registry:

![scandocker01.png](/images/public-cloud/containers-orchestration/scanning-docker-images-for-vulnerabilities-with-ovhcloud-managed-private-registr/19607682426771.png)

 

## Instructions

Using the Harbor UI, you can scan your images on your private registry.

 

### Check that you have enabled a vulnerability scanner

By default, when you create a Private Registry in order to enable a vulnerabilities scanner you need to choose a `M` or `L` plan.

:::info

With the `M` and `L` plans, OVHcloud installs and maintains a vulnerability scanner for you: [Trivy](https://aquasecurity.github.io/trivy/).

:::

To verify if you have a vulnerability scanner in your private registry, go to `Interrogation Services` in the side navigation bar.

As you can see, Trivy is installed and ready to use.

If you want to manually add a vulnerability scanner, you can also do it with the `New Scanner` button. However, it will not be updated and maintained by OVHcloud.

![scandocker02.png](/images/public-cloud/containers-orchestration/scanning-docker-images-for-vulnerabilities-with-ovhcloud-managed-private-registr/19607694629523.png)

 

### Scan a Docker image manually

You can manually scan a Docker image. To do that, access your project, select an image, and click on `Scan`.

![scandocker03.png](/images/public-cloud/containers-orchestration/scanning-docker-images-for-vulnerabilities-with-ovhcloud-managed-private-registr/19607682432403.png)

 

The scanner starts scanning the image.

![scandocker04.png](/images/public-cloud/containers-orchestration/scanning-docker-images-for-vulnerabilities-with-ovhcloud-managed-private-registr/19607682437267.png)

 

The number of vulnerabilities is displayed.

![scandocker05.png](/images/public-cloud/containers-orchestration/scanning-docker-images-for-vulnerabilities-with-ovhcloud-managed-private-registr/19607682440723.png)

 

When you hover over the vulnerabilities column, a chart with the vulnerabilities' severity is displayed.

![scandocker06.png](/images/public-cloud/containers-orchestration/scanning-docker-images-for-vulnerabilities-with-ovhcloud-managed-private-registr/19607694646547.png)

 

Click on the image ID to display all vulnerabilities, ranked by severity.

![scandocker07.png](/images/public-cloud/containers-orchestration/scanning-docker-images-for-vulnerabilities-with-ovhcloud-managed-private-registr/19607694652307.png)

 

#### Scan all the images

You can also scan all your images manually in your private registry.

To do that:

1. Click `Administration` in the side navigation menu.
2. Select `Interrogation Services`.
3. Go to the `Vulnerability` tab.
4. Click `Scan Now`.

![scandocker08\*.png](/images/public-cloud/containers-orchestration/scanning-docker-images-for-vulnerabilities-with-ovhcloud-managed-private-registr/19607694662419.png)

 

### Scan all images regularly

You can schedule a scan:

- hourly
- daily
- weekly
- when you want (enter as a cron format)

For that, select the scheduling and click on the `Save` button.

![scandocker09.png](/images/public-cloud/containers-orchestration/scanning-docker-images-for-vulnerabilities-with-ovhcloud-managed-private-registr/19607682468371.png)
