# Managing OpenStack users

**Learn how to manage OpenStack users in the OVHcloud Control Panel.**

Access to Horizon and the OpenStack APIs is established via username/password pairs called "OpenStack users". You can create as many OpenStack users as needed and assign them various access permissions.

 

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)

 

## Instructions

### Creating an OpenStack user

Log in to the OVHcloud Control Panel and open your `Public Cloud` project. Click on `Users & Roles` in the left-hand menu under **Project Management**.

Click on the button `Create User`.

![openstack\_users01.png](/images/public-cloud/cross-functional/managing-openstack-users/20700611772947.png)

The user description is not the username for the OpenStack user but a descriptive term to help you organize users and their permissions. Enter a description and click on `Next`.

![openstack\_users02.png](/images/public-cloud/cross-functional/managing-openstack-users/20700611793683.png)

Now you can select user roles representing the permissions the user shall have.

For each box checked, the user will gain access privileges according to the table below.

![openstack\_users03.png](/images/public-cloud/cross-functional/managing-openstack-users/20719262149267.png)

Click on `Confirm` to create the OpenStack user.

![openstack\_users04.png](/images/public-cloud/cross-functional/managing-openstack-users/20700619446803.png)

The username and password will be automatically generated and displayed in your Control Panel. Be sure to save the password shown in the green message box to a password manager at this time. The password cannot be recovered afterward.

![openstack\_users05.png](/images/public-cloud/cross-functional/managing-openstack-users/20719262156563.png)

You can edit the roles of a user at any time by clicking the *more options* `...` button and selecting `Edit roles`. The `Show role matrix` button will display the access privileges of each role.

![openstack\_users07.png](/images/public-cloud/cross-functional/managing-openstack-users/20719255171475.png)

With the OpenStack user created, you can use its credentials to log into the [Horizon interface](https://support.us.ovhcloud.com/hc/en-us/articles/20719718436115) by clicking on the link `Horizon` in the left-hand menu.

 

 

### Change an OpenStack user password

You can always create a new password by clicking on the *more options* `...` button and selecting `Generate a password`.

![openstack\_users06.png](/images/public-cloud/cross-functional/managing-openstack-users/20719255168915.png)

If you would like to choose your new password, you can do so from the [Horizon interface](https://support.us.ovhcloud.com/hc/en-us/articles/20719718436115).

Select your `username` in the upper right corner and then `⛭Settings` .

![PCI\_compute\_openstack\_users10\*.png](/images/public-cloud/cross-functional/managing-openstack-users/40155861346835.png)

Select `Change Password` from the left-hand menu. Type in your current password and the new password you wish to use.

:::info

When you change your password, please ensure that it meets the following criteria:

- The password must contain a minimum of eight characters.
- The password must contain a maximum of 30 characters.
- The password must contain at least one upper-case letter.
- The password must contain at least one lower-case letter.
- The password must contain at least one number.
- The password must only contain letters and numbers.

:::

When you have chosen your new password, click `Change`.

![PCI\_compute\_openstack\_users11\*.png](/images/public-cloud/cross-functional/managing-openstack-users/40155861349523.png)

 

### Deleting an OpenStack user

You can remove an OpenStack user in the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub). After clicking `Public Cloud` from the top navigation menu, click on `Users & Roles` in the left-hand menu under **Project Management**.

![openstack\_users08.png](/images/public-cloud/cross-functional/managing-openstack-users/20719262170387.png)

Click on the *more options* `...` button in the user's row and select `Delete`.

:::warning

**NOTE:** Deleting a user is permanent and will invalidate all associated tokens, even those with an expiry date not yet exceeded.

:::

![openstack\_users09.png](/images/public-cloud/cross-functional/managing-openstack-users/20719262174611.png)
