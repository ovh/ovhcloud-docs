# Introducing Horizon

**Discover the main sections of the Horizon interface.**

The Horizon interface, natively offered with OpenStack, has been adapted by OVHcloud to offer additional features than those available in the OVHcloud Control Panel.

 

## Requirements

- A [Public Cloud project](https://support.us.ovhcloud.com/hc/en-us/articles/360002245784) in your OVHcloud account

- **\[Optional since September 2023]** An [OpenStack user](https://support.us.ovhcloud.com/hc/en-us/articles/360008644539) created in your project. This step is optional because we have deployed Single Sign-On (SSO) authentication between the OVHcloud Control Panel and Horizon.

  :::info

  A user must log in using the OpenStack credentials to manage Local Zones.

  :::

 

## Instructions

### Logging in to OpenStack Horizon

Open the [Horizon login page](https://horizon.cloud.ovh.us/auth/login/) and enter the [OpenStack user credentials](https://support.us.ovhcloud.com/hc/en-us/articles/360008644539) previously created, then click on `Connect`.

You can also click on `Horizon` in the left-hand menu under "Management Interfaces" after opening your `Public Cloud` project in the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub).

 

### Datacenter region selection

Unlike the OVHcloud Control Panel, Horizon separates your services according to their region. You can choose the region from the menu in the top left-hand corner:

![horizon\_selectRegion.png](/images/public-cloud/cross-functional/introducing-horizon/41164240820883.png)

 

### Left side menu

This menu allows you to quickly navigate through the project and its various features.

![horizon\_intro02.png](/images/public-cloud/cross-functional/introducing-horizon/20722237838355.png)

#### Overview

- **Limit Summary**

Horizon provides a summary of quotas, which allows you to see the used and available resources for your projects:

![horizon\_intro03.png](/images/public-cloud/cross-functional/introducing-horizon/20722237854355.png)

- **Usage Summary**

Next is a summary of the use of your project instances. The search period can be customized to restrict this summary to a desired period.

![horizon\_intro04.png](/images/public-cloud/cross-functional/introducing-horizon/20722232306579.png)

- **Usage**

A summary of your usage is also available. This is a summary of the various services associated with the project, such as the list of instances.

The summary is downloadable in CSV format, which allows you to extract the information so that you can analyze it via other tools. Simply click on `Download CSV Summary`.

![horizon\_intro05.png](/images/public-cloud/cross-functional/introducing-horizon/20722232312851.png)

 

#### Compute

- **Instances**

Use this page to list and manage instances. For example, you can create new instances, pause them, access the instance console, and much more.

- **Images**

Use this menu to list and manage images, i.e. templates and snapshots associated with your project.

- **Key Pairs**

Here you can list and create your SSH keys for connecting to your instances.

- **Server Groups**

This feature allows you to group servers according to a certain policy.

 

#### Volumes

Use this menu to list and manage volumes, backups, snapshots, groups, and group snapshots.

![horizon\_intro06.png](/images/public-cloud/cross-functional/introducing-horizon/20722232320531.png)

 

#### Network

List and manage your networks, routers, security groups, load balancers, and floating IPs here.

![horizon\_intro07.png](/images/public-cloud/cross-functional/introducing-horizon/20722232322707.png)

 

#### Identity

Use this menu to list information about your projects.

![horizon\_intro08.png](/images/public-cloud/cross-functional/introducing-horizon/20722232332819.png)

 

### User menu

In the top right-hand corner of the Horizon interface, a user menu allows you to:

- Change interface display settings.
- Access Horizon and OpenStack guides.
- Download an OpenRC file containing your user IDs.
- Log out of the Horizon interface.

![horizon\_intro09.png](/images/public-cloud/cross-functional/introducing-horizon/20722232341651.png)
