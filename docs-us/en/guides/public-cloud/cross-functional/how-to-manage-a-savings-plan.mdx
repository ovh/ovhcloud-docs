# How to manage a Savings Plan

This guide provides a clear, detailed method for creating and updating Savings Plans for your resources. You will discover how to manage your Savings Plans using the OVHcloud Control Panel, the OVHcloud API, and Terraform. By following this guide, you will be able to:

- Create a Savings Plan for your resources.
- Modify a Savings Plan.
- Automate the management of Savings Plans via the API or Terraform for greater efficiency and flexibility.

:::warning

**NOTE:** Beginning October 1, 2026, local storage and public IP are not covered by Savings Plans.

:::

 

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- Access to the [OVHcloud API](https://api.us.ovhcloud.com/) (create your credentials using [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/360018130839))
- Being familiar with [Terraform](https://support.us.ovhcloud.com/hc/en-us/articles/15974268257299) if you intend to use it
- Being familiar with the principles of [Savings Plans](https://us.ovhcloud.com/public-cloud/savings-plan/)

 

## Instructions

### OVHcloud Control Panel Access

- **Direct link:** [Public Cloud Projects](https://manager.us.ovhcloud.com/#/public-cloud/pci/projects/)
- **Navigation path:** `Public Cloud` > Select your project

Click on `Savings Plans` in the left-hand navigation bar under **Settings**.

 

### Create a Savings Plan

You can create your Savings Plan for the type of resource you want by following these steps:

<Tabs>

<Tab label="Via the OVHcloud Control Panel">

Click the `Create a Savings Plan` button.

![PCI\_savingsPlans\_onboarding.PNG](/images/public-cloud/cross-functional/how-to-manage-a-savings-plan/50984615241491.png)

On the next screen:

- Select a service
- Choose a deployment mode
- Choose model
- Specify the number of resources
- Select the subscription period
- Select a date
- Enter a name

When you have configured all of your options, click `Create a Subscription Plan`.

In the pop-up window, confirm all of your selections, agree to the terms of service, and click `Create a Savings Plan`.

</Tab>

<Tab label="Via Terraform">

To create a Savings Plan, you will need at least five pieces of information:

- The ID of your Public Cloud project
- The flavor concerned by your Savings Plan
- The duration of your Savings Plan (in standard ISO 8601 format)
- The number of resources concerned
- The name of your Savings Plan

In our example, we are going to create a Savings Plan for 10 instances of type **b3-8**, for a duration of 1 month. Add the following lines to a file named `savings_plan.tf`:

```
# creation of a Savings Plan
resource "ovh_savings_plan" "Savings_plan_simple_b3_8" {
  service_name = "<public cloud project ID>"
  flavor = "b3-8" # instance type or rancher/rancher_standard or rancher_ovhcloud_edition
  period = "P1M" #  P mandatory, number for duration and M for ‘month’, Y for ‘year’ ...
  size = 10
  display_name = "Savings_plan_simple_b3_8"
  auto_renewal = true # optional, ‘true’ to activate.
}
```

You can create your Savings Plan by entering the following command in your console:

```
terraform apply
```

</Tab>

</Tabs>

 

### Modifying a Savings Plan

<Tabs>

<Tab label="Via the OVHcloud Control Panel">

In the OVHcloud Control Panel, clicking the *more options* `⋮` button to the right of your plan gives you the option to:

- Edit the **name** of the Savings Plan,
- **Activate/deactivate** its automatic renewal, and
- **Create an instance** to be included in your plan.

![PCI\_savingsPlans\_planList.PNG](/images/public-cloud/cross-functional/how-to-manage-a-savings-plan/50984615242643.png)

</Tab>

<Tab label="Via the OVHcloud API">

First, find the ID of your service in the list of your services, which can be obtained via the following endpoint:

<Api version="v1" section="/services" method="GET" route={"/services"} regions={["us"]} />

You will obtain a list containing the ID of your services as follows:

![PCI\_savingsPlans\_API\_serviceList.PNG](/images/public-cloud/cross-functional/how-to-manage-a-savings-plan/50985371488659.png)

You can use this route to check whether the service corresponds to the Public Cloud project concerned:

<Api version="v1" section="/services" method="GET" route={"/services/\{serviceId\}"} regions={["us"]} />

You'll get a list containing the details of your service as follows. Check that it's the right project, using the `vars.value` field:

![PCI\_savingsPlans\_API\_serviceDetails.PNG](/images/public-cloud/cross-functional/how-to-manage-a-savings-plan/50985386973203.png)

You can find the ID of your Savings Plan in the list of your Savings Plans obtained via this endpoint:

<Api version="v1" section="/services" method="GET" route={"/services/\{serviceId\}/savingsPlans/subscribed"} regions={["us"]} />

You get a list of Savings Plans as follows:

![PCI\_savingsPlans\_API\_planDetails.PNG](/images/public-cloud/cross-functional/how-to-manage-a-savings-plan/50985371494163.png)

Then look for the Savings Plan concerned in the list and copy its **ID**.

<details>
<summary>Changing the name of a Savings Plan</summary>

To change the name of a Savings Plan, use the following endpoint:

<Api version="v1" section="/services" method="PUT" route={"/services/\{serviceId\}/savingsPlans/subscribed/\{savingsPlanId\}"} regions={["us"]} />

The **savingsPlanId** corresponds to the ID of your previously copied Savings Plan.

</details>

<details>
<summary>Activate/deactivate automatic renewal of a Savings Plan</summary>

To **activate/disable** the automatic renewal of the Savings Plan, use the following endpoint:

<Api version="v1" section="/services" method="POST" route={"/services/\{serviceId\}/savingsPlans/subscribed/\{savingsPlanId\}/changePeriodEndAction"} regions={["us"]} />

</details>

<details>
<summary>Increase the number of Savings Plan resources</summary>

To increase the number of resources subscribed to your Savings Plan, use this route:

:::info

The number of resources can only be increased.

:::

<Api version="v1" section="/services" method="POST" route={"/services/\{serviceId\}/savingsPlans/subscribed/\{savingsPlanId\}/changeSize"} regions={["us"]} />

</details>

</Tab>

<Tab label="Via Terraform">

Modify your resource in the `savings_plan.tf` Terraform file created earlier.

:::info

Note that only the **service\_name**, **size** and **auto\_renewal** fields can be modified. The **size** can only be increased.

:::

</Tab>

</Tabs>
