# Access and security settings in Horizon

**Learn about the access and security settings available in the OpenStack Horizon interface.**

The OpenStack Horizon interface provides options to configure access to your instances and other services.

For example, you can define security groups to filter incoming and outgoing connections or download an OpenRC file containing the credentials for the OpenStack API.

 

## Requirements

- [Configure user access to Horizon](https://support.us.ovhcloud.com/hc/en-us/articles/360008644539)

 

## Instructions

Log in to [the Horizon interface](https://horizon.cloud.ovh.us/auth/login/).

The access and security settings consist of the following sections, accessible via the left-hand menu:

<Tabs>

<Tab label="API Access(under Project)">

The API Access table lists the service endpoints of the OpenStack API.

To review the access values to use with the API, click on `View Credentials`.

Clicking on the button `Download OpenStack RC File` opens a drop-down menu from which you can choose the appropriate RC file to download.

![PCI\_Compute\_Horizon\_security01\*.png](/images/public-cloud/cross-functional/access-and-security-settings-in-horizon/38273494733715.png)

</Tab>

<Tab label="Key Pairs(under Project > Compute)">

This section allows you to store and manage SSH key pairs. You can simply create and add a public and a private key by clicking on `Create Key Pair`.

If you have an existing key to add, click on `Import Public Key`. In the pop-up window, you can enter a key string or select a key file.

This interface section includes some basic instructions; for more information about SSH keys, please refer to [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/33773177952659).

![PCI\_Compute\_Horizon\_security02\*.png](/images/public-cloud/cross-functional/access-and-security-settings-in-horizon/38273494740627.png)

</Tab>

<Tab label="Security(under Project > Network)">

Security groups are sets of filter rules that are applied to network interfaces. You can use them to manage access to instances by IP addresses and ports.

Add a security group by clicking `Create Security Group`, then apply customized or preset rules to it via the `Manage Rules` button in the table.

![PCI\_Compute\_Horizon\_security03\*.png](/images/public-cloud/cross-functional/access-and-security-settings-in-horizon/38273467568915.png)

</Tab>

</Tabs>
