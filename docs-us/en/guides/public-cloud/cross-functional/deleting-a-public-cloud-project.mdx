# Deleting a Public Cloud Project

**Learn how to delete a Public Cloud project.**

When you no longer need your [Public Cloud](https://us.ovhcloud.com/public-cloud/) project, you can delete it directly from the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub).

When you delete your Public Cloud project, a final invoice is issued for the outstanding amount.

:::warning

**NOTE:** Please note that deleting a project is not the same as deactivating your Public Cloud instances. When you delete a project, the resources contained in it will be permanently lost. This action can not be undone.

:::

 

## Requirements

- A [Public Cloud project](https://us.ovhcloud.com/public-cloud/) in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)

 

## Instructions

Log in to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub) and navigate to your Public Cloud Project via the `Public Cloud` menu.

Open the `Project settings` section under **Project Management** in the left-hand menu.

Click the `Delete project` button.

![manager\_project\_delete.png](/images/public-cloud/cross-functional/deleting-a-public-cloud-project/42592948003603.png)

A confirmation message will appear, informing you about the removal of the project's resources, with the exception of any Additional IP addresses attached. Click `Yes, cancel` to proceed.

![manager\_project\_confirmCancel.png](/images/public-cloud/cross-functional/deleting-a-public-cloud-project/42592902381331.png)

When you click on the button, you will receive a "success" message, but **your project is not deleted yet**.

![manager\_project\_delete\_banner.png](/images/public-cloud/cross-functional/deleting-a-public-cloud-project/42592902386579.png)

:::warning

**NOTE:** The project is not immediately deleted. In situations where this may affect the creation of new projects on accounts with limited project quotas, please [contact our support team](https://support.us.ovhcloud.com/hc/en-us/articles/115001819764) for further assistance.

:::
