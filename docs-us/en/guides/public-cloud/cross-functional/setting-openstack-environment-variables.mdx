# Setting OpenStack Environment Variables

By setting OpenStack environment variables on your desktop, you can use the OpenStack API to manage your infrastructure.

 

## Requirements

- access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/)
- an [OpenStack user account](https://support.us.ovhcloud.com/hc/en-us/articles/360008644539)
- OpenStack [installed on your system](https://support.us.ovhcloud.com/hc/en-us/articles/1500009262762)

 

## Instructions

### Step 1: Retrieve the variables

To retrieve your environment variables, you can download the OpenRC file from the OpenStack user account you have created.

Log in to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) and switch to the `Public Cloud` section. Select your Public Cloud project at the top of the left-hand sidebar.

1. Switch to the `Public Cloud` section.
2. Click on `Users & Roles`.
3. Click on the *more options* `...` button to the right of your user and select `Download OpenStack's RC file`.

![setopenstack01.png](/images/public-cloud/cross-functional/setting-openstack-environment-variables/16936631573907.png)

An OpenRC file corresponds to a specific user and zone. You cannot manage multiple zones in the same file.

 

### Step 2: Set the variables

#### **On Linux**

- Open a terminal, or connect via the user who will be making the OpenStack API calls.
- Load the file’s contents in the current environment. You will then be prompted to enter the Horizon user password.

```bash
source openrc.sh
Please enter your OpenStack Password:
```

As outlined in [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/360008644539), the password is only visible once — when it is created.

If you forget your password, you will need to reset it.

If the CLIs are already installed, check if they are working properly:

```bash
(env)$ openstack server list
+--------------------------------------+------------+--------+-----------------------------------------------+-----------+--------+
| ID                                   | Name       | Status | Networks                                      | Image     | Flavor |
+--------------------------------------+------------+--------+-----------------------------------------------+-----------+--------+
| 8d7c67c0-38e1-4091-88d5-c14844c1f455 | b2-7-gra11 | ACTIVE | Ext-Net=2001:xxxx:xxx:xxx::xxxx, xx.xxx.xx.xx | Debian 12 | b2-7   |
+--------------------------------------+------------+--------+-----------------------------------------------+-----------+--------+
```

 

#### **On Windows**

The OpenRC file is not designed to be launched on Windows.

There are two ways of setting environment variables:

1. You will need to adapt the file by changing certain commands. The **export** part can be replaced with **set**:
   ```bash
   set OS_PASSWORD="Your Horizon user password"
   ```

2) You can set the variables directly via the system settings: Control Panel > System > Advanced System Properties > Environment Variables:

![setopenstack02.png](/images/public-cloud/cross-functional/setting-openstack-environment-variables/16936661871251.png)
