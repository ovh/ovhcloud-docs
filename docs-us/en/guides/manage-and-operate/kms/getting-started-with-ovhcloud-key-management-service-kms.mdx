# Getting started with OVHcloud Key Management Service (KMS)

**Learn the steps you need to take to set up your first Key Management Service (KMS) and to create a key and access certificate.**

 

## Requirements

- An [OVHcloud customer account](https://support.us.ovhcloud.com/hc/en-us/articles/115001286870)

 

## Instructions

### Ordering your KMS

Each KMS is associated with a region, so the keys stored there are guaranteed to stay there. You can order multiple Key Management Services in different regions or the same region.

Since the billing for a KMS is based on the number of keys stored on it, ordering a KMS does not generate billing until keys are created.

You can order a KMS from the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) by going to one of the following menus:

1. In the top navigation bar, choose either `Bare Metal Cloud` or `Hosted Private Cloud`.
2. In the left-hand menu, select `Identity, Security & Operations`, and then `Key Management Service`.
3. Click `Order`.

![manage\_KMS\_quickstart01\*\*.png](/images/manage-and-operate/kms/getting-started-with-ovhcloud-key-management-service-kms/31585345273875.png)

Choose a region for your KMS.

![manage\_KMS\_quickstart02\*.png](/images/manage-and-operate/kms/getting-started-with-ovhcloud-key-management-service-kms/31589701854739.png)

You can then finalize the order in another tab. If it has not opened automatically, the URL is displayed:

![manage\_KMS\_quickstart03\*.png](/images/manage-and-operate/kms/getting-started-with-ovhcloud-key-management-service-kms/31590416352915.png)

After a few seconds, the KMS will be available in your OVHcloud Control Panel.

:::warning

**NOTE:** The *more options* `...` button to the right of your service is where you can cancel that service.

:::

![manage\_KMS\_quickstart04\*.png](/images/manage-and-operate/kms/getting-started-with-ovhcloud-key-management-service-kms/31720961604371.png)

 

### Creating an encryption key

:::tip

Click each tab across the top to view all content.

:::

<Tabs>

<Tab label="Via OVHcloud Control Panel">

You can create an encryption key from the OVHcloud Control Panel by selecting the KMS service you just created, choosing the `Encryption keys` tab, and clicking the `+ Create a key` button.

![manage\_KMS\_quickstart05\*.png](/images/manage-and-operate/kms/getting-started-with-ovhcloud-key-management-service-kms/34923338728211.png)

A form allows you to configure the key and select its type, size, and usage. Click `Confirm` when you have made your selections.

![manage\_KMS\_quickstart06\*.png](/images/manage-and-operate/kms/getting-started-with-ovhcloud-key-management-service-kms/34923316130323.png)

Once the key is created, click on it to access its details. The dashboard displays the cryptographic properties of the key and the actions for renaming, disabling, or deleting it.

To reduce the risk of unwanted deletion, it is required to disable the key before deleting it.

:::warning

**NOTE:** A deleted key is not recoverable and results in the loss of any data encrypted with it. Deletions should be performed with great caution.

:::

![manage\_KMS\_quickstart07\*\*.png](/images/manage-and-operate/kms/getting-started-with-ovhcloud-key-management-service-kms/34923316131475.png)

</Tab>

<Tab label="Via API">

You can create (or import) a key using the following API:

<Api version="v2" section="/okms" method="POST" route={"/okms/resource/\{okmsId\}/serviceKey"} regions={["us"]} />

The API expects the following values:

| **Field**  | **Value**           | **Description**                                                                  |
| ---------- | ------------------- | -------------------------------------------------------------------------------- |
| name       | string              | Key name                                                                         |
| context    | string              | Additional credential to verify key authenticity                                 |
| type       | oct, RSA, EC        | Key type: Byte sequence (oct) for symmetric keys, RSA (RSA), Elliptic Curve (EC) |
| size       | Integer             | Key size - see lookup below                                                      |
| operations | Array               | Key Usage - see lookup below                                                     |
| curve      | P-256, P-384, P-521 | (optional) Cryptographic curve for EC type keys                                  |

 

<details>
<summary>Example of symmetric key creation:</summary>

```json
{
  "name": "My first AES key",
  "context": "project A",
  "type": "oct",
  "size": 256,
  "operations": [
    "encrypt",
    "decrypt"
  ]
}
```

</details>

<details>
<summary>Example of asymmetric key creation:</summary>

```json
{
  "name": "My first RSA key",
  "context": "project A",
  "type": "RSA",
  "size": 4096,
  "operations": [
    "sign",
    "verify"
  ]
}
```

</details>

<details>
<summary>Example of EC key creation:</summary>

```json
{
  "name": "My first EC key",
  "context": "project A",
  "type": "EC",
  "operations": [
    "sign",
    "verify"
  ],
  "curve": "P-256"
}
```

</details>

Depending on the key type, the possible sizes and operations are:

- **Oct**:

  - size: 128, 192, 256

  - operations:

    - encrypt, decrypt
    - wrapKey, unwrapKey

- **RSA**:

  - size: 2048, 3072, 4096
  - operations: sign, verify

- **EC**:

  - size: do not specify
  - curve: P-256, P-384, P-521
  - operations: sign, verify

</Tab>

</Tabs>

 

### Creating an access certificate

To communicate with your KMS, you will need to create an access certificate. This will be used for any interaction with the KMS, either to create encryption keys or to carry out operations with them.

The necessary steps to create an access certificate are available in our [Manage your OKMS access certificate](https://support.us.ovhcloud.com/hc/en-us/articles/45416066039443) guide.

 

### Use the OVHcloud KMS

Once your OVHcloud KMS is set up, there are two different ways to use it:

- Using the [Rest API](https://support.us.ovhcloud.com/hc/en-us/articles/34887531180435), if you want to manually use the API to encrypt or sign your data.
- Using the [KMIP protocol](https://support.us.ovhcloud.com/hc/en-us/articles/34925746801555), if you want to connect any KMIP compatible product with your OVHcloud KMS.
