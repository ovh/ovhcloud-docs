# How to restrict local users from billing information in the OVHcloud Control Panel

## Requirements

- An [OVHcloud Control Panel](https://support.us.ovhcloud.com/hc/en-us/articles/115001286870) account

 

## Instructions

### Create a group with no rights

Navigate to the `Identities` menu in your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/iam/identities/users) and select the `User groups` tab.

Click `Declare a group`.

![identities\_userGroupsTab.png](/images/manage-and-operate/iam/how-to-restrict-local-users-from-billing-information-in-the-ovhcloud-control-pan/47869459880851.png)

Enter a **Group name** (a **Group description** is optional) and set the **Role** to `None`, and then click `Confirm`.

![identities\_addGroup\_none.png](/images/manage-and-operate/iam/how-to-restrict-local-users-from-billing-information-in-the-ovhcloud-control-pan/47869459882771.png)

 

### Assign user(s) to the group

<Tabs>

<Tab label="New users">

In the `Local users` tab, click `Add user`.

![identities\_localUsersTab\_empty.png](/images/manage-and-operate/iam/how-to-restrict-local-users-from-billing-information-in-the-ovhcloud-control-pan/47869474211987.png)

Fill in the fields, select the **Group** you created in the [previous step](https://support.us.ovhcloud.com/hc/en-us/articles/46647300035987#create-a-group-with-no-rights), and click `Confirm`.

![identities\_addUser\_no-access.png](/images/manage-and-operate/iam/how-to-restrict-local-users-from-billing-information-in-the-ovhcloud-control-pan/47869459884307.png)

</Tab>

<Tab label="Existing users">

In the `Local users` tab, click the *more options* `...` button to the right of the user you wish to restrict and select `Update user`.

![identities\_localUsersTab\_moreOptions.png](/images/manage-and-operate/iam/how-to-restrict-local-users-from-billing-information-in-the-ovhcloud-control-pan/47869474221715.png)

On the next screen, select the **Group** you created in the [previous step](https://support.us.ovhcloud.com/hc/en-us/articles/46647300035987#create-a-group-with-no-rights). and click `Confirm`.

![identities\_updateUser\_no-access.png](/images/manage-and-operate/iam/how-to-restrict-local-users-from-billing-information-in-the-ovhcloud-control-pan/47869459886227.png)

</Tab>

</Tabs>

 

### Create the policy

Please follow [this guide](https://support.us.ovhcloud.com/hc/en-us/articles/43234246788755) to create your policy, while taking note of the following modification:

When creating the policy, under the **Identities** heading, link the the **User group** created in the [first step of this guide](https://support.us.ovhcloud.com/hc/en-us/articles/46647300035987#create-a-group-with-no-rights).

 

### Allowing users to see and use your services

To allow your local users to access your services again (without overriding the policy created above), you will need to create one or more new policies and carefully select the **Actions** to authorize.

Below is an example for allowing access to a dedicated server:

1. Select the **Product types** and **Resources** you want your users to be able to read and/or use.

   ![policies\_tutorial\_dedicated-1.png](/images/manage-and-operate/iam/how-to-restrict-local-users-from-billing-information-in-the-ovhcloud-control-pan/47869474222995.png)

2. Scroll down to the **Actions** section and authorize all actions in for the Product type (e.g., Dedicated Server) except `dedicatedServer:notification:receive/billing` under **NOTIFICATION**.

   ![policies\_tutorial\_dedicated-2.png](/images/manage-and-operate/iam/how-to-restrict-local-users-from-billing-information-in-the-ovhcloud-control-pan/47869474230675.png)

:::warning

**NOTE:** If you want to restrict the user from ordering or deleting services, you can unselect those actions from the list. Using CTL+F to search for terms, such as "order," "cancel," "terminate," and "bill," can be useful in finding those actions in the lists.

![policies\_tutorial\_dedicated-3.png](/images/manage-and-operate/iam/how-to-restrict-local-users-from-billing-information-in-the-ovhcloud-control-pan/47869459889939.png)

:::
