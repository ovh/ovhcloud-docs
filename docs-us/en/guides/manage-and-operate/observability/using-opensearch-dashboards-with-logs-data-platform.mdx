# Using OpenSearch Dashboards with Logs Data Platform

**Learn how to unleash the full power of [OpenSearch Dashboards](https://opensearch.org/docs/latest/dashboards/index/) and craft some beautiful Dashboards from your logs.**

After some training you will be able to do this kind of Dashboard:

![operate\_LDP\_vqe\_useOpenSearchAPI01.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/29159086279059.png)

 

## Requirements

- the ability to send logs on a stream you own (see our [Quick Start for Logs Data Platform](https://support.us.ovhcloud.com/hc/en-us/articles/28017122298771) guide)

 

## Instructions

### Create your Stream Alias

To access your logs from OpenSearch Dashboards, you will need to set up an OpenSearch Alias and link it to your Graylog streams. To do so:

1. Log in to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/) and access your Logs Data Platform service.

2. In the **Alias** tab, click on the `+ Add an alias` button.

3. Choose a name and define a description for your alias.

4. Save the entry by clicking the `Save` button.

   ![operate\_LDP\_vqe\_useOpenSearchAPI02.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31515748233619.png)

5) Once the alias has been created, use the *more options* `...` button to the right and select `Attach content to the alias` option.

   ![operate\_LDP\_vqe\_useOpenSearchAPI03\*.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31515748245907.png)

6. Define the Graylog streams you want to associate with your alias.

So now Logs Data Platform knows which stream you want to browse. Now let's configure OpenSearch Dashboards and see if it works!

 

### Access your OpenSearch Dashboards instance

To create your OpenSearch Dashboards instance, click on the OpenSearch Dashboards tab. Click on `Add an instance`, add a description, and click on `Order` to launch the creation of your instance. Your instance will be created and delivered in approximately 20 minutes.

![operate\_LDP\_vqe\_useOpenSearchAPI04.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31515748265747.png)

Use the *more options* `...` button to the right and select `Access to your OpenSearch Dashboards instance` option to be redirected.

![operate\_LDP\_vqe\_useOpenSearchAPI05\*\*.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31515748271123.png)

Once there, use your LDP credentials to sign in.

![operate\_LDP\_vqe\_useOpenSearchAPI06\*.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31654952405651.png)

Click on the `Add data` or `Add sample data` buttons to add sample data you can play with. However, if you want to use your own data, you must configure **Index Patterns** on the stack management page.

![operate\_LDP\_vqe\_useOpenSearchAPI07\*.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31654952417555.png)

To use your own data, click the `Manage` button.

You can also use the `Stack Management` option in the left side menu, displayable by using the top left hamburger `☰` button.

![operate\_LDP\_vqe\_useOpenSearchAPI08\*.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31654939726739.png)

On the following page, click `Index patterns` and then `+ Create index pattern`.

![operate\_LDP\_vqe\_useOpenSearchAPI09\*.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31654939731219.png)

Choose `Use default data source`, then click `Next step >`.

![operate\_LDP\_vqe\_useOpenSearchAPI10\*.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31654952443539.png)

In this configuration page, the full name of your alias **logs-XXXXX-a-XXXXX** can be the Index name but you can also use wildcards. Once you've set a name, click `Next step >`.

![operate\_LDP\_vqe\_useOpenSearchAPI11\*\*.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31657738453523.png)

Select `timestamp` for the Time Field and then click `Create index pattern`.

![operate\_LDP\_vqe\_useOpenSearchAPI12\*\*.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31657738457747.png)

The following screen will allow you to edit the fields of your index. You can also delete the index pattern using the trash can icon in the upper-right corner.

![operate\_LDP\_vqe\_useOpenSearchAPI13\*\*.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31657738464531.png)

Use the hamburger `☰` button in the upper left corner and click `Discover` to see your log entries.

![operate\_LDP\_vqe\_useOpenSearchAPI14\*.png](/images/manage-and-operate/observability/using-opensearch-dashboards-with-logs-data-platform/31657738468499.png)

You can also explore any [OpenSearch index](https://support.us.ovhcloud.com/hc/en-us/articles/29215655915923) you created on the platform. One OpenSearch Dashboards instance allows you to explore all the data you delivered on Logs Data Platform.

To know what you can do with OpenSearch Dashboards, read the [OpenSearch Dashboards documentation](https://opensearch.org/docs/latest/dashboards/index/).
