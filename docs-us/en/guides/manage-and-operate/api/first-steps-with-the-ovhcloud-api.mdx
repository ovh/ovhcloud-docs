# First steps with the OVHcloud API

**Learn how to use OVHcloud APIs and pair them with your applications.**

The APIs available on [https://api.us.ovhcloud.com/](https://api.us.ovhcloud.com/) allow you to purchase, manage, update, and configure OVHcloud products without using a graphical interface such as the Control Panel.

 

## Requirements

- Access to your [OVHcloud account](https://support.us.ovhcloud.com/hc/en-us/articles/115001286870)

- Access to the [OVHcloud API](https://api.us.ovhcloud.com/)

### Simple Use

#### Sign in to OVHcloud APIs

On the [OVHcloud API](https://api.us.ovhcloud.com/) page, click `Explore the OVHcloud API` to view the list of APIs.

![manage\_API\_firstSteps01\*.png](/images/manage-and-operate/api/first-steps-with-the-ovhcloud-api/30657525143443.png)

To use the APIs on your products, you must sign in to this site using your OVHcloud credentials.

- Click `Authentication` in the upper left.
- Select `Login with OVHcloud SSO`.

![manage\_API\_firstSteps02\*.png](/images/manage-and-operate/api/first-steps-with-the-ovhcloud-api/30657556863891.png)

- Enter your OVHcloud credentials and click `Login`.

  :::info

  If you are a sub-user, enter your account ID (in the format **XXXX-XXXX-XX/user**) and password.

  :::

![manage\_API\_firstSteps03\*.png](/images/manage-and-operate/api/first-steps-with-the-ovhcloud-api/30657525162643.png)

- Click `Authorize`.

  :::info

  If your OVHcloud account is protected by [two-factor authentication](https://support.us.ovhcloud.com/hc/en-us/articles/115001825710), you will also need to enter the code generated by SMS or OTP mobile application or U2F key.

  :::

![manage\_API\_firstSteps04\*.png](/images/manage-and-operate/api/first-steps-with-the-ovhcloud-api/30657525171603.png)

 

#### Explore available APIs

You can see a list of OVHcloud products that can be managed with APIs in the upper-left corner. This list is sorted alphabetically.

![manage\_API\_firstSteps05\*.png](/images/manage-and-operate/api/first-steps-with-the-ovhcloud-api/30657525179411.png)

For example, to view the Public Cloud APIs, click **/cloud** in the list.

After you click the product, a list of the product’s APIs appears below.

There is also a Filter feature to limit the visible API calls. You can also use the selector to the left of the branch name to switch between the **/v1** and **/v2** branches of the API.

![manage\_API\_firstSteps06\*.png](/images/manage-and-operate/api/first-steps-with-the-ovhcloud-api/30657525203731.png)

 

#### Run API

There are four types of APIs available that use what are called HTTP methods:

**GET**

The GET method is used to retrieve data from a resource.

For example, to retrieve a list of your instances, use the following API:

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\{serviceName\}/instance"} regions={["us"]} />

**POST**

The POST method is used to send additional data to the resource.

For example, to create a new instance, use the following API:

<Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\{serviceName\}/instance"} regions={["us"]} />

**PUT**

The PUT method is used to replace the current data in the resource with the data in the query.

For example, to alter an instance in your project, use the following API:

<Api version="v1" section="/cloud" method="PUT" route={"/cloud/project/\{serviceName\}/instance/\{instanceId\}"} regions={["us"]} />

**DELETE**

The DELETE method is used to delete the called resource.

For example, to delete an instance from your project, use the following API:

<Api version="v1" section="/cloud" method="DELETE" route={"/cloud/project/\{serviceName\}/instance/\{instanceId\}"} regions={["us"]} />

 

##### **API parameters**

After you click the API you want, the **REQUEST** section allows you to assign variables for its application.

For example, when retrieving a list of instances in a project, you must enter the **serviceName** and can also add information in the **region** variable.

Once you have set the parameters, you can launch the API by clicking `TRY`.

![manage\_API\_firstSteps07\*\*.png](/images/manage-and-operate/api/first-steps-with-the-ovhcloud-api/30657556932499.png)

The `RESPONSE` tab below provides the API execution report.

![manage\_API\_firstSteps08\*.png](/images/manage-and-operate/api/first-steps-with-the-ovhcloud-api/30658346288787.png)

Scrolling down further will reveal PHP and Python tabs containing the elements to be added to your script, depending on the language used.

 

### Advanced usage: pair OVHcloud APIs with an application

#### Create your app keys

Any application that wants to communicate with the OVHcloud API must be declared in advance.

:::tip

Click the tab for the type of user you are: Root or Sub.

:::

<Tabs>

<Tab label="Root User">

Use the following link: [https://api.us.ovhcloud.com/createToken/](https://api.us.ovhcloud.com/createToken/).

Fill in:

- your OVHcloud **Account ID** (email address) and **password**
- a script **name** and **description**
- a **Validity** period
- the **Rights** you want to allow

:::info

To allow all OVHcloud APIs for an HTTP method, put an asterisk (`*`) into the "path" field.

:::

Click the `+` button to add additional rights to PUT, POST, and/or DELETE. Click the `-` button to remove any of those rights.

Click `Create keys`.

![manage\_API\_firstSteps09a\*.png](/images/manage-and-operate/api/first-steps-with-the-ovhcloud-api/30657556950547.png)

</Tab>

<Tab label="Sub-User">

Use the following link: [https://us.ovhcloud.com/auth/api/createToken](https://us.ovhcloud.com/auth/api/createToken).

Log in with your sub-user account ID (in the format **XXXX-XXXX-XX/user**) and password and click `Login`.

![manage\_API\_firstSteps09b\*.png](/images/manage-and-operate/api/first-steps-with-the-ovhcloud-api/30657556966803.png)

Fill in:

- an application **name** and **description**
- a **Validity** period
- the **Rights** you want to allow

:::info

To allow all OVHcloud APIs for an HTTP method, put an asterisk (`*`) into the "path" field.

:::

Click the `+` button to add additional rights to PUT, POST, and/or DELETE. Click the `-` button to remove any of those rights.

Click `Create`.

![manage\_API\_firstSteps10b\*.png](/images/manage-and-operate/api/first-steps-with-the-ovhcloud-api/30657525268755.png)

</Tab>

</Tabs>

 

The next screen will show you a set of three keys:

- the application key, or **AK**. For example:

```
7kbG7Bk7S9Nt7ZSV
```

- the application secret, or **AS**, is not to be disclosed. For example:

```
EXEgWIz07P0HYwtQDs7cNIqCiQaWSuHF
```

- the consumer key, or **CK**, is not to be disclosed. For example:

```
MtSwSrPpNjqfVSmJhLbPyr2i45lSwPU1
```

In this case, the **CK** key is attached to your account.

The **CK** token can be used for rights delegation.

 

#### First API usage

Once you have obtained your three keys (**AK**, **AS**, **CK**), you can sign API requests. The signature is calculated as follows:

```
"$1$" + SHA1_HEX(AS+"+"+CK+"+"+METHOD+"+"+QUERY+"+"+BODY+"+"+TSTAMP)
```

To simplify the development of your applications, OVHcloud provides API wrappers in multiple languages. Using them will help you avoid worrying about signing requests so that you can focus on developing your application.

- *Perl*: [https://api.us.ovhcloud.com/wrappers/OvhApi-perl-1.1.zip](https://api.us.ovhcloud.com/wrappers/OvhApi-perl-1.1.zip)
- *Python*: [https://github.com/ovh/python-ovh](https://github.com/ovh/python-ovh)
- *PHP*: [https://github.com/ovh/php-ovh](https://github.com/ovh/php-ovh)
- *Node.js*: [https://github.com/ovh/node-ovh](https://github.com/ovh/node-ovh)
- *Swift*: [https://github.com/ovh/swift-ovh](https://github.com/ovh/swift-ovh)
- *C#*: [https://github.com/ovh/csharp-ovh](https://github.com/ovh/csharp-ovh)

Here is an example of how to use the `/me` section to manage your OVHcloud account:

```python
import ovh

# Instantiate. Visit https://api.us.ovhcloud.com/createToken/?GET=/me
# to get your credentials
client = ovh.Client(
    endpoint='ovh-eu',
    application_key='<application key>',
    application_secret='<application secret>',
    consumer_key='<consumer key>',
)

# Print nice welcome message
print("Welcome", client.get('/me')['firstname'])
```

 

#### List and revoke your keys

<Tab label="Via OVHcloud API">

To see or revoke your keys, you must use the [OVHcloud API](https://api.us.ovhcloud.com/).

List the keys IDs:

<Api version="v1" section="/me" method="GET" route={"/me/api/application"} regions={["us"]} />

Get key details:

<Api version="v1" section="/me" method="GET" route={"/me/api/application/\{applicationId\}"} regions={["us"]} />

<Api version="v1" section="/me" method="DELETE" route={"/me/api/application/\{applicationId\}"} regions={["us"]} />
