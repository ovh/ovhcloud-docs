# Enabling Entra ID SSO connections with your OVHcloud account

**Learn how to associate your OVHcloud account with an external Entra ID.**

You can use **Single Sign-On** (SSO) to connect to your OVHcloud account. To enable these connections, your account and your Entra ID have to be configured using SAML (*Security Assertion Markup Language*) authentications.

 

## Requirements

- Belong to the **Application Administrator** and **User Administrator** roles of an Entra ID service
- An [OVHcloud account](/guides/account/account-information/create-account)
- Access to the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub)

 

## Instructions

:::info

For a service provider (i.e. your OVHcloud account) to establish an SSO connection with an identity provider (i.e. your Entra ID), the essential part is to establish a mutual trust relationship by registering the SSO connection in both services.

:::

### Entra ID Users and Groups

Your Entra ID acts as your identity provider. Authentication requests by your OVHcloud account will only be accepted if it is declared as a trusted party first.

Let's focus for a moment on the identities on the identity provider side.

 

#### Entra ID Users

To start, go to your Entra ID dashboard.

![Entra ID SSO - step 1](/images/account/account-information/sso-entra-id/entra-id-sso-01.png)

Then click `Users` from the left-hand menu.

![Entra ID SSO - step 2](/images/account/account-information/sso-entra-id/entra-id-sso-02.png)

Create as many users as you need, or you can just check your users by clicking on them.

For this example, the user **John Smith** will be used.

![Entra ID SSO - step 3](/images/account/account-information/sso-entra-id/entra-id-sso-03.png)

When an SSO authentication is performed, **John Smith**'s identity will be provided by Entra ID to the OVHcloud account. However, it is necessary that this identity contains at least one group. If no group exists, let's look at how to create one to add **John Smith** to it.

 

#### Entra ID Groups

Click on `Groups` from the left-hand menu.

![Entra ID SSO - step 4](/images/account/account-information/sso-entra-id/entra-id-sso-04.png)

Click on `New group` in the top menu, and fill in all the necessary information.

For this example, the group **manager\@ovhcloudsaml** will be used.

![Entra ID SSO - step 5](/images/account/account-information/sso-entra-id/entra-id-sso-05.png)

Click on the `Create` button to display all information about this group.

![Entra ID SSO - step 6](/images/account/account-information/sso-entra-id/entra-id-sso-06.png)

Now, users who will be used for SSO authentication must be added to a group.

In this example, let's link the user **John Smith** with the group **manager\@ovhcloudsaml**.

In the selected group interface, click on `Members` from the left-hand menu, then click `Add members` in the top menu.

![Entra ID SSO - step 7](/images/account/account-information/sso-entra-id/entra-id-sso-07.png)

Select the user to be added to this group, then click on the `Select` button.

![Entra ID SSO - step 8](/images/account/account-information/sso-entra-id/entra-id-sso-08.png)

Now we have a user assigned to a group.

To perform SSO authentications, an Entra ID application must be created.

SSO must be configured on this application.

 

### Entra ID applications

First of all, it is necessary to create an application if one does not yet exist.

#### Create an Entra ID application

Click on `Enterprise applications` from the left-hand menu.

![Entra ID SSO - step 9](/images/account/account-information/sso-entra-id/entra-id-sso-09.png)

Click on `New application` in the top menu.

![Entra ID SSO - step 10](/images/account/account-information/sso-entra-id/entra-id-sso-10.png)

Click on `Create your own application` in the top menu.

![Entra ID SSO - step 11](/images/account/account-information/sso-entra-id/entra-id-sso-11.png)

Select the `Integrate any other application you don't find in the gallery (Non-gallery)` option, and click on the `Create` button.

![Entra ID SSO - step 12](/images/account/account-information/sso-entra-id/entra-id-sso-12.png)

The details of the application will then be displayed.

![Entra ID SSO - step 13](/images/account/account-information/sso-entra-id/entra-id-sso-13.png)

The Entra ID application is now created. Users who want to perform SSO authentications via this application must now be added to it.

 

#### Entra ID application - User assignment

:::info

In order for a user to perform an SSO authentication from an Entra ID application, it must be added to that application. It is therefore shown here how to add a user to an Entra ID application.

However, it is better to add a user group instead of users if you have **Entra ID Premium**.

:::

Click on `Users and groups` from the left-hand menu, then click `Add user/group` in the top menu.

![Entra ID SSO - step 15](/images/account/account-information/sso-entra-id/entra-id-sso-15.png)

Click then on the `Users` section, select the user to add to the application, and click on the `Select` button.

![Entra ID SSO - step 14](/images/account/account-information/sso-entra-id/entra-id-sso-14.png)

The application is created, a user has been assigned, and all that remains is to set up the SSO via SAML.

Click `Assign` to add the user assignment.

![Entra ID SSO 14](/images/account/account-information/sso-entra-id/entra-id-sso-14-b.png)

 

#### Entra ID application SSO

Get back to the overview via the `Overview` button from the left-hand menu, then click on the `Set up single sign on` section.

![Entra ID SSO - step 16](/images/account/account-information/sso-entra-id/entra-id-sso-16.png)

Click on the `SAML` section.

![Entra ID SSO - step 17](/images/account/account-information/sso-entra-id/entra-id-sso-17.png)

Click on `Upload metadata file` in the top menu.

![Entra ID SSO - step 18](/images/account/account-information/sso-entra-id/entra-id-sso-18.png)

Click on the `Select a file` icon button, select the OVHcloud Service Provider metadata file, and click on the `Add` button.

You can obtain the US region metadata file via the following link: [https://us.ovhcloud.com/auth/sso/saml/sp/metadata.xml](https://us.ovhcloud.com/auth/sso/saml/sp/metadata.xml)

![Entra ID SSO - step 19](/images/account/account-information/sso-entra-id/entra-id-sso-19.png)

The SAML configuration will be displayed. The **Entity ID** and **URL** are: `https://us.ovhcloud.com/auth/`

Click `Save` and close the window.

![Entra ID SSO - step 20](/images/account/account-information/sso-entra-id/entra-id-sso-20.png)

In the **Attributes & Claims&#x20;**&#x73;ection, click on the `Edit` button.

![Entra ID SSO - step 21](/images/account/account-information/sso-entra-id/entra-id-sso-21.png)

You now need to add a UPN (User Principal Name) attribute to SAML info, in order to inform OVHcloud about the user's email. This step is mandatory.

Click on `Add a new claim` in the top menu.

Fill in the **Name** field with `http://schemas.xmlsoap.org/ws/2005/05/identity/claims/upn`.

Fill in the **Source attribute** field with `user.mail`.

Click on `Save`.

![Account service management information OVHcloud connect](/images/account/account-information/sso-entra-id/account-service-management-information-ovhcloud-connect.png)

Now let's declare the attribute for the user group.

Click on `Add a group claim` in the top menu.

![Entra ID SSO - step 22](/images/account/account-information/sso-entra-id/entra-id-sso-22.png)

Select `Security groups`, `Group ID` from the **Source attribute**, and click on the `Save` button.

![Entra ID SSO - step 23](/images/account/account-information/sso-entra-id/entra-id-sso-23.png)

The **groups** claim should now appear in the list.

Copy and save the **Claim name** value somewhere (i.e a notepad), it will be necessary later.

![Entra ID SSO - step 24](/images/account/account-information/sso-entra-id/entra-id-sso-24.png)

In the **SAML Certificates** section, copy the `App Federation Metadata Url` field value.

Use this link to download the Entra ID application metadata file to use it later in the OVHcloud account.

![Entra ID SSO - step 25](/images/account/account-information/sso-entra-id/entra-id-sso-25.png)

 

### Establishing OVHcloud account trust and configuring the connection

#### Establish OVHcloud trust

Adding your Entra ID application as a trusted identity provider is done in the [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/hub) where you can provide the identity provider metadata.

1. Click your `name` and then your `initials`.
2. Select `Identity and Access Management (IAM)` from the left-hand menu.
3. Click the `Identities` tab to access local users management.

![Local identities - SSO entra id](/images/account/account-information/sso-entra-id/local-identities.png)

Click on the `SSO connection` button.

![Entra ID SSO - step 29](/images/account/account-information/sso-entra-id/entra-id-sso-29.png)

Fill in the **Group attribute name** field with the Entra ID application groups **Claim name** value saved before.

Fill in the XML metadata of your Entra ID application from the file saved before. Click on `Confirm`.

:::info

You can keep local users by ticking the `Keep active OVHcloud users` box.

:::

![Entra ID SSO - step 30](/images/account/account-information/sso-entra-id/entra-id-sso-30.png)

The trust of your Entra ID application as the identity provider is thus established but you still have to add groups to your OVHcloud account.

:::warning

**NOTE:** If you try to connect at this stage via SSO, you will probably receive a `Not in valid groups` error message.\
\
That is because your OVHcloud account checks if the authenticating user belongs to a group that actually exists on the account.

:::

To resolve this, check the "Group" attribute that your Entra ID application returns: the **Object Id** field.

 

#### OVHcloud groups declaration

![Entra ID SSO - step 31](/images/account/account-information/sso-entra-id/entra-id-sso-31.png)

Add it by clicking on the `Declare a group`.

![Entra ID SSO - step 32](/images/account/account-information/sso-entra-id/entra-id-sso-32.png)

Fill in the fields, then click on the `Confirm` button.

![Entra ID SSO - step 33](/images/account/account-information/sso-entra-id/entra-id-sso-33.png)

The created group should appear on the list.

![Entra ID SSO - step 34](/images/account/account-information/sso-entra-id/entra-id-sso-34.png)

 

### Connect via SSO

On the [OVHcloud login page](https://us.ovhcloud.com/auth/?action=disconnect\&onsuccess=https%3A%2F%2Fus.ovhcloud.com%2Fmanager%2F\&from=https%3A%2F%2Fus.ovhcloud.com%2F), enter your [customer code](/guides/account/account-information/create-account#what-is-my-customer-code) followed by **/idp** without entering a password, and click the `Login` button.

![Local login - SSO entra id](/images/account/account-information/sso-entra-id/local-login.png)

You are then redirected to your Entra ID application login page. Select `Use another account`.

![Entra ID SSO - step 36](/images/account/account-information/sso-entra-id/entra-id-sso-36.png)

Enter the Entra ID application user email and click on the `Next` button.

![Entra ID SSO - step 37](/images/account/account-information/sso-entra-id/entra-id-sso-37.png)

Enter the Entra ID application user password and click on the `Sign In` button.

![Entra ID SSO - step 38](/images/account/account-information/sso-entra-id/entra-id-sso-38.png)

You are now logged in with the same customer code, but via your Active Directory user and using your Entra ID application SSO.

![Local account - SSO entra id](/images/account/account-information/sso-entra-id/local-account.png)

If your email does not appear below `Connected via SSO`, you have not configured the **UPN** attribute properly, and some of the features will not work correctly.
