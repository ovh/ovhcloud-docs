# How to restrict local users from billing information in the OVHcloud Control Panel

## Requirements

- An [OVHcloud Control Panel](/guides/account/account-information/create-account) account

 

## Instructions

### Create a group with no rights

Navigate to the `Identities` menu in your [OVHcloud Control Panel](https://us.ovhcloud.com/manager/#/iam/identities/users) and select the `User groups` tab.

Click `Declare a group`.

![Identities user groups](/images/account/account-information/restrict-local-users-from-billing-information/identities-user-groups.png)

Enter a **Group name** (a **Group description** is optional) and set the **Role** to `None`, and then click `Confirm`.

![Identities add group](/images/account/account-information/restrict-local-users-from-billing-information/identities-add-group.png)

 

### Assign user(s) to the group

<Tabs>

<Tab label="New users">

In the `Local users` tab, click `Add user`.

![Identities tab empty](/images/account/account-information/restrict-local-users-from-billing-information/identities-tab-empty.png)

Fill in the fields, select the **Group** you created in the [previous step](#create-a-group-with-no-rights), and click `Confirm`.

![Identities add user no](/images/account/account-information/restrict-local-users-from-billing-information/identities-add-user-no.png)

</Tab>

<Tab label="Existing users">

In the `Local users` tab, click the *more options* `...` button to the right of the user you wish to restrict and select `Update user`.

![Identities tab more](/images/account/account-information/restrict-local-users-from-billing-information/identities-tab-more.png)

On the next screen, select the **Group** you created in the [previous step](#create-a-group-with-no-rights). and click `Confirm`.

![Identities update user](/images/account/account-information/restrict-local-users-from-billing-information/identities-update-user.png)

</Tab>

</Tabs>

 

### Create the policy

Please follow [this guide](/guides/account/account-information/iam-control-panel-access) to create your policy, while taking note of the following modification:

When creating the policy, under the **Identities** heading, link the the **User group** created in the [first step of this guide](#create-a-group-with-no-rights).

 

### Allowing users to see and use your services

To allow your local users to access your services again (without overriding the policy created above), you will need to create one or more new policies and carefully select the **Actions** to authorize.

Below is an example for allowing access to a dedicated server:

1. Select the **Product types** and **Resources** you want your users to be able to read and/or use.

   ![Policies tutorial - Restrict local users from billing information](/images/account/account-information/restrict-local-users-from-billing-information/policies-tutorial.png)

2. Scroll down to the **Actions** section and authorize all actions in for the Product type (e.g., Dedicated Server) except `dedicatedServer:notification:receive/billing` under **NOTIFICATION**.

   ![Policies tutorial - Restrict local users from billing information - step 2](/images/account/account-information/restrict-local-users-from-billing-information/policies-tutorial-2.png)

:::warning

**NOTE:** If you want to restrict the user from ordering or deleting services, you can unselect those actions from the list. Using CTL+F to search for terms, such as "order," "cancel," "terminate," and "bill," can be useful in finding those actions in the lists.

![Policies tutorial - Restrict local users from billing information - step 3](/images/account/account-information/restrict-local-users-from-billing-information/policies-tutorial-3.png)

:::
