# Change your Block Storage volume type

The Block Storage volumes can be upgraded or downgraded; for example, changed from Classic to High-speed-gen-2 and back again.

:::info

Volume retyping is not available for encrypted volumes. To learn how to migrate a Block Storage volume to an encrypted LUKS volume, see our [Migrating a Block Storage volume to an encrypted LUKS volume](/storage-and-backup/block-storage/migrating-non-encrypted-to-encrypted-volume) guide.

:::

 

## Requirements

- Access to the [Horizon Interface](/public-cloud/cross-functional/introducing-horizon)
- A [Block Storage volume](/storage-and-backup/block-storage/create-and-configure-an-additional-disk-on-an-instance) created in your [Public Cloud project](https://us.ovhcloud.com/public-cloud/)

#### OVHcloud Console access

- **Direct link:** [Public Cloud projects](https://console.us.ovhcloud.com/#/public-cloud/project)
- **Navigation path:** `Public Cloud` > `Projects` > Select your project > `Storage` > `Block Storage`

 

## Instructions

When trying to change a block storage volume type, the migration policy will need to be changed to `On-demand`.

The migration policy is set by default to `Never`, as the volume stays on the same CEPH cluster. However, for retyping, the volume will need to be migrated to a new cluster.

This modification can be made via Horizon or the OpenStack CLI.

:::warning

**NOTE:** If the Block Storage volume is attached to an instance, you must first detach it before proceeding. For more information, see the **Detach a volume** section of the guide "[Creating and configuring an additional disk on an instance](/storage-and-backup/block-storage/create-and-configure-an-additional-disk-on-an-instance#detach-a-volume)".

Changing the volume type (retyping) via the OVHcloud Console or the OVHcloud API is available only for unencrypted volumes. Encrypted volumes of type **-LUKS** cannot be retyped.

Conversions from **-LUKS** to **non -LUKS** (or vice versa) are not supported, including via OpenStack / Horizon.

:::

 

<Tabs>

<Tab label="Via the OVHcloud Console">

In the left-hand menu of your Public Cloud project, click `Block Storage` under **Storage**.

Click the `⋮` button on the row of your volume, then select `Change volume type`.

In the **Change your offer type** panel:

- If the volume is attached to an instance, type `DETACH` to confirm that it will be detached, then click `Confirm and continue`.
- If the volume has snapshots, type `DELETE` to confirm that they will be deleted, then click `Confirm and continue`.
- Select the new type for your volume (the **Current type** is indicated), then click `Confirm`.

:::info

Changing the volume type (retyping) may take a few minutes.

:::

</Tab>

<Tab label="Via OpenStack CLI">

:::info

Make sure to consult the following guide before proceeding: [Preparing an environment for using the OpenStack API](/public-cloud/cross-functional/compute-prepare-openstack-api-environment).

:::

Find the volume ID of the Block Storage volume you wish to retype. With this command, you will also be able to see the volumes' current type.

```bash
openstack volume list --long
```

Next, list the types of volumes available in your region with the following command:

```bash
openstack volume type list
+--------------------------------------+-----------------------------------------------+----------+
| ID                                   | Name                                          | Is Public|
+--------------------------------------+-----------------------------------------------+----------+
| 27844ef7-1a9a-4944-be59-6e4eb19a71f6 | high-speed-gen2                               |      True|
| 23f75fef-d4f6-416a-a884-95aa3fd45695 | classic                                       |      True|
| 2f78e8af-93c9-4e5c-b177-83c4a7ec456a | high-speed                                    |      True|
----------------------------------------------------------------------------------------------------
```

:::warning

**NOTE:** Please note that if "high-speed-gen2" does not appear in the list, it means that it is not available in this region.

:::

Then, switch volume types with the following command:

```bash
openstack volume set --type <VOLUME_TYPE> --retype-policy on-demand <VOLUME_NAME_OR_ID>
```

Run `openstack volume list --long` again to check the volume's new type.

</Tab>

<Tab label="Via the Horizon Interface">

Log in to the [Horizon interface](https://horizon.cloud.ovh.us/auth/login/) and make sure you are in the correct region. You can verify this in the top left corner.

![Horizon select region](/images/storage-and-backup/block-storage/switch-volume-type/horizon-select-region.png)

Next, open the **Volumes** menu on the left side and click on `Volumes`.

![Horizon volumes classic](/images/storage-and-backup/block-storage/switch-volume-type/horizon-volumes-classic.png)

Find the row for your volume in the table, click on the drop-down arrow next to `Edit Volume`, and select `Change Volume Type`.

![Horizon volumes more options](/images/storage-and-backup/block-storage/switch-volume-type/horizon-volumes-more-options.png)

In the pop-up window:

- For **Type**, select a new volume type.
- For **Migration Policy**, select `On Demand`.

Once done, click on `Change Volume Type` to confirm the change.

![Horizon volumes change](/images/storage-and-backup/block-storage/switch-volume-type/horizon-volumes-change.png)

The Volumes page will refresh itself, and you will see the change reflected in the **Type** column.

![Horizon volumes high speed](/images/storage-and-backup/block-storage/switch-volume-type/horizon-volumes-high-speed.png)

</Tab>

</Tabs>

 

:::warning

**NOTE:** The larger your volume, the longer it may take for the retyping process to complete.

:::
