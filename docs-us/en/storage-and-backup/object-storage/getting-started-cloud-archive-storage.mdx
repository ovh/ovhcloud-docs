# Getting started with Cloud Archive Storage

The Public Cloud Archive offer is an unlimited storage solution with simple billing tailored to your needs. There are many types of object containers:

- For static hosting (static website).
- For private hosting (e.g., storage of personal data).
- For public hosting (to store everything that is accessible to the public).
- For cold storage (archiving).

 

## Requirements

- Access to the [OVHcloud Console](https://console.us.ovhcloud.com/)
- A [Public Cloud project](/public-cloud/cross-functional/create-a-public-cloud-project) in your account

 

## Instructions

### Creating a Public Cloud Archive container

Log in to the [OVHcloud Console](https://console.us.ovhcloud.com/#/public-cloud/project) and select your Public Cloud project.

In the left-hand menu of your Public Cloud project, click `Cloud Archive` under **Storage**, then click `Create an archive container`.

{/* cp-shot: ![Manager onboarding - Getting started cloud archive storage](/images/storage-and-backup/object-storage/getting-started-cloud-archive-storage/manager-onboarding.png) */}

Name your container, then select the region of your container:

:::warning

**NOTE:** If you want to link your container to a domain name, your container name must not contain the following characters:

- \[ . ]
- \[ \_ ]
- And you must not use capital letters.

:::

{/* cp-shot: ![Manager order region](/images/storage-and-backup/object-storage/getting-started-cloud-archive-storage/manager-order-region.png) */}

{/* cp-shot: ![Manager order container name](/images/storage-and-backup/object-storage/getting-started-cloud-archive-storage/manager-order-container-name.png) */}

Check the summary, then click `Create`. Your container appears in the **Cloud Archive** list.

 

### Managing and canceling your container

Once your container is created, you can manage or cancel your container by clicking the `⋮` button to the right of your container and selecting `Delete`.

{/* cp-shot: ![Manager service creation more](/images/storage-and-backup/object-storage/getting-started-cloud-archive-storage/manager-service-creation-more.png) */}
