# Object Storage Swift - Getting started

The Object Storage Swift solution for Public Cloud offers unlimited storage with simple billing tailored to your needs. Containers can be configured for different use cases:

- Static hosting (static website)
- Private hosting (e.g. personal data storage)
- Public hosting (publicly accessible content)
- Cold storage (archiving)

 

## Requirements

- A [Public Cloud project](/public-cloud/cross-functional/create-a-public-cloud-project) in your OVHcloud account

- Depending on the tool you plan to use:

  - **Swift S3**[**1**](#go-further)**&#x20;API**: An environment [prepared for the OpenStack API](/public-cloud/cross-functional/compute-prepare-openstack-api-environment) with `python-openstackclient` and `awscli` installed
  - **Swift client**: An environment [prepared for the OpenStack API](/public-cloud/cross-functional/compute-prepare-openstack-api-environment) with `python-swiftclient` installed
  - **OVHcloud CLI**: The [OVHcloud CLI](/manage-and-operate/cli/getting-started-ovhcloud-cli) installed and configured

---

### OVHcloud Console access

- **Direct link:** [Public Cloud projects](https://console.us.ovhcloud.com/#/public-cloud/project)
- **Navigation path:** `Public Cloud` > `Projects` > Select your project > `Storage` > `Object Storage`

## Instructions

### Preparation

<Tabs>

<Tab label="OVHcloud Console">

In the left-hand menu of your Public Cloud project, click `Object Storage` under Storage.

</Tab>

<Tab label="Swift S3 API">

**Set the OpenStack environment variables**

```
source <user_name>-openrc.sh
Please enter your OpenStack Password for project <project_name> as user <user_name>:
```

**Install the OpenStack client if needed**

```
pip install python-openstackclient
```

OpenStack client command reference: [docs.openstack.org](https://docs.openstack.org/python-openstackclient/latest/)

**Create EC2 credentials**

S3 tokens require two parameters — **access** and **secret** — generated from Keystone:

```
openstack ec2 credentials create
+------------+----------------------------------------------------------------------------------------------------------------------------------------+
| Field      | Value                                                                                                                                  |
+------------+----------------------------------------------------------------------------------------------------------------------------------------+
| access     | 5a4d8b8d88104123a862c527ede5a3d3                                                                                                       |
| links      | {u'self': u'https://auth.cloud.ovh.us/v3/users/d74d05ff121b44bea9216495e7f0df61/credentials/OS-EC2/5a4d8b8d88104123a862c527ede5a3d3'} |
| project_id | 20e124b71be141299e111ec26b1892fa                                                                                                       |
| secret     | 925d5fcfcd9f436d8ffcb20548cc53a2                                                                                                       |
| trust_id   | None                                                                                                                                   |
| user_id    | d74d05ff121b44bea9216495e7f0df61                                                                                                       |
+------------+----------------------------------------------------------------------------------------------------------------------------------------+
```

**Configure the AWS client**

Install `awscli`:

<details>
<summary>Python package</summary>

```
pip install awscli
```

</details>

<details>
<summary>Debian-based OS</summary>

```
sudo apt install awscli
```

</details>

<details>
<summary>RHEL-based OS</summary>

```
sudo yum install awscli
```

</details>

Then configure it with the EC2 credentials generated above:

<details>
<summary>CLI method</summary>

```
aws configure
```

Follow the prompts and enter your access key and secret key when asked.

</details>

<details>
<summary>Manual method</summary>

```
cat ~/.aws/credentials
```

```
[default]
aws_access_key_id = <access_key>
aws_secret_access_key = <secret_key>
```

```
cat ~/.aws/config
```

```
[plugins]
endpoint = awscli_plugin_endpoint
[default]
region = <region>
s3 =
  endpoint_url = https://s3.<region>.cloud.ovh.us
  signature_version = s3v4
s3api =
  endpoint_url = https://s3.<region>.cloud.ovh.us
```

</details>

:::info

Both virtual-hosted-style and path-style access are supported; virtual-hosted-style is recommended, as path-style was deprecated after September 30, 2020.

:::

</Tab>

Set the OpenStack environment variables:

```
source <user_name>-openrc.sh
```

Verify your setup:

```
swift --help
```

For the full list of Swift commands, refer to the [OpenStack documentation](https://docs.openstack.org/python-swiftclient/latest/cli/index.html).

### Create a container

:::info

When using the **Swift S3 API**, bucket names must follow these rules:

- Between 3 and 63 characters long
- Lowercase letters, numbers, periods, and dashes only
- Must start with a lowercase letter or number
- No underscores, no consecutive periods, no dashes adjacent to periods
- Not formatted as an IP address (e.g. `198.51.100.24`)

:::

<Tabs>

<Tab label="OVHcloud Console">

In the `Containers` tab, click `Create an object container`.

Fill in the creation form:

- Container type: Select Swift API.
- Container name: Enter a name for your container.
- Region: Select the region where your container will be created.
- Second **Container type** section: choose Private, Public, or Static hosting.

Review the summary panel, then click `Create`.

</Tab>

<Tab label="Swift S3 API">

```
aws s3 mb s3://<container_name>
```

:::info

S3 buckets can only be created on the PCS (Object Storage) policy.

:::

</Tab>

<Tab label="Swift client">

Create the container:

```
swift post container1
```

To make the container publicly accessible:

```
swift post --header "X-Container-Read: .r:*" container1
```

Verify the configuration:


</Tab>

```

```

</Tab>

<Tab label="OVHcloud CLI">


</Tab>

### Upload objects

<Tabs>

<Tab label="OVHcloud Console">

In the `Containers` tab, click the name of your container, open its `Objects` tab, then click `Add an object`.

You can enter a prefix, then drag and drop your files or click `Browse files`, and click `Upload`.

</Tab>

<Tab label="Swift S3 API">

```
aws s3 cp /path/to/<object_name> s3://<container_name>/<object_name>
```

</Tab>

<Tab label="Swift client">

Upload a single file:

```
swift upload container1 file.txt
```

Upload an entire folder (a prefix matching the folder name is automatically added to the objects):

```
swift upload container1 images/

images/OVHlogo.png
images/OVHSummitKeynote.jpg
```

</Tab>

<Tab label="OVHcloud CLI">

Object upload is not available via the OVHcloud CLI. Use the OVHcloud Console, the Swift S3 API, or the Swift client instead.

</Tab>

</Tabs>

 

### List objects in a container

<Tabs>

<Tab label="OVHcloud Console">

Click the name of your container, then open its `Objects` tab to view its objects.

</Tab>

<Tab label="Swift S3 API">

```
aws s3 ls s3://<container_name>
```

</Tab>

<Tab label="Swift client">

```
swift list container1

images/OVHSummitKeynote.jpg
images/OVHlogo.png
text1.txt
text2.txt
text3.txt
```

Filter by prefix:

```
swift list container1 --prefix images

images/OVHSummitKeynote.jpg
images/OVHlogo.png
```

If the container is public, objects are accessible directly via URL:

```
https://storage.us-east-va.cloud.ovh.us/v1/AUTH_b3e26xxxxxxxxxxxxxxxxxxxb0ba29/container1/images/OVHlogo.png
```

This URL is composed of an endpoint (available from the [Horizon interface](/public-cloud/cross-functional/compute-horizon-access-security)), the container name, and the object name (including prefix).

</Tab>

<Tab label="OVHcloud CLI">

Object listing is not available via the OVHcloud CLI. Use the OVHcloud Console, the Swift S3 API, or the Swift client instead.

</Tab>

</Tabs>

 

### Download objects

<Tabs>

<Tab label="OVHcloud Console">

In the `Objects` tab of your container, click the `Download` icon on the object row.

</Tab>

<Tab label="Swift S3 API">

```
aws s3 cp s3://<container_name>/<object_name> .
```

</Tab>

<Tab label="Swift client">

Download a single file:

```
swift download container1 text1.txt

text1.txt [auth 0.328s, headers 0.452s, total 0.453s, 0.000 MB/s]
```

Download all files with a given prefix:

```
swift download container1 --prefix images

images/OVHlogo.png [auth 0.383s, headers 0.520s, total 0.522s, 0.135 MB/s]
images/OVHSummitKeynote.jpg [auth 0.371s, headers 0.514s, total 0.559s, 2.657 MB/s]
```

</Tab>

<Tab label="OVHcloud CLI">

Object download is not available via the OVHcloud CLI. Use the OVHcloud Console, the Swift S3 API, or the Swift client instead.

</Tab>

</Tabs>

 

### Delete objects and containers

<Tabs>

<Tab label="OVHcloud Console">

**Delete an object**: In the `Objects` tab, click the `Delete` icon on the object row, then click `Delete` to confirm.

**Delete a container**: In the `Containers` tab, click the `⋮` button on the container row, then select `Delete` and confirm.

</Tab>

<Tab label="Swift S3 API">

**Delete an object:**

```
aws s3 rm s3://<container_name>/<object_name>
```

**Delete a container** (the container must be empty first):

```
aws s3 rb s3://<container_name>
```

</Tab>

<Tab label="Swift client">

**Delete a file:**

```
swift delete container1 text1.txt

text1.txt
```

Delete multiple files using a prefix:

```
swift delete container1 images/*

images/OVHSummitKeynote.jpg
images/OVHlogo.png
```

**Delete a container** (also deletes all objects inside it):

```
swift delete container1

text2.txt
text3.txt
```

</Tab>

<Tab label="OVHcloud CLI">

Container and object deletion is not available via the OVHcloud CLI. Use the OVHcloud Console, the Swift S3 API, or the Swift client instead.

</Tab>

</Tabs>
